पञ्चदशः सर्गः

第十五章　シシュパーラの怒り（caidya-kopa-varṇana）
韻律：udgatā（ウドガター）　半頌20+24音節（V.95 vaṃśastha 12音節/pāda　V.96 sragdharā 21音節/pāda）
V.1
Sanskrit (IAST) athatatra pāṇḍutanayena sadasi vihitaṃ muradviṣaḥ / mānamasahata na cedipatiḥ paravṛddhimatsari mano hi māninām //
和訳

さてその場で、パーンドゥの子が敵ムラの討滅者に捧げた栄誉を、チェーディの王は耐えることができなかった。矜持ある者の心は、他者の繁栄を妬むものだからである。

注

【Vallabhadeva】

チェーディパティはシシュパーラのこと。ユディシュティラがクリシュナに対して行ったアルグヤ供養を見て耐えられなかった。「他者の繁栄を妬む」は一般原則で個別事例を根拠づけるarthāntaranyāsa（事例と原則）の修辞。本章の韻律はuddhatā（ウッダター）。

【Mallinātha】

「パーンドゥの子」はユディシュティラ。「ムラの敵」はハリ（クリシュナ）。チェーディパティが彼への供養を「耐えられなかった」とは嫉妬したということ。「他者の繁栄に嫉妬する」のは矜持ある者の心の本性であるという一般命題で個別事例を裏付ける修辞（arthāntaranyāsa）。本章の韻律はudgatā（ウドガター）。

V.2
Sanskrit (IAST) pura eva śārṅgiṇi savairamatha punaramuṃ tadarcayā / manyurabhajadavagāḍhataraḥ samadoṣakāla iva dehinaṃ jvaraḥ //
和訳

以前からシャールンガ弓を持つ者（クリシュナ）に対して敵意を抱いていたが、さらにこのたびの供養によって、一層深い怒りが彼を襲った。体質の乱れと季節が重なった時に熱病が身体を襲うように。

注

【Vallabhadeva】

以前から敵意があったが、クリシュナへの供養によってさらに深い怒りが襲った。samadoṣakālaは体質の素因（doṣa）と季節（kāla）が均衡した時の比喩。春にはkapha（痰）が増大し、それに合った食事をする者に重い熱病が出るように。

【Mallinātha】

「以前から」シャールンガ弓の主に敵意があった。「さらにその供養によって」一層深い怒り（raudra-rasaの恒常感情）が彼を襲った。doṣa（体液の不調）とkāla（季節的要因）が等しく重なった時の熱病に喩える直喩。

V.3
Sanskrit (IAST) abhitarjayanniva samastanṛpagaṇamasāvakampayat / lolamukuṭamaṇiraśmi śanairaśanaiḥ prakampitajagattrayaṃ śiraḥ //
和訳

王たちの全群を威嚇するかのように、彼はゆるやかに、しかし三界をも揺るがすほどに、冠の宝石の光がゆらめく頭を震わせた。

注

【Vallabhadeva】

チェーディ王が全王族を脅すかのように傲然と頭を振った。冠の宝石の光がゆれ動く（lola）。aśanaiḥは「激しく」の意で、三界を揺るがすほどの首振りであった。

【Mallinātha】

「威嚇するかのように」はutprekṣā（想像法）。aśanaiḥは「激しく」（atimātram）で、三界を揺るがす恐ろしい頭の動き。冠の宝石の光（mukuṭamaṇi-raśmi）がゆらめく中での激しい首振りは怒りの表出。Mallinātha以降八詩節でシシュパーラの身体的な怒りの表現を描写すると注する。

V.4
Sanskrit (IAST) sa vamanruṣāśru ghanagharmavigaladurugaṇḍamaṇḍalaḥ / svedajalakaṇakarālakaro vyarucatprabhinna iva kuñjarastridhā //
和訳

怒りの涙を流し、激しい熱気に頬が大きく濡れ、汗の水滴で手がざらつくその姿は、三方から裂発した象のようであった。

注

【Vallabhadeva】

怒りで涙を流し（vaman）、汗で頬が溶けるように濡れ、汗の雫で手がざらつく姿は、三方からmada（発情液）を流す象（tridhā prabhinna kuñjara）に喩えられる。目・頬・手の三箇所からの分泌がmadの三方向の流出に対応。

【Mallinātha】

怒りで涙を吐き出し（vaman）、激しい怒りの熱（krodhoṣman）で大きな頬が滴る。sveda（汗）はsāttvika-bhāva（真情的感情表出）の一つ。三方（tridhā）とは目・頬・手の三箇所から液体が出る様を、三方向にmadaを流す発情象に喩える。直喩。

V.5
Sanskrit (IAST) sa nikāmagharmitamabhīkṣṇamadhuvadavadhūtarājakaḥ / kṣiptabahulajalabindu vapuḥ pralayārṇavotthita ivādiśūkaraḥ //
和訳

王族の集いを圧倒し、蜜を振るうように何度も身体を激しく振るわせ、おびただしい水滴を飛ばすその姿は、劫末の大海から立ち上がった原初の猪のようであった。

注

【Vallabhadeva】

蜂蜜を振るうように（madhuvat）身体を揺すり、豊かな汗の水滴を散らす様は、大洪水の海から出現した原初のヴァラーハ（猪の化身）に喩えられる。avadhūtarājakaḥ（王族の群を圧倒した）。ヴァラーハが海から出て身を振るい水を飛ばす姿との対比。

【Mallinātha】

nikāmagharmitam（十分に汗をかいた）は体が発汗した状態。madhuvat（蜜を振るうように）身体を振るわせた。rājakam（rājan + vuc接尾辞で集合名詞「王族の群」）を圧倒した。原初のヴァラーハ（ādi-śūkara）がpralaya（劫末）の海から出た時のように水滴を散らす。ここでもsveda（汗）のsāttvika-bhāvaが表現されている。直喩。

V.6
Sanskrit (IAST) kṣaṇamāśliṣadghaṭitaśailaśikharakaṭhināṃsamaṇḍanaḥ / stambhamupahitavidhūtimasāvadhikāvadhūnitasamastasaṃsadam //
和訳

山の頂を組み合わせたように硬い肩を持つ彼は、一瞬、柱を抱きかかえた。その柱を揺さぶり、全会衆をことごとく震撼させたのである。

注

【Vallabhadeva】

チェーディ王が柱（stambha）を瞬時に抱きしめた。ghaṭita（堅固に結合した）śailaśikhara（山の頂）のように硬い肩の力で、その柱を揺さぶり（vidhūti）、全会衆を震撼させた。怒りに我を忘れた者の所業。

【Mallinātha】

āśliṣat（抱擁した）はpuṣ-ādi語群によりaṅ代替でkalaに変化。肩の硬さ（kaṭhina-aṃsa-maṇḍana）は山頂（śailaśikhara）の直喩で形容。upahitavidhūti（揺動を加えた）柱を抱いて激しく震わせ、全集会を揺るがした。肩の硬さが柱を打つ理由であるというkāvyaliṅga（詩的論証）が山頂の直喩と混合（saṅkīrṇa）。

V.7
Sanskrit (IAST) kanakāṅgadadyutibhirasya gamitamarucatpiśaṅgatām / krodhamayaśikhiśikhāpaṭalaiḥ paritaḥ parītamiva bāhumaṇḍalam //
和訳

黄金の腕輪の輝きによって黄褐色に染められた彼の両腕は、怒りの炎の火舌の群に四方から包まれているかのように輝いた。

注

【Vallabhadeva】

チェーディ王の黄金の腕飾り（kanakāṅgada）の光によって黄褐色に染められた両腕の輪が、怒りの炎の火焔に四方から包まれているかのようであった。utprekṣā（想像法）。

【Mallinātha】

kanakāṅgada（黄金の腕輪）の光でpiśaṅgatā（黄褐色）に染められた — これはtadguṇālaṅkāra（属性転移の修辞）。怒りの火の火焔（krodhamaya-śikhi-śikhā-paṭala）に四方から包まれた「かのように」はutprekṣā（想像法）。

V.8
Sanskrit (IAST) kṛtasannidhānamiva tasya punarapi tṛtīyacakṣuṣā / krūramajani kuṭilabhru gurubhrukuṭīkaṭhoritalalāṭamānanam //
和訳

眉がゆがみ、重々しい眉間の皺で額が険しくなったその顔は、あたかも再び第三の眼が宿ったかのように、恐ろしいものとなった。

注

【Vallabhadeva】

シシュパーラは幼児の頃に第三の眼を持っていたが、クリシュナの膝に乗せられた時に消えた。その第三の眼がふたたび現れたかのような恐ろしい顔。眉（bhrū）のゆがみと額の皺が、シヴァの第三眼に見える。utprekṣā。

【Mallinātha】

kuṭilabhru（ゆがんだ眉）は従属複合語で短母音化。guru-bhrukuṭī（重い眉間の皺）で額が険しくなった顔が、第三の眼（tṛtīya-cakṣus、シヴァの額の眼）が再び現れたかのようであるというutprekṣā。ajaniはjan動詞のluṅ（過去形）、ciṇ接尾辞の任意形。

V.9
Sanskrit (IAST) atiraktabhāvamupagamya kṛtamatiramuṣya sāhase / dṛṣṭiragaṇitabhayāsilatāmalambate sma samayā sakhīmiva //
和訳

極度に赤みを帯び、暴挙を決意したその眼差しは、恐れを顧みず、傍らの剣のつるを、まるで親しい女友達のように頼りにしていた。

注

【Vallabhadeva】

シシュパーラの視線（dṛṣṭi）が傍らの（samayā）剣の蔓（asilata）を女友達（sakhī）のように頼りにする。atiraktabhāvaは怒りによる充血と、恋する女の情熱の両義。クリシュナ討滅という暴挙に決心した眼は、恐れを捨てて剣に手をかけた。samāsokti（暗喩的一致）とupamā（直喩）の混合。

【Mallinātha】

dṛṣṭi（視線）は怒りの極度の赤み（atirakta-bhāva）を帯び、sāhase（暴挙 — クリシュナ殺害）を決意した。samaye（傍らで）asi-latā（剣の蔓）をsakhīm iva（女友達のように）頼りにしている。直喩で語られるdṛṣṭi（視線）の属性が、暗に情熱的な女主人公（nāyikā）を想起させるsamāsokti（暗喩的一致）がupamā（直喩）と混合。

V.10
Sanskrit (IAST) karakuḍmalena nijamūrumurutaranagāśmakarkaśam / trastacapalacalamānajanaśrutabhīmanādamayamāhatoccakaiḥ //
和訳

山の岩よりも硬い自らの太腿を、蕾のように握り締めた拳で、高々と打ち鳴らした。その恐ろしい音は、おののいて逃げ惑う人々にまで聞こえた。

注

【Vallabhadeva】

チェーディ王が拳（karakuḍmala）で自らの太腿を打った。太腿は山の岩石（nagāśma）よりも硬い（karkaśa）。怯えて走り去る人々（trasta-capala-calamāna-jana）にまで恐ろしい打撃音が聞こえた。怒りに狂った者は的を外し自らを打つものだという含意。

【Mallinātha】

kara-kuḍmala（手の蕾、すなわち握り拳）はupamita-samāsa（喩辞的複合語）。nagāśma（山の岩石）のように硬い（karkaśa）というupamā。ūru（太腿）は男性名詞。uccakaiḥ（高々と）āhata（打った）— āṅ+han動詞のluṅ。「怒りに我を忘れた者は的を外し自らを打つ」という含意。

V.11
Sanskrit (IAST) iti cukrudhe bhṛśamanena nanu mahadavāpya vipriyam / yāti vikṛtimapi saṃvṛtimatkimu yannisarganiravagrahaṃ manaḥ //
和訳

このようにして彼は激しく怒った。大きな侮辱を受ければ、自制心を備えた心さえも変容するのだ。まして生来抑制のない心は言うまでもない。

注

【Vallabhadeva】

このチェーディ王はこのように激しく怒った。自制（saṃvṛti）を持つ深慮の心ですら、大きな不快を受ければ変容する。まして生来抑制のない心はなおさらである。チェーディ王の本性的な激しさを示す。

【Mallinātha】

bhāve liṭ（状態を表す完了形）で「怒った」を示す。saṃvṛtiは感情の変化を隠す力。そのような深い心ですら大きな侮辱で変容するのに、生来抑制なき心はなおさらである。チェーディ王の怒りの原因が後続文の意味であるkāvyaliṅga（詩的論証）。

V.12
Sanskrit (IAST) prathamaṃ śarīrajavikārakṛtamukulabandhamavyathī / bhāvikalahaphalayogamasau vacanena kopakusumaṃ vyacīkasat //
和訳

まず身体に生じた変化が蕾を結び、次いで恐れを知らぬ彼は、言葉によって怒りの花を咲かせた。来たるべき戦いの実を結ぶために。

注

【Vallabhadeva】

チェーディ王の怒りを花に喩える。身体の変化（前述の首振り・汗・太腿打ちなど）は蕾の段階。言葉（これから述べる罵詈）によって怒りの花が開花し、来たるべき戦い（kalaha）がその果実となる。

【Mallinātha】

avyathī（恐れない者）はjihikṣi等のグループによりnañ+√vyath+iniの形。怒り（kopa）を花（kusuma）に喩え、身体の変化を蕾（mukula）に、戦闘を実（phala）に見立てる。vikāra・kalaha・vacana・kopaにmukula・phala・vikāsa・kusumaの属性を重ねたsamastavastuvartita-sāvayava-rūpaka（包括的な隠喩）。

V.13
Sanskrit (IAST) dhvanayansabhāmatha sanīraghanaravagabhīravāgabhīḥ / vācamavadadatiroṣavaśādatiniṣṭhurasphuṭatarākṣaramasau //
和訳

次いで、雨雲の轟きのように低く響く声を持つ彼は、恐れなく会堂を鳴り響かせながら、激しい怒りのあまり、極めて厳しく明瞭な音節の言葉を発した。

注

【Vallabhadeva】

会堂を響かせながら（dhvanayan sabhām）怒りの言葉を放った。sanīra-ghana-rava-gabhīra-vākは「水を含んだ雲の轟きのように深い声」。abhīḥは「恐れなき者」。怒り（roṣa）のために極めて荒々しく明瞭な音節の言葉。

【Mallinātha】

sanīra-ghana（水を含んだ雲）のrava（轟き）のように深い声という直喩。atiroṣavaśāt（極度の怒りのために）atiniṣṭhura（極めて荒い）かつsphuṭatara（より明瞭な）音節の言葉を発した。ghanarava-gabhīraは直喩。

V.14
Sanskrit (IAST) yadapūpujastvamiha pārtha murajitamapūjitaṃ satām / prema vilasati mahattadaho dayitaṃ janaḥ khalu guṇīti manyate //
和訳

「おおパールタよ、善人たちが崇めぬムラの征服者をここで汝が供養するとは。なるほど、大いなる愛情は輝かしいものだ。人は愛する者を徳ある者と思い込むのだから。」

注

【Vallabhadeva】

V.14以降、Vallabhadevaの写本は異なる伝承（nindāstuti詩節）を伝える。Sāṅkhya哲学の用語を用いた非難兼讃嘆の詩節群であり、Mallinātha注の詩節とは異なる。この相違についてMallinātha自身もVallabhadevが第2詩節から第38詩節まで注釈しなかったと記す。

【Mallinātha】

hē pārtha（パールタよ）と母方の名で呼ぶのは急所を突くため。satām apūjitam（善人に崇められていない者）を供養した（apūpujaḥ）。apūpujaḥはcaṅ語幹による使役過去形。大きな愛情が輝くがゆえに、人は愛する者を徳ある者と見なすのだというkāvyaliṅga（詩的論証）。

V.15
Sanskrit (IAST) yadarājñi rājavadihārghyamupahitamidaṃ muradviṣi / grāmyamṛga iva havistadayaṃ bhajate jvalatsu na mahīśavahniṣu //
和訳

「王でない者に王にふさわしい供物がここで捧げられた。王侯という聖火が燃え盛る中で、この者がそれを受けるとは——まるで犬が供物を食らうようなものだ。」

注

【Vallabhadeva】

（Vallabhadevaの写本はこの詩節に対応するnindāstuti詩節を持ち、本詩節への注釈はない。）

【Mallinātha】

arājñi（王でない者に）。即位等の王の資格を欠く者。muradviṣi（ムラの敵、クリシュナ）に対して、rājavat（王にふさわしく）arghyam（供物）が捧げられた。mahīśa-vahniṣu（地上の王たちという聖火）が燃え盛る中で、grāmyamṛga（村の犬）がhavis（供物）を受け取るように、このクリシュナがそれを得る。直喩。別読suradviṣi（神々の敵）はより侮蔑的な呼称。

V.16
Sanskrit (IAST) anṛtāṃ giraṃ na gadasīti jagati paṭahairvighuṣyase / nindyamatha ca harimarcayatastava karmaṇaiva vikasatyasatyatā //
和訳

「汝は偽りの言葉を語らぬと、太鼓をもって世に宣言されている。しかし非難されるべきハリを崇めれば、汝の不実はまさにその行為によって花開くのだ。」

注

【Vallabhadeva】

（Vallabhadevaの写本は異なるnindāstuti詩節を伝える。本詩節への注釈はない。）

【Mallinātha】

ユディシュティラに向けた言葉。「偽りを語らぬ」と太鼓で世に知られている（paṭahair vighuṣyase）が、にもかかわらず（atha ca）非難されるべき（nindya）ハリを崇めることにより、その行い自体が不実（asatyatā）を露呈する。真実で知られる者と不当な崇拝行為の矛盾というviṣamālaṅkāra（不調和の修辞）。

V.17
Sanskrit (IAST) tava dharmarāja iti nāma kathamidamapaṣṭhu paṭhyate / bhaumadinamabhidadhatyathavā bhṛśamapraśastamapi maṅgalaṃ janāḥ //
和訳

「汝のこの『ダルマラージャ（法の王）』という名は、なぜ不当にも唱えられるのか。いや——人々はきわめて不吉な火曜日をも『マンガラ（吉祥）』と呼ぶものだ。」

注

【Vallabhadeva】

（Vallabhadevaの写本は異なるnindāstuti詩節を伝える。本詩節への注釈はない。）

【Mallinātha】

「ダルマラージャ」という名はapaṣṭhu（不当に）唱えられている。「あるいは」（athavā）と自答する——bhaumadina（火曜日、火星の日で不吉）をmaṅgala（吉祥）と呼ぶように、名と実が一致しない例がある。dharmarājaとbhaumadinaの二つの独立した文意が鏡のように対応するdṛṣṭāntālaṅkāra（例証法）。

V.18
Sanskrit (IAST) yadi vārcanīyatama eṣa kimapi bhavatāṃ pṛthāsutāḥ / śauriravanipatibhirnikhilairavamānanārthamiha kiṃ nimantritaiḥ //
和訳

「もしこのシャウリが何としても汝らプリターの息子たちにとって最も崇拝に値するならば、すべての地上の王たちは何のためにここに招かれたのか。彼らを侮辱するためか。」

注

taralaḥ（軽薄な＝落ち着きのない者）がśakaṭavyudāsa（シャカタースラの破壊）、tarubhaṅga（ヤマラールジュナ双樹の折損）、dharaṇidhara-dhāraṇa（ゴーヴァルダナ山の保持）などの業を行ったとしても、sthiracetasām（堅固なる心の者たちにとって）何のvismaya（驚き）があろうか。落ち着きのない赤子や子供の行為はただの偶然であり英雄的行為ではないという含意。kāvyaliṅga、vṛttyanuprāsaとの混合。

V.38

【Vallabhadeva】

（Vallabhadevaの写本は異なるnindāstuti詩節を伝える。本詩節への注釈はない。）

V.39

注

【Vallabhadeva】

シシュパーラは傲慢な言葉を発した後、味方と共に手を打ち鳴らして嘲笑した。soḍharipubalabharaḥ（敵の武威の重荷を堪えてきた者）だが、asahanaḥ（堪えられない）はこの侮辱に対して。

V.40

【Vallabhadeva】

【Mallinātha】

kaṭunā（辛辣な）caidya-vacanena（チェーディ王の言葉によって）もmādhavaḥ（クリシュナ）はvikṛtim na agamat（動揺に至らなかった）。「百の侮辱を堪え忍ぼう」（sahiṣye śatam āgāṃsi）という誓約を守る心からの不動。sujanaṃ vacasā calayituṃ ka īśate（善人を言葉で揺るがしうる者は誰か）は一般的真理による個別事実の支持でarthāntaranyāsa（転義法）。

V.41

注

【Vallabhadeva】

（Vallabhadevaの写本では本詩節はV.49に相当。）yadunṛpāḥ（ヤードゥの諸王）はśaurisamayena（クリシュナの合図に）nigṛhītadhiyaḥ（心を制せられ）、śapamānamapi（罵倒する者に対しても）na pracukrudhuḥ（怒らなかった）。

√śap「罵る」の意（ākrośa）。samayena saṃketena（合図によって）nigṛhītadhiyaḥ（心を制御された）yādavāḥ。一般原理「prabhucittam eva jano 'nuvartate」（人は主の心に従う）が個別事実の理由となり、kāvyaliṅga（詩的推論）にarthāntaranyāsa（転義法）が混交。

V.42

V.43

V.65
Sanskrit (IAST) vidatur yam uttamam aśeṣapariṣadi nadījadharmajau / yātu nikaṣam adhiyuddham asau vacanena kiṃ bhavatu sādhvasādhu vā //
和訳

「河の息子（ビーシュマ）と法の子（ユディシュティラ）が全会衆の中で最上と称えたあの者を、戦場で試金石にかけよ。言葉に何の用がある。結果が善かろうが悪かろうが、構わぬ。」

注

【Vallabhadeva】

（V.71に相当。）nadīja-dharmajau = gāṅgeya-yudhiṣṭhirau（ガンガーの子と法の子）がaśeṣa-pariṣadi sarvasyāṃ sabhāyām（全会衆の中で）yam uttamaṃ vidatuḥ（最上と知った者を）、sa（その者＝クリシュナは）adhiyuddhaṃ = yuddhe（戦場で）nikaṣam（試金石のごとく試されるべき所に）yātu（行くがよい）。vacanamātreṇa kim（言葉だけで何になるか）。sādhu（善い結果）vā asādhu（悪い結果）vā bhavatu（どちらでもなるがままに）。

【Mallinātha】

Mallinātha版V.105。nadīja-dharmajau = bhīṣma-yudhiṣṭhirau。aśeṣa-pariṣadi（全会堂で）yam uttamam（最上と）vidatuḥ（知った。√vid「vidolṭo vā」によりtasのatus代置）。asau（かのクリシュナ）adhiyuddham = yuddhe（戦場で。avyayībhāva複合語）nikaṣam yātu（試金石に行け＝試されよ）。vacanena kiṃ（言葉に何の用ぞ）。sādhu vā asādhu vā bhavatu（善悪どちらでも構わぬ）。力への自負と怒りの表出。

V.66
Sanskrit (IAST) acirān mayā saha gatasya samaram uragārilakṣmaṇaḥ / tīkṣṇaviśikhamukhapītam asṛk patatāṃ gaṇaiḥ pibatu sārdham urvarā //
和訳

「ガルダを旗印とするあの者（クリシュナ）が、やがて私と戦いに至ったとき、鋭い矢先に吸われたその血を、鳥の群れとともに大地が飲むであろう。」

注

【Vallabhadeva】

（V.72に相当。）garuḍadhvajasya（ガルダを軍旗とする者＝クリシュナの）mayā saha raṇaṃ prāptasya（私と戦場に来た者の）、acirāt（間もなく）padvi-vṛndaiḥ sākam（鳥の群れとともに）urvarā（大地が）niśita-sāyaka-agra-pītaṃ rudhiram（研がれた矢先に吸われた血を）pibantu（飲むがよい）。＝私が彼を殺すさまを見届けよ、の意。

【Mallinātha】

Mallinātha版V.106。uragāri-lakṣmaṇaḥ = garuḍa-dhvajasya（蛇の敵＝ガルダを旗印とする者＝クリシュナの）。mayā saha samaram gatasya（私と戦いに赴いた者の）。acirāt（まもなく）。tīkṣṇa-viśikha-mukha-pītam = bāṇa-agra-ucchiṣṭam（矢先に味わわれた＝矢に吸い残された）asṛk（血を）。patatāṃ gaṇaiḥ（鳥の群れとともに。patat = 飛ぶもの＝鳥）sārdham。urvarā = bhūmiḥ（大地が）pibatu（飲むがよい）。ここでもamarṣa（怒り）の表出。

V.67
Sanskrit (IAST) abhidhāya rūkṣam iti mā sma gama iti pṛthāsuteritām / vācam anunayaparāṃ sa tataḥ sahasāvakarṇya niriyāya saṃsadaḥ //
和訳

このように粗暴な言葉を吐いた彼（シシュパーラ）は、プリターの息子たち（パーンダヴァ）が発した「行くな」という宥めの言葉を傲然と聞き流し、突然、集会から退出した。

注

【Vallabhadeva】

（V.73に相当。）sa caidyaḥ（そのチェーディ王が）paruṣam uktvā（粗暴に語って）、tataḥ sabhāyāḥ sahasā niriyāya（集会から突然退出した）。mā tāvat tvaṃ yāsīḥ（「まだ行くな」）というanunayaparāṃ vācam（宥めの言葉を）yudhiṣṭhireṇa uktām（ユディシュティラに言われた）avajñāya（軽んじて）。「mā sma gama」は「māṅi luṅ」（禁止の直説法過去）。

【Mallinātha】

Mallinātha版V.107。rūkṣam abhidhāya（粗暴な言葉を述べて）。pṛthā-sutaiḥ（プリターの息子たちにより）īritām（発された）anunaya-parām vācam（宥めの言葉を）「mā sma gamaḥ」（「行ってはならぬ」。「souttare laṭ ca」によるprerāśiṣのluṅ、√calのaḍādeśa）。avakarṇya = anādareṇa śrutvā（侮蔑を込めて聞いて）。sahasā saṃsadaḥ niriyāya = niryayau（集会から去った）。amarṣāt（怒りゆえ）。

V.68
Sanskrit (IAST) gṛham āgatāya kṛpayā ca katham api nisargadakṣiṇāḥ / kṣāntimahitamanaso jananīsvasurātmajāya cukupur na pāṇḍavāḥ //
和訳

生来の礼節をもち、忍耐によって心を磨いたパーンダヴァたちは、母の姉妹の息子として客として訪れた彼（シシュパーラ）に対し、慈悲によってかろうじて怒りを抑えた。

注

【Vallabhadeva】

（V.74に相当。）pāṇḍavāḥ（パーンダヴァたちは）jananī-svasur-ātmajāya = mātṛṣvasrīyāya caidyāya（母方の叔母の息子＝シシュパーラに）na cukrudhuḥ（怒らなかった）。怒る原因があるにもかかわらずkatham api na kruddāḥ（どうにか怒らずにいた）。理由は五つ：gṛham āgataḥ（家に来た客である）、jananīsvasurātmajaḥ（母方の親族である）、kṛpā（慈悲がある）、svabhāva-priya-vadāḥ（生来穏やかである）、kṣamā-adhiṣṭhita-cittāḥ（忍耐を心の拠り所とする）。śūrasya dve duhitarau sātvatī kuntī ca（シューラの二人の娘はサートヴァティーとクンティー）。

【Mallinātha】

Mallinātha版V.108。nisarga-dakṣiṇāḥ = svabhāvataḥ dākṣiṇya-sampannāḥ（生来の礼節に富む。dakṣiṇa = paracchanda-anuvartin＝他者の意に従う者）。kṣānti-mahita-manasaḥ（忍耐によって心を高めた）。gṛham āgatāya（家に来た客として。abhyāgataの意）。jananī-svasur-ātmajāya（母の姉妹の息子に。samāsapañcamī、「vidyā yonī-」iti aluk）。kṛpayā ca（慈悲によっても）。katham api na cukupuḥ（どうにか怒らなかった）。abhyāgatatvaなどの修飾語がsābhiprāya（意味深い＝不怒の原因を示す）でakopa-hetutva。parikara（付随条件）とkāvyaliṅga（詩的根拠）の混交。

V.69
Sanskrit (IAST) calitaṃ tato 'nabhihateccham avanipatiyajñabhūmitaḥ / tūrṇam atha yayum ivānuyayur damaghoṣasūnum avanīśasūnavaḥ //
和訳

そのとき、何者にも阻まれることなく王の祭祀場から立ち去ったダマゴーシャの息子（シシュパーラ）を、王子たちは、あたかも祭馬を追うかのごとく、速やかに追随した。

注

【Vallabhadeva】

（V.75に相当。）avanīśasūnavaḥ = rājaputrāḥ（王子たち）がtataḥ（それ＝祭祀場から）calitam（立ち去った）anabhipreteccham = acalita-graham（志を挫かれることなく）damaghoṣasūnum（ダマゴーシャの子を）drutam anuyayuḥ（速やかに追った）。yajñabhūmitaḥ（祭祀の地から。pañcamyāḥ tasil）。yayum iva（祭馬のごとく。yayu = aśvamedhīya aśva。馬祭において放たれた馬を王子たちが追うように）。

【Mallinātha】

Mallinātha版V.109。calitam = departing。anabhihateccham = apratihata-manorathm（願望を阻まれない＝自由に）。avanipatiyajñabhūmitaḥ（王ユディシュティラの祭祀場から）。damaghoṣasūnum（ダマゴーシャの子＝シシュパーラを）。avanīśasūnavaḥ（王子たち＝同盟の王の息子たち）がtūrṇam（素早く）yayum iva anuyayuḥ（祭馬のごとく追った。yayu = aśvamedhīyaḥ aśva。「yayuś vāśvamedhīyaḥ」とAmara。aśvamedhaの祭馬が放たれると王子たちが護衛として追うことに掛ける）。

V.70
Sanskrit (IAST) viśikhāntarāṇy atipapāta sapadi javanaiḥ sa vājibhiḥ / draṣṭum alaghurabhasāpātitā vanitāś cakāra na sakāmacetasaḥ //
和訳

彼は速い馬でたちまち街路を駆け抜け、彼を見ようと尋常ならぬ勢いで飛び出してきた恋心を抱く女たちの望みを、満たすことなく去った。

注

【Vallabhadeva】

（V.76に相当。）sa caidyaḥ（そのチェーディ王が）javanaiḥ vājibhiḥ（速い馬で）viśikhāntarāṇi = vīthyantarāṇi（街路の間を）atipapāta（走り過ぎた）。mahā-autsukya-ākulitam āgatāḥ yoṣitaḥ（大いなる切望に乱されて来た女たちを）sakāmacetasaḥ na cakāra（恋心を満たさせなかった）。tvarāyā gamanam = tadarśanāniṣpatteḥ（急いで行ったため、彼女たちの見る望みが果たされなかった）。

【Mallinātha】

Mallinātha版V.110。viśikhāntarāṇi（街路の間を。viśikhā = 小路）sa（彼は）javanaiḥ vājibhiḥ（速い馬で）sapadi（直ちに）atipapāta（駆け抜けた）。draṣṭum（見ようとして）alaghu-rabhasā（並々ならぬ勢いで）āpātitāḥ（飛び出して来た）vanitāḥ（女たちを）sakāma-cetasaḥ（恋心に満ちた心を持つ者たちと）na cakāra（しなかった＝恋を成就させなかった）。
