マハーバーラタ ― カルナ篇 第42章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 42 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ42」（カルナとサンシャプタカ軍によるアルジュナへの猛攻、そしてカルナ自身がユディシュティラ軍を相手に奮戦する場面）です。ドリタラーシュトラがサンジャヤに、両軍激突後のサンシャプタカ軍とアルジュナ・カルナの戦況を問い、サンジャヤがそれに答える形で展開します。サンシャプタカたちは死を覚悟してアルジュナに襲いかかりますが、アルジュナはこれを次々と切り倒します。一方カルナは敵軍を圧倒し、夥しい流血が川のように戦場を覆う凄惨な情景（血の川のメタファー）が詳細に描かれます。なお、原典の奥書（コロフォン）には第40章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。
karṇaparva — dvicatvāriṃśo'dhyāyaḥ (42)
第42章
dhṛtarāṣṭra uvāca|
tathā vyūḍheṣu anīkeṣu saṃsakteṣu ca sañjaya|
saṃśaptakāḥ kathaṃ pārthaṃ kathaṃ karṇaṃ ca pāṇḍavāḥ|| // 8-42-1 //
ドリタラーシュトラは語った。 （1）サンジャヤよ、このように陣形が整えられ、両軍が入り乱れたのち、サンシャプタカ族たちはいかにアルジュナと戦い、パーンダヴァたちはいかにカルナと戦ったのか。
etat vistaraśo yuddhaṃ prabrūhi kuśalo hy asi|
na hi tṛpyāmi vīrāṇāṃ śṛṇvāno yudhi vikramam|| // 8-42-2 //
（2）この戦いを詳しく語ってくれ。お前は語りに巧みである。戦場の勇者たちの武勇を聞くことに、私は飽きない。
sañjaya uvāca|
tat saṃsthim atho dṛṣṭvā pratyamitraṃ mahad balam|
pratyavyūhat tataḥ karṇo hitārthaṃ tanayasya te|| // 8-42-3 //
サンジャヤは語った。 （3）そのように整えられた敵の大軍を見て、カルナはあなたの息子のためを思い、それに対して陣を張った。
tat sādināgakalilaṃ padātirathasaṅkulam|
dhṛṣṭadyumnamukhaṃ ghoram aśobhata mahad balam|| // 8-42-4 //
（4）騎兵・象兵が埋め尽くし、歩兵・戦車兵が群れなし、ドリシュタデュムナを先頭にした恐ろしいその大軍は、輝いて見えた。
pārāvatasavarṇāśvaś candrasūryasamadyutiḥ|
sa pārṣato babhau dhanvī kālo vigrahavān iva|| // 8-42-5 //
（5）鳩と同じ色の馬をもち、月と太陽のような光輝を放つドリシュタデュムナ（プリシャタの子）は、弓を構え、まるで姿をもった「時（死神）」のようであった。
pārṣataṃ tv abhitas tasthur draupadeyā yuyutsavaḥ|
sānugā dīptavapuṣaś candraṃ tārāgaṇā iva|| // 8-42-6 //
（6）ドリシュタデュムナの周りには、戦いを望むドラウパディーの子らが、従者たちと共に立ち並んだ。月をめぐる星々のごとく、輝く姿でいた。
atha vyūḍheṣu anīkeṣu prekṣya saṃśaptakān raṇe|
kruddho'rjuno'bhidudrāva vyākṣipan gāṇḍivaṃ dhanuḥ|| // 8-42-7 //
（7）そして両軍が陣を張り終えたとき、戦場でサンシャプタカ族たちを見たアルジュナは、怒りをこめ、弓ガーンディーヴァを引き絞って攻めかかった。
atha saṃśaptakāḥ pārtham abhyadhāvan vadhaiṣiṇaḥ|
vijaye dhṛtasaṅkalpā mṛtyuṃ kṛtvā anivartanam|| // 8-42-8 //
（8）サンシャプタカたちもまた、勝利を固く誓い、死ぬまで退かぬと決意して、アルジュナを殺そうと彼に襲いかかった。
tad aśvasaṅghabahulaṃ pattināgarathākulam|
udīryamāṇaṃ saṃrabdhaṃ dhanañjayam abhidravat|| // 8-42-9 //
（9）馬の群れが多く、歩兵・象・戦車に満ちて沸き立ち、激昂したその軍勢はアルジュナに向かって押し寄せた。
tad udyataṃ mahat sainyaṃ sāgaraughasamaṃ jave|
pārthavelāṃ samāsādya viṣṭhitaṃ samadṛśyata|| // 8-42-10 //
（10）勢いは大海の奔流のようであり、その大軍はアルジュナという岸辺にぶつかって留まるかに見えた。
mṛdgantaṃ śavarṣaughair drutam arjunam ārdayat|| // 8-42-11 //
（11）矢の雨の流れをもって攻撃してくる者たちを、アルジュナは撃ち砕いた。
sa samprahāras tumulas teṣām āsīt kirīṭinā|
tasyaiva tu yathā rājan nivātakavacaiḥ saha|| // 8-42-12 //
（12）王よ、王冠者（アルジュナ）と彼らとの間には、激しい戦闘が繰り広げられた。それはかつての、ニヴァータカヴァチャたちとの戦いのようであった。
rathān aśvān dhvajān nāgān pattīn gajagatān api|
iṣūn dhanūṃṣi khaṅgāṃś ca cakrāṇi ca paraśvathān|| // 8-42-13 //
（13）戦車・馬・旗・象・歩兵・象の上の戦士、矢・弓・剣・円盤・斧――。
sāyudhān udyatān bāhūn vividhāni āyudhāni ca|
ciccheda dviṣatāṃ pārthaḥ śirāṃsi ca sahasraśaḥ|| // 8-42-14 //
（14）武器を構えた敵の腕、さまざまな武具、そして幾千もの敵の首を、アルジュナは切り落とした。
tasmin sainyamahāvarte pātālatalasannibhe|
nimagnaṃ taṃ rathaṃ matvā neduḥ saṃśaptakā mudā|| // 8-42-15 //
（15）「地獄のような敵軍の大渦に、アルジュナの戦車は沈んでしまった」と思って、サンシャプタカたちは歓喜の声を上げた。
sa purastād arīn hatvā punar uttarato'vadhīt|
dakṣiṇena ca paścāt ca kruddho rudraḥ paśūn iva|| // 8-42-16 //
（16）アルジュナは前方の敵を討ち、北からの敵を討ち、南・西からの敵も討った。まるで怒りのルドラ神が獣たちを討つようであった。
atha pāñcālacedīnāṃ sṛñjayānāṃ ca māriṣa|
tvadīyaiḥ saha saṅgrāma āsīt paramadāruṇaḥ|| // 8-42-17 //
（17）国王よ、そのころ、パーンチャーラ族・チェーディ族・スリンジャヤ族は、あなた方の軍との間に激烈な戦闘を繰り広げていた。
kṛpaś ca kṛtavarmā ca śakuniś ca api saubalaḥ|
hṛṣṭasenāḥ susaṃrabdhā rathānīkaprahāriṇaḥ|| // 8-42-18 //
（18）クリパ、クリタヴァルマン、スバラの子シャクニは、軍を奮い立たせ、敵の戦車隊を打ち破る戦いをした。
kosalaiḥ kāśyamatsyaiś ca kārūśaiḥ kekayair api|
śūrasenaiḥ śūravarair yuyudhur yuddhadurmadāḥ|| // 8-42-19 //
（19）コーサラ族、カーシー族、マツヤ族、カールーシャ族、ケーカヤ族、シューラセーナ族など戦いに熱狂する勇者たちと戦った。
teṣām antakaraṃ yuddhaṃ dehapāpmavināśanam|
kṣatraviṭśūdravīrāṇāṃ dharmyaṃ svargyaṃ yaśaskaram|| // 8-42-20 //
（20）彼らの戦いは、体と罪を滅ぼし、命を奪うものであったが、クシャトリヤ・ヴァイシャ・シュードラの勇者たちにとって、正義であり、天界へ導き、名声をもたらすものであった。
duryodhano'tha sahito bhrātṛbhir bharatarṣabha|
guptaḥ kurupravīraiś ca madrāṇāṃ ca mahārathaiḥ|| // 8-42-21 //
（21）バーラタの雄牛よ、ドゥルヨーダナは兄弟たちと共に、クル族の勇者・マドラ族の偉大な戦車戦士たちに守られていた。
pāṇḍavaiḥ saha pāñcālaiś cedibhiḥ sātyakena ca|
yudhyamānaṃ raṇe karṇaṃ kuruvīro'bhyapālayat|| // 8-42-22 //
（22）パーンダヴァ、パーンチャーラ族、チェーディ族、サーティヤキと戦うカルナを、クル族の勇者（ドゥルヨーダナ）は守っていた。
karṇo'pi niśitair bāṇair vinihatya mahācamūm|
pramṛdya ca rathaśreṣṭhān yudhiṣṭhiram apīḍayat|| // 8-42-23 //
（23）カルナもまた、鋭い矢で大軍を撃破し、すぐれた戦車戦士たちを打ち砕いて、ユディシュティラを苦しめた。
vipatrāyudhadehāsūn kṛtvā śatrūn sahasraśaḥ|
yuktvā svargayaśobhyāṃ ca svebhyo mudamudāvahat|| // 8-42-24 //
（24）幾千の敵から武具も体も命も奪い、天界と名声を彼らに与えた彼は、味方に大きな喜びをもたらした。
tad vigāhya mahānīkaṃ sūtaputro mahārathaḥ|
nadīṃ pravartayāmāsa śoṇitaughataraṅgiṇīm|| // 8-42-25 //
（25）偉大な軍勢のなかに踏み込んだカルナは、血の激流となって流れる川を作り出した。
śoṇitodāṃ kṣuṇṇamatsthāṃ nāganakraduratyayām|
māṃlamajjākardaminīṃ cakrakūrmamahoḍupām|| // 8-42-26 //
（26）血の水をたたえ、流れを押しつぶす肉塊の浅瀬、象というワニがひそむ渡りがたき流れ、肉と髄の泥、車輪を亀とし、大象を舟とするような川であった。
pātitair meghasaṅkāśais tatratatra mahādvipaiḥ|
aśanībhir iva dhvastā nadī rājan virājate|| // 8-42-27 //
（27）王よ、所々に倒れた雲のごとき大象たちが、まるで雷に打たれたかのようで、その川はまことに輝いていた。
tāṃ śarormimahāvartāṃ chatrahaṃsasamākulām|
tanutroṣṇīṣasaṅghāṭāmasthipāṣāṇasaṅkulām|| // 8-42-28 //
（28）矢の波、大渦、傘を白鳥とし、鎧と兜を筏とし、骨を石とした川――。
apārām anapārāṃ ca śaṅkhadundubhighoṣiṇīm|
raudrāṃ nadīṃ mahārāja rajasā sarvato vṛtām|| // 8-42-29 //
（29）果てなく、底なく、法螺貝や太鼓のような音を立て、恐ろしく、大王よ、あたり一面を塵で覆っていた。
atitīkṣṇāṃ narākīrṇāṃ nadīm antakagāminīm|
samaṃ ca viṣamaṃ caiva samāyāntīṃ mahābhayām|| // 8-42-30 //
（30）きわめて鋭く、人々に満ち、死の世界へと導き、平坦と険しさを兼ね備えた、恐るべき大いなる川――。
ākulāś ca atra sīdanti narāḥ śoṇitakardame|
narair abhiparikṣiptā yathā rājan mahādrumāḥ|| // 8-42-31 //
（31）人々はその血の泥に沈み、大王よ、まるで大木が人々に囲まれているかのようであった。
tatas te tatratatraiva pracaranto mahānadīm|
viceruḥ sarvato yodhā nauvāraṇamahārathaiḥ|| // 8-42-32 //
（32）戦士たちは所々にその大河を渡り、船のような象や大戦車でもって、あちこちを進んだ。
śoṇitena samaṃ rājan kṛtam āsīt samantataḥ|
nadīvegair yathā bhūmis tadvad āsīd viśāpate|| // 8-42-33 //
（33）王よ、あたり一面は血と混じり合い、川の激流によって変えられる地面のようになった。
evaṃ bhārata saṅgrāmo naravājigajakṣayaḥ|
kurūṇāṃ sṛñjayānāṃ ca devāsurasamo'bhavat|| // 8-42-34 //
（34）このように、バーラタよ、人・馬・象を滅ぼすクル族とスリンジャヤ族の戦いは、神々とアスラの戦いのごとくであった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe dvicatvāriṃśo'dhyāyaḥ|| 42 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十二章は終わる。
