karṇaparva — ekaviṃśo'dhyāyaḥ (21)
第21章　入り乱れの戦い・第十六日の戦いの終結
sañjaya uvāca|
tataḥ karṇaṃ puraskṛtya tvadīyā yuddhadurmadāḥ|
punarāvṛtya saṅgrāmaṃ cakrurdevāsuropamam|| // 8-21-1 //
サンジャヤは語った。 （1）そこで、カルナを先頭に押し立てて、あなた方の戦いに酔いしれた兵士たちは、再び戻って、神々と阿修羅の戦さながらの合戦を繰り広げました。
dviradanararathāśvaśaṅkhaśabdaiḥ parihṛṣitā vividhaiśca śastrapātaiḥ|
dviradarathapadātisādisaṅghāḥ parikupitābhimukhāḥ prajaghnire te|| // 8-21-2 //
（2）象・人・戦車・馬の鳴り響く法螺貝の音に鼓舞され、さまざまな武器の雨の中で、象兵・戦車兵・歩兵・騎兵の群れは、怒りに燃えて互いに向かい合い、殺し合いました。
śitaparaśvathasāsipaṭṭasair iṣubhir anekavidhaiś ca sūditāḥ|
dviradarathahayā mahāhave varapuruṣaiḥ puruṣāśca vāhanaiḥ|| // 8-21-3 //
（3）鋭い戦斧・剣・投げ槍・さまざまな矢によって、象・戦車・馬たちはこの大戦闘において倒され、優れた戦士たちもまた、乗り物ともども殺されました。
kamaladinakarendusannibhaiḥ sitadaśanaiḥ sumukhākṣināsikaiḥ|
ruciramakuṭakuṇḍalairmahī puruṣaśirobhir upastṛtā babhau|| // 8-21-4 //
（4）蓮華や太陽や月のように輝き、白い歯を持ち、美しい顔・目・鼻を持ち、見事な冠や耳飾りをつけた、人間の首によって、大地は覆われて美しく見えました。
parighamusalaśaktitaumarair nakharabhuśuṇḍigadāśatair hatāḥ|
dviradanarahayāḥ sahasraśo rudhiranadīpravahās tadā'bhavan|| // 8-21-5 //
（5）鉄棒・杵・槍・投げ槍・爪武器・火縄銃・棍棒の数々で打たれて、象・人・馬が何千と倒れ、血の河が流れました。
prahatarathanarāśvakuñjaraṃ pratibhayadarśanamulbaṇavraṇam|
tadahitahatamābabhau balaṃ pitṛpatirāṣṭram iva prajākṣaye|| // 8-21-6 //
（6）戦車・人・馬・象が打ち倒され、恐ろしい光景となり、ひどい傷口が口を開いたその軍勢は、まるで生き物が滅び行くときの閻魔王の国のように見えました。
atha tava naradeva sainikās tava ca sutāḥ surasūnusannibhāḥ|
amitabalapuraḥ sarā raṇe kuruvṛṣabhāḥ śiniputramabhyayuḥ|| // 8-21-7 //
（7）さて、王よ、あなたの兵士たちと、天の子らにも等しいあなたの息子たちは、計り知れない力を持つクル族の雄牛たちとともに、戦場でシニの息子（サーティヤキ）に向かって進みました。
tadatirudhirabhīmamābabhau puruṣavarāśvarathadvipākulam|
lavaṇajalasamudvatasvanaṃ balam asurāmarasainyasaprabham|| // 8-21-8 //
（8）血にまみれて恐ろしく、優れた戦士・馬・戦車・象でごった返し、塩水の大海のような轟きを上げるその軍勢は、阿修羅と天の軍勢に匹敵する輝きを放ちました。
surapatisamavikramas tatas tridaśavarāvarajopamaṃ yudhi|
dinakarakiraṇaprabhaiḥ pṛṣatkai ravitanayo'bhyahanac chinipravīram|| // 8-21-9 //
（9）インドラにも等しい武勇を持ち、戦場でヴィシュヌにも匹敵するカルナ（太陽の子）は、太陽の光のように輝く矢をもって、シニ族の勇者（サーティヤキ）を射ちました。
tamapi sarathavājisārathiṃ śinivṛṣabho vividhaiḥ śarais tvaran|
bhujagaviṣasamaprabhai raṇe puruṣavaraṃ samavāstṛṇot tadā|| // 8-21-10 //
（10）しかしシニ族の雄牛（サーティヤキ）もまた急ぎ、さまざまな矢で——蛇の毒のように輝く矢で——その最高の戦士（カルナ）を戦車・馬・御者ごと戦場で射ち覆いました。
śinivṛṣabhaśarairnipīḍitaṃ tava suhṛdo vasuṣeṇamabhyayuḥ|
tvaritamatirathā ratharṣabhaṃ dviradarathāśvapadātibhiḥ saha|| // 8-21-11 //
（11）シニ族の雄牛の矢に苦しめられたヴァスシェーナ（カルナ）を、あなたの味方である偉大な戦車戦士たちが、象・戦車・馬・歩兵を率いて急いで助けに来ました。
tadudadhinibhamādravadbalaṃ tvaritataraiḥ samabhidrutaṃ paraiḥ|
drupadasutamukhais tadā'bhavat puruṣarathāśvagajakṣayo mahān|| // 8-21-12 //
（12）大海のように押し寄せるその軍勢が、素早い敵に追い立てられ、ドルパダの息子らを先頭とする者たちの攻撃によって、人・戦車・馬・象の大いなる破滅が起こりました。
atha puruṣavarau kṛtāhnikau bhavamabhipūjya yathāvidhi prabhum|
arivadhakṛtaniścayau drutaṃ tava balamarjunakeśavau sṛtau|| // 8-21-13 //
（13）さて、かの二人の最高の人——アルジュナとケーシャヴァ（クリシュナ）は、日課の祈りを終え、しかるべく主なるシヴァ神を拝み、敵を討つ決意を固めて、速やかにあなたの軍勢に向かいました。
jaladaninadaniḥsvanaṃ rathaṃ pavanavidhūtapatākaketanam|
sitahayamupayāntamantikaṃ kṛtamanaso dadṛśus tadā'rayaḥ|| // 8-21-14 //
（14）雷雲のような轟きを上げ、風になびく旗と軍旗を持ち、白い馬に引かれて近づいてくるその戦車を、覚悟を決めた敵たちは目にしました。
atha viṣphārya gāṇḍīvaṃ rathe nṛtyannivārjunaḥ|
śarasambādhamakarotkhaṃ diśaḥ pradiśas tathā|| // 8-21-15 //
（15）そこでアルジュナは、戦車の上でまるで踊るかのようにガーンディーヴァ弓を引き絞り、空も四方八方も矢でびっしりと埋め尽くしました。
rathān vimānapratimān majjayan sāyudhadhvajān|
sasārathīṃs tadā bāṇair abhrāṇi iva anilo'vadhīt|| // 8-21-16 //
（16）天の飛行車にも等しい戦車を、武器や軍旗ごと沈め、御者もろとも矢で打ち倒しました。まるで風が雲を吹き散らすように。
gajān gajaprayantṝṃś ca vaijayantyāyudhadhvajān|
sādino'śvāṃś ca pattīṃś ca śarair ninye yamakṣayam|| // 8-21-17 //
（17）象と象使い、勝利の旗印と武器と軍旗を持つ者たち、騎兵と馬と歩兵を、矢によって閻魔の国へ送りました。
tam antakam iva kruddham anivāryaṃ mahāratham|
duryodhano'bhyayād eko nighnan bāṇair ajihmagaiḥ|| // 8-21-18 //
（18）怒った死神のごとく止めることのできないその偉大な戦車戦士（アルジュナ）に、ドゥルヨーダナがただ一人、まっすぐな矢を放ちながら立ち向かいました。
tasyārjuno dhanuḥ sūtam aśvān ketuṃ ca sāyakaiḥ|
hatvā saptabhir ekena cchatraṃ ciccheda patriṇā|| // 8-21-19 //
（19）アルジュナは七本の矢でドゥルヨーダナの弓・御者・馬・軍旗を打ち落とし、さらに一本の矢で傘を断ち切りました。
navamaṃ ca samādhāya vyasṛjat prāṇaghātinam|
duryodhanāya iṣuvaraṃ taṃ drauṇiḥ saptadhā'cchinat|| // 8-21-20 //
（20）九本目の矢を構えて、命を奪う最上の矢をドゥルヨーダナに放ちましたが、ドローナの息子（アシュヴァッターマン）がそれを七つに切り裂きました。
tato drauṇer dhanuśchitvā hatvā cāśvarathāñ śaraiḥ|
kṛpasyāpi tad atyugraṃ dhanuś ciccheda pāṇḍavaḥ|| // 8-21-21 //
（21）するとパーンダヴァ（アルジュナ）は、ドローナの子の弓を断ち切り、矢で馬と戦車を倒し、クリパの恐るべき弓をも断ち切りました。
hārdikyasya dhanuśchittvā dhvajaṃ cāśvāṃs tadā'vadhīt|
duḥśāsanasya iṣvasanaṃ chittvā rādheyam abhyayāt|| // 8-21-22 //
（22）クリタヴァルマンの弓を断ち切り、軍旗も馬も倒し、ドゥフシャーサナの弓を切り裂いてから、ラーデーヤ（カルナ）に向かって進みました。
atha sātyakim utsṛjya tvaran karṇo'rjunaṃ tribhiḥ|
viddhvā vivyādha viṃśatyā kṛṣṇaṃ pārthaṃ punaḥpunaḥ|| // 8-21-23 //
（23）するとカルナはサーティヤキへの攻撃をやめ、急いでアルジュナを三本の矢で射ち、さらに二十本の矢でクリシュナとパールタ（アルジュナ）を繰り返し射ちました。
na glānir āsīt karṇasya kṣipataḥ sāyakān bahūn|
raṇe vinighnataḥ śatrūn kruddhasya iva śatakratoḥ|| // 8-21-24 //
（24）多くの矢を放ち、戦場で敵を打ち倒すカルナには、いささかの疲れも見えませんでした。まるで怒れるインドラのようでした。
atha sātyakir āgatya karṇaṃ viddhvā śitaiḥ śaraiḥ|
navatyā navabhiś cograiḥ śatena punar ārpayat|| // 8-21-25 //
（25）そこにサーティヤキがやって来て、鋭い矢でカルナを射ち、九十本、さらに九本の猛烈な矢で、合わせて百本の矢を浴びせました。
tataḥ pravīrāḥ pārthānāṃ sarve karṇam apīḍayan|
yudhāmanyuḥ śikhaṇḍī ca draupadeyāḥ prabhadrakāḥ||
uttamaujā yuyutsuś ca yamau pārṣata eva ca|
cedikārūśamātsyānāṃ kekayānāṃ ca yadbalaṃ||
cekitānaś ca balavān dharmarājaś ca suvrataḥ|
ete rathāśvadviradaiḥ pattibhiś cogravikramaiḥ||
parivārya raṇe karṇaṃ nānāśastrair avākiran|
bhāṣanto vāgbhir ugrābhiḥ sarve karṇavadhe dhṛtāḥ|| // 8-21-26-29 //
（26〜29）それからパーンダヴァ軍の勇士たち全員——ユダーマンユ、シカンディン、ドラウパディーの息子たち、プラバドラカ族、ウッタマウジャス、ユユツ、双子（ナクラとサハデーヴァ）、ドリシュタデュムナ、チェーディ・カールーシャ・マツヤ・ケーカヤの軍勢、力あるチェーキターナ、そして誓い堅き法王ユディシュティラ——これらの者たちが戦車・馬・象・歩兵を率いて、猛烈な勇気をもって戦場でカルナを取り囲み、さまざまな武器を浴びせかけ、激しい言葉を浴びせながら、皆カルナを殺す決意で戦いました。
tāṃ śastravṛṣṭiṃ bahudhā karṇaśchittvā śitaiḥ śaraiḥ|
apovāha astravīryeṇa drumaṃ bhaṅktvā iva mārutaḥ|| // 8-21-30 //
（30）カルナはその武器の雨を鋭い矢で幾重にも切り裂き、武器の威力で押し返しました。まるで風が木を吹き折るように。
rathinaḥ samahāmātrān gajān aśvān sasādinaḥ|
pattivrātāṃś ca saṅkruddho nighnan karṇo vyadṛśyata|| // 8-21-31 //
（31）怒りに燃えるカルナは、戦車兵とその将軍たち、象、騎兵付きの馬、歩兵の群れを打ち倒している姿が見えました。
tad vadhyamānaṃ pāṇḍūnāṃ balaṃ karṇāstratejasā|
viśastrapatradehāsu prāya āsīt parāṅmukham|| // 8-21-32 //
（32）カルナの武器の威力に打ち倒されるパーンダヴァ軍は、武器も鎧も吹き飛ばされ、ほとんどが背を向けて逃げ出しました。
atha karṇāstram astreṇa pratihatya arjunaḥ smayan|
diśaṃ khaṃ caiva bhūmiṃ ca prāvṛṇoc charavṛṣṭibhiḥ|| // 8-21-33 //
（33）そこでアルジュナは微笑みながら、カルナの武器を自らの武器で打ち消し、矢の雨で空も大地も四方も覆い尽くしました。
musalāni iva sampetuḥ parighā iva ca iṣavaḥ|
śataghnya iva cāpi anye vajrāṇy ugrāṇi cāpare|| // 8-21-34 //
（34）その矢は杵のように飛び、鉄棒のように突き刺さり、ある矢は殺戮兵器のように、また別の矢は恐るべき金剛杵のようでした。
tair vadhyamānaṃ tat sainyaṃ sapattyaśvarathadvipam|
nimīlitākṣamatyarthaṃ babhrāma ca nanāda ca|| // 8-21-35 //
（35）それらに打たれるドゥルヨーダナ軍は、歩兵・馬・戦車・象もろとも、目をつぶり、あちこちをさまよい、叫び声を上げました。
niṣkaivalyaṃ tadā yuddhaṃ prāpur aśvanaradvipāḥ|
hanyamānāḥ śarair ārtās tadā bhītāḥ pradudruvuḥ|| // 8-21-36 //
（36）馬も人も象も、確実な死を覚悟する戦いとなり、矢に打たれて苦しみ、恐れて逃げ出しました。
tvadīyānāṃ tadā yuddhe saṃsaktānāṃ jayaiṣiṇām|
girim astaṃ samāsādya pratyapadyata bhānumān|| // 8-21-37 //
（37）あなた方の兵士たちが勝利を求めて戦いに没頭しているうちに、太陽は西の山に沈みました。
tamasā ca mahārāja rajasā ca viśeṣataḥ|
na kiñcit pratyapaśyāma śubhaṃ vā yadi vā'śubham|| // 8-21-38 //
（38）大王よ、闇が、そして特に砂埃が立ち込めて、善いことも悪いことも、何も見えなくなりました。
te trasyanto maheṣvāsā rātriyuddhasya bhārata|
apayānaṃ tataś cakruḥ sahitāḥ sarvayodhibhiḥ|| // 8-21-39 //
（39）バーラタよ、偉大な弓の達人たちは、夜の戦闘を恐れ、すべての戦士とともに退却しました。
kauraveṣv apayāteṣu tadā rājan dinakṣaye|
jayaṃ sumanasaḥ prāpya pārthāḥ svaśibiraṃ yayuḥ|| // 8-21-40 //
（40）王よ、カウラヴァ軍が日没とともに退いた時、パーンダヴァたちは喜びに満ちて勝利を得、自らの陣営に戻りました。
vāditraśabdairvividhaiḥ siṃhanādaiḥ sagarjitaiḥ|
parānuvahantaś ca stuvantaś cācyutārjunau|| // 8-21-41 //
（41）さまざまな楽器の音、獅子吼の叫びとともに、アチュタ（クリシュナ）とアルジュナを讃えながら、敵を追い払いました。
kṛte'vahāre tair vīraiḥ sainikāḥ sarva eva te|
āśīrvācaḥ pāṇḍaveṣu prāyuñjanta nareśvarāḥ|| // 8-21-42 //
（42）戦闘が終わると、勇士たち・兵士たち・王たちは皆、パーンダヴァたちに祝福の言葉を捧げました。
tataḥ kṛte'vahāre ca prahṛṣṭās tatra pāṇḍavāḥ|
niśāyāṃ śibiraṃ gatvā nyavasanta nareśvarāḥ|| // 8-21-43 //
（43）戦闘が終わり、喜びに満ちたパーンダヴァたちは、夜になって陣営に帰り、休みました。
tato rakṣaḥ piśācāś ca śvāpadāś caiva saṅghaśaḥ|
jagmur āyodhanaṃ ghoraṃ rudrasyākrīḍasannibham|| || // 8-21-44 //
（44）そして夜叉や餓鬼や獣たちが群れをなして、ルドラ神の遊び場のようなその恐ろしい戦場にやって来ました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe ekaviṃśo'dhyāyaḥ|| 21 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第二十一章は終わる。
