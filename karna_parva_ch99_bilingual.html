マハーバーラタ ― カルナ篇 第99章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 99 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ99」で、シャリヤによるドゥルヨーダナの慰め、戦場の描写、天界の者たちの帰還の場面を描きます。
karṇaparva — ekonaśatatamo'dhyāyaḥ (99)
第99章 ― シャリヤによるドゥルヨーダナの慰め、戦場の描写、天の者たちの帰還
sañjaya uvāca|
karṇaṃ tu śūraṃ patitaṃ pṛthivyāṃ śarācitaṃ śoṇitadigdhagātram|
yadṛcchayā sūryamivāvaniṃ gataṃ didṛkṣavaḥ samparivārya tasthuḥ||
// 8-99-1 //
サンジャヤは語った。
大地に倒れたカルナ、矢に覆われ血に染まった体の勇者を、偶然大地に落ちた太陽のように、人々は見ようと取り囲んで立っていた。
prahṛṣṭavitrastaviṣaṇṇavismitāstathā'pare śokasamanvitā'bhavan|
pare tvadīyāśca raṇe viśāmpate yathāyatheṣṭaṃ pṛtanā tathā gatā||
// 8-99-2 //
歓喜する者、恐れおののく者、落胆する者、驚嘆する者、悲しみにくれる者。味方も敵も、王よ、それぞれの思いのままに軍勢は動いた。
praviddhavarmābharaṇāyudhāmbaraṃ dhanañjayena prahataṃ mahāratham|
niśāmya karṇaṃ kuravaḥ pradudruvurhatarṣabhaṃ kesariṇeva gokulam||
// 8-99-3 //
鎧も飾りも武器も衣も打ち砕かれ、ダナンジャヤに倒された偉大な戦車戦士カルナを見て、クル勢は逃げ出した。雄牛を獅子に殺された牛の群れのように。
kṛtvā dimardaṃ bhṛśamarjunena karṇaṃ hataṃ kesariṇeva nāgam|
dṛṣṭvā śayānaṃ yudhi madrarājaśchinnadhvajenāpayayau rathena||
// 8-99-4 //
アルジュナと大激戦を演じたカルナが、獅子に殺された象のように倒れたのを見て、マドラ王（シャリヤ）は旗を切られた戦車で去っていった。
karṇe hate pārthabhayātpradudruvurvaikartane dhārtarāṣṭrāḥ saśalyāḥ|
avekṣamāṇā muhurarjunasya ketuṃ mahāntaṃ yaśasā jvalantam||
śalyastu karṇārjunayorvimarde balāni dṛṣṭvā mṛditadhvajāni|
yayau sa tenaiva rathena tūrṇaṃ helīkṛtaḥ sṛñjayasomakaiśca||
nipātitasyandanavājināgaṃ balaṃ ca dṛṣṭvā hatasūtaputram|
bhīmastu bhīmena tadā svareṇa samunnadadrodasī kampayaṃśca|
āsphoṭayannṛtyati valgate ca hate karṇe trāsayandhārtarāṣṭrān|
tadā rājansṛñjayāḥ somakāśca śaṅkhāndadhmuḥ sasvajuścāpi sarve||
// 8-99-5-8 //
カルナが討たれるとドリタラーシュトラの息子たちはシャリヤとともにパールタへの恐怖から逃げ出した。アルジュナの旗が名声で燃え輝くのを何度も振り返り見ながら。シャリヤはカルナとアルジュナの激戦で軍勢が旗を砕かれたのを見て、スリンジャヤとソーマカに嘲笑されながら、その戦車で素早く去った。すべての兵が逃走し、スータの息子が倒されたのを見て、ビーマは恐ろしい声で大いに吼え、大地と天空を震わせ、手を叩いて踊り跳ねた。カルナが倒されてドリタラーシュトラの息子たちを恐怖に陥れた。スリンジャヤたちもソーマカたちも法螺貝を吹き鳴らし、互いに抱擁し合った。
parasparaṃ kṣatriyā hṛṣṭarūpāḥ sūtātmaje vai nihate tadānīm|
duryodhano'śrupratipūrṇanetro dīno muhurniśvasannārtarūpaḥ||
// 8-99-9 //
クシャトリヤたちは喜びの表情で互いを見た。スータの息子が倒された時に。ドゥルヨーダナは目に涙を浮かべ、意気消沈して何度もため息をつき、苦悩の表情であった。
madrādhipaścāpi vimūḍhacetāstūrṇaṃ dhvajenāpahṛtena tena|
rathena duryodhanametya tūrṇaṃ paśyansuduḥkhāttamuvāca rājan||
// 8-99-10 //
マドラの王もまた心が惑乱し、旗を奪われた戦車で急いでドゥルヨーダナのもとに来て、深い悲しみの中で王にこう言った。
viśīrṇanāgāśvarathapravīraṃ balaṃ tvadīyaṃ yamarāṣṭrakalpam|
anyonyamāsādya hataiḥ śayānairnarāśvanāgairgirikūṭakalpaiḥ||
naitādṛśaṃ bhārata yuddhamāsīdyathā hi karṇārjunayorbabhūva|
grastau hi karṇena sametya kṛṣṇāvanye hi sarve tava śātraveyāḥ||
daivaṃ tu yattatsvavaśe pravṛttaṃ tatpāṇḍavānpāti nihanti cāsmān|
tavārthasiddhyarthakarā hi sarve prasahya vīrā nihatā dviṣadbhiḥ||
kuberavaivasvatavāsavānāṃ tulyaprabhāvā varuṇasya cāpi|
vīryeṇa śauryeṇa parākrameṇa taiścāpi yuktā vimalairguṇaughaiḥ||
avadhyakalpā nihatā narendrāstavārthakāmā yudhi pāṇḍaveyaiḥ|
tanmā śuco bhārata diṣṭametatparyāyasiddhirna tu nityasiddhiḥ||
// 8-99-11-15 //
「象・馬・戦車の精鋭が砕かれたおまえの軍は、ヤマの王国のようになっている。互いに倒れ合い、山の峰のような人・馬・象が討たれて横たわっている。バーラタよ、カルナとアルジュナの戦いほどの戦いは今までなかった。カルナは相まみえてクリシュナとアルジュナの二人をも飲み込みかけた。おまえの他のすべての敵もそうだった。しかし運命というものは自らの意志で動く。それがパーンダヴァたちを守り、我々を打ちのめすのだ。おまえの利益のために戦ったすべての勇者は、敵に力ずくで倒された。クベーラ、ヤマ、インドラ、ヴァルナに等しい力と武勇と勇気と立派な美徳を備えた、不死身同然の王たちが、おまえのために戦場でパーンダヴァたちに倒された。だからバーラタよ、嘆くな。これは運命なのだ。時が巡って来たのであって、永遠の成功というものはないのだ。」
etadvaco madrapaterniśamya svaṃ cāvinītaṃ manasā vicintya|
duryodhano'śrupratipūrṇanetro muhurmuhurniśvasannārtarūpaḥ||
// 8-99-16 //
マドラ王のこの言葉を聞き、自らの非道な行いを心に思い返して、ドゥルヨーダナは目に涙を浮かべ、何度もため息をつき苦悩の表情であった。
*tadvyānamūkaṃ kṛpaṇaṃ bhṛśārtamārtāyanirdīnamuvāca rājan|
paśyedamugrairnaravājināgairāyodhanaṃ vīra hataiḥ supūrṇam||
// 8-99-17 //
王よ、アールターヤニ（シャリヤ）は、声も出ず哀れで深く苦しむドゥルヨーダナにこう言った。「見よ、この恐ろしい戦場を、勇者よ。人・馬・象の討たれた者で満ちている。」
mahīdharābhaiḥ patitaiśca nāgaiḥ sakṛtprayatnaiḥ śarabhinnagātraiḥ|
pravihvaladbhiśca gatāsubhiśca pradhvastavarmāyudhasarvayodhaiḥ||
vajrāpavidvairiva cācalaughairvibhinnapāṣāṇamṛgadrumaughaiḥ|
praviddhaghaṇṭāṅkuśatomaradhvajaiḥ sahemajālai rudhiraughasamplavaiḥ||
śarāvanunnaiḥ patitaisturaṅgaistanadbhirārtaiḥ kṣatajaṃ vamadbhiḥ|
dīnaistrasadbhiḥ parivṛttanetrairmahī patadbhiḥ kṛpaṇā vabhūva||
tathā'pavidvairgajavājiyūthairmandāsubhiścāpi gatāsubhiśca|
rathaiśca nāgaisturagaiśca nunnairmahī mahāvaitaraṇīva bhāti||
gajairnikṛttāparahastagātrairudvepamānaiḥ patitaiḥ pṛthivyām|
ratharṣabhairnāgavarāśvayodhaiḥ padātibhiścābhimukhaiḥ parairhataiḥ||
viśīrṇavarmābharaṇāmbarāyudhairyutā praśāntairiva pāvakairmahī|
śaraprahārābhihatairmahābalairavekṣamāṇaiḥ patitaiḥ samantataḥ||
pranaṣṭasaṃjñaiḥ punarāśvasadbhirmahī babhau kumbhagatairivāgnibhiḥ|
ratnaiścyutairbhūratidīptimadbhirnaktaṃ grahairdyaurvimalairvibhāti||
śarāstu karṇārjunabāhumuktā vidārya nāgāṃśca manuṣyadehān|
prāṇānnirasyāśu mahīṃ pratīyurmahoragā vāsamivābhinamrāḥ||
hatairmanuṣyaiśca gajaiśca saṅkhye śarāvabhinnai rudhirapradigdhaiḥ|
dhaṉañjayasyādhiratheśca mārge hatairagamyā vasudhā'tidurgā||
rathairmaheṣūnmathitaiḥ sukalpitaiḥ sanāgayodhāśvavarāyudhadhvajaiḥ viśīrṇayoktrairvinikīrṇabandhanairnikṛttacakrākṣayugatriveṇubhiḥ||
vimuktayoktraiśca rathairupaskaraiḥ kṛtābhiṣaṅgairvinibadvakūbaraiḥ|
prabhagnanīḍairmaṇihemabhūṣitairvṛtā mahī dyauriva śāradairghanaiḥ||
nikṛṣyamāṇā javanaisturaṅgamairhateśvarā rājarathāḥ sukalpitāḥ|
manuṣyamātaṅkarathāśvasādiṣu drutaṃ vrajanto bahudhā vighūrṇitāḥ||
sahemapṛṣṭhāḥ saparaśvathāyudhāḥ śitāśca śūlā musalāḥ samudgarāḥ|
citrāśca khaṅgā vimalāśca kośā gajāśca jāmbūnadapaṭṭanaddhāḥ||
cāpāni jāmbūnadabhūṣitāni śarāśca kārtasvaracitrapuṅkhāḥ|
ṛṣṭyaśca pītā vimalāśca kośāḥ prāsāśca daṇḍāḥ kanakaprabhāsāḥ||
śubhrāṇi vālavyajanāni śaṅkhāśchinnāvaruddhā virucaḥ srajaśca|
kuthāḥ patākāmbaraveṣṭanāni kirīṭamālā makuṭāśca śubhrāḥ||
prakīrṇakā vipratikīrṇakāśca pradhānamukhyāstaralāśca hārāḥ|
āpīḍakeyūravarāṅgadāni graiveyaniṣkāḥ sasuvarṇasūtrāḥ||
maṇyuttamā vajrasuvarṇayuktā ratnāni coccāvacamaṅgalāni|
gātrāṇi cābhānti sukhocitāni śirāṃsi cendupratimānanāni||
// 8-99-18-34 //
（※戦場の惨状の詳細な描写が続く。山のような倒れた象、矢に体を裂かれて苦しみもがく者、息絶えた者、打ち砕かれた鎧と武器と兵士、雷に打たれた山の群れのような象の群れ、矢に射抜かれて倒れた馬たち、嘶きながら血を吐く苦しむ馬、砕かれた戦車の車輪・車軸・轅、黄金で覆われた弓、黄金で飾られた矢、槍・棍棒・剣・鞘、象・旗・鎧・首飾り・耳飾り・腕輪、宝石と金とダイヤモンドの飾り、安楽に育てられた美しい体、月のような美しい顔を持つ首。体も楽しみも持ち物もすべて捨てて倒れた者たち。自らのダルマに忠実であった偉大なるものを得て、名声とともに天界に行った者たち。）
dehāṃśca bhogāṃśca paricchadāṃśca tyaktvā manojñā nihatāḥ sukhāni|
svadharmaniṣṭhāṃ mahatīmavāpya prāptāśca lokānyaśasā gatāste||
// 8-99-35 //
「カルナとアルジュナの腕から放たれた矢は、象と人間の体を貫き、命を奪って大地に入った。住処に入る大蛇のように。」
nivarta duryodhana yāntu sainikā vrajasva rājañśibirāṇi mānada|
divākaro'pyeṣa vilambate prabho punastvamevātra narendra kāraṇam||
// 8-99-36 //
「ドゥルヨーダナよ、引き返せ。兵士たちを帰らせよ。日暮れだ、王よ。おまえこそが再びここでの原因となるのだ。」
sañjaya uvāca|
etāvaduktvā virarāma śalyo duryodhanaṃ caiva nivartayitvā|
yuddhāya rājanviniviṣṭabuddhirhā karṇa hā karṇa iti bruvāṇam||
// 8-99-37 //
サンジャヤは語った。 シャリヤはこれだけ言って口を閉じた。ドゥルヨーダナを引き返させた。「ああ、カルナよ、ああ、カルナよ」と叫びながら戦いに固執するドゥルヨーダナを。
taṃ droṇaputrapramukhā narendrāḥ sarve samāśvāsya tataḥ prajagmuḥ|
nirīkṣamāṇā dhvajamarjunasya rathaṃ ca divyaṃ yaśasā jvalantam||
// 8-99-38 //
ドローナの息子（アシュヴァッターマン）を先頭に王たちがすべてドゥルヨーダナを慰めてから去っていった。アルジュナの旗と名声で燃え輝く天の戦車を見つめながら。
narāśvamātaṅgaśarīrajena raktena siktāṃ rudhireṇa bhūmim|
raktāmbarasraktapanīyayogānnārīṃ prakāśāmiva sarvaramyām||
pracchannarūpāṃ rudhireṇa rāja nraudre muhūrte'tivirājamāne|
naivāvatasthuḥ kuravaḥ samīkṣya pravrājitā naradevā yathā'kṣaiḥ||
vadhena karṇasya suduḥkhitāste hā karṇa hā karṇa iti bruvāṇāḥ|
drutaṃ prajagmuḥ śibirāṇi rājandivākaraṃ raktamavekṣamāṇāḥ||
// 8-99-39-41 //
人・馬・象の体から流れた赤い血に浸された大地を、赤い衣と花輪と黄金を身につけた美しい女のように。血に覆われた大地を恐ろしい時に見て、クル勢は立ち止まれなかった。賭博に負けて追放された王たちのように。カルナの死に深く悲しみ、「ああ、カルナよ、ああ、カルナよ」と叫びながら、急いで陣営に帰った。沈みゆく赤い太陽を見つめながら。
gāṇḍīvamuktaistu suvarṇapuṅkhaiḥ śilāśitaiḥ śoṇitadigdhavājaiḥ|
śaraiścitāṅgo'pi rarāja karṇo hato'pi dīptāṃśurivāṃśujālaiḥ||
karṇasya dehaṃ rudhirāmbusiktaṃ putrānakumpī bhagavānvivasvān|
spṛṣṭvā karāgraiḥ kṣatajānurūpaiḥ snātuṃ tadā'gādaparaṃ samudram||
// 8-99-42-43 //
ガーンディーヴァから放たれた金の柄の矢に、石で研がれた血に染まった羽をつけた矢に、全身を射抜かれてもなお、カルナは輝いていた。討たれてもなお光り輝く太陽のように、光の束をまとって。カルナの体は血の水に浸されていた。息子を憐れむ太陽神は、血のように赤い指先でその体に触れてから、西の海へ沐浴に向かった。
itīva sañcintya surarṣabhāśca samprasthitāste tu yathāniketam|
sañcintya sarvā janatā visasruryathāsukhaṃ khe ca mahītale ca||
// 8-99-44 //
こう思いめぐらして、神々の最良者たちはそれぞれの住処に去った。すべての群衆もそれぞれの心地よい場所に散っていった。天にも地にも。
tadadbhutaṃ prāṇabhṛtāṃ bhayaṅkaraṃ niśāmya yuddhaṃ kuruvīramukhyayoḥ|
samācitau karṇaśaraiṛ parantapau tathaiva saṃrejaturacyutārjunau||
tamo nihatyābhyuditau yathā'malau śaśāṅkasūryāviva raśmimālinau|
vihāya tānbāṇagaṇānmahābalau suhṛdvṛtāvapratimānavikramau||
sukhapraviṣṭau sukhadau virejatuḥ sadasyacintyāviva viṣṇuvāsavau|
sadevagandharvamanuṣyacāraṇairmaharṣibhiryakṣamahoragairapi|
jayābhivṛddhyā parayā'bhipūjitau nihatya karṇaṃ paramāhave tadā||
yathānurūpaṃ pratipūjya tānatha praśasyamānāvatulaiśca karmabhiḥ|
nanandatuścaiva suhṛdbhirāvṛtau balaṃ nihatyeva sureśakeśavau||
// 8-99-45-48 //
クルの二大英雄のこの驚くべき恐ろしい戦いを見届けた後、カルナの矢に覆い尽くされたアチュタ（クリシュナ）とアルジュナの二人は、闇を払った後に昇った清らかな月と太陽のように、矢の群れを振り払った偉大なる力の二人は、光の冠をまとった月と太陽のように。友に囲まれ、比類なき武勇を持つ二人は、心地よく入って来て輝いた。想像を超えたヴィシュヌとインドラのように。神々・ガンダルヴァ・人間・チャーラナ・大聖仙・ヤクシャ・大蛇にも、最高の勝利の栄光をもって称えられ、カルナを偉大なる戦いで討ち取って。それぞれにふさわしく称え返し、比類なき功績を讃えられながら、友に囲まれて二人は喜んだ。敵の軍を討ち果たしたインドラとケーシャヴァ（クリシュナ）のように。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekonaśatatamo'dhyāyaḥ|| 99 ||
こうして、聖なる大マハーバーラタのカルナ篇の第99章は終わる。
