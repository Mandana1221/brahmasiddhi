kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

daśamaḥ sargaḥ ― 第十章

アプサラスたちがアルジュナのもとへ赴き苦行から引き離そうとする（1–18）。六季が同時に出現して彼女たちを援助する（19–36）。しかしあらゆる手段を用いても英雄を動揺させることはできない（37–63）。韻律：プシュピターグラー（Puṣpitāgrā）。最終偈はシカリニー（Śikhariṇī）。
1
Sanskrit
atha parimalajām avāpya lakṣmīm avayavadīpitamaṇḍanaśriyas tāḥ / vasatim abhivihāya ramyahāvāḥ surapatisūnuvilobhanāya jagmuḥ //
Puṣpitāgrā
和訳
さて、情交から生じた美しさを身にまとい、肢体そのものが装飾の輝きを際立たせた彼女たちは、魅惑的な仕草で住処を離れ、インドラの息子を惑わすために出発した。
parimala は「芳香」の他に「情交」を意味する。マッリナータは saṃbhogasaṃbhūtā lakṣmī（情交から生じた美しさ）と注する。
2
Sanskrit
drutapadam abhiyātum icchatīnāṃ gamanaparikramalāghavena tāsām / avaniṣu caraṇaiḥ pṛthustanīnām alaghunitambatayā ciraṃ niṣede //
Puṣpitāgrā
和訳
空を飛ぶ速さで足早に近づきたいと望んだが、豊かな胸と重い腰ゆえに、その足は地上に長くとどまった。
3
Sanskrit
nihitasarasayāvakair babhāse caraṇatalaiḥ kṛtapaddhatir vadhūnām / aviralavitateva śakragopair aruṇitanīlatṛṇolapā dharitrī //
Puṣpitāgrā
和訳
みずみずしい紅色の液で染まった足裏が道を刻み、大地は暗い草や藁に赤みを帯びて、あたかも一面のインドラゴーパ虫で覆われたかのように輝いた。
yāvaka は足を赤く染める化粧料（ラック）。śakragopa（インドラゴーパ）は雨季に現れる小さな赤い虫。
4
Sanskrit
dhvanir agavivareṣu nūpurāṇāṃ pṛthuraśanāguṇaśiñjitānuyātaḥ / pratiravavitato vanāni cakre mukharasam utsukahaṃsasārasāni //
Puṣpitāgrā
和訳
山の洞穴に響く足環の音は、幅広い腰紐の鈴の音を伴い、反響によって森々を満たし、白鳥や鶴をざわめかせ、憧れに駆り立てた。
カッペラーは、白鳥や鶴が仲間の鳥が近くにいると思って鳴き出したと解釈する。
5
Sanskrit
avacayaparibhogavanti hiṃsraiḥ sahacaritāny amṛgāṇi kānanāni / abhidadhur abhito muniṃ vadhūbhyaḥ samuditasādhvasaviklavaṃ ca cetaḥ //
Puṣpitāgrā
和訳
花や果実を摘み味わえる森には、猛獣と他の獣が共に歩いていた。こうした森と、新たに湧き起こった畏敬と不安の心とが、聖者が近くにいることを若い女たちに告げた。
アルジュナの苦行の力により、森は楽園のようになり、肉食獣と草食獣が平和に共存している。カッペラーの注参照。
6
Sanskrit
nṛpatimuniparigraheṇa sā bhūḥ surasacivāpsarasāṃ jahāra cetaḥ / upahitaparamaprabhāvadhāmnāṃ na hi jayināṃ tapasām alaṅghyam asti //
Puṣpitāgrā
和訳
王にして聖者（アルジュナ）が住まうその地は、インドラの従者（ガンダルヴァ）とアプサラスたちの心を奪った。最高の威力と光輝を備えた勝利の苦行に、越えられぬものはないからである。
7
Sanskrit
sacakitam iva vismayākulābhiḥ śucisikatāsv atimānuṣāṇi tābhiḥ / kṣitiṣu dadṛśire padāni jiṣṇor upahitaketurathāṅgalāñchanāni //
Puṣpitāgrā
和訳
驚きに目を見張る彼女たちは、清らかな砂の上に、旗と輪の吉兆の印が刻まれたジシュヌ（アルジュナ）の超人的な足跡を、おののくように見つめた。
足裏に旗（ketu）と法輪（aṅga = cakra）の吉相があることは、仏陀にも言及される特徴。カッペラーの注参照。
8
Sanskrit
atiśayitavanāntaradyutīnāṃ phalakusumāvacaye 'pi tadvidhānām / ṛtur iva taruvīrudhāṃ samṛddhyā yuvatijanair jagṛhe muniprabhāvaḥ //
Puṣpitāgrā
和訳
他の森を凌ぐ輝きを放ち、果実や花を摘んでもなお変わらぬ豊かさを見て、若い女たちは、まるで季節のように樹木や草花の繁栄から、聖者の力を察知した。
9
Sanskrit
mṛditakisalayaḥ surāṅganānāṃ sasalilavalkalabhārabhugnaśākhaḥ / bahumatim adhikāṃ yayāv aśokaḥ parijanatāpi guṇāya sadguṇānām //
Puṣpitāgrā
和訳
天女たちに若芽を揉まれ、湿った樹皮衣の重さに枝を撓ませたアショーカの木は、天女たちの深い敬意を勝ち得た。徳ある者に仕えることもまた、徳となるからである。
アショーカの木はアルジュナの樹皮衣を干す場所として使われており、そのことで天女たちの尊敬を集めた。
10
Sanskrit
yamaniyamakṛśīkṛtasthirāṅgaḥ paridadṛśe vidhṛtāyudhaḥ sa tābhiḥ / anupamaśamadīptatāgarīyān kṛtapadapaṅktir atharvaṇeva vedaḥ //
Puṣpitāgrā
和訳
禁戒と勧戒により痩せ細ったが堅固な身体を持ち、武器を携えたその人は、彼女たちの目に映った。比類なき静寂に輝き、より一層の威厳を備えた彼は、アタルヴァンが編纂したヴェーダのようであった。
アタルヴァ・ヴェーダは平和の祈り（śama）とともに調伏（abhicāra）の呪法も含む。武器を持つ苦行者アルジュナとの類似が暗示される。
11
Sanskrit
śaśadhara iva locanābhirāmair gaganavisāribhir aṃśubhiḥ parītaḥ / śikharanicayam ekasānusadmā sakalam ivāpi dadhan mahīdharasya //
Puṣpitāgrā
和訳
月のように、目を楽しませる光線を天空に放ち包まれ、山の一つの台地に座しながらも、山の全ての峰々を満たすかのようであった。
12
Sanskrit
surasariti paraṃ tapo 'dhigacchan vidhṛtapiśaṅgabṛhajjaṭākalāpaḥ / havir iva vitataḥ śikhāsamūhaiḥ samabhilaṣann upavedi jātavedāḥ //
Puṣpitāgrā
和訳
天の河（ガンガー）のほとりで最高の苦行を修め、赤褐色の大きな螺髪の束を保ち、炎の群れを広げて供物を求める祭壇上の火のようであった。
13
Sanskrit
sadṛśam atanum ākṛteḥ prayatnaṃ tadanuguṇām aparaiḥ kriyām alaṅghyām / dadhad alaghu tapaḥ kriyānurūpaṃ vijayavatīṃ ca tapaḥsamāṃ samṛddhim //
Puṣpitāgrā
和訳
その姿にふさわしい並々ならぬ精進と、それに見合った他の者には不可能な行いと、行いに応じた重い苦行と、苦行に等しい勝利をもたらす繁栄とを備えていた。
マッリナータは、前の語が次の語の修飾となる連鎖構造を ekāvalī（一連の真珠）の修辞法と注する。
14
Sanskrit
ciraniyamakṛśo 'pi śailasāraḥ śamanirato 'pi durāsadaḥ prakṛtyā / sasaciva iva nirjane 'pi tiṣṭhan munir api tulyarucis trilokabhartuḥ //
Puṣpitāgrā
和訳
長い苦行で痩せ細っていても山のように堅固。静寂を愛しながらも本性により近づきがたい。人里離れた地にいても従者を伴うかのよう。聖者でありながらも三界の主（インドラ）に匹敵する輝きを放つ。
マッリナータは各 api（〜にもかかわらず）が表す矛盾の見せかけを virodhālaṅkāra（撞着法）と注する。
15
Sanskrit
tanum avajitalokasāradhāmnīṃ tribhuvanaguptisahāṃ vilokayantyaḥ / avayayur amarastriyo 'sya yatnaṃ vijayaphale viphalaṃ tapodhikāre //
Puṣpitāgrā
和訳
世の力と輝きを凌駕し、三界を守護するに足るその身体を見て、天女たちは、勝利をもたらすこの苦行の修練においては、自分たちの努力が無駄であろうと悟った。
16
Sanskrit
munidanutanayān vilobhya sadyaḥ pratanubalāny adhitiṣṭhatas tapāṃsi / alaghuni bahu menire ca tāḥ svaṃ kuliśabhṛtā vihitaṃ pade niyogam //
Puṣpitāgrā
和訳
かつては微力な苦行に励む聖仙や魔族の子らをたちまち誘惑してきた彼女たちも、今回インドラから託された任務を、重大な場におけるきわめて重い務めと感じた。
17
Sanskrit
atha kṛtakavilobhanaṃ vidhitsau yuvatijane harisūnudarśanena / prasabham avatatāra cittajanmā harati mano madhurā hi yauvanaśrīḥ //
Puṣpitāgrā
和訳
さて、若い女たちが作為的な誘惑を企てようとしたとき、インドラの息子を見て不意に恋心が彼女たち自身に宿った。甘美な若さの輝きは心を奪うものだからである。
他者を惑わそうとしていた天女たちが、逆にアルジュナの若々しい美しさに心を奪われるという逆転。
18
Sanskrit
sapadi harisakhair vadhūnideśād dhvanitamanoramavallakīmṛdaṅgaiḥ / yugapad ṛtugaṇasya saṃnidhānaṃ viyati vane ca yathāyathaṃ vitene //
Puṣpitāgrā
和訳
たちまち、女たちの命により、ガンダルヴァたちが美しいヴィーナーと太鼓を鳴らすと同時に、空と森に、六つの季節がそれぞれの場所に一斉に出現した。
19
Sanskrit
sajalajaladharaṃ nabho vireje vivṛtim iyāya rucis taḍillatānām / vyavahitarativigrahair vitene jalagurubhiḥ stanitair digantareṣu //
Puṣpitāgrā
和訳
空は雨雲をたたえて輝き、稲妻の蔓の光が閃いた。水を含んで重く響き、恋人たちの諍いを打ち切らせる雷鳴が、四方に広がった。
ここから六季が順に描写される。雨季（19–23）、秋（24–27）、冬（28–29）、初春（30）、春（31–34）、夏（36）。カッペラーの構成区分に従う。
20
Sanskrit
parisurapatisūnudhāma sadyaḥ samupadadhan mukulāni mālatīnām / viralam apajahāra baddhabinduḥ sarajasatām avaner apāṃ nipātaḥ //
Puṣpitāgrā
和訳
インドラの息子の庵の周りに、しずくを結んだ穏やかな雨が降り注ぎ、たちまちジャスミンの蕾をほころばせ、大地の塵を洗い去った。
21
Sanskrit
pratidiśam abhigacchatābhimṛṣṭaḥ kakubhavikāsasugandhinānilena / nava iva vibabhau sacittajanmā gatadhṛtir ākulitaś ca jīvalokaḥ //
Puṣpitāgrā
和訳
四方から吹き寄せる風に触れて――カクバ（アルジュナ樹）の花の芳香を帯びた風に――生きとし生けるものの世界は、恋に浸り、平静を失い、動揺して、まるで新しく生まれ変わったかのように見えた。
22
Sanskrit
vyathitam api bhṛśaṃ mano harantī pariṇatajambuphalopabhogahṛṣṭā / parabhṛtayuvatiḥ svanaṃ vitene navanavayojitakaṇṭharāgaramyam //
Puṣpitāgrā

苦しむ心さえも激しく奪いながら、熟したジャンブー果の味を楽しんで喜ぶコーキラ（郭公）の雌が声をあげた。絶えず新たに調えられる喉の情感が美しい声であった。
23
Sanskrit
abhibhavati manaḥ kadambavāyau madamadhure ca śikhaṇḍināṃ nināde / jana iva na dhṛteś cacāla jiṣṇur na hi mahatāṃ sukaraḥ samādhibhaṅgaḥ //
Puṣpitāgrā

カダンバの風と、陶酔するほど甘い孔雀の鳴き声が心を圧倒するなか、ジシュヌ（アルジュナ）は凡人のように平静を乱すことはなかった。偉大な者の禅定を破ることは容易ではないからである。
24
Sanskrit

Puṣpitāgrā
和訳
蓮の茎の腕輪の列をつけ、クムダ蓮の林という一枚の絹衣をまとい、矢（葦）を手にした秋は、清らかな蓮の掌を持つ花嫁のように、雨季という花婿に手をとられた。
秋が花嫁、雨季が花婿という比喩。bāṇa は矢と葦（ニーラジンティー）の両義。カッペラーは、クシャトリヤの花嫁が結婚式で矢を手にする風習に言及する。
25
Sanskrit
samadaśikhirutāni haṃsanādaiḥ kumudavanāni kadambapuṣpavṛṣṭyā / śriyam atiśayinīṃ sametya jagmur guṇamahatāṃ mahate guṇāya yogaḥ //
Puṣpitāgrā

26
Sanskrit

27
Sanskrit
mukulitam atiśayya bandhujīvaṃ dhṛtajalabinduṣu śādvalasthalīṣu / aviralavapuṣaḥ surendragopā vikacapalāśacayaśriyaṃ samīyuḥ //

28
Sanskrit

29
Sanskrit

30
Sanskrit

31
Sanskrit

32

33
Sanskrit

34
Sanskrit

śvasana は「風」と「吐息」、madhu は「蜜」と「酒」の二義を持つシュレーシャ（掛詞）。
35
Sanskrit

sitaturaga（白馬の持ち主）はアルジュナの異名で、彼の戦車を引く白馬に因む。同時に「感官を制した者」の含意もある。
36

37

38
Sanskrit

Puṣpitāgrā
和訳
ガンダルヴァたちの伴奏する耳に快いヴィーナーの歌と、さまざまな魅力で人を惹きつける季節の風物とは、インドラの息子には何の変化も起こさなかったが、天女たちに恋心を掻き立てた。
アルジュナを誘惑するための道具が、逆に天女たち自身に恋を起こすという皮肉。マッリナータは viṣamālaṅkāra（不均衡の修辞）と注する。
39
Sanskrit
na dalati nicaye tathotpalānāṃ na ca viṣamacchadagucchayūthikāsu / abhiratum upalebhire yathāsāṃ haritanayāvayaveṣu locanāni //

和訳
彼女たちの目は、咲き誇る睡蓮の群にも、サプタパルナの茂みやジャスミンにも、インドラの息子の肢体に対するほどの喜びを見出すことはなかった。
40
Sanskrit
munim abhimukhatāṃ ninīṣavo yāḥ samupayayuḥ kamanīyatāguṇena / madanam upadadhe sa eva tāsāṃ duradhigamā hi gatiḥ prayojanānām //
Puṣpitāgrā
和訳
美しさという力で聖者を自分に向けようとやって来た女たちに、かの聖者自身が恋心を生じさせた。目的の行方は予測しがたいものである。
41
Sanskrit
prakṛtam anusasāra nābhineyaṃ pravikasadaṅguli pāṇipallavaṃ vā / prathamam upahitaṃ vilāsi cakṣuḥ sitaturage na cacāla nartakīnām //
Puṣpitāgrā
和訳
舞姫たちの艶めいた目は、決められた演技にも、指を広げた蕾のような手にも従わず、初めから白馬の主（アルジュナ）に据えられたまま動かなかった。

42
Sanskrit
abhinayamanasaḥ surāṅganāyā nihitam alaktakavartanābhitāmram / caraṇam abhipapāta ṣaṭpadālī dhutanavalohitapaṅkajābhiśaṅkā //

43
Sanskrit

44
Sanskrit
nṛpasutam abhitaḥ samanmathāyāḥ parijanagātratirohitāṅgayaṣṭeḥ / sphuṭam abhilaṣitaṃ babhūva vadhvā vadati hi saṃvṛtir eva kāmitāni //

恋する花嫁は、侍女たちの体の陰にほっそりとした体を隠して王子を見つめたが、その想いはかえって露わになった。隠すことこそが恋心を語るからである。
45
Sanskrit

Puṣpitāgrā
和訳
聖者の前で突然、雨雲の風がある女の腰衣の一部を吹き飛ばしたとき、太腿の露わになった彼女の恥じらいおののく様子は、恋敵である他の女たちをも驚かせた。
46
Sanskrit
dhṛtabisavalaye nidhāya pāṇau mukham adhirūṣitapāṇḍugaṇḍalekham / nṛpasutam aparā smarābhitāpād amadhumadālasalocanaṃ nidadhyau //

和訳
別のある女は、蓮の茎の腕輪をはめた手の上に、青白さに覆われた頬を載せ、恋の苦悩から、酒に酔ってもいないのに気だるい目で、王子をじっと見つめ続けた。
47
Sanskrit

52
Sanskrit

53
Sanskrit
kusumitam avalambya cūtam uccais tanur ibhakumbhapṛthustanānatāṅgī / tadabhimukham anaṅgacāpayaṣṭir visṛtaguṇeva samunnanāma kācit //

Sanskrit

55
Sanskrit
