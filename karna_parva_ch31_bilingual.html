マハーバーラタ ― カルナ篇 第31章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 31 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ31」（カルナが戦場へ出発する際の不吉な前兆の数々。カルナが自讃しつつアルジュナを討つと誓ったことに対し、シャリヤがそれを認めずアルジュナの武勇を称えつつカルナを叱責し、両者の間で激しい言葉の応酬が交わされる場面）です。各段落は原典の詩節番号（8-31-N）と和訳の段落番号が対応しています。なお、原典の詩節13〜19は底本において欠落しており、欠落以降の詩節は底本の印刷上20番台から振られていますが、内容上は本来の27〜46番に相当するため、本対訳では実際に対応するサンスクリット詩節番号（8-31-27〜46）を表示しています。
karṇaparva — ekatriṃśo'dhyāyaḥ (31)
第31章
sañjaya uvāca|
dṛṣṭvā karṇaṃ mahāvīryaṃ yuyutsaṃ samavasthitam|
cukruśuḥ kuravaḥ sarve hṛṣṭarūpāḥ samantataḥ|| // 8-31-1 //
サンジャヤは語った。 （1）カルナが偉大な力をもって戦いに臨み、しっかりと陣取っているのを見て、クル族の者たちはみな大いに喜んで、周囲で声をあげた。
tato dundubhinirghoṣair bherīṇāṃ ninadena ca|
koṇaśabdaiś ca vividhair garjitaiś ca tarasvinām|
niryayus tāvakāḥ sarve mṛtyuṃ kṛtvā nivartanam|| // 8-31-2 //
（2）そして太鼓の響き、鼓の音、ほら貝などさまざまな音、勇ましい戦士たちの吠える声と共に、あなた方の兵たちは皆、死を覚悟して出陣した（「退却は死」と決めて進んだ）。
prayāte tu tataḥ karṇe ratheṣu maditeṣu ca|
cacāla ca mahī sarvā rarāsa ca suvisvaram|| // 8-31-3 //
（3）カルナが進み、戦車が揺さぶられていくと、大地全体が震え、激しく鳴り響いた。
niḥsaranto vyadṛśyanta sūryāt sapta mahāgrahāḥ|| // 8-31-4 //
（4）太陽から、七つの大きな惑星が離れ出るように見えた。
ulkāpātāś ca sañjajñur digdāhāś ca eva dāruṇāḥ|
tathā'śanyaś ca sampetur vavur vātāś ca bhairavāḥ|| // 8-31-5 //
（5）流星が落ち、恐ろしい空の燃え立つ光があちこちに現れ、雷が落ち、恐ろしい風が吹き荒れた。
mṛgapakṣigaṇāś ca eva pṛtanāṃ bahuśas tava|
apasavyaṃ tadā cakrur vedayanto mahābhayam|| // 8-31-6 //
（6）獣や鳥の群れが、何度もあなたの軍を左に巡り、大きな災いを告げた。
prasthitasya ca karṇasya nipetus turagā bhuvi|
asthivarṣaṃ ca patitam antarikṣād bhayānakam|| // 8-31-7 //
（7）出陣するカルナの馬たちは地に倒れ、空からは恐ろしい骨の雨が降り落ちた。
jajvalus ca eva śastrāṇi dhvajāś ca eva cakampire|
aśrūṇi ca vyamuñcanta vāhanāni viśāmpate|| // 8-31-8 //
（8）武器は燃え、旗は震え、乗り物たちは涙を流した、国王よ。
ete cānye ca bahava utpātās tatra māriṣa|
samutpetur vināśāya kauravāṇāṃ sudāruṇāḥ|| // 8-31-9 //
（9）これ以外にも多くの前兆が、クル族の滅亡を告げるかのように激しく現れた、敬うべき方よ。
na ca tān gaṇayāmāsuḥ sarve daivena mohitāḥ|
prasthitaṃ sūtaputraṃ ca jayet sūcur narādhipāḥ|| // 8-31-10 //
（10）しかし、運命に惑わされた者たちは、誰ひとりとしてそれを気にかけず、出陣する御者の子（カルナ）を見て、王たちは口々に「勝つぞ」と叫んだ。
'śalyena sahitaṃ dṛṣṭvā karṇam āhavaśobhinam'|
nirjitān pāṇḍavāṃś ca eva menire tatra kauravāḥ|| // 8-31-11 //
（11）〔「シャルヤが付き従って、戦いに輝くカルナを見て」〕パーンダヴァたちは敗れるものと、クル族の者たちは思い込んでいた。
tato rathasthaḥ paravīrahantā bhīṣmadroṇāv ativīryau samīkṣya|
samujjvalan bhāskarapāvakābho vaikartano'sau rathakuñjaro vṛṣā|| // 8-31-12 //
（12）戦車に乗り、敵の勇者を討つ者カルナは、ビーシュマとドローナをもしのぐ武勇を振り返り、自らのなすべきことをよく考えた。太陽と火のように輝く、戦車戦士の象とも言うべき雄々しいカルナは、こう語った――。
// 8-31-13 //
（13）「戦場で師（ドローナ）は敵に討たれてしまった以上、もはや人の身を喜ばせる楽しみは十分だ〔もう楽しみなど不要である〕。
// 8-31-14 //
（14）火や太陽に等しい輝きを持ち、武勇においてはヴィシュヌ神やインドラ神にも比べられ、思慮においては常にブリハスパティ（神々の師）やウシャナス（アスラの師）に並ぶあの方（師ドローナ）を、耐え難き武器でさえも救うことができなかったのだ。
// 8-31-15 //
（15）婦人や子どもたちの泣き声が響きわたり、武勇のドリタラーシュトラの子ら（クル族）が敗れている今、シャルヤよ、私には何をすべきかわからぬ。ゆえに、お前は敵軍へと進め。
// 8-31-16 //
（16）真実を守る王（ユディシュティラ）がいる場所、ビーマセーナとアルジュナがいる場所、ヴァースデーヴァ（クリシュナ）、サーティヤキ、スリンジャヤ族、双子（ナクラとサハデーヴァ）がいる場所――私のほかに、だれがそれに耐えられようか。
// 8-31-17 //
（17）ゆえに、マドラの王よ、すみやかに進め。戦場でパーンチャーラ、パーンダヴァ、スリンジャヤの者たちと戦いに行く。私は彼らと会って、討ち取るか、さもなくばドローナのもとへ、ヤマ（死神）の世界へ行こう。
// 8-31-18 //
（18）シャルヤよ、今日、知っておけ。あの勇者たちの只中へ行かぬということは、私にはない。友を裏切ることを、私はどうしても許せぬ。命を捨ててでもドローナのあとを追うのだ。
// 8-31-19 //
（19）賢者であれ愚者であれ、命の終わりに死が訪れることから逃れる者はいない。ゆえに、識ある方よ、私はアルジュナに立ち向かう。定められた運命は、越えることができない。
kalyāṇavṛttaḥ satataṃ hi rājā vaicitravīryasya suto mamāsīt|
tasya arthasiddhyartham ahaṃ tyajāmi priyān bhogān dustyajaṃ jīvitaṃ ca|| // 8-31-27 //
（20）ヴィチトラヴィーリヤの子（ドリタラーシュトラ）の子であるかの王（ドゥルヨーダナ）は、私にとって常に善き振舞いをしてきた。その目的のために、私は愛する楽しみを捨てよう。捨てがたき命をも。
vaiyāghracarmāṇam akūjanākṣaṃ haimaṃ trikośaṃ rajatatriveṇum|
rathaprabarhaṃ turagaprabārhair yuktaṃ prādān mahyam imaṃ hi rāmaḥ|| // 8-31-28 //
（21）虎の皮で覆われ、車軸が軋まず、黄金の三つの鞘をもち、銀の三本の棹をもち、最高の戦車を、最高の馬と共に、ラーマ（パラシュラーマ）が私に与えてくれた。
dhanūṃṣi citrāṇi nirīkṣya śalya dhvajān gadāḥ sāyakāṃś ca ugrarūpān|
asiṃ ca dīptaṃ paramāyudhaṃ ca śaṅkhaṃ ca śubhraṃ svanavantamugram|| // 8-31-29 //
（22）見よシャルヤ、見事な数々の弓、旗、鉄棒、恐ろしい形の矢、燃え立つような剣、最高の武器、白く音の鋭い法螺貝――。
patākinaṃ vajranipātaniḥ svanaṃ sitāśvayuktaṃ śubhatūṇaśobhitam|
imaṃ samāsthāya ratharṣabhaṃ raṇe dṛḍhaṃ haniṣyāmy aham arjunaṃ balāt|| // 8-31-30 //
（23）旗を立て、雷のような音を発し、白馬をつけ、美しい矢筒で飾られたこの戦車の雄牛に乗り、戦場で私は強くアルジュナを討ち取ろう。
taṃ cenmṛtyuḥ sarvaharo'bhirakṣet sadā'pramattaḥ samare pāṇḍuputram|
taṃ vā haniṣyāmi raṇe sametya yāsyāmi vā droṇamukho yamāya|| // 8-31-31 //
（24）すべてを奪い取る死がパーンドゥの子（アルジュナ）を常に油断なく守ろうとも、私は戦場で彼と会って討ち取るか、さもなくばドローナに続いてヤマの世界へ行こう。
yamavaruṇakuberavāsavā vā yadi yugapat sagaṇā mahāhave|
jugupur iha sametya phalgunaṃ kimu bahunā saha tair jayāmi tam|| // 8-31-32 //
（25）ヤマ、ヴァルナ、クベーラ、インドラ――彼らが従者たちを連れて一斉に大戦場でアルジュナを守ろうとも、何を多く言うことがあろう――私は彼らと共にアルジュナに勝つのだ」。
sañjaya uvāca|
iti raṇarabhasasya katthatas tadupaniśamya vacaḥ sa madrarāṭ|
avahasadavamanya vīryavān pratiṣiṣidhe ca jagāda ca uttaram|| // 8-31-33 //
サンジャヤは語った。 （26）戦いに勢いづいて自讃するこの言葉を聞き、マドラ王（シャルヤ）は武勇ある者として嘲笑し、侮るように、それを戒めて答えた。
śalya uvāca|
virama virama karṇa katthanād atirabhaso'py ativācam uktavān|
kva ca hi naravaro dhanañjayaḥ kva punariha tvam aho narādhamaḥ|| // 8-31-34 //
シャルヤは語った。 （27）「やめよ、やめよ、カルナ、その自讃をやめよ。あまりに荒い気性で、度を越した言葉を吐いている。人中の優者アルジュナがどこにいて、人中の最低のお前がここでどうしようというのか。
yadusadanam upendrapālitaṃ tridivam iva amararājarakṣitam|
prasabham ativiloḍya ko haret puruṣavarāvarajām ṛte'rjunāt|| // 8-31-35 //
（28）神々の王（インドラ）に守られた神々の都のように、ヤーダヴァ族の都は、ウペーンドラ（クリシュナ）に守られている。そこを力ずくで荒らして、クリシュナの妹（スバドラー）をさらえる者が、アルジュナ以外にあろうか。
tribhuvanasṛjamīśvareśvaraṃ ka iha pumān bhavam āhvayed yudhi|
mṛgavadhakalahe ṛte'rjunāt surapativīryasamaprabhāvataḥ|| // 8-31-36 //
（29）三界を創造するシヴァ神、神々の主の主さえも、戦場で呼び出す男が、どこにいるか――狩猟のいさかいでアルジュナがそうしたが、他に誰がいるのか。インドラ王の武勇に等しい者を。
asurasuramahoragān narān garuḍapiśācasayakṣarākṣasān|
iṣubhir ajayad agnigauravāt svabhilaṣitaṃ ca havir dadau jayaḥ|| // 8-31-37 //
（30）アスラ、神々、大蛇、人々、ガルダ、ピシャーチャ、ヤクシャ、ラークシャサたちを、アルジュナは矢で征服し、火神アグニに敬われ、望んだ供物を彼に捧げた。
smarasi nanu yadā parair hṛtaḥ sahadhṛtarāṣṭrasuto vimokṣitaḥ|
adhirathaja narottamair yutān kuruṣu bahūn vinihatya tān arīn|| // 8-31-38 //
（31）思い出せ――かつて敵にさらわれたドリタラーシュトラの子（ドゥルヨーダナ）と、その仲間たちを、アルジュナが解放したことを。御者の子よ、クル族の中で、多くの敵をアルジュナは討ったのだ。
prathamamapi palāyite tvayi priyakalahā dhṛtarāṣṭrasūnavaḥ|
smarasi nanu yadā pramocitāḥ khacaragaṇān avajitya pāṇḍavaiḥ|| // 8-31-39 //
（32）お前が真っ先に逃げ出したのを覚えているだろう。いさかい好きなドリタラーシュトラの子たちが、ガンダルヴァたちに捕えられて、パーンダヴァたちが彼らを討って解放したときを。
samuditabalavāhanāḥ punaḥ puruṣavareṇa jitāḥ stha gograhe|
sagurugurusutāḥ sabhīṣmakāḥ kimu na jitaḥ sa tadā tvayā'rjunaḥ|| // 8-31-40 //
（33）武装した軍勢と乗り物を備えたお前たちが、牛奪回のとき、あの優者（アルジュナ）にふたたび打ち負かされたではないか。師（ドローナ）、師の子（アシュヴァッターマン）、ビーシュマもろともに。あのときもアルジュナに負かされたのではないか。
idam aparam upasthitaṃ punas tava nidhanāya suyuddham adya vai|
yadi na ripubhayāt palāyase samaragato'dya hato'si sūtaja|| // 8-31-41 //
（34）そして今、お前の滅びのために、再び立派な戦いが用意された。敵の恐怖に逃げずに戦場に出るなら、今日お前は討たれるだろう、御者の子よ」。
sañjaya uvāca|
iti bahuparuṣaṃ prabhāṣati pramanasi madrapatau ripus tavam|
bhṛśam abhiruṣitaḥ sarantapaḥ kurupṛtanāpatir āha madrapam|| // 8-31-42 //
サンジャヤは語った。 （35）このようにマドラ王がたくさんの辛辣な言葉を語ったので、嬉しそうに語っていたクル軍の将カルナは、敵を焼く者として、激しく憤り、マドラ王に言った。
karṇa uvāca|
bhavatu bhavatu kiṃ vikatthase nanu marma tasya hi yuddham udyatam|
yadi sa jayati mām iha āhave tata idam astu sukatthitaṃ tava|| // 8-31-43 //
カルナは語った。 （36）「よかろう、よかろう、何を自讃するのか。彼の急所となる戦いは始まったのだ。もし彼がこの戦場で私に勝てば、そのときにお前の言うことが正しかったと認めよう」。
sañjaya uvāca|
evam astv iti madreśa uktvā na uttaram uktavān|
yāhi śalya iti ca apy enaṃ karṇaḥ prāha yuyutsayā|| // 8-31-44 //
サンジャヤは語った。 （37）マドラ王は「よかろう」と言って、それ以上は答えなかった。「進め、シャルヤよ」と、戦いを望むカルナが彼を促した。
sa rathaḥ prayayau śatrūn nighnataḥ śalyasārathiḥ|
nighnan amitrān samare tamoghnaḥ savitā yathā|| // 8-31-45 //
（38）その戦車は、敵を討つために進んだ。シャルヤが御者となり、闘を滅する太陽のように、戦場で敵を討ちながら。
tataḥ prāyāt prītimān vai rathena vaiyāghreṇa śvetayujā'tha karṇaḥ|
sa ca ālokya dhvajinīṃ pāṇḍavānāṃ dhanañjayaṃ tvarayā paryapṛcchat|| || // 8-31-46 //
（39）喜びに満ちて、白馬をつけ虎皮で覆われた戦車でカルナは進んだ。彼はパーンダヴァ軍の旗を見て、急いてアルジュナ（ダナンジャヤ）のことを尋ねた。
iti śrīmanmahābhārate karṇaparvaṇi ekatriṃśo'dhyāyaḥ|| 31 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十一章は終わる。
