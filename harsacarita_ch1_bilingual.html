Harṣacarita — Prathama Ucchvāsaḥ
ハルシャチャリタ ― 第1章　ヴァーツヤーヤナ家系の記述
◆ Maṅgala-ślokāḥ
◆ 帰敬偈
namas tuṅga-śiraś-cumbi-candra-cāmara-cārave /
trailokya-nagarârambha-mūla-stambhāya Śambhave // 1.1 //
高くそびえる頂を撫でる月を白蓋（チャーマラ）として輝かせ、三界の都城建設の礎柱たるシャンバヴ（シヴァ神）に帰命す。【1.1】
Hara-kaṇṭha-grahânanda-mīlitâkṣīṃ namāmy Umām /
kāla-kūṭa-viṣa-sparśa-jāta-mūrcchâgamām iva // 1.2 //
ハラ（シヴァ）の喉を抱きしめる歓びに目を閉じたウマー女神に礼拝す。カーラクータ毒に触れて気を失ったかのようなその姿に。【1.2】
namaḥ sarva-vide tasmai Vyāsāya kavi-vedhase /
cakre puṇyaṃ Sarasvatyā yo varṣam iva Bhāratam // 1.3 //
一切を知るかの詩人の創造主ヴィヤーサに帰命す。彼はサラスヴァティー（弁才）をもって、雨のごとく功徳あるバーラタを成した。【1.3】
◆ Kavi-praśaṃsā
◆ 詩論 ― 良き詩人と悪しき詩人
prāyaḥ ku-kavayo loke rāgâdhiṣṭhita-dṛṣṭayaḥ /
kokilā iva jāyante vācâlāḥ kāma-kāriṇaḥ // 1.4 //
世にはおおむね悪しき詩人が、情に目を曇らせたまま、カッコウのように多弁にして欲のままに振る舞いつつ生まれてくる。【1.4】
santi śvāna ivâsaṃkhyā jāti-bhājo gṛhe-gṛhe /
utpādakā na bahavaḥ kavayaḥ śarabhā iva // 1.5 //
家ごとに犬のように数え切れぬほど血統ばかりの者がいる。しかし真に創造する詩人は、シャラバ（伝説の八脚獣）のようにまれである。【1.5】
anya-varṇa-parāvṛttyā bandha-cihna-nigūhanaiḥ /
an-ākhyātāḥ satāṃ madhye kaviś cauro vibhāvyate // 1.6 //
他人の言葉を別の文字に置き換え、盗みの痕跡を隠す――善き人々のあいだにあって、そのような詩人は盗人として見破られる。【1.6】
śleṣa-prāyam udīcyeṣu pratīcyeṣv artha-mātrakam /
utprekṣā dākṣiṇātyeṣu Gauḍeṣv akṣara-ḍambaram // 1.7 //
北方の詩人にはもっぱら語呂合わせ（シュレーシャ）、西方の詩人には意味の平板さ、南方の詩人には想像（ウトプレークシャー）、ガウダ地方の詩人には文字の虚飾がある。【1.7】
navo 'rtho jātir a-grāmyā śleṣo 'kliṣṭaḥ sphuṭo rasaḥ /
vikaṭâkṣara-bandhaś ca kṛtsnam ekatra duṣkaram // 1.8 //
新しい意味、粗野でない語、無理のない掛詞、明瞭な情趣（ラサ）、そして巧みな語の配列――これらすべてを一か所に集めることは困難である。【1.8】
kiṃ kaves tasya kāvyena sarva-vṛttânta-gāminī /
kathêva bhāratī yasya na vyāpnoti jagat-trayam // 1.9 //
一切の事柄を遍歴するバーラティー（弁才）が三界に行き渡らぬような詩人に、その詩に何の価値があろうか。【1.9】
ucchvāsânte 'py a-khinnās te yeṣāṃ vaktre Sarasvatī /
katham ākhyāyikâkārā na te vandyāḥ kavîśvarāḥ // 1.10 //
章の終わりに至ってもなお倦むことなく、サラスヴァティーがその口に宿るような者たち――物語体文学（アーキャーイカー）を創る偉大な詩人たちは、まこと崇敬されるべきである。【1.10】
◆ Pūrva-kavi-praśaṃsā
◆ 先人の詩人への賛辞
kavīnām agalad darpo nūnaṃ Vāsavadattayā /
śakty eva Pāṇḍu-putrāṇāṃ gatayā Karṇa-gocaram // 1.11 //
詩人たちの傲りは『ヴァーサヴァダッター』によって消え失せた。パーンドゥの子らの力（シャクティ＝槍）がカルナのもとに至ったかのように。【1.11】
pada-bandhôjjvalo hārī kṛta-varṇa-krama-sthitiḥ /
bhaṭṭāra-Hariścandrasya gadya-bandho nṛpâyate // 1.12 //
バッターラ・ハリシュチャンドラの散文構成は、語の配列輝き、心を奪い、色彩の序列を整え、王者の風格を備えている。【1.12】
a-vināśinam a-grāmyam akarot Sātavāhanaḥ /
viśuddha-jātibhiḥ kośaṃ ratnair iva subhāṣitaiḥ // 1.13 //
サータヴァーハナ王は、清浄な種姓を持つ宝石のごとき名句をもって、不滅にして粗野ならざる宝庫を築いた。【1.13】
kīrtiḥ Pravarasenasya prayātā kumudôjjvalā /
sāgarasya paraṃ pāraṃ kapi-senâiva setunā // 1.14 //
プラヴァラセーナの名声は、白い睡蓮のように輝きながら、猿の軍勢が橋によって大海の彼岸に達したかのように、海の向こう岸まで行き渡った。【1.14】
sūtra-dhāra-kṛtârambhair nāṭakair bahu-bhūmikaiḥ /
sa-patākair yaśo lebhe Bhāso deva-kulair iva // 1.15 //
バーサは、舞台監督が仕掛けた多幕の、旗印（パターカー＝副筋）を備えた戯曲群によって、まるで神々の一族のような名声を得た。【1.15】
nirgatāsu na vā kasya Kālidāsasya sūktiṣu /
prītir madhura-sāndrāsu mañjarīṣv iva jāyate // 1.16 //
カーリダーサの名句が世に出たとき、その甘く濃密な言葉の花房に、誰の心に歓びが生じなかったであろうか。【1.16】
samuddīpita-kandarpā kṛta-Gaurī-prasādhanā /
Hara-līlêva no kasya vismayāya Bṛhat-kathā // 1.17 //
カーマを燃え立たせ、ガウリーの装いを整えたかのようなハラの遊戯（ハラ・リーラー）、すなわちブリハトカターを読んで驚嘆しない者が誰かあろうか。【1.17】
Āḍhyarāja-kṛtôtsāhair hṛdaya-sthaiḥ smṛtair api /
jihvântaḥ kṛṣyamāṇêva na kavitve pravartate // 1.18 //
アーディヤ王が奮起させた言葉の数々は、心に留まり記憶されるだけでも、舌はその内に引き込まれるかのように、詩作に踏み出すことができなくなる。【1.18】
tathâpi nṛ-pater bhaktyā bhīto nirvahaṇâkulaḥ /
karomy ākhyāyikâmbho-dhau jihvā-plavana-cāpalam // 1.19 //
それでもなお、王への忠節から、完成への不安に怯えつつ、私はアーキャーイカーの大海に舌の泳ぎという無謀を試みる。【1.19】
sukha-prabodha-lalitā suvarṇa-ghaṭanôjjvalaiḥ /
śabdair ākhyāyikā bhāti śayyêva pratipādakaiḥ // 1.20 //
心地よい目覚めのように愛らしく、黄金の細工のごとく輝く語によって、アーキャーイカーは、足台（プラティパーダカ）に支えられた寝台のように光る。【1.20】
jayati jvalat-pratāpa-jvalana-prākāra-kṛta-jagad-rakṣaḥ /
sakala-praṇayi-manoratha-siddhi-śrī-parvato Harṣaḥ // 1.21 //
燃え盛る威光の炎の城壁によって世界を護り、すべての親しき者の願望成就の吉祥の山たるハルシャ王は勝利する。【1.21】
◆ Kathā-prārambhaḥ
◆ サラスヴァティー女神の降臨
evam anuśrūyate: purā kila bhagavān sva-lokam adhitiṣṭhan paramêṣṭhī vikāsini-padma-viṣṭhare samupaviṣṭaḥ sunāsīr-a-pramukhair gīrvāṇaiḥ parivṛto brahmôdyāḥ kathāḥ kurvann anyāś ca nir-avadyā vidyā-goṣṭhīr bhāvayan kadācid āsāṃ-cakre.
かくのごとく伝え聞く。いにしえ、至高なる主パラメーシュティン（ブラフマー神）は、ご自身の世界に住まい、花開く蓮華の座に着座し、インドラを筆頭とする神々に囲まれて、ブラフマン（梵）に関する物語を語り、また非の打ちどころのないさまざまな学問の談論を楽しんでおられた。
tathâsīnaṃ ca taṃ tribhuvana-pratīkṣyaṃ Manu-Dakṣa-Cākṣuṣa-prabhṛtayaḥ Prajāpatayaḥ sarve ca sapta-ṛṣi-puraḥ-sarā mahā-ṛṣayaḥ siṣevire. kecid ṛcaḥ stuti-caturāḥ samudacārayan. kecid apaciti-bhāñji yajūṃṣy apaṭhan. kecit praśaṃsā-sāmāni sāmāni jaguḥ. apare vivṛta-kratu-kriyā-tantrān mantrān vyācacakṣire. vidyā-visaṃvāda-kṛtāś ca tatra teṣām anyonyasya vivādāḥ prādur abhavan.
そのように座していた三界の注視すべき蓮華座のブラフマー神に、マヌ、ダクシャ、チャークシュシャをはじめとするプラジャーパティ（造物主たち）と、七聖仙を先頭とするすべての大聖仙たちが仕えていた。ある者たちは讃歌に巧みにリグ・ヴェーダの詩句を唱え、ある者たちは恭敬の念を込めてヤジュル・ヴェーダを読誦し、ある者たちは讃美のサーマン（旋律）を歌い、また別の者たちは祭祀の秘法を展開するマントラを解説した。そして学問上の見解の相違から、彼らの間に互いの論争が起こった。
athâtiroṣaṇaḥ prakṛtyā mahā-tapā munir Atres tanayas tārā-pater bhrātā nāmnā Durvāsā dvitīyenôpamanyu-nāmnā muninā saha kalahāyamānaḥ sāma-gāyan krodhândho visvaram akarot.
さてその折り、生来極めて激しやすい性質の大苦行者、アトリの息子にしてターラーパティ（月）の兄弟であるドゥルヴァーサスという名の聖仙が、ウパマニュという名の第二の聖仙と口論していたが、サーマ・ヴェーダを歌うにあたって怒りに盲いて調子を外してしまった。
sarveṣu ca teṣu śāpa-bhaya-pratipanna-mauneṣu muniṣv anyâlāpa-līlayā câvadhīrayati Kamala-saṃbhave Bhagavatī kumārī kiñcid unmukta-bāla-bhāve bhūṣita-nava-yauvane vayasi vartamānā, gṛhīta-cāmara-pracalad-bhuja-latā Pitāmaham upavījayantī, nirbhartsana-tāḍana-jāta-rāgābhyām iva sva-bhāvâruṇābhyāṃ pāda-pallavābhyāṃ samudbhāsamānā, śiṣya-dvayenêva pada-krama-mukhareṇa nūpura-yugalena vācālita-caraṇa-yugalā, dharma-nagara-toraṇa-stambha-vibhramaṃ bibhrāṇā jaṅghā-dvitayam, sa-līlam utka-kala-haṃsa-kula-kalâlāpa-pralāpini mekhalâdāmni vinyasta-vāma-hasta-kisalayā, vidvan-mānasa-nivāsa-lagnena guṇa-kalāpenêvâṃsâvalambinā brahmā-sūtreṇa pavitrī-kṛta-kāyā, bhāsvan-madhya-nāyakam an-ekam uktânuyātam apavarga-mārgam iva hāram udvahantī, vadana-praviṣṭa-sarva-vidyā-laktaka-rasenêva pāṭalena sphuratā daśana-cchadena virājamānā, saṃkrānta-kamalâsana-kṛṣṇâjina-pratimāṃ madhura-gītā-karṇanâvatīrṇa-śaśi-hariṇām iva kapola-sthalīṃ dadhānā, tiryak-sâvajñam unnamitâika-bhrū-latā, śrotram ekaṃ visvara-śravaṇa-kaluṣitaṃ prakṣālayantîvâpāṅga-nirgatena locanâśru-jala-pravāheṇêtara-śravaṇena ca vikasita-sita-Sindhuvāra-mañjarī-juṣā hasatêva prakaṭita-vidyā-madā, śruti-praṇayibhiḥ praṇavair iva karṇâvataṃsa-kusuma-madhu-kara-kulair upāsyamānā, sūkṣma-vimalena prajñā-pratānenêvâṃśukenâcchādita-śarīrā, vāṅmayam iva nirmalaṃ dikṣu daśana-jyotsnā-lokaṃ vikirantī devī Sarasvatī śrutvā jahāsa.
すべての聖仙たちが呪いを恐れて沈黙を決め込み、蓮華座のブラフマー神が別の話題の遊びでやり過ごそうとされたとき――女神サラスヴァティーは、少女時代をいくらか脱して花開く青春のさなかにある乙女であった。チャーマラを手にした揺れる腕の蔓でブラフマー神を扇ぎ、叱責と打擲で赤くなったかのような生来赤い足の芽で輝き、二人の弟子のように歩みに合わせて音を立てる一対の足環で両足を饒舌にさせ、ダルマの都城の門柱のような錯覚を与える一対の脛を持ち、優雅に鳴くハンサ鳥の群れのさえずりのような音を立てる腰帯の紐に左手の若芽を置き、学者の心の住処に留まる美徳の束のような肩から垂れるバラモンの聖紐で身を浄め、輝く中央の宝石を主とした多くの従者の付き従う解脱の道のような首飾りを戴き、口に入ったすべての学問のラッカ樹脂の汁のようにピンク色に輝く唇で美しく、蓮華座の黒い鹿皮の似姿が映った、甘い歌を聴きに降りて来た月のウサギのような頬を持ち、片方の眉の蔓を横に軽蔑を込めて上げ、一方の耳は調子外れを聞いて汚れたそれを目尻から流れ出る涙の水流で洗い清めるかのように、もう一方の耳には咲き開いた白いシンドゥヴァーラの花房に止まった蜂のような耳飾りの花が笑うかのように学問の誇りを露わにし、ヴェーダを愛するオーンカーラの音のような耳飾りの花の蜂の群れに崇拝され、微細で清浄な知恵の広がりのような薄衣で身を覆い、言語そのもののように清らかな歯の月光の輝きを四方に撒き散らす女神サラスヴァティーは、それを聞いて笑ったのである。
dṛṣṭvā ca tāṃ tathā hasantīṃ sa muniḥ: "āḥ pāpa-kāriṇi, dur-gṛhīta-vidyā-lavâvalepa-dur-vidagdhe, mām upahasasi" ity uktvā śiraḥ-kampa-śīryamāṇa-bandha-viśarāror unmiṣat-piṅgalimno jaṭā-kalāpasya rociṣā siñcann iva roṣa-dahana-draveṇa daśa diśaḥ kṛta-kāla-saṃnidhānām ivândha-kārita-lalāṭa-paṭṭâṣṭâpadām antakântaḥ-pura-maṇḍana-patra-bhaṅga-makarikāṃ bhru-kuṭim ābadhnan, atilohitena cakṣuṣâmarṣa-devatāyai sva-rudhirôpahāram iva prayacchan, nirdaya-daṣṭa-daśana-cchada-bhaya-palāyamānām iva vācaṃ rundhan dantâṃśu-cchalena, aṃsâvasraṃsinaḥ śāpa-śāsana-paṭṭasyêva grathnan granthim anyathā kṛṣṇâjinasya, sveda-kaṇa-pratibimbitaiḥ śāpa-śaṅkā-śaraṇâgatair iva surâsura-munibhiḥ pratipanna-sarvâvayavaḥ, kopa-kampa-taralitâṅgulinā kareṇa prasādana-lagnām akṣara-mālām ivâkṣa-mālām ākṣipya kāmaṇḍalavena vāriṇā samupaspṛśya śāpa-jalaṃ jagrāha.
このように笑う彼女を見て、かの聖仙ドゥルヴァーサスは「ああ、罪深い者よ、学問の端くれを掴んだだけの思い上がった愚か者め、おれを嘲笑うのか」と言い放ち、頭を振ったことで結び目がほどけ崩れゆく、開いて黄褐色に輝く縺れ髪の束の光で、怒りの炎の溶けた液で十方を灌ぐかのように、死の近接を告げるかのように暗黒に染まった額の碁盤目模様の、閻魔の内宮の装飾の葉文様のマカラのような眉間の皺を結び、極めて赤い目で不寛容の女神に自らの血の供物を捧げるかのようにし、容赦なく噛んだ唇の恐れから逃げ出そうとする声を歯の光の口実で塞ぎ、肩から滑り落ちる呪いの勅令の巻物のように黒い鹿皮の結び目を別のように結び、汗の粒に映る呪いの恐怖に避難を求めるかのような天人・阿修羅・聖仙たちがすべての肢体に宿り、怒りの震えで揺れる指の手で、嘆願にすがりつく文字の数珠のような念珠を振り払い、水瓶の水で浄めの口漱ぎをして、呪いの水を手に取った。
atrântare svayambhuvo 'bhyāśe samupaviṣṭā devī mūrtimatī pīyūṣa-phena-paṭala-pāṇḍaraṃ kalpa-druma-dukūla-valkalaṃ vasānā, bisa-tantumayenâṃśukenôn-nata-stana-madhya-baddha-gātrikā-granthiḥ, tapo-bala-nirjita-tri-bhuvana-jaya-patākābhir iva tisṛbhir bhasma-puṇḍraka-rājibhir virājita-lalāṭâjirā, skandhâva-lambinā sudhā-phena-dhavalena tapaḥ-prabhāva-kuṇḍalī-kṛtena Gaṅgā-srotasêva yoga-paṭṭakena viracita-vaikakṣyakā, savyena brahmôtpatti-puṇḍarīka-mukulam iva sphaṭika-kamaṇḍaluṃ kareṇa kalayantī, dakṣiṇam akṣa-mālā-kṛta-parikṣepaṃ kambu-nirmitôrmikā-danturitaṃ tarjana-taraṅgita-tarjanīkam utkṣipantī karam, "āḥ pāpa, krodhôpahata, durātman, a-jña, an-ātma-jña, brahma-bandho, muni-śeṭa, apasada, nirākṛta, katham ātma-skhalita-vilakṣaḥ surâsura-muni-manuja-vṛnda-vandanīyāṃ tri-bhuvana-mātaraṃ bhagavatīṃ Sarasvatīṃ śaptum abhilaṣasi" ity abhidadhānā, roṣa-vimukta-vetrâsanair oṅ-kāra-mukharita-mukhair utkṣepa-dolāyamāna-jaṭā-bhāra-bharita-digbhiḥ parikara-bandha-bhramita-kṛṣṇâjinâṭopa-cchāyā-śyāmāyamāna-divasair amarṣa-niḥśvāsa-dolā-preṅkholita-brahmalokaiḥ soma-rasam iva sveda-visara-vyājena sravadbhir agnihotra-pavitra-bhasma-smera-lalāṭaiḥ kuśa-tantu-cāmara-cīra-cīvaribhir āṣāḍhibhiḥ praharaṇī-kṛta-kamaṇḍalu-maṇḍalair mūrtaiś caturbhir vedaiḥ saha bṛsīm apahāya Sāvitrī samuttasthau.
そのとき、自存者（ブラフマー神）のそばに座っていた、甘露の泡の群れのように白いカルパ樹の絹の樹皮衣をまとい、蓮根の糸のような薄衣で高い胸の中央に結んだ胴衣の結び目を持ち、苦行の力で三界を征服した勝利の旗印のような三本の灰の額飾りの線条で額の庭を輝かせ、肩から垂れる甘露の泡のように白い苦行の力で巻かれたガンガー河の流れのようなヨーガの帯で斜め掛けの飾りを作り、左手にブラフマーの誕生の蓮華の蕾のような水晶の水瓶を持ち、右手に念珠を巻いた法螺貝製の指輪で飾られた脅すように振る人差し指を高く上げ、「ああ、罪深き者よ、怒りに打たれし者よ、悪しき魂よ、無知なる者よ、自己を知らざる者よ、バラモンの恥よ、聖仙の風上にも置けぬ者よ、堕落した者よ、見捨てられた者よ、自らの過ちに恥じ入りながら、天人・阿修羅・聖仙・人間の群れに崇められるべき三界の母たる女神サラスヴァティーを呪おうと欲するのか」と叫ぶ――怒りで放たれた藤の座を振り回す、オーンカーラの音で口を鳴らす、振り上げる度に揺れる縺れ髪の重みで方角を満たす、帯を締め直す際に回転する黒い鹿皮の影で日を暗くする、不寛容の溜息の揺れでブラフマー界を揺り動かす、ソーマ酒のように汗の口実で滴る、火供の浄灰で輝く額の、クシャ草の糸のチャーマラと粗い衣の苦行者たち、武器にされた水瓶の輪で武装した、具現した四つのヴェーダとともに――座を蹴って、サーヴィトリーは立ち上がった。
Tato "marṣaya bhagavan, a-bhūmir eṣā śāpasya" ity anunāthyamāno 'pi vibudhaiḥ, "upādhyāya, skhalitam ekaṃ kṣamasva" iti baddhâñjali-puṭaiḥ prasādyamāno 'pi sva-śiṣyaiḥ, "putra, mā kṛthās tapasaḥ pratyūham" iti nivāryamāṇo 'py Atriṇā, roṣâveśa-vivaśo Durvāsāḥ "dur-vinīte, vyapanayāmi te vidyā-janitām unnatim imām. adhastād gaccha martya-lokam" ity uktvā tac-chāpôdakaṃ visasarja.
そこで「尊者よ、許されよ。この方は呪うべき対象にはございません」と神々になだめられても、「師よ、一つの過ちをお許しください」と合掌して弟子たちに宥められても、「息子よ、苦行の障害となることをしてはならぬ」と父アトリに止められても、怒りの激情に支配されたドゥルヴァーサスは「無礼な者よ、おまえの学問から生じたこの高慢を取り除いてやろう。下界の人間世界へ堕ちるがよい」と告げ、呪いの水を放った。
pratiśāpa-dānôdyatāṃ Sāvitrīm "sakhi, saṃhara roṣam. a-saṃskṛta-matayo 'pi jātyâiva dvi-janmāno mānanīyāḥ" ity abhidadhānā Sarasvaty eva nyavārayat.
逆呪いを放とうと身構えるサーヴィトリーを、「友よ、怒りを鎮めなさい。粗野な精神の者であっても、生まれによってバラモンである者は本性によって尊敬されるべきです」と言って、サラスヴァティー自身が止めた。
◆ Pitāmaha-vacanam
◆ ブラフマー神の訓戒
atha tāṃ tathā śaptāṃ Sarasvatīṃ dṛṣṭvā pitāmaho Bhagavān kamalôtpatti-lagna-mṛṇāla-sūtrām iva dhavala-yajñôpavītinīṃ tanum udvahan, udgacchad-acchâṅgulīya-marakata-mayūkha-latā-kalāpena tri-bhuvanôpaplava-praśama-kuśâpīḍa-dhāriṇêva dakṣiṇena kareṇa nivārya śāpa-kalakalam, ati-vimala-dīrghair bhāvi-kṛta-yugârambha-sūtra-pātam iva dikṣu pātayan daśana-kiraṇaiḥ, Sarasvatī-prasthāna-maṅgala-paṭahenêva pūrayann āśāḥ svareṇa sudhīram uvāca:
こうして呪いを受けたサラスヴァティーを見て、祖父ブラフマー神は――蓮華の誕生に付着した蓮根の糸のような白い祭紐をまとう体を起こし、透き通った指輪のエメラルドの光線の蔓の束で三界の災厄を鎮めるクシャ草の冠を戴くかのような右手で呪いの騒動を制し、極めて清浄で長い歯の光線を来たるべきユガの始まりの測量糸のように四方に投じ、サラスヴァティーの出発の吉祥な太鼓のように声で方角を満たしながら、静かに仰せになった。
"brahman, na khalu sādhu-sevito 'yaṃ panthāḥ yenâsi pravṛttaḥ. nihanty eṣa parastāt. uddāma-prasṛtêndriyâśva-samutthāpitaṃ hi rajaḥ kaluṣayati dṛṣṭim an-akṣa-jitām. kiyad dūraṃ vā cakṣur īkṣate. viśuddhayā hi dhiyā paśyanti kṛta-buddhayaḥ sarvān arthān a-sataḥ sato vā. nisarga-virodhinī cêyaṃ payaḥ-pāvakayor iva dharma-krodhayor ekatra vṛttiḥ. ālokam apahāya kathaṃ tamasi nimajjasi? kṣamā hi mūlaṃ sarva-tapasām. para-doṣa-darśana-dakṣā dṛṣṭir iva kupitā buddhir na te ātma-rāga-doṣaṃ paśyati. kva mahā-tapo-bhāra-vaivadhikatā, kva puro-bhāgitvam?
「バラモンよ、おまえが踏み入った道は、善き者が歩む道ではない。それは後になって己を滅ぼす。制御なく奔放に駆ける感官という馬が巻き起こす塵は、感覚に打ち勝たれていない視力を曇らせる。目がどれほど遠くを見ることができようか。清浄な知恵によってこそ、悟った者たちは真偽いずれの事物をも見るのだ。水と火のように、ダルマと怒りが一処に共存するのは、本性上矛盾するものである。光を捨てて、どうして闇に沈むのか。忍耐こそすべての苦行の根本ではないか。他者の過ちを見出すに長けた視線のように、怒った知性はおまえ自身の執着の過ちを見ない。大いなる苦行の重荷を担うこととはかけ離れ、先行者たること（前進すること）とは遠く離れている。」
"ati-roṣaṇaś cakṣuṣmān andha eva janaḥ. na hi kopa-kaluṣitā vimṛśati matiḥ kartavyam a-kartavyaṃ vā. kupitasya prathamam andha-kārī bhavati vidyā, tato bhrukuṭiḥ. ādāv indriyāṇi rāgaḥ samāskandati, caramaṃ cakṣuḥ. ārambhe tapo galati, paścāt sveda-salilam. pūrvam a-yaśaḥ sphurati, anantaram adharaḥ. kathaṃ loka-vināśāya te viṣa-pādapasyêva jaṭā-valkalāni jātāni. an-ucitā khalv asya muni-veṣasya hāra-yaṣṭir iva vṛtta-muktā citta-vṛttiḥ. śailūṣa iva vṛthā vahasi kṛtrimam upaśama-śūnyena cetasā tāpasâkalpam. alpam api na te paśyāmi kuśala-jātam. anenâti-laghimnâdyâpy upary eva plavase jñānôdanvataḥ. na khalv an-eḍa-mūkāḥ eḍā jaḍā vā sarva ete maharṣayaḥ. roṣa-doṣa-niṣadye sva-hṛdaye nigrāhye kim artham asi nigṛhītavān an-āgasaṃ Sarasvatīm. etāni tāny ātma-pramāda-skhalita-vailakṣyāṇi, yair yāpyatāṃ yāty a-vidagdho janaḥ"
「あまりに激しやすい者は、目が見えていても盲目に等しい。怒りで曇った知性は、なすべきことと、なすべからざることを弁別しない。怒った者にはまず学問が盲目にさせ、次に眉間の皺がそうする。はじめに情欲が感官を襲い、最後に目を襲う。最初に苦行が溶けて流れ、後から汗の水が流れる。先に不名誉が現れ、後から唇が（震える）。世界の破壊のためにおまえの編み髪と樹皮の衣は生えたのか、毒の木のように。まことにこの聖仙の装いにはふさわしくない、首飾りの糸のように丸く抜け落ちた心の動き（品行）だ。俳優のように、静寂を欠いた心で苦行者の扮装を虚しく身につけている。わずかばかりの善も、おまえには見えない。この軽さゆえに、今もなお知恵の大海の表面に浮かんでいるのだ。この偉大な聖仙たちは、けっして口のきけぬ者でも鈍い者でもない。怒りの罪の座たる己の心こそ制御すべきであるのに、なぜ罪なきサラスヴァティーを抑圧したのか。これこそまさに自らの不注意の過ちの狼狽であり、それによって愚かな者は落ちぶれてゆくのだ」。
ity uktvā punar āha: "vatse Sarasvati, viṣādaṃ mā gāḥ. eṣā tvām anuyāsyati Sāvitrī. vinodayiṣyati câsmad-viraha-duḥkhitām. ātma-ja-mukha-kamalâvalokanâvadhiś ca te śāpo 'yaṃ bhaviṣyati" iti.
こう述べてからさらに仰せになった。「娘サラスヴァティーよ、悲嘆に暮れるでない。このサーヴィトリーがおまえに従って行くであろう。そしてわれとの別離に悲しむおまえを慰めてくれるであろう。おまえの呪いは、己の息子の蓮華のような顔を見届けるまでのことである」と。
etāvad abhidhāya visarjita-surâsura-muni-manuja-maṇḍalaḥ sa-saṃbhramôpagata-Nārada-skandha-vinyasta-hastaḥ samucitâhnika-karaṇāyôdatiṣṭhat. Sarasvaty api śaptā kiñcid adho-mukhī dhavala-kṛṣṇa-śārāṃ kṛṣṇâjina-lekhām iva dṛṣṭim urasi pātayantī surabhi-niḥśvāsa-parimala-lagnair mūrtaiḥ śāpâkṣarair iva ṣaṭ-caraṇa-cakrair ākṣyamāṇā śāpa-śoka-śithilita-hastā 'dho-mukhī-bhūtenôpadiśyamāna-martya-lokâvataraṇa-mārgêva nakha-mayūkha-jālakena nūpura-vyāhārâhūtair bhavana-kalahaṃsa-kulair brahma-loka-nivāsi-hṛdayair ivânugamyamānā samaṃ Sāvitryā gṛham agāt.
これだけを仰せになって、天人・阿修羅・聖仙・人間の群れを退出させ、慌てて駆けつけたナーラダの肩に手を置いて、日課の勤行のために立ち上がられた。サラスヴァティーもまた、呪われてうつむきがちに、白と黒のまだらの黒い鹿皮の線のような視線を胸の上に落としながら、芳しい溜息の香りに引き寄せられた、具現した呪いの文字のような六脚の蜂の群れに導かれ、呪いと悲しみに力を失った手の、下を向いた爪の光の網で人間界への降下の道を指し示すかのように、足環の音に呼ばれた宮殿のハンサ鳥の群れに、ブラフマー界に住む者たちの心のように付き従われながら、サーヴィトリーとともに自室に帰った。

サーヴィトリーは、空虚な心で何やら物思いに沈み、涙を浮かべているサラスヴァティーに語りかけた。「友よ、三界に教えを授ける巧みなそなたの前で、おしゃべりする私の舌は恥じ入ります。そなたも知ってのとおり、善き人にすら、悪人に劣らぬ無慈悲さで、一瞬にして崩れ、抗いがたく、楽しからぬ、運命の逆の振る舞いとはこのようなものです。理由もなく、ふさわしからぬ者から降りかかる苦難の一粒すら、気高い者の心をも曇らせます。絶え間なく涙の水で灌がれる木のように、災難すら千倍に芽生えます。極めて繊細な者には、苦悩の微粒子がジャスミンの花のように萎みをもたらします。偉大な者の上に落ちかかる、たとえ微小なものであっても、象にとっての突き棒のように、苦しみは蹂躙するに十分です。生来の愛着の紐の結び目で縛られた親族のような故郷は、捨てがたいものです。親しき者との別離は、鋸の刃のように心を引き裂きます。そなたはこのようになるべきではありません。まことにそなたは苦しみの種の芽を生む土地ではないのですから。」
"api ca purā-kṛte karmaṇi balavati śubhe 'śubhe vā phala-kṛti tiṣṭhaty adhiṣṭhātari praṣṭhe pṛṣṭhataś ca ko 'vasaro viduṣi śucām. idaṃ ca te tri-bhuvana-maṅgalâika-kamalam a-maṅgala-bhūtāḥ katham iva mukham apavitrayanty aśru-bindavaḥ. tad alam. adhunā kathaya katamaṃ bhuvo bhāgam alaṅ-kartum icchasi. kasminn avatitīrṣati te puṇya-bhāji pradeśe hṛdayam. kāni vā tīrthāny anugrahītum abhilaṣasi. keṣu vā dhanyeṣu tapo-vana-dhāmasu tapasyantī sthātum icchasi. sajjo 'yam upacaraṇa-caturaḥ saha-pāṃśu-krīḍā-paricaya-peśalaḥ preyān sakhī-janaḥ kṣiti-talâvataraṇāya. an-anya-śaraṇā câdyâiva prabhṛti pratipadyasva manasā vācā kriyayā ca sarva-vidyā-vidhātāraṃ dātāraṃ ca śvaḥ-śreyasasya caraṇa-rajaḥ-pavitrita-tridaśâsuraṃ sudhā-sūti-kalikā-kalpita-karṇâvataṃsaṃ deva-devaṃ tri-bhuvana-guruṃ try-ambakam. alpīyasâiva kālena sa te śāpa-śoka-viratiṃ vitariṣyati" iti.
「さらに、過去に行った業が善であれ不善であれ、果報を生む監督者が前にも後ろにもいるのに、賢者に嘆きの余地がありましょうか。三界の吉祥の唯一の蓮華であるこのそなたの顔を、不吉なものとなった涙の滴がどうして穢すことができましょうか。さあ、もう十分です。今こそ語りなさい、大地のいずれの地を飾りたいのか。いずれの功徳ある土地にそなたの心は降り立ちたいのか。いずれの聖地を恩寵したいのか。いずれの幸ある苦行の森の聖所で苦行しつつ留まりたいのか。もてなしに巧みな、幼い頃から砂遊びで親しんだ愛しい友の一団が、地上への降下の準備を整えています。そして他に頼る者なき今日よりさっそく、心と言葉と行為をもって、すべての学問の創造者にして来世の幸福の授与者、足の塵で天人と阿修羅を浄化する、甘露を産む三日月を耳飾りとして戴く、神々の神にして三界の師たる三眼のシヴァ神に帰依なさい。わずかの時のうちに、シヴァ神はそなたに呪いと悲しみからの解放を与えてくださるでしょう」と。

anyedyur udite bhagavati tri-bhuvana-śekhare khaṇa-khaṇāyamāna-skhalat-khalīna-kṣata-nija-turaga-mukha-kṣiptena kṣata-jenêva pāṭalita-vapuṣy udayâcala-cūḍā-maṇau jarat-kṛkavāku-cūḍâruṇâruṇa-puraḥsare virocane nâti-dūra-vartī vivicya pitāmaha-vimāna-haṃsa-kula-pālaḥ paryaṭann a-para-vaktram uccair agāyat:
翌日、三界の冠石たる太陽が昇った。チャリチャリと音を立てて滑り外れる轡に傷ついた己の馬の口から飛び散る血で体を赤くしたかのような、東山の冠石の上の、老いた鶏の鶏冠のように赤いピンク色の先触れを持つ太陽が昇ったとき、さほど遠くないところでブラフマー神の宮殿のハンサ鳥の群れの番人が、人気のないところを一人巡りながら、朗々と歌った。

「清らかな心の湖に住まいを得て甘やかされたハンサ鳥の雌よ、なぜ渇望の瞳を揺らすのか。池に降り立ちなさい。やがてまた蓮華の住処に帰るのだから。」
tac chrutvā Sarasvatī punar acintayat: "aham ivânena paryanuyuktā. bhavatu. mānayāmi muner vacanam" ity uktvôtthāya kṛta-mahī-talâvataraṇa-saṃkalpā parityajya viyoga-viklavaṃ sva-parijanaṃ jñāti-vargam a-vigaṇayyâvagaṇā triḥ pradakṣiṇī-kṛtya catur-mukhaṃ katham apy anunaya-nivartitânuyāyi-vrati-vrātā brahma-lokataḥ Sāvitrī-dvitīyā nirjagāma.
これを聞いてサラスヴァティーは再び思った。「私自身がこの者に促されているかのようだ。よろしい。聖仙（ブラフマー神）の言葉を敬おう」と言って立ち上がり、地上への降下を決意し、離別に震える己の従者を捨て、親族の群れをも顧みず、四つの顔を持つブラフマー神を三度右繞し、どうにか慰めの言葉で引き返させた付き従おうとする修行者の群れを残して、ブラフマー界からサーヴィトリーとともに出発した。

そして天空に立ったまま見た――ヴァルナ神の首飾りのような、月山の甘露の滝のような、ヴィンディヤ山の月長石の流れのような、ダンダカの森の樟脳の木の溶けた流れのような、四方の優美さの泉のような、空の美の水晶の岩板の寝台のような、澄んで冷たく甘い水に満ちた、祖父ブラフマー神の子孫たるヒラニヤヴァーハという名の大河を。人々はこれをショーナ河と呼ぶ。
dṛṣṭvā ca taṃ rāmaṇīyaka-hṛta-hṛdayā tasyaiva tīre vāsam aracayat. uvāca ca Sāvitrīm: "sakhi, madhura-mayūra-virutayaḥ kusuma-pāṃśu-paṭala-sikatila-taru-talāḥ parimala-matta-madhupa-veṇī-vīṇā-raṇita-ramaṇīyā ramayanti māṃ mandī-kṛta-Mandākinī-dyuter asya mahā-nadasyôpakaṇṭha-bhūmayaḥ. pakṣapāti ca hṛdayam atrâiva sthātuṃ me" iti.
それを見て美しさに心を奪われたサラスヴァティーは、その岸辺に住居を定めた。そしてサーヴィトリーに言った。「友よ、孔雀の甘い鳴き声が響き、花粉の塵の層で砂のようになった木の下が、芳香に酔った蜂の編み髪のヴィーナーの音色で美しく、マンダーキニーの輝きをも色褪せさせるこの大河の岸辺の土地が私を喜ばせます。そしてここに留まりたいと私の心は偏っています」と。

言葉を歓迎されてサーヴィトリーの同意を得て、その西岸に降り立った。そして一つの清浄な岩場を持つ岸辺の蔓の東屋に住居の心を定めた。休息してからほどなく立ち上がり、サーヴィトリーとともに供養の花を摘んで沐浴した。そして砂州の上に安置したシヴァ・リンガに、至高の信仰をもって、至高のブラフマンを先頭とする正しい印契の結びで準備を整え、ドルヴァーの歌を含む、大地・風・森・天空・火・太陽・月・祭主からなる八つの姿を長く瞑想しながら、八花供養を捧げた。労せず手に入る果実と根で、甘露の味にも勝る甘さの冷たいショーナ河の水で体の維持をした。日を過ごした後は、蔓の東屋の岩の上に若葉の寝床を作って眠った。翌日もまた同じ手順で昼夜を過ごした。

このように日々が過ぎ、時が流れ、太陽が一時ほど昇ったある日、北の方角から、木霊で満たされた森の奥まで響く、深くまた高い馬のいななきの轟きを聞いた。好奇心をそそられて蔓の東屋から出て見渡すと、開いたケータキーの花の芯の葉のように白っぽい砂塵の塊が、さほど遠くないところから正面に向かって押し寄せてくるのが見えた。

やがて近づくにつれて姿が明らかになるその大きな、シャファラ魚の腹のように灰色の砂塵の中に、水中のマカラの円陣のように浮かびながら前方を駆ける――垂れ下がる巻き毛の若芽で前髪の束を額に作り、白い歯飾りの光で笑う頬の壁を持ち、塗り込められた黒い沈香の泥の粉で黒い斑のカシャーヤ色の上着を締め、上衣で頭巾を作り、左手首に鮮やかな金の腕輪をはめ、二重の帯の紐で固く結んだ剣の帯をつけ、絶え間ない鍛錬で体を硬くした、風の鹿の群れのように何度も空に跳び上がり、平地も穴も枝も跳び越え、隅を守る武器を持ち、刀を片手に、奉仕で集めたさまざまの森の花・果実・根・葉を携え、「進め進め、行け行け、退けよ退けよ、前方に道を開けよ」と絶え間なく叫ぶ若い者が大半の、千人ほどの歩兵を前に走らせた、主を伴う馬の群れを見た。
madhye ca tasya sârdha-candreṇa muktā-phala-jāla-mālinā vividha-ratna-khaṇḍa-khacitena śaṅkha-kṣīra-phena-pāṇḍureṇa kṣīrôdenêva svayaṃ Lakṣmīṃ dātum āgatena gagana-gatenâtapatreṇa kṛta-cchāyam, acchâcchenâbharaṇa-dyutīnāṃ nivahena diśām iva darśanânurāga-lagnena cakravālenânugamyamānam, ā-nitamba-vilambinyā mālatī-śekhara-srajā sakala-bhuvana-vijayârjitayā rūpa-patākayêva virājamānam, utsarpibhiḥ śikhaṇḍa-khaṇḍikā-padma-rāga-maṇer aruṇair aṃśu-jālair a-dṛśyamāna-vana-devatā-vidhṛtair bāla-pallavair iva pramṛjyamāna-mārga-reṇu-paruṣa-vapuṣam, bakula-kuḍmala-maṇḍalī-muṇḍa-mālā-maṇḍana-manohareṇa kuṭila-kuntala-stabaka-mālinā maulinā mīlitâtapaṃ pibantam iva divasam, paśu-pati-jaṭā-mukuṭa-mṛgâṅka-dvitīya-śakala-ghaṭitasyêva sahaja-lakṣmī-samāliṅgitasya lalāṭa-paṭṭasya manaḥśilā-paṅka-piṅgalena lāvaṇyena limpantam ivântarikṣam, abhinava-yauvanârambhâvaṣṭambha-pragalbha-dṛṣṭi-pāta-tṛṇī-kṛta-tri-bhuvanasya cakṣuṣaḥ prathimnā vikaca-kumuda-kuvalaya-kamala-saraḥ-sahasra-saṃchādita-daśa-diśaṃ śaradam iva pravartayantam, ati-surabhi-sahakāra-karpūra-kakkola-lavaṅga-pārijātaka-parimala-pucā matta-madhu-kara-kula-kolāhala-mukhareṇa mukhena sa-nandana-vanaṃ vasantam ivâvatārayantam, āsanna-suhṛt-parihāsa-bhāvanôttānita-mukha-mugdha-hasitair daśana-jyotsnā-snapita-diṅ-mukhaiḥ punaḥ-punar nabhasi saṃcāriṇaṃ candrâlokam iva kalpayantam, anaṅga-yugâvatāram iva darśayantam, candra-mayīm iva sṛṣṭim utpādayantam, vilāsa-prāyam iva jīva-lokaṃ janayantam, kīrti-stambham iva rūpasya, mūla-kośam iva lāvaṇyasya, prathamâṅkuram iva kānti-latāyāḥ aṣṭādaśa-varṣa-deśīyaṃ yuvānam adrākṣīt.
その中央に、半月形の真珠の網の花環で飾られ、さまざまな宝石の欠片をちりばめた、法螺貝の乳の泡のように白い、乳海のようにラクシュミー女神自らを与えに来たかのような空に浮かぶ日傘で影を作られ、透き通った装身具の輝きの群れに方角の地平線が観覧の愛着で付き従うかのように囲まれ、腰まで垂れるジャスミンの冠の花環で全世界の征服で得た美の旗印のように輝き、立ち昇るシカンダカの冠石のルビーの赤い光線の網で見えぬ森の女神たちが差し出す若葉のように道の塵にまみれた体を拭われ、バクラの蕾の花輪の髑髏の首飾りのように美しい巻き毛の花束の冠で日差しを閉ざして昼を飲むかのような、パシュパティ（シヴァ）の縺れ髪の冠の月の第二の欠片で組まれたかのような生来の美に抱かれた額板の、マナッシラー（雌黄）の泥の黄褐色の優美さで空を塗るかのような、花開く新しい青春の始まりの大胆な視線の投射で三界を草のように軽んじる目の広さで、咲き開く夜蓮と青蓮と赤蓮の池の千で十方を覆う秋を始めるかのような、極めて芳しいマンゴー・樟脳・カッコーラ・丁子・パーリジャータカの芳香の束に酔った蜂の群れの喧騒で騒がしい口でナンダナの園を伴う春を降ろすかのような、親しい友との冗談の思いに口を開いた無邪気な微笑みの歯の月光で方角の口を沐浴させ何度も空に月光を再現するかのような――カーマ神の再誕のような、月でできた創造のような、遊戯を主とする生命の世界を生むかのような、美の栄光の柱のような、優美さの根本の宝庫のような、美の蔓の最初の芽のような――十八歳ほどの青年を見た。
pārśve ca tasya dvitīyam a-para-saṃśliṣṭa-turaṅgam, prāṃśum uttapta-tapanīya-stambhâkāram, pariṇata-vayasam api vyāyāma-kaṭhina-kāyam, nīca-nakha-śmaśru-keśam, śukti-khalatim, iṣat-tundilam, romaśôraḥ-sthalam, an-ulvaṇôdāra-veṣatayā jarām api vinayam iva śikṣayantam, gurutām api laghu-bhāvam iva labdhavantam, māhātmyam apy anuyāyitvam ivâdhyāpayantam, mahimānam api bhaṭa-bhāvam iva saṃsthāpayantam, valakṣa-vārabāṇa-dhāriṇam, dhauta-dukūla-paṭṭikā-pariveṣṭita-mauliṃ puruṣam.
その傍らに、別の馬に乗った第二の者を見た。背が高く、熱した黄金の柱のような姿の、年を重ねていても鍛錬で硬い体の、短く切った爪と髭と髪の、貝殻のような禿頭の、わずかに太鼓腹の、毛深い胸の、大げさでない上品な装いで老齢にすら謙虚さを教えるかのような、重厚さにすら軽やかさを得させたかのような、偉大さにすら従者の態度を教えるかのような、威厳にすら兵士の振る舞いを定めるかのような、白い縞の弓を持ち、洗った白い絹の帯で頭を巻いた男であった。
atha sa yuvā puro-yāyināṃ yathā-darśanaṃ pratinivṛtyâti-vismita-manasāṃ kathayatāṃ padātīnāṃ sakāśād upalabhya divyâkṛti-tat-kanyā-yugalam upajāta-kutūhalaḥ pratūrṇa-turago didṛkṣus taṃ latā-maṇḍapôddeśam ājagāma. dūrād eva ca turagād avatatāra. nivārita-parijanaś ca tena dvitīyena sādhunā saha caraṇābhyām eva sa-vinayam upasasarpa.
さてこの若者は、先行して偵察した歩兵たちが驚いた心で戻って来て報告する話から、天の姿をした乙女の一対がいることを知り、好奇心をそそられて馬を急がせ、あの蔓の東屋を見に来た。そして遠くから馬を降り、従者を制止して、あの第二の善き者とともに徒歩で慎み深く近づいた。
kṛtôpasaṃgrahaṇau tau Sāvitrī samaṃ Sarasvatyā kisalayâsana-dānâdinā sa-kusuma-phalârghyâvasānena vana-vāsôcitenâtithyena yathā-kramam upajagrāha. āsīnayoś ca tayor āsīnā nâticiram iva sthitvā taṃ dvitīyaṃ pravayasam uddiśyâvādīt:
迎え入れられた二人を、サーヴィトリーはサラスヴァティーとともに、若葉の座の提供に始まり花と果物の供物の水に至る、森の暮らしにふさわしいもてなしの作法に従って順に迎え入れた。二人が座し、自らも座してしばらく過ごした後、その年長の者に向かって語った。
"ārya, sahaja-lajjā-dhanasya pramadā-janasya prathamâbhibhāṣaṇam a-śālīnatā, viśeṣato vana-mṛgī-mugdhasya kula-kumārī-janasya. kevalam iyam ālokana-kṛtârthāya cakṣuṣe spṛhayantī prerayaty udanta-śravaṇa-kutūhalinī śrotra-vṛttiḥ. prathama-darśane côpāyanam ivôpanayati saj-janaḥ praṇayam. a-pragalbham api janaṃ prabhavatā praśrayeṇârpitaṃ mano-madhv iva vācālayati. a-yatnenâivâti-namre sādhau dhanuṣîva guṇaḥ parāṃ koṭim āropayati visrambhaḥ. janayanti ca vismayam ati-dhīra-dhiyām apy a-dṛṣṭa-pūrvā dṛśyamānā jagati sraṣṭuḥ sṛṣṭy-atiśayāḥ."
「尊者よ、生来の恥じらいを財とする女性が最初に声をかけるのは慎みに欠けること、とりわけ森の雌鹿のように純朴な良家の乙女にとっては。ただ、一目で目の充足を得ようとして渇望する、消息を聞きたいという好奇心が耳の働きを駆り立てるのです。初めて会った時にも、善き人は贈り物のように友情を差し出します。控えめな者であっても、備わった謙譲さから注がれる心の蜜のようなものが饒舌にさせるのです。労せずして極めて謙虚な善き人において、弓の弦のように、信頼は極みにまで引き上げます。そしてこれまで見たことのない、世に現れる創造主の創造の驚異は、極めて堅固な知恵の者にすら驚嘆を生じさせます。」
"yatas tri-bhuvanâbhibhāvi rūpam idam asya mahânubhāvasya. saujanya-paratantrā cêyaṃ Devānāṃ-priyasyâtibhadratā kārayati kathāṃ na tu yuvati-jana-sahôtthā taralatā. tat kathayâgamanenâpuṇya-bhāk katamo vijṛmbhita-viraha-vyathaḥ śūnyatāṃ nīto deśaḥ? kva vā gantavyam? kasya vâyam apahṛta-hara-huṅkārâhaṅkāro 'para ivânanya-jo yuvā? kiṃ-nāmno vā samṛddha-tapasaḥ pitur ayam a-mṛta-varṣī kaustubha-maṇir iva Harer hṛdayam āhlādayati? kā câsya tri-bhuvana-namasyā vibhāta-saṃdhyêva mahatas tejaso jananī? kāni vâsya puṇya-bhāñji bhajanty abhikyām akṣarāṇi?"
「なぜなら三界を圧倒する美がこの偉大なる方のものだからです。そして善良さに従属するこの極めて善き態度が語らせるのであって、若い女性に共通する軽薄さではありません。お話しください、あなた方の到来によって、到来前にはどの不運な土地が別離の苦しみで空虚にされたのですか。どこに行かれるのですか。この方は誰の――ハラ（シヴァ）の威嚇の叫びの傲慢をも奪い取った、他から生まれたのではないような若者は？豊かな苦行を持ついかなる名の父のこの甘露を降らす者は、カウストゥバの宝石のようにハリ（ヴィシュヌ）の心を歓ばせるのですか。三界に礼拝される、暁の黎明のような偉大な光輝の母は誰ですか。いかなる功徳ある文字がこの方の名を成しているのですか。」
sa praśrayeṇôttaram akarot: "āyuṣmati, guṇinaḥ svâlāpa-mādhurī hṛdayaṃ śithilayati. ayaṃ khalu bhūṣaṇaṃ Bhārgava-vaṃśasya bhagavato bhūr-bhuvaḥ-svas-tritaya-tilakasya, a-dabhra-prabhāva-stambhita-Jambhāri-bhuja-stambhasya, surâsura-mukuṭa-maṇi-śilā-śayana-dur-lalita-pāda-paṅkeruhasya, nija-tejaḥ-prasara-pluṣṭa-pulomnaś Cyavanasya bahir-vṛtti-jīvitaṃ Dadhīco nāma tanayaḥ."
彼は恭しい態度で答えた。「ご令嬢よ、善き人のお話の甘美さは心を柔らかくします。この方はまさに、三界の額飾りたる、絶大な威力でインドラの腕の柱をも止めた、天人・阿修羅の冠宝石の岩の寝台で甘やかされた蓮華の足を持つ、己の光輝の広がりでプロームナ（インドラニーの父）をも焼いた、バールガヴァの一族の宝飾、チヤヴァナの外なる命のような息子であり、ダディーチャと申します。」
"janyany apy asya jita-jagato 'neka-pārthiva-sahasrânuyātasya Śaryātasya sutā rājaputrī tri-bhuvana-kanyā-ratnaṃ Sukanyā nāma. tāṃ khalu devīm antarvatnīṃ viditvā vaijanane māsi prasavāya pitā patyuḥ pārśvāt sva-gṛham ānāyayata. asūta ca sā tatra devī dīrghâyuṣam enam. avardhatân-ehasā ca tatrâivâyam ānandita-jñāti-vargo bālas tāraka-rāja iva rājīva-locano rāja-gṛhe."
「この方の母は、世界を征服し幾千の王に付き従われたシャリヤータの娘、王女にして三界の乙女の宝であるスカンヤーと申します。その王妃が身籠もったことを知って、出産の月に父シャリヤータが夫のもとから己の屋敷に連れ帰りました。そしてその王妃はそこで長命のこの方を産みました。そしてこの方は蓮の目をした子として、星の王（月）のように、親族の群れに喜ばれながら、苦もなくその王宮で育ちました。」
"Bhartṛ-bhavanam āgacchantyām api duhitari nâsecanaka-darśanam imam amuñcan mātā-maho mano-vinodanaṃ naptāram. aśikṣatâyaṃ tatrâiva sarvā vidyāḥ sakalāś ca kalāḥ. kālena côpārūḍha-yauvanam imam ālokyâham ivâsāv apy anubhavatu mukha-kamalâvalokanânandam asyêti mātā-mahaḥ kathaṅ-katham apy enaṃ pitur antikam adhunā vyasarjayat."
「娘が夫の家に戻るときにも、母方の祖父は飽くことなき美しさのこの孫を心の慰めとして手放しませんでした。この方はそこですべての学問とすべての技芸を学びました。やがて青春を迎えたこの方を見て、『わしと同じくあの方（チヤヴァナ）もこの方の蓮華のような顔を見る喜びを味わうがよい』と母方の祖父がどうにかこの方を父のもとに今送り出したのです。」
"māmâpi tasyâiva devasya Sugṛhīta-nāmnaḥ Śaryātasyâjñākāriṇaṃ Vikukṣi-nāmānaṃ bhṛtya-paramāṇum avadhārayatu bhavatī. pituḥ pāda-mūlam āyāntaṃ mayā sâbhisāram akarot svāmī. tad dhi naḥ kula-kramâgataṃ rāja-kulam. uttamānāṃ ca cirantanatā janayaty anujīviny api jane kiyan-mātram api mandâkṣam. a-kṣīṇaḥ khalu dākṣiṇya-kośo mahatām. itaś ca gavyūti-mātram iva pāre-Śoṇaṃ tasya bhagavataś Cyavanasya sva-nāmnā nirmita-vyapadeśaṃ Cyāvanaṃ nāma caitra-ratha-kalpaṃ kānanaṃ nivāsaḥ. tad-avadhir evêyaṃ nau yātrā."
「私もまた、あのよき名を持つシャリヤータ王の命に従うヴィクシュクシという名の微小な召使いとお思いください。父のもとに向かうこの方に、主人は私を同行させました。それはわれわれの一族代々仕えてきた王家なのです。そして高貴な方々の寛大さは、仕える者にさえ、いくばくかの親しい目を向けさせるものです。偉大な者の親切の宝庫は尽きることがありません。ここから約一ガヴユーティ（四キロ）ほどのショーナ河の向こう岸に、あのチヤヴァナ仙が自らの名で建てた名を持つ、チャイトラ・ラタの園に匹敵する森、チヤーヴァナという住居があります。それが我々の旅の目的地です。」

純白の大粒の真珠の首飾りで大きな遊星の群れが散りばめられた秋の白い疎らな雲に覆われた空のように輝き、胸の満ちた壺の上に赤と緑の光線の若葉を持つ宝石の垂れ飾りの花環をある功徳ある者の心への入場の花環のように結び、手首にはめた一つの金の腕輪のエメラルドのマカラの台座から放たれる緑の光線の列で地平線を緑に染めてラクシュミーの法螺貝のように付き従われ、極めて濃いビンロウで黒ずんだ唇の閉じた口で顔の月が飲んだ夕焼けの赤みを帯びた闇を吐き出すかのように、咲いた目の青蓮の好奇心に隠れる蜂の群れの列で青い絹の網のように下の顔を覆い、藍の色を置いた青さの孔雀の首のような色の左耳の歯飾りで暗雲の葉陰のように稲妻のごとく輝き、バクラの実に似た三つの真珠で作ったバーリカーの対の俯いた顔から光の水を降らせて極めて柔らかい腕の蔓を潤すかのように、右耳にはケータキーの花の芯の葉の一本を月の舌の蔓のように優美さの貪欲さで頬を舐めるかのようにし、タマーラのように暗い麝香の泥の額飾りの点でカーマ神の全財産のように封印された顔を戴き、額に揺れる分け目に接する宝石の鮮やかな光線の網で赤い薄衣のように頭のヴェールを作り、背後に揺れる無造作に結んだ緩い髪束で青いチャーマラのように影を落とし、冠石のマカラの飾りを戴いた――マカラの旗印（カーマ神）の旗のような、月の家の守護女神のような、花の弓の蘇生薬のような、情欲の海の汀のような、青春の月の出の月光のような、情趣の甘露の大河のような、優雅さの発芽のような、美の栄光の柱のような――青蓮の花弁の花環のように長い目の、ピンク色の唇の、クンダの蕾のように白い歯の、シリーシャの花環のように極めて柔らかい一対の腕の、蓮のように柔らかい手の、バクラのように芳しい溜息の、チャンパカのように輝く体の、花でできたかのようなビンロウの箱持ちの侍女を伴ったマーラティーが姿を現した。
dūrād eva ca Dadhīca-premṇā Sarasvatyā luṇṭhitêva mano-rathaiḥ, ākṛṣṭêva kutūhalena, pratyudgatêvôtkalikābhiḥ, āliṅgitêvôtkaṇṭhayā, antaḥ-praveśitêva hṛdayena, snapitêvânandâśrubhiḥ, viliptêva smitena, vījitêvôcchvasitaiḥ, ācchāditêva cakṣuṣā, abhyarcitêva vadana-puṇḍarīkeṇa, sakhī-kṛtêvâśayā savidham upayayau. avatīrya ca dūrād evânatena mūrdhnā praṇāmam akarot. āliṅgitā ca tābhyāṃ sa-vinayam upāviśat. sa-praśrayaṃ tābhyāṃ saṃbhāṣitā ca puṇya-bhājanam ātmānam amanyata. akathayac ca Dadhīca-saṃdiṣṭaṃ śirasi nihitenâñjalinā namas-kāram. agṛhṇāc câkarataḥ prabhṛty a-grāmyatayā tais tair ati-peśalair ālāpaiḥ Sāvitrī-Sarasvatyor manasī.
遠くからすでにダディーチャへの恋ゆえに、サラスヴァティーは夢に奪われたかのように、好奇心に引き寄せられたかのように、高鳴る期待に出迎えたかのように、渇望に抱擁されたかのように、心の中に迎え入れたかのように、歓喜の涙に沐浴させたかのように、微笑みに塗油されたかのように、溜息に扇がれたかのように、視線に覆われたかのように、顔の蓮華に供養されたかのように、心に友とされたかのように――マーラティーはそばに近づいた。馬を降りて遠くから頭を低くして敬礼した。二人に抱擁されて慎み深く座った。二人と恭しく語り合い、自分を功徳の器と思った。ダディーチャから託された、頭の上に合掌を載せた敬礼の言葉を伝えた。そして最初から粗野ならぬ、極めて巧みなさまざまの会話でサーヴィトリーとサラスヴァティーの心を捉えた。
◆ Mālatī-dūtī
◆ マーラティーの仲立ち
krameṇa câtīte madhyan-dina-samaye Śoṇam avatīrṇāyāṃ Sāvitryāṃ snātum utsārita-parijanā sâkūtêva Mālatī kusuma-srastara-śāyinīṃ samupasṛtya Sarasvatīm ābabhāṣe: "devi, vijñāpyaṃ naḥ kiñ-cid asti rahasi" iti.
やがて午後になり、サーヴィトリーが沐浴のためにショーナ河に降りると、従者を退けたマーラティーは、意味ありげに花の寝床に横たわるサラスヴァティーに近づいて語りかけた。「姫さま、密かにお伝えしたいことがございます」。
Sarasvatī tu Dadhīca-sandeśâśaṅkinī mandaṃ mandam udagāt: "sakhi Mālati, kim-artham evam abhidadhāsi? kâham avadhāna-dānasya? vyāvṛṇu vara-varṇini, vivakṣitam" iti.
サラスヴァティーはダディーチャからの伝言ではないかと疑い、はやる心で静かに起き上がった。「友マーラティーよ、なぜそのようにおっしゃるのですか。私に注意を向ける値打ちがあるとでも。美しき方よ、語りたいことをお明かしなさい」。
sā tv avādīt: "devi, jānāsy eva mādhuryaṃ viṣayāṇām, lolupatāṃ cêndriya-grāmasya, unmāditāṃ ca nava-yauvanasya, pāriplavatāṃ ca manasaḥ. prakhyātâiva manmathasya dur-nivāratā. ato na mām upālambhenôpasthātum arhasi. na ca bāliśatā capalatā cāraṇatā vā vācālatāyāḥ kāraṇam. na kiñ-cin na kārayaty a-sādhāraṇā svāmi-bhaktiḥ. sā tvaṃ devi, yadâiva dṛṣṭâsi devena tata evârabhyâsya kāmo guruḥ, candramā jīvitêśaḥ, malaya-marud-ucchvāsa-hetuḥ, ādhayo 'ntar-aṅga-sthāneṣu, saṃtāpaḥ parama-suhṛt, prajāgara āptaḥ, mano-rathāḥ sarva-gatāḥ, niḥśvāsā vigrahâgre-sarāḥ, mṛtyuḥ pārśva-vartī, raṇaraṇakaḥ saṃcārakaḥ saṃkalpā buddhy-upadeśa-vṛddhāḥ. kiñ ca vijñāpayāmi. anurūpo deva ity ātma-saṃbhāvanā, śīlavān iti prakrama-viruddham, dhīra ity avasthā-viparītam, subhaga iti tvad-āyattam, sthira-prītir iti nipuṇôpakṣepaḥ, jānāti sevitum ity a-svāmi-bhāvôcitam, icchati dāsa-bhāvam ā-maraṇāt kartum iti dhūrtâlāpaḥ, bhavana-svāminī bhavêty upapralobhanam, puṇya-bhāginī bhajati bhartāraṃ tādṛśam iti svāmi-pakṣa-pātaḥ, tvaṃ tasya mṛtyur ity a-priyam, a-guṇa-jñâsîty adhikṣepaḥ, svapne 'py asya bahuśaḥ kṛta-prasādâsîty a-sâkṣikam, prāṇa-rakṣârtham arthayata iti kātaratā, tatra gamyatām ity ājñā, vārito 'pi balād āgacchatîti paribhavaḥ. tad evam a-gocare girām asîti śrutvā devī pramāṇam" ity abhidhāya tūṣṇīm abhūt.
マーラティーは言った。「姫さま、感覚の対象の甘美さはご存じでしょう。感官の群れの貪欲さも、新しい青春の狂気も、心の浮動もご存じでしょう。カーマの止めがたさは周知のことです。ゆえに私を非難で迎えないでくださいませ。幼稚さでも軽薄さでも旅芸人の芸でもなく、饒舌さの原因は別にあるのです。並外れた主人への忠節は何でもさせます。姫さまよ、あなた様をお見かけになったまさにその時から、あの方にとってカーマが師となりました。月が命の主となりました。マラヤ山の風が溜息の原因となりました。苦悩が心の内側の座を占めました。灼熱が最高の友となりました。不眠が側近となりました。空想があらゆるところに行き渡りました。溜息が先陣となりました。死が傍らに立ちました。足環の音が歩み回る者となり、思念が知恵の教えの老人となりました。さらに申し上げます。『あの方にふさわしい』というのは自惚れ、『品性がある』というのは筋違い、『毅然としている』というのは実状と正反対、『幸ある方』というのはあなた様次第、『変わらぬ愛』というのは巧みな仕掛け、『仕える術を知っている』というのは主人らしからぬ態度、『死ぬまで奴隷になりたい』というのは悪賢い台詞、『館の女主人になれ』というのは誘惑、『功徳の持ち主はそのような夫に仕える』というのは主人びいき、『あなたは彼の死だ』というのは不愉快、『美徳を知らない女だ』というのは侮辱、『夢の中でも何度も恩寵を与えた』というのは証拠なし、『命の保護のために懇願する』というのは臆病、『そこへ行け』というのは命令、『止めても力ずくで来る』というのは恥辱です。ゆえに『言葉の及ばぬ方』と聞いて、姫さまのご判断こそが権威でございます」。そう言って黙った。
atha Sarasvatī prīti-visphāritena cakṣuṣā pratyavādīt: "ayi, na śaknomi bahu bhāṣitum. eṣâsmi te smita-vādini vacasi sthitā. gṛhyantām amī prāṇāḥ" iti.
サラスヴァティーは喜びに見開いた目で答えた。「ああ、多くは語れません。微笑みながら語る者よ、あなたの言葉のままに私はいます。この命をお受け取りなさい」と。
Mālatī tu "devi, yad ājñāpayasi, ati-prasādāya" ity abhidhāya harṣôpaplutâñjalim akarot. praṇamya ca prajavena turagena tatāra Śoṇam. agāc ca Dadhīcam ānetuṃ Cyavanâśrama-padam.
マーラティーは「姫さま、ご命令のとおり、まことに光栄でございます」と言い、歓喜に溢れた合掌をした。敬礼してから駿馬でショーナ河を渡った。そしてダディーチャを連れに、チヤヴァナの仙庵に向かった。
◆ Dadhīca-samāgamaḥ
◆ ダディーチャの来訪と結合
ājagāma ca madhu-māsa iva surabhi-gandha-vāhaḥ, haṃsa iva kṛta-mṛṇāla-dhṛtiḥ, śikhaṇḍîva ghana-prīty-unmukhaḥ, payoda iva samasta-cātaka-jīvana-dāna-dakṣaḥ, pavanôddhatâśoka-pallava-prāvṛḍ-agni-jvālêvôpacita-tejo-rāśiḥ Mālatī-dvitīyo Dadhīcaḥ.
そして春の月のように芳しい香りの風を帯び、ハンサ鳥のように蓮根を保ち、孔雀のように雨雲を慕い、雨雲のようにすべてのチャータカ鳥に命を与える施しに巧みで、風に揺れるアショーカの若葉の雨季の火の炎のように蓄えた光輝の山のような――マーラティーを伴ったダディーチャがやって来た。
āgatya ca hṛdaya-gata-dayitā-nūpura-rava-vimiśrayêva haṃsa-gadgadayā girā kṛta-saṃbhāṣaṇo yathā manmathaḥ samājñāpayati yathā yauvanam upādiśati yathā vasanto nirdiśati yathā mādhavo nideśayati yathā madanôtsavo vivṛṇoti tathā tām abhirāmāṃ rāmām aramayat.
やって来て、心の中の恋人の足環の響きに混じるかのような、ハンサ鳥のように甘く途切れがちな声で挨拶を交わし、カーマが命じるように、青春が教えるように、春が指示するように、春の月が導くように、愛の祭りが開くように――あの美しきラーマー（愛しい女）を楽しませた。
upajāta-visrambhā câtmānam akathayad asya Sarasvatī. tena tu sârdham eka-divasam iva saṃvatsaram adhikam anayat.
信頼を得たサラスヴァティーは己の正体を彼に告げた。そしてダディーチャとともに一日のように一年以上を過ごした。
◆ Sārasvata-janma
◆ サーラスヴァタの誕生
atha daiva-yogāt Sarasvatī babhāra garbham. asūta cânehasā sarva-lakṣaṇâbhirāmaṃ tanayam. tasmai ca jāta-mātrāyâiva "samyak-sarahasyāḥ sarve vedāḥ sarvāṇi ca śāstrāṇi sakalāś ca kalā mat-prabhāvāt svayam āvir-bhaviṣyanti" iti varam adāt.
やがて天の運命により、サラスヴァティーは身籠もった。そしてあらゆる吉相を備えた愛らしい息子を容易に産んだ。生まれたばかりのその子に「すべてのヴェーダとその秘義、すべての学問、すべての技芸が、私の威力によって自ずから現れるであろう」という恩恵を授けた。
sad-bhartṛ-ślāghayā darśayitum iva hṛdayenâdāya Dadhīcaṃ pitāmahâdeśāt samaṃ Sāvitryā punar api brahma-lokam āruroha.
善き夫を誇りに見せるかのようにダディーチャを心に抱いて、ブラフマー神の命によりサーヴィトリーとともに再びブラフマー界に昇った。
gatāyāṃ ca tasyāṃ Dadhīco 'pi hṛdaye hrādinī evâbhihato Bhārgava-vaṃśa-saṃbhūtasya bhrātur brāhmaṇasya jāyām Akṣamālâbhidhānāṃ muni-kanyakām ātma-sūnoḥ saṃvardhanāya niyujya virahâturas tapase vanam agāt.
彼女が去った後、ダディーチャもまた心を雷に打たれたかのように、バールガヴァの一族に生まれたバラモンの兄弟の妻で、聖仙の娘であるアクシャマーラーという名の女に、息子の養育を託し、別離の苦しみに打たれて苦行のために森に入った。
Akṣamālā tu taṃ Sarasvatī-sūnuṃ sva-putram iva snehenâvardhayat. āsīc câsyāḥ sva-garbha-sambhūto Vatsa-nāmā putraḥ. sa câpy Akṣamālā-tanayaḥ Sārasvatena saha vardhata. ekas tayoḥ Sārasvatâkhya evâbhavat, aparo 'pi Vatsa-nāmâsīt. āsīc ca tayoḥ sôdaryayor iva spṛhaṇīyā prītiḥ.
アクシャマーラーはそのサラスヴァティーの息子を、自分の子のように愛情をもって育てた。そして彼女には自分の胎から生まれたヴァツァという名の息子がいた。このアクシャマーラーの息子もまたサーラスヴァタとともに成長した。一人はサーラスヴァタ（サラスヴァティーの子）と呼ばれ、もう一人はヴァツァと名づけられた。この二人の間には、同腹の兄弟のような羨むべき友情があった。
◆ Vātsyāyana-vaṃśaḥ
◆ ヴァーツヤーヤナ家系
atha Sārasvato mātur mahimnā yauvanârambha evâvir-bhūtâśeṣa-vidyā-saṃbhāras tasmin sa-vayasi bhrātari preyasi prāṇa-same suhṛdi Vatse vāṅ-mayaṃ samastam eva saṃcārayām āsa. cakāra ca kṛta-dāra-parigrahasyâsya tasminn eva pradeśe prītyā Prītikūṭa-nāmānaṃ nivāsam. ātmanâpy āṣāḍhī, kṛṣṇâjinī, akṣa-valayī, valkalī, mekhalī, jaṭī ca bhūtvā tapasyato janayitur eva jagāmântikam.
さてサーラスヴァタは、母の偉大さにより、青年期の始まりにしてすべての学問の蓄えが自ずから現れ、同年輩にして兄弟のように愛しい命に等しい友ヴァツァに、すべての言語の知識を伝授した。そして妻を娶ったヴァツァのために同じ土地に愛をこめてプリーティクータという名の住居を作った。自らもまたアーシャーディーの杖を持ち、黒い鹿皮をまとい、念珠の腕輪をし、樹皮の衣を着け、腰帯を締め、縺れ髪を結って苦行に赴き、苦行する父のもとに行った。
atha Vatsāt pravardhamānâdi-puruṣa-janitâtma-caraṇônnati-nirgata-praghoṣaḥ prāvartata vimalo vaṃśaḥ. yasmād ajāyanta Vātsyāyanā nāma gṛha-munayaḥ.
さてヴァツァからは、初代の人から生まれた自らの足の高みから発する響きが増大する清浄な一族が広がった。そこからヴァーツヤーヤナと呼ばれる在家聖者たちが生まれた。
te câsan nityâgnihotra-dhūma-dhūsarita-gṛhâjirāḥ, adhīta-traya-trayī-vidyāḥ, ṣaḍ-aṅga-vid-vedāḥ, kṛtâdhyayana-vratôpanayanâdi-saṃskārāḥ, a-luptâgrahâyaṇi-paurṇa-māsī-cāturmāsya-dakṣâyaṇya-prabhṛti-yajña-kriyāḥ, sāyam-prātar-agni-hotriṇaḥ, soma-pīthino, 'dhīta-mīmāṃsāḥ, vedânta-vido, nyāya-vidaḥ, sarva-sattva-sādhāraṇa-sauhārda-dravârdrī-kṛta-hṛdayāḥ, a-sādhāraṇā dvi-jātayaḥ.
彼らは、絶え間ないアグニホートラ（火供）の煙で灰色に染まった家の庭を持ち、三つの三ヴェーダの学問を修め、六支を備えたヴェーダを知り、学習の誓い・入門式などの浄化の儀式を完了し、アーグラハーヤニー・満月祭・四ヶ月祭・ダクシャーヤニーをはじめとする祭祀の勤行を欠かさず、朝夕のアグニホートラを行い、ソーマ酒を飲み、ミーマーンサーを学び、ヴェーダーンタを知り、ニヤーヤ（論理学）に通じ、すべての生命に対する普遍的な友情で潤された心を持つ、平凡ならざるバラモンであった。
teṣu câivam utpadyamāneṣu kālena Kubera-nāmā dvijo janma lebhe. tasyâbhavann Acyuta Iśāno Haraḥ Pāśupataś cêti catvāro tanayāḥ. tatra Pāśupatasyâika evâbhavad Arthapatir iti nāmnā mahâtmā sūnuḥ. so 'janayad Bhṛguṃ Haṃsaṃ Indraṃ Prabhākaraṃ Citrabhānuṃ Devadattaṃ Kuberaṃ Dadhīcaṃ Bādarāyaṇaṃ Sindhuṃ Yajñaṃ cêty ekādaśa pavitrān putrān.
かくのごとき者たちが次々と生まれ、時を経てクベーラという名のバラモンが生まれた。彼にはアチュタ、イーシャーナ、ハラ、パーシュパタという四人の息子がいた。そのうちパーシュパタにはただ一人の偉大な魂の息子アルタパティがいた。アルタパティはブリグ、ハンサ、インドラ、プラバーカラ、チトラバーヌ、デーヴァダッタ、クベーラ、ダディーチャ、バーダラーヤナ、シンドゥ、ヤジュニャという十一人の清浄な息子を生んだ。
alabhata ca Citrabhānus teṣāṃ madhye Rājadevy-abhidhānāyāṃ brāhmaṇyāṃ Bāṇam ātmajam.
そしてその中のチトラバーヌは、ラージャデーヴィーという名のバラモンの妻にバーナという息子を得た。
◆ Bāṇasya bālyam — yauvanam
◆ バーナの少年時代と放浪
sa bāla eva balavato vidher vaśād upasaṃpannayā vyayujyata jananyā. jāta-snehas tu nitarāṃ pitâivâsya mātṛtām akarot. avardhata ca tenâdhikataram ādhīyamāna-dhṛtir dhāmni nije.
バーナは幼くして、強力な運命の力により、母と早くに死別した。しかし深い愛情を注ぐ父が母の代わりをも務めた。そして父のもとで一層堅固さを増しながら自分の家で成長した。
kṛtôpanayanâdi-kriyā-kalāpasya samāvṛttasya câsya catur-daśa-varṣa-deśīyasya pitâpi divam agamat.
入門式などの儀式のすべてを終え、学業を修了した十四歳頃、父もまた天に召された。
saṃsthite ca pitari mahatā śokenâbhīlam anuprāpto divā-niśaṃ dahyamāna-hṛdayaḥ kathaṅ-katham api katipayān divasān ātma-gṛha evânaiṣīt. gate ca viralatāṃ śoke śaiśavôcitāny an-ekāni cāpalāny ācarann itvaro babhūva.
父が逝去した後、大いなる悲しみに打ちひしがれ、恐ろしいほどの嘆きに付き従い、昼夜燃える心で、どうにか数日を自宅で過ごした。やがて悲しみが薄れると、少年にありがちな数々の軽率な振る舞いを重ね、気ままになった。
abhavaṃś câsya sa-vayasaḥ samānāḥ suhṛdaḥ sahāyāś ca. tathā ca. bhrātarau pāraśavau Candrasena-Mātṛṣeṇau, bhāṣā-kavir Īśānaḥ paraṃ mittram, maskarī Tāmracūḍakaḥ. sa ebhir anyaiś cânugamyamāno bālatayā nighnatām upagato deśântarâvalokana-kautukâkṣipta-hṛdayaḥ gṛhān niragāt.
そして同年代の同等の友人や仲間ができた。すなわち、異母兄弟のチャンドラセーナとマートリシェーナ、俗語の詩人イーシャーナが親友、遊行僧タームラチューダカ。バーナはこれらの者や他の者たちに付き従われ、少年の無鉄砲さに陥り、異国の地を見たいという好奇心に心を奪われ、家を出た。
agāc ca nir-avagraho grahavān iva nava-yauvanena svairiṇā manasā mahatām upahāsyatām.
そして制約なく、惑星に取り憑かれたかのように奔放な若い心のままに、偉大な人々の笑いものとなった。
atha śanaiḥ śanair aty-udāra-vyavahṛti-mano-hṛnti bṛhanti rāja-kulāni vīkṣamāṇaḥ, nir-avadyā-vidyā-vibhāvita-guru-kulâvāseṣu vasan, satāṃ samāgameṣu samyag anuśīlayan vinayam, punar api tam eva Vaipaścitīm ātma-vaṃśôcitāṃ prakṛtim abhajat.
やがて次第に、極めて寛大な振る舞いで心を奪う壮大な王宮の数々を目にし、非の打ちどころのない学問で輝く師の家に住まい、善き人々の集いで謙虚さを正しく修練し、再びかのヴァイパシュチティー（知恵）という己の一族に相応しい本性に帰った。
mahataś ca kālāt tam eva bhūyo Vātsyāyana-vaṃśâśramam ātmano janma-bhuvaṃ brāhmaṇâdhivāsam agamat. tatra ca cira-darśanād abhinavī-bhūta-sneha-sad-bhāvaiḥ āptair utsava-divasa ivânanditâgamano bāla-mitra-maṇḍala-madhya-gato mokṣa-sukham ivânvabhavat.
そして長い時を経て、再びあのヴァーツヤーヤナ一族の修行院、己の生まれた地であるバラモンの集落に戻った。そこで久しく会わなかったことで新鮮になった愛情の真心をもつ親族たちに、祝祭の日のように到着を喜ばれ、幼なじみの輪の中に入って、解脱の幸福を味わうかのようであった。
