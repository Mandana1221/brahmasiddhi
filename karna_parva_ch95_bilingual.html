karṇaparva — pañcanavatitamo'dhyāyaḥ (95)
第95章 ― ビーマによるアルジュナへの叱咤激励
sañjaya uvāca|
tau śaṅkhabherīninade samṛddhe samīyatuḥ śvetahayau narāgryau|
vaikartanaḥ sūtaputro'rjunaśca durmantrite te sasutasya rājan||
// 8-95-1 //
サンジャヤは語った。
法螺貝と太鼓の音が盛大に響く中、白い馬に乗る二人の人中の最良者、ヴァイカルタナ（カルナ）とアルジュナが激突した。おまえの息子たちの愚かな策謀のためにこうなったのだ、王よ。
'āśīviṣāvagnimivotsṛjantau tathā mukhābhyāmabhiniḥ śvasantau|
yaśasvinau jajvalaturmṛdhe tadā ghṛtāvasiktāviva havyavāhau'||
yathā gajau haimavatau prabhinnau pravṛddhadantāviva vāsitārthe|
tathā samājagmaturugravīryau dhanañjayaścādhirathiśca vīrau||
balāhakeneva mahābalāhako yadṛcchayā vā giriṇā yathā giriḥ|
tathā dhanurjyātalaneminiḥsvanau samīyatustāviṣuvarṣavarṣiṇau||
śarāstraśaktyṛṣṭigadāsisarpau roṣānilodvūtamahormimālau|
yathā'calau dvau calatastathā tau yathā'rṇavau cāśu caturyugānte'||
// 8-95-2-5 //
毒蛇のように口から火を吐き息を吐きながら、名高き二人は戦場で輝いた。まるでギーを注がれた二つの祭火のように。ヒマラヤの二頭の狂象が牙を伸ばして雌を争うように、恐るべき武勇のダナンジャヤとアディラティの勇者は激突した。雷雲が雷雲と、山が偶然山と出会うように、弓弦と車輪の音を響かせながら二人は矢の雨を降らせて相まみえた。矢・武器・槍・棍棒・剣を蛇のように携え、怒りの風に煽られた大波のように、二つの動く山のように、世界の終末の四つの時代の終わりにおける二つの大洋のようであった。
pravṛddhaśṛṅgadrumavīrudoṣadhī pravṛdvanānāvidhanirjharaughau|
yathā'calau vā calitau mahājalaistathā mahāstrairitaretaraṃ hataḥ||
// 8-95-6 //
高い峰と木々と薬草が繁り、さまざまな滝が流れ落ちる二つの山のように、偉大な武器で互いを打ち合った。
sa sannipāto rathayormahānabhūtsureśavairocanayoryathā purā|
śarairvinunnāśvaniyantṛdehayoḥ suduḥsahāstraiḥ paribhinnadehayoḥ||
// 8-95-7 //
この二台の戦車の衝突は、かつてのインドラとヴァイローチャナ（バリ）の戦いのように壮大であった。矢に打たれ、馬と御者の体が傷つき、耐えがたい武器で体を貫かれていた。
prabhūtapadmotpalamatsyakacchapau mahāhadau pakṣigaṇānunāditau|
susannikṛṣṭāvaniloddhatau yathā tathā rathau tau dhvajinau samīyatuḥ||
// 8-95-8 //
蓮や睡蓮、魚や亀が豊かに棲む二つの大きな湖が、鳥の群れの鳴き声に満ち、風に煽られて近づくように、旗を掲げた二台の戦車が激突した。
ubhau mahendrasya samānavikramāvubhau mahendrapratimau mahārathau|
mahendravajrapratimaiśca sāyakairmahendravṛtrāviva samprajaghnatuḥ||
// 8-95-9 //
二人ともマヘーンドラ（インドラ）に等しい武勇を持ち、マヘーンドラに匹敵する大戦車戦士であった。インドラの雷に等しい矢で、インドラとヴリトラのように打ち合った。
sanāgapattyaśvarathe ubhe bale vicitravarmābharaṇāmbarāyudhe|
cakampatuśconnadatuśca vismayāddharā viyaccārjunakarṇasaṅgame||
// 8-95-10 //
象・歩兵・馬・戦車を擁する両軍が、美しい鎧と装飾と衣と武器をまとい、アルジュナとカルナの激突に震え、驚嘆の叫びを上げた。大地も天空も揺れた。
bhujāḥ savastrāṅgulayaḥ samucchritāḥ sasiṃhanādairhṛṣitairdidṛkṣubhiḥ|
yadā'rjunaṃ matta iva dvipo dvipaṃ samabhyayādādhirathirjighāṃsayā||
// 8-95-11 //
衣をまとった腕が高く上がり、獅子の咆哮とともに歓喜して見物する者たちの間から、アルジュナが狂象のように象に向かうように、アディラティ（カルナ）が殺意をもって彼に突進した時、歓声が上がった。
udakrośansomakāstatra pārthaṃ tvarasva yāhyarjuna bhindhi karṇam|
chindhyasya mūrdhānamalaṃ cireṇa śraddhāṃ ca rājyādvṛtarāṣṭrasūnoḥ||
// 8-95-12 //
ソーマカ（パーンダヴァの同盟軍）たちがパールタに叫んだ。「急げ、行け、アルジュナよ、カルナを打ち砕け！ 奴の首を斬り落とせ！ もうたくさんだ！ ドリタラーシュトラの息子から王国への執着を断ち切れ！」
tathā'smākaṃ bahavastatra yodhāḥ karṇaṃ tathā yāhi yāhītyavocan|
jahyarjunaṃ karṇa tataḥ sudīnāḥ punarvanaṃ yāntvacirāya pārthāḥ||
// 8-95-13 //
同じく味方の多くの兵士たちもカルナに叫んだ。「行け、行け！ アルジュナを討て、カルナよ！ そうすれば惨めなパールタたちはすぐにまた森に戻るだろう！」
karṇo'tha pūrvaṃ daśabhiḥ pṛṣatkairgāṇḍīvadhanvānamavidhyadāśu|
jaghāna taṃ cāpi tataḥ kirīṭī śaraistadāṣṭādaśabhiḥ sumuktaiḥ||
// 8-95-14 //
カルナがまず十本の矢でガーンディーヴァの弓の持ち主（アルジュナ）を素早く射た。するとキリーティン（アルジュナ）も十八本の見事に放たれた矢でカルナを射返した。
punaśca karṇastvarito'pi pārthaṃ ratheṣubhistaṃ daśabhirjaghāna|
taṃ cāpi pārtho daśabhiḥ śitāgraiḥ kakṣyāntare tīkṣṇamukhairavidhyat||
// 8-95-15 //
カルナが再び急いでパールタを十本の矢で射ると、パールタもまた鋭い先端を持つ十本の矢で脇腹に射返した。
karṇastato bhārata sāmparāye ghore'tivelaṃ raṇasaṃvimardī|
jaghāna pārthaṃ navabhiḥ śitāgraiḥ kakṣyānte nāgamiva prabhinnam||
// 8-95-16 //
バーラタよ、恐ろしい戦いの中で戦闘の名手カルナが、鋭い先端の九本の矢でパールタを射た。まるで狂象を射るように。
tato'parābhyāṃ yudhi sūtaputro dvābhyāṃ kṣurābhyāṃ harimāśukārī|
samājaghāna tvarayā mahātmā yathā surendraṃ namuciḥ prasahya||
// 8-95-17 //
さらにカルナはカミソリ矢二本でアルジュナの馬を素早く射った。偉大な魂の戦士が急いで放ったその矢は、かつてナムチがインドラ王を力ずくで打ったかのようであった。
taṃ pāṇ़ḍavaḥ pañcabhirāyasāgrairākarṇapūrṇairnijaghāna karṇam|
te śoṇitaṃ tasya papustadānīṃ kālasya dūtā iva pārthabāṇāḥ||
// 8-95-18 //
パーンダヴァ（アルジュナ）は鉄の先端を持つ五本の矢を、耳まで引き絞って放ち、カルナを射た。パールタの矢はその血を飲んだ。まるでカーラ（死神）の使者のように。
karṇo'pi pārthaṃ saha vāsudevaṃ samācinodbhārata vatsadantaiḥ|
parasparaṃ tau viśikhaiḥ pramuktaistatakṣatuḥ sūtaputro'rjunaśca||
// 8-95-19 //
カルナもまたパールタとヴァースデーヴァ（クリシュナ）を仔牛の歯のような細い矢で覆い尽くした。バーラタよ、スータの息子とアルジュナは互いに放たれた矢で切り刻み合った。
parasparaṃ chidradidṛkṣayā ca subhīmamabhyāyayatuḥ praruṣṭau||
// 8-95-20 //
互いの隙を見つけようと、二人は恐ろしく怒りに満ちて迫り合った。
tato'stramāgneyamamitratāpanaṃ mumoca karṇāya sureśvarātmajaḥ|
dhanañjayātsaṃyugamūrdhni niḥsṛtaṃ tadā prajajvāla tadastramuttamam||
samīkṣya karṇo jvalanāstramudyataṃ sa vāruṇaṃ tatpraśamārthamāhave|
samutsṛjatsūtaputraḥ pratāpavān sa tena vahniṃ śamayāñcakāra||
valāhakāstreṇa diśastarasvī cakāra sarvāstimireṇa saṃvṛtāḥ|
apāvahanmeghagaṇāṃstatastān samīraṇāstreṇa samīritena||
// 8-95-21-23 //
そこでインドラの息子（アルジュナ）は敵を焼き尽くす火の武器（アグネーヤストラ）をカルナに放った。ダナンジャヤから戦場の先頭で放たれたその武器は激しく燃え上がった。カルナはその炎の武器が放たれたのを見て、それを鎮めるために水の武器（ヴァールナストラ）を放ち、火を消し止めた。カルナは雲の武器で四方を暗闇で覆った。するとアルジュナは風の武器（ヴァーユストラ）で雲の群れを吹き払った。
tataḥ so'straṃ dayitaṃ devarājñaḥ prāduścakre vajramamitratāpanaḥ|
gāṇḍīvajyā vimṛśaṃścātimanyurdhanañjayaḥ śatrusaṅghapramāthī||
nārācanālīkavarāhakarṇā gāṇḍīvataḥ prādurāsansutīkṣṇāḥ|
sahasraśo vajrasamānavegāste sarvataḥ paryadhāvanta ghorāḥ||
// 8-95-24-25 //
ダナンジャヤは、敵を苦しめるインドラ王のお気に入りの武器、雷の武器を発動させた。ガーンディーヴァの弦に触れながら大いに怒り、敵の群れを砕く者ダナンジャヤは、ガーンディーヴァからナーラーチャ矢、ナーリーカ矢、猪の耳の矢が千本単位で飛び出し、雷のような速度で四方に走り回った。
pārtheṣavaḥ karṇarathaṃ vilagnā adhomukhāḥ pakṣigaṇā dinānte|
niśāniketārthamivāśu vṛkṣaṃ jagrāha tānsūtaputraḥ pṛṣatkaiḥ||
// 8-95-26 //
パールタの矢がカルナの戦車に突き刺さった。日暮れに鳥の群れが素早く木に止まるように。カルナはその矢を自分の矢で受け止めた。
kṣiptāṃstathā pāṇḍavabāṇasaṅghānamṛṣyamāṇasya dhanañjayasya|
raṇājire tvantakatulyakarmā vaikartano roṣaparītacetāḥ||
jyotiṣprabhāṃ yadvadupāgataḥ sandivākaro nāśayate kṣaṇena|
pārthasya tānbāṇagaṇānsamagrānvyanāśayadyudhyata eva karṇaḥ||
// 8-95-27-28 //
ダナンジャヤの放った矢の群れを許せぬカルナ、ヴァイカルタナは怒りに燃えて、死神のような働きをした。太陽が光の群れを近づけて瞬く間に消し去るように、戦いながらカルナはパールタの矢の群れをすべて打ち消した。
roṣātpradīptaḥ sumahāvimarde bhīmastato'krudhyadadīnasatvaḥ|
pāṇiṃ svapāṇau sa viniṣpiṣya roṣādamarṣito vākyamuvāca pārtham||
// 8-95-29 //
怒りに燃えた壮絶な激戦の中で、ビーマが不屈の精神で怒り出した。手を手に打ちつけて怒りに満ち、パールタ（アルジュナ）にこう言った。
tvāṃ sūtaputro nu kathaṃ kirīṭinratheṣubhirhanti śitāgradhāraiḥ|
dhṛtyā hi bhūtāni yayā'jayastvaṃ grāsaṃ dadatkhāṇḍave pāvakāya||
// 8-95-30 //
「キリーティンよ、なぜスータの息子がおまえを鋭い先端の矢で射っているのだ！ あのカーンダヴァの森でアグニ（火神）に食物を与えた時にすべての生きものを征服した、あの勇気はどうしたのだ！」
dhṛtyā tayā sūtaputraṃ jahi tvamahaṃ vainaṃ gadayā pothayiṣye|
sametya pārthaṃ sunṛśaṃsavādī jīvannāyaṃ yāsyati kālapakvaḥ||
// 8-95-31 //
「あの勇気でスータの息子を討て。さもなくば、私が棍棒で奴を叩き潰してやる。パールタに会って残酷な言葉を吐くこの死にかけの男を、生きたまま去らせはしない。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcanavatitamo'dhyāyaḥ|| 95 ||
こうして、聖なる大マハーバーラタのカルナ篇の第95章は終わる。
