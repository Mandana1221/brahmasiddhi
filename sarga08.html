kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

aṣṭamaḥ sargaḥ ― 第八章

天女たちの森の散策と花摘み（1–26）。ガンガーでの水浴（27–57）。韻律は全篇ヴァンシャスタ（Vaṃśastha）、末尾3偈のみ別韻律。
1
Sanskrit
atha svamāyākṛtamandirojjvalaṃ jvalanmaṇi vyomasadāṃ sanātanam / surāṅganā gopaticāpagopuraṃ puraṃ vanānāṃ vijihīrṣayā jahuḥ //
Vaṃśastha
和訳
さて天女たちは、みずからの幻力によって造られた宮殿が輝き、宝石が光り、虹の門をもつ天界の住人たちの永遠の都を、森々で遊ぶ望みをもって後にした。

gopaticāpagopura：gopati（インドラ）の弓（虹）を門楼にもつ、の意。マッリナータはgopatiをインドラと解す。

2
Sanskrit
yathāyathaṃ tāḥ sahitā nabhaścaraiḥ prabhābhir udbhāsitaśailavīrudhaḥ / vanaṃ viśantyo vanajāyatekṣaṇāḥ kṣaṇadyutīnāṃ dadhur ekarūpatām //
Vaṃśastha
和訳
蓮華のごとき長い目をもつ彼女たちが、ガンダルヴァたちとともに順序正しく森に入るとき、その輝きで山の草木を照らしつつ、稲妻と同じ姿をとった。

kṣaṇadyuti：一瞬の輝き、すなわち稲妻。木々の間に現れては消える姿が稲妻に喩えられる。

3
Sanskrit
nivṛttavṛttorupayodharaklamaḥ pravṛttanirhrādivibhūṣaṇāravaḥ / nitambinīnāṃ bhṛśam ādadhe dhṛtiṃ nabhaḥprayāṇād avanau parikramaḥ //
Vaṃśastha
和訳
豊かな胸の疲れも消え、足飾りが朗々と鳴り始めた。地上を歩き回ることは、空の旅よりも、豊かな腰をもつ女たちに大きな喜びをもたらした。
4
Sanskrit
ghanāni kāmaṃ kusumāni bibhrataḥ karapraceyāny apahāya śākhinaḥ / puro 'bhisasre surasundarījanair yathottarecchā hi guṇeṣu kāminaḥ //
Vaṃśastha
和訳
樹々はたしかに密に、手で摘める花を咲かせていたが、天女たちはそれらを後にしてなお先へ進んだ。よきものを求める者はつねに、より多くを望むものだから。
5
Sanskrit
tanūr alaktāruṇapāṇipallavāḥ sphurannakhāṃśūtkaramañjarībhṛtaḥ / vilāsinībāhulatā vanālayo vilepanāmodahṛtāḥ siṣevire //
Vaṃśastha
和訳
紅漆で赤く染めた手の蕾のような指をもち、輝く爪の光が花束の束のようである美女たちの腕の蔓に、塗香の芳しさに惹かれた森の蜂たちが寄り集まった。

女性の腕を蔓（latā）に、指を蕾（pallava）に、爪の光を花房（mañjarī）に見立てる連続比喩（rūpaka）。

6
Sanskrit
nipīyamānastabakā śilīmukhair aśokayaṣṭiś calabālapallavā / viḍambayantī dadṛśe vadhūjanair amandadaṣṭauṣṭhakarāvadhūnanam //
Vaṃśastha
和訳
蜂に花房を吸われ、若い蕾が揺れるアショーカの枝は、女たちが激しく唇を噛んで手を振る仕草を真似ているように見えた。

aśoka（無憂樹、Jonesia Asoka）：鮮やかな赤い花をつける木で、詩人に多く歌われる。蜂が花を吸うさまを唇を噛む仕草に、若葉の揺れを手を振る動作に見立てる（samāsokti）。

7
ある者が蜂に悩む女に語る
Sanskrit
karau dhunānā navapallavākṛtī vṛthā kṛthā mānini mā pariśramam / upeyuṣī kalpalatābhiśaṅkayā kathaṃ nv itas trasyati ṣaṭpadāvaliḥ //
Vaṃśastha
和訳
「気位の高き人よ、若葉のような両手をいくら振っても無駄。如意蔓と見紛うて寄って来た蜂の群れが、どうしてそれしきで怯えようか。」

kalpalatā（如意蔓）：望みをすべて叶えるという伝説の蔓草。蜂は彼女の腕を如意蔓と思い込んだのだから恐れないという理屈。

8
女友達が恋に怒る女に語る
Sanskrit
jahīhi kopaṃ dayito 'nugamyatāṃ purānuśete tava cañcalaṃ manaḥ / iti priyaṃ kāṃcid upaitum icchatīṃ puro 'nuninye nipuṇaḥ sakhījanaḥ //
Vaṃśastha
和訳
「怒りを捨てて、恋人のもとへ行きなさい。さもなくば、あなたの移り気な心がやがて後悔するでしょう」——こう言って、機転の利く女友達が、すでに自ら恋人のもとへ行こうとしていた彼女をまず諭した。
9
Sanskrit
samunnataiḥ kāśadukūlaśālibhiḥ parikvaṇatsārasapaṅktimekhalaiḥ / pratīradeśaiḥ svakalatracārubhir vibhūṣitāḥ kuñjasamudrayoṣitaḥ //
Vaṃśastha
和訳
カーシャ草が絹のように輝き、鳴きさわぐ鶴の列が腰帯のような、自らの腰辺のように美しい高い岸辺に飾られた森の川たち——

9–12偈は一連の構文（kalāpaka）。川を女性に喩え、岸辺を腰に、カーシャ草を衣に、鶴の列を腰帯に見立てる。kalatraは「腰」と「妻」の両義。

10
Sanskrit
vidūrapātena bhidām upeyuṣaś cyutāḥ pravāhād abhitaḥ prasāriṇaḥ / priyāṅkaśītāḥ śucimauktikatviṣo vanaprahāsā iva vāribindavaḥ //
Vaṃśastha
和訳
高所から落ちて水流が割れ、四方に飛び散る水滴は、恋人の膝のように冷たく、清らかな真珠のような輝きをもち、森の笑い声のようであった。
11
Sanskrit
sakhījanaṃ prema gurūkṛtādaraṃ nirīkṣamāṇā iva namramūrtayaḥ / sthiradvirephāñjanaśāritodarair visāribhiḥ puṣpavilocanair latāḥ //
Vaṃśastha
和訳
身を傾けた蔓草は、じっと留まる蜂という墨で内側を斑に彩られた花の目を大きく開いて、愛情ゆえにいっそう敬意を深めて女友達を見つめているかのようであった。
12
Sanskrit
upeyuṣīṇāṃ bṛhatīr adhityakā manāṃsi jahruḥ surarājayoṣitām / kapolakāṣaiḥ kariṇāṃ madāruṇair upāhitaśyāmarucaś ca candanāḥ //
Vaṃśastha
和訳
広い高台に上った天帝の妃たちの心を奪ったのは、象が頬を擦りつけて発情液で赤く染め、暗い光沢を帯びた白檀の木々であった。

9偈からのkalāpakaがここで結ばれる。主動詞はjahruḥ（奪った）。川、水滴、蔓草、白檀が主語群。

13
Sanskrit
svagocare saty api vittahāriṇā vilobhyamānāḥ prasavena śākhinām / nabhaścarāṇām upakartum icchatāṃ priyāṇi cakruḥ praṇayena yoṣitaḥ //
Vaṃśastha
和訳
自分の手の届く花があるにもかかわらず、心を奪う木の花に誘われて、女たちは親しみをもって、奉仕を望むガンダルヴァたちに花を摘ませる喜びを与えた。
14
Sanskrit
prayacchatoccaiḥ kusumāni māninī vipakṣagotraṃ dayitena lambhitā / na kiṃcid ūce caraṇena kevalaṃ lilekha bāṣpākulalocanā bhuvam //
Vaṃśastha
和訳
高い枝の花を摘んで手渡しながら、恋人がうっかり競妻の名を口にしたとき、誇り高い女は何も言わず、ただ涙に曇った目で、足先で地面を引っ掻いた。
15
Sanskrit
priye 'parā yacchati vācam unmukhī nibaddhadṛṣṭiḥ śithilākuloccayā / samādadhe nāṃśukam āhitaṃ vṛthā viveda puṣpeṣu na pāṇipallavam //
Vaṃśastha
和訳
もう一人の女は、語りかける恋人に面を上げて視線を注いでいたが、帯の結び目が緩んで乱れても衣を直さず、うわの空で花のなかに手を差し入れてそれと気づかなかった。
16
Sanskrit
salīlam āsaktalatāntabhūṣaṇaṃ samāsajantyā kusumāvataṃsakam / stanopapīḍaṃ nunude nitambinā ghanena kaścij jaghanena kāntayā //
Vaṃśastha
和訳
蔓の先の飾りを絡ませた花の耳飾りを戯れにつけながら、ある美女は豊かな臀部で男を胸のところに押しやった。
17
Sanskrit
kalatrabhāreṇa vilolanīvinā galaddukūlastanaśālinorasā / balivyapāyasphuṭaromarājinā nirāyatatvād udareṇa tāmyatā //
Vaṃśastha
和訳
腰の重みで帯紐が揺れ、胸から絹が滑り落ち、伸びた姿勢のために腹の皺が消えて毛筋が露わになった体——

17–18偈は一続き。女性美の伝統的描写：bali（腹の皺）が消えromarāji（毛筋）が現れるのは、手を伸ばす動作による。

18
Sanskrit
vilambamānākulakeśapāśayā kayācid āviṣkṛtabāhumūlayā / taruprasūnāny apadiśya sādaraṃ manodhināthasya manaḥ samādade //
Vaṃśastha
和訳
——乱れた髪を垂らし、腋を見せつつ、花を摘むふりをして、ある女は心の主（恋人）の心を奪った。
19
Sanskrit
vyapohituṃ locanato mukhānilair apārayantaṃ kila puṣpajaṃ rajaḥ / payodhareṇorasi kācid unmanāḥ priyaṃ jaghānonnatapīvarastanī //
Vaṃśastha
和訳
口の息では目から花粉を吹き払えないでいる恋人を、ある高く豊かな乳房をもつ女が心を昂らせ、胸で恋人の胸を打った。
20
Sanskrit
imāny amūnīty apavarjite śanair yathābhirāmaṃ kusumāgrapallave / vihāya niḥsāratayeva bhūruhān padaṃ vanaśrīr vanitāsu saṃdadhe //
Vaṃśastha
和訳
「こちらの花を、次はあちらの花を」と心ゆくまま花と蕾が少しずつ摘まれると、森の美は樹々をまるで無価値になったかのように去り、女たちの上に宿った。
21
Sanskrit
pravālabhaṅgāruṇapāṇipallavaḥ parāgapāṇḍūkṛtapīvarastanaḥ / mahīruhaḥ puṣpasugandhir ādade vapurguṇocchrāyam ivāṅganājanaḥ //
Vaṃśastha
和訳
嫩枝を折って指先を赤く染め、花粉で豊かな胸を黄白く染めた女たちの群れは、花の香りに満たされ、樹々からさらなる体の美しさを得たかのようであった。
22
Sanskrit
varorubhir vāraṇahastapīvaraiś cirāya khinnān navapallavaśriyaḥ / same 'pi yātuṃ caraṇān anīśvarān madād iva praskhalataḥ pade pade //
Vaṃśastha
和訳
象の鼻のように太い美しい太腿に長く疲れ、若芽のように美しい足は平らな地面でさえ歩むことができず、一歩ごとに酔ったようによろめいた。
23
Sanskrit
visārikāñcīmaṇiraśmilabdhayā manoharocchāyanitambaśobhayā / sthitāni jitvā navasaikatadyutiṃ śramātiriktair jaghanāni gauravaiḥ //
Vaṃśastha
和訳
溢れ出る腰帯の宝石の光がもたらす、心を奪う丸みの輝きをもつ臀部は、疲れによっていっそう増した重さで、新しい砂洲の輝きさえも凌いだ。
24
Sanskrit
samucchvasatpaṅkajakośakomalair upāhitaśrīṇy upanīvi nābhibhiḥ / dadhanti madhyeṣu valīvibhaṅgiṣu stanātibhārād udarāṇi namratām //
Vaṃśastha
和訳
膨らむ蓮の莟のように柔らかい臍に、帯の下に美しさを加えられた腹部は、皺の波打つ中央で、乳房の過重のためにしなっていた。
25
Sanskrit
samānakāntīni tuṣārabhūṣaṇaiḥ saroruhair asphuṭapattrapaṅktibhiḥ / citāni gharmāmbukaṇaiḥ samantato mukhāny anutphullavilocanāni ca //
Vaṃśastha
和訳
そして、まだ開かぬ花弁をもつ蓮華と同じ輝きをもつ、一面に汗の雫で覆われた顔々と、まだ十分に開かぬ目——

22–26偈は一連の構文。足、臀部、腹、顔を順に描写し、26偈で結ぶ。汗の雫を露に、半開きの目を蓮の蕾に喩える。

26
Sanskrit
viniryatīnāṃ gurukhedamantharaṃ surāṅganānām anusānuvartmanaḥ / savismayaṃ rūpayato nabhaścarān viveśa tatpūrvam ivekṣaṇādaraḥ //
Vaṃśastha
和訳
高台の道からひどい疲れにゆるやかな足取りで降りてくる天女たちを驚きのまなざしで見つめるガンダルヴァたちの目に、生まれてはじめてのような熱いまなざしが宿った。

カッペラーは、ガンダルヴァたちは通常は図々しく好色であるが（サテュロスやファウヌスに比される）、ここでは初めて畏敬の念をいだいたと注す。

27
Sanskrit
atha sphuranmīnavidhūtapaṅkajā vipaṅkatīraskhalitormisaṃhatiḥ / payo 'vagāḍhuṃ kalahaṃsanādinī samājuhāveva vadhūḥ surāpagā //
Vaṃśastha
和訳
さて天の河は、跳ねる魚に揺らされる蓮華をもち、泥のない岸に波の群れが砕け、鳥たちの鳴き声を響かせつつ、花嫁のように女たちを水に招くかのようであった。
28
Sanskrit
praśāntagharmābhibhavaḥ śanair vivān vilāsinībhyaḥ parimṛṣṭapaṅkajaḥ / dadau bhujālambam ivāttaśīkaras taraṅgamālāntaragocaro 'nilaḥ //
Vaṃśastha
和訳
暑気の苦しみを鎮め、蓮華に触れつつ静かに吹き、波間を抜けて水飛沫を帯びた風は、美女たちに腕の支えを差し出すかのようであった。
29
Sanskrit
gataiḥ sahāvaiḥ kalahaṃsavikramaṃ kalatrabhāraiḥ pulinaṃ nitambibhiḥ / mukhaiḥ sarojāni ca dīrghalocanaiḥ surastriyaḥ sāmyaguṇān nirāsire //
Vaṃśastha
和訳
天女たちは、優美な歩みで白鳥の歩みを、重い腰で砂洲を、長い目の顔で蓮華を——同等の美質を共有していながらも——遥かに凌いだ。
30
Sanskrit
vibhinnaparyantagamīnapaṅktayaḥ puro vigāḍhāḥ sakhibhir marutvataḥ / kathaṃcid āpaḥ surasundarījanaiḥ sabhītibhis tatprathamaṃ prapedire //
Vaṃśastha
和訳
岸辺で魚の群れが散り散りになる中、インドラの友であるガンダルヴァたちがまず先に入った水に、怯える天の美女たちは初めておずおずと足を踏み入れた。
31
Sanskrit
vigāḍhamātre ramaṇībhir ambhasi prayatnasaṃvāhitapīvarorubhiḥ / vibhidyamānā visasāra sārasān udasya tīreṣu taraṅgasaṃhatiḥ //
Vaṃśastha
和訳
美女たちが苦心して豊かな太腿を押しつけながら水に身を沈めた途端、波は裂けて岸の鶴を追い立てつつ溢れ出した。
32
Sanskrit
śilāghanair nākasadām uraḥsthalair bṛhanniveśaiś ca vadhūpayodharaiḥ / taṭābhinītena vibhinnavīcinā ruṣeva bheje kaluṣatvam ambhasā //
Vaṃśastha
和訳
天の住人たちの岩のごとき厚い胸板と、女たちの大きく張り出した乳房によって岸に押しやられ、渦巻いた波とともに、水はまるで怒ったかのように濁った。
33
Sanskrit
vidhūtakeśāḥ parilolitasrajaḥ surāṅganānāṃ praviluptacandanāḥ / atiprasaṅgād vihitāgaso muhuḥ prakampam īyuḥ sabhayā ivormayaḥ //
Vaṃśastha
和訳
天女たちの髪を乱し、花輪をもてあそび、白檀の塗香を洗い流した波は、度重なる狼藉を犯したのち、おびえたかのように震え始めた。
34
Sanskrit
vipakṣacittonmathanā nakhavraṇās tirohitā vibhramamaṇḍanena ye / hṛtasya śeṣān iva kuṅkumasya tān vikatthanīyān dadhur anyathā striyaḥ //
Vaṃśastha
和訳
競妻の心を掻き乱す爪痕を、普段は艶めかしい装飾で隠していた女たちは、今やそれを洗い落とされた紅の残りであるかのように、誇らしげにまったく別のやり方で見せつけた。

爪痕（nakhavraṇa）は情事の激しさの証。普段は化粧で隠すが、水浴で化粧が落ちた今、洗い落とされた紅の痕と装って見せびらかす。41偈とも呼応。

35
Sanskrit
sarojapattre nu vilīnaṣaṭpade viloladṛṣṭeḥ svid amū vilocane / śiroruhāḥ svin natapakṣmasantater dvirephavṛndaṃ nu niśabdaniścalam //
Vaṃśastha
和訳
「蜂がとまった蓮の花弁か、それとも眼差しの揺れるあの人の目なのか。垂れ下がる睫毛の生えそろった髪か、それとも音もなく静かに留まる蜂の群れなのか。」
36
Sanskrit
agūḍhahāsasphuṭadantakesaraṃ mukhaṃ svid etad vikasan nu paṅkajam / iti pralīnāṃ nalinīvane sakhīṃ vidāṃbabhūvuḥ sucireṇa yoṣitaḥ //
Vaṃśastha
和訳
「隠しきれない微笑みに歯の花蕊が輝くあれは顔なのか、それとも咲き開く蓮華なのか。」——こうして女たちは蓮の茂みに隠れた友をようやく見つけ出した。

35–36偈はsaṃśaya（疑惑）の修辞法。蓮池に身を潜めた女と蓮花の区別がつかない趣向。

37
Sanskrit
priyeṇa saṃgrathya vipakṣasaṃnidhāv upāhitāṃ vakṣasi pīvarastane / srajaṃ na kācid vijahau jalāvilāṃ vasanti hi premṇi guṇā na vastuni //
Vaṃśastha
和訳
恋人が編んで競妻の前で豊かな胸に掛けてくれた花輪を、水に濡れても誰一人として捨てなかった。価値は物ではなく、愛情のなかにあるのだから。
38
Sanskrit
asaṃśayaṃ nyastam upāntaraktatāṃ yad eva roddhuṃ ramaṇībhir añjanam / hṛte 'pi tasmin salilena śuklatāṃ nirāsa rāgo nayaneṣu na śriyam //
Vaṃśastha
和訳
たしかに、目尻の赤みを抑えるために美女たちが塗った墨も水に流された。しかし目の赤み（情熱）は白さを消したが、美しさは失われなかった。

rāgaは「赤み」と「情熱」の二義。墨が落ちると目は赤くなるが（水浴の興奮による）、それが逆に美を増す。

39
Sanskrit
dyutiṃ vahanto vanitāvataṃsakā hṛtāḥ pralobhād iva vegibhir jalaiḥ / upaplutās tatkṣaṇaśocanīyatāṃ cyutādhikārāḥ sacivā ivāyayuḥ //
Vaṃśastha
和訳
輝きを放つ女たちの花飾りは、急流に貪欲にさらわれ、落ちた途端に哀れなものとなった——ちょうど職を解かれた大臣のように。
40
Sanskrit
vipattralekhā niralaktakādharā nirañjanākṣīr api bibhratīḥ śriyam / nirīkṣya rāmā bubudhe nabhaścarair alaṃkṛtaṃ tadvapuṣaiva maṇḍanam //
Vaṃśastha
和訳
額飾りもなく、唇の紅もなく、目の墨もない女たちがなお美しさを湛えているのを見て、ガンダルヴァたちは悟った——装身具こそが彼女たちの体によって飾られているのだと。
41
Sanskrit
tathā na pūrvaṃ kṛtabhūṣaṇādaraḥ priyānurāgeṇa vilāsinījanaḥ / yathā jalārdro nakhamaṇḍanaśriyā dadāha dṛṣṭīś ca vipakṣayoṣitām //
Vaṃśastha
和訳
恋人への愛情から飾りに心を砕いていた以前よりも、水に濡れた今の方が、爪痕の飾りの美しさで競妻たちの目をいっそう焼いた。
42
Sanskrit
śubhānanāḥ sāmburuheṣu bhīravo vilolahārāś calaphenapaṅktiṣu / nitāntagauryo hṛtakuṅkumeṣv alaṃ na lebhire tāḥ parabhāgam ūrmiṣu //
Vaṃśastha
和訳
美しい顔は蓮の咲く水面に、揺れる真珠の首飾りは泡の列に、きわめて白い肌は紅を流された波に紛れ、臆病な天女たちは波の中で際立つことができなかった。
43
Sanskrit
hradāmbhasi vyastavadhūkarāhate ravaṃ mṛdaṅgadhvanidhīram ujjhati / muhuḥ stanais tālasamaṃ samādade manoramaṃ nṛtyam iva pravepitam //
Vaṃśastha
和訳
淵の水が女たちの交互に打つ手に太鼓のような低い音を響かせると、絶え間ない胸の揺れが拍子に合わせて、あたかも美しい舞踊のように震えた。
44
Sanskrit
śriyā hasadbhiḥ kamalāni sasmitair alaṃkṛtāmbuḥ pratimāgatair mukhaiḥ / kṛtānukūlyā surarājayoṣitāṃ prasādasāphalyam avāpa jāhnavī //
Vaṃśastha
和訳
ガンガーは、天帝の妃たちに恩恵を施した。その水面に映る微笑んだ顔は美しさで蓮華を恥じ入らせ、好意を返した妃たちによって、その親切の報いを得たのだ。
45
Sanskrit
parisphuranmīnavighaṭṭitoravaḥ surāṅganās trāsaviloladṛṣṭayaḥ / upāyayuḥ kampitapāṇipallavāḥ sakhījanasyāpi vilokanīyatām //
Vaṃśastha
和訳
跳ねる魚に触れて声をあげ、恐怖に目を泳がせ、花のような手を震わせた天女たちは、女友達にとってさえ見惚れるほどの美しさとなった。
46
Sanskrit
bhayād ivāśliṣya jhaṣāhate 'mbhasi priyaṃ mudānandayati sma māninī / akṛtrimapremarasāhitair mano haranti rāmāḥ kṛtakair apīhitaiḥ //
Vaṃśastha
和訳
魚に叩かれた水中で恐怖を装い恋人を抱きしめ喜ばせた気位の高い女——美女たちは作り事の振舞いでさえ、真の愛情の味わいを帯びていれば心を奪うのだ。
47
Sanskrit
tirohitāntāni nitāntam ākulair apāṃ vigāhād alakaiḥ prasāribhiḥ / yayur vadhūnāṃ vadanāni tulyatāṃ dvirephavṛndāntaritaiḥ saroruhaiḥ //
Vaṃśastha
和訳
水に潜って乱れ広がった髪に端を覆われた女たちの顔は、蜂の群れに半ば隠された蓮華と同じ姿に見えた。
48
Sanskrit
karau dhunānā navapallavākṛtī payasy agādhe kila jātasambhramā / sakhīṣu nirvācyam adhārṣṭyadūṣitaṃ priyāṅgasaṃśleṣam avāpa māninī //
Vaṃśastha
和訳
若葉のような手を振りながら深い水に慌てたふりをして、気位の高い女は、友人たちのあいだでも非難されず、慎み深さを損なわぬかたちで恋人の肌に抱きついた。
49
Sanskrit
priyaiḥ salīlaṃ karavārivāritaḥ pravṛddhaniḥśvāsavikampitastanaḥ / savibhramādhūtakarāgrapallavo yathārthatām āpa vilāsinījanaḥ //
Vaṃśastha
和訳
恋人たちに戯れに手で水を掛けられて退けられ、深い溜息で胸を波立たせ、戸惑いに指先を震わせた女たちは、まさに「ヴィラーシニー」（戯れる女）の名にふさわしかった。

vilāsinīは「戯れる女」と「美女」の二義。カッペラーはこの掛詞を「trug die Schaar der Frauen ihren Namen mit Recht」と訳す。

50
Sanskrit
udasya dhairyaṃ dayitena sādaraṃ prasāditāyāḥ karavārivāritam / mukhaṃ nimīlannayanaṃ natabhruvaḥ śriyaṃ sapatnīvadanād ivādade //
Vaṃśastha
和訳
恋人が手の水で優しくなだめると、意地を捨てた眉の垂れた女の目を閉じた顔は、まるで競妻の顔から美しさを奪い取ったかのようであった。
51
Sanskrit
vihasya pāṇau vidhṛte dhṛtāmbhasi priyeṇa vadhvā madanārdracetasaḥ / sakhīva kāñcī payasā ghanīkṛtā babhāra vītoccayabandham aṃśukam //
Vaṃśastha
和訳
恋人が笑いながら水を持った女の手を掴んだとき、愛欲に潤んだ心の花嫁の、水で固くなった腰帯が友のように、結び目が解けた衣を支えて落とさなかった。
52
Sanskrit
nirañjane sācivilokitaṃ dṛśāv ayāvakaṃ vepathur oṣṭhapallavam / natabhruvo maṇḍayati sma vigrahe balikriyā cātilakaṃ tadāspadam //
Vaṃśastha
和訳
墨のない目を横目遣いが飾り、紅のない唇を震えが飾り、額印のない額を眉のひそめが飾った——その体は化粧なくして化粧の場であった。
53
Sanskrit
nimīladākekaralolacakṣuṣāṃ priyopakaṇṭhaṃ kṛtagātravepathuḥ / nimajjatīnāṃ śvasitoddhatastanaḥ śramo nu tāsāṃ madano nu paprathe //
Vaṃśastha
和訳
目を閉じかけて横目で見つめ、恋人の傍らで体を震わせ、水に沈みつつ溜息で胸を波立たせる彼女たち——それは疲労なのか、それとも恋情なのか。
54
Sanskrit
priyeṇa siktā caramaṃ vipakṣataś cukopa kācin na tutoṣa sāntvanaiḥ / janasya rūḍhapraṇayasya cetasaḥ kim apy amarṣo 'nunaye bhṛśāyate //
Vaṃśastha
和訳
競妻より後に恋人に水を掛けられた女は怒り、なだめの言葉でも機嫌を直さなかった。深く愛し合う者の心には、宥められるほどに怒りはいっそう募るのだ。
55
Sanskrit
itthaṃ vihṛtya vanitābhir udasyamānaṃ pīnastanorujaghanasthalaśālinībhiḥ / utsarpitormicayalaṅghitatīradeśam autsukyanunnam iva vāri puraḥ pratasthe //
Vasantatilakā
和訳
かくして、豊かな胸、太腿、臀部をもつ女たちの遊びに掻き乱された水は、高まる波の群れが岸を越え、みずからも焦がれるかのように先へ先へと流れ去った。
56
Sanskrit
tīrāntarāṇi mithunāni rathāṅganāmnāṃ nītvā vilolitasarojavanaśriyas tāḥ / saṃrejire surasarijjaladhautahārās tārāvitānataralā iva yāmavatyaḥ //
Vasantatilakā
和訳
鴛鴦の番いを対岸へ追いやり、蓮の群落の美を乱した女たちは、天の河の水で洗われた真珠の首飾りを光らせ、きらめく星空のもとの夜のように輝いた。

rathāṅganāman：チャクラヴァーカ鳥（鴛鴦の一種）。yāmavatī（夜）に喩える——水で洗われた首飾りの真珠が星のように瞬く。

57
Sanskrit
saṃkrāntacandanarasāhitavarṇabhedaṃ vicchinnabhūṣaṇamaṇiprakarāṃśucitram / baddhormi nākavanitāparibhuktamuktaṃ sindhor babhāra salilaṃ śayanīyalakṣmīm //
Vasantatilakā
和訳
白檀の液を吸い込んで色を変え、砕けた装身具の宝石の光に彩られ、波立つ河の水は、天女たちが浴びて去った後、閨房の褥の美しさを湛えていた。

śayanīyalakṣmī：褥・臥床の美。水浴後の水面が白檀と宝石で彩られ、愛の床のように見えるという比喩で章を結ぶ。

iti bhāravikṛtau mahākāvye kirātārjunīye aṣṭamaḥ sargaḥ //
バーラヴィ作『キラータールジュニーヤ』第八章 終
