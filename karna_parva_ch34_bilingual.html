マハーバーラタ ― カルナ篇 第34章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 34 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ34」（前章でのシャリヤの罵倒に対し、カルナがシャリヤの弱点を徹底的に暴き立てて反論する場面。アルジュナ・クリシュナへの恐れなき自信を述べた後、マドラ国の民の不品行・不貞・不浄を縷々非難し、戦場で名誉の死を選ぶ覚悟と、シャリヤへの最終的な威嚇を語ります）です。各段落は原典の詩節番号（8-34-N）と和訳の段落番号が対応していますが、和訳第21段落のみ原典の21節と22節を統合しているため、それ以降は和訳の段落番号より原典の詩節番号が1つ大きくなります（例：和訳第56段落＝原典第57詩節）。表示する詩節番号は常に原典の正しい番号です。
karṇaparva — catustriṃśo'dhyāyaḥ (34)
第34章
sañjaya uvāca|
adhikṣiptastu rādheyaḥ śalyenāmitatejasā|
śalyamāha susaṅkruddho vākśalyam avadhārayan|| // 8-34-1 //
サンジャヤは語った。 （1）無限の光輝をもつシャルヤに辱められたカルナは、大いに怒ってシャルヤに言った。言葉の矢を深く胸に受けとめながら。
karṇa uvāca|
guṇān guṇavatāṃ śalya guṇavān vetti na aguṇaḥ|
tvaṃ tu nityaṃ guṇair hīnaḥ kiṃ jñāsyasi guṇāguṇān|| // 8-34-2 //
カルナは語った。 （2）「シャルヤよ、徳ある者の徳を、徳ある者こそが知るのであって、徳なき者には分からぬ。お前は常に徳を欠いている。どうして徳と不徳が分かろうか。
arjunasya mahāstrāṇi krodhaṃ vīryaṃ dhanuḥ śarān|
ahaṃ śalya abhijānāmi na tvaṃ jānāsi tat tathā|| // 8-34-3 //
（3）アルジュナの偉大な武器、怒り、武勇、弓、矢――シャルヤよ、私はこれらを知っている。お前はそのようには知らぬ。
tathā kṛṣṇasya māhātmyamṛṣabhasya mahīkṣitām|
yathā ahaṃ śalya jānāmi na tvaṃ jānāsi tat tathā|| // 8-34-4 //
（4）王たちの雄牛であるクリシュナの偉大さを、私が知っているようには、お前は知らぬ、シャルヤよ。
evam eva ātmano vīryam ahaṃ vīryaṃ ca pāṇḍave|
jānaṃs tāv āhvaye yuddhe śalya na agniṃ pataṅgavat|| // 8-34-5 //
（5）自分の力と、パーンダヴァ（アルジュナ）の力を知ったうえで、私はアルジュナを戦いに呼ぶのだ。火に飛び込む虫のようにではない、シャルヤよ。
asti cā'yam iṣuḥ śalya supuṅkho raktabhojanaḥ|
ekas tūṇīśayaḥ patrī sudhautaḥ samalaṅkṛtaḥ|| // 8-34-6 //
（6）私には、シャルヤよ、この矢がある――よい羽根、血を食らい、矢筒の中に一本だけ寝かせてある、よく磨かれ、美しく飾られた――。
śete candanacūrṇena pūjito bahulāḥ samāḥ|
āheyo viṣavān ugro narāśvadvipasaṅghahā|| // 8-34-7 //
（7）白檀の粉の上で、崇められながら多年にわたり寝かされた、蛇のように毒を持つ、激しい、人・馬・象をまとめて討つ――。
ghorarūpo mahāraudras tanutrāsthividāraṇaḥ|
nirbhindyāṃ yena ruṣṭo'ham api meruṃ mahāgirim|| // 8-34-8 //
（8）恐ろしい姿の、きわめて凶暴な、鎧と骨を切り裂く――怒った私はこれをもってメール山をも貫くことができる。
tam ahaṃ jātu nāsyeyamanyasmin phalgunād ṛte|
kṛṣṇād vā devakīputrāt satyaṃ ca api śṛṇuṣva me|| // 8-34-9 //
（9）この矢を、アルジュナか、デーヴァキーの子クリシュナ以外には、決して放つまい。真実を聞いてほしい、シャルヤよ。
tena aham iṣuṇā śalya vāsudevadhanañjayau|
yotsye paramasaṃrabdhau tatkarma sadṛśaṃ mama|| // 8-34-10 //
（10）シャルヤよ、この矢で、激しく怒るヴァースデーヴァ（クリシュナ）とアルジュナと戦う。その働きは、私にふさわしいものだ。
sarveṣāṃ vṛṣṇivīrāṇāṃ kṛṣṇe lakṣmīḥ pratiṣṭhitā|
sarveṣāṃ pāṇḍuputrāṇāṃ jayaḥ pārthe pratiṣṭhitaḥ|
ubhayaṃ tu samāsādya ko nivartitum arhati|| // 8-34-11 //
（11）すべてのヴリシュニ族の勇者の中で、吉祥の女神ラクシュミーはクリシュナにあり、すべてのパーンドゥの子たちの中で、勝利はアルジュナにある。両者を合わせて迎え撃つ――それを退けられる者が、誰かいようか。
tāvetau puruṣavyāghrau sametau syandane sthitau|
mām ekam abhisaṃyuddhau sujātaṃ paśya śalya me|| // 8-34-12 //
（12）人中の虎なるこの二人が戦車に共に立ち、ただ一人の私と戦う――そのよき誕生を見よ、シャルヤよ。
pitṛṣvasāmātulajau bhrātarāvaparājitau|
maṇī sūtra iva protau draṣṭāsi nihatau mayā|| // 8-34-13 //
（13）父方と母方のいとこであり、無敗の兄弟である二人を、糸で連ねた宝石のように、私が討ち取るのを見ることになろう。
arjune gāṇḍivaṃ kṛṣṇe cakraṃ tārkṣyakapidhvajau|
bhīrūṇāṃ trāsajananaṃ śalya harṣakaraṃ mama|| // 8-34-14 //
（14）アルジュナにはガーンディーヴァ弓があり、クリシュナにはチャクラ（円盤）がある。ターキシャ（ガルダ）と猿の旗がある。臆病者には恐怖を与えるが、シャルヤよ、私には喜びを与える。
tvaṃ tu duṣprakṛtir mūḍho mahāyuddheṣv akovidaḥ|
bhayāvadīrṇaḥ santrāsād abaddhaṃ bahuḥ bhāṣase|| // 8-34-15 //
（15）お前は性質の悪い愚か者で、大戦について無知で、恐怖に打ち砕かれて、恐怖のあまりに支離滅裂に多くを語っている。
saṃstauṣi tau tu kena api hetunā tvaṃ kudeśaja|
tau hatvā samare hantā tvām adya saha bāndhavam|| // 8-34-16 //
（16）何らかの理由で二人を褒めそやしているが、悪しき国の者よ。今日戦場で二人を討ち、ついでお前とその仲間たちを討ち取ろう。
pāpadeśaja durbuddhe kṣudra kṣatriyapāṃsana|
suhṛdrūpo ripuḥ kiṃ māṃ kṛṣṇābhyāṃ bhīṣayiṣyasi|| // 8-34-17 //
（17）悪しき国の生まれの愚か者よ、卑しく、クシャトリヤの恥よ。友の姿をしながら敵であるお前は、なぜ二人のクリシュナで私を脅そうとするのか。
tau vā mām adya hantārau haniṣye vā'pi tāv aham|
na ahaṃ bibhemi kṛṣṇābhyāṃ vijānan ātmano balam|| // 8-34-18 //
（18）二人が今日私を討つか、さもなくば私が二人を討つか。私は二人のクリシュナを恐れぬ。自分の力を知っているのだから。
vāsudevasahasraṃ vā phalgunānāṃ śatāni vā|
aham eko haniṣyāmi joṣam āssva kudeśaja|| // 8-34-19 //
（19）千人のヴァースデーヴァがいようと、百人のアルジュナがいようと、私ただ一人で討ち取ろう。黙っていろ、悪しき国の者よ。
striyo bālāś ca vṛddhāś ca prāyaḥ krīḍāgatā janāḥ|| // 8-34-20 //
（20）女、子ども、老人、遊び興じる者たちが――。
yā gāthāḥ sampragāyanti kurvato'dhyayanaṃ yathā|
tā gāthāḥ śṛṇu me śalya madrakeṣu durātmasu||
brāhmaṇaiḥ kathitāḥ pūrvaṃ yathāvad rājasannidhau|
śrutvā ca ekamanā mūḍha mama vā brūhi ca uttaram|| // 8-34-21-22 //
（21）読習するように、いつも歌いならしている歌がある。シャルヤよ、その歌を聞け。邪悪なマドラ族について、王の御前でバラモンたちが昔語ったものを、よくよく聞け、愚か者よ、そして答えるがよい。
mitradhruṅ madrako nityaṃ yo no dveṣṭi sa madrakaḥ|
madrake saṅgataṃ nāsti kṣudravākye narādhame|| // 8-34-23 //
（22）〔続けてカルナは、民衆が歌う歌を引用する〕『マドラカ族はいつも友を裏切る。我らを憎む者はマドラカ族である。マドラカ族には信じられるものがない。低俗な言葉を発する、人中の最低者は』――。
durātmā madrako nityaṃ nityam ānṛtiko'nṛjuḥ|
yac ca anyad api daurātmyaṃ madrakeṣv iti naḥ śrutam|| // 8-34-24 //
（23）『マドラカ族はいつも邪悪で、常に虚言を発し、曲っている。他の邪悪さも、マドラカ族の中にあると我らは聞いた。
pitā putraś ca mātā ca śvaśrūśvaśuramātulāḥ|
bhaginī duhitā bhrātā naptā'nye te ca bāndhavāḥ|| // 8-34-25 //
（24）父、息子、母、義母、義父、叔父、姉妹、娘、兄弟、孫、そしてその他の親族――。
vayasyābhyāgatāś ca anye dāsīdāsāś ca saṅgatāḥ|
pumbhir vimiśrā nāryaś ca jñātājñātāḥ svayecchayā|| // 8-34-26 //
（25）他の友人たち、訪れた客、奴隷の男女、女性たちが男たちと入り乱れ、知り合い・見知らぬ者が思いのままに――。
yeṣāṃ gṛheṣv aśiṣṭānāṃ saktumadyāśināṃ sadā|
pītvā śīdhu sagomāṃsaṃ krandanti ca hasanti ca|| // 8-34-27 //
（26）修養のない者たちの家では、常に炒り麦を食らい、サトウキビの酒と牛肉を共に飲み食いし、叫んだり笑ったり――。
gāyanti ca apy abaddhāni pravartante ca kāmataḥ|
kāmapralāpino'nyonyaṃ teṣu dharmaḥ kathaṃ bhavet|| // 8-34-28 //
（27）でたらめを歌い、欲望のままに振る舞い、欲望について語り合う。そのような者たちにどうして正しい道（ダルマ）があろうか。
madrakeṣv avalipteṣu prakhyātāśubhakarmasu|
na api vairaṃ na sauhārdaṃ madrakeṇa samācaret|| // 8-34-29 //
（28）ごう慢な、不浄な業で名高いマドラカ族とは、憎しみも友情も結ぶべきではない。
madrake saṅgataṃ nāsti madrako hi sadā malaḥ|
madrakeṣu ca saṃsṛṣṭaṃ śaucaṃ gāndhārakeṣu ca|| // 8-34-30 //
（29）マドラカ族には真っ当さがない。マドラカ族は常に穢れた存在である。マドラカ族の交わりの中では清浄が失われる。ガンダーラ族の中でも同じである。
rājayājakayājye hi yathā dattaṃ havir naśet|
śūdrasaṃskārako vipro yathā yāti parābhavam|| // 8-34-31 //
（30）王が祭司の儀式をなすと、その供物が失われ、シュードラの祭式を行うバラモンが落ちるように――。
yathā brahmadviṣo nityaṃ gacchantīha parābhavam|
yathaiva saṃgataṃ kṛtvā naraḥ patati madrakaiḥ|| // 8-34-32 //
（31）バラモンを憎む者は常に凋落するように、マドラカ族と付き合った者は堕ちるのだ。
bāleṣv api sadā na sma dhanaṃ vṛścika te viṣam|
ātharvaṇena mantreṇa sarvaśāntiḥ kṛtā mayā|| // 8-34-33 //
（32）〔サソリの解毒の呪文として〕「サソリよ、お前の毒は若い者たちにいつまでも残らぬ。私はアタルヴァ・ヴェーダの呪文ですべての鎮めを行なった」――。
iti vṛścikadaṣṭasya viṣavegahatasya ca|
kurvanti bheṣajaṃ prājñāḥ satyaṃ tac ca api dṛśyate|| // 8-34-34 //
（33）このような、サソリに咬まれた人、毒に苦しむ人を治す呪文がある。それを賢者は処方する。そしてそれは実に現れる。
evaṃ vidvañ joṣam āssva brūhi ca atrottaraṃ vacaḥ|
vāsāṃsy utsṛjya nṛtyanti striyo madyavimohitāḥ|| // 8-34-35 //
（34）〔続けて：マドラカ族の女たちの振舞い〕識ある者よ、黙って聞け。ここでは答えずに、後で語れ。マドラカ族の女たちは、酒に酔って服を脱ぎ捨てて踊る。
maithune'saṅgatāś ca api yathākāmavarāś ca tāḥ|
tāsāṃ putra kathaṃ dharmaṃ madrako vaktum arhati|| // 8-34-36 //
（35）交わりに節度なく、望みのままに振舞う。そのような女たちの子が、どうして正しい道を語れるだろうか、マドラカ族よ。
yās tiṣṭhantyaḥ pramehanti yathaiva uṣṭradaśerakāḥ|
tāsāṃ vibhraṣṭadharmāṇāṃ nirlajjānāṃ tatas tataḥ|
tvaṃ putras tādṛśīnāṃ hi dharmaṃ vaktum iha icchasi|| // 8-34-37 //
（36）立ったまま小便をすることラクダの雌のごとく――正しい道を失い、恥を知らぬそのような者たちの子であるお前が、どうしてここで正しい道を語れるのか。
sauvīrakaṃ yācyamānā madrikā karṣati sphicau|
adātukāmā vacanam idaṃ vadati dāruṇam|| // 8-34-38 //
（37）マドラ族の女は、酸い飲み物（ソーヴィーラカ）を乞われると尻をゆすり、与えぬつもりで、次のような残酷な言葉を発する――。
mā māṃ sauvīrakaṃ kaścid yācatāṃ dayitaṃ mama|
putraṃ dadyāṃ patiṃ dadyāṃ na tu dadyāṃ suvīrakam|| // 8-34-39 //
（38）「誰も私に愛しいソーヴィーラカをねだるな。息子でも、夫でも差し出そう。だが、ソーヴィーラカだけは渡さぬ」。
gauryo bṛhatyo nirhīkā madrikāḥ kampalāvṛtāḥ|
ghasmarā naṣṭaśaucāś ca prāya ity anuśuśruma|| // 8-34-40 //
（39）色白で背の高いマドラの女たちは、恥知らずで、毛皮に覆われ、大食らいで、清潔を失っている――そう我らは聞いた。
pamehitvā sphicau bhūmau gharṣantyo hīnaśodhanāḥ|
śuddhā na adbhir na mṛdbhiś ca nityocchiṣṭā bhavanti hi|| // 8-34-41 //
（40）地に小便をして尻をこすり付け、洗うことを知らず、水でも土でも清められず、常に穢れている。
evamādi mayā'nyair vā śakyaṃ vaktuṃ bhaved bahu|
ākeśāntān nakhāgrāt ca vaktavyeṣu kukarmasu|| // 8-34-42 //
（41）このようなこと、他にも多く言えよう。髪の先から爪先まで、語るべき悪業が数々あるのだから。
madrakāḥ sindhusauvīrā dharmaṃ vidyuḥ kathaṃ tv iha|
pāpadeśodbhavā mlecchā dharmāṇām avicakṣaṇāḥ|| // 8-34-43 //
（42）マドラカ族やシンドゥ・サウヴィーラ族は、どうして正しい道を知り得よう。悪しき国の生まれの異民族で、道のことを知らぬ者たちなのだから。
eṣa mukhyatamo dharmaḥ kṣatriyasya iti naḥ śrutam|
yadā ājau nihataḥ śete sadbhiḥ samabhipūjitaḥ|| // 8-34-44 //
（43）クシャトリヤにとって最も重要な道は、こう聞いている――戦場で討たれて倒れ、善き者たちに称えられることだ。
āyudhānāṃ sāmparāye yan muñceyam ahaṃ tataḥ|
mamaiṣa prathamaḥ kalpo nidhane svargam icchataḥ|| // 8-34-45 //
（44）戦場で私が武器から離れるとしたら、そのときこそ、私の第一の望みは、死後に天界へ行くことだ。
soyaṃ priyasakhā ca asmi dhārtarāṣṭrasya dhīmataḥ|
tadarthe hi mama prāṇā yac ca me vidyate vasu|| // 8-34-46 //
（45）そして賢きドリタラーシュトラの子（ドゥルヨーダナ）は私の愛する友である。彼のためにこそ、私の命があり、私の財がある。
vyaktaṃ tvam apy upahitaḥ pāṇḍavaiḥ pāpadeśaja|
yathā ca amitravat sarvaṃ tvam asmāsu pravartase|| // 8-34-47 //
（46）お前もまたパーンダヴァに買収されているのが明らかだ、悪しき国の者よ。お前が敵のように我らの中で振舞っているからだ。
kāmaṃ na khalu śakyo'haṃ tvadvidhānāṃ śatair api|
saṅgrāmād vimukhaḥ kartuṃ dharmajña iva nāstikaiḥ|| // 8-34-48 //
（47）たしかに、お前のような者が何百いても、私を戦から退かせることはできぬ。ちょうど不信仰の者が道を知る者を退かせられぬように。
sāraṅga iva gharmārtaḥ kāmaṃ vilapa śuṣya ca|
na ahaṃ bhīṣayituṃ śakyaḥ kṣatradharme vyavasthitaḥ|| // 8-34-49 //
（48）暑さに苦しむシカのように好きなだけ嘆き、萎れるがよい。私はクシャトリヤの道に立っているのだから、脅されない。
tanutyajāṃ nṛsiṃhānām āhaveṣv anivartinām|
yā gatir guruṇā proktā premṇā rāmeṇa tāṃ smare|| // 8-34-50 //
（49）戦場で退かず命を捨てる人中の獅子たちのその行き先を、師であり愛するラーマ（パラシュラーマ）が語ったのを、私は思い起こすのだ。
sveṣāṃ trāṇārtham udyantaṃ vadhārthaṃ dviṣatām api|
viddhi mām āsthitaṃ vṛttaṃ paurūravasamuttamam|| // 8-34-51 //
（50）自分の側の者たちを守るために立ち上がり、敵を討ち取るために立ち上がる私を、最上のプールーラヴァスの道に従う者と知れ。
na tadbhūtaṃ prapaśyāmi triṣu lokeṣu madrapa|
yo mām asmād abhiprāyād vārayed iti me matiḥ|| // 8-34-52 //
（51）マドラ王よ、三界において私の見る限り、私をこの決意から引き戻すことのできる者は、誰もいないと思う。
evaṃ vidvañ joṣam āssva trāsāt kiṃ bahu bhāṣase|
na tvāṃ hatvā pradāsyāmi kravyādbhyo madrakādham|| // 8-34-53 //
（52）識ある者よ、黙って聞け。恐怖のあまり、なぜ多く語るのか。卑しいマドラカ族よ、お前を討っても肉食獣に与えることはしまい。
mitrapratīkṣayā śalya dhṛtarāṣṭrasya ca ubhayoḥ|
apavādatitikṣābhis tribhir etair hi jīvasi|| // 8-34-54 //
（53）友への期待、ドリタラーシュトラ（への義理）と、両者に対する非難への忍耐――この三つの理由によってこそ、お前は生きているのだ、シャルヤよ。
punaś ca īdṛśaṃ vākyaṃ madrarāja vadiṣyasi|
śiras te pātayiṣyāsi gadayā vajrakalpayā|| // 8-34-55 //
（54）再び、マドラ王よ、このような言葉を発すれば、私はお前の頭を雷のような鉄棒で叩き落とすぞ。
śrotāras tv idam adya iha draṣṭāro vā kudeśaja|
karṇaṃ vā jaghnatuḥ kṛṣṇau karṇo vā nijaghāna tau|| // 8-34-56 //
（55）今日、ここで聞く者たち、見る者たちの前で、悪しき国の者よ、二人のクリシュナがカルナを討つか、カルナが二人を討つか、決まるだろう」。
evamuktvā tu rādheyaḥ punar eva viśāmpate|
abravīn madrarājānaṃ yāhi yāhi ity asambhramam|| || // 8-34-57 //
（56）こう言ってカルナは、ふたたびマドラ王に向かって、国王よ、「進め、進め」と慌てずに告げた。
