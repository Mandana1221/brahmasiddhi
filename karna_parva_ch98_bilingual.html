マハーバーラタ ― カルナ篇 第98章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 98 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ98」で、クリシュナの叱責とカルナの最期の場面を描きます。
karṇaparva — aṣṭānavatitamo'dhyāyaḥ (98)
第98章 ― クリシュナの叱責とカルナの最期
sañjaya uvāca|
athābravīdvāsudevo mahātmā rādheya diṣṭyā smarasīha dharmam|
'dharme hi baddhā satataṃ hi pārthāstebhyastato vṛddhisau dadāti||
dharmādapetāḥ paripanthinaste tasmādgatā vai kuravo vināśam'|
prāyeṇa nīcā vyasaneṣu magnā nindanti daivaṃ na tu duṣkṛtaṃ svam||
// 8-98-1-2 //
サンジャヤは語った。
すると偉大なるヴァースデーヴァ（クリシュナ）が言った。「ラーデーヤよ、よくもここでダルマを思い出したものだ。パールタたちは常にダルマに縛られている。だからこそダルマは彼らに繁栄を与えるのだ。ダルマから離れた妨害者たるおまえたちこそが、クル族を滅亡に導いたのだ。大抵の場合、卑しい者は困難に陥ると、自らの悪行ではなく運命を非難するものだ。」
kṛṣṇāṃ sabhāṃ karṇa yadekavastrāmānītavāṃstvaṃ ca suyodhanaśca|
duḥśāsanaḥ śakuniḥ saubalaśca|
dharmastadā te rucito na kasmāt||
// 8-98-3 //
「カルナよ、クリシュナー（ドラウパディー）が一枚の衣だけで集会場に連れてこられた時、おまえとスヨーダナ（ドゥルヨーダナ）とドゥフシャーサナとシャクニが引きずり出したのだ。あの時、おまえのダルマはどこへ行っていたのか。」
yadā sabhāyāṃ rājānamanakṣajñaṃ yudhiṣṭhiram|
ānīya jitavanto vai kva te dharmastadā gataḥ||
// 8-98-4 //
「集会場で、賭博を知らない王ユディシュティラを連れてきて騙し勝った時、あの時おまえのダルマはどこへ行っていたのか。」
vanavāse vyatīte ca karṇa varṣe trayodaśe|
na prayacchasi yadrājyaṃ kva te dharmastadā gataḥ||
// 8-98-5 //
「カルナよ、森での暮らしを終えた十三年目に王国を返さなかった時、あの時おまえのダルマはどこへ行っていたのか。」
yadbhīmasenaṃ sarpaiśca viṣayuktaiśca bhojanaiḥ|
ācarattvanmate rājā kva te dharmastadā gataḥ||
// 8-98-6 //
「ビーマセーナを蛇や毒入りの食事で殺そうとしたのは、おまえの承認のもとで王（ドゥルヨーダナ）がやったことだ。あの時おまえのダルマはどこへ行っていたのか。」
yadvāraṇāvate pārthānsuptāñjatugṛhe tadā|
hantukāmāstadā yūyaṃ kva te dharmastadā gataḥ||
// 8-98-7 //
「ヴァーラナーヴァタ（漆の館）で眠るパールタたちを漆の家で焼き殺そうとした時、おまえたちは殺そうとしたのだ。あの時おまえのダルマはどこへ行っていたのか。」
yadā rajasvalāṃ kṛṣṇāṃ duḥśāsanavaśe sthitām|
sabhāyāṃ prāhasaḥ karṇa kva te dharmastadā gataḥ||
// 8-98-8 //
「月のものの最中のクリシュナー（ドラウパディー）がドゥフシャーサナの手中にあった時、集会場でおまえは笑ったのだ、カルナよ。あの時おまえのダルマはどこへ行っていたのか。」
yadanāryaiḥ purā kṛṣṇāṃ kliśyamānāmanāgasam|
upaprekṣasi rādheya kva te dharmastadā gataḥ||
// 8-98-9 //
「罪なきクリシュナーが卑しい者たちに苦しめられている時、ラーデーヤよ、おまえは傍観していた。あの時おまえのダルマはどこへ行っていたのか。」
vinaṣṭāḥ pāṇḍavāḥ kṛṣṇe śāśvataṃ narakaṃ gatāḥ|
patimanyaṃ vṛṇīṣveti vadaṃstvaṃ gajagāminīm|
upaprekṣasi rādheya kva te dharmastadā gataḥ||
// 8-98-10 //
「『パーンダヴァたちは滅びた、クリシュナーよ、永遠の地獄に行った。別の夫を選べ』と、象のように歩む女にそう言って傍観していた、ラーデーヤよ。あの時おまえのダルマはどこへ行っていたのか。」
rājyalubdhaḥ punaḥ karṇa samāhvayasi pāṇḍavān|
yadā śakunimāśritya kva te dharmastadā gataḥ||
// 8-98-11 //
「王国に貪欲なおまえ、カルナよ、シャクニを頼りにしてパーンダヴァたちを再び賭博に呼んだのだ。あの時おまえのダルマはどこへ行っていたのか。」
yadā'bhimanyuṃ bahavo yuddhe jaghnurmahārathāḥ|
parivārya raṇe bālaṃ kva te dharmastadā gataḥ||
// 8-98-12 //
「大勢の大戦車戦士がアビマニユを、幼い者を戦場で取り囲んで殺した時、あの時おまえのダルマはどこへ行っていたのか。」
yadyeṣa dharmastatra na vidyate hi kiṃ sarvathā tāluviśoṣaṇena|
adyeha dharmyāṇi vidhatsva sūta tathāpi jīvanna vimokṣyase hi||
nalo hyakṣairnirjitaḥ puṣkareṇa punaryaśo rājyamavāpa vīryāt|
prāptāstathā pāṇḍavā bāhuvīryātsarvaiḥ sametāḥ parivṛttalobhāḥ||
nihatya śatrūnsamare pravṛddhānsasomakā rājyamavāpnuyuste|
tathā gatā dhārtarāṣṭrā vināśaṃ dharmābhiguptaiḥ satataṃ nṛsiṃhaiḥ||
// 8-98-13-15 //
「そのダルマがあの時なかったのなら、なぜ今さら口を乾かして叫ぶのか。スータよ、今さらダルマにかなったことをしても、おまえは生きて逃れられないのだ。ナラ王もプシュカラに賭博で負けたが、武勇によって名声と王国を取り戻した。パーンダヴァたちも同じように腕の武勇によって、すべてが団結して貪欲を捨てて戦い、戦場で増長した敵を討ち、ソーマカ勢とともに王国を得るだろう。ダルマに常に守られた人の中の獅子たちによって、ドリタラーシュトラの息子たちは滅亡に向かったのだ。」
sañjaya uvāca|
evamuktastadā karṇo vāsudevena bhārata|
lajjayāvanato bhūtvā nottaraṃ kiñciduktavān||
// 8-98-16 //
サンジャヤは語った。 バーラタよ、ヴァースデーヴァにこう言われて、カルナは恥ずかしさにうつむき、何も答えなかった。
krodhātprasphuramāṇauṣṭho dhanurudyamya bhārata|
yodhayāmāsa vai pārthaṃ mahāvegaparākramaḥ||
// 8-98-17 //
怒りに唇を震わせながら弓を取り上げ、バーラタよ、大いなる速度と武勇でパールタと戦い続けた。
tato'bravīdvāsudevaḥ phalgunaṃ puruṣarṣabham|
divyāstreṇaiva nirbhidya pātayasva mahābala||
// 8-98-18 //
するとヴァースデーヴァが人中の雄牛アルジュナに言った。「大いなる力の者よ、神聖な武器で貫いて倒せ。」
evamuktastu devena krodhamāgāttadā'rjunaḥ|
manyumabhyāviśaddhoraṃ smṛtvā tattu dhanañjayaḥ||
// 8-98-19 //
主（クリシュナ）にこう言われてアルジュナは怒りに入った。過去のすべてを思い出して、恐ろしい怒りが湧き上がった。
tasya kruddhasya sarvebhyaḥ srotobhyastejaso'rciṣaḥ|
prādurāsaṃstadā rājaṃstadadbhutamivābhavat||
// 8-98-20 //
怒った彼のすべての感覚器官から光の炎が噴き出した、王よ。それは驚くべきことであった。
tatsamīkṣya tataḥ karṇo brahmāstreṇa dhanañjayam|
abhyavarṣatpunaryatnamakarodrathasarjane||
brahmāstreṇava taṃ pārtho kavarṣa śaravṛṣṭibhiḥ|
tadastramastreṇāvārya prajahāra ca pāṇḍavaḥ||
tato'nyadastraṃ kaunteyo dayitaṃ jātavedasaḥ|
mumoca karṇamuddiśya tatprajajvāla tejasā||
vāruṇena tataḥ karṇaḥ śamayāmāsa pāvakram|
jīmūtaiśca diśaḥ sarvāścakre timiradurdināḥ||
pāṇḍaveyastvasambhrānto vāyavyāstreṇa vīryavān|
apovāha tadā'bhrāṇi rādheyasya prapaśyataḥ||
// 8-98-21-25 //
カルナはブラフマーストラでダナンジャヤに矢の雨を浴びせ、車輪を引き上げる努力を続けた。パールタもブラフマーストラで矢の雨を降らせて応戦し、その武器を武器で防いでカルナを打った。そこでカウンテーヤ（アルジュナ）はアグニ（火神）のお気に入りの別の武器を放った。それはカルナを目がけて輝きを放った。カルナはヴァールナ（水の武器）で火を消し、雲で四方を暗い悪天にした。パーンダヴァは動じずヴァーユの武器（風の武器）で雲を吹き払った。ラーデーヤが見ている前で。
tataḥ śaraṃ mahāghoraṃ jvalantimiva pāvakam|
ādade pāṇḍuputrasya sūtaputro jighāṃsayā||
yojyamāne tatastasminbāṇe dhanuṣi pūjite|
cacāla pṛthivī rājansaśailavanakānanā||
vavau saśarkaro vāyurdiśaśca rajasā vṛtāḥ|
hāhākāraśca saṃvajñe surāṇāṃ divi bhārata||
tamiguṃ sandhitaṃ dṛṣṭvā sūtaputreṇa māriṣa|
viṣādaṃ paramaṃ jagmuḥ pāṇḍavā dīnacetasaḥ||
sa sāyakaḥ karṇabhujapramuktaḥ śakrāśanigrakhyaruciḥ śitāgraḥ|
mulāntaraṃ prāpya dhanañjayasya viveśa valmīkamivoramottamaḥ||
sa rāḍhaviddhaḥ samare mahātmā vidhūrṇamānaḥ ślathahastagāṇḍivaḥ|
cacāla vībhatsuramitramardanaḥ kṣiteḥ prakampe ca yathā'calottamaḥ||
// 8-98-26-31 //
スータの息子はパーンドゥの息子を殺そうと恐ろしい燃える矢を弓に番えた。その崇められた弓にこの矢が番えられると、大地は山と森と叢林ごと揺れた。砂混じりの風が吹き、四方は塵に覆われた。天界では神々が「ああ！」と嘆いた。この恐ろしい矢がスータの息子によって番えられたのを見て、パーンダヴァたちは意気消沈し、悲嘆に沈んだ。カルナの腕から放たれたその矢は、インドラの雷のように輝き鋭い先端を持ち、ダナンジャヤの胸の中心に達し、蟻塚に潜る大蛇のように入り込んだ。その矢に打たれた偉大な魂の戦士、ヴィーバツ（アルジュナ）は、敵を砕く者であったが、ガーンディーヴァを持つ手が緩み、大地が揺れる中の山のように揺れた。
tadantaraṃ prāpya vṛṣo mahāratho rathāṅgasurvīgatamujjihīrṣuḥ|
rathādavaplutya nigṛhya dorbhyāṃ śaśāka daivānna mahābalo'pi||
tataḥ kirīṭi pratilabhya saṃjñāṃ jagrāha bāṇaṃ yamadaṇḍakalpam|
tato'rjunaḥ prāñjalikaṃ mahātmā tato'bravīdvāsudevo'pi pārtham||
// 8-98-32-33 //
この隙を捉えて偉大な戦車戦士カルナは、戦車から飛び降り、大地に沈んだ車輪を両腕でつかんで引き上げようとした。しかし大いなる力を持つ彼も、運命のゆえにそれができなかった。するとキリーティン（アルジュナ）は意識を取り戻し、ヤマの杖のような矢をつかんだ。そしてアンジャリカ矢を取り出した。偉大な魂のヴァースデーヴァ（クリシュナ）がパールタに言った。
chindhyasya mūrdhānamareḥ śareṇa na yāvadārohati vai rathaṃ vṛṣaḥ|
tathaiva sampūjya sa tadvacaḥ prabhostataḥ śaraṃ prajvalitaṃ pragṛhya|
jaghāna kakṣāmamalārkavarṇāṃ mahārathe rathacakre vimagne||
// 8-98-34 //
「雄牛（カルナ）が戦車に戻る前に、矢で敵の首を斬り落とせ。」 アルジュナは主のこの言葉を敬い、燃え輝く矢を取り、偉大な戦車戦士の車輪が沈んだ中で、美しい太陽のような旗印を射た。
taṃ hastikakṣāpravaraṃ suketuṃ suvarṇamuktāmaṇivajrajuṣṭam|
kalāprakṛṣṭottamaśilpiyatnaiḥ kṛtaṃ surūpaṃ tapanīyacitram||
jayāspadaṃ tava sainyasya nitya-mamitravitrāsanamīḍyarūpam|
vikhyātamādityasutasya loke tviṣā samaṃ pāvakabhānucandraiḥ||
tataḥ kṣurapreṇa susaṃśitena suvarṇapuṅkhena hutāgnivarcasā|
śriyā jvalantaṃ dhvajamunmamātha mahārathasyādhiratheḥ kirīṭī||
// 8-98-35-37 //
あの象の腹帯の旗竿は、黄金・真珠・宝石・ダイヤモンドで飾られ、最高の技の工芸品で作られた美しい黄金細工の旗であった。おまえの軍の勝利の拠り所であり、常に敵に恐怖を与え、崇高な姿をし、太陽の息子（カルナ）のものとして世に名高く、火と太陽と月に等しい輝きを持っていた。キリーティンはカミソリ矢で、黄金の柄を持つ火のように輝く矢で、栄光に輝く偉大な戦車戦士アディラティ（カルナ）の旗を引き倒した。
yaśaśca darpaśca tathā priyāṇi sarvāṇi kāryāṇi ca tena ketunā|
sākaṃ kurūṇāṃ hṛdayāni cāpatan babhūva hāheti ca niḥsvano mahān||
// 8-98-38 //
名声も誇りも、すべての大切な事業も、その旗とともに落ちた。クル勢の心臓も一緒に落ちた。大いなる「ああ！」という叫びが響いた。
dvaṣṭvā dhvajaṃ pātitamāśukāriṇā kurupravīreṇa nikṛttamāhave|
nāśaṃsire sūtaputrasya sarve jayaṃ tadā bhārata ye tvadīyāḥ||
// 8-98-39 //
旗が素早い射手、クルの最良者に切り落とされて戦場に倒れるのを見て、バーラタよ、おまえの兵たちは誰もスータの息子の勝利を信じなくなった。
atha tvarankarṇavadhāya pārtho mahedravajrānaladaṇḍasannibham|
ādatta cāthāñjalikaṃ niṣaṅgātsahasraraśmeriva raśmimuttamam||
marmacchidaṃ śoṇitamāṃsadigdhaṃ vaiśvānarārkapratimaṃ mahārham|
narāśvanāgāsuharaṃ tryaratniṃ ṣaḍvājamañjogatimugravegam||
sahasranetrāśanitulyavīryaṃ kālānalaṃ vyāttamivātighoram|
pinākanārāyaṇacakrasannibhaṃ bhayaṅkaraṃ prāṇabhṛtāṃ vināśanam||
// 8-98-40-42 //
カルナの討伐を急ぐパールタは、矢筒からアンジャリカ矢を取り出した。インドラの雷と火と死の杖に等しいものを。千の光線を持つ太陽から出る最高の光線のように。急所を貫き、血と肉にまみれた、火と太陽に等しい高価な矢。人・馬・象の命を奪う、三アラトニ（約1.3メートル）の長さの、六枚の羽を持ち、まっすぐに飛ぶ恐ろしい速度の矢。千の目のインドラの雷に等しい力を持ち、燃え盛るカーラの火が口を開けたように恐ろしい。ピナーカ（シヴァの弓）、ナーラーヤナの円盤に等しい、すべての命ある者を恐れさせ滅ぼす矢。
jagrāha pārthaḥ sa śaraṃ prahṛṣṭo yo devasaṅghairapi durnivāryaḥ|
sampūjito yaḥ satataṃ mahātmā devāsurānyo vijayenmaheṣuḥ||
taṃ vai pramṛṣṭaṃ prasamīkṣya yuddhe cacāla sarvaṃ sacarācaraṃ jagat|
kṛtsnaṃ jagatsvastyṛṣayo'bhicakrustamudyataṃ prekṣya mahāhaveṣum||
tatastu taṃ vai śaramaprameyaṃ gāṇḍīvadhanvā dhanuṣi vyayojayat|
yuktvā mahāstreṇa pareṇa cāpaṃ vikṛṣya gāṇḍīvamuvāca satvaram||
// 8-98-43-45 //
パールタは歓喜して、神々の群れにさえ防ぎがたいその矢をつかんだ。常に崇拝され、神々もアスラも打ち負かすであろう偉大な矢を。戦場でその矢が磨かれるのを見て、動くものも動かぬものもこの世のすべてが震えた。聖仙たちはこの偉大な矢が構えられるのを見て、全世界の平安を祈った。ガーンディーヴァの弓の持ち主は、その計り知れない矢を弓にかけ、偉大なる武器（アストラ）とともに弓をつがえ、ガーンディーヴァを引き絞ってすぐさまこう言った。
ayaṃ hāstraprahito mahāśaraḥ śarīrahṛccāsuharaśca durhṛdaḥ|
tapo'sti taptaṃ guravaśca toṣitā mayā yadīṣṭaṃ suhutaṃ yadi śrutam||
anena satyena nihantvayaṃ śaraḥ susaṃhitaḥ karṇamariṃ mamorjitam|
ityūcivāṃstaṃ pramumoca bāṇaṃ dhanañjayaḥ karṇavadhāya ghoram||
kṛtyā hyatharvāṅgirasī pracoditā yathā tathā tvaṃ jahi śātravaṃ mama|
bruvankirīṭī tamatiprahṛṣṭo'sṛjaddevānāṃ jayahetuṃ maheṣum||
// 8-98-46-48 //
「この偉大な矢は、アストラに送られ、敵の体を奪い命を奪う者である。もし私に苦行があり、師が満足し、もし私の供犠が正しくなされ、護摩が正しく焚かれ、ヴェーダを正しく学んだならば、この真実の力によって、この矢が私の敵、堅固なるカルナをよく狙って討ちますように。」こう言ってダナンジャヤは、カルナを討つための恐ろしい矢を放った。「アタルヴァ・アンギラスの呪法が駆り立てられたように、おまえは私の敵を討て。」こう言いながらキリーティンは大いに歓喜し、神々の勝利のための偉大な矢を放った。
jighāṃsurarkendusamaprabhāvaḥ karṇaṃ vaśī pāṇḍavaḥ kṣiprakārī|
tato vimukto balinā maheṣuḥ prajvālayāmāsa nabho diśaśca||
sainyānyanekāni ca vipramohya gāṇḍīvamuktena tato mahātmā|
tenārjunastanmahanīyamasya śiro'haratsūtaputrasya rājan||
// 8-98-49-50 //
太陽と月に等しい輝きを持つパーンダヴァは、カルナを殺そうと、自制し素早く行動する者として矢を放った。力ある者から放たれた偉大な矢は、天空と四方を燃え上がらせた。多くの軍勢を惑わせながら、ガーンディーヴァから放たれた偉大な魂のアルジュナは、王よ、その偉大にして畏るべき矢で、スータの息子の首を斬り落とした。
śarottamenāñjalikena rājaṃstadā mahāstrapratimantritena|
pārtho'parāhṇe śira uccakarta vaikartanasyātha mahendrasūnuḥ|
chinnaṃ papātāñjalikena tūrṇaṃ kāyaśca paścāddharaṇīṃ jagāma||
// 8-98-51 //
王よ、最上のアンジャリカ矢で、偉大なるアストラで祝福されたその矢で、パールタはマヘーンドラの息子（アルジュナ）として、午後の時にヴァイカルタナの首を切り落とした。切り落とされた首はアンジャリカ矢とともに速やかに落ち、胴体もその後に大地に倒れた。
tadudyatādityasamānatejasaṃ śarannabhomadhyagabhāskaropamam|
varāṅgamurvyāmapataccamumūkhe divākaro'stādiva raktamaṇḍalaḥ||
// 8-98-52 //
昇る太陽のような輝きを持つ、秋の天空の中央にある太陽のような、その美しい体は軍の前で大地に落ちた。沈む太陽の赤い円盤のように。
tato'sya dehaṃ satataṃ sukhaidhitaṃ surūpamatyarthasukhaṃ sugandhi ca|
pareṇa kṛcchreṇa śiraḥ samatyajadgṛhaṃ mahardhīnnivasanniveśvaraḥ||
śarairvibhinnaṃ vyasu tatsuvarcasaḥ papāta karṇasya śarīmucchritam|
sravadvraṇaṃ gairikatoyavisravaṃ gireryathā vajrahataṃ mahāśiraḥ||
// 8-98-53-54 //
常に安楽に育てられた美しい姿の、この上なく心地よく芳香を放つその体は、大いなる苦難をもって首から離れた。富める者が大いなる館を去るように。矢に砕かれ息絶えたカルナの輝かしき高い体が倒れた。傷から赤い土の水のような血を流しながら。雷に打たれた山の偉大な頂のように。
dehācca karṇasya nipātitasya tejaḥ sūryaṃ khaṃ vitatyāviveśa|
tadadbhutaṃ sarvamanuṣyayodhāḥ saṃdṛṣṭavanto nihate sma karṇe||
// 8-98-55 //
倒れたカルナの体からテージャス（光輝）が太陽に向かって天空を広がって入った。それは驚くべきことであった。すべての人間の兵士たちがカルナの討死の時にそれを目撃した。
tataḥ śaṅkhānpāṇḍavā dadhmuruccairdṛṣṭvā karṇaṃ pātitaṃ phalgunena|
tathaiva kṛṣṇaśca dhanañjayaśca haṣṭau yamau dadhmaturvārijātau||
// 8-98-56 //
パーンダヴァたちは高らかに法螺貝を吹き鳴らした。アルジュナに倒されたカルナを見て。クリシュナとダナンジャヤも歓喜して蓮から生まれた法螺貝を吹いた。双子（ナクラとサハデーヴァ）もまた。
taṃ somakāḥ prekṣya hataṃ śayānaṃ sainyaiḥ sārdhaṃ siṃhanādānpracakruḥ|
tūryāṇi sañjaghnuratīva hṛṣṭā vāsāṃsi caivādudhuvurbhujāṃśca||
saṃvardhayantaśca narendra yodhāḥ pārthaṃ samājagmuratīva hṛṣṭāḥ|
balānvitāścāpare hyapyanṛtyannanyonyamāśliṣya nadanta ūcuḥ||
// 8-98-57-58 //
ソーマカ勢は倒れたカルナを見て、軍勢とともに獅子の咆哮をあげ、楽器を叩き鳴らし、大いに歓喜して衣を振り腕を振った。兵士たちはパールタを讃えて歓喜して集まり、力に満ちた別の者たちは踊り、互いに抱擁し合い、叫びながら語り合った。
dṛṣṭvā tu karṇaṃ bhuvi vā vipannaṃ kṛttaṃ rathātsāyakairarjunasya|
mahānilenādrimivāpavidvaṃ yajñāvasāne'gnimiva praśāntam||
tadānanaṃ sūryasutasya rājanvibhrājate padmivāvanālam|
rarāja karṇasya śiro nikṛttamastaṃgataṃ bhāskarasyeva bimbam||
// 8-98-59-60 //
カルナが大地に倒れたのを見て、アルジュナの矢に切り裂かれて戦車から落ちたのを見て、大風に吹き倒された山のように、供犠の終わりの消えた火のように。スーリヤ（太陽神）の息子の顔は、王よ、茎のない蓮のように輝いていた。切り落とされたカルナの首は、沈みゆく太陽の円盤のように輝いた。
śarairācitasarvāṅgaḥ śoṇitaughapariplutaḥ|
rarāja dehaḥ karṇasya svaraśmibhirivāṃśumān||
pratāpya senāmāmitrīṃ dīptaiḥ śaragabhastibhiḥ|
balinārjunakālena nīto'staṃ karṇabhāskaraḥ||
// 8-98-61-62 //
全身に矢が突き刺さり、血の洪水に浸されたカルナの体は、自らの光線によって輝く太陽のように輝いた。敵の軍を輝く矢の光線で焼き尽くした後、力あるアルジュナというカーラ（時）によって、カルナという太陽は西に沈んだ。
astaṃ gacchanyathā'dityaḥ prabhāmādāya gacchati|
tathā jīvitamāhāya karṇasyeṣurjagāma saḥ||
aparāhṇe'parāhṇasya sūtaputrasya māriṣa|
chinnamañjalikenājau sotsedhamapatacchiraḥ||
// 8-98-63-64 //
太陽が沈む時にその光を奪い去るように、アルジュナの矢はカルナの命を奪い去った。午後の太陽の午後に、王よ、スータの息子の首がアンジャリカ矢によって戦場で切り落とされ、高く飛んで落ちた。
uparyupari sainyānāṃ vinighnannitarāñjanān|
śiraḥ karṇasya so'tsedhamiṣuḥ sopyaharaddrutam||
// 8-98-65 //
軍勢の上高く敵を打ちながら飛んだカルナの首を、あの矢は高々と奪い取って素早く落とした。
karṇaṃ tu śūraṃ patitaṃ pṛthivyāṃ śarācitaṃ śoṇitadigdhagātram|
dṛṣṭvā śayānaṃ bhuvi madrarājaśchinnadhvajenātha yayau rathena||
// 8-98-66 //
大地に倒れたカルナ、矢に覆われ血に染まった体の勇者を見て、マドラ王（シャリヤ）は旗を切られた戦車で去っていった。
hate karṇe kuravaḥ prādravanta bhayārditā gāḍhaviddhāśca saṅkhye|
avekṣamāṇā muhurarjunasya dhvajaṃ mahāntaṃ vapuṣā jvalantam||
// 8-98-67 //
カルナが討たれるとクル勢は逃げ出した。恐怖に苦しみ、戦いで深く傷ついて。何度もアルジュナの偉大な旗が姿で燃え輝くのを振り返り見ながら。
tacchiro bharataśreṣṭha śobhayāmāsa medinīm|
yadṛcchayeva patitaṃ maṇḍalaṃ cāṇḍadīdhiteḥ||
taṃ dṛṣṭvā samaravimarda (baddha) labdhanidraṃ daṣṭoṣṭhaṃ rudhirapīratakātarākṣam|
rādheyaṃ rathavarapṛṣṭhasanniṣaṇṇaṃ hīnāṃśurdivasakaro muhūrtamāsīt||
// 8-98-68-69 //
バーラタの最良者よ、その首は大地を美しく飾った。偶然落ちた月の円盤のように。戦いの中で眠りについたかのように、唇を噛み、血に染まった目を見開いた恐怖の表情のラーデーヤ。最上の戦車の上に座るラーデーヤを見て、太陽は一瞬、光を失った。
niḥśabdatūryaṃ hatayodhamukhyaṃ praśāntadarpaṃ dhṛtarāṣṭrasainyam|
na śobhate sūryasutena hīnaṃ vṛndaṃ grahāṇāmiva candrahīnam||
// 8-98-70 //
楽器も静まり、勇者の首領を失い、誇りも静まったドリタラーシュトラの軍は、太陽の息子（カルナ）を失って輝かなくなった。月を失った惑星の群れのように。
sahasranetrapratimānakarmaṇaḥ sahasrapatrapratimānanaṃ śubham|
sahasraraśmirdivasakṣaye yathā tathā'patatkarṇaśiro vasundharām||
// 8-98-71 //
千の目のインドラに等しい功績を持つ者の、千の花弁の蓮のような美しい顔をした、その首は大地に落ちた。一日の終わりの千の光線を持つ太陽のように。
vyūḍhoraskaṃ kamalavadanaṃ taptahemāvabhāsaṃ karṇaṃ dṛṣṭvā bhuvi nipatitaṃ pārthabāṇābhitaptam|
pāṃsugrastaṃ malinamasakṛtputramanvīkṣamāṇo mandammandaṃ vrajati savitā mandiraṃ mandaraśmiḥ||
// 8-98-72 //
広い胸と蓮のような顔を持ち、焼けた黄金のように輝く、パールタの矢に焼かれて大地に倒れた我が子カルナを、塵にまみれ汚れた姿を何度も見つめながら、太陽神は光を弱め、ゆっくりとゆっくりと西の館へ沈んでいった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe aṣṭānavatitamo'dhyāyaḥ|| 98 ||
こうして、聖なる大マハーバーラタのカルナ篇の第98章は終わる。
