マハーバーラタ ― カルナ篇 第90章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 90 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ90」で、アルジュナによるカルナの子ヴリシャセーナの殺害の場面を描きます。主要テキストの詩節1〜15に続き、झ（jha）写本に見られる異伝詩節（クリシュナとアルジュナの対話）を収録しています。
karṇaparva — navatitamo'dhyāyaḥ (90)
第90章　アルジュナによるカルナの子ヴリシャセーナの殺害
sañjaya uvāca|

tataḥ kirīṭi paravīraghātī hatāśvamālokya narapravīraḥ|
mādrīsutaṃ nakulaṃ lokamadhye samīkṣya kṛṣṇaṃ bhṛśavikṣataṃ ca|
samabhyadhāvadvṛṣasenamāhave sa sūtajasya pramukhe sthitastadā||
// 8-90-1 //
サンジャヤは語った。
そこで敵の勇者を殺す冠を戴く者（アルジュナ）は、人中の勇者として——マードリーの子ナクラが馬を失い、世の人々の中で苦戦し、クリシュナが激しく傷つけられているのを見て——戦場でヴリシャセーナに向かって突撃した。彼はスータの子（カルナ）の前に立っていた。
tamāpatantaṃ naravīramugraṃ mahāhave bāṇasahasradhāriṇam|
abhyāpatatkarṇasuto mahārathaṃ yathā mahendraṃ namuciḥ purā tathā||
// 8-90-2 //
千の矢を持つ恐ろしき人中の勇者が大いなる戦場に突進してくるのに対し、大戦車戦士のカルナの子は向かって行った。かつてナムチがマヘーンドラ（インドラ）に向かったように。
tau tatra śūrau rathakuñjarau raṇe parasparasyābhimukhau mahārathau|
sasarjatuḥ śarasaṅghānanekānsambhrāntarūpau subhṛśaṃ tadānīm||
// 8-90-3 //
二人の勇者、戦場の戦車象のような二人の大戦車戦士は、互いに向き合って、幾多の矢の群れを放った。その時二人とも激しく取り乱した姿であった。
tato drutaṃ caikaśareṇa pārthaṃ śitena viddhvā yudhi karṇaputraḥ|
nanāda nādaṃ sumahānubhāvo viddhveva śakraṃ namuciḥ sa vīraḥ||
// 8-90-4 //
カルナの子は素早く一本の鋭い矢で戦場のアルジュナを射、大いなる力の勇者は大きく吼えた——かつてナムチがインドラを射た時のように。
punaḥ sa pārthaṃ vṛṣasena ugrairbāṇairaviddhyadbhujamūle tu savye|
tathaiva kṛṣṇaṃ navabhiḥ samārdayatpunaśca pārthaṃ daśabhirjaghāna||
// 8-90-5 //
さらにヴリシャセーナは恐ろしい矢でアルジュナの左の腕の付け根を射、九本でクリシュナをも苦しめ、さらに十本でアルジュナを射た。
pūrvaṃ yathā vṛṣasenaprayuktairabhyāhataḥ śvetahayaḥ śaraistaiḥ|
saṃrambhamīṣadgamito vadhāya karṇātmajasyātha manaḥ pradadhre||
// 8-90-6 //
先にヴリシャセーナの矢に打たれた白い馬のアルジュナは、やや怒りを覚え、カルナの子を殺す決意を固めた。
tataḥ kirīṭi raṇamūrdhni kopāt kṛtvā triśākhāṃ bhrukuṭiṃ lalāṭe|
mumoca tūrṇaṃ viśikhānmahātmā vadhe dhṛtaḥ karṇasutasya saṅkhye|
āraktanetro'ntakaśatruhantā uvāca karṇaṃ bhṛśamutsmayaṃstadā||
// 8-90-7 //
そして冠を戴く者（アルジュナ）は、戦場の先頭で怒り、額に三叉の皺を刻み、偉大な者は素早く矢を放った——カルナの子を戦場で殺す決意で。赤い目をした、敵を殺す者として——カルナにこう言った。大いに微笑みながら。
duryodhanaṃ drauṇimukhāṃśca sarvānahaṃ raṇe vṛṣasenaṃ tamugram|
sampaśyataḥ karṇa tavādya saṅkhye nayāmi lokaṃ niśitaiḥ pṛṣatkaiḥ||
// 8-90-8 //
「ドゥルヨーダナやドローナの子らをはじめとする全ての者よ、戦場でこの恐ろしいヴリシャセーナを——カルナよ、お前が見ている前で今日——鋭い矢であの世に送ってやろう。」
ūnaṃ ca tāvaddhi janā vadanti sarvairbhavadbhirmama sūnurhato'sau|
eko ratho madvihīnastarasvī ahaṃ haniṣye bhavatāṃ samakṣam||
// 8-90-9 //
「人々は言っている——お前たち全員によって我が息子（アビマンニュ）は殺された、と。あの一台の戦車の俊敏な者から武器を奪った上で。私はお前たちの目の前で殺してやろう。」
saṃrakṣyatāṃ rathasaṃsthāḥ suto'yamahaṃ haniṣye bhavatāṃ samakṣam||
paścādvadhiṣye tvāmapi sampramūḍhamahaṃ haniṣye'rjuna ājimadhye||
// 8-90-10 //
「お前の息子を戦車に乗せて守れ。私はお前たちの目の前で殺してやろう。そしてその後にお前をも殺す、惑える者よ——私アルジュナが戦場の真ん中で殺してやろう。」
tamadya mūlaṃ kalahasya saṅkhye duryodhanāpāśraya jātadarpam|
tvāmadya hantā'smi raṇe prasahya asyaiva hantā yudhi bhīmasenaḥ|
duryodhanasyādhamapūruṣasya yasyānayādeṣa mahānkṣayo'bhavat||
// 8-90-11 //
「今日、争いの根源たる、ドゥルヨーダナの庇護のもとに傲慢になったお前を、今日この戦場で力ずくで殺す。そしてこの者（ドゥルヨーダナ）の殺害者は戦場でビーマセーナとなるだろう——その愚行のために、この大いなる破滅が生じた卑劣な男の。」
sa evamuktvā vinimṛjya cāpaṃ lakṣyaṃ hi kṛtvā vṛṣasenamājau|
sasarja bāṇānviśikhānmahātmā vadhāya rājankarṇasutasya saṅkhye||
// 8-90-12 //
こう言って弓を拭い、戦場でヴリシャセーナを的として——偉大な者は、カルナの子を戦場で殺すために矢を放った。
vivyādha cainaṃ daśabhiḥ pṛṣatkairmarmasvaśaṅkaṃ prahasankirīṭī|
ciccheda cāsyeṣvasanaṃ bhujau ca kṣuraiścaturbhirniśitaiḥ śiraśca||
// 8-90-13 //
笑いながら冠を戴く者は十本の矢で急所を射、四本の剃刀矢で弓と両腕と首を切り落とした。
sa pārthabāṇābhihataḥ papāta rathādvibāhurviśirā dharāyām|
supuṣpito vajrahato'timātro bhagno yathā sāla ivāvakṛttaḥ||
// 8-90-14 //
アルジュナの矢に打たれた彼は、両腕なく首なく戦車から大地に倒れた。花を咲かせた巨大なサーラ樹が金剛杵に打たれて折れるように。
taṃ pārthabāṇābhihataṃ patantaṃ samprekṣya karṇaḥ sutamāśukārī|
rathaṃ rathenāśu jagāma roṣātkirīṭinaḥ putravadhābhitaptaḥ||
// 8-90-15 (pūrvārdha) //
アルジュナの矢に打たれて倒れる息子を見て、素早き業のカルナは、息子の殺害に焼かれ、怒りから戦車でアルジュナの戦車に向かった。
以下は झ（jha）写本に見られる異伝詩節（8-90-15 後半〜24）
sañjaya uvāca|
tamāyāntamabhiprekṣya velodvṛttamivārṇavam|
garjantaṃ sumahākāyaṃ durnivāraṃ surairapi|
arjunaṃ prāha dāśārhaḥ prahasya puruṣarṣabhaḥ||
// 8-90-1 (jha) //
サンジャヤは語った。
波立つ海のように向かってくる、吼え叫ぶ巨体の、神々にも阻止し難い彼を見て——ダーシャールハ（クリシュナ）は笑いながらアルジュナに言った。
arya saratha āyāsi śvetāśvaḥ śalyasārathiḥ|
yena te saha yoddhavyaṃ sthiro bhava dhanañjaya||
// 8-90-2 (jha) //
「アルジュナよ、シャルヤを御者とする白い馬の戦車がやって来る。お前が戦わねばならぬ相手だ。ダナンジャヤよ、しっかり構えよ。」
paśya cainaṃ samāyuktaṃ rathaṃ karṇasya pāṇḍava|
śvetavājisamāyuktaṃ yuktaṃ rādhāsutena ca||
nānāpatākākalilaṃ kiṅkiṇījālamālinam|
uhyamānamivākāśo vimānaṃ pāṇḍurairhayaiḥ||
// 8-90-3-4 (jha) //
「パーンダヴァよ、カルナのこの戦車を見よ。白い馬に繋がれ、ラーダーの子に乗られている。様々な旗でにぎやかに、鈴の網で飾られ、白い馬に引かれて空に浮かぶ天の乗り物のように運ばれている。」
dhvajaṃ ca paśya karṇasya nāgakakṣaṃ mahātmanaḥ|
ākhaṇḍaladhanuḥprakhyamullikhantamivāmbaram||
// 8-90-5 (jha) //
「カルナの旗を見よ——偉大な者の象の綱の旗が、インドラの弓（虹）のように天を引っ掻いている。」
paśya karṇaṃ samāyāntaṃ dhārtarāṣṭrapriyaiṣiṇam|
śaradhārā vimuñcantaṃ dhārāsāramivāmbudam||
// 8-90-6 (jha) //
「見よ、カルナがやって来る、ドリタラーシュトラの利益を求めて。雨雲が雨を降らすように矢の流れを放ちながら。」
eṣa madreśvaro rājā rathāgre paryavasthitaḥ|
niyacchati hayānasya rādheyasyāmitaujasaḥ||
// 8-90-7 (jha) //
「マドラの王が戦車の前に控え、計り知れぬ力のラーデーヤの馬を操っている。」
śṛṇu dundubhinirghoṣaṃ śaṅkhaśabdaṃ ca dāruṇam|
siṃhanādāṃśca vividhāñśṛṇu pāṇḍava sarvataḥ||
// 8-90-8 (jha) //
「太鼓の轟音と法螺貝の恐ろしい音を聞け。パーンダヴァよ、様々な獅子吼を四方から聞け。」
antardhāya mahāśabdānkarṇenāmitatejasā|
dodhūyamānasya bhṛśaṃ dhanuṣaḥ śṛṇu niḥsvanam||
// 8-90-9 (jha) //
「計り知れぬ力のカルナの大いなる音を覆い隠し、激しく振り回される弓の鳴り響く音を聞け。」
ete dīryanti sagaṇāḥ pāñcālānāṃ mahārathāḥ|
dṛṣṭvā kesariṇaṃ kruddhaṃ mṛgā iva mahāvane||
// 8-90-10 (jha) //
「見よ、パーンチャーラの大戦車戦士たちが隊列もろとも崩れている。怒れる獅子を見た大いなる森の鹿のように。」
sarvayatnena kaunteya hantumarhasi sūtajam|
na hi karṇaśarānanyaḥ soḍhumutsahate naraḥ||
// 8-90-11 (jha) //
「カウンテーヤよ、全力でスータの子を殺すのだ。カルナの矢に耐えられる者は他にいない。」
sadevāsuragandharvāṃstrīṃllokānsacarācarān|
tvaṃ hi jetuṃ raṇe śaktastathaiva viditaṃ mama||
// 8-90-12 (jha) //
「神・アスラ・ガンダルヴァを含む三界の全てのもの、動くもの動かぬものを、お前は戦場で征服することができる。それは私もよく知っている。」
bhīmamugraṃ mahātmānaṃ tryakṣaṃ śarvaṃ kapardinam|
na śaktā draṣṭumīśānaṃ kiṃ punaryodhituṃ prabhum||
// 8-90-13 (jha) //
「恐ろしく、偉大な、三つ目のシャルヴァ（シヴァ神）、マタ髪のイーシャーナを、見ることさえできない者たちが、ましてや主と戦うことなどできようか。」
tvayā sākṣānmahādevaḥ sarvabhūtaśivaḥ śivaḥ|
yuddhenārādhitaḥ sthāṇurdevāśca varadāstava||
// 8-90-14 (jha) //
「お前は、大いなるマハーデーヴァ、全ての生き物に吉祥なるシヴァを、真の戦いで崇拝した。スターヌ（シヴァ神）と神々はお前に恩恵を授けた。」
tasya pārtha prasādena devadevasya śūlinaḥ|
jahi karṇaṃ mahābāho namuciṃ vṛtrahā yathā||
// 8-90-15 (jha) //
「アルジュナよ、神々の神、三叉の矛を持つ主の恩寵によって、大いなる腕の者よ、カルナを殺せ——ヴリトラハン（インドラ）がナムチを殺したように。」
śreyaste'stu sadā pārtha yuddhe jayamavāpnuhi||
// 8-90-16 (jha) //
「アルジュナよ、常に汝に幸いあれ。戦場で勝利を得よ。」
arjuna uvāca|
dhruva eva jayaḥ kṛṣṇa mama nāstyatra saṃśayaḥ|
sarvalokagururyastvaṃ tuṣṭo'si madhusūdana||
// 8-90-17 (jha) //
アルジュナは語った。
「クリシュナよ、勝利は確実だ。疑いはない。全世界の師たるお前が、マドゥスーダナよ、満足しているのだから。」
codayāśvānhṛṣīkeśa rathaṃ mama mahāratha|
nāhatvā samare karṇaṃ nivartiṣyati phalgunaḥ||
// 8-90-18 (jha) //
「フリシーケーシャよ、馬を走らせよ。大戦車戦士よ、我が戦車を。アルジュナは戦場でカルナを殺さずして引き返すまい。」
adya karṇaṃ hataṃ paśya maccharaiḥ śakalīkṛtam|
māṃ vā drakṣyasi govinda karṇena nihataṃ śaraiḥ||
// 8-90-19 (jha) //
「今日、カルナが我が矢で粉砕されて倒れるのを見よ。あるいは、ゴーヴィンダよ、カルナの矢に殺された私を見よ。」
upasthitamidaṃ ghoraṃ yuddhaṃ trailokyamohanam|
yajjanāḥ kathayiṣyanti yāvadbhūmirdhariṣyati||
// 8-90-20 (jha) //
「この恐ろしい、三界を惑わす戦いが目前に迫っている。大地が存続する限り人々が語り継ぐであろう戦いが。」
evaṃ bruvaṃstadā pārthaḥ kṛṣṇamakliṣṭakāriṇam|
pratyudyayau rathenāśu gajaṃ pratigajo yathā||
punarapyāha tejasvī pārthaḥ kṛṣṇamarindama|
codayāśvānhṛṣīkeśa kālo'yamativartate||
// 8-90-21-22 (jha) //
こうクリシュナに語りながら、困難を知らぬ業の者に——アルジュナは素早く戦車で向かった。象に向かう象のように。さらに光り輝くアルジュナは、敵を鎮める者として、クリシュナに言った。「フリシーケーシャよ、馬を走らせよ。時が過ぎようとしている。」
evamuktastadā tena pāṇḍavena mahātmanā|
jayena sampūjya sa pāṇḍavaṃ tadā pracodayāmāsa hayānmanojavān||
sa pāṇḍuputrasya ratho manojavaḥ kṣaṇena karṇasya rathāgrago'bhavat||
// 8-90-23-24 (jha) //
偉大なパーンダヴァにこう言われて、クリシュナは「勝利あれ」とパーンダヴァを称え、風のように速い馬を駆り立てた。パーンドゥの子の風のように速い戦車は、一瞬にしてカルナの戦車の前に到達した。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe navatitamo'dhyāyaḥ|| 90 ||
