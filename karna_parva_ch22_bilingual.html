マハーバーラタ ― カルナ篇 第22章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 22 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ22」（カルナがシャリヤの御者への任命を求める場面）です。各段落は原典の詩節番号（8-22-N）と和訳の段落番号が対応しています。なお本章より「第十六日の戦い」の日次句が原文の奥書から省かれています。
karṇaparva — dvāviṃśo'dhyāyaḥ (22)
第22章　カルナがシャリヤの御者への任命を求める
dhṛtarāṣṭra uvāca|
svena cchandena naḥ sarvān avadhīd vyaktam arjunaḥ|
na hyasya samare mucyed antako'pi ātatāyinaḥ|| // 8-22-1 //
ドリタラーシュトラは語った。 （1）アルジュナは己の意のままに、我らを皆殺しにした。武器を取ったこの者の前からは、死神すら戦場で逃れることはできまい。
pārtho hyeko'harad bhadrām ekaś ca agnim atarpayat|
ekaś ca imāṃ mahīṃ jitvā cakre balibhṛto nṛpān|| // 8-22-2 //
（2）パールタ（アルジュナ）はただ一人でスバドラーを連れ去り、一人で火神（アグニ）を満足させ（カーンダヴァの森を焼いた時）、一人でこの大地を征服して諸王を朝貢者とした。
eko nivātakavacanān ahanad divyakārmukaḥ|
ekaḥ kirātarūpeṇa sthitaṃ śarvam ayodhayat|| // 8-22-3 //
（3）一人でニヴァータカヴァチャの悪魔たちを神弓をもって倒し、一人で猟師の姿をとったシヴァ神と戦った。
eko hyarakṣad bharatān eko bhavam atoṣayat|
tenaikena jitāḥ sarve madīyā hyugratejasaḥ|| // 8-22-4 //
（4）一人でバーラタ族（ドゥルヨーダナたち）を守り（ガンダルヴァ族から救った時）、一人でシヴァ神を喜ばせた。あの恐るべき威光を持つただ一人の者に、我が者たちは皆打ち負かされた。
na te nindyāḥ praśasyāste yat te cakrur bravīhi tat|
tato duryodhanaḥ sūta paścāt kimakarottadā|| // 8-22-5 //
（5）彼らは責められるべきではない。讃えられるべきだ。彼らがなしたことを語ってくれ。そしてドゥルヨーダナはその後どうしたのか、サンジャヤよ。
sañjaya uvāca|
hataprahatavidhvastā vivarmāyudhavāhanāḥ|
dīnasvarā dūyamānā māninaḥ śatrunirjitāḥ||
śibirasthāḥ punarmantraṃ mantrayanti sma kauravāḥ|
bhagnadaṃṣṭrā hataviṣāḥ pādākrāntā iva uragāḥ|| // 8-22-6-7 //
サンジャヤは語った。 （6〜7）傷つき打たれ、打ちのめされ、鎧も武器も乗り物もなくし、弱々しい声で嘆き、誇り高い者たちでありながら敵に打ち負かされて——カウラヴァたちは陣営で再び軍議を行いました。折れた牙と失われた毒を持ち、足で踏みつけられた蛇のように。
tān abravīt tataḥ karṇaḥ kruddhaḥ sarpa iva śvasan|
karaṃ kareṇa niṣpīḍya prekṣamāṇas tava ātmajam|| // 8-22-8 //
（8）彼らに対してカルナは語りました。怒れる蛇のように荒い息をつき、拳を握り締め、あなたの息子（ドゥルヨーダナ）を見つめながら——
yattaḥ dṛḍhaś ca dakṣaś ca dhṛtimān arjunaḥ sadā|
sambodhayati cāpi enaṃ yathākālam adhokṣajaḥ|| // 8-22-9 //
（9）「アルジュナは常に用意周到で、堅固で、巧みで、忍耐力がある。そしてクリシュナが適切な時に彼を導いている。
sahasā'stravisargeṇa vayaṃ tenādya vañcitāḥ|
śvas tvahaṃ tasya saṅkalpaṃ sarvaṃ hantā mahīpate|| // 8-22-10 //
（10）突然の武器の放出によって、我々は今日騙された。しかし明日、私は彼の目論見をすべて打ち砕いてみせる、王よ。」
evam uktas tathetyuktvā so'nujajñe nṛpottamān|
te'nujñātā nṛpāḥ sarve svāni veśmāni bhejire|| // 8-22-11 //
（11）このように言われて、ドゥルヨーダナは「そのようにせよ」と答え、諸王たちに退出の許しを与えました。許された王たちは皆、自分の宿舎に帰りました。
sukhoṣitās tāṃ rajanīṃ hṛṣṭā yuddhāya niryayuḥ|
te'paśyan vihitaṃ vyūhaṃ dharmarājena durjayam|
prayatnāt kurumukhyena bṛhaspatyuśanomatāt|| // 8-22-12 //
（12）快く夜を過ごし、喜んで戦いに出撃した彼らは、ダルマ王（ユディシュティラ）がブリハスパティとウシャナスの知恵に基づいて、クル族の主として苦心して配置した、攻め難い陣形を目にしました。
atha pratīpakartāraṃ pravīraṃ paravīrahā|
sasmāra vṛṣabhaskandhaṃ karṇaṃ duryodhanas tadā|| // 8-22-13 //
（13）そこでドゥルヨーダナは、敵を制圧する勇者、敵の勇者を倒す者、雄牛の肩を持つカルナを思い出しました。
purandarasamaṃ yuddhe marudgaṇasamaṃ bale|
kārtavīryasamaṃ vīrye karṇaṃ rājño'gamanmanaḥ|| // 8-22-14 //
（14）戦場ではインドラに等しく、力ではマルト群神に等しく、武勇ではカールタヴィーリヤに等しいカルナに、王の心は向かいました。
sarveṣāṃ caiva sainyānāṃ karṇamevāgamanmanaḥ|
sūtaputraṃ maheṣvāsaṃ bandhumātyayikeṣu iva|| // 8-22-15 //
（15）すべての軍勢の心もまた、偉大な弓の達人なる御者の息子カルナに向かいました。危急の時の親族を頼るように。
dhṛtarāṣṭra uvāca|
tato duryodhanaḥ sūta paścāt kimakarottadā|
yadvo'gamanmano mandāḥ karṇaṃ vaikartanaṃ prati|| // 8-22-16 //
ドリタラーシュトラは語った。 （16）サンジャヤよ、その後ドゥルヨーダナはどうしたのか。愚かな者たちの心がヴァイカルタナ・カルナに向かったとすれば——
api apaśyata rādheyaṃ śītārtā iva bhāskaram|
kṛte'vahāre sainyānāṃ pravṛtte ca raṇe punaḥ|| // 8-22-17 //
（17）軍の退却の後、再び戦いが始まった時、彼らはラーデーヤ（カルナ）を見たのか？ 寒さに凍える者が太陽を見るように。
'duryodhanaṃ ca tatrājau pāṇḍavena bhṛśārditam|
parākrāntān pāṇḍusutān dṛṣṭvā'pi bhṛśārditam'|| // 8-22-18 //
（18）パーンダヴァに激しく苦しめられているドゥルヨーダナを見て、勇猛なるパーンドゥの息子たちを前にして——
kathaṃ vaikartanaḥ karṇas tatrāyudhyata sañjaya|
kathaṃ ca pāṇḍavāḥ sarve yuyudhus tatra sūtajam|| // 8-22-19 //
（19）ヴァイカルタナ・カルナはどのように戦ったのか、サンジャヤよ。そしてパーンダヴァたちは皆、どのように御者の子（カルナ）と戦ったのか。
karṇo hyeko mahābāhur hanyāt pārthān sasṛñjayān|
karṇasya bhujayorvīryaṃ śakraviṣṇusamaṃ yudhi|| // 8-22-20 //
（20）長い腕を持つカルナ一人で、パーンダヴァとスリンジャヤ族を殺せるだろう。カルナの両腕の力は戦場でインドラやヴィシュヌに等しい。
tasya śastrāṇi ghorāṇi vikramaśca mahātmanaḥ|
karṇamāśritya saṅgrāme matto duryodhano nṛpaḥ|| // 8-22-21 //
（21）彼の恐るべき武器と偉大なる魂の武勇——ドゥルヨーダナ王は戦場でカルナを頼みにして慢心している。
duryodhanaṃ tato dṛṣṭvā pāṇḍavena bhṛśārditam|
parākrāntānpāṇḍusutāndṛṣṭvā cāpi mahārathaḥ||
karṇamāśritya saṅgrāme mando duryodhanaḥ punaḥ|
jetumutsahate pārthān saputrān sahakeśavān|| // 8-22-22-23 //
（22〜23）パーンダヴァに激しく苦しめられるドゥルヨーダナを見、パーンドゥの子らの勇猛さを見ても、愚かなドゥルヨーダナは再び戦場でカルナを頼みにして、ケーシャヴァ（クリシュナ）を伴うパールタの息子たちを打ち負かそうとしている。
'yaḥ saubalaṃ tathā tāta nītimān iti manyate|
karṇaṃ cāgratimaṃ yuddhe devairapi durutsaham||
manyate'bhyadhikaṃ pārthād evaṃ ca asya hṛdi sthitam|
vijeṣyati raṇe karṇa ekaḥ pārthān sasomakān|
mama caiva sadā mandaḥ śaṃsate nityam agrataḥ'|| // 8-22-24-25 //
（24〜25）シャクニを策略家だと考え、カルナを戦場の第一人者で神々にも打ち勝てないと考え、パールタ（アルジュナ）より優れていると信じている。『カルナ一人で戦場においてパールタもソーマカ族も打ち負かすだろう』と、愚か者はいつも私の前で言い続けている。
aho bata mahadduḥkhaṃ yatra pāṇḍusutān raṇe|
nātarad rabhasaḥ karṇo daivaṃ nūnaṃ parāyaṇam|| // 8-22-26 //
（26）ああ、なんという大きな苦しみか。戦場でパーンドゥの子たちを打ち倒すことができなかった猛きカルナよ。運命こそが最も力あるものだ。
aho dyūtasya niṣṭheyaṃ ghorā samprati vartate|| // 8-22-27 //
（27）ああ、賭博の結末のこの恐ろしさが、今まさに現れている。
aho tīvrāṇi duḥkhāni duryodhanakṛtāni aham|
soḍhā ghorāṇi bahuśaḥ śalyabhūtāni sañjaya|| // 8-22-28 //
（28）ああ、ドゥルヨーダナが引き起こした激しく恐ろしい苦痛の数々を、私は何度も我が身の棘のように耐え忍んできた、サンジャヤよ。
saubalaṃ ca tadā tāta nītimān iti manyate|
karṇaś ca rabhaso nityaṃ rājā ta cāpi anuvrataḥ|| // 8-22-29 //
（29）シャクニを策略家だと考え、カルナは常に猛々しく、王（ドゥルヨーダナ）もまた彼に従っている。
yadevaṃ vartamāneṣu mahāyuddheṣu sañjaya|
aśrauṣaṃ nihatān putrān nityam eva vinirjitān|| // 8-22-30 //
（30）このような大戦争が行われている中で、サンジャヤよ、私は息子たちが殺され、常に打ち負かされていると聞き続けた。
na pāṇḍavānāṃ samare kaścid asti hataḥ kila|
strīmadhyam iva gāhante daivaṃ tu balavattaram|| // 8-22-31 //
（31）パーンダヴァ側には戦場で殺された者はほとんどいないという。彼らは女たちの中を歩くように恐れることなく敵陣を突き進む。まことに運命こそ最も強い。
sañjaya uvāca|
rājan pūrvanimittāni dharmiṣṭhāni vicintaya|
atikrāntaṃ hi yatkāryaṃ paścāccintayate naraḥ|
tac ca asya na bhavet kāryaṃ cintayā ca vinaśyati|| // 8-22-32-33 //
サンジャヤは語った。 （32〜33）王よ、過去の前兆や正義について考えなさい。なすべきことが過ぎ去った後に考える者は、そのなすべきことを取り戻すことはできず、悩みの中で滅んでいく。
tadidaṃ tava kāryaṃ tu dūraprāptaṃ vijānatā|
na kṛtaṃ yat tvayā pūrvaṃ prāptāprāptavicāraṇam|| // 8-22-34 //
（34）遠くまで事態が進んでいることを知りながら、あなたは以前に、正しいことと正しくないことの分別をしなかった。
ukto'si bahudhā rājñan mā yudhyasveti pāṇḍavaiḥ|
na ca tattvagrahīr dveṣāt pāṇḍaveṣu viśāmpate|| // 8-22-35 //
（35）王よ、あなたは何度もパーンダヴァたちから「戦うな」と言われた。しかしあなたはパーンダヴァへの憎しみゆえに、それを受け入れなかった。
tvayā pāpāni ghorāṇi samācīrṇāni pāṇḍuṣu|
tvatkṛte vartate ghoraḥ pārthivānāṃ janakṣayaḥ|| // 8-22-36 //
（36）あなたはパーンドゥの子らに対して恐ろしい罪を犯した。あなたのせいで、諸王の恐ろしい人々の殺戮が起こっているのだ。
tattvidānīmatikrāntaṃ mā śuco bharatarṣabha|
śṛṇu sarvaṃ yathāvṛttaṃ ghoraṃ vaiśasamucyate|| // 8-22-37 //
（37）しかし、過ぎたことは過ぎたこと。嘆くな、バーラタの雄牛よ。これから起こった恐ろしい殺戮のすべてを聞くがよい。
prabhātāyāṃ rajanyāṃ tu karṇo rājānamabhyayāt|
sametya ca mahābāhurduryodhanamathābravīt|| // 8-22-38 //
（38）夜が明けると、カルナは王（ドゥルヨーダナ）のもとを訪れ、長い腕を持つカルナはドゥルヨーダナにこう言いました。
karṇa uvāca|
adya rājan sameṣyāmi pāṇḍavena yaśasvinā|
nihaniṣyāmi taṃ vīraṃ sa vā māṃ nihaniṣyati|| // 8-22-39 //
カルナは語った。 （39）「今日、王よ、私は栄光あるパーンダヴァ（アルジュナ）と戦おう。あの勇者を殺すか、さもなくば彼が私を殺すだろう。
bahutvānmama kāryāṇāṃ tathā pārthasya bhārata|
nābhūt samāgamo rājan mama caivārjunasya ca|| // 8-22-40 //
（40）バーラタよ、私にもパールタにも多くの仕事があったため、王よ、私とアルジュナの直接対決は今までなかった。
idaṃ tu me yathāprajñaṃ śṛṇu vākyaṃ viśāmpate|
anihatya raṇe pārthaṃ nāhameṣyāmi bhārata|| // 8-22-41 //
（41）しかしこの私の言葉を、叡智のままに聞いてくれ、王よ。戦場でパールタを殺さぬ限り、私は戻らない、バーラタよ。
hatapravīre sainye'smin mayi cāvasthite yudhi|
abhiyāsyati māṃ pārthaḥ śakraśaktivinākṛtam|| // 8-22-42 //
（42）精鋭が倒されたこの軍勢にあって、私が戦場に立てば、パールタはインドラの槍を失った私に襲いかかるだろう。
tataḥ śreyaskaraṃ yacca tannibodha janeśvara|
āyudhānāṃ ca me vīryaṃ divyānām arjunasya ca|| // 8-22-43 //
（43）そこで、何がより良い結果をもたらすか、それを聞いてくれ、王よ。私の武器の力と、アルジュナの神聖な武器の力について——
kāryasya mahato bhede lāghave dūrapātane|
sauṣṭhave cāstrapāte ca savyasācī na matsamaḥ|| // 8-22-44 //
（44）なすべき仕事を破壊する力において、素早さにおいて、遠射において、武器の発射の巧みさにおいて、左右の手で射る者（アルジュナ）は私と同等ではない。
prāṇe śaurye'tha vijñāne vikrame cāpi bhārata|
nimittajñānayoge ca savyasācī na matsamaḥ|| // 8-22-45 //
（45）体力において、勇気において、知識において、武勇において、バーラタよ、照準の技術においても、左右の手で射る者は私と同等ではない。
sarvāyudhamahāmātraṃ vijayaṃ nāma tad dhanuḥ|
indrārthaṃ priyakāmena nirmitaṃ viśvakarmaṇā|| // 8-22-46 //
（46）すべての武器の中で最上の、ヴィジャヤという名の弓がある。インドラのために、彼を喜ばせようとしてヴィシュヴァカルマンが作ったものだ。
yena daityagaṇān rājañ jitavān vai śatakratuḥ|
yasya ghoṣeṇa daityānāṃ vyāmuhyanta diśo daśa|| // 8-22-47 //
（47）王よ、この弓でインドラは悪魔の群れを打ち負かした。その弓の轟きに、悪魔たちの十方の方角が混乱した。
tadbhārgavāya prāyacchacchakraḥ paramasammatam|
taddivyaṃ bhārgavo mahyam adadad dhanur uttamam|| // 8-22-48 //
（48）インドラはその最上の弓をバールガヴァ（パラシュラーマ）に与え、バールガヴァはその神聖な最上の弓を私に与えてくれた。
tena yotsye mahābāhumarjunaṃ jayatāṃ varam|
yathendraḥ samare sarvāndaiteyānvai samāgatān|
'nijaghāna tathā sarvāñjeṣyāmi yudhi pāṇḍavān'|| // 8-22-49 //
（49）その弓をもって、私は長い腕を持つアルジュナ、勝者の中の最上者と戦おう。インドラが戦場で集まった悪魔たちすべてを打ち倒したように、私もすべてのパーンダヴァを戦場で打ち倒そう。
dhanurghoraṃ rāmadattaṃ gāṇḍīvāt tad viśiṣyate|
trissaptakṛtvaḥ pṛthivī dhanuṣā yena nirjitā|| // 8-22-50 //
（50）パラシュラーマから授かった恐るべき弓は、ガーンディーヴァよりも優れている。その弓で三度七回（二十一回）大地が征服されたのだ。
dhanuṣo hyasya karmāṇi divyāni prāha bhārgavaḥ|
tadrāmo hyadadanmahyaṃ tena yotsyāmi pāṇḍavam|| // 8-22-51 //
（51）この弓の神聖な業についてバールガヴァが語ってくれた。パラシュラーマが私に与えてくれたその弓で、私はパーンダヴァと戦おう。
adya duryodhanāhaṃ tvāṃ nandayiṣye sabāndhavam|
nihatya samare vīramarjunaṃ jayatāṃ varam|| // 8-22-52 //
（52）今日、ドゥルヨーダナよ、私はお前を一族ともども喜ばせよう。勝者の中の最上者、勇者アルジュナを戦場で殺すことによって。
saparvatavanadvīpā hatavīrā sasāgarā|
putrapautrapratiṣṭhā te bhaviṣyatyadya pārthiva|| // 8-22-53 //
（53）山も森も島も持ち、大海に囲まれたこの大地は、勇者を失い、あなたの子孫のものとなるだろう、王よ。
nāśakyaṃ vidyate me'dya tvatpriyārthaṃ viśeṣataḥ|
samyagdharmānuraktasya siddhir ātmavato yathā|| // 8-22-54 //
（54）今日、あなたのために、特に不可能なことなど私にはない。正しく法に帰依する、心を制した者に成就があるように。
na hi me vikramaṃ soḍhuṃ sa śakto'gniṃ tarur yathā|
avaśyaṃ tu mayā vācyaṃ yena hīno'smi phalgunāt|| // 8-22-55 //
（55）あの者は私の武勇に耐えることはできない。火に対する木のように。しかし、私がアルジュナに劣る点について、必ず言わねばならない。
jyā tasya dhanuṣo divyā tathā'kṣayye maheṣudhī|
sārathis tasya govindo mama tādṛṅga vidyate|| // 8-22-56 //
（56）彼の弓の弦は神聖で、その大きな矢筒は尽きることがない。そして彼の御者はゴーヴィンダ（クリシュナ）だ——私にはそのような者がいない。
tasya divyaṃ dhanuḥ śreṣṭhaṃ gāṇḍīvamajitaṃ yudhi|
vijayaṃ ca mahaddivyaṃ mamāpi dhanuruttamam|| // 8-22-57 //
（57）彼の神聖にして最上の弓ガーンディーヴァは戦場で打ち負かされたことがない。しかし私のヴィジャヤという偉大で神聖な最上の弓もある。
tatrāhamadhikaḥ pārthād dhanuṣā tena pārthiva|
yena cāpyadhiko vīraḥ pāṇḍavas tan nibodha me|| // 8-22-58 //
（58）その弓において私はパールタより優れている、王よ。しかしこの勇者パーンダヴァが私より優れている点をお聞きなさい。
raśmigrāhaśca dāśārhaḥ sarvalokanamaskṛtaḥ|
agnidattaśca vai divyo rathaḥ kāñcanabhūṣaṇaḥ|| // 8-22-59 //
（59）手綱を握る者はダーシャールハ族の英雄（クリシュナ）で、全世界に敬われている。そして火神から授かった神聖な戦車は黄金で飾られている。
acchedyāḥ sarvato vīra vājinaśca manojavāḥ|
dhvajaśca divyo dyutimānvānaropi bhayaṅkaraḥ|| // 8-22-60 //
（60）勇者よ、あらゆる方角から切ることのできない、風のように速い馬がいる。そして神聖で光り輝く、恐ろしい猿の旗印がある。
kṛṣṇaśca jagataḥ sraṣṭā rathaṃ tamabhirakṣati|
ebhis tribhir ahaṃ hīno yuddhum icchāmi pāṇḍavam|| // 8-22-61 //
（61）世界の創造者クリシュナがその戦車を守っている。これら三つの点で私は劣っているが、それでもパーンダヴァと戦いたい。
ayaṃ tu sadṛśaḥ śaureḥ śalyaḥ samitiśobhanaḥ|
sārathyaṃ yadi me kuryād dhruvas te vijayo bhavet|| // 8-22-62 //
（62）しかし、ここにヴァースデーヴァ（クリシュナ）に匹敵する、戦場で輝くシャリヤがいる。もし彼が私の御者を務めてくれれば、あなたの勝利は確実だ。
tasya me sārathiḥ śalyo bhavatvasukaraḥ paraiḥ|
nārācān gārdhrapatrāṃś ca śakaṭāni vahantu me|| // 8-22-63 //
（63）シャリヤを私の御者としてくれ。そうすれば敵にとって手に負えない存在になれる。鷲の羽根のついた鉄の矢を、荷車に積んで私のもとへ運んでくれ。
rathāś ca mukhyā rājendra yuktā vājibhir uttamaiḥ|
āyāntu paścāt satataṃ māmeva bharatarṣabha|| // 8-22-64 //
（64）そして王の中の王よ、最上の馬を繋いだ主だった戦車を、常に後方から私についてこさせてくれ、バーラタの雄牛よ。
evamabhyadhikaḥ pārthād bhaviṣyāmi guṇair aham|
śalyo'py abhyadhikaḥ kṛṣṇād arjunād api ca api aham|| // 8-22-65 //
（65）こうすれば私は能力においてパールタを凌駕することになる。シャリヤはクリシュナより優れ、私はアルジュナより優れている。
yathā'śvahṛdayaṃ veda dāśārhaḥ paravīrahā|
tathā śalyo vijānīte hayajñānaṃ mahārathaḥ|| // 8-22-66 //
（66）ダーシャールハ族の英雄（クリシュナ）が馬の心を知るように、シャリヤもまた偉大な戦車戦士として馬の知識に精通している。
bāhuvīrye samo nāsti madrarājasya kaścana|
tathā'stre matsamo nāsti kaścideva dhanurdharaḥ|| // 8-22-67 //
（67）腕の力において、マドラ王に匹敵する者はこの世にいない。同様に武器の技量において、私に等しい弓の使い手もいない。
tathā śalyasamo nāsti hayajñāne hi kaścana|
so'yamabhyadhikaḥ kṛṣṇād bhaviṣyati ratho mama|| // 8-22-68 //
（68）馬の知識においても、シャリヤに匹敵する者はいない。こうすれば私の戦車はクリシュナの戦車を凌駕するだろう。
evaṃ kṛte rathastho'haṃ guṇair abhyadhiko'rjunāt|
vijayeyamahaṃ saṅkhye phalgunaṃ kurusattama|| // 8-22-69 //
（69）このようにすれば、戦車に乗った私は能力においてアルジュナを超え、戦場でアルジュナを打ち負かすことができる、クルの最上者よ。
samudyātuṃ na śakṣyanti devā api savāsavāḥ|
etatkṛtaṃ mahārāja tvayecchāmi parantapa|| // 8-22-70 //
（70）インドラをはじめとする天の神々すらも立ち向かうことができないだろう。大王よ、これを実行してほしい、敵を滅ぼす者よ。
kriyatāmeṣa kāmo me mā vaḥ kālo'tyagādayam|
evaṃ kṛte kṛtaṃ mahyaṃ tvayā sarvaṃ bhaviṣyati|| // 8-22-71 //
（71）この願いをかなえてくれ。時を逃してはならない。こうすれば、あなたは私のためにすべてをなしたことになる。
tato drakṣyasi saṅgrāme yat kariṣyāmi bhārata|
sarvathā pāṇḍavān saṅkhye vijeṣye vai samāgatān|| // 8-22-72 //
（72）そうすれば、バーラタよ、戦場で私が何をなすか見届けるがよい。必ずやパーンダヴァたちを戦場で打ち負かそう。
na hi me samare śaktāḥ samudyātuṃ surāsurāḥ|
kimu pāṇḍusutā rājan raṇe mānuṣayonayaḥ|| // 8-22-73 //
（73）戦場で私に立ち向かうことは、天の神も阿修羅もできない。まして人間から生まれたパーンドゥの子らが、王よ、戦場でどうして耐えられよう。」
sañjaya uvāca|
evam uktas tava sutaḥ karṇenāhavaśobhinā|
sampūjya samprahṛṣṭātmā tato rādheyamabravīt|| // 8-22-74 //
サンジャヤは語った。 （74）戦場で輝くカルナにこのように言われて、あなたの息子は彼を讃え、喜びに満ちた心で、ラーデーヤ（カルナ）にこう言いました。
duryodhana uvāca|
evam etat kariṣyāmi yathā tvaṃ karṇa manyase|
sopāsaṅgā rathāḥ sāśvāḥ svanuyāsyanti saṃyuge|| // 8-22-75 //
ドゥルヨーダナは語った。 （75）「お前が考えるとおりにしよう、カルナよ。従者を付けた戦車と馬が、戦場でお前について行くだろう。
nārācān gārdhrapatrāṃś ca śakaṭāni vahantu te|
anuyāsyāma karṇa tvāṃ vayaṃ sarve ca pārthivāḥ|| // 8-22-76 //
（76）鷲の羽根のついた鉄の矢を荷車に積んで運ばせよう。カルナよ、我ら全員と諸王がお前に従おう。」
sañjaya uvāca|
evamuktvā mahārāja tava putraḥ pratāpavān|
abhigamyābravīd rājā madrarājam idaṃ vacaḥ|| || // 8-22-77 //
サンジャヤは語った。 （77）大王よ、こう語ると、あなたの威厳ある息子は、マドラ王のもとに行き、次の言葉を述べました。
iti śrīmanmahābhārate karṇaparvaṇi dvāviṃśo'dhyāyaḥ|| 22 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十二章は終わる。
