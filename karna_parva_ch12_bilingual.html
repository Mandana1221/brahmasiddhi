本章は南伝（Southern Recension）テキストの「アディヤーヤ12」（ビーマとアシュヴァッターマンの子（ドローニ）の戦い。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-12-N）と和訳の段落番号が対応しています。
karṇaparva — dvādaśo'dhyāyaḥ (12)
第12章　ビーマとアシュヴァッターマンの戦い
sañjaya uvāca|
bhīmasenaṃ tato drauṇī rājan vivyādha patriṇā|
parayā tvarayā yukto darśayan astralāghavam|| // 8-12-1 //
サンジャヤは語った。 （1）王よ、ドローナの子は極めて素早く、武器の軽妙さを見せつけながら、羽根つき矢でビーマセーナを射ちました。
athainaṃ punar ājaghne navatyā niśitaiḥ śaraiḥ|
sarvamarmāṇi samprekṣya marmajño laghuhastavat|| // 8-12-2 //
（2）さらに九十本の鋭い矢で、急所を知る者として軽い手さばきで、すべての急所を見極めて彼を打ちました。
bhīmasenaḥ samākīrṇo drauṇinā niśitaiḥ śaraiḥ|
rarāja samare rājan raśmivāniva bhāskaraḥ|| // 8-12-3 //
（3）王よ、ドローナの子の鋭い矢に覆われたビーマセーナは、戦場で光線をまとった太陽のように輝きました。
tataḥ śarasahasreṇa suprayuktena pāṇḍavaḥ|
droṇaputram avacchādya siṃhanādam amuñcata|| // 8-12-4 //
（4）パーンダヴァ（ビーマ）は巧みに放った何千もの矢でドローナの息子を覆い尽くし、獅子の咆哮を上げました。
śaraiḥ sarāṃstato drauṇiḥ saṃvārya yudhi pāṇḍavam|
lalāṭe'bhyāhanad rājan nārācena smayanniva|| // 8-12-5 //
（5）ドローナの子は矢で矢を打ち払い、パーンダヴァを制して、王よ、微笑むかのように鉄の矢でビーマの額を射ちました。
lalāṭasthaṃ tato bāṇaṃ dhārayāmāsa pāṇḍavaḥ|
yathā śṛṅgaṃ vane dṛptaḥ khaṅgo dhārayate nṛpa|| // 8-12-6 //
（6）パーンダヴァは額に刺さった矢を耐え忍びました。王よ、森で誇り高い犀が角を支えるように。
tato drauṇiṃ raṇe bhīmo yatamānaṃ parākramī|
tribhir vivyādha nārācair lalāṭe vismayanniva|| // 8-12-7 //
（7）勇猛なるビーマは、戦場で奮闘するドローナの子の額に、微笑むかのように三本の鉄の矢を打ち込みました。
lalāṭasthais tato bāṇair brāhmaṇo'sau vyaśobhata|
prāvṛṣīva yathā siktas triśṛṅgaḥ parvatottamaḥ|| // 8-12-8 //
（8）額に矢を立てたそのバラモン（アシュヴァッターマン）は、雨季に水をたたえた三つの峰を持つ最上の山のように美しく輝きました。
tataḥ śaraśatair drauṇir ardayāmāsa pāṇḍavam|
na cainaṃ kampayāmāsa mātariśveva parvatam|| // 8-12-9 //
（9）ドローナの子は何百もの矢でパーンダヴァを攻め立てましたが、彼を揺るがすことはできませんでした。風が山を揺るがせないように。
tathaiva pāṃṇḍavo yuddhe drauṇiṃ śaraśataiḥ śitaiḥ|
nākampayata saṃhṛṣṭo vāryodha iva parvatam|| // 8-12-10 //
（10）同様にパーンダヴァも、何百もの鋭い矢で戦場のドローナの子を揺るがすことができませんでした。喜びに満ちていながらも。水の奔流が山を揺るがせないように。
tāvanyonyaṃ śarair ghoraiś chādayānau mahārathau|
rathavaryagatau vīrau śuśubhāte balotkaṭau|| // 8-12-11 //
（11）互いに恐るべき矢で覆い合う二人の偉大な戦車戦士は、最上の戦車に乗り、力に満ちた勇者として美しく輝きました。
ādityāviva sandīptau lokakṣayakarāvubhau|
svaraśmibhir ivānyonyaṃ tāpayantau śarottamaiḥ|| // 8-12-12 //
（12）二つの燃え上がる太陽のように、共に世界を滅ぼしうる者として、互いに光線のような最上の矢で焼き合いました。
tataḥ pravikṛte yatnaṃ kurvāṇau tau mahāraṇe|
kṛtapratikṛte yattau śarasaṅghair abhītavat|| // 8-12-13 //
（13）この大戦闘で二人は、攻撃と反撃に全力を尽くし、矢の群れをもって恐れることなく戦いました。
vyāghrāviva ca saṅgrāme ceratus tau narottamau|
śaradaṃṣṭrau durādharṣau cāpavakrau bhayaṅkarau|| // 8-12-14 //
（14）二人の最上の人は、戦場で二頭の虎のように動きました。矢を牙とし、弓を湾曲した体とし、恐ろしく近づき難い者として。
abhūtāṃ tāvadṛśyau ca śarajālaiḥ samantataḥ|
meghajālair iva cchanau gagane candrabhāskarau|| // 8-12-15 //
（15）矢の網に四方から覆われた二人は、見えなくなりました。空の月と太陽が雲の網に隠されるように。
cakāśete muhūrtena tatas tāvapyarindamau|
vimuktāvabhrajālena aṅgārakabudhāviva|| // 8-12-16 //
（16）しかしやがて一瞬、敵を滅ぼすその二人は姿を現しました。雲の幕から解放された火星と水星のように。
atha tatraiva saṅgrame vartamāne sudāruṇe|
apasavyaṃ tataścakre drauṇistatra vṛkodaram|| // 8-12-17 //
（17）この恐るべき戦闘が続く中、ドローナの子はビーマを左側に回り込みました（不吉な回り方＝攻撃的旋回）。
kirañ charaśatair ugrair dhārābhir iva parvatam|
na tu tanmamṛṣe bhīmaḥ śatror vijalakṣaṇam|| // 8-12-18 //
（18）何百もの猛烈な矢の雨を、山に降り注ぐ豪雨のように浴びせましたが、ビーマは敵のこの勝利の徴を許しませんでした。
praticakre tato rājan pāṇḍavo'pyapasavyataḥ|
maṇḍalānāṃ vibhāgena gatapratyāgatena ca|| // 8-12-19 //
（19）王よ、パーンダヴァもまた左方への旋回を行いました。円形の機動の配分と、前進後退の技によって。
babhūva tumulaṃ yuddhaṃ tayoḥ puruṣasiṃhayoḥ|
caritvā vividhān mārgān maṇḍalasthānam eva ca|| // 8-12-20 //
（20）さまざまな機動の道筋と円形の陣を駆使した後、二人の人の中の獅子の間に激しい戦闘が繰り広げられました。
śaraiḥ pūrṇāyatotsṛṣṭair anyonyam abhijaghnatuḥ|
anyonyasya vadhe caiva cakratur yatnam uttamam|| // 8-12-21 //
（21）十分に引き絞って放たれた矢で互いを打ち合い、互いの殺害に最善の努力を傾けました。
īṣatur virathaṃ caiva kartum anyonyam āhave|
tato drauṇir mahāstrāṇi prāduścakre mahārathaḥ|| // 8-12-22 //
（22）二人は戦場で互いの戦車を失わせようと望みました。そこでドローナの子という偉大な戦車戦士は、大いなる天の武器を発動させました。
tāny astraireva samare pratijaghne'tha pāṇḍavaḥ|
tato ghoraṃ mahārāja astrayuddham avartata|| // 8-12-23 //
（23）パーンダヴァは戦場でそれを自らの武器で打ち消しました。そして大王よ、恐ろしい武器対武器の戦いとなりました。
grahayudvaṃ yathā ghoraṃ prajāsaṃharaṇe hyabhūt|
te vāṇāḥ samasajjanta muktās tābhyāṃ tu bhārata|| // 8-12-24 //
（24）生き物を滅ぼす時の遊星同士の恐ろしい衝突のようでした。バーラタよ、二人が放った矢は互いにぶつかり合いました。
dyotagranto diśaḥ sarvāstava sainyaṃ samantataḥ|
bāṇasaṅghair vṛtaṃ ghoramākāśaṃ samapadyata|| // 8-12-25 //
（25）四方の空を照らしながら飛び交い、あなたの軍の周囲の空は、矢の群れで恐ろしく覆われました。
ulkāpātāvṛtaṃ yuddhaṃ prajānāṃ saṃkṣaye nṛpa|
bāṇābhighātāt sañjajñe tatra bhārata pāvakaḥ|| // 8-12-26 //
（26）王よ、生き物が滅びる時の流星の雨に覆われた戦場のようでした。バーラタよ、矢の衝突から火が生まれました。
savisphuliṅgo dīptārcir yo'dahad vāhinīdvayam|
tatra siddhā mahārāja sampatanto'bruvan vacaḥ|| // 8-12-27 //
（27）火花を散らし、燃え上がる炎を上げて、両軍を焼く火が。大王よ、そこに天上の成就者たちが降りてきて、こう語りました。
yuddhānāmati sarveṣāṃ yuddham etaditi prabho|
sarvayuddhāni caitasya kalāṃ nārhanti ṣoḍaśīm|| // 8-12-28 //
（28）「主よ、すべての戦いの中で、この戦いこそが最上だ。他のすべての戦いは、この戦いの十六分の一にも値しない。
nedṛśaṃ ca punaryuddhaṃ bhaviṣyati kadācana|
aho jñānena sampannāvubha brāhmaṇakṣatriyau|| // 8-12-29 //
（29）このような戦いは二度と起こるまい。ああ、バラモンとクシャトリヤの二人は、共に知識に満ちている。
aho śauryeṇa sampannāvubhau cograparākramau|
aho bhīmabalo bhīma etasya ca kṛtāstratā|| // 8-12-30 //
（30）ああ、勇気に満ちた二人は、共に猛烈な武勇を持つ。ああ、ビーマの恐るべき力よ。そしてこの者（アシュヴァッターマン）の武器の技量よ。
aho vīryasya sāratvam aho sauṣṭhavam etayoḥ|
sthitāvetau hi samare kālāntakayamopamau|| // 8-12-31 //
（31）ああ、武勇の精髄よ。ああ、この二人の巧みさよ。戦場に立つこの二人は、終末の時の死神と閻魔に等しい。
rudrau dvāvi sambhūtau yathā dvāviva bhāskarau|
yamau vā puruṣavyāghrau ghorarūpāvubhau raṇe|| // 8-12-32 //
（32）二人のルドラが生まれたかのようだ。二つの太陽のようだ。人の中の虎、双子の閻魔のようだ。戦場で恐ろしい姿の二人。」
iti vācaḥ sma śrūyante siddhānāṃ vai muhurmuhuḥ|
siṃhanādaś ca sañjajñe sametānāṃ divaukasām|| // 8-12-33 //
（33）成就者たちのこのような声が、何度も何度も聞こえました。集まった天の住人たちの間から獅子の咆哮が湧き起こりました。
adbhutaṃ cāpyacintyaṃ ca dṛṣṭvā karma tayo raṇe|
sidvacāraṇasaṅghānāṃ vismayaḥ samapadyata|| // 8-12-34 //
（34）戦場での二人の驚くべき、想像を絶する業を見て、成就者とチャーラナの群れは驚嘆しました。
praśaṃsanti tadā devāḥ sidvāśca paramarṣayaḥ|
sādhu drauṇe mahābāho sādhu bhīmeti cābruvan|| // 8-12-35 //
（35）天の神々と成就者と大聖仙たちはその時讃えました。「見事だドローナの子よ、大いなる腕よ。見事だビーマよ」と。
tau śūrau samare rājan parasparakṛtāgasau|
parasparamudīkṣetāṃ krodhād udvṛtya cakṣuṣī|| // 8-12-36 //
（36）王よ、互いに害をなした二人の勇者は、怒りに目を見開いて互いを睨みつけました。
krodharaktekṣaṇau tau tu krodhāt prasphuritādharau|
krodhāt saṃdaṣṭadaśanau tathaiva daśanacchadau|| // 8-12-37 //
（37）怒りに赤くなった目、怒りに震える唇、怒りに歯を食いしばり、唇を噛む二人。
anyonyaṃ chādayantau sma śaravṛṣṭyā mahārathau|
śarāmbudhāro samare śastravidyutprakāśinau|| // 8-12-38 //
（38）偉大な戦車戦士の二人は、戦場で矢の雨で互いを覆い合い、矢の水流と武器の稲光で輝いていました。
tāvanyanyaṃ dhvajaṃ vidvvā sārathiṃ ca mahāraṇe|
anyonyasya hayān vidvā bibhidāte parasparam|| // 8-12-39 //
（39）大戦闘で互いの旗を射ち、互いの御者を射ち、互いの馬を射ち合いました。
tataḥ kruddhau mahārāja bāṇau gṛhya mahāhave|
ubhau cikṣipatus tūrmam anyonyasya vadhaiṣiṇau|| // 8-12-40 //
（40）大王よ、怒りに満ちた二人は大戦闘で互いに矢を取り、互いの殺害を望んで素早く放ちました。
tau sāyakau mahārāja dyotamānau camūmukhe|
ājaghnatuḥ samāsādya vajravegau durāsadau|| // 8-12-41 //
（41）大王よ、軍の正面で輝く二本の矢は、金剛杵の速さと近づき難さをもって互いを打ちました。
tau parasparavegāc ca śarābhyāṃ ca bhṛśāhatau|
nipetatur mahāvīryau rathopasthe tayostadā|| // 8-12-42 //
（42）互いの勢いと矢に激しく打たれた、大いなる武勇の二人は、それぞれの戦車の上にその場で倒れました。
tatastu sārathir jñātvā droṇaputram acetanam|
apovāha raṇād rājan sarvasainyasya paśyataḥ|| // 8-12-43 //
（43）御者はドローナの子が意識を失ったのを知り、王よ、全軍が見守る中、彼を戦場から運び出しました。
tathaiva pāṇḍavaṃ rājan vihvalantaṃ muhurmuhuḥ|
apovāha rathenājau viśokaḥ śatrutāpanam|| // 8-12-44 //
（44）同様に、王よ、繰り返しふらつくパーンダヴァ（ビーマ）を、ヴィショーカ（ビーマの御者）は敵を悩ます者を戦車に乗せたまま戦場から運び出しました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe dvādaśo'dhyāyaḥ|| 12 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十二章は終わる。
