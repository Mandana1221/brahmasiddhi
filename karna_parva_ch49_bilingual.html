マハーバーラタ ― カルナ篇 第49章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 49 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ49」（入り乱れての混戦が続く全49詩節の章）です。サンジャヤが語るところによれば、クリタヴァルマン・クリパ・ドローナの子（アシュヴァッターマン）・カルナ・ウルーカ・シャクニらに守られたドゥルヨーダナ軍は、沈みかけた船のように崩れゆくパーンダヴァ軍に急いで加勢します。クリパとシカンディンの一対一の激闘（バラモンであるクリパに矢の雨を降らせる場面）、クリパが矢でシカンディンの戦車を破壊し、剣を取って徒歩で立ち向かうシカンディンの様子、ドリシュタデュムナによるクリパへの加勢と、クリタヴァルマン・ドローナの子・カルナらによる迎撃が描かれます。後半では、スケトゥ（チトラケートゥの子）がクリパに挑むも討たれ、首と装飾品ごと首を斬り落とされて倒れる凄惨な場面（第27〜30詩節）、ドリシュタデュムナとクリタヴァルマンの一対一の死闘（互いに「止まれ、止まれ」と呼びかけ合いながら棍棒で打ち合う場面、第31〜46詩節）が中心となります。クリタヴァルマンは一時棍棒で打たれて昏倒しますが、シュルタルヴァに戦車に乗せられて戦場から運び去られます（第47詩節）。章末では、ドリシュタデュムナがクル軍を矢で抑え、獅子吼をあげる両軍の戦士たちが入り乱れて戦い続ける場面で終わります（第49詩節）。なお、原典の奥書（コロフォン）には第40・42〜48章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典にも、前章（第48章）と同様、本来の第1〜49詩節の連番に先立って余分な注記「8-49-0」が冒頭の「サンジャヤは語った」の一文に付されているという特異な誤記が見られたため、これを第1詩節の本文に統合した上で全49詩節を正しく分離・対訳しています。なお、第32・33・44・47詩節には「द्व」（dva）と「द्ध」（ddha）の字形混同によると見られるOCR誤記（yudvaṃ→yuddhaṃ、krudvaḥ→kruddhaḥ、yudve→yuddhe、so'tividvo→so'tividdho）が含まれていたため、文脈上明らかな箇所のみ訂正しています。
karṇaparva — ekonapañcāśo'dhyāyaḥ (49)
第49章
sañjaya uvāca|
kṛtavarmā kṛpo drauṇiḥ sūtaputraś ca māriṣa|
ulūkaḥ saubalaś ca eva rājā ca saha sodaraiḥ|| // 8-49-1 //
サンジャヤは語った。 （1）クリタヴァルマン、クリパ、ドローナの子（アシュヴァッターマン）、御者の子（カルナ）、ウルーカ、シャクニ（スバラの子）、そして兄弟たちと共にいる王（ドゥルヨーダナ）は――。
sīdamānāṃ camūṃ dṛṣṭvā pāṇḍuputrabhayārditām|
samujjahruḥ sma vegena bhinnāṃ nāvam iva arṇave|| // 8-49-2 //
（2）パーンダヴァの子（ビーマ）の恐怖に苦しむ軍が沈むのを見て、海で壊れた船のように沈むのを見て、急いで支えようとした。
tato yuddham atīva āsīn muhūrtam iva bhārata|
bhīrūṇāṃ trāsajananaṃ śūrāṇāṃ harṣavardhanam|| // 8-49-3 //
（3）そしてしばらくの間、戦いは極めて激しくなった。臆病者には恐れを、勇者には喜びをもたらすものだった。
kṛpeṇa śaravarṣāṇi pratimuktāni saṃyuge|
sṛñjayāṃś chādayāmāsuḥ śalabhānāṃ vrajā iva|| // 8-49-4 //
（4）クリパは矢の雨を戦場で放ち、スリンジャヤ族をイナゴの群れのように覆った。
śikhaṇḍī ca tataḥ kruddho gautamaṃ tvarito yayau|
vavarṣa śaravarṣāṇi samantād dvijapuṅgavam|| // 8-49-5 //
（5）そして怒ったシカンディンはガウタマ（クリパ）に急いで向かい、矢の雨をあたり一面に、二生の雄牛（バラモン）に降らせた。
kṛpastu śaravarṣaṃ tad vinihatya mahāstravit|
śikhaṇḍinaṃ raṇe kruddho vivyādha daśabhiḥ śaraiḥ|| // 8-49-6 //
（6）クリパは大武器通で、その矢の雨を打ち消し、戦場で怒って、シカンディンを十本の矢で射た。
tataḥ śikhaṇḍī kupitaḥ śaraiḥ saptabhir āhave|
kṛpaṃ vivyādha kupitaṃ kaṅkapatrair ajihmagaiḥ|| // 8-49-7 //
（7）怒ったシカンディンは七本の矢で、戦場で怒ったクリパを、カンカ鳥のまっすぐな羽根矢で射た。
tataḥ kṛpaḥ śarais tīkṣṇaiḥ so'tividdho mahārathaḥ|
'tataḥ suniśitais tīkṣṇaiḥ kṣuraprair hemabhūṣitaiḥ'|
vyaśvasūtarathaṃ cakre śikhaṇḍinam atho dvijaḥ|| // 8-49-8 //
（8）そしてクリパは、深く射抜かれ、鋭い矢で苦しみ、偉大な戦車戦士は、シカンディンを馬・御者・戦車のない者にした、二生者（バラモン）は。
hatāśvāt tu tato yānād avaplutya mahārathaḥ|
khaṅgaṃ carma tathā gṛhya satvaraṃ brāhmaṇaṃ yayau|| // 8-49-9 //
（9）馬を殺された偉大な戦車戦士は、戦車から飛び降り、剣と盾を取って急いでバラモンに向かった。
tam āpatantaṃ sahasā śaraiḥ sannataparvabhiḥ|
vārayāmāsa samare tad adbhutam iva abhavat|| // 8-49-10 //
（10）急に襲いかかる彼を、節のまっすぐな矢で、戦場で抑えた。それは驚異のようであった。
tatra adbhutam apaśyāma śilānāṃ plavanaṃ yathā|
niśceṣṭo yad raṇe rājañ chikhaṇḍī samatiṣṭhata|| // 8-49-11 //
（11）石の板が浮かぶように、驚くべき光景が見られた。王よ、戦場でシカンディンは動けず立ち尽くしていた。
kṛpeṇa vāritaṃ dṛṣṭvā śikhaṇḍinam atho nṛpa|
pratyudyayau kṛpaṃ tūrṇaṃ dhṛṣṭadyumno mahārathaḥ|| // 8-49-12 //
（12）シカンディンが止められているのを見て、王よ、偉大な戦車戦士ドリシュタデュムナはすぐにクリパに向かった。
dhṛṣṭadyumnaṃ tato yāntaṃ śāradvatarathaṃ prati|
pratijagrāha vegena kṛtavarmā mahārathaḥ|| // 8-49-13 //
（13）シャラドヴァットの戦車に向かうドリシュタデュムナを、偉大な戦車戦士クリタヴァルマンが素早く受け止めた。
yudhiṣṭhiram atha āyāntaṃ śāradvatarathaṃ prati|
saputraṃ sahasainyaṃ ca droṇaputro nyavārayat|| // 8-49-14 //
（14）シャラドヴァットの戦車に向かうユディシュティラを、息子と軍と共にいる彼を、ドローナの子（アシュヴァッターマン）が阻んだ。
nakulaṃ sahadevaṃ ca tvaramāṇau mahārathau|
pratijagrāha te putraḥ śaravarṣeṇa vārayan|| // 8-49-15 //
（15）急ぐ偉大な戦車戦士ナクラとサハデーヴァを、あなたの息子（ドゥルヨーダナ？）は、矢の雨で受け止めた。
bhīmasenaṃ karūśāṃś ca kekayān saha sṛñjayaiḥ|
karṇo vaikartano yuddhe vārayāmāsa bhārata|| // 8-49-16 //
（16）ビーマセーナとカールーシャ族・ケーカヤ族、スリンジャヤ族を、カルナ（ヴィカルタナの子）が戦場で押えた、バーラタよ。
śikhaṇḍine tato bāṇān kṛpaḥ śāradvato yudhi|
prāhiṇot tvarayā yukto bībhatsor atha sannidhau|| // 8-49-17 //
（17）シカンディンにそれから矢を、クリパ（シャラドヴァットの子）が戦場で放った、素早くアルジュナの近くで。
tāñ charān preṣitāṃs tena samantāt svarṇabhūṣitān|
ciccheda khaṅgamāvidhya bhrāmayaṃś ca punaḥ punaḥ|| // 8-49-18 //
（18）彼が放った、金の飾られた矢を、剣を振り回して繰り返し切り裂いた。
śatacandraṃ ca tac carma gautamastasya bhārata|
vyadhamat sāyakais tūrṇaṃ tata uccukruśur janāḥ|| // 8-49-19 //
（19）百の月が描かれたその盾を、ガウタマ（クリパ）はその矢で、素早く壊した、バーラタよ。人々は叫び声をあげた。
sa vicarmā mahārāja khaṅgapāṇir upādravat|
kṛpastaṃ śarasaṅghātair ādravantam apīḍayat|| // 8-49-20 //
（20）盾を失った大王よ、剣を手に急いで向かうのを、クリパは矢の束で攻める彼を苦しめた。
śāradvataśarair grastaṃ kliśyamānaṃ mahābalaḥ|
citraketusuto rājan suketus tvarito yayau|| // 8-49-21 //
（21）シャラドヴァットの矢に捕われて苦しむその者を、大力のチトラケートゥの子スケートゥは、王よ、急いで行った。
vikiranbrāhmaṇaṃ yuddhe bahubhir niśitaiḥ śaraiḥ|
abhyāpatadameyātmā gautamasya rathaṃ prati|| // 8-49-22 //
（22）戦場で多くの鋭い矢でそのバラモンを覆いながら、無量の魂をもつ者は、ガウタマの戦車に向かって襲いかかった。
dṛṣṭvā viṣaktaṃ taṃ caiva brāhmaṇaṃ ca nivāritam|
apayātas tatas tūrṇaṃ śikhaṇḍī rājasattama|| // 8-49-23 //
（23）そのバラモンが縛られ、止められたのを見て、シカンディンは素早く逃げ去った、王の最上者よ。
suketus tu tato rājan gautamaṃ navabhiḥ śaraiḥ|
viddhvā vivyādha saptatyā punaś ca enaṃ tribhiḥ śaraiḥ|| // 8-49-24 //
（24）スケートゥは、王よ、ガウタマ（クリパ）を九本の矢で射、七十本でさらに射、三本の矢で再び射た。
athāsya saśaraṃ cāpaṃ punaściccheda māriṣa|
sārathiṃ ca śareṇāsya mṛśaṃ marmasu atāḍayat|| // 8-49-25 //
（25）そして、矢と共にあった彼の弓をまた切り落とした、敬うべき方よ。そしてその御者を、矢で急所に激しく打った。
gautamastu tataḥ kruddho dhanurgṛhya navaṃ dṛḍham|
suketuṃ triṃśatā bāṇaiḥ sarvamarmasu atāḍayat|| // 8-49-26 //
（26）するとガウタマは怒り、新しい堅固な弓を取って、スケートゥを三十本の矢で、あらゆる急所に打った。
sa vihvalitasarvāṅgaḥ pracacāla rathottame|
bhūmikampe yathā vṛkṣaś cacāla ākampito bhṛśam|| // 8-49-27 //
（27）全身を動揺させられて、最高の戦車でよろめいた。大地震の時の木のように、激しく揺れた。
calatastasya kāyāttuṃ śiro jvalitakuṇḍalam|
soṣṇīṣaṃ saśirastrāṇaṃ kṣurapreṇa tvapātayat|| // 8-49-28 //
（28）震える彼の体から、燃える耳輪のついた頭を、頭巾や兜と共に、剃刀矢で落とした。
tacchiraḥ prāpatadbhūmau śyenāhṛtam iva āmiṣam|
tato'sya kāyo vasudhāṃ paścāt prāpatad acyuta|| // 8-49-29 //
（29）その頭は大地に落ちた。鷹に連れ去られた肉片のように。その後、彼の体も大地に倒れた、王よ。
tasmin hate mahārāja putrāstasya padānugāḥ|
gautamaṃ samare tyaktvā dudruvuste diśo daśa|| // 8-49-30 //
（30）大王よ、彼が殺されたとき、付き従っていた息子たちは、戦場でガウタマ（クリパ）を捨てて十方に逃げた。
dhṛṣṭadyumnaṃ tu samare sannivārya mahārathaḥ|
kṛtavarmā'bravīd vṛṣṭas tiṣṭha tiṣṭheti bhārata|| // 8-49-31 //
（31）戦場でドリシュタデュムナを押えて偉大な戦車戦士は、クリタヴァルマンが雨を降らせるように言った、「止まれ、止まれ」と、バーラタよ。
tad abhūt tumulaṃ yuddhaṃ vṛṣṇipārṣatayo raṇe|
āmiṣārthe yathā yuddhaṃ śyenayoḥ kruddhayor nṛpa|| // 8-49-32 //
（32）その戦場でヴリシュニとパーンダヴァ（プリシャタの子ドリシュタデュムナ）の、激しい戦いが起こった。肉を奪い合う、怒った二羽の鷹の戦いのように、王よ。
dhṛṣṭadyumnastu samare hārdikyaṃ navabhiḥ śaraiḥ|
ājaghāna urasi kruddhaḥ pīḍayan hṛdikātmajam|| // 8-49-33 //
（33）戦場でドリシュタデュムナは、九本の矢でクリタヴァルマンを、怒って胸を打った、ヒリディカの子を苦しめながら。
kṛtavarmā tu samare pārṣatena dṛḍhāhataḥ|
pārṣataṃ sarathaṃ sāśvaṃ chādayāmāsa sāyakaiḥ|| // 8-49-34 //
（34）クリタヴァルマンは戦場でドリシュタデュムナに堅く打たれ、戦車・馬と共にドリシュタデュムナを矢で覆った。
sarathaś chādito rājan dhṛṣṭadyumno na dṛśyate|
meghairiva paricchanno bhāskaro jaladhāribhiḥ|| // 8-49-35 //
（35）戦車と共に覆われて、王よ、ドリシュタデュムナは見えなくなった。雲に覆われた太陽のように、水を湛える雲に覆われて。
vidhūya taṃ bāṇagaṇaṃ śaraiḥ kanakabhūṣaṇaiḥ|
vyarocata raṇe rājan dhṛṣṭadyumnaḥ kṛtavraṇaḥ|| // 8-49-36 //
（36）金で飾られた矢で、その矢の群れを振り払って、戦場で輝いた、王よ、傷を負ったドリシュタデュムナは。
tatastu pārṣataḥ kruddhaḥ śastravṛṣṭiṃ sudāruṇām|
kṛtavarmāṇamāsādya vyasṛjat pṛtanāpatiḥ|| // 8-49-37 //
（37）そしてプリシャタの子（ドリシュタデュムナ）は怒り、凄まじい武器の雨を、クリタヴァルマンに向かって放った、軍の首領は。
tām āpatantīṃ sahasā śastravṛṣṭiṃ sudāruṇām|
śarair anekasāhasrair hārdikyo'vārayad yudhi|| // 8-49-38 //
（38）飛来する凄まじいその武器の雨を、数千の矢でヒリディカの子（クリタヴァルマン）は戦場で防いだ。
dṛṣṭvā tu vāritāṃ yuddhe śastravṛṣṭiṃ durāsadām|
kṛtavarmāṇamāsādya vārayāmāsa pārṣataḥ|| // 8-49-39 //
（39）戦場で近寄りがたい武器の雨を防がれたのを見て、クリタヴァルマンのもとへプリシャタの子（ドリシュタデュムナ）は近づいて対峙した。
'yathā yugmarathena ajau vāhān vāhair amiśrayat|
gṛhītvā carma khaṅgaṃ ca rathaṃ tasya avapupluve|| // 8-49-40 //
（40）『戦場で組になった戦車で、両者は馬と馬を組み合わせた。盾と剣を取り、彼の戦車に飛び込んだ。
militeṣvatha vāheṣu pratyāsanne ca pārṣate|
dṛṣṭvā'padānaṃ tasya āśu gadāṃ jagrāha sātvataḥ|| // 8-49-41 //
（41）馬同士が絡み合い、プリシャタの子（ドリシュタデュムナ）が近づいたとき、彼の素早い働きを見て、鉄棒をサートヴァタ族（クリタヴァルマン）は取った。
gadāpāṇistato rājan rathāt tūrṇam avaplutaḥ|
tam adṛṣṭvā rathopasthe sārathiṃ samatāḍayat|| // 8-49-42 //
（42）鉄棒を手にした彼は、王よ、戦車から急いで飛び降りた。戦車の床にその者を見失って、御者を打った。
khaṅgena śitadhāreṇa sa hataḥ prāpatad rathāt|
kṛtavarmā tato hṛṣṭas talaśabdaṃ cakāra ha|| // 8-49-43 //
（43）鋭い剣で殺されてその者は戦車から落ちた。クリタヴァルマンは喜んで手を叩いて音を立てた。
pārṣataṃ ca abravīd rājan nehyehīti punaḥ punaḥ|
sa taṃ na mamṛṣe yuddhe talaśabdaṃ samīritam|| // 8-49-44 //
（44）そしてプリシャタの子（ドリシュタデュムナ）に「来い、来い」と何度も言った。その手の音を戦場で彼は我慢できなかった。
avaplutya rathāt tasmāt svarathaṃ punar āsthitaḥ|
abhyayāt sa tu tat tūrṇaṃ tiṣṭha tiṣṭheti ca abravīt|| // 8-49-45 //
（45）戦車から飛び降り、再び自らの戦車に乗り、素早く向かい、「止まれ、止まれ」と言った。
tato rājan maheṣvāsaṃ kṛtavarmāṇam āśu vai|
gadāṃ gṛhya punar vegāt kṛtavarmāṇam āhanat|| // 8-49-46 //
（46）王よ、大弓使いクリタヴァルマンに素早く、鉄棒を取り、勢いよくクリタヴァルマンを打った。
so'tividdho balavatā nyapatan mūrcchayā hataḥ|
śrutarvā ratham āropya apovāha raṇājirāt'|| // 8-49-47 //
（47）大きく射抜かれ、大力によって、気絶して倒れた。シュルタルヴァが戦車に乗せて、戦場から連れ去った』。
dhṛṣṭadyumnastu samare dṛṣṭvā śatruṃ mahārathaḥ|
kauravān samare tūrṇaṃ vārayāmāsa sāyakaiḥ|| // 8-49-48 //
（48）戦場で敵を見て、偉大な戦車戦士ドリシュタデュムナは、戦場ですばやくクル族を矢で抑えた。
tataste tāvakā yodhā dhṛṣṭadyumnam upādravan|
siṃhanādaravāṃś cakrus tato yuddhamavartata|| || // 8-49-49 //
（49）そしてあなた方の戦士はドリシュタデュムナに襲いかかった。獅子吼をあげて、戦いが続いた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekonapañcāśo'dhyāyaḥ|| 49 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十九章は終わる。
