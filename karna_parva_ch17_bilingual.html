本章は南伝（Southern Recension）テキストの「アディヤーヤ17」（クリパがドリシュタデュムナを、クリタヴァルマンがシカンディンを破る場面。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-17-N）と和訳の段落番号が対応しています。
karṇaparva — saptadaśo'dhyāyaḥ (17)
第17章　クリパがドリシュタデュムナを、クリタヴァルマンがシカンディンを破る
sañjaya uvāca|
dhṛṣṭadyumnaṃ kṛpo rājan vārayāmāsa saṃyuge|
yathā dṛṣṭvā vane siṃhaṃ śarabho vārayed yudhi|| // 8-17-1 //
サンジャヤは語った。 （1）王よ、クリパは戦場でドリシュタデュムナを迎え撃ちました。森で獅子を見たシャラバ（伝説の八本足の獣）が立ち向かうように。
niruddhaḥ pārṣatas tena gautamena balīyasā|
padātpadaṃ vicalituṃ nāśakat tatra bhārata|| // 8-17-2 //
（2）バーラタよ、力ある者ガウタマ（クリパ）に制されたパールシャタ（ドリシュタデュムナ）は、一歩も動くことができませんでした。
gautamasya rathaṃ dṛṣṭvā dhṛṣṭadyumnarathaṃ prati|
vitresuḥ sarvabhūtāni kṣayaṃ prāptaṃ ca menire|| // 8-17-3 //
（3）ガウタマの戦車がドリシュタデュムナの戦車に向かうのを見て、すべての生き物は震え上がり、終わりが来たと思いました。
tadā jalpanti pāṇḍūnāṃ rathinaḥ sādinas tathā|
droṇasya nidhanān nūnaṃ saṅkruddho dvipadāṃ varaḥ|| // 8-17-4 //
（4）その時パーンダヴァの戦車兵と騎兵たちは語り合いました。「ドローナの死のために、バラモンの中の最上者（クリパ）は激怒しているに違いない。
śāradvato mahātejā divyāstravidudāradhīḥ|
api svasti bhavedadya dhṛṣṭadyumnasya gautamāt|| // 8-17-5 //
（5）シャーラドヴァタ（クリパ）は大いなる威光を持ち、神聖な武器を知る寛大な知者だ。今日、ガウタマ（クリパ）からドリシュタデュムナの身は無事であろうか。
apīyaṃ vāhinī kṛtsnā mucyeta mahato bhayāt|
apyayaṃ brāhmaṇaḥ sarvān na no hanyāt samāgatān|| // 8-17-6 //
（6）この全軍が大いなる恐怖から逃れられるだろうか。このバラモンは我ら全員を殺してしまわないだろうか。
yādṛśaṃ dṛśyate rūpamantakapratimaṃ raṇe|
gamiṣyaty adya padavīṃ bhāradvājasya gautamaḥ|| // 8-17-7 //
（7）戦場で死神のような姿を見せている。ガウタマはバーラドヴァージャ（ドローナ）の道を歩もうとしている。
ācāryaḥ kṣiprahastaś ca vijayī ca sadā yudhi|
astravān vīryasampannaḥ krodhena ca samanvitaḥ|| // 8-17-8 //
（8）師匠は素早い手を持ち、常に戦いに勝利し、武器に通じ、武勇に満ち、怒りに燃えている。
pārṣataś ca mahāyuddhe vimukho'dyābhilakṣyate|
ityevaṃ vividhā vācas tāvakānāṃ paraiḥ saha|
vyaśrūyanta mahārāja tayos tatra samāgame|| // 8-17-9 //
（9）パールシャタ（ドリシュタデュムナ）は今日の大戦闘で、顔をそむけているように見える。」——大王よ、二人の出会いにおいて、あなた方と敵方からこのようなさまざまな声が聞こえました。
viniḥśvasya tataḥ krodhāt kṛpaḥ śāradvato nṛpa|
pārṣataṃ cārdayāmāsa niśceṣṭaṃ sarvamarmasu|| // 8-17-10 //
（10）王よ、シャーラドヴァタ・クリパは怒りの息をつき、パールシャタをすべての急所に打って動けなくしました。
sa hanyamānaḥ samare gautamena mahātmanā|
kartavyaṃ na sma jānāti mohena mahatā vṛtaḥ|| // 8-17-11 //
（11）偉大なる魂のガウタマに戦場で打たれるドリシュタデュムナは、大いなる迷妄に包まれて何をすべきかわかりませんでした。
tam abravīt tato yantā kañcit kṣemaṃ tu pārṣata|
īdṛśaṃ vyasanaṃ yuddhe na te dṛṣṭaṃ mayā kvacit|| // 8-17-12 //
（12）そこで御者が彼に言いました。「パールシャタよ、少しでも安全なところへ行きましょう。戦場でこのような窮地をあなたに見たことはありません。
daivayogāt tu te bāṇā nāpatan marmabhedinaḥ|
preṣitā dvijamukhyena marmāṇy uddiśya sarvataḥ|| // 8-17-13 //
（13）天の運により、あのバラモンの最上者が急所を狙って放った矢があなたの急所を貫かなかっただけです。
vyāvartaye rathaṃ tūrṇaṃ nadīvegam iva arṇavāt|
avadhyaṃ brāhmaṇaṃ manye yena te vikramo hataḥ|| // 8-17-14 //
（14）急いで戦車を回しましょう。大海から離れる河の流れのように。バラモンは不死身だと思います。だからこそあなたの武勇が失われたのです。」
dhṛṣṭadyumnas tato rājañ śanakair abravīd vacaḥ|
muhyate me manastāta gātrasvedaśca jāyate||
vepathuśca śarīre me romaharṣaśca sārathe|
varjayan brāhmaṇaṃ yuddhe śanairyāhi yato'rjunaḥ|| // 8-17-15-16 //
（15〜16）王よ、ドリシュタデュムナは静かにこう言いました。「友よ、心が朦朧として、体中に汗が出る。体が震え、毛が逆立つ、御者よ。バラモンを避けて、ゆっくりとアルジュナのいるところへ行ってくれ。
arjunaṃ bhīmasenaṃ vā samare prāpya sārathe|
kṣemam adya bhaven mahyam iti me naiṣṭhikī matiḥ|| // 8-17-17 //
（17）御者よ、戦場でアルジュナかビーマセーナのもとに行けば、今日私は安全だろう——これが私の確かな考えだ。」
tataḥ prāyān mahārāja sārathis tvarayan hayān|
yato bhīmo maheṣvāso yuyudhe tava sainikaiḥ|| // 8-17-18 //
（18）大王よ、御者は馬を急がせて、偉大な弓の達人ビーマがあなたの兵士たちと戦っているところへ向かいました。
pradrutaṃ ca rathaṃ dṛṣṭvā dhṛṣṭadyumnasya māriṣa|
kirañ śaraśatāny eva gautamo'nuyayau tadā|| // 8-17-19 //
（19）ドリシュタデュムナの戦車が逃走するのを見て、ガウタマ（クリパ）は何百もの矢を放ちながら追いかけました。
śaṅkhaṃ ca pūrayāmāsa muhur muhur arindamaḥ|
pārṣataṃ trāsayāmāsa mahendro namuciṃ yathā|| // 8-17-20 //
（20）敵を滅ぼす者は何度も法螺貝を吹き鳴らし、パールシャタを震え上がらせました。大いなるインドラがナムチを震え上がらせたように。
śikhaṇḍinaṃ tu samare bhīṣmamṛtyuṃ durāsadam|
hārdikyo vārayāmāsa smayan iva muhurmuhuḥ|| // 8-17-21 //
（21）ビーシュマの死をもたらした近づき難きシカンディンを、クリタヴァルマン（ハールディキヤ）が何度も微笑みながら戦場で迎え撃ちました。
śikhaṇḍī tu samāsādya hṛdikānāṃ mahāratham|
pañcabhir niśitair bhallair jatrudeśe samāhanat|| // 8-17-22 //
（22）フリディカの子の偉大な戦車戦士（クリタヴァルマン）のもとに至ったシカンディンは、五本の鋭い矢尻の矢で鎖骨のあたりを打ちました。
kṛtavarmā tu saṅkruddho bhittvā ṣaṣṭyā patatribhiḥ|
dhanurekena ciccheda hasan rājan mahārathaḥ|| // 8-17-23 //
（23）王よ、怒ったクリタヴァルマンは偉大な戦車戦士として笑いながら、六十本の矢でシカンディンを射抜き、一本の矢で弓を断ち切りました。
athānyad dhanurādāya drupadasyātmajo balī|
tiṣṭhatiṣṭheti saṅkruddho hārdikyaṃ pratyabhāṣata|| // 8-17-24 //
（24）力あるドルパダの息子（シカンディン）は別の弓を取り、「待て、待て！」と怒りを込めてクリタヴァルマンに呼びかけました。
tato'sya navatiṃ bāṇān rukmapuṅkhān sutejanān|
preṣayāmāsa rājendra te'syābhraśyanta varmaṇaḥ|| // 8-17-25 //
（25）王の中の王よ、金の矢尻の鋭い矢九十本をクリタヴァルマンに放ちましたが、それらは鎧からはじかれてしまいました。
vitathāṃs tān samālakṣya patitāṃś ca mahītale|
kṣurapreṇa sutīkṣṇena kārmukaṃ cicchide bhṛśam|| // 8-17-26 //
（26）矢が外れて大地に落ちたのを見て、鋭い剃刀の矢でクリタヴァルマンの弓を激しく断ち切りました。
athainaṃ chinnadhanvānaṃ bhagnaśṛṅgam iva ṛṣabham|
aśītyā mārgaṇaiḥ kruddho bāhvorurasi cārpayat|| // 8-17-27 //
（27）弓を失い、角を折られた雄牛のようになったクリタヴァルマンに、怒ったシカンディンは八十本の矢を両腕と胸に打ち込みました。
kṛtavarmā tu saṅkruddho mārgaṇaiḥ kṣatavikṣataḥ|
vavāma rudhiraṃ gātraiḥ kumbhavakrād iva udakam|| // 8-17-28 //
（28）激怒したクリタヴァルマンは矢に体を切り裂かれ、壺の口から水が出るように体のあちこちから血を吐きました。
rudhireṇa pariklinnaḥ kṛtavarmā tv arājata|
varṣeṇa kledito rājan yathā gairikaparvataḥ|| // 8-17-29 //
（29）王よ、血にまみれたクリタヴァルマンは、雨に濡れた赤土の山のように輝きました。
athānyad dhanurādāya samārgaṇaguṇaṃ prabhuḥ|
śikhaṇḍinaṃ bāṇagaṇaiḥ skandhadeśe vyatāḍayat|| // 8-17-30 //
（30）力ある者クリタヴァルマンは弓と矢とともに別の弓を取り、矢の群れでシカンディンの肩のあたりを打ちました。
skandhadeśasthitair bāṇaiḥ śikhaṇḍī tu vyarājata|
śākhāpraśākhāvipulaḥ sumahān pādapo yathā|| // 8-17-31 //
（31）肩に矢を立てたシカンディンは、枝を大きく広げた大木のように美しく輝きました。
tāvanyonyaṃ bhṛśaṃ vidvvā rudhireṇa samukṣitau|
popluyamānau hi yathā mahāntau śoṇitahade|
tadvad virejatur vīrau śoṇitena pariplutau||
yathā ca kiṃśukau phullau puṣpamāse samāgate|
rudhirokṣitasarvāṅgau raktacandanarūṣitau|
bhujagāv iva saṅkruddhau rejatus tau narottamau|| // 8-17-32-33 //
（32〜33）互いに激しく射ち合い、血にまみれた二人は——まるで花の季節に満開のキンシュカの木のように、血に染まった全身で、赤い白檀を塗られた二匹の怒れる蛇のように——二人の最上の人は輝きました。
tāvubhau śaravanunnāṅgau parasparaśarakṣatau|
anyonyaśṛṅgābhihatau rejatur vṛṣabhāv iva|| // 8-17-34 //
（34）互いに矢で体を打たれた二人は、互いの角で打ち合う二頭の雄牛のように輝きました。
anyonyasya vadhe yatnaṃ kurvāṇau tau mahārathau|
rathābhyāṃ ceratus tatra maṇḍalāni sahasraśaḥ|| // 8-17-35 //
（35）互いの殺害に努める二人の偉大な戦車戦士は、戦車で何千もの円形の機動を行いました。
kṛtavarmā mahārāja pārṣataṃ niśitaiḥ śaraiḥ|
raṇe vivyādha saptatyā svarṇapuṅkhaiḥ śilāśitaiḥ|| // 8-17-36 //
（36）大王よ、クリタヴァルマンは金の矢尻で石に研がれた七十本の鋭い矢でパールシャタ（シカンディン）を射ちました。
tato'sya samare bāṇaṃ bhojaḥ praharatāṃ varaḥ|
jīvitāntakaraṃ ghoraṃ vyasṛjat tvarayā'nvitaḥ|| // 8-17-37 //
（37）武勇の中の最上者ボージャ族のクリタヴァルマンは、命を奪う恐ろしい矢を、急いで放ちました。
sa tenābhihato rājan mūrcchām āśu samāviśat|
dhvajayaṣṭiṃ ca sahasā śiśriye kaśmalāvṛtaḥ|| // 8-17-38 //
（38）王よ、その矢に打たれたシカンディンはすぐに失神し、もうろうとして突然旗竿にすがりつきました。
apovāha raṇāt tūrṇaṃ sārathī rathināṃ varam|
hārdikyaśarasantaptaṃ niḥśvasantaṃ punaḥpunaḥ|| // 8-17-39 //
（39）御者は戦車兵の中の最上者を素早く戦場から運び出しました。クリタヴァルマンの矢に焼かれ、何度も嘆息するシカンディンを。
parājite tataḥ śūre drupadasyātmaje prabho|
vyadravat pāṇḍavī senā vyadhamānā samantataḥ|| || // 8-17-40 //
（40）主よ、勇者であるドルパダの息子（シカンディン）が敗れると、パーンダヴァ軍は四方から打たれて敗走しました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe saptadaśo'dhyāyaḥ|| 17 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十七章は終わる。
