マハーバーラタ ― カルナ篇 第66章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 66 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ66」、全38詩節からなります。カルナがケーカヤ族の大戦車戦士たちを打ち散らす場面（第1〜2詩節）、ナクラとサハデーヴァがカルナに挑む場面（第3〜13詩節）、ユダーマンユ王がカルナと語り合い撤退を促す場面（第14〜28詩節）、ユダーマンユが陣営に退くまでの場面（第29〜38詩節）で本章は終わります。
karṇaparva — ṣaṭṣaṣṭitamo'dhyāyaḥ (66)
第66章
sañjaya uvāca|
karṇo'pi śarajālena kekayānāṃ mahārathān|
vyadhamatparameṣvāsānagrānīke vyavasthitān||
// 8-66-1 //
カルナもまた矢の網で、前線に配置されたケーカヤ族の大戦車戦士、最高の弓の使い手たちを打ち散らした。
teṣāṃ prayatamānānāṃ rādheyasya nivāraṇe|
rathānpañcaśatānkarṇaḥ prāhiṇodyamasādanam||
// 8-66-2 //
ラーデーヤ（カルナ）を阻もうと努める彼らの戦車五百台を、カルナはヤマの住処へ送った。
aviṣahyatamaṃ dṛṣṭvā rādheyaṃ yudhi yodhinaḥ|
bhīmasenamupāgacchankarṇabāṇaprapīḍitāḥ||
// 8-66-3 //
戦場でラーデーヤに抗し難いのを見て、カルナの矢に苦しめられた戦士たちはビーマセーナのもとに逃げてきた。
rathānīkaṃ vidāryaiva śarai rājannanekadhā|
karṇa ekarathenaiva yudhiṣṭhiramupādravat||
// 8-66-4 //
王よ、戦車軍を様々に矢で引き裂いて、カルナはたった一台の戦車でユディシュティラに迫った。
senāniveśaṃ gacchantaṃ mārgaṇairbhṛśapīḍitam|
yamayormadhyagaṃ vīraṃ śanairyāntaṃ vicetasam||
// 8-66-5 //
矢に激しく苦しめられ陣営へ向かう王は、双子の間を意識朦朧としながらゆっくり進んでいた。
sa samāsādya rājānaṃ duryodhanahitepsayā|
sūtaputrastribhis tīkṣṇairvivyādha parameṣubhiḥ||
// 8-66-6 //
王に追いつくと、ドゥルヨーダナの利益のためにスータの子は三本の鋭い矢で王を射た。
tathaiva rājā rādheyaṃ pratyavidhyatstanāntare|
śaraistribhiś ca yantāraṃ caturbhiś caturo hayān||
// 8-66-7 //
同様に王もラーデーヤの胸を三本の矢で射返し、御者を三本、四頭の馬を四本の矢で射た。
cakrarakṣau nṛpasutau mādrīputrau parantapau|
tāvapyadhāvatāṃ karṇaṃ rājānaṃ mā vadhīditi||
// 8-66-8 //
マードリーの子たちは車輪の護衛であった。敵を滅ぼす王子たちは『王を殺すな』と叫びながらカルナに向かって駆けた。
tau pṛthakśaravarṣābhyāṃ rādheyaṃ samavarṣatām|
nakulaḥ sahadevaś ca paramaṃ yatnamāsthitau||
// 8-66-9 //
ナクラとサハデーヴァは最大の努力をもって、それぞれ別々の矢の雨をラーデーヤに浴びせた。
tathaiva tau pratyavidhyatsūtaputraḥ pratāpavān|
bhallābhyāṃ śitadhārābhyāṃ mahātmānāvarindamau||
// 8-66-10 //
同様にスータの子も威勢をもって、鋭い刃の矢二本で偉大なる敵を滅ぼす二人を射返した。
dantavarṇāṃstu rādheyo nijaghāna manojavān|
yudhiṣṭhirasya saṅgrāme kālavālānhayottamān||
// 8-66-11 //
ラーデーヤは戦場でユディシュティラの象牙色の素早い最高の馬たちを殺した。
tato'pareṇa bhallena śirastrāṇamapātayat|
kaunteyasya maheṣvāsaḥ prahasan iva sūtajaḥ||
// 8-66-12 //
さらにスータの子の大弓の戦士は、笑うかのように別の矢でカウンテーヤの頭飾りを打ち落とした。
tathaiva nakulasyāpi hayānhatvā mahārathaḥ|
tato'pareṇa bhallena bhṛśaṃ tīkṣṇena bhārata|
dhanuściccheda vīrasya mādrīputrasya dhīmataḥ||
// 8-66-13 //
大戦車戦士は同様にナクラの馬をも殺し、バーラタよ、さらに鋭い別の矢で知恵あるマードリーの子の弓を切断した。
tau hatāśvau hatarathau pāṇḍavau bhṛśavikṣatau|
bhrātarāvāruruhatuḥ sahadevarathaṃ tadā||
// 8-66-14 //
馬を殺され戦車を失った二人のパーンダヴァは深く傷つき、兄弟としてサハデーヴァの戦車に乗り込んだ。
tau dṛṣṭvā mātulastatra virathau paravīrahā|
abhyabhāṣata rādheyaṃ madrarājo'nukampayā||
// 8-66-15 //
敵の勇者を殺す叔父マドラ王（シャリヤ）は、戦車を失った二人を見て、憐れみをもってラーデーヤに語りかけた。
mārgitavyastvayā karṇa kuntīputro dhanañjayaḥ|
atastvaṃ dharmarājena kimarthamiha yudhyase||
// 8-66-16 //
『カルナよ、おまえが探すべきはクンティーの子ダナンジャヤ（アルジュナ）だ。なぜここでダルマ王と戦っているのだ。』
kṣīṇaśastrāstrākavacaḥ kṣīṇabāṇo vibāṇadhiḥ|
śrāntasārathivāhaś ca cchanno'strairaribhis tathā|
pārthamāsādya rādheya upahāsyo bhaviṣyasi||
// 8-66-17 //
『武器も防具も鎧も使い果たし、矢筒も空になり、御者も馬も疲れ果て、敵の武器に覆われている今、ラーデーヤよ、パールタ（アルジュナ）に出会えば笑い者にされるぞ。』
tathāpi karṇaḥ saṃrabdho yudhiṣṭhiramapīḍayat|
śaraistīkṣṇairmahāvīryairmādrīputrau ca pāṇḍavau||
// 8-66-18 //
それでもカルナは怒りに燃え、鋭く大いなる力の矢でユディシュティラとマードリーの二人のパーンダヴァを苦しめ続けた。
tataḥ śalyaḥ prahasyedaṃ karṇaṃ punaruvāca ha|
rathasthamatisaṃrabdhaṃ yudhiṣṭhiravadhe sthitam||
// 8-66-19 //
そこでシャリヤは笑いながら、ユディシュティラを殺すことに固執して戦車に立つカルナにこう言った。
yadarthaṃ dhārtarāṣṭreṇa satataṃ mānito bhavān|
taṃ pārtha jahi rādheya kiṃ te hatvā yudhiṣṭhiram|
'hate yasmindhruvaṃ pārthaḥ sarvāñjeṣyati no rathān||
// 8-66-20 //
『ドリタラーシュトラの子（ドゥルヨーダナ）が常におまえを敬ってきたのは、パールタ（アルジュナ）を倒すためだ。ラーデーヤよ、彼を殺せ。ユディシュティラを殺して何になる。
tasminhi dhārtarāṣṭrasya nihate tu dhruvo jayaḥ|
dhvajo'sau dṛśyate tasya rocamānoṃ'śumān iva|
sāro hyeṣa mahābāho kiṃ te hatvā yudhiṣṭhiram||
' // 8-66-21 //
彼が殺されれば必ずパールタが我らの戦車を全て打ち破るだろう。彼（ユディシュティラ）の死こそがドリタラーシュトラの子の勝利を確かにする。あの旗印が太陽のように輝いて見えるぞ。大腕よ、真の敵はアルジュナだ。ユディシュティラを殺して何になる。』
śaṅkhayordhmātayoḥ śabdaḥ sumahāneṣa kṛṣṇayoḥ|
śrūyate cāpaghoṣaś ca prāvṛṣīvāmbudasya ha||
// 8-66-22 //
「二人のクリシュナ（クリシュナとアルジュナ）が法螺貝を吹く大いなる音が聞こえるではないか。雨季の雲のごとき弓の轟きも。」
asau nighnanrathodārānarjunaḥ śaravṛṣṭibhiḥ|
sarvāṃ grasati naḥ senāṃ karṇa paśyainamāhave||
// 8-66-23 //
「カルナよ、あのアルジュナは素晴らしい戦車戦士たちを矢の雨で打ちながら、我々の全軍を飲み込んでいるのだ。戦場で彼を見よ。」
pṛṣṭharakṣau ca śūrasya yudhāmanyūttamaujasau||
// 8-66-24 //
「勇者の背後の護衛はユダーマンユとウッタマウジャスだ。」
uttaraṃ cāsya vai śūraścakraṃ rakṣati sāṃtyakiḥ|
dhṛṣṭadyumnastathā cāsya cakraṃ rakṣati dakṣiṇam||
// 8-66-25 //
「彼の前方右の車輪をサーティヤキの勇者が守り、左の車輪をドリシュタデュムナが守っている。」
bhīmasenaś ca vai rājñā dhārtarāṣṭreṇa yudhyate|
yathā na hanyāttaṃ bhīmaḥ sarveṣāṃ no'dya paśyatām|
kuru rādheya vai rājā yathā mucyeta tattathā||
// 8-66-26 //
「ビーマセーナはドリタラーシュトラの王と戦っている。ビーマが我ら全員の見ている前で王を殺さないよう、ラーデーヤよ、王が解放されるよう手を打て。」
xxxx bhīmasenena grastamāhavaśobhinā|
yadi nāmādya mucyeta vismayaḥ sumahānbhavet||
// 8-66-27 //
「戦場に輝くビーマセーナに捕らえられた王が、もし今日逃れられるなら、それこそ大いなる驚きだ。」
paritrāhyenamabhyetya saṃśayaṃ paramaṃ gatam|
kiṃ nu mādrīsutau hatvā rājānaṃ vā yudhiṣṭhiram||
// 8-66-28 //
「最大の危機に瀕しているドゥルヨーダナを救いに行け。マードリーの子を殺しても、ユディシュティラを殺しても何になる。」
iti śalyavacaḥ śrutvā rādheyaḥ pṛthivīpate|
dṛṣṭvā duryodhanaṃ caiva bhīmagrastaṃ mahāhave||
// 8-66-29 //
シャリヤの言葉を聞き、大いなる戦いでビーマに捕らえられたドゥルヨーダナを見て、ラーデーヤは王の座を切望し、
rājagṛdhnurbhṛśaṃ caiva śalyavākyapracoditaḥ|
ajātaśatrumutsṛjya mādrīputrau ca pāṇḍavau||
// 8-66-30 //
シャリヤの言葉に駆り立てられ、アジャータシャトル（ユディシュティラ）とマードリーの二人のパーンダヴァを残して、
tava putraṃ paritrātumabhyadhāvata vīryavān|
madrarājapraṇuditairaśvairākāśagairiva||
// 8-66-31 //
おまえの息子を救うため、勇敢にもマドラ王に駆られた空を行くかのような馬で駆けていった。
gate karṇe tu kaunteyaḥ pāṇḍuputro yudhiṣṭhiraḥ|
apāyājjavanairaśvaiḥ sahadevasya māriṣa||
// 8-66-32 //
カルナが去ると、カウンテーヤ・パーンドゥの子ユディシュティラは、サハデーヴァの速い馬に乗って退却した。
tābhyāṃ sa sahitastūrṇaṃ vrīḍann iva nareśvaraḥ|
prāpya senāniveśaṃ svaṃ mārgaṇairbhṛśavikṣataḥ||
// 8-66-33 //
二人と共に、恥じるように王は、矢に深く傷つきながら、自軍の陣営に到着した。
avatīrya rathāttūrṇamāviśacchayanaṃ śubham|
apetaśalyo rājā tu hṛcchalyenābhipīḍitaḥ||
// 8-66-34 //
戦車から素早く降りると、美しい寝台に入った。矢は抜かれたが、心の矢に苦しめられて。
so'bravīddhātarau rājā mādrīputrau mahārathau|
gacchanta tvaritau vīrau yatra bhīmo vyavasthitaḥ||
// 8-66-35 //
王はマードリーの二人の大戦車戦士の息子たちに言った。『急いでビーマのいる所へ行け、勇者たちよ。』
'tataste pāṇḍavāḥ sarve samābhāṣya parasparam|
anīkaṃ bhīmasenasya pāṇḍavāvabhyagacchatām'|
jīmūta iva nardaṃstu yudhyate sa vṛkodaraḥ||
// 8-66-36 //
そしてパーンダヴァたち全ては互いに言葉を交わし、二人のパーンダヴァはビーマセーナの陣に向かった。雷雲のように吼えながらヴリコーダラ（ビーマ）は戦っていた。
tato'nyaṃ rathamāsthāya nakulo rathapuṅgavaḥ|
sahadevaś ca tejasvī bhrātarau śatrukarśanau||
// 8-66-37 //
戦車の雄牛ナクラと輝くサハデーヴァは兄弟として敵を苦しめる者であり、別の戦車に乗った。
turagairagryaraṃhobhir yatra bhīmastarasvinau|
anīkaiḥ sahitau tatra bhrātarau samavasthitau||
// 8-66-38 //
最高速の馬で、速き二人の兄弟はビーマのいる所へ軍勢と共に赴き、そこに陣取った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ṣaṭṣaṣṭitamo'dhyāyaḥ|| 66 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第66章終わり。
