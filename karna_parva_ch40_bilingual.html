マハーバーラタ ― カルナ篇 第40章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 40 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ40」（第十七日の戦いにおいて、両軍が激突し、特にビーマセーナがドゥルヨーダナの象軍を打ち破る場面）です。デュルヨーダナはカルナとシャルヤに開戦を促し、アシュヴァッターマン（ドラウナーズ＝ドローナの子）は、父ドローナを討ったドリシュタデュムナへの復讐を誓います。両軍が激突すると、天界の存在やアプサラスたちが戦場に現れ、その後ビーマセーナが象軍を相手に猛戦する様子が描かれます。なお、原典の奥書（コロフォン）には「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されており、これは第38章・第39章には見られない本章特有の表現です。
karṇaparva — catvāriṃśo'dhyāyaḥ (40)
第40章
sañjaya uvāca|
duryodhanastataḥ karṇamupetya bharatarṣabha|
abravīn madrarājaṃ ca tathaiva anyān mahārathān|| // 8-40-1 //
サンジャヤは語った。 （1）ドゥルヨーダナは、バーラタの雄牛よ、カルナのもとへ行き、マドラ王や他の偉大な戦車戦士たちにも語った。
yadṛcchayā'yam avyagro dharmaḥ paramakaḥ sakhā|
sukhinaḥ kṣatriyāḥ karṇa labhante yuddhamīdṛśam|| // 8-40-2 //
（2）「偶然にも、この平穏な、最高の道、友よ。幸福なクシャトリヤたちよ、カルナよ、このような戦いを得ている。
yādṛśaṃ kṣatriyaiḥ śūraiḥ śūrāṇāṃ dīvyatāṃ yudhi|
iṣṭaṃ bhavati rādheya tadidaṃ samupasthitam|| // 8-40-3 //
（3）勇猛なクシャトリヤが、戦場で遊技を行う勇者たちと共に望むもの――それが今、ここで起こっているのだ、ラーデーヤ（カルナ）よ。
hatvā tu pāṇḍavān yuddhe sthirāmurvīṃ praśāsatha|
nihatā vā parair yuddhe vīralokānavāpsyatha|| // 8-40-4 //
（4）戦場でパーンダヴァたちを討てば、堅固なる大地を治められる。敵に討たれれば、勇者の世界（天界）を得られる」。
duryodhanasya vacanaṃ śrutvā tatkṣatriyarṣabhāḥ|
siṃhanādān udakrośan vāditrāṇi ca jaghnire|| // 8-40-5 //
（5）ドゥルヨーダナの言葉を聞いて、クシャトリヤの雄牛たちは獅子吼をあげ、楽器を打ち鳴らした。
tasmin pramudite sainye tvadīye bharatarṣabha|
harṣayaṃs tāvakān yodhān drauṇir vacanam abravīt|| // 8-40-6 //
（6）そのように、あなた方の軍が喜ぶと、バーラタの雄牛よ、ドローナの子（アシュヴァッターマン）は喜ぶ戦士たちを励ますように言った。
pratyakṣaṃ sarvasainyānāṃ bhavatāṃ cāpi paśyatām|
nyastaśastro mama pitā dhṛṣṭadyumnena pātitaḥ|| // 8-40-7 //
（7）「すべての軍勢の前で、皆が見ている前で、武器を捨てた父を、ドリシュタデュムナは討った。
sa tena aham amarṣeṇa pitrarthe cāpi bhārata|
dhṛṣṭadyumnam ahatvā'haṃ na vimokṣyāmi daṃśanam|| // 8-40-8 //
（8）それゆえ、父のために、私は怒りに満ちて、バーラタよ、ドリシュタデュムナを討たぬ限り、鎧を脱ぐことはない。
kṛtvā'nṛtāṃ pratijñāṃ vo nāsmi prāptā mahat phalam|
arjunaṃ bhīmasenaṃ ca yaś ca māṃ pratiyotsyati|
sarvāṃs tān pramathiṣyāmi iti me niścitā matiḥ|| // 8-40-9 //
（9）誓いを偽りにしてしまったら、大きな果報は得られぬ。アルジュナ、ビーマセーナ、そして私に立ち向かう者すべてを、討ち砕こう――これが私の確き決意である」。
sañjaya uvāca|
evamukte tataḥ sarvā harṣitā bhāratī camūḥ|
abhyavartata kaunteyāṃs tathā tāṃ ca api pāṇḍavāḥ|| // 8-40-10 //
サンジャヤは語った。 （10）このように言われて、バーラタの軍すべてが喜び、クンティーの子たち（パーンダヴァ）に向かって進んだ。またパーンダヴァも彼らに向かった。
sa sannipāto rathayūthapānāṃ mahāhave bhārata lobhanīye|
janakṣayaḥ kālayugāntakalpaḥ prāvartatāgre kurusṛñjayānām|| // 8-40-11 //
（11）戦車の指揮官たちの出会いは、バーラタよ、大戦場で、目を引くものとなった。時の終わりのような人々の殺戮が、クル族とスリンジャヤ族の戦いの先頭で始まった。
tataḥ pravṛtte yudhi samprahāre bhūtāni sarvāṇi sadaivatāni|
āsan sametāni saha apsarobhir nirīkṣatībhir yudhi vīrasaṅghān|| // 8-40-12 //
（12）そして戦いが始まり、激突が始まったとき、すべての生き物、神々と共に、アプサラスたちと共に集って、戦場の勇者たちの群れを見守っていた。
divyaiś ca gandhaiḥ paramaiś ca puṣpair anyaiś ca ratnair vividhair narāgryāḥ|
raṇeṣu karmodvahatāḥ prahṛṣṭā nanandayan apsarasaḥ prahṛṣṭāḥ|| // 8-40-13 //
（13）神々の香気と最高の花々、さまざまな他の宝石で、人の頂、戦場で業を行う喜ぶ者たちを、喜ぶアプサラスたちは喜ばせた。
samīraṇas tāṃs tu niṣevya gandhān niṣevate tān api yodhamukhyān|
niṣevyamāṇās tv anilena yodhāḥ parasparaṃ cukruśur ājimadhye|| // 8-40-14 //
（14）風はそれらの香りを運んで、戦場の指揮官たちにもそれを届け、風に浴する戦士たちは、戦場の中で互いに叫び合った。
tathā tu tasmiṃs tumule pravṛtte duryodhanaḥ krodham amṛṣyamāṇaḥ|
'avebhya bhīmaṃ balamadhyasaṃsthaḥ samārpayat kṣudrakāṇāṃ śatena|| // 8-40-15 //
（15）そのような激戦が起こったとき、ドゥルヨーダナは怒りを抑えきれず、『ビーマの軍に対峙して立ち、百のクシュドラカ族（兵士)と合流した――。
duḥśāsanaś citrasenaś ca vīras tathā ulūkaḥ kitavaḥ saubalaś ca|
gajānīkaiḥ sarvato bhīmasenaṃ tathā viṣaktaṃ sahasā eva abhyagacchan|| // 8-40-16 //
（16）ドゥフシャーサナ、チトラセーナ、勇者ウルーカ、キタヴァ、スバラの子（シャクニ）が、象軍を率いて、ビーマセーナを取り囲む。
tam āpatantaṃ samprekṣya gajānīkaṃ vṛkodaraḥ|
duryodhanaṃ mahābāhuḥ śaravarṣair avākirat|| // 8-40-17 //
（17）襲いかかるその象軍を見て、ヴリコーダラ（ビーマ）は長き腕の者、ドゥルヨーダナに矢の雨を浴びせた。
duryodhanaṃ tato bhīmaḥ sāyakair vajrasannibhaiḥ|
pāṇḍavo vimukhīkṛtya gajān abhyadravad balī|| // 8-40-18 //
（18）そして雷のような矢でドゥルヨーダナを退かせ、象たちにパーンダヴァ（ビーマ）は襲いかかった、力強い者は。
tataḥ pāvakasaṅkāśair bhīmabāṇair avakragaiḥ|
śalabhairiva nāgāṃs tān ardayāmāsa pāṇḍavaḥ|| // 8-40-19 //
（19）火のような、恐ろしい矢で、まっすぐに飛ぶ矢で、イナゴのように象たちを苦しめた。
tataḥ kuñjarayūthāni bhīmaseno mahābalaḥ|
vyadhaman niśitair bāṇair mahāvāto ghanān iva|| // 8-40-20 //
（20）そして象の群れを、ビーマセーナは大力の者、鋭い矢で打ち砕いた。大風が雲を打ち砕くように。
nityamattāś ca mātaṅgāḥ śūrair mattair adhiṣṭhitāḥ|
ārohakair mahāmātrais tomarāṅkurāpāṇibhiḥ|| // 8-40-21 //
（21）常に興奮した象たちは、酔った勇者たちを乗せて、鉤棒と鞭を手にした象使いに導かれていた。
suvarṇajālaiḥ pracchannā maṇijālaiś ca kuñjarāḥ|
rūpyajāmbūnadābhāsaḥ kṣuramālābhyalaṅkṛtāḥ|| // 8-40-22 //
（22）金の網で覆われ、宝石の網で飾られた象たち、銀と金の輝きをもち、剃刀の飾りをつけた――。
vadhyamānāḥ śarai rājan bhīmasenena te gajāḥ|
vibhinnahṛdayāḥ kecit tatra eva abhyapatan bhuvi|| // 8-40-23 //
（23）ビーマセーナの矢で打たれる象たちは、心臓を裂かれて、王よ、その場で地に倒れた。
nipatadbhir mahāvegair hemabhāṇḍavibhūṣitaiḥ|
aśobhata mahārāja dhātucitrair iva acalaiḥ|| // 8-40-24 //
（24）大きな勢いで落ちる、金の飾りで飾られた彼らは、大王よ、色鉱物に染まる山のように輝いた。
dīptābharaṇavadbhiś ca gajapṛṣṭhanipātitaiḥ|
saṅgaraḥ śuśubhe rājan kṣīṇapuṇyair iva amaraiḥ|| // 8-40-25 //
（25）燃え立つ飾りをつけた者、象の背から落ちる者――戦いは光り、大王よ、功徳の尽きた神々のように。
mahāparighasaṅkāśau candanāgarurūṣitau|
apaśyaṃ bhīmasenasya dhanurvikṣipato bhujau|| // 8-40-26 //
（26）大きな鉄棒のような、白檀と沈香を塗った、弓を引くビーマセーナの両腕を、我らは見た。
tasya jyātalanirghoṣam asyataḥ savyadakṣiṇam|
taṃ śrutvā'bhyadravan nāgā bhīmasenabhayārditāḥ|| // 8-40-27 //
（27）その弓の籠手の音、左右に射るその音を聞いて、象たちはビーマセーナの恐怖に苦しんで逃げ出した。
tasya bhīmasya tatkarma rājannekasya dhīmataḥ|
apaśyāma mahārāja tadbhūtam iva abhavat'|| // 8-40-28 //
（28）そのビーマの働きを、ただ一人の賢者のそれを、大王よ、我らは見た。まるで神業のようだった』」。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe catvāriṃśo'dhyāyaḥ|| 40 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十章は終わる。
