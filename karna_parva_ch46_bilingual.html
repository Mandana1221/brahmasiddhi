マハーバーラタ ― カルナ篇 第46章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 46 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ46」（ビーマセーナがカルナとの一対一の激闘を続けつつ、ドゥルヨーダナが差し向けた多数の戦士たちと単独で渡り合う全81詩節の章）です。ドゥリタラーシュトラの問いに応じてサンジャヤが語るところによれば、ビーマがカルナを打ち倒した（前章の場面）後、ドゥルヨーダナはカルナを救援・包囲させるべく、シュルターユス、ドゥルダラ、クラータ、ヴィヴィットゥス、ヴィカタ、サマ、ニシャンギー、カヴァチー、パーシー、双子のナンドーパナンダ、ドゥシュプラダルシャ、スバーフ、ヴァータヴェガ、スヴァルチャス、ダヌルグラーハ、ドゥルマダ、ジャラサンダ、シャラ、サハなど多数の戦士を差し向けます。ビーマは単身でこれらの多くを討ち果たし（ヴィヴィットゥスの首を斬り、双子のナンドーパナンダを討つなど）、さらにカルナとの間で矢と棍棒を激しく交え合う一対一の死闘を繰り広げます。後半では、ビーマが棍棒で象軍を次々と打ち倒し、騎兵・歩兵を蹴散らす場面、またサーティヤキがカルナおよびビーマの戦車の後方をめぐって両者と渡り合う挿話が描かれ、大海の怒涛や河川の合流のような壮大な比喩を伴いつつ両軍の衝突が描写されます。章末では、パーンダヴァ軍とカウラヴァ軍の戦士たちが入り乱れて激しい一対一の決闘を繰り広げる場面で終わります（第81詩節）。なお、原典の奥書（コロフォン）には第40・42〜45章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典には、本来の第1〜81詩節の連番に先立って余分な注記「8-46-0」が冒頭の一文に付されているという特異な誤記（規則的な番号付けの前に紛れ込んだ余剰注記）が見られたため、これを第1詩節の本文に統合した上で全81詩節を正しく分離・対訳しています。
karṇaparva — ṣaṭcatvāriṃśo'dhyāyaḥ (46)
第46章
dhṛtarāṣṭra uvāca|
suduṣkaram idaṃ karma kṛtaṃ bhīmena sañjaya|
yena karṇo mahābāhū rathopasthe nipātitaḥ|| // 8-46-1 //
ドリタラーシュトラは語った。 （1）サンジャヤよ、ビーマがなした業は、まことに至難なことであった。長き腕のカルナを戦車の上に打ち倒したのだから。
karṇo hi eko raṇe hantā pāṇḍavān sṛñjayaiḥ saha|
iti duryodhanaḥ sūta prābravīn māṃ muhurmuhuḥ|| // 8-46-2 //
（2）「カルナは戦場で一人でもパーンダヴァとスリンジャヤ族を討つ者である」と、ドゥルヨーダナは再三私に告げていた。
parājitaṃ tu rādheyaṃ dṛṣṭvā bhīmena saṃyuge|
tataḥ paraṃ kim akarot putro duryodhano mama|| // 8-46-3 //
（3）戦場でビーマに敗れたカルナを見て、我が子ドゥルヨーダナは、そのあと何をしたのか。
sañjaya uvāca|
vimukhaṃ prekṣya rādheyaṃ sūtaputraṃ mahāhave|
putrastava mahārāja sodaryān idam abravīt|| // 8-46-4 //
サンジャヤは語った。 （4）大戦で後退する御者の子（カルナ）を見て、大王よ、あなたの息子は実兄弟たちに言った。
śīghraṃ gacchata bhadraṃ vo rādheyaṃ parirakṣata|
bhīmasenabhaye'gādhe majjantaṃ vyasanārṇave|| // 8-46-5 //
（5）「急いで行け、お前たちに幸いあれ。ビーマセーナの計り知れぬ恐怖の中に、不幸の海に沈むカルナを守れ」。
te tu rājñā samādiṣṭā bhīmasenaṃ jighāṃsavaḥ|
abhyavartanta saṅkruddhāḥ pataṅgāḥ pāvakaṃ yathā|| // 8-46-6 //
（6）王にこう命じられた彼らは、ビーマセーナを殺そうと、激怒して攻めかかった。炎に飛び込む虫のように。
śrutāyur durdharaḥ krātho vivitsur vikaṭaḥ samaḥ|
niṣaṅgī kavacī pāśī tathā nandopanandakau|| // 8-46-7 //
（7）シュルタユ、ドゥルダラ、クラータ、ヴィヴィツ、ヴィカタ、サマ、ニシャンギン、カヴァチン、パーシン、そしてナンダとウパナンダカ――。
duṣpradharṣaḥ subāhuś ca vātavegasuvarcasau|
dhanurgrāho durmadaś ca jalasandhaḥ śalaḥ sahaḥ|| // 8-46-8 //
（8）ドゥシュプラダルシャ、スバーフ、ヴァータヴェーガ、スヴァルチャス、ダヌルグラハ、ドゥルマダ、ジャラサンダ、シャラ、サハ――。
ete rathaiḥ parivṛtā vīryavanto mahābalāḥ|
bhīmasenaṃ samāsādya samantāt paryavārayan|| // 8-46-9 //
（9）これらは戦車に囲まれ、武勇ある大力の者として、ビーマセーナに近づき、あたり一面から取り囲んだ。
te vyamuñcan śaravrātān nānāliṅgān samantataḥ|
sa tair abhyardyamānas tu bhīmaseno mahābalaḥ|| // 8-46-10 //
（10）彼らはさまざまな形の矢の雨をあたり一面から放った。攻められる大力のビーマセーナは――。
teṣām āpatatāṃ kṣipraṃ sutānāṃ te janādhipa|
rathaiḥ pañcaśataiḥ sārdhaṃ pañcāśad ahanad rathān|| // 8-46-11 //
（11）人の主よ、攻めてくるあなたの息子たちの戦車五百を、すぐさま五十の戦車と共に討ち取った。
vivitsos tu tataḥ kruddho bhallenāpāharacchiraḥ|
bhīmaseno mahārāja tat papāta hataṃ bhuvi|| // 8-46-12 //
（12）ヴィヴィツに対して怒ったビーマセーナは、大王よ、広頭矢で頭を切り落とし、地に倒した。
sakuṇḍalaśirastrāṇaṃ pūrṇacandropamaṃ tathā|
aśobhata mahārāja pūrṇacandra iva ambare|| // 8-46-13 //
（13）耳輪をつけ兜をかぶった、満月のようなその顔が――。
taṃ dṛṣṭvā nihataṃ śūraṃ bhrātaraḥ sarvatas tadā|
abhyadravanta samare bhīmaṃ bhīmaparākramam|| // 8-46-14 //
（14）その殺された勇者を見て兄弟たちは、あたり一面からビーマの猛勇な者に襲いかかった。
tato'parābhyāṃ bhallābhyāṃ putrayoste mahāhave|
jahāra samare prāṇān bhīmo bhīmaparākramaḥ|| // 8-46-15 //
（15）二本の広頭矢によって、あなたの二人の子の命を、戦場でビーマは奪った。
tau dharām anvapadyetāṃ vātarugṇāv iva drumau|
vikaṭaś ca sahaś ca umau devaputropamau nṛpa|| // 8-46-16 //
（16）両者は風に折られた木のように地に倒れた。神の子に似たヴィカタとサハだった。
tatastu tvarito bhīmaḥ krāthaṃ ninye yamakṣayam|
nārācena sutīkṣṇena sa hato nyapatad bhuvi|| // 8-46-17 //
（17）そして急いでビーマはクラータをヤマの世界へ導いた。鋭い鉄矢に打たれて、彼は地に倒れた。
hāhākāras tatas tīvraḥ sambabhūva janeśvara|
vadhyamāneṣu vīreṣu tava putreṣu dhanviṣu|| // 8-46-18 //
（18）国王よ、弓使いの勇者たるあなたの息子たちが殺されてゆくとき、激しい嘆きの声が起こった。
teṣāṃ sululite sainye punarbhīmo mahābalaḥ|
nandopanandau samare praiṣayad yamasādanam|| // 8-46-19 //
（19）彼らの軍勢が乱れる中、大力のビーマはまた、戦場でナンダとウパナンダをヤマの住処へ送った。
tataḥ te prādravan bhītāḥ putrās te vihvalīkṛtāḥ|
bhīmasenaṃ raṇe dṛṣṭvā kālāntakayamopamam|| // 8-46-20 //
（20）するとあなたの息子たちは恐れ、動揺して逃げた。戦場のビーマセーナを、時の終わりの死神ヤマのように見て。
putrāṃs te nihatān dṛṣṭvā sūtaputraḥ sudurmanāḥ|
haṃsavarṇān hayān bhūyaḥ praiṣayad yatra pāṇḍavaḥ|| // 8-46-21 //
（21）息子たちが殺されるのを見た御者の子（カルナ）は、大いに悲しんで、白鳥の色の馬を再びパーンダヴァのもとに送った。
te preṣitā mahārāja madrarājena vājinaḥ|
bhīmasenarathaṃ prāpya samasajjanta vegitāḥ|| // 8-46-22 //
（22）マドラ王によって促された馬は、素早くビーマセーナの戦車に近づいた。
sa sannipātas tumulo ghorarūpo viśāmpate|
āsīd raudro mahārāja karṇapāṇḍavayor mṛdhe|| // 8-46-23 //
（23）国王よ、カルナとパーンダヴァ（ビーマ）との衝撃は、激しく、恐ろしく、凄まじいものであった。
dṛṣṭvā mama mahārāja tau sametau mahārathau|
āsīd buddhiḥ kathaṃ yuddham etad adya bhaviṣyati|| // 8-46-24 //
（24）大王よ、その二人の偉大な戦車戦士の出会いを見て、私は思った――「今日この戦いはどうなるのか」と。
tato bhīmo raṇaślāghī chādayāmāsa patribhiḥ|
karṇaṃ raṇe mahārāja putrāṇāṃ tava paśyatām|| // 8-46-25 //
（25）戦いに名を馳せるビーマは、大王よ、戦場で羽根矢をもってカルナを覆った。あなたの息子たちの目の前で。
tataḥ karṇo bhṛśaṃ kruddho bhīmaṃ navabhir āyasaiḥ|
vivyādha paramāstrajño bhallaiḥ sannataparvabhiḥ|| // 8-46-26 //
（26）するとカルナは激しく怒り、節のまっすぐな広頭矢・鉄矢九本でビーマを射た。最高の武器通の彼は。
tān nihatya mahābāhur bhīmo bhīmaparākramaḥ|
ākarṇapūrṇair viśikhaiḥ karṇaṃ vivyādha saptabhiḥ|| // 8-46-27 //
（27）長き腕のビーマは、それらを打ち消し、耳まで引き絞った七本の矢でカルナを射た。
tataḥ karṇo mahārāja āśīviṣa iva śvasan|
śaravarṣeṇa mahatā chādayāmāsa pāṇḍavam|| // 8-46-28 //
（28）カルナは毒蛇のように息をしながら、矢の大雨で、パーンダヴァ（ビーマ）を覆った。
bhīmo'pi tataṃ śaravrātaiś chādayitvā mahāratham|
paśyatāṃ kauraveyāṇāṃ vinanarda mahābalaḥ|| // 8-46-29 //
（29）ビーマも矢の群れで偉大な戦車戦士（カルナ）を覆い、クル族の目前で大声で叫んだ。
tataḥ karṇo bhṛśaṃ kruddho dṛḍhamādāya kārmukam|
bhīmaṃ vivyādha daśabhiḥ kaṅkapatraiḥ śilāśitaiḥ|
kārmukaṃ cāsya ciccheda bhallena niśitena ca|| // 8-46-30 //
（30）大いに怒ったカルナは、堅い弓を取り、カンカ鳥の羽根をもつ、石で鋭くされた十本の矢でビーマを射、さらに鋭い広頭矢で彼の弓を切り裂いた。
tato bhīmo mahābāhur hemapaṭṭavibhūṣitam|
parighaṃ ghoramādāya mṛtyudaṇḍam iva aparam|
karṇasya nidhanākāṅkṣī cikṣepātibalo nadan|| // 8-46-31 //
（31）すると長き腕のビーマは、金の帯で飾られた恐ろしい鉄棒を取り、死の杖のような別の武器を、カルナを倒そうと、叫びながら投げた。
tam āpatantaṃ parighaṃ vajrāśanisamasvanam|
ciccheda bahudhā karṇaḥ śarairāśīviṣopamaiḥ|| // 8-46-32 //
（32）飛来する雷のような響きの鉄棒を、カルナは毒蛇のような矢で幾つも切り裂いた。
tataḥ kārmukamādāya bhīmo dṛḍhataraṃ tadā|
chādayāmāsa viśikhaiḥ karṇaṃ parabalārdanam|| // 8-46-33 //
（33）ビーマはさらに堅固な弓を取り、矢でカルナを覆った。敵軍を苦しめる者を。
tato yuddham abhūd ghoraṃ karṇapāṇḍavayor mṛdhe|
balīndrayor iva muhuḥ parasparavadhaiṣiṇoḥ|| // 8-46-34 //
（34）カルナとパーンダヴァ（ビーマ）との間の戦いは、まるで力ある牛同士が互いを殺そうと競うかのように、再び恐ろしいものとなった。
tataḥ karṇo mahārāja bhīmasenaṃ tribhiḥ śaraiḥ|
ākarṇapūrṇair vivyādha dṛḍhamānamya kārmukam|| // 8-46-35 //
（35）大王よ、カルナは、弓を強く引き絞り、耳まで引いた三本の矢でビーマセーナを射た。
so'tividdho maheṣvāsaḥ karṇena balināṃ varaḥ|
ghoramādatta viśikhaṃ karṇakāyāvadāraṇam|| // 8-46-36 //
（36）激しく射られた大弓使いで強者の最上者（ビーマ）は、恐ろしい、カルナの体を裂く矢を取った。
tasya bhittvā tanutrāṇaṃ bhittvā kāyaṃ ca sāyakaḥ|
prāviśad varaṇīṃ rājan valmīkam iva pannagaḥ|| // 8-46-37 //
（37）その矢は、カルナの鎧を貫き、体を貫いて、蟻塚に入る蛇のように大地に入った。
sa tenātiprahāreṇa vyathito vihvalan iva||
sañcacāla rathe karṇaḥ kṣitikampe yathā'calaḥ|| // 8-46-38 //
（38）その激烈な攻撃に苦しみ、動揺したカルナは、地震のときの山のように戦車で揺れた。
tataḥ karṇo mahārāja roṣāmarṣasamanvitaḥ|
bhīmaṃ taṃ pañcaviṃśatyā nārācānāṃ samārpayat|| // 8-46-39 //
（39）するとカルナは怒りに満ちて、ビーマを二十五本の鉄矢で射た。
ciccheda kārmukaṃ tūrṇaṃ pāṇḍavasyāśu patriṇā|| // 8-46-40 //
（40）素早く羽根矢で、パーンダヴァ（ビーマ）の弓を切り裂いた。
tato muhūrtād rājendra nātikṛcchrād vasan iva|
virathaṃ bhīmakarmāṇaṃ bhīmaṃ karṇaścakāra ha|| // 8-46-41 //
（41）そしてしばらくして、王よ、難なく笑うようにして、カルナは巨大な働きをするビーマを、戦車のない者にした。
viratho bharataśreṣṭha prahasan anilopamaḥ|
gadāṃ gṛhya mahābāhur apatat syandanottamāt|| // 8-46-42 //
（42）戦車を失った風のごときビーマは笑いながら、鉄棒を取り、最高の戦車から跳び降りた。
gadayā ca mahārāja karṇasya rathakūbaram|
pothayāmāsa saṅkruddhaḥ samare śatrutāpanaḥ|| // 8-46-43 //
（43）大王よ、怒ったビーマは、鉄棒でカルナの戦車の軛を砕いた。敵を焼く者として。
sa krodhavaśamāpannaḥ pāṇḍuputraḥ pratāpavān|
vidrāvya gadayā vīrastava putrān mahāhave|| // 8-46-44 //
（44）怒りにとらわれた、輝ける力をもつパーンダヴァの子（ビーマ）は、あなたの息子たちを鉄棒で打ち退けて、――。
nāgān saptaśatān rājan nīṣādantān prahāriṇaḥ|
vyadhamat sahasā bhīmaḥ kruddharūpaḥ parantapaḥ|| // 8-46-45 //
（45）突き刺すような牙をもち、攻撃力ある七百の象たちを、怒りの姿で、敵を苦しめる彼は一気に打ち倒した。
dantaveṣṭeṣu netreṣu kumbheṣu ca kaṭeṣu ca|
marmasvapi ca marmajñastān nāgān avadhīd balī|| // 8-46-46 //
（46）急所を知る強者は、歯の根、目、こめかみ、頬、急所を打ち、その象たちを討った。
arditā bhīmasenena vinadanto bhṛśāturāḥ|
tataste prādravan bhītāḥ prahatāś ca punaḥpunaḥ|
mahāmātrās tam āvavrur meghā iva divākaram|| // 8-46-47 //
（47）ビーマセーナに打たれてひどく苦しんで叫ぶ象たちは、恐れて逃げ、何度も打たれて、象使いたちは彼を取り囲んだ。太陽を取り巻く雲のように。
tān sa saptaśatān nāgān sa ārohāyudhaketanān|
bhūmiṣṭho gadayā jaghne vajreṇa indra iva acalān|| // 8-46-48 //
（48）乗り手・武器・旗のついた七百の象たちを、地上に立ったビーマは鉄棒で、インドラが雷で山を打つように打ち殺した。
tataḥ subalaputrasya nāgān atibalān punaḥ|
pothayāmāsa kaunteyo dvipañcāśadarindamaḥ|| // 8-46-49 //
（49）さらにシャクニ（スバラの子）の極めて大力の象五十二頭を、クンティーの子、敵を制する者は打ち砕いた。
tathā rathaśatataṃ sāgraṃ pattīṃś ca śataśo'parān|
nyahanat pāṇḍavo yuddhe tāpayaṃs tava vāhinīm|| // 8-46-50 //
（50）また百以上の戦車、数百の歩兵を、パーンダヴァは戦場で殺し、あなたの軍を苦しめた。
pratāpyamānaṃ sūryeṇa bhīmena ca mahātmanā|
tava sainyaṃ sañcukoca carmāgnāvāhitaṃ yathā|| // 8-46-51 //
（51）太陽と高潔なビーマに焼かれたあなたの軍は、火にくべられた皮のように縮んだ。
te bhīmabhayasantrastās tāvakā bharatarṣabha|
vihāya samare karṇaṃ dudruvur vai diśo daśa|| // 8-46-52 //
（52）ビーマへの恐怖におののき、バーラタの雄牛よ、あなた方の軍は戦場でカルナを見捨てて十方に逃げた。
rathāḥ pañcaśatāś ca anye hādinaḥ śaravarṣiṇaḥ|
bhīmam abhyadravan ghnantaḥ śarapūgaiḥ samantataḥ|| // 8-46-53 //
（53）五百の別の戦車戦士、馬乗り、矢雨を降らす者たちが、ビーマに襲いかかり、矢の束を浴びせた。
tān sa pañcaśatān vīrān sapatākadhvajāyudhān|
pothayāmāsa gadayā bhīmo viṣṇur iva asurān|| // 8-46-54 //
（54）旗・武器を持ったこれら五百の勇者たちを、ビーマは鉄棒で打ち砕いた。ヴィシュヌがアスラたちを討つように。
tataḥ śakuninirdiṣṭāḥ sādinaḥ śūrasammatāḥ|
trisāhasrāṇi abhiyayuḥ śaraśaktyṛṣṭipāṇayaḥ|| // 8-46-55 //
（55）そしてシャクニに指示された騎兵たち、勇者として名高い三千人が、槍・投槍を手に襲いかかった。
tān pratyudgamya yavanān sāśvārohāṃs tadā'rihā|
vividhān vicaran mārgān gadayā samapothayat|| // 8-46-56 //
（56）馬乗りのヤヴァナたちに対し、敵を殺す者ビーマは、さまざまな道を歩みながら、鉄棒で彼らを打ち砕いた。
teṣām āsīn mahāñ chabdas tāḍitānāṃ ca sarvaśaḥ|
agnibhir dahyamānānāṃ nalānām iva bhārata|| // 8-46-57 //
（57）打たれたときに、彼らから大きな音が起こった。火に焼かれる葦のように。
evaṃ subalaputrasya trisāhasrān hayottamān|
hatvā anyaṃ ratham āsthāya kruddho rādheyam abhyayāt|| // 8-46-58 //
（58）このようにシャクニ（スバラの子）の三千の精鋭の馬を殺したビーマは、別の戦車に乗り、怒って御者の子（カルナ）に向かった。
karṇo'pi samare rājan dharmaputram arindamam|
sa śaraiś chādayāmāsa sārathiṃ ca api apātayat|| // 8-46-59 //
（59）カルナも戦場で、王よ、敵を制するダルマの子（ユディシュティラ）を矢で覆い、御者を倒した。
tataḥ sa pradrutaṃ sainyaṃ dṛṣṭvā karṇo mahārathaḥ|
anvadhāvat kiran bāṇaiḥ kaṅkapatrair ajihmagaiḥ|| // 8-46-60 //
（60）偉大な戦車戦士カルナは、逃げる軍を見て、カンカ鳥の羽根のまっすぐな矢を放ちながら追った。
rājānam abhidhāvantaṃ śarairāvṛtya rodasī|
kruddhaḥ pracchādayāmāsa śarajālena mārutiḥ|| // 8-46-61 //
（61）王を追ってくるカルナを、怒った大風の子（ビーマ）は、矢の網で天地を覆い、阻んだ。
sannivṛttas tatas tūrṇaṃ rādheyaḥ śatrukarśanaḥ|
bhīmaṃ pracchādayāmāsa samantān niśitaiḥ śaraiḥ|| // 8-46-62 //
（62）敵を苦しめるカルナは、すぐに向き直って、鋭い矢であたり一面からビーマを覆った。
bhīmasenarathaprepsuṃ karṇaṃ bhārata sātyakiḥ|
abhyardayad ameyātmā pārṣṇigrahaṇakāraṇāt|| // 8-46-63 //
（63）ビーマセーナの戦車を狙うカルナを、バーラタよ、無量の魂のサーティヤキは、側面の守りを固めようとカルナを攻めた。
bhīmasenarathaprepsuṃ karṇo bhārata sātyakim|
abhyavartata śaineyam ardayan śaravṛṣṭibhiḥ|| // 8-46-64 //
（64）ビーマセーナの戦車を狙うカルナは、バーラタよ、サーティヤキに対して、矢の雨を降らせながら向かった。
tāvanyonyaṃ samāsādya vṛṣabhau sarvadhanvinām|
visṛjantau śarān dīptān vibhrājetāṃ manasvinau|| // 8-46-65 //
（65）互いに向き合う弓使いの雄牛たる両者は、放つ光る矢をもって、誇らしげに輝いた。
tābhyāṃ viyati rājendra vitataṃ bhīmadarśanam|
kauñcapṛṣṭhāruṇaṃ raudraṃ bāṇajālaṃ vyadṛśyata|| // 8-46-66 //
（66）両者によって空中に張られた、恐るべき様相を呈する、クラウンチャ鳥の背のように赤い、恐ろしい矢の網が見えた。
naiva sūryaprabhā rājan na diśaḥ pradiśas tathā|
prājñāsiṣma vayaṃ te vā śarairmuktaiḥ sahasraśaḥ|| // 8-46-67 //
（67）王よ、太陽の光も、諸方向も、我らもあなた方も、数千の矢で放たれて、何も分からなくなった。
madhyāhne tapato rājan bhāskarasya mahāprabhāḥ|
hṛtāḥ sarvāḥ śaraughais taiḥ karṇamādhavayos tadā|| // 8-46-68 //
（68）王よ、真昼に輝く太陽の強い光は、カルナとサーティヤキ（マーダヴァ族の者）の矢の群れによって、すべて覆われた。
saubalaṃ kṛtavarmāṇaṃ drauṇimādhirathiṃ kṛpam|
saṃsaktān pāṇḍavair dṛṣṭvā nivṛttāḥ kuravaḥ punaḥ|| // 8-46-69 //
（69）シャクニ（スバラの子）、クリタヴァルマン、ドローナの子、御者の子、クリパ――これらがパーンダヴァたちと激突するのを見て、クル族は再び向かった。
teṣām āpatatāṃ śabdas tītra āsīd viśāmpate|
udvṛttānāṃ yathā vṛṣṭyā sāgarāṇāṃ bhayāvahaḥ|| // 8-46-70 //
（70）彼らの襲いかかる音は激しく、国王よ、まるで嵐の海のように恐ろしかった。
te sene bhṛśasaṃsakte dṛṣṭvā anyonyaṃ mahāhave|
harṣeṇa mahatā yukte parigṛhya parasparam|| // 8-46-71 //
（71）両軍が大戦場で激突するのを見て、両者は大きな喜びで互いを掴み合った。
tataḥ pravavṛte yuddhaṃ madhyaṃ prāpte divākare|
yādṛśaṃ na evam asmābhir dṛṣṭapūrvaṃ na ca śrutam|| // 8-46-72 //
（72）そして太陽が中天に達したとき、戦いが激しく行われた。我らがかつて見たことも聞いたこともないような戦いが。
balaughas tu samāsādya balaughaṃ sahasā raṇe|
upasarpata vegena vāryogha iva sāgaram|| // 8-46-73 //
（73）軍勢と軍勢が急に戦場で出会い、水の流れが海に流れ込むように勢いよく押し寄せた。
āsīn ninādaḥ sumahān bāṇaughānāṃ parasparam|
garjatāṃ sāgaraughāṇāṃ yathā syān niḥsvano mahān|| // 8-46-74 //
（74）矢の群れの大きな音が互いに起こり、吠える海の轟きのような大音響となった。
te tu sene samāsādya vegavatyau parasparam|
ekībhāvam anuprāpte nadyau iva samāgame|| // 8-46-75 //
（75）勢いある二つの軍は互いにぶつかり、川の合流点のごとく、一つになった。
tataḥ pravavṛte yuddhaṃ ghorarūpaṃ viśāmpate|
kurūṇāṃ pāṇḍavānāṃ ca lipsatāṃ sumahadyaśaḥ|| // 8-46-76 //
（76）そして恐ろしい様相の戦いが始まった。大いなる名声を求めるクル族とパーンダヴァの。
śūrāṇāṃ garjatāṃ tatra hyavicchedakṛtā giraḥ|
śruyante vividhā rājan nāmāni uddiśya bhārata|| // 8-46-77 //
（77）叫ぶ勇者たちの声が途切れることなく続き、さまざまに、名を呼び合うのが聞かれた。
yasya yad hi raṇe vyaṅgaṃ pitṛto mātṛto'pi vā|
karmataḥ śīlato vā'pi sa tat śrāvayate yudhi|| // 8-46-78 //
（78）戦場で、だれかが父や母、行いや性格に関して、ある欠点があれば、人々はそれを戦場で言い立てた。
tān dṛṣṭvā samare śūśāṃs tarjamānān parasparam|
abhavanme matī rājan na eṣām astīti jīvitam|| // 8-46-79 //
（79）互いに威嚇する勇者たちを戦場で見て、王よ、私は思った――「彼らの命はもはや長くあるまい」と。
teṣāṃ dṛṣṭvā tu kruddhānāṃ vapūṃṣi amitatejasām|
abhavanme bhayaṃ tīvraṃ katham etad bhaviṣyati|| // 8-46-80 //
（80）激怒した無量の光輝をもつ彼らの姿を見て、私は激しい恐怖を感じ、「これは一体どうなるのか」と思った。
tataḥ te pāṇḍavā rājan kauravāś ca mahārathāḥ|
tatakṣuḥ sāyakais tūrṇam anyonyaṃ vijayaiṣiṇaḥ|| // 8-46-81 //
（81）王よ、パーンダヴァ、そしてクル族の偉大な戦車戦士たちは、勝利を求めて急いで鋭い矢で互いを切り裂いた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ṣaṭcatvāriṃśo'dhyāyaḥ|| 46 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十六章は終わる。
