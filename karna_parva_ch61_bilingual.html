マハーバーラタ ― カルナ篇 第61章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 61 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ61」、全23詩節からなり、クリシュナがアルジュナにユディシュティラの危機を告げる場面を描きます。戦場の血で大地が赤く染まった後（第1詩節）、砂塵が晴れてクリシュナがアルジュナにダルマ王ユディシュティラを指し示す場面（第2詩節）から始まり、ドゥルヨーダナが象軍を率いてユディシュティラを追う様子（第3〜10詩節）、クリシュナが「ユディシュティラは死の口に入った」と警告する場面（第11詩節）、カルナの矢の勢いの恐ろしさを述べる場面（第12〜14詩節）、カルナがユディシュティラを敗走させた様子（第15〜16詩節）、ユディシュティラがブラーフマの力（忍耐の力）に頼っており武力に優れていないことを告げる場面（第17〜19詩節）、ビーマが耐えているという危機の証拠（第20〜21詩節）、そしてカルナが「ユディシュティラを殺せ」と鼓舞し、大戦車戦士たちが追いかける場面（第22〜23詩節）で本章は終わります。本章は第十七日戦闘（サプタダシャ・ディヴァサ・ユッダ）の開幕となる章でもあり、クリシュナの語りのみで構成される点が特徴的です。なお、本章では冒頭の注記「8-61-0」「8-61-0x」（「サンジャヤは語った」）が第1詩節の本文に統合されています。本章末の結びの一文「マハーバーラタ・カルナ篇・第十七日戦闘における第61章終わり」は和訳原典に記載されており、そのまま掲載しています（第51〜60章における連続欠落の後、本章より結びの一文が再開されます）。OCR誤記としては、第16詩節「balavā~l lughuhastaś」の揺らぎ文字（balavā~l→balavāl「強力な」、lughu→laghu「軽い＝敏捷な」）を修正しています。
karṇaparva — ekaṣaṣṭitamo'dhyāyaḥ (61)
第61章
sañjaya uvāca|
teṣāṃ pravṛtte saṅgrāme vipule śoṇitodake|
rarāja lohitena urvī saṃsiktā bahudhā bhṛśam||
// 8-61-1 //
彼らの間で血の河が流れる大いなる戦いが始まり、赤い血で繰り返し染められた大地は輝いていた。
tato rajasi saṃśānte prakāśaḥ sarvato'bhavat|
etasminn antare pārthaṃ kṛṣṇo vacanam abravīt|
darśayann iva kaunteyaṃ dharmarājaṃ yudhiṣṭhiram||
// 8-61-2 //
やがて砂塵が収まり、四方が明るくなった。その折、クリシュナはアルジュナに語りかけた。まるでクンティーの子に、ダルマ王ユディシュティラを指し示すかのように。
eṣa pāṇḍava te bhrātā dhārtarāṣṭrair mahābalaiḥ|
jighāṃsubhir maheṣvāsaiḥ śīghraṃ pārtho'nusāryate||
// 8-61-3 //
「パーンダヴァよ、おまえの兄は、殺意を持つ大弓の強者たるドリタラーシュトラの息子たちに、急速に追われているぞ。」
tam anvag eva pāñcālāś cedimātsyāś ca bhārata|
anuyānti mahātmānaṃ parīpsanto mahājavāḥ||
// 8-61-4 //
パーンチャーラ族、チェーディ族、マツヤ族がバーラタよ、偉大なる王を守ろうと、全速力で後に続いている。
eṣa duryodhanaḥ pārtha gajānīkena daṃśitaḥ|
rājā sarvasya lokasya rājānam anudhāvati||
// 8-61-5 //
パールタよ、見よ、ドゥルヨーダナは象の軍勢で武装し、全世界の王たる者として王（ユディシュティラ）を追いかけているのだ。
jighāṃsuḥ puruṣavyāghraṃ bhrātṛbhiḥ sahito balī|
āśīviṣasamasparśaiḥ sarvāyudhaviśāradaiḥ||
// 8-61-6 //
殺意を持ち、兄弟たちと共に力強く、毒蛇のごとき触れるもの全てを苦しめる者たち、あらゆる武器に通じた者たちと共にいるのだ。
nadadbhiḥ siṃhanādāṃś ca dhamadbhiś ca api vārijān|
balavadbhir maheṣvāsair vidhūnvānair dhanūṃṣi ca||
// 8-61-7 //
獅子吼を上げ、法螺貝を吹き鳴らし、強力な大弓を振るう力ある者たちと共にいる。
ete jighṛkṣavo yānti dvipāśvarathapattayaḥ|
yudhiṣṭhiraṃ dhārtarāṣṭro ratnottamam iva arthinaḥ||
// 8-61-8 //
象兵・馬兵・戦車兵・歩兵が、ユディシュティラを捕らえんとして進んでいる。ドリタラーシュトラの子は、最高の宝を求める者のように。
paśya sātvatabhīmābhyāṃ niruddhā viṣṭhitāḥ punaḥ|
jihīrṣavo'mṛtaṃ daityāḥ śakrāgnibhyām iva āhave||
// 8-61-9 //
見よ、サートヴァタ（サーティヤキ）とビーマによって阻まれ、彼らは一旦立ち止まった。ちょうど甘露を奪おうとするダイティヤたちが、インドラとアグニに阻まれるように。
ete bahutvāt tvaritāḥ punar gacchanti pāṇḍavam|
samudram iva vāryoghāḥ prāvṛṭkāle mahārathāḥ||
// 8-61-10 //
しかし数の多さに勢いづいて、大戦車戦士たちは再びパーンダヴァ（ユディシュティラ）に向かう。雨季の水流が海に流れ込むように。
mṛtyor mukhagataṃ manye kuntīputraṃ yudhiṣṭhiram|
hutam agnau ca kaunteyaṃ duryodhanavaśaṃ gatam||
// 8-61-11 //
パールタよ、クンティーの子ユディシュティラは死の口に落ちたと私は思う。カウンテーヤは火に投じられ、ドゥルヨーダナの支配下に入ったと。
yathāyuktam anīkaṃ hi dhārtarāṣṭrasya pāṇḍava|
nāsya śakro'pi mucyeta samprāpto bāṇagocaram||
// 8-61-12 //
パーンダヴァよ、ドリタラーシュトラの子の軍勢の配置は実に巧みであり、矢の射程に入った者は、インドラでさえ逃れられまい。
duryodhanasya vīrasya śaraughāñ śīghramasyataḥ|
saṅkruddhasya āntakasya iva ko vegaṃ saṃsahed raṇe||
// 8-61-13 //
勇敢なドゥルヨーダナが矢の雨を素早く放つとき、怒れる死神のごとく、誰がその勢いに耐えられようか。
rasatas tasya vīrasya drauṇeḥ śāradvatasya ca|
karṇasya ca iṣuvego vai parvatān api śātayet||
// 8-61-14 //
彼ら勇者たちが轟き、ドローナの子（アシュヴァッターマン）、シャーラドヴァタ（クリパ）、そしてカルナの矢の勢いは山をも砕くであろう。
karṇena ca kṛto rājā vimukho'dya tu dṛśyate||
// 8-61-15 //
王（ユディシュティラ）はカルナによって敗走させられ、今や顔を背けて見えている。
balavāl laghuhastaś ca kṛtī yuddhaviśāradaḥ|
rādheyaḥ pāṇḍavaśreṣṭhaṃ śaktaḥ pīḍayituṃ raṇe|
sahito dhṛtarāṣṭrasya putraiḥ śūrair mahābalaiḥ||
// 8-61-16 //
力強く、素早い手さばきで、熟練し、戦いに通じたラーデーヤ（カルナ）は、ドリタラーシュトラの勇敢な息子たちと共に、パーンダヴァの最高の者（ユディシュティラ）を戦場で苦しめる力がある。
tasya ebhir yudhyamānasya saṅgrāme śaṃsitātmanaḥ|
anyair api ca pārthasya kṛtaṃ karma mahārathaiḥ||
// 8-61-17 //
戦場で彼らと戦う武勇を誓った王（ユディシュティラ）に対し、ドゥルヨーダナら大戦車戦士たちが為すべきことを為し遂げたのだ。
upavāsakṛśo rājā bhṛśaṃ bharatasattamaḥ|
brāhmo bale sthito hy eṣa na kṣātre hi bale vibhuḥ||
// 8-61-18 //
王はバーラタ族の最高者であるが、断食で痩せ細り、ブラーフマの力（忍耐の力）に頼っており、クシャトラの力（武力の力）においては優れていなかった。
karṇena ca abhiyukto 'yam bhūpatiḥ śatrutāpanaḥ|
saṃśayaṃ samanuprāptaḥ pāṇḍavo vai yudhiṣṭhiraḥ||
// 8-61-19 //
敵を苦しめる王パーンダヴァ・ユディシュティラは、カルナに攻め立てられ、危機に陥ったのだ。
na jīvati mahārājo manye pārtha yudhiṣṭhiraḥ|
yad bhīmasenaḥ sahate siṃhanādam amarṣaṇaḥ||
// 8-61-20 //
パールタよ、大王ユディシュティラはもう生きてはいまいと私は思う。なぜなら、怒りを堪えぬビーマセーナが、（敵の）獅子吼を我慢しているからだ。
nardatāṃ dhārtarāṣṭrāṇāṃ punaḥ punar arindamaḥ|
dhamatāṃ ca mahāśaṅkhān saṅgrāme jitakāśinām||
// 8-61-21 //
ドリタラーシュトラの息子たちが繰り返し吼え、勝ち誇ったように戦場で大法螺貝を吹き鳴らしているのに、敵を滅ぼすビーマは耐えているのだ。
yudhiṣṭhiraṃ pāṇḍaveyaṃ hata iti bharatarṣabha|
sañcodayaty asau karṇo dhārtarāṣṭrān mahābalān||
// 8-61-22 //
バーラタの雄牛よ、カルナは大力のドリタラーシュトラの息子たちに『ユディシュティラを殺せ』と鼓舞しているのだ。
sthūṇākarṇāstrajālena pārtha pāśupatena ca|
pracchādayanti rājānam anuyānti mahārathāḥ||
// 8-61-23 //
パールタよ、スターナカルナの武器の網とパーシュパタの武器で王を覆い尽くしながら、大戦車戦士たちが王を追っているのだ。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekaṣaṣṭitamo'dhyāyaḥ|| 61 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第61章終わり。
