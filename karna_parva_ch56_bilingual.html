マハーバーラタ ― カルナ篇 第56章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 56 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ56」、全48詩節からなり、アシュヴァッターマンによるパーンディヤ王殺害を描きます。ドゥリタラーシュトラがサンジャヤに、これまで語られなかったパーンディヤ王の武勇について問う場面から始まり（第1〜2詩節）、サンジャヤの語りに転じてアシュヴァッターマンとパーンディヤ王の壮絶な一騎打ちが描かれます（第3〜44詩節）。最終的にアシュヴァッターマンがパーンディヤ王を討ち果たし、その首と両腕を切り落として大地に倒し（第45〜46詩節）、配下の兵士たちを羅刹への供物として捧げた後、ドローナの子はドゥルヨーダナの息子たちに迎えられ称賛されます（第47〜48詩節）。本章では、冒頭の「ドゥリタラーシュトラは語った」の一文に付された注記「8-56-0」「8-56-0x」を第1詩節の本文に統合し、さらに第2詩節と第3詩節の間にも「サンジャヤは語った」という語り手転換を示す注記「8-56-3x」が現れ、これも同様の処理によって第3詩節の本文に自然に統合されています（これまでの章ではこうした語り手転換注記は中盤に現れることが多かったのに対し、本章では序盤に現れる点が特徴的です）。第46〜47詩節は原典上、角括弧「[ ]」で異文（テキストバリアント）として括られていますが、内容に欠落はなく通常通り訳出しています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜55章に続き六章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、第43詩節「पड्भिः पडृतूपमत्विषः」のष/प（ṣa/pa）字形混同（paḍbhiḥ paḍṛtūpamatviṣaḥ→ṣaḍbhiḥ ṣaḍṛtūpamatviṣaḥ「六本の矢で」）を、前詩節（第42詩節）の「caturdaśa（十四本）」という矢の総数と、本詩節中の「五本」「三本」という言及（5+3+6=14）との算術的整合性により修正しています。また第42詩節末「मन्युना'」のアポストロフィは、直後の語「पादाहतो」が子音始まりであるため正規のアヴァグラハ（母音脱落記号）としては成立し得ない誤記と判断し、削除しています。
karṇaparva — ṣaṭpañcāśo'dhyāyaḥ (56)
第56章
dhṛtarāṣṭra uvāca|
proktas tvayā pūrvam eva pravīro lokaviśrutaḥ|
na tu asya karma saṅgrāme tvayā sañjaya kīrtitam|| // 8-56-1 //
ドゥリタラーシュトラは語った。 （1） サンジャヤよ、汝は以前この世に名高い勇者のことを語ったが、彼の戦場での活躍は語られていなかった。
tasya vistaraśo brūhi pravīrasyādya vikramam|
śikṣāṃ prabhāvaṃ vīryaṃ ca pramāṇaṃ darpam eva ca|| // 8-56-2 //
（2） 今日、その勇者の武勇を詳しく語ってくれ。その技、威力、勇気、力量、そして誇りを。
sañjaya uvāca|
bhīṣmadroṇakṛpadrauṇikarṇārjunajanārdanān|
samāptavidyān dhanuṣi śreṣṭhān yān sapta manyase|| // 8-56-3 //
サンジャヤは語った。 （3） 汝がビーシュマ、ドローナ、クリパ、ドラウニ、カルナ、アルジュナ、ジャナールダナの七人を弓術に通じた最高の者と見なすならば、
yo hi ākṣipati vīryeṇa sarvān etān mahārathān|
na mene ca ātmanā tulyaṃ kañcid eva nareśvaram|| // 8-56-4 //
（4） この者は武勇によってこれら全ての大戦車戦士を凌ぎ、自分に匹敵する王は誰もいないと考えていた。
tulyatāṃ droṇabhīṣmābhyām ātmano yo na mṛṣyate|
vāsudevārjunābhyāṃ ca nyūnatāṃ na aicchat ātmani|| // 8-56-5 //
（5） ドローナやビーシュマとの対等さも認めず、ヴァースデーヴァやアルジュナより劣ることも望まなかった。
sa pāṇḍyo'rthapatiśreṣṭhaḥ sarvaśastrabhṛtāṃ varaḥ|
karṇasya anīkam ahanat pāśahasta iva antakaḥ|| // 8-56-6 //
（6） 武器を持つ者の中で最も優れたパーンディヤ王は、死神が縄を手にするように、カルナの軍を打ち倒した。
tad udīrṇarathāśvebhaṃ pattipravarasaṅkulam|
kulālacakravaddhāntaṃ pāṇḍyena abhyāhataṃ balāt|| // 8-56-7 //
（7） 戦車・馬・象が躍動し精鋭歩兵がひしめくその軍は、パーンディヤに力尽くで打たれ、陶工の轆轤のように回転した。
vyaśvasūtadhvajarathān viprayuktayugān rathān|
samyag astaiḥ śaraiḥ pāṇḍyo vāyur meghān iva akṣipat|| // 8-56-8 //
（8） パーンディヤは的確に放った矢で、馬と御者と旗を失った戦車を、風が雲を吹き散らすように吹き飛ばした。
dviradān pravarārohān vipatākāyudhadhvajān|
sa pādarakṣān ahanad vajreṇa adrīn iva adrihā|| // 8-56-9 //
（9） 優れた騎手を乗せた象を、旗も武器も旗印も奪い、足元の守衛ともどもインドラが雷で山を砕くように倒した。
sa śaktiprāsatūṇīrān aśvārohān hayān api|
pulindakhasabāhlīkaniṣādāndhrakakuntalān|| // 8-56-10 //
（10） パーンディヤは矛と槍と矢筒をつけた騎兵や馬を、プリンダ族、カサ族、バーフリーカ族、ニシャーダ族、アーンドラ族、クンタラ族を、
dākṣiṇātyāṃś ca bhojāṃś ca śūrān saṅgrāmakarkaśān|
viśastrakavacān bāṇaiḥ kṛtvā pāṇḍyo'karod vyasūn|| // 8-56-11 //
（11） 南方の者たちやボージャ族の勇者たちを、戦闘に厳しい者たちを、武器と鎧を奪った上で矢で殺した。
caturaṅgaṃ balaṃ bāṇair nighnantaṃ pāṇḍayam āhave|
dṛṣṭvā drauṇir asambhrāntam asambhrāntas tato'bhyayāt|| // 8-56-12 //
（12） 四軍からなる軍を矢で倒し続けるパーンディヤを戦場で見て、ドラウニは慌てることなく冷静に向かって行った。
ābhāṣya ca enaṃ madhuram abhītaṃ tam abhītavat|
prāha praharatāṃ śreṣṭhaḥ smitapūrvaṃ samāhvayat|| // 8-56-13 //
（13） 打撃の達人の最高者は彼に優しく語りかけ、恐れぬ者に恐れぬように微笑みを浮かべて挑んだ。
rājan kamalapatrākṣa pradhānāyudhavāhana|
vajrasaṃhananaprakhya prakhyātabalapauruṣa|| // 8-56-14 //
（14） 「王よ、蓮の花弁のような目を持つ者よ、最も優れた武器と乗り物を持つ者よ、雷のごとき体の者よ、力と勇気で名高い者よ。
muṣṭikliṣṭāṅgulibhyāṃ ca vyāyatābhyāṃ mahaddhanuḥ|
dorbhyāṃ visphārayan bhāsi mahājaladavad bhṛśam|| // 8-56-15 //
（15） 握りしめた指の両腕で大弓をしならせる汝の姿は、大雨雲のように轟く。
śaravarṣair mahāvegair amitrān abhivarṣataḥ|
mad anyaṃ na anupaśyāmi prativīraṃ tava āhave|| // 8-56-16 //
（16） 大速度の矢の雨で敵を射る汝に、戦場で対抗できるのは私以外にはいない。
rathadviradapattyaśvān ekaḥ pramathase bahūn|
mṛgasaṅghān iva araṇye vibhīr bhīmabalo hariḥ|| // 8-56-17 //
（17） 恐れなき大力のライオンが森で鹿の群れを蹂躙するように、汝は一人で戦車・象・歩兵・馬の多くを蹂躙している。
mahatā rathaghoṣeṇa divaṃ bhūmiṃ ca nādayan|
varṣānte sasyāṃ sūryo bhābhir ādīpayan iva|| // 8-56-18 //
（18） 大戦車の轟きで天と地を震わせ、雨季の終わりの太陽が穀物を光で輝かせるように。
saṃspṛśānaḥ śaraiḥ pūrṇau tūṇī ca āśīviṣopamaiḥ|
mayā eva ekena yudhyasva tryambakena andhako yathā|| // 8-56-19 //
（19） 猛毒の蛇のような矢で満ちた二つの矢筒に触れながら、三つ目の神（シヴァ）がアンダカと戦ったように、私一人と戦え。」
evam uktas tathā iti uktvā pramathya enaṃ sa pārthivaḥ|
karṇinā droṇatanayaṃ vivyādha malayadhvajaḥ|| // 8-56-20 //
（20） こう言われてマラヤの旗を持つ王は「然り」と答え、パーンディヤの王はドローナの息子を一本の耳矢で射た。
marmabhedibhir atyugrair bāṇair agniśikhopamaiḥ|
marmasv abhyahanad drauṇiḥ pāṇḍyam ācāryanandanaḥ|| // 8-56-21 //
（21） 師の息子ドラウニは、火の炎のような極めて恐ろしい矢で急所を射て、パーンディヤを打った。
tato'parān navāṃs tūrṇaṃ nārācān kaṅkavāsasaḥ|
gatyā daśamyā saṃyuktān aśvatthāmā'py avāsṛjat|| // 8-56-22 //
（22） さらにアシュヴァッターマンは新たに九本の鉄矢を、鳥の羽をつけた第十の飛び方で放った。
tān acchinat tadā pāṇḍyaś caturbhir aparaiḥ śaraiḥ|
caturo'bhyāhanac ca āśvān āśu te vyasavo'bhavan|| // 8-56-23 //
（23） パーンディヤはそれらを四本の別の矢で切り落とし、さらに四頭の馬を素早く殺した。
atha droṇasutasya iṣūṃs tāñ chittvā niśitaiḥ śaraiḥ|
dhanurjyāṃ vitatāṃ pāṇḍyaś ciccheda ādityatejasaḥ|| // 8-56-24 //
（24） 太陽のような輝きを持つドラウニの矢を切り裂き、パーンディヤは張られた弓弦をも断ち切った。
divyaṃ dhanur atha adhijyaṃ kṛtvā drauṇir amitrahā|
prekṣya ca āśu rathe yuktān narair anyān hayottamān|| // 8-56-25 //
（25） 敵を滅ぼすドラウニは神聖なる弓に弦を張り、素早く他の優れた馬を戦車に繋がせた。
tataḥ śarasahasrāṇi preṣayāmāsa vai dvijaḥ|
iṣusambādham ākāśam akarod diśa eva ca|| // 8-56-26 //
（26） そしてこのバラモンは数千の矢を放ち、空と方角を矢で塞いだ。
tatas tān asyataḥ sarvān drauṇer bāṇān mahātmanaḥ|
jānāno'py akṣayān pāṇḍyo śātayat puruṣarṣabhaḥ|| // 8-56-27 //
（27） 偉大な魂のドラウニが放つ矢が尽きないことを知りながらも、パーンディヤ王は人の最良者としてそれらを叩き落とした。
prayuktāṃs tān prayatnena chittvā drauṇer iṣūn ariḥ|
cakrarakṣau raṇe tasya prāṇudan niśitaiḥ śaraiḥ|| // 8-56-28 //
（28） 力を込めてドラウニの矢を切り裂いた敵は、鋭い矢で彼の車輪の護衛二人を戦場で突き飛ばした。
atha tal lāghavaṃ dṛṣṭvā maṇḍalīkṛtakārmukaḥ|
prāsyad droṇasuto bāṇān vṛṣṭiṃ pūṣānujo yathā|| // 8-56-29 //
（29） その軽業を見て、弓を円に回すドローナの息子は、パルジャニヤ（雨神）の弟のように矢の雨を放った。
aṣṭāv aṣṭagavān yūhuḥ śakaṭāni yad āyudham|
ahnas tad aṣṭabhāgena drauṇiś cikṣepa māriṣa|| // 8-56-30 //
（30） 八頭の雄牛が引く八台の荷車に載せた武器を、親愛なる者よ、ドラウニは一日の八分の一（約一ヤーマ半）で射尽くした。
tam antakam iva kruddham antakālāntakopamam|
ye ye dadṛśire rūpaṃ visaṃjñāḥ prāyaśo'bhavan|| // 8-56-31 //
（31） 怒れる死神のような、終末の時の死神のような彼の姿を見た者は、ほぼ全員が意識を失った。
ācāryaputras tāṃ senāṃ bāṇavṛṣṭyā vyavīvṛṣat|
parjanya iva gharmānte vṛṣṭyā sādridrumāṃ mahim|| // 8-56-32 //
（32） 師の息子は雨季の終わりの雨雲が山と樹木の大地に雨を降らすように、矢の雨でその軍を潤した。
drauṇiparjanyamuktāṃ tāṃ bāṇavṛṣṭiṃ suduḥsahām|
vāyavyāstreṇa sa kṣipraṃ viddhvā pāṇḍyātilo'nadat|| // 8-56-33 //
（33） ドラウニの雲が放つ耐え難い矢の雨を、パーンディヤは素早くヴァーユの武器で砕き、叫んだ。
tasya nānadataḥ ketuṃ candanāgururūṣitam|
malayapratimaṃ drauṇiś chittvā aśvāṃś caturo'hanat|| // 8-56-34 //
（34） 叫ぶ彼の旗印を——栴檀と沈香で飾られたマラヤ山のようなそれを——ドラウニは切り落とし、四頭の馬を殺した。
sūtam ekeṣuṇā hatvā mahājaladaniḥsvanam|
dhanuś chittvā'rdhacandreṇa tilaśo vyadhamad ratham|| // 8-56-35 //
（35） 大雷雲のような声の御者を一矢で殺し、弓を半月矢で断ち、戦車をばらばらに砕いた。
astrair astrāṇi saṃvārya chittvā sarvāyudhāni ca|
prāptam apy ahitaṃ drauṇir na ahanad yuddhatṛṣṇayā|| // 8-56-36 //
（36） 武器で武器を退け、全ての武具を切り落としながらも、ドラウニは戦いへの渇望から、到達した敵を殺さなかった。
hateśvaro dantivaraḥ sukalpitasatvarābhisṛṣṭaḥ pratiśabdago balī|
tam ādravad drauṇiśarāhatas tvaran javena kṛtvā pratihastigarjitam|| // 8-56-37 //
（37） 主を失ったよく装備された象が、ドラウニの矢に打たれながらも急いで反撃の叫びを上げて突進してきた。
taṃ vāraṇaṃ vāraṇayuddhakovido dvipottamaṃ parvatasānusannibham|
sambhyatiṣṭhan malayadhvajas tvaran yathā'driśṛṅgaṃ harir unnadaṃs tathā|| // 8-56-38 //
（38） 象の戦いに熟達したマラヤの旗を持つパーンディヤ王は、山の峰のようなその最上の象に急いで乗った。ライオンが吼えながら山の峰に立つように。
sa tomaraṃ bhāskararaśmivarcasaṃ balāstrasargottamayatnamanyubhiḥ|
sasarja śīghraṃ paripīḍayan gajaṃ guroḥ sutāya draviḍeśvaro nadan|| // 8-56-39 //
（39） 太陽の光のようなトマラを、力と武器と最高の技と怒りを込めて、象を象刺し棒で駆り立てながら、叫ぶドラヴィダの王は師の息子に放った。
maṇipravekottamavajrahāṭakair alaṅkṛtaṃ cāṃśukamālyamauktikaiḥ|
hato mayā āsīt iti asakṛn mudā nadan parābhinad drauṇivarāṅgabhūṣaṇam|| // 8-56-40 //
（40） 「殺したぞ！」と歓喜して何度も叫びながら、宝石と金剛石と黄金で飾られた、絹と花輪と真珠で飾られたドラウニの最上の冠飾りを打ち砕いた。
tad arkacandragrahapāvakatviṣaṃ bhṛśābhighātāt patitaṃ vighūrṇitam|
mahendravajrābhihataṃ mahāsvanaṃ yathā'driśṛṅgaṃ bharaṇītale tathā|| // 8-56-41 //
（41） 太陽・月・星・火のような輝きを持つそれは、激しい打撃で落ちて揺れ動き、大インドラの雷に打たれた大音声の山の峰がバラニーの星座の領域に落ちるかのようであった。
tataḥ prajajvāla pareṇa manyunā pādāhato nāgapatir yathā tathā|
samādade ca antakadaṇḍasannibhān iṣūn amitrāntakarāṃś caturdaśa|| // 8-56-42 //
（42） 足で踏まれた蛇の王のように極度の怒りに燃え上がり、ドラウニは死神の杖のような十四本の矢を取った。
dvipasya pādāgrakarān sa pañcabhir nṛpasya bāhū ca śiro'tha ca tribhiḥ|
jaghāna ṣaḍbhiḥ ṣaḍṛtūpamatviṣaḥ sa pāṇḍyarājānucarān mahārathān|| // 8-56-43 //
（43） 五本で象の足と鼻を、三本で王の両腕と首を打ち、六つの季節の輝きのような六本の矢でパーンディヤ王の従者の大戦車戦士たちを倒した。
sudīrghavṛttau varacandanokṣitau suvarṇamuktāmaṇivajrabhūṣaṇau|
bhujau dharāyāṃ patitau nṛpasya tau viceṣṭatus tārkṣyahatāv iva uragau|| // 8-56-44 //
（44） 長く丸みのある上質の栴檀で塗られ、黄金・真珠・宝石・金剛石で飾られた王の両腕が大地に落ちて、ガルダに打たれた二匹の蛇のようにのたうった。
śiraś ca tatpūrṇaśaśiprabhānanaṃ saroṣatāmrāyatanetramunnasam|
kṣitāv api bhrājati tatsakuṇḍalaṃ viśākhayor madhyagataḥ śaśī yathā|| // 8-56-45 //
（45） 満月のように輝く顔を持ち、怒りで赤銅色に染まった大きな目と高い鼻、耳飾りをつけたその首は大地に落ちてなお輝いた。二つのヴィシャーカー星の間の月のように。
sa tu dvipaḥ pañcabhir uttameṣubhiḥ kṛtaḥ ṣaḍaṃśaś caturo nṛpas tribhiḥ|
kṛto daśāṃśaḥ kuśalena yudhyatā yathā havis tad daśa daivataṃ tathā|| // 8-56-46 //
（46） 五本の最上の矢で象は六つに分けられ、三本で王は四つに分けられた。十に分ける技は、供物が十の神格に分けられるのと同様であった。
sa pādaśo rākṣasabhojanān bahūn pradāya pāṇḍyo'śvamanuṣyakuñjarān|
svadhām iva āpya jvalanaḥ pitṛpriyas tataḥ praśāntaḥ salilapravāhataḥ|| // 8-56-47 //
（47） パーンディヤ王は馬・人間・象を各部に分けて羅刹の食物として多く捧げ、水の流れで消される父祖を喜ばせる火のように、静まった。
samāptavidyaṃ tu guroḥ sutaṃ nṛpaḥ samāptakarmāṇam upetya te sutaḥ|
suhṛdvṛto'tyartham apūjayan mudā jite balau viṣṇum iva amareśvaraḥ|| || // 8-56-48 //
（48） 学を究めた師の息子が使命を果たしたのを見て、汝の息子は友人たちに囲まれ大いに喜んで彼を称えた。インドラがバリを打ち負かした後にヴィシュヌを称えるように。
