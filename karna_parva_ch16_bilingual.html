karṇaparva — ṣoḍaśo'dhyāyaḥ (16)
第16章　ユユツとウルーカの戦い、シャクニの子とスタソーマの戦い
sañjaya uvāca|
yuyutsaṃ tava putrasya drāvayantaṃ balaṃ mahat|
ulūko nyapatattūrṇaṃ tiṣṭhatiṣṭheti cābravīt|| // 8-16-1 //
サンジャヤは語った。 （1）あなたの息子（ドゥルヨーダナ）の大軍を敗走させているユユツに、ウルーカが素早く襲いかかり、「待て、待て！」と叫びました。
yuyutsuśca tato rājañ śitadhāreṇa patriṇā|
ulūkaṃ tāḍayāmāsa vajreṇa iva mahābalam|| // 8-16-2 //
（2）王よ、ユユツは鋭い刃の羽根つき矢で、大力の者を金剛杵のように打ちました。
ulūkas tu tataḥ kruddhas tava putrasya saṃyuge|
kṣurapreṇa dhanuś chittvā tāḍayāmāsa karṇinā|| // 8-16-3 //
（3）怒ったウルーカは、あなたの息子（ユユツ）に対して戦場で、剃刀の矢で弓を断ち切り、矢尻の矢で打ちました。
tadapāsya dhanuś chinnaṃ yuyutsar vegavattaram|
anyadādatta sumahaccāpaṃ saṃraktalocanaḥ|| // 8-16-4 //
（4）ユユツは切り裂かれた弓を捨て、より速い別の大弓を取り、目を血走らせました。
śākuniṃ tu tataḥ ṣaṣṭyā vivyādha bharatarṣabha|
sārathiṃ tribhir ānarcchat taṃ ca bhūyo vyavidhyata|| // 8-16-5 //
（5）バーラタの雄牛は、シャクニの子（ウルーカ）を六十本の矢で射ち、御者を三本で射ち、さらにウルーカを射ちました。
ulūkas taṃ tu viṃśatyā vidvvā svarṇavibhūṣitaiḥ|
athāsya samare kruddho dhvajaṃ ciccheda kāñcanam|| // 8-16-6 //
（6）ウルーカは金で飾られた二十本の矢で射返し、怒って戦場でユユツの黄金の旗を断ち切りました。
sa cchinnayaṣṭiḥ sumahāñ śīryamāṇo mahādhvajaḥ|
papāta pramukhe rājan yuyutsoḥ kāñcanadhvajaḥ|| // 8-16-7 //
（7）王よ、旗竿を断たれた大きな旗は、砕けながらユユツの前に落ちました。
dhvajamunmathitaṃ dṛṣṭvā yuyutsuḥ krodhamūrcchitaḥ|
ulūkaṃ pañcabhir bāṇair ājaghāna stanāntare|| // 8-16-8 //
（8）旗が倒されたのを見て怒りに燃えたユユツは、五本の矢でウルーカの胸を打ちました。
ulūkas tasya samare tailadhautena māriṣa|
śiraściccheda bhallena yantur bharatasattama|| // 8-16-9 //
（9）ウルーカは油で磨いた矢尻の矢で、ユユツの御者の頭を戦場で切り落としました、バーラタの最上者よ。
tacchinnamapatadbhūmau yuyutsoḥ sārathes tadā|
tārārūpaṃ yathā citraṃ nipapāta mahītale|| // 8-16-10 //
（10）ユユツの御者の切り落とされた首は、星の姿に描かれた美しい絵のように大地に落ちました。
jaghāna caturo'śvāṃśca taṃ ca vivyādha pañcabhiḥ|
so'tividvo balavatā pratyapāyād rathāntaram|| // 8-16-11 //
（11）ウルーカは四頭の馬を殺し、さらにユユツを五本の矢で射ちました。力ある者に深く射られたユユツは、別の戦車に退きました。
taṃ nirjitya raṇe rājan nulūkas tvarito yayau|
pāñcālān sṛñjayāṃś caiva vinighnan niśitaiḥ śaraiḥ|| // 8-16-12 //
（12）王よ、戦場でユユツを打ち負かしたウルーカは急いで向かい、パーンチャーラ族とスリンジャヤ族を鋭い矢で打ち倒していきました。
śatānīkaṃ mahārāja śrutakarmā sutas tava|
vyaśvasūtarathaṃ cakre nimeṣārdhād asambhramaḥ|| // 8-16-13 //
（13）大王よ、あなたの息子シュルタカルマンは、シャタニーカを瞬く間に馬も御者も戦車も失わせました。
hatāśve tu rathe tiṣṭhañ śatānīko mahārathaḥ|
gadāṃ cikṣepa saṅkruddhas tava putrasya māriṣa|| // 8-16-14 //
（14）馬を失った戦車に立つ偉大な戦車戦士シャタニーカは、怒りに燃えて棍棒をあなたの息子に投げつけました。
sā kṛtvā syandanaṃ bhasma hayāṃś caiva sasārathīn|
papāta dharaṇīṃ tūrṇaṃ dārayantī iva bhārata|| // 8-16-15 //
（15）バーラタよ、その棍棒は戦車を灰にし、馬も御者もろとも砕き、大地を割るかのように素早く落ちました。
tāvubhau virathau vīrau kurūṇāṃ kīrtivardhanau|
vyapākrametāṃ yuddhāt tu prekṣamāṇau parasparam|| // 8-16-16 //
（16）二人の勇者は共に戦車を失い、クル族の名誉を増す者として、互いを見つめながら戦闘から退きました。
putras tu tava sambhrānto viviṃśo rathamāruhat|
śatānīko'pi tvaritaḥ prativindhyarathaṃ gataḥ|| // 8-16-17 //
（17）うろたえたあなたの息子（シュルタカルマン）はヴィヴィンシャティの戦車に乗り、シャタニーカも急いでプラティヴィンディヤの戦車に向かいました。
sutasomaṃ tu śakunir vidvvā tu niśitaiḥ śaraiḥ|
nākampayata saṅkruddho vāryogha iva parvatam|| // 8-16-18 //
（18）シャクニは鋭い矢でスタソーマを射ちましたが、怒っても彼を揺るがすことはできませんでした。水の奔流が山を揺るがせないように。
sutasomas tu taṃ dṛṣṭvā pituratyantavairiṇam|
śarair anekasāhasraiś chādayāmāsa bhārata|| // 8-16-19 //
（19）スタソーマは父（ビーマ）の宿敵を見て、バーラタよ、何千もの矢で覆い尽くしました。
tāñ śarāñ śakunis tūrṇaṃ ciccheda anyaiḥ patatribhiḥ|
laghvastraś citrayodhī ca jitakāśī ca saṃyuge|| // 8-16-20 //
（20）シャクニは素早く別の矢でそれらの矢を切り落としました。軽い武器の使い手にして華麗な戦い方をする者として、戦場で勝ち誇った姿を見せながら。
nivārya samare cāpi śarāṃs tān niśitaiḥ śaraiḥ|
ājaghāna susaṅkruddhaḥ sutasomaṃ tribhiḥ śaraiḥ|| // 8-16-21 //
（21）戦場で鋭い矢を防いでから、激怒したシャクニは三本の矢でスタソーマを打ちました。
nākampayata saṅkruddho vāryogha iva parvatam|
tasya aśvān ketanaṃ sūtaṃ tilaśo vyadhamac charaiḥ|
śyālas tava mahārāja tata uccukruśur janāḥ|| // 8-16-22 //
（22）しかしスタソーマは揺るぎませんでした。大王よ、あなたの義兄弟シャクニは矢でスタソーマの馬・旗・御者を粉々にしました。人々は叫び声を上げました。
hatāśvo virathaś caiva chinnaketuś ca māriṣa|
dhanvī dhanurvaraṃ gṛhya rathād bhūmāv atiṣṭhata|| // 8-16-23 //
（23）馬を失い、戦車を失い、旗も切り倒されたスタソーマは、弓兵として最上の弓を持ち、戦車から大地に降り立ちました。
vyasṛjat sāyakāṃś caiva svarṇapuṅkhāñ śilāśitān|
chādayāmāsur atha te tava śyālasya taṃ ratham|
śaḻabhānām iva vrātāḥ śaravrātā mahāratham|| // 8-16-24 //
（24）金の矢尻で石に研がれた矢を放つと、それらの矢の群れはイナゴの群れのように、あなたの義兄弟の戦車を覆いました。
sañchādyamāno'pi dṛḍhaṃ vivyathe naiva saubalaḥ|
pramamātha śarāṃs tasya śaravrātair mahāyaśāḥ|| // 8-16-25 //
（25）激しく覆われても、シャクニの子は少しもひるまず、大いなる名声の者は矢の群れで敵の矢の群れを打ち砕きました。
tatrātuṣyanta yodhāśca siddhāś cāpi divi sthitāḥ|
sutasomasya tatkarma dṛṣṭvāśraddheyam adbhutam|
rathasthaṃ śakuniṃ yat tu padātiḥ samayodhayat|| // 8-16-26 //
（26）戦士たちも天の成就者たちも、スタソーマの信じ難く驚くべき業を見て満足しました。戦車に乗ったシャクニに対して歩兵として戦ったのですから。
tasya tīkṣṇair mahāvegair bhallaiḥ sannataparvabhiḥ|
vyahanat kārmukaṃ rājaṃs tūṇīrāṃś caiva sarvaśaḥ|| // 8-16-27 //
（27）王よ、スタソーマは鋭く大いなる速さのしなやかな矢尻の矢で、シャクニの弓と矢筒をすべて打ち落としました。
sa cchinnadhanvā virathaḥ khaṅgamudyamya cānadat|
vaidūryotpalavarṇābhaṃ dantidantamayat sarum|| // 8-16-28 //
（28）弓を断たれ戦車を失ったシャクニは、エメラルドと青蓮のような色の、象牙の柄のついた剣を振り上げて咆哮しました。
bhrāmyamāṇaṃ tatas taṃ tu vimalāmbaravarcasam|
kāladaṇḍopamaṃ mene sutasomasya dhīmataḥ|| // 8-16-29 //
（29）清らかな空の輝きを持つその剣が回転するのを、賢きスタソーマは閻魔の杖のようなものと見なしました。
so'carat sahasā khaṅgī maṇḍalāni sahasraśaḥ|
caturdaśa mahārāja śikṣābalasamanvitaḥ|| // 8-16-30 //
（30）大王よ、剣を持つシャクニは突然、何千もの円形の動きを行いました——十四の型を、修練と力をもって。
bhrāntamuddhāntamāviddhamāplutaṃ viplutaṃ sṛtam|
sampātasamudīrṇe ca darśayāmāsa saṃyuge|| // 8-16-31 //
（31）回転・飛び上がり・旋回・跳躍・横跳び・疾走、そして突撃による攻撃を、戦場で見せました。
saubalas tu tatas tasya śarāṃś cikṣepa vīryavān|
tān āpatata eva āśu ciccheda paramāsinā|| // 8-16-32 //
（32）力ある者シャクニの子は矢を放ちましたが、スタソーマはそれらを飛んでくるうちに最上の剣で切り落としました。
tataḥ kruddho mahārāja saubalaḥ paravīrahā|
prāhiṇot sutasomāya śarān āśīviṣopamān|| // 8-16-33 //
（33）大王よ、怒った敵を倒すシャクニの子は、毒蛇のような矢をスタソーマに放ちました。
ciccheda tāṃs tu khaṅgena śikṣayā ca balena ca|
darśaya~llāghavaṃ yuddhe tārkṣyatulyaparākramaḥ|| // 8-16-34 //
（34）スタソーマは技と力でそれらを剣で切り落とし、ガルーダに等しい武勇を持って戦闘の軽妙さを見せました。
tasya sañcarato rājan maṇḍalāvartane tadā|
kṣurapreṇa sutīkṣṇena khaṅgaṃ ciccheda suprabham|| // 8-16-35 //
（35）王よ、円形旋回の中を動き回るスタソーマの、輝く剣を、鋭い剃刀の矢で断ち切りました。
sa cchinnaḥ sahasā bhūmau nipapāta mahānasiḥ|
adharmasya sthitaṃ haste sutsaros tatra bhārata|| // 8-16-36 //
（36）大いなる剣は突然、柄のまま大地に落ちました。バーラタよ、まるで不法の手に握られていた武器のように。
chinnamājñāya nistriṃśamavaplutya padāni ṣaṭ|
prāvidhyata tataḥ śeṣaṃ sutasomo mahārathaḥ|| // 8-16-37 //
（37）剣が断たれたと知って、六歩退いてから、偉大な戦車戦士スタソーマは残った柄を投げつけました。
tacchittvā saguṇaṃ cāpaṃ raṇe tasya mahātmanaḥ|
papāta dharaṇīṃ tūrṇaṃ svarṇavajravibhūṣitam|| // 8-16-38 //
（38）それは偉大な魂（シャクニ）の弦のついた弓を切り裂き、金と金剛石で飾られた弓は素早く大地に落ちました。
sutasomas tato'gacchac chrutakīrter mahāratham|
saubalo'pi dhanurgṛhya ghoram anyat sudurjayam|| // 8-16-39 //
（39）スタソーマはシュルタキールティの偉大な戦車に向かい、シャクニの子もまた別の恐るべく攻め難い弓を取り——
abhyayāt pāṇḍavānīkaṃ nighnañ śatrugaṇān bahūn|
tatra nādo mahān āsīt pāṇḍavānāṃ viśāmpate|| // 8-16-40 //
（40）パーンダヴァの軍に突入し、多くの敵の群れを殺しました。王よ、パーンダヴァたちの間に大きな叫び声が上がりました。
saubalaṃ samare dṛṣṭvā vicarantamabhītavat|
tānyanīkāni dṛptāni śastravanti mahānti ca|
drāvyamāṇāny adṛśyanta saubalena mahātmanā|| // 8-16-41 //
（41）シャクニの子が恐れることなく戦場を駆け回り、武器を持った大きく誇り高い軍隊を敗走させているのが見えました。
yathā daityacamūṃ rājan devarājo mamarda ha|
tathaiva pāṇḍavīṃ senāṃ saubaleyo vyanāśayat|| || // 8-16-42 //
（42）王よ、インドラが悪魔の軍を踏み潰したように、シャクニの子はパーンダヴァの軍を滅ぼしました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe ṣoḍaśo'dhyāyaḥ|| 16 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十六章は終わる。
