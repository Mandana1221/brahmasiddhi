第二章　審議の章（Mantra-vicāra）
全118偈・アヌシュトゥブ（シュローカ）韻律。クリシュナがウッダヴァ・バララーマと共にシシュパーラ征伐と祭祀出席の二大課題を審議する。
II.1
Sanskrit (IAST) yiyakṣamāṇenāhūtaḥ pārthenātha dviṣan muram / abhi caidyaṃ pratiṣṭhāsur āsīt kāryadvayākulaḥ //
和訳

祭祀を欲するパールタ（ユディシュティラ）に招かれ、しかしムラの敵（クリシュナ）はチェーディヤ（シシュパーラ）に向かって出征せんとし——二つの務めに板挟みとなっていた。

注

【Vallabhadeva】

本章はmantra-vicāra（政策審議）を主題とする。yiyakṣamāṇena＝yaṣṭum icchatā（祭祀を欲する者によって）、yajのサンナンタ+śānac。pārtha＝プリターの子ユディシュティラ（aṇ接尾辞）。pratiṣṭhāsuḥ＝出発を欲する（prasthātum icchuḥ）。ユディシュティラの祭祀に赴くべきか、チェーディヤを討つべきか——二つの課題に苦悩（kāryadvayākula）。

【Mallinātha】

本章冒頭で審議のbīja（種子）を蒔く。muram dviṣan＝ムラーリ（dviṣo 'mitreのśatṛ接尾辞）。abhi caidyam＝lakṣaṇenābhipratī ābhimukhye（不変化複合語）またはkarmapravacānīyaの二格。パールタのもとに行けばチェーディヤが放置され、チェーディヤを攻めればパールタが怒る——ゆえにākula（困惑）。本章はアヌシュトゥブ韻律。

II.2
Sanskrit (IAST) sārdham uddhavasīribhyām athāsāv āsadat sadaḥ / gurukāvyānugāṃ bibhrac cāndrīm abhinabhaḥ śriyam //
和訳

さてこの者（クリシュナ）は、ウッダヴァとバララーマ（ハラの持ち主＝Sīrin）と共に、グル（木星）とカーヴィヤ（金星）が随う月のごとき輝きを帯びて、人気のない集会の間へと向かった。

注

【Vallabhadeva】

ハリ（クリシュナ）はウッダヴァ・バララーマ（sīrin＝鋤を持つ者）と共にsadaḥ＝mantramandapa（審議の堂）に赴いた。abhinabhaḥ＝天に向かって（不変化複合語、七格の意）。審議は人目を避けて行うべし——マヌ引用：giripṛṣṭhaṃ samāruhya prāsādaṃ vā raho gataḥ / araṇye niḥśalāke vā mantrayedbhāvabhāvitau。guru＝木星（ブリハスパティ）、kāvya＝金星（ウシャナス）が随う月のような輝き——クリシュナを月に喩えるnidarśanā（例証法）。

【Mallinātha】

gurukāvyānugām＝グル（木星）とカーヴィヤ（金星）が随伴する。cāndrīṃ śriyam＝月の輝き。クリシュナは月、ウッダヴァはグル（木星）、バララーマはカーヴィヤ（金星）に対応するnidarśanā。āsadatはルング（puṣādiのc̥lにaṅ代置）。sadaḥは宮殿の広さゆえnabhaḥ（空）に擬す。

II.3
Sanskrit (IAST) jājvalyamānā jagataḥ śāntaye samupeyuṣī / vyadyotiṣṭa sabhāvedyām asau naraśikhitrayī //
和訳

烈しく燃え立ち（jājvalyamānā）、世界の安寧のために集い来たこの人間の火の三組（naraśikhitrayī）は、集会堂の祭壇（sabhāvedī）の上で光り輝いた。

注

【Vallabhadeva】

三人の英傑（ハリ・ウッダヴァ・バララーマ）は威光ゆえに火にほかならず（narāḥ puruṣā eva śikhinaḥ agnayaḥ）、その三組は祭壇の三火——ダクシナーグニ・アーハヴァニーヤ・ガールハパティヤに喩えられる。jājvalyamānāはヤング（強意反復法、dhātor ekāco halādeḥ kriyāsamabhihāre yaṅ）。sabhāvedīはāsthānī（集会堂）＝vedī（祭壇、アマラコーシャ：vediḥ pariṣkṛtā bhūmiḥ）。rūpaka（隠喩）。

【Mallinātha】

śāntaye＝anupadravāya（世界の安穏のために）。samupeyuṣī＝集合した。naraśikhitrayī＝dvitribhyām...のtayas代置でṅīP。祭壇の三火が祭式のために燃え集うように、三人の英傑が世界の安寧のために集会堂に会する——rūpaka（隠喩法）。vyadyotiṣṭaはルング（dyutのsicにiṭ加入）。

II.4
Sanskrit (IAST) ratnastambheṣu saṃkrāntapratimās te cakāśire / ekākino 'pi paritaḥ pauruṣeyavṛtā iva //
和訳

宝石の柱に映った姿（pratimā）を持つ彼らは、独りきりであっても、あたかも四方を従者の群れに囲まれているかのように輝いた。

注

【Vallabhadeva】

宝石柱に反射した像（saṃkrāntapratimāḥ＝saṃkrāntapratibimbāḥ、アマラコーシャ：pratimānaṃ pratibimbaṃ pratimā）が周囲に映るため、ただ一人でも（ekākino 'pi）大勢の随員（pauruṣeya＝puruṣasamūha、人間集団のḍhañ接尾辞）に囲まれているかのよう——utprekṣā（想像法）。審議の場は密閉・少人数であるべし。

【Mallinātha】

ratnastambhaの六格複合語（ṣaṣṭhīsamāsaviśeṣe paryavasānād vikārārthatvam＝宝石製の柱）。ekākinaはakini接尾辞（ekād akinic chāsahāye）。paritaḥはtasil接尾辞。pauruṣeyaはḍhañ接尾辞で集合名詞。反射像の多さ＝随員の多さというutprekṣā。密閉空間での審議が望ましいというvijana（無人）の意を暗示。

II.5
Sanskrit (IAST) adhyāsām āsur uttuṅga-hemapīṭhāni yāny amī / tair ūhe kesarikrānta-trikūṭaśikharopamā //
和訳

この三者が高く聳える黄金の座に就いた時、それらの座は獅子の登った三峰山（Trikūṭa）の頂きに喩えられた。

注

【Vallabhadeva】

amī trayaḥ（三者）がuttuṅga-hemapīṭhāni（高い黄金の座）にadhyāsām āsuḥ（着座した、āsのリト、dadhā yāsac、アートマネーパダのkṛñ補助動詞）。それらの座はkesaribhiḥ siṃhaiḥ krāntānāṃ（獅子が登った）トリクータ山等の峰に喩えられた（ūhe＝vahのkarmaṇi liṭ）。upamā（直喩）。Vallabhadeva異読：citrakūṭa。

【Mallinātha】

adhyāsām āsuḥはadhiśīṅsthāsāṃ karmaの対格支配。uttuṅga＝高い。kesarin＝獅子。trikūṭa＝三つの峰を持つ山（anvarthasaṃjñā）。upamā（直喩法）。三つの黄金座に三者が坐する威容は、獅子が頂に据わるトリクータ山の威容に比す。

II.6
Sanskrit (IAST) gurudvayāya guruṇor ubhayor atha kāryayoḥ / hari-vipratiṣedhaṃ tam ācacakṣe vicakṣaṇaḥ //
和訳

さて明敏なるハリ（クリシュナ）は、二人のグル（叔父ウッダヴァと兄バララーマ）に対し、二つの重大な務めの間の矛盾（vipratiṣedha）を説明した。

注

【Vallabhadeva】

Vallabhadeva異読：gurūbhayasmai（グルたる両者へ）。hari＝クリシュナ。guruṇoḥ＝重大な。ubhayoḥ kāryayoḥ＝二つの課題（ユディシュティラの祭祀への出席とシシュパーラ討伐）。vipratiṣedha＝tulyabalavirodha（等力の矛盾）。二つを同時に遂行できないために対立が生じる。vicakṣaṇa＝vicaṣṭe iti（洞察する者）、ācārya（礼節を知る者）。

【Mallinātha】

gurudvayāya＝二人のグルへ（dvābhyām）。guruṇoḥ＝mahatoḥ（重大な）。着席後、クリシュナはācacakṣe（告げた、cakṣのリト、khyāj代置はvāliṭiで任意）自ら二つの課題の矛盾を。パーニニ学者的含意：文法のvipratiṣedha（「二つのguru課題のうちubhayaの格変化はどちらか」）を審議する賢者の隠喩。

II.7
Sanskrit (IAST) dyotitāntaḥsabhaiḥ kunda-kuḍmalāgradataḥ smitaiḥ / snāpitevābhavat tasya śuddhavarṇā sarasvatī //
和訳

クンダの花蕾の先のような歯並びから発する微笑みで集会堂の内部を照らし、あたかも洗い清められたかのように、彼（ハリ）の弁舌（Sarasvatī）は音声の清澄さを備えていた。

注

【Vallabhadeva】

kunda＝マーガ月に咲く白花（アマラコーシャ：mādhyaṃ kundam）。kuḍmalāgradataḥ＝クンダの蕾の先端のような歯を持つ者の（bhāntaśuddhaśubhravṛṣavarāhebhyaś caのdat代置）。smitaiḥ＝微笑みによってantaḥsabhā（集会堂内部）がdyotita（照らされた）。snāpiteva＝洗浄されたかのよう（snāのṇyanta + kta）。自然な発声の清澄さ（śuddhavarṇā）の原因として洗浄を想像するutprekṣā。微笑みを先に見せてから話す——偉大な人物の作法。

【Mallinātha】

śuddhavarṇā＝明瞭な音声（sphuṭākṣaratva＋svaccchakānti）。白い歯の微笑みで堂内が照らされ、その白さが弁舌にまで及んだかのようだというutprekṣā。snāpitaは洗浄の意でpugāgama（bhartihrī...のpuK挿入）。微笑みを先にしてから語る——smitapūrvābhibhāṣin（偉大な人物の所作）。

II.8
Sanskrit (IAST) bhavadgirām avasarapradānāya vacāṃsi naḥ / pūrvaraṅgaḥ prasaṅgāya nāṭakīyasya vastunaḥ //
和訳

「我々の言葉は、お二方のお言葉に機会を与えるためのもの——演劇（nāṭaka）の本題に入る前の序幕（pūrvaraṅga）にすぎません。」

注

【Vallabhadeva】

クリシュナの言葉は先輩（グル）への配慮から謙譲を示す。bhavadgirām avasarapradānāya＝お二方の言葉に場を与えるために。naḥ vacāṃsi＝我々の言葉は結論（siddhānta）としてではなく。pūrvaraṅga＝演劇の開幕前に行う祭式的儀礼（raṅgavighnaśāntikārin nāndīpāṭhagītavāditrādy anekaṅgaviśeṣa）。本題（vastu）の導入に過ぎないと謙遜する。クリシュナの言葉と序幕の共通点として「導入」の機能を述べるprativastūpamā（対応的直喩）。

【Mallinātha】

nāṭakīya＝nāṭake bhava（vṛddhaccha接尾辞にīyadeśa）。pūrvaraṅga＝演劇の開始前に行う神への讃歌・舞踊・音楽からなる前戯（ダシャルーパカ引用）。先輩に対するpaṇḍitamānitva（自ら学者ぶることの回避）を示す。自らの発言はあくまで導入であり、結論はお二方に委ねるという態度。

II.9
Sanskrit (IAST) karadīkṛtabhūpālo bhrātṛbhir jitvarair diśām / vināpy asmad alaṃ bhūṣṇur ijyāyai tapasaḥ sutaḥ //
和訳

「タパス（苦行＝ダルマ）の子（ユディシュティラ）は、四方を征服に長けた弟たちの力で諸王を朝貢者とし、我々（クリシュナ一族）なしでも祭祀に十分な力を備えている。」

注

【Vallabhadeva】

クリシュナが自説を述べ始める——チェーディヤ征伐を優先すべきだと。tapasaḥ sutaḥ＝ダルマの子ユディシュティラ（tapas＝dharma、ヴィシュヴァコーシャ引用）。bhrātṛbhiḥ＝ビーマ等の兄弟によって。diśāṃ jitvaraiḥ＝四方征服に長けた者たち（iṇ-naś-ji-sarti-bhyaḥ kvrap）。karadīkṛta＝朝貢者にした（karada＝六分の一税を納める者、ūryādi-cvi-ḍācaの恒常複合語）。asmad vināpi＝我々なしでも。bhūṣṇuḥ＝capable（glā-ji-sthā-ś ca ṣṇuḥ接尾辞）。ゆえに征伐遠征こそ先決、祭祀ではない。

【Mallinātha】

ijyāyai＝祭祀のために（yajのbhāveにkyap、vacisvapisamprasāraṇa、namaḥsvasti...の四格）。alaṃ bhūṣṇuḥ＝十分に能力がある（bhūṣṇur bhavaviṣṇur bhavita、アマラコーシャ）。tapasaḥ sutaḥ＝法（ダルマ）の子。ユディシュティラは我々の助力なしでも祭祀を遂行できるのだから、我々はチェーディヤ討伐に向かうべきだ、というクリシュナの主張。

II.10
Sanskrit (IAST) uttiṣṭhamānas tu paro nopekṣyaḥ pathyam icchatā / samau hi śiṣṭair āmnātau vatsyantāv āmayaḥ sa ca //
和訳

「しかし勢力を増しつつある敵は、健全（pathya＝利益）を望む者にとって看過されてはならない。識者たちが等しく説いたのだ——病（āmaya）と彼（敵）とは、放っておけばいずれも増大する、と。」

注

【Vallabhadeva】

uttiṣṭhamāna＝vardhamāna（増大しつつある、ud-o 'nūrdhvakarmaṇiのアートマネーパダ）。pathyam＝hitam ārogyam（利益・健康）。vatsyantau＝vardhiṣyamāṇau（増大するであろう二つ、vṛdhの未来形、vṛddhnaḥ svasanoḥで任意にパラスマイパダ）。āmayaḥ＝vyādhi（病、アマラコーシャ：rogavyādhigadāmayāḥ）。病と敵は同じ性質を持つ——放置すれば増大する（apīyaso 'py arer vṛddhir mahānarthāya rogavat）。upamā（直喩法）。

【Mallinātha】

pathyam icchatā＝健全（利益）を望む者にとって。samau＝等しいと。śiṣṭaiḥ＝nītijñaiḥ（政策通）、イーシュヴァラ・ブリハスパティ等のpaṇḍita。āmnātau＝ākhyātau（説かれた）。āmayaḥ sa ca＝病と彼（敵）は。いずれも些少であっても放置すれば大害をなす——格言：alpīyaso 'py arer vṛddhir mahānarthāya rogavat。upamā。

II.11
Sanskrit (IAST) na dūye sātvatīsūnur yan mahyam aparādhyati / yat tu dandahyate lokam ado duḥkhākaroti mām //
和訳

「サートヴァティー（クリシュナの父方の叔母）の子（シシュパーラ）が私に対して罪を犯すこと自体は、私を苦しませはしない。しかし彼が世間を焼き尽くしている、そのことが私に苦痛を与えるのだ。」

注

【Vallabhadeva】

クリシュナは自らの私怨（svakāryavaira）のためではなく世のためにシシュパーラ討伐を志す。sātvatī＝sātvato 'patyaṃ strī（サートヴァタ族の娘、ハリの父方の叔母）。dandahyate＝garhitaṃ dahati（非道に焼く）、dahのヤング強意形（lupasadcarajap...のyaṅ、japjabhadahadaśabhāpaśāṃ caのnumāgama）。duḥkhākarotiはduḥkhāt prātilomyeのḍāC接尾辞。チェーディヤこそ先に攻むべし、パールタは請願によって後から宥められる。

【Mallinātha】

sātvatīsūnuḥ＝シシュパーラ。身内（bandhu）であっても悪人は容認されないという含意。yan mahyam aparādhyati＝私に罪を犯すこと（kuṣadruh...の四格）。dūye＝pari-tapye（嘆かない、dūṅのダイヴァーディカから能動態）。dandahyateは非難の意のヤング。ado lokadahanaṃ māṃ duḥkhākaroti＝その民への焼き討ちが私を苦しめる。

II.12
Sanskrit (IAST) mama tāvan matam idaṃ śrūyatām aṅga vām api / jñātasāro 'pi khalv ekaḥ saṃdigdhe kāryavastuni //
和訳

「さて、これが私の見解です。お二方の考えもお聞かせください——事の本質を知る者であっても、疑わしい課題においては独りでは迷うものですから。」

注

【Vallabhadeva】

クリシュナは自説を述べ終え、他者の意見を求める謙遜を示す。tāvat＝「お二方の意見を聞くまでは」。aṅga＝親愛なる呼びかけ（アマラコーシャ：atha saṃbodhanārthaika）。vām＝yuvayoḥ（お二方の、yuṣmadasmadoḥ ṣaṣṭhīcaturthīのvāmādeśa）。jñātasāra＝本質を見抜いた者でも。ekaḥ＝独りでは。一般命題（sāmānyena viśeṣasamarthana）で個別の行為を正当化するarthāntaranyāsa。

【Mallinātha】

Vallabhadeva異読：matam adaḥ。jñātasāraḥ＝jñātasvārthaḥ（自ら意義を把握した者でも）。kāryavastuni＝kartavyārthe（遂行すべき事柄において）。saṃdigdheはdih upacaye、スヴァリタ性からkartrにlaṭ。引用：suvimṛṣṭe svayaṃ samyak suhṛdbhiḥ suparīkṣite / naivārambhe vipanne 'pi vācyatāṃ yānti sādhavaḥ。

II.13
Sanskrit (IAST) yāvadarthapadāṃ vācam evam ādāya mādhavaḥ / virarāma mahīyāṃsaḥ prakṛtyā mitabhāṣiṇaḥ //
和訳

このように必要最小限の言葉（yāvadarthapadā）のみを用いた弁をなし終え、マーダヴァ（クリシュナ）は口を閉じた。偉大なる者は生来、言葉少なであるから。

注

【Vallabhadeva】

yāvad-artha-padām＝abhidheyasaṃmitākṣarām（表すべき意味にぴったり合った音節数の）——必要以上に語らない。ādāya＝gṛhītvā（＝uktvā、語ったのち）。virarāma＝tūṣṇīm āsa（沈黙した、vyāṅparibhyo ramaḥパラスマイパダ）。mahīyāṃsaḥ＝uttamāḥ（最上の者たちは）。mitabhāṣiṇaḥ＝寡言。冗語を戒めるpūrvapada-alaṅkāra（前段修辞）。

【Mallinātha】

mādhavaḥ＝ヴィシュヌ（マドゥの後裔）。yāvadarthapadāmはyāvad avādhāraṇeの不変化複合語。意義に見合った分だけの語、chandasapūraṇārtham apravṛttaṃ yasyāṃ na kiñcid uktam（韻律を埋めるための空疎な語が一つもない）。大人物は本来的にmitabhāṣin（寡言）である——arthāntaranyāsa。

II.14
Sanskrit (IAST) tataḥ sapatnāpanayasmaraṇānuśayasphurā / oṣṭhena rāmo rāmauṣṭhabimbacumbanacuñcunā //
和訳

【kulaka 14–21：バララーマの姿態描写。主動詞 jagāda（語った）はII.21にて】それからラーマ（バララーマ）は——敵の非行を想起した悔恨に唇を震わせ、その唇はラーマー（妻レーヴァティー）の唇という果実（bimba）への接吻に巧みで——

注

【Vallabhadeva】

II.24

和訳

注

【Vallabhadeva】

II.25

II.26

II.27

和訳

注

【Vallabhadeva】

多弁に何の意味もなく、kāryatattva（事の本質）こそが肝要であることを示す。anirloḍita＝未吟味の（anirṇīta）。vāgminは弁舌に長けた者。nimitta＝lakṣya（的）。dhānuka（弓を持つ者、dhanuḥ praharaṇam asyaのṬhak接尾辞）が的を外した後に威張っても無益。

書物的知識だけでは不十分であることの帰結。vāgmin＝vāvadūka（多弁家、vāco gminのgmini接尾辞）。nimittaはvedhya（貫くべきもの）＝lakṣya（「vedhyaṃ lakṣyaṃ nimittaṃ ca」とVaijayantī）。dhanuṣka＝弓を武器とする者（praharaṇam iti ṭhak, isusukrāntāt kaḥ）。事の核心を知る者の言葉のみが採るべきである（kāryajñasya vaco grāhyam）。

II.28

注

【Vallabhadeva】

aṅgapañcaka（審議の五肢）＝①行動の開始方法（karmāṇām ārambhopāya）、②人員・財の充足（puruṣadravyasaṃpat）、③時所の配分（deśakālavibhāga）、④不測への対処（vipattipratīkāra）、⑤事業の完遂（kāryasiddhi）。カーマンダキのNītisāra引用。skandhapañcaka（五蘊）＝色・受・識・想・行（rūpa-vedanā-vijñāna-saṃjñā-saṃskāra）。仏教徒は五蘊以外にアートマンを認めない。upamā（直喩）。

【Mallinātha】

多弁の否定から一転してmantraの本質を述べる。sarvakāryaśarīreṣu＝一切の事業を身体に喩えるupamitasamāsa（比喩的複合語）。aṅgāni skandhāḥもまたupamitasamāsa。仏教の五蘊＝rūpa（色：対象の展開）・vedanā（受：知覚の展開）・vijñāna（識：ālayavijñāna相続）・saṃjñā（想：名称の展開）・saṃskāra（行：習気の展開）。五蘊以外にアートマンなきように、五肢以外にマントラなし——upamālaṅkāra。これにより即時行動すべし（yātrākāla）。

II.29
Sanskrit (IAST) mantro yodha ivādhīraḥ sarvāṅgaiḥ saṃvṛtair api / ciraṃ na sahate sthātuṃ parebhyo bhedaśaṅkayā //
和訳

審議（mantra）は、臆病な（adhīra）戦士（yodha）のごとく、あらゆる肢体（sarvāṅga）を鎧で覆っていても（saṃvṛtair api）、敵（para）に漏洩する（bheda）おそれから、長くは耐えられない（na sahate sthātum）。

注

【Vallabhadeva】

mantraの遅延はmantraśakti（智謀力）の損失に繋がることを示す。sarvāṅgaiḥ＝前述のkarmārambhaṇopāya等の五肢でkalpitaiḥ（整えられた）としても、adhīra＝bahukālāvasthānāsahaḥ（長時間の持続に堪えない）。bheda＝漏洩（udbhṛti）。臆病な兵士が甲冑を着ても反撃を恐れて長く留まれないのと同じ——迅速に行動すべし。

【Mallinātha】

審議の遅延の害を説く。saṃvṛtaiḥ＝guptaiḥ（秘匿された）。adhīra＝bhīru（臆病）。yodhaはyudhからpacādyac。bhedaは漏洩（vidāraṇa）と第三者への流出（tṛtīyagāmitva）。sahate sthātumはśakadhr̥ṣeのtumun。ゆえに遅滞すべきではなく、さもなくばmantrabhedaḥ（審議の漏洩）でkāryahāni（事業の失敗）を招く。GRETILにはsahateが脱落しており補った。

II.30
Sanskrit (IAST) ātmodayaḥ parajyānir dvayaṃ nītir itīyatī / tad ūrīkṛtya kṛtibhir vācaspatyaṃ pratāyate //
和訳

自らの興隆（ātmodaya）と敵の衰退（parajyāni）——この二つ（dvayam）こそが政道（nīti）の全体（iyatī）である。それを根幹として受け容れ（ūrīkṛtya）、知者たち（kṛtibhiḥ）の弁舌の巧み（vācaspatyam）は展開される（pratāyate）。

注

【Vallabhadeva】

ātmodaya＝自身の発展、parajyāni＝敵の衰亡。jyāniはbījyāhājvaribhyo niḥのauṇādika ni接尾辞。iyatī（これだけの量の）はkim-idaṃbhyāṃ vo ghaḥのvatupにugitaś caのṅīP。その他のṣaḍguṇa等はすべてこの二原理の展開にすぎない。vācaspatyam＝弁才（vāgīśvaratvam）。pratāyateはtanのカルマニ・ラティ（tanoter yaki āttvam）。ゆえに時間の空費は無意味。

【Mallinātha】

nītiの全体を精査しても遅延の理由はないことを示す。jyāniはhāni（衰亡）。ūrīkṛtyaはūrī（ūrīkṛtasurīkṛtam aṅgīkṛtamとアマラコーシャ）のcvipからkugatiprādayaḥで複合しktvāのlyap代置。vācaspatyam＝弁舌の主宰（vāgmitvam）。この二原理を種子（bīja）として一切の政論が展開されるのであり、我々にもその種子は明らか——ゆえに時間を費やす理由は何もない。

II.31
Sanskrit (IAST) tṛptiyogaḥ pareṇāpi mahimnā na mahātmanām / pūrṇaś candrodayākāṅkṣī dṛṣṭānto 'tra mahārṇavaḥ //
和訳

偉大なる者たち（mahātman）には、たとえ極大の栄光（mahimnā）をもってしても満足（tṛptiyoga）はない。満ちてなお月の出を渇望する（candrodayākāṅkṣin）大海（mahārṇava）が、ここでの例証（dṛṣṭānta）である。

注

【Vallabhadeva】

Vallabhadevaはstutiyogaḥと読む（異読）。自らの繁栄があっても敵の殲滅なしには足りぬのかという疑問に答える。満潮の大洋もなお月の出（潮の増大）を望む——王は成長への意欲を失うべきではない。dṛṣṭānta（例証）の語がみずから比喩であることを示すためupamālaṅkāra。

【Mallinātha】

tṛptiyogaḥ＝santoṣābhaḥ（満足の不在）。満ちた海が月の出を望むように、偉大な者は繁栄のさなかにもさらなる発展を欲す。dṛṣṭāntaの語を用いて比喩を示すのはupamālaṅkāraであり、dṛṣṭāntālaṅkāraではないと注記。ekāvalī（連鎖修辞）の兆候も。GRETILのdṛṣṭānatoはdṛṣṭāntoに訂正。

II.32
Sanskrit (IAST) saṃpadā susthiraṃmanyo bhavati svalpayāpi yaḥ / kṛtakṛtyo vidhir manye na vardhayati tasya tām //
和訳

わずかな繁栄（svalpā saṃpad）によってすら安泰と思い込む者（susthiraṃmanya）——その者の繁栄を、運命（vidhi）も、思うに（manye）、増やすことはない。既に満足した者の務めは果たされたからだ（kṛtakṛtya）。

注

【Vallabhadeva】

Vallabhadevaの読みはsusthitaṃmanyaḥ（異読）。susthiraṃmanyaḥはātmamāne khaś caのkhan接尾辞にsumāgama。自分を安泰と思い込む者は努力を怠り、天（vidhi）すら彼の富を増やさない——人間の努力（pauruṣa）なくして運命も働かない。

【Mallinātha】

満足の害を示す。vidhiḥ＝daivam（運命）。kṛtakṛtyaḥ＝kṛtārthaḥ（目的達成済み）。努力なき者からは運命も離れる（pauruṣahīnād daivam api jugupsita）。GRETILのvardhayanti（複数）はvardhayati（単数、主語vidhiḥ）に訂正。

II.33
Sanskrit (IAST) samūlaghātam aghnantaḥ parān nodyanti māninaḥ / pradhvaṃsitāndhatamasas tatrodāharaṇaṃ raviḥ //
和訳

敵を根こそぎ（samūlaghātam）滅ぼさずしては、誇り高き者（mānin）は興隆しない（na udyanti）。深い闇（andhatamasas）を破壊した太陽（ravi）がその例証（udāharaṇa）である。

注

【Vallabhadeva】

敵の衰亡こそが自らの興隆の原因であることを示す。samūlaghātamはsamūlākṛtajīveṣu hanūdvagrahaḥのṆamul接尾辞。太陽は闇を破壊してからでなければ昇らない——キラータールジュニーヤ引用：avibhidya niśākṛtaṃ tamaḥ prabhayā nāṃśumatāpy udīyate。

【Mallinātha】

māninaḥ＝abhimāninaḥ（矜持ある者）。aghnantaḥはhanのśatṛ形。andhatamasam＝gāḍhaṃ tamaḥ（濃密な闇、アマラコーシャ：dhvānte gāḍhe 'ndhatamasam）。ここもII.31と同じくupamālaṅkāraでありdṛṣṭāntaではないと注記。GRETILのśamūlaはsamūlaに訂正。

II.34
Sanskrit (IAST) vipakṣam akhilīkṛtya pratiṣṭhā khalu durlabhā / anītvā paṅkatāṃ dhūlim udakaṃ nāvatiṣṭhate //
和訳

敵（vipakṣa）を殲滅せずしては（akhilīkṛtya）、安定した地位（pratiṣṭhā）は実に得がたい。塵を泥（paṅka）にせずに（anītvā paṅkatām）、水は留まることがないように。

注

【Vallabhadeva】

興隆以前に、敵を殲滅しなければ安定すら覚束ないことを示す。khaluは前言を受けた限定辞。水は塵を泥にしてはじめて留まるように、敵を滅ぼしてはじめて足場を得る。avatiṣṭhateはアートマネーパダ（samavapravibhyaḥ sthaḥ）。

【Mallinātha】

akhilīkṛtya＝khilam utsaṅgam akṛtvā（荒地＝廃墟にせずして＝殲滅せずして）。pratiṣṭhāは足場。水は塵を泥に変えてはじめて定着する——文の分離によるpratibimbaを要するためdṛṣṭāntālaṅkāra（例証修辞）。

II.35
Sanskrit (IAST) dhriyate yāvad eko 'pi ripus tāvat kutaḥ sukham / puraḥ kliśnāti somaṃ hi saiṃhikeyo 'suradruhām //
和訳

たった一人の敵（ripu）が生き延びている限り（dhriyate yāvat）、どこに安寧（sukha）があろうか。ラーフ（saiṃhikeya＝シンヒカーの子）は、神々（asuradruhām）の眼前で（puraḥ）月（soma）を苦しめるのだから。

注

【Vallabhadeva】

Vallabhadevaはśivam（吉祥）と読む。シシュパーラ一人は脅威ではないとの反論に対し——たった一人でも敵は害を成す。ラーフが日月を飲むのと同じ（somagrahaṇam upalakṣaṇam——月食は日食をも含む表現）。ゆえに討つべし（tasmād yāvaṃ yāma）。

【Mallinātha】

dhriyateはdhṛñ avasthāne（存続する）のtaudādika・kartari・laṭ、riḍādeśaつき。特殊から一般を支持するarthāntaranyāsa（趣旨転換修辞）。格言引用：agneḥ śeṣam ṛṇāc cheṣaṃ śatroḥ śeṣaṃ na śeṣayet（火・借金・敵の残りは残すな）。GRETILのklaśnātiはkliśnātiに訂正。

II.36
Sanskrit (IAST) sakhā garīyān śatruś ca kṛtrimas tau hi kāryataḥ / syātām amitrau mitre ca sahajaprākṛtāv api //
和訳

友人（sakhā）も敵（śatru）も、行為に基づく（kāryataḥ）人為的な（kṛtrima）者こそが重要（garīyān）である。なぜなら、生来の（sahaja）ものも自然な（prākṛta）ものすら、〔行為次第で〕敵にも友にもなりうるから。

注

【Vallabhadeva】

味方敵論（mitrāmitrabala）の三分類——sahaja（生来の：母方従兄弟＝味方、叔父方＝敵）、prākṛta（自然の：隣国＝敵、その隣＝味方）、kṛtrima（人為の：恩義・害悪による）。人為的な味方敵は行為（upakāra/apakāra）に基づくため終生不変——ゆえに最も重い。格言引用：nāsti jātyā ripur nāma mitraṃ jātyā na vidyate / sāmarthyayogāj jāyante mitrāṇi ripvas tathā。

【Mallinātha】

シシュパーラは卑小だから問題ないとの反論への回答——彼のbalavattā（強大さ）を示すため味方敵の区分を論ずる。kṛtrima＝行為（upakārāpakāra）によって成立する。生来・自然の者は状況で入れ替わるが、kṛtrimaは行為に由来するゆえ揺るがない——kṛtrimatvaṃ sarvāpavādāt（人為性がすべてに優先する）。

II.37
Sanskrit (IAST) upakartāriṇā saṃdhir na mitreṇāpakāriṇā / upakārāpakārau hi lakṣyaṃ lakṣaṇam etayoḥ //
和訳

恩恵を施す敵（upakartṛ ariṇā）とこそ和睦（saṃdhi）すべきであり、害をなす友人（mitreṇa apakāriṇā）とではない。なぜなら恩恵と害悪（upakāra-apakāra）こそが、この両者（友敵）の真の定義（lakṣaṇa）であり、見極めるべきもの（lakṣya）であるから。

注

【Vallabhadeva】

敵であっても恩恵を施す者とは和睦すべし——敵性の例外としてkṛtrima-mitratā（人為的友誼）がより強いため。味方であっても害をなす者とは断交すべし。格言引用：yas tv amitreṇa saṃdhatte mitraṃ ca viddhyati / arthayuktiṃ samālocya sa mahad vindate phalam。

【Mallinātha】

シシュパーラはpaitṛṣvaseyatva（父方姉妹の子）ゆえsahajamitra（生来の友）であるから討つべきでないとの反論への応答。行為（kriyā）により友敵が逆転しうるため、upakāra-apakāraこそがlakṣaṇa（定義）でありlakṣya（観察すべきもの）である。GRETILのupakartrariṇā・lakṣamamを訂正。

II.38
Sanskrit (IAST) tvayā viprakṛtaś caidyo rukmiṇīṃ haratā hare / baddhamūlasya mūlaṃ hi mahad vairataroḥ striyaḥ //
和訳

ハリよ、ルクミニーを奪い去った（haratā）お前によって、チェーディ王（caidya）は傷つけられた（viprakṛta）。根深い（baddhamūla）怨恨の木（vairataru）の偉大な根（mūla）とは、女性（striyaḥ）なのだから。

注

【Vallabhadeva】

一般論から具体論へ——チェーディのkṛtrimatā（人為的敵性）を四偈（II.38-41）で示す。ルクミニーは親族によりシシュパーラに与えられていたが、クリシュナがラークシャサ婚（rākṣasadharma＝武力略奪婚）で奪った。vairataru（怨恨の木）はrūpaka（隠喩）融合のarthāntaranyāsa。

【Mallinātha】

ヤージュニャヴァルキヤ引用：rākṣaso yuddhaharaṇāt。マヌ引用：gāndharvo rākṣasaś caiva dharmyau kṣatrasya tau smṛtau（ガーンダルヴァ婚とラークシャサ婚はクシャトリヤの正法）。baddhamūla＝rūḍhamūla（根を張った）。rūpakasaṃsṛṣṭa（隠喩混合）のarthāntaranyāsa（一般により特殊を支持する修辞）。

II.39
Sanskrit (IAST) tvayi bhaumaṃ gate jetum auratsīt sa purīm imām / proṣitāryamaṇaṃ meror andhakāras taṭīm iva //
和訳

お前がバウマ（ナラカースラ）を討ちに出た（gate）とき、彼（シシュパーラ）はこの都（purī＝ドヴァーラカー）を包囲した（auratsīt）。それはあたかも、アーリヤマン（太陽）が去った（proṣita）メール山の斜面（taṭī）を闇（andhakāra）が覆うがごとく。

注

【Vallabhadeva】

シシュパーラによるクリシュナへの逆の害——クリシュナがナラカースラ征伐に出陣した隙に、ドヴァーラカーを攻めた。auratsīt（Vallabhadevaはautsīt saと読む）はrudhのルング。太陽が去ったメール山の斜面に闇が忍び寄るというupamā（直喩）。

【Mallinātha】

bhauma＝bhūmeḥ apatyaṃ pumān（大地の子＝ナラカースラ）。auratsītはrudh（阻止する・包囲する）のaniṬ・ルング・sic加入による活用形。クリシュナ＝太陽、シシュパーラ＝闇、ドヴァーラカー＝メール山の斜面。upamālaṅkāra。

II.40
Sanskrit (IAST) ālapyālam iyaṃ babhror yat sa dārān apāharat / kathāpi khalu pāpānām alam aśreyase yataḥ //
和訳

彼（シシュパーラ）がバブル（ヤーダヴァの一族）の妻を奪った（dārān apāharat）ことは——口にするだけで（ālapya）もう十分（alam）。悪人の所業は、その話題に触れること（kathā）すら、災い（aśreyas）をもたらすに十分なのだから。

注

【Vallabhadeva】

チェーディの更なる悪行——バブル（ヴリシュニ族の一人）の妻の略奪。ālapya alamはālapya（口にして）+ alam（十分、禁止の意：nālapanīyam＝口にすべきでない）。alṃkhalvoḥ pratiṣedhayoḥ prācāṃ ktvāの規則でktvā接尾辞、複合時にlyab代置。

【Mallinātha】

dāra＝妻（bhāryā jāyāのsynonym。アマラコーシャ）。kathā＝kathana（言及）、cintipūjikudhikumbiのa接尾辞。悪人の言及すら災いを招く——口にすることの禁止により、その行為の禁止を正当化するarthāntaranyāsa（趣旨転換修辞：結果による原因の支持）。

II.41
Sanskrit (IAST) virāddha evaṃ bhavatā virāddhā bahudhā ca naḥ / nirvartyate 'riḥ kriyayā sa śrutaśravasaḥ sutaḥ //
和訳

かくして御身（クリシュナ）によって害され、また幾度もわれらを害してきた——かのシュルタシュラヴァスの子（シシュパーラ）は、〔これらの〕行為によって〈敵〉に仕立て上げられたのである。

注

【Vallabhadeva】

ここでクリトゥリマ（人為的敵）の議論を総括する。virāddhaはrādh語根の被動過去分詞（aniṭ）。彼は母方の従兄弟（paitṛṣvaseyatva）ゆえ本来サハジャ・ミトラ（生来の友）でもあったが、相互の行為によりkṛtrima śatru（人為的敵）とされた。それゆえ強力であるから無視すべきでない。

【Mallinātha】

rādheḥ aniṭaḥ karmaṇi ktaḥ＝rādh語根、aniṭ（iṭなし）、被動のkta接尾辞。śrutaśravāはハリ（クリシュナ）の父方の叔母（pitṛṣvasā）ダマゴーシャの妻。母方の従兄弟関係ゆえサハジャ・ミトラでもあった（sahajamitram api）が、行為によりクリトゥリマの敵に転化した。

II.42
Sanskrit (IAST) vidhāya vairaṃ sāmarṣe naro 'rau ya udāsate / prakṣipyodarciṣaṃ kakṣe śerate te 'bhimārutam //
和訳

怒りに燃える敵に対して敵意を抱きながら、なお無為に坐する者たちは、乾いた草むらに火を放ち、風上に向かって眠るに等しい。

注

【Vallabhadeva】

kakṣe＝灌木・枯草（tuṣu）。風に向かって枯草に火を放ち眠ることは自滅を招く——強力な敵に対して無策でいることも同じ。naraはnṛのjas（複数主格）。ātmanepadaはātmanepadānām dhvāṃtaḥによる。

【Mallinātha】

sāmarṣe＝あらかじめ怒っている（prāg eva sakroṣe）敵。kakṣe＝灌木（gulma、ヴァイジャヤンティー辞典：kakṣas tu gulme dormūle pāpe jīrṇavane tṛṇe）。udarciṣam＝猛炎の火。abhimārutam＝風に向かって（ābhimukhye avyayībhāvaḥ）。二つの文の間に事実上の同一性を措定するニダルシャナー・ベーダ（nidarśanā-bheda）の修辞。

II.43
Sanskrit (IAST) manāg anabhyāvṛttyā vā kāmaṃ kṣamyatāṃ yaḥ kṣamī / kriyāsamabhihāreṇa virādhyantaṃ kṣameta kaḥ //
和訳

些細な、あるいは一度きりの過ちであれば、忍耐強き者はなるほど堪忍してもよい。しかし行為を繰り返し積み重ねて害する者を、誰が忍べようか。

Sanskrit (IAST) iti viśakalitārthām auddhavīṃ vācam enām anugata-naya-mārgam argalāṃ durnayasya / janitamudam udasthād uccakair ucchritoraḥ- sthala-niyata-niṣaṇṇa-śrī-śrutāṃ śuśruvān saḥ //
和訳

かくして、あらゆる意義を分析し尽くし（viśakalitārtha）、正しき政道に従い（anugata-naya-mārga）、悪しき政策への閂（argalā）たるこのUddhavaの言葉を——喜びを催しつつ——高々と隆起した胸に不動のŚrī（吉祥天）を戴くかの方（Kṛṣṇa）は、聴き終えて、高く立ち上がった。

注

【Vallabhadeva】

第二章の結偈。auddhavī vāc＝Uddhavaの言葉。viśakalitārthā＝すべての意義を分別・分析した。argalā＝閂・門止め（「tadviṣkambho 'rgalaṃ na nā」Amarakośa）、durnaya（悪政）を防ぐ閂としての比喩でrūpaka。ucchritoaḥsthala＝隆起した胸。niyata-niṣaṇṇa-śrī＝永遠にŚrī（Lakṣmī）が鎮座する——ViṣṇuとしてのKṛṣṇaの胸にŚrīvatsaの印がある伝統的表象。udasthāt＝（座から）立ち上がった（ud+sthā）。uccakaiḥ＝高々と（avyayasarvanāmnām akacprākteḥによるakac接尾辞）。śuśruvān＝聞いた（śruのkasu接尾辞、「bhāṣāyāṃ sadavaśśravaḥ」）。mālinī韻律。

【Mallinātha】

同趣旨。janitamudaの解釈：Kṛṣṇaの中に歓喜（muda）が生じた。Uddhavaの助言にKṛṣṇaが全面的に満足したことを示す。rūpakaとanuprāsa（頭韻）の修辞が用いられている。iti śrīmāghakṛtau śiśupālavadhe mahākāvye śṛṅgāre mantravarṇanaṃ nāma dvitīyaḥ sargaḥ——Māgha作『シシュパーラヴァダ』大詩篇・恋愛情趣の中の、政略評議の描写と称する第二章。
