大学1年生のためのインド哲学入門

はじめての『認識論評釈』第1章と自注
――ダルマキールティの推論論・言語哲学・聖典批判

ダルマキールティの主著『プラマーナ・ヴァールッティカ』（『認識論評釈』）の第1章は、全4章のうち彼自身が散文の注（自注）を付けた唯一の章です。340の偈と自注からなるこの章は、正しい推論の理由を論じる論理学の書であると同時に、言葉はどうやって意味をもつのかという言語哲学（アポーハ論）、そして聖典ヴェーダの権威を理性で吟味する宗教批判の書でもあります。最後の偈は「愚かさの五つの印」として、インド思想史上もっとも有名な言葉の一つです。このページでは、原文の訳は載せずに、議論の中身を図と表、西洋哲学との比較でたどります。

　p.24 のような印は、校訂本（Gnoli 1960）の頁です。第40偈 は同書の偈の番号です。

0この本を読む前に・全体の地図

著者ダルマキールティ（法称、600–660年ごろ）。インド仏教の論理学・認識論の大成者。
書名『プラマーナ・ヴァールッティカ』（『認識論評釈』）。先輩ディグナーガの『認識手段集成』を「評釈」する形をとる、ダルマキールティの最大の主著。全4章。
第1章「自分のための推論」の章。偈340と、ダルマキールティ自身の散文の注（自注）からなる。他の3章には自注がない。
成り立ちシュタインケルナー（Steinkellner）によれば、この章はもともと独立した論理学の著作（フラウワルナーの呼び方で『論証因論』）で、偈と散文を最初から組み合わせて書かれた作品である。最初期の著作と考えられている。
後の著作との関係ここで打ち出した理論が、のちの『プラマーナ・ヴィニシュチャヤ』第2・3章や『ヘートゥビンドゥ』で整理し直される。

1序：なぜ「推論」から始めるのか

帰敬偈・序偈 / p.1

本は、仏陀への帰敬の偈と、少し変わった序の偈で始まります。序の偈でダルマキールティは、「世の人はたいてい俗事に執着し、よい言葉を求めないどころか憎みさえする。だから他人のためになるとは思っていない。長年の学びで募った熱中から書くのだ」と述べます。ふつう大乗の論書は「他者のために書く」と言うので、この孤高の宣言は異例です。

ここが要点 何が有益で何が無益かを見分けることは、推論にかかっている。ところが推論については、学派によって考えがばらばら。だから推論を正しく確立するために、この章から始める。p.1
西洋哲学と比べてみよう：啓蒙の宣言 ミーマーンサー学派は、何が正しい行いか（ダルマ）は聖典ヴェーダの命令によってのみ知られる、と主張しました。シュタインケルナーは、「有益・無益の区別は推論にかかっている」という冒頭の一文を、この学派への意図的な対抗と見ています。
カントは「啓蒙とは何か」（1784年）で、「自分の理性を使う勇気をもて（サペーレ・アウデ）」と呼びかけ、権威に頼らず自分で考えることを求めました。ダルマキールティの冒頭の宣言も、権威ではなく理性（推論）で判断せよという、同じ方向を向いています。この姿勢は、章の最後の聖典批判（§9–§10）までつながっていきます。

2正しい理由の定義と三種類

第1–2偈 / pp.1–4

第1偈：章全体の綱領 理由（論証因）とは、主題の性質であり、推し量られる性質に遍充されているものである。それは三種類だけ。例外のない関係（不可離の関係）は、この三種類にしかないからである。それ以外は、理由のように見えるにせものにすぎない。p.1

この偈は『ヘートゥビンドゥ』冒頭の偈とまったく同じ文です。ダルマキールティは、生涯を通じてこの定義を使い続けました。

三種類例理由と推し量られるものの関係位置
結果煙 → 火因果。結果は原因のもつ性質のうち、それと離れられない限りのものを知らせる第2偈前半 / p.3
本性シンシャパー → 樹、作られたもの → 無常同一性。理由の存在だけに伴う性質を知らせる第2偈後半 / p.4
非認識見えるはずの壺が見えない → 壺はない（§3で）第3–6偈 / pp.4–6
ちょっと注目：師への批判 シュタインケルナーによれば、第1偈の注釈で反論者として出てくるのは、ダルマキールティの師イーシュヴァラセーナです。ダルマキールティは師の論理学を受け継ぎつつ、あちこちで批判しています。とくに§5で見る「見たことがない」だけで十分だという説は、師の説です。

3「ない」ことの知り方

第3–6偈 / pp.4–6

第3偈は、二種類の「見えないこと」を区別します。

① 認識手段が働かないこと② 理由としての非認識
どんな場合対象がない（かもしれない）とき、ただ何も知覚されない見えるための条件がそろっているのに見えない
結果「ある」と思わない・言わない・行動しない「ない」と知る
西洋哲学と比べてみよう：ライバルの定義を借りる シュタインケルナーは、①の定義「認識手段が働かないこと」が、ミーマーンサー学派のクマーリラによる「無」の定義（知覚などが生じないこと）をそっくり借りていると指摘します。ダルマキールティは、相手の定義をいったん受け入れて、その限界を示し、②の「条件つきの非認識」を対置したのです。
これは、全知者（仏陀）の存在を「見たことがない」から否定するミーマーンサー学派への反論の準備でもあります。「証拠がないことは、ないことの証拠ではない」――ただし条件がそろっていれば別だ、という考え方です。

4原因がそろえば結果を推せる

第7–14偈 / pp.6–10

原因から結果を推し量る推論（「雨雲が出ているから雨が降るだろう」）は、ふつう確実ではありません。途中で風が吹けば雨は降らないからです。ダルマキールティは、原因が完全にそろっていて、妨げるものがない場合に限って、結果が生じることを推し量れる、と言います。しかも、それは「結果の理由」ではなく「本性の理由」だ、というのです 第7偈 / p.6。

ここが要点 完全にそろった原因には、「結果を生む力」がすでに本性として含まれている。だから、そこから推し量られるのは、まだ生じていない結果そのものではなく、原因の総体がもつ「結果を生むのにふさわしい性質」である。
西洋哲学と比べてみよう：ミルの「原因の総体」とラプラスの悪魔 ミルは、本当の原因とは、結果に必要なすべての条件の総体だと考えました。ラプラスは、世界の状態と法則をすべて知る知性（ラプラスの悪魔）なら、未来をすべて予言できると述べました。ダルマキールティも「原因が完全にそろえば」結果は推せると考えますが、ふつうの人間にはその完全さを確かめるのが難しいことも自覚しています。

5「見たことがない」では足りない

第15–22偈 / pp.10–16

師ディグナーガは、理由の三つの条件すべてについて確定が必要だと説きました 第15偈 / p.10。ダルマキールティはこれを受けて、師イーシュヴァラセーナの説を批判します。イーシュヴァラセーナは、「推し量られるものがない所（異類）に理由がないこと」は、見たことがない（不見）だけで確かめられる、と考えていました。

ダルマキールティの批判 「見たことがない」だけでは、異類に理由がないとは確定できない。見ていない所にあるかもしれないからだ。確定のためには、理由と推し量られるものの間に本性的な縛り付け（同一性か因果）があることを示さなければならない。
西洋哲学と比べてみよう：帰納の問題 「これまで見た白鳥はすべて白い。だから白くない白鳥はいない」――ヒュームやポパーが問題にした帰納の限界です。イーシュヴァラセーナの「不見」説は素朴な帰納主義、ダルマキールティの「縛り付け」説は、観察の数ではなく事物の構造に必然性の根拠を求める立場だと言えます。

6本性的な縛り付けと例の役割

第23–39偈 / pp.16–24

第23偈：縛り付けがあるときだけ「退去」が伴う あるものの存在だけに縛り付けられた本性は、そのものが退くとき、一緒に退く。原因が退けば、結果も退く。それ以外のもの（縛り付けのないもの）は、一方が退いても他方が退くとは限らない。p.16

ここでダルマキールティは、例（喩例）についても大事な指摘をします。「常住なものは作られたものではない。虚空のように」という否定の例では、その例（虚空）が実在する必要はない（第26偈）。推し量られるものがない所に理由がない、と示せればよいからです。

西洋哲学と比べてみよう：空虚な真理 現代論理学では、「すべての一角獣は額に角が一本ある」は、一角獣が存在しなくても真になります（空虚な真理）。「p ならば q」の形の文は、p にあてはまるものが一つもなくても成り立つのです。第26偈の「否定の例には基体（実在するもの）は必ずしも要らない」は、この考え方とよく似ています。

7アポーハ論：言葉は「排除」で意味をもつ

第40–185偈 / pp.24–93

章のいちばん長い部分は、論理学から一歩出て、言葉と概念の理論に向かいます。きっかけは本性の理由です。「作られたもの」と「無常」が同じ一つのものの本性なら、「音は無常である。作られたものだから」は「無常だから無常だ」と同じで、何も証明していないのではないか？

7.1出発点：すべてのものは他から区別されている 第40–42偈 / p.24

ここが要点（第40–42偈） すべての事物は、それぞれ自分の本性に立っていて、同類のものからも他類のものからも区別されている。事物が何から区別されているかにもとづいて、さまざまな種類（概念）が組み立てられる。だから、一つの事物でも、「何から区別するか」が違えば、違う概念でとらえられる。

7.2普遍（「〜性」）は実在しない 第71–75偈・第143–158偈

他の学派（ニヤーヤ・ヴァイシェーシカ学派、ミーマーンサー学派）は、すべての牛に共通する「牛性」という実在の普遍があるから、どの牛を見ても「牛だ」とわかるのだ、と考えました。ダルマキールティは、これをさまざまな角度から批判します。

批判内容位置
普遍は見えない個物は互いに入り込まない。個物と別の「牛性」が知に現れることもない第71偈 / p.39
「同じ働き」で十分違う薬草が、それぞれ熱病を鎮める。共通の普遍がなくても、同じ結果を生むものを一つの言葉でまとめればよい第73–75偈 / pp.40–44
普遍はどこから来たのか新しい壺が作られると「壺性」が宿る。でも壺性は動かないから他から来たのではなく、前からそこにあったのでもなく、部分もなく、元の壺を離れるのでもない。「ああ、災難の連続！」第152偈 / p.76
結果を生むのは個物だけ火が燃やすのは「この火」であって「火性」ではない。生み出す力をもつのは、区別された個物だけ第163–175偈 / pp.82–88
同時に同じで違う？「事物は普遍としては同じで、個物としては違う」という同異説も成り立たない第176–184偈 / pp.88–90
西洋哲学と比べてみよう：普遍論争と言語哲学
西洋の考えダルマキールティとの関係
プラトン『パルメニデス』：一つのイデアが多くのものに分有されるなら、イデアは「帆」のように分割されてしまうのでは？第152偈の「普遍はどこから来て、どう宿るのか」という批判とそっくり
中世の普遍論争：オッカムの唯名論普遍は実在せず、心と言葉の上にだけある、という立場は同じ
ソシュール：言葉の価値は、他の言葉との差異によって決まる「何でないか」によって意味が決まる、というアポーハ論と驚くほど近い
ウィトゲンシュタイン「家族的類似」：「ゲーム」と呼ばれるものすべてに共通の本質はない共通の本質（普遍）なしに一つの言葉でまとめられる、という点で共通。ダルマキールティは「同じ働き」をまとめる根拠にする

7.3言葉は話し手の意図に従う 第65–70偈・第92偈 / pp.35–51

言葉は、人々が決めた取り決め（約束）によって意味をもちます。ところが、取り決めをしたときの個物（あの時のあの牛）は、言葉を使うときにはもう存在しません（第92偈）。だから言葉が直接指すのは個物そのものではなく、心に描かれた「牛でないものではないもの」という概念です。言葉は事物に支配されるのではなく、話し手の意図に従います（第65偈）。

7.4「ないもの」についての言葉 第185偈 / pp.90–93

「ウサギの角」のような、存在しないものについての言葉はどう説明するのか。非存在には姿がないので、言葉がその姿を表すのではない。言葉はあくまで排除によって働くので、指す実在がなくても問題はない、とダルマキールティは答えます。

8「存在する」ことと「ない」ことの論証

第186–212偈 / pp.93–107

アポーハ論から論理学に戻ります。

  • 本性の理由の区分：本性の理由には、限定のついたもの（「作られたもの」＝原因に依存するもの）と、限定のない単独のもの（「存在するもの」）がある 第186偈 / p.93。後者は「存在するものはすべて刹那的である」という刹那滅の論証で使われます。
  • 非認識が認識手段である理由：行動は知を前提とする。あるものの存在が認識されないなら、それに向かって行動すべきではない。非認識は、こうして行動を正しく導くので、認識手段である 第198偈 / p.101。
  • 「根本原質は存在しない」：サーンキヤ学派の宇宙の根源（原質）のように、実在しないものについての言葉の意味は、始まりのない潜在印象から生じた分別の上に成り立つ。だから「存在しない」と否定することもできる 第205偈 / p.105。
西洋哲学と比べてみよう：プラグマティックな正当化 「行動は知を前提とするので、知られていないものに向かって行動すべきではない」という第198偈の考え方は、知識を行動との関係で正当化する点で、プラグマティズム（パース、ジェイムズ）の発想に近いと言えます。

9聖典は信頼できるか：ヴェーダ批判

第213–339偈 / pp.107–176

章の後半の大部分は、ミーマーンサー学派の中心的な主張――ヴェーダは人が作ったものではない（非人為）。だから作者の誤りがなく、絶対に正しい――への、徹底した批判にあてられます。

① 言葉と実在言葉は実在と離れられない関係にないので、言葉から対象は確定しない。言葉が知らせるのは話し手の意図だけ第213偈 / p.107
② 作者の記憶「作者が記憶されていないから作者はいない」？　覚えていないことは、いないことの証拠にならない第239偈 / p.120
③ 何が永遠か永遠なのが音素なら、日常の音素と違いがなく、ヴェーダだけが特別な理由がない。文は音素と別には存在しない第247偈 / p.126
④ 常住な言葉の知覚言葉が努力から生じるなら、人に由来する。常住なら、覆われることもなく、いつも聞こえるはずだ第251偈 / p.129
⑤ 滅びの無因性音も、すべての存在も、生じたものは原因なしに滅びる（刹那滅）。だから永遠の音はない第269–275偈 / pp.141–150
⑥ 人に由来しない＝正しい？火や灯火は人の過失に汚されていないが、誤った知の原因になることがある（灯火の下では青い蓮の色が違って見える）。人に由来しないことは、正しさの保証にならない第284偈 / p.150
⑦ マントラの効力呪文（マントラ）が効くのが人の取り決めによるなら理解できる。言葉そのものの力なら、誰がいつ唱えても効くはずだ第292偈 / p.155
⑧ 音素の順序「サラハ（池）」と「ラサハ（味）」は同じ音素で順序が違うだけ。順序を決めるのは人なので、文は人に由来する第301偈 / p.160
⑨ 一部が正しい「火は寒さを除く」のようにヴェーダの一部が正しくても、他の文が正しいことにはならない第330偈 / p.173
西洋哲学と比べてみよう：無知に訴える論証・言語行為・啓蒙の聖書批判

②「作者が記憶されていない」から作者はいない論理学で言う無知に訴える論証（「証明されていないから偽／真だ」）の誤り
③⑧ 音素と文、順序パースのタイプとトークン。ソシュールの「言葉の線状性」と「恣意性」
⑦ マントラは取り決めで効くオースティンの言語行為論：「誓います」「命名します」が効力をもつのは、社会的な取り決め（慣習）があるから

10結び：愚かさの五つの印

第340偈 / p.176

章は、インド思想史上もっとも有名なダルマキールティの言葉の一つで閉じられます。韻律も、ほかの偈とは違う荘重なものが使われています。

第340偈 ① ヴェーダを認識手段とすること、② 何者か（創造神）を世界の作者とする説、③ 沐浴に功徳を求めること、④ 生まれ（種姓）を誇ること、⑤ 罪を除くために身を苦しめること――これらは、知恵を失った者たちの愚かさの五つの印である。
印批判の対象章の中の根拠
① ヴェーダの権威ミーマーンサー学派第213–339偈
② 創造神ニヤーヤ・ヴァイシェーシカ学派の主宰神常住なものははたらけない
③ 沐浴の功徳聖地での沐浴による浄化罪は心の過失から生じる（第215偈）
④ 種姓の驕りバラモンの優越の主張第295偈
⑤ 苦行ジャイナ教などの苦行主義過失は無我の智慧で除かれる（第220–223偈）
西洋哲学と比べてみよう：宗教批判と啓蒙 ヴォルテールは「恥ずべきものを打ち砕け」と叫んで迷信と教会の権威を攻撃し、ヒュームは『宗教の自然史』で宗教的慣習を人間の心理から説明しました。ダルマキールティの五つの印は、権威・創造神・儀礼・身分制度・苦行という、当時のインド社会の根本を正面から批判するもので、その大胆さは西洋の啓蒙思想に引けを取りません。
ただし彼は仏教徒として宗教そのものを否定したのではなく、理性で検証できない権威を退け、心の過失を智慧で除く道を勧めたのです。冒頭の「有益・無益は推論で見分ける」という宣言（§1）が、ここで見事に回収されています。
第1章のまとめ
  1. 何が有益で何が無益かは、聖典ではなく推論で見分ける（序）。
  2. 正しい理由は、主題にあり、推し量られるものに遍充される。結果・本性・非認識の三種類だけ（第1–6偈）。
  3. 推論の確実さは「見たことがない」ではなく、本性的な縛り付け（同一性か因果）が支える（第15–39偈）。
  4. 言葉と概念は、実在の普遍ではなく、他のものの排除（アポーハ）によって成り立つ（第40–185偈）。
  5. 言葉は話し手の意図を知らせるだけなので、作者のない聖典の絶対的権威は成り立たない（第213–339偈）。
  6. 権威・創造神・儀礼・身分・苦行への盲信は、愚かさの五つの印である（第340偈）。
発展問題（レポートのヒント）
  1. アポーハ論（§7）とウィトゲンシュタインの家族的類似。「ゲーム」という言葉を、ダルマキールティならどう説明するだろうか。
  2. 「人に由来しないことは正しさの保証にならない。灯火は人の過失に汚されていなくても、色を見誤らせることがある」（第284偈）。この論法は、現代の「自然なものは安全だ」という主張にも当てはまるだろうか。
  3. 第340偈の五つの印を、西洋の啓蒙思想家（ヴォルテール、ヒューム、カント）の宗教批判と比べ、共通点と違いを論じてみよう。

典拠　R. Gnoli, The Pramāṇavārttikam of Dharmakīrti: The First Chapter with the Autocommentary, Roma 1960（頁・偈番号は同書）。E. Steinkellner, Dharmakīrtis frühe Logik, 2 vols., Tokyo 2013。

西洋哲学との比較は、理解の手がかりとして加えたもので、ダルマキールティ自身の議論ではありません。
