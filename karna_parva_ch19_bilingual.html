karṇaparva — ekonaviṃśo'dhyāyaḥ (19)
第19章　入り乱れの戦い
sañjaya uvāca|
yudhiṣṭhiraṃ mahārāja visṛjantaṃ śarān bahūn|
svayaṃ duryodhano rājā pratyagṛhṇād abhītavat|| // 8-19-1 //
サンジャヤは語った。 （1）大王よ、多くの矢を放つユディシュティラに対して、ドゥルヨーダナ王自ら、恐れることなく立ち向かいました。
tamāpatantaṃ sahasā tava putraṃ mahāratham|
dharmarājo drutaṃ viddhvā tiṣṭhatiṣṭheti cābravīt|| // 8-19-2 //
（2）突然突進してくるあなたの息子、偉大な戦車戦士に対し、ダルマ王（ユディシュティラ）は素早く射て、「待て、待て！」と叫びました。
sa tu taṃ prativivyādha navabhir niśitaiḥ śaraiḥ|
sārathiṃ cāsya bhallena bhṛśaṃ kruddho'bhyatāḍayat|| // 8-19-3 //
（3）ドゥルヨーダナは九本の鋭い矢でユディシュティラを射返し、激怒して矢尻の矢で御者を激しく打ちました。
tato yudhiṣṭhiro rājan svarṇapuṅkhāñ śilīmukhān|
duryodhanāya cikṣepa trayodaśa śilāśitān|| // 8-19-4 //
（4）王よ、ユディシュティラは金の矢尻の石に研がれた十三本の矢をドゥルヨーダナに放ちました。
caturbhiś caturo vāhāṃs tasya hatvā mahārathaḥ|
pañcamena śiraḥ kāyāt sāratheś ca samākṣipat|| // 8-19-5 //
（5）偉大な戦車戦士は四本の矢でドゥルヨーダナの四頭の馬を殺し、五本目で御者の首を体から切り離しました。
ṣaṣṭhena tu dhvajaṃ rājñaḥ saptamena tu kārmukam|
aṣṭamena tathā khaṅgaṃ pātayāmāsa bhūtale|
pañcabhir nṛpatiṃ cāpi dharmarājo'rdayadbhṛśam|| // 8-19-6 //
（6）六本目で王の旗を、七本目で弓を、八本目で剣を大地に叩き落とし、残りの五本で王を激しく射ちました。
hatāśvāt tu rathāt tasmād avaplutya sutas tava|
uttamaṃ vyasanaṃ prāpto bhūmāv eva avatiṣṭhata|| // 8-19-7 //
（7）馬を殺された戦車からあなたの息子は飛び降り、最も困難な状況に陥り、大地に立ち尽くしました。
taṃ tu kṛcchragataṃ dṛṣṭvā karṇadrauṇikṛpādayaḥ|
abhyavartanta sahasā parīpsanto narādhipam|| // 8-19-8 //
（8）窮地に陥ったドゥルヨーダナを見て、カルナ、ドローナの子、クリパたちが急いで王を救おうと駆けつけました。
atha pāṇḍusutāḥ sarve parivārya yudhiṣṭhiram|
anvayuḥ samare rājaṃs tato yuddham avartata|| // 8-19-9 //
（9）パーンドゥの子たちは全員ユディシュティラを取り囲んで守り、王よ、そして戦闘が繰り広げられました。
tatas tūryasahasrāṇi prāvādyanta mahāmṛdhe|| // 8-19-10 //
（10）何千もの楽器が大戦闘で鳴り響きました。
kṣvelāḥ kilakilāśabdāḥ prādurāsan mahīpate|
yatrābhyagacchan samare pāñcālāḥ kauravaiḥ saha|| // 8-19-11 //
（11）王よ、叫び声やキリキリという声が上がりました。パーンチャーラ族とカウラヴァが戦場で激突したところで。
narā naraiḥ samājagmur vāraṇā varavāraṇaiḥ|
rathāśca rathibhiḥ sārdhaṃ hayāśca hayasādibhiḥ|| // 8-19-12 //
（12）人は人と、象は象と、戦車は戦車兵と、馬は騎兵とぶつかり合いました。
dvandvāny āsan mahārāja prekṣaṇīyāni saṃyuge|
vividhāny api acintyāni śastravanty uttamāni ca|| // 8-19-13 //
（13）大王よ、戦場では見応えのある、想像を絶する、武器を持った最上の一騎打ちが、さまざまに繰り広げられました。
te śūrāḥ samare sarve citraṃ laghu ca suṣṭhu ca|
ayudhyanta mahāvegāḥ parasparavadhaiṣiṇaḥ|| // 8-19-14 //
（14）すべての勇者は戦場で、華麗に、軽妙に、巧みに、大いなる速さで、互いの殺害を望みながら戦いました。
anyonyaṃ samare jaghnuryodhavratamanuṣṭhitāḥ|
na hi te samaraṃ cakruḥ pṛṣṭhato vai kathañcana|| // 8-19-15 //
（15）戦士の掟に従った者たちは、戦場で互いを打ちました。決して背後から攻撃することはありませんでした。
muhūrtam eva tad yuddham āsīn madhuradarśanam|
tata unmattavad rājan nirmaryādam avartata|| // 8-19-16 //
（16）ほんの一瞬、その戦いは美しく見えましたが、王よ、すぐに狂った者のように、秩序を失いました。
rathī nāgaṃ samāsādya dārayanniśitaiḥ śaraiḥ|
preṣayāmāsa kālāya śaraiḥ sannataparvabhiḥ|| // 8-19-17 //
（17）戦車兵が象に出くわすと、鋭い矢で引き裂き、しなやかな矢で死の世界へ送りました。
nāgā hayān samāsādya vikṣipanto bahūn raṇe|
dārayāmāsur atyugraṃ tatratatra tadātadā|| // 8-19-18 //
（18）象が馬に出くわすと、戦場で多くの馬を投げ飛ばし、あちこちで激しく引き裂きました。
hayārohāś ca bahavaḥ parivārya hayottamān|
talaśabdaravāṃś cakruḥ sampatantas tatastataḥ|| // 8-19-19 //
（19）多くの騎兵たちが最上の馬を囲み、あちこちに飛びかかりながら、手を叩く音を上げました。
dhāvamānāṃs tatas tāṃs tu dravamāṇān mahāgajān|
pārśvataḥ pṛṣṭhataś caiva nijaghnur hayasādinaḥ|| // 8-19-20 //
（20）走っていく馬たちや逃げる大象たちを、騎兵たちは横から、背後から殺しました。
vidrāvya ca bahūn aśvān nāgā rājan madotkaṭāḥ|
viṣāṇaiś cāpare jaghnur mamṛduś cāpare bhṛśam|| // 8-19-21 //
（21）王よ、発情した多くの象が馬を追い散らし、牙で突き殺し、踏み潰しました。
sāśvārohāṃś ca turagān viṣāṇair vivyadhū ruṣā|
apare cikṣipur vegāt pragṛhya atibalās tadā|| // 8-19-22 //
（22）騎兵とともに馬を牙で怒りをもって突き、他の象は勢いよく掴んで投げ飛ばしました。
pādātairāhatā nāgā vivareṣu samantataḥ|
cakrur ārtasvaraṃ ghoraṃ dudruvuś ca diśo daśa|| // 8-19-23 //
（23）歩兵に弱点を打たれた象たちは、あちこちで恐ろしい悲鳴を上げ、十方に逃げ出しました。
padātīnāṃ tu sahasā pradrutānāṃ mahāhave|
utsṛjya ābharaṇaṃ tūrṇam avavavrū raṇājire|| // 8-19-24 //
（24）大戦闘で突然逃げ出す歩兵たちは、装飾品を素早く捨てて戦場を駆け抜けました。
nimittaṃ manyamānās tu pariṇāmya mahāgajāḥ|
jagṛhur bibhiduś caiva citrāṇy ābharaṇāni ca|| // 8-19-25 //
（25）勝利の手段と見なして、大象たちはそれら（装飾品）を向きを変えて拾い上げ、美しい装飾品を砕きました。
tāṃs tu tatra prasaktān vai parivārya padātayaḥ|
hastyārohān nijaghnus te mahāvegā balotkaṭāḥ|| // 8-19-26 //
（26）それに熱中する象たちを取り囲み、力あふれる大いなる速さの歩兵たちは象使いたちを殺しました。
apare hastibhir hastaiḥ khaṃ vikṣiptā mahāhave|
nipatanto viṣāṇāgrair bhṛśaṃ viddhāḥ suśikṣitaiḥ|| // 8-19-27 //
（27）他の者たちは象の鼻で空中に投げ上げられ、大戦闘で落ちてくる時に、よく訓練された象の牙の先で激しく突かれました。
apare sahasā gṛhya viṣāṇaireva sūditāḥ|
senāntaraṃ samāsādya kecit tatra mahāgajaiḥ|| // 8-19-28 //
（28）他の者は突然牙で掴まれて殺されました。大象たちのもとに至った者の中には——
kṣuṇṇagātrā mahārāja vikṣipya ca punaḥpunaḥ|
apare vyajanāni iva vibhrāmya nihatā mṛdhe|| // 8-19-29 //
（29）大王よ、体を踏み潰され、何度も投げ上げられ——扇のように振り回されてから殺された者もいました。
puraḥsarāś ca nāgānām apareṣāṃ viśāmpate|
śarīrāṇy atividdhāni tatratatra raṇājire|| // 8-19-30 //
（30）王よ、象の前衛を務める者たちの、別の者たちの体が、あちこちの戦場でひどく傷つけられていました。
pratimāneṣu kumbheṣu dantaveṣṭeṣu cāpare|
nigṛhītā bhṛśaṃ nāgāḥ prāsatomaraśaktibhiḥ|| // 8-19-31 //
（31）象の頬・頭頂・牙の付け根を、槍・投げ槍・槍で激しく打つ者もいました。
nigṛhya ca gajāḥ kecit pārśvasthair bhṛśadāruṇaiḥ|
rathāśvasādibhis tatra sambhinnā nyapatan bhuvi|| // 8-19-32 //
（32）何頭かの象は、横にいた恐ろしく凶暴な戦車兵・騎兵・歩兵に突き破られて大地に倒れました。
sahayāḥ sādinas tatra tomareṇa mahāmṛdhe|
bhūmāv amṛdran vegena sacarmāṇaṃ padātinam|| // 8-19-33 //
（33）大戦闘で、馬に乗った者が投げ槍で、盾を持った歩兵を力強く大地に押し倒しました。
cachā sāvaraṇān kāṃś cit tatratatra viśāmpate|
rathān nāgāḥ samāsādya parigṛhya ca māriṣa|
vyākṣipan sahasā tatra ghorarūpe bhayānake|| // 8-19-34 //
（34）王よ、あちこちで、覆いのある戦車を象たちが掴んで、恐ろしい形相の恐ろしい光景の中で突然投げ飛ばしました。
nārācairnihatāścāpi gajāḥ peturmahābalāḥ|
parvatasya iva śikharaṃ vajrarugṇaṃ mahītale|| // 8-19-35 //
（35）鉄の矢に打たれた大力の象たちは、金剛杵に砕かれた山の頂のように大地に崩れ落ちました。
yodhā yodhān samāsādya muṣṭibhir vyahanan yudhi|
keśeṣv anyonyam ākṣipya cikṣipur bibhiduś ca ha|| // 8-19-36 //
（36）戦士たちは戦士と出くわして拳で殴り合い、互いの髪をつかみ、投げ、引き裂きました。
udyamya ca bhujān anye nikṣipya ca mahītale|
padā ca uraḥ samākramya sphurato'pāharac chiraḥ|| // 8-19-37 //
（37）ある者は両腕を振り上げてから大地に叩きつけ、足で胸を踏みつけて、もがく者の首を切り落としました。
patataś cāparo rājan vijahārāsinā śiraḥ|
mṛtam anyo mahārāja padā tāḍitavāṃs tadā|| // 8-19-38 //
（38）王よ、倒れる者の首を別の者が剣で切り落としました。大王よ、別の者は死体を足で蹴りました。
jīvataś ca tathaiva anyaḥ śastraṃ kāye nyamajjayat|
muṣṭiyuddhaṃ mahac cāsīd yodhānāṃ tatra bhārata|
tathā keśagrahaścogro bāhuyuddhaṃ ca bhairavam|| // 8-19-39 //
（39）まだ生きている者の体に別の者が武器を突き刺しました。バーラタよ、その場で拳による殴り合い、恐ろしい髪の掴み合い、腕による格闘が行われました。
samāsaktasya cānyena avijñātas tathā'paraḥ|
jahāra samare prāṇān nānāśastair anekadhā|| // 8-19-40 //
（40）一人の者と組み合っている間に、気づかれぬうちに別の者が、さまざまな武器で命を奪いました。
saṃsakteṣu ca yodheṣu vartamāne ca saṅkule|
kabandhāny utthitāni syuḥ śataśo'tha sahasraśaḥ|| // 8-19-41 //
（41）戦士たちが入り乱れ、混乱が起こる中、首なしの胴体（カバンダ）が何百何千と立ち上がりました。
śoṇitaiḥ sicyamānāni śastrāṇi kavacāni ca|
mahārāgānuraktāni vastrāṇi iva cakāśire|| // 8-19-42 //
（42）血に浸された武器や鎧は、深紅に染まった衣服のように輝きました。
evam etan mahad yuddhaṃ dāruṇaṃ śastrasaṅkulam|
unmattagaṅgāpratimaṃ śabdena āpūrayaj jagat|| // 8-19-43 //
（43）このようにこの大いなる恐ろしい武器の入り乱れた戦いは、暴れ狂うガンガー河のように、音で世界を満たしました。
naiva sve na pare rājan vijñāyante śarāturāḥ|
yoddhavyam iti yudhyante rājāno jayagṛddhinaḥ|| // 8-19-44 //
（44）王よ、矢に苦しむ味方も敵も区別がつかず、勝利を望む王たちは「戦わねばならない」と戦い続けました。
svān sve jaghnur maharāja parāṃś caiva samāgatān|
ubhayoḥ senayor vīrair vyākulaṃ samapadyata|| // 8-19-45 //
（45）大王よ、味方が味方を、集まった敵をも殺し、両軍の勇者たちの間に混乱が生じました。
rathairbhagnairmahārāja vāraṇaiś ca nipātitaiḥ|
hayaiś ca patitais tatra naraiś ca vinipātitaiḥ||
agamyarūpā pṛthivī kṣaṇena samapadyata|
kṣaṇenāsīn mahīpāla kṣatajaughapravartinī|| // 8-19-46-47 //
（46〜47）大王よ、壊れた戦車、倒された象、倒れた馬、打ち倒された人で、大地は一瞬にして通行不能となりました。一瞬にして、王よ、血の奔流が流れ出しました。
pāñcālān ahatat karṇas trigartāṃś ca dhanañjayaḥ|
bhīmasenaḥ kurūn rājan hastyanīkaṃ ca sarvaśaḥ|| // 8-19-48 //
（48）カルナはパーンチャーラ族を打ち、ダナンジャヤ（アルジュナ）はトリガルタ族を、ビーマセーナは王よ、クル族と象軍をあらゆる方面から打ちました。
evameṣa kṣayo vṛttaḥ kurupāṇḍavasenayoḥ|
aparāhṇe gate sūrye kāṅkṣatāṃ vipulaṃ yaśaḥ|| || // 8-19-49 //
（49）このようにして、クル族とパーンダヴァの両軍の消耗は、太陽が午後に傾く中、大いなる栄誉を求める者たちの間で起こりました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe ekonaviṃśo'dhyāyaḥ|| 19 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十九章は終わる。
