マハーバーラタ ― カルナ篇 第35章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 35 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ35」（シャルヤが、白鳥に飛行の技を自慢して挑戦し惨敗する烏の寓話を語り、カルナの傲慢と過去の失態―ドヴァイタ林でガンダルヴァに敗走したこと、ヴィラータ王城で逃げたことなど―を痛烈に指摘し、アルジュナ・クリシュナの真の実力を侮るなと諭す場面）です。原典の8-35-33詩節は3パダ（通常より長い1詩節）であり、和訳ではこれを第33段落・第34段落の2つに分けて訳しているため、和訳第35段落以降は原典の詩節番号より和訳の段落番号が1つ大きくなります（例：和訳第87段落＝原典第86詩節）。表示する詩節番号は常に原典の正しい番号です。
karṇaparva — pañcatriṃśo'dhyāyaḥ (35)
第35章
sañjaya uvāca|
māriṣādhiratheḥ śrutvā vāco yuddhābhinandinaḥ|
śalyo'bravīt punaḥ karṇaṃ nidarśanamudāharan|| // 8-35-1 //
サンジャヤは語った。 （1）戦いを喜ぶカルナの言葉を聞いて、シャルヤは再びカルナに、例え話として言った。
jāto'haṃ yajvanāṃ vaṃśe saṅgrāmeṣv anivartinām|
rājñāṃ mūrdhābhiṣiktānāṃ svayaṃ dharmaparāyaṇaḥ|| // 8-35-2 //
シャルヤは語った。 （2）「私は祭祀を行う王の家系、退却せぬ戦士の、自ら正しい道に専念する、灌頂された王の家に生まれた。
yathaiva matto madyena tvaṃ tathā lakṣyase vṛṣa|
tathā'dya tvāṃ pramādyantaṃ cikitseyaṃ suhṛttayā|| // 8-35-3 //
（3）酒に酔った者のように、お前はそう見える、雄々しき者よ。今日、お前が迷うのを、友情のゆえに治そうとしているのだ。
imāṃ kākopamāṃ karṇa procyamānāṃ nibodha me|
śrutvā yatheṣṭaṃ kuryās tvaṃ nihīna kulapāṃsana|| // 8-35-4 //
（4）カルナよ、私の語るこのカラスの例え話を聞け。聞いたら好きなようにせよ、卑しい家を汚す者よ。
nāhamātmani kiñcid vai kilbiṣaṃ karṇa saṃsmare|
yena māṃ tvaṃ mahābāho hantum iccasyanāgasam|| // 8-35-5 //
（5）カルナよ、私は自分の中に、お前から討たれるに値する何の罪も思い起こさぬ。それなのに、長き腕の者よ、お前は罪のない私を討とうとしている。
avaśyaṃ tu mayā vācyaṃ buddhvā tava hitāhitam|
viśeṣato rathasthena rājñaś caiva hitaiṣiṇā|| // 8-35-6 //
（6）しかし、私は必ず、お前のためになるかならぬかを考えて、語らねばならぬ。特に御者として、また王を思う者として。
samaṃ ca viṣamaṃ caiva rathinaś ca balābalam|
śramaḥ khedaś ca satataṃ hayānāṃ rathinā saha|| // 8-35-7 //
（7）平地と険路、戦車戦士とその強弱、馬の疲れや苦しみ、戦車戦士と――。
āyudhasya parijñānaṃ rutaṃ ca mṛgapakṣiṇām|
sāraṃ caiva apy āsaraṃ ca śalyānāṃ ca pratikriyā|| // 8-35-8 //
（8）武器の知識、獣や鳥の鳴き声、矢の鋭さと強さ、矢傷の手当て――。
astrayogaṃ ca yuddhaṃ ca nimittāni tathaiva ca|
sarvametanmayā jñeyaṃ rathasyāsya kuṭumbinā|
atas tvāṃ kathaye karṇa nidarśanamidaṃ punaḥ|| // 8-35-9 //
（9）武器の用法、戦い、前兆――これらすべてを、この戦車の責任者たる私が知るべきだ。ゆえに、カルナよ、ふたたびこの例え話をお前に語ろう。
vaiśyaḥ kila samudrānte prabhūtadhanadhānyavān|
yajvā dānapatiḥ kṣāntaḥ svakarmastho'bhavac chuciḥ|| // 8-35-10 //
（10）かつて、海辺に財産と穀物に富んだヴァイシャがいた。祭祀を行い、施し、忍耐強く、自分の義務に従い、清らかな者だった。
bahuputraḥ priyāpatyaḥ sarvabhūtānukampakaḥ|
rājño dharmapradhānasya rāṣṭre vasati nirbhayaḥ|| // 8-35-11 //
（11）多くの息子を持ち、子どもを愛し、すべての生き物に憐れみを持つ彼は、正義を第一とする王の国に、恐れなく住んでいた。
putrāṇāṃ tasya bālānāṃ kumārāṇāṃ yaśasvinām|
kāko bahūnām abhavad ucchiṣṭakṛtabhojanaḥ|| // 8-35-12 //
（12）その若く、名高い息子たちには、彼らの食の残りを食べる一羽のカラスがいた。
tasmai sadā prayacchanti vaiśyaputrāḥ kumārakāḥ|
māṃsodanaṃ dadhi kṣīraṃ pāyasaṃ madhusarpiṣī|| // 8-35-13 //
（13）ヴァイシャの若い息子たちは、彼に、肉飯、ヨーグルト、牛乳、菓子、蜂蜜、バター油を与えた。
sa cocchiṣṭabhṛtaḥ kāko vaiśyaputraiḥ kumārakaiḥ|
sadṛśān pakṣiṇo dṛptaḥ śreyasas ca avamanyate|| // 8-35-14 //
（14）残り物で育ったそのカラスは、ヴァイシャの息子たちに甘やかされて、自分と同等の鳥たちや、さらに優れた鳥たちまでも見下すようになった。
atha haṃsāḥ samudrānte prajagmuratipātinaḥ|
garuḍasya gatau tulyāś cakrāṅgā hṛṣṭacetasaḥ|| // 8-35-15 //
（15）あるとき、白鳥たちが海辺にやって来た。ガルダに等しい飛翔をする、素早い、美しい翼を持つ、喜びに満ちた白鳥たちが。
kumārakās tadā haṃsān dṛṣṭvā kākam atha abruvan|
bhavān eva viśiṣṭo'si patatribhyo vihaṅgama|| // 8-35-16 //
（16）子どもたちは白鳥を見て、カラスに言った。『あなたこそ、鳥の中で最も優れている、鳥よ。
ete'tipātinaḥ paśya vihaṅgān viyadāśritān|
ehi tvamapi śakto hi kasmān na patitaṃ tvayā|| // 8-35-17 //
（17）この空を飛ぶ、遠くまで飛べる鳥たちを見よ。お前もできるはずだ、来いよ、なぜお前は飛ばないのだ？』。
pratāryamāṇas taiḥ sarvairalpabuddhibhir araṇḍajaḥ|
tadvacaḥ satyamityeva maurkhyād darpāc ca jajñivān|| // 8-35-18 //
（18）〔そう言われて〕小さな思慮しかないカラスは、愚かさと傲慢のあまり、彼らの言葉を真に受けてしまった。
tān sonupatya jijñāsuḥ ka eṣāṃ śreṣṭhabhāgiti|
ucchiṣṭadarpitaḥ kāko bahūnām ekapātinām|| // 8-35-19 //
（19）彼らの中で誰が最も優れているかを試そうと、残り物で傲慢になったカラスは、多くの遠距離飛行者たちの中へと飛び立った。
teṣāṃ yaṃ pravaraṃ mene haṃsānāṃ dūrapātinām|
sa tamāhvata durbuddhiḥ patāva iti pakṣiṇam|
tac chrutvā prāhasan haṃsā ye tatrāsan samāgatāḥ|| // 8-35-20 //
（20）遠くを飛ぶ白鳥たちの中で最も優れていると思った者に向かって、その愚かなカラスは『一緒に飛ぼう』と呼びかけた。それを聞いて、そこに集った白鳥たちは笑った。
bhāṣato bahu kākasya bāliśyāt patatāṃ varāḥ|
idam ūcuḥ sma cakrāṅgā vacaḥ kākaṃ viṅgamāḥ|| // 8-35-21 //
（21）カラスが多く語る愚かさに、白鳥たちは、美しい翼の鳥たちはカラスに次の言葉を語った。
haṃsā ūcuḥ|
vayaṃ haṃsāś carāma imāṃ pṛthivīṃ mānasaukasaḥ|
pakṣiṇāṃ ca vayaṃ nityaṃ dūrapātena pūjitāḥ|| // 8-35-22 //
白鳥たちは語った。 （22）『我らは白鳥、マーナサ湖に住み、この地上を巡る。鳥の中で、常に遠くまで飛べる者として敬われている。
kathaṃ haṃsaṃ nu balinaṃ cakrāṅgaṃ dūrapātinam|
kāko bhūtvā nipatane samāhvayasi durmate|
kathaṃ tvaṃ patitā kāka saha asmābhir bravīhi tat|| // 8-35-23 //
（23）どうして、強き白鳥、美しく遠くまで飛ぶ我らを、お前はカラスでありながら、飛翔に呼ぶのか、愚か者よ。どのようにお前は我らと共に飛ぶのか、それを言え、カラスよ』。
atha haṃsavaco mūḍhaḥ kutsayitvā punaḥ punaḥ|
prajagādottaraṃ kākaḥ katthano jātilāghavāt|| // 8-35-24 //
（24）〔そこで愚かなカラスは、白鳥の言葉を何度も侮辱し、低俗な性質ゆえに自讃しながら、答えを述べた〕
kāka uvāca|
śatam ekaṃ ca pātānāṃ patitā'smi na saṃśayaḥ|
śatayojanamekaikaṃ vicitraṃ vividhaṃ tathā|| // 8-35-25 //
カラスは語った。 （25）『私は百一種類の飛び方で飛べる、疑いなく。一つひとつ百ヨージャナ、それぞれ異なる、多彩な飛翔だ。
uḍḍīnamavaḍīnaṃ ca praḍīnaṃ ḍīnameva ca|
niḍīnamatha saṃḍīnaṃ tiryakḍīnagatāni ca|| // 8-35-26 //
（26）ウッディーナ、アヴァディーナ、プラディーナ、ディーナ、ニディーナ、サンディーナ、横向き飛び――。
viḍīnaṃ pariḍīnaṃ ca parāḍīnaṃ suḍīnakam|
abhiḍīnaṃ mahāḍīnaṃ nirḍīnamatiḍīnakam|| // 8-35-27 //
（27）ヴィディーナ、パリディーナ、パラーディーナ、スディーナカ、アビディーナ、マハーディーナ、ニルディーナ、アティディーナ――。
avaḍīnaṃ praḍīnaṃ ca saṃḍīnaṃ ḍīnaḍīnakam|
saṃḍīnoḍḍīnaḍīnaṃ ca punarḍīnaviḍīnakam|| // 8-35-28 //
（28）アヴァディーナ、プラディーナ、サンディーナ、ディーナディーナ、サンディーナとウッディーナ、ふたたびディーナとヴィディーナ――。
saṃpātaṃ samudīṣaṃ ca tato'nyad vyatiriktakam|
gatāgataṃ pratigataṃ bahvīś ca nikulīnakāḥ|
kartā'smi miṣatāṃ vo'dya tato drakṣayatha me balam|| // 8-35-29 //
（29）サムパータ、サムディーサ、そしてその他いろいろな、行って帰る、帰ってまた行く、たくさんのニクリーナ――。これらを、お前たちの目の前で、今日私がやってみせよう。ゆえに、私の力を見よ。
teṣām anyatamena aham patiṣyāmi vihāyasam|
pradiśadhvaṃ yathānyāyaṃ kena haṃsāḥ patāmy aham|| // 8-35-30 //
（30）これらのどれで飛ぼうか、空を。正しく指し示せ、白鳥たちよ、どれで飛ぼうか。
te vai dhruvaṃ viniścitya sampatadhvaṃ mayā saha|
pātairebhiḥ khalu khagāḥ patituṃ khe nirāśraye|| // 8-35-31 //
（31）お前たちは確かに選んでから、私と一緒に飛べ。これらの飛び方で、依る所のない空を飛ぶのだ』。
evamukte tu kākena prahasyaiko vihaṃgamaḥ|
uvāca kākaṃ rādheya vacanaṃ tannibodha me|| // 8-35-32 //
（32）このようにカラスが言うと、一羽の鳥が笑ってカラスに言った。カルナよ、その言葉を聞け。
haṃsa uvāca|
śatam ekaṃ ca pātānāṃ tvaṃ kāka patitā dhruvam|
ekameva tu yaṃ pātaṃ viduḥ sarve vihaṅgamāḥ|
tamahaṃ patitā kāka na anyaṃ jānāmi kañcana|| // 8-35-33 //
白鳥は語った。 （33〜34）『たしかにカラスよ、お前は百一種類の飛び方ができるだろう。だが、すべての鳥が知る、ただ一つの飛び方、それしか私は知らぬ。その一つで、私は飛ぶ。他は知らぬ』。
kāka uvāca|
pata tvamapi tatra āśu yena pātena manyase|| // 8-35-34 //
カラスは語った。 （35）『お前もそのお前が知る飛び方で、すぐに飛んでみよ』。
atha kākaṃ prajahasurye tatrāsan samāgatāḥ|
katham ekena pātena haṃsaḥ pātaśataṃ jayet|
ekena vāyasa tvā enaṃ pātena abhibhaviṣyati|| // 8-35-35 //
（36）そして、そこに集まっていた者たちはカラスを笑った。『どうして一つの飛び方で、白鳥が百の飛び方に勝てるのか。一つでも、カラスは白鳥を負かすだろう』。
haṃsaś ca utpatitaḥ kāko balavān āśuvikramaḥ|
prapetatuḥ spardhayā ca tatas tau haṃsavāyasau|
uparyupari vegena samudraṃ makarālayam|| // 8-35-36 //
（37）〔そうして競争が始まる〕白鳥は飛び立ち、力ある素早いカラスも飛び立った。二羽は競いながら、海――ワニのすみかの上を、勢いよく上へ上へと飛んだ。
haṃsas tu ekena pātena kākaḥ pātaśatena ca|
spardhinau sahitau tūrṇaṃ khamāsthāya tarasvinau|| // 8-35-37 //
（38）白鳥は一つの飛び方で、カラスは百一の飛び方で、競い合いながら共に空へと飛び立った。
haṃsas tu mṛdunā ekena vikrāntumupacakrame|
pūrvameva tu vai kākaḥ sa taṃ tūrṇaṃ pracakrame|| // 8-35-38 //
（39）白鳥は優しくひとつのやり方でゆっくり進み始めた。先にカラスの方が素早く飛んでいた。
na atyahīyata kākaś ca muhūrtam iva sūtaja|| // 8-35-39 //
（40）カラスは一瞬たりとも白鳥から遅れをとらなかった。
kākopi haṃsaṃ ca āpalyāc chīghratāṃ pratidarśayan|
vegena atītya tarasā punareti muhurmuhuḥ|| // 8-35-40 //
（41）カラスは、白鳥に自分の素早さを見せつけようと、勢いよく追い越しては、何度も戻ってきた。
tuṇḍena abhyahanac ca enaṃ kurvan nāma apasavyataḥ|
rorūyan iva ca apy enaṃ samāhvayati vai muhuḥ|
visismāpayiṣuḥ pātair darśayan ātmanaḥ kriyām|| // 8-35-41 //
（42）くちばしで白鳥を突き、左に回って挑発した。自分の飛び方で驚かせようとして、何度も呼びかけた。
atha tāni vicitrāṇi patitānītarāṇi ca|
dṛṣṭvā pramuditāḥ kākā vinedur adhikaiḥ svaraiḥ|| // 8-35-42 //
（43）その多彩な飛行やその他の動きを見て、カラスたち〔他の陸のカラス〕は喜んで、いっそう甲高い声で鳴いた。
haṃsāś ca apahasanti sma pravadanti priyāṇi ca|
kurvāṇā vividhān rāvān icchanto jayam ātmanaḥ|| // 8-35-43 //
（44）白鳥たちは笑い、愛らしいことを語った。さまざまな鳴き声を上げ、自分たちの勝利を望みながら。
utpatya utpatya ca prāhur muhūrtam iti ceti ca|
vṛkṣāgrebhyaḥ sthalebhyaś ca nipatanty utpatanti ca|| // 8-35-44 //
（45）飛び上がっては言い、「一瞬だ」と言い、木の頂や地面に降り立っては飛び上がった。
avamatya ca haṃsaṃ tam idaṃ kāko'bravīd vacaḥ|
yo'sāv utpatito haṃsaḥ so'sāv eva prahīyate|| // 8-35-45 //
（46）そして白鳥を軽蔑して、カラスはこう言った。『あそこに飛んだ白鳥は、今では置き去りになっている』。
atha haṃsastu tac chrutvā bhāṣitaṃ patatāṃ varaḥ|
vigāhya haṃso vikṣobhya prāpatat paścimāṃ diśam|| // 8-35-46 //
（47）白鳥は、鳥たちの中でも優れたその白鳥は、カラスの言葉を聞いて、海を突き抜け、西方へと飛んでいった。
uparyupari vegena sāgaraṃ makarālayam|
bahusatvasamākīrṇaṃ vīcībhir bhīmadarśanam|| // 8-35-47 //
（48）勢いよく上へ上へと、ワニのすみかである海の上を、多くの生き物に満ち、波によって恐ろしい姿を呈する海を。
athācireṇa rādheya kāko vegādahīyata|
tato'tīva pariśrāntaḥ kathañcid vaṃsam anvagāt|| // 8-35-48 //
（49）そしてまもなく、カルナよ、カラスは速度で遅れをとり始めた。ひどく疲れ果てて、どうにか白鳥について行くだけとなった。
bhīś ca enam āviśat tīvraṃ kākaṃ karṇa vicetasam|
dvīpān drumānvitān paśyan viśramārthaṃ śramāturaḥ|
nipateyaṃ kkanu śrānta iti tasmiñ jalārṇave|| // 8-35-49 //
（50）激しい恐怖がカラスに入り込んで、正気を失った。カルナよ、休む場所を求めて、水の海の中に木の繁る島を探しながら、『疲れた、どこに降りようか』と、この水の大海で思った。
avagāhya samudro'pi bahusatvagaṇālayaḥ|
mahān bhūtaśatodbhūsī nabhasas tu viśiṣyate|| // 8-35-50 //
（51）多くの生き物の群れ、巨大なる生物の集まる住処の海も、空とは異なる。
gāmbhīryārdvi samudrasya na viśeṣaṃ kulādhama|
diśaś ca na ambhasāṃ karṇa samudrasthā vidurjanāḥ|
vipaścitopy apāratvāt kiṃ punaḥ karṇa vāyasaḥ|| // 8-35-51 //
（52）海の深さは、家柄の卑しい者には分からぬ。カルナよ、海の中にいる者たちは、方向さえも知らぬ。賢者にもわからぬ――ましてやカラスはどうして分かるか。
atha haṃsopy atikrāman muhūrtam iva dūrataḥ|
atikramya ca cakrāṅgaḥ kākaṃ taṃ samudaikṣata|| // 8-35-52 //
（53）白鳥は、しばらくして、遠くを飛び続けていたが、やがて振り返ってカラスを見た。
śanakaiḥ parihīnaṃ taṃ pariśrāntam acetasam|
avekṣamāṇas taṃ kākaṃ pratyāgamya hasan iva|| // 8-35-53 //
（54）じわじわと遅れ、疲れ、正気を失いそうになっているカラスを見て、笑うように戻ってきた。
taṃ prahasya ca cakrāṅgaḥ kākaṃ mandagatiṃ tadā|
hīyamānam atho dṛṣṭvā haṃsaḥ prāha yathārthavat|
ujjihīrṣur nimajjantaṃ smaran satpuruṣavratam|| // 8-35-54 //
（55）笑いながら、白鳥は、ゆっくり歩む、遅れているカラスを見て、まことにふさわしい言葉を語った。沈もうとしている者を救うために、善き人の誓いを思い出して――。
bahūni patitāni tvamācakṣāṇo muhurmuhuḥ|
patasy avyāharan khedaṃ tato garhyaṃ prabhāṣase|| // 8-35-55 //
（56）『「たくさんの飛び方がある」と何度も言いながら、疲れを言葉に出さず、恥ずべきことを言っている。
jalaṃ nāma patitaṃ kāka yattvaṃ patasi sāmpratam|
jalaṃ spṛśasi pakṣābhyāṃ tuṇḍena ca punaḥ punaḥ|| // 8-35-56 //
（57）「水」という飛び方――それこそがお前の今している飛び方だ、カラスよ。お前は翼とくちばしで水を触っている、何度も。
prabrūhi katamo'yaṃ te pāto vartati vāyasa|
ehyehi kāka śīghraṃ tvameṣa tvāṃ paripālaye|| // 8-35-57 //
（58）どの飛び方をしているのか、言ってみろ、カラスよ。来い、来い、カラスよ、早く、私がお前を助けてやる』。
sa pakṣābhyāṃ spṛśan ārtas tuṇḍena ca jalaṃ tadā|
kāko dṛḍhaṃ pariśrāntaḥ sahasā nipapāta ha|| // 8-35-58 //
（59）翼とくちばしで水に触れながら苦しみ、ひどく疲れ果てたカラスは、突然落ちた。
sāgarāmbhasi taṃ dṛṣṭvā patatantaṃ dīnacetasam|
mriyamāṇamidaṃ vākyaṃ haṃsaḥ kākam uvāca ha|| // 8-35-59 //
（60）海の水に落ちて、絶望の心で、死にそうなカラスに、白鳥はこう言った。
śatam ekaṃ ca pātānāṃ patāmy aham iti sma ha|
ślāghan ātmānam adya tvaṃ kāka bhāṣitavānasi|| // 8-35-60 //
（61）『「私は百一の飛び方で飛ぶ」と、自らを誇って、今日お前は語った、カラスよ。
sa tvamekaśataṃ pātaṃ patan abhyadhiko mayā|
katham evaṃ pariśrāntaḥ patito'si mahārṇave|| // 8-35-61 //
（62）百一の飛び方をする、私よりも上等なはずのお前が、どうしてこのように疲れ果て、大海に落ちたのか』。
pratyuvāca tataḥ kākaḥ sīdamāna idaṃ vacaḥ|
uparītaṃ tadā haṃsaṃ prasamīkṣya prasādayan|| // 8-35-62 //
（63）そこで沈みながらカラスは答えた。上にいる白鳥を見て、救いを求めながら――。
ucchiṣṭānnena puṣṭo'haṃ darpotsiktaḥ kusatvataḥ|
suparṇa iva cātmānaṃ jñātavān putralāghavāt|| // 8-35-63 //
カラスは語った。 （64）『残り物で太った私は、傲慢に膨れ上がり、自分を鳥王ガルダと思い込んでいた。自分の軽さのゆえに。
śaraṇaṃ tvāṃ prapanno'ham udakāntam avāpnuyām|
haṃsa idānīṃ pariśrāntam āpado māṃ samudvara|| // 8-35-64 //
（65）あなたに庇護を求めます。水の端に達するまで助けてください。白鳥よ、疲れ果てたこの危機から、私を救ってください。
yadi nāma punar jīvan gaccheyaṃ svaṃ niveśanam|
na enaṃ punar hīnam api kṣeptā'haṃ khe vicāriṇam|| // 8-35-65 //
（66）もし生きて自分の家に戻れたら、二度と自分よりも下の者をも、空を飛ぶ者を侮辱しません』。
tamevaṃ karuṇaṃ dīnaṃ vilapantam acetasam|
kākakāketi vāśantaṃ nimajjantaṃ mahārṇave|
kṛpayā'bhiparīto vai kṛpāṃ cakre durātmani|| // 8-35-66 //
（67）そのように哀れにも悲嘆にくれ、「カラス、カラス」と叫び、沈みゆくカラスを、哀れみに満たされて、白鳥は邪悪なその者に慈悲をかけた。
atha taṃ patataṃ dīnaṃ jalaklinnam acetanam|
padbhyām utkṣipya vepantaṃ pṛṣṭham āropayat tadā|| // 8-35-67 //
（68）そして落ちて哀れに、水に濡れて気を失い、震えるカラスを、両足で引き上げ、背中に乗せた。
sa haṃsaḥ pṛṣṭham āropya kākaṃ karṇa vicetasam|
avismayaṃs tadā karṇa punareva samānayat|
tameva deśaṃ tarasā spardhayā petaturyataḥ|| // 8-35-68 //
（69）白鳥は、正気を失ったカラスを背に乗せて、カルナよ、驚かずに、もとの場所へと連れ戻した、二羽が競って飛び立った場所へと。
utsṛjya tva abravīn mā evaṃ punaḥ kāryaṃ tvayeti ha|
sthāpya cainaṃ punardvīpe samāśvasya ca viklavam|
gato yathepsitaṃ deśaṃ haṃso mana ivāśugaḥ|| // 8-35-69 //
（70）そして彼を降ろして、『もう二度とこのようなことはするな』と言い、島に置いて、怯えた彼を安ませてから、望みの場所へと、白鳥は心のように素早く去っていった。
evamucchiṣṭapuṣṭaḥ sa kāko'haṃsaparājitaḥ|
balaṃ vīryaṃ mahat karṇa tyaktvā kṣāntim upāgataḥ|| // 8-35-70 //
（71）このように、残り物で太ったカラスは、白鳥に敗れ、力と勇気を捨て、忍耐するようになった。
ucchiṣṭabhojanaḥ kāko yathā vaiśyakule purā|
evaṃ tvam ucchiṣṭabhṛto dhārtarāṣṭrair na saṃśayaḥ|| // 8-35-71 //
（72）かつてヴァイシャの家で残り物を食べるカラスのように、お前もドリタラーシュトラ族に養われた残り物食いにすぎぬ、疑いなく。
sadṛśāñ śreyasaś ca api sarvān karṇa avamanyase|
droṇadrauṇikṛpair gupto bhīṣmeṇa anyaiś ca kauravaiḥ|| // 8-35-72 //
（73）自分と同等の者、自分より優れた者すべてを、お前は見下すのだ、カルナよ。ドローナ、アシュヴァッターマン、クリパ、ビーシュマ、その他のクル族によって守られながら。
virāṭanagare pārtham ekaṃ kiṃ na avadhīs tadā|
yatra vyastāḥ samastāś ca nirjitāḥ stha kirīṭinā sṛgālā iva siṃhena kva te vīryaṃ tadā gatam|| // 8-35-73 //
（74）ヴィラータの都市で、たった一人のアルジュナを、なぜあのとき討たなかったのか。そこで分散しても集まっても、アルジュナに打ち負かされた。ジャッカルが獅子に負けるように。あのときお前の武勇はどこへ行ったのか。
bhrātaraṃ nihataṃ dṛṣṭvā samare savyasācinā|
paśyatāṃ kuravīrāṇāṃ prathamaṃ tvaṃ palāyitaḥ|| // 8-35-74 //
（75）兄弟（ヴィカルナ）が戦場でアルジュナに討たれるのを見て、クル族の勇者たちが見ている前で、真っ先に逃げたではないか。
tathā dvaitavane karṇa gandharvaiḥ samabhidrutān|
kurūn sadārān utsṛjya tvam eva agre palāyitaḥ|| // 8-35-75 //
（76）同様に、ドヴァイタの森で、カルナよ、ガンダルヴァたちに襲われて、妻を連れたクル族を見捨て、お前が先頭を切って逃げた。
hatvā jitvā ca gandharvāṃś citrasenamukhān raṇe|
karṇa duryodhanaṃ pārthaḥ sabhrātṛkamamokṣayat|| // 8-35-76 //
（77）ガンダルヴァたち、チトラセーナ率いる者たちを戦場で討ち、また勝って、アルジュナが兄弟と共にあるドゥルヨーダナを解放したのだ、カルナよ。
punaḥ prabhāvaḥ pārthasya purāṇaḥ keśavasya ca|
kathitaḥ karṇa rāmeṇa sabhāyāṃ kurusaṃsadi|| // 8-35-77 //
（78）アルジュナとケーシャヴァ（クリシュナ）の昔からの威力は、ラーマ（バララーマ）によって、クル族の会議の場で語られた、カルナよ。
satataṃ ca tvam aśrauṣīr vacanaṃ droṇabhīṣmayoḥ|
avadhyau vadatoḥ kṛṣṇau sannidhau ca mahīkṣitām|| // 8-35-78 //
（79）お前はドローナとビーシュマの言葉を常に聞いてきた。『二人のクリシュナは討てぬ』と語る、王たちの前での言葉を。
kiyantaṃ tatra vakṣyāmi yena yena dhanañjayaḥ|
tvatto'tiriktaḥ sarvebhyo bhūtebhyo brāhmaṇo yathā|| // 8-35-79 //
（80）何を多く語ろうか。アルジュナが優れていることは、お前よりも全ての生き物よりも、バラモンが他のすべての者より優れているように、明らかだ。
idānīm eva draṣṭāsi pradhāne syandane sthitau|
putraṃ ca vasudevasya kuntīputraṃ ca pāṇḍavam|| // 8-35-80 //
（81）今まさに、お前は見ることになる。最高の戦車に乗った、ヴァースデーヴァの息子（クリシュナ）とクンティーの子（アルジュナ）を。
yathā'śrayata cakrāṅgaṃ vāyaso buddhim āsthitaḥ|
tathā āśrayasva vārṣṇeyaṃ pāṇḍavaṃ ca dhanañjayam|| // 8-35-81 //
（82）白鳥を頼って、カラスが賢明な思慮に立ち返ったように、ヴリシュニ族のクリシュナとパーンダヴァのアルジュナを頼みとせよ。
yadā tvaṃ yudhi vikrāntau vāsudevadhanañjayau|
draṣṭāsy ekarathe karṇa tadā na evaṃ vadiṣyasi|| // 8-35-82 //
（83）戦場で勇ましき二人、ヴァースデーヴァとアルジュナが、一つの戦車に乗っているのを見るとき、カルナよ、もはやそのようなことを言うまい。
yadā śaraśataiḥ pārtho darpaṃ tava vadhiṣyati|
tadā tvam antaraṃ draṣṭā ātmanaś ca arjunasya ca|| // 8-35-83 //
（84）アルジュナが百の矢でお前の傲慢を打ち砕くとき、そのときお前は、自分とアルジュナとの差を知るだろう。
devāsuramanuṣyeṣu prakhyātau yau narottamau|
tau mā avamaṃsthā maurkhyāt tvaṃ svadyota iva rocanau|| // 8-35-84 //
（85）神・アスラ・人間の間で名高い、人中の二人の優者を愚かに見下すな、自分の微光で輝く者たちを蛍のように。
sūryācandramasau yadvat tadvad arjunakeśavau|
prakāśyena abhivikhyātau tvaṃ tu khadyotavan nṛṣu|| // 8-35-85 //
（86）太陽と月のごとく、アルジュナとケーシャヴァは輝いて名高い。一方お前は、人々の中で蛍のごときもの。
evaṃ vidvan mā avamaṃsthāḥ sūtaputra acyutārjunau|
narasiṃhau naraśvā tvaṃ joṣam āssva vikatthase|| || // 8-35-86 //
（87）このように、賢者よ、御者の子よ、不滅のクリシュナとアルジュナを見下すな。人中の獅子のごとき二人に――お前は人の犬にすぎぬ。黙って、自讃するな」。
iti śrīmanmahābhārate karṇaparvaṇi pañcatriṃśo'dhyāyaḥ|| 35 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十五章は終わる。
