マハーバーラタ ― カルナ篇 第65章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 65 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ65」、全38詩節からなり、前章（第64章）の流れを受けてアルジュナが白馬の戦車で到着する場面（第1〜2詩節）から始まります。ドゥルヨーダナがユダーマンユとウッタマウジャスに攻撃をかける場面（第3〜6詩節）、各戦士がユダーマンユを護衛する場面（第7〜16詩節）、カルナがユダーマンユに矢の雨を浴びせてパーンダヴァ軍を圧倒する場面（第17〜28詩節）、ユダーマンユが撤退を余儀なくされる場面（第29〜35詩節）、ダールタラーシュトラ側が「捕まえろ！」と叫ぶ場面（第36詩節）、ケーカヤ族の戦士たちが行く手を阻む場面（第37詩節）、そしてドゥルヨーダナとビーマの遭遇（第38詩節）で本章は終わります。第21詩節の「mūtaputra」は原典の「sūtaputra」のOCR誤記と判断し修正しています。
karṇaparva — pañcaṣaṣṭitamo'dhyāyaḥ (65)
第65章
sañjaya uvāca|
tataḥ śvetāśvasaṃyukte nārāyaṇasamāhite|
tiṣṭhan rathavare śrīmān arjunaḥ samapadyata||
// 8-65-1 //
栄光あるアルジュナは、白馬に引かれナーラーヤナ（クリシュナ）に守られた最高の戦車に立って現れた。
tadbalaṃ nṛpatiśreṣṭha tāvakaṃ vijayo raṇe|
vyakṣobhayad udīrṇāśvaṃ mahodadhim iva ānilaḥ||
// 8-65-2 //
王中の最高者よ、ヴィジャヤ（アルジュナ）は戦場でおまえの軍を、馬を奮い立たせながら掻き乱した。大風が大海をかき乱すように。
duryodhanastava sutaḥ pramatte śvetavāhane|
abhyetya sahasā kruddhaḥ sainyārdhena abhisaṃvṛtaḥ||
// 8-65-3 //
白馬のアルジュナが他所で戦っている間に、おまえの息子ドゥルヨーダナは軍の半分を率いて突然怒りをもって近づいた。
paryavārayad āyāntaṃ yudhiṣṭhiramamarṣaṇam|
kṣuraprāṇāṃ trisaptatyā tato 'vidhyata pāṇḍavam||
// 8-65-4 //
やってくるユディシュティラを取り囲み、七十三本の剃刀の矢でパーンダヴァを射た。
akrudhyata bhṛśaṃ tatra kuntīputro yudhiṣṭhiraḥ|
sa bhallāṃs triṃśatas tūrṇaṃ tava putre nyaveśayat||
// 8-65-5 //
クンティーの子ユディシュティラはそこで激しく怒り、おまえの息子に三十本の矢を速やかに突き刺した。
tato dhāvanta kauravyā jighṛkṣanto yudhiṣṭhiram||
// 8-65-6 //
するとカウラヴァ族がユディシュティラを捕らえようと駆けてきた。
duṣṭabhāvān parān jñātvā samavetā mahārathāḥ|
ājagmustaṃ parīpsantaḥ kuntīputraṃ yudhiṣṭhiram||
// 8-65-7 //
敵の邪悪な意図を知った大戦車戦士たちは集まって、クンティーの子ユディシュティラを守ろうとやってきた。
'sañjaya uvāca|
yudhiṣṭhiraś citrasenaṃ śaravarṣair avākirat|
citrasenas tu kaunteyaṃ saṅkruddhaḥ samavārayat||
// 8-65-8 //
ユディシュティラはチトラセーナに矢の雨を浴びせ、チトラセーナも怒ってカウンテーヤ（ユディシュティラ）を阻止した。
muhūrtādvimukhīkṛtya citrasenaṃ sa dharmarāṭ|
tāvakaṃ sainyam abhyaghnatsamantān niśitaiḥ śaraiḥ||
// 8-65-9 //
ほんの一瞬でチトラセーナを退けたダルマ王（ユディシュティラ）は、鋭い矢で四方からおまえの軍を打った。
tāvakā hi mābāho duryodhanapurogamāḥ|
yudhiṣṭhiraṃ jighṛkṣantaḥ sarvasainyaṃ samākṣipan||
// 8-65-10 //
大腕よ、ドゥルヨーダナを先頭とするおまえの者たちは、ユディシュティラを捕らえようと全軍を動かした。
dṛṣṭaprabhāvāṃs tān matvā samavetān mahārathān|
ājagmuḥ samparīpsantaḥ pāṇḍaveyaṃ yudhiṣṭhiram'||
// 8-65-11 //
武勇で名高い大戦車戦士たちが集結し、パーンダヴァのユディシュティラを守ろうとやってきた。
nakulaḥ sahadevaś ca dhṛṣṭadyumnaś ca pārṣataḥ|
akṣauhiṇyā parivṛtāste 'bhyadhāvan yudhiṣṭhiram||
// 8-65-12 //
ナクラ、サハデーヴァ、パールシャタ・ドリシュタデュムナが、一個のアクシャウヒニーに囲まれてユディシュティラのもとに駆けつけた。
bhīmasenaś ca nārācair mṛdraṃs tava mahārathān|
abhyadhāvad abhiprepsū rājānaṃ śatrubhir vṛtam||
// 8-65-13 //
ビーマセーナも鉄矢でおまえの大戦車戦士たちを蹴散らしながら、敵に囲まれた王を救おうと駆けつけた。
tāṃs tu sarvān maheṣvāsān karṇo vaikartano vṛṣā|
śaravarṣeṇa mahatā pratyavārayad āgatān||
// 8-65-14 //
しかし勇敢なヴァイカルタナ・ヴリシャ・カルナは、やってきた大弓の戦士たち全てを、大いなる矢の雨で阻止した。
śaraughān visṛjantas te preyantaś ca kuñjarān|
na śekur yatnavanto 'pi rādheyaṃ prativīkṣitum||
// 8-65-15 //
矢の群れを放ち象を駆りながらも、努力する彼らはラーデーヤ（カルナ）を見つめることすらできなかった。
tāṃś ca sarvān maheṣvāsānsarvaśastraviśāradān|
mahatā śaravarṣeṇa rādheyaḥ pratyavārayat||
// 8-65-16 //
あらゆる武器に通じた大弓の戦士たち全てを、ラーデーヤは大いなる矢の雨で阻んだ。
duryodhanaṃ ca viṃśatyā nārācānāṃ kṛtī balī|
avidhyat tūrṇam abhyetya sahadevo mahīpatim||
// 8-65-17 //
熟練し力強いサハデーヴァは速やかに近づき、二十本の鉄矢で国王ドゥルヨーダナを射た。
sa viddhaḥ sahadevena rarāja balasannidhau|
prabhinna iva mātaṅgo rudhireṇa pariplutaḥ||
// 8-65-18 //
サハデーヴァに射られたドゥルヨーダナは軍勢の中で輝いた。血にまみれ、こめかみを裂かれた象のように。
dṛṣṭvā tava sutaṃ tatra gāḍhaviddhaṃ sutejanaiḥ|
abhyadhāvad dṛḍhaṃ kruddho rādheyo rathināṃ varaḥ||
// 8-65-19 //
おまえの息子が深く鋭い矢に射られたのを見て、戦車戦士の中の最高者ラーデーヤ（カルナ）は激しく怒って駆けつけた。
duryodhanaṃ tathā dṛṣṭvā śīghram astram udīrya saḥ|
avadhīt pāṇḍavānīkaṃ pāñcālāṃś caiva māriṣa||
// 8-65-20 //
ドゥルヨーダナのその姿を見て、カルナは速やかに武器を発動し、パーンダヴァの軍とパーンチャーラ族を殺した。
tato yaudhiṣṭhiraṃ sainyaṃ vadhyamānaṃ mahātmanā|
sahasā prādrāvad rājan sūtaputraśarārditam||
// 8-65-21 //
王よ、ユディシュティラの軍は偉大なカルナに殺され、スータの子の矢に苦しめられて突然逃走した。
vividhā viśikhās tatra sampatanti parasparam|
bhallāḥ puṅkhasamāśliṣṭāḥ sūtaputradhanuścyutāḥ||
// 8-65-22 //
様々な矢が互いに飛び交い、羽のついた矢がスータの子の弓から放たれた。
antarikṣe śaraughāṇāṃ patatāṃ ca parasparam|
saṅgharpeṇa mahārāja pāvakaḥ samajāyata||
// 8-65-23 //
大王よ、空中で矢の群れが互いにぶつかり合い、その摩擦から火が生じた。
takato daśadiśaḥ karṇaḥ śalabhair iva yāyibhiḥ|
abhyaghnaṃs tarasā rājan śaraiḥ paraśarīragaiḥ||
// 8-65-24 //
王よ、カルナは十方をイナゴの群れのような飛び行く矢で覆い尽くし、敵の体を貫く矢で激しく打った。
raktacandanasandigdhau maṇihemavibhūṣitau|
bāhū vyatyakṣipat karṇaḥ paramāstraṃ vidarśayan||
// 8-65-25 //
赤い白檀を塗り、宝石と黄金で飾られた両腕を交互に動かし、カルナは最高の武器の術を見せつけた。
tataḥ sarvā diśo rājansāyakair vipramohayan|
apīḍayad bhṛśaṃ karṇo dharmarājaṃ yudhiṣṭhiram||
// 8-65-26 //
王よ、全方位を矢で幻惑しながら、カルナはダルマ王ユディシュティラを激しく苦しめた。
tataḥ kruddho mahārāja dharmaputro yudhiṣṭhiraḥ|
niśitair iṣubhiḥ karṇaṃ pañcāśadbhiḥ samārpayat||
// 8-65-27 //
大王よ、そこでダルマの子ユディシュティラは怒り、五十本の鋭い矢でカルナを射た。
bāṇāndhakāram abhavattadyuddhaṃ ghoradarśanam|
hāhākāro mahān āsīt tāvakānāṃ viśāmpate||
// 8-65-28 //
矢の暗闇が生じ、その戦いは恐ろしい光景であった。国の主よ、おまえの軍から大いなる悲嘆の声が上がった。
vadhyamāne tadā sainye dharmaputreṇa māriṣa|
sāyakair vividhais tīkṣṇaiḥ kaṅkapatraiḥ śilāśitaiḥ|
bhallairanekairvividhaiḥ śaktyṛṣṭimusalairapi||
// 8-65-29 //
ダルマの子が鷲の羽の石で研いだ鋭い様々な矢、矢、槍、棍棒でおまえの軍を殺しているとき、
yatra yatra sa dharmātmā duṣṭāṃ dṛṣṭiṃ vyasarjayat|
tatra tatra vyaśīryanta tāvakā bharatarṣabha||
// 8-65-30 //
バーラタの雄牛よ、ダルマの心を持つ者が厳しい目を向けたところ、そこそこでおまえの軍は崩れた。
karṇo'pi bhṛśasaṅkudro dharmarājaṃ yudhiṣṭhiram|
nārācair ardhacandraiś ca vatsadantaiś ca saṃyuge||
// 8-65-31 //
カルナも激しく怒り、ダルマ王ユディシュティラを鉄矢、半月矢、子牛の歯のような矢で、
amarṣī krodhanāś caiva roṣaprasphuritānanaḥ|
sāyakair aprameyātmā yudhiṣṭhiram abhidravat||
// 8-65-32 //
怒りに満ち、怒りに顔を震わせ、計り知れぬ精神をもって、矢でユディシュティラに突撃した。
yudhiṣṭhiraścāpi sa taṃ svarṇapuṅkhaiḥ śitaiḥ śaraiḥ||
// 8-65-33 //
ユディシュティラもまた黄金の羽の鋭い矢で彼を射た。
prahasan iva taṃ karṇaḥ kaṅkapatraiḥ śilāśitaiḥ|
urasy avidhyad rājānaṃ kuntīputraṃ yudhiṣṭhiram||
// 8-65-34 //
笑うかのようにカルナは鷲の羽の石で研いだ矢でクンティーの子ユディシュティラの胸を射た。
sa pīḍito bhṛśaṃ tena dharmarājo yudhiṣṭhiraḥ|
upaviśya rathopasthe sūtaṃ yāhīty anodayat||
// 8-65-35 //
カルナに激しく苦しめられたダルマ王ユディシュティラは、戦車の座席にくずおれ、御者に『行け』と命じた。
akrośanta tataḥ sarve dhārtarāṣṭrāḥ sarājakāḥ|
gṛhṇīdhvam iti rājānam abhyadhāvanta sarvaśaḥ||
// 8-65-36 //
ドリタラーシュトラの子たちは王と共に皆叫び、『捕らえよ』と四方から王に殺到した。
tataḥ śatāḥ saptadaśa kekayānāṃ prahāriṇām|
pañcālaiḥ sahitā rājan dhārtarāṣṭrān nyavārayan||
// 8-65-37 //
王よ、そこでケーカヤ族の攻撃的な千七百の戦士がパーンチャーラ族と共にドリタラーシュトラの子らを阻んだ。
tasmin sutumule yuddhe vartamāne janakṣaye|
duryodhanaś ca bhīmaś ca sameyātāṃ mahābalau||
// 8-65-38 //
その壮絶で多くの命を奪う戦いの中で、ドゥルヨーダナとビーマの二人の大力者が相まみえた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcaṣaṣṭitamo'dhyāyaḥ|| 65 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第65章終わり。
