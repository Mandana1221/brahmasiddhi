大学1年生のためのインド哲学入門

はじめての『認識の確定』第3章
――ダルマキールティと「説得すること」の論理学

第2章では、自分の心の中で推し量る「自分のための推論」を見ました。第3章のテーマは、それを言葉で他人に示して納得させる「他人のための推論」です。正しい主張とは何か。正しい理由とは何か。どんな理由が「まちがった理由」なのか。相手をどう批判すればよいのか。インドの討論の世界で磨かれてきた、論証と論破の技術を、ダルマキールティが体系的に整理します。原文の訳は載せずに、議論の中身を図と表、西洋哲学との比較でたどります。

　p.43 のような印は、校訂本（Hugon & Tomabechi 2011）の頁です。節の区分と番号（I、II.2.6 など）も同書の分析に従っています。第33偈 は第3章の偈の番号です。

西洋ではどうだった？ 古代ギリシアでも、討論の技術は哲学の中心でした。アリストテレスは『トピカ』で討論の型を、『詭弁論駁論』でまちがった論法の分類を論じています。インドでも、王の前などで学派どうしの公開討論が行われ、負ければ弟子を失ったり、改宗を迫られたりしました。第3章は、そうした本気の討論のための理論でもあるのです。

I他人のための推論とは：「自分が見た対象を明らかにする」

第1–5偈p.1–10

ダルマキールティは、ディグナーガの定義をそのまま掲げます。

他人のための推論の定義（第1偈） 他人のための推論とは、自分が見た対象を明らかにすることである。つまり、自分が三つの条件をそなえた理由から推し量ったのと同じように、相手にも推論を起こさせるために、その理由を言葉で述べることである。p.1

この短い定義の一語一語が、いろいろな「ずるい論証」を締め出す働きをしている、とダルマキールティは説明します。

定義の語締め出すもの例位置
「自分が」相手だけが認めている理由。論者自身も事物にもとづいて確かめていなければならないサーンキヤ学派：「相手（仏教徒）も『生じるもの』だと認めているのだから、それを理由に使ってよい」p.1–4
「対象（事物）」話し手の都合で頭の中だけで作った理由「音は無常である。主題か同類例かのどちらかだから」という言葉遊びの理由p.7–8
「明らかにする」主張そのものを論証の一部とすること「音は無常である」と述べることは、何も証明しない第4–5偈 / p.8–10
ただし例外：相手の土俵で相手を倒す「帰謬」 相手だけが認める前提を使ってよい場合もあります。相手の考えから矛盾を導いて見せるときです（帰謬法）。たとえば「あなたの言う『一つで、しかも多くの場所にある普遍』は、ある場所で消えれば他の場所でも消えるはずだ」と、相手の前提から不合理を引き出すことは正しい p.4–6。
西洋哲学と比べてみよう：ソクラテスの問答と、トゥールミンの論証モデル ソクラテスは、相手が認めた前提から矛盾を引き出して、相手の思い込みを崩しました（エレンコス）。ダルマキールティの「帰謬」はこれにあたります。
また、20世紀のトゥールミン（Toulmin）は、論証を主張（claim）・データ（data）・論拠（warrant）などに分けて分析しました。ダルマキールティの「主張は証明手段ではない。証明するのは三つの条件をそなえた理由だ」という考えは、主張とその根拠をはっきり分ける点で、トゥールミンの分析と同じ方向を向いています。

II正しい主張の条件

第6–32偈p.11–42

次は「主張」です。ディグナーガの定義を受けて、主張とは何かが詳しく分析されます。

主張の定義（ディグナーガ、第6偈・第26偈） 主張とは、それ自身の形だけで述べられるべきもので、論者が自ら意図したものであり、しかも知覚・推論・権威・世間の承認によって否定されていないものである。p.11, p.28

II-1「意図された」：隠れた狙いを見抜く p.12–18

この語のおかげで、表向きの言葉と本当の狙いを使い分ける論証を批判できます。代表例はサーンキヤ学派の論証です。

サーンキヤ学派の論証 「眼などの感覚器官は、他のもののためにある。寝床や椅子のように、部分が組み合わさってできたものだから」。
表向きは「他のもののため」と言うだけです。でも本当の狙いは、「組み合わさっていない魂（アートマン）のためにある」こと、つまり魂の存在を証明することです。

ダルマキールティは、言葉に出していなくても、この隠れた狙い（魂のため）こそが主張だと見なします。そうすると、寝床や椅子は「組み合わさった人の体」のためにあるので、例として役に立たず、論証は失敗する、と批判できるのです。

西洋哲学と比べてみよう：デザイン論証 ペイリー（Paley）は「時計があれば時計職人がいる。精巧な自然があれば、それを設計した神がいる」と論じました（デザイン論証）。サーンキヤ学派の「感覚器官は何か他のもののためにある。だから魂がある」は、目的から背後の存在を推し量る点でよく似ています。ヒュームは『自然宗教に関する対話』で、この類比はせいぜい「何らかの設計者」までしか示さず、神の性質までは示せない、と批判しました。ダルマキールティの批判も、例（寝床）と本当の結論（魂）のずれを突く点で、ヒュームとよく似ています。

II-2「否定されていない」：四つのチェック 第26–32偈 / p.28–42

何と矛盾してはいけないかだめな主張の例
知覚「音は聞こえないものである」（実際に聞こえている）
推論「壺は常住である」（作られたものは無常だと推論できる）
権威（自分の学派の聖典や、自分の言葉）「私の母は子を産まない女性だ」のような自己矛盾
世間の承認「月（チャンドラ）は『ウサギをもつもの』とは呼ばれない」（世間ではそう呼ぶ）
西洋哲学と比べてみよう：常識と日常言語 「世間の承認と矛盾してはいけない」という基準は、ムーア（G. E. Moore）の「常識の擁護」や、言葉の意味は使われ方で決まるというウィトゲンシュタインの考えを思わせます。ダルマキールティによれば、言葉の意味は人々の取り決めによるので、「月をウサギをもつものとは呼ばない」という主張は、事実の問題ではなく取り決めに反するから否定されるのです。

III正しい理由：九句因と三種の理由

第33–66偈p.43–90

III-1ディグナーガの「九句因」 第33偈 / p.43–49

ディグナーガは、理由が同類の例（推し量られるものがある所）と異類の例（ない所）に、「すべてにある」「どこにもない」「一部にある」のどれであるかを組み合わせて、九通りの表を作りました。これが有名な九句因です。

表を見ると、正しい理由（②⑧）は、どちらも異類の例にどこにもない列にあります。同類の例に「すべてにある」か「一部にある」かは問題ではありません。ダルマキールティは、ここから大事な結論を引き出します p.80–82。

ここが要点 理由の力を決めるのは、同類の例にどれだけ多くあるかではなく、異類の例から完全に排除されていることである。
西洋哲学と比べてみよう：真理表 九句因は、条件の組み合わせを網羅的に並べて、それぞれの結果を判定する表です。これは、現代論理学で命題の真偽の組み合わせをすべて並べる真理表（ウィトゲンシュタイン『論理哲学論考』などで広まった）の発想に通じます。5–6世紀のインドで、すでにこうした網羅的な分類表が作られていたのは驚きです。

III-2「努力の直後に生じる」：音は無常か 第34–39偈 / p.49–56

⑧の「努力の直後に生じるから」をめぐって、ミーマーンサー学派との論争が展開されます。ミーマーンサー学派は、聖典ヴェーダの言葉が永遠であるために、音（言葉）は常住で、努力（発声）はそれを作るのではなく、もともとある音を「顕わにする」だけだと主張しました。ダルマキールティは、努力の前後で音の聞こえ方が変わるのは、音そのものが努力から生じるからだと論じ、「努力の直後に生じる」は正しい結果による理由だと示します。

西洋哲学と比べてみよう：「型」と「出来事」 「ア」という音は、私が発音するたびに新しく生まれるのか、それとも一つの「ア」がそのつど現れるだけなのか。パース（Peirce）は、語や音のタイプ（型）と、一回一回の発話であるトークン（出来事）を区別しました。ミーマーンサー学派は「タイプとしての音こそが実在し、永遠だ」と考え、ダルマキールティは「実在するのは一回ごとのトークンだけだ」と考えた、と整理できるでしょう。

III-3「ない」はどうやって知られるのか 第40–57偈 / p.56–70

第2章で見た非認識（見えるはずのものが見えない）をさらに掘り下げます。新しい論点は、「見えない」ということ自体は、どうやってわかるのかです。

ここが要点 「壺が見えない」とは、知が単に欠けていることではない。「壺のない床だけを見ている」という積極的な経験であり、それは心が自分自身を直接知る働き（自己認識）によって確かめられる。第45–48偈 / p.58–63
西洋哲学と比べてみよう：否定的事実はあるか ラッセルは1918年の講義で、「このテーブルの上にカバはいない」のような否定的事実が世界にあるかどうかを論じ、聴衆と激しく議論しました。ダルマキールティは、否定的事実を世界の側に認めるのではなく、「別のものだけを見ている」という肯定的な経験に還元します。

III-4「存在する」は証明できるか 第58–62偈 / p.70–80

仏教徒は「存在するから、無常である」と、「存在すること」を理由に使います。では反対に、サーンキヤ学派が「根本原質（宇宙の根源）は存在する」と証明しようとするのはなぜだめなのか。ダルマキールティは、「存在」を証明しようとする理由は、どれも「主題にない」「異類にもある」「逆を証明する」のいずれかの過失に陥る、と論じます。

西洋哲学と比べてみよう：カント「存在は実在的述語ではない」 カントは、神の存在論的証明（「最も完全なものは、存在するという完全性ももつはずだ」）を批判して、「存在する」は物の性質を一つ付け加える述語ではない、と論じました。ダルマキールティの「存在を所証として立てることはできない」という議論も、存在を理屈だけで証明しようとする試みへの批判として、カントと響き合います。

III-5すべての理由は二つに帰着する 第63–66偈 / p.82–90

一見すると「本質による理由」にも「結果による理由」にも当てはまらない推論を、ダルマキールティは一つずつ取り上げ、すべてどちらかに帰着することを示します。

一見特殊な推論帰着先理由づけ位置
原因がすべてそろっている → 結果が生じる本質原因の総体には「結果を生む力」がすでに本性として含まれている第63偈 / p.82–84
果物の味 → その色結果味は、色と共通の原因から生じた結果。そこから原因を推し、さらに色を推す第64偈 / p.84–85
牛である → 角がある結果全体と部分の関係も、原因と結果の関係に還元できる第65偈 / p.85–86
水面が静か → 水底がある結果静かな水は、支えるもの（水底）から生じた状態第66偈 / p.86–89
鷺がいる → 近くに水がある結果鷺の生存は水に依存しているので、ある意味で水の結果第66偈 / p.89–90

IVまちがった理由（似因）

第67–83偈p.91–131

理由のように見えて実は理由でないもの（似因）は、三つの条件のどれが成り立たないか、あるいは疑わしいかで分類されます 第67–68偈 / p.91。

IV-1主張の一部を理由にする 第77–81偈 / p.98–106

不成立因の中でも面白いのは、主張の一部をそのまま理由にしてしまう誤りです。「音は無常である。音だから」のように、理由が主張に含まれていると、何も証明されません。

IV-2「全知者はいない。話をするから」 p.106–112

ミーマーンサー学派は、仏陀の全知を否定するためにこう論じました。「話をする者で全知の人を見たことがない。だから話をする者は全知者ではない」。ダルマキールティの批判はこうです。

  1. 「見たことがない」だけでは、異類（全知者）に「話すこと」がないとは確定できない。
  2. 話すことと全知であることは、互いに矛盾しない。
  3. しかも、すべての話し手について「全知でない」と確かめられる者がいるとしたら、その人こそ全知者である。

IV-3「生きた身体には魂がある。呼吸があるから」 p.115–127

ニヤーヤ学派などのこの論証について、ダルマキールティは、呼吸などは魂がある所（同類）にも、ない所（異類）にも、あるともないとも確かめられないので、疑わしい理由だと退けます。

西洋哲学と比べてみよう：誤謬論と生気論
ダルマキールティの似因西洋の誤謬論での名前
主張の一部を理由にする論点先取（petitio principii）
主題にない理由（不成立因）偽の前提
異類にもありうる理由（不定因）早まった一般化、論点のすり替え
反対の結論を証明する理由（相違因）自分の議論が自分に返ってくる（ブーメラン）
「呼吸があるから魂がある」は、生命を物理的なしくみ以上の「生命力」で説明しようとした西洋の生気論や、デカルトの心身二元論をめぐる議論と比べてみると面白いでしょう。

IV-4相違決定：正反対の二つの「正しい」論証 p.128–131

ディグナーガは、同じ主題について、どちらも三つの条件をそなえているように見えるのに、正反対の結論を出す二つの理由がぶつかる場合を「相違決定」と呼び、疑いの原因に数えました。ダルマキールティの答えはこうです。

ここが要点 事物にもとづく正しい推論（本質・結果・非認識）では、相違決定は起こりえない。起こるのは、聖典の権威など、相手が認めているだけの前提にもとづいて推論するときだけである。
西洋哲学と比べてみよう：カントのアンチノミー カントは『純粋理性批判』で、「世界には時間の始まりがある」と「ない」のように、どちらも同じくらいもっともらしく証明できてしまう対立（アンチノミー）を示しました。そして、それは理性が経験を越えたものについて語ろうとするときにだけ生じる、と診断しました。
ダルマキールティの「相違決定は、事物にもとづかない推論でだけ起こる」という診断は、カントのこの診断と驚くほどよく似ています。

V例（喩例）の役割

第84偈p.132–134

ニヤーヤ学派は、例（「かまどのように」）を論式の独立した一部と考えました。ダルマキールティは、例は理由の三つの条件（とくに「理由があるところには必ず〜がある」という関係）を具体的に示すだけで、理由と別に説く必要はない、と言います。まちがった例（同類の例なのに推し量られるものがない、など）も、理由の条件を正しく示せないものとして、同じ原理で退けられます。

西洋哲学と比べてみよう：例は証明か アリストテレスは『弁論術』で、聴衆を説得する手段として「例（パラデイグマ）」を挙げましたが、それは厳密な証明（論証）ではなく、説得のための手段でした。ダルマキールティも、例を理解を助ける見本と位置づけ、証明の力は理由にあると考えます。「数学の証明で、具体例をいくつ挙げても証明にはならない」という現代の常識とも一致します。

VI相手を批判する（論難）

第85偈p.135–137

最後の話題は、相手の論証を批判する方法です。

内容位置
正しい批判相手の論証の欠陥を指摘すること（理由が不成立だ、不定だ、など）。相手が論証を述べ終えたあとで、適切なタイミングで行うp.135–136
見かけだけの批判欠陥がないのに、似たところを取り上げてけちをつける詭弁的な反論。無数にあるので、一つ一つは挙げない。上に述べた原理で見分ければよいp.136–137
西洋哲学と比べてみよう：詭弁術と「論破の技術」 ニヤーヤ学派は見かけだけの反論を24種に分類しましたが、ダルマキールティは「無数にあるから挙げない」とあっさり片づけます。分類を覚えるより、正しい論証の原理を身につければ見分けられる、という態度です。
西洋では、アリストテレスが『詭弁論駁論』で詭弁を分類し、ショーペンハウアーは皮肉をこめて『論争術』で「どんな手を使ってでも議論に勝つ38の策略」を並べました。ダルマキールティなら、そのどれもが「三つの条件」で見破れる、と言うでしょう。

章と本全体は、「誤ることのない方法をもつ見者の教え（ディグナーガの著作）を、よく吟味したうえで解き明かした」という趣旨の結びの偈で閉じられます p.137。

第3章のまとめ
  1. 他人のための推論とは、自分が事物にもとづいて確かめた理由を、言葉で相手に示すこと。主張そのものは証明手段ではない（I）。
  2. 主張は、本当に意図していることで、知覚・推論・権威・世間の承認に否定されていないものでなければならない（II）。
  3. 理由の力は、異類から完全に排除されていることで決まる。正しい理由は本質・結果・非認識の三種類に帰着する（III）。
  4. まちがった理由は、三つの条件のどれが欠けるかで分類できる。正反対の論証がぶつかるのは、事物にもとづかない推論だけ（IV）。
  5. 例は見本にすぎず、正しい批判とは欠陥の指摘である（V–VI）。
