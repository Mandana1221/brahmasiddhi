karṇaparva — ekonanavatitamo'dhyāyaḥ (89)
第89章　混戦
sañjaya uvāca|
sukalpitā haimavatā mahotkaṭā raṇābhikāmaiḥ kṛtibhiḥ samāsthitāḥ|
suvarṇajālairvitatā babhur gajās tathā yathā khe jaladāḥ savidyutaḥ||
// 8-89-1 //
サンジャヤは語った。
kuṇindaputro daśabhirmahāyasaiḥ kṛpaṃ sasūtāśvamapīḍayadbhṛśam|
tataḥ śaradvatsutasāyakairhataḥ sahaiva nāgena papāta bhūtale||
// 8-89-2 //
クニンダ王の子は、十本の大いなる鉄矢でクリパを御者と馬もろとも激しく苦しめた。するとシャラドヴァットの子（クリパ）の矢に殺され、象と共に大地に倒れた。
kuṇindaputrāvarajastu tomārair divākarāṃśupratimairayasmayaiḥ|
jaghāna bhojasya hayānathāpatan kṣaṇādviśastāḥ kṛtavarmaṇe hayāḥ||
// 8-89-3 //
クニンダ王の子の弟は、太陽光線のような鉄の投げ矛で、ボージャ（クリタヴァルマン）の馬を殺した。一瞬にして、クリタヴァルマンの馬は斬り殺された。
athāpare drauṇihatā mahādvipās trayaḥ sasarvāyudhayodhaketanāḥ|
nipetururvyāṃ vyasavo vicetanās tathā yathā vajrahatā mahācalāḥ||
// 8-89-4 //
ドローナの子に殺された三頭の大象が、全ての武器・戦士・旗もろとも、金剛杵に打たれた大山のように、命なく意識を失って大地に倒れた。
kuṇindarājāvarajādanantaraḥ stanāntare patrivarairatāḍayat|
tavātmajaṃ tasya tavātmajaḥ śaraiḥ śitaiḥ śarīraṃ vyahanaddvipaṃ ca tam||
// 8-89-5 //
クニンダ王の弟の次の者が、矢でお前の息子の胸を射た。汝の息子は矢でその体と象を射た。
sa nāgarājaḥ saha rājasūnunā papāta raktaṃ bahu sarvataḥ kṣaran|
mahendravajraprahato'mbudāgame yathā jalaṃ gerikaparvatastathā||
// 8-89-6 //
その象の王は王の子と共に、四方から多くの血を流しながら倒れた。大いなるインドラの金剛杵に打たれた雨季のゲーリカ山のように。
kuṇindaputraprahito'paro dvipaḥ krāthaṃ sasūtāśvarathaṃ vyapothayat|
tato'patatkrāthasarābhighātitaḥ saheśvaro vajrahato yathā giriḥ||
// 8-89-7 //
クニンダ王の子が放った別の象が、クラータを御者・馬・戦車もろとも粉砕した。するとクラータの剣に打たれた象も主もろとも倒れた。金剛杵に打たれた山のように。
rathī dvipasthena hato'pataccharaiḥ krāthādhipaḥ parvatajena durjayaḥ|
savājisūteṣvasanadhvajastathā yathā mahāvātahato mahādrumaḥ||
// 8-89-8 //
クラータの王は象に乗った山の住人に矢で殺されて倒れた——御者・馬・弓・矢筒・旗もろとも、大風に倒された大木のように。
vṛko dvipasthaṃ girirājavāsinaṃ bhṛśaṃ śarairdvādaśabhiḥ parābhinat|
tato vṛkaṃ sāśvarathaṃ mahādvipo drutaṃ caturbhiraṇairvyapothayat||
// 8-89-9 //
ヴリカは象に乗った者を十二本の矢で激しく射た。するとその大象が素早く四本の蹄でヴリカを戦車・馬もろとも粉砕した。
sa pothito nāgaraveṇa vīryavān parābhinaddvādaśabhiḥ śilīmukhaiḥ|
vṛkeṇa bāṇābhihato'patatkṣitau savāraṇo babhrusutena sārdham||
// 8-89-10 //
象の音に打ちのめされた力ある者（ヴリカ）は十二本の矢で象を射た。ヴリカの矢に打たれた象は、バブルの子と共に大地に倒れた。
kuṇindarājasya suto'parastadā sa cāpi śūraḥ sahasā samarpitaḥ|
papāta bāṇaiḥ subalasya sūnunā viṣāṇapucchāparagātrapātinā||
// 8-89-11 //
クニンダ王の子の別の勇敢な者も、素早くスバラの子（シャクニ）の矢に倒れた。牙・尾・その他の体の部分を射抜く矢で。
gajena vāhāñśakuneḥ kuṇindajo nināya vaivasvatamandiraṃ raṇe|
rathaṃ ca saṃkṣubhya nanāda nardatas tato'sya gāndhārapatiḥ śiro'harat||
// 8-89-12 //
クニンダの子は象でシャクニの馬をヤマの館に送った。戦車を揺さぶり吼え叫ぶその象の首を、ガーンダーラ王（シャクニ）が切り落とした。
tataḥ kuṇindeṣu gateṣu teṣu prahṛṣṭarūpāstava te mahārathāḥ|
bhṛśaṃ pradaradhmurlavaṇāmbusambhavān varāṃś ca bāṇāsanapāṇayo'bhyayuḥ||
// 8-89-13 //
クニンダ族が倒された後、汝の大戦車戦士たちは喜び、海から生まれた法螺貝を激しく吹き鳴らし、弓を手にして最上の者たちに向かった。
tathā'bhavadyuddhamatīva dāruṇaṃ punaḥ kurūṇāṃ saha pāṇḍusṛñjayaiḥ|
śarāsiśaktyṛṣṭigadāparaśvathair narāśvanāgāsuharaṃ bhṛśākulam||
// 8-89-14 //
そして再びクル族とパーンドゥ・スリンジャヤ族の間に極めて恐ろしい戦いが起こった。矢・剣・槍・投げ槍・棍棒・斧で、人・馬・象の命を奪う激しく混乱した戦い。
rathāśvamātaṅgapadātayastataḥ parasparaṃ viprahatāḥ kṣitau patan|
yathā savidyuttaṭito jalapradāḥ samutthitairdigbhya ivogramāruteḥ||
// 8-89-15 //
戦車・馬・象・歩兵が、互いに打たれて大地に倒れた。稲妻と雷を伴う雨雲が、四方から吹き上がる恐ろしい嵐に吹き飛ばされるように。
tataḥ śatānīkahatā mahāgajā hayā rathāḥ pattigaṇāś ca tāvakāḥ|
suparṇavātaprahatā yathoragās tathā gatā gāṃ vivaśā vicūrṇitāḥ||
// 8-89-16 //
シャターニーカに殺された大象・馬・戦車・歩兵が汝の軍から——ガルダと風に打たれた蛇のように、力なく粉砕されて大地に落ちた。
tato'bhyaviddhyadbahubhiḥ śitaiḥ śaraiḥ sa vindaputro nakulātmajaṃ smayan|
tato'sya kopādvicakarta nākuliḥ śiraḥ kṣureṇāmbujasannibhānanam||
// 8-89-17 //
ヴィンダの子がナクラの子（シャターニーカ）を多くの鋭い矢で微笑みながら射ると、ナクラの子は怒って剃刀矢でその蓮のような顔の首を切り落とした。
tataḥ śatānīkamavidhyadāyasais tribhiḥ śaraiḥ karṇasuto'rjunaṃ tribhiḥ|
tribhiś ca bhīmaṃ nakulaṃ ca saptabhir janārdanaṃ dvādaśabhiś ca sāyakaiḥ||
// 8-89-18 //
カルナの子（ヴリシャセーナ）は三本の鉄矢でシャターニーカを射、三本でアルジュナを、三本でビーマを、七本でナクラを、十二本の矢でジャナールダナ（クリシュナ）を射た。
tadasya karmātimanuṣyakarmaṇaḥ samīkṣya hṛṣṭāḥ kuravo'bhyapūjayan|
parākramajñāstu dhanañjayasya ye huto'yamagnāviti te tu menire||
// 8-89-19 //
人間離れした業を成すその者の武勇を見て、喜んだクル族は称賛した。しかしダナンジャヤの武勇を知る者たちは、「この者は火に供えられた」と思った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekonanavatitamo'dhyāyaḥ|| 89 ||
