Subandhu's Sanskrit Romance — Bilingual Edition

スバンドゥ作『ヴァーサヴァダッター』（6世紀末頃）は、サンスクリット散文文学（ガディヤ・カーヴィヤ）の最古の作品として知られる恋愛物語である。全編を通じて掛詞（シュレーシャ）が織り込まれた絢爛たる散文で、王子カンダルパケートゥと姫ヴァーサヴァダッターの夢から始まる恋の物語が語られる。

底本: J. M. Shukla 校訂 (Jodhpur, 1966)〔GRETIL〕/ 英訳: L. H. Gray (Columbia UP, 1913) / 注釈: G. S. Rai (Chaukhambha, 1999)

Vāsavadattā
ヴァーサヴァダッター ― スバンドゥ作
Maṅgala — Invocatory Verses
序詩 ― 祈願と詩人論
oṃ namo bhāratyai ||
オーム、弁才天（バーラティー）に帰命す。
karabadarasadṛśam alikhaṃ bhuvanatalaṃ yatprasādataḥ kavayaḥ /
paśyanti sūkṣmamatayaḥ sā jayati sarasvatī devī // 1 //
その恩寵により、鋭い知性を持つ詩人たちが全世界を掌中のナツメの実のように見通す――そのサラスヴァティー女神は勝利する。【1】
khinno 'si muñca śailaṃ bibhṛmo vayam iti vadatsu śithilabhujaḥ /
bharabhugnavitatabāhuṣu gopeṣu hasan harir jayati // 2 //
「お疲れでしょう、山を放してください。私たちが支えます」と牛飼いたちが腕を広げて申し出るとき、その重荷に腕がたわんでいるにもかかわらず、微笑むハリ（クリシュナ）は勝利する。【2】
kaṭhinataradāmaveṣṭanalekhāsandehadāyino yasya /
rājanti valivibhaṅgāḥ sa pātu dāmodaro bhavataḥ // 3 //
固く巻いた紐の跡ではないかと見紛うほどに輝く腰の皺を持つダーモーダラ（クリシュナ）が、汝らを護りたまえ。【3】
sa jayati himakaralekhā cakāsti yasyotsukomayā nihitā /
nayanapratīpakajjalajighṛkṣayā śirasi rajataśuktir iva // 4 //
三日月がその頭上に輝く――ウマーが炎の眼から黒い目墨を拭おうとして額に載せた銀の真珠貝のように。その神（シヴァ）は勝利する。【4】
bhavati subhagatvam adhikaṃ vistāritaparaguṇasya sujanasya /
vahati vikāsitakumudo dviguṇaruciṃ himakarodyotaḥ // 5 //
他者の美徳を広める善き人には、いっそうの幸福が訪れる。睡蓮を花開かせた月の光が、二倍の輝きを帯びるように。【5】
viṣadharato 'py ativiṣamaḥ khala iti na mṛṣā vadanti vidvāṃsaḥ /
yad ayaṃ nakuladveṣī sa kuladveṣī punaḥ piśunaḥ // 6 //
「悪人は毒蛇よりなお始末が悪い」と賢者たちが言うのは嘘ではない。蛇はマングース（ナクラ）を憎むが一族（クラ）は憎まない。しかし悪人は一族をも憎み、中傷する。【6】
atimaline kartavye bhavati khalānām atīva nipuṇā dhīḥ /
timire hi kauśikānāṃ rūpaṃ pratipadyate dṛṣṭiḥ // 7 //
汚れたことをなすにあたって、悪人の知恵はまことに巧みである。闇の中でこそ、梟の目はものの姿を捉えるのだから。【7】
hasta iva bhūtimalino laṅghayati yathā yathā khalaḥ sujanam /
darpaṇam iva taṃ kurute tathā tathā nirmalacchāyam // 8 //
汚れた手で磨けば磨くほど鏡がいっそう清らかに輝くように、悪人が善人を踏みにじろうとすればするほど、善人をいっそう清浄にする。【8】
vidhvastaparaguṇānāṃ bhavati khalānām atīva malinatvam /
antaritaśaśirucām api salilamucāṃ malinim ābhyadhikaḥ // 9 //
他者の美徳を打ち壊す悪人には、きわめて大きな汚れがまとわりつく。月の光を遮った雨雲が、かえっていっそう黒く見えるように。【9】
sā rasavattā nihatā navakā vilasanti carati no kaṅkaḥ /
sarasīva kīrtiśeṣaṃ gatavati bhuvi vikramāditye // 10 //
ヴィクラマーディティヤ王がこの世を去り名声のみを遺したとき、すべての歓びは失われ、鶴は戯れず蒼鷺は飛ばない――涸れた湖のように。【10】
aviditaguṇāpi satkavibhaṇitiḥ karṇeṣu vamati madhudhārām /
anadhigataparimalāpi hi harati dṛśaṃ mālatīmālā // 11 //
その技巧を知らずとも、すぐれた詩人の言葉は耳に蜜の流れを注ぐ。その芳香が伝わらずとも、マーラティーの花輪は目を奪うのだから。【11】
guṇinām api nijarūpapratipattiḥ parata eva saṃbhavati /
svamahimadarśanam akṣṇor mukuratale jāyate yasmāt // 12 //
すぐれた者でも、自らの真価の認識は他者によってこそ生じる。自らの偉大さを目で見るには、鏡の面を用いねばならないのだから。【12】
sarasvatīdattavaraprasādaś cakre subandhuḥ sujanaikabandhuḥ /
pratyakṣaraśleṣamayaprabandhaṃ vinyāsavaidagdhyanidhir nibandham // 13 //
サラスヴァティー女神の恩寵を賜りしスバンドゥ――善き人々のただ一人の友――は、一字一字に掛詞を織り込む構成の巧みさの宝庫ともいうべきこの作品を著した。【13】
Kathā-prārambhaḥ — The Story Begins
物語の始まり ― チンターマニ王の治世
1) abhūd abhūtapūrvaḥ, sarvorvīpaticakracūḍāmaṇiśreṇīśāṇakoṇakaṣaṇanirmalīkṛtacaraṇanakhamaṇiḥ, ṇṛsiṃha iva darśitakaśipukṣetradānavismayaḥ, kṛṣṇa iva kṛtavasudevatarpaṇaḥ, nārāyaṇa iva saukaryasamāsāditadharaṇīmaṇḍalaḥ, kaṃsārātir iva janitayaśodānandasamṛddhiḥ, ānakadundubhir iva kṛtakāvyādaraḥ, sāgaraśāyīvānantabhogīcūḍāmaṇirañjitapādaḥ, varuṇa ivāśāntarakṣaṇaḥ, agastya iva dakṣiṇāśāprasādhakaḥ, jalanidhir iva vāhinīśatanāyakaḥ samakarapracāraś ca, hara iva mahāsenānuyāto nirjitamāraś ca, merur iva vibudhālayo viśvakarmāśrayaś ca, ravir iva kṣaṇadānapriyaś cchāyāsantāpaharaś ca, kusumaketur iva janitāniruddhasaṃpad ratisukhapradaś ca, vidyādharo 'pi sumanāḥ, dhṛtarāṣṭro 'pi guṇapriyaḥ, kṣamānugato 'pi sudharmāśritaḥ, bṛhannalānubhāvo 'py antaḥsaralaḥ, mahiṣīsaṃbhavo 'pi vṛṣotpādī, ataralo 'pi mahānāyakaḥ rājā Cintāmaṇir nāma |
1) かつて、前例のない一人の王がいた。全地上の君主たちの輪の冠宝石の連なりが砥石の角に当たって磨かれ、清められた足の爪の宝石を持つ王である。
人獅子ナラシンハが衣と大地を与えて驚嘆を示したように、王は黄金・食物・衣服・領地を贈って驚嘆を引き起こした。クリシュナがヴァスデーヴァに喜びを与えたように、王は神々にその財で喜びを与えた。ナーラーヤナが猪の姿で大地を支えたように、王はたやすく大地を征服した。カンサの敵（クリシュナ）がヤショーダーとナンダに繁栄をもたらしたように、王は栄光と至福の繁栄を生み出した。
海に臥す神ヴィシュヌが無限の蛇の冠宝石で蓮華の足を飾るように、王の足は多くの蛇の冠宝石の光で飾られた。ヴァルナが西方を護るように、王は絶え間なく護った。アガスティヤが南方を浄めたように、王は請願を施しで飾った。大海が百の河の主であり魚の住処であるように、王は百の軍の長であり正しく徴税した。ハラ（シヴァ）がマハーセーナを伴いマーラを退けるように、王は大軍を従え障害を退けた。メール山が神々の住処でありヴィシュヴァカルマンの拠り所であるように、王は賢者の住処であり万人の営みの拠り所であった。太陽が闇を好まずチャーヤーの悲しみを除くように、王は祭事に惜しみなく与え美によって悲嘆を除いた。カーマ神がアニルッダに繁栄をもたらしラティに歓楽を与えるように、王は妨げなき繁栄を生み交わりの喜びを与えた。
ヴィディヤーダラ（半神）でありながら善き心を持ち、ドゥリタラーシュトラ（盲目王）でありながら美徳を愛し、忍耐に従いながらも正法の庇護を求め、ブリハンナラーの力を持ちながらも内に真直ぐであり、水牛の后から生まれながらも正義を生み出し、軽薄ならざる偉大な指導者であった。その名を王チンターマニという。
2) yatra ca śāsati dharaṇimaṇḍalaṃ chalanigrahaprayogā vādeṣu, nāstikatā cārvākeṣu, kaṇṭakayogo niyogeṣu, parīvādo vīṇāsu, khalasaṃyogaḥ śāliṣu, dvijihvasaṅgṛhītir āhituṇḍikeṣu, kara[cchedaḥ kḷptakara]grahaṇeṣu, netrotpāṭanaṃ munīnāṃ, rājaviruddhatā paṅkajānāṃ, sarvabhaumayogo diggajānāṃ, śūlasaṃyogo yuvatiprasave, agnitulāśuddhiḥ suvarṇānāṃ, duḥśāsanadarśanaṃ bhārate, karapatradāraṇaṃ jalajānāṃ, param evaṃ vyavasthitam |
2) 王が大地を治めていた時代――詭弁や誤謬は論争の場にのみあり、日常の欺瞞とは無縁であった。不信仰はチャールヴァーカ（唯物論者）の間にのみあった。棘の使用は命令の執行にのみあり、敵の雇用はなかった。爪弾きはヴィーナーにのみあり、陰口はなかった。脱穀場は稲にのみ結びつき、悪人との結びつきはなかった。二枚舌の捕獲は蛇使いの仕事にのみあり、嘘つきの捕獲は不要であった。手を切ることは税の受領にのみあり、刑罰としての手の切断はなかった。
根を抜くのはムニ（ワームウッド）の木にのみあり、苦行者（ムニ）が目を抜くことはなかった。王に逆らうのは蓮の花だけであった。「全地の支配者」の称は四方の象にのみ用いられた。火と天秤による試練は種々の黄金にのみ行われ、神明裁判は不要であった。ドゥッシャーサナ（悪しき統治）は叙事詩マハーバーラタにのみ知られ、悪政の兆しはなかった。鋸による裂断は蓮の花にのみあった。このように万事が整っていたのである。
Kandarpakētu — The Prince
王子カンダルパケートゥの登場
3) sa punar anya eva tyaktasarvapūrvorvīpaticaritaḥ | tathā hi | sarvataḥ kaṭakasaṃcāriṇo gandharvān darśitaśṛṅgonnatiḥ sukhayan na virarāma | sa himālayo nāvaśyāyocchalitaḥ no māyājanmane hitaś ca | asau hi mānī giri sthito vṛṣadhvajaś ca | [asau] sadgatiḥ, avadhūtākhilakāntāraḥ, pāvakāgresaraḥ, na bhogotsukaḥ sumanoharaḥ[ś ca] |
3) さて、この王はまた格別の存在であり、過去のすべての王の事跡を凌駕していた。すなわち――王はヒマーラヤのようであった。峰の高さを見せて山腹を行き交うガンダルヴァたちを絶えず喜ばせた。すなわち、王威の高さを示して陣営を行き交う軍馬を絶えず喜ばせた。雪に揺るがされることなく幻術の出生にも向かないヒマーラヤのように、王は驕りに揺るがされず欺きにも向かなかった。
王は風のようであった。よき道を歩み、すべての荒野を払い除け、火を先導し、享楽に執着せず、花を運んで心を奪う。すなわち王は常に忍耐強く、あらゆる曲がったことを正し、苦行者のうちで最も高く、官能の快楽に貪欲ならず、賢者の喜びであった。
sa ratnākaro 'nahimayaḥ, katham agādhaḥ, samaryādaḥ, nodreko 'py asya vismayaḥ, himakarāśrayo 'mṛtamayaḥ, satpātraḥ, tasyācalo na krodhaḥ, mahānadīnaḥ, sapotaḥ sa samudraḥ | [sa candra iva] kṣaṇadānandakaraḥ, kumudavanabandhuḥ, sakalakalākulagṛhaṃ, natārātibalaḥ | [sa samudro] mitrodayahetuḥ, kāñcana śobhāṃ bibhrat, acalādhikalakṣmīḥ sumerur iva |
王は宝石の鉱山であり大海のようであった――蛇を持たず、測り知れぬ深さがあり、秩序があり、溢れても驚かせることなく、月に庇護され甘露に満ち、正しい器であった。王の怒りは山のように不動であり、大河を持ち、船を備えた大海であった。
月のように祭りに喜びをもたらし、睡蓮の園の友であり、あらゆる技芸に満ちた宮殿を持ち、敵の軍勢を屈伏させた。メール山のように友の繁栄の因となり、黄金の輝きを帯び、山々を超える富を持っていた。
tasya ca pārijāta ivāśritanandanaḥ, himālaya iva janitaśivaḥ, mandara iva bhogibhogāṅkitaḥ, kailāsa iva maheśvaropabhuktakoṭiḥ, madhur iva nānārāmānandakaraḥ, ... subāhur api rāmānandī, samadṛṣṭir api maheśvaro, muktāmayo 'py ataralamadhyo, jalada iva vimalataravāridhārātrāsitarājahaṃsaḥ, vaṃśapradīpo 'py akṣatadaśaḥ, tanayaḥ Kandarpaketur nāma |
その王には一人の息子がいた。パーリジャータ（天界の珊瑚樹）のようにインドラの園に喜びを与え、ヒマーラヤのように吉祥（シヴァ）を生み、マンダラ山のように蛇の体で刻まれ、カイラーサのように大自在天がその頂を楽しみ、マトゥラーのように多くの園に歓びを与えた。
スバーフ（美しい腕）でありながら女性を喜ばせ、等しき眼差しを持ちながら偉大な主であり、真珠で作られていながら中心は軽薄でなく、雨雲のように清らかな水の流れで白鳥を驚かせ、家系の灯火でありながら傷なき状態を保った。その名を王子カンダルパケートゥ（愛の旗標）という。
