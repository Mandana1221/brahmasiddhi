スバンドゥ作『ヴァーサヴァダッター』（6世紀末頃）は、サンスクリット散文文学（ガディヤ・カーヴィヤ）の最古の作品として知られる恋愛物語である。全編を通じて掛詞（シュレーシャ）が織り込まれた絢爛たる散文で、王子カンダルパケートゥと姫ヴァーサヴァダッターの夢から始まる恋の物語が語られる。

底本: J. M. Shukla 校訂 (Jodhpur, 1966)〔GRETIL〕/ 英訳: L. H. Gray (Columbia UP, 1913) / 注釈: G. S. Rai (Chaukhambha, 1999)

Vāsavadattā
ヴァーサヴァダッター ― スバンドゥ作
Maṅgala — Invocatory Verses
序詩 ― 祈願と詩人論
oṃ namo bhāratyai ||
オーム、弁才天（バーラティー）に帰命す。
karabadarasadṛśam alikhaṃ bhuvanatalaṃ yatprasādataḥ kavayaḥ /
paśyanti sūkṣmamatayaḥ sā jayati sarasvatī devī // 1 //
その恩寵により、鋭い知性を持つ詩人たちが全世界を掌中のナツメの実のように見通す――そのサラスヴァティー女神は勝利する。【1】
khinno 'si muñca śailaṃ bibhṛmo vayam iti vadatsu śithilabhujaḥ /
bharabhugnavitatabāhuṣu gopeṣu hasan harir jayati // 2 //
「お疲れでしょう、山を放してください。私たちが支えます」と牛飼いたちが腕を広げて申し出るとき、その重荷に腕がたわんでいるにもかかわらず、微笑むハリ（クリシュナ）は勝利する。【2】
kaṭhinataradāmaveṣṭanalekhāsandehadāyino yasya /
rājanti valivibhaṅgāḥ sa pātu dāmodaro bhavataḥ // 3 //
固く巻いた紐の跡ではないかと見紛うほどに輝く腰の皺を持つダーモーダラ（クリシュナ）が、汝らを護りたまえ。【3】
sa jayati himakaralekhā cakāsti yasyotsukomayā nihitā /
nayanapratīpakajjalajighṛkṣayā śirasi rajataśuktir iva // 4 //
三日月がその頭上に輝く――ウマーが炎の眼から黒い目墨を拭おうとして額に載せた銀の真珠貝のように。その神（シヴァ）は勝利する。【4】
bhavati subhagatvam adhikaṃ vistāritaparaguṇasya sujanasya /
vahati vikāsitakumudo dviguṇaruciṃ himakarodyotaḥ // 5 //
他者の美徳を広める善き人には、いっそうの幸福が訪れる。睡蓮を花開かせた月の光が、二倍の輝きを帯びるように。【5】
viṣadharato 'py ativiṣamaḥ khala iti na mṛṣā vadanti vidvāṃsaḥ /
yad ayaṃ nakuladveṣī sa kuladveṣī punaḥ piśunaḥ // 6 //
「悪人は毒蛇よりなお始末が悪い」と賢者たちが言うのは嘘ではない。蛇はマングース（ナクラ）を憎むが一族（クラ）は憎まない。しかし悪人は一族をも憎み、中傷する。【6】
atimaline kartavye bhavati khalānām atīva nipuṇā dhīḥ /
timire hi kauśikānāṃ rūpaṃ pratipadyate dṛṣṭiḥ // 7 //
汚れたことをなすにあたって、悪人の知恵はまことに巧みである。闇の中でこそ、梟の目はものの姿を捉えるのだから。【7】
hasta iva bhūtimalino laṅghayati yathā yathā khalaḥ sujanam /
darpaṇam iva taṃ kurute tathā tathā nirmalacchāyam // 8 //
汚れた手で磨けば磨くほど鏡がいっそう清らかに輝くように、悪人が善人を踏みにじろうとすればするほど、善人をいっそう清浄にする。【8】
vidhvastaparaguṇānāṃ bhavati khalānām atīva malinatvam /
antaritaśaśirucām api salilamucāṃ malinim ābhyadhikaḥ // 9 //
他者の美徳を打ち壊す悪人には、きわめて大きな汚れがまとわりつく。月の光を遮った雨雲が、かえっていっそう黒く見えるように。【9】
sā rasavattā nihatā navakā vilasanti carati no kaṅkaḥ /
sarasīva kīrtiśeṣaṃ gatavati bhuvi vikramāditye // 10 //
ヴィクラマーディティヤ王がこの世を去り名声のみを遺したとき、すべての歓びは失われ、鶴は戯れず蒼鷺は飛ばない――涸れた湖のように。【10】
aviditaguṇāpi satkavibhaṇitiḥ karṇeṣu vamati madhudhārām /
anadhigataparimalāpi hi harati dṛśaṃ mālatīmālā // 11 //
その技巧を知らずとも、すぐれた詩人の言葉は耳に蜜の流れを注ぐ。その芳香が伝わらずとも、マーラティーの花輪は目を奪うのだから。【11】
guṇinām api nijarūpapratipattiḥ parata eva saṃbhavati /
svamahimadarśanam akṣṇor mukuratale jāyate yasmāt // 12 //
すぐれた者でも、自らの真価の認識は他者によってこそ生じる。自らの偉大さを目で見るには、鏡の面を用いねばならないのだから。【12】
sarasvatīdattavaraprasādaś cakre subandhuḥ sujanaikabandhuḥ /
pratyakṣaraśleṣamayaprabandhaṃ vinyāsavaidagdhyanidhir nibandham // 13 //
サラスヴァティー女神の恩寵を賜りしスバンドゥ――善き人々のただ一人の友――は、一字一字に掛詞を織り込む構成の巧みさの宝庫ともいうべきこの作品を著した。【13】
Kathā-prārambhaḥ — The Story Begins
物語の始まり ― チンターマニ王の治世
1) abhūd abhūtapūrvaḥ, sarvorvīpaticakracūḍāmaṇiśreṇīśāṇakoṇakaṣaṇanirmalīkṛtacaraṇanakhamaṇiḥ, ṇṛsiṃha iva darśitakaśipukṣetradānavismayaḥ, kṛṣṇa iva kṛtavasudevatarpaṇaḥ, nārāyaṇa iva saukaryasamāsāditadharaṇīmaṇḍalaḥ, kaṃsārātir iva janitayaśodānandasamṛddhiḥ, ānakadundubhir iva kṛtakāvyādaraḥ, sāgaraśāyīvānantabhogīcūḍāmaṇirañjitapādaḥ, varuṇa ivāśāntarakṣaṇaḥ, agastya iva dakṣiṇāśāprasādhakaḥ, jalanidhir iva vāhinīśatanāyakaḥ samakarapracāraś ca, hara iva mahāsenānuyāto nirjitamāraś ca, merur iva vibudhālayo viśvakarmāśrayaś ca, ravir iva kṣaṇadānapriyaś cchāyāsantāpaharaś ca, kusumaketur iva janitāniruddhasaṃpad ratisukhapradaś ca, vidyādharo 'pi sumanāḥ, dhṛtarāṣṭro 'pi guṇapriyaḥ, kṣamānugato 'pi sudharmāśritaḥ, bṛhannalānubhāvo 'py antaḥsaralaḥ, mahiṣīsaṃbhavo 'pi vṛṣotpādī, ataralo 'pi mahānāyakaḥ rājā Cintāmaṇir nāma |
1) かつて、前例のない一人の王がいた。全地上の君主たちの連なりの冠宝石が砥石の角で磨かれ、清められた足の爪の宝石を持つ王であった。人獅子ナラシンハが衣と大地〈ヒラニヤカシプ〉を与えて驚嘆をもたらしたように、王は黄金・食物・衣服・領地を贈って驚嘆を引き起こした。クリシュナがヴァスデーヴァを喜ばせたように、王は神々に〈財宝で〉喜びを与えた。ナーラーヤナが猪の姿で大地を容易く得たように、王は大地の全域を得た。カンサの敵（クリシュナ）がヤショーダーとナンダに繁栄をもたらしたように、王は〈名声〉と〈至福〉の繁栄を生んだ。
海に臥すヴィシュヌが無限の蛇の冠宝石で足を飾るように、王の足は諸侯の冠宝石の光で飾られた。ヴァルナが方位を護るように、王は絶え間なく護った。アガスティヤが南方を浄めたように、王は〈施し〉で美しくした。大海が百の河の主であり鰐の行き来する所であるように、王は百の軍の長であり正しく徴税した。ハラ（シヴァ）がマハーセーナを伴いマーラを退けたように、王は大軍を従え障害を退けた。メール山が神々の住処でありヴィシュヴァカルマンの拠り所であるように、王は賢者の住処であり万人の営みの拠り所であった。太陽が施しを好み影の苦しみを除くように、王は惜しみなく与え悲嘆を除いた。カーマ神がアニルッダに繁栄をもたらしラティに歓楽を与えるように、王は妨げなき繁栄を生み交わりの喜びを与えた。
ヴィディヤーダラ（半神）でありながら善き心を持ち、ドゥリタラーシュトラ（盲目王）でありながら美徳を愛し、忍耐に従いながらも正法の庇護を求め、ブリハンナラーの力を持ちながらも内に誠実であり、水牛の后から生まれながらも正義を生み出し、軽薄ならざる偉大な指導者であった。その名を王チンターマニ（如意宝珠）という。
2) yatra ca śāsati dharaṇimaṇḍalaṃ chalanigrahaprayogā vādeṣu, nāstikatā cārvākeṣu, kaṇṭakayogo niyogeṣu, parīvādo vīṇāsu, khalasaṃyogaḥ śāliṣu, dvijihvasaṅgṛhītir āhituṇḍikeṣu, kara[cchedaḥ kḷptakara]grahaṇeṣu, netrotpāṭanaṃ munīnāṃ, rājaviruddhatā paṅkajānāṃ, sarvabhaumayogo diggajānāṃ, śūlasaṃyogo yuvatiprasave, agnitulāśuddhiḥ suvarṇānāṃ, duḥśāsanadarśanaṃ bhārate, karapatradāraṇaṃ jalajānāṃ, param evaṃ vyavasthitam | mahāvarāho gotroddharaṇapravṛtto 'pi gotroddalanam akarot | rāghavaḥ pariharann api janakabhuvaṃ janakabhuvā saha vanaṃ viveśa | bharato 'pi rāmadarśitabhaktir api rājye virāmam akarot | nalasya damayantyā militasyāpi punar bhūparigraho jātaḥ | pṛthur api gotrasamutsāraṇād vistāritabhūmaṇḍalaḥ | itthaṃ nāsti vāgavasaraḥ pūrvatararājeṣu |
2) 王が大地を治めていた時代には――〈詭弁と誤謬の行使〉は論争の場にのみあり、日常の欺瞞とは無縁であった。〈無神論〉はチャールヴァーカ（唯物論者）の間にのみあった。〈棘の使用〉は命令の執行にのみあった。〈誹謗〉はヴィーナー（琵琶の爪弾き）にのみあった。〈脱穀場〉は稲にのみ結びつき、悪人との結びつきはなかった。〈二枚舌の捕獲〉は蛇使いの仕事にのみあった。〈手を切ること〉は税の受領にのみあった。〈根を抜くこと〉はムニ（薬草）の木にのみあり、苦行者（ムニ）に目を抜くことはなかった。〈王に逆らう〉のは蓮の花だけであった。〈全地の支配者〉の称は四方の象にのみ用いられた。〈串の苦痛〉は若い女性の出産にのみあった。〈火と天秤の浄め〉は黄金にのみ行われた。〈ドゥッシャーサナ〉は叙事詩マハーバーラタにのみ見られた。〈鋸による裂断〉は蓮にのみあった。このように万事が整っていたのである。
大猪（ヴィシュヌ化身）は〈山〉を持ち上げて〈大地を救済〉したが、〈山〉を切り裂いて〈一族を引き裂き〉もした。ラーマはジャナカの地を離れたにもかかわらず、ジャナカの娘とともに森に入った。バラタはラーマへの献身を示したにもかかわらず、王位を退いた。ナラはダマヤンティーと再会したにもかかわらず、再び大地を支配した。プリトゥもまた一族の追放によって大地を拡張した。このように、以前の王たちについて語り尽くすことはできない。
Rāja-praśaṃsā & Kandarpaketu
王の卓越と王子カンダルパケートゥ
3) sa punar anya eva tyaktasarvapūrvorvīpaticaritaḥ | tathā hi | sarvataḥ kaṭakasaṃcāriṇo gandharvān darśitaśṛṅgonnatiḥ sukhayan na virarāma | sa himālayo nāvaśyāyocchalitaḥ no māyājanmane hitaś ca | asau hi mānī giri sthito vṛṣadhvajaś ca | [asau] sadgatiḥ, avadhūtākhilakāntāraḥ, pāvakāgresaraḥ, na bhogotsukaḥ sumanoharaḥ[ś ca] | sa ratnākaro 'nahimayaḥ, katham agādhaḥ, samaryādaḥ, nodreko 'py asya vismayaḥ, himakarāśrayo 'mṛtamayaḥ, satpātraḥ, tasyācalo na krodhaḥ, mahānadīnaḥ, sapotaḥ sa samudraḥ | [sa candra iva] kṣaṇadānandakaraḥ, kumudavanabandhuḥ, sakalakalākulagṛhaṃ, natārātibalaḥ | [sa samudro] mitrodayahetuḥ, kāñcana śobhāṃ bibhrat, acalādhikalakṣmīḥ sumerur iva | yasya ca ripuvargaḥ sadā pārtho 'pi na mahābhārataraṇayogyaḥ, bhīṣmo 'py aśāntanave hitaḥ, sānucaro 'pi na gotrabhūṣitaḥ | api ca sa triśaṅkur iva nakṣatrapathasthalitaḥ, śaṅkaro 'pi na viṣādī, pāvako 'pi na kṛṣṇavartmā, āśrayāśo ['pi] na dahanaḥ, nāntaka ivākasmād apahṛtajīvanaḥ, na rāhur mitramaṇḍalagrahaṇavardhitaruciḥ, na nala iva kalivilasitavinaṭitaḥ, na cakrīva śṛgālavadhastutisamullasitaḥ, nandagopa iva yaśodayānvitaḥ, jarāsandha iva ghaṭitasandhivigrahaḥ, bhārgava iva sadānabhogaḥ, daśaratha iva sumitropetaḥ sumantrādhiṣṭhitaś ca, dilīpa iva sudakṣiṇānugato rakṣitaguś ca, rāma iva janitakuśalavayo rūpocchrāyaḥ |
3) さてこの王は、過去のあらゆる地上の君主たちの事跡を凌駕する、まったく格別の存在であった。すなわち――王はヒマーラヤのようであった。峰の高さを見せて陣営を行き交うガンダルヴァ〈軍馬〉たちを絶えず喜ばせた。霜に揺るがされることなく、幻術の出生にも向かなかった。誇り高い山に住まい、牡牛の旗〈シヴァ〉をも戴いていた。
王は風のようであった。正しき道を行き、すべての荒野〈邪さ〉を払い除け、火を先導し、蛇の享楽に執着せず、花を運んで〈心を〉奪う。王は宝石の鉱山であり大海のようであった。蛇を持たず、測り知れぬ深さがあり、礼節を保ち、溢れても驚かず、月に庇護され甘露に満ち、正しい器であった。王の怒りは山のように不動であり、大河を擁し、船を備えた大海であった。
月のように夜の祭りに喜びをもたらし、睡蓮の園の友であり、あらゆる技芸に満ちた宮殿を持ち、敵の軍勢を屈伏させた。メール山のように友の繁栄の因となり、黄金の輝きを帯び、山々を超える富を持っていた。王の敵は常に〈パールタ〉のようであったが、マハーバーラタの渡河には及ばなかった。〈ビーシュマ〉のようであっても、シャーンタヌの後裔には属さなかった。
さらに王は三星座の如く星の道に安住し、シャンカラでありながら悲哀なく、火でありながら黒い道を歩まず、ヤマのように突然生命を奪うこともなく、ラーフのように友の輪を掴んで輝きを増すこともなかった。ナラのように賭博に翻弄されることなく、チャクリン（ヴィシュヌ）のように豺の殺害を讃えられることもなかった。ナンダゴーパのように栄光〈ヤショーダー〉に伴われ、ジャラーサンディヤのように和戦を巧みに組み合わせ、バールガヴァ（パラシュラーマ）のように常に蛇の財宝を持ち、ダシャラタのようにスミトラーと善き大臣を備え、ディリーパのように吉祥な右遶と牛の守護を持ち、ラーマのようにクシャとラヴァを生んで美と威容を増していた。
tasya ca pārijāta ivāśritanandanaḥ, himālaya iva janitaśivaḥ, mandara iva bhogibhogāṅkitaḥ, kailāsa iva maheśvaropabhuktakoṭiḥ, madhur iva nānārāmānandakaraḥ, kṣīrodamathanodyatamandara iva mukharitabhuvanaḥ, rāgarajjur ivollāsitaratiḥ, īśānabhūtisañcaya iva sandhyocchalitaḥ, śaranmegha ivāvadātahṛdayo viṣṇupadāvalambī ca, pārtha iva samarasāhasocitaḥ, kaṃsa iva kuvalayāpīḍabhūṣitaḥ, tārkṣya iva [vinatānandakaraḥ] sumukhanandana[ś ca], viṣṇur iva kroḍīkṛtasutanuḥ, śāntanava iva svavaśasthāpitakāladharmaḥ, kauravavyūha iva suśarmādhiṣṭhitaḥ, subāhur api rāmānandī, samadṛṣṭir api maheśvaro, muktāmayo 'py ataralamadhyo, jalada iva vimalataravāridhārātrāsitarājahaṃsaḥ, vaṃśapradīpo 'py akṣatadaśaḥ, tanayaḥ Kandarpaketur nāma |
その王には一人の息子がいた。パーリジャータ（天界の珊瑚樹）のように、帰依する者にナンダナ園の喜びを与え、ヒマーラヤのようにシヴァ（吉祥）を生み、マンダラ山のように蛇の環で刻まれ、カイラーサのように大自在天がその頂を楽しみ、マトゥラーのように多くの園に歓びをもたらした。乳海の攪拌に立てられたマンダラ山のように世界を轟かせ、情愛の紐のようにラティ（快楽）を躍動させ、イーシャーナの富の集積のように薄暮に揺れ動き、秋の雲のように清らかな心でヴィシュヌの足跡（天の川）にすがった。
アルジュナのように戦いの武勇に相応しく、カンサのように象クヴァラヤーピーダで飾られ、ガルダのようにヴィナターの喜びでありスムカの息子でもあり、ヴィシュヌのように大地を懐に抱き、ビーシュマのように時と法とを自らの支配下に置き、カウラヴァの軍陣のようにスシャルマンに統率されていた。美しい腕（スバーフ）でありながらラーマの喜びであり、平等な眼差しでありながら偉大な主であり、真珠で作られていながら中心は軽薄でなく、雨雲のように清らかな水の流れで白鳥を驚かせ、家系の灯火でありながら傷なき状態を保った。その名を王子カンダルパケートゥ（愛の旗標）という。
Kumāra-varṇanam — The Prince's Glory

このように語る友に対して、恋の矢に打たれて我を失った王子は、わずかな言葉で答えた。「友よ、ディティ（ダイティヤの母）のように百の怒り〈インドラ〉に満たされるのが善き人の心の在り方だ。今は忠告の時ではない。手足は焼かれるようだ。感覚は煮えたぎるようだ。急所は裂かれるようだ。命は去りゆくようだ。分別は根こそぎにされるようだ。記憶は失われた。さあ今、もしお前が幼い日に砂遊びを共にした同じ苦楽を分かつ者であるなら、私についてきてくれ」と言って、従者たちに気づかれぬまま、友とともに都城を出た。

60) こうしてカンダルパケートゥは、合流したマカランダとともにヴァーサヴァダッターを伴って自らの都に帰り、心に願ったさまざまな情愛の歓びを味わいながら、時を過ごしたのであった。
