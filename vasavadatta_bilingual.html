スバンドゥ作『ヴァーサヴァダッター』（6世紀末頃）は、サンスクリット散文文学（ガディヤ・カーヴィヤ）の最古の作品として知られる恋愛物語である。全編を通じて掛詞（シュレーシャ）が織り込まれた絢爛たる散文で、王子カンダルパケートゥと姫ヴァーサヴァダッターの夢から始まる恋の物語が語られる。

底本: J. M. Shukla 校訂 (Jodhpur, 1966)〔GRETIL〕/ 英訳: L. H. Gray (Columbia UP, 1913) / 注釈: G. S. Rai (Chaukhambha, 1999)

Vāsavadattā
ヴァーサヴァダッター ― スバンドゥ作
Maṅgala — Invocatory Verses
序詩 ― 祈願と詩人論
oṃ namo bhāratyai ||
オーム、弁才天（バーラティー）に帰命す。
karabadarasadṛśam alikhaṃ bhuvanatalaṃ yatprasādataḥ kavayaḥ /
paśyanti sūkṣmamatayaḥ sā jayati sarasvatī devī // 1 //
その恩寵により、鋭い知性を持つ詩人たちが全世界を掌中のナツメの実のように見通す――そのサラスヴァティー女神は勝利する。【1】
khinno 'si muñca śailaṃ bibhṛmo vayam iti vadatsu śithilabhujaḥ /
bharabhugnavitatabāhuṣu gopeṣu hasan harir jayati // 2 //
「お疲れでしょう、山を放してください。私たちが支えます」と牛飼いたちが腕を広げて申し出るとき、その重荷に腕がたわんでいるにもかかわらず、微笑むハリ（クリシュナ）は勝利する。【2】
kaṭhinataradāmaveṣṭanalekhāsandehadāyino yasya /
rājanti valivibhaṅgāḥ sa pātu dāmodaro bhavataḥ // 3 //
固く巻いた紐の跡ではないかと見紛うほどに輝く腰の皺を持つダーモーダラ（クリシュナ）が、汝らを護りたまえ。【3】
sa jayati himakaralekhā cakāsti yasyotsukomayā nihitā /
nayanapratīpakajjalajighṛkṣayā śirasi rajataśuktir iva // 4 //
三日月がその頭上に輝く――ウマーが炎の眼から黒い目墨を拭おうとして額に載せた銀の真珠貝のように。その神（シヴァ）は勝利する。【4】
bhavati subhagatvam adhikaṃ vistāritaparaguṇasya sujanasya /
vahati vikāsitakumudo dviguṇaruciṃ himakarodyotaḥ // 5 //
他者の美徳を広める善き人には、いっそうの幸福が訪れる。睡蓮を花開かせた月の光が、二倍の輝きを帯びるように。【5】
viṣadharato 'py ativiṣamaḥ khala iti na mṛṣā vadanti vidvāṃsaḥ /
yad ayaṃ nakuladveṣī sa kuladveṣī punaḥ piśunaḥ // 6 //
「悪人は毒蛇よりなお始末が悪い」と賢者たちが言うのは嘘ではない。蛇はマングース（ナクラ）を憎むが一族（クラ）は憎まない。しかし悪人は一族をも憎み、中傷する。【6】
atimaline kartavye bhavati khalānām atīva nipuṇā dhīḥ /
timire hi kauśikānāṃ rūpaṃ pratipadyate dṛṣṭiḥ // 7 //
汚れたことをなすにあたって、悪人の知恵はまことに巧みである。闇の中でこそ、梟の目はものの姿を捉えるのだから。【7】
hasta iva bhūtimalino laṅghayati yathā yathā khalaḥ sujanam /
darpaṇam iva taṃ kurute tathā tathā nirmalacchāyam // 8 //
汚れた手で磨けば磨くほど鏡がいっそう清らかに輝くように、悪人が善人を踏みにじろうとすればするほど、善人をいっそう清浄にする。【8】
vidhvastaparaguṇānāṃ bhavati khalānām atīva malinatvam /
antaritaśaśirucām api salilamucāṃ malinim ābhyadhikaḥ // 9 //
他者の美徳を打ち壊す悪人には、きわめて大きな汚れがまとわりつく。月の光を遮った雨雲が、かえっていっそう黒く見えるように。【9】
sā rasavattā nihatā navakā vilasanti carati no kaṅkaḥ /
sarasīva kīrtiśeṣaṃ gatavati bhuvi vikramāditye // 10 //
ヴィクラマーディティヤ王がこの世を去り名声のみを遺したとき、すべての歓びは失われ、鶴は戯れず蒼鷺は飛ばない――涸れた湖のように。【10】
aviditaguṇāpi satkavibhaṇitiḥ karṇeṣu vamati madhudhārām /
anadhigataparimalāpi hi harati dṛśaṃ mālatīmālā // 11 //
その技巧を知らずとも、すぐれた詩人の言葉は耳に蜜の流れを注ぐ。その芳香が伝わらずとも、マーラティーの花輪は目を奪うのだから。【11】
guṇinām api nijarūpapratipattiḥ parata eva saṃbhavati /
svamahimadarśanam akṣṇor mukuratale jāyate yasmāt // 12 //
すぐれた者でも、自らの真価の認識は他者によってこそ生じる。自らの偉大さを目で見るには、鏡の面を用いねばならないのだから。【12】
sarasvatīdattavaraprasādaś cakre subandhuḥ sujanaikabandhuḥ /
pratyakṣaraśleṣamayaprabandhaṃ vinyāsavaidagdhyanidhir nibandham // 13 //
サラスヴァティー女神の恩寵を賜りしスバンドゥ――善き人々のただ一人の友――は、一字一字に掛詞を織り込む構成の巧みさの宝庫ともいうべきこの作品を著した。【13】
Kathā-prārambhaḥ — The Story Begins
物語の始まり ― チンターマニ王の治世
1) abhūd abhūtapūrvaḥ, sarvorvīpaticakracūḍāmaṇiśreṇīśāṇakoṇakaṣaṇanirmalīkṛtacaraṇanakhamaṇiḥ, ṇṛsiṃha iva darśitakaśipukṣetradānavismayaḥ, kṛṣṇa iva kṛtavasudevatarpaṇaḥ, nārāyaṇa iva saukaryasamāsāditadharaṇīmaṇḍalaḥ, kaṃsārātir iva janitayaśodānandasamṛddhiḥ, ānakadundubhir iva kṛtakāvyādaraḥ, sāgaraśāyīvānantabhogīcūḍāmaṇirañjitapādaḥ, varuṇa ivāśāntarakṣaṇaḥ, agastya iva dakṣiṇāśāprasādhakaḥ, jalanidhir iva vāhinīśatanāyakaḥ samakarapracāraś ca, hara iva mahāsenānuyāto nirjitamāraś ca, merur iva vibudhālayo viśvakarmāśrayaś ca, ravir iva kṣaṇadānapriyaś cchāyāsantāpaharaś ca, kusumaketur iva janitāniruddhasaṃpad ratisukhapradaś ca, vidyādharo 'pi sumanāḥ, dhṛtarāṣṭro 'pi guṇapriyaḥ, kṣamānugato 'pi sudharmāśritaḥ, bṛhannalānubhāvo 'py antaḥsaralaḥ, mahiṣīsaṃbhavo 'pi vṛṣotpādī, ataralo 'pi mahānāyakaḥ rājā Cintāmaṇir nāma |
1) かつて、前例のない一人の王がいた。全地上の君主たちの連なりの冠宝石が砥石の角で磨かれ、清められた足の爪の宝石を持つ王であった。人獅子ナラシンハが衣と大地〈ヒラニヤカシプ〉を与えて驚嘆をもたらしたように、王は黄金・食物・衣服・領地を贈って驚嘆を引き起こした。クリシュナがヴァスデーヴァを喜ばせたように、王は神々に〈財宝で〉喜びを与えた。ナーラーヤナが猪の姿で大地を容易く得たように、王は大地の全域を得た。カンサの敵（クリシュナ）がヤショーダーとナンダに繁栄をもたらしたように、王は〈名声〉と〈至福〉の繁栄を生んだ。
海に臥すヴィシュヌが無限の蛇の冠宝石で足を飾るように、王の足は諸侯の冠宝石の光で飾られた。ヴァルナが方位を護るように、王は絶え間なく護った。アガスティヤが南方を浄めたように、王は〈施し〉で美しくした。大海が百の河の主であり鰐の行き来する所であるように、王は百の軍の長であり正しく徴税した。ハラ（シヴァ）がマハーセーナを伴いマーラを退けたように、王は大軍を従え障害を退けた。メール山が神々の住処でありヴィシュヴァカルマンの拠り所であるように、王は賢者の住処であり万人の営みの拠り所であった。太陽が施しを好み影の苦しみを除くように、王は惜しみなく与え悲嘆を除いた。カーマ神がアニルッダに繁栄をもたらしラティに歓楽を与えるように、王は妨げなき繁栄を生み交わりの喜びを与えた。
ヴィディヤーダラ（半神）でありながら善き心を持ち、ドゥリタラーシュトラ（盲目王）でありながら美徳を愛し、忍耐に従いながらも正法の庇護を求め、ブリハンナラーの力を持ちながらも内に誠実であり、水牛の后から生まれながらも正義を生み出し、軽薄ならざる偉大な指導者であった。その名を王チンターマニ（如意宝珠）という。
2) yatra ca śāsati dharaṇimaṇḍalaṃ chalanigrahaprayogā vādeṣu, nāstikatā cārvākeṣu, kaṇṭakayogo niyogeṣu, parīvādo vīṇāsu, khalasaṃyogaḥ śāliṣu, dvijihvasaṅgṛhītir āhituṇḍikeṣu, kara[cchedaḥ kḷptakara]grahaṇeṣu, netrotpāṭanaṃ munīnāṃ, rājaviruddhatā paṅkajānāṃ, sarvabhaumayogo diggajānāṃ, śūlasaṃyogo yuvatiprasave, agnitulāśuddhiḥ suvarṇānāṃ, duḥśāsanadarśanaṃ bhārate, karapatradāraṇaṃ jalajānāṃ, param evaṃ vyavasthitam | mahāvarāho gotroddharaṇapravṛtto 'pi gotroddalanam akarot | rāghavaḥ pariharann api janakabhuvaṃ janakabhuvā saha vanaṃ viveśa | bharato 'pi rāmadarśitabhaktir api rājye virāmam akarot | nalasya damayantyā militasyāpi punar bhūparigraho jātaḥ | pṛthur api gotrasamutsāraṇād vistāritabhūmaṇḍalaḥ | itthaṃ nāsti vāgavasaraḥ pūrvatararājeṣu |
2) 王が大地を治めていた時代には――〈詭弁と誤謬の行使〉は論争の場にのみあり、日常の欺瞞とは無縁であった。〈無神論〉はチャールヴァーカ（唯物論者）の間にのみあった。〈棘の使用〉は命令の執行にのみあった。〈誹謗〉はヴィーナー（琵琶の爪弾き）にのみあった。〈脱穀場〉は稲にのみ結びつき、悪人との結びつきはなかった。〈二枚舌の捕獲〉は蛇使いの仕事にのみあった。〈手を切ること〉は税の受領にのみあった。〈根を抜くこと〉はムニ（薬草）の木にのみあり、苦行者（ムニ）に目を抜くことはなかった。〈王に逆らう〉のは蓮の花だけであった。〈全地の支配者〉の称は四方の象にのみ用いられた。〈串の苦痛〉は若い女性の出産にのみあった。〈火と天秤の浄め〉は黄金にのみ行われた。〈ドゥッシャーサナ〉は叙事詩マハーバーラタにのみ見られた。〈鋸による裂断〉は蓮にのみあった。このように万事が整っていたのである。
大猪（ヴィシュヌ化身）は〈山〉を持ち上げて〈大地を救済〉したが、〈山〉を切り裂いて〈一族を引き裂き〉もした。ラーマはジャナカの地を離れたにもかかわらず、ジャナカの娘とともに森に入った。バラタはラーマへの献身を示したにもかかわらず、王位を退いた。ナラはダマヤンティーと再会したにもかかわらず、再び大地を支配した。プリトゥもまた一族の追放によって大地を拡張した。このように、以前の王たちについて語り尽くすことはできない。
Rāja-praśaṃsā & Kandarpaketu
王の卓越と王子カンダルパケートゥ
3) sa punar anya eva tyaktasarvapūrvorvīpaticaritaḥ | tathā hi | sarvataḥ kaṭakasaṃcāriṇo gandharvān darśitaśṛṅgonnatiḥ sukhayan na virarāma | sa himālayo nāvaśyāyocchalitaḥ no māyājanmane hitaś ca | asau hi mānī giri sthito vṛṣadhvajaś ca | [asau] sadgatiḥ, avadhūtākhilakāntāraḥ, pāvakāgresaraḥ, na bhogotsukaḥ sumanoharaḥ[ś ca] | sa ratnākaro 'nahimayaḥ, katham agādhaḥ, samaryādaḥ, nodreko 'py asya vismayaḥ, himakarāśrayo 'mṛtamayaḥ, satpātraḥ, tasyācalo na krodhaḥ, mahānadīnaḥ, sapotaḥ sa samudraḥ | [sa candra iva] kṣaṇadānandakaraḥ, kumudavanabandhuḥ, sakalakalākulagṛhaṃ, natārātibalaḥ | [sa samudro] mitrodayahetuḥ, kāñcana śobhāṃ bibhrat, acalādhikalakṣmīḥ sumerur iva | yasya ca ripuvargaḥ sadā pārtho 'pi na mahābhārataraṇayogyaḥ, bhīṣmo 'py aśāntanave hitaḥ, sānucaro 'pi na gotrabhūṣitaḥ | api ca sa triśaṅkur iva nakṣatrapathasthalitaḥ, śaṅkaro 'pi na viṣādī, pāvako 'pi na kṛṣṇavartmā, āśrayāśo ['pi] na dahanaḥ, nāntaka ivākasmād apahṛtajīvanaḥ, na rāhur mitramaṇḍalagrahaṇavardhitaruciḥ, na nala iva kalivilasitavinaṭitaḥ, na cakrīva śṛgālavadhastutisamullasitaḥ, nandagopa iva yaśodayānvitaḥ, jarāsandha iva ghaṭitasandhivigrahaḥ, bhārgava iva sadānabhogaḥ, daśaratha iva sumitropetaḥ sumantrādhiṣṭhitaś ca, dilīpa iva sudakṣiṇānugato rakṣitaguś ca, rāma iva janitakuśalavayo rūpocchrāyaḥ |
3) さてこの王は、過去のあらゆる地上の君主たちの事跡を凌駕する、まったく格別の存在であった。すなわち――王はヒマーラヤのようであった。峰の高さを見せて陣営を行き交うガンダルヴァ〈軍馬〉たちを絶えず喜ばせた。霜に揺るがされることなく、幻術の出生にも向かなかった。誇り高い山に住まい、牡牛の旗〈シヴァ〉をも戴いていた。
王は風のようであった。正しき道を行き、すべての荒野〈邪さ〉を払い除け、火を先導し、蛇の享楽に執着せず、花を運んで〈心を〉奪う。王は宝石の鉱山であり大海のようであった。蛇を持たず、測り知れぬ深さがあり、礼節を保ち、溢れても驚かず、月に庇護され甘露に満ち、正しい器であった。王の怒りは山のように不動であり、大河を擁し、船を備えた大海であった。
月のように夜の祭りに喜びをもたらし、睡蓮の園の友であり、あらゆる技芸に満ちた宮殿を持ち、敵の軍勢を屈伏させた。メール山のように友の繁栄の因となり、黄金の輝きを帯び、山々を超える富を持っていた。王の敵は常に〈パールタ〉のようであったが、マハーバーラタの渡河には及ばなかった。〈ビーシュマ〉のようであっても、シャーンタヌの後裔には属さなかった。
さらに王は三星座の如く星の道に安住し、シャンカラでありながら悲哀なく、火でありながら黒い道を歩まず、ヤマのように突然生命を奪うこともなく、ラーフのように友の輪を掴んで輝きを増すこともなかった。ナラのように賭博に翻弄されることなく、チャクリン（ヴィシュヌ）のように豺の殺害を讃えられることもなかった。ナンダゴーパのように栄光〈ヤショーダー〉に伴われ、ジャラーサンディヤのように和戦を巧みに組み合わせ、バールガヴァ（パラシュラーマ）のように常に蛇の財宝を持ち、ダシャラタのようにスミトラーと善き大臣を備え、ディリーパのように吉祥な右遶と牛の守護を持ち、ラーマのようにクシャとラヴァを生んで美と威容を増していた。
tasya ca pārijāta ivāśritanandanaḥ, himālaya iva janitaśivaḥ, mandara iva bhogibhogāṅkitaḥ, kailāsa iva maheśvaropabhuktakoṭiḥ, madhur iva nānārāmānandakaraḥ, kṣīrodamathanodyatamandara iva mukharitabhuvanaḥ, rāgarajjur ivollāsitaratiḥ, īśānabhūtisañcaya iva sandhyocchalitaḥ, śaranmegha ivāvadātahṛdayo viṣṇupadāvalambī ca, pārtha iva samarasāhasocitaḥ, kaṃsa iva kuvalayāpīḍabhūṣitaḥ, tārkṣya iva [vinatānandakaraḥ] sumukhanandana[ś ca], viṣṇur iva kroḍīkṛtasutanuḥ, śāntanava iva svavaśasthāpitakāladharmaḥ, kauravavyūha iva suśarmādhiṣṭhitaḥ, subāhur api rāmānandī, samadṛṣṭir api maheśvaro, muktāmayo 'py ataralamadhyo, jalada iva vimalataravāridhārātrāsitarājahaṃsaḥ, vaṃśapradīpo 'py akṣatadaśaḥ, tanayaḥ Kandarpaketur nāma |
その王には一人の息子がいた。パーリジャータ（天界の珊瑚樹）のように、帰依する者にナンダナ園の喜びを与え、ヒマーラヤのようにシヴァ（吉祥）を生み、マンダラ山のように蛇の環で刻まれ、カイラーサのように大自在天がその頂を楽しみ、マトゥラーのように多くの園に歓びをもたらした。乳海の攪拌に立てられたマンダラ山のように世界を轟かせ、情愛の紐のようにラティ（快楽）を躍動させ、イーシャーナの富の集積のように薄暮に揺れ動き、秋の雲のように清らかな心でヴィシュヌの足跡（天の川）にすがった。
アルジュナのように戦いの武勇に相応しく、カンサのように象クヴァラヤーピーダで飾られ、ガルダのようにヴィナターの喜びでありスムカの息子でもあり、ヴィシュヌのように大地を懐に抱き、ビーシュマのように時と法とを自らの支配下に置き、カウラヴァの軍陣のようにスシャルマンに統率されていた。美しい腕（スバーフ）でありながらラーマの喜びであり、平等な眼差しでありながら偉大な主であり、真珠で作られていながら中心は軽薄でなく、雨雲のように清らかな水の流れで白鳥を驚かせ、家系の灯火でありながら傷なき状態を保った。その名を王子カンダルパケートゥ（愛の旗標）という。
Kumāra-varṇanam — The Prince's Glory

5) さてある夜、夜警の番が過ぎた頃、凝乳のように白い月が――夜の女神の酒杯のように、メーナカーの爪磨きの水晶の欠片のように――西山を枕に安らかに頭を沈め、夜の花嫁の耳飾りのように残りの蜜を飲みつつ、巻貝の光沢を帯びて西海の水に沈みゆくとき、蜜蜂が冷たい露で固まった睡蓮の花粉のただ中に足を捉えられ、マイナー鳥たちが愛のささやきに驚いた女たちのように目覚め、僧院では修行僧たちが学習に勤しみ、街路では吟遊詩人たちが詩歌の物語を唱え、灯火は夜通し吸い尽くした闇のあまりの薄さにもはや耐えきれぬかのように墨の装いのもとに吐き出し、情人たちの歓楽の様を見るためとばかりに幾百もの窓から首を伸ばして疲れ果て、さまざまな住居での色とりどりの情事を目撃し、庇護を求める者のように下に潜む闇を守り――
灯火は――悪人の言葉のように〈愛情〉が燃え尽きて鈍くなり、極めて老いた者のように〈灯心〉の終わりに達し、没落した貴人のように〈器〉だけが残り、夜中に徘徊する〈羅刹〉のように家の奥に置かれ、西山の頂に〈太陽〉が落ちるように〈蛾〉が飛び回り――絶え間なく滴る蜜の滴りに酔った蜜蜂の群れの羽音に満ちていた閨房の花飾りが萎れゆき、ほつれた髪からクンダの花が零れ落ち、恋人との別離の悲しみに涙の滴を流すかのように、芽のような足先の足環を鳴らしながら愛しき人の旅立ちを引き留めるかのような美女たち――
夜の残りの情事の疲れにほつれた髪に絡まる半開きのマーラティー花の香りに誘われて群がる騒がしい蜜蜂の羽の風に汗の霧は乾き、震える腕を振り上げて腕輪を美しく鳴らし、新しい爪痕に絡む髪が引き裂かれる痛みに歯ぎしりして漏れ出る白い歯の光で閨房を照らし、再会を尋ねる侍女たちに絶えず恋人の姿を見つめさせ、夜の情事の恥ずべき百の言葉を思い出す家鸚鵡の愛嬌ある囀りにふと恥じらい目を伏せる美女たち――秋の日の美のように〈爪で飾られた乳房〉を持ち、死に瀕した者のように〈命の主〉の都に顔を向け、春の森のように〈不安〉に満ち、恋人たちに抱かれる美女たちのなか、花の蕊を揺らし花粉を奪い合う蜜蜂たちのざわめきが満ちた睡蓮の池に歓喜が溢れ、恋人なき女たちからは幸福が去り、カーマ神が火神のように四方に籾殻の火の粉をまき散らし、遠くチャクラヴァーカ鳥の伴侶へと吹くそよ風のなか――
そのとき王子は夢の中にひとりの乙女を見た。その腰は――腿の歓楽の都の門のような、マンマタの大宝庫の黄金の城壁のような、産毛の蔓が這う溝のような、天空の月輪の暈のような、三界征服を讃える産毛の碑文の黄金板のような、万人の心を囚える獄舎の堀のような、世の人々の視線という鳥の群れの止まり木の横木のような腰帯の紐で飾られていた。
高く盛り上がった乳房の重みに月のような顔が隠されて見えぬ嘆きに満ちたかのような、乳房の壺と重い臀部の圧迫に疲れ果てたかのような、重い臀部に深い恨みを抱いたかのような、造物主が力を込めて締め付けた手の苦痛に極めて細くなった腰で飾られ、「この乳房が私の上に落ちたらどうしよう」と心配するかのように細くなった腰で飾られていた。
情熱の宝石で満ちた黄金の宝函のような、乳首を封印とし、その巨大な周囲ゆえに落下を恐れて乳首の装いで造物主に釘止めされたかのような、全身を浄めた後に残った美の余滴のような、心の池の蓮華のような、恋情の戯れの枕のような、産毛の蔓の実のような、カンダルパの誇りを増す魅了の粉で満ちた小箱のような、万人の心の陥落で重い、輪廻の大樹の実、若さの大樹の産物であり、真珠の首飾りを蓮茎とするチャクラヴァーカ鳥のような、産毛の列と首飾りが合流するプラヤーガの聖樹の実のような、三界征服に疲れたマカラの旗を持つ神の隠れ家のような二つの乳房で輝いていた。
月のような顔に親しく寄り添う夕焼けの輝きを帯び、歯の宝石を守る朱の印章を持ち、心の情熱が滲み出て赤く染まったかのような、情熱の海の珊瑚の新芽のような下唇で美しかった。若いケータカの花弁よりも長く、物憂げに揺れる睫毛を持ち、心の奥に住む恋の神の出窓かと疑わせ、情熱に満ちながらも涅槃をもたらし、さらなる伸張を妨げる耳への怒りで端が赤く、世界をあまねく白く照らすかのような、花咲く蓮の森で天空を荘厳するかのような、幾千もの乳海を吐き出すかのような、クンダ花と青蓮の花冠の美を嘲笑う双眸で飾られていた。
歯の宝石の秤の柱たる、眼という海に架かる橋たる、若き情熱に狂う二頭の象の仕切り壁たる鼻で整えられ、眼の青蓮に群がる蜜蜂のような、恋の神の住まう顔の門のような、情熱の海の岸辺のような、若々しい踊りに酔う眉で飾られていた。雨季の空のように美しく盛り上がった〈雲〉のような乳房を持ち、勝利の凱歌を得た者のように震える〈秤〉の先端に立ち、スヨーダナの武勇のように〈カルナ〉に眼を休ませ、矮人ヴァーマナの遊戯のように〈バリの滅亡〉を示し、蠍座の太陽のように〈処女と天秤〉を超え、ウシャーのように〈アニルッダ〉の姿に悦び、シャチーのように〈インドラの遊園〉を眺め、パシュパティの踊りのように〈震える蛇〉のような美しい眼と耳を持ち、森のように聳える黒い〈パンノキ〉のような乳房を持ち、スグリーヴァの軍のように〈美しい喉と腕輪〉で飾られていた。

7) さて、王子の親友マカランダが何とか面会の許しを得て、愛の神の矢に打たれて我を失っているカンダルパケートゥに語りかけた。「友よ、なぜこのような不適切な、善からぬ者にふさわしい振る舞いをしているのだ。お前のこの振る舞いを見て、善き人々は困惑の揺り篭に揺れ、悪しき者たちは不快で不作法だと決めつける。悪人の心は不快なものの暴露にこそ最高の喜びを見出す。誰がこのような者の本性を見抜けようか。すなわち――〈ビーマ〉であっても「バカの敵」ではなく、〈恐ろしい〉者であり「称賛する者の敵」である。〈火〉であっても〈風〉であり、〈己の庇護所を貪り食う〉者であり「母の中の犬」である。極めて〈辛い〉のに「美味」であり、極めて〈残酷〉で「まったく味気ない」。芥子油のように両手で撫でられ頭に載せられても〈辛味〉を棄てぬように、合掌され足元に平伏されても〈苦味〉を棄てぬ。ターラ椰子の実のように最初は〈心地よい〉が最後は不快で「鋭い」。足の塵のように〈払い落とされ〉ても頭を黒く染める。毒樹の実のように〈敬われれば敬われるほど〉「狂気を増す」。〈低い土地〉に〈水〉の不足がないように、「悪行」をもって〈敵〉に事欠かぬ。夏の日が〈花〉に「蚋の群れ」で苦痛を与えるように、〈善き人々〉に「激しい嫉妬」で苦痛を与える。〈シヴァ〉であっても「ヴィシュヌ」であり、〈王〉でありながら「不作法な行い」をする。〈聾〉にして「臣下を称えず」、インドラの馬のように〈嘶き〉て「海から生まれたことを誇る」。善き人の心をかき乱す、〈分離しても〉「愛情を示す」撹拌棒が乳脂の心をかき乱すように。ヤクシャへの供物のように〈自賛〉に喧しく「世の彷徨い」を語る。狂象のように歪んだ顔で〈雌〉を見つめ「酒液」を抑える。〈神の恐れに怯えぬ〉こと牛が〈牝牛との交わりに疲れる〉のと同じ。〈家名の恥辱に惨め〉でありながら「悪しき道」に身を捧げる。〈柔らかく優れた〉話に遅滞をもたらす、消化不良が〈身体〉と言葉に遅滞をもたらすように。〈死体の肉〉と「夜」に身を捧げる山犬のように、〈約束の破壊〉と「主の敵」に身を捧げる。〈善き運〉を滅ぼす、斧が〈白檀〉を断つように。〈大地を割り〉「土に生きる者」を断つ鋤のように、〈一族を滅ぼし〉「忍耐ある人々」を断つ。〈交尾する〉犬のように「卑しい行い」に耽り善き人を恥じ入らせる。〈髪と顔の美〉のすべてを持ちながらも「琴に巧みでありながら」楽しまぬ、狂象が〈森を楽しみ〉ながら「広がる緑を楽しまぬ」ように。悪徳の芽は種なくして生え、株なくして伸び、引き抜き難い。不義の一片が悪人の心に入れば恐ろしいことになる。だが善き者の心にはそもそも入らず、万が一入っても水銀のように一瞬たりとも留まらぬ。鹿のように善き者は快楽を知る者の声に従う。あなたのような方々は秋の季節のように友の心を容易く捕らえる。心ある者は不適切な忠告はせず、愚か者の友情は利に傾く。心なき物の間にさえ、友情は適切な側に置かれる。すなわち乳の甘さ・冷たさ・清さ・熱の鎮めのゆえに水は自らを『乳と同じだ』と思い込んで友情に入ったが、『かつて自分と混ざることで増えた乳の煎じにより、破滅が来た』と考えて、水自身によって滅ぼされるのである。これは不適切な振る舞いだ。友よ、善き人にふさわしい道を取れ。善き者でも迷いのゆえに道を外れることがあるのだから」
このように語る友に対して、恋の矢に打たれて我を失った王子は、わずかな言葉で答えた。「友よ、ディティ（ダイティヤの母）のように百の怒り〈インドラ〉に満たされるのが善き人の心の在り方だ。今は忠告の時ではない。手足は焼かれるようだ。感覚は煮えたぎるようだ。急所は裂かれるようだ。命は去りゆくようだ。分別は根こそぎにされるようだ。記憶は失われた。さあ今、もしお前が幼い日に砂遊びを共にした同じ苦楽を分かつ者であるなら、私についてきてくれ」と言って、従者たちに気づかれぬまま、友とともに都城を出た。

20) 遠くまで広がった蜜〈春〉によって、この世の誰が変化しないであろうか。〈解脱した（アティムクタ）〉聖者でさえも花を咲かせたのだから――〈アティムクタ蔓〉が花開いたように。花の弓を持つ愛の神の新しいマンゴーの矢の根元に隠れた蜜蜂の列は、その矢羽のようであった。茎から出たジャスミンの隙間に潜む唸る蜜蜂は、マカラの旗を持つカーマ神の三界征服の法螺貝の音を鳴らすかのようであった。新しいラック染料の泥で化粧された足輪をつけた若い女性の足の蹴りへの愛着のゆえに、新芽を装ってその同じ赤い色を帯びたアショーカの樹。甘い蜜の響きを立てる美女の口という蓮に親しむ愛着から、その汁を自らの花に湛えたバクラの樹（ミモザ）が輝いた。蜜蜂の群れが間々に落ちて黒い点となったカンケーリー（アショーカ）の花の房は、半ば消えたマノーバヴァ（カーマ神）の火葬の薪の輪のような姿で、旅人の心を焼いた。花咲くジャスミンの列と蜜蜂の群れを持つ春の美しさは、真珠とインドラニーラ（サファイア）の首飾りのように輝いた。ナーガケーサラ（鉄木）の花は、離別に苦しむ女たちの心を攪拌するための花の矢を持つ神（カーマ）の車輪のようであった。パータリー（トランペット・フラワー）の花は、旅人の心という魚を捕えるための花の弓を持つ神（カーマ）の釣り針のように見えた。

40–41) やがて、シヴァ神の喜びの力を持つ王子は、ヴァーサヴァダッターの館を見た。壁に囲まれ――首都の一画に雲をつく棟を築き、漆喰で白く輝き、金・真珠・エメラルド・ルビーが一つ一つ嵌め込まれ、ヴァーサヴァダッターを見るために集まった天の群れのように宝石の冠を戴いていた。風にたなびく旗は天の木の花房のように空の美を嘲笑い、樟脳・白檀・紅花・エーラーの香水で芳しい流れが黄金の石畳の中庭を巡り、宮殿の鳩が岸辺も知られぬ水晶の板の上で安らかに眠り、崩れゆく岸辺の樹木の花で水面が飾られていた。
若き女たちの確かな臀部の打ち寄せに飛沫が跳ね上がる石段は絶えず濡れ、樟脳の流れが造る砂洲にラージャハンサ鳥がその鳴き声から居場所を推し量られ、花開く青蓮の園には突然チャクラヴァーカ鳥が闇の恐怖を覚え、若き女のように美しい水を湛え、スグリーヴァの戦闘技のようにクンバカルナを血に浸し、美女の足の粉で岸辺が彩られ――その宮殿は見る者の目を惹きつけ、黒檀の香の煙が時ならぬ雲の立ち上りを見せ、太鼓の深い響きに孔雀が静かに舞い踊り、夕暮れのように世の人々の目を降りさせ、ジャナカの祭祀の場のように〈妻を恋するラーマ〉を想わせ、歓喜の宝庫のような、情愛の住まいのような、戯れの宮殿のような、美の集合の地のようであった。
侍女たちの互いに親しげな会話を聞いた。「ニガリターよ、走るのが上手ね！ チャパラーはふらふらしている！ お前の耳から花房が落ちたわよ」「スレーカーよ、神々にも乞われる美しさのお前は酒に酔っているわ」「カラハーよ、黄金の腰帯の甘い響きでカーマの神を呼び寄せるわよ」「マラヤーよ、一瞥でカーマの意志を見抜いたのね」「カリカーよ、その騒がしい腰帯を外しなさい。闘争の旗よ。ヴィーナーの微かな甘い音が聞こえるでしょう」「腰帯は迷惑じゃない。お前こそが口うるさいのよ」「アヴァンティセーナーよ、この愚かな娘は花を捧げるときにそこで転ぶのが恐いのね」「ラヴァンギカーよ、もうお前の嘘はたくさん！ 震えがお前の胸の内を明かしているわ」
「アナンガレーカーよ、お前のだるい体はカーマの矢の傷を負っているかのよう。お前の不安の大波は確かに隠されているわ！ 言いなさい、顔に月の比喩が当てはまるか、その目の美しさで飲み干されるべき顔に」「サティーヴラターよ、誰かがお前の心に住んでいるようね。お前の言葉はインドラの雷の百の刃のような鋭さで感じられるわ」「ケーラリカーよ、城門の近くで歌声が聞こえるわ。何を企んでいるの？ 瞬く間に目を閉じて」「ムラリーよ、乳房を打つ歓びを得て、愛の苦悩を払い、今はあの人と離れて――なぜ惑うの？ 恋人はお前の技を、情の悦びを思い出しているわ。新しく切られた爪の傷は、情熱の夜に痛みを生じさせないの？」

52) やがて秋の始まりとなった。鶺鴒は跛でなく〈自在に歩き〉、鶴は歩みを妨げられず、小枝はバラドゥヴァージャ鳥（ヒバリ）の騒がしいさえずりに満ち、夜明けの光はひときわ強く輝き、稲田には放し飼いの鸚鵡の群れが行き交い、ラージャハンサ鳥（フラミンゴ）が客として迎えられ、空はカンサの敵（クリシュナ）の体の色のように青く、古びた雲は鵞鳥の綿毛のように白く、犬たちは強まった発情に喜び、甘い甘蔗の若芽が伸び、湖にはサーラサ鶴の美しい声の精髄が響き渡り、猪の子や孫の鼻先で堤が掘り返された池にはカシェール草の美しい根が露わになり、驚いたチャータカ鳥がおり、さまよう魚鷹（マーシャプトリカー）鳥の群れの甘い鳴き声が喜びをもたらし、カダンバの木は蔑まれ、法螺貝の敵たる〈秋〉であり、蓮は花弁を広げ、雲はまばらになり、星はひときわ明るく輝き、月は美しく大いなる歓喜をもたらし、池の水はいつにも増して甘く、動かぬ鶴の群れが輝くシャファラ魚の群れを飲み込み、蛙の群れは沈黙し、蛇は萎び縮み、稲穂は黄金の粒で黄色く輝き、ミサゴが甲高く叫び、芳しい白蓮の香りで大気は心地よく、クムダ（白い睡蓮）の芳香が漂い、月光は魅力的であり、孔雀は尾羽が抜け落ち、コーヤシュティカ鳥が低く鳴き、ダールタラーシュトラ鵞鳥が現れ、稲の番をする娘たちの歌に鹿の群れは喜び、ユーティカー・ジャスミンは枯れ、マーラティー（マラバル・ジャスミン）の蔓の蕾は萎れ、バンドゥーカの花の親族のような〈秋〉であり、美しさが生まれ、スートラーマン（インドラ）の弓〈虹〉を打ち砕き、微笑むサフランの花粉の塊で十方が黄色く染まり、蓮が花開く中――カンダルパケートゥはさまよい歩き、石の像を見つけて、好奇心と、狂気と、悲しみと、激情から「これは私の愛しい人に似ている」と手で触れた。
Punar-milana — Reunion
再会と結末
53) anantaraṃ spṛṣṭamātrā sā śilāmayīṃ mūrtim utsṛjya, punar Vāsavadattā svarūpam āpede | tām avalokya Kandarpaketur amṛtārṇavamagna iva suciram āliṅgya papraccha | "priye kathaya kim idaṃ vṛttāntam" |
53) 触れるやいなや、その像は石の姿を脱ぎ捨て、再びヴァーサヴァダッターが元の姿に戻った。彼女を見たカンダルパケートゥは甘露の海に沈んだかのように長く抱きしめてから尋ねた。「愛しき人よ、語っておくれ。これはいったいどういうことなのか」と。
54) sā tu dīrgham uṣṇaṃ ca niḥśvasya kathayitum ārebhe | "āryaputrāpuṇyāyā mama mandabhāginyāḥ kṛte mahābhāga ujjhitarājya" iti ekākī jana iva vāṅmanasayor agocaraṃ duḥkham anubhūtavān | anekadivasān āhāraśūnyatayā kṛśataro nidrānte yadi kadācit phalamūlādikaṃ milati, tadā śarīrasthitiṃ karotīti vicintya phalānveṣaṇāyopavanatarūn avalokayantī katipayanalvagocaram agaccham |
54) 姫は長く熱い溜息をついてから語り始めた。「不幸なこの私、薄命の者のために、高貴な御方は王位を捨てて、言葉にも心にも及ばぬ苦しみを独りの人間のように経験なさいました。何日も食事をとらずにますます痩せ細り、眠りから覚めてもし果物や根菜が見つかればそれで体をもたせるのだと思い、果物を探して園の木々を見渡しながら、私は数ナルヴァほど離れた所に行きました。
55) krameṇa ca gulmāntaritakriyamāṇakāyamānikaṃ, viracyamāneśvaragṛhaṃ, avatāryamāṇakaṇṭhālakaṃ, ārabhyamāṇapaṭukaṭukaṃ, vyavasthāpyamānaveśyāsaṃniveśaṃ, śrūyamāṇaturagaheṣāravaṃ, vādyamānaviśrāmaḍhakkāpuṣkaraṃ, anviṣyamāṇasvādusalilāśayaṃ, uddiśyamānavipaṇiketuvāṃśaṃ senāsanniveśam apaśyam | tam avalokyāham acintayam | "kim ayaṃ mamānveṣaṇāya tātasya vyūha āhosvid āryaputrasya vāhinīsambhāra" iti cintayantyāṃ mayi paricārakakathitodanto mām uddiśya senāpatir dhāvitaḥ | tato 'nantaraṃ kirātasainyasenāpatis tādṛśa eva senāsamanvito mṛgayāvyājenāgataḥ so 'pi dāvitaḥ |
55) やがて茂みに隠れて設営される仮屋があり、将軍の館が整えられ、荷が降ろされ、天幕が張られ、遊女の宿舎が設けられ、馬のいななきが聞こえ、休止の太鼓が打たれ、甘い水場が探され、市場の旗が掲げられる――軍営を目にしました。それを見て私は考えました。『これは私を探しに来た父の軍か、それとも御方の軍隊か』と。考えているうちに、偵察兵から知らせを受けた将軍が私のもとに駆けつけてきました。続いてまた同じように軍を率いたキラータ族の軍の将軍が、狩りを口実にしてやって来ました。
56) anantaraṃ cintitaṃ mayā | "yady aham āryaputrāya kathayāmi tadaikāky ebhir avaśyam eva hantavyaḥ | atha na kathayāmi tadāham evaibhir hantavyeti" cintākṣaṇa eva dvayoḥ sainyayor yuddham abhūd ekāmiṣābhiyuktayor gṛdhrayor iva | tataḥ pravṛttapratiśarāsāradurdinahṛtadinakarakiraṇe, rathakarmaviśāradadviradakaradūrotkṣiptakhaḍgadharasubhaṭaśliṣyamāṇavidyādharavibhrame, samaradarśanasañcaradanekanabhaścaracāraṇacakravāle, vetālasamākrāntaskandhakabandhacakrakriyamāṇacārupracāre, cārabhaṭakhaḍgakhaṇḍitadviradapādasamāptapiśācīkarṇolūkhalābharaṇakautuke, samutphullaphalakini, nadannāndīke, kāndiśīkabhīruṇi raṇakhale, sṛgālīprārthanīyeṣv āmiṣapiṇḍeṣv iva vatsadantakṣateṣu tṛṇeṣv iva, jihmagadaṣṭeṣv iva śarīreṣv anāsthāṃ kalayantaḥ samaṃ dviṣāṃ dhanuṣāṃ ca jīvākarṣaṇaṃ cakruḥ |
56) 私は考えました。『もし御方にこのことを告げれば、独りきりの御方は必ずこの者たちに殺される。告げなければ、私自身がこの者たちに殺されるだろう』と。思案するまさにその瞬間に、一つの獲物を争う二羽の禿鷹のように、二つの軍隊の間に戦いが始まりました。対する弓の激しい矢の雨雲で太陽の光が遮られた戦場で、戦いの技に長けた象の牙に高く投げ上げられた勇猛な武者にしがみつくヴィディヤーダラたちがさまよい、戦いを見物に集まる天の吟遊詩人（チャーラナ）の輪が無数に広がり、ヴェーターラに取り憑かれた首なし胴体の群れが不気味に歩き回って親しげな振る舞いを見せ、兵士の剣で切り落とされた象の足で満たされた臼が鬼女（ピシャーチー）の耳飾りとなることを望まれ、盾は打ち鳴らされ、祝福の叫びが轟き、怯えたジャッカルが走り回る――その戦場の脱穀場で、戦士たちはジャッカルの望む肉の塊のように、あるいは蛇に噛まれたかのように体を顧みず、〈敵〉と〈弓〉の両方から同時に〈命〉と〈弦〉を引き絞った。
57-58) 57) tyāgina iva dānavanto mārgaṇasantāpam asahantaḥ mahāmṛgā utkupitā iva kṣamāṃ muñcantas turagā rejuḥ | karṇābhyāṃ paraparivādaśravaṇakutūhalibhyāṃ, netrābhyām ālokitasādhuvipattibhyāṃ, mūrdhnā cāsthāne praṇamatā "tyakto 'ham" iti harṣād eva nanarta ciraṃ kabandhaḥ | 58) tataḥ parihāseneva cakṣuṣī pidadhatā parāpavādaśravaṇāruṇeva śrotravṛttiṃ sthagayatā, sonmādeneva vāyuvegavikṣiptena, palitaṅkaraṇeneva surayoṣitāṃ, andhaṃkaraṇeneva yodhānāṃ, timireṇeva samarapradoṣasya, patiteneva vimuktagotreṇa, mīmāṃsakadarśaneneva tiraskṛtadigambaradarśanena, satpuruṣeṇeva viṣṇupadāvalambinā samarajena rajasā jajṛmbhe | tatra samarasambhāre kaścid āśaṅkitorubhaṅgaḥ suyodhana iva yodhaḥ payasi viveśa | kaścic charatalpaśayo bhīṣma iva cirāya śvasann āsīt | kaścit karṇa iva viklavībhūtasarvāṅgaḥ śaktimokṣaṇam akarot | tato vidhvastadhvajapaṭaṃ patatpatākaṃ cyutacāpacāmarāpīḍaṃ skhalatkhaḍgadhenukaṃ tatsamastasainyam anyonyaṃ nidhanam avāpa |
57–58) 強大な象たちは、〈気前よく施す〉施主のように〈矢（マールガナ＝乞う者）〉に会うことに耐えられず〈液（マダ＝施し物）〉を流した。幸運な〈情夫〉のように〈情熱（ラーガ＝朱）〉と黄金の〈帯〉で飾られ、実は〈朱〉と黄金の〈腹帯〉で飾られていた。美しい〈庭園〉のように〈バショウの木（パタターカ＝旗）〉が美しく〈鳥（パクシン＝象）〉に満ち、実は〈旗〉が輝き〈象〉を従えていた。〈夜〉のように〈星座（ナクシャトラ＝真珠）〉の花環で飾られ、〈昼〉のように〈咲く花（プラスフラ＝鼻先の振り）〉を持っていた。馬たちは、分別を失った者のように〈忍耐（クシャマー＝大地）〉を捨て〈大地〉を離れ、〈渦巻き（アーヴァルタ＝巻き毛）〉と波を持つ〈海〉のように〈巻き毛〉を持ち速い足取りであった。〈ダールタラーシュトラ鵞鳥（マッリカークシャ種）〉のいる〈遊園〉のように〈マッリカークシャ種〉を含み、真新しい〈家具（パリチャダ＝馬具）〉の素晴らしい〈名家〉のように真新しい〈馬具〉で飾られ、〈神々の宝石（デーヴァラトナ＝巻き毛）〉を持つ〈鉱山〉のように〈首の巻き毛〉を持ち、〈インドラとともに不動（ドゥリティ＝忍耐）〉なる〈レーカ族〉のように〈最も偉大な主人たち〉を支えた。首なし胴体は長く踊り続けた――まるで「私は解放された！」と喜ぶかのように。他者の悪口を聞く耳から、善き者の不幸を見る目から、不当に頭を下げる頭から解放されたのだと。
やがて戦場の塵が広がった――笑うかのように目を隠し、他者の中傷を聞くことを恐れるかのように耳の働きを覆い、風の動きに狂ったかのように投げ飛ばされ、天女（アプサラス）たちの白髪の因となり、戦士たちの盲目の因となり、戦の黄昏の闇のようであった。〈家（ゴートラ＝大地）〉から切り離されて落ちた者のように〈大地〉から切り離されて舞い上がり、ミーマーンサー学派の教義が〈ジャイナ教徒（ディガンバラ＝裸行者）の教え〉を隠すように〈四方と空（ディシュ＝方角）〉の眺めを隠し、善き人が〈ヴィシュヌの足（パダ＝天頂）〉に縋るように〈天頂〉にまで昇った。ある者はラーマが〈ラーヴァナ〉を縛ったように〈苦悶の姿勢（アーシャンカ）〉をとり、ある者はクリシュナが〈ナラカ（地獄＝悪魔）〉を滅ぼしたように〈地獄〉を裂き、ある者は仏教の教典が〈伝承・教訓・正見（シュルティ・スムリティ・ダルシャナ）〉を否定するように〈聴覚・言語・視覚〉を失い、ある者は異端の苦行者が〈蓆〉に包まれるように〈屍〉に囲まれ、ある者はスヨーダナのように〈腿の骨折（ウルバンガ＝完敗）〉を恐れて水に飛び込み、ある者はビーシュマのように〈矢（シャラ＝葦）〉の寝台で長く息をし、ある者はカルナのように全身が震えて〈槍（シャクティ＝力）〉を放った。こうして旗は倒れ、幟は落ち、弓と払子は砕け、剣は滑り、両軍のすべてが互いに滅びた。
59) anantaraṃ yasyāśramas tena muninā puṣpādikam ādāyāgatena pratipannasarvavṛttāntena "mamāyam āśramo bhagna iti śilāmayī bhaveti" śaptāham | anantaraṃ "varākī bahuduḥkham anubhavatīti" karuṇayāryaputrasya sparśāvadhi śāpāntam akarot |"
59) やがて、そこに庵を持つ聖者が花などを持って帰ってきて、すべての事情を知ると、『この者のせいで私の庵が壊された。ゆえに石になれ』と私に呪いをかけました。しかしその後、『哀れな者よ、多くの苦しみを受けている』と憐れみ、御方の手が触れるまでを呪いの終わりとしてくださったのです。」
60) tataḥ Kandarpaketuḥ samāgatena Makarandena Vāsavadattayā saha svapuraṃ gatvā hṛdayābhilaṣitāni tāni tāni suratasukhāny anubhavan kālaṃ nināya ||
