マハーバーラタ ― カルナ篇 第72章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 72 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ72」、全88詩節からなります。アルジュナが激怒してガーンディーヴァを抜いてユダーマンユを殺そうとするものの、クリシュナが止める場面（第1〜9詩節）、クリシュナが法の秘密を教えバラカとカウシカの物語を語る場面（第10〜88詩節）で本章は終わります。日本語対訳では複数の詩節が一括して翻訳されている箇所があります（第7〜8、第80〜81、第82〜84、第87〜88詩節など）。
karṇaparva — dvisaptatitamo'dhyāyaḥ (72)
第72章　アルジュナの激怒とクリシュナによる法の秘密の教え——バラカとカウシカの物語
sañjaya uvāca|
yudhiṣṭhireṇaixxxxktaḥ kaunteyaḥ śvetavāhanaḥ|
asiṃ jagrāha saṅkruddho jighāṃsurbharatarṣabham||
// 8-72-1 //
サンジャヤは語った。
tasya kopaṃ samājñāya cittajñaḥ keśavastadā|
uvāca kimidaṃ khaṅgaṃ gṛhṇāsyarjuna śaṃma me||
// 8-72-2 //
彼の怒りを心で察知した、心の読めるケーシャヴァ（クリシュナ）はその時言った。「何だこれは、剣を掴むとは、アルジュナよ。私に教えてくれ。」
neha paśyāmi yoddhavyaṃ tvayā kiñcidvanañjaya|
nehāgatā dhārtarāṣṭrāḥ sarve bhīmena vāritāḥ||
// 8-72-3 //
「ここにお前が戦うべき敵は何もいない、ダナンジャヤよ。ドリタラーシュトラの息子たちはここに来ていない。全てビーマに阻まれている。」
upāgato'si kaunteya rājā draṣṭavya ityasau|
sa rājā bhavatā dṛṣṭaḥ kuśalī ca yudhiṣṭhiraḥ||
// 8-72-4 //
「カウンテーヤよ、王に会うべきだと言って来たのだろう。その王、元気なユディシュティラをお前は見た。」
taṃ dṛṣṭvā nṛpaśārdūlaṃ śārdūlasamavikramam|
harṣakāle ca samprāpte kasmāttvāṃ manyurāviśat||
// 8-72-5 //
「虎のような武勇の王を見て、喜ぶべき時に、なぜ怒りがお前を捉えたのか。」
na taṃ paśyāmi kaunteya yaste vadhyo bhavediha|
prahartumicchase kasmātkiṃ vā te cittavibhramaḥ||
// 8-72-6 //
「カウンテーヤよ、ここにお前が殺すべき者は見当たらない。なぜ打とうとするのか。心の錯乱か何かか。」
kasmādbhavānmahākhaṅgaṃ parigṛhṇātyakāraṇāt|
tattvāṃ pṛcchāmi kaunteya kimidaṃ te cikīrṣitam|
parāmṛśasi yatkruddhaḥ khaṅgamadbhutavikrama||
// 8-72-7-8 //
「なぜ理由もなく大剣を掴むのか。カウンテーヤよ、お前に何がしたいのか聞いている。驚異の武勇の者よ、怒って剣に手をかけるとは。」
evamuktaḥ kaṭākṣeṇa prekṣamāṇo yudhiṣṭhiram|
arjunaḥ prāha govindaṃ kruddhaḥ sarpa iva śvasan||
// 8-72-9 //
このように言われて、横目でユディシュティラを見ながら、アルジュナは怒った蛇のように息を荒くしてゴーヴィンダに言った。
anyasmai dehi gāṇḍīvamiti māṃ yaḥ pracodayet|
bhindyāmahaṃ tasya śira ityupāṃśu vrataṃ mama|
yudhiṣṭhireṇa tenāhamuktaścāsmi janārdana||
// 8-72-10 //
「『ガーンディーヴァを他の者に渡せ』と私に言う者があれば、その者の首を切る——これが私の秘密の誓いだ。ユディシュティラにそう言われたのだ、ジャナールダナよ。」
yadukto'hamadīnārthaṃ rājñā'nena yaśasvinā|
samakṣaṃ tava govinda na tatkṣantumihotsahe||
// 8-72-11 //
「この名高い王に、ゴーヴィンダよ、お前の面前で卑劣でない趣旨で言われたことを、私はここで許すことができない。」
tasmādenaṃ vidhiṣyāmi rājānaṃ dharmacāriṇām|
pratijñāṃ pālayiṣyāmi hatvainaṃ narasattamam||
// 8-72-12 //
「だから法を行う者の王を処断しよう。この人中の最上者を殺して誓いを守る。」
etadarthaṃ mayā khahgo gṛhīto yadunandana|
so'haṃ yudhiṣṭhiraṃ hatvā satyasyānṛṇyatāṃ gataḥ|
viśoko vijvaraścāpi bhaviṣyāmi janārdana||
// 8-72-13 //
「そのためにこの剣を私は取ったのだ、ヤドゥの喜びよ。ユディシュティラを殺して、真実の誓いの負債を返済した私は、ジャナールダナよ、悲しみも苦しみもなくなるだろう。」
kiṃ vā tvaṃ manyase prāptamasminkārya upasthite|
tvamasya jagatastāta vettha sarvaṃ gatāgatam||
'jātastvatto hi dharmaścādharmaśceti parā śrutiḥ'|
tattathā prakariṣyāmi yathā māṃ vakṣyate bhavān||
// 8-72-14-15 //
「この事態に際して、お前はどう思うか。お前はこの世の全ての往来を知っている。『法も不法もお前から生じた』と最高の聖典にある。お前が言う通りに私はする。」
sañjaya uvāca|
dhigdhigityeva govindaḥ pārthamuktvābravītpunaḥ||
// 8-72-16 //
サンジャヤは語った。
kṛṣṇa uvāca|
idānīṃ pārtha jānāmi na vṛddhāḥ sevitāstvayā|
akāle puruṣavyāghra saṃrambhaṃ yadbhavānagāt||
// 8-72-17 //
クリシュナは語った。
na hi dharmavigajñairevaṃ kāryaṃ dhanañjaya|
yathā tvaṃ pāṇḍavādyeha dharmabhīruraṇḍitaḥ||
// 8-72-18 //
「法を見分ける者はこのようなことをしない、ダナンジャヤよ。法を恐れながらパーンダヴァ（ユディシュティラ）にこうした振る舞いをするとは。」
yo'kāryāṇāṃ kriyāyāś ca saṃyogaṃ nāvabudhyate|
kāryāṇāmakriyāyāś ca sa pārtha puruṣādhamaḥ||
// 8-72-19 //
「為すべからざることを為し、為すべきことを為さない者の結合を理解しない者——アルジュナよ、それは人の中の最低の者だ。」
anusṛtya tu ye dharmaṃ kavayaḥ samupasthitāḥ|
samāsavistaravidāṃ na teṣāṃ vetsi niścayam||
aniścayajño hi naraḥ kāryākāryaviniścaye|
evaṃ sa muhyatyavaśo yathā tvaṃ pārtha muhyasi||
// 8-72-20-21 //
「法に従う賢者たちが、要約と詳説に通じた者たちの確定した見解を、お前は知らない。為すべきことと為すべからざることの決定において確信のない者は、お前が迷っているように迷う。」
na hi kāryamakāryaṃ vā sukhaṃ jñātuṃ kathañcana|
śrutena jñāyate sarvaṃ tacca tvaṃ nāvahudhyase||
// 8-72-22 //
「為すべきことと為すべからざることは、容易には知り得ない。全ては聖典の学習によって知られるが、お前はそれを理解していない。」
avijñānādiha bhavānsatyaṃ rakṣati dharmavit|
prāṇināṃ tvaṃ vadhaṃ pārtha dhārmiko nāvabudhyase||
prāṇināṃ hi vadhāttāta vṛthā dharmo mato mama|
anṛtaṃ tu bhavedvācyaṃ na tu hiṃsā kadācana||
// 8-72-23-24 //
「無知から、法を知る者として真実を守ろうとしているが、アルジュナよ、法を守る者として生き物の殺害が（時に）不法であることを理解していない。生き物の殺害よりも、嘘を言う方がましなのだ。暴力は決して許されない。」
sa kathaṃ bhrātaraṃ jyeṣṭhaṃ rājānaṃ dharmakovidam|
hanyādbhavānnaraśreṣṭha prākṛto'nyaḥ pumāniva||
// 8-72-25 //
「どうしてお前が、法に通じた年長の兄であり王を殺せようか。凡人のように。」
ayudhyamānasya gurostathā 'śatroś ca mānada|
parāṅmukhasya dravataḥ śaraṇaṃ cāpi gacchataḥ||
kṛtāñjaleḥ prapannasya pramattasya tathaiva ca|
na vadhaḥ pūjyate sadbhis tac ca sarvaṃ gurau tava||
// 8-72-26-27 //
「戦っていない師、武器を持たぬ者、背を向けて逃げる者、庇護を求める者、合掌して帰依する者、油断している者——これらの者の殺害を善人は称えない。それらの全てがお前の師（兄）に当てはまる。」
tvayā caitadvrataṃ pārtha bāleneva kṛtaṃ purā|
tasmādadharmasaṃyuktaṃ maurkhyādeva vyavasyasi||
svaguruṃ pārtha kasmāttvaṃ hantukāmo'bhidhāvasi|
asampradhārya dharmāṇāṃ gatiṃ sūkṣmāṃ duratyayām||
// 8-72-28-29 //
「お前は子供の頃にこの誓いを立てた。だから愚かにも不法に結びついた行為を決意している。法の道の微妙で越え難い行方を十分に考えもせず、なぜ師を殺そうとするのか。」
idaṃ dharmarahasyaṃ ca tava vakṣyāmi pāṇḍava|
yadbrūyāttava bhīṣmo vā rājā vāpi yudhiṣṭhiraḥ||
viduro vā punaḥ kṣattā gāndhārī vā yaśasvinī|
kuntī vā bharataśreṣṭha draupadī vā yaśasvinī|
tatte vakṣyāmi tattvena nibodhaitaddhanañjaya||
// 8-72-30-31 //
「この法の秘密をお前に語ろう。ビーシュマが、あるいはユディシュティラ王が、ヴィドゥラが、ガーンダーリーが、クンティーが、ドラウパディーが語るであろうことを——バーラタの最上者よ、それを真実として語ろう。ダナンジャヤよ、よく聞け。」
satyasyaṃ vacanaṃ sādhu na satyādvidyate param|
sudurvidaṃ hi tattvena tatsatyamiti me satiḥ||
bhavetsatyamavaktavyaṃ vaktavyamanṛtaṃ bhavet|
yatrānṛtaṃ bhavetsatyaṃ satyaṃ cāpyanṛtaṃ bhavet||
// 8-72-32-33 //
「真実を語ることは善い。真実より優れたものはない。しかしそれを真に見極めることは非常に難しい——それが真実についての私の考えだ。真実が語るべきでないことがあり、偽りが語るべきことになることがある。偽りが真実となり、真実が偽りとなる場合がある。」
vivāhakāle ratisamprayoge prāṇātyaye sarvatranāpahāre|
viprasya cārthe hyanṛtaṃ vadeta pañcānṛtānyāhurapātakāni||
sarvasvasyāpahāre tu vaktavyamanṛtaṃ bhavet||
tatrānṛtaṃ bhavetsatyaṃ satyaṃ cāpyanṛtaṃ bhavet||
// 8-72-34-35 //
「結婚の時、男女の交わりの時、命の危機の時、全財産の喪失の時、バラモンのためには——嘘を言っても五つの場合には罪にならないと言われている。全財産の喪失の際には偽りを語るべきだ。そこでは偽りが真実となり、真実が偽りとなる。」
tādṛśo hanyate bālo yasya satyamaniścitam|
satyānṛte viniścitya tato bhavati dharmavit||
// 8-72-36 //
「真実が定まらない者はそのように殺される、愚かな子供のように。真実と偽りを見極めて初めて、法を知る者となるのだ。」
kimāścaryaṃ kṛtaprajñaḥ puruṣo'pi sudāruṇaḥ|
sumahatprāpnuyātpuṇyaṃ balāko'ndhavadhādiva||
kimāścaryaṃ punarmūḍho dharmakāmo hyapaṇḍitaḥ|
sumahatprāpnuyātpāpamāpagāsviva kauśikaḥ||
// 8-72-37-38 //
「驚くべきことに、知恵ある者でも非常に残酷な行いで、大いなる功徳を得ることがある——バラカが盲目の獣を殺したように。また驚くべきことに、愚かな者が法を求めながらも学のない者が、大いなる罪を得ることがある——河の合流点のカウシカのように。」
arjuna uvāca|
ācakṣva bhagavannetadyathā vindāmyahaṃ tathā|
valākasyānusambaddhaṃ nadīnāṃ kauśikasya ca||
// 8-72-39 //
アルジュナは語った。
vāsudeva uvāca|
mṛgavyādho'bhavatkaścidbalāko nāma bhārata|
yātrārthaṃ putradārāṇāṃ mṛgānhanti na kāmataḥ||
vṛddhau ca mātāpitarau bibharty anyāṃś ca saṃśritān|
svadharmanirato nityaṃ saṃvibhajyānasūyakaḥ||
// 8-72-40-41 //
ヴァースデーヴァは語った。
sa kadācinmṛgaprepsurnānvavindanmṛgaṃ kvacit|
athāpaśyatsa pīvānaṃ śvāpadaṃ ghrāṇacakṣuṣam||
adṛṣṭapūrvamapi tatsatvaṃ tena hataṃ tadā|
andhe hate tato vyomnaḥ puṣpavarṣaṃ papāta ca||
// 8-72-42-43 //
「ある時、鹿を求めてもどこにも鹿が見つからなかった。そこで太った、嗅覚だけで見る獣を見つけた。見たこともないその生き物をその時殺した。その盲目の獣が殺されると、空から花の雨が降り注いだ。」
apsarogītavāditrairnāditaṃ ca manoramam|
vimānamagamatsvargānmṛgavyādhaninīṣayā||
tadbhūtaṃ sarvabhūtānāmabhāvāya kilārjuna|
tapastaptvā varaṃ prāptaṃ kṛtamandhaṃ svayambhuvā||
// 8-72-44-45 //
「天女たちの歌と楽器の心地よい音が鳴り響き、天の乗り物が猟師を天に連れて行こうとした。アルジュナよ、その生き物は全ての生き物を滅ぼすため、苦行によってスヴァヤンブー（ブラフマー）から恩恵を得て、自ら盲目となったのだ。」
taddhatvā sarvabhūtānāmabhāvakṛtaniścayam|
balāko'gātsvargalokamevaṃ dharmaḥ sudurvidaḥ||
// 8-72-46 //
「全ての生き物の破滅を決意したその者を殺して、バラカは天界に行った。このように法は非常に見分け難い。」
kauśiko'pyabhavadviprastapasvīno bahuśrutaḥ|
nadīnāṃ saṅgame grāmādadūre sa kilāvasat||
satyaṃ mayā sadā vācyamiti tasyābhavaddvatam|
satyavādīti vikhyātaḥ sa tadāsīddhanañjaya||
// 8-72-47-48 //
「カウシカというバラモンがいた。苦行者だが多くを学んではいなかった。河の合流点にある村の近くに住んでいた。『常に真実を語らねばならぬ』——それが彼の誓いであった。ダナンジャヤよ、彼は真実を語る者として知られていた。」
atha dasyubhayātkecittadā tadvanamāviśan|
tatrāpi dasyavaḥ kruddhāstānamārganta yatnataḥ||
atha kauśikamabhyetya procuste satyavādinam|
katareṇa pathā yātā bhagavanniti vai janāḥ|
satyena pṛṣṭaḥ prabrūhi yadi tadvettha śaṃsa naḥ||
// 8-72-49-50 //
「ある時、盗賊を恐れた人々がその森に逃げ込んだ。怒った盗賊たちもそこを探し回った。彼らはカウシカのもとに来て、真実を語る者に尋ねた。『人々はどの道を行った？真実に誓って教えよ。知っているなら我々に告げよ。』」
śrīkṛṣṇa uvāca|
satyasya tvavibhāgajñaḥ satyaṃ tebhyaḥ śaśaṃsa ha|
bahuvṛkṣalatāgulmametadgahanamāśritāḥ|
iti tānkhyāpayāmāsa tebhyastattvaṃ sa kauśikaḥ||
tataste tānsamāsādya krūrā jaghnuriti śrutiḥ|
tato'dharmeṇa mahatā vāgduruktena kauśikaḥ||
gataḥ sukaṣṭaṃ nirayaṃ dharmasūkṣmeṣvatattvavit|
dṛṣṭapūrvaśruto mūḍho dharmāṇāmaviśāradaḥ||
vṛddhānapṛcchansandehānandhaḥ śvabhram ivarcchati||
// 8-72-51-54 //
クリシュナは語った。
tatra te lakṣaṇoddeśaḥ kaścideva bhaviṣyati|
duṣkaraṃ pratisaṃkhyānaṃ kārtsnyenātra vyavasthitiḥ||
satyaṃ dharma iti hyeke vadanti bahavo janāḥ|
na ca pārthābhyasūyāmi naitatsarvatra śiṣyate||
śrutistu dhāryā ityeke vadanti bahavo janāḥ|
na tvetatpratyasūyāmi tatra sarvaṃ vidhīyate||
yatsyādahiṃsāsaṃyuktaṃ sa dharma iti niścayaḥ|
ahiṃsārthāya hiṃsrāṇāṃ dharmapravacanaṃ kṛtam|
dhāraṇāddharmamityāhurdharmo dhārayate prajāḥ||
// 8-72-55-58 //
「ここにお前へのいくつかの指針がある。完全な確定は難しい。多くの人々は『真実が法だ』と言う。それを非難はしないが、全てにおいてそうではない。聖典こそが守るべきだと多くの者は言う。それも非難しないが、その中に全てが定められている。非暴力に結びついたものが法である——それが確定した見解だ。暴力的な者たちのために法の教説は説かれた。法は生き物を支える。生き物の繁栄のために法の教説は説かれた。」
prabhavārthāya bhūtānāṃ dharmapravacanaṃ kṛtam|
yasmātprabhavasaṃyuktaḥ sa dharma iti niścayaḥ||
ye'nyāyena jigīṣanto dharmaṃ pṛcchanti mānavāḥ|
akūjanena cenmokṣo nātra kūjetkathañcana||
avaśyaṃ kūjitavye ha śaṅkeranvāpyakūjanāt|
ye'nyāyena jihīrṣanto dharmaṃ pṛcchanti kasyacit|
śreyastatrānṛtaṃ vaktuṃ satyāditi viniścitm||
prāṇātyaye vivāhe vā sarvajātyā mahābhaye|
sarvasvasya ca lope vā vaktavyamanṛtaṃ bhavet||
adharmaṃ hi na paśyanti mṛṣodyaṃ tatra paṇḍitāḥ|
sarvathā'bhivadettattu nānṛtaṃ syādvicakṣaṇaḥ||
yaḥ stenaiḥ saha sambandho mucyate śapathādapi|
bhavettatrānṛtaṃ śreyaḥ satyāditi vicāritam||
na ca tebhyo dhanaṃ deyaṃ satyāditi kathañcana|
pāpebhyo'pi dhanaṃ dattaṃ dātāramapi pīḍayet|
tasmāddharmārthamanṛtamuktvā nānṛtavāgbhavet||
// 8-72-59-65 //
「不正に奪おうとする者が法を問うなら、黙って助かるなら黙るべきだ。しかし黙っていると疑われる場合、不正に奪おうとする者に対しては、真実より偽りを語る方が良い——これが確定した見解だ。命の危機、結婚、全種族の大いなる危難、全財産の喪失の際には偽りを語るべきだ。賢者たちはそこに不法を見ない。盗賊との関わりにおいては誓いからさえも免れる。そこでは真実より偽りが良い。罪人に財を与えれば与えた者をも害する。だから法のために偽りを語っても偽りを語る者とはならない。」
eṣa te lakṣaṇoddeśo mayoddiṣṭo yathāvidhi|
etajjñātvā brūhi pārtha yadi vadhyo yudhiṣṭhiraḥ||
// 8-72-66 //
「これがお前への法則の指針だ、私が正しく示した通りに。これを知った上で、アルジュナよ、ユディシュティラが殺されるべきか言え。」
arjuna uvāca|
yathā brūyānmahāprājño yathā brūyānmahāyaśāḥ||
suhṛdbrūyādyathā'smākaṃ tathoktaṃ vacanaṃ tvayā|
bhavān mātṛsamo 'smākaṃ bhavān pitṛsamo 'pi ca|
gatiś ca paramā kṛṣṇa tvameva ca parāyaṇam||
na hi te triṣu lokeṣu vidyate'viditaṃ kvacit|
tasmādbhavānparaṃ dharmaṃ veda sarvaṃ yathātatham||
// 8-72-67-69 //
アルジュナは語った。
avadhyaṃ pāṇḍavaṃ manye dharmarājaṃ yudhiṣṭhiram|
adharmayukte saṃyoge brūhi kiñcidanugraham||
idaṃ cāparamatraiva brūhi tattvaṃ vivakṣitam||
// 8-72-70-71 //
「パーンダヴァのダルマラージャ・ユディシュティラは殺すべきでないと私は思う。この不法に結びついた状況において、何らかの恩恵の道を教えてくれ。そしてもう一つ、ここで語ろうとする真実のことを教えてくれ。」
jānāsi dāśārha mama vrataṃ tu yo māṃ brūyātkaścana mānuṣeṣu|
anyasmai tvaṃ gāṇḍivaṃ dehi pārtha yo matto'stre vīryato vā viśiṣṭaḥ||
hanyāmahaṃ keśava taṃ prasahya bhīmo hanyāttūvaraketi coktaḥ|
vanmāṃ rājā hyuktavāṃste samakṣaṃ dhanurdehītyasakṛdvṛṣṇivīre||
// 8-72-72-73 //
「ダーシャールハよ、お前は私の誓いを知っている。人間の中で誰であれ私に『アルジュナよ、ガーンディーヴァを他の者に渡せ、武器や武勇においてお前より優れた者に』と言う者があれば、私はその者を力ずくで殺す。ビーマも『それは卑怯者を殺す』と言った。あの王が繰り返しお前の面前で私に『弓を渡せ』と言ったのだ、ヴリシュニの勇者よ。」
taṃ hanyāṃ cetkeśava jīvaloke sthātā nāhaṃ kālamapyalpamātram|
dhyātvā nūnaṃ hyenasā cāpi mukto vadhaṃ rājño bhraṣṭavīryo vicetāḥ||
yathā pratijñā mama lokabuddhau bhavetsatyā dharmabhṛtāṃ variṣṭha|
yathā jīvatpāṇḍavo'haṃ ca kṛṣṇa tathā buddhiṃ dātumapyarhasi tvam||
// 8-72-74-75 //
「もし私がその者を殺すなら、生きてはいられないだろう、わずかな時間さえも。兄の王の殺害を思うだけでも、力を失い正気を失うだろう。だから法の守り手の最上者よ、私の誓いが世間的に真実となり、パーンダヴァ（ユディシュティラ）も生き、私も生きられるような知恵を授けてくれ。」
vāsudeva uvāca|
rājā śrānto vikṣato duḥkhitaś ca karṇena sahkhye niśitair bāṇasaṅghaiḥ|
yaścāniśaṃ sūtaputreṇa vīra śarairbhṛśaṃ tāḍito yudhyamānaḥ||
atastvametena saroṣamukto duḥkhānvitenedamayuktarūpam|
akopito hyeṣa yadi sma saṅkhye karṇaṃ na hanyāditi cābravītsaḥ||
jānāti taṃ pāṇḍava eṣa cāpi pāpaṃ loke karṇamasahyamanyaiḥ|
tatastvamukto bhṛśaroṣitena rājñā samakṣaṃ paruṣāṇi pārtha||
// 8-72-76-78 //
ヴァースデーヴァは語った。
nityodyukte satataṃ cāprasahye karṇe dyūtaṃ hy adya raṇe nibaddham|
tasminhate kuravo nirjitāḥ syur evaṃ buddhiḥ pārthive dharmaputre||
// 8-72-79 //
「常に奮起し、常に抗し難いカルナに対して、今日の戦場で賭けが打たれた。カルナが殺されればクル族は征服される——これがダルマの子の王の考えだ。」
tato badhaṃ nārhati dharmaputras tvayā pratijñā'rjuna pālanīyā|
jīvannayaṃ yena mṛto bhaveddhi tanme nibodheha tavānurūpam||
yadā mānaṃ labhate mānanārhas tadā sa vai jīvati jīvaloke|
yadā'vamānaṃ labhate mahāntaṃ tadā jīvanmṛta ityucyate saḥ||
// 8-72-80-81 //
「だからダルマの子は殺されるべきではない。アルジュナよ、誓いは守らねばならない。生きたまま死人のようにする方法を、お前にふさわしいものとして聞け。尊敬に値する者が大いなる侮辱を受けた時——生きていても死んだと言われるのだ。」
sammānitaḥ pārthivo'yaṃ sadaiva tvayā ca bhīmena tathā yamābhyām|
vṛddhaiś ca loke puruṣaiś ca śūrais tasyāpamānaṃ kalayā prayuṅkṣva||
tvamityatrabhavantaṃ hi brūhi pārtha yudhiṣṭhiram|
tvamityukto hi nihato gururbhavati bhārata||
evamācara kaunteya dharmarāje yudhiṣṭhire|
adharmayuktaṃ saṃyogaṃ kuruṣvainaṃ kurūdvaha||
// 8-72-82-84 //
「この王は常に敬われてきた。お前にも、ビーマにも、双子にも、世の年長者たちや勇者たちにも。彼にわずかな無礼を行え。バーラタよ、お前はダルマラージャ・ユディシュティラに『お前』と呼べ。敬うべき者を『お前』と呼ぶことは、打ち殺すに等しい。このようにカウンテーヤよ、不法に結びついた行為をなせ。」
atharvāṅgirasī hyeṣā śrutīnāmuttamā śrutiḥ|
avicāryaiva kāryaiṣā śreyaskāmairnaraiḥ sadā||
avadhena vadhaḥ prokto yadgurustvamiti prabhuḥ|
tadbrūhi tvaṃ yanmayoktaṃ dharmarājasya dharmavit||
// 8-72-85-86 //
「アタルヴァ・アンギラスの聖典の最高の教え——善を求める者は常に考えることなく実行すべきだ。師に対して『お前は』と言うことで、殺害なき殺害が達せられる。法を知る者よ、私が言ったことをダルマラージャに告げよ。」
yadā hyaṃ pāṇḍava dharmarājas atvatto 'yuktaṃ lapsyate caiva sādhu|
tato'sya pādāvabhivādya paścāc chreyo brūyātsāntvayuktaṃ hitaṃ ca||
bhrātā prājñastava kopaṃ na jātu kuryādrājā dharmamārgānusārī|
mukto'nṛtādvātṛvadhācca pāpād dhṛṣṭaḥ karṇaṃ tvaṃ jahi pārtha paścāt||
// 8-72-87-88 //
「パーンダヴァよ、このダルマラージャが不当なことをお前から受けた後、その足に礼拝し、慰めの言葉と有益な言葉を述べよ。賢明な兄は、法の道に従う王は、決してお前に怒ることはないだろう。偽りと兄殺しの罪から免れ、大胆にカルナを殺せ、アルジュナよ、その後で。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe dvisaptatitamo'dhyāyaḥ|| 72 ||
