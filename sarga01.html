Kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST）・和訳

prathamaḥ sargaḥ ― 第一章

ユディシュティラが派遣した密偵が帰還し、ドゥルヨーダナの巧みな統治を報告する（1-25）。ドラウパディーが王に現状の不名誉を説き、速やかな戦いを促す（26-46）。
1
Sanskrit
śriyaḥ kurūṇām adhipasya pālanīṃ
prajāsu vṛttiṃ yam ayuṅkta veditum /
sa varṇiliṅgī viditaḥ samāyayau
yudhiṣṭhiraṃ dvaitavane vanecaraḥ //
Vaṃśastha
和訳
クル族の主たる王（ドゥルヨーダナ）の王権を守る、臣民に対する統治方法を探るべく〔ユディシュティラが〕遣わした者――その密偵は、梵行学生の姿に身をやつし、〔敵情を〕知り得て、ドヴァイタの森のユディシュティラのもとへ帰参した。

varṇiliṅgī: Mallinātha注によれば「梵行学生の姿を装った者」の意。viditaḥ は「〔敵情を〕知った」と解する。vane / vanecaraḥ の音の反復は繰り返しの修辞（vṛttānuprāsa）。本章の韻律は Vaṃśastha。

2
Sanskrit
kṛtapraṇāmasya mahīṃ mahībhuje
jitāṃ sapatnena nivedayiṣyataḥ /
na vivyathe tasya mano na hi priyaṃ
pravaktum icchanti mṛṣā hitaiṣiṇaḥ //
和訳
拝礼を済ませ、大地が敵に奪われたことを王に報じようとするその者の心は、動揺しなかった。主の利を願う者は、偽りの吉報を伝えようとはしないからである。
3
Sanskrit
dviṣāṃ vighātāya vidhātum icchato
rahasy anujñām adhigamya bhūbhṛtaḥ /
sa sauṣṭhavaudāryaviśeṣaśālinīṃ
viniścitārthām iti vācam ādadhe //
和訳
敵を滅ぼす方策を講じようとする王から、密かな場で許しを得て、彼は、巧みさと気品に秀で、内容の確かな、次のような言葉を述べた。

rahasi: 法典の規定に従い、密偵の報告は秘密裡に行われる。

4
Sanskrit
kriyāsu yuktair nṛpa cāracakṣuṣo
na vañcanīyāḥ prabhavo 'nujīvibhiḥ /
ato 'rhasi kṣantum asādhu sādhu vā
hitaṃ manohāri ca durlabhaṃ vacaḥ //
和訳
密偵の言葉
「王よ、任務に就く従者は、諜者を目とする主君を欺いてはなりませぬ。ですから、正しかろうと誤りであろうと、お聞き届けください。益があり、かつ耳に快い言葉は、得がたいものでございます。」
5
Sanskrit
sa kiṃsakhā sādhu na śāsti yo 'dhipaṃ
hitān na yaḥ saṃśṛṇute sa kiṃprabhuḥ /
sadānukūleṣu hi kurvate ratiṃ
nṛpeṣv amātyeṣu ca sarvasampadaḥ //
和訳
「主君に正しく諫言しない者が、どうして友といえましょう。忠言を聴かぬ者が、どうして主といえましょう。あらゆる繁栄は、互いに誠実な王と大臣のもとにこそ宿るのです。」
6
Sanskrit
nisargadurbodham abodhaviklavāḥ
kva bhūpatīnāṃ caritaṃ kva jantavaḥ /
tavānubhāvo 'yam abodhi yan mayā
nigūḍhatattvaṃ nayavartma vidviṣām //
和訳
「生来捉えがたい王の振る舞いと、無知にうろたえる凡人と――両者はかけ離れております。敵の、真意の隠された政道を、この私が見抜けたのは、あなた様の威光あってのことでございます。」

kva...kva...:「一方は…、他方は…」と両者の隔絶を示す定型表現。密偵は、自分の力ではなく王の威光ゆえに敵情を看破できたと謙遜している。

7
Sanskrit
viśaṅkamāno bhavataḥ parābhavaṃ
nṛpāsanastho 'pi vanādhivāsinaḥ /
durodaracchadmajitāṃ samīhate
nayena jetuṃ jagatīṃ suyodhanaḥ //
和訳
「王座にありながらも、森に住むあなた様から敗北を被ることを恐れ、スヨーダナは、賭博の不正によって勝ち取った大地を、政略によってもまた勝ち取ろうと企てております。」

durodaracchadmajitām: durodara（賭博）+ chadma（欺瞞）+ jitām。Mallinātha注によれば「賭博における詐欺で勝ち取られた〔大地〕」の意。Cappellerも同じく「不正な賭けで得た」と解する。

8
Sanskrit
tathāpi jihmaḥ sa bhavajjigīṣayā
tanoti śubhraṃ guṇasampadā yaśaḥ /
samunnayan bhūtim anāryasaṃgamād
varaṃ virodho 'pi samaṃ mahātmabhiḥ //
和訳
「邪な者でありながら、あなたに打ち勝たんとする志から、彼は多くの美徳によって輝かしい名声を広めております。卑しき者との交わりよりも、高潔な者との敵対のほうが、名誉を高めるのです。」

後半の varaṃ virodho 'pi... は格言的表現。ドゥルヨーダナがユディシュティラに対抗しようとすること自体が、彼の名声を高めている逆説を述べる。

9
Sanskrit
kṛtāriṣaḍvargajayena mānavīm
agamyarūpāṃ padavīṃ prapitsunā /
vibhajya naktaṃdinam astatandriṇā
vitanyate tena nayena pauruṣam //
和訳
「六敵を征服し、マヌが説く近づきがたい道を歩もうとして、昼夜を正しく区分し、倦むことなく、彼は策をもって男子たる力を発揮しております。」

ariṣaḍvarga（六敵）: 欲望（kāma）、怒り（krodha）、貪欲（lobha）、過度の歓喜（harṣa）、驕慢（māna）、慢心（mada）の六つ。mānavīm padavīm: マヌ法典に説かれた王道。

10
Sanskrit
sakhīn iva prītiyujo 'nujīvinaḥ
samānamānān suhṛdaś ca bandhubhiḥ /
sa santataṃ darśayate gatasmayaḥ
kṛtādhipatyām iva sādhu bandhutām //
和訳
「驕りを捨て、彼は常に――従者を親しい友のように愛情をもって遇し、友人を親族と同等の敬意をもって待し――あたかも親族に支配権を委ねたかのように、善き親族の紐帯を示しております。」
11
Sanskrit
asaktam ārādhayato yathāyathaṃ
vibhajya bhaktyā samapakṣapātayā /
guṇānurāgād iva sakhyam īyivān
na bādhate 'sya trigaṇaḥ parasparam //
和訳
「執着なく、それぞれを応分に、偏りなき献身をもって分かちつつ尊び、あたかも彼の美徳への愛ゆえに友誼を結んだかのように、三目的は互いに妨げ合うことがありません。」

trigaṇa（三目的）: 法（dharma）、利（artha）、愛（kāma）の三つ。時に解脱（mokṣa）を加えて四とする。ドゥルヨーダナがこの三者を調和させていることを言う。

12
Sanskrit
niratyayaṃ sāma na dānavarjitaṃ
na bhūri dānaṃ virahayya satkriyām /
pravartate tasya viśeṣaśālinī
guṇānurodhena vinā na satkriyā //
和訳
「彼の穏やかな言葉は害なく、布施を伴わぬことがない。豊かな布施は礼遇を欠くことがない。卓越した礼遇もまた、徳への配慮なくしては行われません。」

政治の四方便のうち sāma（懐柔）と dāna（施与）の巧みさを説く。各々が次のものを伴い、連鎖的に完成する構造。

13
Sanskrit
vasūni vāñchan na vaśī na manyunā
svadharma ity eva nivṛttakāraṇaḥ /
gurūpadiṣṭena ripau sute 'pi vā
nihanti daṇḍena sa dharmaviplavam //
和訳
「自制を備え、財を欲してでもなく、怒りからでもなく、ただ自らの法務と心得て、先師が定めた刑罰をもって、敵に対しても、わが子に対してさえ、法の乱れを正します。」
14
Sanskrit
vidhāya rakṣān paritaḥ paretarān
aśaṅkitākāram upaiti śaṅkitaḥ /
kriyāpavargeṣv anujīvisātkṛtāḥ
kṛtajñatām asya vadanti sampadaḥ //
和訳
「四方に堅固な守りを配しながら、猜疑の心を抱きつつも恐れなき態度を装い――事業の成就の際に従者たちに惜しみなく与えられる報酬が、彼の恩に報いる心を物語っております。」
15
Sanskrit
anārataṃ tena padeṣu lambhitā
vibhajya samyag viniyogasatkriyām /
phalanty upāyāḥ paribṛṃhitāyatīr
upetya saṃgharṣam ivārthasampadaḥ //
和訳
「彼がつねに適所に配し、運用の妙を正しく振り分けた政策の手段は、互いに競い合うかのように、豊かな将来を約束する財の実りをもたらしております。」
16
Sanskrit
anekarājanyarathāśvasaṃkulaṃ
tadīyam āsthānaniketanājiram /
nayaty ayugmacchadagandhir ārdratāṃ
bhṛśaṃ nṛpopāyanadantināṃ madaḥ //
和訳
「多くの王族の戦車と馬でごった返す、彼の謁見殿の中庭を、諸王が贈り物として献上した象たちの、サプタパルナの香りを帯びた発情液がしきりに湿らせております。」

ayugmacchada: 奇数葉の樹、すなわちサプタパルナ（Alstonia Scholaris、七葉樹）。象の発情液（mada）はこの花のような芳香を帯びるとされる。

17
Sanskrit
sukhena labhyā dadhataḥ kṛṣīvalair
akṛṣṭapacyā iva sasyasampadaḥ /
vitanvati kṣemam adevamātṛkāś
cirāya tasmin kuravaś cakāsati //
和訳
「彼が末永く統べるもと、クル族の地は雨に依らずとも、耕さずして実る穀物のごとき豊穣を農夫たちにたやすく与え、安寧を広めております。」

adevamātṛkāḥ: 「天（雨）を母としない」＝雨に頼らない。灌漑が整い、天候に左右されない豊かさを意味する。

18
Sanskrit
mahaujaso mānadhanā dhanārcitā
dhanurbhṛtaḥ saṃyati labdhakīrtayaḥ /
na saṃhatās tasya na bhedavṛttayaḥ
priyāṇi vāñchanty asubhiḥ samīhitum //
和訳
「強力にして誇りを宝とし、財で敬われ、戦において名声を得た弓持つ者たちは、互いに結託するでもなく、離反するでもなく、ただ命を懸けて彼への奉仕を願っております。」
19
Sanskrit
udārakīrter udayaṃ dayāvataḥ
praśāntabādhaṃ diśato 'bhirakṣayā /
svayaṃ pradugdhe 'sya guṇair upasnutā
vasūpamānasya vasūni medinī //
和訳
「高名をば繁栄させ、慈悲深く、守護によって災いを鎮める彼のもとに、大地はその美徳に感じ入って自ら乳を搾り出し、財を差し出しております。それゆえ彼は富神クベーラの如くであります。」
20
Sanskrit
mahībhujāṃ saccaritaiś caraiḥ kriyāḥ
sa veda niḥśeṣam aśeṣitakriyaḥ /
mahodayais tasya hitānubandhibhiḥ
pratīyate dhātur ivehitaṃ phalaiḥ //
和訳
「優れた間諜によって諸王の行いを余すところなく知るこの勤勉な者の企ては、あたかも造物主の意図がその高い実りによって初めて知られるように、吉祥にして利をもたらす成果によってのみ窺い知れるのです。」
21
Sanskrit
na tena sajyaṃ kvacid udyataṃ dhanur
na vā kṛtaṃ kopavijihmam ānanam /
guṇānurāgeṇa śirobhir uhyate
narādhipair mālyam ivāsya śāsanam //
和訳
「彼はいまだかつて弦の張られた弓を構えたことも、怒りに顔を歪めたこともありません。諸王は彼の美徳への愛ゆえに、花環を頭に戴くように、彼の命令を頭上に戴いております。」
22
Sanskrit
sa yauvarājye navayauvanoddhataṃ
nidhāya duḥśāsanam iddhaśāsanaḥ /
makheṣv akhinno 'numataḥ purodhasā
dhinoti havyena hiraṇyaretasam //
和訳
「彼は、若さにあふれるドゥフシャーサナを皇太子に据え、厳格に統治しながら、祭式に倦むことなく、王室祭官の承認のもとに、供物をもって火神を満たしております。」

hiraṇyaretasam:「黄金の精液をもつ者」＝火神アグニ。

23
Sanskrit
pralīnabhūpālam api sthirāyati
praśāsad āvāridhi maṇḍalaṃ bhuvaḥ /
sa cintayaty eva bhiyas tvad eṣyatīr
aho durantā balavadvirodhitā //
和訳
「他の王たちが消え去った後も、海に至るまでの大地の全域を安定的に統治しながら、それでも彼はあなたから来るであろう脅威を思い患っております。ああ、強者との敵対とは終わりなきものでございます。」
24
Sanskrit
kathāprasaṅgena janair udāhṛtād
anusmṛtākhaṇḍalasūnuvikramaḥ /
tavābhidhānād vyathate natānanaḥ
sa duḥsahān mantrapadād ivoragaḥ //
和訳
「人々が話のついでにあなたの名を口にするだけで、インドラの息子の武勇を思い起こし、彼は面を伏せて動揺します。あたかも蛇が堪えがたい呪文の言葉に怯えるように。」

ākhaṇḍalasūnu:「砕く者（インドラ）の息子」＝アルジュナ。アルジュナはインドラの子とされる。

25
Sanskrit
tad āśu kartuṃ tvayi jihmam udyate
vidhīyatāṃ tatra vidheyam uttaram /
parapraṇītāni vacāṃsi cinvatāṃ
pravṛttisārāḥ khalu mādṛśāṃ dhiyaḥ //
和訳
「さればこそ、彼があなたに対して速やかに謀略を企てる今、しかるべき対策をお講じください。他者のもたらした言葉を集めるだけの私のような者の知恵は、所詮、情報の伝達に尽きるのですから。」
26
Sanskrit
itīrayitvā giram āttasatkriye
gate 'tha patyau vanasaṃnivāsinām /
praviśya kṛṣṇā sadanaṃ mahībhujā
tad ācacakṣe 'nujasannidhau vacaḥ //
和訳
このように報告を述べ、褒美を受け取って、森の住民たちの長が去った後、王は住居に入り、クリシュナー〔ドラウパディー〕と弟たちの前でその言葉を伝えた。

kṛṣṇā:「黒き女」＝ドラウパディーの別名。

27
Sanskrit
niśamya siddhiṃ dviṣatām apākṛtīs
tatas tatastyā viniyantum akṣamā /
nṛpasya manyuvyavasāyadīpinīr
udājahāra drupadātmajā giraḥ //
和訳
敵の成功と、それによる屈辱を聞いて、それを抑えることのできぬドルパダの娘は、王の怒りと決意を燃え立たせる言葉を発した。
28
Sanskrit
bhavādṛśeṣu pramadājanoditaṃ
bhavaty adhikṣepa ivānuśāsanam /
tathāpi vaktuṃ vyavasāyayanti māṃ
nirastanārīsamayā durādhayaḥ //
和訳
ドラウパディーの言葉
「あなたのような方に対しては、女の口から出る忠告は、侮辱にも等しいものです。それでも、女の分を越えるほどの深き苦悩が、私に語らせるのです。」
29
Sanskrit
akhaṇḍam ākhaṇḍalatulyadhāmabhiś
ciraṃ dhṛtā bhūpatibhiḥ svavaṃśajaiḥ /
tvayā svahastena mahī madacyutā
mataṅgajena srag ivāpavarjitā //
和訳
「インドラに匹敵する威光をもつ、あなたの家系の王たちが久しく完全に保ってきた大地を、あなたは自らの手で投げ捨ててしまわれた。あたかも発情した象が鼻で花環を振り落とすように。」
30
Sanskrit
vrajanti te mūḍhadhiyaḥ parābhavaṃ
bhavanti māyāviṣu ye na māyinaḥ /
praviśya hi ghnanti śaṭhās tathāvidhān
asaṃvṛtāṅgān niśitā iveṣavaḥ //
和訳
「策謀家に対して策を用いぬ愚か者は、敗北を招きます。身を守らぬ者の急所を、鋭い矢が貫くように、狡猾な者たちはそのような人に入り込んで打ち倒すのです。」
31
Sanskrit
guṇānuraktām anuraktasādhanaḥ
kulābhimānī kulajāṃ narādhipaḥ /
parais tvadanyaḥ ka ivāpahārayen
manoramām ātmavadhūm iva śriyam //
和訳
「忠実な臣下を備え、家門を誇る王であるあなた以外の誰が、美徳に惚れ込み、高貴な生まれの、心を奪う王権を――まるで自分の花嫁のように――敵に奪い取らせたりしましょうか。」
32
Sanskrit
bhavantam etarhi manasvigarhite
vivartamānaṃ naradeva vartmani /
kathaṃ na manyur jvalayaty udīritaḥ
śamītaruṃ śuṣkam ivāgnir ucchikhaḥ //
和訳
「王よ、いま賢者に非難される道を歩んでおられるあなたを、どうして燃え上がる怒りが焼き尽くさないのですか。高く燃え上がる炎が乾いたシャミーの木を焼くように。」

śamītaru: シャミーの木（Acacia Suma）。非常に燃えやすい木材として知られる。

33
Sanskrit
avandhyakopasya nihantur āpadāṃ
bhavanti vaśyāḥ svayam eva dehinaḥ /
amarṣaśūnyena janasya jantunā
na jātahārdena na vidviṣādaraḥ //
和訳
「怒りを空しくせぬ者、災いを打ち砕く者には、人々は自ずと従います。しかし、憤りを持たぬ者は、人に友誼を寄せられることもなく、敵に畏れられることもないのです。」
34
Sanskrit
paribhramaṃl lohitacandanocitaḥ
padātir antargiri reṇurūṣitaḥ /
mahārathaḥ satyadhanasya mānasaṃ
dunoti te kaccid ayaṃ vṛkodaraḥ //
和訳

vṛkodaraḥ:「狼腹」＝ビーマの別名。巨大な食欲にちなむ。

35
Sanskrit
vijitya yaḥ prājyam ayacchad uttarān
kurūn akupyaṃ vasu vāsavopamaḥ /
sa valkavāsāṃsi tavādhunāharan
karoti manyuṃ na kathaṃ dhanaṃjayaḥ //
和訳
「北クル族を征服し、インドラの如くに豊かな貴金属の財をあなたに献上したダナンジャヤ〔アルジュナ〕が、今やあなたのために樹皮の衣を集めている。どうして怒りを覚えずにおられましょうか。」
36
Sanskrit
vanāntaśayyākaṭhinīkṛtākṛtī
kacācitau viṣvag ivāgajau gajau /
kathaṃ tvam etau dhṛtisaṃyamau yamau

和訳

37
Sanskrit
imām ahaṃ veda na tāvakīṃ dhiyaṃ
vicitrarūpāḥ khalu cittavṛttayaḥ /
vicintayantyā bhavadāpadaṃ parāṃ
rujanti cetaḥ prasabhaṃ mamādhayaḥ //
和訳
「あなたのこのお心を、私には理解いたしかねます。心の動きは実にさまざまなものですから。しかし、あなたの大いなる災難を思えば、苦悩が私の胸を激しく引き裂くのです。」
38
Sanskrit
purādhirūḍhaḥ śayanaṃ mahādhanaṃ
vibodhyase yaḥ stutigītimaṅgalaiḥ /
adabhradarbhām adhiśayya sa sthalīṃ
jahāsi nidrām aśivaiḥ śivārutaiḥ //
和訳
「かつては豪華な寝台に横たわり、讃歌と祝歌の吉兆の調べに目覚めておられたあなたが、今やダルバ草の密生する大地に臥し、不吉なジャッカルの遠吠えに眠りから覚めておられます。」
39
Sanskrit
puropanītaṃ nṛpa rāmaṇīyakaṃ
dvijātiśeṣeṇa yad etad andhasā /
tad adya te vanyaphalāśinaḥ paraṃ
paraiti kārśyaṃ yaśasā samaṃ vapuḥ //
和訳
「王よ、かつてはバラモンたちに供した後の残りの美食を召し上がっていたのに、今や野の果実を食すあなたの御体は、名声とともにひどく痩せ衰えてゆきます。」
40
Sanskrit
anārataṃ yau maṇipīṭhaśāyināv
arañjayad rājaśiraḥsrajāṃ rajaḥ /
niṣīdatas tau caraṇau vaneṣu te
mṛgadvijālūnaśikheṣu barhiṣām //
和訳
「かつてはつねに宝石の台座に安らい、諸王の頭の冠の塵を染めていたあなたの両足が、今は森の中の、鹿や鳥が先端を啄んだ孔雀の羽の上に置かれているのです。」
41
Sanskrit
dviṣannimittā yad iyaṃ daśā tataḥ
samūlam unmūlayatīva me manaḥ /
parair aparyāsitavīryasampadāṃ
parābhavo 'py utsava eva māninām //
和訳
「この境遇が敵のせいであるがゆえに、私の心を根こそぎ引き抜くのです。敵に武勇の力を挫かれることのない矜持ある者にとっては、たとえ敗北さえも祝祭なのですから。」

後半は逆説的な格言。武勇が損なわれていないなら逆境すら名誉である――だが今の状況は敵のせいであり、それゆえに耐えがたい、という論理。

42
Sanskrit
vihāya śāntiṃ nṛpa dhāma tat punaḥ
prasīda saṃdhehi vadhāya vidviṣām /
vrajanti śatrūn avadhūya niḥspṛhāḥ
śamena siddhiṃ munayo na bhūbhṛtaḥ //
和訳
「王よ、安閑を捨ててください。お願いです。あの栄光を再び得るため、敵の殲滅に備えてください。欲を離れた聖者こそ敵を振り払い静寂によって成就に至るのであり、王はそうではないのです。」
43
Sanskrit
puraḥsarā dhāmavatāṃ yaśodhanāḥ
suduḥsahaṃ prāpya nikāram īdṛśam /
bhavādṛśāś ced adhikurvate parān
nirāśrayā hanta hatā manasvitā //
和訳
「名声をもって富とし、威光ある者たちの先頭に立つあなたのような方が、これほど堪えがたい屈辱を受けてなお敵をのさばらせるならば、ああ、矜持はその拠り所を失い、滅びてしまいます。」
44
Sanskrit
atha kṣamām eva nirastasādhanaś
cirāya paryeṣi sukhasya sādhanam /
vihāya lakṣmīpatilakṣma kārmukaṃ
jaṭādharaḥ sañ juhudhīha pāvakam //
和訳
「もし手段を捨て去り、ただ忍耐のみを末永き幸福の手立てと求めるのならば、ヴィシュヌの印たる弓を投げ捨て、髪を結い上げ、ここで火に供物を捧げるがよいでしょう。」

戦いを放棄するなら王ではなく苦行者になれ、という皮肉。lakṣmīpatilakṣma: ヴィシュヌの妃ラクシュミーの主の標章＝弓。

45
Sanskrit
na samayaparirakṣaṇaṃ kṣamaṃ te
nikṛtipareṣu pareṣu bhūridhāmnaḥ /
ariṣu hi vijayārthinaḥ kṣitīśā
vidadhati sopadhi saṃdhidūṣaṇāni //
和訳
「陰謀に専心する敵に対して条約を守るのは、大いなる威光あるあなたにはふさわしくありません。勝利を求める王たちは、敵に対しては策略をもって和約を破るものです。」

韻律がここで Puṣpitāgrā に変わる。章末の韻律変化はカーヴィヤの慣例。

46
Sanskrit
vidhisamayaniyogād dīptisaṃhārajihmaṃ
śithilabalam agādhe magnam āpatpayodhau /
riputimiram udasyodīyamānaṃ dinādau
dinakṛtam iva lakṣmīs tvāṃ samabhyetu bhūyaḥ //
和訳
「運命と時の定めによって光輝を奪われ、力を失い、災厄の大海に深く沈んでいるあなたを――敵という暗闇を払い、黎明に昇りゆく太陽のように――ラクシュミー〔繁栄の女神〕が再びお訪れになりますように。」

韻律は Sragdharā。沈んだ太陽が再び昇るように、ユディシュティラの繁栄が回復することを祈る壮大な直喩でドラウパディーの演説が結ばれる。
