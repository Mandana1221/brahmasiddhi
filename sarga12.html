kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

dvādaśaḥ sargaḥ ― 第十二章

アルジュナはシヴァの恩寵を得るべく苦行を続け、その威力は天地を圧倒する（1–16）。怯えた大仙人たちがシヴァのもとへ赴き窮状を訴える（17–31）。シヴァはアルジュナの神聖な本性と、猪に化けた悪魔ムーカの陰謀を明かす（32–39）。シヴァはキラータ族の王に変装し、軍勢を率いて狩猟の体裁で森に入り、アルジュナの庵に到達する（40–54）。韻律：ウドガター（Udgatā）。第54偈はプラハルシニー（Praharṣiṇī）。
1
Sanskrit
atha vāsavasya vacanena ruciravadanas trilocanam / klāntirahitam abhirādhayituṃ vidhivat tapāṃsi vidadhe dhanaṃjayaḥ //
Udgatā
和訳
さてダナンジャヤ（アルジュナ）は、インドラの言葉に従い、輝く顔をもって、三眼の神（シヴァ）を倦むことなく喜ばせんと、聖典の定めに従い苦行を修した。
Mallināthaはruciravadana（輝く顔）をインドラとの対面の喜びによる表情とする。klāntirahitamは「倦まずに」の意で、苦行の方法を形容する副詞。
2
Sanskrit
abhiraśmimāli vimalasya dhṛtajayadhṛter anāśuṣaḥ / tasya bhuvi bahutithās tithayaḥ pratijagmur ekacaraṇaṃ niṣīdataḥ //
Udgatā
和訳
清らかにして勝利への決意を抱き、絶食を続けるその人が、太陽に向かって片足で大地に立つうちに、幾多の日々が過ぎ去った。
3
Sanskrit
vapurindriyopatapaneṣu satatam asukheṣu pāṇḍavaḥ / vyāpa nagapatir iva sthiratāṃ mahatāṃ hi dhairyam avibhāvyavaibhavam //
Udgatā
和訳
肉体と感覚を絶えず苛む苦しみの中で、パーンドゥの子は山の王のごとき堅固さに達した。偉人の忍耐力は計り知れないものだから。
4
Sanskrit
na papāta saṃnihitapakti- surabhiṣu phaleṣu mānasam / tasya śucini śiśire ca payasy amṛtāyate hi sutapaḥ sukarmaṇām //
Udgatā
和訳
彼の心は、間近に熟して芳しい果実にも、清らかで冷たい水にも向かわなかった。善行の者にとって、正しき苦行こそが甘露となるのだから。
5
Sanskrit
na visismiye na viṣasāda muhur alasatāṃ nu cādade / sattvam urudhṛti rajastamasī na hataḥ sma tasya hataśaktipelave //
Udgatā
和訳
彼は誇ることなく、落胆することなく、怠惰に陥ることもなかった。力を失い脆弱となった激質と暗質も、その大いなる不動の純質を損なうことはなかった。
三つのグナ（sattva＝純質、rajas＝激質、tamas＝暗質）によるサーンキヤ的記述。Mallināthaは「得意になれば苦行は散逸する」という聖伝を引用する。
6
Sanskrit
tapasā kṛśaṃ vapur uvāha sa vijitajagattrayodayam / trāsajananam api tattvavidāṃ kim ivāsti yan na sukaraṃ manasvibhiḥ //
Udgatā
和訳
彼は苦行に痩せ細った身体を担いながらも、三界の栄華を凌ぐ光輝を帯びていた。真理を知る者すら畏怖せしめるほどに──智者に成し難きことがあろうか。

Sanskrit

Udgatā
和訳
夜半に燃え立つ火よりも明るく、海の深沈さを凌ぎ、勝利者たるその人は山よりも高く聳えて見えた。
8
Sanskrit

Udgatā
和訳
常に密やかに真言を唱える彼の顔は、歯の輝きが四方に広がって、暈をまとい畏怖を催す日輪のように輝いた。
9
Sanskrit
kavacaṃ sa bibhrad upavīta- padanihitasajyakārmukaḥ / śailapatir iva mahendradhanuḥ- parivītabhīmagahano vididyute //
Udgatā
和訳
鎧をまとい、聖紐の代わりに弦を張った弓をかけた彼は、虹に覆われた深き森を擁する山の王のように輝いていた。
Cappellerは「仙人ならば聖紐を着けるべきところ、弓をその位置に掛けている」と注する。苦行者と戦士の二面性を示す重要な描写。
10
Sanskrit

和訳

Sanskrit

両腕を高く掲げる彼の頭上に広がり、天地の間を満たす近づきがたき光輝は、聖仙たちと天上の者たちの固有の道をも占領した。
12
Sanskrit
rajanīṣu rājatanayasya bahulasamaye 'pi dhāmabhiḥ / bhinnatimiranikaraṃ na jahe śaśiraśmisaṃgamayujā nabhaḥ śriyā //
Udgatā

13
Sanskrit
mahatā mayūkhanicayena śamitaruci jiṣṇujanmanā / hrītam iva nabhasi vītamale na virājate sma vapur aṃśumālinaḥ //
Udgatā
和訳
ジシュヌ（アルジュナ）から発する大いなる光線の集まりに輝きを奪われ、雲ひとつない空にあっても、太陽の姿はまるで恥じ入ったかのように映えなくなった。
14
Sanskrit
tam udīritāruṇajaṭāṃśum adhiguṇaśarāsanaṃ janāḥ / rudram anuditalalāṭadṛśaṃ dadṛśur mimanthiṣum ivāsurīḥ purīḥ //
Udgatā
和訳
赤銅色の髻から光を放ち、弦を張った弓を帯びるその姿を、人々は、額の第三眼をまだ開いていないルドラが、阿修羅の三城を破壊せんとする姿のように見た。
トリプラ（三城）破壊はシヴァの武勇を代表する神話。Mallināthaは「額の眼がないルドラ」という存在しない対象を喩えに用いる特殊な比喩を指摘する。
15
Sanskrit
marutāṃ patiḥ svid ahimāṃśur uta pṛthuśikhaḥ śikhī tapaḥ / taptum asukaram upakramate na jano 'yam ity avayaye sa tāpasaiḥ //
Udgatā
和訳
「これはインドラか、太陽か、あるいは大きな炎の火か──困難なる苦行に着手しているが、こは常の人ではあるまい」と、苦行者たちは判断した。
16
Sanskrit
na dadāha bhūruhavanāni haritanayadhāma dūragam / na sma nayati pariśoṣam apaḥ susahaṃ babhūva na ca siddhatāpasaiḥ //
Udgatā
和訳
インドラの息子の遠方にまで及ぶ光輝は、樹木の森を焼き尽くすこともなく、水を涸らすこともなかったが、シッダたちと苦行者たちには堪え難いものとなった。
Mallināthaはvirodha-ābhāsa（見かけの矛盾）の修辞を指摘する。火のように焼かず、太陽のように水を涸らさないが、生身の者には堪え難いという超自然的な威力。
17
Sanskrit
vinayaṃ guṇā iva vivekam apanayabhidaṃ nayā iva / nyāyam avadhaya ivāśaraṇāḥ śaraṇaṃ yayuḥ śivam atho maharṣayaḥ //
Udgatā
和訳
そこで大仙人たちは、寄る辺なくシヴァに庇護を求めた──徳が教養に、政策が不正を破る識別に、時効が法に帰するように。
18

和訳
太陽の光輪をも凌ぐ光線に包まれたシャンブ（シヴァ）を、目の眩んだ彼ら大仙人たちは、突然にはその姿を見定めることができなかった。

和訳
──高き雪山の頂に立ち、世界を超越する威力をもって、山々、海、大気、天道もろともに全宇宙を覆い尽くすかのように。
22
Sanskrit
anujānumadhyamavasakta- vitatavapuṣā mahāhinā / lokam akhilam iva bhūmibhṛtā ravitejasām avadhinādhiveṣṭitam //
Udgatā
和訳
──両膝の間に巨大な蛇がその長き身体を巻きつかせ、あたかもローカーローカ山が日光の限界となって全世界を囲むかのように。
ローカーローカ山は、日光が届く世界と届かない世界の境界をなす伝説上の山脈。シヴァの膝に巻きつく大蛇をこれに喩える。
23
Sanskrit
pariṇāhinā tuhinarāśi- viśadam upavītasūtratām / nītam uragam anurañjayatā śitinā galena vilasanmarīcinā //
Udgatā
和訳
──雪山のごとく白き蛇を聖紐の代わりに巻きつけ、その青黒く広大にして光輝く頸が蛇を自らの色に染め上げている姿を。
Mallināthaはtadguṇa（他者の性質の吸収）の修辞を指摘する。白い蛇がシヴァの青い頸の色に染まるという。

46
Sanskrit
na virodhinī ruṣam iyāya pathi mṛgavihaṅgasaṃhatiḥ / ghnanti sahajam api bhūribhiyaḥ samam āgatāḥ sapadi vairam āpadaḥ //
Udgatā
和訳
互いに敵対する獣と鳥の群れも、逃走の途上で怒りを発することはなかった。共に訪れた大いなる恐怖の災厄は、たちまちにして生来の敵意さえも消し去るのだ。
47
Sanskrit
camarīgaṇair gaṇabalasya balavati bhaye 'py upasthite / vaṃśavitatiṣu viṣaktapṛthu- priyabālavāladhibhir ādade dhṛtiḥ //
Udgatā
和訳
ガナ（シヴァの眷属）の軍勢による大いなる恐怖が迫る中でさえ、ヤクの群れは竹の茂みに美しい尾毛を絡めたまま、沈着さを保った。
チャマリー（ヤク）は自らの尾毛を非常に大切にし、それが絡まると命に代えても逃げないとされる。
48
Sanskrit
harasainikāḥ pratibhaye 'pi gajamadasugandhikesaraiḥ / svastham abhidadṛśire sahasā pratibodhajṛmbhitamukhair mṛgādhipaiḥ //
Udgatā
和訳
危険が迫る中でも、目覚めた獅子たちは──象の発情液の甘き香りを帯びた鬣を持ち、欠伸をする口をもって──ハラ（シヴァ）の兵士たちを悠然と見つめていた。
49
Sanskrit
bibharāṃbabhūvur apavṛtta- jaṭharaśapharīkulākulāḥ / paṅkaviṣamitataṭāḥ saritaḥ karirugṇacandanarasāruṇaṃ payaḥ //
Udgatā
和訳
河川は、腹を見せてのた打つ魚の群れにざわめき、岸辺は泥で崩れ、象に折られた栴檀の樹液で赤く染まった水を湛えていた。
50
Sanskrit
mahiṣakṣatāgurutamāla- naladasurabhiḥ sadāgatiḥ / vyastaśukanibhaśilākusumaḥ praṇudan vavau vanasadāṃ pariśramam //
Udgatā
和訳
水牛に踏み砕かれた沈香・タマーラ・甘松の芳香を帯び、鸚鵡に似た石の花を散らしながら、絶えず吹く風が森の住人たちの疲労を拭い去った。
51
Sanskrit
mathitāmbhaso rayavikīrṇa- mṛditakadalīgavedhukāḥ / klāntajalaruhalatāḥ sarasīr vidadhe nidāgha iva sattvasamplavaḥ //
Udgatā
和訳
獣たちの殺到は、あたかも猛暑のように、池の水をかき乱し、その勢いで芭蕉やガヴェードゥカ草を踏み散らし、蓮や蔓草を萎れさせた。
52
Sanskrit
iti cālayann acalasānu- vanagahanajān umāpatiḥ / prāpa muditahariṇīdaśana- kṣatavīrudhaṃ vasatim aindrasūnavīm //
Udgatā
和訳
かくして山腹の森と茂みの生き物を追い立てつつ、ウマーの夫（シヴァ）はインドラの息子（アルジュナ）の住処に到達した──そこでは喜ぶ牝鹿の歯が若草を齧っていた。
53
Sanskrit
sa tam āsasāda ghananīlam abhimukham upasthitaṃ muneḥ / potranikaṣaṇavibhinnabhuvaṃ danujaṃ dadhānam atha saukaraṃ vapuḥ //
Udgatā
和訳
そしてシヴァは、仙人（アルジュナ）の面前に迫り来る、濃密な黒雲のごとき、鼻で大地を抉る猪の姿をとった悪魔（ムーカ）に近づいた。
54
Sanskrit
kacchānte surasarito nidhāya senām anvītaḥ sa katipayaiḥ kirātavaryaiḥ / pracchannas tarugahanaiḥ sagulmajālair lakṣmīvān anupadam asya sampratasthe //
Praharṣiṇī
和訳
天の河の岸辺に軍勢を配置し、わずかな精鋭のキラータたちを従え、密なる灌木の茂る木立に身を隠しつつ、威厳に満ちたシヴァはその（猪の）足跡をたどって追跡を始めた。
iti bhāravikṛtau mahākāvye kirātārjunīye dvādaśaḥ sargaḥ //
バーラヴィ作『キラータールジュニーヤ』第十二章 終
