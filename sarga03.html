kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

tṛtīyaḥ sargaḥ ― 第三章

ユディシュティラがヴィヤーサに語りかける（1-9）。ヴィヤーサは戦いを勧め、敵の武勇の困難を説き、アルジュナに秘密の知識を授ける（10-29）。ヴィヤーサが消えた後、ヤクシャがアルジュナの旅の伴侶として現れる。兄弟とドラウパディーの祝福を受けてアルジュナは旅立つ（30-60）。
1
ユディシュティラの言葉
Sanskrit
tataḥ śaraccandrakarābhirāmair utsarpibhiḥ prāṃśum ivāṃśujālaiḥ / bibhrāṇam ānīlarucaṃ piśaṅgīr jaṭās taḍitvantam ivāmbuvāham //
Upajāti
和訳
やがて、秋月の光のように美しい光の束が湧き上がって聳え立つかのように見える、雲のように紺碧の色をもち、稲妻を帯びた雨雲のように赤褐色の編み髪を帯びた――

1-4節はヴィヤーサの容姿を描く長い複合文。jaṭā（編み髪）が稲妻に、暗い身体が雲に喩えられる。

2
Sanskrit
prasādalakṣmīṃ dadhataṃ samagrāṃ vapuḥprakarṣeṇa janātigena / prasahya cetaḥsu samāsajantam asaṃstutānām api bhāvam ārdram //
Upendravajrā
和訳
――超人的なる身体の卓越さによって穏和の美を余すところなく備え、面識なき者の心にさえ否応なく温かい感情を植えつける――
3
Sanskrit
anuddhatākāratayā viviktāṃ tanvantam antaḥkaraṇasya vṛttim / mādhuryavisrambhaviśeṣabhājā kṛtopasambhāṣam ivekṣitena //
Upajāti
和訳
――穏やかな姿によって内心の清浄なる状態を表し、甘美さと信頼に満ちた眼差しによってまるで語りかけるかのような――
4
Sanskrit
dharmātmajo dharmanibandhinīnāṃ prasūtim enaḥpraṇudāṃ śrutīnām / hetuṃ tadabhyāgamane parīpsuḥ sukhopaviṣṭaṃ munim ābabhāṣe //
Upajāti
和訳
――その聖仙に、法を守る聖典の源であり罪を滅ぼす者に、来訪の理由を尋ねんと望みつつ、法の子（ユディシュティラ）は安座する彼に語りかけた。

dharmātmajaはユディシュティラの異名。法（ダルマ）神の子の意。

5
Sanskrit
anāptapuṇyopacarair durāpā phalasya nirdhūtarajāḥ savitrī / tulyā bhavaddarśanasampad eṣā vṛṣṭer divo vītabalāhakāyāḥ //
Upajāti
和訳
「功徳の奉仕を得ぬ者には達しがたく、塵を払い果実をもたらすこの拝謁の幸福は、雲なき空からの雨にも等しい。
6
Sanskrit
adya kriyāḥ kāmadughāḥ kratūnāṃ satyāśiṣaḥ samprati bhūmidevāḥ / ā saṃsṛter asmi jagatsu jātas tvayy āgate yad bahumānapātram //
Indravajrā
和訳
今日こそ祭祀の儀式は願いを叶え、今こそ地上の神々の祝福は真となる。汝の来臨によって尊敬の器となったからには、輪廻の始まりよりこの世に生まれた甲斐がある。
7
Sanskrit
śriyaṃ vikarṣaty apahanty aghāni śreyaḥ parisnauti tanoti kīrtim / saṃdarśanaṃ lokaguror amoghaṃ tavātmayoner iva kiṃ na dhatte //
Upajāti
和訳
世界の導師よ、汝の実りある御姿を拝することは、自ら生まれし者（ブラフマー）の如く、繁栄を引き寄せ、罪を滅ぼし、福を注ぎ、名声を広げる――何をなさぬことがあろうか。
8
Sanskrit
ścyotanmayūkhe 'pi himadyutau me nanirvṛtaṃ nirvṛtim eti cakṣuḥ / samujjhitajñātiviyogakhedaṃ tvatsaṃnidhāv ucchvasatīva cetaḥ //
Upajāti
和訳
甘露を滴らせる月にさえ喜びを見出せなかった我が眼も、今喜びを得る。汝の御前にあって我が心は、親族との離別の悲しみを捨て、蘇るかのようだ。
9
Sanskrit
nirāspadaṃ praśnakutūhalitvam asmāsv adhīnaṃ kim u niḥspṛhāṇām / tathāpi kalyāṇakarīṃ giraṃ te māṃ śrotum icchā mukharīkaroti //
Upajāti
和訳
問いを発する好奇心は場違いであろう。無欲なる者にとって、我々に依存するものがあろうか。しかしなお、汝の吉祥なる言葉を聞きたいという渇望が、私を饒舌にさせる。」
10
ヴィヤーサの言葉
Sanskrit
ity uktavān uktiviśeṣaramyaṃ manaḥ samādhāya jayopapattau / udāracetā giram ity udārāṃ dvaipāyanenābhidadhe narendraḥ //
Upajāti
和訳
かく語り終えた王は、心を勝利の方策に定め、高邁なる精神のドヴァイパーヤナ（ヴィヤーサ）からこの崇高なる言葉を受けた。

dvaipāyanaはヴィヤーサの別名。母が島（dvīpa）で彼を産んだことに由来する。

11
Sanskrit
cicīṣatāṃ janmavatām alaghvīṃ yaśovataṃsām ubhayatra bhūtim / abhyarhitā bandhuṣu tulyarūpā vṛttir viśeṣeṇa tapodhanānām //
Upajāti
和訳
「両世において名声を冠とする立派な繁栄を求める者にとって、親族への均等な振る舞いが称賛される。とりわけ苦行を富とする者においては。
12
Sanskrit
tathāpi nighnaṃ nṛpa tāvakīnaiḥ prahvīkṛtaṃ me hṛdayaṃ guṇaughaiḥ / vītaspṛhāṇām api muktibhājāṃ bhavanti bhavyeṣu hi pakṣapātāḥ //
Upajāti
和訳
しかし王よ、汝の美徳の奔流によって我が心は打ちのめされ、低く伏している。欲を離れ解脱を得た者にも、善き者への偏愛はあるものだ。
13
Sanskrit
sutā na yūyaṃ kim u tasya rājñaḥ suyodhanaṃ vā na guṇair atītāḥ / yas tyaktavān vaḥ sa vṛthā balād vā mohaṃ vidhatte viṣayābhilāṣaḥ //
Upajāti
和訳
汝らはあの王（ドリタラーシュトラ）の子も同然ではないか。あるいは美徳においてスヨーダナに劣るとでもいうのか。彼に汝らを見捨てさせたもの――それは、むなしく、あるいは力ずくで迷妄を生み出す、享楽への渇望にほかならない。
14
Sanskrit
jahātu nainaṃ katham arthasiddhiḥ saṃśayya karṇādiṣu tiṣṭhate yaḥ / asādhuyogā hi jayāntarāyāḥ pramāthinīnāṃ vipadāṃ padāni //
Upajāti
和訳
カルナらを頼みとする者から、どうして成功が去らずにいようか。悪しき者との結びつきは勝利の障害であり、破壊的な災厄の源である。

karṇādiṣuは、ビーシュマやドローナとともにカウラヴァ側についたカルナなどを指す。

15
Sanskrit
pathaś cyutāyāṃ samitau ripūṇāṃ dharmyāṃ dadhānena dhuraṃ cirāya / tvayā vipatsv apy avipatti ramyam āviṣkṛtaṃ prema paraṃ guṇeṣu //
Upajāti
和訳
正道から逸れた敵の集会において、長きにわたり法の重荷を担ってきた汝は、不幸の中にあっても揺るがぬ美しき美徳への至上の愛を示した。
16
Sanskrit
vidhāya vidhvaṃsanam ātmanīnaṃ śamaikavṛtter bhavataś chalena / prakāśitatvanmatiśīlasārāḥ kṛtopakārā iva vidviṣas te //
Upendravajrā
和訳
寂静のみを求める汝に策略をもって自らの損害をもたらすことで、汝の知慧と品性の真髄を明らかにした敵は、いわば汝の恩人のようだ。
17
Sanskrit
labhyā dharitrī tava vikrameṇa jyāyāṃś ca vīryāstrabalair vipakṣaḥ / ataḥ prakarṣāya vidhir vidheyaḥ prakarṣatantrā hi raṇe jayaśrīḥ //
Upajāti
和訳
大地は汝の武勇によって得られる。しかし敵は英雄的武力と兵力において勝る。それゆえ優位を得るための方策を講じねばならない。戦場の勝利の女神は優位に依拠するからだ。
18
Sanskrit
triḥsaptakṛtvo jagatīpatīnāṃ hantā gurur yasya sa jāmadagnyaḥ / vīryāvadhūtaḥ sma tadā viveda prakarṣam ādhāravaśaṃ guṇānām //
Upajāti
和訳
二十一度にわたり王たちを討滅したジャーマダグニヤ（パラシュラーマ）を師とするその者（ビーシュマ）――その武勇に打ち負かされたとき、ジャーマダグニヤは、美徳の卓越がそれを宿す器に依ることを悟ったのである。

jāmadagnyaはパラシュラーマ。ビーシュマの弓術の師だったが、弟子との一騎打ちで苦戦した。Cappellerの注参照。

19
Sanskrit
yasminn anaiśvaryakṛtavyalīkaḥ parābhavaṃ prāpta ivāntako 'pi / dhunvan dhanuḥ kasya raṇe na kuryān mano bhayaikapravaṇaṃ sa bhīṣmaḥ //
Upajāti
和訳
あのビーシュマに対しては、無力の恥辱を被った死神さえも敗北を喫したかのようだった。戦場で弓を振るう彼は、誰の心を恐怖一色に染めずにおくだろうか。

ビーシュマは父から自ら死の時を選ぶ力を授かっており、死神の力を無効にした。

20
Sanskrit
sṛjantam ājāviṣusaṃhatīr vaḥ saheta kopajvalitaṃ guruṃ kaḥ / parisphurallolaśikhāgrajihvaṃ jagaj jighatsantam ivāntavahnim //
Upendravajrā
和訳
怒りに燃えて矢の雨を放つ汝らの師（ドローナ）に、誰が耐え得ようか。揺らめき蠢く炎の舌先をもって世界を呑み込まんとする終末の火のごとき者に。
21
Sanskrit
nirīkṣya saṃrambhanirastadhairyaṃ rādheyam ārādhitajāmadagnyam / asaṃstuteṣu prasabhaṃ bhayeṣu jāyeta mṛtyor api pakṣapātaḥ //
Upajāti
和訳
猛烈な勢いで敵の堅忍を打ち砕く、ジャーマダグニヤの寵愛を受けたラーデーヤ（カルナ）を見れば、死神でさえ、かつて知らぬ恐怖に陥るであろう。
22
Sanskrit
yayā samāsāditasādhanena suduścarām ācaratā tapasyām / ete durāpaṃ samavāpya vīryam unmūlitāraḥ kapiketanena //
Upajāti
和訳
猿の旗を掲げる者（アルジュナ）がこの学問（ヴィディヤー）によって武器を得、苛酷な苦行を修め、得がたき力を獲得したとき、これらの敵は滅ぼされるであろう。
23
Sanskrit
mahattvayogāya mahāmahimnām ārādhanīṃ tāṃ nṛpa devatānām / dātuṃ pradānocita bhūridhāmnīm upāgataḥ siddhim ivāsmi vidyām //
Upajāti
和訳
王よ、偉大なる神々を喜ばせ、壮大なる威力をもたらすこの学問を、施しにふさわしき汝に、汝の偉大さの成就のために授けんと、私は来たのだ。」
24
Sanskrit
ity uktavantaṃ vraja sādhayeti pramāṇayan vākyam ajātaśatroḥ / prasedivāṃsaṃ tam upāsasāda vasann ivānte vinayena jiṣṇuḥ //
Upajāti
和訳
かく語り終えた聖仙に、「行きて成し遂げよ」とのアジャータシャトル（ユディシュティラ）の言葉に従い、ジシュヌ（アルジュナ）は弟子のように恭しく近づいた。
25
Sanskrit
niryāya vidyātha dinādiramyād bimbād ivārkasya mukhān maharṣeḥ / pārthānanaṃ vahnikaṇāvadātā dīptiḥ sphuratpadmam ivābhipede //
Indravajrā
和訳
そのとき知識が、朝美しく輝く太陽の円盤から出るように大仙の口から出で、火の粒子のごとく清らかな輝きとなって、咲く蓮の如きパールタ（アルジュナ）の顔に入った。
26
Sanskrit
yogaṃ ca taṃ yogyatamāya tasmai tapaḥprabhāvād vitatāra sadyaḥ / yenāsya tattveṣu kṛte 'vabhāse samunmimīleva cirāya cakṣuḥ //
Upajāti
和訳
聖仙は苦行の力により、最もふさわしきその者に直ちにヨーガを授けた。それによって真理を見通す眼が、長い眠りから覚めるかのように開かれた。
27
Sanskrit
ākāram āśaṃsitabhūrilābhaṃ dadhānam antaḥkaraṇānurūpam / niyojayiṣyan vijayodaye taṃ tapaḥsamādhau munir ity uvāca //
Upajāti
和訳
多大な獲得を予感させ、内心にふさわしい表情を浮かべるアルジュナを勝利の曙に向けた苦行の精進に任じようとして、聖仙はかく語った。
28
Sanskrit
anena yogena vivṛddhatejā nijāṃ parasmai padavīm ayacchan / samācarācāram upāttaśastro japopavāsābhiṣavair munīnām //
Upendravajrā
和訳
「このヨーガによって力を増し、何人にも道を譲ることなく、武器を手にして、誦経・断食・灌頂によって聖仙たちの行いを実践せよ。
29
Sanskrit
kariṣyase yatra suduścarāṇi prasattaye gotrabhidas tapāṃsi / śiloccayaṃ cāruśiloccayaṃ tam eṣa kṣaṇān neṣyati guhyakas tvām //
Upajāti
和訳
インドラの恩寵を得んために苛酷な苦行を行うべきかの美しい岩山へ、このグヒャカ（ヤクシャ）が汝をたちまち導くであろう。」

gotrabhidは「山を砕く者」すなわちインドラの異名。guhyakaはクベーラに仕える半神的存在。

30
Sanskrit
iti bruvāṇena mahendrasūnuṃ maharṣiṇā tena tirobabhūve / taṃ rājarājānucaro 'sya sākṣāt pradeśam ādeśam ivādhitasthau //
Upajāti
和訳
インドラの子にかく告げつつ、大仙は姿を消した。王の中の王（クベーラ）の従者（ヤクシャ）は、命令のようにその場に直ちに赴いた。
31
Sanskrit
kṛtānatir vyāhṛtasāntvavāde jātaspṛhaḥ puṇyajanaḥ sa jiṣṇau / iyāya sakhyāv iva samprasādaṃ viśvāsayaty āśu satāṃ hi yogaḥ //
Upajāti
和訳
身を屈めて拝し、優しい言葉を発したそのヤクシャは、ジシュヌ（アルジュナ）への愛着を生じ、友人への如く信頼を得た。善き者たちの交わりは速やかに信頼を生む。
32
Sanskrit
athoṣṇabhāseva sumerukuñjān vihīyamānān udayāya tena / bṛhaddyutīn duḥkhakṛtātmalābhaṃ tamaḥ śanaiḥ pāṇḍusutān prapede //
Upendravajrā
和訳
やがて、昇るために太陽に去られてゆく須弥山の谷あいを闇がしだいに覆うように、繁栄を得るために彼（アルジュナ）に別れを告げられた輝かしいパーンドゥの子らを、悲しみから生じた闇が静かに包んだ。
33
Sanskrit
asaṃśayālocitakāryanunnaḥ premṇā samānīya vibhajyamānaḥ / tulyād vibhāgād iva tanmanobhir duḥkhātibhāro 'pi laghuḥ sa mene //
Upajāti
和訳
事業の不可避を確信して駆り立てられ、愛によって引き戻されながら、彼らの心で等しく分かち合われたその悲しみの重荷は、均等に分配されたがゆえに軽く感じられた。
34
Sanskrit
dhairyeṇa viśvāsyatayā maharṣes tīvrād arātiprabhavāc ca manyoḥ / vīryaṃ ca vidvatsu sute maghonaḥ sa teṣu na sthānam avāpa śokaḥ //
Upajāti
和訳
堅忍と大仙への信頼、敵に起因する激しい憤り、そしてインドラの子の武勇への確信により、悲しみは彼らの中に足場を見出せなかった。
35
Sanskrit
tān bhūridhāmnaś caturo 'pi dūraṃ vihāya yāmān iva vāsarasya / ekaughabhūtaṃ tad aśarma kṛṣṇāṃ vibhāvarīṃ dhvāntam iva prapede //
Upajāti
和訳
四人の輝ける兄弟を遠くに置き去りにして――闇が昼の四時を後にするように――一つに凝縮したその苦悩は、クリシュナー（ドラウパディー）を包んだ。暗黒が夜を覆い尽くすように。

インドの時間制度では昼夜はそれぞれ四つのyāma（時）に分けられる。四兄弟を昼の四時に、ドラウパディーを闇に覆われる夜に喩える。

36
Sanskrit
tuṣāralekhākulitotpalābhe paryaśruṇī maṅgalabhaṅgabhīruḥ / agūḍhabhāvāpi vilokane sā na locane mīlayituṃ viṣehe //
Upajāti
和訳
露に濡れた蓮のような涙に潤んだ眼を、吉祥の破壊を恐れるドラウパディーは、感情を隠せぬまま閉じることもできなかった。
37
Sanskrit
akṛtrimapremarasābhirāmaṃ rāmārpitaṃ dṛṣṭivilobhi dṛṣṭam / manaḥprasādāñjalinā nikāmaṃ jagrāha pātheyam ivendrasūnuḥ //
Upajāti
和訳
偽りのない愛の情味に満ち、美しき妻から捧げられた、眼を奪う眼差しを、インドラの子は心の平安という合掌の手で、旅の糧のように存分に受け取った。
38
ドラウパディーの言葉
Sanskrit
dhairyāvasādena hṛtaprasādā vanyadvipeneva nidāghasindhuḥ / niruddhabāṣpodayasannakaṇṭham uvāca kṛcchrād iti rājaputrī //
Upajāti
和訳
堅忍の崩壊によって清澄さを失い――夏の河が野生の象に乱されたように――涙を堪えて声を詰まらせながら、王女はようやくかく語った。
39
Sanskrit
magnāṃ dviṣacchadmani paṅkabhūte sambhāvanāṃ bhūtim ivoddhariṣyan / ādhidviṣām ā tapasāṃ prasiddher asmad vinā mā bhṛśam unmanībhūḥ //
Indravajrā
和訳
「泥沼と化した敵の欺瞞に沈んだ私たちの名誉を、繁栄とともに引き上げてくださるのですから、苦悩を払う苦行が成就するまで、私たちと離れていても、あまり心を乱さないでください。
40
Sanskrit
yaśo 'dhigantuṃ sukhalipsayā vā manuṣyasaṃkhyām ativartituṃ vā / nirutsukānām abhiyogabhājāṃ samutsukevāṅkam upaiti siddhiḥ //
Upendravajrā
和訳
名声を得んとし、幸福を求め、あるいは常人の域を超えんとする者には、渇望せずとも努力する者のもとに、成就の方から熱望するかのように訪れる。
41
Sanskrit
lokaṃ vidhātrā vihitasya goptuṃ kṣattrasya muṣṇan vasu jaitram ojaḥ / tejasvitāyā vijayaikavṛtter nighnan priyaṃ prāṇam ivābhimānam //
Indravajrā
和訳
創造主によって世を守るべく定められたクシャトリヤの財宝と勝利の力を奪い、勇猛に生き勝利のみを求める者の誇りを、命のように奪い去る侮辱――
42
Sanskrit
vrīḍānatair āptajanopanītaḥ saṃśayya kṛcchreṇa nṛpaiḥ prapannaḥ / vitānabhūtaṃ vitataṃ pṛthivyāṃ yaśaḥ samūhann iva digvikīrṇam //
Upajāti
和訳
――親族に連れてこられ、恥辱に面を伏せた王たちに辛うじて受け入れられたその侮辱は、天蓋のように地上に広がり四方に散らばった名声をかき集めるかのようだ。
43
Sanskrit
vīryāvadāneṣu kṛtāvamarṣas tanvann abhūtām iva sampratītim / kurvan prayāmakṣayam āyatīnām arkatviṣām ahna ivāvaśeṣaḥ //
Indravajrā
和訳
――武勇の誉れに傷を負わせ、かつての信望をまるで無かったかのようにし、あたかも日の終わりが陽光の伸びを断つように、未来への展望の広がりを断ち切る――
44
Sanskrit
prasahya yo 'smāsu paraiḥ prayuktaḥ smartuṃ na śakyaḥ kim utādhikartum / navīkariṣyaty upaśuṣyad ārdraḥ sa tvad vinā me hṛdayaṃ nikāraḥ //
Upajāti
和訳
敵から我々に力ずくで加えられたあの侮辱は、思い出すことすら堪えがたく、まして克服することなど不可能。汝なき間に、乾きかけた傷のように、再び我が心を新たに苦しめるだろう。
45
Sanskrit
prāpto 'bhimānavyasanād asahyaṃ dantīva dantavyasanād vikāram / dviṣatpratāpāntaritorutejāḥ śaradghanākīrṇa ivādir ahnaḥ //
Upajāti
和訳
誇りの喪失によって象が牙の喪失によるような堪えがたい変容を被り、敵の威勢によって輝かしき光を遮られ、秋雲に覆われた朝日のようになった汝――
46
Sanskrit
savrīḍamandair iva niṣkriyatvān nātyartham astrair avabhāsamānaḥ / yaśaḥkṣayakṣīṇajalārṇavābhas tvam anyam ākāram ivābhipannaḥ //
Upajāti
和訳
――無力ゆえに恥じ入るかのように鈍く輝く武器をもち、名声の衰退によって水の涸れた海のような姿となり、まるで別人のようになった汝――
47
Sanskrit
duḥśāsanāmarṣarajovikīrṇair ebhir vinārthair iva bhāgyanāthaiḥ / keśaiḥ kadarthīkṛtavīryasāraḥ kaccit sa evāsi dhanaṃjayas tvam //
Indravajrā
和訳
――ドゥフシャーサナの暴虐の塵にまみれ、夫があっても名ばかりで、まるで庇護者なきかのようなこの髪によって、武勇の精髄を辱められた汝は、本当にあのダナンジャヤなのですか。

ドゥフシャーサナによるドラウパディーの髪の侮辱はマハーバーラタの有名な場面。ここでドラウパディーはアルジュナを奮い立たせるために辛辣に問いかける。

48
Sanskrit
sa kṣattriyas trāṇasahaḥ satāṃ yas tat kārmukaṃ karmasu yasya śaktiḥ / vahan dvayīṃ yady aphale 'rthajāte karoty asaṃskārahatām ivoktim //
Upajāti
和訳
善き者を守る力ある者がクシャトリヤであり、実戦で力を発揮するものが弓である。実り無き事物に適用されるこの二つの名称は、正しい語源を失った言葉のようだ。
49
Sanskrit
vītaujasaḥ sannidhimātraśeṣā bhavatkṛtāṃ bhūtim apekṣamāṇāḥ / samānaduḥkhā iva nas tvadīyāḥ sarūpatāṃ pārtha guṇā bhajante //
Upajāti
和訳
パールタよ、汝の美徳は光を失い、ただ存在するだけとなって、汝がもたらす繁栄を待ち望み、同じ苦しみを分かつ我々のように、我々と同じ姿を帯びている。
50
Sanskrit
ākṣipyamāṇaṃ ripubhiḥ pramādān nāgair ivālūnasaṭaṃ mṛgendram / tvāṃ dhūr iyaṃ yogyatayādhirūḍhā dīptyā dinaśrīr iva tigmaraśmim //
Indravajrā
和訳
鬣を失った獅子が象に嘲られるように、油断から敵に侮られる汝に、この重荷は汝のふさわしさゆえに担われた。太陽にその輝きゆえに昼の栄光が託されるように。
51
Sanskrit
karoti yo 'śeṣajanātiriktāṃ sambhāvanām arthavatīṃ kriyābhiḥ / saṃsatsu jāte puruṣādhikāre na pūraṇī taṃ samupaiti saṃkhyā //
Upajāti
和訳
行いによってあらゆる人を超える確固たる評価を得た者は、人々の中で優劣が論じられるとき、ただの員数として数えられることはない。
52
Sanskrit
priyeṣu yaiḥ pārtha vinopapatter vicintyamānaiḥ klamam eti cetaḥ / tava prayātasya jayāya teṣāṃ kriyād aghānāṃ maghavā vighātam //
Upendravajrā
和訳
パールタよ、実際に起こらずとも、思い浮かべるだけで愛する者の心が疲れ果てるような不幸――汝が勝利に向けて旅立ったのち、マガヴァーン（インドラ）がそれらの災いを払いたまえ。
53
Sanskrit
mā gāś cirāyaikacaraḥ pramādaṃ vasann asambādhaśive 'pi deśe / mātsaryarāgopahatātmanāṃ hi skhalanti sādhuṣv api mānasāni //
Upajāti
和訳
広く安全なる地に独り長く住んでも、油断に陥ってはならない。嫉妬と欲望に侵された者の心は、善人においてさえ躓くものだから。
54
Sanskrit
tad āśu kurvan vacanaṃ maharṣer manorathān naḥ saphalīkuruṣva / pratyāgataṃ tvāsmi kṛtārtham eva stanopapīḍaṃ parirabdhukāmā //
Upajāti
和訳
それゆえ速やかに大仙の言葉を実行し、我々の願いを叶えておくれ。使命を果たして帰り来たる汝を、胸にしっかり抱きしめたいのだから。」
55
Sanskrit
udīritāṃ tām iti yājñasenyā navīkṛtodgrāhitaviprakārām / āsādya vācaṃ sa bhṛśaṃ didīpe kāṣṭhām udīcīm iva tigmaraśmiḥ //
Upajāti
和訳
ヤージュナセーニー（ドラウパディー）のこの言葉を聞いて、心中に蓄えられた侮辱の記憶が新たにされたアルジュナは、北の方角に至った太陽のように激しく燃え上がった。

yājñasenīはドラウパディーの父ヤジュニャセーナ（ドルパダ）に由来する別名。

56
Sanskrit
athābhipaśyann iva vidviṣaḥ puraḥ purodhasāropitahetisaṃhatiḥ / babhāra ramyo 'pi vapuḥ sa bhīṣaṇaṃ gataḥ kriyāṃ mantra ivābhicārikīm //
Vaṃśastha
和訳
目前に敵を見るかのように、家庭祭司から武器一式を装着されたアルジュナは、本来美しい身体に恐ろしき姿を帯びた。呪術に用いられた真言のように。
57
Sanskrit
avilaṅghyavikarṣaṇaṃ paraiḥ prathitajyāravakarma kārmukam / agatāv aridṛṣṭigocaraṃ śitanistriṃśayujau maheṣudhī //
Viyoginī（Vaitālīya）
和訳
弦の響きと戦功で名高く、敵が引くに引けぬ弓と、鋭い剣を伴った二つの大きな矢筒を携えて――敵の視界に入ったことのないそれらを。

Cappellerの注によれば、敵は背中の矢筒を見たことがない。アルジュナが背を向けて逃げたことがないためだという。

58
Sanskrit
yaśaseva tirodadhan muhur mahasā gotrabhidāyudhakṣatīḥ / kavacaṃ ca saratnam udvahañ jvalitajyotir ivāntaraṃ divaḥ //
Viyoginī（Vaitālīya）
和訳
名声のように己の輝きによってインドラの雷の傷跡をも隠し、宝石を散りばめた鎧を纏って、煌めく光を放つ天空の如く輝いた。
59
Sanskrit
alakādhipabhṛtyadarśitaṃ śivam urvīdharavartma samprayān / hṛdayāni samāviveśa sa kṣaṇam udbāṣpadṛśāṃ tapobhṛtām //
Viyoginī（Vaitālīya）
和訳
クベーラの従者が示した吉祥なる山への道を進みながら、涙に潤む眼をもつ苦行者たちの心にアルジュナはひとときの間入り込んだ。
60
Sanskrit
anujagur atha divyaṃ dundubhidhvānam āśāḥ surakusumanipātair vyomni lakṣmīr vitene / priyam iva kathayiṣyann āliliṅga sphurantīṃ bhuvam anibhṛtavelāvīcibāhuḥ payodhiḥ //
Mālinī
和訳
やがて天空の太鼓の響きに諸方が応え、天の花々が降り注いで虚空に美を繰り広げた。喜ばしき知らせを伝えるかのように、大海は岸辺に寄せる波の腕で震える大地を抱きしめた。
iti bhāravikṛtau mahākāvye kirātārjunīye tṛtīyaḥ sargaḥ //
