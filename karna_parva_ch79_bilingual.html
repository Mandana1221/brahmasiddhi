Mahābhārata — Karṇaparvan, Adhyāya 79 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ79」、全17詩節からなります。カルナとアルジュナの一対一の戦いの場面（第1〜17詩節）で本章は終わります。日本語対訳では複数の詩節が一括して翻訳されています。
karṇaparva — ekonāśītitamo'dhyāyaḥ (79)
第79章　一対一の戦い
dhṛtarāṣṭra uvāca|
samāgame pāṇḍavasṛñjayānāṃ mahābhaye māmakānāmagādhe|
dhanañjaye tāta raṇāya yāte karṇena tadyudvamatho'tra kīdṛk||
// 8-79-1 //
ドリタラーシュトラは語った。
sañjaya uvāca|
teṣāmanīkāni mahādhvajāni raṇe samṛddhāni susaṅgatāni|
bherīnirādonmukharāṇyaṃgarjan meghā iva prāvṛṣi mārutāstāḥ||
mahāgajābhrākulamastratoyaṃ vāditranemītalaśabdavacca|
hiraṇyacitrāyudhavidyutaṃ ca śarāsinārācamahāstradhāram||
tadbhīmavegaṃ rudhiraughavāhi khaṅgākulaṃ kṣatriyajīvaghāti|
anārtavaṃ krūramaniṣṭavarṣaṃ babhūva saṃrambhakaraṃ prajānām||
// 8-79-2-4 //
サンジャヤは語った。
ekaṃ rathaṃ samparivārya mṛtyuṃ nayantyaneke ca rathāḥ sametāḥ|
ekastathaikaṃ rathinaṃ rathāgryāṃs tathā rathaścāpi rathānanekān||
rathaṃ sasūtaṃ sahayaṃ ca kañcit kaścidratī mṛtyuvaśaṃ nināya|
nināya cāpyekagajena kaścid rathānbahūnmṛtyuvaśe tathāśvān||
rathānsasūtānsahayāngajāṃś ca sarvānarīnmṛtyuvaśaṃ śaraughaiḥ|
ninye hayāṃścaiva tathā sasādīn padātisaṅghāṃś ca tathaiva pārthaḥ||
// 8-79-5-7 //
一台の戦車を囲んで多くの戦車が死に導き、一人の戦車戦士が一人を最上の戦車で倒し、一台の戦車が多くの戦車を倒す。ある戦車兵が御者・馬もろとも戦車を死の支配下に導き、一頭の象で多くの戦車を死の支配下に導き、馬をも。そしてアルジュナは矢の群れで全ての敵——戦車・御者・馬・象・騎馬・歩兵を——死の支配下に導いた。
kṛpaḥ śikhaṇḍī ca raṇe sametau duryodhanaṃ sātyakiradhyagacchat|
śrutaśravā droṇaputreṇa sārdhaṃ yudhāmanyuścitrasenena sārdham||
karṇasya putraṃ tu rathī suṣeṇaṃ samāgataṃ sṛñjayaścottamaujāḥ|
gāndhārarājaṃ sahadevo'kṣadhūrtaṃ maharṣabhaṃ siṃha ivābhyadhāvat||
śatānīko nākuliḥ karṇaputraṃ yuvā yuvānaṃ vṛṣasenaṃ śaraughaiḥ|
samārpayatkarṇaputraś ca śūraḥ pāñcāleyaṃ śaravarṣairanekaiḥ||
ratharṣabhaḥ kṛtavarmāṇabhārcchann mādrīputro nakulaścitrayodhī|
pāñcālānāmadhipo yājñaseniḥ senāpatiḥ karṇamārcchatsasainyam||
// 8-79-8-11 //
クリパとシカンディンは戦場で出会い、サーティヤキはドゥルヨーダナに向かった。シュルタシュラヴァスはドローナの子と、ユダーマンユはチトラセーナと。カルナの子スシェーナにスリンジャヤのウッタマウジャスが立ち向かい、サハデーヴァは賭博に長けたガーンダーラ王（シャクニ）に獅子のように突進した。シャターニーカ（ナクラの子）は若いカルナの子ヴリシャセーナと矢の群れを交わし、ナクラはクリタヴァルマンに立ち向かった。パーンチャーラの将軍ヤージュナセーニ（ドリシュタデュムナ）は軍を率いてカルナに向かった。
duḥśāsano bhārata bhārataṃ tu vyāttānanaṃ krūramivāntakābham|
bhīmaṃ raṇe śastrabhṛtāṃ variṣṭhaṃ bhīmaṃ samārcchattamasahyavegam||
karṇātmajaṃ tatra jaghāna vīras tathācchinaccottamaujāḥ prasahya|
tasyottamāṅgaṃ nipapāta bhūmau ninādayadgāṃ ninadena khaṃ ca||
suṣeṇaśīrṣaṃ patitaṃ pṛthivyāṃ vilokya karṇo'tha tadārtarūpaḥ|
krodhāddhayāṃstasya rathaṃ dhvajaṃ ca bāṇaiḥ sudhārairniśitairakṛntat||
sa tūttamaujā niśitaiḥ pṛṣatkair vivyādha khaṅgena ca bhāsvareṇa|
pārṣṇigrahāṃścaiva kṛpasya hatvā śikhaṇḍivāhaṃ sa tato'dhyarohat||
kṛpaṃ tu dṛṣṭvā virathaṃ rathastho naicchaccharaistāḍayituṃ śikhaṇḍī|
taṃ drauṇirāvārya rathaṃ kṛpasya samujjahe paṅkagatāṃ yathā gām||
hiraṇyavarmā niśitaiḥ pṛṣatkais tavātmajānāmanilātmajo vai|
atāpayatsainyamatīva bhīmaḥ kāle śucau madhyagato yathā'rkaḥ||
// 8-79-12-17 //
ドゥフシャーサナは、口を開けた死神のように恐ろしい、武器持ちの中の最上者、耐え難い速さのビーマに戦場で挑んだ。勇者ウッタマウジャスはカルナの子スシェーナを殺し、その首が大地に落ち、音で天地を震わせた。スシェーナの首が大地に落ちるのを見て、カルナは苦悶の表情となり、怒りからウッタマウジャスの馬・戦車・旗を鋭い矢で切り裂いた。ウッタマウジャスは鋭い矢と輝く剣でカルナを射、クリパの従者を殺し、シカンディンの戦車に乗った。戦車を失ったクリパを見て、シカンディンは矢で打とうとしなかった。ドローナの子がクリパの戦車を持ち上げた——泥に嵌った牛を引き上げるように。黄金の鎧を着けたビーマは、風の子として、鋭い矢でお前の息子たちの軍を灼いた——夏の真昼の太陽のように。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekonāśītitamo'dhyāyaḥ|| 79 ||
