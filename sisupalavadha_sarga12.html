Śiśupālavadha

Māgha · Sarga XII
マーガ作『シシュパーラヴァダ』第十二章——ヴァッラバデーヴァ注・マッリナータ注に基づく対訳

द्वादशः सर्गः

第十二章　出発の描写（prasthāna-varṇana）
韻律：upajāti（ウパジャーティ）——indravṃśā / vaṃśastha 混合　12音節/pāda
V.1
Sanskrit (IAST) itthaṃ rathāśvebhaniṣādināṃ prage gaṇo nṛpāṇām atha toraṇād bahiḥ / prasthānakālakṣamaveṣakalpanākṛtakṣaṇakṣepam udaikṣatācyutam //
和訳

このように暁を迎えた頃、戦車・馬・象に乗り込んだ諸王の一団は、城門の外に出て、出発にふさわしい装いの仕度に僅かな時を費やしたアチュタを仰ぎ見た。

注

【Vallabhadeva】

rathāśvebhaniṣādinām＝戦車・馬・象に座する者たちの。toraṇād bahiḥ＝城門の外で。veṣakalpanā＝出立にふさわしい装束の仕度。kṛtakṣaṇakṣepam＝僅かな時間の遅れを生じたところの（アチュタを）。韻律はvaṃśastha（偶数pāda）とindravṃśā（奇数pāda）の混合によるupajāti。

【Mallinātha】

ittham＝前章で述べたような仕方で。prage＝早朝に（Amarakoṣa「sāye sāye prage prātaḥ」）。toraṇa＝外門（Amarakoṣa「toraṇo'strī bahirdvāram」）。prasthānakāle kṣamaḥ ucitaḥ veṣaḥ＝出発時にふさわしい装い。本章の奇数pādaにはindravṃśā（ta-ta-ja-ga）、偶数pādaにはvaṃśastha（ja-ta-ja-ra）を用い、両者の混合によりupajātiとなる。修辞法はkāvyaliṅga（詩的根拠）——アチュタの遅れの原因が装束の仕度にあると述べることで待機の理由を示す。

V.2
Sanskrit (IAST) svakṣaṃ supatraṃ kanakojjvaladyutiṃ javena nāgāñ jitavantam uccakaiḥ / āruhya tārkṣyaṃ nabhasīva bhūtale yayāv anudghātasukhena so 'dhvanā //
和訳

車軸は堅牢で車体は精巧、黄金の輝きを放ち、速さにおいて蛇をも凌ぐその高い車に乗り、彼は大地の上をあたかも天空を行くかのごとく、何の障りもなく快適に道を進んだ。

注

【Vallabhadeva】

supatram＝車体の優れた（ratha）。別義ではsupatram＝美しい翼を持つ（garuḍa）。kanakojjvaladyutim＝黄金装飾で輝く。別義では金色の光を放つ。nāgān＝蛇（速さで蛇に勝る）。別義ではnāgānta＝蛇の敵（ガルダ）。tārkṣyam＝車。別義ではガルダ。anudghātasukhena＝障害なく快適に。ガルダに乗って天を行くように、車で地上をも妨げなく行ったという趣意。

【Mallinātha】

svakṣam＝良い車軸を持つ（Vaijayantī「akṣaḥ cakradhāraṇaḥ」）。別義ではsu+akṣa＝良い感覚器官を持つ。tārkṣya＝車（Viśva）。別義ではガルダ。全体としてśleṣasaṃkīrṇā upamā（掛詞を伴う直喩）——車を本義、ガルダを比喩として、両義が掛詞により重なる。GRETILはmukhenaと読むがsukhenaが正しい（両注確認）。

V.3
Sanskrit (IAST) hastasthitākhaṇḍitacakraśālinaṃ dvijendrakāntaṃ śritavakṣasaṃ śriyā / satyānuraktaṃ narakasya jiṣṇavo guṇair nṛpāḥ śārṅgiṇam anvayāsiṣuḥ //
和訳

手に不壊の円盤を持ち、鳥の王に愛され、胸にシュリーを戴き、真実に執着し、ナラカを征した——そのシャールンギン（弓の主クリシュナ）に、諸王はその徳ゆえに従った。

注

【Vallabhadeva】

śleṣa（掛詞）による二重描写。ヴィシュヌについて：hastasthita-akhaṇḍita-cakra＝手にある不壊のスダルシャナ円盤、dvijendrakānta＝ガルダに愛される、śriyā śritavakṣasam＝ラクシュミーが胸に宿る、satyānuraktam＝サティヤバーマーに愛着する、narakasya jiṣṇu＝ナラカースラの征服者。諸王について：cakra＝掌の相好線、dvijendrakānta＝バラモンに愛される、śrī＝王の威光、satya＝真実の言葉、naraka＝地獄。

【Mallinātha】

同様のśleṣa解釈を展開。dvijendra＝ガルダ（鳥の王）。別義ではdvijendra＝月（candra）、あるいはバラモンの長。satyā＝サティヤバーマー（クリシュナの妃）。anvayāsiṣuḥ＝anu+√yāの複数アオリスト「従った」。GRETILのdvajendra（旗の王）はdvijendra（鳥の王）の誤り（両注確認）。同じくanyayāsiṣuḥはanvayāsiṣuḥの誤り。

V.4
Sanskrit (IAST) śuklaiḥ satārair mukulīkṛtaiḥ sthūlaiḥ kumudvatīnāṃ kumudākarairiva / vyuṣṭaṃ prayāṇaṃ ca viyogavedanāvidūnanārīkam abhūt samaṃ tadā //
和訳

白く星のような飾りをちりばめ、蕾のように畳まれた大きな天幕は、蓮池の白睡蓮の群れにも似て——そのとき夜明けと軍の出立は、別離の苦しみに悶える女たちを伴うという点で、等しかった。

注

【Vallabhadeva】

vyuṣṭam（夜明け）とprayāṇam（出発）の二つが「同じ」（samam）であったとする。両者の共通点：白く（śuklaiḥ）大きな天幕＝白く咲いた睡蓮、satāraiḥ＝星のある（天幕の飾り金具＝夜空の星）、mukulīkṛtaiḥ＝畳まれた（天幕を携帯用に巻く＝夜明けに睡蓮が萎む）、viyogavedanāvidūnanārīkam＝別離の苦悩に責められる女たちがいること（出征で夫と別れる＝夜明けで情人と別れる）。śleṣasaṃkīrṇā upamā。

【Mallinātha】

kumudvatīnām＝「白睡蓮の多い土地」（Amarakoṣa）、またはkairavṇī（白蓮の池）。sthūlaiḥ＝大きい（天幕を指す）。vyuṣṭam＝夜明け（Abhidhānacintāmaṇi「vyuṣṭaṃ prabhātaṃ pratyūṣam」）。二つのsamudāya（集合体）が一つのabhūtで表現される。

V.5
Sanskrit (IAST) utkṣiptagātraḥ sma viḍambayann abhaḥ samutpatiṣyantam agendram uccakaiḥ / ākuñcitaprohanirūpitakramaṃ kareṇur ārohayate niṣādinam //
和訳

前肢を高く上げ、天に飛び立たんとする大山を真似るかのように聳え立つ象は、前脚を曲げて足場を示しつつ、調教師を自らの背に乗せた。

注

【Vallabhadeva】

utkṣiptagātraḥ＝前肢を持ち上げた。agendram＝大山（aga+indra）。天に飛び立とうとする山のように巨体を聳えさせるという描写。ākuñcitaprauḍhanirūpitakramam＝曲げた前脚（prauḍha＝後肢の関節部）で足の置き場を示す。象が自ら調教師を乗せる——ārohayate＝「乗らせる」使役のātmanepada。

【Mallinātha】

uccakaiḥ＝高く。viḍambayan＝真似る（ullekha修辞法、あるいはabhūtopamā）。proha＝象の前脚（Viśva「gajāṅghriḥ prohaḥ」）。kareṇu＝象（Amarakoṣa「kareṇur gajī」は牝象だが、ここでは雄象にも用いる）。ārohayate＝使役＋ātmanepada——象が自ら騎手を乗せる行為を表す。svabhāvoktī（自然描写）。

V.6
Sanskrit (IAST) svairaṃ kṛtāsphālanalālitān puraḥ sphurattanūn darśitalāghavakriyāḥ / vaṅgāvalagnaikasavalgapāṇayas turaṅgamān āruruhus turaṅgiṇaḥ //
和訳

まずゆっくりと手で叩いてなだめた馬——身を震わせるその馬に、軽やかな身のこなしを見せつつ、鞍の縁に片手をかけ手綱を握って、騎手たちは飛び乗った。

注

【Vallabhadeva】

kṛtāsphālanalālanān＝（Valの読み）手で叩いて撫でた馬たち。vaṅga＝鞍の前縁部分。avalagna＝しがみついた。savalgapāṇayaḥ＝片手に手綱を持つ。

【Mallinātha】

āsphālana＝手の平で体を叩くこと。lālitān＝慈しんだ（causalの過去分詞、upapālitān）。sphurattanūn＝震える体の（馬たちを）。vaṅga＝鞍の部品（Viśva「vaṅkaḥ palyāṇabhāge syāt」）。darśitalāghavakriyāḥ＝素早さの技を見せた。svabhāvoktī。GRETILのsphuratnūn（11音節）はsphurattanūn（12音節）の脱字。同じくlalitānはlālitānの誤り（長母音）。

V.7
Sanskrit (IAST) ahnāya yāvan na cakāra bhūyase niṣedivān āsanabandham adhvane / tīvrotthitās tāvad asahyaraṃhaso viśṛṅkhalaṃ śṛṅkhalakāḥ pratasthire //
和訳

長旅に備えて座った御者が鞍をまだ締め終えぬうちに、猛然と立ち上がった駱駝たちは、抑えがたい勢いで、繋ぎも解けたまま走り出した。

注

【Vallabhadeva】

niṣedivān＝座った者（liṭのkasu接尾辞）。āsanabandha＝長旅用の鞍の固定。śṛṅkhalakāḥ＝駱駝（karabhāḥ）。tīvram utthitāḥ＝激しく立ち上がった。asahyaraṃhasaḥ＝耐えがたい速度の。viśṛṅkhalam＝束縛なく。

【Mallinātha】

addāya（Mallの読み）＝素早く（Amarakoṣa「drāk jhaṭity asahāddāya」）。GRETILおよびVallabhadevaはahnāyaと読む（異読）。niṣedivān＝座った者（nis+√sad、kasu接尾辞、「āpāyāṃ sadavasathyuḥ」）。bhūyase adhvane＝さらに長い旅路のために（kriyārthopapada-caturthī）。śṛṅkhalakāḥ＝駱駝（Amarakoṣa）。svabhāvoktī。

V.8
Sanskrit (IAST) gaṇḍojjvalām ujjvalanābhicakrayā virājamānāṃ navayodaraśriyā / kaścit sukhaṃ prāptumanāḥ susārathī rathīṃ yuyojāvidhurāṃ vadhūm iva //
和訳

頬の艶やかな、車軸の煌めく車輪を備え、新しい車体の美で輝き、轅の壊れぬ戦車を——ある者は快適な旅を望み、良き御者を伴って、あたかも花嫁を娶るように、軛をかけた。

注

【Vallabhadeva】

śleṣa（掛詞）で戦車と花嫁を重ねる。gaṇḍa＝車体の側面（戦車）／頬（花嫁）。ujjvalanābhicakra＝輝く車軸の車輪／輝く臍の周り。navayodaraśrī＝新しい車体の中央部の美／若々しい腰の美。avidhurā＝轅の壊れていない（車）／悲嘆のない（女）。

【Mallinātha】

rathī＝戦車の乗り手、また恋する男。susārathī＝良き御者を持つ、また良き伴侶を持つ。prāptumanāḥ＝得たいと望む心の（「tuṃ kāmamanasopi」によるmaの脱落）。vidhurā＝轅（dhūr）が失われた者、それがない（a-vidhurā）＝完全な。GRETILのadhidhurāṃはavidhurāṃの誤り（両注確認）。また gaṇḍojvalām ujjvanā-はgaṇḍojjvalām ujjvalanā-の脱字（pāda aが11音節→12音節）。śabdārtha-śleṣa。

V.9
Sanskrit (IAST) utthātum icchan vidhṛtaḥ puro balān nidhīyamāne bharabhāji yantrake / ardhojjhitodgāravijharjharasvaraḥ svanāma ninye ravaṇaḥ sphuṭārthatām //
和訳

重い荷枠を載せられる最中、力ずくで立ち上がろうとして前方を押さえつけられた駱駝は、半ば漏れ出る噫気のように濁った声で唸り——「ラヴァナ（吼える者）」という己が名を、まさしく言い当てたものにした。

注

【Vallabhadeva】

ravaṇa＝駱駝（ru「吼える」＋yuc接尾辞）。svanāma＝自分の名を。sphuṭārthatām ninye＝明白な意味あるものとした。bhara-bhāji yantrake＝荷を負う枠（鞍台）が載せられている時。balāt＝力ずくで。ardhojjhitodgāra＝半ば漏れ出た噫気。vijharjhara＝がらがらした。

【Mallinātha】

Mallinātha異読：adhojjhitodāra-vijṛmbhirasvaraḥ＝下方に放たれた大きな欠伸のような声。ravaṇa＝「ru（音を立てる）」より「calanśabdārthakarmakād yuc」で形成。svanāma sphuṭārthatāṃ ninye＝吼えることで「吼える者」という名が事実に即したものとなった。

V.10
Sanskrit (IAST) nasyāgṛhīto 'pi dhuvan viṣāṇayor yugaṃ sasūtkāravivartitatrikaḥ / goṇīṃ janena sma nidhātum uddhṛtām anukṣaṇaṃ nokṣataraḥ pratīcchati //
和訳

鼻綱で押さえられてもなお角の対を振り立て、唸り声とともに腰をよじる牡牛は、人が背に荷袋を載せようと持ち上げるたびに、頑としてそれを受け入れなかった。

注

【Vallabhadeva】

ukṣataraḥ＝大きな牡牛。nasyā＝鼻綱（nāsikāyāṃ bhavā、yat接尾辞）。viṣāṇayoḥ yugam＝二本の角の対を。dhuvan＝揺り動かしつつ。saśatkāra（Valの読み）＝唸り声とともに。vivartitatrikaḥ＝腰の関節（trika＝pṛṣṭhavaṃśādhara-sandhi）をよじった。goṇī＝荷袋。janena＝人が。

【Mallinātha】

nasyā＝鼻に付ける縄（Amarakoṣa）。satkāra＝擬音語（śabdānukaraṇa）、あるいは怒りの鼻息。trika＝背骨の下端の関節部（Amarakoṣa「pṛṣṭhavaṃśādhare trikam」）。goṇī＝荷袋。nidhātum uddhṛtām＝載せるために持ち上げた。na pratīcchati＝受け入れない——何度も振り払ったの意。GRETILのjananaはjanena（具格）の誤り。Mallの読みsasatkāraに対しGRETILはsasūtkāra（異読）。

V.11
Sanskrit (IAST) nānāvidhāviṣkṛtasāmajasvaraḥ sahasravartmā capalaiduradhyayaḥ / gāndharvabhūyiṣṭhatayā samānatāṃ sa sāmavedasya dadhau balodadhiḥ //
和訳

さまざまな象の声を響かせ、千の道を持ち、落ち着きなき馬の多さゆえに近づきがたい——その軍勢の海は、サーマヴェーダとの同等を示した。

注

【Vallabhadeva】

śleṣa（掛詞）で軍勢の海とサーマヴェーダを重ねる。sāmaja＝象（sāman＝サーマ讃歌を歌うブラフマンから生まれた）、同時にsāma＝サーマ讃歌から生じた音。sahasravartman＝千の道を行く軍隊／千の分枝を持つヴェーダ。gāndharvabhūyiṣṭhatā＝ガンダルヴァ（＝馬、Amarakoṣa）の多さ／ガーンダルヴァ（歌謡）の多さ。capalaiḥ duradhyayaḥ＝不安定な者たちには習得しがたい（ヴェーダ）／落ち着きなき馬たちには制御しがたい（軍勢）。

【Mallinātha】

同様のśleṣa解釈。gāndharvabhūyiṣṭhatā＝馬（gandharvāḥ = aśvāḥ、Amarakoṣa「vāji-vāhārva-gandharvā-」）が多いこと、同時にgāndharva（音楽）が豊富なこと。duradhyaya＝√iṇ（学ぶ）のkhal接尾辞で「習得しがたい」、同時に「渡りがたい」。GRETILのāviṣkṛsāmaja-（11音節）はāviṣkṛtasāmaja-（12音節）の脱字。同じくbhūyṣṭhatayāはbhūyiṣṭhatayā（「i」脱落）。

V.12
Sanskrit (IAST) pratyanyanāgaṃ calitasvarāvatā nirasya kuṇṭhaṃ dadhatānyamaṅkuśam / mūrdhānamūrdhvāyatadantamaṇḍalaṃ dhuvannarodhi dvirado niṣādinā //
和訳

敵の象に向かって走り出した象は、声を荒げて駆ける御者が鈍った刺し棒を捨て、鋭い別のものを手にして——上向きに伸びた牙の列ある頭を振りながらも——制された。

注

【Vallabhadeva】

anyam nāgam prati＝敵の象に向かって。calita＝駆け出した。svarāvatā niṣādinā＝声を上げる調教師によって。kuṇṭham＝鈍った刺し棒を。nirasya＝捨てて。anyam aṅkuśam＝別の鋭い棒を。dadhatā＝手にしつつ。mūrdhānam ūrdhvāyata-danta-maṇḍalam＝上に伸びた牙の連なりある頭を。dhuvan＝揺り動かしつつ。arodhi＝制された（受動アオリスト）。

【Mallinātha】

arodhi＝受動態アオリスト（karmaṇi luṅ）。kuṇṭham＝鈍い（atīkṣṇam）刺し棒を捨て、別の鋭いものを持って。calitasvarāvatā＝声を荒げた御者によって。GRETILのcaltastarāvatā（11音節）はcalitasvarāvatā（12音節）への二重の誤り（li脱落、s/t→sv混同）。また文末のdviradāṃ（属格複数）はdvirado（主格単数）の誤り（両注確認）。

V.13
Sanskrit (IAST) samūrcchaducchṛṅkhalaśaṅkhanisvanaḥ svanaḥ prayāte paṭahasya śārṅgiṇi / sattvāni ninye nitarāṃ mahāntyapi vyathāṃ dvayeṣāmapi medinībhṛtām //
和訳

奔放に広がる法螺の音を伴い、弓の主が出立するとき鳴り渡った戦鼓の響きは、二種の「大地を支える者」——王たちと山々——のいかに強大な気力をも苦しめた。

注

【Vallabhadeva】

śleṣaで二重の意味。medinībhṛtām＝大地を支える者たち、すなわち王たちと山々。dvayeṣām api＝両方の。sattvāni＝気力（王について）、また生き物（山について＝山に棲む獅子など）。vyathām ninye＝苦しめた。samūrcchad＝増大する。ucchṛṅkhala＝制限なき。クリシュナの太鼓の音を聞いて、敵の王たちは圧倒の恐れに苦しみ、山の獣たちは驚いた。

【Mallinātha】

mūrcchā＝「増大・昏倒」（√mūrch）。medinībhṛtām dvayeṣām＝王たち（大地の守護者）と山々（大地を支える者）の両方。sattvāni＝sattva（①勇気・力、②生物、Śāśvata引用）。GRETILのsvānininye（意味不明の合字）はsattvāni ninye（「気力を苦しめた」）の大きな誤り。同じくmedinīghṛtāmはmedinībhṛtām（gh→bhの混同）。

V.14
Sanskrit (IAST) kālīyakakṣodavilepanaśriyaṃ diśaddiśāmullasadaṃśumaddyutiḥ / khātaṃ khurairmudgabhujāṃ vipaprthe gireradhaḥ kāñcanabhūmijaṃ rajaḥ //
和訳

馬の蹄に掘り起こされ、陽光のごとく輝き、四方に紅粉の化粧の美を与えつつ——金山の麓から生じた黄金の土埃が広がった。

注

【Vallabhadeva】

kāñcanabhūmijam rajaḥ＝黄金の大地から生じた埃。gireradhaḥ＝山の麓で（重さゆえに遠くへは行かず）。khurairmudgabhujām＝馬（mudgabhuj＝穀物を食す者）の蹄で掘られた。diśaddiśām＝四方に与える。kālīyakakṣodavilepanaśriyam＝紅粉（kālīyaka＝紅花の粉末）による塗り物の美を。ullasadaṃśumaddyutiḥ＝昇る太陽のような輝きの。

【Mallinātha】

kālīyaka＝サフランの粉（Śāśvata「kāśmīrajanma ghuṣaṇaṃ kālīyaṃ kuṅkumaṃ viduḥ」）。mudgabhuja＝穀物を食す者＝馬。aṃśumaddyutiḥ＝日光のような光。GRETILのdiśaddiśam（短母音）はdiśaddiśām（属格複数「四方の」）の誤り。同じくvipaprate（t）はvipaprthe（√prathの受動完了、th）の誤り。

V.15
Sanskrit (IAST) mandrairgajānāṃ rathamaṇḍalasvanairnijuhuve tādṛśameva bṛṃhitam / tārairbabhūve parabhāgalābhataḥ pariśphuṭaisteṣu turaṅgaheṣitaiḥ //
和訳

低く轟く戦車群の音に、同じく低い象の咆哮はかき消された。しかしそれら低音の只中にあって、鋭い馬の嘶きだけは、音域の優位ゆえに、くっきりと聞こえた。

注

【Vallabhadeva】

mandraiḥ＝低音の。rathamaṇḍalasvanaiḥ＝戦車群の轟音によって。tādṛśam＝同じ性質の（低い音という点で）。bṛṃhitam＝象の咆哮は。nijuhuve＝覆い隠された（ni+√hu受動完了）。tāraiḥ＝高い音の。parabhāgalābhataḥ＝優位の音域を得ているため。pariśphuṭaiḥ＝明瞭な。turaṅgaheṣitaiḥ＝馬の嘶きによって。babhūve＝（明瞭に）なった。

【Mallinātha】

mandraḥ＝低い音（Amarakoṣa「mandrastu gambhīre」）。bṛṃhita＝象の声（Amarakoṣa「bṛṃhitaṃ kariṇāṃ śabdo heṣā heṣā ca vājinām」）。象の咆哮と戦車の音は同じ低音域のため一体化して聞き分けられなくなった。しかし高音の馬の嘶きはその中で際立った。nijuhuve＝受動完了。babhūve＝存在の完了（bhāve liṭ）。GRETILのmandrai-（r脱落）はmandrair-、nijuhnuveはnijuhuve（n混入）。

V.16
Sanskrit (IAST) anvetukāmo 'vamatāṅkuśagrahastirogataṃ sāṅkuśamudvahañśiraḥ / sthūloccayenāgamadantikāgatāṃ gajo 'grayātāgrakaraḥ kareṇukām //
和訳

近くに来た牝象を追おうとして、刺し棒使いの制止を侮り、刺し棒ごと振り向けた頭を掲げ、鼻先を伸ばして、象は重々しい足取りで進んだ。

注

【Vallabhadeva】

antikādgatāṃ kareṇukāṃ anvetukāmaḥ＝近くに来た牝象を追いたくて。aṅkuśagrahaḥ＝刺し棒を握る者（調教師）。avamata＝侮った。tirogataṃ śiraḥ＝（刺し棒の引きで）横に向けられた頭を。sāṅkuśam udvahan＝刺し棒がついたまま持ち上げつつ。agrayātāgrakaraḥ＝鼻（agrakara）を前方に伸ばした。sthūloccayena＝重々しい歩調で（sthūloccaya＝象の特有の歩き方、Ratnaprakāśa引用）。

【Mallinātha】

aṅkuśagraha＝刺し棒を握る者、すなわち象使い。avamata＝無視された。sthūloccaya＝象の特有の重い歩行（Ratnaprakāśa「gajāmadhyagatau sthūloccayaḥ」）。jāti修辞法。GRETILのaṅguśa（二箇所）はaṅkuśa（g→k）の誤り。

V.17
Sanskrit (IAST) yānto 'spṛśantaścaraṇairivāvaniṃ javātprakīrṇairabhitaḥ prakīrṇakaiḥ / adyāpi senāturagāḥ savismayairalūnapakṣā iva menire janaiḥ //
和訳

疾走して地に蹄が触れぬかのごとく駆け、両脇にチャーマラ飾りを靡かせる軍馬たちは、今なお人々に「翼を切られていないのでは」と驚きをもって見なされた。

注

【Vallabhadeva】

古い伝承では馬にはかつて翼があり、神々によって切られたとされる。senāturagāḥ＝軍馬たち。avaniṃ caraṇair aspṛśanta iva＝大地に脚が触れないかのように。javāt＝速さゆえに。abhitaḥ prakīrṇaiḥ prakīrṇakaiḥ＝両側に広がるチャーマラ（首飾りの房）によって。alūnapakṣāḥ iva＝翼を切られていないかのように。savismayaiḥ janaiḥ menire＝驚く人々に見なされた（受動完了）。

【Mallinātha】

prakīrṇaka＝チャーマラ（Amarakoṣa「cāmaraṃ tu prakīrṇakam」）。首飾りのチャーマラ飾りが翼のように見え、また地に触れぬほどの速さから、かつて翼があったはずの馬たちがまだ翼を切られていないのではと人々が驚いた。GRETILのyanto（短母音）はyānto（√yāの現在分詞、長母音）の誤り。

V.18
Sanskrit (IAST) ṛjvīrdadhānairavatatya kandharāścalāvacūḍāḥ kalagharghararāravaiḥ / bhūmirmahatyapyavilambitakramaṃ kramelakaistatkṣaṇameva cicchide //
和訳

首をまっすぐに伸ばし、揺れる飾り房のがらがら鳴る音を響かせつつ、駱駝たちは広大な大地をも、遅滞なき歩みでたちまちに踏破した。

注

【Vallabhadeva】

kramelaka＝駱駝。ṛjvīḥ kandharāḥ avatatya dadhānaiḥ＝まっすぐな首を伸ばして保ちつつ。calāvacūḍāḥ＝揺れる飾り房を持つ。gharghara＝小鈴の擬音（śabdānukaraṇa）。avilambitakramam＝遅れない歩調で。tatkṣaṇam eva＝まさにその瞬間に。mahatīm api bhūmim cicchide＝広大な地をも踏破した。

【Mallinātha】

avatatya＝伸ばして（vi+√tan）。cūḍā＝頭飾り（Yādava「śiraḥ-śikhā-bhūṣaṇeṣu cūḍā」）。gharghara＝小鈴（koṣa「ghargharā kṣudraghaṇṭī syāt」）、あるいは擬音語。kramelaka＝駱駝。krama＝歩み（padakṣepa）。svabhāvoktī。GRETILのkalā-（長母音）はkala-（「美しい音の」、短母音）の誤り。同じくtakṣaṇam（t一つ）はtatkṣaṇam（「その瞬間に」、t二つ）の脱字。

V.19
Sanskrit (IAST) tūrṇaṃ praṇetrā kṛtanādamuccakaiḥ praṇoditaṃ vesarayugmamadvani / ātmīyanemikṣatasāndramedinīrajaścayākrāntabhayādivādravat //
和訳

御者に大声で叱咤され、高く嘶きつつ駆り立てられた騾馬の二頭曳きの車は、自らの車輪が抉った濃い土埃の群れに追われるかのごとく、道を疾駆した。

注

【Vallabhadeva】

vesara＝交雑種の馬（saṅkarāśva）。yugmam＝二頭曳きの車。praṇetrā＝御者。uccakaiḥ kṛtanādam praṇoditam＝大声を上げさせ駆り立てた。ātmīyanemikṣatasāndramedinīrajaścayākrāntabhayāt iva＝自らの車輪が抉った濃い土埃の山に圧されるかのように。tūrṇam advani adravat＝速やかに道を駆けた。

【Mallinātha】

praṇetrā＝御者（sārathī）。praṇoditam＝走るよう駆り立てられた。vesara＝交雑馬（Mallinātha「saṅkarāśvo vesaraḥ」）。ātmīyanemi＝自らの車輪の縁。kṣata＝削った。sāndra＝密な。medinīrajas＝大地の塵。śraya＝群れ。ākrānti＝襲いかかること。GRETILのtūrṇa（anusvāra欠落）はtūrṇaṃ。同じくvesarayugmadhvani（11音節）はvesarayugmamadvani（12音節）——yugmam＋advani（道において）に分かれる。

V.20
Sanskrit (IAST) vyāvṛttavaktrairakhilaiścamūcarairvrajadbhireva kṣaṇamīkṣitānanāḥ / valgadgarīyaḥstanakamprakañcukaṃ yayusturaṅgādhiruho 'varodhikāḥ //
和訳

全軍の兵士たちが振り返り一瞬その顔を見つめるなか、揺れ動く豊かな胸に震える上衣をまとい、後宮の女たちも馬に乗って出発した。

注

【Vallabhadeva】

avarodhikāḥ＝後宮の女たち（avarodhastriyaḥ）。turaṅgādhiruhaḥ＝馬に乗る者（turagān adhiruhantī iti kip）。vyāvṛttavaktraiḥ＝振り返った顔の。akhilaiḥ camūcaraiḥ＝すべての軍の者たちによって。kṣaṇam īkṣitānanāḥ＝一瞬顔を見られた。valgat＝揺れ動く。garīyaḥstana＝大きな乳房の。kampra＝震える（√kamp + ra接尾辞）。kañcukam＝上着。

【Mallinātha】

vyāvṛttavaktra＝振り返った顔の。vrajat＝行く（√vraj現在分詞）。camūcaraiḥ＝軍の者たちによって。garīyas＝より重い＝豊かな（gurutaraiḥ、比較級）。kampra＝震えやすい性質の（「nami-kamp-」よりra接尾辞）。kañcuka＝上着。GRETILのvrajidbhir（i）はvrajadbhir（a、√vrajの現在分詞は vrajat-）の誤り。
