Māgha · Sarga XII
マーガ作『シシュパーラヴァダ』第十二章——ヴァッラバデーヴァ注・マッリナータ注に基づく対訳

द्वादशः सर्गः

第十二章　出発の描写（prasthāna-varṇana）
韻律：upajāti（ウパジャーティ）——indravṃśā / vaṃśastha 混合　12音節/pāda
V.1
Sanskrit (IAST) itthaṃ rathāśvebhaniṣādināṃ prage gaṇo nṛpāṇām atha toraṇād bahiḥ / prasthānakālakṣamaveṣakalpanākṛtakṣaṇakṣepam udaikṣatācyutam //
和訳

このように暁を迎えた頃、戦車・馬・象に乗り込んだ諸王の一団は、城門の外に出て、出発にふさわしい装いの仕度に僅かな時を費やしたアチュタを仰ぎ見た。

注

【Vallabhadeva】

rathāśvebhaniṣādinām＝戦車・馬・象に座する者たちの。toraṇād bahiḥ＝城門の外で。veṣakalpanā＝出立にふさわしい装束の仕度。kṛtakṣaṇakṣepam＝僅かな時間の遅れを生じたところの（アチュタを）。韻律はvaṃśastha（偶数pāda）とindravṃśā（奇数pāda）の混合によるupajāti。

【Mallinātha】

ittham＝前章で述べたような仕方で。prage＝早朝に（Amarakoṣa「sāye sāye prage prātaḥ」）。toraṇa＝外門（Amarakoṣa「toraṇo'strī bahirdvāram」）。prasthānakāle kṣamaḥ ucitaḥ veṣaḥ＝出発時にふさわしい装い。本章の奇数pādaにはindravṃśā（ta-ta-ja-ga）、偶数pādaにはvaṃśastha（ja-ta-ja-ra）を用い、両者の混合によりupajātiとなる。修辞法はkāvyaliṅga（詩的根拠）——アチュタの遅れの原因が装束の仕度にあると述べることで待機の理由を示す。

V.2
Sanskrit (IAST) svakṣaṃ supatraṃ kanakojjvaladyutiṃ javena nāgāñ jitavantam uccakaiḥ / āruhya tārkṣyaṃ nabhasīva bhūtale yayāv anudghātasukhena so 'dhvanā //
和訳

車軸は堅牢で車体は精巧、黄金の輝きを放ち、速さにおいて蛇をも凌ぐその高い車に乗り、彼は大地の上をあたかも天空を行くかのごとく、何の障りもなく快適に道を進んだ。

注

【Vallabhadeva】

supatram＝車体の優れた（ratha）。別義ではsupatram＝美しい翼を持つ（garuḍa）。kanakojjvaladyutim＝黄金装飾で輝く。別義では金色の光を放つ。nāgān＝蛇（速さで蛇に勝る）。別義ではnāgānta＝蛇の敵（ガルダ）。tārkṣyam＝車。別義ではガルダ。anudghātasukhena＝障害なく快適に。ガルダに乗って天を行くように、車で地上をも妨げなく行ったという趣意。

【Mallinātha】

svakṣam＝良い車軸を持つ（Vaijayantī「akṣaḥ cakradhāraṇaḥ」）。別義ではsu+akṣa＝良い感覚器官を持つ。tārkṣya＝車（Viśva）。別義ではガルダ。全体としてśleṣasaṃkīrṇā upamā（掛詞を伴う直喩）——車を本義、ガルダを比喩として、両義が掛詞により重なる。GRETILはmukhenaと読むがsukhenaが正しい（両注確認）。

V.3
Sanskrit (IAST) hastasthitākhaṇḍitacakraśālinaṃ dvijendrakāntaṃ śritavakṣasaṃ śriyā / satyānuraktaṃ narakasya jiṣṇavo guṇair nṛpāḥ śārṅgiṇam anvayāsiṣuḥ //
和訳

手に不壊の円盤を持ち、鳥の王に愛され、胸にシュリーを戴き、真実に執着し、ナラカを征した——そのシャールンギン（弓の主クリシュナ）に、諸王はその徳ゆえに従った。

注

【Vallabhadeva】

śleṣa（掛詞）による二重描写。ヴィシュヌについて：hastasthita-akhaṇḍita-cakra＝手にある不壊のスダルシャナ円盤、dvijendrakānta＝ガルダに愛される、śriyā śritavakṣasam＝ラクシュミーが胸に宿る、satyānuraktam＝サティヤバーマーに愛着する、narakasya jiṣṇu＝ナラカースラの征服者。諸王について：cakra＝掌の相好線、dvijendrakānta＝バラモンに愛される、śrī＝王の威光、satya＝真実の言葉、naraka＝地獄。

【Mallinātha】

同様のśleṣa解釈を展開。dvijendra＝ガルダ（鳥の王）。別義ではdvijendra＝月（candra）、あるいはバラモンの長。satyā＝サティヤバーマー（クリシュナの妃）。anvayāsiṣuḥ＝anu+√yāの複数アオリスト「従った」。GRETILのdvajendra（旗の王）はdvijendra（鳥の王）の誤り（両注確認）。同じくanyayāsiṣuḥはanvayāsiṣuḥの誤り。

V.4
Sanskrit (IAST) śuklaiḥ satārair mukulīkṛtaiḥ sthūlaiḥ kumudvatīnāṃ kumudākarairiva / vyuṣṭaṃ prayāṇaṃ ca viyogavedanāvidūnanārīkam abhūt samaṃ tadā //
和訳

白く星のような飾りをちりばめ、蕾のように畳まれた大きな天幕は、蓮池の白睡蓮の群れにも似て——そのとき夜明けと軍の出立は、別離の苦しみに悶える女たちを伴うという点で、等しかった。

注

【Vallabhadeva】

vyuṣṭam（夜明け）とprayāṇam（出発）の二つが「同じ」（samam）であったとする。両者の共通点：白く（śuklaiḥ）大きな天幕＝白く咲いた睡蓮、satāraiḥ＝星のある（天幕の飾り金具＝夜空の星）、mukulīkṛtaiḥ＝畳まれた（天幕を携帯用に巻く＝夜明けに睡蓮が萎む）、viyogavedanāvidūnanārīkam＝別離の苦悩に責められる女たちがいること（出征で夫と別れる＝夜明けで情人と別れる）。śleṣasaṃkīrṇā upamā。

【Mallinātha】

kumudvatīnām＝「白睡蓮の多い土地」（Amarakoṣa）、またはkairavṇī（白蓮の池）。sthūlaiḥ＝大きい（天幕を指す）。vyuṣṭam＝夜明け（Abhidhānacintāmaṇi「vyuṣṭaṃ prabhātaṃ pratyūṣam」）。二つのsamudāya（集合体）が一つのabhūtで表現される。

V.5
Sanskrit (IAST) utkṣiptagātraḥ sma viḍambayann abhaḥ samutpatiṣyantam agendram uccakaiḥ / ākuñcitaprohanirūpitakramaṃ kareṇur ārohayate niṣādinam //
和訳

前肢を高く上げ、天に飛び立たんとする大山を真似るかのように聳え立つ象は、前脚を曲げて足場を示しつつ、調教師を自らの背に乗せた。

注

【Vallabhadeva】

utkṣiptagātraḥ＝前肢を持ち上げた。agendram＝大山（aga+indra）。天に飛び立とうとする山のように巨体を聳えさせるという描写。ākuñcitaprauḍhanirūpitakramam＝曲げた前脚（prauḍha＝後肢の関節部）で足の置き場を示す。象が自ら調教師を乗せる——ārohayate＝「乗らせる」使役のātmanepada。

【Mallinātha】

uccakaiḥ＝高く。viḍambayan＝真似る（ullekha修辞法、あるいはabhūtopamā）。proha＝象の前脚（Viśva「gajāṅghriḥ prohaḥ」）。kareṇu＝象（Amarakoṣa「kareṇur gajī」は牝象だが、ここでは雄象にも用いる）。ārohayate＝使役＋ātmanepada——象が自ら騎手を乗せる行為を表す。svabhāvoktī（自然描写）。

V.6
Sanskrit (IAST) svairaṃ kṛtāsphālanalālitān puraḥ sphurattanūn darśitalāghavakriyāḥ / vaṅgāvalagnaikasavalgapāṇayas turaṅgamān āruruhus turaṅgiṇaḥ //
和訳

まずゆっくりと手で叩いてなだめた馬——身を震わせるその馬に、軽やかな身のこなしを見せつつ、鞍の縁に片手をかけ手綱を握って、騎手たちは飛び乗った。

注

【Vallabhadeva】

kṛtāsphālanalālanān＝（Valの読み）手で叩いて撫でた馬たち。vaṅga＝鞍の前縁部分。avalagna＝しがみついた。savalgapāṇayaḥ＝片手に手綱を持つ。

【Mallinātha】

āsphālana＝手の平で体を叩くこと。lālitān＝慈しんだ（causalの過去分詞、upapālitān）。sphurattanūn＝震える体の（馬たちを）。vaṅga＝鞍の部品（Viśva「vaṅkaḥ palyāṇabhāge syāt」）。darśitalāghavakriyāḥ＝素早さの技を見せた。svabhāvoktī。GRETILのsphuratnūn（11音節）はsphurattanūn（12音節）の脱字。同じくlalitānはlālitānの誤り（長母音）。

V.7
Sanskrit (IAST) ahnāya yāvan na cakāra bhūyase niṣedivān āsanabandham adhvane / tīvrotthitās tāvad asahyaraṃhaso viśṛṅkhalaṃ śṛṅkhalakāḥ pratasthire //
和訳

長旅に備えて座った御者が鞍をまだ締め終えぬうちに、猛然と立ち上がった駱駝たちは、抑えがたい勢いで、繋ぎも解けたまま走り出した。

注

【Vallabhadeva】

niṣedivān＝座った者（liṭのkasu接尾辞）。āsanabandha＝長旅用の鞍の固定。śṛṅkhalakāḥ＝駱駝（karabhāḥ）。tīvram utthitāḥ＝激しく立ち上がった。asahyaraṃhasaḥ＝耐えがたい速度の。viśṛṅkhalam＝束縛なく。

【Mallinātha】

addāya（Mallの読み）＝素早く（Amarakoṣa「drāk jhaṭity asahāddāya」）。GRETILおよびVallabhadevaはahnāyaと読む（異読）。niṣedivān＝座った者（nis+√sad、kasu接尾辞、「āpāyāṃ sadavasathyuḥ」）。bhūyase adhvane＝さらに長い旅路のために（kriyārthopapada-caturthī）。śṛṅkhalakāḥ＝駱駝（Amarakoṣa）。svabhāvoktī。

V.8
Sanskrit (IAST) gaṇḍojjvalām ujjvalanābhicakrayā virājamānāṃ navayodaraśriyā / kaścit sukhaṃ prāptumanāḥ susārathī rathīṃ yuyojāvidhurāṃ vadhūm iva //
和訳

頬の艶やかな、車軸の煌めく車輪を備え、新しい車体の美で輝き、轅の壊れぬ戦車を——ある者は快適な旅を望み、良き御者を伴って、あたかも花嫁を娶るように、軛をかけた。

注

【Vallabhadeva】

śleṣa（掛詞）で戦車と花嫁を重ねる。gaṇḍa＝車体の側面（戦車）／頬（花嫁）。ujjvalanābhicakra＝輝く車軸の車輪／輝く臍の周り。navayodaraśrī＝新しい車体の中央部の美／若々しい腰の美。avidhurā＝轅の壊れていない（車）／悲嘆のない（女）。

【Mallinātha】

rathī＝戦車の乗り手、また恋する男。susārathī＝良き御者を持つ、また良き伴侶を持つ。prāptumanāḥ＝得たいと望む心の（「tuṃ kāmamanasopi」によるmaの脱落）。vidhurā＝轅（dhūr）が失われた者、それがない（a-vidhurā）＝完全な。GRETILのadhidhurāṃはavidhurāṃの誤り（両注確認）。また gaṇḍojvalām ujjvanā-はgaṇḍojjvalām ujjvalanā-の脱字（pāda aが11音節→12音節）。śabdārtha-śleṣa。

V.9
Sanskrit (IAST) utthātum icchan vidhṛtaḥ puro balān nidhīyamāne bharabhāji yantrake / ardhojjhitodgāravijharjharasvaraḥ svanāma ninye ravaṇaḥ sphuṭārthatām //
和訳

重い荷枠を載せられる最中、力ずくで立ち上がろうとして前方を押さえつけられた駱駝は、半ば漏れ出る噫気のように濁った声で唸り——「ラヴァナ（吼える者）」という己が名を、まさしく言い当てたものにした。

注

【Vallabhadeva】

ravaṇa＝駱駝（ru「吼える」＋yuc接尾辞）。svanāma＝自分の名を。sphuṭārthatām ninye＝明白な意味あるものとした。bhara-bhāji yantrake＝荷を負う枠（鞍台）が載せられている時。balāt＝力ずくで。ardhojjhitodgāra＝半ば漏れ出た噫気。vijharjhara＝がらがらした。

【Mallinātha】

Mallinātha異読：adhojjhitodāra-vijṛmbhirasvaraḥ＝下方に放たれた大きな欠伸のような声。ravaṇa＝「ru（音を立てる）」より「calanśabdārthakarmakād yuc」で形成。svanāma sphuṭārthatāṃ ninye＝吼えることで「吼える者」という名が事実に即したものとなった。

V.10
Sanskrit (IAST) nasyāgṛhīto 'pi dhuvan viṣāṇayor yugaṃ sasūtkāravivartitatrikaḥ / goṇīṃ janena sma nidhātum uddhṛtām anukṣaṇaṃ nokṣataraḥ pratīcchati //
和訳

鼻綱で押さえられてもなお角の対を振り立て、唸り声とともに腰をよじる牡牛は、人が背に荷袋を載せようと持ち上げるたびに、頑としてそれを受け入れなかった。

注

【Vallabhadeva】

ukṣataraḥ＝大きな牡牛。nasyā＝鼻綱（nāsikāyāṃ bhavā、yat接尾辞）。viṣāṇayoḥ yugam＝二本の角の対を。dhuvan＝揺り動かしつつ。saśatkāra（Valの読み）＝唸り声とともに。vivartitatrikaḥ＝腰の関節（trika＝pṛṣṭhavaṃśādhara-sandhi）をよじった。goṇī＝荷袋。janena＝人が。

【Mallinātha】

nasyā＝鼻に付ける縄（Amarakoṣa）。satkāra＝擬音語（śabdānukaraṇa）、あるいは怒りの鼻息。trika＝背骨の下端の関節部（Amarakoṣa「pṛṣṭhavaṃśādhare trikam」）。goṇī＝荷袋。nidhātum uddhṛtām＝載せるために持ち上げた。na pratīcchati＝受け入れない——何度も振り払ったの意。GRETILのjananaはjanena（具格）の誤り。Mallの読みsasatkāraに対しGRETILはsasūtkāra（異読）。
