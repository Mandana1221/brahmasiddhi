マハーバーラタ ― カルナ篇 第44章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 44 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ44」（カルナがユディシュティラ軍へ猛攻をかけ、両者が直接対決する場面を中心とする全110詩節の長章）です。カルナはパーンチャーラ・チェーディ・スリンジャヤ等の軍勢を次々と打ち破り、ユディシュティラ自身もカルナに矢を浴びせて一時カルナを昏倒させますが、クンティーへの誓約（パーンドゥ五子のうち四人は討たないという約束）を思い出したカルナはユディシュティラを討たずに退かせます。後半では夥しい流血が川となって戦場を覆う「血の川」の情景が詳細に描かれ、空ではアプサラスたちが歌舞の音とともに戦死者の魂を運び去る幻想的な場面も挿入されます。なお、原典の奥書（コロフォン）には第40・42・43章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典には第101〜110詩節の行末注記が誤って「8-44-10」と短縮表記（OCRによる末尾数字の脱落）されており、本来別個であるべき第10詩節と第101〜110詩節が混同されかねない状態でしたが、第100詩節の出現を境に注記番号を復元する処理を施し、全110詩節を正しく分離・対訳しています。
karṇaparva — catuścatvāriṃśo'dhyāyaḥ (44)
第44章
sañjaya uvāca|
vidārya karṇas tāṃ senāṃ yudhiṣṭhiramathādravat|
rathahastyaśvapattīnāṃ sahasraiḥ parivāritaḥ|| // 8-44-1 //
サンジャヤは語った。 （1）カルナはその軍を切り裂き、戦車・象・馬・歩兵数千に囲まれて、ユディシュティラに襲いかかった。
nānāyudhasahasrāṇi preritāny aribhir vṛṣaḥ|
chittvā bāṇaśatairugraistān avidhyad asambhramāt|| // 8-44-2 //
（2）敵どもの放った数千の武器を、鋭い百本の矢で切り裂き、恐れることなく敵を射た。
nicakarta śirāṃsy eṣāṃ bāhūn ūrūṃś ca sūtajaḥ||
te hatā bhūtale petur bhagnāś ca anye vidudruvuḥ|| // 8-44-3 //
（3）御者の子カルナは、彼らの頭・腕・腿を切り落とした。殺された者は大地に倒れ、他の者は逃げ去った。
draviḍāndhraniṣādās tu punaḥ sātyakicoditāḥ|
prabhyadravañ jighāṃsantaḥ pattayaḥ karṇamāhave|| // 8-44-4 //
（4）ドラヴィダ族、アーンドラ族、ニシャーダ族の歩兵たちは、サーティヤキに促されて、カルナを殺そうと再び襲いかかった。
te vibāhuśirastrāṇāḥ prahatāḥ karṇasāyakaiḥ|
petuḥ pṛthivyāṃ yugapat chinnaṃ sālavanaṃ yathā|| // 8-44-5 //
（5）彼らは腕を切られ、兜を砕かれ、カルナの矢に討たれて、一斉に大地に倒れた。切られたサーラ樹の林のように。
evaṃ yodhaśatānyājau sahasrāṇyayutāni ca|
hatān īyur mahīṃ dehair yaśasā apūrayan diśaḥ|| // 8-44-6 //
（6）このように戦場で、百、千、万の者たちが殺されて大地に倒れ、その死体で名声をあたり一面に満たした。
atha vaikartanaṃ karṇaṃ raṇe kruddham iva antakam|
rurudhuḥ pāṇḍupāñcālā vyādhiṃ mantrauṣadhā iva|| // 8-44-7 //
（7）そして、戦場で怒りの死神のような孤独のカルナを、まるで薬と呪文が病を封じるかのように、パーンダヴァ方とパーンチャーラ方は取り囲んだ。
sa tān pramṛdya abhyapatat punar eva yudhiṣṭhiram|
mantrauṣadhikriyātīto vyādhir atyulbaṇo yathā|| // 8-44-8 //
（8）彼は彼らを打ち砕き、再びユディシュティラに襲いかかった。薬と呪文の限界を超えた、猛烈な病のように。
sa rājagṛddhibhī ruddhaḥ pāṇḍupāñcālakekayaiḥ|
nāśakat tān atikrāntuṃ mṛtyur brāhmavido yathā|| // 8-44-9 //
（9）王（ユディシュティラ）を守ろうとするパーンダヴァ、パーンチャーラ、ケーカヤたちに阻まれて、彼は彼らを越えて進むことができなかった。ブラフマンを知る者にとって死が越えがたいように。
tato yudhiṣṭhiraḥ karṇam adūrasthaṃ nivāritam|
tair yodhapramukhair vīraṃ dṛṣṭvā vivyādha sāyakaiḥ|| // 8-44-10 //
（10）そしてユディシュティラは、近くで止められているカルナを見て、勇者をその先頭の戦士たちの中に見出し、矢で射た。
karṇaḥ pārthaśarāviddhas totrārdita iva dvipaḥ|
pramathya sahitān vīrān yudhiṣṭhiram apīḍayat|| // 8-44-11 //
（11）アルジュナの矢に貫かれたカルナは、銛に刺された象のように、集まった勇者たちを打ち砕き、ユディシュティラを苦しめた。
tato yudhiṣṭhiraḥ karṇam āsādya jayatāṃ varam|
abravīt paravīraghnaṃ krodhasaṃraktalocanaḥ|| // 8-44-12 //
（12）そしてユディシュティラは、勝利者の中の最上者、敵の勇者を討つカルナに近づき、怒りに目を赤くして言った。
karṇakarṇa vṛthādṛṣṭe sūtaputra vacaḥ śṛṇu|
sadā spardhasi saṅgrāme phalgunena tarasvinā|| // 8-44-13 //
（13）「カルナよ、カルナよ、愚かな見識の御者の子よ、我が言葉を聞け。お前はいつも戦場で勇敢なアルジュナと張り合っている。
yathā asmān bādhase nityaṃ dhārtarāṣṭramate sthitaḥ|
yad balaṃ yac ca te vīryaṃ pradveṣo yastu pāṇḍuṣu|| // 8-44-14 //
（14）いつも我らを苦しめ、ドリタラーシュトラの子らの味方をし、自らの力と武勇、パーンダヴァ兄弟に対する憎悪を――。
tat sarvaṃ darśayasva adya pauruṣaṃ mahadāsthitaḥ|
yuddhaśraddhāṃ ca te adya aham vineṣyāmi mahāhave|| // 8-44-15 //
（15）今こそ、その勇気をすべて示してみせよ。私は今、お前の戦闘意欲をこの大戦で打ち砕いてやる」。
evam uktvā mahārāja karṇaṃ pāṇḍusutastadā|
suvarṇapuṅkhair daśabhir vivyādha āyasmayaiḥ śaraiḥ|| // 8-44-16 //
（16）大王よ、パーンダヴァの子（ユディシュティラ）はこう言って、カルナを金の羽根の鉄の矢十本で射た。
taṃ sūtaputro daśabhiḥ pratyaviddhyad arindamaḥ|
vatsadantair maheṣvāsaḥ prahasan iva bhārata|| // 8-44-17 //
（17）御者の子、敵を制するカルナは、仔牛の歯形の矢十本で反撃した。バーラタよ、まるで笑うかのように。
so'vajñāya tu nirviddhaḥ sūtaputreṇa pāṇḍavaḥ|
prajajvāla tataḥ krodhād dhaviṣā iva hutāśanaḥ|| // 8-44-18 //
（18）御者の子に射られた彼は、火に供物を注いだように、怒りで燃え上がった。
jvālāmālāparikṣipto rājño deho vyadṛśyata|
yugānte dagdhukāmasya saṃvartāgnerivāparaḥ|| // 8-44-19 //
（19）炎の光輪に囲まれた王の体は、世の終わりに焼き尽くそうとするサンヴァルタ火のようであった。
tato visphārya sumahat cāpaṃ hemapariṣkṛtam|
samādhatta śitaṃ bāṇaṃ girīṇāmapi dāraṇam|| // 8-44-20 //
（20）彼は金で飾られた大弓を引き絞り、山をも切り裂く鋭い矢をつがえた。
tataḥ pūrṇāyatotkṛṣṭaṃ yamadaṇḍanibhaṃ śaram|
mumoca tvarito rājā sūtaputrajighāṃsayā|| // 8-44-21 //
（21）そして弦を限界まで引き、ヤマ（死神）の杖のごとき矢を、御者の子を殺そうと、素早く放った。
sa tu vegavatā mukto bāṇo vajrāśanisvanaḥ|
viveśa sahasā karṇaṃ savye pārśve mahāratham|| // 8-44-22 //
（22）強い勢いで放たれたその矢は、雷鳴のような音を立て、カルナの左脇に突き刺さった。
sa tu tena prahāreṇa pīḍitaḥ pramumoha vai|
srastagātro mahābāhur dhanur utsṛjya kampitaḥ|| // 8-44-23 //
（23）その衝撃に苦しんでカルナは気を失った。手足は麻痺し、弓を取り落とし、震えた。
gatāsur iva niścetāḥ śalyasyābhimukho'patat|
rājā api bhūyo na ajaghne karṇaṃ pārthahitepsayā|| // 8-44-24 //
（24）意識を失ったカルナは、シャルヤに向かって倒れかかった。しかし王（ユディシュティラ）はアルジュナの利益を思って、それ以上打たなかった。
tato hāhākṛtaṃ sarvaṃ dhārtarāṣṭrabalaṃ mahat|
vivarṇamukhamārtaṃ ca karṇaṃ dṛṣṭvā tathāgatam|| // 8-44-25 //
（25）すると、ドリタラーシュトラの大軍全体が「ああ！」と嘆きの声をあげた。顔色を失い、そのようになったカルナを悲しんで見ていた。
siṃhanādāś ca sañjajñuḥ kṣvelāḥ kilakilāstathā|
pāṇḍavānāṃ mahārāja dṛṣṭvā rājñaḥ parākramam|| // 8-44-26 //
（26）パーンダヴァたちの間では獅子吼、歓声、叫び声が起こった。大王よ、王の武勇を見て喜んだのである。
pratilabhya tu rādheyaḥ saṃjñāṃ na aticirād iva|
dadhre rājavināśāya manaḥ krūraparākramaḥ|| // 8-44-27 //
（27）やがて意識を取り戻したカルナは、残酷なほど武勇に猛る心で、王（ユディシュティラ）を滅ぼそうと決意した。
sa hemavikṛtaṃ cāpaṃ visphārya vijayaṃ mahat|
avākirad ameyātmā pāṇḍavaṃ niśitaiḥ śaraiḥ|| // 8-44-28 //
（28）彼は金で飾られた、大いなる「勝利」という弓を引き絞り、無量の魂をもつ者はパーンダヴァ（ユディシュティラ）に鋭い矢を放った。
tataḥ kṣurābhyāṃ pāñcālyau cakrarakṣau mahātmanaḥ|
jaghāna candradevaṃ ca daṇḍadhāraṃ ca saṃyuge|| // 8-44-29 //
（29）二本の剃刀矢で、ユディシュティラの車輪を守る二人のパーンチャーラ族――チャンドラデーヴァとダンダダーラを戦場で討った。
tāvubhau dharmarājasya pravīrau yudhi bhārata|
rathābhyāśe cakāśete candrasya iva punarvasū|| // 8-44-30 //
（30）両者はダルマ王の勇者として、彼の戦車のそばで輝いていた。月の両脇の星プナルヴァスのように。
yudhiṣṭhiraḥ punaḥ karṇam avidhyat triṃśatā śaraiḥ|
suṣeṇaṃ satyasenaṃ ca tribhis tribhir atāḍayat|| // 8-44-31 //
（31）ユディシュティラは再びカルナを三十本の矢で射、スシェーナとサティヤセーナを三本ずつで射た。
śalyaṃ navatyā vivyādha trisaptatyā ca sūtajam|
tāṃs tasya goptṝn vivyādha tribhis tribhir ajihmagaiḥ|| // 8-44-32 //
（32）シャルヤを九十本、御者の子を七十三本で射、彼の守り手たちをそれぞれ三本のまっすぐな矢で射た。
tataḥ prahasya adhirathiḥ ṣaṣṭhyā rājañ śitaiḥ śaraiḥ|
viddhvā yudhiṣṭhiraṃ saṅkhye nanādātirathastadā|| // 8-44-33 //
（33）そしてカルナは微笑み、王よ、六十本の鋭い矢でユディシュティラを射て、戦場で大声で叫んだ。
tataḥ pravīrāḥ pāṇḍūnām abhyadhāvan amarṣitāḥ|
yudhiṣṭhiraṃ parīpsantaḥ karṇam abhyardayañ charaiḥ|| // 8-44-34 //
（34）するとパーンダヴァ方の勇者たちは、忍びがたい思いで、ユディシュティラを守ろうと、カルナを矢で射た。
sātyakiś cekitānaś ca yuyutsuḥ pāṇḍya eva ca|
dhṛṣṭadyumnaḥ śikhaṇḍī ca draupadeyāḥ prabhadrakāḥ|| // 8-44-35 //
（35）サーティヤキ、チェキターナ、ユユツ、パーンディヤ、ドリシュタデュムナ、シカンディン、ドラウパディーの子ら、プラバドラカ族、――。
yamau ca bhīmasenaś ca śiśupālasya cātmajaḥ|
kārūśā mātsyaśeṣāś ca kekayāḥ kāśikosalāḥ|| // 8-44-36 //
（36）双子（ナクラ・サハデーヴァ）、ビーマセーナ、シシュパーラの子、カールーシャ族、マツヤ族の生き残り、ケーカヤ族、カーシー族、コーサラ族――。
ete ca tvaritā vīrā vasuṣeṇamatāḍayan|
janamejayaś ca pāñcālyaḥ karṇaṃ vivyādha sāyakaiḥ|| // 8-44-37 //
（37）これらの勇者たちは急いで、ヴァスシェーナ（カルナ）を討った。パーンチャーラのジャナメージャヤもカルナを矢で射た。
vārāhakarṇanārācairnālīkairniśitaiḥ śaraiḥ|
vatsadantair vipāṭhaiś ca kṣurapraiś caṭakāmukhaiḥ|| // 8-44-38 //
（38）イノシシの耳形矢、鉄の矢、ナーリカ矢、鋭い矢、仔牛の歯形矢、大きな矢、剃刀矢、雀の嘴形矢――。
nānāpraharaṇaiś ca ugrai rathahastyaśvasādibhiḥ|
sarvato'bhyadravat karṇaṃ parivārya jighāṃsayā|| // 8-44-39 //
（39）さまざまな恐ろしい武器で戦車・象・馬に乗って、あたり一面から襲いかかり、カルナを取り囲んで殺そうとした。
sa pāṇḍavānāṃ pravaraiḥ sarvataḥ samabhidrutaḥ|
chādyamānaḥ śitatairghoraiḥ svasvanāmāṅkitaiḥ śaraiḥ|| // 8-44-40 //
（40）パーンダヴァの勇者たちに四方から襲われ、彼らの恐ろしい、それぞれの名を刻んだ鋭い矢で覆われながら――。
na cacāla raṇe karṇo mahendro dānavair iva|
'nijaghāna maheṣvāsān pāñcālān ekaviṃśatim|| // 8-44-41 //
（41）しかしカルナは揺らぐことなく、ダーナヴァたちの前のインドラ大神のごとくであった。大弓使いパーンチャーラ族二十一人を討ち取った。
tataḥ punarameyātmā cedīnāṃ pravarān daśa|
nyahanad bharataśreṣṭha karṇo vaikartanastadā|| // 8-44-42 //
（42）そしてさらにカルナ（ヴィカルタナの子）は、チェーディ族の勇者十人を討ち取った。
tasya bāṇasahasrāṇi samprapannāni māriṣa|
dṛśyante dikṣu sarvāsu śalabhānām iva vrajāḥ|| // 8-44-43 //
（43）彼の放った数千の矢は、あらゆる方向に見え、イナゴの群れのようであった。
karṇanāmāṅkitā bāṇāḥ svarṇapuṅkhāḥ sutejanāḥ|
narāśvakāyān nirbhidya petururvyāṃ samantataḥ|| // 8-44-44 //
（44）カルナの名が刻まれた、金の羽根をもつ鋭い矢は、人と馬の体を貫き、あたり一面の地に落ちた。
karṇenaikena samare cedīnāṃ pravarāstadā|
sṛñjayānāṃ ca sarveṣāṃ śataśo nihatā raṇe|| // 8-44-45 //
（45）戦場でカルナただ一人によって、チェーディ族の勇者たち、すべてのスリンジャヤ族は、百、千と討ち取られた。
karṇasya śarasañchannaṃ babhūva tumulaṃ tamaḥ|
nājñāyata tataḥ kiñcit pareṣām ātmano'pi vā|| // 8-44-46 //
（46）カルナの矢に覆われて、激しい闘が生じ、敵も味方も何も見えなくなった。
tasmin tamasi bhūte ca kṣatriyāṇāṃ bhayaṅkare|
vicacāra mahābāhur nirdahan kṣatriyān bahūn|| // 8-44-47 //
（47）その闇は、クシャトリヤ階級に恐怖を与えるものであった。長き腕のカルナは、多くのクシャトリヤを焼き尽くしながら動き回った。
tataḥ śaramahājvālo vīryoṣmā karṇapāvakaḥ|
nirdahan pāṇḍavavanaṃ cāru paryacaradraṇe|| // 8-44-48 //
（48）そして矢の大きな炎、武勇の熱をもった火・カルナは、戦場でパーンダヴァの森を美しく巡って焼いた。
tatas teṣāṃ mahārāja pāṇḍavānāṃ mahārathāḥ|
sṛñjayānāṃ ca sarveṣāṃ śataśo'tha sahasraśaḥ|
astraiḥ karṇaṃ maheṣvāsaṃ samantāt paryavārayan|| // 8-44-49 //
（49）大王よ、すると、パーンダヴァの偉大な戦車戦士たち、スリンジャヤ族のすべての者たちは、数百、数千の武器でカルナを取り囲んだ。
sa saṃvārya mahāstrāṇi maheṣvāso mahātmanām|
prahasya puruṣendrasya karṇaś ciccheda kārmukam|| // 8-44-50 //
（50）しかし大弓使いカルナは、高潔な者たちの大武器を押し返し、笑いながら人の長たる者（ユディシュティラ）の弓を切り裂いた。
tataḥ sandhāya navatiṃ nimeṣānnataparvaṇām|
bibheda kavacaṃ rājño raṇe karṇaḥ śitaiḥ śaraiḥ|| // 8-44-51 //
（51）関節の曲がらぬ九十本の矢をつがえ、戦場で王の鎧を鋭い矢で打ち破った。
tadvarma hemavikṛtaṃ ratnacitraṃ babhau patat|
savidyudabhraṃ savituḥ śliṣṭaṃ vātahataṃ yathā|| // 8-44-52 //
（52）金で飾られ宝石をちりばめたその鎧は、雷を含む雲が太陽にまとわりついて風に吹き飛ばされるように、落ちてきらめいた。
tadaṅgāt puruṣendrasya bhraṣṭaṃ varma vyarocata|
ratnairalaṃvṛtaṃ citrair vyabhraṃ niśi yathā nabhaḥ|| // 8-44-53 //
（53）人の長（ユディシュティラ）の体から落ちた鎧は、宝石と華麗な飾りで輝いた。星々に飾られた夜空のように。
bhinnavarmā śaraiḥ pārtho rudhireṇa samukṣitaḥ|
babhāse puruṣaśreṣṭha udyan iva divākaraḥ|| // 8-44-54 //
（54）鎧を失ったアルジュナの兄（ユディシュティラ）は、矢によって体を貫かれ、血にまみれて、昇る太陽のように輝いた。
sa śarācitasarvāṅgaś chinnavarmā atha saṃyuge|
kṣātraṃ dharmaṃ samāsthāya siṃhanādamakurvata|| // 8-44-55 //
（55）矢に体中を覆われ鎧を失った彼は、戦場でクシャトリヤの義務をとどめ、獅子吼を上げた。
narditvā ca ciraṃ kālaṃ pāṇḍavo rabhaso raṇe|
śaktiṃ cikṣepa vegena pradīptām aśanīm iva|| // 8-44-56 //
（56）しばらく叫び続けたパーンダヴァ（ユディシュティラ）は、勢いよく、燃え立つ雷のような槍を力強く投げた。
tāṃ jvalantīmivākāśe śaktiṃ saptabhir āśugaiḥ|
bhallaiściccheda rādheyaḥ sā tvaśīryata vai raṇe|| // 8-44-57 //
（57）空中で炎のように光るその槍を、カルナは七本の素早い矢で切り裂き、それは戦場で粉々に砕け散った。
hṛdi bāhvor lalāṭe ca kṣiprakārī yudhiṣṭhiraḥ|
caturbhis tomaraiḥ karṇaṃ tāḍayitvā anadan mudā|| // 8-44-58 //
（58）素早いユディシュティラは、四本の矛でカルナの胸・両腕・額を打ち、歓びの声をあげた。
udbhinnarudhiraḥ karṇaḥ kruddhaḥ sarpa iva śvasan|
jaghāna sūtaṃ pārthasya pārṣṭhiṃ ca navabhiḥ śaraiḥ|| // 8-44-59 //
（59）血を流したカルナは怒り、蛇のように息をつき、アルジュナの兄の御者、そして脇を守る者を九本の矢で討った。
dhvajaṃ ciccheda nṛpates tribhir vivyādha caiva tam|
iṣudhī cāsya ciccheda rathaṃ ca tilaśo'cchinat|| // 8-44-60 //
（60）王の旗を三本で切り、王自身を射、矢筒も切り、戦車を木っ端微塵にした。
etasminnantare śūrāḥ pāṇḍavānāṃ mahārathāḥ|
vavṛṣuḥ śaravarṣāṇi rādheyaṃ prati bhārata|| // 8-44-61 //
（61）そのとき、パーンダヴァの勇者・偉大な戦車戦士たちは、バーラタよ、カルナに向かって矢の雨を降らせた。
sātyakiḥ pañcaviṃśatyā śikhaṇḍī navabhiḥ śaraiḥ|
avarṣatāṃ mahārāja rādheyaṃ śatrukarśanam|| // 8-44-62 //
（62）サーティヤキは二十五本、シカンディンは九本の矢を、敵を打ち砕くカルナに放った。
śaineyaṃ tu tatuḥ kruddhaḥ karṇaḥ pañcabhir āyasaiḥ|
vivyādha samare rājaṃstribhiś ca anyaiḥ śilīmukhaiḥ|| // 8-44-63 //
（63）怒ったカルナは、サーティヤキを五本の鉄矢で、さらに三本の鋭い矢で射た。
dakṣiṇaṃ tu bhujaṃ tasya tribhiḥ karṇo'bhyavidhyata|
savyaṃ ṣoḍaśabhir bāṇair yantāraṃ ca asya saptabhiḥ|| // 8-44-64 //
（64）カルナはサーティヤキの右腕を三本、左腕を十六本、御者を七本の矢で射た。
athāsya caturo vāhāṃś caturbhir niśitaiḥ śaraiḥ|
sūtaputro'nayatkṣipraṃ yamasya sadanaṃ prati|| // 8-44-65 //
（65）そして鋭い四本の矢で四頭の馬を、ヤマの世界へと急いで送った。
atha apareṇa bhallena dhanuś chittvā mahārathaḥ|
sāratheḥ saśirastrāṇaṃ śiraḥ kāyādapāharat|| // 8-44-66 //
（66）別の広頭矢で弓を切り、御者の兜付きの頭を体から切り離した。
hatāśvasūte tu rathe sthitaḥ sa śinipuṅgavaḥ|
śaktiṃ cikṣepa karṇāya vaidūryamaṇibhūṣitām|| // 8-44-67 //
（67）馬と御者を失った戦車に立ちながら、シニの雄牛（サーティヤキ）は、宝石で飾られた槍をカルナめがけて投げた。
tāmāpatantīṃ sahasā dvidhā ciccheda bhārata|
karṇo vai dhanvināṃ śreṣṭhas tāṃś ca sarvān avārayat|| // 8-44-68 //
（68）バーラタよ、カルナは飛来するその槍を二つに切り裂き、すべての者たちを押し返した。弓の名手の最高者・カルナは。
tatas tān niśitair bāṇaiḥ pāṇḍavānāṃ mahārathān|
nyavārayadameyātmā śikṣayā ca balena ca|| // 8-44-69 //
（69）そして鋭い矢で、パーンダヴァ軍の偉大な戦車戦士たちを、技と力をもって阻んだ。
ardayitvā śaraistāṃstu siṃhaḥ kṣudramṛgān iva|
pīḍayan dharmarājānaṃ śaraiḥ sannataparvabhiḥ|
abhyadravata rādheyo dharmaputraṃ śitaiḥ śaraiḥ|| // 8-44-70 //
（70）獅子が小さな獣たちを苦しめるように矢で彼らを打ち砕き、ダルマ王を節のまっすぐな矢で苦しめ、鋭い矢でダルマの子（ユディシュティラ）に襲いかかった。
tataḥ pārṣo hyapāsāsīdvatāśvo hatasārathiḥ|
aśaknuvanmukhe sthātuṃ tataḥ karṇasya durmanāḥ|| // 8-44-71 //
（71）ユディシュティラは、馬を殺され、御者を殺され、カルナの前に踏みとどまることができず、憂えた。
tamabhidrutya rādheyaḥ pāṇḍuputraṃ yudhiṣṭhiram|
abravīt prahasan rājan kutsayan iva pāṇḍavam|| // 8-44-72 //
（72）襲いかかるカルナは、パーンダヴァ・ユディシュティラを嘲笑するかのように、笑いながら言った。
kathaṃ nāma kule jātaḥ kṣatradharme vyavasthitaḥ|
prajahyāt samare śatrūn prāṇān rakṣa mahāhave|| // 8-44-73 //
（73）「高貴な家柄に生まれ、クシャトリヤの道を歩む者が、戦場で敵を捨てて、この大戦で命を守ろうとするのか？
na bhavān kṣatradharmeṣu kuśalo'sīti me matiḥ|
brāhme bale bhavānyuktaḥ svādhyāye yajñakarmaṇi|| // 8-44-74 //
（74）お前はクシャトリヤの義務に通じていないようだ、と私は思う。お前はバラモンの力、学習、祭りごとにふさわしい。
mā sma yudhyasva kaunteya mā sma vīrān samāsadaḥ|
mā caivaṃ vipriyaṃ brūhi mā ca tvaṃ bhaja saṃyugam|| // 8-44-75 //
（75）クンティーの子よ、戦うな。勇者に向かうな。このような不愉快な言葉をかけるな。戦場に出るな。
vaktavyā māriṣa anye tu na vaktavyāstu mādṛśāḥ|
mādṛśān hi bruvan yuddhe etadanyacca lapsyase|| // 8-44-76 //
（76）敬うべき方よ、他の者たちにそう語れ、だが私のような者にそう語るな。私のような者にそう言うと、これ以外のものを戦場で受けることになる。
svagṛhaṃ gaccha kaunteya yatra vā keśavārjunau|
na hi tvāṃ samare rājan hanyāt karṇaḥ kathañcana|| // 8-44-77 //
（77）クンティーの子よ、家に帰れ、あるいはケーシャヴァ（クリシュナ）とアルジュナのもとへ行け。戦場で王よ、カルナがお前を殺すことは決してないから」。
sañjaya uvāca|
varapradānaṃ kuntyāstu karṇaḥ smṛtvā mahārathaḥ|
vadhaprāptaṃ tu kaunteyaṃ nāvadhītpuruṣottamaḥ|| // 8-44-78 //
サンジャヤは語った。 （78）偉大な戦車戦士カルナは、クンティーの誓いを思い出し、殺される運命にあったクンティーの子（ユディシュティラ）を、人中の最上の者は殺さなかった。
evamuktvā tataḥ pārthaṃ visṛjya ca mahābalaḥ|
nyahanat pāṇḍavīṃ senāṃ vajrahasta iva āsurīm|| // 8-44-79 //
（79）このようにアルジュナの兄に言って彼を放ち、大力のカルナは、雷を手にしたインドラがアスラ軍を討つようにパーンダヴァ軍を討った。
tato'pāyād drutaṃ rājan vrīḍan iva nareśvaraḥ|| // 8-44-80 //
（80）そしてユディシュティラ王は、恥じるようにして、急いで退いた。
atha apayātaṃ rājānaṃ matvā anvīyus tam acyutam|
cedipāṇḍavapāñcālāḥ sātyakiś ca mahārathaḥ|
draupadeyāstathā śūrā mādrīputrau ca pāṇḍavau|| // 8-44-81 //
（81）王が退却するのを知って、チェーディ、パーンダヴァ、パーンチャーラ方、偉大な戦車戦士サーティヤキ、そしてドラウパディーの子ら、勇者マードリーの二子（ナクラ・サハデーヴァ）が彼に従っていった。
tato yudhiṣṭhirānīkaṃ dṛṣṭvā karṇaḥ parāṅmukham|
kurubhiḥ sahito vīraḥ prahṛṣṭaḥ pṛṣṭhato'nvagāt|| // 8-44-82 //
（82）ユディシュティラの軍が背を向けて退くのを見て、カルナはクル族と共に、喜んで後を追った。
bherīśaṅkhamṛdaṅgānāṃ kārmukāṇāṃ ca niḥsvanaḥ|
babhūva dhārtarāṣṭrāṇāṃ siṃhanādaravastathā|| // 8-44-83 //
（83）太鼓、法螺貝、小太鼓、弓の音、そしてドリタラーシュトラ方の獅子吼が響き渡った。
yudhiṣṭhirastu kauravya rathamāruhya satvaram|
śrutakīrtermahārāja dṛṣṭvā tatkarṇavikramam|| // 8-44-84 //
（84）ユディシュティラは急いで、シュルタキールティの戦車に乗り、カルナの武勇を見て――。
kālyamānaṃ balaṃ dṛṣṭvā sūtaputreṇa māriṣa|
svān yodhān abravīt kruddho nighnata etān kim āsata|| // 8-44-85 //
（85）御者の子（カルナ）に軍を退けられるのを見て、怒って自軍の戦士たちに言った――「なぜ、そやつらを討たずに坐っているのか！」
tato rājñā abhyanujñātāḥ pāṇḍavānāṃ mahārathāḥ|
bhīmasenamukhāḥ sarve putrāṃste pratyupādravan|| // 8-44-86 //
（86）王の命令で、ビーマセーナを先頭とするパーンダヴァ方の偉大な戦車戦士たちは皆、あなたの息子たちに反撃に出た。
abhavattumulaḥ śabdo yodhānāṃ tatra bhārata|
rathahastyaśvapattīnāṃ dravatāṃ ninado mahān|
udyataprativiṣṭānāṃ śastrāṇāṃ ca tatastataḥ|| // 8-44-87 //
（87）戦士たちの大音響が起こった。戦車・象・馬・歩兵たちの走る響きと、構えて打ち下ろされる武器の音――。
āgacchata praharata kṣipraṃ viparidhāvata|
iti bruvāṇā hy anyonyaṃ jaghnuryodhā mahāraṇe|| // 8-44-88 //
（88）「来い、打て、すばやく駆け巡れ！」と言い合って、戦士たちは大戦場で互いを討ち合った。
abhracchāyā iva tatrāsīccharavṛṣṭibhirambare|
samāvṛtair naravarair nighnadbhir itaretaram|| // 8-44-89 //
（89）人々が互いを討ち合い、矢が空を覆い、雲の影のようになった。
vipatākadhvajacchatrā vyaśvasūtarathāyudhāḥ|
vyaṅgāṅgāvayavāḥ petuḥ kṣitau kṣīṇāḥ kṣitīśvarāḥ|
śikharāṇīva śelānāṃ vajrabhinnāni māniṣa|| // 8-44-90 //
（90）旗も傘も折れ、馬・御者・戦車・武器を失い、身体の部分を失った王たちが、地に倒れた。雷に打たれた山の峰のように。
sārohā nihatāḥ petur dvipā bhinnā mahītale|
chinnabhinnaviparyastavarmālaṅkāravigrahāḥ|| // 8-44-91 //
（91）乗り手を殺された象が大地に倒れ、鎧と飾りを破られていた。
sārohās turagāḥ petur hatavīrāḥ sahasraśaḥ|
vipravidvāyudhāṅgāś ca dviradā rathibhir hatāḥ|
prativīraiś ca sammarde pattisaṅghāḥ sahasraśaḥ|| // 8-44-92 //
（92）乗り手を殺された馬たちが千も倒れた。象たちも、戦車戦士たちによって、体を切り裂かれ武器を失い倒れていた。戦闘の混乱の中で、歩兵たちも千と倒れた。
viśālāyatatāmrākṣaiḥ padmendusadṛśānanaiḥ|
śirobhir yuddhaśauṇḍānāṃ sarvataḥ saṃvṛtā mahī|| // 8-44-93 //
（93）広く大きな赤い目をもち、蓮や月のような顔をした、戦士たちの首で、大地はあたり一面に覆われた。
yathā bhuvi tathā vyomni niḥsvanaṃ śuśruvur janāḥ|
vimāne'psarasāṃ saṅghair gītavāditraniḥsvanaiḥ|| // 8-44-94 //
（94）地上と同じように、空でもそのような音が人々に聞こえた。天の馬車の中で、アプサラス（天女）たちの群れによる歌と楽器の音が響いていた。
hatān abhimukhān vīrān vīraiḥ śatasahasraśaḥ|
āropyāropya gacchanti vimāneṣvapsarogaṇāḥ|| // 8-44-95 //
（95）敵と向き合って倒れた勇者たちを、百、千の単位で、アプサラスの群れが抱え上げては天の馬車に連れて行った。
taddṛṣṭvā mahadāścaryaṃ pratyakṣaṃ svargalipsayā|
prahṛṣṭamanasaḥ śūrāḥ kṣipraṃ jaghnuḥ parasparam|| // 8-44-96 //
（96）天界に入りたいと願う勇者たちは、その驚くべき光景を目の当たりにし、喜びに満ちた心で素早く互いに討ち合った。
rathino rathibhiḥ sārdhaṃ citraṃ yuyudhurāhave|
pattayaḥ pattibhir nāgāḥ saha nāgair hayair hayoḥ|| // 8-44-97 //
（97）戦車兵は戦車兵と、歩兵は歩兵と、象は象と、馬は馬とで、さまざまな戦いをくり広げた。
evaṃ pravṛtte saṅgrāme gajavājinarakṣaye|
sainyena rajasā vṛttate sve svāñjaghnuḥ pare parān|| // 8-44-98 //
（98）このように象・馬・人の大量の死者を出す戦いが進むなか、軍勢は塵に覆われ、味方すら互いを討ち合ってしまった。
kacākacaṃ yuddhamāsīddantādanti nakhānakhi|
muṣṭiyuddhaṃ niyuddhaṃ ca dehapāpmavināśanam|| // 8-44-99 //
（99）頭髪同士、歯同士、爪同士、拳同士、組み合っての格闘――体と罪を滅ぼす戦いがあった。
tathā vartatati saṅgrame gajavājinarakṣaye|
narāśvanāgadehebhyaḥ prasṛtā lohitāpagā|| // 8-44-100 //
（100）このように象・馬・人の大量の死者を出す戦いが進む中、人・馬・象の体から血の川が流れ出した。
gajāśvanaradehān sā vyuvāha patitān bahūn|
narāśvagajasambādhe narāśvagajasādinām|| // 8-44-101 //
（101）その血の川は、象・馬・人の死体を多く運び、人・馬・象でごったがえす戦場で、人・馬・象の騎手たち――。
lohitodā mahāghorā māṃsaśoṇitakardamā|
narāśvagajadehānvai vahantī bhīrubhīṣaṇā|| // 8-44-102 //
（102）血の水をもち、きわめて恐ろしく、肉と血の泥を含み、人・馬・象の体を運び、臆病者を恐れさせた。
tasyā nadyāḥ paraṃ pāraṃ vrajanti vijayaiṣiṇaḥ|
nāgena ca plavanto vai nimajjyonmajjya cāpare|| // 8-44-103 //
（103）勝利を求める者たちは、その川の向こう岸へと渡った。象によって泳ぎ渡る者もあれば、沈んでは浮かぶ者もあった。
te tu lohitadigdhāṅgā raktavarmāyudhāmbarāḥ|
sasnustatasyāṃ papuś ca asraṃ mamluś ca bharatarṣabha|| // 8-44-104 //
（104）彼らは血で体を染め、赤い鎧と武器と衣装で、その川に浴し、血をすすり、疲れ果てた。
rathānaśvānnārānnāgānāyudhābharaṇāni ca|
varmāṇi ca api apaśyāma patitāni sahasraśaḥ|
khaṃ dyāṃ bhūmiṃ diśaś ca eva prāyaḥ paśyāma lohitāḥ|| // 8-44-105 //
（105）倒れた戦車・馬・人・象・武器・飾り・鎧を、私は何千と見た。天・地・空・すべての方向が、私にはほとんど赤く見えた。
lohitasya tu gandhena spardena ca rasena ca|
rūpeṇa cātiraktatena śabdena ca visarpatā|
viṣādaḥ sumahān āsīt prāyaḥ sainyasya bhārata|| // 8-44-106 //
（106）血の臭い、触感、味、その色、響きで、軍勢はほとんど大きな絶望に陥った。
tattu viprahataṃ sainyaṃ bhīmasenamukhaistava|
bhūyaḥ samādravan vīrāḥ sātyakipramukhās tadā|| // 8-44-107 //
（107）傷ついたその軍勢は、ビーマセーナを先頭にした、あなた方の側の者たちを、サーティヤキを先頭にした勇者たちは再び襲った。
teṣām āpatatatāṃ vegam aviṣahyaṃ nirīkṣya ca|
putrāṇāṃ te mahāsainyam āsīd rājan parāṅmukham|| // 8-44-108 //
（108）彼らの耐えがたい勢いに襲われて、あなたの息子たちの大軍は、王よ、後ろを向いて逃げた。
tatprakīrṇarathāśvebhaṃ naravājisamākulam|
vidhvastavarmakavacaṃ pravidvāyudhakārmukam|| // 8-44-109 //
（109）戦車・馬・象が散り、人・馬でごったがえし、鎧や兜が砕け、武器と弓が散らばった――。
vyadravattāvakaṃ sainyaṃ loḍyamānaṃ samantataḥ|
siṃhārditamivāraṇye yathā gajakulaṃ tathā|| // 8-44-110 //
（110）あなた方の軍は、森で獅子に襲われた象の群れのように、動揺して逃げ去った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe catuścatvāriṃśo'dhyāyaḥ|| 44 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十四章は終わる。
