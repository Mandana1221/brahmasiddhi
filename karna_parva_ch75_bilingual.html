本章は南伝（Southern Recension）テキストの「アディヤーヤ75」、全43詩節からなります。アルジュナがユダーマンユ王を宥める場面（第1〜15詩節）、パーンダヴァ軍がカルナを討つべく進軍する場面（第16〜43詩節）で本章は終わります。日本語対訳では複数詩節が一括して翻訳されています。
karṇaparva — pañcasaptatitamo'dhyāyaḥ (75)
第75章　アルジュナによるユディシュティラの宥め、カルナ殺害の誓い
sañjaya uvāca|
iti sma kṛṣṇavacanātpratyuccārya yudhiṣṭhiram|
babhūva vimanāḥ pārthaḥ kiñcitkṛtveva pātakam||
// 8-75-1 //
サンジャヤは語った。
tato'bravīdvāsudevaḥ prahasanniva pāṇḍavam|
kathaṃ nāma bhavedetadyadi tvaṃ pārtha dharmajam||
asinā tīkṣṇadhāraṇe hanyā dharme vyasthitam|
tvamityuktvātha rājānamevaṃ kaśmalamāviśaḥ||
hatvā tu nṛpatiṃ pārtha kariṣyasi kimuttaram|
evaṃ hi durvido dharmo mandaprajñairviśeṣataḥ||
sa bhavāndharmabhīrutvāddhavaṃ yāyānmahattamaḥ|
narakaṃ ghorarūpaṃ ca bhrāturjyetusya vai vathāt||
sa tvaṃ dharmabhṛtāṃ śreṣṭhaṃ rājānaṃ dharmasaṃhitam|
prasādaya kuruśreṣṭhametadatra mataṃ mama||
// 8-75-2-6 //
ヴァースデーヴァは笑うようにパーンダヴァに言った。「もし鋭い刃の剣で法に立つダルマジャを殺していたら——『お前』と呼んだだけでこのように悔恨に陥るお前が——王を殺した後に何をするつもりだったのか。法はかくも見分け難い、特に知恵の乏しい者には。法を恐れて兄を殺せば、恐ろしい地獄に落ちるだろう。だからクルの最上者よ、法に結びついた王を慰めよ——それが私の意見だ。」
prasādya bhaktyā rājānaṃ prīte caiva yudhiṣṭhire|
prayāvastvaritau yoddhuṃ sūtaputrarathaṃ prati||
hatvā tu samare karṇaṃ tvamadya niśitaiḥ śaraiḥ|
vipulāṃ prītimādhatsva dharmaputrasya mānada||
etadatra mahābāho prāptakālaṃ mataṃ mama|
evaṃ kṛte kṛtaṃ caiva tava kāryaṃ bhaviṣyati||
// 8-75-7-9 //
「敬虔に王を慰め、ユディシュティラが喜んだら、急いで二人でスータの子の戦車に向かって戦いに行こう。今日カルナを鋭い矢で戦場で殺し、ダルマの子に大いなる喜びを与えよ。大いなる腕の者よ、これが今の私の意見だ。」
sañjaya uvāca|
tato'rjuno mahārāja lajjapā vai samanvitaḥ|
dhartarājasya caraṇau prapadya śirasā nataḥ||
uvāca bharataśreṣṭhaṃ prasīdeti punaḥ punaḥ|
kṣamasva rājanyatproktastvaṃ mayā dharmabhīruṇā||
pādayoḥ patitaṃ dṛṣṭvā dharmarājo yudhiṣṭhiraḥ|
dhanañjayamamitraghnaṃ rudantaṃ bharatarṣabham||
utthāpya bhrātaraṃ rājā dharmarājo dhanañjayam|
samāśliṣya ca sasnehaṃ praruroda mahīpatiḥ||
ruditvā suciraṃ kālaṃ bhrātarau sumahādyutī|
kṛtaśaucau mahārāja prītimantau babhūvatuḥ||
// 8-75-10-14 //
サンジャヤは語った。
tata āśliṣya taṃ premṇā mūrdhni cāghrāya pāṇḍavaḥ|
prītyā paramayā yukto vismayaṃś ca punaḥpunaḥ|
abravīttaṃ maheṣvāsaṃ dharmarājo dhanañjayam||
karṇena me mahābāho sarvasainyasya paśyataḥ|
kavacaṃ ca dhvajaṃ caiva dhanuḥ śaktirhayāḥ śarāḥ|
śaraiḥ kṛttā maheṣvāsa yatamānasya saṃyuge||
so'haṃ dṛṣṭvā raṇe tasya karṇa karṇasya phalguna|
vyavasīdāmi duḥkhena na tu me jīvitaṃ priyam||
na cedadya hi taṃ vīraṃ nihaniṣyasi saṃyuge|
prāṇāneva parityakṣye jīvitārtho hi ko mama||
// 8-75-15-18 //
そしてアルジュナを愛情を込めて抱きしめ、頭の匂いを嗅ぎ、最高の喜びに満ち、何度も驚嘆しながら、ダルマラージャは大弓持ちのダナンジャヤに言った。「カルナに我が全軍の面前で、鎧も旗も弓も槍も馬も矢も、戦いながらの矢で切られた。そのカルナの業を見て、アルジュナよ、私は苦しみに沈む。命など惜しくない。もし今日あの勇者を戦場で殺さないのなら、命を捨てよう。私が生きていて何の意味があろう。」
evamuktaḥ pratyuvāca vijayo bharatarṣabha||
satyena te śape rājaṃstvatpādena tathaiva ca|
bhīmena ca naraśreṣṭha yamābhyāṃ ca mahīpate||
'ahamenaṃ naraśreṣṭha sāmātyaṃ ca mahīpate'|
yathādya samare karṇaṃ haniṣyāmi hatopi vā|
mahītale patiṣyāmi satyenāyudhamālabhe||
evamābhāṣya rājānamabravīnmādhavaṃ vacaḥ|
adya karṇaṃ raṇe kṛṣṇa sūdayiṣye na saṃśayaḥ|
tvamanudhyāhi bhadraṃ te vadhaṃ tasya durātmanaḥ||
// 8-75-19-22 //
こう言われて、ヴィジャヤ（アルジュナ）、バーラタの雄牛は答えた。「王よ、真実にかけて誓う。お前の足にかけて、ビーマにかけて、人中の最上者よ、双子にかけて。今日戦場でカルナを殺す、さもなくば殺されて大地に倒れる。真実にかけて武器に触れて誓う。」こう王に告げて、マーダヴァ（クリシュナ）にも言った。「今日戦場でカルナを殺す、疑いない。お前はあの邪悪な者の殺害を考えよ、幸あれ。」
evamukto'bravītpārthaṃ keśavo rājasattama|
śakto'si bharataśreṣṭha yatnaṃ kartuṃ yadāttha mām||
eṣa cāpi hi me kāmo nityameva mahāratha|
kathaṃ bhavānraṇe karṇaṃ nihanyāditi sattama||
evamuktastato rājanpārtho vacanamabravīt|
hanyate dvairathe bhūyo yujyantāṃ vai rathottame||
upāvṛttāś ca turagāḥ śikṣitāścāśvasādibhiḥ|
rathopakaraṇaiḥ sarvaiḥ satvaraṃ yātu me rathaḥ||
evamukto mahārāja phalgunena mahātmanā|
uvāca dārukaṃ kṛṣṇaḥ kuru sarvaṃ yadabravīt|
arjuno bhārataśreṣṭhaḥ śreṣṭhaḥ sarvadhanuṣmatām||
ājñaptastvatha kṛṣṇena dāruko rājasattama|
yojayāmāsa ca rathaṃ vaiyāghnaṃ śatrutāpanam|
sajjaṃ nivedayāmāsa pāṇḍavasya mahātmanaḥ||
// 8-75-23-28 //
クリシュナは言った。「バーラタの最上者よ、お前にはその力がある。」ダールカに命じて戦車を用意させ、ユディシュティラの前で整えた虎の皮の戦車を、マーダヴァはダルマの子にさらに言った。「ユディシュティラよ、このビーバツ（アルジュナ）を慰め、邪悪なカルナの殺害のために送り出す許可を与えよ。大いなる戦場でカルナの矢に苦しむお前の様子を知るためにここに来たのだ。幸いにも王よ、お前は無傷だ。ビーバツを慰め、勝利を祈れ。」
yudhiṣṭhira uvāca|
ehyehi pārtha bībhatso māṃ pariṣvaja pāṇḍava|
vaktavyamuktosmyahitaṃ tvayā kṣāntaṃ ca tanmayā||
ahaṃ tvāmanujānāmi jahi karṇaṃ dhanañjaya|
manyuṃ ca mā kṛthāḥ pārtha yanmayokto'si dāruṇaṃ||
// 8-75-33-34 //
ユディシュティラは語った。
sañjaya uvāca|
tato dhanañjayo rājañśirasā praṇatastadā|
pādau jagrāha pāṇibhyāṃ bhrāturjyeṣṭhasya māriṣa||
tamutthāpya tato rājā pariṣvajya ca pīḍitam|
mūrdhnupāghrāya caivam idaṃ punaruvāca ha||
dhanañjaya mahābāho mānito'smi dṛḍhaṃ tvayā|
māhātmyaṃ vijayaṃ caivaṃ bhūyaḥ prāpnuhi śāśvatam||
// 8-75-35-37 //
サンジャヤは語った。
arjuna uvāca|
adya taṃ pāpakarmāṇaṃ sānubandhaṃ raṇe śaraiḥ|
nayāmyantaṃ samāsādya rādheyaṃ balagarvitam||
yena tvaṃ pīḍito bāṇairdṛḍhamāyamya kārmukam|
tasyādya karmaṇaḥ karṇaḥ phalamāpsyati dāruṇam||
adya tvāmupayāsyāmi karṇaṃ hatvā mahīpate|
sabhājaye tvāmākrandāditi satyaṃ bravīmi te||
nāhatvā viniṣartiṣye karṇamadya raṇājirāt|
iti satyena te pādau spṛśāmi jagatīpate||
// 8-75-38-41 //
アルジュナは語った。
sañjaya uvāca|
iti bruvāṇaṃ sumanāḥ kirīṭinaṃ yudhiṣṭhiraḥ prāha vaco bṛhattaram|
yaśo'kṣayaṃ jīvitamīpsitaṃ te jayaṃ sadā vīryamarikṣayaṃ tadā||
prayāhi vṛddhiṃ ca diśantu devatā yathāhamicchāmi tavāstu tattathā|
prayāhi śīghraṃ jahi karṇamāhave purandaro vṛtramivātmavṛdvaye||
// 8-75-42-43 //
サンジャヤは語った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcasaptatitamo'dhyāyaḥ|| 75 ||
