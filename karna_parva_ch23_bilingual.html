マハーバーラタ ― カルナ篇 第23章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 23 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ23」（シャリヤがやむなくカルナの御者を引き受ける場面）です。各段落は原典の詩節番号（8-23-N）と和訳の段落番号が対応しています。
karṇaparva — trayoviṃśo'dhyāyaḥ (23)
第23章　シャリヤがやむなくカルナの御者を引き受ける
sañjaya uvāca|
evamukto mahārāja tava putraḥ pratāpavān|
madreśvaraṃ prati raṇe surasainyabhayaṅkaram|
sarvaṃ tathā'karottūrṇaṃ rādheyas tad yathā'bravīt|| // 8-23-1 //
サンジャヤは語った。 （1）大王よ、あなたの威厳ある息子は、天の軍勢すら恐れさせる戦場のマドラ王に対して、ラーデーヤ（カルナ）が述べたとおりのことをすべて速やかに実行しました。
madrājaṃ ca samare praṇamya ca mahāratham|
vinayenopasaṅgamya praṇayād vākyam abravīt|| // 8-23-2 //
（2）そして戦場でマドラ王に敬礼し、偉大な戦車戦士に謙虚に近づき、親しみを込めてこう言いました。
satyavrata mahābhāga dviṣatāṃ tāpavardhana|
madreśvara raṇeśūra parasainyabhayaṅkara||
'matpriyārthaṃ hitārthaṃ ca tathā pārthavadhāya ca'|
śrutavānasi karṇasya bruvato vadatāṃ vara|
yathā nṛpatisiṃhānāṃ madhye tvāṃ varaye svayam|| // 8-23-3-4 //
（3〜4）「真実の誓いを持つ、大いなる幸ある者よ、敵の苦しみを増す者よ、マドラの王よ、戦場の英雄よ、敵軍を恐れさせる者よ——私を喜ばせるために、そして利益のために、またパールタ（アルジュナ）を倒すために——雄弁家の中の最上者よ、王の獅子たちの中であなたを自ら選ぶと語るカルナの言葉をあなたは聞いた。
tattvāmaprativīryādya śatrupakṣakṣayāvaha|
madreśvara prayāce'haṃ śirasā vinayena ca|| // 8-23-5 //
（5）今、敵を滅ぼす無比の武勇を持つあなたに、マドラの王よ、私は頭を下げ、謙虚にお願いする。
tasmātpārthavināśārthaṃ hitārthaṃ mama caiva hi|
tvaṃ pāhi sarvataḥ karṇaṃ bhavaṃ brahmeva suvrata|| // 8-23-6 //
（6）パールタを滅ぼすために、そして私の利益のために、ブラフマーがシヴァ神を守るように、あなたはカルナをあらゆる方面から守ってくれ、善き誓いを持つ者よ。
sārathyaṃ rathināṃ śreṣṭha praṇayātkartumarhasi|
tvayi yantari rādheyo vidviṣo me vijeṣyate|| // 8-23-7 //
（7）戦車戦士の中の最上者よ、親しみの情から御者を務めてくれ。あなたが手綱を握れば、ラーデーヤは我が敵を打ち負かすだろう。
abhīṣūṇāṃ hi karṇasya grahītānyo na vidyate|
ṛte hi tvāṃ mahābhāga vāsudevasamaṃ yudhi|| // 8-23-8 //
（8）カルナの手綱を取る者として、戦場でヴァースデーヴァ（クリシュナ）に等しいあなた以外に、ふさわしい者はいない、大いなる幸ある者よ。
sa pāhi sarvathā karṇaṃ yathā brahmā maheśvaram|
yathā ca sarvathā''patsu vārṣṇeyaḥ pāti pāṇḍavam|
tathā madreśvarādya tvaṃ rādheyaṃ pratipālaya|| // 8-23-9 //
（9）ブラフマーが大自在天（マヘーシュヴァラ）を守るように、ヴァールシュネーヤ（クリシュナ）があらゆる困難においてパーンダヴァを守るように、マドラの王よ、今日あなたはラーデーヤを守ってくれ。
bhīṣmo droṇaḥ kṛpaḥ karṇo bhavānbhojaśca vīryavān|
śakuniḥ saubalo drauṇirahameva ca no balam|| // 8-23-10 //
（10）ビーシュマ、ドローナ、クリパ、カルナ、あなた、勇猛なるクリタヴァルマン、シャクニ、ドローナの子（アシュヴァッターマン）、そして私——これが我らの戦力だ。
evameṣa kṛto bhāgo navadhā pṛthivīpate|
na ca bhāgo'tra bhīṣmasya droṇasya ca mahātmanaḥ|| // 8-23-11 //
（11）このようにして九つの部分に分けられた、王よ。しかしビーシュマとドローナの二人の分はもうない。
tābhyāmatītya tau bhāgau nihatā mama śatravaḥ|
vṛddhau hi tau maheṣvāsau chalena nihatau yudhi|| // 8-23-12 //
（12）あの二人の分は過ぎ去り、二人は我が敵を倒してくれた。しかしあの二人の偉大な弓の達人は、老齢であり、策略によって戦場で殺された。
kṛtvā cāsukaraṃ karma gatau svargamito'nagha|
tathānye puruṣavyāghrāḥ parairvinihatā yudhi|| // 8-23-13 //
（13）困難な偉業をなし遂げて天に逝った、罪なき者よ。そして他にも多くの勇者たちが敵に殺された。
asmadīyāśca bahavaḥ svargāya gamitāḥ paraiḥ|
tyaktvā prāṇānaythāśakti ceṣṭāṃ kṛtvā ca puṣkalām| // 8-23-14 //
（14）我が軍の多くの者たちも、命を投げ出し、力の限りの努力をして、敵に天へと送られた。
tadidaṃ hatabhūyiṣṭhaṃ balaṃ mama narādhipa|
pūrvamapyalpakaiḥ pārthairhataṃ kimuta sāmpratam|| // 8-23-15 //
（15）この軍勢は主力を失ってしまった、王よ。以前でさえ少数のパーンダヴァに打ち負かされたのに、ましてや今は。
balavanto mahātmānaḥ kaunteyāḥ satyavikramāḥ|
balaṃ śeṣaṃ na hanyurme yathā tatkuru pārthiva|| // 8-23-16 //
（16）カウンテーヤ（パーンダヴァ）たちは力強く、偉大な魂を持ち、真の武勇がある。残った軍を彼らが滅ぼさぬようにしてくれ、王よ。
hatavīramidaṃ sainyaṃ pāṇḍavaiḥ samare vibho|
karṇo hyeko mahābāhurasmatpriyahite rataḥ|| // 8-23-17 //
（17）この軍勢はパーンダヴァたちに勇者を殺され尽くしている。長い腕を持つカルナだけが、我らの親愛と利益のために残っている。
bhavāṃśca puruṣavyāghra sarvalokamahārathaḥ|
śalya karṇo'rjunenādya yodvumicchati saṃyuge|| // 8-23-18 //
（18）そしてあなた、人の中の虎、全世界の偉大な戦車戦士よ。シャリヤよ、カルナは今日、戦場でアルジュナと戦おうとしている。
tasmiñjayāśā vipulā madrarāja narādhipa|
tasyābhīṣugrahavaro nānyo'sti bhuvi kaścana|| // 8-23-19 //
（19）マドラ王よ、王よ、彼に大きな勝利の望みがかかっている。彼の手綱を取る最上の者は、この世にほかにいない。
pārthasya samare kṛṣṇo yathā'bhīṣugraho varaḥ|
tathā tvamapi karṇasya rathe'bhīṣugraho bhava|| // 8-23-20 //
（20）パールタ（アルジュナ）にとってクリシュナが戦場で最上の手綱取りであるように、あなたもカルナの戦車の手綱取りとなってくれ。
tena yukto raṇe pārtho rakṣyamāṇaśca pārthiva|
yāni karmāṇi kurute pratyakṣāṇi tathaiva tat||
pūrvaṃ naḥ samare hyevamadhīdarjuno ripūn|
idānīṃ vikramo hyasya kṛṣṇena sahitasya ca|| // 8-23-21-22 //
（21〜22）あの者（クリシュナ）に率いられ守られてこそ、パールタは戦場であのような業を成し遂げるのだ。王よ、以前は我らの敵をアルジュナがこのように圧倒することはなかった。彼の今の武勇は、クリシュナと一緒だからこそだ。
kṛṣṇena sahitaḥ pārtho dhārtarāṣṭrīṃ mahācamūm|
ahanyahani madreśa drāvayandṛśyate yudhi|| // 8-23-23 //
（23）クリシュナと一緒のパールタは、マドラの王よ、ドゥルヨーダナの大軍を、日に日に戦場で敗走させている姿が見られる。
bhāgo'vaśiṣṭaḥ karṇasya tava caiva mahādyute|
taṃ bhāgaṃ saha karṇena yugapannāśayādya hi|| // 8-23-24 //
（24）大いなる輝きよ、（九つの分の中で）カルナの分とあなたの分が残っている。その分をカルナとともに、今日一挙に使い果たしてくれ。
aruṇena yathā sārdhaṃ tamaḥ sūryo vyapohati|
tathā karṇena sahito jahi pārthaṃ mahāhave|| // 8-23-25 //
（25）夜明けの神アルナとともに太陽が闇を払うように、カルナとともにこの大戦場でパールタを討ってくれ。
udyantau ca yathā sūryau bālasūryasamaprabhau|
karṇaśalyau raṇe dṛṣṭvā vidravantu mahārathāḥ|| // 8-23-26 //
（26）若い太陽のように輝くカルナとシャリヤの二人が戦場に昇るのを見て、偉大な戦車戦士たちも逃げ出すだろう。
sūryāruṣau yathā dṛṣṭvā tamo naśyati māriṣa|
tathā naśyantu kaunteyāḥ sapāñcālāḥ sasṛñjayāḥ|| // 8-23-27 //
（27）太陽とアルナを見て闇が消えるように、カウンテーヤたち、パーンチャーラ族、スリンジャヤ族は消え去るだろう。
rathināṃ pravaraḥ karṇo yantṝṇāṃ pravaro bhavān|
saṃyogo yuvayorloke nābhūnna ca bhaviṣyati|| // 8-23-28 //
（28）戦車戦士の中の最上がカルナ、御者の中の最上があなただ。二人の組み合わせはこの世に今までなかったし、これからもないだろう。
yathā sarvāsv avasthāsu vārṣmeyaḥ pāti pāṇḍavam|
tathā bhavānparitrātu karṇaṃ vaikartanaṃ raṇe|
'sārathyaṃ kriyatāṃ tasya yudhyamānasya saṃyuge||
yathā ca samare kṛṣṇo rakṣate sarvato'rjunam|
tathā tvamapi rādheyaṃ rakṣasva ca mahāraṇe'|| // 8-23-29-30 //
（29〜30）ヴァールシュネーヤ（クリシュナ）があらゆる状況でパーンダヴァを守るように、あなたもヴァイカルタナ・カルナを戦場で守ってくれ。戦っている彼の御者を務めてくれ。クリシュナが戦場であらゆる方角からアルジュナを守るように、あなたもまたラーデーヤをこの大戦場で守ってくれ。
tvayā sārathinā hyeṣa apradhṛṣyo bhaviṣyati|
devatānāmapi raṇe saśakrāṇāṃ mahīpate|
kiṃ punaḥ pāṇḍaveyānāṃ mā viśaṅkīrvaco mama|| // 8-23-31 //
（31）あなたが御者であれば、この者は、インドラを含む天の神々すら手出しできない存在となるだろう、王よ。ましてやパーンダヴァたちなどなおさらだ。私の言葉を疑うな。」
sañjaya uvāca|
duryodhanavacaḥ śrutvā śalyaḥ krodhasamanvitaḥ|
'dhārtarāṣṭramathovāca sṛkviṇī parilelihan'||
triśikhāṃ bhrukuṭiṃ kṛtvā dhunvan hastau punaḥpunaḥ|
krodharakte mahānetre parivṛtya mahābhujaḥ|
kulaiśvaryaśrutabalairdṛptaḥ śalyo'bravīdidam|| // 8-23-32-33 //
サンジャヤは語った。 （32〜33）ドゥルヨーダナの言葉を聞いて、シャリヤは怒りに満ち、唇を舐め、三重の眉間の皺を寄せ、何度も両手を振り、怒りに赤くなった大きな目を回しながら、大きな腕を持つ者は、家柄・富・教養・武力を誇って、こう言いました。
śalya uvāca|
na māmarhasi rājedra niyoktuṃ karmaṇīdṛśe|
na hi pāpīyasaḥ śreyānpreṣyatvaṃ kartumarhati|| // 8-23-34 //
シャリヤは語った。 （34）「王の中の王よ、私をこのような仕事に任じるべきではない。身分の高い者が、身分の低い者の召使いにされるべきではない。
yo hyabhyupagataṃ mitraṃ garīyāṃsaṃ viśeṣataḥ|
vaśe pāpīyaso dhatte tatkāryamadharottaram|| // 8-23-35 //
（35）味方として迎え入れた者を、しかも身分の上の者を、身分の下の者の支配下に置く——それは本末転倒というものだ。
brahmaṇā brāhmaṇāḥ sṛṣṭā mukhātkṣatraṃ ca bāhutaḥ|
ūrubhyāmatha vaiśyā vai śūdrāḥ padbhyāmiti śrutiḥ|| // 8-23-36 //
（36）ブラフマーの口からバラモンが生まれ、腕からクシャトリヤが生まれ、腿からヴァイシャが、足からシュードラが生まれたと聖典に伝えられている。
tebhyo varṇaviśeṣāśca pratilomānulomajāḥ|
athānyonyasya saṃyogāccāturvarṇyasya bhārata||
goptāraḥ saṅgṛhītāro dātāraḥ kṣatriyāḥ smṛtāḥ|| // 8-23-37-38 //
（37〜38）そしてこれらの四姓の異なる組み合わせから、順姓・逆姓のさまざまな種姓が生まれた、バーラタよ。クシャトリヤは守護者、収集者、施与者と定められている。
yājanādhyāpanairviprā viśuddhaiś ca pratigrahaiḥ|
lokasyānugrahārthāya sthāpitā brāhmaṇā bhuvi|| // 8-23-39 //
（39）バラモンは祭式の執行・教授、そして清浄な布施の受領によって、世の人々を恩恵するためにこの地上に置かれた。
kṛṣiśca pāśupālyaṃ ca viśāṃ dānaṃ ca dharmataḥ|
brahmakṣatraviśāṃ śūdrā vihitāḥ paricārakāḥ|| // 8-23-40 //
（40）農業と牧畜と施しが、法にかなったヴァイシャの務めだ。シュードラはバラモン・クシャトリヤ・ヴァイシャに奉仕する者と定められている。
brahmakṣatrasya vihitāḥ sūtā vai paricārakāḥ|
na kṣatriyo vai sūtānāṃ śṛṇuyācca kathañcana|| // 8-23-41 //
（41）スータ（御者の階級）はバラモンとクシャトリヤに奉仕する者と定められている。クシャトリヤがスータの言うことを聞くべきではない。
ahaṃ mūrdhābhiṣikto hi rājarṣikulajo nṛpaḥ|
mahārathasamākhyātaḥ sevyaḥ stutyaś ca vandināṃ|| // 8-23-42 //
（42）私は灌頂を受けた王であり、王仙の家系に生まれた王であり、偉大な戦車戦士として知られ、吟遊詩人たちに仕えられ讃えられるべき者だ。
so'mahetādṛśo bhūtvā nehāribalasūdanaḥ|
sūtaputrasya saṅgrāme sārathyaṃ kartumutsahe|| // 8-23-43 //
（43）このような者である私が、敵軍を滅ぼす者として、御者の息子アディラタの子（カルナ）の戦場における御者を務めることに耐えられようか。
avamanyase māṃ gāndhāre dhruvaṃ cāpyatiśaṅkase|
yasmādbravīṣi visrabdhaḥ sārathyaṃ kriyatāmiti|| // 8-23-44 //
（44）ガーンダーラ（ドゥルヨーダナ）よ、お前は私を軽んじ、明らかに見下している。だからこそ平然と『御者を務めよ』などと言うのだ。
asmatto'bhyadhikaṃ karṇaṃ manvānas taṃ praśaṃsasi|
na cāhaṃ yudhi rādheyaṃ gaṇaye tulyamātmanaḥ|| // 8-23-45 //
（45）カルナを我々より上だと考えて讃えるが、私は戦場でラーデーヤを自分と同等とすら見なしていない。
ādiśyatāmabhyadhiko mamāṃśaḥ pṛthivīpate|
tamahaṃ samare hatvā gamiṣyāmi yathāgatam|| // 8-23-46 //
（46）私に、より大きな敵の分担を割り当ててくれ、王よ。それを戦場で殺してから、来た時のように帰ろう。
athavāpyeka evāhaṃ yotsyāmi tava śatrubhiḥ|
paśya vīryaṃ mamādya tvaṃ saṅgrāme dahato ripūn|| // 8-23-47 //
（47）あるいは私一人で、お前の敵たちと戦おう。今日、敵を焼き尽くす私の武勇を見よ。
na cāpi kāmānkauravya nidhāya hṛdaye pumān|
asmadvidhaḥ pravarteta mā mā tvamatiśaṅkithāḥ|| // 8-23-48 //
（48）カウラヴヤよ、望みを心に秘めて行動するのは、我々のような者にはふさわしくない。私を疑うな。
api cāpyavamāno me na kartavyaḥ kathañcana|
paśya bhīmau mama bhujau vajrasaṃhananau dṛḍhau|| // 8-23-49 //
（49）そもそも私を侮辱すべきではない。見よ、私の太い腕を——金剛石のように固く、頑丈な腕を。
dhanuḥ paśya ca me citraṃ śarāṃścāśīviṣapamān|
rathaṃ ca paśya me citraṃ sadaśvairvātavegibhiḥ|| // 8-23-50 //
（50）見よ、私の見事な弓と、毒蛇のような矢を。見よ、私の見事な戦車、風のように速い駿馬に引かれた戦車を。
gadāṃ ca paśya gāndhāre hemapaṭṭavibhūṣitām|
dārayeyaṃ mahīṃ kruddho vikireyaṃ ca parvatān|
śoṣayeyaṃ samudrāṃśca pātayeyaṃ ca bhāskaram|| // 8-23-51 //
（51）ガーンダーラよ、見よ、私の金の帯で飾られた棍棒を。怒れば私は大地を裂き、山を砕き、海を干上がらせ、太陽をも落とすことができよう。
taṃ māmevaṃvidhaṃ rājan samartham arinigrahe|
kasmādyunaṅkṣi sārathye sūtasyādhirathes tu mām|| // 8-23-52 //
（52）このような力を持ち、敵を制圧する能力を持つ私を、王よ、なぜ御者の息子アディラタの子のために御者にしようとするのか。
na cāpi mama rādheyaḥ kalāmarhati ṣoḍaśīm|| // 8-23-53 //
（53）ラーデーヤは私の十六分の一にも値しない。
sakarṇā ye trayo lokāḥ sārjunāḥ sajanārdanāḥ|
nibaddhāṃs tantraṇe rājan na gaṇeyaṃ kathañcana|| // 8-23-54 //
（54）カルナを含む三界、アルジュナを含む三界、クリシュナ（ジャナールダナ）を含む三界——すべてが一つに束ねられても、王よ、私は少しも気にしない。
na cāhaṃ prākṛtaḥ kaścinna cāsmyadhigataḥ svayam|
ayaṃ cāpyavamāno me na kartavyaḥ kathañcana|| // 8-23-55 //
（55）私はつまらぬ者ではないし、誰かに征服された者でもない。私への侮辱は断じて行うべきではない。
āpṛcche tvādya gāndhāre yāsyāmi viṣayaṃ prati|
na cāhaṃ sūtaputrasya sārathyamupajagmivān|| // 8-23-56 //
（56）ガーンダーラよ、今日お前に暇乞いをして、自分の国に帰ろう。私は御者の息子の御者など務めない。
avamānamahaṃ prāpya na yotsyāmi kathañcana|
āpṛcche tvā'dya gāndhāre gamiṣyāmi gṛhāya vai|| // 8-23-57 //
（57）侮辱を受けた私は、いかなる形でも戦わない。ガーンダーラよ、今日お前に暇乞いをし、我が家に帰る。」
sañjaya uvāca|
evamuktvā mahārāja śalyaḥ samitiśobhanaḥ|
utthāya prayayau tūrṇaṃ rājamadhyād amarṣitaḥ|| // 8-23-58 //
サンジャヤは語った。 （58）大王よ、戦場で輝くシャリヤはこう言うと、怒りに満ちて、王たちの中から立ち上がり、速やかに去ろうとしました。
praṇayādbahumānācca taṃ nigṛhya sutas tava|
abravīnmadhuraṃ vākyaṃ sāmnā sarvārthasādhakam|| // 8-23-59 //
（59）あなたの息子は、親しみと敬意をもって彼を引き留め、あらゆる目的を達成する融和の策をもって、甘い言葉を語りました。
yathā śalya tvamātthedamevametadasaṃśayam|
abhiprāyas tu me kaścit taṃ nibodha janeśvara|| // 8-23-60 //
（60）「シャリヤよ、あなたがおっしゃったとおり、そのとおりだ、疑いなく。しかし私にはある考えがある。それを聞いてくれ、王よ。
na karṇo'bhyadhikas tvatto na cānye caiva pārthivāḥ|
na ca madreśvara tvāṃ vai kṛṣṇaḥ soḍhuṃ ca śakṣyati|| // 8-23-61 //
（61）カルナがあなたより優れているのでも、他の王たちが優れているのでもない。マドラの王よ、クリシュナですらあなたに耐えることはできないだろう。
ṛtameva hi pūrvās te vadanti puruṣottamāḥ|
tasmādārtāyaniḥ prokto bhavāniti matirmama|| // 8-23-62 //
（62）古の優れた人々は真実を語ったとされる。あなたがアールターヤニ（リタの子孫）と呼ばれるのもそのためだ、と私は考えている。
śalyabhūtas tu śatrūṇāṃ yasmāttvaṃ yudhi mānada|
tasmācchalyeti te nāma kathyate pṛthivītale|| // 8-23-63 //
（63）あなたは戦場で敵にとって棘（シャリヤ＝棘）のような存在であるがゆえに、尊敬を与える者よ、この地上ではシャリヤという名で呼ばれるのだ。
yadetadvyāhṛtaṃ pūrvaṃ bhavatā bhūridakṣiṇa|
tadeva kuru dharmajña madarthaṃ yadyaducyate|| // 8-23-64 //
（64）惜しみなく布施をする者よ、あなたが先に述べたこと——法を知る者よ、私のためにそれをなしてくれ。
na ca tvatto hi rādheyo na cāhamapi vīryavān|
vṛṇe'haṃ tvāṃ hayāgryāṇāṃ yantāramiha saṃyuge|| // 8-23-65 //
（65）ラーデーヤがあなたより強いのでもなく、私が武勇においてあなたより勝っているのでもない。私はあなたを、この戦場で最上の馬の手綱取りとして選ぶのだ。
manye cābhyadhikaṃ śalya guṇaiḥ karṇaṃ dhanañjayāt|
bhavantaṃ vāsudevācca loko'yamatimanyate|| // 8-23-66 //
（66）シャリヤよ、私はカルナがアルジュナより能力において優れていると考えている。そしてこの世の人々は、あなたをヴァースデーヴァ（クリシュナ）より上と認めている。
karṇo hyabhyadhikaḥ pārthād astrair eva nararṣabha|
bhavānabhyadhikaḥ kṛṣṇādaśvajñāne bale tathā|| // 8-23-67 //
（67）カルナは武器においてパールタより優れている、人の中の雄牛よ。あなたは馬の知識と力においてクリシュナより優れている。
yathā'śvahṛdayaṃ veda vāsudevo mahāmanāḥ|
dviguṇaṃ tvaṃ tathā vetsi madrarājeśvarātmaja|| // 8-23-68 //
（68）ヴァースデーヴァという偉大な魂が馬の心を知るように、あなたはその倍を知っている、マドラ王家の王子よ。」
śalya uvāca|
yanmāṃ bravīṣi gāndhāre madhye sainyasya kaurava|
viśiṣṭaṃ devakīputrātprītimānasmyahaṃ tvayi|| // 8-23-69 //
シャリヤは語った。 （69）「ガーンダーラよ、軍のただ中で私をデーヴァキーの子（クリシュナ）より優れていると言ってくれたこと、私はお前に喜びを感じる。
eṣa sārathyamātiṣṭhe rādheyasya yaśasvinaḥ|
yudhyataḥ pāṇḍavāgryeṇa yathā tvaṃ vīra manyase|| // 8-23-70 //
（70）栄光あるラーデーヤの御者を務めよう。パーンダヴァの最上者（アルジュナ）と戦う彼のために。お前が望むとおりに、勇者よ。
samayaśca hi me vīra kaścid vaikartanaṃ prati|
utsṛjeyaṃ yathāśraddham ahaṃ vāco'sya sannidhau|| // 8-23-71 //
（71）しかし勇者よ、ヴァイカルタナ（カルナ）に対して一つ条件がある。私は彼の前で、好きなように言いたいことを言わせてもらう。」
sañjaya uvāca|
tatheti rājan putras te saha karṇena bhārata|
abravīnmadrarājasya mataṃ bharatasaxxxx|| || // 8-23-72 //
サンジャヤは語った。 （72）王よ、あなたの息子は、バーラタよ、カルナとともに「そのようにせよ」と言い、マドラ王の意に同意しました。
iti śrīmanmahābhārate karṇaparvaṇi trayoviṃśo'dhyāyaḥ|| 23 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十三章は終わる。
