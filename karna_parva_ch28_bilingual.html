マハーバーラタ ― カルナ篇 第28章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 28 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ28」（御者の役を疑うシャリヤに対し、ドゥルヨーダナがパラシュラーマの伝説を語る場面。バルガヴァ家のラーマ（パラシュラーマ）がシヴァ神の恩寵により神々の敵を討つ武勇を授かった次第と、その弟子であるカルナの出自・資質に欠けるところがないことを説く）です。各段落は原典の詩節番号（8-28-N）と和訳の段落番号が対応しています。
karṇaparva — aṣṭaviṃśo'dhyāyaḥ (28)
第28章　ドゥルヨーダナがパラシュラーマの物語を語り、カルナの御者をシャリヤに務めてもらう上での問題がないことを示す
duryodhana uvāca|
imaṃ cāpyaparaṃ bhūya iti hāsaṃ nibodha me|
pitur mama sakāśe vai brāhmaṇaḥ prāha dharmavit|| // 8-28-1 //
ドゥルヨーダナは語った。 （1）「もう一つ別の話を聞いてくれ、シャリヤよ。法を知るバラモンが私の父のもとで語ったことだ。
śrutvā ca etad vacaś citraṃ hetukāryārthatattvavit|
kuru śalya viniścitya mā bhūdatra vicāraṇā|| // 8-28-2 //
（2）この不思議な話を聞いて、道理と目的の真理を知る者として、シャリヤよ、確信をもって行動してくれ。ためらうな。
bhārgavāṇāṃ kule jāto jamadagnirmahātapāḥ|
tasya rāmeti vikhyātaḥ putras tejoguṇānvitaḥ|| // 8-28-3 //
（3）バールガヴァ族の家系に生まれた偉大な苦行者ジャマダグニがいた。その息子がラーマ（パラシュラーマ）として知られ、威光と徳に満ちた者だった。
sa tīvraṃ tapa āsthāya samprasāditavān bhavam|
astrahetoḥ prasannātmā niyataḥ saṃyatendriyaḥ|| // 8-28-4 //
（4）彼は激しい苦行を行い、心穏やかに感覚を制して、バヴァ（シヴァ）を喜ばせた——武器を得るために。
tasmai tuṣṭo mahādevo bhaktyā ca praśamena ca|
hṛdgataṃ cāsya vijñāya darśayāmāsa śaṅkaraḥ|
pratyakṣeṇa mahādevaḥ svāṃ tanuṃ sarvaśaṅkaraḥ|| // 8-28-5 //
（5）マハーデーヴァは彼の信仰心と穏やかさに満足し、その心の内を知って、姿を現した。大自在天シャンカラ自ら。
śaṅkara uvāca|
rāma tuṣṭo'smi bhadraṃ te viditaṃ tava ca īpsitam|
kuruṣva pūtamātmānaṃ sarvametadavāpsyasi|| // 8-28-6 //
シャンカラは語った。 （6）『ラーマよ、私はお前に満足した。お前に幸あれ。お前の望みはわかっている。自らを清めよ。そうすればすべてを得るだろう。
dāsyāmi te tadā'strāṇi yadā pūto bhaviṣyasi|
apātramasamarthaṃ ca dahanty astrāṇi bhārgava|| // 8-28-7 //
（7）お前が清らかになった時、武器を授けよう。ふさわしくない器、力なき者は、武器に焼かれてしまう、バールガヴァよ。』
ityukto jāmadagnyas tu devadevena śūlinā|
pratyuvāca mahātmānaṃ śirasā'vanataḥ prabhum|| // 8-28-8 //
（8）ジャマダグニの子はこう言われて、槍を持つ天の神の中の神に、頭を垂れて答えた。
yadā jānāsi deveśa pātraṃ māmastradhāraṇe|
tadā śuśrūṣate'strāṇi bhavān me dātum arhati|| // 8-28-9 //
（9）『天の神の主よ、あなたが武器を受け取るにふさわしい器だと知ってくだされば、その時に、仕える者であるこの私に武器をお授けください。』
tataḥ sa tapasā caiva vratena niyamena ca|
pūjopahārabalibhir homamantrapuraskṛtaiḥ||
samārādhitavāñ śarvaṃ bahuvarṣagaṇāṃs tadā|
prasannaś ca mahādevo bhārgavasya mahātmanaḥ|| // 8-28-10-11 //
（10〜11）それから彼は苦行と誓いと戒律と、供物・捧げ物・供犠・マントラを伴う礼拝によって、何年もの間シャルヴァ（シヴァ）に仕えた。そしてマハーデーヴァはバールガヴァという偉大な魂に満足した。
asakṛc ca abravīt tasya guṇān devyāḥ sakāśataḥ|
bhaktimān eṣa satataṃ mayi rāmo dṛḍhavrataḥ||
evam asya guṇān prīto bahuśo kathayad vibhuḥ|
devatānāṃ pitṝṇāṃ ca samakṣam arisūdana|| // 8-28-12-13 //
（12〜13）何度も妃（パールヴァティー）の前でこの者の美徳を語った。『このラーマは常に私に対して信仰心厚く、堅固な誓いを持っている。』このように喜んで、天の神や祖霊たちの前で何度も彼の美徳を語った、敵を滅ぼす者よ。
etasmin eva kāle tu daityā hy āsan mahābalāḥ|
taiḥ tadā darpamohād vai abādhyanta divaukasaḥ|| // 8-28-14 //
（14）ちょうどその頃、大力の悪魔たちがいて、驕りと妄執から天の者たちを苦しめていた。
tataḥ sambhūya vibudhās tān hantuṃ kṛtaniścayāḥ|
cakruḥ śatruvadhe yatnaṃ daityāñ cetum aśaknuvan|| // 8-28-15 //
（15）そこで天の神々は一致団結して悪魔たちを倒す決意をしたが、敵を倒すための努力にもかかわらず、悪魔たちに勝つことができなかった。
abhigamya tato devā maheśvaramumāpatim|
prāsādayaṃs tadā bhaktyā jahi śatrugaṇān iti|| // 8-28-16 //
（16）天の神々はマヘーシュヴァラ（大自在天）、ウマーの夫のもとに行き、信仰をもって『敵の群れを殺したまえ』と懇願した。
pratijñāya tato devo devatānāṃ ripukṣayam|
rāmaṃ bhārgavam āhūya so'bhyabhāṣata śaṅkaraḥ|| // 8-28-17 //
（17）そこで神は天の神々のために敵の滅亡を約束し、バールガヴァ・ラーマを呼んでこう語りかけた。
ripūn bhārgava devānāṃ jahi sarvān samāgatān|
lokānāṃ hitakāmārthaṃ matpriyārthaṃ tathaiva ca|| // 8-28-18 //
（18）『バールガヴァよ、天の神々の敵を、集まったすべての敵を殺せ。世の人々の利益のために、そして私を喜ばせるために。』
paraśurāma uvāca|
kā śaktir mama deveśa akṛtāstrasya saṃyuge|
nihantuṃ dānavān sarvān kṛtāstrān yuddhadurmadān|| // 8-28-19 //
パラシュラーマは語った。 （19）『天の神の主よ、武器の修行を終えていない私に、戦場で、武器を修めた戦い狂いの悪魔たち全員を殺す力がありましょうか。』
īśvara uvāca|
gaccha tvaṃ madanujñānān nihaniṣyasi śātravān|
vijitya ca ripūn sarvān guṇān prāpsyasi puṣkalān|| // 8-28-20 //
イーシュヴァラは語った。 （20）『我が許しを得て行け。お前は敵を殺すだろう。すべての敵を打ち負かし、豊かな美徳を得るだろう。』」
duryodhana uvāca|
etac chrutvā tu vacanaṃ pratigṛhya ca sarvaśaḥ|
rāmaḥ kṛtasvastyayanaḥ prayayau dānavān prati|| // 8-28-21 //
ドゥルヨーダナは語った。 （21）「この言葉を聞き、すべてを受け入れたラーマは、祝福の儀式を終えて、悪魔たちに向かって出発した。
tato'jayad devaśatrūn mahādarpabalānvitān|
vajrāśanisamasparśaiḥ prahārair eva bhārgavaḥ|| // 8-28-22 //
（22）そして金剛杵や雷のような打撃で、大いなる驕りと力に満ちた天の敵たちを打ち負かした、バールガヴァは。
sa dānavaiḥ kṣatatanur jāmadagnyo nṛpottama|
saṃspṛṣṭaḥ sthāṇunā sadyo nirvraṇaḥ samapadyata|| // 8-28-23 //
（23）悪魔たちに体を傷つけられたジャーマダグニヤ（パラシュラーマ）は、王の中の最上者よ、スターヌ（シヴァ）に触れられるやいなや、傷は癒された。
prītaś ca bhagavān devaḥ karmaṇā tena tasya vai|
varān prādād bahuvidhān bhārgavāya mahātmane|| // 8-28-24 //
（24）そして至高の神はその業に満足し、偉大なる魂バールガヴァにさまざまな恩寵を授けた。
uktaś ca prītiyuktena devadevena śūlinā||
nipātāt tava śastrāṇāṃ śarīre yā'bhavad rujā|
tayā te mānuṣaṃ karma vyapohaṃ bhṛgunandana|
gṛhāṇa astrāṇi divyāni matsakāśād yathā īpsitaṃ|| // 8-28-25-26 //
（25〜26）喜びに満ちた天の神の中の神、槍を持つ方は言った。『お前の武器による傷で体に生じた痛み——それによって、お前の人間としての業（カルマ）は払い除かれた、ブリグの子孫よ。さあ、神聖な武器を、望むままに我から受け取るがよい。』
tato'strāṇi samagrāṇi varāṃś ca manas īpsitān|
labdhvā bahuvidhān rāmaḥ praṇamya śirasā śivam|
anujñāṃ prāpya deveśāj jagāma sa mahātapāḥ|| // 8-28-27 //
（27）こうしてすべての武器と、望みのままのさまざまな恩寵を得たラーマは、シヴァに頭を垂れ、天の神の主から許しを得て去った、あの偉大な苦行者は。
evam etat purāvṛttaṃ tathā kathitavān ṛṣiḥ|| // 8-28-28 //
（28）このように昔のことが聖仙によって語られた。
bhārgavo'pi dadau sarvaṃ dhanurvedaṃ mahātmane|
karṇāya puruṣavyāghraḥ suprītena antarātmanā|| // 8-28-29 //
（29）そしてバールガヴァ（パラシュラーマ）もまた、弓術のすべてを偉大なる魂カルナに、大いに喜んで心から授けたのだ、人の中の虎よ。
vṛjinaṃ na bhavet kiñcid asya karṇasya pārthiva|
sūtena vardhito nityaṃ na sūto nṛpa eva saḥ|| // 8-28-30 //
（30）このカルナには何の罪もない、王よ。御者（スータ）に育てられたが、スータではなく、王族の者なのだ。
viśuddhayoniṃ vijñāya divyāny astrāṇy adād bhṛguḥ|
nāpi sūtakule jātaṃ manye karṇaṃ kathañcana|
devaputramadaṃ manye kṣatriyāṇāṃ kulodbhavam|| // 8-28-31 //
（31）清い血筋であることを知って、ブリグ（パラシュラーマ）は神聖な武器を授けた。カルナが御者の家に生まれた者だとは到底思えない。天の神の息子であり、クシャトリヤの家系の出だと私は考えている。
visṛṣṭam avibodhārthaṃ kulasya iti matir mama|
sarvathā na hy aso śalya karṇaḥ sūtakulodbhavaḥ|| // 8-28-32 //
（32）知られぬまま（養子に）出されたのだと私は思う。いずれにしても、シャリヤよ、カルナは御者の家の出ではない。
sakuṇḍalaṃ sakavacaṃ dīrghabāhum arindamam|
katham ādityasaṅkāśaṃ mṛgī siṃhaṃ prasūyate|| // 8-28-33 //
（33）耳飾りと鎧をまとって生まれ、長い腕を持ち、敵を滅ぼすこの太陽のような者を——鹿がどうして獅子を産めようか。
paśya hy asya bhujau pīnau nāgarājakaropamau|
vakṣaḥ paśya viśālaṃ ca sarvaśastrasahaṃ raṇe|| // 8-28-34 //
（34）見よ、彼の太い腕を——蛇の王の鼻のような腕を。見よ、彼の広い胸を——戦場であらゆる武器に耐える胸を。
na tu eva prākṛtaḥ kaścit karṇo vaikartano vṛṣā|
mahātmā hy eṣa rājendra rāmaśiṣyaḥ pratāpavān|| || // 8-28-35 //
（35）カルナ、ヴァイカルタナ、ヴリシャ——この者はつまらない人間ではない。この偉大な魂は、王の中の王よ、パラシュラーマの弟子であり、威光ある者なのだ。」
iti śrīmanmahābhārate karṇaparvaṇi aṣṭaviṃśo'dhyāyaḥ|| 28 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十八章は終わる。
