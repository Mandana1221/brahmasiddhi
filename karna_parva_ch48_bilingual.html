マハーバーラタ ― カルナ篇 第48章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 48 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ48」（アルジュナがサンシャプタカ（誓いを立てた決死隊）およびコーサラ・ナーラーヤナ軍と戦う全51詩節の章）です。サンジャヤが語るところによれば、ガーンディーヴァの弦音が響き渡る中、アルジュナはサンシャプタカ軍を打ち破り続けますが、敵将スシャルマーは矢の雨で幾度もアルジュナとクリシュナに攻撃を加えます。多数の敵戦士がアルジュナの戦車を取り囲んで馬と車輪を捕らえようとしますが、クリシュナ（猿の旗印、すなわちハヌマーン旗）が恐ろしい咆哮を発して敵軍を一時麻痺させ（第9〜11詩節）、アルジュナはやがて自力で包囲を脱して敵戦士たちを次々と打ち倒します。両軍は法螺貝を吹き交わし（デーヴァダッタとパーンチャジャンヤ、第25〜26詩節）、アルジュナは蛇の武器（ナーガーストラ）でサンシャプタカ軍の足を縛りつけますが（第28〜30詩節）、スシャルマーは金翅鳥の武器（サウパルナーストラ）でこれを打ち破ります（第32〜34詩節）。アルジュナはスシャルマーの矢に深く傷つき一時戦車の中に沈み込み、敵軍は「パールタは死んだ」と一斉に歓声をあげますが（第38詩節）、すぐに意識を取り戻し、インドラの武器（アインドラーストラ）でスシャルマーを退けます（第42詩節）。章末近くでは、戦死者数が一万の戦士・一万四千の戦車・三千の象に及んだことが語られ（第48〜49詩節）、なおも生死を賭してアルジュナを包囲するサンシャプタカ軍を、インドラがアスラを討つがごとくアルジュナが打ち倒す場面で終わります（第51詩節）。なお、原典の奥書（コロフォン）には第40・42〜47章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典にも、前章（第47章）と同様、本来の第1〜51詩節の連番に先立って余分な注記「8-48-0」が冒頭の「サンジャヤは語った」の一文に付されているという特異な誤記が見られたため、これを第1詩節の本文に統合した上で全51詩節を正しく分離・対訳しています。
karṇaparva — aṣṭacatvāriṃśo'dhyāyaḥ (48)
第48章
sañjaya uvāca|
vartamāne tathā yuddhe kṣatriyāṇāṃ nimajjane|
gāṇḍīvasya mahāghoṣaḥ śrūyate yudhi māriṣa|| // 8-48-1 //
サンジャヤは語った。 （1）クシャトリヤたちが沈む戦いが進む中、戦場ではガーンディーヴァ弓の大音響が聞こえた。
saṃśaptakānām akarot kadanaṃ yatra pāṇḍavaḥ|
kosalānāṃ tathā rājan nārāyaṇabalasya ca|| // 8-48-2 //
（2）パーンダヴァ（アルジュナ）はサンシャプタカ族に殺戮を行なっていた。コーサラ族、そしてナーラーヤナ軍に対しても、王よ。
saṃśaptakāstu samare śaravṛṣṭiḥ samantataḥ|
apātayan pārthamūrdhni jayagṛddhāḥ pramanyavaḥ|| // 8-48-3 //
（3）戦場でサンシャプタカ族は、勝利に飢えた激怒した者として、あたり一面に矢の雨をアルジュナの頭上に降らせた。
tāṃ śastravṛṣṭimāyāntīm urasā dhārayan prabhuḥ|
vyagāhata parān pārtho vinighnan rathināṃ varān|| // 8-48-4 //
（4）飛来するその武器の雨を、胸で受けとめながら、主アルジュナは、戦車戦士の最上者たちを討ちつつ、敵の中に踏み込んだ。
vikṣobhya tu rathānīkaṃ kaṅkapatraiḥ śilāśitaiḥ|
āsasāda tataḥ pārthaḥ suśarmāṇaṃ mahāratham|| // 8-48-5 //
（5）鋭くされた羽根矢で戦車軍を揺り動かしたあと、アルジュナは偉大な戦車戦士スシャルマンに近づいた。
sa tasya śaravarṣāṇi vavarṣa rathināṃ varaḥ|
tathā saṃśaptakāś ca eva pārthasya samare sthitāḥ|| // 8-48-6 //
（6）戦車戦士の最上者（スシャルマン）はアルジュナに矢の雨を降らせた。戦場でサンシャプタカ族も共にアルジュナに立ち向かった。
suśarmā tu tataḥ pārthaṃ viddhvā daśabhir āśugaiḥ|
janārdanaṃ tribhir bāṇair ahanad dakṣiṇe bhuje|| // 8-48-7 //
（7）スシャルマンはアルジュナを十本の鋭い矢で射、クリシュナ（ジャナールダナ）を三本の矢で右腕に射た。
tato'pareṇa bhallena ketuṃ pārthasya māriṣa|
vivyādha samare rājan suśarmā krodhamūrcchitaḥ|| // 8-48-8 //
（8）さらに別の広頭矢で、戦場でスシャルマンは、激怒してアルジュナの旗を射抜いた。
sa vānaravaro rājan viśvakarmakṛto mahān|
nanāda sumahānādaṃ nṛtyan iva vibhīṣayan|| // 8-48-9 //
（9）偉大なる猿（アルジュナの旗に描かれた）は、ヴィシュヴァカルマンが作ったもので、踊りながら大きな叫び声を発した。
kapestu ninadaṃ śrutvā santrastā tava vāhinī|
bhayaṃ vipulamāsādya niśceṣṭā samapadyata|| // 8-48-10 //
（10）猿の叫びを聞いて、あなたの軍は恐怖に包まれ、大きな恐れにとらわれ、動けなくなった。
tataḥ sā śuśubhe senā niśceṣṭā'vasthitā nṛpa|
nānāpuṣpasamākīrṇaṃ yathā citrīkṛtaṃ vanam|| // 8-48-11 //
（11）クル族の最上者よ、動かぬその軍は、さまざまな花の散らばる、絵画のような森のように輝いていた。
pratilabhya tataḥ saṃjñāṃ yodhāste kurusattama|
arjunaṃ siṣicur bāṇaiḥ parvataṃ jaladā iva|| // 8-48-12 //
（12）意識を取り戻した戦士たちは、アルジュナに矢を降らせた。山に雲が水を降らすように。
sañchādya samare pārthaṃ parivavruḥ samantataḥ|
te hayān rathacakre tu ratheṣāṃ cāpi māriṣa|
grahītuṃ pracakramuś ca eva krodhāviṣṭāḥ samantataḥ|| // 8-48-13 //
（13）戦場でアルジュナを覆い、あたり一面で取り囲み、馬や戦車の車輪、車軸を、怒ってあたり一面から掴もうとした。
nigṛhya tu rathaṃ tasya yodhāste tu sahasraśaḥ|
rathabandhaṃ pracakrur hi pāṇḍavasya amitaujasaḥ|| // 8-48-14 //
（14）彼らは数千でアルジュナの戦車を押さえようとし、無量の光輝あるパーンダヴァ（アルジュナ）の戦車を縛ろうとした。
rathamāruruhuḥ kecit kṛṣṇapārthau jighṛkṣavaḥ|
saṃśaptakānāṃ yodhāste siṃhanādāṃś ca nedire|| // 8-48-15 //
（15）クリシュナとアルジュナを捕えようと戦車に登った者もあった。サンシャプタカ族の戦士たちは獅子吼をあげた。
apare jagṛhuś ca eva keśavasya mahābhujau|
pārthaṃ caike mahārāja rathasthaṃ jagṛhur mudā|| // 8-48-16 //
（16）他の者はケーシャヴァ（クリシュナ）の長い腕を掴み、大王よ、ある者は戦車の上のアルジュナを喜んで捕えた。
acyutaḥ sa mahābāhur vidhunvan raṇamūrdhani|
pātayāmāsa tān sarvān duṣṭahastī iva hastipān|| // 8-48-17 //
（17）不滅のケーシャヴァは、長き腕を振るい、戦場でそれらすべてを投げ飛ばした。悪い象を象使いが投げるように。
sa rathas tair gṛhītas tu pāṇḍavasya mahātmanaḥ|
spandituṃ nāśakad rājaṃs tad adbhutam iva abhavat|| // 8-48-18 //
（18）高潔なパーンダヴァ（アルジュナ）の戦車は、彼らに掴まれて動くこともできなかった。それは驚異のようであった、王よ。
tataḥ pārtho mahābāhuḥ saṃvṛtaḥ tair mahārathaiḥ|
nigṛhītaṃ rathaṃ dṛṣṭvā tāṃś ca api ādravato bahūn|| // 8-48-19 //
（19）多数の偉大な戦車戦士に囲まれた長き腕のアルジュナは、戦車が拘束されたのを見て、襲ってくる多くの者たちを見て、――。
rathārūḍhāṃś ca subahūn padā''kṣipya nyapātayat|
apātayad asambhrāntaḥ śarair āsannayodhibhiḥ|| // 8-48-20 //
（20）戦車に乗った多くの者を足で蹴り落とし、慌てることなく、近づく敵を矢で倒した。
tāṃs tāpayitvā samare pārthaḥ parapurañjayaḥ|
smayan iva mahābāhuḥ keśavaṃ vākyam abravīt|| // 8-48-21 //
（21）戦場で敵を焼き払ったアルジュナは、長き腕の敵の都を征服する者は、微笑んでケーシャヴァに言った。
paśya kṛṣṇa mahābāho saṃśaptakagaṇān bahūn|
kurvato'sukaraṃ karma mumūrṣūn kālacoditān|| // 8-48-22 //
（22）「クリシュナよ、長き腕の者よ、多くのサンシャプタカ族を見よ。難しい業をなす、死ぬと定められた、死に急かされた者たちを。
rathabandhamimaṃ prāpya pṛthivyāṃ nāsti kaścana|
yaḥ saheta pumān loke mad anyaḥ kṣatriyarṣabhaḥ|| // 8-48-23 //
（23）この戦車の束縛に遭って、地上には誰もいない。私以外に、この束縛に耐え得るクシャトリヤの雄牛は。
paśya etān adya samare matprayuktaiḥ sutejanaiḥ|
pātyamānān raṇe kṛṣṇa śarairāśīviṣopamaiḥ|| // 8-48-24 //
（24）見よ、クリシュナよ、戦場で私の放つ、毒蛇のような矢で、今日、戦場で倒される彼らを」。
iti evam uktvā bībhatsuḥ śaṅkhapravaramuttamam|
vyanādayadameyātmā devadattaṃ mahāmṛdhe|| // 8-48-25 //
（25）こう言って、アルジュナ（ビーバツ）は最上の法螺貝、神の授けし「デーヴァダッタ」を吹き鳴らした。
devadattasvanaṃ śrutvā keśavo'pi mahāyaśāḥ|
pāñcajanyasvanaṃ cakre pūrayan iva rodasī|| // 8-48-26 //
（26）デーヴァダッタの響きを聞いて、名高きケーシャヴァ（クリシュナ）もパーンチャジャニヤの響きを発した。天地を満たすかのように。
tayoḥ śaṅkhasvanaṃ śrutvā saṃśaptakavarūthinī|
sañcacāla mahārāja vitrastā ca adravad bhṛśam|| // 8-48-27 //
（27）その二つの法螺貝の響きを聞いて、サンシャプタカの戦車群は、大王よ、震え、恐れて激しく逃げ去った。
nāgamastraṃ tataḥ pārthaḥ prāduścakre hasan iva|
pādabandhaṃ sa teṣāṃ vai cakre tena mahāstravit|| // 8-48-28 //
（28）パーンダヴァ（アルジュナ）は蛇の武器を、笑うように発動した。武器の通暁者の彼は、彼らの足を縛った。
yān uddiśya raṇe pārthaḥ pādabandhaṃ cakāra ha|
te baddhāḥ pādabandhena yodhāḥ saṃśaptakāstadā|| // 8-48-29 //
（29）戦場でそれを対象としてアルジュナが足を縛った、そのサンシャプタカ族の戦士たちは――。
nirviceṣṭās tadā abhūvan pāṇḍavasya astratejasā|
nirviceṣṭāṃs tato yodhān avadhīt pāṇḍunandanaḥ|
yathā indraḥ samare daityāṃs tārakasya vadhe purā|| // 8-48-30 //
（30）パーンダヴァの武器の威力で動けなくなった。動けない戦士たちを、パーンダヴァの子は討った。インドラがタラカ討伐で昔ダーナヴァ軍を討ったように。
te vadhyamānāḥ samare mumucus taṃ rathottamam|
āyudhāni ca sarvāṇi visraṣṭumupacakramuḥ|| // 8-48-31 //
（31）戦場で殺される彼らは、最上の戦車を離し、すべての武器を投げ捨てようとし始めた。
tataḥ suśarmā rājendra gṛhītāṃ vīkṣya vāhinīm|
sauparṇamastraṃ tvaritaḥ prāduścakre mahārathaḥ|| // 8-48-32 //
（32）王よ、スシャルマンは自軍の縛られたのを見て、鳥王ガルダの武器を素早く発動した、偉大な戦車戦士は。
tataḥ suparṇāḥ sampetur bhakṣayanto bhujaṅgamān|
tato vidudruvur nāgās tān dṛṣṭvā khecarān nṛpa|| // 8-48-33 //
（33）すると鳥ガルダたちが飛来し、蛇たちを食らった。蛇たちはその空を行く者たちを見て、ばらばらに逃げた。
tadvimuktaṃ balaṃ reje pādabandhād viśāmpate|
meghabandhādyathā mukto bhāskaras tāpayan prajāḥ|| // 8-48-34 //
（34）縛りを解かれたその軍は、足縛りから解放されて、国王よ、雲の縛りから解かれた太陽のように輝いた。
vipramuktāḥ svakā yodhāḥ phalgunasya rathaṃ prati|
sasṛjuḥ śarasaṅghāṃś ca śastrasaṅghāṃś ca māriṣa|| // 8-48-35 //
（35）自軍が解放された戦士たちは、アルジュナの戦車に向かって、矢の群れ、武器の群れを放った。
tāṃ mahāstramayīṃ vṛṣṭiṃ śaraiḥ sañchidya bhārata|
avadhīt satato yodhān vāsaviḥ paravīrahā|| // 8-48-36 //
（36）大いなる武器を含むその雨を矢で切り裂き、インドラの子アルジュナは、敵の勇者を討つ者として、戦士たちを討ち続けた。
suśarmā tu tato rājan bāṇena nataparvaṇā|
arjunaṃ hṛdaye viddhvā vivyādha anyais trisaptabhiḥ|| // 8-48-37 //
（37）スシャルマンは節のまっすぐな矢で、王よ、アルジュナを心臓に射抜き、さらに他の七十三本の矢で射た。
sa gāḍhaviddho vyathito rathopastha upāviśat|
tata uccukruśuḥ sarve hataḥ pārtha iti bruvan|| // 8-48-38 //
（38）深く刺され痛みに苦しみ、戦車の床に坐り込んだ。皆が「アルジュナは殺された！」と叫んだ。
tataḥ śaṅkhaninādāś ca bherīśabdāś ca puṣkalāḥ|
nānāvāditraninadāḥ siṃhanādāś ca jajñire|| // 8-48-39 //
（39）そして法螺貝の響き、大量の太鼓の音、さまざまな楽器の音、獅子吼が起こった。
pratilabhya tataḥ saṃjñāṃ śvetāśvaḥ kṛṣṇasārathiḥ|
so'tividdho maheṣvāsaḥ śarair āśīviṣopamaiḥ|
suśarmāṇaṃ mahārāja krodhāviṣṭo mahārathaḥ|| // 8-48-40 //
（40）意識を取り戻した白馬の乗り手（アルジュナ）、黒きクリシュナを御者とする彼は、毒蛇のような矢で激しく苦しめられた大弓使い、激怒した偉大な戦車戦士は――。
tataḥ śaraśataiḥ pārthaḥ sañchādya enaṃ kṣaṇād raṇe|
diśastu vārayāmāsa bāṇais tatra mahāstravit|| // 8-48-41 //
（41）百の矢で、スシャルマンを一瞬で戦場で覆い、矢で諸方向を覆った。大武器の通暁者は。
vimukhīkṛtya samare suśarmāṇaṃ dhanañjayaḥ|
aindramastramameyātmā prāduścakre hasan iva|| // 8-48-42 //
（42）スシャルマンを戦場で退かせて、無量の魂のアルジュナは、インドラの武器を笑うかのように発動した。
tato bāṇasahasrāṇi tadutsṛṣṭāni māriṣa|
sarvadikṣu vyadṛśyanta sūdayanti rathadvipān|| // 8-48-43 //
（43）放たれた数千の矢は、あらゆる方向で、戦車・象・――を見えた。倒すのが――。
hayān pattīṃś ca samare śastraiḥ śatasahasraśaḥ|
rarāja samare rājañ śakro nighnan iva asurān|| // 8-48-44 //
（44）戦場で馬・歩兵を、武器で百千と、王よ、戦場でインドラがアスラたちを討つように、輝いた。
vadhyamāne tataḥ sainye bhayaṃ sumahadāviśat|
saṃśaptakagaṇānāṃ ca gopālānāṃ ca bhārata|| // 8-48-45 //
（45）軍勢が殺されてゆくとき、大きな恐れが入り込んだ。サンシャプタカ族、そして牛飼い（ゴーパーラ）たちに、バーラタよ。
na hi tatra pumān kaścid yo'rjunaṃ pratibudhyate|
paśyatāṃ tatra vīrāṇām ahanyata balaṃ tava|| // 8-48-46 //
（46）アルジュナに気づく者は誰もいなかった。勇者たちの見る前で、あなたの軍は討たれていった。
hanyamānaṃ ca tad abhūn niśceṣṭaṃ ca parākrame|| // 8-48-47 //
（47）殺されていく軍は、武勇の中で動きを失った。
ayutaṃ tatra yodhānāṃ hatvā pāṇḍusuto raṇe|
vyabhrājata mahārāja vidhūmo'gniriva jvalan|| // 8-48-48 //
（48）一万の戦士を戦場で殺したパーンドゥの子は、大王よ、煙のない炎の火のように輝いた。
caturdaśasahasrāṇi yāni dṛṣṭani bhārata|
rathānām ayutaṃ caiva trisahasrāś ca dantinaḥ|| // 8-48-49 //
（49）バーラタよ、一万四千の戦車、そして三千の象が見られた――それらも倒された。
tataḥ saṃśaptakā bhūyaḥ parivavrur dhanañjayam|
martavyamiti niścitya jayaṃ vā api anivartanam|| // 8-48-50 //
（50）そしてサンシャプタカ族は再びアルジュナを取り囲んだ。「死ぬか、勝って帰らぬか」と決意して。
tatra yuddhaṃ mahat ca āsīt tāvakānāṃ viśāmpate|
śūreṇa balinā sārdhaṃ pāṇḍavena kirīṭinā|
jitvā tān nyahanat pārthaḥ śatrūñ śakra iva asurān|| || // 8-48-51 //
（51）国王よ、そこで大きな戦いが起きた。勇者で強者のパーンダヴァ・王冠のアルジュナと、あなた方の勇者たちとの間で。そして勝利を収めたアルジュナは敵を討った。インドラがアスラたちを討つように。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe aṣṭacatvāriṃśo'dhyāyaḥ|| 48 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十八章は終わる。
