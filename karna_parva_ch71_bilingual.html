マハーバーラタ ― カルナ篇 第71章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 71 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ71」、全34詩節からなります。カルナが無事であると知って怒ったユダーマンユがアルジュナを激しく非難する場面（第1〜34詩節）で本章は終わります。ガーンディーヴァの弓をクリシュナに渡してクリシュナ自らカルナを殺すよう強要します。なお、本章のサンスクリット詩節番号は原典ファイル内では「8-73」として記録されていますが、章の見出しは「第71章（071）」となっています。日本語対訳では第2〜3詩節、第28〜29詩節が合わせて翻訳されています。
karṇaparva — ekasaptatitamo'dhyāyaḥ (71)
第71章　カルナが無事と知り怒ったユディシュティラによるアルジュナへの非難とガーンディーヴァ譲渡の強要
sañjaya uvāca|
vaikartanaṃ kuśalinaṃ niśamya kruddhaḥ pārthaḥ phalgūnasyāmitaujāḥ|
dhanañjayaṃ vākyamuvāca rājā yudhiṣṭhiraḥ karṇaśarābhitaptaḥ||
// 8-71-1 //
サンジャヤは語った。
imāṃ ca vasatiṃ hitvā bhayātkarṇena phalguna|
ahaṃ ca bhīmasenaś ca mādrīputrau ca pāṇḍavau||
vāsudevena sahitā vayaṃ karṇena nirjitāḥ|
punareva vanaṃ gatvā tapaścaryāṃ ca kurmahe|
athavā dhārtarāṣṭrāṇāṃ paricaryāṃ carāmahe||
// 8-71-2-3 //
「この陣地を恐れから捨てて、アルジュナよ、私もビーマセーナも、マードリーの二人の息子も、ヴァースデーヴァ（クリシュナ）と共に——我々はカルナに敗れた。再び森に行って苦行をするか、あるいはドリタラーシュトラの息子たちに仕えるか。」
ityevamuktvā bībhatsuṃ roṣātsaṃraktalocanaḥ|
abravītpunarevātra dharmarājo yudhiṣṭhiraḥ||
// 8-71-4 //
ビーバツ（アルジュナ）にこう言って、怒りに赤い目をしたダルマラージャ・ユディシュティラはさらに言った。
idaṃ yadi dvaitavane tu sūktaṃ karṇaṃ niyoddhuṃ na sahe nṛpeti|
vayaṃ tataḥ prāptakālaṃ yathāvat kṛtvā'bhyupekṣāma tathaiva rājyam||
// 8-71-5 //
「もしドヴァイタ湖の森で『カルナとは戦えない、私は王として無力だ』とお前が言ったなら、我々はその時に適切な措置を取り、王国を諦めたであろうに。」
mayi pratiśrutya vadhaṃ hi tasya balasya cārdhasya tathaiva yuddhe|
ānīya māṃ śatrumadhye sa kasmāt samunnāmya sthaṇḍile pratyapiṃṣṭhāḥ||
// 8-71-6 //
「あの者の殺害と、その軍の半分の殺害を戦場で私に約束し、私を敵の中に連れ込んでおきながら、お前は私を高く持ち上げてから地面に叩きつけたのだ。」
anvāsya satyena yadāttha pārtha satyaṃ śapanvāsudevena sārdham|
tannaḥ satyamaphalaṃ hy akārṣīḥ phalasya kāle cācchinnaḥ puṣpavṛkṣam||
// 8-71-7 //
「ヴァースデーヴァと共に真実を誓い、我々に従って約束したこと、それをお前は実りなきものにした。実を結ぶ時に花の咲く木を切り倒したのだ。」
pracchāditastvaṃ bāliśa duryaśobhir anarthavākyo'syarjuna naiva sādhuḥ|
tyaktvā bhīmaṃ sarvabhīmeṣu bhīmaṃ saṃyojitastvaṃ sūtaputraṃ nihantum||
// 8-71-8 //
「お前は偽りに覆われた、愚かで不名誉な者だ。無意味な言葉を吐く者よ、アルジュナよ、お前は善人ではない。全てに恐ろしいビーマを捨てて、お前はスータの子を殺すために送り出されたのに。」
yattadvṛthā vāguvācāntarikṣe saptāhni jāte tvayi mandabuddhau|
apāpīyānvāsavātkuntijāto bahūnsaṅgrāmānayameva jetā||
// 8-71-9 //
「あの時、お前が愚かにも生まれて七日目に、虚空の声がこう言ったではないか——『クンティーから生まれたこの者はヴァーサヴァ（インドラ）より優れ、多くの戦いにおいてこの者こそが勝者である』と。」
ayaṃ jetā pāṇḍavo devasaṅghān sarvāṇi bhūtānyapi cottamaujāḥ|
ayaṃ jetā madrakaliṅgajātān daityāṃś ca rakṣāṃsi samāgatāni||
// 8-71-10 //
「『このパーンダヴァは神々の群れをも、全ての生き物をも征服するだろう、最上の力を持って。マドラ・カリンガの者たち、ダイティヤたち、集まったラークシャサたちをも征服するだろう。』」
bhūmiṃ ca sarvāṃ nikhilena jetā kurūṃś ca jetā svagaṇāṃś ca jetā|
asmāt paro no bhavitā dhanurdharo naiṣyanna bhūtaḥ kaścidenaṃ vijetā||
// 8-71-11 //
「『大地の全てを余すところなく征服し、クル族を征服し、自らの一族をも征服するだろう。彼より優れた弓持ちは将来にも生まれず、過去にも存在せず、誰も彼を征服することはない。』」
icchannayaṃ sarvabhūtāni kuryād vaśī vaśe sarvasamāptavidyaḥ|
kāntyā śaśāṅkasya javena vāyoḥ syairyeṇa meroḥ kṣamayā pṛthivyāḥ||
// 8-71-12 //
「『この者は望めば全ての生き物を意のままにできる。全ての学問を修めた者として——月の輝き、風の速さ、メール山の不動、大地の忍耐を持ち——』」
agneś ca tāpe dhanadasya lakṣmyā śauryeṇa śakrasya jayena viṣṇoḥ|
tulyo mahātmā tava kunti putro jāto 'diter viṣṇur ivāmitaujāḥ||
// 8-71-13 //
「『火の熱、クベーラの富、インドラの武勇、ヴィシュヌの勝利に等しい——お前の偉大な息子はクンティーよ、アディティから生まれたヴィシュヌのように計り知れない力を持つ。』」
sveṣāṃ jayāya dviṣatāṃ vadhāya jāto mahātmā tava nandikartā|
ityantarikṣe śataśṛṅgamūrdhni tapasvināṃ śṛṇvatāṃ vāguvāca||
// 8-71-14 //
「『自らの者たちの勝利と、敵の殲滅のために生まれた偉大な者、お前に喜びをもたらす者だ。』——百峰山の頂で、苦行者たちが聞く中で、虚空の声はこう言った。」
evaṃvidhas tvaṃ na ca bhūtas tathādya devāś ca nūnam anṛtaṃ vadanti||
// 8-71-15 //
「そのようなお前が、しかし今日その通りではない。神々もきっと嘘を言うのだろう。」
tathā pareṣāmṛṣisattamānāṃ śrutvā giraḥ pūjayatāṃ sadā tvām|
na sannatiṃ yāmi suyodhanasya na tvāṃ jānāmyādhiratherbhayārtam||
// 8-71-16 //
「聖仙たちの中の最上の者たちが、常にお前を称える言葉を聞いても、私はスヨーダナ（ドゥルヨーダナ）に屈服しない。お前がアディラタの子（カルナ）に怯えているとは思わなかった。」
tvaṣṭrā kṛtaṃ vāhamakūjanākṣaṃ śubhaṃ samāsthāya kapidhvajaṃ tam|
khaṅgaṃ gṛhītvā hemacitrāvanadvaṃ dhanurvaraṃ gāṇḍivaṃ tālamātram|
tvaṃ vāsudevenohyamānaḥ kathaṃ nu karṇādbhīto vyapayāto'si pārtha||
// 8-71-17 //
「トヴァシュトリ神が作った、軸の軋まない見事な猿の旗を掲げた戦車に乗り、黄金で飾られた剣と、椰子の幹ほどの最上の弓ガーンディーヴァを手に——ヴァースデーヴァに運ばれながら、なぜカルナから怯えて逃げたのだ、アルジュナよ。」
pūrvaṃ yaduktaṃ hi suyodhanena na phalgunaḥ pramukhe sthāsyatīti|
karṇasya yuddhe hi mahābalasya maurkhyāttu tannāvabuddhaṃ mayā'sīt||
// 8-71-18 //
「かつてスヨーダナが言ったことは——『アルジュナは正面に立てないだろう、大力のカルナとの戦いにおいて。』——愚かにも私はそれを理解しなかった。」
tenādya tapsye bhṛśamaprameyaṃ yanmitravargo narakaṃ praviṣṭaḥ|
tadaiva vācyo'smi nanu tvayā'haṃ na yotsye'haṃ sūtaputraṃ kathañcit||
// 8-71-19 //
「そのために今日、私は計り知れない苦しみを味わう。味方の一団が地獄に落ちたのだから。あの時お前は私にこう言うべきだった——『私はスータの子とは決して戦わない』と。」
tato nāhaṃ sṛñjayān kekayāṃś ca samānayeyaṃ suhṛdo raṇāya||
// 8-71-20 //
「そうすれば、私はスリンジャヤ族やケーカヤ族を、味方たちを戦いのために集めなかったものを。」
evaṃ gate kiṃ ca mayā 'dya śakyaṃ kāryaṃ kartuṃ nigrahe sūtajasya|
tathaiva rājñaś ca suyodhanasya ye vāpi māṃ yoddhukāmāḥ sametāḥ||
// 8-71-21 //
「このような状況で、今日私にスータの子を制圧するために何ができよう。スヨーダナ王に対しても、私と戦おうと集まった者たちに対しても。」
dhigastu majjīvitamadya kṛṣṇa yo'haṃ vaśaṃ sūtaputrasya yātaḥ|
madhye kurūṇāṃ samuyodhanānāṃ ye cāpyanye yoddhukāmāḥ sametāḥ||
// 8-71-22 //
「クリシュナよ、呪われよ、今日の我が命は。私はスータの子の支配下に入った。クル族の中のスヨーダナの味方たち、戦おうと集まった者たちの中で。」
ekaḥ sa me bhīmaseno'dyaṃ nātho yenābhipanno'smi raṇe mahābhaye|
vimocya māṃ cāpi rupānvitastataḥ śareṇa tīkṣṇena bibheda karṇam||
// 8-71-23 //
「ただ一人ビーマセーナだけが今日の我が庇護者だ。大いなる恐怖の戦いで私が苦しめられた時に救い出し、怒りを込めた鋭い矢でカルナを射た。」
tyaktvā prāṇānsamare bhīmasenaś cakre yuddhaṃ kurumukhyaiḥ sametaiḥ|
gadāgrahasto rudhirokṣitāṅgaś caran raṇe kāla ivāntakāle||
// 8-71-24 //
「ビーマセーナは命を捨てて、クルの主たちの連合と戦った。棍棒を手に、血にまみれた体で、終末の死神のように戦場を駆け巡った。」
asau hi bhīmasya mahāninādo muhurmahuḥ śrūyate dhārtarāṣṭraiḥ|
yadi sma jīvetsamare nihantā mahārathānāṃ pravaro narottamaḥ||
// 8-71-25 //
「ビーマの大いなる咆哮が繰り返しドリタラーシュトラの軍に聞こえる。もし彼が生き延びれば——大戦車戦士の中の最上の人中の最上者が——殺し手となるだろう。」
tavābhimanyustanayo'dya pārtha na cāsmi gantā samare parābhavam|
athāpi jīvetsamare ghaṭotkacas tathā 'pi nāhaṃ samare parāṅyukhaḥ||
// 8-71-26 //
「アルジュナよ、お前の息子アビマンニュがいたなら、私は戦場で敗北を味わうことはなかった。あるいはガトートカチャが戦場で生きていたなら、私は戦場で背を向けることはなかったのだ。」
bhīmasya putraḥ samarāgrayāyī mahāstravinnāpi tavānurūpaḥ|
yaṃ taṃ xxxsādya riporvalaṃ no nimīlitākṣaṃ bhayaviplutaṃ bhavet||
// 8-71-27 //
「ビーマの息子、戦場の先頭に立つ大いなる武器の使い手も、お前にはふさわしくない。彼が敵の軍に突入すれば、目を閉じて恐怖に取り乱すだろうに。」
xxxxxniśi yuddham ekasty aksā raṇaṃ yatva bhayādravante||
sa cetsamāsādya mahānubhāvaḥ karṇaṃ raṇe bāṇagaṇaiḥ pramohyaḥ|
dhairye sthitenāpi ca sūtajena śakyā hato vāsavadattayā tayā||
// 8-71-28-29 //
「夜戦を一人で戦い、お前が恐れて逃げた時——もしあの偉大な者がカルナに遭遇して、矢の群れで惑わせるなら、堅固に構えるスータの子も、ヴァーサヴァ（インドラ）から授かったあの槍で殺されたかもしれないのに。」
mamaiva bhāgyāni purā kṛtāni pāpāni nūnaṃ phalavanti yuddhe|
tṛṇaṃ ca kṛtvā samare bhavantaṃ tato 'hamevaṃ nikṛto durātmanā|
vaikartanenaiva tathā kṛto'haṃ yathā hy aśaktaḥ kriyate tvabāndhavaḥ||
// 8-71-30 //
「私のかつて作った罪悪の宿業が、きっと戦場で実を結んでいるのだろう。戦場でお前を藁のように扱い——邪悪なヴァイカルタナに私はこのように蔑まれた。力なき親族なき者のように扱われたのだ。」
āpadgrataṃ yaś ca naro vimokṣayet sa bāndhavaḥ snehayutaḥ suhṛc ca|
evaṃ purāṇā ṛṣayo vadanti dharmaḥ sadā sadbhir anuṣṭhitaś ca||
// 8-71-31 //
「災難に陥った者を救い出す者こそが、親族であり、愛情ある友人である。古の聖仙たちはこう言い、善人たちは常にこの法を実践してきた。」
khaṅgaṃ vibhrajjātarūpatsaruṃ ca dhanurvedaṃ gāṇḍivaṃ tālamātram|
sa keśavenohyamānaḥ kathaṃ nu karṇātpārthastvamapaituṃ samaiṣīḥ||
// 8-71-32 //
「黄金の柄の剣と、椰子の幹ほどのガーンディーヴァという弓の学問を持ち——ケーシャヴァ（クリシュナ）に運ばれながら、なぜカルナから逃げようと思ったのだ、アルジュナよ。」
sa gāṇḍīvaṃ keśavāya pradāya yantā bhavestvaṃ yadi keśavasya|
tatastaretkeśavaḥ karṇamugraṃ marutsasvo vṛtramivāttavajraḥ||
// 8-71-33 //
「ガーンディーヴァをケーシャヴァに渡し、お前がケーシャヴァの御者となるがよい。そうすればケーシャヴァは恐ろしいカルナを打ち倒すだろう——マルト神を伴うインドラが金剛杵でヴリトラを倒したように。」
māse'patiṣyo yadi pañcame tvaṃ na vā garbho yadyabhavaḥ pṛthāyāḥ|
mattaḥ śreyān rājaputro 'bhaviṣyanna te yaśaḥ phalguna ityapeyāt||
// 8-71-34 //
「もしお前が五ヶ月目に流産していたなら、あるいはプリターの胎内に宿らなかったなら——私にとって王子の方がましだったろう。お前の名声は『アルジュナ』として去ることもなかったろうに。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekasaptatitamo'dhyāyaḥ|| 71 ||
