एकोनविंशः सर्गः

第十九章　一騎討ち
Metre: Anuṣṭubh (Śloka) — V.1–120 — with Yamaka and Citrabandhana throughout
V.1
Sanskrit (IAST) athottasthe raṇāṭavyām asuhṛdveṇudāriṇā / nṛpāṅghripaughasaṃgharṣād agnivad veṇudāriṇā // 19.1 //
和訳

かくて、戦場という森において、敵という竹を裂く者によって、王という樹木の群れの摩擦から、火のごとく一騎討ちが起こった。

注

【Vallabhadeva】

veṇudārin は「竹を裂く者」で、森の竹を裂く火と敵を倒す戦士の両義。raṇāṭavī は「戦場の森」という upamita-samāsa。nṛpa-aṅghripa は「王という樹木」。森で樹木の摩擦から火が生じるように、王たちの衝突から一騎討ちが生じたという。

【Mallinātha】

本章は anuṣṭubh 韻律で、一偈おきに yamaka 等の śabdālaṅkāra と arthālaṅkāra が交互する。veṇudāriṇā が両半偈末に繰り返される samapādānta yamaka。raṇāṭavī は upamita-samāsa（abhivaditi taddhitaupasya liṅgāt）。taddhi-gatā pūrṇopamā と samāsa-gata-upamā の saṅkara。

V.2
Sanskrit (IAST) āpatantam amuṃ dūrād ūrīkṛtaparākramaḥ / balo 'valokayāmāsa mātaṅgam iva kesarī // 19.2 //
和訳

武勇を引き受けたバラデーヴァは、遠くから突進してくるかの者を、象に向かう獅子のごとく見据えた。

注

【Vallabhadeva】

bala はバラデーヴァ（ハラダラ）。ūrīkṛtaparākrama は「武勇を受け入れた」。獅子が象を見据えるように、という upamā。

【Mallinātha】

amu は先の veṇudārin を指す。ūrīkṛtaparākrama は「武勇を受容した」。バラデーヴァが獅子のごとく敵を見据えるという upamā で、両者の力量差を暗示する vastudhvani。

V.3
Sanskrit (IAST) jajaujojājijijjājī taṃ tato 'titatātitut / bhābho 'bhībhābhibhūbhābhūr ārārir arirīraraḥ // 19.3 //
和訳

戦士の力から生じた戦いに勝ち、勇猛に戦い、強敵をも圧する者、畏れ知らぬ象の威光を凌ぐ輝きの座たる者、戦車の群れに突撃の力を与える者――かの敵バラデーヴァは、彼に向かって出撃した。

注

【Vallabhadeva】

全偈が一音節の繰り返しからなる ekākṣarapāda（一音節詩脚）。jaj は「戦う」。oja は「力」。ābha は「星の輝き」。aririn は「車輪」。各語の分解は極めて複雑で、全体としてバラデーヴァの武威を讃える。

【Mallinātha】

bhinnaikākṣarapāda と称される anuprāsa の一種。各 pāda が一つの子音の反復からなる（ja, ta, bha, ra）。ari はバラデーヴァを指す。語の分解：jajaujojājijijjājī = 戦士の力から生じた戦いに勝つ勇者。atitatātitut = 強敵の苦痛をも圧する者。ābha-upamā と anuprāsa の saṅkara。

V.4
Sanskrit (IAST) bhavan bhayāya lokānām ākampitamahītalaḥ / nirghāta iva nirghoṣabhīmas tasyāpatad rathaḥ // 19.4 //
和訳

人々に恐怖をもたらし、大地を震わせ、轟音をもって恐るべき彼の戦車は、まるで雷撃のように突進した。

注

【Vallabhadeva】

nirghāta は「雷撃・落雷」。戦車もまた人を恐れさせ地を震わせ大音響を発する、という三点で雷撃に似るという upamā。

【Mallinātha】

bhavan bhayāya の第四格は kṛpi saṃpadyamāne ca の規則による。nirghāta iva は śrautī pūrṇopamā（明示的な完全比喩）。

V.5
Sanskrit (IAST) rāme ripuḥ śarān ājimaheṣvāsa vicakṣaṇe / kopād athainaṃ śitayā maheṣvā sa vicakṣaṇe // 19.5 //
和訳

敵は、戦の祝祭に巧みなるラーマに矢を放った。すると彼ラーマは怒りをもって、鋭い大矢でその敵を射殺した。

注

【Vallabhadeva】

rāma はバラデーヴァ（ハラダラ）。ājimaheṣvāsa は ājim（戦い）を maheṣvāsa（祭典の歓喜）と読む rūpaka。vicakṣaṇa は「巧みな」と「殺した」（kṣaṇ = hiṃsā の liṭ）の両義で yamaka。

【Mallinātha】

vicakṣaṇe は前半では形容詞「巧みな」、後半では kṣaṇ hiṃsāyām の liṭ で「殺した」。abhinna-samapāda-yamaka（同音異義の pāda 末反復）。

V.6
Sanskrit (IAST) diśam arkam ivāvācīṃ mūrcchāgatam apāvahат / mandapratāpaṃ taṃ sūtaḥ śīghram āji vihāyasaḥ // 19.6 //
和訳

御者は、失神し威光の衰えたその者を、南方へ向かう冬至の太陽のごとく、戦場から空を通って素早く連れ去った。

注

【Vallabhadeva】

avācī は「南方」。冬至の太陽が南方へ去り光が弱まるように、気絶した敵を御者が戦場から素早く運び去ったという。sūta は「御者」と太陽の御者アルナの両義。

【Mallinātha】

mandapratāpa は「威光の弱い」で、冬至の太陽と失神した戦士の双方に適用される。ājirvihāyasaḥ は upamita-samāsa で「戦場＝空」。rūpaka-upamā-śleṣa の saṅkara。

V.7
Sanskrit (IAST) kṛtvā śineḥ śālvacamūṃ saprabhāvā camūrjitām / sasarja vaktraiḥ phullābjasaprabhā vācam ūrjitām // 19.7 //
和訳

シニの末裔サーティヤキの威力ある軍勢は、シャールヴァの軍を打ち破り、満開の蓮華のごとき輝きを放つ顔で、力強い言葉を発した。

注

【Vallabhadeva】

śini はサーティヤキの祖父。śālva はチェーディ方の王。camūrjitā は camūṃ jitāṃ kṛtvā の意。勝利の喜びで顔が蓮華のように輝き、力強い言葉（勝鬨）を発したという。

【Mallinātha】

saprabhāvā は「威力ある」。phullābjasaprabhā は「満開の蓮華と等しい輝きの」。ūrjitāṃ vācaṃ sasarja は「力強い言葉を発した」すなわち勝鬨を上げた。upamā と yamaka の saṃsṛṣṭi。

V.8
Sanskrit (IAST) ulmukena drumaṃ prāpya saṃkucatpatrasaṃpadam / tejaḥ prakiratā dikṣu sapratāpam adīpyata // 19.8 //
和訳

ウルムカは、ドゥルマという王に迫ると、その軍勢は萎縮し、四方に威光を撒き散らしながら、烈しき勢いで輝いた。

注

【Vallabhadeva】

ulmuka は「燃えさし」と王名の両義。druma は「樹木」と王名の両義。patrasaṃpad は「葉の繁り」と「軍勢」。燃えさしが樹に触れて葉を枯らし四方に火花を散らすように、ウルムカ王がドゥルマ王を破ったという。

【Mallinātha】

abhidhāyāḥ prakṛtārthe niyamād（表面の語義が本来の意味に定まるため）、prakṛtārthaの dhvani であり、śleṣa ではないと言う。saṃkucatpatrasaṃpada は「軍の力が縮む」と「葉が萎れる」の両義。

V.9
Sanskrit (IAST) pṛthor adhyakṣipad rukṃī yayā cāpam udāyudhaḥ / tayaiva vācāpagamaṃ yayācāpam udāyudhaḥ // 19.9 //
和訳

ルクミンは武器を振り上げ、ある言葉でプリトゥの弓を罵った。だがまさにその同じ言葉で、意気消沈し、戦いからの退却を請うた。

注

【Vallabhadeva】

rukmin はルクミニーの兄弟。pṛthu はクリシュナの息子。adhyakṣipat は adhi-kṣip（非難する）の liṭ。apamudā は「歓びを失った」。cāpam は前半で「弓」、後半で「言葉の低さ」。

【Mallinātha】

前半の yayā cāpam は「ある言葉で弓を（非難した）」、後半の yayācāpam udāyudhaḥ は yayāca + apam-udā + āyudhaḥ で「無気力な武器を持って退却を請うた」。yamaka。

V.10
Sanskrit (IAST) samaṃ samantato rājñām āpatantīr anīkinīḥ / kārṣṇiḥ pratyagrahīd ekaḥ sārasvān iva nimnagāḥ // 19.10 //
和訳

クリシュナの子プラデュムナは、ただ一人で、四方から一斉に押し寄せる諸王の軍勢を、大海が河川を受け止めるかのごとく迎え撃った。

注

【Vallabhadeva】

kārṣṇi は「クリシュナの息子」すなわちプラデュムナ（at-iñ 接辞）。sārasvān は「海」。nimnagā は「河」。一人で多くの軍勢を受け止める力量を海の比喩で示す upamā。

【Mallinātha】

kārṣṇi はプラデュムナ。nimnagā は「低い所を流れるもの」すなわち河。samam は「同時に」。ekaḥ は「ただ一人で、味方なく」。upamā。

V.11
Sanskrit (IAST) dadhānair ghanasādṛśyaṃ lasad āyasadaṃśanaiḥ / tatra kāñcanasacchāyā sasṛje taiḥ śarāśaniḥ // 19.11 //
和訳

輝く鉄の鎧を纏い雨雲のごとき姿をした敵兵たちに向けて、彼は黄金色の矢の稲妻を放った。

注

【Vallabhadeva】

鉄の鎧を着た敵兵が雲に喩えられ、金色の矢が稲妻に喩えられるという rūpaka。śarāśani は「矢という稲妻」。

【Mallinātha】

daṃśana は「鎧」（Amara: tanutram varma daṃśanam）。ghanasādṛśya は黒い鎧が雲に似ること。kāñcanasacchāyā は「黄金の輝きを持つ」。upamā-rūpaka の saṃsṛṣṭi。唇音（oṣṭhyavarṇa）を全く含まない citra の一種。

V.12
Sanskrit (IAST) nakhāṃśumañjarīkīrṇam asau tarur ivoccakaiḥ / babhau bibhrad dhanuḥśākhām adhirūḍhaśilīmukhām // 19.12 //
和訳

爪の光が花房のように溢れ、矢が蜂のように止まった弓の枝を携えるプラデュムナは、まるで高くそびえる樹木のように輝いた。

注

【Vallabhadeva】

śilīmukha は「矢」と「蜂」の両義（Amara: alibāṇau śilīmukhau）。dhanuḥśākhā は「弓という枝」。爪の光が花房、矢が蜂、弓が枝で、全体が樹木に喩えられる。

【Mallinātha】

tarur iva の liṅga からすべてが upamita-samāsa。śilīmukha に基づく śliṣṭa-viśeṣaṇa の upamā。

V.13
Sanskrit (IAST) prāpya bhīmam asau janyaṃ saujanyaṃ dadhad ānate / vidhyan mumoca na ripūn aripūgāntakaḥ śaraiḥ // 19.13 //
和訳

敵の群れの殺戮者たるプラデュムナは、恐るべき戦いに臨み、頭を下げる者には温情を示して放免した。だが矢で射ちつつ、傲慢な敵は決して放さなかった。

注

【Vallabhadeva】

ānata は「礼をする者」。saujanya は「温情」。mumoca na は「放さなかった」、すなわち敵を逃さなかった。ānate のみ saujanya を示すという対比。antākṣara の yamaka。

【Mallinātha】

aripūgāntaka は「敵の群れの殺戮者」。na mumoca は「放さなかった」。ānate（恭しい者に対して）saujanya（温情）を示す、という śloka の構造。saṃdaṃśa-yamaka。

V.14
Sanskrit (IAST) kṛtasya sarvakṣitipair vijayāśaṃsayā puraḥ / anekasya cakārāsau bāṇair bāṇasya khaṇḍanam // 19.14 //
和訳

すべての王たちが勝利を期して先陣に立たせた、多くの仲間を持つバーナースラの矢を、プラデュムナは自らの矢で粉砕した。

注

【Vallabhadeva】

bāṇa は「矢」と「バーナースラ（魔王の名）」の両義。khaṇḍana は「破壊」。矢で矢を断つ技量と、バーナースラを打ち破るという二重の意味。vakrokti（曲言）。

【Mallinātha】

bāṇa の二重義で kevala-prakṛta の śleṣa。aneka は「多くの従者を持つ」とバーナースラの千本腕を暗示する。

V.15
Sanskrit (IAST) yā babhāra kṛtānekamāyā senā sasāratām / dhanuḥ sa karṣan rahitam āyāsenāsasāra tām // 19.15 //
和訳

多くの策略を弄した敵の軍勢が素直さを見せたのは、彼が弓を引きつつ、苦もなくその軍に迫ったからであった。

注

【Vallabhadeva】

kṛtānekamāyā は「多くの幻術を用いた」。sasāratā は「素直さ」すなわち降伏。āyāsena rahitam は「苦労なく」。弓を引きながら難なく敵軍に迫り、策略好きの軍が素直に降伏したという。

【Mallinātha】

yamaka 構造。sasāratā は sāra-vattvā（堅実さ）を持った、の意。māyā-senā は「幻術の軍」。āyāsena は「労苦により」、それが rahita（欠く）で「苦もなく」。

V.16
Sanskrit (IAST) ojo mahaujāḥ kṛtvādhas tatkṣaṇād uttamaujasaḥ / kurvann ājāv amukhyatvam anayan nāma mukhyatām // 19.16 //
和訳

大いなる力を持つプラデュムナは、ウッタマウジャスの精気を瞬時に圧倒し、戦場でその者の名を無意味にすると同時に、自らの名「最も力ある者」の意味を真実のものとした。

注

【Vallabhadeva】

uttamaujas はドルパダの子の名で「最上の力」の意。プラデュムナ（mahaujas「大いなる力」）がウッタマウジャスを圧倒し、その名を空虚にしたという arthāntaranyāsa的機知。

【Mallinātha】

ojo adhaḥ kṛtvā は「力を圧し下げて」。amukhyatva は「非主要性」と「名前の無意味さ」の両義。プラデュムナの名 pradyumna は「最も力ある」（prakṛṣṭaṃ bhujaṃ balaṃ yasya）の意。

V.17
Sanskrit (IAST) dūrād eva camūr bhallaiḥ kumāro hanti sa sma yāḥ / na punaḥ sāṃyugīṃ tāḥ sma kumāro hanti sasmayāḥ // 19.17 //
和訳

あのクマーラ（プラデュムナ）は遠方からでも矢で軍勢を討ち果たした。誇り高きその軍勢が再び戦場に戻ることは、もはやなかった。

注

【Vallabhadeva】

kumāra はプラデュムナまたはプリトゥ。bhalla は矢の一種。sasmayāḥ は「誇り高き」。na ārohantiは「戻らなかった」（死んだか逃げたため）。

【Mallinātha】

sāṃyugī kū は「戦場なる大地」（ku = 大地、Amara: gotrā kuḥ pṛthivī）。yamaka。dūrād eva は遠距離からでも、の意。

V.18
Sanskrit (IAST) nipīḍya tarasā tena muktāḥ kāmam anāsthayā / upāyayur vilakṣatvaṃ dviṣo na śilīmukhāḥ // 19.18 //
和訳

プラデュムナに力で圧され、無造作に放たれた敵たちは恥辱に至った。だが矢は的を外すということがなかった。

注

【Vallabhadeva】

vilakṣatva は敵にとって「恥辱」、矢にとって「的を失うこと」。dviṣaḥ は敵、śilīmukhāḥ は矢。敵は恥辱を受けたが矢は一本も外れなかったという vyatireka。

【Mallinātha】

vilakṣatva は「恥を受ける」と「的から外れる」の二義（Amara: vilakṣas tu trapānvite）。dviṣaḥ と śilīmukhāḥ の対比による vyatireka。両者とも prakṛta であるため tulyayogitā-upamyāśrita の saṅkara。

V.19
Sanskrit (IAST) tasyāvadānaiḥ samare sahasā romaharṣibhiḥ / surair aśaṃsi vyomasthaiḥ saha sāro maharṣibhiḥ // 19.19 //
和訳

戦場におけるプラデュムナの身の毛もよだつ武勲によって、空に在る神々と大聖仙たちは、その力を称えた。

注

【Vallabhadeva】

avadāna は「武勲」。romaharṣin は「身の毛がよだつような」。sāra は「力・本質」。aśaṃsi は śaṃs の受動態 luṅ で「称えられた」。

【Mallinātha】

avadāna は「偉業」。vyomasthaiḥ saha maharṣibhiḥ は「空にいる聖仙たちと共に」。aśaṃsi は śaṃsita（称えられた）の意。

V.20
Sanskrit (IAST) sugandhayaddiśaḥ śubhram amlāni kusumaṃ divaḥ / bhūri tatrāpatat tasmād utpapāta divaṃ yaśaḥ // 19.20 //
和訳

天から白く芳しく萎れぬ花々がプラデュムナの上に豊かに降り注いだ。そしてそこから彼の名声が天へと昇った。

注

【Vallabhadeva】

神々が花を降らせるのは武勲を認めた証。śubhra は「白い」。amlāna は「萎れない」。名声もまた芳しく白く永遠であるという parivṛtti-śleṣa の saṅkara。

【Mallinātha】

sugandhayaddiśaḥ は「四方を芳しくする」（sugandha + ṇyanta の luṭ śatr-ādeśa）。花が天から降り名声が天に昇るという対比は anyonyālaṅkāra（parasparaṃ kriyājanane 'nyonyam の規則）。

V.21
Sanskrit (IAST) soḍhuṃ tasya dviṣo nālam apayodharavā raṇam / ūrṇunāva yaśaś ca dyām apayodharavāraṇam // 19.21 //
和訳

雄叫びを失った敵たちはプラデュムナの戦いに耐えられなかった。そして彼の名声は、雲の障壁すらない天を覆い尽くした。

注

【Vallabhadeva】

apayodharava は「叫び声を失った」（恐怖で沈黙した敵）。apayodharavāraṇa は「雲による遮りがない」。名声が雲をも突き抜けて天を覆った、という。

【Mallinātha】

ūrṇunāva は ūrṇu（覆う）の liṭ。apayodharavāraṇam は「雲の障壁がない」すなわち雲の層をも突き抜ける名声。yamaka と vākyārtha-hetuka-kāvyaliṅga の saṃsṛṣṭi。

V.22
Sanskrit (IAST) keśapracuralokasya paryaskāri vikāsinā / śekhareṇeva yuddhasya śiraḥ kusumalakṣmaṇā // 19.22 //
和訳

クスマラクシュマン（花の印を持つ者、プラデュムナの別名）は、多くの戦士が満ちる戦いの先頭を、あたかも髪が豊かな者の頭を冠で飾るように輝かせた。

注

【Vallabhadeva】

V.23
Sanskrit (IAST) sādaraṃ yudhyamānāpi tenānyanarasādaram / sā daraṃ pṛtanā ninye hīyamānā rasādaram // 19.23 //
和訳

【Vallabhadeva】

sādaram は「熱心に」。anyanarasādara は「他の者たちにも無力を与える」。dara は「恐怖」（Amara: daro 'striyāṃ bhaye）。rasāt は「戦への執着から」引き離されるの意。hīyamānā は「退けられる」。

virodha-ābhāsa（見かけの矛盾）：熱心に戦いながらも恐怖に至る。yamaka と virodha-ābhāsa の saṃsṛṣṭi。

V.24

【Vallabhadeva】

krudhā は「怒りの女神」（Krudh, プラデュムナに帰依していた女性が、勝利の女神に嫉妬して去り、チェーディ王の許へ）。恋する女が恋敵の気配を嫌って直ちに他の男の許へ走るという比喩的表現。

V.25

和訳

sarvatobhadra（全方位吉祥）の citrabandha（図像詩）。Daṇḍin の定義：「全方位から読める反復が sarvatobhadra」。kāra は「力」（Viśva: kāro vadhe niścaye ca bale）。atiśayokti：馬の嘶きが軍楽に匹敵するという。

V.28
Sanskrit (IAST) lolāsikāliyakulā yamasyaiva svasā svayam / cikīrṣur ullasallohavarmaśyāmā sahāyatām // 19.28 //
和訳

【Vallabhadeva】

lolāsikā は「揺れる刀剣」。kāliyakula は「カーリヤ蛇の群れ」。lohavarma は「鉄の鎧」で黒さの原因。yamasyaiva svasā は utprekṣā で、軍をヤムナー河に喩える。

V.29
Sanskrit (IAST) sāsenāgamanārambhe rasenāsīd anāratā / tāranādajanāmatta dhīranāgamanāmayā // 19.29 //
和訳

注

【Vallabhadeva】

muraja-bandha（太鼓図）の citrabandha。5行9列の格子に配置される。rasena anāratā は「戦への情熱に倦むことなく」。tāranāda は「高い叫び声」。mattadhīranāga は「酔い勇猛な象」。

murajabandha（太鼓型図像詩）。tāranāda は「高い鬨の声」。anāratā は「倦むことのない」。mattadhīranāga は「酔った堅固な象」。rasena は「闘争心によって」。

V.30
Sanskrit (IAST) dhūtadhautāsayaḥ praṣṭhāḥ prātiṣṭhanta kṣamābhṛtām / śauryānurāganikaṣaḥ sā hi velānujīvinām // 19.30 //
和訳

王たちの先駆けの者たちは、刀を振り研ぎ澄まして出陣した。なぜなら、その時こそが武勲の志と主君への忠誠を試す試金石であったから。

注

praṣṭha は「先陣」（Amara: praṣṭho 'gragāmini, ṣṭutva による）。dhūta は「揺すられた」、dhauta は「磨かれた」。nikaṣa は「試金石」。戦場こそが従者の武勇と忠節を測る場であるという kāvyaliṅga。

V.31

和訳

注

【Vallabhadeva】

amala＝dhauta（研ぎ澄まされた）asilata（剣蔓）を携え（dadhāna）、alasa＝manda（緩い）pada（歩み）を置いた者はいない（ka）。yudhā（戦によって）diva（天界）へ gantum icchan（行こうと欲して）、komalāmalasaṃpadam は天界の形容。yamaka。

V.32

和訳

注

【Vallabhadeva】

sainika は軍に属する者（senāyāḥ pākṣika ṣṭak）。bāhuparigha は「腕という鉄棒」。jaṅghā は「脛・脚」（prasṛtā「進み行く」の意）。kṛtoruvega は「uru＝大いなる、または腿の vega を起こした」。yugapad（一斉に）itaretaram（互いに）vipakṣa（敵方）を vyajigīṣanta（征服せんとした）。tulyayogitā。

【Mallinātha】

bāhuparigha は「腕と鉄棒」、jaṅghā は「脛」。vipakṣa と sajūthīya（同陣営の者）の双方を bāhu と jaṅghā で征服しようとした（先を争って前衛に入ろうとする）。kṛtoruvega＝uru-mahān vega または ūrvoḥ vega。kevalaprakṛtāspadā tulyayogitā。

V.33
Sanskrit (IAST) vāhanājani mānāse sārājāvanamā tataḥ / mattasāragarājebhe bhārīhāvajjanadhvani // 19.33 //
和訳

そこで、敵の誇りを打ち砕く戦場において、屈せぬ軍勢が現れた。狂った力ある王象が闊歩し、重装の武者たちの戦意に満ちた鬨の声が轟いていた。

注

【Vallabhadeva】

sārāja は「優れた戦い」、vāhanā＝vāhinī（軍勢）、anamā＝不屈の（paca 類語尾による nañ 合成）。mānāsa は「誇りを投げ捨てさせる者」（mānam asyati）。mattasāragarājebha は「狂い力強い王象のいる」。bhārīhāvajjanadhvani は「重装にして戦意ある兵の声の轟く」。pratiloma で次の V.34 と対をなす。

【Mallinātha】

mānāse は mānam asyati（敵の慢心を砕く）。mattasāragarājebhe は「狂った（matta）、力ある（sāra-ga）、王象（rājebha）のいる（場）」。bhārīhāvajjanadhvani は「bhārin（重装の）、īhāvat（戦意ある）、jana（兵）の dhvani（声）がある」。vāhanā（軍勢）anamā（不屈の）ajani（出現した）。ślokapratilomayamaka で V.34 と対。

V.34
Sanskrit (IAST) nidhvanajjavahārībhā bheje rāgarasāttamaḥ / tatamānavajārāsā senā mānijanāhavā // 19.34 //
和訳

唸りつつ疾駆する魅惑の象を擁し、広大にして人の群れから喧噪の湧くその軍勢は、勇者たちの戦意に満ちた合戦の場であり、怒りの烈しさゆえに暗闇に没した。

注

【Vallabhadeva】

V.33 の逆読（ślokapratilomayamaka）。nidhvanajjavahārībhā は「唸る（nidhvanat）、速い（java）、魅惑的な（hārin）象（ibha）のいる」。rāgarasa は「怒りの情」、tamas（暗闇）を bheje（得た）。tatamānavajārāsā は「広がった（tata）、人の群（mānava-ja）の叫声（ārāsa）のある」。mānijanāhavā は「勇者たちの戦いのある」。

【Mallinātha】

V.33 を prātilomya（逆順）で読む ślokapratilomayamaka。Daṇḍin の定義を引く：「逆順による pāda・ardha・śloka の反復が pratilomayamaka」。nidhvanat（轟く）java（速い）hārin（美しい）ibha（象）を有する軍。rāgarasa（怒り＝rāga の rasa）から tamas（闇）を bheje（得た）＝怒りに目が眩んだ。

V.35
Sanskrit (IAST) abhagnavṛttāḥ prasabhād ākṛṣṭā yauvanoddhataiḥ / cakrandur uccakair muṣṭigrāhyamadhyā dhanurlatāḥ // 19.35 //
和訳

弦の曲がらぬ弓の蔓は、若さに昂る者たちに力まかせに引き絞られ、拳で握れるほどの細い腰を持ちながら、高々と叫び声をあげた。

注

【Vallabhadeva】

dhanurlatā（弓蔓）は掛詞で貞女をも暗示する samāsokti。abhagnavṛttā＝「折れぬ丸み」（弓の形）または「壊れぬ貞操」。muṣṭigrāhyamadhyā＝「拳で握れる中腰」。yauvanoddhataiḥ＝「若さに高ぶった者」。prasabhāt ākṛṣṭā＝「力ずくで引かれ」（弓を引く／女を引き寄せる）。cakranduḥ＝「叫んだ」（弓弦の音／女の泣き声）。

dhanurlatā（弓蔓）の描写が暗に dhūrtāskandita-pativratā（放蕩者に襲われた貞女）を表す samāsokti。abhagnavṛttā＝「折れぬ円弧」（弓）と「壊れぬ品行」（貞女）。uccakaiḥ＝「大声で」。ākṛṣṭā の viśeṣaṇagati による cakrandana の因を示す kāvyaliṅga と samāsokti の saṅkara。

V.36

kareṇu は雌象（Amara: kareṇur iyaṃ strī）。prāsthita は jātāv ekavacanam。kare（前肢＝鼻先）aṇu（微細な）śīkara（水飛沫）が jajñe（生じた）。janeḥ kaneḥ liṭ。象の群れの膨大さを vyañjanā で示す。yamaka。

V.37
Sanskrit (IAST) dhṛtapratyagraśṛṅgārarasarāgair api dvipaiḥ / saroṣasaṃbhramair babhre raudra eva raṇe rasaḥ // 19.37 //
和訳

【Vallabhadeva】

śṛṅgārarasa は掛詞。象が gairika（赭石）の rāga（色料）を帯びつつ、raudra rasa（戦慄の情）のみが babhre（保持された）。śṛṅgāra と raudra は本来相反する rasa だが、śṛṅgāra が gairika の意なので矛盾しない＝virodhābhāsa。

【Mallinātha】

dhṛtapratyagraśṛṅgārarasarāga は掛詞で「新鮮な śṛṅgāra rasa の rāga を帯びた」と「新たな sindūra（朱）の色彩を施された」。śṛṅgāra と raudra の virodha は言葉上のみで virodhābhāsa。Viśva 辞を引き śṛṅgāra の「象の化粧」の語義を示す。karmaṇi liṭ（babhre）。

V.38

和訳

注

pattiṣu（歩兵たちの）mānasaṃ prati（心に対し）bhayam（恐怖は）na tasthau（留まらなかった）。prāptamānasaṃpratipatti は「bhartṛtaḥ（主より）prāpta（得た）māna（名誉）と saṃpratipatti（恩寵）」。raṇaikasarga は「戦に唯一の utsāha（情熱）」（Vaijayantī: sarga は utsāha, niścaya の意）。

【Mallinātha】

patti は「歩兵」。mānasaṃpratipatti は pūjā-saumanasya（崇敬と慈しみ）。raṇaikasarga は niyatotsāha（確固たる戦意）。先の恩義を思う者たちは戦に fearless で進む（kāvyaliṅga）。Manu 引用で、戦場で逃げれば主の善行を奪うと示す。yamaka と kāvyaliṅga の saṃsṛṣṭi。

V.39

注

【Vallabhadeva】

raṇāṭavī（戦場という森）の sāvayava rūpaka。dhanviśākhin は「弓兵という樹木」。bāṇa＝ahi（矢＝蛇）、tūṇīra＝koṭara（矢筒＝洞穴）、godhā は「弓懸け」（tala）と「大蜥蜴」の掛詞でśliṣṭa rūpaka。bhujā＝śākhā（腕＝枝）。aṭavī も蛇と大蜥蜴のいる恐ろしい森として一貫する。

【Mallinātha】

raṇam eva aṭavī、samasta-vastu-varṇana による sāvayava rūpaka。bāṇa＝ahi（矢＝蛇, śliṣṭa rūpaka）、tūṇīra＝koṭara（矢筒＝洞）、dhanvin＝śākhin（弓兵＝樹木）。godhā は「弓懸け」と「大蜥蜴」の śliṣṭa rūpaka（Viśva: godhā tale nihākāyām）。bhujā＝śākhā（腕＝枝）。

V.40

和訳

V.41

和訳

注

【Vallabhadeva】

mahākāvyaṃ śiśupālavadha 等を指す。ādipada で murajabandha 等も含む。vyūha は balavinyāsa（Amara: vyūhas tu balavinyāse）。viṣama＝duravagāha（難攻）。nagar-ādivṛṇanayuktalakṣaṇa の mahākāvya の定義に触れ、Māgha 自身の作品への自己言及を示す。

V.44

V.45

gomūtrikācitrabandha。viṣāṇibhiḥ＝dantibhiḥ（象たち）。yudham āpya（戦を得て）vikasaddāna（盛大な mada＝発情液）を vavṛṣe（流した）。sādhane＝saṃgrāme（戦場）pravṛtte 'pi（始まっても）aviṣādibhiḥ（怯えぬ者ら）。vikasaddhvāna は「輝かしい jayārava（勝利の声）」。sādhane 'py aviṣādasya avirodha（矛盾なし）は virodhābhāsa。Vallabhadeva の varṇānām ekārūpatvaṃ の定義を引く。

V.53

padātayaḥ（歩兵たち）が pratipakṣam（敵を）kopāt（怒りから）dantaiḥ（歯で）cicchidire（噛み裂いた）。paranistriṃśanirlūnakaravālāḥ は「敵の剣で刀を断たれた者たち」。gajā iva は「象が牙（viṣāṇa＝danta）で敵を裂くように」。象も parakhaḍgacchinna-hastapucchā（敵の剣で鼻や尾を斬られた）後に danta で戦う。

【Mallinātha】

padātayaḥ は pattayaḥ（歩兵）。paranistriṃśa＝pareṣāṃ khaḍga で nirlūnakaravālāḥ＝chinnaKhaḍgāḥ（剣を断たれた者たち）。gajā iva は象が鼻を切られた後に viṣāṇa（牙＝danta）で戦う如し。yamaka。

V.56

和訳

注

【Vallabhadeva】

raṇe vikāsini（拡大する戦場で）na kaścid vipapāṭa（誰も逃げなかった＝palāyāṃ cakre）。rabhasena（勢いで）nirbhinnadvipā（象を貫いた者たち）の pāṭavikā（巧者たち）の asaya（剣）がある戦場。gatabhīḥ＝nirbhaya（恐れを離れた）ゆえにこそ逃げぬ。kāvyaliṅga と virodha の yamaka との結合。

【Mallinātha】

rabhasena（勢いで）nirbhinnadvipāḥ（象を貫き倒した者たち）、pāṭavikānāṃ pāṭavavattamāḥ（最も巧みな者たちの）asayaḥ（剣）のある vikāsini（拡大する）raṇe（戦場で）。gatabhīḥ（恐れなき）kaścid（誰も）na vipapāṭa（逃げなかった）。dvipadalana（象の殺戮）のある raṇe にも nirbhīka という virodha が pratipattipāṭhavayā（理解の巧みさで）解消される virodhābhāsa。kāvyaliṅga と yamaka の saṃsṛṣṭi。

V.58

V.59
Sanskrit (IAST) skhalantī na kvacit taikṣṇyād abhyagraphalaśālinī / amoci śaktiḥ śāktīkair lohajā na śarīrajā // 19.59 //
和訳

注

【Vallabhadeva】

śāktīkaiḥ（śakti を武器とする者たち）により lohajā（鉄製の）śakti（槍）が amoci（放たれた）。na śarīrajā（身体生まれの力ではない）。taikṣṇyāt（鋭さゆえ）na kvacit skhalantī（どこでも外れぬ）。abhyagraphalaśālinī は「abhyagra（近接の）phala（穂先）をもつ」と「abhyagra（目前の）phala（成果）を持つ」の掛詞。kevalaprakṛtaśleṣa。

【Mallinātha】

śāktīka は śakti を武器とする者（Amara: śāktīkaḥ śaktihētikaḥ, śaktiṣyaṣṭor īkak）。taikṣṇyāt（鋭さで）na kvacit skhalantī（決して阻まれぬ）。abhyagrena phālena（近接の穂先で）śālinī。lohajā（鉄製）śakti（槍）が amoci（放たれた）、na śarīrajā（体から生じる sāmarthya ではない）。両方とも prakṛta なので kevalaprakṛtaśleṣa。
