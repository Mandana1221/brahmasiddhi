karṇaparva — aṣṭamo'dhyāyaḥ (8)
第8章　カルナとアルジュナがそれぞれ陣形を組んで出撃する
dhṛtarāṣṭra uvāca|
saināpatyaṃ tu samprāpya karṇo vaikartanas tadā|
tathoktaśca svayaṃ rājñā snigdhaṃ bhrātṛsamaṃ vacaḥ||
hitaśca priyakāmaśca mama putrasya nityaśaḥ|
akarotkiṃ mahāprājñas tan mamācakṣva sañjaya|| // 8-8-1-2 //
ドリタラーシュトラは語った。 （1〜2）「総大将の位を得たヴァイカルタナ・カルナが、王自ら兄弟のように親しみを込めた言葉をかけられて、我が息子に常に忠実で利を望む偉大な知恵の者は、何をなしたのか、それを語ってくれ、サンジャヤよ。」
sañjaya uvāca|
karṇasya matamājñāya putrāste bharatarṣabha|
yogam ājñāpayāmāsur nanditūryapuraḥsaram||
mahatyapararātre ca tava sainyasya māriṣa|
yogo yoga iti hyāśu prādurāsīn mahāsvanaḥ|| // 8-8-3-4 //
サンジャヤは語った。 （3〜4）バーラタの雄牛よ、カルナの意を汲んで、おまえの息子たちは、喜びの楽器を先導として出陣の命を発しました。深夜に、おまえの軍勢から「出陣だ、出陣だ」という大きな声がすぐに響き渡りました。
kalpatāṃ nāgamukhyānāṃ rathānāṃ ca varuthinām|
sannahyatāṃ narāṇāṃ ca vājināṃ ca viśāmpate||
krośatāṃ caiva yodhānāṃ tvaritānāṃ parasparam|
babhūva tumulaḥ śabdo divaspṛksumahāṃstataḥ|| // 8-8-5-6 //
（5〜6）最上の象の支度、装甲された戦車の支度、兵士たちの武装、馬たちの支度、互いに急かし合う戦士たちの叫び——天に届くほどの大きな轟音が生じました、王よ。
tataḥ śvetapatākena balākāvarṇavājinā|
hemapṛṣṭhena dhanuṣā nāgakakṣeṇa ketunā||
tūṇīraśatapūrṇena sagadena varūthinā|
śataghnīkiṅkiṇīśaktiśūlatomaradhāriṇā||
kārmukair upapannena vimalādityavarcasā|
rathena abhipatākena sutaputro hyadṛśyata|| // 8-8-7-9 //
（7〜9）白い旗をなびかせ、サギの色の馬をつけ、黄金の背を持つ弓を備え、象の腹帯を旗印にした、百の矢筒を満たし、棍棒を備えた装甲の戦車は、シャタグニー（投擲兵器）や鈴やシャクティ槍やシューラ矛やトマラ投槍を備えていました。弓を備え、汚れなき太陽のような輝きを放つその戦車に旗をなびかせて、スータの息子の姿が見えました。
dhmāpayan vārijaṃ rājan hemajālavibhūṣintam|
vidhrunvāno mahaccāpaṃ kārtasvaravibhūṣitam|| // 8-8-10 //
（10）黄金の網で飾られた海から生まれた法螺貝を吹き鳴らし、黄金で飾られた大弓を振るいながら。
dṛṣṭvā karṇaṃ maheṣvāsaṃ rathasthaṃ rathināṃ varam|
bhānumantam ivodyantaṃ tamo ghnantaṃ durāsadam||
na bhīṣmavyasanaṃ kecinnāpi droṇasya māriṣa|
nānyeṣāṃ puruṣavyāghra menire tatra kauravāḥ|| // 8-8-11-12 //
（11〜12）偉大な弓の使い手カルナが戦車に立つ姿を見て——昇る太陽のように、闇を払う近づきがたい者として——カウラヴァたちは、ビーシュマの災厄もドローナの災厄も、王よ、他の勇者たちの災厄も何とも思わなかった。
tatastu tvarayan yodhāñ śaṅkhaśabdena māriṣa|
karṇo niṣkarṣayāmāsa kauravāṇāṃ mahadbalam||
vyūhaṃ vyūhya maheṣvāso makaraṃ śatrutāpanaḥ|
pratyudyayau tathā karṇaḥ pāṇḍavān vijigīṣayā|| // 8-8-13-14 //
（13〜14）法螺貝の音で戦士たちを急かし、王よ、カルナはカウラヴァの大軍を引き出しました。偉大な弓の使い手は、敵を苦しめるマカラ（鰐）の陣形を組み、パーンダヴァたちに勝利を求めて向かいました。
makarasya tu tuṇḍe vai karṇo rājan vyavasthitaḥ|
netrābhyāṃ śakuniḥ śūra ulūkaśca mahārathaḥ|| // 8-8-15 //
（15）マカラの嘴（くちばし）にカルナ自身が陣取り、両目にはシャクニとウルーカの偉大な戦車戦士が。
droṇaputrastu śirasi grīvāyāṃ sarvasodarāḥ|
madhye duryodhano rājā balena mahatā vṛtaḥ|| // 8-8-16 //
（16）頭にはドローナの息子、首には同母の兄弟たち。胴体の中央にはドゥルヨーダナ王が大軍に囲まれて。
vāmapāde tu rājendra kṛtavarmā vyavasthitaḥ|
nārāyaṇabalair yukto gopālair yuddhadurmadaiḥ|| // 8-8-17 //
（17）左足には、王の中の王よ、クリタヴァルマンが、ナーラーヤナ軍と戦いに酔いしれたゴーパーラ族とともに陣取りました。
pāde tu dakṣiṇe rājangautamaḥ satyavikramaḥ|
trigartaiḥ sumaheṣvāsair dākṣiṇātyaiśca saṃvṛtaḥ|| // 8-8-18 //
（18）右足には、王よ、真の武勇のガウタマ（クリパ）が、偉大な弓の使い手トリガルタ族と南方の者たちとともに。
anupāde tu yo vāmastatra śalyo vyavasthitaḥ|
mahatyā senayā sārdhaṃ madradeśasamutthayā|| // 8-8-19 //
（19）左の後ろ足にはシャリヤが、マドラ国から起こった大軍とともに陣取りました。
dakṣiṇe tu mahārāja suṣeṇaḥ satyasaṅgaraḥ|
vṛto rathamahasreṇa dantināṃ ca tribhiḥ śataiḥ|| // 8-8-20 //
（20）右の後ろ足には、大王よ、真の誓いのスシェーナが、千台の戦車と三百頭の象とともに。
pucche hyāstāṃ mahāvīryau bhrātarau pārthivau tadā|
citraśca citrasenaśca mahatyā senayā vṛtau|| // 8-8-21 //
（21）尾にはバーラタの偉大な武勇の二人の王子——チトラとチトラセーナが大軍とともに陣取りました。
tathā prayāte rājendra karṇe naravarottame|
dhanañjayam abhipekṣya dharmarājo'bravīdidam||
paśya pārtha yathā senā dhārtarāṣṭrīha saṃyuge|
karṇena vihitā vīra guptā vīrair mahārathaiḥ|| // 8-8-22-23 //
（22〜23）大王よ、このようにしてカルナが最上の人として出陣する時、ダナンジャヤ（アルジュナ）を見てダルマラージャ（ユディシュティラ）はこう言いました。「パールタよ、ドリタラーシュトラの軍がこの合戦でカルナによってどのように配置されたか、勇者よ、勇猛な大戦車戦士たちに守られた姿を見よ。
hatavīratamā hyeṣā dhārtarāṣṭrī mahācamūḥ|
phalguśeṣā mahābāho tṛṇaistulyā matā mama|| // 8-8-24 //
（24）この精鋭を失ったドリタラーシュトラの大軍は、大いなる腕の者よ、藁に等しいと私は思う。
eko hyatra maheṣvāsaḥ sūtaputro virājate|
sadevāsuragandharvaiḥ sakinnaramahoragaiḥ|
carācarais tribhir lokair ajeyo yo mahārathaḥ|| // 8-8-25 //
（25）ただ一人、偉大な弓の使い手スータの息子だけがここに輝いている。神々とアスラとガンダルヴァに、キンナラと大蛇とともに、動くものも動かぬものも含む三界に征服されえぬ偉大な戦車戦士が。
taṃ hatvā'dya mahābāho vijayastava phalguna|
uddhṛtaśca bhavecchalyo mama dvādaśavārṣikaḥ|| // 8-8-26 //
（26）大いなる腕の者よ、あの者を今日殺せば、ファルグナ（アルジュナ）よ、おまえの勝利だ。我が十二年の棘が抜かれるであろう。
evaṃ jñātvā mahābāho vyūhaṃ vyūha yathecchasi|| // 8-8-27 //
（27）このことを知った上で、大いなる腕の者よ、望みのままに陣形を組め。」
sañjaya uvāca|
bhrātur etad vacaḥ śrutvā pāṇḍavaḥ śvetavāhanaḥ|
ardhacandreṇa vyūhena pratyavyūhata tāṃ camūm|| // 8-8-28 //
サンジャヤは語った。 （28）兄のこの言葉を聞いて、白い馬のパーンダヴァは、半月の陣形をもってその軍に対抗しました。
vāmapārśve tu tasyātha bhīmaseno vyavasthitaḥ|
dakṣiṇe ca maheṣvāso dhṛṣṭadyumno vyavasthitaḥ|| // 8-8-29 //
（29）その左翼にはビーマセーナが陣取り、右翼には偉大な弓の使い手ドリシュタデュムナが陣取りました。
madhye vyūhasya rājā tu pāṇḍavaśca dhanañjayaḥ|
nakulaḥ sahadevaśca dharmarājasya pṛṣṭhataḥ|| // 8-8-30 //
（30）陣形の中央には王（ユディシュティラ）とパーンダヴァのダナンジャヤ（アルジュナ）。ナクラとサハデーヴァはダルマラージャの後方に。
cakrarakṣau tu pāñcālyau yudhāmanyūttamaujasau|
pārthaṃ na jahaturyudve pālyamānau kirīṭinā|| // 8-8-31 //
（31）車輪の護衛にはパーンチャーラの二人、ユダーマンユとウッタマウジャスが、キリーティン（アルジュナ）に守られながら、戦いでパールタを離れなかった。
śeṣāṃ nṛpatayo vīrāḥ sthitā vyūhasya daṃśitāḥ|
yathābhāgaṃ yathotsāhaṃ yathāyatnaṃ ca bhārata|| // 8-8-32 //
（32）残りの王たちは勇者として、武装して陣形の各所に立った。それぞれの分担と意気込みと努力に応じて、バーラタよ。
evam etan mahāvyūhaṃ vyūhya bhārata pāṇḍavāḥ|
tāvakāśca maheṣvāsā yuddhāyaiva mano dadhuḥ|| // 8-8-33 //
（33）バーラタよ、このようにして大陣形を組み、パーンダヴァたちもおまえの偉大な弓の使い手たちも、戦いに心を定めました。
dṛṣṭvā vyūḍhāṃ tava camūṃ sūtaputreṇa saṃyuge|
nihatān pāṇḍavān mene dhārtarāṣṭraḥ sabāndhavaḥ||
tathaiva pāṇḍavīṃ senāṃ vyūḍhāṃ dṛṣṭvā yudhiṣṭhiraḥ|
dhārtarāṣṭrān hatān mene sakarṇānvai janādhipaḥ|| // 8-8-34-35 //
（34〜35）おまえの軍がスータの息子によって戦場に整えられたのを見て、ドリタラーシュトラの息子は、パーンダヴァたちは一族もろとも討たれたと思いました。同じようにユディシュティラ王も、パーンダヴァの軍が整えられたのを見て、ドリタラーシュトラの息子たちはカルナもろとも討たれたと、人の支配者は思いました。
tataḥ śaṅkhāśca bheryaśca paṇavānakagomukhāḥ|
ḍiṇḍimāścāpyahanyanta jharjharāśca samantataḥ||
senayorubhayo rājan prāvādyanta mahāsvanāḥ|
siṃhanādaśca sañjajñe śūrāṇāṃ jayagṛddhinām||
hayaheṣitaśabdāśca vāraṇānāṃ ca bṛṃhitāḥ|
rathanemisvanāścogrāḥ sambabhūvur janādhipa||
na droṇavyasanaṃ kaścijjānīte tatra bhārata|
dṛṣṭvā karṇaṃ maheṣvāsaṃ mukhe vyūhasya daṃśitam|| // 8-8-36-39 //
（36〜39）法螺貝、太鼓、パナヴァ、アーナカ、ゴームカ、ディンディマ、ジャルジャラが四方で打ち鳴らされました。両軍から大いなる音が響き、勝利を求める勇者たちの獅子の咆哮が生じました。馬のいななき、象の吼え声、戦車の車輪の恐ろしい響きが湧き起こりました、人の支配者よ。偉大な弓の使い手カルナが武装して陣形の先頭に立つのを見て、バーラタよ、ドローナの災厄など誰も知ることがなかった。
ubhe sainye mahārāja prahṛṣṭanarasaṅkule|
yodvukāme sthite rājan hantum anyonyam ojasā||
vijaye jātasaṃrambhe dṛṣṭvā'nyonyaṃ vyavasthite|
anīkamadhye rājendra ceratuḥ karṇapāṇḍavau|| // 8-8-40-41 //
（40〜41）大王よ、勇者たちがひしめく両軍は、王よ、互いを力ずくで倒そうとして、勝利に奮い立ち、互いの姿を見据えて構えていた。戦場の先頭で、王の中の王よ、カルナとパーンダヴァの二人が動き回った。
nṛtyantyāviva te sene sameyātāṃ parasparam|
tayoḥ pakṣaprapakṣebhyo niryayur yudvalipsavaḥ||
tataḥ pravavṛte yuddhaṃ naravāraṇavājinām|
rathānāṃ ca mahārāja anyonyam abhinighnatām|| || // 8-8-42-43 //
（42〜43）踊るかのように二つの軍がぶつかり合い、その翼と側翼から、戦いを望む者たちが飛び出しました。そこで人・象・馬の戦いが始まりました。大王よ、互いに打ち合う戦車兵たちの間で。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhārambhe aṣṭamo'dhyāyaḥ|| 8 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの始まりの第八章は終わる。
