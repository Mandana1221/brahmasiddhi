マハーバーラタ ― カルナ篇 第59章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 59 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ59」、全34詩節からなり、カルナとパーンダヴァ軍の壮絶な乱戦（サンクラ・ユッダ）を描きます。サンジャヤの語りのみで構成される本章では、カルナとパーンダヴァの間でヤマの国を拡大する戦いが再び始まり（第1詩節）、両軍が多様な武器を手に突撃する場面（第2〜4詩節）、カルナが矢の雨で敵軍を蹂躙する場面（第5〜16詩節）、パーンチャーラの王子・ドラウパディーの息子・双子・サーティヤキが一斉にカルナに向かう場面（第17詩節）、そして両軍が血まじりの激烈な白兵戦に突入し、戦場が血と屍に満ちる場面（第18〜34詩節）が描かれます。本章では冒頭の注記「8-59-0」「8-59-0x」（「サンジャヤは語った」）が第1詩節の本文に統合されています。第13詩節および第27〜28詩節には角括弧「[ ]」に対応するバックティック「\`」〜アポストロフィ「'」による異文表記が見られますが、他章と同様の正規化（バックティックをアポストロフィへ変換）のみを行っています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜58章に続き九章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、第26詩節「rathai」の語末子音r脱落（rathai→rathair「戦車によって」）を、前後の対句「hastibhiḥ hastinaḥ（象によって象を）」「naraiḥ narāḥ（人によって人が）」との並列構文により修正しています。
karṇaparva — ekonaṣaṣṭitamo'dhyāyaḥ (59)
第59章
sañjaya uvāca|
tataḥ pravavṛte bhūyaḥ saṅgrāmo rājasattama|
karṇasya pāṇḍavānāṃ ca yamarāṣṭravivardhanaḥ||
// 8-59-1 //
サンジャヤは語った。
王の中の最良者よ、カルナとパーンダヴァの間にヤマの国を拡大する戦いがさらに激しく始まった。
dhanūṃṣi bāṇān parighān asipaṭṭasatomarān|
musalāni bhuśuṇḍīś ca śaktiriṣṭiparaśvathān||
// 8-59-2 //
弓と矢、パリガ（鉄棒）、剣、パッタサ、トマラ、
gadāḥ prāsāñ śitān kuntān bhiṃḍipālān mahāṅkuśān|
pragṛhya kṣipram āpetuḥ parasparajighāṃsayā||
// 8-59-3 //
棍棒、ブシュンディー、矛、リシュティ、斧を手に取り、互いを殺さんとして素早く突撃した。
bāṇajyātalaśabdena dyāṃ diśaḥ pradiśo viyat|
pṛthivīṃ nemighoṣeṇa nādayanto'bhyayuḥ parān||
// 8-59-4 //
弓弦と手の音で天、方角、中空、大地を車輪の轟きで震わせながら敵に向かった。
tena śabdena mahatā saṃhṛṣṭāś cakrur āhavam|
vīrā vīrair mahāptorakalahāntaṃ titīrṣavaḥ||
// 8-59-5 //
その大きな音に鼓舞され、勇者たちは勇者と戦った。争いの終わりを渡ろうとする大戦闘を。
jyātalatradhanuḥśabdāñ śastrāṇāṃ ca nipātyatām|
tāḍitānāṃ ca patatā ninādāṃś ca padātinām||
// 8-59-6 //
弓弦と防具と弓の音、打ち下ろされる武器の音、打たれて倒れる歩兵の叫び声、
bāṇaśabdāṃś ca vividhāñ śūrāṇāṃ ca abhigarjatām|
śrutvā gajā bhṛśaṃ tresuḥ petur mamluś ca sainikāḥ||
// 8-59-7 //
様々な矢の音と勇者たちの吼え声を聞いて、象は激しく震え、兵士たちは倒れ萎えた。
teṣāṃ ninadatāṃ caiva śastravarṣaṃ ca muñcatām|
bahūn ādhirathir vīraḥ pramamātha iṣubhiḥ parān||
// 8-59-8 //
叫び武器の雨を放つ多くの者たちの中で、アディラティの息子の勇者は矢で敵を打ち倒した。
pañca pāñcālavīrāṇāṃ rathān daśa ca pañca ca|
sāśvasūtadhvajān karṇaḥ śarair ninye yamakṣayam||
// 8-59-9 //
カルナはパーンチャーラの勇者の戦車を五台、さらに十五台を、馬・御者・旗もろとも矢でヤマの国へ送った。
yodhamukhyā mahāvīryāḥ pāṇḍūnāṃ karṇam āhave|
śikṣitās tam abhidrutya parivavruḥ samantataḥ||
// 8-59-10 //
パーンドゥ軍の主だった大力の勇者たちは、訓練されたカルナに駆け寄り四方を取り囲んだ。
tataḥ karṇo dviṣatsenāṃ śaravarṣair viloḍayan|
vijagāha aṇḍajākīrṇāṃ padminīm iva yūthapaḥ||
// 8-59-11 //
カルナは矢の雨で敵の軍を掻き乱し、水鳥が群れる蓮池に入る象の群れの王のように突入した。
dviṣatsainyam avaskandya rādheyo dhanur uttamam|
vidhunvānaḥ śitair bāṇaiḥ śirāṃsy unmathya pātayat||
// 8-59-12 //
敵の軍に飛び込んだラーデーヤは、最上の弓をしならせ鋭い矢で首を切り落とした。
'hastinaḥ samahāmātrānsāśvārohānhayānapi|
rathino 'py ekabāṇena bhramataś ca avapātayat||
// 8-59-13 //
大きな象使いを乗せた象を、騎手を乗せた馬を、戦車兵をも一矢で回転させながら倒した。
varma vā carma vā'śritya nipātam api dehinaḥ|
viṣehur nāsya saṃsparśaṃ dvitīyasya patattriṇaḥ||
// 8-59-14 //
鎧を着ても盾を構えても、二本目の矢の衝撃に耐えられる者はいなかった。
varmayukteṣu deheṣu dhanuṣo'syañśitāñ śarān|
maurvyā talatre nyahanatkaśayā vājino yathā||
// 8-59-15 //
鎧を着けた体に、弓から放たれた鋭い矢を弦と防具から打ち込んだ。御者が鞭で馬を打つように。
pāṇḍusṛñjayapāñcālāñ śaragocaram āgatān|
mamarda tarasā karṇaḥ siṃho mṛgagaṇān iva||
// 8-59-16 //
カルナはパーンドゥ・スリンジャヤ・パーンチャーラの矢の射程に入った者たちを、ライオンが鹿の群れを蹂躙するように力をもって蹂躙した。
tataḥ pāñcālaputraś ca draupadeyāś ca māriṣa|
yamau ca yuyudhānaś ca tvaritāḥ karṇam abhyayuḥ||
// 8-59-17 //
親愛なる者よ、パーンチャーラの王子、ドラウパディーの息子たち、双子、ユユダーナ（サーティヤキ）が急いでカルナに向かった。
teṣu vyāyacchamāneṣu kurupāñcālapāṇḍuṣu|
priyān asūn raṇe tyaktvā yodhā jaghnuḥ parasparam||
// 8-59-18 //
クルとパーンチャーラとパーンドゥの者たちが力を尽くす中、戦士たちは大切な命を戦場で捨て互いを殺し合った。
susannaddhāḥ kavacinaḥ saśirastrāṇabhūṣaṇāḥ|
gadābhir musalaiś ca anye parighaiś ca mahābālāḥ||
// 8-59-19 //
鎧を着け兜と装飾をつけた大力の者たちが、棍棒、棍棒、パリガで、
samabhyadhāvanta bhṛśaṃ kāladaṇḍair iva udyataiḥ|
nardantaś ca āhvayantaś ca pravalgantaś ca māriṣa||
// 8-59-20 //
振り上げたヤマの杖のように激しく駆け寄り、叫び、呼びかけ、跳ね回った。
tato nijaghnur anyonyaṃ petuś ca anyonyatāḍitāḥ|
vamanto rudhiraṃ gātrair vimastiṣkekṣamāyudhāḥ||
// 8-59-21 //
互いを打ち合い倒れた。体から血を吐き、脳をさらけ出し、武器を失い。
dantapūrṇaiḥ sarudhirair vakrair dāḍimasannibhaiḥ|
jīvanta iva ca apy eke tasthuḥ śastraughabṛṃhitāḥ||
// 8-59-22 //
血まみれの口から歯をむき出し、ザクロのような顔で、ある者は武器の洪水に支えられてまだ生きているかのように立っていた。
paraśvathaiś ca apy apare paṭṭasair asibhis tathā|
śaktibhir bhiṇḍipālaiś ca nakharaprāsatomaraiḥ||
// 8-59-23 //
斧で切り、パッタサ（剣）で断ち、矛で突き、ビンディパーラで投げ、爪で引き裂き、槍とトマラで打ちと、
tatakṣuś cicchiduś ca anye bibhiduś cikṣipus tathā|
sañcakartuś ca jaghnuś ca rājan yodhā mahāraṇe||
// 8-59-24 //
王よ、戦士たちは大戦場で互いを切り、裂き、突き、投げ、引き裂き、打ち殺した。
petur anyonyanihatā vyasavo rudhirokṣitāḥ|
kṣarantaḥ svarasaṃ raktaṃ prakṛttāś candanā iva||
// 8-59-25 //
互いに殺された者たちは血に染まって命を失い倒れた。切られた赤栴檀から樹液が流れるように赤い血を流して。
rathair rathā vinihatā hastibhiś ca api hastinaḥ|
narair narā hatāḥ petur aśvāś ca aśvaiḥ sahasraśaḥ||
// 8-59-26 //
戦車は戦車に、象は象に倒され、人間は人間に殺され、馬は馬に千単位で倒れた。
dhvajāḥ śirāṃsi cchinnāḥ peturmahītale||
'vadhyatāṃ dāruṇāḥ śabdāḥ patatāṃ stanatām api|
// 8-59-27 //
旗と首が剃刀矢、バッラ矢、半月矢で切り落とされ大地に落ちた。殺される者たちの恐ろしい叫び声と倒れ落ちる者たちのうめき声が。
kṣurair bhallārdhacandraiś ca cchinnāḥ petur mahītale||
narāśvebharathānāṃ hinarāśvebharathais tathā||
// 8-59-28 //
人間・馬・象・戦車が人間・馬・象・戦車によって蹂躙された。
narāṃś ca nāgāṃś ca rathān hayān mamṛdur āhave||
// 8-59-29 //
人間と象と戦車と馬を戦場で踏み潰した。
aśvārohair hatāḥ śūrāś chinnahastāś ca dantinaḥ|
sapatākādhvajāḥ petur viśīrṇā iva parvatāḥ||
// 8-59-30 //
騎兵に殺された勇者たちは手を切られ、旗と幟をつけたまま崩れる山のように象が倒れた。
pattibhiś ca samāplutya dviradāḥ syandanās tathā|
hatāś ca hanyamānāś ca patitāś ca eva sarvaśaḥ||
// 8-59-31 //
歩兵が飛びかかって象や戦車を倒し、殺される者と殺す者が至るところに倒れた。
aśvārohāḥ samāsādya tvaritāḥ pattibhir hatāḥ|
sādibhiḥ pattisaṅghāś ca nihatā yudhi śerate||
// 8-59-32 //
急いで迫った騎兵は歩兵に殺され、騎兵の群れに歩兵の集団が殺されて戦場に横たわった。
mṛditāny iva padmāni pramlānā iva ca srajaḥ|
hatānāṃ vadanāny āsan gātrāṇi ca mahāhave||
// 8-59-33 //
踏みにじられた蓮のように顔は、萎れた花輪のように肢体は、大戦闘で。
rūpāṇy atyarthakāntāni dviradāśvanṛṇāṃ nṛpa|
samunnāny iva vastrāṇi yayur durdurśatāṃ parām||
// 8-59-34 //
象・馬・人間の極めて美しかった姿は、アルカリで汚れた衣のように見るに堪えないものとなった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekonaṣaṣṭitamo'dhyāyaḥ|| 59 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十九章は終わる。
