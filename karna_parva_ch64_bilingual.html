マハーバーラタ ― カルナ篇 第64章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 64 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ64」、全43詩節からなり、前章（第63章）の流れを受けてパーンチャーラ族がドリシュタデュムナを救おうとドゥフシャーサナに突撃する場面から始まります。ナクラとヴリシャセーナの決闘（第3〜6詩節）、カルナが撤退する軍を立て直す場面（第7〜8詩節）、ウルーカとサハデーヴァの一騎打ち（第10〜12詩節）、サーティヤキとシャクニの決闘（第13〜17詩節）、サーティヤキがカウラヴァ軍を突破する場面（第18〜19詩節）、ビーマがドゥルヨーダナを退けて四種の軍を全滅させる場面（第20〜22詩節）、ユダーマンユとクリパの決闘（第23〜24詩節）、ウッタマウジャスとクリタヴァルマンの決闘（第25〜27詩節）、ビーマが象軍に突進して神の武器を発動する場面（第28〜43詩節）で本章は終わります。本章末の結びの一文は原典に明記されています（第63章に続き第64章でも記載あり）。なお、第8詩節・第10詩節にはバックティック「`」で示される異文注記が含まれますが、他章と同様にアポストロフィへ変換しています。
karṇaparva — catuḥṣaṣṭitamo'dhyāyaḥ (64)
第64章
sañjaya uvāca|
tataḥ sarathanāgāśvāḥ pāñcālāḥ pāṇḍusṛñjayāḥ|
senāpatiṃ parīpsanto rurudhus tanayaṃ tava||
// 8-64-1 //
そこで戦車・象・馬と共にパーンチャーラ族とパーンドゥ・スリンジャヤ族は、総大将（ドリシュタデュムナ）を救おうと、おまえの息子を阻んだ。
tataḥ pravavṛte yudvaṃ tāvakānāṃ paraiḥ saha|
ghoraṃ prāṇabhṛtāṃ kāle bhīmarūpaṃ parantapa||
// 8-64-2 //
おまえの側の者たちと敵との間に恐ろしい戦いが始まった。生き物の寿命が尽きる時のような凄まじい姿であった、敵を滅ぼす者よ。
nakulo vṛṣasenaṃ tu viddhvā pañcabhir āyasaiḥ|
pituḥ samīpe tiṣṭhantaṃ tribhir antyair avidhyata||
// 8-64-3 //
ナクラはヴリシャセーナを五本の鉄矢で射抜き、父の近くに立つ彼をさらに三本の矢で射た。
nakulaṃ tu tataḥ śūro vṛṣaseno hasan iva|
nārācena sutīkṣṇena vivyādha hṛdaye bhṛśam'||
// 8-64-4 //
勇敢なヴリシャセーナは笑うかのように、ナクラの心臓を極めて鋭い鉄矢で深く射抜いた。
so 'tividdho balavatā śatruṇā śatrukarśana|
śatruṃ vivyādha viṃśatyā sūtaṃ caivāsya saptabhiḥ||
// 8-64-5 //
敵を苦しめる者ナクラは、力ある敵に深く射られたが、敵を二十本の矢で射返し、その御者をも七本で射た。
tataḥ śarasahasreṇa tau ubhau puruṣarṣabhau|
anyonyam ācchādayatāṃ tava abhajyata vāhinī||
// 8-64-6 //
そして両者、人中の雄牛たちは数千の矢で互いを覆い尽くしたが、おまえの軍は崩れた。
sa dṛṣṭvā pradrutāṃ senāṃ dhārtarāṣṭrasya sūtajaḥ|
nivārayāmāsa balād anupatya viśāmpate||
// 8-64-7 //
軍が逃走するのを見たスータの子（カルナ）は、国の主よ、急いで追いかけて力ずくで阻止した。
'etasminn antare yuddhaṃ kaṣṭamāsīd viśāmpate'|
nivṛtte tu tataḥ sainye nakulaḥ kauravān yayau||
// 8-64-8 //
「この合間に激しい戦いがあった、国の主よ。」軍が立ち直ると、ナクラはカウラヴァたちに向かっていった。
karṇaputras tu samare hitvā nakulameva tu|
jugopa cakraṃ tvarito rādheyasyaiva māriṣa||
// 8-64-9 //
カルナの息子（ヴリシャセーナ）は戦場でナクラを置いて、急いでラーデーヤ（カルナ）の車輪を守りに行った。
ulūkas tu raṇe kruddhaḥ sahadevena māriṣa|
'nivāritaḥ śaraśataiḥ kruddhena raṇamūrdhani||
// 8-64-10 //
ウルーカは戦場で怒って、サハデーヴァに数百の矢で戦場の先頭で阻まれた。
tasyāśvāṃś caturo hatvā sahadevaḥ pratāpavān|
sārathiṃ preṣayāmāsa yamasya sadanaṃ prati||
// 8-64-11 //
威勢あるサハデーヴァはウルーカの四頭の馬を殺し、御者をヤマの館へ送った。
ulūkas tu tato yānād avaplutya viśāmpate|
trigartānāṃ balaṃ tūrṇaṃ jagāma pitṛnandanaḥ||
// 8-64-12 //
国の主よ、ウルーカは戦車から飛び降り、父を喜ばせる者として速やかにトリガルタ軍の中に入った。
sātyakiḥ śakuniṃ viddhvā viṃśatyā niśitaiḥ śaraiḥ|
dhvajaṃ ciccheda bhallena saubalasya hasan iva||
// 8-64-13 //
サーティヤキはシャクニを二十本の鋭い矢で射抜き、笑うかのようにサウバラ（シャクニ）の旗を矢で切り落とした。
saubalastasya samare kruddho rājan pratāpavān|
vidārya kavacaṃ bhūyo dhvajaṃ ciccheda kāñcanam||
// 8-64-14 //
王よ、威勢あるサウバラ（シャクニ）は戦場で怒り、サーティヤキの鎧を裂き、さらに黄金の旗を切り落とした。
tathainaṃ niśitair bāṇaiḥ sātyakiḥ pratyavidhyata|
sārathiṃ ca mahārāja tribhir eva samārpayat||
// 8-64-15 //
同様にサーティヤキは鋭い矢で射返し、大王よ、その御者をも三本の矢で射た。
athāsya vāhāṃstvaritaḥ śarairnitye yamakṣayam|
tato 'vaplutya sahasā śakunirbharatarṣabha||
// 8-64-16 //
そしてすぐさまサーティヤキの矢がシャクニの馬を永遠のヤマの住処へ送った。そこでバーラタの雄牛シャクニは急いで飛び降り、
āruroha rathaṃ tūrṇam ulūkasya mahātmanaḥ|
apovāhātha śīghraṃ sa śaineyād yuddhaśālinaḥ||
// 8-64-17 //
速やかに偉大なウルーカの戦車に乗り込み、戦いに優れたシャイネーヤ（サーティヤキ）から素早く逃れ去った。
sātyakistu raṇa rājaṃs tāvakānām anīkinīm|
abhidudrāva vegena tato 'nīkam abhajvata||
// 8-64-18 //
王よ、サーティヤキは戦場でおまえの軍に猛速で突撃し、軍陣を打ち破った。
śaineyaśarasañchannaṃ tava sainyaṃ viśāmpate|
bheje daśā diśas tūrṇaṃ nyapatac ca gatāsuvat||
// 8-64-19 //
国の主よ、シャイネーヤの矢に覆われたおまえの軍は、速やかに十方に散り、命を失ったかのように倒れた。
bhīmasenaṃ tava suto vārayāmāsa saṃyuge||
// 8-64-20 //
おまえの息子（ドゥルヨーダナ）がビーマセーナを戦場で阻もうとしたが、
taṃ tu bhīmo muhūrtena vyaśvasūtarathadhvajam|
cakre lokeśvaraṃ tatra tena atuṣyanta vai janāḥ||
// 8-64-21 //
ビーマはほんの一瞬で彼を馬も御者も戦車も旗もなき姿にし、この世の支配者をそのような状態にした。人々はそれに喝采した。
tato 'pāyān nṛpas tasmād bhīmasenabhayārditaḥ|
kurusainyaṃ tataḥ sarvaṃ bhīmasenaṃ upādravat|
tatra nādo mahānāsīddhīmasenaṃ jighāṃsatām||
// 8-64-22 //
そこで王はビーマセーナへの恐怖に怯えてその場を去り、クル軍の全てがビーマセーナに向かって殺到した。ビーマセーナを殺そうとする者たちの大いなる喚声が上がった。
yudhāmanyuḥ kṛpaṃ viddhvā dhanurasya āśu cicchade|
athānyad dhanur ādāya kṛpaḥ śastrabhṛtāṃ varaḥ|
yudhāmanyordhvajaṃ sūtaṃ chatraṃ cāpātayatkṣitau||
// 8-64-23 //
ユダーマンユはクリパを射抜き、すぐにその弓を切断した。すると武器を持つ者の中の最高者クリパは別の弓を取り、ユダーマンユの旗・御者・天蓋を地に打ち落とした。
tato'pāyādrathenaiva yudhāmanyurmahārathaḥ||
// 8-64-24 //
そこで大戦車戦士ユダーマンユは戦車で退却した。
uttamaujāś ca hārdikyaṃ bhīmaṃ bhīmaparākramam|
chādayāmāsa sahasā megho vṛṣṭyā iva parvatam||
// 8-64-25 //
ウッタマウジャスは恐るべき武勇のハールディキヤ（クリタヴァルマン）を、雲が雨で山を覆うように、突然矢で覆い尽くした。
tadyuddhamāsītsumahaddhorarūpaṃ parantapa|
tādṛśaṃ na mayā yuddhaṃ dṛṣṭapūrvaṃ viśāmpate||
// 8-64-26 //
その戦いは実に壮大で恐ろしい姿であった、敵を滅ぼす者よ。国の主よ、このような戦いを私は以前見たことがなかった。
kṛtavarmā tato rājan uttamaujaṃ āhave|
hṛdi vivyādha sahasā rathopastha upāviśat||
// 8-64-27 //
王よ、クリタヴァルマンはウッタマウジャスの胸を突然射抜き、彼は戦車の座席にくずおれた。
sārathistamapovāha rathena rathināṃ varam|
tatastu sātvato rājan pāṇḍusainyam abhidravat||
// 8-64-28 //
御者は戦車戦士の中の最高者を戦車で運び去った。王よ、サートヴァタ（クリタヴァルマン）はパーンドゥの軍に突撃した。
duḥśāsanaḥ saubalaś ca gajānīkena pāṇḍavam|
mahatā parivāryaiva kṣudrakair abhyatāḍayat||
// 8-64-29 //
ドゥフシャーサナとサウバラ（シャクニ）は象の軍勢でパーンダヴァ（ビーマ）を大いに取り囲み、軽い矢で打ちかかった。
tato bhīmaḥ śaraśatair duryodhanam amarṣaṇam|
vimukhīkṛtya tarasā gajānīkam upādravat||
// 8-64-30 //
そこでビーマは数百の矢で怒れるドゥルヨーダナを退けてから、象の軍勢に突撃した。
tamāpatantaṃ sahasā gajānīkaṃ vṛkodaraḥ|
dṛṣṭvaiva subhṛśaṃ kruddho divyamastramudairayat||
// 8-64-31 //
突然迫りくる象の軍勢を見たヴリコーダラ（ビーマ）は、激しく怒り、神聖な武器を発動した。
gajair gajān abhyahanadvajreṇa indra ivāsurān||
// 8-64-32 //
象には象をもって打った。インドラが雷でアスラを打つように。
tato'ntarikṣaṃ bāṇaughaiḥ śalabhair iva pādapam|
chādayāmāsa samare gajān nighnan vṛkodaraḥ||
// 8-64-33 //
そして空中を矢の群れでイナゴが木を覆うように覆い、象を殺しながらヴリコーダラは戦った。
tataḥ kuñjarayūthāni sametāni sahasraśaḥ|
vyadhamattarasā bhīmo meghasaṅghān iva ānilaḥ||
// 8-64-34 //
数千頭の象の群れを、ビーマは激しく打ち散らした。風が雲の群れを吹き散らすように。
suvarṇajālāpihitā maṇijālaiś ca kuñjarāḥ|
rejurabhyadhikaṃ saṃkhye vidyutvanta iva ambudāḥ||
// 8-64-35 //
黄金の網と宝石の網で覆われた象たちは、戦場でひときわ輝いていた。稲妻を帯びた雲のように。
te vadhyamānā bhīmena gajā rājan vidudruvuḥ|
kecidvibhinnahṛdayāḥ kuñjarā nyapatan bhuvi||
// 8-64-36 //
王よ、ビーマに殺されている象たちは逃げ散った。あるものは心臓を貫かれて地に倒れた。
patitair nipatadbhiś ca gajairhemavibhūṣitaiḥ|
aśobhata mahī tatra viśīrṇair iva parvataiḥ||
// 8-64-37 //
倒れ、倒れつつある黄金で飾られた象たちで、大地はそこかしこで崩れ落ちた山々のように見えた。
dīptābhai ratnavadbhiś ca patitair gajayodhibhiḥ|
rarāja bhūmiḥ patitaiḥ kṣīṇapuṇyair iva grahaiḥ||
// 8-64-38 //
宝石を身に着けた輝く象兵たちが倒れ、大地は功徳を失って落ちた星々のように輝いた。
tato bhinnakaṭā nāgā bhinnakumbhakarās tathā|
dudruvuḥ śataśaḥ saṃkhye bhīmasenaśarāhatāḥ||
// 8-64-39 //
こめかみを裂かれ、額を割られた象たちは、ビーマセーナの矢に打たれて戦場から数百頭単位で逃走した。
kecidvamanto rudhiraṃ bhayārtāḥ parvatopamāḥ|
vyadravaṃś charaviddhāṅgā dhātucitrā iva ācalāḥ||
// 8-64-40 //
あるものは血を吐きながら恐怖に怯え、山のような巨体に矢を刺されて逃げ走った。色とりどりの鉱物を持つ山のように。
mahābhujagasaṅkāśau candanāgururūṣitau|
apaśyaṃ bhīmasenasya dhanurvikṣipato bhujau||
// 8-64-41 //
私はビーマセーナの弓を引く両腕を見た。大蛇のようで、白檀と沈香で飾られていた。
tasya jyātalanirghoṣaṃ śrutvā āśanisamasvanam|
vimuñcantaḥ śakṛnmūtraṃ gajāḥ prādudruvurbhṛśam||
// 8-64-42 //
雷鳴のような弦の響きを聞いて、象たちは糞尿を漏らしながら激しく逃げ出した。
bhīmasenasya tatkarma rājan ekasya dhīmataḥ|
nighnataḥ sarvabhūtāni rudrasya iva ca nirbabhau||
// 8-64-43 //
王よ、知恵あるビーマセーナ一人のこの業は、全ての生き物を殺すルドラ（シヴァ）の業のごとく輝いた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe catuḥṣaṣṭitamo'dhyāyaḥ|| 64 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第64章終わり。
