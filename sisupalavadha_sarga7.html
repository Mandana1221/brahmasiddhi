सप्तमः सर्गः / 第七章　林苑の遊楽（vanavihāravarṇana）

ヤードゥ族の男女がライヴァタカ山の林苑に出て遊楽する
puṣpitāgrā throughout — ayuji nayugarephato yakāro yuji ca najaujaragāś ca puṣpitāgrā
V.1
Sanskrit (IAST) anugirm ṛtubhir vitāyamānām atha sa vilokayituṃ vanāntalakṣmīm / niragamad abhirāddhum ādṛtānāṃ bhavati mahatsu na niṣphalaḥ prayāsaḥ //
和訳

かくて彼（ハリ）は、山ごとに季節が織り広げる林苑の美を見ようと出発した。崇敬する者たちの営為は、偉大なる者のもとで実を結ばぬことはない。

注

【Vallabhadeva】

anugiram＝山に沿って（avyayībhāva）。vitāyamānām＝広げられつつある（√tan の受動進行形）。vanāntalakṣmī＝林苑の美。abhirāddhum＝崇拝する者たちの。arthāntaranyāsa：特殊例（ハリの出発）から一般命題（偉大な者への奉仕は無駄にならない）への推論。

【Mallinātha】

前章（ṛtuvarṇana）の季節の出現を述べ終え、その果実としてのハリの林苑遊楽を描写し始める。ādṛtānām＝敬意をもって臨む者たちの。niragamad＝出発した（√gam の luṅ）。本章の韻律は puṣpitāgrā。

V.2
Sanskrit (IAST) dadhati sumanaso vanāni bahvīr yuvatiyutā yadavaḥ prayātum īṣuḥ / manasi śayam ahāstram anyathāmī na kusumapañcakam alaṃ visoḍhum //
和訳

林が多くの花を湛えているなか、ヤードゥ族の者たちは女たちを伴って出発しようとした。さもなくば、心に眠るカーマの偉大な武器である五つの花の矢にすら耐えることができまい。

注

【Vallabhadeva】

sumanasaḥ＝花（女性複数）。manasi-śaya＝心に眠る者＝Kāma。kusumapañcaka＝五花の矢（aravindam, aśoka, cūta, navamallika, nīlotpala）。女たちを連れて出たのは、花の武器に耐えるため——kāvyaliṅga。

【Mallinātha】

bahvīḥ＝多くの（bahvādibhyaś ca のオプション変化でīkāra）。mahāstra＝偉大な武器。五花の矢はカーマの弓の矢で、林苑の花がそれを喚起する。女を伴うことがその対処法＝kāvyaliṅga（原因の比喩的提示）。

V.3
Sanskrit (IAST) avasaram adhigamya taṃ harantyo hṛdayam ayatnakṛtojjvalasvarūpāḥ / avaniṣu padam aṅganās tadānīṃ nyadadhata vibhramasampado 'ṅganāsu //
和訳

その好機を得て、努力なくして輝く姿をもち心を奪う女たちは、大地に足を踏み出し、同時に媚態の富を振り撒いた。

注

【Vallabhadeva】

avasaram＝好機（外出の機会）。ayatnakṛtojjvala＝努力なくして輝く＝生まれながらの美。avaniṣu padam nyadadhata＝地に足を置いた＝徒歩で出かけた。aṅganāsu vibhramasampadaḥ padam nyadadhata＝媚態の豊かさが女たちのうちに場所を得た。tulyayogitā（同一動詞の二重適用）。

【Mallinātha】

harantyaḥ hṛdayam＝心を奪いつつ（＝魅力的な）。aṅganā の語の二義：女性・大地。vibhramasampada＝媚態の豊かさ。名詞の二重かかりによるtulyayogitā、さらにekāvalī が含意される。

V.4
Sanskrit (IAST) nakharuciracitendracāpalekhāṃ lalitagateṣu gatāgataṃ dadhānā / mukharitavalayaṃ pṛthau nitambe bhujalatikā muhur askhalat taruṇyāḥ //
和訳

爪の輝きで虹の線を描き、優美な歩みのなかで行きつ戻りつし、腕輪を鳴らしながら、広い腰にたびたびぶつかった——若い女の腕の蔓は。

注

【Vallabhadeva】

bhujalatikā＝腕の蔓。nakharucir＝爪の光。indracāpalekhā＝虹の線。gatāgatam＝行きつ戻りつ（dvandva）。pṛthau nitambe＝広い腰に。mukharitavalayam＝腕輪を鳴らしつつ。uddīpana の四要素：ālambana-guṇa（爪の輝き）、ceṣṭā（行きつ戻り）、alaṅkṛti（腕輪の音）、taṭastha（春等の傍観者）。

【Mallinātha】

lalitagateṣu＝優雅な歩みにおいて。askhalat＝躓いた・ぶつかった。女性の身体描写における uddīpana（情感喚起）の四種の分類が示される。以下の詩句でも同じ構造が続く。

V.5
Sanskrit (IAST) atiśayapariṇāhavān vitene bahutaram arpitakiṅkiṇīkaḥ / alaghuni jaghanasthale 'parasyā dhvanim adhikaṃ kalamekhalākalāpaḥ //
和訳

格別に広がりを持ち、多くの宝石の鈴をあしらった美しい腰帯の束が、別の女の重い腰の上で、ひときわ高い音を響かせた。

注

【Vallabhadeva】

kalamekhalākalāpa＝美しい腰帯の束。alaghuni jaghanasthale＝重い（大きい）腰の上で。dhvanim adhikam vitene＝より多くの音を生じた。aparasyāḥ＝別の女の。alaṅkṛti（装飾描写）の例。

【Mallinātha】

atiśayapariṇāhavān＝並外れた広がりを持つ。kiṅkiṇīka＝小さな鈴（kap 接辞）。kalamekhalā＝美しい腰帯。腰が重く広いがゆえに帯の鈴がより大きく鳴るという因果関係の描写。

V.6
Sanskrit (IAST) gurunibiḍanitambabimbabhārā- kramaṇanipīḍitam aṅganājanasya / caraṇayugam asusruvat padeṣu svarasam asaktam alaktakacchalena //
和訳

重く引き締まった腰の重みに押し付けられた女たちの両足は、歩くたびに、ラック染料を口実として自らの液を絶え間なく流した。

注

【Vallabhadeva】

gurunibiḍanitambabimbabhāra＝重く密な腰の丸みの重量。ākramaṇa＝踏みしめ。nipīḍita＝圧迫された。svarasam＝自らの液（＝汗・血）を。alaktakacchalena＝ラック染料を口実に。実際は腰の重さで足が圧迫され汁が滲むのを、ラックの赤い液で隠したというapahṇava（隠蔽の修辞）。

【Mallinātha】

asusruvat＝流した（√sru の luṅ）。asaktam＝途切れなく。alaktaka＝ラック（足を赤く染める化粧料）。腰の重さによる足の圧迫から滲む液を、ラックの液だと偽る——apahṇavālaṅkāra（否認の修辞）。

V.7
Sanskrit (IAST) tava sapadi samīpam ānaye tām aham iti tasya mayāgrato 'bhyadhāyi / atirabhasakṛtālaghupratiñām anṛtagiraṃ guṇagauri mā kṛthā mām //
和訳

「あの女をすぐにあなたのもとに連れてまいります」と私は彼の前で申しました。ああ美徳の輝く方よ、あの大胆にも大きな約束をした私を嘘つきにしないでください。

注

【Vallabhadeva】

V.7-11 は五偈からなるkulaka（連鎖偈群）。友人（sakhī）が怒った nāyikā を説得する場面。ānaye＝「連れてまいります」（ānayati の vartamāna ātmane）。guṇagauri＝美徳のごとく白く輝く女よ（rūpaka）。anṛtagiram＝嘘つきに。atirabhasakṛtā＝性急になされた、alaghu＝大きな、pratiñā＝約束。

【Mallinātha】

atha kāścit sakhyāḥ kupitanāyikānunayavacanaṃ pañcabhiḥ kulakena āha（友人の、怒った女主人公への宥めの言葉を五偈のkulakaで述べる）。abhyadhāyi＝述べられた（√dhā の受動 luṅ）。mā kṛthāḥ＝なさらないで（√kṛ の luṅ 禁止）。

V.8
Sanskrit (IAST) na ca sutanu na vedmi yan mahīyān asunirasa stava niścayaḥ pareṇa / vitathayati na jātu madvaco 'sāv iti ca tathāpi sakhīṣu me 'bhimānaḥ //
和訳

美しき方よ、あなたの決意が他の男を容易に捨て去るほど固いことは、私も知らぬわけではありません。しかしそれでも「この子は決して私の言葉を無にしない」という誇りが、女友達の中での私にはあるのです。

注

【Vallabhadeva】

na na vedmi＝知らぬわけではない（二重否定＝肯定）。mahīyān niścayaḥ＝より大きな決意。asunirasa＝容易に棄てうる（asu＝容易に、nirasa＝無味な・棄てうる）。pareṇa＝他の男と。sakhīṣu me 'bhimānaḥ＝友人たちの中での私の誇り。

【Mallinātha】

sutanu＝美しい体をもつ女よ。vitathayati＝虚偽にする（vitatha + √kṛ の ṇyanta）。jātu＝いかなる時にも。tathāpi＝それでもなお。友人の自尊心に訴えて nāyikā の心を動かそうとする修辞的戦略。

V.9
Sanskrit (IAST) satatam anabhibhāṣaṇaṃ mayā te pariṇamitaṃ bhavatīmānāyantyā / tvayi tad iti virodhiniścitāyāṃ bhavati bhavatsuhṛjjanaḥ sakāmaḥ //
和訳

あなたを連れて来ることのできない私に、あなたとの絶え間ない語らいが定められました。あなたがそうして敵意を固めるなら、あなたの敵は願いを遂げるでしょう。

注

【Vallabhadeva】

anabhibhāṣaṇam＝語り合わないこと（逆説的に「つねに語りかけること」に転化した）。ānāyantyā＝連れて来ることができないゆえに。virodhiniścitāyām＝敵意を確定させたならば。asuhṛjjana＝敵対者。sakāmaḥ＝願い叶う。

【Mallinātha】

pariṇamitam＝結果として定まった（pariṇam の ṇic の kta）。bhavatī＝あなた（尊称）。māna（怒り・自尊心）をやめなければ敵が喜ぶ——間接的な説得。

V.10
Sanskrit (IAST) gatadhṛtir avalambituṃ batāsūn alam anālapanād ahaṃ bhavatyāḥ / praṇayini yadi na prasādabuddhir bhava mama mānini jīvite dayāluḥ //
和訳

あなたに口を利いてもらえぬため、気力を失い、ああ、命を保つことすらできません。愛しい方よ、もし和解のお気持ちがないなら、せめて誇り高き方よ、私の命に情けをかけてください。

注

【Vallabhadeva】

gatadhṛti＝気力を失った。asūn avalambitum alam＝命を保つことすら出来ない。anālapanāt＝語りかけてもらえないがゆえに（lyablopa で pañcamī）。praṇayini＝愛すべき方よ。mānini＝誇り高き方よ。prasādabuddhi＝和解の意志。

【Mallinātha】

bata＝ああ（感嘆）。alam＝出来ない（śakti の否定）。jīvite dayāluḥ＝命に慈悲を。友人が自らの命を盾にして nāyikā を説得する最終手段。kulaka の第四偈。
