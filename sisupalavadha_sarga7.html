सप्तमः सर्गः / 第七章　林苑の遊楽（vanavihāravarṇana）

ヤードゥ族の男女がライヴァタカ山の林苑に出て遊楽する
puṣpitāgrā throughout — ayuji nayugarephato yakāro yuji ca najaujaragāś ca puṣpitāgrā
V.1
Sanskrit (IAST) anugirm ṛtubhir vitāyamānām atha sa vilokayituṃ vanāntalakṣmīm / niragamad abhirāddhum ādṛtānāṃ bhavati mahatsu na niṣphalaḥ prayāsaḥ //
和訳

かくて彼（ハリ）は、山ごとに季節が織り広げる林苑の美を見ようと出発した。崇敬する者たちの営為は、偉大なる者のもとで実を結ばぬことはない。

注

【Vallabhadeva】

anugiram＝山に沿って（avyayībhāva）。vitāyamānām＝広げられつつある（√tan の受動進行形）。vanāntalakṣmī＝林苑の美。abhirāddhum＝崇拝する者たちの。arthāntaranyāsa：特殊例（ハリの出発）から一般命題（偉大な者への奉仕は無駄にならない）への推論。

【Mallinātha】

前章（ṛtuvarṇana）の季節の出現を述べ終え、その果実としてのハリの林苑遊楽を描写し始める。ādṛtānām＝敬意をもって臨む者たちの。niragamad＝出発した（√gam の luṅ）。本章の韻律は puṣpitāgrā。

V.2
Sanskrit (IAST) dadhati sumanaso vanāni bahvīr yuvatiyutā yadavaḥ prayātum īṣuḥ / manasi śayam ahāstram anyathāmī na kusumapañcakam alaṃ visoḍhum //
和訳

林が多くの花を湛えているなか、ヤードゥ族の者たちは女たちを伴って出発しようとした。さもなくば、心に眠るカーマの偉大な武器である五つの花の矢にすら耐えることができまい。

注

【Vallabhadeva】

sumanasaḥ＝花（女性複数）。manasi-śaya＝心に眠る者＝Kāma。kusumapañcaka＝五花の矢（aravindam, aśoka, cūta, navamallika, nīlotpala）。女たちを連れて出たのは、花の武器に耐えるため——kāvyaliṅga。

【Mallinātha】

bahvīḥ＝多くの（bahvādibhyaś ca のオプション変化でīkāra）。mahāstra＝偉大な武器。五花の矢はカーマの弓の矢で、林苑の花がそれを喚起する。女を伴うことがその対処法＝kāvyaliṅga（原因の比喩的提示）。

V.3
Sanskrit (IAST) avasaram adhigamya taṃ harantyo hṛdayam ayatnakṛtojjvalasvarūpāḥ / avaniṣu padam aṅganās tadānīṃ nyadadhata vibhramasampado 'ṅganāsu //
和訳

その好機を得て、努力なくして輝く姿をもち心を奪う女たちは、大地に足を踏み出し、同時に媚態の富を振り撒いた。

注

【Vallabhadeva】

avasaram＝好機（外出の機会）。ayatnakṛtojjvala＝努力なくして輝く＝生まれながらの美。avaniṣu padam nyadadhata＝地に足を置いた＝徒歩で出かけた。aṅganāsu vibhramasampadaḥ padam nyadadhata＝媚態の豊かさが女たちのうちに場所を得た。tulyayogitā（同一動詞の二重適用）。

【Mallinātha】

harantyaḥ hṛdayam＝心を奪いつつ（＝魅力的な）。aṅganā の語の二義：女性・大地。vibhramasampada＝媚態の豊かさ。名詞の二重かかりによるtulyayogitā、さらにekāvalī が含意される。

V.4
Sanskrit (IAST) nakharuciracitendracāpalekhāṃ lalitagateṣu gatāgataṃ dadhānā / mukharitavalayaṃ pṛthau nitambe bhujalatikā muhur askhalat taruṇyāḥ //
和訳

爪の輝きで虹の線を描き、優美な歩みのなかで行きつ戻りつし、腕輪を鳴らしながら、広い腰にたびたびぶつかった——若い女の腕の蔓は。

注

【Vallabhadeva】

bhujalatikā＝腕の蔓。nakharucir＝爪の光。indracāpalekhā＝虹の線。gatāgatam＝行きつ戻りつ（dvandva）。pṛthau nitambe＝広い腰に。mukharitavalayam＝腕輪を鳴らしつつ。uddīpana の四要素：ālambana-guṇa（爪の輝き）、ceṣṭā（行きつ戻り）、alaṅkṛti（腕輪の音）、taṭastha（春等の傍観者）。

【Mallinātha】

lalitagateṣu＝優雅な歩みにおいて。askhalat＝躓いた・ぶつかった。女性の身体描写における uddīpana（情感喚起）の四種の分類が示される。以下の詩句でも同じ構造が続く。

V.5
Sanskrit (IAST) atiśayapariṇāhavān vitene bahutaram arpitakiṅkiṇīkaḥ / alaghuni jaghanasthale 'parasyā dhvanim adhikaṃ kalamekhalākalāpaḥ //
和訳

格別に広がりを持ち、多くの宝石の鈴をあしらった美しい腰帯の束が、別の女の重い腰の上で、ひときわ高い音を響かせた。

注

【Vallabhadeva】

kalamekhalākalāpa＝美しい腰帯の束。alaghuni jaghanasthale＝重い（大きい）腰の上で。dhvanim adhikam vitene＝より多くの音を生じた。aparasyāḥ＝別の女の。alaṅkṛti（装飾描写）の例。

【Mallinātha】

atiśayapariṇāhavān＝並外れた広がりを持つ。kiṅkiṇīka＝小さな鈴（kap 接辞）。kalamekhalā＝美しい腰帯。腰が重く広いがゆえに帯の鈴がより大きく鳴るという因果関係の描写。

V.6
Sanskrit (IAST) gurunibiḍanitambabimbabhārā- kramaṇanipīḍitam aṅganājanasya / caraṇayugam asusruvat padeṣu svarasam asaktam alaktakacchalena //
和訳

重く引き締まった腰の重みに押し付けられた女たちの両足は、歩くたびに、ラック染料を口実として自らの液を絶え間なく流した。

注

【Vallabhadeva】

gurunibiḍanitambabimbabhāra＝重く密な腰の丸みの重量。ākramaṇa＝踏みしめ。nipīḍita＝圧迫された。svarasam＝自らの液（＝汗・血）を。alaktakacchalena＝ラック染料を口実に。実際は腰の重さで足が圧迫され汁が滲むのを、ラックの赤い液で隠したというapahṇava（隠蔽の修辞）。

【Mallinātha】

asusruvat＝流した（√sru の luṅ）。asaktam＝途切れなく。alaktaka＝ラック（足を赤く染める化粧料）。腰の重さによる足の圧迫から滲む液を、ラックの液だと偽る——apahṇavālaṅkāra（否認の修辞）。

V.7
Sanskrit (IAST) tava sapadi samīpam ānaye tām aham iti tasya mayāgrato 'bhyadhāyi / atirabhasakṛtālaghupratiñām anṛtagiraṃ guṇagauri mā kṛthā mām //
和訳

「あの女をすぐにあなたのもとに連れてまいります」と私は彼の前で申しました。ああ美徳の輝く方よ、あの大胆にも大きな約束をした私を嘘つきにしないでください。

注

【Vallabhadeva】

V.7-11 は五偈からなるkulaka（連鎖偈群）。友人（sakhī）が怒った nāyikā を説得する場面。ānaye＝「連れてまいります」（ānayati の vartamāna ātmane）。guṇagauri＝美徳のごとく白く輝く女よ（rūpaka）。anṛtagiram＝嘘つきに。atirabhasakṛtā＝性急になされた、alaghu＝大きな、pratiñā＝約束。

【Mallinātha】

atha kāścit sakhyāḥ kupitanāyikānunayavacanaṃ pañcabhiḥ kulakena āha（友人の、怒った女主人公への宥めの言葉を五偈のkulakaで述べる）。abhyadhāyi＝述べられた（√dhā の受動 luṅ）。mā kṛthāḥ＝なさらないで（√kṛ の luṅ 禁止）。

V.8
Sanskrit (IAST) na ca sutanu na vedmi yan mahīyān asunirasa stava niścayaḥ pareṇa / vitathayati na jātu madvaco 'sāv iti ca tathāpi sakhīṣu me 'bhimānaḥ //
和訳

美しき方よ、あなたの決意が他の男を容易に捨て去るほど固いことは、私も知らぬわけではありません。しかしそれでも「この子は決して私の言葉を無にしない」という誇りが、女友達の中での私にはあるのです。

注

【Vallabhadeva】

na na vedmi＝知らぬわけではない（二重否定＝肯定）。mahīyān niścayaḥ＝より大きな決意。asunirasa＝容易に棄てうる（asu＝容易に、nirasa＝無味な・棄てうる）。pareṇa＝他の男と。sakhīṣu me 'bhimānaḥ＝友人たちの中での私の誇り。

【Mallinātha】

sutanu＝美しい体をもつ女よ。vitathayati＝虚偽にする（vitatha + √kṛ の ṇyanta）。jātu＝いかなる時にも。tathāpi＝それでもなお。友人の自尊心に訴えて nāyikā の心を動かそうとする修辞的戦略。

V.9
Sanskrit (IAST) satatam anabhibhāṣaṇaṃ mayā te pariṇamitaṃ bhavatīmānāyantyā / tvayi tad iti virodhiniścitāyāṃ bhavati bhavatsuhṛjjanaḥ sakāmaḥ //
和訳

あなたを連れて来ることのできない私に、あなたとの絶え間ない語らいが定められました。あなたがそうして敵意を固めるなら、あなたの敵は願いを遂げるでしょう。

注

【Vallabhadeva】

anabhibhāṣaṇam＝語り合わないこと（逆説的に「つねに語りかけること」に転化した）。ānāyantyā＝連れて来ることができないゆえに。virodhiniścitāyām＝敵意を確定させたならば。asuhṛjjana＝敵対者。sakāmaḥ＝願い叶う。

【Mallinātha】

pariṇamitam＝結果として定まった（pariṇam の ṇic の kta）。bhavatī＝あなた（尊称）。māna（怒り・自尊心）をやめなければ敵が喜ぶ——間接的な説得。

V.10
Sanskrit (IAST) gatadhṛtir avalambituṃ batāsūn alam anālapanād ahaṃ bhavatyāḥ / praṇayini yadi na prasādabuddhir bhava mama mānini jīvite dayāluḥ //
和訳

あなたに口を利いてもらえぬため、気力を失い、ああ、命を保つことすらできません。愛しい方よ、もし和解のお気持ちがないなら、せめて誇り高き方よ、私の命に情けをかけてください。

注

【Vallabhadeva】

gatadhṛti＝気力を失った。asūn avalambitum alam＝命を保つことすら出来ない。anālapanāt＝語りかけてもらえないがゆえに（lyablopa で pañcamī）。praṇayini＝愛すべき方よ。mānini＝誇り高き方よ。prasādabuddhi＝和解の意志。

【Mallinātha】

bata＝ああ（感嘆）。alam＝出来ない（śakti の否定）。jīvite dayāluḥ＝命に慈悲を。友人が自らの命を盾にして nāyikā を説得する最終手段。kulaka の第四偈。

V.11
Sanskrit (IAST) priyam iti vanitā nitāntam āgaḥ- smaraṇasaroṣakaṣāyitākṣī / caraṇagatasakhīvaco 'nurodhāt kila katham apy anukūlayāñcakāra //
和訳

過ちの記憶にひどく怒り、目を赤く染めた女は、足元にひれ伏す友人の言葉に従い、どうにかこうにか恋人に好意を示した。

注

【Vallabhadeva】

kulaka の第五偈（結末）。āgaḥsmaraṇa＝（恋人の）過失の記憶。kaṣāyitākṣī＝赤く染まった目。caraṇagatasakhī＝足元に跪いた友人。kila＝「表面上は」（実際は恋情ゆえ）。khaṇḍitā nāyikā（浮気を知った女主人公）の類型。

【Mallinātha】

anukūlayāñcakāra＝好意を示した（anukūla + √kṛ の liṭ）。kila＝実際には（友人の言葉ではなく）愛ゆえに。khaṇḍitā＝「他の女との関係を知り傷ついた女主人公」（Daśarūpaka の定義）。

V.12
Sanskrit (IAST) drutapadam iti mā vayasya yāsir nanu sutanuṃ paripālayānuyāntīm / na hi na viditakhedam etadīyas tanajaghanodvahane tavāpi cetaḥ //
和訳

「友よ、そんなに急いで行かないで。後からついて行くあの美しい女を待ってあげて。彼女の乳房と腰を支えて歩く苦労を、あなたの心も知らぬわけではないでしょう。」

注

【Vallabhadeva】

新しい場面：ある女友達（sakhī）が先を急ぐ男（vayasya）に二偈で語る。drutapadam＝急ぎ足で。mā yāsīḥ＝行くな（√yā の luṅ 禁止）。anuyāntīm＝後に従う女を。stanajaghanodvahana＝乳房と腰を支え運ぶこと。na hi na＝二重否定＝肯定。

【Mallinātha】

vayasya＝友よ（男性への呼びかけ）。etadīya＝この人の（恋人の女の）。sutanum＝美しい体の女を。paripālaya＝待て。女性の重い身体の歩行困難を恋人が知っているはずだとの暗示。svādhīnapatikā（夫に慕われる女主人公）の描写。

V.13
Sanskrit (IAST) iti vadati sakhījane 'nurāgād dayitatamām aparaś ciraṃ pratīkṣya / tadanugamavaśād anāyatāni nyadhita mimāna ivāvaniṃ padāni //
和訳

女友達がそう言うなか、別の男は愛ゆえに最愛の女を長く待ち、彼女の後について歩くがゆえに、大地を測るかのように小さな歩幅で足を運んだ。

注

【Vallabhadeva】

tadanugamavaśāt＝彼女（恋人）について行くがゆえに。anāyatāni padāni＝間隔の狭い歩み。mimānaḥ iva＝測っているかのよう（utprekṣā）。nydhita＝置いた（√dhā の luṅ）。svādhīnapatikā の nāyikā。

【Mallinātha】

aparaḥ＝別のある男。dayitatamām＝最愛の女を。mimānaḥ＝測る者（√mā の śānac）。歩幅の小ささを大地の測量に喩えるutprekṣā。

V.14
Sanskrit (IAST) yadi mayi laghimānam āgatāyāṃ tava dhṛtir asti gatāsmi sampratīyam / drutatarapadapātam āpapāta priyam iti kopapadena kāpi sakhyā //
和訳

「私が自ら出向くという恥辱を受けても、あなたが平気でいられるなら、もう行きます」——こう怒りを装って友に言い、ある女はいっそう急ぎ足で恋人のもとへ駆け寄った。

注

【Vallabhadeva】

laghimānam＝軽さ（＝恥辱、自ら出向く不面目）。gatāsmi＝行きます（表面上は「もう去る」だが実際は恋人のもとへ）。kopapadena＝怒りの言葉を口実に。kalahāntaritā nāyikā（喧嘩して後悔する女主人公）の類型。

【Mallinātha】

自ら恋人のもとへ駆け寄りたい女が、怒りを装って友人に文句を言い、その口実で急いで恋人のもとへ向かう。drutatarapadapāta＝一層速い足取りで。āpapāta＝駆け寄った（ā + √pat の liṭ）。

V.15
Sanskrit (IAST) aviralapulakaḥ saha vrajantyāḥ pratipadam ekataraḥ stanas taruṇyāḥ / ghaṭitavighaṭitaḥ priyasya vakṣas- taṭabhuvi kandukavibhramaṃ babhāra //
和訳

ともに歩む若い女の、密に総毛立つ片方の乳房が、一歩ごとに恋人の胸の面で離れたりくっついたりして、まるで鞠遊びのような動きを見せた。

注

【Vallabhadeva】

aviralapulaka＝密な鳥肌。ekataraḥ stanaḥ＝（恋人に近い側の）片方の乳房。ghaṭitavighaṭita＝くっついたり離れたり。vakṣastaṭabhū＝胸の面。kandukavibhrama＝鞠の動き。歩行する女の体の揺れを鞠遊びに喩えるnidarśanā（比喩）。pārśvagāminī（恋人の傍を歩く女）。

【Mallinātha】

saha vrajantyāḥ＝寄り添って歩く女の。pratipadam＝一歩ごとに。他のものの振舞いとの類似を指摘するnidarśanā。

V.16
Sanskrit (IAST) aśithilam aparāvasajya kaṇṭhe dṛḍhaparirabdhabṛhadbahistanena / hṛṣitatanuruhā bhujena bhartur mṛdum amṛdu vyatividdham ekabāhum //
和訳

外側に押し出された大きな乳房をしっかりと抱き、毛が逆立った腕で、夫の首にきつく絡みつき、柔らかな自分の片腕を力強く交差させた。

注

【Vallabhadeva】

V.16-18 は viśeṣaka（特殊描写の三偈連鎖）で一人の女の歩みを描く。aśithilam＝緩めず。avasajya＝掛けて。dṛḍhaparirabdha＝しっかり抱かれた。bahistana＝外側に押し出された乳房。hṛṣitatanuruha＝毛が逆立った（鳥肌の）。vyatividdham＝交差させた。

【Mallinātha】

V.16-18 は一人の女の歩行を三偈で描くviśeṣaka。aparā（別の女の）歩みの詳細。ekabāhum＝片腕を。mṛdu amṛdu＝柔らかくかつ強く。夫の首に絡みつきながら歩く女の姿。

V.17
Sanskrit (IAST) muhur asusamam ādhnatī nitāntaṃ praṇaditakāñci nitambamaṇḍalena / viṣamitapṛthuhārayaṣṭi tiryak- kucam itaraṃ tad urasthale nipīḍya //
和訳

腰帯を激しく鳴らす腰で何度も夫にぶつかり、大きな首飾りの紐を歪ませつつ、もう片方の乳房を斜めに夫の胸に押し付けながら——

注

【Vallabhadeva】

viśeṣaka の第二偈。ādhnatī＝ぶつかりながら（ā + √han の śatṛ + ṅīp）。praṇaditakāñci＝腰帯を鳴らす。viṣamitapṛthuhārayaṣṭi＝大きな首飾りの紐を歪めた。itaram kucam＝もう片方（右）の乳房を。nipīḍya＝押し付けて。

【Mallinātha】

asusama＝夫（prāṇeśa）。nitambamaṇḍalena＝腰の丸みで。tiryak＝斜めに。動作の連続が一人の女の歩行を生き生きと描く。

V.18
Sanskrit (IAST) gurutarakalanūpurānunādaṃ salalitanartitavāmapādapadmā / itarad atilolam ādadhānā padam atha manmathamantharaṃ jagāma //
和訳

一層深い美しい足飾りの響きとともに、左の蓮華の足を優雅に踊らせ、もう一方の足はあまり動かさずに置き、カーマにけだるく酔ったように歩んで行った。

注

【Vallabhadeva】

viśeṣaka の第三偈（結末）。gurutarakalanūpurānunāda＝一層深い美しい足環の響き。salalitanartita＝優雅に踊らせた。vāmapādapadmā＝左の蓮足。itarat padam＝もう一方の（右の）足を。atilolam＝あまり動かさず（恋人の足に躓かないように）。manmathamantharam＝カーマに緩慢な＝情欲でけだるい。pārśvagāminī の描写完結。

【Mallinātha】

jagāma＝歩んだ（三偈の述語動詞はここに）。manmathamantharam＝恋にけだるく。左足は夫から離れる側で活発に動き、右足は夫に近い側で控えめに——歩き方の非対称を描く。

V.19
Sanskrit (IAST) laghu lalitapadaṃ tadaṃsapīṭha- dvayanihitobhayapāṇipallavānyā / sakaṭhinakucacūcukapraṇodaṃ priyam abalā savilāsam anvināya //
和訳

軽やかで優美な足取りで、両の手の蕾を恋人の両肩に置き、硬い乳首で背中を押しながら、か弱い女は恋人を艶やかに後ろから導いた。

注

【Vallabhadeva】

aṃsapīṭhadvaya＝（恋人の）両肩。nihitobhayapāṇipallava＝両手の蕾を置いた。kaṭhinakucacūcukapraṇoda＝硬い乳首による押し。anvināya＝後ろから導いた（anu + √nī）。pṛṣṭhagāminī（恋人の背後を歩く女）の類型。

【Mallinātha】

abalā＝か弱い女。savilāsam＝艶やかに。pṛṣṭhagāminī の描写。恋人の背後から肩に手を置き乳房で押しながら歩く姿。

V.20
Sanskrit (IAST) jaghanam alaghu pīvaroru kṛcchrād urunibirīsanitambabhārakhedi / dayitatamaśirodharāvalambi- svabhujalatāvibhavena kācid ūhe //
和訳

重い腰、太い腿、きつく引き締まった臀部の重みに苦しみつつ、ある女は最愛の者の首に垂れかかる自らの腕の蔓の力で、辛うじて腰を支え運んだ。

注

【Vallabhadeva】

alaghu jaghanam＝重い前腰。pīvaroru＝太い腿。urunibirīsanitambabhārakhedi＝きわめて密な臀部の重みに苦しむ。dayitatamaśirodharāvalambi＝最愛の者の首に垂れかかる。svabhujalatāvibhavena＝自らの腕蔓の力で。kṛcchrāt＝辛うじて。ūhe＝運んだ（√vah の ātmanepada liṭ）。pṛṣṭhagāminī の別の女。

【Mallinātha】

nibirīsa＝密な・引き締まった。bhārakhedi＝重みに苦しむ者（ākhīkṣṇye ṇini）。恋人の首に腕を垂らしてしがみつきながら歩く女。背後から首に懸かる描写。
