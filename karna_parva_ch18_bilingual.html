karṇaparva — aṣṭādaśo'dhyāyaḥ (18)
第18章　アルジュナがサンシャプタカ族を破る
sañjaya uvāca|
śvetāśvo'pi mahārāja vyadhamat tāvakaṃ balam|
yathā vāyuḥ samāsādya tūlarāśiṃ samantataḥ|| // 8-18-1 //
サンジャヤは語った。 （1）大王よ、白い馬の者（アルジュナ）もまた、あなたの軍を打ち砕きました。風が綿の山を四方に吹き散らすように。
pratyudyayus trigartās taṃ śibayaḥ kauravaiḥ saha|
vasātayo'tha sālvāś ca gopālāśca yaśasvinaḥ|| // 8-18-2 //
（2）トリガルタ族、シビ族、カウラヴァの者たち、ヴァサーティ族、サールヴァ族、そして名高いゴーパーラ族が彼に立ち向かいました。
satyadevaḥ satyakīrtir mitradevaḥ śrutañjayaḥ|
sauśrutiś candradevaś ca mitravarmā ca bhārata|| // 8-18-3 //
（3）サティヤデーヴァ、サティヤキールティ、ミトラデーヴァ、シュルタンジャヤ、サウシュルティ、チャンドラデーヴァ、そしてミトラヴァルマン——バーラタよ——
trigartarājaḥ samare bhrātṛbhiḥ parivāritaḥ|
putraiś caiva maheṣvāsair nānāśastraviśāradaiḥ|| // 8-18-4 //
（4）トリガルタの王は戦場で兄弟たちに囲まれ、偉大な弓兵にしてさまざまな武器に精通した息子たちとともに——
vyasṛjanta śastrātān kiranto'rjunamāhave|
abhyavartanta sahasā vāryoghā iva sāgaram|| // 8-18-5 //
（5）武器を手にした者たちは、矢を降り注がせながらアルジュナに襲いかかりました。水の奔流が大海に向かうように。
te tvarjunaṃ samāsādya yodhāḥ śatasahasraśaḥ|
agacchan vilayaṃ sarve tārkṣyaṃ dṣṭvā iva pannagāḥ|| // 8-18-6 //
（6）しかしアルジュナのもとに至った何十万もの戦士たちは、ガルーダを見た蛇のように、皆滅んでいきました。
te hanyamānāḥ samare na jahuḥ pāṇḍavaṃ raṇe|
hanyamānā mahārāja śalabhā iva pāvakam|| // 8-18-7 //
（7）大王よ、戦場で打たれながらも、彼らはパーンダヴァ（アルジュナ）の前から逃げませんでした。蛾が火に向かっていくように。
satyadevas tribhir bāṇair vivyādha yudhi pāṇḍavam|
mitradevas triṣaṣṭyā tu candradevas tu saptabhiḥ|| // 8-18-8 //
（8）サティヤデーヴァは三本の矢で戦場のパーンダヴァを射ち、ミトラデーヴァは六十三本、チャンドラデーヴァは七本で射ちました。
mitravarmā trisaptatyā sauśrutiścāpi saptabhiḥ|
śrutaṃjayas tu viṃśatyā suśarmā navabhiḥ śaraiḥ|| // 8-18-9 //
（9）ミトラヴァルマンは七十三本、サウシュルティは七本、シュルタンジャヤは二十本、スシャルマンは九本の矢で射ちました。
sa viddho bahubhiḥ saṅkhye prativivyādha tān nṛpān|
sauśrutiṃ saptabhir vidvvā candradevaṃ tribhiḥ śaraiḥ|| // 8-18-10 //
（10）多くの矢を受けたアルジュナは、それらの王たちを射返しました。サウシュルティを七本、チャンドラデーヴァを三本の矢で射ち——
śrutaṃjayaṃ ca viṃśatyā candradevaṃ tathā'ṣṭabhiḥ|
mitradevaṃ śatenaiva satyadevaṃ tribhiḥ śaraiḥ|| // 8-18-11 //
（11）シュルタンジャヤを二十本、チャンドラデーヴァを八本、ミトラデーヴァを百本、サティヤデーヴァを三本の矢で射ち——
navabhir mitravarmāṇaṃ suśarmāṇaṃ tathā'ṣṭabhiḥ|
śrutañjayaṃ ca rājānaṃ hatvā tatra śilāśitaiḥ|| // 8-18-12 //
（12）ミトラヴァルマンを九本、スシャルマンを八本で射ち、シュルタンジャヤ王を石に研がれた矢で殺しました。
sauśruteḥ saśirastrāṇaṃ śiraḥ kāyādapāharat|
tvaritaścandradevaṃ ca śarairninye yamakṣayam|| // 8-18-13 //
（13）サウシュルティの兜ごとの首を体から切り離し、素早くチャンドラデーヴァも矢で閻魔の館に送りました。
tathetarān mahārāja yatamānān mahārathān|
pañcabhiḥ pañcabhir bāṇair ekaikaṃ pratyavārayat|| // 8-18-14 //
（14）大王よ、その他の奮闘する偉大な戦車戦士たちも、それぞれ五本ずつの矢で一人一人を退けました。
satyadevas tu saṅkruddhas tomaraṃ vyasṛjan mahat|
samuddiśya raṇe kṛṣṇaṃ siṃhanādaṃ nanāda ca|| // 8-18-15 //
（15）激怒したサティヤデーヴァは、戦場でクリシュナを狙って大きな投げ槍を放ち、獅子の咆哮を上げました。
sa nirbhidya bhujaṃ savyaṃ mādhavasya mahātmanaḥ|
ayasmayaḥ svarṇadaṇḍo jagāma dharaṇīṃ tadā|| // 8-18-16 //
（16）鉄製で金の柄のその投げ槍は、マーダヴァ（クリシュナ）の偉大な魂の左腕を貫いて大地に落ちました。
mādhavasya tu viddhasya tomareṇa mahāraṇe|
pratodaḥ prāpatad vastād raśmayaś ca viśāmpate|| // 8-18-17 //
（17）大戦闘で投げ槍に貫かれたマーダヴァの手から、鞭が落ち、手綱も落ちました、王よ。
vāsudevaṃ vibhinnāṅgaṃ dṛṣṭvā pārtho dhanañjayaḥ|
krodhamāhārayattīvraṃ kṛṣṇaṃ cedamuvāca ha|| // 8-18-18 //
（18）体を傷つけられたヴァースデーヴァ（クリシュナ）を見て、パールタ・ダナンジャヤ（アルジュナ）は激しい怒りを覚え、クリシュナにこう言いました。
prāpayāśvānmahābāho satyadevaṃ prati prabho|
yāvadenaṃ śarais tīkṣṇair nayāmi yamasādanam|| // 8-18-19 //
（19）「大いなる腕の者よ、主よ、馬をサティヤデーヴァの方へ向けてくれ。鋭い矢でこの者を閻魔の館に送るまで。」
pratodaṃ gṛhya so'nyat tu raśmīn saṅgṛhya ca drutam|
vāhayāmāsa tān aśvān satyadevarathaṃ prati|| // 8-18-20 //
（20）クリシュナは別の鞭を取り、素早く手綱を握り直し、馬をサティヤデーヴァの戦車に向けて走らせました。
viṣvaksenaṃ sunirviddhaṃ dṛṣṭvā pārtho dhanañjayaḥ|
satyadevaṃ śarais tīkṣṇair vārayitvā mahārathaḥ|| // 8-18-21 //
（21）ヴィシュヴァクセーナ（クリシュナ）がひどく傷ついたのを見て、パールタ・ダナンジャヤは偉大な戦車戦士として、まず鋭い矢でサティヤデーヴァを制し——
tataḥ suniśitair bhallai rājñas tasya mahacchiraḥ|
kuṇḍalopacitaṃ kāyāccakarta pṛtanāntare|| // 8-18-22 //
（22）そして鋭い矢尻の矢で、耳飾りを輝かせた王の大きな首を、軍の中で体から切り落としました。
tannikṛtya śitair bāṇair mitravarmāṇam ākṣipat|
vatsadantena tīkṣṇena sārathiṃ cāsya māriṣa|| // 8-18-23 //
（23）鋭い矢でそれを切り裂き、ミトラヴァルマンを攻撃しました。鋭い子牛の歯のような矢で、彼の御者も。
tataḥ śaraśatair bhūyaḥ saṃśaptakagaṇān balī|
pātayāmāsa saṅkruddhaḥ śataśo'tha sahasraśaḥ|| // 8-18-24 //
（24）そしてさらに何百もの矢で、怒りに燃え、サンシャプタカ族の群れを何百何千と打ち倒しました。
tato rajatapuṅkhena rājañ śīrṣaṃ mahātmanaḥ|
mitradevasya ciccheda kṣurapreṇa mahārathaḥ|
suśarmāṇaṃ susaṅkruddho jatrudeśe samāhanat|| // 8-18-25 //
（25）王よ、偉大な戦車戦士は銀の矢尻の剃刀の矢で偉大なる魂のミトラデーヴァの首を切り、激怒してスシャルマンの鎖骨のあたりを打ちました。
tataḥ saṃśaptakāḥ sarve parivārya dhanañjayam|
śastraughair mamṛduḥ kruddhā nādayanto diśo daśa|| // 8-18-26 //
（26）そしてサンシャプタカ族全員がダナンジャヤを取り囲み、怒って武器の雨を浴びせかけ、十方に雄叫びを上げました。
abhyarditas tu tajjiṣṇuḥ śakratulyaparākramaḥ|
aindram astram ameyātmā prāduścakre mahārathaḥ|| // 8-18-27 //
（27）苦しめられたジシュヌ（アルジュナ）は、インドラに等しい武勇を持つ計り知れない魂の偉大な戦車戦士として、インドラの天の武器を発動させました。
tataḥ śarasahasrāṇi prādurāsan viśāmpate|
kārmukāt pāṇḍuputrasya pārthasya amitatejasaḥ|| // 8-18-28 //
（28）王よ、何千もの矢が、計り知れない威光を持つパーンドゥの子パールタの弓から現れました。
tatas tu cchidyamānānāṃ dhvajānāṃ dhanuṣāṃ tathā|
rathānāṃ sapatākānāṃ tūṇīrāṇāṃ yugaiḥ saha||
akṣāṇām atha cakrāṇāṃ yoktrāṇāṃ raśmibhiḥ saha|
kūbarāṇāṃ varūthānāṃ pṛṣatkānāṃ ca saṃyuge||
aśvānāṃ patatāṃ cāpi prāsānām ṛṣṭibhiḥ saha|
gadānāṃ parighānāṃ ca śaktitomarapaṭṭasaiḥ||
śataghnīnāṃ sacakrāṇāṃ bhujānāṃ corubhiḥ saha|
kaṇṭhasūtrāṅgadānāṃ ca keyūrāṇāṃ ca māriṣa||
hārāṇām atha niṣkāṇāṃ tanutrāṇāṃ ca bhārata|
chatrāṇāṃ vyajanānāṃ ca śirasāṃ kumuṭaiḥ saha|
rāśayaścātra dṛśyante patitānāṃ mahītale|| // 8-18-29-33 //
（29〜33）王よ、切り裂かれる旗・弓・旗のついた戦車・矢筒と軛、車軸・車輪・繋ぎ紐と手綱、轅と車輪の覆い・矢、落ちていく馬・槍と投げ矢、棍棒・鉄棒・槍と投げ槍と刀剣、車輪つきの殺戮兵器・腕と腿、首飾り・腕輪・腕飾り、首飾り・装身具・鎧、傘・扇・兜つきの首——これらの山が大地に落ちているのが見えました。
sakuṇḍalāni svakṣīmi pūrṇacandranibhāni ca|
śirāṃsy urvyām adṛśyanta tārājālam iva ambare|| // 8-18-34 //
（34）耳飾りをつけ美しい目を持つ、満月のような顔の首が大地に散らばっているのが見えました。空の星の連なりのように。
susragvīṇi suvāsāṃsi candanenokṣitāni ca|
śarīrāṇi vyadṛśyanta nihatānāṃ mahītale|| // 8-18-35 //
（35）美しい花輪をまとい、美しい衣を着、白檀を塗った体が、殺された者たちの体が大地に見えました。
rudrasyākrīḍasadṛśaṃ ghoram āyodhanaṃ tadā|| // 8-18-36 //
（36）ルドラ神の遊び場のような恐ろしい戦場でした。
nihatai rājaputraiśca kṣatriyaiśca mahābalaiḥ|
arjunena mahārāja tatratatra mahāraṇe||
hastibhiḥ patitaiś caiva turaṅgaiś cābhavan mahī|
agamyarūpā samare viśīrṇair iva parvataiḥ|| // 8-18-37-38 //
（37〜38）大王よ、アルジュナに殺された王子やクシャトリヤの大力の者たち、倒れた象、倒れた馬で——大地は戦場で通行不能になりました。崩れた山のように。
nāsīd rathapathas tasya pāṇḍavasya mahātmanaḥ|
nighnataḥ śātravān bhallair hastyaśvaṃ cāsyato mahat|| // 8-18-39 //
（39）パーンダヴァという偉大な魂の者が矢尻の矢で敵を殺し、大量の象と馬を射ち倒す中、戦車の通り道はありませんでした。
svānugā iva sīdanti rathacakrāṇi māriṣa|
caratas tasya saṅgrāme tasmiṃllohitakardame|| // 8-18-40 //
（40）戦場のその血の泥沼の中を進む彼の戦車の車輪は、まるで追随者のように沈み込みました。
sīdamānāni cakrāṇi samuhūs turagā bhṛśam|
śrameṇa mahatā yuktā manomārutaraṃhasaḥ|| // 8-18-41 //
（41）沈む車輪を馬たちは懸命に引きました。心と風のように速い馬たちは、大いなる疲労に苦しみながら。
vadhyamānaṃ tu tatsainyaṃ pāṇḍuputreṇa dhanvinā|
prāyaśo vimukhaṃ sarvaṃ nāvatiṣṭhata bhārata|| // 8-18-42 //
（42）バーラタよ、パーンドゥの子という弓兵に打たれるその軍は、ほとんどが背を向けて逃げ、踏みとどまることはありませんでした。
tāñ jitvā samare jiṣṇuḥ saṃśaptakagaṇān bahūn|
virarāja tadā pārtho vidhūmo'gnir iva jvalan|| || // 8-18-43 //
（43）ジシュヌ（アルジュナ）は戦場で多くのサンシャプタカ族の群れを打ち負かし、煙のない燃え上がる炎のように輝きました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe aṣṭādaśo'dhyāyaḥ|| 18 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十八章は終わる。
