kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

saptamaḥ sargaḥ ― 第七章

天界の軍勢が空を行きインドラキーラ山へ向かう（1-19）。山上への降下と陣営の設営（20-29）。神々の象の描写（30-40）。韻律は Praharṣiṇī（第40偈のみ Vasantatilakā）。
1
Sanskrit
śrīmadbhiḥ sarathagajaiḥ surāṅganānāṃ guptānām atha sacivais trilokabhartuḥ / saṃmūrchann alaghuvimānarandhrabhinnaḥ prasthānaṃ samabhidadhe mṛdaṅganādaḥ //
Praharṣiṇī
和訳
三界の主（インドラ）の荘厳なる戦車と象を従えた従者たちに護られた天女たちの出発を、巨大な天車の空洞に反響してうねる太鼓の音が告げた。

vimāna（天車）は宮殿のような巨大な空飛ぶ乗り物。車輪が回転しないまま空中を移動する（4節参照）。本章の韻律 Praharṣiṇī は「喜びを与えるもの」の意。

2
Sanskrit
sotkaṇṭhair amaragaṇair anuprakīrṇān niryāya jvalitarucaḥ purān maghonaḥ / rāmāṇām upari vivasvataḥ sthitānāṃ nāsede caritaguṇatvam ātapatraiḥ //
Praharṣiṇī
和訳
好奇に満ちた神々の群に見送られ、光り輝くマゴーナ（インドラ）の都を出て、太陽の上に位置した美女たちにとって、日傘はその本来の役目を果たすことができなかった。

天女たちは太陽よりも高い位置を飛行しているため、日傘が日光を遮る必要がない。天界の高さを示す巧みな着想。

3
Sanskrit
dhūtānām abhimukhapātibhiḥ samīrair āyāsād aviśadalocanotpalānām / āninye madajanitāṃ śriyaṃ vadhūnām uṣṇāṃśudyutijanitaḥ kapolarāgaḥ //
Praharṣiṇī
和訳
向かい風に吹かれ、疲労で蓮華のような瞳が曇った天女たちに、太陽の光が生み出す頬の紅潮は、酔いが醸す艶めかしさを与えた。
4
Sanskrit
tiṣṭhadbhiḥ katham api devatānubhāvād ākṛṣṭaiḥ prajavibhir āyataṃ turaṅgaiḥ / nemīnām asati vivartane rathaughair āsede viyati vimānavat pravṛttiḥ //
Praharṣiṇī
和訳
神々の威力でかろうじて空中に留まり、疾駆する馬に長く引かれた戦車の群は、車輪の回転なくして、天車のように空中を進んだ。
5
Sanskrit
kāntānāṃ kṛtapulakaḥ stanāṅgarāge vaktreṣu cyutatilakeṣu mauktikābhas / sampede śramasalilodgamo vibhūṣā ramyāṇāṃ vikṛtir api śriyaṃ tanoti //
Praharṣiṇī
和訳
美女たちの胸の紅粉の上に鳥肌が立ち、額飾りの剥がれた顔に真珠のような汗の雫が現れ、それは装飾品となった。美しき者には乱れさえも美を増すのだ。
6
Sanskrit
rājadbhiḥ pathi marutām abhinnarūpair ulkārciḥ sphuṭagatibhir dhvajāṅkuśānām / tejobhiḥ kanakanikāṣarājigaurair āyāmaḥ kriyata iva sma sātirekaḥ //
Praharṣiṇī
和訳
風神の道（空中）に輝く、途切れることなく流れ星の閃光のように鮮やかな軌跡を描く旗幟と鉤棒の光芒は、金の試金石に引かれた黄金の筋のように、空間をさらに広げるかに見えた。
7
Sanskrit
rāmāṇām avajitamālyasaukumārye samprāpte vapuṣi sahatvam ātapasya / gandharvair adhigatavismayaiḥ pratīye kalyāṇī vidhiṣu vicitratā vidhātuḥ //
Praharṣiṇī
和訳
花環にも勝る繊細さを持つ天女たちの肉体が日光の熱に晒されたとき、驚嘆に打たれたガンダルヴァたちは、造物主の創造の見事な多彩さを悟った。
8
Sanskrit
sindūraiḥ kṛtarucayaḥ sahemakakṣyāḥ srotobhis tridaśagajā madaṃ kṣarantaḥ / sādṛśyaṃ yayur aruṇāṃśurāgabhinnair varṣadbhiḥ sphuritaśatahradaiḥ payodaiḥ //
Praharṣiṇī
和訳
辰砂で美しく輝き、黄金の帯を締め、体中の穴から発情液を滴らせる神々の象たちは、朝焼けの光に裂かれ、稲妻を閃かせつつ雨を降らす雲に似ていた。
9
Sanskrit
atyarthaṃ durupasadād upetya dūraṃ paryantād ahimamayūkhamaṇḍalasya / āśānām uparacitām ivaikaveṇīṃ ramyormīṃ tridaśanadīṃ yayur balāni //
Praharṣiṇī
和訳
近づきがたい太陽の円盤の縁から遠く離れ、さらに進んだ軍勢は、天空に一本の編み髪のように広がる美しい波をもつ天の河に達した。
10
Sanskrit
āmattabhramarakulākulāni dhunvann udbhūtagrathitarajāṃsi paṅkajāni / kāntānāṃ gagananadītaraṅgaśītaḥ saṃtāpaṃ viramayati sma mātariśvā //
Praharṣiṇī
和訳
酔った蜜蜂の群がたかる蓮の花を揺らし、花粉を舞い上がらせつつ、天の河の波で冷たくなった風が天女たちの暑さを和らげた。
11
Sanskrit
sambhinnair ibhaturagāvagāhanena prāpyorvīr anupadavīṃ vimānapaṅktīḥ / tatpūrvaṃ pratividadhe surāpagāyā vaprāntaskhalitavivartanaṃ payobhiḥ //
Praharṣiṇī
和訳
象と馬が潜ることで濁った天の河の波が、天車の列と並んでその道をたどるとき、あたかも初めて岸辺で砕け散るかのように流れ去った。

天のガンガーには本来岸がない。天車の列が「岸」の役割を果たし、波がそこで砕けるという趣向。

12
Sanskrit
krāntānāṃ grahacaritāt patho rathānām akṣāgrakṣatasuraveśmavedikānām / niḥsaṅgaṃ pradhibhir upādade vivṛttiḥ sampīḍakṣubhitajaleṣu toyadeṣu //
Praharṣiṇī
和訳
惑星の軌道上で車軸の先端が神々の宮殿のテラスを削っていた戦車は、そこを離れると、車輪が雲の中で自在に回転し始めた。衝撃で雲の水を揺り動かしながら。

天界の宮殿近くでは車輪が回らず空中を滑るように進んでいたが（4節参照）、雲の中に入ると抵抗を受けて車輪が回転し始めるという巧みな着想。

13
Sanskrit
taptānām upadadhire viṣāṇabhinnāḥ prahlādaṃ surakariṇāṃ ghanāḥ kṣarantaḥ / yuktānāṃ khalu mahatāṃ paropakāre kalyāṇī bhavati rujatsv api pravṛttiḥ //
Praharṣiṇī
和訳
牙で裂かれながらも水を滴らせる雲は、暑さに苦しむ神々の象に涼を与えた。他者を助けることに心を砕く偉大なる者の行いは、苦しめられてもなお善きものである。
14
Sanskrit
saṃvātā muhur anilena nīyamāne divyastrījaghanavarāṃśuke vivṛttim / paryasyatpṛthumaṇimekhalāṃśujālaṃ saṃjajñe yutakam ivāntarīyam ūrvoḥ //
Praharṣiṇī
和訳
風が繰り返し天女たちの腰の美しい衣を開くと、大きな宝石を散りばめた腰帯から溢れ出る光の網が、太腿の内衣のように見えた。
15
Sanskrit
pratyārdrīkṛtatilakās tuṣārapātaiḥ prahlādaṃ śamitapariśramā diśantaḥ / kāntānāṃ bahumatim āyayuḥ payodā nālpīyān bahu sukṛtaṃ hinasti doṣaḥ //
Praharṣiṇī
和訳
雪の飛沫で額飾りを溶かしてしまうものの、疲労を鎮めて涼を与える雲は、美女たちの尊敬を得た。小さな過失は大きな善行を損なうことはない。
16
Sanskrit
yātasya grathitataraṅgasaikatābhe vicchedaṃ vipayasi vārivāhajāle / ātenus tridaśavadhūjanāṅgabhājāṃ saṃdhānaṃ suradhanuṣaḥ prabhā maṇīnām //
Praharṣiṇī
和訳
波状の砂洲に似た、水気を失った雲の帯の中で虹が途切れたとき、天女たちの体を飾る宝石の輝きがその虹の欠けた部分を繋ぎ合わせた。
17
Sanskrit
saṃsiddhāv iti karaṇīyasaṃnibaddhair ālāpaiḥ pipatiṣatāṃ vilaṅghya vīthīm / āsede daśaśatalocanadhvajinyā jīmūtair apihitasānur indrakīlaḥ //
Praharṣiṇī
和訳
任務の成就のためになすべきことを語り合いつつ、鳥の通う道を越えて進んだ千眼の神（インドラ）の軍勢は、雲に頂を覆われたインドラキーラ山に到達した。
18
Sanskrit
ākīrṇā mukhanalinair vilāsinīnām udbhūtasphuṭaviśadātapatraphenā / sā tūryadhvanitagabhīram āpatantī bhūbhartuḥ śirasi nabhonadīva reje //
Praharṣiṇī
和訳
美女たちの蓮のような顔で満ち、高く開かれた明るい日傘を泡のように掲げ、深い太鼓の音を響かせつつ降下するその軍勢は、山の頂に降り注ぐ天の河のように輝いた。
19
Sanskrit
setutvaṃ dadhati payomucāṃ vitāne saṃrambhād abhipatato rathāñ javena / āninyur niyamitaraśmibhugnaghoṇāḥ kṛcchreṇa kṣitim avanāmitas turaṅgāḥ //
Praharṣiṇī
和訳
雲の帷が橋のようになす中を、勢いよく突進する戦車を曳いて、手綱を引き絞られ鼻面を曲げた馬たちは、辛うじて地上へ戦車を導き下ろした。
20
Sanskrit
māhendraṃ nagam abhitaḥ kareṇuvaryāḥ paryantasthitajaladā divaḥ patantaḥ / sādṛśyaṃ nilayananiṣprakampapakṣair ājagmur jalanidhiśāyibhir nagendraiḥ //
Praharṣiṇī
和訳
天から降りてインドラの山の周りに降り立つ、雲をまとった巨大な象たちは、海に眠り翼を折り畳んだ山王たちに似ていた。

山はかつて翼を持っていたがインドラに切り落とされ、海に逃げた一部の山だけが翼を保ったとされる伝承。象をまとう雲が「翼」に見立てられる。

21
Sanskrit
utsaṅge samaviṣame samaṃ mahādreḥ krāntānāṃ viyadabhipātalāghavena / ā mūlād upanadi saikateṣu lebhe sāmagrī khurapadavī turaṅgamāṇām //
Praharṣiṇī
和訳
大山の起伏ある頂上を空中飛行の軽やかさで均等に駆けた馬たちの蹄の跡は、山麓の河辺の砂地に至ってようやく完全な形を得た。

険しい頂では馬が空中に浮くように走るため蹄跡が途切れるが、平坦な砂地に降りて初めて連続した足跡になるという着想。

22
Sanskrit
sadhvānaṃ nipatitanirjharāsu mandraiḥ saṃmūrchan pratininadair adhityakāsu / udgrīvair ghanaravaśaṅkayā mayūraiḥ sotkaṇṭhaṃ dhvanir upaśuśruve rathānām //
Praharṣiṇī
和訳
滝の落ちる高台で反響し増幅された戦車の轟音を、雷の音と勘違いした孔雀たちが首を伸ばして切望をもって聞き入った。
23
Sanskrit
sambhinnām aviralapātibhir mayūkhair nīlānāṃ bhṛśam upamekhalaṃ maṇīnām / vicchinnām iva vanitā nabhontarāle vaprāmbhaḥsrutim avalokayāṃbabhūvuḥ //
Praharṣiṇī
和訳
青い宝石から絶え間なく放たれる光線で岸辺の端まで深く染められた水の流れを、天女たちは空から見下ろした。あたかも途切れた水の流れのように。
24
Sanskrit
āsannadvipapadavīmadānilāya krudhyanto dhiyam avamatya dhūrgatānām / savyājaṃ nijakariṇībhir āttacittāḥ prasthānaṃ surakariṇaḥ kathaṃcid īṣuḥ //
Praharṣiṇī
和訳
近くの野生象の足跡から漂う発情の匂いに激昂し、象使いの命令を無視する神々の象たちは、本心では自分の雌象に心を奪われながらも、かろうじて前進を続けた。
25
Sanskrit
nīrandhraṃ pathiṣu rajo rathāṅganunnaṃ paryasyan navasalilāruṇaṃ vahantī / ātene vanagahanāni vāhinī sā gharmāntakṣubhitajaleva jahnukanyā //
Praharṣiṇī
和訳
道に車輪が巻き上げた途切れなき土埃を撒き散らし、新しい泥水のように赤味を帯びて、かの軍勢は森の茂みに広がった。夏の終わりに水が濁ったジャフヌの娘（ガンガー）のように。
26
Sanskrit
sambhogakṣamagahanām athopagaṅgaṃ bibhrāṇāṃ jvalitamaṇīni saikatāni / adhyūṣuś cyutakusumācitāṃ sahāyā vṛtrārer aviralaśādvalāṃ dharitrīm //
Praharṣiṇī
和訳
そこでインドラの仲間たち（ガンダルヴァ）は、ガンガーの畔の、楽しむに適した茂み、光る宝石を散りばめた砂洲、散り落ちた花に覆われ、青草の絶えない大地に陣を敷いた。
27
Sanskrit
bhūbhartuḥ samadhikam ādadhe tadorvyāḥ śrīmattāṃ harisakhavāhinīniveśaḥ / saṃsaktau kim asulabhaṃ mahodayānām ucchrāyaṃ nayati yadṛcchayāpi yogaḥ //
Praharṣiṇī
和訳
ハリ（インドラ）の仲間の軍勢が駐屯したことで、山の大地はいっそう華やかさを増した。偉大なる者たちの結びつきに何が得がたいであろうか。偶然の出会いでさえ高みへ導くのだ。
28
Sanskrit
sāmodāḥ kusumataruśriyo viviktāḥ sampattiḥ kisalayaśālinīlatānām / sāphalyaṃ yayur amarāṅganopabhuktāḥ sā lakṣmīr upakurute yayā pareṣām //
Praharṣiṇī
和訳
花樹の芳しく孤独な美も、新芽を湛えた蔓草の豊かさも、天女たちに享受されて初めて実を結んだ。他者をも幸せにする富こそ真の繁栄である。
29
Sanskrit
klānto 'pi tridaśavadhūjanaḥ purastāl līnāhiśvasitavilolapallavānām / sevyānāṃ hatavinayair ivāvṛtānāṃ samparkaṃ pariharati sma candanānām //
Praharṣiṇī
和訳
疲れていても天女たちは、潜む蛇の息吹に揺れる葉を持つ白檀の木——近づくに値するが無法者に囲まれた尊敬すべき人のような——との接触を避けた。

白檀の木は涼しく快いが蛇が棲みつくことで知られる。高潔だが悪党に取り囲まれた人物に近づきにくいのと同じだという巧みな喩え。

30
Sanskrit
utsṛṣṭadhvajakuthakaṅkaṭā dharitrīm ānītā viditanayaiḥ śramaṃ vinetum / ākṣiptadrumagahanā yugāntavātaiḥ paryastā giraya iva dvipā virejuḥ //
Praharṣiṇī
和訳
旗、布、鎧を外されて休息のために地上に降ろされた象たちは、世界の終末の嵐に木々や茂みを吹き飛ばされた山々のように見えた。
31
Sanskrit
prasthānaśramajanitāṃ vihāya nidrām āmukte gajapatinā sadānapaṅke / śayyānte kulam alināṃ kṣaṇaṃ vilīnaṃ saṃrambhacyutam iva śṛṅkhalaṃ cakāśe //
Praharṣiṇī
和訳
旅の疲れから眠りを振り払って立ち上がった象王が去った後の、発情液の泥に汚れた寝床の端に一瞬留まっていた蜂の群れは、急いで落ちた鎖のように見えた。
32
Sanskrit
āyastaḥ surasaridogharuddhavartmā samprāptuṃ vanagajadānagandhi rodhaḥ / mūrdhānaṃ nihitaśitāṅkuśaṃ vidhunvan yantāraṃ na vigaṇayāṃcakāra nāgaḥ //
Praharṣiṇī
和訳
天の河の激流に道を阻まれ、野生象の発情液の香る対岸に渡ろうと奮い、頭に突き立てられた鋭い鉤を振り払いつつ、象は象使いを顧みなかった。
33
Sanskrit
āroḍhuḥ samavanatasya pītaśeṣe sāśaṅkaṃ payasi samīrite kareṇa / saṃmārjann aruṇamadasrutī kapolau sasyande mada iva śīkaraḥ kareṇoḥ //
Praharṣiṇī
和訳
身を屈めて飲み残した水に鼻を恐る恐る差し入れた象の、赤い発情液の流れる両頬を洗い流す水飛沫は、あたかも発情液そのものが流れ出すかのようであった。
34
Sanskrit
āghrāya kṣaṇam atitṛṣyatāpi roṣād uttīraṃ nihitavivṛttalocanena / sampṛktaṃ vanakariṇāṃ madāmbusekair nāceme himam api vāri vāraṇena //
Praharṣiṇī
和訳
一瞬嗅いだだけで、激しい渇きにもかかわらず、目を怒りに見開いて対岸を睨む象は、野生象の発情液が混じった水を——たとえ冷たくとも——決して口にしなかった。
35
Sanskrit
praścyotanmadasurabhīṇi nimnagāyāḥ krīḍanto gajapatayaḥ payāṃsi kṛtvā / kiñjalkavyavahitatāmradānalekhair utteruḥ sarasijagandhibhiḥ kapolaiḥ //
Praharṣiṇī
和訳
滴り落ちる発情液で河の水を香しくしつつ戯れた大象たちは、蓮の雄蕊が赤い発情の筋に交じった、蓮の香りを帯びた頬をして岸に上がった。
36
Sanskrit
ākīrṇaṃ balarajasā ghanāruṇena prakṣobhaiḥ sapadi taraṅgitaṃ taṭeṣu / mātaṅgonmathitasarojareṇupiṅgaṃ māñjiṣṭhaṃ vasanam ivāmbu nirbabhāse //

軍勢の巻き上げた深紅の土埃に覆われ、岸辺で急に波立ち、象が踏み荒らした蓮の花粉で黄色く染まった水は、茜染めの衣のように輝いた。
37
Sanskrit

Praharṣiṇī

38
Sanskrit
niḥśeṣaṃ praśamitareṇu vāraṇānāṃ srotobhir madajalam ujjhatām ajasram / āmodaṃ vyavahitabhūripuṣpagandho bhinnailāsurabhim uvāha gandhavāhaḥ //
Praharṣiṇī

絶えず発情液の流れで土埃を完全に洗い流す象たちの芳香を、風は、多くの花の香りとカルダモンの香りを交えて運んだ。
39
Sanskrit
sādṛśyaṃ dadhati gabhīrameghaghoṣair unnidrakṣubhitamṛgādhipaśrutāni / ātenuś cakitacakoranīlakaṇṭhān kacchāntān amaramahebhabṛṃhitāni //
Praharṣiṇī
和訳
深い雷鳴に似た神々の大象の咆哮は、眠りから覚めた獅子を興奮させ、チャコーラ鳥と孔雀を驚かせつつ、岸辺の茂みの果てまで響き渡った。

Sanskrit
sāsrāvasaktakamanīyaparicchadānām adhvaśramāturavadhūjanasevitānām / jajñe niveśanavibhāgapariṣkṛtānāṃ lakṣmīḥ puropavanajā vanapādapānām //
Vasantatilakā
和訳
美しい衣装が枝に掛けられ、旅の疲れに悩む天女たちが憩い、陣営の区画で整えられた森の木々には、都の庭園に生まれるような優美さが現れた。
iti bhāravikṛtau mahākāvye kirātārjunīye saptamaḥ sargaḥ //
