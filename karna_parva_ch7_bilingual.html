マハーバーラタ ― カルナ篇 第7章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 7 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ7」（アシュヴァッターマンの進言によりカルナが総大将に任命される章）です。各段落は原典の詩節番号（8-7-N）と和訳の段落番号が対応しています。
karṇaparva — saptamo'dhyāyaḥ (7)
第7章　アシュヴァッターマンの進言でカルナが総大将に任命される
sañjaya uvāca|
hate droṇe maheṣvāse tasminnahani bhārata|
kṛte ca moghasaṃkalpe droṇaputre mahārathe|| // 8-7-1 //
サンジャヤは語った。 （1）バーラタよ、偉大な弓の使い手ドローナがその日殺され、偉大な戦車戦士ドローナの息子（アシュヴァッターマン）の決意が空しくなった時——
dravamāṇe mahārāja kauravāṇāṃ balārṇave|
vyūhya pārthaḥ svakaṃ sainyam atiṣṭhad vātṛbhir vṛtaḥ|| // 8-7-2 //
（2）大王よ、カウラヴァの大軍が潰走する中、パールタ（ユディシュティラ）は自軍を整え、兄弟たちに囲まれて陣を構えました。
tam avasthitam ājñāya putraste bharatarṣabha|
vidrutaṃ svabalaṃ dṛṣṭvā pauruṣeṇa nyavārayat|| // 8-7-3 //
（3）それが陣を張ったと知り、バーラタの雄牛よ、おまえの息子は、自軍が潰走するのを見て、自らの武勇をもって押しとどめました。
svam anīkam avasthāpya bāhuvīryam upāśritaḥ|
yuddhā ca suciraṃ kālaṃ pāṇḍavaiḥ saha bhārata|| // 8-7-4 //
（4）自軍を立て直し、腕の力を頼りに、バーラタよ、長い間パーンダヴァたちと戦いました。
labdhalakṣaiḥ parair haṣṭair vyāyacchadbhiś ciraṃ tadā|
sandhyākālaṃ samāsādya pratyāhāram akārayat|| // 8-7-5 //
（5）勝利をつかんだ敵が喜んで力を尽くす中、黄昏の時を迎えて、撤退を命じました。
'niveśya balavadvoraṃ kṣutpipāsābalair yutam|
śrameṇa mahatā yuktaṃ tathā droṇavadhena ca||
dīnarūpā raṇe karma kṛtvā ghoraṃ ca śarvarīm|
viśaṃ prāpya sā senā viśramya muditā'bhavat'|| // 8-7-6-7 //
（6〜7）疲労と飢えと渇きに苛まれ、またドローナの死による深い悲しみに満ちた、意気消沈した軍は、夜に入って自陣に戻り、休息して元気を取り戻しました。
kṛtvā'vahāraṃ sainyānāṃ praviśya śibiraṃ svakam|
kuravaḥ sahitā mantraṃ mantrayāñcakrire mithaḥ|| // 8-7-8 //
（8）軍を撤退させ、自陣に入ってから、クルの者たちは集まって互いに協議しました。
paryaṅkeṣu parārdhyeṣu spardhyāstaraṇavatsu ca|
varāsaneṣūpaviṣṭāḥ sukhaśayyāsvivāmarāḥ|| // 8-7-9 //
（9）最上の長椅子に、見事な敷物を敷いた豪華な座に座り、天上の神々が安楽な寝台にいるように。
tato duryodhano rājā sāmnā paramavalgunā|
tānābhāṣya maheṣvāsān prāptakālam abhāṣata|| // 8-7-10 //
（10）そこでドゥルヨーダナ王は、最も甘美な融和の言葉をもって、偉大な弓の使い手たちに語りかけ、時宜にかなった言葉を述べました。
mataṃ matimatāṃ śreṣṭhāḥ sarve prabrūta mā ciram|
evaṅgatena yatkāryaṃ bhavet kāryataraṃ nṛpāḥ|| // 8-7-11 //
（11）「知恵ある者たちの中の最上者よ、すべての者が意見を述べよ、遅れることなく。このような事態において何をなすべきか、最も緊急なことを、王たちよ。」
sañjaya uvāca|
evamukte narendreṇa narasiṃhā yuyutsavaḥ|
cakrur nānāvidhāś ceṣṭāḥ siṃhāsanagatās tadā|| // 8-7-12 //
サンジャヤは語った。 （12）王にこう言われて、戦いを望む人の中の獅子たちは、王座に座ったまま、さまざまな仕草を見せました。
teṣāṃ niśāmyeṅgitāni yuddhe prāṇāñ juhūṣatām|
samudvīkṣya mukhaṃ rājño bālārkasamavarcasam|
ācāryaputro medhāvī vākyajño vākyamādade|| // 8-7-13 //
（13）戦いに命を捧げようとする者たちの仕草を見て、朝日のような輝きを持つ王の顔を見上げて、知恵ある師の息子（アシュヴァッターマン）は、言葉の達人として言葉を発しました。
rāgo yogastathā dākṣyāṃ nayaś cetyarthasādhakāḥ|
upāyāḥ paṇḍitaiḥ proktāste tu daivam upāśritāḥ|| // 8-7-14 //
（14）「信仰心、好機、巧みさ、政策——これらは目的達成の手段であると賢者たちは説く。しかしそれらもまた運命に依拠している。
lokapravīrā ye'smākaṃ devakalpā mahārathāḥ|
nītimantastathā yuktā dakṣā raktāśca te hatāḥ|| // 8-7-15 //
（15）我が方の世界の精鋭、神に等しい偉大な戦車戦士たちは、政策に通じ、準備万端で、巧みで、忠誠に厚かったが、殺された。
na tveva kāryaṃ nairāśyam asmābhir vijayaṃ prati|
sunītairiha sarvārthair daivam apy anulomyate|| // 8-7-16 //
（16）だからといって勝利に絶望すべきではない。正しく導かれた手段によって、運命すらも味方につけることができるのだから。
te vayaṃ pravaraṃ nṝṇāṃ sarvair yodhaguṇair yutam|
karṇam evābhiṣebhyāmaḥ saināpatyena bhārata|| // 8-7-17 //
（17）我々はすべての戦士の美徳を備えた最上の者、バーラタよ、カルナを総大将に就任させよう。
karṇaṃ senāpatiṃ kṛtvā pramathiṣyāmahe ripūn|| // 8-7-18 //
（18）カルナを総大将にして、敵を打ち砕こうではないか。
eṣa hyatibalaḥ śūraḥ kṛtāstro yuddhadurmadaḥ|
vaivasvata ivāsahyaḥ śakto jetuṃ raṇe nipūn|| // 8-7-19 //
（19）この者こそ極めて強く、勇敢で、武器に通じ、戦いに酔いしれる者だ。ヴァイヴァスヴァタ（ヤマ）のように耐えがたく、戦場で敵を征服する力がある。」
etad ācāryatanayāc chrutvā rājaṃstavātmajaḥ|
'duryodhano mahārāja bhṛśaṃ prītamanāstadā'|| // 8-7-20 //
（20）大王よ、師の息子からこれを聞いて、おまえの息子は大いに喜びました。
āśāṃ bahumatīṃ cakre varṇaṃ prati sa vai tadā|
hate bhīṣme ca droṇe ca karṇo jeṣyati pāṇḍavān|| // 8-7-21 //
（21）カルナに対する大きな期待を抱いたのです。ビーシュマとドローナが殺された今、カルナこそがパーンダヴァたちを打ち負かすだろうと。
tāmāśāṃ hṛdaye kṛtvā samāśvasya ca bhārata|
tato duryodhanaḥ prītaḥ priyaṃ śrutvā'sya tadvacaḥ|
prītisatkārasaṃyuktaṃ tathyamātmahitaṃ śūbham||
svaṃ manaḥ samavasthāpya bāhuvīryam upāśritaḥ||
'priyasatkārasaṃyuktaṃ tathyamātmahite ratam'|
duryodhano mahārāja rādheyam idam abravīt|| // 8-7-22-24 //
（22〜24）その期待を胸に抱き、バーラタよ、自らの心を奮い立たせ、腕の力を頼りにして、大王よ、ラーデーヤ（カルナ）にこう言いました。
karṇa jānāmi te vīryaṃ sauhṛdaṃ paramaṃ mayi|
tathā'pi tvāṃ mahābāho pravakṣyāmi hitaṃ vacaḥ|| // 8-7-25 //
（25）「カルナよ、おまえの武勇を私は知っている。そして私に対するおまえの最大の友情も。それでもなお、大いなる腕の者よ、有益な言葉をおまえに語ろう。
śrutvā yatheṣṭaṃ ca kuru vīra yattava rocate|
bhavān prājñatamo nityaṃ mama caiva parā gatiḥ|| // 8-7-26 //
（26）聞いた上で、勇者よ、おまえの思うとおりにせよ。おまえは常に最も賢き者であり、私にとって最後の拠り所だ。
bhīṣmadroṇāvatirathau hatau senāpatī mama|
senāpatir bhavān astu tābhyāṃ draviṇavattaraḥ|| // 8-7-27 //
（27）ビーシュマとドローナという二人のアティラタ（最上の戦車戦士）が、我が総大将として殺された。おまえが総大将となれば、あの二人よりも力あるものとなろう。
vṛddho ca tau maheṣvāsau sāpekṣo ca dhanañjaye|
mānitau ca mayā vīrau rādheya vacanāttava|| // 8-7-28 //
（28）あの二人の偉大な弓の使い手は年老いており、ダナンジャヤ（アルジュナ）にえこひいきしていた。ラーデーヤよ、おまえの言葉に従って私はあの二人を敬っていたのだ。
pitāmahatvaṃ samprekṣya pāṇḍuputrā mahāraṇe|
rakṣitāstāta bhīṣmeṇa divasāni daśaiva tu|| // 8-7-29 //
（29）祖父としての立場を顧みて、パーンドゥの息子たちは大合戦において、ビーシュマに十日間守られていたのだ。
nyastaśastre tu bhavati hato bhīṣmaḥ pitāmahaḥ|
śikhaṇḍinaṃ puruskṛtya phalgunena mahāhave|| // 8-7-30 //
（30）武器を捨てたビーシュマは、祖父として、シカンディンを前に立てたファルグナ（アルジュナ）に大合戦で殺された。
hate tasmin maheṣvāse śaratalpagate tathā|
tvayokte puruṣavyāghra droṇo hyāsīt puraḥsaraḥ|| // 8-7-31 //
（31）あの偉大な弓の使い手が矢の床に横たわった後、おまえの言葉で、人の中の虎よ、ドローナが先頭に立った。
tenāpi rakṣitāḥ pārthāḥ śiṣyatvāditi me matiḥ|
sa cāpi nihato vṛddho dhṛṣṭadyumnena satvaram|| // 8-7-32 //
（32）あの者もまた、弟子であるがゆえにパールタたちを守っていたと私は思う。あの老いた者もまた、ドリシュタデュムナに速やかに殺された。
nihatābhyāṃ pradhānābhyāṃ tābhyām atulavikrama|
tvatsamaṃ samare yodhaṃ nānyaṃ paśyāmi cintayan|| // 8-7-33 //
（33）精鋭が二人とも殺された今、比類なき武勇の者よ、戦いにおいておまえに匹敵する戦士を、私はいくら考えても他に見出せない。
bhavāneva tu naḥ śakto vijayāya na saṃśayaḥ|
pūrvaṃ madhye ca paścāśca tathaiva vihitaṃ hitam|| // 8-7-34 //
（34）おまえだけが我々の勝利のために力を持つ者だ、疑いなく。始めにも中程にも最後にも、そのようにおまえは配置した。
sa bhavān dhuryavat saṅkhye dhuram udvo'ḍhum arhati|
abhiṣecaya sainānye svayamātmānamātmanā|| // 8-7-35 //
（35）そのおまえが、戦いの軛に雄牛のように重荷を担ってくれ。自ら自らを総大将として灌頂せよ。
devatānāṃ yathā skandaḥ senānīḥ prabhuravyayaḥ|
tathā bhavānimāṃ senāṃ dhārtarāṣṭrīṃ bibhartu vai|| // 8-7-36 //
（36）神々にとってスカンダが総大将であり、不滅の主であるように、おまえもこのドリタラーシュトラの軍を支えよ。
jahi śatrugaṇān sarvān mahendro dānavāniva|
avasthitaṃ rame dṛṣṭvā pāṇḍavāstvāṃ mahārathāḥ|
draviṣyanti ca pāñcālā viṣṇuṃ dṛṣṭveva dānavāḥ|| // 8-7-37 //
（37）マヘーンドラ（インドラ）がダーナヴァたちを滅ぼすように、すべての敵の群れを討て。戦場でおまえが構えているのを見れば、偉大な戦車戦士パーンダヴァたちは逃げ出すだろう。パーンチャーラ族もまた、ヴィシュヌを見たダーナヴァたちのように。
tasmāttvaṃ puruṣavyāghra prakarṣaitāṃ mahācamūm|| // 8-7-38 //
（38）だから、人の中の虎よ、この大軍を率いて引き出してくれ。
bhavatyavasthite yatte pāṇḍavā mandacetasaḥ|
draviṣyanti sahāmātyāḥ pāñcālāḥ sṛñjayāśca ha|
yathā hyabhyuditaḥ sūryaḥ pratapansvena tejasā|
vyapohati tamastīvraṃ tathā śatrūn pratāpaya|| // 8-7-39-40 //
（39〜40）おまえが構えていれば、パーンダヴァたちは愚かな心で逃げ出すだろう。パーンチャーラ族もスリンジャヤ族も味方もろとも。昇る太陽がその熱で濃い闇を払うように、敵を焼き尽くせ。」
sañjaya uvāca|
evamuktastu rādheyo rājñā duryodhanena ha|
rājñāṃ madhye mahābāhuḥ prītātmā sa mahābalaḥ|
harṣayann abravīt karṇo duryodhanamidaṃ vacaḥ|| // 8-7-41 //
サンジャヤは語った。 （41）大王よ、ドゥルヨーダナ王にこう言われて、大いなる腕の者ラーデーヤは、喜んだ心で、偉大な力の者として、王たちの只中で、ドゥルヨーダナを喜ばせてこう言いました。
karṇa uvāca|
uktametanmayā pūrvaṃ gāndhāre tava sannidhau|
jeṣyāmi pāṇḍavān sarvān saputrān sajanārdanān|| // 8-7-42 //
カルナは語った。 （42）「以前から私はおまえの面前で申し上げていた、ガーンダーラよ。パーンダヴァたちを息子もろとも、ジャナールダナ（クリシュナ）もろとも打ち負かすと。
senāpatir bhaviṣyāmi tavāhaṃ nātra saṃśayaḥ|
sthiro bhava mahārāja jitānvidvi ca pāṇḍavān|| // 8-7-43 //
（43）おまえの総大将となろう、疑いはない。大王よ、心を定めよ。パーンダヴァたちは敗れたと知れ。」
sañjaya uvāca|
evamukto mahārāja tato duryādhano nṛpaḥ|
uttasthau rājabhiḥ sārdhaṃ devairiva śatakratuḥ|| // 8-7-44 //
サンジャヤは語った。 （44）大王よ、こう言われてドゥルヨーダナ王は、王たちとともに立ち上がった。シャタクラトゥ（インドラ）が神々とともに立つように。
saināpatyena satkartuṃ karṇaṃ skandamivāmarāḥ|
tato'bhiṣiṣicuḥ karṇaṃ vidhidṛṣṭena karmaṇā|| // 8-7-45 //
（45）カルナを総大将として讃え、不死の者たちがスカンダを讃えるように、聖典に定められた儀式によってカルナに灌頂を行いました。
duryodhanamuktā rājan rājāno vijayaiṣiṇaḥ|
śātakumbhamayaiḥ kumbher māheyaiś cābhimantritaiḥ||
toyapūrṇair viṣāṇaiśca dvipakhaṅgamaharṣabhaiḥ|
maṇimuktāyutaiścānyaiḥ puṇyagandhais tathauṣadhaiḥ||
audumbare sukhāsīnam āsane kṣaumasaṃvṛte|
śāstradṛṣṭena vidhinā sambhāraiśca susambhṛtaiḥ|| // 8-7-46-48 //
（46〜48）黄金の瓶、大地から作った聖句で祝福された瓶、水を満たした象の角と犀の角と大牛の角、宝石と真珠をちりばめた瓶、吉祥の香を持つ薬草とともに——ウドゥンバラ（無花果樹）の座に、亜麻の布を敷いた安楽の座に座らせ、聖典に定められた儀式と資材を整えて。
brāhmaṇaḥ kṣatriyā vaiśyāstathā śūdrāśca sammatāḥ|
tuṣṭuvus taṃ mahātmānam abhiṣiktaṃ varāsane|| // 8-7-49 //
（49）バラモン、クシャトリヤ、ヴァイシャ、そしてシュードラも、灌頂を受けて最上の座に着いた偉大な魂の者を讃えました。
tato'bhiṣikte rājendra niṣkair gobhir dhanena ca|
vācayāmāsa viprāgryān rādheyaḥ paravīrahā|| // 8-7-50 //
（50）大王よ、灌頂を受けたラーデーヤ、敵の勇者を殺す者は、金貨と牛と財で最上のバラモンたちに布施をさせました。
'sa vyarocata rādheyaḥ sūtamāgadhabandibhiḥ|
stūyamāno yathā bhānurudaye brahmavādibhiḥ||
tataḥ puṇyāhaghoṣeṇa vāditraninadena ca|
jayaśabdena śūrāṇāṃ tumulaḥ sarvato'bhavat||
jayety ūcur nṛpāḥ sarve rādheyaṃ tatra saṅgatāḥ'|| // 8-7-51-53 //
（51〜53）ラーデーヤは、スータ（吟遊詩人）やマーガダ（讃歌師）やバンディン（讃美者）たちに讃えられて輝いた。日の出に梵行者たちに讃えられる太陽のように。吉祥の唱えの声、楽器の響き、勇者たちの「勝利あれ」という声で、あらゆる方角が大きな轟きに満たされた。集まった王たちも皆、ラーデーヤに「勝利あれ」と唱えた。
jaya pārthān sagovindān sānugāṃs tān mahāmṛdhe|
iti taṃ bandinaḥ prāhur dvijāśca puruṣarṣabham||
jahi pārthān sapāñcālān rādheya vijayāya naḥ|
udyanniva sadā bhānus tamāṃsy ugrair gabhastibhiḥ||
na hyalaṃ tvadvisṛṣṭānāṃ śarāṇāṃ vai sakeśavāḥ|
ulūkāḥ sūryaraśmīnāṃ jvalatāmiva darśane||
na hi pārthāḥ sapāñcālāḥ sthātuṃ śaktās tavāgrataḥ|
āttavajrasya samare mahendrasyeva dānavāḥ|| // 8-7-54-57 //
（54〜57）バラモンたちも吟遊詩人たちも、人の中の最上者に言った——「パールタたちを倒せ、ゴーヴィンダ（クリシュナ）の追随者もろとも。ラーデーヤよ、我々の勝利のために。常に昇る太陽が激しい光線で闇を払うように。おまえが放つ矢の前には、ケーシャヴァ率いるパールタたちは堪えられまい。燃え輝く太陽の光線の前のフクロウたちのように。パールタたちはパーンチャーラたちとともに、おまえの前に立つことなどできはしない。金剛杵を構えたマヘーンドラの前のダーナヴァたちのように。」
'sañjaya uvāca|
sa satkṛtaḥ stūyamānaḥ suhṛdgaṇavṛto ruṣā|
karṇo duryodhanaṃ vākyam abravīt prahasan priyam||
duryodhanādya sagaṇaṃ pāṇḍūnāṃ pravaraiḥ saha|
phalgunaṃ sūdayiṣyāmi tvatpriyārthaṃ sabāndhavam||
saparvatārṇavadvīpāṃ śādhi gāṃ gatapāṇḍavām|
putrapautraprapautreṣu pratiṣṭhāṃ gamayiṣyami||
nāsahyaṃ vidyate mahyaṃ tvatpriyārtham arindama|
satyadharmānuraktasya siddhirātmavato yathā|| // 8-7-58-61 //
サンジャヤは語った。 （58〜61）こうして讃えられ、友人たちに囲まれ、怒りに満ちたカルナは、ドゥルヨーダナに笑いながら親しみを込めてこう言いました。「ドゥルヨーダナよ、今日、味方もろともパーンドゥの精鋭たちとともに、ファルグナ（アルジュナ）を倒してみせよう、おまえを喜ばせるために、一族もろとも。パーンダヴァのいなくなった大地を——山と海と島を持つ大地を——治めよ。息子・孫・曾孫の繁栄のもとに。おまえの利益のために、私に不可能なことなどない。敵を滅ぼす者よ。真実にダルマを奉じ、心を制した者に成就があるように。」
abhiṣiktastu rāgheyaḥ prabhayā so'mitaprabhaḥ|
atyaricyata rūpeṇa divākara ivāparaḥ||
saināpatye tu rādheyam abhiṣicya sutastava|
amanyata tadātmānaṃ kṛtārthaṃ kālacoditaḥ|| // 8-7-62-63 //
（62〜63）灌頂を受けたラーデーヤは、その光輝によって計り知れぬ輝きを放ち、もう一つの太陽のように輝いた。ラーデーヤに総大将の位を授けて、おまえの息子は、時に駆り立てられた者として、自らの目的は達せられたと思った。
karṇo'pi rājñaḥ saṃprāpya saināpatyam arindamaḥ|
yogamājñāpayāmāsa sūryasyodayanaṃ prati|| // 8-7-64 //
（64）カルナもまた王から総大将の位を得て、敵を滅ぼす者として、日の出に向けて出陣を命じました。
tava putrairvṛtaḥ karṇaḥ śuśubhe tatra bhārata|
devairiva yathā skandaḥ saṅgrāme tārakāmaye|| || // 8-7-65 //
（65）バーラタよ、おまえの息子たちに囲まれたカルナは、そこで輝いた。ターラカーマヤ（ターラカの戦い）においてスカンダ（軍神）が神々に囲まれて輝いたように。
iti śrīmanmahābhārate karṇaparvaṇi saptamo'dhyāyaḥ|| 7 ||
こうして、聖なる大マハーバーラタのカルナ篇の第七章は終わる。
