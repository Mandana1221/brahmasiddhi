本章は南伝（Southern Recension）テキストの「アディヤーヤ20」（ユディシュティラがドゥルヨーダナを破る場面。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-20-N）と和訳の段落番号が対応しています。
karṇaparva — viṃśo'dhyāyaḥ (20)
第20章　ユディシュティラがドゥルヨーダナを破る
dhṛtarāṣṭra uvāca|
atitīvrāṇi duḥkhāni duḥsahāni bahūni ca|
tvatto'haṃ sañjayāśrauṣaṃ putrāṇāṃ caiva saṅkṣayam|| // 8-20-1 //
ドリタラーシュトラは語った。 （1）サンジャヤよ、お前から極めて激しく耐え難い多くの苦しみと、息子たちの滅亡を聞いた。
yathā tvaṃ me kathayase yathā yuddham avartata|
na santi sūta kauravyā iti me niścitā matiḥ|| // 8-20-2 //
（2）お前が語るような戦いの有様では、サンジャヤよ、カウラヴヤ族はもういないというのが私の確信だ。
duryodhanaśca virathaḥ kṛtas tatra mahārathaḥ|
dharmaputraḥ kathaṃ cakre tasya vā nṛpatiḥ katham|| // 8-20-3 //
（3）ドゥルヨーダナもその場で戦車を失わされた偉大な戦車戦士となった。ダルマの子はどうしたのか、またあの王（ドゥルヨーダナ）はどうしたのか。
aparāhṇe kathaṃ yuddham abhavad romaharṣaṇam|
tanmamācakṣva tattvena kuśalo hyasi sañjaya|| // 8-20-4 //
（4）午後にどのように身の毛もよだつ戦闘が行われたのか。その真実を語ってくれ。お前は語るのが上手だ、サンジャヤよ。
sañjaya uvāca|
saṃsakteṣu tu sainyeṣu vadhyamāneṣu bhāgaśaḥ|
rathamanyaṃ samāsthāya putras tava viśāmpate|| // 8-20-5 //
サンジャヤは語った。 （5）王よ、両軍が入り乱れ、各所で打たれている中、あなたの息子は別の戦車に乗り——
krodhena mahatā yuktaḥ saviṣo bhujago yathā|
duryodhanaḥ samālakṣya dharmarājaṃ yudhiṣṭhiram|
provāca sūtaṃ tvarito yāhiyāhīti bhārata|| // 8-20-6 //
（6）毒蛇のように大いなる怒りに満ちて、ダルマ王ユディシュティラを見据え、バーラタよ、御者に「行け、行け！」と急かしました。
tatra māṃ prāpaya kṣipraṃ sārathe yatra pāṇḍavaḥ|
dhriyamāṇātapatreṇa rājā rājati daṃśitaḥ|| // 8-20-7 //
（7）「御者よ、あの傘に守られ武装して輝くパーンダヴァのいるところへ、素早く連れて行け。」
sa sūtaścodito rājñā rājñaḥ syandanamuttamam|
yudhiṣṭhirasyābhimukhaṃ preṣayāmāsa saṃyuge|| // 8-20-8 //
（8）王に急かされた御者は、王の最上の戦車をユディシュティラに向かって走らせました。
tato yudhiṣṭhiraḥ kruddhaḥ prabhinna iva kuñjaraḥ|
sārathiṃ codayāmāsa yāhi yatra suyodhanaḥ|| // 8-20-9 //
（9）怒ったユディシュティラは、発情した象のように、御者に命じました。「スヨーダナ（ドゥルヨーダナ）のいるところへ行け。」
tau samājagmaturvīrau bhrātarau rathasattamau|| // 8-20-10 //
（10）二人の勇猛な兄弟は、最上の戦車戦士として出会いました。
sametya ca mahāvīrau saṃrabdhau yuddhadurmadau|
vavarṣatur maheṣvāsau śarair anyonyam āhave|| // 8-20-11 //
（11）出会った二人の大勇者は、怒りに燃え、戦いに酔い、偉大な弓兵として戦場で互いに矢を浴びせかけました。
tato duryodhano rājā dharmaśīlasya māriṣa|
śilāśitena bhallena dhanuściccheda saṃyuge|| // 8-20-12 //
（12）ドゥルヨーダナ王は、法に従う者（ユディシュティラ）の弓を、石に研がれた矢尻の矢で戦場において断ち切りました。
taṃ na amṛṣyata saṅkruddho hyavamānaṃ yudhiṣṭhiraḥ|
apavidhya dhanuśchinnaṃ krodhasaṃraktalocanaḥ|| // 8-20-13 //
（13）激怒したユディシュティラはこの侮辱を許さず、切り裂かれた弓を投げ捨て、怒りに目を赤くして——
anyatkārmukamādāya dharmaputraścamūmukhe|
duryodhanasya ciccheda dhvajaṃ kārmukameva ca|| // 8-20-14 //
（14）別の弓を取り、軍の正面でドゥルヨーダナの旗と弓を断ち切りました。
athānyad dhanurādāya putra te bharatarṣabha|
yudhiṣṭhirasya cikṣepa śarān kanakabhūṣaṇān|
rukmapuṅkhān prasannāgrān saviṣān iva pannagān|| // 8-20-15 //
（15）バーラタの雄牛よ、あなたの息子は別の弓を取り、金で飾られた、金の矢尻の、澄んだ先端の、毒蛇のような矢をユディシュティラに放ちました。
tāvanyonyaṃ susaṅkruddhau śastravarṣāṇy amuñcatām|
siṃhāv iva susaṃrabdhau parasparajigīṣayā|| // 8-20-16 //
（16）激怒した二人は武器の雨を浴びせ合いました。互いに勝利を望む、怒れる二頭の獅子のように。
jaghnatus tau raṇe'nyonyaṃ nardamānau vṛṣāv iva|
antaraṃ mārgamāṇau ca ceratus tau mahārathau|| // 8-20-17 //
（17）吼える二頭の雄牛のように戦場で互いを打ち合い、隙を探しながら、二人の偉大な戦車戦士は動き回りました。
tataḥ pūrṇāyatotsṛṣṭaiḥ śarais tau tu kṛtavraṇau|
virejatur mahārāja kiṃśukāv iva puṣpitau|| // 8-20-18 //
（18）大王よ、十分に引き絞って放たれた矢で傷だらけになった二人は、花咲くキンシュカの木のように美しく輝きました。
tato rājan vimuñcantau siṃhanādān muhurmuhuḥ|
talayoś ca tathā śabdān dhanuṣaś ca mahāhave|| // 8-20-19 //
（19）王よ、二人は何度も何度も獅子の咆哮を上げ、手のひらを打つ音と弓の音を大戦闘で響かせました。
śaṅkhaśabdavarāṃś caiva cakratus tau nareśvarau|
anyonyaṃ tau mahārāja pīḍayāṃ cakratur bhṛśam|| // 8-20-20 //
（20）二人の王は法螺貝の最上の音も上げ、大王よ、互いを激しく苦しめました。
tato yudhiṣṭhiro rājā putraṃ tava śarais tribhiḥ|
ājaghāna urasi kruddho vajravegair durāsadaiḥ|| // 8-20-21 //
（21）ユディシュティラ王は怒り、金剛杵のような速さの近づき難い三本の矢で、あなたの息子の胸を打ちました。
prativivyādha taṃ tūrṇaṃ tava putro mahīpatiḥ|
pañcabhir niśitair bāṇaiḥ svarṇapuṅkhaiḥ śilāśitaiḥ|| // 8-20-22 //
（22）あなたの息子の王もまた素早く、金の矢尻で石に研がれた五本の鋭い矢でユディシュティラを射返しました。
tato duryodhano rājā śaktiṃ cikṣepa bhārata|
sarvapāraśavīṃ tīkṣṇāṃ maholkāpratimāṃ tadā|| // 8-20-23 //
（23）バーラタよ、ドゥルヨーダナ王は槍を投げつけました。すべてを滅ぼす鋭い、大きな流星のような槍を。
tām āpatantīṃ sahasā dharmarājaḥ śitaiḥ śaraiḥ|
tribhiś ciccheda sahasā taṃ ca vivyādha pañcabhiḥ|| // 8-20-24 //
（24）突然飛んでくるその槍を、ダルマ王は三本の鋭い矢で素早く断ち切り、ドゥルヨーダナをさらに五本の矢で射ちました。
nipapāta tataḥ sā'tha svarṇadaṇḍā mahāsvanā|
nipatantī maholkā iva vyarājacchikhisannibhā|| // 8-20-25 //
（25）金の柄のその大きな音を立てる槍は大地に落ちました。落ちながら大きな流星のように、火焔のように輝きました。
śaktiṃ vinihatāṃ dṛṣṭvā putras tava viśāmpate|
navabhir niśitair bhallair nijaghāna yudhiṣṭhiram|| // 8-20-26 //
（26）槍が打ち落とされたのを見て、王よ、あなたの息子は九本の鋭い矢尻の矢でユディシュティラを打ちました。
so'tividdho balavatā śatruṇā śatrutāpanaḥ|
duryodhanaṃ samuddiśya bāṇaṃ jagrāha satvaraḥ|| // 8-20-27 //
（27）敵を悩ます者ユディシュティラは、力ある敵に深く射られながらも、ドゥルヨーダナを狙って素早く矢を手に取りました。
samādhatta ca taṃ bāṇaṃ dhanurmadhye mahābalaḥ|
cikṣepa ca mahārāja tataḥ kruddhaḥ parākramī|| // 8-20-28 //
（28）大いなる力の者は弓の中央に矢を番え、大王よ、怒りと勇猛をもって放ちました。
sa tu bāṇaḥ samāsādya tava putraṃ mahāratham|
vyāmohayata rājānaṃ dharaṇīṃ ca dadāra ha|| // 8-20-29 //
（29）その矢はあなたの息子、偉大な戦車戦士のもとに至り、王を朦朧とさせ、大地をも穿ちました。
tato duryodhanaḥ kruddho gadām udyamya vegitaḥ|
vidhitsuḥ kalahasyāntaṃ dharmarājam upādravat|| // 8-20-30 //
（30）怒ったドゥルヨーダナは棍棒を振り上げ、勢いよく、争いに決着をつけようと、ダルマ王に襲いかかりました。
tam udyatagadaṃ dṛṣṭvā daṇḍahastam iva antakam|
dharmarājo mahāśaktiṃ prāhiṇottava sūnave|| // 8-20-31 //
（31）棍棒を振り上げたドゥルヨーダナを——棒を持った閻魔のように——見て、ダルマ王は大きな槍をあなたの息子に投げつけました。
dīpyamānāṃ mahāvegāṃ maholkāṃ jvalitām iva|
yamadaṇḍanibhāṃ ghorāṃ kālarātrim iva aparām|| // 8-20-32 //
（32）燃え上がり、大いなる速さを持ち、大きな流星のように燃え盛る——閻魔の杖のように恐ろしく、もう一つの死の夜のような槍を。
rathasthaḥ sa tayā viddho varma bhittvā stanāntare|
bhṛśaṃ saṃvignahṛdayaḥ papāta ca mumoha ca|| // 8-20-33 //
（33）戦車に乗ったままその槍に打たれたドゥルヨーダナは、鎧を貫かれて胸を射抜かれ、心を激しく震わせて倒れ、気を失いました。
nabhas tam āha ca tataḥ pratijñām anupālaya|
nāyaṃ vadhyas tava nṛpa ity uktaḥ sa nyavartata|| // 8-20-34 //
（34）天から声がして言いました——「誓いを守れ。この王はお前に殺される者ではない。」こう言われて、ユディシュティラは引き下がりました。
tatas tvaritam āgamya kṛtavarmā tavātmajam|
pratyapadyata rājānaṃ nimnaṃ vyasanārṇave|| // 8-20-35 //
（35）そこにクリタヴァルマンが急いで駆けつけ、あなたの息子を——災難の大海に沈みかけた王を——救い上げました。
gadām ādāya bhīmo'pi hemapaṭṭapariṣkṛtām|
abhidudrāva vegena kṛtavarmāṇam āhave|| // 8-20-36 //
（36）ビーマもまた、金の帯で飾られた棍棒を取り、勢いよくクリタヴァルマンに戦場で突進しました。
evaṃ tad abhavad yuddhaṃ tvadīyānāṃ paraiḥ saha|
aparāhṇe mahārāja kāṅkṣatāṃ vijayaṃ yudhi|| || // 8-20-37 //
（37）このようにして、大王よ、あなた方の者たちと敵との戦いは、午後に、戦場での勝利を求めて行われました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe viṃśo'dhyāyaḥ|| 20 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第二十章は終わる。
