चतुर्थः सर्गः

第四章　ライヴァタカ山の描写（raivatakavarṇana）

韻律：前半（1–18）upajāti（各pāda 11音節）、後半に各種韻律

Kṛṣṇaの旅路に姿を現すRaivataka山の壮大な景観。全68偈。

IV.1
Sanskrit (IAST) niḥśvāsadhūmaṃ saharatnabhābhir bhittvotthitaṃ bhūmim ivoragāṇām / nīlopalasyūtavicitradhātum asau giriṃ raivatakaṃ dadarśa //
和訳

藍玉（indranīla）で縫い合わされた色とりどりの鉱脈を有し、宝石の輝きとともに大地を突き破って立ち上がった蛇たちの吐息の煙のようなかのライヴァタカ山を、彼（Kṛṣṇa）は見た。

注

【Vallabhadeva】

蛇（uraga）たちが大地（bhūmi）を突き破って（bhittvā）噴き上げる吐息の煙（niḥśvāsa-dhūma）のように聳え立つ山と見立てる。煙に相当するのが nīlopala（藍玉）、宝石の輝きに相当するのが色とりどりの鉱脈（dhātu）。syūta（縫い合わされた）は√sīv（縫う）のkta。utprekṣā（詩的想像）のうち、特殊な性質（guṇa）に基づく種類の比喩とする。

【Mallinātha】

この章（sarga）では種々の韻律（nānāvṛtta）が用いられる。冒頭の18偈は upajāti（indravajrāとupendravajrāの混合）である。本章は章末まで山の描写（girivarṇana）に終始する。山が蛇の吐息の煙のごとく宝石の光とともに大地から隆起した姿に見立てる utprekṣā。特殊な性質（guṇa）を理由（nimitta）とし、その本質（svarūpa）に基づく種類。

IV.2
Sanskrit (IAST) gurvīr ajasraṃ dṛṣadaḥ samantād upary upary ambumucāṃ vitānaiḥ / vindhyāyamānaṃ divasasya bhartur mārgaṃ punā roddhumivonnamadbhiḥ //
和訳

重い岩塊を絶えず戴き、四方からますます高く聳え立つ雲の天蓋によって、日の主（太陽）の道を再び塞ごうとするかのごとく——ヴィンディヤ山さながらに振る舞う〔山を〕。

注

【Vallabhadeva】

vindhyāyamāna（ヴィンディヤ山のように振る舞う）：ヴィンディヤ山がかつて自らを高くして太陽の通行を阻んだという伝承に基づく。iva（〜のように）が utprekṣā の標識。dṛṣadaḥ（岩）は「岩の上方に」（upary upari）と解する。kartṛ-mārgam はVallの異読で「造物主の道」とするが、本テキストでは bhartur mārgam「〔日の〕主の道」を採る。

【Mallinātha】

gurvīḥ＝大きな〔岩塊〕。dṛṣadaḥ（石・岩）は Amarakośa に「pāṣāṇa, prastara, upala, aśman, śilā, dṛṣat」と挙げられる。upary upari（上へ上へと）は場所の近接を表す反復。ajasram＝絶えず。雲の天蓋（ambumucāṃ vitānaiḥ）が途切れなく湧き上がり太陽の道を再び塞ごうとする——この utprekṣā は行為（kriyā）を理由とし行為の本質に基づく種類とする。

IV.3
Sanskrit (IAST) krāntaṃ rucā kāñcanavaprabhājā navaprabhājālabhṛtāṃ maṇīnām / śritaṃ śilāśyāmalatābhirāmaṃ latābhir āmantritaṣaṭpadābhiḥ //
和訳

新鮮な光の網を帯びた宝石群の、黄金の台地から生まれた輝きに満たされ、岩の暗色ゆえに美しく、蜂たちを誘い寄せた蔓草に覆われた〔山を〕。

注

【Vallabhadeva】

黄金の台地（kāñcana-vapra）の光（bhā）に由来する（jā）輝き（rucā）に満たされた（krāntam）と解す。また蔓草（latā）に蜂（ṣaṭpada＝六本足の虫＝蜂）が集まるのは花蜜の香りゆえとする。岩（śilā）の黒さ（śyāmalatā）ゆえに美しい（abhirāmam）。

【Mallinātha】

nava-prabhā-jāla-bhṛtām＝「新鮮な光の網を保持する」宝石たちの。kāñcana-vapra-bhā-jā＝黄金の堤（vapra）の光から生じた。yamaka（反復音修辞）：...vaprabhājā / navaprabhājāla... および ...ābhirāmaṃ latābhir āmantrita... と、同音列が二組の半偈の境界を跨ぐ。Daṇḍin の yamaka の定義を引く：「前後の語音列（varṇa-saṃhati）が異なる意味で反復されるもの」。

IV.4
Sanskrit (IAST) sahasrasaṃkhyair gaganaṃ śirobhiḥ pādair bhuvaṃ vyāpya vitiṣṭhamānam / vilocanasthānagatoṣṇaraśmi- niśākaraṃ sādhu hiraṇyagarbham //
和訳

千を数える頂で天空を、裾野（pāda＝足）で大地を覆い尽くして聳え立ち、眼のあるべき位置に太陽と月を据えた——まことにヒラニヤガルバ（黄金の胎＝ブラフマー神）のごとき〔山を〕。

注

【Vallabhadeva】

多数の頂（śiras）と支脈（pāda＝足）で天地を覆って立つ姿を、ヴェーダ聖典の「千頭の原人（sahasra-śīrṣā puruṣaḥ）」に見立てる。目の位置（vilocana-sthāna）に太陽と月があると述べることで、山の途方もない高さを暗示する（atiśayokti）。sādhu-hiraṇyagarbham＝宝物を胎蔵する山であり、同時にブラフマー神（Hiraṇyagarbha）でもあるという二重の含意（adhikṣepa）。

【Mallinātha】

sahasra-saṃkhyaiḥ śirobhiḥ＝千を数える頂きと千本の光線（光の手）で天を、同じく千の足（裾野と支脈）で大地を占める。vilocana-sthāna-gata＝眼の位置にある太陽（uṣṇaraśmi）と月（niśākara）。ゆえに sādhu（真に）hiraṇyagarbha であるという utprekṣā。śruti（聖典）の「sahasra-śīrṣā puruṣaḥ」に基づく。hiraṇyagarbha には「宝を蔵する」の意もある。GRETIL底本ではśirobhiḥが脱落——注釈文から補う。

IV.5
Sanskrit (IAST) kvacij jalāpāyavipāṇḍurāṇi dhautottarīyapratimacchavīni / abhrāṇi bibhrāṇam umāṅgasaṅga- vibhaktabhasmānam iva smarārim //
和訳

ところどころ水が引いて白くなり、洗い晒した上衣のような色合いの雲を纏い——ウマー（パールヴァティー）の肢体との結合によって片身に灰を塗り分けた、恋の敵（スマラーリ＝シヴァ）のごとき〔山を〕。

注

【Vallabhadeva】

山の一部が雲に覆われ一部が黄金色に露出する姿を、シヴァの半身にパールヴァティーの肢体が合わさり灰が片側だけに塗られた ardhanaārīśvara の姿に喩える。黄金部分がウマーの半身、白い雲に覆われた部分がシヴァの灰身に対応。ライヴァタカ山が黄金なのは Sumeru の峰で造営されたため（IV.10参照）。upamā（直喩）。

【Mallinātha】

kvacit＝ある箇所で（全面ではない）。jalāpāya＝水の去った（引いた）所。vipāṇḍurāṇi＝白く清らかな。dhautottarīya-pratimā cchavi＝洗った上衣に似た色合い。abhrāṇi＝雲を。bibhrāṇam（√bhṛ の現在分詞 śānac）＝纏っている山。ウマーの肢体との合一（aṅga-saṅga）で灰（bhasma）が半身に分かたれたシヴァに喩える upamā。

IV.6
Sanskrit (IAST) chāyāṃ nijastrīcaṭulālasānāṃ madena kiñciccaṭulālasānām / kurvāṇam utpiñjalajātapatrair vihaṅgamānāṃ jalajātapatraiḥ //
和訳

自らの雌への甘い言葉を求めて懸命ながら、蜜の酔いにいささか気怠くも軽やかな鳥たちのために、逆立った羽の〔鳥たちに〕水生の花弁で蔭を作っている〔山を〕。

注

【Vallabhadeva】

鳥たち（vihaṅgama＝鵞鳥・蜂など）は雌たちの甘い言葉（caṭu）を求めて切望し（lālasa）、同時に花蜜（madana）の酔いで少し（kiñcit）気怠い（alasa）のに落ち着きなく（caṭula）動く。yamaka：caṭulālasa が二度現れるが、語の切り方が異なる——①caṭu-lālasa（甘言を切望する）②caṭula-alasa（軽やかで気怠い）。

【Mallinātha】

utpiñjala-jāta-patraiḥ＝逆立って（utpiñjala）生えた（jāta）羽（patra）を持つ〔鳥たちに〕。jalajātapatraiḥ＝水生（jalaja）の葉・花弁（patra）によって。蓮花の大量の葉で鳥に蔭を作る山の姿であり、大規模な蓮池の繁栄が暗示される。yamaka と rūpaka の混合（saṅkara）。utpiñjara（黄色味がかった）とも解し得る（r/l の交替）。

IV.7
Sanskrit (IAST) skandhādhirūḍhojjvalanīlakaṇṭhān urvīruhaḥ śliṣṭatanūnahīndraiḥ / pranartitānekalatābhujāgrān rudrān anekān iva dhārayantam //
和訳

幹（skandha）の上に輝く青頸の孔雀を載せ、蛇王（ahīndra）たちにその身を巻きつかれ、多くの蔓草の腕先を舞わせる——あたかも数多のルドラ神を戴くかのごとく、樹木を〔山は〕支えている。

注

【Vallabhadeva】

śleṣa（掛詞）による二重の描写——樹木（urvīruha）の場合：skandha＝幹にnīlakaṇṭha＝孔雀が止まり、蛇（ahīndra）が巻きつき、蔓（latā）の先端が風で揺れる。ルドラ神（Rudra）の場合：skandha＝肩にnīlakaṇṭha＝青い喉の神が坐し、蛇王（Vāsuki）が身体に巻きつき、多くの腕（bhuja）の先端が舞踏のように動く。anantān（Val異読：無数の）。utprekṣā。

【Mallinātha】

skandhaに二義：①樹の幹、②肩。nīlakaṇṭhaに二義：①孔雀、②青い喉を持つ者（＝シヴァ）。ahīndra：①大蛇（樹に巻きつく）、②蛇王（シヴァの装飾）。樹に蛇が住むのは住処ゆえ、ルドラに蛇が巻くのは装飾ゆえ。蔓の先端（latā-bhujāgra）が踊る＝ルドラの無数の腕（bhuja）が舞踏する——utprekṣā。

IV.8
Sanskrit (IAST) vilambinīlotpalakarṇapūrāḥ kapolabhittīr iva lodhragaurīḥ / navolapālaṅkṛtasaikatābhāḥ śucīr apaḥ śaivalinīr dadhānam //
和訳

垂れ下がる青蓮華（nīlotpala）の耳飾りをつけ、lodhra花粉で白く輝く頬のような——新しい草（ulapa）で飾られた砂洲の色合いの、清らかで苔むした水を湛えた〔山を〕。

注

【Vallabhadeva】

水流（apas）を女性の頬（kapola-bhitti）に喩える。水辺に垂れる青蓮華が耳飾り（karṇapūra）、苔（śaivala）の緑と砂洲（saikata）の白さに見立て、lodhra樹の花粉で白い頬とする。ulapa＝丈夫な草の一種（Amarakośa：ulapa＝balavaja）。水の清らかさ（śuci）と苔の緑との二重比喩（upamā）。

【Mallinātha】

vilambinīlotpala-karṇapūrāḥ＝垂れ下がる青蓮華を耳飾りとする〔頬＝水〕。lodhra-gaurīḥ＝lodhra花粉で白い。kapolabhittīḥ＝女性の頬面。iva で直喩。navolapālaṅkṛta-saikatābhāḥ＝新鮮な ulapa 草で飾られた砂洲のような外観。śucīḥ＝清浄な。śaivalinīḥ＝苔のある。水の清浄さが頬の白さの、苔が飾りの対応物（bimba-pratibimba-bhāva）で、upamā が二重にかかる。GRETILは śaivalanīr と読むが śaivalinīrが正。

IV.9
Sanskrit (IAST) rājīvarājīvaśalolabhṛṅgaṃ muṣṇantam uṣṇaṃ tatibhis tarūṇām / kāntālakāntā lalanāḥ surāṇāṃ rakṣobhir akṣobhitam udvahantam //
和訳

蓮の列に仕える蜂たちが飛び交い、樹木の群れで暑さを奪い去る——美しい巻毛の天女（apsaras）たちを抱き、羅刹（rākṣasa）たちにも揺るがされぬ〔山を〕。

注

【Vallabhadeva】

yamaka：rājīva-rājī-vaśa-lola-bhṛṅgam——rājīva＝蓮花、rājī＝列・行列、vaśa＝支配下にある、lola＝揺れ動く。蜂が蓮の列に従い飛び回る。kānta-alaka-āntāḥ＝美しい巻毛の先端を持つ天女たち。rakṣobhiḥ akṣobhitam＝羅刹たちにも動揺させられない（a-kṣobhita）。

【Mallinātha】

rājīva-rājī＝蓮花の列（padma-paṅkti）。それらにvaśa（従属する）でlola（動揺する）蜂（bhṛṅga）がいる〔山〕。tatibhiḥ＝樹木の群れ（tati＝saṅgha）でuṣṇam（暑さ）をmuṣṇantam（奪う）。kāntā alakāntāḥ＝美しい（kāntā）前髪の先（alaka-antā）を持つ天界の女性。akṣobhitam＝揺るがされない。yamaka：muṣṇāntam uṣṇaṃ / kāntālakāntā / rakṣobhir akṣobhitam。GRETIL底本のrakṣebhitamはakṣobhitamの誤り。

IV.10
Sanskrit (IAST) mude murārer amaraiḥ sumeror ānīya yasyopacitasya śṛṅgaiḥ / bhavanti noddāmagirāṃ kavīnām ucchrāyasaundaryaguṇā mṛṣodyāḥ //
和訳

ムラの敵（Kṛṣṇa）の喜びのために、神々がスメール山から峰々を運び来て増築した——そのような〔山の〕高さと美の卓越は、大胆な言葉を操る詩人たちにとっても虚言とはならない。

注

【Vallabhadeva】

ライヴァタカ山はスメール山（Sumeru）の峰を神々（amara）が運んで来てナーラーヤナ（Nārāyaṇa＝Kṛṣṇa）の喜びのために増築した（upacita）もの。ゆえにスメール山そのものの黄金の峰と同じ素性を持つのであり、詩人たちが雄弁に（uddāma-girām）その高さ（ucchrāya）と美しさ（saundarya）を讃えても、虚言（mṛṣā-udya）にはならない。Sumeru の峰との関連を述べることによる atiśayokti（誇張法）。

【Mallinātha】

murāreḥ mude＝ムラの敵の喜びのために。amaraiḥ（kartṛ）＝神々が。sumeror ānīya＝スメール山から運んで来て。śṛṅgaiḥ upacitasya＝峰々で盛り立てた。uddāma-girām＝奔放な言辞の。kavīnām＝詩人たちにとって。ucchrāya-saundarya-guṇāḥ＝高さと美との優越が。mṛṣodyāḥ na bhavanti＝虚偽の言表にはならない。mṛṣodyāḥは √vad の kyap（Pāṇini が規定する不規則派生）。Sumeru の峰との関連を叙述しながらの atiśayokti。
