マハーバーラタ ― カルナ篇 第38章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 38 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ38」（カルナが、ある婆羅門の見聞や呪言の故事を引いて、バーフリーカ・マドラの人々の道徳的混乱を畳みかけるように非難し、最後にシャルヤがそれに反論する場面）です。なお、和文訳の段落番号（30）と（31）は、原典では1つのサンスクリット詩節（トリシュトゥブ調6行、第30詩節）に対応しており、この対訳では両段落を1つの行に統合し、マーカー「8-38-30」としてまとめて示しています。それ以降、和文の段落番号は原典の詩節番号より1つ多くなりますが、これは上記の統合に伴うものであり、詩節の脱落はありません。
karṇaparva — aṣṭatriṃśo'dhyāyaḥ (38)
第38章
karṇa uvāca|
iti śalya vijānīhi hanta bhūyo bravīmi te|
anuyamānaṃ mayā samyak tvam ekāgramanāḥ śṛṇu|| // 8-38-1 //
カルナは語った。 （1）「このように、シャルヤよ、知れ。さらに言おう。私が正しく語るのを、一心に聞け。
brāhmaṇaḥ kila no geham adhyagacchat purā'tithiḥ|
ācāraṃ tatra samprekṣya prīto vacanam abravīt|| // 8-38-2 //
（2）あるバラモンが、客として我らの家にかつて来た。私たちの振舞いを見て、喜んで次のように語った。
mayā himavataḥ śṛṅgam ekena adhyuṣitaṃ ciram|
dṛṣṭāś ca bahavo deśā nānādharmasamāvṛtāḥ|| // 8-38-3 //
（3）『私はヒマラヤの山頂にひとり、長く住んだ。多くのさまざまな道の土地を見てきた。
na ca kena ca dharmeṇa virudhyante prajā imāḥ|
sarvāś ca api ācaran dharmaṃ yaduktaṃ vedapāragaiḥ|| // 8-38-4 //
（4）それらの住人はどこも道に反かず、ヴェーダに通じた人々が語った道を行なっていた。
aṭatā tu mayā deśān nānādharmasamākulān|
āgacchatā mahārāja bāhlīkeṣu niśāmitam|| // 8-38-5 //
（5）しかし、さまざまな道の混乱した国々を旅してきた大王よ、バーフリーカ国に近づいて、私は聞いた。
tatra vai brāhmaṇo bhūtvā punarbhavati kṣatriyaḥ|
vaiśyaḥ śūdraś ca bāhlīkas tato bhavati nāpitaḥ|| // 8-38-6 //
（6）そこでは、バラモンであった者が、再びクシャトリヤに、ヴァイシャに、シュードラに、バーフリーカにあたるとき床屋になり――。
nāpitaś ca tato bhūtvā punarbhavati brāhmaṇaḥ|
dvijo bhūtvā ca tatraiva punardāso'bhijāyate|| // 8-38-7 //
（7）床屋になると、再びバラモンに戻り、バラモンになると、そこでまた奴隷に生まれるのだ。
bhavantyekakule viprāḥ śiṣṭā ye kāmacāriṇaḥ|
gāndhārā madrakāś caiva bāhlīkāś ca api atejasaḥ|| // 8-38-8 //
（8）一つの家に、優れたバラモンたちも欲望のままに行動する者もいる。ガンダーラ族、マドラカ族、そしてバーフリーカ族も、栄光を欠いている。
etanmayā śrutaṃ tatra dharmasaṅkarakārakam|
kṛtsnām aṭitvā pṛthivīṃ bāhlīkeṣu viparyayaḥ|| // 8-38-9 //
（9）私はそこで、道の混乱を引き起こすこのようなことを聞いた。全地球を旅したが、バーフリーカ族にだけ逆転現象がある。
iti śalya vijānīhi hanta bhūyo bravīmi te|
yad api anyo'bravīd vākyaṃ bāhlīkānāṃ vikutsitaṃ|| // 8-38-10 //
（10）このように、シャルヤよ、知れ。さらに、バーフリーカ族を非難して別の者が語った言葉を言おう。
ānīya iha akṣatā kācid āraṭṭāt kila dasyubhiḥ|
adharmataś ca upayātā sā tān abhyaśapat tataḥ|| // 8-38-11 //
（11）盗賊たちによってアーラッタから連れてこられたある純粋な女が、不道徳に彼らのもとへ行かされた。彼女は彼らを呪った――。
bālāṃ bandhumatīṃ yan mām adharmeṇa upagacchatha|
tasmāt kumāryaḥ svairiṇyo bhaviṣyanti kuleṣu vaḥ|| // 8-38-12 //
（12）「私を、親族ある少女であるのに、不道徳に犯したから、お前たちの家系の娘たちは、勝手気ままになるだろう。
na caiva asmāt pramokṣadhvaṃ ghorāc chāpān narādhamāḥ|
tasmāt teṣāṃ bhāgaharaḥ kathaṃ dharmān vadiṣyasi|| // 8-38-13 //
（13）この恐ろしい呪いから、お前たちは解放されぬだろう、人中の最下位の者よ。ゆえに、彼らの税の一部を取るお前が、どうして道を語れるのか」。
kuravaḥ sahapāñcālāḥ sālvā mātsyāḥ sanaimiśāḥ|
kosalāḥ kāśapauṇḍrāś ca kāliṅgā māgadhās tathā|| // 8-38-14 //
（14）クル族、パーンチャーラ族、サールヴァ族、マツヤ族、ナイミシャ族、コーサラ族、カーシー族、パウンドラ族、カリンガ族、マガダ族――。
cedayaś ca mahābhāgā dharmaṃ jānanti śāśvatam|
nānādeśeṣvasantaś ca prāyo bāhyālayānṛte|| // 8-38-15 //
（15）そして高いチェーディ族は、永遠の道を知っている。さまざまな国の住人たちの中で、バーフリーカ国の外の者たちは大抵、そうなのだ。
āmatsyebhyaḥ kurupāñcālasālvā ānaimiśāccedayo ye viśiṣṭāḥ|
dharmaṃ purāṇamupajīvanti santo madrānṛte pāñcanadāṃś ca jihmān|| // 8-38-16 //
（16）マツヤ族を除き、クル族、パーンチャーラ族、サールヴァ族、ナイミシャ族のうち、チェーディ族は優れている。彼らは古の道によって生きる、善き者たちである――マドラ族と五つの川の曲がった者たちを除けば。
evaṃ vidvāndharmakathāsu rājaṃs tūṣṇīṃbhūtaḥ śalya bhaveḥ sadā tvam|
tvaṃ tasya goptā ca janasya rājā ṣaḍbhāgahartā śubhaduṣkṛtasya|| // 8-38-17 //
（17）識ある者よ、このように知り、道について沈黙を守れ、シャルヤよ。お前はその民の保護者であり王である。善行・悪行の税の六分の一を取る者なのだから。
athavā duṣkṛtasya tvaṃ hartā teṣām arakṣitā|
rakṣitā puṇyabhāgrājā prajānāṃ tvaṃ hy apuṇyabhāk|| // 8-38-18 //
（18）あるいは、お前は悪行の六分の一を取る者として、その民を守らぬならば、守る王は功徳を得るが、お前は民の罪を得ることになる。
pūjyamāne purā dharme sarvadeśeṣu śāśvate|
dharmaṃ pāñcanadaṃ dṛṣṭvā dhig ity āha pitāmahaḥ|| // 8-38-19 //
（19）以前、すべての国で永遠の道が尊ばれていたとき、五川の道を見て祖父（プラジャーパティ）は「恥ずべし」と言った。
vrātyānāṃ dāśakīyānāṃ kṛte'py aśubhakarmaṇām|
brahmaṇā ninditān dharmān kaścit siddhātmako'bravīt|| // 8-38-20 //
（20）規律なく、奴隷のような、悪行をなす彼らの行いの、ブラフマによって非難された道を、成就者のある者が語った。
iti pāñcanadaṃ dharmavamene pitāmahaḥ|
svadharmastheṣu varṇeṣu so'py etān na abhyapūjayat|| // 8-38-21 //
（21）このように、五川の道を祖父は思い、自らの道に従う四つの身分のそれぞれに尊びはしなかった。
iti śalya vijānīhi hanta bhūyo bravīmi te|
kalmāṣapādaḥ sarasi nimajjan rākṣaso'bravīt|| // 8-38-22 //
（22）このように、シャルヤよ、知れ。さらに言おう。カルマーシャパーダ王が湖で沈みつつ、鬼は言った――。
kṣatriyasya malaṃ bhaikṣyaṃ brāhmaṇasyāśrutaṃ malam|
malaṃ pṛthivyā bāhlīkāḥ strīṇāṃ kautūhalaṃ malam|| // 8-38-23 //
（23）「クシャトリヤの穢れは物乞いすることであり、バラモンの穢れはヴェーダを学ばぬこと。地球の穢れはバーフリーカ族であり、女の穢れは好奇心である」。
nimajjamānam uddhṛtya kaścid rājā niśācaram|
apṛcchat tena ca ākhyātaṃ tac chṛṇuṣva narādhipa|| // 8-38-24 //
（24）沈みつつあった夜行者（鬼）を、ある王が引き上げて尋ねた。それに答えたことを聞け、国王よ。
mānuṣāṇāṃ malaṃ mlecchā mlecchānāṃ muṣṭikā malam|
muṣṭikānāṃ malaṃ ṣaṇḍhāḥ ṣaṇḍhānāṃ rājayājakāḥ|| // 8-38-25 //
（25）「人の穢れはムレッチャ族（異民族）。ムレッチャ族の穢れはムシュティカ族。ムシュティカ族の穢れは宦官（シャンダ）。宦官の穢れは王の祭司――。
rājayājakayājyānāṃ madrakāṇāṃ ca yan malam|
tad bhavet vai tava malaṃ yady asmān na vimuñcasi|| // 8-38-26 //
（26）王の祭司の祭るところの、マドラカ族の穢れは――もしお前が我らを解放せぬなら、お前の穢れとなるだろう」。
iti rakṣopasṛṣṭeṣu viṣavīryahateṣu ca|
vidvadbhir bheṣajaṃ dṛṣṭaṃ saṃsiddhavacanottaram|| // 8-38-27 //
（27）このように鬼に襲われた者、毒に打たれた者たちに、賢者たちは薬と最上の真言を見出した。
brāhayāḥ pañcālāḥ kauraveyās tu dharmyāḥ satyā matsyāḥ śūrasenāś ca yājyāḥ|
prācyā dāsā vṛṣalā dākṣiṇātyāḥ stenā bāhlīkāḥ saṅkāra vai surāṣṭrāḥ|| // 8-38-28 //
（28）バラモン、パーンチャーラ族、クル族は正義深く、マツヤ族は真実である。シューラセーナ族は祭りをなすに値する。東方の者は奴隷、ヴリシャラ（低位のシュードラ）、南方の者たち、盗人のバーフリーカ族、混じり合ったスラーシュトラ族――。
kṛtaghnatā paravittāpahāro madyapānaṃ gurudārāvamardaḥ|
vākpāruṣyaṃ govadho rātricaryā bahirgehaṃ paravastropabhogaḥ|| // 8-38-29 //
（29）恩知らず、他人の財を盗む、飲酒、師の妻を犯す、言葉の荒さ、牛殺し、夜行、家を離れての生活、他人の衣を用いる――。
yeṣāṃ dharmas tān prati nāsty adharmo hy āraṭṭajān pāñcanadān dhig astu|
āpāñcālāḥ kuravo naimiśāś ca matsyāś caiva apy anujānanti dharmam|
atha udīcyāś ca udayo bhāgadhāś ca śiṣṭān dharmān upajīvanti vṛddhāḥ|| // 8-38-30 //
（30〜31）これらを道とする者には不道徳がない、アーラッタ生まれ、五川の民――恥よ。パーンチャーラ族まで、クル族、ナイミシャ族――。そしてマツヤ族は、道を正しく知る。北方の民、東方の民、マガダ族は、長老となって、道に従って生きている――。
prācīṃ diśaṃ śritā devā jātavedaḥpurogamāḥ|
dakṣiṇā pitṛbhir guptā yamena śubhakarmaṇā|| // 8-38-31 //
（32）東方は神々がジャータヴェーダス（アグニ神）を先頭にして住み、南方は祖霊と、善行をなすヤマに守られている。
pratīcīṃ varuṇaḥ pāti pālayan asurān bahūn|
udīcīṃ bhagavān soma brahmā ca brāhmaṇaiḥ saha|| // 8-38-32 //
（33）西方はヴァルナが多くのアスラを守りながら支配し、北方は尊き月神ソーマとブラフマがバラモンと共に守る。
rakṣaḥpiśācān himavān guhyakān gandhamādanaḥ|
dhruvaṃ sarvāṇi bhūtāni viṣṇuḥ pāti surottamaḥ|| // 8-38-33 //
（34）ラークシャサとピシャーチャはヒマラヤが、グヒヤカはガンダマーダナ山が。すべての生き物は不動のヴィシュヌ、神々の最上者が守る。
iṅgitajñāś ca magadhāḥ prekṣitajñāś ca kosalāḥ|
ardhoktāḥ kurupāñcālāḥ sarvoktā dākṣiṇāpathāḥ|| // 8-38-34 //
（35）マガダ族は仕草を知り、コーサラ族は観察を知り、クル族とパーンチャーラ族は半分の言葉で分かり合い、南方の民はすべて言わなければ分からぬ。
pārvatīyāś ca viṣayā yathaiva girayas tathā|
sarvajñā yavanā rājañ śūrāś caiva viśeṣataḥ|
mlecchāḥ svasaṃjñāniyatā nānuktamitare janāḥ|| // 8-38-35 //
（36）山岳民族も山のように――。すべてを知るヤヴァナ族、王よ、勇士として特筆される。ムレッチャ族は、自分たちの取り決めだけに従い、他の民はまだ言うまい。
pratirabdhās tu bāhlīkā na ca kecana madrakāḥ|
sa tvametādṛśaḥ śalya nottaraṃ vaktumarhasi|| // 8-38-36 //
（37）反逆者のバーフリーカ族、そして誰よりもマドラカ族――お前はそのような者だ、シャルヤよ。もはや答えるべきでない。
evaṃ jñātvā joṣam āssva pratīpaṃ mā sma kruddhaḥ pāpabhṛtāṃ variṣṭha|
pūrvaṃ hatvā tvāṃ saputraṃ balaiś ca paścāddhaṃsye vāsudevārjunau ca|| // 8-38-37 //
（38）このように知り、黙っていろ。怒るな、悪を背負う者の最たる者よ。私はまず、お前を、その子と軍勢と共に討ち、そのあとでヴァースデーヴァとアルジュナを討とう」。
śalya uvāca|
āturāṇāṃ parityāgaḥ svadārasutavikrayaḥ|
aṅge pravartate karṇa yeṣām adhipatir bhavān|| // 8-38-38 //
シャルヤは語った。 （39）「病人の放棄、妻子の売買が、お前が王として君臨するアンガ国で行われているではないか、カルナよ。
rathātirathasaṅkhyāyāṃ yat tvāṃ bhīṣmas tadā abravīt|
tān viditvā'tmano doṣān nirmanyur bhava mā krudhaḥ|| // 8-38-39 //
（40）戦車戦士と偉大な戦車戦士の数え上げのとき、ビーシュマがお前について語ったこと――お前自身の欠点を知り、怒りを捨てよ。怒るな。
sarvatra brāhmaṇāḥ santi santi sarvatra kṣatriyāḥ|
vaiśyāḥ śūdrās tathā karṇa striyaḥ sādhvyaś ca suvratāḥ|| // 8-38-40 //
（41）どこにもバラモンはおり、どこにもクシャトリヤ、ヴァイシャ、シュードラがいる。カルナよ、貞淑で誓いを守る女たちもいる。
ramante copahāsena puruṣāḥ puruṣaiḥ saha|
anyonyena ratāḥ kṣībā deśedeśe ca maithunam|| // 8-38-41 //
（42）男同士が笑い合い、酔って互いに戯れ、国ごとに交わりがある。
paravācyeṣu nipuṇaḥ sarvo bhavati sarvadā|
ātmavācyaṃ na jānīte jānannapi ca muhyati|| // 8-38-42 //
（43）他人の欠点にはいつもみな目ざとい。自分の欠点は、知っていても迷う。
sarvatra santi rājanaḥ svaṃsvaṃ dharmamanuvratāḥ|
durmanuṣyān nigṛhṇanti santi sarvatra dhārmikāḥ|| // 8-38-43 //
（44）どこにも自分の道に従う王たちがいて、悪人を制し、どこにも正義の者がいる。
na karṇa deśasāmānyāt sarvaḥ pāpaṃ niṣevate|
yādṛśāḥ svasvabhāvena deśāṃs tāṃs tādṛśān viduḥ|| // 8-38-44 //
（45）カルナよ、地域ゆえだけで、すべての者が悪を行うわけではない。それぞれの性質によって、それぞれの地域がそのようになっているだけだ」。
sañjaya uvāca|
tato duryodhano rājā karṇaśalyāv avārayat|
sakhibhāvena rādheyaṃ śalyaṃ saujanyakena ca|| // 8-38-45 //
サンジャヤは語った。 （46）そしてドゥルヨーダナ王は、カルナとシャルヤの両者を宥めた。カルナには友情で、シャルヤには慈しみで。
tato nivāritaḥ karṇo dhārtarāṣṭreṇa māriṣa|
prahasya tatra rājendraṃ yāhi śalya ity acodayat|| // 8-38-46 //
（47）ドリタラーシュトラの子に止められたカルナは、敬うべき方よ、笑いながら王の中の王（シャルヤ）に「進めシャルヤ」と促した。
iti śrīmanmahābhārate karṇaparvaṇi aṣṭatriṃśo'dhyāyaḥ|| 38 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十八章は終わる。
