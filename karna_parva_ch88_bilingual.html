マハーバーラタ ― カルナ篇 第88章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 88 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ88」で、ドゥフシャーサナ殺害後の戦闘、シャルヤによるカルナへの激励の場面を描きます。
karṇaparva — aṣṭāśītitamo'dhyāyaḥ (88)
第88章　ドゥフシャーサナ殺害後の弟たちの殺害、シャルヤによるカルナの鼓舞、混戦
sañjaya uvāca|
sa pītvā rudhiraṃ tasya caraṇau gṛhya bhārata|
ityuccairvacanaṃ prāha pratinṛtyanvṛkodaraḥ||
// 8-88-1 //
サンジャヤは語った。
eṣa te rudhiraṃ tīvraṃ pibāmi puruṣādavat|
vadedānīṃ susaṃrabdhaḥ punargauriti gauriti||
// 8-88-2 //
「お前の激しい血をこうして人食いのように飲んでやるぞ。さあ今度は怒って言ってみろ、もう一度『牛よ！牛よ！』と。」
ye cāsmānpratinṛtyanti tadā gauriti gauriti|
tānvayaṃ pratinṛtyāmaḥ punargauriti gauriti||
// 8-88-3 //
「我々に向かって踊りながら『牛よ！牛よ！』と言った者たちに、我々もまた踊り返して『牛よ！牛よ！』と言ってやろう。」
pramāṇakoṭyāṃ śayane kālakūṭakabhojanam|
daṃśanaṃ cāhibhistīkṣṇairdāhaṃ jatugṛhe ca yat||
// 8-88-4 //
「寝台の端に毒の食事を盛り、毒蛇に噛ませ、漆の家で火をつけたこと——」
dyūte ca doṣabhūyastvamaraṇye vasatiś ca yā|
iṣvastrāṇi ca saṅgrāme anilānilaveśmasu||
// 8-88-5 //
「賭博での過ちの数々、森での暮らし——矢の武器の戦場で、風の吹く家で——」
duḥkhānyevābhijānīmo na sukhāni kadācana|
dhṛtarāṣṭrasya daurātmyātsaputrasya vayaṃ sadā||
// 8-88-6 //
「我々は苦しみだけを知り、幸せは一度もなかった。ドリタラーシュトラとその息子たちの悪意によって、常に。」
ityuccairvacanaṃ procya jayaṃ prāpya vṛkodaraḥ|
punareva mahārāja tava sainyamabhidravat||
// 8-88-7 //
こう大声で宣言し、勝利を得たヴリコーダラは、大王よ、再び汝の軍に突撃した。
raktārdrapāṇistu tato mahātmā gadāpāṇiḥ kāla ivāntakāle|
vibhīṣayaṃstava putrasya sainyas mitastato dhāvati vāhinīṃ te||
// 8-88-8 //
血に濡れた手で、棍棒を持ち、終末の死神のように——汝の息子の軍を震え上がらせながら、あちこちに汝の軍を追い回した。
tataḥ kṣaṇādbhārata śūnyamāsīd āyodhanaṃ ghorataraṃ kurūṇām|
yatrājimadhye prāpibadbhīmaseno duḥśāsanasya rudhiraṃ krodhadīptaḥ||
// 8-88-9 //
バーラタよ、一瞬にして、怒りに燃えるビーマセーナがドゥフシャーサナの血を飲んだ戦場の周囲は空になった。クル族の恐ろしい戦場が。
sa hatvā samare rājanrājaputraṃ mahābalam|
pūrṇakāmo madodagraḥ siṃho rurumivotkaṭaḥ||
// 8-88-10 //
王よ、戦場で大力の王子を殺し、望みを果たし、酩酊して意気揚々と——獅子がルル鹿を倒したように——
rudhirārdro mahārāja vyaśobhata parantapaḥ|
sapuṣpaḥ kiṃśuka iva raktaraktataro babhau||
// 8-88-11 //
大王よ、敵を滅ぼすビーマは血にまみれて輝いた。花をつけたキンシュカ（パラーシャの木）のように、赤の上にさらに赤く輝いた。
rudhirākto ghoraveṣaḥ kruddho rājanvaco'bravīt|
brūhīdānīṃ pāpamate nṛśaṃsa patito hyasi||
// 8-88-12 //
血にまみれ、恐ろしい姿で、怒って王よ、こう叫んだ。「邪悪な者よ、卑劣な者よ、今こう言え——お前は倒れた。」
duḥśāsane yādṛśaṃ saṃśrutaṃ nas tadavāptaṃ pāṇḍavaiḥ sarvameva|
atraivamāpsyāmyaparaṃ dvitīyaṃ duryodhanaṃ yajñapaśuṃ viśasya||
// 8-88-13 //
「ドゥフシャーサナについて我々が誓った全てのことは、パーンダヴァによって達成された。ここでさらにもう一つ——ドゥルヨーダナという祭りの供犠の獣を屠って——」
śiro mṛditvā'sya punaś ca śāntiṃ yāsyāmyahaṃ kauravāṇāṃ samakṣam|
yā sā'patiḥ sā sapatirhi jātā yāstāḥ sapatyo'patayastu jātāḥ||
// 8-88-14 //
「彼の頭を踏み潰し、私は安らぎを得るだろう、カウラヴァの面前で。夫なき者は夫ある者となり、夫ある者たちは夫なき者となった。」
paśyantu citraṃ vividhaṃ hi loke ye vai tilāḥ ṣaṇḍatilā babhūvuḥ|
te cetsaṃsiddhā nidhanaṃ gatāḥ pare kiṃ citrarūpaṃ bata jīvaloke||
// 8-88-15 //
「世に様々な驚きを見よ——かつて種であった者たちが去勢された種となった。彼らが滅び、敵が滅んだなら、一体何が不思議であろうか、この生ある世界で。」
etāvaduktvā vacanaṃ prahṛṣṭaḥ prākrośaduccai rudhirārdravakraḥ|
nanarta caivātibalo mahātmā vṛtraṃ nihatyeva sahasranetraḥ||
// 8-88-16 //
こう言い終えて喜び、血に濡れた口で大声で叫び——大いなる力の偉大な者は踊り回った。ヴリトラを殺したインドラのように。
dṛṣṭvā tu nṛtyantamudagravīryaṃ kālaṃ yathā tvantakāle prajānām|
mahadbhayaṃ cādhirathiṃ viveśa jaye nirāśāś ca sutāstvadīyāḥ||
// 8-88-17 //
激怒して踊る、意気揚々たる武勇の者を見て——終末の時の民の前のカーラ（死神）のように——アディラタの子（カルナ）に大いなる恐怖が入り込み、汝の息子たちは勝利の望みを失った。
duḥśāsane tu nihate putrāstava mahārathāḥ|
mahatkrodhaviṣaṃ vīrā dhārayanto mahābalāḥ|
te tu rājanmahāvīryā bhīmaṃ prācchādayañcharaiḥ||
// 8-88-18 //
ドゥフシャーサナが殺されると、汝の息子たちの大戦車戦士で、勇猛で大力の勇者たちは、大いなる怒りの毒を抱き——王よ、矢でビーマを覆い尽くした。
niṣaṅgī kavacī khaṅgī daṇḍadhāro dhanurdharaḥ|
alamburjalasandhaś ca vātavegasuvarcasau||
// 8-88-19 //
ニシャンギン、カヴァチン、カンギン、ダンダダーラ、ダヌルダラ、アランブル、ジャラサンダ、ヴァータヴェーガ、スヴァルチャス——
ete sametya sahitā bhrātṛvyasanakarśitāḥ|
bhīmasenaṃ mahābāhuṃ pīḍayāmāsurañjasā||
// 8-88-20 //
これらの者たちが一致団結し、兄弟の災難に苦しみながら、大いなる腕のビーマセーナを直ちに苦しめた。
sa vadhyamāno viśikhaiḥ samantāttairmahārathaiḥ|
bhīmaḥ krodhābhiraktākṣaḥ kruddhaḥ kāla ivābabhau||
// 8-88-21 //
大戦車戦士たちの四方からの矢に討たれるビーマは、怒りに赤い目をし、怒れる死神のように見えた。
tataḥ parivṛto rājannavabhiḥ śatrutāpanaiḥ|
duḥśāsanādavarajaiḥ putraistava vṛkodaraḥ||
// 8-88-22 //
王よ、ドゥフシャーサナの弟である九人の敵を苦しめる者たち、汝の息子たちに囲まれたヴリコーダラは——
tāṃstu bhallairmahāvegairnavabhirnava bhārata|
rukmāṅgadānrukmapuṅkhaiḥ pārtho ninye yamakṣayam||
// 8-88-23 //
バーラタよ、黄金の腕輪と黄金の羽根を持つ大速の九本の鏃で九人を、ヤマの館へ送った。
hateṣu tava putreṣu balaṃ tadvipradudruve|
paśyataḥ sūtaputrasya pāṇḍavasya bhayārditam||
// 8-88-24 //
汝の息子たちが殺されると、軍は逃げ散った。スータの子（カルナ）の目の前で、パーンダヴァへの恐怖に打たれて。
tataḥ karṇaṃ mahārāja praviveśa mahadbhayam|
dṛṣṭvā bhīmasya vikrāntamantakasya prajāsviva||
// 8-88-25 //
大王よ、カルナに大いなる恐怖が入り込んだ。ビーマの武勇を見て——民の前の死神のように。
tasya tvākārabhāvajñaḥ śalyaḥ samitiśobhanaḥ|
uvāca vacanaṃ karṇaṃ prāptakālaṃ hitaṃ tadā||
// 8-88-26-27 //
彼の態度を読み取る者、戦場で輝くシャルヤが、時宜を得た有益な言葉をカルナに語った。
ete dravanti rājāno bhīmasenabhayārditāḥ|
duryodhanaś ca sammūḍho bhrātṛvyasanakarśitaḥ||
// 8-88-28 //
「見よ、王たちがビーマセーナへの恐怖に打たれて逃げている。ドゥルヨーダナは兄弟の災難に苦しみ、混乱している。」
duḥśāsanasya rudhire pīyamāne mahātmanā|
vyāpannacetāḥ sahasā śokopahatacetanaḥ||
// 8-88-29 //
「偉大な者がドゥフシャーサナの血を飲んでいる時、意識を失い、突然の悲嘆に心を奪われた。」
upāsate tvāmete hi parivārya mahārathāḥ|
kṛpaprabhṛtayaḥ karṇa hataśeṣāḥ sahodarāḥ||
// 8-88-30 //
「カルナよ、クリパらを始めとする大戦車戦士たちと残った兄弟たちが、お前を囲んで控えている。」
pāṇḍavā labdhalakṣāś ca dhanañjayapurogamāḥ|
tvāmevābhimukhāḥ śūrā yuddhāya samupasthitāḥ||
// 8-88-31 //
「パーンダヴァたちは好機を得て、ダナンジャヤを先頭に、勇者として戦いの用意を整えてお前に向き合っている。」
sa tvaṃ puruṣaśārdūla pauruṣe mahati sthitaḥ|
kṣatradharmaṃ puraskṛtya pratyudyāhi dhanañjayam||
// 8-88-32 //
「人中の虎よ、お前は大いなる勇気をもって、クシャトリヤの法を前に立て、ダナンジャヤに向かって行け。」
bhāro hi dhārtarāṣṭreṇa tvayi sarvaḥ samāhitaḥ|
tamudvaha mahābāho yathāśakti yathābalam||
// 8-88-33 //
「ドリタラーシュトラの子は全ての重荷をお前に委ねた。大いなる腕の者よ、力と能力に応じてその重荷を担え。」
jaye syādvipulā kīrtirdhruvaḥ svargaḥ parājaye|
vṛṣasenaś ca rādheya saṅkruddhastanayastava|
tvayi mohaṃ samāpanne pāṇ़ḍavānabhidhāvati||
// 8-88-34 //
「勝てば大いなる名声、敗れれば天国が確実だ。ラーデーヤよ、お前の息子ヴリシャセーナも、怒り狂って——お前が意気消沈する中——パーンダヴァに向かって突撃している。」
sañjaya uvāca|
etacchrutvā tu vacanaṃ śalyasyāmitatojasaḥ|
hṛdi mānuṣyakaṃ bhāvaṃ kṛtvā yudvāya susthiram||
// 8-88-35 //
サンジャヤは語った。
tataḥ kruddho vṛṣaseno'bhyadhāvad bhīmaṃ samāyāntamamitrasāham|
bāṇaiḥ kirantaṃ pratiyāti cograṃ vyāttānanaṃ kālamivāpatantam||
// 8-88-36 //
すると怒れるヴリシャセーナが、やって来る敵を圧倒するビーマに向かって突撃した。矢を放ちながら進み、口を開けた死神のように向かってくる恐ろしい者に。
tamabhyadhāvannakulaḥ pravīram ārādamitraṃ pratudanpṛṣatkaiḥ|
karṇasya putraṃ samare prahṛṣṭaṃ jiṣṇurjighāṃsurmaghaveva jambham||
// 8-88-37 //
勇敢なナクラが、敵を矢で突きながら、カルナの息子を喜んで殺さんとして向かった。インドラがジャンバを倒すように。
tato dhvajaṃ sphāṭikahemacitraṃ ciccheda dhairyānnakulaḥ kṣureṇa|
karṇātmajasyeṣvasanaṃ ca citraṃ bhallena jāmbūnadacitranaddham||
// 8-88-38 //
ナクラは勇敢にも剃刀矢でカルナの子の水晶と黄金で飾られた旗と、黄金で飾られた美しい弓を鏃で切り落とした。
athānyadādāya dhanuḥ sa śīghraṃ karṇātmajaḥ pāṇḍavamabhyavidhyat|
divyairastrairabhyavarṣattadainaṃ karṇasya putro nakulaṃ kṛtāstram||
// 8-88-39 //
カルナの子は素早く別の弓を取り、パーンダヴァ（ナクラ）を射た。そして神聖な武器でナクラを攻めた。武器の技に長けたカルナの子が。
tataḥ kruddho nakulaḥ karṇaputraṃ śarairmaholkābhirivābhyapīḍayat|
sa karṇaputro nakulasya rājan sarvānastrānvārayaduttamāstraiḥ||
// 8-88-40 //
怒れるナクラは、大いなる松明のような矢でカルナの子を苦しめた。王よ、カルナの子はナクラの全ての武器を最上の武器で防いだ。
āsītsughoraṃ bharatapravīra yuddhaṃ tadā karṇajapāṇḍavābhyām||
// 8-88-41 //
バーラタの勇者よ、カルナの子とパーンダヴァの間に極めて恐ろしい戦いがあった。
vanāyujānsukumārānsuśubhrān alaṅkṛtāñjātarūpeṇa citrān|
jaghāna cāśvānnakulasya vīro raṇājire sūtaputrasya putraḥ||
// 8-88-42 //
勇者のカルナの子（ヴリシャセーナ）は、戦場で森生まれの美しい白い黄金で飾られたナクラの馬を殺した。
tato hatāśvādavaruhya yānāc carmā''dade ruciraṃ barhicitram|
ākāśasaṅkāśamasiṃ pragṛhya prakāśamānaḥ khagavaccacāra||
// 8-88-43 //
馬を失った車から降りたナクラは、孔雀の羽根で飾られた美しい楯を取り、空のように輝く剣をつかんで、鳥のように動き回った。
tato'sya pakṣānanayadyamāya dvisāhasrānnakulaḥ kṣiprakārī|
te prāpatannasinā vai viśastā yathā'śvamedhe paśavaḥ śamitrā||
// 8-88-44 //
そしてナクラは素早い手で、その楯の両翼にあたる二千人を剣でヤマに送った。彼らはアシュヴァメーダの祭りで屠殺者に屠られる獣のように斬られて倒れた。
tatastato vijitā yuddhaśauṇḍā nānādeśyāḥ suhṛdaḥ satyasandhāḥ|
ekena śīghraṃ nakulena nunnāḥ sārepsunevottamacandanasya||
// 8-88-45 //
各地からの戦いに熟練した、真実を誓う味方たちが——一人のナクラに素早く追い散らされた。
bhūmau carantaṃ nakulaṃ rathaughāḥ samantataḥ sāyakaiḥ pratyagṛhṇan|
sa tudyamāno nakulo vihaṅgaiś cacāra saṅkhye dviṣato vinighnan||
// 8-88-46 //
地上を行くナクラを、戦車群が四方から矢で捕えようとした。しかし突きながら行くナクラは、矢に突かれながらも戦場を駆け巡り、敵を殺した。
taṃ karṇaputro'pi carantamājau narāśvamātaṅgarathapravīrān|
nighnantamaṣṭādaśabhiḥ pṛṣatkair vivyādha vīraḥ sa cukopa viddhaḥ||
// 8-88-47 //
戦場を行くナクラを、カルナの子もまた十八本の矢で射た。勇者は射られて怒った。
tato'bhyadhāvatsamare jighāṃsuḥ karṇātmajaṃ pāṇḍusuto nṛvīram|
tasyeṣubhirvadhamatsūtaputro mahāraṇe varma sahasrabhāram||
// 8-88-48 //
そこで殺さんとして、パーンドゥの子はカルナの子に突進した。スータの子の子は大いなる戦場でナクラの千の重さの鎧を矢で砕いた。
tasyātha kāṃsyaṃ suśitaṃ supītam asi pravīraṃ gurubhārāsāham|
dviṣaccharīrāpaharaṃ sughoram ādhūnvataḥ sarpamivāttakośam||
// 8-88-49 //
そして鋭い鉄矢六本でナクラの鋭い美しい剣を切り落とし、再び鋭い矢でナクラの胸を素早く射た。
kṣipraṃ śaraiḥ ṣaṅbhiramitrasāhaś cakarta khaṅgaṃ niśitaiḥ sudhāraiḥ|
punaś ca pārthaṃ niśitaiḥ pṛṣatkaiḥ stanāntare kṣipramivātyavidhyat||
sa bhīmasenasya rathaṃ ca gatvā vavarṣa vai śaravarṣaṃ sughoram||
// 8-88-50-51 //
ナクラはビーマセーナの戦車に行き、恐ろしい矢の嵐を降らせた。
nakulamatha viditvā chinnabāṇāsanāsiṃ virathamaribhirārtaṃ karṇaputrāstramagnam|
pavanacalapatākā hlādino valgitāśvāḥ parapuruṣaniyuktāḥ svai rathaiḥ śīghramīyuḥ||
// 8-88-52 //
弓・矢・剣を失い、戦車を失い、敵に苦しめられ、カルナの子の武器に沈んだナクラを知って——旗がはためき、心地よく馬が跳ねる彼ら自身の戦車で、素早くやって来た。
drupadasutavariṣṭhāḥ pañca śaineyaṣaṣṭhā drupadaduhitṛputrāḥ pañca cāmitrasāhāḥ|
dviradarathanarāśvānsūdayantastvadīyān bhagavata iva rudrāḥ saṅkhyayā hetimantaḥ||
// 8-88-53 //
ドルパダの息子の最上の五人と、シャイネーヤ（サーティヤキ）を六人目とする、ドルパダの娘の息子五人、敵を圧倒する者たちが、象・戦車・人・馬を殺しながら——恐ろしいルドラ神の数（十一）のように武器を持って。
atha tava rathamukhyāstānpratīyustvarantaḥ kṛpahṛdikasutau ca drauṇiduryodhanau ca|
śakuniśukavṛkāś ca krāthadevāvṛdhau ca dviradajaladaghauṣaiḥ syandanaiḥ kārmukaiś ca||
// 8-88-54 //
汝の最上の戦車戦士たちが急いで彼らに立ち向かった——クリパ、フリディカの子（クリタヴァルマン）、ドローナの子とドゥルヨーダナ、シャクニ、シュカ、ヴリカ、クラータ、デーヴァ、アヴリダ——象のような雲の轟音を持つ戦車と弓を携えて。
atha tava rathavaryāstāndaśaikapravīrān iṣubhiraśanikalpaistāḍayanto nyarundhan|
navajaladasavarṇairhastibhistānsma vavrur giriśikharanikāśairbhīmavegaiḥ kuṇindāḥ||
// 8-88-55 //
汝の最上の戦車十一人の勇者が、雷に等しい矢で彼らを打ち、阻止した。新しい雨雲のような色の象に、山の峰のような恐ろしい速さのクニンダ族が彼らを囲んだ。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe aṣṭāśītitamo'dhyāyaḥ|| 88 ||
