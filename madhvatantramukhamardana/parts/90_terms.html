用語集

本文全体に出てくる主な術語（訳中の初出の説明も参照）
pañcādhikaraṇī
BS 冒頭の五 adhikaraṇa（1.1.1–11）。本書の批判対象
adhikaraṇa
論題。viṣaya・saṃśaya・pūrvapakṣa・siddhānta・saṅgati からなる解釈の単位
yojana
sūtra を特定の意味に結びつけること。sūtra 解釈
saguṇa / nirguṇa
属性をもつ／もたない（brahman）
nirviśeṣa / saprapañca
差異をもたない／現象世界を伴う
upāsana / nididhyāsana
念想／（解脱知に至る）深い瞑想
kramamukti
漸次解脱。saguṇa 念想者が死後の世界を経て解脱すること
nahi nindā-nyāya
非難の文は非難対象の否定ではなく、規定対象の称揚を目的とする、という Mīmāṃsā の原則
viśvatomukha
あらゆる方向に顔を向けた。sūtra の多義性
adhyāropa / apavāda
仮託／否定。説いたうえで取り去る Advaita の教授法
sthūlārundhatī-nyāya
粗大なものから微細なものへ段階的に導く喩え
vineya
教化される者。学ぶ者
prakārabheda / racanābhaṅgī
解釈の型の違い／論の組み立て方
vaidikamaryādā / prāmāṇikamaryādā
Veda の規範／正しい認識手段の規範
āpta / anāpta
信頼できる者／信頼できない者
asādhuśabda
文法に反する語形
dūṣyasthala / dūṣaṇīyapradeśa
論難すべき箇所
paramatamaryādā
相手の説の規範。本書は Madhva 自身の前提だけを使って批判する、という方法をとる
āpādana / prasaṅga
相手の前提から望まない帰結を引き出すこと。帰謬。自説（svamata）とは区別される（§43）
vāda / jalpa / vitaṇḍā
真理の確定を目的とする論議／勝利を目的とする論議／自説をもたない論破。本書は自説の確立（本頌55）により vāda となる
bheda / abheda
差異／不異。Madhva の五種の差異（pañcabheda）と Advaita の jīva–brahman の不異
viśeṣa
Madhva の体系で、同一のものの中に区別の言語慣行を成り立たせる原理。基体と異ならない
tāratamya
段階差。Madhva では魂・神々・解脱者の歓喜に優劣がある（muktitāratamya）
yogyatā
Madhva の説で、魂が無始以来もつ固有の資格。念想の対象や解脱の可否を決める
sālokya / sāmīpya / sārūpya / sāyujya
解脱の四種。sāyujya は Viṣṇu の身体に入って享受を共にする解脱で、神々にのみ許される
ekārthaniyama / anekārthatva
文は一つの意味をもつという規則／多義性。Madhva による多義の容認が第三 adhikaraṇa 以下の批判の軸
viśeṣavacana
特別な文。一般的な語（「有」「ブラフマン」）を特定の神格に限定する文（「Nārāyaṇa のみがあった」など）
kartraikyaśruti
世界の作者が一人であることを説く śruti（ŚvetU 3.3 など）
tātparyaliṅga / ṣaḍliṅga
主旨の標識。upakrama・upasaṃhāra・abhyāsa・apūrvatā・phala・arthavāda・upapatti
ekavākyatā
主文と補足の文などが一つの主旨のもとに一つの文をなすこと
vākyaśeṣa
補足の文。語義の確定に用いられる（śyena、yūpa・āhavanīya の規則）
balābala / virodha
強弱の判定／矛盾。強弱の判定は矛盾があるときにのみ働く
sāvakāśa / niravakāśa
他に適用の余地がある／ない。余地のないものが優先する
vidvadrūḍhi / ajñarūḍhi
学識者の慣用／世人の慣用。Madhva はすべての語が学識者の慣用では Viṣṇu を表すとする
mahāyoga
最大の語源的意味。すべての語が語源的に Viṣṇu の完全な徳を表すという Madhva の説
pravṛttinimittatādadhīnya
語の適用根拠がその者に従属していること。Madhva はこれによってすべての語が Viṣṇu を最も本来的に表すとする（§48）
mukhya / paramamukhya / lakṣaṇā
本来の表示／最高に本来的な表示／二次的指示
pratibimba / bimba
映像／原像。Madhva では念想されるのはブラフマンの映像、jīva もブラフマンの映像
nityāvyakta
永遠に顕現しないもの。Madhva の BS 3.2.23 の解釈によるブラフマン
upasaṃhāra（guṇopasaṃhāra）
諸念想の徳の取り集め（BS 3.3）
anuvāda
既知のことの再述。それ自体は新たに事実を主張しない
arthavāda / prarocana
称賛・非難の文／関心を起こさせること。非難の文は他の選択肢の称賛のためにある
bhūman
ChU 7.23 の「多さ・充満」。Madhva では資格に応じて段階的に知られる無上の充満
syādvāda / kṣapaṇaka
ジャイナの「ある意味では」の説／ジャイナ（裸形行者）の蔑称
siddhasādhana / bādha
既に成立していることの論証／〔論証対象が〕他の認識によって覆されること。推論の過失
dharmisamasattāka
主題と同じ実在性をもつ。差異の推論に加えられる限定（§49）
akhaṇḍārtha / sakhaṇḍa
無分節の意味／分節をもつ〔意味〕。大文章（mahāvākya）の意味をめぐる論点
