kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

navamaḥ sargaḥ ― 第九章

夕暮れの描写（1–16）。月の出（17–33）。愛の営みと酒宴（34–75）。夜明けの訪れ（76–78）。韻律は全篇スヴァーガター（Svāgatā）、末尾数偈のみ別韻律。
1
Sanskrit
vīkṣya rantumanasaḥ suranārīr āttacitraparidhānavibhūṣāḥ / tatpriyārtham iva yātum athāstaṃ bhānumān upapayodhi lalambe //
Svāgatā
和訳
色とりどりの衣と装身具を身にまとい、愛の営みに心を向ける天女たちを見て、太陽は彼女たちに好意を示すかのように、海のほとりへ沈み始めた。
2
Sanskrit
madhyamopalanibhe lasadaṃśāv ekataś cyutim upeyuṣi bhānau / dyaur uvāha parivṛttivilolāṃ hārayaṣṭim iva vāsaralakṣmīm //
Svāgatā
和訳
中央の宝石のように輝く光をもつ太陽が一方に傾くと、空は回転して揺れる真珠の首飾りのように、昼の美しさを帯びていた。

太陽を首飾りの中央宝石（nāyaka）に見立てる。太陽が傾くと光の帯が首飾りの揺れに似る。

3
Sanskrit
aṃśupāṇibhir atīva pipāsuḥ padmajaṃ madhu bhṛśaṃ rasayitvā / kṣībatām iva gataḥ kṣitim eṣyaṃl lohitaṃ vapur uvāha pataṅgaḥ //
Svāgatā
和訳
光線の手で蓮華の蜜をたっぷりと味わい、過度に渇いていた太陽は、あたかも酔いしれたかのように地に沈みつつ赤い姿をとった。
4
Sanskrit
gamyatām upagate nayanānāṃ lohitāyati sahasramarīcau / āsasāda virahayya dharitrīṃ cakravākahṛdayāny abhitāpaḥ //
Svāgatā
和訳
赤くなった千光の太陽が目に見えるほどになると、熱は大地を離れてチャクラヴァーカ鳥の心に入り込んだ。

cakravāka：番いが夜に離れ離れになる鳥。日没は彼らにとって離別の苦しみの始まり。

5
Sanskrit
muktamūlalaghur ujjhitapūrvaḥ paścime nabhasi sambhṛtasāndraḥ / sāmi majjati ravau na vireje khinnajihma iva raśmisamūhaḥ //
Svāgatā
和訳
根を失って軽くなり、東に見捨てられ、西の空に密集した光の群れは、太陽が半ば沈むと、打ちひしがれて傾いたかのように輝きを失った。

掛詞：mūlaは「根」と「拠りどころ（主人）」、pūrvaは「東」と「高貴な人々」の二義。光線の衰えを失脚した臣下に喩える。

6
Sanskrit
kāntadūtya iva kuṅkumatāmrāḥ sāyamaṇḍalam abhi tvarayantyaḥ / sādaraṃ dadṛśire vanitābhiḥ saudhajālapatitā ravibhāsaḥ //
Svāgatā
和訳
恋人の使いのように紅花色に赤く、夕べの化粧へと急かすかのように窓格子から差し込む夕日の光を、女たちは敬虔なまなざしで見つめた。
7
Sanskrit
agrasānuṣu nitāntapiśaṅgair bhūruhān mṛdukarair avalambya / astaśailagahanaṃ nu vivasvān āviveśa jaladhiṃ nu mahīṃ nu //
Svāgatā
和訳
山頂で深紅の柔らかな光線で樹々にすがりつきながら、太陽は没山の密林に入ったのか、海に入ったのか、大地に入ったのか。
8
Sanskrit
ākulaś calapatatrikulānām āravair anuditauṣasarāgaḥ / āyayāv aharidaśvavipāṇḍus tulyatāṃ dinamukhena dināntaḥ //
Svāgatā
和訳
飛び交う鳥の群れの騒がしい声に満ち、朝焼けのない、太陽を失って蒼白な夕暮れは、夜明けと同じ姿をとった。
9
Sanskrit
āsthitaḥ sthagitavāridapaṅktyā saṃdhyayā gaganapaścimabhāgaḥ / sormividrumavitānavibhāsā rañjitasya jaladheḥ śriyam ūhe //
Svāgatā
和訳
雲の列を覆い尽くした夕映えに染まった西の空は、波の下に珊瑚の林が輝いて赤く染まった海の美しさを帯びていた。
10
Sanskrit
prāñjalāv api jane natamūrdhni prema tatpravaṇacetasi hitvā / saṃdhyayānuvidadhe viramantyā cāpalena sujanetaramaitrī //
Svāgatā
和訳
合掌して頭を垂れ、心を傾けて祈る人々への愛を捨てて、夕映えは気まぐれに消え去った——まさに悪しき者の友情のように。

saṃdhyāの礼拝：朝夕の薄明への礼拝はヒンドゥーの日課。シヴァもこれを行う（XVIII.31参照）。薄明が信仰深い人を見捨てるさまを不実な友に喩える。

11
Sanskrit
auṣasātapabhayād apalīnaṃ vāsaracchavivirāmapaṭīyaḥ / saṃnipatya śanakair iva nimnād andhakāram udavāpa samāni //
Svāgatā
和訳
曙の光を恐れて隠れていた闇は、昼の光が止むのに巧みで、窪地から静かに這い寄り、平地を覆い尽くした。
12
Sanskrit
ekatām iva gatasya vivekaḥ kasyacin na mahato 'py upalebhe / bhāsvatā nidadhire bhuvanānām ātmanīva patitena viśeṣāḥ //
Svāgatā
和訳
どんな大きなものにも区別がつかなくなり、あたかも一体と化したかのようであった。沈んだ太陽はこの世の事物の差異を自らのうちに仕舞い込んだかのようだった。
13
Sanskrit
icchatāṃ saha vadhūbhir abhedaṃ yāminīvirahiṇāṃ vihagānām / āpur eva mithunāni viyogaṃ laṅghyate na khalu kālaniyogaḥ //
Svāgatā
和訳
夜に雌と離れ離れになる鳥たちは、ともにいたいと望みながらも番いは別れを迎えた。時の定めは越えがたい。
14
Sanskrit
yacchati pratimukhaṃ dayitāyai vācam antikagate 'pi śakuntau / nīyate sma natim ujjhitaharṣaṃ paṅkajaṃ mukham ivāmburuhiṇyā //
Svāgatā
和訳
近くにいながらも鳥が伴侶に向かって鳴き声を上げると、喜びを失った蓮華は、蓮の池の女が顔を伏せるかのようにうなだれた。

チャクラヴァーカ鳥の声に呼応して、日没とともに蓮華が閉じるさまを、悲しみに顔を伏せる女に喩える。

15
Sanskrit
rañjitā nu vividhās taruśailā nāmitaṃ nu gaganaṃ sthagitaṃ nu / pūritā nu viṣameṣu dharitrī saṃhṛtā nu kakubhas timireṇa //
Svāgatā
和訳
闇がさまざまな樹や岩を染めたのか、空を引き下ろしたのか、覆い隠したのか、大地の凹凸を埋めたのか、それとも方角を縮めてしまったのか。
16
Sanskrit
rātrirāgamalināni vikāsaṃ paṅkajāni rahayanti vihāya / spaṣṭatārakam iyāya nabhaḥ śrīr vastum icchati nirāpadi sarvaḥ //
Svāgatā
和訳
夜の闇に曇り、もはや開くことのない蓮華を見捨てて、光の美は星の澄んだ空に移った。すべてのものは安全な場所に住むことを望む。
17
Sanskrit
vyānaśe śaśadhareṇa vimuktaḥ ketakīkusumakesarapāṇḍuḥ / cūrṇamuṣṭir iva lambhitakāntir vāsavasya diśam aṃśusamūhaḥ //
Svāgatā
和訳
月から放たれた、ケータキーの花蕊のように黄白い光の群れが、粉の一握りのように輝きを帯びつつ、ヴァーサヴァ（インドラ）の方角（東）を覆った。
18
Sanskrit
ujjhatī śucam ivāśu tamisrām antikaṃ vrajati tārakarāje / dikprasādaguṇamaṇḍanam ūhe raśmihāsaviśadaṃ mukham aindrī //
Svāgatā
和訳
星々の王（月）が近づくと、インドラの方角は悲しみのように闇をたちまち捨て去り、晴朗の美に飾られ、光の微笑みに澄んだ顔をもった。
19
Sanskrit
nīlanīrajanibhe himagauraṃ śailaruddhavapuṣaḥ sitaraśmeḥ / khe rarāja nipatatkarajālaṃ vāridheḥ payasi gāṅgam ivāmbhaḥ //
Svāgatā
和訳
山に隠れた月の雪のように白い光線の網が、暗い蓮華のような空に降り注ぎ、大海の水にガンガーの水が流れ込むかのように輝いた。

ガンガーの黄白い水が暗い海に注ぐさまに、月光が暗い空に差し込むさまを喩える。

20
Sanskrit
dyāṃ nirundhad atinīlaghanābhaṃ dhvāntam udyatakareṇa purastāt / kṣipyamāṇam asitetarabhāsā śambhuneva karicarma cakāse //
Svāgatā
和訳
空を覆う、深い青黒い雲に似た闇は、東から光線を掲げた月によって退けられ、シャンブ（シヴァ）が象の皮を剥いだかのように見えた。
21
Sanskrit
antikāntikagatenduvisṛṣṭe jihmatāṃ jahati dīdhitijāle / niḥsṛtas timirabhāranirodhād ucchvasann iva rarāja digantaḥ //
Svāgatā
和訳
刻一刻と近づく月が放つ光の網がまっすぐに伸びると、闇の重荷から解き放たれた地平は、息を吹き返したかのように輝いた。
22
Sanskrit
lekhayā vimalavidrumabhāsā saṃtataṃ timiram indur udāse / daṃṣṭrayā kanakaṭaṅkapiśaṅgyā maṇḍalaṃ bhuva ivādivarāhaḥ //
Svāgatā
和訳
月は清らかな珊瑚のように輝く光の弧で、密集した闇を持ち上げた――原初の猪（ヴィシュヌ）が黄金の鑿のように黄褐色の牙で、大地の円盤を持ち上げたように。

ヴィシュヌの第三アヴァターラであるヴァラーハ（猪）が牙で大地を救い上げる神話。月の弧をその牙に見立てる。

23
Sanskrit
dīpayann atha nabhaḥ kiraṇaughaiḥ kuṅkumāruṇapayodharagauraḥ / hemakumbha iva pūrvapayodher unmamajja śanakais tuhināṃśuḥ //
Svāgatā
和訳
光線の洪水で空を照らしながら、紅花のように赤い乳房のような輝きをもつ月は、黄金の壺のように東の海からゆっくりと浮かび上がった。
24
Sanskrit
udgatendum avibhinnatamisrāṃ paśyati sma rajanīm avitṛptaḥ / vyaṃśukasphuṭamukhīm atijihmāṃ vrīḍayā navavadhūm iva lokaḥ //
Svāgatā
和訳
月が昇っても闇の消えぬ夜を、世の人々は飽くことなく見つめた——あたかも面紗を脱いで顔をのぞかせながらも恥じらいに深く俯く新婦のように。
25
Sanskrit
na prasādam ucitaṃ gamitā dyaur noddhṛtaṃ timiram adrivanebhyaḥ / diṅmukheṣu na ca dhāma vikīrṇaṃ bhūṣitaiva rajanī himabhāsā //
Svāgatā
和訳
空には然るべき晴朗も得られず、山の森から闇も拭われず、方角の面々に光も撒かれなかった——それでも夜は月光によって飾られていた。
26
Sanskrit
māninījanavilocanapātān uṣṇabāṣpakaluṣān pratigṛhṇan / mandamandam uditaḥ prayayau khaṃ bhītabhīta iva śītamayūkhaḥ //
Svāgatā
和訳
熱い涙に曇った誇り高き女たちの視線を受けつつ、冷たい光の月はゆっくりゆっくりと、おびえるかのように空へと昇っていった。
27
Sanskrit
śliṣyataḥ priyavadhūr upakaṇṭhaṃ tārakās tatakarasya himāṃśoḥ / udvamann abhirarāja samantād aṅgarāga iva lohitarāgaḥ //
Svāgatā
和訳
愛する妻たる星々を光線の手で首のあたりに抱く月から、赤い色が四方に溢れ出て、あたかも紅の塗香のように輝いた。
28
Sanskrit

Svāgatā
和訳
月から放たれた光の洪水は、密集した闇をも払った——ちょうどマンダラ山に攪拌された乳海が、高木の密生する森を押し流すかのように。
29
Sanskrit
śāratāṃ gamitayā śaśipādaiś chāyayā viṭapināṃ pratipede / nyastaśuklabalicitratalābhis tulyatā vasativeśmamahībhiḥ //
Svāgatā
和訳
月光によって斑模様にされた木々の影は、白い供物粒を撒いた住居の屋上と同じように見えた。

bali：屋上に鳥の餌として撒く米粒。月の光と影が交錯する地面をこれに喩える。

30
Sanskrit
ātape dhṛtimatā saha vadhvā yāminīvirahiṇā vihagena / sehire na kiraṇā himaraśmer duḥkhite manasi sarvam asahyam //
Svāgatā
和訳
日中は伴侶とともに耐えた鳥も、夜に離れると月の光にも耐えられなかった。悲しむ心にはすべてが耐えがたい。
31
Sanskrit
gandham uddhatarajaḥkaṇavāhī vikṣipan vikasatāṃ kumudānām / ādudhāva parilīnavihaṅgā yāminīmarud apāṃ vanarājīḥ //
Svāgatā
和訳
舞い上がる花粉の粒を運び、咲き開く夜睡蓮（クムダ）の香りを撒き散らしながら、夜風は鳥たちが身を潜める水辺の森を揺らした。
32
Sanskrit
saṃvidhātum abhiṣekam udāse manmathasya lasadaṃśujalaughaḥ / yāminīvanitayā tatacihnaḥ sotpalo rajatakumbha ivenduḥ //
Svāgatā
和訳
愛の神の灌頂を執り行うために、輝く光の水流をたたえ、斑の印を広げた月が、夜という女の手で掲げられた――蓮華を添えた銀の壺のように。

カーマ（愛の神）の即位式（abhiṣeka）を月が銀の灌頂壺として執り行うという比喩。

33
Sanskrit
ojasāpi khalu nūnam anūnaṃ nāsahāyam upayāti jayaśrīḥ / yad vibhuḥ śaśimayūkhasakhaḥ sann ādade vijayi cāpam anaṅgaḥ //
Svāgatā
和訳
たしかに、力が十分あっても助けなしには勝利の栄光は得られぬ。だからこそ偉大なる無体の神（カーマ）は、月光を味方につけて初めて、その勝利の弓を手に取ったのだ。

anaṅga（無体者）：カーマの別名。シヴァに焼かれて肉体を失った。月と春はカーマの盟友とされる。

34
Sanskrit
sadmanāṃ viracanāhitaśobhair āgatapriyakathair api dūtyam / saṃnikṛṣṭaratibhiḥ suradārair bhūṣitair api vibhūṣaṇam īṣe //
Svāgatā
和訳
愛の祭りが近づくと、天女たちはすでに飾り立てられた部屋をさらに飾り、すでに恋人の便りを受けていても使いを送り、すでに美しく装っていてもなお身を飾ることを求めた。
35
Sanskrit

36
Sanskrit

Svāgatā

37
Sanskrit

Svāgatā
和訳

38
Sanskrit

39
恋する女と使いの対話
Sanskrit

40
Sanskrit

41

42
Sanskrit

使いの女が恋人に語る
Sanskrit
dvāri cakṣur adhipāṇi kapolau jīvitaṃ tvayi kutaḥ kalaho 'syāḥ / kāminām iti vacaḥ punaruktaṃ prītaye navanavatvam iyāya //

和訳

44
Sanskrit

45
Sanskrit
savyalīkam avadhīritakhinnaṃ prasthitaṃ sapadi kopapadena / yoṣitaḥ suhṛd iva sma ruṇaddhi prāṇanātham abhibāṣpanipātaḥ //
Svāgatā
和訳
嘘の口実で蔑ろにされて傷つき、怒りの足取りで立ち去ろうとする主を、女の溢れる涙が友のように引き留めた。
46
Sanskrit
śaṅkitāya kṛtabāṣpanipātām īrṣyayā vimukhitāṃ dayitāya / māninīm abhimukhāhitacittāṃ śaṃsati sma ghanaromavibhedaḥ //
Svāgatā
和訳
疑い深い恋人に対し、嫉妬で涙を流し顔を背けた気位の高い女が、実は心を彼に向けていることを、全身に立つ鳥肌が告げていた。
47
Sanskrit
loladṛṣṭi vadanaṃ dayitāyāś cumbati priyatame rabhasena / vrīḍayā saha vinīvi nitambād aṃśukaṃ śithilatām upapede //
Svāgatā
和訳
最愛の人が揺れる目の恋人の顔を激しく口づけすると、恥じらいとともに帯が解け、衣が腰から滑り落ちた。
48
Sanskrit
hrītayā galitanīvi nirasyann antarīyam avalambitakāñci / maṇḍalīkṛtapṛthustanabhāraṃ sasvaje dayitayā hṛdayeśaḥ //
Svāgatā
和訳
恥じらう恋人の、帯が解けても腰帯だけで留まった下衣を引き剥がすと、心の主は、大きな胸の重みが円く押しつけられるままに彼女と抱き合った。
49
Sanskrit
ādṛtā nakhapadaiḥ parirambhāś cumbitāni ghanadantanipātaiḥ / saukumāryaguṇasambhṛtakīrtir vāma eva surateṣv api kāmaḥ //
Svāgatā
和訳
抱擁は爪痕によって賞され、口づけは強い歯の跡によって讃えられた。繊細さの美徳で名を馳せるカーマも、情事においてはやはり荒々しい。
50
Sanskrit
pāṇipallavavidhūnanam antaḥ sītkṛtāni nayanārdhanimeṣāḥ / yoṣitāṃ rahasi gadgadavācām astratām upayayur madanasya //
Svāgatā
和訳
花のような手を振り、密かに歎息をもらし、半ば目を閉じ、ひそやかに途切れ途切れの声をもらす女たち——これらすべてがカーマの武器となった。
51
Sanskrit
pātum āhitaratīny abhileṣus tarṣayanty apunaruktarasāni / sasmitāni vadanāni vadhūnāṃ sotpalāni ca madhūni yuvānaḥ //
Svāgatā
和訳
愛の息吹を帯び、渇きを誘い、二度と同じ味のない微笑みをたたえた女たちの顔と、蓮華の浮かぶ蜜酒を、若者たちは飲み干すことを望んだ。

杯に蓮の花弁を浮かべて香りをつける習慣（56偈参照）。女たちの顔と酒杯を重ね合わせる。

52
Sanskrit
kāntasaṃgamaparājitamanyau vāruṇīrasanaśāntavivāde / māninījana upāhitasaṃdhau saṃdadhe dhanuṣi neṣum anaṅgaḥ //
Svāgatā
和訳
恋人との逢瀬に意地が敗れ、酒の味わいに争いが静まり、和解が成ったとき、無体の神（カーマ）は弓に矢をつがえることを止めた。
53
Sanskrit
kupyatāśu bhavatānatacittāḥ kopitāṃś ca varivasyata yūnaḥ / ity aneka upadeśa iva sma svādyate yuvatibhir madhuvāraḥ //
Svāgatā
和訳
「すぐに怒り、しかも心を捧げよ。怒らせた若者たちにもまた仕えよ」——このような様々な教えを授けるかのように、乙女たちは酒宴を楽しんだ。
54
Sanskrit
bhartṛbhiḥ praṇayasambhramadattāṃ vāruṇīm atirasāṃ rasayitvā / hrīvimohavirahād upalebhe pāṭavaṃ nu hṛdayaṃ nu vadhūbhiḥ //
Svāgatā
和訳
夫たちが愛の昂ぶりの中で差し出した甘美な酒を味わい、恥じらいも惑いも去った女たちに見てとれたのは、巧みさなのか本心なのか。
55
Sanskrit
svāditaḥ svayam athaidhitamānaṃ lambhitaḥ priyatamaiḥ saha pītaḥ / āsavaḥ pratipadaṃ pramadānāṃ naikarūparasatām iva bheje //
Svāgatā
和訳
まず自ら味わい、次に意地を高め、そして最愛の人とともに飲まれた酒は、女たちにとって一杯ごとに異なる風味を帯びるかのようであった。
56
Sanskrit
bhrūvilāsasubhagān anukartuṃ vibhramān iva vadhūnayanānām / ādade mṛduvilokapalāśair utpalaiś caṣakavīciṣu kampaḥ //
Svāgatā
和訳
泡立つ杯の中で、柔らかな花弁をもつ蓮華が揺れ動くさまは、花嫁たちの目の、眉の戯れに美しいまなざしの揺れを真似るかのようであった。
57
Sanskrit
oṣṭhapallavavidaṃśarucīnāṃ hṛdyatām upayayau ramaṇānām / phullalocanavinīlasarojair aṅganāsyacaṣakair madhuvāraḥ //
Svāgatā
和訳
唇の蕾を噛む麗しさをもつ恋人たちにとって、女たちの顔が杯となり、咲き開いた目が青蓮華となって、酒宴はいっそう心地よいものとなった。
58
Sanskrit
prāpyate guṇavatāpi guṇānāṃ vyaktam āśrayavaśena viśeṣaḥ / tat tathā hi dayitānanadattaṃ vyānaśe madhu rasātiśayena //
Svāgatā
和訳
美質を備えたものでさえ、寄る辺によってさらなる卓越を得るのは明らかだ。だからこそ恋人の口から与えられた酒は、格別な味わいに輝いたのだ。
59
Sanskrit
vīkṣya ratnacaṣakeṣv atiriktāṃ kāntadantapadamaṇḍanalakṣmīm / jajñire bahumatāḥ pramadānām oṣṭhayāvakanudo madhuvārāḥ //
Svāgatā
和訳
宝石の杯に映って一段と際立つ恋人の歯形の飾りの美しさを見て、唇の紅を拭い去る酒宴は女たちの珍重するものとなった。
60
Sanskrit
locanādharakṛtāhṛtarāgā vāsitānanaviśeṣitagandhā / vāruṇī paraguṇātmaguṇānāṃ vyatyayaṃ vinimayaṃ nu vitene //
Svāgatā
和訳
目に赤みを与え唇から赤みを奪い、香る口で芳香を高めた酒は——他者の美質と自らの美質の入れ替えを偶然に行ったのか、意図的に行ったのか。
61
Sanskrit
tulyarūpam asitotpalam akṣṇoḥ karṇagaṃ nirupakāri viditvā / yoṣitaḥ suhṛd iva pravibheje lambhitekṣaṇarucir madarāgaḥ //
Svāgatā
和訳
目と同じ姿をもつ耳の青蓮華が目を引き立てないと知って、酔いの赤みは友のように振る舞い、目に光を与えて両者を分かった。

酔いが目を充血させることで、蓮花の耳飾りと目の区別がつくようになるという趣向。酔いのない目は蓮と見分けがつかない。

62
Sanskrit
kṣīṇayāvakaraso 'py atipānaiḥ kāntadantapadasambhṛtaśobhaḥ / āyayāv atitarām iva vadhvāḥ sāndratām adharapallavarāgaḥ //
Svāgatā
和訳
何度も飲んで紅漆の色が落ちていても、恋人の歯形に美しさを増した花嫁の唇の蕾の色は、いっそう深まったかのようであった。
63
Sanskrit
rāgajāntanayaneṣu nitāntaṃ vidrumāruṇakapolataleṣu / sarvagāpi dadṛśe vanitānāṃ darpaṇeṣv iva mukheṣu madaśrīḥ //
Svāgatā
和訳
情熱に燃える目に、珊瑚のように赤い頬に——酔いの美はどこにでも宿るが、鏡に映るかのように、女たちの顔にとりわけ映し出された。
64
Sanskrit
baddhakopavikṛtīr api rāmāś cārutābhimatatām upaninye / vaśyatāṃ madhumado dayitānām ātmavargahitam icchati sarvaḥ //
Svāgatā
和訳
怒りで顔を歪めてもなお女たちの美しさは愛される対象であり、蜜酒の酔いは恋人たちを従順にした。すべてのものは同類の利益を望むものだ。

文法的な洒落：cārutā（美しさ）は女性名詞で女たちの味方、madhumada（酒酔い）は男性名詞で恋人たちの味方。カッペラーもこの掛詞を注す。

65
Sanskrit
vāsasāṃ śithilatām upanābhi hrīnirāsam apade kupitāni / yoṣitāṃ vidadhatī guṇapakṣe nirmamārja madirā vacanīyam //
Svāgatā
和訳
臍のあたりで衣を緩め、恥じらいを払い、理由なく怒らせる——酒はこれらを美徳の側に置き換えて、女たちの非難されるべきところを拭い去った。
66
Sanskrit
bhartṛṣūpasakhi nikṣipatīnām ātmano madhumadodyamitānām / vrīḍayā viphalayā vanitānāṃ na sthitaṃ na vigataṃ hṛdayeṣu //
Svāgatā
和訳
酒に駆り立てられ、友の目の前で夫に身を投げる女たちの心の中で、もはや役に立たぬ恥じらいは留まりもせず、去りもしなかった。
67
Sanskrit
rundhatī nayanavākyavikāsaṃ sāditobhayakarā parirambhe / vrīḍitasya lalitaṃ yuvatīnāṃ kṣībatā bahuguṇair anujahre //
Svāgatā
和訳
目と言葉の開きを抑え、抱擁のときには両の手の力を萎えさせる――乙女たちの恥じらいのその優美さを、酔いは多くの点で模倣した。
68
Sanskrit
yoṣid uddhatamanobhavarāgā mānavaty api yayau dayitāṅkam / kārayaty anibhṛtā guṇadoṣe vāruṇī khalu rahasyavibhedam //
Svāgatā
和訳
恋の炎に燃え立つ女は、意地を持ちながらも恋人の膝に乗った。軽はずみな酒はまさに善悪の秘密を暴く。
69
Sanskrit
āhite nu madhunā madhuratve ceṣṭitasya gamite nu vikāsam / ābabhau nava ivoddhatarāgaḥ kāminīṣv avasaraḥ kusumeṣoḥ //
Svāgatā
和訳
酒が甘さを添えたのか、戯れが十分に花開いたのか——高まる情熱のなかに、花の矢をもつ神（カーマ）への新たな好機が女たちに現れた。
70
Sanskrit
mā gaman madavimūḍhadhiyo naḥ projjhya rantum iti śaṅkitanāthāḥ / yoṣito na madirāṃ bhṛśam īṣuḥ prema paśyati bhayāny apade 'pi //
Svāgatā
和訳
「酔いに惑わされた心で私たちを捨ててよそへ遊びに行くのでは」と恐れて、女たちは深酒を好まなかった。愛は根拠のない恐れさえ抱くもの。
71
Sanskrit
cittanirvṛtividhāyi viviktaṃ manmatho madhumadaḥ śaśibhāsaḥ / saṃgamaś ca dayitaiḥ sma nayanti prema kām api bhuvaṃ pramadānām //
Svāgatā
和訳
心を悦ばす静寂、カーマ、蜜酒の酔い、月の光、恋人との逢瀬——これらが女たちの愛をこの上ない境地へと導いた。
72
Sanskrit
dhārṣṭyalaṅghitayathocitabhūmau nirdayaṃ vilulitālakamālye / māninīratividhau kusumeṣur mattamatta iva vibhramam āpa //
Svāgatā
和訳
大胆さが礼節の境を越え、容赦なく髪の花飾りを乱す気位の高い女の愛の戯れにおいて、花の矢をもつ神（カーマ）は酔いに酔いを重ねたかのように陶然とした。
73
Sanskrit
śīdhupānavidhureṣu vadhūnāṃ vighnatām upagateṣu vapuḥṣu / īhitaṃ ratirasāhitabhāvaṃ vītalakṣyam api kāmiṣu reje //
Svāgatā
和訳
酒に蕩けた花嫁たちの体がもつれて思うに任せぬとき、恋の味わいに満ちた振舞いは目的を失ってもなお、恋する者たちのうちに美しく輝いた。
74
Sanskrit
anyonyaraktamanasām atha bibhratīnāṃ cetobhuvo harisakhāpsarasāṃ nideśam / vaibodhikadhvanivibhāvitapaścimārdhā sā saṃhṛteva parivṛttim iyāya rātriḥ //
Vasantatilakā
和訳
互いに心を通わせ、カーマの命に従うインドラの友であるアプサラスたちの夜は、報知の声によって後半が告げられると、まるで短く縮められたかのように過ぎ去った。
75
Sanskrit
nidrāvinoditanitāntaratiklamānām āyāmimaṅgalaninādavibodhitānām / rāmāsu bhāvivirahākulitāsu yūnāṃ tatpūrvatām iva samādadhire ratāni //
Vasantatilakā
和訳
眠りによって情事の激しい疲れを癒され、長い吉祥の歌声に目覚めた若者たちの、来たる別離に動揺する女たちとの逢瀬は、あたかも初めてのような新鮮さを帯びた。
76
Sanskrit
kāntājanaṃ suratakhedanimīlitākṣaṃ saṃvāhituṃ samupayān iva mandamandam / harmyeṣu mālyamadirāparibhogagandhān āviścakāra rajanīparivṛttivāyuḥ //
Vasantatilakā
和訳
情事の疲れに目を閉じた女たちを愛撫するかのようにゆっくりと忍び寄り、明け方の風は楼閣のなかに、萎れた花輪と飲み残しの酒の香りを漂わせた。
77
Sanskrit
āmodavāsitacalādharapallaveṣu nidrākaṣāyitavipāṭalalocaneṣu / vyāmṛṣṭapattratilakeṣu vilāsinīnāṃ śobhāṃ babandha vadaneṣu madāvaśeṣaḥ //
Vasantatilakā
和訳
芳香に薫る揺れる唇と、眠りに渋く赤らんだ目と、額の線や飾りの拭い去られた顔に、酔いの名残りが美女たちの美しさを結びつけた。
78
Sanskrit
gatavati nakhalekhālakṣyatām aṅgarāge samadadayitapītātāmrabimbādharāṇām / virahavidhuram iṣṭā satsakhīvāṅganānāṃ hṛdayam avalalambe rātrisambhogalakṣmīḥ //
Mālinī
和訳
塗香が消えて爪痕だけが残り、酔った恋人に吸われてビンバの実のように赤い唇をもつ女たちの、来たる別離に悲しむ心に、一夜の逢瀬の美しい思い出が親しき友のようにすがりついた。
iti bhāravikṛtau mahākāvye kirātārjunīye navamaḥ sargaḥ //
