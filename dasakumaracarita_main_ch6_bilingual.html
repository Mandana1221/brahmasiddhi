1ダーマリプタ到着とカンドゥカ祭

so 'py ācacakṣe — deva, so 'ham api suhṛt-sādhāraṇa-bhramaṇa-kāraṇaḥ suhmeṣu dāmaliptāhvayasya nagarasya bāhyodyāne mahāntam utsava-samājam ālokayam / tatra kvacid atimuktaka-latā-maṇḍape kam api vīṇā-vādenātmānaṃ vinodayantam utkaṇṭhitaṃ yuvānam adrākṣam / aprākṣaṃ ca “bhadra, ko nāmāyam utsavaḥ, kimarthaṃ vā samārabdhaḥ, “kena vā nimittenotsavam anādṛtyaikānte bhavān utkaṇṭhita iva parivādinī-dvitīyas tiṣṭhati” iti /
1.1ミトラグプタもまた物語った。「王よ、私も友人たちと同じ目的で諸国を遍歴し、スフマ国のダーマリプタという都市の郊外の園林で、大きな祭りの群集を目にしました。そこでアティムクタカ蔓の東屋の中に、琵琶を弾いて気を紛らわせている物思いにふけった若者を見かけました。私は尋ねました。『友よ、この祭りは何ですか、何のために催されたのですか、なぜあなたは祭りに構わず、琵琶だけを伴にして一人寂しく物思いにふけっているのですか』と。」
so 'bhyadhatta “saumya, suhma-patis tuṅgadhanvā nāmānapatyaḥ prārthitavān amuṣminn āyatane vismṛta-vindhya-vāsa-rāgaṃ vasantyā vindhyavāsinyāḥ pāda-mūlād apatya-dvayam” / anayā ca kilāsmai pratiśayitāya svapne samādiṣṭam “samutpatsyate tavaikaḥ putraḥ, janiṣyate caikā duhitā / sa tu tasyāḥ pāṇigrāhakam anujīviṣyati / sā tu saptamād varṣād ārabhyāpariṇayanāt pratimāsaṃ kṛttikāsu kanduka-nṛtyena guṇavad-bhartṛ-lābhāya māṃ samārādhayatu / yaṃ cābhilaṣet sāmuṣmai deyā / sa cotsavaḥ kandukotsava-nāmāstu” iti /
1.2彼は答えました。「友よ、スフマ国王トゥンガダンヴァンは子がなく、この寺院において、ヴィンドヤ山への愛着を忘れて住まわれている女神ヴィンドヤヴァーシニーに祈願し、御足元から二人の子を授かりました。女神は横になって眠る王に夢の中でこう告げました。『汝に一人の息子が生まれ、一人の娘も生まれるであろう。息子は娘の婿に従属するものとなる。娘は七歳から結婚するまで、毎月クリッティカー星の日に、優れた夫を得るために鞠の舞で私を供養せよ。彼女が望む者にこそ嫁がせよ。この祭りをカンドゥカ祭と名付けよ』と。」
tato 'lpīyasā kālena rājñaḥ priya-mahiṣī medinī nāmaikaṃ putram asūta / samutpannā caikā duhitā / sādya nāma kanyā kandukāvatī somāpīḍāṃ devīṃ kanduka-vihāreṇārādhayiṣyati /
1.3「やがて王の愛妃メーディニーは一人の息子を産みました。一人の娘も生まれました。その王女カンドゥカーヴァティーは今日、鞠遊びによってソーマーピーダー女神を供養するのです。」

2コーシャダーサとチャンドラセーナー

tasyās tu sakhī candrasenā nāma dhātreyikā mama priyāsīt / sā caiṣu divaseṣu rāja-putreṇa bhīmadhanvanā balavad-anuruddhā / tad aham utkaṇṭhito manmatha-śara-śalya-duḥkhodvigna-cetāḥ kalena vīṇā-raveṇātmānaṃ kiñcid āśvāsayan viviktam adhyāse” iti /
2.1「カンドゥカーヴァティーの親友で乳姉妹のチャンドラセーナーという女性が私の恋人でした。しかし近頃、王子ビーマダンヴァンに強引に言い寄られていました。そこで私はカーマ神の矢の苦痛に心を乱され、琵琶の調べで少しばかり自らを慰めつつ、人気のない場所にいたのです」と。
asminn eva ca kṣaṇe kim api nūpura-kvaṇitam upātiṣṭhat / āgatā ca kācid aṅganā dṛṣṭaiva sa enām utphulla-dṛṣṭir utthāyopagūḍha-kaṇṭhaś ca tayā tatraivopāviśat / aśaṃsac ca “saiṣā me prāṇa-samā, yad-viraho dahana iva dahati mām / idaṃ ca me jīvitam apaharatā rāja-putreṇa mṛtyuneva niruṣmatāṃ nītaḥ / na ca śakṣyāmi rāja-sūnur ityamuṣmin pāpam ācaritum / ato 'nayātmānaṃ su-dṛṣṭaṃ kārayitvā tyakṣyāmi niṣpratikriyān prāṇān” iti /
2.2ちょうどその時、何やら足環の音が聞こえてきました。ある女性がやって来ると、コーシャダーサは彼女を見るなり目を輝かせて立ち上がり、首を抱いてそこに座りました。そして語りました。「これこそ私の命に等しい人です。彼女との別離は火のように私を焼きます。私の命を奪い取る王子は、死神のように私を活力なき者にしました。しかし王族に対して罪を犯すこともできません。だからこの人に自分の姿をよく見せてから、なす術のない命を捨てましょう」と。
sā tu paryaśru-mukhī samabhyadhāt “mā sma nātha, mat-kṛte 'dhyavasyaḥ sāhasam / yas tvam uttamāt sārthavāhād arthadāsād utpadya kośadāsa iti gurubhir abhihita-nāmadheyaḥ punar mad-atyāsaṅgād veśadāsa iti dviṣadbhiḥ prakhyāpito 'si, tasmiṃs tvayyuparate yadyahaṃ jīveyaṃ nṛśaṃso veśa iti samarthayeyaṃ lokavādam / ato 'dyaiva naya mām īpsitaṃ deśam” iti /
2.3彼女は涙に濡れた顔で言いました。「ああ、あなた、私のために無謀なことを決心しないでください。あなたは優れた隊商の長アルタダーサから生まれ、年長者たちにコーシャダーサと名付けられたのに、私への過度の執着のため、敵からはヴェーシャダーサ（遊女の奴隷）と呼ばれるようになりました。あなたが亡くなった後もし私が生きていたら、世間は遊女の世界は残酷だと非難するでしょう。ですから今日のうちに私をお望みの国へ連れて行ってください」と。
sa tu mām abhyadhatta “bhadra, bhavad-dṛṣṭeṣu rāṣṭreṣu katamat samṛddhaṃ saṃpanna-sasyaṃ sat-puruṣa-bhūyiṣṭhaṃ ca” iti / tam aham īṣad vihasyābravam “bhadra, vistīrṇeyam arṇavāmbarā / na paryanto 'sti sthāna-sthāneṣu ramyāṇāṃ janapadānām / api tu na ced iha yuvayoḥ sukha-nivāsa-kāraṇaṃ kam apyupāyam utpādayituṃ śaknuyām / tato 'ham eva bhaveyam adhva-darśī /
2.4彼は私に尋ねました。「友よ、あなたが見てこられた国々の中で、どこが最も繁栄し、穀物が豊かで、善人の多い国ですか」と。私はかすかに微笑んで答えました。「友よ、この大地は海を衣として広大です。あちこちに美しい国は尽きることがありません。しかし、もしここでお二人が幸せに暮らせる方策を何も生み出せなければ、その時は私自身が道案内をいたしましょう。」
tāvatodairata raṇitāni maṇi-nūpurāṇām / athāsau jāta-saṃbhramā “prāpta iveyaṃ bhartṛ-dārikā kandukāvatī kanduka-krīḍitena devīṃ vindhyavāsinīm ārādhayitum / aniṣiddha-darśanā ceyam asmin kandukotsave / saphalam astu yuṣmac-cakṣuḥ / āgacchataṃ draṣṭum / aham asyāḥ sakāśa-vartinī bhaveyam” ityayāsīt / tām anvayāva cāvām /
2.5するとちょうどその時、宝石の足環の音が鳴り響きました。チャンドラセーナーは慌てて言いました。「王女カンドゥカーヴァティーが鞠遊びで女神ヴィンドヤヴァーシニーを供養するためにいらっしゃいました。このカンドゥカ祭では誰でも自由に見ることができます。お二人の目に果報がありますよう。さあ、ご覧になりにいらしてください。私は王女のお側に参ります」と言って去りました。私たち二人は彼女の後を追いました。

3カンドゥカーヴァティーの鞠の舞

mahati ratna-raṅgapīṭhe sthitāṃ prathamaṃ tāmroṣṭhīm apaśyam / atiṣṭhac ca sā sadya eva mama hṛdaye / na mayānyena vāntarāle dṛṣṭā / citrīyāviṣṭa-cittaś cācintayam “kim iyaṃ lakṣmīḥ / nahi nahi / tasyāḥ kila haste vinyastaṃ kamalam, asyās tu hasta eva kamalam / bhukta-pūrvā cāsau purātanena puṃsā pūrva-rājaiś ca, asyāḥ punar anavadyam ayātayāmaṃ ca yauvanam” iti cintayatyeva mayi, sānagha-sarva-gātrī vyatyasta-hasta-pallavāgra-spṛṣṭa-bhūmir ālola-nīla-kuṭilālakā savibhramaṃ bhagavatīm abhivandya kandukam amanda-rāga-rūṣitākṣam anaṅgam ivālambata /
3.1大きな宝石で飾られた舞台の上に座っている赤い唇の女性を、私は最初に目にしました。彼女はたちまち私の心に入りました。その間合いは、私にも誰にも見えないほどでした。驚嘆に心を奪われて私は考えました。「これはラクシュミー女神か。いや、いや。ラクシュミーの手には蓮が置かれているが、この人の手そのものが蓮である。かの女神はかつて原初の男（ヴィシュヌ）や往古の王たちに享受されたが、この人の若さは汚れなく新鮮である」と。私がこう考えているうちに、罪なき完璧な肢体をもつ彼女は、手の若芽のような指先で地面に触れ、揺れる黒く巻いた髪を靡かせながら優美に女神に礼拝し、深紅に染まった目をしたカーマ神のように鞠を手に取りました。
līlā-śithilaṃ ca bhūmau muktavatī / mandotthitaṃ ca kiñcit kuñcitāṅguṣṭhena prasṛta-komalāṅgulinā pāṇipallavena samāhatya hasta-pṛṣṭhena connīya, caṭula-dṛṣṭi-lāñchitaṃ stabakam iva bhramara-mālānuviddham avapatantam ākāśa evāgrahīt / amuñcac ca / madhya-vilambita-druta-laye mṛdu-mṛdu ca praharantī tat-kṣaṇaṃ cūrṇapadam adarśayat / praśāntaṃ ca taṃ nirdaya-prahārair udapātayat / viparyayeṇa ca prāśamayat / pakṣam ṛjvāgataṃ ca vāma-dakṣiṇābhyāṃ karābhyāṃ paryāyeṇābhighnatī śakuntam ivodasthāpayat / dūrotthitaṃ ca prapatantam āhṛtya gītamārgam āracayat / pratidiśaṃ ca gamayitvā pratyāgamayat /
3.2戯れに緩やかに地面に落とすと、ゆっくりと跳ね上がる鞠を、少し曲げた親指と伸ばした柔らかな指の手の若芽で打ち、手の甲で弾き上げ、愛らしい眼差しに彩られた花房のように蜂の列に貫かれて落ちてくるものを空中で掴みました。そしてまた放しました。中間の遅いリズムと速いリズムで柔らかく柔らかく打ちながら、その瞬間に細やかな足捌きを見せました。静まった鞠を容赦ない打撃で跳ね上げ、逆の動きで鎮めました。真っ直ぐ飛んでくる鞠を左右の手で交互に打って、鳥のように飛ばしました。遠くへ飛んで落ちてくるものを受け取って、歌の旋律を奏でました。四方に送り出してはまた呼び戻しました。
evam aneka-karaṇa-madhuraṃ viharantī raṅga-gatasya rakta-cetaso janasya pratikṣaṇam uccāvacāḥ praśaṃsā-vācaḥ pratigṛhṇatī, pratikṣaṇārūḍha-vibhramaṃ kośadāsam aṃse 'valambya kaṇṭakita-gaṇḍam utphullekṣaṇaṃ ca mayyabhimukhībhūya tiṣṭhati tat-prathamāvatīrṇa-kandarpa-kārita-kaṭākṣa-dṛṣṭis tad-anumārga-vilasita-līlāñcita-bhrū-latā, śvāsānila-vegāndolitair dantacchada-raśmi-jālair līlā-pallavair iva mukha-kamala-parimala-grahaṇa-lolān alinas tāḍayantī, maṇḍala-bhramaṇeṣu kandukasyāti-śīghra-pracāratayā viśantīva mad-darśana-lajjayā puṣpamayaṃ pañjaram, pañcabinduprasṛteṣu pañcāpi pañcabāṇa-bāṇān yugapad ivābhipatatas trāsenāvaghaṭṭayantī, gomūtrikā-pracāreṣu ghana-darśita-rāga-vibhramā vidyul-latām iva viḍambayantī,
3.3このように多彩で甘美な技を披露しながら、観覧席で心を奪われた人々からさまざまな称賛の声を受け取り、刻一刻と恋情を募らせるコーシャダーサの肩にもたれ、頬を粟立て目を見開いて私が向かい合って立っていると、その時初めて降り注いだカーマ神の仕業たる流し目、その眼差しの軌跡に沿って戯れ動く優美な眉の蔓、溜息の風に揺れる唇の光の網は、戯れの若芽のように顔という蓮の芳香を求めて飛びかかる蜂たちを打ち、円を描く回転では鞠の極めて速い動きによって、まるで私を見る恥じらいから花の檻に入るかのようであり、五点散らしの技では、五本の花矢の矢が一斉に襲いかかるかのような恐れで鞠をはじき、ゴームートリカー（蛇行）の動きでは、濃密に見せる情愛の戯れで稲妻の蔓を真似るかのようでした。
bhūṣaṇa-maṇi-raṇita-datta-laya-saṃvādi-pāda-cāram, apadeśa-smita-prabhā-niṣikta-bimbādharam, aṃsa-sraṃsita-pratisamāhita-śikhaṇḍa-bhāram, samāghaṭṭita-kvaṇita-ratna-mekhalā-guṇam, añcitotthita-pṛthu-nitamba-vilambita-vicalad-aṃśukojjvalam, ākuñcita-prasṛta-vellita-bhuja-latābhihata-lalita-kandukam, āvarjita-bāhu-pāśam, upari parivartita-trika-vilagna-lola-kuntalam, avagalita-karṇapūra-kanaka-patra-pratisamādhāna-śīghratānatikramita-prakṛta-krīḍanam, asakṛd utkṣipyamāṇa-hasta-pāda-bāhyābhyantara-bhrānta-kandukam, avanamanonnamana-nairantarya-naṣṭa-dṛṣṭa-madhya-yaṣṭikam, avapatanotpatana-nirvyavastha-muktā-hāram, aṅkurita-gharma-salila-dūṣita-kapola-patra-bhaṅga-śoṣaṇādhikṛta-śravaṇa-pallavānilam, āgalita-stana-taṭāṃśuka-niyamana-vyāpṛtaika-pāṇi-pallavaṃ ca niṣadyotthāya nimīlyonmīlya sthitvā gatvā caivāti-citraṃ paryakrīḍata rāja-kanyā /
3.4装飾品の宝石の鳴る音にリズムを合わせた足運び、口実の微笑みの輝きに浸されたビンバの実のような下唇、肩から滑り落ちてはまた整えられる髪飾りの重み、ぶつかり合って鳴る宝石の腰帯の紐、反り上がって立ち上がる豊かな腰に垂れ動く衣の輝き、曲げ伸ばしうねる腕の蔓で優美に打たれる鞠、傾けられた腕の輪、上に回転する腰に絡みつく揺れる巻き毛、落ちた耳飾りの金の葉を直す素早さが本来の遊戯を超える場面、繰り返し投げ上げられ手や足や腕の間を飛び交う鞠、屈んだり伸び上がったりの連続で消えた腰の細さ、落下と上昇の混乱の中で乱れる真珠の首飾り、にじみ出る汗に損なわれた頬の装飾模様を乾かすために働く耳の傍の風、ずり落ちる胸当ての布を直すために片方の手の若芽を使いながら、座っては立ち、目を閉じては開き、止まっては進んで、王女はこの上なく見事に遊戯しました。
abhihatya bhū-talākāśayor api krīḍāntarāṇi darśanīyānyekenaiva vānekenaiva kandukenādarśayat / candrasenādibhiś ca priya-sakhībhiḥ saha vihṛtya vihṛtānte cābhivandya devīṃ manasā me sānurāgeṇeva parijanenānugamyamānā, kuvalaya-śaram iva kusuma-śarasya mayyapāṅgaṃ samarpayantī, sāpadeśam asakṛd āvartyamāna-vadana-candra-maṇḍalatayā sva-hṛdayam iva mat-samīpe preritaṃ pratinivṛttaṃ na vetyālokayantī, saha sakhībhiḥ kumārīpuram agamat /
3.5地上でも空中でも、一つの鞠でも複数の鞠でも、見事な遊技の数々を披露しました。チャンドラセーナーをはじめとする親しい女友達と共に遊び、遊戯の終わりに女神を礼拝すると、恋い慕う従者のように後を追う私の心を引き連れて、私に向かって花の矢を持つカーマ神の青蓮の矢のような流し目を投げかけ、何度も口実を作って月のような顔を私の方に向けながら、自分の心を私の近くに送って戻ってきたのか戻ってこなかったのかと確かめるように見つめ、女友達と共に王女の館へと去りました。
注この鞠の舞（kanduka-nṛtya）の描写はダンディンの最も華麗な散文の一つとして知られる。鞠を打つ技法の名称（cūrṇapada＝細やかな足捌き、gomūtrikā＝蛇行、pañcabindu＝五点散らし、maṇḍalabhramaṇa＝円形回転など）は、古代インドの球技の専門用語である。Kale注参照。

4チャンドラセーナーの策略

ahaṃ cānaṅga-vihvalaḥ sva-veśma gatvā kośadāsena yatnavad atyudāraṃ snāna-bhojanādikam anubhāvito 'smi / sāyaṃ copasṛtya candrasenā rahasi māṃ praṇipatya patyur aṃsam aṃsena praṇaya-peśalam āghaṭṭayantyupāviśat / ācaṣṭa ca hṛṣṭaḥ kośadāsaḥ “bhūyāsam evaṃ yāvadāyur āyatākṣi, tvat-prasādasya pātram” iti /
4.1私はカーマ神に心を乱されて自分の宿に帰り、コーシャダーサに心を込めて立派な沐浴や食事などのもてなしを受けました。夕方になるとチャンドラセーナーがひそかに来て、私に敬礼し、夫の肩に自分の肩を愛情深く触れ合わせて座りました。喜んだコーシャダーサは言いました。「大きな目の人よ、一生こうしてあなたの恩寵を受ける者でありますように」と。
mayā tu sasmitam abhihitam — “sakhe, kim etad āśāsyam / asti kiñcid añjanam / anayā tad-akta-netrayā rāja-sūnur upasthito vānarīm ivaināṃ drakṣyati, viraktaś caināṃ punas tyakṣyati” iti /
4.2私は微笑みながら言いました。「友よ、なぜそんなことを望むのですか。ある軟膏があります。彼女がそれを目に塗って王子の前に出れば、王子は彼女を雌猿のように見て、嫌悪してまた彼女を捨てるでしょう」と。
tayā tu smerayāsmi kathitaḥ “so 'yam āryeṇājñākaro jano 'tyartham anugṛhītaḥ, yad asminn eva janmani mānuṣaṃ vapur apanīya vānarī-kariṣyate / tadāstām idam / anyathāpi siddhaṃ naḥ samīhitam / adya khalu kandukotsave bhavantam apahasita-manobhavākāram abhilaṣantī roṣād iva śambaradviṣātimātram āyāsyate rāja-putrī / so 'yam artho vidita-bhāvayā mayā sva-mātre tayā ca tan-mātre, mahiṣyā ca manujendrāya, nivedayiṣyate / viditārthas tu pārthivas tvayā duhituḥ pāṇiṃ grāhayiṣyati / tataś ca tvad-anujīvinā rāja-putreṇa bhavitavyam / eṣa hi devatā-samādiṣṭo vidhiḥ / tvad-āyatte ca rājye nālam eva tvām atikramya mām avaroddhuṃ bhīmadhanvā / tat sahatām ayaṃ tricaturāṇi dināni” iti mām āmantrya priyaṃ copagūhya pratyayāsīt /
4.3するとチャンドラセーナーは微笑みながら私に言いました。「このお言葉に従う僕は大変なご恩を受けました。この同じ生でもって人間の体を取り去って猿にしていただけるとは。それはさておき、別の方法でも私たちの望みは叶います。今日のカンドゥカ祭で、カーマ神の姿をも嘲笑うあなたを慕った王女は、まるで怒ったかのように愛神（シャンバラの敵）に甚だしく苦しめられています。この事情は、その気持ちを察した私から自分の母に、母からあの方の母へ、王妃から王へ伝えられましょう。事情を知った王はあなたに娘の手を取らせるでしょう。そうすれば王子はあなたの従者となるのです。これは女神が定めた運命です。あなたが王国を得れば、ビーマダンヴァンはもはやあなたを差し置いて私を囲うことなどできません。ですから三日か四日だけお待ちください」と言って私に挨拶し、恋人を抱きしめて帰って行きました。

5ビーマダンヴァンの裏切り

mama ca kośadāsasya ca tad-uktānusāreṇa bahu-vikalpayatoḥ kathañcid akṣīyata kṣapā / kṣapānte ca kṛta-yathocita-niyamas tam eva priyā-darśana-subhagam udyānoddeśam upāgato 'smi / tatraiva copasṛtya rāja-putro nirabhimānam anukūlābhiḥ kathābhir mām anuvartamāno muhūrtam āsta / nītvā copakāryām ātma-samena snāna-bhojana-śayanādi-vyatikareṇopācaram /
5.1コーシャダーサと私は、チャンドラセーナーの言葉に従い、さまざまに思案しながら、何とか夜を過ごしました。夜明けにはいつもの朝の務めを果たし、恋しい人を見た幸せな園林の場所へと向かいました。そこへ王子が自ら近づいてきて、傲慢さもなく親しげな話で私に付き合い、しばらく過ごしました。自分の天幕に連れて行き、自分と同等の沐浴・食事・寝所のもてなしで歓待してくれました。
talpa-gataṃ ca svapnenānubhūyamāna-priyā-darśanāliṅgana-sukham āyasena nigaḍenāti-balavad-bahu-puruṣaiḥ pīvara-bhuja-daṇḍoparuddham abandhayan mām / pratibuddhaṃ ca sahasā samabhyadhāt — “ayi durmate, śrutam ālapitaṃ hatāyāś candrasenāyā jāla-randhra-niḥsṛtaṃ tac ceṣṭāvabodha-prayuktayānayā kubjayā tvaṃ kilābhilaṣito varākyā kandukāvatyā tava kilānujīvinā mayā stheyam, tvad-vacaḥ kilānatikramatā mayā candrasenā kośadāsāya dāsyate” ityuktvā pārśvacaraṃ puruṣam ekam ālokyākathayat — “prakṣipainaṃ sāgare” iti / sa tu labdha-rājya ivāti-hṛṣṭaḥ “deva, yad ājñāpayasi” iti yathādiṣṭam akarot /
5.2しかし寝台に横になり、夢の中で恋しい人との出会いと抱擁の喜びを味わっていた私を、鉄の足枷で、極めて強力な大勢の男たちが太い腕を押さえつけて縛り上げました。目覚めた私に王子は突然こう告げました。「この愚か者め、あのろくでなしのチャンドラセーナーが格子の穴から漏らした話を、その行動を監視するために配置したこの背の曲がった女から聞いたぞ。あの哀れなカンドゥカーヴァティーがお前を慕い、この私がお前の従者になるのだと。お前の言葉に背かずに、私がチャンドラセーナーをコーシャダーサに与えるのだと」と言って、側近の一人を見やり命じました。「こいつを海に投げ込め」と。その男は王位を得たかのように大喜びし、「王子よ、仰せのままに」と命じられた通りにしました。

6海の冒険とヤヴァナ海賊

ahaṃ tu nirālambano bhujābhyām itas tataḥ spandamānaḥ kim api kāṣṭhaṃ daiva-dattam urasopaśliṣya tāvad aploṣi, yāvad apāsarad vāsaraḥ śarvarī ca sarvā / pratyuṣasyadṛśyata kim api vahitram / amutrāsan yavanāḥ te mām uddhṛtya rāmeṣu-nāmne nāvika-nāyakāya kathitavantaḥ “ko 'pyayam āyasa-nigala-baddha eva jale labdhaḥ puruṣaḥ / so 'yam api siñcet sahasraṃ drākṣāṇāṃ kṣaṇenaikena” iti /
6.1私は頼るもののない身で、両腕をあちこち動かしながら、天の恵みで流れてきた何かの木材を胸に抱きしめ、昼が過ぎ夜が明け尽きるまで漂い続けました。明け方に何かの船が見えました。そこにいたヤヴァナ人たちが私を引き上げ、ラーメーシュという名の船長に告げました。「鉄の足枷を嵌められたまま水中で見つかったこの男は、一瞬にして千本の葡萄の木に水を撒けるほどの力の持ち主です」と。
asminn eva kṣaṇe naika-naukā-parivṛtaḥ ko 'pi madgur abhyadhāvat / abibhayur yavanāḥ / tāvad ati-javā naukāḥ śvāna iva varāham asmat-potaṃ paryarutsata / prāvartata saṃprahāraḥ / parājayiṣata yavanāḥ / tān aham agatīn avasīdataḥ samāśvāsyālapiṣam “apanayata me nigala-bandhanam / ayam aham avasādayāmi vaḥ sapatnān” iti / amī tathākurvan sarvāṃś ca tān pratibhaṭān bhalla-varṣiṇā bhīma-ṭaṅkṛtena śārṅgeṇa lavalavīkṛtāṅgān akārṣam /
6.2ちょうどその時、多くの船に囲まれた何者かの大船が突進してきました。ヤヴァナ人たちは恐れおののきました。猛スピードの敵船は犬が猪を追うように我らの船を取り囲みました。戦闘が始まりました。ヤヴァナ人たちは敗れつつありました。行き場を失い沈みゆく彼らを私は励まして言いました。「私の足枷を外してくれ。この私がお前たちの敵を打ち倒そう」と。彼らはそうしました。私は矢を雨のように降らせる恐るべきシャールンガ弓で、すべての敵兵の体を粉々にしました。
avaplutya hata-vidhvasta-yodham asmat-pota-saṃsakta-potam amutra nāvika-nāyakam anabhisaram abhipatya jīva-grāham agrahīṣam / asau cāsīt sa eva bhīmadhanvā / taṃ cāham avabudhya jāta-vrīḍam abravam “tāta, kiṃ dṛṣṭāni kṛtānta-vilasitāni” iti / te tu sāṃyātrikā madīyenaiva śṛṅkhalena tam ati-gāḍhaṃ baddhvā harṣa-kilakilā-ravam akurvan māṃ cāpūjayan /
6.3飛び移って、戦士たちが倒れ打ち砕かれ我らの船に絡みついた敵船の上で、供回りもない船長に飛びかかり、生け捕りにしました。それはなんと、あのビーマダンヴァンその人でした。それと気づいた私は、恥じ入った彼にこう言いました。「殿、運命の戯れをご覧になりましたか」と。船乗りたちは私自身の鎖で彼をきつく縛り上げ、歓喜の歓声を上げて私を讃えました。

7島のブラフマラークシャサ

durvārā tu sā naur ananukūla-vāta-nunnā dūram abhipatya kam api dvīpaṃ nibiḍam āśliṣṭavatī / tatra ca svādu pānīyam edhāṃsi kanda-mūla-phalāni saṃjighṛkṣavo gāḍha-pātita-śilā-valayam avātarāma / tatra cāsīn mahā-śailaḥ /
7.1しかしその船は抗い難く逆風に押されて遠くまで流され、ある島にしっかりと着きました。そこで甘い水や薪や根菜・果物を求めて、投錨のために岩壁を降り、我々は上陸しました。そこには大きな山がありました。
so 'ham “aho ramaṇīyo 'yaṃ parvata-nitamba-bhāgaḥ, kāntatareyaṃ gandhapāṣāṇavatyupatyakā, śiśiram idam indīvarāravinda-makaranda-bindu-candrakottaraṃ gotra-vāri, ramyo 'yam aneka-varṇa-kusuma-mañjarī-bharas taru-vanābhogaḥ” ityatṛptatarayā dṛśā bahu-bahu paśyann alakṣitādhyārūḍha-kṣoṇīdhara-śikharaḥ śoṇībhūtam utprabhābhiḥ padmarāga-sopāna-śilābhiḥ kim api nālīka-parāga-dhūsaraṃ saraḥ samadhyagamam / snātaś ca kāṃścid amṛta-svādūn bisa-bhaṅgān āsvādya, aṃsa-lagna-kahlāras tīra-vartinā kenāpi bhīma-rūpeṇa brahmarākṣasenābhipatya “ko 'si, kutastyo 'si” iti nirbhartsayatābhyadhīye /
7.2私は「ああ、この山の麓の何と美しいことか、この芳香ある石に覆われた山裾はさらに愛らしく、この青蓮と蓮の蜜の滴で冷涼な山の水は心地よく、この多彩な花房を重く垂らした樹木の森の広がりは見事だ」と、満ち足りぬ目であちこちを見つめながら、気づかぬうちに山頂に登り、紅蓮石の階段石の輝きで赤く染まり、蓮の花粉で灰色がかった何かの池に至りました。沐浴し、甘露のように甘い蓮の茎をいくつか味わっていると、肩に睡蓮をかけた私に、岸辺にいた恐ろしい姿のブラフマラークシャサが飛びかかってきて「お前は誰だ、どこから来た」と脅しつけました。
nirbhayena ca mayā so 'bhyadhīyata “saumya, so 'ham asmi dvijanmā / śatru-hastād arṇavam, arṇavād yavana-nāvam, yavana-nāvaś citragrāvāṇam enaṃ parvata-pravaraṃ gataḥ, yadṛcchayāsmin sarasi viśrāntaḥ, bhadraṃ tava” iti / so 'brūta “na ced bravīṣi praśnān, aśnāmi tvām” iti /
7.3恐れずに私は答えました。「友よ、私は再生族（バラモン）です。敵の手から海へ、海からヤヴァナ人の船へ、ヤヴァナ人の船から美しい岩のあるこの優れた山へと来て、偶然この池で休んでいるのです。あなたに幸いあれ」と。彼は言いました。「もし私の質問に答えなければ、お前を食ってしまうぞ」と。
mayoktam “pṛccha tāvat / bhavatu” iti / athāvayor ekayāryayāsīt saṃlāpaḥ — “kiṃ krūraṃ strī-hṛdayaṃ kiṃ gṛhiṇaḥ priya-hitāya dāra-guṇāḥ / kaḥ kāmaḥ saṃkalpaḥ kiṃ duṣkara-sādhanaṃ prajñā //
7.4私は言いました。「では尋ねよ。よかろう」と。そこで我々の間に一つの詩節による対話がありました。 「何が残酷か。女の心が。何が家長の幸福のためか。妻の美徳が。 欲望とは何か。心の想念である。何が困難な事を成し遂げるか。知恵である。」
tatra dhūminī-gominī-nimbavatī-nitambavatyaḥ pramāṇam” ityupadiṣṭo mayā so 'brūta “kathaya, kīdṛśyas tāḥ” iti /
7.5「その証拠としてドゥーミニー、ゴーミニー、ニンバヴァティー、ニタンバヴァティーの話がある」と私が示すと、彼は言いました。「語れ、彼女たちはどのような者か」と。
注ブラフマラークシャサ（brahmārākṣasa）はバラモンの羅刹、すなわち生前にバラモンであった悪鬼。この四つの問いとその例証としての四つの物語は、本章の核心部分をなす。
注aṃsa-lagna-kahlāraḥ（肩に睡蓮をかけた）は語り手ミトラグプタの姿の描写であり、ブラフマラークシャサのものではない。

8ドゥーミニーの物語 — 女の心は残酷なり

atrodāharaṇam “asti trigarto nāma janapadaḥ / tatrāsan gṛhiṇas trayaḥ sphīta-sāra-dhanāḥ sodaryā dhanaka-dhānyaka-dhanyakākhyāḥ / teṣu jīvatsu na vavarṣa varṣāṇi dvādaśa daśaśatākṣaḥ, kṣīṇa-sāraṃ sasyam, oṣadhyo vandhyāḥ, na phalavanto vanaspatayaḥ, klībā meghāḥ kṣīṇasrotasaḥ sravantyaḥ, paṅka-śeṣāṇi palvalāni, nirnisyandānyutsa-maṇḍalāni, viralībhūtaṃ kanda-mūla-phalam, avahīnāḥ kathāḥ, galitāḥ kalyāṇotsava-kriyāḥ, bahulībhūtāni taskara-kulāni, anyonyam abhakṣayan prajāḥ, paryaluṭhann itas tato balākā-pāṇḍurāṇi nara-śiraḥ-kapālāni, paryahiṇḍanta śuṣkāḥ kāka-maṇḍalyaḥ, śūnyībhūtāni nagara-grāma-kharvaṭa-puṭabhedanādīni /
8.1「その実例を語ろう。トリガルタという国があった。そこに三人の同腹の兄弟が住んでおり、豊かな財産を持つ家長で、ダナカ、ダーニャカ、ダニャカという名であった。彼らが生きている間、千の目を持つ神（インドラ）は十二年間雨を降らさなかった。穀物は実らず、薬草は枯れ、樹木は実を結ばず、雲は力なく、河は水の流れを失い、池は泥だけが残り、泉は涸れ、根菜や果物はまばらとなり、語り草は途絶え、祝いの祭事は消え、盗賊の一族が増え、人々は互いを食い合い、あちこちに白鷺のように白い人間の頭蓋骨が転がり、干からびた鴉の群れが徘徊し、都市も村も集落も空っぽになった。
ta ete gṛhapatayaḥ sarva-dhānya-nicayam upayujyājāvikaṃ gavala-gaṇaṃ gavāṃ yūthaṃ dāsī-dāsa-janam apatyāni jyeṣṭha-madhyama-bhārye ca krameṇa bhakṣayitvā “kaniṣṭha-bhāryā dhūminī śvo bhakṣaṇīyā” iti samakalpayan /
8.2この三人の家長たちはすべての穀物の蓄えを使い果たし、山羊・水牛の群れ、牛の群れ、男女の使用人たち、子供たち、長兄と次兄の妻たちを順に食べ、「末弟の妻ドゥーミニーを明日食べよう」と決めた。
atha kaniṣṭho dhanyakaḥ priyāṃ svām attum akṣamas tayā saha tasyām eva niśyapāsarat / mārga-klāntāṃ codvahan vanaṃ jagāhe / sva-māṃsāsṛg-apanīta-kṣut-pipāsāṃ tāṃ nayann antare kam api nikṛtta-pāṇi-pāda-karṇa-nāsikam avani-pṛṣṭhe viceṣṭamānaṃ puruṣam adrākṣīt / tam apyārdrāśayaḥ skandhenodvahan kanda-mūla-mṛga-bahule gahanoddeśe yatna-racita-parṇa-śālaś ciram avasat /
8.3しかし末弟のダニャカは愛する妻を自分では食べることができず、その夜のうちに彼女と共に逃げ出した。道に疲れた彼女を背負って森に分け入った。自分の肉と血で彼女の飢えと渇きを癒しながら道を行く途中、手足・耳・鼻を切り落とされて地面でもがいている男を見つけた。情け深いダニャカはその男をも肩に担ぎ、根菜や獣の豊富な森の奥深くに心を込めて作った葉の小屋で長く暮らした。
amuṃ ca ropita-vraṇam iṅgudītailādibhir āmiṣeṇa śākenātma-nirviśeṣaṃ pupoṣa / puṣṭaṃ ca tam udrikta-dhātum ekadā mṛgānveṣaṇāya ca prayāte dhanyake sā dhūminī riraṃsayopātiṣṭhata / bhartsitāpi tena balātkāram arīramat / nivṛttaṃ ca patim udakābhyarthinam “uddhṛtya kūpāt piba, rujati me śiraḥ śiro-rogaḥ” ityudañcanaṃ sarajjuṃ puraś cikṣepa / udañcayantaṃ ca taṃ kūpād apaḥ, kṣaṇāt pṛṣṭhato gatvā praṇunoda /
8.4イングディー油などで傷を治してやり、肉や菜で自分と同じように養い育てた。体力が回復したその男に対し、ある日ダニャカが猟に出かけた隙に、ドゥーミニーは欲情して言い寄った。男は叱りつけたが、彼女は力ずくで情を交わした。戻ってきた夫が水を求めると、「井戸から汲んで飲んで。頭が痛くて頭痛がするの」と縄付きの桶を放り投げた。夫が井戸から水を汲み上げようとしたその瞬間に、背後に回って突き落とした。
taṃ ca vikalaṃ skandhenoduhya deśād deśāntaraṃ paribhramantī pativratā-pratītiṃ lebhe, bahuvidhāś ca pūjāḥ / punar avanti-rājānugrahād ati-mahatyā bhūtyā nyavasat /
8.5そしてあの不具の男を肩に担いで国から国へと放浪し、貞女としての名声を得、さまざまな崇敬を受けた。さらにアヴァンティ王の恩寵により、非常に大きな富を得て暮らした。
atha pānīyārthi-sārtha-jana-samāpatti-dṛṣṭoddhṛtam avantiṣu bhramantam āhārārthinaṃ bhartāram upalabhya sā dhūminī yena me patir vikalīkṛtaḥ sa durātmāyam” iti tasya sādhoś citra-vadham ajñena rājñā samādeśayāñcakāra / dhanyakas tu datta-paścād bandho vadhyabhūmiṃ nīyamānaḥ saśeṣatvād āyuṣaḥ “yo mayā vikalīkṛto 'bhimato bhikṣuḥ, sa cen me pāpam ācakṣīta, yukto me daṇḍa” ity adīnam adhikṛtaṃ jagāda /
8.6ところが、水を求める隊商の人々に発見され救い出されて、アヴァンティ地方を食を求めてさまよっていた本当の夫ダニャカを見つけると、ドゥーミニーは「私の夫を不具にした邪悪な者はこいつです」と、事情を知らぬ王にあの善良な者の残酷な処刑を命じさせた。しかしダニャカは後手に縛られて刑場に連行されながらも、寿命が尽きていなかったので「私が不具にしたとされる乞食殿を連れて来い。もし彼が私の罪を証言するなら、この処罰は正当だ」と役人に静かに語った。
“ko doṣaḥ” ityupanīya darśite 'muṣmin sa vikalaḥ paryaśruḥ pāda-patitas tasya sādhos tat-su-kṛtam asatyāś ca tasyās tathābhūtaṃ duścaritam ārya-buddhir ācacakṣe / kupitena rājñā virūpita-mukhī sā duṣkṛta-kāriṇī kṛtā śvabhyaḥ pācikā / kṛtaś ca dhanyakaḥ prasāda-bhūmiḥ tad bravīmi “strī-hṛdayaṃ krūram” iti /
8.7「何の問題があろう」とあの不具者を連れて来て見せると、彼は涙を流してダニャカの足元にひれ伏し、高潔な心でダニャカの善行と自身の罪過、そしてあの不誠実な女の忌まわしい悪行を語った。怒った王はドゥーミニーの顔を醜く変え、その悪事を犯した女を犬のための料理女とした。ダニャカは恩赦を受けた。だから私は言うのだ。『女の心は残酷である』と。」

9ゴーミニーの物語 — 妻の美徳

punar anuyukto gominī-vṛttāntam ākhyātavān “asti draviḍeṣu kāñcī nāma nagarī / tasyām aneka-koṭi-sāraḥ śreṣṭhi-putraḥ śaktikumāro nāmāsīt / so 'ṣṭādaśa-varṣa-deśīyaś cintām āpede “nāstyadārāṇām ananuguṇa-dārāṇāṃ vā sukhaṃ nāma / tat kathaṃ nu guṇavad vindeyaṃ kalatram” iti /
9.1「さらに問われてゴーミニーの物語を語った。ドラヴィダの国にカーンチーという都があった。そこに数千万の富を持つ商家の息子でシャクティクマーラという者がいた。彼は十八歳頃になって思い悩んだ。『妻のいない者にも、相応しくない妻を持つ者にも、幸福というものはない。では、どうすれば美徳ある妻を見つけられるだろうか』と。
atha vara-pratyayāhṛteṣu dāreṣu yādṛcchikīṃ saṃpattim anabhisamīkṣya kārtāntiko nāma bhūtvā vastrānta-pinaddha-śāli-prastho bhuvaṃ babhrāma / “lakṣaṇa-jño 'yam” ityamuṣmai kanyāḥ kanyāvantaḥ pradarśayāṃbabhūvuḥ / yāṃ kāṃcil lakṣaṇavatīṃ savarṇāṃ kanyāṃ dṛṣṭvā sa kila sma bravīti “bhadre, śaknoṣi kim anena śāli-prasthena guṇavad annam asmān abhyavahārayitum” iti / sa hasitāvadhūto gṛhād gṛhaṃ praviśyābhramat /
9.2花婿選びで連れて来られた妻たちに偶然の相性を当てにすることを良しとせず、カールターンティカ（占い師）を装い、衣の端に一プラスタ（約750g）の米を包んで大地をさまよった。『この人は人相見だ』と言って、娘を持つ者たちが彼に娘を見せた。吉相があり同じ身分の娘を見るたびに彼はこう尋ねた。『娘さん、このプラスタの米で我々に上等な食事を作れますか』と。笑って相手にされず、家から家へとさまよった。
ekadā tu śibiṣu paṭṭane saha pitṛbhyām avasita-maharddhim avaśīrṇa-bhavana-sārāṃ dhātryā pradarśyamānāṃ kāṃcana virala-bhūṣaṇāṃ kumārīṃ dadarśa / asyāṃ saṃsakta-cakṣuś cātarkayat “asyāḥ khalu kanyakāyāḥ sarva evāvayavā nāti-sthūlā nāti-kṛśā nāti-hrasvā nāti-dīrghā na vikaṭā mṛjāvantaś ca / rakta-talāṅgulī yava-matsya-kamala-kalaśādyaneka-puṇya-lekhā-lāñchitau karau, sama-gulpha-saṃdhī māṃsalāvaśirālau cāṅghrī, jaṅghe cānupūrva-vṛtte, pīvaroru-graste iva durupalakṣye jānunī, sakṛd vibhaktaś caturasraḥ kakundara-vibhāga-śobhī rathāṅgākāra-saṃsthitaś ca nitamba-bhāgaḥ tanutaram īṣan nimnaṃ gambhīraṃ nābhi-maṇḍalam, vali-trayeṇa cālaṅkṛtam udaram,
9.3ある時シビ国のある港町で、両親と共に住む、かつての富を失い家屋も朽ちかけた娘を乳母に案内されて見た。飾りの少ないその娘に目が釘付けになり、彼は観察した。『この娘の体の各部位はすべて、太すぎず痩せすぎず、短すぎず長すぎず、不格好でもなく、清潔である。手のひらには赤い線、魚・蓮・水瓶などの多くの吉祥の紋様がある。足首の関節は整い、肉付きよく静脈が見えず、脛は優美に丸く、太い太腿に隠れるように膝は目立たず、整然として四角く、カクンダラの区分が美しく車輪の形をした臀部、薄く僅かにくぼんだ深い臍、三条の皺に飾られた腹、
uro-bhāga-vyāpināv unmagna-cūcukau viśālārambha-śobhinau payodharau, dhana-dhānya-putra-bhūyastva-cihna-lekhā-lāñchita-tale snigdhodagra-komala-nakha-maṇī ṛjvanupūrva-vṛtta-tāmrāṅgulī saṃnatāṃsa-deśe saukumāryavatyau nimagna-parva-saṃdhī ca bāhu-late, tanvī kambu-vṛtta-bandhurā ca kandharā, vṛtta-madhya-vibhakta-rāgādharam, asaṃkṣipta-cāru-cibukam, āpūrṇa-kaṭhina-gaṇḍa-maṇḍalam, saṃgatānuvakra-nīla-snigdha-bhrū-latam, anatiprauḍha-tila-kusuma-sadṛśa-nāsikam, atyasita-dhavala-rakta-tri-bhāga-bhāsura-madhurādhīra-saṃcāra-mantharāyatekṣaṇam, indu-śakala-sundara-lalāṭam, indranīla-śilākāra-ramyālaka-paṅkti dviguṇa-kuṇḍalita-mlāna-nālīka-nāla-lalita-lamba-śravaṇa-pāśa-yugalam ānana-kamalam, anati-bhaṅguro bahulaḥ paryante 'py akapila-rucirāyāmavān ekaika-nisarga-sama-snigdha-nīlo gandhagrāhī ca mūrdhaja-kalāpaḥ /
9.4胸の広がりにそびえ突出した乳首の美しい豊かな乳房、富・穀物・多子の吉兆の線が刻まれた掌に艶やかで高く柔らかい爪の宝石と真っ直ぐに丸く順に銅色の指を持ち、なだらかに下がる肩の辺りは柔らかく関節の接合が目立たない両腕、細く法螺貝のように丸く美しく曲がった首、丸みのある中央で赤みを分かつ唇、小さくない美しい顎、ふっくらと固い頬の輪郭、合わさった僅かに曲がる黒く艶やかな眉の蔓、胡麻の花のように成熟しすぎない鼻、極めて黒・白・赤の三部分に輝く甘くゆったりした動きの緩やかに長い瞳、三日月のように美しい額、インドラニーラ宝石のように美しい巻き毛の列と二重に巻かれた萎びた蓮の茎のように優美に垂れた耳飾りの対を持つ顔という蓮、過度に脆くなく豊かで端でも褐色がからず美しい長さを持ち一本一本が天性にしっとりと黒く芳香を帯びた頭髪の束。
seyam ākṛtir na vyabhicarati śīlam / āsajati ca me hṛdayam asyām eva / tat parīkṣyainām udvaheyam / avimṛśya kāriṇāṃ hi niyatam anekāḥ patanty anuśaya-paramparāḥ” iti snigdha-dṛṣṭir ācaṣṭa “bhadre, kaccid asti kauśalaṃ śāli-prasthenānena saṃpannam āhāram asmān abhyavahārayitum” iti /
9.5この容姿は品性を裏切ることがない。私の心はこの娘にこそ惹かれる。試した上で彼女を娶ろう。慎重さを欠く者には必ず多くの後悔が連なるものだ』と。優しい眼差しで彼は尋ねた。『娘さん、このプラスタの米で上等な食事を我々に作る腕前がありますか』と。
tatas tayā vṛddha-dāsī sākūtam ālokitā / tasya hastāt prastha-mātraṃ dhānyam ādāya kvacid alindoddeśe su-sikta-saṃmṛṣṭe datta-pāda-śaucam upāveśayat / sā kanyā tān gandha-śālīn saṃkṣudya mātrayā viśoṣyātape muhur muhuḥ parivartya sthira-samāyāṃ bhūmau nālīpṛṣṭhena mṛdu-mṛdu ghaṭṭayantī tuṣair akhaṇḍais taṇḍulān pṛthak cakāra /
9.6すると彼女は老女中に意味ありげな目配せをし、彼の手から一プラスタの穀物を受け取り、よく水を撒いて掃き清められた廊下の一角に足を洗わせて座らせた。その娘は芳しい米を量りながら砕き、日に当てて何度もひっくり返して乾かし、堅く平らな地面の上で管の裏で柔らかく柔らかく叩いて、一粒も砕かずに籾と米粒を分けた。
jagāda ca dhātrīm “mātaḥ, ebhis tuṣair arthino bhūṣaṇa-mṛjā-kriyā-kṣamaiḥ svarṇakārāḥ / tebhya imān dattvā labdhābhiḥ kākiṇībhiḥ sthiratarāṇy anatyārdrāṇi nāti-śuṣkāṇi kāṣṭhāni mitaṃpacāṃ sthālīm ubhe śarāve cāhara” iti /
9.7そして乳母に言った。『お母さん、この籾殻は装飾品の研磨に使えるので金細工師が欲しがります。これを彼らに渡して、得たカーキニー銅貨で、しっかりした湿りすぎも乾きすぎもしない薪と、少量で調理できる鍋と二枚の皿を買ってきてください』と。
tathā kṛte tayā tāṃs taṇḍulān anati-nimnottāna-vistīrṇa-kukṣau kakubholūkhale loha-patra-veṣṭita-mukhena sama-śarīreṇa vibhāvyamāna-madhya-tānavena vyāyatena guruṇā khādireṇa musalena catura-lalita-kṣepaṇotkṣepaṇāyāsita-bhujam asakṛd aṅgulībhir uddhṛtyoddhṛtyāvahatya śūrpa-śodhita-kaṇa-kiṃśārukāṃs taṇḍulān asakṛd adbhiḥ prakṣālya kvathita-pañcaguṇe jale datta-cullī-pūjā prākṣipat /
9.8そうされると、彼女はその米粒を、あまり深くも浅くも広くもない腹のカクバ材の臼に入れ、鉄の板で巻かれた口を持つ均整のとれた体で明瞭に中央が細い重い長いカディラ材の杵で、巧みに優雅に上げ下げして腕を働かせ、何度も指で取り出しては箕でふるって糠と小さな殻を除いた米粒を、何度も水で洗い、五倍に沸かした湯に竈に供養をしてから入れた。
praślathāvayaveṣu prasphuratsu taṇḍuleṣu mukulāvasthām ativartamāneṣu saṃkṣipyānalam upahita-mukha-pidhānayā sthālyānna-maṇḍam agālayat / darvyā cāvaghaṭya mātrayā parivartya sama-pakveṣu siktheṣu tāṃ sthālīm adhomukhīm avātiṣṭhipat / indhanānyantaḥ sārāṇyambhasā samabhyukṣya praśamitāgnīni kṛṣṇāṅgārīkṛtya tad-arthibhyaḥ prāhiṇot /
9.9米粒がほぐれて膨らみ、蕾の段階を過ぎようとする頃、火を弱め蓋をした鍋で重湯を取り出した。杓子でかき混ぜ量を測って返し、飯が均等に炊けると鍋を逆さに伏せた。芯のある薪を水で湿らせて火を消し、黒い炭にして、それを欲しがる者に送った。
“ebhir labdhāḥ kākiṇīr dattvā śākaṃ dhṛtaṃ dadhi tailam āmalakaṃ ciñcā-phalaṃ ca yathālābham ānaya” iti / tathānuṣṭhite ca tayā dvitrān upadaṃśān upapādya tad anna-maṇḍam ārdra-vālukopahita-nava-śarāva-gatam iti mṛdunā tālavṛntānilena śītalīkṛtya salavaṇa-saṃbhāraṃ dattāṅgāra-dhūpa-vāsaṃ ca saṃpādya, tad apyāmalakaṃ ślakṣṇa-piṣṭam utpala-gandhi kṛtvā dhātrī-mukhena snānāya tam acodayat /
9.10『これで得たカーキニー銅貨で、菜、澄ましバター、凝乳、油、アーマラカ果、タマリンドの実を手に入る限り買ってきて』と。そうされると、二、三品の副菜を用意し、その重湯を湿った砂を置いた新しい皿に入れて柔らかな棕櫚団扇の風で冷まし、塩と薬味を加え炭の煙で燻して整え、アーマラカ果も滑らかにすりつぶして蓮の香りにし、乳母を通して沐浴を勧めた。
tayā ca snāna-śuddhayā datta-tailāmalakaḥ krameṇa sasnau / snātaḥ sikta-mṛṣṭe kuṭṭime phalakam āruhya pāṇḍu-haritasya tri-bhāga-śeṣa-lūnasyāṅgaṇa-kadalīpalāśasyopari datta-śarāva-dvayam ārdram abhimṛśann atiṣṭhat / sā tu tāṃ peyām evāgre samupāharat / pītvā cāpanītādhva-klamaḥ prahṛṣṭaḥ praklinna-sakala-gātraḥ sthito 'bhūt /
9.11乳母による清い沐浴で油とアーマラカ果を与えられて順に沐浴した。沐浴を終えると水で洗い清められた床の上、板に上り、三分の一を残して切った庭の淡緑のバナナの葉の上に置かれた二枚の皿の湿り気に触れながら立っていた。彼女はまずあの重湯を供した。飲むと旅の疲れが去り、喜びに満ち体中がしっとりとなった。
tatas tasya śālyodanasya darvī-dvayaṃ dattvā sarpir-mātrāṃ sūpam upadaṃśaṃ copajahāra / imaṃ ca dadhnā ca trijātakāvacūrṇitena surabhi-śītalābhyāṃ ca kālaśeya-kāñjikābhyāṃ śeṣam annam abhojayat / saśeṣa evāndhasyasāvatṛṣyat / ayācata ca pānīyam /
9.12次に米飯を杓子二杯盛り、澄ましバターを少し、豆のスープと副菜を添えた。凝乳と三種の香辛料を振りかけたもの、そして香り高く冷たいバターミルクと酸い粥汁とで残りの飯を食べさせた。飯がまだ残っているうちに彼は喉が渇いた。水を求めた。
atha nava-bhṛṅgāra-saṃbhṛtam aguru-dhūpa-dhūpitam abhinava-pāṭalā-kusuma-vāsitam utphullotpala-grathita-saurabhaṃ vāri nālīdhārātmanā pātayāṃbabhūva / so 'pi mukhopahita-śarāveṇa hima-śiśira-kaṇa-karālitāruṇāyamānākṣi-pakṣmā dhārā-ravābhinandita-śravaṇaḥ sparśa-sukhodbhinna-romāñca-karkaśa-kapolaḥ pravālotpīḍa-parimala-phulla-ghrāṇa-randhro mādhurya-prakarṣāvarjita-rasanendriyas tad acchaṃ pānīyam ākaṇṭhaṃ papau /
9.13すると新しい水瓶に入れたアグル香の煙で燻し、咲いたばかりのパータラー花の香りを付け、満開の青蓮の芳香を編み込んだ水を、管から細い流れにして注いだ。彼も口に皿を当てて、雪のように冷たい水滴に赤みを帯びた睫毛を震わせ、水流の音に耳を楽しませ、触れる快さに鳥肌の立つ頬で、珊瑚を搾ったような芳香に鼻孔を開き、甘美の極みに味覚を奪われて、その澄んだ水を喉まで飲み干した。
śiraḥ-kampa-saṃjñā-vāritā ca punar apara-karakeṇācamanam adatta kanyā / vṛddhayā tu tad ucchiṣṭam apohya harita-gomayopalipte kuṭṭime svam evottarīya-karpaṭaṃ vyavadhāya kṣaṇam aśeta / parituṣṭaś ca vidhivad upayamya kanyāṃ ninye /
9.14頭を振る合図で止められると、もう一つの水差しで口をすすがせた。老女中は残り物を片付け、緑の牛糞で塗られた床に自分の上着の布切れを敷いて、少しの間休ませた。満足した彼は礼法に則って娘を娶り連れ帰った。
nītvaitad anapekṣaḥ kām api gaṇikām avarodham akarot / tām apyasau priya-sakhīm ivopācarat / patiṃ ca daivatam iva mukta-tandrā paryacarat / gṛha-kāryāṇi cāhīnam anvatiṣṭhat / parijanaṃ ca dākṣiṇya-nidhir ātmādhīnam akarot / tad-guṇa-vaśīkṛtaś ca bhartā sarvam eva kuṭumbaṃ tad-āyattam eva kṛtvā tad-ekādhīna-jīvita-śarīras trivargaṃ nirviveśa / tad bravīmi “gṛhiṇaḥ priya-hitāya dāra-guṇāḥ” iti /
9.15連れ帰った後、彼は彼女を顧みずにある遊女を囲った。彼女はその女をも親友のように遇した。夫を神のように倦むことなく仕えた。家事を一つも欠かさず行った。巧みな礼儀正しさで使用人を自分の意のままにした。その美徳に服した夫は全家族を彼女に委ね、彼女一人に命と体を任せて三種の目的（法・利・愛）を遂行した。だから私は言うのだ。『家長の幸福のためには妻の美徳こそが要である』と。」
注ゴーミニーの物語は、一プラスタの米で完璧な食事を供する理想的な主婦の技量を極めて詳細に描写した、古代インド家政術の貴重な記録として知られる。Kale注によれば、南インドの家庭経済の実態を反映している。

10ニンバヴァティーの物語 — 欲望とは心の想念なり

tatas tenānuyukto nimbavatī-vṛttam ākhyātavān “asti saurāṣṭreṣu valabhī nāma nagarī / tasyāṃ guhagupta-nāmno guhyakendra-tulya-vibhavasya nāvika-pater duhitā ratnavatī nāma / tāṃ kila madhumatyāḥ samupāgamya balabhadro nāma sārthavāha-putraḥ paryaṇaiṣīt / tayāpi nava-vadhvā rahasi rabhasa-vighnita-surata-sukho jhaṭiti dveṣam alpetaraṃ babandha / na tāṃ punar draṣṭum iṣṭavān / tad-gṛhāgamanam api suhṛd-vākya-śatātivartī lajjayā parijahāra /
10.1「さらに問われてニンバヴァティーの話を語った。サウラーシュトラの国にヴァラビーという都があった。そこにグハグプタという名の、ヤクシャの王に匹敵する富を持つ船主の娘がラトナヴァティーであった。彼女のところにマドゥマティーの町からバラバドラという隊商主の息子が求婚に来た。しかし新妻との初夜において性急に中断された情事の不快感から、たちまち少なからぬ嫌悪を抱いた。二度と彼女を見ようとはせず、友人たちの百の言葉にも背いて、恥じらいから彼女の家に近づくことすらしなくなった。
tāṃ ca durbhagāṃ tadā prabhṛtyeva “neyaṃ ratnavatī, nimbavatī ceyam” iti sva-janaḥ parijanaś ca paribabhūva / gate ca kasmiṃścit kālāntare sā tvanutapyamānā “kā me gatiḥ” iti vimṛśantī kām api vṛddha-pravrājikāṃ mātṛ-sthānīyāṃ deva-śeṣa-kusumair upasthitām apaśyat / tasyāḥ puro rahasi sakaruṇaṃ ruroda /
10.2不幸な彼女はその時以来、『この人はラトナヴァティー（宝石の女）ではなくニンバヴァティー（苦い女）だ』と親族や使用人たちに蔑まれた。いくらかの時が過ぎると、彼女は悔い悩み、『私にはどんな行く末があるのか』と思い巡らしていた折、母親代わりの年老いた遍歴の尼僧が神への供え花の残りを持って訪れるのを見かけた。その前で人目を避けて哀れに泣いた。
tayāpyaśru-mukhyā bahu-prakāram anunīya rudita-kāraṇaṃ pṛṣṭā trapamāṇāpi kārya-gauravāt kathaṃcid abravīt “amba, kiṃ bravīmi daurbhāgyaṃ nāma jīvan-maraṇam evāṅganānām, viśeṣataś ca kulavadhūnām / tasyāham asmyudāharaṇa-bhūtā / mātṛ-pramukho 'pi jñāti-vargo mām avajñayaiva paśyati / tena su-dṛṣṭāṃ māṃ kuru / na cet tyajeyam adyaiva niṣprayojanān prāṇān / ā virāmāc ca me rahasyaṃ nāśrāvyam” iti pādayoḥ papāta /
10.3涙顔の彼女をさまざまに慰め泣いている理由を尋ねると、恥じらいながらも事の重大さから何とか打ち明けた。『お母さま、何と申しましょう、不幸というものは女にとってまさに生ける死です、特に良家の嫁にとっては。その実例が私なのです。母をはじめ親族も皆、軽蔑の目で私を見ます。ですから私をうまくお導きください。さもなくば今日にも無用な命を捨てます。そして私の秘密は最後まで誰にも漏らさないでください』と足元にひれ伏した。
sainām utthāpyodvāṣpovāca “vatse, mādhyavasya sāhasam / iyam asmi tvan-nideśa-vartinī / yāvati mayopayogas tāvati bhavāmyananyādhīnā / yadyevāsi nirviṇṇā tapaś cara tvaṃ mad-adhiṣṭhitā pāralaukikāya kalyāṇāya / nanvayam udarkaḥ prāktanasya duṣkṛtasya, yad anenākāreṇedṛśena śīlena jātyā caivaṃbhūtayā samanugatā satī akasmād eva bhartṛ-dveṣyatāṃ gatāsi / yadi kaścid astyupāyaḥ pati-droha-pratikriyāyai darśayāmum, matir hi te paṭīyasī” iti /
10.4尼僧は彼女を起こし、涙を拭いて言った。『娘よ、無謀なことを決心してはなりません。この私があなたの命に従う者です。私が役に立てる限りは他の誰にも頼らずにすみましょう。もしそんなに嫌気がさしているなら、私の監督のもとに苦行をして来世の幸福のために励みなさい。これは前世の悪業の報いなのです、このような容姿で美徳も家柄もこのように備わりながら、夫に嫌われるに至ったのは。もし夫の無関心を覆す方策があるなら見せてください、あなたの知恵は鋭いのですから』と。
athāsau kathañcit kṣaṇam adhomukhī dhyātvā dīrghoṣṇa-śvāsa-pūrvam avocat “bhagavati, patir eka-daivataṃ vanitānām, viśeṣataḥ kula-jānām / atas tacchuśrūṣaṇābhyupāya-hetu-bhūtaṃ kiñcid ācaraṇīyam / astyasmat-prātiveśyo vaṇig abhijanena vibhavena rājāntaraṅga-bhāvena ca sarva-paurān atītya vartate / tasya kanyā kanakavatī nāma mat-samāna-rūpāvayavā mamāti-snigdhā sakhī / tayā saha tad-vimāna-harmya-tale tato 'pi dviguṇa-maṇḍitā vihariṣyāmi /
10.5彼女はしばしうつむいて考え、長く熱い溜息をついてから言った。『尊い方よ、夫こそが女の唯一の神です、特に良家の女にとっては。ですから夫への奉仕の方便となる何かを行わねばなりません。私たちの隣に、家柄・財力・王への親密さにおいて全ての市民を凌ぐ商人がいます。その娘カナカヴァティーは私と同じ容姿と体格で、私の大の親友です。彼女と共にあの邸宅の屋上で、さらに倍の装いをして遊びましょう。
tvayā tu tan-mātṛ-prārthanaṃ sakaruṇam abhidhāya mat-patir etad gṛhaṃ kathañcanāneyaḥ / samīpa-gateṣu ca yuṣmāsu krīḍā-mattā nāma kandukaṃ bhraṃśayeyam / atha tam ādāya tasya haste dattvā vakṣyasi “putra, taveyaṃ bhāryā-sakhī nidhi-pati-dattasya sarva-śreṣṭhi-mukhyasya kanyā kanakavatī nāma / tvām iyam anavastho niṣkaruṇaś ceti ratnavatī-nimittam atyarthaṃ nindati / tad eṣa kanduko vipakṣa-dhanaṃ pratyarpaṇīyam” iti / sa tathokto niyatam unmukhībhūya tām eva priya-sakhīṃ manyamāno māṃ baddhāñjali yācamānāyai mahyaṃ bhūyas tvat-prārthitaḥ sābhilāṣam arpayiṣyati / “tena randhreṇopaśliṣya rāgam ujjvalīkṛtya yathāsau kṛta-saṅketo deśāntaram ādāya māṃ gamiṣyati tathopapādanīyam” iti /
10.6あなたは彼女の母への懇願を哀れっぽく伝えながら、何とかして私の夫をこの家へ連れてきてください。近くに来たら、私は遊びに夢中なふりをして鞠を落としましょう。それを拾って彼の手に渡しながらこう言ってください。「坊や、これはあなたの奥さんの親友で、宝の守護者ニディパティダッタ殿という全商人の長の娘カナカヴァティーという方よ。この方はあなたのことを冷淡で無情だとラトナヴァティーのことでひどく非難しているの。だからこの鞠は敵方の財産として返さねばなりません」と。そう言われれば彼はきっと関心を持ち、親友だと思い込んでいる私に、合掌して頼む私に、あなたの懇願を受けて好意を持って渡すでしょう。その隙に近づいて情愛を燃え上がらせ、約束を取り付けて別の国へ連れ去るよう仕向けるのです』と。
harṣābhyupetayā cānayā tathaiva saṃpāditam / athaitāṃ kanakavatīti vṛddha-tāpasī-vipralabdho balabhadraḥ saratna-sābharaṇām ādāya niśi nīrandhre tamasi prāvasat / sā tu tāpasī vārtām āpādayat “mandena mayā nirnimittam upekṣitā ratnavatī, śvaśurau ca paribhūtau, suhṛdaś cātivartitāḥ / tad atraiva saṃsṛṣṭo jīvituṃ jihremīti balabhadraḥ pūrvedyur mām akathayat / nūnam asau tena nītā vyaktiś cācirād bhaviṣyati” iti / tacchrutvā tad-bāndhavās tad-anveṣaṇāṃ prati śithila-yatnās tasthuḥ /
10.7喜びに溢れた尼僧によってまさにその通りに手配された。カナカヴァティーだと老い行者女に騙されたバラバドラは、宝石を散りばめた装飾品を持つ彼女を連れて、隙間のない闇夜に旅立った。尼僧は噂を流した。「愚かな私が理由もなくラトナヴァティーを軽んじ、舅姑も蔑ろにし、友人たちも裏切った。だからここで結ばれて生きるのは恥ずかしいとバラバドラが前日私に語っていた。きっと彼に連れ去られたのだろう、やがて明らかになるだろう」と。これを聞いたその親族は捜索の努力を緩めた。
ratnavatī tu mārge kāñcit paṇya-dāsīṃ saṃgṛhya tayohyamāna-pātheyādyupaskarā kheṭakapuram agamat / amutra ca vyavahāra-kuśalo balabhadraḥ svalpenaiva mūlena mahad dhanam upārjayat / paurāgragaṇyaś cāsīt / parijanaś ca bhūyān artha-vaśāt samājagāma / tatas tāṃ prathama-dāsīm “na karma karoṣi, dṛṣṭaṃ muṣṇāsi, apriyaṃ bravīṣi” iti paruṣam uktvā bahvatāḍayat /
10.8ラトナヴァティーは道中で買い取った女奴隷を一人手に入れ、彼女に食料など旅支度を運ばせてケータカプラに着いた。かの地で商売上手のバラバドラはわずかな元手で大きな富を築いた。町の筆頭に数えられた。使用人も大勢、財力によって集まった。するとあの最初の女奴隷に対して「お前は仕事をしない、目の前の物を盗む、不快なことを言う」と厳しく叱って何度も打った。
ceṭī tu prasāda-kālopākhyāta-rahasyasya vṛttāntaika-deśam ātta-roṣā nirbibheda / tacchrutvā lubdhena tu daṇḍavāhinā paura-vṛddha-saṃnidhau nidhi-pati-dattasya kanyāṃ kanakavatīṃ moṣeṇāpahṛtyāsmat-pure nivasatyeṣa durmatir balabhadraḥ / tasya sarva-sva-haraṇaṃ na bhavadbhiḥ pratibandhanīyam” iti nitarām abhartsyata /
10.9女奴隷は怒りにまかせて、御機嫌を取る時に聞き出した秘密の一部を暴露した。それを聞いた欲深い奉行が市の長老たちの前で「ニディパティダッタの娘カナカヴァティーを盗み出してこの町に住んでいるのはこの悪党バラバドラだ。その全財産を没収することを諸公は阻止してはならぬ」と厳しく脅した。
bhītaṃ ca balabhadram abhijagāda ratnavatī “na bhetavyam / brūhi, neyaṃ nidhi-pati-datta-kanyā kanakavatī / valabhyām eva gṛhagupta-duhitā ratnavatī nāmeyaṃ dattā pitṛbhyāṃ mayā ca nyāyoḍhā / na cet pratītha praṇidhiṃ prahiṇutāsyā bandhu-pārśvam” iti / balabhadras tu tathoktvā śreṇīprātibhāvyena tāvad avātiṣṭhata yāvat tat-pura-vṛddha-lekhya-labdha-vṛttānto gṛhaguptaḥ kheṭakapuram āgatya saha jāmātrā duhitaram ati-prītaḥ pratyanaiṣīt / tathā dṛṣṭvā ratnavatīṃ kanakavatīti bhāvayatas tasyaiva balabhadrasyāti-vallabhā jātā / tad bravīmi “kāmo nāma saṃkalpaḥ” iti /
10.10怯えるバラバドラにラトナヴァティーは言った。「恐れることはありません。こう言いなさい。この人はニディパティダッタの娘カナカヴァティーではなく、ヴァラビーのグハグプタの娘ラトナヴァティーで、両親が私に与え正式に娶った妻です。信じないなら、彼女の親族のもとへ使者を送ってください」と。バラバドラがそう述べ、商人組合の保証の下で待っていると、やがてかの都の長老の書簡で事実を知ったグハグプタがケータカプラに来て、婿と共に娘を大いに喜んで連れ帰った。こうしてラトナヴァティーをカナカヴァティーだと思い込んでいたバラバドラにとって、彼女は最愛の妻となった。だから私は言うのだ。『欲望とは心の想念にすぎない』と。」

11ニタンバヴァティーの物語 — 知恵こそが困難を成し遂げる

tad-anantaram asau nitambavatī-vṛttāntam aprākṣīt / so 'ham abravam “asti śūraseneṣu mathurā nāma nagarī / tatra kaścit kula-putraḥ kalāsu gaṇikāsu cāti-raktaḥ mitrārthaṃ sva-bhuja-mātra-nirvyūḍhāneka-kalahaḥ, kalahakaṇṭaka iti karkaśair abhikhyāpitākhyaḥ pratyavātsīt /
11.1「続いてラークシャサはニタンバヴァティーの話を尋ねた。私は語った。シューラセーナの国にマトゥラーという都があった。そこにある良家の子で、諸芸と遊女の両方に熱中し、友のために自らの腕一つで幾多の争いをものにした、カラハカンタカ（喧嘩の棘）と荒々しい者たちに渾名された男がいた。
sa caikadā kasyacid āgantoś citrakarasya haste citra-paṭaṃ dadarśa / tatra kācid ālekhya-gatā yuvatir āloka-mātreṇaiva kalahakaṇṭakasya kāmāturaṃ cetaś cakāra / sa ca tam abravīt “bhadra, viruddham ivaitat pratibhāti yataḥ kula-jādurlabhaṃ vapuḥ, ābhijātya-śaṃsinī ca namratā, pāṇḍurā ca mukha-cchaviḥ, anati-paribhukta-subhagā ca tanuḥ, prauḍhatānuviddhā ca dṛṣṭiḥ / na caiṣā proṣita-bhartṛkā, pravāsa-cihnasya veṇyāder adarśanāt / lakṣma caitad dakṣiṇa-pārśva-varti /
11.2ある日、旅の絵師の手に絵布を見た。そこに描かれた若い女は、一目見ただけでカラハカンタカの心を恋に狂わせた。彼は絵師に言った。『友よ、これは矛盾しているように見える。良家にはめったにない姿、高貴さを示す謙虚さ、青白い顔色、まだ十分に享受されていない美しい体、成熟を帯びた眼差し。しかし彼女は夫が旅に出ている婦人ではない、旅の印である編み髪などが見えないから。そしてこの印は右側にある。
tad iyaṃ vṛddhasya kasyacid vaṇijo nāti-puṃstvasya yathārha-saṃbhogālābha-pīḍitā gṛhiṇī tvayāti-kauśalād yathādṛṣṭam ālikhitā bhavitum arhati” iti / sa tam abhipraśasyāśaṃsat “satyam idam / avanti-puryām ujjayinyām anantakīrti-nāmnaḥ sārthavāhasya bhāryā yathārtha-nāmā nitambavatī nāmaiṣā saundarya-vismitena mayaivam ālikhitā” iti /
11.3つまりこの人は年老いた商人の、あまり男らしくない者の、相応の享楽を得られずに苦しむ妻で、あなたが巧みに見たままに描いたものに違いない』と。絵師は彼を大いに称賛して告げた。『その通りです。アヴァンティ城市ウッジャイニーに住むアナンタキールティという隊商主の妻で、その名に相応しいニタンバヴァティーと申す方で、その美しさに驚嘆した私がこのように描いたのです』と。
sa tadaivonmanāyamānas tad-darśanāya parivavrājojjayinīm / bhārgavo nāma bhūtvā bhikṣā-nibhena tad-gṛhaṃ praviśya tāṃ dadarśa / dṛṣṭvā cātyārūḍha-manmatho nirgatya paura-mukhyebhyaḥ śmaśāna-rakṣām ayācata / alabhata ca /
11.4彼はただちに心を高ぶらせ、彼女に会うためにウッジャイニーへ旅立った。バールガヴァという名の行者を装い、托鉢の体でその家に入って彼女を見た。見て恋情が極まり、外へ出て町の長老たちに墓地の番人の仕事を求めた。得ることができた。
tatra labdhaiś ca śavāvaguṇṭhana-paṭādibhiḥ kām apyarhantikāṃ nāma śramaṇikām upāsāṃcakre / tan-mukhena ca nitambavatīm upāṃśu mantrayāmāsa / sā caināṃ nirbhartsayantī pratyācacakṣe / śramaṇikā-mukhāc ca duṣkara-śīla-bhraṃśāṃ kulastriyam upalabhya rahasi dūtikām aśikṣayat
11.5そこで得た死体の覆い布などを使って、ある出家尼（アルハンティカー、ジャイナ教の尼僧）に取り入った。その口を通じてニタンバヴァティーにひそかに話を持ちかけた。しかし彼女はこれを厳しく叱りつけて拒絶した。尼僧を通じても容易に貞操を崩せない良家の婦人だと知り、ひそかに使い女にこう教えた。
“bhūyo 'pyupatiṣṭha sārthavāha-bhāryām / brūhi copahvare saṃsāra-doṣa-darśanāt samādhim āsthāya mumukṣamāṇo mādṛśo janaḥ kulavadhūnāṃ śīla-pātane ghaṭata iti kva ghaṭate / etad api tvām apyudārayā samṛddhyā rūpeṇāti-mānuṣeṇa prathamena vayasopapannāṃ kim itara-nārī-sulabhaṃ cāpalaṃ spṛṣṭaṃ na veti parīkṣā kṛtā / tuṣṭāsmi tathaivam aduṣṭa-bhāvatayā /
11.6『もう一度その隊商主の妻のところへ行け。そしてこう言え。「輪廻の過ちを見て禅定に入り解脱を求める私のような者が、良家の嫁の貞操を堕落させるなど、どうしてありえましょう。むしろ、これほど豊かな富と超人的な美貌と初々しい若さを備えたあなたが、他の女に容易な軽率さに触れたか否かを試したのです。そのような清い心のままであることに満足しております。
tvām idānīm utpannāpatyāṃ draṣṭum icchāmi / bhartā tu bhavatyāḥ kenacid graheṇādhiṣṭhitaḥ pāṇḍu-roga-durbalo bhoge cāsamarthaḥ sthito 'bhūt / na ca śakyaṃ tasya vighnam apratikṛtyāpatyam asmāl labdhum / ataḥ prasīda / vṛkṣa-vāṭikām ekākinī praviśya mad-upanītasya kasyacin mantra-vādinaś channam eva haste caraṇam arpayitvā tad-abhimantritena praṇaya-kupitā nāma bhūtvā bhartāram urasi prahartum arhasi / uparyasāvuttama-dhātu-puṣṭim ūrjitāpatyotpādana-kṣamām āsādayiṣyati / anuvartiṣyate devīm ivātra bhavatīm / nātra śaṅkā kāryā” iti /
11.7今は子をもうけたあなたに会いたいのです。しかしあなたの夫は何かの悪霊に取り憑かれ、黄疸病で衰え、情事にも力がありません。その障害を除かずに子を得ることはできません。ですからどうかお許しください。一人で庭園に入り、私が連れて来たある呪術師の手にこっそり足を委ね、その呪文をかけた力で、愛の怒りを装って夫の胸を打ってください。すると夫は最上の体液に満ちて強壮な子を生める力を得、女神のようにあなたに従うでしょう。心配は無用です」と。
sā tathoktā vyaktam abhyupaiṣyati naktaṃ māṃ vṛkṣa-vāṭikāṃ praveśya tām api praveśayiṣyasi tāvataiva tvayāham anugṛhīto bhaveyam” iti / sā tathaivopagrāhitavatī /
11.8そう言われれば彼女はきっと承諾する。夜に私を庭園に入れ、彼女も入れてくれれば、それだけで私はお前に恩義を受けたことになる』と。尼僧はまさにその通りに手はずを整えた。
so 'ti-prītas tasyām eva kṣapāyāṃ vṛkṣa-vāṭikāyāṃ gato nitambavatīṃ nirgranthikā-prayatnenopanītāṃ pāde parāmṛśann iva hema-nūpuram ekam ākṣipya churikayoru-mūle kiñcid ālikhya drutataram apāsarat / sā tu sāndra-trāsā svam eva durṇayaṃ garhamāṇā jighāṃsantīva śramaṇikāṃ tad vraṇaṃ bhavana-dīrghikāyāṃ prakṣālya dattvā paṭa-bandhanam āmayāpadeśād aparaṃ cāpanīya nūpuraṃ śayana-parā tricaturāṇi dinānyekānte ninye /
11.9大いに喜んだ彼はその夜のうちに庭園に行き、ジャイナ教の尼僧の手引きで連れて来られたニタンバヴァティーの足に触れるふりをしながら、金の足環を一つ引き抜き、小刀で太腿の付け根を少し引っ掻いて、素早く立ち去った。彼女は深い恐怖に襲われ、自分の過ちを責めながら、尼僧を殺さんばかりに怒り、その傷を屋敷の池で洗い布で巻き、病気を装ってもう一方の足環も外し、寝室に籠って三、四日を過ごした。
sa dhūrtaḥ “vikreṣye” iti tena nūpureṇa tam anantakīrtim upāsasāda / sa dṛṣṭvā “mama gṛhiṇyā evaiṣa nūpuraḥ, katham ayam upalabdhas tvayā” iti tam abruvāṇaṃ nirbandhena papraccha / sa tu “vaṇig-grāmasyāgre vakṣyāmi” iti sthito 'bhūt / punar asau gṛhiṇyai “sva-nūpura-yugalaṃ preṣaya” iti saṃdideśa / sā ca salajjaṃ sasādhvasaṃ cādya rātrau viśrāma-praviṣṭāyāṃ vṛkṣa-vāṭikāyāṃ prabhraṣṭo mamaikaḥ praśithila-bandho nūpuraḥ / so 'dyāpyanviṣṭo na dṛṣṭaḥ sa punar ayaṃ dvitīya ityaparaṃ prāhiṇot /
11.10あの悪賢い男は『売りつけてやろう』とその足環を持ってアナンタキールティのもとへ行った。見て「これは私の妻の足環だ、どうやって手に入れたのだ」と言う彼にしつこく尋ねられた。男は「商人組合の前で申し上げましょう」と言い張った。夫は妻に「お前の足環の一対を送れ」と伝えた。彼女は恥じらいと恐れの中で「昨夜、散歩のために入った庭園で緩んだ留め金の一つが外れました。今日探しても見つかりません。こちらがもう一方です」と残りの一つを送った。
anayā ca vārtayāmuṃ puraskṛtya sa vaṇik vaṇig-jana-samājam ājagāma / sa cānuyukto dhūrtaḥ savinayam āvedayat — “viditam eva khalu vaḥ, yathāhaṃ yuṣmad-ājñayā pitṛvanam abhirakṣya tad-upajīvī prativasāmi / lubdhāś ca kadācin mad-darśana-bhīravo niśi daheyur api śavānīti niśāsvapi śmaśānam adhiśaye / aparedyur dagdhādagdhaṃ mṛtakaṃ citāyāḥ prasabham ākarṣantī śyāmākārāṃ nārīm apaśyam / artha-lobhāt tu nigṛhya sādhvasaṃ sā gṛhītā śastrikayoru-mūle yadṛcchayā kiñcid ullikhitam / eṣa ca nūpuraś caraṇād ākṣiptaḥ / tāvatyeva druta-gatiḥ sā palāyiṣṭa / so 'yam asyāgamaḥ / paraṃ bhavantaḥ pramāṇam” iti /
11.11この話を証拠に男を前面に立てて、商人アナンタキールティは商人組合の集まりにやって来た。問い詰められた悪賢い男は恭しく述べた。「皆様もご存知の通り、私は皆様の命により墓地（ピトリヴァナ）を守り、それで生計を立てております。欲張りな者たちが時折、私を恐れて夜に死体を燃やすことがあるので、夜は墓地で寝ております。ある日、焼け残りの死体を火葬場から力ずくで引きずり出している黒い姿の女を見ました。利欲から恐怖を抑えて彼女を捕らえ、小刀で太腿の付け根を偶然少し引っ掻きました。足環も足から外れました。それだけで彼女は素早く逃げ去りました。これが足環の由来です。あとは皆様のご判断に委ねます」と。
vimarśena ca tasyāḥ śākinītvam aikamatyena paurāṇām abhimatam āsīt / bhartrā ca parityaktā tasminn eva śmaśāne bahu vilapya pāśenodbadhya kartu-kāmā tena dhūrtena naktam agṛhyata / anunītā ca sundari, tvad-ākāronmāditena mayā tvad-āvarjane bahūn upāyān bhikṣukī-mukhenopanyasya teṣvasiddheṣu punar ayam upāyo yāvajjīvam asādhāraṇīkṛtya rantum ācaritaḥ / tat prasīdānanya-śaraṇāyāsmai dāsa-janāya” iti muhur muhuś caraṇayor nipatya, prayujya sāntva-śatāni, tām agatyantarām ātma-vaśyām akarot / tad idam uktam “duṣkara-sādhanaṃ prajñā” iti /
11.12検討の結果、彼女がシャーキニー（魔女）であるという意見が市民の一致した見解となった。夫にも捨てられ、あの墓地で大いに嘆き、首吊り紐で死のうとしていた彼女を、あの悪賢い男が夜に捕らえた。そしてなだめた。「美しき人よ、あなたの姿に狂った私は、あなたを手に入れるために乞食尼を通じて多くの策を講じたが、それらが失敗したので、この策略を、一生あなたを独占して楽しむために行ったのだ。だからどうかこの、他に頼る者のない僕にお情けを」と何度も足元にひれ伏し、百の甘い言葉を尽くして、他に行き場のない彼女を自分の意のままにした。だからこう言われる。『知恵こそが困難なことを成し遂げる』と。」

12ブラフマラークシャサの戦いとカンドゥカーヴァティーの救出

idam ākarṇya brahmarākṣaso mām apūpujat / asminn eva kṣaṇe nāti-prauḍha-puṃnāga-mukula-sthūlāni muktāphalāni saha salila-bindubhir ambara-talād apatan / ahaṃ tu “kiṃ nvidam” ity uccakṣur ālokayan kam api rākṣasaṃ kāñcid aṅganāṃ viceṣṭamāna-gātrīm ākarṣantam apaśyam / katham apaharatyakāmām api striyam anācāro nairṛtaḥ iti gagana-gamana-manda-śaktir aśastraś cātapye /
12.1これ（四つの物語）を聞いてブラフマラークシャサは私を大いに称賛した。まさにその瞬間、まだ十分に開いていないプンナーガ花の蕾ほどの大きさの真珠が、水滴とともに空から落ちてきた。私は「これは何事か」と見上げると、空中にあるラークシャサが、もがき抵抗する一人の女を引きずっているのが見えた。「どうして無法なラークシャサは女の意に反して連れ去るのか」と憤ったが、私には空を飛ぶ力もなく、武器もなかったので、苦悶するしかなかった。
sa tu mat-saṃbandhī brahmarākṣasaḥ “tiṣṭha tiṣṭha pāpa, kvāpaharasi” iti bhartsayann utthāya rākṣasena samasṛjyata / tāṃ tu roṣād anapekṣāpaviddhām amara-vṛkṣa-mañjarīm ivāntarikṣād āpatantīm unmukha-prasāritobhaya-karaḥ karābhyām agrahīṣam / upagṛhya ca vepamānāṃ saṃmīlitākṣīṃ mad-aṅga-sparśa-sukhenodbhinna-romāñcāṃ tādṛśīm eva tām anavatārayann atiṣṭham /
12.2しかし私の友であるブラフマラークシャサが「止まれ、止まれ、悪党め、どこへ連れ去るのだ」と叱咤しながら空に飛び上がり、そのラークシャサと戦いを交えた。すると、そのラークシャサは怒りのあまり女を顧みずに投げ捨てた。天界の樹の花房のように空中から落ちてくる彼女を、私は顔を上げて両手を差し伸べ、両腕で受け止めた。震えている彼女を抱きかかえ、目を閉じ、私の体に触れた喜びに総毛立っている彼女を、そのまま降ろしながら立っていた。
tāvat tāvubhāvapi śaila-śṛṅga-bhaṅgaiḥ pādapaiś ca rabhasonmūlitair muṣṭi-pāda-prahāraiś ca parasparam akṣapayetām /
12.3その間に、あの二体のラークシャサは山の峰の破片、力ずくで引き抜いた樹木、拳と足の打撃で互いを滅ぼし合った。
punar aham ati-mṛduni pulinavati kusuma-lava-lāñchite saras-tīre 'varopya saspṛhaṃ nirvarṇayaṃs tāṃ mat-prāṇaika-vallabhāṃ rāja-kanyāṃ kandukāvatīm alakṣayam /
12.4私は極めて柔らかな砂地の、花弁の痕が散らばる池の岸辺に彼女を降ろし、切望をもって眺めた。それは私の命にも等しい唯一の愛しい王女、カンドゥカーヴァティーに他ならなかった。
sā hi mayā samāśvāsyamānā tiryaṅ mām abhinirūpya jāta-pratyabhijñā sakaruṇaṃ arodīt /
12.5私が慰めると、彼女は横目で私を見つめ、私と気づいて哀れに泣いた。
avādīc ca “nātha, tvad-darśanād upoḍha-rāgā tasmin kandukotsave punaḥ sakhyā candrasenāya tvat-kathābhir eva samāśvāsitāsmi / tvaṃ kila samudra-madhye majjitaḥ pāpena mad-bhrātrā bhīmadhanvanā” iti śrutvā sakhī-janaṃ parijanaṃ ca vañcayitvā jīvitaṃ jihāsur ekākinī krīḍā-vanam upāgamam / tatra ca mām acakamata kāma-rūpa eṣa rākṣasādhamaḥ / so 'yaṃ mayā bhītayāvadhūta-prārthanaḥ sphurantīṃ māṃ nigṛhyābhyadhāvat / atraivam avasito 'bhūt / “ahaṃ ca daivāt tavaiva jīviteśasya haste patitā / bhadraṃ tava” iti /
12.6そして語った。「わが君よ、あのカンドゥカ祭であなたを見て以来、堪えがたい恋情を抱き、友のチャンドラセーナーにあなたの話を聞かせてもらうことだけが慰めでした。あなたが私の邪悪な兄ビーマダンヴァンに海の中で沈められたと聞いて、友人や侍女たちの目を欺き、命を絶とうとただ一人遊園に参りました。そこでこの変幻自在のラークシャサの最も卑しい者が私に懸想したのです。恐怖にかられて求愛を拒むと、もがく私を捕らえて飛び去りました。そしてこのような結末を迎えたのです。私は運命のめぐりあわせにより、わが命の主であるあなたの手に落ちました。あなたに幸あらんことを」と。

13ダーマリプタへの帰還とラージャヴァーハナの宮廷

śrutvā ca tayā sahāvaruhya, nāvam adhyāroham / muktā ca nauḥ prativāta-preritā tām eva dāmaliptāṃ pratyupātiṣṭhat /
13.1これを聞き、彼女とともに降りて船に乗り込んだ。船は解き放たれ、逆風に吹かれてあのダーマリプタの港にまさしく帰り着いた。
avarūḍhāś ca vayam aśrameṇa “tanayasya ca tanayāyāś ca nāśād ananyāpatyas tuṅgadhanvā suhma-patir niṣkalaḥ svayaṃ sakalatra eva niṣkalaṅka-gaṅgā-rodhasyanaśanenoparantu pratiṣṭhate / saha tena martum icchatyananya-nātho 'nuraktaḥ paura-vṛddha-lokaḥ” ityaśru-mukhīnāṃ prajānām ākrandam aśṛṇum /
13.2上陸すると、苦もなく、涙に濡れた顔の民衆の嘆きの声が聞こえてきた。「息子も娘も失い、他に子のないスフマの主トゥンガダンヴァン王は気力を失い、自ら妃を伴って、清浄なるガンガー河畔で断食による昇天を遂げようとしておられる。王に他の主を知らず、深く慕う市中の老臣たちも、王とともに死のうとしている」と。
athāham asmai rājñe yathāvṛttam ākhyāya tad-apatya-dvayaṃ pratyarpitavān / prītena tena jāmātā kṛto 'smi dāmalipteśvareṇa / tat-putro mad-anujīvī jātaḥ /
13.3そこで私はこの王にすべてのいきさつを語り、その二人の子をお返しした。喜んだダーマリプタの王は私を婿とした。その王子（ビーマダンヴァン）は私の従者となった。
mad-ājñaptena cāmunā prāṇa-vad ujjhitā candrasenā kośadāsam abhajat /
13.4私の命により、ビーマダンヴァンはチャンドラセーナーを命のように惜しみながらも手放し、彼女はコーシャダーサのもとに赴いた。
tataś ca siṃhavarma-sāhāyyārtham atrāgatya bhartus tava darśanotsava-sukham anubhavāmi” iti /
13.5その後、シンハヴァルマンを助けるためにここに参り、主君であるあなた様にお目にかかる喜びを味わっております」と。
śrutvā “citreyaṃ daiva-gatiḥ / avasareṣu puṣkalaḥ puruṣakāraḥ” ityabhidhāya bhūyaḥ smitābhiṣikta-dantacchado mantragupte harṣotphullaṃ cakṣuḥ pātayāmāsa devo rājavāhanaḥ
13.6これを聞いてラージャヴァーハナ殿下は「実に不思議なるは運命の成り行き。好機に恵まれし時、人の努力は豊かな実りをもたらす」と仰せられ、再び微笑みに輝く歯を見せながら、マントラグプタのほうに喜びに満ちた眼差しを向けた。
sa kila kara-kamalena kiñcit saṃvṛtānano lalita-vallabhā-rabhasa-datta-danta-kṣata-vyasana-vihvalādhara-maṇir niroṣṭhya-varṇam ātma-caritam ācacakṣe //
13.7マントラグプタは蓮華のような手で顔を少し覆い、愛しい人が激情にまかせて付けた歯形の痛みに唇の宝石を悩ませていたので、唇音を用いずに自らの冒険を語り始めた。
注lalita-vallabhā は「愛らしい恋人」の意で、人名ではない。次章の語り手マントラグプタは、この唇の傷のため唇音（niroṣṭhya）を避けて語る。
