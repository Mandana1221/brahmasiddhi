マハーバーラタ ― カルナ篇 第29章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 29 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ29」（ドゥルヨーダナの懇願に対し、シャリヤが先のパラシュラーマ伝説を引いてカルナの武勇と素性を称え、最終的に条件付きでカルナの御者を引き受ける場面）です。各段落は原典の詩節番号（8-29-N）と和訳の段落番号が対応しています。
karṇaparva — ekonatriṃśo'dhyāyaḥ (29)
第29章　ドゥルヨーダナの懇願により、シャリヤが条件つきでカルナの御者を引き受ける
duryodhana uvāca|
evaṃ sa bhagavān devaḥ sarvalokapitāmahaḥ|
sārathyam akarot tatra brahmā rudro'bhavadrathī|| // 8-29-1 //
ドゥルヨーダナは語った。 （1）「このようにして至高の神、すべての世界の祖父であるブラフマーが、ルドラの御者を務めた。ブラフマーが御者で、ルドラが戦士であった。
rathino'bhyadhiko vīra kartavyo rathasārathiḥ|
tasmāt tvaṃ puruṣavyāghra niyaccha turagān yudhi|| // 8-29-2 //
（2）勇者よ、戦車の戦士より優れた者が御者になるべきなのだ。だから、人の中の虎よ、戦場で馬の手綱を取ってくれ。
yathā devagaṇais tatra vṛto yatnāt pitāmahaḥ|
tathā'smābhir bhavān yatnāt karṇād abhyadhiko vṛtaḥ|| // 8-29-3 //
（3）かつて天の神々の群れが苦心して祖父神ブラフマーを選んだように、我々も苦心してカルナよりも優れたあなたを選んだのだ。
yathā devair mahārāja īśvarād adhiko vṛtaḥ|
tathā devair mahārāja kṣipraṃ rudrasya iva pitāmahaḥ|
niyaccha turagān yuddhe rādheyasya mahādyute|| // 8-29-4 //
（4）天の神々がイーシュヴァラ（シヴァ）よりも優れた者として祖父神を選んだように、大王よ、速やかにルドラのための祖父神のように、戦場でラーデーヤの馬の手綱を取ってくれ、大いなる輝きよ。」
śalya uvāca|
mayā api etan naraśreṣṭha bahuśo narasiṃhayoḥ|
kathyamānaṃ śrutaṃ divyam ākhyānam atimānuṣam|| // 8-29-5 //
シャリヤは語った。 （5）「人の中の最上者よ、かの二人の英雄（ルドラとブラフマー）について語られるこの神聖な、人間を超えた物語を、私も何度も聞いたことがある。
yathā ca cakre sārathyaṃ bhavasya prapitāmahaḥ|
yathā'surāś ca nihatā iṣuṇā ekena bhārata|| // 8-29-6 //
（6）バヴァ（シヴァ）のために祖父神が御者を務め、一本の矢で阿修羅たちが滅ぼされたことも、バーラタよ。
kṛṣṇasya cāpi viditaṃ sarvam etat purā hy abhūt|| // 8-29-7 //
（7）クリシュナもまた、このすべてを以前から知っている。
yathā pitāmaho jajñe bhagavān sārathis tadā|
anāgatamatikrāntaṃ veda kṛṣṇo'pi tattvataḥ|| // 8-29-8 //
（8）至高の祖父神が御者となった時のこと——過去のことも未来のことも、クリシュナは真に知っている。
etadarthaṃ viditvā'pi sārathyam upajagmivān|
svayambhūr iva rudrasya kṛṣṇaḥ pārthasya bhārata|| // 8-29-9 //
（9）この目的を知った上で、クリシュナは自らパールタの御者を務めたのだ——自存するブラフマーがルドラのためにしたように、バーラタよ。
yadi hanyāc ca kaunteyaṃ sūtaputraḥ kathañcanaḥ|
dṛṣṭvā pārthaṃ hi nihataṃ svayaṃ yotsyati keśavaḥ|| // 8-29-10 //
（10）もしカルナがなんとかしてカウンテーヤ（アルジュナ）を殺したなら——パールタが殺されるのを見て、ケーシャヴァ自ら戦うだろう。
śaṅkhacakragadāpāṇir dhakṣyate tava vāhinīm|
na cāpi tasya kruddhasya vārṣṇeyasya mahātmanaḥ|
sthāsyate pratyanīkeṣu kaścid atra nṛpas tava|| // 8-29-11 //
（11）法螺貝・円盤・棍棒を手にしたケーシャヴァが、お前の軍勢を焼き尽くすだろう。怒れるヴァールシュネーヤ（クリシュナ）という偉大な魂の前に立ち向かう王は、お前の軍にはいなくなるだろう。」
sañjaya uvāca|
taṃ tathā bhāṣamāṇaṃ tu madrarājam arindamaḥ|
pratyuvāca mahābāhur adīnātmā sutas tava||
māvamaṃsthā mahābāho karṇaṃ vaikartanaṃ raṇe|
sarvaśastrabhṛtāṃ śreṣṭhaṃ sarvaśāstrārthaparāgam|| // 8-29-12-13 //
サンジャヤは語った。 （12〜13）このように語るマドラ王に対して、大きな腕を持ち、気力旺盛なあなたの息子は答えた。「大いなる腕の者よ、戦場でヴァイカルタナ・カルナを侮るな。すべての武器の使い手の中の最上者、すべての武術の奥義に精通した者を。
yasya jyātalanirghoṣaṃ śrutvā bhayakaraṃ mahat|
pāṇḍaveyāni sainyāni vidravanti diśo daśa|| // 8-29-14 //
（14）彼の弓弦の轟きを——恐ろしく大きな音を——聞けば、パーンダヴァ軍は十方に逃げ散る。
pratyakṣa te mahābāho yathā rātrau ghaṭotkacaḥ|
māyāśatāni kurvāṇo hato māyāpuraskṛtaḥ|| // 8-29-15 //
（15）大いなる腕の者よ、お前自身が見たではないか、夜の戦闘でガトートカチャが何百もの幻術を使いながらも、幻術ごと殺されたのを。
na cātiṣṭhata bībhatsuḥ pratyanīke kathañcana|
etāṃś ca divasān sarvān bhayena mahatā vṛtaḥ|| // 8-29-16 //
（16）ビーバツ（アルジュナ）はその日から、大きな恐怖に包まれて、決して（カルナの）正面に立つことができなかった。
bhīmasenaś ca balavān dhanuṣkoṭyābhicoditaḥ|
uktaś ca saṃjñayā rājan mūḍha audariko yathā|| // 8-29-17 //
（17）力あるビーマセーナも、弓の先で追い立てられ、王よ、愚かな食いしん坊のように合図で追い払われた。
mādrīputrau tathā śūrau yena jitvā mahāraṇe|
kam apy arthaṃ puraskṛtya na hatau yudhi māriṣa|| // 8-29-18 //
（18）マードリーの二人の息子も、あの勇者（カルナ）は大戦闘で打ち負かしながら、ある目的があって殺さなかったのだ。
yena vṛṣṇipravīras tu sātyakiḥ sātvatāṃ varaḥ|
nirjitya samare śūro visthaś ca balātkṛtaḥ|| // 8-29-19 //
（19）ヴリシュニ族の勇者サーティヤキ、サートヴァタ族の最上者も、あの勇者に戦場で打ち負かされ、力ずくで退かされた。
sṛñjayāś ca itare sarve dhṛṣṭadyumnapurogamāḥ|
asakṛn nirjitāḥ saṅkhye smayamānena saṃyuge|| // 8-29-20 //
（20）ドリシュタデュムナを先頭とするスリンジャヤ族やその他の者たちも、戦場で微笑みながら何度も打ち負かされた。
taṃ kathaṃ pāṇḍavā yuddhe vijeṣyanti mahāratham|
yo hanyāt samare kruddho vajrahastaṃ purandaram|| // 8-29-21 //
（21）そのような偉大な戦車戦士を、パーンダヴァたちが戦場でどうして打ち負かせようか。怒れば戦場で金剛杵を持つインドラすら殺しうる者を。
tvaṃ ca sarvāstravid vīraḥ sarvavidyāstrapāragaḥ|
bāhuvīryeṇa te tulyaḥ pṛthivyāṃ nāsti kaścana|| // 8-29-22 //
（22）お前はすべての武器を知る勇者であり、すべての武術の奥義に精通している。腕の力においてお前に等しい者はこの大地にいない。
tvaṃ śalyabhūtaḥ śatrūṇām aviṣahyaḥ parākrame|
tatas tvam ucyase rājañ śalya ity arisūdana|| // 8-29-23 //
（23）お前は敵にとって棘（シャリヤ）のような存在であり、武勇において耐え難い。だからこそ、王よ、シャリヤと呼ばれるのだ、敵を滅ぼす者よ。
tava bāhubalaṃ prāpya na śekuḥ sarvasātvatāḥ|
tava bāhubalād rājan kiṃ nu kṛṣṇo balādhikaḥ|| // 8-29-24 //
（24）お前の腕の力を得て、すべてのサートヴァタ族（ヤーダヴァ族）の者たちも太刀打ちできなかった。王よ、お前の腕の力に比べて、クリシュナがどれほど力があるというのか。
yathā hi kṛṣṇena balaṃ dhāryaṃ vai phalgune hate|
tathā karṇa atyayībhāve tvayā dhāryaṃ mahad balam|| // 8-29-25 //
（25）もしアルジュナが殺された場合にクリシュナが力を発揮するならば、同様にカルナが倒された場合には、お前が大いなる力を発揮してくれ。
kimarthaṃ samare sainyaṃ vāsudevo nyavārayat|
kimarthaṃ ca bhavān sainyaṃ na haniṣyati māriṣa|| // 8-29-26 //
（26）ヴァースデーヴァが戦場で軍を制止したのはなぜか。そしてお前が軍を滅ぼさないのはなぜか。
tvatkṛte padavīṃ gantum iccheyaṃ yudhi māriṣa|
sodarāṇāṃ ca vīrāṇāṃ sarveṣāṃ ca mahīkṣitām|| // 8-29-27 //
（27）お前のためになら、私は戦場で（命の）借りを返す道を歩む覚悟がある。同胞の勇者たちとすべての王たちのために。」
śalya uvāca|
yan māṃ bravīṣi gāndhāre agre sainyasya mānada|
viśiṣṭaṃ devakīputrāt prītimān asmy ahaṃ tvayi|| // 8-29-28 //
シャリヤは語った。 （28）「ガーンダーラよ、軍の前で私をデーヴァキーの子（クリシュナ）より優れていると言ってくれたこと、私はお前に喜びを感じる。
eṣa sārathyam ātiṣṭhe rādheyasya yaśasvinaḥ|
yudhyataḥ pāṇḍavāgryeṇa yathā tvaṃ vīra manyase|| // 8-29-29 //
（29）栄光あるラーデーヤの御者を務めよう。パーンダヴァの最上者（アルジュナ）と戦う彼のために。お前が望むとおりに、勇者よ。
samayaś ca hi me vīra kaścid vaikartanaṃ prati|
utsṛjeyaṃ yathāśraddham ahaṃ vāco'sya sannidhau|| // 8-29-30 //
（30）しかし勇者よ、ヴァイカルタナ（カルナ）に対して一つ条件がある。私は彼の前で、好きなように言いたいことを言わせてもらう。」
sañjaya uvāca|
tatheti rājan putras te saha karṇena māriṣa|
abravīt madrarājānaṃ sarvakṣatrasya sannidhau|| // 8-29-31 //
サンジャヤは語った。 （31）王よ、あなたの息子は、カルナとともに、バーラタよ、すべてのクシャトリヤの面前で、マドラ王に「そのとおりにせよ」と言いました。
sārathyasya abhyupagamāc chalyena āśvāsitas tadā|
duryodhanas tadā hṛṣṭaḥ karṇaṃ tam abhiṣasvaje|| // 8-29-32 //
（32）シャリヤが御者を引き受けたことで安心したドゥルヨーダナは、その時喜んでカルナを抱きしめました。
abravīc ca punaḥ karṇaṃ stūyamānaḥ sutas tava|
jahi pārthān raṇe sarvān mahendro dānavān iva|| // 8-29-33 //
（33）そしてあなたの息子は讃えられながら、再びカルナに言いました。「インドラが悪魔を倒すように、戦場でパーンダヴァたちを全員殺せ。」
sa śalyena abhyupagate hayānāṃ sanniyacchane|
karṇo hṛṣṭamanā bhūyo duryodhanabhāṣata|| // 8-29-34 //
（34）シャリヤが馬の手綱を取ることに同意した時、カルナは喜びに満ちた心で、再びドゥルヨーダナに語った。
nātihṛṣṭamanā hy eṣa madrarājo'bhibhāṣate|
rājan madhurayā vācā punar enaṃ bravīhi vai|| // 8-29-35 //
（35）「このマドラ王はあまり喜んでいない様子だ。王よ、甘い言葉でもう一度彼に語りかけてくれ。」
tato rājā mahāprājñaḥ sarvāstrakuśalo balī|
duryodhano'bravīc chalyaṃ madrarājaṃ mahīpatim||
pūrayan iva ghoṣeṇa meghagambhīrayā girā|
śalya karṇo'rjunenādya yoddhavyam iti manyate|| // 8-29-36-37 //
（36〜37）そこで大いなる叡智と武器の達人である力あるドゥルヨーダナ王は、マドラ王シャリヤに語りかけた。雷雲のように深い声で場を満たしながら——「シャリヤよ、カルナは今日アルジュナと戦わねばならないと考えている。
tasya tvaṃ puruṣavyāghra niyaccha turagān yudhi|
karṇo hatvā itarān sarvān phalgunaṃ hantum icchati|
tasya abhīṣugrahe rājan prayāce tvāṃ punaḥ punaḥ|| // 8-29-38 //
（38）人の中の虎よ、戦場で彼のために馬の手綱を取ってくれ。カルナは他のすべての者を倒した後、アルジュナを殺したいのだ。彼のための御者を、何度もお願いする。
pārthasya sacivaḥ kṛṣṇo yathā'bhīṣugraho varaḥ|
tathā tvam api rādheyaṃ sarvataḥ paripālaya|| // 8-29-39 //
（39）パールタ（アルジュナ）にとってクリシュナが最上の御者であるように、お前もラーデーヤをあらゆる方面から守ってくれ。」
sañjaya uvāca|
tataḥ śalyaḥ pariṣvajya sutaṃ te vākyam abravīt|
duryodhanam amitraghnaṃ prīto madrādhipas tadā|| // 8-29-40 //
サンジャヤは語った。 （40）そこでシャリヤはあなたの息子、敵を滅ぼすドゥルヨーダナを抱きしめ、喜んだマドラの王はこう言いました。
śalya uvāca|
evaṃ cen manyase rājan gāndhāre priyadarśana|
tasmāt te yatpriyaṃ kiñcit tat sarvaṃ karavāṇy aham|| // 8-29-41 //
シャリヤは語った。 （41）「もしそのようにお考えなら、美しき者、ガーンダーラよ、お前のために、何であれ喜ばしいことはすべてなそう。
yatra asmi bharataśreṣṭha yogyaḥ karmaṇi karhicit|
tatra sarvātmanā yukto vakṣye kāryaṃ parantapa|| // 8-29-42 //
（42）バーラタの最上者よ、私がふさわしい仕事、いつでも全身全霊で力を尽くそう、敵を滅ぼす者よ。
yat tu karṇam ahaṃ brūyāṃ hitakāmaḥ priyāpriye|
mama tatkṣamatāṃ sarvaṃ bhavān karṇaś ca sarvaśaḥ|| // 8-29-43 //
（43）しかし、カルナの利益と不利益のために、私が彼に言うことがあれば——それをすべてお前もカルナも受け入れてくれ。」
karṇa uvāca|
īśānasya yathā brahmā yathā pārthasya keśavaḥ|
tathā nityaṃ hite yukto madrarāja bhavasva naḥ|| // 8-29-44 //
カルナは語った。 （44）「イーシャーナ（シヴァ）にとってのブラフマーのように、パールタ（アルジュナ）にとってのケーシャヴァ（クリシュナ）のように、マドラの王よ、常に我らの利益のために働いてくれ。」
śalya uvāca|
ātmanindā ātmapūjā ca paranindā parastavaḥ|
anācaritamāryāṇāṃ vṛttam etac caturvidham|| // 8-29-45 //
シャリヤは語った。 （45）「自分を貶め、自分を讃え、他者を貶め、他者を讃える——この四つの行いは高貴な者にはふさわしくないとされている。
yat tu vidvan pravakṣyāmi praxxxxyārtham ahaṃ tava|
ātmanaḥ stavasaṃyuktaṃ tan nibodha yathātatham|| // 8-29-46 //
（46）しかし学識ある者よ、お前の利益のために私がこれから語ることは、自らを讃える内容を含む。そのまま聞いてくれ。
ahaṃ śakrasya sārathye yogyo mātalivatprabho|
apramādāt prayogāc ca jñānavidyācikitsanaiḥ|| // 8-29-47 //
（47）私はインドラの御者マータリのように、御者の務めにふさわしい者だ。注意深さにおいて、馬の操り方において、知識と技術と治療の術において。
tataḥ pārthena saṅgrāme yudhyamānasya te'nagha|
vāhayiṣyāmi turagān vijvaro bhava sūtaja|| || // 8-29-48 //
（48）パールタ（アルジュナ）と戦うお前のために、罪なき者よ、私は馬を走らせよう。心配するな、御者の子よ。」
iti śrīmanmahābhārate karṇaparvaṇi ekonatriṃśo'dhyāyaḥ|| 29 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十九章は終わる。
