マハーバーラタ ― カルナ篇 第60章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 60 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ60」、全30詩節からなり、ドゥルヨーダナに命じられた象兵によるドゥリシュタデュムナへの攻撃（ガジャ・ユッダ、象の戦い）を描きます。東方・南方の象使いの部族たち（アンガ族・ヴァンガ族・プンドラ族・マガダ族・タームラリプタカ族・メーカラ族・コーサラ族・マドラ族・ダシャールナ族・ニシャダ族・カリンガ族）が一斉にドゥリシュタデュムナに突撃する場面から始まり（第1〜4詩節）、ドゥリシュタデュムナが六本・八本・十本の矢で各象を射る場面（第5〜6詩節）、パーンドゥ・パーンチャーラ側が救援に駆けつける場面（第7〜9詩節）、象が人馬車を踏み潰す場面（第10〜11詩節）、サーティヤキ・サハデーヴァ・ナクラが各象を倒す場面（第12〜18詩節）、アンガ軍が再び象でナクラに向かい（第19〜21詩節）、パーンドゥ・パーンチャーラ・サーティヤキが反撃する場面（第22〜27詩節）、そしてパーンドゥ軍の戦車・象が敵軍の象を討ち果たし、再びカルナに向かう場面（第28〜30詩節）で本章は終わります。なお、本章では冒頭の注記「8-60-0」「8-60-0x」（「サンジャヤは語った」）が第1詩節の本文に統合されています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜59章に続き十章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。日本語原典第60章末には「── カルナ篇 第51章〜第60章　完 ──」のセクション区切りが記載されていますが、これは編者による構成上の区切りであり、詩節には対応しないため本訳注に記載するのみとしています。OCR誤記としては、第6詩節「ṣa़ḍbhir」の余分なヌクタ記号（ṣa़ḍbhir→ṣaḍbhir「六本で」）を修正しています。また第17詩節「divākarakaprakhyānaṅgaś」については、文脈・日本語訳（「太陽のように輝くアンガの勇者」）との照合により「divākarakaprakhyān aṅgaś」（「太陽のように輝く者としてのアンガが」）と分かち書きしています。
karṇaparva — ṣaṣṭitamo'dhyāyaḥ (60)
第60章
sañjaya uvāca|
hastibhis tu mahāmātrās tava putreṇa coditāḥ|
dhṛṣṭadyumnaṃ ghnate ity āśu kruddhāḥ pārṣatam abhyayuḥ||
// 8-60-1 //
サンジャヤは語った。
汝の息子に命じられた大将たちは象に乗り、「ドゥリシュタデュムナを殺せ！」と怒ってパールシャタに向かった。
prācyāś ca dākṣiṇātyāś ca pravarā gajayodhinaḥ|
aṅgā vaṅgāś ca puṇḍrāś ca māgadhās tāmraliptakāḥ||
// 8-60-2 //
東方の者たちと南方の者たちの最も優れた象兵たち、アンガ族、ヴァンガ族、プンドラ族、マガダ族、タームラリプタカ族、
mekalāḥ kośalā madrā daśārṇā niṣadhās tathā|
gajayuddheṣu kuśalāḥ kaliṅgaiḥ saha bhārata||
// 8-60-3 //
メーカラ族、コーサラ族、マドラ族、ダシャールナ族、ニシャダ族が、バーラタよ、象の戦いに熟達したカリンガ族とともに。
śaratomaranārācair vṛṣṭimanta iva ambudāḥ|
siṣicus te tataḥ sarve pāñcālabalam āhave||
// 8-60-4 //
矢・トマラ・鉄矢の雨を降らす雨雲のように、彼らは全員で戦場のパーンチャーラ軍に降り注いだ。
tān abhidravato nāgān madavegasamuddhatān|
vipāṭhakṣuranārācair dhṛṣṭadyumno hy avīvṛṣat||
// 8-60-5 //
発情の勢いで突進してくるそれらの象を、ドゥリシュタデュムナはヴィパータ矢、剃刀矢、鉄矢で射た。
ekaikaṃ daśabhiḥ ṣaḍbhir aṣṭābhir api pārṣataḥ|
dviradān abhivivyādha kṣipraṃ girinibhāñ śaraiḥ||
// 8-60-6 //
パールシャタは一頭につき六本、八本、十本の矢で、山のような象たちを素早く射抜いた。
pracchādyamānaṃ dviradair meghair iva divākaram|
paryayuḥ pāṇḍupāñcālā nadanto hy āttakārmukāḥ||
// 8-60-7 //
象に覆い隠されたドゥリシュタデュムナを——太陽が雲に覆われるように——パーンドゥとパーンチャーラの者たちが弓を構えて叫びながら駆けつけた。
tān nāgān abhivarṣanto jyātalatravinādinaḥ|
vīranṛtyaṃ pranṛtyantaḥ śūratālapracoditaiḥ|
nakulaḥ sahadevaś ca draupadeyāḥ prabhadrakāḥ||
// 8-60-8 //
弓弦と防具の音を響かせながら象に矢の雨を浴びせ、勇者の踊りを踊る者たちが——勇者の拍子に合わせて——ナクラ、サハデーヴァ、ドラウパディーの息子たち、プラバドラカ族、
sātyakiś ca śikhaṇḍī ca cekitānaś ca vīryavān|
samantāt siṣicur vīrā meghās toyair iva ācalān||
// 8-60-9 //
サーティヤキ、シカンディン、勇猛なるチェーキターナが、四方から雲が山に水を注ぐように勇者たちは矢の雨を浴びせた。
te mlecchaiḥ preṣitā nāgā narān aśvān rathān api|
hastairākṣipya mamṛduḥ padbhiś ca apy atimanyavaḥ||
// 8-60-10 //
ムレッチャ（蛮族）に駆られたそれらの象は、人間・馬・戦車を鼻で掴んで踏み潰した。激しい怒りで。
bibhiduś ca viṣāṇāgraiḥ samākṣipya ca cikṣipuḥ|
viṣāṇalagnāś ca apy anye paripertur vibhīṣaṇāḥ||
// 8-60-11 //
牙の先で突き刺し、掴み上げて投げ飛ばした。牙に引っかかったまま恐ろしい姿で倒れる者たちもいた。
pramukhe vartamānaṃ tu dvipam aṅgasya sātyakiḥ|
nārācena ugravegena bhittvā marmāṇy atāḍayat||
// 8-60-12 //
前方にいたアンガ族の象を、サーティヤキは激しい速度の鉄矢で急所を貫いて打った。
tasyāvarjitakāyasya dviradādutpatiṣyataḥ|
nārācena āhanad vakṣaḥ sātyakiḥ so 'patad bhuvi||
// 8-60-13 //
打撃で体を傾けて象から飛び降りようとするアンガの戦士の胸を、サーティヤキは鉄矢で射た。彼は地面に倒れた。
puṇḍrasyāpatato nāgaṃ calantamiva parvatam|
sahadevaḥ prasannāgrair nārācair ahanat tribhiḥ||
// 8-60-14 //
動く山のように突進してくるプンドラの象を、サハデーヴァは鋭い先端の三本の鉄矢で打った。
vipatākaṃ viyantāraṃ vivarmadhvajajīvitam|
taṃ kṛtvā dviradaṃ bhūyaḥ sahadevo 'ṅgam abhyayāt||
// 8-60-15 //
旗も御者も鎧も旗印も命も失わせたその象に対して、サハデーヴァは再びアンガの勇者に向かった。
sahadevaṃ tu nakulo vārayitvā aṅgam ārdayat|
nārācair yamadaṇḍābhais tribhir nāgaṃ śatena tam||
// 8-60-16 //
サハデーヴァを制してナクラがアンガの勇者を、ヤマの杖のような三本の鉄矢で打ち、象を百本で射た。
divākarakaprakhyān aṅgaś cikṣepa tomarān|
nakulāya śatāny aṣṭau tridhā ekaikam tu so 'cchinat||
// 8-60-17 //
太陽のように輝くアンガの勇者は八百本のトマラをナクラに投げたが、パーンダヴァはそれぞれを三つに切り裂いた。
tathā'rdhacandreṇa śirastasya ciccheda pāṇḍavaḥ|
sa papāta hato mlecchas tena eva saha dantinā||
// 8-60-18 //
そしてパーンダヴァは半月矢で彼の首を切った。ムレッチャはその象とともに倒れた。
atha aṅgaputre nihate hastiśikṣāviśārade|
aṅgāḥ kruddhā mahāmātrā nāgair nakulam abhyayuḥ||
// 8-60-19 //
アンガの王子が殺されると——象の戦いに熟練した者が——怒ったアンガ族の大将たちは象でナクラに向かった。
calatpatākaiḥ sumukhair hemakakṣyātanucchadaiḥ|
mimardiṣantas tvaritāḥ pradīptair iva parvataiḥ||
// 8-60-20 //
旗をはためかせた美しい顔の、黄金の腹帯と甲冑をつけた、蹂躙せんと急ぐ燃える山のような象で。
mekalā utkalakāliṅgā niṣadhās tāmraliptakāḥ|
śaratomaravarṣāṇi vimuñcanto jighāṃsavaḥ||
// 8-60-21 //
メーカラ族、ウトカラ族、カリンガ族、ニシャダ族、タームラリプタカ族が、矢とトマラの雨を放ちながら殺意をもって。
taiś chādyamānaṃ nakulaṃ niśākaram iva ambudaiḥ|
paripetuḥ susaṃrabdhāḥ pāṇḍupāñcālasātyakāḥ||
// 8-60-22 //
雲に覆われた月のように覆われたナクラの周りに、怒りに燃えるパーンドゥ・パーンチャーラ・サーティヤキの者たちが駆けつけた。
tatas tad abhavad yuddhaṃ rathināṃ hastibhiḥ saha|
sṛjatāṃ śaravarṣāṇi tomarāṃś ca sahasraśaḥ||
// 8-60-23 //
戦車兵と象の間に、矢の雨とトマラを千単位で放つ戦いが起こった。
nāgānāṃ prāsphuṭat kumbhāḥ marmāṇi ca nakhāni ca|
dantāś ca eva atividdhānāṃ nārācair hemabhūṣaṇaiḥ||
// 8-60-24 //
黄金で飾られた鉄矢に深く射られた象たちの瘤と急所と爪と牙が裂けた。
teṣām aṣṭau mahānāgāṃś catuḥṣaṣṭyā sutejanaiḥ|
nārācaiḥ sahadevas tān pātayāmāsa sādibhiḥ||
// 8-60-25 //
サハデーヴァは八頭の大象を六十四本の鋭い鉄矢で騎手もろとも倒した。
añjogatibhir āyamya prayatnāt dhanur uttamam|
nārācair ahanan nāgān nakulaḥ kulanandanaḥ||
// 8-60-26 //
家名を輝かすナクラは、最上の弓を力いっぱい引き、一直線に飛ぶ鉄矢で象を倒した。
tataḥ pāñcālaśaineyau draupadeyāḥ prabhadrakāḥ|
śikhaṇḍī ca mahānāgān siṣicuḥ śaravṛṣṭibhiḥ||
// 8-60-27 //
パーンチャーラとシャイネーヤ（サーティヤキ）、ドラウパディーの息子たち、プラバドラカ族、シカンディンが大象に矢の雨を浴びせた。
te pāṇḍuyodhāmbudharaiḥ śatrudviradaparvatāḥ|
bāṇavarṣair hatāḥ petur vajravarṣair iva ācalāḥ||
// 8-60-28 //
パーンドゥの戦士という雨雲によって、敵の象という山々は矢の雨に打たれ、雷の雨に打たれた山々のように倒れた。
evaṃ hatvā tava gajāṃs te pāṇḍurathakuñjarāḥ|
drutaṃ senāṃ ca varṣanto bhinnakūlām iva āpagām||
// 8-60-29 //
こうして汝の象を倒したパーンドゥ軍の戦車と象は、急いで軍勢に雨を降らせ、堤防の崩れた川のように押し寄せた。
tāṃ te senāṃ samāloḍya pāṇḍuputrasya sainikāḥ|
vikṣobhayitvā ca punaḥ karṇaṃ samabhidudruvuḥ||
// 8-60-30 //
パーンドゥの息子の兵士たちはその軍を攪乱し、再び動揺させた後、カルナに向かって突進した。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ṣaṣṭitamo'dhyāyaḥ|| 60 ||
こうして、聖なる大マハーバーラタのカルナ篇の第六十章は終わる。
