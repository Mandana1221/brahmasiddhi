この章の位置づけ

第24章は、マントラ成就のための「いつ行うべきか」という時間知の総合体系です。27ナクシャトラ（星宿）、12ラーシ（黄道十二宮）、9グラハ（惑星）の体系を詳細に記述し、さらに地震・日食・月食・流星・彗星などの天文現象を「マントラの成否を左右する兆相」として読み解きます。仏典でありながら、インド占星術（jyotiṣa）の実用マニュアルとしても読める異色の章です。

1. 序 — 釈尊が星宿・惑星に語りかける

釈尊（Bhagavān Śākyamuni）は、すべての世界に遍在する一切のナクシャトラ（星宿）・グラハ（惑星）・ターラカー（恒星）・ジョーティシュ（光体）に語りかけます。「貴方がたよ聴け。貴方がたの威力の語を示そう。すべてのマントラの行為と目的を成就せしめよ。この根本儀軌（kalparāja）における文殊師利の教えにおいて悉地（成就）をもたらせ」。v.1–2

続いて釈尊は宣言します。「グラハ（惑星）たちの行い、一切の衆生の利益のために、念誦者たちの利益のために、マントラの意義を成就する体系を説こう」。v.3

読解の鍵

本章では惑星や星宿が「人格を持つ聴衆」として扱われています。インドの伝統では、惑星（graha）は単なる天体ではなく、衆生に影響を与える天界の存在です。釈尊がそれらに「約束を守れ」（samaye ca tiṣṭhantu）と命じるのは、マントラの宇宙論的効力を惑星たちに保証させる行為です。

3. 宇宙開闢論 — 四ユガと星宿の起源

釈尊は、最初のユガ（クリタユガ＝完成の時代）には星宿も日月も存在しなかったと語ります。衆生は自ら光を放ち（svayambhuprabhāvāḥ）、空を飛び、老いも死もなく、食物も必要とせず、清浄で無病でした。姓（gotra）も日取り（tithi）もジャータカ（出生占い）も、断食も、マントラすらも存在しませんでした。v.13–16

やがて過去の業（pūrveṇa karmeṇa）に引かれて地上に降り、天宮から人間の身体へと堕落するにつれ、食への貪りで自発光を失い、そのとき初めて昼夜・星宿・惑星の知識が生まれたのです。v.17–20

菩薩の方便としての占星術

釈尊は続けて、自分が過去世においてリシ（聖仙）の姿をとり、あるいは梵天・ヴィシュヌ・大自在天・ガルダ・ヤクシャ・ラークシャサ・ピシャーチャの姿をとって、占星術を含むあらゆる知識を教えたと述べます。しかしそれらの世俗的知識では解脱は得られず、ただ仏陀の正覚によってのみ涅槃に達したと結びます。つまり占星術は菩薩の方便（ウパーヤ）であり、衆生を導くための「仮の教え」として位置づけられています。v.21–35

4. ジャータカ（出生星宿占い） — 各ラーシの人物像

本章の中核部分です。12のラーシそれぞれについて、そこに生まれた人の容姿・性格・運命・寿命・王権の可能性が詳細に記述されます。

ジャータカの「混合」

テキストは、出生が正確な瞬間から外れると「混合ジャータカ」（vyatimiśra-jātaka）となり、運命も「混合」すると述べます。現実の人間が教科書通りにならない理由を、このシステム内で説明する仕組みです。v.57–58

5. 地震占（ブーミカンパ） — 時刻と方角の吉凶

本章のなかで最も具体的で独特な部分です。地震がどのナクシャトラの支配する時刻・季節に発生したかによって、何が起きるかを予告する体系が展開されます。

ナクシャトラ別の地震の影響

  • マガー・アシュヴィニー・プナルヴァスで地震 → 中インドが苦しみ、盗賊と南方の侵攻が起きる v.129–130
  • バラニー・クリッティカー・ローヒニー・ムリガシラスで地震 → 西方の王が死ぬ。辺境のムレッチャ族が動く v.131–133
  • アールドラー・プシュヤ・アーシュレーシャー・パルグニーで地震 → 互いの王が争い、殺害・捕縛・飢饉 v.134–136
  • ハスタ・チトラー・スヴァーティ・アヌラーダー・ジェーシュターで地震 → ヒマラヤのムレッチャ族・盗賊、ネパール王・カシャ谷の王たちが互いに戦う v.137–139
  • ムーラ・アーシャーダーで地震 → 東方（プンドラ・ウドラ・カーマルーパ）の王が死に、ヴァンガーラ（ベンガル）王が死ぬ。ガウダの王も阻まれるか死ぬ v.140–143

時刻別の地震の意味

  • 正午の地震 → マガダの王が苦しむ v.149–150
  • 午後の地震 → 出家者が七日間病気に罹る v.151–152
  • 日没前の地震 → バラモン・王の大臣・プロヒタ（祭官）が殺される v.153–157
  • 日没後の地震 → 動物界と人間の有力者が滅ぶ v.158–159
  • 初夜の地震 → 大雨と雹 v.160
  • 二更の初め → 疫病・敵の侵入・腹の病 v.163–164
  • 二更の半ば → 大暴風。樹木・神殿・楼閣・城壁が倒壊 v.165–166
  • 真夜中 → 東方の王が殺されるか、その子が死ぬか、飢饉 v.167
  • 三更 → 蚊・蛾・泥棒が滅ぶ。健康と長寿 v.170
  • 黎明 → 諸城の火災 v.171
  • 日の出 → 中インドに盗賊。七日以内に王の死 v.172

地政学的テキストとしての価値

地震占のセクションは、プンドラ（北ベンガル）、ウドラ（オリッサ）、カーマルーパ（アッサム）、ヴァンガーラ（ベンガル）、ガウダ、ネパール、カシャ（カーシュミーラ）、ガンジス北岸のティーラ・ブクティ（ティルフット）、マガダ、ヴィンディヤ山麓といった具体的な地名を含みます。これらは8世紀のインド亜大陸の政治地理を反映しており、本経の成立年代を推定する手がかりとなります。

6. 日蝕・月蝕（ラーフのグラハナ） — 地域別災厄予告

日蝕・月蝕は、阿修羅王ラーフ（Rāhu）が太陽・月を「飲み込む」（grasyate）現象として記述されます。蝕がどのナクシャトラで起きるかによって、影響を受ける地域と災厄が異なります。

  • アシュヴィニー〜クリッティカーで蝕 → 痰性・胆汁性・風性の種々の病気が全衆生に生じる v.212–213
  • マガー〜ヴィシャーカーで蝕 → 東方の王、ラーダ地方、ヴァンガ・アンガ・マガダの王が眼病に罹り、子や妻の死、敵の結集 v.214–217
  • アヌラーダー・ジェーシュターで蝕 → 全ジャナパダ（地方）に疫病、殺害・捕縛・苦悩 v.220–221
  • プールヴァーシャーダー〜シュラヴァナで蝕 → 太陽が赤変、飢饉 v.222
  • レーヴァティー〜ウッタラバドラパダーで蝕 → マガダ王が王権を喪失 v.225–226

テキストは、ラーフがどの方角で太陽・月を飲み込むかによって、その方角の地域に吉凶が生じるという原理を述べます。また、地震に関する兆相（ニミッタ）は、日食・月食にもそのまま適用されるとします。v.227–228

7. 流星・彗星・虹と動物の異変

流星（ウルカー）の色による判定

  • 白色の流星 → 吉兆、幸福をもたらす v.175
  • 赤色の流星 → 大火災の予兆 v.175
  • 煙色または黒色 → 王の死を予告 v.176
  • 黄色・褐色・混合色 → 結果も混合。種々の異変 v.176–177

雷鳴（ニルガータ）の音質

  • 甘美で調和的な音 → 安寧・健康 v.178
  • 恐ろしく極めて激しい音 → 飢饉 v.179

動物の異変

白いカラス、黒い白鳥、季節外れの鳴き声、犬が口を上に向けて繰り返し吠えること — これらはすべて「倒錯の兆相」（viparīta）であり、干ばつ、王権の崩壊、大恐怖を予告します。二足・四足・無足・多足・鳥・爬虫類のすべてに適用されます。v.236–240

8. マントラ実践のための暦法と吉日選定

章の後半は、マントラの念誦・マンダラ描画・護摩・出陣に適したナクシャトラと日取りを規定します。

マントラ成就に好ましいナクシャトラ

アシュヴィニー・バラニー・プシュヤー・バドラパダー（両方）・レーヴァティー・アヌラーダー。「これらの宿においてマントラは成就し、成就した目的を与える」（sidhyante eṣu mantrā vai siddham arthaṃ dadanti te）。v.181

マンダラ描画に適した惑星

木星（Bṛhaspati）・金星（Śukra）・月（Candra）・水星（Budha）の四惑星が、黄色・白色の光を発して照らす日が最善です。v.182, 186–187

吉日（ティティ）

満月（15日）と、1日・3日・5日・7日・10日・13日が吉。4日は障碍の原因として避けるべし — ヴィナーヤカ（ガネーシャ）が4日目に障碍をなすためです。また8日・12日・14日の黒半月も避けるべきとされます。v.183–194

第15章との関係

第15章（一切作法）では占星術・夢占い・人相学が行者の「適性診断」として扱われましたが、本章では占星術がマントラ成就のタイミング選定という実践的機能に特化しています。第15章の適性判断と第24章の暦法選定を組み合わせることで、本経の「誰が・いつ・何を」の体系が完成します。

結語の原理

章は「ジャータカ（出生占い）が衆生の吉凶を示すのと同様に、兆相（ウトパータ）もまた吉凶をなす。因なくして兆相は生じず、障碍も理由なく起こらない」（nāhetukaṃ pravartante vighnā utpātasambhavāḥ）と結びます。これは占星術全体を仏教の因果論（業のシステム）のなかに回収する宣言であり、「星が運命を決める」のではなく、「業の結果を星が表示する」という仏教的な読み替えです。v.241–242
