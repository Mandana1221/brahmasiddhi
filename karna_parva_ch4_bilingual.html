本章は南伝（Southern Recension）テキストの「アディヤーヤ4」（ドリタラーシュトラが嘆き、サンジャヤが生存している主要な戦士たちの名を告げる章）です。各段落は原典の詩節番号（8-4-N）と和訳の段落番号が対応しています。
karṇaparva — caturtho'dhyāyaḥ (4)
第4章　生存者の名が告げられる
dhṛtarāṣṭra uvāca|
māmakasyāsya sainyasya hṛtotsekasya sañjaya|
avaśeṣaṃ na paśyāmi kakude mṛdite sati||
tau hi vīrau maheṣvāsau madarthe kurusattamau|
bhīṣmadroṇau hatau śrutvā konvartho jīvitena me|| // 8-4-1-2 //
ドリタラーシュトラは語った。 （1〜2）「サンジャヤよ、我が軍は誇りを打ち砕かれた。頂点が潰された今、残された者が見えない。大いなる弓の達人ビーシュマとドローナ——あのクルの最上者二人が我がために殺されたと聞いて、生きていることに何の意味があろう。
na ca mṛṣyāmi rādheyaṃ hatamāhavaśobhinam|
yasya bāhvor balaṃ tulyaṃ kuñjarāṇāṃ śataṃ śatam|| // 8-4-3 //
（3）戦場で輝くラーデーヤ（カルナ）が殺されたことも耐え難い。その両腕の力は百頭の象に匹敵したのに。
hatapravarasainyaṃ me yathā śaṃsasi sañjaya|
ahatānapi me śaṃsa ye'tra jīvanti kecana|| // 8-4-4 //
（4）サンジャヤよ、精鋭を殺し尽くされた我が軍についてお前は語ったが、まだ生き残っている者があれば、その者たちも教えてくれ。
eteṣu hi mṛteṣvadya ye tvayā parikīrtitāḥ|
ye'pi jīvanti te sarve mṛtā iti matir mama|| // 8-4-5 //
（5）お前が名を挙げた者たちが死んだ今、生き残る者たちもすべて死んだも同然だと私は考える。」
sañjaya uvāca|
yasmin mahāstrāṇi samarpitāni citrāṇi śubhrāṇi caturvidhāni|
divyāni rājan vihitāni caiva droṇena vīre dvijasattamena||
mahārathaḥ kṛtimān kṣiprahasto dṛḍhāyudho dṛḍhamuṣṭir dṛḍheṣuḥ|
sa vīryavān droṇaputras tarasvī vyavasthito yodvukāmastvadarthe|| // 8-4-6-7 //
サンジャヤは語った。 （6〜7）「偉大なる力の者、見事で輝かしい四種の武器を神聖な形でドローナに授けられた者——偉大な戦車戦士にして巧みで素早い手を持ち、堅い武器と堅い拳と堅い矢を持つ者——武勇あるドローナの子（アシュヴァッターマン）は、あなたのために戦う意欲をもって立っています。
ānartavāsī hṛdikātmajo'sau mahārathaḥ sātvatānāṃ variṣṭhaḥ|
svayaṃ bhojaḥ kṛtavarmā kṛtāstro vyavasthito yodvukāmastvadarthe|| // 8-4-8 //
（8）アーナルタに住むフリディカの子——偉大な戦車戦士にしてサートヴァタ族の最上者、ボージャ族のクリタヴァルマンは武器に精通し、あなたのために戦う意欲をもって立っています。
ārtāyaniḥ samare duṣprakampyaḥ senāgraṇīḥ prathamastāvakānām|
yaḥ svasrīyān pāṇḍaveyān visṛjya satyāṃ vācaṃ svāṃ cikīrṣustarasvī||
tajovadhaṃ sūtaputrasya saṅkhye pratiśrutyājātaśatroḥ purastāt|
durādharṣaḥ śakrasamānavīryaḥ śalyaḥ sthito yodvukāmastvadarthe|| // 8-4-9-10 //
（9〜10）アールターヤニ（シャリヤ）は戦場で揺るぎなく、あなた方の軍の先頭に立つ者。甥であるパーンダヴァたちを見捨て、自らの真実の言葉を守ろうとする勇猛な者——アジャータシャトル（ユディシュティラ）の前で御者の子（カルナ）の殺害を阻止すると誓い——インドラに等しい武勇を持つ近づき難きシャリヤは、あなたのために戦う意欲をもって立っています。
śāradvato gautamaścāpi rājan mahābāhucitrāstrayodhī|
dhanuścitraṃ sumahadbhāvarasāhaṃ vyavasthito yodvukāmaḥ pragṛhya|| // 8-4-11 //
（11）シャーラドヴァタ・ガウタマ（クリパ）もまた、王よ、大いなる腕と見事な武器の戦い手として、大きく立派で力強い弓を持って、あなたのために戦う意欲をもって立っています。
gāndhārarājaḥ sasutaśca rājan durdyūtadevī kalahapriyaśca|
gāndhāramukhyairyavanaiśca rājan vyavasthito yodvukāmastvadarthe|| // 8-4-12 //
（12）ガーンダーラの王（シャクニ）は息子とともに、王よ、賭博の巧みな争い好きとして、ガーンダーラの精鋭やヤヴァナ族とともに、あなたのために戦う意欲をもって立っています。
mahārathaḥ kekayarājaputraḥ sadaśvayuktaṃ ca patākinaṃ ca|
rathaṃ samāruhya kurupravīra vyavasthito yodvukāmastvadarthe|| // 8-4-13 //
（13）偉大な戦車戦士ケーカヤの王子は、良い馬と旗を持つ戦車に乗り、クルの勇者として、あなたのために戦う意欲をもって立っています。
tathā sutaste jvalanārkavarṇaṃ rathaṃ samāsthāya kurupravīraḥ|
vyavasthitaḥ purumitro narendra vyabhre sūryo bhrājamāno yathā khe|| // 8-4-14 //
（14）あなたの息子プルミトラもまた、火と太陽の色の戦車に乗り、クルの勇者として、王の中の王よ、雲のない空に輝く太陽のように美しく立っています。
duryodhano nāgakulasya madhye vyavasthitaḥ siṃha ivābabhāse|
rathena jāmbūnadabhūṣaṇena vyavasthitaḥ samare yotsyamānaḥ|| // 8-4-15 //
（15）ドゥルヨーダナは象の群れの中に立ち、獅子のように輝きました。黄金で飾られた戦車に乗り、戦場で戦おうと構えて。
sa rājamadhye puruṣapravīro rarāja jāmbūnadacitravarmā|
padmaprabho vahnirivālpadhūmo meghāntare sūrya iva prakāśaḥ|| // 8-4-16 //
（16）王たちの中に立つ人の中の勇者は、黄金と見事な色彩の鎧をまとい、蓮華の輝きを持つ火のように、煙少なき火のように、雲間の太陽のように輝きました。
tathā suṣeṇo'pyasicarmapāṇis tavātmajaḥ satyasenaśca vīraḥ|
vyavasthitau citrasenena sārdhaṃ hṛṣṭātmānau samare yoddhakāmau|| // 8-4-17 //
（17）あなたの息子スシェーナとサティヤセーナも、剣と盾を持ち、チトラセーナとともに、喜びに満ちて戦場で戦おうと構えています。
hīniṣevo bhāratarājaputra ugrāyudhaḥ śrutavarmā jayaśca|
śalaśca satyavrataduḥśalau ca vyavasthitāḥ sahasainyā narāgryāḥ|| // 8-4-18 //
（18）バーラタの王子ヒーニシェーヴァ、ウグラーユダ、シュルタヴァルマン、ジャヤ、シャラ、サティヤヴラタ、ドゥフシャラもまた軍とともに、人の中の精鋭として構えています。
kaitavyānāmadhipaḥ śūramānī raṇeraṇe śatruhā rājaputraḥ|
rathī hayī nāgapattiprayāyī vyavasthito yodvukāmastvadarthe|| // 8-4-19 //
（19）カイタヴヤ族の王にして勇者の誇りを持つ王子は、何度もの戦場で敵を殺す者として、戦車・馬・象・歩兵を率いて、あなたのために戦う意欲をもって立っています。
vīraḥ śrutāyuśca dhṛtāyudhaśca citrāṅgadaścitrasenaśca vīraḥ|
vyavasthitā yodvukāmā narāgryāḥ prahāriṇo māninaḥ satyasandhāḥ|| // 8-4-20 //
（20）勇者シュルターユス、ドリターユダ、チトラーンガダ、勇者チトラセーナもまた、武勇を持つ人の精鋭として、真実の誓いを持つ誇り高き戦士として構えています。
karṇātmajaḥ satyasandho mahātmā vyavasthitaḥ samare yodvukāmaḥ|| // 8-4-21 //
（21）カルナの息子サティヤサンダは偉大なる魂として、戦場で戦う意欲をもって立っています。
athāparau karṇasutau varāstrau vyavasthitau laghuhastau narendra|
bale mahatyulbaṇasatvavīryau samāsthitau yodvukāmau tvadarthe|| // 8-4-22 //
（22）王の中の王よ、カルナの他の二人の息子もまた、最上の武器を持ち、素早い手の者として、大軍の中に優れた力と武勇をもって、あなたのために戦う意欲をもって立っています。
etaiśca mukhyairaparaiśca rājan yodhapravīrairamitaprabhāvaiḥ|
vyavasthito nāgakulasya madhye yathā mahendraḥ kururājo jayāya|| // 8-4-23 //
（23）王よ、これらの主だった者たちと、計り知れない力を持つ他の戦士の勇者たちとともに、クルの王は象の群れの中に大いなるインドラのごとく、勝利のために構えています。」
dhṛtarāṣṭra uvāca|
ākhyātā jīvamānā ye pare sainyā yathāyatham|
itīdamavagacchāmi vyaktamarthābhipattitaḥ|| // 8-4-24 //
ドリタラーシュトラは語った。 （24）「生き残っている者たちが両陣営においてあるべく告げられた。結果から判断して、（我が軍の敗北は）明白だと理解する。」
vaiśampāyana uvāca|
evaṃ bruvanneva tadā dhṛtarāṣṭro'mbikāsutaḥ|
hatapravīraṃ bhūyiṣṭhaṃ kiñciccheṣaṃ svakaṃ balam|
śrutvā vyāmohamāgacchacchokavyākulitendriyaḥ||
vyākulaṃ me manas tāta śrutvā sumahadapriyam||
mano muhyati cāṅgāni na ca śaknomi dhāvitum|
ityevamuktvā vacanaṃ dhṛtarāṣṭro'mbikāsutaḥ|
bhrāntacittastataḥ so'tha babhūva jagatīpatiḥ||
|| // 8-4-25-26 //
ヴァイシャンパーヤナは語った。 （25〜26）こう語ったアンビカーの子ドリタラーシュトラは、精鋭のほとんどを殺され、わずかしか残らない自軍の状況を聞いて、悲しみに感覚を乱されて朦朧となりました。「友よ、心が乱れている。大いなる不幸を聞いて。心はめまいを起こし、体の自由がきかない。走ることもできない。」こう語ったアンビカーの子ドリタラーシュトラは、大地の主は心乱れた者となりました。
iti śrīmanmahābhārate karṇaparvaṇi caturtho'dhyāyaḥ|| 4 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四章は終わる。
