マハーバーラタ ― カルナ篇 第36章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 36 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ36」（シャルヤの言葉に怒ったカルナが反論する場面）です。カルナは、かつてラーマ・ジャーマダグニヤ（パラシュラーマ）に正体を偽ってブラフマ武器を学んだものの、虫に脚を食われても動じなかったため正体を見破られ、「死の間際以外には武器を思い出せない」という呪いを受けた過去を語ります。さらに、誤って聖牛の仔牛を矢で殺し、別のバラモンから「戦場で車輪が陥没する」という呪いを受けたことも告白します。それでもカルナは、アルジュナとクリシュナへの恐れではなく、ただバラモンの呪言こそを恐れていると述べ、シャルヤを「友ならぬ者」として痛烈に非難しつつ、命を賭けてアルジュナ・クリシュナと戦う決意を表明して章を終えます。なお、この章は詩節ごとに4行・各11音節のトリシュトゥブ（triṣṭubh/upajāti）調で書かれており、和文・梵文ともに第35章までの標準的なシュローカ調とは異なります。
karṇaparva — ṣaṭtriṃśo'dhyāyaḥ (36)
第36章
sañjaya uvāca|
madrādhipasyādhirathirmahātmā vaco niśamya apriyam apratītaḥ|
uvāca śalyaṃ viditaṃ mama etad yathāvidhāv arjunavāsudevau|| // 8-36-1 //
サンジャヤは語った。 （1）マドラ王の不快な言葉を聞いた高潔な御者の子は、平静を保ちながらシャルヤに言った。「このことは、私はよく知っている――アルジュナとヴァースデーヴァがどのような者であるか。
śaure rathaṃ vāhayato'rjunasya balaṃ mahāstrāṇi ca pāṇḍavasya|
ahaṃ vijānāmi yathāvad adya parokṣabhūtaṃ tava tattu śalya|| // 8-36-2 //
（2）アルジュナの戦車を駆るクリシュナの力、パーンダヴァ（アルジュナ）の偉大な武器――私はそれを知っている、シャルヤよ。お前には分からぬ。
tau ca apy aham śastrabhṛtāṃ variṣṭhau vyapetabhīr yodhayiṣyāmi kṛṣṇau|
santāpayaty abhyadhikaṃ hi rāmācchāpo'dya māṃ brāhmaṇasattamāc ca|| // 8-36-3 //
（3）私は武器を取る者の中で最上の二人、クリシュナたちと、恐れることなく戦うつもりだ。だが、今、私を苦しめているのは、ラーマ（パラシュラーマ）と、あるバラモンの聖者から受けた呪いである。
'purā mahendrādrivare samudre tapasvinaṃ rāmam upetya śalya|
astrārthinaṃ mā'dya śiṣyaṃ gṛhāṇa ity athā'bruvaṃ brāhmaṇacchadmanā ca|| // 8-36-4 //
（4）かつて、最上のマヘーンドラ山の頂、海のそばにいた苦行者ラーマのもとへ、武器を求めて私は行った、シャルヤよ。『今、私を弟子として受け入れてください』と、私はバラモンの姿に変装して願った。
tatrāvasaṃ brāhmaṇa iti avipro brahmāstralobhād anṛtena ca aham|
taj jāmadagnyena paraṃ mahāstraṃ samantrayuktaṃ vihitaṃ mama āsīt|| // 8-36-5 //
（5）私は『バラモンだ』と偽って、ブラフマの武器を得たい欲から、偽りの姿で彼のもとに住んだ。ジャーマダグニ（パラシュラーマ）から、呪文と共に最高の大武器を授かった。
astraṃ yadā tad viditaṃ mama āsīt tadā'bravīd brāhmaṇo māṃ maharṣiḥ|
āpadgatena astram idaṃ prayojyaṃ tvayā raṇe gacchatā sādhayeti'|| // 8-36-6 //
（6）その武器を私が取得したとき、大聖仙のバラモン（パラシュラーマ）は私に言った、『窮したときに、この武器をお前が使え、戦場で。行って仕上げよ』と。
tatra api me devarājena vighno hitārthinā phalgunasya eva śalya|
kṛto vibhedena mama ūrum etya praviśya kīṭasya tanuṃ virūpām|| // 8-36-7 //
（7）そのとき、神々の王インドラは、アルジュナの利益のために、私に障害をもたらしました、シャルヤよ。醜い虫の姿で私の太腿に入り込んで。
mama ūrum etya prabibheda kīṭaḥ supte gurau tatra śiro nidhāya|
ūruprabhedāc ca mahān babhūva śarīrato me ghanaśoṇitaughaḥ|| // 8-36-8 //
（8）その虫は私の太腿に入り、そこに頭を置いて師が眠っている間に、私の体に深く食い込んだ。太腿の傷口からは大量の血が流れ出た。
guror bhayāc ca api na celivān ahaṃ tato vibuddho dadṛśe sa vipraḥ|
sa dhairyayuktaṃ prasamīkṣya māṃ vai na tvaṃ vipraḥ ko'si satyaṃ vada iti|| // 8-36-9 //
（9）師への恐れから、私は動かなかった。目覚めたバラモンは、じっと耐えている私を見て、『お前はバラモンではない、誰であるか、真実を言え』と言った。
tasmai tadā ātmānam ahaṃ yathāvad ākhyātavān sūta iti eva śalya|
sa māṃ niśāmyātha mahātapasvī saṃśaptavānroṣaparītacetāḥ|| // 8-36-10 //
（10）そこで私は自分の正体を、『御者の子（スータ）です』と、ありのままに告げた、シャルヤよ。大苦行者はこれを聞いて、怒りに満ちた心で、呪いを発した――。
sūta tvayā hi āptam idaṃ tava astraṃ na karmakāle pratibhāsyati iti|
anyatra tu syāt tava mṛtyukālād abrāhmaṇe brahma na hi dhruvaṃ syāt|| // 8-36-11 //
（11）『御者の子よ、お前が偽って得たこの武器は、お前が実行するときに、お前の記憶に浮かばぬだろう。死のときでない限りはな。バラモンでない者に、バラモンの知識は確かに留まらぬ』と。
tad adya paryāptam atīva me'stram upasthite'smiṃs tumule vimarde|| // 8-36-12 //
（12）それゆえ今、激しい混戦が始まった今、私の武器は十分ではない。
śalya ugradhanvānam ahaṃ variṣṭhaṃ tarasvinaṃ bhīmamasahyavīryam|
satyapratijñaṃ yudhi pāṇḍaveyaṃ dhanañjayaṃ mṛtyumukhaṃ nayiṣye|| // 8-36-13 //
（13）しかし、シャルヤよ、恐ろしい弓の雄しき、優れた、素早い、耐え難い武勇のビーマ、戦場で誓いを守るパーンダヴァのアルジュナ、彼らを死の入口へと導くぞ。
astraṃ tato'nyat pratipannam adya yena kṣepsye samare śatrupūgān|
pratāpinaṃ balavantaṃ kṛtāstraṃ tamugradhanvānamamitaujasaṃ ca|
krūraṃ śūraṃ raudramamitrasāhaṃ dhanañjayaṃ saṃyuge'haṃ haniṣye|| // 8-36-14 //
（14）別の武器が、今日私の手に入った。それをもって、戦場で敵の群れを討ち倒そう。勢いよく、力あり、武器を習得した、恐ろしき弓の者、無量の光輝ある、残酷で、勇者で、荒々しき、敵に耐える、アルジュナを、戦場で私は討ち取る。
apāṃpatir vegavān aprameyo nimajjayiṣyan bahulāḥ prajā iva|
mahāravaṃ yaḥ kurute samudro velā iva taṃ vārayāmy aprameyam|| // 8-36-15 //
（15）水の主（ヴァルナ）のように勢いよく、量り知れない、多くの民を沈めようとし、大きな音を立てる海を、堤防のように、私はその無量の敵を抑えよう。
pramuñcantaṃ bāṇasaṅghān ameyān marmacchido vīrahaṇaḥ supatrān|
kuntīputraṃ pratiyotsyāmi yuddhe jyāṃ karṣatām uttamaṃ martyaloke|| // 8-36-16 //
（16）矢の束を放ち、急所を切り裂き、敵を討つ、美しい矢羽をもつクンティーの子（アルジュナ）を、私は戦いで相手にする。人の世で弓を引く者の最上者を。
evaṃ balena atibalaṃ mahāstraṃ samudrakalpaṃ sudurāpamugram|
śaraughiṇaṃ pārthivān majjayantaṃ velā iva pārtham iṣubhir vārayiṣye|| // 8-36-17 //
（17）力において超越した、海のような、耐え難い、矢を雨のように降らせて王たちを沈めるその大武器を、堤防のように私は矢でアルジュナを抑えよう。
kṛtī kṛtāstro dṛḍhahastayodhī divyāstravic chvetahayaḥ pramāthī|
surāsurān yudhi vai yo jayeta tena adya me paśya yuddhaṃ sughoram|| // 8-36-18 //
（18）巧みで、武器を習得し、手強き戦士、神の武器を知る、白馬をつけた、粉砕する者、神々とアスラを戦場で征服する者、そのような彼と、今日私の恐ろしい戦いを見よ。
abhīr mānī pāṇḍavo yuddhakāmo hi amānuṣair asyati māṃ mahāstraiḥ|
tasya astram astrair abhibhūya saṅkhye bāṇottamaiḥ pātayiṣyāmi pārtham|| // 8-36-19 //
（19）恐れなく誇り高き、戦いを望むパーンダヴァ（アルジュナ）が、人を超えた偉大な武器で私を討とうとも、その武器を武器で打ち倒し、最上の矢でアルジュナを戦場で倒そう。
sahasraraśmipratimaṃ jvalantaṃ diśaś ca sarvāḥ pratapantamugram|
tamonudaṃ megha iva atimātraṃ dhanañjayaṃ chādayiṣyāmi bāṇaiḥ|| // 8-36-20 //
（20）千光線（太陽）のように輝き、全方向を燃やす、激しい、闘を滅する、彼を雲のように、矢で覆い尽くそう。
vaiśvānaraṃ dhūmaketuṃ jvalantaṃ tejasvinaṃ naravīrān dahantam|
parjanyabhūtaḥ śaravarṣair yathā'gniṃ tathā pārthaṃ śamayiṣyāmi yuddhe|| // 8-36-21 //
（21）ヴァイシュヴァーナラ（火）、煙の旗をもつ、燃え立つ、輝きあり、人の勇者を焼く者である――そのアルジュナを、雨雲となって矢の雨で、火を消すように、戦場で鎮めよう。
āśīviṣaṃ dṛṣṭihaṇaṃ sughoraṃ sutīkṣṇadaṃṣṭraṃ jvalanaprabhavām|
krodhāt pradīptānalavad dahantaṃ kuntīputraṃ śamayiṣyāmi bhallaiḥ|| // 8-36-22 //
（22）毒蛇のように目で殺し、恐ろしく、鋭い牙をもち、炎のように輝き、怒りで燃え立つ火のごとく焼くクンティーの子を、広頭矢で鎮めよう。
pravāhiṇaṃ balavantaṃ mahaujasaṃ prabhañjanaṃ mātariśvānam ugram|
yuddhe sahiṣye himavān iva acalo dhanañjayaṃ kruddham amṛṣyamāṇam| // 8-36-23 //
（23）流れ、力あり、大いなる勢いの、押し倒す者、風神の子（ビーマ）、激しい者を、戦場で私はヒマラヤのように、怒る耐え難いアルジュナを耐え忍ぶ。
viśāradaṃ rathamārgeṣu śaktaṃ dhuryaṃ nityaṃ samareṣu pravīram|
loke varaṃ sarvadhanurdharāṇāṃ dhanañjayaṃ saṃyuge'haṃ haniṣye|| // 8-36-24 //
（24）戦車の道に通じ、力ある、戦いで常に先頭に立つ勇者、世で弓を持つすべての者の中でも最優秀の者、アルジュナを私は戦場で討ち取る。
adya āhave yasya na tulyam anyaṃ manye manuṣyaṃ dhanurādadānam|
sarvām imāṃ yaḥ pṛthivīṃ saheta tathāpi tena adya raṇe sameṣye|| // 8-36-25 //
（25）今日、戦場で彼に匹敵する者は、弓を取る者として、他にはいないと思う。この全地球を耐え得る者であろうとも、彼と私は戦う。
yaḥ sarvabhūtāni sadaivatāni prasthe'jayat khāṇḍave savyasācī ko jīvitaṃ rakṣamāṇo hi tena yuyutsate'strair mānuṣo mām ṛte'nyaḥ|| // 8-36-26 //
（26）神々を含むすべての生類を、カーンダヴァの平原でただ一人打ち負かしたサヴィヤサーチン（アルジュナ）――彼と戦おうとする生を惜しむ人間が、私以外にどこにいるか。
mānī kṛtāstraḥ kṛtahastayodhī divyāstravic chvetahayaḥ pramāthī|
tasya aham adya atirathasya kāyāc chiro hariṣyāmi śitaiḥ pṛṣatkaiḥ| // 8-36-27 //
（27）誇り高く、武器を習得し、手強く、神の武器を知る、白馬をつけた、粉砕する者――その至極の戦車戦士（アティラタ）の体から、今日、鋭い矢で私は首を切り取ろう。
yotsyāmy enaṃ śalya dhanañjayaṃ vai mṛtyuṃ puraskṛtya raṇe jayaṃ vā|
anyo hi na hi ekarathena martyo yudhyeta yaḥ pāṇḍavam indrakalpam // 8-36-28 //
（28）シャルヤよ、私はこのアルジュナと戦場で戦おう、死か勝利かを目の前に置いて。インドラに等しいパーンダヴァと、一つの戦車で戦える人間は、他にはいない。
tasya āhave pauruṣaṃ pāṇḍavasya brūyāṃ pṛṣṭaḥ samitau kṣatriyāṇām kiṃ tvaṃ mūrkhaḥ prahasan mūḍhacetā ākhyāsi me pauruṣaṃ phalgunasya|| // 8-36-29 //
（29）私がアルジュナの武勇を述べよう――戦場での――クシャトリヤの集会で問われたとき。一方お前は、愚か者よ、嘲りながら、混乱した心で、アルジュナの武勇を語るのか。
atyapriyo yaḥ puruṣo niṣṭhuro hi kṣudraḥ kṣeptā kṣamiṇaś ca akṣamāvān|
hanyām ahaṃ tvādṛśānāṃ śatāni kṣamāmy ahaṃ kṣamiṇāṃ kāla eṣaḥ|| // 8-36-30 //
（30）卑しく、残酷で、辛辣で、忍耐者を踏みつけるような、忍耐を持たぬ者――お前のような者たちを百人でも討つことができる。私は忍耐者を忍耐する。今はその時である。
avocas tvaṃ pāṇḍavārye priyāṇi pradharṣayan māṃ mūḍhavat pāpakarman|
mayi ārjave jihmamatir yatas tvaṃ mitradrohī sāptapadaṃ hi mitram|| // 8-36-31 //
（31）お前は、私を愚か者のように辱めながら、パーンダヴァの兄（ユディシュティラ）を褒めて、嬉しがらせた、悪を行う者よ。私が誠実であるのに、お前はひどい心で友の裏切り者だ。友とは七歩分かち合うだけで友である（古の格言）。
kālas tvayaṃ pratyupayāti dāruṇo duryodhano yuddham upāgamad yat|
tasya arthasiddhiṃ tu abhikāṅkṣamāṇas tam anveṣye yatra ca ekāntam asti|| // 8-36-32 //
（32）恐ろしい時が迫ってきた。ドゥルヨーダナが戦場に出る時が。彼の目的の達成を望みながら、私は彼を追い求める。ただ一つの道（勝利か死か）のある場所へ。
'tathāpi ahaṃ pāṇḍavavāsudevau yotsye raṇe madvidhasya eva karma|
na prākṛtaḥ sajjate vai kadācid yaḥ pratyudīyāt kṛṣṇadhanañjayau tau'|| // 8-36-33 //
（33）『それでも私はパーンダヴァとヴァースデーヴァと戦う。それこそが私のような者の仕事である。クリシュナとアルジュナに立ち向かう卑しき者は、決していない』。
mitraṃ minder nandateḥ prīyater vā santrāyater minuter modater vā|
duryodhane sarvam idaṃ mama asti tac ca api sarvaṃ mama vetti rājā|| // 8-36-34 //
（34）『ミトラ（友）』という言葉は、『喜ばせる』『気に入る』『愛する』『救う』『敬う』『楽しませる』などの語根から来ている。ドゥルヨーダナには、この友としての徳すべてが私にはある。それを王も知っている。
śatruḥ śadeḥ śāsater vā śyater vā śṛṇāter vā śvasateḥ sīdater vā|
śrameḥ śuco bahuśaḥ sūdateś ca prāyeṇa sarvaṃ tvayi tac ca mahyam|| // 8-36-35 //
（35）『シャトル（敵）』という言葉は、『殺す』『殴る』『弱める』『裂く』『息をつく』『沈める』『疲らせる』『苦しめる』『殺害する』などの語根から来ている。おおよそすべて、お前の中にあり、私に対してある。
duryodhanārthaṃ tava ca priyārthaṃ yaśo'rtham ātmārtham api īśvarārtham|
tasmādahaṃ pāṇḍavavāsudevau yotsye yatnātkarma ca paśya me'dya|| // 8-36-36 //
（36）ドゥルヨーダナのためにも、お前の喜びのためにも、名誉のためにも、自分のためにも、神のためにも、パーンダヴァとヴァースデーヴァと戦う。今日、私の懸命な業を見よ。
'śalya adya ahaṃ saṅgataḥ pāṇḍavena mucyeyaṃ cej jīvamānaḥ kathañcit|
śaśvan mṛtyoḥ syām anādhṛṣyarūpo vyaktaṃ tasmāt saṃyugād vipramuktāḥ'|| // 8-36-37 //
（37）『シャルヤよ、私が今日パーンダヴァと対峙し、どうにか生きて解放されるなら、それ以後、私は死に対して無敵となる。明らかに、そうして戦から解放されるか――』。
astraṃ brāhmaṃ manasā sañjapan vai yadā'syate krodhitaḥ savyasācī|
tadā api me na eva mucyeta pārtho na cet pated viṣame me'dya cakram|| // 8-36-38 //
（38）『ブラフマ武器を心の中で唱えてアルジュナが怒って放つとき、そのときでも、アルジュナが私から解放されることはない――もし、今日、困難な場所で私の車輪が沈まなければ』。
astrāṇi viddhvā samare gatāni brāhmāṇi divyāni atha mānuṣāṇi|
āsādayiṣyāmy aham ugravīryaṃ nāgottamaṃ nāga iva prabhinnaḥ|| // 8-36-39 //
（39）ブラフマや神の武器、そして人間の武器――これらを習得し、戦場に行った。〔……〕
vaivasvatād daṇḍahastād varuṇād vā api pāśinaḥ|
sagadād vā dhanapateḥ savajrād vā surādhipāt|| // 8-36-40 //
（40）ヤマ（棒をもつ死神）、ヴァルナ（縄をもつ水の神）、鉄棒を手にした富の主（クベーラ）、雷を手にした神々の王（インドラ）――。
atha anyasmād api surād amitrād ātatāyinaḥ|
iti śalya vijānīhi yathā na ahaṃ bibhemy uta|| // 8-36-41 //
（41）その他の神からも、敵や攻撃者からも――シャルヤよ、知るがよい、私がどれほど恐れていないかを。
tasmān na me bhayaṃ pārthān na api caiva janārdanāt|
saha yuddhaṃ hi me tābhyāṃ sāmparāye bhaviṣyati|| // 8-36-42 //
（42）ゆえに、アルジュナや、ジャナールダナ（クリシュナ）をも恐れない。今日、彼ら二人と戦いを交えることになるのだから。
śvabhre te patatāṃ cakram iti māṃ brāhmaṇo'bravīt|
yudhyamānasya saṅgrāme prāptasya ekāyanaṃ bhayam|| // 8-36-43 //
（43）『戦場でお前の車輪は穴に落ちるだろう』と、バラモンが私に言った。戦う者として、一方的な恐怖に見舞われるだろう、と。
tasmād bibhemi balavad brāhmaṇavyāhṛtād aham|
ete hi somarājāna īśvarāḥ sukhaduḥkhayoḥ|| // 8-36-44 //
（44）そのためにこそ、バラモンの言葉を、私は強く恐れるのだ。彼らは月の王たち（祭祀者）にして、苦楽を支配する主だからだ。
kadāci brāhmaṇasya atha yogyaheter ahaṃ nṛpa|
ajānan akṣipaṃ bāṇaṃ ghorarūpaṃ bhayāvaham|| // 8-36-45 //
（45）かつて、あるバラモンの祭祀用の牛を、私は知らずに獲物を狙う矢を放ち、恐ろしい姿の射てしまった。
homadhenvās tato vatsaḥ pramatta iṣuṇā hataḥ|
caranvai vijane śalya tato'nu vyājahāra saḥ|| // 8-36-46 //
（46）ホーマ（供犠）の牛の仔牛が、私の矢でうっかりと討たれた。人気のない場所を歩いていたのだ、シャルヤよ。するとバラモンは呪いを発した。
yasmād vatsas tvayā cātra homadhenvā hato nṛpa|
tasmāt tvam api rādheya vākśalyaṃ mahad āpnuhi|| // 8-36-47 //
（47）『お前が、私のホーマ牛の仔牛を討ったから、お前にも、カルナよ、言葉の矢の大きな苦しみが降りかかれ。
śvabhre te patitā cakraṃ yudhyamānasya śatruṇā|
prāpta ekāyane kāle mṛtyusādhāraṇe tvayi|| // 8-36-48 //
（48）戦う敵に対して、お前の車輪は穴に落ちるだろう。ただ一つの道のある時、死と結びつく時に、お前に』。
spardhase yena saṅgrāme yadarthaṃ ghaṭase'niśam|
tata eva dhruvaṃ mṛtyuṃ sūta prāpsyasi saṃyuge|| // 8-36-49 //
（49）『お前が競い合う戦場で、お前が奮闘するその時、確実に死をお前は戦場で得るだろう、御者の子よ』。
ahaṃ prasādayāñcakre brāhmaṇaṃ saṃśitavratam|| // 8-36-50 //
（50）私は誓いを立てた厳しい行のバラモンの機嫌を取ろうとした。
gavāṃ daśaśataṃ vittaṃ balīvardāṃś ca ṣaṭśatam|
pracchannaṃ kāñcanaiḥ kāmaṃ brāhmaṇārtham ahaṃ tadā|| // 8-36-51 //
（51）千頭の牛、六百頭の雄牛、金で覆われた財物を、バラモンに捧げようとした。
dāsīśataṃ niṣkakaṇṭhaṃ śatam aśvatarīrathān|
kanyānāṃ niṣkakaṇṭhīnāṃ sahasraṃ samalaṃkṛtam|| // 8-36-52 //
（52）胸飾りをつけた百人の奴隷女、百のラバ戦車、胸飾りと美しく飾られた千人の少女――。
īṣādantān nāgaśatān dāsīdāsaśatāni ca|
dadmi tair dvijamukhyo me prasādaṃ na cakāra saḥ|| // 8-36-53 //
（53）象の牙のような牙を持つ百頭の象、百人の奴隷の男女――これらを優れたバラモンに捧げたが、彼は満足しなかった。
kṛṣṇānāṃ śvetavatsānāṃ gośatāni caturdaśa|
dadan hi na labhe tasmāt prasādaṃ dvijasattamāt|| // 8-36-54 //
（54）黒い母牛と白い仔牛の四百頭の牛の乳――これらを捧げたが、優れたバラモンから満足を得られなかった。
yat kiñcin māmakaṃ vittaṃ tvad adhīnaṃ karomi tat|
iti māṃ yācamānaṃ vai brāhmaṇaḥ pratyavārayat|
krodhadīptekṣaṇaḥ śaḻya nirdahan iva cakṣuṣā|| // 8-36-55 //
（55）『私の財産全部を、あなたに渡します』と願ったが、バラモンはそれでも退け、怒りに目を燃え立たせて、シャルヤよ、目で私を焼き尽くすかのようだった。
vyāhṛtaṃ yan mayā sūta tat tathā na tad anyathā|
anṛtoktaṃ prajāṃ hanyāt tataḥ pāpam avāpnuyām|| // 8-36-56 //
（56）『御者の子よ、私が発した言葉は、そのように変わることはない。偽りを語れば子孫が滅び、私自身に罪が降りかかる』。
tasmād dharmābhirakṣārthaṃ nānṛtaṃ vaktumutsahe|
mā tvaṃ brahmagatiṃ hiṃsyāḥ prāyaścittaṃ kṛtaṃ tvayā|| // 8-36-57 //
（57）『ゆえに、正義の保護のため、偽りを言うつもりはない。お前はブラフマンの力を侮辱するな。お前が贖罪をしたのは、そのためだ』。
madvākyaṃ nānṛtaṃ loke kaścit kuryāt samāpnuhi|
'yan mayā uktaṃ saroṣeṇa gaccha sūtaja mā aciram|| // 8-36-58 //
（58）『私の言葉を嘘にしようと思う者はこの世にいない。受け入れよ。怒って語ったこの言葉――さっさと行け、御者の子よ、ぐずぐずするな』。
iti mām asakṛt kruddhaḥ sa uvāca dbijottamaḥ|
ete hi somarājāna īśvarāḥ sukhaduḥkhayoḥ|| // 8-36-59 //
（59）こう、怒りの余り、何度もそのバラモンは私に言った。彼らは月の王たちにして、苦楽を支配する主だ。
nāhaṃ bibhemi bībhatsor na śalya madhusūdanām|
tasmād bibhemy ahaṃ śāpāt tena satyena te śape|| // 8-36-60 //
（60）シャルヤよ、私はアルジュナを恐れぬ。クリシュナをも恐れぬ。ただ呪いを恐れるのだ。そのことを真実において、お前に誓う。
saha yuddhaṃ sametābhyām adya idaṃ samupasthitam|
yuddhe'smiñ jīvitaṃ me'dya śalya saṃśayam āgataṃ|| // 8-36-61 //
（61）彼ら二人との戦いが、今、共に始まった。戦場での私の命は、今日、危険にさらされている。
śakro'py amararāṭ tābhyām upagamya āhavaṃ saha|
saṃśayaṃ paramaṃ gacchet kathaṃ vā manyate bhavān|| // 8-36-62 //
（62）神々の王インドラであっても、二人と戦いを交えれば、極度の危険に陥るだろう。ましてや、あなたはどう思われるか。
iti evaṃ te mayā ākhyātaṃ kṣiptena na suhṛttayā|
jānāmi tvā'dhikṣipantaṃ doṣam ātmagataṃ śṛṇu'|| || // 8-36-63 //
（63）このように、お前から辱められたから私は語ったのだ、友として語ったのではない。お前が私を辱めているのを知っている。自分の中の欠点を聞け」。
iti śrīmanmahābhārate karṇaparvaṇi ṣaṭtriṃśo'dhyāyaḥ|| 36 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十六章は終わる。
