karṇaparva — prathamo'dhyāyaḥ (1)
カルナ篇 ― 第1章　サンジャヤがカルナの死をドリタラーシュトラに告げる・ドリタラーシュトラの嘆き
śrīvedavyāsāya namaḥ|
聖なるヴェーダヴィヤーサに敬礼する。
nārāyaṇaṃ namaskṛtya naraṃ caiva narottamam /
devīṃ sarasvatīṃ vyāsaṃ tato jayam udīrayet // 8-1-1 //
（1）ナーラーヤナに、そして人の中の最上者ナラに、女神サラスヴァティーに、ヴィヤーサに、敬礼してのち、「勝利」（ジャヤ）を語り始めよう。
vaiśampāyana uvāca|
śibirāddhāstinapuraṃ prāpya bhārata sañjayaḥ| praviveśa mahābāhurdhṛtarāṣṭraniveśanam||
ヴァイシャンパーヤナは語った。バーラタよ、サンジャヤは陣営からハースティナプラへ帰り、大いなる腕の者はドリタラーシュトラの館に入りました。
śokenāpahataḥ sūto vilapan bhṛśaduḥkhitaḥ /
cintayan nidhanaṃ ghoraṃ sūtaputrasya pāṇḍavaiḥ // 8-1-2 //
（2）御者の子は悲しみに打ちのめされ、激しく嘆き苦しみ、パーンダヴァたちによる御者の子（カルナ）の恐ろしい死を思い悩んでいました。
antaḥpuraṃ praviśyaiva sañjayo rājasattamam /
aśrupūrṇo bhṛśaṃ trasto rājānam upajagmivān // 8-1-3 //
（3）後宮に入り、涙に溢れ、深く震えながら、サンジャヤは最上の王のもとに参りました。
upasthāya ca rājānaṃ viniśvasya ca sūtajaḥ /
nātihṛṣṭamanā rājan idaṃ vacanam abravīt // 8-1-4 //
（4）王に近づき、嘆息し、喜びのない心で、王よ、次の言葉を述べました。
sañjaya uvāca|
sañcayo'haṃ mahārāja namaste bharatarṣabha| hato vaikartanaḥ karṇaḥ kṛtvā karma suduṣkaram|| 8-1-5 ||
サンジャヤは語った。
（5）「大王よ、サンジャヤでございます。バーラタの雄牛よ、あなたに敬礼いたします。ヴァイカルタナ・カルナは、極めて困難な業を成し遂げた後、討たれました。
cedikāśikarūśānāṃ matsyānāṃ somakaiḥ saha /
kṛtvā'sau kadanaṃ śete vātanunna iva drumaḥ // 8-1-6 //
（6）チェーディ・カーシ・カルーシャ・マツヤの軍とソーマカ族に大殺戮を行った後、風に倒された木のように横たわっています。
goṣṭhamadhyeva ṛṣabho govrajaiḥ parivāritaḥ /
vyālena nihato yadvattathā'sau nihataḥ paraiḥ // 8-1-7 //
（7）牧場の中の雄牛が、牛の群れに囲まれながら、猛獣に殺されるように、彼は敵に殺されました。
nirāśān pāṇḍavān kṛtvā dṛḍhaṃ rājan sasātyakān /
pāñcālānāṃ rathāṃścaiva vinihatya sahasraśaḥ // 8-1-8 //
（8）王よ、パーンダヴァたちとサーティヤキの望みを打ち砕き、パーンチャーラ族の何千もの戦車を殺した後に——
jitvā śūrān maheṣvāsān vidrāvya ca diśo daśa /
hato vaikartanaḥ karṇaḥ pāṇḍavena kirīṭinā // 8-1-9 //
（9）勇者で偉大な弓の達人たちを打ち負かし、十方に追い散らした後に——ヴァイカルタナ・カルナは、冠を戴くパーンダヴァ（アルジュナ）に殺されました。
vairasya gata ānṛṇyaṃ durgamasya durātmabhiḥ /
hatvā karṇaṃ mahārāja viśalyaḥ pāṇḍavo'bhavat // 8-1-10 //
（10）大王よ、悪しき者たちには越え難い敵意の借りを、カルナを殺すことで返し、パーンダヴァは棘を抜かれた者となりました。
śoṣaṇaṃ sāgarāṇāṃ vā patanaṃ vā vivasvataḥ /
viśīrṇatvaṃ yathā meros tathā karṇasya pātanam // 8-1-11 //
（11）大海が干上がるか、太陽が落ちるか、メール山が崩れるか——カルナの滅亡はそのようなものです。
yodhāśca bahavo rājan hatās tatra jayaiṣiṇaḥ /
rājāno rājaputrāśca śūrāḥ parighabāhavaḥ // 8-1-12 //
（12）王よ、勝利を求める多くの戦士たち——王たち、王子たち、鉄棒のような腕を持つ勇者たちが、その場で殺されました。
rathaughāśca naraughāśca hatā rājan sahasraśaḥ /
vāraṇā nihatās tatra vājinaśca mahāhave // 8-1-13 //
（13）王よ、何千もの戦車の群れ、人の群れが殺されました。象も馬もこの大戦闘で殺されました。
kṣatriyāśca mahārāja senayor ubhayor hatāḥ /
parasparaṃ vai vīkṣya atra parasparakṛtāgasaḥ // 8-1-14 //
（14）大王よ、両軍のクシャトリヤたちは、互いに互いを見つめながら、互いに害をなし合って殺されました。
kiñcit śeṣān parān kṛtvā tīrtvā pāṇḍavavāhinīm /
pārthavelāṃ samāsādya hato vaikartano vṛṣā // 8-1-15 //
（15）敵をほとんど残さず、パーンダヴァ軍を渡り切ろうとして、パールタ（アルジュナ）という岸辺に達した時、ヴァイカルタナの雄牛（カルナ）は討たれました。
jayāśā dhārtarāṣṭrāṇāṃ vairasya ca mukhaṃ nṛpa /
tīrṇaṃ tat pāṇḍavai rājan yat purā nāvabudhyase // 8-1-16 //
（16）ドリタラーシュトラの子らの勝利の望み、敵意の先頭——それはパーンダヴァたちに越えられたのです、王よ。あなたが以前それを悟らなかったことを。
procyamānaṃ mahārāja bandhubhir hitabuddhibhiḥ /
tad idaṃ samanuprāptaṃ vyasanaṃ tvāṃ mahābhayam // 8-1-17 //
（17）大王よ、利益を考える親族たちに言われ続けていたことが——この大いなる恐怖の災厄が、今あなたに降りかかったのです。
putrāṇāṃ rājyakāmena tvayā rājan hitaiṣiṇā /
caritāny ahitāny eva teṣāṃ te phalamāgatam // 8-1-18 //
（18）息子たちの王位を望むあなたは、利益を願いながら、実際には有害なことばかりを行ってきた。その報いが今来たのです。
hato duḥśāsano rājan yathoktaṃ pāṇḍavena tu /
pratijñā bhīmasenena nistīrṇā sā camūmukhe // 8-1-19 //
（19）王よ、ドゥフシャーサナもパーンダヴァ（ビーマ）の宣言どおりに殺されました。ビーマセーナの誓いは軍の前で果たされたのです。
pītaṃ ca kṣatajaṃ tasya dhārtarāṣṭrasya saṃyuge /
pāṇḍavena mahārāja karma kṛtvā suduṣkaram // 8-1-20 //」
（20）大王よ、パーンダヴァ（ビーマ）は極めて困難な業をなし、戦場でドリタラーシュトラの子（ドゥフシャーサナ）の血を飲みました。」
vaiśampāyana uvāca|
etacchrutvā mahārāja dhṛtarāṣṭro'mbikāsutaḥ| śokasya antam apaśyan vai hataṃ matvā suyodhanam| vihvalaḥ patito bhūmau naṣṭacetā iva dvipaḥ|| 8-1-21 ||
ヴァイシャンパーヤナは語った。
（21）大王よ、これを聞いたアンビカーの子ドリタラーシュトラは、悲しみの果てが見えず、スヨーダナ（ドゥルヨーダナ）も死んだと思い、うろたえて大地に倒れました。意識を失った象のように。
tasmin nipatite bhūmau vihvale rājasattame /
ārtanādo mahān āsīt strīṇāṃ bharatasattama // 8-1-22 //
śa śabdaḥ pṛthivīṃ kṛtsnāṃ pūrayāmāsa sarvaśaḥ // 8-1-23 //
（22〜23）バーラタの最上者よ、王の中の最上者が大地にうろたえて倒れた時、女たちの間に大きな悲鳴が上がりました。その声は大地全体をあらゆる方向に満たしました。
śokārṇave mahāghore nimagnā bharatastriyaḥ /
rurudur duḥkhaśokārtā bhṛśam udvignacetasaḥ // 8-1-24 //
（24）恐ろしく大きな悲しみの海に沈んだバーラタの女たちは、苦しみと悲しみに打たれて泣きました。深く心を乱しながら。
rājānaṃ ca samāsādya gāndhārī bharatarṣabha /
niḥsaṃjñā patitā bhūmau sarvāṇy antaḥ purāṇi ca // 8-1-25 //
（25）バーラタの雄牛よ、ガーンダーリーも王のもとに駆けつけ、意識を失って大地に倒れました。後宮の女たちもすべて。
tatas tāḥ sañjayo rājan samāśvāsayad āturāḥ /
muhyāmānāḥ subahuśo muñcantīr vāri netrajam // 8-1-26 //
（26）王よ、サンジャヤは苦しむ彼女たちを慰めました。何度もめまいを起こし、目から涙を流す者たちを。
samāśvastāḥ striyas tās tu vepamānā muhurmuhuḥ /
kadalya iva vātena dhūyamānāḥ samantataḥ // 8-1-27 //
（27）慰められた女たちは、それでも何度も震えていました。風にあちこち揺すられるバナナの木のように。
rājānaṃ viduraścāpi prajñācakṣuṣam īśvaram /
āśvāsayāmāsa tadā siñcaṃs toyena kauravam // 8-1-28 //
（28）ヴィドゥラもまた、智慧の目を持つ主なるその王を慰めました。水をかけてカウラヴァを介抱しながら。
sa labdhvā sanakaiḥ saṃjñāṃ tāśca dṛṣṭvā striyo nṛpaḥ /
unmatta iva rājendra sthitas tūṣṇīṃ viśāmpate // 8-1-29 //
（29）王はゆっくりと意識を取り戻し、女たちの姿を（心の目で）見て、王の中の王よ、まるで狂ったように黙って立っていました、王よ。
tato dhyātvā ciraṃ kālaṃ niḥśvasya ca punaḥpunaḥ /
svān putrān garhayāmāsa bahumene ca pāṇḍavān // 8-1-30 //
（30）それから長い間瞑想し、何度も嘆息してから、自分の息子たちを責め、パーンダヴァたちを讃えました。
garhayaṃś cātmano buddhiṃ śakuneḥ saubalasya ca /
dhyātvā tu suciraṃ kālaṃ vepamāno muhurmuhuḥ // 8-1-31 //
（31）自分の判断とシャクニ・サウバラの判断を責め、長い間考え込み、何度も震えながら——
saṃstabhya ca mano bhūyo rājā dhairyasamanvitaḥ /
punar gāvalgaṇiṃ sūtaṃ paryapṛcchata sañjayam // 8-1-32 //
（32）やがて心を落ち着かせ、忍耐力を取り戻した王は、ガーヴァルガニの子なる御者サンジャヤに再び尋ねました。
na tvayā kathitaṃ vākyaṃ śrutaṃ sañjaya tan mayā // 8-1-33 //
（33）「サンジャヤよ、お前の言葉をちゃんと聞いていなかった。
kaccid duryodhanaḥ sūta na gato vai yamakṣayam /
jaye nirāśaḥ putro me satataṃ jayakāmukaḥ /
brūhi sañjaya tattvena punaruktāṃ kathām imām // 8-1-34 //」
（34）御者よ、ドゥルヨーダナは閻魔の館に行ってしまったのではないか？ 勝利に望みを失ったか？ 常に勝利を求めていた我が息子は。サンジャヤよ、真実を語ってくれ、この話をもう一度。」
vaiśampāyana uvāca|
evam ukto'bravīt sūto rājānaṃ janamejaya| hato vaikartano rājan sahaputrair mahārathaḥ| bhrātṛbhiś ca maheṣvāsaiḥ sūtaputrais tanutyajaiḥ|| 8-1-35 ||
ヴァイシャンパーヤナは語った。
（35）ジャナメージャヤよ、こう言われた御者は王に語りました。「王よ、ヴァイカルタナ（カルナ）は討たれました。偉大な戦車戦士は、息子たちとともに、命を惜しまぬ偉大な弓兵の兄弟である御者の子たちとともに。
duḥśāsanaś ca nihataḥ pāṇḍavena yaśasvinā /
pītaṃ ca rudhiraṃ kopād bhīmasenena saṃyuge // 8-1-36 //」
（36）ドゥフシャーサナも栄光あるパーンダヴァ（ビーマ）に殺されました。ビーマセーナは怒りから戦場でその血を飲みました。」
vaiśampāyana uvāca|
etacchrutvā mahārāja dhṛtarāṣṭro'mbikāsutaḥ| dahyamāno'bravīt sūtaṃ muhūrtaṃ tiṣṭha sañjaya| vyākulaṃ me manas tāta mā tāvat kiṃcid ucyatām|| 8-1-37 ||
rājāpi nābravīt kiñcit sañjayo viduras tathā| tūṣṇīm bhūtas tadā so'tha babhūva jagatīpatiḥ|| 8-1-38 ||
ヴァイシャンパーヤナは語った。
（37〜38）これを聞いたアンビカーの子ドリタラーシュトラは、燃えるような苦しみの中で御者に言いました。「サンジャヤよ、しばらく待ってくれ。友よ、心が乱れている。今は何も言わないでくれ。」王もまた何も言わず、サンジャヤもヴィドゥラも。大地の主は、その時黙り込んでいました。
iti śrīmanmahābhārate karṇaparvaṇi prathamo'dhyāyaḥ|| 1 ||
こうして、聖なる大マハーバーラタのカルナ篇の第一章は終わる。
［南伝・続章 1］
第1章（続き）——ドゥルヨーダナたちがカルナを総大将に任命し、戦いに出発する
vaiśampāyana uvāca|
tato droṇe hate rājan duryodhanamukhā nṛpāḥ| bhṛśam udvignamanaso droṇaputram upāgaman|| 8-1-2 ||
ヴァイシャンパーヤナは語った。
（2）王よ、ドローナが殺された後、ドゥルヨーダナを先頭とする王たちは、深く心を乱しながらドローナの子（アシュヴァッターマン）のもとに行きました。
te droṇam anuśocantaḥ kaśmalābhihataujasaḥ /
paryupāsanta śokārtās tataḥ śāradvatīsutam // 8-1-3 //
（3）ドローナを悼み、失意に打ちひしがれた者たちは、悲しみに沈んでシャーラドヴァティーの子（クリパ）の傍に座りました。
te muhūrtaṃ samāśvasya hetubhiḥ śāstrasammitaiḥ /
rātryāgame mahīpālāḥ svāni veśmāni bhejire // 8-1-4 //
（4）しばらく聖典にかなう道理で気を取り直し、夜が来ると諸王は自分の宿舎に帰りました。
te veśmasv api kauravya pṛthvīśā nāpnuvan sukham /
cintayantaḥ kṣayaṃ tīvraṃ duḥkhaśokasamanvitāḥ // 8-1-5 //
（5）カウラヴヤよ、宿舎にいてもその王たちは安らぎを得ませんでした。激しい消耗を考え、苦しみと悲しみに満ちて。
viśeṣataḥ sūtaputro rājā caiva suyodhanaḥ /
duḥśāsanaśca śakuniḥ saubalaśca mahābalaḥ // 8-1-6 //
（6）とりわけ御者の子（カルナ）、スヨーダナ（ドゥルヨーダナ）王、ドゥフシャーサナ、そして大力のシャクニ・サウバラが。
uṣitās te niśāṃ tāṃ tu duryodhananiveśane /
cintayantaḥ parikleśān pāṇḍavānāṃ mahātmanām // 8-1-7 //
（7）彼らはドゥルヨーダナの宿舎でその夜を過ごし、偉大なる魂のパーンダヴァたちの苦しみを思い起こしていました。
yat tad dyūte parikliṣṭā kṛṣṇā cānāyitā sabhām /
tat smaranto'nuśocanto bhṛśam udvignacatetasaḥ // 8-1-8 //
（8）かつて賭博で苦しめられ、クリシュナー（ドラウパディー）が会議場に引きずり出されたこと——それを思い出し、嘆き、深く心を乱して。
tathā tu sañcintayatāṃ tān kleśān dyūtakāritān /
duḥkhena kṣaṇadā rājañ jagāmābdaśatopamā // 8-1-9 //
（9）賭博がもたらしたそれらの苦しみを思い返していると、王よ、苦しみの中で一夜が百年のように過ぎていきました。
tataḥ prabhāte vimale sthitā diṣṭasya śāsane /
cakrur āvaśyakaṃ sarve vidhidṛṣṭena karmaṇā // 8-1-10 //
（10）やがて清らかな朝が来ると、運命の支配のもとに立ち、聖典に定められた作法で皆が朝の勤めを行いました。
te kṛtvā'vaśyakāryāṇi samāśvasya ca bhārata /
yogam ājñāpayāmāsur yudvāya ca viniryayuḥ // 8-1-11 //
（11）バーラタよ、必要な作業を終え、気を取り直してから、出陣の命を下し、戦いに出発しました。
karṇaṃ senāpatiṃ kṛtvā kṛtakautukamaṅgalāḥ /
pūjayitvā dvijaśreṣṭhān dadhipātraghṛtākṣataiḥ // 8-1-12 //
（12）カルナを総大将に据え、吉祥の儀式を行い、最上のバラモンたちを凝乳の器・乳脂・穀物で供養し——
gobhir aśvaiś ca niṣkaiś ca vāsobhiś ca mahādhanaiḥ /
vandyamānā jayāśīrbhiḥ sūtamāgadhabandibhiḥ // 8-1-13 //
（13）牛・馬・金貨・高価な衣服で布施をし、吟遊詩人やマーガダ族の讃歌師たちの勝利の祝福を受けながら。
tathaiva pāṇḍavā rājan kṛtapūrvāhṇikakriyāḥ /
śibirān niryayus tūrṇaṃ yudvāya kṛtaniścayāḥ // 8-1-14 //
（14）同様に、王よ、パーンダヴァたちも朝の儀式を終え、戦いの決意を固めて速やかに陣営から出撃しました。
tataḥ pravavṛte yudvaṃ tumulaṃ romaharṣaṇam /
kurūṇāṃ pāṇḍavānāṃ ca parasparajayaiṣiṇām // 8-1-15 //
（15）そして、互いの勝利を求めるクル族とパーンダヴァの間に、身の毛もよだつ激しい戦いが始まりました。
tayor dvau divasau yudvaṃ kurupāṇḍavasenayoḥ /
karṇe senāpatau rājan babhūvādbhutadarśanam // 8-1-16 //
（16）王よ、カルナが総大将の間、クル・パーンダヴァ両軍の間に二日間の驚くべき戦闘がありました。
tataḥ śatrukṣayaṃ kṛtvā sumahāntaṃ raṇe vṛṣaḥ /
paśyatāṃ dhārtarāṣṭrāṇāṃ phalgunena nipātitaḥ // 8-1-17 //
（17）雄牛（カルナ）はその場で敵の大殺戮を行った後、ドリタラーシュトラの子らが見守る中、アルジュナに倒されました。
tatas tu sañjayaḥ sarvaṃ gatvā nāgapuraṃ drutam /
ācaṣṭa dhṛtarāṣṭrāya yad vṛttaṃ kurujāṅgale // 8-1-18 //
（18）そしてサンジャヤは急いで象の都（ハースティナプラ）に行き、クルジャーンガラ（クルクシェートラ）で起きたことをすべてドリタラーシュトラに語りました。
janamejaya uvāca|
āpageyaṃ hataṃ śrutvā droṇaṃ cāpi mahāratham| ājagāma parāmārtiṃ vṛdvo rājā'mbikāsutaḥ|| 8-1-19 ||
ジャナメージャヤは語った。
（19）ガンガーの子（ビーシュマ）が殺され、偉大な戦車戦士ドローナが殺されたと聞いて、老いた王アンビカーの子は最も深い苦悩に達しました。
sa śrutvā nihataṃ karṇaṃ duryodhanahitaiṣiṇam /
kathaṃ dvijavara prāṇān adhārayata duḥkhitaḥ // 8-1-20 //
（20）ドゥルヨーダナの利益を願うカルナが殺されたと聞いて、バラモンの最上者よ、苦しむ王はどのようにして命を保ったのですか。
yasmiñ jayāśāṃ putrāṇāṃ samamanyata pārthivaḥ /
tasmin hate sa kauravyaḥ kathaṃ prāṇān adhārayat // 8-1-21 //
（21）息子たちの勝利の望みを等しく託していた者が殺された時、カウラヴヤの王はどのようにして命を保ったのですか。
durmaraṃ tad ahaṃ manye nṛṇāṃ kṛcchre'pi vartatām /
yatra karṇaṃ hataṃ śrutvā nātyajat jīvitaṃ nṛpaḥ // 8-1-22 //
（22）困難の中にある人々にとって死ぬことは難しいと私は思います。カルナの死を聞いても王が命を捨てなかったのですから。
tathā śāntanavaṃ vṛdvaṃ brahman bāhlīkam eva ca /
droṇaṃ ca somadattaṃ ca bhūriśravasam eva ca // 8-1-23 //
（23）バラモンよ、老いたシャーンタナヴァ（ビーシュマ）やバーフリーカ、ドローナやソーマダッタ、ブーリシュラヴァスも同様に——
tathaiva cānyān suhṛdaḥ putrān pautrāṃś ca pātitān /
śrutvā yan nājahāt prāṇāṃs tan manye duṣkaraṃ dvija // 8-1-24 //
（24）そして他の親友たち、息子たち、孫たちが倒されたと聞いても命を捨てなかったことは、困難なことだと思います、バラモンよ。
etan me sarvam ācakṣva vistareṇa mahāmune /
na hi tṛpyāmi pūrveṣāṃ śṛṇvānaś caritaṃ mahat // 8-1-25 //」
（25）大聖仙よ、これをすべて詳しく語ってください。先祖の偉大な行いを聞いて飽きることがありませんので。」
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhārambhe prathamo'dhyāyaḥ|| 1 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの始まりの第一章は終わる。
［南伝・続章 2］
第1章（続き）——ドリタラーシュトラがビーシュマとドローナを嘆く
vaiśampāyana uvāca|
hate karṇe mahārāja niśi gāvalgaṇis tadā| dīno yayau nāgapuram aśvair vātasamair jave|| 8-1-1 ||
ヴァイシャンパーヤナは語った。
（1）大王よ、カルナが殺された後、ガーヴァルガニ（サンジャヤ）は夜、意気消沈して、風のように速い馬で象の都に向かいました。
sa hāstinapuraṃ gatvā bhṛśam udvignacetanaḥ /
jagāma dhṛtarāṣṭrasya kṣayaṃ prakṣīṇabāndhavam // 8-1-2 //
（2）ハースティナプラに着いた彼は、深く心を乱し、親族を失ったドリタラーシュトラの館へ行きました。
sa tam udvīkṣya rājānaṃ kaśmalābhihataujasam /
vavande prāñjalir bhūtvā mūrdhnā pādau nṛpasya ha // 8-1-3 //
（3）失意に打ちのめされた王を見て、合掌し、頭で王の足に礼をしました。
sampūjya ca yathānyāyaṃ dhṛtarāṣṭraṃ mahīpatim /
hā kaṣṭam iti coktvā sa tato vacanam ādade // 8-1-4 //
（4）しかるべくドリタラーシュトラ大王を供養してから、「ああ、なんということだ」と言い、語り始めました。
sañjayo'haṃ kṣitipate kaccidāste sukhaṃ bhavān /
svadoṣair āpadaṃ prāpya kaccin nādya vimuhyati // 8-1-5 //」
（5）「大地の主よ、サンジャヤでございます。ご安泰でしょうか。自らの過ちで災厄に遭われて、今日惑わされてはいませんか。
hitāny uktāni viduradroṇagāṅgeyakeśavaiḥ /
agṛhītāny anusmṛtya kaccin na kuruṣe vyathām // 8-1-6 //
（6）ヴィドゥラ・ドローナ・ビーシュマ・ケーシャヴァ（クリシュナ）が語った有益な言葉を受け入れなかったことを思い出して、苦しんではいませんか。
rāmanāradakaṇvādyair hitam uktaṃ sabhātale /
na gṛhītam anusmṛtya kaccin na kuruṣe vyathām // 8-1-7 //
（7）ラーマ・ナーラダ・カンヴァたちが会議場で語った有益な言葉を受け入れなかったことを思い出して、苦しんではいませんか。
suhṛdas tvadvite yuktān bhīṣmadroṇamukhān paraiḥ /
nihatān yudhi saṃsmṛtya kaccin na kuruṣe vyathām // 8-1-8 //」
（8）あなたの利益のために尽くした親友たち——ビーシュマやドローナを先頭とする者たちが、敵に殺されたことを思い出して、苦しんではいませんか。」
tam evaṃvādinaṃ rājā sūtaputraṃ kṛtājalim /
sudīrgham atha niḥśvasya duḥkhārta idam abravīt // 8-1-9 //
（9）このように語る御者の子が合掌しているのを見て、王は長く深い嘆息をつき、苦しみに満ちてこう言いました。
dhṛtarāṣṭra uvāca|
āpageye hate śūre divyāstravati sañjaya /
droṇe ca parameṣvāse bhṛśaṃ me vyathitaṃ manaḥ // 8-1-10 //
ドリタラーシュトラは語った。
（10）「サンジャヤよ、神聖な武器を持つ勇者ガンガーの子（ビーシュマ）が殺され、最上の弓兵ドローナも殺されて、我が心は深く苦しんでいる。
yo rathānāṃ sahasrāṇi daṃśitānāṃ daśaiva tu /
ahany ahani tejasvī nijaghne vasusambhavaḥ // 8-1-11 //
（11）あの威光ある者ガンガーの子は、武装した何千もの戦車を毎日打ち倒していた。
taṃ hataṃ yajñasenasya putreṇeha śikhaṇḍinā /
pāṇḍaveyābhiguptena śrutvā me vyathitaṃ manaḥ // 8-1-12 //
（12）あの者がヤジニャセーナの子シカンディンに——パーンダヴァたちに守られたシカンディンに殺されたと聞いて、我が心は苦しんでいる。
bhārgavaḥ pradadau yasmai paramāstraṃ mahāhave /
sākṣād rāmaṇe yo bālye dhanurveda upākṛtaḥ // 8-1-13 //
（13）バールガヴァ（パラシュラーマ）があの者に最上の武器を授け、幼少の時にラーマ自身から弓術を学んだ者——
yasya prasādāt kaunteyā rājaputrā mahārathāḥ /
mahārathatvaṃ samprāptās tathā'nye vasudhādhipāḥ // 8-1-14 //
（14）あの者の恩恵によって、カウンテーヤたちすなわち偉大な戦車戦士の王子たちが偉大な戦車戦士の位に達し、他の王たちもそうなった。
taṃ droṇaṃ nihataṃ śrutvā dhṛṣṭadyumnena saṃyuge /
satyasandhaṃ maheṣvāsaṃ bhṛśaṃ me vyathitaṃ manaḥ // 8-1-15 //
（15）真実の誓いを持つ偉大な弓兵ドローナが戦場でドリシュタデュムナに殺されたと聞いて、我が心は深く苦しんでいる。
yayor loke pumān astre na samo'sti caturvidhe /
tau droṇabhīṣmau śrutvā tu hatau me vyathitaṃ manaḥ // 8-1-16 //
（16）四種の武器において世にこの二人に等しい者はいなかった。ドローナとビーシュマが共に殺されたと聞いて、我が心は苦しんでいる。
trailokye yasya cāstreṣu na pumān vidyate samaḥ /
taṃ droṇaṃ nihataṃ śrutvā kim akurvata māmakāḥ // 8-1-17 //
（17）三界の武器において彼に等しい者はいなかった。あのドローナが殺されたと聞いて、我が者たちはどうしたのか。
saṃśaptakānāṃ ca bale pāṇḍavena mahātmanā /
dhanañjayena vikramya gamite yamasādanam // 8-1-18 //
（18）偉大なる魂のパーンダヴァ、ダナンジャヤ（アルジュナ）が力をもってサンシャプタカ族の軍を閻魔の館に送り——
nārāyaṇāstre ca hate droṇaputrasya dhīmataḥ /
vipradrutān aham manye nimagnāñ śokasāgare // 8-1-19 //
（19）ドローナの子の叡智あるナーラーヤナ武器も無効にされて——敗走する我が者たちは悲しみの海に沈んだと思う。
plavamānān hate droṇe sannanaukān ivārṇave /
duryodhanasya karṇasya bhojasya kṛtavarmaṇaḥ // 8-1-20 //
madrarājasya śalyasya drauṇeś caiva kṛpasya ca /
matputrasya ca śeṣasya tathā'nyeṣāṃ ca sañjaya // 8-1-21 //
（20〜21）ドローナが殺され、舟なくして大海に漂う者のように——ドゥルヨーダナ、カルナ、ボージャのクリタヴァルマン、マドラ王シャリヤ、ドローナの子、クリパ、そして残る我が息子たち——サンジャヤよ、軍が敗走した時、彼らの顔色はどうであったか。
vipradruteṣv anīkeṣu mukhavarṇo'bhavat katham /
etat sarvaṃ yathāvṛttaṃ tathā gāvalgaṇe mama // 8-1-22 //
ācakṣva pāṇḍaveyānāṃ māmakānāṃ ca vikramam // 8-1-23 //」
（22〜23）これらすべてがどのように起こったか、ガーヴァルガネよ、パーンダヴァたちと我が者たちの武勇を語ってくれ。」
sañjaya uvāca|
tavāparādhād yad vṛttaṃ kauraveyeṣu māriṣa /
tacchrutvā mā vyathāṃ kārṣīrdiṣṭe na vyathate budhaḥ // 8-1-24 //
サンジャヤは語った。
（24）「あなたの過ちによってカウラヴェーヤ族に起こったこと——それを聞いて嘆いてはなりません。運命に対して賢者は嘆かないものです。
yasmād abhāvī bhāvī vā bhaved artho naraṃ prati /
aprāptau tasya vā prāptau na kaścid yathate budhaḥ // 8-1-25 //」
（25）人に対して起こるべきことも起こらざるべきことも——それが来ても来なくても、賢者は嘆きません。」
dhṛtarāṣṭra uvāca|
na vyathā'bhyadhikā kācid vidyate mama sañjaya /
diṣṭam etat purā manye kathayasya yathecchakam // 8-1-26 //」
ドリタラーシュトラは語った。
（26）「サンジャヤよ、私にはこれ以上の苦しみはない。これは以前から定められた運命だと思う。望むままに語ってくれ。」
iti śrīmanmahābhārate karṇaparvaṇi dvitīyo'dhyāyaḥ|| 2 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二章は終わる。
［南伝・続章 3］
第1章（続き）——ドゥルヨーダナがカルナの武勇を讃えて兵を鼓舞する
sañjaya uvāca|
hate droṇe maheṣvāse tava putrā mahārathāḥ| babhūvur asvasthamukhā viṣaṇṇā gatacetasaḥ|| 8-1-1 ||
サンジャヤは語った。
（1〜2）偉大な弓兵ドローナが殺された後、あなたの息子たち偉大な戦車戦士たちは、不安な顔をし、落胆して意気消沈していました。うつむいて武器を持ち、悲しみに打たれて誰とも言葉を交わしませんでした。
avāṅmukhāḥ śastrabhṛtaḥ sarva eva viśāmpate /
avekṣamāṇāḥ śokārtā nābhyabhāṣan parasparam // 8-1-2 //
（続き：上記に統合）
tān dṛṣṭvā vyathitākārān sainyāni tava bhārata /
ūrdhvam eva niraikṣanta duḥkhatrastāny anekaśaḥ // 8-1-3 //
śastrāṇy eṣāṃ tu rājendra śoṇitāktāni sarvaśaḥ /
prābhraśyanta karāgrebhyo dṛṣṭvā droṇaṃ hataṃ yudhi // 8-1-4 //
tāni badvāny ariṣṭāni lambamānāni bhārata /
adṛśyanta mahārāja nakṣatrāṇi yathā divi // 8-1-5 //
（3〜5）バーラタよ、彼らの取り乱した様子を見て、あなたの軍も怯えて見上げるばかりでした。王の中の王よ、彼らの血にまみれた武器は、ドローナが殺されたのを見て手先から滑り落ちていきました。それらの武器は腕に固定されたままぶら下がり、大王よ、空の星座のように見えました。
tathā tu stimitaṃ dṛṣṭvā gatasatvam avasthitam /
balaṃ tava mahārāja rājā duryodhano'bravīt // 8-1-6 //
（6）こうして動きを止め、気力を失って立ちすくむあなたの大軍を見て、大王よ、ドゥルヨーダナ王は語りました。
bhavatāṃ bāhuvīryaṃ hi samāśritya mayā yudhi /
pāṇḍaveyāḥ samāhūtā yudvaṃ cedaṃ pravartitam // 8-1-7 //
tadidaṃ nihate droṇe viṣaṇṇamiva lakṣyate /
yudhyamānāś ca samare yodhā vadhyanti sarvaśaḥ // 8-1-8 //
jayo vā'pi vadho vā'pi yudhyamānasya saṃyuge /
bhavet kim atra citraṃ vai yudhyadhvaṃ sarvatomukhāḥ // 8-1-9 //」
（7〜9）「あなた方の腕の武勇を頼みにして、私は戦場でパーンダヴァたちに挑み、この戦争を始めた。今ドローナが殺されて軍は落胆しているように見えるが、戦って死ぬ者は戦場にいるのだ。そこに何の不思議があろう。全方位に向かって戦え。
paśyadhvaṃ ca mahātmānaṃ karṇaṃ vaikartanaṃ yudhi /
pracarantaṃ maheṣvāsaṃ divyair astrair mahābalam // 8-1-10 //
yasya vai yudhi santrāsāt kuntīputro dhanañjayaḥ /
nivartate sadā mandaḥ siṃhāt kṣudramṛgo yathā // 8-1-11 //
（10〜11）見よ、大いなる武勇の偉大な弓兵ヴァイカルタナ・カルナが、神聖な武器をもって戦場で活躍する姿を。カルナへの恐怖から、クンティーの子ダナンジャヤ（アルジュナ）は常に愚かにも退いている。獅子から小さな獣が逃げるように。
yena nāgāyutaprāṇo bhīmaseno mahābalaḥ /
mānuṣeṇaiva yuddhena tām avasthāṃ praveśitaḥ // 8-1-12 //
（12）万頭の象の力を持つ大力のビーマセーナですら、人間の力だけの戦いであの窮地に追い込まれた。
yena divyāstravicchūro māyāvī sa ghaṭotkacaḥ /
amoghayā raṇe śaktyā nihato bhairavaṃ nadan // 8-1-13 //
（13）神聖な武器を知る幻術使いの勇者ガトートカチャですら、あの者は戦場で必中のインドラの槍で恐ろしい叫び声とともに殺した。
tasya durvāravīryasya satyasandhasya dhīmataḥ /
bāhvor draviṇam akṣayyam adya drakṣyatha saṃyuge // 8-1-14 //
（14）抗い難い武勇を持ち、真実の誓いを持つ叡智ある者——その両腕の尽きぬ富を、今日戦場で見届けるがよい。
droṇaputrasya vikrāntaṃ rādheyasyaiva cobhayoḥ /
paśyantu pāṇḍuputrās te viṣṇuvāsavayor iva // 8-1-15 //
（15）ドローナの子の武勇と、ラーデーヤ（カルナ）のそれと——両者の武勇をパーンドゥの子らに見せてやろう。ヴィシュヌとインドラの武勇のように。
sarva eva bhavantaś ca śaktāḥ pratyekaśo'pi vā /
pāṇḍuputrān raṇe hantuṃ sasainyān kisu saṃhatāḥ /
vīryavantaḥ kṛtāstrāś ca drakṣyathādya parasparam // 8-1-16 //」
（16）あなた方は全員、一人一人でもパーンドゥの子らを軍ごと戦場で殺す力がある。まして団結すれば。武勇に満ち、武器に精通した者たちよ、今日互いに見届けるがよい。」
sañjaya uvāca|
evam uktvā tataḥ karṇaṃ cakre senāpatiṃ tadā| tava putro mahāvīryo bhrātṛbhiḥ sahito'nagha|| 8-1-17 ||
サンジャヤは語った。
（17）こう語ってから、あなたの大いなる武勇の息子は、兄弟たちとともに、罪なき者よ、カルナを総大将に任命しました。
saināpatyam athāvāpya karṇo rājan mahārathaḥ /
siṃhanādaṃ vinadyoccaiḥ prāyudhyata raṇotkaṭaḥ // 8-1-18 //
sasṛñjayānāṃ sarveṣāṃ pāñcālānāṃ ca māriṣa /
kekayānāṃ videhānāṃ cakāra kadanaṃ mahat // 8-1-19 //
tasyeṣudhārāḥ śataśaḥ prādurāsañ charāsanāt /
agre puṅkheṣu saṃsaktā yathā bhramarapaṅktayaḥ // 8-1-20 //
（18〜20）王よ、総大将の位を得た偉大な戦車戦士カルナは、高く獅子の咆哮を上げ、戦意に燃えて戦いました。スリンジャヤ族全員、パーンチャーラ族、ケーカヤ族、ヴィデーハ族に大殺戮を行いました。彼の弓から何百もの矢の流れが現れました——先端に矢尻が、矢尻にミツバチの列のように連なって。
sa pīḍayitvā pāñcālān pāṇḍavāṃś ca tarasvinaḥ /
hatvā sahasraśo yodhān arjunena nipātitaḥ // 8-1-21 //
（21）パーンチャーラ族と勇猛なパーンダヴァたちを苦しめ、何千もの戦士を殺した後に、アルジュナに倒されました。
iti śrīmanmahābhārate karṇaparvaṇi tṛtīyo'dhyāyaḥ|| 3 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三章は終わる。
