कर्णपर्व — प्रथमोऽध्यायः (1)
カルナ篇 ― 第1章　サンジャヤがカルナの死をドリタラーシュトラに告げる・ドリタラーシュトラの嘆き
श्रीवेदव्यासाय नमः।
聖なるヴェーダヴィヤーサに敬礼する。
नारायणं नमस्कृत्य नरं चैव नरोत्तमम् /
देवीं सरस्वतीं व्यासं ततो जयमुदीरयेत् // 8-1-1 //
（1）ナーラーヤナに、そして人の中の最上者ナラに、女神サラスヴァティーに、ヴィヤーサに、敬礼してのち、「勝利」（ジャヤ）を語り始めよう。
वैशम्पायन उवाच।
शिबिराद्धास्तिनपुरं प्राप्य भारत सञ्जयः। प्रविवेश महाबाहुर्धृतराष्ट्रनिवेशनम्॥
ヴァイシャンパーヤナは語った。バーラタよ、サンジャヤは陣営からハースティナプラへ帰り、大いなる腕の者はドリタラーシュトラの館に入りました。
शोकेनापहतः सूतो विलपन्भृशदुःखितः /
चिन्तयन्निधनं घोरं सूतपुत्रस्य पाण्डवैः // 8-1-2 //
（2）御者の子は悲しみに打ちのめされ、激しく嘆き苦しみ、パーンダヴァたちによる御者の子（カルナ）の恐ろしい死を思い悩んでいました。
अन्तःपुरं प्रविश्यैव सञ्जयो राजसत्तमम् /
अश्रुपूर्णो भृशं त्रस्तो राजानमुपजग्मिवान् // 8-1-3 //
（3）後宮に入り、涙に溢れ、深く震えながら、サンジャヤは最上の王のもとに参りました。
उपस्थाय च राजानं विनिश्वस्य च सूतजः /
नातिहृष्टमना राजन्निदं वचनमब्रवीत् // 8-1-4 //
（4）王に近づき、嘆息し、喜びのない心で、王よ、次の言葉を述べました。
सञ्जय उवाच।
सञ्चयोऽहं महाराज नमस्ते भरतर्षभ। हतो वैकर्तनः कर्णः कृत्वा कर्म सुदुष्करम्॥ 8-1-5 ॥
サンジャヤは語った。
（5）「大王よ、サンジャヤでございます。バーラタの雄牛よ、あなたに敬礼いたします。ヴァイカルタナ・カルナは、極めて困難な業を成し遂げた後、討たれました。
चेदिकाशिकरूशानां मत्स्यानां सोमकैः सह /
कृत्वाऽसौ कदनं शेते वातनुन्न इव द्रुमः // 8-1-6 //
（6）チェーディ・カーシ・カルーシャ・マツヤの軍とソーマカ族に大殺戮を行った後、風に倒された木のように横たわっています。
गोष्ठमध्येव ऋषभो गोव्रजैः परिवारितः /
व्यालेन निहतो यद्वत्तथाऽसौ निहतः परैः // 8-1-7 //
（7）牧場の中の雄牛が、牛の群れに囲まれながら、猛獣に殺されるように、彼は敵に殺されました。
निराशान्पाण्डवान्कृत्वा दृढं राजन्ससात्यकान् /
पाञ्चालानां रथांश्चैव विनिहत्य सहस्रशः // 8-1-8 //
（8）王よ、パーンダヴァたちとサーティヤキの望みを打ち砕き、パーンチャーラ族の何千もの戦車を殺した後に——
जित्वा शूरान्महेष्वासान्विद्राव्य च दिशोदश /
हतो वैकर्तनः कर्णः पाण्डवेन किरीटिना // 8-1-9 //
（9）勇者で偉大な弓の達人たちを打ち負かし、十方に追い散らした後に——ヴァイカルタナ・カルナは、冠を戴くパーンダヴァ（アルジュナ）に殺されました。
वैरस्य गत आनृण्यं दुर्गमस्य दुरात्मभिः /
हत्वा कर्णं महाराज विशल्यः पाण्डवोऽभवत् // 8-1-10 //
（10）大王よ、悪しき者たちには越え難い敵意の借りを、カルナを殺すことで返し、パーンダヴァは棘を抜かれた者となりました。
शोषणं सागराणां वा पतनं वा विवस्वतः /
विशीर्णत्वं यथा मेरोस्तथा कर्णस्य पातनम् // 8-1-11 //
（11）大海が干上がるか、太陽が落ちるか、メール山が崩れるか——カルナの滅亡はそのようなものです。
योधाश्च बहवो राजन्हतास्तत्र जयैषिणः /
राजानो राजपुत्राश्च शूराः परिघबाहवः // 8-1-12 //
（12）王よ、勝利を求める多くの戦士たち——王たち、王子たち、鉄棒のような腕を持つ勇者たちが、その場で殺されました。
रथौघाश्च नरौघाश्च हता राजन्सहस्रशः /
वारणा निहतास्तत्र वाजिनश्च महाहवे // 8-1-13 //
（13）王よ、何千もの戦車の群れ、人の群れが殺されました。象も馬もこの大戦闘で殺されました。
क्षत्रियाश्च महाराज सेनयोरुभयोर्हताः /
परस्परं वै वीक्ष्यात्र परस्परकृतागसः // 8-1-14 //
（14）大王よ、両軍のクシャトリヤたちは、互いに互いを見つめながら、互いに害をなし合って殺されました。
किञ्चिच्छेषान्परान्कृत्वा तीर्त्वा पाण्डववाहिनीम् /
पार्थवेलां समासाद्य हतो वैकर्तनो वृषा // 8-1-15 //
（15）敵をほとんど残さず、パーンダヴァ軍を渡り切ろうとして、パールタ（アルジュナ）という岸辺に達した時、ヴァイカルタナの雄牛（カルナ）は討たれました。
जयाशा धार्तराष्ट्राणां वैरस्य च मुखं नृप /
तीर्णं तत्पाण्डवै राजन्यत्पुरा नावबुध्यसे // 8-1-16 //
（16）ドリタラーシュトラの子らの勝利の望み、敵意の先頭——それはパーンダヴァたちに越えられたのです、王よ。あなたが以前それを悟らなかったことを。
प्रोच्यमानं महाराज बन्धुभिर्हितबुद्धिभिः /
तदिदं समनुप्राप्तं व्यसनं त्वां महाभयम् // 8-1-17 //
（17）大王よ、利益を考える親族たちに言われ続けていたことが——この大いなる恐怖の災厄が、今あなたに降りかかったのです。
पुत्राणां राज्यकामेन त्वया राजन्हितैषिणा /
चरितान्यहितान्येव तेषां ते फलमागतम् // 8-1-18 //
（18）息子たちの王位を望むあなたは、利益を願いながら、実際には有害なことばかりを行ってきた。その報いが今来たのです。
हतो दुःशासनो राजन्यथोक्तं पाण्डवेन तु /
प्रतिज्ञा भीमसेनेन निस्तीर्णा सा चमूमुखे // 8-1-19 //
（19）王よ、ドゥフシャーサナもパーンダヴァ（ビーマ）の宣言どおりに殺されました。ビーマセーナの誓いは軍の前で果たされたのです。
पीतं च क्षतजं तस्य धार्तराष्ट्रस्य संयुगे /
पाण्डवेन महाराज कर्म कृत्वा सुदुष्करम् // 8-1-20 //」
（20）大王よ、パーンダヴァ（ビーマ）は極めて困難な業をなし、戦場でドリタラーシュトラの子（ドゥフシャーサナ）の血を飲みました。」
वैशम्पायन उवाच।
एतच्छ्रुत्वा महाराज धृतराष्ट्रोऽम्बिकासुतः। शोकस्यान्तमपश्यन्वै हतं मत्वा सुयोधनम्। विह्वलः पतितो भूमौ नष्टचेता इव द्विपः॥ 8-1-21 ॥
ヴァイシャンパーヤナは語った。
（21）大王よ、これを聞いたアンビカーの子ドリタラーシュトラは、悲しみの果てが見えず、スヨーダナ（ドゥルヨーダナ）も死んだと思い、うろたえて大地に倒れました。意識を失った象のように。
तस्मिन्निपतिते भूमौ विह्वले राजसत्तमे /
आर्तनादो महानासीत्स्त्रीणां भरतसत्तम // 8-1-22 //
श शब्दः पृथिवीं कृत्स्नां पूरयामास सर्वशः // 8-1-23 //
（22〜23）バーラタの最上者よ、王の中の最上者が大地にうろたえて倒れた時、女たちの間に大きな悲鳴が上がりました。その声は大地全体をあらゆる方向に満たしました。
शोकार्णवे महाघोरे निमग्ना भरतस्त्रियः /
रुरुदुर्दुःखशोकार्ता भृशमुद्विग्नचेतसः // 8-1-24 //
（24）恐ろしく大きな悲しみの海に沈んだバーラタの女たちは、苦しみと悲しみに打たれて泣きました。深く心を乱しながら。
राजानं च समासाद्य गान्धारी भरतर्षभ /
निःसंज्ञा पतिता भूमौ सर्वाण्यन्तः पुराणि च // 8-1-25 //
（25）バーラタの雄牛よ、ガーンダーリーも王のもとに駆けつけ、意識を失って大地に倒れました。後宮の女たちもすべて。
ततस्ताः सञ्जयो राजन्समाश्वासयदातुराः /
मुह्यामानाः सुबहुशो मुञ्चन्तीर्वारि नेत्रजम् // 8-1-26 //
（26）王よ、サンジャヤは苦しむ彼女たちを慰めました。何度もめまいを起こし、目から涙を流す者たちを。
समाश्वस्ताः स्त्रियस्तास्तु वेपमाना मुहुर्मुहुः /
कदल्य इव वातेन धूयमानाः समन्ततः // 8-1-27 //
（27）慰められた女たちは、それでも何度も震えていました。風にあちこち揺すられるバナナの木のように。
राजानं विदुरश्चापि प्रज्ञाचक्षुषमीश्वरम् /
आश्वासयामास तदा सिञ्चंस्तोयेन कौरवम् // 8-1-28 //
（28）ヴィドゥラもまた、智慧の目を持つ主なるその王を慰めました。水をかけてカウラヴァを介抱しながら。
स लब्ध्वा सनकैः संज्ञां ताश्च दृष्ट्वा स्त्रियो नृपः /
उन्मत्त इव राजेन्द्र स्थितस्तूष्णीं विशाम्पते // 8-1-29 //
（29）王はゆっくりと意識を取り戻し、女たちの姿を（心の目で）見て、王の中の王よ、まるで狂ったように黙って立っていました、王よ。
ततो ध्यात्वा चिरं कालं निःश्वस्य च पुनःपुनः /
स्वान्पुत्रान्गर्हयामास बहुमेने च पाण्डवान् // 8-1-30 //
（30）それから長い間瞑想し、何度も嘆息してから、自分の息子たちを責め、パーンダヴァたちを讃えました。
गर्हयंश्चात्मनो बुद्धिं शकुनेः सौबलस्य च /
ध्यात्वा तु सुचिरं कालं वेपमानो मुहुर्मुहुः // 8-1-31 //
（31）自分の判断とシャクニ・サウバラの判断を責め、長い間考え込み、何度も震えながら——
संस्तभ्य च मनो भूयो राजा धैर्यसमन्वितः /
पुनर्गावल्गणिं सूतं पर्यपृच्छत सञ्जयम् // 8-1-32 //
（32）やがて心を落ち着かせ、忍耐力を取り戻した王は、ガーヴァルガニの子なる御者サンジャヤに再び尋ねました。
न त्वया कथितं वाक्यं श्रुतं सञ्जय तन्मया // 8-1-33 //
（33）「サンジャヤよ、お前の言葉をちゃんと聞いていなかった。
कच्चिद्दुर्योधनः सूत न गतो वै यमक्षयम् /
जये निराशः पुत्रो मे सततं जयकामुकः /
ब्रूहि सञ्जय तत्त्वेन पुनरुक्तां कथामिमाम् // 8-1-34 //」
（34）御者よ、ドゥルヨーダナは閻魔の館に行ってしまったのではないか？ 勝利に望みを失ったか？ 常に勝利を求めていた我が息子は。サンジャヤよ、真実を語ってくれ、この話をもう一度。」
वैशम्पायन उवाच।
एवमुक्तोऽब्रवीत्सूतो राजानं जनमेजय। हतो वैकर्तनो राजन्सहपुत्रैर्महारथः। भ्रातृभिश्च महेष्वासैः सूतपुत्रैस्तनुत्यजैः॥ 8-1-35 ॥
ヴァイシャンパーヤナは語った。
（35）ジャナメージャヤよ、こう言われた御者は王に語りました。「王よ、ヴァイカルタナ（カルナ）は討たれました。偉大な戦車戦士は、息子たちとともに、命を惜しまぬ偉大な弓兵の兄弟である御者の子たちとともに。
दुःशासनश्च निहतः पाण्डवेन यशस्विना /
पीतं च रुधिरं कोपाद्भीमसेनेन संयुगे // 8-1-36 //」
（36）ドゥフシャーサナも栄光あるパーンダヴァ（ビーマ）に殺されました。ビーマセーナは怒りから戦場でその血を飲みました。」
वैशम्पायन उवाच।
एतच्छ्रुत्वा महाराज धृतराष्ट्रोऽम्बिकासुतः। दह्यमानोऽब्रवीत्सूतं मुहूर्तं तिष्ठ सञ्जय। व्याकुलं मे मनस्तात मा तावत्किंचिदुच्यताम्॥ 8-1-37 ॥
राजापि नाब्रवीत्किञ्चित्सञ्जयो विदुरस्तथा। तूष्णीम्भूतस्तदा सोऽथ बभूव जगतीपतिः॥ 8-1-38 ॥
ヴァイシャンパーヤナは語った。
（37〜38）これを聞いたアンビカーの子ドリタラーシュトラは、燃えるような苦しみの中で御者に言いました。「サンジャヤよ、しばらく待ってくれ。友よ、心が乱れている。今は何も言わないでくれ。」王もまた何も言わず、サンジャヤもヴィドゥラも。大地の主は、その時黙り込んでいました。
इति श्रीमन्महाभारते कर्णपर्वणि प्रथमोऽध्यायः॥ १ ॥
こうして、聖なる大マハーバーラタのカルナ篇の第一章は終わる。
［南伝・続章 1］
第1章（続き）——ドゥルヨーダナたちがカルナを総大将に任命し、戦いに出発する
वैशम्पायन उवाच।
ततो द्रोणे हते राजन्दुर्योधनमुखा नृपाः। भृशमुद्विग्नमनसो द्रोणपुत्रमुपागमन्॥ 8-1-2 ॥
ヴァイシャンパーヤナは語った。
（2）王よ、ドローナが殺された後、ドゥルヨーダナを先頭とする王たちは、深く心を乱しながらドローナの子（アシュヴァッターマン）のもとに行きました。
ते द्रोणमनुशोचन्तः कश्मलाभिहतौजसः /
पर्युपासन्त शोकार्तास्ततः शारद्वतीसुतम् // 8-1-3 //
（3）ドローナを悼み、失意に打ちひしがれた者たちは、悲しみに沈んでシャーラドヴァティーの子（クリパ）の傍に座りました。
ते मुहूर्तं समाश्वस्य हेतुभिः शास्त्रसम्मितैः /
रात्र्यागमे महीपालाः स्वानि वेश्मानि भेजिरे // 8-1-4 //
（4）しばらく聖典にかなう道理で気を取り直し、夜が来ると諸王は自分の宿舎に帰りました。
ते वेश्मस्वपि कौरव्य पृथ्वीशा नाप्नुवन्सुखम् /
चिन्तयन्तः क्षयं तीव्रं दुःखशोकसमन्विताः // 8-1-5 //
（5）カウラヴヤよ、宿舎にいてもその王たちは安らぎを得ませんでした。激しい消耗を考え、苦しみと悲しみに満ちて。
विशेषतः सूतपुत्रो राजा चैव सुयोधनः /
दुःशासनश्च शकुनिः सौबलश्च महाबलः // 8-1-6 //
（6）とりわけ御者の子（カルナ）、スヨーダナ（ドゥルヨーダナ）王、ドゥフシャーサナ、そして大力のシャクニ・サウバラが。
उषितास्ते निशां तां तु दुर्योधननिवेशने /
चिन्तयन्तः परिक्लेशान्पाण्डवानां महात्मनाम् // 8-1-7 //
（7）彼らはドゥルヨーダナの宿舎でその夜を過ごし、偉大なる魂のパーンダヴァたちの苦しみを思い起こしていました。
यत्तद्द्यूते परिक्लिष्टा कृष्णा चानायिता सभाम् /
तत्स्मरन्तोऽनुशोचन्तो भृशमुद्विग्नचतेतसः // 8-1-8 //
（8）かつて賭博で苦しめられ、クリシュナー（ドラウパディー）が会議場に引きずり出されたこと——それを思い出し、嘆き、深く心を乱して。
तथा तु सञ्चिन्तयतां तान्क्लेशान्द्यूतकारितान् /
दुःखेन क्षणदा राजञ्जगामाब्दशतोपमा // 8-1-9 //
（9）賭博がもたらしたそれらの苦しみを思い返していると、王よ、苦しみの中で一夜が百年のように過ぎていきました。
ततः प्रभाते विमले स्थिता दिष्टस्य शासने /
चक्रुरावश्यकं सर्वे विधिदृष्टेन कर्मणा // 8-1-10 //
（10）やがて清らかな朝が来ると、運命の支配のもとに立ち、聖典に定められた作法で皆が朝の勤めを行いました。
ते कृत्वाऽवश्यकार्याणि समाश्वस्य च भारत /
योगमाज्ञापयामासुर्युद्वाय च विनिर्ययुः // 8-1-11 //
（11）バーラタよ、必要な作業を終え、気を取り直してから、出陣の命を下し、戦いに出発しました。
कर्णं सेनापतिं कृत्वा कृतकौतुकमङ्गलाः /
पूजयित्वा द्विजश्रेष्ठान्दधिपात्रघृताक्षतैः // 8-1-12 //
（12）カルナを総大将に据え、吉祥の儀式を行い、最上のバラモンたちを凝乳の器・乳脂・穀物で供養し——
गोभिरश्वैश्च निष्कैश्च वासोभिश्च महाधनैः /
वन्द्यमाना जयाशीर्भिः सूतमागधबन्दिभिः // 8-1-13 //
（13）牛・馬・金貨・高価な衣服で布施をし、吟遊詩人やマーガダ族の讃歌師たちの勝利の祝福を受けながら。
तथैव पाण्डवा राजन्कृतपूर्वाह्णिकक्रियाः /
शिबिरान्निर्ययुस्तूर्णं युद्वाय कृतनिश्चयाः // 8-1-14 //
（14）同様に、王よ、パーンダヴァたちも朝の儀式を終え、戦いの決意を固めて速やかに陣営から出撃しました。
ततः प्रववृते युद्वं तुमुलं रोमहर्षणम् /
कुरूणां पाण्डवानां च परस्परजयैषिणाम् // 8-1-15 //
（15）そして、互いの勝利を求めるクル族とパーンダヴァの間に、身の毛もよだつ激しい戦いが始まりました。
तयोर्द्वौ दिवसौ युद्वं कुरुपाण्डवसेनयोः /
कर्णे सेनापतौ राजन्बभूवाद्भुतदर्शनम् // 8-1-16 //
（16）王よ、カルナが総大将の間、クル・パーンダヴァ両軍の間に二日間の驚くべき戦闘がありました。
ततः शत्रुक्षयं कृत्वा सुमहान्तं रणे वृषः /
पश्यतां धार्तराष्ट्राणां फल्गुनेन निपातितः // 8-1-17 //
（17）雄牛（カルナ）はその場で敵の大殺戮を行った後、ドリタラーシュトラの子らが見守る中、アルジュナに倒されました。
ततस्तु सञ्जयः सर्वं गत्वा नागपुरं द्रुतम् /
आचष्ट धृतराष्ट्राय यद्वृत्तं कुरुजाङ्गले // 8-1-18 //
（18）そしてサンジャヤは急いで象の都（ハースティナプラ）に行き、クルジャーンガラ（クルクシェートラ）で起きたことをすべてドリタラーシュトラに語りました。
जनमेजय उवाच।
आपगेयं हतं श्रुत्वा द्रोणं चापि महारथम्। आजगाम परामार्तिं वृद्वो राजाऽम्बिकासुतः॥ 8-1-19 ॥
ジャナメージャヤは語った。
（19）ガンガーの子（ビーシュマ）が殺され、偉大な戦車戦士ドローナが殺されたと聞いて、老いた王アンビカーの子は最も深い苦悩に達しました。
स श्रुत्वा निहतं कर्णं दुर्योधनहितैषिणम् /
कथं द्विजवर प्राणानधारयत दुःखितः // 8-1-20 //
（20）ドゥルヨーダナの利益を願うカルナが殺されたと聞いて、バラモンの最上者よ、苦しむ王はどのようにして命を保ったのですか。
यस्मिञ्जयाशां पुत्राणां सममन्यत पार्थिवः /
तस्मिन्हते स कौरव्यः कथं प्राणानधारयत् // 8-1-21 //
（21）息子たちの勝利の望みを等しく託していた者が殺された時、カウラヴヤの王はどのようにして命を保ったのですか。
दुर्मरं तदहं मन्ये नृणां कृच्छ्रेऽपि वर्तताम् /
यत्र कर्णं हतं श्रुत्वा नात्यजज्जीवितं नृपः // 8-1-22 //
（22）困難の中にある人々にとって死ぬことは難しいと私は思います。カルナの死を聞いても王が命を捨てなかったのですから。
तथा शान्तनवं वृद्वं ब्रह्मन्बाह्लीकमेव च /
द्रोणं च सोमदत्तं च भूरिश्रवसमेव च // 8-1-23 //
（23）バラモンよ、老いたシャーンタナヴァ（ビーシュマ）やバーフリーカ、ドローナやソーマダッタ、ブーリシュラヴァスも同様に——
तथैव चान्यान्सुहृदः पुत्रान्पौत्रांश्च पातितान् /
श्रुत्वा यन्नाजहात्प्राणांस्तन्मन्ये दुष्करं द्विज // 8-1-24 //
（24）そして他の親友たち、息子たち、孫たちが倒されたと聞いても命を捨てなかったことは、困難なことだと思います、バラモンよ。
एतन्मे सर्वमाचक्ष्व विस्तरेण महामुने /
न हि तृप्यामि पूर्वेषां शृण्वानश्चरितं महत् // 8-1-25 //」
（25）大聖仙よ、これをすべて詳しく語ってください。先祖の偉大な行いを聞いて飽きることがありませんので。」
इति श्रीमन्महाभारते कर्णपर्वणि षोडशदिवसयुद्धारम्भे प्रथमोऽध्यायः॥ १ ॥
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの始まりの第一章は終わる。
［南伝・続章 2］
第1章（続き）——ドリタラーシュトラがビーシュマとドローナを嘆く
वैशम्पायन उवाच।
हते कर्णे महाराज निशि गावल्गणिस्तदा। दीनो ययौ नागपुरमश्वैर्वातसमैर्जवे॥ 8-1-1 ॥
ヴァイシャンパーヤナは語った。
（1）大王よ、カルナが殺された後、ガーヴァルガニ（サンジャヤ）は夜、意気消沈して、風のように速い馬で象の都に向かいました。
स हास्तिनपुरं गत्वा भृशमुद्विग्नचेतनः /
जगाम धृतराष्ट्रस्य क्षयं प्रक्षीणबान्धवम् // 8-1-2 //
（2）ハースティナプラに着いた彼は、深く心を乱し、親族を失ったドリタラーシュトラの館へ行きました。
स तमुद्वीक्ष्य राजानं कश्मलाभिहतौजसम् /
ववन्दे प्राञ्जलिर्भूत्वा मूर्ध्ना पादौ नृपस्य ह // 8-1-3 //
（3）失意に打ちのめされた王を見て、合掌し、頭で王の足に礼をしました。
सम्पूज्य च यथान्यायं धृतराष्ट्रं महीपतिम् /
हा कष्टमिति चोक्त्वा स ततो वचनमाददे // 8-1-4 //
（4）しかるべくドリタラーシュトラ大王を供養してから、「ああ、なんということだ」と言い、語り始めました。
सञ्जयोऽहं क्षितिपते कच्चिदास्ते सुखं भवान् /
स्वदोषैरापदं प्राप्य कच्चिन्नाद्य विमुह्यति // 8-1-5 //」
（5）「大地の主よ、サンジャヤでございます。ご安泰でしょうか。自らの過ちで災厄に遭われて、今日惑わされてはいませんか。
हितान्युक्तानि विदुरद्रोणगाङ्गेयकेशवैः /
अगृहीतान्यनुस्मृत्य कच्चिन्न कुरुषे व्यथाम् // 8-1-6 //
（6）ヴィドゥラ・ドローナ・ビーシュマ・ケーシャヴァ（クリシュナ）が語った有益な言葉を受け入れなかったことを思い出して、苦しんではいませんか。
रामनारदकण्वाद्यैर्हितमुक्तं सभातले /
न गृहीतमनुस्मृत्य कच्चिन्न कुरुषे व्यथाम् // 8-1-7 //
（7）ラーマ・ナーラダ・カンヴァたちが会議場で語った有益な言葉を受け入れなかったことを思い出して、苦しんではいませんか。
सुहृदस्त्वद्विते युक्तान्भीष्मद्रोणमुखान्परैः /
निहतान्युधि संस्मृत्य कच्चिन्न कुरुषे व्यथाम् // 8-1-8 //」
（8）あなたの利益のために尽くした親友たち——ビーシュマやドローナを先頭とする者たちが、敵に殺されたことを思い出して、苦しんではいませんか。」
तमेवंवादिनं राजा सूतपुत्रं कृताजलिम् /
सुदीर्घमथ निःश्वस्य दुःखार्त इदमब्रवीत् // 8-1-9 //
（9）このように語る御者の子が合掌しているのを見て、王は長く深い嘆息をつき、苦しみに満ちてこう言いました。
धृतराष्ट्र उवाच।
आपगेये हते शूरे दिव्यास्त्रवति सञ्जय /
द्रोणे च परमेष्वासे भृशं मे व्यथितं मनः // 8-1-10 //
ドリタラーシュトラは語った。
（10）「サンジャヤよ、神聖な武器を持つ勇者ガンガーの子（ビーシュマ）が殺され、最上の弓兵ドローナも殺されて、我が心は深く苦しんでいる。
यो रथानां सहस्राणि दंशितानां दशैव तु /
अहन्यहनि तेजस्वी निजघ्ने वसुसम्भवः // 8-1-11 //
（11）あの威光ある者ガンガーの子は、武装した何千もの戦車を毎日打ち倒していた。
तं हतं यज्ञसेनस्य पुत्रेणेह शिखण्डिना /
पाण्डवेयाभिगुप्तेन श्रुत्वा मे व्यथितं मनः // 8-1-12 //
（12）あの者がヤジニャセーナの子シカンディンに——パーンダヴァたちに守られたシカンディンに殺されたと聞いて、我が心は苦しんでいる。
भार्गवः प्रददौ यस्मै परमास्त्रं महाहवे /
साक्षाद्रामणे यो बाल्ये धनुर्वेद उपाकृतः // 8-1-13 //
（13）バールガヴァ（パラシュラーマ）があの者に最上の武器を授け、幼少の時にラーマ自身から弓術を学んだ者——
यस्य प्रसादात्कौन्तेया राजपुत्रा महारथाः /
महारथत्वं सम्प्राप्तास्तथाऽन्ये वसुधाधिपाः // 8-1-14 //
（14）あの者の恩恵によって、カウンテーヤたちすなわち偉大な戦車戦士の王子たちが偉大な戦車戦士の位に達し、他の王たちもそうなった。
तं द्रोणं निहतं श्रुत्वा धृष्टद्युम्नेन संयुगे /
सत्यसन्धं महेष्वासं भृशं मे व्यथितं मनः // 8-1-15 //
（15）真実の誓いを持つ偉大な弓兵ドローナが戦場でドリシュタデュムナに殺されたと聞いて、我が心は深く苦しんでいる。
ययोर्लोके पुमानस्त्रे न समोऽस्ति चतुर्विधे /
तौ द्रोणभीष्मौ श्रुत्वा तु हतौ मे व्यथितं मनः // 8-1-16 //
（16）四種の武器において世にこの二人に等しい者はいなかった。ドローナとビーシュマが共に殺されたと聞いて、我が心は苦しんでいる。
त्रैलोक्ये यस्य चास्त्रेषु न पुमान्विद्यते समः /
तं द्रोणं निहतं श्रुत्वा किमकुर्वत मामकाः // 8-1-17 //
（17）三界の武器において彼に等しい者はいなかった。あのドローナが殺されたと聞いて、我が者たちはどうしたのか。
संशप्तकानां च बले पाण्डवेन महात्मना /
धनञ्जयेन विक्रम्य गमिते यमसादनम् // 8-1-18 //
（18）偉大なる魂のパーンダヴァ、ダナンジャヤ（アルジュナ）が力をもってサンシャプタカ族の軍を閻魔の館に送り——
नारायणास्त्रे च हते द्रोणपुत्रस्य धीमतः /
विप्रद्रुतानहं मन्येनिमग्नाञ्शोकसागरे // 8-1-19 //
（19）ドローナの子の叡智あるナーラーヤナ武器も無効にされて——敗走する我が者たちは悲しみの海に沈んだと思う。
प्लवमानान्हते द्रोणे सन्ननौकानिवार्णवे /
दुर्योधनस्य कर्णस्य भोजस्य कृतवर्मणः // 8-1-20 //
मद्रराजस्य शल्यस्य द्रौणेश्चैव कृपस्य च /
मत्पुत्रस्य च शेषस्य तथाऽन्येषां च सञ्जय // 8-1-21 //
（20〜21）ドローナが殺され、舟なくして大海に漂う者のように——ドゥルヨーダナ、カルナ、ボージャのクリタヴァルマン、マドラ王シャリヤ、ドローナの子、クリパ、そして残る我が息子たち——サンジャヤよ、軍が敗走した時、彼らの顔色はどうであったか。
विप्रद्रुतेष्वनीकेषु मुखवर्णोऽभवत्कथम् /
एतत्सर्वं यथावृत्तं तथा गावल्गणे मम // 8-1-22 //
आचक्ष्व पाण्डवेयानां मामकानां च विक्रमम् // 8-1-23 //」
（22〜23）これらすべてがどのように起こったか、ガーヴァルガネよ、パーンダヴァたちと我が者たちの武勇を語ってくれ。」
सञ्जय उवाच।
तवापराधाद्यद्वृत्तं कौरवेयेषु मारिष /
तच्छ्रुत्वा मा व्यथां कार्षीर्दिष्टे न व्यथते बुधः // 8-1-24 //
サンジャヤは語った。
（24）「あなたの過ちによってカウラヴェーヤ族に起こったこと——それを聞いて嘆いてはなりません。運命に対して賢者は嘆かないものです。
यस्मादभावी भावी वा भवेदर्थो नरं प्रति /
अप्राप्तौ तस्य वा प्राप्तौ न कश्चिद्यथते बुधः // 8-1-25 //」
（25）人に対して起こるべきことも起こらざるべきことも——それが来ても来なくても、賢者は嘆きません。」
धृतराष्ट्र उवाच।
न व्यथाऽभ्यधिका काचिद्विद्यते मम सञ्जय /
दिष्टमेतत्पुरा मन्ये कथयस्य यथेच्छकम् // 8-1-26 //」
ドリタラーシュトラは語った。
（26）「サンジャヤよ、私にはこれ以上の苦しみはない。これは以前から定められた運命だと思う。望むままに語ってくれ。」
इति श्रीमन्महाभारते कर्णपर्वणि द्वितीयोऽध्यायः॥ २ ॥
こうして、聖なる大マハーバーラタのカルナ篇の第二章は終わる。
［南伝・続章 3］
第1章（続き）——ドゥルヨーダナがカルナの武勇を讃えて兵を鼓舞する
सञ्जय उवाच।
हते द्रोणे महेष्वासे तव पुत्रा महारथाः। बभूवुरस्वस्थमुखा विषण्णा गतचेतसः॥ 8-1-1 ॥
サンジャヤは語った。
（1〜2）偉大な弓兵ドローナが殺された後、あなたの息子たち偉大な戦車戦士たちは、不安な顔をし、落胆して意気消沈していました。うつむいて武器を持ち、悲しみに打たれて誰とも言葉を交わしませんでした。
अवाङ्मुखाः शस्त्रभृतः सर्व एव विशाम्पते /
अवेक्षमाणाः शोकार्ता नाभ्यभाषन्परस्परम् // 8-1-2 //
（続き：上記に統合）
तान्दृष्ट्वा व्यथिताकारान्सैन्यानि तव भारत /
ऊर्ध्वमेव निरैक्षन्त दुःखत्रस्तान्यनेकशः // 8-1-3 //
शस्त्राण्येषां तु राजेन्द्र शोणिताक्तानि सर्वशः /
प्राभ्रश्यन्त कराग्रेभ्यो दृष्ट्वा द्रोणं हतं युधि // 8-1-4 //
तानि बद्वान्यरिष्टानि लम्बमानानि भारत /
अदृश्यन्त महाराज नक्षत्राणि यथा दिवि // 8-1-5 //
（3〜5）バーラタよ、彼らの取り乱した様子を見て、あなたの軍も怯えて見上げるばかりでした。王の中の王よ、彼らの血にまみれた武器は、ドローナが殺されたのを見て手先から滑り落ちていきました。それらの武器は腕に固定されたままぶら下がり、大王よ、空の星座のように見えました。
तथा तु स्तिमितं दृष्ट्वा गतसत्वमवस्थितम् /
बलं तव महाराज राजा दुर्योधनोऽब्रवीत् // 8-1-6 //
（6）こうして動きを止め、気力を失って立ちすくむあなたの大軍を見て、大王よ、ドゥルヨーダナ王は語りました。
भवतां बाहुवीर्यं हि समाश्रित्य मया युधि /
पाण्डवेयाः समाहूता युद्वं चेदं प्रवर्तितम् // 8-1-7 //
तदिदं निहते द्रोणे विषण्णमिव लक्ष्यते /
युध्यमानाश्च समरे योधा वध्यन्ति सर्वशः // 8-1-8 //
जयो वाऽपि वधो वाऽपि युध्यमानस्य संयुगे /
भवेत्किमत्र चित्रं वै युध्यध्वं सर्वतोमुखाः // 8-1-9 //」
（7〜9）「あなた方の腕の武勇を頼みにして、私は戦場でパーンダヴァたちに挑み、この戦争を始めた。今ドローナが殺されて軍は落胆しているように見えるが、戦って死ぬ者は戦場にいるのだ。そこに何の不思議があろう。全方位に向かって戦え。
पश्यध्वं च महात्मानं कर्णं वैकर्तनं युधि /
प्रचरन्तं महेष्वासं दिव्यैरस्त्रैर्महाबलम् // 8-1-10 //
यस्य वै युधि सन्त्रासात्कुन्तीपुत्रो धनञ्जयः /
निवर्तते सदा मन्दः सिंहात्क्षुद्रमृगो यथा // 8-1-11 //
（10〜11）見よ、大いなる武勇の偉大な弓兵ヴァイカルタナ・カルナが、神聖な武器をもって戦場で活躍する姿を。カルナへの恐怖から、クンティーの子ダナンジャヤ（アルジュナ）は常に愚かにも退いている。獅子から小さな獣が逃げるように。
येन नागायुतप्राणो भीमसेनो महाबलः /
मानुषेणैव युद्धेन तामवस्थां प्रवेशितः // 8-1-12 //
（12）万頭の象の力を持つ大力のビーマセーナですら、人間の力だけの戦いであの窮地に追い込まれた。
येन दिव्यास्त्रविच्छूरो मायावी स घटोत्कचः /
अमोघया रणे शक्त्या निहतो भैरवं नदन् // 8-1-13 //
（13）神聖な武器を知る幻術使いの勇者ガトートカチャですら、あの者は戦場で必中のインドラの槍で恐ろしい叫び声とともに殺した。
तस्य दुर्वारवीर्यस्य सत्यसन्धस्य धीमतः /
बाह्वोर्द्रविणमक्षय्यमद्य द्रक्ष्यथ संयुगे // 8-1-14 //
（14）抗い難い武勇を持ち、真実の誓いを持つ叡智ある者——その両腕の尽きぬ富を、今日戦場で見届けるがよい。
द्रोणपुत्रस्य विक्रान्तं राधेयस्यैव चोभयोः /
पश्यन्तु पाण्डुपुत्रास्ते विष्णुवासवयोरिव // 8-1-15 //
（15）ドローナの子の武勇と、ラーデーヤ（カルナ）のそれと——両者の武勇をパーンドゥの子らに見せてやろう。ヴィシュヌとインドラの武勇のように。
सर्व एव भवन्तश्च शक्ताः प्रत्येकशोऽपि वा /
पाण्डुपुत्रान्रणे हन्तुं ससैन्यान्किसु संहताः /
वीर्यवन्तः कृतास्त्राश्च द्रक्ष्यथाद्य परस्परम् // 8-1-16 //」
（16）あなた方は全員、一人一人でもパーンドゥの子らを軍ごと戦場で殺す力がある。まして団結すれば。武勇に満ち、武器に精通した者たちよ、今日互いに見届けるがよい。」
सञ्जय उवाच।
एवमुक्त्वा ततः कर्णं चक्रे सेनापतिं तदा। तव पुत्रो महावीर्यो भ्रातृभिः सहितोऽनघ॥ 8-1-17 ॥
サンジャヤは語った。
（17）こう語ってから、あなたの大いなる武勇の息子は、兄弟たちとともに、罪なき者よ、カルナを総大将に任命しました。
सैनापत्यमथावाप्य कर्णो राजन्महारथः /
सिंहनादं विनद्योच्चैः प्रायुध्यत रणोत्कटः // 8-1-18 //
ससृञ्जयानां सर्वेषां पाञ्चालानां च मारिष /
केकयानां विदेहानां चकार कदनं महत् // 8-1-19 //
तस्येषुधाराः शतशः प्रादुरासञ्छरासनात् /
अग्रे पुङ्खेषु संसक्ता यथा भ्रमरपङ्क्तयः // 8-1-20 //
（18〜20）王よ、総大将の位を得た偉大な戦車戦士カルナは、高く獅子の咆哮を上げ、戦意に燃えて戦いました。スリンジャヤ族全員、パーンチャーラ族、ケーカヤ族、ヴィデーハ族に大殺戮を行いました。彼の弓から何百もの矢の流れが現れました——先端に矢尻が、矢尻にミツバチの列のように連なって。
स पीडयित्वा पाञ्चालान्पाण्डवांश्च तरस्विनः /
हत्वा सहस्रशो योधानर्जुनेन निपातितः // 8-1-21 //
（21）パーンチャーラ族と勇猛なパーンダヴァたちを苦しめ、何千もの戦士を殺した後に、アルジュナに倒されました。
इति श्रीमन्महाभारते कर्णपर्वणि तृतीयोऽध्यायः॥ ३ ॥
こうして、聖なる大マハーバーラタのカルナ篇の第三章は終わる。
