マハーバーラタ ― カルナ篇 第83章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 83 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ83」、全98詩節からなります。アルジュナの要請によるクリシュナのカルナへの接近、およびカルナとアルジュナの激しい戦いの場面（第1〜98詩節）で本章は終わります。本章は詩節ごとの詳細な対訳が収録されており、第15詩節は日本語対訳では省略されています。
karṇaparva — tryaśītitamo'dhyāyaḥ (83)
第83章　アルジュナの要請によるクリシュナのカルナへの接近、シャルヤによるカルナの鼓舞、カルナのアルジュナ称賛と討伐の誓い、混戦
sañjaya uvāca|
hatvā tu phalgunaḥ senāṃ kauravāṇāṃ pṛthakpṛthak|
sūtaputrasya saṃrambhaṃ dṛṣṭvā caiva mahāraṇe||
// 8-83-1 //
サンジャヤは語った。
śoṇitodāṃ nadīṃ kṛtvā māṃsamajjāsthipaṅkilām|
manuṣyaśīrṣapāṣāṇāṃ hastyaśvakṛtarodhasam||
// 8-83-2 //
肉・骨髄・骨のぬかるみの、血を水とし、人の頭蓋骨を岩とし、象と馬で土手を作った河を——
śūrāsthittayasaṅkīrṇāṃ kākagṛdhrānunāditām|
chatrahaṃsapluvopetāṃ vīravṛkṣāpahāriṇīm||
// 8-83-3 //
勇者の骨が散乱し、カラスとハゲワシが鳴き叫ぶ、傘を白鳥とし勇者という木々を運ぶ——
hārapadmākaravatīmuṣṇīṣavaraphenilām|
dhanuḥśaradhvajopetāṃ narakṣudrakapālinīm||
// 8-83-4 //
首飾りを蓮池とし、ターバンを美しい泡とし、弓・矢・旗を備え、人の小さな頭蓋骨が浮かぶ——
carmavarmabhramopetāṃ rathoḍupasamākulām|
jayaiṣiṇāṃ ca sutarāṃ bhīrūṇāṃ ca sudustarām||
// 8-83-5 //
楯・鎧の渦を持ち、戦車を舟とし、勝利を求める者には容易に渡れるが、臆病者にはまことに渡り難い——
nadīṃ prāvartayitvā ca bībhatsuḥ paravīrahā|
vāsudevamidaṃ vākyamabravītpuruṣarṣabhaḥ||
// 8-83-6 //
そのような河を作り出した後、敵の勇者を殺すビーバツ（アルジュナ）、人中の雄牛はヴァースデーヴァ（クリシュナ）にこう言った。
arjuna uvāca|
eṣa ketū raṇe kṛṣṇa sūtaputrasya dṛśyate|
bhīmasenādayaścaite yodhayanti mahāratham||
// 8-83-7 //
アルジュナは語った。
ete dravanti pāñcālāḥ karmatrastā janārdana|
eṣa duryodhano rājā śvetacchatreṇa dhāryate||
// 8-83-8 //
「パーンチャーラ族がカルナに怯えて逃げているぞ、ジャナールダナよ。あれはドゥルヨーダナ王だ、白い傘に守られている。」
karṇena bhagnānpāñcālāndrāvayanbahu śobhate|
kṛpaś ca kṛtavarmā ca drauṇiś caiva mahārathaḥ||
// 8-83-9 //
「カルナに打ち破られたパーンチャーラ族を追い散らして、彼は大いに輝いている。クリパ、クリタヴァルマン、大戦車戦士ドローナの子も——」
ete rakṣanti rājānaṃ sūtaputreṇa rakṣitāḥ|
avadhyamānāste'smābhir yodhayiṣyanti somakān||
// 8-83-10 //
「スータの子に守られて彼らが王を守っている。我々に討たれることなく、ソーマカ族と戦い続けるだろう。」
eṣa śalyo rathopasthe raśmisaṅgrāhakovidaḥ|
sūtaputrarathaṃ kṛṣṇa vāhayanbahu śobhate||
// 8-83-11 //
「あれはシャルヤだ、戦車の台座で手綱さばきに長けた者として、スータの子の戦車を操り、大いに輝いている、クリシュナよ。」
tatra me buddhirutpannā vāhayātra rathaṃ mama|
nāhatvā samare karṇaṃ nivartiṣye kathañcana||
// 8-83-12 //
「そこで私は決意した。我が戦車をあそこへ走らせてくれ。戦場でカルナを殺さずして、決して引き返すまい。」
mā sma karṇo raṇe pārthānsṛñjayāṃś ca mahārathān|
niḥśeṣānsamare kuryātpaśyatāṃ no janārdana||
// 8-83-13 //
「ジャナールダナよ、カルナが戦場でパーンダヴァたちとスリンジャヤの大戦車戦士たちを、我らが見ている前で殲滅させてはならぬ。」
sañjaya uvāca|
tataḥ prāyājjavenāśu keśavastava vāhinīm|
karṇaṃ prati maheṣvāsaṃ dvairathe savyasācinaḥ||
// 8-83-14 //
サンジャヤは語った。
rathaghoṣastatastasya pāṇḍavasya babhūva ha|
vāsavāstranipātena parvateṣviva māriṣa||
// 8-83-16 //
そのパーンダヴァの戦車の轟音は、ヴァーサヴァ（インドラ）の武器が山々に落ちた時のようであった。
mahatā rathaghoṣeṇa pāṇḍavaḥ satyavikramaḥ|
abhyayādaprameyātmā nirjayaṃstava vāhinīm||
// 8-83-17 //
大いなる戦車の轟音を響かせながら、真の武勇を持つパーンダヴァ（アルジュナ）は、計り知れない魂を持ち、汝の軍を打ち破りながら進んだ。
tamāyāntaṃ samīkṣyaiva śvetāśvaṃ kṛṣṇasārathim|
madrarājo'bravītkarṇaṃ ketuṃ dṛṣṭvā mahātmanaḥ||
// 8-83-18 //
白い馬に引かれクリシュナを御者とする彼が近づいてくるのを見て、マドラ国王（シャルヤ）は、偉大な者の旗を見てカルナに言った。
ayaṃ sa ratha āyāti śvetāśvaḥ kṛṣṇasārathiḥ|
nighnannamitrānsamare yaṃ karṇa paripṛcchasi||
// 8-83-19 //
「白い馬に引かれクリシュナを御者とするこの戦車がやって来る。カルナよ、お前が探し求めている者だ、戦場で敵を殺しながら。」
eṣa tiṣṭhati kaunteyaḥ saṃspṛśangāṇḍivaṃ dhanuḥ|
taṃ haniṣyasi cedadya tannaḥ śreyo bhaviṣyati||
// 8-83-20 //
「カウンテーヤ（アルジュナ）がガーンディーヴァの弓に手をかけて立っている。もし今日彼を殺すことができれば、それは我々にとって幸いとなるだろう。」
dhanurjyā candratārāṅkā patākākiṅkiṇīyutā|
paśya karṇārjunasyaiṣā saudāmanyambare yathā||
// 8-83-21 //
「カルナよ、見よ、アルジュナの弓弦は月と星で飾られ、旗と鈴をつけ、空の稲妻のように輝いている。」
eṣa dhvajāgre pārthasya prekṣamāṇaḥ samantataḥ|
dṛśyate vānaro bhīmo vīkṣatāṃ bhayavardhanaḥ||
// 8-83-22 //
「見よ、アルジュナの旗の先端に、四方を見渡す恐ろしい猿が見え、恐怖を増している。」
etaccakraṃ gadā śaṅkhaḥ śārṅgaṃ kṛṣṇasya ca prabho|
dṛśyate pāṇḍavarathe vāhayānasya vājinaḥ||
// 8-83-23 //
「クリシュナの円盤・棍棒・法螺貝・シャールンガ弓が、馬を操るパーンダヴァの戦車に見える。」
etatkūjati gāṇḍīvaṃ visṛṣṭaṃ savyasācinā|
ete hastavatā muktā ghnantyamitrāñśitāḥ śarāḥ||
// 8-83-24 //
「これがサヴャサーチン（アルジュナ）の放つガーンディーヴァの鳴り響く音だ。手から放たれた鋭い矢が敵を殺している。」
viśālāyatatāmrākṣaiḥ pūrṇacandranibhānanaiḥ|
eṣā bhūḥ kīryate rājñāṃ śirobhir apalāyinām||
// 8-83-25 //
「大きく広く赤銅色の目を持ち、満月のような顔をした、退かぬ王たちの首で大地が覆われている。」
ete parighasaṅkāśāḥ puṇyagandhānulepanāḥ|
uddhatā raṇaśūrāṇāṃ pātyante sāyudhā bhujāḥ||
// 8-83-26 //
「腕輪のような太さの、聖なる香油を塗った、戦場の勇者たちの武器を持った腕が切り落とされている。」
nirastajihvā netrāntā vājinaḥ saha sādibhiḥ|
patitāḥ pātyamānāś ca kṣitau kṣīṇā viśerate||
// 8-83-27 //
「舌を出し目を見開いた馬たちが、騎手と共に倒れ、倒されつつ、力尽きて大地に横たわっている。」
ete parvataśṛṅgāṇāṃ tulyā haimavatā gajāḥ|
sañchinnakumbhāḥ pārthena prapatantyadrayo yathā||
// 8-83-28 //
「これらの山の峰に等しいヒマラヤの象たちが、アルジュナに頭頂を砕かれ、山のように崩れ落ちている。」
gandharvanagarākārā rathā hatanareśvarāḥ|
vimānādiva puṇyānte svargiṇo nipatantyamī||
// 8-83-29 //
「ガンダルヴァの幻の都のような、主を失った戦車が、功徳が尽きた時に天から落ちる天人のように、空中から落ちている。」
vyākulīkṛtamatyarthaṃ paśya sainyaṃ kirīṭinā|
nānāmṛgasahasrāṇāṃ yūthaṃ kesariṇā yathā||
// 8-83-30 //
「見よ、冠を戴く者（アルジュナ）によって軍が激しく混乱させられている。様々な鹿の群れが獅子によって混乱させられるように。」
tvāmabhiprepsurāyāti karṇa nighnanvarānrathān|
asajjamāno rādheya taṃ yāhi prati bhārata||
// 8-83-31 //
「カルナよ、彼は最上の戦車戦士たちを殺しながらお前のもとに向かっている。ラーデーヤよ、躊躇せず彼に向かって進め、バーラタよ。」
eṣā vidīryate senā dhārtarāṣṭrī samantataḥ|
arjunasya bhayāttūrṇaṃ nighnataḥ śātravānbahūn||
// 8-83-32 //
「ドリタラーシュトラの軍は四方から崩壊している。敵を多く殺すアルジュナへの恐怖から、素早く。」
varjayansarvasainyāni tvarate hi dhanañjayaḥ|
tvadarthamiti manye'haṃ yathāsyodīryate vapuḥ||
// 8-83-33 //
「ダナンジャヤ（アルジュナ）は全ての軍を避けて急いでいる。彼の姿が燃え上がるのを見ると、お前のためだと私は思う。」
na hyavasthāsyate pārtho yuyutsuḥ kenacitsaha|
tvāmṛte krodhadīpto hi pīḍyamāne vṛkodare||
// 8-83-34 //
「ヴリコーダラ（ビーマ）が苦しめられている中、怒りに燃えるアルジュナは、お前以外の誰とも戦わないだろう。」
virathaṃ dharmarājaṃ tu dṛṣṭvā sudṛḍhavikṣatam|
śikhaṇḍinaṃ sātyakiṃ ca dhṛṣṭadyumnaṃ ca pārṣatam||
draupadeyānyudhāmanyumuttamaujasameva ca|
nakulaṃ sahadevaṃ ca vaśagāṃste samīkṣya tu||
// 8-83-35-36 //
「法王（ユディシュティラ）が戦車を失い深く傷ついたのを見て、シカンディン、サーティヤキ、パールシャタ・ドリシュタデュムナ、ドラウパディーの息子たち、ユダーマンユ、ウッタマウジャス、ナクラ、サハデーヴァが征服されたのを見て——」
sahasaikarathaḥ pārthastvāmabhyeti parantapaḥ|
krodharaktekṣaṇaḥ kruddho jighāṃsuḥ sarvapārthivān||
// 8-83-37 //
「一騎のアルジュナが、敵を滅ぼす者として、怒りに赤い目をして、全ての王を殺さんと向かってくる。」
tvarito'bhipatatyasmāṃstyaktvā sainyānyasaṃśayam|
tvaṃ karṇa pratiyāhyenaṃ nāstyanyo hi dhanurdharaḥ||
// 8-83-38 //
「急いで我らに向かってくる、軍を置き去りにして疑いなく。カルナよ、お前が彼に立ち向かえ。他に弓持ちはいない。」
na taṃ paśyāmi loke'smiṃstvatto hyanyaṃ dhanurdharam|
arjunaṃ samare kruddhaṃ yo velāmiva vārayet||
// 8-83-39 //
「この世で、お前以外に、怒れるアルジュナを岸が海を堰き止めるように阻止できる弓持ちは、私には見当たらない。」
na cāsya rakṣāṃ paśyāmi pārśvato na ca pṛṣṭhataḥ|
eka evābhiyāti tvāṃ paśya sāphalyamātmanaḥ||
// 8-83-40 //
「彼の横にも後ろにも護衛は見えない。一人でお前に向かってくる。己の成功を見よ。」
tvaṃ hi kṛṣṇau raṇe śakto yoddhumetau parantapau|
tavaiva bhāro rādheya pratyudyāhi dhanañjayam||
// 8-83-41 //
「お前こそ二人のクリシュナ（アルジュナとクリシュナ）と戦場で戦うことができる敵を滅ぼす者。ラーデーヤよ、お前の重荷だ。ダナンジャヤに向かって進め。」
samāno hyasi bhīṣmeṇa dromadrauṇikṛpeṇa ca|
savyasācinamāyāntaṃ nivāraya mahāraṇe||
// 8-83-42 //
「お前はビーシュマ、ドローナ、ドローナの子、クリパと同等である。大いなる戦場で、やって来るサヴャサーチン（アルジュナ）を阻止せよ。」
lelihānaṃ yathā sarpaṃ garjantamṛṣabhaṃ yathā|
vanasthitaṃ yathā vyāghraṃ jahi karṇa dhanañjayam||
// 8-83-43 //
「舌なめずりする蛇のように、吼える雄牛のように、森に潜む虎のように、カルナよ、ダナンジャヤ（アルジュナ）を殺せ。」
ete dravanti samarānnirapekṣā narādhipāḥ|
arjunasya bhayatrastā dhārtarāṣṭrā mahābalāḥ||
// 8-83-44 //
「見よ、王たちが戦場から逃げている、顧みることなく。アルジュナへの恐怖に怯えた大力のドリタラーシュトラの息子たちが。」
dravatāmatha teṣāṃ tu nānyo'sti yudhi mānavaḥ|
bhayahā yo bhavedvīrastvāmṛte sūtanandana||
// 8-83-45 //
「彼らが逃げる中で、スータの子よ、お前以外に恐怖を除く勇者はいない。」
ete tvāṃ kuravaḥ sarve dvīpamāsādya saṃyuge|
dhiṣṭhitāḥ puruṣavyāghra tvattaḥ śaraṇakāṅkṣiṇaḥ||
// 8-83-46 //
「人中の虎よ、これらのクル族の者たちは全て、戦場でお前という島に辿り着き、お前の庇護を求めて立っている。」
vaidehāmbaṣṭhakāmbhojāstathā nagnajitastvayā|
gāndhārāś ca yayā dhṛtyā jitāḥ saṅkhye sudurjayāḥ|
tāṃ dhṛtiṃ kururādheya tataḥ pratyehi pāṇḍavam||
// 8-83-47 //
「ヴァイデーハ族・アムバシュタ族・カムボージャ族・ナグナジット、ガーンダーラ族をお前が戦いで征服した不屈の勇気で、ラーデーヤよ、その勇気をもってパーンダヴァに立ち向かえ。」
vāsudevaṃ ca vārṣṇeyaṃ prīyamāṇaṃ kirīṭinā|
pratyudyāhi mahābāho pauruṣe mahati sthitaḥ||
// 8-83-48 //
「大いなる腕を持つ者よ、冠を戴く者（アルジュナ）を喜ばせるヴァールシュネーヤ・ヴァースデーヴァ（クリシュナ）に対して、大いなる勇気をもって立ち向かえ。」
karṇa uvāca|
prakṛtistho'si me śalya idānīṃ sammatastathā|
pratibhāsi mahābāho abhītaś ca dhanañjayāt||
// 8-83-49 //
カルナは語った。
paśya bāhvorbalaṃ me'dya śikṣitasya ca paśya me|
eko'dya nihaniṣyāmi pāṇḍavānāṃ mahācamūm||
// 8-83-50 //
「今日、我が両腕の力を見よ。訓練された私を見よ。今日、私一人でパーンダヴァの大軍を殺してやる。」
kṛṣṇau ca puruṣavyāghra tataḥ satyaṃ bravīmi te|
nāhatvā yudhi tau vīrau vyapayāsye kathañcana||
// 8-83-51 //
「そして二人のクリシュナ（アルジュナとクリシュナ）も、人中の虎よ。お前に真実を言おう。戦場であの二人の勇者を殺さずして、決して退くまい。」
śiśye vā nihatastābhyāmanityo hi raṇe jayaḥ|
kṛtārtho'dya bhaviṣyāmi hatvā vāpyatha vā hataḥ||
// 8-83-52 //
「あるいは彼らに殺されて横たわるか。戦場での勝利は定まらぬもの。殺すにせよ殺されるにせよ、今日私は目的を達成するだろう。」
śalya uvāca|
ajayyamenaṃ pravadanti yuddhe mahārathāḥ karṇa rathapravīram|
ekākina kimu kṛṣṇābhiguptaṃ vijetumenaṃ ka ihotsaheta||
// 8-83-53 //
シャルヤは語った。
karṇa uvāca|
naitādṛśo jātu babhūva loke rathottamo yāvadupaśrutaṃ naḥ|
tamīdṛśaṃ pratiyotsyāmi pārthaṃ mahāhave paśya ca pauruṣaṃ me ||
// 8-83-54 //
カルナは語った。
raṇe caratyeṣa rathapravīraḥ sitairhayaiḥ kauravarājaputraḥ|
sa vā'dya māṃ neṣyati kṛcchram etat karṇo'syānte'pyatra bhavetsamarthaḥ||
// 8-83-55 //
「このカウラヴァの王子、白い馬に引かれた戦車の勇者が戦場を駆け巡っている。彼が今日私を窮地に追い込むか、あるいはカルナが最後にはこれに打ち勝つか。」
asvedinau rājaputrasya hastāv avepamānau jātakiṇau bṛhantau|
dṛḍhāyudhaḥ kṛtimānkṣiprahasto na pāṇḍaveyena samo'sti yodhaḥ||
// 8-83-56 //
「王子の手は汗をかかず、震えず、胼胝（たこ）があり、大きい。堅固な武器を持ち、熟練し、素早い手を持つ——パーンダヴァに匹敵する戦士はいない。」
gṛhṇātyanekānapi kaṅkapatrān ekaṃ yathā tānpratiyojya cāśu|
te krośamātre nipatantyamodhāḥ kastena yodho'sti samaḥ pṛthivyām||
// 8-83-57 //
「彼は多くのサギの羽根の矢を掴み、一本ずつ素早く放つ。それらは一クローシャ（約3km）先に外れることなく落ちる。この地上に彼と等しい戦士がいるだろうか。」
atoṣayatsvāṇḍave yo hutāśaṃ kṛṣṇadvitīyo'tirathastarasvī|
lebhe cakraṃ yatra kṛṣṇo mahātmā dhanurgāṇḍīvaṃ pāṇḍavaḥ savyasācī||
// 8-83-58 //
「クリシュナと二人で、優れた戦車戦士として俊敏に、カーンダヴァの森でアグニ（火神）を満足させた者。そこでクリシュナは円盤を得、パーンダヴァのサヴャサーチンはガーンディーヴァの弓を得た。」
śvetāśvayuktaṃ ca sughoṣamugraṃ rathaṃ mahābāhuradīnasatvaḥ|
maheṣudhī cākṣaye divyarūpe śastrāṇi divyāni ca havyavāhāt||
// 8-83-59 //
「白い馬に繋がれた恐ろしいスゴーシャという戦車と、不屈の精神の大いなる腕の者は、二つの尽きることのない神聖な矢筒と、火神から神聖な武器を得た。」
yastvindraloke nijaghāna daityān asaṅkhyeyānkālakeyāṃś ca sarvān|
lebhe śaṅkhaṃ devadattaṃ sma tatra ko nāma tenābhyadhikaḥ pṛthivyām||
// 8-83-60 //
「インドラの世界でダイティヤたちと数え切れないカーラケーヤ族を殺し、そこで天から授かったデーヴァダッタという法螺貝を得た——この地上に彼より優れた者があろうか。」
mahādevaṃ toṣayāmāsa yo'straiḥ sākṣātsuyuddhena mahānubhāvaḥ|
lebhe tataḥ pāśupataṃ sughoraṃ trailokyasaṃhārakaraṃ mahāstram||
// 8-83-61 //
「マハーデーヴァ（シヴァ神）を、武器による真の戦いで満足させた偉大な者は、そこから三界を滅ぼす恐ろしいパーシュパタという大いなる武器を得た。」
pṛthakpṛthaglokapālāḥ sametā dadurmahāstrāṇyaprameyāṇi saṅkhye|
yaistāñjaghānāśu raṇe nṛsiṃhaḥ sakālakeyānasurānsametān||
// 8-83-62 //
「世界の守護神たちが一堂に会し、戦場で計り知れない大いなる武器を授けた。人中の獅子たるアルジュナは、それらの武器でカーラケーヤ族とアスラの連合軍を素早く戦場で殺した。」
tathā virāṭasya pure sametān sarvānasmānekarathena jitvā|
jahāra tadrodhanamājimadhye vastrāṇi cādatta mahārathebhyaḥ||
// 8-83-63 //
「同様に、ヴィラータの都で、我々全員を一台の戦車で打ち負かし、戦場で牛の群れを奪い返し、大戦車戦士たちの衣服をも奪った。」
tamīdṛśaṃ vīryaguṇopapannaṃ kṛṣṇadvitīyaṃ paramaṃ nṛpāṇām|
tamāhvayansāhasamuttamaṃ vai jāne svayaṃ sarvalokasya śalya||
// 8-83-64 //
「このように武勇と能力を備え、クリシュナを二人目とする王の中の最上の者——そのような者に挑戦するのは大胆なことだと、シャルヤよ、私自身よく知っている、全世界の中で。」
anantavīryeṇa ca keśavena nārāyaṇenāpratimena guptaḥ|
varṣāyutairyasya guṇā na śakyā vaktuṃ sametairapi sarvalokaiḥ||
// 8-83-65 //
「無限の力を持つケーシャヴァ、比類なきナーラーヤナに守られた者——彼の能力は、全世界が集まっても何万年かけても語り尽くせない。」
mahātmanaḥ śaṅkhacakrāsipāṇer viṣṇorjiṣṇorvasudevātmajasya|
bhayaṃ na me jāyate sādhvasaṃ ca dṛṣṭvā kṛṣṇāvekarathe sametau||
// 8-83-66 //
「法螺貝・円盤・剣を手に持つヴィシュヌ、勝利者、ヴァスデーヴァの子の偉大な者——同じ戦車に乗った二人のクリシュナを見ても、私には恐れも怯えもない。」
atīvāyaṃ dhanuṣi rājaputreṣv atīvānyānkeśavaścakrayuddhe|
evaṃvidhau pāṇḍavavāsudevau caletsvadeśādvimavānna kṛṣṇau||
// 8-83-67 //
「王子たちの弓においてこの者は極めて優れ、ケーシャヴァは円盤戦において極めて優れている。このようなパーンダヴァとヴァースデーヴァ——ヒマヴァット山ですら動くとも、二人のクリシュナは動くまい。」
ubhau hi śūrau balinau dṛḍhāyudhau mahārathau saṃhananopapannau|
etau vīrau naravīrau sametau sthānāccyutau devakumārarūpau||
// 8-83-68 //
「二人とも勇敢で力強く、堅固な武器を持ち、大戦車戦士で、しっかりとした体格を持つ。この二人の勇者、人中の勇者が合流した——神の御子のような姿の。」
agryādityāvindravṛhaspatī vā yamāntakau vā śatripūṣaṇau vā|
bhagāṃśamitrāvaruṇāvaśvinau vā marudgaṇau vā vasavaḥ sametāḥ|
vyastāḥ samastāś ca yudhā na śaktā jetuṃ prasahyārjunaṃ cācyutaṃ ca||
// 8-83-69 //
「アグニとアーディティヤ、インドラとブリハスパティ、ヤマとアンタカ、シャチとプーシャン、バガとアンシュ、ミトラとヴァルナ、アシュヴィン双神、マルト神群、ヴァス神群が集まっても——離れていようと一緒であろうと、戦いでアルジュナとアチュタ（クリシュナ）を力ずくで倒すことはできない。」
etau hi tāvarjunavāsudevau ko'nyaḥ pratīyānmadṛte tu śalya||
// 8-83-70 //
「アルジュナとヴァースデーヴァ、この二人——シャルヤよ、私以外に誰が立ち向かえようか。」
sarveṣāṃ vṛṣṇivīrāṇāṃ kṛṣṇe lakṣmīḥ pratiṣṭhitā|
sarveṣāṃ pāṇḍuputrāṇāṃ jayaḥ pārthe pratiṣṭhitaḥ||
// 8-83-71 //
「全てのヴリシュニの勇者たちの幸運はクリシュナに宿り、全てのパーンドゥの息子たちの勝利はアルジュナに宿っている。」
tāvubhau puruṣavyāghrau samāne syandane sthitau|
māmekamabhiyoddhārau sujātaṃ bata śalya me||
// 8-83-72 //
「その二人の人中の虎が同じ戦車に乗って、私一人と戦おうとしている。シャルヤよ、我が誕生はまことに幸いであった。」
naitacciraṃ kṣipramimaṃ rathaṃ me pravartayaitāvabhiyāmi caivam|
asminmuhūrte nihatau paśya kṛṣṇau tābhyāṃ hataṃ vā yudhi māṃ ripubhyām||
// 8-83-73 //
「直ちに我が戦車を進めよ。彼らに向かって行こう。今この瞬間に二人のクリシュナが殺されるのを見よ——あるいは戦場で二人の敵に殺された私を。」
evaṃ bruvāṇaḥ sahasā mahārathas tvabhyadravatpāṇḍavaṃ sūtaputraḥ||
// 8-83-74 //
こう言いながら、大戦車戦士たるスータの子は、猛然とパーンダヴァに向かって突進した。
abhyetya putreṇa tavābhinanditāḥ sametya coktāḥ kuruvīrasattamāḥ|
kṛpaś ca bhojaś ca mahārathāvubhau tathaiva gāndhārapatiḥ sahānujaḥ|
guroḥ sutastasya tavātmajāstathā padātisaṅghā dviradāstathā tadā||
// 8-83-75 //
汝の息子に歓迎され、クルの勇者の最上の者たちに集められ——大戦車戦士の二人、クリパとボージャ（クリタヴァルマン）、ガーンダーラ王とその弟、師の子（アシュヴァッターマン）、汝の息子たち、そして歩兵・象の群れが——
nirudhyatābhidravatācyutārjunau śrameṇa saṃyojayatāśu sarvaśaḥ|
yathā bhavadbhir bhṛśavikṣatāvubhau sukhena hanyānmama vāhinīpatiḥ||
// 8-83-76 //
「アチュタ（クリシュナ）とアルジュナを阻止せよ、攻撃せよ、全方面から疲弊させよ。お前たちに深く傷つけられた二人を、我が軍の総帥が容易に殺せるように。」と命じられた。
tatheti coktvā tvaritāḥ sma te'rjunaṃ jighāṃsavo vīratarāḥ samāyayuḥ|
śaraiś ca jaghnuryudhi taṃ mahārathā dhanañjayaṃ karṇanideśakāriṇaḥ|
nadīnadaṃ bhūrijalo mahārṇavo yathā tathā tānsamare'rjuno'grasat||
// 8-83-77 //
「承知」と言い、急いで勇猛な者たちはアルジュナを殺さんとして集まった。大戦車戦士たちは、カルナの命に従い、矢で戦場のダナンジャヤ（アルジュナ）を射た。しかし、河川が大海に飲み込まれるように、アルジュナはそれらを戦場で呑み込んだ。
na sandadhāno na tathā śarottamān pramuñcamāno ripubhiḥ pradṛśyate|
dhanañjayāstaiḥ sma śarairvidāritā hatā nipeturnaravājikuñjarāḥ||
// 8-83-78 //
矢をつがえるのも、最上の矢を放つのも、敵には見えないほどであった。ダナンジャヤの矢に引き裂かれ、殺されて、人・馬・象が倒れた。
śarārciṣaṃ gāṇḍivacārumaṇḍalaṃ yugāntasūryapratimānatejasam|
na kauravāḥ śekurudīkṣituṃ jayaṃ yathā raviṃ vyādhitacakṣuṣo janāḥ||
// 8-83-79 //
矢の輝きを炎とし、ガーンディーヴァを美しい円輪とし、ユガの終わりの太陽に匹敵する光を放つアルジュナを、カウラヴァたちは見つめることさえできなかった。目を病む者が太陽を見られないように。
śarottamānsamprahitānmahārathai ściccheda pārthaḥ prahasañcharaudhaiḥ|
bhūyaś ca tānahanadbāṇasaṅghān gāṇḍīvadhanvāyatapūrṇamaṇḍalam||
// 8-83-80 //
大戦車戦士たちが放った最上の矢を、アルジュナは笑いながら矢の群れで切り落とし、さらにガーンディーヴァの弓を十分に引き絞って矢の群れで彼らを射った。
yathograraśmiḥ śuciśukramadhyagaḥ sukhaṃ vivasvānharate jalaughān|
tathārjuno bāṇagaṇānnirasya dadāha senāṃ tava pārthivendra||
// 8-83-81 //
清浄な白い月の間にある太陽が容易に水の流れを奪い去るように、アルジュナは矢の群れを払い除け、汝の軍を焼き尽くした、王の中の王よ。
tamabhyadhāvadvisṛjankṛpaḥ śarāṃs tathaiva bhojastava cātmajaḥ svayam|
mahāratho droṇasutaś ca sāyakair avākiraṃstoyadharā yathā'calam||
// 8-83-82 //
クリパは矢を放ちながら彼に向かい、ボージャ（クリタヴァルマン）も、汝自身の息子も同様に。大戦車戦士ドローナの子も矢で、雲が山に雨を降らせるように、彼に矢を浴びせた。
jighāṃsubhis tānkuśalaiḥ śarottamān mahātmabhiḥ samprahitānprayatnataḥ|
śaraiḥ praticcheda sa pāṇḍavastvaran parānvinirbhidya ca tāṃstribhis tribhiḥ||
// 8-83-83 //
殺さんとする偉大な者たちが全力で放った最上の矢を、急いでパーンダヴァは矢で迎え撃ち、三本ずつで彼らを貫いた。
sa gāṇḍivavyāyatapūrṇamaṇḍalas tapanripūnarjunabhāskaro vabhau|
śarograśmiḥ śuciśukramadhyago yathaiva sūryaḥ pariveyavāṃstathā||
// 8-83-84 //
ガーンディーヴァを十分に引き絞った円輪で敵を焼くアルジュナ太陽は輝いた。矢の鋭い光線を持ち、暈をまとった太陽のように。
athāgryabāṇairdaśabhir dhanañjayaṃ parābhinaddoṇasuto'cyutaṃ tribhiḥ|
caturbhir aśvāṃścaturaḥ kapiṃ tataḥ śaraiś ca nārācavarairavākirat||
// 8-83-85 //
ドローナの子は最上の十本の矢でダナンジャヤを貫き、三本でアチュタ（クリシュナ）を射、四本で四頭の馬を、そして矢と鉄矢で猿の旗を射た。
tathā tataḥ prasphuradasya kārmukaṃ tribhiḥ śarairyantṛśiraścakarta ha|
hayāṃścaturbhiś caturastribhir dhvajaṃ dhanañjayo drauṇirathādapātayat||
// 8-83-86 //
するとアルジュナは、三本の矢でドローナの子の弓を弾き飛ばし、三本で旗を、四本で四頭の馬を、三本で車軸旗を、ドローナの子の戦車から打ち落とした。
sa roṣapūrṇo hmativajrahāṭakair alaṅkṛtaṃ takṣakabhogavarcasam|
sa tadvadhe kārmukamanyadādade yathā mahāhipravaraṃ tathaiva ca||
// 8-83-87 //
怒りに満ちたドローナの子は、金剛石と黄金で飾られた、タクシャカ蛇のような輝きを持つ別の弓を取った。
svamāyudhaṃ cāpi vikīrya bhūtale dhanuś ca kṛtvā saguṇaṃ guṇādhikaḥ|
samānayaṃsaltāvajitau narottamau śarottamairdrauṇiravidhyadantikāt||
// 8-83-88 //
自分の武器を地上に撒き散らし、弦を張った弓を構えると、能力に優れたドローナの子は、征服されざる二人の人中の最上者を、間近から最上の矢で射た。
kṛpaś ca bhojaś ca tavātmajaś ca te śarairanekairyudhi pāṇḍavarṣabham|
mahārathāḥ saṃyugamūrdhani sthitās tamonudaṃ vāridharā ivāpatan||
// 8-83-89 //
クリパ、ボージャ、汝の息子も、多くの矢で戦場の先頭に立つパーンダヴァの雄牛を、大戦車戦士たちとして、闇を払う太陽に雨雲が降り注ぐように攻撃した。
kṛpasya pārthaḥ śaraṃ śarāsanaṃ hayāndhvajānsāradhimeva patribhiḥ|
samārpayadvāhusahasravikramas tathā yathā vajradharaḥ purā baleḥ||
sa pārthabāṇairvinipātitāyudho dhvajāvamarde ca kṛte mahāhave|
kṛtaḥ kṛpo bāṇasahasrayanito yathāpageyaḥ prathamaṃ kirīṭinā||
// 8-83-90-91 //
アルジュナはクリパの矢・弓・馬・旗・御者をも矢で撃ち落とした。千の腕の力を持つ者として、かつてインドラがバリを倒したように。アルジュナは矢の千で阻止し、かつてビーシュマに対してしたように。
śaraiḥ praciccheda tavātmajasya dhvajaṃ dhanuś ca pracakarta nardataḥ|
jaghāna cāśvānkṛtavarmaṇaḥ śubhān dhvajaṃ ca ciccheda tavātmajasya ha||
// 8-83-92 //
アルジュナは旗と弓を切り、汝の息子の馬を殺し、クリタヴァルマンの美しい馬と旗をも切り落とし、汝の息子の旗を切った。
savājisūteṣvasanānsaketanān jayāna nāgāśvarathāṃś ca sa tvaran|
tataḥ prakīrṇaṃ sumahadvalaṃ tava prapīḍitaṃ saviturivaujasā bhṛśam||
// 8-83-93 //
馬・御者・弓・旗を持つ者たちを征服し、象・馬・戦車を殺し、汝の大軍は散り散りにされ、太陽の力に激しく押し潰されたかのようであった。
tato'rjunasvāśu rathena keśavaś cakāra śatrūnapasavyamāturān|
tataḥ prayātaṃ tvaritaṃ dhanañjayaṃ śatakratuṃ vṛtranijaghruṣaṃ yathā|
samanvadhāvanpunarutthitairdhvajai rathaiḥ suyuktairapare yuyutsavaḥ||
// 8-83-94 //
そしてケーシャヴァ（クリシュナ）は素早くアルジュナの戦車で敵を左回りに回して苦しめた。素早く進むダナンジャヤを、ヴリトラを殺さんとするインドラのように——旗を立て直し馬を繋ぎ直した戦車に乗った戦わんとする他の者たちが追い駆けた。
athābhisṛtya prativārya cāhitān dhanañjayasyānucarānmahārathāḥ|
śikhaṇḍiśaineyayamāḥ śitaiḥ śarair vidārayanto vyanadansubhairavam||
// 8-83-95 //
そして駆けつけて敵を押しとどめ、ダナンジャヤの従者である大戦車戦士たち——シカンディン、サーティヤキの一族、ヤマの双子——が鋭い矢で引き裂き、恐ろしく叫んだ。
tato'bhijaghnuḥ kupitāḥ parasparaṃ śaraistadāñcogatibhiḥ sutejanaiḥ|
kurupravīrāḥ saha pṛñjayairyathā surārayo devapatiṃ yathā tathā||
// 8-83-96 //
そして怒れる者たちは互いを、素早く鋭い矢で射合った。クルの勇者たちとプリンジャヤ族が、アスラたちが天帝インドラに向かうように。
jayepsavaḥ svargamanāya cotsukāḥ patanti nāgāśvarathāḥ parantapa|
tathaiva sarve bahavaś ca vivyadhuḥ śaraiḥ sumuktairitaretaraṃ pṛthak||
// 8-83-97 //
勝利を望み、天への旅立ちにも意気込み、象・馬・戦車が倒れ、全ての者が互いを様々に放たれた矢で射合った。
śarāndhakāre tu mahātmabhiḥ kṛte mahāmṛdhe yodhavaraiḥ parasparam|
caturdiśo vai vidiśaś ca pārthiva prabhā ca sūryasya tamovṛtā'bhavat||
// 8-83-98 //
偉大な者たちが互いに作り出した矢の暗闘の中、大いなる戦いにおいて、四方と中間の方角、太陽の光さえも闇に覆われた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe tryaśītitamo'dhyāyaḥ|| 83 ||
