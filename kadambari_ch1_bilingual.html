◆ 帰敬偈
rajojuṣe janmani sattva-vṛttaye
sthitau prajānāṃ pralaye tamaḥ-spṛśe /
ajāya sarga-sthiti-nāśa-hetave
trayī-mayāya tri-guṇātmane namaḥ // 1 //
万物の誕生においてはラジャス（動性）を帯び、存続においてはサットヴァ（善性）をもって営み、滅びにおいてはタマス（暗性）に触れる者――生まれなき者、創造・維持・破壊の因たる者、三ヴェーダよりなり三グナを本性とする者に帰命す。【1】
jayanti bāṇāsura-mauli-lālita-
daśāsya-cūḍāmaṇi-cakra-cumbinaḥ /
surāsurādhīśa-śikhānta-śāyino
bhavac-chidas tryambaka-pāda-pāṃsavaḥ // 2 //
バーナースラ（バーナ魔王）の頭冠を愛撫し、ダシャーナン（ラーヴァナ）の頂上宝珠の輪に触れ、神々と阿修羅の王たちの頭頂に安らう――存在の苦を断つ三眼神（シヴァ）の御足の塵は勝利する。【2】

◆ 詩人讃嘆・文学讃嘆
jayaty upendraḥ sa cakāra dūrato
vibhitsayā yaḥ kṣaṇa-labdha-lakṣyayā /
dṛśaiva kopāruṇayā ripur uraḥ
svayaṃ bhayād bhinnam ivāsa-pāṭalam // 3 //
かのウペンドラ（ヴィシュヌ）は勝利する。彼は遠方より、瞬時に的を得る破壊意志をもって、怒りに赤く染まった眼差しのみによって、敵の胸を――恐怖ゆえに自ら裂けたかのごとく赤く――なしたのである。【3】
namāmi bhartuś caraṇāmbuja-dvayaṃ
sa-śikhaira-maukharibhiḥ kṛtārcanam /
samasta-sāmanta-kirīṭa-vedikā-
luṭhitāruṇāṅguli // 4 //
わが主君の二つの蓮華の御足を礼拝す。マウカリ族の一族郎党が供養を捧げ、あらゆる封臣たちの冠の台座の上を転がる紅の御指を持つその御足を。【4】
akāraṇāviṣkṛta-vaira-dāruṇād
asajjanāt tasya bhayaṃ na jāyate /
viṣaṃ mahāher iva yasya durvacaḥ
su-duḥsahaṃ saṃnihitaṃ sadā mukhe // 5 //
理由もなく敵意をあらわにする残忍な悪人に対しても、彼には恐れが生じない。大蛇の毒のごとく、耐えがたき悪言が常にその口に備わっていようとも。【5】
kaṭu kaṇanto maladāyakāḥ khalās
tudanty alaṃ bandhana-śṛṅkhalā iva /
manas tu sādhu-dhvanibhiḥ pade pade
haranti santo maṇi-nūpurā iva // 6 //
悪人は、縛鎖のごとく耳障りな音を立てて汚れを与え、はなはだしく苦しめる。しかし善人は、宝珠の足飾りのごとく、一歩ごとに美しき響きをもって心を奪い去る。【6】
subhāṣitaṃ hāri viśaty adho galān
na durjanasyārka-ripor ivāmṛtam /
tad eva dhatte hṛdayena sajjano
harir mahā-ratnam ivāti-nirmalam // 7 //
美しき言葉は、悪人の喉より下には入らない――アルカ（ラーフ）にとっての甘露のように。しかしまさにそれを、善人は心に抱く――ハリ（ヴィシュヌ）がこの上なく清らかなる大宝珠（カウストゥバ）を胸に戴くがごとく。【7】
sphurat-kalālāpa-vilāsa-komalā
karoti rāgaṃ hṛdi kautukādhikam /
rasena śayyāṃ svayam abhyupāgatā
kathā janasyābhinavā vadhūr iva // 8 //
きらめく甘き語らいの戯れにしなやかな物語は、自ら情趣をもって褥（しとね）に寄り添い来たる新妻のごとく、人の心に好奇を超えた愛着を生じさせる。【8】
haranti kaṃ nojjvala-dīpakopamair
navaiḥ padārthair upapāditāḥ kathāḥ /
nirantara-śleṣa-ghanāḥ su-jātayo
mahā-srajaś campaka-kuḍmalair iva // 9 //
輝く灯明にも似た新鮮な詩句によって飾られた物語は、誰の心を奪わずにいようか。隙間なく二義ある語（シュレーシャ）が密に連なり、良き生まれの大花鬘がチャンパカの蕾で編まれたかのようである。【9】
◆ Bāṇa-vaṃśa-varṇanam
◆ バーナの家系の描写
babhūva vātsyāyana-vaṃśa-saṃbhavo
dvijo jagad-gīta-guṇo 'graṇīḥ satām /
aneka-guptārcita-pāda-paṅkajaḥ
kubera-nāmāṃśa iva svayambhuvaḥ // 10 //
ヴァーツヤーヤナの家系に生まれ、世にその徳を歌われ、善人の中の筆頭たる一人のバラモンがいた。多くの「グプタ」（守護者）たちに御足の蓮華を供養される者――あたかもスヴァヤンブー（ブラフマー）のクベーラ（財宝神）の名を持つ分身のごとく。【10】
uvāsa yasya śruti-śānta-kalpame
sadā puroḍāśa-pavitritādhare /
sarasvatī soma-kaṣāyitodare
samasta-śāstra-smṛti-bandhure mukhe // 11 //
シュルティ（天啓聖典）の寂静なるカルパ樹のごとく、常にプローダーシャ（祭式の供物）によって清められた唇を持ち、ソーマ液に染められた腹を持ち、あらゆる学問と法典にいろどられた――その口にサラスヴァティー（弁才天）は住まった。【11】
jagur gṛhe 'bhyasta-samasta-vāṅmayaiḥ
sa-sārikaiḥ pañjara-vartibhiḥ śukaiḥ /
nigṛhyamāṇā vaṭavaḥ pade pade
yajūṃṣi sāmāni ca yasya śaṅkitāḥ // 12 //
彼の家では、あらゆる文学を習い覚えた籠の中の鸚鵡やサーリカー鳥たちがヤジュル・ヴェーダやサーマ・ヴェーダを詠唱していた。学童（ヴァタヴァ）たちは一歩ごとにそれに制止され、おそれおののきながら〔自らも〕唱えた。【12】
hiraṇyagarbho bhuvanāṇḍakād iva
kṣapākaraḥ kṣīra-mahārṇavād iva /
abhūt suparṇo vinatodарād iva
dvijanmanām artha-patiḥ patis tataḥ // 13 //
ヒラニヤガルバ（ブラフマー）が宇宙卵から生まれたかのごとく、月が乳海から生まれたかのごとく、スパルナ（ガルダ）がヴィナターの胎から生まれたかのごとく、その家系からバラモンたちの財宝の主（＝もう一人のクベーラ）たる主が生まれた。【13】
vivṛṇvato yasya visāri vāṅmayaṃ
dine dine śiṣya-gaṇā navā navāḥ /
upaḥsu lagnāḥ śravaṇe 'dhikāṃ śriyaṃ
pracakrire candana-pallavā iva // 14 //
広がりゆく学問を講説する彼のもとに、日ごとに新たな弟子の群れが加わった。朝の礼拝時に耳に付き従い、ますます美しさを増していった――チャンダナ（白檀）の新芽のように。【14】
vidhāna-saṃpādita-dāna-śobhitaiḥ
sphuran-mahā-vīra-sanātha-mūrtibhiḥ /
makhair asaṃkhyair ajayat surālayaṃ
sukhena yo yūpa-karair ajair iva // 15 //
規定通りの布施によって荘厳され、輝く大勇士に護持される形姿を持つ無数の祭祀によって、彼は天界をやすやすと征服した――祭柱を手にした山羊たち（＝不生なる者たち）のごとく。【15】
sa citrabhānuṃ tanayaṃ mahātmanāṃ
sutottamānāṃ śruti-śāstra-śālinām /
avāpa madhye sphaṭikopalopamaṃ
krameṇa kailāsam ivākṣamābhṛtām // 16 //
彼は、偉大なる者たちの優れた息子、ヴェーダと諸学に輝く者たちの中に、水晶の宝石に等しきチトラバーヌという息子を得た――山々の中にカイラーサ山を得たかのように。【16】
mahātmano yasya su-dūra-nirgatāḥ
kalaṅka-muktendu-kalāmala-tviṣaḥ /
dviṣan-manaḥ prāviviśuḥ kṛtāntarā
guṇā nṛsiṃhasya nakhāṅkurā iva // 17 //
この偉大なる者の遠方にまで達した、汚れなき月の光のごとく清らかな輝きを持つ徳は、敵の心に入り込んだ――人獅子（ナラシンハ）の爪先が〔ヒラニヤカシプの胸を〕引き裂いたかのように。【17】
diśām alīkālaka-bhaṅgatāṃ gata-
kṣayī-vadhū-karṇa-tamāla-pallavaḥ /
cakāra yasyādhvara-dhūma-saṃcayo
mailīmasaḥ śukrataraṃ nijaṃ yaśaḥ // 18 //
諸方位の額飾りの黒髪の巻き毛となり、下弦の月（クシャイー）の妻たちの耳のタマーラ葉の飾りとなったこの者の祭祀の煙の集積は、汚れたものをもさらに白くして、己の名声を輝かせた。【18】
sarasvatī-pāṇi-saroja-saṃspṛṣṭa-
homa-śrama-śīkarāmbhasaḥ /
yaśo-'ṃśu-śuklī-kṛta-sapta-viṣṭapat-
tataḥ suto bāṇa iti vyajāyata // 19 //
サラスヴァティー女神の蓮華の掌に触れられ、護摩の労苦の飛沫の水を浴び、名声の光芒によって七天界を白く染めた――その彼から息子バーナが生まれた。【19】
dvijena tenākṣata-kaṇṭha-kauṇṭhyayā
mahā-mano-moha-milīmasāndhayā /
alan-dhavaidagdhya-vilāsa-mugdhayā
dhiyā nibaddheyam atīdvayī kathā // 20 //
かのバラモン〔バーナ〕によって、喉にいささかのためらいもなく、大いなる心の迷妄を暗く霞ませ、巧みさの戯れに魅了された知によって、この二部に及ぶ比類なき物語が編まれた。【20】
◆ Kathāmukham — Śūdraka-varṇanam
◆ カタームカ（物語の枠組み） ― シュードラカ王の描写
āsīd aśeṣa-narapati-śiraḥ-samabhyarcita-śāsanaḥ pākaśāsana ivāparaḥ, catur-udadhi-mālā-mekhalāyā bhuvo bhartā, pratāpānurāgāvanata-samasta-sāmanta-cakraḥ, cakravarti-lakṣaṇopetaḥ, cakradhara-kara-kamalopālakṣyamāṇa-śaṅkha-cakrācchannaḥ,
すべての王たちが頭を垂れてその勅命を崇め奉る者、インドラ（パーカシャーサナ）のもう一人の化身のごとき者がいた。四つの大洋の花鬘を腰帯とする大地の主であり、武威と愛慕によってひれ伏すあらゆる封臣の輪を従え、転輪聖王の相を備え、チャクラダラ（ヴィシュヌ）の蓮華の御手に見出される法螺貝と円盤の印を隠し持つ者。
hara iva jita-manmathaḥ, guha ivāpratihata-śaktiḥ, kamalayonir iva vimānī-kṛta-rāja-haṃsa-maṇḍalaḥ, jaladhi iva lakṣmī-prasūtiḥ, gaṅgā-pravāha iva bhagīratha-patha-pravṛttaḥ, ravir iva prati-divasa-upajāyamānodayaḥ, merur iva sakalopajīvyamāna-pāda-cchāyāḥ, dig-gaja ivānavarata-pravṛtta-dānādrī-kṛta-karaḥ,
ハラ（シヴァ）のごとく愛の神を征服し、グハ（スカンダ）のごとく槍をもって無敵であり、カマラヨーニ（ブラフマー）のごとく王族のハンサ鳥の群れを乗物とし、大海のごとくラクシュミーを生み出し、ガンガーの流れのごとくバギーラタの道を進み、太陽のごとく日ごとに新たなる興隆をなし、メール山のごとくすべての者がその足元の陰に依り頼み、方位の象のごとく絶えず布施を施して手を濡らす者。
kartā mahāścaryāṇām, āhartā ṛtūnām, ādarśaḥ sarva-śāstrāṇām, utpattiḥ kalānām, kula-bhavanaṃ guṇānām, āgamaḥ kāvyāmṛta-rasānām, udaya-śailo mitra-maṇḍalasya, utpāta-ketur ahita-janasya,
大いなる驚異の作り手、祭祀の執行者、あらゆる学問の鏡、諸技芸の源泉、美徳の家門、詩の甘露の味の聖典、友の群れの日の出の山、敵にとっての凶兆の彗星。
pravartayitā goṣṭhī-bandhānām, āśrayo rasikānām, pratyādeśo dhanuṣmatām, dhaureyaḥ sāhasikānām, agraṇīr vidagdhānām, vainateya iva vinatānanda-jananaḥ, vainya iva cāpa-koṭi-samutsāritārāti-kulācalo rājā śūdrako nāma.
談論の結びの創始者、趣味人たちの拠り所、弓術者たちへの叱咤、大胆な者たちの先導者、粋人たちの筆頭――ヴァイナテーヤ（ガルダ）のごとくヴィナター（母）に歓びをもたらし、ヴァイニヤ（プリトゥ王）のごとく弓の端で敵の山脈を打ち払う――シュードラカという名の王がいた。
nāmnaiva yo nirbhinnārāti-hṛdayo viracita-nārasiṃha-rūpāḍambaram, eka-vikramānta-sakala-bhuvana-talaṃ vikrama-trayāyāsitaṃ bhuvana-trayaṃ ca hasati smeva vāsudevam.
名のみによって敵の心臓を貫き、人獅子（ナラシンハ）の姿の虚飾を暴いた者。ただ一つの武勇によって全地上を平定し、三歩の労を費やして三界を〔征服した〕ヴァースデーヴァ（ヴィシュヌ）をも嘲笑するかのようであった。
aticirakāla-lagnam atikrānta-nṛpati-sahasra-saṃparka-kalaṅkam iva kṣālayantī yasya kṛpāṇa-dhārā-jale ciram uvāsa lakṣmīḥ.
長き時をかけてこびりついた、過去の千人もの王との交わりの汚れを洗い流すかのように、ラクシュミー（王権の女神）は彼の剣の刃の水の中に長く住まった。
yaś ca manasi dharmeṇa, kope yamena, prasāde dhanadena, pratāpe vahninā, bhuje bhuvā, dṛśi śriyā, vāci sarasvatyā, mukhe śaśinā, bale marutā, prajñāyāṃ suraguruṇā, rūpe manasijena, tejasi savitā ca vasatā sarva-deva-mayasya prakāṭita-viśvarūpākṛter anukaroti bhagavato nārāyaṇasya.
心にはダルマが、怒りにはヤマが、恩寵にはクベーラが、威光には火神が、腕には大地が、眼にはラクシュミーが、言葉にはサラスヴァティーが、顔には月が、力にはヴァーユが、知恵にはブリハスパティが、美貌にはカーマ神が、輝きにはスーリヤが――それぞれ住まうことによって、一切の神々を体現するヴィシュヴァルーパ（宇宙の姿）を顕したバガヴァーン・ナーラーヤナに倣う者。
◆ Śūdraka-parākrama-varṇanam
◆ シュードラカ王の武勇の描写
yasya ca madakala-kari-kumbha-pīṭha-pāṭanaṃ vidadhato labdha-sthūla-muktā-phalena heḍa-muṣṭi-nipīḍanān niṣpyūta-dhārā-jala-vindu-dantureṇeva kṛpāṇenākṛṣyamāṇā, subhaṭoraḥ-kapāṭa-vighaṭita-kavaca-sahasrāndhakāra-madhyavartinī kari-karaṭa-galita-mada-jalāsāra-durdināstre bhisārikeva samara-niśāsu samīpaṃ saṃkrāntā rāja-lakṣmīḥ.
彼が酔象の額板を打ち砕くとき得られた大粒の真珠を持ち、侮蔑の拳で握り締めて噴き出す刃の水滴に覆われた剣に引き寄せられるかのように、勇士たちの胸板を打ち破り幾千もの鎧の暗闇の只中にあって、象の額から滴り落ちるマダ液の豪雨の悪天候の夜に逢瀬に赴く恋する女のごとく、戦闘の夜ごとに王権の女神ラクシュミーは彼のもとに近づき来た。
yasya ca hṛdi sthitān api bhartr̥̄n daidhakṣur iva pratāpānalo viyoginīnām api ripu-sundarīṇām antar-janita-dāho divā-niśaṃ jajvāla.
彼の武威の炎は、心中に〔かくまわれた〕夫たちをも焼き尽くさんとするかのように、離別の女たちのごとき敵の美女たちにも内なる灼熱を生じさせ、昼夜を問わず燃え盛った。
◆ Śleṣa-varṇanam
◆ シュレーシャ（双関語による王治の賛美）
yasmiṃś ca rājani jita-jagati pālayati mahīṃ citra-karmeṣu varṇa-saṃkaraḥ, rateṣu keśa-grahaḥ, kāvyeṣu dṛḍha-bandhāḥ, śāstreṣu cintā, svapneṣu vipralambhāḥ, chatrreṣu kanaka-daṇḍāḥ, dhvajeṣu prakampāḥ, gīteṣu rāgāvilasitāni, kariṣu mada-vikārāḥ, cāpeṣu guṇa-cchedāḥ, gavākṣeṣu jāla-mārgāḥ, śaśi-kṛpāṇa-kavaceṣu kalaṅkāḥ, rati-kalaheṣu dūta-preṣyaṇāni, sārtha-kṣetreṣu śūnya-gṛhā na prajānām āsan.
世界を征服して大地を治めるこの王のもとでは、臣民に以下のものは存在しなかった。――絵画においてのみヴァルナサンカラ（色の混合／身分の混交）が、情交においてのみケーシャグラハ（髪を掴むこと／苦悩に捕えられること）が、詩作においてのみドゥリダバンダ（堅固な構成／強固な束縛）が、学問においてのみチンター（思索／憂慮）が、夢においてのみヴィプラランバ（欺き／離別の情）が、日傘においてのみカナカダンダ（黄金の柄／黄金の刑罰）が、旗においてのみプラカンパ（はためき／恐怖の震え）が、歌においてのみラーガ（旋法／情欲）が、象においてのみマダヴィカーラ（発情の変調／驕慢の乱れ）が、弓においてのみグナッチェーダ（弦の断裂／美徳の断絶）が、窓においてのみジャーラマールガ（格子の通路／網の罠）が、月・剣・鎧においてのみカランカ（斑点／汚名）が、痴話喧嘩においてのみドゥータプレーシャナ（使者の派遣／密使の送付）が、隊商の野営地においてのみシューニャグリハ（空き家／虚しき家庭）が。
yasya ca paralokād bhayam, antaḥpurikā-kuntaleṣu bhaṅgaḥ, nūpureṣu mukharatā, vivāheṣu kara-grahaṇam, anavaratam aśru-pātaḥ, turaṅgeṣu kaśābhighātaḥ, makara-dhvaje cāpa-dhvanir bhūt.
また彼のもとでは次のものしかなかった。――来世からの〔帰還の〕恐怖（／来世への恐怖は無し）、後宮の女たちの巻き毛におけるバンガ（ウェーブ／破壊）、足飾りにおけるムカラター（音を立てること／饒舌）、婚礼におけるカラグラハナ（手を取ること／逮捕）、絶え間なきアシュルパータ（雨滴の落下／涙の落下）、馬におけるカシャービガータ（鞭の打撃／苦痛の打撃）、愛の神の旗印においてのみチャーパドゥヴァニ（弓の音／弓の鳴動）。
◆ Vidiśā-nagarī-varṇanam
◆ ヴィディシャーの都の描写
tasya ca rājñaḥ kali-kāla-bhaya-puñjī-bhūta-kṛta-yugānukāriṇī, tri-bhuvana-prasava-bhūmir iva vistīrṇā, mañjana-mālava-vilāsinī-kuca-taṭāsphālana-jarjaritormi-mālyā jalāvagāhenāgata-jaya-kuñjara-kumbha-sindūra-sandhyāyamāna-salilā unmada-kala-haṃsa-kula-kolāhala-mukharī-kṛta-kūlayā vetravātyā parigatā vidiśābhidhānā nagarī rājadhāny āsīt.
その王には、カリ・ユガ（暗黒時代）の恐怖を寄せ集めてクリタ・ユガ（黄金時代）を模する都があった。三界の産出の大地のごとく広大であり、マールワ地方の美女たちの乳房の斜面が打ち寄せて波の花鬘を砕き、水浴びに入った凱旋の象の額のシンドゥーラ（朱紅）に染まった水を湛え、狂酔したハンサ鳥の群れの喧騒が岸辺を賑わすヴェートラヴァティー河に囲まれた、ヴィディシャーという名の王都であった。
sa tasyām eva jitāśeṣa-bhuvana-maṇḍalatayā vigata-rājya-cintā-bhāra-nirbṛtaḥ, dvīpāntarāgatāneka-bhūpāla-mauli-mālā-lālita-caraṇa-yugalo valayam iva līlayā bhujena bhuvana-bhāram udvahan, ama-gurum api prajñayopahsadbhir aneka-kula-kramāgatair asakṛd-ālocita-nīti-śāstra-nirmala-manobhir alubdhaiḥ snigdhaiḥ prabuddhaiś cāmātyaiḥ parivṛtaḥ,
彼はその都において、あまねく世界を征服し終えた安堵から王権の重荷の憂いを離れ、他の島々から来た多くの王たちの冠の列に愛撫される両足を持ち、腕輪のごとく腕によって戯れに世界の重荷を担い、ブリハスパティ（神々の師）をも知恵で凌駕し、多くの名門から代々仕え、繰り返し政治学の典籍を吟味して清らかな心を持つ、貪欲なく、情け深く、聡明な大臣たちに囲まれ、
samāna-vayo-vidyālaṃkārair aneka-mūrdhābhiṣikta-pārthiva-kulaughitair akhila-kalā-kalāpālocana-kaṭhora-matibhir ati-pragalbhaiḥ kālavidbhiḥ premāvānurakta-hṛdayair grāmyopahāsa-kuśalair iṅghaiḥ,
同じ年齢・学識・装いを持ち、多くの灌頂を受けた王家の群れと交わり、あらゆる技芸の集積の考究によって研ぎ澄まされた知性を持ち、きわめて大胆にして、時を知り、愛と献身に満ちた心を持ち、世俗の冗談にも巧みな友人たちと、
kāvya-nāṭaka-ākhyānaka-ākhyāyikā-ālekhya-vyākhyānādi-kriyā-nipuṇair ati-kaṭhina-pīvara-skandhoru-bāhubhir asakṛd avadalita-samada-ripu-gaja-ghaṭā-pīṭha-bandhaiḥ kesari-kiśorakair iva vikramaika-rasair api vinaya-vyavahāribhir ātmanaḥ pratibimbair iva rāja-putraiḥ saha ramamāṇaḥ prathame vayasi sukham aticiram uvāsa.
詩・戯曲・物語・小説・絵画・解説等の技芸に秀で、堅く太い肩・腿・腕を持ち、幾度となく酔った敵の象群の額の結合部を打ち砕き、獅子の子のごとく武勇のみを好みつつも礼儀正しく振る舞い、王の分身のごとき王子たちとともに楽しみつつ、青年期にきわめて長く安楽に過ごした。
tasya cātivijigīṣutayā mahā-sattvatayā ca tṛṇam iva laghu-vṛtti kṣauṇam ākalayataḥ prathame vayasi vartamānasyāpi rūpavato 'pi saṃtānārthibhir amātyair apekṣitasyāpi surata-sukhasyopari dveṣa ivāsīt, satyapi rūpa-vilāsa-pahāsita-rati-vibhrame lāvaṇyavati vinayavaty anvayavati hṛdaya-hāriṇi cāvarodha-jane.
彼は極度の征服欲と大いなる雄心から、大地を草のごとく軽きものと見なしていた。青年期にあってなお容貌端麗でありながらも、跡継ぎを望む大臣たちに期待されていながらも、情交の快楽に対してはまるで嫌悪を覚えるかのようであった――たとえ後宮の婦人たちが、その美しさの戯れでラティ（愛の女神）の媚態をも凌ぎ、優美にして慎ましく、家柄よく、心を奪うものであったとしても。
◆ Kadācit-varṇanam — Śūdraka-divasa-krīḍā
◆ カダーチト（ある時は～）― シュードラカ王の日々の遊び
sa kadācid anavarata-dolāyamāna-rala-valayo gharghrikā-sphālana-prakampa-jhaṇa-jhaṇāyamāna-maṇi-karṇa-pūraḥ svayam ārabdha-mṛdaṅga-vādyaḥ saṃgītaka-prasaṅgena, kadācid virala-vimukta-śarāsāra-śūnyī-kṛta-kānano mṛgayā-vyāpāreṇa, kadācid ābaddha-vidagdha-maṇḍalaḥ kāvya-prabandha-racanena,
彼はある時は、絶え間なく揺れるラーラの腕輪をつけ、ガルガリカー（小鈴）を打つ振動にジャナジャナと鳴る宝石の耳飾りを響かせ、自ら始めたムリダンガの演奏に合わせて音楽の集いに興じ、ある時は、矢の雨を惜しみなく放って森を獣のいない空地と化す狩猟に携わり、ある時は粋人たちの輪を結び詩作の創作に勤しみ、
kadācic chāstrālāpena, kadācid ākhyānaka-ākhyāyikā-itihāsa-purāṇākarṇanena, kadācid ālekhya-vinodena, kadācid vīṇayā, kadācid darśanāgata-muni-jana-caraṇa-śuśrūṣayā, kadācid akṣara-cyuta-mātrā-cyuta-kabindumati-gūḍha-caturtha-pāda-prahelikā-pradānādibhir vanitā-saṃbhoga-sukha-parāṅmukhaḥ suhṛt-parivṛto divasam anaiṣīt.
ある時は学問の談論に、ある時は説話・小説・叙事詩・古伝の聞き語りに、ある時は絵画の遊びに、ある時はヴィーナーの演奏に、ある時は訪れた聖仙たちの足下への奉仕に、ある時は文字落とし・拍落とし・隠し句・第四句の謎かけ等の遊びに興じ――女人との歓楽を背にしつつ、友人たちに囲まれて一日を過ごした。
yathaiva ca divasam evam ārabdha-vividha-krīḍā-parihāsa-caturaiḥ suhṛdbhir upeto niśām anaiṣīt.
昼をそのように過ごしたのと同様に、さまざまな遊びと冗談に巧みな友人たちとともに夜をも過ごした。
◆ Prātihārī-varṇanam
◆ プラーティハーリー（門番の女官）の描写
ekadā tu nātidūrodite nava-nalina-dala-saṃpuṭa-bhidi kiṃcin-mukta-pāṭalimni bhagavati sahasra-marīci-mālini rājānam āsthāna-maṇḍapa-gatam aṅganā-jana-viruddhena vāma-pārśva-lambinā kaukṣeyakeṇa saṃnihita-viṣadhareva candana-latā bhīṣaṇa-ramaṇīyākṛtiḥ,
ある日のこと、新しい蓮の花弁の合わせ目を裂くかのように昇り始め、いくらか赤みを帯びた千光の冠を戴く太陽神のもと、王が謁見の殿堂に臨んでいるところへ――婦人には似つかわしからぬ剣を左脇に下げて、毒蛇を身に纏う栴檀の蔓のごとく恐ろしくも美しい姿の、
avirala-malayajānulepa-dhavalitta-stana-taṭonmajjad-rāvata-kumbha-maṇḍaleva mandākinī, cūḍā-maṇi-prativimba-chalena rājājñeva mūrtimatī rājabhiḥ śirobhir uhyamānā, śarad iva kala-haṃsa-dhavala-ambarā,
白檀の塗香に白く輝く胸の斜面から、ラーヴァタ（アイラーヴァタ象）の額瘤のごとき乳房が浮かび上がるマンダーキニー（天のガンガー）のごとき者、頭頂の宝珠の映りを口実に王の勅命の化身のごとく諸王に頭上に戴かれる者、秋のごとくハンサ鳥のように白い衣を纏う者、
jāmadagnya-paraśu-dhāreva vaśī-kṛta-sakala-rāja-maṇḍalā, vindhya-vana-bhūmir iva vetra-latāvatī, rājyādhidevateva vigrahiṇī prātihārī samupāsya vāsaram anaiṣīt. evaṃ tathaiva niśāṃ triyāmām api.
パラシュラーマ（ジャーマダグニャ）の斧の刃のごとく全王族を従え、ヴィンディヤの森の大地のごとく竹杖を携え、王国の守護女神のごとく威厳ある姿の――プラーティハーリー（門番の女官）が、王に侍して一日を過ごした。夜の三更もまた同様に。
◆ Cāṇḍāla-kanyā-āgamanam
◆ チャンダーラの娘の到来
kṣiti-tala-nihita-jānu-karatalā sa-vinayam abravīt — "deva, dvāra-sthitā sura-lokam ārohathas triśaṅkor iva kupita-śatamakha-huṃkāra-nipātitā rāja-lakṣmīr dakṣiṇa-pathād āgatā cāṇḍāla-kanyā pañjara-sthaṃ śukam ādāya devaṃ vijñāpayati —
〔プラーティハーリーが〕地に膝と両手をつけ、恭しく申し上げた。「王よ、門前に立っております。天界に昇ろうとするトリシャンクのごとく、怒れるインドラ（シャタマカ）のフームカーラ（呵責の咆哮）によって突き落とされた王権の女神のごとき――ダクシナーパタ（南方）から参ったチャンダーラの娘が、籠に入った鸚鵡を携え、王にこう申し上げております。
'sakala-bhuvana-tala-ratnānām udadhir ivaikabhājanaṃ devaḥ. vihaṅgamaś cāyam āścarya-bhūto nikhila-bhuvana-tala-ratnam iti kṛtvā deva-pāda-mūlam ādāyāgatāham icchāmi deva-darśana-sukham anubhavitum' iti."
『王は全世界の宝の大海のごとき唯一の器です。この鳥は驚くべき存在であり、全世界の宝です。それゆえ王の御足許にこの鳥を携えて参りました。わたくしは王にお目にかかる喜びを味わいとう存じます。』と。」
◆ Rājā-āsthāna-varṇanam
◆ 玉座に坐す王の描写
avalambita-sthūla-muktā-kalāpasya kanaka-śṛṅkhalā-niyamita-maṇi-daṇḍikā-catuṣṭayasya gagana-sindhu-phena-paṭala-pāṇḍurasya nātimahato dukūla-vitānasyādhastād indu-kānta-paryaṅke niṣaṇṇam,
〔プラーティハーリーは〕大粒の真珠の瓔珞を垂らし、黄金の鎖で四本の宝石の柱に固定された、天の大河の飛沫のごとく白い、さして大きくない絹の天蓋の下に、月光石の寝台に坐す〔王を見た〕。
uddrīyamāṇa-suvarṇa-daṇḍa-cāmara-kalāpam, unmayūkha-mukha-kānti-vijaya-parābhava-praṇate śaśini iva sphaṭika-pāda-pīṭhe vinyasta-vāma-pādam, indranīla-maṇi-kuṭṭima-prabhā-saṃparkeṇa śyāmāyamānaiḥ praṇata-ripu-niḥśvāsa-malinī-kṛtair iva caraṇa-nakha-mayūkha-jālaiḥ upaśobhamānam,
黄金の柄の払子の束が振られ、光輝ける顔の美に敗北してひれ伏す月のごとき水晶の足台に左足を置き、インドラニーラ（藍玉）の床石の光と交わって黒ずみ、ひれ伏す敵のため息で曇らされたかのような足の爪の光芒に飾られた〔王を〕。
āsanollasita-padmarāga-kiraṇa-pāṭalī-kṛtenāciramṛdita-madhu-kaiṭabha-rudhirāruṇena harim ivoru-yugalena virājamānam, amṛta-phena-dhavale gorocanā-likhita-haṃsa-mithuna-sanātha-paryante cāru-cāmara-vāyu-pranartitāntar-deśe dukūle vasānam,
玉座に映えるパドマラーガ（紅玉）の光に赤く染まり、今しも圧殺したマドゥとカイタバの血に赤いハリ（ヴィシュヌ）の両腿のごとく輝き、甘露の泡のごとく白く、ゴーローチャナー（牛黄）で描かれたハンサ鳥の番いを端に配し、美しい払子の風に内側が踊る絹衣を纏う〔王を〕。
ati-surabhi-candanānulepa-dhavalitoraḥ-sthalam, upari-vinyasta-kuṅkuma-sthāsakam antarāntarā nipatita-vālātapa-cchedam iva kailāsa-śikharam, apara-śiśaṅkayā nakṣatra-mālayeva hāra-latayā kṛta-mukha-pariveṣam,
芳しき栴檀の塗香に白く輝く胸を持ち、その上にクンクマ（紅花）の手型を押し、ところどころに射し込む朝日の断片を受けてカイラーサ山の頂のごとく、もう一つの月のごとき真珠の首飾りの蔓で顔の周囲に光背を作る〔王を〕。
āsanna-vartinībhiḥ sarvataḥ sevārtham āgatābhir iva dig-vadhūbhir iva vilāsinībhiḥ parivṛtam, amala-maṇi-kuṭṭima-saṃkrānta-sakala-deha-pratibimbatayā pati-premṇā vasuṃdharyā hṛdaye nevoddvahyamānam,
近くに控える、四方から奉仕に参った方位の女神たちのごとき美女たちに囲まれ、清浄な宝石の床に全身の映像が映ることで、愛ゆえに大地の女神ヴァスンダラーに心の中に担い上げられるかのような〔王を〕。
aśeṣa-jana-bhogyatām upanītayāpy asādhāraṇayā rāja-lakṣmyā samāliṅgita-deham, aparimita-parivāra-janam apy advitīyam, ananta-gaja-turaga-sādhanam api khaḍga-mātra-sahāyam, eka-deśa-sthitam api vyāpta-bhuvana-maṇḍalam,
すべての者が享受しうるものとしながらも比類なき王権の女神ラクシュミーに身体を抱かれ、無量の随従を持ちながらもただ独りであり、無数の象・馬・軍備を持ちながらも剣のみを伴とし、一所に座しながらも全世界に遍く及ぶ〔王を〕。
āsane sthitam api dhanuṣi niṣaṇṇam, utsādita-dviṣ-indhanam api jvalat-pratāpānalam, āyata-locanam api sūkṣma-darśanam, mahā-doṣam api sakala-guṇādhiṣṭhānam, ku-patim api kalatra-vallabham, dānam apy amadam, atyanta-śuddha-svabhāvam api kṛṣṇa-caritam, akaram api hasta-sthita-bhuvana-talaṃ rājānam adrākṣīt.
玉座に座しながらも弓に跨り、敵という薪を焼き尽くしながらも武威の炎を燃やし、大きな眼を持ちながらも微細を見通し、大いなるドーシャ（夜＝欠点）を持ちながらもあらゆるグナ（美質）の拠り所であり、ク・パティ（大地の主＝悪しき夫）でありながらもカラトラ（妻）に愛され、ダーナ（布施＝象の発情液）を持ちながらもア・マダ（驕慢なき＝酔わぬ）であり、きわめて清浄な本性でありながらもクリシュナ（黒き＝クリシュナ神の）行いをなし、ア・カラ（手なき＝租税なき）でありながらも手中に世界を収める――そのような王を〔彼女は〕見た。
◆ Cāṇḍāla-kanyā-praveśaḥ
◆ チャンダーラの娘の入場
ālokya ca sā dūra-sthitaiva pracalita-ratna-valayena rakta-kuvalaya-daḷa-komalena pāṇinā jarjarita-mukha-bhāgāṃ veṇu-latām ādāya nara-pati-prabodhanārthaṃ sakṛt sabhā-kuṭṭimam ājagāna,
〔王を〕見て、彼女は遠くに立ったまま、揺れる宝石の腕輪をつけた赤い睡蓮の花弁のごとく柔らかな手で、先端の砕けた竹の杖を取り、王に注意を喚起するためにひとたび議場の床を打った。
yena sakalam eva tad rājakam ekapade vana-kari-yūtham iva tāla-śabdena yugapad āvalita-vadanam avanipāla-mukhād ākṛṣya cakṣus tad-abhimukham āsīt.
その打撃音によって、拍子木の音に一斉に顔を向ける森の象の群れのごとく、宮廷のすべての者が王の顔から視線を引き離して、一斉にその方を向いた。
avanipatis tu "dūrād ālokaya" ity abhidhāya prātihāryā nirdiśyamānāṃ tāṃ vayaḥ-pariṇāma-śubhra-śirasā rakta-rājīva-netrāpāṅgena anavarata-kṛta-vyāyāmatayā yauvanāpagame 'py aśithila-śarīra-saṃdhinā satyapi mātaṅgatve nātinṛśaṃsākṛtinā anugṛhītārya-veṣeṇa śubhra-vāsasā puruṣeṇādhiṣṭhita-purobhāgam,
王は「遠くから見せよ」と命じ、プラーティハーリーに指し示された者を〔見た〕。――年齢により白くなった頭髪の、赤蓮のような目尻を持つ、絶え間ない鍛錬のゆえに若さが去った後も関節の衰えぬ身体の、チャンダーラ（不可触民）でありながら残忍な容貌ではなく、高貴な装いに恵まれ、白衣をまとう男が前方に立つ〔一行の姿を〕。
◆ Cāṇḍāla-kanyā-varṇanam
◆ チャンダーラの娘の容姿の描写
ākula-ākula-kāka-pakṣa-dhāriṇā kanaka-śalākā-nirmitam ayy antar-gata-śuka-prabhā-śyāmāyamānaṃ marakata-mayam iva pañjaram udvahatā cāṇḍāla-dārakeṇānugamyamānām,
乱れた黒髪の額飾りを戴き、黄金の細棒で造られた、中に入った鸚鵡の緑の光に翠玉のごとく輝く鳥籠を担うチャンダーラの少年に付き従われる〔娘を見た〕。
asura-gṛhītāmṛtāpaharaṇa-kṛtaka-paṭu-vilāsini-veṣam apy śyāmatayā bhagavato harer ivānukurvatīm, saṃcāriṇīm ivendranīla-maṇi-putrikām,
阿修羅から甘露を奪うために巧みな美女の姿をとりながらも、その黒さによってバガヴァーン・ハリ（ヴィシュヌ）を模倣するかのような――歩き回るインドラニーラ（藍宝石）の人形のごとき〔娘を〕。
gulpha-avalambinoḷa-kañcukenāvacchanna-śarīrām, uparitaḥ rakta-śuka-citāvaguṇṭhanām, nīlotpala-sthalīm iva nipatita-sandhyā-tāpam,
踝まで垂れる黒い上着に身体を覆い、上に赤い絹の被衣を纏い、夕焼けが降り注いだ青蓮の野のような〔娘を〕。
eka-karṇāvasakta-danta-patra-prabhā-dhavalita-kapola-maṇḍalām, udyad-indu-kiraṇa-cchurita-mukhīm iva vibhāvarīm, ākapila-gorocanā-racita-tilaka-tṛtīya-locanām īśāna-racitānurcita-kirāta-veṣām iva bhavānīm,
片方の耳に掛けた象牙の耳飾りの輝きに白く照らされた頬の、昇る月の光に顔を照らされた夜のごとき者。やや赤みを帯びたゴーローチャナー（牛黄）で描かれたティラカの第三の眼を持ち、イーシャーナ（シヴァ）自らが整えた狩人の装いのバヴァーニー（パールヴァティー）のごとき〔娘を〕。
uraḥ-sthala-nivāsa-saṃkrānta-nārāyaṇa-deha-prabhām ilitām iva śriyam, kupita-hara-hutāśana-dahyamāna-madana-dhūma-malinī-kṛtām iva ratim, unmada-hali-helā-karṣaṇam anudravyamānām,
胸に宿るナーラーヤナ（ヴィシュヌ）の身体の輝きを移し染めたかのようなラクシュミー（美の女神シュリー）のごとき者、怒れるシヴァの火に焼かれるカーマ神の煙にくすぶらされたラティ（愛の女神）のごとき者、狂える蜂がたわむれに引き寄せられて追いかける〔娘を〕。
ativahla-piṇḍālaktaka-rasa-rāga-pallavita-pāda-paṅkajām, aciramṛdita-mahiṣāsura-rudhira-rakta-caraṇām iva kātyāyanīm, ālohitāṅguli-prabhā-pāṭalita-nakha-mayūkhām,
豊かなラックの赤い色料に赤く染まった蓮華の足を持ち、今しもマヒシャースラ（水牛の魔神）の血に赤く濡れた足のカーティヤーヤニー（ドゥルガー）のごとき者、赤みを帯びた指の輝きに桃色に染まる爪の光を持つ〔娘を〕。
prāvṛṣam iva ghana-keśa-jālām, malaya-mekhalām iva candana-pallavāvataṃsām, nakṣatra-mālām iva citra-śravaṇābharaṇa-bhūṣitām, śriyam iva hasta-sthita-kamala-śobhām,
濃密な髪の網を持つ雨季のごとき者、栴檀の若葉の耳飾りをつけたマラヤ山脈の腰帯のごとき者、色鮮やかな耳飾りで装った星々の列のごとき者、手に蓮を持つ美のラクシュミーのごとき者、
mūrcchām iva mano-hāriṇīm, araṇya-bhūmim iva rūpa-saṃpannām, divya-yoṣitam ivākulīnām, nidrām iva locana-grāhiṇīm, araṇya-kamalinīm iva mātaṅga-kula-dūṣitām,
失神のごとく心を奪う者、森の大地のごとく美（ルーパ）に恵まれた者、天女のごとく家柄なき者、眠りのごとく眼を捕らえる者、森の蓮池のごとく象（マータンガ＝チャンダーラ）の族に汚された者、
amūrtām iva sparśa-varjitām, ālekhya-gatām iva darśana-mātra-phalām, madhu-māsa-kusuma-samṛddhim ivājātim, anaṅga-kusuma-cāpa-lekhām iva muṣṭi-grāhya-madhyām, yakṣādhipa-lakṣmīm ivālaṃkāsinīm, aciropa-ārūḍha-yauvanām, atiśaya-rūpākṛtiṃ nimiṣa-locanāṃ dadarśa.
非物質的存在のごとく触れえぬ者、絵の中の姿のごとく見ることだけが果実である者、春月の花の豊穣のごとくジャーティ（ジャスミン＝高い生まれ）なき者、カーマ神の花の弓の線描のごとく拳に握れる細い腰を持つ者、クベーラの妃ラクシュミーのごとくアランカーの都に住む者、今しも若さの盛りに昇った、超絶の美の姿の、瞬きする瞳の〔娘を〕王は見た。
◆ Rāja-vismayaḥ
◆ 王の驚嘆
jāta-vismayā bhūn manasi mahīpateḥ — "aho vidhātuḥ sthāne saundarya-niṣpādana-prayatnaḥ. tathā hi. yadi nāmeyam ātma-rūpopahāsitāśeṣa-rūpa-saṃpad utpāditā, kim artham apagata-sparśa-saṃbhoga-sukhe kṛtaṃ kule janma.
王の心に驚きが生じた。「ああ、創造主ブラフマーの美の創出の努力はまことに然るべきものだ。実にこの娘は、自らの美によってあらゆる美の富を嘲笑するほどに創られた。それなのに、なぜ触れることも交わりの喜びもなき身分に生まれさせたのか。
manye ca mātaṅga-jāti-sparśa-doṣa-bhayād aspṛśyateyam utpāditā prajāpatinā, anyathā katham iyam akliṣṭā lāvaṇyasya. na hi kara-tala-sparśa-kleśitānām avayavānām īdṛśī bhavati kāntiḥ.
思うに、チャンダーラの生まれの触穢の過ちを恐れたゆえに、プラジャーパティ（創造主）はこの娘を『触れえぬ者』として創造したのだ。さもなくば、どうしてこれほど優美さに苦心の跡がないことがありえよう。手の平で触れて磨き上げた肢体には、このような輝きは生まれぬものだから。
sarvathā dhig vidhi-dhātāram asat-sadṛśa-saṃyoga-kāriṇam, manohārākṛtir api krūra-jātitayā yeneyam asura-śrīr iva satata-nindita-suratā ramaṇīyāpy udvegatī" iti.
まこと呪わしきは、ふさわしからぬ結合をなす運命の造物主よ。心を奪う姿でありながらも、残忍な生まれのゆえに――アスラの美のごとく常に交わりを非難されて――魅惑的でありながらも恐れを抱かせる。」と。
evam ādi cintayantam eva rājānam īṣad-vigalita-karṇa-pallavāvataṃsā pragalbha-vaniteva kanyakā praṇāma.
こう思案する王のもとに、耳の若葉の飾りがわずかに滑り落ちた、大胆な女のような娘が礼拝した。
◆ Vaiśampāyana-śuka-paricayaḥ
◆ 鸚鵡ヴァイシャンパーヤナの紹介
kṛta-praṇāmāyāṃ ca tasyāṃ maṇi-kuṭṭimopa-viṣṭāyāṃ sa puruṣas taṃ vihaṅgamaṃ śukam ādāya pañjara-gatam eva kiṃcid upetyā rājñe nyavedayat.
礼拝を終えた娘が宝石の床に座ると、かの男は鳥――鸚鵡を籠に入れたまま少し近づいて王に差し出した。
"deva, vidita-sakala-śāstrārthaḥ, rāja-nīti-prayoga-kuśalaḥ, purāṇa-itihāsa-kathā-lāpana-puṇaḥ, veditā gīta-śrutīnām, kāvya-nāṭaka-ākhyāyikā-ākhyānaka-prabhṛtīnām aparimitānāṃ subhāṣitānām adhyetā svayaṃ ca kartā,
「王よ。あらゆる学問の義を知り、王道政治の実践に巧みにして、プラーナやイティハーサの物語を語るに秀で、歌曲とヴェーダの旋律を知り、詩・戯曲・小説・説話等の無量の名言の学習者にして自ら作者でもあり、
parihāsālāpa-peśalaḥ, vīṇā-veṇu-muraja-ādīnām asamaḥ śrotā, nṛtta-prayoga-darśana-nipuṇaḥ, citra-karmaṇi pravīṇaḥ, dyūta-vyāpāre pragalbhaḥ, praṇaya-kalaha-kupita-kāminī-prasādanopāya-caturaḥ,
冗談の会話に巧みにして、ヴィーナー・笛・ムラジャ等の無比の聞き手であり、舞踏の演技の鑑賞に秀で、絵画に精通し、賭博に大胆にして、痴話喧嘩で怒った恋人をなだめる術に長け、
gaja-turaṅga-puruṣa-lakṣaṇa-abhijñaḥ, sakala-bhūtala-ratna-bhūto 'yaṃ vaiśampāyano nāma śukaḥ sarva-ratnānām uddhir iva devo bhājanam iti kṛtvainam ādāyāsmat-svāmi-duhitā deva-pāda-mūlam āyātā."
象・馬・人の相を見分ける智に通じた者。全地上の宝ともいうべきこのヴァイシャンパーヤナという名の鸚鵡は――あらゆる宝の海のごとき器たる王にこそふさわしいと考え、これを携えてわが主人の娘が王の御足許に参りました。」
◆ Śuka-jayaśabda — Āryā 21
◆ 鸚鵡の勝利の詞 ― アーリヤー韻律 第21偈
apasṛte ca tasmin vihaṅga-rājo rājābhimukho bhūtvonnāmya dakṣiṇaṃ caraṇam atispṣṭa-varṇa-svara-saṃskārayā girā kṛta-jaya-śabdo rājānam uddiśyāryām imāṃ papāṭha —
かの男が退くと、鳥の王（鸚鵡）は王の方を向き、右足を高く上げ、きわめて明瞭な母音・子音・サンスクリット文法を備えた声でジャヤ（勝利）の言葉を発し、王に向けてこのアーリヤー韻律の偈を詠んだ。
stana-yugam aśru-srātaṃ samīpa-varti hṛdy aśokāmeḥ /
carati vimuktāhāraṃ vratam iva bhavato ripu-strīṇām // 21 //
「汝の敵の妻たちの両の乳房は涙に濡れ、心に悲しみのアショーカ樹が傍らに茂り、
食を断って歩む――まるで苦行の誓いのように。」【21】
〔śleṣa: aśru-srātam＝涙に濡れた／乳を注いだ、aśoka＝悲しみなき／アショーカ樹、vimuktāhāram＝食を断った／首飾りを外した、vratam＝誓い／禁欲〕
rājā tu tām āryāṃ śrutvā saṃjāta-vismayaḥ sa-harṣam āsanna-vartinam, atimahārhema-āsanopa-viṣṭam, amara-gurum ivāśeṣa-nīti-śāstra-pāragam, ativayasam, agrajanmānam, akhile mantri-maṇḍale pradhānam amātyaṃ kumārapālita-nāmānam abravīt —
王はこのアーリヤー偈を聞いて驚嘆し、喜びとともに近くに控える、きわめて高価な黄金の座に座す、天の師ブリハスパティのごとくあらゆる政治学に通暁した、高齢の、バラモンの、全大臣団の筆頭たる、クマーラパーリタという名の大臣に言った。
"śrutā bhavadbhir asya vihaṅgamasya sphuṭatā varṇoccāraṇe, svare ca madhuratā. prathamaṃ tāvad idam eva mahad āścaryam, yad ayam asaṃkīrṇa-varṇa-vibhāga-abhivyakta-mātrā-anusvāra-saṃskāra-yogāṃ giram udīrayati."
「卿らはこの鳥の子音発音の明瞭さ、声の甘美さを聞いたか。まず第一にこれこそが大いなる驚異である。この鳥が混同なき子音の区別を示し、拍（マートラー）とアヌスヴァーラのサンスクリット文法の結合を備えた言葉を発するとは。」
"tatra punar aparam — abhita-viṣaye tiraśco 'pi manujasyeva saṃskāravato buddhi-pūrvā pravṛttiḥ. tathā hi. anena samutkṣipta-dakṣiṇa-caraṇenoccārya jaya-śabdam iyam āryā mām uddiśya parisphuṭākṣaraṃ gītā. prāyeṇa hi pakṣiṇaḥ paśavaś ca bhayāhāra-maithuna-nidrā-saṃjñā-mātra-vedino bhavanti."
「さらに驚くべきことがある――未知の事柄に対しても、この畜生は人間の教養ある者のごとく知性に基づいて行動する。実に見よ、この鳥は右足を高く掲げてジャヤの声を発し、私に向けてこのアーリヤー偈を明瞭な音節で歌った。通常、鳥や獣は恐怖・食・交尾・睡眠の本能のみを知るものだというのに。」
◆ Madhyāhna-visarjanam
◆ 正午の退朝
evaṃ bruvāṇam eva nara-patim ambara-tala-madhyam aśiśira-kiraṇam ārūḍham āvedayan ḍiṅkā-ccheda-prahata-paṭu-paṭaha-nādānusārī madhyāhna-śaṅkha-dhvanir udatiṣṭhat.
こう語る王のもとに、空の中天に太陽が昇ったことを告げる、鋲の切れ目を打つ巧みな太鼓の響きに従う正午の法螺貝の音が鳴り響いた。
tam ākarṇya ca samāsanna-jñāna-samayo visarjita-rāja-lokaḥ kṣitipa āsthāna-maṇḍapād uttasthau.
その音を聞いて、〔鸚鵡の物語の〕聞き知る時がまだ近いと悟りつつ、王は群臣を退出させ、謁見の殿堂から立ち上がった。
atha calati mahīpatau anyonyam ati-rabhasa-saṃcālana-cālitāṅgada-patra-bhaṅga-makara-koṭi-pāṭitāṃśuka-paṭānām, ākṣepa-dolāyamāna-kaṇṭha-dāmnām, aṃsa-sthala-ullasita-kuṅkuma-paṭavāsa-dhūli-paṭala-piñjarī-kṛta-diśām, ālola-mālatī-puṣpa-śekharopata-dalika-dambakānām, ardhāvalambibhiḥ karṇotpalair cumyamāna-gaṇḍa-sthalānām, gamana-preṇa-ālālasānām aham-ahamikayā, vakṣaḥ-sthala-preṅkholita-hāra-latānām, uttiṣṭhatām āsīt saṃśramo mahīpatīnām.
王が動き始めると、互いに急いで動き出すあまりに腕輪の蝶番が鳴り、マカラ（海獣）の飾り先が衣の端を引き裂き、素早い動きに揺れる首飾りをつけ、肩のクンクマの粉の香粉の塵が四方を黄金色に染め、揺れ動くマーラティーの花の髪飾りから蜜蜂の群れが舞い落ち、半ば垂れた耳の蓮が頬をなでるように触れ、歩む願いに急きたてられ、我先にと胸に揺れる真珠の首飾りを震わせて――立ち上がる諸王の喧騒が起こった。
itaś caitaś ca niḥpatantīnāṃ skandhāvasakta-cāmarāṇāṃ cāmara-grāhiṇīnāṃ kamala-madhu-pāna-matta-jarat-kala-haṃsa-nāda-jarjaritena pade pade raṇita-maṇīnāṃ maṇi-nūpurāṇāṃ ninādena,
あちこちから飛び出してくる、肩に払子を掛けた払子持ちの侍女たちの――蓮の蜜を飲んで酔った老いたハンサ鳥の声に打ち砕かれるかのような――一歩ごとに宝石が鳴る宝石の足飾りの響きと、
vāra-vilāsinī-janasya saṃcarato jaghana-sthala-āsphālana-rasita-ratna-mālikānāṃ maṇi-mekhalānāṃ manohāriṇā jhaṅkāreṇa, nūpura-vāk-kṛtānāṃ ca dhavalitāsthāna-maṇḍapa-sopāna-phalakānāṃ bhavana-dīrghikā-kala-haṃsānāṃ kolāhalena,
行き交う宮廷美女たちの腰のあたりで打ち鳴らされる宝石の列の宝石の腰帯の魅惑的な響きと、足飾りの音に呼び覚まされ、白く輝く謁見殿の階段板の上の宮殿の池のハンサ鳥たちの喧騒と、
rājñāṃ ca sa-saṃbhrama-avajita-mauli-lela-cūḍā-maṇīnāṃ praṇamatām amala-maṇi-śalākā-danturābhiḥ kirīṭa-koṭibhir ullikhyamānasya maṇi-kuṭṭimasya niḥsvanena, maṅgala-pāṭhakānāṃ ca puro-yāyināṃ ca jaya-jīveti madhura-vacanānuyāyinā kalakalena sarvataḥ kṣubhitam iva tad āsthāna-bhavanam abhavat.
慌ただしく冠を抑える際に揺れ落ちる頂の宝石を持つ諸王が礼拝するとき、清浄な宝石の細棒のような冠の先端が宝石の床を引っ掻く音と、吉祥の朗読者たちや先駆けの者たちの「ジャヤ！ジーヴァ！（勝利！長命！）」という甘美な声に続くざわめきとで――四方から揺さぶられるかのごとく、その謁見の殿堂は喧騒に満ちた。
◆ Rāja-abhyantara-praveśaḥ
◆ 王の内殿への入場・武芸・沐浴
atha visarjita-rāja-loko "viśrabhyatām" iti svayam evābhidhāya tāṃ cāṇḍāla-kanyakāṃ, "vaiśampāyanaḥ praveśyatām abhyantaram" iti tāmbūla-karaṅka-vāhinīm ādiśya, katipayāpta-rāja-putra-parivṛto nara-patir abhyantaraṃ prāviśat.
そして群臣を退出させた王は、自ら「安心せよ」とチャンダーラの娘に声を掛け、「ヴァイシャンパーヤナを内殿に入れよ」と嚼箱を運ぶ侍女に命じ、数名の信任する王子たちに囲まれて内殿に入った。
apanītābharaṇaś ca divasa-kara iva vigalita-kiraṇa-jālaḥ, candra-tārakā-samūha-śūnya iva gaganābhogaḥ, samupāhata-samucita-vyāyāmopakaraṇāṃ vyāyāma-bhūmim ayāsīt.

sa tasyāṃ ca samāna-vayobhiḥ saha rāja-putraiḥ kṛta-madhura-vyāyāmaḥ, śrama-vaśād unmiṣantībhiḥ kapolayoḥ īṣad-vadalita-sinduvāra-kusuma-mañjarī-vibhramābhiḥ, urasi nirdaya-śrama-cchinna-hāra-vigalita-muktā-phala-prakarānukāriṇībhiḥ, lalāṭa-paṭṭake aṣṭamī-candra-śakala-lolasa-dasṛta-bindu-viḍambanībhiḥ sveda-jala-kaṇikā-saṃtatibhir alaṃ-kriyamāṇa-mūrtiḥ,

ratna-karṇapūra-amātrābharaṇaḥ samucita-bhojanaiḥ saha bhūpatibhir abhimata-rasāsvāda-jāta-prītiḥ nirvartayāmāsa.
宝石の耳飾りのみを装身具とし、しかるべき食事を諸王とともに好みの味わいを楽しんで満足しつつ、食事を済ませた。

薫香の煙を吸い、漱いで嚼みものを取り、磨き上げられた宝石の床から立ち上がり――豊かな沈香の薫りが漂い、水を失った白い雲の断片を模する、花の芳香に薫らされた覆い布の絹の枕に頭を載せ、宝石の室内履きに足を置き、氷のような石板の寝台で床几を備えた――食後の休息の殿堂に赴いた。
tatra ca śayane niṣaṇṇaḥ kṣiti-talopaiṣṭāyā śanaiḥ śanair utsaṅga-nihitāsi-latayā khaḍga-vāhinyā nava-nalina-dala-komalena kara-saṃpuṭena saṃvāhyamāna-caraṇas tat-kālocita-darśanavanpatibhir amātyair mitraiś ca saha tās tāḥ kathāḥ kurvan muhūrtam ivāsāṃcakre.
そこで寝台に座り、地に座した女剣士が膝に剣の蔓を置きつつ新しい蓮の葉のごとく柔らかな手の器で静かに足を揉む中、その時刻にふさわしく参上した大臣や友人たちとさまざまな話を交わし、ほんのひとときを過ごした。

vaiśampāyanas tu svayam upajāta-kutūhalena sa-bahumānam avaṇipatinā pṛṣṭo muhūrtam iva dhyātvā sādaram abravīt — "deva, mahatīyaṃ kathā. yadi kautukam ākarṇyatām —
ヴァイシャンパーヤナは、みずから好奇心を起こして敬意をもって問う王に尋ねられ、しばしの間思案してから敬い深く語った。「王よ、これは大いなる物語でございます。もしお望みならばお聞きください――
asti pūrvāpara-jalanidhi-velāvanālaghnā madhya-deśālaṃkāra-bhūtā mekhaleva bhuvaḥ, vana-kari-kulam-ajala-seka-saṃvardhitair ativikaca-dhavala-kusuma-nikarām atyuccatayā tārakāṇām iva śikhara-pradeśa-saṃlagna-m-udvahad-bhiḥ pādapair upaśobhitā,

ity evam-ādikam asmat-saṃbaddha-ālāpam ākarṇya kiñcid-upajāta-kutūhalo bhagavāñ jābālir iṣad-avalita-kaṃdharaḥ puṇya-jalaiḥ prakṣālayann iva mām ati-praśāntayā dṛśā dṛṣṭvā suciram upajāta-pratyabhijña iva punaḥ punar vilokya 'svasyaivāvinayasya phalam anenānubhūyate' ity avocat.

ity evam upayācyamānas tapo-dhana-pariṣadā sa mahāmuniḥ pratyavadat — 'atimahad idam āścaryam ākhyātavyam. alpa-śeṣam ahaḥ. pratyāsīdati ca naḥ snāna-samayaḥ. bhavatām apy atikrāmati devārcana-vidhi-belā.
このように苦行者の集いに請われて、その大仙人は答えました。「これはきわめて大きな驚嘆すべき話で、語らねばならぬ。しかし日はもう僅かしか残っていない。われらの沐浴の時も迫っている。あなた方も神々への供養の時刻が過ぎようとしている。
tad uttiṣṭhantu bhavantaḥ. sarva evācarantu yathocitaṃ divasa-vyāpāram. aparāhna-samaye bhavatāṃ punaḥ kṛta-mūla-phalāśanānāṃ viśrāntopaviṣṭānām āditaḥ prabhṛti sarvam āvedayāmi yo 'yam, yenānena kṛtam aparasmin janmani, iha ca loke yathāsya saṃbhūtiḥ.
さあ、皆さん立たれよ。すべて然るべき日中の勤めを行われよ。午後の時に、皆さんが果実と根を食し終え、休息して座られた時に、改めて初めからすべてをお話しよう――この者が何者であるか、前世においてこの者が何をしたか、そしてこの世においてどのように生まれたかを。
ayaṃ ca tāvad apagata-klamaḥ kriyatām āhāreṇa. niyatam ayam apy ātmano janmāntarodantaṃ svapnopalabdham iva mayi kathayati sarvam aśeṣataḥ smariṣyati.' ity abhidadhad evotthāya saha munibhiḥ snānādikam ucita-divasa-vyāpāram akarot.

◆ 夕暮れの描写
anena ca samayena pariṇato divasaḥ. snānotthitena muni-janenārghya-vidhim upādayatā yaḥ kṣiti-tale dattaḥ tam ambara-tala-gataḥ sākṣād iva rakta-candanāṅga-rāgaṃ ravir udvahāt.
この間に日は傾きました。沐浴から上がった仙人たちがアルギヤ（水供養）の作法を行い、地上に捧げた（水の）赤を、空にある太陽がまるで直接受け取ったかのように、紅い栴檀の化粧を帯びていました。
udyat-saptarṣi-sārtha-sparśa-parijihīrṣayeva saṃhṛta-pādaḥ pārāvata-pāda-pāṭala-rāgo ravir ambaratalād ailambata. ālohitāṃśu-jālaṃ jala-śayana-madhya-gatasya madhuripoḥ iva galat-madhu-dhāram iva nābhi-nalinaṃ pratimāgatam aparārṇave sūrya-maṇḍalam alakṣyata.
昇り来る七仙人の群れとの接触を避けんとするかのように脚を縮め、鳩の脚のような紅い色合いの太陽が空から垂れ下がりました。赤い光線の網を放ちつつ、水の褥に横たわるヴィシュヌの臍の蓮から滴る蜜の流れのように、西の海に映る太陽の円盤が見えました。
vihāyāmbara-talam unmucya ca kamalinī-vanāni śakunaya iva divasa-avasāne taru-śikhareṣu parvatāgreṣu ca ravi-kiraṇāḥ sthitim akurvata. astam upagate ca bhagavati sahasra-dīdhitau aparārṇava-talād ullasantī vidruma-lateva pāṭalā saṃdhyā samadṛśyata.
空を離れ、蓮の園を捨てて、鳥のように日暮れに木々の梢や山の頂に、太陽の光線は止まりました。千光の主が沈むと、西の海の底から現れ出る珊瑚の蔓のような薄紅色の黄昏(サンディヤー)が見えました。
yasyām ābaddhyamāna-dhyānam, eka-deśa-duhyamāna-homa-dhenu-dugdha-dhārā-dhvanita-dhanyatarātimanoharam, agni-vedī-vikīyamāṇa-harit-kuśam āśrama-padam abhavat.
その（黄昏の）中で瞑想が結ばれ、一角で搾られる護摩の牝牛の乳の流れの音がこの上なく美しく響き、火壇に緑のクシャ草が撒かれる庵の地となりました。
acirāt proṣite savitari śoka-vidhurā kamala-mukula-kamaṇḍalu-dhāriṇī haṃsa-sita-dukūla-paridhānā mṛṇāla-dhavala-yajñopavītinī madhukara-maṇḍalākṣa-valayam udvahantī kamalinī dina-pati-samāgama-vratam avācarat.
程なく太陽が遠ざかると、悲しみに沈んだ蓮池は、蓮の蕾の水瓶を持ち、ハンサ鳥のように白い絹を纏い、蓮の茎のように白い聖紐を着け、蜂の群れの数珠を帯びて、日の主との逢瀬の誓い（サティーの行）を守りました。
kṣayam upāgatāyāṃ saṃdhyāyāṃ tad-vināśa-duḥkhitā kṛṣṇājinam iva vibhāvarī-timira-udgamam abhinavam avahat. apahāya muni-hṛdayāni sarvam anyad andhakāratāṃ timiram anayat.
黄昏が消え去ると、その滅びを悲しむかのように、黒鹿の皮のような夜の闇が新たに降り立ちました。仙人の心を除いて、他のすべてを暗闇が覆いました。

◆ 月の出
timira-mālā-vṛkṣa-lekhaṃ saptarṣi-maṇḍalādhyuṣitam arundhati-saṃcaraṇa-pūtam ekānta-sthita-cāru-tārakā-mṛgam amalokāśramam iva gaganatalaṃ a-tad-dīdhitir adhyatiṣṭhat.
闇の蔓の樹の列があり、七仙人の星座が住まい、アルンダティー星の巡りに清められ、ひとところに静かに美しい星々の鹿が棲む、清浄な庵のような空を、月が統べました。
candrābharaṇa-bhṛtaḥ tārakāpāla-śakala-laṃkṛtād ambaratala-tryambakottamāṅgād iva gaṅgā sāgarān āpūrayantī haṃsa-dhavalā dharaṇyām apataj jyotsnā.
月を飾りに戴き、星の髑髏片に飾られた、空という三つ目の神（シヴァ）の頭からガンガー川が大海を満たすように、ハンサ鳥のように白い月光が大地に降り注ぎました。
himakara-sarasi vikaca-puṇḍarīka-site candrikā-jala-pāna-lobhād avatīrṇī niścala-mūrtir amṛta-paṅka-lagna ivādṛśyata hariṇaḥ.
月の湖に咲く白蓮のように白い月光の水を飲もうとして降り立った鹿が、動かぬ姿のまま、甘露の泥に捕らわれたかのように見えました。
◆ Niśā-sabhā — Jābāli-kathā-prārambhaḥ
◆ 夜の集会 ― ジャーバーリの物語の始まり
śanaiḥ śanair dūraudite bhagavati hima-tejasi candrātapena jagatī dhavlīkṛte, ārābdha-romantham anathara-mukhaiḥ sukhāsīnair āśrama-mṛgair abhinanditāgamaneṣu pravahatshu niśā-mukha-samīraṇeṣu, ardha-yāma-mātrāvakhaṇḍitāyāṃ vibhāvaryām —
徐々に遠くへ昇った月の光に世界が白く照らされ、反芻を始めて物静かな顔の、くつろぐ庵の鹿たちがその到来を喜ぶ宵の風が吹く中、半夜（一ヤーマ半）ほどの夜が途切れなく過ぎた頃――
hārītaḥ kṛtāhāraṃ mām ādāya sarvair mahā-munibhir upasṛtya candrātapodbhāsini tapovana-eka-deśe vetrāsanopaviṣṭam bhagavantaṃ jābālim upāsata.
ハーリータは食事を終えたわたくしを手に取り、すべての大仙人たちと共に近づいて、月光に輝く苦行林の一角で、籐の座に座す尊きジャーバーリのもとに参じました。
tasyopasṛtyovacat — 'he tāta, sakaleyam āścaryaśravaṇa-kutūhala-ākulita-hṛdayā samupasthitā tāpasa-pariṣad ābaddha-maṇḍalā pratīkṣate. vyapanīta-śramaś ca kṛto 'yaṃ patatri-potaḥ. tad āvedyatāṃ yad anena kṛtam. aparasmin janmani ko 'yaṃ bhūta-bhaviṣyati ca' iti.
近づいて言いました。「父上、この驚くべき話を聞く好奇心に心をかき乱されたすべての苦行者の集いが、輪を成してお待ちしております。この鳥の雛も疲れが取れました。どうか明かしてください、この者が何をしたのか、前世においてこの者は誰であり、また何者となるのかを。」
evam uktas tu sa mahāmunir mataḥ sthitaṃ mām avalokya tāṃś ca sarvān ekāgrāc chravaṇa-parān munīn buddhvā śanaiḥ śanair abravīt — 'śrūyatāṃ yadi kutūhalam' —
このように言われると、その大仙人は傍らに置かれたわたくしを見つめ、すべての仙人たちが一心に聴くことに没頭しているのを察して、ゆっくりと語り始めました。「聞くがよい、好奇心があるならば――」
◆ Ujjayinī-varṇanam
◆ ウッジャイニーの描写
'asti sakala-tribhuvana-lalāma-bhūtā, prasava-bhūmir iva kṛta-yugasya ātma-nivāsocitā bhagavatā mahākālābhidhānena bhuvana-traya-sarga-sthiti-saṃhāra-kāriṇā pramathanāthena apareva pṛthivī samutpāditā,
「三界すべての額飾りとなる（都がある）。クリタ・ユガ（完全なる時代）の誕生の地のように、自らの住処にふさわしいとして、マハーカーラ（大いなる時）と名づけられし、三界の創造・維持・破壊をなすプラマタの主（シヴァ）によって、もう一つの大地のごとく創り出された（都がある）。
dvitīya-pṛthivī-śaṅkayā jala-nidhineva rasātala-gambhīreṇa parikhāvalayena parivṛtā, paśupati-nivāsa-astrītyā gagana-parisarollekhiśikhara-mālena kailāsa-giriṇeva sudhā-sitena prākāra-maṇḍalena parivṛtā,
第二の大地ではないかとの疑いから、大海のようにラサータラ（地底界）まで深い堀の輪に囲まれ、パシュパティ（シヴァ）の住処であるとの確信ゆえに、空に梢の列が触れるカイラーサ山のような白亜の城壁の輪に囲まれた、
prakaṭa-śaṅkha-śukti-muktā-pravāla-marakata-maṇi-śobhi-cūrṇa-sikatā-nikara-nicitarāyā mahā-vipaṇi-pathair upaśobhitā, surāsura-siddha-gandharva-vidyādhara-uragādhyāsitābhir avirata-utsava-mada-avalokana-kutūhalād ambaratalād avatīrṇābhir divya-vimāna-paṅktibhir ivālaṃkṛtā,
法螺貝・貝殻・真珠・珊瑚・エメラルド・宝石の輝く粉状の砂を敷き詰めた大きな市場の道に飾られ、神・阿修羅・仙人・ガンダルヴァ・ヴィディヤーダラ・ナーガが棲む休憩所を持ち、絶え間ない祭りを見物する好奇心から空から降りた天の飛行車の列で飾られたかのような、
mathana-udvarta-dugdha-dhavalita-mandara-dyutibhiḥ kanaka-māyāmala-kalaśa-śikharair anila-dolāyita-sita-dhvajair uparīpatad-agra-gaṅgair amara-mandirair virājita-śṛṅgāṭakā,
攪拌から迸る乳海に白く輝くマンダラ山のような黄金の宝瓶を頂きに戴き、風に揺れる白い旗を翻し、上から天のガンガーが降り注ぐかのような神殿が、四辻を輝かせる、
satatapravṛttādhyayana-dhvani-dhauta-kalmāṣā, dhārā-gṛheṣu matta-mayūrair maṇḍalī-kṛta-śikhaṇḍais tāṇḍava-vyasanibhir āvidhyamāna-kekā-kolāhalā,
絶えず行われる読誦の響きで汚れを洗い清められ、噴水殿(ダーラーグリハ)では酔った孔雀たちが尾羽を輪に広げて踊りに耽り、ケーカーの叫びの喧騒が巻き起こる、
vikaca-kuvalaya-kāntair utphulla-kumuda-dhavala-oghair animiṣa-darśana-ramaṇīyair akhaṇḍa-locanair iva sahasra-saṃkhyair udbhāsitā sarobhiḥ,
咲き誇る青蓮華の美しさと、満開の白蓮の白い流れを持ち、瞬かぬ目で見るに美しいインドラの千の目のような、千を数える池に照らし出された、
satatam samāvaddha-taraṅga-bhrukuṭi-lekhayā kham iva kṣālayāntyā siprāyā parikṣiptā,
常に結ばれた波の眉をひそめたような線で空をも洗い清めるシプラー川に囲まれた、
sakala-bhuvana-khyāta-yaśasā saṃgṛhīta-garuḍenāpi bhujaṃga-bhīruṇā khalopajīvinā api praṇayi-janopajīvyamāna-vibhavena vīreṇāpi vinayavatā priyaṃvadenāpi satya-vādinā abhirūpeṇāpi sva-dāra-saṃtuṣṭena kāmārtha-pareṇāpi dharma-pradhānena mahā-
全世界に名声を轟かせ、ガルダ（鳥）を捕らえていても蛇を恐れ（＝謙虚で）、悪人に養われても（＝悪しき臣を使役しても）親しき者の繁栄に資し、勇者でありながら礼節を備え、甘美な言葉でありながら真実を語り、美しくありながら自らの妻に満足し、欲と利に通じながらもダルマを第一とする偉大な――
sva-dāra-saṃtuṣṭenātithi-janābhyāgamārthinā api para-prārthanānabhijñena smita-pūrvābhibhāṣiṇā veda-antyena dakṣeṇa sarva-lipi-jñena mahābhārata-purāṇa-rāmāyaṇānurāgiṇā bṛhat-kathā-kuśalena vilasijanenādhiṣṭhitā — vijitāmara-loka-dyutir avantīpurī nāma nagarī.
客人の来訪を求めながらも他者に物乞いを知らず、微笑みをもって先に語りかけ、ヴェーダーンタに通じ、あらゆる文字を知り、マハーバーラタ・プラーナ・ラーマーヤナを愛し、ブリハットカターに巧みな――（そのような王に）治められた、天界の輝きを凌ぐアヴァンティープリーという名の都がある。

◆ マハーカーラ（シヴァ）の描写
yasyāṃ surāsura-cūḍāmaṇi-marīci-cumbita-caraṇa-nakha-mayūkhaḥ, niśita-śūla-dāritāndhaka-mahāsuraḥ, gaurī-nūpura-koṭi-ghṛṣṭa-śekhara-candra-śakalaḥ, tripura-bhasma-rajaḥ-kṛtāṅga-rāgaḥ, pralayānala-śekhā-kalāpa-kapila-jaṭā-bhāra-bhrānta-sura-sindhur andhakārātiḥ, bhagavān utsṛṣṭa-kailāsa-vāsa-prītiḥ mahākālābhidhānaḥ svayaṃ vasati.
そこには、神々と阿修羅の冠宝石の光に爪先の輝きを接吻され、鋭い三叉戟でアンダカ大魔を引き裂き、ガウリーの足釧の端が擦れる三日月の欠片を頭に戴き、三都の灰塵を身の装飾とし、劫末の炎の光背のような赤褐色の編髪の重みの中を天のガンガーが巡り流れ、闇の敵たる尊きマハーカーラと名づけられた方が、カイラーサに住む楽しみをも捨てて、自ら住んでおられる。
◆ Rājā Tārāpīḍaḥ
◆ ターラーピーダ王
tasyāṃ caivamvidhāyāṃ nagaryāṃ nala-nahuṣa-yayāti-dhundhumāra-bharata-bhagīratha-daśaratha-pratimaḥ, bhuja-balājita-bhū-maṇḍalaḥ, phalita-śakti-trayaḥ, matimān, utsāha-saṃpannaḥ, nīti-śāstra-viccchinna-buddhiḥ, adhīta-dharma-śāstraḥ, tṛtīya iva tejasā kāntyā ca sūryā-candramasoḥ,
このような都に、ナラ・ナフシャ・ヤヤーティ・ドゥンドゥマーラ・バラタ・バギーラタ・ダシャラタに比肩する、腕の力で大地の輪を征服し、三つの力（プラブ・マントラ・ウトサーハ）が実を結び、聡明にして、精力に満ち、政治学(ニーティ・シャーストラ)に磨かれた知性を持ち、ダルマの聖典を修め、輝きと美しさにおいて太陽と月の第三者ともいうべき――
sapta-tantu-pūtam-mūrtiḥ, upaśamita-sakala-jagad-upaplavaḥ, vihāya kamala-vanāny avagaṇayya nārāyaṇa-vakṣaḥsthala-vasati-sukham utphullāravinda-hastayā śūra-samāgamadyasaninayā nirvyājam āliṅgito lakṣmyā,
七つの政治要素(サプタ・タントゥ)に浄められた身体を持ち、全世界の災厄を鎮め、蓮の園をも捨て、ナーラーヤナの胸に住まう幸福をも顧みず、満開の蓮を手にしたラクシュミーが勇者との出会いを渇望してこの方を飾り気なく抱擁する、
sudhā-sūter iva sāgara udbhavo yaśasaḥ, graha-gaṇa iva budhānugataḥ, makara-dhvaja ivottsanna-vigrahaḥ, daśaratha iva sumitrotetaḥ, paśupati-
甘露を生む月のように大海こそ名声の源であり、惑星のようにブダ（水星＝賢者）に従われ、カーマ神のように肉体を超え（＝戦に勝ち）、ダシャラタのようにスミトラー（善友）を伴う、パシュパティ（シヴァ）の――
r iva mahāsenānuyātaḥ, bhujagarāja iva kṣamā-bhara-guruḥ, narmadā-pravāha iva mahāvaṃśa-prabhavaḥ, avatāra iva dharmasya, pratinidhir iva puruṣottamasya — parihata-prajāpīḍo rājā tārāpīḍo 'bhūt.
（シヴァ）のようにマハーセーナ（スカンダ）に随われ、蛇王のように大地の重荷を担う崇高さを持ち、ナルマダー川の流れのように偉大な家系から生まれ、ダルマの化身のごとく、プルショーッタマ（ヴィシュヌ）の代理人のごとき――民の苦しみを取り除くターラーピーダという名の王がおられた。」
