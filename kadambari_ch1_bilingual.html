カーダンバリー ― 前篇
◆ Maṅgalācaraṇam
◆ 帰敬偈
rajojuṣe janmani sattva-vṛttaye
sthitau prajānāṃ pralaye tamaḥ-spṛśe /
ajāya sarga-sthiti-nāśa-hetave
trayī-mayāya tri-guṇātmane namaḥ // 1 //
万物の誕生においてはラジャス（動性）を帯び、存続においてはサットヴァ（善性）をもって営み、滅びにおいてはタマス（暗性）に触れる者――生まれなき者、創造・維持・破壊の因たる者、三ヴェーダよりなり三グナを本性とする者に帰命す。【1】
jayanti bāṇāsura-mauli-lālita-
daśāsya-cūḍāmaṇi-cakra-cumbinaḥ /
surāsurādhīśa-śikhānta-śāyino
bhavac-chidas tryambaka-pāda-pāṃsavaḥ // 2 //
バーナースラ（バーナ魔王）の頭冠を愛撫し、ダシャーナン（ラーヴァナ）の頂上宝珠の輪に触れ、神々と阿修羅の王たちの頭頂に安らう――存在の苦を断つ三眼神（シヴァ）の御足の塵は勝利する。【2】
◆ Kavi-praśaṃsā / Kāvya-praśaṃsā
◆ 詩人讃嘆・文学讃嘆
jayaty upendraḥ sa cakāra dūrato
vibhitsayā yaḥ kṣaṇa-labdha-lakṣyayā /
dṛśaiva kopāruṇayā ripur uraḥ
svayaṃ bhayād bhinnam ivāsa-pāṭalam // 3 //
かのウペンドラ（ヴィシュヌ）は勝利する。彼は遠方より、瞬時に的を得る破壊意志をもって、怒りに赤く染まった眼差しのみによって、敵の胸を――恐怖ゆえに自ら裂けたかのごとく赤く――なしたのである。【3】
namāmi bhartuś caraṇāmbuja-dvayaṃ
sa-śikhaira-maukharibhiḥ kṛtārcanam /
samasta-sāmanta-kirīṭa-vedikā-
luṭhitāruṇāṅguli // 4 //
わが主君の二つの蓮華の御足を礼拝す。マウカリ族の一族郎党が供養を捧げ、あらゆる封臣たちの冠の台座の上を転がる紅の御指を持つその御足を。【4】
akāraṇāviṣkṛta-vaira-dāruṇād
asajjanāt tasya bhayaṃ na jāyate /
viṣaṃ mahāher iva yasya durvacaḥ
su-duḥsahaṃ saṃnihitaṃ sadā mukhe // 5 //
理由もなく敵意をあらわにする残忍な悪人に対しても、彼には恐れが生じない。大蛇の毒のごとく、耐えがたき悪言が常にその口に備わっていようとも。【5】
kaṭu kaṇanto maladāyakāḥ khalās
tudanty alaṃ bandhana-śṛṅkhalā iva /
manas tu sādhu-dhvanibhiḥ pade pade
haranti santo maṇi-nūpurā iva // 6 //
悪人は、縛鎖のごとく耳障りな音を立てて汚れを与え、はなはだしく苦しめる。しかし善人は、宝珠の足飾りのごとく、一歩ごとに美しき響きをもって心を奪い去る。【6】
subhāṣitaṃ hāri viśaty adho galān
na durjanasyārka-ripor ivāmṛtam /
tad eva dhatte hṛdayena sajjano
harir mahā-ratnam ivāti-nirmalam // 7 //
美しき言葉は、悪人の喉より下には入らない――アルカ（ラーフ）にとっての甘露のように。しかしまさにそれを、善人は心に抱く――ハリ（ヴィシュヌ）がこの上なく清らかなる大宝珠（カウストゥバ）を胸に戴くがごとく。【7】
sphurat-kalālāpa-vilāsa-komalā
karoti rāgaṃ hṛdi kautukādhikam /
rasena śayyāṃ svayam abhyupāgatā
kathā janasyābhinavā vadhūr iva // 8 //
きらめく甘き語らいの戯れにしなやかな物語は、自ら情趣をもって褥（しとね）に寄り添い来たる新妻のごとく、人の心に好奇を超えた愛着を生じさせる。【8】
haranti kaṃ nojjvala-dīpakopamair
navaiḥ padārthair upapāditāḥ kathāḥ /
nirantara-śleṣa-ghanāḥ su-jātayo
mahā-srajaś campaka-kuḍmalair iva // 9 //
輝く灯明にも似た新鮮な詩句によって飾られた物語は、誰の心を奪わずにいようか。隙間なく二義ある語（シュレーシャ）が密に連なり、良き生まれの大花鬘がチャンパカの蕾で編まれたかのようである。【9】
◆ Bāṇa-vaṃśa-varṇanam
◆ バーナの家系の描写
babhūva vātsyāyana-vaṃśa-saṃbhavo
dvijo jagad-gīta-guṇo 'graṇīḥ satām /
aneka-guptārcita-pāda-paṅkajaḥ
kubera-nāmāṃśa iva svayambhuvaḥ // 10 //
ヴァーツヤーヤナの家系に生まれ、世にその徳を歌われ、善人の中の筆頭たる一人のバラモンがいた。多くの「グプタ」（守護者）たちに御足の蓮華を供養される者――あたかもスヴァヤンブー（ブラフマー）のクベーラ（財宝神）の名を持つ分身のごとく。【10】
uvāsa yasya śruti-śānta-kalpame
sadā puroḍāśa-pavitritādhare /
sarasvatī soma-kaṣāyitodare
samasta-śāstra-smṛti-bandhure mukhe // 11 //
シュルティ（天啓聖典）の寂静なるカルパ樹のごとく、常にプローダーシャ（祭式の供物）によって清められた唇を持ち、ソーマ液に染められた腹を持ち、あらゆる学問と法典にいろどられた――その口にサラスヴァティー（弁才天）は住まった。【11】
jagur gṛhe 'bhyasta-samasta-vāṅmayaiḥ
sa-sārikaiḥ pañjara-vartibhiḥ śukaiḥ /
nigṛhyamāṇā vaṭavaḥ pade pade
yajūṃṣi sāmāni ca yasya śaṅkitāḥ // 12 //
彼の家では、あらゆる文学を習い覚えた籠の中の鸚鵡やサーリカー鳥たちがヤジュル・ヴェーダやサーマ・ヴェーダを詠唱していた。学童（ヴァタヴァ）たちは一歩ごとにそれに制止され、おそれおののきながら〔自らも〕唱えた。【12】
hiraṇyagarbho bhuvanāṇḍakād iva
kṣapākaraḥ kṣīra-mahārṇavād iva /
abhūt suparṇo vinatodарād iva
dvijanmanām artha-patiḥ patis tataḥ // 13 //
ヒラニヤガルバ（ブラフマー）が宇宙卵から生まれたかのごとく、月が乳海から生まれたかのごとく、スパルナ（ガルダ）がヴィナターの胎から生まれたかのごとく、その家系からバラモンたちの財宝の主（＝もう一人のクベーラ）たる主が生まれた。【13】
vivṛṇvato yasya visāri vāṅmayaṃ
dine dine śiṣya-gaṇā navā navāḥ /
upaḥsu lagnāḥ śravaṇe 'dhikāṃ śriyaṃ
pracakrire candana-pallavā iva // 14 //
広がりゆく学問を講説する彼のもとに、日ごとに新たな弟子の群れが加わった。朝の礼拝時に耳に付き従い、ますます美しさを増していった――チャンダナ（白檀）の新芽のように。【14】
vidhāna-saṃpādita-dāna-śobhitaiḥ
sphuran-mahā-vīra-sanātha-mūrtibhiḥ /
makhair asaṃkhyair ajayat surālayaṃ
sukhena yo yūpa-karair ajair iva // 15 //
規定通りの布施によって荘厳され、輝く大勇士に護持される形姿を持つ無数の祭祀によって、彼は天界をやすやすと征服した――祭柱を手にした山羊たち（＝不生なる者たち）のごとく。【15】
sa citrabhānuṃ tanayaṃ mahātmanāṃ
sutottamānāṃ śruti-śāstra-śālinām /
avāpa madhye sphaṭikopalopamaṃ
krameṇa kailāsam ivākṣamābhṛtām // 16 //
彼は、偉大なる者たちの優れた息子、ヴェーダと諸学に輝く者たちの中に、水晶の宝石に等しきチトラバーヌという息子を得た――山々の中にカイラーサ山を得たかのように。【16】
mahātmano yasya su-dūra-nirgatāḥ
kalaṅka-muktendu-kalāmala-tviṣaḥ /
dviṣan-manaḥ prāviviśuḥ kṛtāntarā
guṇā nṛsiṃhasya nakhāṅkurā iva // 17 //
この偉大なる者の遠方にまで達した、汚れなき月の光のごとく清らかな輝きを持つ徳は、敵の心に入り込んだ――人獅子（ナラシンハ）の爪先が〔ヒラニヤカシプの胸を〕引き裂いたかのように。【17】
diśām alīkālaka-bhaṅgatāṃ gata-
kṣayī-vadhū-karṇa-tamāla-pallavaḥ /
cakāra yasyādhvara-dhūma-saṃcayo
mailīmasaḥ śukrataraṃ nijaṃ yaśaḥ // 18 //
諸方位の額飾りの黒髪の巻き毛となり、下弦の月（クシャイー）の妻たちの耳のタマーラ葉の飾りとなったこの者の祭祀の煙の集積は、汚れたものをもさらに白くして、己の名声を輝かせた。【18】
sarasvatī-pāṇi-saroja-saṃspṛṣṭa-
homa-śrama-śīkarāmbhasaḥ /
yaśo-'ṃśu-śuklī-kṛta-sapta-viṣṭapat-
tataḥ suto bāṇa iti vyajāyata // 19 //
サラスヴァティー女神の蓮華の掌に触れられ、護摩の労苦の飛沫の水を浴び、名声の光芒によって七天界を白く染めた――その彼から息子バーナが生まれた。【19】
dvijena tenākṣata-kaṇṭha-kauṇṭhyayā
mahā-mano-moha-milīmasāndhayā /
alan-dhavaidagdhya-vilāsa-mugdhayā
dhiyā nibaddheyam atīdvayī kathā // 20 //
かのバラモン〔バーナ〕によって、喉にいささかのためらいもなく、大いなる心の迷妄を暗く霞ませ、巧みさの戯れに魅了された知によって、この二部に及ぶ比類なき物語が編まれた。【20】
◆ Kathāmukham — Śūdraka-varṇanam
◆ カタームカ（物語の枠組み） ― シュードラカ王の描写
āsīd aśeṣa-narapati-śiraḥ-samabhyarcita-śāsanaḥ pākaśāsana ivāparaḥ, catur-udadhi-mālā-mekhalāyā bhuvo bhartā, pratāpānurāgāvanata-samasta-sāmanta-cakraḥ, cakravarti-lakṣaṇopetaḥ, cakradhara-kara-kamalopālakṣyamāṇa-śaṅkha-cakrācchannaḥ,
すべての王たちが頭を垂れてその勅命を崇め奉る者、インドラ（パーカシャーサナ）のもう一人の化身のごとき者がいた。四つの大洋の花鬘を腰帯とする大地の主であり、武威と愛慕によってひれ伏すあらゆる封臣の輪を従え、転輪聖王の相を備え、チャクラダラ（ヴィシュヌ）の蓮華の御手に見出される法螺貝と円盤の印を隠し持つ者。
hara iva jita-manmathaḥ, guha ivāpratihata-śaktiḥ, kamalayonir iva vimānī-kṛta-rāja-haṃsa-maṇḍalaḥ, jaladhi iva lakṣmī-prasūtiḥ, gaṅgā-pravāha iva bhagīratha-patha-pravṛttaḥ, ravir iva prati-divasa-upajāyamānodayaḥ, merur iva sakalopajīvyamāna-pāda-cchāyāḥ, dig-gaja ivānavarata-pravṛtta-dānādrī-kṛta-karaḥ,
ハラ（シヴァ）のごとく愛の神を征服し、グハ（スカンダ）のごとく槍をもって無敵であり、カマラヨーニ（ブラフマー）のごとく王族のハンサ鳥の群れを乗物とし、大海のごとくラクシュミーを生み出し、ガンガーの流れのごとくバギーラタの道を進み、太陽のごとく日ごとに新たなる興隆をなし、メール山のごとくすべての者がその足元の陰に依り頼み、方位の象のごとく絶えず布施を施して手を濡らす者。
kartā mahāścaryāṇām, āhartā ṛtūnām, ādarśaḥ sarva-śāstrāṇām, utpattiḥ kalānām, kula-bhavanaṃ guṇānām, āgamaḥ kāvyāmṛta-rasānām, udaya-śailo mitra-maṇḍalasya, utpāta-ketur ahita-janasya,
大いなる驚異の作り手、祭祀の執行者、あらゆる学問の鏡、諸技芸の源泉、美徳の家門、詩の甘露の味の聖典、友の群れの日の出の山、敵にとっての凶兆の彗星。
pravartayitā goṣṭhī-bandhānām, āśrayo rasikānām, pratyādeśo dhanuṣmatām, dhaureyaḥ sāhasikānām, agraṇīr vidagdhānām, vainateya iva vinatānanda-jananaḥ, vainya iva cāpa-koṭi-samutsāritārāti-kulācalo rājā śūdrako nāma.
談論の結びの創始者、趣味人たちの拠り所、弓術者たちへの叱咤、大胆な者たちの先導者、粋人たちの筆頭――ヴァイナテーヤ（ガルダ）のごとくヴィナター（母）に歓びをもたらし、ヴァイニヤ（プリトゥ王）のごとく弓の端で敵の山脈を打ち払う――シュードラカという名の王がいた。
nāmnaiva yo nirbhinnārāti-hṛdayo viracita-nārasiṃha-rūpāḍambaram, eka-vikramānta-sakala-bhuvana-talaṃ vikrama-trayāyāsitaṃ bhuvana-trayaṃ ca hasati smeva vāsudevam.
名のみによって敵の心臓を貫き、人獅子（ナラシンハ）の姿の虚飾を暴いた者。ただ一つの武勇によって全地上を平定し、三歩の労を費やして三界を〔征服した〕ヴァースデーヴァ（ヴィシュヌ）をも嘲笑するかのようであった。
aticirakāla-lagnam atikrānta-nṛpati-sahasra-saṃparka-kalaṅkam iva kṣālayantī yasya kṛpāṇa-dhārā-jale ciram uvāsa lakṣmīḥ.
長き時をかけてこびりついた、過去の千人もの王との交わりの汚れを洗い流すかのように、ラクシュミー（王権の女神）は彼の剣の刃の水の中に長く住まった。
yaś ca manasi dharmeṇa, kope yamena, prasāde dhanadena, pratāpe vahninā, bhuje bhuvā, dṛśi śriyā, vāci sarasvatyā, mukhe śaśinā, bale marutā, prajñāyāṃ suraguruṇā, rūpe manasijena, tejasi savitā ca vasatā sarva-deva-mayasya prakāṭita-viśvarūpākṛter anukaroti bhagavato nārāyaṇasya.
心にはダルマが、怒りにはヤマが、恩寵にはクベーラが、威光には火神が、腕には大地が、眼にはラクシュミーが、言葉にはサラスヴァティーが、顔には月が、力にはヴァーユが、知恵にはブリハスパティが、美貌にはカーマ神が、輝きにはスーリヤが――それぞれ住まうことによって、一切の神々を体現するヴィシュヴァルーパ（宇宙の姿）を顕したバガヴァーン・ナーラーヤナに倣う者。
◆ Śūdraka-parākrama-varṇanam
◆ シュードラカ王の武勇の描写
yasya ca madakala-kari-kumbha-pīṭha-pāṭanaṃ vidadhato labdha-sthūla-muktā-phalena heḍa-muṣṭi-nipīḍanān niṣpyūta-dhārā-jala-vindu-dantureṇeva kṛpāṇenākṛṣyamāṇā, subhaṭoraḥ-kapāṭa-vighaṭita-kavaca-sahasrāndhakāra-madhyavartinī kari-karaṭa-galita-mada-jalāsāra-durdināstre bhisārikeva samara-niśāsu samīpaṃ saṃkrāntā rāja-lakṣmīḥ.
彼が酔象の額板を打ち砕くとき得られた大粒の真珠を持ち、侮蔑の拳で握り締めて噴き出す刃の水滴に覆われた剣に引き寄せられるかのように、勇士たちの胸板を打ち破り幾千もの鎧の暗闇の只中にあって、象の額から滴り落ちるマダ液の豪雨の悪天候の夜に逢瀬に赴く恋する女のごとく、戦闘の夜ごとに王権の女神ラクシュミーは彼のもとに近づき来た。
yasya ca hṛdi sthitān api bhartr̥̄n daidhakṣur iva pratāpānalo viyoginīnām api ripu-sundarīṇām antar-janita-dāho divā-niśaṃ jajvāla.
彼の武威の炎は、心中に〔かくまわれた〕夫たちをも焼き尽くさんとするかのように、離別の女たちのごとき敵の美女たちにも内なる灼熱を生じさせ、昼夜を問わず燃え盛った。
◆ Śleṣa-varṇanam
◆ シュレーシャ（双関語による王治の賛美）
yasmiṃś ca rājani jita-jagati pālayati mahīṃ citra-karmeṣu varṇa-saṃkaraḥ, rateṣu keśa-grahaḥ, kāvyeṣu dṛḍha-bandhāḥ, śāstreṣu cintā, svapneṣu vipralambhāḥ, chatrreṣu kanaka-daṇḍāḥ, dhvajeṣu prakampāḥ, gīteṣu rāgāvilasitāni, kariṣu mada-vikārāḥ, cāpeṣu guṇa-cchedāḥ, gavākṣeṣu jāla-mārgāḥ, śaśi-kṛpāṇa-kavaceṣu kalaṅkāḥ, rati-kalaheṣu dūta-preṣyaṇāni, sārtha-kṣetreṣu śūnya-gṛhā na prajānām āsan.
世界を征服して大地を治めるこの王のもとでは、臣民に以下のものは存在しなかった。――絵画においてのみヴァルナサンカラ（色の混合／身分の混交）が、情交においてのみケーシャグラハ（髪を掴むこと／苦悩に捕えられること）が、詩作においてのみドゥリダバンダ（堅固な構成／強固な束縛）が、学問においてのみチンター（思索／憂慮）が、夢においてのみヴィプラランバ（欺き／離別の情）が、日傘においてのみカナカダンダ（黄金の柄／黄金の刑罰）が、旗においてのみプラカンパ（はためき／恐怖の震え）が、歌においてのみラーガ（旋法／情欲）が、象においてのみマダヴィカーラ（発情の変調／驕慢の乱れ）が、弓においてのみグナッチェーダ（弦の断裂／美徳の断絶）が、窓においてのみジャーラマールガ（格子の通路／網の罠）が、月・剣・鎧においてのみカランカ（斑点／汚名）が、痴話喧嘩においてのみドゥータプレーシャナ（使者の派遣／密使の送付）が、隊商の野営地においてのみシューニャグリハ（空き家／虚しき家庭）が。
yasya ca paralokād bhayam, antaḥpurikā-kuntaleṣu bhaṅgaḥ, nūpureṣu mukharatā, vivāheṣu kara-grahaṇam, anavaratam aśru-pātaḥ, turaṅgeṣu kaśābhighātaḥ, makara-dhvaje cāpa-dhvanir bhūt.
また彼のもとでは次のものしかなかった。――来世からの〔帰還の〕恐怖（／来世への恐怖は無し）、後宮の女たちの巻き毛におけるバンガ（ウェーブ／破壊）、足飾りにおけるムカラター（音を立てること／饒舌）、婚礼におけるカラグラハナ（手を取ること／逮捕）、絶え間なきアシュルパータ（雨滴の落下／涙の落下）、馬におけるカシャービガータ（鞭の打撃／苦痛の打撃）、愛の神の旗印においてのみチャーパドゥヴァニ（弓の音／弓の鳴動）。
◆ Vidiśā-nagarī-varṇanam
◆ ヴィディシャーの都の描写
tasya ca rājñaḥ kali-kāla-bhaya-puñjī-bhūta-kṛta-yugānukāriṇī, tri-bhuvana-prasava-bhūmir iva vistīrṇā, mañjana-mālava-vilāsinī-kuca-taṭāsphālana-jarjaritormi-mālyā jalāvagāhenāgata-jaya-kuñjara-kumbha-sindūra-sandhyāyamāna-salilā unmada-kala-haṃsa-kula-kolāhala-mukharī-kṛta-kūlayā vetravātyā parigatā vidiśābhidhānā nagarī rājadhāny āsīt.
その王には、カリ・ユガ（暗黒時代）の恐怖を寄せ集めてクリタ・ユガ（黄金時代）を模する都があった。三界の産出の大地のごとく広大であり、マールワ地方の美女たちの乳房の斜面が打ち寄せて波の花鬘を砕き、水浴びに入った凱旋の象の額のシンドゥーラ（朱紅）に染まった水を湛え、狂酔したハンサ鳥の群れの喧騒が岸辺を賑わすヴェートラヴァティー河に囲まれた、ヴィディシャーという名の王都であった。
sa tasyām eva jitāśeṣa-bhuvana-maṇḍalatayā vigata-rājya-cintā-bhāra-nirbṛtaḥ, dvīpāntarāgatāneka-bhūpāla-mauli-mālā-lālita-caraṇa-yugalo valayam iva līlayā bhujena bhuvana-bhāram udvahan, ama-gurum api prajñayopahsadbhir aneka-kula-kramāgatair asakṛd-ālocita-nīti-śāstra-nirmala-manobhir alubdhaiḥ snigdhaiḥ prabuddhaiś cāmātyaiḥ parivṛtaḥ,
彼はその都において、あまねく世界を征服し終えた安堵から王権の重荷の憂いを離れ、他の島々から来た多くの王たちの冠の列に愛撫される両足を持ち、腕輪のごとく腕によって戯れに世界の重荷を担い、ブリハスパティ（神々の師）をも知恵で凌駕し、多くの名門から代々仕え、繰り返し政治学の典籍を吟味して清らかな心を持つ、貪欲なく、情け深く、聡明な大臣たちに囲まれ、
samāna-vayo-vidyālaṃkārair aneka-mūrdhābhiṣikta-pārthiva-kulaughitair akhila-kalā-kalāpālocana-kaṭhora-matibhir ati-pragalbhaiḥ kālavidbhiḥ premāvānurakta-hṛdayair grāmyopahāsa-kuśalair iṅghaiḥ,
同じ年齢・学識・装いを持ち、多くの灌頂を受けた王家の群れと交わり、あらゆる技芸の集積の考究によって研ぎ澄まされた知性を持ち、きわめて大胆にして、時を知り、愛と献身に満ちた心を持ち、世俗の冗談にも巧みな友人たちと、
kāvya-nāṭaka-ākhyānaka-ākhyāyikā-ālekhya-vyākhyānādi-kriyā-nipuṇair ati-kaṭhina-pīvara-skandhoru-bāhubhir asakṛd avadalita-samada-ripu-gaja-ghaṭā-pīṭha-bandhaiḥ kesari-kiśorakair iva vikramaika-rasair api vinaya-vyavahāribhir ātmanaḥ pratibimbair iva rāja-putraiḥ saha ramamāṇaḥ prathame vayasi sukham aticiram uvāsa.
詩・戯曲・物語・小説・絵画・解説等の技芸に秀で、堅く太い肩・腿・腕を持ち、幾度となく酔った敵の象群の額の結合部を打ち砕き、獅子の子のごとく武勇のみを好みつつも礼儀正しく振る舞い、王の分身のごとき王子たちとともに楽しみつつ、青年期にきわめて長く安楽に過ごした。
tasya cātivijigīṣutayā mahā-sattvatayā ca tṛṇam iva laghu-vṛtti kṣauṇam ākalayataḥ prathame vayasi vartamānasyāpi rūpavato 'pi saṃtānārthibhir amātyair apekṣitasyāpi surata-sukhasyopari dveṣa ivāsīt, satyapi rūpa-vilāsa-pahāsita-rati-vibhrame lāvaṇyavati vinayavaty anvayavati hṛdaya-hāriṇi cāvarodha-jane.
彼は極度の征服欲と大いなる雄心から、大地を草のごとく軽きものと見なしていた。青年期にあってなお容貌端麗でありながらも、跡継ぎを望む大臣たちに期待されていながらも、情交の快楽に対してはまるで嫌悪を覚えるかのようであった――たとえ後宮の婦人たちが、その美しさの戯れでラティ（愛の女神）の媚態をも凌ぎ、優美にして慎ましく、家柄よく、心を奪うものであったとしても。
