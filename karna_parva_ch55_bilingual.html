マハーバーラタ ― カルナ篇 第55章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 55 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ55」、全63詩節からなる、アルジュナによるサムシャプタカ族殺戮を描く長大な章です。サンジャヤが語る形で、サムシャプタカ軍を打ち破ったアルジュナが戦車・象・馬・歩兵を次々と倒す場面から始まり（第1〜22詩節）、クリシュナがアルジュナにカルナ討伐へ急ぐよう促し、アルジュナがそれに応じてサムシャプタカの残党を討つ場面が続きます（第23〜26詩節）。続いてクリシュナはアルジュナに、累々と横たわる屍と破壊された武具・戦車・象馬で覆われた凄惨な戦場の光景を、延々と詳細に描写しながら示します（第27〜57詩節）。場面は再びサンジャヤの語りに転じ、クリシュナがアルジュナを伴いドゥルヨーダナ軍の轟音を聞きながら進軍し、パーンディヤ王が奮戦している様を目にする場面で本章は閉じます（第58〜63詩節）。なお、本章でも冒頭の「サンジャヤは語った」の一文に余分な二重の注記「8-55-0」「8-55-0x」が付されていたため、これを第1詩節の本文に統合しています。また第57詩節と第58詩節の間には、クリシュナの語りからサンジャヤの語りへの転換を示す「サンジャヤは語った」の文言が再度現れ、これに付された注記「8-55-58x」も同様の処理によって第58詩節の本文に自然に統合されています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜54章に続き五章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、第10詩節「त्रिवेणु」のु脱落（triveṇu→trivenu）、第21詩節の余分な子音重複と脱落字（vyadhamannniśitairbāṇaiḥ kṣiprmārjunamārutaḥ等）、第30詩節のa/at混同（nataparvaṇaḥ）、第40詩節の語境界欠落と字形類似による誤記（sāṅgulitrair bhujāgraiś ca vipravidvair alaṅkṛtaiḥ）、第43詩節のa/u母音混同（buhadhā）を、それぞれ周辺文脈および類似語の照合により修正しています。第41〜42詩節にまたがる箇所には、バックティック「`」とアポストロフィ「'」による不明な引用符的記号が見られますが、この区間は和訳原典の「」（直接話法）の範囲（第28〜57詩節）とは一致せず、起源不明の編集上の痕跡であるため、推測を避けて他章と同様の正規化（バックティックをアポストロフィへ変換）のみを行い、特別な修正を加えずそのまま残しています。第22詩節および第63詩節（章末）には、詩節中間および末尾に単一ダンダの代わりに二重ダンダ（॥）が用いられている箇所がありますが、これは脱落や誤記ではなく原典の韻律構成・章末書式に基づくものと判断し、そのまま保持しています。
karṇaparva — pañcapañcāśo'dhyāyaḥ (55)
第55章
sañjaya uvāca|
pratyetya atha punar jiṣṇur jitvā saṃśaptakān babhau|
vakrānuvakragamanād aṅgāraka iva grahaḥ|| // 8-55-1 //
サンジャヤは語った。 （1） サムシャプタカ族を倒し、再び引き返して来たジシュヌ（アルジュナ）は、逆行・順行を繰り返す火星のように輝いた。
pārthabāṇahatā rājan narāśvarathakuñjarāḥ|
vicelur babhramur neśuḥ petur mamluś ca bhārata|| // 8-55-2 //
（2） バーラタよ、パールタの矢に打たれた人間・馬・戦車・象はよろめき、さまよい、倒れ、萎えた。
dhuryān dhuryetarān sūtān dhvajāṃś ca pāsisāyakān|
pāṇīn pāṇigatāñ śastrān bāhūn api śirāṃsi ca|| // 8-55-3 //
（3） 轅馬、副馬、御者、旗、弓、剣、矢、手、手にした武器、腕、そして首をも、
bhallaiḥ kṣurair ardhacandrair vatsadantaiś ca pāṇḍavaḥ|
ciccheda amitravīrāṇāṃ samare pratiyudhyatām|| // 8-55-4 //
（4） パーンダヴァは戦場で反撃する敵の勇者たちに対して、バッラ矢、剃刀矢、半月矢、ヴァツァダンタ矢で切り落とした。
taṃ pravīrās tvadīyānāṃ nardamānā'bhidudruvuḥ|
vāsitārthe yuyutsanto vṛṣabhā vṛṣabhaṃ yathā|
nipatanty arjunaṃ śūrāḥ śataśo'tha sahasraśaḥ|| // 8-55-5 //
（5） 汝の精鋭たちは叫びながら突進した。発情して雌を求めて戦おうとする雄牛が雄牛に向かうように。百人、千人とアルジュナに降りかかる勇者たち。
teṣāṃ tasya ca tad yuddham abhavad romaharṣaṇam|
trailokyavijaye yādṛg daityānāṃ saha vajriṇā|| // 8-55-6 //
（6） 彼と彼らの戦いは身の毛がよだつものであった。三界の征服を巡る阿修羅とインドラの戦いのごとくであった。
tam avidhyat tribhir bāṇair dandaśūkair iva ahibhiḥ|
ugrāyudhasya tasyāśu śiraḥ kāyād apāharat|| // 8-55-7 //
（7） 毒蛇のような三本の矢でウグラーユダを射て、素早くその首を体から切り落とした。
te'rjunaṃ sarvataḥ kruddhā nānāśastrair avīvṛṣan|
marudbhiḥ preritā meghā himavantam iva uṣṇage|| // 8-55-8 //
（8） 怒った敵たちは四方からアルジュナに様々な武器の雨を浴びせた。雨季が過ぎた後に風に押された雲がヒマラヤ山に雨を降らすように。
astrair astrāṇi saṃvārya dviṣatāṃ sarvato'rjunaḥ|
samyag astaiḥ śaraiḥ sarvān ahitān ahanad bahūn|| // 8-55-9 //
（9） アルジュナは敵の武器を武器で退け、四方から多くの矢で正確に射て全ての敵を倒した。
chinnatriveṇujaṅgheṣān hatāśvān hatasārathīn|
visrastahastatūṇīrān vicakrathaketanān|| // 8-55-10 //
（10） 轅と車台と轅棒を砕かれ、馬を殺され御者を倒され、手の防具と矢筒を散乱させ、車輪と旗を打ち砕かれた、
sañchinnaraśmiyoktrākṣān vyanukarṣayugān rathān|
vidhvastasarvasannāhān bāṇaiś cakre'rjunas tvaran|| // 8-55-11 //
（11） 手綱と繋ぎ紐と車軸を断たれ、副轅とくびきを壊された戦車を、急ぐアルジュナは矢で作り上げた。
te rathās tatra vidhvastāḥ parārdvyā bhānty anekaśaḥ|
dhaninām iva veśmāni hatāny agnyanilāmbubhiḥ|| // 8-55-12 //
（12） それらの破壊された戦車は、あちこちに散乱して、火・風・水に打ち壊された富者の屋敷のように見えた。
dvipāḥ sambhinnamarmāṇo vajrāśanisamaiḥ śaraiḥ|
petur giryagraveśmāni vajravātāgnibhir yathā|| // 8-55-13 //
（13） 雷と稲妻のような矢で急所を射抜かれた象たちは、雷・風・火に打たれた山の頂のように倒れた。
anekaiś ca śilādhautair vajrānalaviṣopamaiḥ|
śarair nijaghnivān pārtho mahendra iva dānavān|| // 8-55-14 //
（14） 石で研がれた、雷・火・毒のような数々の矢で、パールタは大インドラが阿修羅を倒すように敵を倒した。
sārohās turagāḥ petur bahavo'rjunatāḍitāḥ|
nirjihvāntrāḥ kṣitau kṣīṇā rudhirārdrāḥ sudurdṛśaḥ|| // 8-55-15 //
（15） アルジュナに打たれた騎手つきの馬は多数地面に倒れ、舌と腸をさらけ出し、地上で力尽き、血に濡れて見るに堪えなかった。
narāśvanāgā nārācaiḥ saṃsyūtāḥ savyasācinā|
babhramuś ca askhaluḥ petur nedur mamluś ca māriṣa|| // 8-55-16 //
（16） 親愛なる者よ、人間・馬・象がサヴィヤサーチンの鉄矢に縫いつけられ、よろめき、つまずき、倒れ、叫び、萎えた。
mahārhavarmābharaṇā nānārūpāmbarāyudhāḥ|
sarathāśvadvipā vīrā hatāḥ pārthena śerate|| // 8-55-17 //
（17） 高価な鎧と装飾を身につけ、様々な形の衣と武器を持ち、戦車・馬・象とともに勇者たちがパールタに倒されて横たわった。
nirbhayāḥ puṇyakarmāṇo viśiṣṭābhijanaśrutāḥ|
gatāḥ śarīrair vasudhām ūrjitaiḥ karmabhir divam|| // 8-55-18 //
（18） 恐れを知らず善行を積み、優れた家柄と名声を持つ彼らは、体は大地に伏し、その力ある行いで天に昇った。
atha arjunarathaṃ vīrās tvadīyāḥ samabhidravan|
nānājanapadādhyakṣāḥ sagaṇā jātamanyavaḥ|| // 8-55-19 //
（19） さまざまな国の領主たちが、軍勢を率い怒りに燃えて、アルジュナの戦車に突進した。
uhyamanā rathāśvebhaiḥ pattayaś ca jighāṃsavaḥ|
samabhyadhāvann asyanto vividhaṃ kṣipram āyudham|| // 8-55-20 //
（20） 戦車・馬・象に乗り、殺意に満ちた歩兵たちが、様々な武器を素早く放ちながら駆けてきた。
tad āyudhamahāvarṣaṃ kṣiptaṃ yodhamahāmbudaiḥ|
vyadhamann niśitair bāṇaiḥ kṣipram arjunamārutaḥ|| // 8-55-21 //
（21） 戦士の大雨雲から放たれた武器の大雨を、アルジュナの風は鋭い矢で素早く吹き散らした。
sāśvapattidviparathaṃ mahāśastraughasamplavam||
sahasā santitīrṣantaṃ pārthaṃ śastrāstrasetunā|| // 8-55-22 //
（22） 馬・歩兵・象・戦車という大武器の洪水を、武器と技の橋でまさに渡ろうとするパールタを。
atha abravīd vāsudevaḥ pārtha kiṃ krīḍase'nagha|
saṃśaptakān pramathya enāṃs tataḥ karṇavadhe tvara|| // 8-55-23 //
（23） ヴァースデーヴァは言った。「パールタよ、何を遊んでいる。サムシャプタカ族を片付けたら、カルナを倒すことを急げ。」
tathā iti uktvā'rjunaḥ kṛṣṇaṃ śiṣṭān saṃśaptakāṃs tadā|
kṣapayiṣyaṃs tadā bāṇair daityān indra iva avadhīt|| // 8-55-24 //
（24） 「然り」とクリシュナに答え、アルジュナは残りのサムシャプタカ族を滅ぼすべく、インドラが阿修羅を倒すように矢で殺した。
ādadat sandadhan iṣṛn dṛṣṭaḥ kaiścid raṇe'rjunaḥ|
vimuñcan vā śarāñ śīghraṃ dṛśyante vai narā hatāḥ|| // 8-55-25 //
（25） 矢をつがえ、弦を引き、放つアルジュナの姿を誰かが見たかと思えば、もう人々が倒されているのが見えるのであった。
āścaryam iti govindo bruvann aśvān acodayat|
haṃsāṃśugaurāste senāṃ haṃsāḥ sara iva aviśan|| // 8-55-26 //
（26） 「驚嘆すべきことだ」とゴーヴィンダは語りながら馬を駆った。白鳥のように白いそれらの馬は、白鳥が湖に入るように軍勢に入っていった。
tataḥ saṅgrāmabhūmiṃ tāṃ vartamāne janakṣaye|
avekṣamāṇo govindaḥ savyasācinam abravīt|| // 8-55-27 //
（27） 人の殺戮が続く戦場を見渡しながら、ゴーヴィンダはサヴィヤサーチンに語った。
eṣa pārtha mahāraudro vartate bharatakṣayaḥ|
pṛthivyāṃ pārthivānāṃ vai duryodhanakṛte mahān|| // 8-55-28 //
（28） 「パールタよ、このバーラタ族の大いなる恐ろしい殺戮は、地上の王たちのドゥルヨーダナのせいで起こったのだ。
paśya bhārata cāpāni rukmapṛṣṭhāni dhanvinām|
hatānām apaviddhāni kalāpān iṣudhīṃs tathā|| // 8-55-29 //
（29） バーラタよ、見よ。倒された弓手たちの黄金の背を持つ弓が投げ捨てられ、矢筒も同様に。
jātarūpamayaiḥ puṅkhaiḥ śarāṃś ca nataparvaṇaḥ|
tailadhautāṃś ca nārācān nirmuktān iva pannagān|| // 8-55-30 //
（30） 黄金の矢羽根のなめらかな矢、油で磨かれた鉄矢が、解き放たれた蛇のように散乱している。
ākīrṇāṃs tomarān vāhāṃś chatrān hemavibhūṣitān|
carmāṇi cāpaviddhāni rukmapṛṣṭhāni bhārata|| // 8-55-31 //
（31） バーラタよ、トマラ（投槍）、乗り物、黄金で飾られた日傘、盾が黄金の背面を見せて投げ捨てられている。
suvarṇavikṛtān prāsāñ śaktīḥ kanakabhūṣitāḥ|
jāmbūnadamayaiḥ paṭṭair baddhāś ca vipulā gadāḥ|| // 8-55-32 //
（32） 黄金細工の槍、黄金で飾られた矛、純金の帯で結ばれた大きな棍棒が。
jātarūpamayīś carṣṭīḥ paṭṭasān hemabhūṣitān|
daṇḍaiḥ kanakacitraiś ca vipraviddhān paraśvathān|| // 8-55-33 //
（33） 純金のリシュティ（槍）、黄金で飾られたパッタサ（剣）、黄金で彩られた柄のパラシュヴァタ（斧）が。
parighān bhiṇḍipālāṃś ca bhuśuṇḍīḥ kaṇapān api|
ayaskuntāṃś ca patitān musalāni gurūṇi ca|| // 8-55-34 //
（34） パリガ（鉄棒）、ビンディパーラ（投石器）、ブシュンディー（火矢）、カナパ（弩）、鉄のクンタ（槍）、重い棍棒が落ちている。
nānāvidhāni śastrāṇi pragṛhya jayagṛddhinaḥ|
jīvanta iva dṛśyante gatasatvās tarasvinaḥ|| // 8-55-35 //
（35） 様々な武器を取って勝利を求めた者たちが、命を失いながらもまだ生きているかのように見える。
gadāvimathitair gātrair musalair bhinnamastakān|
gajavājirathaiḥ kṣuṇṇān paśya yodhān sahasraśaḥ|| // 8-55-36 //
（36） 棍棒で砕かれた肢体、棍棒で割られた頭、象・馬・戦車に踏み潰された戦士たちを千人単位で見よ。
manuṣyagajavājīnāṃ śaraśaktyṛṣṭitomaraiḥ|
nistriṃśaiḥ paṭṭasaiḥ prāsair nakharair laguḍair api|| // 8-55-37 //
（37） 人間・象・馬の体が、矢・矛・リシュティ・トマラで、
śarīrair bahughā chinnaiḥ śoṇitaughapariplutaiḥ|
gatāsubhir amitraghna saṃvṛtā raṇabhūmayaḥ|| // 8-55-38 //
（38） 剣・パッタサ・槍・爪・棒で、多様に切り裂かれ血の洪水にまみれた命なき者たちで、敵を滅ぼす者よ、戦場は覆われている。
bāhubhiś candanādigdhaiḥ sāṅgadaiḥ śubhabhūṣaṇaiḥ|
satalatraiḥ sakeyūrair bhāti bhārata medinī|| // 8-55-39 //
（39） 栴檀を塗り、腕輪を着けた美しい装飾の、防具とブレスレット付きの腕で、バーラタよ、大地は輝いている。
sāṅgulitrair bhujāgraiś ca vipravidvair alaṅkṛtaiḥ|
hastihastopamaiś chinnair ūrubhiś ca tarasvinām|| // 8-55-40 //
（40） 指の防具をつけた腕の先端や、飾りのある切り落とされた、象の鼻のような太さの勇者の太腿で。
baddhacūḍāmaṇivaraiḥ śirobhiś ca sakuṇḍalaiḥ|
'nikṛttair vṛṣabhākṣāṇāṃ śarīraiś ca api saṅghaśaḥ|| // 8-55-41 //
（41） 冠の宝石を着けた王たちの耳飾りをつけた首や体の塊で。
gajavājimanuṣyāṇāṃ śaraśaktyṛṣṭitomaraiḥ|
kabandhaiḥ śoṇitādigdhaiś chinnagātraśirodharaiḥ|
bhūr bhāti bharataśreṣṭha śāntāgnibhir iva adhvare'|| // 8-55-42 //
（42） バーラタ族の最良者よ、象・馬・人間の矢・矛・リシュティ・トマラで切り裂かれた胴体と首が血にまみれ、消えた火の祭壇のように大地は輝いている。
rathāṃś ca bahudhā bhagnān hemakiṅkiṇinaḥ śubhān|
aśvāṃś ca buhadhā paśya śoṇitena pariplutān|| // 8-55-43 //
（43） 様々に壊れた黄金の鈴をつけた美しい戦車を、血にまみれた多くの馬を見よ。
anukarṣānupāsaṅgān patākā vividhān dhvajān|
yodhānāṃ ca mahāśaṅkhān pāṇḍurāṃś ca prakīrṇakān|
nirastajihvān mātaṅgāñ śayānān parvatopamān|| // 8-55-44 //
（44） 副轅、付属品、旗、様々な幟、戦士たちの大きな法螺貝、白い散乱したもの、舌を垂らし横たわる山のような象たちを。
vaijayantīr vicitrāś ca hatāṃś ca gajayodhinaḥ|
vāraṇānāṃ paristomān saṃyuktān ekakambalān|| // 8-55-45 //
（45） 勝利の旗の色鮮やかなもの、殺された象兵たち、象の覆いと連結された毛布を。
vipāṭitavicitrāś ca rūpacitrāḥ kuthās tathā|
bhinnāś ca bahudhā ghaṇṭāḥ patadbhiś cūrṇitā gajaiḥ|| // 8-55-46 //
（46） 引き裂かれた色鮮やかな敷物、壊されたさまざまな鈴、倒れて粉砕された象たちを。
vaidūryamaṇidaṇḍāṃś ca patitāṃś ca aṅkuśān bhuvi|
aśvānāṃ ca yugāpīḍān ratnacitrān uraśchadān|| // 8-55-47 //
（47） 琉璃と宝石の柄の象刺し棒が地面に落ち、馬の額当てや宝石で飾られた胸当てが。
viddhāḥ sādidhvajāgreṣu suvarṇavikṛtāḥ kuthāḥ|
vicitrān maṇicitrāṃś ca jātarūpapariṣkṛtān|| // 8-55-48 //
（48） 騎兵の旗の先端には黄金細工の刺繍の敷物が射込まれ、宝石と黄金で飾られた色鮮やかなものが。
aśvāstaraparistomān rāṅkavān patitān bhuvi|
cūḍāmaṇīn narendrāṇāṃ vicitrāḥ kāñcanasrajaḥ|
chatrāṇi cāpaviddhāni cāmaravyajanāni ca|| // 8-55-49 //
（49） 馬やラバの覆い、毛織物が地面に落ち、王たちの冠の宝石、色鮮やかな黄金の花輪、投げ捨てられた日傘やチャーマラ（払子）の扇が。
candranakṣatrabhāsaiś ca vadanaiś cārukuṇḍalaiḥ|
klṛptaśmaśrubhir atyarthaṃ vīrāṇāṃ samalaṅkṛtaiḥ|
vadanaiḥ paśya sañchannāṃ mahīṃ śoṇitakardamām|| // 8-55-50 //
（50） 月と星のように輝く美しい耳飾りをつけた、手入れされた髭の立派に飾られた勇者たちの顔で、血の泥に覆われた大地を見よ。
sajīvāṃś ca narān paśya kūjamānān samantataḥ|
upāsyamānāṃś ca bahūn nyastaśastraiś ca bhūpate|
jñātibhiś ca jalaklinnān rodamānair muhurmuhuḥ|| // 8-55-51 //
（51） まだ生きて四方からうめく者たち、武器を捨てた多くの者たちが看取られている。親族が水で濡らしながら繰り返し泣いている。
utkrāntān aparān yodhāñ chādayitvā tarasvinaḥ|
punar yuddhāya gacchanti jaye lubdhāḥ pramanyavaḥ|| // 8-55-52 //
（52） すでに死んだ戦士たちを覆い、勇猛な者たちは勝利に貪欲で怒り狂って再び戦いに向かう。
apare tatratatraiva paridhāvanti mānavāḥ|
sannivṛttāś ca te śūrā dṛṣṭā ca etān vicetasaḥ|| // 8-55-53 //
（53） またある者たちはあちこち走り回り、引き返してきた勇者たちは意識を失った者たちを見つける。
jalaṃ tyaktvā pradhāvanti krośamānāḥ parasparam|
jalaṃ pītvā mṛtān paśya pibato'nyāṃś ca bhārata|| // 8-55-54 //
（54） バーラタよ、水を捨てて互いに叫びながら走る者、水を飲んで死んだ者、飲んでいる最中の他の者を見よ。
pariṣvajya priyān anye bāndhavān bandhuvatsalāḥ|
visaṃjñān samare yodhāṃs tatratatra mahāraṇe|| // 8-55-55 //
（55） また親族を愛する者たちは戦場のあちこちで、意識を失った戦士たちの愛する親族を抱きしめている。
paśya aparān naraśreṣṭha sandaṣṭoṣṭhapuṭān punaḥ|
bhṛkuṭīkuṭilair vaktraiḥ prekṣamāṇān mahāraṇam|| // 8-55-56 //
（56） 人の最良者よ、唇を噛みしめ、眉を顰めた顔で大戦場を見つめる者たちを見よ。
etat tavaiva anurūpaṃ karma arjuna mahāhave|
divi vā devarājasya tvayā yat kṛtam āhave|| // 8-55-57 //
（57） 「アルジュナよ、まさにこのような働きは、大戦場において汝にこそふさわしい。天上でデーヴァラージャ（インドラ）の戦場でのそれと同じく。」
sañjaya uvāca|
evaṃ tāṃ darśayan kṛṣṇo yuddhabhūmiṃ kirīṭine|
gacchann eva aśṛṇoc chabdaṃ duryodhanabale mahat|| // 8-55-58 //
サンジャヤは語った。 （58） このようにクリシュナがキリーティンに戦場を見せながら進むうちに、ドゥルヨーダナ軍の中に大きな音を聞いた。
śaṅkhadundubhinirghoṣaṃ bherīpaṇavaniḥsvanam|
rathāśvanaranāgānāṃ pādaśabdāṃś ca dāruṇān|| // 8-55-59 //
（59） 法螺貝と太鼓の轟き、金鼓とパナヴァの音、戦車・馬・人間・象の恐ろしい足音を。
praviśya tad balaṃ kṛṣṇas turagair vātavegitaiḥ|
pāṇḍyena abhyarditaṃ sainyaṃ tvadīyaṃ vīkṣya vismitaḥ|| // 8-55-60 //
（60） 風のように速い馬でその軍に入ったクリシュナは、パーンディヤ王に猛攻されている汝の軍を見て驚いた。
sa hi nānāvidhair bāṇair iṣvastrapravaro yudhi|
nyahanad dviṣatāṃ pūgān gatāsūn antako yathā|| // 8-55-61 //
（61） 弓術に最も優れたその者は、戦場で様々な矢を用いて、命を終えた死神のごとく敵の群れを倒した。
gajavājimanuṣyāṇāṃ śarīrāṇi śitaiḥ śaraiḥ|
bhittvā praharatāṃ śreṣṭho videhāsūn apātayat|| // 8-55-62 //
（62） 打撃の達人は鋭い矢で象・馬・人間の体を突き破り、魂を抜いて倒した。
śatrupravīrairastrāṇi nānāśastrāṇi sāyakaiḥ|
chittvā tān avadhīc chatrūn pāṇḍyaḥ śakra iva asurān|| || // 8-55-63 //
（63） パーンディヤ王は敵の精鋭たちの武器と様々な武具を矢で断ち切り、インドラが阿修羅を倒すように敵を殺した。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcapañcāśo'dhyāyaḥ|| 55 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十五章は終わる。
