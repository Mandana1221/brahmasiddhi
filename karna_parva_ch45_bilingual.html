マハーバーラタ ― カルナ篇 第45章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 45 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ45」（ビーマセーナとカルナが一対一で激突する全51詩節の章）です。サンジャヤはビーマがカルナを討つことを誓い、勇んでカルナに向かって突進する場面から語り始めます。マドラ国王シャルヤはカルナに、ビーマの恐ろしい怒りについて警告します——アビマンユとガトートカチャが討たれたときの怒り、また潜伏中（アグニャータヴァーサ）にドラウパディーのために単身でキーチャカを討った剛力です。両者は矢を激しく撃ち合い、カルナはビーマを矢で全身血に染め昏倒させますが、シャルヤはカルナに、アルジュナがカルナ討伐を誓っている以上ビーマを討たずユディシュティラを追うべきだと進言し、カルナはビーマを戦車で退かせます。意識を取り戻したビーマセーナは、ドゥルヨーダナがドラウパディーを辱めたこと、また自らがドゥフシャーサナの舌を引き抜くと誓ったことを語り、カルナへの激しい怒りを露わにします。なお、原典の奥書（コロフォン）には第40・42〜44章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典には第1〜51詩節の行末注記が一貫して実際の詩節番号より9大きい数字（「8-45-10」〜「8-45-60」）で振られているという特異な誤記（注記番号の基準点のずれ）が見られ、さらに第1詩節の前半句にのみ別個の注記「8-45-1」が紛れ込んでいたため、これを後半句の注記（実際の基準）に統合した上で、全体に−9の補正を施して全51詩節を正しく分離・対訳しています。
karṇaparva — pañcacatvāriṃśo'dhyāyaḥ (45)
第45章
sañjaya uvāca|
tān abhidravato dṛṣṭvā pāṇḍavāṃs tāvakaṃ balam|
antamadya gamiṣyāmi tasya duḥkhasya pārṣata|| // 8-45-1 //
サンジャヤは語った。 （1）パーンダヴァたちが襲ってくるのを見て、あなた方の軍は……。〔ビーマセーナは言った〕「ドリシュタデュムナよ、私は今日、その（兄の）苦しみの終わりを告げよう。
hantāsmyadya raṇe karṇaṃ sa vā māṃ nihaniṣyati|
saṅgrāme'dya sughore'smin satyam etad bravīmi vaḥ|| // 8-45-2 //
（2）今日、戦場でカルナを殺す。さもなければ彼が私を殺すであろう。この恐ろしき戦いにおいて、これは真実であると、あなた方に告げる。
rājānam adya bhavatāṃ nyāsabhūtaṃ dadāni vai|
tasya saṃrakṣaṇe sarve yatadhvaṃ vigatajvarāḥ|| // 8-45-3 //
（3）王（ユディシュティラ）は、今日、あなた方にゆだねよう。あなた方はすべて、彼を守ることに、憂いなく努めてほしい」。
evam uktvā mahābāhuḥ prāyād ādhirathiṃ prati|
siṃhanādena mahatā sarvāḥ sannādayan diśaḥ|| // 8-45-4 //
（4）こう言って長き腕のビーマは、御者の子（カルナ）に向かって、大きな獅子吼で諸方向を震わせながら進んで行った。
dṛṣṭvā tvaritam āyāntaṃ bhīmaṃ yuddhābhinandinam|
sūtaputram atha uvāca madrāṇām īśvaro vibhuḥ|| // 8-45-5 //
（5）戦いを喜び急いで向かってくるビーマを見て、マドラ族の王シャルヤは御者の子（カルナ）に言った。
śalya uvāca|
paśya karṇa mahābāhuṃ saṅkruddhaṃ pāṇḍunandanam|
dīrghakālārjitaṃ krodhaṃ moktukāmaṃ tvayi dhruvam|| // 8-45-6 //
シャルヤは語った。 （6）「カルナよ、長き腕の激怒したパーンドゥの子（ビーマ）を見よ。長年貯えた怒りを、今、お前に対して解き放とうとしているのだ。
īdṛśaṃ nāsya rūpaṃ me dṛṣṭapūrvaṃ kadācana|
abhimanyau hate karṇa rākṣase ca ghaṭotkace|| // 8-45-7 //
（7）このような姿を、私はこれまで見たことがない。カルナよ、アビマニユが殺されたときも、鬼ガトートカチャが殺されたときも――。
trailokyasya samastasya śaktaḥ kruddho nivāraṇe|
bibharti sadṛśaṃ rūpaṃ yugāntāgnisamaprabham|| // 8-45-8 //
（8）三界全体を怒って止めるに足るほどの姿をしている。世の終わりの火にも等しい輝きを放っている」。
sañjaya uvāca|
iti bruvati rādheyaṃ madrāṇām īśvare nṛpa|
abhyavartata vai karṇaṃ krodhadīptato vṛkodaraḥ|| // 8-45-9 //
サンジャヤは語った。 （9）マドラ王がこのようにカルナに語っているあいだに、怒りに燃えるビーマ（ヴリコーダラ）がカルナに迫っていた。
athāgataṃ tu samprekṣya bhīmaṃ yuddhābhinandinam|
abravīd vacanaṃ śalyaṃ rādheyaḥ prahasan iva|| // 8-45-10 //
（10）戦いを望むビーマを見て、カルナは笑いながらシャルヤに語った。
yaduktaṃ vacanaṃ me'dya tvayā madrajaneśvara|
bhīmasenaṃ prati vibho tatsatyaṃ nātra saṃśayaḥ|| // 8-45-11 //
カルナは語った。 （11）「マドラ王よ、お前が今日私に語った言葉、ビーマセーナについてのそれは、真実である。それに疑いはない。
eṣa śūraś ca vīraś ca krodhanaś ca vṛkodaraḥ|
nirapekṣaḥ śarīre ca prāṇataś ca balādhikaḥ|| // 8-45-12 //
（12）この者は勇気と力の者、怒れる者。自らの体や命にも無頓着で、力において強者である。
ajñātavāsaṃ vasatā virāṭanagare tadā|
draupadyāḥ priyakāmena kevalaṃ bāhusaṃśrayāt|
gūḍhabhāvaṃ samāśritya kīcakaḥ sagaṇo hataḥ|| // 8-45-13 //
（13）かつてヴィラータ王の都で姿を隠して住んでいたとき、ドラウパディーを思うあまり、腕の力だけで、姿を変えたキーチャカとその一団を殺した者である。
so'dya saṅgrāmaśirasi sannaddhaḥ krodhamūrcchitaḥ|
kiṃ karodyatadaṇḍena mṛtyunāpi vrajed raṇam|| // 8-45-14 //
（14）その者が今日、戦場の先頭で武装し、怒りに我を忘れ、振り上げた死の杖のように、戦場に向かってくる。
cirakālābhilaṣito mama ayaṃ tu manorathaḥ|
arjunaṃ samare hanyāṃ māṃ vā hanyād vanañjayaḥ|| // 8-45-15 //
（15）私が長く望んでいた願いがある――『戦場でアルジュナを殺すか、アルジュナに殺されるか』というものだ。
sa me kadācid adyaiva bhaved bhīmasamāgamāt|| // 8-45-16 //
（16）それが今日、ビーマとの出会いによって叶うかもしれぬ。
nihate bhīmasene vā yadi vā virathīkṛte|
abhiyāsyati māṃ pārthas tan me sādhu bhaviṣyati|
atra yan manyase prāptaṃ tac chīghraṃ sampradhāraya|| // 8-45-17 //
（17）ビーマセーナを殺すか戦車を失わせれば、アルジュナは私に襲いかかるだろう。それは私にとって幸いである。お前がここで良いと思うことを、素早く判断せよ」。
sañjaya uvāca|
etac chrutvā tu vacanaṃ rādheyasya amitaujasaḥ|
uvāca vacanaṃ śalyaḥ sūtaputraṃ tathāgatam|| // 8-45-18 //
サンジャヤは語った。 （18）カルナの無量の力ある言葉を聞いて、シャルヤはこの御者の子に語った。
abhiyāhi mahābāho bhīmasenaṃ mahābalam|
nirapekṣaś ca yudhyasva śaktiṃ svāṃ sampradarśayan|| // 8-45-19 //
シャルヤは語った。 （19）「長き腕の者よ、大力のビーマセーナに向かって進め。無頓着に戦い、自分の力を示せ。
yas te kāmo'bhilaṣitaś cirāt prabhṛti hṛdgatataḥ|
sa vai sampatsyate karṇa satyam etad bravīmi te|| // 8-45-20 //
（20）お前が長きにわたり心の中で抱いてきた願いは、カルナよ、かなえられるだろう。これは真実である」。
evam ukte tataḥ karṇaḥ śalyaṃ punarabhāṣata|
hantā'ham enaṃ saṃrabdhaṃ māṃ vā hantā vṛkodaraḥ|| // 8-45-21 //
サンジャヤは語った。 （21）こう言われたカルナは再びシャルヤに言った。「この激した者を私が殺すか、ビーマが私を殺すか、どちらかだ」。
evam uktvā mahārāja rādheyo rathināṃ varaḥ|
yuddhe manaḥ samādhāya yāhi yāhīty acodayat|| // 8-45-22 //
（22）大王よ、こう言って戦車戦士の最上者カルナは、戦いに心を集中させ、「進め、進め！」と（御者を）促した。
tataḥ prāyād rathenāśu śalyas tatra viśāmpate|
yatra bhīmo maheṣvāso vyadrāvayata vāhinīm|| // 8-45-23 //
（23）シャルヤは戦車を駆って急いで、ビーマが軍を退かせている場所に向かった。
tatas tūryaninādaś ca bherīṇāṃ ca mahāsvanaḥ|
udatiṣṭhat ca rājendra karṇabhīmasamāgame|| // 8-45-24 //
（24）カルナとビーマの出会いにあたって、大音響の楽器、大いなる太鼓の音が高らかに鳴り響いた。
bhīmaseno'tha saṅkruddhas tasya sainyaṃ durāsadam|
nārācair vimalais tīkṣṇair diśaḥ prādrāvayad balī|| // 8-45-25 //
（25）激怒したビーマセーナは、打ち勝ちがたい彼の軍を、澄んで鋭い鉄矢で諸方向に撃ち払った。
sa sannipātas tatumulo ghorarūpo viśāmpate|
āsīd raudro mahārāja karṇapāṇḍavayor mṛdhe|| // 8-45-26 //
（26）大王よ、カルナとパーンダヴァ（ビーマ）との間には、激しい、恐ろしい衝撃があった。
tato muhūrtād rājendra nātikṛcchrād dhasan iva|
bhīmaseno mahābāhuḥ karṇaṃ prepsur abhidravat|| // 8-45-27 //
（27）やがて、しばらくして、長き腕のビーマセーナは、笑うかのように、カルナを捕えようと向かって行った。
samāpatantaṃ samprekṣya karṇo vaikartano vṛṣā|
ājaghāna susaṅkruddho nārācena stanāntare|
punaś ca enam ameyātmā śaravarṣairavākirat|| // 8-45-28 //
（28）襲いかかるビーマを見て、カルナは怒り、鉄矢を胸に放った。そしてさらに矢の雨を浴びせた。
sa vidvaḥ sūtaputreṇa cchādayāmāsa patribhiḥ|
vivyādha niśitaiḥ karṇaṃ navabhir nataparvabhiḥ|| // 8-45-29 //
（29）御者の子に射られた彼は羽根矢に覆われ、九本の節のまっすぐな鋭い矢でカルナを射た。
tasya karṇo dhanurmadhye dvidhā ciccheda patribhiḥ|| // 8-45-30 //
（30）カルナはビーマの弓の中央を二つに切り裂いた。
athainaṃ chinnadhanvānaṃ pratatya vidhyat stanāntare|
nārācena sutīkṣṇena sarvāvaraṇabhedinā|| // 8-45-31 //
（31）そして弓を失った彼の胸を、あらゆる鎧を貫く、きわめて鋭い鉄矢で射た。
so'nyat kārmukam ādāya sūtaputraṃ vṛkodaraḥ|
rājan marmasu marmajño vivyādha niśitaiḥ śaraiḥ|
nanāda balavannādaṃ kampayan iva rodasī|| // 8-45-32 //
（32）ビーマ（ヴリコーダラ）は、別の弓を取って、急所を知る者として、鋭い矢で御者の子の急所を射、大きな音を発して天地を震わせた。
tataḥ karṇaḥ pañcaviṃśatyā nārācānāṃ samārpayat|
madotkaṭaṃ vane dṛptam ulkābhir iva kuñjaram|| // 8-45-33 //
（33）するとカルナは、二十五本の鉄矢を彼に放った。森で酔って勢いづいた象を、たいまつで追い立てるかのように。
tataḥ sāyakabhinnāṅgaḥ pāṇḍavaḥ krodhamūrcchitaḥ|
saṃrambhāmarṣatāmrākṣaḥ sūtaputravadhepsayā|| // 8-45-34 //
（34）矢に体を射抜かれたパーンダヴァ（ビーマ）は、怒りに狂い、怒りと怒りで目を赤くし、御者の子を殺そうと望んだ。
sa kārmuke mahāvegaṃ bhārasādhanamuttamam|
girīṇāmapi bhettāraṃ sāyakaṃ samayojayat|| // 8-45-35 //
（35）彼は弓に大きな勢いで、山をも切り裂く、重荷を運ぶ最上の矢をつがえた。
vikṛṣya balavaccāpamākarṇādatimārutiḥ|
taṃ mumoca maheṣvāsaḥ kruddhaḥ karṇajighāṃsayā|| // 8-45-36 //
（36）大風の子（ビーマ）は強く弓を引き絞り、耳まで引いて、カルナを殺そうと怒って放った。
sa visṛṣṭo balavatā bāṇo vajrāśanisvanaḥ|
adārayad raṇe karṇaṃ vajravego yathā'calam|| // 8-45-37 //
（37）強者によって放たれた、雷のような響きをもつその矢は、雷の勢いで山を裂くように、戦場でカルナを引き裂いた。
sa bhīmasenābhihataḥ sūtaputraḥ kurūdvaha|
niṣasāda rathopasthe visaṃjñaḥ pṛtanāpatiḥ|
rudhireṇāvasiktāṅgo gatāsuvadarindamaḥ|| // 8-45-38 //
（38）クル族の誇りよ、ビーマセーナの一撃を受けた御者の子は、軍の主は戦車の上に気を失って崩れ落ちた。体を血で濡らし、敵を制する彼は死せる者のようであった。
etasminnantare dṛṣṭvā madrarājo vṛkodaram|
jighāṃsuṃ chettumāyāntaṃ sādhayan idam abravīt|| // 8-45-39 //
（39）そのとき、マドラ王はビーマを見て、殺そうと切り裂こうと進んでくるのを見て、説き諭すように言った。
bhīmasena mahābāho yathātattvaṃ vakṣyāmi tacchṛṇu|
vacanaṃ hetusampannaṃ śrutvā ca etat tathā kuru|| // 8-45-40 //
（40）「ビーマセーナよ、長き腕の者よ、私があなたに告げる言葉を、よく聞け。道理にかなった言葉を聞いて、そのとおりにせよ。
arjunena pratijñāto vadhaḥ karṇasya śuṣmiṇaḥ|
tāṃ tathā kuru bhadraṃ te pratijñāṃ savyasācinaḥ|| // 8-45-41 //
（41）アルジュナは、豪勇のカルナを殺すと誓った。あなたに幸いあれ、左手にも利くアルジュナのその誓いを、そのまま果たさせよ」。
bhīmasena uvāca|
dṛḍhavratatvaṃ pārthasya jānāmi nṛpasattama|
rājñas tu dharṣaṇaṃ pāpaḥ kṛtavān mama sannidhau|| // 8-45-42 //
ビーマセーナは語った。 （42）「王の最上者よ、アルジュナが誓いを固く守る者であることを私は知っている。だが、邪悪な者は私の目前で、王を辱めた。
tataḥ kopābhibhūtena śeṣaṃ na gaṇitaṃ mayā|
patite cāpi rādheye na me manyuḥ śamaṃ gataḥ|
jihvodvaraṇam eva asya prāptakālaṃ mataṃ mama|| // 8-45-43 //
（43）そして怒りに支配された私は、残りのことを顧みなかった。カルナが倒れたとしても、私の怒りは収まらなかった。彼の舌を引き抜くのが、今こそ時機であると私は思う。
anena sunṛśaṃsena samaveteṣu rājasu|
asmākaṃ śṛṇvatāṃ śalya yāni vākyāni mātula|
asaheyāni nīcāni bahūni śrāvitāni bho|| // 8-45-44 //
（44）この極めて非道な者は、王たちが集まる場で、我らに聞かせて、数々の耐えがたい卑しい言葉を、ああシャルヤ、叔父よ、放ったのだ。
nūnaṃ ca etat pratijñātaṃ dūrasthasya api pārthiva|
chedanaṃ cāsya jihvāyās tadaiva ākāṅkṣitaṃ mayā|
rājñas tu priyakāmena kālo'yaṃ paripālitaḥ|| // 8-45-45 //
（45）王よ、遠くにあっても、私は彼の舌を切り取ることを誓った。王を喜ばせるため、その時を待っていたのだ。
bhavatā tu yad ukto'smi vākyaṃ hetvarthasaṃhitam|
tad gṛhītaṃ mahārāja kaṭukastham iva auṣadham|| // 8-45-46 //
（46）しかしあなたが道理ある言葉を語ったので、大戦士よ、私はそれを苦い薬のように受け入れよう。
hīnapratijño bībhatsur na hi jīveta karhicit|
asmin vinaṣṭe naṣṭāḥ smaḥ sarva eva sakeśavāḥ|| // 8-45-47 //
（47）誓いを破ればアルジュナは決して生きていられない。彼が滅びれば、我らはみな、ケーシャヴァ（クリシュナ）と共に滅びる。
adya caiva nṛśaṃsātmā pāpaḥ pāpakṛtāṃ varaḥ|
gamiṣyati parībhāvaṃ dṛṣṭamātraḥ kirīṭinā|| // 8-45-48 //
（48）今日、残酷な魂の邪悪な、悪行を働く者どもの頂点に立つこの者は、アルジュナに見られただけで侮辱されるだろう。
yudhiṣṭhirasya kopena pūrvaṃ dagdho nṛśaṃsakṛt|
tvayā saṃrakṣitatastatvadya matsamīpād upāgataḥ|| // 8-45-49 //
（49）ユディシュティラの怒りによって焼き尽くされるはずだった残酷な行為者の彼は、あなたに守られて、私のそばに今日来たのだ」。
sañjaya uvāca|
' evaṃ madrādhipaḥ śrutvā visaṃjñaṃ sūtanandanam|
apovāha rathenājau karṇamāhavaśobhinam|| // 8-45-50 //
サンジャヤは語った。 （50）マドラ王はこう聞いて、意識を失ったカルナを戦場で戦車に乗せて運び去った。戦場で輝いていた彼を。
parājite tataḥ karṇe dhārtarāṣṭrī mahācamūḥ|
vyapāyāt sarvato bhagnā hāhābhūtā samantataḥ|| // 8-45-51 //
（51）カルナが敗れると、ドリタラーシュトラ方の大軍は、すっかり崩れ、「ああ」と嘆きの声をあげて諸方に逃げ去った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcacatvāriṃśo'dhyāyaḥ|| 45 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十五章は終わる。
