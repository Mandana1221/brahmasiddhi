अष्टादशः सर्गः

第十八章　激戦
Metre: Śālinī (ma-ta-ta-ga-ga) — V.1–80
V.1
Sanskrit (IAST) sañjagmāte tāv apāyānapekṣau senāmbhodhī dhīranādau rayeṇa / pakṣacchedāt pūrvam ekatra deśe vāñchantau vā vindhyasahyau niletum // 18.1 //
和訳

退却を顧みない二つの軍勢の大海は、重々しい響きをあげつつ、勢いよく衝突した。あたかも翼を切られる前に、一つの場所に腰を据えようとするヴィンディヤとサヒヤの二山のように。

注

【Vallabhadeva】

両軍の大海が激突した。退却を考えず、獅子吼の雄叫びをあげて。直喩ではなく、ヴィンディヤとサヒヤが翼を切られる前に一所に集まろうとするかのようだという想像の比喩（utprekṣā）。vā は「かのように」の意。本章の韻律は全篇シャーリニー（śālinī）。

【Mallinātha】

apāya は退却（戦場からの撤退）。niletum は「住まう」の不定詞で līṅ（付着する）からの派生。saṃjagmāte は sam 接頭辞 + gam のリト（完了形）で、「互いに合流した」の意。翼を切る前に一所に集まろうとする二山という utprekṣā であるが、比喩対象（upamāna）が周知の事実でないため純粋な直喩（upamā）ではなく想像比喩（utprekṣā）であると注記。

V.2
Sanskrit (IAST) pattiḥ pattiṃ vāham eyāya vājī nāgaṃ nāgaḥ syandanastho rathasthām / itthaṃ senā vallabhasyeva rāgād aṅgenāṅgaṃ pratyanīkasya bheje // 18.2 //
和訳

歩兵は歩兵に向かい、騎馬は騎馬に、象は象に、戦車兵は戦車兵に向かった。かくして軍勢は、恋する女が愛人の肢体を自らの肢体で抱くように、敵軍の各部隊を同種の部隊で受け止めた。

注

【Vallabhadeva】

軍勢が敵軍の各兵科を同種の兵科で迎え撃った。歩兵対歩兵、騎兵対騎兵、象対象、戦車対戦車という一対一の戦い。恋人の比喩は、女が愛する者の腿を自らの腿で、手を手で、顔を顔で抱くように、という意。eyāya は ā 接頭辞 + iṇ のリト形。

【Mallinātha】

patti は歩兵。rāgāt は戦への熱意、また恋情の意。aṅgenāṅgam は同種の部隊で対応する部隊を、また恋人の肢体を肢体で、の意。秩序を保った戦い（dharmayuddha）であり、兵種を越えた乱戦ではないことを示唆。恋人の比喩により戦闘と情事の類似を暗示する。

V.3
Sanskrit (IAST) rathyāghoṣair bṛṃhaṇair vāraṇānām aikyaṃ gacchan vājināṃ hreṣayā ca / vyomavyāpī santataṃ dundubhīnām avyakto 'bhūd īśiteva praṇādaḥ // 18.3 //
和訳

戦車群の轟音、象の咆哮、馬のいななきが渾然一体となり、太鼓の大音声は天空に満ちわたって判別不能となった。あたかも至上主のごとく――遍在し、不可分であった。

注

【Vallabhadeva】

太鼓の響きが戦車の軋み・象の咆哮・馬のいななきと混ざり合い、空一面に広がって不分明となった。ブラフマン（至上者）もまた音声をその本質とし、遍在し、不可分であることからの比喩。rathyā は「戦車の群れ」。

【Mallinātha】

rathyā は「戦車の集団」で ratha に yat 接尾辞。bṛṃhaṇa は象の喉から発する吠声。avyakta は「識別不能」であり、哲学的にはbrahmanの別名。īśitā は「支配者＝最高神」。比喩の根拠は、遍在性・不可分性・音声の本質性の三点。修辞上はkāvyaliṅga（文飾的因果）とupamāの混交。

V.4
Sanskrit (IAST) roṣāveśād gacchatāṃ pratyamitraṃ dūrotkṣiptasthūlabāhudhvajānām / dīrghās tiryag vaijayantīsadṛśyaḥ pādātānāṃ bhrejire khaḍgalekhāḥ // 18.4 //
和訳

怒りに駆られて敵に向かって突進する歩兵たちの、高く掲げた太い腕は旗竿のようであった。その手に握られた長い刀剣の線は、横たわる軍旗のように輝いた。

注

【Vallabhadeva】

歩兵の群れの刀剣の線が輝いた。怒りから敵に向かって駆ける彼らの太い腕は旗竿のよう、その刀身は横に延びて軍旗に似る。pādāta は歩兵の集合形。bhrejire は bhrāj のリト形で、etvābhyāsalopa による変化。

【Mallinātha】

pādātānām は歩兵集団。dūrotkṣipta「遠くに突き上げた」は腕の描写。腕を旗竿に、刀剣の横に延びる線を旗布に見立てる。bhrejire は bhrāj のリト形。意味的な直喩（ārthī upamā）。

V.5
Sanskrit (IAST) vardhrābaddhā dhauritena prayātām aśvīyānām uccakair uccalantaḥ / raukmā rejuḥ sthāsakā mūrtibhājo darpasyeva vyāptadehasyaśeṣāḥ // 18.5 //
和訳

疾駆する馬群の、高々と跳ね上がる革帯に留められた黄金の胸飾りが輝いた。あたかも全身に行き渡った「慢心」が、肉体を得て砕け散ったその破片のように。

注

【Vallabhadeva】

馬群の黄金の胸飾り（sthāsaka）が輝いた。革紐で繋がれ、疾駆する馬上で跳ね上がるそれらは、全身に満ちた「慢心」が具現した姿の断片のようだという想像比喩。vardhrā は「革紐」。dhaurita は馬の特定の歩法（速歩）。aśvīya は馬の集合。

【Mallinātha】

vardhrā は馬具の革帯で vṛdh から ran 接尾辞。sthāsaka は円形の胸飾り。raukmā は「黄金製の」。跳ね飛ぶ黄金の飾りを、全身に行き渡った慢心の実体化した破片と見なす utprekṣā。

V.6
Sanskrit (IAST) sāndratvakkās talpalāśliṣṭakakṣā āṅgīṃ śobhām āpnuvantaś caturthīm / kalpasyānte mārutenopanunnāś celuś caṇḍaṃ gaṇḍaśailā ivebhāḥ // 18.6 //
和訳

厚い皮膚を持ち、背骨に腹帯を密着させた象たちは、身体の第四の美――壮年の美しさ――を得て、劫末の暴風に吹き飛ばされる山の巨岩のように、猛然と進んだ。

注

【Vallabhadeva】

象たちが猛然と進発した。厚い皮膚は打撃に耐える甲冑、背に締めた腹帯を備え、身体の第四の美とは象の生涯の十二段階のうち四十歳台の壮美。劫末の風に吹き飛ばされる巨岩（gaṇḍaśailā）のようだという直喩。

【Mallinātha】

象の寿命百二十年に十二段階あり、第四段階が身体的美の頂点。sāndratvac は「密な皮膚の」で ka 接尾辞。kalpasyānte mārutena は劫末の嵐。gaṇḍaśaila は「頬のような岩」すなわち巨石、山の断崖。直喩（upamā）。

V.7
Sanskrit (IAST) saṃkrīḍantī tejitāśvasya rāgād udyamyārād agrakāyotthitasya / raṃhobhājām akṣadhūḥ syandanānāṃ hāhākāraṃ prājituḥ pratyanandat // 18.7 //
和訳

手綱を遠くから振り上げ、馬を奮い立たせた御者の「ハーハー」という掛け声に、疾走する戦車の車軸の轅が軋んで応えた。あたかも「よくぞ馬を励ました」と喜んでいるかのように。

注

【Vallabhadeva】

疾走する戦車の車軸が摩擦で軋む音を、御者の掛け声への賛同と見る想像比喩（utprekṣā）。御者が鞭を高く振り上げ、前体を起こして馬を叱咤する。akṣadhūḥ は車軸の轅。saṃkrīḍantī は「軋んでいる」の意で、sam 接頭辞 + krīḍ。

【Mallinātha】

akṣadhūḥ は車輪の支持木。prājitu は御者。saṃkrīḍantī は「摩擦音を発する」の意で、sam を伴う場合は鳴声の意が許される。御者の掛け声を車軸が嬉しそうに復唱するかのようだという utprekṣā。

V.8
Sanskrit (IAST) kurvāṇānāṃ sāmparāyāntarāyaṃ bhūreṇūnāṃ mṛtyunā mārjanāya / sammārjanyo nūnam uddhūyamānā bhānti smoccaiḥ ketanānāṃ patākāḥ // 18.8 //
和訳

戦いの障害となる大量の塵埃を、死神が掃き清めるために振るう箒こそ、高々とはためく旗竿の旗であるに違いない。

注

【Vallabhadeva】

旗布が風にはためく様を、死神が塵を掃くための箒と見る想像比喩。戦いの妨げとなる多くの塵埃を掃き清めようとしている。sammārjanyaḥ は「箒」。nūnam は「きっと～であろう」で utprekṣā の標識。

【Mallinātha】

sāmparāya は「戦い」。ketana は「旗竿」。旗布が塵を払って揺れている様を、死神が戦場を掃き清めているのだという utprekṣā。nūnam が想像比喩の標識語。

V.9
Sanskrit (IAST) udyannādaṃ dhanvibhir niṣṭhurāṇi sthūlāny uccair maṇḍalatvaṃ dadhanti / āsphālyante kārmukāṇi sma kāmaṃ hastyārohaiḥ kuñjarāṇāṃ śirāṃsi // 18.9 //
和訳

弓兵たちによって、硬く太い弓が大きく引き絞られて丸く撓み、唸りをあげる。同じく象使いたちも、象の頭を力いっぱい叩いて奮い立たせる。弓と象の頭、いずれも硬く太く、高く弧を描く。

注

【Vallabhadeva】

弓兵が弓を引き絞り、象使いが象の頭を叩く。弓も象の頭もどちらも硬く大きく、弧を描くという共通の性質から、同格の並列による修辞（tulyayogitā）。āsphālyante は弓は弦を弾く、象の頭は叩くの意。

【Mallinātha】

kārmuka は「弓」。maṇḍalatva は引き絞ることで丸くなる弓の形状、および象頭の丸みの両方に対応。niṣṭhura（硬い）・sthūla（太い）・uccai（高い）・maṇḍalatva（丸み）が弓と象の頭に共通する属性であることから、主題対象のみによる等格比喩（kevalaprakṛtāspada tulyayogitā）。

V.10
Sanskrit (IAST) ghaṇṭānādo nisvano ḍiṇḍimānāṃ graiveyāṇām āravo bṛṃhitāni / āmetīva pratyavocan gajānām utsāhārthaṃ vācam ādhoraṇasya // 18.10 //
和訳

鈴の響き、小太鼓の音、頸鎖の鳴り、象の咆哮――これらの音が象使いの叱咤の声に、「承知した」とばかりに応えたかのようであった。象たちを奮い立たせるために。

注

【Vallabhadeva】

象を激励する象使いの声に、鈴の音・小太鼓の音・頸の鎖の響き・象の吠声が「ām（然り）」と応えたかのようだという想像比喩。ām は「その通りだ」の意味の感嘆詞。graiveya は「頸に付ける装飾品・鎖」。

【Mallinātha】

ghaṇṭānāda は小鈴の音。ḍiṇḍima は太鼓の一種。graiveya は頸の鎖で、grīvā から ḍhak 接尾辞。bṛṃhita は象の吠声。ām は同意の感嘆詞で「その通りだ」の意。象使いの命令にこれらの音が唱和するかのようだという utprekṣā。

V.11
Sanskrit (IAST) yātaiś cāturvidhyam astrādibhedād avyāsaṅgaiḥ sauṣṭhavāl lāghavāc ca / śikṣāśaktiṃ prāharan darśayanto muktāmuktair āyudhair āyudhīyāḥ // 18.11 //
和訳

武器で生計を立てる戦士たちは、投擲武器と近接武器を駆使して攻撃し、弓矢・大武器などの種別によって得た四種の熟達と、優美さと敏捷さから、その修練の力を見せつけた。

注

【Vallabhadeva】

武器で生きる者たちが投擲武器（円盤など）と手持ち武器（剣など）で攻撃した。武器の四種分類は、弓（astra）・棒矛類（vyastra）・投擲武器（pāśa）・大武器（mahāstra）。sauṣṭhava は「巧みさ」、lāghava は「軽妙さ」。

【Mallinātha】

āyudhīya は「武器で生計を立てる者」。mukta は矢・円盤など投擲するもの、amukta は剣など手放さないもの。cāturvidhya は武器の四種分類から来る。sauṣṭhava は巧みさ、lāghava は素早さ。自然に備わった二つの性質の混交（saṃsṛṣṭi）。

V.12
Sanskrit (IAST) roṣāveśād ābhimukhyena kaucit pāṇigrāhaṃ raṃhasaivopayātau / hitvā hetīr mallavan muṣṭighātaṃ ghnantau bāhūbāhavi vyāsṛjetām // 18.12 //
和訳

怒りに駆られた二人の戦士が、正面から勢いよく接近し、互いに手を取り合った。武器を捨て、力士のように拳で殴り合いながら、腕と腕による格闘戦に入った。

注

【Vallabhadeva】

二人が腕と腕の格闘戦（bāhuyuddha）に及んだ。怒りから正面に突進し、手を掴み合い、武器を捨てて力士のように拳で殴り合った。pāṇigrāham は「手を掴んで」の意で ṇamul 接尾辞。muṣṭighātam も同じく ṇamul。

【Mallinātha】

kaucit はある二人の戦士。pāṇigrāham は互いの手を掴んでの意で ṇamul 接尾辞。hetīḥ は武器。mallavan は「力士のように」で vati 接尾辞による比喩。bāhūbāhavi は「腕と腕の」で ic 接尾辞（相互行為を表す）。完全な直喩（pūrṇopamā）。

V.13
Sanskrit (IAST) śuddhāḥ saṅgaṃ na kvacit prāptavanto dūrān muktāḥ śīghratāṃ darśayantaḥ / antaḥsenaṃ vidviṣām āviśanto yuktaṃ cakruḥ sāyakā vājitāyāḥ // 18.13 //
和訳

純粋にして何物にも遮られず、遠くから放たれて疾走し、敵軍の内部に突き入る――矢たちは「羽を持つもの」の名にふさわしい働きをした。

注

【Vallabhadeva】

矢が「羽のあるもの」（vājitā）の名にふさわしい行いをした。矢の属性がすべて馬にも当てはまる：純血（śuddha）、どこにも妨げられない、遠くから放たれる、速い、敵軍の中に入り込む。もう一つの読みでは、矢は馬（vājin）にふさわしい行いをした、すなわち馬のような働きをしたの意。

【Mallinātha】

śuddha は「無毒の」（矢に毒を塗らない）であり、また「純血の」の意。vājitā は「羽を持つこと」と「馬であること」の掛詞。矢の諸属性（純粋・無障碍・遠方より放つ・迅速・敵軍内部に侵入）が馬の属性と重なる。主題たる矢のみの描写で馬の連想を喚起するが、二義の意味的独立がないため掛詞ではなくkāvyaliṅga。

V.14
Sanskrit (IAST) ākramyājer agrimaskandham uccair āsthāyātho vītaśaṅkaṃ śiraś ca / helālolā vartma gatvātimartyaṃ dyām ārohan mānabhājaḥ sukhena // 18.14 //
和訳

誇り高き勇士たちは、戦場の最前線に高々と躍り上がり、次いで恐れなく頂点に立ち、人の域を超えた道を悠然と歩んで、容易く天界へと昇った。

注

【Vallabhadeva】

誇り高き者たちが苦もなく天界に昇った。戦いの前線（skandha）を攻略し、高みに立ち、恐れなく頭上（＝頂点）に至り、人間を超えた道を悠然と歩んで天に到達した。同時に、高い場所に楽に登ろうとする者が肩→頭と段階を踏んで登るように、という暗喩（samāsokti）。

【Mallinātha】

ājeḥ は「戦い」の属格。skandha は前線であり肩でもある。atimartyam vartma は人間を超える道、すなわち戦死して天界に至る道。マヌの法典にも「戦って退かぬ者は天に至る」と説かれる。肩を踏み頭に乗って高所に登る行為との類似から暗喩（samāsokti）。

V.15
Sanskrit (IAST) rodorandhraṃ vyaśnuvānāni lolair aṅgasyāntar māpitaiḥ sthāvarāṇi / kecid gurvīm etya saṃyanniṣadyāṃ krīṇanti sma prāṇamūlyair yaśāṃsi // 18.15 //
和訳

ある者たちは、大いなる市場に赴いて、命という対価で名声を買い求めた。その名声は、天地の間に広がり、不動であるのに、身体の内なる不安定なもの（命）によって量られた。

注

【Vallabhadeva】

勇士たちは大きな市場（niṣadyā＝交易場）に来て、命を代価に名声を購った。名声は天地の間に満ちて不動（sthāvara）だが、身体の内の不安定なもの（命）で計られる。不安定なものと不動のものの交換であるから、安いもので高いものを得た「下位交換」の修辞。

【Mallinātha】

rodas は天と地。niṣadyā は商いの場。lolair「不安定な」は命（prāṇa）の形容で、対する名声はsthāvara「不動」。少ない価値のもの（命）で大きなもの（名声）を得るという下位交換の修辞（nyūnaparivṛtti）。

V.16
Sanskrit (IAST) vīryotsāhaślāghi kṛtvāvadānaṃ saṅgrāmāgre mānināṃ lajjitānām / ajñātānāṃ śatrubhir yuktam uccaiḥ śrīmannāma śrāvayanti sma nagrāḥ // 18.16 //
和訳

武勇と気概を誇るにふさわしい大いなる武功を戦場の最前線で立てた、誇り高き者たちは恥じらって名を隠す。敵にも知られぬその名を、吟遊詩人たちが高らかに唱えた。

注

【Vallabhadeva】

誇り高い勇士たちは自ら名乗ることを恥じるため敵に知られていない。その栄光ある名を吟遊詩人（nagrā＝māgadha）が戦場で高らかに唱えた。自慢しない者の武功を他者が讃えるのはふさわしいこと。

【Mallinātha】

nagrāḥ は吟遊詩人（bandin）。avadāna は「偉大な武功」。lajjitānām は自ら名乗ることを恥じる誇り高き者たちの謙虚さ。敵に知られていないからこそ吟遊詩人による名の宣揚が適切であるというkāvyaliṅga（詩的因果の修辞）。

V.17
Sanskrit (IAST) ādhāvantaḥ sammukhaṃ dhāritānām anyair anye tīkṣṇakaukṣeyakāṇām / vakṣaḥpīṭhair ātsaror ātmanaiva krodhenāndhāḥ prāviśan puṣkarāṇi // 18.17 //
和訳

怒りに目が眩んだ戦士たちは、他の者たちが正面に構えた鋭い刃の盾に向かって突進し、胸板をもって柄元まで、自ら刃の中に飛び込んだ。

注

【Vallabhadeva】

怒りで盲目となった戦士たちが、敵が正面に構えた鋭い剣の刃先に、自ら胸を晒して柄元まで突き刺さった。puṣkarāṇi は「刀剣の刃先」の意。

【Mallinātha】

kaukṣeyaka は「腰に帯びるもの＝剣」で kukṣi から ḍhak 接尾辞。puṣkara は剣の刃先。ātsaroḥ は「柄まで」。怒りによる盲目が自ら刃に飛び込む原因であるというkāvyaliṅga。

V.18
Sanskrit (IAST) miśrībhūte tatra sainyadaye 'pi prāyeṇāyaṃ vyaktam āsīd viśeṣaḥ / ātmīyās te ye parāñcaḥ purastād abhyāvartī saṃmukho yaḥ paro 'sau // 18.18 //
和訳

両軍が入り混じった中でも、おおむねこの区別は明らかであった。前方で背を向けている者たちが味方、正面を向いて迫ってくる者が敵である、と。

注

【Vallabhadeva】

両軍が混在しても区別は保たれた。前方で背を向ける者は味方（前進中だから）、こちらに向かって来る者は敵。誰も逃げなかったという含意。parāñcaḥ は「背を向けている者」。

【Mallinātha】

混戦でも敵味方の識別が可能だった。parāñcaḥ（背を向けている者）は同じ方向に進む味方、abhyāvartī（こちらに向かって来る者）は敵。マヌの法典に「背を向ける者を殺すなかれ」とあり、味方を斬る危険がないことを示す。

V.19
Sanskrit (IAST) sadvaṃśatvād aṅgasaṃsaṅginītvaṃ nītvā kāmaṃ gauraveṇāvabaddhā / nītā hastaṃ vañcayitvā pareṇa drohaṃ cakre kasyacit svā kṛpāṇī // 18.19 //
和訳

良き家系の出であるがゆえに身体に寄り添い、敬われて腰に結わえられていたのに、敵に手を取られ欺かれて、ある者の自らの刀が主を裏切った。

注

【Vallabhadeva】

刀（kṛpāṇī）が人妻の暗喩で描かれる。良い出自（sadvaṃśa＝良い鋼と良い家系）、身体に密着する（腰帯と夫婦の絆）、敬いをもって結わえられる（尊重と鞘の締め）。敵に手を取られ（刀を奪われ、人妻を誘惑され）、主に対する裏切りを犯した。刀と不貞の妻の暗喩による samāsokti。

【Mallinātha】

sadvaṃśatva は「良い竹＝良い鋼」と「良い家系」の掛詞。aṅgasaṃsaṅginītva は「身体に寄り添うこと」で腰の剣と妻の両方。gauraveṇāvabaddhā は敬意をもって結ばれたこと。敵が刀を奪い取って持ち主を斬る――人妻が他の男に連れ去られ夫を裏切るように。samāsokti。

V.20
Sanskrit (IAST) nīte bhedaṃ dhautadhārābhighātād ambhodābhe śātraveṇāparasya / sāsṛgrājis tīkṣṇamārgasya mārgo vidyuddīptaḥ kaṅkaṭe lakṣyate sma // 18.20 //
和訳

敵の研ぎ澄まされた刃の一撃によって、雨雲のように黒い相手の鎧が断ち割られたとき、血に濡れた刀の軌跡が、稲妻に照らされたかのように鎧の上に浮かび上がった。

注

【Vallabhadeva】

敵の鎧（kaṅkaṭa）は雨雲のように黒い。刃の一撃で割れた鎧の上に、血に染まった刀の筋が稲妻のように光った。tīkṣṇamārga は「鋭い道＝剣」の別名。ambhodābha は「雲のような色」。

【Mallinātha】

śātrava は「敵の」で śatru から aṇ 接尾辞。dhautadhārā は「磨かれた刃」。kaṅkaṭa は鎧。sāsṛgrāji は「血の筋のある」。黒い鎧を雷雲に、血の筋を稲妻に見立てる直喩（upamā）。
