kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

pañcamaḥ sargaḥ ― 第五章

ヒマーラヤ山の描写（1-16）。詩人は第17詩節からヤクシャの口を借りて語る。ヤクシャは山の神秘的な性格、シヴァとパールヴァティーとの関係を強調し、ヴィヤーサの命に従いインドラキーラ山で苦行を行うようアルジュナに勧めて姿を消す（17-52）。
1
Sanskrit
atha jayāya nu merumahībhṛto rabhasayā nu digantadidṛkṣayā / abhiyayau sa himācalam ucchritaṃ samuditaṃ nu vilaṅghayituṃ nabhaḥ //
Drutavilambita
和訳
さて彼はかの聳え立つヒマーラヤ山へと向かった。それはメール山に勝たんがために聳えるのか、あるいは地の果てを見んとする激しい欲望のゆえか、あるいは高き天空に達せんとして聳えるのか。
2
Sanskrit
tapanamaṇḍaladīpitam ekataḥ satatanaiśatamovṛtam anyataḥ / hasitabhinnatamisracayaṃ puraḥ śivam ivānugataṃ gajacarmaṇā //
Drutavilambita
和訳
一方は太陽の光に照らされ、他方は永遠の夜闇に覆われ、前面では笑いの白さが暗闇を打ち砕く――あたかもシヴァが背に象皮を纏うかのごとき山を。

山の白い雪面をシヴァの笑いに、暗い裏面をシヴァが纏う象皮になぞらえる。シヴァは殺したアスラの象皮を背に負う。

3
Sanskrit
kṣitinabhaḥsuralokanivāsibhiḥ kṛtaniketam adṛṣṭaparasparaiḥ / prathayituṃ vibhutām abhinirmitaṃ pratinidhiṃ jagatām iva śambhunā //
Drutavilambita
和訳
地・空・天の住人たちが互いに見えぬまま住まう山。シャンブ（シヴァ）がその威力を示すため、諸世界の代理として創ったかのような山を。

三界（地・空・天）がこの一山に凝縮されているという壮大な比喩。

4
Sanskrit
bhujagarājasitena nabhaḥśriyā kanakarājivirājitasānunā / samuditaṃ nicayena taḍitvatīṃ laghayatā śaradambudasaṃhatim //
Drutavilambita
和訳
蛇王（シェーシャ）のように白く天に届く輝きをもち、金の筋に輝く山腹をもつ、その峰の連なりは、稲妻をまとう秋の雲の列を凌駕している。
5
Sanskrit
maṇimayūkhacayāṃśukabhāsurāḥ suravadhūparibhuktalatāgṛhāḥ / dadhatam uccaśilāntaragopurāḥ pura ivoditapuṣpavanā bhuvaḥ //
Drutavilambita
和訳
宝石の光線の束を衣として輝き、天女たちが楽しむ蔓の楼閣をもち、高い岩の間を城門とし、花咲く林をもつ地所を抱く山――都市のごとき山を。
6
Sanskrit
aviratojjhitavārivipāṇḍubhir virahitair aciradyutitejasā / uditapakṣam ivārataniḥsvanaiḥ pṛthunitambavilambibhir ambudaiḥ //
Drutavilambita
和訳
絶え間なく水を落として蒼白くなり、稲妻の輝きを失い、鳴り止んだ、広い裾を垂らす雲をまとって――あたかも翼を得たかのような山を。
7
Sanskrit
dadhatam ākaribhiḥ karibhiḥ kṣataiḥ samavatārasamair asamais taṭaiḥ / vividhakāmahitā mahitāmbhasaḥ sphuṭasarojavanā javanā nadīḥ //
Drutavilambita
和訳
鉱脈に富み、象に踏み荒らされ、渡り場だけが平らな比類なき断崖をもち、さまざまな望みを叶え、讃えられた水をもち、蓮の林の繁る急流を擁する山を。

この詩節はヤマカ（同音反復）の技法を駆使する。ākaribhiḥ karibhiḥ、samavatārasamair asamais、mahitāmbhasaḥ / mahitā など音の繰り返しが顕著。

8
Sanskrit
navavinidrajapākusumatviṣāṃ dyutimatāṃ nikareṇa mahāśmanām / vihitasāṃdhyamayūkham iva kvacin nicitakāñcanabhittiṣu sānuṣu //
Drutavilambita
和訳
金の壁に満ちた山腹に、咲き初めたジャパー（チャイナローズ）の花のように輝くルビーの群れが、あたかも夕映えの光を放つかのごとき山を。
9
Sanskrit
pṛthukadambakadambakarājitaṃ grathitamālatamālavanākulam / laghutuṣāratuṣārajalaścyutaṃ dhṛtasadānasadānanadantinam //
Drutavilambita
和訳
広大なカダンバの群落に輝き、連なるタマーラの森に満ち、細かい雪の水滴を滴らせ、常に光る額から歓喜液を流す象を抱く山を。

ヤマカの技法が続く。kadambakadambaka（カダンバの群落）、mālatamāla（マーラター蔓とタマーラ樹）、tuṣāratuṣāra（雪と霰）、sadānasadāna（常に・歓喜液）。

10
Sanskrit

12
Sanskrit

Drutavilambita

13
Sanskrit
vikacavāriruhaṃ dadhataṃ saraḥ sakalahaṃsagaṇaṃ śuci mānasam / śivam agātmajayā ca kṛterṣyayā sakalahaṃ sagaṇaṃ śucimānasam //
Drutavilambita
和訳
咲き誇る蓮と白鳥の群れをもつ清らかなマーナサ湖を抱き、嫉妬する山の娘（パールヴァティー）と争いつつも眷属を従えた清浄なる心のシヴァを擁する山を。

ヤマカの傑作。前半sakalahaṃsagaṇaṃ śuci mānasam（白鳥の群れをもつ清いマーナサ湖）と後半sakalahaṃ sagaṇaṃ śucimānasam（争いながらも眷属を伴い清い心のシヴァ）は同音でまったく異なる意味をもつ。パールヴァティーの嫉妬は、シヴァが頭上にガンガーを戴くことに由来する。

14
Sanskrit
grahavimānagaṇān abhito divaṃ jvalayatauṣadhijena kṛśānunā / muhur anusmarayantam anukṣapaṃ tripuradāham umāpatisevinaḥ //
Drutavilambita
和訳
薬草から生じた火が周囲の空に遊星と天の車を照らし、シヴァの従者たちに夜ごとトリプラ焼滅を思い起こさせる山を。

tripuradāha（三都焼滅）はシヴァがアスラの三つの空飛ぶ都市を焼き払った伝説。山上の発光植物がその火を連想させる。

15
Sanskrit

和訳
高い山腹から流れ落ち、岩の堤を巡り、広がる飛沫の群れを放つ水をもって、白い払子を掲げるかのごときガンガー河を擁する山を。
16
Sanskrit

Drutavilambita
和訳

和訳
「雪に白い頂で幾千もの空への道を拓くかのようなこの山の王を目にするだけで、人々の罪の集積をたちまち滅ぼすに足る。

ヤクシャの言葉
Sanskrit
iha duradhigamaiḥ kiṃcid evāgamaiḥ satatam asutaraṃ varṇayanty antaram / amum ativipinaṃ veda digvyāpinaṃ puruṣam iva paraṃ padmayoniḥ param //
Kṣamā
和訳
ここでは、難解な聖典によってさえ、常に渡りがたいその内奥はわずかしか語られない。森を越えて広がり四方に満ちるこの山を真に知るのは、至高のプルシャを知るように、蓮から生まれた者（ブラフマー）のみである。

山の広大さと至高存在の不可知性を重ねるシュレーシャ（二重意味）の修辞。antaram は「内部／本質」、āgamaiḥ は「聖典によって／到達手段によって」。

ヤクシャの言葉
Sanskrit

Praharṣiṇī
和訳

天の象アイラーヴァタの歓喜液がマンゴーの香りと酷似するため、コーキラが春と錯覚して鳴くという。

ヤクシャの言葉
Sanskrit

Jaloddhatagati
和訳

ヤマカの技法が集約された詩節。甘露（sudhā）がこの山を住処としたという、メール山に対するヒマーラヤの優位を示す。

ヤクシャの言葉
Sanskrit

ヤクシャの言葉
Sanskrit
krāmadbhir ghanapadavīm anekasaṃkhyais tejobhiḥ śucimaṇijanmabhir vibhinnaḥ / usrāṇāṃ vyabhicaratīva saptasapteḥ paryasyann iha nicayaḥ sahasrasaṃkhyām //
Praharṣiṇī
和訳
清らかな宝石から生じ、空の道を進む無数の光に混じり合って、ここでは七頭の馬をもつ者（太陽）の光線の集まりが、千という数を越えてゆくかのようである。

太陽は「千光線のもの」（sahasraraśmi）と呼ばれるが、山の宝石の光がその数を超えるという誇張。

ヤクシャの言葉
Sanskrit
vyadhatta yasmin puram uccagopuraṃ purāṃ vijetur dhṛtaye dhanādhipaḥ / sa eṣa kailāsa upāntasarpiṇaḥ karoty akālāstamayaṃ vivasvataḥ //
Vaṃśastha
和訳
その山上に、財宝の主（クベーラ）が三都の征服者（シヴァ）を喜ばせるために高い城門をもつ都を築いた――それがこのカイラーサ山であり、そばを行く太陽に季節外れの日没をもたらす。

カイラーサはクベーラの住処であり、シヴァの居所でもある。purāṃ vijetṛ（都市の征服者）はシヴァの異名（トリプラ焼滅にちなむ）。山が高すぎて太陽が時ならず隠れるという誇張。

Śālinī
和訳
さまざまな宝石の光が充満する、山腹の隠れた谷間を、壁ではないかと幾度も思わせる錯覚を、吹き込む風が幾度も打ち砕く。
37
ヤクシャの言葉
Sanskrit
ramyā navadyutir apaiti na śādvalebhyaḥ śyāmībhavanty anudinaṃ nalinīvanāni / asmin vicitrakusumastabakācitānāṃ śākhābhṛtāṃ pariṇamanti na pallavāni //
Vasantatilakā
和訳
この山では、美しい新鮮な輝きが芝から去ることはなく、蓮の林は日ごとに黒々と茂り、色とりどりの花房に飾られた樹木の若葉は枯れることがない。
38
ヤクシャの言葉
Sanskrit
parisaraviṣayeṣu līḍhamuktā haritatṛṇodgamaśaṅkayā mṛgībhiḥ / iha navaśukakomalā maṇīnāṃ ravikarasaṃvalitāḥ phalanti bhāsaḥ //
Puṣpitāgrā
和訳
この山では、太陽の光と混じった宝石の輝きが、若い鸚鵡のように柔らかく周囲に広がり、青草の芽かと錯覚した牝鹿に舐められては放たれる。
39
ヤクシャの言葉
Sanskrit
utphullasthalanalinīvanād amuṣmād uddhūtaḥ sarasijasambhavaḥ parāgaḥ / vātyābhir viyati vivartitaḥ samantād ādhatte kanakamayātapatralakṣmīm //
Praharṣiṇī
和訳
あの咲き誇る陸蓮の林から舞い上がった蓮生まれの花粉は、旋風に空中で渦を巻き、四方に広がって黄金の天蓋の美しさを呈する。
40
ヤクシャの言葉
Sanskrit
iha saniyamayoḥ surāpagāyām uṣasi sayāvakasavyapādarekhā / kathayati śivayoḥ śarīrayogaṃ viṣamapadā padavī vivartaneṣu //
Puṣpitāgrā
和訳
ここでは、天の河のほとりで朝の勤行を行うシヴァとその妃の足跡が、一体となった身体での右繞を物語る。不揃いの歩みの中、左足にはヤーヴァカ（足飾りの染料）の赤い筋がある。

シヴァとパールヴァティーはardhanārīśvara（半身半女）として一つの体を共有し火を右繞する。そのため足跡は不揃いで、左足だけがパールヴァティーの足紅で赤く染まる。

41
ヤクシャの言葉
Sanskrit
saṃmūrchatāṃ rajatabhittimayūkhajālair ālokapādapalatāntaranirgatānām / gharmadyuter iha muhuḥ paṭalāni dhāmnām ādarśamaṇḍalanibhāni samullasanti //
Vasantatilakā
和訳
銀の壁面の光の網と混じり合い、天窓の蔓草の隙間から漏れ入る太陽光の層は、ここで鏡の円盤のように幾重にも輝く。
42
ヤクシャの言葉
Sanskrit
śuklair mayūkhanicayaiḥ parivītamūrtir vaprābhighātaparimaṇḍalitorudehaḥ / śṛṅgāṇy amuṣya bhajate gaṇabhartur ukṣā kurvan vadhūjanamanaḥsu śaśāṅkaśaṅkām //
Vasantatilakā
和訳
白い光の群れに身を包まれ、丘を突いて巨体を丸くするガナの主（シヴァ）の牡牛（ナンディン）は、かの山の峰々に住まい、女たちの心に月ではないかとの疑念を起こさせる。

シヴァの乗り物ナンディンは白い牡牛で、月に見誤られるという。

43
ヤクシャの言葉
Sanskrit
samprati labdhajanma śanakaiḥ katham api laghuni kṣīṇapayasy upeyuṣi bhidāṃ jaladharapaṭale / khaṇḍitavigrahaṃ balabhido dhanur iha vividhāḥ pūrayituṃ bhavanti vibhavaḥ śikharamaṇirucaḥ //
Vaṃśapatrapatita
和訳
いま、ようやく現れた虹が、水を失い裂けた薄い雲の上で途切れた姿を見せるとき、ここでは峰々の宝石の色とりどりの輝きが、インドラの弓（虹）の欠けた身体を補うに足る。
44
ヤクシャの言葉
Sanskrit
snapitanavalatātarupravālair amṛtalavasrutiśālibhir mayūkhaiḥ / satatam asitayāminīṣu śambhor amalayatīha vanāntam indulekhā //
Puṣpitāgrā
和訳
シャンブ（シヴァ）の三日月は、若い蔓草と木の新芽を浴びせるような、甘露のしずくを滴らせる光線で、暗い夜にここの森の奥を清らかに照らし続ける。

シヴァは頭上に三日月を戴く（indumauli）。その月光が森を甘露で浄化するという。

45
ヤクシャの言葉
Sanskrit
kṣipati yo 'nuvanaṃ vitatāṃ bṛhad bṛhatikām iva raucanikīṃ rucam / ayam anekahiraṇmayakaṃdaras tava pitur dayito jagatīdharaḥ //
Drutavilambita
和訳
森ごとに広く、大きな黄金色の外衣を広げるように輝きを投げかける、多くの黄金の洞窟をもつこの山は、汝の父（インドラ）の愛する山である。

インドラキーラ山のこと。tava pitur dayitaḥ（汝の父に愛される）はアルジュナの父インドラを指す。

46
ヤクシャの言葉
Sanskrit
saktiṃ lavād apanayaty anile latānāṃ vairocanair dviguṇitāḥ sahasā mayūkhaiḥ / rodhobhuvāṃ muhur amutra hiraṇmayīnāṃ bhāsas taḍidvilasitāni viḍambayanti //
Vasantatilakā
和訳
風がわずかに蔓草の絡まりを解くや、たちまち太陽の光で倍増された黄金の崖の輝きが、かの地で稲妻の閃きを模倣する。
47
ヤクシャの言葉
Sanskrit
kaṣaṇakampanirastamahāhibhiḥ kṣaṇavimattamataṅgajavarjitaiḥ / iha madasnapitair anumīyate suragajasya gataṃ haricandanaiḥ //
Drutavilambita
和訳
ここでは、擦れた振動で大蛇が落ち去り、一瞬の恐怖に他の象が逃げ去った後、歓喜液に浸された白檀の木から、天の象（アイラーヴァタ）の通過が推測される。
48
ヤクシャの言葉
Sanskrit
jaladajālaghanair asitāśmanām upahatapracayeha marīcibhiḥ / bhavati dīptir adīpitakaṃdarā timirasaṃvaliteva vivasvataḥ //
Drutavilambita
和訳
ここでは雲の網のように濃い黒石の光線の群れに遮られ、太陽の輝きは洞窟を照らしえず、あたかも闇と混じったかのようになる。
49
ヤクシャの言葉
Sanskrit
bhavyo bhavann api muner iha śāsanena kṣātre sthitaḥ pathi tapasya hatapramādaḥ / prāyeṇa saty api hitārthakare vidhau hi śreyāṃsi labdhum asukhāni vināntarāyaiḥ //
Vasantatilakā
和訳
汝は敬虔なる者であるが、聖仙の命によりここで、クシャトリヤの道に留まりつつ、怠りなく苦行を行え。運命が善を成すとも、障害なくして福を得ることは稀であるゆえに。
50
ヤクシャの言葉
Sanskrit
mā bhūvann apathahṛtas tavendriyāśvāḥ saṃtāpe diśatu śivaḥ śivāṃ prasaktim / rakṣantas tapasi balaṃ ca lokapālāḥ kalyāṇīm adhikaphalāṃ kriyāṃ kriyāyuḥ //
Praharṣiṇī
和訳
汝の感覚という馬が邪道に引かれることなかれ。シヴァが苦行に吉祥なる成就を与えたまわんことを。世界の守護者たちが汝の力を守り、豊かな実りある吉祥の行いを完遂させんことを。」
51
Sanskrit
ity uktvā sapadi hitaṃ priyaṃ priyārhe dhāma svaṃ gatavati rājarājabhṛtye / sotkaṇṭhaṃ kim api pṛthāsutaḥ pradadhyau saṃdhatte bhṛśam aratiṃ hi sadviyogaḥ //
Praharṣiṇī
和訳
かく利と親愛の言葉を語り終え、王の中の王（クベーラ）の従者が速やかに自らの住処へ去ると、プリターの子は何事かを切なく想い耽った。善き者との別離はまことに深い悲しみを生むものである。
52
Sanskrit
tam anatiśayanīyaṃ sarvataḥ sārayogād avirahitam anekenāṅkabhājā phalena / akṛśam akṛśalakṣmīś cetasāśaṃsitaṃ sa svam iva puruṣakāraṃ śailam abhyāsasāda //
Mālinī
和訳
衰えぬ栄光をもつ彼は、心に思い描いた、その力の本質ゆえにあらゆる点で無比であり、多くの印を帯びた果実に満ち、揺るぎない山を――あたかも自らの英雄的行為そのものであるかのように――目指して進んだ。

puruṣakāra（人間の努力／英雄的行為）と山を重ねるシュレーシャ。山は「不変で、あらゆる方面に精髄を備え、多くの（鉱物の）宝を抱く」もの。英雄の自己努力もまた同様であるという。

iti bhāravikṛtau mahākāvye kirātārjunīye pañcamaḥ sargaḥ //
