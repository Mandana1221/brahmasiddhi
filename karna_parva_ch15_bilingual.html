マハーバーラタ ― カルナ篇 第15章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 15 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ15」（カルナとナクラの戦い。カルナがナクラを嘲って放免する場面。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-15-N）と和訳の段落番号が対応しています。
karṇaparva — pañcadaśo'dhyāyaḥ (15)
第15章　カルナとナクラの戦い・カルナがナクラを嘲って放免する
sañjaya uvāca|
nakulaṃ rabhasaṃ yuddhe drāvayantaṃ varūthinīm|
karṇo vaikartano rājan vārayāmāsa vai ruṣā|| // 8-15-1 //
サンジャヤは語った。 （1）王よ、戦いに猛り立ち、軍を敗走させているナクラを、ヴァイカルタナ・カルナが怒りをもって迎え撃ちました。
nakulas tu tataḥ karṇaṃ prahasann idam abravīt||
cirasya bata dṛṣṭo'haṃ daivataiḥ saumyacakṣuṣā|
yasya me tvaṃ raṇe pāpa cakṣurviṣayam āgataḥ||
tvaṃ hi mūlam anarthānāṃ vairasya kalahasya ca|
tvaddoṣāt kuravaḥ kṣīṇāḥ samāsādya parasparam|
tvām adya samare hatvā kṛtakṛtyo'smi vijvaraḥ|| // 8-15-2-4 //
（2〜4）ナクラは笑いながらカルナに言いました。「長い間、ようやく神々は優しい目で私を見てくれた。悪しき者よ、お前が戦場で私の視界に入ったからだ。お前こそすべての不幸の根源、敵意と争いの元凶。お前のせいでクル族は互いに出会って滅び合っている。今日お前を戦場で殺せば、私は目的を達し、憂いなき身となる。」
evamuktaḥ pratyuvāca nakulaṃ sūtanandanaḥ|
sadṛśaṃ rājaputrasya dhanvinaś ca viśeṣataḥ||
praharasva ca me vīra paśyāmas tava pauruṣam|
karma kṛtvā raṇe śūra tataḥ katthitumarhasi|| // 8-15-5-6 //
（5〜6）こう言われて、御者の子（カルナ）はナクラに答えました。王子にして弓兵にふさわしい言葉で——「勇者よ、まず私に打ちかかれ。お前の勇猛さを見せてもらおう。勇者よ、戦場で業を成してから、自慢するがよい。
anuktvā samare tāta śūrā yudhyanti śaktitaḥ|
prayudhyasva mayā śaktyā haniṣye darpameva te|| // 8-15-7 //
（7）友よ、戦場で勇者は大言壮語せずに力の限り戦うものだ。私と力の限り戦え。お前の驕りを打ち砕いてやろう。」
ityuktvā prāharattūrṇaṃ pāṇḍuputrāya sūtajaḥ|
vivyādha cainaṃ samare trisaptatyā śilīmukhaiḥ|| // 8-15-8 //
（8）こう言って御者の子はパーンドゥの息子に素早く攻撃を加え、七十三本の矢で射ちました。
nakulas tu tato vidvaḥ sūtaputreṇa bhārata|
aśītyā''śīviṣaprakhyaiḥ sūtaputram avidhyata|| // 8-15-9 //
（9）バーラタよ、御者の子に射たれたナクラは、毒蛇のような八十本の矢で御者の子を射返しました。
tasya karṇo dhanuś chittvā svarṇapuṅkhaiḥ śilāśitaiḥ|
triṃśatā parameṣvāsaḥ śaraiḥ pāṇḍavamardayat|| // 8-15-10 //
（10）最上の弓兵カルナは、ナクラの弓を断ち切り、金の矢尻で石に研がれた三十本の矢でパーンダヴァを攻め立てました。
te tasya kavacaṃ bhittvā papuḥ śoṇitam āhave|
āśīviṣā yathā nāgā bhittvā gāṃ salilaṃ papuḥ|| // 8-15-11 //
（11）それらの矢は鎧を貫いて、戦場でナクラの血を飲みました。毒蛇が大地を貫いて水を飲むように。
athānyad dhanurādāya hemapṛṣṭhaṃ durāsadam|
karṇaṃ vivyādha saptatyā sārathiñ ca tribhiḥ śaraiḥ|| // 8-15-12 //
（12）ナクラは別の金の背板がついた近づき難い弓を取り、七十本の矢でカルナを射ち、三本で御者を射ちました。
tataḥ kruddho mahārāja nakulaḥ paravīhā|
kṣurapreṇa sutīkṣṇena karṇasya dhanurācchinat|| // 8-15-13 //
（13）大王よ、怒った敵を倒すナクラは、鋭い剃刀の矢でカルナの弓を断ち切りました。
athainaṃ chinnadhanvānaṃ sāyakānāṃ śatais tribhiḥ|
ājaghne prahasan vīraḥ sarvalokamahāratham|| // 8-15-14 //
（14）弓を失ったカルナに、勇者ナクラは笑いながら三百本の矢を浴びせかけました。全世界の偉大な戦車戦士である者に。
karṇamabhyarditaṃ dṛṣṭvā pāṇḍuputreṇa māriṣa|
vismayaṃ paramaṃ jagmurṛṣayaḥ saha daivataiḥ|| // 8-15-15 //
（15）パーンドゥの息子にカルナが苦しめられるのを見て、聖仙たちと天の神々は最高の驚嘆に達しました。
athānyad dhanurādāya karṇo vaikartanas tadā|
nakulaṃ pañcabhir bāṇair jatrudeśe samārpayat|| // 8-15-16 //
（16）カルナは別の弓を取り、ナクラの鎖骨のあたりに五本の矢を打ち込みました。
urasthairatha tair bāṇair mādrīputro vyarocata|
svaraśmibhir ivādityo bhuvane visṛjan prabhām|| // 8-15-17 //
（17）胸に矢を受けたマードリーの息子は、太陽がその光線で世に輝きを放つかのように美しく輝きました。
nakulas tu tataḥ karṇaṃ vidvvā saptabhir āśugaiḥ|
athāsya dhanuṣaḥ koṭiṃ punaś ciccheda māriṣa|| // 8-15-18 //
（18）ナクラは七本の素早い矢でカルナを射ち、さらにカルナの弓の先端を再び断ち切りました。
so'nyat kārmukam ādāya samare vegavattaram|
nakulasya tato bāṇaiḥ samantāc chādayad diśaḥ|| // 8-15-19 //
（19）カルナは戦場でより速い別の弓を取り、矢でナクラの四方の空を覆い尽くしました。
sañchādyamānaḥ sahasā karṇacāpacyutaiḥ śaraiḥ|
ciccheda sa śarāṃs tūrṇaṃ śaraireva mahārathaḥ|| // 8-15-20 //
（20）カルナの弓から飛び出す矢に突然覆われながらも、偉大な戦車戦士ナクラは矢で矢を素早く切り落としました。
tato bāṇamayaṃ jālaṃ vitataṃ vyomnyadṛśyata|
khadyotānām iva vrātaiḥ sampatadbhir yathā nabhaḥ|| // 8-15-21 //
（21）矢の網が空に広がり、蛍の群れが飛び交う夜空のようでした。
tairvimuktaiḥ śaraśataiś chāditaṃ gaganaṃ tadā|
śalabhānāṃ yathā vrātais tadvad āsīd viśāmpate|| // 8-15-22 //
（22）放たれた何百もの矢で覆われた空は、イナゴの群れのようでした、王よ。
te śarā hemavikṛtāḥ sampantau muhurmuhuḥ|
śreṇīkṛtā vyakāśānta krauñcāḥ śreṇīkṛtā iva|| // 8-15-23 //
（23）金で飾られた矢は何度も何度も飛び交い、列を組んで、まるで列をなしたクラウンチャ鶴のように輝きました。
bāṇajālavṛte vyomni cchādite ca divākare|
na sma sampatate bhūtaṃ kiñcid apy antarikṣagam|| // 8-15-24 //
（24）矢の網で空が覆われ、太陽が隠された時、空を飛ぶ生き物は何一つ飛ぶことができませんでした。
nirudve tatra mārge ca śarasaṅghaiḥ samantataḥ|
vyarocetāṃ mahātmānau kālasūryāv iva uditau|| // 8-15-25 //
（25）矢の群れで四方の道が塞がれた中、二人の偉大なる魂の者は、終末の二つの太陽が昇ったかのように輝きました。
karṇacāpacyutair bāṇair vadhyamānās tu somakāḥ|
avālīyanta rājendra vedanārtā bhūśārditāḥ|| // 8-15-26 //
（26）カルナの弓から放たれる矢に打たれたソーマカ族の者たちは、王の中の王よ、苦しみに耐えかねて身を伏せました。
nakulasya tathā bāṇair hanyamānā camūs tava|
vyaśīryata diśo rājan vātanunnā iva ambudāḥ|| // 8-15-27 //
（27）同様に、ナクラの矢に打たれるあなたの軍は、王よ、四方に散り散りになりました。風に吹き散らされた雲のように。
te sene hanyamāne tu tābhyāṃ divyairmahāśaraiḥ|
śarapātamapākramya tasthatuḥ prekṣike tadā|| // 8-15-28 //
（28）両軍がこの二人の神聖な大いなる矢に打たれると、矢の届かぬ場所に退いて、観戦の位置につきました。
protsāritajane tasmin karṇapāṇḍavayoḥ śaraiḥ|
avidhyetāṃ mahātmānāv anyonyaṃ śaravṛṣṭibhiḥ|| // 8-15-29 //
（29）カルナとパーンダヴァの矢によって人々が追い払われた広い場所で、二人の偉大なる魂の者は矢の雨で互いを射ち合いました。
vidarśayantau divyāni śastrāṇi raṇamūrdhani|
chādayantau ca sahasā parasparavadhaiṣiṇau|| // 8-15-30 //
（30）互いの殺害を望み、戦場の最前線で神聖な武器を見せつけ合い、突然互いを覆い尽くしました。
nakulena śarā muktā kaṅkabarhiṇavāsasaḥ|
sūtaputram avacchādya vyatiṣṭhanta yathā'mbare|| // 8-15-31 //
（31）ナクラが放った鷺と孔雀の羽根の矢は、御者の子を覆ってから、空に留まりました。
tathaiva sūtaputreṇa preṣitāḥ paramāhave|
pāṇḍuputram avacchādya vyatiṣṭhanta ambare śarāḥ|| // 8-15-32 //
（32）同様に、御者の子が大戦闘で放った矢も、パーンドゥの子を覆ってから、空に留まりました。
śaraveśmapraviṣṭau tau dadṛśāte na kaiścana|
sūryācandramasau rājañ chādyamānau ghanair iva|| // 8-15-33 //
（33）矢の家に入り込んだ二人は、誰にも見えなくなりました。王よ、太陽と月が雲に覆い隠されるように。
tataḥ kruddho raṇe karṇaḥ kṛtvā ghorataraṃ vapuḥ|
pāṇḍavaṃ chādayāmāsa samantāc charavṛṣṭibhiḥ|| // 8-15-34 //
（34）そこでカルナは戦場で怒り、さらに恐ろしい姿となって、パーンダヴァを四方から矢の雨で覆い尽くしました。
so'ticchanno mahārāja sūtaputreṇa pāṇḍavaḥ|
na cakāra vyathāṃ rājan bhāskaro jaladair yathā|| // 8-15-35 //
（35）大王よ、御者の子に覆い尽くされたパーンダヴァは、王よ、少しも苦しみを見せませんでした。太陽が雲に覆われても何の影響もないように。
tataḥ prahasyādhirathiḥ śarajālāni māriṣa|
preṣayāmāsa samare śataśo'tha sahasraśaḥ|| // 8-15-36 //
（36）そこでアディラタの子（カルナ）は笑いながら、矢の網を何百、何千と戦場で放ちました。
ekacchāyam abhūt sarvaṃ tasya bāṇair mahātmanaḥ||
abhracchāyā iva sañjajñe sampatadbhiḥ śarottamaiḥ|| // 8-15-37 //
（37）偉大なる魂のその矢によって、すべてが一つの影に覆われました。飛び交う最上の矢は雲の影のようでした。
tataḥ karṇo mahārāja dhanuś chittvā mahātmanaḥ|
sārathiṃ pātayāmāsa rathanīḍād vasann iva|| // 8-15-38 //
（38）大王よ、カルナは偉大なる魂（ナクラ）の弓を断ち切り、御者を戦車から叩き落としました。
tato'śvāṃś chaturaś cāsya caturbhir niśitaiḥ śaraiḥ|
yamasya bhavanaṃ tūrṇaṃ preṣayāmāsa bhārata|| // 8-15-39 //
（39）そしてナクラの四頭の馬を四本の鋭い矢で素早く閻魔の館に送りました、バーラタよ。
athāsya taṃ rathaṃ divyaṃ tilaśo vyadhamac charaiḥ|
patākāṃ cakrarakṣāṃś ca gadāṃ khaṅgaṃ ca māriṣa|| // 8-15-40 //
（40）そしてナクラの神聖な戦車を粉々に矢で砕きました——旗も車輪の守りも棍棒も剣も。
śatacandraṃ ca taccarma sarvāpakaraṇāni ca|
suvarṇavikṛtaṃ tac ca dhanuḥ śaram āhave|| // 8-15-41 //
（41）百の月を描いた盾も、すべての装備も、金で飾られた弓と矢も。
hatāśvo virathaś caiva vivarmā ca viśāmpate|
avatīrya rathāt tūrṇaṃ parighaṃ gṛhya dhiṣṭhitaḥ|| // 8-15-42 //
（42）馬を失い、戦車を失い、鎧も失った王よ、ナクラは素早く戦車から飛び降り、鉄棒を手に取って立ちました。
tamudyataṃ mahāraghoraṃ parighaṃ tasya sūtajaḥ|
vyahanat sāyakair rājan sutīkṣṇair bhārasādhanaiḥ|| // 8-15-43 //
（43）王よ、御者の子は、振り上げられた大きく恐ろしい鉄棒を、鋭く重い矢で打ち砕きました。
vyāyudhaṃ cainamālakṣya śaraiḥ sannataparvabhiḥ|
ārpayadbahubhiḥ karṇo na cainaṃ samapīḍayat|| // 8-15-44 //
（44）武器を失ったナクラを見て、カルナはしなやかな矢を何本も浴びせかけましたが、彼を殺しはしませんでした。
sa hanyamānaḥ samare kṛtāstreṇa balīyasā|
prādravat sahasā rājan nakulo vyākulendriyaḥ|| // 8-15-45 //
（45）王よ、武器の達人にして力の勝る者に戦場で打たれ、ナクラは感覚を乱して突然逃げ出しました。
tamabhidrutya rādheyaḥ prahasan vai punaḥpunaḥ|
sajyamasya dhanuḥ kaṇṭhe vyavāsṛjata bhārata|| // 8-15-46 //
（46）ラーデーヤ（カルナ）はナクラを追いかけ、何度も何度も笑いながら、弦を張ったままの弓をナクラの首にかけてやりました、バーラタよ。
tataḥ sa śuśubhe rājan kaṇṭhāsaktamahādhanuḥ|
pariveṣam anuprāpto yathā syād vyomni candramāḥ|| // 8-15-47 //
（47）王よ、首に大弓をかけられたナクラの姿は、空で光輪（パリヴェーシャ）をまとった月のように美しく輝きました。
yathaiva cāsito meghaḥ śakracāpena śobhitaḥ|
aśobhata mahārāja pāṇḍuputras tathā raṇe|| // 8-15-48 //
（48）あるいは虹で飾られた暗い雲のようでもありました。大王よ、パーンドゥの子はそのように戦場で輝きました。
tamabravīttataḥ karṇo vyarthaṃ vyāhṛtavānasi|
vadedānīṃ punarhṛṣṭo vadhyamānaḥ punaḥpunaḥ|| // 8-15-49 //
（49）カルナはナクラに言いました。「お前は無駄口を叩いた。何度も何度も打たれながら、もう一度喜んで言ってみろ。
mā yotsīḥ kurubhiḥ sārdhaṃ balavadbhiś ca pāṇḍava|
sadṛśaistāta yudhyasva vrīḍāṃ mā kuru pāṇḍava|| // 8-15-50 //
（50）パーンダヴァよ、強いクル族の者たちと戦うな。友よ、身の丈に合った者と戦え。パーンダヴァよ、恥をかくな。
gṛhaṃ vā gaccha mādreya yatra vā kṛṣṇaphalgunau|
evamuktvā mahārāja visasarja sa taṃ tadā|| // 8-15-51 //
（51）マードリーの子よ、家に帰れ。あるいはクリシュナとアルジュナのいるところへ行け。」
vadhaprāptaṃ tu taṃ śūro nāhanad varmavit tadā|
smṛtvā kuntyā vaco rājaṃs tata enaṃ vyasarjayat|| // 8-15-52 //
（52）殺すことのできた者を、武芸の掟を知るその勇者は、殺さなかったのです。王よ、クンティーの言葉を思い出し、彼を解放したのです。
visṛṣṭaḥ pāṇḍavo rājan sūtaputreṇa dhanvinā|
vrīḍann iva jagāmātha yudhiṣṭhirarathaṃ prati|| // 8-15-53 //
（53）王よ、御者の子という弓兵に放免されたパーンダヴァは、恥じ入りながらユディシュティラの戦車に向かいました。
āruroha rathaṃ cāpi sūtaputrapratāpitaḥ|
niḥśvasan duḥkhasantaptaḥ kumbhakṣipta iva uragaḥ|| // 8-15-54 //
（54）御者の子の威力に打ちのめされ、戦車に乗り込んだナクラは、壺に投げ込まれた蛇のように苦しみに嘆息していました。
taṃ vijityātha karṇo'pi pāñcālāṃs tvarito yayau|
rathenātipatākena candravarṇahayena ca|| // 8-15-55 //
（55）カルナはナクラを打ち負かした後、大旗をはためかせ月色の馬に引かせた戦車で、急いでパーンチャーラ軍に向かいました。
tatrākrando mahān āsīt pāṇḍavānāṃ viśāmpate|
dṛṣṭvā senāpatiṃ yāntaṃ pāñcālānāṃ rathavrajān|| // 8-15-56 //
（56）王よ、パーンダヴァたちの間に大きな叫び声が上がりました。総大将（カルナ）がパーンチャーラ族の戦車群に向かうのを見て。
tatrākaron mahārāja kadanaṃ sūtanandanaḥ|
madhyaṃ prāpte dinakare cakravad vicaran prabhuḥ|| // 8-15-57 //
（57）大王よ、御者の子はその場で大殺戮を行いました。太陽が中天に達した時、車輪のようにぐるぐると回りながら。
bhagnacakrair rathaiḥ kaiścic chinnadhvajapatākibhiḥ|
hatāśvair hatasūtaiś ca bhagnākṣaiś caiva māriṣa|
hiyamāṇān apaśyāma pāñcālānāṃ rathavrajān|| // 8-15-58 //
（58）壊れた車輪の戦車、旗竿や旗を切り裂かれた戦車、馬を殺され御者を殺され車軸を折られた戦車——パーンチャーラ族の戦車群が引きずられていくのが見えました。
tatratatra ca sambhrāntā vicerur atha kuñjarāḥ|
dāvāgnyabhiparītāṅgā yathaiva syur mahāvane|| // 8-15-59 //
（59）あちこちで混乱した象たちが彷徨っていました。森の大火に体を焼かれた象のように。
bhinnakumbhāḥ sarudhirāś chinnahastāś ca vāraṇāḥ|
chinnagātrāvarāś caiva cchinnavāladhayo'pare|
chinnābhrāṇi iva sampetur hanyamānā mahātmanā|| // 8-15-60 //
（60）頭の瘤を砕かれ、血にまみれ、鼻を切られた象たち——手足を切られた者、尾を切られた者——偉大なる魂の者に打たれながら、砕けた雲のように散り散りに倒れていきました。
apare trāsitā nāgā nārācaśaratomaraiḥ|
tamevābhimukhaṃ jagmuḥ śalabhā iva pāvakam|| // 8-15-61 //
（61）鉄の矢や槍や投げ槍に恐れおののいた他の象たちは、まっすぐカルナに向かっていきました。蛾が火に向かうように。
apare niṣṭanantaś ca vyadṛśyanta mahādvipāḥ|
kṣarantaḥ śoṇitaṃ gātrair nagā iva jalasravāḥ|| // 8-15-62 //
（62）また他の大象たちは苦しみにうめき声を上げ、体のあちこちから血を流しているのが見えました。水を噴き出す山のように。
uraśchadair viyuktāṃś ca vālabandhaiś ca vājinaḥ|
rājataiś ca tathā kāṃsyaiḥ sauvarṇaiś caiva bhūṣaṇaiḥ||
hīnāṃś cābharaṇaiś caiva khalīnaiś ca vivarjitān|
cāmaraiś ca kuthābhiś ca tūṇīraiḥ patitair api|| // 8-15-63-64 //
（63〜64）胸当てを失い、尾の飾り紐を失った馬たち——銀や青銅や金の飾りを失い、装飾品もなく、くつわもなく、扇も鞍覆いもなく、矢筒も落ちた——
nihataiḥ sādibhiś caiva śūrair āhavaśobhitaiḥ|
apaśyāma raṇe tatra bhrāmyamāṇān hayottamān|| // 8-15-65 //
（65）勇猛な騎兵たちが殺され、主を失った最上の馬たちが戦場をさまよっているのが見えました。
prāsaiḥ khaṅgaiś ca rahitān ṛṣṭibhiś cāpi bhārata|
hayasādīn apaśyāma kañcukoṣṇīṣadhāriṇaḥ|| // 8-15-66 //
（66）バーラタよ、槍も剣も投げ矢も持たず、上着と頭巾をつけた騎兵たちが見えました。
nihatān vadhyamānāṃś ca vepamānāṃś ca bhārata|
nāgāṅgāvayavair hīnāṃs tatratatraiva bhārata|| // 8-15-67 //
（67）バーラタよ、殺された者、今まさに殺されている者、震えている者——象の体の一部を失った者があちこちに見えました。
rathān hemapariṣkārān saṃyuktāñ javanair hayaiḥ|
bhrāmyamāṇān apaśyāma hateṣu rathiṣu drutam|| // 8-15-68 //
（68）金で飾られた戦車が、速い馬を繋がれたまま、乗り手を殺されて素早くあちこちをさまよっているのが見えました。
bhagnākṣakūbarān kāṃścid bhagnacakrāṃś ca bhārata|
vipatākadhvajāṃś cānyāñ chinneṣādaṇḍabandhurān|| // 8-15-69 //
（69）バーラタよ、車軸や轅を折られた戦車、車輪を壊された戦車、旗や旗竿を失い、轅や車台の留め具を切り裂かれた戦車——
vihīnān rathinas tatra dhāvamānāṃs tatastataḥ|
sūtaputraśarais tīkṣṇair hanyamānān viśāmpate|| // 8-15-70 //
（70）王よ、乗り手を失い、あちこちを走り回る戦車が、御者の子の鋭い矢に打たれながら走っているのが見えました。
viśastrāṃś ca tathaivānyān saśastrāṃś ca hatān bahūn|
tārakājālasañchannān varaghaṇṭāviśobhitān|| // 8-15-71 //
（71）武器を失った者たちも、武器を持ったまま殺された多くの者たちも——星の網で覆われ、美しい鈴で飾られた——
nānāvarṇavicitrābhiḥ patākābhir alaṅkṛtān|
vāramaānanupaśyāma dhāvamānān samantataḥ|| // 8-15-72 //
（72）さまざまな色の見事な旗で飾られた象たちが、四方に走り回っているのが見えました。
śirāṃsi bāhūn ūrūṃś ca cchinnān anyāṃs tathaiva ca|
karṇacāpacyutair bāṇair apaśyāma samantataḥ|| // 8-15-73 //
（73）カルナの弓から放たれた矢で切り落とされた頭・腕・腿やその他の部分が四方に見えました。
mahān vyatikaro raudro yodhānām anvapadyata|
karṇasāyakanunnānāṃ yudhyatāṃ ca śitaiḥ śaraiḥ|| // 8-15-74 //
（74）カルナの矢に追い立てられ、鋭い矢で戦う戦士たちの間に、恐ろしく凄まじい混乱が生じました。
te vadhyamānāḥ samare sūtaputreṇa sṛñjayāḥ|
tamevābhimukhaṃ yānti pataṅgā iva pāvakam|| // 8-15-75 //
（75）戦場で御者の子に打たれるスリンジャヤ族の者たちは、まっすぐカルナに向かっていきました。蛾が火に向かうように。
taṃ dahantam anīkāni tatratatra mahāratham|
kṣatriyā varjayāmāsur yugāntāgnim iva ulbaṇam|| // 8-15-76 //
（76）あちこちの軍を焼き尽くすその偉大な戦車戦士を、クシャトリヤたちは避けました。終末の燃え盛る火のように。
hataśeṣās tu ye vīrāḥ pāñcālānāṃ mahārathāḥ|
tān prabhagnān drutān vīraḥ pṛṣṭho vikiran charaiḥ|
abhyadhāvata tejasvī viśīrṇavacanadhvajān|| // 8-15-77 //
（77）生き残ったパーンチャーラ族の偉大な戦車戦士の勇者たちが敗走するのを、威光ある者は背後から矢を散らしながら追いかけました。旗も声も砕けた者たちを。
tāpayāmāsa tān bāṇaiḥ sūtaputro mahābalaḥ|
madhyandinam anuprāpto bhūtāni iva tamonudaḥ|| || // 8-15-78 //
（78）大いなる力の御者の子は、矢で彼らを焼きました。中天に昇った闇を払う者（太陽）が生き物を焼くように。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe pañcadaśo'dhyāyaḥ|| 15 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十五章は終わる。
