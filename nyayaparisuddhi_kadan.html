本書の基本テーゼ

書名にある pariśuddhi（浄化）は、nyāyavistara（論理学）は正統な14 vidyāsthāna の一つだが諸派によって濁らされた、だから Veda と Vedānta に合うように濁りを除く、という意味です（帰敬偈 vidyāsthāneṣu dharmyeṣu gaṇyate nyāyavistaraḥ / sa ca viplāvitas tais tais tato 'tra pariśodhyate、l.157–158）。全体を通る立場を表にまとめます。

pramā の定義yathāvasthitavyavahārānuguṇaṃ jñānam。どの khyāti 説を採る人でも受け入れられる、世間の言語活動に即した定義です。「samyag-anubhava」などの自派他説、Nyāya、Mīmāṃsāpra.7
pramāṇa の数pratyakṣa・anumāna・śabda の3つです。smṛti も pramā ですが、それぞれの根拠となる pramāṇa の中に含めて数えます。Cārvāka から Paurāṇika までpra.11末, śa.51–55
hetu の種類anvayavyatirekin と kevalānvayin の2種だけを認めます。kevalavyatirekin は退けます。hetvābhāsa の根本は avyāpta と apakṣadharma の2つです。Nyāya（kevalavyatirekin、5種の hetvābhāsa）II章 āh.1, 4
prāmāṇyasvataḥ（生起も把握も自律的）。aprāmāṇya だけが doṣa に依存します。Udayana（Nyāyakusumāñjali）śa.15–19
文意論anvitābhidhāna。語は他の語と結合した意味を直接に表示し、語はいつも viśiṣṭa を表示します。abhihitānvaya 説、akhaṇḍārtha 説śa.5–14
sāmānādhikaraṇya働きの根拠（pravṛttinimitta）を異にする語が、一つの viśeṣya を指します。śarīra-śarīri-bhāva を通じて、すべての語は最終的に Īśvara を指します。Advaita（svarūpaikya・bādhārtha）śa.9–14
vidhi（liṅ の意味）kartṛvyāpārasādhyatā と preṣaṇa。その実質は Īśvara の命令（śāsana / ājñā）です。Prābhākara（apūrva）、Kumārila（śabdabhāvanā）śa.33–40
padārthadravya / adravya の2つに分けます。dravya は6種：triguṇa, kāla, jīva, īśvara, śuddhasattva, mati。Vaiśeṣika の6（7）句義prame.1–8

2. adhikārin と prayojana（pra.4–5）

adhikārin

Mahābhārata Āśvamedhika の14 vidyāsthāna（aṅgāni vedāś catvāro mīmāṃsā nyāyavistaraḥ / purāṇaṃ dharmaśāstraṃ ca）を引き、「na spraṣṭavyāni śūdraiḥ」とします。Brāhmaṇa は vidyā の獲得と dharma の実践のために、Kṣatriya と Vaiśya は dharma の実践のためだけに学びます（l.336）。nyāyavistara は Veda 解釈の補助なので、Veda に資格のない者には資格がない、という理屈です。

prayojana

pada と artha を浄めること、grāvāṇaḥ plavante のような文を矛盾ゆえに別の意図で読むこと、citrayā yajeta paśukāmaḥ の果報が見えないことの扱い、anuvāda と vidhāna の判定。どれも pratyakṣa などが確立していないとできません（l.347–357）。pramāṇa が主題で、prameya は「paramparayā prayojanajñāpanāya」（間接的に目的を知らせるため）に扱います。16という数にもこだわらない（l.368）。

3. pramā の定義と khyātivāda（pra.6–8）

pra.6 では、pramāṇa/apramāṇa の区別をすべて否定する懐疑論者を、自分の立場の成否を問うことで論駁します（na sarvasyāpramāṇatvaṃ svapakṣasya svataḥ kṣateḥ）。saṃśaya が成り立つにも、選択肢（koṭi）がどこかで確定している必要がある、という論点が要です（l.400–410）。

Īśvara は推論できない

1. 序偈・定義・anumāna の成立（第一 āhnika 前半）

序偈 · p.92atha pratyakṣamūlatvād āgamajyeṣṭhabhāvataḥ / tayor antarataḥ sāṅgam anumānaṃ prasādhyateanumāna は pratyakṣa に根ざし、āgama は最上位（jyeṣṭha）にある。だからその間で、aṅga とともに anumāna を確立する。Nyāyasāra はこの順序を世間の成り行き（lokamaryādā）で説明します。生まれた者にはまず pratyakṣa が働き、pakṣa・hetu・vyāpti を捉えたあとに anumāna が生じ、年長者のやりとりを見て語の śakti を知ったあとに śābda が生じる、という順です。「sāṅgam」は、この章で vyāpti・pakṣadharmatā・upādhi・bhūyodarśana・avayava・tarka・hetvābhāsa・chala・jāti・nigrahasthāna を扱う理由を示しています。これらはみな anumāna を助けるものだからです。4つの āhnika から成る章の構成が、この一語で予告されているわけです。
anumāna の定義 · p.92vyāpyasya vyāpyatvānusaṃdhānād vyāpakaviśeṣapramitir anumānam実際に vyāpya であるものについて、それが vyāpya であると思い合わせること（anusaṃdhāna）から生じる、vyāpaka の特定（viśeṣa）の知。anumāna を推論の手段ではなく推論知（pramiti）そのものとして定義しています。pra.6 の「pramāṇa は pramā とも、その手段とも取れる」という方針どおりです。

上の viśeṣa をめぐる議論で、Śrīnivāsa は Deśika の śābdāparokṣa 批判（pra.15）を引きます。手などから人を確かめたとき「この人を直接見ている」と感じるのは、熟練していない者の言い方にすぎません。豆の山に紛れ込んだ墨のかけらまで「豆」と呼ぶように、前後の知覚に挟まれた推論までが知覚と呼ばれる、というのです。

prāmāṇya · p.93tat pramāṇaṃ karaṇadoṣabādhakapratyayarahitatvāt. kiṃ ca —anumāna は、原因の欠陥（karaṇadoṣa）も反証する知（bādhakapratyaya）もないので pramāṇa です。これは śa.1 で śabda の prāmāṇya を立てたときと同じ基準です。ただ、anumāna を認めない Cārvāka に hetu を示しても論証にならないので、「kiṃ ca」として別の論法に移ります。Cārvāka の主張は、推論知はそもそも存在しない、正しくない、疑いである、のどれかです。第一は、煙から火を知って行動している当人が反論者なのだから成り立ちません。第二と第三は、次に見るように論破されます。

続く p.94 では、Cārvāka の「anumāna は pramāṇa でない」という主張が三方から崩されています。pratyakṣa でその非 prāmāṇya を知ることはできません。非 prāmāṇya は外の対象を含むので、意（manas）では捉えられないからです。anumāna で知るなら、自分の主張と矛盾します（tadvirodhaprasaṅgataḥ）。anumāna を saṃśaya だとすることも、世間の経験に反します（sarvalokavirodhataḥ）。続いて、anumāna は感官の働きが止んだ後にも想起された liṅga から生じるので pratyakṣa ではないこと、mānasa でもないこと、また想起されたもの以上の内容を対象とする（adhikaviṣayakatvāt）ので smṛti でもないことが論じられます（pp.98–99）。

あわせて、anumāna が確立するのは「他の pramāṇa で知られた vahni などが pakṣa と結びつくこと」だけであり、感官をまったく超えたもの（Īśvara）は推論できない、と明言されます（vayam atyantātīndriyavastvanumānaṃ necchāmaḥ）。根拠は Brahmasūtra 1.1.3 śāstrayonitvāt です（p.97）。pra.12 の Īśvara 推論の否定とも、śa.15 の Udayana 批判ともつながる、本書を一貫する論点です。

2. vyāpti と upādhi

vyāpti · p.102yadrūpasya yaddeśakālavartino yasya yādṛgrūpeṇa yaddeśakālavartinā yenāvinābhāvaḥ tad idam avinābhūtaṃ vyāpyam, tatpratisaṃbandhi vyāpakamどの形をとり、どの場所と時にあるものが、どの形をとり、どの場所と時にあるものと離れずにあるか。その離れずにあるもの（avinābhūta）が vyāpya、相手方が vyāpaka です。vyāpti は条件のない（nirupādhika）定まった関係です。場所が同じ場合（熱による変化と、それから生じた guṇa）だけでなく、場所も時も異なる場合（昼の月の入りから海の干満を推す）も含むように、場所と時を明示した定義になっています（p.101）。

upādhi は、「sādhya と範囲が等しく（sādhyasamavyāpta）、sādhana を覆わない（sādhanāvyāpaka）」性質として定義されます。限定語が3つあるのは、kṛtakatva や sāvayavatva のように範囲が等しい hetu を互いの upādhi としないため、また「pakṣa 以外であること」を upādhi から除くためです（p.109）。例としては「仕えることは苦の原因である、仕えることだから、王に仕えるように」での pāpārabdhatva（p.111）、「Maitrī の息子だから色が黒い」での特定の食物の変化（p.117）が挙がります。upādhi が疑わしいだけの hetu は aprayojaka と呼ばれます。

4. 論証式・論争・nigrahasthāna（第二 āhnika）

parārthānumāna

どの pramāṇa にも、条件群から自ずと生じる場合と、他人の言葉によって生じる場合がある。だから anumāna にも svārtha・parārtha の2種がある（p.156）。他人のための推論を引き起こす言葉が prayoga（sādhana）です。
pratijñā：paraṃ prati pratipipādayiṣayā pakṣavacanam（parvato 'gnimān）。
hetu：sādhakatvaprakāśaka-vibhakti-padāntarasamabhivyāhārādiyuktaṃ liṅgasya vacanam（dhūmavattvāt）。

upanaya・nigamana の機能論批判

upanaya は asiddha を防ぐため、nigamana は siddhasādhana や bādha を防ぐため、という説明は「欠点を払う呪文を唱えるようなもの（mantrapāṭha）」だとされます。それなら「これは asiddha ではない」と明言すべきことになるからです（p.161）。論証文の組み方はどの学派の書物でも多様であり、語が結びつきさえすれば世間の言語活動も Veda の言語活動も成り立つ（p.163）。

5. chala・jāti・kukathā（第三 āhnika）

第三 āhnika は「niranuyojyānuyoga」（咎められない者を咎めること）の名のもとに、不当な応答をまとめて扱います。jāti の定義は pra.2 の svavyāpidūṣaṇam を受けて vyāghātakatva（自分の論拠も壊す非難）とされ、「suṣṭhūktaṃ vyāghātakatvaṃ jātilakṣaṇam」と確認されます（p.225）。種類は数限りないが、一つの定義ですべてをまとめられる（svavyāpi dūṣaṇaṃ jātir iti sāmānyasaṃgrahāt / avāntaravidhābhedasyānantye 'pi ca gṛhyate、p.235）。そのうえで bādhasama・kāryasama などを一つずつ吟味します。

kukathā · p.267yatra dvayor na vijayo na vā tattvaviniścayaḥ / kukathāṃ kathayanty enām asaduktiparaṃparāmどちらも勝たず、真実も確定しない、誤った応答が連なる論議が kukathā です。主張が2つ（dvipakṣa）から6つ（ṣaṭpakṣa）まで続く型が分析され、それ以上は sabhya（審判役）が止めます。審判役が不在か無能なら「猫の喧嘩のように成り行きに任せるしかない」（p.269）という皮肉で āhnika が終わります。

3　śabdādhyāya

章頭の偈は、GRETIL 本では「athānumodayaṃ smṛtyā hetutvenāpi saṃsthitm / madhye tayor ihetadānīṃ mānaṃ śabdaṃ pracakṣmahe」（l.794）となっています。Chowkhamba 本（刊本 p.360）では「athānumodbhavaṃ smṛtyā hetutvenāpi saṃsthitam / madhye tayor ihedānīṃ mānaṃ śābdaṃ pracakṣmahe」で、こちらが正しい読みです。意味は「anumāna から生じ、smṛti の原因でもある śābda を、両者の間でここに説く」。Nyāyasāra はここで upamāna を anumāna または śabda に還元する議論をしています（śa.54 と同じ論旨）。

karmaguṇa に含める推論でしか知られない karma 説は無用。知覚される karma を否定する必要はないが、guṇa から独立した類を作る区分の根拠がない（prame.2）
guṇa・dravya残すただし guṇa の意味は apṛthaksiddhaviśeṣaṇa で、dravya にも guṇa と呼ばれるものがある。だから区分は dravya / adravya とする（l.1721）

2. adravya（prame.3–7）

ātman の guṇa と saṃskāra

sukha・duḥkha・icchā・dveṣa・prayatna は buddhiviśeṣa である（Vedārthasaṃgraha）。dharma・adharma は、命令を下す王のように、Īśvara の恩寵と懲罰という知の一種（anugraha-nigraha-buddhiviśeṣa）である。saṃskāra は、dharmabhūtajñāna を dravya とみるなら、その jñāna に宿る。guṇa とみるなら ātman に宿る。vega は karma とは別に見られない。sthitisthāpaka は saṃyoga の一種である。

jñāna は dravya であり guṇa でもある

別の状態をとりうること（avasthāntarayogitva）が質料因であることで、それがすなわち dravya の定義です。buddhi は永遠でありながら縮んだり広がったりするので dravya です。同時に apṛthaksiddhaviśeṣaṇa なので guṇa でもあります。Vaiśeṣika も avayavin については「依存する dravya」を認めているではないか、と言います（prame.5）。

5. hita と段階的な道（prame.10）

世間での hita（ためになること）と ahita は、経験や Āyurveda、nītiśāstra で知られます。世間を超えたそれは Veda で知られます。kāmya の祭式や abhicāra（呪詛の祭式）も、資格者の違いに応じて「hita」です。欲望をもつ者を、地獄の原因となる世俗の手段から引き離すからです。そのうえで、最高の hita（hitatama）は bhagavadupāsana だとされます。それは知覚と同じ明瞭さをもつ、途切れのない想起（darśanasamānākāra-dhruvānusmṛti）であり、sad・akṣara・nyāsa・vaiśvānara・madhu・bhūma・dahara などの vidyā に分かれます。

最後に、他派の解脱観が列挙され、śārīraka までの諸学によって退けられるべきものとされます。身体が絶えるだけ、千人の乙女との享楽、vijñāna の連続が断たれること、vāsanā が止むこと、上昇を続けること、śiva と同じ姿、cicchakti だけが残ること、avidyā や upādhi が消えること、Vaiśeṣika の特殊な guṇa がすべて消えること、などです（l.1769）。prameya をここで要約したのは、pramāṇa を論じることの究極の目的を示すためだ、と締めくくられます。nyāyavistara の主題は、あくまで補助部分を含めた pramāṇa の範囲を示すことにあります（l.1770）。
