本書の基本テーゼ

書名にある pariśuddhi（浄化）は、nyāyavistara（論理学）は正統な14 vidyāsthāna の一つだが諸派によって濁らされた、だから Veda と Vedānta に合うように濁りを除く、という意味です（帰敬偈 vidyāsthāneṣu dharmyeṣu gaṇyate nyāyavistaraḥ / sa ca viplāvitas tais tais tato 'tra pariśodhyate、p.85）。全体を通る立場を表にまとめます。

pramā の定義yathāvasthitavyavahārānuguṇaṃ jñānam。どの khyāti 説を採る人でも受け入れられる、世間の言語活動に即した定義です。「samyag-anubhava」などの自派他説、Nyāya、Mīmāṃsāpp.90–92
pramāṇa の数pratyakṣa・anumāna・śabda の3つです。smṛti も pramā ですが、それぞれの根拠となる pramāṇa の中に含めて数えます。Cārvāka から Paurāṇika までp.95, pp.173–178
hetu の種類anvayavyatirekin と kevalānvayin の2種だけを認めます。kevalavyatirekin は退けます。hetvābhāsa の根本は avyāpta と apakṣadharma の2つです。Nyāya（kevalavyatirekin、5種の hetvābhāsa）II章 āh.1, 4
prāmāṇyasvataḥ（生起も把握も自律的）。aprāmāṇya だけが doṣa に依存します。Udayana（Nyāyakusumāñjali）pp.155–157
文意論anvitābhidhāna。語は他の語と結合した意味を直接に表示し、語はいつも viśiṣṭa を表示します。abhihitānvaya 説、akhaṇḍārtha 説pp.150–155
sāmānādhikaraṇya働きの根拠（pravṛttinimitta）を異にする語が、一つの viśeṣya を指します。śarīra-śarīri-bhāva を通じて、すべての語は最終的に Īśvara を指します。Advaita（svarūpaikya・bādhārtha）pp.153–155
vidhi（liṅ の意味）kartṛvyāpārasādhyatā と preṣaṇa。その実質は Īśvara の命令（śāsana / ājñā）です。Prābhākara（apūrva）、Kumārila（śabdabhāvanā）pp.162–166
padārthadravya / adravya の2つに分けます。dravya は6種：triguṇa, kāla, jīva, īśvara, śuddhasattva, mati。Vaiśeṣika の6（7）句義pp.178–183

科段は階層番号で示します。章は 1〜5（1 pratyakṣa、2 anumāna、3 śabda、4 smṛti、5 prameya）、その下が āhnika（1.1）、さらに論題（1.1.1）です。各項目は IAST の見出しと和文の要旨から成り、右端は底本（1941年版）の頁です。

2. adhikārin と prayojana（pp.89–90）

prāmāṇya · p.98tat pramāṇaṃ karaṇadoṣabādhakapratyayarahitatvāt. kiṃ ca —anumāna は、原因の欠陥（karaṇadoṣa）も反証する知（bādhakapratyaya）もないので pramāṇa です。これは p.149 で śabda の prāmāṇya を立てたときと同じ基準です。ただ、anumāna を認めない Cārvāka に hetu を示しても論証にならないので、「kiṃ ca」として別の論法に移ります。Cārvāka の主張は、推論知はそもそも存在しない、正しくない、疑いである、のどれかです。第一は、煙から火を知って行動している当人が反論者なのだから成り立ちません。第二と第三は、次に見るように論破されます。

続く p.98 では、Cārvāka の「anumāna は pramāṇa でない」という主張が三方から崩されています。pratyakṣa でその非 prāmāṇya を知ることはできません。非 prāmāṇya は外の対象を含むので、意（manas）では捉えられないからです。anumāna で知るなら、自分の主張と矛盾します（tadvirodhaprasaṅgataḥ）。anumāna を saṃśaya だとすることも、世間の経験に反します（sarvalokavirodhataḥ）。続いて、anumāna は感官の働きが止んだ後にも想起された liṅga から生じるので pratyakṣa ではないこと、mānasa でもないこと、また想起されたもの以上の内容を対象とする（adhikaviṣayakatvāt）ので smṛti でもないことが論じられます（p.98）。

あわせて、anumāna が確立するのは「他の pramāṇa で知られた vahni などが pakṣa と結びつくこと」だけであり、感官をまったく超えたもの（Īśvara）は推論できない、と明言されます（vayam atyantātīndriyavastvanumānaṃ necchāmaḥ）。根拠は Brahmasūtra 1.1.3 śāstrayonitvāt です（p.98）。pp.95–96 の Īśvara 推論の否定とも、pp.155–156 の Udayana 批判ともつながる、本書を一貫する論点です。

第三 āhnika は「niranuyojyānuyoga」（咎められない者を咎めること）の名のもとに、不当な応答をまとめて扱います。jāti の定義は pp.85–87 の svavyāpidūṣaṇam を受けて vyāghātakatva（自分の論拠も壊す非難）とされ、「suṣṭhūktaṃ vyāghātakatvaṃ jātilakṣaṇam」と確認されます（pp.120–121）。種類は数限りないが、一つの定義ですべてをまとめられる（svavyāpi dūṣaṇaṃ jātir iti sāmānyasaṃgrahāt / avāntaravidhābhedasyānantye 'pi ca gṛhyate、p.122）。そのうえで bādhasama・kāryasama などを一つずつ吟味します。

5. hita と段階的な道（pp.184–186）

世間での hita（ためになること）と ahita は、経験や Āyurveda、nītiśāstra で知られます。世間を超えたそれは Veda で知られます。kāmya の祭式や abhicāra（呪詛の祭式）も、資格者の違いに応じて「hita」です。欲望をもつ者を、地獄の原因となる世俗の手段から引き離すからです。そのうえで、最高の hita（hitatama）は bhagavadupāsana だとされます。それは知覚と同じ明瞭さをもつ、途切れのない想起（darśanasamānākāra-dhruvānusmṛti）であり、sad・akṣara・nyāsa・vaiśvānara・madhu・bhūma・dahara などの vidyā に分かれます。

最後に、他派の解脱観が列挙され、śārīraka までの諸学によって退けられるべきものとされます。身体が絶えるだけ、千人の乙女との享楽、vijñāna の連続が断たれること、vāsanā が止むこと、上昇を続けること、śiva と同じ姿、cicchakti だけが残ること、avidyā や upādhi が消えること、Vaiśeṣika の特殊な guṇa がすべて消えること、などです（pp.185–186）。prameya をここで要約したのは、pramāṇa を論じることの究極の目的を示すためだ、と締めくくられます。nyāyavistara の主題は、あくまで補助部分を含めた pramāṇa の範囲を示すことにあります（p.186）。
