マハーバーラタ ― カルナ篇 第68章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 68 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ68」、全29詩節からなります。アルジュナとクリシュナが傷ついたユダーマンユ王を見舞う場面（第1〜11詩節）、ビーマとアルジュナが王の消息を問い合わせる場面（第12〜24詩節）、クリシュナとアルジュナが王の陣営に到着する場面（第25〜29詩節）で本章は終わります。
karṇaparva — aṣṭaṣaṣṭitamo'dhyāyaḥ (68)
第68章
sañjaya uvāca|
tato janārdanaḥ śrutvā tasya vākyaṃ viśāmpate|
rathenāpayayau kṣipraṃ saṅgrāmāditi bhārata||
// 8-68-1 //
国の主よ、ジャナールダナ（クリシュナ）はアルジュナの言葉を聞いて、素早く戦車を戦場から退かせた、バーラタよ。
pratyanīkamavasthāpya bhīmaṃ bhīmaparākramam|
alaṃ viṣahituṃ hyeṣa kurūṇāṃ samprapaśyatām||
// 8-68-2 //
恐るべき武勇のビーマを敵の前に配置した。クル族が見ている前で彼は十分に持ちこたえることができるからだ。
karṇaṃ ca samare rājangrāhayiṣyañśramaṃ prati|
viśvamārthaṃ ca kauravya pārthasya ca mahātmanaḥ|
apayāto raṇādvīro rājānaṃ draṣṭumeva ca||
// 8-68-3 //
王よ、カウラヴィヤよ、カルナを疲労に追い込み、世界の利益のためにもパールタの大いなる利益のためにも、勇者クリシュナは戦場から王に会うために退いたのだ。
arjunaṃ cābravītkṛṣṇo bhṛśaṃ rājā parikṣataḥ|
tamāśvāsya kuruśreṣṭha tataḥ karṇaṃ haniṣyasi||
// 8-68-4 //
クリシュナはアルジュナにも言った。「王は深く傷ついている。クルの最高者よ、彼を慰めてからカルナを殺すがよい。」
tato dhanañjayaḥ śrutvā rājānaṃ śalyapīḍitam|
yāhiyāhiti bahuśo vāsudevamacodayat|
rājānaṃ prati vārṣṇeya dūyate me dṛḍhaṃ manaḥ||
// 8-68-5 //
ダナンジャヤは王が矢の苦痛にあると聞いて、ヴァースデーヴァに何度も『行け、行け』と催促した。『ヴァールシュネーヤよ、王のことが深く私の心を苦しめている。』
sa codyamānaḥ pārthena keśighno vṛṣṇinandanaḥ|
rathenāpayayau kṣipraṃ saṅgrāmāddhoradarśanāt||
// 8-68-6 //
パールタに催促されたケーシの殺し手（クリシュナ）、ヴリシュニ族の喜びは、恐ろしい光景の戦場から素早く戦車を退かせた。
gacchanneva tu kaunteyo dharmarājadidṛkṣayā|
sainyamālokayāmāsa nāpaśyattatra cāgrajam||
// 8-68-7 //
カウンテーヤはダルマ王を見たいと願いながら進む途中で軍を見渡したが、そこに兄の姿はなかった。
yuddhaṃ kṛtvā tu kaunteyo droṇaputreṇa bhārata|
duḥsahaṃ vajriṇā saṅkhye parājitya guroḥ sutam||
// 8-68-8 //
バーラタよ、カウンテーヤはドローナの子と戦場でインドラでも堪え難い戦いを行い、師の子を打ち負かし、
drauṇiṃ parājitya tatogradhanvā kṛtvā mahadduṣkaraṃ śūrakarma|
ālokayāmāsa tataḥ svasainyaṃ dhanañjayaḥ śatrubhir apradhṛṣyaḥ||
// 8-68-9 //
恐るべき弓を引きながら至難の勇者の業を成し遂げた後、敵に打ち勝てぬダナンジャヤは自軍を見渡した。
saṃyudhyamānānpṛtanāmukhasthā-- ñśūraḥ śūrānharṣayansavyasācī|
pūrvāpadānaiḥ prathitaiḥ praśaṃsa-- nsthitāṃścakārātmarathānanīke||
// 8-68-10 //
軍の先頭で戦う勇者たちを、勇者を勇者として励まし、サヴィヤサーチン（アルジュナ）はかつての偉業を称えながら、自分の戦車陣に留まらせた。
apaśyamānastu kirīṭamālī yudhiṣṭhiraṃ bhrātaramājamīḍham|
uvāca bhīmaṃ tarasābhyupetya rājñaḥ pravṛttistviha kutra ceti||
// 8-68-11 //
王冠を被るキリーティン（アルジュナ）はアージャミーダ族の兄ユディシュティラの姿を見つけられず、急いでビーマのもとに行って尋ねた。『王の消息はここにあるか、どこだ。』
bhīmasena uvāca|
apayāta ito rājā dharmaputro yudhiṣṭhiraḥ|
karṇabāṇābhitaptāṅgo yadi jīvetkathañcana||
// 8-68-12 //
「ダルマの子ユディシュティラ王はここから退却した。カルナの矢に全身を焼かれて。もし生きていればの話だが。」
arjuna uvāca|
tasmādbhavāñśīghramitaḥ prayātu jñātuṃ pravṛttiṃ puruṣarṣabhasya|
nūnaṃ sa viddho'tibhṛśaṃ pṛṣatkaiḥ karṇena rājā śibiraṃ gato'sau||
// 8-68-13 //
「それゆえおまえは速やかにここから行って、人中の雄牛の消息を知れ。きっと王は矢で深く傷つき、カルナに射られて陣営に退いたのだろう。
yaḥ samprahārairyudhi sampravṛtte droṇena viddho'tibhṛśaṃ tarasvī|
tasthau sa tatrāpi jayapratīkṣo droṇena yāvanna hataḥ kilāsīt||
// 8-68-14 //
戦いの激突が始まった時、ドローナに深く射られた速き王は、それでも勝利を待ちながらそこに留まった。ドローナが殺されるまでは。
sa saṃśayaṃ gamitaḥ pāṇḍavāgryaḥ saṅkhye'dya karṇena mahānubhāvaḥ|
jñātuṃ prayāhyāśu tamadya bhīma sthāsyāmyahaṃ śatrugaṇānnirudhya||
// 8-68-15 //
そのパーンダヴァの最高者、偉大な者は、今日の戦場でカルナに危機に陥れられた。ビーマよ、速やかに行って彼の様子を知れ。私はここに留まって敵軍を阻止する。」
bhīmasena uvāca|
tvameva jānīhi mahānubhāva rājñaḥ pravṛttiṃ bharatarṣabhasya|
ahaṃ hi yadyarjuna yāmyamitrā vadanti māṃ bhīta iti pravīrāḥ||
// 8-68-16 //
「偉大な者よ、バーラタの雄牛たる王の消息はおまえ自身が行って知れ。アルジュナよ、もし私が行けば、敵の勇者たちが『ビーマは怯えたのだ』と言うだろう。」
tato'bravīdarjuno bhīmasenaṃ saṃśaptakāḥ pratyanīkasthitā me|
etānahatvādya mayā na śakya-- mitopayātuṃ ripusaṅkhamadhyāt||
// 8-68-17 //
そこでアルジュナはビーマセーナに言った。『サンシャプタカ軍が私の正面に陣取っている。今日彼らを殺さずに、この敵軍の真ん中から退くことは私にはできない。』
athābravīdarjunaṃ bhīmasenaḥ svavīryamāsādya kurupravīra|
saṃśaptakānpratiyotsyāmi saṅkhye sarvānahaṃ yāhi dhanañjaya tvam||
// 8-68-18 //
するとビーマセーナはアルジュナに言った。『クルの勇者よ、自分の武勇を頼りにせよ。戦場でサンシャプタカの全てと私が戦おう。ダナンジャヤよ、おまえは行け。』
tadbhīmasenasya vaco niśamya dhanañjayo bhrāturamitramadhye|
draṣṭuṃ kuruśreṣṭhamabhiprayāsya-- nprovāca vṛṣṇipravaraṃ tadānīm||
// 8-68-19 //
兄ビーマセーナのこの言葉を敵の中で聞いて、ダナンジャヤはクルの最高者（ユディシュティラ）を見に行こうとして、ヴリシュニの最高者（クリシュナ）に言った。
arjuna uvāca|
'rājānaṃ prati vārṣṇeya dūyate me dṛḍhaṃ manaḥ'|
codayāśvānhṛṣīkeśa vihāyaitadbalārṇavam|
ajātaśatruṃ rājānaṃ draṣṭumicchāmi keśava||
// 8-68-20 //
「『ヴァールシュネーヤよ、王のことが深く私の心を苦しめている。』フリシーケーシャよ、馬を駆れ。この軍の大海を越えて、アジャータシャトル王に会いたいのだ、ケーシャヴァよ。」
sañjaya uvāca|
'taṃ ratha codayāmāsa bībhatsorvacanāddhariḥ'||
// 8-68-21 //
「ビーバツ（アルジュナ）の言葉によりハリ（クリシュナ）は戦車を走らせた。」
tato hayānsarvadāśārhamukhyaḥ pracodayanbhīmamuvāca cedam|
naitaccitraṃ tava karmādya bhīma yāsyāvahe jahi pārthārisaṅghān||
// 8-68-22 //
ダーシャールハ族の主（クリシュナ）は馬を駆りながらビーマにこう言った。『ビーマよ、今日のおまえの業は驚くにあたらない。我々は行く。パールタの敵の軍勢を殺せ。』
tato yayau hṛṣīkeśo yatra rājā yudhiṣṭhiraḥ|
śīghrācchīghrataro rājan vājibhir garuḍopamaiḥ||
// 8-68-23 //
王よ、フリシーケーシャ（クリシュナ）はユディシュティラ王のいる所へ、ガルダのような馬で最速よりもさらに速く向かった。
pratyanīke tvavasthāpya bhīmasenamarindamam|
sandiśya cainaṃ rājendra yuddhaṃ prati vṛkodaram||
// 8-68-24 //
王たちの王よ、敵の前にビーマセーナを配置し、ヴリコーダラ（ビーマ）に戦いの指示を与えてから。
tatastu gatvā puruṣapravīrau rājānamāsādya śayānamekam|
rathādubhau pratyavaruhya tasmā-- dvavandaturdharmarājasya pādau||
// 8-68-25 //
人中の勇者二人は進んで行き、一人横たわる王のもとに到着した。その戦車から二人とも降り、ダルマ王の足に触れた。
'ityevamupasaṅgṛhya ubhau tu pāñjalī sthitau|
śastrakṣatau mahārāja rudhireṇa samukṣitau|
nihatya vāhinīṃ tubhyamapayātau raṇājirāt'||
// 8-68-26 //
「こうして敬礼を捧げ、二人は合掌して立った。大王よ、武器に傷つき血にまみれて。おまえのために軍を殺し、戦場から退いてきたのだ。」
taṃ dṛṣṭvā puruṣavyāghraṃ kṣemiṇaṃ puruṣarṣabham|
mudābhyanandatāṃ kṛṣṇāvaśvināviva vāsavam||
// 8-68-27 //
人中の虎たる無事な人中の雄牛（ユディシュティラ）を見て、両クリシュナ（クリシュナとアルジュナ）は喜んだ。アシュヴィン双神がヴァーサヴァ（インドラ）に会うように。
tāvabhyanandadrājāpi vivasvān aśvināv iva|
hate mahāsure jambhe śakraviṣṇū yathā guruḥ||
// 8-68-28 //
王も二人を喜んで迎えた。太陽がアシュヴィン双神を迎えるように。大アスラのジャンバが殺された時、師（ブリハスパティ）がインドラとヴィシュヌを迎えたように。
manyamāno hataṃ karṇaṃ prītaḥ parapurañjayaḥ|
'sa bhūtvā puruṣavyāghro rājā tatra yudhiṣṭhiraḥ'|
harṣagadgadayā vācā prītaḥ prāha parantapaḥ||
||
// 8-68-29 //
カルナが殺されたと思い、敵の城を破る者（ユディシュティラ）は喜んだ。「人中の虎たるユディシュティラ王はそこで」喜びに声を詰まらせながら、敵を滅ぼす者は語った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe aṣṭaṣaṣṭitamo'dhyāyaḥ|| 68 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第68章終わり。
