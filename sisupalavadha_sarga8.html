अष्टमः सर्गः / 第八章　水浴の戯れ（jalakrīḍāvarṇana）

疲れた女たちが河に入り水の戯れを楽しむ
praharṣiṇī throughout — jñau jñau gaś cidraśayatiḥ praharṣiṇī yam
V.1
Sanskrit (IAST) āyāsād alaghutarastanaiḥ svanadbhiḥ śrāntānām avikacalocanāravindaiḥ / abhyambhaḥ kathamapi yoṣitāṃ samūhais tair urvīnihitacalatpadaṃ pracele //
和訳

疲労のために重い乳房を揺らし、開かぬ蓮のような眼をした、疲れ果てた女たちの群れは、地面にひきずるように足を運びながら、かろうじて水辺へ向かった。

注

【Vallabhadeva】

pracele＝進んだ（bhāve lakāra）。alaghutarastanaiḥ＝非常に重い乳房で（遅歩の因）。svanadbhiḥ＝音を立てる（装飾品か喘ぎ息か）。avikacalocanāravindaiḥ＝開かない蓮のような目（疲れで半眼）。urvīnihitacalatpadam＝地面に置いたまま引きずるように動く足。praharṣiṇī韻律。

【Mallinātha】

svabhāvokti-alaṅkāra。alaghutarastanaiḥ＝大きな乳房で（māndya-hetūkti、遅さの原因を述べる）。avikaca＝疲れで閉じた。abhyambhaḥ＝水に向かって。urvīnihitacalatpadam＝足を持ち上げられず地に引きずる。本章はpraharṣiṇī韻律。

V.2
Sanskrit (IAST) yāntīnāṃ samam asitabhruvāṃ natatvād aṃsānāṃ mahati nitāntam antare 'pi / saṃsaktair vipulatayā mitho nitambaiḥ saṃbādhaṃ bṛhad api tad babhūva vartma //
和訳

黒い眉の女たちが一斉に歩くと、肩が傾いているために上の方には大きな隙間があるのに、広い腰が互いに密着して、広い道さえも窮屈になった。

注

【Vallabhadeva】

samam yāntīnām＝一緒に歩く女たちの。aṃsānāṃ natatvāt＝肩が傾いているため上部に間隔が生じる（前章V.62で述べた通り）。vipulatayā＝（腰の）広さゆえ。mithaḥ saṃsaktaiḥ nitambaiḥ＝互いに密着した腰で。bṛhad api vartma saṃbādham＝広い道さえ窮屈に。

【Mallinātha】

natatvam（肩の傾き）とnitambavaipulya（腰の広さ）による美の極致の表現。上は隙間が開き下は密着——asaṃbādhe saṃbādhābhidhānāt atiśayokti。

V.3
Sanskrit (IAST) nīrandhradrumaśiśirāṃ bhuvaṃ vrajantīḥ sāśaṅkaṃ muhur iva kautukāt karais tāḥ / pasparśa kṣaṇam anilākulīkṛtānāṃ śākhānām atuhinaraśmir antarālaiḥ //
和訳

隙間なく茂る樹木で涼しい地面を歩む女たちに、風に揺れる枝の合間から差す陽光が、興味津々で、しかし恐る恐るといった様子で、つかの間その手で触れた。

注

【Vallabhadeva】

atuhinaraśmiḥ＝太陽。anilākulīkṛtānāṃ śākhānām antarālaiḥ＝風に揺れる枝の隙間から。kautukāt iva sāśaṅkam＝好奇心からのように、恐れを抱きつつ（paradāra＝他人の妻だから恐れる）。utprekṣā——枝の動きによる木漏れ日の明滅を、太陽が女たちに触れようとする躊躇いと見立てる。

【Mallinātha】

nīrandhra＝隙間なく密な。drumaśiśirām＝樹木で涼しい。kṣaṇam pasparśa＝つかの間触れた。iva＝utprekṣā。木漏れ日の明滅を太陽の触れたがる好奇心と恐れに見立てる。calacchākhāhetukasya tapanakarasparśa-sautsukya-hetutva-utprekṣaṇāt。

V.4
Sanskrit (IAST) ekasyās tapanakaraiḥ karālitāyā bibhrāṇaḥ sapadi sitoṣṇavāraṇatvam / sevāyai vadanasarojanirjitaśrīr āgatya priyam iva candramāś cakāra //
和訳

日射しに苦しめられるある女のために、蓮の顔に光輝を負かされた月が、奉仕せんとやって来て、たちまち白い日傘となって、恋人のように喜ばせた。

注

【Vallabhadeva】

candramāḥ＝月。vadanasarojanirjitaśrīḥ＝女の蓮の顔に美を凌駕された。sevāyai āgatya＝奉仕のために来て。sitoṣṇavāraṇatvam bibhrāṇaḥ＝白い日傘の役割を帯びて（sita＝白、uṣṇavāraṇa＝日傘）。priyam iva cakāra＝恋人のように喜ばせたかのよう——kriyāsvarūpa-utprekṣā。負けた者が勝者に仕えるのは道理。

【Mallinātha】

tapanakaraiḥ karālitāyāḥ＝日光に苦しめられた女。karāla＝bhīṣaṇa（恐ろしい、Viśva辞典）。sitoṣṇavāraṇatvam＝白い日傘としての性質（śvetātapatra）。kriyāsvarūpa-utprekṣā。月が女の顔に負けた（nirjitaśrīḥ）がゆえに奉仕する。

V.5
Sanskrit (IAST) svaṃ rāgād upari vitanvato 'ttarīyaṃ kāntena pratipad avāritātapāyāḥ / sacchatrād aparavilāsinīsamūhāc chāyāsīd adhikatarā tadāparasyāḥ //
和訳

愛情から自分の上衣を頭上に広げて、一歩ごとに日射しを遮ってくれる恋人がいたある女には、日傘を持つ他の美女の一群よりも、いっそう大きな蔭と光輝があった。

注

【Vallabhadeva】

kāntena＝恋人が。rāgāt＝愛情から。svam uttarīyam upari vitanvataḥ＝自分の上衣を頭上に広げる。pratipad＝一歩ごとに。chāyā＝①日蔭、②美しさ（Amara辞典：chāyā tv anātape kāntau）。sacchatrāt aparavilāsinīsamūhāt＝日傘つきの他の美女の群れよりも。恋人の手による特別な蔭と、その寵愛の誇りによる顔の輝き。virodhābhāsa。

【Mallinātha】

chāyā＝anātapa（日蔭）かつ kānti（光輝）の両義。sacchatra＝日傘のある→ chāyā（蔭）は当然あるのに、日傘なしの方がadhikatarā chāyā。virodhābhāsa-alaṅkāra。

V.6
Sanskrit (IAST) saṃsparśaprabhavasukhopacīyamāne sarvāṅge karatalalagnavallabhāyāḥ / kauśeyaṃ vrajad api gāḍhatām ajasraṃ sasraṃse vigalitanīvi nīrajākṣyāḥ //
和訳

恋人の掌に手を預けて歩く蓮の目の女は、全身が触れ合う悦びにふくらむにつれ、絹の衣は堅く結ばれているはずなのに、腰紐がほどけてずり落ちた。

注

【Vallabhadeva】

karatalalagnavallabhāyāḥ＝恋人の掌にしがみつく女。saṃsparśaprabhavasukhopacīyamāne sarvāṅge＝触れ合いから生じる悦びで全身が高揚する。gāḍhatām vrajad api＝堅さを増してさえも。vigalitanīvi＝腰紐のほどけた。sasraṃse＝ずり落ちた（kartari lakāra）。快楽の恍惚で自ずと。hṛṣṭā（鳥肌立つ女）。

【Mallinātha】

sukhopacīyamāne＝悦びで満ちてゆく。gāḍhatām vrajad api＝堅く結ばれてさえも——逆説。vigalitanīvi＝紐がほどけた。sukhapāravaśyāt＝快楽の没我により。kauśeyam＝絹衣（koṣāḍ ḍhak）。nīvi＝腰衣の結び目（nīvir āgrathanam）。

V.7
Sanskrit (IAST) gacchantīr alasam avekṣya vismayinyas tās tanvīr na vidadhire gatāni haṃsyaḥ / buddhvā vā jitam apareṇa kāmam āvi- ṣkurvīta svaguṇam apatrapaḥ ka eva //
和訳

物憂げに歩む細身の女たちを見て驚いた鵞鳥の雌たちは、もはや歩みの美を見せようとはしなかった。他者に負かされたと知りながら、なお自分の長所を見せびらかす恥知らずがどこにいようか。

注

【Vallabhadeva】

haṃsyaḥ＝雌の鵞鳥たち。tanvīḥ＝細身の女たち。alasam gacchantīḥ avekṣya＝物憂げに歩くのを見て。vismayinyaḥ＝驚嘆して。gatāni na vidadhire＝歩みを見せなくなった。後半は一般原則（arthāntaranyāsa）：他者に勝る者を知りながらなお自分の美点を誇示する者は恥知らず。鳥にさえ分別があるのだから——tiraścāṃ vivekitvātiśayoktyā。

【Mallinātha】

haṃsyaḥ＝hāṃsāṅganāḥ（雌鵞鳥）。alasam＝mandam（ゆっくり）。gatikaranaṇa-niṣedha-samarthanārtha（歩みの中止の正当化）としてarthāntaranyāsa。

V.8
Sanskrit (IAST) śrīmadbhir jitapulināni mādhavīnām ārohair nibiḍabṛhannitambabimbaiḥ / pāṣāṇaskhalanavilolam āśu nūnaṃ vailakṣyād yayur avarodhanāni sindhoḥ //
和訳

マーダヴァの女たちの美しく豊かに引き締まった大きな腰に砂洲を凌駕された大海の妻たる河川は、恥じらいのためか、岩に躓きよろめきながら急いで奥へ退いていった。

注

【Vallabhadeva】

sindhoḥ avarodhanāni＝大海の妃たち＝河川。jitapulināni＝砂洲を凌駕された。mādhavīnām ārohaiḥ＝マーダヴァ（クリシュナ族）の女たちの腰で。nibiḍabṛhannitambabimbaiḥ＝引き締まり大きな臀部。pāṣāṇaskhalanena vilolam＝岩に当たってよろめくように（河の自然な急流を敗走と見立てる）。vailakṣyāt＝恥じらいから——guṇahetūtprekṣā。

【Mallinātha】

avarodhanāni＝mahiṣyaḥ（正妃たち＝河）。sindhoḥ＝samudra（大海の）。jitapulināni＝pulina（砂洲）を腰の美に負かされた。pāṣāṇaskhalana＝河の自然な急流（岩に当たる）をvailakṣya（恥じらい）の因と見立てる（guṇahetūtprekṣā）。

V.9
Sanskrit (IAST) muktābhiḥ salilarayāstataśuktipeśī- muktābhiḥ kṛtaruci saikataṃ nadīnām / strīlokaḥ parikalayāñcakāra tulyaṃ palyaṅkair vigalitahāracārubhiḥ svaiḥ //
和訳

水流に押し流されて貝殻から放たれた真珠で美しくなった河の砂浜を、女たちは、崩れた頸飾りの真珠で美しい自分たちの寝台と同じだと見なした。

注

【Vallabhadeva】

muktābhiḥ＝真珠で。salilarayāstata-śuktipeśī-muktābhiḥ＝水流に放置された貝殻から出た（真珠で）。saikatam＝砂浜（sikatāmaya）。strīlokaḥ tulyaṃ parikalayāñcakāra＝女たちは同等と見なした。palyaṅkaiḥ＝寝台と。vigalitahāracārubhiḥ＝崩れた真珠の首飾りで美しい。pūrṇopamā（完全な直喩）。

【Mallinātha】

二つのmuktābhiḥ：①muktā＝真珠（mauktika）、②muktā＝放たれた（śukti-peśī＝貝殻の鞘から）。saikatam＝pulina（砂浜、Amara辞典）。palyaṅka＝śayana（寝台）。pūrṇopamā。

V.10
Sanskrit (IAST) āghrāya śramajam anindyagandhabandhum niśvāsaśvasanam asaktam aṅganānām / āraṇyāḥ sumanasa īṣire na bhṛṅgair aucityaṃ gaṇayati ko viśeṣakāmaḥ //
和訳

蜂たちは、疲れから出た女たちの溜息の吐息——妨げられぬ、えもいわれぬ芳香の友——を嗅いでしまい、もはや野の花を求めなくなった。より良いものを欲する者が、義理などかえりみようか。

注

【Vallabhadeva】

bhṛṅgaiḥ＝蜂が。niśvāsaśvasanam＝溜息の息吹。śramajam＝疲れから生じた。anindyagandhabandhum＝素晴らしい芳香の友。āghrāya＝嗅いで。āraṇyāḥ sumanasaḥ＝野の花を（na īṣire＝望まなくなった）。viśeṣakāmaḥ＝より上を求める者が、aucityam＝義理・道理を。gaṇayati＝数え入れるだろうか。いや誰もしない。arthāntaranyāsa。

【Mallinātha】

anindyagandhasya bandhu＝素晴らしい香りの伴侶（＝それ自体が芳しい）。asaktam＝遮られない。āraṇyāḥ＝野の（araṇyāc co vakravyaḥ）。na īṣire＝望まなかった（iṣu icchāyām、karmaṇi liṭ）。arthāntaranyāsa。

V.11
Sanskrit (IAST) āyāntyāṃ nijayuvatau vanāt saśaṅkaṃ barhāṇām aparaśikhaṇḍinīṃ bhareṇa / ālokya vyavadadhataṃ puro mayūraṃ kāminyaḥ śradadhur anārjavaṃ nareṣu //
和訳

自分の雌が林から帰ってくると、おびえた様子で尾羽の扇を広げて別の雌孔雀を隠す雄孔雀を目の当たりにして、女たちは男というものの不誠実さを確信した。

注

【Vallabhadeva】

mayūram＝雄の孔雀が。nijayuvatau āyāntyām＝自分の雌が帰ってくるとき。aparaśikhaṇḍinīm＝別の雌孔雀を。barhāṇām bhareṇa＝尾羽の量で。vyavadadhatam＝隠そうとする。kāminyaḥ＝女たちは。anārjavam＝不誠実を。nareṣu śradadhuḥ＝男たちに対して確信した。鳥獣さえそうなのだから人間の男はなおさら——tiraścāmの例証。

【Mallinātha】

saśaṅkam＝sabhayam（恐れて）。barhāṇām bhareṇa＝孔雀の羽の広がりで。aparaśikhaṇḍinīm＝別の雌。vyavadadhatam＝隠す（dudhāteḥ luṅ）。śradadhuḥ＝確信した（śrat-pūrvasya dadhāteḥ laṅ）。

V.12
Sanskrit (IAST) ālāpais tulitaravāṇi mādhavīnāṃ mādhuryād amalapatattriṇāṃ kulāni / antardhām upayayur utpalāvalīṣu prāduṣyāt ka iva jitaḥ puraḥ pareṇa //
和訳

マーダヴァの女たちの語らいの甘美さに鳴き声を凌駕された白鳥の群れは、蓮の茂みに姿を隠した。他者に打ち負かされた者が、勝者の前に姿を現すだろうか。

注

【Vallabhadeva】

amalapatattriṇāṃ kulāni＝清らかな翼を持つもの（白鳥）の群れ。mādhavīnām ālāpaiḥ＝マーダヴァの女たちの語らいにより。tulitaravāṇi＝鳴き声を凌駕された。antardhām upayayuḥ＝姿を消した（antaḥśabdasyopasargatvāt ac pratyaya）。utpalāvalīṣu＝蓮の茂みに。後半はarthāntaranyāsa。

【Mallinātha】

mādhavīnām＝harivadhūnām（ハリの妃たち）。tulitaravāṇi＝声を凌ぐ。mādhuryāt＝甘美さゆえに。antardhām＝消失（「antaḥśabdasy-」āc pratyaya）。prāduṣyāt＝prādurbhavet。arthāntaranyāsa。

V.13
Sanskrit (IAST) mugdhāyāḥ smaralaliteṣu cakravākyā niśśaṅkaṃ dayitatamena cumbitāyāḥ / praṇeśān abhi vidadhur vidhūtahastāḥ sītkāraṃ samucitam uttaraṃ taruṇyaḥ //
和訳

恋の戯れに初心な雌のチャクラヴァーカ鳥が、伴侶に遠慮なく口づけされるのを見て、若い女たちは手を振りながら、自分の恋人に向かって、ふさわしい返答として「シーッ」と声を発した。

注

【Vallabhadeva】

cakravākyāḥ＝雌のチャクラヴァーカの。mugdhāyāḥ＝恋に未熟な。dayitatamena cumbitāyāḥ＝最愛の雄に口づけされた。smaralaliteṣu＝恋の戯れにおいて。taruṇyaḥ＝若い女たちが。praṇeśān abhi＝恋人たちに向かって。sītkāram＝「シーッ」という声（口づけへの反応）。vidhūtahastāḥ＝手を振りながら——鳥のキスを見て自分も経験したかのように反応。

【Mallinātha】

sītkāra＝口づけの際の応答声。samucitam uttaram＝ふさわしい返答（口づけにはsītkāraが適切な返事）。tādātmyabhāvanā——鳥の口づけを見て、あたかも自分が口づけされたかのように反応する。tatsambandha-atiśayoktyā udīpaka。

V.14
Sanskrit (IAST) utkṣiptasphuṭitasaroruhārghyam uccaiḥ sasnehaṃ vihagarutair ivālapantī / nārīṇām atha sarasī saphenahāsā prītyeva vyatanuta pādyam ūrmihastaiḥ //
和訳

やがて池は、打ち上げた開いた蓮を供物とし、鳥の声で親しげに語りかけるかのように、泡の笑みを浮かべ、波の手で、喜びからのように女たちに足洗いの水を捧げた。

注

【Vallabhadeva】

sarasī＝池が。ūrmihastaiḥ＝波の手で。pādyam vyatanuta＝足洗いの水を捧げた。utkṣiptasphuṭitasaroruhārghyam＝打ち上げた開花の蓮を供物として。vihagarutaiḥ iva ālapantī＝鳥の声で挨拶するかのように。saphenahāsā＝泡の笑みを帯びて。prītyā iva＝喜びからのように——utprekṣā。客を迎えるように水・花・言葉・笑みで歓待する。rūpaka-anupraṇita-utprekṣā-dvayasya sāpekṣatvāt saṃsṛṣṭi。

【Mallinātha】

pādyam＝pādodaka（足洗いの水、「pādārghyābhyāṃ ca」yat pratyaya）。arghya＝供物。rūpakānuprāṇita-utprekṣā-dvaya（暗喩に支えられた二重の見立て）の融合（saṃsṛṣṭi）。

V.15
Sanskrit (IAST) nityāyā nijavasater nirāsire yad rāgeṇa śriyam aravindataḥ karāgraiḥ / vyaktatvaṃ niyatam anena ninyur asyāḥ sāpatnyaṃ kṣitisutavidviṣo mahiṣyaḥ //
和訳

クリシュナの妃たちが赤い指先で蓮から美——永遠の住処から——ラクシュミーを追い出したことで、ラクシュミーとの同妻の間柄をはっきりと証明した。

注

【Vallabhadeva】

kṣitisutavidviṣaḥ＝大地の子（Narakāsura）の敵＝Viṣṇu。mahiṣyaḥ＝正妃たち（Satyabhāmāなど）。rāgeṇa＝赤い色で／愛情で。karāgraiḥ＝指先で。aravindataḥ＝蓮から。śriyam nirāsire＝美を／ラクシュミーを追い出した。nityāyāḥ nijavasateḥ＝永遠の住処から（蓮はラクシュミーの永住の地）。asyāḥ sāpatnyam vyaktatvam ninyuḥ＝彼女（ラクシュミー）との同妻関係を明らかにした。śrī＝美＋ラクシュミー、rāga＝赤色＋愛情のśleṣa。

【Mallinātha】

sahṛdayayā iva と読み、首飾りがあたかも心ある者のように振る舞うと解く。haricandana の赤色が洗い落とされると、肌が蒼白（āpāṇḍu）になり、同色の真珠との区別がつかなくなる。心ある者は、自分の優位が失われた場所からは即座に離れるものだ、という含意。ahnāya は「即座に」の意の不変化辞。

【Mallinātha】

蒼白となった乳房と真珠の同色化による sāmānyālaṅkāra（共通性による同一視）を認め、首飾りが「心ある者のように」とする utprekṣā との saṅkara（混交修辞）とする。haricandana は赤栴檀。dhāv 語根の受動過去分詞 nirdhautam。ahnāya は「即座に」（Amara: jhāk, jhaṭiti に同じ）。upeye は iṇ の受動完了形。

V.52
Sanskrit (IAST) anyūnaṃ guṇam amṛtasya dhārayantī saṃphullasphuritasaroruhāvataṃsā / preyobhiḥ saha sarasī niṣevyamāṇā raktatvaṃ vyadhita vadhūdṛśāṃ surā ca //
和訳

甘露にも劣らぬ美質を備え、満開の蓮華を飾りとし、愛する者たちとともに楽しまれる蓮池――そして酒もまた――花嫁たちの目に赤みを与えた。

注

【Vallabhadeva】

sarasī（蓮池）と surā（酒）の二つが、ともに花嫁の目を赤くするという共通の作用を述べる。蓮池の水は amṛta（水＝甘露）のごとき美質（清涼・甘美など）を持ち、満開の蓮華に飾られ、愛する者とともに楽しまれる。酒もまた、甘露のごとき味、花の飾り、恋人との同伴という諸点で蓮池に共通する。

【Mallinātha】

蓮池と酒の双方が「赤み」を与えるという共通作用を述べる修辞。蓮池も酒もともに prākṛta（本題）とみなせば tulyayogitā（等結合）、酒を補助的とみなせば dīpaka（灯明修辞）。sureva（酒のように）という異読では upamā となるが、iva がある場合 tulyayogitā の余地がないため upamānopamā になると注記。amṛta は「水」と「甘露」の両義。

V.53
Sanskrit (IAST) snāntīnāṃ bṛhadamalodabinducitrai rejāte ruciradṛśām urojakumbhau / hārāṇāṃ maṇibhir upāśritau samantād utsūtrair guṇavad upannakāmyayeva //
和訳

水浴する美しい眼の女たちの壺のような両乳房は、大粒の清らかな水滴に彩られ、糸の切れた真珠の首飾りの玉に四方から取り囲まれて輝いていた――あたかも真珠たちが、糸（徳）ある優れたものに寄り添いたいという願いから駆けつけたかのように。

注

【Vallabhadeva】

糸の切れた（utsūtra）真珠が乳房に寄り添う様を、guṇavat（糸ある者＝徳ある者）への接近願望と見る utprekṣā。guṇa は「糸」と「美徳」の両義。真珠は糸を失い（nirguna）、糸ある（guṇavat）立派な拠り所を求める。乳房は豊満で堅く滑らかで、まさに guṇavat。

【Mallinātha】

upannakāmyā を kāmyac 接尾辞による形と分析。guṇavat は「糸を持つ」と「美徳を備えた」の śleṣa。atiśayokti に裏打ちされた utprekṣā とする。GRETIL の upaghnakāmyayeva は upannakāmyayeva の誤り。

V.54
Sanskrit (IAST) ārūḍhaḥ patita iti svasambhavo 'pi svacchānāṃ pariharaṇīyatām upaiti / karṇebhyaś cyutam asitotpalaṃ vadhūnāṃ vīcībhis taṭam anu yan nirāsur āpaḥ //
和訳

高きに昇りて後に落ちた者は、たとえ自ら生まれた仲間であっても、清らかな者たちから排斥されるものだ――女たちの耳から落ちた青蓮華を、波が岸辺へと押しやったように。

注

【Vallabhadeva】

蓮華は池の水から生まれ（svasambhava）、女の耳に飾られて高位に昇り（ārūḍha）、そこから落ちる（patita）。清らかな水（svaccha）は、自ら生んだものであっても、落ちた者を岸に排斥する。一般に、清廉な者は身分の高きから落ちた者を遠ざける、という処世の格言。arthāntaranyāsa。

【Mallinātha】

svasambhava を ātmasambhava（自ら生まれた者）と解く。一般則で特殊例を支える arthāntaranyāsa。格言部分に含まれる śleṣa に基づく atiśayokti との saṅkīrṇa（混交）とする。GRETIL の vīcibhis は vīcībhis が正（vīcī 女性名詞）。

V.55
Sanskrit (IAST) dantānām adharam ayāvakaṃ padāni pratyagrās tanum avilepanāṃ nakhāṅkāḥ / āninyuḥ śriyam adhitoyam aṅganānāṃ śobhāyai vipadi sadāśritā bhavanti //
和訳

水中にあって、歯の痕は紅を失った唇に美をもたらし、新しい爪の痕は塗香を洗い落とされた身体に美をもたらした。善き者に忠実に仕える者は、逆境にあってこそ美の源となるものだ。

注

【Vallabhadeva】

adhitoyam を「水中にあって」と解く（vibhaktyarthe avyayībhāva）。紅（yāvaka）や塗香（vilepana）が水で流れ落ちても、歯痕（dantapada）と爪痕（nakhāṅka）は残り、かえって美を際立たせる。sadāśritā（善き者に仕える者＝常に寄り添う者）は逆境にも美の源となる、という一般格言。nī の二重目的語構文。

【Mallinātha】

arthāntaranyāsa。sadāśritā を「善人に仕える者」および「常に身に付いている者」の両義に取る。vipadi＝逆境（財の喪失の時）、śobhāyai＝繁栄のために。kūpa の意味での caturthī。

V.56
Sanskrit (IAST) kasyāścin mukham anu dhautapatralekhaṃ vyātene salilabharāvalambinībhiḥ / kiñjalkavyatikarapiñjarāntarābhiś citraśrīr alam alakāgravallarībhiḥ //
和訳

ある女の顔では、描かれた葉模様が洗い落とされたが、水の重みで垂れ下がり、蓮の花粉の混じりで中ほどが黄褐色に染まった巻き毛の先の蔓が、その装飾の美を十分に作り出していた。

注

【Vallabhadeva】

化粧の patralekha（葉模様）が水で流れても、濡れた巻き毛が蓮の花粉で黄褐色に染まり、顔の上に自然に同様の模様を作り出す。mukham anu は「顔について」（karmapravacanīya による dvitīyā）。kiñjalka は蓮の花粉。citraśrī は装飾的な美。

V.57
Sanskrit (IAST) vakṣobhyo ghanam anulepanaṃ yadūnām uttaṃsān aharata vāri mūrdhajebhyaḥ / netrāṇāṃ madarucir akṣataiva tasthau cakṣuṣyaḥ khalu mahatāṃ parair alaṅghyaḥ //
和訳

水はヤーダヴァの男たちの胸から濃い塗香を奪い、髪から冠飾りを奪った。しかし眼の酔いの輝きだけは損なわれずに留まった。まことに、偉大な者にとって目に快いものは、他者には侵しがたい。

注

【Vallabhadeva】

ここから二詩節で男たち（yadūnām）の状態変化を描く。水が塗香と冠飾りを奪っても、酒の酔いによる眼の輝き（madaruci）だけは消えない。cakṣuṣya は「眼に快い」と「眼に生じた」の両義。parair agamyaḥ は「他者に到達しがたい」。

水遊び自体が陶酔を生むゆえ、外的な装飾色と内的な酔いの色を同一視する atiśayokti。cakṣuṣya の śleṣa による atiśayokti と、先行の atiśayokti に支えられた arthāntaranyāsa の saṅkīrṇa。GRETIL の vakṣebhyo は vakṣobhyo の誤り（vakṣas の奪格複数）。

V.58
Sanskrit (IAST) yo bāhyaḥ sa khalu jalair nirāsi rāgo yaś citte sa tu tadavastha eva teṣām / dhīrāṇāṃ vrajati hi sarva eva nāntaḥ- pātitvād abhibhavanīyatāṃ parasya //
和訳

外面にある色は水によって洗い去られた。しかし心にある色はそのまま変わらずに留まった。堅固な者にとって、内なるものは何であれ、外からの力では決して圧倒されないのだから。

注

【Vallabhadeva】

rāga の二義。外面の rāga（身体の塗料）は水で洗い落とされるが、心の rāga（愛情）は不変。dhīrāṇām（堅固な者）にとって、antaḥpātin（内にあるもの）は外者（parasya）に圧倒されない。jalair を「水によって」と「愚鈍な者たちによって」の両義に取る。

V.60
Sanskrit (IAST) bhraśyadbhir jalam abhi bhūṣaṇair vadhūnām aṅgebhyo gurubhir amajji lajjayeva / nirmālyair atha nanṛte 'vadhīritānām apy uccair bhavati laghīyasāṃ hi dhārṣṭyam //
和訳

注

【Vallabhadeva】
