マハーバーラタ ― カルナ篇 第53章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 53 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ53」、全26詩節からなる、アルジュナによるアシュヴァッターマン（ドラウニ、ドローナの子）の敗走を描く章です。サンジャヤが語る形で、シュクラ（金星）とアンギラス（木星）のような輝きを放つ二人――アルジュナとアシュヴァッターマン――の一対一の対決が展開されます（第1〜7詩節）。アルジュナはアシュヴァッターマンの矢を防ぎつつ、サムシャプタカ軍を弓矢で圧倒し、戦車・象・馬・歩兵を次々と打ち倒します（第8〜19詩節）。クリシュナがアルジュナに油断を戒め、アルジュナはドラウニの武具・身体を矢で射抜きます（第20〜22詩節）。ついにアシュヴァッターマンは矢に圧倒されて引き返すことができず、馬に運ばれて戦場を去り、ヴリシュニの英雄（クリシュナ）とダナンジャヤ（アルジュナ）の勝利を悟ってカルナの軍へと逃げ込みます（第23〜25詩節）。最後にケーシャヴァとアルジュナはサムシャプタカ軍に向けて出発する場面で本章は閉じます（第26詩節）。なお、本章でも冒頭の「サンジャヤは語った」の一文に余分な二重の注記「8-53-0」「8-53-0x」が付されていたため、これを第1詩節の本文に統合しています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜52章に続き三章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、「स्रिच्छेद」→「ciccheda」（切った、文脈上必須の動詞）、「स्मन्दन」→「syandana」（戦車、字形類似の母音記号混同）の二箇所を、本文中の同一動詞・名詞の頻出用法と照合のうえ修正しています。一方、第3詩節の「dhuvormadhye」（直訳では「ध्रुव（不動の星）の間」となるが、文脈上は眉間を射る場面であり「bhruvor」（眉、ब्रुवोः）である可能性も検討されたものの、原典の綴り字自体からは確実な再構成根拠が見出せなかったため、憶測を避けて未修正のまま残しています）。アヴァグラハ（ऽ）で示された母音脱落形（tato'rjunaḥ、vāsudeve'bhibhūte、aśvatthāmnā'rditau等）は、本来の語境界規則に従い分離せず、アポストロフィ付きの融合形のまま保持しています。また第23〜24詩節は、原典の詩節境界（ダンダの位置）が通常とは異なる形で記されていましたが、これは脱落や誤記ではなく原典の韻律構成（トリシュトゥブ調の長詩節）に基づくものと確認し、そのまま保持しています。
karṇaparva — tripañcāśo'dhyāyaḥ (53)
第53章
sañjaya uvāca|
tataḥ samabhavad yuddhaṃ śukrāṅgirasavarcasoḥ|
nakṣatram abhito vyomni śukrāṅgirasayor iva|| // 8-53-1 //
サンジャヤは語った。 （1） シュクラ（金星）とアンギラス（木星）のような輝きを持つ二人の間に戦いが起こった。空で一つの星座をめぐるシュクラとアンギラスのように。
santāpayantāv anyonyaṃ dīptaiḥ śaragabhastibhiḥ|
lokatrāsakarāv āstāṃ vimārgasthau grahāv iva|| // 8-53-2 //
（2） 燃える矢の光線で互いを苦しめる二人は、軌道を外れた二つの惑星のように世界に恐怖をもたらした。
tato'vidhyad dhuvor madhye nārācairarjuno bhṛśam|
sa tena vibabhau drauṇir ūrdhvaraśmir yathā raviḥ|| // 8-53-3 //
（3） アルジュナは両眉の間に鉄矢を深く射込んだ。それによってドラウニは上昇する太陽のように輝いた。
atha kṛṣṇau śaraśatair aśvatthāmnā'rditau bhṛśam|
svaraśmijālavikacau yugāntārkāv iva asutaḥ|| // 8-53-4 //
（4） アシュヴァッターマンの矢に激しく打たれた二人のクリシュナ（クリシュナとアルジュナ）は、自らの光線の網で輝く二つの終末の太陽のようであった。
tato'rjunaḥ sarvatodhāram astram avāsṛjad vāsudeve'bhibhūte|
drauṇāyaniś ca abhyahanat pṛṣatkair vajrāgnivaivasvatadaṇḍakalpaiḥ|| // 8-53-5 //
（5） ヴァースデーヴァが圧倒されるのを見て、アルジュナは全方位に切れ味のある武器を放った。ドラウニもまた、雷・火・ヤマの杖のような矢でアルジュナを打った。
sa keśavaṃ ca arjunaṃ ca atitejā vivyādha marmasv atiraudrakarmā|
bāṇaiḥ sumuktair atitīvravegair yair āhato mṛtyur api vyatheta|| // 8-53-6 //
（6） 極めて恐ろしい行いをするドラウニは、よく放たれた極めて激しい矢で、ケーシャヴァとアルジュナの急所を射た。それに打たれれば死神すら苦しむほどの矢で。
drauṇer iṣūn iṣubhiḥ sannivārya vyāyacchatas tad dviguṇaiḥ supuṅkhaiḥ|
taṃ sāśvasūtadhvajam ekavīram āvṛtya saṃśaptakasainyam ārcchat|| // 8-53-7 //
（7） ドラウニの矢を矢で防ぎ、その二倍の美しい矢羽根の矢で力を尽くし、馬・御者・旗もろともその一人の勇者を囲み込み、アルジュナはサムシャプタカの軍に向かった。
dhanūṃṣi bāṇān iṣudhīr dhanurjyāḥ pāṇīn bhujān pāṇigataṃ ca śastram|
chatrāṇi ketūṃs turagān ratheṣāṃ vastrāṇi mālyāny atha bhūṣaṇāni|| // 8-53-8 //
（8） 弓と矢と矢筒と弦、手と腕と手にした武器、
carmāṇi varmāṇi manoramāṇi prasahya ca eṣāṃ sa śirāṃsi caiva|
ciccheda pārtho dviṣatāṃ sumuktair bāṇaiḥ sthitānām aparāṅmukhānām|| // 8-53-9 //
（9） 傘と旗と馬と轅、衣と花輪と装身具、盾と鎧の美しいものを、さらに敵の首をも、パールタは背を向けずに立つ者たちに対して、よく放たれた矢で切り裂いた。
sukalpitāḥ syandanavājināgāḥ samāsthitāḥ kṛtayatnair nṛvīraiḥ|
pārtheritair bāṇaśatair nirastās taireva sārdhaṃ nṛvarair vineśuḥ|| // 8-53-10 //
（10） 美しく装備され、訓練された勇者たちが乗る戦車・馬・象は、パールタが放つ数百の矢に打たれ、乗り手もろとも滅びた。
padmārkapūrṇendunibhānanāni kirīṭamālyābharaṇojjvalāni|
bhallārdhacandrakṣurasannikṛttāny apātayac chatruśirāṃsy ajasram|| // 8-53-11 //
（11） 蓮や太陽や満月のような顔を持ち、冠・花輪・装飾に輝く敵の首を、バッラ矢、半月矢、剃刀矢で絶え間なく切り落とした。
atha dvipair daityaripudvipābhair devārikalpā balamanyukalpaiḥ|
kaliṅgavaṅgāṅganiṣādavīrā jighāṃsavaḥ pāṇḍavam abhyadhāvan|| // 8-53-12 //
（12） 阿修羅の敵（インドラ）の象に匹敵する象に乗り、阿修羅のごとき勇士たちが怒り狂って、カリンガ族・ヴァンガ族・アンガ族・ニシャーダ族の勇者たちがパーンダヴァを殺さんと突進した。
teṣāṃ dvipānāṃ nicakarta pārtho varmāṇi carmāṇi karān niyantṝn|
dhvajāḥ patākāś ca tataḥ prapetur vajrāhatāni iva gireḥ śirāṃsi|| // 8-53-13 //
（13） パールタはそれらの象の鎧と盾と鼻と御者を切り落とした。旗と幟もまた、雷に打たれた山の峰のように落ちた。
teṣu prabhagneṣu guros tanūjaṃ bāṇaiḥ kirīṭi navasūryavarṇaiḥ|
pracchādayāmāsa mahābhrajālair vāyuḥ samudyantam iva aṃśumantam|| // 8-53-14 //
（14） 彼らが崩壊した後、キリーティン（アルジュナ）は新たに昇る太陽のような矢で師の息子を覆った。大雨雲の群れが昇る太陽を覆うように、風がそれをなすかのごとく。
tato'rjuneṣūn iṣubhir nirasya drauṇiḥ śitair arjunavāsudevau|
pracchādayitvā divi candrasūryau nanāda so'mbhoda iva atapānte|| // 8-53-15 //
（15） アルジュナの矢を矢で退け、ドラウニは鋭い矢でアルジュナとヴァースデーヴァを覆い隠し、雨季の終わりの雷雲のように叫んだ。
tam arjunas tāṃś ca punas tvadīyān abhyarditas tair abhisṛtya śastraiḥ|
vāṇāndhakāraṃ sahasā eva kṛttvā vivyādha pārtho varahemapuṅkhaiḥ|| // 8-53-16 //
（16） アシュヴァッターマンと汝の他の者たちに打たれたアルジュナは、彼らの武器に突進し、たちまち矢の暗闇を断ち切り、美しい黄金の矢羽根の矢で射抜いた。
na api ādadat sandadhan naiva muñcan bāṇān rathe'dṛśyata savyasācī|
rathāṃś ca nāgāṃs turagān padātīn saṃsyūtadehān dadṛśur hatāṃś ca|| // 8-53-17 //
（17） 矢をつがえる姿も弦を引く姿も放つ姿も見えず、サヴィヤサーチン（アルジュナ）は戦車上で姿を消していた。しかし戦車も象も馬も歩兵も、体を射抜かれて倒れているのが見えた。
sandhāya nārācavarān daśa āśu drauṇis tvaran ekam iva utsasarja|
teṣāṃ ca pañca arjunam abhyavidhyan pañca acyutaṃ nirbibhuduḥ supuṅkhāḥ|| // 8-53-18 //
（18） ドラウニは素早く十本の最上の鉄矢を同時に放ち、五本がアルジュナに、五本がアチュタ（クリシュナ）に突き刺さった。
tair āhatau sarvamanuṣyamukhyāv asṛksravantau dhanadendrakalpau|
samāptavidyena tathā'bhibhūtau hatau raṇe tāv iti menire'nye|| // 8-53-19 //
（19） クベーラやインドラに匹敵する二人の人の王者がそれに打たれ、血を流す姿を見て、学問を究めた者にこのように打ち負かされた二人は戦場で死んだと他の者たちは思った。
atha arjunaṃ prāha daśārhanāthaḥ pramādyase kiṃ jahi yodham etam|
kuryād dhi doṣaṃ samupekṣito'yaṃ kaṣṭo bhaved vyādhir iva akriyāvān|| // 8-53-20 //
（20） ダシャールハの主（クリシュナ）はアルジュナに語った。「何を呆けている。この戦士を倒せ。放っておけば害をなす。治療しなければ悪化する病のように厄介になるぞ。」
tathā iti ca uktvā'cyutam apramādī drauṇeḥ prahasya āśu kirīṭamālī|
bhujau varau candanasāradigdhau vakṣaḥ śiro'tha apratimau tathā ūrū|| // 8-53-21 //
（21） 「然り」とアチュタに答え、油断なきキリーティン（アルジュナ）は微笑みながら素早く、ドラウニの優れた栴檀香を塗った両腕、胸、そして頭と比類なき両腿を、
gāṇḍīvamuktaiḥ kupitāhikalpai drauṇiṃ śaraiḥ saṃyati nirbibheda|
chittvā tu raśmīṃs turagān avidhyat te taṃ raṇād ūhur atīva dūram|| // 8-53-22 //
（22） ガーンディーヴァから放たれた怒れる蛇のような矢でドラウニを射抜いた。手綱を断ち切り馬を射ると、馬はドラウニを戦場から遥かに遠くへ運び去った。
sa tair hṛto vātajavais turaṅgair drauṇir dṛḍhaṃ pārthaśarābhibhūtaḥ|
āvṛtya na eva vyaṣahat sa yoddhuṃ pārthena sārdhaṃ matimān vimṛśya| // 8-53-23 //
（23） 風のように速い馬に運ばれ、パールタの矢に激しく打たれたドラウニは、引き返して賢明に考え、パールタと戦い続けることに耐えられなかった。
jānan jayaṃ niyataṃ vṛṣṇivīre dhanañjaye ca aṅgirasāṃ variṣṭhaḥ||
viveśa karṇasya balaṃ tarasvī bhagnotsāhaḥ kṣīṇavāṇāstrayogaḥ|| // 8-53-24 //
（24） アンギラス族の中で最も優れたドラウニは、ヴリシュニの英雄とダナンジャヤに勝利が定まっていることを知り、勇気を失い矢と武器の力を消耗して、カルナの軍に入っていった。
pratīpakāme tu raṇād aśvatthāmni hṛte hayaiḥ|
mantrauṣadhikriyāyogair vyādhau dehād iva āhṛte|| // 8-53-25 //
（25） 戦いを望まぬアシュヴァッターマンが馬に運ばれ戦場を去ったのは、まるで呪文と薬と治療の力によって病が体から取り除かれたかのようであった。
saṃśaptakān abhimukhau prayātau keśavārjunau|
vātodvūtapatākena syandanena aughanādinā|| || // 8-53-26 //
（26） ケーシャヴァとアルジュナはサムシャプタカ族に向かって出発した。風にはためく旗のある、水の激流のような音を立てる戦車で。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe tripañcāśo'dhyāyaḥ|| 53 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十三章は終わる。
