マハーバーラタ ― カルナ篇 第67章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 67 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ67」、全65詩節からなります。アシュヴァッターマン（ドローナの子）がアルジュナと激しい武器戦を行う場面（第1〜34詩節）、カルナがバールガヴァ武器を発動してパーンダヴァ軍を圧倒する場面（第35〜65詩節）で本章は終わります。
karṇaparva — saptaṣaṣṭitamo'dhyāyaḥ (67)
第67章
sañjaya uvāca|
drauṇistu rathavaṃśena mahatā parivāritaḥ|
apatatsahasā rājanyatra pārtho vyavasthitaḥ||
// 8-67-1 //
王よ、ドローナの子（アシュヴァッターマン）は大いなる戦車軍団に囲まれ、パールタ（アルジュナ）のいる所へ突然突撃した。
tamāpatantaṃ sahasā śūraḥ śaurisahāyavān|
dadhāra samare pārtho veleva makarālayam||
// 8-67-2 //
勇者パールタはシャウリ（クリシュナ）を助けとして、突然襲いかかる彼を戦場で受け止めた。海岸が大海を受け止めるように。
tataḥ kruddho mahārāja droṇaputraḥ pratāpavān|
arjunaṃ vāsudevaṃ ca cchādayāmāsa sāyakaiḥ||
// 8-67-3 //
大王よ、そこで威勢あるドローナの子は怒り、アルジュナとヴァースデーヴァを矢で覆い尽くした。
avacchannau tataḥ kṛṣṇau dṛṣṭvā tatra mahārathāḥ|
vismayaṃ paramaṃ gatvā praikṣanta kuravastadā||
// 8-67-4 //
覆い尽くされた二人のクリシュナを見て、大戦車戦士たちは驚き、クル族の者たちは見守った。
arjunastu tato divyamastraṃ cakre hasan iva|
tadastraṃ vārayāmāsa brāhmaṇo yudhi bhārata||
// 8-67-5 //
するとアルジュナは笑うかのように神聖な武器を発動した。バーラタよ、ブラーフマナ（アシュヴァッターマン）は戦場でその武器を防いだ。
yadyaddhi vyākṣipadyuddhe phalguno'straṃ jighāṃsayā|
tattadastrairmaheṣvāso droṇaputro jaghāna ha||
// 8-67-6 //
アルジュナが殺意をもって放つ武器のことごとくを、大弓のドローナの子は武器で打ち消した。
astrayuddhe mahārāja vartamāne mahābhaye|
apaśyāma raṇe drauṇiṃ vyāttānanamivāntakam||
// 8-67-7 //
大王よ、大いなる恐怖の武器の戦いが展開される中、我々はドローナの子が戦場で口を開けた死神のように見えた。
sa diśaḥ pradiśaścaiva cchādayitvā hyajihmagaiḥ|
vāsudevaṃ tribhir bāṇairavidhyaddakṣiṇe bhuje||
// 8-67-8 //
彼は四方八方を真っ直ぐ飛ぶ矢で覆い尽くし、ヴァースデーヴァの右腕を三本の矢で射た。
tato'rjuno rathānsarvānhatvā tasya padānugān|
cakāra samare bhūmiṃ śoṇitaughapariplutām|
sarbalokavahāṃ raudrāṃ paralokavahāṃ nadīm||
// 8-67-9 //
アルジュナはドローナの子の全ての随従の戦車を倒し、戦場の大地を血の洪水で満たした。恐ろしい、あの世へ流れる川を作った。
sarathā rathinaḥ petuḥ pārthacāpacyutaiḥ śaraiḥ||
// 8-67-10 //
戦車に乗った戦車戦士たちがパールタの弓から放たれた矢で倒れた。
drauṇerapahatānsaṅkhe dadṛśu sa ca tāṃ tathā|
prāvartayanmahāghorāṃ nadīṃ paravahāṃ tadā||
// 8-67-11 //
（追加のテキスト）ドローナの子の軍は倒され、恐ろしい戦いの川が流れた。
tayostu vyākule yuddhe drauṇeḥ pārthasya dāruṇe|
amaryādaṃ yodhayantaḥ paryadhāvanta pṛṣṭhataḥ||
// 8-67-12 //
ドローナの子とパールタの激しい戦いで混乱した者たちが、秩序なく戦いながら走り回った。
rathairhatāśvasūtaiś ca hatārohaiś ca vājibhiḥ|
dviradaiś ca hatārohairmahāmātrairhatadvipaiḥ||
// 8-67-13 //
馬も御者も殺された戦車、乗り手を殺された馬、乗り手を殺された象、象を殺された大将たち。
pārthena samare rājankṛto ghoro janakṣayaḥ|
nihatā rathinaḥ petuḥ pārthacāpacyutaiḥ śaraiḥ||
// 8-67-14 //
王よ、パールタは戦場で恐ろしい殺戮を行った。戦車戦士たちはパールタの弓から放たれた矢で殺されて倒れた。
hayāś ca paryadhāvanta muktayoktrāstatastataḥ|
taddṛṣṭvā karma pārthasya drauṇirāhavaśobhinaḥ||
// 8-67-15 //
馬は手綱を放たれてあちこちに走り回った。パールタの戦場に輝く業を見て、ドローナの子は
arjunaṃ jayatāṃ śreṣṭhaṃ tvarito'bhyetya vīryavān|
vidhunvāno mahaccāpaṃ kārtasvaravibhūṣitam||
// 8-67-16 //
勝者の中の最高者アルジュナに急いで接近し、勇敢にも大いなる黄金で飾られた弓を振りかざし、
avākirattato draumiḥ samantānniśitaiḥ śaraiḥ|
bhūyo'rjunaṃ mahārāja drauṇirāyamya patriṇā||
// 8-67-17 //
大王よ、ドローナの子は四方から鋭い矢でアルジュナに浴びせかけ、さらに引き延ばした矢で
vakṣodeśe bhṛśaṃ pārthaṃ tāḍayāmāsa nirdayam|
so'tividdho raṇe tena droṇaputreṇa bhārata||
// 8-67-18 //
パールタの胸を激しく容赦なく打った。バーラタよ、戦場でドローナの子に深く射られて、
gāṇḍīvadhanvā prasabhaṃ śaravarṣairudāradhīḥ|
sañchādya samare drauṇiṃ cicchedāsya ca kārmukam||
// 8-67-19 //
ガーンディーヴァの弓を持つ高潔な者は、力をもって矢の雨でドローナの子を覆い尽くし、その弓を切断した。
sa cchinnadhanvā paridhaṃ vajrasparśasamaṃ yudhi|
ādāya cikṣepa tadā droṇaputraḥ kirīṭine||
// 8-67-20 //
弓を切断されたドローナの子は、金剛石の如き鉄棒を取り、戦場でキリーティン（アルジュナ）に投げつけた。
tamāpantataṃ parighaṃ jāmbūnadapariṣkṛtam|
ciccheda sahasā rājanprahasan iva pāṇḍavaḥ||
// 8-67-21 //
飛来する黄金で飾られたその鉄棒を、王よ、パーンダヴァは笑うかのようにたちまち矢で切り裂いた。
sa papāta tadā bhūmau nikṛttaḥ pārthasāyakaiḥ|
vikīrṇaḥ parvato rājanyathā vajreṇa tāḍitaḥ||
// 8-67-22 //
パールタの矢に切り裂かれた鉄棒は地に落ちた。王よ、まるで雷に打たれた山が砕け散るように。
tataḥ kruddho mahārāja droṇaputro mahārathaḥ|
aindreṇa cāstravegena bībhatsuṃ samavākirat||
// 8-67-23 //
大王よ、怒ったドローナの子の大戦車戦士はインドラの武器の勢いでビーバツ（アルジュナ）に浴びせかけた。
tasyendrajālāvatataṃ samīkṣya pārtho rājan gāṇḍivamādade saḥ|
aindraṃ jālaṃ pratyaharattarasvī varāstramādāya mahendrasṛṣṭam||
// 8-67-24 //
王よ、インドラの網が広がったのを見て、パールタはガーンディーヴァを取り、素早く偉大なるインドラの網の武器を、マヘーンドラが授けた最高の武器で打ち返した。
vidārya tajjālamathendramuktaṃ pārthastato drauṇirathaṃ kṣaṇena|
pracchādayāmāsa tato'bhyupetya drauṇistadā pārthaśarābhibhūtaḥ||
// 8-67-25 //
インドラの網を引き裂いたパールタは一瞬でドローナの子の戦車を覆い尽くした。パールタの矢に圧倒されたドローナの子はそこに近づいた。
vigāhya tāṃ pāṇḍavabāṇavṛṣṭiṃ śaraiḥ paraṃ nāma tataḥ prakāśya|
śatena kṛṣṇaṃ sahasābhyaviddhyā-- ttribhiḥ śatairarjunaṃ kṣudrakāṇām||
// 8-67-26 //
パーンダヴァの矢の雨に突入し、至高の武器を発動して、百本の矢で突然クリシュナを射、三百本の細かい矢でアルジュナを射た。
tato'rjunaḥ sāyakānāṃ śatena guroḥ sutaṃ marmasu nirbibheda|
aśvāṃś ca sūtaṃ ca tathā dhanurjyā-- mavākiratpaśyatāṃ tāvakānām||
// 8-67-27 //
するとアルジュナは百本の矢で師の子の急所を射抜き、馬・御者・弓弦を、おまえの者たちが見ている前で射倒した。
sa viddhvā marmasu drauṇiṃ pāṇḍavaḥ paravīrahā|
sārathiṃ cāsya bhallena rathanīḍādapātayat||
// 8-67-28 //
ドローナの子の急所を射たパーンダヴァの敵殺しは、矢で御者を戦車の座席から叩き落とした。
sa saṅgṛhya svayaṃ vāhānkṛṣṇau prācchadayaccharaiḥ|
tatrādbhutamaparaśyāma drauṇerāśu parākramam||
// 8-67-29 //
ドローナの子は自ら手綱を取り、両クリシュナ（クリシュナとアルジュナ）を矢で覆った。そこでドローナの子の素早い武勇という驚くべきものを我々は見た。
saṃyacchaṃsturagānyacca phalgunaṃ cāpyayodhayat|
tadasya samare rājansarvabhūtānyapūjayan||
// 8-67-30 //
馬を制しながらアルジュナとも戦ったのだ。王よ、その戦場での業を全ての生き物が称賛した。
'tenāsya samare yodhāstuṣṭuvuḥ sarva eva te|
yadā nijagṛhe pārtho droṇaputreṇa dhanvinā||
// 8-67-31 //
戦場で弓を持つドローナの子にパールタが捕らえられた時、戦士たちは皆称賛した。
tadā prahasya bībhasturdroṇaputrasya saṃyuge|
kṣipraṃ raśmīnathāśvānāṃ kṣurapraiścicchide jayaḥ||
// 8-67-32 //
するとビーバツ（アルジュナ）は笑いながら、戦場でドローナの子の馬の手綱を剃刀の矢で素早く切断した、ジャヤ（アルジュナの別名）は。
prādravaṃsturagāstasya śaravegaprapīḍitāḥ|
tato'bhūnninado ghorastava sainyasya bhārata||
// 8-67-33 //
馬は矢の勢いに追われて逃げ出した。バーラタよ、おまえの軍から恐ろしい悲鳴が上がった。
pāṇḍavāstu jayaṃ labdhvā tava sainyaṃ samādravan|
samantānniśitānbāṇānvimuñcanto jayaiṣiṇaḥ||
// 8-67-34 //
パーンダヴァたちは勝利を得て、おまえの軍に突撃した。勝利を求めて四方から鋭い矢を放ちながら。
tāvakī caturaṅgaiṣā pāṇḍavaistu mahācamūḥ|
punaḥpunaratho vīraiḥ prabhagnā jitakāśibhiḥ||
// 8-67-35 //
おまえの四種の大軍は、パーンダヴァの勝ち誇った勇者たちに何度も何度も打ち破られた。
paśyatāṃ te mahārāja putrāṇāṃ citrayodhinām|
śakuneḥ saubaleyasya karṇasya ca viśāmpate||
// 8-67-36 //
大王よ、巧みに戦うおまえの息子たち、サウバラのシャクニ、カルナ、国の主が見ている前でのことだ。
vāryamāṇā mahāsenā putraistava janeśvara|
na cātiṣṭhata saṅgrāme pīḍyamānā samantataḥ||
// 8-67-37 //
人々の主よ、おまえの息子たちが大軍を阻止しようとしても、四方から攻められて軍は戦場に持ちこたえられなかった。
tato yodhairmahārāja palāyadbhiḥ samantataḥ|
abhavadyvākulaṃ bhītaṃ putrāṇāṃ te mahadbalam||
// 8-67-38 //
大王よ、四方から兵士たちが逃げ出し、おまえの息子たちの大軍は混乱し怯えた。
tiṣṭhatiṣṭheti satataṃ sūtaputrasya jalpataḥ|
nāvatiṣṭhati sā senā vadhyamānā mahātmabhiḥ||
// 8-67-39 //
スータの子がしきりに『止まれ、止まれ』と叫んでも、偉大な者たちに殺されるその軍は持ちこたえなかった。
athotkruṣṭaṃ mahārāja pāṇḍavairjitakāśibhiḥ|
dhārtarāṣṭrabalaṃ dṛṣṭvā vidrutaṃ vai samantataḥ||
// 8-67-40 //
大王よ、勝ち誇ったパーンダヴァたちは、ドリタラーシュトラの軍が四方に逃走するのを見て歓声を上げた。
tato duryodhanaḥ karṇamabravītpraṇayādiva|
paśya karṇa mahāsenāṃ pāṇḍavairarditāṃ bhṛśam||
// 8-67-41 //
そこでドゥルヨーダナは親しみを込めたようにカルナに言った。『カルナよ、見よ、パーンダヴァに激しく打たれた大軍を。
tvayi tiṣṭhati santrāsātsamantātprapalāyate|
etajjñatvā mahābāho kuru prāptamarindama||
// 8-67-42 //
おまえがいるのに、恐怖のあまり四方に逃走しているではないか。大腕よ、これを知って今なすべきことをせよ、敵を滅ぼす者よ。
sahasrāṇi ca yodhānāṃ tvāmeva puruṣottama|
krośante samare vīra drāvyamāṇāni pāṇḍavaiḥ||
// 8-67-43 //
人中の最高者よ、何千もの兵士たちが、パーンダヴァに追い散らされながら、戦場でおまえに向かって叫んでいるのだ、勇者よ。』
sañjaya uvāca|
etacchrutvā tu rādheyo duryodhanavaco mahat|
madrarājamidaṃ vākyamabravītprahasan iva||
// 8-67-44 //
ドゥルヨーダナの偉大な言葉を聞いて、ラーデーヤは笑うかのようにマドラ王にこう言った。
paśya me bhujayorvīryamastrāṇāṃ ca janeśvara|
adya hanmi raṇe sarvānpāñcālānpāṇḍubhiḥ saha||
// 8-67-45 //
『人々の主よ、我が両腕と武器の力を見よ。今日、戦場でパーンチャーラ族をパーンドゥの子らもろとも全て殺す。
vāhayāśvānnaravyāghra madrādhipa na saṃśayaḥ|
evamuktvā mahārāja sūtaputraḥ pratāpavān||
// 8-67-46 //
人中の虎よ、マドラの王よ、馬を走らせよ。疑いはない。』大王よ、こう言って威勢あるスータの子は
pragṛhya vijayaṃ vīro dhanuḥśreṣṭhaṃ purātanam|
sajyaṃ kṛtvā mahārāja sammṛjya ca punaḥ punaḥ||
// 8-67-47 //
ヴィジャヤという名の最高の古い弓を取り上げ、大王よ、弦を張って何度も磨き、
sannivārya ca tānyodhānsatyena śapathena ca|
prāyojayadameyātmā bhārgavāstraṃ mahābalaḥ||
// 8-67-48 //
兵士たちを真言と誓いで奮い立たせてから、計り知れぬ精神の大力者はバールガヴァ（パラシュラーマの）武器を発動した。
tasmādrājansahasrāṇi prayutānyarbudāni ca|
koṭiśaś ca śarāstīkṣṇā niragacchanmahāmṛdhe||
// 8-67-49 //
王よ、そこから何千、何万、何億、何兆もの鋭い矢が大いなる戦場に放たれた。
jvalitaistaiḥ śarairghoraiḥ kaṅkabarhiṇavājitaiḥ|
sañcannā pāṇḍavī senā na prājñāyata kiñcana||
// 8-67-50 //
鷺や孔雀の羽で飾られた燃え立つ恐ろしい矢に覆われ、パーンダヴァの軍は何も見えなくなった。
hāhākāro mahānāsītpāṇḍavānāṃ viśāmpate|
pīḍitānāṃ balavatā bhārgavāstreṇa saṃyuge||
// 8-67-51 //
国の主よ、パーンダヴァの間から大いなる悲嘆の叫びが上がった。戦場で力あるバールガヴァの武器に苦しめられて。
nipatadbhir gajai rājannaśvaiścāpi sahasraśaḥ|
rathaiścāpi naravyāghra naraiścaiva samantataḥ||
// 8-67-52 //
人中の虎よ、王よ、象が、馬が、戦車が、人間が、四方から何千と倒れていった。
prākampata mahī rājannihataistaiḥ samantataḥ|
vyākulaṃ sarvamabhavatpāṇḍavānāṃ mahadbalam||
// 8-67-53 //
王よ、四方に倒れた者たちで大地は震え、パーンダヴァの大軍は全て混乱に陥った。
karṇastveko yudhāṃ śreṣṭho vidhūma iva pāvakaḥ|
dahañśatrūnnaravyāghraḥ śuśubhe sa parantapaḥ||
// 8-67-54 //
人中の虎カルナは煙のない炎のごとく、敵を焼きながら一人で輝いた。敵を滅ぼす者として。
te vadhyamānāḥ karṇena pāñcālāścedibhiḥ saha|
tatra tatra vyamuhyanta vanadāhe yathā dvipāḥ||
// 8-67-55 //
カルナに殺されるパーンチャーラ族とチェーディ族は、あちこちで混乱した。森の火の中の象のように。
cukruśuś ca naravyāghra yathāprāṇaṃ narottamāḥ|
teṣāṃ tu krośatāṃ dīnaṃ bhītānāṃ raṇamūrdhani||
// 8-67-56 //
人中の虎よ、最高の人々は力の限り叫んだ。戦場の先頭で怯えて哀れに叫ぶ者たちの中で。
dhāvatāṃ ca tato rājaṃstrastānāṃ ca samantataḥ|
ārtanādo babhūvātra bhūtānāmiva sampluve||
// 8-67-57 //
王よ、怯えた者たちが四方に逃げ惑う中、生き物たちの大洪水のような悲痛な叫びが起こった。
vadhyamānāṃstu tāndṛṣṭvā sūtaputreṇa māriṣa||
vitresuḥ sarvabhūtāni tiryagyonigatānyapi||
// 8-67-58 //
スータの子に殺される者たちを見て、動物たちさえも恐れおののいた。
te vadhyamātāḥ samare sūtaputreṇa sṛñjayāḥ|
arjunaṃ vāsudevaṃ ca krośanti ca muhurmuhuḥ|
pretarājapure yadvatpretarājaṃ vicetasaḥ||
// 8-67-59 //
戦場でスータの子に殺されるスリンジャヤ族は、アルジュナとヴァースデーヴァを繰り返し呼んだ。死者の王の都で正気を失った者たちが死者の王を呼ぶように。
śrutvā tu ninadaṃ teṣāṃ vadhyatāṃ karṇasāyakaiḥ|
athābravīdvāsudevaṃ kuntīputro dhaṉañjayaḥ|
bhārgavāstraṃ mahāghoraṃ dṛṣṭvā tatra samīritam||
// 8-67-60 //
カルナの矢に殺される者たちの叫びを聞いて、そして恐ろしいバールガヴァの武器が発動されたのを見て、クンティーの子ダナンジャヤはヴァースデーヴァに言った。
paśya kṛṣṇa mahābāho bhārgavāstrasya vikramam|
naitadastraṃ hi samare śakyaṃ hantuṃ kathañcana||
// 8-67-61 //
『クリシュナよ、大腕よ、バールガヴァの武器の威力を見よ。この武器は戦場で如何なる方法でも打ち破ることはできない。
sūtaputraṃ ca saṃrabdhaṃ paśya kṛṣṇa mahāraṇe|
antakapratimaṃ vīrye kurvāṇaṃ karma dāruṇam||
// 8-67-62 //
クリシュナよ、大いなる戦場で怒り狂うスータの子を見よ。勇気においてヤマ（死神）に等しく、恐ろしい業をなしている。
abhīkṣṇaṃ codayannaśvānprekṣate māṃ muhurmuhuḥ|
naca śakṣyāmi karṇasya saṃyuge'haṃ palāyitum||
// 8-67-63 //
しきりに馬を駆りながら、繰り返し私を見ている。しかし私はカルナから戦場で逃げるわけにはいかない。
jīvanprāpnoti puruṣaḥ saṅkhye jayaparājayau|
mṛtasya tu hṛpīkeśa bhaṅga eva kuto jayaḥ||
// 8-67-64 //
生きていれば人は戦で勝ちも負けもする。しかしフリシーケーシャ（クリシュナ）よ、死んだ者にとっては敗北のみ、どこに勝利があろうか。
eṣa karṇo raṇe bhāti madhyāhna iva bhāskaraḥ|
nivartaya rathaṃ kṛṣṇa jīvanbhadrāṇi paśyati||
// 8-67-65 //
このカルナは戦場で真昼の太陽のように輝いている。クリシュナよ、戦車を引き返せ。生きている者こそ幸福を見ることができるのだ。』
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe saptaṣaṣṭitamo'dhyāyaḥ|| 67 ||
