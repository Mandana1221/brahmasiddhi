マハーバーラタ ― カルナ篇 第26章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 26 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ26」（天の神々の命により、工匠の神ヴィシュヴァカルマンが大地・天体・季節・ヴェーダなど森羅万象を素材としてルドラ神のために神聖な戦車と矢を作り上げる場面）です。各段落は原典の詩節番号（8-26-N）と和訳の段落番号が対応しています。
karṇaparva — ṣaḍviṃśo'dhyāyaḥ (26)
第26章　天の神々の命により、ヴィシュヴァカルマンがルドラのために戦車を造る
duryodhana uvāca|
tejaso'rdhaṃ surā dattvā śaṅkarāya mahātmane|
paśutvam api ca upetya viśvakarmāṇam avyayam||
ūcuḥ sarve samābhāṣya rathaḥ saṅkalpyatām iti|
viśvakarmā'pi sañcintya rathaṃ divyamakalpayat|| // 8-26-1-2 //
ドゥルヨーダナは語った。 （1〜2）「天の神々はシャンカラという偉大な魂に力の半分を捧げ、家畜となることをも受け入れた後、不滅のヴィシュヴァカルマンに全員で語りかけ、『戦車を作れ』と命じた。ヴィシュヴァカルマンは熟考して神聖な戦車を作り上げた。
sametāṃ pṛthivīṃ devī viśālāṃ puramālinīm|
saparvatavanadvīpāṃ cakre bhūtadharāṃ ratham|| // 8-26-3 //
（3）広大で、城市に飾られ、山と森と島を持つ大地の女神そのものを集めて、生き物を支えるこの大地を戦車とした。
īṣāṃ nakṣatravaṃśaṃ ca chatraṃ merumahāgirim|
anekadrusañchannaṃ ratnākaramanuttamam|| // 8-26-4 //
（4）轅には星座の列を、傘にはメール大山を——数多の樹木に覆われ、宝石の鉱脈を持つ最上のもの。
himavantaṃ ca vindhyaṃ ca nānādrumalatākulam|
avaskaraṃ pratiṣṭhānaṃ kalpayāmāsa vai tadā|| // 8-26-5 //
（5）ヒマラヤとヴィンディヤ山脈を、さまざまな樹木や蔓草に満ちたものを、戦車の足場と台座とした。
astaṃgirimadhiṣṭhānaṃ nānādvijagaṇāyutam|
cakāra bhagavāṃs tvaṣṭā udayaṃ rathakūbaram|| // 8-26-6 //
（6）日没の山を戦車の背もたれとし、さまざまな鳥の群れで満たし、至高の工匠トヴァシュトリ（ヴィシュヴァカルマン）は日の出の山を戦車の轅とした。
mīnanakrajhaṣāvāsaṃ dānavālayamuttamam|
samudramakṣaṃ vidadhe pattanākaraśobhitam|| // 8-26-7 //
（7）魚やワニや鯨が住み、悪魔たちの住処であり、港や鉱山で飾られた大海を車軸とした。
cakraṃ cakre candramasaṃ tārakāgaṇamaṇḍitam|
divākaraṃ cāpyaparaṃ cakraṃ cakre'ṃśumālinam|| // 8-26-8 //
（8）月を一方の車輪に作り、星座の群れで飾った。太陽をもう一方の車輪として、光の輪をまとわせた。
gaṅgāṃ sarasvatīṃ tūṇīṃ cakre viśvakṛdavyayaḥ|
alaṅkārā rathasyāsannāpagāḥ saritas tathā|| // 8-26-9 //
（9）不滅の万物の創造者は、ガンガー河とサラスヴァティー河を矢筒とした。河川や小川は戦車の装飾となった。
trīn agnīn mantravac cakre rathasya atha triveṇukam|
anukarṣān rathe dīptān varūthāṃś cāpi tārakāḥ|| // 8-26-10 //
（10）三つの祭火を、戦車の三本の竹竿（旗竿）とし、マントラを唱えて作った。輝く車輪の金具と守りの板は星々であった。
oṣadhīr vīrudhaś caiva ghaṇṭājālaṃ ca bhānumat|
alañcakāra ca rathaṃ māsapakṣartubhir vibhuḥ|| // 8-26-11 //
（11）薬草と草木は輝く鈴の網となった。主は月と半月と季節で戦車を飾った。
ahorātraiḥ kalābhiś ca kāṣṭhābhir ayanais tathā|
dyāṃ yugaṃ yugaparvāṇi saṃvartakabalāharakān|| // 8-26-12 //
（12）昼と夜、時刻、瞬間、方向に、天空を軛とし、ユガ（世界周期）とユガの節目を、世界を終わらせる雲々とした。
śamyāṃ dhṛtiṃ ca medhāṃ ca sthitiṃ sannatim eva ca|
ṛghvedaṃ sāmavedaṃ ca dhuryāv aśvāv akalpayat||
pṛṣṭhāśvau tu yajurvedaḥ kalpito'tharvaṇas tathā|
aśvānāṃ cāpyalaṅkāraṃ vidadhe padasañcayam|| // 8-26-13-14 //
（13〜14）忍耐と知力と記憶を安定と恭順に——リグ・ヴェーダとサーマ・ヴェーダを前方の二頭の馬とし、ヤジュル・ヴェーダとアタルヴァ・ヴェーダを後方の二頭の馬とした。馬の装飾には韻律の集まりを当てた。
sinīvālīmanumatiṃ kuhūṃ rākāṃ ca suprabhām|
yoktāṇi cakre cāśvānāṃ kūśmāṇḍāṃś cāpi pannagān|
tālapṛṣṭho'tha nahuṣaḥ kārkoṭakadhanañjayau|
itare cābhavan nāgā hayānāṃ vāhabandhanam|| // 8-26-15-16 //
（15〜16）シニーヴァーリー、アヌマティ、クフー、ラーカーという輝く月の女神たちを馬の繋ぎ紐とした。クーシュマーンダの精霊と蛇たちも。ターラプリシュタ、ナフシャ、カールコータカ、ダナンジャヤの蛇たち、そのほかの蛇たちが馬を繋ぐ帯となった。
abhīśavaḥ ṣaḍaṅgāni kalpitāni mahīpate|
oṅkāraḥ kalpitas tasya pratodo viśvakarmaṇā|| // 8-26-17 //
（17）六つのヴェーダーンガ（補助学問）が手綱となり、王よ。ヴィシュヴァカルマンはオームの聖音を鞭とした。
yajñāḥ sarve pṛthaklṛptā rathāṅgāni ca bhāgaśaḥ|
adhiṣṭhānaṃ manaścāsītparirathyā sarasvatī|| // 8-26-18 //
（18）すべての祭儀がそれぞれ戦車の部品として配置された。心が乗車台となり、サラスヴァティー女神が戦車を巡る道となった。
nānāvarṇāni śastrāṇi patākāḥ pavaneritāḥ|
vidyudindradhanuryuktaṃ rathaṃ dīptyā vyadīpayat|| // 8-26-19 //
（19）さまざまな色の武器、風になびく旗——稲妻と虹を備えたその戦車は輝きに包まれた。
varma yoddhuṃ ca vihitaṃ namo grahagaṇākulam|
abhedyaṃ bhānumaccitraṃ kālacakraparikṣatam|| // 8-26-20 //
（20）戦士のために作られた鎧は、敬礼を象り、遊星の群れで飾られ、破壊不能で、光り輝き、美しく、時の車輪で護られたものだった。
evam asmin mahārāja kalpite rathasattame|
tvaṣṭrā manujaśārdūla dviṣatāṃ bhayavardhane||
svānyāyudhāni divyāni nyadadhāc chaṅkaro rathe|
dhvajayaṣṭiṃ viyatkṛtvā sthāpayāmāsa govṛṣam|| // 8-26-21-22 //
（21〜22）こうしてこの最上の戦車が、人の中の虎よ、敵の恐怖を増す者として、トヴァシュトリによって作り上げられた後、シャンカラは自らの神聖な武器を戦車に置き、空そのものを旗竿として、雄牛の旗印を立てた。
brahmadaṇḍaḥ kāladaṇḍo rudradaṇḍaś ca te jvarāḥ|
pariṣkārā rathasyāsan samantād diśam uddhatāḥ|| // 8-26-23 //
（23）ブラフマーの杖、時の杖、ルドラの杖——これらの恐るべきものが戦車の装飾として四方に高く掲げられた。
vicitramṛtubhiḥ ṣaḍbhiḥ kṛtvā saṃvatsaraṃ dhanuḥ|
chāyām eva ātmanaś cakre dhanurjyāmakṣayāṃ dhruvām|| // 8-26-24 //
（24）六つの季節をもって一年という見事な弓を作り、自らの影を弓弦とした——不滅にして堅固な弓弦を。
kālo hi bhagavān rudras tac ca saṃvatsaraṃ dhanuḥ|
tasmād raudrī kālarātrī jyā kṛtā dhanuṣo jarā|| // 8-26-25 //
（25）至高の神ルドラは時そのものである。その弓は一年。だからルドラの弓弦は時の夜、すなわち老いとして作られた。
tato rathe rathāśvāṃs tān ṛṣayaḥ samayojayan|
ekaikaśaḥ susaṃhṛṣṭānādāya sudhṛtavratāḥ|| // 8-26-26 //
（26）そして戦車にヴェーダの馬たちを、聖仙たちが一頭ずつ喜んで繋ぎ、堅い誓いを守る者たちが取りまとめた。
dakṣiṇasyāṃ dhuri kṛta ṛgvedo mantrapāragaiḥ|
savyataḥ sāmavedaś ca yukto rājan maharṣibhiḥ|| // 8-26-27 //
（27）右の轅にはリグ・ヴェーダがマントラに精通した者たちによって繋がれ、左にはサーマ・ヴェーダが大聖仙たちによって繋がれた。
pārṣṭhidakṣiṇato yukto yajurvedaḥ suradvijaiḥ|
itarasyāṃ tathā pārṣṭhyāṃ yukto rājan atharvaṇaḥ|| // 8-26-28 //
（28）右の後方にはヤジュル・ヴェーダが天の賢者たちによって、もう一方の後方にはアタルヴァ・ヴェーダが繋がれた。
evaṃ te vājino yuktā yajñavidbhis tathā rathe|
aśobhanta tathā yuktā yathaivādhvaramadhyagāḥ|| // 8-26-29 //
（29）こうして祭儀に通じた者たちによってヴェーダの馬が戦車に繋がれ、祭場にいるかのように美しく輝いた。
kalpayitvā rathaṃ divyaṃ tato bāṇamakalpayat|
cintayitvā hariṃ viṣṇumavyayaṃ yajñavāhanam|| // 8-26-30 //
（30）神聖な戦車を作り上げた後、次に矢を作った。不滅で祭儀を乗り物とするハリ・ヴィシュヌを思い浮かべて——
śaraṃ saṅkalpayāñcakre viśvakarmā mahāmanāḥ|
tasya vājāṃś ca puṅkhaṃ ca kalpayāmāsa vai tadā|| // 8-26-31 //
（31）偉大な心のヴィシュヴァカルマンは矢を作り上げた。その羽根と矢尻を彼はこのように定めた。
puṇyagandhavahaṃ rājañ śvasanaṃ rājasattama|
agnīṣomau śaramukhe kalpayāmāsa vai tadā|| // 8-26-32 //
（32）王の中の最上者よ、良い香りを運ぶ風を矢の羽根とし、火神と月神（アグニとソーマ）を矢の先端に据えた。
agnīṣomātmakaṃ kṛtsnamucyate vaiṣṇavaṃ jagat|
viṣṇurātmā bhagavato bhavasyāmitatejasaḥ|| // 8-26-33 //
（33）アグニとソーマからなるこの全世界はヴィシュヌのものと言われる。ヴィシュヌは至高の神バヴァ（シヴァ）の計り知れない威光のアートマン（魂）である。
tasmāddhanurjyāsaṃsparśaṃ sa viṣehe śarasya vai|
tasmiñ śare tīkṣṇamanyum amuñcad duḥsahaṃ prabhuḥ|| // 8-26-34 //
（34）だからこそ、その矢は弓弦との接触に耐えることができた。この矢に主は、耐え難い激しい怒りを込めた。
bhṛgvaṅgiromanyubhavaḥ krodhāgniratiduḥsahaḥ|
sa nīlalohito dhūmraḥ kṛttivāsā bhayānakaḥ|| // 8-26-35 //
（35）ブリグとアンギラスの怒りから生まれた怒りの炎、耐え難きもの——それは青と赤の入り混じった煙色で、獣皮を身にまとい、恐ろしかった。
ādityāyutasaṅkāśas tejojvālāvṛto bhavaḥ|
duścaryacyāvako jetā hantā brahmadviṣāṃ varaḥ|| // 8-26-36 //
（36）一万の太陽に匹敵する輝きで、威光の炎に包まれたバヴァは、苦行を乱す者、征服者、ブラフマンの敵の最上の殺害者であった。
tasyāṅgāni samāśritya sthitaṃ viśvamidaṃ jagat|
jaṅgamājaṅgamaṃ rājañ chuśubhe'dbhutadarśanam|| // 8-26-37 //
（37）その体の各部に寄りかかって、この動くものと動かないものすべてからなる全世界が存在していた。王よ、驚くべき光景であった。
dṛṣṭā tu taṃ rathaṃ divyaṃ kavacī sa śarāsanī|
ādade sa śaraṃ divyaṃ somaviṣṇvagnivāyujam|| // 8-26-38 //
（38）その神聖な戦車を見て、鎧をまとい弓を持ったシヴァは、ソーマ・ヴィシュヌ・アグニ・ヴァーユの力からなる神聖な矢を手に取った。
tamādāya mahādevas trāsayan daityadānavān|
āruroha tadā yattaḥ kampayan iva rodasī|| // 8-26-39 //
（39）偉大なる神は、悪魔たちを震え上がらせながらその矢を手に取り、大地と天を震わせるかのように、身構えて戦車に乗り込んだ。
maharṣibhiḥ stūyamāno vandyamānaś ca vandibhiḥ|
upanṛttaścāpsarasāṃ gaṇairnṛttaviśāradaiḥ|| // 8-26-40 //
（40）大聖仙たちに讃えられ、吟遊詩人たちに敬われ、踊りに長けた天女たちの群れに囲まれて踊りを見せられた。
sa śobhamāno varadaḥ khaṅgī bāṇī śarāsanī|
hasannivābravīddevaḥ sārathiḥ ko bhavediti|| || // 8-26-41 //
（41）恩寵を与える方は、剣と矢と弓を持ち、輝きながら、微笑むかのように言った——『御者は誰がなるのか？』と。」
iti śrīmanmahābhārate karṇaparvaṇi ṣaḍviṃśo'dhyāyaḥ|| 26 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十六章は終わる。
