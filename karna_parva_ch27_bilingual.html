マハーバーラタ ― カルナ篇 第27章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 27 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ27」（天の神々の懇願によりブラフマー神がルドラ神の御者となり、ルドラが三都市（トリプラ）の悪魔たちを矢で焼き滅ぼし、その後ドゥルヨーダナがこの先例を引いてシャリヤにカルナの御者を務めるよう懇願する場面）です。各段落は原典の詩節番号（8-27-N）と和訳の段落番号が対応しています。
karṇaparva — saptaviṃśo'dhyāyaḥ (27)
第27章　天の神々の懇願によりブラフマーがルドラの御者となる・ルドラがトリプラを焼く
duryodhana uvāca|
tam abruvan devagaṇā yaṃ bhavān sanniyokṣyate|
sa bhaviṣyati deveśa sārathis te na saṃśayaḥ|| // 8-27-1 //
ドゥルヨーダナは語った。 （1）「天の神々の群れは言った。『あなたが任命される方こそが、天の神の主よ、あなたの御者となりましょう。疑いありません。』
tān abravīn mahādevo mattaḥ śreṣṭhataro hi yaḥ|
taṃ sārathiṃ kurudhvaṃ vai svayaṃ sañcintya mā ciram|| // 8-27-2 //
（2）マハーデーヴァは彼らに言った。『私より優れた者を御者とせよ。自ら考えて急いで決めよ。』
etac chrutvā vaco devāḥ sarve gatvā pitāmaham|
praṇipatya ūcur ekāgrāḥ prasādyainaṃ maharṣibhiḥ|| // 8-27-3 //
（3）これを聞いた天の神々は皆、祖父神ブラフマーのもとに行き、大聖仙たちとともになだめ、敬礼して一心に言った。
tvayā yatkathitaṃ deva tridaśārinibarhaṇe|
tathā tatkṛtamasmābhiḥ prasannaś ca vṛṣadhvajaḥ|| // 8-27-4 //
（4）『神よ、三十三天の敵を打ち倒すために、あなたがお告げくださったとおりのことを我々はすべて行いました。ヴリシャバドヴァジャ（牛の旗印の神＝シヴァ）も満足されています。
rathaś ca vihito'smābhir vicitrāyudhasaṃvṛtaḥ|
sārathiṃ ca na jānīmaḥ kaḥ syāt tasmin rathottame|| // 8-27-5 //
（5）さまざまな武器を備えた戦車も用意しました。しかしあの最上の戦車にふさわしい御者がわかりません。
tasmād vidhīyatāṃ kaścit sārathir devasattama|
saphalāṃ tāṃ giraṃ deva kartumarhasi no vibho|
evam asmāsu hi purā bhagavann uktavān asi|| // 8-27-6 //
（6）ですから御者を定めてください、天の神の中の最上者よ。あの言葉を実現してください、主よ。以前、あなたは我々にそうおっしゃったのですから。
sadaiva yukto rathasattamo vai durādharṣo drāvaṇaḥ śātravāṇām|
pinākadhanvā vihito'tra yoddhā vibhīṣayan dānavān udyato'sau|| // 8-27-7 //
（7）常に備えられた最上の戦車、敵を打ち砕く攻め難い戦車——ピナーカの弓を持つ者が戦士として定められ、悪魔たちを震え上がらせて立ち上がっている。
tathaiva vedāś ca hayā rathāgrya dharā saśailā ca ratho mahātmanaḥ|
nakṣatravaṃśānugato varūthī yasmin yoddhā sārathinā'bhirakṣyaḥ|| // 8-27-8 //
（8）ヴェーダが馬であり、大地と山が偉大な魂の戦車であり、星座の列が車輪の守りとなっている。この戦車で戦う者は御者に守られねばならない。
tatra sārathir eṣṭavyaḥ sarvair etair viśeṣavān|| // 8-27-9 //
（9）そこで御者は、これらすべてにおいて特別に優れた者でなければならない。
taṃ praviṣṭā rathaṃ devā rathayodvāram eva ca|
kavacāni ca śastrāṇi kārmukaṃ ca pitāmaha||
tvām ṛte sārathiṃ tatra nānyaṃ paśyāmahe vayam|
tvaṃ hi sarvair gaṇair yukto devatābhyo'dhikaḥ prabho|| // 8-27-10-11 //
（10〜11）戦車に入り込んだ天の神々も、戦車の戦士も、鎧も武器も弓も——祖父よ、あなた以外に御者として我々はふさわしい者を見ない。あなたはすべての群れを率い、天の神々よりも優れた主なのですから。
tvaṃ deva śakto lokeśa niyantuṃ pradrutānimān|
vedāṃś ca sopaniṣadaḥ sārathirbhava naḥ svayam|| // 8-27-12 //
（12）神よ、世界の主よ、あなたこそヴェーダとウパニシャッドを伴うこの疾走する馬たちを御する力を持つ方。自ら我らの御者となりたまえ。
yoddhuṃ balena vīryeṇa satvena vinayena ca|
adhikaḥ sārathiḥ kāryo nāsti cānyo'dhiko bhavāt|| // 8-27-13 //
（13）力・武勇・真実・謙虚さにおいて優れた者が御者になるべきであり、あなたより優れた者はいない。
sa bhavāṃs tārayatv asmān kuru sārathyam avyaya|
bhavān abhyadhikas tvatto nānyosti bhavitā tviha|| // 8-27-14 //
（14）あなたこそ我らを救い出す方——御者を務めてください、不滅の方よ。あなたより優れた者は他にいないし、今後もいないでしょう。
tvaṃ hi deveśa sarvaistu viśiṣṭo vadatāṃ vara|
taṃ rathaṃ tvaṃ samāruhya saṃyaccha paramān hayān|| // 8-27-15 //
（15）天の神の主よ、あなたはすべてにおいて卓越しています、雄弁家の中の最上者よ。あの戦車に乗り、最上の馬を御してください。
tava prasādād vadhyeyur deva daivatakaṇṭakāḥ|
sa no rakṣa mahābāho daityebhyo mahato bhayāt|| // 8-27-16 //
（16）あなたの恩恵によって、天の神の棘（敵）どもは殺されるでしょう。大いなる腕の方よ、悪魔たちから来る大いなる恐怖から我々を守ってください。
tvaṃ hi no gatiravyagra tavaṃ ntre goptā mahāvrata|
tvatprasādātsurāḥ sarve pūjyante tridive prabho|| // 8-27-17 //
（17）あなたこそ我らの帰依処、守護者、偉大な誓いの方。あなたの恩恵によってこそ、すべての天の神々は三十三天で崇められているのですから、主よ。』
iti te śirasā'gacchaṃs trilokeśaṃ pitāmaham|
devāḥ prasādayāmāsuḥ sārathyāyeti naḥ śrutam|| // 8-27-18 //
（18）こうして彼らは頭を下げて三界の主なる祖父神に嘆願し、天の神々は御者となることをお願いした——と伝えられている。」
brahmovāca|
evam etat surās tathyaṃ nānyas tv abhyadhiko bhavāt|
sārathitvaṃ kariṣyāmi śaṅkarasya mahātmanaḥ|| // 8-27-19 //
ブラフマーは語った。 （19）「『天の神々よ、そのとおりだ。これより優れた者は他にいない。シャンカラという偉大な魂の御者を私が務めよう。
sarvathā rathinaḥ śreyān kartavyo rathasārathiḥ|
tasmād etad yathātattvaṃ jñātvā yuṣmāṃś ca saṅgatān|
saṃyacchāmi hayān eṣa vibudhāya kapardine|| // 8-27-20 //
（20）あらゆる点で、戦車の戦士よりも御者は優れた者であるべきだ。この真理を知り、お前たちが集まって願うがゆえに、私はこの偉大なるカパルディン（シヴァ）のために馬を御そう。』」
duryodhana uvāca|
evamuktvā jaṭābhāraṃ saṃyamya prapitāmahaḥ|
paridhāya ājinaṃ gāḍhaṃ sannyasya ca kamaṇḍalum|
pratodapāṇirbhagavānāruroha rathaṃ tadā|| // 8-27-21 //
ドゥルヨーダナは語った。 （21）「こう言って、祖父神は髻を結い上げ、鹿皮をしっかりとまとい、水瓶を置いて、鞭を手に取り、至高の神は戦車に乗り込んだ。
sārathau kalpite devair īśānasya mahātmanaḥ|
tasmin ārohati rathaṃ kalpitaṃ lokasambhṛtam|
śirobhiḥ patitā bhūmau turagā vedasambhṛtāḥ|| // 8-27-22 //
（22）イーシャーナという偉大な魂のために天の神々が御者を定めた時——その世界の力を集めた戦車に乗ろうとすると、ヴェーダから生まれた馬たちは頭を地に垂れて倒れた。
ubhābhyāṃ lokanāthābhyām āsthitaṃ rathasattamam|
oḍhuṃ na śaktā vedāśvā jānubhyām apatan mahīm|| // 8-27-23 //
（23）二人の世界の主がともに乗った最上の戦車を引くことができず、ヴェーダの馬たちは膝から崩れ落ちた。
abhīśubhis tu bhagavān udyamya ca hayān vibhuḥ|
astu vīryaṃ ca śauryaṃ ca vedāśvānām iti prabhuḥ|
rathaṃ sañcodayāmāsa devānāṃ prabhuravyayaḥ|| // 8-27-24 //
（24）しかし至高の神は手綱で馬たちを引き起こし、『ヴェーダの馬たちに力と武勇あれ』と命じ、不滅の天の神々の主は戦車を走らせた。
tato'dhirūḍhe varade rathaṃ paśupatis tadā|
sādhusādhviti deveśaṃ smayamāno'bhyabhāṣata|| // 8-27-25 //
（25）恩寵を与える方が戦車に乗り込むと、パシュパティ（家畜の主＝シヴァ）は微笑みながら天の神の主に言った。『よし、よし。
yāhi deva yato daityāś codaya aśvān arindama|
paśya bāhvor balaṃ me'dya nighnataḥ śātravān raṇe|| // 8-27-26 //
（26）神よ、悪魔のいるところへ行け。馬を走らせよ、敵を滅ぼす者よ。我が両腕の力で敵を打ち倒す様を今日見るがよい。』
tato'śvāṃś codayāmāsa manomārutaraṃhasaḥ|
purāṇyuddiśya khasthāni dānavānāṃ tarasvinām|| // 8-27-27 //
（27）そこでブラフマーは心と風のように速い馬を走らせ、空に浮かぶ強大な悪魔たちの都市を目指した。
tatas te sahasotpatya vedākhyā rathavājinaḥ|
kṣaṇena tena daityānāṃ purāṇi prāpayan haram|| // 8-27-28 //
（28）するとヴェーダという名の戦車の馬たちは一瞬にして飛び立ち、一瞬のうちにハラ（シヴァ）を悪魔たちの都市に到達させた。
atharvāṅgirasau cāstāṃ cakrarakṣau mahātmanaḥ|
athādhijyaṃ dhanuḥ kṛtvā śarvaḥ sandhāya taṃ śaram|
yuktvā pāśupatāstreṇa tripuraṃ samacintayat|| // 8-27-29 //
（29）アタルヴァとアンギラスの両ヴェーダが偉大なる魂の車輪の護衛として立った。そしてシャルヴァ（シヴァ）は弓に弦を張り、あの矢をつがえ、パーシュパタ武器を込めて、トリプラに狙いを定めた。
tasmin sthite tato rājan rudre sajjitakārmuke|
purāṇi tena kālena jagmur ekatvam āśu vai|| // 8-27-30 //
（30）王よ、ルドラが弓を引き構えて立っているその時、都市は次々と一つに合体し始めた。
ekībhāvaṃ gate caiva tripuratvam upāgate|
babhūva tumulo harṣo devatānāṃ mahātmanām|| // 8-27-31 //
（31）三つの都市が一つになってトリプラ（三都市）となった時、偉大な魂を持つ天の神々の間に大きな歓喜が湧き起こった。
tato devaguṇāḥ sarve siddhāś ca paramarṣayaḥ|
jayeti vāco mumucuḥ saṃstuvanto maheśvaram|| // 8-27-32 //
（32）そして天の神の群れも、成就者も、大聖仙たちも皆、マヘーシュヴァラを讃えながら『勝利あれ』と声を上げた。
tato'grataḥ prādurabhūt tripuraṃ jaghnuṣo'surān|
anirdeśyāgryavapuṣo devasyāsahyatejasaḥ|| // 8-27-33 //
（33）そこでトリプラの前に——阿修羅を殺そうとする者の前に——言い表し難い最上の姿を持ち、耐え難い威光の神が現れた。
trīṇi dṛṣṭvaiva saṃsthāni purāṇy atha pinākadhṛt|
sa tad vikṛṣya bhagavān divyaṃ lokeśvaro dhanuḥ|
trailokyasāraṃ tamiṣuṃ mumoca tripuraṃ prati|| // 8-27-34 //
（34）三つに集まった都市を見て、ピナーカの弓を持つ者は、至高の神は世界の主はその神聖な弓を引き絞り、三界の精髄たるあの矢をトリプラに向けて放った。
ekabāṇena taṃ devas tripuraṃ parameśvaraḥ|
nijaghne sāsuragaṇaṃ devadevo maheśvaraḥ|| // 8-27-35 //
（35）天の神の中の神、マヘーシュヴァラ、偉大なる神は、一本の矢でそのトリプラを、阿修羅の群れもろとも打ち砕いた。
bāṇatejognidagdhaṃ tad viprakīrṇaṃ sahasradhā|
mahadārtasvaraṃ kṛtvā nāvaśeṣamupāgatam|
madreśa sāsuragaṇaṃ prāpatat paścimārṇave|| // 8-27-36 //
（36）矢の威光の火に焼かれたトリプラは千に砕け散り、大きな悲鳴を上げて跡形もなくなった。マドラの王よ、阿修羅の群れともども西の海に落ちた。
evaṃ hi tripuraṃ dagdhaṃ dānavāś cāpy aśeṣataḥ|
maheśvareṇa kruddhena trailokyasya hitaiṣiṇā|| // 8-27-37 //
（37）こうしてトリプラは焼かれ、悪魔たちも残らず滅ぼされた。三界の利益を願う怒れるマヘーシュヴァラによって。
sa cātmakrodhajo vihnir dahety ukto nivāritaḥ|
trailokyamaviśeṣeṇa punardagdhuṃ pracakrame|| // 8-27-38 //
（38）そしてシヴァ自身の怒りから生まれた炎は、『焼け』と命じられたが、三界を区別なく焼き尽くそうとし始め、制止された。
kālāgnim iva nirdagdhum utthitaṃ taṃ punaḥ punaḥ|
mākārṣīr bhasmāsāl lokān iti tryakṣo'bravīd vacaḥ|| // 8-27-39 //
（39）世界を終わらせる炎のように立ち上がるその火を、何度も繰り返し——『世界を灰にするな』と三つ目の神は命じた。
tataḥ prakṛtimāpannā devalokāḥ tathā ṛṣayaḥ|
tuṣṭuvur vāgbhir agryābhiḥ sthāṇuṃ tripuravairiṇam|| // 8-27-40 //
（40）そこで天の世界と聖仙たちは本来の姿に戻り、最上の言葉をもってスターヌ（不動の者）、トリプラの敵を讃えた。
te'nujñātā bhagavatā sarve jagmur yathāgatam|
kṛtakāmāḥ prasannena prajāpatimukhāḥ surāḥ|| // 8-27-41 //
（41）至高の神に許されて、皆は来た時のように帰って行った。願いをかなえられた者たちは、満足した方に——プラジャーパティを先頭とする天の神々は。
evaṃ rudrasya kṛtavān sārathyaṃ tu pitāmahaḥ|
saṃyaccha turagān asya rādheyasya mahātmanaḥ|| // 8-27-42 //
（42）このようにしてルドラの御者を祖父神ブラフマーが務めたのだ。同じように、お前もラーデーヤという偉大な魂のために馬の手綱を握ってくれ。
tvaṃ hi kṛṣṇāc ca karṇāc ca phalgunāc ca guṇādhikaḥ|
balato rūpato yogādastrasampada eva ca|| // 8-27-43 //
（43）お前はクリシュナよりも、カルナよりも、アルジュナよりも、力において、姿において、技量において、武器の集まりにおいて優れている。
samāsaktaṃ mahīpāla kuru me hitam īpsitam|
yuddhe hy ayaṃ rudrakalpas tvaṃ ca brahmasamo'nagha|
tasmāc chaktau yuvāṃ jetuṃ macchatrūn divi vā surān|| // 8-27-44 //
（44）差し迫った状況だ、王よ。望まれる利益のために働いてくれ。この者（カルナ）は戦場でルドラに等しく、お前はブラフマーに等しい、罪なき者よ。だからお前たち二人こそ、我が敵を——天にあっては天の神をも——打ち負かす力がある。
sa yathā śalya karṇo'yaṃ śvetāśvaṃ kṛṣṇasārathim|
pramathya hanyāt kaunteyaṃ tathā nītir vidhīyatām|| // 8-27-45 //
（45）シャリヤよ、このカルナがシュヴェターシュヴァ（白い馬の戦車）を持ちクリシュナを御者とするカウンテーヤを打ち倒して殺すように——そのような策を講じてくれ。
tvayi rājyaṃ sukhaṃ caiva jīvitaṃ jayam eva ca|
samāsaktaṃ mahīpāla kuru me hitamīpsitam|| // 8-27-46 //
（46）あなたに王国も安楽も、命も勝利もかかっている、王よ。望まれる利益のために働いてくれ。
saṃyaccha asya hayān rājan matpriyārthaṃ parantapa|| || // 8-27-47 //
（47）敵を滅ぼす者よ、私のために、王よ、彼（カルナ）の馬の手綱を握ってくれ。」
iti śrīmanmahābhārate karṇaparvaṇi saptaviṃśo'dhyāyaḥ|| 27 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十七章は終わる。
