◆ 冒頭の偈
ati-gambhīre bhūpe kūpa iva janasya nir-avatārasya /
dadhati samīhita-siddhiṃ guṇavantaḥ pārthivā ghaṭakāḥ // 2.1 //
あまりに深淵なる王のもとでは、庶民にとって井戸のように近づきがたい。（そこで）有徳の大臣たちが滑車のように、人々の願望の成就をもたらす。

an-apekṣita-guṇa-doṣaḥ parôpakāraḥ satāṃ vyasanam // 2.2 //
太陽は、情熱的な蓮華に、太陽自身から生じた女神ラクシュミー（輝き）を授ける。善き人々の営みは、功罪を問わず他者を利することである。

tathā-bhūte ca tasminn aty-ugre grīṣma-samaye kadā-cid asya sva-gṛhâvasthitasya bhuktavato 'parâhṇa-samaye bhrātā pāraśavaś Candrasena-nāmā praviśyâkathayat: "eṣa khalu devasya catuḥ-samudrâdhipateḥ sakala-rāja-cakra-cūḍā-maṇi-śreṇī-śāṇa-koṇa-kaṣaṇa-nirmalī-kṛta-caraṇa-nakha-maṇeḥ sarva-cakra-vartināṃ dhaureyasya mahā-rājâdhirāja-paramêśvara-śrī-Harṣa-devasya bhrātrā Kṛṣṇa-nāmnā bhavatām antikaṃ prajñātatamo dīrghâdhva-gaḥ prahito dvāram adhyāste" iti. so 'bravīt: "āyuṣman, a-vilambitaṃ praveśayâinam" iti.
そのような極めて苛烈な夏のある日、自宅にいて食事を終えた午後、異母弟のチャンドラセーナが入って来て告げた。「四海の支配者、すべての王の冠宝石の列を研ぐ砥石の角で磨かれた足の爪の宝石を持つ、すべての転輪聖王の中の至高者、大王の中の王にして至高主シュリー・ハルシャデーヴァの兄弟であるクリシュナ様から、最も信頼厚い長旅の使者が門前に控えております」と。バーナは言った。「直ちに通しなさい」。

そして連れてこられた使者を見た。極めて長い旅で重く鈍った脚の、泥まみれの衣の端で手荒いチャンダータカ（下衣）を押さえ、背に揺れるぼろ布のつなぎ目を首に結び、極めて密な糸の縛りで間隔を作った書簡の束で頭を巻いた、書簡運び人が入ってくるのを見た。そして遠くから尋ねた。「善き者よ、全世界の無条件の友であるクリシュナ殿は息災であるか」。彼は「息災です」と言い、礼拝して近くに座った。休息してから言った。「主人より敬うべき方への書簡が送られました」と紐を解いて差し出した。バーナは丁重に受け取り、自ら読み上げた。「メーカラカより申し述べる。智者は果報の障害となる時間の浪費を避けるべきである。これが要旨。その他は消息を伝える程度のものである」。書簡の趣旨を理解し、従者を退出させてから口頭の伝言を尋ねた。メーカラカは言った。「主人はこう仰せです。『貴殿はよくご存知のとおり、同じゴートラ（氏族）であること、同じ学問であること、同じカーストであること、共に育ったこと、同じ土地に住むこと、頻繁に会うこと、相互の愛情、噂を聞くこと、陰ながらの恩恵、同じ性格であること――これらが友情の原因である。しかし貴殿に対しては、理由もなく、まだ会ったことのない近しい親族のように、私の心は何かしら親愛を抱いている。遠くにいても、月が夜蓮の池に対するように。なぜなら、貴殿がいなかったため、この転輪聖王は悪人たちにさまざまに吹き込まれていた。しかしそれは真実ではない。善き人にさえ敵・中立・味方がいないということはあり得ない。
Śiśu-cāpalâparācīna-ceto-vṛttitayā ca bhavataḥ kena-cid a-sahiṣṇunā yat-kiñ-cid a-sadṛśam udīritam. itaro lokas tathâiva tad gṛhṇāti vakti ca. salilānîva gatânugatikāni lolāni khalu bhavanty a-vivekināṃ manāṃsi. bahu-mukha-śravaṇa-niścalī-kṛta-niścayaś ca kiṃ karotu pṛthivī-patiḥ. Tattvânveṣibhiś câsmābhir dūra-sthito 'pi pratyakṣī-kṛto 'si. vijñaptaś cakravartī tvad-artham: yathā prāyeṇa prathame vayasi sarvasyâiva cāpalaiḥ śaiśavam aparādhîti. tathêti ca svāminā pratipannam. ato bhavatā rāja-kulam a-kṛta-kāla-kṣepam āgantavyam. avakeśîvâdṛṣṭa-paramêśvaro bandhu-madhyam adhivasann api na me bahu-mataḥ. na ca sevā-vaiṣamya-viṣādinā paramêśvarôpasarpaṇa-bhīruṇā vā bhavatā bhavitavyam. yato yady api:
書簡の趣旨を理解し、従者を退出させてから口頭の伝言を尋ねた。メーカラカは言った。「主人はこう仰せです。『貴殿はよくご存知のとおり、同じゴートラ（氏族）であること、同じ学問であること、同じカーストであること、共に育ったこと、同じ土地に住むこと、頻繁に会うこと、相互の愛情、噂を聞くこと、陰ながらの恩恵、同じ性格であること――これらが友情の原因である。しかし貴殿に対しては、理由もなく、まだ会ったことのない近しい親族のように、私の心は何かしら親愛を抱いている。遠くにいても、月が夜蓮の池に対するように。なぜなら、貴殿がいなかったため、この転輪聖王は悪人たちにさまざまに吹き込まれていた。しかしそれは真実ではない。善き人にさえ敵・中立・味方がいないということはあり得ない。貴殿の少年時代の軽率さゆえに、心の向きが反対であった誰かが、何かしら相応しくないことを言ったのだ。世間はそのまま受け取り、繰り返す。水のように流れに従うのが、分別なき者の心というものだ。多くの口から聞いて確信を固められた王に何ができようか。しかし真実を探る我々は、遠くにいても貴殿を目の当たりにしている。転輪聖王には貴殿のために申し上げた。「おおよそ最初の若さにおいては、誰にでも軽率さという罪がある」と。そして主人もそのとおりだと認められた。ゆえに貴殿は時を失わず王宮に来られたい。至高主に謁見せずに親族の中に住む者は、剃髪しても私には重んじられない。また、仕えることの不公平さに悩んだり、至高主に近づくことを恐れたりしてはならない。なぜなら、たとえ：
tathâpy anye te bhū-patayaḥ, anya evâyam. このことを否定はいたしません。そしてまさにこの過去の過ちを、私の心は悔いているかのようです。しかし今や、ブッダのように静まった心の、マヌのようにヴァルナとアーシュラマの秩序の創始者の、自らダンダ（法の杖）を持つかのような主が、七つの海を帯とする全島嶼の大地を統治される今日、一体誰が怖れることなく、すべての悪徳の友である不作法の模倣を心にさえ企てるでしょうか。人間どもはさておき、陛下のご威光により、蜂ですら恐れるかのように蜜を飲み、チャクラヴァーカ鳥ですら恥じるかのように恋人への追従の悪癖を控え、猿ですら怯えたかのように軽率に振る舞い、虎ですら慈悲深いかのように肉を食べます。いずれにせよ、時が経てば主人は私を自ずとお知りになるでしょう。なぜなら、智慧ある者の性情は、正しき心の動きを捉えるものだからです」。こう述べて沈黙した。王もまた「我々もそのように聞いている」とだけ仰せになって沈黙された。しかし会話の席と座の供与などの恩寵によって彼を受け入れた。ただ甘露の雨で沐浴させるかのような、愛情を孕んだ一瞥だけで、内に秘めた喜びを告げた。

バーナもまた退出して、洗い清められた赤銅のような柔らかい夕日の輝きに一日が冷めゆくなか、西山の頂の冠にニクラの花房のような光線を放つ太陽が天から消え、反芻に気だるいガゼルの群れが柔らかい牧場の背に座る森の空き地に、別離の悲しみに泣くチャクラヴァーカ鳥の雌の悲鳴が響く川岸に、止まり木に止まった騒がしい雀の群れが取り巻く灌漑用の水桶のある庭園に、昼の散歩から戻って乳を滴らせる母牛の群れに飢えた仔牛の群れが吸い付き、やがて夕日の円盤が黄昏の海の杯のように赤く沈み、水瓶の水で清浄な足の祠堂に礼拝するパーラーシャリたち（学者）が、祭具を手に清浄な撒き散らされたクシャ草の上に炎を上げるアグニ（火神）にホーマの供物を捧げるヤジュル・ヴェーダの祭官たちが、眠りに目覚めたフクロウの一族が古木の洞から出立し、千の聖仙の手から散りまかれた夕暮れの礼拝の水滴の群れのように星の群れが夜の野蛮な女の髪飾りのように空に広がるころ――カルティケーヤの斧のような三日月の喉元の闇が幼い残光を呑み込み、暗闇を脅す灯火が、炎に入った太陽の手の枝のように揺らめき、寝台に就いて老婆の語る物語に眠りゆく子どもたち、老いた水牛の墨のように黒い闇に信心深い者たちの不寝番が起こされ、恐ろしき闘暗の口が大きく開き、絶え間なく弦を鳴らす弓からすべての衆生の賢さを奪う矢の群れを放つ愛の旗印マカラ（鯨魚旗の神カーマ）が現れ、情事の支度に美しく装い始めた侍女たち、腰紐の網を結ばれる女たちの腰が鳴り、媚薬の矢に操られ片膝だけの歩みで忍び出る密会の女たち（アビサーリカー）の夜に――

婦人たちの足首飾りのチリンチリンと鳴る鈍い囁きに蜂の群れがまばらになり、眠りから覚めて長く鳴くサーラサ鳥の声が離別の恋人たちの心を溶かすころ、来たるべき日の種子の芽のように灯火の群れが世界に撒かれるなか、宿舎に戻った。そして心のなかでこう考えた。「まことに恵み深い方であるハルシャ王は、数々の少年時代の軽率さにふさわしい家柄への怒りを抱きながらも、心では私を慈しんでおられる。もし私が目の前にいたならば、会うことで恩寵を示されたであろう。しかし私が有徳であることを望んでおられるのだ。主人は仕える者に対して、言葉なしに、ふさわしい待遇を以って、礼儀を教えるものだ。恥ずかしいことだ、己の過ちに盲いて、軽蔑に苦しみながらも、かくも有徳な王についてああでもないこうでもないと考えていた私は。いずれ時が経てば私のありのままを知っていただけるよう、あらゆることをしよう」。こう決意して翌日、陣営を出て友人や親族の家にしばらく留まった。そしてやがて王自ら彼の本性を見抜き、恩寵を与えるに至った。再び王宮に入り、わずかの日々で最高の喜悦をもって、恩寵から生じた敬意・愛情・信頼・財・親しき冗談・権威の極みにまで王によって引き上げられた。
