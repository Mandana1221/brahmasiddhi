マハーバーラタ ― カルナ篇 第91章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 91 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ91」で、カルナとアルジュナの一騎討ちへの突入、および天界の者たちの参集の場面を描きます。
karṇaparva — ekanavatitamo'dhyāyaḥ (91)
第91章 ― カルナとアルジュナの一騎討ちへの突入、天界の者たちの参集
sañjaya uvāca|
vṛṣasenaṃ hataṃ dṛṣṭvā krodhāmarṣasamanvitaḥ|
putraśokodbhavaṃ vāri netrābhyāṃ samavāsṛjat||
// 8-91-1 //
サンジャヤは語った。
ヴリシャセーナ（カルナの息子）が討たれたのを見て、カルナは怒りと悔しさに満たされた。息子を失った悲しみから、その両目から涙をあふれさせた。
rathena karṇastejasvī jagāmābhimukho ripum|
yuddhāyāmarpatāmrākṣaḥ samāhūya dhanañjayam||
// 8-91-2 //
輝かしきカルナは戦車に乗り、敵に向かって進んだ。怒りで目を赤く染め、ダナンジャヤ（アルジュナ）を戦いに呼びかけた。
tau rathau sūryasaṅkāśau vaiyāghraparivāritau|
sametau dadṛśustatra dvāvivārkau samudgatau||
// 8-91-3 //
太陽のように輝く二台の戦車が、虎の皮で覆われ、まるで天に昇った二つの太陽のように見えた。
śvetāśvau puruṣādityāvāsthitāvarimardanau|
śuśubhāte mahātmānau candrādityau yathā divi|
'rathau caturbhirjaladairbhagamitrāvivāmbare'||
// 8-91-4 //
白い馬を駆る、人の中の太陽ともいうべき二人の偉大な戦士が、敵を打ち砕く者として立ち、天空の月と太陽のように輝いた。
tau dṛṣṭvā vismayaṃ jagmuḥ sarvasainyāni māriṣa|
trailokyavijaye yattāvindravairocanāviva||
// 8-91-5 //
この二人の姿を見て、全軍が驚嘆した。まるでインドラとヴァイローチャナ（バリ）が三界の支配をかけて争うかのようであった。
rathajyātalanirhādairbāṇaśaṅkharavaistathā|
tau rathāvabhyadhāvanta kṣatriyāḥ sarva eva hi||
// 8-91-6 //
戦車の車輪の音、弓弦の音、矢の音、法螺貝の音を響かせながら、二台の戦車が突進すると、すべてのクシャトリヤたちが駆け寄った。
dhvajāvālokya vīrāṇāṃ vismayaḥ samapadyata|
hastikakṣyāṃ ca karṇasya vānaraṃ ca kirīṭinaḥ||
// 8-91-7 //
勇者たちの旗印を見て、人々は驚嘆した。カルナの象の腹帯の旗と、キリーティン（アルジュナ）の猿の旗を。
tau rathau samprasaktau tu dṛṣṭvā bhārata pārthivāḥ|
siṃhanādaravāṃścakruḥ sādhuvādāṃś ca puṣkalān||
// 8-91-8 //
バーラタの王よ、この二台の戦車が激突するのを見て、王たちは獅子の咆哮をあげ、「素晴らしい！」と盛んに喝采した。
śrutvā tayordvairathaṃ ca tatra yodhāḥ sahasraśaḥ|
cakrurbāhusvanāṃścaiva tathā bāṇaravaṃ mahat||
// 8-91-9 //
二人の一騎討ちを聞いて、何千もの兵士たちが腕を叩き鳴らし、矢を射って大歓声をあげた。
ājaghnuḥ kuravastatra vāditrāṇi samantataḥ|
rādheyamabhito dadhmuḥ śaṅkhāñśatasahasraśaḥ||
// 8-91-10 //
カウラヴァ勢はあたり一面で楽器を打ち鳴らし、ラーデーヤ（カルナ）の周りで何十万もの法螺貝を吹き鳴らした。
tathaiva pāṇḍavāḥ sarve harṣayanto dhanañjayam|
tūryaśaṅkhaninādena diśaḥ sarvā vyanādayan||
// 8-91-11 //
同じようにパーンダヴァ勢もすべて、ダナンジャヤを鼓舞し、楽器と法螺貝の音で四方を響かせた。
kṣvelitāsphoṭitotkruṣṭaistumulaṃ sarvato'bhavat|
bāhuśabdaiś ca śūrāṇāṃ karṇārjunasamāgame||
// 8-91-12 //
口笛、手を叩く音、歓声が入り混じり、カルナとアルジュナの激突に際して、勇者たちの腕を叩く音とともに大騒然となった。
tau dṛṣṭvā puruṣavyāghrau rathasthau rathināṃ varau|
pragṛhītamahācāpau śaraśaktidhvajāyutau||
varmiṇau baddhanistriṃśau śvetāśvau śaṅkhaśobhitau|
tūṇīravasampannau dvāvapyetau sudarśanau||
// 8-91-13-14 //
人々は、この二人の人中の虎を見た。戦車に立ち、大弓を構え、矢と槍と旗を備え、鎧を着け、剣を帯び、白い馬に乗り、法螺貝で飾られ、矢筒を備えた二人は、いずれも美しい姿であった。
raktacandanadigdhāṅgau samadau govṛṣāviva|
cāpavidyuddhvajopetau śastrasampattiyodhinau||
// 8-91-15 //
赤い白檀を全身に塗り、牧場の二頭の雄牛のように堂々とし、弓は稲妻のごとく、旗をなびかせ、武器の技に秀でた戦士たちであった。
cāmaravyajanopaitau śvetacchatropaśobhitau|
kṛṣṇaśalyarathopetau tulyarūpau mahārathau||
// 8-91-16 //
白い払いの扇と白い日傘で飾られ、クリシュナとシャリヤが御者を務める二台の戦車に乗り、等しい姿の偉大な戦車戦士であった。
siṃhaskandhau dīrghabhujau raktākṣau hemamālinau|
siṃhaskandhapratīkāśau vyūḍhoraskau mahābalau|
anyonyavadhamicchantāvanyonyajayakāṅkṣiṇau||
// 8-91-17 //
獅子のような肩、長い腕、赤い目、黄金の首飾り、獅子のような体格、広い胸、大いなる力。互いに相手を討ち取ろうと望み、互いの勝利を渇望していた。
anyonyamabhidhāvantau goṣṭhe govṛṣabhāviva|
prabhinnāviva mātaṅgau susaṃrabdhāvivācalau||
// 8-91-18 //
牧場の二頭の雄牛のように互いに突進し、狂った二頭の象のように、怒り猛る二つの山のようであった。
āśīviṣaśiśuprakhyau yamakālāntakopamau|
indravṛtrāviva kruddhau sūryacandrasamaprabhau||
// 8-91-19 //
毒蛇の子のように恐ろしく、ヤマ（死神）やカーラ（時）や終末の破壊者に等しく、インドラとヴリトラのように怒り、太陽と月のように輝いていた。
mahāgrahāviva kruddhau yugāntāya samutthitau|
devagarbhau devasamau devatulyau ca rūpataḥ||
// 8-91-20 //
世界の終末のために現れた二つの大惑星のように怒り、神の胎から生まれ、神に等しく、容姿も神のようであった。
yadṛcchayā samāyātau sūryācandramasau yathā|
balinau samare dṛptau nānāśastradharau yudhi||
// 8-91-21 //
偶然出会った太陽と月のように、戦場で誇り高く、さまざまな武器を手にしていた。
tau dṛṣṭvā puruṣavyāghrau śārdūlāviva dhiṣṭhitau|
babhūva paramo harṣastāvakānāṃ viśāmpate||
// 8-91-22 //
虎のように立つこの二人の人中の虎を見て、おまえの軍勢には最高の歓喜が起こった、王よ。
saṃśayaḥ sarvabhūtānāṃ vijaye samapadyata|
sametau puruṣavyāghrau prekṣya karṇadhanañjayau||
// 8-91-23 //
カルナとダナンジャヤが相まみえるのを見て、すべての生きとし生けるものに、どちらが勝つかという疑念が生じた。
ubhau varāyudhadharāvubhau raṇakṛtaśramau|
ubhau ca bāhuśabdena nādayantau nabhastalam||
// 8-91-24 //
二人とも最高の武器を持ち、二人とも戦い慣れ、二人とも腕を叩く音で天空を響かせていた。
ubhau viśrutakarmāṇau pauruṣeṇa balena ca|
ubhau ca sadṛśau yuddhe śambarāmararājayoḥ||
// 8-91-25 //
二人とも武勇と力で名高い功績を持ち、二人とも戦いにおいてシャンバラと天の王（インドラ）に匹敵した。
kārtavīryasamau cobhāvubhau dāśaratheḥ samau|
viṣṇuvīryasamau cobhāvubhau bhavasamau yudhi||
// 8-91-26 //
二人ともカールタヴィーリヤに等しく、ダーシャラティ（ラーマ）に等しく、ヴィシュヌの武勇に等しく、シヴァに等しかった。
ubhau śvetahayau rājanrathapravaravāhinau|
sārathipravarau cāpi ubhau madrajanārdanau||
// 8-91-27 //
王よ、二人とも白い馬に乗り、最高の戦車を駆り、最高の御者を持っていた。マドラ王（シャリヤ）とジャナールダナ（クリシュナ）である。
tato dṛṣṭvā mahārāja rājamānau mahārathau|
siddhacāraṇasaṅghānāṃ vismayaḥ samapadyata||
// 8-91-28 //
大王よ、輝く二人の大戦車戦士を見て、シッダたちとチャーラナたちの群れに驚嘆が広がった。
dhārtarāṣṭrāstatastūrṇaṃ sabalā bharatarṣabha|
parivavrurmahātmānaṃ karṇamāhavaśobhinam||
// 8-91-29 //
バーラタの雄牛よ、ドリタラーシュトラの息子たちは軍勢を率いて、すぐさま戦場で輝くカルナを取り囲んだ。
tathaiva pāṇḍavā dṛṣṭvā dhṛṣṭadyumnapurogamāḥ|
yamau ca cekitānaś ca prahṛṣṭāś ca prabhadrakāḥ||
nānādeśyāś ca ye śūrāḥ śiṣṭā yuddhābhinandinaḥ|
te sarve sahitā hṛṣṭāḥ parivavrurdhanañjayam||
// 8-91-30-31 //
同じようにパーンダヴァ勢も、ドリシュタデュムナを先頭に、双子（ナクラとサハデーヴァ）、チェーキターナ、喜びにあふれたプラバドラカたちが、各地から集まった勇者たち、戦いを好む残りの者たちもすべて、喜んでダナンジャヤを取り囲んだ。
rirakṣiṣantaḥ śathrughnāḥ pattyaśvarathakuñjarāḥ|
dhanañjayasya vijaye dhṛtāḥ karṇavadhe'pi ca||
// 8-91-32 //
敵を討つ者たち、歩兵・騎兵・戦車兵・象兵が、ダナンジャヤの勝利とカルナの討伐に心を定めて、彼を守ろうとした。
tathaiva tāvakāḥ sarve yattāḥ senāprahāriṇaḥ|
duryodhanamukhā rājankarṇaṃ jugupurāhave||
// 8-91-33 //
同じく、おまえの軍勢もすべて戦いに備え、ドゥルヨーダナを先頭に、戦場でカルナを守った。
tāvakānāṃ raṇe karṇo glaho hyāsīdviśāmpate|
tathaiva pāṇḍaveyānāṃ glahaḥ pārtho'bhavattadā||
// 8-91-34 //
王よ、おまえの軍にとってカルナは賭けの骰子であった。同じように、パーンダヴァ勢にとってはパールタ（アルジュナ）が骰子であった。
tayostu sabhyāstatrāsanprekṣakāścābhavanyudhi|
tatraiṣāṃ glahamānānāṃ dhruvau jayaparājayau||
// 8-91-35 //
二人にとって審判がおり、観客がいた。この賭けをする者たちにとって、勝利と敗北は確実であった。
tābhyāṃ dyataṃ samāsaktaṃ vijayāyetarāya vā|
asmākaṃ pāṇḍavānāṃ ca sthitānāṃ raṇamūrdhani||
// 8-91-36 //
両軍が戦場の先頭に立つ中、この二人による賭けが、勝利かさもなくば敗北のために始まったのだ。
tau tu sthitau mahārāja samare yuddhaśālinau|
anyonyaṃ pratisaṃrabdhāvanyonyavadhakāṅkṣiṇau||
// 8-91-37 //
大王よ、戦場での戦いに秀でたこの二人は、互いに怒りを燃やし、互いの死を望んで立っていた。
tāvumau prajihīrṣantāvindravṛtrāviva prabho|
bhīmarūpadharāvāstāṃ mahādhūmāviva grahau||
// 8-91-38 //
インドラとヴリトラのように互いを打ち倒そうとし、大きな煙を上げる二つの惑星のように恐ろしい姿であった。
tato'ntarikṣe sañjajñe vivādo bharatarṣabha|
mitho bhedāś ca bhūtānāmāsankarṇārjunāntare||
// 8-91-39 //
バーラタの雄牛よ、すると天空で論争が起こった。カルナとアルジュナの間をめぐって、生きとし生けるものたちの間に意見の分裂が起こった。
vyāśrayanta dvidhā bhinnāḥ sarve lokāstu māriṣa|
devadānavagandharvāḥ piśācoragarākṣasāḥ|
pratipakṣagrahaṃ cakruḥ karṇārjunasamāgame||
// 8-91-40 //
すべての世界の者が二つに分かれた。神々、ダーナヴァ（魔族）、ガンダルヴァ（天の楽士）、ピシャーチャ（餓鬼）、蛇族、ラークシャサ（羅刹）が、カルナとアルジュナの激突においてそれぞれの側についた。
dyaurāsītkarṇapakṣe'tra sanakṣatrā viśāmpate|
bhūrviśālā pārthamātā putrasya jayakāṅkṣiṇī||
// 8-91-41 //
王よ、星々を従えた天空はカルナの側についた。一方、広大な大地は、パールタ（アルジュナ）の母として、息子の勝利を願った。
sāgarāścaiva girayaḥ saritaś ca narottama|
mahījā jalajāścaiva vyāśrayanta kirīṭinam||
// 8-91-42 //
海も山も河も、地に生まれたもの水に生まれたものも、キリーティン（アルジュナ）の側についた。
asurā yātudhānāś ca guhyakāś ca parantapa|
karṇaḥ samabhavadyatra khecarāṇi vayāṃsi ca||
// 8-91-43 //
アスラ（阿修羅）、ヤートゥダーナ（夜叉の一種）、グヒヤカ（秘密の精霊）、空を飛ぶ者たち、鳥たちはカルナの側についた。
ratnāni nidhayaḥ sarve vedāścākhyānapañcamāḥ|
sopavedopaniṣado vyāśrayanta kirīṭinam||
// 8-91-44 //
宝石、あらゆる宝蔵、叙事詩を第五番目とする四つのヴェーダ、副ヴェーダやウパニシャッドとともにキリーティンの側についた。
vāsukiścitrasenaś ca takṣakaścopatakṣakaḥ|
mahīviyajjalacarāḥ kādraveyāś ca sānvayāḥ|
viṣavanto mahānāgā veginaścārjune'bhavan||
airāvatāḥ saurabheyā vaiśāleyāś ca bhoginaḥ|
ete'bhavannarjunasya pāpāḥ sarpāś ca karṇataḥ||
// 8-91-45-46 //
ヴァースキ、チトラセーナ、タクシャカ、ウパタクシャカ、地を這い水に住むカードラヴェーヤ族とその一族、毒を持つ大蛇たち、素早い蛇たちはアルジュナの側についた。アイラーヴァタ族、サウラベーヤ族、ヴァイシャーレーヤ族の蛇たちもアルジュナの側につき、邪悪な蛇たちはカルナの側についた。
īhāmṛgā vyālamṛgā maṅgalā mṛgapakṣiṇaḥ|
maṅgalāḥ paśavaścaiva siṃhavyāghrāstathaiva ca|
pārthasya vijaye rājansarva eva samāśritāḥ||
// 8-91-47 //
鹿、猛獣、吉祥な動物や鳥、吉祥な家畜、獅子や虎も、すべてパールタの勝利の側についた。
vasavo marutaḥ sādhyā rudrā devāśvināvapi|
agnī rudraś ca somaś ca pannagāś ca diśo daśa|
karṇataḥ samapadyanta śvasṛgālavayāṃsi ca||
// 8-91-48 //
ヴァス神群、マルト神群、サーディヤ神群、ルドラ神群、アシュヴィン双神、アグニ、ルドラ、ソーマ、蛇神たち、十方はカルナの側につき、犬やジャッカルや鳥もカルナの側についた。
vasavaś ca mahendreṇa marutaś ca sahāgninā|
dhanañjayasya te vargā ādityāḥ karṇato'bhavan||
// 8-91-49 //
しかし、ヴァス神群はマヘーンドラ（インドラ）とともに、マルト神群はアグニとともにダナンジャヤの側についた。アーディティヤ神群はカルナの側についた。
devatāḥ pitṛbhiḥ sārdhamṛṣibhiś ca parantapa|
tumburupramukhāḥ sarve gandharvā bharatarṣabha|
yamau vaiśravaṇaścaiva varuṇaś ca yato'rjunaḥ||
// 8-91-50 //
神々は祖霊や聖仙たちとともに、トゥンブル（天楽士の長）を先頭にすべてのガンダルヴァたちも、ヤマの双子、ヴァイシュラヴァナ（クベーラ）、ヴァルナもアルジュナの側についた。
devarṣibrahmarṣigaṇāḥ sarve ca khacarāś ca ye prāleyāḥ sahamauneyāḥ śubhāścāpsarasāṃ gaṇāḥ||
sahāpsarobhiḥ śubhrābhirdevadūtāś ca guhyakāḥ|
kirīṭinaṃ saṃśritāḥ sma puṇyagandhā manoramāḥ||
// 8-91-51-52 //
デーヴァリシ（天の聖者）やブラフマリシ（梵の聖者）の群れ、すべての空を飛ぶ者たち、ヒマラヤの者たち、マウネーヤ族、美しいアプサラスの群れ、輝くアプサラスたちとともに天の使者やグヒヤカたちも、芳香を放つ美しい者たちとして、キリーティンの側についた。
amanojñāś ca ye gandhāste sarve karṇamāśritāḥ|
viparītānyaniṣṭāni bhavanti vinaśiṣyatām||
// 8-91-53 //
不快な匂いはすべてカルナの側についた。滅びゆく者のもとには、縁起の悪い逆のものごとが起こるのである。
ye tvantakāle puruṣaṃ viparītamupāśritam|
praviśanti naraṃ kṣipraṃ mṛtyukāle'bhyupāgate|
te bhāvāḥ sahitāḥ karṇaṃ praviṣṭāḥ sūtanandanam||
// 8-91-54 //
死の時が近づいた人間のもとに、逆転したものが入り込むように、それらの兆候がまとまってカルナ、スータの息子のもとに入り込んだ。
ojastejaś ca siddhiś ca praharṣaḥ satyavikramau|
manastuṣṭirjayaścāpi tathā''nando nṛpottama||
// 8-91-55 //
力、輝き、成就、歓喜、真実と勇武、心の満足、勝利、そして喜び――。
īdṛśārni naravyāgh tasminsaṅgrāmasāgare|
nimittāni ca śubhrāṇi viviśurjiṣṇumāhave||
// 8-91-56 //
人中の虎よ、この戦いの大海において、こうした輝かしい吉兆がすべて、戦場でジシュヌ（アルジュナ）のもとに入った。
ṛṣayo brāhmaṇaiḥ sārdhamabhajanta kirīṭinam||
// 8-91-57 //
聖仙たちはバラモンたちとともにキリーティンの側についた。
tato devagaṇaiḥ sārdhaṃ siddhāś ca saha cāraṇaiḥ|
dvidhā bhūtā mahārāja vyāśrayanta narottamau||
// 8-91-58 //
大王よ、こうして神々の群れとともにシッダたちやチャーラナたちも二つに分かれて、この二人の人中の最良者の側についた。
vimānāni vicitrāṇi guṇavanti ca sarvaśaḥ|
samāruhya samājagmurdvairathaṃ karṇapārthayoḥ|
antarikṣe mahārāja devagandharvarākṣasāḥ||
// 8-91-59 //
さまざまな美しい天の乗り物に乗り、大王よ、神々、ガンダルヴァ、ラークシャサたちが天空にやって来て、カルナとパールタの一騎討ちを見物した。
evaṃ sarveṣu bhūteṣu dvidhā bhūteṣu bhārata|
āśaṃsamāneṣu jayaṃ rādheyasyārjunasya ca|
vimānāyutasambādhamākāśamabhavattadā||
// 8-91-60 //
バーラタよ、こうしてすべての生きものが二つに分かれ、ラーデーヤ（カルナ）かアルジュナかの勝利を願う中、天空は何万もの天の乗り物でひしめき合った。
īhāmṛgavyālamṛgairdipāśvarathapaṅktibhiḥ|
ūhyamānāḥ pare meghairvāyunā ca manīṣiṇaḥ|
didṛkṣavaḥ samājagmuḥ karṇārjunasamāgamam||
// 8-91-61 //
鹿や猛獣たち、象・馬・戦車の列、雲や風に乗って運ばれた賢者たちが、カルナとアルジュナの激突を見ようと集まってきた。
devadānavagandharvā nāgayakṣapatatriṇaḥ|
maharṣayo devagaṇāḥ pitaraś ca svadhābhujaḥ||
tapovidyauṣadhīsidadhā nānārūpāmbaratviṣaḥ|
antarikṣe mahārāja vivadanto'vatasthire||
// 8-91-62-63 //
神々、ダーナヴァ、ガンダルヴァ、ナーガ、ヤクシャ、鳥たち、大聖仙たち、神々の群れ、供物を食べる祖霊たち、苦行・知識・薬草の成就者たち、さまざまな姿と衣をまとう者たちが、大王よ、天空で議論しながらとどまった。
brahmā brahmarṣibhiḥ sārdhaṃ prajāpatibhireva ca|
āsthito yānamākāśe divyaṃ tejaḥ samāgatāḥ||
// 8-91-64 //
ブラフマー神がブラフマリシたちやプラジャーパティたちとともに、天の乗り物に乗って天空に来られ、神々しい光輝が集まった。
tataḥ prajāpatistūrṇamājagāma mahāmate|
dvairathaṃ yudhi taṃ druṣṭaṃ karṇapāṇḍavayostadā||
// 8-91-65 //
そしてプラジャーパティが急いで来られたのは、カルナとパーンダヴァの一騎討ちを見るためであった。
vijitya karṇaḥ svidimāṃ vasundharām athārjunaḥ svitpratipadyate'khilām|
itīśvarasyāpi babhūva saṃśayaḥ prajāpateḥ prekṣya tayormahadbalam||
// 8-91-66 //
「カルナがこの大地を征服するのか、それともアルジュナが全大地を得るのか」――この二人の偉大なる力を見て、世界の主プラジャーパティにさえ疑念が生じた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekanavatitamo'dhyāyaḥ|| 91 ||
こうして、聖なる大マハーバーラタのカルナ篇の第91章は終わる。
