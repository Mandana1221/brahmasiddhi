चतुर्दशः सर्गः

第十四章　ラージャスーヤ祭の準備（rājasūya-yajña-varṇana）
韻律：rathoddhata（ラトーッダター）　11音節/pāda　rā-n-narā-viha lagau
V.1
Sanskrit (IAST) taṃ jagāda giramudgiranniva snehamāhitavikāsayā dṛśā / yajñakarmaṇi manaḥ samādadhadvāgvidāṃ varamakadvado nṛpaḥ //
和訳

祭祀の実行に心を定め、開いた眼差しから慕情を溢れ出させるかのように、弁に秀でた人々のうちの最上にして悪しき言葉なき王（ユディシュティラ）が、彼（クリシュナ）に語りかけた。

注

【Vallabhadeva】

「言辞に通じた者たちの最上」であるユディシュティラが、祭祀を心に決しつつ、愛情を湛えたまなざしでクリシュナに語りかける。この章全体の韻律は rathoddhata。

【Mallinātha】

akadvadaḥ を「卑しき言葉を持たぬ者」と解く。kadvadaḥ＝garhyavāk（悪言者）の否定。āhitavikāsayā dṛśā sneham udgiran iva（開花した眼差しから愛情を注ぎ出すかのように）は utprekṣā（想像修辞）。この章の韻律は rathoddhata（rān narā viha rathoddhatā lagau）。

※GRETIL校訂：akamadvado→akadvado（余分な am。12→11音節。Mallinātha の語釈「kutitasya vadaḥ kadvadaḥ」により確認）。

V.2
Sanskrit (IAST) lajjate na gaditaḥ priyaṃ paro vaktureva bhavati trapādhikā / vrīḍam eti na tava priyaṃ vadan hrīmatātrabhavataiva bhūyate //
和訳

他の人は好ましい言葉を言われても恥じないが、言う側にこそ恥じらいが大きくなる。しかしあなたの美質を称える者は恥じることがない——ここではむしろ称えられる側の高貴なあなたこそが恥じ入られるのです。

注

【Vallabhadeva】

他者は称賛されても恥じず、称える側こそ虚言を恐れて恥じる。だがクリシュナの場合、称賛者は恥じない（言葉が真実だから）。むしろ称えられるクリシュナ自身が謙虚のゆえに恥じ入る。

【Mallinātha】

前半は一般論：称賛を受ける他者は恥じないが、お世辞を言う側に恥が多い。後半は対比：あなたを称える者は恥じない（無限の美質ゆえに虚言にならない）。むしろ尊いatrabhavat（＝pūjya、尊者）であるあなた自身が恥じ入る。vyatireka（対照修辞）。

V.3
Sanskrit (IAST) toṣam eti vitathaiḥ stavaiḥ paras te ca tasya sulabhāḥ śarīribhiḥ / asti na stutivaco 'nṛtaṃ tava stotrayogya na ca tena tuṣyasi //
和訳

他の者は虚偽の讃辞で喜び、そのような讃辞は生き物たちから容易に得られる。しかし讃美に値するお方よ、あなたへの讃辞に偽りはなく、しかもあなたはそれによって喜ばれることがない。

注

【Vallabhadeva】

他者は虚偽の讃辞で歓び、そのような空辞は容易に得られる——虚言に際限はないから。しかしクリシュナの讃辞に嘘はなく（美質の宝庫ゆえ）、しかも讃辞によって喜ぶこともない（沈着なる性質ゆえ）。

【Mallinātha】

前二句と後二句の対照により vyatireka（対照修辞）。stotrayogya は呼びかけ（「讃美に値する方よ」）。一般の者は根拠なき賞賛で満足するが、クリシュナは全徳の源泉であるゆえ讃辞が真であり、しかも深遠なるがゆえにそれで喜ぶこともない。

V.4
Sanskrit (IAST) bahv api priyam ayaṃ tava bruvan na vrajaty anṛtavāditāṃ janaḥ / sambhavanti yad adoṣadūṣite sārva sarvaguṇasampadastvayi //
和訳

万民の益を図るお方よ、この私があなたの好ましきことを多く語っても、嘘つきの汚名を受けることはありません。なぜなら、過失に汚されぬあなたのうちに、あらゆる美徳の宝がそなわっているからです。

注

【Vallabhadeva】

ayaṃ janaḥ（この人＝自分自身）が多くの称賛を述べても虚言者とはならない。なぜなら一切の過失なきクリシュナにすべての美質が実際に宿っているから——虚飾なき讃辞は虚偽ではない。

【Mallinātha】

後半の文意が前半の理由付けとなっており、kāvyaliṅga（詩的根拠）修辞。sārva は呼びかけ（sarva + ṇ 接尾辞＝万民の益を図る者）。

V.5
Sanskrit (IAST) sā vibhūtir anubhāvasampadāṃ bhūyasī tava yad āyatāyati / etad ūḍhagurubhāra bhārataṃ varṣam adya mama vartate vaśe //
和訳

重き荷を担い給うお方よ、このバーラタ国土が今、永きにわたって私の支配に服しているということ——それこそがあなたの威光の富がもたらした大いなる栄光なのです。

注

【Vallabhadeva】

ūḍhagurubhāra（三界を支える者）への呼びかけ。バーラタ国が自分の支配下にあるのは、すべてクリシュナの威光のおかげであると述べる。

【Mallinātha】

bhārataṃ varṣam＝バーラタの地。āyatāyati＝長期にわたって。自らの王権とクリシュナの威光との関係を必然以上に強調する修辞として atiśayokti（誇張法）。

V.6
Sanskrit (IAST) saptatantum adhigantum icchataḥ kurv anugraham anujñayā mama / mūlatām upagate prabho tvayi prāpi dharmamayavṛkṣatā mayā //
和訳

主よ、祭祀を執り行うことを望む私に、許可という恩恵をお与えください。あなたが根となってくださったからこそ、私は法の樹という性を得ることができたのです。

注

【Vallabhadeva】

saptatantu＝七本の糸を持つもの、すなわち祭祀。クリシュナが根（mūla）となり、ユディシュティラが法の大樹となった——マハーバーラタの有名な比喩「yudhiṣṭhiro dharmamayo mahādrumaḥ... mūlaṃ kṛṣṇo brahma ca brāhmaṇaś ca」を引く。

【Mallinātha】

saptatantu＝makha（祭祀）。ユディシュティラを法の樹、クリシュナをその根とする sāvayavarūpaka（部分隠喩法）。クリシュナの恩寵なくしては法の成立もないという含意。

V.7
Sanskrit (IAST) sambhṛtopakaraṇena nirmalāṃ kartum iṣṭim abhivāñchatā mayā / tvaṃ samīraṇa iva pratīkṣitaḥ karṣakeṇa valajān pupūṣatā //
和訳

祭具をすべて整え、清浄なる祭祀を行おうと望む私によって、あなたは待ち望まれました——ちょうど穀物の山を箕で払い清めようとする農夫が、風を待ち望むように。

注

【Vallabhadeva】

祭祀の道具を揃えた私がクリシュナを待つのは、農夫が穀物を風選するために風を待つのと同じ。valaja＝穀物の山。pupūṣatā＝清めたいと欲する者（√pū の san + śatṛ）。クリシュナなくしては祭祀が成就しない。

【Mallinātha】

iṣṭi＝祭祀（√yaj + ktin）。valajān＝穀物の山。pupūṣatā＝浄化せんと欲する者。風なくして穀物を箕で清められぬように、クリシュナなくして祭祀は果たせないの意。

V.8
Sanskrit (IAST) vītavighnam anaghena bhāvitā sannidhes tava makhena me 'dhunā / ko vihantum alam āsthitodaye vāsaraśriyam aśītadīdhitau //
和訳

今やあなたの御前にあって、私の祭祀は障碍なく、無垢なるものとなるでしょう。熱き光の太陽が昇った時、昼の輝きを妨げうる者がいるでしょうか。

注

【Vallabhadeva】

クリシュナの臨席によりラージャスーヤは無障碍に遂行されるだろう。太陽が昇れば昼の美を妨げる者はいない——同様にクリシュナの臨席があれば祭祀の障碍はない。bhāvitā は bhāve luṭ（未来受動）。

【Mallinātha】

前半が主題（クリシュナの臨席と祭祀の成功）、後半がたとえ（太陽と昼の輝き）。文の分離（vākyabheda）により dṛṣṭānta（証例）修辞。aśītadīdhiti＝熱き光をもつ太陽。

V.9
Sanskrit (IAST) svāpateyam adhigamya dharmataḥ paryapālayam avīvṛdhaṃ ca yat / tīrthagāmi karavai vidhānatas taj juṣasva juhavāni cānale //
和訳

法にかなった方法で得、守り育てた財を、定められた作法に従って布施の行き届く場へ捧げましょう。どうかそれをお受け入れください。そして火中に供物を注ぎましょう。

注

【Vallabhadeva】

svāpateyam＝主人に属する財（svapati + ḍañ）。法に従い取得し、守護し、増殖した財を、聖典の定めに従い適格者に施し、火中に供犠する。juṣasva＝受納したまえ。スムリティを引く：「法に従い得んと欲し、得たるものを守り、守りたるものを増やし、増やしたるものを器に注げ」。

【Mallinātha】

同じスムリティを引く（dharmeṇa labdhum īheta...）。tīrthagāmi karavai＝適格者たるクリシュナへ施す。juhavāni＝√hu の祈願法（loṭ）。火への供犠もクリシュナへの奉献と同義である含意。

V.10
Sanskrit (IAST) pūrvam aṅga juhudhi tvam eva vā snātavaty avabhṛthe tatas tvayi / somapāyini bhaviṣyate mayā vāñchitottamavitānayājinā //
和訳

あるいは、おお友よ、まずあなたご自身が先に祭祀を執り行ってください。ソーマを飲む方であるあなたがアヴァブリタ沐浴を終えられた後に、望みの最高の祭祀を執り行う者として、私が祭祀をいたしましょう。

注

【Vallabhadeva】

aṅga＝呼びかけの間投詞（「おお」「友よ」）。あるいはクリシュナ自身がまず祭祀を行い、その終了沐浴（avabhṛtha）の後で、ユディシュティラがラージャスーヤを行うと提案する。juhudhi＝√hu の命令法。

【Mallinātha】

avabhṛtha＝祭祀の最終沐浴（dīkṣānto 'vabhṛtho yajñe）。vāñchitottamavitānayājinā＝望みの最上の祭式（ラージャスーヤ）の祭主として。この二句でクリシュナの祭祀との関連を超度に強調する atiśayokti（誇張法）。

V.11
Sanskrit (IAST) kiṃ vidheyam anayā vidhīyatāṃ tvatprasādajitayārthasampadā / śādhi śāsaka jagattrayasya mām āśravo 'smi bhavataḥ sahānujaḥ //
和訳

あなたの恩恵によって勝ち得たこの財をもって、何をなすべきでしょう——どうかあなた自身が定めてください。三界の統治者よ、私を導いてください。弟たちともども、あなたの忠実な従者なのですから。

注

【Vallabhadeva】

三界の支配者への呼びかけ。ユディシュティラは自分の財がすべてクリシュナの恩寵によるものとし、その用途もクリシュナに委ねる。āśravaḥ＝従順なる者（Amarakośa: vidheyaḥ）。

【Mallinātha】

十句の演説の結び。クリシュナへの絶対的帰依を表明する。atiśayokti（誇張法）を基盤とする preyas（愛情修辞）——最も愛しき者の称揚であるから。

V.12
Sanskrit (IAST) taṃ vadantam iti viṣṭaraśravāḥ śrāvayann atha samastabhūbhṛtaḥ / vyājahāra daśanāṃśumaṇḍalavyājahāraśabalaṃ dadhadvapuḥ //
和訳

このように語る王に対し、広大な名声をもつ方（クリシュナ）は、居並ぶすべての諸王に聞かせつつ語った——歯の光輝の環を口実とした真珠の首飾りに彩られた御身をもって。

注

【Vallabhadeva】

viṣṭaraśravāḥ はヴィシュヌの異名。歯の光の輪（daśanāṃśumaṇḍala）を口実（vyāja）として身に帯びた頸飾り（hāra）に彩られた身体で語った——真珠の白い輝きが歯光と見分けられぬ。

【Mallinātha】

vyājahāra（語った）と vyāja-hāra（口実の首飾り）の yamaka（同音反復）。歯の光輪が首飾りの白い光の「見せかけ」となるという apahnutibheda（隠蔽修辞の一種）。

V.13
Sanskrit (IAST) sāditākhilanṛpaṃ mahanmahaḥ samprati svanayasaṃpadaiva te / kiṃ parasya sa guṇaḥ samaśnute pathyavṛttir api yady arogitām //
和訳

すべての王を服従させたあなたの偉大なる威光は、今やあなた自身の善政の力によるものです。適正な食事をする者が健康を得るならば、医者の功績が何であろうか。

注

【Vallabhadeva】

クリシュナはユディシュティラの謙遜を退け、王の威光は自身の善政による、クリシュナの力ではないと述べる。適正な食事（pathyavṛtti）をする者に医者は不要であるように。

【Mallinātha】

V.5「あなたの威光が……」への返答。自身の善政が諸王を服従させたのであり、他者（クリシュナ）の功績ではない。dṛṣṭānta（証例修辞）：適正食の者が健康を得るなら、医者の功は何か。

V.14
Sanskrit (IAST) tat surājñi bhavati sthite punaḥ kaḥ kratuṃ yajatu rājalakṣaṇam / uddhṛtau bhavati kasya vā bhuvaḥ śrīvarāham apahāya yogyatā //
和訳

善き王たるあなたが控えている以上、他の誰がラージャスーヤという王たるしるしの祭祀を行えるでしょうか。聖なる大猪（ヴァラーハ）を除いて、大地を救い上げる能力が誰にあるでしょうか。

注

【Vallabhadeva】

V.10「まずあなたが祭祀を」への返答。surājñi＝善き王。ラージャスーヤは王の資質ある者のための祭祀。大地を救い上げるのがヴァラーハ（ヴィシュヌの化身）のみであるように、ラージャスーヤを行うべきはユディシュティラのみ。

【Mallinātha】

rājalakṣaṇa＝王にふさわしき祭祀、すなわちラージャスーヤ。ヴァラーハの比喩により dṛṣṭānta（証例修辞）。聖典に「rājā rājasūyena yajeta」とある通り、王であるユディシュティラにこそ資格がある。

V.15
Sanskrit (IAST) śāsane 'pi guruṇi vyavasthitaṃ kṛtyavastuṣu niyuṅkṣva kāmataḥ / tvatprayojanadhanaṃ dhanañjayād anya eṣa iti māṃ ca māvagāḥ //
和訳

たとい重き命令であっても従う覚悟のある私を、なすべき事柄に思いのままに使ってください。そしてアルジュナとは違うなどと私を見なさないでいただきたい——あなたの用のためにこそ財をもつ者ですから。

注

【Vallabhadeva】

クリシュナはV.7への応答として、自分を望み通りに使役せよと述べる。tvatprayojanadhanam＝あなたの用を唯一の財とする者。アルジュナ（Dhanañjaya「財を勝ち取る者」）と自分は同じだと言う。

【Mallinātha】

tvatprayojanam eva dhanaṃ yasya（あなたの用こそ我が富）という bahuvrīhi。「Dhanañjaya（アルジュナ）とは別だ」と思うなかれ——「dhana」の語の反復による kāvyaliṅga（詩的根拠）修辞、atiśayokti（誇張法）を基盤とする。

※GRETIL校訂：tvatprayojanaghanaṃ→tvatprayojanadhanaṃ（gha→dha。両註釈家が bahuvrīhi「dhana＝財」と解釈。Dhanañjaya との語呂合わせも dhana でのみ成立）。

V.16
Sanskrit (IAST) yas taveha savane na bhūpatiḥ karma karmakaravat kariṣyati / tasya neṣyati vapuḥ kabandhatāṃ bandhur eva jagatāṃ sudarśanaḥ //
和訳

いかなる王であれ、ここであなたの祭祀において使用人のごとく務めを果たさぬ者があれば、世界の親しき友なるスダルシャナ（円盤武器）が、その者の体を首なしの胴にしてしまうでしょう。

注

【Vallabhadeva】

sudarśana＝クリシュナの円盤武器（Amarakośa: cakraṃ sudarśanaḥ）。kabandhatā＝首のない胴体の状態。すべての王がこの祭祀に奉仕すべきことを宣言する威嚇。

【Mallinātha】

V.8への応答としての障碍排除の約束。bandhur eva jagatām（世界の親族）は sudarśana の修飾——世界の護り手でありながら敵を斬る。スダルシャナに「親族」性を付与する rūpaka（隠喩法）。

V.17
Sanskrit (IAST) ity udīritagiraṃ nṛpas tvayi śreyasi sthitavati sthirā mama / sarvasampad iti śaurim uktavān udvahan mudam udasthita kratau //
和訳

「あなたが幸いの側に立ってくださる限り、我が一切の繁栄は揺るがぬ」とクリシュナに告げた王は、喜びを抱いて祭祀に立ち上がった。

注

【Vallabhadeva】

ユディシュティラがクリシュナに最後の言葉を述べ、歓喜とともにラージャスーヤ祭の実行に着手する。ここからが祭祀の叙述の始まり。

【Mallinātha】

ここで対話が終わり、祭祀の描写に移る。udasthita＝√sthā の luṅ（ud + asthita＝立ち上がった）。続く二十五詩節で祭祀を一気に描く。

V.18
Sanskrit (IAST) ānanena śaśinaḥ kalāṃ dadhad darśanakṣayitakāmavigrahaḥ / āplutaḥ sa vimalair jalair abhūd aṣṭamūrtidharamūrtir aṣṭamī //
和訳

顔に月の光を宿し、見るだけで愛欲の姿を滅する王は、清らかな水で沐浴し、八体を持つ神（シヴァ）の第八の姿（＝祭主）となった。

注

【Vallabhadeva】

シヴァの八つの姿（地・水・風・火・月・太陽・虚空・祭主）のうちの第八が祭主（yajamāna）。ユディシュティラが沐浴して祭主となったことを、シヴァの第八の姿に喩える。顔の月光は断食による清浄な光輝、見るだけで欲望を滅するのは施しにより請願者を満たすこと。

【Mallinātha】

śleṣa（双関修辞）：ユディシュティラは月のごとき顔をもち、シヴァは額に月を戴く。「見るだけで欲望を滅する」はユディシュティラの離欲を指し、同時にシヴァがカーマを焼き尽くしたことを指す。āplutaḥ は沐浴と同時にガンジス水に濡れるシヴァの暗示。

V.19
Sanskrit (IAST) tasya sāṃkhyapuruṣeṇa tulyatāṃ bibhrataḥ svayam akurvataḥ kriyāḥ / kartṛtā tadupalambhato 'bhavad vṛttibhāji karaṇe yathartiviji //
和訳

サーンキヤ学派の言うプルシャのように自ら行為をなさぬ彼の、作者性は、活動する祭官（＝道具）を知覚することから生じた——ちょうどプルシャの作者性が、活動する認識器官を見守ることから生じるように。

注

【Vallabhadeva】

注

【Vallabhadeva】

snātaka＝ヴェーダ学習を修了した在家者。saṃyuj＝親族・婿。六者すべてがユディシュティラの集会に同時に来ている。引用：「ācāryam ṛtvijaṃ caiva saṃyujaṃ ca yudhiṣṭhira / snātakaṃ ca priyaṃ catha ṣaḍ arghārhān nṛpaṃ tathā」。

六者が各々 arghabhāj（水供養に値する者）であるのは同一の guṇa（資格）に基づく——tulyayogitābheda（等価並置法の一種）。medinīpati＝王（同じく六者の一つ）。

V.56
Sanskrit (IAST) śobhayanti paritaḥ pratāpino mantraśaktivinivāritāpadaḥ / tvanmakhaṃ mukhabhuvaḥ svayambhuvo bhūbhujaś ca paralokajiṣṇavaḥ //
和訳

【Vallabhadeva】

【Mallinātha】

婆羅門と王の双方に共通する特質（pratāpa 等）の sādharmya（類似性）に基づく tulyayogitābheda（等価並置）。その類似性が śleṣa（掛詞）に基づくことから saṃkara（修辞の混交）。

V.57
Sanskrit (IAST) ābhajanti guṇinaḥ pṛthak pṛthak pārtha satkṛtim akṛtrimām amī / eka eva guṇavattamo 'thavā pūjya ity ayam apīṣyate vidhiḥ //
和訳

注

【Vallabhadeva】

六者それぞれが名誉に値するが、もう一つの見解として、最も優れた一人のみに argha を捧げるべきとも言われる。パーラーシャリヤ（Vyāsa）の言葉を引用。

六者の pūjyatva（崇拝されるべきこと）の理由が guṇa（徳）であることから kāvyaliṅgabheda（詩的理由の一変種）。guṇavattamatva（最高の徳）が一者のみの崇拝の理由であることからも同様——sajātīyasaṃkara（同種修辞の交叉）。

V.58

和訳

注

【Vallabhadeva】

bhūmideva＝地上の神＝婆羅門。naradeva＝人間の神＝王。aśeṣaguṇabandhu＝すべての美徳の友＝あらゆる徳に豊かな者。pūrvadeva＝古き神＝阿修羅（asura）。bhāti māṃ prati＝「私にはそう思われる」。

他の者にも崇拝の可能性がある中でハリのみに限定する——parisaṃkhyā（限定修辞法）。定義：「ekasya vastunaḥ prāptāv anetraikadhayā yadā / ekatra niyamaḥ sā hi parisaṃkhyā nigadyate」。

V.59
Sanskrit (IAST) martyamātram avadīdharad bhavān mainam ānamitadaityadānavam / aṃśa eṣa janatātivartino vedhasaḥ pratijanaṃ kṛtasthiteḥ //
和訳

注

【Vallabhadeva】

vedhas＝prajāpati（造物主）、すなわちナーラーヤナ。janatātivartina＝一切衆生を超越した者。pratijanaṃ kṛtasthiteḥ＝各々の衆生に遍在する者（sarvabhūtāntaryāmin＝万物の内なる支配者）。avadīdharat＝「知る」の使役形 luṅ「そうみなす」。

ハリが至高者の化身であることが、「単なる人間ではない」という主張の vākyahetu（文意上の理由）——kāvyaliṅga。ānamita＝√nam の使役受動 kta「頭を下げさせた」。

V.60
Sanskrit (IAST) dhyeyam ekam apathe sthitaṃ dhiyaḥ stutyam uttamam atītavākpatham / āmananti yam upāsyam ādarād dūravartinam atīva yoginaḥ //
和訳

注

【Vallabhadeva】

āmananti＝√mnā のmena代置形「述べる・伝える」。dhyeya（瞑想対象）でありながら apathe sthita（知の外）、stutya（賛嘆対象）でありながら atītavākpatha（言語を超えた）——矛盾がハリの不可思議な偉大さで解消される virodhābhāsa（外見上の矛盾）。

V.61

注

【Vallabhadeva】

三神一体の教義——至高者はラジョグナにおいて梵天（padmabhū＝蓮華生）として世界を創造し、サットヴァにおいてアチュタ（不動者＝ヴィシュヌ）として存在を維持し、タモグナにおいてハラ（シヴァ）として破壊する。traidha＝tridhā（三様に）。

【Mallinātha】

クマーラサンバヴァの偈「rajoyukte janmani sattvavṛttaye sthitau…」を引き、創造・維持・破壊が三グナに対応することを確認。

V.62
Sanskrit (IAST) sarvavedinam anādim āsthitaṃ dehinām anujighṛkṣayā vapuḥ / kleśakarmaphalabhogavarjitaṃ puṃviśeṣam amum īśvaraṃ viduḥ //

注

【Vallabhadeva】

【Mallinātha】

ヨーガ学派がハリをpuruṣaviśeṣa（至上の精神的存在）と認定する。煩悩・業・果報の享受から離れている点が通常の個我と異なる。

V.63

注

【Vallabhadeva】

【Mallinātha】

bhaktavatsala＝帰依者を愛する神の称号。saṃsṛti-kleśa-nāṭaka-viḍambanā-vidhiは輪廻→苦→芝居→嘲弄→仕組みという重層的複合語。絶え間ない念想が罪を滅ぼす。

V.64

注

durgamは到達困難の意。apunarnivṛttaye＝再び輪廻に戻らぬために。ギーターの「mām upetya tu kaunteya punarjanma na vidyate」を想起させる。

V.65
Sanskrit (IAST) āditām ajananāya dehinām antatāṃ ca dadhate 'napāyine / bibhrate bhuvam adhaḥ sadātha ca brahmaṇo 'py upari tiṣṭhate namaḥ //

注

【Vallabhadeva】

四つの矛盾。始源でありながら不生、終末を与えながら不滅、地下で大地を支え（アナンタ蛇として）ながら梵天の上に位する。「anādyantāya jagato janmasaṃhārakāriṇe / sarvagāya namas tubhyam」を引く。

【Mallinātha】

不生でありながら始源、不滅でありながら終末の主——すべての矛盾が神の不可思議な本性で解消される。namaḥで結び、讃歌的な帰敬偈の形をとる。

V.66

和訳

注

V.69

V.70
