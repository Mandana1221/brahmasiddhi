kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

ṣoḍaśaḥ sargaḥ ― 第十六章

アルジュナの内省——キラータの正体への疑念（1–24）。天上の武器（アストラ）による戦い：催眠の武器、蛇の武器、ガルダの武器、火の武器、水の武器——すべてシヴァに封じられるアルジュナ（25–64）。
1
アルジュナの内省
Sanskrit
tataḥ kirātādhipater alaghvīm ājikriyāṃ vīkṣya vivṛddhamanyuḥ / sa tarkayāmāsa viviktatarkaś ciraṃ vicinvann iti kāraṇāni //
Upajāti
和訳
そこでキラータの王の軽からぬ戦技を目にして怒りの増した、明晰な思考を持つ彼（アルジュナ）は、その原因を長く探りつつ、こう思案した。
2
アルジュナの内省
Sanskrit
madasrutiśyāmitagaṇḍalekhāḥ krāmanti vikrāntanarādhirūḍhāḥ / sahiṣṇavo neha yudhām abhijñā nāgā nagocchrāyam ivākṣipantaḥ //
Upajāti
和訳
「頬に発情汁の黒い筋を滴らせ、勇猛な騎手を背に乗せ、山の高さを凌ぐほどの、戦に慣れた忍耐強き象がここにはいない。
3
アルジュナの内省
Sanskrit
vicitrayā citrayateva bhinnāṃ rucaṃ raveḥ ketanaratnabhāsā / mahārathaughena na saṃniruddhāḥ payodamandradhvaninā dharitrī //
Upendravajrā
和訳
旗の宝石の輝きが太陽の光をも色彩に染め上げるかのような、雲の如く轟く大戦車の群れが大地を覆うこともない。
4
アルジュナの内省
Sanskrit
samullasatprāsamahormimālaṃ parisphuraccāmaraphenapaṅkti / vibhinnamaryādam ihātanoti nāśvīyam āśā jaladher ivāmbhaḥ //
Upajāti
和訳
閃く槍の大波と、きらめくチャーマラ（白い牛尾の払子）の泡の列を伴い、境界を越えて溢れ出す——海の水のような馬の群れもここにはいない。
5
アルジュナの内省
Sanskrit
hatāhatety uddhatabhīṣmaghoṣaiḥ samujjhitā yoddhṛbhir abhyamitram / na hetayaḥ prāptataḍittviṣaḥ khe vivasvadaṃśujvalitāḥ patanti //
Upendravajrā
和訳
『打て、殺せ』という恐ろしい叫びとともに戦士たちが敵に向けて投げ放つ、太陽の光に燃え、稲妻の輝きを得た武器が空を飛ぶこともない。
6
アルジュナの内省
Sanskrit
abhyāyataḥ saṃtatadhūmadhūmraṃ vyāpi prabhājālam ivāntakasya / rajaḥ pratūrṇāśvarathāṅganunnaṃ tanoti na vyomani mātariśvā //
Upajāti
和訳
疾駆する馬と戦車の車輪に巻き上げられ、煙のように暗く広がり、近づく死神の光の網のような塵を、風が空に撒き散らすこともない。
7
アルジュナの内省
Sanskrit
bhūreṇunā rāsabhadhūsareṇa tirohite vartmani locanānām / nāsty atra tejasvibhir utsukānām ahni pradoṣaḥ surasundarīṇām //
Upajāti
和訳
灰色の砂塵で視界が遮られ、勇者たちを恋い慕う天女たちにとって昼間に宵闇が訪れるということもここにはない。
天女たちは戦死した勇者がインドラの天に昇るのを待って夜を望む、との詩的伝統を踏まえる。
8
アルジュナの内省
Sanskrit
rathāṅgasaṃkrīḍitam aśvaheṣā bṛhanti mattadvipabṛṃhitāni / saṃgharṣayogād iva mūrchitāni hrādaṃ nigṛhṇanti na dundubhīnām //
Upajāti
和訳
車輪の軋み、馬のいななき、発情した象の咆哮が、互いに競い合うかのように高まり、太鼓の響きをかき消すということもない。
9
アルジュナの内省
Sanskrit
asmin yaśaḥpauruṣalolupānām arātibhiḥ pratyurasaṃ kṣatānām / mūrchāntarāyaṃ muhur ucchinatti nāsāraśītaṃ kariśīkarāmbhaḥ //
Upajāti
和訳
名声と武勇に飢え、敵に胸を打たれた者たちの、繰り返す失神を、象の鼻から噴き出す雨のように冷たい水が断ち切るということもない。
10
アルジュナの内省
Sanskrit
asṛṅnadīnām upacīyamānair vidārayadbhiḥ padavīṃ dhvajinyāḥ / ucchrāyam āyānti na śoṇitaughaiḥ paṅkair ivāśyānaghanais taṭāni //
Upajāti
和訳
増水し、軍の進路を裂いて広がる血の奔流が、粘り強い泥のように岸を高めることもない。
11
アルジュナの内省
Sanskrit
parikṣate vakṣasi dantidantaiḥ priyāṅkaśītā nabhasaḥ patantī / neha pramohaṃ priyasāhasānāṃ mandāramālā viralīkaroti //
Upajāti
和訳
象の牙に胸を裂かれた無謀な勇者たちの昏倒を、天から降り注ぐ、恋人の腕のように冷たいマンダーラの花環が覚ますこともない。
12
アルジュナの内省
Sanskrit
niṣādisaṃnāhamaṇiprabhaughe parīyamāṇe kariśīkareṇa / arkatviṣonmīlitam abhyudeti na khaṇḍam ākhaṇḍalakārmukasya //
Upajāti
和訳
象使いの鎧の宝石の光の流れが象の鼻水に濡れるとき、太陽の光に照らされてインドラの虹の弧が現れるということもない。
13
アルジュナの内省
Sanskrit
mahībhṛtā pakṣavateva bhinnā vigāhya madhyaṃ paravāraṇena / nāvartamānā ninadanti bhīmam apāṃ nidher āpa iva dhvajinyaḥ //
Upajāti
和訳
翼ある山のような敵の象が中央に突入して軍を分断し、渦巻く海の水のように恐ろしく轟くこともない。
翼ある山（pakṣavat）はマイナーカ山の伝説を踏まえる。かつて山々には翼があったが、インドラに切り落とされた。
14
アルジュナの内省
Sanskrit
mahārathānāṃ pratidantyanīkam adhisyadasyandanam utthitānām / āmūlalūnair atimanyuneva mātaṅgahastair vriyate na panthāḥ //
Upajāti
和訳
象の軍に向かって急ぎ立ち上がる大戦車の道を、激怒のあまり根元から切り落とされたかのような象の鼻が塞ぐこともない。
15
アルジュナの内省
Sanskrit
dhṛtotpalāpīḍa iva priyāyāḥ śiroruhāṇāṃ śithilaḥ kalāpaḥ / na barhabhāraḥ patitasya śaṅkor niṣādivakṣaḥsthalam ātanoti //
Upendravajrā
和訳
倒れて突き刺さった投げ槍の孔雀羽の束が、蓮花の髪飾りをつけた恋人の解けた髪のように、象使いの胸に広がることもない。
16
アルジュナの内省
Sanskrit
ujjhatsu saṃhāra ivāstasaṃkhyam ahnāya tejasviṣu jīvitāni / lokatrayāsvādanalolajihvaṃ na vyādadāty ānanam atra mṛtyuḥ //
Indravajrā
和訳
数え切れぬ勇者たちが世界の終わりの如く瞬時に命を捨てる中、三界を飲み尽くそうと舌なめずりする死が大口を開けることもない。
17
アルジュナの内省
Sanskrit
iyaṃ ca durvāramahārathānām ākṣipya vīryaṃ mahatāṃ balānām / śaktir mamāvasyati hīnayuddhe saurīva tārādhipadhāmni dīptiḥ //
Upajāti
和訳
「にもかかわらず、防ぎがたい大戦車を擁する大軍の武勇をも退けてきた我が力が、この取るに足らぬ戦いで衰えてゆく。月に宿った太陽の光が（冷たく）弱まるように。」
18
アルジュナの内省
Sanskrit
māyā svid eṣā mativibhramo vā dhvastaṃ nu me vīryam utāham anyaḥ / gāṇḍīvamuktā hi yathā purā me parākramante na śarāḥ kirāte //
Upajāti
和訳
「これは幻術なのか、あるいは我が心の迷いか。我が武勇が損なわれたのか、それとも我は別人になったのか。ガーンディーヴァから放たれた我が矢が、かつてのようにはキラータに効かないのだから。」
19
アルジュナの内省
Sanskrit
puṃsaḥ padaṃ madhyamam uttamasya dvidheva kurvan dhanuṣaḥ praṇādaiḥ / nūnaṃ tathā naiṣa yathāsya veṣaḥ pracchannam apy ūhayate hi ceṣṭā //
Upajāti
和訳
「弓の響きで至上なる存在の中間の領域（大気）をも二つに裂くかのようなこの者は、その装いが示すものではない。隠されていても、行いがそれを推し量らせるのだ。」
padaṃ madhyamam uttamasya puṃsaḥはヴィシュヌの三歩（trivikrama）の中間——大気を指す。Cappellerは「至上の精神（ヴィシュヌ）の中間の場所、すなわち大気」と解する。
20
アルジュナの内省
Sanskrit
dhanuḥ prabandhadhvanitaṃ ruṣeva sakṛd vikṛṣṭā vitateva maurvī / saṃdhānam utkarṣam iva vyudasya muṣṭer asambheda ivāpavarge //
Upajāti
和訳
「弓は怒りに駆られたかのごとく絶え間なく鳴り、弦は一度引かれたまま張り続けているかのようだ。矢は番えるのに矢筒から引き抜く必要がないかのよう。放つ時、手は開かぬまま。」
21
アルジュナの内省
Sanskrit
aṃsāv avaṣṭabdhanatau samādhiḥ śirodharāyā rahitaprayāsaḥ / dhṛtā vikārāṃs tyajatā mukhena prasādalakṣmīḥ śaśalāñchanasya //
Upajāti
和訳
「両肩はがっしりと傾き、首の構えには力みがない。顔は変化を捨て、月のように穏やかな美を湛えている。」
22
アルジュナの内省
Sanskrit
prahīyate kāryavaśāgateṣu sthāneṣu viṣṭabdhatayā na dehaḥ / sthitaprayāteṣu sasauṣṭhavaś ca lakṣyeṣu pātaḥ sadṛśaḥ śarāṇām //
Upajāti
和訳
「状況に応じたさまざまな姿勢においても身体はまったく動じない。立っている的にも動いている的にも、矢は同じ優雅さで命中する。」
23
アルジュナの内省
Sanskrit
parasya bhūyān vivare 'bhiyogaḥ prasahya saṃrakṣaṇam ātmarandhre / bhīṣme 'py asambhāvyam idaṃ gurau vā na sambhavaty eva vanecareṣu //
Upajāti
和訳
「敵の隙を巧みに突き、自らの隙は断固として守る。ビーシュマにさえ、あるいは師（ドローナ）にさえ不可能なこれが、森の住人にできるはずがない。」
24
アルジュナの内省
Sanskrit
aprākṛtasyāhavadurmadasya nivāryam asyāstrabalena vīryam / alpīyaso 'py āmayatulyavṛtter mahāpakārāya ripor vivṛddhiḥ //
Upajāti
和訳
「この尋常ならざる、戦に酔う者の武勇は、天上の武器（アストラ）の力で制さねばならぬ。たとえ小さな敵でも、病のように成長すれば大いなる害をなすのだから。」
25
Sanskrit
sa sampradhāryaivam ahāryasāraḥ sāraṃ vineṣyan sagaṇasya śatroḥ / prasvāpanāstraṃ drutam ājahāra dhvāntaṃ ghanānaddha ivārdharātraḥ //
Upajāti
和訳
奪い難い力を持つ彼はこう思案した後、敵とその群衆の力を挫くべく、速やかに催眠の武器（プラスヴァーパナアストラ）を発動した。雲に覆われた真夜中が闇を呼び出すように。
26
Sanskrit
prasaktadāvānaladhūmadhūmrā nirundhatī dhāma sahasraraśmeḥ / mahāvanānīva mahātamisrā chāyā tatāneśabalāni kālī //
Upajāti
和訳
絶え間ない山火事の煙のように暗く、太陽の輝きを遮る黒い影が、深い闇が大森林を覆うように、シヴァの軍勢を包み込んだ。
27
Sanskrit
āsāditā tatprathamaṃ prasahya pragalbhatāyāḥ padavīṃ harantī / sabheva bhīmā vidadhe gaṇānāṃ nidrā nirāsaṃ pratibhāguṇasya //
Upajāti
和訳
ガナたちに初めて力ずくで襲いかかり、大胆さの居場所を奪い去った恐ろしい眠りは、臆した者にとっての恐るべき集会のように、彼らの機転の働きを消し去った。
王宮（sabhā）では静粛にしなければならないという慣習を、眠りの効果の比喩に用いる。
28
Sanskrit
gurusthirāṇy uttamavaṃśajatvād vijñātasārāṇy anuśīlanena / kecit samāśritya guṇān vitāni suhṛtkulānīva dhanūṃṣi tasthuḥ //
Upajāti
和訳
ある者たちは、優れた竹林（良家）に生まれたゆえに重く堅固で（威厳があり堅固で）、使い込みによって（経験によって）その真価を知られた弦の備わった（美徳を持つ）弓に（忠実な友のように）身を寄せて立っていた。
弓と友人の二義をかけたシュレーシャ。uttamavaṃśajatvaは「優れた竹から生まれた」（弓）と「良い家系に生まれた」（友人）の両義。
29
Sanskrit
kṛtāntadurvṛtta ivāpareṣāṃ puraḥ pratidvandvini pāṇḍavāstre / atarkitaṃ pāṇitalān nipetuḥ kriyāphalānīva tadāyudhāni //
Upendravajrā
和訳
ある者たちからは、パーンドゥの子の武器という敵が目前に立ち、運命の邪悪な振る舞いのように、武器が不意に手のひらから足元に落ちた。あたかも行いの果報のように。
30
Sanskrit
aṃsasthalaiḥ kecid abhinnadhairyāḥ skandheṣu saṃśleṣavatāṃ tarūṇām / madena mīlannayanāḥ salīlaṃ nāgā iva srastakarā niṣeduḥ //
Upajāti
和訳
不屈の勇気を持つある者たちは、肩を抱く木々の幹にもたれ、発情で目を細めた象のように、垂れ下がった手で悠然と座り込んだ。
31
Sanskrit
tirohitendor atha śambhumūrdhnaḥ praṇamyamānaṃ tapasāṃ nivāsaiḥ / sumeruśṛṅgād iva bimbam ārkaṃ piśaṅgam uccair udiyāya tejaḥ //
Upendravajrā
和訳
そのとき、月が隠されたシャンブの頭頂から、苦行者たちに崇められる赤褐色の光輝が高く昇った。スメール山の頂から太陽の円盤が昇るように。
キラータに変装したシヴァは月冠を隠していたが、ここでその神威が顕れ始める。
32
Sanskrit
chāyāṃ vinirdhūya tamomayīṃ tāṃ tattvasya saṃvittir ivāpavidyām / yayau vikāsaṃ dyutir indumauler ālokam abhyādiśatī gaṇebhyaḥ //
Upajāti
和訳
真理の認識が無明を払拭するように、月冠の神の光輝がかの闇の影を吹き払い、花開いて、ガナたちに視界を与えた。
33
Sanskrit
tviṣāṃ tatiḥ pāṭalitāmbuvāhā sā sarvataḥ pūrvasarīva saṃdhyā / nināya teṣāṃ drutam ullasantī vinidratāṃ locanapaṅkajāni //
Upajāti
和訳
雲を赤く染めるその光の広がりは、四方に、まるで曙の光のように、彼らの蓮華のような眼を速やかに覚醒させた。
34
Sanskrit
pṛthagvidhāny astravirāmabuddhāḥ śastrāṇi bhūyaḥ pratipedire te / muktā vitānena balāhakānāṃ jyotīṃṣi ramyā iva digvibhāgāḥ //
Upajāti
和訳
アストラが止んだと悟り、彼らはさまざまな武器を再び手に取った。雲の幕から解き放たれた美しい空が星々を取り戻すように。
35
Sanskrit
dyaur unnanāmeva diśaḥ praseduḥ sphuṭaṃ visasre savitur mayūkhaiḥ / kṣayaṃ gatāyām iva yāmavatyāṃ punaḥ samīyāya dinaṃ dinaśrīḥ //
Upajāti
和訳
天はいわば高みに上り、方角は澄み渡り、太陽の光がはっきりと広がった。夜が去ったかのように、昼の美が再び昼と出会った。
36
Sanskrit
mahāstradurge śithilaprayatnaṃ digvāraṇeneva pareṇa rugṇe / bhujaṅgapāśān bhujavīryaśālī prabandhanāya prajighāya jiṣṇuḥ //
Upajāti
和訳
アストラの砦が方角の守護象のような敵によって容易く砕かれると、腕の力に優れたジシュヌ（アルジュナ）は、敵を縛るために蛇の縄（ブジャンガパーシャ）を放った。
37
Sanskrit
jihvāśatāny ullasayanty ajasraṃ lasattaḍillolaviṣānalāni / trāsān nirastāṃ bhujagendrasenā nabhaścarais tatpadavīṃ vivavre //
Upajāti
和訳
幾百もの舌を絶え間なく揺らし、閃く稲妻のように毒の炎を揺らめかせる蛇王の軍勢が、恐怖で逃げた天空の者たちが空けた空を覆い尽くした。
38
Sanskrit
diṅnāgahastākṛtim udvahadbhir bhogaiḥ praśastāsitaratnanīlaiḥ / rarāja sarpāvalir ullasantī taraṅgamāleva nabhorṇavasya //
Upajāti
和訳
方角の守護象の鼻のような形を持ち、讃えられるべきサファイアのように青い胴体を持つ蛇の列は、天空の海の波の環のように輝いた。
39
Sanskrit
niḥśvāsadhūmaiḥ sthagitāṃśujālaṃ phaṇāvatām utphaṇamaṇḍalānām / gacchann ivāstaṃ vapur abhyuvāha vilocanānāṃ sukham uṣṇaraśmiḥ //
Upajāti
和訳
鎌首をもたげた蛇たちの吐息の煙で光の網が覆われ、太陽はあたかも沈むかのように姿を見せ、眼にとって心地よいものとなった。
40
Sanskrit
prataptacāmīkarabhāsureṇa diśaḥ prakāśena piśaṅgayantyaḥ / niścakramuḥ prāṇaharekṣaṇānāṃ jvālā maholkā iva locanebhyaḥ //
Upajāti
和訳
溶けた黄金のように燦然と輝く光で四方を赤褐色に染めながら、命を奪う眼を持つ蛇たちの両眼から、大きな松明のような炎が噴き出した。
41
Sanskrit
ākṣiptasampātam apetaśobham udvahni dhūmākuladigvibhāgam / vṛtaṃ nabho bhogikulair avasthāṃ paroparuddhasya purasya bheje //
Upajāti
和訳
通行を遮られ、美を失い、火と煙で四方が騒然とし、蛇の一族に覆われた空は、敵に包囲された城市のような状態になった。
42
Sanskrit
tam āśu cakṣuḥśravasāṃ samūhaṃ mantreṇa tārkṣyodayakāraṇena / netā nayeneva paropajāpaṃ nivārayāmāsa patiḥ paśūnām //
Upajāti
和訳
獣たちの主（シヴァ）は、ガルダを出現させる真言によって、その蛇の大群をただちに退けた。将軍が策をもって敵の離間工作を防ぐように。
cakṣuḥśravas（耳で見る者）は蛇の別称。tārkṣyaはガルダ（蛇を食す神鳥）。
43
Sanskrit
pratighnatībhiḥ kṛtamīlitāni dyulokabhājām api locanāni / garutmatā saṃhatibhir vihāyaḥ kṣaṇaprakāśābhir ivāvatene //
Upendravajrā
和訳
稲妻のように一瞬の閃光を放ち、天界の住人たちの目さえも眩ませるガルダの群れが空を満たした。
44
Sanskrit
tataḥ suparṇavrajapakṣajanmā nānāgatir maṇḍalayañ javena / jarattṛṇānīva viyan nināya vanaspatīnāṃ gahanāni vāyuḥ //
Upajāti
和訳
スパルナ（ガルダ）の群れの翼から生まれた風が、あらゆる方向に旋回しながら、枯れ草のように樹木の茂みを空中に巻き上げた。
45
Sanskrit
manaḥśilābhaṅganibhena paścān nirudhyamānaṃ nikareṇa bhāsām / vyūḍhair urobhiś ca vinudyamānaṃ nabhaḥ sasarpeva puraḥ khagānām //
Upajāti
和訳
背後では砕いた雄黄に似た光の群れに押され、前方では鳥たちの広い胸に押し出され、空そのものが前方に這い進むかのようだった。
46
Sanskrit
darīmukhair āsavarāgatāmraṃ vikāsi rukmacchadadhāma pītvā / javānilāghūrṇitasānujālo himācalaḥ kṣība ivācakampe //
Upendravajrā
和訳
洞窟の口から、酒のように赤味を帯びた、輝く金色の翼の光を飲み込んだヒマラヤ山は、疾風にゆらぐ蔓のように、酔いどれのごとくぐらぐらと揺れた。
47
Sanskrit
pravṛttanaktaṃdivasaṃdhidīptair nabhastalaṃ gāṃ ca piśaṅgayadbhiḥ / antarhitārkaiḥ paritaḥ patadbhiś chāyāḥ samācikṣipire vanānām //
Upajāti
和訳
昼と夜の境のように輝き、太陽を覆い隠しながら四方に飛び交う鳥たちが、空と大地を赤褐色に染め、森の影を払い散らした。
48
Sanskrit
sa bhogasaṃghaḥ śamam ugradhāmnāṃ sainyena ninye vinatāsutānām / mahādhvare vidhyapacāradoṣaḥ karmāntareṇeva mahodayena //
Upajāti
和訳
あの蛇の群れは、猛き力を持つヴィナターの子ら（ガルダ）の軍勢によって滅ぼされた。大祭において儀軌の過失が、より偉大な別の行為によって相殺されるように。
49
Sanskrit
sāphalyam astre ripupauruṣasya kṛtvā gate bhāgya ivāpavargam / anindhanasya prasabhaṃ samanyuḥ samādade 'straṃ jvalanasya jiṣṇuḥ //
Upajāti
和訳
アストラが善行のように実を結んで敵の武勇に成功を与え、消え去った後、怒れるジシュヌ（アルジュナ）は力ずくで、自ら燃え上がる火のアストラ（アーグネーヤアストラ）を手にした。
50
Sanskrit
ūrdhvaṃ tiraścīnam adhaś ca kīrṇair jvālāsaṭair laṅghitameghapaṅktiḥ / āyastasiṃhākṛtir utpapāta prāṇyantam icchann iva jātavedāḥ //
Indravajrā
和訳
上へ、横へ、下へと撒き散らされた炎の鬣で雲の列を飛び越え、跳びかかろうとする獅子の姿をした火が飛び立った。あらゆる命あるものに終わりをもたらそうとするかのように。
51
Sanskrit
bhittveva bhābhiḥ savitur mayūkhāñ jajvāla viṣvag visṛtasphuliṅgaḥ / vidīryamāṇāśmaninādadhīraṃ dhvaniṃ vitanvann akṛśaḥ kṛśānuḥ //
Upajāti
和訳
太陽の光線をもその輝きで打ち砕くかのように、四方に火花を散らしながら猛火は燃え盛り、砕ける岩のように低く力強い音を響かせた。
52
Sanskrit
cayān ivādrīn iva tuṅgaśṛṅgān kvacit purāṇīva hiraṇmayāni / mahāvanānīva ca kiṃśukānāṃ tatāna vahniḥ pavanānuvṛttyā //
Upendravajrā
和訳
風に従って燃え広がる火は、あるところでは積み上げた山のように、あるところでは高い峰の山々のように、あるところでは黄金の都城のように、またキンシュカの大森林のように広がった。
kiṃśuka（ブテア・フロンドーサ）は赤い花を咲かせる木。火炎の赤さとの比較。
53
Sanskrit
muhuś calatpallavalohinībhir uccaiḥ śikhābhiḥ śikhino 'valīḍhāḥ / taleṣu muktāviśadā babhūvuḥ sāndrāñjanaśyāmarucaḥ payodāḥ //
Upajāti
和訳
若芽のように赤く揺らめく高い炎に舐められた雲は、濃い煤煙のように黒く光っていたのに、その底部では真珠のように白く透き通った。
54
Sanskrit
lilikṣatīva kṣayakālaraudre lokaṃ vilolārciṣi rohitāśve / pinākinā hūtamahāmbuvāham astraṃ punaḥ pāśabhṛtaḥ praṇinye //
Upajāti
和訳
終末の時のように恐ろしい、揺らめく炎の赤い馬に乗った火が世界を舐め尽くそうとする中、ピナーキン（シヴァ）は大いなる雨雲を呼ぶ、縄の持ち主（ヴァルナ）のアストラを発動した。
pāśabhṛt（縄を持つ者）はヴァルナ神。海と水の支配者であり、罪人を縄で縛る神としても知られる。
55
Sanskrit
tato dharitrīdharatulyarodhasas taḍillatāliṅgitanīlamūrtayaḥ / adhomukhākāśasarinnipātinīr apaḥ prasaktaṃ mumucuḥ payomucaḥ //
Vaṃśastha
和訳
すると、山のような堤を持ち、稲妻の蔓に抱かれた青黒い姿の雨雲が、天の川のように下向きに流れ落ちる水を絶え間なく注ぎ出した。
56
Sanskrit
parāhatadhvastaśikhe śikhāvato vapuṣy adhikṣiptasamiddhatejasi / kṛtāspadās tapta ivāyasi dhvaniṃ payonipātāḥ prathame vitenire //
Vaṃśastha
和訳
敵に打たれて炎が崩れ、燃え上がっては消える火の体に落ちた最初の水の滴は、焼けた鉄に触れたかのようにシュウシュウと音を立てた。
57
Sanskrit
mahānale bhinnasitābhrapātibhiḥ sametya sadyaḥ kvathanena phenatām / vrajadbhir ārdrendhanavat parikṣayaṃ jalair vitene divi dhūmasaṃtatiḥ //
Vaṃśastha
和訳
裂けた白い雲から降り注ぎ、大火にぶつかって即座に泡立ち、湿った薪のように消滅していく水によって、空に煙の連なりが広がった。
58
Sanskrit
svaketubhiḥ pāṇḍuranīlapāṭalaiḥ samāgatāḥ śakradhanuḥprabhābhidaḥ / asaṃsthitām ādadhire vibhāvasor vicitracīnāṃśukacārutāṃ tviṣaḥ //
Vaṃśastha
和訳
白、青、赤の自らの幡と交じり合い、虹の光を映した火の輝きは、色とりどりの絹のように定まらぬ美しさを帯びた。
59
Sanskrit
jalaughasaṃmūrchanamūrchitasvanaḥ prasaktavidyullasitaidhitadyutiḥ / praśāntim eṣyan dhṛtadhūmamaṇḍalo babhūva bhūyān iva tatra pāvakaḥ //
Vaṃśastha
和訳
水の奔流との衝突で轟音が高まり、絶え間ない稲妻の閃きで輝きを増した火は、消えようとしているのに、煙の輪を纏ってかえって大きくなったかのようだった。
60
Sanskrit
pravṛddhasindhūrmicayasthavīyasāṃ cayair vibhinnāḥ payasāṃ prapedire / upāttasaṃdhyārucibhiḥ sarūpatāṃ payodavicchedalavaiḥ kṛśānavaḥ //
Vaṃśastha
和訳
増水した河の波よりも大きな水の塊に砕かれた火の残りは、夕焼けの色を帯びた千切れ雲と同じ姿になった。
61
Sanskrit
upaity anantadyutir apy asaṃśayaṃ vibhinnamūlo 'nudayāya saṃkṣayam / tathā hi toyaughavibhinnasaṃhatiḥ sa havyavāhaḥ prayayau parābhavam //
Vaṃśastha
和訳
たとえ無限の輝きを持つ者でも、根を断たれれば確実に滅び、再び興ることはない。かくして水の奔流に集積を砕かれた供物を運ぶ者（火）は敗北に至った。
62
Sanskrit
atha vihitavidheyair āśu muktā vitānair asitanaganitambaśyāmabhāsāṃ ghanānām / vikasadamaladhāmnāṃ prāpa nīlotpalānāṃ śriyam adhikaviśuddhāṃ vahnidāhād iva dyauḥ //
Mālinī
和訳
そこで、役目を終えて速やかに去った、黒い山の麓のように暗く光る雲の天蓋から解き放たれた空は、火の浄化を経たかのように、咲き開く清らかな青蓮のような至純の美を取り戻した。
63
Sanskrit
iti vividham udāse savyasācī yad astraṃ bahusamaranayajñaḥ sādayiṣyann arātim / vidhir iva viparītaḥ pauruṣaṃ nyāyavṛtteḥ sapadi tad upaninye riktatāṃ nīlakaṇṭhaḥ //
Mālinī
和訳
かくして、多くの戦の技に精通したサヴヤサーチン（アルジュナ）が敵を倒そうと用いるあらゆる種類のアストラを、ニーラカンタ（シヴァ）は即座に無効化した。正道を歩む者の努力を挫く逆境の運命のように。
64
Sanskrit
vītaprabhāvatanur apy atanuprabhāvaḥ pratyācakāṅkṣa jayinīṃ bhujavīryalakṣmīm / astreṣu bhūtapatināpahṛteṣu jiṣṇur varṣiṣyatā dinakṛteva jaleṣu lokaḥ //
Vasantatilakā
和訳
光を失った身体でありながら衰えぬ威力を持つジシュヌ（アルジュナ）は、すべてのアストラが万物の主に奪われた後、勝利をもたらす腕の力の栄光を待ち望んだ。やがて雨を降らすであろう太陽に水を奪われた世界のように。
太陽が水を蒸発させるのは、やがて雨として返すため。同様にシヴァがアルジュナの武器を奪うのは、やがて恩寵を与えるためという含意。Cappellerの注に「アルジュナは大干ばつの時に腕力（井戸掘り等）でしか命を繋げない人間に喩えられる」とある。
iti bhāravikṛtau mahākāvye kirātārjunīye ṣoḍaśaḥ sargaḥ //
