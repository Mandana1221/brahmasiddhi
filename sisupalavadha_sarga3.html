तृतीयः सर्गः

第三章　出発の描写（yātrāvarṇana）

韻律：upajāti（indravajrā・upendravajrā混合、各pāda 11音節）

Uddhavaの助言を容れたKṛṣṇaが、装いを整えてDvārakāからIndraprasthaへ出発する。

III.1
Sanskrit (IAST) kauberadigbhāgam apāsya mārgam āgastyam uṣṇāṃśur ivāvatīrṇaḥ / apetayuddhābhiniveśasaumyo harir hariprastham atha pratasthe //
和訳

クベーラの方角（北）を捨てて、アガスティヤの道（南）へ降りゆく太陽のように——戦いへの執着が去り、穏やかとなったハリ（Kṛṣṇa）は、かくしてハリプラスタ（Indraprastha）へ向けて出立した。

注

【Vallabhadeva】

uṣṇāṃśuḥ（太陽）がkaubera（北＝uttarāyaṇa）を離れāgastya（南＝dakṣiṇāyana）に入る如く、Kṛṣṇaの怒りはkāryavaśāt（任務のため）一時的に抑えられたのであって、本質的に消えたのではないと示唆する。hariprastha＝Indraprastha（hari＝Indra）。

【Mallinātha】

Uddhavaの言葉を聞いた後。upamālaṅkāra。太陽の比喩：北行（uttarāyaṇa）から南行（dakṣiṇāyana）に転じると太陽はsaumya（穏やか）になる。hariprastha＝indraprastha（「indro duścyavano hariḥ」Halāyudha辞典）。pratasthe——sam-ava-pra-vibhyaḥ sthāによりātmanepada。この章の韻律はupajāti——indravajrāとupendravajrāの混合。

III.2
Sanskrit (IAST) jagatpavitrair api taṃ na pādaiḥ spraṣṭuṃ jagatpūjyam ayujyatārkaḥ / yato bṛhatpārvaṇacāru tasya ātapatraṃ vibharāṃ babhūve //
和訳

世界を浄める光線（pāda＝足／光線）をもってしても、世界に崇められるかの方（Kṛṣṇa）に太陽は触れるに値しなかった。ゆえに——満月の如く大きく美しい傘蓋（ātapatra）が、彼のために掲げられたのである。

注

【Vallabhadeva】

傘蓋の描写が始まる。pādaは「足」と「光線」の両義。太陽はその光線で世界を清めるが、jagatpūjyaたるViṣṇuには触れることすら相応しくない。ゆえに傘蓋が差されている——太陽光を遮るためではなく、Kṛṣṇaの威厳ゆえに。bṛhat-pārvaṇa-cāru＝大きく、満月の日に関わる美しさ（白い傘蓋を満月に喩える）。

【Mallinātha】

pādaのśleṣa（両義）——足と光線。jagatpūjyaたる者をいかに清浄な足であれ触れることは不適。pārvaṇa＝parvan（満月の日）に関わる。upamālaṅkāra（傘蓋を満月に喩える）。vibharāṃ babhūve＝bhṛの受動完了形（periphrastic perfect, passive）。

III.3
Sanskrit (IAST) mṛṇālasūtrāmalam antareṇa sthitaś calaccāmarayor dvayaṃ saḥ / bheje 'bhitaḥpātukasiddhasindhor abhūtapūrvāṃ rucam amburāśeḥ //
和訳

蓮の茎の繊維のように白く清らかな、揺れ動く二本の払子（cāmara）の間に立つ彼は——両側から流れ落ちる天の河（siddhasindhu）を擁する大海のような、かつてなき美しさ（ruci）を帯びた。

注

【Vallabhadeva】

abhitaḥpātukā siddhasindhuḥ＝両側から流れ落ちる天の河（ākāśagaṅgā）。白い払子二本の間に立つ黒い肌のKṛṣṇaの姿を、天の河の二つの流れに挟まれた大海に喩える。abhūtapūrvā＝過去に存在したことのない——現実には天の河が二方向に流れることはないから。Vallabhaはrucamの代わりにśriyamと読む。

【Mallinātha】

mṛṇālasūtrāmala＝蓮の茎の繊維のように白い（upamā）。calat＝扇いで揺れる。abhitaḥpātukā＝ubhayataḥpātinī（両側に流れ落ちる）。siddhasindhu＝ākāśagaṅgā（天の河）。nidarśanā修辞——実在しない状況を想定して比喩とする。

III.4
Sanskrit (IAST) citrābhir asyopari maulibhājāṃ bhābhir maṇīnām aṇīyasībhiḥ / anekadhātucchuritāśmarāśer govardhanas​yākṛtir anvakāri //
和訳

彼の頭上で、冠に嵌められた宝石たちの——多彩にして決して小さからぬ輝きにより——さまざまな鉱物の脈で彩られた岩塊をもつゴーヴァルダナ山の姿が、模倣された（anvakāri）。

注

【Vallabhadeva】

冠の宝石の多色の光がKṛṣṇaの上方で輝き、さまざまな鉱脈（dhātu＝ガイリカ等の鉱物色素）をもつゴーヴァルダナ山の外観を再現する。Kṛṣṇaが幼時にゴーヴァルダナ山を持ち上げた故事が背景にある。

【Mallinātha】

maulibhājām＝冠に座す（宝石たちの）。aṇīyasībhiḥ＝aṇuの比較級否定＝「決して微小でない」＝盛んな。anekadhātu＝多種の鉱物（ガイリカ等）。cchuritā＝まみれた。pūrṇopamā（完全な直喩）。anvakāri＝受動 aorist（anukṛ）。

III.5
Sanskrit (IAST) tasyollasatkāñcanakuṇḍalāgra- pratyuptagārutmatataralabhāsā / avāpa bālyocitanīlakaṇṭha- picchāvacūḍākalanām ivoraḥ //
和訳

彼の輝く黄金の耳飾りの先端に嵌め込まれたエメラルド（gārutmata）の揺れる光によって——胸元は、幼き日に相応しい孔雀の羽の花冠を解き放つかのような姿を得た。

注

【Vallabhadeva】

gārutmata＝ガルダの石＝エメラルド（marakata）。黄金の耳飾りの先端に嵌め込まれたエメラルドの緑の光が胸に射し、あたかも幼年期のKṛṣṇa（牧童時代）が着けていた孔雀羽飾りの花冠（cūḍā）を解いた（akalanā＝amocana）かのように見えた。utprekṣā。

【Mallinātha】

pratyupta＝嵌め込まれた。bālya＝幼年期（brāhmaṇāditvāt ṣyañ）。nīlakaṇṭhapiccha＝孔雀の羽（「piccha-barhe napuṃsake」Amarakośa）。cūḍā＝花冠・頭飾り。kalanā＝結びつけること、あるいは解き放つこと。utprekṣā修辞。

III.6
Sanskrit (IAST) tam aṅgade mandarakūṭakoṭi- vyāghaṭṭanottejanatayā maṇīnām / baṃhīyasā dīptivitānakena cakāsayāmāsatur ullasantī //
和訳

二つの腕輪（aṅgada）が彼を飾った——その宝石の輝きの帳（dīptivitānaka）は、マンダラ山の頂との摩擦（vyāghaṭṭana）によって研ぎ澄まされ（uttejanā）、いよいよ盛んであった。

注

【Vallabhadeva】

腕輪の宝石はかつて乳海撹拌の際にマンダラ山の頂と擦れ合い（vyāghaṭṭana）、砥石にかけたように（uttejanā＝śāṇollekhanā）光を増した。前生の腕輪と同一であるかのようなatiśayokti（誇張法）。cakāsayāmāsatuḥ＝cakāsの使役形・迂言完了・双数。

【Mallinātha】

baṃhīyasā＝bahuの比較級（priyasthir-等の規則でbaṃh代替＋īyasun）＝きわめて盛大な。aṅgada＝keyūra（腕輪。「keyūram aṅgadaṃ tulye」Amarakośa）。二つのatiśayoktiのsaṃkara（混合）。

III.7
Sanskrit (IAST) nisargaraktair valayāvanaddha- tāmrāśmaraśmicchuritair nakhāgraiḥ / vyadyotad adyāpi surārivakṣo- vikṣobhajāsṛksnapitair ivāsau //
和訳

生来赤く、腕輪に嵌めたルビー（tāmrāśman）の光に彩られた爪先をもつ彼は、今なお輝いていた——あたかもその爪先が、魔王（surāri＝Hiraṇyakaśipu）の胸を引き裂いた血に染まっているかのように。

注

【Vallabhadeva】

nisargaraktaiḥ＝本来赤い。腕輪（valaya＝kaṭaka）に嵌めた紅宝石（tāmrāśman＝padmarāga）の光で赤みが増す。Narasiṃha化身がHiraṇyakaśipuの胸を裂いた血（asṛk）に今なお染まっている如く。utprekṣā。

【Mallinātha】

adyāpi＝「今日に至るまで」——Narasiṃha化身の際の血がいまだ乾かぬかのよう。surāri＝hiraṇyakaśipu。vakṣovikṣobha＝胸の引き裂き。asṛk-snapitaiḥ＝血に浸された。utprekṣā。

III.8
Sanskrit (IAST) ubhau yadi vyomni pṛthakpravāhāv ākāśagaṅgāpayasaḥ patetām / tenopamīyeta tamālanīlam āmuktamuktālatam asya vakṣaḥ //
和訳

もし天のガンガーの水が、空において二つの別々の流れとなって流れ落ちるならば——そのときはじめて、タマーラ樹のように黒く、真珠の連なりを纏った彼の胸と比べることができよう。

注

【Vallabhadeva】

黒い胸に白い真珠の二連（muktālatam＝真珠の紐）が懸かる姿は、天のガンガーが二筋に分かれて流れるなら、その間の夜空のようであろう。しかし天のガンガーが二方向に流れることはあり得ない——ゆえに比較不可能。atiśayokti。

【Mallinātha】

saṃbhāvanāyāṃ liṅ（仮想法の optative）。tamāla＝暗色の樹。āmuktamuktālata＝真珠の蔓（紐）を着けた。空の二つのガンガー流と黒い胸に白い二条の真珠——両者の相似は仮定的にしか成立しないからatiśayokti。

III.9
Sanskrit (IAST) tenāmbhasāṃ sārasamayaḥ payodher dadhe maṇidīdhitidīpitāśaḥ / antarvasanbimbagatastadaṅge sākṣād ivālakṣyata yatra lokaḥ //
和訳

海水の精髄から生まれた宝珠（Kaustubha）が彼に掲げられ、その光輝は四方の地平を照らした。そしてその宝珠の中に映る世界（bimbagata）は、あたかも実際に彼の身体の内に住んでいるかのように見えた。

注

【Vallabhadeva】

ambhasāṃ sāramayaḥ＝水の精髄からなる宝珠＝Kaustubha（乳海撹拌から出現）。dadhe＝dhṛの受動完了。宝珠の透明さゆえに外界が映り込み、それがViṣṇuの身体に世界が内在するという神学的真理の暗示となる。utprekṣā。

【Mallinātha】

sāramaya＝精髄の変形物（tat-prakṛti-vacane mayaṭ）。dīdhiti＝光線。dīpitāśaḥ＝四方を照らした。bimbagata＝映像として入った。宝珠に映った外界が、あたかもKṛṣṇaの体内に実際に住む世界のように見える——utprekṣā。Viṣṇuの腹中に全宇宙がある（kukṣistha-loka）という教理が背景。

III.10
Sanskrit (IAST) muktāmayaṃ sārasanāvalambi bhāti sma dāmā prapadīnam asya / aṅguṣṭhaniṣṭhyūtam ivordhvam uccais trisrotasaḥ saṃtatadhāram ambhaḥ //
和訳

腰紐（sārasana）から垂れ下がり、つま先にまで届く真珠の連なり（dāman）が彼に輝いていた——あたかもViṣṇuの親指から噴き上げられた三筋の流れをもつガンガーの、絶え間なく注ぐ水が、上方へ高々と〔舞い戻るかのように〕。

注

【Vallabhadeva】

sārasana＝kaṭisūtra（腰紐）（「klībe sārasanaṃ cātha puṃstryāṃ śṛṅkhalaṃ triṣu」Amarakośa）。āprapadīna＝つま先（prapada＝pādāgra）まで届く。muktāmaya＝真珠に満ちた。

【Mallinātha】

niṣṭhyūtam＝放出された。Viṣṇuの足の親指からガンガーが発するという神話に基づく。trisrotasaḥ＝三筋の流れをもつ Mandākinī（天上のガンガー）。上方へ（ūrdhvam）高く（uccaiḥ）噴き上がった水が再び降りてくるかのように、真珠の鎖が腰から足先へ垂れ下がる。utprekṣā。Daṇḍin はこの種の表現をgauṇavṛtti（比喩的用法）としてgrāmya（粗野）と批評している。

III.11
Sanskrit (IAST) sa indranīlasthalanīlamūrtī rarāja karpūrapiśaṅgavāsāḥ / visṛtvarair amburuhāṃ rajobhir yamasvasuś citra ivodabhāraḥ //
和訳

インドラニーラ（藍玉）の地面のように青黒い身体に、カルプーラ（黄金色）の衣を纏った彼は——蓮の花粉（rajas）が惜しみなく散りかかり彩る、ヤマの妹（Yamunā河）の水の奔流のように輝いた。

注

【Vallabhadeva】

indranīlasthala＝サファイアの台座のような暗色。karpūra＝Vallabhaは「黄金（kāñcana）、あるいは芳香物質」と解す。piśaṅga＝黄色——黄衣のViṣṇu（pītāmbara）。yamasvasā＝Kālindī（Yamunā河）。udabhāra＝水の奔流（udakaのud代替＋bhāra）。upamā。mūrtī rarāja——sandhi: mūrtiḥのvisarga脱落と母音の長音化（「ḍhalope pūrvasya dīrgho 'ṇaḥ」）。

【Mallinātha】

karcūraと読み、harītāla（雄黄）に比す黄色と解す（「harītālaṃ tu karcūram」Vaijayantī辞典）。visṛtvaraiḥ＝visamaraiḥ（ひろく散った）。amburuhām＝蓮花の（ruhのkvip接尾辞）。rajobhiḥ＝花粉で。暗い肌に黄衣をまとうKṛṣṇaの姿を、Yamunā河の暗い水に蓮花粉が散って三色に彩る様子に喩える。

III.12
Sanskrit (IAST) prasādhitasyāsya madhudviṣo 'bhūd anyaiva lakṣmīr iti yuktam etat / vapuṣy aśeṣe 'khilalokakāntā sānanyakāntā hy urasītarā tu //
和訳

装いを整えたこのMadhu仇敵（Kṛṣṇa）の美（lakṣmī）は、まったく別物となった——これは至当である。なぜならば、その美は全身にわたり万人に愛されるが、もう一方のLakṣmī（女神）は、彼以外に恋人を持たず、胸のみに〔住む〕からである。

注

【Vallabhadeva】

Kṛṣṇaが装飾されたことでanyā eva lakṣmīḥ＝前代未聞の、別格の美が生じた。lakṣmīのśleṣa——美・輝きの意と、女神Śrīの意。全身に行きわたる美は万人の愛するところ（akhilalokakāntā）、対する女神Lakṣmīは胸だけに宿り（urasi）、Kṛṣṇa以外の恋人をもたない（ananyakāntā）。

【Mallinātha】

prasādhita＝alaṅkṛta（装飾された）。madhudviṣ＝Madhu殺しのViṣṇu。lakṣmīは「śobhā-saṃpatti-padmāsu lakṣmīḥ śrīr api gadyate」（Viśvakośa）により美・吉祥・女神の三義。装飾によって生じた美（表義のśobhā）と、女神Śrī（含意のpadmā）の同一視のうちに差異を見出す——abhede bhedarūpātiśayoktiḥ（同一性のうちの差異による誇張法）。

III.13
Sanskrit (IAST) kapāṭavistīrṇamanoramoraḥ- sthalasthitaśrīlalanasya tasya / ānanditāśeṣajanā babhūva sarvaṅgasaṅginy aparaiva lakṣmīḥ //
和訳

扉のように広く美しい胸板にŚrī（女神）が恋人として住まうかの方（Kṛṣṇa）に——万人を歓ばせつつ、全身に遍くまとう、もうひとつ別のLakṣmī（美）が生じた。

注

【Vallabhadeva】

前偈（III.12）と同趣旨をbhaṅgāntara（別の角度）で表現。kapāṭavistīrṇa＝扉（kapāṭa）のように広い。śrīlalanā＝Śrī（吉祥天）を恋人（lalanā＝kāntā）とする。aparā eva lakṣmīḥ＝別格の美（前偈のanyā evaと同義）。

【Mallinātha】

同一主題を異なる表現で重ねる詩法（uktiviseṣalābha）。Naiṣadha等の先例を引用。sarvaṅgasaṅginī＝全身に寄り添う＝全身に行きわたる美。aparā eva＝asādhāraṇī（比類なき）。同じ修辞法。

III.14
Sanskrit (IAST) prāṇacchidāṃ daityapater nakhānām upeyuṣāṃ bhūṣaṇatāṃ kṣatena / prakāśakārkaśyaguṇau dadhānāḥ stanau taruṇyaḥ parivavru renam //
和訳

魔王（Hiraṇyakaśipu）の命を奪った爪——いまや装飾品の地位を得たそれら爪の——傷痕（kṣata）によって、輝きと硬さという二つの性質を帯びた胸を持つ若き妃たちが、彼を取り囲んだ。

注

【Vallabhadeva】

異読daityādhipaprāṇamuṣāṃ nakhānām（「魔王の命を盗む爪」）。bhūṣaṇatām upeyuṣām＝かつては武器だった爪が今や装飾品と化した——Narasiṃha化身から現在のKṛṣṇへの連続性を暗示。kṣatena＝傷（爪痕）は乳房の上に現れ、光沢（prakāśa）と硬さ（kārkaśya）をもたらす。

【Mallinātha】

prāṇacchid＝命を断つ。vajrād api kaṭhorāṇām＝金剛石よりも硬い——爪の硬さが乳房の硬さと掛かる。stanauはjāti（種類）として双数（Vāmanaの説「stanādīnāṃ dvitvaviśiṣṭā jātiḥ」）。二つのatiśayoktiのsaṃkara——Narasiṃhaの爪とKṛṣṇaの爪の同一視、および乳房と爪傷の属性の結合。

III.15
Sanskrit (IAST) ākarṣatevoḥrdhvam atikaśīyān atyunnatatvāt kucamaṇḍalena / nanāma madhyo 'tigurutvabhājā nitāntam ākrānta ivāṅganānām //
和訳

極めて細い（atikaśīyān）女たちの腰は、上方へ引き上げられるかのようであり——きわめて重く突き出た乳房の塊（kucamaṇḍala）に、ひたすら圧倒されたかのごとく、しなだれた（nanāma）。

注

【Vallabhadeva】

同趣旨。

【Mallinātha】

atikaśīyān＝kṛśa（痩せた）の比較級（r ṛto hlādelaṅghoḥによりrepha→kaśa代替、＋īyasun）＝極めて細い腰。atyunnatvāt＝極端に隆起しているため。ākrānta iva＝まるで踏みつけられたかのように。utprekṣā。またsamāsoktī（暗喩法）が含まれる——腰と乳房の描写が、敵の攻撃に屈する征服者の姿を暗示する。

III.16
Sanskrit (IAST) yāṃ yāṃ priyaḥ praikṣata kātarākṣīṃ sā sā hriyā namramukhī babhūva / niḥśaṅkam anyāḥ samam āhiterṣyās tatrāntare jaghnur amuṃ kaṭākṣaiḥ //
和訳

Sanskrit (IAST) pītvā jalānāṃ nidhinātigādhyād vṛddhiṃ gate 'py ātmani naiva māntīḥ / kṣitā ivendoḥ sa ruco 'dhivelaṃ muktāvalīr ākalayāṃcakāra //
和訳

海は水の宝庫であるが、その飽くなき貪欲ゆえに、自らの体が膨れ上がっても光を抑え切れず――月の光線を吐き出したかのように、あの御方は汀に真珠の列を見出した。

注

【Vallabhadeva】(= Val 72)

kṣitā（吐き出された）：Val本はcitā（積み上げられた）と読む。vṛddhiṃ gate ātmani＝自身が満ちてゆくとき（月の出に海は膨張する）。真珠が月光の化身かとのutprekṣā。

【Mallinātha】

gārdhya（貪欲）はgṛdhiの派生、svārthe ṣyañ接尾辞。pītvā（飲んだ後）はkṣepaṇa（嘔吐）に対するpūrvakālatā（先行時制）。māntīḥ＝amāntīḥ、抑え切れぬ。ākalayāṃcakāra（認めた）はkalのperiphrastic perfect。utprekṣā。

III.74
Sanskrit (IAST) sāṭopamurvīm aniśaṃ nadanto yaiḥ plāvayiṣyanti samantato 'mī / tāny ekadeśān nibhṛtaṃ payodheḥ so 'mbhāṃsi meghān pibataḥ dadarśa //
和訳

あの雲たちが、威勢よく絶え間なく雷鳴を轟かせつつ、これらの水で大地を四方から水浸しにしようというのに――その水をこっそり隅の方から飲んでいる雲たちを、あの御方は見た。大海の広大無辺さよ。

注

【Vallabhadeva】(= Val 73)

ekadeśān＝「片隅から」。nibhṛtam＝密かに。海が大きすぎて、雲が端からこっそり水を吸い上げるしかないと。偉大なる者（mahādhana）が誰かに少しだけ与えても全体を豊かにしてしまうのに似る。

【Mallinātha】

sāṭopam＝sasaṃbhramam（威勢をもって）。plāvayiṣyantiは使役未来形。pibataḥはpayodheḥを修飾する属格分詞。海のaparicchinnarūpatva（無辺の形姿）が暗示される。

III.75
Sanskrit (IAST) uddhṛtya meghais tata eva toyam arthaṃ munīndrair iva saṃpraṇītāḥ / ālokayāmāsa hariḥ patantīr nadīḥ smṛtīr vedam ivāmburāśim //
和訳

雲によってまさにそこ（海）から水を汲み上げ、大聖仙たちによって編まれたかのように――あの御方（ハリ）は、海に注ぎ込む河川を見た。まるでスムリティ（法典）がヴェーダに帰入するように。

注

【Vallabhadeva】(= Val 74)

雲は仙人に、水は経典の意味（artha）に比される。河川がヴェーダ（海）に帰入するように、スムリティ（法典）は聖典（ヴェーダ）に根拠を持ち最後にそこへ帰る。aneka-upamā（多重直喩）。

【Mallinātha】

munīndraiḥ＝meghaiḥに対応。tataḥ＝amburaśeḥ（海から）。saṃpraṇītāḥ＝制作された。スムリティはśrutimūlatva（天啓に根拠をもつこと）ゆえに権威がある。aneka-upamā。

III.76
Sanskrit (IAST) vikrīya diśyāni dhanāny urūṇi dvaipyān asāv uttamalābhabhājaḥ / tarīṣu tatratyam aphalgu bhāṇḍaṃ sāṃyātrikān āvapato 'bhyanandat //
和訳

遠方から運んだ多大な財貨を売り、島々の住民から最上の利益を得て、船に現地の貴重な商品を積み込む――そうした航海商人たちをあの御方は祝福した。

注

【Vallabhadeva】(= Val 75)

dvaipya＝dvīpa（島）に住む者（yañ接尾辞）。viśrīyaと読む写本もあり。āvapataḥ＝積み入れている（ā-vapの現在分詞）。

【Mallinātha】

diśyāni＝dikṣu bhavāni（諸方向に産する、遠方から運んだ）。uttamalābhabhājaḥ＝dvaiguṇyādi（倍増の）利益を享受する者。bhāṇḍam＝mūladhana（元手）／paṇyadravya（商品）。sāṃyātrika＝potavaṇij（船商人）。tarī＝nau（船）。

III.77
Sanskrit (IAST) utpitsavo 'ntar nadabhartur uccair garīyasā niḥśvasitānilena / payāṃsi bhaktyā garuḍadhvajasya dhvajānivocchikṣipire phaṇīndrāḥ //
和訳

河川の主（海）の内から脱出しようと欲する蛇王たちが、ガルダの旗をもつ御方（クリシュナ）への帰依ゆえに、旗のように水を高く打ち上げた――海の猛烈な吐息の風によって。

注

【Vallabhadeva】(= Val 76)

蛇王たち（phaṇīndrāḥ）は海中から脱出したがっている（utpitsavaḥ、patの意欲活用san+u接尾辞）。海の息吹（niḥśvasitānila）で水が旗のように立ち上がる。

【Mallinātha】

nadabhartuḥ＝samudrasya（海の）。utpitsavaḥはpatatIのsan願望活用からu接尾辞。ucchikṣipireはut-kṣipのātmanepada完了形（svaritettvaによる中動態）。utprekṣā。dhvajāniva＝旗を掲げるように水を上方に跳ね上げた。

III.78
Sanskrit (IAST) tam āgataṃ vīkṣya yugāntabandhum utsaṅgaśayyāśayam amburāśiḥ / pratyujjagāmeva gurupramoda- prasāritottuṅgataraṅgabāhuḥ //
和訳

劫末の友であり、膝の褥に眠る御方が来たと見て、大海は歓びに満ち、高くそびえる波の腕を広げて出迎えに行ったかのようであった。

注

【Vallabhadeva】(= Val 77)

yugāntabandhu＝劫末の友（プララヤの際、ヴィシュヌは海上に横たわる）。utsaṅgaśayyā＝膝上が臥所。āśaya＝そこに眠る者（adhikaraṇe śeteのkyap接尾辞）。波が腕のように広がり歓喜をもって出迎える。

【Mallinātha】

yugāntabandhu＝āpadbandhum（災難の友）の意。utsaṅgaśayyāśaya＝utsaṅga（膝）がśayyāで、そこにśete（臥す）のac接尾辞。pratyujjagāma＝出迎えに行った。ivaの省略でkriyāsvarūpotprekṣā（行為自体の想見法）。

III.79
Sanskrit (IAST) utsaṅgitāmbhaḥkaṇako nabhasvān udanvataḥ khedalavān mamārja / tasyānuvelaṃ vrajato 'dhivelaṃ elālatāsphālanalabdhagandhaḥ //
和訳

水飛沫を含み、小荳蒄の蔓を揺すって得た芳香を帯びた海風が、汀に沿って歩むあの御方の疲れの滴を際限なく拭い去った。

注

【Vallabhadeva】(= Val 78)

Val本はsvedalavān（汗の滴を）と読む。utsaṅgitāḥ＝上方に運ばれた、あるいは中に含まれた水の飛沫。ailālatānām āsphālane＝ailā（小荳蒄）の蔓を打ち揺すること。anuvelam＝岸の近くで。ativelam＝甚だしく。

【Mallinātha】

Mal本はkhedalavān（疲れの微粒）と読む。nabhasvān＝vāyu（風）。elālatāのāsphālana（打擦）によってlabdhagandha（芳香を得た）。adhivelam＝velāyām（汀に）。anuvelam＝pratikṣaṇam（絶え間なく）。kāvyaliṅga（詩的因由）。

III.80
Sanskrit (IAST) uttālatālīvanasaṃpravṛtta- samīrasīmantitaketakīkāḥ / āsedire lāvaṇasaindhavīnāṃ camūcaraiḥ kacchabhuvāṃ pradeśāḥ //
和訳

高く聳えるヤシ林から吹き出す風にケータキー（タコノキ）の花が分け目をつけられた――そのような塩海沿岸の湿地帯を、軍兵たちは踏み分けて到達した。

注

【Vallabhadeva】(= Val 79)

uttāla＝高く聳える。sīmantita＝髪の分け目を付けたように（sīmantaから使役ṇyanta＋受動kta）。ケータキーの花弁が風で割れる様を女性の髪の分け目に喩える。kaccha＝汀・湿地。lāvaṇasaindhavīはlavaṇa-sindhu（塩海）の女性形（ubhayapadavṛddhi）。

【Mallinātha】

camūcaraiḥ＝軍隊に従う者たち（caraṣṭaḥによるṭa接尾辞）。āsedireはsadの受動完了形（karmaṇi liṭ）。ここにsvabhāvokti（自然描写法）とprāsa（頭韻）の修辞あり。ojas（壮麗さ）がśleṣa・śabdasaukumārya等の多重美質として現れる。

III.81
Sanskrit (IAST) lavaṅgamālākalitāvataṃsās te nārikelāntarapaḥ pibantaḥ / āsvāditādrakramukāḥ samudrād abhyāgatasya pratipattim īyuḥ //
和訳

丁子の花輪で髪飾りをつけ、椰子の実の中の水を飲み、生姜入りの檳榔子を味わいながら――彼ら兵士たちは、遠来の客への歓待を大海から受けた。

注

【Vallabhadeva】(= Val 80)

nārikelāntarapaḥはpṛthakpada（分離語）。nārikelasya abhyantare yāḥ āpaḥ（椰子の果実の中の水）。兵士たちは客人として海にpratipatti（歓待）を受けた。家に来客があれば花・飲料・tāmbūlaが出されるように。Val本はāpuḥと読む。韻律はupajāti。

【Mallinātha】

lavaṅgamālā＝丁子花の花環。kalitāvataṃsāḥ＝飾りを作った。kramuka＝pūgīphala（檳榔子）。pratipattim＝gaurava（敬意）・satkāra（歓待）。abhyāgatapratipatti（来客歓待）を原因とするkāvyaliṅga。さらに海と兵士が家主と客人に喩えられるalaṅkārālaṅkāradhvani（修辞の余韻）。

III.82
Sanskrit (IAST) turagaśatākulasya paritaḥ param ekaturagajanmanaḥ pramathitabhūbhṛtaḥ pratipathaṃ mathitasya bhṛśaṃ mahībhṛtā / paricalataḥ balānujabalasya puraḥ satataṃ dhṛtaśriyaś ciravigataśriyo jalanidheś ca tadābhavad antaraṃ mahat //
和訳

周囲に幾百の馬で溢れる者と、ただ一頭の馬（ウッチャイフシュラヴァス）から生まれたのみの者。
行く先々で王たちを砕く者と、曼荼羅山によって激しく撹拌された者。
常にシュリー（吉祥・ラクシュミー）を保つ者が前方に進むバラの弟（クリシュナ）の軍勢と、久しくシュリーを失った海と――その時、両者の間には大きな隔たりがあった。

注

【Vallabhadeva】(= Val 81)

最終偈。韻律はpañcāvalī（別名racitā）。balānujabala＝bala（バララーマ）の弟（anuja）であるヴィシュヌの軍勢（bala＝sainya）。海との対比：軍勢は馬群に囲まれるが、海はただ一頭の馬（uccaiḥśravas）を産んだのみ。軍勢は諸王を打ち砕くが、海は曼荼羅山に撹拌された。軍勢は常にシュリーを保つが、海は久しく（乳海撹拌の後）シュリー（ラクシュミー）を失った。vyatireka（差異法）。

【Mallinātha】

turagaśatākulasya＝無数の馬で満ちた（軍勢）に対し、海はekaturagajanmanaḥ（ただ一頭の馬すら生んだだけ）。pramathitabhūbhṛtaḥ＝王たち（bhūbhṛt）と山々を打ち砕いた（軍勢）に対し、海は曼荼羅山（mahībhṛtā）に撹拌された（mathita、受動）。dhṛtaśriyaḥ＝常にシュリーを保つ軍勢に対し、海はciravigataśriyaḥ（ヴィシュヌが海からラクシュミーを取り去って以来、久しく無き者）。vyatireka-alaṅkāra（差異法）。韻律はpañcāvalī（na-bha-ja-ja-jā-ja-rau）。ある注者はdhṛtaśrīと読み別韻律を想定。
