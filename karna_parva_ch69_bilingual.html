マハーバーラタ ― カルナ篇 第69章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 69 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ69」、全52詩節からなります。ユダーマンユ王がクリシュナとアルジュナを迎える場面（第1〜3詩節）、ユダーマンユ王の歓迎の言葉（第4〜52詩節）で本章は終わります。カルナはまだ無事であると知り、王は驚きます。
karṇaparva — ekonasaptatitamo'dhyāyaḥ (69)
第69章
sañjaya uvāca|
athopayātau pṛthulohitākṣau śarācitāṅgau rudhirapradigdhau|
samīkṣya senāgranarapravīrau yudhiṣṭhiro vākyamidaṃ babhāṣe||
// 8-69-1 //
広い赤い目をし、矢に覆われた体に血をまとった軍の先頭の二人の勇者を見定めて、ユディシュティラはこう語った。
tato yudhiṣṭhiro dṛṣṭvā sahitau keśavārjunau|
hatamādhirathiṃ mene saṅkhye gāṇḍīvadhanvanā||
// 8-69-2 //
ユディシュティラはケーシャヴァとアルジュナが共にいるのを見て、ガーンディーヴァの弓を持つ者が戦場でアーディラティ（カルナ）を殺したのだと思った。
tāvabhyanandatkaunteyaḥ sāmnā paramavalgunā|
smitapūrvamamitraghna pūjayanbharatarpabha||
// 8-69-3 //
カウンテーヤは最も優しい穏やかな言葉で二人を歓迎し、微笑みながら、敵を滅ぼす者よ、バーラタの雄牛よ、敬意を表した。
yudhiṣṭhira uvāca|
svāgataṃ devakīputra svāgataṃ te dhanañjaya|
priyaṃ me darśanaṃ vāḍhaṃ yuvayornarasiṃhayoḥ||
// 8-69-4 //
「デーヴァキーの子よ、ようこそ。ダナンジャヤよ、ようこそ。人中の獅子たる汝ら二人に会えて、私は実に喜ばしい。
ariṣṭayorakṣatayoḥ karṇaṃ hatvā mahāratham|
āśīvipasamaṃ yuddhe sarvaśastraviśāradam||
// 8-69-5 //
無傷で無事なまま、大戦車戦士カルナを殺してくれたのだな。戦いにおいて毒蛇のごとく、全ての武器に通じた者を。
agragaṃ dhārtarāṣṭrāṇāṃ sarveṣāṃ śarma varma ca|
rakṣitaṃ vṛṣasenena supeṇena ca dhanvinā||
// 8-69-6 //
ドリタラーシュトラの息子たち全ての先頭に立ち、全ての者の盾であり鎧であった者を。弓の達人ヴリシャセーナとスシェーナに守られた者を。
anujñātaṃ mahāvīryaṃ rāmeṇāstre sudurjayam|
agryaṃ sarvasya lokasya rathinaṃ lokaviśrutam||
// 8-69-7 //
パラシュラーマに武器の術を授かった大いなる力の者、征服し難き者を。全世界の最高の戦車戦士にして世に名高い者を。
trātāraṃ dhārtarāṣṭrāṇāṃ gantāraṃ vāhinīmukhe|
hantāraṃ parasainyānāmamitragaṇamardanam||
// 8-69-8 //
ドリタラーシュトラの息子たちの守護者、軍の先頭に立つ者、敵軍の殺戮者、敵の軍勢を粉砕する者を。
duryodhanahite yuktamasmadduḥkhāya codyatam|
apradhṛṣyaṃ mahāyuddhe devairapi savāsavaiḥ||
// 8-69-9 //
ドゥルヨーダナの利益に尽くし、我々の苦しみのために立ち上がった者、ヴァーサヴァ（インドラ）率いる神々にも大いなる戦いで打ち勝てぬ者を。
analānilayostulyaṃ tejasā ca balena ca|
pātālamiva gambhīraṃ suhṛdāṃ nandivardhanam||
// 8-69-10 //
火と風に等しい輝きと力を持ち、奈落のように深く、味方の喜びを増す者を。
antakaṃ mama mitrāṇāṃ hatvā karṇaṃ mahāmṛdhe|
diṣṭyā yuvāmanuprāptau hatvā'suramivāmarau||
// 8-69-11 //
我が友人たちを滅ぼす者カルナを大いなる戦いで殺して、汝ら二人が帰ってきてくれた。まるにアスラを殺した不死者たちのように。幸いなことだ。
tena yuddhamabhītena mayā'dyāpyacyutārjunau|
kṛtaṃ ghoraṃ mahābāhū dhṛṣṭadyumnasya paśyataḥ|
antakeneva kruddhena prajāḥ sarvā jighāṃsatā||
// 8-69-12 //
大腕の二人よ、あの恐れを知らぬ者と今日もまた、ドリシュタデュムナが見ている前で恐ろしい戦いを私は行ったのだ。怒って全ての生き物を殺そうとするヤマ（死神）のように。
tena ketuś ca me cchinno hatau ca pārṣṇisārathī|
hatavāhaḥ kṛtaścāsmi yuyudhānasya paśyataḥ||
// 8-69-13 //
あの者に私の旗印は切り落とされ、車輪の護衛と御者も殺された。馬を殺されて無力にされたのだ、ユユダーナ（サーティヤキ）が見ている前で。
dhṛṣṭadyumnasya yamayorvīrasya ca śikhaṇḍinaḥ|
paśyatāṃ draupadeyānāṃ śatadroś ca mahātmanaḥ||
// 8-69-14 //
ドリシュタデュムナ、双子（ナクラとサハデーヴァ）、勇者シカンディン、ドラウパディーの子たち、シャタドルの偉大な者が見ている前で。
etāñjitvā mahāvīryaḥ karṇaḥ śatrugaṇānbahūn|
jitavānmāṃ mahābāho yatamāno mahāraṇe||
// 8-69-15 //
大いなる武勇のカルナは、多くの敵の軍勢を破ってから、大腕よ、大いなる戦場で全力を尽くす私を打ち負かしたのだ。
anusṛtya ca māṃ yuddhe paruṣāṇyuktavānbahu|
tatra tatra yudhāṃ śreṣṭha paribhūya na saṃśayaḥ||
// 8-69-16 //
戦いの最高者よ、私を追いかけて戦場のあちこちで辛辣な言葉を多く浴びせ、軽蔑したことは疑いない。
bhīmasenaprabhāvāttu yajjīvāmi dhanañjaya|
bahunātra kimuktena hate soḍhuṃ samutsahe||
// 8-69-17 //
ダナンジャヤよ、ビーマセーナの力のおかげで私は生きている。多くを語っても仕方がない。耐えねばならなかったことを。
trayodaśāhaṃ varṣāṇi yasmādbhīto dhanañjaya|
na sma nidrāṃ labhe rātrau na cāhani sukhaṃ kvacit||
// 8-69-18 //
ダナンジャヤよ、十三年もの間、私はあの者を恐れ、夜に眠りを得ることもなく、昼にもどこにも安らぎはなかった。
tasya dveṣeṇa saṃyuktaḥ paridahye dhanañjaya|
ātmano maraṇaṃ jānanvādhrīṇasa iva dvijaḥ||
// 8-69-19 //
ダナンジャヤよ、あの者への憎しみに私は焼かれている。自らの死を知りながらも、供儀の鳥（ヴァードリーナサ）のように。
tasyāyamagamatkālaścintayānasya me ciram|
kathaṃ karṇo mayā śakyo yuddhe kṣapayituṃ bhavet||
// 8-69-20 //
長い間考え続けていたこの時がついに来たのだ。どうすれば戦いでカルナを滅ぼせるかと。
jāgratsvapaṃś ca kaunteya karṇameva smarāhyaham|
paśyāmi tatratatraiva karṇabhūtamidaṃ jagat||
// 8-69-21 //
カウンテーヤよ、目覚めている時も眠っている時も、私はカルナのことだけを思い出す。あちこちを見ても、この世界がカルナだけに見えるのだ。
yatra yatra hi gacchāmi karṇādbhīto dhanañjaya|
tatra tatra hi paśyāmi karṇamevāgrataḥ sthitam||
// 8-69-22 //
ダナンジャヤよ、カルナを恐れてどこへ行こうとも、私にはカルナが目の前に立っているように見えるのだ。
so'haṃ tenaiva vīreṇa samareṣvapalāyinā|
sahayaḥ sarathaḥ pārtha jitvā jīvanvisarjitaḥ||
// 8-69-23 //
パールタよ、戦場で退かぬあの勇者によって、私は馬も戦車もろとも打ち負かされながらも、生きたまま放免されたのだ。
ko nu me jīvitenārtho rājyenārtho bhavetpunaḥ|
mamaivaṃ vikṣatasyādya karṇenāhavaśobhinā||
// 8-69-24 //
戦場に輝くカルナにこのように傷つけられた今、私の命に何の意味があろうか。王国に何の意味があろうか。
na prāptapūrvaṃ yadbhīṣmātkṛpāddroṇācca saṃyuge|
tatprāptamadya me yuddhe sūtaputrānmahārathāt||
// 8-69-25 //
ビーシュマからも、クリパからも、ドローナからも戦場で受けなかったことを、今日スータの子の大戦車戦士から受けたのだ。
sa tvāṃ pṛcchāmi kaunteya yathā na kuśalastathā|
tanmamācakṣva kārtsnyena yathā karṇo hatastvayā||
// 8-69-26 //
カウンテーヤよ、元気であるとはとても言えぬ私がおまえに尋ねる。カルナをどのように殺したのか、すべてを詳しく語ってくれ。
śakratulyabalo yuddhe yamatulyaḥ parākrame|
rāmatulyastathāstreṣu sa kathaṃ te niṣūditaḥ||
// 8-69-27 //
戦いにおいてインドラに等しい力を持ち、武勇においてヤマに等しく、武器においてパラシュラーマに等しい者が、どのようにしておまえに殺されたのか。
mahārathasamākhyātaḥ sarvayuddhaviśāradaḥ|
dhanurdharāṇāṃ pravaraḥ sarveṣāṃ vai sadārjuna||
// 8-69-28 //
大戦車戦士と称えられ、あらゆる戦いに通じ、常に弓の使い手の中の最高者であった者が。
pūjito dhṛtarāṣṭreṇa saputreṇa viśāmpate|
tvadarthameva rādheyaḥ sa kathaṃ nihatastvayā||
// 8-69-29 //
ドリタラーシュトラに息子たちと共に敬われ、おまえのためにこそラーデーヤは存在していた。その者がどのようにしておまえに殺されたのか。
dhārtarāṣṭrasya yoddhāraḥ sarva eva sadārjuna|
tava mṛtyuṃ raṇe karṇaṃ manyante puruṣarṣabha||
// 8-69-30 //
人中の雄牛よ、ドリタラーシュトラの子の全ての戦士たちは、常にカルナこそがおまえの死であると見なしていたのだ。
sa tvayā puruṣavyāghra kathaṃ yuddhe niṣūditaḥ|
tanmamācakṣva kaunteya yathā karṇo hatastvayā||
// 8-69-31 //
人中の虎よ、その者がおまえにどのように戦いで殺されたのか。カウンテーヤよ、それを語ってくれ。カルナをどのように殺したのかを。
sotsedhamasya ca śiraḥ paśyatāṃ suhṛdāṃ hṛtam|
tvayā puruṣaśārdūla siṃheneva yathā ruroḥ||
// 8-69-32 //
人中のシャールドゥーラ（虎）よ、味方たちが見ている前で、おまえによって高々とした彼の首が奪われたのだな。獅子がルル鹿を殺すように。
sarvā diśaḥ paryapatattvadarthaṃ tvāṃ sūtaputraḥ samare parīpsan|
ditsannṛṇāṃ śakaṭaṃ ratnapūrṇaṃ kathaṃ tvayāsau nihato'dya karṇaḥ||
// 8-69-33 //
おまえを求めて全方位を駆け巡り、戦場でおまえを追い求めていたスータの子が、宝物満載の車を施そうとしていた者が、どのようにして今日おまえに殺されたのか。
tvayā raṇe nihataḥ sūtaputraḥ kaccitkṛtaṃ me paramaṃ tvayādya priyaṃ raṇe sūtaputraṃ nihatya||
// 8-69-34 //
戦場でおまえに殺されたスータの子よ。おまえが今日、スータの子を殺して私に最高の喜びを与えてくれたのか。
sarvā diśaḥ paryapatattvadarthaṃ mudānvito garvitaḥ sūtaputraḥ|
sa śūramānī samare sametya kaccittvayā nihataḥ sūtaputraḥ||
// 8-69-35 //
おまえを求めて全方位を駆け巡り、喜びに満ち傲慢であったスータの子。戦場で自らを勇者と称するあの者が、おまえに殺されたのか。
rājyaṃ paraṃ hastigavāśvayuktaṃ rathaṃ ditsuryaḥ parebhyastvardarthe|
tvayā raṇe spardhate yaḥ sa pāpaḥ kaccittvayā nihataḥ pāpabuddhiḥ||
// 8-69-36 //
おまえのために敵に象・牛・馬で満ちた最高の王国と戦車を与えようとしていた者、おまえと争ったあの罪深い者が、おまえに殺されたのか、あの邪悪な知性の者が。
yo'sau nityaṃ śauryamadena matto vikatthate saṃsadi kauravāṇām|
prītyarthaṃ vai tāta suyodhanasya kaccitsa pāpo nihatastvayādya||
// 8-69-37 //
武勇の誇りに酔い、カウラヴァの宮廷でスヨーダナ（ドゥルヨーダナ）を喜ばせるために常に自慢していた者が、あの罪深い者が今日おまえに殺されたのか。
kaccitsamāgamya dhanuḥpramuktai-- stvatpreṣitairlohamayairvihaṃgaiḥ|
śete bhinnaḥ pāṃsuṣu sūtaputraḥ kaccidbhagrau dhārtarāṣṭrasya bāhū||
// 8-69-38 //
弓から放たれた鉄の鳥（矢）に打たれて、スータの子は塵の中に横たわっているのか。ドリタラーシュトラの子の両腕は折れたのか。
yo'sau sadā ślāghate rājamadhye duryodhanaṃ harṣayandarpayuktaḥ|
hantā'smi sarvāniti pāṇḍuputrā-- nahaṃ hantā phalgunasyeti mohāt||
// 8-69-39 //
ドゥルヨーダナを喜ばせ傲慢に満ちて、王たちの中で常に自慢していた者が、「パーンドゥの子たち全てを私が殺す」「私がアルジュナを殺す」と愚かにも言っていた者が。
kaccidvaco'sya vitathaṃ tvayā kṛtaṃ yattatpriyāmavadattāta karṇaḥ|
sabhāmathye rūkṣamanekarūpaṃ dhikpāṇḍavānapatistvaṃ hi kṛṣṇe||
// 8-69-40 //
あの者が最愛の妻（ドラウパディー）に語った粗暴で多様な言葉、「クリシュナ（ドラウパディー）よ、パーンダヴァを捨てよ、おまえの主人は彼らだ」という宮廷での言葉を、おまえは虚しくしてくれたのか。
kaccidbhuvaṃ śatrurayaṃ mahātmā hyadhārayaddvādaśa yaḥ samāstu|
karṇo vrataṃ ghoramamitrasāho duryodhanasyārthaniviṣṭabuddhiḥ||
// 8-69-41 //
敵を耐えぬかせる者カルナが十二年間恐ろしい誓いを立てて大地の上を歩んでいた者が、ドゥルヨーダナの利益に心を定めて。
pādau na dhāve yāvadahaṃ na hanmi dhanañjayaṃ samareṣūgravegam|
kaccidraṇe phalguna taṃ nihatya kaccidvrataṃ tasya bhagnaṃ tvayā'dya||
// 8-69-42 //
「激しい勢いのダナンジャヤを戦場で殺すまで足を洗わぬ」という誓いを、アルジュナよ、戦場であの者を殺して、おまえは今日その誓いを砕いたのか。
yo'sau kṛṣṇāmabravīdduṣṭabuddhiḥ karṇaḥ sabhāyāṃ kuruvīramadhye|
kiṃ pāṇḍavāṃstvaṃ na jahāsi kṛṣṇe sudurbalānpatitānhīnasatvān||
// 8-69-43 //
邪悪な知性のカルナがクリシュナ（ドラウパディー）にクルの勇者たちの面前で宮廷で言った言葉、「クリシュナよ、なぜパーンダヴァを捨てぬのか。力なく、落ちぶれ、気力を失った者たちを。」
yo'sau karṇaḥ pratyajānāttvadarthe nāhaṃ hatvā saha kṛṣṇena pārtham|
ihopayāteti sa pāpabuddhiḥ kaccicchete śarasambhinnagātraḥ||
// 8-69-44 //
おまえのために「クリシュナと共にパールタを殺さずしてはここに帰らぬ」と誓った邪悪な知性のあの者が、矢に体を貫かれて横たわっているのか。
kaccitsaṅgrāmo vidito vai tavāyaṃ samāgame sṛñjaya kauravāṇām|
yenāvasthāmīdṛśīṃ prāpito'haṃ kaccittvayā so'dya hato durātmā||
// 8-69-45 //
スリンジャヤとカウラヴァの合戦において、このような境遇に私を陥れた者を知っておるか。あの邪悪な者が今日おまえに殺されたのか。
kaccittvayā tasya sumandabuddhe-- rgāṇḍīvamuktairviśikhairjvaladbhiḥ|
sakuṇḍalaṃ bhānumaduttamāṅgaṃ kāyātprakṛttaṃ yudhi savyasācin||
// 8-69-46 //
サヴィヤサーチン（アルジュナ）よ、あの愚かな知性の者の耳飾りを付けた光輝ある首が、おまえのガーンディーヴァから放たれた燃え立つ矢によって、戦場で体から切り落とされたのか。
yattanmayā bāṇasamarpitena dhyāto'si karṇasya vadhāya vīra|
tanme tvayā kaccidamoghamadya dhyānaṃ kṛtaṃ karṇanipātanena||
// 8-69-47 //
矢に打たれた（カルナに射られた）私が、カルナの殺害のためにおまえを念じたその念じが、カルナを倒すことによって今日おまえによって無駄でなくされたのか。
yaddarpapūrṇaḥ sa suyodhano'smā-- ndidhakṣate karṇasamāśrayeṇa|
kaccittvayā so'dya samāśrayo'sya bhagnaḥ parākramya suyodhanasya||
// 8-69-48 //
傲慢に満ちたスヨーダナ（ドゥルヨーダナ）がカルナを頼りにして我らを焼き尽くそうとしたが、その頼みの綱が今日おまえによって砕かれたのか、スヨーダナの。
yo naḥ purā ṣaṇḍhatilānavoca-- tsabhāmadhye kauravāṇāṃ samakṣam|
sa durmatiḥ kaccidupetya saṅkhye tvayā hataḥ sūtaputro'tyamarṣī||
// 8-69-49 //
カウラヴァたちの面前で宮廷で我らを去勢者・ゴマと呼んだ者が、戦場でその邪悪な知性の怒り深いスータの子がおまえに殺されたのか。
yaḥ prāhiṇotsūtaputro durātmā kṛṣṇāṃ jitāṃ saubalehānayeti|
sa mandabuddhirnihataḥ prasahya vaikartanastvadya kaccinmahātman||
// 8-69-50 //
邪悪な魂のスータの子が「サウバラ（シャクニ）よ、クリシュナ（ドラウパディー）は勝ち取られた。連れて来い」と送り出した者が、あの愚かな知性のヴァイカルタナは今日おまえに力ずくで殺されたのか、偉大なる者よ。
yaḥ śastrabhṛcchreṣṭhatamaṃ pṛthivyāṃ pitāmahaṃ vyākṣipadalpacetāḥ|
saṅkhyāyamāno'rdharathaḥ sa kacci-- ttvayāṃ hato'dyādhirathirmahātman||
// 8-69-51 //
この大地の上の武器を持つ者の最高者たる祖父（ビーシュマ）を侮り、小さな心で半戦車戦士と数えられていたあのアーディラティ（カルナ）が、今日おまえに殺されたのか、偉大なる者よ。
amarṣajaṃ nikṛtisamīraṇeritaṃ hṛdi sthitaṃ jvalanamimaṃ sadā mama|
hato mayā so'dya sametya karṇa iti bruvanpraśamayase'dya phalguna||
||
// 8-69-52 //
怒りから生じ、侮辱の風に煽られ、常に私の心に燃え続けるこの炎を、「あのカルナを戦場で出会って殺した」と語って、アルジュナよ、おまえは今日鎮めてくれるのか。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekonasaptatitamo'dhyāyaḥ|| 69 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第69章終わり。
