本章は南伝（Southern Recension）テキストの「アディヤーヤ14」（サハデーヴァがドゥフシャーサナを破る場面。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-14-N）と和訳の段落番号が対応しています。
karṇaparva — caturdaśo'dhyāyaḥ (14)
第14章　サハデーヴァがドゥフシャーサナを破る
sañjaya uvāca|
sahadevaṃ tathā kruddhaṃ nighnantaṃ tava vāhinīm|
duḥśāsano mahārāja bhrātā bhrātaram abhyayāt|| // 8-14-1 //
サンジャヤは語った。 （1）大王よ、怒ってあなたの軍を打ち倒しているサハデーヴァに対して、ドゥフシャーサナは兄弟として兄弟に向かいました。
tau sametau mahārāja dṛṣṭvā tatra mahārathāḥ|
siṃhanādaravāṃś cakrur vāsāṃsy ādudhuvuś ca ha|| // 8-14-2 //
（2）大王よ、二人が出会ったのを見て、偉大な戦車戦士たちは獅子の咆哮を上げ、衣を振り回しました。
tato bhārata ruṣṭena tava putreṇa dhanvinā|
pāṇḍuputras tribhir bāṇair vakṣasy abhihato balī|| // 8-14-3 //
（3）バーラタよ、怒った弓兵であるあなたの息子は、力あるパーンドゥの子の胸を三本の矢で打ちました。
sahadevastato rājan nārācena tavātmajam|
vidvvā vivyādha saptatyā sārathiṃ ca tribhiḥ śaraiḥ|| // 8-14-4 //
（4）王よ、サハデーヴァは鉄の矢であなたの息子を射ち、さらに七十本の矢で、御者を三本の矢で射ちました。
duḥśāsanas tataś cāpaṃ chittvā rājan mahāhave|
sahadevaṃ trisaptatyā bāhor urasi cārpayat|| // 8-14-5 //
（5）ドゥフシャーサナは大戦闘でサハデーヴァの弓を断ち切り、七十三本の矢を両腕と胸に打ち込みました。
sahadevastu saṅkruddhaḥ khaṅgaṃ gṛhya mahāhave|
āvidhya prāsṛjattūrṇaṃ tava putrathaṃ prati|| // 8-14-6 //
（6）大戦闘で激怒したサハデーヴァは、剣を取り上げ、振り回してあなたの息子の戦車に向けて素早く投げつけました。
samārgaṇaguṇaṃ cāpaṃ chittvā tasya mahānasiḥ|
nipapāta tato bhūmau cyutaḥ sarpa ivāmbarāt|| // 8-14-7 //
（7）大いなる剣は矢とともに弓を断ち切り、空から落ちた蛇のように大地に落ちました。
athānyad dhanurādāya sahadevaḥ pratāpavān|
duḥśāsanāya cikṣepa bāṇamantakaraṃ tataḥ|| // 8-14-8 //
（8）威光あるサハデーヴァは別の弓を取り、命を奪う矢をドゥフシャーサナに放ちました。
tamāpatantaṃ viśikhaṃ yamadaṇḍopamatviṣam|
khaṅgena śitadhāreṇa dvidhā ciccheda kauravaḥ|| // 8-14-9 //
（9）閻魔の杖のように輝きながら飛んでくるその矢を、カウラヴァ（ドゥフシャーサナ）は鋭い刃の剣で真っ二つに切りました。
tatas taṃ niśitaṃ khaṅgam āvidhya yudhi satvaraḥ|
dhanuś cānyat samādāya śaraṃ jagrāha vīryavān|| // 8-14-10 //
（10）素早く戦場でその鋭い剣を振り回し、別の弓を取り、力ある者は矢を手にしました。
tamāpatantaṃ sahasā nistriṃśaṃ niśitaiḥ śaraiḥ|
pātayāmāsa samare sahadevo hasann iva|| // 8-14-11 //
（11）突然飛んでくるその剣を、サハデーヴァは微笑みながら鋭い矢で戦場に叩き落としました。
tato bāṇāṃś catuḥṣaṣṭiṃ tava putro mahāraṇe|
sahadevarathaṃ tūrṇaṃ preṣayāmāsa bhārata|| // 8-14-12 //
（12）バーラタよ、あなたの息子は大戦闘で六十四本の矢を素早くサハデーヴァの戦車に向けて放ちました。
tāñ charān samare rājan vegenāpapato bahūn|
ekaikaṃ pañcabhir bāṇaiḥ sahadevo nyakṛtantata|| // 8-14-13 //
（13）王よ、勢いよく飛んでくるその多くの矢を、サハデーヴァは一本ずつ五本の矢で撃ち落としました。
sannivārya mahābāṇān sahadevaḥ pratāpavān|
athāsmai subahūn bāṇān preṣayāmāsa saṃyuge|| // 8-14-14 //
（14）威光あるサハデーヴァは大いなる矢を防ぎ止めてから、多くの矢を戦場で相手に放ちました。
tān bāṇāṃs tava putro'pi chittvā ekaikaṃ tribhiḥ śaraiḥ|
nanāda sumahānādaṃ nādayāno vasuṃdharām|| // 8-14-15 //
（15）あなたの息子もそれらの矢を一本ずつ三本の矢で切り落とし、大地を震わせる大きな咆哮を上げました。
tato duḥśāsano rājan dvābhyāṃ pāṇḍusutaṃ raṇe|
sārathiṃ navabhir bāṇair mādreyasya samācinot|| // 8-14-16 //
（16）王よ、ドゥフシャーサナは二本の矢でパーンドゥの子を、九本の矢でマードリーの子の御者を射ちました。
tataḥ kruddho mahārāja sahadevaḥ pratāpavān|
samādhatta śaraṃ ghoraṃ mṛtyukālāntakopamam|| // 8-14-17 //
（17）大王よ、激怒した威光あるサハデーヴァは、死の時の閻魔のような恐るべき矢を番えました。
vikṛṣya balavac cāpaṃ tava putrāya so'sṛjat|
sa taṃ nirbhidya vegena bhittvā ca kavacaṃ mahat|| // 8-14-18 //
（18）力強く弓を引き絞り、あなたの息子に放ちました。その矢は勢いよくドゥフシャーサナを貫き、大きな鎧を突き破り——
prāviśad varaṇīṃ rājan valmīkam iva pannagaḥ|
tataḥ sammumuhe rājaṃs tava putro mahārathaḥ|| // 8-14-19 //
（19）王よ、蛇が蟻塚に入るように大地に入りました。すると王よ、あなたの息子は偉大な戦車戦士でありながら、もうろうとしました。
mūḍhaṃ cainaṃ samālokya sārathis tvarito ratham|
apovāha bhṛśaṃ trasto vadhyamānaṃ śitaiḥ śaraiḥ|| // 8-14-20 //
（20）朦朧としたドゥフシャーサナを見て、御者は急いで恐れおののき、鋭い矢に打たれている主を戦場から運び出しました。
parājitya raṇe taṃ tu kauravyaṃ pāṇḍunandanaḥ|
duryodhanabalaṃ dṛṣṭvā pramamātha samantataḥ|| // 8-14-21 //
（21）戦場でカウラヴヤ（ドゥフシャーサナ）を破ったパーンドゥの歓喜の子（サハデーヴァ）は、ドゥルヨーダナの軍を見据えて、四方から打ち砕きました。
pipīlikapuṭaṃ rājan yathā mṛdgan naro ruṣā|
tathā sā kauravī senā mṛditā tena bhārata|| || // 8-14-22 //
（22）王よ、人が怒って蟻の巣を踏み潰すように、バーラタよ、カウラヴァ軍はサハデーヴァに踏み潰されました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe caturdaśo'dhyāyaḥ|| 14 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十四章は終わる。
