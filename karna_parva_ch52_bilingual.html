マハーバーラタ ― カルナ篇 第52章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 52 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ52」、全68詩節からなります。ドリタラーシュトラがサンジャヤに対し、アルジュナとサンシャプタカ軍との戦い、またカルナとパーンチャーラ軍との戦いがどのように起こったかを問うところから始まります（第1〜2詩節）。アルジュナはサンシャプタカ軍の中へ、大海に突入する暴風のように突入し、獅子奮迅の働きを見せます（第3〜16詩節）。天空にはクリシュナとアルジュナを称える太鼓の音と花の雨が降り、両者はブラフマーとシヴァ、あるいはナラとナーラーヤナの如き姿に喩えられます（第17〜19詩節）。これを見たアシュヴァッターマン（ドラウニ、ドローナの子）が激怒してクリシュナとアルジュナに襲いかかり、矢を手にアルジュナに一対一の対決を挑みます（第20〜25詩節）。クリシュナはアルジュナに対決を促し、両者の激しい矢戦が展開されます（第26〜37詩節）。続く第38〜42詩節は、両資料（サンスクリット原典・和訳原典）の該当箇所が共通して欠落しているのではなく、サンスクリット原典そのものに「xxxxxxxx」という文字数分の損傷（おそらく写本の物理的損傷または読解不能箇所）が連続五詩節にわたって存在することが直接確認された、本シリーズ最大規模の損傷箇所です。憶測による補完を避ける方針に従い、損傷部分は原典の記号のまま「x」で保持しています。その後、両者の激戦は続き、クリシュナはアルジュナの武勇に一瞬の不安を覚えて問いかけ（第49〜52詩節）、アルジュナはこれに応えてドラウニの武具を次々と打ち砕きます（第53〜55詩節）。アルジュナは再びサンシャプタカ軍に矢の雨を降らせ、獅子が鹿の群れを、斧が森の木々を切り倒すように圧倒し（第56〜63詩節）、ドラウニとの一対一の対決もなお続きます（第64〜67詩節）。最後にサンシャプタカ軍が踏みとどまり、二人の偉大な魂（マハートマン）の戦いを見守る場面で本章は閉じます（第68詩節）。なお、本章でも冒頭の「ドリタラーシュトラは語った」の一文に余分な二重の注記「8-52-0」「8-52-0x」が付されていたため、これを第1詩節の本文に統合しています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51章に続き二章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、「द्व」（dva）と「द्ध」（ddha）の混同が本章では四箇所（tadyudvam→tat yuddham、yadvaddaityānāṃ→yadvat daityānāṃ、vidvvā→viddhvā、yudvātithyaṃ→yuddhātithyaṃ）に見られ、本シリーズ全体を通じて最も頻出するOCR誤記パターンであることが改めて確認されました。また「nighntam」→「nighnantam」（脱落音節の補完、文脈上必須）、「ivarṣabhāḥ」→「iva ṛṣabhāḥ」（母音連声、牛の比喩、二箇所）の修正も行っています。一方、「vākvāśarīriṇī」（第17詩節）および「tadvi」（第24詩節）の二箇所は、確実な再構成根拠が見出せなかったため、憶測を避けて未修正のまま残しています。アヴァグラハ（ऽ）で示された母音脱落形（samare'rjunaḥ、evamukto'vahat、pāṇinā''hūya等、二重アヴァグラハの箇所も原典のまま保持）は、本来の語境界規則に従い分離せず、アポストロフィ付きの融合形のまま保持しています。
karṇaparva — dvipañcāśo'dhyāyaḥ (52)
第52章
dhṛtarāṣṭra uvāca|
kathaṃ saṃśaptakaiḥ sārdham arjunasya abhavad raṇaḥ|
sūtaputrasya pāñcālaiḥ kathaṃ yuddhaṃ pravartitam|| // 8-52-1 //
ドゥリタラーシュトラは語った。 （1） サムシャプタカ族とアルジュナの戦いはどのようであったか。スータの息子とパーンチャーラ族の戦いはどう展開したか。
aśvatthāmnastu yad yuddham arjunasya ca sañjaya|
anyeṣāṃ ca madīyānāṃ pāṇḍavais tad bravīhi me|| // 8-52-2 //
（2） サンジャヤよ、アシュヴァッターマンとアルジュナの戦い、そしてわが方の他の者たちとパーンダヴァの戦いを語ってくれ。
sañjaya uvāca|
śṛṇu rājan yathāvṛttaṃ saṅgrāmaṃ bruvato mama|
vīrāṇāṃ śatrubhiḥ sārdhaṃ dehapāpmavināśanam|| // 8-52-3 //
サンジャヤは語った。 （3） 王よ、聞くがよい。敵と戦い体の罪を滅ぼした勇者たちの、あの戦いのありさまを私が語るのを。
pārthaḥ saṃśaptakabalaṃ praviśyārṇavasannibham|
vyakṣobhayad amitraghno mahāvāta iva arṇavam|| // 8-52-4 //
（4） パールタ（アルジュナ）は海のようなサムシャプタカの軍に入り込み、敵を滅ぼす者として、大風が海を掻き乱すように軍をかき乱した。
pūrṇacandrābhavakrāṇi svakṣibhrūdaśanāni ca|
śirāṃsyunmathya vīrāṇāṃ śitairbhallairdhanañjayaḥ|
santastāra kṣitiṃ kṣipraṃ vinālair nalinair iva|| // 8-52-5 //
（5） ダナンジャヤは鋭いバッラ矢で、満月のような顔、美しい眉と目と歯を持つ勇者たちの首を刈り取り、茎を切られた蓮の花のように素早く大地にばらまいた。
suvṛttānāyatānpuṣṭāṃścandanāgurubhūṣitān|
sāyudhānsatalatrāṃśca pañcāsyoragasannibhān|
bāhūnkṣurairamitrāṇāṃ ciccheda samare'rjunaḥ|| // 8-52-6 //
（6） 丸みがあり長くたくましい、栴檀と沈香で飾られた、武器と手の防具をつけた、五つの頭を持つ蛇のような敵の腕を、アルジュナは戦場で剃刀矢で切り落とした。
dhuryān dhuryotarān sūtān dhvajāṃś cāpāni sāyakān|
pāṇīn nitāntaniśitair bhallaiś ciccheda pāṇḍavaḥ|| // 8-52-7 //
（7） 轅馬、副馬、御者、旗、弓、矢、手を、パーンダヴァは極めて鋭いバッラ矢で切断した。
rathān dvipān hayāṃś ca eva sārohān arjuno yudhi|
śarair anekasāhasrair ninye rājan yamakṣayam|| // 8-52-8 //
（8） 王よ、アルジュナは戦場で戦車・象・馬を騎手もろとも、数千の矢でヤマの国へ送った。
taṃ pravīrāḥ susaṃrabdhā nardamānā iva ṛṣabhāḥ|
vāsitārtham iva kruddham abhidrutya mahotkaṭāḥ|
nighnantam abhijaghnus te śaraiḥ śṛṅgair iva ṛṣabhāḥ|| // 8-52-9 //
（9） 怒り猛り叫ぶ精鋭たちは、発情して雌を求める雄牛のように、怒り猛った大きな者が殺戮する彼に突進し、矢で雄牛が角で突くように打った。
tasya teṣāṃ ca tat yuddham abhavat romaharṣaṇam|
trailokyavijaye yadvat daityānāṃ saha vajriṇā|| // 8-52-10 //
（10） 彼と彼らの戦いは身の毛がよだつものであった。三界の征服を巡る阿修羅とインドラの戦いのごとくであった。
astraistrāṇi saṃvārya dviṣatāṃ sarvato'rjunaḥ|
iṣubhir bahubhis tūrṇaṃ viddhvā prāṇāñ jahāra saḥ|| // 8-52-11 //
（11） アルジュナは敵の武器を武器で退け、四方から多くの矢で素早く射て命を奪った。
chinnatriveṇucakrākṣān hatayodhān sasārathīn|
vidhvastāyudhatūṇīrān samunmathitaketanān|| // 8-52-12 //
（12） 轅と車輪と車軸を砕かれ、戦士と御者を倒され、武器と矢筒を打ち散らされ、旗を叩き折られた、
sañchinnayokraraśmīṣān vitriveṇūn vikūbarān|
visrastabandhurayugān visrastākṣapramaṇḍalān|| // 8-52-13 //
（13） 繋ぎ紐と手綱とくびきを断たれ、轅と車台を砕かれ、軸と車輪周りを崩された、
rathān viśakalīkurvan mahābhrāṇi iva mārutaḥ|| // 8-52-14 //
（14） そのような戦車を風が大雲を砕くようにアルジュナは粉砕した。
vismāpakaṃ prekṣakāṇāṃ dviṣatāṃ bhayavardhanam|
mahārathasahasrasya samaṃ karma akarod jayaḥ|| // 8-52-15 //
（15） 見物人を驚嘆させ敵に恐怖を増させるその働きは、千の大戦車戦士に匹敵するものであった。
siddhadevarṣisaṅghāś ca cāraṇāś ca api tuṣṭuvuḥ|| // 8-52-16 //
（16） シッダ、天の聖仙たち、チャーラナたちもこれを称えた。
devadundubhayo neduḥ puṣpavarṣāṇi ca apatan|
keśavārjunayormūrdhni prāha vākvāśarīriṇī|| // 8-52-17 //
（17） 天上の太鼓が鳴り響き、花の雨が降り注いだ。ケーシャヴァとアルジュナの頭上に、声だけの存在が語った。
candrāgnyanilasūryāṇāṃ kāntidīptibaladyutīḥ|
yau sadā bibhratur vīrāv imau tau keśavārjunau|| // 8-52-18 //
（18） 「月・火・風・太陽の美しさ・輝き・力・光をつねに備えるこの二人の勇者こそ、ケーシャヴァとアルジュナである。」
brahmeśānāv iva purā vīrāv ekarathe sthitau|
sarvabhūtavarau vīrau naranārāyaṇāv imau|| // 8-52-19 //
（19） 「かつてのブラフマーとイーシャーナのように、一台の戦車に立つ二人の勇者、一切衆生の中で最も優れた英雄、ナラとナーラーヤナがここにいる。」
ity etan mahad āścaryaṃ dṛṣṭvā śrutvā ca bhārata|
aśvatthāmā susaṅkruddhaḥ kṛṣṇāv abhyadravad raṇe|| // 8-52-20 //
（20） バーラタよ、この大いなる奇跡を見聞きして、アシュヴァッターマンは激怒し、戦場でクリシュナとアルジュナに突進した。
atha pāṇḍavam asyantam amitrāntakarāñ charān|
seṣuṇā pāṇinā''hūya prahasan drauṇir abravīt|| // 8-52-21 //
（21） 敵を滅ぼす矢を放つパーンダヴァを、矢を手にした弓手として呼び止め、微笑みながらドラウニは語った。
yadi māṃ manyase vīra prāptamarhamihātithim|
tataḥ sarvātmanā tu adya yuddhātithyaṃ prayaccha me|| // 8-52-22 //
（22） 「もし勇者よ、ここに至った私を客にふさわしいと思うなら、今日すべてをかけて私に戦いのもてなしをしてくれ。」
evamācāryaputreṇa samāhūto yuyutsayā|
bahumene'rjuno''tmānam iti ca āha janārdanam|| // 8-52-23 //
（23） 師の息子にこのように戦いの申し込みを受け、アルジュナは自分が敬われたと思い、ジャナールダナ（クリシュナ）にこう語った。
saṃśaptakāś ca me vadhyā drauṇir āhvayate ca mām|
yad atra anantaraṃ prāptaṃ śaṃsa me tadvi mādhava|| // 8-52-24 //
（24） 「サムシャプタカ族は私が倒さねばならぬし、ドラウニも私を呼んでいる。マーダヴァよ、ここで次にすべきことを教えてくれ。」
ātithyakarmābhyutthāya dīyatāṃ yadi manyase|
evam ukto'vahat pārthaṃ kṛṣṇo droṇātmajāntike|| // 8-52-25 //
（25） 「客へのもてなしを立ち上がって行うべきだと思われるなら、そのようにせよ。」こう言われてクリシュナはパールタをドローナの息子の近くに運んだ。
śaikṣyeṇa vidhinā''hūtaṃ vāyur indram iva adhvare|
tam āmantrya ekamanasaṃ keśavo drauṇim abravīt|| // 8-52-26 //
（26） 祭りの作法で招かれた者を、風がインドラを祭壇に運ぶように。ケーシャヴァは集中するドラウニに語った。
aśvatthāman sthiro bhūtvā prahara āśu sahasva ca|
nirveṣṭuṃ bhartṛpiṇḍaṃ hi kālo'yam upajīvinām|| // 8-52-27 //
（27） 「アシュヴァッターマンよ、しっかりと立ち、打ち、また打たれよ。主君の食を食む者にとって、その恩を返すべき時が今だ。」
sūkṣmo vivādo viprāṇāṃ sūkṣmau kṣāstrau jayājayau|| // 8-52-28 //
（28） 「バラモンの論争は微妙であり、勝敗もまた微妙なものだ。」
na hi saṃkṣamase mohād divyāṃ pārthasya satkriyām|
samāptim icchan yudhyasva sthiro bhūtvā'dya pāṇḍavaṃ|| // 8-52-29 //
（29） 「汝は愚かにも、パールタの神聖なる武勇の前に立つことを耐えられまい。決着をつけたいなら、覚悟を決めて今日パーンダヴァと戦え。」
ity ukto vāsudevena tathā ity uktvā dvijottamaḥ|
vivyādha keśavaṃ ṣaṣṭyā nārācair arjunaṃ tribhiḥ|| // 8-52-30 //
（30） ヴァースデーヴァにこう言われて、ドヴィジャの最良者（アシュヴァッターマン）は「然り」と応え、ケーシャヴァを六十本の鉄矢で、アルジュナを三本で射た。
tasya arjunaḥ susaṅkruddhas tribhir bāṇaiḥ śarāsanam|
ciccheda atha anyad ādatta drauṇir ghorataraṃ dhanuḥ|| // 8-52-31 //
（31） 激怒したアルジュナは三本の矢で彼の弓弦を断った。するとドラウニはより恐ろしい別の弓を取った。
sajyaṃ kṛtvā nimeṣāt ca vivyādha arjunakeśavau|
tribhiḥ śatair vāsudevaṃ sahasreṇa ca pāṇḍavam|| // 8-52-32 //
（32） 瞬く間に弦を張り、ヴァースデーヴァを三百本の矢で、パーンダヴァを千本の矢で射た。
tataḥ śarasahasrāṇi prayutānyarbudāni ca|
sasṛje drauṇir āyastaḥ stambhayāmāsa ca arjunam|| // 8-52-33 //
（33） ドラウニは数千、数万、数億の矢を放ち、力を込めてアルジュナの動きを封じた。
iṣudher dhanuṣo jyāyās tv aṅgulibhyaś ca māriṣa|
bāhvoḥ karābhyām uraso vadanād vrāṇanetrataḥ|| // 8-52-34 //
（34） 親愛なる者よ、矢筒から、弓から、弦から、指から、両腕から、手から、胸から、顔から、傷口から、目から、
karṇābhyāṃ śiraso'ṅgebhyo lomavarmabhya eva ca|
rathadhvajābhyāṃ ca śarā niṣpetur brahmavādinaḥ|| // 8-52-35 //
（35） 両耳から、頭から、体の各部から、毛と鎧からまで、ブラフマーの言葉を語るこの者の矢が飛び出した。
śarajālena mahatā baddhvā mādhavapāṇḍavau|
nanāda sudito drauṇir mahāmeghaughaniḥsvanam|| // 8-52-36 //
（36） 大いなる矢の網でマーダヴァとパーンダヴァを縛り上げ、ドラウニは歓喜して大雷雲のような声で叫んだ。
taiḥ patadbhir mahārāja drauṇimuktaiḥ samantataḥ|
sañchāditau rathasthau tāv ubhau kṛṣṇadhanañjayau|| // 8-52-37 //
（37） 大王よ、ドラウニが四方から放つ矢が降り注ぎ、戦車に立つクリシュナとダナンジャヤの二人は覆い隠された。
dataḥ śaraxxxxxxkṣṇair bhāradvājaḥ pratāpavān|
nixxxxxcakre rathe mādhavapāṇḍavau|| // 8-52-38 //
（38） バーラドヴァージャの息子の勇者は鋭い矢で、戦車上のマーダヴァとパーンダヴァを見えなくした。
xxxxjaṅgamaṃ sthāvaraṃ tathā|
carācarasā moptārau dṛṣṭvā sañchāditau śaraiḥ|| // 8-52-39 //
（39） 動くものも動かぬものも包含する二人が矢で覆われたのを見て、
siddhacāraxxxxxś ca saṃpeturśai samantataḥ|
api xxxxxxxx lokānām iti ca abruvan|| // 8-52-40 //
（40） シッダやチャーラナたちが四方から集まり、「この二人は世界のすべての守護者であるのに」と語った。
na mayā xxxxxxxxxx rājan dṛṣṭapṛrvaḥ parākamaḥ|
xxxxxxxxxxxx kṛṣṇo chādayato raṇe|| // 8-52-41 //
（41） 「王よ、戦場でクリシュナをも覆い隠すこのような武勇を見たことがない。」
xxxxxxxxxxxśabdaṃ rathānāṃ trāsanaṃ raṇe|
xxxxxxxxxx rājan siṃhasya nadato yathā|| // 8-52-42 //
（42） 「戦車の恐ろしい音と、王よ、戦場で吼えるライオンのような彼の声が、
carato yuddhe savyaṃ dakṣiṇam asyataḥ|
vidyud ambhodharasya iva bhrājamānā vyadṛśyata|| // 8-52-43 //
（43） 戦いで左右に動き回り矢を放つその姿は、稲妻の雲のように輝いて見えた。」
sa tadā kṣiprakārī ca dṛḍhahastaś ca pāṇḍavaḥ|
pramohaṃ paramaṃ gatvā prekṣann āste dhanañjayaḥ|| // 8-52-44 //
（44） 素早く行動し手の確かなパーンダヴァは、極度の驚愕に至り、ダナンジャヤは見つめるのみであった。
vikramaṃ carato yuddhe savyaṃ dakṣiṇam asyataḥ|
vikramaṃ ca hṛtaṃ mene ātmanas tena saṃyuge|| // 8-52-45 //
（45） 戦場で左右に動き射る彼の武勇を見て、アルジュナは自分の武勇が彼に奪われたと感じた。
atha asya samare rājan vapur āsīt sudurdṛśam|
drauṇes tat kurvataḥ karma yādṛgrūpaṃ pinākinaḥ|| // 8-52-46 //
（46） 王よ、このような働きをするドラウニの戦場での姿は、ピナーカを持つ者（シヴァ）のごとくで見つめがたかった。
vardhamāne tatas tatra droṇaputre viśāmpate|
hīyamāne ca kaunteye kṛṣṇaṃ roṣaḥ samāviśat|| // 8-52-47 //
（47） ドローナの息子が勢いを増しクンティーの息子が押されるのを見て、クリシュナは怒りに駆られた。
sa roṣān niśvasan rājan nirdahan iva cakṣuṣā|
drauṇiṃ dadarśa saṅgrāme phalgunaṃ ca muhurmuhuḥ|| // 8-52-48 //
（48） 王よ、怒りで荒く息をし、目で焼き尽くすかのように、クリシュナは戦場でドラウニとパルグナを交互に見やった。
tataḥ kṛṣṇo'bravīt kruddhaḥ pārthaṃ sapraṇayaṃ vacaḥ|| // 8-52-49 //
（49） 怒ったクリシュナは、親しみを込めてパールタにこう語った。
atyadbhutatam idaṃ pārtha tvayi paśyāmi saṃyuge|
yat tvāṃ viśeṣayati ājau droṇaputro'dya bhārata|| // 8-52-50 //
（50） 「パールタよ、戦場で汝に極めて驚くべきことを見る。バーラタよ、今日の戦いでドローナの息子が汝を上回っている。
kaccit te gāṇḍivaṃ haste muṣṭir vā na vyaśīryata|
kaccid vīryaṃ yathāpūrvaṃ bhujayor vā balaṃ tava|| // 8-52-51 //
（51） まさかガーンディーヴァは手から滑り、握力が衰えたのではあるまいな。まさか勇気も以前のまま、両腕の力も健在であろうな。
udīryamāṇaṃ hi raṇe paśyāmi drauṇim āhave|
guruputra iti hi enaṃ mānayan pāṇḍavarṣabha|
upekṣāṃ mā kṛthāḥ pārtha nāyaṃ kāla upekṣitum'|| // 8-52-52 //
（52） 戦場でドラウニが勢いを増しているのが見える。パーンダヴァの雄牛よ、師の息子だからと敬って手加減するな。パールタよ、今は手加減する時ではない。」
arjuna uvāca|
paśya mādhava daurātmyaṃ guruputrasya māṃ prati|
vadhaṃ prāptau manyate nau prāveśya śavareśmani|
eṣa asmi hanmi saṅkalpaṃ śikṣayā ca balena ca|| // 8-52-53 //
アルジュナは語った。 （53） 「マーダヴァよ、見よ、師の息子の私に対する大胆不敵さを。我ら二人が矢の檻に入れられ殺されると思っている。今ここに、技と力で彼の思惑を打ち砕こう。」
evam uktvā asya ciccheda bhallaiḥ karmāramārjitaiḥ|
dhanuśchatraṃ patākāṃ ca rathaśaktiṃ gadāṃ varām'|| // 8-52-54 //
（54） こう言って、鍛冶の磨いたバッラ矢で彼の弓、日傘、旗、戦車の槍、優れた棍棒を切り落とした。
aśvatthāmnaḥ śarān astāñ chittvā ekaikaṃ tridhā tridhā|
vyadhamad bharataśreṣṭho nīhāram iva mārutaḥ|| // 8-52-55 //
（55） アシュヴァッターマンの放った矢を一本ずつ三つに断ち切り、バーラタ族の最良者は霧を払う風のようにそれらを打ち散らした。
tataḥ saṃśaptakān bhūyaḥ sāśvasūtarathadvipān|
dhvajapattigaṇān urgrair bāṇair vivyādha pāṇḍavaḥ|| // 8-52-56 //
（56） そしてパーンダヴァは再びサムシャプタカ族を馬・御者・戦車・象もろとも、旗を持つ歩兵たちを、猛烈な矢で射抜いた。
ye ye dadṛśire tatra yad yad rūpās tadā janāḥ|
te te tatra śarair vyāptaṃ menire''tmānam ātmanā|| // 8-52-57 //
（57） そのとき見ていた者たちは、どこにいるどのような姿の者であっても、矢が自分自身に向かって来ていると感じた。
te gāṇḍīvapramuktās tu nānārūpāḥ patatriṇaḥ|
krośe sāgre sthitāñ jaghnur dvipāṃś ca puruṣān raṇe|| // 8-52-58 //
（58） ガーンディーヴァから放たれた様々な形の矢は、一クローシャ以上の先にいる象と人間を倒した。
bhallaiś chinnāḥ karāḥ petuḥ kariṇāṃ madavarṣiṇām|
yathā vane paraśubhir nikṛttāḥ śālmalidrumāḥ|| // 8-52-59 //
（59） 蜜を滴らす象の切られた鼻は、森でおので切られたシャールマリ樹のようにバッラ矢で落ちた。
paścāt tu śailavat patus te gajāḥ saha sādibhiḥ|
vajrivajrāvamathitā yathaiva adricayās tathā|| // 8-52-60 //
（60） それから象たちは騎手ごと山のように後ろに倒れた。インドラの雷に砕かれた山脈のように。
gandharvanagarākārān rathāṃś caiva sukalpitān|
vinītair javanair yuktān āsthitān yudvadurmadaiḥ|| // 8-52-61 //
（61） 蜃気楼の都市のような、美しく装備され、躾けられた速い馬を駆る、戦いに狂った者たちが乗る戦車を、
śarair viśakalīkurvann amitrān abhyavīvṛṣat|
svalaṅkṛtān aśvasādīn pattīṃś ca ahan dhanañjayaḥ|| // 8-52-62 //
（62） 矢で粉砕しながら敵を攻め、美しく飾られた騎兵や歩兵をダナンジャヤは倒した。
dhanañjayayugāntārkaḥ saṃśaptakamahārṇavam|
vyaśoṣayata duḥśoṣaṃ tīkṣṇaiḥ śaragabhastibhiḥ|| // 8-52-63 //
（63） ダナンジャヤは終末の太陽となり、サムシャプタカの大海を干上がらせがたいものを鋭い矢の光線で干上がらせた。
punar drauṇimahāśailaṃ nārācair vajrasannibhaiḥ|
nirbibheda mahāvegais tvaran vajrī iva parvatam|| // 8-52-64 //
（64） 再びドラウニの大山を雷のような鉄矢で猛スピードで打ち砕いた。インドラが雷で山を砕くように。
tam ācāryasutaḥ kruddhaḥ sāśvayantāram āśugaiḥ|
yuyutsur āgamad yoddhuṃ pārthas tān acchinac charān|| // 8-52-65 //
（65） 怒った師の息子は馬と御者もろとも速射の矢で戦おうとしたが、パールタはそれらの矢を断ち切った。
tataḥ paramasaṅkruddhaḥ kāṇḍakośam avāsṛjat|
aśvatthāmā abhirūpāya gṛhān atithaye yathā|| // 8-52-66 //
（66） 極めて激怒して、アシュヴァッターマンは矢筒の全てを放った。客のために用意した家のごとく。
atha saṃśaptakāṃs tyaktvā pāṇḍavo drauṇim abhyayāt|
apāṅkteyān iva tyaktvā dātā pāṅkteyam arthinam|| // 8-52-67 //
（67） そしてサムシャプタカ族を離れ、パーンダヴァはドラウニに向かった。祭りに列に加わる資格のない者を離れ、施し手が列に加わる資格のある求道者に向かうように。
sthitāḥ saṃśaptakā rājan dṛṣṭvā yuddhaṃ mahātmanoḥ|| || // 8-52-68 //
（68） 王よ、サムシャプタカ族は二人の偉大な魂の戦いを見て立ち止まった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe dvipañcāśo'dhyāyaḥ|| 52 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十二章は終わる。
