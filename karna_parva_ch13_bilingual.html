本章は南伝（Southern Recension）テキストの「アディヤーヤ13」（シャリヤがシュルタキールティを破る場面。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-13-N）と和訳の段落番号が対応しています。
karṇaparva — trayodaśo'dhyāyaḥ (13)
第13章　シャリヤがシュルタキールティを破る
sañjaya uvāca|
śrutakīrtim athāyāntaṃ kirantaṃ niśitāñśarān|
madrarājo mahārāja vārayāmāsa hṛṣṭavat|| // 8-13-1 //
サンジャヤは語った。 （1）大王よ、鋭い矢を放ちながら進んでくるシュルタキールティを、マドラ王（シャリヤ）が喜んで迎え撃ちました。
madrarājaṃ samāsādya śrutakīrtir mahārathaḥ|
vivyādha bhallair viśatyā kārtasvaravibhūṣitaiḥ|| // 8-13-2 //
（2）マドラ王のもとに至った偉大な戦車戦士シュルタキールティは、黄金で飾られた二十本の矢尻の矢で彼を射ちました。
prativivyādha taṃ śalyaṃ tribhis tūrṇam ajihmagaiḥ|
sārathiṃ cāsya bhallena bhṛśaṃ vivyādha bhārata|| // 8-13-3 //
（3）シャリヤも三本のまっすぐな矢で素早くシュルタキールティを射返し、バーラタよ、矢尻の矢で彼の御者を激しく射ちました。
sa śalyaṃ śaravarṣeṇa cchādayāmāsa saṃyuge|
mumoca niśitān bāṇān madrarājarathaṃ prati|| // 8-13-4 //
（4）シュルタキールティは矢の雨で戦場のシャリヤを覆い、マドラ王の戦車に向けて鋭い矢を放ちました。
tataḥ śalyo mahārāja śrutakīrtibhujacyutān|
ciccheda samare bāṇāsan bāṇaiḥ sannataparvabhiḥ|| // 8-13-5 //
（5）大王よ、シャリヤはシュルタキールティの腕から放たれた矢を、しなやかな矢で戦場において切り落としました。
śrutakīrtis tataḥ śalyaṃ bhittvā navabhir āyasaiḥ|
sārathiṃ tribhir ānarcchat punaḥ śalyaṃ ca pañcabhiḥ|| // 8-13-6 //
（6）シュルタキールティは九本の鉄の矢でシャリヤを射抜き、三本で御者を射ち、さらに五本でシャリヤを射ちました。
tasya śalyo dhanuś chittvā hastāvāpaṃ nikṛtya ca|
vivyādha samare tūrṇaṃ saptabhis taṃ śarottamaiḥ|| // 8-13-7 //
（7）シャリヤはシュルタキールティの弓を断ち切り、手の防具も切り落とし、七本の最上の矢で素早く戦場で射ちました。
athānyad dhanurādāya śrutakīrtir mahārathaḥ|
bhadreśvaraṃ catuḥṣaṣṭyā bāhvor urasi cārpayat|| // 8-13-8 //
（8）偉大な戦車戦士シュルタキールティは別の弓を取り、マドラの王を六十四本の矢で両腕と胸に射ち込みました。
tatas tu samare rājaṃs tena vidvaḥ śilīmukhaiḥ|
xx vivyādha taṃ cāpi navatyā niśitaiḥ śaraiḥ|| // 8-13-9 //
（9）王よ、その矢に射抜かれたシャリヤは、九十本の鋭い矢でシュルタキールティを射返しました。
tasya madreśvaraś cāpaṃ punaś ciccheda māriṣa|
sa cchinnadhanvā samare gadāṃ cikṣepa satvaraḥ|| // 8-13-10 //
（10）マドラの王はシュルタキールティの弓を再び断ち切りました。弓を断たれた彼は素早く棍棒を投げつけました。
paṭṭair jāmbūnadair baddhāṃ rupyapaṭṭaiś ca bhārata|
bhrājamānāṃ yathā nārīṃ divyavastravibhūṣitām|| // 8-13-11 //
（11）バーラタよ、金と銀の帯で巻かれたその棍棒は、神聖な衣をまとった輝く女のようでした。
tāmāpatantīṃ sahasā dīpyamānāśaniprabhām|
śarair anekasāhasrair vyaṣṭambhayata madrarāṭ|| // 8-13-12 //
（12）突然飛んでくる、燃える稲妻のように輝くその棍棒を、マドラ王は何千もの矢で空中で食い止めました。
viṣṭabhya ca gadāṃ vīraḥ pātayitvā ca bhūtale|
śrutakīrtim athāyatto rājan vivyādha pañcabhiḥ|| // 8-13-13 //
（13）棍棒を止め、大地に落として、勇者シャリヤは身構えたシュルタキールティを五本の矢で射ちました。
tasya śaktiṃ raṇe bhūyaś cikṣepa bhujopamām|
tāṃ dvidhā cāchinacchalyo medinyāṃ sā tv aśīryata|| // 8-13-14 //
（14）シュルタキールティは再び腕のような大きさの槍を投げましたが、シャリヤはそれを真っ二つに切り、大地に砕け散らせました。
tasya śalyaḥ kṣurapreṇa yantuḥ kāyācchiro'harat|
bālahastād yathā śyena āmiṣaṃ vai narottama|| // 8-13-15 //
（15）シャリヤは鋭い剃刀のような矢で、シュルタキールティの御者の首を体から切り落としました。鷹が子供の手から肉を奪い取るように、最上の人よ。
sa papāta rathopasthāt sārathis tasya bhārata|
tatas te prādravan saṅkhye hayās tasya mahātmanaḥ|| // 8-13-16 //
（16）バーラタよ、御者は戦車の上から崩れ落ちました。そして偉大なる魂の者の馬たちは戦場を逃げ走りました。
palāyamānaistairaśvaiḥ sopanīto raṇājirāt|
śrutakīrtir mahārāja paśyatāṃ sarvayodhinām|| // 8-13-17 //
（17）大王よ、逃げる馬たちに引かれて、シュルタキールティは全戦士の見守る中、戦場から運び出されました。
tato madreśvaro rājā pāṇḍavānām anīkinīm|
vyagāhata mudā yukto nalinīṃ dvirado yathā|| // 8-13-18 //
（18）そしてマドラの王は、喜びに満ちて、パーンダヴァの軍に突入しました。雄象が蓮池に入るように。
lolayāmāsa sa balaṃ siṃhaḥ paśugaṇān iva|
śalyas tatra mahāraṅge pāṇḍavānāṃ mahātmanām|| // 8-13-19 //
（19）シャリヤは大きな闘技場で、パーンダヴァたちの偉大なる魂の者たちの軍を蹂躙しました。獅子が家畜の群れを蹂躙するように。
nipātya pāṇḍupāñcālān pṛtanāsu vyavasthitaḥ|
aśobhata raṇe śalyo vidhūmo'gnir iva jvalan|| // 8-13-20 //
（20）パーンドゥとパーンチャーラの軍を打ち倒し、軍の中に立つシャリヤは、煙のない燃え上がる炎のように戦場で輝きました。
senākakṣaṃ mahad dagdhvā kakṣam agnir iva utthitaḥ|
sthito rarāja samare puraṃ dagdhvā iva śaṅkaraḥ|| || // 8-13-21 //
（21）軍という大きな茂みを焼き尽くし、燃え上がった火のように立ち、戦場で輝きました。まるで都市を焼いたシャンカラ（シヴァ）のように。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe trayodaśo'dhyāyaḥ|| 13 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十三章は終わる。
