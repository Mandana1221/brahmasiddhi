マハーバーラタ ― カルナ篇 第54章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 54 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ54」、全25詩節からなる、アルジュナによるダンダおよびダンダダーラ（マガダ族の二人の象兵）の殺害を描く章です。サンジャヤが語る形で、パーンドゥ軍の北方でダンダダーラによって戦車・象・馬・歩兵が倒される轟音が響くところから始まり、クリシュナがアルジュナにダンダダーラへの応戦を促します（第1〜4詩節）。アルジュナは最上の象に乗ったダンダダーラと一対一の対決を繰り広げ、矢でその弓・旗・腕・首を次々と切り落とし、ついに討ち果たします（第5〜19詩節）。続いてダンダダーラに匹敵する他の象たちも同じ運命をたどり、敵の大軍は崩壊します（第20〜22詩節）。味方の兵士たちはアルジュナを神々がプランダラ（インドラ）を讃えるように称え、アルジュナは礼を尽くしたのち再びサムシャプタカの群れを討ちに向かう場面で本章は閉じます（第23〜25詩節）。なお、本章でも冒頭の「サンジャヤは語った」の一文に余分な二重の注記「8-54-0」「8-54-0x」が付されていたため、これを第1詩節の本文に統合しています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜53章に続き四章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、第10詩節の「दण़्ड」（daṇḍa「ダンダ」の語幹に余分な濁点記号が紛れ込んだもの）を、本章で繰り返し登場する固有名「daṇḍadhāra」との照合により「daṇḍa」に修正し、また同詩節の三重ハイフン「---」（通常の行末ハイフン記号の重複）も他章の単一・二重ハイフンの用例に基づき除去しています。第15詩節では、詩節中間に二つの単一ダンダ（句切り符号）の代わりに二重ダンダ（॥）が用いられている箇所がありますが、これは脱落や誤記ではなく原典の韻律構成（トリシュトゥブ調）に基づくものと判断し、そのまま保持しています。第25詩節の「itīva」（iti+iva）は、標準の分離規則に従い「iti iva」として分離しています。
karṇaparva — catuḥpañcāśo'dhyāyaḥ (54)
第54章
sañjaya uvāca|
atha uttareṇa pāṇḍūnāṃ senāyāṃ dhvanir utthitaḥ|
rathanāgāśvapattīnāṃ daṇḍadhāreṇa vadhyatām|| // 8-54-1 //
サンジャヤは語った。 （1） パーンドゥ軍の北方で、ダンダダーラによって戦車・象・馬・歩兵が倒される轟音が響き渡った。
nivartayitvā tu rathaṃ keśavo'rjunam abravīt|
vāhayan eva turagān garuḍānilaraṃhasaḥ|| // 8-54-2 //
（2） 戦車を引き返させてケーシャヴァはアルジュナに語った。ガルダと風のように速い馬を走らせながら。
māgadho'sāv atikrānto dviradena pramāthinā|
bhagadattād anavamaḥ śikṣayā ca balena ca|| // 8-54-3 //
（3） 「あのマガダの者が破壊的な象で突破した。技と力においてバガダッタに劣らぬ者だ。」
enaṃ hatvā nihantā'si punaḥ saṃśaptakān iti|
vākyānte prāpayat pārthaṃ daṇḍadhāragajaṃ prati|| // 8-54-4 //
（4） 「この者を倒せば、再びサムシャプタカ族を倒せる」と。この言葉の終わりにクリシュナはパールタをダンダダーラの象の前に運んだ。
sa māgadhānāṃ pravaro mahābalo'śubhagraho yodhagaṇaiḥ samanvitaḥ|
sapatnasenāṃ pramamātha dāruṇo bhīmaṃ samagrāṃ balavān iva graham|| // 8-54-5 //
（5） マガダ族の最良者にして大力のこの者は、不吉な惑星のごとく、戦士たちに囲まれ、猛々しく敵の全軍を粉砕した。強い惑星が全軍を圧倒するかのように。
sukalpitaṃ dānavanāgasannibhaṃ mahābhranirhādasamasvanaṃ raṇe|
samāsthito nāgavaraṃ nareśvaro rathāśvamātaṅganarapramāthinam|| // 8-54-6 //
（6） この王は最上の象に乗っていた。阿修羅の象に匹敵し、大雷雲のような唸りを上げ、戦車・馬・象・人間を蹂躙するその象に。
sa nāgayantṝn samare mahārathān sapattisaṅghāṃs turagān sasādinaḥ|
dvipāṃś ca bāṇair nijaghāna vīryavān samantato ghnan iva kālacakravat|| // 8-54-7 //
（7） 彼は勇猛にも、象使い、大戦車戦士、歩兵の軍団、騎手つきの馬、象を矢でことごとく倒した。死の車輪が回るように四方を打ち。
narāṃs tu kāṃsyāyasavarmabhūṣaṇān nipātya sāśvān api pattibhiḥ saha|
vyapothayad dantivareṇa śuṣmiṇā saśabdavat sthūlanalaṃ yathā tathā|| // 8-54-8 //
（8） 鎧と甲冑で飾られた人間を、馬もろとも歩兵ごと打ち倒し、猛り狂う象で踏み潰した。太い中空の葦を踏み潰すように。
atha arjuno jyātalaneminiḥsvane mṛdaṅgabherībahuśaṅkhanādite|
rathāśvamātaṅgasahasranādite rathottamena abhyapatad dvipottamam|| // 8-54-9 //
（9） 弓弦と車輪と太鼓と法螺貝と多くの楽器の音が響き、戦車・馬・象・数千の声が轟く中、アルジュナは最上の戦車で最上の象に向かった。
tato'rjunaṃ dvādaśabhiḥ śarottamair janārdanaṃ ṣoḍaśabhiḥ samārpayat|
sa daṇḍadhāras turagāṃs tribhis tribhis tato nanāda prajahāsa ca asakṛt|| // 8-54-10 //
（10） ダンダダーラはアルジュナを十二本の最上の矢で、ジャナールダナを十六本で射て、馬をそれぞれ三本ずつで打ち、叫び声を上げて何度も笑った。
tato'sya pārthaḥ saguṇeṣukārmukaṃ cakarta bhallair dhvajam api alaṅkṛtam|
punar niyantṝn sahapādagoptṛbhis tataḥ sa cukrodha girivrajeśvaraḥ|| // 8-54-11 //
（11） パールタはバッラ矢で弓弦と矢つきの弓を断ち、飾りある旗をも切り落とし、さらに御者と足回りの護衛をも倒した。するとギリヴラジャの王は激怒した。
tato'rjunaṃ bhinnakaṭena dantinā ghanāghanena anilatulyaraṃhasā|
atīva cukrodhayiṣur janārdanaṃ ghanañjayaṃ ca abhijaghāna tomaraiḥ|| // 8-54-12 //
（12） 裂けた額から汁を垂らし、風のように速い象で、ジャナールダナとダナンジャヤを激怒させんと、トマラ（投槍）で打ちかかった。
atha asya bāhū dvipahastasannibhau śiraś ca pūrṇendunibhānanaṃ tribhiḥ|
kṣuraiḥ praciccheda sahaiva pāṇḍavas tato dvipaṃ bāṇaśataiḥ samarpayat|| // 8-54-13 //
（13） パーンダヴァは同時に三本の剃刀矢で、象の鼻のような両腕と、満月のような顔の首を切り落とし、さらに数百の矢で象を射た。
sa pārthabāṇaistapanīyabhūṣaṇaiḥ samāvṛtaḥ kāñcanavarmabhṛddvipaḥ|
bhṛśaṃ cakāśe niśi parvato yathā dāvāgninā prajvalitauṣadhidrumaḥ|| // 8-54-14 //
（14） パールタの黄金の矢に覆われた黄金の鎧を着けたその象は、夜に燃え盛る薬草と樹木の山火事に燃える山のように輝いた。
sa vedanārto'mbudanisvano nadaṃś caran bhraman prassvalitāntaro'dravat|
papāta rugṇaḥ saniyantṛkas tathā||
yathā girir vajravidāritas tathā|| // 8-54-15 //
（15） 苦痛に叫び、雷雲のような声で鳴き、走り回り揺れ動き、つまずきながら走り、御者もろとも砕けて倒れた。雷に割られた山のように。
himāvadānena suvarṇamālinā himādrikūṭapratimena dantinā|
hate raṇe bhrātari daṇḍa āvrajaj jighāṃsur indrāvarajaṃ dhanañjayam|| // 8-54-16 //
（16） 雪のような顔の黄金の首飾りを着けた、ヒマラヤの峰のような象に乗った兄が戦場で殺されると、ダンダはインドラの弟（クリシュナ）に仕えるダナンジャヤを殺さんとして突進した。
satomarair arkaraprabhais tribhir janārdanaṃ pañcabhir arjunaṃ śitaiḥ|
samarpayitvā vinanāda ca ardayaṃs tato'sya bāhū nicakarta pāṇḍavaḥ|| // 8-54-17 //
（17） 太陽のように輝く三本のトマラでジャナールダナを、五本の鋭い矢でアルジュナを射て叫んだが、パーンダヴァは彼の両腕を切り落とした。
kṣuraprakṛttau vipulau satomarau śubhāṅgadau candanarūṣitau bhujau|
gajāt patantau yugapad virejatur yathā uragau parvataśṛṅgavan mahīm|| // 8-54-18 //
（18） 剃刀矢で切られた太くトマラを握った栴檀香を塗り美しい腕輪のある二本の腕は、象から落ちながら、二匹の蛇が山の峰から地面に落ちるように同時に輝いた。
atha ardhacandreṇa hataṃ kirīṭinā papāta daṇḍasya śiraḥ kṣitiṃ dvipāt|
sa śoṇitārdro nipatan vireje divākaro'stād iva paścimāṃ diśam|| // 8-54-19 //
（19） キリーティンの半月矢で切り落とされたダンダの首は象から大地に落ちた。血に濡れたその落ちる姿は、夕暮れ時に太陽が西の山に沈むかのように輝いた。
atha dvipaṃ śvetanagāgrasannibhaṃ divākarāṃśupratimaiḥ śarottamaiḥ|
bibheda pārthaḥ sa papāta nādayan himādrikūṭaṃ kuliśāhataṃ yathā|| // 8-54-20 //
（20） 白い山の頂のような、太陽の光のような最上の矢で、パールタがその象を射ると、象は叫び声を上げて倒れた。雷に打たれたヒマラヤの峰のように。
tato'paraṃ tatpratimā gajottamā jigīṣavaḥ saṃyati savyasācinā|
tathā kṛtās te'pi yathaiva tau dvipau tataḥ prabhagnaṃ sumahad ripor balam|| // 8-54-21 //
（21） それに匹敵する他の優れた象たちも、サヴィヤサーチン（アルジュナ）との戦いで勝利を求めて来たが、あの二頭の象と同じ運命となった。それにより敵の大軍は崩壊した。
gajā rathāśvāḥ puruṣāś ca saṅghaśaḥ parasparaghnāḥ paripetur āhave|
parasparaṃ praskhalitāḥ samāhatā bhṛśaṃ ca tattad bahubhāṣiṇo hatāḥ|| // 8-54-22 //
（22） 象・戦車・馬・人間が集団で互いに殺し合い、戦場に倒れた。つまずき合い、打ち合い、互いに多くの言葉を叫びながら倒された。
atha arjunaṃ sve parivārya sainikāḥ purandaraṃ devagaṇā iva abruvan|
abhaiṣma yasmān maraṇād iva prajāḥ sa vīra diṣṭyā nihatas tvayā ripuḥ|| // 8-54-23 //
（23） 味方の兵士たちはアルジュナを取り囲み、プランダラ（インドラ）を神々が讃えるように語った。「我々が死に怯えたその敵を、勇者よ、幸いにも汝が倒してくれた。
na cet paritrāsyad imāñ janān bhayād dviṣadbhir evaṃ balibhiḥ prapīḍitān|
tathā'bhaviṣyad dviṣatāṃ pramodanaṃ yathā hateṣv eṣv iha no'risūdana|| // 8-54-24 //
（24） もし汝がこの恐怖から人々を救わず、強大な敵に苦しめられたままであったなら、我らが倒された時のように敵に喜びを与えることになっただろう。」
iti iva bhūyaś ca suhṛdbhir īḍitā niśamya vācaḥ sumanās tadā'rjunaḥ|
yathā anurūpaṃ pratipūjya taṃ janaṃ jagāma saṃśaptakasaṅghahā punaḥ|| || // 8-54-25 //
（25） このように友人たちに繰り返し称えられ、その言葉を聞いて心喜んだアルジュナは、その人々に礼を尽くし、再びサムシャプタカの群れを倒しに向かった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe catuḥpañcāśo'dhyāyaḥ|| 54 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十四章は終わる。
