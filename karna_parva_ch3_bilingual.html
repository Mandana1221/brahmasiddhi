マハーバーラタ ― カルナ篇 第3章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 3 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ3」（ドリタラーシュトラがサンジャヤに敵側（パーンダヴァ側）の戦死者の名を問い、サンジャヤがドローナによって倒された者たちの名を列挙する章）です。各段落は原典の詩節番号（8-3-N）と和訳の段落番号が対応しています。
karṇaparva — tṛtīyo'dhyāyaḥ (3)
カルナ篇 ― 第3章　敵側（パーンダヴァ側）の戦死者の名
dhṛtarāṣṭra uvāca|
ākhyātā māmakāstāta nihatā yudhi pāṇḍavaiḥ|
hatāṃś ca pāṇḍaveyānāṃ māmakair brūhi sañjaya|| // 8-3-1 //
ドリタラーシュトラは語った。
（1）「友よ、我が軍でパーンダヴァに殺された者たちは告げられた。パーンダヴァ軍で我が者たちに殺された者たちも語ってくれ、サンジャヤよ。」
sañjaya uvāca|
kṛtino yudhi vikrāntā mahāsatvā mahābalāḥ|
sānubandhāḥ sahāmātyā gāṅgeyena nipātitāḥ||
nārāyaṇā vallavāś ca rāmāśca śataśo pare|
anuraktāś ca vīreṇa bhīṣmeṇa yudhi pātitāḥ|| // 8-3-2-3 //
サンジャヤは語った。
（2〜3）「勇猛にして偉大な力と大いなる武勇を持ち、追従者とともに家臣とともに、ガーンゲーヤ（ビーシュマ）に倒された者たち——ナーラーヤナ族、ヴァッラヴァ族、ラーマ族ら何百もの者が、勇者ビーシュマに忠誠を持って戦場で倒されました。
samaḥ kirīṭinā saṅkhye vīryeṇa ca balena ca|
satyajit satyasandhena droṇena nihato yudhi|| // 8-3-4 //
（4）戦場でアルジュナに武勇と力で等しかったサティヤジットは、真実の誓いを持つドローナに殺されました。
pāñcālānāṃ maheṣvāsāḥ sarve yudvaviśāradāḥ|
droṇena saha saṅgamya gatā vaivasvatakṣayam|| // 8-3-5 //
（5）パーンチャーラ族の偉大な弓兵たち、すべて戦術に精通した者たちは、ドローナと出会って閻魔の世界に去りました。
tathā virāṭadrupadau vṛdvau sahasutau nṛpau|
parākramantau mitrārthe droṇena nihatau raṇe|| // 8-3-6 //
（6）老いたヴィラータとドルパダの二人の王は、息子たちとともに、友のために奮戦しながらドローナに戦場で殺されました。
yo bāla eva samare sammitaḥ savyasācinā|
keśavena ca durdharṣo baladevena cābhibhūḥ||
pareṣāṃ kadanaṃ kṛtvā mahadraṇaviśāradaḥ|
parivārya madāmātraiḥ ṣaḍbhiḥ paramakai rathaiḥ|
aśaknuvadbhir bībhatsum abhimanyur nipātitaḥ|| // 8-3-7-8 //
（7〜8）幼くしてアルジュナに匹敵し、ケーシャヴァ（クリシュナ）にもバラデーヴァにも近づき難いアビマニュ——戦術に精通した偉大な戦闘者として、敵に大殺戮を行った後、六人の最上の戦車戦士に取り囲まれ、ビーバツ（アルジュナ）に太刀打ちできなかった者たちによって、アビマニュは倒されました。
kṛtaṃ taṃ virathaṃ vīraṃ kṣatradharme vyavasthitam|
dauḥśāsanir mahārāja saubhadraṃ hatavān raṇe|| // 8-3-9 //
（9）大王よ、戦車を失い、クシャトリヤの戒律に従って立つ勇者スバドラーの子を、ドゥフシャーサナの息子が戦場で殺しました。
paṭaccaranihantā ca mahatyā senayā vṛtaḥ|
ambaṣṭhasya sutaḥ śrīmān mitrahetoḥ parākraman||
āsādya lakṣmaṇaṃ vīraṃ duryodhanasutaṃ raṇe|
sumahatkadanaṃ kṛtvā gato vaivasvatakṣayam|| // 8-3-10-11 //
（10〜11）パタッチャラの殺し手にして、大軍に囲まれた、アンバシュタの栄光ある息子は、友のために奮戦し、勇者ラクシュマナ（ドゥルヨーダナの息子）に出会い、大殺戮を行った後に閻魔の世界に去りました。
bṛhantaḥ sumaheṣvāsaḥ kṛtāstro yudvadurmadaḥ|
duḥśāsanena vikramya gamito yamasādanam|| // 8-3-12 //
（12）偉大な弓兵にして武器に精通し戦闘に酔いしれたブリハンタは、ドゥフシャーサナに力をもって閻魔の館に送られました。
maṇimāndaṇḍadhāraś ca rājānau yuddhadurmadau|
parākramantau mitrārthe droṇena yudhi pātitau|| // 8-3-13 //
（13）マニマーンとダンダダーラの二人の王は、戦闘に酔いしれた者として、友のために奮戦しながらドローナに戦場で倒されました。
aṃśumān bhojarājas tu sahasainyo mahārathaḥ|
bhāradvājena vikramya gamito yamasādanam|| // 8-3-14 //
（14）ボージャの王アンシュマーンは偉大な戦車戦士として軍とともに、バーラドヴァージャ（ドローナ）に力をもって閻魔の館に送られました。
sāmudraścitrasenaśca saha putreṇa bhārata|
samudrasenena balād gamito yamasādanam|| // 8-3-15 //
（15）バーラタよ、サームドラ・チトラセーナは息子サムドラセーナとともに、力をもって閻魔の館に送られました。
anūpavāsī nīlaśca vyādhradattaśca vīryavān|
aśvatthāmnā vikarṇena gamitau yamasādanam|| // 8-3-16 //
（16）水辺に住むニーラと武勇あるヴィヤーグラダッタは、アシュヴァッターマンとヴィカルナに閻魔の館に送られました。
citrāyudhaścitrayodhī kṛtvā ca kadanaṃ mahat|
citramārgeṇa vikramya vikarṇena hato mṛdhe| // 8-3-17 //
（17）チトラーユダとチトラヨーディンは大殺戮を行い、見事な戦い方でヴィカルナに戦場で殺されました。
vṛkodarasamo yuddhe vṛtaḥ kekayajo yudhi|
kekayena ca vikramya bhrātā bhrātrā nipātitaḥ|| // 8-3-18 //
（18）戦場でビーマに等しかったケーカヤの王子は、ケーカヤの者に——兄弟が兄弟に倒されました。
janamejayo gadāyodhī pārvatīyaḥ pratāpavān|
durmukhena mahārāja tava putreṇa pātitaḥ|| // 8-3-19 //
（19）大王よ、棍棒で戦う山岳の者ジャナメージャヤは、あなたの息子ドゥルムカに倒されました。
rocamānau naravyāghrau rocamānau grahāviva|
drauṇena yugapad rājan divaṃ samprātitau śaraiḥ|| // 8-3-20 //
（20）王よ、ローチャマーナという名の二人の兄弟は、人の中の虎として、輝く遊星のような二人は、ドローナの子に矢で同時に天へ送られました。
nṛpāśca pratiyudhyantaḥ parākrāntā viśāmpate|
kṛtvā na sukaraṃ karma gatā vaivasvatakṣayam||
purujit kṛntibhojaś ca mātulau savyasācinaḥ|
saṃgrāmanirjitān lokān gamitau droṇasāyakaiḥ|| // 8-3-21-22 //
（21〜22）王よ、奮戦し力を示した多くの王たちもまた、困難な業をなし遂げて閻魔の世界に去りました。左右の手で射る者（アルジュナ）の母方の叔父プルジットとクンティボージャは、ドローナの矢によって戦勝者の世界に送られました。
abhibhūḥ kāśirājaśca kāśikair bahubhir vṛtaḥ|
vasudānasya putreṇa tyājito dehamāhave|| // 8-3-23 //
（23）カーシ王アビブーは、カーシの多くの者とともに、ヴァスダーナの息子に戦場で命を絶たれました。
amitaujā yudhāmanyur uttamaujāśca vīryavān|
nihatya śataśaḥ sūrānasmadīyair nipātitāḥ|| // 8-3-24 //
（24）アミタウジャス、ユダーマニュ、そして武勇あるウッタマウジャスは、何百もの勇者を殺した後に我が者たちに倒されました。
mitravarmā ca pāñcālyaḥ kṣatradharmā ca bhārata|
droṇena parameṣvāsau gamitau yamasādanam|| // 8-3-25 //
（25）バーラタよ、パーンチャーラのミトラヴァルマンと最上の弓兵クシャトラダルマンは、ドローナに閻魔の館に送られました。
śikhaṇḍitanayo yuddhe kṣatradevo yudhāmpatiḥ|
lakṣmaṇena hato rājaṃs tava pautreṇa bhārata|| // 8-3-26 //
（26）バーラタよ、シカンディンの息子クシャトラデーヴァは、あなたの孫ラクシュマナに戦場で殺されました。
sucitraścitravarmā ca pitāputrau mahārathau|
pracarantau mahāvīrau droṇena nihatau raṇe|| // 8-3-27 //
（27）スチトラとチトラヴァルマンの父子は偉大な戦車戦士にして大勇者として、ドローナに戦場で殺されました。
vārdhakṣemir mahārāja samudra iva parvaṇi|
āyudhakṣayamāsādya praśāntiṃ paramāṃ gataḥ|| // 8-3-28 //
（28）大王よ、ヴァールダクシェーミは満潮時の大海のように武器が尽きて、最上の静寂（死）に達しました。
senābindusutaḥ śreṣṭhaḥ śāstravān praharan yudhi|
bāhlikena mahārāja kauravendreṇa pātitaḥ|| // 8-3-29 //
（29）セーナービンドゥの最上の息子は、聖典に通じ戦場で戦いながら、大王よ、カウラヴァの王バーフリーカに倒されました。
dhṛṣṭaketur mahārāja cedīnāṃ pravaro rathaḥ|
kṛtvā na sukaraṃ karma gato vaivasvatakṣayam|| // 8-3-30 //
（30）大王よ、チェーディ族の最上の戦車戦士ドリシュタケートゥは、困難な業をなし遂げて閻魔の世界に去りました。
tathā satyadhṛtirvīraḥ kṛtvā kadanamāhave|
pāṇḍavārthe parākrānto gamito yamasādanam|| // 8-3-31 //
（31）勇者サティヤドリティもまた、戦場で殺戮を行い、パーンダヴァのために奮戦して閻魔の館に送られました。
putrastu śiśupālasya suketuḥ pṛthivīpatiḥ|
nihatya śātravān saṅkhye droṇena nihato yudhi|| // 8-3-32 //
（32）シシュパーラの息子スケートゥ王は、敵を殺した後に戦場でドローナに殺されました。
tathā satyadhṛtirvīro madirāśvaśca vīryavān|
sūryadattaśca vikrānto nihato droṇasāyakaiḥ|| // 8-3-33 //
（33）勇者サティヤドリティ、武勇あるマディラーシュヴァ、勇猛なるスーリヤダッタもドローナの矢に殺されました。
'mātsyādavarajaḥ śrīmāñ śatānīko nipātitaḥ|
śreṇimāṃś ca mahārāja yudhyamānaḥ parākramī|
kṛtvā na sukaraṃ karma gato vaivasvatakṣayam||
tathaiva yudhi vikrānto māgadhaḥ paramāstravit|
bhīṣmeṇa nihato rājañ śete'dya paravīrahā||
virāṭaputraḥ śaṅkhastu uttaraśca mahārathaḥ|
kurvantau sumahatkarma gatau vaivasvatakṣayam||
vasudānaśca kadanaṃ kurvāṇo'tīva saṃyuge|
bhāradvājena vikramya gamito yamasādanam||
ete cānye ca bahavaḥ pāṇḍavānāṃ mahārathāḥ|
hatā droṇena vikramya yanmāṃ tvaṃ paripṛcchasi|| || // 8-3-34-35-36-37-38 //
（34〜38）マツヤの弟シャタニーカ、勇猛にして困難な業を成し遂げた戦士シュレーニマーンも閻魔の世界に去りました。戦場で勇猛なマガダ王は最上の武器の達人としてビーシュマに殺されました。ヴィラータの息子シャンカとウッタラという偉大な戦車戦士も大いなる業を成し遂げて閻魔の世界に去りました。ヴァスダーナも戦場で激しい殺戮を行いながらバーラドヴァージャ（ドローナ）に閻魔の館に送られました。これらの者たちや他にも多くのパーンダヴァの偉大な戦車戦士たちが、ドローナに力をもって殺されました——あなたが私にお尋ねのとおり。」
iti śrīmanmahābhārate karṇaparvaṇi tṛtīyo'dhyāyaḥ|| 3 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三章は終わる。
