kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

saptadaśaḥ sargaḥ ― 第十七章

アルジュナは弓を取り直してシヴァの軍勢に矢を放つが、シヴァ自身には効果がない。矢を使い果たした後、剣に持ち替えるもそれも折られ、最後には石や樹木を投げつけるが、すべてキラータ王＝シヴァに受け止められる。
1
Sanskrit
athāpadām uddharaṇakṣameṣu mitreṣv ivāstreṣu tirohiteṣu / dhṛtiṃ guruśrīr guruṇābhipuṣyan svapauruṣeṇeva śarāsanena //
Upajāti
和訳
さて、災いを除くに足る忠実な友のごとき武器（アストラ）が消え失せた今、大いなる威光を湛える彼は、自らの勇武にも等しい力強い弓をもって決意を新たにし——
第1〜6偈は連続構文（kulaka）をなし、第6偈の主動詞で結ばれる。前章でアストラ（神の武器）がすべて無効化された後、アルジュナが通常の弓矢に頼る場面。guruśrī は「重き＝偉大なる栄光を持つ者」。
2
Sanskrit
bhūriprabhāveṇa raṇābhiyogāt prīto vijihmaś ca tadīyavṛddhyā / spaṣṭo 'py avispaṣṭavapuḥprakāśaḥ sarpanmahādhūma ivādrivahniḥ //
Indravajrā
和訳
偉大なる力をもって戦いの労苦を喜びつつも、敵の優勢に意気消沈し、光り輝きながらもその身の輝きが覆い隠された者——大いなる煙を噴き上げる山火事のように——
3
Sanskrit
tejaḥ samāśritya parair ahāryaṃ nijaṃ mahanmitram ivorudhairyam / āsādayann askhalitasvabhāvaṃ bhīme bhujālambam ivāridurge //
Upajāti
和訳
敵には奪い得ぬ自らの力——偉大なる友のごとき——に頼り、恐るべき敵の砦にあって、揺るぎなき性質の大いなる忍耐を、腕の支えのごとく得ながら——
4
Sanskrit
vaṃśocitatvād abhimānavatyā samprāptayā sampriyatām asubhyaḥ / samakṣam āditsitayā pareṇa vadhveva kīrtyā paritapyamānaḥ //
Upajāti
和訳
家系に相応しいがゆえに誇り高く、命よりも愛しき名誉を、目の前で敵に奪い取られようとして——高貴な花嫁のごとき栄光のために——苦悶し——
kīrti（名誉）が高貴な花嫁（vadhū）に喩えられる。家系（vaṃśa）に相応しい誇り高い名誉が命より大切であり、敵に目の前で奪われそうになっている苦しみ。
5
Sanskrit
patiṃ nagānām iva baddhamūlam unmūlayiṣyaṃs tarasā vipakṣam / laghuprayatnaṃ nigṛhītavīryas trimārgagāvega iveśvareṇa //
Upajāti
和訳
山の王のごとく根を張った敵を力ずくで根こそぎ倒そうとして、三道を流れるガンガーの奔流のように、主宰者によって軽々と勇猛さを抑え込まれ——
trimārgagā（三つの道を行く者）はガンジス河の別名。かつてシヴァが天から落下するガンガーの奔流を自らの結髪で受け止めたという神話を踏まえる。
6
Sanskrit
saṃskāravattvād ramayatsu cetaḥ prayogaśikṣāguṇabhūṣaṇeṣu / jayaṃ yathārtheṣu śareṣu pārthaḥ śabdeṣu bhāvārtham ivāśaśaṃse //
Upajāti
和訳
プリターの子は、見事に仕上げられ心を喜ばせる矢——その飾りは技量と修練と弦（グナ）にある——に勝利を期した。あたかも話者が、巧みに構成され心を楽しませる言葉——修辞と練達と美質が装いとなる——に真意の成就を期するように。
弓術と弁論術の二重比喩。guṇa は弓弦と美質の両義、śara は矢と言葉（śabda）の対応、prayoga は発射と用法の両義。yathārtha は「名に相応しい」で、矢（śara ＝ 砕く者）が実際に砕く力を持つこと。連続構文の結語。
7
Sanskrit
bhūyaḥ samādhānavivṛddhatejā naivaṃ purā yuddham iti vyathāvān / sa nirvavāmāsram amarṣanunnaṃ viṣaṃ mahānāga ivekṣaṇābhyām //
Upajāti
和訳
再び集中力を高めて闘志を燃やしながらも、「かつてはこのような戦いではなかった」と嘆き苦しみ、彼は両眼から怒りに駆られた涙を流した——大蛇が毒を吐くように。
8
Sanskrit
tasyāhavāyāsavilolamauleḥ saṃrambhatāmrāyatalocanasya / nirvāpayiṣyann iva roṣataptaṃ prasnāpayāmāsa mukhaṃ nidāghaḥ //
Indravajrā
和訳
戦いの激しさに髪飾りが乱れ、憤激に赤く見開かれた目をした彼——その怒りに焼ける顔を冷ますかのように、夏の暑気が汗で顔を濡らした。
9
Sanskrit
krodhāndhakārāntarito raṇāya bhrūbhedarekhāḥ sa babhāra tisraḥ / ghanoparuddhaḥ prabhavāya vṛṣṭer ūrdhvāṃśurājīr iva tigmaraśmiḥ //
Upajāti
和訳
怒りの闇に覆われた彼は、戦いに向けて三本の眉間の皺を刻んだ——雲に遮られた太陽が、雨の前兆として上向きの光線を放つように。
太陽が上向きの光条を放つのは降雨の前兆とされる。アルジュナの三本の眉間の皺が、矢の雨の前触れであることを暗示する。
10
Sanskrit
sa pradhvanayyāmbudanādi cāpaṃ hastena diṅnāga ivādriśṛṅgam / balāni śambhor iṣubhis tatāpa cetāṃsi cintābhir ivāśarīraḥ //
Upajāti
和訳
彼は雷雲のごとく轟く弓を鳴らし——方位の象が鼻で山頂を鳴り響かせるように——シャンブの軍勢を矢で苦しめた。あたかも肉体なき者（カーマ）が憂いで人々の心を悩ますように。
aśarīra（肉体なき者）はカーマ神（愛の神）の別名。シヴァの第三の目で焼かれて肉体を失った。弓の轟音と矢の攻撃をカーマの精神攻撃に喩える。
11
Sanskrit
sadvāditevābhiniviṣṭabuddhau guṇābhyasūyeva vipakṣapāte / agocare vāg iva copareme śaktiḥ śarāṇāṃ śitikaṇṭhakāye //
Upajāti
和訳
矢の力は青き喉の者（シヴァ）の身体に届かなかった——正しき弁論が頑迷な者に通じぬように、美徳への嫉妬が公正なる者に及ばぬように、言葉が把握し得ぬもの（ブラフマン）に届かぬように。
三重の比喩（mālā-upamā）。agocara（到達し得ぬ領域）はウパニシャッドの「そこから言葉は及ばず退く」（yato vāco nivartante）を踏まえる。マッリナータはこの句をブラフマンの不可知性として注釈する。
12
Sanskrit
umāpatiṃ pāṇḍusutapraṇunnāḥ śilīmukhā na vyathayāṃbabhūvuḥ / abhyutthitasyādripater nitambam arkasya pādā iva haimanasya //
Upajāti
和訳
パーンドゥの子が放った矢はウマーの夫を苦しめることができなかった——冬の太陽の光線が、聳え立つ山の王の山腹を温め得ぬように。
13
Sanskrit
samprīyamāṇo 'nubabhūva tīvraṃ parākramaṃ tasya patir gaṇānām / viṣāṇabhedaṃ himavān asahyaṃ vaprānatasyeva suradvipasya //
Upajāti
和訳
ガナの主は喜びつつ彼の猛烈な攻撃を受け止めた——ヒマラヤ山が、身を傾けた神象（アイラーヴァタ）の耐え難い牙の一撃を受け止めるように。
14
Sanskrit
tasmai hi bhāroddharaṇe samarthaṃ pradāsyatā bāhum iva pratāpam / ciraṃ viṣehe 'bhibhavas tadānīṃ sa kāraṇānām api kāraṇena //
Upajāti
和訳
あらゆる原因の原因たるシヴァは、その時、彼に重荷を担うに足る力——腕にも等しい威力——を与えようとして、長く屈辱を耐え忍んだ。
シヴァがアルジュナの攻撃に耐えるのは、後に彼に力を授けるため。bhāra（重荷）は地上の統治の責任を指す。Cappellerはこの「重荷」を「地上の支配権」と解釈する。
15
Sanskrit
pratyāhataujāḥ kṛtasattvavegaḥ parākramaṃ jyāyasi yas tanoti / tejāṃsi bhānor iva niṣpatanti yaśāṃsi vīryajvalitāni tasya //
Upajāti
和訳
力を跳ね返されてもなお気力を奮い起こし、より強き者に立ち向かう者——その者の名声は、勇猛に輝いて、太陽の光のごとく迸る。
16
Sanskrit
dṛṣṭāvadānād vyathate 'rilokaḥ pradhvaṃsam eti vyathitāc ca tejaḥ / tejovihīnaṃ vijahāti darpaḥ śāntārciṣaṃ dīpam iva prakāśaḥ //

和訳
その武勲を目にして敵の群れは動揺し、動揺した者から気迫は消え、気迫を失った者からは傲慢も去る——炎の消えた灯火から光が去るように。
17
Sanskrit
tataḥ prayāty astamadāvalepaḥ sa jayyatāyāḥ padavīṃ jigīṣoḥ / gandhena jetuḥ pramukhāgatasya pratidvipasyeva mataṅgajaughaḥ //
Upajāti
和訳
かくして傲慢と驕りが沈むと、敵は勝利を渇望する者に敗北の道を辿る——勝利の象が前に立ちはだかれば、その発情臭だけで象の群れが屈するように。
18
Sanskrit
evaṃ pratidvandviṣu tasya kīrtiṃ maulīndulekhāviśadāṃ vidhāsyan / iyeṣa paryāyajayāvasādāṃ raṇakriyāṃ śambhur anukrameṇa //
Upajāti
和訳
このようにして敵たちのなかでアルジュナに、冠の三日月のごとく清らかな名声を与えようとして、シャンブは勝敗が交互に訪れる戦いを順序立てて展開しようとした。
シヴァがわざと勝ち負けを交互にさせるのは、一方的な勝利よりも交互の勝敗のほうがアルジュナの名声をより高めるためだとCappellerは解釈する。maulīndulekhā（冠の三日月の線条）はシヴァ自身の三日月の冠を指す。
19
Sanskrit
muner vicitrair iṣubhiḥ sa bhūyān ninye vaśaṃ bhūtapater balaughaḥ / sahātmalābhena samutpatadbhir jātisvabhāvair iva jīvalokaḥ //
Upajāti
和訳
彼の多彩な矢によって、ブータの主（シヴァ）の大軍は制圧された——生物の世界が、誕生と同時に起こる種の本性（業の定め）に支配されるように。
jātisvabhāva（種の本性）は前世の業に由来する宿命を指す。生き物が生まれながらにして業の定めに従うように、シヴァの軍勢もアルジュナの矢に屈したという比喩。
20
Sanskrit

彼が矢の闇を広げると、怯えた軍勢はその唸りを聞いた——夜の雷雲が降り注ぐとき、震え続ける牛の群れがその音を聞くように。
21
Sanskrit

彼は恐怖に打ちひしがれた敵に無類の巧みさで矢を放ち、分身して各所に現れるかのように見えた——眼病に侵された者の目には月が幾つにも分かれて見えるように。
22
Sanskrit

23
Sanskrit
prasedivāṃsaṃ na tam āpa kopaḥ kutaḥ parasmin puruṣe vikāraḥ / ākāravaiṣamyam idaṃ ca bheje durlakṣyacihnā mahatāṃ hi vṛttiḥ //
Upajāti
和訳
平静なる彼に怒りは訪れなかった——至高のプルシャにどうして変化があろうか。しかし彼はこの外見の変容を受け入れた——偉大なる者たちの振る舞いは、その真意を窺い知り難いものである。
シヴァは内面では動じていないが、外見上の変化は受け入れる。parasmin puruṣe（至高のプルシャ）はシヴァの本質が不変であることを示す哲学的表現。偉大なる者の行為は凡人には理解し難いという思想。
24
Sanskrit

Indravajrā
和訳

Sanskrit

26
Sanskrit

27
Sanskrit
vibhedam antaḥ padavīnirodhaṃ vidhvaṃsanaṃ cāviditaprayogaḥ / netārilokeṣu karoti yad yat tat tac cakārāsya śareṣu śambhuḥ //
Upajāti
和訳
内部からの分裂、道の封鎖、壊滅——策略を知らせぬ指揮官が敵勢に対して行うこと、その一切をシャンブはアルジュナの矢に対して行った。
シヴァが弓術に不慣れ（aviditaprayoga）であるにもかかわらず、巧みな軍事戦略のごとくアルジュナの矢を無力化するという逆説的表現。Cappellerは「弓術を知らぬ者が」と訳す。
28
Sanskrit

最初の武器が耐え抜かれ嘲られたアルジュナの矢は、怒りに駆られて猛然と飛び、折られてもなお敵軍を脅かした——あたかも目的を果たしたかのように落ちていった。
29
Sanskrit

和訳

ṛjutā は矢の直進性と人の正直さの両義、guṇa は弓弦と美徳の両義、aparvan（節のない所）は矢の折れにくい部分と、不当な時点の両義。善人が不当に苦しむ哲学的問題を射掛ける。
30
Sanskrit

32
Sanskrit

33
Sanskrit

Upajāti
和訳
矢を求めて頼りにした箭筒が内実を失い、突然財産を失った友のようになったとき、その時の信頼が空しくなったにもかかわらず、手は非難を恐れるかのように箭筒のほうを向き続けた。
箭筒を友人に喩える擬人化。矢のなくなった箭筒は財を失った友に等しいが、それでも手は背を向けない——恩知らずの非難を受けたくないかのように。
38
Sanskrit
āghaṭṭayāmāsa gatāgatābhyāṃ sāvegam agrāṅgulir asya tūṇau / vidheyamārge matir utsukasya nayaprayogāv iva gāṃ jigīṣoḥ //
Upajāti
和訳
彼の指先は慌ただしく行き来して両方の箭筒を探った——天下を求める焦る者の知性が、政策と実行の二つの道を思い巡らすように。
39
Sanskrit
babhāra śūnyākṛtir arjunas tau maheṣudhī vītamaheṣujālau / yugāntasaṃśuṣkajalau vijihmaḥ pūrvāparau loka ivāmburāśī //
Upajāti
和訳
虚ろな表情でアルジュナは、大いなる矢の群れが消え去った二つの大箭筒を背負った——世界の終わりに水が干上がった東西二つの大海を、歪んだ世界が背負うように。
40
Sanskrit
tenātimittena tathā na pārthas tayor yathā riktatayānutepe / svām āpadaṃ projjhya vipattimagnaṃ śocanti santo hy upakāripakṣam //
Upajāti
和訳
この不吉な前兆よりも、プリターの子は箭筒が空であることをこそ嘆いた——善き人は自らの災いを顧みず、恩ある者が不幸に沈むのを悲しむものである。
41
Sanskrit
pratikriyāyai vidhuraḥ sa tasmāt kṛcchreṇa viśleṣam iyāya hastaḥ / parāṅmukhatve 'pi kṛtopakārāt tūṇīmukhān mitrakulād ivāryaḥ //
Upajāti
和訳
対策の手立てを失ったその手は、やむを得ず箭筒の口から離れた——高貴な者が、もはや顧みてくれなくとも、かつて恩を受けた友の一族からようやく離れるように。
42
Sanskrit
paścātkriyā tūṇayugasya bhartur jajñe tadānīm upakāriṇīva / sambhāvanāyām adharīkṛtāyāṃ patyuḥ puraḥ sāhasam āsitavyam //
Indravajrā
和訳
箭筒の対を背中に回したことは、主人の恩恵であるかのように思われた——威厳が失われたとき、主の前に出ることは僭越というものである。
空の箭筒を背中に回す（前面から隠す）のは、箭筒への恩恵であるという機知。威厳を失った者が主人の前に留まるのは無謀だから、背後に退くのが救いとなる。Cappellerは「背中に回すことで恥から救った」と解釈する。
43
Sanskrit
taṃ śambhur ākṣiptamaheṣujālaṃ lohaiḥ śarair marmasu nistutoda / hṛtottaraṃ tattvavicāramadhye vakteva doṣair gurubhir vipakṣam //
Upajāti
和訳
大いなる矢の群れを失った彼を、シャンブは鉄の矢で急所を突き刺した——真理の論争のなかで、論敵が反論に窮したとき、重大な過誤を指摘して痛打する弁者のように。
44
Sanskrit
jahāra cāsmād acireṇa varma jvalanmaṇidyotitahaimalekham / caṇḍaḥ pataṅgān marudekanīlaṃ taḍitvataḥ khaṇḍam ivāmbudasya //
Upajāti
和訳
そして間もなく、輝く宝珠に照らされた黄金の筋の入った鎧を彼から奪い取った——激しい風が、稲妻を帯びた雷雲の一片を太陽から引き剥がすように。
鎧が剥ぎ取られた後のアルジュナの輝きが、暗い覆いを取り去られた太陽のごとく一層増すという逆説的な比喩。
45
Sanskrit
vikośanirdhautatanor mahāseḥ phaṇāvataś ca tvaci vicyutāyām / pratidvipābaddharuṣaḥ samakṣaṃ nāgasya cākṣiptamukhacchadasya //
Upajāti
和訳
鎧を失った彼は——鞘から抜かれ刃を磨かれた大剣のように、あるいは脱皮した蛇のように、あるいは敵象を前にして怒りに燃え顔の覆いを振り落とした象のように見えた——
46
Sanskrit
vibodhitasya dhvaninā ghanānāṃ harer apetasya ca śailarandhrāt / nirastadhūmasya ca rātrivahner vinā tanutreṇa ruciṃ sa bheje //
Upendravajrā
和訳
——あるいは雷鳴に目覚め岩穴から現れた獅子のように、煙を脱ぎ捨てた夜の火のように——彼は鎧なしで一層の輝きを放った。
47
Sanskrit
acittatāyām api nāma yuktām anūrdhvatāṃ prāpya tadīyakṛcchre / mahīṃ gatau tāv iṣudhī tadānīṃ vivavratuś cetanayeva yogam //
Upendravajrā
和訳
意識なき物であるにもかかわらず、主人の苦境にあって相応しい謙虚さを示し、地に落ちた二つの箭筒は、まるで意識を持ち合わせたかのように振る舞った。
箭筒が地に落ちることが、主人の苦境に同情してひれ伏す行為と見立てられる擬人化（utprekṣā）。
48
Sanskrit
sthitaṃ viśuddhe nabhasīva sattve dhāmnā tapovīryamayena yuktam / śastrābhighātais tam ajasram īśas tvaṣṭā vivasvantam ivollilekha //
Upajāti
和訳
清浄な虚空に立つかのごとく、苦行の力による輝きを帯びた彼を、イーシュヴァラは絶え間なく武器の打撃で彫り上げた——神匠トヴァシュトリが太陽を彫り刻むように。
Tvaṣṭar（トヴァシュトリ）は神々の工匠。太陽を旋盤で削って形を整えたという神話。シヴァの矢の打撃がアルジュナをより輝かしく鍛え上げるという逆説的表現。
49
Sanskrit
saṃrambhavegojjhitavedaneṣu gātreṣu bāhiryam upāgateṣu / muner babhūvāgaṇiteṣurāśer lauhas tiraskāra ivātmamanyuḥ //
Upajāti
和訳
激昂の勢いで痛みを忘れ、四肢が無感覚になったとき、矢の雨を物ともしないこの聖仙にとって、自らの怒りこそが鉄の鎧の代わりとなった。
50
Sanskrit
tato 'nupūrvāyatavṛttabāhuḥ śrīmān kṣarallohitadigdhadehaḥ / āskandya vegena vimuktanādaḥ kṣitiṃ vidhunvann iva pārṣṇighātaiḥ //
Upajāti
和訳
そこで均整のとれた長く丸い腕を持つ威光ある者は、流れる血に塗れた身体で、勢いよく突進し雄叫びを上げ、踵の一蹴りで大地を揺るがすかのように——
第50偈と第51偈は連続構文。第51偈に主動詞がある。
51
Sanskrit
sāmyaṃ gatenāśaninā maghonaḥ śaśāṅkakhaṇḍākṛtipāṇḍureṇa / śambhuṃ bibhitsur dhanuṣā jaghāna stambaṃ viṣāṇena mahān ivebhaḥ //
Upajāti
和訳
——インドラの雷霆にも等しく、三日月のごとく白い弓でシャンブを打った——巨大な象が牙で杭を突くように。
52
Sanskrit
rayeṇa sā saṃnidadhe patantī bhavodbhavenātmani cāpayaṣṭiḥ / samuddhatā sindhur anekamārgā pare sthitenaujasi jahnuneva //
Upendravajrā
和訳
飛来するその弓杖を、存在の源たるシヴァは勢いのままに自らの内に収めた——多くの流れに分かれて迫り来る大河（ガンガー）を、至高の力に安んずるジャフヌが呑み込んだように。
王仙ジャフヌは、天から降り注ぐガンガーが祭場を水浸しにしたとき、怒って河を呑み込み、のちに再び放出した。ガンガーがジャーフナヴィー（ジャフヌの娘）と呼ばれる由来。シヴァがアルジュナの弓を呑み込む場面をこの神話に重ねる。
53
Sanskrit
vikārmukaḥ karmasu śocanīyaḥ paricyutaudārya ivopacāraḥ / vicikṣipe śūlabhṛtā salīlaṃ sa patribhir dūram adūrapātaiḥ //
Upendravajrā
和訳
弓を失い、行いにおいて哀れな者――気品を失った礼儀のような者――となった彼を、三叉戟を持つ者（シヴァ）は、間近に落ちる矢で、戯れに遠くまで追いやった。
54
Sanskrit
upoḍhakalyāṇaphalo 'bhirakṣan vīravrataṃ puṇyaraṇāśramasthaḥ / japopavāsair iva saṃyatātmā tepe munis tair iṣubhiḥ śivasya //
Upajāti
和訳
吉祥の果実に近づき、英雄の誓いを守り、聖なる戦場の行場に身を置くこの聖仙は、シヴァの矢によって苦しんだ——念誦と断食による苦行者のように、自らを律しながら。
戦場（raṇa）を苦行の場（āśrama）に、矢の苦痛を苦行（tapas）に見立てる。muni（聖仙）という呼称がアルジュナの苦行者としての側面を強調する。
55
Sanskrit
tato 'grabhūmiṃ vyavasāyasiddheḥ sīmānam anyair atidustaraṃ saḥ / tejaḥśriyām āśrayam uttamāsiṃ sākṣād ahaṃkāram ivālalambe //
Upajāti
和訳
そこで彼は、決意の成就の先端であり、他者には越え難い限界であり、武威の栄光の拠り所である最上の剣を手に取った——あたかも自負心そのものを身に纏うかのように。
56
Sanskrit
śarān avadyann anavadyakarmā cacāra citraṃ pravicāramārgaiḥ / hastena nistriṃśabhṛtā sa dīptaḥ sārkāṃśunā vāridhir ūrmiṇeva //
Upajāti
和訳
非の打ちどころなき行いの者は、矢を弾き返しながら様々な剣の道筋で華麗に進んだ——剣を持つ手で輝いて、太陽の光を受けた波を持つ大海のように。
57
Sanskrit
yathā nije vartmani bhāti bhābhiś chāyāmayaś cāpsu sahasraraśmiḥ / tathā nabhasy āśu raṇasthalīṣu spaṣṭadvimūrtir dadṛśe sa bhūtaiḥ //
Upajāti
和訳
千光の太陽が自らの軌道において光輝で輝き、水面にもその影として映るように、彼もまた空と戦場の二つに明瞭な二つの姿をもって、生きとし生けるものに目撃された。
58
Sanskrit
śivapraṇunnena śilīmukhena tsarupradeśād apavarjitāṅgaḥ / jvalann asis tasya papāta pāṇer ghanasya vaprād iva vaidyuto 'gniḥ //
Upendravajrā
和訳
シヴァが放った矢によって柄の部分から断たれ、燃え輝く剣は彼の手から落ちた——雷雲の斜面から雷の火が落ちるように。
59
Sanskrit
ākṣiptacāpāvaraṇeṣujālaś chinnottamāsiḥ sa mṛdhe 'vadhūtaḥ / riktaḥ prakāśaś ca babhūva bhūmer utsāditodyāna iva pradeśaḥ //
Indravajrā
和訳
弓と鎧と矢の群れを奪われ、至上の剣を折られ、戦場で打ちのめされた彼は、空しく、むき出しになった――庭園を伐り払われた土地のように。
60
Sanskrit
sa khaṇḍanaṃ prāpya parād amarṣavān bhujadvitīyo 'pi vijetum icchayā / sasarja vṛṣṭiṃ parirugṇapādapāṃ dravetareṣāṃ payasām ivāśmanām //
Vaṃśastha
和訳
敵に打ち負かされても憤激を抑えず、両腕のみを武器として、なお勝利を求めて、彼は樹木を折り砕くほどの石の雨を投げつけた——流れぬ水である石の雨を。
61
Sanskrit
nīrandhraṃ parigamite kṣayaṃ pṛṣatkair bhūtānām adhipatinā śilāvitāne / ucchrāyasthagitanabhodigantarālaṃ cikṣepa kṣitiruhajālam indrasūnuḥ //
Praharṣiṇī
和訳
隙間なく降り注いだ石の幕がブータの主の矢で壊されると、インドラの子は空と地平線の間を覆い隠すほどの樹木の群れを投げつけた。
62
Sanskrit
niḥśeṣaṃ śakalitavalkalāṅgasāraiḥ kurvadbhir bhuvam abhitaḥ kaṣāyacitrām / īśānaḥ sakusumapallavair nagais tair ātene balim iva raṅgadevatābhyaḥ //
Praharṣiṇī
和訳
樹皮も幹も心材も残らず砕け散り、大地を一面に褐色の斑模様に染めたそれらの花と新芽をつけた樹木で、イーシャーナは戦場の神々にさながら供物を捧げた。
63
Sanskrit
unmajjan makara ivāmarāpagāyā vegena pratimukham etya bāṇanadyāḥ / gāṇḍīvī kanakaśilānibhaṃ bhujābhyām ājaghne viṣamavilocanasya vakṣaḥ //
Praharṣiṇī
和訳
天の河から浮かび上がるマカラ（海獣）のように、矢の河の流れに正面から突進して、ガーンディーヴァの持ち主は両腕で三つ目の神の黄金の岩のごとき胸を打った。
64
Sanskrit
abhilaṣata upāyaṃ vikramaṃ kīrtilakṣmyor asugamam arisainyair aṅkam abhyāgatasya / janaka iva śiśutve supriyasyaikasūnor avinayam api sehe pāṇḍavasya smarāriḥ //
Mālinī
和訳
名声と栄光の道であり、敵軍には到達し難い勇猛を求めて膝に攀じ登ってきたパーンドゥの子の無礼をさえ、カーマの敵（シヴァ）は耐え忍んだ——幼き最愛の一人息子の無作法を父が許すように。
第十七章の結び。シヴァがアルジュナの攻撃を「父が幼子の無作法を許す」という比喩で結ぶ。aṅkam abhyāgatasya（膝に攀じ登った者）は文字通りには格闘で組みつく動作だが、幼子が父の膝に上る仕草と重ねられる。
iti bhāravikṛtau mahākāvye kirātārjunīye saptadaśaḥ sargaḥ //
