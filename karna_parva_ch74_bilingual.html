Mahābhārata — Karṇaparvan, Adhyāya 74 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ74」、全17詩節からなります。アルジュナがユダーマンユ王を侮辱し怒らせてしまい、ユダーマンユが森へ去ろうとする場面（第1〜17詩節）で本章は終わります。日本語対訳では複数の詩節が一括して翻訳されています。
karṇaparva — catuḥsaptatitamo'dhyāyaḥ (74)
第74章　アルジュナの侮辱に怒り森へ向かおうとするユディシュティラをクリシュナが慰める
sañjaya uvāca|
etacchrutvā pāṇḍavo dharmarājo bhrāturvākyaṃ paruṣaṃ phalgunasya|
utthāya tasmācchayanāduvāca pārthaṃ tato duḥkhaparītacetāḥ||
// 8-74-1 //
サンジャヤは語った。
kṛtaṃ mayā pārthaṃ na sādhukarma yena prāptaṃ vyasanaṃ vaḥ sughoram|
tasmācchiraśchindhi mamaitadadya kulāntakasyādhamapūruṣasya||
pāpasya pāpmohatasya vīra vimūḍhabuddheralasasya bhīroḥ|
vṛddhāvamansuḥ paruṣatya caiva kiṃ te ciraṃ māmanusṛjya rūkṣam||
// 8-74-2-3 //
「アルジュナよ、私は善からぬ業をなした。それによってお前たちは恐ろしい災難に陥った。だからこの首を切れ、一族の滅亡者、最低の男の首を。罪深く、罪に酩酊し、勇者よ、知恵を失い、怠惰で臆病な、年長者を蔑む残酷な者の——なぜ長く残酷な私に付き従うのか。」
gacchāmyahaṃ vanamadyaiva pāpaḥ sukhaṃ bhavānvartatāṃ madvihīnaḥ|
yogyo rājā bhīmaseno mahātmā klībasya kiṃ vā mama rājyakṛtyam||
na cāpi śaktaḥ paruṣāṇi soḍhuṃ punastavemāni ruṣānvitasya|
bhīmo'stu rājā mama jīvitena na kāryamadyāvamatasya vīra||
// 8-74-4-5 //
「今日すぐに罪深い私は森に行く。私なしでお前は安楽に過ごせ。ビーマセーナこそふさわしい王だ。臆病者の私に王の務めは何の意味があろう。お前の怒りに満ちた厳しい言葉をもはや耐えられない。ビーマが王になるがよい。蔑まれた私の命に今日価値はない、勇者よ。」
ityevamuktvā sahasotpapāta ruṣānvitastacchayanaṃ vihāya|
iyeṣa nirgantumatho vanāya taṃ vāsudevaḥ praṇato'bhyuvāca||
// 8-74-6 //
こう言い、怒りに満ちて寝台を離れ、突然立ち上がり、森へ出発しようとした。それに対しヴァースデーヴァ（クリシュナ）は頭を垂れて語った。
na rājanviditaṃ tatte yathā gāṇḍīvadhanvanaḥ|
pratijñā satyasandhasya gāṇḍīvaṃ prati viśrutā||
brūyādya enaṃ gāṇḍīvaṃ dehyanyasmai tvamityuta|
vadhyo'sya sa pumā~lloke tvayā coktoyamīdṛśam||
tataḥ satyāṃ pratijñāṃ tāṃ pārthena pratirakṣatā|
macchandādavamāno'yaṃ kṛtastava mahīpate||
// 8-74-7-9 //
「王よ、ガーンディーヴァの弓持ちの、真実を誓った者の有名な誓いをお前は知らなかった。『ガーンディーヴァを他の者に渡せ』と言う者は殺されるべきだ——それがこの世における彼の定め。お前はそのようなことを言った。だから真実の誓いを守ろうとするアルジュナが、私の勧めで、王よ、お前に対してこの無礼を行ったのだ。」
gurūṇāmavamāno hi vadha ityabhidhīyate|
tasmātkṣama mahābāho mama pārthasya cobhayoḥ||
vyatikramamimaṃ rājansatyasaṃrakṣaṇaṃ prati|
śaraṇaṃ tvāṃ mahārāja pratipannāvubhāvapi||
kṣantumarhasi me rājanpraṇatasyābhiyācataḥ|
rādheyasyādya pāpasya bhūmiḥ pāsyati śoṇitam||
// 8-74-10-12 //
「師への無礼は殺害に等しいと言われている。だから大いなる腕の者よ、私とアルジュナの両方を許してくれ。この逸脱を、王よ、真実の守護のためのものとして許してくれ。大王よ、我々二人ともお前に帰依している。許してくれ、私が頭を垂れて懇願する。今日、邪悪なラーデーヤの血を大地が飲むだろう。」
satyaṃ te pratijānāmi hataṃ vidvyadya sūtajam|
yasyecchasi vadhaṃ tasya gatamevādya jivītam||
// 8-74-13 //
「真実を誓う——今日スータの子は殺されたと知れ。お前が殺したい者の命はすでに去った。」
iti kṛṣṇavacaḥ śrutvā dharmarājo yudhiṣṭhiraḥ|
sasambhramaṃ hṛṣīkeśamutthāpya praṇataṃ tadā|
kṛtāñjalimuvācedaṃ vākyaṃ yatsamanantaram||
evameva yathāttha tvamastyeṣo'tikramo mama|
anunīto'smi govinda tāritaścāsmi mādhava||
mocitā vyasanāddhorādvayamadya tvayācyuta|
bhavantaṃ nāvamāsādya hyāvāṃ vyasanasāgarāt|
ghorādadya samuttīrṇāvubhāvajñānamohitau||
tvadbuddhiplavamāsādya duḥkhaśokārṇavādvayam|
samuttīrṇāḥ sahāmātyāḥ sanāthāḥ sma tvayācyuta||
// 8-74-14-17 //
クリシュナの言葉を聞いて、ダルマラージャ・ユディシュティラは、慌てて頭を垂れたフリシーケーシャ（クリシュナ）を立ち上がらせ、合掌してこう言った。「まさにお前の言う通りだ。この逸脱は私のものだ。ゴーヴィンダよ、私は慰められた。マーダヴァよ、私は救われた。恐ろしい災難から今日お前に救われた、アチュタよ。お前に会わなければ、我々二人は災難の海から——恐ろしい、無知に惑わされた二人は渡ることができなかった。お前の知恵の舟に乗って、苦しみと悲嘆の海から、大臣たちと共に渡ることができた。アチュタよ、お前によって我々は守られている。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe catuḥsaptatitamo'dhyāyaḥ|| 74 ||
