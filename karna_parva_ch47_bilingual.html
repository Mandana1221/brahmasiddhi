マハーバーラタ ― カルナ篇 第47章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 47 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ47」（両軍の区別すら失われた、混戦・乱戦の凄惨な情景を描く全43詩節の比較的短い章）です。サンジャヤは、互いに憎しみを抱いたクシャトリヤたちが戦車・馬・象・歩兵の群れを問わず入り乱れて殺し合う様を語ります。血にまみれた大地はインドラゴパ虫の群れのような雨季の地面に、また赤く染めた白衣をまとう色黒の若い女性のごとくに譬えられ、切り落とされた頭・腕・腿や装飾品が地に散らばります。象たちは互いの牙で攻め合い、矢や槍に貫かれて血に染まりながらも山のごとく輝き、ある象は雷を帯びた雨雲のように、ある象は崩れた山のように倒れていきます。戦場の混乱は極まり、敵味方の区別さえつかぬまま、塵と闇に包まれて殺し合う者たちの姿が描かれ、血の大河が幾度も流れ出し、骨を魚、頭髪を海草、弓矢や棍棒を筏とする凄惨な「血の川」の情景が詳細に展開されます。さらに、肉と血に飽くまで酔いしれて踊る亡霊たちの群れや、脂肪・骨髄・肉を食らう犬・鷲・鷺・禿鷹（カーカ・グリドラ・バカ）の群れも描かれます。章末では、互いに名と血統を告げ合いながら戦う戦士たちの姿が示され、クル軍が海に沈む船のように崩れていく場面で終わります（第43詩節）。なお、原典の奥書（コロフォン）には第40・42〜46章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典にも、前章（第46章）と同様、本来の第1〜43詩節の連番に先立って余分な注記「8-47-0」「8-47-0x」が冒頭の「サンジャヤは語った」の一文に付されているという特異な誤記が見られたため、これを第1詩節の本文に統合した上で全43詩節を正しく分離・対訳しています。
karṇaparva — saptacatvāriṃśo'dhyāyaḥ (47)
第47章
sañjaya uvāca|
kṣatriyās te mahārāja parasparavadhaiṣiṇaḥ|
anyonyaṃ samare jaghnuḥ kṛtavairā mahaujasaḥ|| // 8-47-1 //
サンジャヤは語った。 （1）国王よ、大力のクシャトリヤたちは互いに殺し合うことを望み、憎しみを抱いて戦場で討ち合った。
rathaughāś ca hayaughāś ca naraughāś ca samantataḥ|
gajaughāś ca mahārāja saṃsaktāś ca parasparam|| // 8-47-2 //
（2）戦車の群れ、馬の群れ、人の群れ、象の群れがあたり一面で互いに激突した。
gadānāṃ parighāṇāṃ ca śaktīnāṃ ca parasparam|
prāsānāṃ bhiṇḍipālānāṃ musuṇṭhīnāṃ ca sarvaśaḥ|| // 8-47-3 //
（3）鉄棒、棍棒、槍、短槍、投槍、短棒――。
sampātaṃ ca anupaśyāma saṅgrāme bhṛśadāruṇe|
śalabhā iva sampetuḥ śaravṛṣṭyaḥ samantataḥ|| // 8-47-4 //
（4）きわめて凄まじい戦いで、さまざまな矢の雨が降るのを、我らはあたり一面で見た。イナゴの群れのように矢が降り注いだ。
nāgān nāgāḥ samāsādya vyadhamanta parasparam|
hayā hayāṃś ca samare rathino rathinas tathā|| // 8-47-5 //
（5）象は象と、馬は馬と、戦車戦士は戦車戦士と、戦場で互いに討ち合った。
pattayaḥ pattisaṅghāṃś ca hayasaṅghāṃś ca pattayaḥ|
pattayo rathamātaṅgān rathā hastyaśvam eva ca|
nāgāś ca samare tryaṅgaṃ mamṛduḥ śīghragā nṛpa|| // 8-47-6 //
（6）歩兵は歩兵の群れと、馬の群れと、戦車・象を、戦車は象・馬を、象は戦場で三種（三軍）を、素早く踏みつぶした、王よ。
vadhyatāṃ tatra śūrāṇāṃ krośatāṃ ca parasparam|
ghoramāyodhanaṃ jajñe paśūnāṃ ghātane yathā|| // 8-47-7 //
（7）勇者たちが殺され互いに叫ぶ戦場で、まるで獣を屠るかのような、恐ろしい戦場が生じた。
rudhireṇa samāstīrṇā babhau bhārata medinī|
śakragopagaṇākīrṇā prāvṛṣī iva vasundharā|| // 8-47-8 //
（8）血にまみれた大地は、バーラタよ、インドラゴパ虫の群れでいっぱいの雨季の地面のように輝いて見えた。
yathā vā vāsasī śukle mahārajanarañjite|
bibhratī yuvatī śyāmā tadvad āsīd vasundharā|| // 8-47-9 //
（9）大きな赤色で染めた白い衣服を着た、色黒の若い女性のように、大地はなった。
'baddhacūḍāmaṇidharaiḥ śirobhiścārukuṇḍalaiḥ|
ujjhitairvṛṣabhākṣāṇāṃ bhrājate sma vasundharā'|| // 8-47-10 //
（10）頂にダイヤモンドのついた、耳輪の美しい、雄牛のような目の勇者たちの頭が地に落ちて、大地は輝いていた。
śaśaśoṇitadigdhā iva śātakumbhamayī iva ca|
bhūr babhau bharataśreṣṭha śāntārcirbhir iva analaiḥ||
' // 8-47-11 //
（11）大地は月影のようで、また黄金のごとくであった。穏やかな炎の火に焼かれるようであった。
chinnānāṃ ca uttamāṅgānāṃ bāhūnāṃ ca ūrubhiḥ saha|
kuṇḍalānāṃ pinaddhānāṃ bhūṣaṇānāṃ ca bhārata|| // 8-47-12 //
（12）切り落とされた頭・腕・腿、耳輪・装飾品、――。
niṣkāṇāṃ hemasūtrāṇāṃ śarīrāṇāṃ ca dhanvinām|
carmaṇāṃ sapatākānāṃ saṅghās tatra apatan bhuvi| // 8-47-13 //
（13）金の飾り、金の糸、弓使いたちの体、旗のついた盾、これらの群れが地に落ちた。
'agamyakalpā pṛthivī sarvato bhṛśakardamā'||
gajā gajān samāsādya viṣāṇair ārdayan nṛpa|
viṣāṇāgrahatās tatra bhrājante dviradottamāḥ|
rudhireṇa avasiktāṅgā gairikaprasravā iva|
'prāvṛṭkāle mahārāja meghā iva savidyutaḥ'|| // 8-47-14 //
（14）「通ることもできぬほどに、大地は泥でぬかるんでいた」。象は象に出会って牙で攻め、牙に打たれた素晴らしい象たちは、血で体を濡らし、赤土を流す山のごとく輝いた。「大王よ、雨季の稲妻をもつ雲のごとく」――。
syandamānā yathā bhānti parvatā dhātumaṇḍitāḥ|
'tathā rejū raṇe nāgā rudhireṇa samāplutāḥ'|| // 8-47-15 //
（15）流れるように輝く山々が金属で飾られるように――「戦場の象たちは血に浸されて輝いた」。
tomarān sādibhir muktān pratimānasthitān bahūn|
hastairuddhṛtya tān nāgā babhañjuś ca apare raṇe|| // 8-47-16 //
（16）騎兵の放った槍が多く象たちに刺さるのを、他の象たちは鼻で取り除き、戦場で砕いた。
nārācaiś chinnavarmāṇo bhrājante sma gajottamāḥ|
himāgame yathā rājan vyabhrā iva mahīdharāḥ|| // 8-47-17 //
（17）鉄矢で鎧を切り裂かれた素晴らしい象たちは、冬のおとずれに、雲の切れた山々のごとく輝いた。
śaraiḥ kanakapuṅkhaiś ca citā rejur gajottamāḥ|
ulkābhiḥ sampradīptāgrāḥ parvatā iva bhārata|| // 8-47-18 //
（18）金の羽根の矢が集まった素晴らしい象たちは、先端が燃え立つたいまつで輝く山のようであった。
kecid abhyāhatā nāgair nāgā nagavaropamāḥ|
na celuḥ samarāt tasmāt chinnapakṣā iva adrayaḥ|| // 8-47-19 //
（19）象たちに打たれた山のような象たちは、戦場から動かなかった。翼を折られた山のように。
apare prādravan nāgāḥ śarārtā vraṇapīḍitāḥ|
pratimānaiś ca kumbhaiś ca petur urvyāṃ mahāhave|| // 8-47-20 //
（20）他の象たちは矢に苦しめられ、傷ついて逃げた。戦場で、こめかみ・頭を打たれて倒れた。
niṣeduḥ siṃhavat ca anye nadanto bhairavānravān|
vemuś ca bahavo rājaṃś cukruśuś ca apare gajāḥ|| // 8-47-21 //
（21）ある象は獅子のように坐り、恐ろしい声で叫び、多くの象は震え、他の象は叫んだ。
hayāś ca nihatā bāṇair hemabhāṇḍavibhūṣitāḥ|
niṣeduś ca eva mamluś ca babhramuś ca diśo daśa|| // 8-47-22 //
（22）金の馬具で飾られた馬たちが矢に打たれて倒れ、疲れ果て、十方に彷徨った。
apare kliśyamānāś ca vyaveṣṭanta mahītale|
bhāvān bahuvidhāṃś cakrus tāḍitāḥ śaratomaraiḥ|| // 8-47-23 //
（23）他の者たちは苦しんで地面を転げまわった。矢や投槍に打たれ、さまざまな様子をした。
narāstu nihatā bhūmau kūjantas tatra māripa|
dṛṣṭvā ca bāndhavān anye pitṝn anye pitāmahān|| // 8-47-24 //
（24）地に倒れて呻く者たちもいた。敬うべき方よ、親類、父、祖父を見て――。
dhāvamānān parāṃś ca anye dṛṣṭvā anye tatra bhārata|
khyātāni gotranāmāni śaśaṃsur itaretaram|| // 8-47-25 //
（25）走る敵を見て、バーラタよ、名高い血統の名を、互いに告げた。
teṣāṃ chinnā mahārāja bhujāḥ kanakabhūṣaṇāḥ|
udveṣṭante viveṣṭante bhramanti hi utpatanti ca|| // 8-47-26 //
（26）大王よ、金で飾られた彼らの腕は切られ、丸まり、広がり、回り、跳ね上がった。
nipatanti tathaivānye sphuranti ca sahasraśaḥ|
vegāṃś ca anye rame cakruḥ pañcāsyā iva pannagāḥ|| // 8-47-27 //
（27）他のものは落ち、震え、千と躍り、その勢いは、五つの頭の蛇のようであった。
te bhujā bhogibhogābhāś candanāktā viśāmpate|
lohitārdrā bhṛśaṃ rejus tapanīyadhvajā iva|| // 8-47-28 //
（28）蛇の胴のようなそれらの腕は、白檀を塗られ、血で濡れて、黄金の旗のように輝いていた。
vartamāne tathā ghore saṅkule sarvato diśam|
avijñātāḥ sma yudhyante vinighnantaḥ parasparam|| // 8-47-29 //
（29）このように恐ろしい、あたり一面の混乱の戦いにおいて、人々は互いを認識できぬまま、討ち合っていた。
bhaumena rajasākīrṇe śastrasampātasaṅkule|
naiva sve na pare rājan vyajñāyanta tamovṛtāḥ|| // 8-47-30 //
（30）大地の塵が舞い、武器が交差する中で、王よ、闘に覆われて、味方も敵も見分けがつかなくなった。
tathā tad abhavad yuddhaṃ ghorarūpaṃ bhayānakam|
lohitodā mahānadyaḥ prasasrus tatra cāsakṛt|| // 8-47-31 //
（31）このように恐ろしく怖ろしい様相の戦いが行われた。そこでは血の大河が幾度も流れた。
śīrṣapāṣāṇasañchannāḥ keśaśaivalaśādvalāḥ|
asthimīnasamākīrṇā dhanuḥśaragadoḍupāḥ|| // 8-47-32 //
（32）頭が石で覆い尽くされ、髪が海草となり、骨が魚となり、弓・矢・鉄棒が筏となった――。
māṃsaśoṇitapaṅkinyo ghorarūpāḥ sudāruṇāḥ|
nadīḥ pravartayāmāsuḥ soṇitaughavivardhinīḥ|| // 8-47-33 //
（33）肉と血の泥の、恐ろしい様相の、きわめて凄まじい川。血の流れが膨らむ川が生じた。
bhīruvitrāsakāriṇyaḥ śūrāṇāṃ harṣavardhanāḥ|
tā nadyo ghorarūpāstu nayantyo yamasādanam|| // 8-47-34 //
（34）臆病者を恐れさせ、勇者の喜びを増す、恐ろしい様相の、死の世界へ連れて行く川が――。
avagāḍhān majjayantyaḥ kṣatrasya ajanayan bhayam|
kravyādānāṃ naravyāghra nardatāṃ tatratatra ha|| // 8-47-35 //
（35）浸る者を沈めて、クシャトリヤに恐怖を与えた。あちこちで吠える、人食い獣たちがいた。
ghoramāyodhanaṃ jajñe pretarājapuropamam|
utthitāny agaṇeyāni kabandhāni samantataḥ|| // 8-47-36 //
（36）死の王の都のごとく、恐ろしい戦場が生じた。首なしの胴体が無数に立ち上がった。
nṛtyanti vai bhūtagaṇāḥ sutṛptā māṃsaśoṇitaiḥ|
pītvā ca śoṇitaṃ tatra vasāṃ bhuktvā ca bhārata|| // 8-47-37 //
（37）肉と血に飽きるまで満足した霊たちの群れが踊っていた。そこで血を飲み、バーラタよ、脂肪を食べ――。
medomajjāvasāmattāstṛptā māṃsasya caiva ha|
dhāvamānāḥ sma dṛśyante kākagṛdhrabakās tathā|| // 8-47-38 //
（38）脂肪・髄・脂を食らい、肉にも満足していた。
śūrāstu samare rājan bhayaṃ tyaktvā sudustyajam|
yodhavratasamākhyātāś cakruḥ karmāṇyabhītavat|| // 8-47-39 //
（39）戦士の誓いに従う者たちは、恐れることなく業を行なった。
śaraśaktisamākīrṇe kravyādagaṇasaṅkule|
vyacaranta raṇe śūrāḥ khyāpayantaḥ svapauruṣam|| // 8-47-40 //
（40）矢・槍で満ち、人食い獣たちでごった返す戦場で、勇者たちは自らの武勇を示しながら動き回った。
anyonyaṃ śrāvayanti sma nāmagotrāṇi bhārata|
pitṛnāmāni ca raṇe gotranāmāni vā vibho|| // 8-47-41 //
（41）互いに名前や血統を告げ合った、バーラタよ、戦場で父の名、血統の名、また――。
śrāvayāṇāś ca bahavas tatra yodhā viśāmpate|
anyonyamavamṛdrantaḥ śaktitomarapaṭṭasaiḥ|| // 8-47-42 //
（42）そう告げ合う多くの戦士たちが、国王よ、槍・投槍・短槍で互いを打ち砕いた。
vartamāne tathā yuddhe ghorarūpe sudāruṇe|
vyaṣīdat kauravī senā bhinnā naur iva sāgare|| || // 8-47-43 //
（43）このように恐ろしく、きわめて凄まじい戦いが進むなか、クル族の軍は、海の中で割れた船のように沈んだ。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe saptacatvāriṃśo'dhyāyaḥ|| 47 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十七章は終わる。
