マハーバーラタ ― カルナ篇 第24章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 24 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ24」（ドゥルヨーダナがシャリヤにトリプラ＝三都市の魔神たちの物語を語り始め、天の神々がルドラ神に救いを求めて讃歌を捧げる場面）です。各段落は原典の詩節番号（8-24-N）と和訳の段落番号が対応しています。
karṇaparva — caturviṃśo'dhyāyaḥ (24)
第24章　ドゥルヨーダナがシャリヤにトリプラ（三都市）の物語を語り始める——天の神々がルドラ神を讃える
duryodhana uvāca|
bhūya eva tu madreśa yattvā vakṣyāmi tacchṛṇu|
yathā purāvṛttamidaṃ yuddhe devāsure prabho|| // 8-24-1 //
ドゥルヨーダナは語った。 （1）「マドラの王よ、もう一つ聞いてくれ、これからお前に語ることを。かつて天と阿修羅の戦いで起きたことだ。
yaduktavānpiturmahyaṃ mārkaṇḍeyo mahātapāḥ|
bruvatas tadaśeṣeṇa mama rājarṣisattama|
nibodha manasā cātra na te kāryā vicāraṇā|| // 8-24-2 //
（2）偉大な苦行者マールカンデーヤが私の父の前で語ったことを、王仙の中の最上者よ、余すところなく聞いてくれ。心に留めて、疑うな。
'samutpanno hi rājānaḥ pramoha iti niścayam|
kṛtvā caiva vyavasyanti sarve dharmārthaniścayān|| // 8-24-3 //
（3）王たちの間に混乱が生まれた時、彼らは確信を得てから、すべての法と利のことを決定する。
devānāmasurāṇāṃ ca mahānāsītsamucchrayaḥ|
saiṃhikeyās tadodvṛttā vibudhānavasūdayan|
te nirastaḥ kṛtā devairdānavā balagarvitāḥ'|| // 8-24-4 //
（4）天の神々と阿修羅たちの大いなる戦いがあった。シンヒカーの子ら（ラーフの一族）が増長して天の神々を苦しめた。しかし力に驕る悪魔たちは、天の神々に追い払われた。
tatrāsītprathamo rājan saṅgrāmas tārakāmayaḥ|
nirjitāś ca tato daityā daivatairiti naḥ śrutiḥ|| // 8-24-5 //
（5）王よ、その最初の戦争はターラカーマヤ（ターラカにまつわる戦い）と呼ばれた。その戦いで悪魔たちは天の神々に打ち負かされたと伝えられている。
bhagnadarpā nirutsāhāḥ pātālaṃ viviśus tadā|| // 8-24-6 //
（6）意気消沈し、やる気を失った彼らは、地底界（パーターラ）に入り込んだ。
nirjiteṣu ca daityeṣu tārakasya sutās trayaḥ|
tārākṣaḥ kamalākṣaś ca vidyunmālī ca pārthiva|| // 8-24-7 //
（7）悪魔たちが打ち負かされた後、ターラカの三人の息子——ターラークシャ、カマラークシャ、ヴィデュンマーリン——が立ち上がった。
tapa ugraṃ samāsthāya niyame parame sthitāḥ|
tapasā karṇayāmāsur dehāṃs tāñ śatrukarśanāḥ|| // 8-24-8 //
（8）彼らは激しい苦行を行い、最上の戒律に身を置き、苦行によって敵を滅ぼす者たちは己の体を消耗させた。
damena tapasā caiva niyamena samādhinā|
teṣāṃ pitāmahaḥ prīto varadaḥ pradadau varam|| // 8-24-9 //
（9）自制と苦行と戒律と瞑想によって——彼らに祖父神ブラフマーが喜び、恩寵として望みを与えた。
avadhyatvaṃ ca te sarve sarvabhūteṣu sarvadā|
sahitā varayāmāsaḥ sarvalokapitāmaham|| // 8-24-10 //
（10）彼ら全員は声を合わせて、あらゆる生き物に対する不死身をすべての世界の祖父神に求めた。
tānabravīttadā devaḥ sarvalokaguruḥ prabhuḥ|
nāsti sarvāmaratvaṃ vai nivartadhvam ito'surāḥ|
anyaṃ varaṃ vṛṇīdhvaṃ vai rocate yādṛśo hi vaḥ|| // 8-24-11 //
（11）すると神は、すべての世界の師であり主である方は彼らに言った。『完全な不死というものはない。阿修羅たちよ、引き返せ。望むような別の恩寵を選ぶがよい。』
tatas te sahitā rājan sampradhārya asakṛd bahuḥ|
sarvalokeśvaraṃ vākyaṃ praṇamya enamathā'bruvan|| // 8-24-12 //
（12）そこで彼らは一緒に何度も相談し、すべての世界の主に敬礼して言った。
vastum icchāma nagaraṃ kartuṃ kāmagamaṃ śubham|
sarvakāmasamṛddhārtham avadhyaṃ devadānavaiḥ||
yakṣarakṣoragagaṇair nānājātibhir eva ca|
na kṛtyābhir na śastraiś ca na śāpairbrahmavādinām|
vadhyeta tripuraṃ deva prayaccheḥ prapitāmaha|| // 8-24-13-14 //
（13〜14）『我らは都市に住み、思いのままに動き回れる美しい都市を作りたい。あらゆる望みが満たされ、天の神にも悪魔にも、夜叉・羅刹・蛇族・様々な種族にも、呪術にも武器にも、バラモンの呪いにも滅ぼされないトリプラ（三都市）を、偉大なる祖父よ、お与えください。
vayaṃ purāṇi trīṇyeva samāsthāya mahīmimām|
vicariṣyāma loke'smiṃs tvatprasādapuraskṛtāḥ|| // 8-24-15 //
（15）我らは三つの都市に住んで、この大地を巡り歩きましょう。あなたの恩恵を受けて。
tato varṣasahasreṣu sameṣyāmaḥ parasparam|
ekībhāvaṃ gabhiṣyanti purāṇyetāni cānagha|| // 8-24-16 //
（16）そして千年の後に、都市は再び一つに集まるでしょう。
samāgatāni caitāni yo hanyād bhagavāṃs tadā|
ekeṣuṇā devavaraḥ sa no mṛtyurbhaviṣyati|| // 8-24-17 //
（17）集まったこれらの都市を、至高の神が一本の矢で滅ぼすことができれば——その方こそ我らの死となるでしょう。』」
duryodhana uvāca|
teṣāṃ tad vacanaṃ śrutvā dānavānāṃ pitāmahaḥ|
evam astv iti tāndevaḥ pratyuktvā prāviśad divam|| // 8-24-18 //
ドゥルヨーダナは語った。 （18）「悪魔たちのこの言葉を聞いて、祖父神は『そのようにあれ』と答え、天に帰った。
te tu labdhavarāḥ prītāḥ sampradhārya parasparam|
puratrayavisṛṣṭyarthaṃ mayaṃ vavrurmahārathāḥ|
viśvakārmāṇamajaraṃ daityadānavapūjitam|| // 8-24-19 //
（19）恩寵を得て喜んだ彼らは、互いに相談し、三都市の建設のために、悪魔・ダーナヴァ族に崇められる不老の天工マヤを選んだ。
tato mayaḥ svatapasā cakre dhīmānpurāṇi ca|
trīṇi kāñcanamekaṃ vai raupyaṃ kārṣṇāyasaṃ tathā|| // 8-24-20 //
（20）そこで叡智あるマヤは己の苦行の力によって三つの都市を作った——一つは黄金、一つは銀、一つは鉄で。
kāñcanaṃ divi tatrāsīdantarikṣe ca rājatam|
āyasaṃ cābhavadbhaumaṃ tadā teṣāṃ parantapa|| // 8-24-21 //
（21）黄金の都市は天に、銀の都市は空中に、鉄の都市は地上にあった、敵を滅ぼす者よ。
ekaikaṃ yojanaśataṃ vistṛtaṃ tāvadāyatam|
dṛḍhaṃ cāṭṭālakayutaṃ bṛhatprākāratoraṇam|| // 8-24-22 //
（22）それぞれ百ヨージャナの幅と長さがあり、堅固で、見張り塔を備え、大きな城壁と門を持っていた。
gṛhapravarasambādhamasambādhamahāpatham|
prāsādairvividhaiścāpi dvāraiś caivopaśobhitam|| // 8-24-23 //
（23）最上の家々が密集し、広い大通りがあり、さまざまな宮殿と門で飾られていた。
tripuraṃ teṣu cāpyāsanrājāno vai pṛthakpṛthak|
divyamālyāmbaradharā daiteyā rājasattama|| // 8-24-24 //
（24）三都市にはそれぞれ別々の王がいた。神聖な花輪と衣をまとった悪魔の王たち。
kāñcanaṃ tārakākṣasya divyamāsīnmahātmanaḥ|
rājataṃ kamalākṣasya vidyunmālina āyasam|| // 8-24-25 //
（25）黄金の都市は偉大なるターラークシャのもの、銀の都市はカマラークシャのもの、鉄の都市はヴィデュンマーリンのものであった。
trayas te daityarājānas trī~llokānāśu tejasā|
ākramya tasthur ūcuś ca kaś ca nāma prajāpatiḥ|| // 8-24-26 //
（26）この三人の悪魔の王たちは、その威光によって三界を支配し、『プラジャーパティ（創造神）など何者か』と言い放った。
teṣāṃ dānavamukhyānāṃ prayutānyarbudāni ca|
koṭyāścāprativīrāṇāṃ samājagmus tatastataḥ|| // 8-24-27 //
（27）彼ら無敵の悪魔の王たちのもとに、何百万、何億、何兆という者たちがあちこちから集まった。
māṃsāśinaḥ sudṛptāś ca surairvinikṛtāḥ purā|
mahadaiśvaryam icchantas tripuraṃ durgamāśritāḥ|| // 8-24-28 //
（28）肉食で高慢で、かつて天の神々に打ち負かされた者たち——偉大な権力を望みつつ、難攻不落のトリプラに身を寄せた。
sarveṣāṃ ca punaś ca eṣāṃ sarvayogavaho mayaḥ|
tamāśritya hi te sarve'vartayannakutobhayāḥ|| // 8-24-29 //
（29）そして、これらすべての者にあらゆる便宜を図るのがマヤであった。マヤを頼みにして、彼らは皆、何も恐れずに暮らしていた。
yo hi yaṃ manasā kāmaṃ dadhyau tripurasaṃśrayaḥ|
tasmai tasmai mayas taṃ taṃ vidadhe māyayā tadā|| // 8-24-30 //
（30）トリプラに住む者が心に望むものは何であれ、マヤがその幻術によって与えてくれた。
tārakākṣasutaś cāsīd varir nāma mahābalaḥ|
tapas tepe paramakaṃ yenātuṣyat pitāmahaḥ|| // 8-24-31 //
（31）ターラークシャの息子にハリという大力の者がいて、最上の苦行を行い、祖父神を満足させた。
santuṣṭamavṛṇoddevaṃ vāpī bhavatuḥ naḥ pure|
śastrair vinihatā yatra kṣiptāḥ syurbalavattarāḥ|| // 8-24-32 //
（32）彼は神に願った——『我らの都市に泉を設けてください。武器で殺されてその泉に投げ込まれた者が、より強くなって蘇る泉を。』
sa tu labdhvā varaṃ vīras tārakākṣasuto hariḥ|
sasṛje tatra vāpīṃ tāṃ mṛtasañjīvinīṃ prabho|| // 8-24-33 //
（33）恩寵を得た勇者ハリは、ターラークシャの子は、その都市に死者蘇生の泉を作った。
yena rūpeṇa yo daityo yena veṣeṇa cāpyatha|
kṣipyate nihato vāpyāṃ tādṛśena eva jāyate|
sampūrṇabalavīryas tu rājañ chauryasamanvitaḥ|| // 8-24-34 //
（34）どのような姿で、どのような装いの悪魔が殺されて泉に投げ込まれようとも、そのままの姿で、完全な力と武勇と勇気を持って蘇った。
evaṃ vīryeṇa saṃyuktāṃ kṛtāṃ tena mahātmanā|
tāṃ prāpya traipurā vāpīṃ lokānsarvānbabādhire|| // 8-24-35 //
（35）このように力を備え、偉大なる魂が作ったその泉を得て、トリプラの住民たちはあらゆる世界を苦しめた。
mahatā tapasā siddhāḥ surāṇāṃ bhayavardhanāḥ|
ekasminnihate daitye sṛjanti sma daśāsurān|
na teṣāṃ vidyate yuddhe kṣayo rājan kathañcana|| // 8-24-36 //
（36）偉大な苦行によって力を得、天の神々の恐怖を増大させる彼らは、一人の悪魔が殺されると十人の阿修羅を生み出した。王よ、彼らは戦場で決して減ることがなかった。
tatas te lobhamohābhyām abhibhūtā vicetasaḥ|
nirbhīkāḥ sahitāḥ sarve sthāpitāḥ samalolupāḥ|| // 8-24-37 //
（37）そこで彼らは、貪欲と妄執に圧倒されて正気を失い、恐れもなく一致団結して、貪欲にまみれた。
vidrāvya sagaṇān devāṃs tatratatra tadātadā|
viceruḥ svena kāmena varadānena darpitāḥ|| // 8-24-38 //
（38）恩寵に驕り、己の意のままに、あちこちで天の神々とその従者を追い払い、好き勝手に振る舞った。
devodyānāni sarvāṇi sthānāni ca divaukasām|
ṛṣīṇām āśramān puṇyān ramyāñ janapadāṃs tathā|
utsādayanta maryādāṃ dānavā duṣṭacāriṇaḥ|| // 8-24-39 //
（39）天の神々のすべての庭園と住処、聖仙たちの清浄な隠遁所、美しい国土——悪夢の行いをする悪魔たちはすべての秩序を破壊した。
niḥsthānāś ca kṛtā devā ṛṣayaḥ pitṛbhiḥ saha|
daityais tribhis trayo lokā hyākrāntās taiḥ suretaraiḥ|| // 8-24-40 //
（40）天の神々も聖仙も祖霊たちも住処を追われた。三人の悪魔による三つの都市が三界を占拠した。
pīḍyamāneṣu lokeṣu tataḥ śakro marudvṛtaḥ|
purāṇyāyodhayāñcakre vajrahastaḥ samantataḥ|| // 8-24-41 //
（41）世界が苦しめられる中、インドラはマルト群神を率い、金剛杵を手にして都市にあらゆる方面から攻撃を加えた。
nāśakattānyabhedyāni yadā bhettuṃ purandaraḥ|
purāṇi varadattāni dhātrā tena narādhipa|| // 8-24-42 //
（42）しかしプランダラ（インドラ）は、ブラフマーの恩寵によって守られた、破壊不能なこれらの都市を破ることができなかった、王よ。
tadā bhītaḥ surapatirmuktvā tāni purāṇyatha|
taireva vibudhaiḥ sārdhaṃ pitāmaham arindama|
jagāma atha tadākhyātuṃ viprakāraṃ suretaraiḥ|| // 8-24-43 //
（43）そこで恐れた天の王インドラは、都市への攻撃をやめ、天の神々とともに祖父神ブラフマーのもとへ行き、敵を滅ぼす者よ、人間ならざる者たちの非道を報告した。
te tattvaṃ sarvamākhyāya śirobhiḥ sampraṇamya ca|
tad vadhopāyamācakṣva bhagavanniti cābruvan|| // 8-24-44 //
（44）彼らはすべての真実を述べ、頭を垂れて敬礼し、『彼らを殺す方法を教えてください、至高の者よ』と言った。
śrutvā tadbhagavāndevo devān idam uvāca ha|
śrūyatāṃ tridaśāḥ sarve yathedaṃ vākyagauravam|| // 8-24-45 //
（45）聞き終えた至高の神は天の神々にこう言った。『聞くがよい、すべての天の神々よ、この言葉の重みを。
durātmāno'surā nityaṃ te cāpi vibudhā mama|
na śaknuvanti te (ye) sarve yuṣmānvai pīḍayanti te|| // 8-24-46 //
（46）悪の魂を持つ阿修羅たちも、また天の神々であるお前たちも、共に我が子である。彼らはお前たちを苦しめているが、お前たちすべてを殺す力は持っていない。
ahaṃ samas tu sarveṣāṃ bhūtānāṃ nātra saṃśayaḥ|
avinītā nihantavyā ityevaṃ prabravīmi vaḥ|| // 8-24-47 //
（47）私はすべての生き物に対して平等である、これに疑いはない。しかし無法な者は滅ぼされるべきだ——このように私はお前たちに告げる。
ekeṣuṇā (hi) vibhedyāni tāni durgāṇi nānyathā|
śaktas tu tāni bāṇena bhettuṃ kāmaṃ trilocanaḥ|| // 8-24-48 //
（48）あの要塞は一本の矢で破壊されねばならない。それ以外の方法はない。あの都市を矢で破壊できる力を持つのは三つ目の神（シヴァ）だ。
te yūyaṃ sthāṇumīśānaṃ jiṣmumakliṣṭakāriṇam|
yoddhāraṃ vṛṇuta kṣipraṃ sa tānhantā suretarān|| // 8-24-49 //
（49）お前たちは急いでスターヌ（動かざる者）、イーシャーナ（支配者）、困難なきことをなし遂げる勝利者を戦士として選ぶがよい。彼こそが人間ならざる敵を滅ぼすだろう。』
te devās tena vākyena coditāḥ praṇatāḥ sthitāḥ|
divyaṃ varṣasahasraṃ vai tapas taptvā surarṣabhāḥ|
śubhātmāno mahātmāno jagmurvai vṛṣabhadhvajam|| // 8-24-50 //
（50）この言葉に促された天の神々は、敬礼して立ち、神聖な千年の苦行を行い、天の神々の中の雄牛たちは、清らかな魂と偉大な魂を持って、牛の旗印を持つ方（シヴァ）のもとへ行った。
brahmāṇamagrataḥ kṛtvā śaraṇyaṃ śaraṇāgatāḥ|
tapaḥ paramamājagmurgṛṇanto brahma śāśvatam|| // 8-24-51 //
（51）ブラフマーを先頭にして、守護者に守護を求める者として、最上の苦行に赴き、永遠のブラフマンを唱えた。
anaṅgamathanaṃ sarve bhavaṃ sarvātmanā gatāḥ|
devadevaṃ paraṃ sthāṇuṃ varadaṃ tryambakaṃ śivam|| // 8-24-52 //
（52）すべての者は全身全霊でバヴァ（シヴァ）のもとへ行った——カーマ（愛の神）を焼いた者、天の神の中の神、至高のスターヌ、恩寵を与える者、トリヤンバカ（三つ目の者）、シヴァ（吉祥なる者）に。
śarvamīḍyamajaṃ rudraṃ śaśāṅkāṅkitamūrdhajam|
tuṣṭuvur vāgbhir ugrābhir bhayeṣvabhayamacyutam|
sarvātmānaṃ mahātmānaṃ yenāptaṃ viśvamātmanā|| // 8-24-53 //
（53）シャルヴァ、讃えるべき者、生まれざる者、ルドラ、三日月を頂に戴く者——彼らは最上の言葉をもって讃えた。恐れある時に恐れなきアチュタ（不動の者）、万物の魂にして偉大な魂、自らによって万物を満たした方を。
tapoviśeṣairvividhairyogaṃ yo veda cātmanaḥ|
yaḥ sāṅkhyamātmanā vetti yasya cātmā veśe sadā|| // 8-24-54 //
（54）さまざまな特別の苦行によってヨーガを知り、サーンキヤを自ら知り、常に自らを制している方——
taṃ te dadṛśurīśānaṃ tejorāśimumāpatim|
'pareṇa yatnena bhavaṃ tridaśāḥ śarvamīśvaram'|
ananyasadṛśaṃ loke pratapantamakalmaṣam|| // 8-24-55 //
（55）彼らはイーシャーナを見た。光の集まりなるウマーの夫を。三十三の天の神々は最上の努力をもってバヴァ、シャルヴァ、イーシュヴァラを見た——世に類いなき、輝く、無垢なる方を。
ekaś ca bhagavāṃs tatra nānārūpamakalpayat|
ātmanaḥ pratirūpāṇi rūpāṇyatha mahātmani|
parasparasya cāpaśyan sarve paramavismitāḥ|| // 8-24-56 //
（56）至高の神は一人でありながら、さまざまな姿を現した。偉大な魂における自らの似姿を。互いに見合って、皆は最も驚いた。
sarvabhūtamayaṃ dṛṣṭvā tamajaṃ jagataḥ parim|
devā brahmarṣayaś caiva śirobhir dharaṇīṃ gatāḥ|| // 8-24-57 //
（57）万物からなる、生まれざる、世界の主なるこの方を見て、天の神々とブラフマンの聖仙たちは頭を大地につけた。
tān svastivācya cābhyarcya samutthāpya ca śaṅkaraḥ|
brūtabrūteti bhagavānsmayamāno'bhyabhāṣata|| // 8-24-58 //
（58）シャンカラ（吉祥をなす者）は彼らに祝福を与え、供養し、立ち上がらせて、微笑みながら言った——『語れ、語れ。私に何をしてほしいのか。』
tryambakeṇābhyanujñātās tatas te svasthacetasaḥ|
namo namo namaste'stu prabho ityabruvanbhavam|| // 8-24-59 //
（59）トリヤンバカ（三つ目の神）に許可を得て、心安らかになった彼らは言った。『主よ、あなたに何度も何度も敬礼いたします。』
namo devādhidevāya priyādhāghne'timanyave|
prajāpatimakhaghnāya prajāpatibhir īḍyate|| // 8-24-60 //
（60）『天の神々の中の神、愛する妻の敵を滅ぼす者、大いなる怒りの方、プラジャーパティの祭儀を破壊する者にして、プラジャーパティたちに讃えられる方に敬礼いたします。
namaḥ stutāya stutyāya stūyamānāya śambhave|
vilohitāya rudrāya nīlagrīvāya śūline|| // 8-24-61 //
（61）讃えられる方、讃えるべき方、讃えられつつある方シャンブ（吉祥者）に、ヴィローヒタ（赤き者）、ルドラ、青い首を持つ者、槍を持つ者に敬礼いたします。
amoghāya mṛgākṣāya pravarāyudhayodhine|
arhāya caiva śuddhāya kṣayāya krathanāya ca|| // 8-24-62 //
（62）必ず的を射る者、美しき目の者、最上の武器で戦う者、供養にふさわしい者、清浄なる者、滅びと破壊の者に敬礼いたします。
durvāraṇāya śukrāya brahmaṇe brahmacāriṇe|
īśānāyāprameyāya nihantre carmavāsase|| // 8-24-63 //
（63）制し難き者、シュクラ（白き者）、ブラフマン、梵行を守る者、イーシャーナ（支配者）、計り知れぬ者、殺す者、獣皮を着る者に敬礼いたします。
taporatāya piṅgāya vratine kṛttivāsase|
kumārapitre tryakṣāya pravarāyudhadhāriṇe|| // 8-24-64 //
（64）苦行に専念する者、赤褐色の者、誓いを守る者、獣皮を着る者、クマーラ（スカンダ神）の父、三つ目の者、最上の武器を持つ者に敬礼いたします。
prapannārtivināśāya brahmadviṭsaṅghaghātine|
vanaspatīnāṃ pataye vanānāṃ pataye namaḥ|| // 8-24-65 //
（65）帰依する者の苦しみを取り除く者、ブラフマンの敵の群れを滅ぼす者、森の木々の主、森の主に敬礼いたします。
gavāṃ ca pataye nityaṃ yajñānāṃ pataye namaḥ|
namo'stu te sasainyāya tryambakāya amitaujase|
manovākkarmabhir deva tvāṃ prapannānbhajasva naḥ|| // 8-24-66 //
（66）牛の主、常に祭儀の主に敬礼いたします。軍勢を率いるトリヤンバカ、無量の力を持つ方に敬礼いたします。心と言葉と行いをもって、神よ、帰依する我らを恵み給え。』
tataḥ prasanno bhagavānsvāgatenābhinandya ca|
provāca vyetu vas trāso brūta kiṃ karavāṇi vaḥ|| // 8-24-67 //
（67）すると至高の神は喜び、歓迎の言葉をもって迎え、言った。『お前たちの恐れを去らせよう。何をしてほしいのか、語れ。』
'devāḥ śarvasya vacanaṃ śrutvā harṣamupāgatāḥ'|| || // 8-24-68 //
（68）天の神々はシャルヴァの言葉を聞いて喜びに満たされた。」
iti śrīmanmahābhārate karṇaparvaṇi caturviṃśo'dhyāyaḥ|| 24 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十四章は終わる。
