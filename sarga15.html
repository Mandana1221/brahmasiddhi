kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

pañcadaśaḥ sargaḥ ― 第十五章

逃走する軍勢をシヴァの息子スカンダが長い演説で鼓舞し、シヴァとともに軍を制止する（1–33）。シヴァとアルジュナの矢の戦い（34–53）。本章はヤマカ（音戯）詩節が多く、詩人バーラヴィの技巧が際立つ。
1
Sanskrit
atha bhūtāni vārtraghna- śarebhyas tatra tatrasuḥ / bheje diśaḥ parityakta- maheṣvāsā ca sā camūḥ //
Anuṣṭubh
和訳
さて、そこでは生きとし生けるものがインドラの子の矢を恐れて震え上がり、かの軍勢は大弓を投げ捨てて四方に逃げ散った。
2
Sanskrit
apaśyadbhir iveśānaṃ raṇān nivavṛte gaṇaiḥ / muhyatīva hi kṛcchreṣu sambhramajvalitaṃ manaḥ //
Anuṣṭubh
和訳
あたかも主（シヴァ）を見失ったかのように、ガナ（群衆）たちは戦場から退いた。苦境にあっては心は困惑に燃え立ち、迷妄に陥るものだからである。
3
Sanskrit
khaṇḍitāśaṃsayā teṣāṃ parāṅmukhatayā tayā / āviveśa kṛpā ketau kṛtoccairvānaraṃ naram //
Anuṣṭubh
和訳
希望を打ち砕かれた彼らの潰走を見て、旗竿に高く猿（ハヌマーン）を掲げた英雄（アルジュナ）の心に哀れみが湧いた。
4
Sanskrit
āsthām ālambya nīteṣu vaśaṃ kṣudreṣv arātiṣu / vyaktim āyāti mahatāṃ māhātmyam anukampayā //
Anuṣṭubh
和訳
卑しい敵が力を尽くして屈服させられた時、偉大な者たちの高潔さは哀れみによってこそ明らかになる。
5
Sanskrit
sa sāsiḥ sāsusūḥ sāso yeyāyeyāyayāyayaḥ / lalau līlāṃ lalo 'lolaḥ śaśīśaśiśuśīḥ śaśan //
Anuṣṭubh
和訳
剣を帯び、矢を放つ弓を持ち、弓を携えたその英雄は、到るべき所にも到りがたい所にも馳せゆく者、揺るがぬ者として、月を戴く神（シヴァ）の子（スカンダ）を悩ませつつ跳躍し、優美な戯れを示した。
一音節ごとの語が韻律の制約上極めて凝縮されたekākṣarapāda（一文字脚）の例。sāsiḥ＝剣を持つ者、sāsusūḥ＝矢を放つ者、sāsaḥ＝弓を持つ者。śaśīśaśiśuśīḥ＝月神（シヴァ）の子スカンダを殺す者。Cappellerは「金や象の収入を持つ王子として」とも解する。
6
Sanskrit
trāsajihmaṃ yataś caitān mandam evānviyāya saḥ / nātipīḍayituṃ bhagnān icchanti hi mahaujasaḥ //
Anuṣṭubh
和訳
恐怖でよろめきながら逃げる彼らを、彼（アルジュナ）はゆっくりと追った。偉大な力を持つ者は、打ち破られた者をあまりに苦しめようとはしないからである。
7
スカンダ（軍神）の演説
Sanskrit
athāgre hasatā sāci- sthitena sthirakīrtinā / senānyā te jagadire kiṃcidāyastacetasā //
Anuṣṭubh
和訳
そこで先頭にいた不動の栄光を持つ将軍（スカンダ）が、微笑みつつも少し心を痛めながら、脇に立って彼ら（ガナたち）にこう語りかけた。
senānī（将軍）はスカンダの別名。パールヴァティーの子にして軍神。nirauṣṭhya（唇音なし）の技法で書かれた詩節。

スカンダ
Sanskrit
mā vihāsiṣṭa samaraṃ samarantavyasaṃyataḥ / kṣataṃ kṣuṇṇāsuragaṇair agaṇair iva kiṃ yaśaḥ //
Anuṣṭubh
和訳
「戦場を捨てるな、遊戯と戦いを等しく楽しむ者たちよ。アスラの軍勢を粉砕した汝らが、取るに足らぬ者のように名声を傷つけてどうするのか。」

スカンダ
Sanskrit

スカンダ
Sanskrit
pātitottuṅgamāhātmyaiḥ saṃhṛtāyatakīrtibhiḥ / gurvīṃ kām āpadaṃ hantuṃ kṛtam āvṛttisāhasam //
Anuṣṭubh
和訳
「高みから落とされ、広く知れた名声を奪われた汝ら、いかなる重大な災いを避けるために、退却という暴挙に出るのか。」

スカンダ
Sanskrit
nāsuro 'yaṃ na vā nāgo dharasaṃstho na rākṣasaḥ / nā sukho 'yaṃ navābhogo dharaṇistho hi rājasaḥ //
Anuṣṭubh
和訳
「この者はアスラでもなく、地底に住むナーガでもなく、ラークシャサでもない。たやすい相手ではないが、若々しい力に満ち、地上に立つ、激質（ラジャス）の人間にすぎない。」
gomūtrikā（牛の尿の如きジグザグ配列）のヤマカ技法。十六のマス目を交互に読み替えることで二つの異なる文が現れる。

スカンダ
Sanskrit
mandam asyann iṣulatāṃ ghṛṇayā munir eṣa vaḥ / praṇudaty āgatāvajñaṃ jaghaneṣu paśūn iva //
Anuṣṭubh
和訳
「あの聖仙（アルジュナ）は哀れみから、蔓のような矢をゆるやかに放ちつつ、やって来た者を侮蔑して、汝らの背中を家畜のように追い立てているのだ。」

スカンダ
Sanskrit
na nonanunno 'nunneno na nā nānānanā nanu / nunno 'nunno na nunneno nānenānunnanun na nut //
Anuṣṭubh
和訳
「卑しき者に傷つけられた者は男ではない。卑しき者を傷つける者もまた男ではない、さまざまな顔を持つ汝らよ。主が傷つけられぬ限り、傷ついた者も傷つかぬも同然。重傷者をさらに打つ者は罪なきにあらず。」
ekavyañjana（単一子音）の技法。na音のみで構成される。マッリナータ注に詳細な語の分解が示される。

スカンダ
Sanskrit
varaṃ kṛtadhvastaguṇād atyantam aguṇaḥ pumān / prakṛtyā hy amaṇiḥ śreyān nālaṃkāraś cyutopalaḥ //
Anuṣṭubh
和訳
「美徳を示した後にそれを失う者より、まったく美徳のない者のほうがましだ。もともと宝石のない飾りのほうが、宝石が落ちてしまった飾りより優れている。」
16
スカンダ
Sanskrit
syandanā no caturagāḥ surebhā vāvipattayaḥ / syandanā no ca turagāḥ surebhāvā vipattayaḥ //
Anuṣṭubh
和訳
「ここには速き戦車も、敏捷な馬も、轟く象も、無敵の優れた歩兵もいるではないか。」
上下の半詩節が同じ音で構成されながら、ヤマカによって異なる意味を表す。syandanāは「速い者」と「戦車」、turagāḥは「馬」、surebhāḥは「良い象」と「美しき声の」の二義。

スカンダ
Sanskrit
bhavadbhir adhunārāti- parihāpitapauruṣaiḥ / hradair ivārkaniṣpītaiḥ prāptaḥ paṅko durutsahaḥ //
Anuṣṭubh
和訳

スカンダ
Sanskrit

Sanskrit

スカンダ
Sanskrit
nanu ho mathanā rāgho ghorā nāthamaho nu na / tayadātavadā bhīmā mābhīdā bata dāyata //
Anuṣṭubh

pratilomānulomapāda。逆読みで同じ詩節になる技法。

スカンダ
Sanskrit

スカンダ
Sanskrit
niśitāsirato 'bhīko nyejate 'maraṇā rucā / sārato na virodhī naḥ svābhāso bharavān uta //
Anuṣṭubh

スカンダ
Sanskrit

Anuṣṭubh

スカンダ
Sanskrit
devākānini kāvāde vāhikāsvasvakāhi vā / kākārebhabhare kākā nisvabhavyavyabhasvani //

神々を奮い立たせ、小競り合いに満ち、交替で戦の重荷を担い合い、発情した象の群れが突き進み、臆病者も勇者もともに覆い尽くす——

pranṛttaśavavitrasta- turagākṣiptasārathau / mārutāpūrṇatūṇīra- vikruṣṭahatasādini //

ardhabhramaka（半回転）のチトラバンダ。

スカンダ
Sanskrit
āsure lokavitrāsa- vidhāyini mahāhave / yuṣmābhir unnatiṃ nītaṃ nirastam iha pauruṣam //
Anuṣṭubh

29
Sanskrit
iti śāsati senānyāṃ gacchatas tān anekadhā / niṣidhya hasatā kiṃcit tatra tasthe 'ndhakāriṇā //
Anuṣṭubh
和訳
将軍（スカンダ）がこのように訓戒している間、アンダカの敵（シヴァ）は微笑みながら、四方に逃げ散る者たちを制止して、そこに立っていた。
30
Sanskrit
munīṣudahanātaptāṃl lajjayā nivivṛtsataḥ / śivaḥ prahlādayāmāsa tān niṣedhahimāmbunā //
Anuṣṭubh
和訳
聖仙（アルジュナ）の矢の炎に焼かれ、恥じて退こうとする彼らを、シヴァは「止まれ」という制止の冷たい水で蘇らせた。
「矢の炎」と「制止の冷水」の対比によるrūpaka（隠喩）。
31
Sanskrit
dūnās te 'ribalād ūnā nirebhā bahu menire / bhītāḥ śitaśarābhītāḥ śaṃkaraṃ tatra śaṃkaram //
Anuṣṭubh
和訳
打ちのめされ、敵の力に及ばず、声を失い、恐れ、鋭い矢に追い詰められた彼らは、そこでシャンカラ（シヴァ）をまことのシャンカラ（幸福をもたらす者）と深く敬った。
śaṃkaraの語を「シヴァ」と「幸福をもたらす者」の二義に掛けたシュレーシャ。
32
Sanskrit
maheṣujaladhau śatror vartamānā duruttare / prāpya pāram iveśānam āśaśvāsa patākinī //
Anuṣṭubh
和訳
敵の矢の大海に漂い、渡りがたい苦境にあった軍勢は、主（シヴァ）に辿り着いて、あたかも彼岸に達したかのように安堵の息をついた。
33
Sanskrit
sa babhāra raṇāpetāṃ camūṃ paścād avasthitām / puraḥ sūryād upāvṛttāṃ chāyām iva mahātaruḥ //
Anuṣṭubh
和訳
彼（シヴァ）は、戦場から退いて背後に控える軍勢を支えた。あたかも大樹が、太陽から背を向けた自らの影を支えるように。
34
Sanskrit
muñcatīśe śarāñ jiṣṇau pinākasvanapūritaḥ / dadhvāna dhvanayann āśāḥ sphuṭann iva dharādharaḥ //
Anuṣṭubh
和訳
主（シヴァ）がジシュヌ（アルジュナ）に向けて矢を放つと、ピナーカ弓の音に満ちた山（インドラキーラ）は、四方を轟かせながら、今にも裂けんばかりであった。
35
Sanskrit
tadgaṇā dadṛśur bhīmaṃ citrasaṃsthā ivācalāḥ / vismayena tayor yuddhaṃ citrasaṃsthā ivācalāḥ //
Anuṣṭubh
和訳
シヴァのガナたちは、さまざまな形の山々のように、絵に描かれたかのごとく微動だにせず、驚嘆しながら二人の恐るべき戦いを見つめた。
citrasaṃsthāḥを「さまざまな形の」と「絵に描かれた如く不動の」の二義に掛けたシュレーシャ。acalāḥも「山」と「不動の」の両義。
36
Sanskrit
parimohayamāṇena śikṣālāghavalīlayā / jaiṣṇavī viśikhaśreṇī parijahre pinākinā //
Anuṣṭubh
和訳
修練と軽やかな技をもって幻惑するピナーキン（シヴァ）によって、ジシュヌ（アルジュナ）の矢の列は打ち払われた。
37
Sanskrit
avadyan patriṇaḥ śambhoḥ sāyakair avasāyakaiḥ / pāṇḍavaḥ paricakrāma śikṣayā raṇaśikṣayā //
Anuṣṭubh
和訳
パーンドゥの子（アルジュナ）は、致命的な矢でシャンブの矢を砕きながら、武技への意欲と戦いの熟練をもって戦場を駆け巡った。
38
Sanskrit
cāracuñcuś cirārecī cañcaccīrarucā rucaḥ / cacāra ruciraś cāru cārair ācāracañcuraḥ //
Anuṣṭubh
和訳
歩法に長じ、長く敵を払い除け、ひるがえる樹皮衣の輝きに照り映えるかの輝かしき者は、戦の作法に精通し、美しき歩みで麗しく進んだ。
dvyakṣara（二子音）の技法。caとraの二子音のみで構成される。
39
Sanskrit
sphuratpiśaṅgamaurvīkaṃ dhunānaḥ sa bṛhaddhanuḥ / dhṛtolkānalayogena tulyam aṃśumatā babhau //
Anuṣṭubh
和訳
赤褐色に閃く弦を持つ大弓を振るう彼は、松明の炎を掲げた太陽のように輝いた。
40
Sanskrit
pārthabāṇāḥ paśupater āvavrur viśikhāvalim / payomuca ivārandhrāḥ sāvitrīm aṃśusaṃhatim //
Anuṣṭubh
和訳
プリターの子（アルジュナ）の矢は、パシュパティ（シヴァ）の矢の群れを覆った。隙間なき雨雲が太陽の光の束を覆うように。
41
Sanskrit
śaravṛṣṭiṃ vidhūyorvīm udastāṃ savyasācinā / rurodha mārgaṇair mārgaṃ tapanasya trilocanaḥ //
Anuṣṭubh
和訳
三つ目の神（シヴァ）は、サヴヤサーチン（アルジュナ）が放った矢の雨を払いのけ、自らの矢で太陽の道をも遮った。
42
Sanskrit
tena vyātenire bhīmā bhīmārjanaphalānanāḥ / na nānukampya viśikhāḥ śikhādharajavāsasaḥ //
Anuṣṭubh
和訳
彼（シヴァ）によって放たれた恐るべき矢は、恐怖を滅ぼす力を持ち、孔雀の羽で飾られ、哀れみをもって——非情にではなく——放たれた。
43
Sanskrit
dyuviyadgāminī tāra- saṃrāvavihataśrutiḥ / haimīṣumālā śuśubhe vidyutām iva saṃhatiḥ //
Anuṣṭubh
和訳
天空と大気を貫き、高き響きで耳を聾するその黄金の矢の連なりは、稲妻の群れのように輝いた。
44
Sanskrit
vilaṅghya patriṇāṃ paṅktiṃ bhinnaḥ śivaśilīmukhaiḥ / jyāyo vīryaṃ samāśritya na cakampe kapidhvajaḥ //
Anuṣṭubh
和訳
シヴァの矢が自分の矢の列を突き破って突き刺さっても、猿の旗を持つ者（アルジュナ）は、優れた武勇の力に頼って、動じなかった。
45
Sanskrit
jagatīśaraṇe yukto harikāntaḥ sudhāsitaḥ / dānavarṣīkṛtāśaṃso nāgarāja ivābabhau //
Anuṣṭubh
和訳
世界の主との戦いに臨み、獅子のように輝き、清らかに白く、施しの雨で願いを叶える彼は、山の王（ヒマラヤ）のように、あるいは象の王（アイラーヴァタ）のように、あるいは蛇の王（シェーシャ）のように輝いた。
三義を含むśleṣa。(a) アルジュナを山の王ヒマヴァットに、(b) インドラの象アイラーヴァタに、(c) 蛇王シェーシャに喩える。harikāntaは「獅子の如く美しい」「インドラの愛する」「クリシュナの友」の三義。Cappellerの注釈がこの三重の意味を詳述する。
46
Sanskrit
viphalīkṛtayatnasya kṣatabāṇasya śambhunā / gāṇḍīvadhanvanaḥ khebhyo niścacāra hutāśanaḥ //
Anuṣṭubh
和訳
シャンブ（シヴァ）に努力を無にされ、矢を砕かれたガーンディーヴァの弓手（アルジュナ）の感覚器官から、火焔が噴き出した。
47
Sanskrit
sa piśaṅgajaṭāvaliḥ kirann urutejaḥ parameṇa manyunā / jvalitauṣadhijātavedasā himaśailena samaṃ vididyute //
Viyoginī（Vaitālīya）
和訳
赤褐色の螺髪の列をなびかせ、至高の怒りをもって巨大な光焔を放つ彼は、薬草と山火事の火に燃えるヒマラヤ山のように輝いた。
48
Sanskrit
śataśo viśikhān avadyate bhṛśam asmai raṇavegaśāline / prathayann anivāryavīryatāṃ prajigāyeṣum aghātukaṃ śivaḥ //
Viyoginī（Vaitālīya）
和訳
シヴァは、戦いの勢いに秀でたこの者（アルジュナ）の矢を幾百と砕きながら、自らの制し難き武勇を示しつつ、殺傷力なき矢を放った。
49
Sanskrit
śambhor dhanurmaṇḍalataḥ pravṛttaṃ taṃ maṇḍalād aṃśum ivāṃśubhartuḥ / nivārayiṣyan vidadhe sitāśvaḥ śilīmukhacchāyavṛtāṃ dharitrīm //
Upajāti
和訳
シャンブの弓の円弧から飛び出す矢——太陽の円盤から射す光のような——を防ごうとして、白馬の主（アルジュナ）は矢の影で大地を覆い尽くした。
50
Sanskrit
ghanaṃ vidāryārjunabāṇapūgaṃ sasārabāṇo 'yug alocanasya / ghanaṃ vidāryārjunabāṇapūgaṃ sasāra bāṇo 'yugalocanasya //
Upendravajrā
和訳
密集するアルジュナの矢の群れを突き破り、奇数の眼を持つ神（シヴァ）の、力と音を兼ね備えた矢は突き進んだ。密集するアルジュナの矢の束を貫いて、奇数の眼の神の矢は、アルジュナ樹やバナナやビンロウの茂みの中へ飛び込んだ。
上下の半詩節はほぼ同音だが語の分割（padaccheda）を変えることで異なる意味が生じる。arjunaは「アルジュナ」と「アルジュナ樹」、bāṇaは「矢」と「バナナ」、pūgaは「群れ」と「ビンロウ樹」。
51
Sanskrit
rujan pareṣūn bahudhāśupātino muhuḥ śaraughair apavārayan diśaḥ / calācalo 'neka iva kriyāvaśān maharṣisaṃghair bubudhe dhanaṃjayaḥ //
Vaṃśastha
和訳
速射する敵の矢を幾度も砕き、矢の群れで四方を覆い尽くす、激しく動き回るダナンジャヤ（アルジュナ）は、その多様な戦技の故に、大聖仙たちの群れには幾人もいるかのように見えた。
52
Sanskrit
vikāśam īyur jagatīśamārgaṇā vikāśam īyur jagatīśamārgaṇāḥ / vikāśam īyur jagatīśamārgaṇā vikāśam īyur jagatīśamārgaṇāḥ //
Vaṃśastha
和訳
大地の王（アルジュナ）の矢は広がった。世界の主（シヴァ）の矢は挫折した。ダイティヤを滅ぼすガナたちは歓喜した。シヴァを見ようとする天の探索者たちは天空に飛び立った。
四つの脚がすべて同じ音（vikāśam īyur jagatīśamārgaṇāḥ）でありながら、語の分割を変えることで四つの異なる意味を生じさせる。バーラヴィのヤマカ技法の極致。mārgaṇaは「矢」「探索者」、jagatīśaは「大地の主」「世界の主」「ダイティヤを滅ぼす者」。
53
Sanskrit
sampaśyatām iti śivena vitāyamānaṃ lakṣmīvataḥ kṣitipates tanayasya vīryam / aṅgāny abhinnam api tattvavidāṃ munīnāṃ romāñcam añcitataraṃ bibharāmbabhūvuḥ //
Vasantatilakā
和訳
シヴァによってかくも引き出された栄光ある国王の息子（アルジュナ）の武勇を目の当たりにして、真理を知る聖仙たちの身体は、傷つけられてもいないのに、激しく持続する歓喜の総毛立ちに覆われた。
マッリナータ注：真理を知る聖仙（tattvavid）たちはアルジュナがシヴァの化身であることをすでに知っており、それでもなおその武勇に総毛立つ。況んや他の者をやとの含意。Cappellerも「すでにアルジュナの神性を知る聖仙たちですら」と解する。
iti bhāravikṛtau mahākāvye kirātārjunīye pañcadaśaḥ sargaḥ //
