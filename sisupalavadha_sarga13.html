त्रयोदशः सर्गः

第十三章　クリシュナの歓迎と入城（svāgata-praveśa-varṇana）
韻律：sumaṅgalī（スマンガリー）/ makṣubhāṣiṇī　13音節/pāda
V.1
Sanskrit (IAST) yamunāmatītamatha śuśruvānamuṃ tapasastanūja iti nādhunocyate / sa yadācalannijapurādaharniśaṃ nṛpatestadādi samacāri vārtayā //
和訳

「彼がヤムナー河を渡り終えた」と苦行者の子（ダルマラージャ）が今さら聞いたとは言えない。なぜなら彼（クリシュナ）が自分の都を出発してから昼夜絶えず、王のもとへは報せの使いが通っていたからである。

注

【Vallabhadeva】

tapasas tanūjaḥ は「ダルマの息子」すなわちユディシュティラ。彼が出発の日から毎日逐一、消息を得ていたことを述べ、ヤムナー渡河を「今聞いた」とは言えないと巧みに表現する。韻律はこの章全体が sumaṅgalī（「dvigau sajau mahagurū」）。

【Mallinātha】

atha は「ヤムナー渡河の後」。tapasas tanūjaḥ は dharmanandana（法の子＝ユディシュティラ）。śuśruvān は bhāṣāyāṃ sad-avasa-śruvaḥ による ka-su 接尾辞。vārtayā samacāri（報せによって行き来があった）は bhāve luṅ 構文。韻律は makṣubhāṣiṇī（「sajasā jagau」の定義による）。

V.2
Sanskrit (IAST) yadubharturāgamanalabdhajanmanaḥ pramadādamāniva pure mahīyasi / sahasā tataḥ sa sahito 'nujanmabhirvasudhādhipo 'bhimukhamasyaniryayau //
和訳

ヤドゥ族の主の来訪によって生まれた歓喜のために、広大な都の中にすら容まりきれぬかのように、直ちに弟たちを伴い、地の王（ダルマラージャ）はクリシュナに面と向かって城を出た。

注

【Vallabhadeva】

yadubhartuḥ（ヤドゥ族の主＝クリシュナ）の到来により生じた歓喜で、体が膨れ上がるかのように広大な都にも容まりきれないという修辞。anujanmabhiḥ は弟たち（ビーマ等）。abhimukham は「面前へ」。

【Mallinātha】

pramadāt は harṣāt（歓喜から）。mahīyasi pure は「広大な都においても」。amān は「容まらぬ」で、喜びによる身体の膨張を暗示する utprekṣā（想像的比喩）。anujanmabhiḥ（弟たち）と共に niryyau は「城を出た」。

V.3
Sanskrit (IAST) rabhasapravṛttakurucakradundubhidhvanibhirjanasya badhirīkṛtaśruteḥ / samavādi vaktṛbhirabhīṣṭasaṅkathāprakṛtārthaśeṣamatha hastasaṃjñayā //
和訳

歓喜に打ち鳴らされたクル軍の太鼓の轟音に聴覚を奪われた人々は、語り手たちが望みの話題について語りかけた残りの部分を、ついには手振りで伝え合った。

注

【Vallabhadeva】

rabhasa は harṣa（歓喜）の意。クリシュナ到来の喜びで打ち鳴らされた dundubhi（太鼓）の響きで聴覚が奪われ、話の残りを手の合図で伝えたとする情景描写。

【Mallinātha】

rabhasa は「歓喜」（rabhaso vegaharṣayoḥ）。kurucakradundubhi は「クル軍陣の太鼓」。badhirīkṛtaśruteḥ は「耳を聾せしめられた」。hastasaṃjñayā は「手の合図で」。耳が聾になったために手話を用いる因果関係を述べるのは kāvyaliṅga 修辞の一種。

V.4
Sanskrit (IAST) apadāntaraṃ ca paritaḥ kṣitikṣitāmapatandrutabhramitahemanemayaḥ / javimārutāñcitaparasparopamakṣitireṇuketuvasanāḥ patākinaḥ //
和訳

王たちの周りを隙間なく、黄金の車輪を勢いよく回転させながら駆け抜ける旗を立てた戦車群が、疾走する風に靡いて互いに似通った砂塵と旗布をまとって走り去った。

注

【Vallabhadeva】

apadāntaram は「隙間なく」（saṃsaktam）。hemanemayaḥ は「黄金の車輪縁をもつ」戦車群。javimāruta（速い風）によって靡かされた kṣitireṇu（地の砂塵）と ketu（旗）と vasana（布）が互いに似る（parasparopama）とする修辞。

【Mallinātha】

kṣitikṣitām は kṣitiṃ kṣiyantīti kṣitikṣitaḥ kṣitīśāḥ で「国王たち」。hemanemayaḥ は「金の車輪縁をもつ」（cakradhārā pradhir nemiḥ）。parasparopama は「互いに似ている」、すなわち砂塵と旗が同色で見分けがつかない。tulyayogitā と upameyopamā の修辞を含む。

V.5
Sanskrit (IAST) drutamadhvanannupari pāṇivṛttayaḥ paṇavā ivāśvacaraṇakṣatā bhuvaḥ / nanṛtuśca vāridharadhīravāraṇadhvanihṛṣṭakūjitakalāḥ kalāpinaḥ //
和訳

馬の蹄に打たれた大地は、掌で叩かれた小太鼓のように速いテンポで響いた。そして雲のように重々しい象の鳴声に興じた孔雀たちは、美しい声で鳴きながら舞い踊った。

注

【Vallabhadeva】

druta は「速いテンポ」（三種の拍子 druta, madhya, vilambita の一つ）。upari pāṇivṛttayaḥ は「上面を掌で打つ」奏法をもつ小太鼓に喩える。kalāpinaḥ は孔雀（barhin）で、雷雲と象の鳴声の両方に喜んで踊るとする二重の upamā。

【Mallinātha】

aśvacaraṇakṣatāḥ bhuvaḥ は「馬蹄に打たれた大地」。paṇavāḥ iva は「小太鼓のように」。vāridharadhīravāraṇadhvani は「雨雲のように重々しい象の鳴声」で、孔雀は雷鳴に喜んで踊る習性をもつ。二つの upamā の saṃsṛṣṭi（混合）がある。

V.6
Sanskrit (IAST) vrajatorapi praṇayapūrvamekatāṃ kukurādhināthakururājasainyayoḥ / ruruṣe viṣāṇibhiranukṣaṇaṃ mitho madamūḍhabuddhiṣu vivekitā kutaḥ //
和訳

ククラ族の主とクル王の両軍が友愛をもって合流しつつあったにもかかわらず、両軍の象たちは牙を突き合わせて絶え間なく争った。発情に理性を失った者に分別など、どうしてあろうか。

注

【Vallabhadeva】

kukurādhinātha は yaduapti（ヤドゥ族の主）すなわちクリシュナ、kururāja はユディシュティラ。両軍が友好的に合流する中、発情した象は牙で互いに争う。madamūḍhabuddhi は「発情で理性を失った」。主人たちの友好にもかかわらず象が争うのは咎めるに値しないとする arthāntaranyāsa。

【Mallinātha】

vrajator は両軍の属格双数。viṣāṇibhiḥ は「牙を持つ者たち＝象」。ruruṣe は bhāve liṭ（受動完了）。madena mūḍhabuddhiṣu（発情で理性を失った者たちにおいて）vivekitā（分別）kutaḥ（どこにあろう）は arthāntaranyāsa 修辞。◆ GRETILは asurāripāṇḍusutasainyayos と読むが、両注とも kukura/kuru の複合語を支持する。

V.7
Sanskrit (IAST) avaloka eva nṛpateḥ sma dūrato rabhasādrathādavatarītumicchataḥ / avatīrṇavānprathamamātmanā harirvinayaṃ viśeṣayati sambhrameṇa saḥ //
和訳

遠くから姿を認めただけで、王が急いで戦車から降りようとするよりも先に、クリシュナ自ら真っ先に降り立ち、恭敬の礼を際立たせた。

注

【Vallabhadeva】

nṛpateḥ は属格（genitive absolute）で、ダルマラージャが降りようとするよりも先にクリシュナが自ら降車した、という場面。sambhramena vinayaṃ viśeṣayati は「恭敬を際立たせた」。

【Mallinātha】

dūrataḥ avaloke（遠方での一瞥だけで）、rabhasāt は harṣāt（歓喜から）。prathamamātmanā avatīrṇavān は「自ら先に降りた」。sambhrameṇa は「敬意に満ちた急ぎ」。これによりハリの pūjyaviṣaya（尊敬すべき対象への）raty-ākhya bhāva（愛情の情態）が暗示される。

V.8
Sanskrit (IAST) vapuṣā purāṇapuruṣaḥ puraḥ kṣitau paripuñjyamānapṛthuhārayaṣṭinā / bhuvanairnato 'pi vihitātmagauravaḥ praṇanāma nāma tanayaṃ pitṛṣvasuḥ //
和訳

永遠の至上者たるクリシュナは、三界から礼拝されながらも自らの威厳を示し、地面の前に太い首飾りの紐を山と重ねるほどの身体をもって、叔母の息子（ダルマラージャ）に公然と礼拝した。

注

【Vallabhadeva】

purāṇapuruṣaḥ は「永遠の至上者」すなわちパラマートマン。pitṛṣvasuḥ tanayam は「父の姉妹（クンティー）の息子」。bhuvanaiḥ nataḥ api（三界に礼拝されながらも）praṇanāma（礼拝した）は virodhābhāsa（矛盾の外見）の修辞。

【Mallinātha】

paripuñjyamānapṛthuhārayaṣṭinā は「太い首飾りの紐が積み重なるような（身体をもって）」。bhuvanaiḥ nataḥ api vihitātmagauravaḥ は「三界に礼拝されながらも自尊を打ち立てた」で、尊ぶべき者への礼拝が逆に威厳を高めるという vicitra 修辞。nāma は「公然と」の意。praṇanāma は pra+√nam の完了形。

V.9
Sanskrit (IAST) mukuṭāṃśurañjitaparāgamagrataḥ sa na yāvadāpa śirasā mahītalam / kṣitipena tāvadanapekṣitakramaṃ bhujapañjareṇa rabhasādagṛhyata //
和訳

冠の光輝で黄金に染めた塵をまとって、クリシュナがまだ額を地面に着けぬうちに、王は順序も構わず勢いよく両腕の籠でかれを抱きしめた。

注

【Vallabhadeva】

mukuṭāṃśubhiḥ（冠の光で）rañjitaparāgam（塵を染めた）前方の大地に、クリシュナが額をつける前に王に抱きしめられた。anapekṣitakramaṃ は「順序を構わず」、すなわち礼拝の完了を待たずに抱擁した。◆ Vallabhadeva は avilambitakramam と読む。

【Mallinātha】

na āpa は「触れなかった」。anapekṣitakramam は「手順を無視して」。bhujapañjareṇa は「腕の檻で」という比喩。rabhasāt は vegāt（勢いで）。礼拝の所作が完了する前に抱き上げ抱擁したという情景。

V.10
Sanskrit (IAST) na mamau kapāṭataṭavistṛtaṃ tanau muravairivakṣa urasi kṣamābhujaḥ / bhujayostathāpi yugalena dīrghayorvikaṭīkṛtena parito 'bhiṣasvaje //
和訳

門扉のように広い敵魔ムラの仇（クリシュナ）の胸は、地の王（ダルマラージャ）の細身の胸には容まらなかった。それでも長い両腕を大きく広げ、四方からかれを抱擁した。

注

【Vallabhadeva】

kapāṭataṭavistṛtam は「門扉の面のように広い」。クリシュナの胸がダルマラージャの細身の胸には容まりきらないが、長い両腕を vikaṭīkṛtena（大きく広げて）四方から抱擁した。これによりダルマラージャの ājānubāhutva（膝まで届く長腕）とクリシュナの胸の広さが示される。

【Mallinātha】

muravairivakṣaḥ は「ムラの仇（クリシュナ）の胸」。na mamau は「容まらなかった」。vikaṭīkṛtena は「大きく広げた」。paritaḥ abhiṣasvaje は「四方から抱擁された」。クリシュナの胸の広大さに対して atiyukti（誇張）の修辞がある。◆ GRETILは muravairimavakṣa と余分な ma を含み14音節になる誤り。

V.11
Sanskrit (IAST) gatayā nirantaranivāsamadhyuraḥ parinābhi nūnamavamucya vārijam / kururājanirdayanipīḍanābhayānmukhamadhyarohi muravidviṣaḥ śriyā //
和訳

胸に絶えず住み着いていた美（ラクシュミー）は、臍のあたりの蓮華を離れて胸へと移り、クル王（ユディシュティラ）の容赦ない強い抱擁を恐れて、きっとクリシュナの顔へと上ったのだろう。

注

【Vallabhadeva】

śrī（美＝ラクシュミー）は臍の蓮華（vārija）を離れ、胸（uraḥ）に住み着いていたが、ユディシュティラの激しい抱擁を恐れて顔に上った。前世でヴィシュヌの臍に蓮華があったことを背景にした重層的修辞。nūnam は utprekṣā（想像的比喩）を示す。

【Mallinātha】

parinābhi（臍のあたり）の vārijam（蓮華＝臍蓮華）を離れ、adhyuraḥ（胸に）nirantaranivāsam（絶えず住むために）移った śrī（美/ラクシュミー）が、kururājanirdayanipīḍanā（クル王の容赦なき圧迫＝抱擁）を恐れて顔に上った。śrī の語が śobhā（美）と Ramā（ラクシュミー）の二義を兼ねる śleṣa に基づく paryāya 修辞。◆ GRETILは kurarāja と読むが、両注とも kururāja を支持。

V.12
Sanskrit (IAST) śirasi sma jighrati surāribandhane chalavāmanaṃ vinayavāmanaṃ tadā / yaśaseva vīryavijitāmaradrumaprasavena vāsitaśiroruhe nṛpaḥ //
和訳

かつて阿修羅（バリ）を縛るために偽りの矮躯を装った御方（ヴィシュヌ）が、今は恭敬によって身を低くしている——その頭を、武勇で勝ち取ったパーリジャータの花で芳しくなった髪をもつ王（ユディシュティラ）は、あたかも名声によって薫らされたかのように嗅いだ。

注

【Vallabhadeva】

surāribandhane（阿修羅を縛るために）chalavāmanam（偽りの矮躯＝ヴァーマナ化身）であった方が、今は vinayavāmanam（恭敬による矮躯＝身をかがめている）。王は帰還した者の頭を嗅ぐ（jighrati）習わしに従う。

【Mallinātha】

chalavāmanam は「詐りによるヴァーマナ（矮小の姿）」（バリ縛りのための化身）。vinayavāmanam は「恭敬によるヴァーマナ」（礼拝で身を低くする姿）。vāsitaśiroruhe は「パーリジャータ花で薫じた髪の」。yaśasā iva は utprekṣā（想像的比喩）で、あたかも栄誉の芳香で薫らされたかのように。旅から帰った者の頭を嗅ぐ慣習（pravāsādetya mūrdhanyavaghraṇam）を背景にする。

V.13
Sanskrit (IAST) sukhavedanāhṛṣitaromakūpayā śithilīkṛte 'pi vasudevajanmani / kurubharturaṅgalatayā na tatyaje vikasatkadambanikurumbacārutā //
和訳

ヴァースデーヴァ（クリシュナ）との抱擁が解かれた後も、快楽の感覚に逆立った毛穴をもつクル王の身体の蔓は、咲き誇るカダンバの花房のような美しさを失わなかった。

注

【Vallabhadeva】

vasudevajanmani（ヴァスデーヴァの子）が śithilīkṛte（離された）後も、抱擁の快楽（sukhavedanā）で鳥肌が立ち続け、カダンバ花房の美しさを失わなかった。抱擁の余韻の描写。Vallabhadeva は vikasatkadamba を vidalatkadamba と読む。

【Mallinātha】

vasudevajanmani は「ヴァスデーヴァの子＝ヴァースデーヴァ（クリシュナ）」（janma が後置される bahuvrīhi）。sukhavedanā（快楽の体験）により hṛṣita（逆立った）romakūpa（毛穴）をもつ aṅgalatā（身体の蔓）から、kadambanikurumba（カダンバ花房）の cārutā（美しさ）が離れなかった。原因と結果の叙述による vibhāvanā 修辞。◆ GRETILは nikuramba と読むが nikurumba が正。

V.14
Sanskrit (IAST) itarānapi kṣitibhujo 'nujanmanaḥ pramanāḥ pramodapariphullacakṣuṣaḥ / sa yathocitaṃ janasabhājanocitaḥ prasabhoddhṛtāsurasabho 'sabhājayat //
和訳

喜びに心を弾ませ、歓喜に目を輝かせた弟たちをも、万民の敬崇にふさわしく、力ずくで阿修羅の一族を引き抜いたクリシュナは、それぞれにふさわしく歓待した。

注

【Vallabhadeva】

kṣitibhujaḥ anujanmanaḥ は「王の弟たち」（ビーマ、アルジュナ等）。prasabhoddhṛtāsurasabhaḥ は「力ずくで阿修羅の軍勢を根絶した者」。asabhājayat は「歓待した」（sabhāj 使役、āliṅganādibhiḥ ānandayāmāsa）。ビーマには先に挨拶し、アルジュナには微笑みをもって、マードレーヤ（双子）には抱擁をもって——yathocitam の意。

【Mallinātha】

janasabhājanocitaḥ は「万人の崇敬にふさわしい」。pramanāḥ は「心喜ぶ」。pramodapariphullacakṣuṣaḥ は「歓喜に満開の目をもつ」。asabhājayat は caurādika（第十類）活用形の luṅ で「歓待した」。

V.15
Sanskrit (IAST) samupetya tulyamahasaḥ śilāghanānghanapakṣadīrghatarabāhuśālinaḥ / pariśiśliṣuḥ kṣitipatīnkṣitīśvarāḥ kuliśātpareṇa girayo girīniva //
和訳

同等の威光をもち、石のように堅固で、翼のように長大な腕を備えた王たちが、一斉に近寄って互いの王たちを抱擁した——雷電（の後）山々が山々を抱くように。

注

【Vallabhadeva】

tulyamahasaḥ は「同じ威光をもつ」。śilāghanān は「石のように堅固な」。ghanapakṣadīrghatarabāhuśālinaḥ は「翼のように長い腕をもつ」。kuliśātpareṇa（雷電の後に）girayo girīniva は「山が山を抱くように」——かつて翼を切られた山の比喩。◆ GRETILは samapetya と読むが、Vallabhadeva は samupetya を支持。

【Mallinātha】

samam etya は「一斉に近づいて」。śilā iva ghanān（石のように堅固な者たちを）。ghanaiḥ pakṣaiḥ iva dīrghatara-bāhubhiḥ は「堅い翼のように長い腕で」。kuliśāt pareṇa は「雷電（ヴァジュラ）の後で」——かつてインドラが山の翼を切断した後、残った山体同士が抱き合うかのような upamā。pariśiśliṣuḥ は √śliṣ の完了形。

V.16
Sanskrit (IAST) ibhakumbhatuṅgaghaṭitetaretarastanabhāradūravinivāritodarāḥ / pariphullagaṇḍaphalakāḥ parasparaṃ parirebhire kukurakauravastriyaḥ //
和訳

象の額瘤のように高くそびえ互いに密着した乳房の重みで腹が遠く隔てられ、頬の面が喜びに輝いて——ククラ族とカウラヴァ族の女たちは互いに抱き合った。

注

【Vallabhadeva】
