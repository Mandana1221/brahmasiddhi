षोडशः सर्गः

第十六章　使者との対話
Metre: Vaitālīya (mātrā-vṛtta) — V.1–79; mixed metres V.80–85
V.1
Sanskrit (IAST) damaghoṣasutena kaścana pratiśiṣṭaḥ pratibhānavānatha / upagamya hariṃ sadasyadaḥ sphuṭabhinnārthamudāharadvacaḥ //
和訳

さてその後、ダマゴーシャの子シシュパーラに派遣された、弁才あるある使者が、集会においてハリに近づき、明白に二義を含む言葉を述べた。

注

【Vallabhadeva】

damaghoṣātmajena śiśupālena pratiśiṣṭaḥ = ādiṣṭaḥ（シシュパーラに命じられた）。pratibhānavān = sampratibhaḥ（機知に富む）。kaścana koʼpi dūtaḥ（ある使者が）。sadasi gatvā adaḥ etad vacaḥ harim udāharat avocata（集会にてこの言葉をハリに述べた）。sphuṭaḥ = prakaṭaḥ, bhinnaḥ = vibhaktaḥ（明白で、かつ分かれた。priya-apriya-rūpaの二義を持つ）。韻律vaitālīya。半等韻（ardhasamaṃ vṛttam）。

【Mallinātha】

atha saṃnāhānantaraṃ（武装の後）damaghoṣasutena śiśupālena pratiśiṣṭaḥ = prahitaḥ（派遣された）。pratibhānavān = avaasarocitottarasphuraṇaśaktimān（機に応じた応答力を持つ者）。kaścana kaścit dūtaḥ（ある使者が）。hariṃ kṛṣṇam upagamya（クリシュナに近づいて）sadasi sabhāyāṃ（集会において）sphuṭabhinnārtham（明白に二義ある）vacaḥ udāharat = vyāharat（言葉を述べた）。この章の韻律はvaitālīya（「ṣaḍ bhrame aṣṭau same kalāś ca same syur nirantarāḥ…」との定義）。全章を通じ各偈がpriya（好意）とapriya（敵意）の二義を同時に持つśleṣa（掛詞）の技法で構成される。

V.2
Sanskrit (IAST) abhidhāya tadā tadapriyaṃ śiśupālo 'nuśayaṃ paraṃ gataḥ / bhavato 'bhimanāḥ samīhate saruṣaḥ kartumupetya mānanām //
和訳

【好意】あのとき不快な言葉を口にしたシシュパーラは深い後悔に陥り、熱望を抱いて怒りを収め、やって来てあなたを敬いたいと願っています。【敵意】彼は深い怨恨を募らせ、恐れなき心で怒りに任せてやって来て、あなたを殺そうとしています。

注

【Vallabhadeva】

【好意】śiśupālaḥ tad apriyam abhidhāya（あの不快な言葉を述べた後）param anuśayaṃ paścāttāpaṃ gataḥ（深い後悔に陥った）。abhimanāḥ = unmanāḥ tvāṃ prati utkacittaḥ（あなたに対して熱意ある心で）。mānanāṃ saṃmānaṃ kartum（敬意を表するために）。saruṣaḥ kudasyaの修飾はtavaに掛かり「怒りの消えたあなたの」。【敵意】param anuśayaṃ = krodhaṃ gataḥ（深い怨恨を抱いた）。abhimanāḥ = nirbhayacittaḥ（恐れなき心の）。mānanāṃ = pūjāṃ roṣasya（怒りの栄誉＝敵の殺害）kartum（実行するために）。saruṣaḥ = sakopasya bhavataḥ（怒るあなたの）。

【Mallinātha】

【好意】śiśupālaḥ tadā arddhasvīkārakāle tad apriyam abhidhāya（あのとき不快な言葉を述べた後）param anuśayam anutāpaṃ gataḥ（深い後悔に陥った）。abhimanāḥ = utkaṇṭhitacittaḥ（渇望する心の）。upetya āgatya saruṣaḥ bhavatas tatra mānanāṃ pūjāṃ kartum samīhate（怒りを鎮めたあなたの前に来て敬意を表したいと望む）。【敵意】anuśayaṃ = dīrghadveṣam（「randhra śabde atha anuśayo dīrghadveṣānutāpayoḥ」Amara）。abhimanāḥ = niḥśaṅkacittaḥ（恐れなき心の）。mānanāṃ = hananaṃ（殺害。「mānanā hanane māne」iti Keśava）。bhavataḥ mānanāṃ = あなたを殺すことを。全14偈の使者の言葉がsphuṭabhinnārtha（明白な二義）を持つ構造。

V.3
Sanskrit (IAST) vipulena nipīḍya nirdayaṃ mudamāyātu nitāntamunmanāḥ / pracurādhigatāṅganirvṛtiṃ paritastvāṃ khalu vigraheṇa saḥ //
和訳

【好意】彼は大いなる体であなたを四方から強く抱きしめ、肢体の触れ合いの喜びをたっぷり得て、待ち焦がれていた心からの歓びを味わうでしょう。【敵意】彼は大いなる戦いであなたを容赦なく圧し潰し、あなたの体の安楽を奪い去って、至上の満足を得るでしょう。

注

【Vallabhadeva】

【好意】saḥ caidyaḥ vipulena vṛhatā vigraheṇa dehena tvāṃ paritaḥ sarvataḥ nirdayaṃ gāḍhaṃ nipīḍya āliṅgya nitāntam atyarthaṃ mudam āyātu（巨大な体であなたを四方から力いっぱい抱きしめ、このうえない歓びを味わうだろう）。unmanāḥ = utkaṇṭhitaḥ（待ち焦がれた）。pracuraṃ bahu adhigatā prāptā aṅganirvṛtiḥ（肢体の触れ合いの喜びがたっぷり得られた）。【敵意】saḥ tvāṃ vigraheṇa yuddhena nipīḍya vyathayitvā mudam āyātu（戦によりあなたを苦しめて喜ぶだろう）。unmanāḥ = manasvin（意志堅い）。pracurādhiḥ = pracurā ādhayaḥ manaḥpīḍā（多くの苦悩）gata aṅganirvṛtiṃ = vigatā śarīrasaukhyam（肉体の安楽が失われたあなたを）。

【Mallinātha】

【好意】unmanāḥ = utsukacetāḥ saḥ caidyaḥ（渇望する心の彼チェーディ王が）paritaḥ pracuraṃ yathā tathā adhigatā prāptā aṅganirvṛtiḥ suhṛtasparśakṛtam aṅgasukham（たっぷりと肢体の触れ合いの喜びを得たあなたを）。vipulena viśiṣṭapulakena（著しき鳥肌立つほどの。「pulaḥ syāt pulake nāpi pulaṃ tu vipulaianyavat」Viśva）。vigraheṇa vapuṣā nirdayaṃ gāḍhaṃ nipīḍya āliṅgya（体で力いっぱい抱きしめて）nitāntaṃ mudam āyātu（このうえない歓びを味わうだろう）。【敵意】vigraheṇa = samareṇa（戦いで。「vigrahaḥ samare kāye」Viśva）。nirdayaṃ niṣkṛpaṃ nipīḍya hatvā（容赦なく打ち殺して）mudam āyātu（歓ぶだろう）。

V.4
Sanskrit (IAST) praṇataḥ śirasā kariṣyate sakalairetya samaṃ dharādhipaiḥ / tava śāsanamāśu bhūpatiḥ paravānadya yatastvayaiva saḥ //
和訳

【好意】彼の王は全ての王たちと共にやって来て、頭を垂れて礼をし、直ちにあなたの命令に従うでしょう。今やあなたこそ彼の主なのですから。【敵意】全ての王たちと共に来た彼は、あなたに頭を下げさせ、速やかにあなたを懲罰するでしょう。あなただけが彼の唯一の敵として残っているのですから。

注

【Vallabhadeva】

【好意】saḥ caidyaḥ rājā sarvair nṛpaiḥ saha āgatya praṇataḥ san śāsanam ājñām āśu vidhāsyati（彼チェーディ王は全ての王たちと来て頭を下げ、直ちにあなたの命令を実行するだろう）。yatas tvayaiva saḥ paravān tvam eva tasya prabhuḥ（あなたこそ彼の主だから）。prabhośca ādeśo avaśyam eva kriyate（主人の命には必ず従うものだから）。【敵意】śirasā praṇataḥ = nṛpair eva praṇataḥ（王たちによって頭を下げさせられる。kartari ktaではなくkarmaṇi kta）。śāsanaṃ = nigrahaṃ kariṣyate（懲罰を行うだろう。「śāsanaṃ rājadattājñāṃ lekhājñāśāstiṣu」Viśva）。paravān = saśatruḥ（敵を持つ者＝あなただけが彼の残された敵）。

【Mallinātha】

【好意】bhūpatiḥ caidyaḥ sakalaiḥ dharādhipaiḥ samaṃ saha etya āgatya śirasā praṇataḥ（全ての王たちと来て頭を下げる。kartari kta）。āśu tava śāsanam ājñāṃ kariṣyate tvadājñākaro bhaviṣyati（直ちにあなたの命に従うだろう）。kutaḥ yataḥ saḥ caidyaḥ asmin avasare tvayaiva paravāḥ tvadekaparatantraḥ（この場においてあなただけに従属するから）。【敵意】śirasā praṇataḥ = namaskṛtaḥ, narādhipair iti bhāvaḥ（王たちによって伏させられる。karmaṇi kta）。bhūpatiḥ tava śāsanaṃ śāstiṃ śikṣāṃ kariṣyate（王があなたを懲罰するだろう）。tvayaiva paravān = tvam evaikaḥ tasya śatruḥ avaśiṣṭaḥ（あなただけが彼の唯一残った敵）。

V.5
Sanskrit (IAST) adhivahnipataṅgatejaso niyatasvāntasamarthakarmaṇaḥ / tava sarvavidheyavartinaḥ praṇatiṃ bibhrati kena bhūbhṛtaḥ //
和訳

【好意】火と太陽を凌ぐ威光を持ち、堅固な心で偉業を成し遂げ、万人が命に従うあなたに対して、どの王が敬礼しないでしょうか。【敵意】火に飛び込む蛾のような勇気しか持たず、自らの滅びに向かう無謀な行いをし、誰にでも従属するあなたに、いかなる理由で王たちが拝礼するでしょうか。

注

【Vallabhadeva】

【好意】tava ke bhūbhṛtaḥ praṇatiṃ na vibhrati, sarve api vibhratītyarthaḥ（どの王が礼をしないか＝すべての王が礼をする）。adhigataṃ vahni-pataṅgayoḥ abhibhānoḥ iva tejaḥ（火と太陽を超える光輝を得た。adhivahnipataṅga- = 火と太陽より上の）。niyatasya sthirasya svāntasya manasaḥ samarthaṃ yogyaṃ karma（堅固な心に相応しい偉業を成す）。sarve vidheyavartinaḥ ājñākāriṇaḥ（万人がその命に従う）。【敵意】adhivahni = agnau（火に対する）pataṅgasya = śalabhasya iva tejaḥ（蛾のような「勇気」。「pataṅgaḥ śalabhe bhānau」Viśva）。niyate anavyabhicāre svānte svavināśe samarthakāraṇabhūtaṃ karma（確実な自滅に向かう無謀な行い）。sarveṣāṃ vidheyavartī = sarva-kiṅkarasya niṣpauruṣasya（万人の召使い、無力な者の）。kena guṇena bhūbhṛtaḥ praṇatiṃ vibhrati = na kenāpītyarthaḥ（いかなる理由で王たちが礼をするか＝しない）。

【Mallinātha】

【好意】adhigataṃ vahni-pataṅgayoḥ abhibhānor iva tejaḥ（火と太陽を凌ぐ光輝を得た）。niyatasvāntaḥ = niyatacittaḥ（堅固な心の者）sa cāsau samarthakarmā ca（かつ偉業を成す。khaṅkuñjavad-viśeṣaṇa-samāsa）。sarve vidheyavartinaḥ vaśavartinaḥ karmakrāḥ（万人が従者となる）。ke bhūbhṛtaḥ praṇatiṃ na vibhrati = sarve api vibhratītyarthaḥ（どの王が礼をしないか＝全員がする）。【敵意】adhivahni agnau pataṅgasya śalabhasya iva tejaḥ pauruṣaṃ yasya（火中に飛び込む蛾のような勇気の者）。niyate svānte svavināśe samarthahetu-bhūtaṃ karma（自滅を招く行い）。sarvavidheyavartinaḥ sarva-kiṅkarasya niṣpauruṣasya（万人の召使い、無力な者の）。kena guṇena bhūbhṛtaḥ praṇatiṃ vibhrati（何の理由で王たちが拝礼するか＝しない）。

V.6
Sanskrit (IAST) janatāṃ bhayaśūnyadhīḥ parairabhibhūtāmavalambase yataḥ / tava kṛṣṇa guṇāstato narairasamānasya dadhatyagaṇyatām //
和訳

【好意】おおクリシュナよ、恐れなき心で敵に虐げられた人々を庇護するゆえに、比類なきあなたの徳は数え尽くせぬほどと称えられる。【敵意】おお卑しき者よ、怖いもの知らずの愚かさで、他者に見捨てられた下層民にしがみつくゆえに、誰よりも劣るあなたの「徳」は歯牙にもかけられぬ。

注

【Vallabhadeva】

【好意】he kṛṣṇa! tava tato hetor guṇāḥ śauryādayaḥ agaṇyatāṃ = asaṃkhyatvaṃ vibhrati（クリシュナよ、あなたの徳は数え切れないほど）。yataḥ paraiḥ śatrubhiḥ abhibhūtāṃ bādhitāṃ janatāṃ lokasāmūham avalambase vahasi trāyase（敵に虐げられた民を護るから）。bhayena śūnyā dhīḥ = nirbhayacittaḥ（恐れなき心）。asamānasya = sarvotkkṛṣṭatvāt（比類なき者の）。【敵意】he kṛṣṇa! = he pāpa!（卑しき者よ）。bhayaśūnyadhīḥ = mūḍhabuddhiḥ（愚かな心の）。paraiḥ tvadanyaiḥ abhibhūtām avadhīritāṃ janatāṃ（他者に見捨てられた＝蔑まれた下層民を）。pṛthagjanatvam = gopālapāratantryādinā（牧人としての卑賤さ）。asamānasya = ūnasya hīnatvāt（劣った者の）。agaṇyatām = anādraṇīyatām（歯牙にもかけられぬこと）。

【Mallinātha】

【好意】he kṛṣṇa he hare（おおハリよ）。bhayaśūnyadhīḥ = nirbhīkacittaḥ san（恐れなき心で）。paraiḥ śatrubhiḥ abhibhūtāṃ janatāṃ janasāmūham（敵に虐げられた民衆を）yataḥ avalambase parigṛhṇāsi rakṣatītyarthaḥ（庇護するゆえに）。tataḥ hetoḥ asamānasya sarvotkkṛṣṭasya（比類なき）tava guṇāḥ ārtabhūtabharaṇādayaḥ（苦しむ民を養う等のあなたの徳が）agaṇyatām = asaṃkhyayatāṃ dadhati（数え切れないほどとなる）。【敵意】he malinātmaka（汚れた者よ）。bhayaśūnyadhīḥ = mūḍhabuddhiḥ（愚昧な心の）。paraiḥ tvadanyaiḥ abhibhūtām avadhīritāṃ janatāṃ paśupālanapāratantryādinā pṛthagjanatvaṃ（牛飼いの卑しい暮らしを）yataḥ avalambase āśrayasi（拠り所とする）。tataḥ asamānasya = tatopi hīnasya（さらに劣る）tava guṇāḥ agaṇyatām = anādraṇīyatāṃ dadhati（あなたの徳は無視されるに値する）。

V.7
Sanskrit (IAST) ahitādanapatrapastrasannatimātrojjhitabhīranāstikaḥ / vinayopahitastvayā kutaḥ sadṛśonyo guṇavānavismayaḥ //
和訳

【好意】罪を恐れ、恥じらいを忘れず、敵への恐怖を完全に捨て去り、正しき信仰を持ち、礼節に満ち、徳高く、驕りなきあなたに匹敵する者が他にどこにいようか。【敵意】敵の前に震え、恥知らずで、相手にひれ伏すだけで怖がりを免れ、不信心で、礼節なく、徳なく、傲慢なあなたと同類の者が他にどこにいようか。

注

【Vallabhadeva】

【好意】tvayā sadṛśaḥ anyaḥ evaṃvidhaḥ kutaḥ guṇavān（あなたのような者が他にどこにいるか＝いない）。ahitāt = ātmahitāt pāpāt asat trasyat = akāryabhīruḥ（罪を恐れる）。anapattrapaḥ = salajjaḥ（恥を知る。否定の否定で肯定）。atimātram ujjhitā bhīḥ = atyarthom ujjhitā bhīḥ（恐怖を完全に捨てた）。anāstikaḥ = āstikaḥ, dharma-niṣṭhaḥ（信仰ある者。na + nāstika = āstika）。vinayopahitaḥ = ācāreṇa yukataḥ（礼節に満ちた）。avismayaḥ = peśalaḥ（驕りなき、慎み深い）。【敵意】ahitāt śatroḥ trasaṃ = kātaratvāt（敵を恐れる臆病者）。anapattrapaḥ = nirlajjaḥ（恥知らず）。natimātreṇa praṇāmamātreṇa ujjhitā bhīḥ（ひれ伏しただけで恐怖を免れる）。anāstikaḥ = nāstikaḥ, pāpaḥ（不信心の悪人）。vinayo nayo nītiḥ apahitaḥ（礼節が失われた）。avismayaḥ = garvī（驕慢）。arthaśleṣa（意味の掛詞）とśabdaśleṣa（音声の掛詞）のsaṅkara（混交）。

【Mallinātha】

【好意】tvayā sadṛśaḥ anyaḥ guṇavān guṇāḍhyaḥ kutaḥ（あなたに等しい有徳の者がどこにいるか）。ahitāt anarthāt trasan（不善を恐れる＝dharma-bhīru）。anapattrapaḥ = nistrapaḥ na bhavati iti anapatrapas trapāvān（恥じらいある者）。atimātram atyantam ujjhitabhīḥ = tyaktāribhayaḥ（敵の恐怖を完全に捨てた）。nāstīti matir yasyeti nāstikaḥ, sa na bhavatīty anāstikaḥ = āstikaḥ（信仰ある者。ṭhak接尾辞の二重否定）。vinayena ānauddhhatyena upahitaḥ viśiṣṭaḥ（謙虚さで飾られた）。avismayaḥ = viśiṣṭagarvaḥ na bhavatīty avismayaḥ agarvah（驕りなき者）。【敵意】上記のすべてを反転。arthaśleṣa修辞法。

V.8
Sanskrit (IAST) kṛtagopavadhūraterghnato vṛṣamugre narake 'pi saṃprati / pratipattiradhaḥkṛtainaso janatābhistava sādhu varṇyate //
和訳

【好意】牛飼い女たちに愛され、牡牛の姿の悪魔を滅ぼし、恐ろしきナラカ鬼をも討ち果たした、罪を打ち砕くあなたの行為は、人々に称えられている。【敵意】牛飼い女たちと情を通じ、聖なる牡牛を殺し、罪を重ねたあなたは、今や恐ろしい地獄の底に堕ちるべき者と、人々に語られている。

注

【Vallabhadeva】

【好意】tava ugre ghore narake dānave pratipattiḥ vadhāyānuṣṭhānam（恐ろしいナラカ鬼への征伐の行為が）janatābhiḥ sāmprati sādhu suṣṭhu varṇyate（人々により今よく称えられている）。kṛtagopavadhūrateḥ = gopānāṃ vadhūnāṃ ca ratiḥ prītiḥ（牛飼いたちとその妻たちの愛情を得た者の）。vṛṣam = dānvarūpeṇa ariṣṭasya dānavabhātrā mārayataḥ（牡牛の姿をした悪魔アリシュタを殺した者の）。adhaḥkṛtainasaḥ = puṇyavataḥ（罪を打ち砕いた＝有徳の者の）。【敵意】tava ugre narake = adhīcyādāv adhaḥ pratipattiḥ = apatanapraāptiḥ（恐ろしい地獄の底へ堕ちること）。kṛtā gopavadhūnāṃ ratiḥ kāmecchā（牛飼いの妻たちと情を通じた者＝不倫者）。vṛṣam ghnataḥ = dharmaṃ hataḥ（聖なる牡牛＝法を殺す者。vṛṣa = dharmaの意）。paradāragamana govadhaśca mahāpātakam（他人の妻との関係と牛殺しは大罪）。virudhābhāsaḥ（矛盾の見かけ）がśleṣa（掛詞）により統合される。

【Mallinātha】

和訳

この王の敵の若き妻たちは、繁栄の時にも災厄の時にも「永遠に飾られている」——体は新しい白檀で彩られ／白檀を奪われ、唇は紅で染められ／紅を引き裂かれ、眼は塗墨で澄み輝き／墨が落ちて蒼白に、腰は帯が輝き／帯を失い、豊かな胸は真珠の首飾りを得て／真珠を喪う。

注

【Vallabhadeva】

śleṣa（掛詞）——繁栄と災厄で同じ語が反対の意味を持つ。saṃpadi: navacandanena vicchittiḥ = 白檀による装飾。alaktakena adharaḥ bhinnaḥ = 紅で彩られた唇。netre patitāñjane = 塗墨された眼。acchācche = 澄んだ・輝く。śroṇyaḥ lasanmekhalāḥ = 輝く腰帯の腰。unnatakucābhogaḥ mauktikahāraṃ prāptaḥ = 豊満な胸に真珠の首飾り。āpadi: vicchittiḥ = 離別・喪失。bhinnaḥ = 引き裂かれた。patitāñjane = 墨が落ちた。acchācche = 蒼白の。a-lasan-mekhalāḥ = 帯のない。mauktikānāṃ hāraṃ = 真珠の喪失（hāra = 首飾り／喪失）。śārdūlavikrīḍitaṃ vṛttam（韻律: シャールドゥーラヴィクリーディタ）。

【Mallinātha】

saṃpatsu: vapuṣo navacandanena vicchittiḥ = viracitā, 白檀の装飾。adhara alaktakaiḥ bhinnaḥ = viśeṣitaḥ, 紅で彩られた唇。nayane patitāñjane = prāptāñjane, 塗墨された眼、ゆえに acchācche = acchaprakāre, 澄んだ。śroṇyaḥ lasanmekhalāḥ = 輝く腰帯。unnatakucābhogaḥ mauktikahāraṃ muktādāma prāptaḥ = 真珠の首飾りを得た胸。āpatsu: vicchittiḥ = viyogaḥ（離別）。bhinnaḥ = viyuktaḥ（離れた）。patitāñjane = galitakajjale（墨が流れ落ちた）, acchācche = 蒼白。a-lasan-mekhalāḥ = nirmekhalāḥ（帯を失った）。mauktikānāṃ hāraṃ mopaṃ = 真珠の喪失。nityavibhūṣaṇāḥ = 繁栄では多様な装飾をもち、災厄では装飾を失った。

V.85
Sanskrit (IAST) vinihatya bhavantam ūrjitaśrīr yudhi sadyaḥ śiśupālatāṃ yathārthām / rudatāṃ bhavadaṅganāgaṇānāṃ karuṇāntaḥkaraṇaḥ kariṣyate 'sau // 16.85 //
和訳

この威光溢れる王は、戦場で汝をたちまち打ち倒し、嘆き泣く汝の妻たちに慈悲の心をもって、その名「シシュパーラ」を真に意味あるものとするであろう——汝の遺児たちを守護することによって。

注

【Vallabhadeva】

tvāṃ saṃyati sadyaḥ māriyitvā = 汝を戦場で直ちに殺して。rājā śiśupālatāṃ yathārthāṃ kariṣyate = 王は「シシュパーラ」の名を真実のものとする。nāmānyarthaṃ vidhāsyati tvacchiśūnāṃ pālanāt = 汝の子供たちを養育することで名の意味を成就する。karuṇāntaḥkaraṇaḥ = 慈悲に満ちた心の持ち主。bhavadaṅganāgaṇānāṃ rudatām anādṛtya = 汝の妻たちが泣いているのを顧みず。bhavatkān-tāsu krandantīṣu bhavatputrān bālān iva kāruṇyād rājye rājābhiṣekṣyati = 汝の妻たちが泣くなか、慈悲から汝の幼き子らを王位に即かせるであろう。aupacchandasikaṃ vṛttam。viparyaya alaṅkāra（反語の修辞）。

【Mallinātha】

ūrjitaśrīḥ = adhikaiśvaryaḥ（卓越した繁栄の持ち主）。yudhi bhavantaṃ sadyaḥ vinihatya = 戦場で汝を直ちに打ち倒して。rudatāṃ bhavadaṅganāgaṇānām = 嘆き泣く汝の妻たちに対して。karuṇāntaḥkaraṇaḥ = kṛpāviṣṭacittaḥ（慈悲に満ちた心）。śiśupālatāṃ yathārthāṃ kariṣyate = 「シシュパーラ」（śiśu + pāla = 子の守護者）の名を真実のものとする——汝の妻たちの子供を養育することで。aṅganāgaṇānāṃ prati tacchiśupālanena nijāṃ śiśupālasaṃjñām anvarthāṃ kariṣyati = 妻たちの子供を養うことで自身の「シシュパーラ」の名称を意味ある名とする。kāvyaliṅgayoḥ saṃkaraḥ。aupacchandasikaṃ vṛttam。

॥
