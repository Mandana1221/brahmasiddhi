षष्ठः सर्गः

第六章　季節の描写（ṛtuvarṇana）

Metre: drutavilambita throughout — drutavilambitam āha nabhau bharau (12 syllables per pāda)

ライヴァタカ山上に六季が同時に現れ、ヴィシュヌを歓待する。全篇にヤマカ（音の反復装飾）を配す

V.1
Sanskrit (IAST) atha riraṃsum amuṃ yugapad girau kṛtayathāsvatarupra­savaśriyā / ṛtugaṇena niṣevitum ādadhe bhuvi padaṃ vipadantakṛtaṃ satām //
和訳

さて、山上において、それぞれの樹木に本来の花実の美をなし、楽しもうとするかのヴィシュヌに仕えるため、季節の群れは一斉にこの地上に足を踏み入れた——善き人々の災厄を終わらせる御方のもとへ。

注

【Vallabhadeva】

girauはライヴァタカ山。riraṃsumは「楽しませたい」（rab-の san 形）。vipadantakṛtamは善人の災い（生死の苦）を終わらせる者。本章の韻律はドゥルタヴィランビタ（drutavilambitam āha nabhau bharau）、全篇にわたりヤマカ（一部反復型）を配す。

【Mallinātha】

軍営布陣の後、ヴィシュヌを楽しませんとして季節の群れが各樹木に固有の花と実の美を作り出し、一斉にこの地に足を据えた。yathāsvatarupra­savaśriyāは「各自の樹に応じた花果の繁栄」。ṛtugaṇena yugapat padaṃ ādadhe——諸季節が同時に現れた。召使は好機を逃さないのが道理であると含意する。

V.2
Sanskrit (IAST) navapalāśapalāśavanaṃ puraḥ sphuṭaparāgaparāgatapāṅkajam / mṛdulatāntalatāntam alokayat sa surabhiṃ surabhiḥ sumanobharaiḥ //
和訳

みずみずしい若葉をつけたパラーシャ（紅花樹）の林が前方にあり、満開の花粉を帯びた蓮が咲き渡り、柔らかな蔓の先が萎れかけた——花の豊かさによって芳しい春の景を、かのヴィシュヌは眼にした。

注

【Vallabhadeva】

saはハリ（ヴィシュヌ）。surabhiは春（ヴァサンタ）、同時に「芳香ある」の意。navapalāśaは新鮮な若葉、palāśavanaはキンシュカ（紅花樹）の林。tāntaは「萎れた」の意とする者もあれば、「長い」とする者もある。

【Mallinātha】

先ず春を描写する。ヴィシュヌが春の姿を見た（alokayat）。surabhiは春の季節名であるとともに芳香を意味する。ヤマカは各詩脚の第一音節二字の後に三字が反復する形式。同種のヤマカの結合（sajātīyasaṃsṛṣṭi）。

V.3
Sanskrit (IAST) vilulitālakasaṃhṛtir āmṛśan mṛgadṛśāṃ śramavāri lalāṭajam / tanutaraṅgatatiṃ sarasāṃ dalat- kuvalayaṃ valayan marudāvavau //
和訳

鹿の瞳の女たちの乱れた髪を揺らし、その額に浮かぶ汗を拭い取り、池の水面にさざ波の列を立て、睡蓮を開花させながら巡り行く——そのように風は吹いた。

注

【Vallabhadeva】

マラヤ（南方山地）の風について述べる。女たちの乱れた髪を揺らすのは柔らかさの表現、額の汗を拭くのは親しさの表現、水面にさざ波を立て睡蓮を開かせるのは涼しさと芳香の表現。

【Mallinātha】

vilulitālakasaṃhṛtiは「揺れ動く髪の束」。śramavāriは汗。ā-mṛśanは「触れつつ拭う」。sarasāmは「池々の」。dalat-kuvalayamは「睡蓮が開くところの」。

V.4
Sanskrit (IAST) tulayati sma vilocanatārakāḥ kurabakastabakavyatiṣaṅgiṇi / guṇavadāśrayalabdhaguṇodaye malinimā"lini mādhavayoṣitām //
和訳

クラバカの花房に止まり、美しいものに依拠して黒さの際立ちを得た蜜蜂の黒さは、春の女たちの瞳の黒点をも比肩し得ぬものとした。

注

【Vallabhadeva】

aliは蜜蜂。そのmalinimā（黒さ）が女たちの瞳を凌いだ。クラバカの白い花房（guṇavadāśraya）に止まることで黒が際立つ。白の上の黒はより映えるのが道理。malinimāはimanic接尾辞による形。

【Mallinātha】

クラバカの花房に留まった蜜蜂が、白い花を背景に得て黒さの優位を増し、春の女たちの瞳の瞳孔をも凌駕した。tulayati smaは「同等にした」。ウパマー（直喩）の修辞。

V.5
Sanskrit (IAST) sphuṭam ivojjvalakāñcanakāntibhir yutam aśokam aśobhata campakaiḥ / virahiṇāṃ hṛdayasya bhidābhṛtaḥ kapiśitaṃ piśitaṃ madanāgninā //
和訳

輝く黄金の光沢をもつチャンパカの花に囲まれたアショーカの赤い花は、まるで裂かれた恋する者の心臓の、恋の炎に赤褐色に焼かれた肉片のように美しく輝いた。

注

【Vallabhadeva】

黄金色のチャンパカ花に囲まれて咲くアショーカの赤い花を、裂けた恋する者の心臓の焦げた肉片に見立てる。bhidābhṛtaḥは「裂けたるものを持つ」、すなわち裂かれた心臓。kapiśitaは赤褐色に変色した。

【Mallinātha】

チャンパカ群の中の満開のアショーカは、離別者の引き裂かれた心臓の、カーマの火で焦がされた肉片のごとく見えた。ウトプレークシャー（空想的比喩）。

V.6
Sanskrit (IAST) smarahutāśanamurmuracūrṇatāṃ dadhur ivāmravanasya rajaḥkaṇāḥ / nipātitāḥ paritaḥ pathikavrajān upari te paritepurato bhṛśam //
和訳

マンゴーの林の花粉の粒は、愛欲の火の火花の粉末のようになり、あたり一面に旅人の群れの頭上に降りかかり、彼らを激しく焼き苦しめた。

注

【Vallabhadeva】

マンゴーの花粉が旅人の頭上に降り注ぐと彼らは激しく苦しんだ。もし花粉がカーマの火の火花でなければ頭に落ちただけで焦がすことはあるまい——それゆえ確かにカーマの火の粉であったのだ、と推論する（ウトプレークシャー）。murmuraは微細な火花。

【Mallinātha】

āmravanasyaはマンゴー林。murmuraは「籾殻の火」（murmuḥ tuṣānalaḥ）。花粉がカーマの火花の粉と化したかのようだ、というウトプレークシャー。旅人たちは離別の苦を味わう者であるから一層苛まれる。

V.7
Sanskrit (IAST) ratipatiprahi­teva kṛtakrudhaḥ priyatameṣu vadhūr anunāyikā / bakulapuṣparasāsavapeśala- dhvanir agān niragān madhupāvaliḥ //
和訳

愛人に怒りを向ける女を宥めに遣わされたかのように——バクラの花の蜜酒に酔い甘美な唸りを響かせながら、蜜蜂の群れは飛び立っていった。

注

【Vallabhadeva】

蜜蜂の群れが飛び出した。バクラの花蜜という酒で滑らかな声を持つ。恋人に怒る女を宥めるためカーマに遣わされた花嫁のようだ——蜜蜂の唸りを聞けば拗ねた女もなだめられるから。agātとniragātのヤマカ。

【Mallinātha】

ratipatiprahi­tāはカーマに遣わされた者。蜜蜂の声を聞いて拗ねた女が怒りを捨てる——ゆえに蜜蜂は仲介者のようだ。ウトプレークシャー。anunāyikāはanunīの未来形ṇvul接尾辞。

V.8
Sanskrit (IAST) priyasakhīsadṛśaṃ pratibodhitāḥ kim api kāmyagirā parapuṣṭayā / priyatamāya vapur gurumatsara- cchidurayādur ayācitam aṅganāḥ //
和訳

親しい女友達のように、郭公の愛らしい声で何かしら言葉にし難いことを教えられて、大きな嫉妬をも砕くほどの力で、女たちは頼まれもせぬのに愛する男に身を差し出した。

注

【Vallabhadeva】

拗ねていた女たちが、郭公の声を信頼できる女友達の助言のごとく聞き、求められもしないのに自ら身を許した。kim apiは「何か不可知のもの」。matsaraは嫉妬。chidurayāはchid（断つ）のkurac接尾辞。

【Mallinātha】

郭公の声を聞いた直後に女たちが怒りを捨てたので、何か秘密の助言を受けたかのようだという推論（ウトプレークシャー）。kāmyagirāは「愛らしい声で」。ayācitamは求められずとも。

V.9
Sanskrit (IAST) madhukarair apavādakarair iva smṛtibhuvaḥ pathikāḥ hariṇā iva / kalatayā vacasaḥ parivādinī- svarajitā rajitā vaśam āyayuḥ //
和訳

鹿のごとく旅人たちは、猟師が甘い笛の音で鹿を惑わすように、蜜蜂の声の甘美さに魅了され、ヴィーナーの調べに打ち負かされて、カーマの支配下に入った。

注

【Vallabhadeva】

旅人が蜜蜂の唸りを聴き恋人を思い出してカーマに屈した。apavādakaraは猟師が鹿をだます偽声を出す者。parivādinīは七弦のヴィーナー。蜜蜂の声が音楽のようで鹿のように旅人が捕らわれたという二重の喩え。rajitāはraj（赤くする＝魅了する）のṇyanta受動形。

【Mallinātha】

蜜蜂がカーマの命を受けた猟師のごとく、ヴィーナーの調べで旅人＝鹿を魅了して虜にした。svarajitā rajitāのヤマカ。smṛtibhuvaḥは思い出を呼び起こす存在。ウパマー（直喩）の修辞。

V.10
Sanskrit (IAST) samabhisṛtya rasād avalambitaḥ pramadayā kusumāvacicīrṣayā / avinamanna rarāja vṛthoccakair anṛtayā nṛtayā vanapādapaḥ //
和訳

花を摘もうとして近づいた娘に幹をつかまれても身をかがめぬ森の樹は、いたずらに高いだけ——偽りの男らしさで輝いた。なぜなら彼女が縋っても靡かぬのだから。

注

【Vallabhadeva】

森の樹は娘に花摘みのためにつかまれても撓まなかった。ゆえに高いだけで無駄であり、偽りの男らしさを持つにすぎない。pādapa（樹）は男性名詞。anṛtayā nṛtayāは「偽りの男性性によって」というヤマカ。

【Mallinātha】

花を摘みたい女が近寄り手を伸ばしても身を屈めない——それは都会の洗練された男ではない。nṛtāは「男性たること」（puṃstvaの意、puruṣa＝nṛのtal接尾辞による抽象名詞）。恋する女に手を取られても靡かぬ者は男ですらない——虚飾にすぎぬ。

V.11
Sanskrit (IAST) idam apāsya virāgi parāgiṇīr alikadambakam amburuhāṃ tatīḥ / stanabhareṇa jitastabakānamann avalate valate 'bhimukhaṃ tava //
和訳

「花粉に厭きた蜂の群れは蓮の列を離れ去った。この若い蔓は、花房をも凌ぐ乳房の重みで身を傾けつつ、おまえの方へと向きを変える。」

注

【Mallinātha】

ある男が蜂を口実に恋人を自ら抱こうとして語りかける。V.11-13はクラカ（連結詩節）。navalatāは乳房の重みで花房の垂れた蔓に喩えられる女。蜂の群れが花粉のある蓮の列を去り、この蔓があなたの方へ向かうと言い、暗にあなたのもとへ彼女が来ると示す。

V.12
Sanskrit (IAST) surabhiṇi śvasite dadhatas tṛṣaṃ navasuddhāmadhure ca tavādhare / alam aleriva gandharasāv amū mama na saumanasau manaso mude //
和訳

「おまえの芳しい吐息に、甘露のごとく甘いおまえの唇に、渇きを覚える蜜蜂たるわたしにとって、この花々の香と蜜は心の喜びに足りない。」

注

【Mallinātha】

恋人の口元の香りと唇の甘さに渇望する蜜蜂のように、花の香と蜜では満足できないと男が語る。saumanasauは花の香と蜜（sumanas＝花）。ウパマー・アヌプラーサ・ヤマカの異種混合。V.11-13全体で「蜂の来訪を口実にした抱擁」の場面。

V.13
Sanskrit (IAST) iti gadantam anantaram aṅganā bhujayugonnamanonnatastanī / praṇayinaṃ rabhasād udaraśriyā valibhayād alibhayād iva sasvaje //
和訳

このように語る恋人を、両腕を上げて胸を高くした女は、蜂を恐れるかのように勢いよく——腹の美しさに皺を刻みつつ——抱きしめた。実は情欲のゆえに。

注

【Vallabhadeva】

valibhāは「皺を持つ女」。alibhayāt ivaは「蜂を恐れてのごとく」。実際には情欲ゆえの抱擁。V.11-13のクラカ終了。

【Mallinātha】

両腕を挙げたため胸がさらに高くなった女が恋人を抱きしめた。valibhayātとalibhayātのヤマカ。女の行為は蜂の恐怖を口実にした抱擁で、実際には恋慕ゆえのもの。「仲取り持ちの愛人に挟まれた女主人公」の類型。

V.14
Sanskrit (IAST) vadanasaurabhalobhaparibhramad- bhramarasaṃbhramasaṃbhṛtaśobhayā / calitayā vidadhe kalamekhalā- kalakalo 'lakaloladṛśānyayā //
和訳

顔の芳香に惹かれて飛び回る蜜蜂に驚き、身をよじった別の女——揺れる巻き毛の下で流し目を送る——の腰帯がかすかな鈴の音を立てた。

注

【Vallabhadeva】

別の女が蜜蜂に驚いて身をよじり、腰帯が音を立てた。kalamekhalākalakalaは「美しい腰帯のざわめき」。驚き（チャキタ）の描写。

【Mallinātha】

顔の芳しさへの貪欲さで蜜蜂が飛び回り、その慌てぶりが美しさを添えた。蜂から逃げる動きで腰帯が鳴った。アヌプラーサとヤマカの同種混合。

V.15
Sanskrit (IAST) ajagaṇan gaṇaśaḥ priyam agrataḥ praṇatam apy abhimānitayā na yāḥ / sati madhāv abhavan madanavyathā- vidhurittā dhuri tāḥ kukurastriyaḥ //
和訳

自尊心ゆえに、目の前にひれ伏す愛人をも幾度となく顧みなかったククラ族の女たちが、春が訪れると、カーマの苦しみに打ちひしがれてかえって先頭に立った。

注

【Vallabhadeva】

ヴリシュニ族の女たちは誇り高く愛人の懇願を無視していたが、春になるとカーマの苦痛に打ちのめされ、自ら率先して愛人に近づいた。dhuriは「先頭に」。

【Mallinātha】

kukurastriyaḥはヤーダヴァの女たち。gaṇaśaḥは「繰り返し」。madhauは春（チャイトラ月）。madanavyathāvidhurittā dhuriのヤマカ。

V.16
Sanskrit (IAST) kusumakārmukakārmukasaṃhita- drutaśilīmukhakhaṇḍitavigrahāḥ / maraṇam apy aparāḥ pratipedire kimu muhur muhur gatabhartṛkāḥ //
和訳

花の弓を持つカーマの弓弦に番えられた鋭い矢に体を貫かれ、夫が遠方にいる女たちは死さえ迎えた。まして繰り返し気絶したのは言うまでもない。

注

【Vallabhadeva】

夫が旅に出た女たちはカーマの矢に射抜かれ死すら迎えた。kimuは「まして言うまでもなく」。muhur muhur（繰り返し）気絶したのは当然。

【Mallinātha】

gatabhartṛkāḥは離別の女。kusumakārmukaはカーマ。śilīmukhaは矢。死を遂げるほどの苦しみ、増してや繰り返しの昏倒は言うまでもない。

V.17
Sanskrit (IAST) rurudiṣā vadanāmburuhaśriyaḥ sutanu satyam alaṅkaraṇāya te / tad api saṃprati sannihite madhāv adhigamaṃ dhig amaṅgalam aśruṇaḥ //
和訳

「美しい人よ、泣きたいという気持ちが蓮のようなおまえの顔をかえって飾るのは確かだ。しかし春が近づいた今、涙が訪れるとは——不吉なことよ。」

注

【Vallabhadeva】

ある離別の女を親族が慰める言葉。V.17-19はヴィシェーシャカ（特殊連結）を構成する。泣くことが顔を飾るのは事実だが、春の祝祭の時に涙は不吉だから泣くなと諭す。

【Mallinātha】

夫を失った女への慰撫。rurudiṣāはrud（泣く）のsan形の抽象名詞。「美しい者の変容すら美を添える」という格言を引く。adhigamaṃ dhig amaṅgalamのヤマカ。

V.18
Sanskrit (IAST) tyajati kaṣṭam asāv acirād asūn virahavednayety aghaśaṅkibhiḥ / priyatayā gaditās tvayi bāndhavair avitathā vitathāḥ sakhi mā giraḥ //
和訳

「あぁ、あの人は離別の苦しみにやがて命を捨てるだろう」と不吉を恐れる親族があなたについて語った言葉——友よ、それは偽りではないけれど、偽りにしなさい。過度に嘆くな。

注

【Vallabhadeva】

親族が愛情ゆえに不吉なことを心配して語った言葉は真実だが、それを嘘にしろ——すなわち死ぬな、という慰め。

【Mallinātha】

aghaśaṅkibhiḥは不幸を恐れる者たち。avitathā vitathāḥのヤマカ——「真実でないわけではないが、嘘にせよ」。mā giraḥは「そのような言葉を実現させるな」。

V.19
Sanskrit (IAST) na khalu dūragato 'py ativartate maham asāv iti bandhutayoditaiḥ / praṇayino niśamayya vadhūr bahiḥ svaram ṛtair amṛtair iva nirvavau //
和訳

「遠くにいても、あの人は春の祭りを見過ごすまい」と親族が語った真実の言葉を聞いた折しも、外から愛しい人の声が——甘露のごとき真実の声が聞こえ、花嫁は安らぎを得た。

注

【Vallabhadeva】

ある離別の女が真実の言葉だけで安堵した——甘露のような真実の言葉で。ṛtaiḥは「真実の」、amṛtaiḥは「甘露のごとき」——真実の声を聞いて彼女は安息を得た。偶然にも恋人が帰還して声が聞こえた。

【Mallinātha】

mahamは祭り。ṛtaiḥ amṛtaiḥ ivaのヤマカ——真実の声が甘露のごとく彼女を生き返らせた。nirvavauはvā（吹く）のliṭ、ここでは「安堵した」の意。

V.20
Sanskrit (IAST) madhurayā madhubodhitamādhavī- madhusamṛddhisamedhitamedhayā / madhukarāṅganayā muhur unmada- dhvanibhṛtā nibhṛtākṣaram ujjage //
和訳

甘美な声で——春に咲いたマーダヴィー蔓の蜜の豊かさに知恵を研ぎ澄まされ、陶酔の唸りを帯びた雌蜂が、かすかな音を立てて繰り返し歌った。

注

【Vallabhadeva】
