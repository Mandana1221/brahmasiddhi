本章は南伝（Southern Recension）テキストの「アディヤーヤ25」（天の神々がルドラ神に各自の力の半分を捧げ、ルドラがトリプラ滅ぼしの大権を得る場面）です。各段落は原典の詩節番号（8-25-N）と和訳の段落番号が対応しています。
karṇaparva — pañcaviṃśo'dhyāyaḥ (25)
第25章　天の神々がルドラに半分の力を捧げ、ルドラがトリプラ滅ぼしの大権を得る
duryodhana uvāca|
pitṛdevarṣisaṅghebhyo'bhaye datte mahātmanā|
satkṛtya śaṃkaraṃ prāha brahmā lokapitāmahaḥ|| // 8-25-1 //
ドゥルヨーダナは語った。 （1）「祖霊・天の神・聖仙の群れに安全が保証された後、世界の祖父ブラフマーはシャンカラに語った。
imānyasuradurgāṇi lokāṃs trīn ākramanti hi|
kaś ca prajāpatir ghorāṃs tān sarvāñ jahi mā ciram|| // 8-25-2 //
（2）『この阿修羅の要塞が三界を侵略している。誰がプラジャーパティ（創造神）だとうそぶく恐ろしい者どもを、速やかに討ち果たしてくれ。
varātisargāddeveśa prājāpatyamidaṃ param|
mayā'dhitiṣṭhatā datto dānavebhyo mahānvaraḥ|| // 8-25-3 //
（3）天の神の主よ、プラジャーパティの権限による恩寵の超過により、私が居ながらにして悪魔たちに偉大な恩寵を与えてしまった。
nāsty anyo yudhi teṣāṃ vai nihantā iti naḥ śrutam|
tānatikrāntamaryādānnānyaḥ saṃhartumarhati|
tvām ṛte sarvabhūteśa tvaṃ hyeṣāṃ pratyarirvadhe|| // 8-25-4 //
（4）戦場であの者たちを殺せる者は他にいないと聞いている。秩序を踏み越えた者たちを滅ぼせるのは、すべての生き物の主よ、あなたをおいてほかにない。あなたこそ彼らの殺戮における対抗者だ。
sa tvaṃ deva prapannānāṃ yācatāṃ ca divokasām|
kuru prasādaṃ varada dānavāñjahi saṃyuge|| // 8-25-5 //
（5）神よ、帰依し嘆願する天の者たちのために、恩寵を与える者よ、恵みを垂れたまえ。戦場で悪魔たちを滅ぼしたまえ。
tvatprasādājjagatsarvaṃ sukhamaidhata mānada|
śaraṇyas tvaṃ hi devānāṃ vayaṃ tvāṃ śaraṇaṃ gatāḥ|| // 8-25-6 //
（6）あなたの恩恵によってこそ、全世界は幸福に栄える、尊敬を与える者よ。あなたこそ天の神々の守護者。我々はあなたに帰依する。』」
īśvara uvāca|
hantavyāḥ śatravaḥ sarve yuṣmākamiti me matiḥ|
na tvekaścotsahe hantuṃ balinaḥ suravidviṣaḥ|| // 8-25-7 //
イーシュヴァラ（シヴァ）は語った。 （7）「『すべての敵を殺すべきだというのは我が意見でもある。しかし私一人で、力ある天の神の敵どもを殺すことはできない。
te yūyaṃ sahitāḥ sarve madīyenāpi tejasā|
jayadhvaṃ yudhi tānsarvānsaṅghātena mahābalān|| // 8-25-8 //
（8）お前たち全員が一致団結し、さらに私の力をも加えて、戦場であの強大な者たちを打ち倒すがよい。』」
devā ūcuḥ|
asmattejobalaṃ yāvat tāvad dviguṇam eva vā|
tat teṣāmiti manyāmo dṛṣṭatejobalā hi te|| // 8-25-9 //
天の神々は語った。 （9）「『我らの力の総量、あるいはその二倍——それが彼らの力に等しいと我らは考えます。彼らの力と武勇を目の当たりにしているのですから。』」
īśvara uvāca|
vadhyās te sarvathā pāpā ye yuṣmāsvaparādhinaḥ|
mama tejobalārdhena sarve mṛdgatha śātravān|| // 8-25-10 //
イーシュヴァラは語った。 （10）「『お前たちに害をなすあの悪人どもはいずれにせよ滅ぼされねばならない。我が力と武勇の半分をもって、敵を踏み潰せ。』」
devā ūcuḥ|
bibhartuṃ tava tejordhaṃ na śakṣyāma sureśvara|
sarveṣāṃ no balārdhena tvameva jahi śātravān|| // 8-25-11 //
天の神々は語った。 （11）「『天の主よ、あなたの力の半分を受け止めることは我々にはできません。我ら全員の力の半分をあなたにお渡しします。あなた自ら敵を滅ぼしてください。
vayaṃ ca sarvathā deva rakṣaṇīyās tathaiva ca|
sa no rakṣa mahādeva tvameva jahi śātravān|| // 8-25-12 //
（12）そして神よ、我々はあらゆる方面から守られるべきです。偉大なる神よ、あなた自ら我らを守り、敵を滅ぼしてください。』」
īśvara uvāca|
mama tejo na śaktā hi sarve dhārayituṃ yadi|
ahamenānvadhiṣyāmi yuṣmattejordhasaṃyutaḥ|| // 8-25-13 //
イーシュヴァラは語った。 （13）「『もし全員で我が力を受け止めることができないならば、お前たちの力の半分を加えて、私が彼らを殺そう。
balārdhaṃ yadi me devā na dhārayitumāhave|
śaktāḥ sarve hi saṅgamya yūyaṃ tatprabravīmi vaḥ|| // 8-25-14 //
（14）天の神々よ、もしお前たち全員合わせても戦場で我が力の半分を受け止めることができないならば、私がお前たちに告げよう。
samā bhavanti me sarve dānavāś cāmarāś ca ye|
śivo'smi sarvabhūtānāṃ śivatvaṃ tena me surāḥ|| // 8-25-15 //
（15）悪魔も天の神も、私にとってはすべて平等である。私はすべての生き物にとって吉祥なる者（シヴァ）である。だからこそ天の神々よ、私のシヴァという名がある。
kintvadharmeṇa vartante yasmātte suraśatravaḥ|
tasmād vadhyā mayāpyete yuṣmākaṃ ca hitepsayā|| // 8-25-16 //
（16）しかし彼ら天の神の敵は不法に振る舞っている。だからこそ、お前たちの利益を願って、私によっても殺されるべきなのだ。
śaraṇaṃ vaḥ prapannānāṃ dharmeṇa ca jigīṣatām|
sāhāyyaṃ vaḥ kariṣyāmi nihaniṣyāmi vo ripūn|| // 8-25-17 //
（17）法によって勝利を求め、帰依してくるお前たちの守護者として、私はお前たちを助け、お前たちの敵を殺そう。
dīyatāṃ ca balārdhaṃ me sarvairapi pṛthakpṛthak|
paśutvaṃ caiva me lokāḥ sarve kalpantu pīḍitāḥ|| // 8-25-18 //
（18）全員がそれぞれ私に力の半分を与えよ。そして苦しめられているすべての世界よ、私のために家畜となれ。
paśūnāṃ tu patitvaṃ me bhavatvadya divaukasaḥ|
evaṃ na pāpaṃ prāpsyāmi paśūnhatvā suradvipaḥ|| // 8-25-19 //
（19）すべての家畜の主たる地位を今日、天の神々よ、我に与えよ。こうすれば、天の神の敵という家畜を殺しても、罪を受けることはない。
kalpayadhvaṃ rathaṃ divyaṃ rathāśvāṃś caiva pāragān|
dhanuḥ śaraṃ sārathiṃ ca tato jeṣyāmi vo ripūn|| // 8-25-20 //
（20）神聖な戦車を用意し、戦車の馬と、弓と矢と御者を——そうすれば敵を打ち負かしてやろう。』
iti śrutvā vaco devā devadevasya bhūpateḥ|
viṣādamagamansarve paśutvaṃ prati śaṅkitāḥ|| // 8-25-21 //
（21）天の神の中の神の言葉を聞いて、天の神々は皆、落胆した。家畜にされることを恐れて。
teṣāṃ bhāvaṃ bhavo jñātvā devas tān abravīd idam|
mā vostu paśubhāve'sminbhayaṃ vibudhasattamāḥ|| // 8-25-22 //
（22）彼らの心を察した神バヴァ（シヴァ）は言った。『この家畜たる身分を恐れるな、天の神々の中の最上者たちよ。
śrūyatāṃ paśubhāvasya vimokṣaḥ kriyatāṃ ca saḥ|| // 8-25-23 //
（23）家畜の身分からの解放の方法を聞き、それを行うがよい。
yo vaḥ paśupateś caryāṃ cariṣyati sa mokṣyate|
paśutvāditi satyaṃ vaḥ pratijāne samāgame|| // 8-25-24 //
（24）パシュパティ（家畜の主＝シヴァ）の行い（ヴラタ＝修行法）を行う者は、家畜の身分から解放されるだろう。これを集いの中で誓って約束する。
ye cāpyanye cariṣyanti vrataṃ mokṣyanti te'pi ca|| // 8-25-25 //
（25）他の者たちがこの行いを行っても、彼らもまた解放されるであろう。
nai(tya)ṣṭhikaṃ dvādaśābdaṃ vā ardhamabdamṛtutrayam|
māsaṃ dvādaśarātraṃ guhyaṃ vrataṃ divyaṃ cariṣyatha|| // 8-25-26 //
（26）終生、あるいは十二年間、あるいは半年間、三つの季節の間、一か月間、十二夜の間——秘密の神聖な行いを行え。
taṃ tathetyabruvan devā devadevanamaskṛtam|
ūcuścedaṃ gṛhāṇedaṃ tejaso'rdhamiti prabhum|| // 8-25-27 //
（27）天の神々は、天の神の中の神に敬礼されるこの方に「そのとおりに」と言い、『力の半分をお受けください、主よ』と申し上げた。
pratyuvāca tathetyeva śūladhṛdrājasattama|
tatas te pradaduḥ sarve tejaso'rdhaṃ mahātmane|| // 8-25-28 //
（28）槍を持つ方は「そのとおり」と答えた、王の中の最上者よ。そこで全員がこの偉大な魂にそれぞれの力の半分を捧げた。
sarvamādāya sarveṣāṃ tejaso'rdhaṃ divaukasām|
tejasāpyadhiko bhūtvā bhūyo'pyatibalo'bhavat|| // 8-25-29 //
（29）すべての天の者たちの力の半分をすべて受け取り、力において圧倒的になったシヴァは、さらなる力をも得た。
tataḥ prabhṛti devānāṃ devadevo'bhavadbhavaḥ|
patiś ca sarvabhūtānāṃ paśūnāṃ cābhavattadā|| // 8-25-30 //
（30）それ以来、バヴァ（シヴァ）は天の神々の中の神となり、すべての生き物の主、そして家畜の主となった。
tasmātpaśupatiścokto bhavatvācca bhaveti vai||
ardhamādāya sarveṣāṃ tejasā prajvalan iva| // 8-25-31 //
（31）だからパシュパティ（家畜の主）と呼ばれ、バヴァ（存在者）という名からバヴァと呼ばれる。すべての者の力の半分を受け取り、燃えるように輝き——
bhāsayāmāsa tānsarvāndevadevo mahādyutiḥ||
tato'bhiṣiṣicyuḥ sarve surā rudraṃ purāriṇam| // 8-25-32 //
（32）天の神の中の神、大いなる輝きを持つ方は、すべての天の神々を照らし出した。
mahādeva iti hyāsīddevadevo maheśvaraḥ|| || // 8-25-33 //
（33）そして天の神々は皆、城塞の敵であるルドラに灌頂を行った。こうして天の神の中の神、マヘーシュヴァラ（大自在天）は、マハーデーヴァ（偉大なる神）と呼ばれるようになった。」
iti śrīmanmahābhārate karṇaparvaṇi pañcaviṃśo'dhyāyaḥ|| 25 ||
こうして、聖なる大マハーバーラタのカルナ篇の第二十五章は終わる。
