एकादशः सर्गः

第十一章　暁の描写（prabhāta-varṇana）
韻律：mālinī（マーリニー）——全67偈　◡◡◡ ◡◡◡ —— —◡—— ◡——
V.1
Sanskrit (IAST) śrutisamadhikam uccaiḥ pañcamaṃ pīḍayantaḥ satatam ṛṣabhahīnaṃ bhinnakīkṛtya ṣaḍjam / praṇijagadur akākuśrāvakasnigdhakaṇṭhāḥ pariṇatim iti rātrer māgadhā mādhavāya //
和訳

微音の豊かなシュルティを高く響かせつつ、第五音を抑え、常にリシャバ音を欠いたままシャッジャ音を変調にして、吟遊詩人たちは——歌声に不快な嗄れはなく、遠くまで届く滑らかな喉で——かくのごとく夜の終わりをクリシュナに告げた。

注

【Vallabhadeva】

māgadhāは吟遊詩人。ṣaḍja（シャッジャ）を変調し（bhinnakīkṛtya）、pañcama（第五音）を抑え（pīḍayantaḥ＝遠ざけつつ）、ṛṣabha（第二音）を欠いた旋律で夜明けを歌う。これは暁の音楽理論に基づく——早朝にはリシャバとパンチャマは忌避される。

【Mallinātha】

Bharata（『ナーティヤシャーストラ』）を引用：「暁にリシャバとパンチャマは特に忌むべし」。śruti（微音）は音程の最小単位で、ṣaḍjaとpañcamaは各四シュルティ。akāku＝声に歪みがないこと、śrāvaka＝遠くまで届く声。本章は全篇mālinī韻律。

V.2
Sanskrit (IAST) ratirabhasavilāsābhyāsatāntaṃ na yāvan nayanayugam amīlat tāvad evāhato 'sau / rajaniviratiśaṃsī kāminīnāṃ bhaviṣyad-virahavihitanidrābhaṅgam uccair mṛdaṅgaḥ //
和訳

情事の激しい戯れを繰り返して疲れた両の目が、まだ閉じきらぬうちに——夜の終わりを告げるあの太鼓が高らかに打ち鳴らされた。恋する女たちに、来たるべき別離の憂いから眠りを破るかのように。

注

【Vallabhadeva】

rati（情交）のrabhasavilāsa（激しい戯れ）をabhyāsa（繰り返し）て疲労した目がまだ閉じぬうちに太鼓が鳴る。bhaviṣyad-viraha（来たるべき別離）への不安が眠りを妨げる。

【Mallinātha】

mṛdaṅga（太鼓）は暁に打ち鳴らされ夜の終わりを告げる。viraha（別離）という語は能力によって「不安・悩み」を含意する。目の閉じることと眠りの破れの因果関係によりkāvyaliṅga（詩的論拠）の修辞。

V.3
Sanskrit (IAST) sphuṭataram upariṣṭād alpamūrter dhruvasya sphurati suramunīnāṃ maṇḍalaṃ vyastam etat / śakaṭam iva mahīyaḥ śaiśave śārṅgapāṇeś capalacaraṇakābjapreraṇottuṅgitāgram //
和訳

小さな姿のドゥルヴァ星の上方に、七聖仙の星群がいっそう明るく広がって輝いている——かつて幼きクリシュナが、その小さな蓮華の足で蹴り上げた大きな荷車のように、先端を高く突き上げた姿で。

注

【Vallabhadeva】

suramunīnāṃ maṇḍala＝七仙人（saptarṣi）の星座。dhruva＝北極星（ウッターナパーダの子）。vyasta＝広がった。幼児クリシュナ（śārṅgapāṇi）がśakaṭāsura（荷車の姿を取った悪魔）を足で蹴り倒した伝説を踏まえた直喩。

【Mallinātha】

alpamūrti＝遠方ゆえに小さく見える。caraṇaka＝小さな足（alpa の意味でkan接尾辞）。śakaṭa（荷車）はシャカターースラの体。upamālaṅkāra（直喩の修辞）。GRETILはvyastametと誤って截断——正しくはvyastam etat。

V.4
Sanskrit (IAST) praharakam apanīya svaṃ nididrāsatoccaiḥ pratipadam upahūtaḥ kenacij jāgṛhīti / muhur aviśadavarṇāṃ nidrayā śūnyaśūnyāṃ dadad api giram antar budhyate no manuṣyaḥ //
和訳

自分の夜番を終えて眠りたい者が、大声で名を呼ばれ「起きろ」と促される。しかしその男は、眠気のために不明瞭で空疎な言葉を繰り返し返事するものの、心の内ではまったく目覚めていない。

注

【Vallabhadeva】

praharaka＝夜番（prahara＝時間区分、yakの接尾辞）。nididrāsataḥ＝眠りたがっている（nidrāの希求活用）。名前を一々呼ばれて起こされるが（pratipadam upahūtaḥ）、不明瞭な返事をしつつも内心では目覚めない。śūnyaśūnya＝意味のない空虚な（prakāra の畳語）。

【Mallinātha】

「目覚めよ」と繰り返し呼ばれて返事をしながらも目覚めぬ矛盾——api（「～にもかかわらず」）がそれを示し、nidra（眠り）がその矛盾を解消する。virodhābhāsa（見せかけの矛盾）の修辞。

V.5
Sanskrit (IAST) vipulataranitambābhogaruddhe ramaṇyāḥ śayitum anadhigacchan jīviteśo 'vakāśam / ratiparicayanaśyan naidratandraḥ kathañcid gamayati śayanīye śarvarīṃ kiṃ karotu //
和訳

愛しい女の豊かな腰の広がりに塞がれた寝床で、横になる場所も見つけられず、愛の営みの繰り返しで睡魔も消え失せた夫は——どうにかして夜を過ごす。いったい他に何ができよう。

注

【Vallabhadeva】

nitambinī（豊かな腰の女）のabhoga（広がり）で寝台に場所がない。ratiparicaya（情交の繰り返し）で睡気も消え、寝台そのもので夜を過ごすしかない——kiṃ karotu（他に何ができよう）。GRETILのnaindratandraḥは誤り、正しくはnaidratandraḥ（nidrā→naidra、タッディタ派生）。

【Mallinātha】

寝台に寝る場所がないのに寝台との関わりを述べる——atiśayokti（誇張法）。女の広い腰が寝場所を奪う原因であることはkāvyaliṅga（詩的論拠）で、二つの修辞が混在する。

V.6
Sanskrit (IAST) kṣaṇaśayitavibuddhāḥ kalpayantaḥ prayogān udadhimahati rājye kāvyavad durvigāhe / gahanam apararātraprāptabuddhiprasādāḥ kavaya iva mahīpāś cintayanty arthajātam //
和訳

わずかに眠ってすぐ目覚めた王たちが、海のように広大で、詩の如く踏み込み難い王国において、さまざまな方策を練り、深遠な事柄を思案する——後夜に得た明晰な知力をもって、あたかも詩人が作品を構想するように。

注

【Vallabhadeva】

kṣaṇa（わずかな間）眠って目覚めた王たちが暁の最終時分（apararātra）に国政を考える。rājyeとkāvye、mahīpāḥとkavayaḥが掛詞的に対応する二重の喩え。prayoga＝政策・方策（詩においては修辞技法）。

【Mallinātha】

udadhimahati（海のように広大な）rājye（王国）はkāvyavat（詩のように）durvigāha（踏み込み難い）——複合的な直喩。apararātra（後夜）は夜の最終時分、ブラーフマ・ムフールタに知性が冴える時。pūrṇā vākyārthopamā（完全な文意の直喩）。

V.7
Sanskrit (IAST) kṣititaṭaśayanāntād utthitaṃ dānapaṅkaplutabahulaśarīraṃ śāyayaty eṣa bhūyaḥ / mṛducalad aparāntodīritāndūninādaṃ gajapatim adhirohaḥ pakṣakavyatyayena //
和訳

地面を寝床の端として起き上がった象——発情の泥に浸った巨大な体——を、象使いは再び横たえさせる。脚を静かに動かすと足鎖が鳴り、体の向きを反転させて。

注

【Vallabhadeva】

adhiroha＝象使い。dānapaṅka＝発情液の泥。pakṣakavyatyaya＝体の片側を入れ替えること。andūnināda＝足鎖の音。GRETILのdānapaṅgaは誤り、正しくはdānapaṅka（paṅka＝泥）。

【Mallinātha】

kṣititaṭa（地面）そのものが寝床。pakṣaka＝pārśva（体側）。象を再び横たえさせる（śāyayati＝使役形）。svabhāvokti（自然描写）の修辞。

V.8
Sanskrit (IAST) drutatarakaradakṣāḥ kṣiptavaiśākhaśaile dadhati dadhani dhīrān āravān vāriṇīva / śaśinam iva suraughāḥ sāram uddhartum ete kalaśim udadhigurvīṃ vallavā loḍayanti //
和訳

素早い手さばきの牧女たちが、マンダラ山の如き攪拌棒を立てて、ヨーグルトの中に深い響きを立てる——まるで水を湛えた大海のように。神々が月を引き上げたように精髄を取り出すため、海のように重い甕を攪拌する。

注

【Vallabhadeva】

vallavā＝牧人（ここでは牧女）。kalaśī＝乳攪拌の甕。vaiśākha＝攪拌棒（viśākhāから派生）。sāra＝精髄（＝バター）。乳海攪拌神話との比喩——甕は海、攪拌棒はマンダラ山、バターは月。

【Mallinātha】

乳海攪拌（samudra-manthana）の神話を背景にした完全な文意の直喩。dhīra（深い・荘重な）音はdadhani（ヨーグルトの中）と vāriṇi（水の中）に共通する。vākyārthopamā（文意の直喩）。

V.9
Sanskrit (IAST) anunayam agṛhītvā vyājasuptā parācī rutam atha kṛkavākos tāram ākarṇya kalpye / katham api parivṛttā nidrayāndhā kila strī mukulitanayanaivā śliṣyati prāṇanātham //
和訳

夫の宥めの言葉を受け入れず、嘘寝して背を向けていた女が——やがて暁に鶏の高い鳴き声を耳にすると、どうにか寝返りを打ち、眠りに惑うふりをして目を閉じたまま、愛する夫を抱きしめる。

注

【Vallabhadeva】

kalahāntaritā（喧嘩で隔てられた）恋人の型。夜通し拗ねていた女が、暁の鶏鳴を聞いて別れの時を悟り、自尊心と未練の板挟みから、眠りを装って夫を抱く。nidrayāndhā kila＝「眠りに目が眩んだかのように」。GRETILのśiliṣyatiは誤り、正しくはśliṣyati（√śliṣ）。

【Mallinātha】

kṛkavāku＝鶏。kalpya＝prabhāta（暁）（Amara: pratyūṣo 'harmukhaṃ kalpyam）。vyāja（偽り）の睡眠から覚め、mukulitanayanā（目を閉じたまま）夫を抱擁する描写。

V.10
Sanskrit (IAST) gatam anugatavīṇair ekatāṃ veṇunādaiḥ kalam avikalatālaṃ gāyakair bodhahetoḥ / asakṛd anavagītaṃ gītam ākarṇayantaḥ sukhamukulitanetrā yānti nidrāṃ narendrāḥ //
和訳

ヴィーナーに寄り添う笛の音と一体となり、柔らかに、拍子も乱れず、歌い手たちが目覚めのために繰り返し歌う——その非の打ち所のない歌を聴きながら、王たちは心地よく目を閉じ、かえって眠りに落ちてゆく。

注

【Vallabhadeva】

gāyaka（歌い手）が目覚めのために歌う音楽（bodhahetoḥ）を聴きながら、王たちはかえってsukhamukulitanetrā（心地よく瞼を閉じ）眠ってしまう逆説。veṇunāda（笛の音）がvīṇā（弦楽器）とekatā（一体）になっている。anavagīta＝非難の余地のない歌。

【Mallinātha】

bodha（目覚め）が原因なのに結果はnidrā（眠り）という反転。anugatavīṇa＝ヴィーナーに追随する笛の音。avikalatāla＝拍子に乱れがない。anavagīta＝avagīta（非難される）の否定、すなわち完璧な歌。vṛtyanuprāsa（子音の反復）の修辞。

V.11
Sanskrit (IAST) pariśithilitakarṇagrīvam āmīlitākṣaḥ kṣaṇam ayam anubhūya svapnam ūrdhvajñur eva / rirasayiṣati bhūyaḥ śaṣpam agre vikīrṇaṃ paṭutaracapalauṣṭhaḥ prasphuratprotham aśvaḥ //
和訳

耳と首をだらりと弛め、目を閉じ、立ったまま膝を突っ張ってわずかな眠りをとった馬が——ふたたび、器用に動く唇と震える鼻孔で、前に撒かれた青草を味わおうとする。

注

【Vallabhadeva】

ūrdhvajānu＝膝を上に（突っ張って立つ＝馬の立ち寝の姿勢）。rirasayiṣati＝味わおうと欲する（√ras の希求活用）。śaṣpa＝若草。良馬の特徴を示す描写。

【Mallinātha】

pariśithilita＝弛んだ・垂れた。protha＝馬の鼻孔。uttama-aśva（最良の馬）の特徴描写。svabhāvokti（自然描写）の修辞。

V.12
Sanskrit (IAST) udayam uditadīptir yāti yaḥ saṃgatau me patati na varam induḥ so 'parām eṣa gatvā / sitarucir iva sadyaḥ sābhyasūyaṃ prabheti sphurati viśadam eṣā pūrvakāṣṭhāṅganāyāḥ //
和訳

「わたしと共にいれば輝きを増し栄えるのに、あの月はよその女のもとへ行って落ちぶれた——当然の報いだ」——嫉妬混じりの微笑の白い輝きのように、東の方角の女の光がたちまち鮮やかに煌めく。

注

【Vallabhadeva】

pūrvakāṣṭhā（東の方角）を女（aṅganā）に見立てる。月は東の女と共にいれば輝く（udaya）が、西の女（aparā）のもとへ行って没落する（patati）。それを見た東の女が嫉妬の微笑（sita-ruci）を浮かべる——それが暁の光。sābhyasūyam＝嫉妬を伴って。

【Mallinātha】

pūrvakāṣṭhā＝東の方角、かつ元の恋人（nāyikā）。aparā＝西の方角、かつ他の女。月の没落と浮気者の没落を重ねる。utprekṣā（想像法）とrūḍhi-nyūḍhi（掛詞）の混合修辞。GRETILのsmitaはsita（白い）が正しく、両注釈一致。

V.13
Sanskrit (IAST) ciraratiparikheda prāptanidrāsukhānāṃ caramam api śayitvā pūrvam eva prabuddhāḥ / aparicalitagātrāḥ kurvate na priyāṇām aśithilabhujacakrāśleṣabhedaṃ taruṇyaḥ //
和訳

長い情事の疲れからようやく眠りの安らぎを得た愛しい人々——その最後の眠りの後、先に目覚めた若い妻たちは、身じろぎもせず、夫の固い腕の輪の抱擁を解こうとしない。

注

【Vallabhadeva】

貞女の条件「後に臥し先に目覚め、心に他の男を思わぬ者」を踏まえる。身動きしないのは夫の眠りを妨げまいとする心遣い。

【Mallinātha】

bhujacakra＝腕の輪（抱擁の姿）。aśithila＝固い・緩まぬ。先に目覚めても抱擁を解かないのは夫の安眠を守るため。rati-śrama（情事の疲労）はsañcārī-bhāva（副次的情感）、その結果のnidrā（眠り）はanubhāva（情感の表出）。

V.14
Sanskrit (IAST) kṛtadhavalimabhedaiḥ kuṅkumeneva kiñcin malayaruharajobhir bhūṣayan paścimāśām / himarucir aruṇimnā rājate rajyamānair jaraṭhakamalakandacchedagaurair mayūkhaiḥ //
和訳

白さにわずかに紅を混ぜた光線で——まるで白檀の粉に少しクンクマを加えたように——西の空を飾りながら、月は沈みゆく赤みを帯びて輝く。その光は、老いた蓮の根茎の断面のように白い。

注

【Vallabhadeva】

月の光線が白（gaura）で、沈む時の赤味（aruṇimna）で染まる。malayaruha-rajas＝白檀の粉、kuṅkuma＝サフラン——白に少し紅が混じる比喩。jaraṭhakamalakandaccheda＝熟した蓮根の切り口の白さ。

【Mallinātha】

himaruci＝月。aruṇimnā＝日没時の赤み。rajyamāna＝赤く染まりつつある（√rañj）。月光線を白檀と紅の混合に喩えるupamā（直喩）。

V.15
Sanskrit (IAST) dadhad asakalam ekaṃ khaṇḍitāmānam adbhiḥ śriyam aparam apūrṇām ucchvasadbhiḥ palāśaiḥ / karavam upagīte ṣaṭpadaughena dhattaḥ kumudakamalaṣaṇḍe tulyarūpām avasthām //
和訳

一方の睡蓮の茂みは、萎む花びらで欠けゆく栄華を宿し、他方の蓮の茂みは、開く花弁でまだ満ちぬ栄華を湛える——どちらも蜂の群れに歌われて、ふたつの茂みは等しい姿の境遇を見せる。

注

【Vallabhadeva】

kumuda（月見草）は夜に咲き暁に閉じ、kamala（蓮）は朝に開く。一方は衰え、一方は栄える——その中間で両者が「等しい姿」（tulyarūpā avasthā）になる瞬間。dhattaḥ＝双数形（√dhā）。ṣaṭpadaugha＝蜂の群れ。

【Mallinātha】

衰退と興隆が等しくなる一瞬——どちらがどちらかわからぬという趣向。kāvyaliṅga（詩的論拠）。両者が交互に喩えられるupameyopamā（被喩同士の直喩）が暗示される。

V.16
Sanskrit (IAST) madarucim aruṇenodgacchatā lambhitasya tyajata iva cirāya sthāyinīm āśu lajjām / vasanam iva mukhasya sraṃsate saṃpratīdaṃ sitakarakarajālaṃ vāsavāśāyuvatyāḥ //
和訳

昇る太陽の赤い光に「情欲の赤らみ」を与えられた東の方角の若い女——その顔から、長く留まっていた羞恥を今や素早く捨て去るかのように、月光の白い光の網がずるりと滑り落ちる——まるで顔の衣のように。

注

【Vallabhadeva】

vāsavāśā＝prācī（東の方角）を若い女に見立てる。月光＝面の衣（vasana）。赤い暁の光＝情欲の赤らみ（madaruci）。恥じらいを失う女の衣が落ちるように月光が消える。utprekṣā（想像法）。

【Mallinātha】

lambhita＝与えられた（√labh使役の過去分詞）。月光の白い光線網が、東の方角（＝女の顔）から滑り落ちる。mukha＝顔と東の始まりの掛詞。nidarśana（例証法）とutprekṣāの混合修辞。

V.17
Sanskrit (IAST) avirataratalīlāyāsajātaśramāṇām upaśamam upayāntaṃ niḥsahe 'ṅge 'ṅganānām / punar uṣasi viviktair mātariśvāvacūrṇya jvalayati madanāgniṃ mālatīnāṃ rajobhiḥ //
和訳

絶え間ない情事の疲労に打ちひしがれた女たちの体——その鎮まりかけた愛の炎を、暁にふたたび風が、清らかなジャスミンの花粉を振りかけて燃え上がらせる。

注

【Vallabhadeva】

mātariśvan＝風。消えかけた炭火に牛糞の灰を振りかけて再び燃やすように、風がジャスミンの花粉を疲れた女の体に振りかけて恋情を再燃させる。GRETILはyāḥsa（余分な visarga）とviviktaimarmā（余分な mar）に誤り。

【Mallinātha】

mālatī＝ジャスミン。avacūrṇya＝振りかけて。madanāgni＝愛の炎。暁の風がジャスミンの香りを運び恋心を再び掻き立てるという自然描写。vṛttyanuprāsa（子音の反復）の修辞。

V.18
Sanskrit (IAST) animiṣam avirāmā rāgiṇāṃ sarvarātraṃ navanidhuvanalīlāḥ kautukenātivīkṣya / idam udavasitānām asphuṭālokasaṃpannayanam iva sanidraṃ ghūrṇate daipam arciḥ //
和訳

恋人たちの一晩中の新たな情事の戯れを、瞬きもせず止むことなく興味深げに見つめ続けた灯火の焔——今やその光も朧げになり、眠そうに揺れている。まるで家々の、眠りに塞がった目のように。

注

【Vallabhadeva】

daipam arciḥ＝灯火の焔。animiṣam＝瞬きせず（灯火は瞬かない→一晩中見つめた）。asphuṭālokasaṃpat＝光の勢いが不明瞭になった。sanidram＝眠そうに。udavasita＝家屋。

【Mallinātha】

灯火の焔を人間のように擬人化。一晩中恋人たちを見届けた焔が暁に揺らめく——nayanam iva（目のように）というutprekṣā（想像法）。油の消耗と暁の光による灯火の衰えが自然な原因。

V.19
Sanskrit (IAST) vikacakamalagandhair andhayan bhṛṅgamālāḥ surabhitam akarandaṃ mandam āvāti vātaḥ / pramadanamadanādyadyauvanoddāmarāmāramaṇarabhasakhedasvedavicchedadakṣaḥ //
和訳

咲き誇る蓮の香りで蜂の群れを惑わし、花蜜を薫らせながら、風がそよそよと吹く——歓喜と愛欲に酔い、若さに奔放な女たちの情事の激しい疲れの汗を拭い去ることに巧みな風が。

注

【Vallabhadeva】

暁の風（vāta）の二つの働き：蓮の香りで蜂を惑わすこと（andhayan）と、女たちの汗を拭うこと（svedaviccheda）。pramadana＝歓喜を与えること、madana＝愛の神。GRETILは余分なmで16音節になる誤り。

【Mallinātha】

巨大な複合語がpāda c-dを構成する。ādyat＝食い尽くしつつある・制圧しつつある（√ad）。āvāti＝そよぐ（√vā）。vṛttyanuprāsa（子音の反復）の修辞。十の詩的美質（guṇa）がほぼすべてここに見出される。

V.20
Sanskrit (IAST) lulitanayanatārāḥ kṣāmavaktrendubimbā rajanaya iva nidrāklāntanīlotpalākṣyaḥ / timiram iva dadhānāḥ sraṃsinaḥ keśapāśān avanipatigṛhebhyo yānty amūr vāravadhvaḥ //
和訳

瞳の星は揺らぎ、顔の月は蒼ざめ、青蓮華のような目は眠りに萎れ、闇のような黒髪を垂らして——あたかも去りゆく夜そのもののように、遊女たちが王の邸から出てゆく。

注

【Vallabhadeva】

vāravadhū＝遊女。lulitanayanatārā＝瞳の輝きが乱れた（＝夜空の星が薄れた）。kṣāmavaktrendubimbā＝顔の月が痩せた（＝月が傾いた）。すべての形容が女と夜の両方に当てはまるśliṣṭa-viśeṣaṇa（密着形容）の直喩。

【Mallinātha】

sraṃsin＝垂れ下がった。keśapāśa＝髪の束（＝夜の闇）。nīlotpala＝青蓮華。rajanayaḥ iva＝夜のように。遊女が帰る暁の場面に夜の去りゆく姿を重ねる。GRETILのnindrāはnidrāが正しい（余分なn）。
