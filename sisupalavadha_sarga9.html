नवमः सर्गः / 第九章　日没の描写（sūryāstavarṇana）

太陽の沈みゆくさまと黄昏の情景を描く
pramitākṣarā throughout — s-j-s-s (◡◡— ◡—◡ ◡◡— ◡◡—), 12 syllables per pāda
V.1
Sanskrit (IAST) abhitāpasaṃpadam athoṣṇaruciḥ nijatejasām asahamāna iva / payasi prapitsur aparāmbunidher adhiroḍhum astagirim abhyapatat //
和訳

自らの光の灼熱の盛りに堪えかねたかのように、太陽は大洋の水に沈まんとして、西の山を登らんと駆け寄った。

注

【Vallabhadeva】

水に沈む理由として utprekṣā（擬想）。太陽が自らの光の灼熱に堪えかねて水に入ろうとするという仮想因の付加。pramitākṣarā 韻律（s-j-s-s、各 pāda 12音節）が本章を通じて用いられる。GRETIL の nijatesāma は nijatejasām の脱字（"ja" 欠落）。

【Mallinātha】

時宜にかなった沈没に、自らの光の熱に堪えぬという擬想因を付す utprekṣā。本章の韻律は pramitākṣarā。Mallinātha 本は amitāpasaṃpadam と読む（異読）。

V.2
Sanskrit (IAST) gatayā puraḥ pratigavākṣamukhaṃ dadhatī ratena bhṛśam utsukatām / muhur antarālabhuvam astagireḥ savituś ca yoṣid amimīta dṛśā //
和訳

ある女が、窓辺に進み出て、情交への激しい焦がれを抱きながら、西山と太陽との間の距離を何度も目で測っていた。

注

【Vallabhadeva】

情交への渇望から日没を待ちわびる女が、窓辺に出て西山と太陽の中間の距離を視線で測る。日没の到来を待つ心理描写。

【Mallinātha】

ratena は saptamy-artha の tṛtīyā（情事における焦がれ、の意味で具格が処格的に用いられる）。autsukya（焦燥）の描写であり preyas（愛情修辞）。amimīta は √mā の luṅ。

V.3
Sanskrit (IAST) viralātapacchavir anuṣṇavapuḥ parito vipāṇḍu dadhad abhraśiraḥ / abhavad gataḥ pariṇatiṃ śithilaḥ parimandasūryanayano divasaḥ //
和訳

日は老いの極みに達し、力なく萎えていた——日差しの輝きはまばらとなり、身体はもはや熱くなく、四方に蒼白い雲の頭を戴き、太陽という鈍い眼を持つばかりであった。

注

【Vallabhadeva】

日を老人に喩える。まばらな日差し＝衰えた容色、ぬるい身体＝老体の冷え、蒼白い雲の頭＝白髪、鈍い太陽の眼＝老眼。pariṇati は「成熟」と「老衰」の両義。

【Mallinātha】

avayavarūpaṇa（部分描写）による ekadeśavṛtti rūpaka（部分的隠喩）。日が老人として描かれ、śleṣa がそれを支える。GRETIL の paramandasūryanayano は parimandasūryanayano と読む（Mallinātha 本）。

V.4
Sanskrit (IAST) aparāhṇaśītalatareṇa śanair anilena lolitalatāṅgulaye / nilayāya śākhina ivāhvayate dadur ākulāḥ khagakulāni giraḥ //
和訳

午後のひときわ涼しい風がそよそよと蔓の指を揺らすと、鳥の群れは樹々にせわしく声を上げた。まるで宿を求めて樹が手招きしているかのように。

注

【Vallabhadeva】

樹が風に揺れる蔓の指（latāṅguli）で招くかのように鳥が応える utprekṣā。午後の涼風は住みやすさの表現。dadur は √dā（与える・発する）の完了形。GRETIL の dudur は dadur の誤り。

【Mallinātha】

lolitalatāṅgulaye は蔓が揺れて指のように招く utprekṣā。鳥が応じて声を出すのは anuṣaṅga（連鎖的）utprekṣā。

V.5
Sanskrit (IAST) upasaṃdhyam āsta tanu sānumataḥ śikhareṣu tatkṣaṇam aśītarucaḥ / karajālam astamaye 'pi satām ucitaṃ khalūccataram eva padam //
和訳

黄昏どき、灼熱の太陽のかすかな光の網が山の峰々にとどまっていた。没落の時にあってさえ、高い位こそ善き者にふさわしい。

注

【Vallabhadeva】

山頂にかすかに残る光を「高い地位」に重ねる。偉大なる者は終末のときにも卑しい場所には落ちないという arthāntaranyāsa（意味の転移修辞）。āsta は √ās の kartari laṭ。GRETIL の utitaṃ は ucitaṃ の誤り。

【Mallinātha】

astamaye（没落の時）にも satām（善人にとって）の ucitam（ふさわしい）padam は uccataram eva（まさに高い地位のみ）。arthāntaranyāsa。

V.6
Sanskrit (IAST) pratikūlatām upagate hi vidhau viphalatvam eti bahusādhanatā / avalambanāya dinabhartur abhūn na patiṣyataḥ karasahasram api //
和訳

運命が逆境に転じたとき、いかに豊かな手段も無に帰す。沈みゆく日の主にとって、千本の手さえ支えとはならなかった。

注

【Vallabhadeva】

karasahasra は「千本の光線」と「千本の手」の śleṣa で太陽の擬人化。運命が逆行すれば千本の手も支えにならぬという arthāntaranyāsa。dṛṣṭānta ではなく arthāntaranyāsa とする理由は、一般命題と特殊事例の関係にあるから。GRETIL の pratikūlamupagate は pratikūlatām upagate の誤り（"tā" 欠落、韻律不合）。

【Mallinātha】

個別例（太陽）で一般則（運命逆行時の無力）を支持する viśeṣeṇa sāmānya 型 arthāntaranyāsa。karāḥ は aṃśavaḥ（光線）と hastāḥ（手）の両義。

V.7
Sanskrit (IAST) navakuṅkumāruṇapayodharayā svakarāvasaktarucirāmbarayā / atisaktim etya varuṇasya diśā bhṛśam anvarajyad atuṣārakaraḥ //
和訳

新しい紅で赤く染まった胸を持ち、自らの手にまとう美しい衣をまとった西の方角に深く寄り添われて、太陽はひどく染められた。

注

【Vallabhadeva】

西の方角を女性に擬する samāsokti（暗示的比喩）。紅い胸＝夕焼けに赤く染まった雲、美しい衣＝光に包まれた空。太陽が恋人のように赤く染まる。anvarajyad は anu-vi-√rañj（染まる・恋着する）。

【Mallinātha】

vāruṇī-diśā（西方）の viśeṣaṇa の力で女性と西方の jāra-bhāva（情事関係）が暗示される samāsokti。Mallinātha 本は tuṣārakaraḥ（冷光者＝通常は月）と読むが uṣṇāṃśuḥ（太陽）と註す。GRETIL はatuṣārakaraḥ（非冷光者＝太陽）と読む。

V.8
Sanskrit (IAST) gatavaty arājata japākusumastabakadyutau dinakare 'vanatim / bahalānurāgakuruvindadalapratibaddhamadhyam iva digvalayam //
和訳

木槿の花房のごとき赤い輝きの太陽が地平に沈みゆくと、地平線の環は、濃い紅の紅宝石の石片をはめ込んだ腕輪のように輝いた。

注

【Vallabhadeva】

沈みゆく木槿色の太陽を kuruvinda（紅宝石の一種）に見立て、地平線の環を腕輪に喩える utprekṣā。kuruvinda は padmarāga（紅玉）の一種。

【Mallinātha】

japākusumastabakadyuti は木槿の花房のごとき輝き。digvalayam（方角の環＝地平線の輪）を kuruvinda（紅宝石）をはめ込んだ腕輪（kaṅkaṇa）に擬する utprekṣā。

V.9
Sanskrit (IAST) drutaśātakumbhanibham aṃśumato vapur ardhamagnavapuṣaḥ payasi / ruruce viriñcinakhabhinnabṛhajjagadaṇḍaikatarakhaṇḍam iva //
和訳

水中に半ば沈んだ太陽の身体は、溶けた黄金のように輝いた——まるでブラフマーの爪で二つに割られた大宇宙卵の片方の殻のように。

注

【Vallabhadeva】

drutaśātakumbha は溶けた黄金。半ば沈んだ太陽の円盤を、ブラフマーの爪で割られた宇宙卵の半片に喩える。Vallabhadeva 本は vyarucad（√ruc の imperfect）と読む。

【Mallinātha】

upamāna（喩えるもの）が purāṇa（神話）に基づく upamā（直喩）。ruruce は √ruc の完了形。GRETIL の bṛhaddaṇaḍaka は bṛhajjagadaṇḍa の脱字（"jaga" 欠落）。

V.10
Sanskrit (IAST) anurāgavantam api locanayoḥ dadhataṃ vapuḥ sukham atāpakaram / nirakāsayad ravim apetavasuṃ viyadālayād aparadiggaṇikā //
和訳

両の眼に愛着を抱かせ、苦痛を与えぬ快い姿をしていたにもかかわらず、西の方角という遊女は、富を失った太陽を空の住処から追い出した。

注

【Vallabhadeva】

西方を遊女に擬する暗示的比喩の延長。遊女は金のある間は愛人を手元に置き、無一文になれば追い出す。太陽が光（＝富 vasu）を失って追い出される。anurāgavat は「情愛深い」と「赤く染まった」の両義。

【Mallinātha】

ekadeśarūpaṇa（部分的描写）により aparadiggaṇikā のような rūpaka（隠喩）が推知される ekadeśavṛtti rūpaka。atāpakara は「苦痛を与えない」と「灼熱でない」、apetavasu は「富を失った」と「光を失った」の śleṣa。
