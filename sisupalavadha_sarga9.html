नवमः सर्गः / 第九章　日没の描写（sūryāstavarṇana）

太陽の沈みゆくさまと黄昏の情景を描く
pramitākṣarā throughout — s-j-s-s (◡◡— ◡—◡ ◡◡— ◡◡—), 12 syllables per pāda
V.1
Sanskrit (IAST) abhitāpasaṃpadam athoṣṇaruciḥ nijatejasām asahamāna iva / payasi prapitsur aparāmbunidher adhiroḍhum astagirim abhyapatat //
和訳

自らの光の灼熱の盛りに堪えかねたかのように、太陽は大洋の水に沈まんとして、西の山を登らんと駆け寄った。

注

【Vallabhadeva】

水に沈む理由として utprekṣā（擬想）。太陽が自らの光の灼熱に堪えかねて水に入ろうとするという仮想因の付加。pramitākṣarā 韻律（s-j-s-s、各 pāda 12音節）が本章を通じて用いられる。GRETIL の nijatesāma は nijatejasām の脱字（"ja" 欠落）。

【Mallinātha】

時宜にかなった沈没に、自らの光の熱に堪えぬという擬想因を付す utprekṣā。本章の韻律は pramitākṣarā。Mallinātha 本は amitāpasaṃpadam と読む（異読）。

V.2
Sanskrit (IAST) gatayā puraḥ pratigavākṣamukhaṃ dadhatī ratena bhṛśam utsukatām / muhur antarālabhuvam astagireḥ savituś ca yoṣid amimīta dṛśā //
和訳

ある女が、窓辺に進み出て、情交への激しい焦がれを抱きながら、西山と太陽との間の距離を何度も目で測っていた。

注

【Vallabhadeva】

情交への渇望から日没を待ちわびる女が、窓辺に出て西山と太陽の中間の距離を視線で測る。日没の到来を待つ心理描写。

【Mallinātha】

ratena は saptamy-artha の tṛtīyā（情事における焦がれ、の意味で具格が処格的に用いられる）。autsukya（焦燥）の描写であり preyas（愛情修辞）。amimīta は √mā の luṅ。

V.3
Sanskrit (IAST) viralātapacchavir anuṣṇavapuḥ parito vipāṇḍu dadhad abhraśiraḥ / abhavad gataḥ pariṇatiṃ śithilaḥ parimandasūryanayano divasaḥ //
和訳

日は老いの極みに達し、力なく萎えていた——日差しの輝きはまばらとなり、身体はもはや熱くなく、四方に蒼白い雲の頭を戴き、太陽という鈍い眼を持つばかりであった。

注

【Vallabhadeva】

日を老人に喩える。まばらな日差し＝衰えた容色、ぬるい身体＝老体の冷え、蒼白い雲の頭＝白髪、鈍い太陽の眼＝老眼。pariṇati は「成熟」と「老衰」の両義。

【Mallinātha】

avayavarūpaṇa（部分描写）による ekadeśavṛtti rūpaka（部分的隠喩）。日が老人として描かれ、śleṣa がそれを支える。GRETIL の paramandasūryanayano は parimandasūryanayano と読む（Mallinātha 本）。

V.4
Sanskrit (IAST) aparāhṇaśītalatareṇa śanair anilena lolitalatāṅgulaye / nilayāya śākhina ivāhvayate dadur ākulāḥ khagakulāni giraḥ //
和訳

午後のひときわ涼しい風がそよそよと蔓の指を揺らすと、鳥の群れは樹々にせわしく声を上げた。まるで宿を求めて樹が手招きしているかのように。

注

【Vallabhadeva】

樹が風に揺れる蔓の指（latāṅguli）で招くかのように鳥が応える utprekṣā。午後の涼風は住みやすさの表現。dadur は √dā（与える・発する）の完了形。GRETIL の dudur は dadur の誤り。

【Mallinātha】

lolitalatāṅgulaye は蔓が揺れて指のように招く utprekṣā。鳥が応じて声を出すのは anuṣaṅga（連鎖的）utprekṣā。

V.5
Sanskrit (IAST) upasaṃdhyam āsta tanu sānumataḥ śikhareṣu tatkṣaṇam aśītarucaḥ / karajālam astamaye 'pi satām ucitaṃ khalūccataram eva padam //
和訳

黄昏どき、灼熱の太陽のかすかな光の網が山の峰々にとどまっていた。没落の時にあってさえ、高い位こそ善き者にふさわしい。

注

【Vallabhadeva】

山頂にかすかに残る光を「高い地位」に重ねる。偉大なる者は終末のときにも卑しい場所には落ちないという arthāntaranyāsa（意味の転移修辞）。āsta は √ās の kartari laṭ。GRETIL の utitaṃ は ucitaṃ の誤り。

【Mallinātha】

astamaye（没落の時）にも satām（善人にとって）の ucitam（ふさわしい）padam は uccataram eva（まさに高い地位のみ）。arthāntaranyāsa。

V.6
Sanskrit (IAST) pratikūlatām upagate hi vidhau viphalatvam eti bahusādhanatā / avalambanāya dinabhartur abhūn na patiṣyataḥ karasahasram api //
和訳

運命が逆境に転じたとき、いかに豊かな手段も無に帰す。沈みゆく日の主にとって、千本の手さえ支えとはならなかった。

注

【Vallabhadeva】

karasahasra は「千本の光線」と「千本の手」の śleṣa で太陽の擬人化。運命が逆行すれば千本の手も支えにならぬという arthāntaranyāsa。dṛṣṭānta ではなく arthāntaranyāsa とする理由は、一般命題と特殊事例の関係にあるから。GRETIL の pratikūlamupagate は pratikūlatām upagate の誤り（"tā" 欠落、韻律不合）。

【Mallinātha】

個別例（太陽）で一般則（運命逆行時の無力）を支持する viśeṣeṇa sāmānya 型 arthāntaranyāsa。karāḥ は aṃśavaḥ（光線）と hastāḥ（手）の両義。

V.7
Sanskrit (IAST) navakuṅkumāruṇapayodharayā svakarāvasaktarucirāmbarayā / atisaktim etya varuṇasya diśā bhṛśam anvarajyad atuṣārakaraḥ //
和訳

新しい紅で赤く染まった胸を持ち、自らの手にまとう美しい衣をまとった西の方角に深く寄り添われて、太陽はひどく染められた。

注

【Vallabhadeva】

西の方角を女性に擬する samāsokti（暗示的比喩）。紅い胸＝夕焼けに赤く染まった雲、美しい衣＝光に包まれた空。太陽が恋人のように赤く染まる。anvarajyad は anu-vi-√rañj（染まる・恋着する）。

【Mallinātha】

vāruṇī-diśā（西方）の viśeṣaṇa の力で女性と西方の jāra-bhāva（情事関係）が暗示される samāsokti。Mallinātha 本は tuṣārakaraḥ（冷光者＝通常は月）と読むが uṣṇāṃśuḥ（太陽）と註す。GRETIL はatuṣārakaraḥ（非冷光者＝太陽）と読む。

V.8
Sanskrit (IAST) gatavaty arājata japākusumastabakadyutau dinakare 'vanatim / bahalānurāgakuruvindadalapratibaddhamadhyam iva digvalayam //
和訳

木槿の花房のごとき赤い輝きの太陽が地平に沈みゆくと、地平線の環は、濃い紅の紅宝石の石片をはめ込んだ腕輪のように輝いた。

注

【Vallabhadeva】

沈みゆく木槿色の太陽を kuruvinda（紅宝石の一種）に見立て、地平線の環を腕輪に喩える utprekṣā。kuruvinda は padmarāga（紅玉）の一種。

【Mallinātha】

japākusumastabakadyuti は木槿の花房のごとき輝き。digvalayam（方角の環＝地平線の輪）を kuruvinda（紅宝石）をはめ込んだ腕輪（kaṅkaṇa）に擬する utprekṣā。

V.9
Sanskrit (IAST) drutaśātakumbhanibham aṃśumato vapur ardhamagnavapuṣaḥ payasi / ruruce viriñcinakhabhinnabṛhajjagadaṇḍaikatarakhaṇḍam iva //
和訳

水中に半ば沈んだ太陽の身体は、溶けた黄金のように輝いた——まるでブラフマーの爪で二つに割られた大宇宙卵の片方の殻のように。

注

【Vallabhadeva】

drutaśātakumbha は溶けた黄金。半ば沈んだ太陽の円盤を、ブラフマーの爪で割られた宇宙卵の半片に喩える。Vallabhadeva 本は vyarucad（√ruc の imperfect）と読む。

【Mallinātha】

upamāna（喩えるもの）が purāṇa（神話）に基づく upamā（直喩）。ruruce は √ruc の完了形。GRETIL の bṛhaddaṇaḍaka は bṛhajjagadaṇḍa の脱字（"jaga" 欠落）。

V.10
Sanskrit (IAST) anurāgavantam api locanayoḥ dadhataṃ vapuḥ sukham atāpakaram / nirakāsayad ravim apetavasuṃ viyadālayād aparadiggaṇikā //
和訳

両の眼に愛着を抱かせ、苦痛を与えぬ快い姿をしていたにもかかわらず、西の方角という遊女は、富を失った太陽を空の住処から追い出した。

注

【Vallabhadeva】

西方を遊女に擬する暗示的比喩の延長。遊女は金のある間は愛人を手元に置き、無一文になれば追い出す。太陽が光（＝富 vasu）を失って追い出される。anurāgavat は「情愛深い」と「赤く染まった」の両義。

【Mallinātha】

ekadeśarūpaṇa（部分的描写）により aparadiggaṇikā のような rūpaka（隠喩）が推知される ekadeśavṛtti rūpaka。atāpakara は「苦痛を与えない」と「灼熱でない」、apetavasu は「富を失った」と「光を失った」の śleṣa。

V.11
Sanskrit (IAST) abhitigmaraśmi ciramāviramād avadhānakhinnam animeṣatayā / vigalanmadhuvratakulāśrujalaṃ nyamimīlad abjanayanaṃ nalinī //
和訳

蓮池は、烈しい光を放つ太陽を、その沈むまで長い間、瞬きもせず見つめ続けて疲れた蓮の眼を、蜜蜂の群れという涙を流しながら、閉じた。

注

【Vallabhadeva】

蓮池を恋する女に擬えた ekadeśavṛtti rūpaka（部分的隠喩）。蓮（abja）を眼に、蜜蜂の群れの飛び去りを涙に見立てる。夫が遠方に去るとき、妻は瞬きせず見つめ続け、やがて涙ながらに眼を閉じる。nyamimīlad は ni+mīl の重複完了形。

【Mallinātha】

蓮池を恋する女と見る部分描写の隠喩。madhuvratakulam（蜜蜂の群れ）が aśrujalam（涙）に等しい。蓮の開閉を瞼の開閉になぞらえる。GRETIL「vigalannamadhu」は余分な na で13音節となり誤り、「vigalanmadhu」が正。「nmamīlad」も「nyamimīlad」の訛り。「ciramaviramād」は ciramāviramād と長母音で読むべし（第9音節が guru となり pramitākṣarā の sa-gaṇa に合致）。

V.12
Sanskrit (IAST) avibhāvyatārakam adṛṣṭahimadyutibimbam astamitabhānu nabhaḥ / avasannatāpam atamisram abhād apadoṣataiva viguṇasya guṇaḥ //
和訳

星は見えず、月の円盤も見えず、太陽も沈んだ空は、暑さも去り、闇もなく、輝いていた。徳なき者にとって、欠点がないことこそが徳である。

注

【Vallabhadeva】

空は星・月・太陽という美点を欠くが、暑さも闇もないという欠点の不在ゆえに輝く。「すぐれた徳のない者でも、害を為さぬ限りにおいてそれ自体が大いなる徳である」と。

【Mallinātha】

空の無徳（viguṇa）にもかかわらず、無過失（apadoṣatā）が徳（guṇa）であるという一般命題で具体例を補強する arthāntaranyāsa（意義転用）。avibhāvyatārakam は未だ星が見えない状態、astamitabhānu は太陽が沈んだ状態。

V.13
Sanskrit (IAST) rucidhāmni bhartari bhṛśaṃ vimalāḥ paralokam abhyupagate viviśuḥ / jvalanaṃ tviṣaḥ katham itarathā sulabho 'nyajanmani sa eva patiḥ //
和訳

光の宝庫たる夫が他界に赴いたとき、清浄な光線たちは火に入った。そうしなければ、来世で再びあの夫を得ることがどうしてできようか。

注

【Vallabhadeva】

ヴェーダの教え「太陽は夕方に火に入る（agniṃ vāvādityaḥ sāyam anu praviśati）」に基づく。光線が火に入ることで翌朝再び太陽と合一できる。貞女が夫の死後に火に入り来世で同じ夫を得る暗示。GRETIL「vivaśuḥ」は「viviśuḥ」（√viś の完了形）の誤り。

【Mallinātha】

光線の火への入没をヴェーダ聖典に基づき、貞女の殉死の論理で正当化する kāvyaliṅga（詩的論証）。「mṛte yā mriyate patyau sā strī jñeyā pativratā」の格言を踏まえる。itarathā は「さもなくば」。

V.14
Sanskrit (IAST) vihitāñjalir janatayā dadhatī vikasat kusumbhakusumāruṇatām / ciram ujjhitāpi tanur aujjhad asau na pitṛprasūḥ prakṛtim ātmabhuvaḥ //
和訳

人々に合掌で礼拝され、咲くベニバナのような紅色をまとい、永く捨てられた身でありながら、この祖霊の母たる躯は、自ら生ずる者の本性を捨てなかった。

注

【Vallabhadeva】

夕焼けを梵天（ātmabhū）が捨てた身体と見る。梵天が創造の際に祖霊たちを見て捨てた身体が saṃdhyā（薄明）となった伝承。世の人々に礼拝され、紅色を帯びるのは梵天と同じ本性。pitṛprasūḥ（祖霊の母）は薄明の異名。

【Mallinātha】

身体の放棄（tanūtyāga）という原因がありながら、本性の放棄（prakṛtityāga）という結果が生じない viśeṣokti（特殊陳述）。bhāviṣyapurāṇa を典拠とする。janatā は janasamūha（人々の群れ）。kusumbha はベニバナ。

V.15
Sanskrit (IAST) atha sāndrasāndhyakiraṇāruṇitaṃ harihetihūti mithunaṃ patatoḥ / pṛthag utpapāta virahārtidaladdhṛdayasrutāsṛganuliptam iva //
和訳

それから、濃い夕映えの光に赤く染められたチャクラヴァーカ鳥の番いは、離別の苦しみに裂ける心臓から流れ出た血に塗られたかのように、別れ別れに飛び立った。

注

【Vallabhadeva】

チャクラヴァーカ（赤雁）の番いは夜に別離するという伝承。赤い夕焼けの色を、離別の苦悶で裂けた心臓からの血に見立てる utprekṣā（見立て）。harihetihūti はヴィシュヌの武器 cakra（円盤）を叫声とする鳥、すなわちチャクラヴァーカ。

【Mallinātha】

sāndrasāndhya は濃い黄昏時の光線。harihetihūti = cakrāhva（チャクラヴァーカ）。ラーマの呪いにより夜に離れるという伝承（āgama）。赤色を心臓の血の utprekṣā で表す。hūti は長母音ū（韻律上 sa-gaṇa の要請）。

V.16
Sanskrit (IAST) nilayaḥ śriyaḥ satatam etad iti prathitaṃ yad eva jalajanma tayā / divasātyayāt tad api muktam aho capalājanaṃ prati na codyam adaḥ //
和訳

蓮は常にシュリーの住処であると世に知られている。その蓮すらも、日暮れに彼女に捨てられた。ああ、移り気な者に対しては、それも咎めるには及ばない。

注

【Vallabhadeva】

蓮をラクシュミーの永遠の住処とする定説にもかかわらず、夕方には蓮から離れる。己の家をも捨てる者を世間が不実と非難しても、もとより気まぐれな者に咎め立ては不要。capalājanam は「気まぐれな女性」と「ラクシュミー」の両義。

【Mallinātha】

jalajanma（水に生まれたもの＝蓮）を śleṣa（語義双関）で展開。capalājanam は「移り気な女」と「蓮に住むラクシュミー」の両義。śleṣamūla（双関に基づく）atiśayokti（誇張法）を arthāntaranyāsa（一般命題の適用）で補強する複合修辞。

V.17
Sanskrit (IAST) divaso 'numitram agamad vilayaṃ kim ihāsyate bata mayābalayā / rucibhartur asya virahādhigamād iti saṃdhyayāpi sapadi vyagami //
和訳

「昼は友に従って滅んだ。力なき女の私が、この輝きの主の離別を知って、ここに留まってどうしよう」と、薄暮もまた直ちに去った。

注

【Vallabhadeva】

薄暮を太陽の妻に擬え、その独白として構成。anumitram は「友（＝太陽 mitra）と共に」。abalā は「力なき女」。rucibhartṛ は「輝きの主」かつ「愛の夫」の śleṣa。夫とその友が亡びたなら、妻も留まる理由がない。Vallabhadeva 本は nyaśami（ni+√śam「静まった」）と読む。GRETIL「valayaṃ」は「vilayaṃ」（滅亡）の誤り。

【Mallinātha】

mitra は太陽の異名かつ友人の意の śleṣa。vilayam は滅亡。薄暮が自ら消え去る理由を独白形式（iti）で述べる utprekṣā。vyagami は vi+gam の luṅ（不定過去）。別読に vyaśami あり。

V.18
Sanskrit (IAST) patite pataṅgamṛgarāji nijapratibimbaroṣita ivāmbunidhau / atha nāgayūthamalināni jagat paritas tamāṃsi paritastarire //
和訳

太陽という獅子王が、自らの映像に怒ったかのように大海に沈んだとき、象の群れのごとく黒ずんだ闇が世界を四方から覆い尽くした。

注

【Vallabhadeva】

太陽を mṛgarāja（獅子王）と見る rūpaka（隠喩）。獅子が水面に映る自分の姿を敵と誤認して海に飛び込むと、象の群れが自由に闊歩する。同様に太陽が沈めば闇が世界を覆う。paritastarire は pari+√stṛ の完了形。

【Mallinātha】

pataṅgamṛgarāj（太陽＝獅子）は rūpaka 複合語。自らの映像（pratibimba）への怒りは utprekṣā（見立て）。闇を象の群れに擬える upamā が rūpaka と結合する saṅkara（混合修辞）。nāgayūthamalināni は upamitasamāsa。

V.19
Sanskrit (IAST) vyasaran nu bhūdharaguhāntarataḥ paṭalaṃ bahir bahalapaṅkaruci / divasāvasānapaṭunas tamaso bahir etya cādhikam abhakta guhāḥ //
和訳

泥のように黒く濃い闇の塊が山の洞窟の奥から外へ流れ出たのか、それとも日暮れに力を得た闇が外から来て洞窟をさらに深く満たしたのか。

注

【Vallabhadeva】

闇の出所をめぐる saṃdeha（疑惑）の修辞。闇が洞窟から外へ広がったのか、外から洞窟に入り込んだのか判別しがたい。V.20 と yugmaka（連句）を成す。GRETIL「pacalaṃ」は「paṭalaṃ」（塊・層）の誤り、「bhahala」は「bahala」（濃厚な）の転倒。

【Mallinātha】

bahalapaṅkaruci（濃い泥のような色）の闇が洞窟から出たのか入ったのかという saṃdehālaṅkāra（疑惑の修辞法）。闇の遍満性ゆえに出入りの判別がつかない。abhakta は √bhaj の luṅ（不定過去）。

V.20
Sanskrit (IAST) kim alambatāmbaravilagnam adhaḥ kim avardhatordhvam avanītalataḥ / visasāra tiryag atha digbhya iti pracurībhavan na niradhāri tamaḥ //
和訳

闇は空に懸かって下へ垂れたのか、大地から上へ伸びたのか、それとも四方から横に広がったのか。ますます濃くなりながら、その出所は定めがたかった。

注

【Vallabhadeva】

V.19 と yugmaka（連句）。闇の遍満がいかなる方向から来たか判別できぬ saṃdeha（疑惑）。pracurībhavat は「濃厚になりつつ」。niradhāri は √dhṛ の受動態 aorist「定められなかった」。

【Mallinātha】

V.19 と同じ saṃdehālaṅkāra の継続。空から垂れたか（alambata ambaravilagnam adhaḥ）、地から伸びたか（avardhata ūrdhvam avanītalataḥ）、四方から広がったか（visasāra tiryag digbhyaḥ）、いずれとも定められず。

V.21
Sanskrit (IAST) sthagitāmbarakṣititale paritas timire janasya dṛśam andhayati / dadhire rasāñjanam apūrvam ataḥ priyaveśmavartma sudṛśo dadṛśuḥ //
和訳

天地を覆った闇が人々の視力を奪ったとき、美しい女たちは前代未聞の目薬を塗った。それゆえに恋人の家への道を見出した。

注

【Vallabhadeva】

rasāñjana は二義——rāga（情愛）そのものが añjana（目薬）となる意と、実際の rasāñjana（薬用目薬）を差す意。情愛に満ちた者には闇も恐怖も障りとならない。GRETIL「apūrvataḥ」は「apūrvam ataḥ」の脱字（pāda c が11音節となる）。

【Mallinātha】

rasa（情愛）が añjana（目薬）となるという śleṣa を通じ、恋する女が闇中で恋人の家への道を見出すことを論証する kāvyaliṅga（詩的論証）。rasāñjana は siddāñjana（霊薬）とも掛かる。

V.22
Sanskrit (IAST) avadhārya kāryagurutām abhavan na bhayāya sāndratamasantamasam / sutanoḥ stanau ca dayitopagame tanuromarājipathavepathave //
和訳

逢引に赴く美女は、その目的の重大さを心に定めて、濃密に広がる闇も恐怖の種とはならず、その乳房も細い腹毛の道の震えの因とはならなかった。

注

【Vallabhadeva】

abhisārikā（逢引に赴く女）の場面。闇（saṃtamasa）も恐怖（bhaya）を生まず、乳房（stana）も中央の腹毛の道（tanuromarājipath）の震え（vepathave）を生じない。kāryagurutā = 目的（恋人との逢瀬）の重大さを悟ったがゆえに。

【Mallinātha】

sāndratama-saṃtamasam は「最も濃い遍満する闇」。kāryagurutā（目的の重さ）を悟れば恐怖も動揺もない。闇と乳房という二つの主語が恐怖と震えという二つの結果を生じない構成で、viśeṣokti に utprekṣā が内在する。

V.23
Sanskrit (IAST) dadṛśe 'pi bhāskararucāhni na yaḥ sa tamīṃ tamobhir adhigamya tatām / dyutim agrahīd grahagaṇo laghavaḥ prakaṭībhavanti malināśrayataḥ //
和訳

昼に太陽の光輝のもとでは見えなかった星々が、闇に満ちたかの夜に至って光を得た。卑小なる者は、劣悪な環境においてこそ顕わになるものだ。

注

【Vallabhadeva】

grahagaṇa は tārakā（星辰）全般の upalakaṣaṇa。昼には太陽の光に隠れていた星々が夜に輝く。「卑小な者が劣った環境で目立つ」の一般命題。agrahīt は √grah の luṅ。GRETIL「tamobir」は「tamobhir」の誤記、「abhigamya」は Mallinātha 本「adhigamya」と異読。

【Mallinātha】

grahagaṇa が昼に見えず夜に輝くことを arthāntaranyāsa（一般命題の適用）で敷衍。laghavaḥ（微小な者）が malināśrayataḥ（劣った境遇から）prakaṭībhavanti（目立つ）。

V.24
Sanskrit (IAST) anulepanāni kusumāny abalāḥ kṛtamanyavaḥ patiṣu dīpaśikhāḥ / samayena tena cirasuptamanobhavabodhanam samam abodhiṣata //
和訳

塗香、花々、夫に拗ねた女たち、灯火の焔——これらすべてが、その刻限に、長い眠りから覚めた愛の神の目覚めと共に、一斉に目覚めさせられた。

注

【Vallabhadeva】

宵の刻（pradoṣa）の到来により、anulepana（塗香）、kusuma（花）、dīpaśikhā（灯火）、kṛtamanyavaḥ abalāḥ（拗ねた女たち）が一斉に「目覚めさせられた」。cirasuptamanobhavabodhanam = 長い昼間眠っていた Kāma（愛の神）を目覚めさせること。GRETIL「dhīpaśikhāḥ」は「dīpaśikhāḥ」の誤り。

【Mallinātha】

塗香・花・怒れる女・灯火がいずれも Kāma の目覚めの手段であり、同時に「目覚めさせられた」対象でもある śleṣa に基づく atiśayokti の saṅkara（混合修辞）。abodhiṣata は bodhayati（使役）の受動態 luṅ。

V.25
Sanskrit (IAST) vasudhāntaniḥsṛtam ivāhipateḥ paṭalaṃ phaṇāmaṇisahasrarucām / sphuradaṃśujālam atha śītarucaḥ kakubhaṃ samaskuruta mādhavanīm //
和訳

それから、月の閃く光線の網が、大地の果てから現れた蛇王の千の頭巾宝石の輝きの塊のように、東の方角を飾り立てた。

注

【Vallabhadeva】

月光（aṃśujāla）が東方の地平から昇る様を、地中から出た阿難陀龍の頭巾宝石（phaṇāmaṇi）の光群に擬える utprekṣā。mādhavnī は māhendri（インドラの方角＝東方）。samaskuruta は sam+√kṛ「飾り立てた」。

【Mallinātha】

vasudhānta は地平。ahipati は Śeṣa 龍王。千の頭巾の宝石群の輝きが地中から出るかのような utprekṣā。kakubham は方角（diś）。saṃpūrvasya karoti に suṭ āgama で samaskuruta となる。

V.26
Sanskrit (IAST) viśadaprabhāparigataṃ vibabhāvudayācalavyavahitenduvapuḥ / mukham aprakāśadaśanaṃ śanakaiḥ savilāsahāsam iva śakradiśaḥ //
和訳

清らかな光に包まれ、東山に隠された月を内に秘めた東方の前面は、歯を見せずにゆっくりと艶やかに微笑む顔のように輝いた。

注

【Vallabhadeva】

東方（śakradiś）を女の顔に見立て、月の円盤（induvapus）を歯に、白い光輝を微笑に擬える。東山（udayācala）が月を遮るので aprakāśadaśanam（歯が見えない＝月が隠れた微笑）。

【Mallinātha】

東方の前面（mukha）が明るい光に包まれているが、月が東山に隠れて見えない状態を、歯を見せずに微笑む女の顔に擬える。prabhā＝微笑、śaśin＝歯の śleṣa-rūpaka。vibabhau は vi+√bhā の完了。

V.27
Sanskrit (IAST) kalayā tuṣārakiraṇasya puraḥ parimandabhinnatimiraughajaṭam / kṣaṇam abhyapadyata janair na mṛṣā gaganaṃ gaṇādhipatimūrtir iti //
和訳

月の細い光がその前方で闇の塊という結髪をわずかに分けている空は、人々によって一瞬、まさしくシヴァの御姿であると認められた。

注

【Vallabhadeva】

三日月（kalā）を前額の月、闇（timiraugha）を jaṭā（結び髪）に見立て、空全体をシヴァの身体と認識する rūpaka。ākāśa はシヴァの八身体（aṣṭamūrti）のひとつであり「虚妄ではなく（na mṛṣā）真実」。

【Mallinātha】

三日月を冠した闇の結髪という姿により空を gaṇādhipati（＝Śiva, pramathanātha）の顕現と認定する rūpaka。GRETIL「gaṇādipatimūrtir」は「gaṇādhipatimūrtir」の脱字。

V.28
Sanskrit (IAST) navacandrikākusumakīrṇatamaḥkabarībhṛto malayajārdram iva / dadṛśe lalāṭataṭahāri harer harito mukhe tuhinaraśmidalam //
和訳

新しい月光という花を散らした闇の黒髪を戴くインドラの方角の顔に、白檀を塗られたかのような月の断片が、額の飾りのように美しく見えた。

注

【Vallabhadeva】

東方（harer harit）の前面を女の顔に見立て、闇を黒髪（kavarī）に、新しい月光を花に、月の断片（tuhinaraśmidalam）を白檀（malayaja）に湿った額の飾りに擬える重層的隠喩。GRETIL「navacandrakā」は「navacandrikā」（月光）の誤り。

【Mallinātha】

candrikā（月光）を kusuma（花）に、tamas を kabarī（黒髪）に見立て、月の半片を白檀で湿った額の飾りとする。東方の擬人化と自然描写を重ねる ekadeśavivartirūpaka（部分転換的隠喩）と utprekṣā の saṅkara。

V.29
Sanskrit (IAST) prathamaṃ kalābhavad athārdham atho himadīdhitir mahad abhūd uditaḥ / dadhati dhruvaṃ kramaśa eva na tu dyutiśālino 'pi sahasopacayam //
和訳

月はまず細い一片であった。次に半月となり、やがて昇りきって大きく輝いた。光ある者は確かに、段階を経てこそ成長を遂げるものであり、突然にではない。

注

【Vallabhadeva】

月の段階的増大——細片（kalā）、半月（ardha）、完全な円盤——を描写し、「輝きある者は順を追ってのみ繁栄を得る」という格言で補強する。mahad abhūt は abhūtatad-bhāve cvi 構文。

【Mallinātha】

kalā（十六分の一）→ ardha（半分）→ mahad abhūt（大きくなった）と段階を踏む月の成長を、「光輝ある者も急には成長せず」という一般命題で裏付ける arthāntaranyāsa。

V.30
Sanskrit (IAST) udamajji kaiṭabhajitaḥ śayanād apanidrapāṇḍurasarojarucā / prathamaprabuddhanadarājasutāvadanenduneva tuhinadyutinā //
和訳

眠りから覚めた白蓮のような輝きをもつ月が、カイタバを倒した神の臥所から浮かび上がった——先に目覚めた大河の王の娘の顔という月によるかのように。

注

【Vallabhadeva】

kaiṭabhajit はヴィシュヌ。その śayana（臥所）は大海。月の浮上を、ヴィシュヌより先に目覚めた nadarājasutā（海の王の娘＝ラクシュミー）の顔から放たれた月光に擬える utprekṣā。

【Mallinātha】

apanidra-pāṇḍura-saroja-rucā は「眠りから覚めた白蓮の輝きをもつ」月を修飾。ラクシュミーが先に目覚め（prathamaprabuddhā）、海面に月が先に現れる情景を神話的に描く。udamajji は ud+√majj の受動態 luṅ。

V.31
Sanskrit (IAST) atha lakṣmaṇāgatakāntavapurjaladhiṃ vilaṅghya śaśidāśarathiḥ / parivāritaḥ parita ṛkṣagaṇaistimiraugharākṣasakulaṃ bibhide //
和訳

さて月は、ダシャラタの子ラーマのごとく、吉祥の印を伴う美しい姿で大海を渡り、四方を星の群れに囲まれつつ、闇という羅刹の一族を打ち砕いた。

注

【Vallabhadeva】

śleṣa（掛詞）の構造を示す。lakṣmaṇa は月の印（兎の紋）、かつラーマの弟ラクシュマナ。ṛkṣa は星座、かつジャーンバヴァット率いる熊の軍勢。月が大海を越えて闇を破る情景を、ラーマが海を渡りラークシャサを滅ぼした叙事詩に重ねる。

【Mallinātha】

śleṣa-saṃkīrṇa-rūpaka と認定。lakṣmaṇānugata は śabda-śleṣa（一語で二義）、ṛkṣagaṇa は artha-śleṣa（語は一つだが事物として二義：星群と熊群）。bibhide は √bhid の kartari liṭ。

V.32
Sanskrit (IAST) upajīvati sa satataṃ dadhataḥ parimugdhatāṃ vaṇigivoḍupateḥ / ghanavīthivīthimavatīrṇavato nidhirambhasāmupacayāya kalāḥ //
和訳

海という宝庫は、常に愛らしさを湛え雲の大道を降りゆく月の主から、己の増大のためにその相を搾取する——あたかも商人が世間知らずの者から利息を巻き上げるように。

注

【Vallabhadeva】

月の kalā（十六分の一の相）を、資本の利息（kalā）に掛ける。月光に触れて海が満ちる現象を、商人が素朴な者の利殖を搾取する比喩で描く。ghanavīthī（雲の街路＝空）を商業街路に重ねる upamita-samāsa。

【Mallinātha】

śleṣa-saṃkīrṇa-upamā。parimugdhatā は「美しさ」と「愚鈍さ」の二義（Viśva 辞典）。kalā は月の十六分の一相と利息の二義。nidhir ambhasām は大海。upacayāya は自らの潮の増大と財の増殖。

V.33
Sanskrit (IAST) rajanīmavāpya rucamāpa śaśī sapadi vyabhūṣayadasāvapi tām / avilambitakramamaho mahatāmitaretaropakṛtimaccaritam //
和訳

夜に達して月は輝きを得、直ちにその夜をも飾り立てた。ああ、偉大なる者たちの行いとは、遅滞なく、互いに恩恵を施し合うものである。

注

【Vallabhadeva】

夜と月が互いに美を与え合う相互修飾（anyonyālaṅkāra）。後半は arthāntaranyāsa（一般命題の挿入）：偉大な者の行いは迅速かつ相互扶助的であるという教訓。

【Mallinātha】

anyonyālaṅkāra の定義「互いが互いの生起原因となる」を引用。それを支える一般命題の arthāntaranyāsa との aṅgābhāvena saṃkara（従属関係なき合体修辞）。

V.34
Sanskrit (IAST) divasaṃ bhṛśoṣṇarucipādahatāṃ rudatīmivānavaratālirutaiḥ / muhurāmṛśan mṛgadharo 'grakarairudaśiśvasat kumudinīvanitām //

注

【Vallabhadeva】

kumudinī（蓮池）を vanitā（女性）に擬える rūpaka。pāda（光線／足）で打たれた女が泣き、夫が手で撫でて安心させる情景に重ねる。udaśiśvasat は √śvas 使役の luṅ（ṇic aorist）。

pāda が「光線」と「足」の śliṣṭa-rūpaka。ālirutaiḥ は蜂の鳴き声を泣き声に見立てる utprekṣā。kara が「光線」と「手」の二義で、月が蓮池の女を慰撫する重層的な rūpaka。vijātīya-saṃkara（異種修辞の合体）と認定。

V.35
Sanskrit (IAST) pratikāminīti dadṛśuścakitāḥ smarajanmagharmapayasopacitām / sudṛśo 'bhibhartṛśaśiraśmigalajjalabindumindumaṇidāruvadhūm //

美しい女たちは、夫のそばにある月光石の人形——月の光で水滴を滴らせ、情熱の汗に濡れたかのような姿——を恋敵だと思い込み、驚いて見つめた。

注

【Vallabhadeva】

indumaṇi（月光石＝candrakānta）の人形が月光で水滴を流す性質を利用し、女たちが情敵と誤認する bhrantimat-alaṅkāra（錯覚の修辞）。abhibhartṛ は「夫のそば」を意味する avyayībhāva。

【Mallinātha】

smarajanma-gharma-payasā は「恋によって生じた汗の水」。月光石の人形に sādṛśya（類似）による恋敵への誤認が成立し、bhrantimat-alaṅkāra と認定。

V.36
Sanskrit (IAST) amṛtadravairvidadhad abjadṛśām apamārgam oṣadhipatiḥ sma karaiḥ / parito visarpi paritāpi bhṛśaṃ vapuṣo 'vatārayati mānaviṣam //
和訳

薬草の王たる月は、甘露の滴る光の手で蓮の目の女たちを清め拭いつつ、全身に広がり激しく苦しめる怒りという毒を、その体から取り除いた。

注

【Vallabhadeva】

oṣadhipati は月であり同時に名医。amṛta-dravaiḥ karaiḥ は甘露の液を持つ光線であり薬液を持つ手。māna-viṣam（怒り＝毒）を体から除去するのは、毒蛇咬傷の治療師が手で触れて毒を抜く比喩。

śliṣṭa-rūpaka：oṣadhipati が「月」と「医師」の二義。amṛta は「甘露」と「薬」、kara は「光線」と「手」。apamārga は「清拭・除去」。蛇毒師の手の接触で毒が去るように、月の光の接触で女たちの怒りが消える upamā が含意される。

V.37
Sanskrit (IAST) amalātmasu pratiphalannabhitastaruṇīkapolaphalakeṣu muhuḥ / visasāra sāndrataramindurucāmadhikāvabhāsitadiśāṃ nikaraḥ //
和訳

すでに四方を照らしていた月光の群れは、若い女たちの清らかな頬の面に繰り返し両側から映り、さらに一層濃密に広がった。

注

【Vallabhadeva】

清らかな頬の面を鏡に見立て、月光が反射してさらに増す。清浄な人格に宿った者は必ずさらに輝きを増すという含意。

【Mallinātha】

月光が頬に映って実際に移動するわけではないが、移動したかのように述べる saṃbandhoktirūpa-atiśayokti（関係述定による誇張）と認定。鏡に光が移る原理（darpaṇa-saṃkramaṇa）に基づく。

V.38
Sanskrit (IAST) upagūḍhavelamalaghūrmibhujaiḥ saritāmacukṣubhadadhīśamapi / rajanīkaraḥ kimiva citramado yadurāgiṇāṃ gaṇamanaṅgalaghum //
和訳

月は、大波という腕で岸辺を力強く抱きしめる河川の王・大海をさえ動揺させた。ならば、愛神に心を軽くされた恋する者たちの群れを揺さぶったとて、何の不思議があろう。

注

【Vallabhadeva】

月の昇りで潮が満ちる自然現象を、月が海さえ動揺させる力として描き、まして恋人たちは容易だと推論する。ūrmi（波）を bhuja（腕）に擬え、vela（岸辺）を抱擁する rūpaka。

【Mallinātha】

arthāpatti（推論的含意）の修辞。揺るがし難い海でさえ揺らすのだから、既に恋に軽くなった者たちが揺らぐのは自明。acukṣubhat は √kṣubh 使役の luṅ（ṇic aorist）。daṇḍāpūpika-nyāya（杖と菓子の論理）に基づく。

V.39
Sanskrit (IAST) bhavanodareṣu parimandatayā śayito 'lasaḥ sphaṭikayaṣṭirucaḥ / avalambya jālakamukhopagatānudatiṣṭhadindukiraṇānmadanaḥ //
和訳

力なく室内に横たわっていた愛神は、格子窓から差し込む月の光——水晶の杖のように輝くそれ——を掴んで支えにし、身を起こした。

注

【Vallabhadeva】

日中は力を持たぬ愛神が、格子窓に差し込む月光を水晶の杖に見立て、それを支えに立ち上がる。dāru-vadhū（木偶）の杖と同じく、光の杖で起き上がるという atiśayokti。

【Mallinātha】

三種の修辞の合体（saṃkara）：sphaṭikayaṣṭirucaḥ は upamā（直喩）、avalambya は utprekṣā（月光を杖として掴んだ「かのように」という想像）、udatiṣṭhat は abheda-adhyavasāya-mūla-atiśayokti（覚醒と起立の同一視に基づく誇張）。

V.40
Sanskrit (IAST) avibhāviteṣuviṣayaḥ prathamaṃ madano 'pi nūnamabhavattamasā / udite diśaḥ prakaṭayatyamunā yadagharmadhāmni dhanurācakṛṣe //
和訳

はじめ愛神もまた、闇のために矢の的を見定められずにいたに違いない。涼しい光の月が昇り四方を照らし出すと、彼は弓を引き絞ったのだから。

注

【Vallabhadeva】

日中は闇がなく恋の矢も効かなかったが、月が昇り闇を払って対象が見えると愛神が弓を引く。agharmadhāman（涼光者）は月の異名。ācakṛṣe は √kṛṣ の kartari liṭ。

【Mallinātha】

nūnam（きっと）に utprekṣā（想像的推量）を認める。月の昇りが愛神の活動条件であるという因果関係を詠む。闇の中では矢の的（iṣu-viṣaya＝恋人たち）が見えなかったが、月光で可視になった。

V.41
Sanskrit (IAST) yugapadvikāsamudayādgamite śaśinaḥ śilīmukhagaṇo 'labhata / drutametya puṣpadhanuṣo dhanuṣaḥ kumude 'ṅganāmanasi cāvasaram //
和訳

月の昇りによって開花と高揚が同時にもたらされると、花の弓の弓から飛び出した蜂の矢の群れは、急ぎ来て、夜咲蓮にも女たちの心にも居場所を得た。

注

【Vallabhadeva】

śilīmukha は「蜂」と「矢」の二義。月の昇りで蓮が開き女心も高まる。蜂は花弓（カーマの弓）から飛び出し、蓮の中に入り、同時に矢として女の心にも刺さる。vikāsa は花の開花と心の高揚の二義。

【Mallinātha】

śilīmukha の二義（蜂と矢）の同一視による atiśayokti の prasāda（余韻）を含む tulyayogitā（等しい属性の結合）。蓮と女心の両方に「蜂＝矢が入る」という一つの dharma（属性）が成立する。

V.42
Sanskrit (IAST) kakubhāṃ mukhāni sahasojjvalayan dadhadākulatvamadhikaṃ rataye / adidīpadinduraparo dahanaḥ kusumeṣumatrinayanaprabhavaḥ //
和訳

四方の面を瞬く間に照らし、情事への渇望を一層掻き立てつつ、アトリ仙の眼から生まれた月は、もう一つの火として花矢の神を燃え立たせた。

注

【Vallabhadeva】

月はアトリの眼から生まれた（atri-nayana-prabhava）。三眼の神（シヴァ）の眼から生まれた火はカーマを焼いたが、こちらの火（月）はカーマを燃え立たせる——もう一つの火（aparo dahana）。

【Mallinātha】

atrinayanaprabhava は「アトリの眼から生まれた」と「三眼の神からは生まれていない」の二義。シヴァの火がカーマを焼滅させたのに対し、月は「燃え立たせる」（dīpayati）。dīpana は「煽動」と「点火」の意をかけ、utprekṣā（火への想像的同一視）と認定。

V.43
Sanskrit (IAST) iti niścitapriyatamāgatayaḥ sitadīdhitāvudayavatyabalāḥ / pratikarma kartumucakramire samaye hi sarvamupakāri kṛtam //
和訳

このようにして、白い光の月が昇ると、愛しい人の来訪を確信した女たちは、化粧を始めた。時宜にかなえばこそ、すべての行いは益をもたらすのだから。

注

【Vallabhadeva】

pratikarma は化粧・身繕い。月の昇りから恋人の来訪を確信して化粧に取りかかる。後半は arthāntaranyāsa：適切な時に行えばすべてが有益になるという一般命題。

【Mallinātha】

以上で candrodaya（月の昇り）という uddīpana-vibhāva（煽動的状況因）の記述を終え、その結果を述べる。pratikarma は「化粧」（Amarakoṣa）。samaye kṛtam は「好機に為されたこと」。arthāntaranyāsa。

V.44
Sanskrit (IAST) samamekameva dadhatuḥ sutanor guruhārabhūṣaṇamurojataṭau / ghaṭate hi saṃhatatayā janitāmidameva nirvivaratāṃ dadhatoḥ //
和訳

美しい女の両の胸の斜面は、重い真珠の首飾りという一つの装飾を均しく戴いた。密着して隙間のない二つのものには、こうした共有こそ相応しいのだから。

注

【Vallabhadeva】

muktā-kalāpa（真珠の首飾り）が一つだけ両胸に共有される。両胸は密着して隙間がないゆえ、装飾品の共有が自然に成り立つ。同志の間では利益も共有されるという含意。

【Mallinātha】

saṃhatatā（密着）により nirvivaratā（隙間のなさ）が生じた二者の間では、一つの装飾の共有こそが適う。胸の間に隙間がないので別々の装飾を入れる余地がないという物理的理由と、一致団結した者には享受の共有が自然だという道徳的含意。

V.45
Sanskrit (IAST) kadalīprakāṇḍarucirorutarau jaghanasthalīparisare mahati / raśanākalāpakaguṇena vadhūrmakaradhvajadviradamākalayat //
和訳

芭蕉の幹のように美しい太腿という二本の樹がそびえる大きな腰の周辺で、ある女は腰飾りの紐という綱でカーマという象を繋ぎ止めた。

注

【Vallabhadeva】

腰回り全体を sāvayava-rūpaka（要素ごとの隠喩）で構成。太腿は芭蕉の幹に似た二本の樹、腰飾りの紐（raśanā-kalāpaka-guṇa）は象を繋ぐ綱、makaradhvaja（カーマ）は象。腰飾りの装着がカーマを捕縛する情景に重なる。

【Mallinātha】

samasta-vastu-varti sāvayava-rūpaka（全体に及ぶ要素的隠喩）。jaghanasthalī-parisara は腰の周辺地帯。kadalī-prakāṇḍa は芭蕉の幹で、太腿の滑らかさと美しさの比喩。taru-śabda で「木」と重ねるのは punarukti（重複）ではなく、「繋がれうる木」としての意味を加えるため。

V.46
Sanskrit (IAST) adhareṣvalaktakarasaḥ sudṛśāṃ viśadaṃ kapolabhuvi lodhrarajaḥ / navamañjanaṃ nayanapaṅkajayorvibhide na śaṅkhanihitātpayasaḥ //
和訳

美しい女たちの唇のラックの赤、頬の白いロードラ粉、蓮の目の新しい墨——これらは法螺貝に盛った牛乳と見分けがつかなかった。

注

【Vallabhadeva】

天性の美しい唇に塗るラック液、白い頬に載せるロードラ粉、美しい目に引く墨——いずれも法螺貝に入れた牛乳のように、容器の白さに溶けて区別がつかない。女たちの素肌の美しさゆえ化粧品が目立たないことを讃える。

【Mallinātha】

nidarśanālaṅkāra（例証の修辞）。化粧品がその下地と同質に見えるという不可能な状況を、法螺貝に入れた牛乳に喩えて一体化を述べる。結果として sāmānyālaṅkāra（性質の同一性に基づく共通の修辞）が含意される。

V.47
Sanskrit (IAST) sphuradujjvalādharadalaīrvilasaddaśanāṃśukeśarabharaiḥ paritaḥ / dhṛtamugdhagaṇḍaphalakairvibabhurvikasadbhirāsyakamalaiḥ pramadāḥ //

āsya-kamala（顔蓮）の rūpaka により、女たちが蔓草のように推測される ekadeśivartin sāvayava-rūpaka。adhara-dala は唇＝花弁、daśana-aṃśu-keśara は歯光＝蕊、gaṇḍa-phalaka は頬＝花托。

V.48
Sanskrit (IAST) bhajate videśamadhikena jitastadanupraveśamathavā kuśalaḥ / mukhamindurujjvalakapolamataḥ pratimācchalena sudṛśāmaviśat //

注

【Vallabhadeva】

月は女たちの頬の美しさに打ち負かされたが、巧みなので映り込み（pratimā）という口実で彼女らの顔に入った。月の敗北と侵入を政治的比喩で描く。

【Mallinātha】

前半は kāvyaliṅga（詩的根拠）：月が顔に映る理由を、敗者の処世術として提示。後半は apahnuty-alaṅkāra（否認の修辞）：映像としての月は実は月そのものだという含意。chala（口実）の語がそれを暗示する。二つの修辞の saṃkara。

V.49
Sanskrit (IAST) dhruvamāgatāḥ pratihatiṃ kaṭhine madaneṣavaḥ kucataṭe mahati / itarāṅgavanna yadidaṃ garimaglapitāvalagnamagamattanutāṃ //
和訳

カーマの矢はきっとあの大きく堅い胸の斜面で跳ね返されたに違いない。だからこそこの胸は、他の部位のように、自らの重みに圧されてすがりつく腰が細くなったのに、痩せ細ることがなかったのだ。

注

【Vallabhadeva】

カーマの矢は他の肢体を痩せさせるが、胸だけは大きく堅いため跳ね返された。腰は胸の重みで圧されて細くなった（garima-glapita-avalagna）が、胸自体は痩せなかった。

【Mallinātha】

胸（kucataṭa）の堅さと大きさゆえにカーマの矢が弾かれた推論。itarāṅgavat は「他の肢体のように」。細い腰は胸の重みに押し潰されたのであって、カーマの矢の効果ではない。

V.50
Sanskrit (IAST) na manoramāsvapi viśeṣavidāṃ niraceṣṭa yogyamidametaditi / gṛhameṣyati priyatame sudṛśāṃ vasanāṅgarāgasumanaḥsu manaḥ //
