マハーバーラタ ― カルナ篇 第93章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 93 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ93」で、シャリヤとカルナの会話、クリシュナとアルジュナの会話の場面を描きます。
karṇaparva — trinavatitamo'dhyāyaḥ (93)
第93章 ― シャリヤとカルナの会話、クリシュナとアルジュナの会話
sañjaya uvāca|
rathau tayoḥ śvetahayau divyau yuktau mahāsvanau|
samāsthitau lokavīrau śaṅkhāndadhmuḥ pṛthakpṛthakam|
vāsudevārjunau vīrau karṇaśalyau ca bhārata||
// 8-93-1 //
サンジャヤは語った。
白い馬をつけた二台の戦車は神々しく、大きな音を立てていた。世界の英雄たちが乗り込み、それぞれ法螺貝を吹き鳴らした。ヴァースデーヴァ（クリシュナ）とアルジュナ、カルナとシャリヤが。バーラタよ。
tadbhīrusantrāsakaraṃ yuddhaṃ samabhavattadā|
anyonyaspāṃdhenorugraṃ śakraśambarayoriva||
// 8-93-2 //
臆病者を震え上がらせるような恐ろしい戦いが始まった。互いに傷つけ合う激烈な戦い、まるでシャクラ（インドラ）とシャンバラのようであった。
tayordhvajau hi vimalau śuśubhāte rathe sthitau|
rāhuketū yathā''kāśe uditau jagataḥ kṣaye||
// 8-93-3 //
二人の旗印は曇りなく輝き、戦車の上にそびえていた。あたかも世界の終末に天空に現れたラーフとケートゥ（蝕の星）のように。
karṇasyāśīviṣanibhā ratnasāramayī dṛढ़ā|
purandaradhanuḥ prakhyā hastikakṣyā virājate||
// 8-93-4 //
カルナの旗竿には、毒蛇のような、宝石で作られた堅固な、インドラの弓に似た象の腹帯が輝いていた。
kapiśreṣṭhastu pārthasya vyāditāsya ivāntakaḥ|
daṃṣṭrābhirbhīṣayanbhābhirdurnirīkṣyo raviryathā||
// 8-93-5 //
パールタ（アルジュナ）の猿の旗は、終末の神のように口を開き、牙で恐れさせ、光で太陽のように見つめがたかった。
yuddhābhilāṣuko bhūtvā dhvajo gāṇḍīvadhanvanaḥ|
karṇadhvajamupātiṣṭhatsvasthānādvegavānkapiḥ||
// 8-93-6 //
戦いを望むガーンディーヴァの弓の持ち主の旗が、その場所から勢いよく飛び出し、カルナの旗に襲いかかった。
utpatya ca mahāvegaḥ kakṣyāmabhyāhanattadā|
nakhaiś ca daśanaiścaiva garuḍaḥ pannagaṃ yathā||
// 8-93-7 //
大きな勢いで飛び上がり、爪と歯で腹帯を攻撃した。まるでガルダ（鷲の王）が蛇を攻撃するように。
sā kiṅkiṇīkābharaṇā kālapāśopamā tadā|
abhyadravatsusaṃrabdhā hastikakṣyā'tha taṃ kapim||
// 8-93-8 //
鈴の飾りをつけた、死の縄のような象の腹帯もまた、怒り猛って猿の旗に襲いかかった。
tayorghoratare yuddhe dvairathe dyūta āhite|
prākurvatāṃ dhvajau yuddhaṃ pūrvaṃ pūrvataraṃ tadā||
// 8-93-9 //
この二人のもっとも恐ろしい一騎討ちの前に、まず旗印同士が先に戦いを行った。
hayā hayānabhyaheṣanspardhamānāḥ parasparam|
avidhyatpuṇḍarīkākṣaḥ śalyaṃ nayanasāyakaiḥ|
śalyaś ca puṇḍarīkākṣaṃ tathaivābhisamaikṣata||
// 8-93-10 //
馬たちも互いにいなないて競い合った。プンダリーカークシャ（蓮の目のクリシュナ）はシャリヤを視線の矢で射た。シャリヤもまたプンダリーカークシャ（クリシュナ）を同じように見つめた。
tatrājayadvāsudevaḥ śalyaṃ nayanasāyakaiḥ|
karṇaṃ cāpyajayadṛṣṭyā kuntīputro dhanañjayaḥ||
// 8-93-11 //
そこではヴァースデーヴァが視線の矢でシャリヤに勝ち、クンティーの息子ダナンジャヤもまた視線でカルナに勝った。
ayābravītsūtaputraḥ śalyamābhāṣya sasmitam||
// 8-93-12 //
するとスータの息子（カルナ）は微笑みながらシャリヤに話しかけて言った。
yadi pārtho raṇe hanyādadya māmiha karhicit|
kiṃ kariṣyasi saṅghāme śalya satyamathocyatām||
// 8-93-13 //
「もしパールタが今日この戦場で私を討ち取ったなら、シャリヤよ、おまえは戦いで何をするか。本当のことを言え。」
śalya uvāca|
yadi karṇa raṇe hanyādadya tvāṃ śvetavāhanaḥ|
ubhāvekarayenāhaṃ hanyāṃ mādhavapāṇḍavau||
// 8-93-14 //
シャリヤは言った。「カルナよ、もし白い馬の戦士（アルジュナ）が今日おまえを討ち取ったなら、私は一人で戦車に乗り、マーダヴァ（クリシュナ）とパーンダヴァ（アルジュナ）の二人を討ち取ってみせよう。」
sañjaya uvāca|
evameva tu govindamarjunaḥ pratyabhāṣata|
taṃ prahasyābravītkṛṣṇaḥ pārthaṃ paramidaṃ vacaḥ||
// 8-93-15 //
サンジャヤは語った。 同じようにアルジュナもゴーヴィンダ（クリシュナ）に問いかけた。するとクリシュナは笑ってパールタにこの最高の言葉を語った。
pateddivākaraḥ sthānācchīryedbhūmiranekadhā|
śailyamagniriyānna tvāṃ hanyātkārṇo dhanañjaya||
// 8-93-16 //
「太陽がその位置から落ち、大地が幾つにも砕け、山が火に飲み込まれても、カルナがおまえを討つことはない、ダナンジャヤよ。」
yadi caitatkathañcitsyāllokaparyasanaṃ bhavet|
hanyāṃ karṇaṃ tathā śalyaṃ bāhubhyāmeva saṃyuge||
// 8-93-17 //
「もし万が一そのようなことが起こり、世界が滅亡するようなことがあっても、私がこの両腕でカルナとシャリヤを戦場で討ち取ろう。」
iti kṛṣṇavacaḥ śrutvā prahasankapiketanaḥ|
arjunaḥ pratyuvācedaṃ kṛṣṇamakliṣṭakāriṇam||
// 8-93-18 //
クリシュナの言葉を聞いて、猿の旗の戦士アルジュナは笑いながら、苦なく事を成すクリシュナにこう答えた。
mama tāvadaparyāptau karṇaśalyau janārdana|
sapatākadhvajaṃ karṇaṃ saśalyarathavājinam||
sacchatrakavacaṃ caiva saśaktiśarakārmukam|
draṣṭā'syadya raṇe kṛṣṇa śaraiśchinnamanekadhā||
// 8-93-19-20 //
「ジャナールダナ（クリシュナ）よ、カルナとシャリヤは私一人で十分だ。旗と旗竿のついたカルナを、シャリヤと戦車と馬もろとも、傘と鎧もろとも、槍と矢と弓もろとも、今日の戦場で矢によって幾つにも切り刻まれたのを見届けるがよい、クリシュナよ。」
adyaiva sarathaṃ sāśvaṃ saśaktikavacāyudham|
sañcūrṇitamivāraṇye vṛkṣaṃ paśyādya dantinā||
// 8-93-21 //
「今日こそ戦車と馬もろとも、槍と鎧と武器もろとも、森の中で象に踏み潰された木のように粉砕されたカルナを見よ。」
adya rādheyabhāryāṇāṃ vaidhavyaṃ samupasthitam|
dhruvaṃ svapneṣvaniṣṭāni tābhirdṛṣṭāni mādhava||
// 8-93-22 //
「今日、ラーデーヤ（カルナ）の妻たちに寡婦の身が訪れた。きっと彼女たちは夢に不吉なものを見たことだろう、マーダヴァよ。」
draṣṭāsi dhruvamadyaiva vidhavāḥ karṇayoṣitaḥ|
na hi me śāmyate manyuryadanena purā kṛtam||
// 8-93-23 //
「確かに今日、カルナの妻たちが寡婦となるのを見届けるだろう。あの男が以前なしたことへの私の怒りは収まらないのだ。」
kṛṣṇāṃ sabhāgatāṃ dṛṣṭvā mūḍhenādīrghadarśinā|
asmāṃstathā'vahasatā kṣipatā ca punaḥpunaḥ||
// 8-93-24 //
「あの愚かで先の見えない者が、サバー（集会場）に連れてこられたクリシュナー（ドラウパディー）を見て、我々を何度も嘲笑し侮辱した。」
adya draṣṭāsi govinda karṇamunmathitaṃ mayā|
vāraṇeneva mattena puṣpitaṃ gajatīruham||
// 8-93-25 //
「今日、ゴーヴィンダよ、猛った象が花咲く樹を引き倒すように、私がカルナを打ち砕くのを見届けるがよい。」
adya tā madhurā vācaḥ śrotāsi madhusūdana|
diṣṭyā jayasi vārṣṇeya iti karṇe nipātite||
// 8-93-26 //
「今日、おまえは甘い言葉を聞くだろう、マドゥスーダナよ。カルナが倒された時、『ヴァールシュネーヤ（クリシュナ）よ、幸いにもおまえは勝った！』と。」
adyābhimanyujananīṃ prahṛṣṭaḥ sāṃtvayiṣyasi|
kuntīṃ pitṛṣvasāraṃ ca prahṛṣṭaḥ san janārdana||
// 8-93-27 //
「今日、私は喜んでアビマニユの母（スバドラー）を慰めるだろう。そして叔母のクンティーも、ジャナールダナよ、喜びをもって。」
adya bāṣpamukhīṃ kṛṣṇāṃ sāntvayiṣyasi mādhava|
vāgbhiścāmṛtakalpābhirdharmarājaṃ ca pāṇḍavam||
// 8-93-28 //
「今日、涙に濡れた顔のクリシュナー（ドラウパディー）を、甘露のような言葉で慰めるだろう、マーダヴァよ。そしてパーンダヴァのダルマラージャ（ユディシュティラ）も。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe trinavatitamo'dhyāyaḥ|| 93 ||
こうして、聖なる大マハーバーラタのカルナ篇の第93章は終わる。
