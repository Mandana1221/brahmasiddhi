マハーバーラタ ― カルナ篇 第57章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 57 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ57」、全46詩節からなり、カルナとパーンダヴァ軍・ドゥルヨーダナ軍の入り乱れた大規模戦闘（サンクラ・ユッダ）の再開を描きます。ドゥリタラーシュトラがサンジャヤに、パーンディヤ王が討たれた後アルジュナは何をしたかを問う冒頭部分（第1〜3詩節）に続き、サンジャヤの語りに転じ（第4詩節冒頭の「サンジャヤは語った」）、クリシュナがアルジュナに戦況を告げ、アルジュナが急戦を命じる場面（第4〜11詩節）、クリシュナが出発する場面（第12詩節）、パーンダヴァ側とカウラヴァ側が再集結して凄まじい乱戦が展開する場面（第13〜20詩節）、ドゥルヨーダナ（ドゥリシュタデュムナ）対カルナ（ラーデーヤ）の激戦（第21〜33詩節）、そしてドラウニ（アシュヴァッターマン）がドゥルヨーダナ（ドゥリシュタデュムナ）に迫る場面（第34〜46詩節）で本章は終わります。なお、本章でも冒頭の「ドゥリタラーシュトラは語った」の一文に付された余分な注記「8-57-0」「8-57-0x」が第1詩節の本文に統合されており、また第3〜4詩節間に現れる「サンジャヤは語った」の語り手転換も注記「8-57-4x」として処理され、第4詩節冒頭に自然に統合されています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜56章に続き七章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、第1詩節「दृतराष्ट्र」のध（dh）の脱落（dṛtarāṣṭra→dhṛtarāṣṭra）、第14詩節「हुनः」のप/ह（pa/ha）字形混同（hunaḥ→punaḥ「再び」、前後文脈の「再び集結」に対応）、第14詩節「युधिषरमुखाः」の「ष्ठिर」→「षर」脱落・誤記（yudhiṣaramukhāḥ→yudhiṣṭhiramukhāḥ「ユディシュティラを先頭とする」）、第15詩節「यूद्धं」の長音誤記（yūddhaṃ→yuddhaṃ）、第18詩節「कार्णो」の余分な長母音（kārṇo→karṇo「カルナ」）、第41詩節「रैरिणं」のर/व（ra/va）字形混同（rairiṇaṃ→vairiṇaṃ「仇敵」、日本語訳「究極の仇敵」との対応から確認）を、それぞれ文脈・語形・字形類似の照合により修正しています。なお第7詩節および第12詩節の一部にバックティック「\`」とアポストロフィ「'」による不明な引用符的記号が見られますが、他章と同様の正規化（バックティックをアポストロフィへ変換）のみを行っています。
karṇaparva — saptapañcāśo'dhyāyaḥ (57)
第57章
dhṛtarāṣṭra uvāca|
pāṇḍye hate kim akarod arjuno jayatāṃ varaḥ|
ekavīreṇa karṇena drāvite ca yudhiṣṭhire||
// 8-57-1 //
ドゥリタラーシュトラは語った。
パーンディヤが殺され、勝者の最良アルジュナは何をしたか。一人の勇者カルナにユディシュティラが追い払われた後は。
samāptavidyo balavān yukto vīraś ca pāṇḍavaḥ|
sarvabhūteṣv anujñātaḥ śaṅkareṇa mahātmanā||
// 8-57-2 //
ドゥリタラーシュトラは語った。
学を修め力強く、勇士であるパーンダヴァは、全ての存在の中でマハートマン・シャンカラ（シヴァ）に「汝は無敵であろう」と祝福された。
tasmān mahadbhayaṃ tīvram amitraghnāt dhanañjayāt|
sa yat tatrākarot pārthas tan mama ācakṣva sañjaya||
// 8-57-3 //
ドゥリタラーシュトラは語った。
それゆえ敵を滅ぼすダナンジャヤから大いなる恐怖がある。サンジャヤよ、パールタがそこで何をしたか語ってくれ。
sañjaya uvāca|
hate pāṇḍye'rjunaṃ kṛṣṇas tvaran nāha vaco hitam|
hataṃ paśya svarājānam apayātāṃś ca pāṇḍavān||
// 8-57-4 //
サンジャヤは語った。
パーンディヤが殺されると、クリシュナは急いでアルジュナにためになる言葉を語った。「自らの王が倒され、パーンダヴァ軍が退却しているのを見よ。
karṇaṃ paśya mahāraṅge jvalantam iva pāvakam|
asau bhīmo maheṣvāsaḥ prativṛtto raṇaṃ prati||
// 8-57-5 //
サンジャヤは語った。
大闘技場で燃える火のようなカルナを見よ。あのビーマは大弓手として戦場に引き返している。
ta ime nānuvartante dhṛṣṭadyumnapurogamāḥ|
pāñcālāḥ sṛñjayāś caiva pāṇḍavānāṃ camūmukham||
// 8-57-6 //
サンジャヤは語った。
しかしドゥリシュタデュムナを先頭とするパーンチャーラ族やスリンジャヤ族は、パーンダヴァ軍の前線を維持していない。
'nivṛttaiś ca punaḥ pārthair bhagnaṃ śatrubalaṃ mahat'|
kauravān dravato hy eṣa karṇo vārayate bhṛśam||
// 8-57-7 //
サンジャヤは語った。
パールタたちが引き返すと、敵の大軍は再び崩壊した。カルナは逃げるカウラヴァ軍を懸命に食い止めている。
antakapratimo vege śakratulyaparākramaḥ|
asau gacchati kaunteya drauṇiḥ śastrabhṛtāṃ varaḥ||
// 8-57-8 //
サンジャヤは語った。
速さで死神に匹敵し、武勇でインドラに等しいドラウニ、武器を持つ者の最良者が向かっている。クンティーの息子よ。
tam eṣa pradrutaḥ saṅkhye dhṛṣṭadyumno mahārathaḥ|
aśvatthāmnā hatāḥ saṅkhye sarve kaunteya sṛñjayāḥ||
// 8-57-9 //
サンジャヤは語った。
大戦車戦士ドゥリシュタデュムナが戦場でドラウニに追われている。クンティーの息子よ、アシュヴァッターマンは戦場でスリンジャヤ族を全て殺した。
rathāśvanaranāgānāṃ kṛtaṃ ca kadanaṃ mahat|
ity etat sarvam ācaṣṭa vāsudevaḥ kirīṭine||
// 8-57-10 //
サンジャヤは語った。
戦車・馬・人間・象に大殺戮がなされた。」このすべてをヴァースデーヴァはキリーティンに伝えた。
etac chrutvā ca dṛṣṭvā ca bhrātṛṇāṃ vyasanaṃ mahat|
vāhaya aśvān hṛṣīkeśa kṣipram ity āha pāṇḍavaḥ||
// 8-57-11 //
サンジャヤは語った。
これを聞き、兄弟たちの大きな危機を見て、パーンダヴァは言った。「フリシーケーシャよ、馬を速く走らせよ。」
tataḥ prāyād dhṛṣīkeśo rathena apratimo yudhi|
'tato reṇuḥ samabhavat punas tatra mahāraṇe||
// 8-57-12 //
サンジャヤは語った。
するとフリシーケーシャは比類なき戦車で出発した。
tato rājan mahān āsīt saṅgāmo romaharṣaṇaḥ|
siṃhanādaravāś ca atra prādurāsan samāgame|
ubhayoḥ senayo rājan mṛtyuṃ kṛtvā nivartanam||
// 8-57-13 //
サンジャヤは語った。
王よ、大いなる戦いで再び身の毛がよだつ激戦が起こった。双方の軍で死を覚悟してライオンの吼え声が起こった。
tataḥ punaḥ samājagmur abhītāḥ kurusṛñjayāḥ|
yudhiṣṭhiramukhāḥ pārthā vaikartanamukhā vayam||
// 8-57-14 //
サンジャヤは語った。
恐れなきクルとスリンジャヤは再び集結した。パールタたちはユディシュティラを先頭に、我らはヴァイカルタナ（カルナ）を先頭に。
tataḥ pravavṛte yuddhaṃ ghorarūpaṃ viśāmpate|
karṇasya pāṇḍavānāṃ ca yamarāṣṭravivardhanam||
// 8-57-15 //
サンジャヤは語った。
王よ、カルナとパーンダヴァの間にヤマの国を膨らませる恐ろしい戦いが再開された。
tasmin pravṛtte saṅgrāme tumule romaharṣaṇe|
saṃśaptakeṣu vīreṣu kiñcic cheṣeṣu bhārata||
// 8-57-16 //
サンジャヤは語った。
バーラタよ、サムシャプタカの勇者たちがわずかに残る中で、この凄まじく身の毛がよだつ戦いが始まった。
dhṛṣṭadyumno mahārāja sahitaḥ sarvarājabhiḥ|
karṇam eva abhidudrāva pāṇḍavāś ca mahārathāḥ||
// 8-57-17 //
サンジャヤは語った。
大王よ、ドゥリシュタデュムナは全ての王たちとともに、大戦車戦士パーンダヴァたちとともに、カルナに向かって突進した。
āgacchamānāṃs tān dṛṣṭvā saṅgrame vijayaiṣiṇaḥ|
dadhāra ekaḥ raṇe karṇo jalaughān iva parvataḥ||
// 8-57-18 //
サンジャヤは語った。
勝利を求めて向かってくる彼らを見て、カルナは一人で戦場に踏みとどまった。山が水流を受け止めるように。
samāsādya tu te karṇaṃ vyaśīryanta mahārathāḥ|
yathā'calaṃ samāsādya vāryodhāḥ sarvatodiśam||
// 8-57-19 //
サンジャヤは語った。
しかしカルナに到達した大戦車戦士たちは崩壊した。山に当たって四方に砕ける水の流れのように。
tayor āsīn mahārāja saṅgrāmo ghoradarśanaḥ|
pravṛddhayoḥ mahāraṅge balinoḥ vijigīṣatoḥ||
// 8-57-20 //
サンジャヤは語った。
大王よ、二人の間の戦闘は恐ろしい姿であった。大闘技場で成長した二人の強者が勝利を争い。
dhṛṣṭadyumnas tu rādheyaṃ śareṇa anataparvaṇā|
chādayāmāsa saṅkruddhas tiṣṭha tiṣṭheti ca abravīt||
// 8-57-21 //
サンジャヤは語った。
ドゥリシュタデュムナは怒り狂って、しなやかな矢でラーデーヤ（カルナ）を覆い、「止まれ、止まれ！」と叫んだ。
vijayaṃ tu dhanuḥ śreṣṭhaṃ vidhṛnvāno mahārathaḥ|
pārṣatasya dhanuś chittvā śarāṃś ca āśīviṣopamān||
// 8-57-22 //
サンジャヤは語った。
大戦車戦士は最上の弓ヴィジャヤをしならせ、パールシャタの弓を断ち切り、毒蛇のような矢を、
vavarṣa śaravarṣāṇi toyavarṣān iva ambudaḥ|
chādayāmāsa saṅkruddhaḥ pārṣataṃ navabhiḥ śaraiḥ||
// 8-57-23 //
サンジャヤは語った。
矢の雨として雨雲が水を降らすように浴びせかけ、怒ってパールシャタを九本の矢で覆った。
te hemavikṛtaṃ varma bhittvā tasya mahātmanaḥ|
śoṇitāktā vyarājanta śakragopā iva anagha||
// 8-57-24 //
サンジャヤは語った。
黄金で飾られたそれらの矢は、偉大な魂の鎧を貫き、血に染まって輝いた。てんとう虫のように美しく。
tad apāsya dhanuś chinnaṃ dhṛṣṭadyumnaḥ pratāpavān|
tato'nyad dhanurādāya sāravad bhārasādhanam|
karṇaṃ vivyādha saptatyā śaraiḥ sannataparvabhiḥ||
// 8-57-25 //
サンジャヤは語った。
ドゥリシュタデュムナは切られた弓を捨て、勇猛にも別の丈夫で重い弓を取り、しなやかな七十本の矢でカルナを射た。
tathā eva rājan karṇo'pi pārṣataṃ śatrutāpanam|
droṇaśatruṃ maheṣvāso vivyādha niśitaiḥ śaraiḥ||
// 8-57-26 //
サンジャヤは語った。
同様に王よ、カルナもまた、敵を苦しめるドローナの敵たる大弓手パールシャタを鋭い矢で射た。
punar anyaṃ mahārāja śaraṃ kanakabhūṣaṇam|
preṣayāmāsa samare mṛtyudaṇḍam iva aparam||
// 8-57-27 //
サンジャヤは語った。
大王よ、さらに別の黄金で飾られた矢を、もう一本の死の杖のように戦場に放った。
tam āpatantaṃ sahasā ghorarūpaṃ viśāmpate|
ciccheda śatadhā rājan pārṣataḥ kṛtahastavat||
// 8-57-28 //
サンジャヤは語った。
王よ、飛来する恐ろしい姿のその矢を、パールシャタは百に砕いた。熟達した手つきで。
dṛṣṭavān patitaṃ bhūmau śaraṃ karṇo viśāmpate||
// 8-57-29 //
サンジャヤは語った。
王よ、カルナは地面に落ちた自分の矢を見た。
pārṣataḥ śaravarṣeṇa samantāt paryavārayat|
vivyādha ca enaṃ tvarito nārācaiḥ saptabhis tadā||
// 8-57-30 //
サンジャヤは語った。
パールシャタはカルナを矢の雨で四方から取り囲み、素早く七本の鉄矢で射た。
taṃ pratyavidhyad daśabhiḥ śarair hemavibhūṣitaiḥ|
tayor yuddhaṃ samabhavad dṛṣṭiśrotramanoharam||
// 8-57-31 //
サンジャヤは語った。
カルナは十本の黄金で飾られた矢で撃ち返した。二人の戦いは見る者・聞く者・心を奪うものであった。
āsīd ghoraṃ ca citraṃ ca prekṣaṇīyaṃ ca sarvaśaḥ||
// 8-57-32 //
サンジャヤは語った。
恐ろしくもあり華麗でもあり、あらゆる面から見物に値した。
sarveṣāṃ tatra bhūtānāṃ romaharṣo vyajāyata|
dṛṣṭvā tat samare karma karṇapārṣatayor nṛpa||
// 8-57-33 //
サンジャヤは語った。
王よ、カルナとパールシャタの戦場での働きを見て、全ての存在の毛が逆立った。
etasminn antare drauṇir abhyayāt taṃ mahāratham|
pārṣataṃ śatrudamanaṃ śatruvīryāsunāśanam||
// 8-57-34 //
サンジャヤは語った。
そのとき、ドラウニが大戦車戦士パールシャタ、敵を制し敵の武勇と命を奪う者に向かった。
sa dṛṣṭvā samare yāntam abhītaṃ ca mahāratham|
abhyabhāṣata saṅkruddhaḥ pārṣataṃ śatrutāpanam||
// 8-57-35 //
サンジャヤは語った。
戦場で恐れなく向かってくる大戦車戦士を見て、激怒したドラウニはパールシャタに語った。
rathaṃ rathena sampīḍya pārṣatasya tu brāhmaṇaḥ||
// 8-57-36 //
サンジャヤは語った。
バラモンはパールシャタの戦車に自分の戦車を押し寄せて言った。
tiṣṭha tiṣṭheti brahmaghna na me jīvan vimokṣyase|
ity uktvā subhṛśaṃ vīraḥ śīghrakṛn niśitaiḥ śaraiḥ|
chādayāmāsa samare yatamāno mahārathaḥ||
// 8-57-37 //
サンジャヤは語った。
「止まれ、止まれ。ブラフマー殺し（師の殺害者）よ。汝を生かしては帰さぬ。」こう言って勇者は鋭い矢で、力を尽くして大戦車戦士ドゥリシュタデュムナを覆い隠した。
yatnataḥ parayā śaktyā dhṛṣṭadyumnaṃ mahāratham|
yodhayāmāsa samare kruddharūpo viśāmpate||
// 8-57-38 //
サンジャヤは語った。
最大の力を込めて、怒りの姿で、王よ、ドラウニは戦場でドゥリシュタデュムナと戦った。
tayos tu sannipāte hi ghorarūpo viśāmpate||
// 8-57-39 //
サンジャヤは語った。
王よ、二人が激突した時の姿は恐ろしいものであった。
yathā hi samare drauṇiḥ pārṣataṃ dṛśyata māriṣa|
na atihṛṣṭamanā hy āsīn manvāno mṛtyum ātmanaḥ||
// 8-57-40 //
サンジャヤは語った。
親愛なる者よ、戦場でドラウニがパールシャタを攻めるのを見て、ドゥリシュタデュムナは自分の死が近いと悟り、全く喜ばしい気持ちにはなれなかった。
sa jñātvā pitur atyantaṃ vairiṇaṃ tu mahāhave|
ātmānaṃ samare jñātvā'śastravadhyaṃ mahābalaḥ|
javena abhiyayau drauṇiṃ kālaḥ kālakṣaye yathā||
// 8-57-41 //
サンジャヤは語った。
父の究極の仇敵が大戦場にいることを知り、自分は武器では殺されない（運命にある）ことも悟った大力の者は、終末の時のごとくドラウニに向かっていった。
drauṇis tu dṛṣṭvā rājendra dhṛṣṭadyumnam avasthitam|
krodhena niḥśvasan vīraḥ pārṣadaṃ samabhidravat||
// 8-57-42 //
サンジャヤは語った。
ドラウニもまた、王よ、ドゥリシュタデュムナが構えているのを見て、怒りに荒く息をしながらパールシャタに突進した。
tāv anyonyaṃ tu dṛṣṭvā eva saṃrambhaṃ jagmatuḥ param|
pragṛhya mahatī cāpe śarāsanasamanvite||
// 8-57-43 //
サンジャヤは語った。
互いを見るや二人は極度の激昂に至り、弓弦を張った大弓を構えた。
atha abravīn mahārāja droṇaputraḥ pratāpavān|
dhṛṣṭadyumnaṃ samīpasthaṃ tvaramāṇo viśāmpate||
// 8-57-44 //
サンジャヤは語った。
大王よ、勇猛なるドローナの息子は、急ぎながら近くにいるドゥリシュタデュムナに語った。
pāñcāla apaśada ādya tvāṃ preṣayāmi yamakṣayam|
pāpaṃ hi yat tvayā karma kṛtaṃ tātaṃ ghnatā raṇe||
// 8-57-45 //
サンジャヤは語った。
「パーンチャーラの下賤の者め、今日こそ汝をヤマの国に送ってやる。汝が戦場で父を殺すという罪を犯したのだから。
adya tvaṃ prāpsyase tad vai yathā hy akuśalas tathā|
arakṣyamāṇaḥ pārthena yadi tiṣṭhasi saṃyuge|
na apakrāmasi vā mohāt satyam etad bravīmi te||
||
// 8-57-46 //
サンジャヤは語った。
今日その報いを受けよ。無能なる者が受けるように。アルジュナに守られず戦場に留まるなら、あるいは愚かにも逃げぬなら——これは真実を語っているのだ。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe saptapañcāśo'dhyāyaḥ|| 57 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十七章は終わる。
