ハルシャチャリタ ― 第3章　王との謁見
◆ Maṅgala-ślokāḥ
◆ 冒頭の偈
nija-varṣâhita-snehā bahu-bhakta-janânvitāḥ /
su-kālā iva jāyante prajā-puṇyena bhū-bhujaḥ // 3.1 //
自らの雨季（統治期間）に愛情（水分）を蓄え、多くの忠実な人々を伴う王たちは、良き時節のように、民の功徳によって生まれる。【3.1】
sādhūnām upakartuṃ Lakṣmīṃ draṣṭuṃ vihāyasā gantum /
na kutūhali kasya manaś-caritaṃ ca mahâtmanāṃ śrotum // 3.2 //
善き人を助けること、ラクシュミー（繁栄の女神）を見ること、天空を行くこと――これらに好奇心を持たぬ心がどこにあろう。そして偉大な魂の行状を聞くことに。【3.2】
◆ Śarat-samayārambha — Bāṇa-pratyāgamana
◆ 秋の帰郷と親族の懇願
atha kadā-cid viralita-balāhake, cātakâtaṅka-kāriṇi kvaṇat-kādambe, dardura-dviṣi, mayūra-mada-muṣi, haṃsa-pathika-sârtha-sarvâtithau, dhautâsi-nibha-nabhasi, bhāsvara-bhāsvati, śuci-śaśini, taruṇa-tārā-gaṇe, galat-sunāsīra-śarâsane, sīdat-saudāmanī-dāmni, dāmôdara-nidrā-druhi, druta-vaidūrya-varṇârṇasi ghūrṇamāna-mihikā-laghu-megha-mogha-maghavati, nimīlan-nīpe, niṣ-kusuma-kuṭaje, nir-mukula-kandale, komala-kamale, madhu-syandîndīvare, kahlārâhlādini, śephālikā-śītalī-kṛta-niśe, yūthikā-modini, modamāna-kumudâvadāta-daśa-diśi, sapta-cchada-dhūli-dhūsarita-samīre, stabakita-bandhura-bandhūkâbadhyamānâkāṇḍa-saṃdhye, nīrājita-vājini, uddāma-dantini darpa-kṣībâukṣake, kṣīyamāṇa-paṅka-cakra-vāle, bāla-pulina-pallavita-sindhu-rodhasi, pariṇāmâśyāna-śyāmāke, janita-priyaṅgu-mañjarī-rajasi, kaṭhorita-trapusa-tvaci, kusuma-smera-śare, śarat-samayârambhe rājñaḥ samīpād Bāṇo bandhūn draṣṭuṃ punar api taṃ brāhmaṇâdhivāsam agāt.
さてある時――雨雲がまばらになり、チャータカ鳥を不安にさせるなか、鳴り響くカーダンバの木が蛙の敵を呼び、孔雀の狂喜を奪い、ハンサ鳥の旅人の群れを歓待し、洗った刀のような空に輝く太陽と清らかな月のある、若い星の群れの空に、インドラの弓が消えゆき、稲妻の花輪が力を失い、ヴィシュヌの眠りを妨げ、溶けた翡翠色の海にぐらつく霧の軽い雲がインドラの力を空しくする――ニーパの花が閉じ、クタジャの花がなくなり、カンダラの蕾が消え、蓮は柔らかく、青蓮が蜜を滴らせ、カハラーラの蓮が歓びを与え、セファーリカーの花が夜を涼しくし、ユーティカーの香りが漂い、喜ぶ夜蓮で十方が白くなり、サプタッチャダの花粉に風が灰色になり、花房が美しいバンドゥーカの花が不意の夕焼けのように結ばれ――秋の始まりに、バーナは王のもとを辞して、親族を訪ねてふたたびかのバラモンの集落に赴いた。
samupalabdha-bhū-pāla-saṃmānâtiśaya-parituṣṭās tv asya jñātayaḥ ślāghamānā niryayuḥ. krameṇa ca kāṃś-cid abhivādayamānaḥ, kaiś-cid abhivādyamānaḥ, kaiś-cic chirasi cumbyamānaḥ, kāṃś-cin mūrdhni samājighran, kaiś-cid āliṅgyamānaḥ, kāṃś-cid āliṅgan, anyair āśiṣânugṛhyamāṇaḥ, parān anugṛhṇan, bahu-bandhu-madhya-vartī paraṃ mumude. saṃbhrānta-parijanôpanītaṃ câsanam āsīneṣu guruṣu bheje. bhajamānaś cârcâdi-satkāraṃ nitarāṃ nananda.
王から受けた格別の名誉に満足した親族たちは、彼を讃えながら迎え出た。ある者に敬礼し、ある者に敬礼され、ある者に額にキスされ、ある者の頭を嗅ぎ、ある者に抱擁され、ある者を抱擁し、ある者から祝福を受け、ある者を祝福しながら、多くの親族に囲まれて大いに喜んだ。
prīyamāṇena ca manasā sarvāṃs tān paryapṛcchat: "kac-cid etāvato divasān sukhino yūyam? a-pratyūhā vā samyak-karaṇa-paritoṣita-dvija-cakrā krātavī kriyā kriyate? yathāvad-a-vikala-mantra-bhāñji bhuñjate vā havīṃṣi huta-bhujaḥ? yathā-kālam adhīyate vā baṭavaḥ? prati-dinam a-vicchinno vā vedâbhyāsaḥ? kac-cit sa eva ciraṃtano yajña-vidyā-karnaṇy abhiyogaḥ? tāny eva vyākaraṇe paraspara-spardhânubandhâbandhya-divasa-darśitâdarāṇi vyākhyāna-maṇḍalāni, sâiva vā purātanī parityaktânya-kartavyā pramāṇa-goṣṭhī, sa eva vā mandī-kṛtêtara-śāstra-raso mīmāṃsāyām ati-rasaḥ? kac-cit ta evâbhinava-subhāṣita-sudhā-varṣiṇaḥ kāvyâlāpāḥ?" iti.
喜ぶ心でバーナは皆に尋ねた。「これだけの日々、皆さんは幸福でしたか。バラモンの衆を正しく満足させる祭祀の儀式は滞りなく行われていますか。祭火は正しい完全なマントラとともに供物を受けていますか。少年たちは時宜にかなってヴェーダを学んでいますか。毎日絶え間ないヴェーダの学習はありますか。あの古来の祭祀学への熱心さは変わりませんか。文法学における互いの競争で日々の努力を示し合う講義の集まりは同じですか。他のすべてを捨てた古来のプラマーナ（認識論）の談論は同じですか。他の学問の味わいを色褪せさせるミーマーンサー（祭祀哲学）への格別な情熱は同じですか。新しい名句の甘露の雨を降らせる文学の談話はありますか」。
atha te tam ūcuḥ: "tāta! saṃtoṣa-juṣāṃ satata-saṃnihita-vidyā-vinodānāṃ vaitāna-vahni-mātra-sahāyānāṃ kiyan-mātraṃ na kṛtyaṃ sukhitayā sakala-bhuvana-bhuji bhujaṅga-rāja-deha-dīrghe rakṣati kṣitiṃ kṣiti-bhuje. sarvathā sukhina eva vayam, viśeṣeṇa tu tvayi vimukta-kausīdye paramêśvara-pārśva-vartini vetrâsanam adhitiṣṭhati. sarve ca yathā-śakti yathā-vibhavaṃ yathā-kālaṃ ca saṃpādyante vipra-janôcitāḥ kriyā-kalāpāḥ" ity evam-ādibhir ālāpaiḥ skandhâvāra-vārtābhiś ca śaiśavâtikrānta-krīḍânusmaraṇaiḥ pūrva-ja-kathābhiś ca vinodita-manās taiḥ saha su-ciram atiṣṭhat.
すると彼らは答えた。「息子よ、満足に安んじ、常に学問の楽しみを身近にし、祭壇の火だけを友とする我々にとって、全世界を治める大蛇王の体のように長い王が大地を守っておられるなか、何が不足でしょうか。すべてにおいて我々は幸福です。とりわけ、怠惰を捨てたおまえが至高主のそばで杖座（重臣の席）に就いているとあっては。すべてのバラモンにふさわしい勤行はそれぞれの力と財と時に応じて行われています」。このような話、陣営の消息、幼い頃の遊びの回想、先祖の物語などで心を慰められたバーナは、彼らとともに長く留まった。
atrântare dugūla-paṭṭa-prabhave śikhaṇḍy-apâṅga-pāṇḍunī pauṇḍre vāsasī vasānaḥ snānâvasāna-samaye banditayā tīrtha-mṛdā gorocanayā ca racita-tilakaḥ, tailâmalaka-masṛṇita-mauliḥ, an-ucca-cūḍā-cumbinā nibiḍena kusumâpīḍakena samudbhāsamānaḥ, asakṛd-upayukta-tāmbūla-viralâdhara-rāga-kāntiḥ, eka-śalākâñjana-janita-locana-ruciḥ, a-cira-bhuktaḥ, vinītam āryaṃ ca veṣaṃ dadhānaḥ, pustaka-vācakaḥ Sudṛṣṭir ājagāma. nâti-dūra-vartinyāṃ câsandyāṃ niṣasāda. sthitvā ca muhūrtam iva tat-kālâpanīta-sūtra-veṣṭanam api nakha-kiraṇair mṛdu-mṛṇāla-sūtrair ivâveṣṭitaṃ pustakaṃ puro-nihita-śara-śalākā-yantrake nidhāya, pṛṣṭhataḥ sanīḍa-saṃniviṣṭābhyāṃ madhukara-pārāvatābhyāṃ vaṃśikābhyāṃ datte sthānake prābhātika-prapāṭhaka-ccheda-cihnī-kṛtam antaraṃ patram utkṣipya, gṛhītvā ca katipaya-patra-laghvīṃ kapāṭikām kṣālayann iva maṣī-malināny akṣarāṇi danta-kāntibhiḥ, arcayann iva sita-kusuma-muktibhir grantham, mukha-saṃnihita-Sarasvatī-nūpura-ravair iva gamakair madhurair ākṣipan manāṃsi śrotṝṇāṃ gītyā pavamāna-proktaṃ purāṇaṃ papāṭha. tasmiṃś ca tathā śruti-subhaga-gīti-garbhaṃ paṭhati Sudṛṣṭau nâti-dūra-vartī bandī Sūcībāṇas tāra-madhureṇa gīti-dhvanim anuvartamānaḥ svareṇêdam āryā-yugalam agāyat:
そうこうするうちに、絹の布から生まれた孔雀の横目のように淡い一対のパウンドラの衣をまとい、沐浴を終えたばかりで聖なる泥とゴーローチャナー（黄色顔料）でティラカ（額飾り）を施し、油とアーマラカで頭を滑らかにし、高くない髷に触れる密な花の髪飾りで輝き、幾度もキンマを噛んだためにほのかに赤い唇の美しさを帯び、一本の棒のアンジャナ（目薬）で生じた目の輝きを持ち、食事を済ませたばかりで、控えめにして高雅な装いをした朗読師スドゥリシュティがやって来た。さほど遠くない低い椅子に座した。しばし留まった後、紐の包みを解かれた写本を――爪の光が柔らかな蓮茎の糸のようにいまだ包んでいるかのような――前に置いた葦の棒の書見台に据え、背面で蜂と鳩の飾りのついた二本の竹の頁押さえに挟まれた場所で、朝の朗読の中断箇所を印した頁を開き、数頁の軽い栞を手に取り、歯の輝きで墨に汚れた文字を洗い清めるかのように、白い花の供物で書物を礼拝するかのように、口元に寄せたサラスヴァティーの足環の響きのような甘く美しいガマカ（装飾音）で聴衆の心を奪いながら、ヴァーユ神の語ったプラーナを朗唱した。このように耳に快い歌を含んで朗読するスドゥリシュティのそばで、近くにいた吟遊詩人スーチーバーナが、高く甘い声で旋律に合わせて、この一対のアーリヤー韻律の偈を歌った。
tad api muni-gītam ati-pṛthu tad api jagad-vyāpi pāvanaṃ tad api /
Harṣa-caritād a-bhinnaṃ pratibhāti hi me purāṇam idam // 3.3 //
それもまた聖仙が歌ったもの、それもまた極めて広大なもの、それもまた世界に遍く清めるもの――このプラーナはハルシャ王伝と異ならぬものと私には思われる。【3.3】
vaṃśânugama-vivādi sphuṭa-karaṇaṃ bharata-mārga-bhajana-guru /
śrī-kaṇṭha-viniryātaṃ gītam idaṃ Harṣa-rājyam iva // 3.4 //
ヴァンシャ（笛の旋律＝王統）の継承に比肩し、明瞭なカラナ（楽技法＝行為）を持ち、バーラタ（音楽家バラタ＝バーラタ王統）の道を奉ずることに重きを置き、シュリーカンタ（シヴァの喉＝シュリーカンタ国）より生まれ出たこの歌は、ハルシャの王国のようである。【3.4】
◆ Harṣa-carita-kathā-prārambha
◆ ハルシャ王伝の語りの始まり
tac chrutvā Bāṇasya catvāraḥ pitā-maha-mukha-padmā iva vedâbhyāsa-pavatrita-mūrtayaḥ, upāyā iva sāma-prayoga-lalita-mukhāḥ, Gaṇapatiḥ, Adhipatiḥ, Tārāpatiḥ, Śyāmala iti pitṛvya-putrā bhrātaraḥ, prasanna-vṛttayaḥ, gṛhīta-vākyāḥ, kṛta-guru-pada-nyāsāḥ, nyāya-vādinaḥ, su-kṛta-saṃgrahâbhyāsa-guravo labdha-sādhu-śabdā loka iva vyākaraṇe 'pi sakala-purāṇa-rāja-rṣi-caritâbhijñāḥ, mahā-bhārata-bhāvitâtmānaḥ, vidita-sakalêtihāsāḥ, mahā-vidvāṃsaḥ, mahā-kavayaḥ, mahā-puruṣa-vṛttânta-kutūhalinaḥ, subhāṣita-śravaṇa-rasa-rasāyanāḥ, vi-tṛṣṇāḥ, vayasi vacasi yaśasi tapasi sadasi mahasi vapuṣi yajuṣi ca prathamāḥ, pūrvam eva kṛta-saṃgarāḥ, vivakṣavaḥ, smita-sudhā-dhavalita-kapolôdarāḥ, parasparasya mukhāni vyalokayan.
それを聞いて、バーナの四人の従兄弟たち――ガナパティ、アディパティ、ターラーパティ、シャーマラ――が互いの顔を見合わせた。彼らは祖父の顔の蓮華のようにヴェーダの学習で浄められた姿を持ち、四つのウパーヤ（方便）のようにサーマ（宥和策）の使用に巧みな口を持つ叔父の息子たる兄弟であった。清らかな行いの者たち、言葉を習得した者たち、師の足跡を踏む者たち、ニヤーヤ（論理学）の論者たち。善行の集積と修練において重きをなし、世間においてのみならず文法学においても「正しい言葉」（sādhu-śabda）を得た者たち。すべてのプラーナに語られる古代の聖王仙の事績に精通し、マハーバーラタに心を養われ、あらゆるイティハーサ（叙事詩）を知る大学者にして大詩人。偉大な人物の事績への好奇心を持ち、美しい言葉を聞く味わいが不老の霊薬であるかのような者たち。世俗の欲望を離れ、年齢においても、言葉においても、名声においても、苦行においても、集会においても、祭祀においても、容姿においても、ヤジュル・ヴェーダにおいても第一の者たち。以前からすでに約束を交わしており、語りたいと望んでいた彼らは、微笑みの甘露で頬の内側を白くしながら、互いの顔を見合わせた。
atha teṣāṃ kanīyān kamala-dala-dīrgha-locanaḥ Śyāmalo nāma Bāṇasya preyān prāṇānām api vaśayitā datta-saṃjñastaiḥ sa-praṇayaṃ daśana-jyotsnā-snapita-kakubhā mukhêndunā babhāṣe: "tāta Bāṇa! dvijānāṃ rājā guru-dāra-grahaṇam akārṣīt. Purūravā brāhmaṇa-dhana-tṛṣṇayā dayitenÂyuṣā vyayujyata. Nahuṣaḥ para-kalatrâbhilāṣā mahā-bhujaṅga āsīt. Yayātir āhita-brāhmaṇī-pāṇi-grahaṇaḥ papāta. Sudyumnaḥ strīmaya evâbhavat. Somakasya prakhyātā jagati Jantu-vadha-nirghṛṇatā. Māṃdhātā mārgaṇa-vyasanena sa-putra-pautro rasātalam agāt. Purukutsaḥ kutsitaṃ karma tapasyann api Mekala-kanyakāyām akarot. Kuvalayāśvo bhujaṅga-loka-parigrahād Aśvatara-kanyām api na parijahāra. Pṛthuḥ prathama-puruṣakaḥ paribhūtavān Pṛthivīm. Nṛgasya kṛkalāsa-bhāve 'pi varṇa-saṃkaraḥ samadṛśyata. Saudāsena narakṣitā paryākulī-kṛtā kṣitiḥ. Nalam a-vaśâkṣa-hṛdayaṃ kalir abhibhūtavān. Saṃvaraṇo mitra-duhitari viklavatām agāt. Daśaratha iṣṭa-rāmônmādena mṛtyum avāpa. Kārtavīryo go-brāhmaṇâti-pīḍanena nidhanam ayāsīt. Marutta iṣṭa-bahu-suvarṇako 'pi deva-dvija-bahu-mato na babhūva. Śantanur ati-vyasanād ekākī viyukto vāhinyā vipine vilalāpa. Pāṇḍur vana-madhya-gato matsya iva madana-rasâviṣṭaḥ prāṇān mumoca. Yudhiṣṭhiro guru-bhaya-viṣaṇṇa-hṛdayaḥ samara-śirasi satyam utsṛṣṭavān. itthaṃ nâsti rājatvam apakalaṅkam ṛte devadevād amutaḥ sarva-dvīpa-bhujo Harṣāt.

◆ Puṣpabhūti-rāja-varṇana
◆ プシュパブーティ王のシヴァ信仰
tatra ca sākṣāt-sahasrâkṣa iva sarva-varṇa-dharaṃ dhanur dadhānaḥ, merumaya iva kalyāṇa-prakṛtitve, mandaramaya iva lakṣmī-samākarṣaṇe, jala-nidhimaya iva maryādāyām, ākāśamaya iva śabda-prādur-bhāve, śaśimaya iva kalā-saṃgrahe, vedamaya ivâkṛtrimâlāpatve, dharaṇimaya iva loka-dhṛti-karaṇe, pavanamaya iva sarva-pārthiva-rajo-vikāra-haraṇe, gurur vacasi, pṛthur urasi, viśālo manasi, janakas tapasi, su-yātras tejasi, su-mantro rahasi, budhaḥ sadasi, arjuno yaśasi, bhīṣmo dhanuṣi, niṣadho vapuṣi, śatrughnaḥ samare, sarvâdi-rāja-tejaḥ-puñja-nirmita iva rājā Puṣpabhūtir iti nāmnā babhūva.
そこに、千の目を持つインドラのようにすべての色を持つ弓を携え、メール山のように吉祥な本性において、マンダラ山のようにラクシュミーの引き寄せにおいて、大海のように規律において、虚空のように名声の発現において、月のように技芸の集成において、ヴェーダのように偽りなき言葉において、大地のように世界の保持において、風のようにすべての王の塵の汚れの除去において――言葉においてはブリハスパティ、胸においてはプリトゥ、心においてはヴィシャーラ、苦行においてはジャナカ、光輝においてはスヤートラ、秘密においてはスマントラ、集会においてはブダ、名声においてはアルジュナ、弓においてはビーシュマ、容姿においてはニシャダ、戦いにおいてはシャトゥルグナ――すべての古代の王の光輝の集まりで造られたかのようなプシュパブーティという名の王がいた。
Pṛthunā gaur ivêyaṃ kṛtêti yaḥ spardhamāna iva mahīṃ mahiṣīṃ cakāra. nisarga-svairiṇī sva-rucy-anurodhinī ca bhavati hi mahatāṃ matiḥ. yatas tasya kena-cid an-upadiṣṭā sahajâiva śaiśavād ārabhyân-anya-devatā bhagavati, bhakti-sulabhe, bhuvana-bhṛti, bhūta-bhāvane, bhava-cchidi, bhave bhūyasī bhaktir abhūt. a-kṛta-vṛṣabha-dhvaja-pūjā-vidhir na svapne 'py āhāram akarot. a-jam, a-jaram, a-mara-gurum, asura-pura-ripum, a-parimita-gaṇa-patim, a-cala-duhitṛ-patim, akhila-bhuvana-kṛta-caraṇa-natim, paśu-patiṃ prapanno 'nya-devatā-śūnyam amanyata trailokyam. bhartṛ-cittânuvartinyaś cânujīvināṃ prakṛtayaḥ. tathā hi: gṛhe gṛhe bhagavān apūjyata khaṇḍa-paraśuḥ. vavur asya homâlavālânala-vilīyamāna-bahala-guggulu-gandha-garbhāḥ snapana-kṣīra-śīkara-kṣoda-kṣāriṇo bilva-pallava-dāma-dalôdvāhinaḥ puṇya-viṣayeṣu vāyavaḥ. Śiva-saparyā-samucitair upāyanaiḥ prābhṛtaiś ca paurāḥ pādôpajīvinaḥ sacivāḥ sva-bhuja-bala-nirjitāś ca karadī-kṛtā mahā-sāmantās taṃ siṣevire. tathā hi: Kailāsa-kūṭa-dhavalaiḥ kanaka-patra-latâlaṅ-kṛta-viṣāṇa-koṭibhir mahā-pramāṇaiḥ saṃdhyā-bali-vṛṣaiḥ sauvarṇaiś ca snapana-kalaśair argha-bhājanaiś ca dhūpa-pātraiś ca puṣpa-paṭṭaiś ca maṇi-yaṣṭi-pradīpaiś ca brahma-sūtraiś ca mahârha-māṇikya-khaṇḍa-khacitaiś ca mukha-koṣaiḥ paritoṣam asya manasi cakruḥ. antaḥ-purāṇy api svayam-ārabdha-bāleya-taṇḍula-kaṇḍanāni deva-gṛhôpalepana-lohitatara-kara-kisalayāni kusuma-grathana-vyagra-samasta-parijanāni tasyâbhilaṣitam anvavartanta.
プリトゥ王が牝牛のように大地を搾ったと競うかのように、彼は大地を王妃とした。偉大な者の心は本性上自由であり、自らの趣味に従う。誰にも教えられることなく、幼い頃からシヴァ神への生来の無比の信仰があった。牡牛の旗印（シヴァ）を崇拝せずに夢の中でさえ食事をしなかった。不生にして不老なる神々の師、アスラの都の敵、無限のガナたちの主、山の娘の夫、全世界がその足に礼拝するパシュパティ（獣の主、シヴァ）に帰依して、三界をば他の神なきものと見なした。主人の心に従うのが家臣の本性であるから、家々でカンダ・パラシュ（シヴァ神）が崇拝された。彼の領内には、護摩の炉の火に溶けた濃厚なグッグル香の芳香を孕み、沐浴の乳の飛沫の滴を散らし、ビルヴァの若葉の花環の花弁を運ぶ聖なる風が吹いていた。シヴァの供養にふさわしい供物と贈り物で、市民たち、俸給を受ける大臣たち、武力で征服された封臣たちが彼に仕えた。すなわち、カイラーサ山頂のように白い、金の葉の蔓で角の先端を飾った大きな黄昏の供犠の牡牛で、黄金の沐浴の水瓶と供水の器と香炉と花布と宝石の棒の灯明と聖紐と高価なルビーの破片を嵌め込んだ面覆いで、王の心に喜びをもたらした。内宮の女たちもまた、自ら若い米の粒を砕き、神殿の塗装でいっそう赤くなった手の若葉で、すべての侍女が花を編むことに忙しくして、彼の望みに従った。
◆ Bhairavācārya-milana
◆ バイラヴァーチャーリヤとの出会い
parama-māheśvaraḥ sa bhū-pālo lokataḥ śuśrāva bhuvi bhagavantam a-param iva sākṣād dakṣa-makha-mathanaṃ dākṣiṇātyaṃ bahu-vidha-vidyā-prabhāva-prakhyātair guṇaiḥ śiṣyair ivân-eka-sahasra-saṃkhyair vyāpta-martya-lokaṃ Bhairavācārya-nāmānaṃ mahā-śaivam. upanayanti hi hṛdayam a-dṛṣṭam api janaṃ śīla-saṃvādāḥ. yataḥ sa rājā śravaṇa-sama-kālam eva tasmin Bhairavācārye bhagavati dvitīya iva kapardini dūra-gate 'pi garīyasīṃ babandha bhaktim. ācakāṅkṣa ca mano-rathair apy asya sarvathā darśanam.
至高のシヴァ信者たるこの王は、地上に大地のもう一つのダクシャの祭祀の破壊者のごとく、数千の弟子で人間界に遍く知られた、バイラヴァーチャーリヤという名の大シヴァ派行者の噂を世間から聞いた。品性の一致は見知らぬ者にも心を導く。それゆえ王はバイラヴァーチャーリヤのことを聞くや否や、遠くにいる第二のシヴァ神のように深い信仰を結んだ。そしてあらゆる手段で彼との謁見を夢見た。
atha kadā-cit paryaste 'stâcala-cumbini vāsare 'ntaḥ-pura-vartinaṃ rājānam upasṛtya pratīhārī vijñāpitavatī: "deva! dvāri parivrāḍ āste, kathayati ca Bhairavācārya-vacanād devam anuprāpto 'smi" iti. rājā tu tac chratvā sâdaram: "kvâsau? ānayâtrâiva, praveśayâinam" iti câbravīt. tathā câkarot pratīhārī. na cirāc ca praviśantaṃ prāṃśum, ā-jānu-bhujam, bhaikṣa-kṣāmam api sthūlâsthibhir avayavaiḥ pīvaram ivôpalakṣyamāṇam, pṛthûttamâṅgam, uttuṅga-vali-bhaṅga-stha-puṭa-lalāṭam, nir-māṃsa-gaṇḍa-kūpakam, madhu-bindu-piṅgala-parimaṇḍalâkṣam, īṣad-āvakra-ghoṇam, ati-pralambâika-karṇa-pāśam, alābu-bīja-vikaṭônnata-danta-paṅktim, turagânūka-ślathâdhara-lekham, lamba-cibukâyatatara-lapanam, aṃsâvalambinā kāṣāyeṇa yoga-paṭṭakena viracita-vaikakṣakam, hṛdaya-madhya-nibaddha-granthinā ca rāgeṇêva khaṇḍaśaḥ kṛtena dhātu-rasâruṇena karpaṭena kṛtôttarâsaṅgam, vāma-kara-dhṛtena yoga-bhārakeṇâdhyāsita-skandham, itara-kara-gṛhīta-vetrâsanaṃ maskariṇam adrākṣīt.
ある日、日が暮れて西山に接するころ、内宮にいた王のもとに侍女が告げた。「陛下、門前に遊行僧がおります。バイラヴァーチャーリヤの言葉により参上したと申しております」。王はこれを聞いて丁重に「どこにいる、ここへ連れて来い、通せ」と言った。間もなく入って来た、背の高い、腕が膝まで届く、托鉢で痩せていても太い骨の四肢で太って見える、大きな頭の、高い皺の折り目のある広い額の、肉のない窪んだ頬の、蜜の雫のように黄褐色の丸い目の、やや曲がった鼻の、極めて長い片方の耳たぶの、ひょうたんの種のように大きく突き出た歯列の、馬の後ろのように緩んだ下唇の、垂れた顎の長い顔の、肩から垂れるカーシャーヤ色のヨーガの帯で斜め掛けを作り、胸の中央に結び目をつけた鉱物質の赤い繕い布で上衣を作った遊行僧を見た。左手に持つヨーガの荷、右手に持つ杖座の遊行僧であった。
kṣiti-patir apy upagatam ucitena câinam ādareṇânvagrahīt. āsīnaṃ ca papraccha: "kva Bhairavācāryaḥ?" iti. sâdara-nara-pati-vacana-mudita-matis tu parivrāṭ tam upanagaraṃ Sarasvatī-taṭa-vanâvalambini śūnyâyatane sthitam ācacakṣe. bhūyaś câbabhāṣe: "arcayati hi mahā-bhāgaṃ bhagavān āśīr-vacasā" ity uktvā côpaninye yoga-bhārakād ākṛṣya Bhairavācārya-prahitāni ratnavanti bahalâloka-liptântaḥ-purāṇi pañca rājatāni puṇḍarīkāṇi.
王は丁重に迎え入れ、座った彼に尋ねた。「バイラヴァーチャーリヤはどこにおられるか」。遊行僧はサラスヴァティー河岸の森に接する空き地に滞在していると告げ、さらに「尊師は祝福の言葉でお慶び申し上げます」と言い、ヨーガの荷からバイラヴァーチャーリヤが送った、宝石をちりばめた光に満ちた五つの銀の蓮華を差し出した。
nara-patis tu priya-jana-praṇaya-bhaṅga-kātaro dākṣiṇyam anurudhyamāno grahaṇa-lāghavaṃ ca laṅghayitum a-samartho dolāyamānena manasā sthitvā ciraṃ kathaṃ-katham apy ati-saujanya-nighnas tāni jagrāha. jagāda ca: "sarva-phala-prasava-hetuḥ Śiva-bhaktir iyaṃ no mano-ratha-dur-labhāni phalati phalāni. yenâivam asmāsu prīyate tatra-bhagavān bhuvana-gurur Bhairavācāryaḥ. śvo draṣṭāsmi bhagavantam" ity uktvā ca maskariṇaṃ vyasarjayat. anayā ca vārtayā parāṃ mudam avāpa.
しかし王は、親しき者の好意を損なうことを恐れ、礼儀を重んじ、受け取りの軽率さを避けることもできず、揺れ動く心で長く留まった後、あまりの高潔さに打たれてどうにかそれらを受け取った。そして言った。「すべての果報の原因たるシヴァへの信仰が、我らに願いでも得がたい果実を実らせる。かくも我々に愛情を寄せてくださるのは、世界の師バイラヴァーチャーリヤ尊師です。明日、尊師にお目にかかりましょう」。こう言って遊行僧を送り出した。そしてこの知らせに大いなる喜びを得た。
aparedyuś ca prātar evôtthāya vājinam adhiruhya samucchrita-śvetâtapatraḥ samuddhūyamāna-dhavala-cāmara-yugalaḥ katipayair eva rāja-putraiḥ parivṛto Bhairavācāryaṃ savitāram iva śaśī draṣṭuṃ pratasthe.
翌朝、王は馬に乗り、白い日傘を掲げ、白いチャーマラの対を揺らし、わずかの王子たちだけを供に、太陽を見に行く月のようにバイラヴァーチャーリヤに会いに出発した。
gatvā ca kiñ-cid antaraṃ tadīyam evâbhi-mukham āpatantam anyatamaṃ śiṣyam adrākṣīt. aprākṣīc ca: "kva bhagavān āste?" iti. so 'kathayat: "asya jīrṇa-mātṛ-gṛhasyôtareṇa bilva-vāṭikām adhyāste" iti. gatvā ca taṃ pradeśam avatatāra turagāt. praviveśa ca bilva-vāṭikām.
しばらく進んだところで、向こうから駆け寄って来るバイラヴァーチャーリヤの弟子の一人に出会った。「尊師はどこにおられるか」と尋ねると、彼は答えた。「この古い母堂の家の北にあるビルヴァの園におられます」。その場所に行き着くと馬を降り、ビルヴァの園に入った。
◆ Bhairavācārya-darśana
◆ バイラヴァーチャーリヤの壮大な描写
atha mahataḥ kārpaṭhika-vṛndasya madhye prātar eva snātam, dattâṣṭa-puṣpikam, anuṣṭhitâgni-kāryam, kṛta-bhasma-rekhā-parihāra-parikare harita-gomayôpalipta-kṣiti-tala-vitate vyāghra-carmaṇy upaviṣṭam, kṛṣṇa-kambala-prāvaraṇa-nibhenâsura-vivara-praveśâśaṅkayā pātālândhakārâvāsam ivâbhyasyantam, unmiṣatā vidyut-kapilenâtma-tejasā śiṣya-lokaṃ limpantam, jaṭī-kṛtâika-deśa-lambamāna-rudrâkṣa-śaṅkha-guṭikenôrdhva-baddhena śikhā-pāśena badhnantam iva vidyâvalepa-dur-vidagdhān upari-saṃcarataḥ siddhān, dhavala-katipaya-śiro-ruheṇa vayasā pañca-pañcāśataṃ varṣāṇy atikrāmantam, ati-dīrgheṇa locana-yugalena parito mahā-maṇḍalam ivân-eka-varṇa-rāgam ālikhantam, dūra-vidīrṇa-sṛkka-saṃkṣipta-kapolam, jihvâgra-sthita-sarva-śaiva-saṃhitâti-bhāreṇêva manāk-pralambitâuṣṭham, dakṣiṇena pāṇinā rudrâkṣa-mālāṃ bhramayantam, dhāma dharmasya, tīrthaṃ tathyasya, kośaṃ kuśalasya, pattanaṃ pūtatāyāḥ, śālā śīlasya, kṣetraṃ kṣamāyāḥ, ākaraṃ karuṇāyāḥ, bhagavantaṃ sākṣād iva vi-rūpâkṣaṃ Bhairavācāryaṃ dadarśa.
そしてビルヴァの園に入り、多くのカールパティカ（苦行者）の群れの中央に座す師を見た。早朝の沐浴を済ませ、八花供養を捧げ、火の勤行を終え、灰の線条の周囲に、緑の牛糞で塗られた大地に広げた虎の皮の上に座し、黒い毛布を覆うナーガの洞窟に入る稽古のように地底の闇に住むことを練習するかのような、閃く稲妻のような黄褐色の己の光輝で弟子たちを塗油するかのような、一部を結って垂らしたルドラークシャと法螺貝の玉のついた髪束で天を行く成就者たちを縛るかのような、白い数本の頭髪で五十五歳を超える年齢を示しながらも、極めて長い目の対で周囲に大きなマンダラのように多色の輝きを描く、遠くまで裂けた口角で頬を圧縮した、舌の先にすべてのシヴァ聖典の過重を載せたかのようにわずかに垂れた唇の、右手でルドラークシャの数珠を回す――ダルマの住処、真実の聖地、善の宝庫、浄の港、品性の殿堂、忍耐の田畑、慈悲の鉱山――まさに三つ目のシヴァ神の具現のようなバイラヴァーチャーリヤを見た。
Bhairavācāryas tu dūrād eva rājānaṃ dṛṣṭvā śaśinam iva jala-nidhiś cacāla. Prathamatarôtthita-śiṣya-lokaś côtthāya pratyujjagāma. Samarpita-śrī-phalôpāyanaś ca Jahnu-karṇa-samudgīryamāṇa-Gaṅgā-pravāha-hrāda-gambhīrayā girā svasti-śabdam akarot.
バイラヴァーチャーリヤは遠くから王を見ると、月を見た大海のように動いた。弟子たちが先に立ち上がるなか自らも立って出迎え、ジャフヌ仙の耳から溢れ出るガンガーの流れの轟きのように深い声で吉祥の言葉を述べた。
nara-patir api prīti-vistāryamāṇa-dhavalimnā cakṣuṣā pratyarpayann iva bahutarāṇi puṇḍarīka-vanāni lalāṭa-paṭṭa-paryastena côd-aṃśunā śikhā-maṇinā Mahêśvara-prasādam iva tṛtīya-nayanôdgamena prakāśayann dūrād avanataḥ praṇāmam abhinavaṃ cakāra. ācāryo 'pi: "āgaccha. atrôpaviśa" iti śārdūla-carmâtmīyam adarśayat. upadarśita-praśrayas tu rājā matta-haṃsa-kala-gadgada-svara-subhagāṃ madhu-rasamayīṃ mahā-nadīm iva pravartayan vācaṃ vyājahāra: "bhagavan! nârhasi mām anya-nṛpa-skhalitaiḥ khalī-kartum. dūra-sthito 'pi mano-ratha-śiṣyo 'yaṃ jano bhavatām. mānanīyaṃ ca guruvan nôllaṅghanam arhati guror āsanam. āsatāṃ ca bhavanta evâtra" iti vyāhṛtyā parijanôpanīte vāsasi niṣasāda. Bhairavācāryo 'pi prītyân-atikramaṇīyaṃ nṛpa-vacanam anuvartamānaḥ pūrvavat tad eva vyāghrâjinam abhajata.
王もまた歓びで広がる白い瞳で多くの白蓮の園を返すかのように、額の冠石の光でマヘーシュヴァラの恩寵を第三の目の出現のように示しながら、遠くから身を屈めて新たな礼拝をした。師は「来なさい、ここに座りなさい」と自らの虎の皮を示した。王は恭しく、蜜のように甘い大河のような声で語った。「尊者よ、他の王たちの過ちで私を欺かないでください。遠くにいても夢の弟子であるこの者はあなた方のものです。師の座を踏み越えるべきではありません。どうかあなた方こそお座りください」。こう言って従者が持ってきた布の上に座った。バイラヴァーチャーリヤもまた王の言葉に従い、もとの虎の皮に座した。
āsīne ca sa-rājake parijane śiṣya-jane ca samucitam arghyâdikaṃ cakre. krameṇa ca nṛpa-mādhurya-hṛtântaḥ-karaṇaḥ uvāca: "tāta! ati-namratâiva te kathayati guṇānāṃ gauravam. sakala-saṃpat-pātram asi. vibhavânurūpās tu pratipattayaḥ. janmanaḥ prabhaty a-datta-dṛṣṭir evâsmi svāpateyeṣu. yataḥ sakala-doṣa-kalāpânalêndhanair dhanair a-vikrītaṃ kva-cic charīrakam asti. bhaikṣa-rakṣitāḥ santi prāṇāḥ. dur-gṛhītāni kati-cid vidyante vidyâkṣarāṇi. bhagavac Chiva-bhaṭṭāraka-pāda-sevayā samupārjitāḥ kiyatyo 'pi saṃnihitāḥ puṇya-kaṇikāḥ. svī-kriyatāṃ yad atrôpayogârham. pratanu-guṇa-grāhyāṇi kusumānîva hi bhavanti satāṃ manāṃsi. api ca, vidvat-saṃmatāḥ śrūyamāṇā api sādhavaḥ śabdā iva sudhīre 'pi hi manasi yaśāṃsi kurvanti. vivaraṃ viśataḥ kutūhalasya phena-dhavalaiḥ srotobhir ivâpahriyamāṇo guṇa-gaṇair ānīto 'smi kalyāṇinā" iti.
王とともに随行者と弟子たちが座すと、師はふさわしい供水などの礼をなした。やがて王の優しさに心を奪われた師は語った。「息子よ、あなたの過度の謙虚さこそが徳の重みを語っています。あなたはすべての繁栄の器です。しかし待遇は分相応でなければなりません。生まれてこのかた、私は自分の財に目を向けたこともありません。あらゆる欠陥の薪を焼く火のような財で買われていないこの身があります。命は托鉢で守られています。いくばくかの不完全な学問の文字があります。シヴァ・バッターラカ尊主の足への奉仕で獲得されたいくばくかの功徳の粒があります。このなかで役に立つものをお受け取りください。細い糸で摘まれる花のように、善き者たちの心は微細な美徳をも受け入れます。また、学者に認められた正しい言葉が耳にされるだけで賢者の心にも名声を生むように、好奇心の裂け目に入る泡のように白い流れに運ばれて、美徳の群れに導かれ、幸いなる方に連れてこられました」。
rājā tu taṃ pratyavādīt: "bhagavan! anurakteṣv api śarīrâdiṣu sādhūnāṃ svāmina eva praṇayinaḥ. yuṣmad-darśanād upārjitam eva câ-parimitaṃ kuśala-jātam. anenâivâgamanena spṛhaṇīyaṃ padam āropito 'smi guruṇā" iti vividhābhiś ca kathābhiś ciraṃ sthitvā gṛham agāt.
王は答えた。「尊者よ、体などに愛着する者にとっても、善き人の真の愛するところは主人のみです。あなたとの出会いから、計り知れない善の種類がすでに獲得されました。この来訪だけで、師によって羨むべき地位に引き上げられました」。そしてさまざまな話をして長く留まった後、家に帰った。
anyasmin divase Bhairavācāryo 'pi rājānaṃ draṣṭuṃ yayau. tasmai ca rājā sântaḥ-puraṃ sa-parijanaṃ sa-koṣam ātmānaṃ niveditavān. sa ca vihasyôvāca: "tāta! kva vibhavāḥ, kva ca vayaṃ vana-vardhitāḥ? dhanôṣmaṇā mlāyaty alaṃ latêva manasvitā. Khadyotānām ivâsmākam iyam a-parôpatāpinī rājate tejasvitā. bhavādṛśā eva bhājanaṃ bhūteḥ" iti sthitvā ca kaṃ-cit kālaṃ jagāma.
別の日、バイラヴァーチャーリヤも王を訪ねた。王は内宮も従者も財宝も含めて自らを彼に委ねた。師は微笑んで言った。「息子よ、富はどこにあり、我ら森で育った者はどこにいるのか。財の熱で蔓のように誇りは萎れてしまう。蛍のように我々のこの光輝は他者を焼くことがない。あなたのような方こそが繁栄の器です」。しばらく留まった後、去った。
◆ Aṭṭahāsa-khaḍga-pradāna
◆ 名剣アッタハーサの授与
parivrāṭ tenâiva krameṇa pañca pañca rājatāni puṇḍarīkāṇy upāyanī-cakāra. ekadā tu śveta-karpaṭâvṛtaṃ kim apy ādāya prāviśat. upaviśya ca pūrvavat sthitvā muhūrtam abravīt: "mahā-bhāga! bhavantam āha bhagavān yathâsmac-chiṣyaḥ Pātālasvāmi-nāmā brāhmaṇaḥ. tena brahma-rākṣasa-hastād apahṛto mahâsir Aṭṭahāsa-nāmā. so 'yaṃ bhavad-bhuja-yogyo gṛhyatām" ity abhidhāyâpahṛta-karpaṭâvacchādanāt parivārād ācakarṣa śarad-gagana-talam iva piṇḍatāṃ nītam, kālindī-pravāham iva stambhita-jalam, nandaka-jigīṣayā kṛṣṇa-kopitaṃ kāliyam iva kṛpāṇatāṃ gatam, loka-vināśāya prakāśita-dhārā-sāraṃ pralaya-kāla-megha-khaṇḍam iva nabhas-talāt patitam, hāsam iva hiṃsāyāḥ, hari-bāhu-daṇḍam iva kṛta-dṛḍha-muṣṭi-graham, kāla-kūṭenêva nirmitam, kṛtânta-kopânala-taptenêvâyasā ghaṭitam, ati-tīkṣṇatayā pavana-sparśenâpi ruṣêva kvaṇantam, maṇi-sabhā-kuṭṭima-patat-pratibimba-cchadmanâtmānam api dvidhêva pāṭayantam, kṛpāṇam.
やがて遊行僧が五つの銀の蓮華を贈り物とし、ある日バイラヴァーチャーリヤは白い布に包んだ何かを持って入ってきた。しばし座ってから言った。「偉大なる方よ、尊師が仰せです。我が弟子パーターラスヴァーミンというバラモンが、ブラフマ・ラークシャサ（梵天の鬼神）の手からアッタハーサ（大笑い）という名の大剣を奪い取りました。これはあなたの腕にふさわしい。お受け取りください」。こう言って布の覆いを取り去ると――秋の空を一塊にしたかのような、カーリンディー河の流れを静止させたかのような、ナンダカの剣に対抗してクリシュナが怒らせたカーリヤ竜が刀剣の姿になったかのような、世界の破壊のために刃の精髄を露わにした末世の雲の欠片が天から落ちたかのような、殺戮の笑いのような、ハリ（ヴィシュヌ）の腕のような固い握りの、カーラクータ毒で造られたかのような、死神の怒りの火で熱した鉄で鍛えられたかのような、極めて鋭いゆえに風が触れるだけで怒って鳴るかのような、宝石の間の床に映る自らの影に自分自身をも二つに裂くかのような――刀剣を引き出した。
avani-patis tu taṃ gṛhītvā kareṇâyudha-prītyā pratimā-nibhenâliṅgann iva su-ciraṃ dadarśa.
王はそれを手に取り、武器への愛で像のように抱きしめるように長く見つめた。
saṃdideśa ca: "vaktavyo bhagavān para-dravya-grahaṇâvajñā-dur-vidagdham api hi me mano yuṣmad-viṣaye na śaknoti vacana-vyatikrama-vyabhicāram ācaritum" iti. parivrāṭ tu gṛhīte tasmin parituṣṭaḥ "svasti bhavate. sādhayāmaḥ" ity uktvā nirayāsīt. nṛpaś ca prakṛtyā vīra-rasânurāgī tena kṛpāṇenâmanyata kara-tala-vartinīṃ medinīm.

ナーガはなおさら構わず「来い、武器はいらぬ。腕だけでおまえの傲りを砕いてやる」と言い放って指を鳴らした。王もまた、武装せぬ者を武器で打ち倒すことを恥じ、盾付きのアッタハーサの剣を腿の上に縛り、腕だけの格闘に備えた。そして二人は容赦ない指弾で裂けた腕の血の飛沫を浴びながら、石の柱のように落ちる腕の棒で世界を音で満たすかのように戦った。間もなく王はナーガを大地に投げ倒した。そして髪を掴み、首を斬ろうとアッタハーサを抜いた。しかし斜め掛けの帯の間にバラモンの聖紐を見つけた。武器を収めて言った。「無礼者め！これが悪行を支える種子だ。だからこそ臆面もなく横暴を働くのだ」と言って放した。

すると、手のなかのアッタハーサの剣の中央に、暗雲の腹に輝く稲妻のように光り、その輝きで三夜（夜）を飲むかのような、蓮華を手にした、柔らかい指の赤い筋の網を足元に引く汀の若い珊瑚の蔓の林のような、手の蓮の閉じる恐れのように月の円盤を砕いた清浄な足の爪の集まりのような光を帯び、足首に垂れる足環の鈴の固い腕輪の束縛から脱け出てきたかのような、多種の花と鳥の百で飾られた風に揺れる波のような極めて透明な衣から海の水から上がるかのような、三本の腰の皺のように三道の河（ガンガー）に中央を抱かれた、極めて高い胸の丸みの、見える方角の守護象の額のような地平線のような、媚液に付着する象の水飛沫の群れのような秋の星の群れの輝く首飾りを胸に帯び、白いチャーマラのような緩やかな溜息に揺れる首飾りの光線に扇がれるかのような、本来赤い両手で陶酔した象の額を打って移った辰砂のように輝く、シヴァの冠の月の第二の欠片のような巻かれた月光を放つ歯飾りで光り、カウストゥバ宝石の光の房のように耳に付けたアショーカの若葉で飾られ、大きな象の媚液の額飾りで見えない傘の影の円のように額を離れることのない、足先から分け目まで月光のように白い白檀で初代の王の名声のように白くされた、首の花環で河のように海の女主人に治められるかのような、蓮根のように柔らかい肢体で蓮から生まれたことを言葉なく語る女を見た。

王は動揺せず尋ねた。「よき方よ、あなたはどなたですか。なぜ姿を現されたのですか」。女は、女にふさわしからぬ大胆さで彼を圧倒するかのように言った。「勇者よ、知れ。私はナーラーヤナ（ヴィシュヌ）の胸で遊ぶガゼルのような者、プリトゥ・バラタ・バギーラタなどの王の家系の旗印、勇者の腕の勝利の柱の遊びの殿堂の人形、戦の血の河の波に戯れるのを好む気ままな王のハンサ鳥の雌、白い王の傘の林の雌孔雀、極めて鋭い武器の刃の森を彷徨う遊びの雌獅子、剣の刃の水の蓮池――シュリー（女神ラクシュミー、繁栄の女神）である。おまえのこの武勇の精髄に奪われた。求めよ。望む恩恵を与えよう」。

Lakṣmīs tu devī prītatara-hṛdayā vistīryamāṇena cakṣuṣā kṣīrôdenêvôpari paryastenâbhiṣiñcantī bhū-pālam "evam astu" ity abravīt. avādīc ca punaḥ: "anena sattvôtkarṣeṇa bhagavac-Chiva-bhaṭṭāraka-bhaktyā câsādhāraṇayā bhavān bhuvi sūryā-candramasos tṛtīya ivâ-vicchinnasya prati-dinam upacīyamāna-vṛddheḥ śuci-su-bhaga-mānya-satya-tyāga-śaurya-śauṇḍa-puruṣa-prakāṇḍa-prāyasya mahato rāja-vaṃśasya kartā bhaviṣyati. yasminn utpatsyate sarva-dvīpānāṃ bhoktā Hariścandra iva Harṣa-nāmā cakravartī tri-bhuvana-vijigīṣur dvitīyo Māndhātêva yasyâyaṃ karaḥ svayam eva kamalam apahāya grahīṣyati cāmaram" iti vacaso 'nte tiro-babhūva.

Bhairavācāryo 'pi tasyā devyās tena vacasā karmaṇā ca samyag-upapāditena sadya eva kuntalī kirīṭī kuṇḍalī hārī keyūrī mekhalī mudgarī khaḍhgī ca bhūtvâvāpa vidyā-dharatvam. provāca ca: "rājan! a-dūra-vyāpinaḥ phalgu-cetasām alasānāṃ manorathāḥ. satāṃ tu bhuvi vistāra-vatyaḥ sva-bhāvenâivôpakṛtayaḥ. svapne 'py a-saṃbāvitāṃ dātum imāṃ dakṣiṇāṃ kṣamaḥ ko 'nyo bhavantam apahāya. saṃpat-kaṇikām api prāpya tulêva laghu-prakṛtir unnatim āyāti. tvadīyair guṇair upakaraṇī-kṛtasya tvatta eva ca labdhâtma-lābhasya nirlajjatêyam asya mūḍha-hṛdayasya. tad icchāmi yena kena-cit kārya-lavôpapādanôpayogena smarayitum ātmānam" iti. tathôktaś ca bhū-bhujā jigamiṣuḥ su-dṛḍhaṃ samāliṅgya Ṭīṭibhâdīn kuvalaya-vanenêvâśyāya-śīkara-srāviṇā sâsreṇa cakṣuṣā vīkṣamāṇaḥ kṣiti-patiṃ punar-uvāca: "tāta! bravīmi yāmîti na sneha-sadṛśam. tvadīyāḥ prāṇā iti punar uktam. gṛhyatām idaṃ śarīrakam iti vyatirekeṇârtha-karaṇam. tilaśaḥ krītā vayam iti nôpakārânurūpam. bāndhavo 'sîti dūrī-karaṇam iva. tvayi sthitaṃ hṛdayam ity a-pratyakṣam. tvad-virahânukāriṇī kāraṇêyaṃ na siddhir ity a-śraddheyam. niṣ-kāraṇas tavôpakāra ity anuvādaḥ. smartavyā vayam ity ājñā. sarvathā kṛtaghnâlāpeṣv a-saj-jana-kathāsu ca cetasi kartavyo 'yaṃ svârtha-niṣṭhuro janaḥ" pratyupakāra-duṣ-praveśās tu bhavanti dhīrāṇāṃ hṛdayâvaṣṭambhāḥ. yatas taṃ rājā "bhavat-siddhyâiva parisamāpta-kṛtyo 'smi. sādhayatu mānyo yathā-samīhitaṃ sthānam" iti pratyācacakṣe. tathôktaś ca bhū-bhujā jigamiṣuḥ su-dṛḍhaṃ samāliṅgya Ṭīṭibhâdīn kuvalaya-vanenêvâśyāya-śīkara-srāviṇā sâsreṇa cakṣuṣā vīkṣamāṇaḥ kṣiti-patiṃ punar-uvāca: yayau ca sīmantita-graha-grāmaḥ siddhy-ucitaṃ dhāma.
王はこれを聞いて心の底から喜んだ。バイラヴァーチャーリヤもまたこの女神の言葉と正しく完遂された儀式によって、直ちに巻き髪・冠・耳飾り・首飾り・腕飾り・腰帯・棍棒・剣を得てヴィディヤーダラ（知識の持ち主＝半神）の身分を獲得した。そして言った。「王よ、怠け者の願望は遠くまで及ばない。善き者の利他行為は本性によって大地のように広い。夢にも思わなかったこの報酬を与え得る者は、あなたを除いて他にいない。繁栄の一粒でも得れば、秤のように軽い性質の者は高慢になる。あなたの美徳に道具として使われ、あなたからこそ自己の獲得を得たこの愚かな心の者の厚かましさよ。それゆえ、何らかの務めの一端を果たすことで自らを思い出させたいのです」。しかし報恩は勇者の心の確信には入りがたい。それゆえ王は「あなたの成就によってこそ私の務めは完了しました。尊者よ、望みの場所へお行きください」と辞退した。こう王に言われて去ろうとする師は、しっかりと抱擁し、ティーティバらを青蓮の園のように露の雫を滴らす涙の目で見つめながら、王にさらに言った。「息子よ、"去る"と言えば情愛にふさわしくない。"あなたの命です"と言えば繰り返しに過ぎない。"この身を受け取れ"と言えば逆説の修辞に過ぎない。"胡麻粒ほどに買い取られた我々"と言えば恩義にふさわしくない。"あなたは親族だ"と言えば遠ざけるようだ。"あなたに心を残す"と言えば目に見えぬこと。"あなたとの別離に似たこの成就は原因ではない"と言えば信じがたいこと。"あなたの恩義は無条件だ"と言えば既知の繰り返し。"我々を思い出せ"と言えば命令。すべてにおいて忘恩の言葉と不善人の話に、この自己の利益に冷酷な者を心に留めよ」。こう述べて勢いよく切れた首飾りの真珠が飛び散って星の群れを打つかのように天空に飛び立った。そして星座の群れを分け目のように分けて、成就にふさわしい住処へと去った。

katipaya-divasâpagame ca parivrāḍ bhū-bhujā vāryamāṇo 'pi vanaṃ yayau. Pātālasvāmi-Karṇatālau tu śauryânuraktau tam eva siṣevāte. Saṃpādita-mano-rathâtirikta-vibhavau ca su-bhaṭa-maṇḍala-madhye niṣkṛṣṭa-maṇḍalâgrau samara-mukheṣu prathamam upayujyamānau kathântareṣu cântarântarā vicitrāṇi Bhairavācārya-caritāni śaiśava-vṛttântāṃś ca kathayantau tenâiva sârdhaṃ jarām ājagmatur iti.
数日後、遊行僧は王に止められながらも森に去った。パーターラスヴァーミンとカルナターラは武勇に惚れ込んで王に仕え続けた。願望を超える財を得た彼らは、勇者の群れの中で最前線に立ち、戦の先頭で最初に用いられ、話の合間にバイラヴァーチャーリヤのさまざまな行状や少年時代の逸話を語りながら、王とともに老いに至ったという。
iti mahā-kavi-śrī-Bāṇa-bhaṭṭa-kṛte Harṣacarite rāja-darśanaṃ nāma tṛtīya ucchvāsaḥ
