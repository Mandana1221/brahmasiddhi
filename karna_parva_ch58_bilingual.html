マハーバーラタ ― カルナ篇 第58章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 58 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ58」、全39詩節からなり、アルジュナによるドゥリシュタデュムナの救出とドラウニ（アシュヴァッターマン）の撃退、そして三人の勇士（アルジュナ・ドゥリシュタデュムナ・サハデーヴァ）によるサンシャプタカ討伐への転進を描きます。章の冒頭はドゥリシュタデュムナ（パールシャタ）がドラウニの挑発に応えて言葉を返す場面（第1〜3詩節）から始まり、ドゥリシュタデュムナがドラウニを矢で射る場面（第4〜11詩節）、ドラウニが剣と盾をとって反撃する場面（第12〜18詩節）、クリシュナがアルジュナにドゥリシュタデュムナの危機を告げる場面（第19〜21詩節）、アルジュナがドラウニを撃退してドゥリシュタデュムナを救出する場面（第22〜35詩節）、そしてクリシュナがアルジュナにサンシャプタカとの約定を想起させ、サンシャプタカ討伐へと向かう場面（第36〜39詩節）で本章は終わります。なお、本章では冒頭の注記「8-58-0」「8-58-0x」（「サンジャヤは語った」）が第1詩節の本文に統合されており（これまでの章と同じ処理）、第39詩節末には「|| ||」の二重ダンダが見られますが、これは章の終わりを示す通常の書式として処理しています。また、和訳原典には本章末の結びの一文が存在しなかったため（第51〜57章に続き八章連続の事例）、サンスクリット原典の奥書（コロフォン）に基づき、結びの一文を補って記載しています。OCR誤記としては、第12・17詩節「khaṅgam」「khahgaṃ」の子音誤記（khaṅgam/khahgaṃ→khaḍgam/khaḍgaṃ「剣」、文脈上「剣と盾を手にした」場面に対応）、第16詩節「yadamāno」の子音誤記（yadamāno→yatamāno「奮戦する」）、第25詩節「dṛṣṭvai」の語尾誤記（dṛṣṭvai→dṛṣṭvā「見て」）を、それぞれ文脈・語形・字形類似の照合により修正しています。
karṇaparva — aṣṭapañcāśo'dhyāyaḥ (58)
第58章
sañjaya uvāca|
evam uktaḥ pratyuvāca dhṛṣṭadyumnaḥ pratāpavān|
āśiṣaṃ tāṃ pravaktavyāṃ māmako dāsyate tava||
// 8-58-1 //
サンジャヤは語った。
こう言われてドゥリシュタデュムナは勇猛に答えた。「我が剣が、汝の父が力を尽くして戦場で受けた祝福を汝に与えるであろう。
yena eva te pitur dattā yatamānasya saṃyuge|
eṣa te prativākyaṃ vai asir dāsyati māmakaḥ|
yena kṛttaṃ tava pitur yatamānasya tac chiraḥ||
// 8-58-2 //
サンジャヤは語った。
この我が剣が汝への返答となろう。これで汝の父の首を切ったのだから。」
yadi tāvan mayā droṇo nihato brāhmaṇabruvaḥ|
tvām idānīṃ kathaṃ yuddhe na haniṣyāmi kilbiṣam||
// 8-58-3 //
サンジャヤは語った。
「ブラフマーを名乗るだけの者（ドローナ）を私が殺したのなら、犯罪者よ、今この戦いで汝を殺せぬわけがあろうか。」
evam uktvā mahātejāḥ senāpatir arindamaḥ|
sutīkṣṇena atha bhallena drauṇiṃ vivyādha pārṣataḥ||
// 8-58-4 //
サンジャヤは語った。
こう言って、大いなる光輝の総大将、敵を制する者パールシャタは、鋭いバッラ矢でドラウニを射た。
tato drauṇiḥ susaṅkruddhaḥ śaraiḥ sannataparvabhiḥ|
ācchādayat diśo rājan dhṛṣṭadyumnasya saṃyuge||
// 8-58-5 //
サンジャヤは語った。
王よ、激怒したドラウニは、しなやかな矢で戦場のドゥリシュタデュムナの方角を覆い尽くした。
naiva antarikṣaṃ na diśo nāpi yodhāḥ sahasraśaḥ|
dṛśyante vai mahārāja śaraiśchannāḥ samantataḥ|
ekaḥ sanvārayāmāsa prekṣaṇīyaḥ samantataḥ||
// 8-58-6 //
サンジャヤは語った。
空も方角も数千の戦士たちさえも、大王よ、四方から矢で覆われて見えなくなった。一人で四方を見事に防いでいた。
tathā eva pārṣato rājan drauṇim āhavaśobhinam|
śaraiḥ sañchādayāmāsa sūtaputrasya paśyataḥ||
// 8-58-7 //
サンジャヤは語った。
同様にパールシャタも、王よ、スータの息子（カルナ）が見ている前で、戦場で輝くドラウニを矢で覆い隠した。
rādheyo'pi mahārāja pāñcālān saha pāṇḍavaiḥ|
draupadeyā yudhāmanyum uttamaujasam eva ca||
// 8-58-8 //
サンジャヤは語った。
ラーデーヤもまた、大王よ、パーンチャーラ族とパーンダヴァ、ドラウパディーの息子、ユダーマニユ、ウッタマウジャスを、
sātyakiś ca mahārāja yodhāṃś ca anyān sahasraśaḥ|
ekas tān vārayāmāsa prekṣaṇīyaḥ samantataḥ||
// 8-58-9 //
サンジャヤは語った。
大王よ、サーティヤキや他の数千の戦士たちをも、一人で四方を見事に防いでいた。
dhṛṣṭadyumnas tu samare drauṇeś ciccheda kārmukam|
kṣurapreṇa sutīkṣṇena paśyatāṃ sarvayodhinām||
// 8-58-10 //
サンジャヤは語った。
ドゥリシュタデュムナは戦場で、全ての戦士たちが見ている前で、鋭い剃刀矢でドラウニの弓を切り落とした。
tad apāsya dhanuś chinnam anyad ādatta kārmukam|
vegavat samare ghoraṃ śarāṃś ca āśīviṣopamān||
// 8-58-11 //
サンジャヤは語った。
ドラウニは切られた弓を捨て、別の恐ろしい弓と毒蛇のような矢を取った。
sa pārṣatasya rājendra dhanuḥ śaktiṃ gadāṃ dhvajam|
hayān sūtaṃ rathaṃ ca eva nimeṣād vyadhamac charaiḥ||
// 8-58-12 //
サンジャヤは語った。
王よ、彼はパールシャタの弓、矛、棍棒、旗、馬、御者、戦車を瞬く間に矢で打ち砕いた。
sa cchinnadhanvā viratho hatāśvo hatasārathiḥ|
khaḍgam ādatta vipulaṃ śatacandraṃ ca bhānumat||
// 8-58-13 //
サンジャヤは語った。
弓を断たれ、戦車を失い、馬と御者を殺されたドゥリシュタデュムナは、大きな剣と百の月の模様の輝く盾を取った。
drauṇis tad api rājendra bhallaiḥ kṣipraṃ mahārathaḥ|
ciccheda samare vīraḥ kṣiprahasto dṛḍhāyudhaḥ||
// 8-58-14 //
サンジャヤは語った。
王よ、ドラウニはそれをも素早くバッラ矢で切り裂いた。素早い手と確かな武器を持つ大戦車戦士として。
rathādanavarūḍhasya dhanvino bāhuśālinaḥ|
paśyatāṃ sarvasainyānāṃ tad adbhutam iva abhavat||
// 8-58-15 //
サンジャヤは語った。
弓の名手にして腕の達人が、全軍が見ている前で戦車から降りもしていない者に対してこれをなしたのは驚嘆すべきことであった。
dhṛṣṭadyumnaṃ tu virathaṃ hatāśvarathasārathim|
śastraiś ca bahudhā viddham astraiś ca śakalīkṛtam|
na atarat bharataśreṣṭha yatamāno mahārathaḥ||
// 8-58-16 //
サンジャヤは語った。
バーラタ族の最良者よ、大戦車戦士ドラウニは、戦車を失い馬と御者を殺され、様々な武器で射られ武器を破壊されたドゥリシュタデュムナを、力を尽くしても打ち倒すことはできなかった。
tasya antam iṣubhī rājan yadā drauṇir na gacchati|
atha tyaktvā rathaṃ vīraḥ pārṣataṃ tvarito'nvagāt|
pragṛhya vipulaṃ khaḍgaṃ jātarūpapariṣkṛtam||
// 8-58-17 //
サンジャヤは語った。
王よ、ドラウニが矢でパールシャタの最後を遂げさせられないとき、勇者は戦車を捨て、黄金で飾られた大剣を手に取り、急いでパールシャタを追った。
tasya sampatato rājan vapurāsīn mahātmanaḥ|
garuḍasya iva tato jighṛkṣoḥ pannagottamam||
// 8-58-18 //
サンジャヤは語った。
王よ、突進するこの偉大な魂の姿は、蛇の王を捕らえんとするガルダのようであった。
etasminn eva kāle tu keśavaḥ paravīrahā|
abravīd bharataśreṣṭham arjunaṃ jayatāṃ varam||
// 8-58-19 //
サンジャヤは語った。
まさにその時、敵の勇者を殺すケーシャヴァは、バーラタの最良者アルジュナ、勝者の最上に語った。
paśya drauṇiṃ pārṣatasya yatamānaṃ vadhaṃ prati|
yatnaṃ karoti vipulaṃ hanyāc ca enaṃ na saṃśayaḥ||
// 8-58-20 //
サンジャヤは語った。
「パールシャタの殺害を目指して力を尽くすドラウニを見よ。大いなる努力をしており、疑いなく彼を殺すだろう。
trāyasva enaṃ mahābāho pārṣataṃ yuddhadurmadam|
drauṇer āsyagataṃ vīra mṛtyor āsyagataṃ yathā||
// 8-58-21 //
サンジャヤは語った。
大腕よ、戦いに勇猛なパールシャタを救え。ドラウニの口に入った者を、死の口から救うように。」
evam uktvā mahārāja vāsudevaḥ pratāpavān|
praiṣayat turagān yatra drauṇir vīro vyavasthitaḥ||
// 8-58-22 //
サンジャヤは語った。
大王よ、こう言って勇猛なるヴァースデーヴァは、ドラウニが構えているところへ馬を走らせた。
te hayāś candrasaṅkāśāḥ keśavena pracoditāḥ|
pibanta iva ca ākāśaṃ jagmur drauṇer mahāratham||
// 8-58-23 //
サンジャヤは語った。
ケーシャヴァに駆られた月のように白い馬たちは、空を飲み込むかのようにドラウニの大戦車に向かった。
dṛṣṭvā drauṇir mahārāja vāsudevadhanaṃjayau|
dhṛṣṭadyumnavadhe rājaṃś cakre yatnaṃ mahābalaḥ||
// 8-58-24 //
サンジャヤは語った。
大王よ、ドラウニはヴァースデーヴァとダナンジャヤを見て、王よ、大力をもってドゥリシュタデュムナの殺害にいっそう力を注いだ。
vikṛṣyamāṇaṃ dṛṣṭvā dhṛṣṭadyumnaṃ janeśvara|
śarāṃś cikṣepa vai pārtho drauṇiṃ prati mahārathaḥ||
// 8-58-25 //
サンジャヤは語った。
ドゥリシュタデュムナが引きずられているのを見て、パールタは大戦車戦士としてドラウニに向かって矢を放った。
te śarā hemavikṛtā gāṇḍīvapreṣitā bhṛśam|
drauṇimāsādya viviśur valmīkam iva pannagāḥ||
// 8-58-26 //
サンジャヤは語った。
ガーンディーヴァから激しく放たれた黄金で飾られた矢は、ドラウニに到達して、蛇が蟻塚に入るように体に刺さった。
viddhas tu taiḥ śarair ghorair droṇaputraḥ pratāpavān|
utsṛjya samare rājan pāñcālam amitaujasam||
// 8-58-27 //
サンジャヤは語った。
恐ろしい矢に射られたドローナの息子は勇猛にも、王よ、戦場でパーンチャーラの計り知れぬ力の者を放した。
āruroha rathaṃ vīro dhanañjayaśarārditaḥ|
pragṛhya ca dhanuḥ śreṣṭhaṃ pārthaṃ vivyādha sāyakaiḥ||
// 8-58-28 //
サンジャヤは語った。
ダナンジャヤの矢に苦しめられた勇者は戦車に乗り、最上の弓を取ってパールタを矢で射た。
etasminn antare śūraḥ sahadevo janādhipa|
apovāha rathena ājau pārṣataṃ śatrutāpanam||
// 8-58-29 //
サンジャヤは語った。
まさにその時、王よ、勇者サハデーヴァが戦場で戦車に乗せて、敵を苦しめるパールシャタを運び去った。
arjuno'pi mahārāja drauṇiṃ vivyādha patribhiḥ|
taṃ droṇaputraḥ saṃrabdho bāhvor urasi ca arpayat||
// 8-58-30 //
サンジャヤは語った。
大王よ、アルジュナもドラウニを羽矢で射た。ドローナの息子は怒って両腕と胸に矢を打ち込んだ。
krodhitas tu raṇe pārtho nārācaṃ kālasannibham|
droṇaputrāya cikṣepa yamadaṇḍam iva aparam||
// 8-58-31 //
サンジャヤは語った。
怒ったパールタは死神の杖のような鉄矢を、もう一本のヤマの杖のようなものをドローナの息子に放った。
sa brāhmaṇasya aṃsadeśe nipapāta mahādyuteḥ|
sa vihvalo mahārāja śaravegena saṃyuge|
niṣasāda rathopasthe vaiklavyaṃ paramaṃ yayau||
// 8-58-32 //
サンジャヤは語った。
大王よ、大輝きのバラモンの肩のあたりにそれは突き刺さった。矢の勢いに揺れ動き、戦車の床に座り込み、極度のめまいに陥った。
taṃ tu matvā hataṃ vīraṃ sārathiḥ śatrukarśanam|
apovāha raṇena ājau tvaramāṇo raṇājirāt||
// 8-58-33 //
サンジャヤは語った。
御者は勇者が殺されたと思い、急いで戦場から戦車を退却させた。
atha uddhṛṣṭaṃ mahārāja pāñcālair jitakāśibhiḥ|
mokṣitaṃ pārṣataṃ dṛṣṭvā droṇaputraṃ ca pīḍitam||
// 8-58-34 //
サンジャヤは語った。
大王よ、勝利に酔うパーンチャーラ族がパールシャタを救出し、ドローナの息子が打ち負かされたのを見て、
vāditrāṇi ca divyāni prāvādyanta sahasraśaḥ|
siṃhanādaś ca sañjajñe dṛṣṭvā yuddhaṃ tad adbhutam||
// 8-58-35 //
サンジャヤは語った。
数千の天上の楽器が奏でられ、この驚嘆すべき戦いを見てライオンの吼え声が起こった。
tataḥ karṇo mahārāja vyākṣipat vijayaṃ dhanuḥ|
dṛṣṭvā arjunaṃ raṇe kruddhaḥ prekṣate ca muhurmuhuḥ|
dvairathaṃ cāpi pārthena gantukāmo mahādyutiḥ||
// 8-58-36 //
サンジャヤは語った。
大王よ、カルナは怒ってヴィジャヤの弓をしならせ、戦場でアルジュナを見て何度も見つめた。大輝きの者はパールタとの一騎打ちを望んでいた。
evaṃ kṛtvā'bravītpārtho vāsudevaṃ dhanañjayaḥ|
yāhi saṃśaptakān kṛṣṇa kāryam etat paraṃ mama||
// 8-58-37 //
サンジャヤは語った。
このようにしてパールタ、ダナンジャヤ（アルジュナ）はヴァースデーヴァに語った。「クリシュナよ、サムシャプタカ族のところへ行ってくれ。それが私の最優先の任務だ。」
tataḥ prayāto govindaḥ śrutvā pāṇḍavabhāṣitam|
rathena atipatākena manomārutaraṃhasā||
// 8-58-38 //
サンジャヤは語った。
パーンダヴァの言葉を聞いて、ゴーヴィンダは旗をはためかせ心と風のような速さの戦車で出発した。
evam eṣa kṣayo vṛttaḥ pṛthivyāṃ pṛthivīpate|
tāvakānāṃ pareṣāṃ ca rājan durmantrite tava||
||
// 8-58-39 //
サンジャヤは語った。
このようにして、大地の王よ、汝の軍にも敵の軍にも殺戮が起こった。王よ、これは汝の誤った策謀のゆえであった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe aṣṭapañcāśo'dhyāyaḥ|| 58 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十八章は終わる。
