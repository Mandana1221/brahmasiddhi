1ひとことで言うと

人間の王プルーラヴァスと、天の踊り子（天女）ウルヴァシーの恋の劇です。出会い、すれ違い、結ばれ、引き離され、最後に「ずっと一緒にいてよい」と神に許されるまでを、五つの幕で描きます。

カーリダーサには三つの戯曲が伝わっています。『マーラヴィカーとアグニミトラ』『ヴィクラモールヴァシーヤ』、そして最も有名な『シャクンタラー』です。この劇はその真ん中にあたり、人間と天の存在の恋、別れ、子どもの登場による解決という点で、『シャクンタラー』とよく似た骨組みをもっています（→解説）。

2登場人物と人物相関図

登場人物は、大きく天の世界の者と地上（王の宮廷）の者に分かれます。物語の中心は、そのあいだを結ぶ一本の赤い線——王とウルヴァシーの恋です。

4物語の山と谷

この劇は、二人が「近づく」と「離れる」を交互にくり返します。下の図は、二人の幸せの度合いを、幕の流れにそって描いたイメージ図です（数値ではありません）。

「近づいては離れる」をくり返すたびに、山と谷の幅は大きくなります。そして最も深い谷（第四幕の狂乱）のすぐあとに再会がやってきます。終わりの直前にも、もう一度だけ小さな谷（別れの危機）が置かれ、最後の喜びをいっそう大きく見せています。

5天と地を行き来するウルヴァシー

ウルヴァシーは天界の住人なので、地上にずっといることができません。各幕で彼女がどこにいるかを追うと、物語の骨組みがよく見えます。

前半は「天の者が地上に来ても、すぐ帰ってしまう」話、後半は「地上にとどまった天の者を、どうすれば引き止めておけるか」という話だと言えます。

6幕ごとのあらすじ

I第一幕　救出と一目ぼれ対訳を読む →
場所
ヒマラヤのヘーマクータの峰
とき
王が太陽神への参拝から帰る途中
詩節
18（うち王が12）
  1. 座頭の前口上のあと、天女たちの悲鳴が聞こえる。財宝の神クベーラのもとから帰る途中のウルヴァシーとチトラレーカーが、魔族ケーシンにさらわれたのだ。
  2. プルーラヴァス王は車を駆って魔族を追い払い、二人を取り戻して峰に連れ帰る。
  3. 気を失っていたウルヴァシーが目を覚ます。二人は互いに一目で恋に落ちる。
  4. 天の楽人の王チトララタが迎えに来て、ウルヴァシーは天へ帰る。首飾りが蔓草に引っかかったふりをして、もう一度王を振り返りながら。

見どころ：目覚めたウルヴァシーの美しさを讃える王の詩（「この人を造ったのは月か、恋の神か、春か」）。

II第二幕　恋文の行方対訳を読む →
場所
王都プラティシュターナの王宮、プラマダ園（後宮の庭）
とき
第一幕の後日、昼
詩節
23（うち王が19）
  1. （前場）王妃の侍女ニプニカーが、口の軽い道化から、王の恋の相手がウルヴァシーだと聞き出す。
  2. 王は道化と庭へ行き、恋の苦しみを嘆く。そこへ、姿を隠したウルヴァシーとチトラレーカーが天から降りて来て、それを聞く。
  3. ウルヴァシーは樺の皮に恋の詩を書いて王の前に落とす。やがて姿を現すが、天の劇の上演のため、すぐに呼び戻されてしまう。
  4. 道化がなくした恋文は風に飛ばされ、王妃の手に。王の言いわけもむなしく、王妃は怒って去る。

見どころ：道化と王のかけあいの喜劇。恋文が人の手から手へ渡っていく、すれ違いの面白さ。

III第三幕　王妃の誓い対訳を読む →
場所
宮殿の「宝石の御殿」の屋上
とき
夕暮れから月の出
詩節
22（うち王が19）
  1. （幕間）バラタ仙の二人の弟子が語る。天界での劇で、ウルヴァシーは「プルショーッタマ（ヴィシュヌ）に」と言うべき台詞を「プルーラヴァスに」と言いまちがえ、天界にいられなくなる呪いを受けた。しかしインドラは、「王が子を見るまで、王のもとにいてよい」と許した。
  2. 王妃は「夫の機嫌を直す誓い」を立て、王を月の見える屋上に招く。
  3. 姿を隠したウルヴァシーの見ている前で、王妃は月とローヒニー星を証人に、「王が愛する女とは仲良くする」と誓って去る。
  4. ウルヴァシーが姿を現して後ろから王の目をふさぎ、二人はついに結ばれる。

見どころ：怒っていた王妃が、自ら身を引く場面。嫉妬から気高さへの変化が、この幕の山場。

IV第四幕　狂乱の王対訳を読む →
場所
ガンダマーダナ山の森
とき
雨季
詩節
43（うち王が42）——全幕で最多
  1. （前場）王とウルヴァシーは山の森で暮らしていた。王が楽人の娘に見とれたことに怒ったウルヴァシーは、女の立ち入りを禁じたクマーラ神の森に入り、蔓草に変えられてしまう。
  2. 恋人を失った王は正気をなくし、雨の森をさまよう。雲を魔物と見まちがえ、孔雀・カッコウ・ハンサ鳥・チャクラヴァーカ鳥・蜜蜂・象・山・川・鹿に、次々と恋人の行方を尋ねる。
  3. 岩のあいだで赤い宝石を見つける。天の声が、それは別れた者を結び合わせる「結びの宝石」だと教える。
  4. 宝石を持って、恋人に似た蔓草を抱きしめると、蔓草はウルヴァシーに戻る。二人は雲を車にして都へ帰る。

見どころ：王の独り舞台。自然のすべてに語りかける詩が続く、インド文学屈指の名場面。伝本によっては、ここに歌と踊りが数多く入る（→解説）。

V第五幕　王子アーユス対訳を読む →
場所
王都の宮殿
とき
ガンガーとヤムナーの合流点での沐浴の日
詩節
24（うち王が16）
  1. 結びの宝石を、禿鷹が肉と見まちがえてさらっていく。やがて矢に射られた禿鷹が宝石とともに落ちてくる。矢には「ウルヴァシーとプルーラヴァスの子、アーユスの矢」と刻まれていた。
  2. チヤヴァナ仙の庵の女行者が少年を連れてくる。それはウルヴァシーがひそかに産み、庵に預けていた息子アーユスだった。
  3. 喜ぶ王の横で、ウルヴァシーは泣き出す。「王が子を見たら天へ帰る」という約束の時が来てしまったのだ。王は位を息子に譲り、森に隠れ住もうと決める。
  4. そこへナーラダ仙がインドラの言葉を伝えに来る。「神々と阿修羅の戦いが近い。王は武器を捨ててはならない。ウルヴァシーは生涯、王の妻でいてよい」。アーユスは皇太子に立てられ、劇は祝福の詩で終わる。

見どころ：喜びと悲しみが一瞬で入れかわる展開。最後に神の計らいですべてが解決する大団円。

7呪いと約束のしくみ

この劇でいちばんわかりにくいのが、ウルヴァシーにかけられた「呪い」と「条件」です。順番に並べると、次のようになります。

1
劇での言いまちがい第三幕・幕間
天界で、バラタ仙の劇『ラクシュミーの婿選び』が上演される。ラクシュミー役のウルヴァシーは「誰を愛するか」と問われ、「プルショーッタマに」と言うべきところを「プルーラヴァスに」と答えてしまう。
2
バラタ仙の呪い第三幕・幕間
怒った師は「お前は天界にいられなくなる」と呪う。
3
インドラの条件第三幕・幕間
王に恩のあるインドラは、呪いをゆるめる。「王のもとへ行ってよい。ただし、王が二人の子の顔を見るまで」。
4
子を隠す第四幕と第五幕のあいだ
王と離れたくないウルヴァシーは、生まれた子をチヤヴァナ仙の庵にひそかに預け、王に見せないようにする。
5
王が子を見てしまう第五幕
成長したアーユスが宮殿に連れてこられ、条件が満たされてしまう。ウルヴァシーは天へ帰らなければならない。
6
インドラの新しい言葉第五幕
ナーラダ仙が伝える。神々の戦いに王の力が必要なので、ウルヴァシーは生涯王のもとにいてよい。

つまり、第三幕で「時限つき」の幸せが約束され、第五幕でその期限が来てしまい、最後に神によって「期限なし」に書きかえられる、というしくみです。第三幕の幕間は、第五幕のための伏線になっています。

10解説——読むためのヒント

① 題名の意味

『ヴィクラモールヴァシーヤ』は、vikrama（武勇）と urvaśī（ウルヴァシー）を合わせた題名で、「武勇によって得られたウルヴァシー（の物語）」という意味です。第一幕で、王が魔物から彼女を救い出したことを指します。一説には、カーリダーサの保護者とされるヴィクラマーディティヤ王の名がかけられているとも言われます。

② もとになった古い物語

ウルヴァシーとプルーラヴァスの話は、インド最古の文献『リグ・ヴェーダ』（第10巻95番）にまでさかのぼる、とても古い物語です。カーリダーサはこれを大きく作りかえました。

古い物語（ヴェーダ・ブラーフマナ）カーリダーサの劇
出会い天女が人間の王の妻になる王が魔物から天女を救い、互いに一目ぼれする
別れの原因天女が出した約束（『シャタパタ・ブラーフマナ』では「裸の姿を見せない」）が、天の楽人たちの策略で破られる師の呪いと、インドラの「子を見るまで」という条件。第四幕では蔓草への変身
王の姿去った天女を探し、戻ってくれと嘆願する狂乱して森をさまよい、自然のすべてに恋人の行方を尋ねる
結末天女は戻らない（『リグ・ヴェーダ』）、または王が祭式によって天の楽人の仲間になる（ブラーフマナ）神の許しで、天女は生涯地上にとどまる。めでたしめでたし

『シャタパタ・ブラーフマナ』で、天女たちが水鳥の姿で池に現れる場面は、第四幕で王がハンサ鳥に恋人の行方を尋ねる詩を思い出させます。

④ 第四幕の「歌」と二つの伝本

この劇には、大きく分けて二つの伝わり方（伝本）があります。一方の伝本では、第四幕にアパブランシャ語（中世インドの口語に近い言葉）の歌が三十あまり入っていて、王は歌い踊りながら森をさまよいます。もう一方の伝本にはこれらの歌がありません。

本サイトの底本の Kāle 本は、歌を本文から外して巻末の付録に収めています。一方、対照に使った Clay Sanskrit Library 本は歌を本文に含めています。そのため、第四幕の詩節番号は、Kāle 本では43まで、Clay 本では77までと大きく違います。対訳の第四幕では、歌が入る位置ごとに内容を注で紹介しています。

⑤ サンスクリットとプラークリット

サンスクリット劇では、登場人物によって話す言葉が決まっています。

サンスクリット王、聖仙（ナーラダ）、天の楽人の王、御者、侍従長、バラタの弟子の一人（ガーラヴァ）など、主に身分の高い男性
プラークリットウルヴァシー、チトラレーカー、王妃、侍女たち、女行者、道化（ヴィドゥーシャカ）、バラタの弟子の一人（パッラヴァ）など、主に女性と道化

天女であるウルヴァシーも、女性の役としてプラークリットで話します。対訳では、プラークリットの台詞にサンスクリット訳（チャーヤー）を小さく添えています。

⑥ トロータカという形式

Kāle 本のサンスクリット注は、この劇を「トロータカ（troṭaka）」と呼び、その定義として「五・七・八・九幕からなり、神々と人間にかかわる劇」（सप्ताष्टनवपञ्चाङ्कं दिव्यमानुषसंश्रयम्）という規定を引いています。天女と人間の王の恋を五幕で描くこの劇に、よく合った分類です。

⑦ 読みどころ

  • 第一幕の王の詩——ウルヴァシーの美しさを讃える、カーリダーサらしい華やかな比喩。
  • 第二幕の喜劇——道化のうっかりと、恋文をめぐるすれ違い。
  • 第三幕の王妃——嫉妬から思いやりへと変わる、もう一人のヒロイン。
  • 第四幕の狂乱——雨の森で、鳥や獣や山や川に語りかける王。自然と心が一つになる、この劇の頂点。
  • 第五幕の逆転——喜びが悲しみに、悲しみが喜びに、目まぐるしく入れかわる結末。
