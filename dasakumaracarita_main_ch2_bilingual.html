Daśakumāracarita — Apahāravarmacaritam — Dvitīya Ucchvāsaḥ
dvitīyocchvāsaḥ — Apahāravarmacaritam
第二章 アパハーラヴァルマンの物語
◆ 1. 出発とマリーチ仙の庵
◆ 1. 主君を求めてチャンパーへ
"deva, tvayi tadāvatīrṇe dvijopakārāyāsuravivaraṃ tvadanveṣaṇaprasṛte ca mitragaṇa ahamapi mahīmaṭannaṅgeṣu gaṅgātaṭe bahiścampāyāḥ "kaścidasti tapaḥprabhāvotpannadivyacakṣurmarīcirnāma maharṣiḥ' iti / kutaścitsaṃlapato janasamājādupalabhyāmutobubhutsustvadgatiṃ tamuddeśamagamam /
nyaśāmayaṃ ca tasminnāśrame kasyāciccūtapotakasya chāyāyāṃ kamapyudvignavarṇaṃ tāpasam / amunā cātithivadupacaritaḥ kṣaṇaṃ viśrāntaḥ "kvāsau bhagavānmaraciḥ, tasmādahamupalipsuḥ prasaṅgaproṣitasya suhṛdo gatima āścaryajñānavibhavo hi sa maharṣirmahyāṃ viśrutaḥ' ityavādipam /
「陛下よ、あなたがバラモンを助けるため魔洞に降りられ、友の群れがあなたを探して散っていった時、私もまた大地を彷徨い歩きました。アンガ国のガンジス河岸、チャンパーの城外にて、ある人々の語らいの中に『苦行の力で天眼を得たマリーチという大聖者がいる』と聞き及び、あなたの消息を知りたく、その場所へ赴きました。」
「その庵にて、若いマンゴーの木の陰に、何か心を悩ませている様子の苦行者を見かけました。その者に客のように迎えられ、しばし休息した後、私はこう尋ねました――『あの尊きマリーチ仙はどこにおられるか。訳あって離れ離れになった友の行方をあの方からお聞きしたい。不思議な知恵の力を持つ大聖者と聞いております。』」
◆ 2. マリーチの物語：遊女カーママンジャリーの策略
◆ 2. マリーチ仙の身の上話
athāsāvuṣṇamāyataṃ ca niḥśvasyāśaṃsata—"āsīttādṛśo munirasminnāśrame / tamekadā kāmamañjarī nāmāṅgapurīvataṃsasthānīyā bārayuvatiraśrubindutārakitapayodharā sanirvedamabhyetya kīrṇaśikhaṇḍāstīrṇabhūmirabhyavandiṣṭa /
tasminneva ca kṣaṇe mātṛpramukhastadāptavargaḥ sānukrośamanupradhāvitastatraivāvicchinnapātamapatat /
すると彼は熱く長い溜息をついて語り始めました。「かつてこの庵にそのような聖者がいた。ある時カーママンジャリーという名の、アンガの都の冠というべき若い遊女が、涙の雫に胸を飾り、嫌悪の情を帯びてやって来て、乱れた髪を地に敷いて聖者にひれ伏した。」
「まさにその瞬間、母を先頭にした彼女の縁者たちが、哀れみの声を上げながら追いかけてきて、そこにどさりと倒れ伏した。」
【注】 Kale注：カーママンジャリーは遊女（gaṇikā）の名で、チャンパーの都随一の美女とされる。「乱れた髪を地に敷いて」（kīrṇaśikhaṇḍāstīrṇabhūmir）は、嘆き悲しむ女の典型的な所作描写。この遊女が仙人を篭絡する挿話は、ダンディンの得意とする叙事的入れ子構造の一例である。
◆ 3. 遊女の母の陳情：遊女の義務
◆ 3. ガニカーの掟——母の長大な弁明
sa kila kṛpālustaṃ janamārdrayā girāśvāsyārtikāraṇaṃ tāṃ gaṇikāmapṛcchat / sā tu savrīḍeva sārvapādeva sagāraiveva cāvravīt / "bhagavan! aihikasya sukhasyābhājanaṃ jano 'yamāmuṣmikāya śvovasīyāyārtābhyupapattivittayorbhagavatpādayormūlaṃ śaraṇamabhiprapannaḥ' iti /
tasyāstu jananyudañjaliḥ paritaśāraśikhaṇḍabandhaspṛṣṭamuktabhūmirabhāṣata — "bhagavan, asyā me doṣameṣā vo dāsī vijñāpayati / doṣaśca mama svādhikarārānuṣṭhā panam / eṣa hi gaṇikāmāturadhikāro yadduhiturjanmanaḥ prabhṛtyevāṅgakriyā, tejobalavarṇamedhāsaṃvardhanena…" iti /
慈悲深い聖者は優しい言葉で一同を慰め、遊女にその苦悩の理由を尋ねた。彼女は恥じらいと悲しみと敬意を込めて答えた。「尊者よ、この世の快楽に縁のないこの者は、来世の幸いを求め、あなたの御足のもとに身を寄せて参りました。」
すると母親が合掌し、白髪交じりの結い髪を地に触れさせて平伏し、こう述べた。「尊者よ、この私の娘の過ちを、あなたの下婢がお伝えいたします。その過ちとは私自身の職務の不履行にあります。遊女の母の義務とは——娘の生まれた時から容姿を磨くこと、体力・光沢・容色・知力を増す適切な食事で身体を養うこと、五歳まで父にさえあまり見せぬこと、誕生日と吉日には盛大な祝祭を行うこと、愛の学問をあらゆる分野にわたって教えること、舞踊・歌唱・楽器・演劇・絵画・料理・調香・花飾りの技を仕込むこと、読み書きと巧みな話術を修めさせること、文法・論理・占星術の概要を教えること……」
【注】 Kale注（pp. 66-68）：この遊女の母の演説は、ヴァーツヤーヤナの『カーマスートラ』第6篇「ヴェーシヤーディカーラナ」の遊女規範をほぼそのまま散文に移し替えたものである。gaṇikāmātur adhikāra（遊女の母の職分）として、娘の教育・売り込み・客の選別・富裕な客の確保・無資力の客の追い払い方など、極めて詳細かつ体系的に列挙される。ダンディンはこの長大な列挙によって、遊女の世界の精緻な掟を読者に示すとともに、後に続くカーママンジャリーの策略の伏線を張っている。
◆ 4. カーママンジャリーの哲学的誘惑
◆ 4. ダルマ・アルタ・カーマの論争
sā tu rāgādaśanihata ivodbhāmyābravīt—"priye' kimetat / kuta idamaudāsīnyam / kva gatastava mayyasādhāraṇo 'nurāgaḥ' iti / atha sā sasmitamavādīt—"bhagavan, yayādya rājakale mattaḥ parājayo 'byupetastasyāśca mama ca kasmaicitsaṃgharṣe "marīcimāvarjitavatīva ślāghase' iti tayāsmyahamadhikṣiptā / dāsyaṇṇabandhena cāsminnarthe prāvartiṣi / siddhārthā cāsmitvatprasādāt' iti /
samasthā tathāvadhūto durmatiḥ kṛtānuśayaḥ śūnyavananyavartiṣṭa /
（聖者が情欲に溺れた後）彼はまるで雷に打たれたかのように激しく動揺して言った。「愛しい者よ、これは何だ。なぜ急にこの冷たさか。私に対するあの比類なき愛情はどこへ行ったのだ。」すると彼女はにっこりと微笑んで言った。「尊者よ、本日宮廷にて私に負けを認めたあの女との諍いで、『マリーチを篭絡したと自慢するのか』と私はなじられました。奴隷となるという賭けの約束で、この件を始めたのです。あなた様のお陰で勝ちを収めました。」
このように打ちのめされた愚かな聖者は、深く悔い、心ここにあらずのように虚ろな森に去って行った。
【注】 Kale注（p. 71）：この挿話の核心は「三つの人生目標」（trivarga：dharma・artha・kāma）をめぐる哲学的論争である。カーママンジャリーは、ダルマがアルタとカーマに優越するという巧みな議論を展開し、ブラフマーやヴィシュヌ、シヴァなど神々の情事の例を挙げて、真の知識を持つ者は感官の享楽に汚されないと説く。これにより聖者の自負心をくすぐり、世俗的快楽への扉を開かせた。遊女が聖者を哲学的に誘惑するという逆説的な構成は、ダンディンの技巧の極みである。
◆ 5. ヴァスパーリタとの出会い
◆ 5. ジャイナ僧院のヴァスパーリタ
adraśaṃ ca mārgābhyāśavartinaḥ kasyāpi kṣapaṇakavihārasya bahirvivikte raktāśokaṣaṇḍe niṣaṇṇamaspṛṣṭasamādhimādhikṣīṇamagragaṇyamanabhirūpāṇāṃ kṛpaṇavarṇaṃ kamapi kṣapaṇakam / urasi cāsya śithilitamalanicayānmukhānnipatato 'śrubindūnalakṣayam /
aprākṣaṃ cāntikopaviṣṭaḥ—"kva tapaḥ, kva ca ruditam / na cedrahasyamicchāmi śrotuṃ śokahetum' iti /
道端のジャイナ僧院の外、人気のない紅アショーカの林に座っている一人のジャイナ行者を見かけました。三昧にも達していない、やつれ果てた最も醜い者たちの筆頭のような、哀れな姿をしていました。その胸には、顔の汚れがゆるんだところから涙の雫がこぼれ落ちていました。
私は傍に座って尋ねました。「苦行と涙と、何という取り合わせでしょう。秘密でなければ、あなたの悲しみの理由をお聞かせください。」
◆ 6. ヴァスパーリタの話：カーママンジャリーに騙されて
◆ 6. 美貌の誇りと遊女の罠
so 'brūta—"saumya, śrūyatām / ahamasyāmeva campāyāṃ nidhipālitanāmnaḥ śroṣṭhino jyeṣṭhasūnurvasupālito nāma / vairūpyānmama nirūpaka iti prasiddhirāsīt / anyaścātra sundaraka iti yathārthanāmākalāguṇaiḥ samṛddho vasunā nātipuṣṭo 'bhavat /
tasya ca mama ca vapurvasunī nimittīkṛtya vairaṃ vairūpajīvibhiḥ pauradhūrtairudapādyata… abhyupetyāvāṃ prāhiṇuva tasyai dūtān / ahameva kilāmuṣyāḥ smaronmādaheturāsam /
彼は答えました。「優しい方よ、お聞きください。私はこのチャンパーで、ニディパーリタという名の長者の長男、ヴァスパーリタと申します。醜貌のため『ヴィルーパカ（醜い者）』として知られておりました。もう一人、スンダラカ（美男）というその名の通りの青年がおり、技芸と教養には富んでいましたが財力には恵まれませんでした。」
「私と彼との間で、容姿と財力を種にして、不和を煽ることで生計を立てている都市の悪党どもが争いを引き起こしました。…結局二人ともカーママンジャリーに使者を送りました。彼女の恋の狂気の火付け役となったのは、まさに私だったのです。」
【注】 Kale注（p. 73）：nirūpaka（醜い者）とsundaraka（美しい者）のペアは、容姿と財力の対比を際立たせる命名。結局カーママンジャリーは富裕なヴァスパーリタの方を流し目で選び、彼の全財産を巻き上げた後に追い出す。vairūpajīvinaḥ pauradhūrtāḥ（不和をあおって生きる都市の悪党たち）は、古代インドの都市社会における寄生的存在を反映する。
◆ 7. 賭博場と窃盗への参入
◆ 7. 賭博と盗賊の道
śrutvā caitadanukampamāno 'bravam—"bhadra, kṣamasva / kañcitkālamatraiva nivasa / nijena dyumnenāsāveva veśyā yathā tvāṃ yojayiṣyati tathā yatiṣye / santyupāyāstādṛśāḥ' ityāśvāsya tamanutthito 'ham /
nagaramāviśanneva copalabhya lokavādāllubdhasamṛddhapūrṇaṃ puramityarthānāṃ naśvaratvaṃ ca pradarśya prakṛtisthānamūnvidhāsyankarmīsutaprahite tathi matimakaravam /
anupraviśya ca dyūtasabhāmakṣadhūrtaiḥ samagaṃsi / teṣāṃ ca pañcaviṃśatiprakārāsu sarvāsu dyūtāśrayāsu kalāsu kauśalam… ahasaṃ ca kiñcitpramādadattaśāre kvacitkitave /
これを聞いて同情した私は言いました。「友よ、辛抱してください。しばらくここに留まりなさい。あの遊女自身が、己の才覚であなたの財産を返すよう仕向けてみせましょう。そのような策はあるのです。」と彼を慰めて立ち上がりました。
都に入るや、人々の噂から、この都は貪欲な富豪に満ちていることを知り、財の無常を彼らに思い知らせて本来の姿に戻すべく、カルニースタ（伝説的盗賊術の祖）の道に従う決意をしました。
賭博場に入り、賽子の達人たちと合流しました。彼らの二十五種に及ぶ賭博技芸の熟練ぶり、賽子盤や手先における見破りがたい欺し技、賭けの種類の説明、分配金の気前よさ、合間の卑猥な掛け声――これら一切を体験しても私は満たされませんでした。そしてある賭博師が手を誤った時に、つい笑ってしまいました。
【注】 Kale注（pp. 75-76）：karmīsuta-prahita（カルニースタの道）は盗賊術の伝統的教本に拠る道とされる。pañcaviṃśati-prakārāsu dyūtāśrayāsu kalāsu（賭博に関連する二十五種の技芸）は、『カーマスートラ』や『アルタシャーストラ』に列挙されるものと対応する。ダンディンはここで古代インドの賭博文化を詳細に描写しており、骰子の不正操作、場の取り仕切り役（sabhika）の制度、掛け金の分配法など、社会史的にも貴重な資料である。
◆ 8. 賭博での勝利と夜の強盗
◆ 8. 一万六千ディーナーラの勝利と夜盗
pratikitavastu nirdahanniva krodhatāmrayā dṛśā māmabhivīkṣya "śikṣayasi re dyūtavartma hāsavyājena…" iti dyūtādhyakṣānumatyā vyatyaṣajat / mayā jitaścāsau ṣoḍaśasahasrāṇi dīnārāṇām / tadardhaṃ sabhikāya sabhyebhyaśca dattvārdhaṃ svīkṛtyodatiṣṭham /
tanmukhena ca sārataḥ karmataḥ śīlataśca sakalameva nagaramavadhārya dūrjaṭikaṇṭhakalmāṣakālatame tamasi nīlanivasanārdhorukaparihito badadhatīkṣṇakaukṣeyakaḥ… gatvā kasyacillabdheśvarasya gṛhe saṃdhiṃ chittvā… nīvīṃ sāramahatīmādāya niragām /
相手の賭博師は怒りに目を赤くして私を睨み、「笑いを装って賭博の道を教えるつもりか…」と賭博監督の許可を得て私に勝負を挑みました。私は彼に勝ち、一万六千ディーナーラを得ました。その半分を監督と場の者たちに渡し、残りの半分を取って立ち上がりました。
ヴィマルダカ（場の主人）を通じて都の全容——財力、仕事ぶり、性格に至るまで——を把握した後、シヴァ神の喉のように漆黒の闇の中、紺の衣に半ズボン姿で、鋭い剣を帯び、蛇口型のくぎ抜き・人頭の偽首・魔法の粉・計測紐・梯子縄・灯籠・蜂の入った箱など数多の道具を携え、ある成り上がりの屋敷に忍び入り、壁に穴を開け、格子窓の小穴から中の様子を探り、恐れることなく自分の家のように入り込み、重い金袋を奪って脱出しました。
【注】 Kale注（p. 76）：dūrjaṭi-kaṇṭha-kalmāṣa-kālatame tamasi（シヴァ神の喉＝毒による青黒い斑のように暗い闇）は、ダンディンの好む比喩的修飾語の連鎖。盗賊の道具一覧（phaṇimukha-kākalī-saṃdaṃśaka「蛇口型のくぎ抜き」、puruṣa-śīrṣaka「偽の人頭」、yoga-cūrṇa「魔法の粉」、māna-sūtra「計測紐」、karkaṭaka-rajju「梯子縄」等）は、『アルタシャーストラ』第4巻の盗賊取り締まり章に列挙される道具と対応する。
◆ 9. 闇夜のクラパーリカー救出
◆ 9. 夜道の娘と毒蛇の芝居
nīlanīradanikarapīvaratamonibiḍitāyāṃ rājavīthyāṃ jhaṭiti śatahradāsaṃpātamiva kṣaṇamālokamalakṣayam / athāsau nagaradevateva nagaramoṣaroṣitā niḥsaṃbādhavelāyāṃ niḥsṛtā saṃnikṛṣṭā kācidunmiṣadbhūṣaṇā yuvatirāvirāsīt /
"kāsi vāsu, kvayāsi' iti sadayamuktā trāsagadgadamagādīt—"ārya, paryusyāmaryavaryaḥ kuberadattanāmā vasati / āsmyahaṃ tasya kanyā / māṃ jātamātrāṃ dhanamitranāmne 'tratyāyaiva kasmaicidibhyakumārāyānvajānādbhāryāṃ me pitā…"
紺碧の雲の群れのように濃い闇に閉ざされた王道で、一瞬、稲妻のように光が走りました。すると、この都の盗みに怒った都市の守護女神のように、静まり返った時刻に姿を現した、宝飾がきらめく若い娘が目の前に立っていました。
「お嬢さん、どなたですか、どちらへ？」と優しく声をかけると、恐怖に声を震わせて答えました。「旦那様、この近くにクベーラダッタという名の裕福な商人が住んでおります。私はその娘です。父は私を生まれたばかりの時にこの都のダナミトラという若者に嫁がせると約束しました。ところがその方は両親の死後、持ち前の寛大さゆえに施しを受ける者たちから貧困を買い取ったかのように無一文になり……（中略）……父は今やアルタパティという名にふさわしい富裕な隊商長に私を嫁がせようとしています。今宵その不吉な婚礼が明朝に迫ると知り、愛する人との約束に従い、家人の目を欺いて幼い頃から馴染んだ道でダナミトラの家に向かうところなのです。どうか私を行かせてください。この装身具をお取りください。」
◆ 10. 偽の蛇咬と夜警の欺き
◆ 10. 機転の策略——死んだふり
dayamānaścāhamabravam—"ehi sādhvi, tvāṃ nayeyaṃ tvatpriyāvasatham' iti tricaturāṇi padānyudacalam / āpatacca dīpikālokaparilupyamānatimirabhāraṃ yaṣṭikṛpāṇapāṇi nāgārikabalamanalpam /
dṛṣṭvaiva pravepamānāṃ kanyakāmavadam—"bhadre, mā bhaiṣīḥ / astyayamasidvitīyo me bāhuḥ / api tu mṛdurayamupāyastvadapekṣayā cintitaḥ / śaye 'haṃ bhāvitaviṣavegavikriyaḥ / tvayāpyamī vācyāḥ…"
同情して私は言いました。「おいでなさい、淑女よ。あなたの愛する人の住まいに連れて行ってあげましょう。」三、四歩進んだところで、松明の光が闇を払い、棒と剣を手にした少なからぬ夜警の群れが迫ってきました。
震えている娘を見て私は言いました。「お嬢さん、恐れることはありません。この剣を持つ腕がある。しかしあなたのために穏やかな策を思いつきました。私は毒に侵されたふりをして横たわります。あなたはこの者たちにこう言うのです——『夜中にこの都に入ったところ、この私の連れがあの公共の建物の隅で毒蛇に噛まれました。もし誰か呪法を知る慈悲深い方がいらっしゃれば、この哀れな女を助けるため、この者を蘇らせてください。』」
sāpi bālā gatyantarābhāvādbhayagadgadasvarā… kathaṅkathamapi gatvā maduktamanvatiṣṭhan, aśayiti cādaṃ bhāvitaviṣavikriyaḥ teṣu kaścannirendrābhimānī māṃ nirṇyaṃ mudrātantatramantradhyānādibhiścopakramyākṛtārthaḥ "gata evāyaṃ kāladaṣṭaḥ…" iti sahetaraiḥ prāyāt /
あの娘も他に手段がなく、恐怖で声を震わせながら、どうにか彼らのもとに行って私の言った通りにしました。私も毒に侵されたかのように横たわりました。彼らの中の一人が自称毒薬師で、私を調べ、呪符・真言・瞑想などで治療を試みましたが効果なく、「この者は死に神に噛まれたのだ。体は硬直して青黒く、視線は据わり、息は完全に止まっている。嘆くのはもう十分だ。明朝火葬にしよう。誰が運命に逆らえようか。」と言って仲間と去って行きました。
【注】 Kale注（pp. 78-79）：蛇咬を装い夜警を欺く一幕は、ダンディンの得意とするピカレスク的場面。nirendrābhimānin（自称毒薬師）が呪符（mudrā）・真言（mantra）・瞑想（dhyāna）で治療を試みるが失敗するという描写は、古代インドの民間医療の実態を風刺的に映し出している。

◆ 11. 義賊への感嘆と象での逃走劇

udārakastu tadādāya salajjaṃ ca saharṣaṃ ca sasaṃbhramaṃ ca māmabhāṣata—"ārya, tvayeveyamasyāṃ niśi priyā me dattā / vākpunarmamāpahṛtā…"
起き上がった私はウダーラカ（ダナミトラ）のもとへ彼女を連れて行き、言いました。「私はただの盗賊です。あなたに心を寄せる助けとなる彼女が、一人で夜道をあなたの元に向かっているのを偶然見つけ、哀れに思って連れて参りました。彼女の装身具もここにあります。」と、光の帯で闇の網を裂くようなその宝飾品をも渡しました。

◆ 12. 二軒同時の大強盗と象の暴走
avicārānumatena tena sadya evaināṃ tadgṛhamupanīya tayaivāpasarpabhūtayā tatra mṛdbhāṇḍāvaśeṣamacorayāva / tato niṣpatya kvacinmuṣitakaṃ nidhāya samuccalantau nāgarikasaṃpāte mārgapārśvaśāyinaṃ kañcinmattavārayaṇamuparipuruṣamākṛṣyādhyārohāva /
graiveyaprotapādayugalena ca mayotthāpyamāna eva pātitādhoraṇapṛthuloraḥsthalapariṇataḥ purītallatāparīdantakāṇḍaḥ sa rakṣikabalamakṣiṇot / adhvaṃsayāva cāmunaivārthapatibhavanam /
考えなしに同意したダナミトラと共に、すぐさまクラパーリカーを彼の家に送り届け、彼女自身を案内役にして、その家を土器以外すべて盗み尽くしました。そこから抜け出し、盗品をどこかに隠して走り出した折、夜警の一隊に出くわしました。道端に横たわっていた酔った軍象の象使いを引きずり下ろして二人で飛び乗りました。

◆ 13. 魔法の革袋の策略
◆ 13. ダナミトラと魔法の革袋
upahvare punarityaśikṣayaṃ dhanamitram—"upatiṣṭha sakhe, ekānta eva carmaratnabhastrikāmimāṃ puraskṛtyāṅgarājam / ācakṣva ca…" / rājā ca niyatamevaṃ vakṣyati—"bhadra, prīto 'smi / gaccha / yatheṣṭamimāmupabhuṅkṣva' iti /
内密にダナミトラにこう指示しました。「友よ、この革袋の宝を携え、密かにアンガの王に謁見せよ。そしてこう言え——『陛下もご存知のように、私ダナミトラは数億の財を持つヴァスミトラの一人息子です。施しの者たちに全父祖の財を失い、蔑まれておりました。クベーラダッタが私のために育ててきたクラパーリカーを、私の貧困のせいでアルタパティに嫁がせようとした時、絶望して都の近くの老樹林に入り、喉に刃を当てたところ、ある苦行者に止められました。その苦行者はこう言いました——「若者よ、汝は愚かだ。自殺より大きな罪はない。善き者は自らを滅ぼさず、己の力で身を起こすものだ。……私は呪力を完成した者だ。この革の袋は一ラクシャ（十万枚）の金貨を生む力がある。……商人か遊女の手でしか乳を出さぬという評判がある。毎朝清浄な場所に神像のように安置して礼拝すれば、朝ごとに黄金で満たされていよう。」こうして私に授けてくださり、自ら洞窟に入られました。この革袋は宝物ですから、陛下にお知らせせずに用いるわけにはまいりません。』……王は必ず『よし、好きに使え』と仰るだろう。さらに『誰にも盗まれぬようご加護を』と言えば、それも承知するだろう。その後、家に帰って言った通り財を手放し、毎晩盗みで得た金を袋に詰め、朝になったら人々に見せるのだ。するとクベーラダッタは金に目がくらみ、アルタパティを藁同然と見なし、自分からクラパーリカーを連れてお前に嫁がせようとするだろう。」
【注】 Kale注（pp. 82-83）：carmaratna-bhastrikā（革の宝袋）をめぐる精巧な詐欺計画は、本章の中核的プロットである。王を巻き込んで革袋の正統性を保証させ、夜の盗みで得た金を朝に「魔法の産物」として見せるという二重構造は、アルタシャーストラ的知略の文学的応用と言える。ダンディンは策略の一手一手を論理的に組み立て、読者を知的興奮へと導く。

◆ 14. 遊女ラーガマンジャリーへの恋
eṣveva divaseṣu kāmamañjaryāḥ svasā yavīyasī rāgamañjarī nāma pañcavīragoṣṭhe saṃgītakamanuṣṭhāsyatīti sāndrādaraḥ samāgamananāgarajanaḥ / sa cāhaṃ saha sakhyādhanamitreṇa tatra saṃnyadhiṣi /
pravṛttanṛtyāyāṃ ca tasyāṃ dvitīyaṃ raṅgapīṭhaṃ mamābhūnmanaḥ / taddṛṣṭivibhramotpalavanasaccāpāśrayaśca pañcaśaro bhāvarasānāṃ sāmagryātsamuditabala iva māmatimātramavyathayat /
ちょうどその頃、カーママンジャリーの妹のラーガマンジャリーが五勇士の集会場で演奏会を開くということで、都人たちが熱心に集まりました。私も友のダナミトラと共にそこに出向きました。
彼女が踊り始めると、私の心はいわば第二の舞台と化しました。彼女の妖艶な眼差しの蓮池を真の弓として拠り所とするカーマ神は、感情と情趣の総力を結集して力を得たかのように、私を極度に苦しめたのです。
【注】 Kale注（pp. 84-85）：pañcavīragoṣṭha（五勇士の集会場）は公共の演芸場。dvitīyaṃ raṅgapīṭham mamābhūn manaḥ（私の心は第二の舞台となった）という比喩は、舞踊を見る者の心が踊り手に完全に支配されることを表す。pañcaśara（五矢神＝カーマ）が彼女の流し目を弓として用いるという描写は、古典的な恋愛修辞の変奏である。ラーガマンジャリーは姉とは異なり、guṇaśulkā（才徳を花代とする者）であり、金銭ではなく品性によってのみ身を許すと宣言した異色の遊女である。

tataśca kāñcitkāmamañjaryāḥ pradhānadūtīṃ dharmarakṣitāṃ nāma śākyabhikṣukīṃ cīvarapiṇḍadānādinopasaṃgṛhya tanmukhena tayā bandhakyā paṇabandhamakaravam—"ajinaratnamudārakānmuṣitvā mayā tubhyaṃ deyam, yadi pratidānaṃ rāgamañjarī' iti /

yasyāṃ ca niśi carmaratnasteyavādastasyāḥ prārambhe kāryāntarāpadeśenāhūteṣu śṛṇvatsveva nāgaramukhyeṣu matpraṇidhirvimardakor'thapatigṛhyo nāmabhūtvā dhanamitramullaṅghya bahvartayat /

（一連の策略の結果）カーママンジャリーとその母は直ちに王に呼び出されました。……追い詰められた二人は、かの哀れなアルタパティこそ盗人だと証言しました。怒った王はアルタパティに死刑を宣告しようとしました。
prāñjalinā dhanamitreṇaiva pratyaṣidhyata—"ārya, mauryadatta eṣa varo vaṇijām ridṛśeṣvaparādheṣvasubhiraviyogaḥ / yadi kupito 'si hṛtasarvasvo nirvāsanīyaḥ pāpa eṣaḥ' iti / tanmūlā ca dhanamitrasya kīrtiraprathata /

ぼろ切れ一枚だけ残されたアルタパティは、財産に酔って道を誤った者として、全市民の目の前で追放されました。
【注】 Kale注（p. 83）：paṭaccharacchedaśeṣa（ぼろ切れだけ残された）は、完全な没落を表す諧謔的表現。mauryadatta eṣa varaḥ vaṇijām（マウリヤダッタ法によれば商人中の名士は……）の典拠は不明だが、『アルタシャーストラ』における商人階層への刑罰規定を想起させる。アパハーラヴァルマンの一連の策略は、全員の行動を予測し操作する「傀儡師型」の知略であり、ダンディンが理想とする「実利の達人」（arthaśāstrin）の文学的形象化である。

◆ 18. 獄中の取引と地下道の掘削
athottaredyurāgatya dṛptataraḥ subhagamānī sundaraṃmanyaḥ… kāntako nāma nāgārikaḥ kiñcidiva bhartsayitvā māṃ samabhyadhatta—"na ceddhanamitrasyājinaratnaṃ pratiprayacchasi… drakṣyasi pāramaṣṭādaśānāṃ kāraṇānāmante ca mṛtyumukham' iti

acintayaṃ ca—"hantumanasaivāmunā manmocanāya śapathaḥ kṛtaḥ / tadenaṃ hatvāpi nāsatyavādadoṣeṇa spṛśye' iti / niṣpatataśca me nigajanāya prasāryamāṇapāṇestasya pādenorasi nihatya patitasaya tasyaivāsidhenvā śiro nyakṛntam /

dṛṣṭvaiva sphuradanaṅgarāgaścakitaścorayitavayanispṛhastayaiva tāvacchoryamāṇahṛdayaḥ kiṅkartavyatāmūḍhaḥ kṣaṇamatiṣṭham /
（シュリガーリカーが教えてくれた）配置図に従って王女の宮殿深くに入り込みました。宝石の灯火が輝く中、遊び疲れて眠りこけた侍女たちの間に、獅子の姿の象牙の脚の寝台にハンサ鳥の羽毛を詰めた褥を載せ、花を散らした縁飾りのある寝台の上に……王女を見ました。
見た瞬間、恋の炎が燃え上がり、驚愕し、もはや何も盗む気が失せ、むしろ彼女に心を盗まれて、何をすべきかもわからぬまましばし立ち尽くしました。
【注】 Kale注（pp. 88-90）：王女アンバーリカーの眠りの描写は本作で最も有名な一節の一つ。haṃsatūlagarbhaśayyā（ハンサ鳥の羽毛を詰めた寝台）は王族の贅沢を示す定型表現。ダンディンはここで、頭から爪先まで王女の体の各部を下降的に描写する伝統的なnakhaśikhāvarṇana（爪先から頭までの身体描写）を逆転させ、足先から始めて顔に至る上昇的描写を用い、読者（および盗賊）の視線を誘導する。corayitavaya-nispṛhaḥ tayaiva tāvac-choryamāṇa-hṛdayaḥ（もはや何も盗む気がなく、むしろ彼女に心を盗まれている）という表現は、「盗賊が盗まれる」という逆説的比喩であり、ダンディンの機知の精華。
◆ 20. 王女への絵と詩
◆ 20. 寝台の傍の告白画
nāgadantalagnaniryāsakalkavarṇitaṃ phalakamādāya maṇisamudgakādvarṇavartikāmuddhṛtya tāṃ tathāśayānāṃ tasyāśca māmāvaddhañjāliṃ caraṇalagnamālikham /
āryāṃ caitām — "tvāmayamābaddhāñjali dāsajanastamimamarthamarthayate / svapihi mayā saha suratavyatikarakhinneva mā maivam' //
象牙に付着した樹液の練り物で描かれた画板を取り上げ、宝石の小箱から絵筆を取り出して、このように眠る彼女と、合掌して足元にひれ伏す自分の姿を描きました。
そしてこのアーリヤー詩を添えました。「合掌して控えるこの下僕は、あなた様にただ一つお願い申し上げます――どうか私と共にお眠りください、あたかも情事の疲れで眠り込んだかのように。」
【注】 Kale注（pp. 89-90）：本章における唯一のアーリヤー韻律の詩句。盗賊が宝石箱から絵具を取り出し、眠る王女と自分を描くという場面は、ダンディンが散文叙事詩中に稀に挿入する韻文の効果を巧みに利用している。この詩は機知に富み、表面上は「共に眠れ」と懇願しているが、「情事の後のように」という比喩が、まだ起こっていない恋を既成事実のように示唆する。
◆ 21. 指輪の交換と脱出
◆ 21. 嚙檳榔の交換と地下道での脱出
hemakaraṇḍakāccavāsatāmbūlavīṭikāṃ kapūrasphuṭikāṃ pārijātakaṃ copayujyālaktakapāṭalena tadrasena sudhābhitau cakravākamithunaṃ niraṣṭhīvam / aṅgulīyakavinimayaṃ ca kṛtvā kathaṅkathamapi niragām /
suraṅgayā ca pratyetya bandhāgāraṃ tatra baddhasya nāgarikavarasya siṃhaghoṣanāmnasteṣveva dineṣu mitratvenopacaritasya "evaṃ mayā hatastapasvī kāntakaḥ, tattvayā pratibhidya rahasyaṃ labdhavyo mokṣaḥ' ityupadiśya saha śṛgālikayā nirakrāmiṣam /
金の手箱から檳榔の噛みものと樟脳の粒とパーリジャータカの花を取って味わい、赤い口紅の色をした液で、白い壁に鴛鴦（チャクラヴァーカ）のつがいを吐き出すように描きました。指輪を交換し、どうにかして脱出しました。
地下道を通って牢獄に戻り、同じ日々の間に友として世話をしていた獄中の貴公子シンハゴーシャに「このようにして私はあの哀れなカーンタカを殺した。お前は秘密を暴露することで自由を得るがよい」と教え、シュリガーリカーと共に脱出しました。

◆ 22. 夜警からの脱出——老女の機転
nṛpatipathe ca samāgatya rakṣikapuruṣairagṛhye / acintayaṃ ca—"alamasmi javenāpasartumanāmṛṣṭa evaibhiḥ / eṣā punarvarākī gṛhyeta / tadidamatra prāptarūpam' iti tāneva capalamabhipatya svapṛṣṭhasamarpitakūrparaḥ parāṅmukhaḥ sthitvā "bhadrāḥ, yadyahamasmi taskaraḥ badhnīta mām / yuṣmākamayamadhikāraḥ, na punarasyā varṣiyasyāḥ' ityavādiṣam /
sā tu tāvataivonnītamadabhiprāyā… "bhadramukhāḥ, mamaiṣa putro vāyugrastaś ciraṃ cikitsitaḥ…" / ahamapi "sthavire, kena devo mātariśvā baddhapūrvaḥ…" ityabhyadhāvam /
王の大道に出たところで夜警に捕まりました。私は考えました。「速さで逃げることはできるが、この者たちに触れずにおけば、代わりにこの哀れな老女が捕まるだろう。ここはこうするのが適切だ。」そこで彼らに素早く突進し、背中を見せて肘を当て、こう言いました。「諸君、私が盗賊なら縛るがよい。それが諸君の職務だ。だがこの老婦人には関わるな。」
するとシュリガーリカーは即座に私の意図を察し、「皆さま、この者は私の息子で、長い間風邪の神（ヴァーユ）に取り憑かれて治療を受けていたのです……」と涙ながらに訴えました。私も「婆さん、誰が風の神を縛れたことがあるか！ こいつらが俺を捕まえられるとでも？ 静かにしろ！」と叫んで走り出しました。
【注】 Kale注：vāyugrasta（風の神に取り憑かれた）は「狂人」の意。シュリガーリカーの機転により、盗賊と老女が母と狂った息子を演じるという即興劇が展開される。mātariśvā（風の神ヴァーユの異名）は、vāyugrasta（風邪＝狂気に取り憑かれた）との掛詞になっている。このような即興の芝居は、『アルタシャーストラ』に記される盗賊の逃亡術の文学的変奏である。
◆ 23. マリーチ仙の予言とアンバーリカーとの逢瀬
◆ 23. 天眼回復と王女との密会
atha bhagavantaṃ marīciṃ veśakṛcchudutthāya punaḥ pratitaptatapaḥprabhāvapratyāpannādivyacakṣuṣamupasaṃgamya tenāsmyevaṃbhūtatvaddarśanamavagamitaḥ /
siṃhaghoṣaśca kāntakāpacāraṃ nirbhidya tatapade prasannena rājñā pratiṣṭhāpitaḥ tenaiva cārakasuraṅgāpathena kanyāpurapraveśaṃ bhūyo 'pi me samapādayat / samagaṃsi cāhaṃ śṛgālikāmukhaniḥsṛtavārtānuraktayā rājaduhitrā /
それから尊きマリーチ仙を訪ねました。遊女の災いから立ち直り、再び苦行の力で天眼を取り戻した仙人のもとに赴き、こうした経緯であなた様のありかを知らされたのです。
シンハゴーシャはカーンタカの悪行を暴露し、好意を示した王に復権させられ、あの密偵の地下道を使って、再び私の王女の宮殿への潜入を手配してくれました。そしてシュリガーリカーの口から伝わった噂によって心惹かれていた王女と、ついに結ばれたのです。
◆ 24. チャンダヴァルマンの攻城とアパハーラヴァルマンの武勇
◆ 24. チャンパーの危機と英雄的救出
taṣveve divaseṣu caṇḍavarmā siṃhavarmāvadhūtaduhitṛprārthanaḥ kupito 'bhiyujya puramavāruṇat / amarṣaṇaścāṅgarājo yāvadariḥ pāragrāmikaṃ vidhimācikīrṣati tāvatsvayameva prākāraṃ nirbhidya pratyāsannānapi sahāyānapratīkṣamāṇo nirgatyābhyadhikabalena vidviṣā mahati saṃparāye bhinnavarmā siṃhavarmā balādagṛhyata /
ambālikā ca balavadabhigṛhya caṇḍavarmaṇā haṭhātpariṇetumātmabhavanamanīyat /
ちょうどその頃、チャンダヴァルマンがシンハヴァルマンの娘との婚姻要求を拒絶されて怒り、攻め寄せて都を包囲しました。気性の激しいアンガの王は、敵が遠方での決戦を望んでいるうちに、自ら城壁を破って出撃し、近くまで来ていた援軍をも待たずに戦いました。大戦の末、鎧を打ち砕かれたシンハヴァルマンは、超人的な戦闘力を持つ敵に力ずくで捕えられました。
アンバーリカーも力ずくで捕えられ、チャンダヴァルマンは強引に自分の館に連れ去り、婚礼の準備を進めました。
ahaṃ ca dhanamitragṛhe tadvivāhāyaiva pinaddhamaṅgalapratisarastamevamavocam—"sakhe, samāpatitamevāṅgarājābhisaraṃ rājamaṇḍalam / sugūḍhameva saṃbhūya pauravṛddhaistadupāvartaya / upāvṛttaśca kṛttaśirasameva śutruṃ drakṣyasi' iti /
私はダナミトラの家で、まさにその婚礼のために吉祥の紐を腕に巻いたまま、彼にこう言いました。「友よ、アンガの王を救うべく諸王の同盟軍がすでに到着しつつある。密かに都の長老たちと合流し、敵の注意をそらせ。戻ってくれば、敵は首を刎ねられているのを目にするだろう。」
"tathā' iti tenābhyupagate gatāyuṣo 'muṣya bhavanamutsavākulamupasamādhīyamānapariṇayopakaraṇamistataḥ praveśanirgamapravṛttalokasaṃbādhamalakṣyaśastrikaḥ saha praviśya maṅgalapāṭhakairambalikāpāṇipallavamagnau sākṣiṇyātharvaṇena vidhinārpyamāṇamāditsamānasyāyāminaṃ bāhuduṇḍamākṛṣya cchurikayorasi prāharṣam / sphurataśca katipayānanyānapi yamaviṣayamagamayam /
「承知した」と彼が引き受けると、命運尽きたチャンダヴァルマンの館に、祝祭の準備に沸き立ち人の出入りで混雑する中、武器を隠して紛れ込みました。祝福の僧侶たちがアンバーリカーの花のような手を火の神を証人としてアタルヴァ・ヴェーダの儀式に従って（チャンダヴァルマンの手に）差し出そうとしていたまさにその瞬間、長く伸ばされた腕を引き寄せ、小刀で胸を刺しました。動き出す残りの者たちも数人、冥界に送りました。
◆ 25. ラージャヴァーハナとの再会
◆ 25. 物語の結び——主君との再会
hatavidhvastadaṃ ca tadgṛhaman vicaranvepamānamadhuragātrīṃ viśālalocanāmabhiniśāmya tadāliṅganasukhamanububhūṣustāmādāya garbhagṛhamavikṣam /
asminneva kṣaṇe tavāsmi navāmbuvāhastanitagambhīreṇa svareṇānugṛhītaḥ' iti /
殺され打ち壊された館を歩き回り、震える肢体の美しい大きな瞳の女を見つけ、抱擁の喜びを味わおうと彼女を抱き上げて奥の間に入りました。
「まさにその瞬間、新しい雨雲の雷鳴のように深いあなた様のお声に恵まれたのです。」
śrutvā ca smitvā ca devo 'pi rajavāhanaḥ "kathamasi kārkasyena karṇīsutamapyatikrāntaḥ' ityabhidhāya punaravekṣyopahāravarmāṇam ācakṣva, tavedānīmavasaraḥ' ityabhāṣata /
so 'pi sasmitaṃ praṇasyārabhatābhidhātum // Dkc_2,2 //
iti śrīdaṇḍinaḥ kṛtau daśakumāracarite 'pahāravarmacaritaṃ nāma dvitīya ucchvāsaḥ
これを聞いて微笑んだラージャヴァーハナ王子は「何と、大胆さにおいてカルニースタ（伝説の盗賊の祖）をも凌いだとは」と述べ、次にウパハーラヴァルマンに目を向けて、「さあ語れ、次はそなたの番だ」と言いました。
ウパハーラヴァルマンもまた微笑んで平伏し、語り始めました。// Dkc_2,2 //

【注】 Kale注：katham asi kārkasyena karṇīsutam api atikrāntaḥ（大胆さにおいてカルニースタをも凌いだ）——karṇīsuta は盗賊術の伝説的開祖で、『アルタシャーストラ』にも言及される。ラージャヴァーハナがこの名を引くのは、アパハーラヴァルマンの冒険が単なる盗みを超えた知略と勇気の物語であることへの賛辞。本章はダシャクマーラチャリタ全体の中で最も長く、最もピカレスクな章であり、遊女の社会学・賭博の技芸・盗賊術・地下道の掘削・婚礼場での暗殺など、古代インドの裏社会を百科全書的に描き出す。
