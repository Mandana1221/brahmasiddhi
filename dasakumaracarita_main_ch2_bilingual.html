1主君を求めてチャンパーへ

“deva, tvayi tadāvatīrṇe dvijopakārāyāsura-vivaraṃ tvad-anveṣaṇa-prasṛte ca mitra-gaṇe 'ham api mahīm aṭann aṅgeṣu gaṅgā-taṭe bahiś campāyāḥ “kaścid asti tapaḥ-prabhāvotpanna-divya-cakṣur marīcir nāma maharṣiḥ” iti / kutaścit saṃlapato jana-samājād upalabhyāmuto bubhutsus tvad-gatiṃ tam uddeśam agamam /
1.1「陛下よ、あなたがバラモンを助けるため魔洞に降りられ、友の群れがあなたを探して散っていった時、私もまた大地を彷徨い歩きました。アンガ国のガンジス河岸、チャンパーの城外にて、ある人々の語らいの中に『苦行の力で天眼を得たマリーチという大聖者がいる』と聞き及び、あなたの消息を知りたく、その場所へ赴きました。」
nyaśāmayaṃ ca tasminn āśrame kasyacic cūta-potakasya chāyāyāṃ kam apyudvigna-varṇaṃ tāpasam / amunā cātithi-vad upacaritaḥ kṣaṇaṃ viśrāntaḥ “kvāsau bhagavān marīciḥ, tasmād aham upalipsuḥ prasaṅga-proṣitasya suhṛdo gatim āścarya-jñāna-vibhavo hi sa maharṣir mahyāṃ viśrutaḥ” ityavādiṣam /
1.2「その庵にて、若いマンゴーの木の陰に、何か心を悩ませている様子の苦行者を見かけました。その者に客のように迎えられ、しばし休息した後、私はこう尋ねました――『あの尊きマリーチ仙はどこにおられるか。訳あって離れ離れになった友の行方をあの方からお聞きしたい。不思議な知恵の力を持つ大聖者と聞いております。』」
注旧版の第2章は本文の約3分の1（16箇所、計約11,000字）を欠いていた。本書ではGRETIL・DCSに基づいて欠落部分を補い、新たに訳出した（ヴァスパーリタの出家と還俗、賭博の後の酒宴、ダナミトラとの相談、夜明けの帰宅、革袋の老行者の退場、ラーガマンジャリーの誓い、アルタパティの失脚とカーママンジャリーの破産、獄中の策略、シュリガーリカーの謀略など）。

2マリーチ仙の身の上話

athāsāvuṣṇam āyataṃ ca niḥśvasyāśaṃsata “āsīttādṛśo munir asminn āśrame / tam ekadā kāmamañjarī nāmāṅga-purī-vataṃsa-sthānīyā vārayuvatir aśru-bindu-tārakita-payodharā sanirvedam abhyetya kīrṇa-śikhaṇḍāstīrṇa-bhūmir abhyavandiṣṭa /
2.1すると彼は熱く長い溜息をついて語り始めました。「かつてこの庵にそのような聖者がいた。ある時カーママンジャリーという名の、アンガの都の冠というべき若い遊女が、涙の雫に胸を飾り、嫌悪の情を帯びてやって来て、乱れた髪を地に敷いて聖者にひれ伏した。」
tasminn eva ca kṣaṇe mātṛ-pramukhas tad-āpta-vargaḥ sānukrośam anupradhāvitas tatraivāvicchinnapātam apatat /
2.2「まさにその瞬間、母を先頭にした彼女の縁者たちが、哀れみの声を上げながら追いかけてきて、そこにどさりと倒れ伏した。」
注Kale注：カーママンジャリーは遊女（gaṇikā）の名で、チャンパーの都随一の美女とされる。「乱れた髪を地に敷いて」（kīrṇaśikhaṇḍāstīrṇabhūmir）は、嘆き悲しむ女の典型的な所作描写。この遊女が仙人を篭絡する挿話は、ダンディンの得意とする叙事的入れ子構造の一例である。

3ガニカーの掟——母の長大な弁明

sa kila kṛpālus taṃ janam ārdrayā girāśvāsyārti-kāraṇaṃ tāṃ gaṇikām apṛcchat / sā tu savrīḍeva saviṣādeva sagauraveva cābravīt / “bhagavan! aihikasya sukhasyābhājanaṃ jano 'yam āmuṣmikāya śvovasīyāyārtābhyupapatti-vittayor bhagavat-pādayor mūlaṃ śaraṇam abhiprapannaḥ” iti /
3.1慈悲深い聖者は優しい言葉で一同を慰め、遊女にその苦悩の理由を尋ねた。彼女は恥じらいと悲しみと敬意を込めて答えた。「尊者よ、この世の快楽に縁のないこの者は、来世の幸いを求め、あなたの御足のもとに身を寄せて参りました。」
tasyās tu jananyudañjaliḥ palita-śāra-śikhaṇḍa-bandha-spṛṣṭa-mukta-bhūmir abhāṣata — “bhagavan, asyā me doṣam eṣā vo dāsī vijñāpayati / doṣaś ca mama svādhikārānuṣṭhāpanam / eṣa hi gaṇikā-mātur yaśaḥ-prakhyāpanam, kārtāntikādibhiḥ kalyāṇa-lakṣaṇodghoṣaṇam, pīṭhamarda-viṭa-vidūṣakair bhikṣukyādibhiś ca nāgarika-puruṣa-samavāyeṣu rūpa-śīla-śilpa-saundarya-mādhurya-prastāvanā, svatantrāya pradānam, adhika-guṇāyāsvatantrāya prājñatamāyālpenāpi bahu-vyapadeśenārpaṇam, asvatantreṇa vā gandharva-samāgamena tad-gurubhyaḥ śulkāpaharaṇam, alābhe 'rthasya kāma-svīkṛte svāminyadhikaraṇe ca sādhanam, raktasya duhitraikacāriṇī-vratānuṣṭhāpanam, nitya-naimittika-prīti-dāyakatayā hṛtaśiṣṭānāṃ gamya-dhanānāṃ citrair upāyair apaharaṇam, adadatā lubdha-prāyeṇa ca vigṛhyāsanam pratihasti-protsāhanena lubdhasya rāgiṇas tyāga-śakti-saṃdhukṣaṇam, asārasya vāk-saṃtakṣaṇair lokopakrośanair duhitṛ-nirodhanair vrīḍotpādanair anyābhiyogair avamānaiś cāpavāhanam, mātṛkāyā vā śāsanātivṛttiḥ / evaṃ sthite 'nayā prajāpati-vihitaṃ svadharmam ullaṅghya kvacid āgantukaṃ rūpa-mātra-dhane vipra-yūni svenaiva dhana-vyayena ramamāṇayā māsa-mātram atyavāhi / gamya-janaś 3.2すると母親が合掌し、白髪交じりの結い髪を地に触れさせて平伏し、こう述べた。「尊者よ、この私の娘の過ちを、あなたの下婢がお伝えいたします。その過ちとは、私が自分の職分を（娘に）守らせようとしたことにございます。遊女の母の義務とは——娘の生まれた時から容姿を磨くこと、体力・光沢・容色・知力を増す適切な食事で身体を養うこと、五歳まで父にさえあまり見せぬこと、誕生日と吉日には盛大な祝祭を行うこと、愛の学問をあらゆる分野にわたって教えること、舞踊・歌唱・楽器・演劇・絵画・料理・調香・花飾りの技を仕込むこと、読み書きと巧みな話術を修めさせること、文法・論理・占星術の概要を教えること、生計の知識・遊戯の巧みさ・生きた駒と生命なき駒の賭博技芸に精通させること、内密の技芸は信頼できる者から実地で習得させること、祭礼や行列の際には念入りに飾り立て豪華な装いで人目に曝すこと、音楽などを好む機会にはあらかじめ用意した魅惑的な言葉で求婚者を引き留めること、各方面の技芸通をして名声を広めること、占星術師らに吉兆の相を宣伝させること、幇間・道化・太鼓持ち・尼僧らを使い都市紳士の集まりで容姿・品性・技芸・美しさ・優雅さを紹介させること、若者たちの憧れの的となった暁には最高額の花代を設定すること、自ら情欲に盲いた者あるいは彼女を見て恋狂いした者のうち、生まれ・容姿・財力・清浄・気前のよさ・器用さ・品性・優雅さを備えた自立の男に与えること、より優れた資質を持つが自立でない者には最も聡明な者を選び少額でも多くの口実を設けて委ねること、あるいは自立でない者とガーンダルヴァ式の結びつきにより相手の後見人から花代を取り立てること、自ら受け入れた客が支払わぬ場合は裁判所に訴えて財を回収すること、惚れた客には娘の貞節の誓いを守らせること、日常的・臨時的に快楽を与えて搾り取った客の残りの財を巧みな手段で奪い取ること、ほとんど吝嗇で与えぬ客とは喧嘩をし、対抗馬を煽って吝嗇な恋する客の気前を刺激すること、甲斐なき者は辛辣な言葉・世間の非難・娘の幽閉・恥辱の惹起・他の訴え・侮辱により追い払うこと、財を与え害を防ぐ非難なき客との間で利害得失を見極めて何度でも結び直すことである。遊女が客に対するは用意のみにて執着にあらず。たとえ愛情が生じても母や祖母の教えを破ってはならぬ。しかるにこの娘は、プラジャーパティが定めた己の法を踏み越え、どこからか来た容姿だけの無一文の旅人と自分の金を使って一月も遊び暮らしました。多くの財力ある適格な客がこの娘の拒絶に怒りました。一家の生計は破綻し、『これは愚行であって吉事にあらず』と制する私に腹を立て、森の生活に出発したのです。もしこの娘の決意が覆らぬならば、ここにいるこの者たちは皆、他に行き場もなく絶食して死ぬでしょう。」と泣き崩れた。
注Kale注（pp. 66-68）：この遊女の母の演説は、ヴァーツヤーヤナの『カーマスートラ』第6篇「ヴェーシヤーディカーラナ」の遊女規範をほぼそのまま散文に移し替えたものである。gaṇikāmātur adhikāra（遊女の母の職分）として、娘の教育・売り込み・客の選別・富裕な客の確保・無資力の客の追い払い方など、極めて詳細かつ体系的に列挙される。ダンディンはこの長大な列挙によって、遊女の世界の精緻な掟を読者に示すとともに、後に続くカーママンジャリーの策略の伏線を張っている。

4聖者の諭し——森の生活と本分への帰還

atha sā vārayuvatis tena tāpasena “bhadre! nanu duḥkhākaro 'yaṃ vana-vāsaḥ / tasya phalam apavargaḥ svargo vā / prathamas tu tayoḥ prakṛṣṭa-jñāna-sādhyaḥ prāyo duḥsaṃpāda eva, dvitīyas tu sarvasyaiva sulabhaḥ kula-dharmānuṣṭhāyinaḥ / tad-aśakyārambhād uparamya mātur mate vartasva” iti sānukampam abhihitā yad iha bhagavat-pāda-mūlam aśaraṇam, śaraṇam astu mama kṛpaṇāyā hiraṇyaretā deva eva ity udamanāyata /
4.1すると遊女はその苦行者に慈悲をもってこう諭された。「お嬢さんよ、この森の生活は苦しいではないか。その果報は解脱か天界かのいずれか。前者は深遠な知識によってのみ達成されるもので、おおよそ到達し難い。後者は家の法（クラダルマ）に従って務める者にはすべてたやすく得られる。ゆえに不可能な企てはやめて、母の意に従いなさい。」しかし彼女はこう叫んだ。「もしここ、尊者の御足元が頼りにならぬのならば、黄金の精を持つ神（火神アグニ）こそ、この哀れな私の拠り所でございます」と——すなわち火に身を投じるとほのめかしたのである。
注Kale注（pp. 68-69）：hiraṇyaretā deva（黄金の精を持つ神）は火神アグニの異名。カーママンジャリーは「御足元に庇護がなければ焼身自殺する」と暗示し、聖者の慈悲心を巧みに利用している。この脅迫的嘆願は、古典文学における女性の嘆願の定型表現（ārtā-vacana）の一変形である。

5聖者の心を虜にする献身

sa tu munir anuvimṛśya gaṇikā-mātaram avadat — “saṃprati gaccha gṛhān / pratīkṣasva kāni cid dināni yāvad iyaṃ su-kumārā sukhopabhoga-samucitā satyaraṇya-vāsa-vyasanenodvejitā bhūyobhūyaś cāsmābhir vibodhyamānā prakṛtāveva sthāsyatīti /
5.1聖者は考えた末に遊女の母にこう告げた。「さあ家に帰りなさい。しばらくの間待っておれ。この華奢な娘は快楽の享受に慣れた身であるから、森の生活の辛さに嫌気がさし、私たちが繰り返し諭せば、やがて本来の姿に戻るであろう。」
“tathā” iti tasyāḥ pratiyāte sva-jane sā gaṇikā tam ṛṣim alaghu-bhaktir dhautodgamanīya-vāsinī nātyādṛta-śarīra-saṃskārā vana-taru-potālavāla-pūraṇair devatārcana-kusumoccayāvacaya-prayāsair naika-vikalpopahāra-karmabhiḥ kāma-śāsanārthe ca gandha-mālya-dhūpa-dīpa-nṛtya-gīta-vādyādibhiḥ kriyābhir ekānte ca trivarga-saṃbandhanībhiḥ kathābhir adhyātma-vādaiś cānurūpair alpīyasaiva kālenānvarañjayat /
5.2「承知しました」と母の一族が去ると、かの遊女は並々ならぬ信心をもって聖者に仕え、洗い清めた衣を纏い、身の飾りにはあまり気を配らず、森の木の根元に水をやり、神々を祀る花を摘み集めて供え、様々な種類の供物を捧げた。カーマを懲らしめた神（シヴァ）の礼拝のために香・花環・灯明を奉じて舞踊・歌・楽器の音を捧げ、二人きりの折には三つの人生目標（トリヴァルガ）に関わる物語やふさわしきアートマン（自己）の議論を交わして、ごく短い期間のうちに聖者の心を虜にした。
注Kale注（p. 69）：遊女が聖者に仕える一連の描写は、苦行者の庵にふさわしい振る舞い（alaghu-bhakti＝並々ならぬ信心、dhauta-vastra＝清浄な衣、nātyādṛta-śarīra-saṃskāra＝控えめな身の飾り）を装いながら、カーマを懲らしめたシヴァ（kāma-śāsana）への礼拝という名目で、香・花環・灯明・舞踊・歌・楽器（gandha-mālya-dhūpa-dīpa-nṛtya-gīta-vādya）を通じて聖者の感覚を徐々に目覚めさせるという二重構造を持つ。trivarga-saṃbandhinībhiḥ kathābhiḥ（トリヴァルガに関わる物語）は、次に続く哲学的論争の巧みな布石である。

6「ダルマは百倍勝る」——神々の情事を引いて

ekadā ca rahasi raktaṃ tam upalakṣya mūḍhaḥ khalu loko yat saha dharmeṇārtha-kāmāvapi gaṇayatīti kiñcid asmayata / “kathaya vāsu, kenāṃśenārtha-kāmātiśāyī dharmas tavābhipretaḥ” iti preritā marīcinā lajjā-mantharam ārabhatābhidhātum — “itaḥ kila janād bhagavatas trivarga-balābala-jñānam / athavaitad api prakārāntaraṃ dāsa-janānugrahasya / bhavatu, śrūyatām /
6.1ある日、ひそかに聖者が自分に惚れ込んでいるのを見て取ると、彼女はかすかに微笑んでこう言った。「ダルマと共にアルタとカーマをも数える世の人々はなんと愚かなことでしょう。」マリーチに「では言ってみよ、いかなる点でダルマがアルタとカーマに優ると考えるのか」と促されると、恥じらいながらゆっくりと語り始めた。「尊者のような方から、トリヴァルガの強弱の知識を、私のような卑しい者がいかに論じましょう。しかしこれもまた、主人が下僕を慈しむ別の形でございましょう。では、お聞きください。」
nanu dharmād ṛte 'rtha-kāmayor anutpattir eva / tad-anapekṣa eva dharmo nivṛtti-sukha-prasūti-hetur ātma-samādhāna-mātra-sādhyaś ca / so 'rtha-kāma-vad bāhya-sādhaneṣu nātyāyatate / tattva-darśanopabṛṃhitaś ca yathā kathañcid apy anuṣṭhīyamānābhyāṃ nārtha-kāmābhyāṃ bādhyate / bādhito 'pi cālpāyāsa-pratisamāhitas tam api doṣaṃ nirhṛtya śreyase 'nalpāya kalpate /
6.2「ダルマなくしてはアルタもカーマも生じることすらありません。ダルマはそれ自体で独立し、離欲の安楽を生み出す原因であり、内なる三昧のみで達成されます。アルタやカーマのように外的手段に依存しません。真理の洞察に支えられたダルマは、アルタやカーマをいかに行じても損なわれることがありません。たとえ損なわれても、わずかな努力で回復し、その過ちをも除いて大いなる至福に導きます。」
tathā hi pitāmahasya tilottamābhilāṣaḥ, bhavānī-pater muni-patnī-sahasra-saṃdūṣaṇam, padmanābhasya ṣoḍaśa-sahasrāntaḥpura-vihāraḥ, prajāpateḥ sva-duhitaryapi praṇaya-pravṛttiḥ, śacīpater ahalyā-jāratā, śaśāṅkasya guru-talpa-gamanam, aṃśumālino vaḍavā-laṅghanam, anilasya kesari-kalatra-samāgamaḥ, bṛhaspater utathya-bhāryābhisaraṇam, parāśarasya dāśa-kanyā-dūṣaṇam, pārāśaryasya bhrātṛ-dāra-saṃgatiḥ, atrer mṛgī-samāgama iti /
6.3「たとえばブラフマー神のティロッタマーへの欲望、パールヴァティーの主シヴァ神が千人の聖者の妻を誘惑したこと、蓮臍のヴィシュヌ神の一万六千人の後宮の楽しみ、プラジャーパティの実の娘への恋慕、インドラ神のアハリヤーとの密通、月神チャンドラの師の妻との不義、太陽神の牝馬ヴァダヴァーとの交わり、風神とケーサリンの妻（アンジャナー）との交わり、ブリハスパティのウタティヤの妻への求愛、パラーシャラの漁師の娘の汚し、ヴヤーサ（パラーシャラの子）の兄弟の妻との交わり、アトリ仙の牝鹿との交合——」
amarāṇāṃ ca teṣu teṣu kāryeṣvāsura-vipralambhanāni jñāna-balān na dharma-pīḍām āvahanti / dharma-pūte ca manasi nabhasīva na jātu rajo 'nuṣajyate / tan manye nārtha-kāmau dharmasya śatatamīm api kalāṃ spṛśataḥ” iti /
6.4「これらの神々の行為において、阿修羅を欺く数々の企みも、知恵の力によってダルマを損なうことはありません。ダルマに浄められた心には、大空に塵が付着せぬように、いかなる汚れも染みつきません。ゆえに私は、アルタもカーマもダルマの百分の一にすら及ばぬものと考えます。」
注Kale注（pp. 69-70）：この場面がマリーチ挿話の哲学的核心であり、トリヴァルガ（dharma・artha・kāma）の序列をめぐる巧みな論争である。カーママンジャリーは「真理を見る者のダルマは感覚の享楽に汚されない」と説き、聖者の自負心をくすぐって世俗的快楽への扉を開かせる。神々の情事の列挙（pitāmaha＝ブラフマーからatri＝アトリ仙まで12例）は叙事詩・プラーナ文献に遡る定型的な「神々の過失列挙」であり、古典文学ではカーマの力の証左として引かれる常套手段である。遊女が聖者を哲学的に誘惑するという逆説的な構成は、ダンディンの技巧の極みと評される。

7感覚の快楽を説く——聖者、誓戒を棄つ

śrutvaitad ṛṣir udīrṇa-rāga-vṛttir abhyadhāt — “ayi vilāsini, sādhu paśyasi na dharmas tattva-darśināṃ viṣayopabhogenoparudhyata iti / kintu janmanaḥ prabhṛtyartha-kāma-vārtānabhijñā vayam / jñeyau cemau kiṃrūpau kiṃparivārau kiṃphalau ca” iti /
7.1これを聞いた聖者は情欲を高ぶらせて言った。「おお艶やかな者よ、まことによく見ている。真理を見る者のダルマは感覚の享楽によって損なわれぬものだ。しかし我々は生まれてこのかた、アルタとカーマの事柄を知らぬ。この二つはいかなる姿をし、いかなる眷属を持ち、いかなる果報をもたらすのか。」
sā tvavādīd — “arthas tāvad arjana-vardhana-rakṣaṇātmakaḥ, kṛṣi-pāśupālya-vāṇijya-saṃdhi-vigrahādi-parivāraḥ tīrtha-pratipādana-phalaś ca / kāmas tu viṣayāti-saktacetasoḥ strī-puṃsayor niratiśaya-sukha-sparśa-viśeṣaḥ / parivāras tvasya yāvad iha ramyam ujjvalaṃ ca / phalaṃ punaḥ paramāhlādanam paraspara-vimarda-janma, smaryamāṇa-madhuram, udīritābhimānam anuttamam sukham aparokṣaṃ sva-saṃvedyam eva / tasyaiva kṛte viśiṣṭa-sthāna-vartinaḥ kaṣṭāni tapāṃsi, mahānti dānāni, dāruṇāni yuddhāni, bhīmāni samudra-laṅghanādīni ca narāḥ samācarantīti /
7.2彼女はこう答えた。「アルタとは獲得・増殖・保護を本質とし、農業・牧畜・商業・同盟・戦争などを眷属とし、ふさわしい相手への施しを果報とします。カーマとは、感覚に深く執着した男女の間の、比類なき快楽としての特別な触れ合いです。その眷属はこの世にある麗しく輝かしいもののすべて。その果報は至高の歓喜——互いの抱擁から生まれ、思い出しても甘美で、誇りを高めれば無上で、直接に自ら体験するほかないもの。このカーマのためにこそ、高き地位にある者たちは苛烈な苦行を、偉大な布施を、凄惨な戦を、恐るべき大洋の渡海などを行うのです。」
niśamyaitan niyati-balān nu tat-pāṭavān nu sva-buddhi-māndyān nu sva-niyamam anādṛtya tasyām asau prāsajat / sā su-dūraṃ mūḍhātmānaṃ ca taṃ pravahaṇena nītvā puram udāra-śobhayā rāja-vīthyā sva-bhavanam anaiṣīt /
7.3運命の力か、彼女の手練か、聖者自身の愚鈍さか——己の誓戒を顧みることなく、聖者は彼女に耽溺した。彼女ははるばる、すっかり迷妄に陥った聖者を車に乗せ、壮麗な王の大路を通って自分の邸宅に連れ帰った。
注Kale注（pp. 70-71）：カーマの定義 niratiśaya-sukha-sparśa-viśeṣaḥ（比類なき快楽としての特別な触れ合い）はヴァーツヤーヤナの定義を彷彿させる。「思い出しても甘美で」（smaryamāṇam madhuram）「自ら体験するほかない」（sva-saṃvedyam eva）というカーマの四つの属性は、享楽主義の哲学的正当化として機能する。prāsajat（耽溺した）の一語で聖者の堕落が簡潔に示される。pravahāṇena（車で）都に連れ帰る場面は、聖者が完全に俗界に引き戻されたことの象徴である。

8祝祭の場での賭けの決着

abhūc ca ghoṣaṇā “śvaḥ kāmotsavaḥ” iti / uttaredyuḥ snātānuliptam āracita-mañju-mālam ārabdha-kāmi-jana-vṛttaṃ nivṛtta-sva-vṛttābhilāṣaṃ kṣaṇa-mātre gate 'pi tayā vinā dūyamānaṃ tam ṛddhimatā rājamārgeṇotsava-samājaṃ nītvā kvacid upavanoddeśe yuvati-jana-śata-parivṛtasya rājñaḥ saṃnidhau smita-mukhena tena “bhadre, bhagavatā saha niṣīda” ityādiṣṭā savibhramaṃ kṛta-praṇāmā sasmitaṃ nyaṣīdat /
8.1やがて「明日はカーマ祭！」との触れが出た。翌日、沐浴させ塗香を施し美しい花環を飾り、恋する者の振る舞いを真似させ、もはや己の苦行の志をすっかり捨て、一瞬でも彼女と離れれば悶え苦しむ聖者を、華やかな王の大路を通って祭りの集会へ連れて行った。ある庭園の一角で、百人の美女に囲まれた王の御前にて、微笑む王に「お嬢さん、尊者と共にお座りなさい」と命じられると、彼女は優雅にお辞儀をして微笑みつつ腰を下ろした。
tatra kācid utthāya baddhāñjalir uttamāṅganā “deva, jitānayāham, asyai dāsyam adya prabhṛtyabhyupetaṃ mayā” iti prabhuṃ prāṇaṃsīt /
8.2そこである高位の女が立ち上がり合掌して王に申し上げた。「陛下、私はこの者に負けました。本日より彼女への奴隷の身を受け入れます。」
vismaya-harṣa-mūlaś ca kolāhalo lokasyodajihīta / hṛṣṭena ca rājñā mahārhai ratnālaṅkārair mahatā ca paribarheṇānugṛhya visṛṣṭā vāramukhyābhiḥ paura-mukhyaiś ca gaṇaśaḥ praśasyamānā sva-bhavanam agatvaiva tam ṛṣim abhāṣata — “bhagavan, ayam añjaliḥ, ciram anugṛhīto 'yaṃ dāsa-janaḥ, svārtha idānīm anuṣṭheyaḥ” iti /
8.3驚きと歓喜のどよめきが人々の間に沸き起こった。喜んだ王は高価な宝石の装身具と豪華な供の者を授けて彼女を送り出した。遊女の長や市民の長たちに口々に称賛されながら、彼女は自邸に戻るや否や聖者にこう告げた。「尊者よ、これにてご挨拶を申し上げます。長きにわたりこの下婢はお情けを頂きました。今より自分の本分に戻らねばなりません。」
注Kale注（p. 71）：kāmotsava（カーマ祭）は春に行われるカーマ神の祝祭で、恋人たちが公然と戯れる機会であった。カーママンジャリーが聖者を祭りに連れ出すのは、公衆の面前で勝利を誇示するためである。uttamāṅganā（高位の女＝ライバルの遊女）が「奴隷となる」と宣言する場面は、遊女同士の名誉と勢力をかけた賭け（paṇa-bandha）の結末を示す。svārtha idānīm anuṣṭheyaḥ（今より自分の本分に戻る）という冷酷な一言が、それまでの偽りの献身をすべて覆す劇的転換点となっている。

9カーママンジャリーの真意

sa tu rāgād aśani-hata ivodbhrāmyābravīt — “priye, kim etat / kuta idam audāsīnyam / kva gatas tava mayyasādhāraṇo 'nurāgaḥ” iti / atha sā sasmitam avādīt — “bhagavan, yayādya rāja-kule mattaḥ parājayo 'bhyupetas tasyāś ca mama ca kasmiṃścit saṃgharṣe “marīcim āvarjitavatīva ślāghase” iti tayāsmyaham adhikṣiptā / dāsya-paṇa-bandhena cāsminn arthe prāvartiṣi / siddhārthā cāsmi tvat-prasādāt” iti /
9.1（聖者が情欲に溺れた後）彼はまるで雷に打たれたかのように激しく動揺して言った。「愛しい者よ、これは何だ。なぜ急にこの冷たさか。私に対するあの比類なき愛情はどこへ行ったのだ。」すると彼女はにっこりと微笑んで言った。「尊者よ、本日宮廷にて私に負けを認めたあの女との諍いで、『マリーチを篭絡したと自慢するのか』と私はなじられました。奴隷となるという賭けの約束で、この件を始めたのです。あなた様のお陰で勝ちを収めました。」
sa tayā tathāvadhūto durmatiḥ kṛtānuśayaḥ śūnya-vanāny avartiṣṭa /
9.2このように打ちのめされた愚かな聖者は、深く悔い、心ここにあらずのように虚ろな森に去って行った。
yas tayaivaṃ kṛtas tapasvī tam eva māṃ mahābhāga, manyasva / sva-śakti-niṣiktaṃ rāgam uddhṛtya tayaiva bandhakyā mahad vairāgyam arpitam / acirād eva śakya ātmā tvad-artha-sādhana-kṣamaḥ kartum / asyām eva tāvad vasāṅga-puryāṃ campāyām” iti /
9.3「あの遊女にそのようにされた苦行者こそ、他ならぬこの私なのです、高貴な方よ。己の力で注ぎ込んだ情欲を、あの遊女自身の手で引き抜かれ、大いなる離欲を授けられました。遠からず、あなた様のお役に立てる者となりましょう。さしあたりはこのアンガの都チャンパーに留まりましょう。」
atha tan-manaś-cyuta-tamaḥ-sparśa-bhiyevāstaṃ ravir agāt / ṛṣi-muktaś ca rāgaḥ saṃdhyātvenāsphurat / tat-kathā-datta-vairāgyāṇīva kamala-vanāni samakucan / anumata-muni-śāsanas tv aham amunaiva sahopāsya saṃdhyām anurūpābhiḥ kathābhis tam anuśayya nīta-rātriḥ pratyunmiṣaty udaya-prastha-dāva-kalpe kalpadruma-kisalayāvadhīriṇyaruṇārciṣi taṃ namaskṛtya nagarāyodacalam /
9.4すると、あたかも彼の心から落ちた闇の影に触れたかのように太陽は沈んだ。聖者から解き放たれた情欲は黄昏の赤みとなって揺らめいた。蓮池はあの物語に離欲を授けられたかのように花を閉じた。聖者の教えに従い、私は彼と共に黄昏の礼拝を行い、ふさわしい物語で夜を共に過ごした。東山の野火のごとく夜明けが訪れ、如意樹の新芽をも凌ぐ朝日の赤い光が射す頃、聖者に礼拝して都へと出発した。
注Kale注（p. 71）：rājakale（宮廷にて）で行われた遊女同士の賭け（paṇa-bandha）が全ての発端であったという衝撃の真相が明かされる。「priye, kimetat」（愛しい者よ、これは何だ）と呼びかける聖者の言葉——priyaは恋人への呼びかけ——の直後にカーママンジャリーが冷然と真相を告げる落差は、ダンディンの皮肉な筆致の真骨頂である。dāsyaṇṇa-bandhena（奴隷となる約束で）は負けた遊女が勝者の下婢となる賭けの形式を指す。kṛtānuśaya（深い後悔）と śūnyavana（虚ろな森）の語が、聖者の精神的荒廃を端的に表現している。

10ジャイナ僧院のヴァスパーリタ

adarśaṃ ca mārgābhyāśa-vartinaḥ kasyāpi kṣapaṇaka-vihārasya bahir vivikte raktāśoka-ṣaṇḍe niṣaṇṇam aspṛṣṭa-samādhim ādhi-kṣīṇam agragaṇyam anabhirūpāṇāṃ kṛpaṇa-varṇaṃ kam api kṣapaṇakam / urasi cāsya śithilita-mala-nicayān mukhān nipatato 'śru-bindūn alakṣayam /
10.1道端のジャイナ僧院の外、人気のない紅アショーカの林に座っている一人のジャイナ行者を見かけました。三昧にも達していない、やつれ果てた最も醜い者たちの筆頭のような、哀れな姿をしていました。その胸には、顔の汚れがゆるんだところから涙の雫がこぼれ落ちていました。
aprākṣaṃ cāntikopaviṣṭaḥ — “kva tapaḥ, kva ca ruditam / na ced rahasyam icchāmi śrotuṃ śoka-hetum” iti /
10.2私は傍に座って尋ねました。「苦行と涙と、何という取り合わせでしょう。秘密でなければ、あなたの悲しみの理由をお聞かせください。」

11美貌の誇りと遊女の罠

so 'brūta “saumya, śrūyatām / aham asyām eva campāyāṃ nidhipālita-nāmnaḥ śreṣṭhino jyeṣṭha-sūnur vasupālito nāma / vairūpyān mama nirūpaka iti prasiddhir āsīt / anyaś cātra sundaraka iti yathārtha-nāmā kalā-guṇaiḥ samṛddho vasunā nāti-puṣṭo 'bhavat /
11.1彼は答えました。「優しい方よ、お聞きください。私はこのチャンパーで、ニディパーリタという名の長者の長男、ヴァスパーリタと申します。醜貌のため『ヴィルーパカ（醜い者）』として知られておりました。もう一人、スンダラカ（美男）というその名の通りの青年がおり、技芸と教養には富んでいましたが財力には恵まれませんでした。」
tasya ca mama ca vapur-vasunī nimittīkṛtya vairaṃ vairopajīvibhiḥ paura-dhūrtair udapādyata / ta eva kadācid āvayor utsava-samāje svayam utpāditam anyonyāvamāna-mūlam adhikṣepa-vacana-vyatikaram upaśamayya “na vapur vasu vā puṃstva-mūlam, api tu prakṛṣṭa-gaṇikā-prārthya-yauvano hi yaḥ sa pumān / ato yuvati-lalāma-bhūtā kāmamañjarī yaṃ vā kāmayate sa haratu subhaga-patākām” iti vyavāsthāpayan / abhyupetyāvāṃ prāhiṇuva tasyai dūtān / aham eva kilāmuṣyāḥ smaronmāda-hetur āsam /
11.2「私と彼との間で、容姿と財力を種にして、不和を煽ることで生計を立てている都市の悪党どもが争いを引き起こしました。ある時祭りの場で、彼らが自ら焚きつけた互いの罵り合いを鎮めてこう裁定しました。『容姿でも財力でもない。最も優れた遊女に求められる若者こそ真の男である。ゆえに女性の冠たるカーママンジャリーが望む方こそ勝者の旗を得よ。』と。結局二人ともカーママンジャリーに使者を送りました。彼女の恋の狂気の火付け役となったのは、まさに私だったのです。」
注Kale注（p. 73）：nirūpaka（醜い者）とsundaraka（美しい者）のペアは、容姿と財力の対比を際立たせる命名。結局カーママンジャリーは富裕なヴァスパーリタの方を流し目で選び、彼の全財産を巻き上げた後に追い出す。vairūpajīvinaḥ pauradhūrtāḥ（不和をあおって生きる都市の悪党たち）は、古代インドの都市社会における寄生的存在を反映する。

12賭博と盗賊の道

āsīnayoś cāvayor mām evāpagamya sā nīlotpalamayam ivāpāṅga-dāmāṅge mama muñcantī taṃ janam apatrapayādhomukhaṃ vyadhatta / subhagaṃmanyena ca mayā sva-dhanasya sva-gṛhasya sva-gaṇasya sva-dehasya sva-jīvitasya ca saiveśvarī kṛtā / kṛtaś cāham anayā malamallaka-śeṣaḥ hṛta-sarva-svatayā cāpavāhitaḥ prapadya lokopahāsa-lakṣyatām akṣamaś ca soḍhuṃ dhikkṛtāni paura-vṛddhānām iha jaināyatane muninaikenopadiṣṭa-mokṣa-vartmā sukara eṣa veṣo veśa-nirgatānām ityudīrṇa-vairāgyas tad api kaupīnam ajahām / atha punaḥ prakīrṇa-mala-paṅkaḥ prabala-keśaluñcana-vyathaḥ prakṛṣṭatama-kṣut-pipāsādi-duḥkhaḥ sthānāsana-śayana-bhojaneṣvapi dvipa iva nava-graho balavatībhir yantraṇābhir udvejitaḥ pratyavāmṛśam / “aham asmi dvijātiḥ / asvadharmo mamaiṣa pākhaṇḍi-pathāvatāraḥ / śruti-smṛti-vihitenaiva vartmanā mama pūrvajāḥ prāvartanta / mama tu mandabhāgyasya nindya-veṣam amanda-duḥkhāyatanaṃ hari-hara-hiraṇyagarbhādi-devatāpavāda-śravaṇa-nairantaryāt pretyāpi niraya-phalam aphalaṃ vipralambha-prāyam īdṛśam idam adharma-vartma dharma-vat samācaraṇīyam āsīt” iti pratyākalita-sva-durnayaḥ piṇḍī-ṣaṇḍaṃ viviktam etad āsādya paryāptam aśru muñcāmīti / śrutvā caitad anukampamāno 'bravam “bhadra, kṣamasva / kañcit kālam atraiva nivasa / nijena dyumnenāsāveva veśyā yathā tvāṃ yojayiṣyati tathā yatiṣye / santyupāyās tādṛśāḥ” ityāśvāsya tam anutthito 'ham /
12.1私たち二人が座っていると、彼女は私のほうに近づき、青蓮でできたかのような流し目の花綱を私の体に投げかけて、あの男（スンダラカ）を恥じ入らせ、うつむかせました。自分を果報者と思い込んだ私は、自分の財産も家も一族も体も命も、すべて彼女の思うままにさせました。ところが彼女は私を腰布一枚の身にし、すべてを奪い取ると私を追い出しました。世間の笑い者となり、町の長老たちの罵りに耐えかねた私は、このジャイナ教の寺院で、ある僧から解脱の道を説かれ、「遊女の家を追われた者には、この姿こそたやすい」と言われて離欲の心を起こし、その腰布さえ捨てました。ところがその後、全身に垢と泥がこびりつき、髪を抜く荒行の痛みに苦しみ、極度の飢えと渇きに悩まされ、立つにも座るにも、寝るにも食べるにも、捕えられたばかりの象のように厳しい戒めに縛られて、私は悔い改めて考えました。「私は再生族（バラモン）だ。異端の道に堕ちたことは、私の本分ではない。我が祖先は天啓聖典と聖伝の定める道を歩んできた。それなのに不運な私は、卑しむべき装いで、大きな苦しみの住みかであり、ハリ（ヴィシュヌ）、ハラ（シヴァ）、ヒラニヤガルバ（ブラフマー）などの神々への誹りを絶えず聞かされるために死後も地獄の報いを招く、実りのない、欺きに満ちたこのような非法の道を、あたかも正法であるかのように行わねばならなかったのだ。」こうして自らの過ちを省みて、この人気のないアショーカの林にやって来て、思う存分涙を流しているのです。」 これを聞いて同情した私は言いました。「友よ、辛抱してください。しばらくここに留まりなさい。あの遊女自身が、己の才覚であなたに財産を返すよう仕向けてみせましょう。そのような策はあるのです。」と彼を慰めて立ち上がりました。
nagaram āviśann eva copalabhya lokavādāl lubdha-samṛddha-pūrṇaṃ puram ityarthānāṃ naśvaratvaṃ ca pradarśya prakṛti-sthān amūn vidhāsyan karṇīsuta-prahite pathi matim akaravam /
12.2都に入るや、人々の噂から、この都は貪欲な富豪に満ちていることを知り、財の無常を彼らに思い知らせて本来の姿に戻すべく、カルニースタ（伝説的盗賊術の祖）の道に従う決意をしました。
anupraviśya ca dyūta-sabhām akṣa-dhūrtaiḥ samagaṃsi / teṣāṃ ca pañcaviṃśati-prakārāsu sarvāsu dyūtāśrayāsu kalāsu kauśalam akṣabhūmi-hastādiṣu cātyanta-durupalakṣyāṇi kūṭa-karmāṇi tan-mūlāni sāvalepānyadhikṣepa-vacanāni jīvita-nirapekṣāṇi saṃrambha-viceṣṭitāni sabhika-pratyaya-vyavahārān nyāya-bala-pratāpa-prāyān aṅgīkṛtārtha-sādhana-kṣamān baliṣu sāntvanāni durbaleṣu bhartsitāni pakṣa-racanā-naipuṇam uccāvacāni pralobhanāni glaha-prabheda-varṇanāni dravya-saṃvibhāgaudāryam antarāntarāślīla-prāyān kalakalān ityetāni cānyāni cānubhavan na tṛptim adhyagaccham / ahasaṃ ca kiñcit pramāda-datta-śāre kvacit kitave /
12.3賭博場に入り、賽子の達人たちと合流しました。彼らの二十五種に及ぶ賭博技芸の熟練ぶり、賽子盤や手先における見破りがたい欺し技、賭けの種類の説明、分配金の気前よさ、合間の卑猥な掛け声――これら一切を体験しても私は満たされませんでした。そしてある賭博師が手を誤った時に、つい笑ってしまいました。
注Kale注（pp. 75-76）：karmīsuta-prahita（カルニースタの道）は盗賊術の伝統的教本に拠る道とされる。pañcaviṃśati-prakārāsu dyūtāśrayāsu kalāsu（賭博に関連する二十五種の技芸）は、『カーマスートラ』や『アルタシャーストラ』に列挙されるものと対応する。ダンディンはここで古代インドの賭博文化を詳細に描写しており、骰子の不正操作、場の取り仕切り役（sabhika）の制度、掛け金の分配法など、社会史的にも貴重な資料である。

13一万六千ディーナーラの勝利と夜盗

pratikitavas tu nirdahann iva krodha-tāmrayā dṛśā mām abhivīkṣya “śikṣayasi re dyūta-vartma hāsa-vyājena / āstām ayam aśikṣito varākaḥ / tvayaiva tāvad vicakṣaṇena deviṣyāmīti dyūtādhyakṣānumatyā vyatyaṣajat / mayā jitaś cāsau ṣoḍaśa-sahasrāṇi dīnārāṇām / tad-ardhaṃ sabhikāya sabhyebhyaś ca dattvārdhaṃ svīkṛtyodatiṣṭham /
13.1相手の賭博師は怒りに目を赤くして私を睨み、「笑いを装って賭博の道を教えるつもりか。この無学な哀れ者はさておき、まずお前のような目利きと勝負してやろう。」と賭博監督の許可を得て私に勝負を挑みました。私は彼に勝ち、一万六千ディーナーラを得ました。その半分を監督と場の者たちに渡し、残りの半分を取って立ち上がりました。
udatiṣṭhaṃś ca tatra gatānāṃ harṣa-garbhāḥ praśaṃsālāpāḥ / prārthayamāna-sabhikānurodhāc ca tad-agāre 'tyudāram abhyavahāra-vidhim akaravam / yan-mūlaś ca me durodarāvatāraḥ sa me vimardako nāma viśvāsyataraṃ dvitīyaṃ hṛdayam āsīt / tan-mukhena ca sārataḥ karmataḥ śīlataś ca sakalam eva nagaram avadhārya dhūrjaṭi-kaṇṭha-kalmāṣa-kālatame tamasi nīla-nivasanārdhoruka-parihito baddha-tīkṣṇa-kaukṣeyakaḥ phaṇimukha-kākalī-saṃdaṃśaka-puruṣaśīrṣaka-yogacūrṇa-yogavartikā-mānasūtra-karkaṭaka-rajju-dīpa-bhājana-bhramara-karaṇḍaka-prabhṛtyanekopakaraṇa-yukto gatvā kasyacil lubdheśvarasya gṛhe saṃdhiṃ chittvā paṭa-bhāsa-sūkṣma-cchidrālakṣitāntargṛha-pravṛttir avyatho nija-gṛham ivānupraviśya nīvīṃ sāramahatīm ādāya niragām /
13.2その場にいた人々から、喜びに満ちた賞賛の声が上がりました。強く求める胴元の願いに応じて、その家で盛大な酒宴を催しました。そして私が賭け事に加わるきっかけとなったあの男、ヴィマルダカが、私にとって最も信頼できる第二の心となりました。そのヴィマルダカを通じて都の全容——財力、仕事ぶり、性格に至るまで——を把握した後、シヴァ神の喉のように漆黒の闇の中、紺の衣に半ズボン姿で、鋭い剣を帯び、蛇口型のくぎ抜き・人頭の偽首・魔法の粉・計測紐・梯子縄・灯籠・蜂の入った箱など数多の道具を携え、ある成り上がりの屋敷に忍び入り、壁に穴を開け、格子窓の小穴から中の様子を探り、恐れることなく自分の家のように入り込み、重い金袋を奪って脱出しました。
注Kale注（p. 76）：dūrjaṭi-kaṇṭha-kalmāṣa-kālatame tamasi（シヴァ神の喉＝毒による青黒い斑のように暗い闇）は、ダンディンの好む比喩的修飾語の連鎖。盗賊の道具一覧（phaṇimukha-kākalī-saṃdaṃśaka「蛇口型のくぎ抜き」、puruṣa-śīrṣaka「偽の人頭」、yoga-cūrṇa「魔法の粉」、māna-sūtra「計測紐」、karkaṭaka-rajju「梯子縄」等）は、『アルタシャーストラ』第4巻の盗賊取り締まり章に列挙される道具と対応する。

14夜道の娘と毒蛇の芝居

nīla-nīrada-nikara-pīvara-tamo-nibiḍitāyāṃ rāja-vīthyāṃ jhaṭiti śatahradā-saṃpātam iva kṣaṇam ālokam alakṣayam / athāsau nagara-devateva nagara-moṣa-roṣitā niḥsaṃbādha-velāyāṃ niḥsṛtā saṃnikṛṣṭā kācid unmiṣad-bhūṣaṇā yuvatir āvirāsīt /
14.1紺碧の雲の群れのように濃い闇に閉ざされた王道で、一瞬、稲妻のように光が走りました。すると、この都の盗みに怒った都市の守護女神のように、静まり返った時刻に姿を現した、宝飾がきらめく若い娘が目の前に立っていました。
“kāsi vāsu, kva yāsīti sadayam uktā trāsa-gadgadam agādīt “ārya, puryasyām arya-varyaḥ kuberadatta-nāmā vasati / asmyahaṃ tasya kanyā / māṃ jāta-mātrāṃ dhanamitra-nāmne 'tratyāyaiva kasmaicid ibhya-kumārāyānvajānād bhāryāṃ me pitā / sa punar asminn atyudāratayā pitror ante vittair nijaiḥ krītvevārthi-vargād dāridryaṃ daridrati satyathodāraka iti ca prīta-lokādhiropitāpara-ślāghya-nāmani varayatyeva tasmin māṃ taruṇī-bhūtām adhana ity adattvārthapati-nāmne kasmaicid itarasmai yathārtha-nāmne sārthavāhāya ditsati me pitā / tad amaṅgalam adya kila prabhāte bhāvīti jñātvā prāg eva priyatama-datta-saṃketā vañcita-sva-janā nirgatya bālyābhyastena vartmanā manmathābhisarā tad-agāram abhisarāmi tan māṃ muñca / gṛhāṇaitad bhāṇḍam” ityunmucya mahyamarpitavatī /
14.2「お嬢さん、どなたですか、どちらへ？」と優しく声をかけると、恐怖に声を震わせて答えました。「旦那様、この近くにクベーラダッタという名の裕福な商人が住んでおります。私はその娘です。父は私を生まれたばかりの時にこの都のダナミトラという若者に嫁がせると約束しました。ところがその方は両親の死後、持ち前の寛大さゆえに施しを受ける者たちからまるで貧困を買い取ったかのように無一文になりました。しかし世間は『ウダーラカ（気前の良い者）』というもう一つの賞賛に値する名を彼に与えました。あの方を慕い続ける私を、父は貧しいからという理由でその方に嫁がせず、アルタパティという名にふさわしい富裕な隊商長に嫁がせようとしています。今宵その不吉な婚礼が明朝に迫ると知り、愛する人との約束に従い、家人の目を欺いて幼い頃から馴染んだ道で恋の神に駆り立てられるまま彼の家に向かうところなのです。どうか私を行かせてください。この装身具をお取りください。」と装身具を外して私に渡しました。

15機転の策略——死んだふり

dayamānaś cāham abravam — “ehi sādhvi, tvāṃ nayeyaṃ tvat-priyāvasatham” iti tricaturāṇi padānyudacalam / āpatac ca dīpikā-loka-parilupyamāna-timira-bhāraṃ yaṣṭi-kṛpāṇa-pāṇi nāgarika-balam analpam /
15.1同情して私は言いました。「おいでなさい、淑女よ。あなたの愛する人の住まいに連れて行ってあげましょう。」三、四歩進んだところで、松明の光が闇を払い、棒と剣を手にした少なからぬ夜警の群れが迫ってきました。
dṛṣṭvaiva pravepamānāṃ kanyakām avadam — “bhadre, mā bhaiṣīḥ / astyayam asi-dvitīyo me bāhuḥ api tu mṛdur ayam upāyas tvad-apekṣayā cintitaḥ / śaye 'haṃ bhāvita-viṣa-vega-vikriyaḥ / tvayāpyamī vācyāḥ “niśi vayam imāṃ purīṃ praviṣṭāḥ / daṣṭaś ca mamaiṣa nāyako darvīkareṇāmuṣmin sabhā-gṛha-koṇe / yadi vaḥ kaścin mantra-vit kṛpāluḥ sa enam ujjīvayan mama prāṇān āhared anāthāyāḥ” iti /
15.2震えている娘を見て私は言いました。「お嬢さん、恐れることはありません。この剣を持つ腕がある。しかしあなたのために穏やかな策を思いつきました。私は毒に侵されたふりをして横たわります。あなたもこの者たちにこう言うのです——『夜に私たちはこの都に入りました。この私の連れがあの集会所の隅でコブラに噛まれたのです。もしあなた方の中に呪法を知る慈悲深い方がいらっしゃれば、この者を蘇らせて身寄りのない私の命を救ってください。』と。」
sāpi bālā gatyantarābhāvād bhaya-gadgada-svarā bāṣpa-durdinākṣī baddha-vepathuḥ kathaṅkatham api gatvā mad-uktam anvatiṣṭhat, aśayiṣi cāhaṃ bhāvita-viṣa-vikriyaḥ teṣu kaścin narendrābhimānī māṃ nirvarṇya mudrā-tantra-mantra-dhyānādibhiś copakramyākṛtārthaḥ “gata evāyaṃ kāla-daṣṭaḥ / tathā hi stabdha-śyāvam aṅgam, ruddhā dṛṣṭiḥ, śānta evoṣmā / śucālaṃ vāsu, śvo 'gnisāt kariṣyāmaḥ / ko 'tivartate daivam” iti sahetaraiḥ prāyāt /
15.3あの娘も他に手段がなく、恐怖で声を震わせながら、どうにか彼らのもとに行って私の言った通りにしました。私も毒に侵されたかのように横たわりました。彼らの中の一人が自称毒薬師で、私を調べ、呪符・真言・瞑想などで治療を試みましたが効果なく、「この者は死に神に噛まれたのだ。体は硬直して青黒く、視線は据わり、息は完全に止まっている。嘆くのはもう十分だ。明朝火葬にしよう。誰が運命に逆らえようか。」と言って仲間と去って行きました。
注Kale注（pp. 78-79）：蛇咬を装い夜警を欺く一幕は、ダンディンの得意とするピカレスク的場面。nirendrābhimānin（自称毒薬師）が呪符（mudrā）・真言（mantra）・瞑想（dhyāna）で治療を試みるが失敗するという描写は、古代インドの民間医療の実態を風刺的に映し出している。

16義賊への感嘆と象での逃走劇

utthitaś cāham udārakāya tāṃ nītvābravam — “aham asmi ko 'pi taskaraḥ / tvad-gatenaiva cetasā sahāya-bhūtena tvām imām abhisarantīm antaropalabhya kṛpayā tvat-samīpam anaiṣam / bhūṣaṇam idam asyāḥ” ityaṃśu-paṭala-pāṭita-dhvānta-jālaṃ tad apyarpitavān /
16.1起き上がった私はウダーラカ（ダナミトラ）のもとへ彼女を連れて行き、言いました。「私はただの盗賊です。あなたに心を寄せる助けとなる彼女が、一人で夜道をあなたの元に向かっているのを偶然見つけ、哀れに思って連れて参りました。彼女の装身具もここにあります。」と、光の帯で闇の網を裂くようなその宝飾品をも渡しました。
udārakas tu tad ādāya salajjaṃ ca saharṣaṃ ca sasaṃbhramaṃ ca mām abhāṣata “ārya, tvayeveyam asyāṃ niśi priyā me dattā / vāk punar mamāpahṛtā / tathā hi na jāne vaktuṃ tvat-karmaitad adbhutam iti / na te sva-śīlam adbhuta-vat pratibhāti / naivam anyenāpi kṛta-pūrvam iti pratiniyataiva vastu-śaktiḥ / na hi tvayyanyadīyā lobhādayaḥ / tvayādya sādhutonmīliteti tat prāyas tvat-pūrvāvadānebhyo na rocate / tvayāmunā su-kṛtena krīto 'yaṃ dāsa-jana ityasāram ati-garīyasā krīṇāsīti sa te prajñādhikṣepaḥ / priyā-dānasya pratidānam idaṃ śarīram iti tad-alābhe nidhanonmukham idam api tvayaiva dattam / athavaitāvad atra prāpta-rūpam / adya prabhṛti bhartavyo 'yaṃ dāsa-janaḥ” iti mama pādayor apat /
16.2ウダーラカはそれを受け取り、恥じらいと喜びと狼狽を交えて私に言いました。「旦那様、この夜にあなたは私の恋人を与えてくださいました。しかし同時に私の言葉をも奪い去られました。あなたの行いを驚くべきことだと言えばよいのか——しかしあなた自身にとっては驚くべきことではないのでしょう。他の者がかつてこのようなことをしたことはないと言えば——それは事物の本性に限界があるだけのこと。あなたに他人のものへの貪欲はないと言おうか——あなたは今日まさに善行を成し遂げたのだ、と言えばそれはあなたの過去の偉業に比べて映えぬ。あなたの善行でこの下僕は買い取られたと言えば——くだらぬ言葉でこれほどの御方を買うのかという知性への侮辱となる。恋人を与えてくださった返礼にこの身体を捧げようと言えば——それが叶わぬなら死を向かえるこの身体さえ、あなたに与えられたもの。いや、ここはこう言うのがふさわしい。今日からこの下僕をお養いください。」と私の足下に倒れ伏しました。
注Kale注（pp. 79-80）：ウダーラカの感謝の言葉はダンディンの修辞学的技巧の見本で、彼は盗賊への感謝を様々な角度から表現しようとするが、そのどれもが論理的に自己撞着を含むことを認識し、結局「今日よりこの下僕をお養いください」という直接的な表現に落ち着く。この「言い尽くせぬ感謝」のモチーフは、古典サンスクリット文学の定型である。

17二軒同時の大強盗と象の暴走

atutthāpya cainamurasopaśliṣyābhāṣiṣi “bhadra, kādya te pratipattiḥ” iti / so 'bhyadhatta — “na śaknomi cainām atra pitror anabhyanujñayopayamya jīvitum / ato 'syām eva yāminyāṃ deśam imaṃ jihāsāmi” ko vāham, yathā tvam ājñapayasīti / atha mayoktam “astyetat / sva-deśo deśāntaram iti neyaṃ gaṇanā vidagdhasya puruṣasya / kintu bāleyam analpa-saukumāryā / kaṣṭāḥ pratyavāya-bhūyiṣṭhāś ca kāntāra-pathāḥ / śaithilyam iva kiñcit prajñā-sattvayor anarthenedṛśena deśa-tyāgena saṃbhāvyate / tat sahānayā sukham ihaiva vastavyam / ehi nayāvaināṃ svam evāvāsam” iti / avicārānumatena tena sadya evaināṃ tad-gṛham upanīya tayaivāpasarpa-bhūtayā tatra mṛd-bhāṇḍāvaśeṣam acorayāva / tato niṣpatya kvacin muṣitakaṃ nidhāya samuccalantau nāgarika-saṃpāte mārga-pārśva-śāyinaṃ kañcin matta-vāraṇam upari puruṣam ākṛṣyādhyārohāva /
17.1私は彼を起こして胸に抱き、「友よ、これからどうするつもりか」と尋ねました。彼は答えました。「この人の両親の許しなしに彼女を娶って、ここで暮らしていくことはできません。ですから今夜のうちにこの国を去ろうと思います。もっとも、私などに何が決められましょう。あなたのお指図どおりにいたします。」そこで私は言いました。「それも一つの道だ。故郷か異郷かなどということは、才ある男には問題にならない。しかしこの娘はまだ若く、ひどく華奢だ。荒野の道は苦しく、危険に満ちている。このような国外への逃亡は、知恵と胆力にいささか欠けるとみなされよう。だから彼女とともに、ここで安楽に暮らすべきだ。さあ、彼女を彼女自身の家へ連れて行こう。」考えなしに同意したダナミトラと共に、すぐさまクラパーリカーを彼女の（父の）家に送り届け、彼女自身を案内役にして、その家を土器以外すべて盗み尽くしました。そこから抜け出し、盗品をどこかに隠して走り出した折、夜警の一隊に出くわしました。道端に横たわっていた酔った軍象の象使いを引きずり下ろして二人で飛び乗りました。
graiveya-prota-pāda-yugalena ca mayotthāpyamāna eva pātitādhoraṇa-pṛthuloraḥ-sthala-pariṇataḥ purītal-latā-parīta-danta-kāṇḍaḥ sa rakṣika-balam akṣiṇot / adhvaṃsayāva cāmunaivārthapati-bhavanam /
17.2私が象の首鎖に足を突っ込んで立ち上がらせると、象は下に落ちた象使いの広い胸板に牙を斜めに突き立て、腸を牙に巻きつけながら夜警の兵を蹴散らしました。さらにこの象でアルタパティの邸宅をも破壊しました。
注Kale注（p. 81）：graiveya-prota-pāda-yugalena（首鎖に足を突っ込んで）は、象の操縦法の専門的描写。mṛdbhāṇḍāvaśeṣam（土器以外すべて）というユーモラスな表現は、盗みの徹底ぶりを誇張的に示すダンディンの諧謔趣味。mattavāraṇa（酔象）に乗って逃走するという展開は、本作中でも特に動的な場面である。

18ダナミトラと魔法の革袋

apavāhya ca kvacana jīrṇodyāne śākhā-grāhikayā cāvātarāva / sva-gṛha-gatau ca snātau śayanam adhyaśiśriyāva / tāvad evodagād udadher udayācalendra-padmarāga-śṛṅga-kalpaṃ kalpadruma-hema-pallavāpīḍa-pāṭalaṃ pataṅga-maṇḍalam / utthāya ca dhauta-vaktrau pragetanāni maṅgalānyanuṣṭhāyāsmat-karma-tumulaṃ puram anuvicarantāvaśṛṇuva vara-vadhū-gṛheṣu kolāhalam / athārthair arthapatiḥ kuberadattam āśvāsya kulapālikā-vivāhaṃ māsāvadhikam akalpayat / upahvare punar ityaśikṣayaṃ dhanamitram — “upatiṣṭha sakhe, ekānta eva carmaratna-bhastrikām imāṃ puraskṛtyāṅga-rājam / ācakṣva ca jānātyeva devo naika-koṭi-sārasya vasumitrasya māṃ dhanamitraṃ nāmaika-putram / so 'haṃ mūla-haratvam etyārthi-vargād asmyavajñātaḥ / mad-artham eva saṃvardhitāyāṃ kulapālikāyāṃ mad-dāridrya-doṣāt punaḥ kuberadattena duhitaryarthapataye ditsitāyām udvegād ujhitum asūn upanagara-bhavaṃ jarad-vanam avagāhya kaṇṭha-nyasta-śastrikaḥ kenāpi jaṭādhareṇa nivāryaivam uktaḥ “kiṃ te sāhasasya mūlam” iti / mayoktam — “avajñā-sodaryaṃ dāridryam” iti / sa punar evaṃ kṛpālur anvagrahīt — “tāta, mūḍho 'si / nānyat pāpiṣṭhatamam ātmatyāgāt / ātmānam ātmanānavasādyaivoddharanti santaḥ / santyupāyā dhanārjanasya bahavaḥ naiko 'pi chinna-kaṇṭha-pratisaṃdhāna-pūrvasya prāṇa-lābhasya / kim anena / so 'smyahaṃ mantra-siddhaḥ / sādhiteyaṃ lakṣa-grāhiṇī carmaratna-bhastrikā / ciram aham asyāḥ prasādāt kāmarūpeṣu kāma-pradaḥ prajānām avātsam / matsariṇyāṃ jarasi bhūmi-svargam atroddeśe pravekṣyann āgataḥ / tām imāṃ pratigṛhāṇa / mad anyatra ceyaṃ vaṇigbhyo vāramukhyābhyo vā dugdhe iti hi tad-gatā pratītiḥ / kintu yat sakāśād anyāyāpahṛtaṃ tat tasmai pratyarpaṇīyam / nyāyārjitaṃ tu deva-brāhmaṇebhyas tyājyam / atheyaṃ devateva śucau deśe niveśyārcyamānā prātaḥ prātaḥ suvarṇa-pūrṇaiva dṛśyate / sa eṣa kalpaḥ iti baddhāñjalaye mahyam enāṃ dattvā kim api grāva-cchidraṃ prāviśat / iyaṃ ca ratna-bhūtā carmabhastrikā devāyānivedya nopajīvyetyānītā / parantu devaḥ pramāṇam” iti / rājā ca niyatam evaṃ vakṣyati — “bhadra, prīto 'smi / gaccha / yatheṣṭam imām upabhuṅkṣva” iti / bhūyaś ca brūhi “yathā na kaścid enāṃ muṣṇāti tathānugṛhyatām” iti / tad apyavaśyam asāvabhyupaiṣyati / tataḥ sva-gṛham etya yathoktam artha-tyāgaṃ kṛtvā dine dine varivasyamānāṃ steya-labdhair arthair naktam āpūrya prāhṇe lokāya darśayiṣyasi / tataḥ kuberadattas tṛṇāya matvārthapatim artha-lubdhaḥ kanyakayā svayam eva tvām upasthāsyati / atha kupito 'rthapatir vyavahartum artha-garvād abhiyokṣyate / taṃ ca bhūyaś citrair upāyaiḥ kaupīnāvaśeṣaṃ kariṣyāvaḥ / svakaṃ cauryam anenaivābhyupāyena su-pracchannaṃ bhaviṣyatīti /
18.1私たちは象を町外れへ連れ出し、とある荒れた庭園で枝につかまって降りました。それぞれ家に帰って沐浴し、寝床に就きました。ちょうどその時、東山の王の紅玉の峰にも似て、如意樹の金の若葉の冠のように紅い日輪が、海から昇りました。起きて顔を洗い、朝の吉祥の儀礼を済ませ、私たちの所業で騒然とする町を歩き回ると、花婿の家でも花嫁の家でも騒ぎが起きているのが聞こえました。そこでアルタパティは財貨でクベーラダッタを慰め、クラパーリカーとの婚礼を一か月後と定めました。内密にダナミトラにこう指示しました。「友よ、この革袋の宝を携え、密かにアンガの王に謁見せよ。そしてこう言え——『陛下もご存知のように、私ダナミトラは数億の財を持つヴァスミトラの一人息子です。施しの者たちに全父祖の財を失い、蔑まれておりました。クベーラダッタが私のために育ててきたクラパーリカーを、私の貧困のせいでアルタパティに嫁がせようとした時、絶望して都の近くの老樹林に入り、喉に刃を当てたところ、ある苦行者に止められました。その苦行者はこう言いました——「若者よ、汝は愚かだ。自殺より大きな罪はない。善き者は自らを滅ぼさず、己の力で身を起こすものだ。財を得る手段は多くあれど、切られた喉を繋ぎ直して命を取り戻す方法は一つもない。もうよい。この私は呪力を完成した者だ。この革の袋は一ラクシャ（十万枚）の金貨を生む力がある。長い間この袋の恩恵でカーマルーパ（アッサム）の地にて人々に望みを叶えてきた。嫉妬深い老齢に達し、この地上の天国とも言うべき場所で洞窟に入ろうとやって来た。これを受け取れ。ただしこの袋は私以外の者の手では、商人か遊女の手でしか乳を出さぬという言い伝えがある。不正に奪ったものはその相手に返さねばならぬ。正当に得たものは神とバラモンに捧げよ。この袋を神像のように清浄な場所に安置して礼拝すれば、毎朝黄金で満たされているのが見えるだろう。これがその作法である」と言って、合掌する私にこの袋を与え、どこかの岩の割れ目へと入って行きました。この宝の革袋は陛下に届け出ずに用いるべきではないと思い、持参いたしました。最終判断は陛下に委ねます。』と。王は必ず『よし、好きに使え』と仰るだろう。さらに『誰にも盗まれぬようご加護を』と言え。それも必ず承知するだろう。その後、家に帰って言った通り財を手放し、毎晩盗みで得た金を袋に詰め、朝になったら人々に見せるのだ。するとクベーラダッタは金に目がくらみアルタパティを藁同然と見なし、自ら娘を連れてお前のもとに嫁がせようとするだろう。怒ったアルタパティが財力を笠に訴訟を起こせば、そいつは巧みな手段でふんどし一枚にしてやろう。自分たちの盗みもこの手段で完璧に隠されるだろう。」
注Kale注（pp. 82-83）：carmaratna-bhastrikā（革の宝袋）をめぐる精巧な詐欺計画は、本章の中核的プロットである。王を巻き込んで革袋の正統性を保証させ、夜の盗みで得た金を朝に「魔法の産物」として見せるという二重構造は、アルタシャーストラ的知略の文学的応用と言える。ダンディンは策略の一手一手を論理的に組み立て、読者を知的興奮へと導く。

19遊女ラーガマンジャリーへの恋

hṛṣṭaś ca dhanamitro yathoktam anvatiṣṭhat / tad ahar eva man-niyogād vimardako 'rthapati-sevābhiyuktas tasyodārake vairam abhyavardhayat / artha-lubdhaś ca kuberadatto nivṛttyārthapater dhanamitrāyaiva tanayāṃ sānunayaṃ prāditsata / pratyabadhnāc cārthapatiḥ / eṣveva divaseṣu kāmamañjaryāḥ svasā yavīyasī rāgamañjarī nāma pañcavīragoṣṭhe saṃgītakam anuṣṭhāsyatīti sāndrādaraḥ samāgaman nāgara-janaḥ / sa cāhaṃ saha sakhyā dhanamitreṇa tatra saṃnyadhiṣi /
19.1喜んだダナミトラは言われたとおりに実行しました。その日のうちに、私の指図でアルタパティに仕えるようになったヴィマルダカが、ウダーラカ（ダナミトラ）に対するアルタパティの敵意を煽り立てました。財に目のくらんだクベーラダッタは、アルタパティとの縁談を翻し、娘を丁重にダナミトラに与えようとしました。アルタパティはこれに異を唱えました。ちょうどその頃、カーママンジャリーの妹のラーガマンジャリーが五勇士の集会場で演奏会を開くということで、都人たちが熱心に集まりました。私も友のダナミトラと共にそこに出向きました。
pravṛtta-nṛtyāyāṃ ca tasyāṃ dvitīyaṃ raṅgapīṭhaṃ mamābhūn manaḥ / tad-dṛṣṭi-vibhramotpala-vana-sac-cāpāśrayaś ca pañcaśaro bhāva-rasānāṃ sāmagryāt samudita-bala iva mām atimātram avyathayat /
19.2彼女が踊り始めると、私の心はいわば第二の舞台と化しました。彼女の妖艶な眼差しの蓮池を真の弓として拠り所とするカーマ神は、感情と情趣の総力を結集して力を得たかのように、私を極度に苦しめたのです。
注Kale注（pp. 84-85）：pañcavīragoṣṭha（五勇士の集会場）は公共の演芸場。dvitīyaṃ raṅgapīṭham mamābhūn manaḥ（私の心は第二の舞台となった）という比喩は、舞踊を見る者の心が踊り手に完全に支配されることを表す。pañcaśara（五矢神＝カーマ）が彼女の流し目を弓として用いるという描写は、古典的な恋愛修辞の変奏である。ラーガマンジャリーは姉とは異なり、guṇaśulkā（才徳を花代とする者）であり、金銭ではなく品性によってのみ身を許すと宣言した異色の遊女である。

20革袋の取引と遊女一家の懐柔

athāsau nagara-devateva nagara-moṣa-roṣitā līlā-kaṭākṣa-mālā-śṛṅkhalābhir nīlotpala-palāśa-śyāmalābhir mām abadhnāt / nṛtyotthitā ca sā siddhi-lābha-śobhinī “kiṃ vilāsāt, kim abhilāṣāt, kim akasmād eva vā, na jāne, -asakṛn māṃ sakhībhir apyanupalakṣitenāpāṅga-prekṣitena savibhramārecita-bhrū-latam abhivīkṣya, sāpadeśaṃ ca kiñcid āviṣkṛta-daśana-candrikaṃ smitvā, loka-locana-mānasānuyātā prātiṣṭhata / so 'haṃ sva-gṛham etya durnivārayotkaṇṭhayā dūrīkṛtāhāra-spṛhaḥ śiraḥ-śūla-sparśanam apadiśan vivikte talpe muktair avayavair aśayiṣi / ati-niṣṇātaś ca madana-tantre mām abhyupetya dhanamitro rahasyakathayat “sakhe, saiva dhanyā gaṇikā-dārikā, yām evaṃ bhavan-mano 'bhiniviśate / tasyāś ca mayā su-lakṣitā bhāva-vṛttiḥ / tām apyacirād ayugmaśaraḥ śaraśayane śāyayiṣyati / sthānābhiniveśinoś ca vām ayatna-sādhyaḥ samāgamaḥ / kintu sā kila vārakanyakā gaṇikā-svadharma-pratīpa-gāminā bhadrodāreṇāśayena samagirata “guṇa-śulkāham, na dhana-śulkā / na ca pāṇigrahaṇād ṛte 'nya-bhogyaṃ yauvanam” iti / tac ca muhuḥ pratiṣidhyākṛtārthā tad-bhaginī kāmamañjarī-mātā ca mādhavasenā rājānam aśru-kaṇṭhyau vyajijñapatām “deva, yuṣmad-dāsī rāgamañjarī rūpānurūpa-śīla-śilpa-kauśalā pūrayiṣyati manorathān ityāsīd asmākam ati-mahatyāśā sādya mūlac-chinnā / yad iyam atikramya sva-kula-dharmam artha-nirapekṣā guṇebhya evaṃ svaṃ yauvanaṃ vicikrīṣate kula-strī-vṛttam evācyutamanutiṣṭhāsati / sā ced iyaṃ deva-pādājñayāpi tāvat prakṛtim āpadyeta tadā peśalaṃ bhavet” iti / rājñā ca tad-anurodhāt tathānuśiṣṭā satyapyanāśravaiva sā yadāsīt, tadāsyāḥ svasā mātā ca rudita-nirbandhena rājñe samagiratām “yadi kaścid bhujaṅgo 'smad-icchayā vinaināṃ bālāṃ vipralabhya nāśayiṣyati sa taskara-vad vadhyaḥ” iti / tad evaṃ sthite dhanād ṛte na tat-sva-jano 'numanyate / na tu dhana-dāyāsāvabhyupagacchatīti vicintyo 'trābhyupāyaḥ” iti / atha mayoktam “kim atra cintyam / guṇais tām āvarjya gūḍhaṃ dhanais tat-sva-janaṃ toṣayāvaḥ” iti /
20.1すると、都が盗み荒らされたことに怒った都の守護女神さながらに、彼女は青蓮の花弁のように黒い、戯れの流し目の鎖で私を縛りました。舞い終えて立ち上がると、首尾よく喝采を得て輝きながら、媚態からか、恋心からか、それともただ偶然か――私には分かりませんが――友人たちにも気づかれぬ流し目で、眉の蔓を艶やかにつり上げて何度も私を見つめ、何かの口実にかこつけて、歯の月光をわずかにのぞかせて微笑み、人々の目と心を引き連れて去って行きました。私は家に帰ると、抑えがたい恋しさに食欲もなくなり、頭痛がすると口実をつけて、人気のない寝台に手足を投げ出して横たわりました。恋の道に通じたダナミトラが来て、密かにこう言いました。「友よ、あなたの心をこれほど捉えたあの遊女の娘は果報者だ。私は彼女の心の動きもよく見ておいた。間もなく奇数の矢をもつ神（カーマ）が、彼女をも矢の褥に臥させるだろう。お互いにふさわしい相手を想っているのだから、二人の逢瀬は苦もなく叶うはずだ。ただ、あの遊女の娘は、遊女の掟に背く気高く寛い心で、こう宣言したそうだ――『私は才徳を花代とし、金を花代とはいたしません。婚礼で手を取られるのでなければ、私の若さを他人に味わわせはいたしません』と。何度禁じても聞き入れられなかった姉のカーママンジャリーと母のマーダヴァセーナーは、涙に声を詰まらせて王にこう申し上げた――『陛下、陛下の婢ラーガマンジャリーは、容姿にふさわしい品性と技芸を備え、私どもの願いをかなえてくれるものと大いに望みをかけておりましたが、それも今日、根元から断たれてしまいました。この子は家の掟を踏み越え、金に目もくれず、才徳のためだけに自分の若さを売ろうとし、良家の婦人のような身持ちを揺るぎなく貫こうとしております。せめて陛下のご命令によってでも本来の姿に戻ってくれれば幸いです』と。王に頼まれて諭されても彼女が聞き入れなかったので、姉と母は泣いてせがみ、王に『もし我々の同意なく、この娘を欺いて身を損なう遊び人がいれば、盗賊と同じく死刑に処す』と言わせた。というわけで、家族は金がなければ承知せず、本人は金を払う者を受け入れない。ここは策を練らねばならない。」私は言いました。「何を思案する必要があろう。才徳で彼女の心を惹き、密かに金で彼女の家族を満足させればよい。」
tataś ca kāñcit kāmamañjaryāḥ pradhāna-dūtīṃ dharmarakṣitāṃ nāma śākya-bhikṣukīṃ cīvara-piṇḍa-dānādinopasaṃgṛhya tan-mukhena tayā bandhakyā paṇa-bandham akaravam — “ajina-ratnam udārakān muṣitvā mayā tubhyaṃ deyam, yadi pratidānaṃ rāgamañjarī” iti /
20.2そこでカーママンジャリーの主たる仲介者であるダルマラクシター という名の仏教尼僧を、法衣や食事の布施で味方につけ、その口利きでカーママンジャリーとこう取り決めました。「ウダーラカ（ダナミトラ）の革の宝を盗み出してお前に渡す。その代わりにラーガマンジャリーをよこせ。」
注Kale注（pp. 85-86）：dharmarakṣitā nāma śākyabhikṣukī（ダルマラクシターという仏教尼僧）が恋の仲介役を務めるという設定は、古代インド文学に頻出するモチーフ。仏教の比丘尼が遊女の使い走りを務めるという風刺的描写は、ダンディンの時代のヒンドゥー文学における仏教批判の一面でもある。ラーガマンジャリーの「guṇaśulkā, na dhanaśulkā」（才徳を対価とし、金銭を対価としない）という宣言は、彼女が姉とは正反対の気質を持つことを示す。

21策略の完成——アルタパティの追放

21.2ダナミトラは言いました。「お前、他人のために私を罵るとは、どういうつもりだ。私がお前に少しでも害をなした覚えはない。」相手はなおも脅すように言いました。「それこそが財の驕りというものだ。他人が花代を払って買い取った妻を、その両親を金で誘惑して自分のものにしようとしている。それでいて『私がお前にどんな害をなしたか』だと。ヴィマルダカは隊商の長アルタパティの体の外を歩く命だと、誰もが知っているではないか。あの方のためなら私は命も捨てる。バラモン殺しさえ厭わぬ。お前の革の宝への驕りという熱病は、私が一晩寝ずに働けば治るのだ。」こう言い立てる彼は、町の長老たちに憤然と制止され、連れ去られました。この出来事を、ダナミトラは困り果てたふりをして、まず革の宝が失われたことを申し立てた上で王に報告しました。王はアルタパティを呼び出して、ひそかに尋ねました。「そなたのところにヴィマルダカという者はいるか。」愚かな彼が「おります、陛下、大の親友です。あの者が何か」と答えると、王は「その者をここへ呼べるか」と言いました。「もちろんです」と言って出て行き、自分の家、遊郭、賭博場、市場と念入りに探しましたが、見つかりませんでした。あの哀れな男が見つかるはずがありません。ヴィマルダカは、私があなた様を見分ける目印を教えておいたので、私の指図でその日のうちに、あなた様を探しにウッジャイニーへ旅立っていたのです。アルタパティは彼が見つからないので、その罪が自分に及ぶと思い、愚かさからか恐れからか、彼との関わりを否定しましたが、ダナミトラに証拠を突きつけられ、怒った王に捕えられて足枷をはめられました。ちょうどその頃、カーママンジャリーは定められた作法どおりに革の宝から富を搾り出そうと、かつて自分が搾り取ってジャイナの裸形行者となっていたヴィルーパカ（ヴァスパーリタ）のもとへ密かに行き、彼から奪った財をすべて返し、丁重に何度も詫びて帰って来ました。彼もまた、私が教えておいたとおり、どうにかジャイナ教徒の手から逃れて、大いに喜んで本来の務めに立ち返りました。カーママンジャリーは、革の宝から富を搾り出せるという期待から、わずか数日で自分の財産を竈の石だけになるまで手放してしまいました。そこで私に指図されたダナミトラは、王にひそかにこう申し上げました。「陛下、この遊女カーママンジャリーは、ひどい強欲ゆえに『ローバマンジャリー（強欲の花房）』と世間の非難の的となっていた女ですが、今日では杵や臼まで惜しげもなく手放しております。その原因は、私の革の宝を手に入れたことにあると思われます。あの宝の作法はまさにそういうもので、商人と遊女のためにしか富を出さず、他の者には出さないと信じられているのです。ですから、あの女に疑いをかけております。」カーママンジャリーとその母は直ちに王に呼び出されました。私は苦悶の表情を装って内密に彼女にこう告げました。「ねえ姐さん、全財産を手放したことで目立ちすぎ、革の宝の入手先を疑われている。その尋問のためにアンガの王に呼ばれたのだ。何度隠しても必ず盗品の出どころとして私の名が出る。そうなれば私は凄惨な死を遂げ、私が死ねばお前の妹も生きてはいまい。お前も無一文になり、革の宝はダナミトラの手に戻るだけだ。この災いは四方すべてに不幸を連ねる。さてどうしたものか。」すると彼女と母は涙を流してこう答えました。「実はこの秘密は私たちの愚かさからほぼ露見しています。王がしつこく問い詰めれば、二度三度四度と否認しても、最後には盗品の出どころとしてあなたの名が必ず出ます。あなたが名指しされれば私たちの一族は崩壊します。幸いアルタパティにはすでに汚名が着いています。アンガの都で知られたあの守銭奴と私たちの間柄を利用し、あの者から受け取ったのだと偽って身を守りましょう。」と私に同意を求め、王宮に向かいました。王が詰問した際、「遊女の家の掟として贈り主の名を明かさぬのが道理。そもそも正当に稼いだ金だけで男が遊郭に通うわけではない。」と何度もはぐらかしましたが、耳と鼻を削がれるぞと脅された二人は、ついにかの哀れなアルタパティこそ盗人だと証言しました。怒った王はアルタパティに死刑を宣告しようとしました。
prāñjalinā dhanamitreṇaiva pratyaṣidhyata “ārya, mauryadatta eṣa varo vaṇijām īdṛśeṣv aparādheṣv asubhir aviyogaḥ / yadi kupito 'si hṛta-sarva-svo nirvāsanīyaḥ pāpa eṣaḥ” iti / tan-mūlā ca dhanamitrasya kīrtir aprathata /
21.3合掌したダナミトラが諫めました。「旦那様、マウリヤダッタ法典によれば、商人中の名士の場合、このような罪で命を奪うことはありません。お怒りであれば、財産を没収して追放すれば十分です。」こうしてダナミトラの評判はいよいよ高まりました。

22酩酊と投獄

tasyaiva dravyāṇāṃ tu kenacid avayavena sā varākī kāmamañjarī carmaratna-mṛgatṛṣṇikāpaviddha-sarva-svā sānukampaṃ dhanamitrābhinoditena bhūpenānvagṛhyata / dhanamitraś cāhani guṇini kulapālikām upāyaṃsta / tad evaṃ siddha-saṃkalpo rāgamañjarī-gṛhaṃ hema-ratna-pūrṇam akaravam / asmiṃś ca pure lubdha-samṛddha-vargas tathā muṣito yathā kapāla-pāṇiḥ svair eva dhanair mad-viśrāṇitaiḥ samṛddhīkṛtasyārtha-vargasya gṛheṣu bhikṣārtham abhramat / na hyalam ati-nipuṇo 'pi puruṣo niyati-likhitāṃ lekhām atikramitum / yato 'ham ekadā rāgamañjaryāḥ praṇaya-kopa-praśamanāya sānunayaṃ pāyitāyāḥ punaḥ punaḥ praṇaya-samarpita-mukha-madhu-gaṇḍūṣam āsvādam āsvādaṃ madenāspṛśye / śīlaṃ hi madonmādayor amārgeṇāpyucita-karmasveva pravartanam / yad aham upoḍha-madaḥ “nagaram idam ekayaiva śarvaryā nirdhanīkṛtya tvad-bhavanaṃ pūrayeyam” iti pravyathita-priyatamā-praṇāmāñjali-śapatha-śatātivartī matta-vāraṇa iva rabhasac-chinna-śṛṅkhalaḥ kayāpi dhātryā śṛgālikāṅkhyayānugamyamāno nāti-parikaro 'si-dvitīyo raṃhasā pareṇodacalam /
22.1哀れなカーママンジャリーは、革の宝という蜃気楼のために全財産を投げ捨ててしまったので、ダナミトラの口添えで、王は憐れみをかけ、アルタパティの財産の一部を彼女に与えました。ダナミトラは吉日にクラパーリカーを娶りました。こうして思いを遂げた私は、ラーガマンジャリーの家を黄金と宝石で満たしました。この都の強欲な富豪たちは徹底的に盗み尽くされ、髑髏の鉢を手に、私が分け与えた彼ら自身の財で豊かになった貧しい人々の家々を、施しを乞うて回るありさまでした。しかし、どれほど巧みな者でも、運命の書き記した線を越えることはできません。ある時私は、恋の拗ねをなだめようとラーガマンジャリーに機嫌を取って酒を飲ませ、彼女が愛情を込めて口移しに差し出す酒を何度も何度も味わううち、酔いが私に取り憑きました。酔いと狂気の性質とは、道を外れても自分の得意なわざにのみ向かうものです。私は深酔いして「この都をたった一夜で無一文にし、お前の家を満たしてやろう」と言い、震え上がる恋人の懇願の合掌と幾百の誓いの言葉を振り切り、鎖を断ち切った酔象のように、シュリガーリカーという乳母に後を追われながら、ろくな支度もせず剣一本を供として、猛然と走り出しました。
abhipatato 'pi nāgarika-puruṣān aśaṅkam eva vigṛhya taskara iti tair abhihanyamāno 'pi nāti-kupitaḥ krīḍann iva madāvasanna-hasta-patitena nistriṃśena dvitrān eva hatvāvaghūrṇa-māna-tāmra-dṛṣṭir apatam /
22.2襲いかかる夜警たちを遠慮なく相手にし、「盗賊だ」と打ちかかられても怒りもせず、遊んでいるかのように、酔いのさなかに手から落ちた剣で二、三人を斬り、赤く据わった目でぐらりと揺れ、倒れました。

23獄中の取引と地下道の掘削

anantaram ārta-ravān visṛjantī śṛgālikā mamābhyāśam āgamat / abadhye cāham aribhiḥ / āpadā tu madāpahāriṇyā sadya eva bodhitas tat-kṣaṇopajātayā pratibhayā vyacīcaram “aho, mameyaṃ moha-mūlā mahatyāpad āpatitā / prasṛtataraṃ ca sakhyaṃ mayā saha dhanamitrasya, mat-parigrahatvaṃ ca rāgamañjaryāḥ / mad-enasā ca tau prorṇutau śvo niyataṃ nigrahīṣyete / tad iyam iha pratipattir yayānuṣṭhīyamānayā man-niyogatas tau paritrāsyete / māṃ ca kadācid anarthāditas tārayiṣyatīti kam apyupāyam ātmanaiva nirṇīya śṛgālikām agādiṣam “apehi jaratike, yā tām artha-lubdhāṃ dagdha-gaṇikāṃ rāgamañjarikām ajina-ratna-mattena śatruṇā me mitra-chadmanā dhanamitreṇa saṃgamitavatī, sā hatāsi / tasya pāpasya carmaratna-moṣād duhituś ca te sārābharaṇāpahārād aham adya niḥśalyam utsṛjeyaṃ jīvitam” iti / sā punaruddhaṭitajñā parama-dhūrtā sāśru-gadgadam udañjalis tān puruṣān sapraṇāmam āsāditavatī sāma-pūrvaṃ mama purastād ayācata “bhadrakāḥ, pratīkṣyatāṃ kañcit kālaṃ yāvad asmād asmadīyaṃ sarvaṃ muṣitam artha-jātam avagaccheyam” iti / tatheti taiḥ pratipanne punar mat-samīpam āsādya “saumya, kṣamasvāsya dāsī-janasyaikam aparādham / astu sa kāmaṃ tvat-kalatrābhimarśī vairāspadaṃ dhanamitraḥ / smaraṃs tu cira-kṛtāṃ te paricaryām anugrahītum arhasi dāsīṃ rāgamañjarīm / ākalpa-sāro hi rūpājīvā-janaḥ / tad brūhi kva nihitam asyāṃ bhūṣaṇam” iti pādayor apatat / tato dayamāna ivāham abravam “bhavatu, mṛtyu-hasta-vartinaḥ kiṃ mamāmuṣyā vairānubandhena” iti tad bruvann iva karṇa evainām aśikṣayam “evam evaṃ pratipattavyam” iti / sā tu pratipannārtheva jīva ciram, prasīdantu te devatāḥ, devo 'pyaṅgarājaḥ pauruṣa-prīto mocayatu tvām, ete 'pi bhadra-mukhās tava dayantām, iti kṣaṇād apāsarat / ānīye cāham ārakṣaka-nāyakasya śāsanāc cārakam / athottaredyur āgatya dṛptataraḥ subhaga-mānī sundaraṃmanyaḥ pitur atyayād acirādhiṣṭhitādhikāras tāruṇya-madādanatipakvaḥ kāntako nāma nāgarikaḥ kiñcid iva bhartsayitvā māṃ samabhyadhatta — “na ced dhanamitrasyājina-ratnaṃ pratiprayacchasi, na ced vā nāgarikebhyaś coritakāni pratyarpayasi, drakṣyasi pāram aṣṭādaśānāṃ kāraṇānām ante ca mṛtyu-mukham” iti mayā tu smayamānenābhihitam — “saumya, yadyapi dadyām janmano muṣitaṃ dhanaṃ na tvarthapati-dārāpahāriṇaḥ śatror me mitra-mukhasya dhanamitrasya carmaratna-pratyāśāṃ pūrayeyam / adattvaiva tad ayutam api yātanānām anubhaveyam / iyaṃ me sādhīyasī sandhā” iti /
23.1その後、悲痛な叫び声を上げながら、シュリガーリカーが私のそばにやって来ました。私は敵に縛られました。しかし酔いを奪い去る災難によってたちまち目が覚め、その瞬間に湧いた機転で、私は考えました。「ああ、迷いがもとで大きな災難が降りかかった。ダナミトラが私と親しいことは広く知られているし、ラーガマンジャリーは私の妻だ。私の罪に覆われて、二人は明日きっと罰せられるだろう。ここは、私の指図どおりに行えば二人を救い、ひょっとすると私をもこの不運から救い出してくれる策を取らねばならない。」こうして自分一人である策を決めると、私はシュリガーリカーに言いました。「去れ、婆め。あの金目当ての忌々しい遊女、ラーガマンジャリーめを、革の宝に酔いしれた、友を装う我が敵ダナミトラと引き合わせたお前は、もうおしまいだ。あの悪党から革の宝を盗み、お前の娘から高価な装身具を奪ってやったのだから、今日、私は心残りなく命を捨てられる。」すると、目配せをすぐに察する大した曲者の彼女は、涙ながらに声を詰まらせ、合掌して男たちに恭しく近づき、私の前で穏やかに頼みました。「皆様、盗まれた私どもの財がどこにあるか、この者から聞き出すまで、しばらくお待ちください。」彼らが承知すると、再び私に近寄って「旦那様、この婢の一度の過ちをお許しください。あなたの奥方に手を出したダナミトラは、恨むならお恨みなさいませ。けれども長年お仕えしてきたことを思い出して、婢のラーガマンジャリーにはお情けをおかけください。容姿で生きる者には装身具こそが財産なのです。どうか、あの子の装身具をどこに隠したのかお教えください」と言って、私の足元にひれ伏しました。そこで私は哀れむふりをして「まあよい、死神の手中にある私が、あの女を恨み続けても何になろう」と言い、それを告げるふりをして、彼女の耳元で「これこれのようにせよ」と教えました。すると彼女は事情を呑み込んだ様子で、「長生きなさいませ。神々があなたにお恵みを垂れますように。アンガの王様もあなたの男らしさに感じ入って、お赦しくださいますように。この皆様方もあなたに情けをおかけくださいますように」と言って、たちまち立ち去りました。私は治安長官の命令で牢獄へ連れて行かれました。翌日、傲慢で美男を自称するカーンタカという名の治安官がやって来て、私を少々脅してこう言いました。「ダナミトラの革の宝を返さなければ、十八種の拷問を経た果てに死の淵を見ることになるぞ。」私は微笑んで答えました。「たとえ生まれてから盗んだ財をすべて返すとしても、アルタパティの妻を奪った、友の顔をした我が敵ダナミトラの、革の宝への望みだけはかなえてやる気はない。渡さずとも一万もの責め苦に耐えよう。これが私の最後の取引だ。」
tenaiva krameṇa vartamāne sāntvana-tarjana-prāye pratidinam anuyoga-vyatikare 'nuguṇānna-pāna-lābhāt katipayair evāhobhir viropita-vraṇaḥ prakṛti-stho 'ham āsam / atha kadācid acyutāmbara-pītātapa-tviṣi kṣayiṇi vāsare hṛṣṭa-varṇā śṛgālikojjvalena veṣeṇopasṛtya dūra-sthānucarā mām upaśliṣyābravīt — “ārya, diṣṭyā vardhase / phalitā tava su-nītiḥ / yathā tvayādiśye tathā dhanamitram etyābravam — ārya tavaivam āpannaḥ suhṛd ityuvāca “aham adya veśa-saṃsarga-sulabhāt pāna-doṣād baddhaḥ / tvayā punar aviśaṅkam adyaiva rājā vijñāpanīyaḥ — “deva, deva-prasādād eva purāpi tad ajina-ratnam arthapati-muṣitam āsāditam / atha tu bhartā rāgamañjaryāḥ kaścid akṣadhūrtaḥ kalāsu kavitveṣu loka-vārtāsu cāti-vaicakṣaṇyān mayā samasṛjyata tat-sambandhāc ca vastrābharaṇa-preṣaṇādinā tad-bhāryāṃ pratidinam anvavarte / tad asāv aśaṅkiṣṭa nikṛṣṭāśayaḥ kitavaḥ / tena ca kupitena hṛtaṃ tac carmaratnam ābharaṇa-samudgakaś ca tasyāḥ / sa tu bhūyaḥ steyāya bhramann agṛhyata nāgarika-puruṣaiḥ / āpannena cāmunānusṛtya rudatyai rāgamañjarī-paricārikāyai pūrva-praṇayānuvartinā tad-bhāṇḍa-nidhānoddeśaḥ kathitaḥ / mamāpi carmaratnam upāyopakrānto yadi prayacched iha deva-pādaiḥ prasādaḥ kāryaḥ iti / tathā niveditaś ca narapatir asubhir mām aviyojyopacchandanair eva svaṃ te dāpayituṃ prayatiṣyate tan naḥ pathyam” iti /
23.2このようにして、なだめすかしと脅しの入り混じった取り調べが毎日続くうちに、まずまずの食べ物と飲み物を与えられたおかげで、数日のうちに傷も癒え、私は元どおりの体に戻りました。ある時、ヴィシュヌの黄衣のように日差しが黄ばむ夕暮れ時、晴れやかな顔色のシュリガーリカーが華やかな装いで訪れ、付き添いを遠ざけて私に抱きつき言いました。「旦那様、ご無事で何より。あなたの巧みな策が実を結びました。あなたの指示通りにダナミトラのもとへ行き『旦那様、窮地に陥ったあなたの友がこう言っております』と伝えました。するとダナミトラは『今日すぐ何の心配もなく王に申し上げよ——陛下のお力添えにより、あの革の宝は以前アルタパティに盗まれたものを取り戻しました。ところがラーガマンジャリーの夫であるある賭博師が、技芸や詩歌や世間話において抜群に巧みであったため私は親しくなり、その縁で衣裳や装身具の贈り物で毎日彼の妻に言い寄りました。その卑しい心の賭博師はこれを怪しみ、怒って革の宝と彼女の宝石箱を盗みました。その者がまた盗みに出歩いているところを夜警に捕えられました。窮地の彼女に従い、泣くラーガマンジャリーの侍女に以前の誼で革袋の隠し場所を教えました。もし私にも革の宝が策を施せば返ってくるなら、陛下のお慈悲を賜りたい——と。』こう王に届けられれば、命は助かり、懐柔策だけで全てを返させようとするでしょう。これで万事うまくいきます。」

ānayainam” iti / athānītenāmunā man-mocanāya śapathaḥ kṛtaḥ, ahaṃ ca rahasyānirbhedāya vinigaḍīkṛtaś ca snāna-bhojana-vilepanānyanubhūya nityāndhakārād bhitti-koṇād ārabhyoragāsyena suraṅgām akaravam /
23.3ダナミトラはこれを聞くと、あなた様のお力を信じて、さほど恐れることもなく、そのとおりに運んでくれました。それから私は、あなた様の合図の品を見て私を信用したラーガマンジャリーから望むだけの金品を受け取り、あなた様に教えられたやり方で、王女アンバーリカーの乳母マーンガリカーの心をつかみました。彼女を橋渡しにして、ラーガマンジャリーとアンバーリカーの間に深い友情を育てました。毎日新しい贈り物を届け、心を惹く面白い話をしてさしあげて、私は王女のこの上ないお気に入りとなりました。ある日、王女が楼上におられた時、きちんと付いている耳飾りの青蓮を「ずれております」と言って直すふりをし、うっかりしたように落とし、地面から拾い上げると、何かの用で王女の館のそばの中庭に入って来たカーンタカめがけて、壁の穴の鳩を追い払うふりをして、笑いながら投げつけました。彼はそれで自分を果報者と思い込み、少し顔を上げて微笑みました。私の仕業に笑い出した王女の艶やかな表情を、自分への恋心から出たものと思い込むように、私も身振りで巧みに合図を送りました。弓を引き絞った愛神の、結果も定かでない矢に射抜かれて、すっかり心を奪われた彼は、ようやくのことで立ち去りました。夕方、王女の指輪で封をし、香りのよいキンマと絹の衣一対と装身具の一部を入れた籠を、ある少女に持たせ、「ラーガマンジャリーさまへ」と言って運び出し、カーンタカの家へ行きました。底知れぬ恋の海に溺れていた彼は、舟を見つけたかのように私を迎えて大いに喜び、私が王女の恐ろしいほどの恋煩いのさまを語って聞かせると、あの愚か者はすっかり狂わんばかりになりました。彼に頼まれて、翌日私は「あなたの恋人から」と言って、自分の口から出したキンマの残りや塗香、使い古しの花輪や汚れた衣を届けました。彼の品は「王女さまに」と言って受け取り、こっそり捨ててしまいました。こうして恋の火を燃え上がらせた彼に、私は人目のない所でこう持ちかけました。「旦那様、あなたの吉相は決して外れません。私の隣に住む占い師が『この国はカーンタカの手に落ちる、彼にはそういう相がある』と申しておりましたが、そのとおりに、この王女様はあなたを慕っておいでです。王様には王女様しかお子がないので、あなたが王女様と結ばれたと知ってお怒りになっても、王女様が死んでしまうことを恐れて、あなたを滅ぼしはなさいますまい。それどころか皇太子の位にお就けになるでしょう。この話は利が利を呼ぶのです。どうしてお進めにならないのですか。もし王女様の館に入る手立てがお分かりにならないのなら、牢獄の壁から庭園の塀までは三尋しかありません。腕のよい盗人にそれだけの長さの地下道を掘らせて庭に入られれば、そこから先の守りは私どもが引き受けます。王女様のお付きの者たちはみな深く慕っておりますから、秘密を漏らしはいたしません。」彼は言いました。「よく教えてくれた。穴掘りにかけてはサガラ王の息子たちにも劣らぬ盗人がいる。あの者を使えば、たちまちやり遂げるだろう。」私が「それは誰で、どうすれば使えるのですか」と尋ねると、「ダナミトラの革の宝を盗んだ男だ」と、あなた様のことを名指しました。私は言いました。「それなら、こうなさいませ。『この仕事をやり遂げたら、あれこれ手を尽くしてお前を釈放してやる』と誓って約束し、事が済んだら再び足枷をはめ、王様には『あの盗人をあらゆる手で責めましたが、図太い上に恨みが深く、革の宝のありかを明かしません』と申し上げて、何か変わった刑で殺しておしまいなさい。そうすれば目的も果たせ、秘密も漏れません。」すると彼は大喜びで承知し、あなた様を誘い込む役を私に任せて、外で待っております。この先どうするか、お考えください。」私は喜んで言いました。「私の教えたことはわずかだ。ここでは、そなたの策こそが大きい。その男を連れて来い。」連れて来られたカーンタカは、私を釈放すると誓いました。私は秘密が漏れぬようにという配慮から足枷を外され、入浴・食事・塗油の待遇を受けた上で、いつも真っ暗な壁の角を起点にして、蛇の口のような鑿で地下道を掘り始めました。
注Kale注（pp. 87-88）：カーンタカ（kāntaka）は治安官（nāgarika）の息子で、王女アンバーリカーに恋をしている。この盗賊に地下道を掘らせて王女の寝所に忍び込もうという取引が成立する。oragāsya（蛇の口のような鑿）は盗賊の専門道具。suraṅgā（地下道）の掘削は『アルタシャーストラ』にも記述される攻城術の一つだが、ここでは恋愛の文脈に転用されている。

24眠れる王女と盗賊の恋

acintayaṃ caivam “hantu-manasaivāmunā man-mocanāya śapathaḥ kṛtaḥ tad enaṃ hatvāpi nāsatya-vāda-doṣeṇa spṛśye” iti / niṣpatataś ca me nigaḍanāya prasāryamāṇa-pāṇes tasya pādenorasi nihatya patitasya tasyaivāsidhenvā śiro nyakṛntam /
24.1私はこう考えました。「奴は私を殺すつもりで釈放の誓いを立てたのだ。だから奴を殺しても嘘つきの咎めには当たらぬ。」地下道から出る時、私を縛ろうと手を伸ばしてきた彼の胸を足で蹴り、倒れた彼の首を彼自身の剣で刎ねました。
akathayaṃ ca śṛgālikām “bhaṇa bhadre, kathaṃbhūtaḥ kanyāpura-saṃniveśaḥ? mahān ayaṃ prayāso mā vṛthaiva bhūt / amutra kiñcic corayitvā nivartiṣye” iti / tad-upadarśita-vibhāge cāvagāhya kanyāntaḥpuraṃ prajvalatsu maṇi-pradīpeṣu naika-krīḍā-kheda-suptasya para-janasya madhye mahita-mahārgha-ratna-pratyupta-siṃhākāra-danta-pāde haṃsatūla-garbha-śayyopadhāna-śālini kusuma-vicchurita-paryante paryaṅka-tale dakṣiṇa-pāda-pārṣṇyadhobhāgānuvalitetara-caraṇāgra-pṛṣṭham īṣad vivṛtta-madhura-gulpha-saṃdhi, parasparāśliṣṭa-jaṅghā-kāṇḍam, ākuñcita-komalobhaya-jānu kiñcid vellitoru-daṇḍa-yugalam, adhinitamba-srasta-muktaika-bhuja-latāgra-peśalam, apāśrayānta-nimitākuñcitetara-bhuja-latottāna-tala-kara-kisalayam, ābhugna-śroṇi-maṇḍalam, atiśliṣṭa-cīnāṃśukāntarīyam, anativalita-tanutarodaram, atanutara-niḥśvāsārambha-kampamāna-kaṭhora-kuca-kuḍmalam, atiraścīna-bandhura-śirodharoddeśa-dṛśyamāna-niṣṭapta-tapanīya-sūtra-paryasta-padmarāga-rucakam, ardha-lakṣyādhara-karṇa-pāśa-nibhṛta-kuṇḍalam, upari-parāvṛtta-śravaṇa-pāśa-ratna-karṇikā-kiraṇa-mañjarī-piñjarita-viṣaya-vyāviddhāśithila-śikhaṇḍa-bandham, ātma-prabhā-paṭala-durlakṣya-pāṭalottarādhara-vivaram, gaṇḍa-sthalī-saṃkrānta-hasta-pallava-darśita-karṇāvataṃsa-kṛtyam, upari kapolādarśa-tala-niṣakta-citra-vitāna-patra-jāta-janita-viśeṣaka-kriyam, āmīlita-locanendīvaram, avibhrānta-bhrū-patākam, udbhidyamāna-śramajala-pulaka-bhinna-śithila-candana-tilakam, ānanendu-saṃmukhālaka-lataṃ ca viśrabdha-prasuptām ati-dhavalottaracchada-nimagna-prāyaika-pārśvatayā cira-vilasana-kheda-niścalāṃ śarad-ambhodharotsaṅga-śāyinīm iva saudāminīṃ rāja-kanyām apaśyam /
24.2私はシュリガーリカーに言いました。「おい、王女の館の造りはどうなっている。これほど骨を折ったのだ、無駄にはしたくない。あそこで何か盗んでから戻ってこよう。」（シュリガーリカーが教えてくれた）配置図に従って王女の宮殿深くに入り込みました。宝石の灯火が輝く中、遊び疲れて眠りこけた侍女たちの間に、高貴な宝石を嵌め込んだ獅子の姿の象牙の脚の寝台にハンサ鳥の羽毛を詰めた褥を載せ、花を散らした縁飾りのある寝台の上に——右足の踵の下にもう一方の足の甲を重ね、甘やかなくるぶしの関節がわずかに曲がり、脛は互いに寄り添い、柔らかな両膝がやや曲がって腿の対がわずかに震え、臀部に深く沈んだ腰からひとつの蔓のような腕の先が優美に垂れ、もう一方の腕は枕の陰でやや曲がり手のひらを上に向けた花の蕾のような指先を見せ、腰まわりは布に包まれ、絹のアンタリーヤが肌にぴったりと貼りつき、あまり撓まぬ細い腹は微かに、太い吐息の始まりに揺れる硬い乳房の紅のクンクマ色を見せ、ゆるやかに曲がった美しい首筋には練り上げた黄金の糸に貫かれたパドマラーガ宝石の首飾りが覗き、半ば見え隠れする下唇の傍の耳朶にはひっそりと耳飾りが留まり、裏返った耳朶の宝石の耳飾りの光の房に染められたあたりには乱れた髪の結い目が解けかかり、自らの輝きの帳に隠れるほのかな薔薇色の唇の隙間、頬に移った手の花弁が耳飾りの役目を見せ、頬の鏡面に貼りついた天蓋の彩色模様が額飾りの代わりとなり、閉じた蓮の蕾のような瞳、静かな弓なりの眉、にじむ汗の粒に崩れかけた白檀のティラカ、月のような顔に向かって垂れる額の巻き毛——こうして安らかに深く眠る王女は、あまりに白い掛布にほぼ片側を沈め、長い遊びの疲れに動かぬさまが、秋の雲の懐に横たわる稲妻のようでした。
dṛṣṭvai va sphurad-anaṅga-rāgaś cakitaś corayitavya-nispṛhas tayaiva tāvac coryamāṇa-hṛdayaḥ kiṅkartavyatā-mūḍhaḥ kṣaṇam atiṣṭham / atarkayaṃ ca “na ced imāṃ vāmalocanām āpnuyāṃ na mṛṣyati māṃ jīvituṃ vasantabandhuḥ asaṃketita-parāmṛṣṭā ceyam ati-bālā vyaktam ārta-svareṇa nihanyān me manoratham /
24.3見た瞬間、恋の炎が燃え上がり、驚愕し、もはや何も盗む気が失せ、むしろ彼女に心を盗まれて、何をすべきかもわからぬまましばし立ち尽くしました。そして思い巡らしました——「もしこの美しい瞳の女を得られぬなら、カーマ神（春の友）は私を生かしてはおかぬだろう。しかし逢瀬の約束もなく手を触れれば、このいたいけな少女はきっと悲痛な声を上げて私の望みを打ち砕くだろう。
注Kale注（pp. 88-90）：王女アンバーリカーの眠りの描写は本作で最も有名な一節の一つ。haṃsatūlagarbhaśayyā（ハンサ鳥の羽毛を詰めた寝台）は王族の贅沢を示す定型表現。ダンディンはここで、頭から爪先まで王女の体の各部を下降的に描写する伝統的なnakhaśikhāvarṇana（爪先から頭までの身体描写）を逆転させ、足先から始めて顔に至る上昇的描写を用い、読者（および盗賊）の視線を誘導する。corayitavaya-nispṛhaḥ tayaiva tāvac-choryamāṇa-hṛdayaḥ（もはや何も盗む気がなく、むしろ彼女に心を盗まれている）という表現は、「盗賊が盗まれる」という逆説的比喩であり、ダンディンの機知の精華。

25寝台の傍の告白画

tato 'hamevāhanyeya / tad iyam atra pratipattiḥ” iti / nāgadanta-lagna-niryāsa-kalka-varṇitaṃ phalakam ādāya maṇi-samudgakād varṇavartikām uddhṛtya tāṃ tathā śayānāṃ tasyāś ca mām ābaddhāñjaliṃ caraṇa-lagnam ālikham
25.1そうなれば私自身が殺されてしまう。だからここはこうしよう。」と。そこで、象牙に付着した樹液の練り物で描かれた画板を取り上げ、宝石の小箱から絵筆を取り出して、このように眠る彼女と、合掌して足元にひれ伏す自分の姿を描きました。
āryāṃ caitām- “tvām ayam ābaddhāñjali dāsa-janas tam imam artham arthayate / svapihi mayā saha surata-vyatikara-khinneva mā maivam ” //
25.2そしてこのアーリヤー詩を添えました。「合掌して控えるこの下僕は、あなた様にただ一つお願い申し上げます――どうか私と共にお眠りください、あたかも情事の疲れで眠り込んだかのように。」
注Kale注（pp. 89-90）：本章における唯一のアーリヤー韻律の詩句。盗賊が宝石箱から絵具を取り出し、眠る王女と自分を描くという場面は、ダンディンが散文叙事詩中に稀に挿入する韻文の効果を巧みに利用している。この詩は機知に富み、表面上は「共に眠れ」と懇願しているが、「情事の後のように」という比喩が、まだ起こっていない恋を既成事実のように示唆する。

26嚙檳榔の交換と地下道での脱出

hema-karaṇḍakāc ca vāsa-tāmbūla-vīṭikāṃ karpūra-sphuṭikāṃ pārijātakaṃ copayujyālaktaka-pāṭalena tad-rasena sudhā-bhittau cakravāka-mithunaṃ niraṣṭhīvam / aṅgulīyaka-vinimayaṃ ca kṛtvā kathaṅ katham api niragām /
26.1金の手箱から檳榔の噛みものと樟脳の粒とパーリジャータカの花を取って味わい、赤い口紅の色をした液で、白い壁に鴛鴦（チャクラヴァーカ）のつがいを吐き出すように描きました。指輪を交換し、どうにかして脱出しました。
suraṅgayā ca pratyetya bandhāgāraṃ tatra baddhasya nāgarika-varasya siṃhaghoṣa-nāmnas teṣveva dineṣu mitratvenopacaritasya “evaṃ mayā hatas tapasvī kāntakaḥ, tat tvayā pratibhidya rahasyaṃ labdhavyo mokṣaḥ” ityupadiśya saha śṛgālikayā nirakrāmiṣam /
26.2地下道を通って牢獄に戻り、同じ日々の間に友として世話をしていた獄中の貴公子シンハゴーシャに「このようにして私はあの哀れなカーンタカを殺した。お前は秘密を暴露することで自由を得るがよい」と教え、シュリガーリカーと共に脱出しました。

27夜警からの脱出——老女の機転

nṛpati-pathe ca samāgatya rakṣika-puruṣair agṛhye / acintayaṃ ca “alam asmi javenāpasartum anāmṛṣṭa evaibhiḥ / eṣā punar varākī gṛhyeta / tad idam atra prāptarūpam” iti tān eva capalam abhipatya sva-pṛṣṭha-samarpita-kūrparaḥ parāṅmukhaḥ sthitvā “bhadrāḥ, yadyaham asmi taskaraḥ badhnīta mām / yuṣmākam ayam adhikāraḥ, na punar asyā varṣīyasyāḥ” ityavādiṣam /
27.1王の大道に出たところで夜警に捕まりました。私は考えました。「速さで逃げることはできるが、この者たちに触れずにおけば、代わりにこの哀れな老女が捕まるだろう。ここはこうするのが適切だ。」そこで彼らに素早く突進し、両肘を背に回して後ろ向きに立ち、こう言いました。「諸君、私が盗賊なら縛るがよい。それが諸君の職務だ。だがこの老婦人には関わるな。」
sā tu tāvataivonnīta-mad-abhiprāyā tān sapraṇāmam abhyetya “bhadra-mukhāḥ, mamaiṣa putro vāyugrastaś ciraṃ cikitsitaḥ / pūrvedyuḥ prasanna-kalpaḥ prakṛti-stha eva jātaḥ / jātāsthayā mayā bandhanān niṣkramayya snāpito 'nulepitaś ca paridhāpya niṣpravāṇi-yugalam abhyavahārya paramānnamauśīre 'dya kāmacāraḥ kṛto 'bhūt / atha niśīthe bhūya eva vāyunighnaḥ “nihatya kāntakaṃ nṛpati-duhitrā rameya” iti raṃhasā pareṇa rāja-patham abhyapatat / nirūpya cāhaṃ putram evaṅgatam asyāṃ velāyām anudhāvāmi / tat prasīdata / baddhvainaṃ mahyamarpayata” iti yāvadasau krandati tāvad ahaṃ “sthavire, kena devo mātariśvā baddha-pūrvaḥ / kim ete kākāḥ śauṅgeyasya me nigrahītāraḥ / śāntaṃ pāpam” ityabhyadhāvam /
27.2するとシュリガーリカーは即座に私の意図を察し、夜警たちに恭しく近づいてこう訴えました。「皆さま、この者は私の息子で、長い間ヴァーユ（風の神＝狂気）に取り憑かれて治療を受けていたのです。昨日はほぼ正気に戻り、回復したかに見えました。安心した私は牢から連れ出し、沐浴させ塗油を施し、上等の衣を着せて最高のご馳走を食べさせ、今日は好きにさせていたのです。ところが真夜中に再びヴァーユに打たれ、『カーンタカを殺して王女と戯れてやる』と猛然と王の大道に飛び出したのです。息子がこのありさまなのを見て、この刻限に追いかけてまいりました。どうかお慈悲を。縛ってこの私にお渡しください。」と泣き叫ぶのを聞いて、私は「婆さん、誰が風の神を縛れたことがあるか！ こいつらが鷲の子の俺を捕まえられるとでも？ とんでもない！」と叫んで走り出しました。
注Kale注：vāyugrasta（風の神に取り憑かれた）は「狂人」の意。シュリガーリカーの機転により、盗賊と老女が母と狂った息子を演じるという即興劇が展開される。mātariśvā（風の神ヴァーユの異名）は、vāyugrasta（風邪＝狂気に取り憑かれた）との掛詞になっている。このような即興の芝居は、『アルタシャーストラ』に記される盗賊の逃亡術の文学的変奏である。

28天眼回復と王女との密会

asāvapyamībhiḥ “tvam evonmattā yānunmatta ityunmattaṃ muktavatī / kas tam idānīṃ badhnātīti ninditā kadarthitā rudatyeva mām anvadhāvat / gatvā ca rāgamañjarī-gṛhaṃ cira-viraha-kheda-vihvalām imāṃ bahuvidhaṃ samāśvāsya taṃ niśā-śeṣam anayam / pratyūṣe punar udārakeṇa ca samagacche / atha bhagavantaṃ marīciṃ veśa-kṛcchrād utthāya punaḥ pratitapta-tapaḥ-prabhāva-pratyāpanna-divya-cakṣuṣam upasaṃgamya tenāsmyevaṃbhūta-tvad-darśanam avagamitaḥ /
28.1彼女もまた、彼らに「狂った男を『狂っていない』と言って放した、お前こそ狂っている。いまさら誰があいつを捕まえられるものか」と罵られ、責め立てられ、泣きながら私の後を追って来ました。私はラーガマンジャリーの家へ行き、長い別離の辛さにうちひしがれていた彼女をさまざまに慰めて、残りの夜を過ごしました。夜明けにはまたウダーラカ（ダナミトラ）と落ち合いました。それから尊きマリーチ仙を訪ねました。遊女の災いから立ち直り、再び苦行の力で天眼を取り戻した仙人のもとに赴き、こうした経緯であなた様のありかを知らされたのです。
siṃhaghoṣaś ca kāntakāpacāraṃ nirbhidya tat-pade prasannena rājñā pratiṣṭhāpitaḥ tenaiva cāraka-suraṅgā-pathena kanyāpura-praveśaṃ bhūyo 'pi me samapādayat / samagaṃsi cāhaṃ śṛgālikā-mukha-niḥsṛta-vārtānuraktayā rāja-duhitrā /
28.2シンハゴーシャはカーンタカの悪行を暴露し、好意を示した王に復権させられ、あの牢獄からの地下道を使って、再び私の王女の宮殿への潜入を手配してくれました。そしてシュリガーリカーの口から伝わった噂によって心惹かれていた王女と、ついに結ばれたのです。

29チャンパーの危機と英雄的救出

teṣv eva divaseṣu caṇḍavarmā siṃhavarmāvadhūta-duhitṛ-prārthanaḥ kupito 'bhiyujya puram avāruṇat / amarṣaṇaś cāṅga-rājo yāvad ariḥ pāragrāmikaṃ vidhim ācikīrṣati tāvat svayam eva prākāraṃ nirbhidya pratyāsannān api sahāyān apratīkṣamāṇo nirgatyābhyadhika-balena vidviṣā mahati saṃparāye bhinna-varmā siṃhavarmā balād agṛhyata /
29.1ちょうどその頃、チャンダヴァルマンがシンハヴァルマンの娘との婚姻要求を拒絶されて怒り、攻め寄せて都を包囲しました。気性の激しいアンガの王は、敵が攻城の手立てを講じようとしているうちに、自ら城壁を破って出撃し、近くまで来ていた援軍をも待たずに戦いました。大戦の末、鎧を打ち砕かれたシンハヴァルマンは、勢力で勝る敵に力ずくで捕えられました。
ambālikā ca balavad abhigṛhya caṇḍavarmaṇā haṭhāt pariṇetum ātma-bhavanam anīyata / kautukaṃ ca sa kila kṣapāvasāne vivāha ityabadhnāt /
29.2アンバーリカーも力ずくで捕えられ、チャンダヴァルマンは強引に自分の館に連れ去り、明け方に婚礼を挙げると言って、吉祥の紐を結びました。
ahaṃ ca dhanamitra-gṛhe tad-vivāhāyaiva pinaddha-maṅgala-pratisaras tam evam avocam “sakhe, samāpatitam evāṅga-rājābhisaraṃ rāja-maṇḍalam / su-gūḍham eva saṃbhūya pauravṛddhais tad upāvartaya / upāvṛttaś ca kṛtta-śirasam eva śatruṃ drakṣyasīti /
29.3私はダナミトラの家で、まさにその婚礼のために吉祥の紐を腕に巻いたまま、彼にこう言いました。「友よ、アンガの王を救うべく諸王の同盟軍がすでに到着しつつある。密かに都の長老たちと合流して、彼らを味方に引き入れよ。戻ってくれば、敵は首を刎ねられているのを目にするだろう。」
“tathā” iti tenābhyupagate gatāyuṣo 'muṣya bhavanam utsavākulam upasamādhīyamāna-pariṇayopakaraṇam itas tataḥ praveśa-nirgama-pravṛtta-loka-saṃbādham alakṣya-śastrikaḥ saha praviśya maṅgala-pāṭhakair ambālikā-pāṇi-pallavam agnau sākṣiṇyātharvaṇena vidhinārpyamāṇam āditsamānasyāyāminaṃ bāhu-daṇḍam ākṛṣya churikayorasi prāharṣam / sphurataś ca katipayān anyān api yama-viṣayam agamayam /
29.4「承知した」と彼が引き受けると、命運尽きたチャンダヴァルマンの館に、祝祭の準備に沸き立ち人の出入りで混雑する中、武器を隠して紛れ込みました。祝福の僧侶たちがアンバーリカーの花のような手を火の神を証人としてアタルヴァ・ヴェーダの儀式に従って（チャンダヴァルマンの手に）差し出そうとしていたまさにその瞬間、長く伸ばされた腕を引き寄せ、小刀で胸を刺しました。動き出す残りの者たちも数人、冥界に送りました。

30物語の結び——主君との再会

hata-vidhvastaṃ ca tad-gṛham anuvicaran vepamāna-madhura-gātrīṃ viśāla-locanāmabhiniśāmya tad-āliṅgana-sukham anububhūṣus tām ādāya garbhagṛham avikṣam /
30.1殺され打ち壊された館を歩き回り、震える肢体の美しい大きな瞳の女を見つけ、抱擁の喜びを味わおうと彼女を抱き上げて奥の間に入りました。
asminn eva kṣaṇe tavāsmi navāmbuvāha-stanita-gambhīreṇa svareṇānugṛhītaḥ” iti /
30.2「まさにその瞬間、新しい雨雲の雷鳴のように深いあなた様のお声に恵まれたのです。」
śrutvā ca smitvā ca devo 'pi rājavāhanaḥ “katham asi kārkaśyena karṇīsutam apyatikrāntaḥ” ityabhidhāya punar avekṣyopahāravarmāṇam ācakṣva, tavedānīm avasaraḥ” ityabhāṣata /
30.3これを聞いて微笑んだラージャヴァーハナ王子は「何と、大胆さにおいてカルニースタ（伝説の盗賊の祖）をも凌いだとは」と述べ、次にウパハーラヴァルマンに目を向けて、「さあ語れ、次はそなたの番だ」と言いました。
so 'pi sasmitaṃ praṇamyārabhatābhidhātum //
30.4ウパハーラヴァルマンもまた微笑んで平伏し、語り始めました。
注Kale注：katham asi kārkasyena karṇīsutam api atikrāntaḥ（大胆さにおいてカルニースタをも凌いだ）——karṇīsuta は盗賊術の伝説的開祖で、『アルタシャーストラ』にも言及される。ラージャヴァーハナがこの名を引くのは、アパハーラヴァルマンの冒険が単なる盗みを超えた知略と勇気の物語であることへの賛辞。本章はダシャクマーラチャリタ全体の中で最も長く、最もピカレスクな章であり、遊女の社会学・賭博の技芸・盗賊術・地下道の掘削・婚礼場での暗殺など、古代インドの裏社会を百科全書的に描き出す。
