1ヴィデーハ到着と老乳母との出会い

eṣo 'smi paryaṭann ekadā gato videheṣu / mithilām apraviśyaiva bahiḥ kvacin maṭhikāyāṃ viśramitum etya kayāpi vṛddha-tāpasyā datta-pādyaḥ kṣaṇam alinda-bhūmāv avāsthiṣi / tasyās tu mad-darśanād eva kim apyābaddha-dhāram aśru prāvartata / “kim etad amba, kathaya kāraṇam” iti pṛṣṭā sakaruṇam ācaṣṭa —
1.1さて、私（ウパハーラヴァルマ）は（殿下を探して）遍歴の旅をしていたとき、ある時ヴィデーハ国に赴いた。ミティラー（首都）に入ることさえせず、城外のある僧院に休息のため立ち寄った。そこで、ある老齢の女行者に足を洗う水を差し出され、しばらく入口の敷居のところに腰を据えた。ところが、その老女は私の姿を見るなり、何やら止めどもない涙を流し始めた。「母よ、これは何事だ、理由を教えてくれ」と尋ねると、彼女は悲痛な調子で語り始めた——
注ヴィデーハ国はマガダ国の北東に位置した。首都ミティラーはネパールのジャナカプルと同定される（Kale注, p.103）。

2乳母の物語——プラハーラヴァルマンの没落

“jaivātṛka, nanu śrūyate patir asyā mithilāyāḥ prahāravarmā nāmāsīt / tasya khalu magadha-rājo rājahaṃsaḥ paraṃ mitram āsīt / tayoś ca vallabhe bala-śambalayor iva vasumatī-priyaṃvade sakhyam apratimam adhattām / atha prathama-garbhābhinanditāṃ tāṃ ca priya-sakhīṃ didṛkṣuḥ priyaṃvadā vasumatīṃ saha bhartrā puṣpapuram agamat / tasminn eva ca samaye mālavena magadha-rājasya mahaj janyam ajani / tatra leśato 'pi durlakṣyāṃ gatim agaman magadha-rājaḥ,
2.1「お命長かれ。よくお聞きなさい。このミティラーの王はプラハーラヴァルマンという方でした。マガダの王ラージャハンサは、まことにその親友でありました。両王の妃——ヴァスマティーとプリヤンヴァダー——は、あたかもバラとシャンバラ（二人の阿修羅）のように、比類なき友情を結んでおりました。初めての懐妊を祝われた親友ヴァスマティーを訪ねようと、プリヤンヴァダーは夫とともにプシュパプラ（パータリプトラ）へ参りました。まさにその折、マーラヴァ王とマガダ王の間に大戦争が起こり、マガダ王はいかなる運命を辿ったか、わずかにも知り得ない状態となりました。
注balaśambala（バラとシャンバラ）は二人のアスラ（阿修羅）の名。プシュパプラはパータリプトラ（現在のパトナ）の別名。

3ヴィカタヴァルマンの簒奪と乳母の逃亡

maithilendras tu mālavendra-prayatna-prāṇitaḥ sva-viṣayaṃ pratinivṛtto jyeṣṭhasya saṃhāravarmaṇaḥ sutair vikaṭavarma-prabhṛtibhir vyāptaṃ rājyam ākarṇya svasrīyāt suhma-pater daṇḍāvayavam āditsur aṭavī-padam avagāhya lubdhaka-lupta-sarvasvo 'bhūt / tat-sutena ca kanīyasā hastavartinā sahaikākinā vanacara-śara-varṣa-bhaya-palāyitā vanam agāhiṣi / tatra ca me śārdūla-nakhāvalīḍha-nipatitāyāḥ pāṇi-bhraṣṭaḥ sa bālakaḥ kasyāpi kapilā-śavasya kroḍam abhyalīyata / tacchavākarṣiṇaś ca vyāghrasyāsūn iṣur iṣvasana-yantra-muktaḥ kṣaṇād alikṣat /
3.1ミティラーの王（プラハーラヴァルマン）はマーラヴァ王の助力で命は助かりましたが、自国に帰ると兄サンハーラヴァルマンの息子ヴィカタヴァルマンらに王国を奪われていたことを知りました。姉の子であるスフマ国王から軍の一部を借りようとして森に入りましたが、そこで猟師たちに全てを奪われてしまいました。私は王の幼い方の王子を抱いて、森人たちの矢の雨を恐れて森の奥へ逃げ込みました。ところが虎の爪に打たれて倒れた私の手から、その幼子は落ち、ある褐色の死んだ牛の胸元に身を隠しました。その死骸を引きずっていた虎は弓から放たれた矢に一瞬にして命を奪われ、子供は森の子どもたちに連れ去られました。
注スフマ国はヴァンガ（東ベンガル）の西に位置し、その首都タームラリプタは現代のタムルク (Tumlook) と同定される（Kale注, p.104）。daṇḍāvayava（軍の一部）のdaṇḍaは「軍」の意（Raghuvaṃśa XVII.62参照）。
注śārdūla-nakhāvalīḍha-nipatitāyāḥ（虎の爪に引き裂かれて倒れた私の）――GRETILの nakhāvalījha- は意味をなさず、avalīḍha（引き裂かれた）の誤記と推定した。

4乳母の娘と青年の到来

bhilla-dārakaiḥ sa bālo 'pāhāri / sā tvahaṃ moha-suptā kenāpi vṛṣṇipālenopanīya svaṃ kuṭīram āveśya kṛpayopakrānta-vraṇā svasthībhūya sva-bhartur antikam upatiṣṭhāsur asahāyatayā yāvad vyākulībhavāmi tāvan mamaiva duhitā saha yūnā kenāpi tam evoddeśam āgamat / sā bhṛśaṃ ruroda / ruditānte ca sā sārtha-ghāte sva-hasta-gatasya rāja-putrasya kirāta-bhartṛ-hasta-gamanam, ātmanaś ca kenāpi vanacareṇa vraṇa-viropaṇam, svasthāyāś ca punas tenopayantuṃ cintitāyā nikṛṣṭa-jāti-saṃsarga-vaiklavyāt pratyākhyāna-pāruṣyam, tad-akṣameṇa cāmunā vivikte vipine sva-śiraḥ- kartanodyamam, anena yūnā yadṛcchayā dṛṣṭena tasya durātmano hananam, ātmanaś copayamanam ityakathayat /
4.1幼子はビッラ族の子どもたちに連れ去られました。私は気を失って倒れていたのを、ある牛飼いに拾われてその小屋に運ばれ、親切にも傷の手当てを受けました。回復して主人のもとに戻ろうとしましたが、助けもなく途方に暮れておりますと、まさにその場所に、ある若者を伴った私の娘がやって来ました。娘はひどく泣きました。泣き止んでから、彼女は語りました——隊商が襲われた時、手に抱いていた王子が山賊の頭目の手に落ちたこと、自分は森人に傷を癒されたこと、回復後にその森人が求婚してきたが卑しい身分との交わりへの嫌悪から断ったこと、それを承服できなかったその男が森の奥で彼女の首を斬ろうとしたこと、そしてたまたま通りかかったこの若者がその悪人を殺し自分を娶ったこと。

5両親の投獄と乳母の嘆き

sa tu pṛṣṭo maithilendrasyaiva ko 'pi sevakaḥ kāraṇa-vilambī tan-mārgānusāri-jātaḥ / saha tena bhartur antikam upasṛtya putra-vṛttāntena śrotram asya devyāḥ priyaṃvadāyāś cādahāva / sa ca rājā diṣṭa-doṣāj jyeṣṭha-putraiś ciraṃ vigṛhya punar asahiṣṇutayātimātraṃ ciraṃ prayudhya baddhaḥ / devī ca bandhanaṃ gamitā / dagdhā punar aham asminn api vārddhake hata-jīvitam apārayantī hātuṃ pravrajyāṃ kilāgrahīṣam / duhitā tu mama hata-jīvitākṛṣṭā vikaṭavarma-mahā-devīṃ kalpasundarīṃ kilāśiśriyat /
5.1尋ねてみると、その若者はミティラー王に仕える者で、何かの用事で遅れて、同じ道を辿っていたのでした。私たちはその若者とともに主人のもとに参り、王子たちの消息を王と妃プリヤンヴァダーの耳に注ぎ入れ、焼き焦がしました。王は運命の過ちにより兄の息子たちと長く争い、さらに耐え切れずに激しく長く戦い、ついに捕えられました。妃もまた投獄されました。不幸な私は、この老年になっても呪われた命を捨てることもできず、出家しました。一方、私の娘は、自らの不幸な命に引き寄せられるまま、ヴィカタヴァルマンの正妃カルパスンダリーに仕えるようになりました。

6ウパハーラヴァルマの正体告白

tau ced rāja-putrau nirupadravāv evāvardhiṣyetām, iyatā kālena tavemāṃ vayovasthām asprakṣyetām / tayoś ca sator na dāyādā narendrasya prasahya kāriṇo bhaveyuḥ” iti pramanyur abhiruroda / śrutvā ca tāpasī-giram aham api pravṛddha-bāṣpo nigūḍham abhyadhām “yadyevam amba, samāśvasihi / nanvasti kaścin munis tvayā tad-avasthayā putrābhyupapādanārthaṃ yācitas tena sa labdho vardhitaś ca / vārteyam ati-mahatī / kim anayā / so 'ham asmi /
6.1あの二人の王子たちが無事に育っておれば、今頃はあなた様と同じ年齢になっていたでしょう。王子たちが生きていれば、一族の者たちも王に対して暴虐を振るうことはなかったでしょう」——こう言って、彼女は悲しみを募らせ、激しく泣いた。女行者の言葉を聞いて私もまた涙があふれ、密かにこう言った——「もしそうであるなら、母よ、安心なさい。あなたがあの窮状の折に、息子を見つけ出してくれるよう頼んだ聖者がいただろう。その聖者に見出され、育てられたのだ。話は長い。要するに——それは私だ。
注「あなたがあの窮状の折に頼んだ聖者」——これはウパハーラヴァルマの推測であり、実際にはその女性から聖者への直接的な依頼はなかったとKaleは注記する（p.105）。

7ヴィカタヴァルマン打倒の謀略

śakyaś ca mayāsau vikaṭavarmā yathā kathañcid upaśliṣya vyāpādayitum / anujāḥ punar ati-bahavaḥ, tair api ghaṭante paura-jānapadāḥ / māṃ tu na kaścid ihatya īdṛktayā jano jānāti / pitarāvapi tāvan māṃ na saṃvidāte, kim utetare tam enam artham upāyena sādhayiṣyāmi” ityagādiṣam / sā tu harṣa-nirbhara-nipīḍitā ciraṃ prarudya bahu vilapya śāntā punaḥ sva-mātrā rājāntaḥpura-vṛttāntākhyāne nyayujyata /
7.1あのヴィカタヴァルマンを、何とかして近づき殺すことは私の力で可能だ。しかし、やつの弟たちも非常に多く、市民や住民は彼らとも結託するだろう。だが私のことを、ここでは誰もこれこれの者だとは知らない。両親でさえ私を知らないのだ、ましてや他の者たちは。だからこの仕事は策略によって成就しよう」——と私は語った。老女は歓喜に圧倒され、長く泣き、多くを嘆き、やがて静まると、母（老乳母）は娘を王宮内部の事情を語る役目に就けた。

8プシュカリカーによるカルパスンダリーの情報

uktaṃ ca tayā “kumāra, kāmarūpeśvarasya kalindavarma-nāmnaḥ kanyā kalpasundarī kalāsu rūpe cāpsaraso 'pyatikrāntā patim abhibhūya vartate / tad-eka-vallabhaḥ, sa tu bahvavarodho 'pi vikaṭavarmā” iti / tām avocam “upasarpaināṃ mat-prayuktair gandha-mālyaiḥ / upajanaya cāsamāna-doṣa-nindādinā sva-bhartari dveṣam / anurūpa-bhartṛgāminīnāṃ ca vāsavadattādīnāṃ varṇanena grāhayānuśayam / avarodhanāntareṣu ca rājño vilasitāni su-gūḍhānyapi prayatnenānviṣya prakāśayantī mānam asyā vardhaya” iti /
8.1そしてその娘（プシュカリカー）は言った——「王子様、カーマルーパ国王カリンダヴァルマンの娘カルパスンダリーは、技芸にも容貌にも天女たちをすら凌駕し、夫を見下しております。ヴィカタヴァルマンは彼女だけに執心しておりますが、彼自身は多くの後宮の女を持っております。」これを聞いて、私は娘に指示した——「私が調合した香料や花輪をもって彼女に近づけ。釣り合わぬ相手との結婚を非難するなどして夫への嫌悪を生じさせよ。ヴァーサヴァダッターなど、自分にふさわしい夫を得た女性たちの話を語って後悔の念を抱かせよ。また後宮の他の女たちとの王の密かな戯れを苦心して探り出し暴露して、彼女の嫉妬の怒りを高めよ」と。
注ヴァーサヴァダッター（Vāsavadattā）は、スバンドゥ作『ヴァーサヴァダッター』の女主人公。また、ウッジャイニーのチャンダマハーセーナの娘で、ウダヤナ王に連れ去られた（Kale注, p.106）。ダンディンはヴァーツヤーヤナの『カーマスートラ』V.4の策略をここで用いている。

9策謀の夜と乳母への指示

punar idam ambām avocam “ittham eva tvayāpyananya-vyāpārayā nṛpāṅganāsāvupasthātavyā / pratyahaṃ ca yad yatra vṛttaṃ tad asmi tvayaiva bodhyaḥ, mad-uktā punar iyam udarka-svāduno 'smat-karmaṇaḥ prasādhanāya chāyevānapāyinī kalpasundarīm anuvartatām” iti / tena ca tam arthaṃ tathaivānvatiṣṭhatām / keṣuciddineṣu gateṣvācaṣṭa māṃ mad-ambā “vatsa, mādhavīva picumandāśleṣiṇī yathāsau śocyam ātmānaṃ manyeta tathopapādya sthāpitā / kiṃ bhūyaḥ kṛtyam” iti /
9.1さらに老乳母にこう言った——「同様に、あなたも他の一切の仕事を離れてあの王妃に仕えなさい。毎日そこで起こったことを私に報告しなさい。また、私が指示したこの娘は、快い結末をもたらす我々の仕事を成就させるため、影のようにカルパスンダリーに付き従いなさい」と。二人はまさに私が望んだ通りにその任務を果たした。数日が経つと、乳母が私に告げた——「坊ちゃま、マーダヴィー蔓がニンバの木に絡みつくように自分を不幸だと思うよう、あの方は仕込まれ、そう思い定めました。次に何をすべきでしょうか」と。
注マーダヴィー蔓（Mādhavī, 春の蔓草）は芳香ある花を咲かせ、通常マンゴーの木に絡むが、苦いニンバの木に絡みつけば不幸な取り合わせとなる（Kale注, p.107）。

10肖像画をカルパスンダリーに送る

punar aham abhilikhyātmanaḥ pratikṛtim “iyam amuṣyai neyā / nītāṃ caināṃ nirvarṇya sā niyatam evaṃ vakṣyati / “nanvasti kaścid īdṛśākāraḥ pumān” iti / pratibrūhyenām “yadi syāt tataḥ kim” iti / tasya yad uttaraṃ sā dāsyati “tad aham asmi pratibodhanīyaḥ” iti /
10.1私は自分の似顔絵を描き、こう言った——「これを彼女のもとに持って行け。見せれば、彼女はきっとこう言うだろう——『このような姿の男が本当にいるのか』と。そうしたら彼女にこう問い返せ——『もしいたら、どうなさるのですか』と。彼女がどう答えるか、それを私に知らせよ」と。

11カルパスンダリーの反応と恋慕

sā “tathā iti rāja-kulam upasaṃkramya pratinivṛttā mām ekānte nyavedayat “vatsa, darśito 'sau citra-paṭas tasyai mattakāśinyai / citrīyamāṇā cāsau bhuvanam idaṃ sanāthīkṛtaṃ yad deve 'pi kusumadhanvani nedṛśī vapuḥ-śrīḥ saṃnidhatte / citram etac citrataram / na ca tam avaimi ya īdṛśam idam ihatyo nirmimīte / kenedam ālikhitam, ityādṛtavatī vyāhṛtavatī ca / mayā ca smerayodīritam “devi, sadṛśam ājñāpayasi / bhagavān makaraketur apy evaṃ sundaraṃ iti na śakyam eva saṃbhāvayitum / atha ca vistīrṇeyam arṇavanemiḥ / kvacid īdṛśam api rūpaṃ daiva-śaktyā saṃbhavet / atha tu yadyevaṃrūpo rūpānurūpa-śilpa-śīla-vidyā-jñāna-kauśalo yuvā mahā-kulīnaś ca kaścit saṃnihitaḥ syāt, sa kiṃ lapsyate” iti / tayoktam “amba, kiṃ bravīmi / śarīraṃ hṛdayaṃ jīvitam iti sarvam idam alpam anarhaṃ ca / tato na kiñcil lapsyate na ced ayaṃ vipralambhas tasyāmuṣya darśanānubhavena yathedaṃ cakṣuś caritārthaṃ bhavet tathānugrahaḥ kāryaḥ” iti /
11.1乳母は「承知しました」と言って王宮に赴き、戻ると密かに告げた——「坊ちゃま、あの絵をあの美女に見せました。驚嘆して彼女は言いました——『まことにこの世は恵まれたことだ。愛の神カーマにさえこれほどの美はないのに。この絵はなおさら不思議だ。このような絵をここで描ける者を私は知らない。誰がこれを描いたのか』——と、大いに関心を示して尋ねました。私は微笑んでこう答えました——『王妃様、ごもっともでございます。カーマ神ですらこれほど美しいとは到底思えません。しかし、この海に囲まれた大地は広うございます。どこかにこのような姿が、運命の力によって存在するかもしれません。もしこのような容貌を持ち、その美にふさわしい技芸・品性・学識・才知を兼ね備えた名門の若者がここにおりましたら、彼は何を得られるでしょうか』と。すると王妃は答えました——『母よ、何と申しましょう。我が体も、心も、命も、すべてわずかで彼にはふさわしくない。だから彼は何も得るものはないでしょう。もしこれが偽りでないなら、せめてこの目が見るという目的を果たせるよう、彼に会わせてください』と。」
注この報告をもたらすのはウパハーラヴァルマを「坊ちゃま」（vatsa）と呼ぶ乳母であり、続く第12節・第14節の語り手も乳母である。旧版はこれらを娘プシュカリカーの言葉としていたが誤り。

12策略の深化——王子の存在を告げる

bhūyo 'pi mayā dṛḍhatarīkartum upanyastam “asti ko 'pi rāja-sūnur nigūḍhaṃ caran / amuṣya vasantotsave saha sakhībhir nagaropavana-vihāriṇī ratir iva vigrahiṇī yadṛcchayā darśana-pathaṃ gatāsi / gataś cāsau kāma-śaraika-lakṣyatāṃ mām anvavartiṣṭa / mayā ca vām anyonyānurūpair anya-durlabhair ākārādibhir guṇātiśayaiś ca preryamāṇayā tad-racitair eva kusuma-śekhara-srag-anulepanādibhiś ciram upāsitāsi / sādṛśyaṃ ca svam anena svayam evābhilikhya tvat-samādhi-gāḍhatva-darśanāya preṣitam / eṣa ced artho niścitas tasyāmuṣyātimānuṣa-prāṇa-sattva-prajñā-prakarṣasya na kiñcid duṣkaraṃ nāma / tam adyaiva darśayeyam / saṃketo deyaḥ” iti /
12.1（乳母の報告の続き）「私はさらに王妃の心を固めるため、こう申し上げました——「ある王子が密かに暮らしております。春祭りの時、友たちと市の園林を逍遥なさっていたあなた様は、あたかも愛の神（ラティ）の化身のように、偶然彼の視界に入りました。彼はカーマの矢の唯一の的となった私のもとに取り入りました。私は、お二人の互いに釣り合い他に得がたい容姿や徳の卓越に動かされて、彼が調えた花冠・花環・塗香などで長くあなた様に奉仕してまいりました。彼は自ら自分の肖像を描き、あなた様への深い想いを示すために送ったのです。この件が定まれば、超人的な勇気・胆力・才知を持つ彼に不可能なことはありません。今日にも彼をお見せいたしましょう。逢瀬の場所をお決めください」と。

13カルパスンダリーの告白——父の約束

tayā tu kiñcid iva dhyātvā punar abhihitam — “amba, tava naitad idānīṃ gopyatamam / ataḥ kathayāmi / mama tātasya rājñā prahāravarmaṇā saha mahatī prītir āsīt / mātuś ca me mānavatyāḥ priya-vayasyā devī priyaṃvadāsīt / tābhyāṃ punar ajātāpatyābhyām eva kṛtaḥ samayo 'bhūt — “āvayoḥ putramatyāḥ putrāya duhitṛmatyā duhitā deyā” iti / tātas tu māṃ jātāṃ pranaṣṭāpatyā priyaṃvadeti prārthayamānāya vikaṭavarmaṇe daivād dattavān /
13.1少し考えてから王妃は答えた——「母よ、もうこれは隠すまい。打ち明けましょう。私の父の王はプラハーラヴァルマンと大変な親友でした。母マーナヴァティーもまた妃プリヤンヴァダーの親友でした。両家はまだ子のなかった頃にこう約束を交わしていました——『息子を持つ方が、娘を持つ方の娘を嫁にもらう』と。ところが、プリヤンヴァダーの息子たちが失われたので、父は運命のいたずらにより、求婚してきたヴィカタヴァルマンに私を与えてしまったのです。

14ヴィカタヴァルマンへの不満

ayaṃ ca niṣṭhuraḥ pitṛ-drohī nāpyupapanna-saṃsthānaḥ kāmopacāreṣv alabdha-vaicakṣaṇyaḥ kalāsu kāvya-nāṭakādiṣu mandābhiniveśaḥ śauryonmādī durvikatthano 'nṛta-vādī cāsthāna-varṣī / nātirocate ma eṣa bhartā viśeṣataś caiṣu vāsareṣu yad ayam udyāne mad-antaraṅga-bhūtāṃ puṣkarikām apy upānta-vartinīm anādṛtya mayi baddha-sāpatnya-matsarām anātma-jñām ātma-nāṭakīyāṃ ramayantikāṃ nāmāpatya-nirviśeṣaṃ mat-saṃvardhitāyāś campaka-latāyāṃ svayam avacitābhiḥ sumanobhir alamakārṣīt / mad-upabhukta-mukte citrakūṭa-garbha-vedikā-gate ratna-talpe tayā saha vyahārṣīt / ayogyaś ca pumān avajñātaṃ ca pravṛttaḥ / tat kim ityapekṣyate para-loka-bhayaṃ caihikena duḥkhenāntaritam / aviṣahyaṃ hi yoṣitām anaṅga-śara-niṣaṅgībhūta-cetasām aniṣṭa-jana-saṃvāsa-yantraṇāduḥkham / ato 'munā puruṣeṇa mamādyodyāna-mādhavī-gṛhe samāgamaya / tad-vārttā-śravaṇa-mātreṇaiva hi mamātimātraṃ mano 'nuraktam / asti cāyam artha-rāśiḥ / anenāmuṣya pade pratiṣṭhāpya tam evātyantam upacarya jīviṣyāmi” iti /
14.1この夫は残酷で父に背く者、容貌も均整がとれておらず、閨事にも技が無く、詩や演劇などの芸術にもさして関心がなく、武勇を鼻にかけ、空しく自慢する嘘つきで、ふさわしくない者に恩を施す。とりわけ最近、この男は庭園で、私の腹心の侍女プシュカリカーが傍に控えているのに顧みず、私に側室としての嫉妬を抱く、身の程も知らぬ、王お抱えの踊り子ラマヤンティカーなる者を——私が子のように育てたチャンパカの蔓から自ら摘んだ花で飾り立て、私が使ったのち空けた洞窟状の丘の中の壇上の宝石の寝台の上で彼女と戯れたのだ。この男は私にふさわしくなく、今や侮辱を加え始めた。だから何を彼に遠慮することがあろうか。来世への恐れなど、現世の苦しみに遮られている。愛の矢の矢筒と化した心を持つ女にとって、嫌いな男との同居を強いられる苦しみは耐えがたいものだ。だから今日、庭園のマーダヴィーの東屋であの方と会わせてくれ。彼の消息を聞いただけで、私の心は深く惹かれているのだ。この財宝がある。これで彼をヴィカタヴァルマンの地位に据え、ただ彼だけに仕えて生きよう」と。
mayāpi tad abhyupetya pratyāgatam / ataḥ paraṃ bhartṛdārakaḥ pramāṇam” iti /
14.2乳母は話を結んだ——「私もこの頼みを承知して戻って参りました。この先のことは若様のご判断次第です」と。

15夕暮れの逢引——王宮の庭園に潜入

tatas tasyā eva sakāśād antaḥpura-niveśam antarvaṃśika-puruṣa-sthān pramada-vana-pradeśān api vibhāgenāvagamya, asta-giri-kūṭa-pāta-kṣubhita-śoṇita iva śoṇībhavati bhānu-bimbe, paścimāmbudhi-payaḥ-pāta-nirvāpita-pataṅgāṅgāra-dhūma-saṃbhāra iva bharita-nabhasi tamasi vijṛmbhate, para-dāra-parāmarśonmukhasya mamācāryakam iva kartum utthite guru-parigraha-ślāghini grahāgresare kṣapākare, kalpasundarī-vadana-puṇḍarīkeṇeva mad-darśanāti-rāga-prathamopanatena smayamānena candra-maṇḍalena saṃdhukṣyamāṇa-tejasi bhuvana-vijigīṣodyate deve kusumadhanvani, yathocitaṃ śayanīyam abhaje /
15.1そこでその乳母から、内宮の配置、警備の者たちの持ち場、さらに遊苑の区画を詳しく聞き出した。太陽の円盤が没山の頂に落下して血をかき立てられたかのように赤く染まり、西の海に落ちた太陽という燃えかすの消火による煙の塊のごとく闇が空に満ちわたり、他人の妻を犯さんとする私にあたかも教導を施さんと、師の妻を慕うことで名高いグラハ（惑星）の長たる月が昇り、カルパスンダリーの顔という白蓮のような——私を見たいという激しい恋慕をもって最初に差し出された——微笑む月輪にその勇気を炽（おこ）された花の弓の神（カーマ）が世界征服に乗り出すとき、私はしかるべき寝床についた。
注guruparigrahaślāghin（師の妻を羨慕する者）は月（チャンドラ）がブリハスパティの妻ターラーを連れ去った故事を指す（Kale注, p.111）。ダンディンは、他人の妻を犯す行為について、月が「先達」であるという皮肉を込めている。

16道徳的省察とガネーシャの夢

vyacīcaraṃ ca “siddha-prāya evāyam arthaḥ / kintu para-kalatra-laṅghanād dharma-pīḍā bhavet, sāpyartha-kāmayor dvayor upalambhe śāstra-kārair anumata iveti / guru-jana-bandha-mokṣopāya-saṃdhinā mayā caiṣa vyatikramaḥ kṛtaḥ, tad api pāpaṃ nirhṛtya kiyatyāpi dharma-kalayā māṃ samagrayed iti / api tvetad ākarṇya devo rājavāhanaḥ suhṛdo vā kiṃ nu vakṣyanti” iti cintā-parādhīna eva nidrayā parāmṛśye / adṛśyata ca svapno hastivaktro bhagavān /
16.1そして思案した——「この仕事はほぼ成就した。だが他人の妻を犯すことはダルマ（法）に反する。しかしその反面、アルタ（実利）とカーマ（快楽）の二つを得ることは、法典の著者たちにも容認されている。私はまた親族の救出という手段によってこの越権をなしたのであるから、その罪もまた贖い、何がしかのダルマの部分をもって私を浄めてくれるだろう。しかし、これを聞いて殿下ラージャヴァーハナは、あるいは友人たちは何と言うだろう」——こう憂いに沈んだまま、眠りに捕えられた。すると夢に象の顔をした神（ガネーシャ）が現れた。
注pāratalpika（他人の妻との密通）の道徳的正当化は、この章のテーマである。ダンディンは「目的が手段を正当化する」という議論を展開し、ラージャヴァーハナが章末にこれを肯定する。Kale注（p.111）：dharmapīḍā = violation of religious law。

17ガネーシャの啓示

āha sma ca “saumya upahāravarman, mā sma te durvikalpo bhūt / yatas tvam asi mad-aṃśaḥ / śaṅkara-jaṭā-bhāra-lālanocitā surasarid asau varavarṇinī / sā ca kadācin mad-viloḍanāsahiṣṇur mām aśapat “ehi martyatvam” iti / aśapyata mayā ca “yatheha bahu-bhogyā tathā prāpyāpi mānuṣyakam aneka-sādhāraṇī bhava” iti / abhyarthitaś cānayā “eka-pūrvā punas tvām evopacarya yāvajjīvaṃ rameyam” iti / tad ayam artho bhavya eva bhavatā nirāśaṅkyaḥ” iti /
17.1神は仰せられた——「善きウパハーラヴァルマンよ、疑念を抱くでない。そなたは我が分身（アンシャ）なのだ。あの美しき女（カルパスンダリー）は、シャンカラ（シヴァ）の髪に戯れるに慣れたガンガー（天の河）である。彼女はかつて、私の（水中での）戯れに耐えかねて呪いをかけた——『人間界に生まれよ』と。私もまた彼女を呪った——『この世で多くの者に享受されるごとく、人間界に生まれても多くの者に共有されよ（＝遊女となれ）』と。しかし彼女に乞われた——『生涯ただ一人の夫を持ち、あなただけに仕えて楽しみましょう』と。ゆえにこの件は疑うことなく運命づけられたものである」と。
注「多くの者に享受される」（bahubhogyā）はガンガーが多くの人々に使われる河であることと、人間界での遊女的存在の両義をかけている（Kale注, p.112）。この夢の啓示により、カルパスンダリーとの密通は前世の因縁として正当化される。

18夜の庭園への潜入

pratibudhya ca prīti-yuktas tad ahar api priyā-saṃketa-vyatikarādi-smaraṇenāham anaiṣam / anyedyur ananyathā vṛttir anaṅgo mayyeveṣu-varṣam avarṣat / aśuṣyac ca jyotiṣmataḥ prabhāmayaṃ saraḥ / prāsarac ca timiramayaḥ kardamaḥ / kārdamika-nivasanaś ca dṛḍhatara-parikaraḥ khaḍga-pāṇir upahṛta-prakṛtopaskaraḥ / smaran mātṛ-dattānyabhijñānāni rāja-mandira-parikhām udambhasam upātiṣṭham / athopakhātaṃ mātṛ-gṛha-dvāre puṣkarikayā prathama-saṃnidhāpitāṃ veṇu-yaṣṭim ādāya tayā śāyitayā ca parikhām, sthāpitayā ca prākāra-bhittim alaṅghayam /
18.1目覚めると喜びに満たされたが、その日もなお恋人との逢瀬のことが思い出されてならなかった。翌日も変わらず、私にだけカーマ神の矢の雨が降り注いだ。太陽の光でできた池は干上がり（＝日が暮れ）、闇でできたぬかるみが広がった。泥色の衣をまとい、腰をしっかりと締め、剣を手に、必要な道具を携え、乳母から教えられた目印を思い出しつつ、王宮の堀にそっと近づいた。堀のそばに掘られた穴のところで、プシュカリカーがあらかじめ置いておいた竹の竿を取り、それを横たえて堀を渡り、次に立てかけて城壁を乗り越えた。
注kārdamikanivasana（泥色の衣）——恋人たちが夜の密会の際に黒い衣を着て目立たぬようにする習慣は、サンスクリット詩に頻出する描写（Kale注, p.112）。

19庭園を抜けて蔓の東屋へ

adhiruhya pakveṣṭakacitena gopuroparitalādhiroheṇa sopāna-pathena bhuvam avātaram / avatīrṇaś ca bakula-vīthīm atikramya campakāvali-vartmanā manāg ivopasṛtyottarāhi karuṇaṃ cakravāka-mithuna-ravam aśṛṇavam / punarudīcā pāṭali-pathena sparśa-labhya-viśāla-saudha-kuḍyodareṇa śara-kṣepam iva gatvā punaḥ prācā piṇḍī-bhāṇḍīra-ṣaṇḍa-maṇḍitobhaya-pārśvena saikata-pathena kiñcid uttaram atikramya punar avācīṃ cūta-vīthīm agāhiṣi / tataś ca gahanataram udaropacita-ratna-vedikaṃ mādhavī-latā-maṇḍapam īṣad vivṛta-samudgakonmiṣita-bhāsā dīpa-vartyā nyarūpayam /
19.1焼煉瓦で築かれた城門の塔の上の階段を伝って地面に降りた。バクラ樹の並木を過ぎ、チャンパカ並木の道をそっと進んでいくと、北の方からチャクラヴァーカ（鴛鴦）の番いの哀れな鳴き声が聞こえた。さらに北へパータリ樹の並木道を、手で触れることができるほど張り出した広大な宮殿の壁沿いに一矢の射程ほど進み、次いで東へ、両側をピンディーバンダーラの樹林で飾られた砂利道をやや北に進んでから、南のマンゴー並木に入った。そこで、うっそうと茂り中央に宝石を嵌め込んだ壇を持つマーダヴィー蔓の東屋を、わずかに開いた覆い付き灯火のほのかな光で見出した。

20カルパスンダリーとの逢瀬

praviśya caika-pārśve phulla-puṣpa-nirantara-kuraṇṭa-pota-paṅkti-bhitti-parigataṃ garbhagṛham, avani-patitāruṇāśoka-latāmayam abhinava-kusuma-koraka-pulaka-lāñchitaṃ pratyagra-pravāla-paṭala-pāṭalaṃ kapāṭam udghāṭya prāvikṣam, tatra cāsīt svāstīrṇaṃ kusuma-śayanam, suratopakaraṇa-vastu-garbhaś ca bhṛṅgārakaḥ / samupaviśya muhūrtaṃ viśrāntaḥ parimalam atiśayavantam āghrāsiṣam / aśrauṣaṃ ca manda-mandaṃ pada-śabdam / śrutvaiva saṃketa-gṛhān nirgatya raktāśoka-skandha-pārśva-vyavahitāṅgayaṣṭiḥ sthito 'smi / sā ca su-bhrūḥ suṣīma-kāmā śanair upetya tatra mām adṛṣṭvā balavad avyathiṣṭa / vyasṛjac ca matta-rājahaṃsa-vikaṇṭha-rāga-valgu-gadgadāṃ giram
20.1入り口の片側から、満開の花が途切れなく咲くクランタカの若木の列が壁のように取り囲む奥の部屋に入った。地面に垂れた赤いアショーカの蔓でできた、新しい花の蕾の毛羽で飾られ、みずみずしい嫩葉（わかば）の層で赤く彩られた扉を開けて入ると、そこには美しく敷かれた花の寝床と、情事の道具を収めた水差し（ブリンガーラカ）があった。しばし座って休み、この上なく芳しい香りを嗅いだ。するとかすかに足音が聞こえた。それを聞いた途端、逢引の部屋から出て赤いアショーカの幹の陰に身を隠して立った。美しい眉の彼女は、激しい情熱を秘めてゆっくりと近づいてきたが、私の姿が見えず、ひどく動揺した。そして酔った雌のハンサ鳥のように、情感こもった甘い声で言った——

21カルパスンダリーの嘆きと現身

“vyaktam asmi vipralabdhā / nāstyupāyaḥ prāṇitum / ayi hṛdaya, kim idam akāryaṃ kārya-vad adhyavasāya tad-asaṃbhavena kim evam uttāmyasi / bhagavan pañcabāṇa, kas tavāparādhaḥ kṛto mayā yad evaṃ dahasi, na ca bhasmīkaroṣi” iti / athāham āvirbhūya vivṛta-dīpa-bhājanaḥ “bhāmini, nanu bahvaparāddhaṃ bhavatyā cittajanmano yad amuṣya jīvita-bhūtā ratir ākṛtyā kadarthitā, dhanuryaṣṭir bhrū-latābhyām, bhramara-mālāmayī jyā nīlālaka-dyutibhiḥ, astrāṇyapāṅga-vīkṣita-vṛṣṭibhiḥ, mahārajana-rañjita-dhvaja-paṭāṃśukaṃ dantacchada-mayūkha-jālaiḥ, prathama-suhṛn-malaya-mārutaḥ parimala-paṭīyasā niḥśvāsa-pavanena, parabhṛto 'ti-mañjulaiḥ pralāpaiḥ, puṣpamayī patākā bhuja-yaṣṭibhyām, dig-vijayārambha-pūrṇa-kumbha-mithunam uroja-kumbha-yugalena, krīḍā-saro nābhi-maṇḍalena, saṃnāhya-rathaḥ śroṇi-maṇḍalena, bhavana-ratna-toraṇa-stambha-yugalam ūru-yugalena, līlā-karṇa-kisalayaṃ caraṇa-tala-prabhābhiḥ / ataḥ sthāna eva tvāṃ dunoti mīnaketuḥ / māṃ punar anaparādham adhikam āyāsayatītyeṣa eva tasya doṣaḥ / tat prasīda sundari, jīvaya māṃ jīvanauṣadhibhir avāpāṅgair anaṅga-bhujaṅga-daṣṭam” ity āśliṣṭavān /
21.1「ああ、確かに私は欺かれたのだ。もう生きる術はない。ああ我が心よ、不可能なことを可能と思い定め、それが叶わぬとなぜこうも悶えるのか。五矢の神（カーマ）よ、私があなたに何の罪を犯したというのか。こうも焼くのに、なぜ灰にしてくれぬのか」と。そこで私は灯火の覆いを外しながら姿を現し、こう言った——「情熱の美女よ、あなたこそカーマ神に大いに罪を犯したのだ。彼の命そのものであるラティ（愛の女神）を、あなたの美貌でもって恥じ入らせたのだから。あなたの蔓のような眉で彼の弓の柄を、紺碧の巻き毛の輝きで蜂の列でできた弦を、流し目の矢雨で彼の矢を、唇の光の網で紅花色に染まった軍旗の布を、この上なく芳しい吐息の風で彼の第一の友たるマラヤ山の微風を、甘美極まる囁きでカッコウの歌を、腕の柄で花の旗を、世界征服の発端としての満瓶の対で乳房の双丘を、丸い臍で遊戯の池を、腰の円で武装の戦車を、太腿の対で館の宝石門柱の対を、足の裏の光輝で耳に飾る戯れの若芽を——すべて凌駕してしまった。だからカーマ神があなたを苦しめるのは当然のこと。しかし私は何の罪もないのに、彼はなおさら私を苛む。これこそ彼の過ちだ。だからどうか、美しき人よ、愛の蛇に噛まれた私を、命の薬たるあなたの流し目で生き返らせてくれ」——そう言って、固く彼女を抱きしめた。

22合一と別れ

arīramaṃ cānaṅga-rāga-peśala-viśāla-locanām / avasitārthāṃ cārakta-valitekṣaṇām īṣat sveda-rekhodbheda-jarjarita-kapola-mūlām anargala-kalakala-pralāpinīm akaruṇa-daśana-kararuhārpaṇa-vyatikarām atyartha-pariślathāṅgīm ārtām iva lakṣayitvā mānasīṃ śārīrīṃ ca dhāraṇāṃ śithilayann ātmānam api tayā samānārtham āpādayam / tat-kṣaṇa-vimukta-saṃgatau ratāvasānakaṃ vidhim anubhavantau cira-paricitāvivātirūḍha-viśrambhau kṣaṇam avātiṣṭhāvahi / punar aham uṣṇam āyataṃ ca niḥśvasya kiñcid dīna-dṛṣṭiḥ sacakita-prasāritābhyāṃ bhujābhyām enām anatipīḍaṃ pariṣvajya nāti-viśadam acumbiṣam / aśru-mukhī tu sā “yadi prāyāsi nātha, prayātam eva me jīvitaṃ gaṇaya / naya mām api / na ced asau dāsa-jano niṣprayojanaḥ” ityañjalim avataṃsatām anaiṣīt /
22.1愛の情熱に輝く大きな瞳の彼女と交わった。事が終わると、わずかに赤みを帯びて転がる眼差し、かすかな汗の筋が滲み出て乱れた頬の根元、止めどない甘い呟き、情け容赦ない歯と爪の交錯の痕、この上なく弛緩した四肢——まるで疲弊したかのような彼女の姿を見て、私もまた精神と肉体の両方の持ちこたえを緩め、自らも彼女と同じ境地に至った。その瞬間、体を離し、情事の終わりの儀式を味わいながら、あたかも長年の馴染みであるかのように深い信頼を置いてしばし二人で過ごした。やがて私は長く熱い溜息をつき、いくらか悲しげな目で、震える両腕をそっと伸ばして彼女を強すぎぬように抱きしめ、かすかな口づけをした。涙に濡れた顔で彼女は言った——「もしお行きになるなら、私の命もすでに去ったとお思いください。私も連れて行ってください。さもなくば、このはしためは無用の者です」——と合掌を額にかかげた。

23変身の術の計略

avādiṣaṃ ca tām — “ayi mugdhe, kaḥ sacetanaḥ striyam abhikāmayamānāṃ nābhinandati / yadi mad-anugraha-niścalas tavābhisaṃdhir ācarāvicāraṃ mad-upadiṣṭam / ādarśaya rahasi rājñe mat-sādṛśya-garbhaṃ citra-paṭam / ācakṣva ca kim iyam ākṛtiḥ puruṣa-saundaryasya pāram ārūḍhā na vā” iti / “bāḍham ārūḍhā” iti nūnam asau vakṣyati / brūhi bhūyaḥ — “yadyevam, asti kāpi tāpasī deśāntara-bhramaṇa-labdha-prāgalbhyā mama ca mātṛ-bhūtā” / tayedam ālekhya-rūpaṃ puraskṛtyāham uktā “so 'sti tādṛśo mantro yena tvam upoṣitā parvaṇi viviktāyāṃ bhūmau purohitair huta-mukte saptārciṣi naktam ekākinī śataṃ candana-samidhaḥ, śatam aguru-samidhaḥ karpūra-muṣṭīḥ paṭṭavastrāṇi ca prabhūtāni hutvā bhaviṣyasyevam ākṛtiḥ / atha cālayiṣyasi ghaṇṭām / ghaṇṭā-puṭa-kvaṇitāhūtaś ca bhartā bhavatyai sarva-rahasyam ākhyāya nimīlitākṣo yadi tvām āliṅget, iyam ākṛtir amum upasaṃkrāmet / tvaṃ tu bhaviṣyasi yathā purākāraiva yadi bhavatyai bhavat-priyāya caivaṃ roceta, na cāsmin vidhau visaṃvādaḥ kāryaḥ” iti / “vapuś ced idaṃ tavābhimataṃ saha suhṛn-mantribhir anujaiḥ paura-jānapadaiś ca saṃpradhārya teṣām apyanumate karmaṇy abhimukhena stheyam” iti / sa niyatam abhyupaiṣyati / punar asyām eva pramada-vana-vāṭī-śṛṅgāṭikāyām ātharvaṇikena vidhinā saṃjñapita-paśunābhihutya mukte hiraṇyaretasi dhūma-paṭena saṃpraviṣṭena mayāsminn eva latā-maṇḍape sthātavyam /
23.1私は彼女にこう告げた——「おお純真な人よ、自ら慕ってくる女をいったい誰が喜ばぬか。もし私への好意が不動であるなら、迷わず私の指示に従え。密かに王に私の肖像画を見せ、この姿が男の美の極致に達しているかどうか尋ねよ」と。王はきっと「確かに達している」と答えるだろう。そうしたらさらにこう言え——「もしそうならば、諸国を遍歴して経験を積んだ女行者がおります。私にとって母のような人です」と。その人がこの絵を示して、わたくし（カルパスンダリー）にこう申しました——「ある呪文がある。それによれば、あなた様が新月の夜に断食し、祭司が聖火に供物を捧げ退いた後、人気のない場所で独り、百本の白檀の薪、百本の沈香の薪、幾掴みもの樟脳、多くの絹布を火に投じれば、あなた様はこの姿となるでしょう。そうしたら鈴を鳴らしなさい。鈴の音に呼ばれた夫が、すべての秘密を打ち明け、目を閉じてあなたを抱きしめれば、この姿は彼に移るでしょう。あなた様はもとの姿のままです。もしあなた様と夫君がこれに同意なさるなら、この儀式に偽りはありません」と。「この姿がお気に召すなら、友人・大臣・弟たち・市民と住民と相談し、彼らの同意のもと事を進めなさい」と。王はきっと承諾するだろう。さらに、この遊苑の四辻で、アタルヴァヴェーダの儀式に従い殺した獣を聖火に投じ供えた後、煙の幕に紛れて私がこの蔓の東屋に潜んでいよう。
tvaṃ punaḥ pragāḍhāyāṃ pradoṣa-velāyām ālapiṣyasi karṇe kṛta-narma-smitā vikaṭavarmāṇam — “dhūrto 'si tvam akṛtajñaś ca / mad-anugraha-labdhenāpi rūpeṇa loka-locanotsavāyamānena mat-sapatnīr abhiramayiṣyasi / nāham ātma-vināśāya vetālotthāpanam ācareyam” iti / śrutvedaṃ tvad-vacaḥ sa yad vadiṣyati tan mahyamekākinyupāgatya nivedayiṣyasi tataḥ param aham eva jñāsyāmi / mat-pada-cihnāni copavane puṣkarikayā pramārjaya” iti /
23.2おまえは夜更けの宵闇の中、戯れの笑みを浮かべてヴィカタヴァルマンの耳にこう囁け——「あなたはずるくて恩知らずだ。私の恩恵で得た姿——人々の目の祭りとなるほどの美しさ——で、妾たちと楽しむつもりでしょう。自分を滅ぼすために亡霊など呼び出すものですか」と。これを聞いて彼が何と言うか、独りで私のもとに来て知らせなさい。その先は私が判断する。庭園に残った私の足跡はプシュカリカーに消させよ」と。
注この変身の儀式（身体交換の術）は、ヴィカタヴァルマンを欺いて殺すための罠である。彼が「秘密（国政の陰謀）」をすべて打ち明けさせることが肝要で、それにより後にウパハーラヴァルマが王になりすますことが可能となる。

24噂の流布と儀式の夜

sā “tathā” iti śāstropadeśam iva mad-uktam ādṛtyātṛpta-surata-rāgaiva kathaṅ katham apy agād antaḥpuram / aham api yathāpraveśaṃ nirgatya svam evāvāsam ayāsiṣam / atha sā mattakāśinī tathā tam artham anvatiṣṭhat / atiṣṭhac ca tan-mate sa durmatiḥ / abhramac ca paura-jānapadeṣv iyam adbhutāyamānā vārtā “rājā kila vikaṭavarmā devī-mantra-balena deva-yogyaṃ vapur āsādayiṣyati / nūnam eṣa vipralambho nātikalyāṇaḥ / kaiva kathā pramādasya / svasminn evāntaḥpuropavane svāgramahiṣyaiva saṃpādyaḥ kilāyam arthaḥ / tathā hi bṛhaspati-pratima-buddhibhir mantribhir apyabhyūhyānumataḥ / yadyevaṃ bhāvi nānyad ataḥ param asti kiñcid adbhutam / acintyo hi maṇi-mantrauṣadhīnāṃ prabhāvaḥ iti prasṛteṣu loka-pravādeṣu prāpte parva-divase, pragāḍhāyāṃ prauḍhatamasi pradoṣa-velāyām antaḥpurodyānād udairayad dhūrjaṭi-kaṇṭha-dhūmro dhūmodgamaḥ /
24.1彼女は「仰せの通りに」と聖典の教えのように私の言葉を敬い、まだ情欲の満たされぬまま何とか内宮に戻った。私もまた来た道をたどって退き、自分の住まいに帰った。かの美女はまさにその通りに計略を実行し、あの愚か者もその指示に従った。そして市民と地方民の間に驚くべき噂が広まった——「王ヴィカタヴァルマンは王妃の呪術の力で神にふさわしい姿を得るらしい」「きっとまやかしで、ろくなことにはなるまい」「いや、どんな過ちが起こりえよう。何しろ王自身の後宮の庭園で、正妃自らが執り行うというのだから。ブリハスパティに匹敵する知恵を持つ大臣たちが熟慮の上で認めたのだ。もし実現すれば、これ以上の驚異はない。宝石と呪文と薬草の力は思議の及ぶところではないのだから」と。こうした風聞が流れる中、新月の日が訪れ、濃密な闇の宵に、後宮の庭園からシヴァの喉のごとき暗灰色の煙が立ち上った。
注karmaṇy abhimukhena stheyam（儀式に前向きであるべきです）――GRETILの steyam（盗み）は stheyam の誤記。kāryaḥ（なされるべき）もGRETILの kāyaḥ を訂正したもの。

25カルパスンダリーの到来とヴィカタヴァルマン殺害

kṣīrājya-dadhi-tila-gaura-sarṣapa-vasā-māṃsa-rudhirāhutīnāṃ ca parimalaḥ pavanānusārī diśi diśi prāvātsīt / praśānte ca sahasā dhūmodgame tasminn aham aviśam / niśāntodyānam agāc ca gaja-gāminī / āliṅgya ca māṃ sasmitaṃ samabhyadhatta — “dhūrta, siddhaṃ te samīhitam / avasitaś ca paśur asau / amuṣya pralobhanāya tvad-ādiṣṭayā diśā mayoktam “kitava, na sādhayāmi te saundaryam / evaṃ sundaro hi tvam apsarasām api spṛhaṇīyo bhaviṣyasi, kim uta mānuṣīṇām / madhukara iva nisarga-capalo yatra kvacid asajjati bhavādṛśo nṛśaṃsaḥ” iti / tena tu me pādayor nipatyābhihitam “rambhoru, sahasva mat-kṛtāni duścaritāni / manasāpi na cintayeyam itaḥ param itara-nārīm / tvarasva prastute karmaṇi” iti /
25.1乳、ギー、凝乳、胡麻、白芥子、脂肪、肉、血の供物の香りが風に乗って四方に広がった。煙がふと消えると、私は庭園に入った。象のように優雅に歩む彼女もまた宮殿の庭にやって来た。私を抱きしめ、微笑んでこう言った——「ずるい人、あなたの望みは叶いました。あの獣（いけにえ）はもう仕留めたも同然です。あの男を騙すために、あなたの指示通りにこう言いました——『ペテン師め、私はお前に美を授けてやりはしない。こんなに美しくなれば天女たちすら欲しがるだろうに、人間の女など言うまでもない。蜜蜂のように生まれつき移り気で、あちこちに執着するあなたのような残酷な人だもの』と。するとあの男は私の足元にひれ伏して言いました——『美しき太腿の人よ、私の悪行を許してくれ。これから先は心の中でさえ他の女を思うまい。急いで儀式を行ってくれ』と。」
tad aham īdṛśena vaivāhikena nepathyena tvām abhisṛtavatī / prāg api rāgāgni-sākṣikam anaṅgena guṇa-rūpā dattaiva tubhyameṣā jāyā / punar apīmaṃ jātavedasaṃ sākṣīkṛtya sva-hṛdayena dattā iti prapadena caraṇa-pṛṣṭhe niṣpīḍyotkṣipta-pāda-pārṣṇir itaretara-vyatiṣakta-komalāṅguli-dalena bhuja-latā-dvayena kandharāṃ mamāveṣṭya salīlam ānanam ānamayya svayam unnamita-mukha-kamalā vibhrānta-viśāla-dṛṣṭir asakṛd abhyacumbat /
25.2「だから私はこのような婚礼の装いであなたのもとに参りました。以前から、愛の炎を証人としてカーマ神が美徳と容姿によってこの妻をあなたに与えたのです。今またこの聖火を証人として、我が心からあなたに捧げます」——こう言って、つま先で私の足の甲を踏みしめ、踵を上げ、互いに絡み合う柔らかな指先の蔓のような両腕で私の首を巻き、優美に私の顔を引き寄せ、自ら蓮の花のような顔を上げ、揺れる大きな瞳で何度も口づけをした。

26ヴィカタヴァルマン誅殺

athainām “ihaiva kuraṇṭaka-gulma-garbhe tiṣṭha yāvad ahaṃ nirgatya sādhayeyaṃ sādhyaṃ samyak” iti visṛjya tām upasṛtya homānala-pradeśam aśoka-śākhāvalambinīṃ ghaṇṭām acālayam / akūjac ca sā taṃ janaṃ kṛtānta-dūtīvāhvayantī / prāvartiṣi cāham aguru-candana-pramukhāni hotum / āyāsīc ca rājā yathoktaṃ deśam / śaṅkāpannam iva kiñcit savismayaṃ vicārya tiṣṭhantam abravam — “brūhi satyaṃ bhūyo 'pi me bhagavantaṃ citrabhānum eva sākṣīkṛtya / na ced anena rūpeṇa mat-sapatnīr abhiramayiṣyasi, tatas tvayīdaṃ rūpaṃ saṃkrāmayeyam” iti / sa tadaiva “devya iveyam, nopadhiḥ” iti sphuṭopajāta-saṃpratyayaḥ prāvartata śapathāya /
26.1そこで彼女に「ここのクランタカの藪の中で待っていろ。私が出て行って仕上げよう」と言い残し、護摩の火の場所に行ってアショーカの枝に吊るされた鈴を揺らした。鈴は死神の使者のようにあの男を呼ぶかのように鳴り響いた。私は沈香と白檀の薪を火に投じ始めた。王もまた取り決め通りやって来た。恐れて疑い、少々驚いて考え込んで立っている王に向かって私は言った——「もう一度この聖なる火を証人として真実を誓いなさい。この姿で妾たちと楽しまぬと。さもなくばこの姿はあなたに移しますまい」と。王はそこで「まさしく妃本人だ、偽りではない」と完全に確信し、誓いを立て始めた。

27秘密の暴露と誅殺

smitvā punar mayoktam — “kiṃ vā śapathena / kaiva hi mānuṣī māṃ paribhaviṣyati / yadyapsarobhiḥ saṃgacchase, saṃgacchasva kāmam / kathaya kāni te rahasyāni / tat-kathanānte hi tvat-sva-rūpa-bhraṃśaḥ” iti / so 'bravīt — “asti baddho mat-pituḥ kanīyān bhrātā prahāravarmā / taṃ viṣānnena vyāpādyājīrṇa-doṣaṃ khyāpayeyam iti mantribhiḥ sahā dhyavasitam / anujāya viśālavarmaṇe daṇḍacakraṃ puṇḍra-deśābhikramaṇāya ditsitam / paura-vṛddhaś ca pāñcālikaḥ paritrātaś ca sārthavāhaḥ khanati-nāmno yavanād vajram ekaṃ vasuṃdharā-mūlyaṃ laghīyasārgheṇa labhyam iti mamaikānte 'mantrayetām / gṛhapatiś ca mamāntaraṅga-bhūto janapada-mahattaraḥ śatahalir alīka-vāda-śīlam avalepavantaṃ duṣṭa-grāmaṇyam ananta-sīraṃ janapada-kopena ghātayeyam iti daṇḍadharān uddhāra-karmaṇi mat-prayogān niyoktum abhyupāgamat / ittham idam acira-prastutaṃ rahasyam” / ity ākarṇya tam “iyat tavāyuḥ / upapadyasva sva-karmocitāṃ gatim” iti churikayā dvidhākṛtya kṛtta-mātraṃ tasminn eva pravṛtta-sphītasarpiṣi hiraṇyaretasy ajūhavam / abhū ccāsau bhasmasāt /
27.1私は微笑んで言った——「誓いなど何の用があろう。いったいどの人間の女が私を蔑ろにできようか。天女たちと交わりたければ、好きにするがよい。おまえの秘密を語れ。秘密を語り終えた時、おまえの本来の姿は消える」と。ヴィカタヴァルマンは語った——「父の弟プラハーラヴァルマンを投獄している。毒入りの食物で殺し、消化不良の病で死んだと公表しようと大臣たちと謀った。弟ヴィシャーラヴァルマンには軍の一部を与えてプンドラ国を攻撃させようとしている。市の長老パーンチャーリカと隊商の長パリトラータは、カナーティという名のヤヴァナ（外国人）から、大地にも値するダイヤモンド一つを僅かな値で手に入れられると、私に密かに告げた。また我が腹心の長官で郡の長であるシャタハリは、嘘つきで傲慢な悪しき地主アナンタシーラを、民衆の怒りに見せかけて殺させようと、取り立ての任務に捕吏たちを任じるための私の命令を取り付けに来た。これが最近企てた秘密の計画だ」と。これを聞いて——「おまえの寿命はここまでだ。己の業にふさわしい末路を辿れ」と告げ、短剣でその体を二つに切り裂き、切るが早いか、ギーがたっぷり注がれた聖火にそのまま投じた。たちまち灰と化した。
注Kaleは「ヤヴァナのカナーティ」をペルシア人またはアラブ商人と推定する（p.120注）。vajra（金剛石、ダイヤモンド）の取引。ヴィカタヴァルマンの「秘密」はすべて彼の暴政と陰謀を示し、ウパハーラヴァルマンが王になりすました後にこれらを逆転させることで善政を行う布石となる。
注khanati-nāmno yavanāt（カナーティという名のヤヴァナから）――GRETILの svanati- は、デーヴァナーガリーの ख（kha）と स्व（sva）の字形の混同による誤記。uddhāra-karman は租税・債務の取り立ての任務。

28変身王としての統治開始

atha strī-svabhāvād īṣad vihvalāṃ hṛdaya-vallabhāṃ samāśvāsya hasta-kisalaye 'valambya gatvā tad-gṛham anujñayāsyāḥ sarvāṇyantaḥpurāṇyāhūya sadya eva sevāṃ dattavān / savismita-vilāsinī-sārtha-madhye kañcid vihṛtya kālaṃ visṛṣṭāvarodha-maṇḍalas tām eva saṃhatorūm ūrūpapīḍaṃ bhujopapīḍaṃ copaguhya talpe 'bhiramayann alpām iva tāṃ niśām atyanaiṣam / alabhe ca tan-mukhāt tad-rāja-kulasya śīlam / uṣasi snātvā kṛta-maṅgalo mantribhiḥ saha samagacche /
28.1女の性として少し動揺した愛しい人を慰め、その蕾のような手を取って宮殿に行き、彼女の許しを得て内宮のすべての者を呼び集め、直ちに拝謁を受けた。驚嘆する後宮の美女たちの群れの中でしばし楽しんだ後、後宮の女たちを退出させ、太腿をぴったりと合わせ、腕に抱きしめて寝台で愛し合い、まるで短すぎるかのようにその夜を過ごした。彼女の口から王家の慣習のすべてを学んだ。夜明けに沐浴し、吉祥の儀式を済ませ、大臣たちと合流した。

29悪政の転覆——善政の実施

tāṃś cābravam — “āryāḥ, rūpeṇaiva saha parivṛttau mama svabhāvaḥ / ya eva viṣānnena hantu cintitaḥ pitā me sa muktvā svam etad rājyaṃ bhūya eva grāhayitavyaḥ / pitṛ-vad amuṣmin vayaṃ śuśrūṣayaiva vartāmahe / na hyasti pitṛ-vadhāt paraṃ pātakam” iti / bhrātaraṃ ca viśālavarmāṇam āhūyoktavān — “vatsa, na subhikṣāḥ sāṃprataṃ puṇḍrāḥ te duḥkha-mohopahatās tyaktātmāno rāṣṭraṃ no na samṛddham abhidraveyuḥ / ato muṣṭi-vadhaḥ sasya-vadho vā yadotpadyate tadābhiyāsyasi, nādya yātrā yuktā” iti /
29.1そして大臣たちにこう告げた——「諸氏よ、姿とともに私の性格も変わった。毒入りの食物で殺そうとしていた叔父は、すなわち私の父にあたる方であり、釈放してこの王国を再び与えなければならぬ。父のごとくあの方に仕えよう。父殺しに勝る罪はないのだから」と。弟ヴィシャーラヴァルマンを呼んで言った——「弟よ、今プンドラ国は豊かではない。苦しみと絶望にとりつかれた彼らは自棄になって豊かとはいえぬわが国に攻め込んでくるかもしれぬ。だから種蒔きか収穫の時に攻め込むべきで、今は侵攻の時機ではない」と。

30さらなる善政と両親との再会

nagara-vṛddhāv apy alāpiṣam — “alpīyasā mūlyena mahārhaṃ vastu māstu me labhyaṃ dharma-rakṣāyai, tad-anuguṇenaiva mūlyenādaḥ krīyatām” iti / śatahaliṃ ca rāṣṭra-mukhyam āhūyākhyātavān — “yo 'sāvanantasīraḥ prahāravarmaṇaḥ pakṣa iti nināśayiṣitaḥ, so 'pi pitari me prakṛtisthe kim iti nāśyeta, tat tvayāpi tasmin saṃrambho na kāryaḥ” iti / ta ime sarvam ābhijñānikam upalabhya “sa evāyam” iti niścinvānā vismayamānāś ca māṃ mahādevīṃ ca praśaṃsanto mantra-balāni codghoṣayanto bandhanāt pitarau niṣkrāmayya svaṃ rājyaṃ pratyapādayan /
30.1市の長老と隊商の長の二人にも告げた——「法（ダルマ）を守るため、僅かな代金で貴重な品を得ることは私の望むところではない。相応の価格で購入せよ」と。長官シャタハリを呼んで言った——「プラハーラヴァルマンの味方だから滅ぼそうとしたアナンタシーラだが、叔父が元の地位に復した今、なぜ滅ぼす必要があろうか。おまえも彼に敵意を抱くな」と。大臣たちはすべての秘密を知って「まさしく同一人物だ」と確信しつつも驚嘆し、私と王妃を讃え、呪術の力を大いに褒めそやし、両親を投獄から解放して王国を返還した。

31皇太子となり、シンハヴァルマン救援へ

ahaṃ ca tayā me dhātryā sarvam idaṃ mamāceṣṭitaṃ rahasi pitror avagamayya praharṣa-kāṣṭhādhirūḍhayos tayoḥ pāda-mūlam abhaje / abhajye ca yauvarājya-lakṣmyā tad-anujñātayā / prasādhitātmā deva-pāda-viraha-duḥkha-durbhagān bhogān nirviśan bhūyo 'sya pitṛ-sakhasya siṃhavarmaṇo lekhyāc caṇḍavarmaṇaś campābhiyogam avagamya “śatru-vadho mitra-rakṣā cobhayam api karaṇīyam eva” ityalaghunā laghu-samutthānena sainya-cakreṇābhyasaram / abhavaṃ ca bhūmis tvat-pāda-lakṣmī-sākṣātkriyā-mahotsavānanda-rāśeḥ” iti /
31.1私はあの乳母を通じて両親に密かに一部始終を打ち明け、歓喜の極みに達した両親の足元にひれ伏した。両親の命によって皇太子の位を授かった。目的を果たし、しかし殿下と離れている悲しみのゆえに味気ない享楽に甘んじていたが、やがて父の友シンハヴァルマンの書状からチャンダヴァルマンのチャンパー攻撃を知り、「敵の殲滅と友の救援、どちらもなすべきこと」と、軽やかな迅速さで大軍を率いて進軍し、殿下のみ足を目の当たりにするという大祝祭の歓喜の宝となったのでございます」と。

32ラージャヴァーハナの論評

śrutvaitad devo rājavāhanaḥ sasmitam avādīt — “paśyata pāratalpikam upadhi-yuktam api guru-jana-bandha-vyasana-mukti-hetutayā duṣṭāmitra-pramāpaṇābhyupāyatayā rājyopalabdhi-mūlatayā ca puṣkalāv artha-dharmāv apy arīradhat / kiṃ hi buddhimat-prayuktaṃ nābhyupaiti śobhām” iti / arthapāla-mukhe nidhāya snigdha-dīrghāṃ dṛṣṭim “ācaṣṭāṃ bhavān ātmīya-caritam” ityādideśa / so 'pi baddhāñjalir abhidadhe //
32.1これを聞いてラージャヴァーハナ殿下は微笑んでこう仰せられた——「見よ、不義密通（パーラタルピカ）は策略を伴うものであったとはいえ、年長の親族を災難から救い出す手段として、邪悪な敵を滅ぼす方策として、さらに王国奪回の根拠として、アルタ（実利）とダルマ（法）を豊かに成就させた。知恵ある者によって用いられた手段で、輝かしくならぬものがあろうか」と。そしてアルタパーラの顔に愛情深い長い視線を注ぎ、「卿も自らの冒険を語られよ」と命じた。アルタパーラもまた合掌して語り始めた。
注pāratalpika（パーラタルピカ, 不義密通）は paratalpā（他人の寝台＝他人の妻）に由来する語。ラージャヴァーハナは「目的が手段を正当化する」という立場を示し、不義密通を含む策略が親の救出、悪敵の排除、王国回復という三つの正当な目的に資したことを称揚する。この道徳的パラドックスは、ダンディンの物語世界における知略の美学の核心である（Kale注, p.122）。
