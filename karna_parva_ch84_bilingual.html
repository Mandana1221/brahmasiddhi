karṇaparva — catuḥśītitamo'dhyāyaḥ (84)
第84章　混戦
sañjaya uvāca|
xxxxxxxxxxxprabarairvalairbhīmamabhidrutam|
xxxxxxxxxx kaunteyamusthihīrṣurdhanañjayaḥ||
// 8-84-1 //
サンジャヤは語った。
xxxxxxxxx senāṃ mārata sāyakaiḥ|
xxxxxxxxxx paravīrāndhanañjayaḥ||
xxxxxxxxxxx śarajālāni bhāgaśaḥ|
adṛśyanta tathānye ca nijaghnustava vāhinīm||
// 8-84-2-3 //
アルジュナは矢でバーラタの軍を切り裂き、敵の勇者たちを殺した。矢の網が部分ごとに見えなくなり、他の者たちも汝の軍を殺した。
sa pakṣisaṅghācaritamākāśaṃ pūrayañśaraiḥ|
dhanañjayo mahābāhuḥ kurūṇāmantako'mayat // 8-84-4 //
鳥の群れが飛び交う空を矢で満たしながら、大いなる腕のダナンジャヤは、クル族の死神のように見えた。
tato bhallaiḥ kṣurapraiś ca nārācairvimalairapi|
gātrāṇi prācchinatpārthaḥ śirāṃsi ca cakarta ha||
// 8-84-5 //
そして鏃・剃刀矢・清浄な鉄矢で、アルジュナは手足を切り、首をも切り落とした。
chinnagātrairvikavacairviśiraskaiḥ samantataḥ|
pātitaiś ca patadbhiś ca yodhairāsītsamāvṛtā||
// 8-84-6 //
手足を切られ、鎧を剥がれ、首を失い、四方に倒れた者、倒れつつある者たちの戦士で大地は覆われた。
dhanañjayaśarābhyastaiḥ syandanāśvarathadvipaiḥ|
sañchinnabhinnavidhvastairvyaṅgāṅgāvayavaiḥ stṛtā|
gatasatvaiḥ sasatvaiś ca saṃvṛtā''sīdvasundharā||
// 8-84-7 //
ダナンジャヤの矢に打たれた戦車・馬・象が、切断され・砕かれ・粉砕され、手足を失い、命ある者も命なき者も、大地は覆われた。
sudurgamā suviṣamā ghorā'tyarthaṃ sudurdṛśā|
raṇabhūmirabhūdrājanmahāvaitaraṇī yathā||
// 8-84-8 //
大王よ、戦場はまるで大いなるヴァイタラニー河のように、非常に通行困難で、凸凹で、恐ろしく、見るに堪えないものとなった。
īṣācakrākṣabhallaiś ca vyaśvaiḥ sāśvaiś ca yudhyatām|
sasūtairhatasūtaiś ca rathaiḥ stīrṇā'bhavanmahī||
// 8-84-9 //
車軸・車輪・鏃で、馬を失った戦車、馬を持つ戦車、御者のいる戦車、御者を殺された戦車で、大地は覆い尽くされた。
suvarṇavarmasannāhairyodhaiḥ kanakamālibhiḥ|
āsthitāḥ klṛptavarmāṇo bhadrā nityamadā dvipāḥ||
kruddhāḥ krurairmahāmātraiḥ preṣitārjunamabhyayuḥ|
catuḥ śatā rathavarā hatāḥ petuḥ kirīṭinā||
// 8-84-10-11 //
黄金の鎧を身につけ、黄金の花輪を戴いた戦士たちが乗る、鎧を着けた常に酩酊した象たちが、怒った象使いに駆り立てられアルジュナに向かった。四百台の最上の戦車がアルジュナに殺されて倒れた。
paryastānīva śṛṅgāṇi sasatvāni mahāgireḥ|
dhanañjayaśarābhyastaiḥ stīrṇā bhūrvaravāraṇaiḥ||
// 8-84-12 //
山の頂の峰が崩れ落ちるように、ダナンジャヤの矢に打たれた最上の象たちで大地は覆われた。
samantājjaladaprakhyānvāraṇānmadavarṣiṇaḥ|
abhipede'rjunaratho ghanānbhindannivāṃśumān||
// 8-84-13 //
雲のごとき、酩酊した象たちに、アルジュナの戦車は、光が雲を貫くように突入した。
hatairgajamanuṣyāśvairbhinnaiś ca bahudhā rathaiḥ|
viśastrayantrakavacairyuddhaśauṇḍairgatāsubhiḥ|
upaviddhāyudhairmārgaḥ stīrṇo'bhūtphalgunena vai||
// 8-84-14 //
殺された象・人・馬で、多くの戦車が壊され、武器・甲冑を失い、戦いの勇者たちが息絶え、武器を打ち落とされた者たちの道がアルジュナによって作られた。
visphāritaṃ ca gāṇḍīvamatyāsīdbhairavasvanam sughoṣaṃ vajraniṣpeṣaṃ stanayanniva toyadaḥ||
// 8-84-15 //
ガーンディーヴァの轟音は、雷のように雲鳴りのように、恐ろしい響きであった。
tataḥ prādīryata camūrdhanañjayaśarāhatā|
mahāvātasamāviddhā mahānauriva sāgare||
// 8-84-16 //
ダナンジャヤの矢に打たれた軍は崩壊した。海上の大船が大風に打たれるように。
nānārūpāḥ prāṇaharāḥ śarā gāṇḍīvacoditāḥ|
alātolkāśaniprakhyāstava sainyaṃ vinirdahan||
// 8-84-17 //
ガーンディーヴァから放たれた様々な形の命を奪う矢は、火の玉・松明・雷のように、汝の軍を焼き尽くした。
mahāgirau veṇuvanaṃ niśi prajvalitaṃ yathā|
tathā tava mahāsainyaṃ prāsphuraccharapīḍitam||
// 8-84-18 //
大山のタケ藪が夜に燃え上がるように、汝の大軍は矢に苦しめられてきらめいた。
tadvinaṣṭaṃ suvidhvastaṃ tava sainyaṃ kirīṭinā|
hatapravihataṃ bāṇaiḥ sarvataḥ pradrutaṃ diśaḥ||
// 8-84-19 //
アルジュナによって壊滅し、完全に粉砕された汝の軍は、矢に打たれ蹴散らされ、四方に逃げ散った。
saśvāpadā mṛgagaṇā dāvāgnitrāsitā yathā|
kuravaḥ paryavartanta nirdagdhāḥ savyasācinā||
// 8-84-20 //
獣と鹿の群れが山火事に怯えるように、クル族はサヴャサーチン（アルジュナ）に焼き尽くされて逃げ回った。
utsṛjya ca mahābāhuṃ bhīmasenaṃ tathā raṇe|
balaṃ kurūṇāmudvignaṃ sarvamāsītparāṅmukham||
// 8-84-21 //
大いなる腕のビーマセーナを戦場に残し、クルの軍は動揺して全員が背を向けた。
tataḥ kuruṣu bhagneṣu bībhatsuraparājitaḥ|
bhīmasenaṃ samāsādya muhūrtaṃ so'bhyavartata||
// 8-84-22 //
クル軍が崩壊すると、無敵のビーバツ（アルジュナ）は、ビーマセーナに近づき、しばし留まった。
samāgamya ca bhīmena mantrayitvā ca phalgunaḥ|
viśalyamarujaṃ cāsmai kathayitvā yudhiṣṭhiram||
// 8-84-23 //
ビーマに会い、相談し、ユディシュティラが矢傷もなく無事であることを伝え——
bhīmasenābhyanujñātastataḥ prāyāddhanañjayaḥ|
nādanrathaghoṣeṇa pṛthivīṃ dyāṃ ca bhārata||
// 8-84-24 //
ビーマセーナの許可を得て、ダナンジャヤは出発した。バーラタよ、戦車の轟音で大地と空を鳴り響かせながら。
tataḥ parivṛto vīrairdaśabhiḥ śatrutāpanaḥ|
duḥśāsanādavarajaistava putrairdhanañjayaḥ||
// 8-84-25 //
そして敵を苦しめるダナンジャヤは、十人の勇者——ドゥフシャーサナの弟である汝の息子たちに囲まれた。
te tamabhyardayanbāṇairulkābhiriva kuñjaram|
ātateṣvasanā vīrā nṛtyanta iva bhārata||
// 8-84-26 //
バーラタよ、弓を引き絞った勇者たちは、松明で象を責めるように、矢で彼を苦しめ、踊るように戦った。
apasavyāṃstu tāṃścakre rathena madhusūdanaḥ|
niyuktānhi sa tānmene yamāyāśu kirīṭinā||
// 8-84-27 //
マドゥスーダナ（クリシュナ）は彼らの戦車を左回りに回した。アルジュナは彼らをヤマに捧げられた者と見なした。
tathānye prāṇadanmūḍhāḥ parāṅmukhamivārjunam||
// 8-84-28 //
また別の者たちも愚かにも背を見せるかのようにアルジュナに向かってきた。
teṣāṃ nānadatāṃ ketūnaśvāṃścāpāni sārathīn|
nārācairardhacandraiś ca kṣipraṃ pārtho nyakṛntata||
// 8-84-29 //
彼らの叫ぶ旗・馬・弓・御者を、アルジュナは鉄矢と半月矢で素早く切り落とした。
*athānyairdaśabhirbhallaiḥ śirāṃsyeṣāmapātayat|
roṣasaṃraktanetrāṇi sandaṣṭauṣṭhāni bhūtale||
// 8-84-30 //
そして別の十本の鏃で彼らの首を打ち落とした。怒りに赤い目をした首が、歯を食いしばったまま大地に落ちた。
teṣāṃ vakrāṇi vibabhurvyomni tārāgaṇā iva||
// 8-84-31 //
それらの顔は空に星座のように輝いた。
tāṃstu bhallairmahāvegairdaśabhirdaśa kauravān|
rukmāṅgadāvrukmapuṅkhairhatvā prāyādamitrahā||
// 8-84-32 //
黄金の腕輪と黄金の羽根を持つ大速の十本の鏃で十人のカウラヴァを殺し、敵を殺す者は進んだ。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe catuḥśītitamo'dhyāyaḥ|| 84 ||
