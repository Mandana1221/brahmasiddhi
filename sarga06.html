Kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST）・和訳

ṣaṣṭhaḥ sargaḥ ― 第六章

アルジュナのインドラキーラ山登攀と自然描写（1-18）。苦行の実践と精神的成長（19-28）。グヒヤカたちがインドラに嘆願（29-37）。インドラがアプサラスたちを派遣（38-47）。
1
Sanskrit
rucirākṛtiḥ kanakasānum atho paramaḥ pumān iva patiṃ patatām / dhṛtasatpathas tripathagām abhitaḥ sa tam āruroha puruhūtasutaḥ //
和訳
美しい姿をしたプルフータの子（アルジュナ）は、正しき道を歩む者として、三つの道を流れる河（ガンガー）に面した、かの黄金の山嶺を登った。あたかも至高の神（ヴィシュヌ）が鳥の王（ガルダ）に乗るように。

tripathagā（三道を行く者）はガンガー河の別名。天上・空中・地上の三界を流れるとされる。paramaḥ pumān（至高の神）がガルダに乗る喩えは、ヴィシュヌの乗騎。Pramitākṣarā 韻律が本章の基本韻律。

2
Sanskrit
tam anindyabandina ivendrasutaṃ vihitālinikvaṇajayadhvanayaḥ / pavaneritākulavijihmaśikhā jagatīruho 'vacakaruḥ kusumaiḥ //
和訳
風に揺られてざわめき、曲がった梢を持つ木々は、蜜蜂の羽音を勝利の歓声に見立て、申し分なき楽士のように、かのインドラの子を花々で降り注いだ。
3
Sanskrit
avadhūtapaṅkajaparāgakaṇās tanujāhnavīsalilavīcibhidaḥ / parirebhire 'bhimukham etya sukhāḥ suhṛdaḥ sakhāyam iva taṃ marutaḥ //
和訳
蓮の花粉を吹き飛ばし、ジャーフナヴィー（ガンガー）の細波を砕く心地よい風は、彼のもとへ向かって来て、友が親友を迎えるように彼を抱擁した。
4
Sanskrit
uditopalaskhalanasaṃvalitāḥ sphuṭahaṃsasārasavirāvayujaḥ / mudam asya māṅgalikatūryakṛtāṃ dhvanayaḥ pratenur anuvapram apām //
和訳
高い岩に打ち当たって砕ける水音は、白鳥やサーラサ鶴の明朗な鳴き声と相まって、岸辺にて祝祭の楽の音が奏でるような喜びを彼にもたらした。
5
Sanskrit
avarugṇatuṅgasuradārutarau nicaye puraḥ surasaritpayasām / sa dadarśa vetasavanācaritāṃ praṇatiṃ balīyasi samṛddhikarīm //
和訳
彼は、高きデーヴァダール樹をも押し倒す天の河（ガンガー）の激流の前で、蘆の林がなす吉兆の礼拝を見た。強大なる者への敬礼は繁栄をもたらすのだ。

suradāru（デーヴァダール）はヒマラヤ杉。vetasavana（蘆の林）が水流に靡く様を「礼拝」に喩える。

6
Sanskrit
prababhūva nālam avalokayituṃ paritaḥ sarojarajasāruṇitam / sariduttarīyam iva saṃhatimat sa taraṅgaraṅgi kalahaṃsakulam //
和訳
彼は、周囲を蓮の花粉で赤く染められ、密集して波間に揺れる白鳥の群れを——河の上掛けのように——見飽きることができなかった。
7
Sanskrit
dadhati kṣatīḥ pariṇatadvirade muditāliyoṣiti madasrutibhiḥ / adhikāṃ sa rodhasi babandha dhṛtiṃ mahate rujann api guṇāya mahān //
和訳
発情期の象が岸を傷つけ、蜜蜂たちがその汗液に喜ぶ河岸において、彼はひときわの喜悦を覚えた。偉大なる者は、害をなしても、それが大いなる徳となるのだ。

格言的な後半句：象が岸を崩しても、その発する汗液（madasruti）は蜜蜂を喜ばせる。偉大なる者の行為は、損害を与えるように見えても結局は徳となるという含意。

8
Sanskrit
anuhemavapram aruṇaiḥ samatāṃ gatam ūrmibhiḥ sahacaraṃ pṛthubhiḥ / sa rathāṅganāmavanitāṃ karuṇair anubadhnatīm abhinananda rutaiḥ //
和訳
黄金の山腹のそばで、赤みを帯びた大きな波と見分けがつかなくなった伴侶を、哀れな鳴き声で探し求めるチャクラヴァーカ（鴛鴦）の雌鳥を、彼は喜ばしく眺めた。

rathāṅga（チャクラヴァーカ、赤鴛鴦）は夜に雌雄が離れて嘆くとされる鳥。伴侶が黄金色の波に紛れて見えなくなるという詩想。

9
Sanskrit
sitavājine nijagadū rucayaś calavīcirāgaracanāpaṭavaḥ / maṇijālam ambhasi nimagnam api sphuritaṃ manogatam ivākṛtayaḥ //
和訳
揺れる波を彩ることに巧みな輝きが、白馬の御者（アルジュナ）に告げた。水中深くに沈んでいても煌めく宝石の網を。あたかも外に表れた仕草が心の内を示すように。

sitavājin（白馬の御者）はアルジュナの別名。水中の宝石が光で存在を知らせるのを、心中の感情が外面の挙動で知れる喩えに重ねる。

10
Sanskrit
upalāhatoddhatataraṅgadhṛtaṃ javinā vidhūtavitataṃ marutā / sa dadarśa ketakaśikhāviśadaṃ saritaḥ prahāsam iva phenam apām //
和訳
彼は、岩に打ちつけられて跳ね上がった波に支えられ、激しい風に散らされ広がった水の泡を見た。ケータカの花穂のように白く、まるで河の哄笑のようであった。
11
Sanskrit
bahu barhicandrikanibhaṃ vidadhe dhṛtim asya dānapayasāṃ paṭalam / avagāḍham īkṣitum ivaibhapatiṃ vikasadvilocanaśataṃ saritaḥ //
和訳
孔雀の目玉模様に似た発情液の水滴の集まりが、彼に喜びをもたらした。あたかも河が百の目を開いて、水中に沈んだ象の王を見つめるかのように。

barhicandrika（孔雀の尾羽の目玉模様）に象の発情液（dānapayasām）の水滴を喩え、河が「百の目」で象を見つめるという擬人化。インドラの千眼の暗示もある。

12
Sanskrit
pratibodhajṛmbhaṇavibhīnamukhī puline saroruhadṛśā dadṛśe / patadacchamauktikamaṇiprakarā galadaśrubindur iva śuktivadhūḥ //
和訳
砂洲の上で、目覚めの欠伸で口を大きく開いた真珠貝の乙女を、蓮華のような眼の彼は見た。透き通った真珠の粒が零れ落ちて、涙を流す女のようであった。
13
Sanskrit
śucir apsu vidrumalatāviṭapas tanusāndraphenalavasaṃvalitaḥ / smaradāyinaḥ smarayati sma bhṛśaṃ dayitādharasya daśanāṃśubhṛtaḥ //
和訳
水中の清らかな珊瑚の蔓の枝は、薄く濃い泡の破片に覆われて、歯の光を帯びた恋人の唇——恋情を掻き立てるそれ——を強く思い起こさせた。
14
Sanskrit
upalabhya cañcalataraṅgahṛtaṃ madagandham utthitavatāṃ payasaḥ / pratidantinām iva sa sambubudhe kariyādasām abhimukhān kariṇaḥ //
和訳
揺れる波に運ばれてくる発情の匂いを嗅ぎつけて、彼は、水中から上がってきた河馬に向かって、敵の象に立ち向かうかのように突進する象たちを認めた。
15
Sanskrit
sa jagāma vismayam udvīkṣya puraḥ sahasā samutpipatiṣoḥ phaṇinaḥ / prahitaṃ divi prajavibhiḥ śvasitaiḥ śaradabhravibhramam apāṃ paṭalam //
和訳
彼は驚嘆した。目の前で突然跳び上がろうとする蛇の激しい吐息によって天空へ噴き上げられた水の塊が、秋の雲のように美しく輝いていたのを見て。
16
Sanskrit
sa tatāra saikatavatīr abhitaḥ śapharīparisphuritacārudṛśaḥ / lalitāḥ sakhīr iva bṛhajjaghanāḥ suranimnagām upayatīḥ saritaḥ //
和訳
彼は砂洲の多い支流を渡った。その川々は、跳ね回る小魚を美しい瞳とし、豊かな腰をもつ優美な女友達のように、天の大河（ガンガー）のもとへ向かっていた。
17
Sanskrit
adhiruhya puṣpabharanamraśikhaiḥ paritaḥ pariṣkṛtatalāṃ tarubhiḥ / manasaḥ prasattim iva mūrdhni gireḥ śucim āsasāda sa vanāntabhuvam //
和訳
さらに登り、花の重みで梢を垂れた木々に四方を飾られた山頂の清らかな森の地を、彼は見出した。それは心の安らぎが姿をとったかのようであった。
18
Sanskrit
anusānu puṣpitalatāvitatiḥ phalitorubhūruhaviviktavanaḥ / dhṛtim ātatāna tanayasya hares tapase 'dhivastum acalām acalaḥ //
和訳
峰ごとに花咲く蔓草が広がり、実をつけた大木の静寂な森を擁するかの山は、ハリ（インドラ）の子がそこに留まり苦行するための揺るぎなき決意を、彼に与えた。

acalām ... acalaḥ：「不動の決意を……不動の山が」。acala（不動）の語を山と決意に掛ける巧みな反復。

19
Sanskrit
praṇidhāya tatra vidhinātha dhiyaṃ dadhataḥ purātanamuner munitām / śramam ādadhāv asukaraṃ na tapaḥ kim ivāvasādakaram ātmavatām //
和訳
その地で規則に従い心を集中させ、太古の聖者の沈黙行を修めるにあたり、苦行は彼に困難な疲労を与えなかった。自己を制する者に、何が挫けさせるものとなろうか。

purātanamuni：アルジュナは原初の聖者ナラの化身とされる（XII.33参照）。マッリナータもこの点を注記している。

20
Sanskrit
śamayan dhṛtendriyaśamaikasukhaḥ śucibhir guṇair aghamayaṃ sa tamaḥ / prativāsaraṃ sukṛtibhir vavṛdhe vimalaḥ kalābhir iva śītaruciḥ //
和訳
感覚の鎮静のみを唯一の楽とする彼は、清浄なる徳によって罪の闇を払い、日ごとに善行により成長した。汚れなき月が日ごとに光の部分を増すように。
21
Sanskrit
adharīcakāra ca vivekaguṇād aguṇeṣu tasya dhiyam astavataḥ / pratighātinīṃ viṣayasaṅgaratiṃ nirupaplavaḥ śamasukhānubhavaḥ //
和訳
識別力の徳によって悪徳から心を遠ざけた彼にとって、妨げなき寂静の楽の体験が、障碍をもたらす感官の快楽への執着を、卑しいものへと貶めた。
22
Sanskrit
manasā japaiḥ praṇatibhiḥ prayataḥ samupeyivān adhipatiṃ sa divaḥ / sahajetare jayaśamau dadhatī bibharāṃbabhūva yugapan mahasī //
和訳
瞑想と誦唱と礼拝により身を清め、天の主に近づいた彼は、生来の勇猛と後天の寂静という、二つの光輝を同時に兼ね備えた。

jayaśamau：jaya（勝利＝勇猛心）と śama（寂静）という通常は相反する二つの力を同時に体現している点が、アルジュナの超人的な質を示す。

23
Sanskrit
śirasā harinmaṇinibhaḥ sa vahan kṛtajanmano 'bhiṣavaṇena jaṭāḥ / upamāṃ yayāv aruṇadīdhitibhiḥ parimṛṣṭamūrdhani tamālatarau //
和訳
翠玉のように暗い肌を持つ彼は、沐浴によって伸びた黄褐色の髪を頭に戴き、朝焼けの光に頂を照らされたタマーラ樹に似たものとなった。

tamāla はクロモジ科の常緑樹で、暗い樹皮に白い花をつける。暗い肌のアルジュナが黄色い髪（苦行で変色した）を戴く姿をタマーラ樹の頂に朝焼けが差す情景に喩える。

24
Sanskrit

和訳
武器を携えながらも邪心を持たず、清浄な行いで聖仙たちを凌ぎ、煩悩なき彼は鹿たちをも魅了した。徳は誰を喜ばせることができないだろうか。
25
Sanskrit

和訳
（苦行の力は）四方に順風で穏やかに芳香を運ぶ風を吹かせ、季節の厳しさを退けて、太陽の光の束さえも快適なものへと変えた。
26
Sanskrit
navapallavāñjalibhṛtaḥ pracaye bṛhatas tarūn gamayatāvanatim / stṛṇatā tṛṇaiḥ pratiniśaṃ mṛdubhiḥ śayanīyatām upayatīṃ vasudhām //
和訳
摘み取る際に新芽の合掌を捧げる大木を低く撓め、毎夜やわらかな草で大地を覆って寝床としたのは——
27
Sanskrit
patitair apetajaladān nabhasaḥ pṛṣatair apāṃ śamayatā ca rajaḥ / sa dayāluneva parigāḍhakṛśaḥ paricaryayānujagṛhe tapasā //
和訳
——雲なき空から降る水滴で塵を鎮めた苦行そのもので、あたかも慈悲深き者のように、極度に痩せ衰えた彼を、苦行は奉仕によって守り育てた。

25-27節は一連の描写。苦行の功徳が自然そのものを彼に奉仕させる。主語は tapas（苦行）で、風を吹かせ、木を撓め、雨を降らせて彼に仕えるという擬人法（utprekṣā）。

28
Sanskrit
mahate phalāya tad avekṣya śivaṃ vikasannimittakusumaṃ sa puraḥ / na jagāma vismayavaśaṃ vaśināṃ na nihanti dhairyam anubhāvaguṇaḥ //
和訳
大いなる果報を予示する吉兆の花が目前に開くのを見ても、彼は驚嘆に身を任せることがなかった。自己を制する者の沈着を、威力の徳は損なわないのだ。
29
Sanskrit
tad abhūrivāsarakṛtaṃ sukṛtair upalabhya vaibhavam ananyabhavam / upatasthur āsthitaviṣādadhiyaḥ śatayajvano vanacarā vasatim //
和訳
わずかな日数の善行によって他に類なき威力が生じたのを知り、憂慮に心を捉えられた森の住人たち（グヒヤカ）は、百回の祭祀を行いし者（インドラ）の住処へ赴いた。

vanacarāḥ（森の住人）はグヒヤカたち。彼らは山の守護を任されていたが、超常的な苦行の力により世界秩序が乱されることを恐れてインドラに報告に行く。

30
Sanskrit
viditāḥ praviśya vihitānatayaḥ śithilīkṛte 'dhikṛtakṛtyavidhau / anapetakālam abhirāmakathāḥ kathayāṃbabhūvur iti gotrabhide //
和訳
認められて入り、礼を尽くした彼らは、己に託された務めの遂行が疎かであったにもかかわらず、時を逸することなく、山を裂く者（インドラ）に次のように心地よい言葉で語った。

gotrabhi（山を裂く者）はインドラの異名。マッリナータによれば、彼らが任を怠った（śithilīkṛte 'dhikṛtakṛtyavidhau）のは山の警護の職務を十分に果たしていなかったことを指す。

グヒヤカたちの言葉
Sanskrit

37
グヒヤカたちの言葉
Sanskrit
vigaṇayya kāraṇam anekaguṇaṃ nijayāthavā kathitam alpatayā / asad apy adaḥ sahitum arhati naḥ kva vanecarāḥ kva nipuṇā matayaḥ //
和訳
「多くの徳をもつかの苦行の因由をお考えの上、あるいは我らが生来の愚鈍ゆえに申したこの言葉を、たとえ不適切であってもお聞き入れくださいますよう。森の住人と明敏な知恵は、いずこに共存しましょうか。」

グヒヤカたちは自らの知性の限界を率直に認めて謝罪する。「森の住人と鋭い判断力は両立しない」という格言的表現（arthāntaranyāsa）。

38
Sanskrit
adhigamya guhyakagaṇād iti tan manasaḥ priyaṃ priyasutasya tapaḥ / nijugopa harṣam uditaṃ maghavā nayavartmagāḥ prabhavatāṃ hi dhiyaḥ //
和訳
グヒヤカの群れからこのように愛する息子の心に叶う苦行を知ったマガヴァン（インドラ）は、湧き上がる喜びを隠した。権力者の知恵は政略の道を歩むものだから。

インドラはアルジュナが己の子であることを知っており内心喜ぶが、政略上その感情を表に出さない。マッリナータは「感情を露わにすれば機密が漏れ、事業が損なわれる」と注する。

39
Sanskrit
praṇidhāya cittam atha bhaktatayā vidite 'py apūrva iva tatra hariḥ / upalabdhum asya niyamasthiratāṃ surasundarīr iti vaco 'bhidadhe //
和訳
そこでハリ（インドラ）は心を集中させ、その信仰篤き者を知りながらもあたかも初めて聞くかのように装い、彼の誓戒の堅固さを試すために、天女たちに次の言葉を述べた。
40
インドラの言葉
Sanskrit
sukumāram ekam aṇu marmabhidām atidūragaṃ yutam amoghatayā / avipakṣam astram aparaṃ katamad vijayāya yūyam iva cittabhuvaḥ //
和訳
「心を貫く武器のうち、繊細で、唯一で、微細で、遠くまで届き、必中で、対抗し得ぬもの——カーマ（愛の神）の、おまえたちのような他の武器がどこにあろうか。」

天女たちをカーマ（愛の神）の武器と呼ぶ。sukumāra（繊細）・eka（唯一）・aṇu（微細）・atidūraga（遠方に届く）・amogha（必中）・avipakṣa（対抗不能）の六属性はすべて天女と矢の双方に掛かる二重表現。

41
インドラの言葉
Sanskrit
bhavavītaye hatabṛhattamasām avabodhavāri rajasaḥ śamanam / paripīyamāṇam iva vo 'sakalair avasādam eti nayanāñjalibhiḥ //
和訳
「輪廻を超えるために大いなる闇を打ち破った者たちの、塵を鎮める覚知の水さえも、おまえたちの半ば閉じた目の器で飲まれると、枯渇してしまうのだ。」

天女たちの流し目（nayanāñjali）を「器」に喩え、悟りの水をも飲み干すという巧みな比喩。煩悩を超克した聖者の知恵さえも美女の眼差しで失われるという意。śleṣa と rūpaka の混合。

42
インドラの言葉
Sanskrit
bahudhā gatāṃ jagati bhūtasṛjā kamanīyatāṃ samabhihṛtya purā / upapāditā vidadhatā bhavatīḥ surasadmayānasumukhī janatā //
和訳
「かつて世界創造の神が、世に散らばった美をすべて集めておまえたちを造ったとき、人々は天界への旅路を切望するようになったのだ。」

ブラフマーが天女を創造する際に世界中の美を集約したとする伝承。英雄たちが戦死して天界に赴くのは、天女たちの恩寵を享受するためだという含意。

43
インドラの言葉
Sanskrit
tad upetya vighnayata tasya tapaḥ kṛtibhiḥ kalāsu sahitāḥ sacivaiḥ / hṛtavītarāgamanasāṃ nanu vaḥ sukhasaṅginaṃ prati sukhāvajitiḥ //
和訳
「さればおまえたちは赴いて、芸に巧みなる伴侶（ガンダルヴァ）と共に彼の苦行を妨げよ。離欲の者の心をも奪うおまえたちにとって、快楽に執着する者に対する勝利は、たやすいことではないか。」

sacivaiḥ（伴侶）はガンダルヴァたち。彼らは音楽の名手であり、アプサラスたちの夫とされる。Cappellerも「芸術に通じた仲間」と独訳する。

44
インドラの言葉
Sanskrit
avimṛṣyam etad abhilaṣyati sa dviṣatāṃ vadhena viṣayābhiratim / bhavavītaye na hi tathā sa vidhiḥ kva śarāsanaṃ kva ca vimuktipathaḥ //
和訳
「疑う余地なく、彼が望んでいるのは敵の殺戮による世俗の快楽であって、輪廻からの解脱ではない。弓と解脱の道はいずこに共存しようか。」

インドラはアルジュナの目的が解脱ではなく戦勝であることを見抜いている。kva śarāsanaṃ kva ca vimuktipathaḥ（弓はどこに、解脱の道はどこに）は両者の相容れなさを示す修辞疑問（arthāntaranyāsa）。

45
インドラの言葉
Sanskrit
pṛthudāmni tatra paribodhi ca mā bhavatībhir anyamunivad vikṛtiḥ / svayaśāṃsi vikramavatām avatāṃ na vadhūṣv aghāni vimṛṣyanti dhiyaḥ //
和訳
「またかの威光大いなる者に対して、他の聖仙にするように害を受けるのではないかと案ずるな。武勇ある者たちの心は、己の名声を守りつつ、女に対する悪行を考えはしないのだ。」

聖仙たちはしばしば誘惑に怒って呪いを放つが、クシャトリヤの英雄は名誉を重んじ女性を害さないとインドラは保証する。

46
Sanskrit
āśaṃsitāpaciticāru puraḥ surāṇām ādeśam ity abhimukhaṃ samavāpya bhartuḥ / lebhe parāṃ dyutim amartyavadhūsamūhaḥ sambhāvanā hy adhikṛtasya tanoti tejaḥ //
和訳
期待された栄誉の美しき報酬への希望を抱きつつ、神々の前で主の命を正面から受けた天女たちの群は、無上の輝きを帯びた。任を託された者への敬意は、その光彩を増すものだから。
Vasantatilakā
47
Sanskrit
praṇatim atha vidhāya prasthitāḥ sadmanas tāḥ stanabharanamitāṅgīr aṅganāḥ prītibhājaḥ / acalanalinalakṣmīhāri nālaṃ babhūva stimitam amarabhartur draṣṭum akṣṇāṃ sahasram //
和訳
礼拝を終えて宮殿を出発した、豊かな乳房の重みに身を屈めた喜びに満ちた女たちを、山の蓮の美しさをも奪うその姿を、天の主の千の眼は見つめても見つめ尽くすことができなかった。

インドラは千眼を持つとされるが、その千の目をもってしてもアプサラスたちの美しさを見飽きることがないという誇張表現。acalanalinalakṣmīhāri（山の蓮の美をも奪う）は長い複合語。

Puṣpitāgrā
