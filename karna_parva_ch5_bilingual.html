本章は南伝（Southern Recension）テキストの「アディヤーヤ5」（ジャナメージャヤの問いに応えてヴァイシャンパーヤナが、カルナの死を聞いたドリタラーシュトラの悲嘆を語る章）です。各段落は原典の詩節番号（8-5-N）と和訳の段落番号が対応しています。
karṇaparva — pañcamo'dhyāyaḥ (5)
第5章　ドリタラーシュトラがカルナの美徳を讃えて嘆く
janamejaya uvāca|
śrutvā karṇaṃ hataṃ yudve putrāṃścaiva palāyinaḥ|
narendraḥ kiñcidāśvasto dvijaśreṣṭha kimabravīt||
prāptavān paramaṃ duḥkhaṃ putravyasanajaṃ mahat|
tasmin yad uktavān kāle tanmamācakṣva pṛcchataḥ|| // 8-5-1-2 //
ジャナメージャヤは語った。 （1〜2）「カルナが殺され、息子たちが敗走したと聞いて、少し落ち着いた王は、バラモンの最上者よ、何と言いましたか。息子の災厄から生じた最も深い苦しみに達した者が、その時何と言ったか、尋ねる私に語ってください。」
vaiśampāyana uvāca|
śrutvā karṇasya nidhanamaśradveyamivādbhutam|
bhūtasammohanaṃ bhīmaṃ meroḥ saṃsarpaṇaṃ yathā||
visrastāṅgaḥ śvasan dīno hāhetyuktvā suduḥkhitaḥ|
vilalāpa mahārāja dhṛtarāṣṭro'mbikāsutaḥ|| // 8-5-3-9 //
ヴァイシャンパーヤナは語った。 （3〜9）カルナの死を聞いて——信じ難く驚くべきこと——すべての生き物を惑わせる恐ろしいこと、メール山が動くようなこと、バールガヴァの偉大な知者の心が惑わされるようなこと、恐るべき業のインドラが敵に敗れるようなこと、大いなる輝きの太陽が大地に落ちるようなこと、無尽の水を持つ大海が干上がるようなこと、大地・空・方角・水のすべてが消滅するようなこと、善悪の業が無に帰するようなこと——人の支配者ドリタラーシュトラは深く知恵をめぐらし、「これはありえない」とカルナの戦場での死を考え——しかし「生き物にはこのようなこともある」と思い直し——悲しみの火に焼かれ、心の中で吹き回されるかのように、体を崩し、弱々しく嘆息し、「ああ」と嘆いて、大王よ、アンビカーの子ドリタラーシュトラは悲嘆しました。
dhṛtarāṣṭra uvāca|
sañjaya ādhirathir vīraḥ siṃhadviradavikramaḥ|
vṛṣabhapratimaskandho vṛṣabhākṣagatisvaraḥ||
vṛṣabho vṛṣabhasyeva yo yuddhe na nivartate|
śatrorapi mahendrasya vajrasaṃhanano yuvā|| // 8-5-10-11 //
ドリタラーシュトラは語った。 （10〜11）「サンジャヤよ、アディラタの子は勇者にして、獅子と象の武勇を持ち、雄牛のような肩と、雄牛の目・歩み・声を持ち、雄牛の中の雄牛のように戦場から決して退かぬ者——敵が大いなるインドラであろうとも——金剛杵のような体を持つ若者。
yasya jyātalaśabdena śaravṛṣṭiraveṇa ca|
rathāśvanaramātaṅgā nāvatiṣṭhanti saṃyuge|| // 8-5-12 //
（12）その弓弦の音と矢の雨の音に、戦車・馬・人・象は戦場で立つことができなかった。
yamāśritya mahābāhuṃ dviṣatsaṅghaghnamacyutam|
duryodhano'karod vairaṃ pāṇḍuputrairmahārathaiḥ|| // 8-5-13 //
（13）大いなる腕の、敵の群れを滅ぼす不動の者——カルナを頼みにして、ドゥルヨーダナは偉大な戦車戦士パーンドゥの子たちと敵対したのだ。
sa kathaṃ rathināṃ śreṣṭhaḥ karṇaḥ pārthena saṃyuge|
nihataḥ puruṣavyāghraḥ prasahyāsahyavikramaḥ|| // 8-5-14 //
（14）その戦車戦士の最上者、人の中の虎カルナが、耐え難い武勇をもって力ずくで、なぜパールタ（アルジュナ）に戦場で殺されたのか。
yo nāmanyata vai nityamacyutaṃ ca dhanañjayam|
na vṛṣmīn sahitān anyān svabāhubaladarpitaḥ|| // 8-5-15 //
（15）常にアチュタ（クリシュナ）もダナンジャヤ（アルジュナ）もヴリシュニ族全員も、自らの腕の力を誇って歯牙にもかけなかった者が。
śārṅgagāṇḍīvadhanvānau sahitāvaparājitau|
ahaṃ divyād rathād ekaḥ pātayiṣyāmi saṃyuge|| // 8-5-16 //
（16）『シャールンガとガーンディーヴァの弓を持つ無敗の二人を、私は神聖な戦車から一人で戦場において落としてやろう』——
iti yaḥ satataṃ mandamavocallobhamohitam|
duryodhanam avācīnaṃ rājyakāmukamāturam|| // 8-5-17 //
（17）このように、愚かにして貪欲に惑わされ、うつむき加減で王位を渇望するドゥルヨーダナに、常にこう言い続けた者が。
yo'jayat sarvakāmbhojān āvantyān kekayaiḥ saha|
gāndhārān madrakān mātsyāṃs trigartāṃs taṅkaṇāñ śakān|
karamāhārayāmāsa jitvā sarvān arīṃstathā|
duryodhanasya vṛddhyarthaṃ rādheyo rathināṃ varaḥ|
divyāstravimanhātejāḥ karṇo vaikartano vṛṣaḥ|| // 8-5-18-22 //
（18〜22）すべてのカーンボージャ、ケーカヤとともにアーヴァンティ、ガーンダーラ、マドラカ、マツヤ、トリガルタ、タンカナ、シャカ、パーンチャーラ、ヴィデーハ、クリンダ、カーシ・コーサラ、スーフマ、アンガ、ヴァンガ、ニシャーダ、プンドラ・キーカタ、ヴァツァ、カリンガ、ダラダ、アシュマカ、リシカ——これらすべてを戦場で燃える矢で征服し、すべての敵を打ち負かして朝貢を取り立てた——ドゥルヨーダナの繁栄のために——ラーデーヤ（カルナ）、戦車兵の中の最上者、神聖な武器を持つ大いなる威光のヴァイカルタナの雄牛が。
senāgopaśca sa kathaṃ śatrubhiḥ paramāstravit|
ghātitaḥ pāṇḍavaiḥ śūraiḥ samare vīryaśālibhiḥ|| // 8-5-23 //
（23）その軍の守護者にして最上の武器の達人が、敵に——武勇に輝くパーンダヴァの勇者たちに——殺されたとは。
vṛṣo mahendro deveṣu vṛṣaḥ karṇo nareṣvapi|
tṛtīyamanyaṃ lokeṣu vṛṣaṃ naivānuśuśruma|| // 8-5-24 //
（24）天の神々においてはインドラが雄牛（最上者）であり、人間においてはカルナが雄牛である。世界で三番目の雄牛のことは聞いたことがない。
uccaiḥ śravā varo'śvānāṃ rājñāṃ vaiśravaṇo varaḥ|
varo mahendro devānāṃ karṇaḥ praharatāṃ varaḥ|| // 8-5-25 //
（25）馬の中の最上はウッチャイフシュラヴァス、王の中の最上はヴァイシュラヴァナ（クベーラ）、天の神の中の最上はインドラ、戦う者の中の最上はカルナだ。
yo'jitaḥ pārthivaiḥ śūraiḥ samarthairvīryaśālibhiḥ|
duryodhanasya vṛddhyarthaṃ kṛtsnāmurvīmathājayat||
yaṃ labdhvā māgadho rājā sāṃtvamāno'tha sauhṛdaiḥ|
arautsīt pārthivaṃ kṣatram ṛte yādavakauravān|| // 8-5-26-27 //
（26〜27）武勇に輝く強い諸王に打ち負かされたことのない者が、ドゥルヨーダナの繁栄のために全大地を征服した。あの者を得たマガダの王（ジャラーサンダ）は、融和・敬意・友情をもって、ヤーダヴァとカウラヴァを除いて王族のクシャトリヤを皆打ち砕いた。
taṃ śrutvā nihataṃ karṇaṃ dvairathe savyasācinā|
śokārṇave nimagno'haṃ bhinnā naur iva sāgare||
taṃ vṛṣaṃ nihataṃ śrutvā dvairathe rathināṃ varam|
śokārṇave nimagno'ham apluvaḥ sāgare yathā|| // 8-5-28-29 //
（28〜29）一騎打ちで左右の手で射る者（アルジュナ）にカルナが殺されたと聞いて、私は悲しみの海に沈んでいる。壊れた船で大海にいるように。あの雄牛が、戦車兵の中の最上者が、一騎打ちで殺されたと聞いて、私は悲しみの海に沈んでいる。泳げない者が大海にいるように。
īdṛśairyadyahaṃ duḥkhair na vinaśyāmi sañjaya|
vajrād dṛḍhataraṃ manye hṛdayaṃ mama durbhidam|| // 8-5-30 //
（30）サンジャヤよ、このような苦しみで私が滅びないとすれば、我が心は金剛杵よりも固く、砕き難いものだと思う。
jñātisaṃbandhimitrāṇāmimaṃ śrutvā parābhavam|
ko mad anyaḥ pumān loke na jahyāt sūta jīvitam|| // 8-5-31 //
（31）親族・縁者・友人のこの敗北を聞いて、御者よ、私以外のどんな人間が命を捨てずにいられようか。
viṣam agniṃ prapātaṃ ca parvatāgrād ahaṃ vṛṇe|
'mahāprasthānagamanaṃ jalaṃ prāyopaveśanam'|
na hi śakṣyāmi duḥkhāni soḍhuṃ kaṣṭāni sañjaya||
|| // 8-5-32 //
（32）毒・火・山頂からの身投げを、私は望む。サンジャヤよ、この苦しく耐え難い苦痛を耐えることはもうできない。」
iti śrīmanmahābhārate karṇaparvaṇi pañcamo'dhyāyaḥ|| 5 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五章は終わる。
