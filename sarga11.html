kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

ekādaśaḥ sargaḥ ― 第十一章

インドラが老仙人に変装してアルジュナの庵を訪れ、その苦行を称えつつ、武器を帯びる矛盾を指摘して解脱を勧める（1–36）。アルジュナは自らがクシャトリヤであり、一族の名誉回復こそが使命であると答える（37–79）。インドラは本来の姿を現し、シヴァの恩寵を得るよう命じて姿を消す（80–81）。韻律：アヌシュトゥブ（Anuṣṭubh）。第80偈はウパジャーティ（Upajāti）、第81偈はヴァサンタティラカー（Vasantatilakā）。
1
Sanskrit
athāmarṣān nisargāc ca jitendriyatayā tayā / ājagāmāśramaṃ jiṣṇoḥ pratītaḥ pākaśāsanaḥ //
Anuṣṭubh
和訳
さてインドラは、かの憤怒と生来の性質とに由来する感覚の制御に満足し、ジシュヌ（アルジュナ）の庵へと赴いた。
Mallināthaによれば、amarṣa（憤怒）は敵に対する怒りであり、nisarga（生来の性質）はアルジュナの本来の瞑想的気質。この二重の動機から生じた感覚制御にインドラが喜んだとする。pākaśāsana（パーカの懲罰者）はインドラの別名。
2
Sanskrit
munirūpo 'nurūpeṇa sūnunā dadṛśe puraḥ / drāghīyasā vayotītaḥ pariklāntaḥ kilādhvanā //
Anuṣṭubh
和訳
仙人の姿をとったインドラは、相応しい息子（アルジュナ）の前に姿を現した。年老いて、長い旅路に疲れ果てた様子で。
kila（まるで〜のように）は、実際にはインドラは疲れていないが、そのように見せかけていることを示す（Mallināthaはこの虚偽性を強調している）。
3
Sanskrit
jaṭānāṃ kīrṇayā keśaiḥ saṃhatyā paritaḥ sitaiḥ / pṛktayendukarair ahnaḥ paryanta iva saṃdhyayā //
Anuṣṭubh
和訳
白い毛髪で一面に覆われた髻の束をもって──あたかも月光に染まる夕暮れの空のように。
4
Sanskrit
viśadabhrūyugacchanna- valitāpāṅgalocanaḥ / prāleyāvatatimlāna- palāśābja iva hradaḥ //
Anuṣṭubh
和訳
白い眉に覆い隠され、目尻に皺の寄った眼をもって──霜に萎れた蓮の葉をたたえる池のように。
5
Sanskrit
āsaktabharanīkāśair aṅgaiḥ parikṛśair api / adyūnaḥ sadgṛhiṇy eva prāyo yaṣṭyāvalambitaḥ //
Anuṣṭubh
和訳
痩せ衰えた手足はまるで重荷を負っているかのようであったが、太鼓腹であった。殆ど常に杖にもたれかかり──あたかも貞淑な妻に寄り添うかのように。
Cappellerはsadgṛhiṇī（良き妻）と杖の比喩に着目し、「忠実な主婦に寄りかかるように」と訳す。adyūna（太鼓腹）はMallināthaにより「飢えを知らぬ者」の意とされる。
6
Sanskrit
gūḍho 'pi vapuṣā rājan dhāmnā lokābhibhāvinā / aṃśumān iva tanvabhra- paṭalacchannavigrahaḥ //
Anuṣṭubh
和訳
その姿を隠してはいたが、世を圧する光輝によって──薄い雲の幕に身を包まれた太陽のように輝いていた。
7
Sanskrit
jaratīm api bibhrāṇas tanum aprākṛtākṛtiḥ / cakārākrāntalakṣmīkaḥ sasādhvasam ivāśrayam //
Anuṣṭubh
和訳
老いた身体をまといながらも、その非凡な姿ゆえに庵の美を凌駕し、庵はあたかも畏れおののくかのようであった。
8
Sanskrit
abhitas taṃ pṛthāsūnuḥ snehena paritastare / avijñāte 'pi bandhau hi balāt prahlādate manaḥ //
Anuṣṭubh
和訳
プリターの息子（アルジュナ）はその人に対して四方から愛情で満ちた。なぜならば、見知らぬ血縁に対してさえも、心は否応なく喜びを覚えるものだから。
9
Sanskrit
ātitheyīm athāsādya sutād apacitiṃ hariḥ / viśramya viṣṭare nāma vyājahāreti bhāratīm //
Anuṣṭubh
和訳
ハリ（インドラ）は息子から客人としての敬意を受け、座に腰を下ろして休んだかのようにして、次のように語った。
Mallināthaによればnāmaは「見せかけだけで」の意。神であるインドラに本来休息は不要であり、その動作は演技にすぎないとする。

インドラ
Sanskrit

Sanskrit

Anuṣṭubh

Sanskrit

インドラ
Sanskrit

Anuṣṭubh
和訳
「汝には優れた心がある。善き志が汝のもとに到来したのだから。ただ、その装いが（苦行と）矛盾しており、私の心に疑いを生じさせる。」

Sanskrit
prapitsoḥ kiṃ ca te muktiṃ niḥspṛhasya kalevare / maheṣudhī dhanur bhīmaṃ bhūtānām anabhidruhaḥ //

インドラ
Sanskrit
jayam atrabhavān nūnam arātiṣv abhilāṣukaḥ / krodhalakṣma kṣamāvantaḥ kvāyudhaṃ kva tapodhanāḥ //
Anuṣṭubh

インドラ
Sanskrit
yaḥ karoti vadhodarkā niḥśreyasakarīḥ kriyāḥ / glānidoṣacchidaḥ svacchāḥ sa mūḍhaḥ paṅkayaty apaḥ //

インドラ
Sanskrit
mūlaṃ doṣasya hiṃsāder arthakāmau sma mā puṣaḥ / tau hi tattvāvabodhasya durucchedāv upaplavau //

インドラ
Sanskrit
abhidroheṇa bhūtānām arjayan gatvarīḥ śriyaḥ / udanvān iva sindhūnām āpadām eti pātratām //
Anuṣṭubh

インドラ
Sanskrit
yā gamyāḥ satsahāyānāṃ yāsu khedo bhayaṃ yataḥ / tāsāṃ kiṃ yan na duḥkhāya vipadām iva sampadām //
Anuṣṭubh
和訳
「良き仲間を持つ者にのみ到達しうるもの、そこに苦労があり、そこから恐怖が生じるもの──不幸と同じく幸福にも、苦痛をもたらさぬものは何かあろうか。」
23
インドラ
Sanskrit
durāsadān arīn ugrān dhṛter viśvāsajanmanaḥ / bhogān bhogān ivāheyān adhyāsyāpan na durlabhā //
Anuṣṭubh
和訳
「安心感から生じた満足の、近づきがたく恐ろしい敵である享楽に──蛇の胴体に乗るかのように──ひとたび溺れれば、災いは遠からず訪れる。」
bhogān bhogān iva aheyān：bhogaには「享楽」と「蛇の胴体」の双方の意があり、縁語的修辞（śleṣa）が用いられている。
24
インドラ
Sanskrit
nāntarajñāḥ śriyo jātu priyair āsāṃ na bhūyate / āsaktās tāsv amī mūḍhā vāmaśīlā hi jantavaḥ //
Anuṣṭubh
和訳
「幸運は人を区別することを知らず、その親しき者となることもできない。それに執着する愚者たち──生き物とは本来、邪まな性質を持つものだ。」
25
インドラ
Sanskrit
ko 'pavādaḥ stutipade yad aśīleṣu cañcalāḥ / sādhuvṛttān api kṣudrā vikṣipanty eva sampadaḥ //
Anuṣṭubh
和訳
「悪しき者のもとで移ろいやすいのは非難に値しない。だが卑しき富は、善き行いの者をも見捨てるのだ。」
26
インドラ
Sanskrit
kṛtavān anyadeheṣu kartā ca vidhuraṃ manaḥ / apriyair iva saṃyogo viprayogaḥ priyaiḥ saha //
Anuṣṭubh
和訳
「不快なるものとの結合と同様に、愛しきものとの離別は、他の衆生においても心を苦しめてきたし、今後も苦しめるであろう。」
Cappellerはこの偈から4偈にわたり、インドラがアルジュナの「敵への復讐のみを望み、富は求めない」という予想される反論を先取りして反駁しているとする。他の生き物も自分と同じく苦しみを感じるのだから、復讐もまた正当化されないという論理。
27
インドラ
Sanskrit

Anuṣṭubh
和訳
「愛しき者との再会あらば、空虚は充満に変わり、不幸は祝祭に等しくなり、欺かれることすら利益となる。」

インドラ

インドラ
Sanskrit
janmino 'sya sthitiṃ vidvāṃl lakṣmīm iva calācalām / bhavān mā sma vadhīn nyāyyaṃ nyāyādhārā hi sādhavaḥ //

31
インドラ
Sanskrit
vijahīhi raṇotsāhaṃ mā tapaḥ sādhi nīnaśaḥ / ucchedaṃ janmanaḥ kartum edhi śāntas tapodhana //
Anuṣṭubh

32
インドラ
Sanskrit
jīyantāṃ durjayā dehe ripavaś cakṣurādayaḥ / jiteṣu nanu loko 'yaṃ teṣu kṛtsnas tvayā jitaḥ //
Anuṣṭubh
和訳
「己の身体にある征し難き敵──眼をはじめとする感覚器官を克服せよ。それらを征したならば、この全世界を汝は征したことになる。」
33
インドラ
Sanskrit
paravān arthasaṃsiddhau nīcavṛttir apatrapaḥ / avidheyendriyaḥ puṃsāṃ gaur ivaiti vidheyatām //
Anuṣṭubh
和訳
「利益の追求において他人に依存し、卑しき行いをなし、恥を知らず、感覚を制御できぬ者は──牛のように人々の隷属に入る。」
34
インドラ
Sanskrit
śvas tvayā sukhasaṃvittiḥ smaraṇīyādhunātanī / iti svapnopamān matvā kāmān mā gās tadaṅgatām //
Anuṣṭubh
和訳
「明日になれば、今日の快楽はただ記憶の中にのみ存する。されば欲望を夢のごときものと見なし、それに身を委ねてはならぬ。」
35
インドラ
Sanskrit
śraddheyā vipralabdhāraḥ priyā vipriyakāriṇaḥ / sudustyajās tyajanto 'pi kāmāḥ kaṣṭā hi śatravaḥ //
Anuṣṭubh
和訳
「信頼すれば欺き、親しければ苦痛を与え、捨てようとしても捨てがたい──欲望とはまことに厄介な敵なのだ。」
Mallināthaはここにvirodha-ābhāsa（見かけの矛盾）の修辞を指摘する。信頼に値するものが欺くなど、欲望の本性ゆえに一見矛盾する諸性質が一つの対象に共存する。
36
インドラ
Sanskrit
vivikte 'smin nage bhūyaḥ plāvite jahnukanyayā / pratyāsīdati muktis tvāṃ purā mā bhūr udāyudhaḥ //
Anuṣṭubh
和訳
「人気なきこの山で、ガンガーに幾度も洗われたこの地で、解脱は汝に近づいている。今のうちに武器を取る者となるな。」
37
Sanskrit
vyāhṛtya marutāṃ patyāv iti vācam avasthite / vacaḥ praśrayagambhīram athovāca kapidhvajaḥ //
Anuṣṭubh
和訳
マルト神群の主（インドラ）がこのように語り終えて黙すると、猿旗の勇者（アルジュナ）は、慎ましくも重厚なことばを語った。
38
Sanskrit
prasādaramyam ojasvi garīyo lāghavānvitam / sākāṅkṣam anupaskāraṃ viṣvaggati nirākulam //
Anuṣṭubh
和訳
──その言葉は、明晰さゆえに美しく、力に満ち、重厚にして軽妙であり、含蓄を持ちながら飾りがなく、多方面にわたりながら混乱がなかった。
第38〜41偈はアルジュナの発話の質を叙述する。Mallināthaは各形容詞をインド修辞学の用語に対応させる。prasādaは「表現の明瞭さ」、ojasは「複合語の多用による力強さ」など。
39
Sanskrit
nyāyanirṇītasāratvān nirapekṣam ivāgame / aprakampyatayānyeṣām āmnāyavacanopamam //
Anuṣṭubh
和訳

Sanskrit

Sanskrit
kṣatriyas tanayaḥ pāṇḍor ahaṃ pārtho dhanaṃjayaḥ / sthitaḥ prāstasya dāyādair bhrātur jyeṣṭhasya śāsane //
Anuṣṭubh
和訳
「私はクシャトリヤ、パーンドゥの息子、パールタにして富を勝ち取る者（ダナンジャヤ）。同族の者たちによって追放された兄の命に従う者である。」
Mallināthaは各語の必然性を説明する。kṣatriyaで法的身分を示し、pāṇḍoḥ tanayaで高貴な血統を、pārthaでクンティーの嫡子であることを、dhanaṃjayaで武勇を示す。

アルジュナ
Sanskrit
kṛṣṇadvaipāyanādeśād bibharmi vratam īdṛśam / bhṛśam ārādhane yattaḥ svārādhyasya marutvataḥ //
Anuṣṭubh
和訳
「クリシュナ・ドヴァイパーヤナ（ヴヤーサ）の指示に従い、私はこのような誓戒を守っている。容易に喜ばせうるインドラの恩寵を得んと懸命に努めているのだ。」
svārādhyaは「容易に崇拝しうる」の意。アルジュナは変装したインドラの目の前で、インドラを崇拝対象として名指しする皮肉な状況が生じている。

アルジュナ
Sanskrit
durakṣān dīvyatā rājñā rājyam ātmā vayaṃ vadhūḥ / nītāni paṇatāṃ nūnam īdṛśī bhavitavyatā //
Anuṣṭubh
和訳
「不正な骰子で博打をうった王は、王国、己自身、我々兄弟、そして妻までも賭けの対象に供してしまった。これはきっと運命の定めであったのだろう。」
48
アルジュナ
Sanskrit
tenānujasahāyena draupadyā ca mayā vinā / bhṛśam āyāmiyāmāsu yāminīṣv abhitapyate //
Anuṣṭubh
和訳
「あの方は弟たちとともに、ドラウパディーとともに、私と離れて──果てしなく長い夜毎に激しく苦しんでいる。」
āyāmiyāmāsu：「延々と長い更」を重ねた表現。苦悩する者にとって夜が果てしなく長く感じられることを示す。
49
アルジュナ
Sanskrit
hṛtottarīyāṃ prasabhaṃ sabhāyām āgatahriyaḥ / marmacchidā no vacasā niratakṣann arātayaḥ //
Anuṣṭubh
和訳
「集会の場で力ずくで上衣を剥がれたあの者を前にして、恥を忘れた敵たちは、心臓を抉るような言葉で我々を切り刻んだ。」
50
アルジュナ
Sanskrit
upādhatta sapatneṣu kṛṣṇāyā gurusaṃnidhau / bhāvam ānayane satyāḥ satyaṃkāram ivāntakaḥ //
Anuṣṭubh
和訳
「貞淑なるクリシュナー（ドラウパディー）が長老たちの面前に引き出されたとき、死神は敵たちの上に、あたかも手付けを置くように、その意を据えたのだ。」
Cappellerは、死神がドゥルヨーダナたちに対し、やがて罰が下るという「保証金」（satyaṃkāra）を差し入れたかのようだと解釈する。
51
アルジュナ
Sanskrit
tām aikṣanta kṣaṇaṃ sabhyā duḥśāsanapuraḥsarām / abhisāyārkam āvṛttāṃ chāyām iva mahātaroḥ //
Anuṣṭubh
和訳
「ドゥフシャーサナに引かれゆく彼女を、集会の者たちは束の間見つめた──夕日に向かって伸びる大木の影のように。」
Cappellerは、ドゥフシャーサナを大木に、引きずられるドラウパディーをその影に、傍観するだけの者たちを太陽に譬えていると解く。
52
アルジュナ
Sanskrit
ayathārthakriyārambhaiḥ patibhiḥ kiṃ tavekṣitaiḥ / arudhyetām itīvāsyā nayane bāṣpavāriṇe //
Anuṣṭubh
和訳
「名に値する行いを果たさぬ夫たちを見て何になるのか──そう思ったかのように、彼女の両眼は涙で閉ざされた。」
53
アルジュナ
Sanskrit
soḍhavān no daśām antyāṃ jyāyān eva guṇapriyaḥ / sulabho hi dviṣāṃ bhaṅgo durlabhā satsv avācyatā //
Anuṣṭubh
和訳
「美徳を愛する長兄こそが、我々のあの最悪の境遇を甘受したのだ。敵を打ち破ることは容易だが、善き人々の間で非難されぬことは困難なのだから。」
ユディシュティラが約定の期間を守って反撃しなかった理由の説明。武力による勝利より、信義を守ることで善き人々の非難を避けることの方が難しいとする。
54
アルジュナ
Sanskrit
sthityatikrāntibhīrūṇi svacchāny ākulitāny api / toyāni toyarāśīnāṃ manāṃsi ca manasvinām //
Anuṣṭubh
和訳
「大海の水と智者の心は、たとえ揺さぶられても、分際の逸脱を恐れ、清らかさを保つ。」
55
アルジュナ
Sanskrit
dhārtarāṣṭraiḥ saha prītir vairam asmāsv asūyata / asanmaitrī hi doṣāya kūlacchāyeva sevitā //
Anuṣṭubh
和訳
「ドリタラーシュトラの息子たちとの親交が、我々に対する敵意を生み出した。悪しき者との友情は、崩れかけた岸の陰に身を寄せるようなもの──害をもたらすのみだ。」
56
アルジュナ
Sanskrit
apavādād abhītasya samasya guṇadoṣayoḥ / asadvṛtter ahovṛttaṃ durvibhāvaṃ vidher iva //
Anuṣṭubh
和訳
「非難を恐れず、善悪を等しく扱う悪行の者の内心は──運命の仕業のように計り知れない。」
57
アルジュナ
Sanskrit
dhvaṃseta hṛdayaṃ sadyaḥ paribhūtasya me paraiḥ / yady amarṣaḥ pratīkāraṃ bhujālambaṃ na lambhayet //
Anuṣṭubh
和訳
「敵に辱められた私の心がただちに砕け散らぬのは、憤怒が──腕を拠りどころとする復讐を見出しているからにほかならない。」
58
アルジュナ
Sanskrit
avadhūyāribhir nītā hariṇais tulyavṛttitām / anyonyasyāpi jihrīmaḥ kiṃ punaḥ sahavāsinām //
Anuṣṭubh
和訳
「敵に蹂躙されて鹿と同じ暮らしに貶められた我々は、互いの前ですら恥じ入る。まして近隣の者たちの前では言うまでもない。」
59
アルジュナ
Sanskrit
śaktivaikalyanamrasya niḥsāratvāl laghīyasaḥ / janmino mānahīnasya tṛṇasya ca samā gatiḥ //
Anuṣṭubh
和訳
「力の欠如ゆえに身を屈め、中身のなさゆえに軽んじられ、誇りを失った人間の行く末は──草と同じである。」
60
アルジュナ
Sanskrit
alaṅghyaṃ tat tad udvīkṣya yad yad uccair mahībhṛtām / priyatāṃ jyāyasīṃ mā gān mahatāṃ kena tuṅgatā //
Anuṣṭubh
和訳
「山々の高き峰はまさにその高さゆえに踰え難きことを見れば──偉人たちにとっての高き矜持こそ、いっそう愛しきものとなるべきではないか。」
61
アルジュナ
Sanskrit
tāvad āśrīyate lakṣmyā tāvad asya sthiraṃ yaśaḥ / puruṣas tāvad evāsau yāvan mānān na hīyate //
Anuṣṭubh
和訳
「名誉から離れぬ限り、幸運の女神はその人を守り、名声は揺るがず、その人は真の男である。」
62
アルジュナ
Sanskrit
sa pumān arthavaj janmā yasya nāmni puraḥsthite / nānyām aṅgulim abhyeti saṃkhyāyām udyatāṅguliḥ //
Anuṣṭubh
和訳
「その名が挙げられたとき、英雄を数えあげようと指を立てた者が二本目の指に移らぬ──そのような男こそ、生まれた甲斐のある者である。」
Cappellerは次のように説明する──英雄たちを指折り数えようとした者が、最初に思い浮かんだ人物があまりに傑出していて、他を挙げるのをやめてしまう情景を描いている。
63
アルジュナ
Sanskrit
durāsadavanajyāyān gamyas tuṅgo 'pi bhūdharaḥ / na jahāti mahaujaskaṃ mānaprāṃśum alaṅghyatā //
Anuṣṭubh
和訳
「踏破し難い森を擁する高き山ですら到達しうる。しかし誇り高く大いなる威力ある人を、近づきがたさは決して見捨てない。」
Mallināthaはvyatireka（比較対照）の修辞を指摘する。山は高くとも登ることができるが、誇り高い人物はそれ以上に近づきがたいとする。
64
アルジュナ
Sanskrit
gurūn kurvanti te vaṃśyān anvarthā tair vasuṃdharā / yeṣāṃ yaśāṃsi śubhrāṇi hrepayantīndumaṇḍalam //
Anuṣṭubh
和訳
「先祖たちに重みを与えるのは彼らの子孫であり、彼らによって大地は名実ともに富を運ぶものとなる──その白き名声が月輪をも恥じ入らせるような者たちは。」
65
アルジュナ
Sanskrit
udāharaṇam āśīḥṣu prathame te manasvinām / śuṣke 'śanir ivāmarṣo yair arātiṣu pātyate //
Anuṣṭubh
和訳
「怒りを、枯れた木に落ちる雷のごとく敵に下す者たち──彼らは高邁な者たちの中の先達であり、誓いの際の模範である。」
66
アルジュナ
Sanskrit
na sukhaṃ prārthaye nārtham udanvadvīcicañcalam / nānityatāśanes trasyan viviktaṃ brahmaṇaḥ padam //
Anuṣṭubh
和訳
「私は快楽を望まず、大海の波のように不安定な財をも望まない。無常という雷を恐れてブラフマンの寂静なる境地を求めるのでもない。」
67
アルジュナ
Sanskrit
pramārṣṭum ayaśaḥpaṅkam iccheyaṃ chadmanā kṛtam / vaidhavyatāpitārāti- vanitālocanāmbubhiḥ //
Anuṣṭubh
和訳
「私が望むのは、詭計によって塗りつけられた不名誉の泥を──寡婦の苦しみに悶える敵の妻たちの涙によって洗い流すことだ。」
68
アルジュナ
Sanskrit
apahasye 'thavā sadbhiḥ pramādo vāstu me dhiyaḥ / asthānavihitāyāsaḥ kāmaṃ jihretu vā bhavān //
Anuṣṭubh
和訳
「あるいは私は賢者たちに嘲笑されるのかもしれぬ。あるいは私の判断の過ちなのかもしれぬ。実らぬ所に労を費やしたあなたが恥じ入るのはやむを得まい。」
69
アルジュナ
Sanskrit
vaṃśalakṣmīm anuddhṛtya samucchedena vidviṣām / nirvāṇam api manye 'ham antarāyaṃ jayaśriyaḥ //
Anuṣṭubh
和訳
「敵の根絶によって一族の輝きを回復するまでは、私は涅槃さえも勝利の栄光への障碍と見なす。」
70
アルジュナ
Sanskrit
ajanmā puruṣas tāvad gatāsus tṛṇam eva vā / yāvan neṣubhir ādatte viluptam aribhir yaśaḥ //
Anuṣṭubh
和訳
「敵に奪われた名声を矢によって取り戻すまでは、人は生まれていないに等しく、死者に等しく、いや草にも等しい。」
71
アルジュナ
Sanskrit
anirjayena dviṣatāṃ yasyāmarṣaḥ praśāmyati / puruṣoktiḥ kathaṃ tasmin brūhi tvaṃ hi tapodhana //
Anuṣṭubh
和訳
「敵を征することなく怒りが鎮まるような者を、どうして男と呼べようか。おお苦行の富者よ、あなたこそ答えよ。」
72
アルジュナ
Sanskrit
kṛtaṃ puruṣaśabdena jātimātrāvalambinā / yo 'ṅgīkṛtaguṇaiḥ ślāghyaḥ savismayam udāhṛtaḥ //
Anuṣṭubh
和訳
「ただ生まれに依拠するだけの『男』という称号はもう沢山だ。真に徳を認めた人々から驚嘆とともに讃えられてこそ、称えるに足る者なのだ。」
73
アルジュナ
Sanskrit
grasamānam ivaujāṃsi sadasā gauraveritam / nāma yasyābhinandanti dviṣo 'pi sa pumān pumān //
Anuṣṭubh
和訳
「集会において敬いをもって唱えられ、聞く者の光輝を呑み込むかのようなその名を、敵すらも称える者──その男こそ真の男である。」
Mallināthaはpumān pumānの反復にlāṭānuprāsa（同語反復の修辞）を指摘する。最初のpumānは種族としての「男」、二番目は徳による「真の男」の意。
74
アルジュナ
Sanskrit
yathāpratijñaṃ dviṣatāṃ yudhi praticikīrṣayā / mamaivādhyeti nṛpatis tṛṣyann iva jalāñjaleḥ //
Anuṣṭubh
和訳
「誓いのとおりに戦場で敵に報復せんとして、王は渇いた者が一掬の水を求めるように、ひたすら私を待ち望んでいる。」
75
アルジュナ
Sanskrit
sa vaṃśasyāvadātasya śaśāṅkasyeva lāñchanam / kṛcchreṣu vyarthayā yatra bhūyate bhartur ājñayā //
Anuṣṭubh
和訳
「困難に際して主君の命が果たされぬところ──その者は清浄なる一族にとって、月面の汚点にも等しい。」
76
アルジュナ
Sanskrit
kathaṃ vādīyatām arvāṅ munitā dharmarodhinī / āśramānukramaḥ pūrvaiḥ smaryate na vyatikramaḥ //
Anuṣṭubh
和訳
「義務を妨げる出家をなぜ時期を待たずに受け入れるべきか。先人たちが定めたのは生活期の順序であって、その逸脱ではない。」
Cappellerの注釈によれば、四住期の順序は学生期（brahmacārin）、家住期（gṛhastha）、林住期（vānaprastha）、遊行期（bhikṣu）であり、アルジュナはまだ家住期の義務を果たし終えていないので、出家は時期尚早であるという論理。
77
アルジュナ
Sanskrit
āsaktā dhūr iyaṃ rūḍhā jananī dūragā ca me / tiraskaroti svātantryaṃ jyāyāṃś cācāravān nṛpaḥ //
Anuṣṭubh
和訳
「この重き責務は私に課せられている。遠くにいる母も、そして徳高き兄の王も、私の自由を許さないのだ。」
78
アルジュナ
Sanskrit
svadharmam anurundhante nātikramam arātibhiḥ / palāyante kṛtadhvaṃsā nāhavān mānaśālinaḥ //
Anuṣṭubh
和訳
「誇りある者たちは己の法に従い、それを逸脱しない。敵に打ち負かされたとて、戦場から逃げはしない。」
79
アルジュナ
Sanskrit
vicchinnābhravilāyaṃ vā vilīye nagamūrdhani / ārādhya vā sahasrākṣam ayaśaḥśalyam uddhare //
Anuṣṭubh
和訳
「風に引き裂かれた雲のようにこの山頂で消え果てるか、あるいはインドラの恩寵を得て不名誉の棘を抜き去るか──そのいずれかだ。」
80
Sanskrit
ity uktavantaṃ parirabhya dorbhyāṃ tanūjam āviṣkṛtadivyamūrtiḥ / aghopaghātaṃ maghavā vibhūtyai bhavodbhavārādhanam ādideśa //
Upajāti
和訳
かく語った息子を両腕で抱きしめ、インドラは神々しい本来の姿を現し、繁栄のために、罪を滅ぼすシヴァの礼拝を命じた。
81
インドラ
Sanskrit
prīte pinākini mayā saha lokapālair lokatraye 'pi vihitāprativāryavīryaḥ / lakṣmīṃ samutsukayitāsi bhṛśaṃ pareṣām uccārya vācam iti tena tirobabhūve //
Vasantatilakā
和訳
「弓を持つ神（シヴァ）が喜んだならば、我と世界の守護者たちから、三界においても阻み得ぬ力を与えられ、汝は敵の幸運をことごとく己のものとするであろう。」──こう告げて、インドラは姿を消した。
iti bhāravikṛtau mahākāvye kirātārjunīye ekādaśaḥ sargaḥ //
バーラヴィ作『キラータールジュニーヤ』第十一章 終
