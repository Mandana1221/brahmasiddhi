kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

trayodaśaḥ sargaḥ ― 第十三章

アルジュナが猪の出現を目撃し、疑惑を抱く（1–13）。シヴァとアルジュナが同時に矢を射て猪を倒す（14–31）。キラータ（シヴァの変装した従者）がアルジュナの前に現れ、矢の所有権を主張してその返還を求める長い演説を行う（32–71）。韻律：アウパッチャンダシカ（Aupacchandasika、マーラバーリニー型）。第35偈以降はラトーッダター（Rathoddhatā）。第71偈はヴァサンタティラカー（Vasantatilakā）。
1
Sanskrit
vapuṣāṃ parameṇa bhūdharāṇām atha sambhāvyaparākramaṃ vibhede / mṛgam āśu vilokayāṃcakāra sthiradaṃṣṭrogramukhaṃ mahendrasūnuḥ //
Mālabhāriṇī（Aupacchandasika）
和訳
さて大インドラの息子（アルジュナ）は、山々をも引き裂くほどの巨大な体躯を持ち、堅固な牙と恐ろしい顔を備えた猪を、ただちに目にした。
sambhāvyaparākramaは「その武勇が推量されるほどの」の意。Mallināthaはvibhedeを「引き裂くこと」と解し、山々を破壊しうる力を持つ猪として描写する。

Sanskrit
athavaiṣa kṛtajñayeva pūrvaṃ bhṛśam āsevitayā ruṣā na muktaḥ / avadhūya virodhinīḥ kim ārān mṛgajātīr abhiyāti māṃ javena //
Mālabhāriṇī（Aupacchandasika）
和訳
「あるいはこの猪は、前世から深く抱いた怒りを、恩讐を忘れぬ者のように手放さず、敵対する他の獣の群れを振り捨てて、私に向かって一心に突進してくるのか。」
Mallināthaはpūrvamを「前世において」と解し、前世の因縁による怨恨の継続として読む。

9
Sanskrit
ayam eva mṛgavyasattrakāmaḥ prahariṣyan mayi māyayā śamasthe / pṛthubhir dhvajinīsravair akārṣīc cakitodbhrāntamṛgāṇi kānanāni //
Mālabhāriṇī（Aupacchandasika）
和訳
「この者こそが狩場を我が物とせんとして、幻術によって安静の中にいる私を攻撃しようとしたのだ。大軍の喧騒で森の獣たちを怯えさせ、混乱に陥れたのも、この者に違いない。」
Mallināthaはmṛgavyasattrakāmaを「狩猟の地を欲する者」と解する。アルジュナが先の軍勢の出現（第12章）もこの者の仕業と推測する場面。
10
Sanskrit
bahuśaḥ kṛtasatkṛter vidhātuṃ priyam icchann athavā suyodhanasya / kṣubhitaṃ vanagocarābhiyogād gaṇam āśiśriyad ākulaṃ tiraścām //
Mālabhāriṇī（Aupacchandasika）
和訳
「あるいは、たびたび恩恵を受けたスヨーダナ（ドゥルヨーダナ）のために、その喜びを果たさんと欲して、森の獣の群れに侵入したのかもしれない。森の住処を侵されて動揺する獣たちの群れの中に。」
Cappellerは「私を殺すことでスヨーダナを喜ばせようとして」と解釈しており、Mallināthaの注もこれを支持する。

Sanskrit
avalīḍhasanābhir aśvasenaḥ prasabhaṃ khāṇḍavajātavedasā vā / pratikartum upāgataḥ samanyuḥ kṛtamanyur yadi vā vṛkodareṇa //
Mālabhāriṇī（Aupacchandasika）
和訳
「あるいはカーンダヴァの森の火によって一族を激しく滅ぼされたアシュヴァセーナが、怒りに燃えて復讐に来たのか。それとも、ヴリコーダラ（ビーマ）に怒りを抱く何者かか。」
アシュヴァセーナはナーガ王タクシャカの息子。パーンダヴァたちはかつてアルジュナの指揮のもとカーンダヴァの森を焼き払い、タクシャカ一族の多くが滅んだ。

Sanskrit
kuru tāta tapāṃsy amārgadāyī vijayāyety alam anvaśān munir mām / balinaś ca vadhād ṛte 'sya śakyaṃ vratasaṃrakṣaṇam anyathā na kartum //

Sanskrit
iti tena vicintya cāpanāma prathamaṃ pauruṣacihnam ālalambe / upalabdhaguṇaḥ parasya bhede sacivaḥ śuddha ivādade ca bāṇaḥ //
Mālabhāriṇī（Aupacchandasika）
和訳
このように思案して、彼は弓という男子の第一の標しを手に取った。そして、敵を裂く能力が証明された、清廉な大臣のような矢を弦に据えた。
弓はpauruṣacihna（男子の武勇の象徴）。矢は、敵の間に分裂を生じさせる純粋な宰相（saciva）に喩えられる。bhedaは「裂く」と「離間策」の両義。

Sanskrit
anubhāvavatā guru sthiratvād avisaṃvādi dhanur dhanaṃjayena / svabalavyasane 'pi pīḍyamānaṃ guṇavan mitram ivānatiṃ prapede //
Mālabhāriṇī（Aupacchandasika）
和訳
威厳に満ちたダナンジャヤ（アルジュナ）によって引かれた弓は、堅固さゆえに頼もしく裏切ることなく、自らの力が衰えても圧迫に耐えて撓む——あたかも徳を備えた友が敬意をもって身を屈するかのように。
弓と友人の二重の意味を持つシュレーシャ（掛詞）。guṇaは「弦」と「美徳」、sthiratvaは「堅牢さ」と「忠実さ」、ānatim prapedeは「撓んだ」と「敬意を示した」を兼ねる。

Sanskrit

Mālabhāriṇī（Aupacchandasika）
和訳

Sanskrit
vicakarṣa ca saṃhiteṣur uccaiś caraṇāskandananāmitācalendraḥ / dhanurāyatabhogavāsukijyā- vadanagranthivimuktavahni śambhuḥ //
Mālabhāriṇī（Aupacchandasika）
和訳
シャンブ（シヴァ）もまた矢を番えて弓を大きく引き絞った。足を踏みしめて山の王を押し撓め、弦はヴァースキの長大な体のごとく、その結び目（口）から炎が放たれた。
弦を蛇王ヴァースキに喩える。弦の結び目（granthi）はヴァースキの頭部（口）に相当し、そこから炎が吹き出るとする。

Sanskrit

Mālabhāriṇī（Aupacchandasika）
和訳
世界の滅亡の唯一の原因たるバヴァ（シヴァ）と白馬を御すアルジュナとが、同じ目的を果たさんとする両者の中間に、敵（猪）は立った。あたかも語基と接辞の間に、消滅すべきアヌバンダ（指示文字）が立つように。
文法学（パーニニ文法）の比喩。語基（prakṛti）と接辞（pratyaya）の間のアヌバンダ（指示的子音）は意味に貢献せず最終的に除去される。敵も同様に滅ぼされる運命にある。Cappellerも「文法から取られた比喩」と注する。

その矢は、卑しき者に施された恩恵のように、猪の中に留まらず姿を消し、力を発揮したにもかかわらず、自らの重さ（威厳）ゆえに下を向き、己の武勇に恥じ入るかのようであった。
34
Sanskrit
sa samuddharatā vicintya tena svarucaṃ kīrtim ivottamāṃ dadhānaḥ / anuyukta iva svavārtam uccaiḥ parirebhe nu bhṛśaṃ vilocanābhyām //
Mālabhāriṇī（Aupacchandasika）
和訳
思慮深くその矢を引き抜いたアルジュナは、最高の栄光のように自らの輝きを帯びるその矢を、安否を尋ねるかのように、両の眼をもって熱く抱擁した。
矢を友人のように両眼で「抱擁する」（parirebhe vilocanābhyām）とは、熱い視線で見つめることの比喩。Mallināthaは「通常の安否の問いに代えて、愛情ある視線をもって出迎えた」と注する。
35
Sanskrit
tatra kārmukabhṛtaṃ mahābhujaḥ paśyati sma sahasā vanecaram / saṃnikāśayitum agrataḥ sthitaṃ śāsanaṃ kusumacāpavidviṣaḥ //
Rathoddhatā
和訳
その場で、長い腕の勇者（アルジュナ）は突然、弓を持つ森の住人（キラータ）が目の前に立っているのを見た。花の弓の敵（シヴァ＝カーマの敵）の命を伝えるために。
36
Sanskrit
sa prayujya tanaye mahīpater ātmajātisadṛśīṃ kilānatim / sāntvapūrvam abhinītihetukaṃ vaktum ittham upacakrame vacaḥ //
Rathoddhatā
和訳
そのキラータは王子に対し、自らの種族にふさわしい礼を捧げた上で、宥めの意を込めた巧みな言葉を、次のように語り始めた。
Mallināthaはkila（～だという）を注目し、キラータの「種族」は偽りであるがゆえにこの語が用いられていると指摘する。実際にはシヴァの化身である。
37
キラータの演説（37–71）
Sanskrit
śāntatā vinayayogi mānasaṃ bhūridhāma vimalaṃ tapaḥ śrutam / prāha te nu sadṛśī divaukasām anvavāyam avadātam ākṛtiḥ //
Rathoddhatā
和訳
「あなたの静謐さは、修養に適った心を語り、偉大なる輝きは清浄な苦行を、神々に等しい姿は清らかな血統を物語っている。」
38
Sanskrit
dīpitas tvam anubhāvasampadā gauraveṇa laghayan mahībhṛtaḥ / rājase munir apīha kārayann ādhipatyam iva śātamanyavam //
Rathoddhatā
和訳
「あなたは威厳の豊かさで輝き、威光によって王たちをも凌駕している。聖仙であるにもかかわらず、ここでインドラの支配権をさえ行使しているかのように輝いている。」
39
Sanskrit
tāpaso 'pi vibhutām upeyivān āspadaṃ tvam asi sarvasampadām / dṛśyate hi bhavato vinā janair anvitasya sacivair iva dyutiḥ //
Rathoddhatā
和訳
「苦行者でありながらも威厳に達し、あなたはすべての繁栄の拠り所である。なぜなら、人々の随行なくともあなたの光輝は、大臣に伴われているかのように見えるのだから。」
40
Sanskrit
vismayaḥ ka iva vā jayaśriyā naiva muktir api te davīyasī / īpsitasya na bhaved upāśrayaḥ kasya nirjitarajastamoguṇaḥ //
Rathoddhatā
和訳
「勝利の幸運について何の驚きがあろうか。あなたにとっては解脱さえも遠くはない。ラジャスとタマスの性質を克服した者に、何の望みが叶わぬことがあろうか。」
41
Sanskrit
hrepayann ahimatejasaṃ tviṣā sa tvam ittham upapannapauruṣaḥ / hartum arhasi varāhabhedinaṃ nainam asmadadhipasya sāyakam //
Rathoddhatā
和訳
「輝きをもって太陽をも恥じ入らせるほどの武勇を備えたあなたが、我が主の矢——猪を貫いたこの矢——を奪い取るのはふさわしくない。」
42
Sanskrit
smaryate tanubhṛtāṃ sanātanaṃ nyāyyam ācaritam uttamair nṛbhiḥ / dhvaṃsate yadi bhavādṛśas tataḥ kaḥ prayātu vada tena vartmanā //
Rathoddhatā
和訳
「最も優れた人々によって、生あるものの永遠なる正しい行いが記憶されている。もしあなたのような者がそれを壊すならば、言え、いったい誰がその道を歩むというのか。」
43
Sanskrit
ākumāram upadeṣṭum icchavaḥ saṃnivṛttim apathān mahāpadaḥ / yogaśaktijitajanmamṛtyavaḥ śīlayanti yatayaḥ suśīlatām //
Rathoddhatā
和訳
「少年の頃から、大いなる災いの因たる邪道からの離反を教えんとし、瑜伽の力で生死を超克した行者たちは、善き行いを実践している。」
44
Sanskrit
tiṣṭhatāṃ tapasi puṇyam āsajan sampado 'nuguṇayan sukhaiṣiṇām / yogināṃ pariṇaman vimuktaye kena nāstu vinayaḥ satāṃ priyaḥ //
Rathoddhatā
和訳
「苦行に専念する者には功徳を生じさせ、楽を求める者には富を増やし、瑜伽行者には解脱へと熟する——正しき行いが善き人々に愛されないわけがあろうか。」
四つの人生の目的（puruṣārtha）のうち三つ（法・財・解脱）が正しい行いから生じることを説く。
45
Sanskrit
nūnam atrabhavataḥ śarākṛtiṃ sarvathāyam anuyāti sāyakaḥ / so 'yam ity anupapannasaṃśayaḥ kāritas tvam apathe padaṃ yayā //
Rathoddhatā
和訳
「たしかに、この矢はあなた様の矢の形にあらゆる点で似ている。『これが自分のだ』という根拠なき確信によって、あなたは不義の道に足を踏み入れさせられたのだ。」
46
Sanskrit
anyadīyaviśikhe na kevalaṃ niḥspṛhasya bhavitavyam āhṛte / nighnataḥ paranibarhitaṃ mṛgaṃ vrīḍitavyam api te sacetasaḥ //
Rathoddhatā
和訳
「聡明なあなたは、他者の矢を奪い取ることに無欲であるべきのみならず、他者が倒した獲物を射ることをも恥じるべきである。」
47
Sanskrit
saṃtataṃ niśamayanta utsukā yaiḥ prayānti mudam asya sūrayaḥ / kīrtitāni hasite 'pi tāni yaṃ vrīḍayanti caritāni māninam //
Rathoddhatā
和訳
「賢者たちがたえず熱心に聞き入っては喜びに浸るあの方の偉業も、たとえ戯れに讃えられただけで、慎み深いあの方を恥じ入らせるのだ。」
48
Sanskrit
anyadoṣam iva saḥ svakaṃ guṇaṃ khyāpayet katham adhṛṣṭatājaḍaḥ / ucyate sa khalu kāryavattayā dhig vibhinnabudhasetum arthitām //
Rathoddhatā
和訳
「謙虚さゆえに沈黙する者が、どうして他者の欠点のように自らの美徳を示すであろうか。やむを得ぬ目的があればこそ言うのだ。智者の定めた限度を越える要求には災いあれ。」
Cappellerの解釈：「我が主があなたに伝えることは自慢ではなく特定の目的がある。その目的が賢者の設けた限度を越えるとき呪われるべきだ」。
49
Sanskrit
durvacaṃ tad atha mā sma bhūn mṛgas tvām asau yad akariṣyad ojasā / nainam āśu yadi vāhinīpatiḥ pratyapatsyata śitena pattriṇā //
Rathoddhatā
和訳
「あの猪がその力をもってあなたに何をしたであろうか、もし我が軍の長がただちに鋭い矢をもって迎え撃たなかったならば——その不吉なことが起きずに済んだのだから。」
50
Sanskrit
ko nv imaṃ harituraṅgam āyudha- stheyasīṃ dadhatam aṅgasaṃhatim / vegavattaramṛte camūpater hantum arhati śareṇa daṃṣṭriṇam //
Rathoddhatā
和訳
「インドラの金剛杵のごとく堅固な体躯を持つこの獰猛な牙獣を、我が軍主の迅速なる矢を除いて、いったい誰が一矢で倒しえたであろうか。」
51
Sanskrit
mitram iṣṭam upakāri saṃśaye medinīpatir ayaṃ tathā ca te / taṃ virodhya bhavatā nirāsi mā sajjanaikavasatiḥ kṛtajñatā //
Rathoddhatā
和訳
「この王は危難の際にあなたの親しく有益な友であった。その者と敵対して、善人のみに宿る感謝の念を滅ぼしてはならない。」
52
Sanskrit
labhyam ekasukṛtena durlabhā rakṣitāram asurakṣyabhūtayaḥ / svantam antavirasā jigīṣatāṃ mitralābham anu lābhasampadaḥ //
Rathoddhatā
和訳

53
Sanskrit
cañcalaṃ vasu nitāntam unnatā medinīm api haranty arātayaḥ / bhūdharasthiram upeyam āgataṃ māvamaṃsta suhṛdaṃ mahīpatim //
Rathoddhatā
和訳

54
Sanskrit
jetum eva bhavatā tapasyate nāyudhāni dadhate mumukṣavaḥ / prāpsyate ca sakalaṃ mahībhṛtā saṃgatena tapasaḥ phalaṃ tvayā //

55
Sanskrit
vājibhūmir ibharājakānanaṃ santi ratnanicayāś ca bhūriśaḥ / kāñcanena kim ivāsya pattriṇā kevalaṃ na sahate vilaṅghanam //
Rathoddhatā
和訳

56
Sanskrit

Rathoddhatā
和訳

57
Sanskrit

Rathoddhatā
和訳

ラーマとスグリーヴァの友情はラーマーヤナの有名な逸話。偶然の出会いから互いに助け合う関係が生まれた。
58
Sanskrit
nābhiyoktum anṛtaṃ tvam iṣyate kas tapasviviśikheṣu cādaraḥ / santi bhūbhṛti śarā hi naḥ pare ye parākramavasūni vajriṇaḥ //
Rathoddhatā
和訳

59
Sanskrit

Rathoddhatā

60
Sanskrit

Rathoddhatā
和訳

61
Sanskrit
śaktir arthapatiṣu svayaṃgrahaṃ prema kārayati vā niratyayam / kāraṇadvayam idaṃ nirasyataḥ prārthanādhikabale vipatphalā //
Rathoddhatā
和訳

Cappellerの解釈：力があるか、あるいは相手の確固たる愛情があるかの二つの根拠があってこそ自ら取ることが許される。
62
Sanskrit
astravedam adhigamya tattvataḥ kasya ceha bhujavīryaśālinaḥ / jāmadagnyam apahāya gīyate tāpaseṣu caritārtham āyudham //
Rathoddhatā
和訳
「武器の学を真に会得し、腕の武勇に輝く者が、ジャーマダグニヤ（パラシュラーマ）を除いて、苦行者の中で誰か称えられようか。武器をもって目的を達した者として。」
パラシュラーマ（ジャーマダグニヤ）はバラモンでありながら武器を極めた唯一の例外。苦行者は本来武器と無縁であるべきという論旨。

Sanskrit

和訳

64
Sanskrit

Rathoddhatā
和訳

65
Sanskrit

67

68
Sanskrit
