पञ्चमः सर्गः

第五章　進軍の描写（yātrāvarṇana）

Metre: vasantatilakā throughout — tabhajā jagau gaḥ (14 syllables per pāda)

クリシュナ軍がライヴァタカ山に向けて進軍する様子を描写する

V.1
Sanskrit (IAST) itthaṃ giraḥ priyatamā iva so 'vyalīkāḥ śuśrāva sūtatanayasya tadā vyalīkāḥ / rantuṃ nirantaram iyeṣa tato 'vasāne tāsāṃ girau ca vanarājipaṭaṃ vasāne //
和訳

かくして彼（クリシュナ）は、最愛の女の言葉のように偽りなき、御者の子ダールカの言葉を聴いた。その言葉が終わるや、森の列が衣のように覆うかの山（ライヴァタカ）で、絶え間なく遊ぶことを望んだ。

注

【Vallabhadeva】

彼（ハリ＝クリシュナ）はこのように、心に快い（avyalīka）、すなわち真実なる（vyalīka＝虚偽を欠く）ダールカの言葉を、最愛の女の言葉のごとく聴いた。その言葉が終わると、森の列が衣のように纏うライヴァタカ山で遊ぶことを望んだ。yamaka（同音反復）：vyalīkāḥ / vyalīkāḥ、vasāne / vasāne。

【Mallinātha】

avyalīkāḥ は「不快を離れた」の意。「vyalīkaṃ tv apriye 'nṛte」（Amara）。priyatamāḥ は最愛の女に比せられる。vyalīkāḥ は「虚偽なき＝真実なる」。vanarājipaṭaṃ vasāne は「森の列という衣を纏う」、√vas（着衣）のśānac。upamā と yamaka の混合（saṃsṛṣṭi）。本章は全篇 vasantatilakā韻律。「uktā vasantatilakā tabhajā jagau gaḥ」。

V.2
Sanskrit (IAST) taṃ sa dvipendratulitātulatuṅgaśṛṅgam abhyullasatkadalikāvanarājim uccaiḥ / vistāraruddhavasudho 'nvacalaṃ cacāla lakṣmīṃ dadhat pratigireralaghur balaughaḥ //
和訳

象王にも比されるほどの、比類なき高き峰を持つかの山に向かって、そびえ立つバナナ樹の列を伴い、広がりをもって大地を覆い、もう一つの山のごとき威容を湛えつつ、大いなる軍勢が進んだ。

注

【Vallabhadeva】

balaugha（軍勢の奔流）が acalam（ライヴァタカ山）に向けて cacāla（進んだ）。kadalikā（バナナ樹）＝旗竿の比喩。pratigireralaghur lakṣmīṃ dadhat：もう一つの山のごとき壮麗さを帯びている。anu は karmapravacānīya で二格支配。

【Mallinātha】

kadalikā は旗竿（dhvajaダンダ）、vanarāji はバナナ樹の列。dvipendratulita は象王に匹敵する峰の形容。pratigireḥ lakṣmīṃ dadhat は「いかなる山に対しても勝る輝きを帯びた」の意。nidarśanā を通じた utprekṣā、saṃkara（修辞の混合）。

V.3
Sanskrit (IAST) bhāsvatkaravyatikarollasitāmbarāntās sāpatrapā iva mahājanadarśanena / saṃvivyur ambaravikāsi camūsamutthaṃ pṛthvīrajaḥ karabhakaṇṭhakaḍāram āśāḥ //
和訳

太陽の光線が交差して空の果てまで輝かせる諸方位は、大勢の人に見られて恥じらうかのように、空に広がる軍勢から立ちのぼる、駱駝の首のごとき赤褐色の土埃を身に纏った。

注

【Vallabhadeva】

āśāḥ（諸方位）が pṛthvīrajaḥ（大地の塵）を saṃvivyuḥ（纏った）。bhāsvat（太陽）の kara（光線）の vyatikara（交差）により ambarānta（衣の端／空の果て）が輝く。mahājanadarśanena sāpatrapāḥ iva：大勢の人に見られて恥じらう女のように。karabhakaṇṭhakaḍāra：三歳の駱駝の首のような赤褐色。samāsokti（圧縮比喩）。

【Mallinātha】

āśāḥ は方角。ambara は二義：空（vyoman）と衣（vāsas）。sāpatrapā は「恥じらいある」（Amara「lajjā sāpatrapāntyataḥ」）。karabha は若い駱駝（Amara「uṣṭre kramelakaḥ」）。kaḍāra は赤褐色（Amara「kaḍāraḥ kapiśaḥ piṅgaḥ」）。saṃvivyuḥ は√vyañ（纏う）。非情物に女性のふるまいを重ねる samāsokti、sāpatrapā という utprekṣā に裏打ちされた saṃkara。

V.4
Sanskrit (IAST) āvartinaḥ śubhaphalapradaśaktiyuktāḥ saṃpannadevamāṇayo bhṛtarandhrabhāgāḥ / aśvāḥ pyadhur vasumatīm atirocamānās tūrṇaṃ payodhaya ivormibhir āpatantaḥ //
和訳

旋毛を持ち、吉祥の果を与える力を具え、完全なる「神の宝石」を備え、脇腹も満ちた馬たちは、波を打ち寄せて迫り来る大洋のように、すばやく大地を覆い尽くした。

注

【Vallabhadeva】

全篇 śleṣa（掛詞）。āvartin（馬：吉祥の旋毛を持つ／海：渦巻きを持つ）。śaktiyukta（馬：能力を具える、また śukti＝旋毛の特殊形を持つ／海：真珠貝を持つ）。devamāṇi（馬：喉の旋毛 nigālāvarta ／海：宝石 kaustubha を蔵す）。bhṛtarandhrabhāga（馬：脇腹が満ちた／海：水で満ちた深み）。atirocamāna（馬：rocamānā と呼ばれる喉の旋毛を持つ／海：光り輝く）。ūrmibhiḥ（馬：特殊な歩法／海：波）。pyadhuḥ は api+√dhā（覆う）の luṅ。

【Mallinātha】

āvartin は十の吉祥旋毛を有すること。śakti は śukti（旋毛の一種、Vaijayantī に「vakṣaḥsthāḥ śuktayas tisra ūrdhvaromā jayāvahāḥ」と）。devamāṇi は nigālāvarta。ūrmi は馬の歩法の特殊形。「一つの語幹から二つの意味が得られる」ことによる upamā を含む saṃkara。

V.5
Sanskrit (IAST) ārakṣam agram avamatya sṛṇiṃ śitāgram ekaḥ palāyata javena kṛtārtanādaḥ / anyaḥ punar muhur udapluvat āstabhāram anyonyataḥ pathi batābibhitām ibhoṣṭrau //
和訳

道中、象と駱駝は互いに怯えた。一方（象）は額に突き刺さった鋭い先端の鉤を振り払い、悲鳴を上げながら全速力で逃げ去り、他方（駱駝）はまた荷を振り捨てては繰り返し跳ね上がった。まことに！

注

【Vallabhadeva】

ibhoṣṭrau（象と駱駝の双数形）が pathi（道で）anyonyataḥ（互いに）abibhitām（怯えた）。生来の習性である。ekaḥ ibhaḥ：象は ārakṣa（額の下部、Amara「kumbhayoradhaḥ pradeśaḥ」）に食い込んだ sṛṇi（鉤、aṅkuśa）を avamatya（振り払い）、ārtanāda（悲鳴）を上げて palāyata（逃走した）。√plu の luṅ 形 udapluvat。svabhāvokti（自然描写）。

【Mallinātha】

abibhitām は√bhī（恐れる）の luṅ。「bhiyo 'nyatarasyām」により ītva。bata は驚嘆。ekaḥ ibhaḥ（一頭の象）。palāyata は parā+√i の luṅ、「upasargāt syatau」により reph の latva。anyaḥ（駱駝）は udapluvat（√plu、跳躍した）。svabhāvokti。

V.6
Sanskrit (IAST) āyastam aikṣata janaś caṭulāgrapādam gacchantam uccalitacāmaracārum aśvam / nāgaṃ punar mṛdu salīlanimīlitākṣaṃ sarvaḥ priyaḥ khalu bhavaty anurūpaceṣṭaḥ //
和訳

人々は、前脚を軽快に動かし、揺れるたてがみを美しくなびかせながら疲れつつ進む馬を眺め、また一方、ゆるやかに、戯れるかのように目を細めて進む象を見た。すべての者は、身の丈にかなう振る舞いをしてこそ愛されるものである。

注

【Vallabhadeva】

janaḥ（人々）は aśvam（馬）を āyastam（疲れた様子で）aikṣata（見た）。caṭula は「軽やかな」。cāmara はたてがみ。nāgam（象）は mṛdu（ゆるやかに）salīlanimīlitākṣam（戯れるように目を細めて）進む。なぜ双方とも人の目を引くのか——sarvaḥ priyaḥ khalu bhavaty anurūpaceṣṭaḥ：自らに相応しい振る舞いをする者は、すべて愛される。arthāntaranyāsa。

【Mallinātha】

aikṣata は√īkṣ の luṅ、「āṅ jādīnām」により āṭ。āyasta は√yas（努力する）の kta。salīlanimīlitākṣam：「bahuvrīhau sakhyakṣṇoḥ svāṅgāt ṣac」。arthāntaranyāsa（一般命題への帰着）。

V.7
Sanskrit (IAST) trastaḥ samastajanahāskaraḥ kareṇos tāvat kharaḥ prakharam ullalayāñcakāra / yāvac calāsanavilolanitambabimba- visrastavastram avarodhavadhūḥ papāta //
和訳

雌象に怯えた驢馬が、すべての人の笑いを誘いつつ激しく跳ね上がった。するとたちまち、不安定な座から腰が揺れ、衣がずり落ちて、後宮の女が落ちた。

注

【Vallabhadeva】

kareṇoḥ（雌象、Amara「kareṇur ibhyā strī neme」）に trastaḥ（怯えた）kharaḥ（驢馬）が ullalayāñcakāra（跳ね上がった）。それにより avarodhavadhūḥ（後宮の女）が papāta（落ちた）。calāsana（不安定な座）から nitambabimba（腰）が vilola（揺れ動き）、vastra（衣）が visrasta（ずり落ちた）。ullasayāñcakāra は使役形の periphrastic perfect。

【Mallinātha】

kareṇoḥ は apādāna（恐怖の原因）。kharaḥ は驢馬。prakharam は「激しく」。samastajanahāskaraḥ は「すべての人に笑いを生じさせる」。calāsana は動揺した座席。svabhāvokti。

V.8
Sanskrit (IAST) śailopaśalyanipatadrathanemīdhārā- niṣpiṣṭaniṣṭhuraśilātalacūrṇagarbhāḥ / bhūreṇavo nabhasi naddapayodacakrāś cakrīvad aṅgaruhadhūmraruco visasruḥ //
和訳

山の麓に突き進む戦車の車輪の縁に砕かれた硬い岩の粉塵を含んだ土埃は、空に雲の輪のような塊をなし、驢馬の体毛のような暗赤色の光を帯びて、四方へ広がった。

注

【Vallabhadeva】

bhūreṇavaḥ（大地の塵）が nabhasi（空に）visasruḥ（広がった）。naddha（結びつけた）payodacakra（雲の輪）を持つ。cakrīvat（驢馬、Amara「cakrīvantastu bāleyā rāsabhā gardabhāḥ kharāḥ」）のaṅgaruha（体毛）のごときdhūmraruc（暗赤色の輝き）。

【Mallinātha】

śailopaśalya は「山の裾」（upacāra による拡張、本来は grāmānta）。nemi は車輪の縁（Amara「cakraṃ rathāṅgaṃ tasyānte nemiḥ strī」）。cakrīvat は驢馬の別名（Amara）。dhūmra は暗赤色（Amara「dhūmradhūmalau kṛṣṇalohite」）。

V.9
Sanskrit (IAST) udyatkṛśānuśakaleṣu khurābhighātād bhūmīsamāyataśilāphalakāciteṣu / paryantavartmasu vicakramire mahāśvāḥ śailasya dardurapuṭāniva vādayantaḥ //
和訳

蹄の打撃から火花が飛び散り、大地と同じ高さに広がる石板で敷き詰められた山の麓の道を、大馬たちはダルドゥラ太鼓を打ち鳴らすかのように歩んだ。

注

【Vallabhadeva】

mahāśvāḥ（大馬）が śailasya paryantavartmasu（山の麓の道で）vicakramire（歩んだ）。khura（蹄）の打撃から udyat kṛśānuśakala（火花＝sphuliṅga）が散る道は、bhūmyā samāni（地面と同じ高さの）āyata（広がった）śilāphalaka（石板）で ācita（敷き詰められた）。dardurapuṭa は太鼓の一種の面。utprekṣā。

【Mallinātha】

khura は蹄（Amara「śaphaṃ klībe khuraḥ pumān」）。kṛśānuśakala は火花。śilāphalaka は平らな岩板。dardura は打楽器の一種（Amara「darduras tauyade meke vādyabhāṇḍādribhedayoḥ」）、puṭa はその打面。vicakramire は√kram のātmanepada（Amara「veḥ pādaviharaṇe」）。utprekṣā。

V.10
Sanskrit (IAST) tejonirodhsamatāvahitena yaṣṭrā samyak kaśātrayavicāravatā niyuktaḥ / āraṭṭajaś caṭulaniṣṭhurapātam uccaiś citraṃ cakāra padam ardhapulāyitena //
和訳

気性の制御と均衡に心を砕き、三種の鞭の使い分けに精通した騎手に駆られて、アーラッタ産の馬は高々と、激しく鋭い着地をなしながら、半旋回歩法で見事な足運びを見せた。

注

【Vallabhadeva】

āraṭṭaja（アーラッタ産の馬）が citram padam cakāra（見事な足運びを見せた）。tejas は馬の生来の気性（darpa）、その nirodha（抑制）と samatā（均衡）に avahita（専念した）騎手が、kaśātraya（三種の鞭打ち：上・中・下）の vicāra（使い分け）に精通して、馬を niyukta（駆った）。ardhapulāyita は馬の歩法の一種で、半円を描く旋回。āraṭṭa・vāhīka 等は馬の産地。

【Mallinātha】

tejas は馬の気性（sattva-guṇa-vikāra）。Bhoja 王の馬術書を引き、kaśātraya（三段階の鞭＝穏やか・中程度・強い）とその用いるべき十二の場面を詳述。ardhapulāyita は馬の旋回歩法の一種（Hayalīlāvatī「plutāṃ lavaṅgitām āhur yā dhārā pulanābhidhā...」）。āraṭṭaja は産地名（āraṭṭa）に由来。caṭulaniṣṭhurapāta は激しく鋭い足の着き。

V.11
Sanskrit (IAST) nīhārajālamalinaḥ punaruktasāndrāḥ kurvan vadhūjanavilocanapakṣmamālāḥ / kṣuṇṇaḥ kṣaṇaṃ yadubaleir divam ātitāṃsuḥ pāṃśur diśāṃ mukham atutthayad utthito 'dreḥ //
和訳

山から立ちのぼりヤドゥ軍に踏み砕かれた土埃は、霧の網のように汚れ、婦人たちの睫毛の列を二重に濃くしながら、空を覆おうと欲して諸方の顔を覆い隠した。

注

【Vallabhadeva】

pāṃśu（土埃）が adreḥ（山から）utthitaḥ（立ちのぼり）、yadubaleḥ（ヤドゥ軍に）kṣuṇṇaḥ（踏み砕かれ）、diśāṃ mukham（諸方位の顔を）atutthayat（覆った、√tuth 覆う、使役形）。nīhārajāla（霧の網）のように malinaḥ（汚れた）。vadhūjana の vilocana（目）の pakṣmamālāḥ（睫毛の列）を punaruktasāndrāḥ（二重に濃く）kurvan（しつつ）。ātitāṃsuḥ は√tan の san 形（空を覆い広がろうと欲した）。

【Mallinātha】

ātitāṃsuḥ は√tan の desiderative。「tanipatidarirdrāṇām upasamkhyānāt」により iḍ の任意省略、「tanoter vibhāṣā」により長音化。atutthayat は√tuth（覆う、caus.）の luṅ。

V.12
Sanskrit (IAST) ucchidya vidviṣa iva prasabhaṃ mṛgendrān indrānujānucarabhūpatayo 'dhyavātsuḥ / vanyebhamastakanikhātanakhāgramukta- muktāphalaprakarabhāñji guhāgṛhāṇi //
和訳

インドラの弟（クリシュナ）の従者たる王たちは、敵を討つかのように獅子たちを力ずくで追い払い、野生象の頭に突き刺さった爪先から零れ落ちた真珠の粒で飾られた洞窟の住処に入った。

注

【Vallabhadeva】

indrānujānucarabhūpatayaḥ（インドラの弟＝ウペーンドラ＝ハリの従者たる王たち）が mṛgendrān（獅子を）vidviṣaḥ iva（敵のように）prasabham（力ずくで）ucchidya（排除して）、guhāgṛhāṇi（洞窟を住居として）adhyavātsuḥ（住んだ、√vas の luṅ）。洞窟は、野生象の額に nikhāta（突き刺さった）獅子の nakhāgra（爪先）から mukta（放たれた）muktāphala（真珠）の prakara（群）を具える。upamitasamāsa。

【Mallinātha】

adhyavātsuḥ は「upānvadhyāṅ vasaḥ」による二格支配。√vas の luṅ に sic、vṛddhi。獅子が野生象を仕留めた際に額に突き刺さった爪先から真珠が散り、それが洞窟を飾る。敵の城を奪って住むのと同じ構図。

V.13
Sanskrit (IAST) bibhrāṇayā bahalayāvakapaṅkapiṅga- picchāvacūḍam anumādhavadhāma jagmuḥ / cañcvagradaṣṭacaṭulāhipatākayānye svāvāsabhāgam uragāśanaketuyaṣṭyā //
和訳

他の王たちは、嘴の先端で噛みつかれてのたうつ蛇を旗印とし、濃厚な臘脂の泥で黄褐色に染まった孔雀の尾羽を頂きの飾りとして掲げるガルダの旗竿に導かれ、マーダヴァの陣営に続いて自らの宿営地に赴いた。

注

【Vallabhadeva】

anye bhūpatayaḥ（他の王たち）が uragāśanaketuyaṣṭyā（ガルダの旗竿によって）anumādhavadhāma（マーダヴァの陣営に続いて）svāvāsabhāgam（自らの宿営地に）jagmuḥ（赴いた）。yāvaka は臘脂（Amara「lākṣā rākṣā jatu klībe yāvo 'laktako drumāmayaḥ」）。bahala な yāvakapaṅka（臘脂の泥）で piṅga（黄褐色に染まった）piccha（孔雀の尾羽）が avacūḍa（頂きの飾り）。cañcu（嘴）の agra で daṣṭa（噛まれた）caṭula（のたうつ）ahi（蛇）が patākā（旗印）。

【Mallinātha】

avacūḍa は旗竿の先端の飾り（Halāyudha「asyocūḍāvacūḍākhyāv ūrdhvādhomukha-cūḍakau」）。uragāśana はガルダ。遠くからガルダ旗によりマーダヴァの陣営を認め、それを目印にして自らの宿営地に向かった。

V.14
Sanskrit (IAST) chāyām apāsya mahatīm api vartamānām āgāminīṃ jagṛhire janatās tarūṇām / sarvo hi nopagataṃ apy apacīyamānaṃ vardhiṣṇum āśrayam anāgatam abhyupaiti //
和訳

人々の群れは、今ある大きな木陰を捨てて、これからやって来る木陰を求めた。まことに、すべての者は、すでに得たものであっても衰えゆく拠り所を離れ、未だ得ぬものであっても成長する拠り所に向かうものである。

注

【Vallabhadeva】
