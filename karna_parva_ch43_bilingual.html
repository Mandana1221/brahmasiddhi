マハーバーラタ ― カルナ篇 第43章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 43 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ43」（カルナがパーンチャーラ軍へ猛攻を加え、両軍の息子・将軍たちが激しく入り乱れて戦う場面）です。ドリタラーシュトラがサンジャヤに、カルナがパーンチャーラ勢をいかに討ったかを問い、サンジャヤが詳述します。カルナはパーンチャーラの勇士たちを次々と射倒し、その子スシェーナ・サティヤセーナ・ヴリシャセーナらがビーマセーナ、ナクラ、サーティヤキ、ドリシュタデュムナらと一対一の激闘を繰り広げます。矢の雨が降り注ぎ、戦車・旗・弓が次々と切り倒され、視界も利かぬほどの混戦の様子が描かれます。最後にはカルナがチェーディ軍を打ち破ってユディシュティラに迫り、両軍とも自陣の主将（ユディシュティラ／カルナ）の周りに再集結して章が終わります。なお、原典の奥書（コロフォン）には第40章・第42章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章には「ヴァヌフ（vanuḥ）」という「弓（ダヌフ dhanuḥ）」の異例の表記が3箇所（第25・37・39詩節）に一貫して現れるため、OCR誤りではなく原典の表記としてそのまま保持しました。
karṇaparva — tricatvāriṃśo'dhyāyaḥ (43)
第43章
dhṛtarāṣṭra uvāca|
yuktaṃ praviśya pārthānāṃ sainyaṃ kurvañjanakṣayam|
karṇo rājānam abhyetya tan mama ācakṣva sañjaya|| // 8-43-1 //
ドリタラーシュトラは語った。 （1）サンジャヤよ、パーンダヴァ軍のただなかに入り込んで人を討ち、そして王（ユディシュティラ）のそばに近づいたカルナが何をしたのか、語ってくれ。
ke ca pravīrāḥ pārthānāṃ yudhi karṇam avārayan|
kāṃś ca pramathya adhirathir yudhiṣṭhiram apīḍayat|| // 8-43-2 //
（2）パーンダヴァ方のどの勇者が戦場でカルナを阻んだのか。またカルナはだれを打ち砕いてユディシュティラを苦しめたのか。
sañjaya uvāca|
dhṛṣṭadyumnamukhān pārthān dṛṣṭvā karṇo vyavasthitān|
samabhyadhāvat tvaritaḥ pāñcālāñ chatrukarśanaḥ|| // 8-43-3 //
サンジャヤは語った。 （3）ドリシュタデュムナを先頭にしたパーンダヴァ方を見て、敵を苦しめるカルナは、急いでパーンチャーラ族に向かって襲いかかった。
taṃ tūrṇam abhidhāvantaṃ pāñcālā jitakāśinaḥ|
pratyudyayur mahātmānaṃ haṃsāḥ sara iva uṣṇage|| // 8-43-4 //
（4）その勢いよく迫るカルナに対して、勝利に輝くパーンチャーラ族は、まるで暑い季節に湖に向かう白鳥のように向かって行った。
tataḥ śaṅkhasahasrāṇāṃ niḥsvano hṛdayaṅgamaḥ|
prādurāsīd ubhayato bherīśabdaś ca dāruṇaḥ|| // 8-43-5 //
（5）すると両軍から、幾千もの法螺貝の心震わせる音、太鼓の恐ろしい響き、――。
nānābāṇaninādaś ca dvipāśvarathaniḥsvanaḥ|
siṃhanādaś ca vīrāṇām abhavad dāruṇas tadā|| // 8-43-6 //
（6）さまざまな矢の音、象・馬・戦車の響き、勇者たちの恐ろしい獅子吼が上がった。
sādridrumārṇavā bhūmiḥ savātāmbudamambaram|
sārkendugrahanakṣatrā dyauś ca vyaktaṃ vighūrṇitā|| // 8-43-7 //
（7）山・樹木・海を含む大地、風・雲を含む空、太陽・月・星々を含む天――すべてが明らかに震え動いた。
iti bhūtāni taṃ śabdaṃ menire te ca vivyathuḥ|
yāni ca api alpasatvāni prāyas tāni mṛtāni vai|| // 8-43-8 //
（8）すべての生類はその音を聞き、震えおののいた。弱い生き物はほとんど死んでしまった。
atha karṇo bhṛśaṃ kruddhaḥ śīghram astram udīrayan|
jaghāna pāṇḍavīṃ senām āsurīṃ maghavān iva|| // 8-43-9 //
（9）激しく怒ったカルナは、素早く武器を放ち、インドラ神がアスラ軍を討つように、パーンダヴァ軍を討った。
sa pāṇḍavabalaṃ karṇaḥ praviśya visṛjañ charān|
prabhadrakāṇāṃ pravarān ahanat saptasaptatim|| // 8-43-10 //
（10）カルナはパーンダヴァ軍のただなかに入って矢を放ち、プラバドラカ族の最も優れた者七十七人を討ち取った。
tataḥ supuṅkhair niśitair atha śraṣṭho ratheṣubhiḥ|
avadhīt pañcaviṃśatyā pāñcālān pañcaviṃśatim|| // 8-43-11 //
（11）そして最上の羽根をもつ鋭い矢で、戦車戦士の中でも最高の彼は、二十五のパーンチャーラ族の二十五人を討ち取った。
suvarṇapuṅkhair nārācaiḥ parakāyavidāraṇaiḥ|
cedikān avadhīd vīraḥ śataśo'tha sahasraśaḥ|| // 8-43-12 //
（12）金の羽根をもち、敵の体を貫く矢によって、勇者は百、千のチェーディ族を討ち取った。
taṃ tathā samare karma kurvāṇam atimānuṣam|
parivavrur mahārāja pāñcālānāṃ rathavrajāḥ|| // 8-43-13 //
（13）大王よ、このように人間離れした働きをするカルナを、パーンチャーラ族の戦車群が取り囲んだ。
tataḥ sandhāya viśikhān pañca bhārata duḥsahān|
pāñcālān avadhīt pañca karṇo vaikartano vṛṣaḥ|| // 8-43-14 //
（14）バーラタよ、そこでカルナは耐えがたい五本の矢をつがえ、五人のパーンチャーラ族を討ち取った。
bhānudevaṃ citrasenaṃ senābinduṃ ca bhārata|
tapanaṃ śūrasenaṃ ca pāñcālān ahanad raṇe|| // 8-43-15 //
（15）バーヌデーヴァ、チトラセーナ、セーナービンドゥ、バーラタよ、タパナ、シューラセーナ――これらパーンチャーラの者たちを戦場で討った。
pāñcāleṣu ca śūreṣu vadhyamāneṣu sāyakaiḥ|
hāhākāro mahān āsīt pāñcālānāṃ mahāhave|| // 8-43-16 //
（16）パーンチャーラの勇者たちが矢で倒されていくとき、戦場では大きな嘆きの声が上がった。
teṣāṃ saṅkrīḍamānānāṃ hāhākāraṃ prakurvatām|
punareva ca tān karṇo jaghānāśu patattribhiḥ|| // 8-43-17 //
（17）戦い合い、嘆声をあげる彼らを、カルナは再び羽根矢で素早く討った。
cakrarakṣau tu karṇasya putrau māriṣa durjayau|
suṣeṇaḥ satyasenaś ca tyaktvā prāṇān ayudhyatām|| // 8-43-18 //
（18）カルナの車輪を守るかの打ち勝ちがたい二人の息子、スシェーナとサティヤセーナは、命を捨てて戦った。
pṛṣṭhagoptā tu karṇasya jyeṣṭhaḥ putro mahārathaḥ|
vṛṣaseno'nvayāt karṇaṃ pṛṣṭhataḥ paripālayan|| // 8-43-19 //
（19）そしてカルナの背後を守る長子、偉大な戦車戦士ヴリシャセーナは、父を守りながら後ろから従った。
dhṛṣṭadyumnaḥ sātyakiś ca draupadeyā vṛkodaraḥ|
janamejayaḥ śikhaṇḍī ca pravīrāś ca prabhadrakāḥ|| // 8-43-20 //
（20）ドリシュタデュムナ、サーティヤキ、ドラウパディーの子ら、ビーマ、ジャナメージャヤ、シカンディン、そしてプラバドラカ族の勇者たち――。
cedikekayapāñcālā yamau mātsyāś ca daṃśitāḥ|
samabhyadhāvan rādheyaṃ jighāṃsantaḥ prahāriṇam|| // 8-43-21 //
（21）チェーディ族、ケーカヤ族、パーンチャーラ族、双子のナクラ・サハデーヴァ、そしてマツヤ族は、武装して、撃破する者カルナを討とうと襲いかかった。
ta enaṃ vividhaiḥ śastraiḥ śaradhārābhir eva ca|
abhyavarṣan vimardantaṃ prāvṛṣi iva ambudā girim|| // 8-43-22 //
（22）雨季の雨雲が山を覆うように、彼らはさまざまな武器や矢の流れでカルナを攻め立てた。
pitaraṃ tu parīpsantaḥ karṇaputrāḥ prahāriṇaḥ|
tvadīyāś ca apare rājan vīrā vīrān avārayan|| // 8-43-23 //
（23）王よ、父を救おうとする撃破する者カルナの子たち、また他のあなたの勇者たちも、彼らに立ち向かった。
suṣeṇo bhīmasenasya cchittvā bhallena kārmukam|
nārācaiḥ saptabhir viddhvā hṛdi bhīmaṃ nanāda ha|| // 8-43-24 //
（24）スシェーナはビーマセーナの弓を広頭矢で切り断ち、七本の矢でビーマの胸を射抜き、叫び声を上げた。
atha anyad vanur ādāya sudṛḍhaṃ bhīmavikramaḥ|
sajyaṃ vṛkodaraḥ kṛtvā suṣeṇasya ācchinad vanuḥ|| // 8-43-25 //
（25）すると恐ろしい武勇のビーマ（ヴリコーダラ）は、別の堅固な弓を取り、弦を張り、スシェーナの弓を切り落とした。
vivyādha cainaṃ daśabhiḥ kruddho nṛtyan iva iṣubhiḥ|
karṇaṃ ca tūrṇaṃ vivyādha trisaptatyā śitaiḥ śaraiḥ|| // 8-43-26 //
（26）怒って踊るかのようにしながら、十本の矢で彼を射抜き、カルナをも七十三本の鋭い矢で素早く射抜いた。
satyasenaṃ ca daśabhiḥ sāśvasūtāyudhadhvajam|
paśyatāṃ suhṛdāṃ madhye karṇaputram apātayat|| // 8-43-27 //
（27）馬・御者・武器・旗と共にあったサティヤセーナを、十本の矢で射、友人たちの目前で、カルナの子を討ち倒した。
kṣurapraṇunnaṃ tat tasya śiraś candranibhānanam|
śubhadarśanam eva āsīt na ālabhraṣṭam iva ambujam|| // 8-43-28 //
（28）広頭矢によって切り落とされた月のように美しい彼の首は、茎から落ちた蓮のように美しく見えた。
hatvā karṇasutaṃ bhīmas tāvakān punar ārdayat|
kṛpahārdikyayoś chittvā cāpau tau api atha ārdayat|| // 8-43-29 //
（29）カルナの子を討ったビーマは、またあなた方の軍を苦しめた。クリパとクリタヴァルマンの弓を切り折って、彼らをも苦しめた。
duḥśāsanaṃ tribhir viddhvā śakuniṃ ṣaḍbhir āyasaiḥ|
ulūkaṃ ca patatriṃ ca cakāra virathau ubhau|| // 8-43-30 //
（30）ドゥフシャーサナを三本の矢で射、シャクニを六本の鉄矢で射、ウルーカとその御者を戦車から降ろして、二人とも戦車のない者にした。
he suṣeṇa hato'sīti bruvan ādatta sāyakam|
tamasya karṇaś ciccheda tribhiś ca enam atāḍayat|| // 8-43-31 //
（31）「おお、スシェーナよ、お前は死んだ！」と叫びながら、矢を取ったビーマに対して、カルナはその矢を切り裂き、さらに三本の矢で彼を打った。
atha anyaṃ parijagrāha suparvāṇaṃ sutejanam|
suṣeṇāya asṛjad bhīmas tam api asya ācchinad vṛṣaḥ|| // 8-43-32 //
（32）ビーマは節のよい、鋭い別の矢をスシェーナに放ったが、カルナはそれをも切り裂いた。
punaḥ karṇas trisaptatyā bhīmasenam atha iṣubhiḥ|
putraṃ parīpsan vivyādha kruddhaḥ śatrujighāṃsayā|| // 8-43-33 //
（33）再びカルナは、息子を守ろうと、敵を殺そうと怒って、七十三本の矢でビーマセーナを射た。
suṣeṇas tu dhanurgṛhya bhārasādhanamuttamam|
nakulaṃ pañcabhir bāṇair bāhvor urasi ca arpayat|| // 8-43-34 //
（34）スシェーナは重い戦いにも耐える最高の弓を取って、ナクラの腕と胸に五本の矢を放った。
nakulas taṃ tu viṃśatyā viddhvā bhārasahair dṛḍhaiḥ|
nanāda balavannādaṃ karṇasya bhayamādadhat|| // 8-43-35 //
（35）ナクラはそれに対して、重く堅固な二十本の矢で射ち、カルナに恐怖を与えるような大声を発した。
taṃ suṣeṇo mahārāja viddhvā daśabhir āśugaiḥ|
ciccheda ca dhanuḥ śīghraṃ kṣurapreṇa mahārathaḥ|| // 8-43-36 //
（36）大王よ、スシェーナは十本の鋭矢でナクラを射、そして偉大な戦車戦士は素早く広頭矢で彼の弓を切り裂いた。
atha anyad vanur ādāya nakulaḥ krodhamūrcchitaḥ|
suṣeṇaṃ navabhir bāṇair vārayāmāsa saṃyuge|| // 8-43-37 //
（37）別の弓を取ると、怒りに狂ったナクラは、九本の矢でスシェーナを戦場で抑え込んだ。
sa tu bāṇair diśo rājan ācchādya paravīrahā||
ājaghne sārathiṃ ca asya suṣeṇaṃ ca tatas tribhiḥ|
ciccheda ca asya sudṛḍhaṃ dhanur bhallais tribhis tridhā|| // 8-43-38 //
（38）王よ、敵の勇者を討つナクラは、矢で諸方向を覆い、スシェーナの御者を討ち、彼を三本の広頭矢で射、その堅い弓を三本に切り裂いた。
atha anyad vanur ādāya suṣeṇaḥ krodhamūrcchitaḥ|
āvidhyan nakulaṃ ṣaṣṭyā sahadevaṃ ca saptabhiḥ|| // 8-43-39 //
（39）別の弓を取って怒りに狂ったスシェーナは、六十本の矢でナクラを射、七本の矢でサハデーヴァを射た。
tad yuddhaṃ sumahad ghoram āsīd devāsuropamam|
nighnatāṃ sāyakais tūrṇam anyonyasya vadhaṃ prati|| // 8-43-40 //
（40）その戦いは大変に凄まじく、神々とアスラの戦いのようであった。双方がたがいに討ち合っていた。
sātyakir vṛṣasenaṃ tu viddhvā saptabhir āyasaiḥ|
'punar vivyādha saptatyā sārathiṃ ca tribhiḥ śitaiḥ|| // 8-43-41 //
（41）サーティヤキはヴリシャセーナを七本の鉄矢で射、さらに七十本で射、御者を三本の鋭い矢で射た。
vṛṣasenas tu śaineyaṃ śareṇānataparvaṇā|
ājaghāna mahārāja śaṅkhadeśe mahāratham|| // 8-43-42 //
（42）ヴリシャセーナは関節のまっすぐな矢でサーティヤキの偉大な戦車戦士のこめかみを打った。
śaineyo vṛṣasenena patriṇā paripīḍitaḥ|
kopaṃ cakre mahārāja kruddho vegaṃ ca dāruṇam|| // 8-43-43 //
（43）大王よ、ヴリシャセーナの羽根矢によって苦しめられたシニの雄牛（サーティヤキ）は、怒りに満ち、恐ろしい勢いで激昂した。
jagrāha iṣuvarān vīraḥ śīghraṃ vai daśa pañca ca|
sātyakir vṛṣasenasya sūtaṃ hatvā tribhiḥ śaraiḥ'|| // 8-43-44 //
（44）サーティヤキは素早く十五本の最上の矢を取り、三本の矢でヴリシャセーナの御者を討った。
dhanuś ciccheda bhallena jaghāna aśvāṃś ca saptabhiḥ|
dhvajam ekeṣuṇā unmathya tribhiś taṃ hṛdi atāḍayat|| // 8-43-45 //
（45）広頭矢で弓を切り、七本の矢で馬を討ち、一本の矢で旗を倒し、三本の矢で胸を強く打った。
atha avasannaḥ svarathe muhūrtāt punar utthitaḥ|
sa raṇe yuyudhānena visūtāśvarathadhvajaḥ|
kṛto jighāṃsuḥ śaineyaṃ khaṅgacarmadhṛg abhyayāt|| // 8-43-46 //
（46）しかし一瞬気を失った彼は立ち直り、戦場で馬・御者・旗を失ったまま、サーティヤキを殺そうと、剣と盾を取って進んだ。
tasya ca āpatataḥ śīghraṃ vṛṣasenasya sātyakiḥ|
vārāhakarṇair daśabhir avidhyad asicarmaṇī|| // 8-43-47 //
（47）迫り来るヴリシャセーナに対し、サーティヤキはイノシシの耳形矢十本で、剣と盾を射抜いた。
duḥśāsanas tu taṃ dṛṣṭvā virathaṃ vyāyudhaṃ kṛtam|
āropya svarathaṃ tūrṇam apovāha rathāntaram|| // 8-43-48 //
（48）ドゥフシャーサナは、戦車を失い、武器も失ったヴリシャセーナを見て、急いで彼を自分の戦車に乗せ、別の戦車のところへ運んだ。
atha anyaṃ rathamāsthāya vṛṣaseno mahārathaḥ|
draupadeyāṃs trisaptatyā yuyudhānaṃ ca pañcabhiḥ|| // 8-43-49 //
（49）別の戦車に乗って、偉大な戦車戦士ヴリシャセーナは、ドラウパディーの子らを七十三本の矢で、サーティヤキを五本で射、――。
bhīmasenaṃ catuḥṣaṣṭyā sahadevaṃ ca pañcabhiḥ|
nakulaṃ triṃśatā bāṇaiḥ śatānīkaṃ ca saptabhiḥ|| // 8-43-50 //
（50）ビーマセーナを六十四本、サハデーヴァを五本、ナクラを三十本、シャターニーカを七本、――。
śikhaṇḍinaṃ ca daśabhir dharmarājaṃ śatena ca|
etāṃś ca anyāṃś ca rājendra pravīrāñ jayagṛddhinaḥ|| // 8-43-51 //
（51）シカンディンを十本、ダルマ王を百本の矢で射、――これら勝利を求める勇者たちを苦しめた。
abhyardayan maheṣvāsaḥ karṇaputro viśāmpate|
karṇasya yudhi durdharṣas tataḥ pṛṣṭham apālayat|| // 8-43-52 //
（52）勝利に飢えた大弓使いカルナの子ヴリシャセーナは、打ち勝ちがたいカルナの背後を戦場で守っていた。
yuyudhānaṃ ca rādheyo navair navabhir āyasaiḥ|
visūtāśvarathaṃ kṛtvā lalāṭe tribhir ārpayat|| // 8-43-53 //
（53）カルナはサーティヤキを九本と九本の鉄矢で射、馬・戦車・御者のない者にし、額を三本の矢で打った。
sa tu anyaṃ rathamāsthāya vidhivat kalpitaṃ punaḥ|
yuyudhe pāṇḍubhiḥ sārdhaṃ karṇasya vyadhamad balam|| // 8-43-54 //
（54）彼は別の戦車に乗り直し、パーンダヴァ軍と戦い、カルナの軍を打ち砕いた。
dhṛṣṭadyumnas tataḥ karṇam avidhyad daśabhiḥ śaraiḥ|
draupadeyās trisaptatyā yuyudhānas tu saptabhiḥ|| // 8-43-55 //
（55）ドリシュタデュムナはカルナを十本の矢で射、ドラウパディーの子らは七十三本、サーティヤキは七本――。
bhīmasenaś catuḥṣaṣṭyā sahadevaś ca saptibhiḥ|
nakulas triṃśatā bāṇaiḥ śatānīkas tu saptabhiḥ|| // 8-43-56 //
（56）ビーマセーナは六十四、サハデーヴァは七、ナクラは三十、シャターニーカは七――。
śikhaṇḍī daśabhir vīro dharmarājaḥ śatena tu|
ete ca anye ca rājendra pravīrā jayagṛddhinaḥ|
abhyardayan maheṣvāsaṃ sūtaputraṃ mahāmṛdhe|| // 8-43-57 //
（57）シカンディンは十、ダルマ王は百の矢で――、これらの勇者、勝利を望む者たちは、大戦場でカルナ（スータの子）を射て苦しめた。
tān sūtaputro viśikhair daśabhir daśabhiḥ śaraiḥ|
rathena anucaran vīraḥ pratyavidhyad arindamaḥ| // 8-43-58 //
（58）それに対し、敵を制するカルナは、それぞれに十本ずつの矢を放ち、戦車で追いかけながら反撃した。
'sātyakiṃ bhīmasenaṃ ca dhṛṣṭadyumnaṃ śikhaṇḍinam|
draupadeyāṃś ca saṃrabdhān yatamānān mahārathān|| // 8-43-59 //
（59）サーティヤキ、ビーマセーナ、ドリシュタデュムナ、シカンディン、ドラウパディーの子ら――激昂した偉大な戦車戦士たちを――。
paśyatāṃ sarvasainyānām atha enān sūtanandanaḥ|
virathān rathinaḥ śreṣṭhān nimeṣārdhāt cakāra ha|| // 8-43-60 //
（60）すべての軍勢が見つめるなか、御者の子カルナは、戦車を失った者にしてしまった。わずかな間に、弓の名手たちを無力にした。
amoghatvāt ca bāṇānāṃ bhūtasaṅghā visipmayuḥ'|| // 8-43-61 //
（61）その矢は外れることがなく、生き物たちは皆驚嘆した。
tatra astravīryaṃ karṇasya lāghavaṃ ca mahātmanaḥ|
apaśyāma mahābhāga tat adbhutam iva abhavat|| // 8-43-62 //
（62）カルナの武器の威力と、高潔な彼の素早さを、我らは見た。あたかも奇蹟のようであった。
na hy ādadānaṃ dadṛśuḥ sandadhānaṃ ca sāyakān|
vimuñcantaṃ ca saṃrambhād apaśyan naiva taṃ janāḥ|| // 8-43-63 //
（63）矢を取り、つがえ、激しく放つところを、人々は見ることさえできなかった。
pratīcyāṃ diśi taṃ dṛṣṭvā prācyāṃ paśyāma lāghavāt|
na ca paśyāma rājendra kva nu karṇo vyatiṣṭhata|| // 8-43-64 //
（64）西の方向に彼を見たかと思うと、東の方向に見えた。その素早さゆえ、王よ、カルナがどこにいるのかさえ、分からなかった。
iṣūn eva asya paśyāmo vinikīrṇān samantataḥ|
chādayānān diśo rājañ śalabhānām iva vrajān|| // 8-43-65 //
（65）王よ、あたり一面に矢がまき散らされ、イナゴの群れのように、諸方向を覆うのを見るばかりであった。
tasya tair iṣubhis trīkṣṇaiḥ sampatadbhiḥ sahasraśaḥ|
marīcibhir iva uṣṇāṃśoḥ śaraiḥ sannataparvabhiḥ|| // 8-43-66 //
（66）その鋭い矢が幾千も降りそそぎ、太陽の光線のように、節をそろえた矢が降った。
vyāptāḥ sarvā diśo rājan yodhāś ca dadṛśus tadā|
śaraiḥ saṃvṛtam ākāśaṃ tatra abhrair iva ca abhavat|| // 8-43-67 //
（67）王よ、すべての方向が満たされ、戦士たちは、空が雲のように矢で覆われるのを見た。
dyaur viyad bhūr diśaś ca eva pracchannā niśitaiḥ śaraiḥ|
aruṇābhrāvṛtākāraṃ tasmin deśe babhau viyat|| // 8-43-68 //
（68）天・空・地・諸方向は鋭い矢に覆われ、まるで赤い雲に覆われたかのように、その一帯の空が見えた。
tataḥ punar ameyātmā karṇo rājā mahārathaḥ|
nyahanat samare yodhān yodhavṛttam anuṣṭhitaḥ|| // 8-43-69 //
（69）そしてまた、無量の魂をもつ偉大な戦車戦士カルナ王は、戦士にふさわしい振舞いで、戦場で敵を討ち続けた。
nṛtyan iva hi rādheyaś ca apahasto raṇājire|
yair viddhaḥ pratyaviddhyat tān ekaikaṃ triguṇaiḥ śaraiḥ|| // 8-43-70 //
（70）戦場で弓を手に、踊るかのようなカルナは、自分を射てきた者たち一人一人に対して、三倍の矢で撃ち返した。
śataiś ca daśabhiś ca etān punar viddhvā nanāda ca|
sāśvasūtadhvajacchatrās tatas te vivaraṃ daduḥ|| // 8-43-71 //
（71）さらに百本、十本の矢で射、叫び声をあげた。馬・御者・旗・傘を失った者たちは逃げ場を求めた。
'te hanyamānāḥ karṇena palāyanta diśo daśa|
nādayanto diśaḥ sarvāḥ karmatrastā vicetasaḥ'|| // 8-43-72 //
（72）カルナに討たれて彼らは十方に逃げた。すべての方向に叫びながら、恐怖に我を忘れていた。
tān pramathya maheṣvāsān rādheyaḥ śaravṛṣṭibhiḥ|
rājānīkam asambādhaṃ prāviśat chatrukarśanaḥ|| // 8-43-73 //
（73）大弓使いたちを自らの矢の雨で打ち砕いたカルナは、敵を苦しめる者として、難なく王の陣営に入り込んだ。
sa rathāṃs triśataṃ hatvā cedīnām anivartinām|
rādheyo niśitair bāṇais tato'bhyāgād yudhiṣṭhiram|| // 8-43-74 //
（74）退かぬチェーディ族の戦車三百を討ち、鋭い矢で、カルナはユディシュティラへと進み寄った。
'tatas te virathāḥ śūrā rathān anyān samāsthitāḥ|
parivavrur mahārāja dharmaputraṃ yudhiṣṭhiram'|| // 8-43-75 //
（75）戦車を失った勇者たちは別の戦車に乗り、大王ダルマ王ユディシュティラを取り囲んだ。
tatas te tu pare rājañ chikhaṇḍī ca sasātyakiḥ|
rādheyāt parirakṣanto rājānaṃ paryavārayan|
muñcanto vividhān bāṇān svarṇapuṅkhāñ śilāśitān|| // 8-43-76 //
（76）シカンディンとサーティヤキは、カルナから王を守ろうと取り囲み、金の羽根をもち鋭くみがかれたさまざまな矢を放った。
tathaiva tāvakāḥ sarve karṇaṃ durvāraṇaṃ raṇe|
yattāḥ śūrā maheṣvāsāḥ paryarakṣanta sarvaśaḥ|| // 8-43-77 //
（77）そしてあなた方の側の大弓使いの勇者たちは皆、打ち勝ちがたいカルナを戦場ですっかり守った。
nānāvāditraghoṣāś ca prādurāsan viśāmpate|
siṃhanādaś ca sañjajñe śūrāṇām abhigarjatām|| // 8-43-78 //
（78）国王よ、さまざまな楽器の音が響き、吠える勇者たちの獅子吼が生じた。
tataḥ punaḥ samājagmur abhītāḥ kurupāṇḍavāḥ|
yudhiṣṭhiramukhāḥ pārthāḥ sūtaputramukhā vayam|| // 8-43-79 //
（79）そしてクル族とパーンダヴァ族は、再び恐れることなく激突した。ユディシュティラを先頭にしたパーンダヴァ方、カルナを先頭にした我ら――こうして戦いは続いた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe tricatvāriṃśo'dhyāyaḥ|| 43 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十三章は終わる。
