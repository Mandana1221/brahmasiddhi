マハーバーラタ ― カルナ篇 第70章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 70 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ70」、全23詩節からなります。カルナがまだ無事であることを聞いてクリシュナがアルジュナに語りかける場面（第1〜23詩節）で本章は終わります。アルジュナがカルナを殺すよう励まされます。
karṇaparva — saptatitamo'dhyāyaḥ (70)
第70章
sañjaya uvāca|
taddharmaśīlasya vaco niśamya rājñaḥ kruddhasyātiratho mahātmā|
uvāca durmarṣamadīnasatvo yudhiṣṭhiraṃ jiṣṇuranantavīryaḥ||
// 8-70-1 //
ダルマを重んじる王の怒りの言葉を聞いて、アティラタ（最高の戦車戦士）にして偉大な者、耐え難い力と不屈の精神のジシュヌ（アルジュナ）、無限の武勇の者が、ユディシュティラに語った。
droṇaṃ hataṃ pārtha karṇo viditvā bhinnāṃ nāvavimāvatyagādhe kurūṇām|
sammuhyamānāndhārtarāṣṭrānviditvā nirutsāhāṃś ca vijaye pareṣām||
// 8-70-2 //
「パールタよ、ドローナが殺されたことを知ったカルナは、クル族の船が底知れぬ大海で壊れたことを悟り、ドリタラーシュトラの子らが動揺し、敵に対する勝利への意欲を失っていることを知り、
sodaryavattvarito'mitaujā uttārayiṣyandhṛtarāṣṭrasya putrān|
raṇe rathenādhirathirmahātmā tato hi māṃ tvaritaḥ so'bhyadhāvat||
// 8-70-3 //
兄弟のように急いで、無限の力のアーディラティ（カルナ）は、偉大なる者として、ドリタラーシュトラの息子たちを戦場から救い出そうと、戦車で私に向かって急いで突進してきた。
saṃśaptakairyudhyamānasya me'dya senāgrayāyī kurusainyasya rājan|
āśīviṣābhānvikirañśaraughā-- ndrauṇiḥ purastātsahasādhyatiṣṭhat||
// 8-70-4 //
王よ、サンシャプタカ軍と私が戦っている最中に、クル軍の先頭に立つ軍の指導者が、毒蛇のような矢の群れを振りまきながら、ドローナの子が突然私の前に立ちふさがった。
sa me dṛṣṭvā śūratamo dhvajāgraṃ samādiśadrathasaṅghānanekān|
teṣāmahaṃ pañcaśataṃ nihatya āsādayaṃ droṇaputraṃ nadantam||
// 8-70-5 //
あの最も勇敢な者は私の旗の先端を見て、多くの戦車軍団に指示を出した。私はその五百台を殺し、吼えるドローナの子に到達した。
sa droṇaputraḥ sadṛśaṃ mahātmā māmapyarautsīttadanīkamadhye|
kirañśaraughānbahurūpānvicitrā-- nsvātīgataḥ śukra iva ativarṣan||
// 8-70-6 //
偉大なドローナの子は、あの軍勢の中で私にも攻撃をかけてきた。多種多様な矢の群れを浴びせながら、スヴァーティー星座に入った金星（シュクラ）のように大雨を降らせて。
sa me rānsarvataḥ kaṅkapatrā-- navāsṛjadvai pṛthivīprakāśān|
nivārya tūrṇaṃ paramājimadhye tato'pi māṃ bāṇagaṇaiḥ samārpayat||
// 8-70-7 //
彼は四方から鷲の羽の大地を照らすような矢を放ち、すぐに戦場の真ん中で阻み、さらに矢の群れで私を射た。
ākarṣaṇaṃ vāpi vikṛṣya muktaṃ na dṛśyate tasya mahārathasya|
na sandadhānaḥ kuta ādadāno na vyākṣipanna vikarṣanvimuñcan||
// 8-70-8 //
彼の引き絞りも引き絞って放つのも見えなかった、あの大戦車戦士の。弦に番えるところも、矢を取るところも、弓を引くところも引き絞るところも放つところも見えなかった。
savyena vā yadi vā dakṣiṇena na jñāyate katareṇāsyatīti|
ācāryavatsamare paryavarta-- nmahaccitraṃ darśayansarvataḥ sma||
// 8-70-9 //
左手で射るのか右手で射るのか、どちらの手で射っているのかわからなかった。師（ドローナ）のように戦場を駆け巡り、四方に大いなる驚くべき技を見せていた。
dṛṣṭvīviṣaṃ cāsuharaṃ pareṣāṃ sarvā diśaḥ pūrayānaṃ śaraudhaiḥ|
alātacakrapratimaṃ mahātmanaḥ sadā nataṃ kārmukaṃ brahmabandhoḥ||
// 8-70-10 //
毒蛇のように敵の命を奪い、四方を矢の群れで満たし、火の輪のように見える偉大なブラーフマナの子（アシュヴァッターマン）の常に曲がった弓を見て、
tato'parānbāṇagaṇānanekā-- nākarṇapūrṇāyatavipramuktān|
sasarja śīghrāstrabalena vīra-- stoyaṃ yathā prāvṛṣi kālameghaḥ||
// 8-70-11 //
勇者は武器の術の力で、耳まで引き絞り十分に伸ばして放たれた別の矢の群れを続けざまに放った。雨季の時の黒雲が水を降らすように。
āvidhyanmāṃ pañcabhidroṇaputraḥ śitaiḥ śaraiḥ pañcabhir vāsudevam|
abhyaghnaṃ bāṇaistamahaṃ sudhārai-- rnimeṣamātreṇa suvarṇapuṅkhaiḥ||
// 8-70-12 //
ドローナの子は五本の鋭い矢で私を射、五本でヴァースデーヴァを射た。私は一瞬のうちに黄金の羽の鋭い矢で彼を射返した。
sa nirviddho viratho droṇaputro rathānīkaṃ cādhiratherviveśa|
mayābhibhūtānsvarathaprabarhā-- nastraṃ ca paśyanrudhirapradigdham||
// 8-70-13 //
深く射られ、戦車を失ったドローナの子は、アーディラティ（カルナ）の戦車陣の中に入った。自分の戦車の最高の者たちが私に打ち負かされ、血にまみれた武器を見ながら。
tato'bhibhūtaṃ yudhi vīkṣya sainyaṃ vidhvastayodhaṃ drutanāgayūtham|
pañcāśatā rathamukhyaiḥ sametaḥ karṇastvarannabhyapatatpramāthī||
// 8-70-14 //
戦いで軍が打ち負かされ、戦士たちが散り散りになり、象の群れが逃走するのを見て、カルナは五十台の主要な戦車と共に、急いで攻めかかってきた、粉砕者として。
tānsūdayitvā'hamapāsya karṇaṃ draṣṭuṃ bhavantaṃ tvarayopayātaḥ|
sarve pāñcālā hyudvijante sma karṇaṃ dṛṣṭvā gāvaḥ kesariṇaṃ yathaiva||
// 8-70-15 //
私はそれらを殺し、カルナを退けてから、おまえに会うために急いでここに来た。パーンチャーラ族は皆カルナを見ると怯えていた。牛がたてがみを持つ獅子を見るように。
mṛtyorāsyaṃ vyāttamivābhipadya prabhadrakāḥ karṇamāsādya sarve|
yāsyāmi tāṃstārayiṣyanbalaughā-- ddiṣṭyā bhavānsvastimānpārtha dṛṣṭaḥ||
// 8-70-16 //
死の口を開けた口に入り込むように、プラバドラカ族の全てがカルナに出くわした。私は彼らを軍勢の洪水から救いに行くつもりだ。パールタよ、おまえが無事で見つかって幸いだ。
haniṣye'haṃ bhārata sūtaputra-- masminsaṅgrāme yadi dṛśyate'dya|
āyāhi paśyādya yuyutsamānau māṃ sūtaputraṃ ca dhṛtau raṇāya||
// 8-70-17 //
バーラタよ、この戦場でスータの子がもし今日姿を見せるなら、私は彼を殺す。来たれ、今日戦いを望む私とスータの子が戦う姿を見よ。二人とも戦いの覚悟ができている。
mahājhaṣasyeva mukhaṃ prapannāḥ prabhadrakāḥ karṇamukhaṃ prapannāḥ|
ṣaṭsāhasrā bhārata rājaputrāḥ svargāya lokāya raṇe nimagnāḥ||
// 8-70-18 //
バーラタよ、大魚の口に飲み込まれるように、カルナの口に飲み込まれたプラバドラカ族の六千の王子たちは、天界に向けて戦場に沈んだ。
tānadya yāsyāmi raṇādvimoktuṃ sarvātmanā sūtaputraṃ ca hantum||
// 8-70-19 //
今日、彼らを戦場から救い出し、全力でスータの子を殺しに行くのだ。
atha pravīreṇa mahānubhāva dviṣatsainyaṃ nirdahanvistareṇa|
sametyāhaṃ sūtaputreṇa saṅkhye vajrīva vṛtreṇa narendramukhya||
// 8-70-20 //
偉大なる者よ、大いなる勇者が敵軍を広大に焼き尽くす中、私は戦場でスータの子と出会うだろう。インドラがヴリトラと出会うように、王たちの主よ。
evaṃ gate kiñca mayā'dya śakyaṃ kāryaṃ kartuṃ nigrahe sūtajasya|
tathaiva rājñaś ca suyodhanasya ye cāpi māṃ yoddhukāmāḥ sametāḥ||
// 8-70-21 //
このような状況で、スータの子の打倒のため、またスヨーダナ（ドゥルヨーダナ）の王の打倒のため、そして私と戦おうと集まった者たちの打倒のため、今日私にできることがある。
karṇaṃ na cedadya nihanmi rāja-- nsabāndhavaṃ yudhyamānaṃ prasahya|
pratiśrutyā'kurvatāṃ yā gatirvai kaṣṭāṃ yāyāṃ tāmahaṃ rājasiṃha||
// 8-70-22 //
王よ、もし今日カルナを一族もろとも力ずくで戦って殺さなければ、誓いを果たさぬ者が辿る苦しい道を、私は辿ることになるだろう、王の中の獅子よ。
āmantraye tvāṃ brūhi raṇe jayaṃ me purā bhīmaṃ dhārtarāṣṭrā grasanti|
sautiṃ haniṣyāmi narendrasiṃha sainyaṃ tathā śatrugaṇāṃś ca sarvān||
// 8-70-23 //
おまえに別れを告げる。戦場で私の勝利を祈ってくれ。ドリタラーシュトラの子らがビーマを飲み込む前に。スータの子を殺し、王の中の獅子よ、敵軍とその全ての軍勢をも殺そう。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe saptatitamo'dhyāyaḥ|| 70 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第70章終わり。
