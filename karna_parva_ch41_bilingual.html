マハーバーラタ ― カルナ篇 第41章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 41 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ41」（カルナが布陣を完了し、両軍が激突する場面）です。カルナはドリシュタデュムナに守られたパーンダヴァ軍に対し、壮大な陣形を敷いて進軍します。両軍の戦士たちは互角の戦闘を待ち望み、太鼓や法螺貝の音が響き渡ります。その後、ドリタラーシュトラがサンジャヤに、カルナがいかにパーンダヴァ軍に対して布陣したかを問い、サンジャヤは両軍の陣形（ヴィユーハ）を詳細に語ります。クリシュナ側の陣にはクリパ、シャルヤ、アシュヴァッターマン、デュルヨーダナ、ドゥシャーサナらが、パーンダヴァ側にはアルジュナ、ビーマセーナ、ユディシュティラ、サティヤキ、ドラウパディーの子らとドリシュタデュムナ・シカンディンが配置されます。ユディシュティラはアルジュナに対し、各々が討つべき敵将を具体的に指示し、アルジュナはこれに同意して布陣に従います。なお、第18詩節の話者標示「ドリタラーシュトラ言う」は原典で「dhṛtarāṣṭraṃ uvāca」（通常の主格でなく対格的な語形）という特異な形で記されており、原典のママ保持しています。
karṇaparva — ekacatvāriṃśo'dhyāyaḥ (41)
第41章
sañjaya uvāca|
tataḥ parānīkabhidaṃ vyūham apratimaṃ mahat|
samīkṣya karṇaḥ pārthānāṃ dhṛṣṭadyumnābhirakṣitam|| // 8-41-1 //
サンジャヤは語った。 （1）敵軍を突き破るほどの、比類なき巨大な陣形を見て、カルナは、パーンダヴァ軍のドリシュタデュムナに守られた陣形をよく観察した。
prayayau rathaghoṣeṇa siṃhanādaraveṇa ca|
vāditrāṇāṃ ca ninadaiḥ kampayanniva medinīm|| // 8-41-2 //
（2）そしてカルナは、戦車の轟音と獅子吼の叫び、そして楽器の鳴り響く音で大地を震わせながら進み出た。
vepamāna iva krodhād yudvaśauṇḍaḥ parantapaḥ|
prativyūhya mahātejā yathāvad bharatarṣabha|| // 8-41-3 //
（3）戦いに長けた、敵を焼く者カルナは、怒りのために身を震わせるかのようであった。偉大な光輝をもつ彼は、バーラタの雄牛よ、正しく対陣して陣形を整えた。
vyadhamat pāṇḍavīṃ senām āsurīṃ maghavān iva|
yudhiṣṭhiraṃ ca abhyahanad apasavyaṃ cakāra ha|| // 8-41-4 //
（4）そしてインドラ神がアスラ軍を打ち破るように、パーンダヴァ軍を打ち砕き、ユディシュティラに攻撃を加え、彼を右に回り込むように動かした。
karṇasya rathaghoṣeṇa maurvīniṣpeṣaṇena ca|
susaṅgrāheṇa raśmīnāṃ samakampanta sṛñjayāḥ|| // 8-41-5 //
（5）カルナの戦車の轟音と弓弦の打ち鳴らす音、手綱のしっかりとした引き締めによって、スリンジャヤ族の兵士たちは震え上がった。
tāni sarvāṇi sainyāni karṇa dṛṣṭvā viśāmpate|
babhūvuḥ samprahṛṣṭāni tāvakāni yuyutsayā|| // 8-41-6 //
（6）国王よ、カルナを見て、あなた方の軍勢はみな戦意に燃え、大いに喜んだ。
aśrūyanta tato vācas tāvakānāṃ viśāmpate|
karṇārjunamahāyuddham etad adya bhaviṣyati|| // 8-41-7 //
（7）国王よ、そしてあなた方の軍のあいだからは、このような声が聞こえてきた――「今日こそ、カルナとアルジュナの大決戦が行われるだろう。
adya duryodhano rājā hatāmitro bhaviṣyati|
adya karṇaṃ raṇe dṛṣṭvā phalguno vidraviṣyati|| // 8-41-8 //
（8）今日、ドゥルヨーダナ王は敵を討ち果たすだろう。今日、戦場でカルナを見れば、アルジュナは逃げ去るだろう。
adya tāvad vayaṃ yuddhe karṇasya eva anugāminaḥ|
karṇabāṇamayaṃ bhīmaṃ yuddhaṃ drakṣyāma saṃyuge|| // 8-41-9 //
（9）今日こそ、我らは戦場でカルナに従い、カルナの矢による恐ろしい戦いを目撃するであろう。
cirakālepsitam idam adya idānīṃ bhaviṣyati|
adya drakṣyāma saṅgrāmaṃ ghoraṃ devāsuropamam|| // 8-41-10 //
（10）長きにわたって望んでいたことが、今、実現しようとしている。今日、神々とアスラの戦いにも似た、恐るべき戦いを我らは見るだろう。
adya idānīṃ mahad yuddhaṃ bhaviṣyati bhayānakam|
adya idānīṃ jayo nityam ekasya ekasya vā raṇe|| // 8-41-11 //
（11）今、恐ろしく偉大な戦いが起こるだろう。今日、どちらか一方に勝利が決まるだろう。
arjunaṃ kila rādheyo vadhiṣyati mahāraṇe|
athavā kaṃ naraṃ loke na spṛśanti manorathāḥ|| // 8-41-12 //
（12）カルナは大戦でアルジュナを必ず討ち取るだろう。いや――どんな人間にも、望みというものが叶わぬことがあろうか」。
iti uktvā vividhā vācaḥ kuravaḥ kurunandana|
ājaghnuḥ paṭahāṃś caiva tūryāṃś caiva sahasraśaḥ|| // 8-41-13 //
（13）クル族の喜びよ、このようにさまざまな言葉を発しながら、クル族の人々は太鼓や諸楽器を何千と打ち鳴らした。
bherīnādāṃś ca vividhān siṃhanādāṃś ca puṣkalān|
murajānāṃ mahāśabdān ānakānāṃ mahāravān|| // 8-41-14 //
（14）種々の大鼓の響き、豊かな獅子吼、ムラジャ太鼓の大音響、アーナカ太鼓の大きな轟き――。
nṛtyamānāś ca bahuśas tarjamānāś ca māriṣa|
anyonyam abhyayur yuddhe yuddharaṅgagatā narāḥ|| // 8-41-15 //
（15）舞い踊り、敵を威嚇し合いながら、戦場に向かう戦士たちは、たがいに打ち合うために進んでいった。
teṣāṃ padātā nāgānāṃ pādarakṣāḥ samantataḥ|
paṭṭasāsidharāḥ śūrāś cāpabāṇamusuṇṭhinaḥ|| // 8-41-16 //
（16）彼らの足もとには、象の足を守る歩兵たち――剣や槍を持つ勇者、弓矢を持つ兵、投棒を持つ者――が周りを固めていた。
bhiṇḍipāladharāś caiva śūralahastāḥ sucakriṇaḥ|
teṣāṃ samāgamo ghoro devāsuraraṇopamaḥ|| // 8-41-17 //
（17）短槍を持ち、長き腕をもつ勇者、円盤を使いこなす者たちもいた。彼らの激突は、神々とアスラの戦いにも似た恐るべきものであった。
dhṛtarāṣṭraṃ uvāca|
kathaṃ sañjaya rādheyaḥ pratyavyūhata pāṇḍavān|
dhṛṣṭadyumnamukhān saṅkhye bhīmasenābhirakṣitān|
sarvān eva maheṣvāsān ajayyān amarair api|| // 8-41-18 //
ドリタラーシュトラは語った。 （18）サンジャヤよ、カルナはいかにしてパーンダヴァ軍と対陣したのか。ドリシュタデュムナを先頭とし、ビーマセーナに守られ、神々にさえ打ち勝てぬ大弓使いたちすべてを従えた敵軍に対して、どのように備えたのか。
ke ca prapakṣau pakṣau vā mama sainyasya sañjaya|
pravibhajya yathānyāyam avatasthuḥ sudaṃśitāḥ|| // 8-41-19 //
（19）サンジャヤよ、我が軍の両翼、そして側翼にはだれがいたのか。彼らはよき鎧をつけ、どのように配置されたのか。
kathaṃ pāṇḍusutāś ca api pratyavyūhanta māmakān|
kathaṃ ca etan mahad yuddhaṃ prāvartata sudāruṇam|| // 8-41-20 //
（20）パーンダヴァたちはいかにして我が軍と向かい合ったのか。そしてこの大いなる恐ろしい戦いはどのように始まったのか。
kva ca bībhatsur abhavad yat karṇo'yād yudhiṣṭhiram|
ko hy arjunasya sānnidhye śakto jetuṃ yudhiṣṭhiram|| // 8-41-21 //
（21）アルジュナはどこにいて、カルナはどのようにしてユディシュティラに向かったのか。アルジュナがそばにいるのに、だれがユディシュティラを打ち負かすことができるというのか。
sarvabhūtāni yo hy ekaḥ khāṇḍave jitabān purā|
kas tam anyas tu rādheyāt pratiyudhyej jijīviṣuḥ|| // 8-41-22 //
（22）かつてカーンダヴァの森では、アルジュナただ一人で、すべての生類にさえ勝ったのである。カルナ以外のだれが、命を賭してアルジュナに対抗できるだろうか。
sañjaya uvāca|
śṛṇu vyūhasya racanām arjunaś ca yathā gataḥ|
parivārya nṛpān sarvān saṅgrāmaś ca abhavad yathā|| // 8-41-23 //
サンジャヤは語った。 （23）陣形の構成と、アルジュナがどのようにして進んだか、すべての王たちを取り囲んで、戦いがどのように始まったかをお聞きください。
kṛpaḥ śāradvato rājan māgadhāś ca tarasvinaḥ|
sātvataḥ kṛtavarmā ca dakṣiṇaṃ pakṣamāśritāḥ|| // 8-41-24 //
（24）王よ、シャラドヴァットの子クリパ、すばやきマガダ族、サートヴァタ族のクリタヴァルマン――彼らは右翼を守った。
teṣāṃ prapakṣe śakunir ulūkaś ca mahārathaḥ|
sādibhir vimalaprāsais tadānīm abhyarakṣatām|| // 8-41-25 //
（25）彼らの側翼では、シャクニと偉大な戦車戦士ウルーカが、澄んだ槍をもつ騎兵たちとともに、そのときしっかりと守護していた。
gāndhāraiś ca api asambhrāntaiḥ pārvatīyaiś ca durjayaiḥ|
śalabhānām iva vrātaiḥ piśācair iva durdṛśaiḥ|| // 8-41-26 //
（26）ひるむことなきガンダーラ族、征服しがたき山岳民族――まるでイナゴの群れ、見るも恐ろしきピシャーチャ鬼神のごとき彼らと共に――。
caturviṃśat sahasrāṇi rathānām anivartinām|
saṃśaptakā yudvaśauṇḍā vāmapārśvam apālayan|| // 8-41-27 //
（27）二万四千の退却せぬ戦車たち、戦いに長けたサンシャプタカ族の者たちが左翼を守った。
samanvitās tava sutaiḥ kṛṣṇārjunajighāṃsavaḥ|
teṣāṃ prapakṣāḥ kāmbhojāḥ śakāś ca yavanaiḥ saha|| // 8-41-28 //
（28）彼らはあなたの子らと共に、クリシュナとアルジュナを殺そうと望んでいた。彼らの側翼には、カーンボージャ族、シャカ族、そしてヤヴァナ族――。
nideśāt sūtaputrasya sarathāśvebhapattayaḥ|
āhvayanto'rjunaṃ tasthuḥ keśavaṃ ca mahābalam|| // 8-41-29 //
（29）カルナの命令に従って、戦車・馬・象・歩兵を率いた彼らは、アルジュナと偉大なるケーシャヴァ（クリシュナ）を呼び寄せるかのように立ち並んでいた。
tataḥ senāmukhe karṇo'py avātiṣṭhata daṃśitaḥ|
citravarmāṅgadaḥ sragvī pālayan vāhinīmukham|| // 8-41-30 //
（30）そして軍の先頭にはカルナ自身が鎧をまとって立った。華麗な鎧と腕輪をまとい、花輪をつけ、軍の先頭を守っていた。
rakṣamāṇaiḥ susaṃrabdhaiḥ putraiḥ śastrabhṛtāṃ varaḥ|
vāhinīṃ pramukhe vīraḥ samprakarṣan aśobhata|| // 8-41-31 //
（31）武器を持つ者のなかで最も優れた勇者カルナは、奮い立つ息子たちに守られて、軍の先頭で軍を率いて輝いていた。
aśokastu mahābāhuḥ sūryavaiśvānaraprabhaḥ|
mahādvipaskandhagataḥ piṅgākṣaḥ priyadarśanaḥ|
duḥśāsano vṛtaḥ sainyaiḥ sthito vyūhasya pṛṣṭhataḥ|| // 8-41-32 //
（32）長い腕のアショーカ、太陽と火のような光輝をもち、大象の肩に乗り、褐色の目をして、見た目も麗しいドゥフシャーサナは、軍勢に囲まれて陣形の後方に立った。
tanmadhye sa mahābāhuḥ svayaṃ duryodhano nṛpaḥ|
citrāśvaiś citrasannāhaiḥ sodaryair abhirakṣitaḥ|| // 8-41-33 //
（33）その中央には、長き腕のドゥルヨーダナ王自身が、華麗な馬と鎧をまとい、実兄弟たちに守られて立っていた。
rakṣyamāṇo mahāvīryaiḥ sahitair madrakekayaiḥ|
aśobhata mahārāja devair iva śatakratuḥ|| // 8-41-34 //
（34）大王よ、偉大な力をもつマドラ族・ケーカヤ族に守られた彼は、神々に守られたインドラのように輝いて見えた。
aśvatthāmā kurūṇāṃ ca ye pravīrā mahārathāḥ|
nityamattāś ca mātaṅgāḥ śūrair mlecchaiḥ samanvitāḥ|
anvayus tadrathānīkaṃ kṣaranta iva toyadāḥ|| // 8-41-35 //
（35）アシュヴァッターマン、クル族の誇る偉大な戦車戦士たち、常に興奮した象たち、勇ましき異民族（ムレーッチャ）たちと共に、まるで雨雲のように、戦車軍を後方から従えていた。
te dhvajair vaijayantībhir jvaladbhiḥ paramāyudhaiḥ|
sādibhiś ca āsthitā rejur drumavanta iva acalāḥ|| // 8-41-36 //
（36）彼らは旗や戦勝旗、燃え立つような最上の武器を掲げ、騎兵と共に、まるで樹木に覆われた山々のように輝いていた。
teṣāṃ padātināgānāṃ pādarakṣāḥ sahasraśaḥ|
paṭṭasāsidharāḥ śūrā babhūvur anivartinaḥ|| // 8-41-37 //
（37）彼らの歩兵・象兵の足を守る兵士は、剣や槍を持ち、決して退かぬ勇者として、幾千も立ち並んでいた。
sādibhiḥ syandanair nāgair adhikaṃ samalaṅkṛtaiḥ|
sa vyūharājo vibabhau devāsuracamūpamaḥ|| // 8-41-38 //
（38）騎兵・戦車・飾り立てた象に囲まれ、その陣形の王は、神々とアスラの軍勢にも似て輝いていた。
bārhaspatyaḥ suvihito nāyakena vipaścitā|
nṛtyati iva mahāvyūhaḥ pareṣāṃ bhayamādadhat|| // 8-41-39 //
（39）賢い指揮官によって、バールハスパティヤの兵法に従ってよく構成されたその陣形は、敵に恐怖を与えながら、まるで踊っているかのように見えた。
tasya pakṣaprapakṣebhyo niṣpatanti yuyutsavaḥ|
hastyaśvarathamātaṅgāḥ prāvṛṣi iva balāhakāḥ|| // 8-41-40 //
（40）その両翼・側翼からは、戦いを望む象兵・騎兵・戦車兵が、雨季の雨雲のようにあふれ出てきた。
tataḥ senāmukhe karṇaṃ dṛṣṭvā rājā yudhiṣṭhiraḥ|
dhanañjayam amitraghnam ekavīram uvāca ha|| // 8-41-41 //
（41）そして軍の先頭にカルナを見て、ユディシュティラ王は、敵を滅ぼす無比の勇者アルジュナに言った。
paśya arjuna mahāvyūhaṃ karṇena vihitaṃ raṇe|
yuktaṃ pakṣaiḥ prapakṣaiś ca parānīkaṃ prakāśate|| // 8-41-42 //
（42）「アルジュナよ見よ、カルナが戦場で整えたこの巨大な陣形を。両翼・側翼を備えた敵軍はこのように輝いている。
tat samīpagataṃ hy etat pratyamitraṃ mahad balam|
yathā na abhibhavati asmāṃs tathā nītir vidhīyatām|| // 8-41-43 //
（43）この大軍勢は、我々の目前に迫りつつある。どうすれば彼らが我らを打ち負かせぬように対応できるか、策を立ててくれ」。
sañjaya uvāca|
evam ukto'rjuno rājñā prāñjalir nṛpam abravīt|| // 8-41-44 //
サンジャヤは語った。 （44）王からこう言われたアルジュナは、両手を合わせて王に答えた。
yathā yathā bhavān āha tat tathā na tad anyathā|
yat tasya vihitaṃ kāryaṃ tat kariṣyāmi suvrata|
pradhānam atha ca eva asya vināśaṃ ca karomi aham|| // 8-41-45 //
（45）「あなたのおっしゃるとおり、それ以外ではありません。誠実なお方よ、あなたから命じられたことを、私は果たします。そして彼らの主要な者と、彼らの滅亡を私が引き起こしましょう。
tasmāt tvaṃ jahi rādheyaṃ bhīmasenaḥ suyodhanam|
vṛṣasenaṃ ca nakulaḥ sahadevo'pi saubalam|| // 8-41-46 //
（46）ですから、あなたはカルナを討ってください。ビーマセーナはドゥルヨーダナを、ナクラはヴリシャセーナを、サハデーヴァはシャクニ（スバラの子）を――。
duḥśāsanaṃ śatānīko hārdikyaṃ śinipuṅgavaḥ|
dhṛṣṭadyumno droṇasutaṃ svayaṃ yotsyāmy ahaṃ kṛpam|| // 8-41-47 //
（47）シャターニーカはドゥフシャーサナを、シニの雄牛（サーティヤキ）はクリタヴァルマンを、ドリシュタデュムナはドローナの子（アシュヴァッターマン）を、私自身はクリパと戦います。
draupadeyā dhārtarāṣṭrāñ śiṣṭān saha śikhaṇḍinā|
te te ca tāṃs tān ahitān asmākaṃ ghnantu māmakāḥ|| // 8-41-48 //
（48）ドラウパディーの子らはシカンディンと共に、残るドリタラーシュトラの子らと戦うでしょう。我が方の者たちはそれぞれ、我らの敵を討ち取りましょう」。
sañjaya uvāca|
iti ukto dharmarājena tathā iti uktvā dhanañjayaḥ|
vyādideśa svasainyāni svayaṃ ca āgāc camūmukham|| // 8-41-49 //
サンジャヤは語った。 （49）ダルマ王（ユディシュティラ）にこう言われて、アルジュナは「承知しました」と答え、自軍に指示を出し、自身も軍の先頭へと赴いた。
dhanañjayo mahārāja dakṣiṇaṃ pakṣam āsthitaḥ|
bhīmaseno mahābāhur vāmaṃ pakṣam upāśritaḥ|| // 8-41-50 //
（50）大王よ、アルジュナは右翼に陣取り、長き腕のビーマセーナは左翼に立った。
sātyakir draupadeyāś ca svayaṃ rājā ca pāṇḍavaḥ|
vyūhasya pramukhe tasthuḥ svenānīkena saṃvṛtāḥ|| // 8-41-51 //
（51）サーティヤキ、ドラウパディーの子ら、そしてパーンダヴァ王（ユディシュティラ）自らは、自軍に囲まれて陣形の先頭に立った。
svabalena arisainyaṃ tat pratyavasthāpya pāṇḍavaḥ|
pratyavyūhat puraskṛtya dhṛṣṭadyumnaśikhaṇḍinau|| // 8-41-52 //
（52）パーンダヴァは自軍をもって敵軍と対峙し、ドリシュタデュムナとシカンディンを先頭に立てて陣を張った。
tat sādināgakalilaṃ padātirathasaṅkulam|
dhṛṣṭadyumnamukhaṃ ghoram aśobhata mahad balam|| // 8-41-53 //
（53）騎兵・象兵で埋め尽くされ、歩兵・戦車が群れなし、ドリシュタデュムナを先頭にしたその恐ろしい大軍は、まことに輝かしく見えた。
iti śrīmanmahābhārate karṇaparvaṇi ekacatvāriṃśo'dhyāyaḥ|| 41 ||
こうして、聖なる大マハーバーラタのカルナ篇の第四十一章は終わる。
