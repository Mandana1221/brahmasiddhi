karṇaparva — dvinavatitamo'dhyāyaḥ (92)
第92章 ― プラジャーパティの嘆願とブラフマーの裁定
sañjaya uvāca|
prajāpatistu taṃ dṛṣṭvā devabhāgaṃ samāgatam|
abravīttu tato rājanpaśyato vai svayaṃbhuvaḥ||
// 8-92-1 //
サンジャヤは語った。
プラジャーパティは、神々の集団が集まったのを見て、スヴァヤンブー（ブラフマー）が見守る中、こう語った。
ubhāvatirathau śūrāvubhau dṛḍhaparākramau|
ubhau sadṛśakarmāṇau vajricakrāyudhaupamau||
// 8-92-2 //
「二人ともアティラタ（最高の戦車戦士）で勇敢、二人とも堅固な武勇を持ち、二人とも同じような功績を持ち、ヴァジリン（インドラ）とチャクラーユダ（ヴィシュヌ）に等しい。」
aho bata mahadyuddhaṃ karṇārjunasamāgame|
bhaviṣyati mahāghoraṃ vṛtravāsavayoriva||
// 8-92-3 //
「ああ、カルナとアルジュナの激突において、ヴリトラとヴァーサヴァ（インドラ）のごとき恐るべき大戦闘が起こるであろう。」
prajāpatirathoktvaivaṃ svayambhuvamacodayat|
samo'stu vijayaḥ kāmamubhayornarasiṃhayoḥ||
// 8-92-4 //
プラジャーパティはこう言ってから、スヴァヤンブー（ブラフマー）にこう求めた。「この二人の人中の獅子の勝利を等しいものとしてくれ。」
karṇārjunavivādena mā naśyedakhilaṃ jagat|
svayaṃbho brūhi tadvākyaṃ samo'stu vijayo'nayoḥ||
// 8-92-5 //
「カルナとアルジュナの争いによって全世界が滅びることのないように。スヴァヤンブーよ、この二人の勝利が等しくなるよう、その言葉を述べてくれ。」
evamuktastu bhagavāñjaye tābhyāmaniścite|
ityabravīnmahārāja mahābrahmā prajāpatim||
// 8-92-6 //
このように言われたブラフマー神は、二人の勝敗がまだ定まらぬ中、大王よ、プラジャーパティにこう言った。
dvāvapyetau hi kṛtinau dvāvapyatibalotkaṭau|
bhaviṣyatyanayoryuddhaṃ trailokyasya bhayāvaham||
// 8-92-7 //
「この二人はいずれも達人であり、いずれも力において最高に優れている。この二人の戦いは三界にとって恐ろしいものとなろう。」
tataḥ prajāpatiṃ tatra sahasrākṣo'bhyacodayat|
vijayo dhruva evāstu pāṇḍavasya mahātmanaḥ||
// 8-92-8 //
そこで千の目を持つインドラがプラジャーパティにこう求めた。「偉大なるパーンダヴァ（アルジュナ）の勝利こそ確実であるべきです。」
manasvī balavāñśūraḥ kṛtavidyastapodhanaḥ|
vibharti ca mahātejā dhanurvedamaśeṣataḥ||
// 8-92-9 //
「彼は意志強く、力あり、勇敢で、学問を修め、苦行に富み、偉大な輝きを持ち、弓術の知識を余すところなく身につけています。」
pārthaḥ sarvaguṇopeto devakāryamidaṃ yataḥ|
kliśyante pāṇḍavā nityaṃ vanavāsādibhirbhṛśaṃ||
// 8-92-10 //
「パールタはすべての美徳を備え、これは神々のための事業です。パーンダヴァたちは森の放浪などで常に苦しめられてきました。」
sampannastapasā caiva paryāptaḥ puruṣarṣabhaḥ|
atikrāmecca māhātmyāddiṣṭamapyavicārayan||
// 8-92-11 //
「彼は苦行を完成させた人の中の雄牛であり、その偉大さゆえに、運命すらも顧みずに超えてしまうでしょう。」
atikrame ca lokānāmabhāvo niyato bhavet|
nāvasthānaṃ ca paśyāmi kruddhayoḥ kṛṣṇayoḥ kvacit||
// 8-92-12 //
「もし行き過ぎれば、世界の消滅は避けられません。怒った二人のクリシュナ（クリシュナとアルジュナ）を止める場所をどこにも見出せません。」
sraṣṭārau jagataścaitau tataś ca puruṣarṣabhau|
naranārāyaṇāvetau purāṇāvṛṣisattamau||
// 8-92-13 //
「この二人は世界の創造者であり、人の中の雄牛です。ナラとナーラーヤナという古の最高の聖仙なのです。」
aniyamyau niyantārau jagataḥ puruṣarṣabhau|
naitayostu samaḥ kaściddivi vā mānuṣeṣu vā||
anugamyāstrayo lokāḥ saha devarṣicāraṇaiḥ|
sarvadevagaṇāścāpi sarvabhūtāni yāni ca|
anayostu prabhāvena vartate nikhilaṃ jagat||
// 8-92-14-15 //
「制御できぬ世界の統御者たる人中の雄牛です。天にも人の世にも、この二人に等しい者はおりません。三界はデーヴァリシやチャーラナとともにこの二人に従い、すべての神々もすべての生きものも、この二人の力によってこの世界全体は存在しているのです。」
kāmaṃ tu sukṛtā~llokānāpnotu puruṣarṣabhaḥ|
karṇo vaikartanaḥ śūro vijayastvastu kṛṣṇayoḥ||
// 8-92-16 //
「勇敢なるヴァイカルタナ・カルナには、善行によって得られる天界を与えよう。しかし勝利は二人のクリシュナ（クリシュナとアルジュナ）のものとすべきです。」
vasūnāṃ samalokatvaṃ marutāṃ vāsamāpnuyāt|
sahito droṇabhīṣmābhyāṃ nākapṛṣṭhe mahīyatām||
// 8-92-17 //
「カルナはヴァス神群と同じ世界に住み、マルト神群の住処を得よ。ドローナやビーシュマとともに天の頂に輝け。」
'kleśito hi vane pārtho dirghakālaṃ pitāmaha|
tasmādeṣa jayedyuddhe tapasā'bhyadhiko'rjunaḥ||
// 8-92-18 //
「パールタは森で長い間苦しめられました、祖父よ。だから彼が戦いに勝つべきです。苦行においてアルジュナは上回っています。」
pūrvaṃ bhagavatā proktaḥ kṛṣṇayorvijayo dhruvaḥ|
tattathāstu namaste'stu pramo brūhi pitāmaha||
// 8-92-19 //
「以前に神が、二人のクリシュナの勝利は確実だと告げられました。そのとおりになりますように。あなたに敬礼いたします。祖父よ、お言葉を。」
tatsahasrākṣavacanaṃ niśamya bhagavānprabhuḥ|
novāca tajjayaṃ tulyaṃ tayoḥ karṇakirīṭinoḥ||
// 8-92-20 //
インドラのこの言葉を聞いた神なる主ブラフマーは、二人のうちの勝利について沈黙を保った。カルナとキリーティンの勝利が等しいとは言わなかった。
tasmādāśāṃ gataḥ śakrastūṣṇīmbhūte pitāmahe|
vijayaḥ pāṇḍaveyasya karṇasya ca vadho bhavet||
// 8-92-21 //
祖父が沈黙したので、インドラは希望を持った。パーンダヴァ（アルジュナ）の勝利とカルナの討死があるだろうと。
brahmeśānau tato vākyamūcaturbhuvaneśvaram|
vijayo dhruva evāstu pāṇḍavasya mahātmanaḥ||
// 8-92-22 //
そこでブラフマーとイーシャーナ（シヴァ）が世界の主（プラジャーパティ）に言った。「偉大なるパーンダヴァの勝利こそ確実であるべきです。」
manasvī jayatāṃ śūraḥ kṛtavidyastapodhanaḥ|
bibharti ca mahātejā dhanurvedamaśeṣataḥ||
// 8-92-23 //
「意志強き勇者が勝つべきです。学問を修め苦行に富み、偉大な輝きを持ち、弓術の知識を余すところなく身につけた者が。」
atikrāmecca māhātmyāddiṣṭamapyavicārayan|
atikrame ca lokānāmabhāvo niyato bhavet||
// 8-92-24 //
「その偉大さゆえに運命すらも顧みずに超えてしまうでしょう。行き過ぎれば世界の消滅は避けられません。」
na ca vidma hyavasthānaṃ kruddhayoḥ kṛṣṇayoḥ kvacit|
sraṣṭārau jagataścaiva sataś ca puruṣarṣabhau||
// 8-92-25 //
「怒った二人のクリシュナを止める場所をどこにも見出せません。この二人は世界の創造者であり、人の中の雄牛です。」
kāmaṃ tu sukṛtā~llokānprāpnotveṣa parantapaḥ|
karṇo vaikartanaḥ śūro vijayastu nare dhruvaḥ||
// 8-92-26 //
「勇敢なるヴァイカルタナ・カルナには善行の天界を得させよ。しかし勝利は確実にナラ（アルジュナ）のものです。」
tathokte devadevābhyāṃ sahasrākṣo'bravīdvacaḥ|
āmantrya sarvabhūtāni brahmeśānānuśāsanāt||
// 8-92-27 //
二大神にこう言われて、インドラはブラフマーとイーシャーナの教えに従い、すべての生きものに呼びかけてこう言った。
śrutaṃ bhavadbhiryatproktaṃ bhagavadbhyāṃ jagaddhitam|
tattathā vyetu te rogaḥ śamāpnuta vimanyavaḥ||
// 8-92-28 //
「皆の者、世界の利益のために二柱の神が語られたことを聞いたであろう。そのとおりになれ。おまえたちの苦しみが癒え、怒りなく安らぎを得よ。」
iti śrutvendravacanaṃ sarvabhūtāni māniṣa|
vismitānyabhavanrājanpūjayāñcakrire tadā|
nocustadā jayaṃ tulyaṃ tayoḥ puruṣasiṃhayoḥ||
// 8-92-29 //
インドラのこの言葉を聞いて、すべての生きものは驚嘆し、崇拝した。しかし、この二人の人中の獅子の勝利が等しいとは、誰も言わなかった。
vyasṛjaṃś ca sugandhīni puṣpavarṣāṇi harṣitāḥ|
nānārūpāṇi vibudhā devatūryāṇyavādayan||
// 8-92-30 //
喜びにあふれた神々は芳しい花の雨を降らせ、さまざまな形の天の楽器を奏でた。
didṛkṣavaścāpratimaṃ dvairathaṃ narasiṃhayoḥ|
vismayotphullanayanā nānyā bubudhire kriyāḥ||
// 8-92-31 //
比類なきこの二人の人中の獅子の一騎討ちを見ようとして、驚きに目を見開き、他のことには何も気づかなかった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe dvinavatitamo'dhyāyaḥ|| 92 ||
こうして、聖なる大マハーバーラタのカルナ篇の第92章は終わる。
