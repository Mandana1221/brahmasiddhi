マハーバーラタ ― カルナ篇 第81章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 81 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ81」、全77詩節からなります。アルジュナの武勇とビーマセーナによるシャクニの敗北の場面（第1〜77詩節）で本章は終わります。本章は詩節ごとの詳細な対訳が収録されています。
karṇaparva — ekāśītitamo'dhyāyaḥ (81)
第81章　アルジュナの武勇とビーマによるシャクニの敗北
sañjaya uvāca|
śrutvā tu rathanirghoṣaṃ siṃhanādaṃ ca saṃyuge|
arjunaḥ prāha govindaṃ śīghraṃ vāhaya vājinaḥ||
// 8-81-1 //
サンジャヤは語った。
arjunasya vacaḥ śrutvā govindo'rjunamabravīt|
eṣa gacchāmi sukṣipraṃ yatra bhīmo vyavasthitaḥ||
// 8-81-2 //
アルジュナの言葉を聞いて、ゴーヴィンダはアルジュナに言った。「すぐにビーマのいる所へ向かおう。」
taṃ yāntamaśvā himaśaṅkhavarṇāḥ suvarṇamuktāmaṇijālanaddhāḥ|
jambhaṃ jighāṃsuṃ pragṛhītavajraṃ hayā yathā tatra yathā vahaṃstadā||
// 8-81-3 //
雪や法螺貝のように白く、黄金と真珠と宝石の網で飾られた馬たちは、ジャンバを討とうと金剛杵を振りかざすインドラの馬たちのように、彼をそこへ運んでいった。
rathāśvamātaṅgapadātisaṅghā bāṇasvanairnemikhurasvanaiś ca|
sannādayanto vasudhāṃ diśaś ca kruddhā nṛsiṃhā jayamabhyudīyaḥ||
// 8-81-4 //
戦車・馬・象・歩兵の群れが、弓弦の音と車輪・蹄の音で大地と四方を響かせながら、怒れる人中の獅子たちは勝利を求めて進んだ。
teṣāṃ ca pārthasya ca māriṣāsīd dehāsupāpakṣapaṇaṃ suyuddham|
trailokyahetorasurairyathāsīd devasya viṣṇorjayatāṃ varasya||
// 8-81-5 //
彼ら（カウラヴァ軍）とアルジュナとの間に、体と命を賭けた激しい戦いが起こった。それは、三界のために、アスラたちと勝者の中の最上者たるヴィシュヌ神との間の戦いのようであった。
tairastamuccāvacamāyudhaṃ tad ekaḥ praciccheda kirīṭamālī|
kṣurārdhacandrairniśitaiś ca bhallaiḥ śirāṃsi teṣāṃ bahudhā ca bāhūn||
// 8-81-6 //
彼らの投げる様々な武器を、冠を戴くアルジュナはただ一人で、鋭い剃刀矢・半月矢・鏃で切り落とし、彼らの首と多くの腕を断ち切った。
chatrāṇi vālavyajanāni ketūn aśvānrathānpattigaṇāndvipāṃś ca|
te petururvyāṃ bahudhā vikṛttā vātapraṇunnāni yathā vanāni||
// 8-81-7 //
傘・払子・旗・馬・戦車・歩兵・象が、風に吹き倒された森のように、切り裂かれて次々と大地に落ちた。
suvarṇajālāvanatā mahāgajāḥ savaijayantīdhvajayodhakalpitāḥ|
suvarṇapuṅghairiṣubhiḥ samācitāś cakāśire prajvalitā yathācalāḥ||
// 8-81-8 //
黄金の網で覆われ、旗と戦士を載せた大象たちは、黄金の羽根を持つ矢で射抜かれ、火を噴く山々のように輝いた。
vidārya nāgāśvarathāndhañjayaḥ śarottamairvāsavavajrasannibhaiḥ|
drutaṃ yayau karṇajighāṃsayā tathā yathā marutvānbalabhedane purā||
// 8-81-9 //
ダナンジャヤ（アルジュナ）は、ヴァーサヴァ（インドラ）の金剛杵にも似た最上の矢で、象・馬・戦車を引き裂き、カルナを討とうとする意志を持って、かつてインドラがバラの城を破った時のように疾駆した。
tataḥ sa puruṣavyāghrastava sainyamarindamaḥ|
praviveśa mahābāhurmakaraḥ sāgaraṃ yathā||
// 8-81-10 //
そしてその人中の虎たるアルジュナは、大いなる腕を持つ敵の鎮圧者として、マカラ（ワニ）が海に入るように、汝（ドリタラーシュトラ）の軍に突入した。
taṃ hṛṣṭāstāvakā rājanrathapattisamanvitāḥ|
gajāśvasādibahulāḥ pāṇḍavaṃ samupādravan||
// 8-81-11 //
王よ、戦車・歩兵を伴い、象・騎馬を多数擁する汝の歓喜せる兵士たちは、パーンダヴァ（アルジュナ）に向かって殺到した。
teṣāmāpatatāṃ pārthamārāvaḥ sumahānabhūt|
sāgarasyeva kṣubdhasya yathā syātsalilasvanaḥ||
// 8-81-12 //
アルジュナに向かって突進する彼らの叫び声は、荒れ狂う大海の水の音のように、非常に大きかった。
te tu taṃ puruṣavyāghraṃ vyāghrā iva mahārathāḥ|
abhyadravanta saṅgrāme tyaktvā prāṇakṛtaṃ bhayam||
// 8-81-13 //
しかし、その人中の虎に対して、虎のごとき大戦車戦士たちは、命を捨てる覚悟で恐れを捨て、戦場で突撃した。
teṣāmāpatatāṃ tatra śaravarṣāṇi muñcatām|
arjuno vyadhamatsainyaṃ mahāvāto ghanāniva||
// 8-81-14 //
矢の雨を放ちながら突撃してくる彼らの軍を、アルジュナは、大風が雲を吹き散らすように蹴散らした。
te'rjunaṃ sahitā bhūtvā rathavaṃśaiḥ grahāriṇaḥ|
abhiyāya maheṣvāsā vivyadhurniśitaiḥ śaraiḥ||
// 8-81-15 //
弓の名手たる大戦車戦士たちは一致団結して、戦車群でアルジュナに迫り、鋭い矢で射った。
tato'rjunaḥ sahasrāṇi rathavāraṇavājinām|
preṣayāmāsa viśikhairyamasya sadanaṃ prati||
// 8-81-16 //
そしてアルジュナは、数千の戦車・象・馬を、矢によってヤマ（死神）の館へ送った。
te vadhyamānāḥ samare pārthacāpacyutaiḥ śaraiḥ|
tatratatra sma līyante bhaye jāte mahārathāḥ||
// 8-81-17 //
戦場でアルジュナの弓から放たれた矢に討たれた大戦車戦士たちは、恐怖に駆られ、あちこちに隠れた。
teṣāṃ catuḥśatānvīrānyatamānānmahārathān|
arjuno niśitairbāṇairanayadyamasādanam||
// 8-81-18 //
力を尽くして戦う四百人の勇猛な大戦車戦士たちを、アルジュナは鋭い矢でヤマの館へ送った。
te vadhyamānāḥ samare nānāliṅgaiḥ śitaiḥ śaraiḥ|
arjunaṃ samabhityajya dudruvurvai diśo daśa||
// 8-81-19 //
様々な形の鋭い矢で戦場で討たれた彼らは、アルジュナを見捨てて十方に逃げ散った。
teṣāṃ śabdo mahānāsīddravatāṃ vāhinīmukhe|
meghaughasyeva bhadraṃ te girimāsādya dīryataḥ||
// 8-81-20 //
軍の先頭で逃げる彼らの大きな叫び声は、山に当たって砕ける雨雲の群れのようであった。汝に幸あれ。
tāṃ tu senāṃ bhṛśaṃ viddhvā drāvayitvā'rjunaḥ śaraiḥ|
prāyādabhimukhaḥ pārthaḥ sūtānīkaṃ hi māriṣa||
// 8-81-21 //
その軍を矢で激しく射抜き、逃走させたアルジュナは、スータ族（カルナ）の軍に向かって前進した。
tasya śabdo mahānāsītparānabhimukhasya vai|
garuḍasyeva patataḥ pannagārthe yathā purā||
// 8-81-22 //
敵に向かって進む彼の音は、かつて蛇を求めて飛び降りるガルダ（神鳥）のそれのように、非常に大きかった。
taṃ tu śabdamabhiśrutya bhīmaseno mahābalaḥ|
babhūva paramaprītaḥ pārthadarśanalālasaḥ||
// 8-81-23 //
その音を聞いて、大力のビーマセーナは大いに喜び、アルジュナに会うことを切望した。
śrutvaiva pārthamāyāntaṃ bhīmasenaḥ pratāpavān|
tyaktvā prāṇānmahārāja senāṃ tava mamarda ha||
// 8-81-24 //
アルジュナが近づいて来ると聞くや、威光あるビーマセーナは、大王よ、命を惜しまず汝の軍を蹂躙した。
sa vāyuvīryapratimo vāyuvegasamo jave|
vāyuvadvyacaradbhīmo vāyuputraḥ pratāpavān||
// 8-81-25 //
風の力に等しく、風の速さと同じ俊足を持つ、風神の子たる威光あるビーマは、風のように戦場を駆け巡った。
tenādyamānā rājendra senā tava viśāmpate|
vyabhraśyata mahārāja bhinnā nauriva sāgare||
// 8-81-26 //
王の中の王よ、彼に打ち据えられた汝の軍は、大王よ、海で壊れた船のように崩壊した。
tāṃ tu senāṃ tadā bhīmo darśayanpāṇilāghavam|
śarairavacakartograiḥ prepayiṣyanyamakṣayam||
// 8-81-27 //
その時ビーマは、手の素早さを見せつけながら、恐ろしい矢でその軍を切り裂き、ヤマの館へ送ろうとした。
tatra bhārata bhīmasya balaṃ dṛṣṭvātimānuṣam|
vyatrasyanta raṇe yodhāḥ kālasyeva yugakṣaye||
// 8-81-28 //
バーラタよ、人間離れしたビーマの力を見て、戦場の戦士たちは、ユガの終わりの死神（カーラ）を前にしたように恐れおののいた。
tathā'rditānbhīmabalānbhīmasenena bhārata|
dṛṣṭvā duryodhano rājā idaṃ vacanamabravīt||
// 8-81-29 //
バーラタよ、ビーマセーナに激しく苦しめられたビーマの力を見て、ドゥルヨーダナ王はこう言った。
sainikāṃś ca maheṣvāsānyodhāṃś ca bharatarṣabha|
samādiśanraṇe sarvānhata bhīmamiti sma ha||
// 8-81-30 //
バーラタの雄牛よ、彼は兵士たちと大弓持ちの戦士たち全員に戦場で命じた。「ビーマを殺せ！」と。
tasminhate hataṃ manye pāṇḍusainyamaśeṣataḥ||
// 8-81-31 //
「彼が討たれれば、パーンドゥの全軍が討たれたも同然と私は思う。」
pratigṛhya ca tāmājñāṃ tava putrasya pārthivāḥ|
bhīmaṃ pracchādayāmāsuḥ śaravarṣaiḥ samantataḥ||
// 8-81-32 //
汝の息子のその命令を受けた王たちは、四方からビーマを矢の雨で覆い尽くした。
gajāś ca bahulā rājannarāś ca jayagṛddhinaḥ|
rathe sthitāś ca rājendra parivavrurvṛkodaram||
// 8-81-33 //
王よ、勝利を求める多くの象と兵士、そして戦車に乗った王たちがヴリコーダラ（ビーマ）を取り囲んだ。
sa taiḥ parivṛtaḥ śūraiḥ śūro rājansamantataḥ|
śuśubhe bharataśreṣṭho nakṣatrairiva candramāḥ||
// 8-81-34 //
四方を勇者たちに囲まれた勇猛なるビーマは、バーラタの最上者として、星に囲まれた月のように輝いた。
pariveṣī yathā somaḥ paripūrṇo virājate|
sa rarāja tathā saṅkhye darśanīyo narottamaḥ|
nirviśeṣo mahārāja vijayenaiva saṃyuge||
// 8-81-35 //
暈をまとった満月が輝くように、その見事な人中の最上者は戦場で輝いた。大王よ、戦場におけるアルジュナと見紛うばかりであった。
tasya te pārthivāḥ sarve śaravṛṣṭiṃ samāsṛjan|
krodharaktekṣaṇāḥ śūrā hantukāmā vṛkodaram||
// 8-81-36 //
怒りに赤い目をした勇敢な王たちは全員、ヴリコーダラ（ビーマ）を殺そうとして、矢の雨を浴びせた。
tāṃ vidārya mahāsenāṃ śaraiḥ sannataparvabhiḥ|
niścakrāma raṇādbhīmo matsyo jālādivāmbhasi||
// 8-81-37 //
しかしビーマは、真っ直ぐな節を持つ矢でその大軍を引き裂き、水中の魚が網から抜け出すように、戦場から脱出した。
hatvā daśasahasrāṇi gajānāmanivartinām|
nṛṇāṃ śatasahasre dve dve śate caiva bhārata||
pañca cāśvasahasrāṇi rathānāṃ śatameva ca|
hatvā prāsyandayadbhīmo nadīṃ śoṇitavāhinīm||
// 8-81-38-39 //
バーラタよ、後退せぬ一万頭の象、二十万二百人の兵士、五千頭の馬、百台の戦車を討ち倒し、ビーマは血の流れる河を生じさせた。
śoṇitodāṃ rathāvartāṃ hastigrāhasamākulām|
naramīnāśvanakrāntāṃ keśaśaivalaśādvalām||
sañchinnabhujanāgendrāṃ bahuratnāpahāriṇīm|
ūrugrāhāṃ majjapaṅkāṃ śīrṣopalasamāvṛtām||
// 8-81-40-41 //
血を水とし、戦車を渦とし、象を鰐とし、人を魚とし、馬をワニとし、髪を藻草とし、切断された腕を蛇王とし、多くの宝を奪い去り、腿を鰐とし、骨髄を泥とし、頭蓋骨を石で覆うその河は——
dhanuḥkāśāṃ śarāvāpāṃ gadāparighaketanām|
haṃsachatradhvajopetāmuṣṇīṣavaraphenilām||
hārapadmākarāṃ caiva bhūmireṇūrmimālinīm|
āryavṛttavatīṃ saṅkhye sutarāṃ bhīrudustarām||
// 8-81-42-43 //
弓を葦とし、矢を水門とし、棍棒と鉄棒を旗とし、白鵞鳥を傘とし、旗を目印とし、ターバンを美しい泡とし、首飾りを蓮池とし、大地の塵を波の連なりとし、戦場における高貴な行いの流れを持ち、勇者にとっては容易に渡れるが、臆病者にとっては渡り難いものであった。
yodhagrāhavatīṃ saṅkhye vahantīṃ pitṛsādanam|
kṣaṇena puruṣavyāghraḥ prāvartayata nimnagām||
// 8-81-44 //
戦場において戦士という鰐を擁し、祖先の館（死の世界）へ流れるその河を、人中の虎たるビーマは一瞬にして作り出した。
yathā vaitaraṇīmugrāṃ dustarāmakṛtātmabhiḥ|
tathā dustaraṇīṃ ghorāṃ bhīrūṇāṃ bhayavardhanīm||
// 8-81-45 //
それはちょうど、心を浄めぬ者には渡り難いヴァイタラニー河のように、恐ろしく渡り難く、臆病者の恐怖を増すものであった。
yatoyataḥ pāṇḍaveyaḥ praviṣṭo rathasattamaḥ|
tatastataḥ prāpatanvai yodhāḥ śatasahasraśaḥ||
// 8-81-46 //
パーンダヴァの戦車の最上者が突入するところ、どこであろうと、幾十万もの戦士が倒れた。
evaṃ dṛṣṭvā kṛtaṃ karma bhīmasenena saṃyuge|
duryodhano mahārāja śakuniṃ vākyamabravīt||
// 8-81-47 //
戦場でビーマセーナのなしたこの業を見て、大王よ、ドゥルヨーダナはシャクニに言った。
jahi mātula saṅgrāme bhīmasenaṃ mahābalam|
asmiñjite jitaṃ manye pāṇḍaveyaṃ mahābalam||
// 8-81-48 //
「叔父上よ、戦場で大力のビーマセーナを討て。この者を倒せば、大力のパーンダヴァ軍を倒したも同然と私は思う。」
tataḥ prāyānmahārāja saubaleyaḥ pratāpavān|
raṇāya mahate yukto bhrātṛbhiḥ parivāritaḥ||
// 8-81-49 //
そこで大王よ、威光あるスバラの子（シャクニ）は、大いなる戦いの用意をし、兄弟たちに囲まれて出陣した。
sa samāsādya saṅgrāme bhīmaṃ bhīmaparākramam|
vārayāmāsa taṃ vīro veleva makarālayam||
// 8-81-50 //
彼は戦場で恐るべき武勇のビーマに遭遇し、海岸が海の怪物（マカラ）を押しとどめるように、その勇者を阻止した。
sannyavartata taṃ bhīmo vāryamāṇaḥ śitaiḥ śaraiḥ|
śakunistasya rājendra vāmapārśve stanāntare|
preṣayāmāsa nārācānrukmapuṅkhāñśilāśitān||
// 8-81-51 //
鋭い矢で阻まれたビーマは引き返した。王の中の王よ、シャクニはビーマの左脇と胸の間に、黄金の羽根を持ち石で研がれた鉄矢を放った。
varma bhittvā tu te ghorāḥ pāṇḍavasya mahātmanaḥ|
nyama़ñjanta mahārāja kaṅkabarhiṇavāsasaḥ||
// 8-81-52 //
その恐ろしい矢は、偉大なパーンダヴァの鎧を貫通し、大王よ、サギとクジャクの羽根を持つ矢が体に突き刺さった。
so'tividdho raṇe bhīmaḥ śaraṃ rukmavibhūṣitam|
preṣayāmāsa sa ruṣā saubalaṃ prati bhārata||
// 8-81-53 //
戦場で激しく射抜かれたビーマは、怒りを込めて、黄金で飾られた矢をスバラの子に向けて放った。
tamāyāntaṃ śaraṃ ghoraṃ śakuniḥ śatrutāpanaḥ|
ciccheda saptadhā rājankṛtahasto mahābalaḥ||
// 8-81-54 //
その恐ろしい飛来する矢を、敵を苦しめるシャクニは、王よ、熟練の腕で七つに切り裂いた。大力の者であった。
tasminnipatite bhūmau bhīmaḥ kruddho viśāmpate|
dhanuśchiccheda bhallena saubalasya hasanniva||
// 8-81-55 //
その矢が地に落ちると、王よ、怒れるビーマは笑うかのように、鏃でスバラの子の弓を切断した。
tadapāsya dhanuśchinnaṃ saubaleyaḥ pratāpavān|
anyadādāya vegena dhanurbhallāṃś ca ṣoḍaśa|
taistasya tu mahārāja bhallaiḥ sannataparvabhiḥ||
// 8-81-56 //
威光あるスバラの子は、その切断された弓を捨て、素早く別の弓と十六本の鏃を取り上げた。
dvābhyāṃ sa sārathiṃ hyārcchadbhīmaṃ saptabhir eva ca|
dhvajamekena ciccheda dvābhyāṃ chatraṃ viśāmpate|
caturbhiścaturo vāhānvivyādha subalātmajaḥ||
// 8-81-57 //
大王よ、その真っ直ぐな節を持つ鏃で、二本で御者を射、七本でビーマを射た。一本で旗を切り、王よ、二本で傘を打ち、四本で四頭の馬を、スバラの子は射抜いた。
tataḥ kruddho mahārāja bhīmasenaḥ pratāpavān|
śaktiṃ cikṣepa samare rukmadaṇḍāmayasmayīm||
// 8-81-58 //
大王よ、怒れる威光あるビーマセーナは、戦場に黄金の柄の鉄の槍を投げた。
sā bhīmabhujanirmuktā nāgajihvena cañcalā|
nipapāta raṇe tūrṇaṃ saubalasya mahātmanaḥ||
// 8-81-59 //
ビーマの腕から放たれたその槍は、蛇の舌のように揺れ動き、偉大なスバラの子の上に素早く落ちた。
tatastāmeva saṃgṛhya śaktiṃ kanakabhūṣaṇām|
bhīmasenāya cikṣepa kruddharūpo viśāmpate||
// 8-81-60 //
するとスバラの子は、その黄金で飾られた同じ槍をつかみ、怒りの形相で王よ、ビーマセーナに投げ返した。
sā nirbhidya bhujaṃ savyaṃ pāṇḍavasya mahātmanaḥ|
nipapāta tadā bhūmau yathā vidyunnabhaścyutā||
// 8-81-61 //
その槍は偉大なパーンダヴァの左腕を貫き、空から落ちる稲妻のように大地に落ちた。
athotkruṣṭaṃ mahārāja dhārtarāṣṭraiḥ samantataḥ|
na tu taṃ mamṛṣe bhīmaḥ siṃhanādaṃ tarasvinām||
// 8-81-62 //
大王よ、ドリタラーシュトラの息子たちは四方から喝采した。しかしビーマは、勇者たちの獅子吼を許さなかった。
anyadgṛhya dhanuḥ sajyaṃ tvaramāṇo mahābalaḥ|
muhūrtādiva rājendra cchādayāmāsa sāyakaiḥ|
saubalasya balaṃ saṅkhye tyaktvā nādaṃ mahābalaḥ||
// 8-81-63 //
大力の者は急いで別の弦を張った弓を取り、大王よ、一瞬にして矢でスバラの子の軍を覆い尽くし、大力をもって雄叫びを上げた。
tasyāśvāṃścaturo hatvā sūtaṃ caiva viśāmpate|
dhvajaṃ ciccheda bhallena tvaramāṇaḥ parākramī||
// 8-81-64 //
王よ、彼はスバラの子の四頭の馬と御者を殺し、鏃で素早く旗を切り落とした。
hatāśvaṃ rathamutsṛjya tvaramāṇo narottamaḥ|
tasthau visphārayaṃścāpaṃ krodharaktekṣaṇaḥ śvasan||
// 8-81-65 //
馬を失った戦車を捨て、素早く人中の最上者は立ち上がり、弓を引き絞り、怒りに赤い目をして、荒い息を吐いた。
śaraiś ca bahudhā rājan bhīmamārcchatsamantataḥ||
// 8-81-66 //
王よ、彼は四方からビーマを多くの矢で射た。
pratihatya tu vegena bhīmasenaḥ pratāpavān|
dhanuściccheda saṅkruddho vivyādha ca śitaiḥ śaraiḥ||
// 8-81-67 //
威光あるビーマセーナは、その勢いを力で押し返し、激怒して弓を切断し、鋭い矢で射抜いた。
so'tividdho balavatā śatruṇā śatrukarśanaḥ|
nipapāta tadā bhūmau kiñcitprāṇo narādhipaḥ||
// 8-81-68 //
その敵を苦しめる者（シャクニ）は、強力な敵に激しく射抜かれ、わずかに息があるだけの王となって大地に倒れた。
tatastaṃ vihvalaṃ jñātvā putrastava viśāmpate|
apovāha rathenājau bhīmasenasya paśyataḥ||
// 8-81-69 //
そこで王よ、汝の息子は、彼が意識を失ったと知り、ビーマセーナの目の前で彼を戦車に乗せて運び去った。
śakuniṃ vihvalaṃ dṛṣṭvā dhārtarāṣṭrāḥ parāṅmukhāḥ|
pradudruvurdiśo bhītā bhīmasenabhayātprabho||
// 8-81-70 //
シャクニが意識を失ったのを見て、ドリタラーシュトラの息子たちは背を向け、ビーマセーナへの恐怖から四方に逃げ散った。
saubale nirjite rājanbhīmasenena dhanvinā|
bhayena mahatā''viṣṭaḥ putro duryodhanastava|
apāyājjavanairaśvaiḥ sāpekṣo mātulaṃ prati||
// 8-81-71 //
スバラの子が弓の名手ビーマセーナに打ち負かされると、汝の息子ドゥルヨーダナは大いなる恐怖に取り憑かれ、叔父を気にしながら、速い馬で逃走した。
parāṅmukhaṃ tu rājānaṃ dṛṣṭvā sainyāni bhārata|
viprajagmuḥ samutsṛjya dvairathāni samantataḥ||
// 8-81-72 //
バーラタよ、王が背を向けて逃げるのを見て、軍勢は一対一の戦いを放棄し、四方に散り散りになった。
tāndṛṣṭvā vidrutānsarvāndhārtarāṣṭrānparāṅmukhān|
javenābhyāpatadbhīmaḥ kirañśaraśatānbahūn||
// 8-81-73 //
逃げ散る全てのドリタラーシュトラの息子たちが背を向けるのを見て、ビーマは何百もの矢を放ちながら猛追した。
te vadhyamānā bhīmena dhārtarāṣṭrāḥ parāṅmukhāḥ|
karṇamāsādya samare sthitā rājansamantataḥ||
// 8-81-74 //
ビーマに討たれながら、背を向けたドリタラーシュトラの息子たちは、戦場でカルナのもとに辿り着き、王よ、四方に陣取った。
sa hi teṣāṃ mahāvīryo dvīpo'bhūtsumahābalaḥ|
bhinnanaukā yathā rājandvīpamāsādya nirvṛtāḥ||
bhavanti puruṣavyāghra nāvikāḥ kālaparyaye|
tathā karṇaṃ samāsādya tāvakāḥ puruṣarṣabha||
// 8-81-75-76 //
大いなる武勇のカルナこそ、彼らにとっての島（避難所）であった。王よ、壊れた船の乗組員が運命の転換期に島に辿り着いて安堵するように、人中の虎よ、汝の兵たちもカルナのもとに辿り着いた。
samāśvastāḥ sthitā rājansamprahṛṣṭāḥ parasparam|
samājagmuś ca yuddhāya mṛtyuṃ kṛtvā nivartanam||
// 8-81-77 //
安堵し、互いに勇気を取り戻し、死を覚悟して再び戦いに向かった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekāśītitamo'dhyāyaḥ|| 81 ||
