マハーバーラタ ― カルナ篇 第6章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 6 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ6」（ドリタラーシュトラがカルナの武勇を讃え、その死の経緯をサンジャヤに尋ねる章）です。各段落は原典の詩節番号（8-6-N）と和訳の段落番号が対応しています。なお、原典で角括弧に入った異伝詩節（51-52, 60-63, 72-76節）は和訳の底本では省略されていましたが、サンスクリット原文を省略しないという方針に基づき、該当詩節を補い、日本語訳を付しました。
karṇaparva — ṣaṣṭho'dhyāyaḥ (6)
第6章　ドリタラーシュトラがカルナの武勇を讃え、その死の経緯を尋ねる
sañjaya uvāca|
śriyā kulena yaśasā tapasā ca śrutena ca|
tvām adya santo manyante yayātimiva nāhuṣam|| // 8-6-1 //
サンジャヤは語った。 （1）富と家柄と名声と苦行と学問において、今日、善人たちはあなたをナーフシャ（ナフシャの子）のヤヤーティのように尊んでいます。
śrute maharṣipratimaḥ kṛtakṛtyo'si pārthiva|
paryavasthāpayātmānaṃ mā viṣāde manaḥ kṛthāḥ|| // 8-6-2 //
（2）学問において大聖仙に等しく、あなたはすべてを成し遂げた王です。自分自身を奮い立たせてください。絶望に心を向けてはなりません。
dhṛtarāṣṭra uvāca|
daivameva paraṃ manye dhik pauruṣam anarthakam|
yatra sālapratīkāśaḥ karṇo'hanyata saṃyuge|| // 8-6-3 //
ドリタラーシュトラは語った。 （3）「運命こそが至上のものだと私は思う。人の努力など何の意味もない。サーラ樹のごとき偉大なカルナが戦場で討たれたのだから。
hatvā yudhiṣṭhirānīkaṃ pāñcālānāṃ rathavrajān|
pratāpya śaravarṣeṇa diśaḥ sarvā mahārathaḥ|| // 8-6-4 //
（4）ユディシュティラの軍を殺し、パーンチャーラ族の戦車群を殺し、矢の雨で四方を焼き尽くした偉大な戦車戦士が。
mohiyitvā raṇe pārthān vajrahasta ivāsurān|
sa kathaṃ nihataḥ śete vāyurugṇa iva drumaḥ|| // 8-6-5 //
（5）金剛杵を持つインドラが阿修羅を惑わすように、戦場でパールタたちを惑わしたあの者が、なぜ討たれて横たわっているのか。風に倒された木のように。
śokasyāntaṃ na paśyāmi pāraṃ jalanidheriva|
cintā me vardhate'tīva mumūrṣā cāpi jāyate|| // 8-6-6 //
（6）悲しみの果てが見えない。大海の彼岸が見えないように。思い悩みは増す一方で、死の願いすら生じている。
karṇasya nidhanaṃ śrutvā vijayaṃ phalgunasya ca|
aśraddheyamahaṃ manye vadhaṃ karṇasya sañjaya|| // 8-6-7 //
（7）カルナの死とファルグナ（アルジュナ）の勝利を聞いて。サンジャヤよ、カルナが討たれたとは、信じがたいことだと私は思う。
vajrasāramidaṃ nūnaṃ hṛdayaṃ durbhidaṃ mama|
yacchrutvā puruṣavyāghraṃ hataṃ karṇaṃ na dīryate|| // 8-6-8 //
（8）我が心は金剛杵のように固く、砕きがたいに違いない。人の中の虎カルナが殺されたと聞いても砕けないのだから。
āyur nūnaṃ sudīrghaṃ me vihitaṃ daivataiḥ purā|
yatra karṇaṃ hataṃ śrutvā jīvāmīha suduḥkhitaḥ|| // 8-6-9 //
（9）まことに長い寿命が、神々によってかつて私に定められたのだろう。カルナが殺されたと聞いても、深く苦しみながらここに生きているのだから。
dhig jīvitam idaṃ caiva suhṛdvīnasya sañjaya|
adya cāhaṃ daśām etāṃ gataḥ sañjaya garhitām|
kṛpaṇaṃ vartayiṣyāmi śocyaḥ sarvasya mandadhīḥ|| // 8-6-10 //
（10）友人を失った者のこの命など呪わしい、サンジャヤよ。今日、私はこのような哀れで非難されるべき境遇に至った。愚かな者は、万人から哀れまれるだろう。
ahameva purā bhūtvā sarvalokasya satkṛtaḥ|
paribhūtaḥ kathaṃ sūta paraiḥ śakṣyāmi jīvitum|| // 8-6-11 //
（11）かつては全世界から敬われた私が、侮られた者として、御者よ、どうして敵のもとで生きていけようか。
duḥkhād duḥkhataraṃ bhanye prāptavānasmi sañjaya|
bhīṣmadroṇavadhenaiva karṇasya ca mahātmanaḥ|| // 8-6-12 //
（12）苦しみの上にさらに大きな苦しみを味わっていると私は思う、サンジャヤよ。ビーシュマとドローナの死、そして偉大な魂のカルナの死によって。
nāvaśeṣaṃ prapaśyāmi sūtaputre hate yudhi|
sa hi pāraṃ mahān āsīt putrāṇāṃ mama sañjaya|| // 8-6-13 //
（13）スータの息子が戦場で殺された今、何も残っていない。あの者こそが、サンジャヤよ、我が息子たちの偉大なる守りであった。
yuddhe hi nihataḥ śūro visṛjan sāyakān bahūn|
ko hi me jīvitena arthas tam ṛte puruṣarṣabham|| // 8-6-14 //
（14）戦いで殺された勇者は、多くの矢を放ちながら。あの人の中の最上者なくして、私の命にいかなる意味があろうか。
rathād ādhirathir nūnaṃ nyapatat sāyakārditaḥ|
parvatasyeva śikharaṃ vajrapātād vidāritam|| // 8-6-15 //
（15）アーディラティ（カルナ）は、矢に打たれて戦車から落ちたに違いない。金剛杵の一撃で引き裂かれた山の頂のように。
sa śete pṛthivīṃ nūnaṃ śobhayan rudhirokṣitaḥ|
mātaṅga iva mattena matāṅgena nipātitaḥ|| // 8-6-16 //
（16）あの者は大地に横たわって大地を飾っているに違いない。血に濡れて。狂った象に打ち倒された象のように。
yo balaṃ dhārtarāṣṭrāṇāṃ pāṇḍavānāṃ yato bhayam|
so'rjunena hataḥ karṇaḥ pratimānaṃ dhanuṣmatām|| // 8-6-17 //
（17）ドリタラーシュトラの息子たちの力であり、パーンダヴァたちの恐怖であった者——そのカルナがアルジュナに殺された。弓持ちたちの中の最高の規範であった者が。
sa hi vīro maheṣvāso mitrāṇām abhayaṅkaraḥ|
śete vinihato vīraḥ śakreṇeva purā balaḥ|| // 8-6-18 //
（18）あの勇者にして大弓の使い手、味方に恐れなきを与える者が、殺されて横たわっている。かつてバラがシャクラ（インドラ）に殺されたように。
paṅgor ivādhvagamanaṃ daridrasyeva kāmitam|
duryodhanasya lobhaśca samānyetāni sañjaya|| // 8-6-19 //
（19）脚の不自由な者が旅をするようなもの、貧しい者が欲望を抱くようなもの、ドゥルヨーダナの貪欲もまた同じことだ、サンジャヤよ。
anyathā cintitaṃ kāryamanyathā tattu jāyate|
aho nu balavaddaivaṃ kālaśca duratikramaḥ|| // 8-6-20 //
（20）計画は一つのように考えられたのに、結果はまた別のものとなった。ああ、運命は何と強いことか、時は何と越えがたいことか。
palāyamānaḥ kṛpaṇo dīnātmā dīnapauruṣaḥ|
kaccid vinihataḥ sūta putro duḥśāsano mama|| // 8-6-21 //
（21）逃げ惑い、哀れで意気消沈した勇気なき者として——御者よ、我が息子ドゥフシャーサナは殺されたのだろうか。
kaccinna dīnācaritaṃ kṛtavāṃs tāta saṃyuge|
kaccinna nihataḥ śūrā yathā'nye kṣatriyarṣabhāḥ|| // 8-6-22 //
（22）あの者は戦場で卑怯な行いをしなかったか。他のクシャトリヤの雄牛たちのように勇者として殺されたか。
yudhiṣṭhirasya vacanaṃ mā yuddhamiti sarvadā|
duryodhano nābhyagṛhṇān mūḍhaḥ pathyam ivauṣadham|| // 8-6-23 //
（23）ユディシュティラの『戦うな』という言葉を、常に、ドゥルヨーダナは聞き入れなかった。愚かにも、良い薬のような助言を。
śatalpe śayānena bhīṣmeṇa sumahātmanā|
pānīyaṃ yācitaḥ pārthaḥ so'vidhyan medinītalam|| // 8-6-24 //
（24）矢の床に横たわるビーシュマは、偉大なる魂の者として、パールタ（アルジュナ）に水を求め、大地を射抜いて水を湧き出させた。
jalasya dhārāṃ janitāṃ dṛṣṭvā pāṇḍusutena ca|
abravīt sa mahābāhus tāta saṃśāmya pāṇḍavaiḥ|| // 8-6-25 //
（25）パーンドゥの子が作り出した水の流れを見て、大いなる腕の者（ビーシュマ）は言った。『パーンダヴァたちと和解せよ。
praśamād vibhavecchāntir madantaṃ yuddham astu vaḥ|
bhrātṛbhāvena pṛthivīṃ bhuṅkṣva pāṇḍusutaiḥ saha|| // 8-6-26 //
（26）和解から安寧が生まれる。戦いはおまえたちの破滅をもたらす。兄弟の情をもって、パーンドゥの子たちとともに大地を治めよ。』
akurvan vacanaṃ tasya nūnaṃ śocati putrakaḥ|
tadidaṃ samanuprāpta vacanaṃ dīrghadarśinaḥ|| // 8-6-27 //
（27）あの者の言葉に従わなかった息子は、きっと今嘆いていることだろう。先見の明ある者のその言葉は、今こうして現実となったのだ。
ahaṃ tu nihatāmātyo hataputraśca sañjaya|
dyūtataḥ kṛcchramāpanno lūnapakṣa iva dvijaḥ|| // 8-6-28 //
（28）私は家臣を失い、息子を失った、サンジャヤよ。賭博から災難に陥った、翼を切られた鳥のように。
yathā hi śakuniṃ gṛhya chittvā pakṣau ca sañjaya|
visarjayanti saṃhṛṣṭāḥ krīḍamānāḥ kumārakāḥ|| // 8-6-29 //
（29）ちょうど鳥を捕まえて翼を切り、嬉しそうに遊びながら放す子供たちのように。
lūnapakṣatayā tasya gamanaṃ nopapadyate|
tathāhamapi samprāpto lūnapakṣa iva dvijaḥ|| // 8-6-30 //
（30）翼を切られたその者には飛ぶことがかなわない。同じように私もまた、翼を切られた鳥のような境遇に至ったのだ。
kṣīṇaḥ sarvārthahīnaśca nirjñātir bandhuvarjitaḥ|
kāṃ diśaṃ pratipatsyāmi dīnaḥ śatruvaśaṃ gataḥ|| // 8-6-31 //
（31）衰え、すべてを失い、親族もなく、縁者もなく、どの方角に向かえばよいのか。哀れにも敵の支配下に入った私は。」
vaiśampāyana uvāca|
ityevaṃ dhṛtarāṣṭro'tha vilapya bahuduḥkhitaḥ|
provāca sañjayaṃ bhūyaḥ sokavyākulamānasaḥ|| // 8-6-32 //
ヴァイシャンパーヤナは語った。 （32）こうしてドリタラーシュトラは深く苦しみながら嘆き、悲しみに心を乱されて、さらにサンジャヤにこう語った。
dhṛtarāṣṭra uvāca|
yo'jayat sarvakāmbhojān ambaṣṭhān kaikayaiḥ saha|
gāndhārāṃśca videhāṃśca jitvā kāryārtham āhave|| // 8-6-33 //
ドリタラーシュトラは語った。 （33）「すべてのカーンボージャを、アムバシュタをケーカヤとともに、ガーンダーラとヴィデーハを戦場で征服した者が。
duryodhanasya vṛddhyarthaṃ yo'jayat pṛthivīṃ prabhuḥ|
sa jitaḥ pāṇḍavaiḥ śūraiḥ samare vāhuśālibhiḥ|| // 8-6-34 //
（34）ドゥルヨーダナの繁栄のために大地を征服した力ある者が、勇猛で腕の力に秀でたパーンダヴァたちに戦場で敗れた。
tasmin hate maheṣvāse karṇe yudhi kirīṭinā|
ke vīrāḥ paryatiṣṭhanta tanmamācakṣva sañjaya|| // 8-6-35 //
（35）あの偉大な弓の使い手カルナがキリーティン（アルジュナ）に戦場で殺された今、どの勇者たちが踏みとどまったのか、それを語ってくれ、サンジャヤよ。
kaccinnaikaḥ parityaktaḥ pāṇḍavair nihato raṇe|
uktaṃ tvayā purā tāta yathā vīro nipātitaḥ|| // 8-6-36 //
（36）まさか一人だけ見捨てられて、パーンダヴァたちに戦場で殺されたのではないだろうな。おまえは以前、あの勇者がどのように倒されたか語ったが。
bhīṣmam apratiyudhyantaṃ śikhamḍī sāyakottamaiḥ|
pātayāmāsa samare sarvaśastrabhṛtāṃ varam|| // 8-6-37 //
（37）ビーシュマは戦おうとしない者であった——シカンディンが最上の矢で、すべての武器の持ち主の中の最良者を戦場で打ち倒した。
tathā draupadinā droṇo nyastasarvāyudho yudhi|
'dharmarājavacaḥ śrutvā aśvatthāmā hatastviti'|| // 8-6-38 //
（38）同様にドローナは、ドラウパディー（ドルパダの息子ドリシュタデュムナ）によって——ダルマラージャの言葉を聞いて、すべての武器を捨てた状態で——
yuktayogo maheṣvāsaḥ śarair bahubhir ācitaḥ|
nihataḥ khaṅgamudyamya dhṛṣṭadyumnena sañjaya|| // 8-6-39 //
（39）偉大な弓の使い手、多くの矢に飾られた者が、剣を振り上げたドリシュタデュムナに殺された、サンジャヤよ。
antareṇa hatāvetau chalena ca viśeṣataḥ|
aśrauṣam aham etad vai bhīṣmadroṇau nipātitau|| // 8-6-40 //
（40）この二人は裏側から、特に策略によって殺されたのだ。ビーシュマとドローナが倒されたと私は聞いた。
bhīṣmadroṇau hi samare na hanyād vajrabhṛt svayam|
nyāyena yudhyan samare tadvai satyaṃ bravīmi te|| // 8-6-41 //
（41）戦場でビーシュマとドローナを正面から戦って殺すことは、金剛杵を持つインドラ自身にもできなかったであろう。正当な戦い方で戦えばの話だが。それは真実として言っている。
karṇaṃ tvasya antamastrāṇi divyāni ca bahūni ca|
katham indropamaṃ vīraṃ mṛtyur yudve samaspṛśat|| // 8-6-42 //
（42）神聖なる多くの武器を放つカルナを——あのインドラに等しい勇者を——どのようにして死が戦いで捕らえたのか。
yasya vidyutprabhāṃ śaktiṃ divyāṃ kanakabhūṣaṇām|
prāyacchad dviṣatāṃ hantrīṃ kuṇḍalābhyāṃ purandaraḥ|| // 8-6-43 //
（43）稲妻のように輝く神聖な槍を、黄金で飾られた、敵を殺す槍を——耳飾りと引き換えにインドラは彼に与えたのだ。
yasya sarpamukho divyaḥ śaraḥ kāñcanabhūṣaṇaḥ|
aśeta niśitaḥ patrī samareṣvarisūdanaḥ|| // 8-6-44 //
（44）蛇の頭を持つ神聖な矢——黄金で飾られ、鋭く研がれ、羽をつけた、戦いで敵を滅ぼす矢が、あの者のもとにあったのだ。
bhīṣmadroṇamukhān vīrān yo'vamatya mahārathān|
jāmadagnyān mahāghoraṃ brāhmam astram aśikṣata|| // 8-6-45 //
（45）ビーシュマやドローナを先頭とする勇者たちをも軽んじた者が、ジャーマダグニヤ（パラシュラーマ）からブラフマーの武器という極めて恐ろしいものを学んだ。
yaśca droṇamukhān dṛṣṭvā vimukhān arditāñ śaraiḥ|
saubhadrasya mahābāhur vyadhamat kārmukaṃ śitaiḥ|| // 8-6-46 //
（46）大いなる腕の者は、ドローナを先頭とする者たちが矢に射られて背を向けるのを見て、スバドラーの子（アビマニユ）の弓を、鋭い矢で打ち砕いた者でもある。
yaśca nāgāyutaprāṇāṃ vajraraṃhasamacyutam|
virathaṃ sahasā kṛtvā bhīmasenam apāhasat|| // 8-6-47 //
（47）万頭の象の力を持ち、金剛杵の速さの不動のアチュタ（クリシュナ）をも、突然戦車を失わせ、ビーマセーナを嘲笑った者が。
sahadevaṃ ca nirjitya śaraiḥ sannataparvabhiḥ|
kṛpayā virathaṃ kṛtvā nāhanad dharmacintayā|| // 8-6-48 //
（48）サハデーヴァをも射ち負かし、しなやかな矢で戦車を失わせながら、ダルマを思いやって殺さなかった者が。
yaśca māyāsahasrāṇi vikurvāṇaṃ jayaiṣiṇam|
ghaṭotkacaṃ rākṣasendraṃ śakraśaktyā nijaghnivān|| // 8-6-49 //
（49）何千もの幻術を駆り、勝利を求める羅刹の王ガトートカチャをも、シャクラ（インドラ）の槍で殺した者が。
evāṃśca divasāny asya yuddhe bhīto dhanañjayaḥ|
nāgamad dvairathaṃ vīraḥ sa kathaṃ nihato raṇe|| // 8-6-50 //
（50）何日もの間、戦いで恐れたダナンジャヤ（アルジュナ）は、あの勇者との一騎打ちに出なかった。そのような者がなぜ戦場で殺されたのか。
saṃśaptakānāṃ yodhā ye āhvayanta sadā'nyataḥ|
etānhatvā haniṣyāmi paścād vaikartanaṃ raṇe|| // 8-6-51 //
（51）サンシャプタカ軍の戦士たちは常に別の場所から（アルジュナを）誘い出した。これらを殺してから、後でヴァイカルタナ（カルナ）を戦場で殺そう、と。
iti vyapadiśan pārtho varjayansūtajaṃ raṇe|
sa kathaṃ nihato vīraḥ pārthena paravīrahā|| // 8-6-52 //
（52）このように言い分けて、パールタ（アルジュナ）は戦場で御者の子（カルナ）を避けていた。その敵を滅ぼす勇者が、どうしてパールタに殺されたのか。
rathabhahgo na cettasya dhanurvā na vyaśīryata|
na cedastrāṇi naṣṭāni sa kathaṃ nihataḥ paraiḥ|| // 8-6-53 //
（53）あの者の戦車が壊れたのでなければ、弓が砕けたのでもなければ、武器が消えたのでもなければ——ならばどうしてあの者は敵に殺されたのか。
ko hi śakto raṇe karṇaṃ vidhunvānaṃ mahad dhanuḥ|
vimuñcantaṃ śarān ghorān divyāny astrāṇi cāhave|
jetuṃ puruṣaśārdūlaṃ śārdūlamiva veginam|| // 8-6-54 //
（54）大弓を振るい、恐ろしい矢と神聖な武器を戦場で放つカルナを——虎のように俊敏な人の中の虎を——誰が戦場で打ち勝てるというのか。
dhravaṃ tasya dhanuśchinnaṃ ratho vā'pi mahīṃ gataḥ|
astrāṇi vā pranaṣṭāni yathā śaṃsasi me hatam|
na hyanyadapi paśyāmi kāraṇaṃ tasya nāśane|| // 8-6-55 //
（55）きっとあの者の弓が断たれたのだ、あるいは戦車が大地に沈んだのだ、あるいは武器が消えたのだ——おまえがそのように殺されたと告げるからには。あの者が滅びる原因は他に思い当たらない。
na hinmi phalgunaṃ yāvat tāvat pādau na dhāvaye|
iti yasya mahāghoraṃ vratam āsīn mahātmanaḥ|| // 8-6-56 //
（56）『ファルグナ（アルジュナ）を殺さぬ限り足を洗わぬ』——偉大な魂のあの者には、そのような恐ろしい誓いがあったのだ。
yasya bhīto rame nidrāṃ dharmarājo yudhiṣṭhiraḥ|
trayodaśasamā nityaṃ nābhajat puruṣarṣabhaḥ|| // 8-6-57 //
（57）あの者を恐れて、ダルマラージャ・ユディシュティラは、十三年間、夜に安眠を得ることがなかった、人の中の最上者は。
yasya vīryavato vīryam upāśritya mahātmanaḥ|
mama putraḥ sabhāṃ bhāryāṃ pāṇḍūnāṃ nītavān balāt|| // 8-6-58 //
（58）あの武勇ある偉大な魂の武勇を頼みにして、我が息子は、パーンドゥの者たちの妻を集会場に力ずくで連れ出したのだ。
tatrāpi ca sabhāmadhye pāṇḍavānāṃ ca paśyatām|
dāsabhāryeti pāñcālīm abravīt kurusannidhau|| // 8-6-59 //
（59）その集会場の真ん中で、パーンダヴァたちが見ている前で、パーンチャーリー（ドラウパディー）にクルの者たちの面前で『奴隷の妻よ』と言った者が。
na santi tapayaḥ kṛṣṇe sarve ṣaṇḍatilaiḥ samāḥ|
upatiṣṭhasva bhartāramanyaṃ vā varavarṇini|| // 8-6-60 //
（60）「クリシュナーよ、汝の夫たちは皆、去勢された者に等しい。他の夫を選ぶがよい、美しい女よ。」
ityevaṃ yaḥ purā vāco rūkṣāḥ saṃśrāvayanruṣā|
sabhāyāṃ sūtajaḥ kṛṣṇāṃ sa kathaṃ nihataḥ paraiḥ|| // 8-6-61 //
（61）このように、以前怒りをもって辛辣な言葉をクリシュナーに集会場で聞かせた御者の子が、どうして敵に殺されたのか。
yadi bhīṣmo raṇaślāghī droṇo vā yudhi durmadaḥ|
na haniṣyati kaunteyān pakṣapātāt suyodhana|
sarvāneva haniṣyāmi vyetu te mānaso jvaraḥ|| // 8-6-62 //
（62）『もしビーシュマが戦いを誇る者、あるいはドローナが戦場で傲慢な者として、偏愛のゆえにクンティーの子らを殺さないなら、スヨーダナよ、私自身が彼ら全員を殺そう。お前の心の熱病を去らせよ。』
kiṃ kariṣyati gāṇḍīvam akṣayyau ca maheṣudhī|
snigdhacandanadigdhasya maccharasyābhidhāvataḥ|
sa nūnam ṛṣabhaskandho hyarjunena kathaṃ hataḥ|| // 8-6-63 //
（63）ガーンディーヴァの弓も、尽きることのない二つの矢筒も何ができようか、香油と白檀を塗った私の矢が迫れば。雄牛のような肩を持つあの者が、どうしてアルジュナに殺されたのか。
yaśca gāṇḍīvamuktānāṃ sparśam ugram acintayan|
apatir hy asi kṛṣṇeti bruvan pārthān avaikṣata|| // 8-6-64 //
（64）ガーンディーヴァから放たれた矢の衝撃をも意に介さず、クリシュナー（ドラウパディー）に『夫なき者よ』と言いながらパールタたちを見つめた者が。
yasya nāsīd bhayaṃ pārthāt saputrāt sajanārdanāt|
svabāhubalam āśritya muhūrtam api sañjaya|| // 8-6-65 //
（65）パールタを息子とジャナールダナ（クリシュナ）もろとも、自らの腕の力を頼りにして、一瞬たりとも恐れなかった者、サンジャヤよ。
tasya nā'haṃ vadhaṃ manye devairapi savāsavaiḥ|
pratīpam abhighāvadbhiḥ kiṃ punas tāta pāṇḍavaiḥ|| // 8-6-66 //
（66）そのような者の死は、ヴァーサヴァ（インドラ）を先頭とする神々にさえ、正面から攻め寄せたとしても不可能であると私は思う。ましてパーンダヴァたちにおいてをや。
na hi jyāṃ saṃsampṛśānasya talatre vā'pi gṛhṇataḥ|
pumān ādhiratheḥ sthātuṃ kaścit pramukhato'rhati|| // 8-6-67 //
（67）弓弦に触れ、あるいは手の防具を握るアーディラティ（カルナ）の正面に、立つことのできる者は誰もいないのだ。
api syān medinī hīnā somasūryaprabhāṃśubhiḥ|
na vadhaḥ puruṣendrasya saṃyugeṣvapalāyinaḥ|| // 8-6-68 //
（68）大地が月と太陽の光を失うことがあっても——あの戦場で退くことなき人の中のインドラの死はあり得ない。
yena mandaḥ sahāyena bhrātrā duḥśāsanena ca|
vāsudevasya durbuddhiḥ pratyākhyānam arocata|| // 8-6-69 //
（69）あの愚かな者（ドゥルヨーダナ）が、あの者と弟ドゥフシャーサナを助けにして、悪しき知恵をもってヴァースデーヴァ（クリシュナ）への拒否を思い立ったのだ。
sa nūnaṃ vṛṣabhaskandhaṃ karṇaṃ dṛṣṭvā nipātitam|
duḥśāsanaṃ ca nihataṃ manye śocati putrakaḥ|| // 8-6-70 //
（70）あの者はきっと、雄牛のような肩を持つカルナが倒れたのを見て、ドゥフシャーサナも殺されたのを見て、嘆いているに違いない、息子は。
hataṃ vaikartanaṃ dṛṣṭvā dvairathe savyasācinā|
jayataḥ pāṇḍavān dṛṣṭvā kiṃsvid duryodhano'bravīt|| // 8-6-71 //
（71）ヴァイカルタナが一騎打ちでサヴヤサーチン（アルジュナ）に殺されたのを見て、パーンダヴァたちの勝利を見て、ドゥルヨーダナは何と言ったのか。
durmarṣaṇaṃ hataṃ dṛṣṭvā vṛṣasenaṃ ca saṃyuge|
prabhagraṃ ca balaṃ dṛṣṭvā vadhyamānaṃ mahārathaiḥ|| // 8-6-72 //
（72）ドゥルマルシャナが殺され、ヴリシャセーナも戦場で殺されたのを見て、大戦車戦士たちに討たれて崩れゆく軍を見て——
parāṅmukhāṃśca rājñastu palāyanaparāyaṇān|
vidrutān rathino dṛṣṭvā manye śocati putrakaḥ|| // 8-6-73 //
（73）背を向けて逃げ去ることに専心する王たちを、逃げ惑う戦車兵たちを見て、息子は嘆いているに違いないと私は思う。
aneyaścābhimānī ca durbuddhir ajitendriyaḥ|
hatotsāhaṃ balaṃ dṛṣṭvā kiṃsvid duryodhano'bravīt|| // 8-6-74 //
（74）導かれ難く、自負心強く、悪しき知恵を持ち、感覚を制し得ない者——士気を失った軍を見て、ドゥルヨーダナは何と言ったのか。
svayaṃ vairaṃ mahatkṛtvā vāryamāṇaḥ suhṛdgaṇaiḥ|
pradhane hatabhūyiṣṭhaiḥ kiṃsvid duryodhano'bravīt|| // 8-6-75 //
（75）自ら大いなる怨恨を作り、友人たちに制止されながら——戦場でほとんどの者が殺された今、ドゥルヨーダナは何と言ったのか。
bhrātaraṃ nihataṃ dṛṣṭvā bhīmasenena saṃyuge|
rudhire pīyamāne ca kiṃsvid duryodhano'bravīt|| // 8-6-76 //
（76）兄弟（ドゥフシャーサナ）がビーマセーナに戦場で殺され、その血が飲まれるのを見て、ドゥルヨーダナは何と言ったのか。
saha gāndhārarājena sabhāyāṃ yadabhāṣata|
karṇo'rjunaṃ raṇe hantā hate tasmin kim abravīt|| // 8-6-77 //
（77）ガーンダーラの王（シャクニ）とともに集会場で語ったこと——『カルナがアルジュナを戦場で殺す』と——あの者が殺された今、何と言ったのか。
dyūtaṃ kṛtvā purā hṛṣṭho vañcayitvā ca pāṇḍavān|
śakuniḥ saubalas tāta hate karṇe kim abravīt|| // 8-6-78 //
（78）かつて喜んで賭博をし、パーンダヴァたちを欺いたスバラの子シャクニは——カルナが殺された今、何と言ったのか。
kṛtavarmā maheṣvāsaḥ sātvatānāṃ mahārathaḥ|
hataṃ vaikartanaṃ dṛṣṭvā hārdikyaḥ kim abhāṣata|| // 8-6-79 //
（79）偉大な弓の使い手クリタヴァルマンは、サートヴァタ族の偉大な戦車戦士ハールディキヤは——ヴァイカルタナが殺されたのを見て、何と言ったのか。
brāhmaṇāḥ kṣatriyā vaiśyā yasya śikṣām upāsate|
dhanurvedaṃ cikīrṣanto droṇaputrasya dhīmataḥ||
yuvā rūpeṇa sampanno darśanīyo mahāyaśāḥ|
aśvatthāmā hate karṇe kim abhāṣata sañjaya|| // 8-6-80-81 //
（80〜81）バラモン・クシャトリヤ・ヴァイシャがその教えに仕え、弓術を学ぼうとする知恵あるドローナの息子——若く美しく名高いアシュヴァッターマンは、カルナが殺された時、何と言ったのか、サンジャヤよ。
ācāryo yo dhanurvede gautamo rathasattamaḥ|
kṛpaḥ śāradvatas tāta hate karṇe kim abravīt|| // 8-6-82 //
（82）弓術の師にしてガウタマ（ゴータマの子孫）、戦車兵の中の最上者クリパ・シャーラドヴァタは——カルナが殺された時、何と言ったのか。
madrarājo maheṣvāsaḥ śalyaḥ samitiśobhanaḥ|
dṛṣṭvā vinihataṃ karṇaṃ sārathye rathināṃ varaḥ|
kim abhāṣata sauvīro madrāṇām adhipo balī|| // 8-6-83 //
（83）マドラの王にして偉大な弓の使い手、戦場に輝くシャリヤは——殺されたカルナを見て、戦車兵の中の最上者の御者であった者は——マドラの強き支配者ソーヴィーラは何と言ったのか。
dṛṣṭvā vinihataṃ sarve yodhā vāraṇadurjayāḥ|
ye ca kena rājānaḥ pṛthivyāṃ yodvum āgatāḥ|
vaikartanaṃ hataṃ dṛṣṭavā kāny abhāṣanta sañjaya|| // 8-6-84 //
（84）殺されたのを見て、すべての戦士たち、象の上の征服し難き者たちは——大地の上から戦いに来た王たちは——ヴァイカルタナが殺されたのを見て何と言ったのか、サンジャヤよ。
droṇe tu nihate vīre rathavyāghre nararṣabhe|
ke vā mukham anīkānām āsan sañjaya bhāgaśaḥ|| // 8-6-85 //
（85）ドローナが殺された後、勇猛なる戦車の虎、人の中の雄牛よ——戦場の先頭に誰が、サンジャヤよ、それぞれどの部署にいたのか。
madrarājaḥ kathaṃ śalyo niyukto rathināṃ varaḥ|
vaikartanasya sārathye tanmamācakṣva sañjaya|| // 8-6-86 //
（86）マドラの王シャリヤは、戦車兵の中の最上者として、どのようにしてヴァイカルタナの御者に任じられたのか、それを語ってくれ、サンジャヤよ。
ke'rakṣan dakṣiṇaṃ cakraṃ sūtaputrasya yudhyataḥ|
vāmaṃ cakraṃ rarakṣur vā ke vā vīrasya pṛṣṭhataḥ|| // 8-6-87 //
（87）スータの息子が戦っている間、右の車輪を誰が守り、左の車輪を誰が守り、あるいは勇者の背後を誰が守ったのか。
ke karṇaṃ na jahuḥ śūrāḥ ke kṣudrāḥ prādravaṃs tataḥ|
kathaṃ ca vaḥ sametānāṃ hataḥ karṇo mahārathaḥ|| // 8-6-88 //
（88）どの勇者たちがカルナを見捨てなかったのか。どの卑怯者たちがそこから逃げ出したのか。そしておまえたちが集結していたにもかかわらず、どのようにしてカルナは殺されたのか、大戦車戦士が。
pāṇḍavāśca svayaṃ śūrāḥ pratyudīyur mahārathāḥ|
sṛjantaḥ śaravarṣāṇi vāridhārā ivāmbudāḥ|| // 8-6-89 //
（89）パーンダヴァたちも自ら勇猛な大戦車戦士として、矢の雨を放ちながら立ち向かった。雨雲が水の流れを降らすように。
sa ca sarpamukho divyo maheṣupravaras tadā|
vyarthaḥ kathaṃ samabhavat tan mamācakṣva sañjaya|| // 8-6-90 //
（90）あの蛇の頭を持つ神聖な大いなる矢は、あの時、なぜ無効になったのか、それを語ってくれ、サンジャヤよ。
māmakasyāsya sainyasya hatotsedhasya sañjaya|
avaśeṣaṃ na paśyāmi kakude mṛdite sati|| // 8-6-91 //
（91）頂を砕かれた我が軍の、士気を失った軍の残りが、私には見えない。
tau hi vīrau maheṣvāsau madarthe tyaktajīvītau|
bhīṣmadroṇau hatau śrutvā ko nvartho jīvitena me|| // 8-6-92 //
（92）あの二人の勇者、偉大な弓の使い手は、私のために命を捨てた。ビーシュマとドローナが殺されたと聞いて、私の命にいかなる意味があろうか。
punaḥ punar na mṛṣyāmi vadhaṃ karṇasya pāṇḍavaiḥ|
yasya bāhvor balaṃ tulyaṃ kuñjarāṇāṃ śataṃ śatam|| // 8-6-93 //
（93）パーンダヴァによるカルナの殺害を、何度考えても許せない。あの者の両腕の力は百頭の象に等しかったのだ。
droṇe hate ca yad vṛttaṃ kauravāṇāṃ paraiḥ saha|
saṅghāme naravīrāṇāṃ tanmamācakṣva sañjaya|| // 8-6-94 //
（94）ドローナが殺された後、カウラヴァたちと敵の間に何が起こったのか——勇者たちの合戦において——それを語ってくれ、サンジャヤよ。
yathā karṇaśca kaunteyaiḥ saha yuddham ayojayat|
tathā ca dviṣatāṃ hantā raṇe śāntas tad ucyatām|| || // 8-6-95 //
（95）カルナがカウンテーヤ（パーンダヴァ）たちとどのように戦ったか、そしてどのように敵を滅ぼす勇者が戦場で静まったか——それを語ってくれ。」
iti śrīmanmahābhārate karṇaparvaṇi ṣaṣṭho'dhyāyaḥ|| 6 ||
こうして、聖なる大マハーバーラタのカルナ篇の第六章は終わる。
