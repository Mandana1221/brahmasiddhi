マハーバーラタ ― カルナ篇 第50章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 50 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ50」（ドローナの子アシュヴァッターマン（ドラウニ）がユディシュティラの守備陣に猛攻を加える全44詩節の章）です。サンジャヤが語るところによれば、ドラウニは矢の雨で天を覆い隠すほどの矢の幕（バーナジャーラ）を張り巡らせ、戦場は太陽さえ見えぬ闇に包まれます（第2〜7詩節）。サーティヤキとパーンチャーラ軍、さらにユディシュティラの五人の子（プラティヴィンディヤ・シュルタカルマン・シュルタキールティ・スタソーマ・シャターニーカ）らが一斉にドラウニに挑みますが、ドラウニはこれをことごとく打ち返し（第8〜20詩節）、シュルタキールティとの一対一の応戦も見られます（第18詩節）。ドラウニは火炎のように陣営を焼き払うほどの勢いでパーンダヴァ軍を圧倒し（第28〜31詩節）、ドゥルヨーダナはこれを喜んで眺めます（第32詩節）。後半では、ユディシュティラ自らがドラウニに激しく詰め寄り、「バラモンでありながら武器を取って戦うのは道に背くことではないか」と痛烈に非難する場面が中心となります（第33〜39詩節）。ドラウニはこれに対し一言も答えず黙したまま（第40詩節）、なおも矢の雨でパーンダヴァを圧迫し続け、ユディシュティラはついに戦場を退いて自軍へと向かい、ドラウニが戦場に踏み留まる場面で終わります（第41〜44詩節）。なお、原典の奥書（コロフォン）には第40・42〜49章と同様「サプタダシャディヴァサユッデ（第十七日の戦いにて）」という句が付されています。また、本章のサンスクリット原典にも、前章（第49章）と同様、本来の第1〜44詩節の連番に先立って余分な注記「8-50-0」が冒頭の「サンジャヤは語った」の一文に付されているという特異な誤記が見られたため、これを第1詩節の本文に統合した上で全44詩節を正しく分離・対訳しています。なお、本章では新たに「व」（va）と「ध」（dha）の字形混同によるOCR誤記（athānyadvanurādāya→atha anyad dhanur ādāya、第18・24詩節に同一の誤記が二度出現）、「भ」（bha）と「म」（ma）の混同（drauṇāyanibhupādravan→drauṇāyanim upādravan、bhāriṣa→māriṣa）、「स」（sa）と「श」（śa）の混同（darsayet→darśayet、sayanniva→śayan iva）、また既出の「द्व」（dva）と「द्ध」（ddha）の混同（tribhirvidvvā→tribhir viddhvā、krudvarūpān→kruddharūpān）、「प」（pa）と「ष」（ṣa）の混同（rājannāśīvipa→rājan āśīviṣa、pārpataṃ→pārṣataṃ）が確認されたため、文脈上明らかな箇所のみ訂正しています。なお、第21詩節の原文には「द्रोणपुत्रं त्रिपष्टxx ततु बाह्वोरुरसि चार्पययत्」という、判読不能な文字列「xx」を含む損傷・欠損箇所が原典に存在するため、この部分は訂正せずそのまま転写しています（"tripaṣṭaxx"）。
karṇaparva — pañcāśo'dhyāyaḥ (50)
第50章
sañjaya uvāca|
drauṇiryudhiṣṭhiraṃ dṛṣṭvā śaineyena abhirakṣitam|
draupadeyaistathā śūrair abhyavartata hṛṣṭavat|| // 8-50-1 //
サンジャヤは語った。 （1）ドローナの子（アシュヴァッターマン）は、シニ族（サーティヤキ）と勇者ドラウパディーの子らに守られたユディシュティラを見て、喜んで向かって行った。
kiran niṣugaṇān ghorān hemapuṅkhāñ śilāśitān|
darśayan vividhān mārgāñ śikṣayā laghuhastavān|| // 8-50-2 //
（2）金の羽根をもつ、石で鋭くされた恐ろしい矢の群れを放ち、さまざまな攻撃を示し、訓練によって素早い手の者は――。
khaṃ purayañ śarais tīkṣṇair vegavadbhiḥ samantataḥ|
yudhiṣṭhirasya samare diśaḥ sarvāḥ samāvṛṇot|| // 8-50-3 //
（3）鋭く速い矢で空を満たし、戦場であたり一面に、ユディシュティラの諸方向を覆った。
bhāradvājaśaraiś channaṃ na prājñāyata kiñcana|
bāṇabhūtam abhūt sarvam āyodhanaśiro mahat|| // 8-50-4 //
（4）バーラドヴァージャの子（ドローナの子）の矢に覆われて、何も見えなかった。戦場の空はすべて矢でいっぱいだった。
bāṇajālaṃ diviṣṭhaṃ tat svarṇapuṅkhavibhūṣitam|
śuśubhe bharataśreṣṭha vimānam iva viṣṭhitam|| // 8-50-5 //
（5）金の羽根で飾られた空中にある矢の網は、バーラタの最上者よ、天の戦車が停泊しているかのように輝いた。
tena cchanne raṇe rājan bāṇajālena bhāsvatā|
abhracchāyā iva sajajñe hṛtaraśmis tamonudaḥ|| // 8-50-6 //
（6）それに覆われた戦場では、王よ、輝く矢の網によって、雲の影のような、光を奪われた闘が生じた。
tad adbhutam apaśyāma bāṇabhūte nabhasthale|
na sma sampatate bhūtaṃ drauṇer dṛṣṭvā parākramam|| // 8-50-7 //
（7）矢で空が満たされたその驚きを我らは見た。ドローナの子の武勇を見た生き物は誰一人として通らなかった。
sātyakir yatamānas tu dharmarājas tu pāṇḍavaḥ|
tathā itarāṇi sainyāni na sma cakruḥ parākramam|| // 8-50-8 //
（8）サーティヤキは懸命に戦い、ダルマ王パーンダヴァも、他の軍勢も武勇を発揮できなかった。
lāghavaṃ droṇaputrasya dṛṣṭvā tatra mahārathāḥ|
vyasmayanta mahārāja na ca enaṃ pratyudīkṣitum|| // 8-50-9 //
（9）ドローナの子の素早さを見て、戦場の偉大な戦車戦士たちは驚いた、大王よ。彼に対抗して見ることもできなかった。
śekus te sarvarājānas tapantam iva bhāskaram|
vadhyamāne tataḥ sainye draupadeyā mahārathāḥ|| // 8-50-10 //
（10）すべての王たちは、輝く太陽のような彼を見ることができなかった。軍勢が殺されてゆくとき、ドラウパディーの子の偉大な戦車戦士たちは――。
sātyakir dharmarājaś ca pāñcālāś ca api saṅgatāḥ|
tyaktvā mṛtyubhayaṃ ghoraṃ drauṇāyanim upādravan|| // 8-50-11 //
（11）サーティヤキ、ダルマ王、パーンチャーラ族が一緒になり、恐ろしい死の恐怖を捨ててドローナの子に襲いかかった。
sātyakiḥ saptaviṃśatyā drauṇiṃ viddhvā śilīmukhaiḥ|
punar vivyādha nārācaiḥ saptabhiḥ svarṇabhūṣitaiḥ|| // 8-50-12 //
（12）サーティヤキは二十七本の矢でドローナの子を射、さらに金で飾られた七本の鉄矢で再び射た。
yudhiṣṭhiras trisaptatyā prativindhyaś ca saptabhiḥ|
śrutakarmā tribhir vāṇaiḥ śrutakīrtiś ca saptabhiḥ| // 8-50-13 //
（13）ユディシュティラは七十三本で、プラティヴィンディヤは七本で、シュルタカルマンは三本の矢で、シュルタキールティは七本で、――。
sutasomas tu navabhiḥ śatānīkaś ca saptabhiḥ|
anye ca vahavaḥ śūrā vivyadhus taṃ samantataḥ|| // 8-50-14 //
（14）スタソーマは九本で、シャターニーカは七本で、他の多くの勇者たちがあたり一面から彼を射た。
sa tu kruddhas tato rājan āśīviṣa iva śvasan|
sātyakiṃ pañcaviṃśatyā prāvidhyata śilīmukhaiḥ|| // 8-50-15 //
（15）激怒した彼は、王よ、毒蛇のように息をしながら、サーティヤキを二十五本の矢で射た。
śrutakīrtiṃ ca navabhiḥ sutasomaṃ ca pañcabhiḥ|
aṣṭabhiḥ śrutakarmāṇaṃ pratibindhyaṃ tribhiḥ śaraiḥ|| // 8-50-16 //
（16）シュルタキールティを九本で、スタソーマを五本で、八本でシュルタカルマンを、プラティヴィンディヤを三本の矢で射――。
śatānīkaṃ ca navabhir dharmaputraṃ ca pañcabhiḥ|
tathā itarāṃs tataḥ śūrān dvābhyāṃ dvābhyām atāḍayat|
śrutakīrtes tathā cāpaṃ ciccheda niśitaiḥ śaraiḥ|| // 8-50-17 //
（17）シャターニーカを九本、ダルマの子（ユディシュティラ）を五本で、他の勇者たちを二本ずつで打った。シュルタキールティの弓を鋭い矢で切り裂いた。
atha anyad dhanur ādāya śrutakīrtir mahārathaḥ|
drauṇāyaniṃ tribhir viddhvā vivyādha anyaiḥ śitaiḥ śaraiḥ|| // 8-50-18 //
（18）別の弓を取って偉大な戦車戦士シュルタキールティは、ドローナの子を三本の矢で射、他の鋭い矢でも射た。
tato drauṇirmahārāja śaravarṣeṇa māriṣa|
chādayāmāsa tat sainyaṃ samantād bharatarṣabha|| // 8-50-19 //
（19）そしてドローナの子は、大王よ、矢の雨で、バーラタの雄牛よ、その軍をあたり一面覆った。
tataḥ punar ameyātmā dharmarājasya kārmukam|
drauṇiś ciccheda vihasan vivyādha ca śarais tribhiḥ|| // 8-50-20 //
（20）無量の魂をもつ者は再びダルマ王の弓を、笑いながらドローナの子は切り裂き、三本の矢で射た。
tato dharmasuto rājan pragṛhya anyan mahad dhanuḥ|
droṇaputraṃ tripaṣṭaxx tatu bāhvorurasi cārpayayat|| // 8-50-21 //
（21）ダルマの子（ユディシュティラ）は、他の大きな弓を取って、ドローナの子を六十三本の矢で、両腕と胸に射た。
sātyakis tu tataḥ kruddho drauṇeḥ praharato raṇe|
ardhacandreṇa tīkṣṇena dhanuś chittvā'nadad bhṛśam|| // 8-50-22 //
（22）サーティヤキは怒り、戦場で戦うドローナの子の弓を、半月矢の鋭い矢で切って、強く叫んだ。
chinnadhanvā tato drauṇiḥ śaktyā śaktimatāṃ varaḥ|
sārathiṃ pātayāmāsa śaineyasya rathād drutam|| // 8-50-23 //
（23）弓を切られたドローナの子は、槍の中で最上の力をもつ者として、槍を投げてシニ族（サーティヤキ）の御者を戦車から素早く落とした。
atha anyad dhanur ādāya droṇaputraḥ pratāpavān|
śaineyaṃ śaravarṣeṇa cchādayāmāsa bhārata|| // 8-50-24 //
（24）別の弓を取ってドローナの子は輝ける者として、シニ族を矢の雨で覆った、バーラタよ。
tasyāśvāḥ pradrutāḥ saṅkhye patite rathasārathau|
tatra tatra eva dhāvantaḥ samadṛśyanta bhārata|| // 8-50-25 //
（25）その馬たちは、御者が倒れたため、戦場で走り去った。あちらこちらへ走る彼らが見えた、バーラタよ。
yudhiṣṭhirapurogās tu drauṇiṃ śastrabhṛtāṃ varam|
abhyavarṣanta vegena visṛjantaḥ śitāñ charān|| // 8-50-26 //
（26）ユディシュティラを先頭にする者たちは、武器の最上者ドローナの子に向かって、勢いよく鋭い矢を放ちながら襲いかかった。
sahasā patatas tān vai kruddharūpān parantapaḥ|
prahasan pratijagrāha droṇaputro mahāraṇe|| // 8-50-27 //
（27）突然襲いかかる怒れる者たちを、敵を焼く者は、笑いながらドローナの子は戦場で受け止めた。
tataḥ śaraśatajvālaḥ senākakṣaṃ mahāraṇe|
drauṇir dadāha samare kakṣam agnir iva utthitaḥ|| // 8-50-28 //
（28）そして数百の矢の炎で、軍の束を戦場で、ドローナの子は焼いた、起こった火が森を焼くように。
tad balaṃ pāṇḍuputrasya droṇaputrapratāpitam|
cukṣubhe bharataśreṣṭha tasminneva camūmukhe|| // 8-50-29 //
（29）パーンダヴァの軍は、ドローナの子に焼かれて動揺した、バーラタの最上者よ、軍の先頭で。
tad balaṃ pāṇḍaveyasya droṇaputraḥ śarārciṣā|
tāpayan bharataśreṣṭha gabhastibhir iva aṃśumān|| // 8-50-30 //
（30）パーンダヴァのその軍を、ドローナの子は矢の光で焼きながら、バーラタの最上者よ、太陽のように光線で――。
tat pacyamānaṃ marṣeṇa brāhmaṇasya ca sāyakaiḥ|
kṣubhyate pāṇḍavaṃ sainyaṃ timinā iva nadīmukham|| // 8-50-31 //
（31）そのバラモンの矢でじわじわと焼かれて、パーンダヴァの軍は動揺した、河口の魚のように。
dṛṣṭvā caiva mahārāja droṇaputraparākramam|
sarvān duryodhanaḥ pārthān hatān yuddhe'bhyamanyata|| // 8-50-32 //
（32）そのドローナの子の武勇を見て、大王よ、ドゥルヨーダナはアルジュナの兄弟たちがすべて戦場で殺されたと思った。
yudhiṣṭhiras tu tvarito drauṇiṃ pīḍya mahāratham|
abravīd droṇaputraṃ sa roṣāmarṣasamanvitaḥ|| // 8-50-33 //
（33）ユディシュティラは急いで偉大な戦車戦士ドローナの子を攻め、怒りと憤りに満ちて言った。
'jānāmi tvāṃ yudhi śreṣṭha vīryavantaṃ balānvitam|
kṛtāstraṃ kṛtinaṃ caiva tathā laghuparākramam|| // 8-50-34 //
（34）『戦いの最上者よ、私はお前を知っている。武勇と力あり、武器に通じ、器用な素早い武勇の持ち主と。
balam etad bhavān sarvaṃ pārṣate yadi darśayet|
tatas tvāṃ balavantaṃ ca kṛtavidyaṃ ca vidmahe|| // 8-50-35 //
（35）もしお前がすべての力をプリシャタの子（ドリシュタデュムナ）に示すなら、そのときお前が力あり学識ある者と認めよう。
na hi vai pārṣataṃ dṛṣṭvā samare śatrusūdanam|
bhavet tava balaṃ kiñcid bravīmi tvāṃ na tu dvijam'|| // 8-50-36 //
（36）しかし戦場で敵を討つプリシャタの子を見れば、お前にはなんの力もないだろう。私はそう言うが、二生者（バラモン）にそう言うのではない』。
naiva nāma tava prītir naiva nāma kṛtajñatā|
yatas tvaṃ puruṣavyāghra mām eva adya jighāṃsasi|| // 8-50-37 //
（37）お前には愛情も、恩を知る心もないのか。人の虎よ、今、私を殺そうとしているのだから。
brāhmaṇena tapaḥ kāryaṃ śamaś ca dama eva ca|
kṣatriyeṇa dhanur nābhyaṃ sa bhavān brāhmaṇabruvaḥ|| // 8-50-38 //
（38）バラモンには苦行を、静かさと抑制こそがふさわしい。クシャトリヤは弓を持つべきであり、お前は自称バラモンにすぎぬ。
miṣatas te mahāvāho yudhi jeṣyāmi kauravān|
kuruṣva samare karma brahmabandhe yathā iṣṭataḥ|| // 8-50-39 //
（39）長き腕のお前が見ている前で、戦場でクル族を打ち負かそう。戦場で、お前の望むがままに業を行なえ、バラモンの兄弟よ」。
evamukto mahārāja droṇaputraḥ śayan iva|
yukta tattvaṃ ca sañcintya nottaraṃ kiñcid abravīt|| // 8-50-40 //
（40）大王よ、このように言われたドローナの子は、よく考えて、何も答えなかった。
anuktvā ca tataḥ kiñcic charavarṣeṇa pāṇḍavam|
chādayāmāsa samare kruddho'ntaka iva prajāḥ|| // 8-50-41 //
（41）何も答えずに、矢の雨でパーンダヴァを覆った。怒りの死神が衆生を覆うように。
sa cchādyamānas tu tadā droṇaputreṇa māriṣa|
pārtho'payātaḥ śīghraṃ vai pragṛhya mahatīṃ camūm|| // 8-50-42 //
（42）ドローナの子に覆われて、敬うべき方よ、大軍勢を連れてアルジュナの兄（ユディシュティラ）は素早く退いた。
apayāte tatas tasmin dharmaputre yudhiṣṭhire|
droṇaputraḥ sthito rājan pratyādeśān mahātmanaḥ|| // 8-50-43 //
（43）ダルマの子（ユディシュティラ）が退いたのち、王よ、ドローナの子は高潔な者の命令によって立ち尽くしていた。
tato yudhiṣṭhiro rājaṃs tyaktvā drauṇiṃ mahāhave|
prayayau tāvakaṃ sainyaṃ yuktaḥ krurāya karmaṇe|| || // 8-50-44 //
（44）ユディシュティラ王は戦場でドローナの子を捨てて、あなた方の軍へと向かった、残酷な業に挑むべく。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcāśo'dhyāyaḥ|| 50 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十章は終わる。
