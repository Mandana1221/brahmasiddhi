マハーバーラタ ― カルナ篇 第87章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 87 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ87」で、ビーマセーナによるドゥフシャーサナの胸からの血の飲み干しの場面を描きます。
karṇaparva — saptāśītitamo'dhyāyaḥ (87)
第87章　ビーマによるドゥフシャーサナの胸からの血の飲み干し
sañjaya uvāca|
sara rājaputreṇa samārcchadugra duḥśāsanena nikṛto nikṛtyā||
// 8-87-1 //
サンジャヤは語った。
tatrākarodduṣkaraṃ rājaputro duḥśāsanaḥ kuruvīro mahātmā|
yadbhīmasenaṃ pratiyodhayadraṇe jambho yathā śakramudāravīryam||
// 8-87-2 //
そこで王子ドゥフシャーサナ、クルの勇者、偉大な者は困難なことを成し遂げた。ジャンバがインドラと戦うように、ビーマセーナと戦場で戦ったのだ。
dhanucchittvā bhīmasenasya saṅkhye ṣaḍbhiḥ śaraiḥ sārathimabhyavidhyat|
tato'vidhyattriṃśatā bhīmasenaṃ vareṣubhirvanyamiva dvipendram||
// 8-87-3 //
ビーマセーナの弓を戦場で切断し、六本の矢で御者を射た。そして三十本の優れた矢でビーマセーナを射た。森の象のように。
sa kārmukaṃ gṛhya tu bhārasādhanaṃ bhīmastadā rājaputraṃ hyavidhyat|
pañcāśatairbāṇagaṇaiḥ stanānantare totrairyathā tīvravegaṃ dvipendram||
// 8-87-4 //
ビーマは力で引く弓を取り、王子（ドゥフシャーサナ）の胸に五十本の矢の群れを射た。象の突き棒で象を刺すように。
tatastu rājanvirathaṃ mahātmā duḥśāsano bhīmasenaṃ cakāra|
nihatya saṅkhye caturo'sya bāhāñ chittvā ratheṣāṃ punareva cākṣipat||
// 8-87-5 //
そして王よ、偉大なドゥフシャーサナは、ビーマセーナを戦車を失わせた。戦場で四頭の馬を殺し、戦車の轅を切り、再び投げ飛ばした。
tataḥ kṣitisvo hyabaruhya yānād vṛkodaro madayā tasya vāhān|
yamakṣayaṃ preṣayitvā mahātmā rathaṃ samākarpata rājasūnoḥ||
// 8-87-6 //
そこで王よ、ヴリコーダラ（ビーマ）は車から飛び降り、彼の馬たちをヤマの館に送った偉大な者は、王の子の戦車を引き寄せた。
tasmādavaplutya rathātsasarja duḥśāsanastomaramugravegam|
sa tena viddho hyurasi hyaprameyo gadāṃ tasmai visasarjāprameyām||
// 8-87-7 //
その戦車から飛び降りて、ドゥフシャーサナは恐ろしい速さの投げ矛を放った。胸に射抜かれたビーマは、計り知れぬ者として、計り知れぬ棍棒を彼に放った。
tataḥ krodhādbhīmasenaḥ kṛtāni sarvāṇi duḥkhānyanusaṃsmaranvai|
saṃsmṛtya saṃsmṛtya tathā pratijñām ugrām asau rājaputrau vyaṣīdat||
// 8-87-8 //
そしてビーマセーナは、怒りから、過去の全ての苦難を思い出し——思い出し、思い出しては——そして（ドラウパディーへの）恐ろしい誓いを思い、王の子に向かって行った。
sañcintitaṃ roṣamatīva vegā- ttrayodaśābdaṃ puruṣapravīraḥ|
pragṛhya vajrāśanitulyavegāṃ gadāṃ kareṇātha vṛkodaro ruṣā||
// 8-87-9 //
十三年間蓄えた怒りを、人中の勇者は、極めて激しく——金剛杵と雷に等しい速さの棍棒を手に取り、ヴリコーダラは怒りをもって——
nipātayitvā pṛthivītale bhṛśaṃ sa tājayāmā vṛkodaro balī|
atīva santāḍitabhinnagātro duḥśāsano vai nipapāta bhūmau||
// 8-87-10 //
大地に激しく叩きつけた。力あるヴリコーダラに激しく打ちのめされ、四肢を砕かれたドゥフシャーサナは大地に倒れた。
ākramya kaṇṭhe yudhi rājaputraṃ saṃraktanetro hyabravīddhārtarāṣṭram|
tadbrūhi kiṃ tvaṃ parimārgamāṇo hyasmānparābhūya ihāgataḥ punaḥ||
// 8-87-11 //
戦場で王子の喉を踏みつけ、目を赤く染めてドリタラーシュトラの息子に言った。「今度は何を求めてここに来たのだ、我々を蔑んで？」
didīpayaṃstadbhṛśadīpitaṃ me cirārjitaṃ roṣamatipradīptam|
madhu prapāsye tava koṣṭabhājanād ityabravīdbhīmasenastarasvī||
// 8-87-12 //
「長い間積もった、激しく燃え上がった我が怒りを燃え立たせ——お前の腹の器から蜜を飲んでやるぞ。」と勇猛なビーマセーナは言った。
duḥśāsanaṃ kaṇṭhadeśe pramṛdraṃs tataḥ krūraṃ bhīmasenaścakāra|
kataṃ vyaṃsayitvā sahasā sasāra balādasau dhārtarāṣṭrastarasvī||
// 8-87-13 //
ドゥフシャーサナの喉を踏みつけ、ビーマセーナは残酷なことをした。鎧を力ずくで引き剥がし、力強いドリタラーシュトラの息子はよろめいた。
bhīmo'bhidudrāva sutaṃ tvadīyaṃ sapatratāṃ darśayandhārtarāṣṭre|
mṛgaṃ muhuḥ siṃhaśiśuryathā vane tathāśvabhidrutya mahābalaṃ balī||
// 8-87-14 //
ビーマは汝の息子に向かって突進し、ドリタラーシュトラの息子に敵意を示しながら——森で獅子の子が鹿を追うように、大力の者が力で追い駆けた。
nigṛhya cainaṃ parameṇa karmaṇā utkṣipya cotkṣipya ca tūrṇamenam|
bhūmau tadā niṣpipeṣātha vīra asiṃ vikośaṃ vimalaṃ cakāra||
// 8-87-15 //
最高の技で彼をねじ伏せ、何度も投げ上げ投げ上げて——勇者は彼を大地に叩きつけ、抜き身の清浄な剣を引き抜いた。
taṃ pātayitvā tu vṛkodaro'tha jagarja harṣeṇa vinādayandiśaḥ|
nādena tenākhilapārśvavartino mūrcchākulāḥ patitāstvājamīḍha||
// 8-87-16 //
ヴリコーダラはドゥフシャーサナを倒し、喜びの雄叫びで四方を震わせた。その叫び声で、周りにいた全ての者が意識を失って倒れた、アジャミーダ（ドリタラーシュトラ）よ。
duḥśāsanaṃ tatra samīkṣya rājan bhīmo mahābāhuracintyakarmā|
smṛtvā ca keśagrahaṇaṃ ca devyā vastrāpahāraṃ ca rajasvalāyāḥ||
// 8-87-17 //
王よ、大いなる腕を持つ、思いもよらぬ業を行うビーマが、ドゥフシャーサナを見つめながら——ドラウパディーの髪をつかんだことを、月経中の女から衣を剥いだことを思い出した。
anāgaso bhartṛparāṅmukhāyā duḥkhāni dattānyapi vipracintyā|
jajvāla kopādatha bhīmasena ājyaprasikto hi yathā hutāśaḥ||
// 8-87-18 //
罪なき者、夫に背を向けることのない妻に与えられた、考え難い苦しみを。ビーマセーナは怒りに燃えた。バターを注がれた火のように。
tatrāha karṇaṃ ca suyodhanaṃ ca kṛpaṃ drauṇiṃ kṛtavarmāṇameva|
nihanmi duḥśāsanamadya pāpaṃ saṃrakṣyatāmadya samastayodhāḥ||
// 8-87-19 //
そしてカルナ、ドゥルヨーダナ、クリパ、ドローナの子、クリタヴァルマンに向かって叫んだ。「今日この邪悪なドゥフシャーサナを殺す。全ての戦士たちよ、守れるものなら守ってみろ！」
ityevamuktvā sahasābhyadhāvan nihantukāmo'tibalastarasvī|
tathā tu vikramya rame vṛkodaro mahāgajaṃ kesariko yathaiva|
nigṛhya duḥśāsanamekavīraḥ suyodhanasyādhiratheḥ samakṣam||
// 8-87-20 //
こう言うと、大いなる力の俊敏な者は殺さんとして突進した。ヴリコーダラは戦場でこのように奮戦し——大象を獅子が倒すように——スヨーダナ（ドゥルヨーダナ）とアディラタの子（カルナ）の目の前で、唯一の勇者としてドゥフシャーサナをねじ伏せた。
asiṃ samudyamya sitaṃ sudhāraṃ kaṇṭhe padākramya ca vepamānam|
uvāca tadgauriti yadbruvāṇo hṛṣṭo'vadaḥ karṇasuyodhanābhyām||
// 8-87-21 //
光り輝く鋭い白い剣を振り上げ、震える者の喉を踏みつけ、こう言った——「お前が『牛よ！牛よ！』と言いながら、カルナとスヨーダナに喜んで言ったことを——」
ye rājasūyāvabhṛthe pavitrā jātāḥ kachā yājñasenyā durātman|
te pāṇinā katareṇāvakṛṣṭās tadbrūhi tvāṃ pṛcchati bhīmasenaḥ||
// 8-87-22 //
「ラージャスーヤ祭の聖浴で清められたヤージュナセーニー（ドラウパディー）の清らかな髪を、悪党よ、どちらの手で引きずったのだ？それを言え——ビーマセーナがお前に問うている。」
śrutvā tu tadbhīmavacaḥ sughoraṃ duḥśāsano bhīmasenaṃ nirīkṣya|
jajvāla bīmaṃ sa tadā smayena saṃśṛṇvatāṃ kauravasomakānām|
uktastadājau sa tathā saroṣaṃ jagāda bhīmaṃ parivṛttanetraḥ||
// 8-87-23 //
ビーマの恐ろしい言葉を聞いて、ドゥフシャーサナはビーマセーナを見つめ——カウラヴァとソーマカが聞いている中で、恐ろしい笑みを浮かべた。戦場でこのように怒りを込めて言われ、目をぎらつかせて——
ayaṃ karikarākāraḥ pīnastanavimardanaḥ|
gosahasrapradātā ca kṣatriyāntakaraḥ karaḥ||
// 8-87-24 //
「この象の鼻のような太い腕、豊かな乳房を揉んだ腕、千頭の牛を施す腕、クシャトリヤを殺す腕——」
anena yājñasenyā me bhīma keśā vikarṣitāḥ|
paśyatāṃ kurumukhyānāṃ yuṣmākaṃ ca sabhāsadām||
// 8-87-25 //
「ビーマよ、この腕でヤージュナセーニーの髪が引きずられた。クルの長老たちの面前で、お前たちの面前で、集会の人々の前で。」
evaṃ tvasau rājasutaṃ niśamya bruvantamājau vinipīḍya vakṣaḥ|
bhīmo balāttaṃ pratigṛhya dorbhyām uccairnanādātha samastayodhān||
// 8-87-26 //
ビーマは、こう語る王の子を聞いて、戦場でその胸を押さえつけ、両腕で力ずくでつかみ、全ての戦士に向かって大声で叫んだ。
uvāca yasyāsti balaṃ sa rakṣat vasau bhavedadya nirastabāhuḥ|
duḥśānaṃ jīvitaṃ protsṛjantam ākṣipya yodhāṃstarasā mahābalaḥ||
// 8-87-27 //
こう言った。「力ある者は守れ。この者は今日、腕を失うだろう。」大力の者は戦士たちを一喝し、ドゥフシャーサナの命が尽きようとしていることを告げた。
evaṃ kruddho bhīmasenaḥ kareṇa utpāṭayāmāsa bhujaṃ mahātmā|
duḥśāsanaṃ tena sa vīramadhye jaghāna vajrāśanisannibhena||
// 8-87-28 //
怒れるビーマセーナは手で偉大な者の腕を引き抜き、勇者たちの中で、その金剛杵と雷に等しい腕でドゥフシャーサナを打った。
kaṇṭhe samākramya ca vepamānaṃ kṛtvā'nu rūpaṃ paramaṃ sughoram|
kālāntakābhyāṃ sadṛśaṃ tadānīṃ vidārya vakṣaś ca mahārathasya||
// 8-87-29 //
震える者の喉を踏みつけ、最も恐ろしいことを行った——死神そのもののように——偉大な戦車戦士の胸を引き裂いた。
duḥśāsanasya nipuśāsanasya uddhṛtya vakṣaḥ patitasya bhūmau|
tato'pibacchoṇitamasya koṣṇam āsvādya cāsvādya ca vīkṣamāṇaḥ||
// 8-87-30 //
大地に倒れたドゥフシャーサナの——従わぬ者への罰を行う者の——胸を引き裂き、そのまだ温かい血を飲んだ。味わい、味わっては見回しながら。
kruddhaḥ prahṛṣṭo nijagāda vākyaṃ stanyasya mātuḥ payaso'mṛtasya|
mādhvīkajasyeva rasasya tasya madhoś ca pānādyavakasya pānāt||
payodadhibhyāṃ mathitācca mukhyāt tathekṣusārasya manoharasya|
sarvebhya evābhyadhiko raso'sya mato mamādyāhitalohitasya||
// 8-87-31-32 //
怒り、喜びながら言葉を発した——「母の乳よりも、蜜酒よりも、ヨーグルトと乳から作った最上のもの、サトウキビの汁、心を奪う美味なもの——これら全てよりも勝っている。今日の敵の血の味は、私にとって。」
evaṃ bruvāṇaṃ punarutthitaṃ tam āsphoṭya valgantamatiprahṛṣṭam|
ye bhīmasenaṃ dadṛśustadānīṃ prāyeṇa te'pi vyathitā nipetuḥ||
// 8-87-33 //
こう語りながら再び立ち上がり、両手を叩いて飛び跳ね、大いに喜ぶビーマセーナを見た者たちは、ほとんどが苦しみに倒れた。
ye cāpi nāsanpatitā manuṣyās teṣāṃ karebhyaḥ patitaṃ tu śastram|
bhayācca sañcukruśurasvaraistadā nimīlitākṣā mumuhuś ca tatra||
// 8-87-34 //
倒れなかった者たちの手からも武器が落ち、恐怖のあまりかすれた声で叫び、目を閉じ、意識を失った。
ye tatra bhīmaṃ rudhiraṃ pibantaṃ duḥśāsanasya dadṛśuḥ prapannāḥ|
nāyaṃ manuṣyastviti bhāṣamāṇāḥ sarve'palāyanta bhayābhipannāḥ||
// 8-87-35 //
倒れたドゥフシャーサナの血を飲むビーマを見た全ての者たちは——「これは人間ではない」と言いながら、恐怖に駆られて逃げ去った。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe saptāśītitamo'dhyāyaḥ|| 87 ||
