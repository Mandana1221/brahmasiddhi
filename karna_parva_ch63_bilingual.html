マハーバーラタ ― カルナ篇 第63章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 63 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ63」、全37詩節からなり、前章（第62章）の流れを受けてドゥルヨーダナが戦況を嘆く問い（第1〜5詩節）とサンジャヤの答え（第6〜37詩節）で構成されます。ドリタラーシュトラが戦況を問う（第1〜5詩節）、カルナがビーマを食い止めて軍を立て直した場面（第6〜9詩節）、各戦士の一騎打ちの配置（第10〜19詩節）、シカンディンとカルナの決闘（第20〜28詩節）、ドリシュタデュムナとドゥフシャーサナの決闘（第29〜37詩節）で本章は終わります。なお、本章では冒頭の注記「8-63-0」「8-63-0x」（「ドリタラーシュトラは語った」）が第1詩節の本文に統合されており、第5詩節でドリタラーシュトラの問いが終わり、第6詩節の0x注記「サンジャヤは語った」が第6詩節に統合されています。第4詩節にはバックティック記号「`」で示される異文注記が含まれますが、他章と同様の正規化（アポストロフィへ変換）のみを行っています。第7詩節の「preṣāyaṣyāmi」（本来 preṣayiṣyāmi）はOCR誤記と思われますが、原典の形を保持しています。
karṇaparva — trisaṣṭitamo'dhyāyaḥ (63)
第63章
dhṛtarāṣṭra uvāca|
nivṛtte bhīmasene ca pāṇḍave ca yudhiṣṭhire|
vadhyamāne bale cāpi māmake pāṇḍusṛñjayaiḥ||
// 8-63-1 //
「ビーマセーナが帰還し、パーンダヴァのユディシュティラも退き、我が軍がパーンドゥ・スリンジャヤ族に殺されているとき、
dravamāṇe balaughe ca nirākrande muhurmuhuḥ|
'avaśeṣaṃ na paśyāmi mama sainyeṣu sañjaya||
// 8-63-2 //
軍勢の洪水が繰り返し逃走し、助けを求める叫びも虚しい中、サンジャヤよ、我が軍に残りはないと私には見える。
aho bata daśāṃ prāpto na hi śakṣyāmi jīvitum|
jayakāṅkṣī kathaṃ sūta putrāṇāmanivartinām||
// 8-63-3 //
ああ、私はこのような境遇に至った。もはや生きていくことはできまい。退かぬ息子たちの勝利を望みながら、御者よ、どうして生きていられようか。
kathaṃ jīvāmi nihatāñśrutvā ca mama sainikān|
bahunā 'dya kim uktena daivaṃ teṣāṃ parāyaṇam'||
// 8-63-4 //
我が兵士たちが殺されたと聞いて、どうして生きていられようか。多くを語っても仕方がない。彼らの運命は天に委ねられているのだ。」
māmakāḥ kimakurvanta tanmamācakṣva sañjaya||
// 8-63-5 //
「我が者たちは何をしたのだ。それを私に語れ、サンジャヤよ。」
sañjaya uvāca|
dṛṣṭvā bhīmaṃ mahābāhuṃ tava putraḥ pratāpavān|
krodharaktekṣaṇo rājan bhīmasenam abhidravat||
// 8-63-6 //
大腕のビーマを見て、おまえの息子は威勢を見せ、王よ、怒りに目を赤くしてビーマセーナに突進した。
'tiṣṭhatiṣṭha pṛthāputra paśya me 'dya parākramam|
adya tvāṃ preṣāyaṣyāmi yamasya sadanaṃ prāte|
ity uktvā prayayau karṇo yatra bhīmo vyavasthitaḥ'||
// 8-63-7 //
『止まれ、止まれ、プリターの子よ。今日の我が武勇を見よ。今日おまえをヤマの館へ送ってやる。朝のうちに。』こう言って、カルナはビーマのいる所へ向かった。
tāvakaṃ tu balaṃ dṛṣṭvā bhīmasenāt parāṅmukham|
yatnena mahatā karṇaḥ paryavasthāpayad balī||
// 8-63-8 //
しかしおまえの軍がビーマセーナから顔を背けて逃げるのを見て、カルナは大いなる努力をもって力強く軍を立て直した。
vyavasthāpya mahābāhus tava putrasya vāhinīm|
pratyudyayau tadā karṇaḥ pāṇḍavān yuddhadurmadān||
// 8-63-9 //
大腕の者がおまえの息子の軍を立て直してから、カルナは戦いに狂うパーンダヴァたちに立ち向かっていった。
pratyudyayuś ca rādheyaṃ pāṇḍavānāṃ mahārathāḥ|
dhunvānāḥ kārmukāṇy ājau vikṣipantaś ca sāyakān||
// 8-63-10 //
パーンダヴァ軍の大戦車戦士たちもラーデーヤ（カルナ）に対抗し、戦場で弓を振るい矢を放った。
bhīmasenaḥ śiner naptā śikhaṇḍī janamejayaḥ|
dhṛṣṭadyumnaś ca balavān sarve cāpi prabhadrakāḥ||
// 8-63-11 //
ビーマセーナ、シニの孫（サーティヤキ）、シカンディン、ジャナメージャヤ、力強いドリシュタデュムナ、そしてプラバドラカ族の全てが向かった。
pāñcālānāṃ naravyāghrāḥ samantāt tava vāhinīm|
abhyadravanta saṅkruddhāḥ samare jitakāśinaḥ||
// 8-63-12 //
パーンチャーラ族の人中の虎たちが、四方からおまえの軍に怒って突撃した。戦場で勝ち誇って。
tathaiva tāvakā rājan pāṇḍavānām anīkinīm|
abhyadravanta tvaritā jighāṃsanto mahārathān||
// 8-63-13 //
同様に、王よ、おまえの側の者たちもパーンダヴァ軍に急いで突撃した。大戦車戦士たちを殺さんとして。
rathanāgāśvakalilaṃ pattidhvajasamākulam|
babhūva puruṣavyāghra sainyamadbhutadarśanam||
// 8-63-14 //
人中の虎よ、戦車・象・馬が入り乱れ、歩兵と旗で満ちた軍は驚くべき光景であった。
śikhaṇḍī tu yayau karṇaṃ dhṛṣṭadyumnaḥ sutaṃ tava|
duḥśāsanaṃ mahārāja mahāsenaḥ samabhyayāt||
// 8-63-15 //
シカンディンはカルナに向かい、ドリシュタデュムナはおまえの息子ドゥフシャーサナに向かった、大王よ。マハーセーナが（ドゥフシャーサナに）向かっていった。
nakulo vṛṣasenaṃ tu citrasenaṃ yudhiṣṭhiraḥ|
ulūkaṃ samare rājan sahadevaḥ samabhyayāt||
// 8-63-16 //
ナクラはヴリシャセーナに、チトラセーナにはユディシュティラが。ウルーカには、王よ、戦場でサハデーヴァが向かった。
sātyakiḥ śakuniṃ cāpi draupadeyāś ca kauravān|
arjunaṃ ca raṇe yatto droṇaputro mahārathaḥ||
// 8-63-17 //
サーティヤキはシャクニに、ドラウパディーの子たちはカウラヴァたちに向かった。そして戦場で身構えたドローナの子の大戦車戦士がアルジュナに向かった。
yudhāmanyuṃ maheṣvāsaṃ gautamo 'bhyapatad raṇe|
kṛtavarmā ca balavānuttamaujasamādravat||
// 8-63-18 //
大弓のユダーマンユにはガウタマ（クリパ）が戦場で向かい、力強いクリタヴァルマンはウッタマウジャスに突進した。
bhīmasenaḥ kurūn sarvānputrāṃś ca tava māriṣa|
sahānīkān mahābāhur eka eva nyavārayat||
// 8-63-19 //
大腕のビーマセーナは、クル族の全てとおまえの息子たちを、軍勢ごと一人で阻み止めた。
śikhaṇḍī tu tataḥ karṇaṃ vicarantam abhītavat|
bhīṣmahantā mahārāja vārayāmāsa patribhiḥ||
// 8-63-20 //
大王よ、ビーシュマを殺した者シカンディンは、恐れなく動き回るカルナを矢で阻んだ。
pratiruddhas tataḥ karṇo ropāt prasphuritādharaḥ|
śikhaṇḍinaṃ tribhir bāṇairbhruvor madhye 'bhyatāḍayat||
// 8-63-21 //
阻まれたカルナは怒りに唇を震わせ、シカンディンの眉間を三本の矢で射抜いた。
dhārayaṃstu sa tān vāṇāñ śikhaṇḍī bahvaśobhata|
rājataḥ parvato yadvattribhiḥ śṛṅgaiḥ samanvitaḥ||
// 8-63-22 //
シカンディンはそれらの矢を受け止めて大いに輝いた。三つの峰を持つ銀の山のように。
so 'tividdho maheṣvāsaḥ sūtaputreṇa saṃyuge|
karṇaṃ vivyādha samare navatyā niśitaiḥ śaraiḥ||
// 8-63-23 //
大弓の戦士シカンディンは戦場でスータの子に深く射られたが、戦場でカルナを九十本の鋭い矢で射返した。
tasya karṇo hayānhatvā sārathiṃ ca śaraiḥ|
unmamātha dhvajaṃ cāsya kṣurapreṇa mahārathaḥ||
// 8-63-24 //
カルナはその馬を殺し、御者をも矢で倒し、大戦車戦士は剃刀の矢で旗を切り落とした。
hatāśvāt tu tato yānād avaplutya mahārathaḥ|
śaktiṃ cikṣepa karṇāya saṅkruddhaḥ śatrutāpanaḥ||
// 8-63-25 //
馬を殺された戦車から飛び降りた大戦車戦士シカンディンは、敵を苦しめる者として怒りにまかせ、カルナに向かって槍を投げつけた。
tāṃ chittvā samare karṇas tribhir bhārata sāyakaiḥ|
śikhaṇḍinam atha avidhyann navabhir niśitaiḥ śaraiḥ||
// 8-63-26 //
カルナはその槍を戦場で三本の矢で切り裂き、バーラタよ、シカンディンをさらに九本の鋭い矢で射抜いた。
karṇacāpacyutān bāṇān varjayaṃs tu narottamaḥ|
apayātas tatas tūrṇaṃ śikhaṇḍī bhṛśavikṣataḥ||
// 8-63-27 //
カルナの弓から放たれる矢を避けながら、人中の最高者シカンディンは深く傷つき、速やかに退却した。
tataḥ karṇo mahārāja pāṇḍusainyāny aśātayat|
tūlarāśiṃ samāsādya yathā vāyur mahābalaḥ||
// 8-63-28 //
大王よ、そこでカルナはパーンドゥの軍を打ち散らした。大力の風が綿の山に吹きつけるように。
dhṛṣṭadyumno mahārāja tava putreṇa pīḍitaḥ|
duḥśāsanaṃ tribhir bāṇaiḥ pratyavidhyat stanāntare||
// 8-63-29 //
大王よ、ドリシュタデュムナはおまえの息子に苦しめられながらも、ドゥフシャーサナの胸を三本の矢で射返した。
tasya duḥśāsano bāhuṃ savyaṃ vivyādha māriṣa|
sa tena rukmapuṅkhena bhallena nataparvaṇā||
// 8-63-30 //
ドゥフシャーサナは曲がった節の黄金の羽の矢で、ドリシュタデュムナの左腕を射抜いた。
dhṛṣṭadyumnas tu nirviddhaḥ śaraṃ ghoram amarṣaṇaḥ|
duḥśāsanāya saṅkruddhaḥ preṣayāmāsa bhārata||
// 8-63-31 //
射抜かれたドリシュタデュムナは怒り、恐ろしい矢をドゥフシャーサナに向けて放った、バーラタよ。
āpatantaṃ mahāvegaṃ dhṛṣṭadyumnasamīritam|
śaraiś ciccheda putraste tribhir eva viśāmpate||
// 8-63-32 //
飛来する猛速のドリシュタデュムナの矢を、国の主よ、おまえの息子は三本の矢で切り落とした。
athāparaiḥ ṣoḍaśabhir bhallaiḥ kanakabhūṣaṇaiḥ|
dhṛṣṭadyumnaṃ samāsādya bāhvor urasi cārpayat||
// 8-63-33 //
さらに十六本の黄金で飾られた矢で、ドリシュタデュムナに近づいて両腕と胸を射抜いた。
tataḥ sa pārṣataḥ kruddho dhanuś ciccheda māriṣa|
kṣurapreṇa sutīkṣṇena tata uccukruśur janāḥ||
// 8-63-34 //
すると怒ったパールシャタ（ドリシュタデュムナ）は、極めて鋭い剃刀の矢で敵の弓を切断した。人々は歓声を上げた。
athānyad dhanur ādāya putras te prahasan iva|
dhṛṣṭadyumnaṃ śaravrātaiḥ samantāt paryavārayat||
// 8-63-35 //
おまえの息子は別の弓を取り、笑うかのように、ドリシュタデュムナを矢の群れで四方から取り囲んだ。
tava putrasya te dṛṣṭvā vikramaṃ sumahātmanaḥ|
vyasmayanta raṇe yodhāḥ siddhāś cāpsarasas tathā||
// 8-63-36 //
偉大なるおまえの息子のこの武勇を見て、戦場の戦士たちとシッダたちやアプサラスたちは驚嘆した。
dhṛṣṭadyumnaṃ tu paśyāma ghaṭamānaṃ mahābalam|
duḥśāsanena saṃruddhaṃ siṃhena iva mahāgajam||
// 8-63-37 //
大力のドリシュタデュムナが奮戦しながらもドゥフシャーサナに阻まれている姿を見よう。獅子に阻まれた大象のように。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe trisaṣṭitamo'dhyāyaḥ|| 63 ||
マハーバーラタ・カルナ篇・第十七日戦闘における第63章終わり。
