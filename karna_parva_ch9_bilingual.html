マハーバーラタ ― カルナ篇 第9章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 9 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ9」（入り乱れの戦い・ビーマがクシェーマドゥールティを殺す章。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-9-N）と和訳の段落番号が対応しています。
karṇaparva — navamo'dhyāyaḥ (9)
第9章　入り乱れの戦い・ビーマがクシェーマドゥールティを殺す
sañjaya uvāca|
te sene'nyonyamāsādya prahṛṣṭāśvanaradvipe|
bṛhatyau samprajahāte devāsuracamūsame|| // 8-9-1 //
サンジャヤは語った。 （1）勇者にして喜ぶ馬と人と象で満ちた二つの軍は、神々と阿修羅の軍のように激突しました。
tato nānārathāśvebhāḥ pattayaścogravikramāḥ|
samprahārān bhṛśaṃ cakrur dehapāpmavināśanān|| // 8-9-2 //
（2）さまざまな戦車・馬・象と勇猛な歩兵たちが、体の罪を滅ぼす激しい戦いを繰り広げました。
pūrṇacandrārkapadmānāṃ kāntitviṅgandhataḥ samaiḥ|
uttamāṅgair nṛsiṃhānāṃ nṛsiṃhās tastarur mahīm|| // 8-9-3 //
（3）満月や太陽や蓮のような美しさと輝きと香りを持つ、人の中の獅子たちの首で、人の中の獅子たちは大地を覆いました。
ardhacandrais tathā bhallaiḥ kṣuraprairasipaṭṭasaiḥ|
paraśvathaiścāpahṛtānyuttamāṅgāni yudhyatām|| // 8-9-4 //
（4）半月矢、バッラ矢、クシュラプラ矢、剣、パッタサ、パラシュヴァタ（斧）で、戦う者たちの首が切り落とされました。
vyāyatāyatabāhūnāṃ vyāyatāyatabāhubhiḥ|
vāhavaḥ pātitā rejurdharaṇyāṃ sāyudhāṅgadaiḥ|| // 8-9-5 //
（5）鍛えられた長い腕を持つ者たちの腕が、鍛えられた長い腕の者たちによって、武器と腕輪をつけたまま、大地に打ち落とされて輝いていました。
taiḥ sphuradbhir mahī bhāti raktāṅgulitalais tathā|
garuḍaprahitairugraiḥ pañcāsyairuragairiva|| // 8-9-6 //
（6）それらの腕は、赤い指先を震わせながら大地で輝いた。ガルダ（神鳥）に放たれた恐ろしい五つの頭を持つ蛇たちのように。
dviradasyandanāśvebhyaḥ peturvīrā dviṣaddhatāḥ|
vimānebhyo yathā kṣīṇe puṇye svargadastathā|| // 8-9-7 //
（7）象・戦車・馬から勇者たちが、敵に倒されて落ちた。天上の乗り物から功徳が尽きた天界の住人が落ちるように。
gadābhiranye gurvībhiḥ paridhairmusalairapi|
pothitāḥ śataśaḥ peturvīrā vīratarai raṇe|| // 8-9-8 //
（8）重い棍棒、パリガ（鉄棒）、ムサラ（杵）で、他の勇者たちが数百単位で、戦いでさらに勇猛な者に打ち倒されました。
rathā rathair vimathitā mattā mattairdvipā dvipaiḥ|
sādinaḥ sādibhiścaiva tasmin paramasaṅkule|| // 8-9-9 //
（9）戦車は戦車に砕かれ、酔った象は酔った象に、騎兵は騎兵に——その極めて混乱した戦いの中で。
rathairnarā rathā nāgair aśvārohāśca pattibhiḥ|
aśvārohaiḥ padātāśca nihatā yudhi śerate|| // 8-9-10 //
（10）人は戦車に、戦車は象に、騎兵は歩兵に、騎兵が歩兵に殺されて横たわりました。
rathāśvapattayo nāgai rathāśvebhāśca pattibhiḥ|
rathapattidvipāścāścai rathaiścāpi naradvipāḥ||
rathāśvebhanarāṇāṃ tu narāśvebharathaiḥ kṛtam|
pāṇipādaiśca śastraiśca rathaiśca kadanaṃ mahat|| // 8-9-11-12 //
（11〜12）戦車・馬・歩兵は象に、戦車・馬・象は歩兵に、戦車・歩兵・象は馬に、戦車が人と象を——戦車・馬・象・人の者たちが、人・馬・象・戦車によって、手・足・武器・戦車をもって大いなる殺戮を行いました。
tathā tasminbale śūrair vadhyamāne hate'pi ca|
asmān abhyāyayuḥ pārthā vṛkodarapurogamāḥ|| // 8-9-13 //
（13）そのようにして軍が勇者たちに殺され、打たれる中、パールタたちがヴリコーダラ（ビーマ）を先頭にして我々に向かってきました。
vṛṣṭadyumnaḥ śikhaṇḍī ca draupadeyāḥ prabhadrakāḥ|
sātyakiścekitānaśca drāviḍaiḥ sainikaiḥ saha|| // 8-9-14 //
（14）ドリシュタデュムナ、シカンディン、ドラウパディーの息子たち、プラバドラカ族、サーティヤキ、チェーキターナが、ドラーヴィダの兵士たちとともに。
vṛtā vyūhena mahatā pāṇḍyāścolāḥ sakeralāḥ|
vyūḍhoraskā dīrghabhujāḥ prāṃśavaḥ pṛthulocanāḥ||
āpīḍino raktadantā mattamātaṅgavikramāḥ|
nānāvirāgavasānā gandhacūrṇāvacūrṇitāḥ|| // 8-9-15-16 //
（15〜16）偉大な陣形に囲まれて、パーンディヤ、チョーラ、ケーラ族が——広い胸、長い腕、背の高い、大きな目の者たちが——髪飾りをつけ、赤い歯で、酔った象のような勇猛さで、さまざまな色の衣をまとい、香料の粉をふりかけて。
baddhāsayaḥ pāśahastā vāraṇaprativāraṇāḥ|
samānamṛtyavo rājan nātyajanta parasparam|| // 8-9-17 //
（17）剣を帯び、縄を手に持ち、象を象で迎え撃つ者として——王よ、死を等しく分かち合う者として、互いを見捨てなかった。
kalāpinaścāpahastā dīrghakeśāḥ priyaṃvadāḥ|
pattayaḥ sāyakairviddhā ghorarūpaparākramāḥ|| // 8-9-18 //
（18）弓を手にし、矢筒をつけた長い髪の美しい言葉の歩兵たちが、矢に射抜かれて恐ろしい姿と武勇を見せました。
athāpare punaḥ śūrāścedipāñcālakekayāḥ|
kārūśāḥ kosalāḥ kāñcyā māgadhāścāpi dudruvuḥ|| // 8-9-19 //
（19）また別の勇者たちが——チェーディ、パーンチャーラ、ケーカヤ、カールーシャ、コーサラ、カーシー、マガダも走り出しました。
teṣāṃ rathāśvanāgāśca pravarāścograpattayaḥ|
nānābāṇaravairhṛṣṭā nṛtyanti ca hasanti ca|| // 8-9-20 //
（20）彼らの戦車・馬・象と精鋭の勇猛な歩兵たちは、さまざまな矢の音に喜び、踊り、笑っていました。
tasya sainyasya mahato mahāmātravarair vṛtaḥ|
madhye vṛkodaro'bhyāyāt tvadīyān nāgadhūrgataḥ|| // 8-9-21 //
（21）その偉大な軍の中、大将たちに囲まれて、ヴリコーダラ（ビーマ）は象の背に乗って、おまえの軍に向かいました。
sa nāgapravaro'tyugro vidhivat kalpito babhau|
udayāgrādribhavanaṃ yathā'bhyuditabhāskaram|| // 8-9-22 //
（22）その最上の象は極めて勇猛で、しかるべく装備されて輝いていた。日の出の山の頂に昇った太陽のように。
tasyāyasaṃ varmavaraṃ vararatnavibhūṣitam|
tārāvyāptasya nabhasaḥ śāradasya samaṃ tviṣā|| // 8-9-23 //
（23）その者の鉄の甲冑は最上の宝石で飾られ、秋の空の星に覆われた天空のような輝きであった。
sa tomaravyagrakaraścārumauliḥ svalaṅkṛtaḥ|
śaranmadhyandinārkābhastejayā pradāhadripūn|| // 8-9-24 //
（24）投げ槍を手に持ち、美しい冠で飾られたその者は、秋の正午の太陽のような輝きで、熱で敵を焼きました。
taṃ dṛṣṭvā dviradaṃ dūrāt kṣemadhūrtir dvipasthita|
āhvayan abhidudrāva prahasan pṛtanāmukhe|| // 8-9-25 //
（25）その象を遠くから見て、象に乗ったクシェーマドゥールティは、呼びかけながら突進し、軍の先頭で笑いながら。
tayoḥ samabhavad yuddhaṃ dvipayorugrarūpayoḥ|
yadṛcchayā drutavatormahāparvatayoriva|| // 8-9-26 //
（26）二頭の恐ろしい姿の象の間に戦いが起こった。偶然衝突した速い大山のように。
saṃsaktanāgau tau vīrau tomarairitaretaram|
balavatsūryaraśmyābhairbhittvā'nyonyaṃ vinedatuḥ|| // 8-9-27 //
（27）象を組み合わせた二人の勇者は、太陽の光線のようなトマラ（投槍）で互いを突き破り、叫び声を上げました。
vyapasṛtya tu nāgābhyāṃ maṇḍalāni viceratuḥ|
pragṛhya cobhau dhanuṣī jaghnaturvai parasparam|| // 8-9-28 //
（28）象から離れて旋回し、二人とも弓を取って互いに射合いました。
kṣveḍitāsphoṭitaravairbāṇaśabdaistu sarvataḥ|
tau janaṃ harṣayantau ca siṃhanādaṃ pracakratuḥ|| // 8-9-29 //
（29）叫び声と手を叩く音、弓の音が四方から響く中、二人は人々を喜ばせながら獅子の咆哮を上げました。
samudyatakarābhyāṃ tau dvipābhyāṃ kṛtināvubhau|
vātodvūtapatākābhyāṃ yuyudhāte mahābalau||
tāvanyonyasya dhanuṣī chittvā'nyonyaṃ vinedatuḥ|
śaktitomaravarṣeṇa prāvṛṇmeghāvivāmbubhiḥ|| // 8-9-30-31 //
（30〜31）象の上で手を振り上げた二人の強者は、風になびく旗を掲げた象の上で戦いました。互いの弓を切り合い叫び声を上げ、シャクティ槍とトマラ投槍の雨を降らせた。雨季の雲が水を降らすように。
kṣemadhūrtis tadā bhīmaṃ tomareṇa stanāntare|
nirbibhedātivegena ṣaḍbhiścāpyaparairnadan||
sa bhīmasenaḥ śuśubhe tomarair aṅgamāśritaiḥ|
krodhadīptavapurmedhaiḥ saptasaptirivāṃśamān|| // 8-9-32-33 //
（32〜33）クシェーマドゥールティはビーマの胸をトマラで大いなる勢いで突き破り、さらに六本の別の投槍で打ちながら叫びました。ビーマセーナはトマラが体に刺さって輝いた。怒りに燃える姿で、雲に覆われた太陽が光線を放つように。
tato bhāskaravarṇābhamañcogatimayasmāyam|
sasarja tomaraṃ bhīmaḥ pratyamitrāya yatnavān|| // 8-9-34 //
（34）太陽色に輝く、まっすぐに飛ぶ鉄のトマラを、ビーマは全力をもって敵に投げつけました。
tataḥ karūśādhipatiścāpamānamya sāyakaiḥ|
daśabhistomaraṃ bhittvā ṣaṣṭyā vivyādha pāṇḍavam|| // 8-9-35 //
（35）カルーシャの王は弓をしならせ、十本の矢でトマラを砕き、六十本でパーンダヴァを射ました。
atha kārmukamādāya bhīmo jaladaniḥ svanam|
ripor abhyardayan nāgam unnadan pāṇḍavāḥ śaraiḥ|| // 8-9-36 //
（36）ビーマは雷のような響きの弓を取り、敵の象を矢で苦しめながらパーンダヴァとして叫びました。
sa śaraughārdito nāgo bhīmasenena saṃyuge|
gṛhyamāṇo'pi nātiṣṭhad vātoddhūta ivāmbudaḥ|| // 8-9-37 //
（37）矢の群れに苦しめられたその象は、ビーマセーナの合戦で、クシェーマドゥールティに制止されてもとどまらなかった。風に吹き飛ばされる雲のように。
tam abhyadhāvad dviradaṃ bhīmo bhīmasya nāgarāṭ|
mahāvāteritaṃ meghaṃ vātoddhūta ivāmbudaḥ|| // 8-9-38 //
（38）ビーマの恐るべき象がその象に突進しました。大風に吹かれた雲が、風に吹かれた雲に向かうように。
sannivāryātmano nāgaṃ kṣemadhūrtiḥ pratāpavān|
vivyādhābhidrutaṃ bāṇair bhīmasenasya kuñjaram|| // 8-9-39 //
（39）自分の象を押しとどめた勇猛なクシェーマドゥールティは、突進するビーマセーナの象を矢で射りました。
tataḥ sādhuvisṛṣṭena kṣureṇānataparvaṇā|
chittvā śarāsanaṃ śatrornāgaṃ cāpi pramārdayat|| // 8-9-40 //
（40）よく放たれたしなやかな刃の矢で敵の弓を切り、象をも痛めつけました。
tataḥ kruddho raṇe bhīmaṃ kṣemadhūrtiḥ parābhinat|
jaghāna cāsya dviradaṃ nārācaiḥ sarvamarmasu|| // 8-9-41 //
（41）怒ったクシェーマドゥールティはビーマを矢で射返し、ナーラーチャ（鉄の矢）であらゆる急所を射ってビーマの象をも倒しました。
sa papāta mahānāgo bhīmasenasya bhārata|
purā nāgasya patanād avaplutya sthito mahīm|| // 8-9-42 //
（42）バーラタよ、ビーマセーナの偉大な象が倒れました。象が倒れる前に飛び降りて、ビーマは大地に立ちました。
bhīmaseno'pi tannāgaṃ gadayā samapothayat|
tasmāt pramathitān nāgāt kṣemadhūrtir avaplutaḥ|| // 8-9-43 //
（43）ビーマセーナは棍棒でその象を打ち倒しました。打ち潰された象から、クシェーマドゥールティは飛び降りました。
'uddhṛtya svaṅgaṃ niśitam abhyadhāvat sa pāṇḍavam'|
udyatāyudhamāyāntaṃ sadayā'han vṛkodaraḥ|| // 8-9-44 //
（44）抜き身の剣を引き抜いてパーンダヴァに突進してきたが、武器を振り上げて迫るその者を、ヴリコーダラ（ビーマ）は棍棒で打ち倒しました。
sa papāta hataḥ sāsir vyasus tam abhito dvipam|
vajraprabhagnamacalaṃ siṃho vajrahato yathā|| // 8-9-45 //
（45）剣を持ったまま打ち倒されたあの者は、倒れた象の傍に命なく崩れました。金剛杵に砕かれた山のように、金剛杵に打たれた獅子のように。
taṃ hataṃ nṛpatiṃ dṛṣṭvā karūśānāṃ yaśaskaram|
prādrāvad vyathitā senā tvadīyā bharatarṣabha|| || // 8-9-46 //
（46）カルーシャの名声ある王が殺されたのを見て、バーラタの雄牛よ、おまえの軍は苦しみに動揺して逃げ出しました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe navamo'dhyāyaḥ|| 9 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第九章は終わる。
