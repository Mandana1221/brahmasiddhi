マハーバーラタ ― カルナ篇 第2章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 2 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ2」（ジャナメージャヤがドリタラーシュトラの反応を尋ね、サンジャヤが第十六日の戦死者の名を列挙する章）です。各段落は原典の詩節番号（8-2-N）と和訳の段落番号が対応しています。
karṇaparva — dvitīyo'dhyāyaḥ (2)
カルナ篇 ― 第2章　ドリタラーシュトラが自軍の戦死者の名を聞く
'janamejaya uvāca| tacchrutvā karṇahananaṃ putrāṃś caiva palāyitān| dhṛtarāṣṭro nṛpaścaiva dvijaśreṣṭha kim abravīt|| / prāptavān vyasanaṃ ghoraṃ putravyasanajaṃ mahat| kāle yad uktavāṃs tasmiṃs tan mamācakṣva tattvataḥ'|| // 8-2-1-2 //
ジャナメージャヤは語った。
（1〜2）「カルナの殺害と息子たちの敗走を聞いて、バラモンの最上者よ、ドリタラーシュトラ王は、息子の災厄から生じた恐ろしく大きな苦難に達したが、その時何と言いましたか。真実を語ってください。」
vaiśampāyana uvāca| etacchrutvā mahārāja dhṛtarāṣṭro'mbikāsutaḥ| abravīt sañjayaṃ sūtaṃ śokasaṃvignamānasaḥ|| // 8-2-3 //
ヴァイシャンパーヤナは語った。
（3）大王よ、これを聞いたアンビカーの子ドリタラーシュトラは、悲しみに心を乱しながら御者サンジャヤに語りました。
duṣpraṇītena me tāta putrasyādīrghajīvinaḥ| hataṃ vaikartanaṃ śrutvā śoko marmāṇi kṛntati|| // 8-2-4 //
（4）「友よ、長命ならざる我が息子の愚策によって、ヴァイカルタナ（カルナ）が殺されたと聞いて、悲しみが急所を引き裂く。
tasya me saṃśayaṃ chindhi duḥkhapāraṃ titīrṣataḥ| kurūṇāṃ sṛñjayānāṃ ca ke jīvanti ke mṛtāḥ|| // 8-2-5 //
（5）苦しみの彼岸に渡ろうとする私の疑いを断ち切ってくれ。クル族とスリンジャヤ族のうち、誰が生き、誰が死んだのか。」
sañjaya uvāca| hataḥ śāntanavo rājan durādharṣaḥ pratāpavān| hatvā pāṇḍavayodhānāmarbudaṃ daśabhir dinaiḥ|| // 8-2-6 //
サンジャヤは語った。
（6）「王よ、シャーンタナヴァ（ビーシュマ）は殺されました。威厳ある近づき難い者は、十日間でパーンダヴァの戦士一億を殺した後に。
tathā droṇo maheṣvāsaḥ pāñcālānāṃ rathavrajān| nihatya yudhi durdharṣaḥ pañcād rukmaratho hataḥ|| // 8-2-7 //
（7）同様に偉大な弓兵ドローナは、パーンチャーラ族の戦車群を打ち倒した後、金の戦車を持つ近づき難き者は五日目に殺されました。
hataśeṣasya bhīṣmeṇa droṇena ca mahātmanā| ardhaṃ nihatya sainyasya karṇo vaikartano hataḥ|| // 8-2-8 //
（8）ビーシュマとドローナという偉大なる魂に殺し残された軍の半分を殺した後に、ヴァイカルタナ・カルナは殺されました。
viviṃśatir mahārāja rājaputro mahābalaḥ| ānartayodhāñ śataśo nihatya nihato raṇe|| // 8-2-9 //
（9）大王よ、大力の王子ヴィヴィンシャティは、アーナルタの戦士たちを何百と殺した後に、戦場で殺されました。
tathā putro vikarṇaste kṣatravratamanusmaran| kṣīṇabāṇo hataḥ śūraḥ sthito hyabhimukhaḥ paraiḥ|| // 8-2-10 //
（10）あなたの息子ヴィカルナもまた、クシャトリヤの戒律を思い出しながら、矢が尽きても敵に向かって立ち続け、勇者として殺されました。
dhorarūpān parikleśān duryodhanakṛtān bahūn| pratijñāṃ smaratā tena bhīmasenena pātitaḥ|| // 8-2-11 //
（11）ドゥルヨーダナが行った恐ろしく残酷な数々の迫害を思い出し、自らの誓いを胸に、ビーマセーナに倒されました。
vindānuvindāvāvantyau rājaputrau mahārathau| kṛtvā svasukaraṃ karma gatau vaivasvatakṣayam|| // 8-2-12 //
（12）アーヴァンティのヴィンダとアヌヴィンダ——偉大な戦車戦士の二人の王子は、困難な業をなし遂げて閻魔の世界へ去りました。
sindhurāṣṭramukhānīha daśa rāṣṭrāṇi yāniha| yasya tiṣṭhanti vacane yaḥ sthitas tava śāsane|| / akṣauhiṇīr daśaikāṃ ca vinirjitya śitaiḥ śaraiḥ| so'rjunena hato rājan mahāvīryo jayadrathaḥ|| // 8-2-13-14 //
（13〜14）シンドゥ国を筆頭とする十の国がその命に従い、あなたの支配下にあった者——十一のアクシャウヒニー軍を鋭い矢で打ち負かした、大いなる武勇のジャヤドラタは、王よ、アルジュナに殺されました。
tathā duryodhanasutas tarasvī yuddhadurmadaḥ| vartamānaḥ pituḥ śāstre saubhadreṇa nipātitaḥ|| // 8-2-15 //
（15）勇猛にして戦闘に酔いしれたドゥルヨーダナの息子も、父の教えに従いながら、スバドラーの子（アビマニュ）に倒されました。
tathā dauḥśāsaniḥ sūro bāhuśālī raṇotkaṭaḥ| draupadeyena saṅgamya gamito yamasādanam|| // 8-2-16 //
（16）ドゥフシャーサナの息子もまた、勇敢にして腕力があり戦場で勇猛な者として、ドラウパディーの子と出会って閻魔の館に送られました。
kirātānāmadhipatiḥ sāgarānūpavāsinām| devarājasya dharmātmā priyo bahumataḥ sakhā|| / bhagadatto mahīpālaḥ kṣatradharmarataḥ sadā| dhanañjayena vikramya gamito yamasādanam|| // 8-2-17-18 //
（17〜18）海辺に住む山岳民キラータ族の王、インドラの徳ある愛する友バガダッタは、クシャトリヤの法に常に喜ぶ王として、ダナンジャヤに力をもって閻魔の館に送られました。
tathā kauravadāyādo nyastaśastro mahāyaśāḥ| hato bhūriśravā rājañ śūraḥ sātyakinā yudhi|| // 8-2-19 //
（19）カウラヴァの一族であり、大いなる名声を持ち、武器を置いた勇者ブーリシュラヴァスは、王よ、戦場でサーティヤキに殺されました。
śrutāyurapi cāmbaṣṭhaḥ kṣatriyāṇāṃ dhurandharaḥ| carann abhītavat saṅkhye nihataḥ savyasācinā|| // 8-2-20 //
（20）アンバシュタのシュルターユスもまた、クシャトリヤの先頭に立つ者として、恐れることなく戦場を駆け巡り、左右の手で射る者（アルジュナ）に殺されました。
tava putraḥ sadāmarṣī kṛtāstro yuddhadurmadaḥ| duḥśāsano mahārāja bhīmasenena pātitaḥ|| // 8-2-21 //
（21）大王よ、常に怒りに満ち、武器に精通し、戦闘に酔いしれたあなたの息子ドゥフシャーサナは、ビーマセーナに倒されました。
yasya rājan gajānīkaṃ bahusāhasramadbhutam| sudakṣiṇaḥ sa saṅgrāme nihataḥ savyasācinā|| // 8-2-22 //
（22）王よ、驚くべき何千もの象の軍を持っていたスダクシナは、戦場で左右の手で射る者に殺されました。
kosalānāmadhipatir hatvā bahumatānparān| saubhadreṇeha vikramya gamito yamasādanam|| // 8-2-23 //
（23）コーサラの王は多くの敵を殺した後、スバドラーの子に力をもって閻魔の館に送られました。
bahuśo yodhayitvā tu bhīmasenaṃ mahāratham| citrasenas tava suto bhīmasenena pātitaḥ|| // 8-2-24 //
（24）偉大な戦車戦士ビーマセーナと何度も戦ったあなたの息子チトラセーナは、ビーマセーナに倒されました。
madrarājātmajaḥ śūraḥ pareṣāṃ bhayavardhanaḥ| asicarmadharaḥ śrīmān saubhadreṇa nipātitaḥ|| // 8-2-25 //
（25）マドラ王の勇敢な息子、敵の恐怖を増す者は、剣と盾を持ちながら、栄光あるスバドラーの子に倒されました。
samaḥ karṇasya samare yaḥ sa karṇasya paśyataḥ| vṛṣaseno mahātejāḥ śīghrāstro dṛḍhavikramaḥ|| / abhimanyor vadhaṃ smṛtvā pratijñāmapi cātmanaḥ| dhanañjayena vikramya gamito yamasādanam|| // 8-2-26-27 //
（26〜27）戦場でカルナに等しく、カルナの見守る前で——大いなる威光を持ち、素早い武器と堅い武勇を持つヴリシャセーナは、アビマニュの殺害を思い出し、自らの誓いをも胸に、ダナンジャヤに力をもって閻魔の館に送られました。
nityaṃ prasaktavairo yaḥ pāṇḍavaiḥ pṛthivīpatiḥ| viśrāvya vairaṃ pārthena śrutāyuḥ sa nipātitaḥ|| // 8-2-28 //
（28）常にパーンダヴァに対して敵意を持っていた王シュルターユスは、パールタ（アルジュナ）に敵意を宣言した後に倒されました。
śalyaputrastu vikrāntaḥ sahadevena māriṣa| hato rukmaratho rājañ śyālo mātulajo yudhi|| // 8-2-29 //
（29）シャリヤの息子にして勇猛なルクマラタは、サハデーヴァに殺されました、王よ。母方の甥であり叔父の子として戦場で。
rājā bhāgīratho vṛddho bṛhatkṣatraś ca kekayaḥ| parākramantau vikrāntau nihatau vīryavattarau|| // 8-2-30 //
（30）老いた王バーギーラタと、ケーカヤのブリハットクシャトラは、共に勇猛にして武勇のさらに勝る二人として、奮戦しながら殺されました。
bhagadattasuto rājan kṛtaprajño maṃhābalaḥ| śyenavaccaratā saṅkhye nakulena nipātitaḥ|| // 8-2-31 //
（31）王よ、バガダッタの息子——大力にして叡智ある者は、鷹のように戦場を駆け巡るナクラに倒されました。
pitāmahastava tathā bāhlīkaḥ saha bāhlikaiḥ| nihato bhīmasenena mahābālaparākramaḥ|| // 8-2-32 //
（32）あなたの祖父バーフリーカもまた、バーフリーカ族とともに、大いなる力と武勇を持つ者として、ビーマセーナに殺されました。
jayatsenas tathā rājañ jārāsandhir mahābalaḥ| māgadho nihataḥ saṅkhye saubhadreṇa mahātmanā|| // 8-2-33 //
（33）王よ、マガダの大力のジャヤツセーナ（ジャラーサンダの子）もまた、偉大なる魂のスバドラーの子に戦場で殺されました。
putras te durmukho rājan duḥsahaś ca mahārathaḥ| gadayā bhīmasenena nihatau śūramāninau|| // 8-2-34 //
（34）王よ、あなたの息子ドゥルムカとドゥフサハもまた偉大な戦車戦士として、勇者の誇りを持ちながら、ビーマセーナの棍棒で殺されました。
durmarṣaṇo durviṣaho durjayaśca mahārathaḥ| kṛtvā tvasukaraṃ karma gatā vaivasvatakṣayam|| // 8-2-35 //
（35）ドゥルマルシャナ、ドゥルヴィシャハ、ドゥルジャヤという偉大な戦車戦士は、困難な業をなし遂げて閻魔の世界に去りました。
ubhau kaliṅgavṛṣakau bhrātarau yuddhadurmadau| kṛtvā cāsukaraṃ karma gatau vaivasvatakṣayam|| // 8-2-36 //
（36）カリンガとヴリシャカの兄弟二人も、戦闘に酔いしれた者として、困難な業をなし遂げて閻魔の世界に去りました。
sacivo vṛṣaparvā te śūraḥ paramavīryavān| bhīmasenena vikramya gamito yamasādanam|| // 8-2-37 //
（37）あなたの参謀ヴリシャパルヴァンもまた勇者にして最上の武勇を持つ者として、ビーマセーナに力をもって閻魔の館に送られました。
tathaiva pauravo rājā nāgāyutabalo mahān| samare pāṇḍuputreṇa nihataḥ savyasācinā|| // 8-2-38 //
（38）同様に、万頭の象の力を持つ大いなるパウラヴァ王も、パーンドゥの子、左右の手で射る者に戦場で殺されました。
vasātayo mahārāja dvisāhasrāḥ prahāriṇaḥ| śūrasenāśca vikrāntāḥ sarve yudhi nipātitāḥ|| // 8-2-39 //
（39）大王よ、二千のヴァサーティ族の戦士たち、そして勇猛なるシューラセーナ族もすべて戦場で倒されました。
abhīṣāhāḥ kavacinaḥ praharanto raṇotkaṭāḥ| śibayaś ca rathodārāḥ kāliṅgasahitā hatāḥ|| // 8-2-40 //
（40）鎧を着た猛きアビーシャーハ族、戦場で奮戦するシビ族も、カーリンガ族とともに殺されました。
gokule nityasaṃvṛddhā yuddhe paramakopanāḥ| gopālāḥ kṛtavīrāste nihatāḥ savyasācinā|| // 8-2-41 //
（41）牧場で常に育ち、戦場で極めて怒りっぽいゴーパーラ族の勇者たちは、左右の手で射る者に殺されました。
śreṇayo bahusāhasrāḥ saṃśaptakagaṇāś ca ye| te sarve pārthamāsādya gadā vaivasvatakṣayam|| // 8-2-42 //
（42）何千ものシュレーニ族の軍とサンシャプタカ族の群れ——彼らはすべてパールタ（アルジュナ）のもとに至り、閻魔の世界に去りました。
śyālau tava mahārāja rājānau vṛṣakācalau| tvadarthamativikrāntau nihatau savyasācinā|| // 8-2-43 //
（43）大王よ、あなたの二人の義兄弟ヴリシャカとアチャラは、あなたのために極めて勇猛に戦い、左右の手で射る者に殺されました。
ugrakarmā maheṣvāso nāmataḥ karmatastathā| sālvarājo mahābāhur bhīmasenena pātitaḥ|| // 8-2-44 //
（44）名のとおり恐るべき業を持つ偉大な弓兵サールヴァ王は、大いなる腕を持つ者として、ビーマセーナに倒されました。
oghavāṃś ca mahārāja bṛhantaḥ sahitau raṇe| parākramantau mitrārthe gatau vaivasvatakṣayam|| // 8-2-45 //
（45）大王よ、オーガヴァーンとブリハンタは共に戦場で、友のために奮戦して閻魔の世界に去りました。
tathaiva rathināṃ śreṣṭhaḥ kṣemadhūrtir viśāmpate| nihato gadayā rājan bhīmasenena saṃyuge|| // 8-2-46 //
（46）王よ、戦車兵の中の最上者クシェーマドゥールティもまた、ビーマセーナの棍棒で戦場において殺されました。
tathā rājan maheṣvāso jalasandhau mahābalaḥ| sumahatkadanaṃ kṛtvā hataḥ sātyakinā raṇe|| // 8-2-47 //
（47）王よ、偉大な弓兵にして大力のジャラサンダは、大殺戮を行った後、サーティヤキに戦場で殺されました。
alambuso rākṣasendraḥ kharabandhurayānavān| ghaṭotkacena vikramya gamito yamasādanam|| // 8-2-48 //
（48）羅刹の王アランブサは、驢馬に引かれた戦車を持つ者として、ガトートカチャに力をもって閻魔の館に送られました。
rādheyaḥ sūtaputraś ca bhrātaraś ca mahārathāḥ| kekayāḥ sarvaśaś cāpi nihatāḥ svyasācinā|| // 8-2-49 //
（49）ラーデーヤ（カルナ）の御者の子の兄弟たち、偉大な戦車戦士たちも、すべてのケーカヤ族も、左右の手で射る者に殺されました。
mālavā madrakāścaiva drāviḍāś cograkarmiṇaḥ| yaudheyāśca lalitthāśca kṣudrakāś cāpy uśīnarāḥ|| / māvellakāstuṇḍikerāḥ sāvitrīputrakāśca ye| prācyodīcyāḥ pratīcyāśca dākṣiṇātyāśca māriṣa|| // 8-2-50-51 //
（50〜51）マーラヴァ族、マドラカ族、恐るべき業のドラーヴィダ族、ヤウデーヤ族、ラリッタ族、クシュドラカ族、ウシーナラ族、マーヴェーッラカ族、トゥンディケーラ族、サーヴィトリープトラカ族——東方・北方・西方・南方の者たち。
pattīnāṃ nihatāḥ saṅghā hayānāṃ prayutāni ca| rathavrajāś ca nihatā hatāśca varavāraṇāḥ|| / sadhvajāḥ sāyudhāḥ śūrāḥ savarmāmbarabhūṣaṇāḥ| kālena mahatā''yastāḥ kuśalair ye ca vardhitāḥ|| // 8-2-52-53 //
（52〜53）歩兵の群れが殺され、何百万もの騎馬が殺され、戦車群が殺され、最上の戦象も殺されました。旗を持ち、武器を持ち、鎧と衣と装飾を持つ勇者たち——長い年月をかけて育てられ、熟練者に鍛えられた者たち。
te hatāḥ samare rājan pārthenākliṣṭakarmaṇā| anye tathā'mitabalāḥ parasparavadhaiṣiṇaḥ|| // 8-2-54 //
（54）王よ、彼らはパールタ（アルジュナ）という困難なき業を持つ者に戦場で殺されました。他にも計り知れない力の者たちが、互いの殺害を望んで。
ete cānye ca bahavo rājānaḥ sagaṇā raṇe| hatāḥ sahasraśo rājan yan māṃ tvaṃ paripṛcchasi|| // 8-2-55 //
（55）王よ、あなたが私にお尋ねのとおり、これらの者たちや他にも多くの王たちが、軍とともに何千と戦場で殺されました。
evameṣa kṣayo vṛttaḥ karṇārjunasamāgame| mahendreṇa yathā vṛtro yathā rāmeṇa rāvaṇaḥ|| / yathā kṛṣṇena narako muruśca nihato raṇe| kārtavīryaśca rāmeṇa bhārgaveṇa yathā hataḥ|| / sajñātibāndhavaḥ śūraḥ samare yuddhadurmadaḥ| raṇe kṛtvā mahadyuddhaṃ ghoraṃ trailokyamohanam|| / yathā skandena mahiṣo yathā rudreṇa cāndhakaḥ| tathā'rjunena sa hato dvairathe yuddhadurmadaḥ|| // 8-2-56-57-58-59 //
（56〜59）このようにしてこの滅亡は、カルナとアルジュナの対決で起こりました。大いなるインドラがヴリトラを殺したように、ラーマがラーヴァナを殺したように、クリシュナがナラカとムルを戦場で殺したように、バールガヴァ・ラーマがカールタヴィーリヤを殺したように——親族・同盟者とともに勇猛にして戦場で酔いしれた者が、三界を惑わす恐ろしい大戦闘を繰り広げた後に——スカンダがマヒシャを、ルドラがアンダカを殺したように——アルジュナに一騎打ちで殺されました。戦闘に酔いしれた者が。
sāmātyabāndhavo rājan karṇaḥ praharatāṃ varaḥ| jayāśā dhārtarāṣṭrāṇāṃ vairasya ca mukhaṃ nṛpaḥ|| / tīrṇaṃ tat pāṇḍavai rājan yat purā nāvabudhyase| ucyamāno mahārāja bandhubhir hitakāṅkṣibhiḥ|| / 'na kṛtaṃ ca tvayā pūrvaṃ daivena vidhinā balāt'| tad idaṃ samanuprāptaṃ vyasanaṃ sumahātyayam|| / gāṇāṃ rājyakāmānāṃ tvayā rājan hitaiṣiṇā| ahitānyeva cīrṇāni teṣāṃ te phalamāgatam|| || // 8-2-60-61-62-63 //
（60〜62）王よ、参謀・同盟者とともに——武勇の中の最上者カルナ。ドリタラーシュトラの子らの勝利の望み、敵意の先頭——それはパーンダヴァたちに越えられました。大王よ、利益を願う親族たちに言われ続けていたことを。運命の力によって以前あなたがなさなかったこと——その大いなる破滅の災厄が今やって来ました。息子たちの王位を望むあなたが、利益を願いながら有害なことばかりを行った、その報いが来たのです。」
iti śrīmanmahābhārate karṇaparvaṇi dvitīyo'dhyāyaḥ|| 2 ||
