karṇaparva — aśītitamo'dhyāyaḥ (80)
第80章　ビーマセーナと御者ヴィショーカの対話
sañjaya uvāca|
atha tvidānīṃ tumule vimarde dviṣadbhir eko bahubhiḥ samāvṛtaḥ|
mahāraṇe sārathimityuvāca bhīmaścamūṃ vāhaya dhārtarāṣṭrīm|
tvaṃ sārathe yāhi javena vāhair nayāmyetāndhārtarāṣṭrānyamāya||
sañcodito bhīmasenena caivaṃ sa sārathiḥ putrabalaṃ tvadīyam|
prāyāttataḥ satvaramugravego yato bhīmastadbalaṃ gantumaicchat||
// 8-80-1-2 //
サンジャヤは語った。
tato'pare nāgarathāśvapattibhiḥ pratyudyayustaṃ kuravaḥ samantāt|
bhīmasya vāhāgryamudāravegaṃ samantato bāṇagaṇairnijaghnuḥ||
tataḥ śarānāpatato mahātmā ciccheda bāṇaistapīnayapuṅkhaiḥ|
te vai nipetustapanīyapuṅkhā dvidhā tridhā bhīmaśarairnikṛttāḥ||
tato rājannāgarathāśvayūnāṃ bhīmāhatānāṃ vararājamadhye|
ghoro ninādaḥ sumahānabhūttadā vajrāhatānāmiva parvatānām||
te vadhyamānāś ca narendramukhyā nirbhidyanto bhīmaśarapravekaiḥ|
bhīmaṃ samantātsamare'bhyarohan vṛkṣaṃ śakuntā iva puṣpahetoḥ||
tato'bhiyāte tava sainye sa bhīmaḥ prāduścakre vegamanantavegaḥ|
yathā'ntakāle kṣapayandidhakṣur bhūtāntakṛtkāla ivāttadaṇḍaḥ||
tasyātivegasya raṇe'tivegaṃ nāśaknuvandhārayituṃ tvadīyāḥ|
vyāttānanasyāpatato yathaiva kālasya kāle harataḥ prajā vai||
tato balaṃ bhārata bhāratānāṃ pradahyamānaṃ samare mahātmanā|
bhītaṃ diśo'kīryata bhīmanunnaṃ mahānilenābhragaṇā yathaiva||
// 8-80-3-9 //
御者はビーマセーナに駆り立てられ、お前の息子の軍へ急いだ。クル族は象・戦車・馬・歩兵で四方からビーマの最上の戦車を矢の群れで射た。偉大な者ビーマは黄金の羽根の矢で飛来する矢を切り落とした。王よ、ビーマに殺された象・戦車・馬の間に恐ろしい大きな叫び声が上がった——金剛杵に打たれた山のように。殺されながらも王たちはビーマに向かった——花を求める鳥が木に集まるように。無限の速さのビーマはお前の軍に出現し、終末に民を滅ぼす死神の杖を持つ死神のように力を発揮した。お前の者たちはビーマの過度の速さに耐えられなかった——口を開けた死神が時に民を奪うように。バーラタよ、偉大な者に焼かれるバーラタの軍は、恐怖に駆られ四方に散った——大風に吹かれた雲の群れのように。
tato dhīmānsārathimabravīdbalī sa bhīmasenaḥ punareva hṛṣṭaḥ||
sūtābhijānīhi parānsvakānvā rathāndhvajāṃścāpatataḥ sametān|
yudhyanhyahaṃ nābhijānāmi kiñcin mā sainyaṃ svaṃ chādayiṣye pramattaḥ||
arīnviśokānhi nirīkṣya sarvato mahāṃś ca manyuḥ punareti māṃ bhṛśam|
rājāturo nāgamadyatkirīṭī bahūni duḥkhānyabhicintayāmi||
etadduḥkhaṃ dhāraye dharmarājo yanmāṃ hitvā yātavāñśatrumadhye|
nainaṃ jīvaṃ nābhijānāmyajīvaṃ bībhatsuṃ vā tanmamādyātiduḥkham||
so'haṃ dviṣatsainyamudagrakalpaṃ vināśayiṣye paramapratītaḥ|
etannihatyājimadhye sametaṃ prīto bhaviṣyāmi saha tvayādya||
// 8-80-10-14 //
そこで知恵ある力の者ビーマセーナは再び喜んで御者に言った。「御者よ、四方から迫る敵と味方の戦車と旗を見分けてくれ。私は戦いながら何も見分けられない。うっかり味方の軍を覆い隠してしまうかもしれない。敵を見て大いなる怒りが再び激しく湧き上がる。王が心配だ、冠を戴く者（アルジュナ）がまだ来ない。多くの苦しみを思う。最も辛いのは、ダルマラージャが敵の中に私を置いて去ったことだ。彼が生きているのか死んでいるのか分からない。ビーバツ（アルジュナ）もだ——それが今日の我が最大の苦しみだ。」
sarvāṃstūṇānsāyakānāmavekṣya kiṃ śiṣṭaṃ syātsāyakānāṃ rathe me|
kā vā jātiḥ kiṃ pramāṇaṃ ca teṣāṃ jñātvā vyaktaṃ tatsamācakṣva sūta|
'kati vā sahasrāṇi kati vā śatāni hyācakṣva me sārathe kṣiprameva||
// 8-80-15 //
「全ての矢筒の矢を調べて、戦車に残っている矢の数、種類、大きさを確かめ、明確に報告せよ、御者。何千、何百か、御者よ、直ちに教えよ。」
viśoka uvāca|
sarvaṃ viditvaivamahaṃ vadāmi tavārthasiddhipradamadya vīra|
kaikeyakāmbhojasurāṣṭrabāhlikā mlecchāś ca suhmāḥ parataṅkaṇāś ca|
madrāś ca vaṅgā magadhāḥ kuṇindā ānartakāvartakāḥ pārvatīyāḥ|
sarve gṛhītapravarāyudhāstvāṃ saṃveṣṭya saṃveṣṭya tato viveduḥ||
rathe tavāsminniśitāḥ supītās tato bhallā dvādaśa vai sahasrāḥ'|
ṣaṇmārgaṇānāmayutāni vīra kṣurāś ca bhallāś ca tathāyutākhyāḥ||
nārācānāṃ dve sahasre ca vīra trīṇyepa ca pradarāṇāṃ sma pārtha|
astyāyudhaṃ pāṇḍaveyāvaśiṣṭaṃ na yadvahecchakaṭaṃ ṣaṅgavīyam||
etadvidvanmuñca sahasraśo'pi gadāsibāhudraviṇaṃ ca te'sti|
prāsāś ca mudrarāḥ śaktayastomarāś ca mābhaiṣīstvaṃ saṃkṣayādāyudhānām||
// 8-80-16-20 //
ヴィショーカは語った。
bhīmasena uvāca|
'adyaiva nūnaṃ kathayantu siddhāṃ mama pratijñāṃ sarvaloke viśoka|
na mokṣyate samare bhīmasena ekaḥ śatrūnsamare vāpyajaiṣīt|
āśaṃsitānāmidamekamastu tanme devāḥ sakalaṃ sādhayantu||
' sūtādya madbāhuyutaiḥ samastān samāhanadbhiḥ pārthivānāśuvegaiḥ|
cchannaṃ bāṇairāhavaṃ ghorarūpaṃ naṣṭādityaṃ mṛtyulokena tulyam||
adyaitadyai viditaṃ pārthivānāṃ bhaviṣyati hyākumāraṃ ca sūta|
nimagno vā samare bhīmasena ekaḥ kurūnvā samare vyajaiṣīt||
sarve saṅkhye kuravo niṣpatantu māṃ vā lokāḥ kīrtayantvākumāram|
sarvānekastānahaṃ pātayiṣye te vā sarve bhīmasenaṃ tudantu||
āśāstāraḥ karma cāpyuttamaṃ ye tanme devāḥ saphalaṃ sādhayantu|
āyātīha keśavasārathī rathī śakrastūrṇaṃ yajña ivopahūtaḥ||
// 8-80-21-25 //
ビーマセーナは語った。
īkṣasvaitāṃ bhāratīṃ dīryamāṇām ete kasmādvidravante narendrāḥ|
vyaktaṃ dhīmānsavyasācī narāgryaḥ sainyaṃ hyetacchādayatyāśu bāṇaiḥ||
paśya dhvajāṃś ca dravato viśoka nāgānhayānpattisaṅghāṃś ca saṅkhye|
rathānvikīrṇāñśaraśaktitāḍitān paśyasvaitānrathinaścaiva sūta||
āpūryate kauravī cāpyabhīkṣṇaṃ senā hyasau subhṛśaṃ hanyamānā|
dhanañjayasyāśanitulyavegair grastā śaraiḥ kāñcanabarhajālaiḥ||
ete dravanti sma rathāśvanāgāḥ padātisaṅghānatimardayantaḥ|
sammuhyamānāḥ kauravāḥ sarva eva dravanti nāgā iva dāhabhītāḥ||
hāhākṛtāścaiva raṇe viśoka muñcanti nādānvipulāngajendrāḥ||
// 8-80-26-30 //
「見よ、バーラタの軍が崩壊している。なぜ王たちが逃げるのか。明らかに知恵ある人中の最上者サヴャサーチン（アルジュナ）が、この軍を素早く矢で覆い尽くしている。逃げる旗、象、馬、歩兵の群れを見よ、ヴィショーカよ。矢と槍に打たれた戦車と戦車兵を見よ。カウラヴァの軍が繰り返し満たされてはまた激しく殺されている。ダナンジャヤの雷に等しい速さの、黄金と孔雀の羽根の網をつけた矢に飲み込まれて。戦車・馬・象が逃げ、歩兵の群れを踏みつけ、混乱したカウラヴァが全て逃げる——火を恐れる象のように。戦場で叫び声を上げ、象の王たちが大きな叫びを放っている。」
viśoka uvāca|
kiṃ bhīma nainaṃ tvamihāśṛṇoṣi visphāritaṃ gāṇḍivasyātighoram|
kruddhena pārthena vikṛṣyato'dya kaccinnemau tava karṇau vinaṣṭau||
sarve kāmāḥ pāṇḍava te samṛddhāḥ kapirhyasau dṛśyate hastisainye|
nīlāddhanādvidyutamuccarantīṃ tathā paśya visphurantīṃ dhanurjyām||
kapirhyasau vīkṣate sarvato vai dhvajāgramāruhya dhanañjayasya|
vitrāsayanri pusaṅghānvimarde bibhemyasmādātmanaivābhivīkṣya||
vibhrājate cātimātraṃ kirīṭaṃ vicitrametacca dhanañjayasya|
divākarābho maṇireṣa divyo vibhrājate caiva kirīṭasaṃsthaḥ||
pārśve bhīmaṃ pāṇḍurābhraprakāśaṃ paśyasva saṅkhaṃ devadattaṃ sughoṣam|
abhīṣuhastasya janārdanasya vigāhamānasya camūṃ pareṣām||
raviprabhaṃ vajranābhaṃ kṣurāntaṃ pārśve sthitaṃ paśya janārdanasya|
cakraṃ yaśovardhanaṃ keśavasya sadārcitaṃ yadibhiḥ paśya vīra||
mahādvipānāṃ saraladrumopamāḥ karā nikṛttāḥ prapatantyamī kṣuraiḥ|
kirīṭinā tena punaḥ sasādinaḥ śarairnikṛttāḥ kuliśairivādrayaḥ||
tathaiva kṛṣṇasya ca pāñcajanyaṃ mahārhametaṃ dvijarājavarṇam|
kaunteya paśyorasi kaustubhaṃ ca jājvalyamānaṃ vijayāṃ srajaṃ ca||
// 8-80-31-38 //
ヴィショーカは語った。
dhravaṃ rathāgryaḥ samupaiti pārtho vidrāvayansainyamidaṃ pareṣām|
sitābhravarṇairasitaprayuktair hayairmahārhai rathināṃ variṣṭhaḥ||
rathānhayānpattigaṇāṃś ca sāyakair vidāritānpaśya patantyamī yathā|
tavānujenāmararājatejasā mahāvanānīva suparṇavāyunā||
catuḥ śatānpaśya rathānimānhatān savājisūtānsamare kirīṭinā|
maheṣubhiḥ saptaśatāni dantināṃ padātisādīṃś ca rathānanekaśaḥ||
ayaṃ samabhyeti tavāntikaṃ balī nighnankurūṃścitra iva graho'rjunaḥ|
samṛddhakāmo'si hatāstavāhitā balaṃ tavāyuś ca cirāya vardhatām||
// 8-80-39-42 //
「確かに最上の戦車のアルジュナが、敵のこの軍を追い散らしながら近づいてくる。白い雲色の馬に、黒い者（クリシュナ）に引かれて——戦車戦士の中の最上者が。戦車・馬・歩兵が矢に引き裂かれて倒れるのを見よ——天帝の威光を持つお前の弟によって、大いなる森がガルダと風に倒されるように。四百台の戦車が馬と御者もろとも、冠を戴く者に殺されたのを見よ。大いなる矢で七百頭の象、歩兵と騎馬と多くの戦車も。この力ある者がお前のもとに近づいてくる。輝く星のようにクル族を殺しながら。お前の願いは叶い、敵は殺された。お前の力と命が永く栄えんことを。」

// 8-80-43 //
ビーマセーナは語った。
