本章は南伝（Southern Recension）テキストの「アディヤーヤ10」（一騎打ちの数々・サーティヤキがヴィンダとアヌヴィンダを殺す章。第十六日目の戦いの続き）です。各段落は原典の詩節番号（8-10-N）と和訳の段落番号が対応しています。
karṇaparva — daśamo'dhyāyaḥ (10)
第10章　一騎打ちの数々・サーティヤキがヴィンダとアヌヴィンダを殺す
sañcaya uvāca|
tataḥ karṇo maheṣvāsaḥ pāṇḍavānāmanīkinīm|
jaghāna samare śūraḥ sannataparvabhiḥ|| // 8-10-1 //
サンジャヤは語った。 （1）偉大な弓の使い手カルナは、しなやかな矢でパーンダヴァの軍を戦場で殺しました、勇猛に。
tathaiva pāṇḍavā rājaṃs tava putrasya vāhinīm|
karṇasya pramukhe kruddhā nijaghnuste mahārathāḥ|| // 8-10-2 //
（2）同じようにパーンダヴァたちも、王よ、おまえの息子の軍を、怒りに燃えた偉大な戦車戦士たちとして、カルナの面前で殺しました。
karṇo'pi rājan samare vyahanat pāṇḍavīṃ camūm|
nārācair arkaraśmyābhaiḥ karmāraparimārjitaiḥ|| // 8-10-3 //
（3）カルナもまた、王よ、戦場でパーンダヴァの軍を、太陽の光線のような、鍛冶に磨かれたナーラーチャ矢で打ちました。
tatra bhārata karṇena nārācais tāḍitā gajāḥ|
neduḥ seduśca mamluśca babhrumuśca diśo daśa|| // 8-10-4 //
（4）バーラタよ、カルナのナーラーチャ矢に打たれた象たちは、叫び、倒れ、萎え、恐れて十方に逃げ散りました。
vadhyamāne bale tasmin sūtaputreṇa māriṣa|
nakulo'bhyadravat tūrṇaṃ sūtaputraṃ mahāraṇe|| // 8-10-5 //
（5）スータの息子にその軍が殺される中、王よ、ナクラが速やかにスータの息子に向かって大合戦で突進しました。
bhīmasenas tathā drauṇiṃ kurvāṇaṃ karma duṣkaram|
vindānuvindau kaikeyau sātyakiḥ samavārayat|| // 8-10-6 //
（6）ビーマセーナは、困難な業をなすドローナの子（アシュヴァッターマン）に向かい、ケーカヤのヴィンダとアヌヴィンダにはサーティヤキが立ちはだかりました。
śrutakarmāṇamāyāntaṃ citraseno mahīpatiḥ|
prativindhyas tathā citraṃ citraketanakārmukam|| // 8-10-7 //
（7）シュルタカルマンに向かって来たのはチトラセーナ王、プラティヴィンディヤには色鮮やかな弓と旗を持つチトラが向かいました。
duryodhanastu rājānaṃ dharmaputraṃ yudhiṣṭhiram|
saṃśaptakagaṇā hṛṣṭā hyabhyadhāvan dhanañjayam|| // 8-10-8 //
（8）ドゥルヨーダナはダルマの息子ユディシュティラ王に向かい、喜ぶサンシャプタカの群れがダナンジャヤ（アルジュナ）に突進しました。
dhṛṣṭadyumnaḥ kṛpaṃ cāpi tasmin vīravarakṣaye|
śikhaṇḍī kṛtavarmāṇaṃ samāsādayad acyutam|| // 8-10-9 //
（9）ドリシュタデュムナはクリパに、その勇者の殺し合いの中で——シカンディンは不動のクリタヴァルマンに立ちはだかりました。
śrutakīrtis tathā śalyaṃ mādrīputraḥ sutaṃ tava|
duḥśāsanaṃ mahārāja sahadevaḥ pratāpavān|| // 8-10-10 //
（10）シュルタキールティにはシャリヤが、マードリーの息子（サハデーヴァ）にはおまえの勇猛な息子ドゥフシャーサナが、大王よ。
kaikeyau sātyakiṃ yuddhe śaravarṣeṇa bhāsvatā|
sātyakiḥ kekayau cāpi cchādayāmāsa bhārata||
tāvenaṃ bhrātarau vīrau jaghnatur hṛdaye bhṛśam|
viṣāṇābhyāṃ yathā nāgau pratināgaṃ mahāvane|| // 8-10-11-12 //
（11〜12）バーラタよ、ケーカヤの二人はサーティヤキを輝く矢の雨で覆い、サーティヤキもまたケーカヤの二人を覆いました。勇猛な二人の兄弟は、彼の心臓を激しく射りました。大きな森で象が牙で別の象を突くように。
śarasambinnavarmāṇau tāvubhau bhrātarau raṇe|
sātyakiṃ satyakarmāṇaṃ rājan vivyadhatuḥ śaraiḥ|| // 8-10-13 //
（13）矢で鎧を射抜かれた兄弟の二人は、真の業のサーティヤキを、王よ、矢で射りました。
tau sātyakir mahārāja prahasan sarvatodiśaḥ|
chādayañ charavarṣeṇa vārayāmāsa bhārata|| // 8-10-14 //
（14）大王よ、サーティヤキは笑いながら、四方からの矢の雨で彼らを覆い、バーラタよ、阻止しました。
vāryamāṇau tatastau hi śaineyaśaravṛṣṭibhiḥ|
śaineyasya rathaṃ tūrṇaṃ chādayāmāsatuḥ śaraiḥ|| // 8-10-15 //
（15）シャイネーヤ（サーティヤキ）の矢の雨に阻まれた二人は、速やかにシャイネーヤの戦車を矢で覆いました。
tayostu dhanuṣī citre chittvā śaurir mahāyaśāḥ|
atha tau sāyakais tīkṣṇair vārayāmāsa sātyakiḥ|| // 8-10-16 //
（16）大いなる名声のシャウリ（サーティヤキ）は、二人の美しい弓を切り落とし、鋭い矢で二人を阻止しました。
athānye dhanuṣī citre pragṛhya ca mahāśarān|
sātyakiṃ chādayantau tau ceratur laghu suṣṭhu ca|| // 8-10-17 //
（17）二人は別の美しい弓を取り、大きな矢を手にして、サーティヤキを覆いながら、軽やかに巧みに動き回りました。
tābhyāṃ muktā mahābāṇāḥ kaṅkabarhiṇavāsasaḥ|
dyotayanto diśaḥ sarvāḥ sampetuḥ svarṇabhūṣaṇāḥ||
bāṇāndhakāram abhavat tayo rājan mahāmṛdhe|
anyonyasya dhanuścaiva cicchiduste mahārathāḥ|| // 8-10-18-19 //
（18〜19）二人から放たれた大いなる矢は、カンカ鳥とクジャクの羽で飾られ、四方を照らし、黄金で飾られて飛んでいきました。王よ、二人の大合戦で矢の暗闇が生じ、偉大な戦車戦士たちは互いの弓を切り合いました。
tataḥ kruddho mahārāja sātvato yuddhadurmadaḥ|
dhanur anyat samādāya sajyaṃ kṛtvā ca saṃyuge||
kṣurapreṇa sutīkṣṇena hyanuvindaśiro'harat|
apatattacchiro rājan kuṇḍalopacitaṃ mahat|| // 8-10-20-21 //
（20〜21）大王よ、怒ったサートヴァタ族の戦いに酔いしれた者は、別の弓を取り弦を張って戦いに臨み、鋭いクシュラプラ矢でアヌヴィンダの首を切り落としました。王よ、耳飾りで飾られたその大きな首が落ちました。
śambarasya śiro yadvan nihatasya mahāraṇe|
śocayan kekayān sarvāñ jagāmāśu vasundharām|| // 8-10-22 //
（22）大合戦で殺されたシャンバラの首のように、すべてのケーカヤたちを悲しませながら、速やかに大地に落ちました。
taṃ dṛṣṭvā nihataṃ śūraṃ bhrātā tasya mahārathaḥ|
sajyam anyad dhanuḥ kṛtvā śaineyaṃ paryavārayat|| // 8-10-23 //
（23）あの勇者が殺されたのを見て、兄の偉大な戦車戦士は、別の弓に弦を張り、シャイネーヤ（サーティヤキ）を取り囲みました。
sa ṣaṣṭyā sātyakiṃ vidvvā svarṇapuṅkhaiḥ śilāśitaiḥ|
nanāda balavannādaṃ tiṣṭhatiṣṭheti cābravīt|| // 8-10-24 //
（24）六十本の黄金の矢羽根の石で研がれた矢でサーティヤキを射り、大きな声で吼え、「止まれ、止まれ！」と叫びました。
sātyakiṃ ca tatastūrṇaṃ kekayānāṃ mahārathaḥ|
śarair anekasāhasrair bāhvor urasi cārpayat|| // 8-10-25 //
（25）ケーカヤの偉大な戦車戦士は、速やかに何千もの矢をサーティヤキの両腕と胸に打ち込みました。
sa śaraiḥ kṣatasarvāṅgaḥ sātyakiḥ satyavikramaḥ|
rarāja samare rājan sapuṣpa iva kiṃśukaḥ|| // 8-10-26 //
（26）矢で全身を傷つけられた真の武勇のサーティヤキは、王よ、戦場で花咲くキンシュカの木のように美しく輝きました。
sātyakiḥ samare vidvaḥ kaikeyena mahātmanā|
kaikeyaṃ pañcaviṃśatyā vivyādha prahasanniva|| // 8-10-27 //
（27）偉大なケーカヤに射られたサーティヤキは、笑うかのように、ケーカヤを二十五本の矢で射返しました。
tāvanyonyasya samare sañchidya dhanuṣī śubhe|
hatvā ca sārathī tūrṇaṃ hayāṃśca rathināṃ varau|| // 8-10-28 //
（28）二人は互いの美しい弓を切り合い、速やかに互いの御者を殺し、戦車兵の中の最上者として——
virathāvasiyuddhāya samājagmatur āhave|
śatacandracite gṛhya carmaṇī subhujau tathā|| // 8-10-29 //
（29）戦車を失い、百の月の模様の盾を持ち、美しい腕の二人は、剣の戦いに臨みました。
virocetāṃ mahāraṅge nistriṃśavaradhāriṇau|
yathā devāsure yuddhe jambhaśakrau mahābalau|| // 8-10-30 //
（30）大きな闘技場で、最上の剣を持つ二人は輝きました。まるで神々と阿修羅の戦いにおけるジャンバとシャクラ（インドラ）のように、大いなる力の二人が。
maṇḍalāni tatastau tu vicantau mahāraṇe|
anyonyam abhitas tūrṇaṃ samājagmatur āhave|| // 8-10-31 //
（31）大合戦で旋回しながら、二人は速やかに互いに接近し、戦場で出会いました。
anyonyasya vadhe caiva cakratur yatnamuttamam|
kaikeyasya dvidhā carma tataściccheda sātvataḥ|| // 8-10-32 //
（32）互いの殺害に最大の努力を尽くしました。サートヴァタ（サーティヤキ）はケーカヤの盾を二つに切り裂きました。
sātyakestu tathaivāsau carma ciccheda pārthivaḥ|
carma cchittvā tu kaikeyas tārāgaṇaśatairvṛtam|
cacāra maṇḍalānyeva gatapratyāgatāni ca|| // 8-10-33 //
（33）同じようにケーカヤ王もサーティヤキの盾を切り裂きました。盾を切り裂いたケーカヤは、星の群れに覆われた盾を切り、旋回の型——前進と後退——を演じました。
taṃ carantaṃ mahāraṅge nistriṃśavaradhāriṇam|
apahastena ciccheda śaineyas tvarayā'nvitaḥ|| // 8-10-34 //
（34）大きな闘技場で最上の剣を持って旋回するその者を、シャイネーヤ（サーティヤキ）は急いで斜めの一撃で切りました。
savarmā kekayo rājan dvidhā cchinno mahāraṇe|
nipapāta maheṣvāso vajrāhata ivātvalaḥ|| // 8-10-35 //
（35）大王よ、ケーカヤ王は鎧ごと大合戦で二つに切り裂かれ、偉大な弓の使い手は金剛杵に打たれた山のように倒れました。
taṃ nihatya raṇe śūraḥ śaineyo rathasattamaḥ|
yudhāmanyurathaṃ tūrṇamāruroha parantapaḥ|| // 8-10-36 //
（36）戦場であの勇者を殺したシャイネーヤ、戦車兵の中の最上者、敵を苦しめる者は、速やかにユダーマンユの戦車に乗りました。
tato'nyaṃ rathamāsthāya vidhivat kalpitaṃ punaḥ|
kekayānāṃ mahatsainyaṃ vyadhamat sātyakiḥ śaraiḥ|| // 8-10-37 //
（37）それから別の戦車に乗り、しかるべく装備されたもので、サーティヤキはケーカヤの大軍を矢で打ち砕きました。
sā vadhyamānā samare kekayānāṃ mahācamūḥ|
tam utsṛjya raṇe śatruṃ pradudrāva diśo daśa|| || // 8-10-38 //
（38）戦場で殺されるケーカヤの大軍は、あの敵を捨てて、十方に逃げ散りました。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe daśamo'dhyāyaḥ|| 10 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十章は終わる。
