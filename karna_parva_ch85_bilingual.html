マハーバーラタ ― カルナ篇 第85章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 85 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ85」で、混戦の場面を描きます。複数の詩節が一括して翻訳されています。
karṇaparva — pañcāśītitamo'dhyāyaḥ (85)
第85章　混戦
sañjaya uvāca|
tamāyāntaṃ mahāvegairaśvaiḥ kapivaradhvajam|
yuddhāyābhyadravandīrāḥ kurūṇāṃ navatīṃ rathāḥ||
// 8-85-1 //
サンジャヤは語った。
kṛtvā saṃśaptakā ghoraṃ śapathaṃ pāralaukikam|
parivavrurnaravyāghrā naravyāghraṃ raṇe'rjunam||
// 8-85-2 //
来世での恐ろしい誓いを立てた誓約戦士たちが、人中の虎として人中の虎アルジュナを戦場で取り囲んだ。
kṛṣṇaḥ śvetānmahāvegānaśvānkāñcanabhūṣaṇān|
muktājālapraticchannānpraiṣītkarṇarathaṃ prati||
// 8-85-3 //
クリシュナは、黄金で飾られ真珠の網で覆われた白く大速の馬を、カルナの戦車に向けて走らせた。
prekṣya karṇarathaṃ yāntamarighnaṃ taṃ dhanañjayam|
bāṇavarṣairabhighnantaḥ saṃśaptakagaṇā yayuḥ||
// 8-85-4 //
敵を殺すダナンジャヤがカルナの戦車に向かうのを見て、矢の雨を浴びせながら誓約戦士の群れが向かってきた。
tvaramāṇāṃstu tānsarvānsasūteṣvasanadhvajān|
jaghāna navatiṃ vīrānarjuno niśitaiḥ śaraiḥ||
// 8-85-5 //
急ぐ彼ら全員を——御者・弓・旗もろとも——アルジュナは鋭い矢で九十人の勇者を殺した。
te'patanta hatā bāṇairnānārūpaiḥ kirīṭinā|
vimānebhyaḥ sukṛtinaḥ svargātpuṇyakṣaye yathā||
// 8-85-6 //
様々な形のアルジュナの矢に殺された彼らは、功徳が尽きて天上の乗り物から落ちる善行者のように倒れた。
tataḥ sarathanāgāśvāḥ kuravaḥ kurusattamam|
nirbhayā bharataśreṣṭhamabhyavartanta phalgunam||
// 8-85-7 //
そしてクル族の最上者として、戦車・象・馬を伴うクル族の者たちは、恐れることなくアルジュナに向かった。
tadāyastamanuṣyāśvamudīrṇavaravāraṇam|
putrāṇāṃ te mahāsainyaṃ samarautsīddhanañjayam||
// 8-85-8 //
汝の息子たちの大軍は、鉄の武器を持つ人・馬と、奮い立つ象を擁して、ダナンジャヤを包囲した。
śaktyṛṣṭitomaraprāsairgadānistriṃśasāyakaiḥ|
prācchādayanmaheṣvāsāḥ kuravaḥ kurunandanam||
// 8-85-9 //
槍・投げ槍・矛・棍棒・刀・矢で、クルの大弓持ちの者たちはクルの子（アルジュナ）を覆い尽くした。
tāmantarikṣe vitatāṃ śastravṛṣṭiṃ samantataḥ|
vyadhamatpāṇḍavo bāṇaistamaḥ sūrya ivāṃśubhiḥ||
// 8-85-10 //
空中に張り巡らされたその武器の雨を、パーンダヴァは太陽が光線で闇を払うように矢で蹴散らした。
tato mlecchāḥ sthitā mattaistrayodaśaśatairgajaiḥ|
pārśvato vyahananpārthaṃ tava putrasya śāsanāt||
// 8-85-11 //
そして、汝の息子の命令により、酩酊した千三百頭の象に乗ったムレッチャ（蛮族）がアルジュナの側面から攻撃した。
karṇinālīkanārācaistomaraprāsaśaktibhiḥ|
karpaṇairbhiṇḍipālaiś ca rathasthaṃ pārthamārdayan||
// 8-85-12 //
角のある矢・管矢・鉄矢・矛・投げ槍・槍・カルパナ・ビンディパーラで、戦車に乗るアルジュナを苦しめた。
tāṃ śastravṛṣṭimatulāṃ dvipasthaiḥ preṣitāṃ prabhuḥ|
ciccheda niśitairbhallairardhacandraiś ca phalgunaḥ||
// 8-85-13 //
象に乗る者たちが放った比類なきその武器の雨を、アルジュナは鋭い鏃と半月矢で切り落とした。
atha tāndviradānsarvānnānāliṅgaiḥ śarottamaiḥ|
sapatākadhvajārohāngirīnvajrairivābhinat||
// 8-85-14 //
そして様々な形の最上の矢で、旗・幟・騎手もろとも、山を金剛杵で砕くように象を全て打ち砕いた。
te hemapuṅkhairiṣubhirarditā hemamālinaḥ|
hatāḥ peturmahānāgāḥ sāgrijvālā ivādrayaḥ||
// 8-85-15 //
黄金の羽根の矢に打たれた、黄金の花輪を持つ大象たちは、火を噴く山のように殺されて倒れた。
tato gāṇḍīvanirghoṣo mahānāsīdviśāmpate|
stanatāṃ kūjatāṃ caiva manuṣyagajavājinām||
// 8-85-16 //
王よ、ガーンディーヴァの轟音が大きく響いた。呻き・叫ぶ人・象・馬と共に。
kuñcarāś ca hatā rājandadruvuste samantataḥ|
aśvāś ca paryadhāvanta hatārohā diśo daśa||
// 8-85-17 //
王よ、象たちは殺されて四方に走り出し、騎手を失った馬が十方に駆け回った。
rathā hīnā nahārāja rathibhirvājibhistathā|
gandharvanagarākārā dṛśyante sma sahasraśaḥ||
// 8-85-18 //
大王よ、騎手を失い馬も失った戦車が、ガンダルヴァの幻の都のように、何千もが見られた。
aśvārohā mahārāja dhāvamānā itastataḥ|
tatratatraiva dṛśyante nihatāḥ pārthasāyakaiḥ||
// 8-85-19 //
大王よ、あちこちに走り回る騎馬兵が、あちこちでアルジュナの矢に殺されているのが見えた。
tasminkṣaṇe pāṇḍavasya bāhvorbalamadṛśyata|
yatsādino vāraṇāṃś ca rathāṃścaiko'jayadyudhi||
// 8-85-20 //
その一瞬にパーンダヴァの両腕の力が示された。一人で騎馬・象・戦車を戦場で打ち倒したのだ。
asaṃyuktāś ca te rājanparivṛttā raṇaṃ prati|
narā nāgā rathāścaiva nadanto'rjunamabhyayuḥ||
// 8-85-21 //
王よ、連結を解かれた者たちが再び戦場に戻り、人・象・戦車が叫びながらアルジュナに向かった。
tatastryeṅgeṇa mahatā balena bharatarṣabha|
dṛṣṭvā parivṛtaṃ rājanbhīmasenaḥ kirīṭinam||
hatāvaśeṣānutsṛjya tvadīyānkaticidrathān|
javenābhyadravadbhīmo dhanañjayarathaṃ prati||
// 8-85-22-23 //
バーラタの雄牛よ、大いなる三翼の軍にアルジュナが包囲されるのを見て、ビーマセーナは残った汝の数台の戦車を捨て、素早くダナンジャヤの戦車に向かって駆けた。
tatastatprādravatsainyaṃ hatabhūyiṣṭhamāturam|
dṛṣṭvā'rjunaṃ tadā bhīmamāgataṃ bhrātaraṃ prati||
// 8-85-24 //
そして、多くが殺され疲弊したその軍は、アルジュナとその兄弟ビーマが合流するのを見て逃げ散った。
hatāvaśiṣṭāṃsturagānarjunena mahābalaḥ|
bhīmo vyadhamadaśrānto gadāpāṇirmahāhave||
// 8-85-25 //
残った馬を、大力のビーマが棍棒を手に持ち、疲れを知らず大いなる戦場で蹴散らした。
'gadāpāṇiṃ tadā dṛṣṭvā bhīmaṃ bhārata bhāratāḥ|
menire tamanuprāptaṃ daṇḍapāṇimivāntakam'||
// 8-85-26 //
バーラタよ、棍棒を手にしたビーマを見て、バーラタの者たちは、杖を振り上げたヤマ（死神）が現れたと思った。
kālarātrimivātyugrāṃ naranāgāśvabhojanām|
prākārāṭṭapuradvāradāraṇīmatidāruṇām||
gadāṃ turaganāśāya tvaranbhīmo vyavāsṛjat|
sā jaghāna bahūnaśvānaśvārohāṃś ca māriṣa||
// 8-85-27-28 //
人・象・馬を食い尽くす死の夜のように極めて恐ろしく、城壁・塔門・城門を破壊する極めて恐ろしい棍棒を、馬を殺すためにビーマが急いで投げ、多くの馬と騎馬兵を殺した。
kāṃsyāyasatanutrāṃś ca narānaśvāṃś ca pāṇḍavaḥ|
pothayāmāsa gadayā saśabdaṃ te'patanhatāḥ||
// 8-85-29 //
銅と鉄の鎧を着た人と馬を、パーンダヴァは棍棒で大きな音を立てて粉砕し、彼らは殺されて倒れた。
dantairdaśanto vasudhāṃ śerate kṣatajokṣitāḥ|
bhagnamūrdhāsthicaraṇāḥ kravyādagaṇabhojanāḥ||
// 8-85-30 //
歯で大地を噛みながら横たわる彼らは、血にまみれ、頭蓋・骨・足が砕かれ、肉食の群れの餌となった。
asṛṅmāṃsavasābhiś ca tṛptimabhyāgatā gadā|
asthīnyapyaśnatī tasthau kālarātrīva durdṛśā||
// 8-85-31 //
血と肉と脂肪で棍棒は満足し、骨をもなお食らい、死の夜のように恐ろしい姿で立っていた。
sahasrāṇi daśāśvānāṃ hatvā pattīṃś ca bhūyasaḥ|
bhīmo'bhyadhāvatsaṅkruddho gadāpāṇiritastataḥ||
// 8-85-32 //
一万頭の馬と多くの歩兵を殺し、怒り狂ったビーマは棍棒を手にあちこちに駆け回った。
gadāpāṇiṃ tato bhīmaṃ dṛṣṭvā bhārata tāvakāḥ|
menire samanuprāptaṃ kāladaṇ़ḍodyataṃ yamam||
// 8-85-33 //
バーラタよ、棍棒を手にしたビーマを見て、汝の軍の者たちは、死の杖を振り上げたヤマ（死神）が現れたと思った。
sa matta iva mātaṅgaḥ saṅkruddhaḥ pāṇḍunandanaḥ|
praviveśa gajānīkaṃ makaraḥ sāgaraṃ yathā||
// 8-85-34 //
酩酊した象のように怒り狂ったパーンドゥの子は、マカラ（ワニ）が海に入るように象の軍に突入した。
vigāhya ca gajānīkaṃ pragṛhya mahatīṃ gadām|
kṣaṇena bhīmaḥ saṅkruddhastanninye yamasādanam||
// 8-85-35 //
象の軍に分け入り、大きな棍棒を振り上げ、怒れるビーマは一瞬にしてそれをヤマの館へ送った。
gajānsakaṅkaṭānmattānsārohānsapatākinaḥ|
patataḥ samapaśyāma sapakṣānparvatāniva||
// 8-85-36 //
鎧を着け、酩酊し、騎手と旗を載せた象たちが、翼を持つ山のように倒れるのを我々は見た。
hatvā tu tadgajānīkaṃ bhīmaseno mahābalaḥ|
punaḥ svarathamāsthāya pṛṣṭhato'rjunamabhyayāt||
// 8-85-37 //
象の軍を殺した大力のビーマセーナは、再び自分の戦車に乗り、アルジュナの背後に従った。
tataḥ parāṅmukhībhūtaṃ nirutsāhaṃ balaṃ tava|
tadānīṃ tu mahārāja prāyaśaḥ śastraveṣṭitam||
// 8-85-38 //
その時、汝の軍は背を向け、意気消沈し、大王よ、ほとんどが武器にまみれていた。
vilambamānaṃ tatsainyabhapragalbhamavasthitam|
dṛṣṭvā prācchādayadbāṇairarjunaḥ śastravṛṣṭibhiḥ||
// 8-85-39 //
ぐずぐずしている軍が意気消沈して立っているのを見て、アルジュナは矢の嵐の武器の雨で覆い尽くした。
narāśvarathamātaṅgā yudhi gāṇḍīvadhanvanā|
śaravrātaiścitā rejuḥ kadambā iva kesaraiḥ||
// 8-85-40 //
人・馬・戦車・象が、ガーンディーヴァの弓持ちによって矢の群れで覆われ、花弁を持つカダンバの木のように輝いた。
tataḥ kuruṇāmabhavadārtanādo mahānnṛpa|
narāśvanāgāsuhanāndṛṣṭvā bāṇānkirīṭinaḥ||
// 8-85-41 //
王よ、クル族の苦悶の叫び声が大きく響いた。人・馬・象の命を奪う冠を戴く者の矢を見て。
hāhākṛtaṃ bhṛśaṃ trastaṃ līyamānaṃ parasparam|
alātacakravatsainyaṃ tadā babhrāma tāvakam||
// 8-85-42 //
「ああ、ああ」と叫び、怯え、互いに身を寄せ合い、汝の軍は火の輪のようにぐるぐる回った。
tato'rjunaśaradhvastaṃ kurūṇāṃ sumahadbalam|
na hyatrāsīdanirbhinno rathaḥ sādī hayo gajaḥ||
// 8-85-43 //
アルジュナの矢に粉砕されたクル軍の大軍には、貫かれていない戦車・騎手・馬・象は一つもなかった。
ādīptamiva tatsainyaṃ śaraiśchinnatanucchadam|
āsītsvaśoṇitaklinnaṃ raudraṃ naṣṭaṃ viśāmpate||
// 8-85-44 //
矢で燃え上がるかのようなその軍は、体の覆いを切り裂かれ、自らの血にまみれ、恐ろしく、壊滅した、王よ。
tatsainyaṃ hatabhūyiṣṭhamāhataṃ niśitaiḥ śaraiḥ|
na jahau samaraṃ prāpya phalgunaṃ śatrutāpanam||
// 8-85-45 //
その軍はほとんどが殺され、鋭い矢で打たれながらも、敵を苦しめるアルジュナに遭遇しても戦場を離れなかった。
tatrādbhutamapaśyāma kauravāṇāṃ parākramam|
vadhyamāno'pi yatpārthaṃ na jahau bharatarṣabha||
// 8-85-46 //
カウラヴァの武勇にも驚嘆すべきものがあった。殺されながらもアルジュナを見捨てなかったことだ、バーラタの雄牛よ。
taṃ dṛṣṭvā vikramaṃ tasya kuravaḥ savyasācinaḥ|
nirāśāḥ samapadyanta sarve karṇasya jīvite||
// 8-85-47 //
しかしサヴャサーチン（アルジュナ）のその武勇を見て、クル族はカルナの命に対する望みをすべて失った。
aviṣahyaṃ tu pārthasya śarasaṃsparśamāhave|
matvā nyavartankuravo jitā gāṇḍīvadhanvanā||
// 8-85-48 //
アルジュナの矢の打撃は戦場で耐え難いと悟り、ガーンディーヴァの弓持ちに敗れたクル族は退却した。
te hitvā samare pārthaṃ vadhyamānāś ca sāyakaiḥ|
pradudruvurdiśo bhītāścukruśuścāpi sūtajam||
// 8-85-49 //
戦場でアルジュナを捨て、矢に殺されながら、恐怖に駆られて四方に逃げ散り、スータの子（カルナ）に助けを求めて叫んだ。
tānvidrāvayate pārthaḥ kirañśaraśatānbahūn|
harṣayanpāṇḍavīṃ senāṃ rājānaṃ ca yudhiṣṭhiram||
// 8-85-50 //
アルジュナは何百もの矢を放ちながら彼らを追い散らし、パーンダヴァの軍とユディシュティラ王を喜ばせた。
putrāstava mahārāja jagmuḥ karṇarathaṃ prati|
agādhe majjatāṃ teṣāṃ dvīpaḥ karṇo'bhavattadā||
// 8-85-51 //
大王よ、汝の息子たちはカルナの戦車へ向かった。底なしの淵に沈む彼らにとって、カルナが島（避難所）となった。
kuravo hi mahārāja nirviṣāḥ pannagā iva|
karṇamevopalīyanta bhayādgāṇḍīvaghanvanaḥ||
// 8-85-52 //
大王よ、クル族は毒を失った蛇のように、ガーンディーヴァの弓持ちへの恐怖からカルナに身を寄せた。
yathā sarvāṇi bhūtāni mṛtyorbhītāni māriṣa|
upalīyanti santrāsāddharmaṃ lokaparāyaṇam||
// 8-85-53 //
全ての生き物が死を恐れて法（ダルマ）に、世界の拠り所に身を寄せるように——
tathā karṇaṃ maheṣvāsaṃ putrāstava narādhipa|
upālīyanta santrāsātpāṇḍavasya mahātmanaḥ||
// 8-85-54 //
汝の息子たちは、偉大なパーンダヴァへの恐怖から、大弓持ちのカルナに身を寄せた。
tāñśoṇitapariklinnānviṣamasthāñśarāturān|
mā bhaiṣṭetyabravītkarṇo bhītānāviṣṭacetasaḥ||
// 8-85-55 //
血にまみれ、困難な状況にあり、矢に苦しむ彼らに、カルナは「恐れるな」と言った。恐怖に取り憑かれ意気消沈した者たちに。
sambhagnaṃ hi balaṃ dṛṣṭvā balātpārthena tāvakam|
dhanurvisphārayankarṇastasthau śatrujighāṃsayā||
// 8-85-56 //
汝の軍がアルジュナの力で崩壊するのを見て、カルナは弓を引き絞り、敵を殺す決意で立った。
tānpradrutānkurūndṛṣṭvā karṇaḥ śastrabhṛtāṃ varaḥ|
sañcintayitvā pārthasya vadhe dadhre manaḥ śvasan||
// 8-85-57 //
逃げるクル族を見て、武器持ちの中の最上者カルナは、アルジュナの討伐に心を定め、思い巡らし、息を荒くした。
visphārya sumahaccāpaṃ tataścādhirathirvṛṣaḥ|
pāñcālānpunarādhāvatpaśyataḥ savyasācinaḥ||
// 8-85-58 //
その大いなる弓を引き絞り、アディラタの子（カルナ）は、サヴャサーチン（アルジュナ）の目の前で再びパーンチャーラ族に突撃した。
tataḥ kṣaṇena kṣitipāḥ kṣatajapratimekṣaṇāḥ|
śaraughaiśchādayāmāsurmahāmeghā ivācalam||
// 8-85-59 //
そして一瞬にして、血のような目をした王たちは、大いなる雲が山に降り注ぐように、矢の群れでカルナを覆った。
tataḥ śarasahasrāṇi karṇamuktāni māriṣa|
pāñcālānāṃ haratprāṇāṃstamāṃsīva tamonudaḥ||
// 8-85-60 //
カルナが放った何千もの矢は、闇を払う太陽のように、パーンチャーラ族の命を奪った。
mahadāsīttadā yuddhaṃ pāñcālānāṃ mahāmate|
vadhyatāṃ sūtaputreṇa mitrārthe mitragṛddhinā||
// 8-85-61 //
パーンチャーラ族がスータの子に殺される大いなる戦いがそこにあった。友のために友を求めて戦う者によって。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe pañcāśītitamo'dhyāyaḥ|| 85 ||
