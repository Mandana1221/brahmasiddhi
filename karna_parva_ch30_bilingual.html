Mahābhārata — Karṇaparvan, Adhyāya 30 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ30」（シャリヤが御者となった戦車にカルナが乗り、戦場へ出陣する場面。出発前にドゥルヨーダナがカルナに激励の言葉をかけ、カルナとシャリヤの間でアルジュナ・ビーマセーナら パーンダヴァ勢への強がりと挑発の言葉が交わされる）です。各段落は原典の詩節番号（8-30-N）と和訳の段落番号が対応しています。
karṇaparva — triṃśo'dhyāyaḥ (30)
第30章　シャリヤが御者となった戦車に乗り、カルナが戦場へ出陣する
duryodhana uvāca|
ayaṃ te karṇa sārathyaṃ madrarājaḥ kariṣyati|
kṛṣṇād abhyadhiko yantā deveśasya iva mātaliḥ|| // 8-30-1 //
ドゥルヨーダナは語った。 （1）「カルナよ、このマドラ王がお前の御者を務めてくれる。クリシュナよりも優れた御者だ——天の神の王（インドラ）にとってのマータリのように。
yathā harihayair yuktaṃ saṅgṛhṇāti sa mātaliḥ|
śalyas tathā tava adya ayaṃ saṃyantā rathavājinām|| // 8-30-2 //
（2）マータリがインドラの緑の馬に繋がれた戦車を御するように、シャリヤも今日、お前の戦車の馬を御してくれるだろう。
yodhe tvayi rathasthe ca madrarāje ca sārathau|
rathaśreṣṭho dhruvaṃ saṅkhye pārthān abhibhaviṣyati|| // 8-30-3 //
（3）お前が戦車に乗り、マドラ王が御者となれば、戦場で最上の戦車は必ずパーンダヴァたちを圧倒するだろう。」
sañjaya uvāca|
tato duryodhano bhūyo madrarājaṃ tarasvinam|
uvāca rājan saṅgrāme'dhyuṣite paryupasthite|| // 8-30-4 //
サンジャヤは語った。 （4）そしてドゥルヨーダナは再び、勇猛なるマドラ王に語りかけた、王よ。夜明けが来て戦いが近づいた時に——
karṇasya yaccha saṅgrāme madrarāja hayottamān|
tvayā'bhigupto rādheyo vijeṣyati dhanañjayam|| // 8-30-5 //
（5）「マドラ王よ、戦場でカルナのために最上の馬の手綱を取ってくれ。お前に守られたラーデーヤは、ダナンジャヤ（アルジュナ）を打ち負かすだろう。」
ityukto ratham āsthāya tatheti prāha bhārata|
śalye'bhyupagate karṇaḥ sārathiṃ sumanā'bravīt|| // 8-30-6 //
（6）こう言われて戦車に乗り、「そのようにしよう」と答えた、バーラタよ。シャリヤが引き受けたことを知り、カルナは喜んで御者にこう言った。
tvaṃ sūta syandanaṃ mahyaṃ kalpaya ity asakṛt tvaran|| // 8-30-7 //
（7）「御者よ、私のために戦車を速やかに用意せよ」と急かしながら何度も。
tato jaitraṃ rathavaraṃ gandharvanagaropamam|
vidhivat kalpitaṃ bhadraṃ jaya ity uktvā nyavedayat|| // 8-30-8 //
（8）すると御者は、勝利をもたらす最上の戦車——ガンダルヴァの都市のように美しい戦車を、しかるべく用意し、「勝利あれ」と告げて差し出した。
taṃ rathaṃ rathināṃ śreṣṭhaḥ karṇo'bhyarcya yathāvidhi|
sampāditaṃ brahmavidā pūrvameva purodhasā|| // 8-30-9 //
（9）戦車戦士の中の最上者カルナは、しかるべくその戦車を供養した。ヴェーダに通じた祭官によってあらかじめ祝福された戦車を。
kṛtvā pradakṣiṇaṃ yatnād upasthāya ca bhāskaram|
samīpasthaṃ madrarājam āroha tvam atha abravīt|| // 8-30-10 //
（10）右回りに回り、苦心して太陽神を拝んでから、近くにいたマドラ王に「さあ乗ってくれ」と言った。
tataḥ karṇasya durdharṣaṃ syandanapravaraṃ mahat|
āruroha mahātejāḥ śalyaḥ siṃha iva acalam|| // 8-30-11 //
（11）すると大いなる威光のシャリヤは、打ち負かし難きカルナの最上の大戦車に、獅子が山に登るように乗り込んだ。
tataḥ śalyāśritaṃ dṛṣṭvā karṇaḥ svaṃ ratham uttamam|
adhyatiṣṭhad yathā'mbhodaṃ vidyutvantaṃ divākaraḥ|| // 8-30-12 //
（12）シャリヤが乗り込んだ自分の最上の戦車を見て、カルナもまたそこに立った——太陽が稲妻に満ちた雲の上に立つように。
tau ekaratham ārūḍhāv ādityāgnisamatviṣau|
abhrājetāṃ yathā meghaṃ sūryāgnī sahitau divi|| // 8-30-13 //
（13）一つの戦車に乗った二人は、太陽と火のような輝きを放ち、空に太陽と火が雲の上に並んでいるように光り輝いた。
saṃstūyamānau tau vīrau tadā āstāṃ dyutimattamau|
ṛtviksadasyair indrāgnī stūyamānāv iva adhyare|| // 8-30-14 //
（14）讃えられるその二人の輝ける勇者は、祭式で祭官と列席者に讃えられるインドラとアグニのようであった。
sa śalyasaṅgṛhītāśve rathe karṇaḥ sthito babhau|
dhanur viṣphārayan ghoraṃ pariveṣī iva bhāskaraḥ|| // 8-30-15 //
（15）シャリヤが手綱を取る馬の戦車に立つカルナは、恐るべきガーンディーヴァを引き絞りながら、光輪をまとった太陽のように輝いた。
āsthitaḥ sa rathaśreṣṭhaṃ karṇaḥ śaragabhastimān|
prababhau puruṣavyāghro mandarastha iva aṃśumān|| // 8-30-16 //
（16）最上の戦車に乗り、矢を光線としたカルナ、人の中の虎は、マンダラ山に立つ太陽のように光り輝いた。
taṃ rathasthaṃ mahābāhuṃ yuddhāyāmitatejasam|
duryodhanas tu rādheyam idaṃ vacanam abravīt|| // 8-30-17 //
（17）大いなる腕を持ち、計り知れない威光を持つラーデーヤが戦車に立って戦いに臨む姿を見て、ドゥルヨーダナはこう言いました。
akṛtaṃ droṇabhīṣmābhyāṃ duṣkaraṃ karma saṃyuge|
kuruṣva adhirathe vīra miṣatāṃ sarvadhanvinām|| // 8-30-18 //
（18）「アディラタの子（カルナ）よ、ドローナとビーシュマがなし得なかった困難な業を、すべての弓の達人たちが見ている前で、勇者よ、成し遂げてくれ。
manogataṃ mama hy āsīd bhīṣmadroṇau mahārathau|
arjunaṃ bhīmasenaṃ ca nihantārāv iti dhruvam|| // 8-30-19 //
（19）私はかつて心の中で、偉大な戦車戦士であるビーシュマとドローナが必ずやアルジュナとビーマセーナを殺してくれると思っていた。
tābhyāṃ yad akṛtaṃ vīra vīrakarma mahāmṛdhe|
tatkarma kuru rādheya vajrapāṇir iva aparaḥ|| // 8-30-20 //
（20）勇者よ、あの二人が大戦闘でなし得なかった勇者の業を、ラーデーヤよ、なし遂げてくれ。もう一人の金剛杵を持つインドラのように。
gṛhāṇa dharmarājaṃ vā jahi vā tvaṃ dhanañjayam|
bhīmasenaṃ ca rādheya mādrīputrau yamāv api|| // 8-30-21 //
（21）ダルマ王（ユディシュティラ）を捕らえるか、ダナンジャヤ（アルジュナ）を殺すか——ラーデーヤよ、ビーマセーナも、マードリーの双子の息子たちも。
jayaś ca te'stu bhadraṃ te prayāhi puruṣarṣabha|
pāṇḍuputrasya sainyāni kuru sarvāṇi bhasmasāt|| // 8-30-22 //
（22）勝利あれ、幸運あれ。出発せよ、人の中の雄牛よ。パーンドゥの子の軍勢をすべて灰燼に帰せしめよ。」
tatas tūryasahasrāṇi bherīṇāmayutāni ca|
vādyamānāny arocanta meghaśabdo yathā divi|| // 8-30-23 //
（23）すると何千もの喇叭と何万もの太鼓が鳴り響き、天の雷鳴のような音が轟いた。
pratigṛhya tu tadvākyaṃ rathastho ratharuttamaḥ|
abhyabhāṣata rādheyaḥ śalyaṃ yuddhaviśāradam|| // 8-30-24 //
（24）この言葉を受けて、戦車に乗った最上の戦車戦士ラーデーヤ（カルナ）は、戦に精通したシャリヤに語りかけた。
codaya aśvān mahābāho yāvad vanmi dhanañjayam|
bhīmasenaṃ yamau ca ubhau rājānaṃ ca yudhiṣṭhiram|| // 8-30-25 //
（25）「大いなる腕の者よ、馬を走らせてくれ。私がダナンジャヤ（アルジュナ）を殺すまで。ビーマセーナも、双子も、ユディシュティラ王も。
adya paśyatu me śalya bāhuvīryaṃ dhanañjayaḥ|
asyataḥ kaṅkapatrāṇāṃ sahasrāṇi śatāni ca|| // 8-30-26 //
（26）今日、シャリヤよ、我が両腕の武勇をアルジュナに見せてやろう。鷲の羽根のついた矢を何千何百と放つ者の武勇を。
adya kṣepsyāmy ahaṃ śalya śarān paramatejanān|
pāṇḍavānāṃ vināśāya duryodhanajayāya ca|| // 8-30-27 //
（27）今日、シャリヤよ、最も鋭い矢を放とう。パーンダヴァの破滅のために、ドゥルヨーダナの勝利のために。」
sañjaya uvāca|
etac chrutvā vacas tasya śalyaḥ karṇaṃ vaco'bravīt|
kathaṃ nu tān mahāvīryān pāṇḍavān avamanyase|| // 8-30-28 //
サンジャヤは語った。 （28）カルナのこの言葉を聞いて、シャリヤはカルナに言った。「いったいどうして、あの偉大な武勇を持つパーンダヴァたちを侮ることができるのか。
sarvāstrajñān maheṣvāsān sarvān ena mahābalān|
anivartino mahābhāgān ajayyān satyavikramān|
api sañjanayeyur ye bhayaṃ sākṣāc chatakratoḥ|| // 8-30-29 //
（29）すべての武器を知る偉大な弓の達人、大いなる力、不退転、大いなる幸運、不可征の、真の武勇を持つ者たち——インドラすら恐れさせうる者たちを。
yadā śroṣyasi nirghoṣaṃ visphūrjitam iva aśaneḥ|
rādheya pārthadhanuṣas tadā naivaṃ vadiṣyasi|| // 8-30-30 //
（30）ラーデーヤよ、雷鳴のようなパールタの弓の轟きを聞いた時、お前はそのようなことは言わなくなるだろう。
yadā drakṣyasi bhīmena kuñjarānīkam āhave|
viśīrṇadantaṃ nihataṃ tadā naivaṃ vadiṣyasi|| // 8-30-31 //
（31）ビーマが戦場で象の軍団を——牙を折り、打ち倒すのを見た時、お前はそのようなことは言わなくなるだろう。
yadā drakṣyasi saṅgrāme dharmaputraṃ yamau tathā|
śitaiḥ pṛṣatkaiḥ kurvāṇān abhracchāyām iva ambare||
asyataḥ kṣiṇvataś ca arīn laghuhastān durāsadān|
pārthivāg api ca anyāṃs tvaṃ tadā naivaṃ vadiṣyasi|| // 8-30-32-33 //
（32〜33）ダルマの子（ユディシュティラ）と双子（ナクラ・サハデーヴァ）が、戦場で鋭い矢を放ち、空を雲のように覆い、軽い手さばきで近づき難い敵を射ち滅ぼし——そしてまた他の王たちも見た時、お前はそのようなことは言わなくなるだろう。」
sañjaya uvāca|
anādṛtya tu tadvākyaṃ madrarāje bhāṣitam|
drakṣyasi adya iti avocat taṃ śalyaṃ karṇo janeśvara|| || // 8-30-34 //
サンジャヤは語った。 （34）しかしカルナはマドラ王のこの言葉を意に介さず、「今日見届けるがよい」とシャリヤに言ったのでした、王よ。
iti śrīmanmahābhārate karṇaparvaṇi triṃśo'dhyāyaḥ|| 30 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十章は終わる。
