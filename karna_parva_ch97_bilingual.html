マハーバーラタ ― カルナ篇 第97章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 97 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ97」で、ナーガ・アシュヴァセーナの矢の場面、カルナの戦車の車輪が大地に沈む場面を描きます。
karṇaparva — saptanavatitamo'dhyāyaḥ (97)
第97章 ― ナーガ・アシュヴァセーナの矢、カルナの車輪が大地に沈む
sañjaya uvāca|
tato'payātāḥ śarapātamātramavasthitā vai kuravo narendra|
vidyutprakāśaṃ dadṛśuḥ samantādvanañjayāstraṃ samudīryamāṇam||
// 8-97-1 //
サンジャヤは語った。
矢の射程ほどの距離に退いたクル勢は、稲妻のように輝くダナンジャヤの武器が発動されるのを四方に見た。
tato'grasatsūtaputro'rjunasya viyadgataṃ ghorataraṃ śaraistat|
kruddhena pārthena śaraṃ visṛṣṭaṃ vadhāya karṇasya mahāvimarde||
udīryamāṇaṃ sma kurūndahantaṃ suvarṇapuṅkhairviśikhairmamarda|
karṇastvamogheṣvasanaṃ dṛḍhajyaṃ visphārayitvā visṛjañcharoghān||
rāmādupāttena mahāmahimnā hyātharvaṇenārivināśanena|
tadarjunāstraṃ vyadhamaddahantaṃ pārthaṃ ca bāṇairniśitairavidhyat||
// 8-97-2-4 //
スータの息子はアルジュナの恐ろしい天を飛ぶ矢を、自らの矢で飲み込んだ。怒ったパールタがカルナを討つために大激戦の中で放った矢を。パラシュラーマ（ラーマ）から授かった偉大なる威力のアタルヴァナの敵を滅ぼす武器で、燃え上がるアルジュナの武器を打ち破り、鋭い矢でパールタを射た。
tato vimardaḥ sumahānbabhūva tatrārjunasyādhiratheśca rājan|
anyonyamāsādayatoḥ pṛṣatkairviṣāṇaghātairdvipayorivājau||
tato'strasaṅghātasamāvṛtaṃ tadā babhūva rājaṃstumulaṃ raṇājiram|
yatkarṇapārthau śaravṛṣṭisaṅghairnirantaraṃ cakraturambaraṃ tadā||
// 8-97-5-6 //
王よ、アルジュナとアディラティ（カルナ）の激しい戦いが起こった。矢でぶつかり合う姿は、牙で打ち合う二頭の象のようであった。武器の集積で覆われた戦場は恐ろしいものとなった。カルナとパールタが矢の雨の群れで途切れなく天空を覆ったためだ。
tato jālaṃ bāṇamayaṃ mahāntaṃ sarve'drākṣuḥ kuravaḥ somakāśca|
nānyaṃ ca bhūtaṃ dadṛśustadā te bāṇāndhakāre tumule'tha kiñcit||
tau sandadhānāvaniśaṃ ca rājan|
samasyantau cāpi śarānanekān|
sandarśayetāṃ yudhi mārgānvicitrāndhanurdharau tau vividhaiḥ kṛtāstraiḥ||
tayorevaṃ yudhyatorājimadhye sūtātmajo'bhūdadhikaḥ kadācit|
pārthaḥ kadācittvadhikaḥ kirīṭi vīryāstramāyābalapauruṣeṇa||
// 8-97-7-9 //
両軍ともに矢の大きな網を見た。矢の暗闇の中で恐ろしいほど何も見えなくなった。二人は絶え間なく弦にかけ、何本もの矢を同時に放ち、さまざまな武器の技を見せた。時にはスータの子（カルナ）が優勢となり、時にはキリーティン（パールタ）が武勇・武器・策略・力・男気において優勢となった。
dṛṣṭvā tayostaṃ yudhi samprahāraṃ parasparasyāntaramīkṣamāṇayoḥ|
ghoraṃ tayordurviṣahaṃ raṇe'nyairyodhāḥ sarve vismayamabhyagacchan||
tato bhūtānyantarikṣasthitāni tau karṇapārthau praśaśaṃsurnarendra|
bhoḥ karṇa sādhvarjuna sādhu ceti viyatsu vāṇī śrūyate sarvatopi||
// 8-97-10-11 //
互いの隙を探りながらの恐ろしい戦いを見て、他の者たちには耐えがたいその光景に、すべての兵士が驚嘆した。天空の生きものたちがカルナとパールタの二人を称えた。「おお、カルナよ、見事！ アルジュナよ、見事！」という声が天空のあらゆる方角から聞こえた。
tasminvimarde rathavājināgaistadā'bhighātairdalite hi bhūtale|
tatastu pātālatale śayāno nāgo'śvasenaḥ kṛtavairo'rjunena||
rājaṃstadā khāṇḍavadāhamukto viveśa kopādvasudhātale yaḥ|
athotpapātordhvagatirjavena sandṛśya karṇārjunayorvimardam||
ayaṃ hi kālosya durātmano vai pārthasya vairapratiyātanāya|
sañcintya tūrṇaṃ praviveśa caiva karṇasya rājanśararūpadhārī||
// 8-97-12-14 //
戦車・馬・象の踏みつけで大地が砕かれたその時、地底に横たわっていたナーガ（蛇）のアシュヴァセーナが、アルジュナに恨みを持つ者として地の底から現れた。王よ、かつてカーンダヴァの森の大火の時に逃れたこの蛇が、怒りから大地の底に入っていたのだ。カルナとアルジュナの激戦を見て、勢いよく上に飛び出した。「今こそ、あの邪悪なパールタに恨みを晴らす時だ」と素早く考え、矢の姿をとってカルナの矢に入り込んだ。
tatostrasaṅghātasamākulaṃ tadā babhūva janyaṃ vitatāṃśujālam|
tatkarṇapārtho śarasaṅghavṛṣṭibhirnirantaraṃ cakraturambaraṃ tadā||
tadbāṇajālaikamayaṃ mahāntaṃ sarve'trasankuravaḥ somakāśca|
nānyatkiñciddadṛśuḥ sampatadvai bāṇāndhakāre tumule'timātram||
tatastau puruṣavyāghrau sarvalokadhanurdharau|
tyaktaprāṇau raṇe vīro yuddhaśramamupāgatau||
samutkṣepairvīkṣamāṇau siktau candanavāriṇā|
savālavyajanairdivyairdivisthairapsarogaṇaiḥ|
śakrasūryakarābjābhyāṃ pramārjitamukhāvubhau||
karṇo'tha pārthaṃ na viśeṣayadyadā bhṛśaṃ ca pārthena śarābhitaptaḥ|
tatastu vīraḥ śaravikṣatāṅgo dadhre mano hyekaśayasya tasya||
// 8-97-15-19 //
武器の集積で覆われた戦場は、矢の雨の群れで途切れなく天空を覆い尽くされた。命を捨てて戦う二人の人中の虎、世界最高の弓の使い手は、戦闘の疲労に達した。額の汗を拭い、白檀の水を振りかけられ、ヤクの尾の扇で仰がれ、天にいるアプサラスの群れによって。インドラと太陽の手の蓮で顔を拭われた二人。カルナがパールタに勝てず、パールタの矢に激しく苦しめられた時、矢で全身を傷つけられた勇者カルナは、あの一本の矢（ナーガストラ）に心を定めた。
tato ripughnaṃ samadhatta karṇaḥ susañcitaṃ sarpamukhaṃ jvalantam|
raudraṃ śaraṃ sannatamugradhautaṃ pārthārthamityeva cirābhiguptam||
sadārcitaṃ candanacūrṇaśāyitaṃ suvarṇatūṇīraśayaṃ mahārciṣam|
ākarṇapūrṇaṃ vicakarṣa karṇo vimoktukāmaḥ śaramugravegam||
// 8-97-20-21 //
そこでカルナは、敵を殺す、よく準備された、蛇の頭を持ち燃え輝く、恐ろしい矢を、研ぎ澄まされたものを取り出した。パールタのためにと長い間大切にしてきたものを。常に白檀の粉の上に寝かされ、黄金の矢筒に収められた大いなる輝きの矢を、カルナは耳まで引き絞った。恐ろしい速度のこの矢を放とうとして。
pradīptamairāvatavaṃśasambhavaṃ śiro jihīrṣuryudhi savyasācinaḥ|
tataḥ prajajvāla diśo nabhaśca ulkāśca ghorāḥ śataśaḥ prapetuḥ||
// 8-97-22 //
燃え輝くアイラーヴァタの血統から生まれたこの矢は、戦場でサヴヤサーチン（アルジュナ）の首を取ろうとしていた。すると四方と天空が燃え上がり、恐ろしい流星が数百も落ちた。
tasmiṃstu nāge dhanuṣi prayukte hāhākṛtā lokapālāḥ saśakrāḥ||
// 8-97-23 //
この蛇が弓に番えられると、インドラを先頭にロカパーラ（世界の守護者）たちが「ああ！」と嘆いた。
sa sūtaputrastamapāṅgadeśe avāṅmukhaṃ sandhayati sma roṣāt|
na taṃ sma jānāti mahānubhāvamapāṅgadeśe'bhiniviṣṭamājau||
na cāpi taṃ bubudhe sūtaputro bāṇe praviṣṭaṃ yogabalena nāgam|
daśaśatanayano'hiṃ dṛśya bāṇe praviṣṭaṃ nihata iti suto me srastagātro babhūva|
jalajakusumayoniḥ śreṣṭhabhāvo jitātmā tridaśapatimavocanmā vyathiṣṭhā jaye śrīḥ||
// 8-97-24-25 //
スータの息子はこの矢を弦の端に逆さまに怒りをもって番えた。しかし戦場で矢の端に入り込んだ偉大な存在（蛇のアシュヴァセーナ）のことに気づかなかった。十の目を持つインドラは矢に入った蛇を見て、「息子（アルジュナ）が殺される」と体の力が抜けたが、蓮から生まれた者（ブラフマー）は偉大なる存在として自らを制し、三十三神の王に言った。「恐れるな。勝利の栄光はある。」
tato'bravīnmadrarājo mahātmā dṛṣṭvā karṇaṃ prahiteṣu tamugram|
grīvāyataḥ karṇa na saṃhito'yaṃ samīkṣya sandhatsva śaraṃ paraghnam||
// 8-97-26 //
するとマドラ王（シャリヤ）が、カルナが恐ろしい矢を構えるのを見て言った。「カルナよ、この矢は首の高さに合っていないぞ。よく狙ってから矢を放て、敵を討つ者よ。」
athābravītkrodhasaṃraktanetro madrādhipaṃ sūtaputro manasvī|
na sandhatte dviḥ śaraṃ śalya karṇo na mādṛśā jihmayudvā bhavanti||
// 8-97-27 //
カルナは怒りで目を赤くして、マドラの王にこう言った。「シャリヤよ、カルナは二度同じ矢を番えることはしない。私のような者は卑怯な戦い方はしない。」
itīdamuktvā visasarja taṃ śaraṃ prayatnato varṣagaṇābhipūjitam|
hatosi re phalguna ityadhikṣipannuvāca coccairniramūrjitāṃ vṛṣaḥ||
// 8-97-28 //
こう言ってから、何年もの間崇拝してきたその矢を、全力で放った。「おまえは死んだぞ、アルジュナ！」と大声で叫びながら、力あふれる雄牛のように放った。
sa sāyakaḥ karṇabhujaprasṛṣṭo hutāśanārkapratimaḥ sughoraḥ|
guṇacyutaḥ karṇadhanuḥpramukto viyadgataḥ prājvaladantarikṣe||
// 8-97-29 //
カルナの腕から放たれたその矢は、火と太陽に等しく輝き、恐ろしく、弓弦から放たれて天空を飛び、虚空で燃え上がった。
tamāpatantaṃ jvalitaṃ nirīkṣya viyadgataṃ vṛṣṇikulapravīraḥ|
rathasya cakraṃ sahasā nipīḍya pañcāṅgulaṃ majjayati sma vīraḥ||
// 8-97-30 //
その燃え輝く矢が飛来するのを見て、ヴリシュニ族の英雄（クリシュナ）は、素早く戦車の車輪を足で踏み込み、五指分だけ大地に沈めた。
tato'ntarikṣe sumahānninādaḥ sampūjanārthaṃ madhusūdanasya|
divyāśca vācaḥ sahasā babhūvurdivyāni puṣpāṇyatha siṃhanādāḥ|
tasmiṃstathā vai dharaṇīṃ nimagne rathe prayatnānmadhusūdanasya||
// 8-97-31 //
すると天空で大きな歓声が上がり、マドゥスーダナ（クリシュナ）を称えた。クリシュナの努力により戦車が大地に沈んだその時に。
tataḥ kirīṭaṃ bahuratnacitraṃ jaghāna nāgo'rjunamūrdhato balāt|
gireḥ sujātāṅkurapuṣpitadrumaṃ mahendravajraṃ śikharaṃ yathottamam||
tataḥ kirīṭaṃ tapanīyacitraṃ pārthottamāṅgādaharattarasvī|
taddhemajālāvanataṃ sughoraṃ samprajvalattannipapāta bhūmau||
// 8-97-32-33 //
蛇の矢はアルジュナの頭頂部から輝かしい多宝石の冠を力ずくで打ち落とした。山の頂にある美しい芽吹きの樹を、インドラの雷が打つように。素早い蛇がパールタの頭から黄金で飾られた冠を奪い取った。恐ろしく燃え上がるその冠は地上に落ちた。
tato'rjunasyottamagātrabhūṣaṇaṃ suvarṇamuktāmaṇivajracitritam|
dharāviyaddyosalileṣu viśrutaṃ balaṃ nisargottamamanyudhiḥ sadā||
śareṇa mūrdhni prajahāra sūtajo divākarendujvalanagrahatviṣam|
suvarṇamuktāmaṇivajrabhūṣaṇaṃ purandarārthaṃ tapasā prayatnataḥ||
svayaṃ kṛtaṃ yadvidhinā svayambhuvā mahārharūpaṃ dviṣatāṃ bhayaṅkaram|
nijaghnate devaripūnsureśvaraḥ svayaṃ dadau yaddhi mudā'rjunāya||
haripracetoharivittagoptṛbhiḥ pinākapāśāśanidaṇḍadhāribhiḥ|
surottamairapyaviṣahyamardituṃ prasahya nāgena jahāra tadvṛṣā||
taduttameṣūnmathitaṃ viṣāhinā pradīptamarciṣmadatīva sundaram|
papāta pārthasya kirīṭamuttamaṃ divākarostādiva parvatājjvalan||
mahīviyaddyosalilāni vāyunā prasahya rugṇāni vighūrṇitāni vā|
itīva śabdaṃ bhuvaneṣu tattathā janā vyavasyanti diśaśca vihvalāḥ||
// 8-97-34-39 //
そしてアルジュナの最高の体の飾り、黄金・真珠・宝石・ダイヤモンドで飾られた、大地・天空・天界・水中で名高い冠が、矢により頭頂から落ちた。太陽・月・火のような輝きを持つ黄金・真珠・宝石・ダイヤモンドの飾りの冠、インドラのために苦行をもってスヴァヤンブー（ブラフマー）自身が作った大いなる価値の冠、敵に恐怖を与える冠、インドラ自身が喜んでアルジュナに与えた冠が。ハリ（ヴィシュヌ）、プラチェータス（ヴァルナ）、ハリヴィッタゴープトリ（クベーラ）、ピナーカ（シヴァ）、パーシャ（ヴァルナ）、アシャニ（インドラ）、ダンダ（ヤマ）を持つ最高の神々にさえ破壊しがたかったものを、蛇の力で雄牛（カルナ）が奪い取ったのだ。最高の矢で打ち落とされた毒蛇による輝かしく美しい冠は、パールタの頭から落ちた。沈む太陽が山から落ちるように燃えながら。大地・天空・天界・水が風によって砕かれ揺さぶられたかのような音が世界中に響いた。
vinā kirīṭaṃ* śuśubhe sa pārthaḥ śyāmo yuvā śaila triśṛṅgaiḥ||
tataḥ samudgrathya sitena vāsasā svamūrdhajanāvyathitastadā'rjunaḥ|
babhau susampūrṇamarīcinendunā śirogatenodayaparvato yathā||
// 8-97-40-41 //
冠を失ったパールタは、黒い肌の若者として、高い峰を持つ山のように輝いた。白い布で頭髪を結び直し、動じることなく、満月の光が頭上にある東の山のように輝いた。
sa cāpi rādheyabhujapramukto hutāśanārkapratimadyutirmahān|
mahoragaḥ kṛtavairo'rjunena kirīṭamāhṛtya samutpapāta||
tamutpatantaṃ dvipadāṃ variṣṭho dṛṣṭvā vacaḥ pārthamuvāca kṛṣṇaḥ|
mahoragaṃ pāṇḍava paśyapaśya prayojitaṃ tvannidhanārthamugram||
sa evamukto madhusūdanena gāṇḍīvadhanvā harimugravācā|
uvāca ko nveṣa mamādya nāgaḥ kṣayāya nāgādgaruḍasya vakram||
kṛṣṇa uvāca|
yo'sau tvayā khāṇḍave citrabhānuṃ santarpayāṇena dhanurdhareṇa|
viyadgato jananīguptadeho matvaikarūpaṃ nihatā'sya mātā||
sa eṣa tadvairamanusmaranvai tvāṃ prārthayatyātmavadhāya nūnam|
nabhaścutāṃ prajvalitāmivolkāṃ paśyainamāyāntamamitrasāha||
sañjaya uvāca|
tataḥ sa jiṣṇuḥ parivṛtya roṣācciccheda ṣaḍbhirniśitaiḥ sudhāraiḥ|
nāgaṃ viyattiryagivotpatataṃ sa cchinnagātro nipapāta bhūmau||
// 8-97-42-47 //
ラーデーヤの腕から放たれた、火と太陽に等しい輝きを持つ偉大な蛇は、アルジュナに恨みを持つ大蛇であったが、冠を奪い取って飛び上がった。二足の者の中の最良者クリシュナが、飛び上がるその蛇を見てパールタに言った。「パーンダヴァよ、見よ、おまえを殺すために放たれた恐ろしい大蛇を。」 マドゥスーダナにこう言われたガーンディーヴァの弓の持ち主アルジュナは、恐ろしい声の主ハリ（クリシュナ）にこう問うた。「今日、私に向かってくるこの蛇は何者か。ガルダの口に向かう蛇のような奴は。」 クリシュナは言った。「かつてカーンダヴァの森で、おまえが弓を持ってチトラバーヌ（火神アグニ）を満足させた時、母に体を守られて天に逃れた蛇がいた。おまえは一つの姿だと思って母を殺したが、こいつはその恨みを覚えており、おまえを殺そうとしているのだ。天から落ちてくる燃える流星のように迫りくるこの敵を見よ。」 サンジャヤは語った。 そこでジシュヌ（アルジュナ）は怒りに身を翻し、六本の鋭い刃の矢で、天空を横切って飛ぶ蛇を切り裂いた。体を切り裂かれた蛇は大地に落ちた。
gate ca tasminbhujage kirīṭinā svayaṃ vibhuḥ pārthiva bhūtalādatha|
samujjahārāśu punaḥ patantaṃ rathaṃ bhujābhyāṃ puruṣottamastataḥ||
// 8-97-48 //
蛇が退いた後、主（クリシュナ）は大地から沈みかけた戦車を、両腕で素早く持ち上げた。
tasminmuhūrte daśabhiḥ pṛṣatkaiḥ silāśitairbarhiṇabarhavājitaiḥ|
vivyādha karṇaḥ puruṣapravīro dhanañjayaṃ tiryagavekṣamāṇaḥ||
// 8-97-49 //
その瞬間、カルナは十本の孔雀の羽をつけた石で研いだ矢で、横を向いているダナンジャヤを射た。
tato'rjuno dvādaśabhiḥ sumuktairvarāhakarṇairjiśitaiḥ samarpya|
nārācamāśīviṣatulyavegamākarṇapūrṇāyatamutsasarja||
sa citravarmeṣuvaro vidārya prāṇānnirasyanniva sādhumuktaḥ|
karṇasya pītvā rudhiraṃ viveśa vasundharāṃ śoṇitadigdhavājaḥ||
// 8-97-50-51 //
アルジュナは十二本の見事に放たれた猪の耳の矢を浴びせた後、毒蛇のような速度の鉄の矢を、耳まで引き絞って放った。その矢は美しい鎧を貫き、命を奪うかのように見事に放たれ、カルナの血を飲んで大地に入った。血に染まった羽をつけて。
tato vṛṣo bāṇanipātakopito mahorago daṇḍavighaṭṭito yathā|
tadā''śukārī vyasṛjaccharottamān mahāviṣaḥ sarpa ivottamaṃ viṣam||

興奮したアルジュナを見て、カルナはこう言った。「おいおい、パールタよ、偉大なる射手よ、しばし待ってくれ。この大地に飲み込まれた車輪を引き上げるまで。左の車輪が運命によって大地に沈んだのを見てくれ、パールタよ。卑怯者のやり口を捨ててくれ。おまえは卑怯者の道を歩むべきではない。カウンテーヤよ、おまえは戦いの技で名高い者だ。パーンダヴァよ、もっと立派なことをしてくれ。髪を乱した者、背を向けた者、バラモン、合掌した者、降伏した者、武器を捨てた者、命乞いする者に対して、戦士の正しい掟に立つ勇者は武器を放たない。おまえはこの世で最も勇敢で、正しい行いの者だ、パーンダヴァよ。戦いのダルマを知る者よ、だからほんのしばらくだけ待ってくれ。この大地に飲み込まれた車輪を引き上げる間だけ、大いなる腕の主よ。戦車に乗った者が地上に降りて苦しむ者を討つべきではない。私はヴァースデーヴァにもおまえにも、パーンダヴァよ、恐れはしない。おまえはクシャトリヤの正統な後継者であり、偉大な一族を栄えさせる者だ。だからこそ頼むのだ。パーンダヴァよ、しばし待ってくれ。」
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe saptanavatitamo'dhyāyaḥ|| 97 ||
こうして、聖なる大マハーバーラタのカルナ篇の第97章は終わる。
