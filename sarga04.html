kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

caturthaḥ sargaḥ ― 第四章

道中の描写：秋の自然と牧畜生活の叙景（1-19）。ヤクシャの言葉：秋の情景を讃え、自然の美を詠む（20-36）。山の遠望とバラーラーマの想起（37-38）。
1
Sanskrit
tataḥ sa kūjatkalahaṃsamekhalāṃ sapākasasyāhitapāṇḍutāguṇām / upāsasādopajanaṃ janapriyaḥ priyām ivāsāditayauvanāṃ bhuvam //
Vaṃśastha
和訳
かくして人々に愛されるその人（アルジュナ）は、鳴き交わす白鳥を帯のように纏い、熟した穀物により黄金色の美質を帯びた大地へと赴いた。あたかも若さの盛りを迎えた恋人のもとへ向かうかのように。

kalahaṃsamekhalā（白鳥を帯とする）は大地を女性に見立てた比喩。upajana は「人々の近くへ」の意（マッリナータ注では「侍女たちの前へ」とも解する）。

2
Sanskrit
vinamraśāliprasavaughaśālinīr apetapaṅkāḥ sasaroruhāmbhasaḥ / nananda paśyann upasīma sa sthalīr upāyanībhūtaśaradguṇaśriyaḥ //
Vaṃśastha
和訳
畦道のあたりで、頭を垂れる稲穂の豊かな実りに輝き、泥の去った蓮池を湛える野を見て、彼は喜びを覚えた。秋の美徳と美しさが、あたかも彼への贈り物となったかのように。
3
Sanskrit
nirīkṣyamāṇā iva vismayākulaiḥ payobhir unmīlitapadmalocanaiḥ / hṛtapriyādṛṣṭivilāsavibhramā mano 'sya jahruḥ śapharīvivṛttayaḥ //
Vaṃśastha
和訳
驚きに満ちた水が蓮の花の目を見開いて見つめるかのごとく、恋人のまなざしの媚態を模して跳ねる魚の動きが、彼の心を奪った。

蓮の花を水の目に見立て、魚の跳ねを恋する女の流し目になぞらえた複合比喩。

4
Sanskrit
tutoṣa paśyan kalamasya so 'dhikaṃ savārije vāriṇi rāmaṇīyakam / sudurlabhe nārhati ko 'bhinandituṃ prakarṣalakṣmīm anurūpasaṃgame //
Vaṃśastha
和訳
蓮の咲く水の中に立つ稲の、格別の美しさを見て彼は喜んだ。まれなる調和のうちに現れた卓越の美を、誰が喜ばずにいられようか。

蓮（美）と稲（実用）が同じ水の中で共存する光景。美しいものと実用的なものの稀有な共存を讃える（リュッケルトの解釈をカペラーが引用）。

5
Sanskrit
nunoda tasya sthalapadminīgataṃ vitarkam āviṣkṛtaphenasaṃtati / avāptakiñjalkavibhedam uccakair vivṛttapāṭhīnaparāhataṃ payaḥ //
Vaṃśastha
和訳
泡沫を露わにし、蕊を散らし、高く跳ねる大魚に打たれた水が、あれは陸の蓮ではないかという彼の疑念を払拭した。

sthalapadminī（陸生の蓮）ではなく水中の蓮であることを、水の飛沫・蕊の散乱・魚の跳躍によって示す。マッリナータ注は「疑惑が確信に変わる装飾法」（niścayottarasaṃdeha）とする。

6
Sanskrit
kṛtormirekhaṃ śithilatvam āyatā śanaiḥ śanaiḥ śāntarayeṇa vāriṇā / nirīkṣya reme sa samudrayoṣitāṃ taraṅgitakṣaumavipāṇḍu saikatam //
Vaṃśastha
和訳
次第に引いてゆく流れの穏やかな水が波の筋を残し、波打つ絹衣のように白く輝く砂洲を見て、彼は楽しんだ。海の女たち（河川）の砂洲である。

河川を海の妻に見立て、砂洲を腰に、水を絹衣になぞらえる詩的伝統。

7
Sanskrit
manoramaṃ prāpitam antaraṃ bhruvor alaṃkṛtaṃ kesarareṇunāṇunā / alaktatāmrādharapallavaśriyā samānayantīm iva bandhujīvakam //
Vaṃśastha
和訳
眉間に飾られた、わずかな蕊の花粉で彩られた愛らしいバンドゥジーヴァカの花を、ラック染めの赤い唇の若枝のような美しさに等しくせんとするかのような田の番の娘を――

bandhujīvaka（Pentapetes Phoenicea）は秋を象徴する花。7-9は連続する一文で、田を守る娘の描写。

8
Sanskrit
navātapālohitam āhitaṃ muhur mahāniveśau paritaḥ payodharau / cakāsayantīm aravindajaṃ rajaḥ pariśramāmbhaḥpulakena sarpatā //
Vaṃśastha
和訳
朝日のように赤い蓮の花粉を、豊かに盛り上がる両の胸のあたりに何度も塗り、汗のしずくが広がって花粉を輝かせている娘を――
9
Sanskrit
kapolasaṃśleṣi vilocanatviṣā vibhūṣayantīm avataṃsakotpalam / sutena pāṇḍoḥ kalamasya gopikāṃ nirīkṣya mene śaradaḥ kṛtārthatā //
Vaṃśastha
和訳
頬に触れる耳飾りの蓮を瞳の輝きで飾り立てている稲の番の娘を見て、パーンドゥの子は秋の完成を思った。

gopikā は「稲を守る女」（kalamasya gopikā）。マッリナータ注はṇvul接尾辞による造語と説明。

10
Sanskrit
upāratāḥ paścimarātrigocarād apārayantaḥ patituṃ javena gām / tam utsukāś cakrur avekṣaṇotsukaṃ gavāṃ gaṇāḥ prasnutapīvaraudhasaḥ //
Vaṃśastha
和訳
夜明け前の牧草地から戻り、（重い乳房のために）地を速く駆けることもかなわぬ牛の群れは、乳を滴らせる豊かな乳房をもち、仔牛を恋い慕いつつ、彼の心にも見入りたいという思いを起こさせた。
11
Sanskrit
parītam ukṣāvajaye jayaśriyā nadantam uccaiḥ kṣatasindhurodhasam / dadarśa puṣṭiṃ dadhataṃ sa śāradīṃ savigrahaṃ darpam ivādhipaṃ gavām //
Vaṃśastha
和訳
牡牛との闘いの勝利に輝きに包まれ、高らかに吼えて河岸を崩し、秋の豊満さを身に纏う牛の王を見た。あたかも傲慢そのものが肉体を得たかのようであった。
12
Sanskrit
vimucyamānair api tasya mantharaṃ gavāṃ himānīviśadaiḥ kadambakaiḥ / śarannadīnāṃ pulinaiḥ kutūhalaṃ galaddukūlair jaghanair ivādadhe //
Vaṃśastha
和訳
雪のように白い牛の群れがゆっくりと離れてゆく秋の河の砂洲は、絹の衣が滑り落ちる腰のごとく、彼の心に好奇を掻き立てた。
13
Sanskrit
gatān paśūnāṃ sahajanmabandhutāṃ gṛhāśrayaṃ prema vaneṣu bibhrataḥ / dadarśa gopān upadhenu pāṇḍavaḥ kṛtānukārān iva gobhir ārjave //
Vaṃśastha
和訳
パーンダヴァは、家畜と生まれながらの兄弟の絆を結び、森に家への愛着を抱く牧人たちを、牛のそばで見た。その素朴さにおいて、牛たちに倣っているかのようであった。
14
Sanskrit
paribhraman mūrdhajaṣaṭpadākulaiḥ smitodayādarśitadantakesaraiḥ / mukhaiś calatkuṇḍalaraśmirañjitair navātapāmṛṣṭasarojacārubhiḥ //
Vaṃśastha
和訳
なびく黒髪が蜂のように群がり、微笑みに歯の蕊をのぞかせ、揺れる耳飾りの光に照らされ、朝日を浴びた蓮のように美しい顔をもつ――

14-16は牧女（ballavī）の描写で、17へと続く連続構文。顔を蓮に、黒髪を蜂に、歯を蕊に見立てる。

15
Sanskrit
nibaddhaniḥśvāsavikampitādharā latā iva prasphuritaikapallavāḥ / vyapoḍhapārśvair apavartitatrikā vikarṣaṇaiḥ pāṇivihārahāribhiḥ //
Vaṃśastha
和訳
抑えた吐息に唇を震わせ、ひとつの若葉を揺らす蔓草のごとく、繰り綱を引く手の優美な動きに脇を反らし腰をくねらせている――
16
Sanskrit
vrajājireṣv ambudanādaśaṅkinīḥ śikhaṇḍinām unmadayatsu yoṣitaḥ / muhuḥ praṇunneṣu mathāṃ vivartanair nadatsu kumbheṣu mṛdaṅgamantharam //
Vaṃśastha
和訳
牛舎の庭で、攪拌棒を繰り返し回して鳴り響く乳甕が太鼓のように低く轟き、雷と誤った孔雀の雌を興奮させている中で――

孔雀が乳攪拌の音を雷と取り違えて興奮するという詩的常套。マッリナータ注はbhrantimad（錯覚の修辞法）と指摘。

17
Sanskrit
sa mantharāvalgitapīvarastanīḥ pariśramaklāntavilocanotpalāḥ / nirīkṣituṃ nopararāma ballavīr abhipranṛttā iva vārayoṣitaḥ //
Vaṃśastha
和訳
ゆるやかに揺れる豊かな胸と、労働に疲れた蓮の目をもつ牧女たちを――踊る遊女のように見える彼女たちを――彼は飽くことなく見つめ続けた。
18
Sanskrit
papāta pūrvāṃ jahato vijihmatāṃ vṛṣopabhuktāntikasasyasampadaḥ / rathāṅgasīmantitasāndrakardamān prasaktasampātapṛthakkṛtān pathaḥ //
Vaṃśastha
和訳
彼は道を行った。以前の曲がりくねりを失い、路傍では牡牛が穀物を食み、車輪が固まった泥に轍を刻み、絶えぬ往来によって踏み分けられた道を。

雨季が終わり道が真っ直ぐになったことを示す。マッリナータ注：「秋には泥が乾いて道が歩きやすくなるため」。

19
Sanskrit
janair upagrāmam anindyakarmabhir viviktabhāveṅgitabhūṣaṇair vṛtāḥ / bhṛśaṃ dadarśāśramamaṇḍapopamāḥ sapuṣpahāsāḥ sa niveśavīrudhaḥ //
Vaṃśastha
和訳
村々で、非難の余地なき生業に従い、心と身振りと装いの清らかな人々に囲まれた、花の笑みをたたえて庵のように見える家々の庭の蔓草を、彼はしげしげと眺めた。
20
Sanskrit
tataḥ sa samprekṣya śaradguṇaśriyaṃ śaradguṇālokanalolacakṣuṣam / uvāca yakṣas tam acodito 'pi gāṃ na hīṅgitajño 'vasare 'vasīdati //
Vaṃśastha
和訳
かくしてかのヤクシャは、秋の美を観賞するに貪欲な眼差しの彼（アルジュナ）に、求められずとも語りかけた。心の機微を知る者は、好機に沈黙してはいないからである。

iṅgitajña（心の機微を知る者）。マッリナータ注：「問われずに語ることの禁は、相手が望んでいない場合にのみ適用される」。

21
ヤクシャの言葉
Sanskrit
iyaṃ śivāyā niyater ivāyatiḥ kṛtārthayantī jagataḥ phalaiḥ kriyāḥ / jayaśriyaṃ pārtha pṛthūkarotu te śarat prasannāmbur anambuvāridā //
Vaṃśastha
和訳
「おお、プリターの子よ。澄んだ水と水なき雲をもつこの秋は、あたかも吉兆の運命の成就のごとく、世界の営みを果実で報いつつ、汝の勝利の栄光を広く輝かせんことを。
22
ヤクシャの言葉
Sanskrit
upaiti sasyaṃ pariṇāmaramyatā nadīr anauddhatyam apaṅkatā mahīm / navair guṇaiḥ samprati saṃstavasthiraṃ tirohitaṃ prema ghanāgamaśriyaḥ //
Vaṃśastha
和訳
穀物には成熟の美しさが訪れ、河には穏やかさが、大地には泥のなさが訪れた。いまや新たなる美質の前に、慣れ親しんだ雨季への愛着は消え去った。
23
ヤクシャの言葉
Sanskrit
patanti nāsmin viśadāḥ patattriṇo dhṛtendracāpā na payodapaṅktayaḥ / tathāpi puṣṇāti nabhaḥ śriyaṃ parāṃ na ramyam āhāryam apekṣate guṇam //
Vaṃśastha
和訳
この空には白鷺は飛ばず、虹を抱く雲の列もない。それでも空は至高の美を湛える。生来美しいものは、外から借りた飾りを必要としない。

viśadāḥ patattriṇaḥ は白鷺（balāka）で雨季の特徴。虹も雨季のもの。秋の空はそれらなしでも美しいという論。

24
ヤクシャの言葉
Sanskrit
vipāṇḍubhir glānatayā payodharaiś cyutācirābhāguṇahemadāmabhiḥ / iyaṃ kadambānilabhartur atyaye na digvadhūnāṃ kṛśatā na rājate //
Vaṃśastha
和訳
疲れに蒼ざめた胸（雲）から稲妻の黄金の帯が落ち、雨季という夫が去った後の方位の乙女たちのやつれは――否、それは輝かぬのではない。むしろ麗しく映える。

方角を女性に、雨季をその夫に見立てる伝統的比喩。マッリナータ注：「夫の旅立ちに際し、女は憔悴しつつも美しい」という詩的規範。rūpaka（隠喩）の修辞。

25
ヤクシャの言葉
Sanskrit
vihāya vāñchām udite madātyayād araktakaṇṭhasya rute śikhaṇḍinaḥ / śrutiḥ śrayaty unmadahaṃsaniḥsvanaṃ guṇāḥ priyatve 'dhikṛtā na saṃstavaḥ //
Vaṃśastha
和訳
酔いの醒めた孔雀の色褪せた声への欲を捨て、耳は陶然たる白鳥の鳴き声を求める。愛されるに値するのは美質であって、慣れ親しみではない。」

雨季には孔雀が鳴き、秋には白鳥（haṃsa）が鳴く。カペラーは「友情を左右するのは徳であって、習慣ではない」と解する。

26
ヤクシャの言葉
Sanskrit
amī pṛthustambabhṛtaḥ piśaṅgatāṃ gatā vipākena phalasya śālayaḥ / vikāsi vaprāmbhasi gandhasūcitaṃ namanti nighrātum ivāsitotpalam //
Vaṃśastha
和訳
太い茎を持ち、実の成熟によって黄金色に変わったあの稲たちは、畦の水に咲く黒蓮を、その香りに導かれて嗅ごうとするかのように身を傾ける。

稲穂が実りで頭を垂れる自然現象を、蓮に首を傾けて匂いを嗅ぐ行為に見立てる。マッリナータ注はphalotprekṣā（目的の空想法）とする。

27
ヤクシャの言葉
Sanskrit
mṛṇālinīnām anurañjitaṃ tviṣā vibhinnam ambhojapalāśaśobhayā / payaḥ sphuracchāliśikhāpiśaṅgitaṃ drutaṃ dhanuṣkhaṇḍam ivāhividviṣaḥ //
Vaṃśastha
和訳
蓮の茎の輝きに緑に染まり、蓮の花弁の艶やかさに赤く彩られ、揺れる稲穂の先に黄ばんだ水は、あたかも蛇の敵（インドラ）の虹の一片が溶けたかのようである。

ahividviṣ（蛇の敵）はインドラの異名（ヴリトラ退治にちなむ）。dhanuṣkhaṇḍa（弓の断片）は虹を指す。マッリナータ注は「溶けた虹は世間に知られぬゆえ直喩ではなく空想法」とする。

28
ヤクシャの言葉
Sanskrit
vipāṇḍu saṃvyānam ivāniloddhataṃ nirundhatīḥ saptapalāśajaṃ rajaḥ / anāvilonmīlitabāṇacakṣuṣaḥ sapuṣpahāsā vanarājiyoṣitaḥ //
Vaṃśastha
和訳
風に舞い上がるシチヨウジュ（七葉樹）の花粉を、白い上衣のようにまとい、澄んだバーナの花の目を見開き、花の笑みをたたえた森の女たちを――

ヤクシャの言葉
Sanskrit
sitacchadānām apadiśya dhāvatāṃ rutair amīṣāṃ grathitāḥ patatriṇām / prakurvate vāridarodhanirgatāḥ parasparālāpam ivāmalā diśaḥ //

31
ヤクシャの言葉
Sanskrit
vihārabhūmer abhighoṣam utsukāḥ śarīrajebhyaś cyutayūthapaṅktayaḥ / asaktam ūdhāṃsi payaḥ kṣaranty amūr upāyanānīva nayanti dhenavaḥ //

和訳
牧草地から帰り、牛舎を慕って群れの列を崩し、絶え間なく乳を滴らせる乳房を、あたかも仔牛への贈り物のように運んでゆく牝牛たち。
32
ヤクシャの言葉
Sanskrit
jagatprasūtir jagadekapāvanī vrajopakaṇṭhaṃ tanayair upeyuṣī / dyutiṃ samagrāṃ samitir gavām asāv upaiti mantrair iva saṃhitāhutiḥ //
Vaṃśastha
和訳
世界の母にして世界唯一の浄化者たるあの牛の群れは、牛舎の近くで仔牛たちと合流し、完全なる輝きに至る。あたかも聖句を伴う供犠のごとく。

牛は供犠に必要なバター等を供するため「世界の創造者・浄化者」と呼ばれる。マッリナータ注は「火に投ぜられた供物が太陽に至り、太陽から雨が、雨から食物が、食物から生類が生ずる」という聖典を引く。

33
ヤクシャの言葉
Sanskrit
kṛtāvadhānaṃ jitabarhiṇadhvanau suraktagopījanagītaniḥsvane / idaṃ jighatsām apahāya bhūyasīṃ na sasyam abhyeti mṛgīkadambakam //
Vaṃśastha
和訳
恋に染まる牧女たちの歌声が孔雀の声を圧するのを聞き入り、このあたりの鹿の群れは大いなる食欲を忘れて穀物に近寄ろうとしない。
34
ヤクシャの言葉
Sanskrit
asāv anāsthāparayāvadhīritaḥ saroruhiṇyā śirasā namann api / upaiti śuṣyan kalamaḥ sahāmbhasā manobhuvā tapta ivābhipāṇḍutām //
Vaṃśastha
和訳
あの稲は、頭を垂れて敬意を示しても、無関心な蓮に軽んじられ、水とともに枯れながら黄ばんでゆく。あたかも恋の神に焼かれたかのように。

稲と蓮を恋人に見立てたsamāsokti（凝縮表現）。26で暗示された稲と蓮の恋愛を展開。マッリナータ注：「立ち上がる蓮を冷淡な恋人に見立てる隠喩と、恋に苦しむかのようだという空想法の複合」。

35
ヤクシャの言葉
Sanskrit
amī samuddhūtasarojareṇunā hṛtā hṛtāsārakaṇena vāyunā / upāgame duścaritā ivāpadāṃ gatiṃ na niścetum alaṃ śilīmukhāḥ //
Vaṃśastha
和訳
蓮の花粉を巻き上げ、雨粒を帯びた風に攫われたあの蜂たちは、災厄の迫るとき行き場を見出せぬ悪人のごとく、避難先を定めることができない。
36
ヤクシャの言葉
Sanskrit
mukhair asau vidrumabhaṅgalohitaiḥ śikhāḥ piśaṅgīḥ kalamasya bibhratī / śukāvalir vyaktaśirīṣakomalā dhanuḥśriyaṃ gotrabhido 'nugacchati //
Vaṃśastha
和訳
珊瑚を砕いたように赤い嘴に黄金色の稲穂を咥え、咲き誇るシリーシャの花のように柔らかなあの鸚鵡の群れは、山を裂く者（インドラ）の弓（虹）の美を追っている。」

gotrabhid（山を裂く者）はインドラ。鸚鵡の赤・黄・緑の色彩が虹に喩えられる。ヤクシャの言葉はここで終わる。

37
Sanskrit
iti kathayati tatra nātidūrād atha dadṛśe pihitoṣṇaraśmibimbaḥ / vigalitajalabhāraśuklabhāsāṃ nicaya ivāmbumucāṃ nagādhirājaḥ //
Puṣpitāgrā
和訳
かく語るうちに、さほど遠からぬところに、太陽の円盤を覆い隠し、水の重荷を下ろして白く輝く雲の集まりのごとき山の王（ヒマーラヤ）が姿を現した。
38
Sanskrit
tam atanuvanarājiśyāmitopatyakāntaṃ nagam upari himānīgauram āsādya jiṣṇuḥ / vyapagatamadarāgasyānusasmāra lakṣmīm asitam adharavāso bibhrataḥ sīrapāṇeḥ //
Mālinī
和訳
広大な森によって裾野を黒く染め、頂は雪に白く輝くその山に至り、ジシュヌ（アルジュナ）は、酔いの赤みが去り黒い下衣をまとった鋤を持つ者（バララーマ）の美を思い起こした。

sīrapāṇi（鋤を持つ者）はバララーマ。白い肌と黒い衣という彼の容姿が、雪に白い頂と森に暗い裾野の山容に重ねられる。madarāga（酔いの赤み）が去った姿は、酒を好むバララーマが素面の時の白さを示す。マッリナータ注はsmaraṇa（想起法）と指摘。

iti bhāravikṛtau mahākāvye kirātārjunīye caturthaḥ sargaḥ //
