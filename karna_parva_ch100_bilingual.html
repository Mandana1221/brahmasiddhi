マハーバーラタ ― カルナ篇 第100章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 100 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ100」で、カルナ討死後のクリシュナとアルジュナのユダーマンユへの帰還の場面を描きます。
karṇaparva — śatatamo'dhyāyaḥ (100)
第100章 ― カルナ討死後のクリシュナとアルジュナのユディシュティラへの帰還
sañjaya uvāca|
śarasaṅkṛttavarmāṇaṃ rudhirokṣitavakṣasam|
gatāsumapi rādheyaṃ naiva lakṣmīrvimuñcati||
taptajāmbūnadanibhaṃ bālārkasadṛśadyutim|
jīvantamiva taṃ śūraṃ sarvabhūtāni menire||
// 8-100-1-2 //
サンジャヤは語った。
矢に鎧を砕かれ胸を血に染めたラーデーヤ（カルナ）は、息絶えてもなお幸運の女神に見放されなかった。焼けた黄金のように輝き、昇る朝日のような光を放つその勇者を、すべての生きものが生きているかのように思った。
hatasyāpi mahārāja sūtaputrasya saṃyuge|
vitresuḥ sarvato yodhāḥ siṃhasyevetare mṛgāḥ||
// 8-100-3 //
大王よ、スータの息子が戦場で倒されてもなお、すべての兵士は四方から恐れた。獅子に対する他の動物たちのように。
hato'pi puruṣavyāghro vyāharanniva lakṣyate|
nābhavadvikṛtiḥ kācinmṛtasyāpi mahātmanaḥ||
// 8-100-4 //
討たれてもなおこの人中の虎は、まるで語りかけているかのように見えた。死してもなお偉大な魂の者には何の変わりもなかった。
cāruveṣadharaṃ rājaṃścārumauliśirodharam|
tanmukhaṃ sūtaputrasya pūrṇacandrasamadyuti||
kanakottamasahkāśo jvalanniva vibhāvasuḥ|
sa śāntaḥ puruṣavyāghraḥ pārthasāyakavāriṇā||
// 8-100-5-6 //
美しい衣を身にまとい、美しい冠と首を持つ、スータの息子の顔は満月のような輝きであった。黄金のように輝き、燃える火のように。しかしこの人中の虎はパールタの矢の水によって鎮められた。
yathā'gnirjvalano dīpto jalamāsādya śāmyati|
karṇāgniḥ samare tadvatpārthameghena śāmitaḥ||
āhṛtya sa yaśo dīptaṃ suyuddhenātmano bhuvi|
saputraḥ samare karṇaḥ praśāntaḥ pārthatejasā||
// 8-100-7-8 //
燃え上がる火が水に出会って鎮まるように、カルナの火はパールタの雷雲によって消し止められた。見事な戦いによってこの世に輝く名声を勝ち取った後、息子とともに戦場でカルナはパールタの光に消えた。
pratāpya pāṇḍavānsarvānpāñcālānastratejasā|
nānābharaṇavānrajaṃstaptajāmbūnadaprabhaḥ||
varṣitvā śaravarṣāṇi pratāpya ripuvāhinīm|
śrīmāniva sahasrāṃśurjvalansarvānpratāpya ca|
hato vaikartanaḥ karṇaḥ pādapo'ṅkuravāniva||
// 8-100-9-10 //
パーンダヴァたちすべてとパーンチャーラ勢を武器の輝きで焼き尽くした後、さまざまな装飾品を身にまとい焼けた黄金のように輝いていた彼は、矢の雨を降らせて敵の軍を焼き尽くした。輝く千の光線を持つ太陽のように、すべてを焼き尽くした後に。ヴァイカルタナ・カルナは討たれた。芽を出した大樹が倒されるように。
dadānītyeva yaḥ prādānna nāstītyarthito'vadat|
saddhyaḥ sadā satpuruṣaḥ sa hato dvairathe vṛṣā||
// 8-100-11 //
「差し上げよう」と言って与え、「ない」とは言わなかった者、常に善良で、常に善人であった雄牛（カルナ）が一騎討ちで討たれた。
yasya brāhmaṇasātsarvaṃ vittamāsīnmahātmanaḥ|
nādeyaṃ brāhmaṇeṣvāsīdyasya svamapi jīvitam||
// 8-100-12 //
偉大な魂の者のすべての財産はバラモンのものであった。バラモンに対して与えられないものはなく、自分の命さえも。
sa dātṝṇāṃ priyo rājandātā caiva manorathān|
sa pārthāstravinirdagdho gataḥ paramikāṃ gatim||
// 8-100-13 //
施す者たちに愛され、王よ、人の望みをも叶えて与える施主。パールタの武器に焼かれて最高の境地に行った。
yamāśrityākarodvairaṃ sutaste sa gato divam|
ādāya tava putrāṇāṃ jayāśāṃ sarma varma ca||
// 8-100-14 //
おまえの息子が頼りにして敵対していた者が天に行った。おまえの息子たちの勝利の希望と幸福のすべてを持ち去って。
hate ca karṇe sarito na sasrurjagāma cāstaṃ kaluṣo divākaraḥ|
śveto grahaśca jvalitārkavarṇo yamasya putro'bhyuditaḥ sa tiryak||
nabhaścacālātha nanāda corvī vavuśca vātāḥ paruṣāśca ghorāḥ|
diśo babhūvurjvalitāḥ sadhūmā mahārṇavāḥ sasvanuścukṣubhuśca||
sakānanāścādrivarāścakampire pravivyathurbhūtagaṇāśca māriṣa|
bṛhaspatiḥ samparivārya rohiṇīṃ babhūva candrārkasamo viśāmpate||
hate karṇe na diśo vipracārāḥ sacandrārkā dyaurvicacāla bhūmiḥ|
papāta colkā jvalanaprabhā ca niśācarā hṛṣṭatarā babhūvuḥ||
śaśiprakāśānanamarjuno yadā jahāra karṇasya śiraḥ śareṇa|
tato'ntarikṣe sahasaiva śabdo babhūva hāheti surairvimuktaḥ||
// 8-100-15-19 //
カルナが討たれると、河は流れを止め、太陽は曇って沈んだ。白い惑星が燃える太陽のような色で、ヤマの息子のように、横切って昇った。天空は鳴動し大地は轟き、荒々しく恐ろしい風が吹いた。四方は煙を上げて燃え、大海は音を立てて波立った。山々は森ごと震え、生きものの群れが苦しんだ。ブリハスパティ（木星）がローヒニー星を取り囲み、月と太陽に等しくなった。四方は不安定にならず、月と太陽のある天空がぐらつき大地が揺れた。流星が炎のように落ち、夜の者たちがさらに喜んだ。月のように輝く顔を持つアルジュナがカルナの首を矢で刈り取った時、天空で突然「ああ！」という声が神々から発せられた。
sadevagandharvamanuṣyapūjitaṃ nihatya karṇaṃ ripumāhave'rjunaḥ|
rarāja rājanparameṇa tejasā yathā purā vṛtravadhe śatakratuḥ||
// 8-100-20 //
神々・ガンダルヴァ・人間に崇拝された敵カルナを戦場で討ったアルジュナは、最高の輝きで輝いた。かつてヴリトラを討ったシャタクラトゥ（インドラ）のように。
patākinā bhīmaninādaketunā rathena śaṅkhasphaṭikāvabhāsinā|
mahendravāhapratimena tāvubhau mahendravīryapratimānapauruṣau||
suvarṇamuktāmaṇivajravidrumairalaṅkṛtenāpratimena raṃhasā|
narottamau yādavapāṇḍunandanau divākarau dīptahutāśanāviva|
raṇājire vītabhayau virejatuḥ samānayogāviva viṣṇuvāsavaiḥ||
tato dhanurjyātalaneminisvanaiḥ prasahya kṛtvā ca ripūngataprabhān|
sa sādhayitvā ca ripūñśaraughaiḥ kapidhvajaḥ pakṣivaradhvajaśca|
pradadhmatuḥ śaṅkhavarau sughoṣau manāṃsyarīṇāmupatāpayantau||
suvarṇajālāvatatau mahāsvanau himāvadātau parigṛhya pāṇimiḥ|
cucumbatuḥ śaṅkhavarau nṛṇāṃ varau vighoṣayantau vijayaṃ jagattraye||
// 8-100-21-24 //
旗をなびかせ恐ろしい音を立てる旗竿を持つ、法螺貝と水晶のように輝く戦車に乗り、インドラの乗り物に匹敵するその戦車で、インドラの武勇に匹敵する力を持つ二人の人中の最良者、ヤーダヴァ（クリシュナ）とパーンドゥの息子（アルジュナ）は、黄金・真珠・宝石・珊瑚で飾られた比類なき速さの戦車で、昇る二つの太陽のように、燃え盛る二つの火のように、戦場で恐れなく輝いた。ヴィシュヌとインドラのように等しい力で。弓弦と手の平と車輪の音を響かせ、敵を力ずくで光を失わせ、矢の群れで敵を征服してから、猿の旗の者と鳥の王の旗の者は最上の法螺貝を吹き鳴らした。敵の心をも震え上がらせて。黄金の網に覆われた偉大な音の、雪のように白い法螺貝を手に取り、人の中の最良者たる二人は三界に勝利を告げる法螺貝を吹いた。パーンチャジャニヤとデーヴァダッタの二つの轟きが大地と天空と四方を満たした。
pāñcajanyasya nirghoṣo devadattasya cobhayoḥ|
pṛthivīmantarikṣaṃ ca diśaśca samapūrayat||
vitrastāścābhavansarve kuravo rājasattama|
śūrayoḥ śaṅkhaśabdena mādhavasyārjunasya ca||
tau śaṅkhaśabdena ninādayantau vanāni śailānsarito guhāśca|
vitrāsayantau tava putrasenāṃ yudhiṣṭhiraṃ nandayituṃ prayātau||
tataḥ prajagmuḥ kuravo javena śrutvaiva śaṅkhasvanamīryamāṇam|
vihāya madrādhipatiṃ patiṃ ca duryodhanaṃ bhārata bhāratānām||
// 8-100-25-28 //
マーダヴァ（クリシュナ）とアルジュナの法螺貝の音に、すべてのクル勢が恐怖に震えた。二人は法螺貝の音で森も山も河も洞窟も響かせ、おまえの息子の軍を恐怖に陥れながら、ユディシュティラを喜ばせるために向かった。クル勢は素早く逃げ去った。法螺貝の音が響くのを聞くだけで。マドラの王もドゥルヨーダナも、バーラタの中のバーラタの主をも見捨てて。
tato rathenāmbudabṛndanādinā śaradvaharmadhyadivākaratviṣā|
dhanañjayasyādhiratheśca vismitāḥ praśaṃsamānāḥ prayayustadā'rjunam||
mahāhave taṃ bahuśobhamānaṃ dhanañjayaṃ yodhagaṇaiḥ sametāḥ|
tāvanvamodaṃśca janāḥ prakāmaṃ prabhākarāvabhyuditau yathaiva||
// 8-100-29-30 //
雲の群れのように轟く、秋の正午の太陽のように輝く戦車で、人々はダナンジャヤとアディラティの偉大さに驚嘆し、称賛しながらアルジュナのもとに集まった。偉大なる戦いで美しく輝くダナンジャヤを、兵士たちの群れとともに。人々はこの二人を心ゆくまで喜んだ。二つの光明が昇ったかのように。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe śatatamo'dhyāyaḥ|| 100 ||
こうして、聖なる大マハーバーラタのカルナ篇の第100章は終わる。
