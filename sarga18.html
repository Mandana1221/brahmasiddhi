キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

aṣṭādaśaḥ sargaḥ ― 第十八章

両者は拳で打ち合い、ついに組み合って格闘する。シヴァがアルジュナを胸に抱きしめて真の姿を現すと、アルジュナは讃歌をもってシヴァを讃え、戦いの力と勝利を願う。喜んだシヴァと世界の守護者たちはアルジュナを称え、様々な武器を授ける。

Sanskrit

Sanskrit
ayam asau bhagavān uta pāṇḍavaḥ sthitam avāṅ muninā śaśimaulinā / samadhirūḍham ajena nu jiṣṇunā svid iti vegavaśān mumuhe gaṇaiḥ //
Drutavilambita
和訳
「これは世尊（シヴァ）か、それともパーンダヴァか。下にいるのは聖仙か、月冠の者か。上に乗っているのは不生の者（シヴァ）か、ジシュヌか」――と、ガナたちはその目まぐるしい勢いに惑った。
組み合う二人の区別がつかなくなる場面。aja（不生者）はシヴァの称号で「生まれなき者」の意。ガナたちの問いは修辞的で、両者の力の対等さを表現する。
10
Sanskrit
pracalite calitaṃ sthitam āsthite vinamite natam unnatam unnatau / vṛṣakapidhvajayor asahiṣṇunā muhur abhāvabhayād iva bhūbhṛtā //
Drutavilambita
和訳
牡牛旗と猿旗の二者を支えきれない山は、自らの崩壊を恐れるかのように繰り返しよろめいた——二人が揺れれば山も揺れ、立てば静まり、傾けば傾き、起き上がれば起き上がった。
vṛṣadhvaja（牡牛の旗）はシヴァ、kapidhvaja（猿の旗）はアルジュナの標識。山全体が格闘に共振する壮大な描写。

Sanskrit

Sanskrit
vismitaḥ sapadi tena karmaṇā karmaṇāṃ kṣayakaraḥ paraḥ pumān / kṣeptukāmam avanau tam aklamaṃ niṣpipeṣa parirabhya vakṣasā //
Rathoddhatā
和訳
その技に驚嘆して、業の消滅者たる至高のプルシャ（シヴァ）は、地に投げ倒そうとする疲れ知らずのアルジュナをたちまち抱きしめ、胸に押し当てた。
シヴァがアルジュナを胸に抱く瞬間は、格闘の終結であると同時に恩寵の表明。karmaṇāṃ kṣayakaraḥ（業の消滅者）はシヴァの救済者としての側面を暗示する。
14
Sanskrit
tapasā tathā na mudam asya yayau bhagavān yathā vipulasattvatayā / guṇasaṃhateḥ samatiriktam aho nijam eva sattvam upakāri satām //
Pramitākṣarā
和訳
聖者はアルジュナの苦行によってよりも、むしろその偉大なる気力によって喜んだ。ああ、善き者たちの助けとなるのは、あらゆる美徳の集合を超えた、生来の勇猛心そのものなのだ。
sattva（勇猛心・本質的な力）がguṇa（後天的美質）の集合を超えるという思想。シヴァが最も評価したのはアルジュナの苦行ではなく、生まれながらの不屈の精神であった。
15
Sanskrit
atha himaśucibhasmabhūṣitaṃ śirasi virājitam indulekhayā / svavapur atimanoharaṃ haraṃ dadhatam udīkṣya nanāma pāṇḍavaḥ //
Aparavaktra
和訳
そこでパーンダヴァは、雪のごとく白き灰に飾られ、頭上に三日月が輝く、この上なく魅惑的な自らの真の姿を現したハラを仰ぎ見て、ひれ伏した。
シヴァがキラータの姿を捨て、真の姿——白灰を塗り三日月を戴く苦行者の姿——を現す転換点。

Sanskrit

Sanskrit
vrajati śuci padaṃ tvayi prītimān pratihatam atir eti ghorāṃ gatim / iyam anagha nimittaśaktiḥ parā tava varada na cittabhedaḥ kvacit //
Pramuditavadanā
和訳
汝に歓喜する者は清浄な境地に至り、拒む者は恐ろしき道を行く。おお無垢なる者よ、恩恵を与える者よ、これは因果の至高の力であり、汝の心には偏りなどない。
シヴァの公平性を説く。善悪の報いはシヴァの好悪によるものではなく、因果（nimittaśakti）の法則に従う。シヴァ自身にはいかなる心の偏り（cittabheda）もない。
27
Sanskrit
dakṣiṇāṃ praṇatadakṣiṇa mūrtiṃ tattvataḥ śivakarīm aviditvā / rāgiṇāpi vihitā tava bhaktyā saṃsmṛtir bhava bhavaty abhavāya //
Svāgatā
和訳
帰依する者に恵み深き者よ、汝の恵み深い姿が真に吉祥をもたらすものであることを知らずとも、おおバヴァよ、執着ある者が帰依の心からなす汝への想念でさえ、生存からの解脱をもたらす。
dakṣiṇā mūrti（南に向く姿＝ダクシナームールティ）はシヴァの教師としての姿。rāgin（執着ある者）による不完全な帰依ですら解脱をもたらすというシヴァの慈悲の深さ。bhava（存在・生死）とabhava（非存在・解脱）の語呂合わせ。

Sanskrit

和訳

Sanskrit

Sanskrit
saṃnibaddham apahartum ahāryaṃ bhūri durgatibhayaṃ bhuvanānām / adbhutākṛtim imām atimāyas tvaṃ bibharṣi karuṇāmaya māyām //
Svāgatā

māyā（幻力）を超える（atimāya）シヴァ自身が、衆生救済のためにあえて幻力の姿（māyā）をとるという逆説。

Sanskrit
na rāgi cetaḥ paramā vilāsitā vadhūḥ śarīre 'sti na cāsti manmathaḥ / namaskriyā coṣasi dhātur ity aho nisargadurbodham idaṃ tavehitam //
Vaṃśastha
和訳
汝の心には執着なく、しかも至高の遊戯あり。身体に妻（パールヴァティー）を有しながら、愛欲の神は存在せず。創造主をも礼拝するとは——ああ、汝の行いは本性として理解し難い。
シヴァの三つの逆説：（1）無執着でありながら最高の遊戯（パールヴァティーとの戯れ）を行う、（2）半身に妻を有しながらカーマ神を焼き滅ぼした、（3）万物に崇拝される存在でありながら自らブラフマンを礼拝する。

Sanskrit

33
Sanskrit
avigrahasyāpy atulena hetunā sametabhinnadvayamūrti tiṣṭhataḥ / tavaiva nānyasya jagatsu dṛśyate viruddhaveṣābharaṇasya kāntatā //
Vaṃśastha
和訳

sametabhinnadvayamūrti（合一と分離の二つの姿）はアルダナーリーシュヴァラ（半男半女の合一姿）と独立した男性姿の両方を指す。相矛盾する装飾品（象の皮と月、灰と白檀など）にもかかわらず美が成立するのはシヴァのみ。
34
Sanskrit
ātmalābhapariṇāmanirodhair bhūtasaṃgha iva na tvam upetaḥ / tena sarvabhuvanātiga loke nopamānam asi nāpy upameyaḥ //
Svāgatā
和訳
生成・変化・消滅に支配される生物の群れと異なり、汝はそれらに縛られない。それゆえ、おおすべての世界を超越する者よ、この世に汝の比喩となるものもなく、汝に比されるものもない。
35
Sanskrit
tvam antakaḥ sthāvarajaṅgamānāṃ tvayā jagat prāṇiti deva viśvam / tvaṃ yogināṃ hetuphale ruṇatsi tvaṃ kāraṇaṃ kāraṇakāraṇānām //
Upajāti
和訳
汝は動くものと動かざるものの終焉者。汝によって全世界は息づく、おお神よ。汝は瞑想者たちのために因と果を断ち切る。汝は原因の原因の、さらなる原因である。
シヴァの三つの宇宙的機能：（1）破壊者（antaka）、（2）生命の賦与者（prāṇiti）、（3）業の因果を断つ解脱の付与者。kāraṇaṃ kāraṇakāraṇānām（原因の原因の原因）は第十七章14偈にも現れた表現。

Sanskrit

和訳
力をもって世界を支え、至高にして清浄なるブラフマンの響きが発し、あらゆる罪を浄める者——シヴァよ、風の姿をとる汝に礼拝を。
ここからシヴァの八つの顕現形態のうち四つ——風（37偈）、火（38偈）、水（39偈）、虚空（40偈）——が讃えられる。brahma はここではオームの聖音を指す。
38
Sanskrit
bhavataḥ smaratāṃ sadāsane jayini brahmamaye niṣeduṣām / dahate bhavabījasaṃtatiṃ śikhine 'nekaśikhāya te namaḥ //
Viyoginī（Vaitālīya）
和訳
汝を想い、勝利ある聖なる座において、ブラフマンに満ちた瞑想に座す者たちのために、生存の種子の連鎖を焼き尽くす多炎の火よ、汝に礼拝を。
39
Sanskrit
ābādhāmaraṇabhayārciṣā cirāya pluṣṭebhyo bhava mahatā bhavānalena / nirvāṇaṃ samupagamena yacchate te bījānāṃ prabhava namo 'stu jīvanāya //
Praharṣiṇī
和訳
苦悩と死の恐怖という炎を持つ生存の大火に長く焼かれた者たちに、近づくだけで涅槃の安らぎを与える汝——おお種子の源よ、水の姿たる命の与え手よ、礼拝あれ。
bhavānala（生存の火）は輪廻の苦、nirvāṇa（涅槃）は火の消滅と解脱の両義。水の元素としてのシヴァが生存の火を鎮めるという比喩。
40
Sanskrit
yaḥ sarveṣām āvarītā varīyān sarvair bhāvair nāvṛto 'nādiniṣṭhaḥ / mārgātītāyendriyāṇāṃ namas te 'vijñeyāya vyomarūpāya tasmai //
Śālinī
和訳
すべてのものを包みながら最も偉大なる者、すべての存在に包まれることなく始まりも終わりもなき者——感覚の道を超え、知り得ざる者、虚空の姿をとる彼に礼拝を。
41
Sanskrit
aṇīyase viśvavidhāriṇe namo namo 'ntikasthāya namo davīyase / atītya vācāṃ manasāṃ ca gocaraṃ sthitāya te tatpataye namo namaḥ //
Vaṃśastha
和訳
最も微細なる者、万物を支える者に礼拝を。最も近きにいます者に礼拝を。最も遠きにいます者に礼拝を。言葉と思考の領域を永遠に超えて立つ汝に——その主に——礼拝を、礼拝を。
42
Sanskrit
asaṃvidānasya mameśa saṃvidāṃ titikṣituṃ duścaritaṃ tvam arhasi / virodhya mohāt punar abhyupeyuṣāṃ gatir bhavān eva durātmanām api //
Vaṃśastha
和訳
認識の主よ、無知なる私の悪行をどうかお許しください。迷妄から汝に逆らい、のちに帰依する者たちにとって——たとえ邪悪なる者であっても——汝こそが唯一の帰依処である。
アルジュナがシヴァと知らずに戦った自らの無知を謝罪する偈。durātman（邪悪なる魂の者）すらもシヴァは受け入れるという赦しの教説。
43
Sanskrit
āstikyaśuddham avataḥ priyadharma dharmaṃ dharmātmajasya vihitāgasi śatruvarge / samprāpnuyāṃ vijayam īśa yayā samṛddhyā tāṃ bhūtanātha vibhutāṃ vitarāhaveṣu //
Vasantatilakā
和訳
正しき信仰に浄められた法を守る法の友よ、法の子（ユディシュティラ）に罪を犯した敵の群れに対する勝利を得られるよう、おおイーシャよ、ブータの主よ、その力を戦いにおいて我に与えたまえ。
讃歌の最終偈。哲学的讃嘆から具体的な願い——カウラヴァに対する勝利のための力——へと転じる。dharmātmaja（法の子）はユディシュティラを指す。
44
Sanskrit
iti nigaditavantaṃ sūnum uccair maghonaḥ praṇataśirasam īśaḥ sādaraṃ sāntvayitvā / jvaladanalaparītaṃ raudram astraṃ dadhānaṃ dhanurupapadam asmai vedam abhyādideśa //
Mālinī
和訳
このように声高く語り、頭を垂れるインドラの子を、主は敬意をもって慰め、燃え盛る炎に包まれた恐ろしきラウドラ武器を携えたダヌル・ヴェーダ（弓術の学）を彼に授けた。
raudram astram（ラウドラ武器）はルドラ＝シヴァに由来する神の武器で、パーシュパタ武器と同一視される。dhanurveda（弓術の学）が人格化されて授与される。
45
Sanskrit
sa piṅgākṣaḥ śrīmān bhuvanamahanīyena mahasā tanuṃ bhīmāṃ bibhrat triguṇaparivārapraharaṇaḥ / parītyeśānaṃ triḥ stutibhir upagītaḥ suragaṇaiḥ sutaṃ pāṇḍor vīraṃ jaladam iva bhāsvān abhiyayau //
Śikhariṇī
和訳
赤い目をした栄光あるその武器（パーシュパタ）は、世界に崇められる威光をもって恐ろしい姿をとり、三種の武具を携え、主（シヴァ）を三度右繞し、神々の群れに讃歌で讃えられながら、パーンドゥの勇猛なる子のもとへ赴いた――太陽が雲に向かうように。
dhanurveda の人格化された姿の描写。triguṇaparivārapraharaṇa（三種の武具に囲まれた）は三つの性質（guṇa）との二重の意味も持ちうる。
46
Sanskrit
atha śaśadharamauler abhyanujñām avāpya tridaśapatipurogāḥ pūrṇakāmāya tasmai / avitathaphalam āśirvādam āropayanto vijayi vividham astraṃ lokapālā viteruḥ //
Mālinī
和訳
月冠の者の許しを得て、インドラを先頭とする世界の守護者たちは、願いが成就した彼に、誤りなき果実をもたらす祝福の言葉とともに、勝利をもたらす様々な武器を授けた。
47
Sanskrit
asaṃhāryotsāhaṃ jayinam udayaṃ prāpya tarasā dhuraṃ gurvīṃ voḍhuṃ sthitam anavasādāya jagataḥ / svadhāmnā lokānāṃ tam upari kṛtasthānam amarās tapolakṣmyā dīptaṃ dinakṛtam ivoccair upajaguḥ //
Śikhariṇī
和訳
挫けぬ気概もて勝利を得、力をもって隆盛に至り、世の安寧のために重き責務を担おうとする彼——自らの威光で世界の上に立ち、苦行の輝きに燃える彼を、不死の者たちは大声で讃えた——高く昇る太陽を讃えるかのように。
48
Sanskrit
vraja jaya ripulokaṃ pādapadmānataḥ san gadita iti śivena ślāghito devasaṃghaiḥ / nijagṛham atha gatvā sādaraṃ pāṇḍuputro dhṛtagurujayalakṣmīr dharmasūnuṃ nanāma //
Mālinī
和訳
「行け、敵の群れを征服せよ」——蓮華の御足にひれ伏す彼にシヴァがこう告げ、神々の群れに讃えられたパーンドゥの子は、家に帰り、偉大なる勝利の栄光を帯びて、法の子（ユディシュティラ）に敬意を込めて礼拝した。
キラータールジュニーヤ全18章の最終偈。シヴァの命を受けたアルジュナが家に帰還し、兄ユディシュティラに勝利の吉報を伝えて礼拝する。マハーバーラタの物語の流れに復帰する結末。
iti bhāravikṛtau mahākāvye kirātārjunīye aṣṭādaśaḥ sargaḥ //
バーラヴィ作『キラータールジュニーヤ』第十八章 終
