प्रथमः सर्गः

第一章　ナーラダの来訪（見本：第1〜5偈）
韻律：vaṃśastha（ヴァンシャスタ）——全75偈
I.1
Sanskrit (IAST) śriyaḥ patiḥ śrīmati śāsituṃ jagaj- jagannivāso vasudevasadmani / vasan dadarśāvatarantam ambarād dhiraṇyagarbhāṅgabhuvaṃ muniṃ hariḥ //
和訳

シュリー（吉祥天）の夫にして、世界の住処たるハリ（ヴィシュヌ）は、世界を統治するために、栄えあるヴァスデーヴァの館に住まいしていたが、あるとき空から降りてくる聖仙——ヒラニヤガルバ（ブラフマー）の身体から生まれた者（ナーラダ）——を見た。

注

【Vallabhadeva】

śriyaḥ patiḥ——ラクシュミーの夫。これにより、ルクミニーの姿をとったシュリーを伴っていることが示唆される。『ヴィシュヌ・プラーナ』に「ラーマの時にはシーター、クリシュナに生まれた時にはルクミニー」とある。jagannivāsaḥ——諸世界の依りどころ。腹中に全宇宙を収める者の意。hiraṇyagarbhāṅgabhuvaṃ——ヒラニヤガルバ（ブラフマー）の身から生まれた者、すなわちナーラダ。『バーガヴァタ』に「ブラフマーの膝から（ナーラダは生まれた）」とある。

【Mallinātha】

冒頭にśrīの語を用いるのは、「成就を祈願して吉祥語等で詩作を始めるべし」という教説に従う吉祥の開始（maṅgalādi）。修辞として、巨大なハリが小さなヴァスデーヴァの館に容れられるというadhika（誇張法）。またjagaj-jaganの音の反復はvṛttyanuprāsa（繰返し音韻）。韻律は vaṃśastha——「ja-ta-ja-ra の脚が vaṃśastha と称される」。

I.2
Sanskrit (IAST) gataṃ tiraścīnam anūrusāratheḥ prasiddham ūrdhvajvalanaṃ havirbhujaḥ / pataty adho dhāma visāri sarvataḥ kim etad ity ākulam īkṣitaṃ janaiḥ //
和訳

「太腿なき御者（アルナ）を持つ太陽の光は水平に進み、供物を食らう火（アグニ）の炎は上方に燃え上がることで知られている。ところが、この光は下方へ、四方に広がりつつ降ってくる——これは一体何であろうか」と、人々は動揺して見つめた。

注

【Vallabhadeva】

anūrusāratheḥ——太腿がない者を御者とする者、すなわちスーリヤ（太陽神）。御者アルナは太腿がないとされる。havirbhujaḥ——供物を食する者、すなわちアグニ（火神）。太陽の光は横に進み、火の炎は上に向かうのが常であるが、この光は下へ降り四方に広がる。それゆえ人々は「これは何であろうか」と驚き戸惑って見た。

【Mallinātha】

太陽と火という二つの既知の比較対象（upamāna）に対して、聖仙の光がそれらを超える性質（下方への拡散）を持つことを述べているので、修辞法としてはvyatireka（超越法）。ヘーマチャンドラはdhāmanの語義を「光線・家・身体・場所・誕生・威力」と挙げる。

I.3
Sanskrit (IAST) cayaś tviṣām ity avadhāritaṃ purā tataḥ śarīrīti vibhāvitākṛtim / vibhur vibhaktāvayavaṃ pumān iti kramād amuṃ nārada ity abodhi saḥ //
和訳

最初は「光の塊だ」と認識され、次に、姿形が判別されると「身体を持つ者だ」と、さらに肢体が分かたれて見えると「男だ」と、順を追ってこの者を「ナーラダだ」と、彼（ハリ）は知った。

注

【Vallabhadeva】

ハリはまず光の集合体と認識し、近づくにつれ姿形が見えて「身体ある者（有情）」と知り、さらに肢体が区別できて「男性」と知り、最後にナーラダと認識した。nārada iti——itiの語はprātipadikārtha（語基の意味そのもの）を示す。ナーラダが対格（目的語）であっても、iti（引用不変化辞）で表示されているために二格語尾は付かない。

【Mallinātha】

形の認識・肢体の識別がそれぞれ有情性・男性の確定の根拠として提示されているので、修辞法はkāvyaliṅga（詩的論証法）——「原因が文あるいは語の意味であるとき、それは kāvyaliṅga と呼ばれる」。

I.4
Sanskrit (IAST) navān adho 'dho bṛhataḥ payodharān samūḍhakarpūraparāgapāṇḍuram / kṣaṇaṃ kṣaṇotkṣiptagajendrakṛttinā sphuṭopamaṃ bhūtisitena śaṃbhunā //
和訳

（ナーラダは）みずみずしい大きな雲の下に、樟脳の粉末が一面に散ったかのように白く、灰（vibhūti）で白いシャンブ（シヴァ）が、踊りの刹那に象王の皮を高々と掲げた姿に、はっきりと似ていた。

注

【Vallabhadeva】

navān——水をたたえた雲、すなわち深い藍色の雲。adho 'dhaḥ——雲のすぐ下あたりにいた、の意。「upari-adhi-adhaḥ は近接を表す」により二度重ねる。samūḍha——堆積した、の意。kṣaṇam——踊り（tāṇḍava）の祝祭の折に。シヴァは象の皮を纏う者であるから、踊りの際に上に掲げた象王の皮を持つシヴァとの類似が鮮明。

【Mallinātha】

kṣaṇamの語は二義。(1) 極めて短い時間（雲の近くにいる一瞬）、(2) 祝祭・機会（tāṇḍava の場面）。sphuṭopama——明瞭な類似、すなわちシヴァにはっきりと似ている。upamāの語は類似（sādṛśya）を意味し、atulā-upamāの禁則により具格をとるとする説がある。

I.5
Sanskrit (IAST) dadhānam ambhoruhakesaradyutīr jaṭāḥ śaraccandramarīcirociṣam / vipākapiṅgās tuhinasthalīruho dharādharendraṃ vratatītatīr iva //
和訳

蓮の蕊（しべ）の輝きのような髪の房をなびかせ、自らは秋の月光のごとく白く輝く——まるで、成熟して黄褐色に色づいた雪原の蔓草（lata）を戴くヒマーラヤ山の王のようであった。

注

【Vallabhadeva】

ambhoruhakesaradyutīḥ——蓮のしべ（kiñjalka）の光に似て黄金色の、の意。jaṭāḥ dadhānam——そのような髪の房を持つ。自身はśaraccandramarīcirociṣam、すなわち秋の月光のような輝きを持つ、白い身体。それゆえvipāka（成熟）により黄褐色になった雪原の蔓草を戴くdharādharendraḥ（山の王＝ヒマーラヤ）のようである。tuhinasthalīの語から山の王がヒマヴァットであることが示される。

【Mallinātha】

vratatīは蔓（latā）の同義語。アマラコーシャに「vallī tu vratatir latā」（蔓は vratatī とも latā とも呼ばれる）とある。比喩の構造：ナーラダの黄金色の髪の房が、ヒマーラヤの成熟して色づいた蔓草に対応し、ナーラダの白い身体がヒマーラヤの雪に対応する。

I.6
Sanskrit (IAST) piśaṅgamauñjīyujam arjunacchaviṃ vasānam eṇājinam añjanadyuti / suvarṇasūtrākalitādharāmbarāṃ viḍambayantaṃ śitivāsasas tanum //
和訳

黄褐色のムンジャ草の帯を締め、白い輝きを持ちながら、墨のように黒い鹿皮（エーナアジナ）を纏い、黄金の紐で下衣を結んだその姿は、青衣のバララーマ（シティヴァーサス）の身体を模しているかのようであった。

注

【Vallabhadeva】

piśaṅgamauñjīyuj——黄褐色のムンジャ草の腰紐を着ける者。arjunacchavi——白い光沢。eṇājinam——黒鹿の皮。añjanadyuti——墨のような光沢のある。śitivāsasaḥ——青い衣を着るバララーマ。ムンジャの腰紐は黄金の紐（dorakam）に、黒鹿の皮は青い衣に対応する。暗示的直喩（ārthī upamā）。

【Mallinātha】

piśaṅgaは muñja 草の色で黄褐色。arjunaは白色。アマラコーシャに「valakṣo dhavalo 'rjunaḥ」。vas ācchādane（覆う）の現在分詞でvasānam。suvarṇasūtraは黄金の腰紐（kanakamaekhalā）、adharāmbaramは下着（antarīya）。śitivāsasaḥは「青衣の者」すなわちバララーマの身体を模倣（viḍambayantam = anukurvāṇam）していた。

I.7
Sanskrit (IAST) vihaṅgarājāṅgaruhair ivāyatair hiraṇmayorvīruhavallitantubhiḥ / kṛtopavītaṃ himaśubhram uccakair ghanaṃ ghanānte taṭitāṃ gaṇair iva //
和訳

鳥の王（ガルダ）の羽根のように長い、黄金の蔓草の繊維で聖紐（ウパヴィータ）を作り、雪のように白く——まるで雨季の終わりに、稲妻の群れをまとった高くそびえる雲のようであった。

注

【Vallabhadeva】

hiraṇmayorvīruhavallitantubhiḥ——黄金の蔓草の繊維で。kṛtopavītam——聖紐（yajñopavīta）を作った。自身はhimaśubhram（雪のように白い）。それゆえghanānte（雨季の終わり＝秋の初め）の雲のよう。秋の白雲に稲妻がまとわりつく姿に似る。uccakaiḥは「高く聳える」の意で、雲にも聖仙にもかかる。

【Mallinātha】

vihaṅgarājāṅgaruhaiḥ——鳥の王ガルダの羽毛に似た、の意で長い繊維を形容。hiraṇmayīはhiraṇyaの変化形で「dāṇḍināyana…」の規則によりmayaṭに際してyaが脱落する。アマラコーシャに「taḍit saudāmanī vidyut」（稲妻の異名）。

I.8
Sanskrit (IAST) nisargacitrojvalasūkṣmapakṣmaṇā lasadbisacchedasitāṅgasaṅginā / cakāsataṃ cārucamūrucarmaṇā kuthena nāgendram ivendravāhanam //
和訳

生まれながらに色鮮やかで、輝き、繊細な毛を持ち、蓮の茎の切り口のように白い身体にぴたりと寄り添う、美しいチャムール鹿の皮——その刺繍毛布（kutha）を纏って輝くさまは、インドラの乗騎たる象王（アイラーヴァタ）のようであった。

注

【Vallabhadeva】

cārucamūrucarma——美しいチャムール鹿の皮。「聖仙たちは皮衣を纏う（carmaprāvaraṇā hi munayaḥ）」。アマラコーシャに「samūrāś ca camūruś ca mṛgā ajinayonayaḥ」。bisacchedaは蓮の茎（mṛṇāla）の断面で、白さの比喩。indravāhanamはアイラーヴァタ象。象も白く、kutha（敷布）も色とりどりの細かい毛を持つ点で類似。

【Mallinātha】

nisarga——生来。pakṣmanは体毛（loman）。kuthaは背に敷く布。アマラコーシャに「praveṇyāstaraṇaṃ varṇaḥ parastomaḥ kutho dvayoḥ」。indrasya vāhanamの複合語は所有関係のみを表すのでṇatvaは適用されない。ヴァーマナの説に従う。cakāsatはcakāsの現在分詞で、abhyasta（重複語根）ゆえnumは入らない。

I.9
Sanskrit (IAST) ajasram āsphālitavallakīguṇa- kṣatojvalāṅguṣṭhanakhāṃśubhinnayā / puraḥ pravālair iva pūritārdhayā vibhāntam acchasphaṭikākṣamālayā //
和訳

絶えずヴァッラキー（琴）の弦を弾いて、その摩擦で輝く親指の爪の光に射され、前面が珊瑚で半ば満たされたかのように見える——そのような透明な水晶の念珠を持って輝いていた。

注

【Vallabhadeva】

acchasphaṭikākṣamālā——透明な水晶の珠の数珠。ajasram——絶え間なく弦を弾くこと。親指を裏返して弦を叩くのは調弦の作法として知られる。その摩擦で爪が光り、赤い光が水晶に混じるので、前面が珊瑚（pravāla = vidruma）で半分埋まったかのように見える。acchaの語を用いたのは、透明であればこそ赤い色を如実に映すことを強調するため。水晶の数珠であることから解脱を志す者であることが暗示される。

【Mallinātha】

爪の光が水晶に移って自らの性質（透明）を捨て他の性質（赤色）を帯びるので、修辞法はtadguṇa（性質転移法）——「tadguṇaḥ svaguṇatyāgāt」（自己の性質を捨てて他の性質を取ること）。アマラコーシャに「atha vidrumaḥ puṃsi pravālaṃ puṃnapuṃsakam」（珊瑚の別名）。

I.10
Sanskrit (IAST) raṇadbhir āghaṭṭanayā nabhasvataḥ pṛthag vibhinnaśrutimaṇḍalaiḥ svaraiḥ / sphuṭībhavadgrāmaviśeṣamūrcchanām avekṣamāṇaṃ mahatīṃ muhurmuhuḥ //
和訳

風の衝撃により響き、それぞれ異なるシュルティ（微分音）の群を持つ音階が鳴り渡り、グラーマ（旋法）ごとのムールッチャナー（音階上行下行）が明瞭に現れるのを——自らのマハティー琴について——繰り返し観察していた。

注

【Vallabhadeva】

mahatīm——百弦琴（śatatantrīkā vīṇā）で、ナーラダ固有の琴の名。驚きゆえに繰り返し見つめていた。スヴァラ（音）は風の触発で自然に鳴り響き（anāhata）、人の手を借りずにグラーマの旋法が明瞭に現れるので驚嘆した。グラーマは三種——ṣaḍja, madhyama, gāndhāra。ムールッチャナーはスヴァラの上行下行の順序の別で、各グラーマに七ずつ計二十一。

【Mallinātha】

音楽理論の詳説。śruti——スヴァラを構成する微分音。ṣaḍja, madhyama, pañcama は各4シュルティ、ṛṣabha, dhaivata は各3、niṣāda, gāndhāra は各2、計22シュルティ。人の演奏なしに自然に旋法が現出するという超自然の技が示され、修辞法としてはatśayokti（誇張法）の一種。

I.11
Sanskrit (IAST) nivartya so 'nuvrajataḥ kṛtānatīn atīndriyajñānanidhir nabhaḥsadaḥ / samāsadat sāditadaityasampadaḥ padaṃ mahendrālayacāru cakriṇaḥ //
和訳

超感覚的な知識の宝庫たるその聖仙（ナーラダ）は、敬礼して随行する天界の住人たちを退け、悪魔の富を打ち滅ぼした円盤を持つ者（ヴィシュヌ＝クリシュナ）の、インドラの宮殿のごとく美しい住処に到着した。

注

【Vallabhadeva】

atīndriyajñānanidhiḥ——感覚を超えた知（時空・事物の本質に関する知識）の蔵。kṛtānatīn——礼拝した者たちを。許可を得た者は頭を下げるのが礼法。nabhaḥsadaḥ——空に住む者たち、すなわち神々を退かせて。sāditadaityasampadaḥ——悪魔たちの富を滅ぼした者、すなわちヴィシュヌの館に到った。転生の意義を暗示。

【Mallinātha】

natīn-atīn、padaḥ-padamの二組の同音反復はchekaanuprāsa（巧みな頭韻）。他の箇所のvṛttyanuprāsa（音の繰返し）とのsaṃsṛṣṭi（混合修辞）。

I.12
Sanskrit (IAST) patatpataṅgapratimas taponidhiḥ puro 'sya yāvan na bhuvi vyalīyata / gires taḍitvān iva tāvad uccakair javena pīṭhād udatiṣṭhad acyutaḥ //
和訳

降りてくる太陽にも似た苦行の宝庫（ナーラダ）が、ハリの前の地上にまだ降り立たぬうちに、早くもアチュタ（クリシュナ）は——山から稲妻を帯びた雲が立ち上がるかのように——高い座から勢いよく立ち上がった。

注

【Vallabhadeva】

patatpataṅgapratimaḥ——落ちてくる太陽のような、光輝ゆえに。yāvat … tāvatの呼応で、ナーラダが着地する前にクリシュナが既に立ち上がっていたことを示し、敬意の深さを表す。法典に「若者が年長者に対し立ち上がって迎え礼拝すれば、寿命・学識・名声・力を取り戻す」とある（マヌ法典）。

【Mallinātha】

pataṅgaは太陽。アマラコーシャに「pataṅgau pakṣisūryau ca」。太陽が「落ちる」ことは現実にはありえないので、ダンディン等の古師はこれをabhūtopamā（非実在の直喩）と見なした。近代の修辞学者たちは、知られていないものを比喩の対象にできないとしてutprekṣā（想像法）と分類する。

I.13
Sanskrit (IAST) atha prayatnonnamitānamatphaṇair dhṛte kathañcit phaṇināṃ gaṇair adhaḥ / nyadhāyiṣātām abhi devakīsutaṃ sutena dhātuś caraṇau bhuvas tale //
和訳

そこで、造物主（ブラフマー）の息子（ナーラダ）により、デーヴァキーの息子（クリシュナ）に向かって、大地の表面に両足が置かれた。その大地は、力を込めて頭をもたげたがまた垂れてしまう頭巾を持つ蛇の群れに、かろうじて支えられていた。

注

【Vallabhadeva】

ナーラダが足を踏み下ろすと、その威厳の重みで地下の蛇神たちの頭巾が下がりかけ、懸命に持ち上げてもまた撓む——かろうじて大地を支えた。これにより両者の偉大さ（mahāpuruṣalakṣaṇa）と威厳の超絶が表現される。nyadhāyiṣātāmはni-dhāの受動態 luṅ（アオリスト）。

【Mallinātha】

蛇の頭巾の上下動は実際には聖仙の足の重さとは無関係だが、聖仙の威厳のためにその関係を述べるのはatiśayokti（誇張法）の一種。abhi devakīsutamはavyayībhāva（不変化複合語）で「デーヴァキーの息子に向かって」の意。

I.14
Sanskrit (IAST) tam arghyam arghyādikayādipūruṣaḥ saparyayā sādhu sa paryapūjayat / gṛhān upaitum praṇayād abhīpsavo bhavanti nāpuṇyakṛtāṃ manīṣiṇaḥ //
和訳

原初の御方（ādi-pūruṣa＝クリシュナ）は、供物に値するその聖仙を、アルギャ（迎賓水）などの礼をもって丁重に敬った。まことに、徳を積まぬ者の家を、賢者たちは好意から訪れたいとは思わないものである。

注

【Vallabhadeva】

II.23

注

【Vallabhadeva】

atiśayyateはśīṅのカルマニ・ラティにyak（ayaṅ yi ktiのayaṅ代置）。bhūyasyā＝bahulatarā（より多い）、bahulope bhū caの代置。言葉の威力は量ではなく意味の重さにある。同一の法則（dharma）を映すdṛṣṭānta（比喩証明）。

II.24

和訳

注

【Vallabhadeva】

クリシュナの言葉のいわば注釈（bhāṣya）——「もし私がハリの簡潔な言葉の注釈をしなければ、ウッダヴァのような知者がその言を解体しかねない。注釈すれば味方として支持することになる」と言い、自らの発言の必然性を弁明する（svadānītaka：自分の発言の正当化）。sūtra（経典）の解説がbhāṣya（注釈）であるように。

【Mallinātha】

凌駕し得ないならばなぜ語るのかという問いに答える。bhāṣyabhūtā＝bhāṣyaiḥ samāḥ（注釈に等しい）、nityasamāsa（恒常複合語）。パタンジャリのマハーバーシュヤのように、スートラを敷衍して本義を明らかにするのであって、超越するためではない（na tv atiśayāya pratyākhyāyata ity adoṣaḥ）。upamālaṅkāra（比喩修辞）。GRETILのbhūṣyabhūtāはbhāṣyabhūtāに訂正。

II.25
Sanskrit (IAST) virodhivacaso mūkān vāgīśān api kurvate / jaḍān apy anulomārthapravācaḥ kṛtināṃ giraḥ //
和訳

知者たちの言葉（kṛtināṃ giraḥ）は、敵対する論者（virodhivacasaḥ）を、弁舌の王（vāgīśān）であろうとも沈黙させ、愚鈍な者（jaḍān）をも順理（anulomārtha）に巧みな弁者（pravācaḥ）にする。

注

【Vallabhadeva】

Vallabhadevaではこの偈がII.24。vāgīśān＝sarvaśāstrajñān（一切の学を知る者）をもmūkān（唖者）にする。対論者（prativādin）を沈黙に追い込み、味方は愚者でも順序だった論述ができるようにする——ゆえに自分もクリシュナの言を注釈しなければならない。

II.26
Sanskrit (IAST) ṣaḍguṇāḥ śaktayas tisraḥ siddhayaś codayās trayaḥ / granthān adhītya vyākartum iti durmedhaso 'py alam //
和訳

六種の方策（ṣaḍguṇa）、三つの力（śakti）、諸成就（siddhi）、そして三種の興隆（udaya）——これらを書物から学んで解説するだけなら、愚鈍な者（durmedhas）にも可能である。

注

【Vallabhadeva】

ṣaḍguṇa＝saṃdhi（和睦）・vigraha（開戦）・yāna（進軍）・āsana（静観）・dvaidhībhāva（二股）・saṃśraya（帰附）。śakti三種＝prabhu（主権力：koṣa財とdaṇḍa軍）・mantra（智謀力：vijñānasaṃpat）・utsāha（勇猛力：parākrama）。siddhi＝三力から生ずる成果。udaya＝vṛddhi（増大）・kṣaya（衰退）・sthāna（維持）の三状態。これらは書物の知識にすぎず、本当のmantra（審議）はaṅgapañcaka（五肢）にある。

durmedhasはnityam asic ajāmedhyoḥのsamāsānta。ṣaḍguṇa等の分類は書物的知識であり、五肢の判断力こそがmantraである——書物だけの学者（pañcāṅganirṇayaśaktiviḥkānāṃ saṃkhyāmātrapāṭhakānām）は信ずべきではない。アマラコーシャの定義を引く。GRETILのsiddhayodayāstrayaḥはsiddhayaś codayās trayaḥに訂正（ca脱落）、またgrandhānはgranthānに訂正。

II.27
Sanskrit (IAST) anirloḍitakāryasya vāgjālaṃ vāgmino vṛthā / nimittād aparāddheṣor dhanuṣkasyeva valgitam //
和訳

事の本質を吟味していない（anirloḍitakārya）弁舌家（vāgmin）の言葉の網（vāgjāla）は無益である。それはちょうど、的（nimitta）を外した矢を持つ弓手（dhanuṣka）の威勢（valgita）が無益であるようなものだ。

注

【Vallabhadeva】

多弁に何の意味もなく、kāryatattva（事の本質）こそが肝要であることを示す。anirloḍita＝未吟味の（anirṇīta）。vāgminは弁舌に長けた者。nimitta＝lakṣya（的）。dhānuka（弓を持つ者、dhanuḥ praharaṇam asyaのṬhak接尾辞）が的を外した後に威張っても無益。

【Mallinātha】

書物的知識だけでは不十分であることの帰結。vāgmin＝vāvadūka（多弁家、vāco gminのgmini接尾辞）。nimittaはvedhya（貫くべきもの）＝lakṣya（「vedhyaṃ lakṣyaṃ nimittaṃ ca」とVaijayantī）。dhanuṣka＝弓を武器とする者（praharaṇam iti ṭhak, isusukrāntāt kaḥ）。事の核心を知る者の言葉のみが採るべきである（kāryajñasya vaco grāhyam）。

II.28
Sanskrit (IAST) sarvakāryaśarīreṣu muktvāṅgaskandhapañcakam / saugatānām ivātmānyo nāsti mantro mahībhṛtām //
和訳

仏教徒（saugata）にとって五蘊（skandhapañcaka）を除いて一切の身体に別のアートマンがないように、王たちにとっても五肢（aṅgapañcaka）を除いて一切の事業において別の審議（mantra）はない。

注

【Vallabhadeva】

aṅgapañcaka（審議の五肢）＝①行動の開始方法（karmāṇām ārambhopāya）、②人員・財の充足（puruṣadravyasaṃpat）、③時所の配分（deśakālavibhāga）、④不測への対処（vipattipratīkāra）、⑤事業の完遂（kāryasiddhi）。カーマンダキのNītisāra引用。skandhapañcaka（五蘊）＝色・受・識・想・行（rūpa-vedanā-vijñāna-saṃjñā-saṃskāra）。仏教徒は五蘊以外にアートマンを認めない。upamā（直喩）。

【Mallinātha】

多弁の否定から一転してmantraの本質を述べる。sarvakāryaśarīreṣu＝一切の事業を身体に喩えるupamitasamāsa（比喩的複合語）。aṅgāni skandhāḥもまたupamitasamāsa。仏教の五蘊＝rūpa（色：対象の展開）・vedanā（受：知覚の展開）・vijñāna（識：ālayavijñāna相続）・saṃjñā（想：名称の展開）・saṃskāra（行：習気の展開）。五蘊以外にアートマンなきように、五肢以外にマントラなし——upamālaṅkāra。これにより即時行動すべし（yātrākāla）。

II.29
Sanskrit (IAST) mantro yodha ivādhīraḥ sarvāṅgaiḥ saṃvṛtair api / ciraṃ na sahate sthātuṃ parebhyo bhedaśaṅkayā //
和訳

審議（mantra）は、臆病な（adhīra）戦士（yodha）のごとく、あらゆる肢体（sarvāṅga）を鎧で覆っていても（saṃvṛtair api）、敵（para）に漏洩する（bheda）おそれから、長くは耐えられない（na sahate sthātum）。

注

【Vallabhadeva】

mantraの遅延はmantraśakti（智謀力）の損失に繋がることを示す。sarvāṅgaiḥ＝前述のkarmārambhaṇopāya等の五肢でkalpitaiḥ（整えられた）としても、adhīra＝bahukālāvasthānāsahaḥ（長時間の持続に堪えない）。bheda＝漏洩（udbhṛti）。臆病な兵士が甲冑を着ても反撃を恐れて長く留まれないのと同じ——迅速に行動すべし。

【Mallinātha】

審議の遅延の害を説く。saṃvṛtaiḥ＝guptaiḥ（秘匿された）。adhīra＝bhīru（臆病）。yodhaはyudhからpacādyac。bhedaは漏洩（vidāraṇa）と第三者への流出（tṛtīyagāmitva）。sahate sthātumはśakadhr̥ṣeのtumun。ゆえに遅滞すべきではなく、さもなくばmantrabhedaḥ（審議の漏洩）でkāryahāni（事業の失敗）を招く。GRETILにはsahateが脱落しており補った。

II.30
Sanskrit (IAST) ātmodayaḥ parajyānir dvayaṃ nītir itīyatī / tad ūrīkṛtya kṛtibhir vācaspatyaṃ pratāyate //
和訳

自らの興隆（ātmodaya）と敵の衰退（parajyāni）——この二つ（dvayam）こそが政道（nīti）の全体（iyatī）である。それを根幹として受け容れ（ūrīkṛtya）、知者たち（kṛtibhiḥ）の弁舌の巧み（vācaspatyam）は展開される（pratāyate）。

注

【Vallabhadeva】

ātmodaya＝自身の発展、parajyāni＝敵の衰亡。jyāniはbījyāhājvaribhyo niḥのauṇādika ni接尾辞。iyatī（これだけの量の）はkim-idaṃbhyāṃ vo ghaḥのvatupにugitaś caのṅīP。その他のṣaḍguṇa等はすべてこの二原理の展開にすぎない。vācaspatyam＝弁才（vāgīśvaratvam）。pratāyateはtanのカルマニ・ラティ（tanoter yaki āttvam）。ゆえに時間の空費は無意味。

【Mallinātha】

nītiの全体を精査しても遅延の理由はないことを示す。jyāniはhāni（衰亡）。ūrīkṛtyaはūrī（ūrīkṛtasurīkṛtam aṅgīkṛtamとアマラコーシャ）のcvipからkugatiprādayaḥで複合しktvāのlyap代置。vācaspatyam＝弁舌の主宰（vāgmitvam）。この二原理を種子（bīja）として一切の政論が展開されるのであり、我々にもその種子は明らか——ゆえに時間を費やす理由は何もない。

II.31
Sanskrit (IAST) tṛptiyogaḥ pareṇāpi mahimnā na mahātmanām / pūrṇaś candrodayākāṅkṣī dṛṣṭānto 'tra mahārṇavaḥ //

II.32

和訳

注

II.33
Sanskrit (IAST) samūlaghātam aghnantaḥ parān nodyanti māninaḥ / pradhvaṃsitāndhatamasas tatrodāharaṇaṃ raviḥ //
和訳

敵を根こそぎ（samūlaghātam）滅ぼさずしては、誇り高き者（mānin）は興隆しない（na udyanti）。深い闇（andhatamasas）を破壊した太陽（ravi）がその例証（udāharaṇa）である。

注

【Vallabhadeva】

敵の衰亡こそが自らの興隆の原因であることを示す。samūlaghātamはsamūlākṛtajīveṣu hanūdvagrahaḥのṆamul接尾辞。太陽は闇を破壊してからでなければ昇らない——キラータールジュニーヤ引用：avibhidya niśākṛtaṃ tamaḥ prabhayā nāṃśumatāpy udīyate。

【Mallinātha】

māninaḥ＝abhimāninaḥ（矜持ある者）。aghnantaḥはhanのśatṛ形。andhatamasam＝gāḍhaṃ tamaḥ（濃密な闇、アマラコーシャ：dhvānte gāḍhe 'ndhatamasam）。ここもII.31と同じくupamālaṅkāraでありdṛṣṭāntaではないと注記。GRETILのśamūlaはsamūlaに訂正。

II.34
Sanskrit (IAST) vipakṣam akhilīkṛtya pratiṣṭhā khalu durlabhā / anītvā paṅkatāṃ dhūlim udakaṃ nāvatiṣṭhate //
和訳

敵（vipakṣa）を殲滅せずしては（akhilīkṛtya）、安定した地位（pratiṣṭhā）は実に得がたい。塵を泥（paṅka）にせずに（anītvā paṅkatām）、水は留まることがないように。

注

【Vallabhadeva】

興隆以前に、敵を殲滅しなければ安定すら覚束ないことを示す。khaluは前言を受けた限定辞。水は塵を泥にしてはじめて留まるように、敵を滅ぼしてはじめて足場を得る。avatiṣṭhateはアートマネーパダ（samavapravibhyaḥ sthaḥ）。

【Mallinātha】

akhilīkṛtya＝khilam utsaṅgam akṛtvā（荒地＝廃墟にせずして＝殲滅せずして）。pratiṣṭhāは足場。水は塵を泥に変えてはじめて定着する——文の分離によるpratibimbaを要するためdṛṣṭāntālaṅkāra（例証修辞）。

II.35
Sanskrit (IAST) dhriyate yāvad eko 'pi ripus tāvat kutaḥ sukham / puraḥ kliśnāti somaṃ hi saiṃhikeyo 'suradruhām //
和訳

たった一人の敵（ripu）が生き延びている限り（dhriyate yāvat）、どこに安寧（sukha）があろうか。ラーフ（saiṃhikeya＝シンヒカーの子）は、神々（asuradruhām）の眼前で（puraḥ）月（soma）を苦しめるのだから。

注

【Vallabhadeva】

Vallabhadevaはśivam（吉祥）と読む。シシュパーラ一人は脅威ではないとの反論に対し——たった一人でも敵は害を成す。ラーフが日月を飲むのと同じ（somagrahaṇam upalakṣaṇam——月食は日食をも含む表現）。ゆえに討つべし（tasmād yāvaṃ yāma）。

【Mallinātha】

dhriyateはdhṛñ avasthāne（存続する）のtaudādika・kartari・laṭ、riḍādeśaつき。特殊から一般を支持するarthāntaranyāsa（趣旨転換修辞）。格言引用：agneḥ śeṣam ṛṇāc cheṣaṃ śatroḥ śeṣaṃ na śeṣayet（火・借金・敵の残りは残すな）。GRETILのklaśnātiはkliśnātiに訂正。

II.36
Sanskrit (IAST) sakhā garīyān śatruś ca kṛtrimas tau hi kāryataḥ / syātām amitrau mitre ca sahajaprākṛtāv api //
和訳

友人（sakhā）も敵（śatru）も、行為に基づく（kāryataḥ）人為的な（kṛtrima）者こそが重要（garīyān）である。なぜなら、生来の（sahaja）ものも自然な（prākṛta）ものすら、〔行為次第で〕敵にも友にもなりうるから。

注

【Vallabhadeva】

味方敵論（mitrāmitrabala）の三分類——sahaja（生来の：母方従兄弟＝味方、叔父方＝敵）、prākṛta（自然の：隣国＝敵、その隣＝味方）、kṛtrima（人為の：恩義・害悪による）。人為的な味方敵は行為（upakāra/apakāra）に基づくため終生不変——ゆえに最も重い。格言引用：nāsti jātyā ripur nāma mitraṃ jātyā na vidyate / sāmarthyayogāj jāyante mitrāṇi ripvas tathā。

【Mallinātha】

シシュパーラは卑小だから問題ないとの反論への回答——彼のbalavattā（強大さ）を示すため味方敵の区分を論ずる。kṛtrima＝行為（upakārāpakāra）によって成立する。生来・自然の者は状況で入れ替わるが、kṛtrimaは行為に由来するゆえ揺るがない——kṛtrimatvaṃ sarvāpavādāt（人為性がすべてに優先する）。

II.37
Sanskrit (IAST) upakartāriṇā saṃdhir na mitreṇāpakāriṇā / upakārāpakārau hi lakṣyaṃ lakṣaṇam etayoḥ //
和訳

恩恵を施す敵（upakartṛ ariṇā）とこそ和睦（saṃdhi）すべきであり、害をなす友人（mitreṇa apakāriṇā）とではない。なぜなら恩恵と害悪（upakāra-apakāra）こそが、この両者（友敵）の真の定義（lakṣaṇa）であり、見極めるべきもの（lakṣya）であるから。

注

【Vallabhadeva】

敵であっても恩恵を施す者とは和睦すべし——敵性の例外としてkṛtrima-mitratā（人為的友誼）がより強いため。味方であっても害をなす者とは断交すべし。格言引用：yas tv amitreṇa saṃdhatte mitraṃ ca viddhyati / arthayuktiṃ samālocya sa mahad vindate phalam。

【Mallinātha】

シシュパーラはpaitṛṣvaseyatva（父方姉妹の子）ゆえsahajamitra（生来の友）であるから討つべきでないとの反論への応答。行為（kriyā）により友敵が逆転しうるため、upakāra-apakāraこそがlakṣaṇa（定義）でありlakṣya（観察すべきもの）である。GRETILのupakartrariṇā・lakṣamamを訂正。

II.38
Sanskrit (IAST) tvayā viprakṛtaś caidyo rukmiṇīṃ haratā hare / baddhamūlasya mūlaṃ hi mahad vairataroḥ striyaḥ //
和訳

ハリよ、ルクミニーを奪い去った（haratā）お前によって、チェーディ王（caidya）は傷つけられた（viprakṛta）。根深い（baddhamūla）怨恨の木（vairataru）の偉大な根（mūla）とは、女性（striyaḥ）なのだから。

注

【Vallabhadeva】

一般論から具体論へ——チェーディのkṛtrimatā（人為的敵性）を四偈（II.38-41）で示す。ルクミニーは親族によりシシュパーラに与えられていたが、クリシュナがラークシャサ婚（rākṣasadharma＝武力略奪婚）で奪った。vairataru（怨恨の木）はrūpaka（隠喩）融合のarthāntaranyāsa。

【Mallinātha】

ヤージュニャヴァルキヤ引用：rākṣaso yuddhaharaṇāt。マヌ引用：gāndharvo rākṣasaś caiva dharmyau kṣatrasya tau smṛtau（ガーンダルヴァ婚とラークシャサ婚はクシャトリヤの正法）。baddhamūla＝rūḍhamūla（根を張った）。rūpakasaṃsṛṣṭa（隠喩混合）のarthāntaranyāsa（一般により特殊を支持する修辞）。

II.39
Sanskrit (IAST) tvayi bhaumaṃ gate jetum auratsīt sa purīm imām / proṣitāryamaṇaṃ meror andhakāras taṭīm iva //
和訳

お前がバウマ（ナラカースラ）を討ちに出た（gate）とき、彼（シシュパーラ）はこの都（purī＝ドヴァーラカー）を包囲した（auratsīt）。それはあたかも、アーリヤマン（太陽）が去った（proṣita）メール山の斜面（taṭī）を闇（andhakāra）が覆うがごとく。

注

【Vallabhadeva】

シシュパーラによるクリシュナへの逆の害——クリシュナがナラカースラ征伐に出陣した隙に、ドヴァーラカーを攻めた。auratsīt（Vallabhadevaはautsīt saと読む）はrudhのルング。太陽が去ったメール山の斜面に闇が忍び寄るというupamā（直喩）。

【Mallinātha】

bhauma＝bhūmeḥ apatyaṃ pumān（大地の子＝ナラカースラ）。auratsītはrudh（阻止する・包囲する）のaniṬ・ルング・sic加入による活用形。クリシュナ＝太陽、シシュパーラ＝闇、ドヴァーラカー＝メール山の斜面。upamālaṅkāra。

II.40
Sanskrit (IAST) ālapyālam iyaṃ babhror yat sa dārān apāharat / kathāpi khalu pāpānām alam aśreyase yataḥ //
和訳

彼（シシュパーラ）がバブル（ヤーダヴァの一族）の妻を奪った（dārān apāharat）ことは——口にするだけで（ālapya）もう十分（alam）。悪人の所業は、その話題に触れること（kathā）すら、災い（aśreyas）をもたらすに十分なのだから。

注

【Vallabhadeva】

チェーディの更なる悪行——バブル（ヴリシュニ族の一人）の妻の略奪。ālapya alamはālapya（口にして）+ alam（十分、禁止の意：nālapanīyam＝口にすべきでない）。alṃkhalvoḥ pratiṣedhayoḥ prācāṃ ktvāの規則でktvā接尾辞、複合時にlyab代置。

【Mallinātha】

dāra＝妻（bhāryā jāyāのsynonym。アマラコーシャ）。kathā＝kathana（言及）、cintipūjikudhikumbiのa接尾辞。悪人の言及すら災いを招く——口にすることの禁止により、その行為の禁止を正当化するarthāntaranyāsa（趣旨転換修辞：結果による原因の支持）。
