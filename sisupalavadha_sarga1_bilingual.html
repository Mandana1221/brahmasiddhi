प्रथमः सर्गः

第一章　ナーラダの来訪（見本：第1〜5偈）
韻律：vaṃśastha（ヴァンシャスタ）——全75偈
I.1
Sanskrit (IAST) śriyaḥ patiḥ śrīmati śāsituṃ jagaj- jagannivāso vasudevasadmani / vasan dadarśāvatarantam ambarād dhiraṇyagarbhāṅgabhuvaṃ muniṃ hariḥ //
和訳

シュリー（吉祥天）の夫にして、世界の住処たるハリ（ヴィシュヌ）は、世界を統治するために、栄えあるヴァスデーヴァの館に住まいしていたが、あるとき空から降りてくる聖仙——ヒラニヤガルバ（ブラフマー）の身体から生まれた者（ナーラダ）——を見た。

注

【Vallabhadeva】

śriyaḥ patiḥ——ラクシュミーの夫。これにより、ルクミニーの姿をとったシュリーを伴っていることが示唆される。『ヴィシュヌ・プラーナ』に「ラーマの時にはシーター、クリシュナに生まれた時にはルクミニー」とある。jagannivāsaḥ——諸世界の依りどころ。腹中に全宇宙を収める者の意。hiraṇyagarbhāṅgabhuvaṃ——ヒラニヤガルバ（ブラフマー）の身から生まれた者、すなわちナーラダ。『バーガヴァタ』に「ブラフマーの膝から（ナーラダは生まれた）」とある。

【Mallinātha】

冒頭にśrīの語を用いるのは、「成就を祈願して吉祥語等で詩作を始めるべし」という教説に従う吉祥の開始（maṅgalādi）。修辞として、巨大なハリが小さなヴァスデーヴァの館に容れられるというadhika（誇張法）。またjagaj-jaganの音の反復はvṛttyanuprāsa（繰返し音韻）。韻律は vaṃśastha——「ja-ta-ja-ra の脚が vaṃśastha と称される」。

I.2
Sanskrit (IAST) gataṃ tiraścīnam anūrusāratheḥ prasiddham ūrdhvajvalanaṃ havirbhujaḥ / pataty adho dhāma visāri sarvataḥ kim etad ity ākulam īkṣitaṃ janaiḥ //
和訳

「太腿なき御者（アルナ）を持つ太陽の光は水平に進み、供物を食らう火（アグニ）の炎は上方に燃え上がることで知られている。ところが、この光は下方へ、四方に広がりつつ降ってくる——これは一体何であろうか」と、人々は動揺して見つめた。

注

【Vallabhadeva】

anūrusāratheḥ——太腿がない者を御者とする者、すなわちスーリヤ（太陽神）。御者アルナは太腿がないとされる。havirbhujaḥ——供物を食する者、すなわちアグニ（火神）。太陽の光は横に進み、火の炎は上に向かうのが常であるが、この光は下へ降り四方に広がる。それゆえ人々は「これは何であろうか」と驚き戸惑って見た。

【Mallinātha】

太陽と火という二つの既知の比較対象（upamāna）に対して、聖仙の光がそれらを超える性質（下方への拡散）を持つことを述べているので、修辞法としてはvyatireka（超越法）。ヘーマチャンドラはdhāmanの語義を「光線・家・身体・場所・誕生・威力」と挙げる。

I.3
Sanskrit (IAST) cayaś tviṣām ity avadhāritaṃ purā tataḥ śarīrīti vibhāvitākṛtim / vibhur vibhaktāvayavaṃ pumān iti kramād amuṃ nārada ity abodhi saḥ //
和訳

最初は「光の塊だ」と認識され、次に、姿形が判別されると「身体を持つ者だ」と、さらに肢体が分かたれて見えると「男だ」と、順を追ってこの者を「ナーラダだ」と、彼（ハリ）は知った。

注

【Vallabhadeva】

ハリはまず光の集合体と認識し、近づくにつれ姿形が見えて「身体ある者（有情）」と知り、さらに肢体が区別できて「男性」と知り、最後にナーラダと認識した。nārada iti——itiの語はprātipadikārtha（語基の意味そのもの）を示す。ナーラダが対格（目的語）であっても、iti（引用不変化辞）で表示されているために二格語尾は付かない。

【Mallinātha】

形の認識・肢体の識別がそれぞれ有情性・男性の確定の根拠として提示されているので、修辞法はkāvyaliṅga（詩的論証法）——「原因が文あるいは語の意味であるとき、それは kāvyaliṅga と呼ばれる」。

I.4
Sanskrit (IAST) navān adho 'dho bṛhataḥ payodharān samūḍhakarpūraparāgapāṇḍuram / kṣaṇaṃ kṣaṇotkṣiptagajendrakṛttinā sphuṭopamaṃ bhūtisitena śaṃbhunā //
和訳

（ナーラダは）みずみずしい大きな雲の下に、樟脳の粉末が一面に散ったかのように白く、灰（vibhūti）で白いシャンブ（シヴァ）が、踊りの刹那に象王の皮を高々と掲げた姿に、はっきりと似ていた。

注

【Vallabhadeva】

navān——水をたたえた雲、すなわち深い藍色の雲。adho 'dhaḥ——雲のすぐ下あたりにいた、の意。「upari-adhi-adhaḥ は近接を表す」により二度重ねる。samūḍha——堆積した、の意。kṣaṇam——踊り（tāṇḍava）の祝祭の折に。シヴァは象の皮を纏う者であるから、踊りの際に上に掲げた象王の皮を持つシヴァとの類似が鮮明。

【Mallinātha】

kṣaṇamの語は二義。(1) 極めて短い時間（雲の近くにいる一瞬）、(2) 祝祭・機会（tāṇḍava の場面）。sphuṭopama——明瞭な類似、すなわちシヴァにはっきりと似ている。upamāの語は類似（sādṛśya）を意味し、atulā-upamāの禁則により具格をとるとする説がある。

I.5
Sanskrit (IAST) dadhānam ambhoruhakesaradyutīr jaṭāḥ śaraccandramarīcirociṣam / vipākapiṅgās tuhinasthalīruho dharādharendraṃ vratatītatīr iva //
和訳

蓮の蕊（しべ）の輝きのような髪の房をなびかせ、自らは秋の月光のごとく白く輝く——まるで、成熟して黄褐色に色づいた雪原の蔓草（lata）を戴くヒマーラヤ山の王のようであった。

注

【Vallabhadeva】

ambhoruhakesaradyutīḥ——蓮のしべ（kiñjalka）の光に似て黄金色の、の意。jaṭāḥ dadhānam——そのような髪の房を持つ。自身はśaraccandramarīcirociṣam、すなわち秋の月光のような輝きを持つ、白い身体。それゆえvipāka（成熟）により黄褐色になった雪原の蔓草を戴くdharādharendraḥ（山の王＝ヒマーラヤ）のようである。tuhinasthalīの語から山の王がヒマヴァットであることが示される。

【Mallinātha】

vratatīは蔓（latā）の同義語。アマラコーシャに「vallī tu vratatir latā」（蔓は vratatī とも latā とも呼ばれる）とある。比喩の構造：ナーラダの黄金色の髪の房が、ヒマーラヤの成熟して色づいた蔓草に対応し、ナーラダの白い身体がヒマーラヤの雪に対応する。

I.6
Sanskrit (IAST) piśaṅgamauñjīyujam arjunacchaviṃ vasānam eṇājinam añjanadyuti / suvarṇasūtrākalitādharāmbarāṃ viḍambayantaṃ śitivāsasas tanum //
和訳

黄褐色のムンジャ草の帯を締め、白い輝きを持ちながら、墨のように黒い鹿皮（エーナアジナ）を纏い、黄金の紐で下衣を結んだその姿は、青衣のバララーマ（シティヴァーサス）の身体を模しているかのようであった。

注

【Vallabhadeva】

piśaṅgamauñjīyuj——黄褐色のムンジャ草の腰紐を着ける者。arjunacchavi——白い光沢。eṇājinam——黒鹿の皮。añjanadyuti——墨のような光沢のある。śitivāsasaḥ——青い衣を着るバララーマ。ムンジャの腰紐は黄金の紐（dorakam）に、黒鹿の皮は青い衣に対応する。暗示的直喩（ārthī upamā）。

【Mallinātha】

piśaṅgaは muñja 草の色で黄褐色。arjunaは白色。アマラコーシャに「valakṣo dhavalo 'rjunaḥ」。vas ācchādane（覆う）の現在分詞でvasānam。suvarṇasūtraは黄金の腰紐（kanakamaekhalā）、adharāmbaramは下着（antarīya）。śitivāsasaḥは「青衣の者」すなわちバララーマの身体を模倣（viḍambayantam = anukurvāṇam）していた。

I.7
Sanskrit (IAST) vihaṅgarājāṅgaruhair ivāyatair hiraṇmayorvīruhavallitantubhiḥ / kṛtopavītaṃ himaśubhram uccakair ghanaṃ ghanānte taṭitāṃ gaṇair iva //
和訳

鳥の王（ガルダ）の羽根のように長い、黄金の蔓草の繊維で聖紐（ウパヴィータ）を作り、雪のように白く——まるで雨季の終わりに、稲妻の群れをまとった高くそびえる雲のようであった。

注

【Vallabhadeva】

hiraṇmayorvīruhavallitantubhiḥ——黄金の蔓草の繊維で。kṛtopavītam——聖紐（yajñopavīta）を作った。自身はhimaśubhram（雪のように白い）。それゆえghanānte（雨季の終わり＝秋の初め）の雲のよう。秋の白雲に稲妻がまとわりつく姿に似る。uccakaiḥは「高く聳える」の意で、雲にも聖仙にもかかる。

【Mallinātha】

vihaṅgarājāṅgaruhaiḥ——鳥の王ガルダの羽毛に似た、の意で長い繊維を形容。hiraṇmayīはhiraṇyaの変化形で「dāṇḍināyana…」の規則によりmayaṭに際してyaが脱落する。アマラコーシャに「taḍit saudāmanī vidyut」（稲妻の異名）。

I.8
Sanskrit (IAST) nisargacitrojvalasūkṣmapakṣmaṇā lasadbisacchedasitāṅgasaṅginā / cakāsataṃ cārucamūrucarmaṇā kuthena nāgendram ivendravāhanam //
和訳

生まれながらに色鮮やかで、輝き、繊細な毛を持ち、蓮の茎の切り口のように白い身体にぴたりと寄り添う、美しいチャムール鹿の皮——その刺繍毛布（kutha）を纏って輝くさまは、インドラの乗騎たる象王（アイラーヴァタ）のようであった。

注

【Vallabhadeva】

cārucamūrucarma——美しいチャムール鹿の皮。「聖仙たちは皮衣を纏う（carmaprāvaraṇā hi munayaḥ）」。アマラコーシャに「samūrāś ca camūruś ca mṛgā ajinayonayaḥ」。bisacchedaは蓮の茎（mṛṇāla）の断面で、白さの比喩。indravāhanamはアイラーヴァタ象。象も白く、kutha（敷布）も色とりどりの細かい毛を持つ点で類似。

【Mallinātha】

nisarga——生来。pakṣmanは体毛（loman）。kuthaは背に敷く布。アマラコーシャに「praveṇyāstaraṇaṃ varṇaḥ parastomaḥ kutho dvayoḥ」。indrasya vāhanamの複合語は所有関係のみを表すのでṇatvaは適用されない。ヴァーマナの説に従う。cakāsatはcakāsの現在分詞で、abhyasta（重複語根）ゆえnumは入らない。

I.9
Sanskrit (IAST) ajasram āsphālitavallakīguṇa- kṣatojvalāṅguṣṭhanakhāṃśubhinnayā / puraḥ pravālair iva pūritārdhayā vibhāntam acchasphaṭikākṣamālayā //
和訳

絶えずヴァッラキー（琴）の弦を弾いて、その摩擦で輝く親指の爪の光に射され、前面が珊瑚で半ば満たされたかのように見える——そのような透明な水晶の念珠を持って輝いていた。

注

【Vallabhadeva】

acchasphaṭikākṣamālā——透明な水晶の珠の数珠。ajasram——絶え間なく弦を弾くこと。親指を裏返して弦を叩くのは調弦の作法として知られる。その摩擦で爪が光り、赤い光が水晶に混じるので、前面が珊瑚（pravāla = vidruma）で半分埋まったかのように見える。acchaの語を用いたのは、透明であればこそ赤い色を如実に映すことを強調するため。水晶の数珠であることから解脱を志す者であることが暗示される。

【Mallinātha】

爪の光が水晶に移って自らの性質（透明）を捨て他の性質（赤色）を帯びるので、修辞法はtadguṇa（性質転移法）——「tadguṇaḥ svaguṇatyāgāt」（自己の性質を捨てて他の性質を取ること）。アマラコーシャに「atha vidrumaḥ puṃsi pravālaṃ puṃnapuṃsakam」（珊瑚の別名）。

I.10
Sanskrit (IAST) raṇadbhir āghaṭṭanayā nabhasvataḥ pṛthag vibhinnaśrutimaṇḍalaiḥ svaraiḥ / sphuṭībhavadgrāmaviśeṣamūrcchanām avekṣamāṇaṃ mahatīṃ muhurmuhuḥ //
和訳

風の衝撃により響き、それぞれ異なるシュルティ（微分音）の群を持つ音階が鳴り渡り、グラーマ（旋法）ごとのムールッチャナー（音階上行下行）が明瞭に現れるのを——自らのマハティー琴について——繰り返し観察していた。

注

【Vallabhadeva】

mahatīm——百弦琴（śatatantrīkā vīṇā）で、ナーラダ固有の琴の名。驚きゆえに繰り返し見つめていた。スヴァラ（音）は風の触発で自然に鳴り響き（anāhata）、人の手を借りずにグラーマの旋法が明瞭に現れるので驚嘆した。グラーマは三種——ṣaḍja, madhyama, gāndhāra。ムールッチャナーはスヴァラの上行下行の順序の別で、各グラーマに七ずつ計二十一。

【Mallinātha】

音楽理論の詳説。śruti——スヴァラを構成する微分音。ṣaḍja, madhyama, pañcama は各4シュルティ、ṛṣabha, dhaivata は各3、niṣāda, gāndhāra は各2、計22シュルティ。人の演奏なしに自然に旋法が現出するという超自然の技が示され、修辞法としてはatśayokti（誇張法）の一種。

I.11
Sanskrit (IAST) nivartya so 'nuvrajataḥ kṛtānatīn atīndriyajñānanidhir nabhaḥsadaḥ / samāsadat sāditadaityasampadaḥ padaṃ mahendrālayacāru cakriṇaḥ //
和訳

超感覚的な知識の宝庫たるその聖仙（ナーラダ）は、敬礼して随行する天界の住人たちを退け、悪魔の富を打ち滅ぼした円盤を持つ者（ヴィシュヌ＝クリシュナ）の、インドラの宮殿のごとく美しい住処に到着した。

注

【Vallabhadeva】

atīndriyajñānanidhiḥ——感覚を超えた知（時空・事物の本質に関する知識）の蔵。kṛtānatīn——礼拝した者たちを。許可を得た者は頭を下げるのが礼法。nabhaḥsadaḥ——空に住む者たち、すなわち神々を退かせて。sāditadaityasampadaḥ——悪魔たちの富を滅ぼした者、すなわちヴィシュヌの館に到った。転生の意義を暗示。

【Mallinātha】

natīn-atīn、padaḥ-padamの二組の同音反復はchekaanuprāsa（巧みな頭韻）。他の箇所のvṛttyanuprāsa（音の繰返し）とのsaṃsṛṣṭi（混合修辞）。

I.12
Sanskrit (IAST) patatpataṅgapratimas taponidhiḥ puro 'sya yāvan na bhuvi vyalīyata / gires taḍitvān iva tāvad uccakair javena pīṭhād udatiṣṭhad acyutaḥ //
和訳

降りてくる太陽にも似た苦行の宝庫（ナーラダ）が、ハリの前の地上にまだ降り立たぬうちに、早くもアチュタ（クリシュナ）は——山から稲妻を帯びた雲が立ち上がるかのように——高い座から勢いよく立ち上がった。

注

【Vallabhadeva】

patatpataṅgapratimaḥ——落ちてくる太陽のような、光輝ゆえに。yāvat … tāvatの呼応で、ナーラダが着地する前にクリシュナが既に立ち上がっていたことを示し、敬意の深さを表す。法典に「若者が年長者に対し立ち上がって迎え礼拝すれば、寿命・学識・名声・力を取り戻す」とある（マヌ法典）。

【Mallinātha】

pataṅgaは太陽。アマラコーシャに「pataṅgau pakṣisūryau ca」。太陽が「落ちる」ことは現実にはありえないので、ダンディン等の古師はこれをabhūtopamā（非実在の直喩）と見なした。近代の修辞学者たちは、知られていないものを比喩の対象にできないとしてutprekṣā（想像法）と分類する。

I.13
Sanskrit (IAST) atha prayatnonnamitānamatphaṇair dhṛte kathañcit phaṇināṃ gaṇair adhaḥ / nyadhāyiṣātām abhi devakīsutaṃ sutena dhātuś caraṇau bhuvas tale //
和訳

そこで、造物主（ブラフマー）の息子（ナーラダ）により、デーヴァキーの息子（クリシュナ）に向かって、大地の表面に両足が置かれた。その大地は、力を込めて頭をもたげたがまた垂れてしまう頭巾を持つ蛇の群れに、かろうじて支えられていた。

注

【Vallabhadeva】

ナーラダが足を踏み下ろすと、その威厳の重みで地下の蛇神たちの頭巾が下がりかけ、懸命に持ち上げてもまた撓む——かろうじて大地を支えた。これにより両者の偉大さ（mahāpuruṣalakṣaṇa）と威厳の超絶が表現される。nyadhāyiṣātāmはni-dhāの受動態 luṅ（アオリスト）。

【Mallinātha】

蛇の頭巾の上下動は実際には聖仙の足の重さとは無関係だが、聖仙の威厳のためにその関係を述べるのはatiśayokti（誇張法）の一種。abhi devakīsutamはavyayībhāva（不変化複合語）で「デーヴァキーの息子に向かって」の意。

I.14
Sanskrit (IAST) tam arghyam arghyādikayādipūruṣaḥ saparyayā sādhu sa paryapūjayat / gṛhān upaitum praṇayād abhīpsavo bhavanti nāpuṇyakṛtāṃ manīṣiṇaḥ //
和訳

原初の御方（ādi-pūruṣa＝クリシュナ）は、供物に値するその聖仙を、アルギャ（迎賓水）などの礼をもって丁重に敬った。まことに、徳を積まぬ者の家を、賢者たちは好意から訪れたいとは思わないものである。

注

【Vallabhadeva】

ヒラニヤカシプの時代から、富（śrī）が定まらぬものという世評が生じた。四方の守護神（インドラ・ヤマ・ヴァルナ・クベーラ）をさえ捨てて彼に仕えた——それはrāgahatāḥ（愛欲に奪われて）であり、強制ではなかったという含意。ちょうど最初の夫を捨てて他の男に走る女が悪評を得るように。pravādaは非難。ayaśaskaraは「不名誉を生む」（hetuにṭac接尾辞）。

diśām adhīśān——方位の主宰者＝四天王。rāgahatāḥ——欲に心を奪われて、強制ではなく自発的に。ārabhyaは「以来」の意の不変化辞（prabhṛti同義）。calāḥ——不安定、移り気。ucaiḥ——あまねく広まった。四天王の財をさえ奪ったことで、彼の驕慢の甚大さが暗示される。

Sanskrit (IAST) purāṇi durgāṇi niśātam āyudhaṃ balāni śūrāṇi ghanāś ca kañcukāḥ / svarūpaśobhaikaphalāni nākināṃ gaṇais tam āśaṅkya tadādi cakrire //
和訳

神々は彼を恐れ、それ以来、城塞を堅固にし、武器を研ぎ、軍勢を勇壮に整え、厚い甲冑を纏った——しかしそれらはすべて、ただ見た目の美しさだけが取り柄となった。

注

【Vallabhadeva】

神々（nākin）は集団で（gaṇaiḥ）彼を恐れて（āśaṅkya）、あれこれ軍備を整えた——城は難攻に、武器は鋭利に、軍は勇猛に、甲冑は厚く——しかしすべてsvarūpaśobhaikaphalāni（外見の美しさだけが唯一の成果であるもの）にすぎなかった。つまり実戦には役立たず、飾りと化した。durgāṇi——壕や城壁により近づき難いもの（duḥsena gamyante iti durgāṇi）。kañcukaは鎧・甲冑（アマラコーシャ：kañcuko vārabāṇo 'strī）。

【Mallinātha】

城塞（purāṇi durgāṇi）、鋭利な武器（niśātam āyudham）、勇壮な軍勢（balāni śūrāṇi）、厚い甲冑（ghanāḥ kañcukāḥ）——すべて外見だけの飾りと化した（svarūpaśobhaikaphalāni）。ヒラニヤカシプを前にしては実用の役に立たなかったという意。niśātaはśo（研ぐ）のkta形。tadādi＝それ以来。napuṃsakaśeṣaによる中性統一。
