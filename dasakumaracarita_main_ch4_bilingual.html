第四章
アルタパーラの物語
§1 Vārāṇasī-āgamaḥ

deva, so 'hamapyobhireva suhṛdbhirekakarmormimālinemibhūmivalayaṃ paribhramannupāsaraṃ kadācitkāśīpurīṃ vārāṇasīm /

upaspṛśya maṇibhaṅganirmalāmbhasi maṇikarṇikāyāmavimukteśvaraṃ bhagavantamandhakamathanamabhipraṇamya pradakṣiṇaṃ paribhramanpuruṣamekamāyāmavantamāyasapari ghapīvarābhyāṃ bhujābhyāmābadhvamānaparikaramavirataruditocchūnatāmradṛṣṭimadrākṣam /

atarkayaṃ ca—"karkaśo 'yaṃ puruṣaḥ kārpaṇyamiva varṣapi kṣīṇatāraṃ cakṣuḥ, ārambhaśca sāhasānuvādī, nūnamasau prāṇaniḥspṛhaḥ kimapi kṛcchraṃ priyajanavyasanamūlaṃ pratipatsyate / tatpṛccheyamenam / asti cenmamāpi ko 'pi sāhāyyadānāvakāśastamenamabhyupetyetyapṛccham—"bhadra, saṃnāho 'yaṃ sāhasamavagamayati / na cedgopyamicchāmi śrotuṃ śokahetum' iti /

sa māṃ sabahumānaṃ nirvarṇya "ko doṣaḥ, śrūyatām' iti / kvacitkaravīratale mayā saha niṣaṇṇaḥ kathāmakāraṣit—
§1 ヴァーラーナスィー到着

「陛下、私（アルタパーラ）もまた、同じ友人たちと共に、一つの波のように連なる大地の輪を巡りながら、あるとき聖都カーシー、すなわちヴァーラーナスィーに近づきました。」

「宝石の砕けたように澄み切った水をたたえるマニカルニカー・ガートで沐浴し、アヴィムクテーシュヴァラなるシヴァ神――アンダカの殺害者たる大神――に深く礼拝し、右繞して巡拝しておりますと、ある男を見かけました。背は高く、鉄の棒のように逞しい両腕で帯を締め直し、絶え間なく泣き続けて腫れ上がった赤い目をしておりました。」

「私は推察しました。『この男は荒々しい性格だ。星が衰えるように涙で瞳が薄れた目をしている。その身構えは無謀な行為を暗示している。きっとこの男は命を惜しまず、愛する者の災難に根ざした何か恐ろしいことを企てるのだろう。彼に尋ねてみよう。もし私にも何か助力の機会があるなら。』こう考えて近づき、尋ねました。『友よ、その武装は無謀を企てていることを示している。秘密でなければ、悲しみの原因を聞かせてほしい。』」

「彼は私を敬意をもって見つめ、『差し支えありません、お聞きください』と言い、あるカラヴィーラの木の下に私と共に座って物語を語り始めました。」

注：マニカルニカー（maṇikarṇikā）はヴァーラーナスィー（ベナレス）の最も神聖な火葬ガートの一つ。アヴィムクテーシュヴァラ（avimukteśvara）は「決して去らぬ主」の意で、ヴァーラーナスィーのシヴァ神の名。andhakamathanam は魔神アンダカを殺した者の意で、シヴァの異名（Kale注）。
§2 Pūrṇabhadrasya kathā

"mahābhāga, so 'hamasmi pūrveṣu kāmacaraḥ pūrṇabhadro nāma gṛhapatiputraḥ / prayatnasaṃvardhito 'pi pitrā daivacchandānuvartī cauryavṛttirāsam / athāsyāṃ kāśīpuryāmaryavaryasya kasyacidgṛhe corayitvā rūpābhigrāhito baddhaḥ /

vadhye ca mayi mattahastī mṛtyuvijayo nāma hiṃsāvihārī rājagopuroparitalādhirūḍhasya paśyataḥ kāmapālanāmna uttamāmātyasya śāsanājjanakaṇṭharavadviguṇitaghaṇṭāravo maṇḍalitahastakāṇḍaṃ samabhyadhāvat /

abhipatya ca mayā nibhayana nirbhartsitaḥ pariṇamandārukhaṇḍasuṣirānupraviṣṭobhayabhujadaṇḍaghaṭitapratimāno bhītavannyavartiṣṭa / bhūyaśca netrā jātasaṃrambheṇa nikāmadāruṇairvāgaṅkuśapādapātairabhimukhīkṛtaḥ / mayāpi dviguṇābaddhamanyunā nirbhartsyābhihato nivṛtyāpādravat /

atha mayopetya sarabhasamākruṣṭo ruṣṭaśca yantā "hanta, mṛto 'si kuñjarāpasada' iti niśitena vāraṇena vāraṇaṃ muhurmuhurabhighnanniryāṇabhāge kathamapi madabhimukhamakarot /

athāvocyam—"apasaratu dvikakīṭa eṣaḥ / anyaḥ kaścinmātaṅgaphatirānīyatām / yenāhaṃ muhūrtaṃ vihṛtya gacchāmi gantavyāṃ gatim' iti / dṛṣṭaiva sa māṃ ruṣṭamudgarjantamutkrāntayantṛniṣṭhurājñaḥ palāyiṣṭa /
§2 プールナバドラの物語 ― 盗賊、象による処刑

「『大徳よ、私はかつて自由気ままに暮らしていたプールナバドラという名の商人の息子です。父に丹精込めて育てられましたが、運命に従い盗みを生業としておりました。この聖都カーシーで、ある高貴な方の家に忍び込み、現行犯で捕らえられ、縛り上げられました。』」

「『私が処刑されることになると、ムリティユヴィジャヤ（「死に勝つ者」）という名の、殺戮を好む狂象が、王宮の楼閣の上から見守るカーマパーラという名の宰相の命令により、群衆の喉を震わせるかのように鈴の音を倍加させ、鼻を振り回しながら突進してきました。』」

「『しかし突撃してきた象を、私は恐れず一喝し、象は恐怖のあまり、近くにあった朽木の洞に両腕を突っ込んで棒のように固まり、怯えて後退しました。御者が再び激昂し、残忍な鞭と言葉の鉤と足蹴りで象を向き直させましたが、私が倍加した怒りで一喝し打ち据えると、象は逃げ出しました。』」

「『私が駆け寄って荒々しく引きずり、怒った御者が「この象の恥さらしめ、死ぬがよい」と鋭い鞭で何度も打って、やっとのことで私に向き直らせました。』」

「『すると私は言いました。「この二足の虫けらをどけろ。もっと立派な象を連れて来い。一時ほど戯れてから、行くべき道に行こうぞ。」すると象は、怒って雄叫びを上げる私を見、御者の残忍な命令をも超えて逃げ去りました。』」

注：mṛtyuvijaya（ムリティユヴィジャヤ）は「死に勝つ者」の意。処刑用の狂象で、死刑囚を踏み殺す役割を担う。プールナバドラが象を恐れず、逆に威嚇して怯えさせた場面は、彼の超人的な勇猛さを示す（Kale注: "Mrityuvijaya is Death itself incarnate in the form of an elephant"）。
§3 Kāmapāla-praśaṃsā

mantriṇā punarahamāhūyābhyadhāyiṣi—"bhadra, mṛtyurevaiṣa mṛtyuvijayo nāma hiṃsāvihārī / so 'yamapi tāvattvayaivaṃbhūtaḥ kṛtaḥ / tadviram karmaṇo 'smānmalīmasātkimalamasi pratipadyāsmānāryavṛttyā vartitum' iti / "yathājñāpito 'smi' iti vijñāpito 'yaṃ mayā mitravanmayyavartiṣṭa /

pṛṣṭaśca mayaikadā rahasi jātaviśrambheṇābhāṣata svacaritam—
§3 宰相カーマパーラの賞賛と登用

「『すると宰相（カーマパーラ）が私を呼び寄せて言いました。「友よ、このムリティユヴィジャヤは死そのもの、殺戮を楽しむ象だ。それをお前はこのようにしてしまった。だから汚れた行いはやめよ。もう十分だ。我々に仕えて高貴な生き方をせよ。」私は「仰せのままに」と申し上げ、彼は私に友のように接してくれました。』」

「『そしてあるとき、密かに信頼関係が生まれた折、尋ねると彼は自らの身の上話を語り始めました。』」

注：宰相カーマパーラがプールナバドラを登用する場面。karmaṇo 'smān malīmasāt は「我々を汚す（malīmasa）行為から」の意。宰相は盗賊の勇猛さを正しい方向に導こうとする（Kale注, p.128）。
§4 Kāmapālasya svacaritam (1)

"āsītkusumapure rājño ripuñjayasya mantrī dharmapālo nāma viśrutadhīḥ śrutaṛṣiḥ / amuṣya putraḥ sumitro nāma pitraiva samaḥ prajñāguṇeṣu / tasyāsmi dvaimāturaḥ kanīyanbhrātāham /

veśeṣu vilasantaṃ māmasau vinayaruciravārayat / avāryadurnayaścāhamapasṛtya diṅmukheṣu bhramanyadṛcchayāsyāṃ vāraṇasyāṃ pramadavane madanadamanārādhanāya nirgatya sahasakhībhiḥ kandukenānukrīḍamānāṃ kāśībhartuścaṇḍasiṃhasya kanyāṃ kāntimatīṃ nāma cakame / kathamapi samagacche ca /
§4 カーマパーラの身の上話（一）― クスマプラ出身、放蕩と恋

「『クスマプラ（パータリプトラ）にリプンジャヤ王の宰相ダルマパーラという名の、智慧高く聖仙のごとき者がおりました。その息子スミトラは、父と同じく知恵の徳に優れておりました。私はその異母弟にあたります。』」

「『兄は遊郭に入り浸る私を礼儀正しく諌めましたが、私は止まらず、素行不良のまま家を飛び出して諸方を彷徨い、偶然このヴァーラーナスィーに来ました。そこで遊園（pramadavana）でカーマの神の祠を礼拝するために出てきた、カーシー王チャンダスィンハの王女カーンティマティーを、侍女たちとまり遊びに興じている姿に見染め、恋に落ちました。そしてどうにかして彼女と逢瀬を重ねるようになりました。』」

注：Kusumapura（クスマプラ）はパータリプトラ（現パトナ）の別名。カーマパーラの父ダルマパーラはリプンジャヤ王の宰相で、兄スミトラも同様に賢明。dvaimāturaḥ は「異母の」の意（Kale注）。pramadavana は王宮付属の遊園。
§5 Kāmapālasya svacaritam (2)

atha channaṃ ca viharatā kumārīpure sā mayāsīdāpannasattvā / kañcitsutaṃ ca prasūtavatī / mṛtajāta iti so 'paviddho rahasyanirbhedabhayātparijanena krīḍāśaile /

śabaryā ca smaśānābhayāśaṃ nītaḥ / tayaiva nivartamānayā niśīthe rājyavidhyamārakṣikapuruṣairabhigṛhaṃya tarjitayā daṇḍapārupyabhītayā nirbhinnaprāyaṃ rahasyam /

rājajñayā niśīthe 'hamākrījanagiridarīgṛhe viśrabdhaprasuptastayopadaraśito yathopapannarajjubaddhaḥ śmaśānamupanīya mātaṅgodyatena kṛpāṇena prājihīrṣye niyatibalāllūnabandhastamasimācchidyāntyajaṃ tamanyāṃśca kāṃścitprahṛtyāpāsaram /
§5 カーマパーラの身の上話（二）― 密通発覚、処刑未遂と逃亡

「『私は密かに王女の居室に通い、彼女は身ごもり、やがて男子を産みました。秘密が漏れることを恐れた侍従たちは、その子を死産と偽って遊戯の丘に捨てました。』」

「『シャバラ族の女がその子を火葬場の近くの小屋に連れていきました。しかし夜中に帰る途中、巡回中の王の警吏に捕らえられ、脅された彼女は刑罰を恐れて秘密をほぼ打ち明けてしまいました。』」

「『王の命令で、夜中に遊戯の山の洞窟で安心して眠っていた私は、彼女の密告で見つかり、有り合わせの縄で縛られ、火葬場に連行されました。不可触民（マータンガ、チャンダーラ）が剣を振り上げたその時、運命の力で縄が切れ、闇を切り裂いて不可触民やその他の者たちを打ち倒して逃れました。』」

注：kumārīpura は王女の居所。krīḍāśaila（遊戯の丘）は王宮付属の人工の丘。mātaṅga は不可触民（チャンダーラ）を指し、処刑人の役割を担った。niyatibalāt（運命の力により）は、カーマパーラの脱出が天命であったことを示す（Kale注, p.128）。
§6 Tārāvalī-darśanam

aśaraṇśca bhramannaṭavyāmekadāśrumukhyā kayāpi divyākārayā saparicārayā kanyayopāsthāyipi / sā māmañjalikisalayottaṃsitena mukhavilolakuntalena mūrdhnā praṇamya mayā saha vanavaṭadrumasya kasyāpi mahataḥ pracchāyaśītale tale niṣaṇṇā, "kāsi vāsu, kuto 'syāgatā, kasya hetorasya me prasīdasi' iti sābhilāṣamābhāṣitā mayā vāṅmayaṃ madhuvarṣamavarṣat—
§6 ターラーヴァリーとの出会い

「『身寄りもなく森を彷徨っておりますと、あるとき涙を浮かべた顔の、天上の姿をした侍女を伴う乙女が近づいてきました。彼女は蕾のように合わせた掌を頭上に掲げ、顔に垂れる巻き毛を揺らしながら頭を下げて私に礼拝し、私と共に森の大きな菩提樹の涼しい木陰に座りました。私が「お前は誰だ、どこから来た、何のために私を慕うのか」と情を込めて問うと、彼女は蜜の雨のような言葉を降らせました。』」
§7 Tārāvalī-kathā

"ārya, nāthasya yakṣāṇāṃ maṇibhadrasyāsmi duhitā tārāvalī nāma / sāhaṃ kadācidagastyapatnīṃ lopāmudrāṃ namaskṛtyāpāvartamānā malayagireḥ paretāvāse vārāṇasyāḥ kamapi dārakaṃ rudantamadrākṣam / ādāya cainaṃ tīvrasnehānmamapitroḥ saṃnidhimanaiṣam /

anaipīcca me pitā devasyālakeśvarasyāsthānīm / athāhamāhūyājñaptā harasakhena, "bāle bāle 'sminkīdṛśaste bhāvaḥ' iti / "aurasa ivāsminvatse vatsalatā' iti mayā vijñāpitaḥ "satyamāha varākī' iti tanmūlāmatimahatīṃ kathāmakarot /
§7 ターラーヴァリーの物語 ― ヤクシャの娘

「『「旦那様、私はヤクシャたちの主マニバドラの娘ターラーヴァリーと申します。かつてマラヤ山でアガスティヤ仙の妻ローパームドラーに礼拝した帰り、ヴァーラーナスィーの火葬場のあたりで泣いている赤子を見つけました。深い愛情から抱き上げ、両親の元に連れて行きました。」』」

「『「父は私をアラケーシュヴァラ（クベーラ神）の宮殿に連れて行きました。するとシヴァの友（クベーラ）が私を呼んで尋ねました。「おい娘よ、この子にどんな思い入れがあるのだ。」私が「実の子のようにこの子に慈しみを感じます」と申し上げると、「哀れな娘の言うことは真実だ」と仰り、その子にまつわる非常に長い物語を語り始めました。」』」

注：Maṇibhadra（マニバドラ）はヤクシャの首長の一人でクベーラの部下。Lopāmudrā（ローパームドラー）はアガスティヤ仙の妻。Alakeśvara（アラケーシュヴァラ）はクベーラ神の別名で、アラカー城の主。harasakha（シヴァの友）もクベーラの別名。
§8 Punarjanmakathā

tatraitāvanmayāvagatam "tvaṃ kila śaunakaḥ śūdrakaḥ kāmapālaścābhinnaḥ / bandhumatī vinayavatī kāntimatī cābhinnā / vedimatyāryadāsī somadevī vaikaiva / haṃsāvalī śūrasenā sulocanā cānanyā / nandinī raṅgapatākendrasenā cāpṛthagbhūtā /

yā kila śaunakāvasthāyāmagnisākṣikamātmasātkṛtā gopakanyā saiva kilāryadāsī punaścādya tārāvalītyabhūvam /

bālaśca kilaśūdrakāvasthe tvayyāryadāsyavasthāyāṃ mayyudabhūt / avardhyata ca vinayavatyā snehavāsanayā / sa tu tasyāṃ kāntimatyavasthāyāmadyodabhūt /
§8 輪廻転生の物語 ― クベーラの啓示

「『「その物語から私が理解したのは次のことです。あなたはシャウナカ、シュードラカ、そしてカーマパーラと同一人物です。バンドゥマティー、ヴィナヤヴァティー、カーンティマティーも同一人物です。ヴェーディマティー、アーリヤダースィー、ソーマデーヴィーも一人です。ハンサーヴァリー、シューラセーナー、スロチャナーも別人ではありません。ナンディニー、ランガパターカー、インドラセーナーも同じです。」』」

「『「シャウナカの世において火を証人として娶った牧女こそアーリヤダースィーであり、さらに今の私――ターラーヴァリーとなりました。」』」

「『「シュードラカの世のあなたと、アーリヤダースィーの世の私との間に男の子が生まれ、ヴィナヤヴァティー（＝カーンティマティー）の愛情の宿縁で育てられました。その子が、カーンティマティーの世では今日お生まれになったのです。」』」

注：ここにダンディン文学の核心的主題である輪廻転生の入れ子構造が現れる。シャウナカ→シュードラカ→カーマパーラ、バンドゥマティー→ヴィナヤヴァティー→カーンティマティー等、登場人物が複数の生にわたって同一であることをクベーラ神が明かす。gopakanyā（牧女）がターラーヴァリーの前世であるという設定は、ヤクシャ族の娘が人間と深い宿縁で結ばれていることを示す。
§9 Tārāvalī-samarpayati

evamanekamṛtyumukhaparibhraṣṭaṃ daivānmayopalabdhaṃ tamekapiṅgādeśādvane tapasyato rājahaṃsasya devyai vasumatyai tatsutasya bhāvicakravartino rājavāhanasya paricaryārthaṃ samarpya gurubhirabhyanujñātā kṛtāntayogātkṛtāntamukhabhraṣṭasya te pādapadmaśuśrūṣārthamāgatāsmi' iti /

śrutvā tāmanekajanmaramaṇīmasakṛdāśliṣya harṣāśrumukho muhurmuhuḥ sāntvayitvā tatprabhāvadarśite mahati mandire 'harniśaṃ bhūmidurlabhānbhogānanvabhūvam /
§9 ターラーヴァリーの使命 ― 赤子の托身

「『「こうして幾度も死の口から逃れたその子を、天命により私が見出し、エーカピンガーの指示に従い、森で苦行するラージャハンサ王の妃ヴァスマティーに、その子にして未来の転輪聖王ラージャヴァーハナの侍者として献上しました。そして師たちの許しを得て、死の宿縁により死の口から逃れたあなた様の蓮華の御足に仕えるために参りました。」と（ターラーヴァリーは語りました）。』」

「『幾世にもわたる愛しい女の言葉を聞き、私は何度も彼女を抱きしめ、歓喜の涙を浮かべながら繰り返し慰めました。そして彼女の神通力で現れた大きな宮殿で、昼夜を問わず地上では得がたい享楽を味わいました。』」

注：ekapiṅga はクベーラ神の異名（片目が黄色い者）。bhāvicakravartin（未来の転輪聖王）としてのラージャヴァーハナの運命が予言されている。kṛtāntayogāt kṛtāntamukhabhraṣṭa は「死の宿縁により死の口から逃れた」という巧みな語呂合わせ（Kale注）。
§10 Caṇḍasiṃha-pratikāraḥ

dvitrāṇi danānyatikramya mattakāśinīṃ tāmavādiṣam—"priye, pratyapakṛtya matprāṇadgohiṇaścaṇḍasiṃhasya vairaniryātanasukhamanububhūṣāmi' iti tayā sasmitamabhihitam—"ehi kānta, kāntimatīdarśanāya nayāmi tvām' iti /

sthiter'dharātre rājño vāsagṛhanīye / tatastacchirobhāgavartinīmādāyāsiyaṣṭiṃ prabodhyainaṃ prasphurantamabravam—"ahamasmi bhavajjāmātā / bhavadanumatyā vinā tava kanyābhimarśī / tamaparādhamanuvṛttyā pramārṣṭumāgataḥ' iti /

so 'tibhītomāmabhipraṇamyāha—"ahameva mūḍho 'parāddhaḥ yastava duhitṛsaṃsargānugrāhiṇo grahagrasta ivotkrāntasīmā bhavadadhīnam' ityavādīt /
§10 チャンダスィンハへの対決 ― 夜の王宮侵入

「『二、三日が経ち、陶然としたターラーヴァリーに私は言いました。「愛しい者よ、命を狙ったチャンダスィンハに報復し、復讐の快楽を味わいたい。」彼女は微笑んで言いました。「さあ、愛しい方、カーンティマティーに会わせてあげましょう。」』」

「『深夜になって王の寝室に至ると、その枕元にあった鉄の杖を取り、王を起こし、震える彼に言いました。「私はあなたの婿です。あなたの許可なく王女を犯した者です。その罪を繰り返し行うことで償いに来ました。」』」

「『王は甚だ恐れ、私に平伏して言いました。「愚かなのは私の方でした。娘との縁を結んでくれた恩人であるあなたに対し、惑星に取り憑かれたように分を超えた振る舞いをしてしまいました。あなたに従います。」』」

注：anuvṛttyā pramārṣṭum（繰り返し行うことで罪を拭う）は皮肉を込めた表現。Kale注は anuvṛtti を「服従、追従」とも解し、「奉仕によって償う」とする読みも紹介している。ここでのカーマパーラの大胆な行動は、彼の策士としての性格を示す。
§11 Vivāhaḥ

athāparedyuḥ prakṛtiṇḍalaṃ saṃnipātya vidhivadātmajāyāḥ pāṇimagrāhayat / aśrāvayacca tanayavārtāṃ tārāvalī kāntimatyai, somadevīsulocanendrasenābhyaśca pūrvajātivṛttāntam /

itthamahaṃ mantripadāpadeśaṃ yauvarājyamanubhavanviharāmi vilāsinībhiḥ' iti /
§11 正式な婚姻 ― 宰相から事実上の皇太子へ

「『翌日、王は臣下の集会を召集し、正式な儀礼に則って自らの娘（カーンティマティー）の手を私に与えました。そしてターラーヴァリーはカーンティマティーに息子の消息を、またソーマデーヴィー、スロチャナー、インドラセーナーにも前世の経緯を語り聞かせました。』」

「『こうして私は宰相の地位を名目として、実質的な副王（ユヴァラージャ）の権威を享受し、妃たちと共に暮らしておりました。』と（カーマパーラは語り終えました）。」

注：mantripadāpadeśam yauvarājyam は「宰相の地位を口実として（実質は）副王の権力」の意。apadeśa は「名目、口実」（Kale注: "under the guise of the ministerial post"）。カーマパーラは義父チャンダスィンハを制圧した後、形式上は宰相だが実権を握っている。
§12 Durmantriṇāṃ piśunatā

sa evaṃ mādṛśe 'pi jantau paricaryānubandhī bandhurekaḥ sarvabhūtānāmalasakena svargate śvaśure, jyāyasi ca śyāle caṇḍaghoṣanāmni strīṣvatiprasaṅgātprāgeva kṣayakṣīṇāyuṣi, pañcavarṣadeśīyaṃ sihaghoṣanāmānaṃ paiśunyavādināṃ durmantriṇaḥ katicidāsannantaraṅgabhūtāḥ /

taiḥ kilāsāvitthamagrāhyata—"prasaṅyaiva svasā tavāmunā bhujaṅgena saṃgṛhītā / punaḥ prasupte rājani prāhartumadyutāsirāsīt / tenāsmai talkṣaṇapravṛddhena bhītyānunīya dattā kanyā / taṃ ca devajyeṣṭhaṃ caṇḍaghoṣaṃ viṣeṇa hatvā bālo 'yamasamartha iti tvamadyāpi prakṛtiviśrambhaṇāyopekṣitaḥ / kṣiṇoti ca purā sa kṛtaghno bhavantam / tamevāntakapuramabhigamayituṃ yatasva' iti /
§12 悪臣たちの讒言 ― スィンハゴーシャの毒心

「〔プールナバドラの語り再開〕『このように彼（カーマパーラ）は私のような卑しい者にも恩寵を示す、万物に対して唯一無二の温かき人でした。しかし義父が無為のうちに世を去り、義兄チャンダゴーシャも女色に溺れてすでに肺病で命を縮めて亡くなると、五歳ばかりのスィンハゴーシャという王子が即位しました。讒言を弄する悪臣が数人、王の側近となりました。』」

「『彼らは幼王をこう唆しました。「あなたの姉をこの蛇のような男（カーマパーラ）が強引に我がものとした。さらに王（チャンダスィンハ）が眠っている間に殺そうとして鉄杖を持って立っていた。恐怖で屈服させ、娘を与えさせたのだ。兄君チャンダゴーシャも毒殺した。この子（スィンハゴーシャ）は幼く無力だから今のところ臣下の信頼を繋ぎ止めるために放置しているだけだ。やがてこの恩知らずがあなたを滅ぼすだろう。だからこの男を死の都（ヤマの国）に送るべく手を打て。」と。』」

注：paiśunyavādin（讒言者）は paiśunya（中傷）に由来。antakapuram は閻魔（Yama）の都、すなわち死の意。caṇḍaghoṣa は strīṣv atiprasaṅgāt（女色への過度の耽溺から）kṣayakṣīṇāyuṣi（肺病で寿命が尽きた）。Kale注では kṣaya は rājayakṣman（王の病＝肺結核）を指すとする。
§13 Kāntimatyāḥ duḥkham

sa tathā dūṣito 'pi yakṣiṇībhayānnāmuṣminpāpamācaritumaśakat / eṣu kila divaseṣvayathāpūrvamākṛtau kāntimatyāḥ samupalakṣya rājamahiṣī sulakṣaṇā nāma sapraṇayamapṛcchat—"devi, nāhamāyathātathyena vipralambhanīyā / kathaya tathyaṃ kenedamayathāpūrvamānanāravinde tavaiṣu vāsareṣu' iti /

sā tvavadīt—"bhadre, smarasi kimadyāpyāyathātathyena kiñcinmayoktapūrvam / sakhī me tārāvalī sapatnī ca kimapi kaluṣitāśayā rahasi bhartrā madgotrāpadiṣṭā praṇayamapyupekṣya praṇamyamānāpyasmabhirupoḍhamatsarā prāvasat / avasīdati ca naḥ patiḥ / ato me daurmanatyam' iti /
§13 カーンティマティーの苦悩 ― スラクシャナー王妃の問い

「『しかし王はヤクシャの女（ターラーヴァリー）を恐れ、カーマパーラに手を出すことができませんでした。そのころ、カーンティマティーの表情がいつもと違っているのを察した先代王妃スラクシャナーが、親しみを込めて尋ねました。「王妃殿、私は嘘で欺かれるべき者ではありません。何がこのところあなたの蓮華のような御顔をいつもと変えているのか、本当のことを話してください。」』」

「『カーンティマティーは答えました。「親しき方よ、私がかつて嘘を申し上げたことがありましょうか。友にして共妻（sapatnī）であるターラーヴァリーが、何か心を乱されて、密かに夫から私の一族について告げ口され、親愛の情も顧みず、我々が礼を尽くしても嫉妬を募らせて去ってしまいました。そして夫も落魄しております。それゆえの鬱でございます。」と。』」

注：sulakṣaṇā はチャンダスィンハの王妃で、カーンティマティーの母にあたる。yakṣiṇībhayāt はターラーヴァリーのヤクシャとしての超自然的な力への恐怖を指す。kaluṣitāśayā（心を乱された）のはターラーヴァリーが前世の因縁を巡る嫉妬か宿怨を抱いていることを示唆する。
§14 Kāmapāla-bandhanam

tatprāyeṇaikānte sulakṣaṇayā kāntāya kathitam / "athāsau nirbhayo 'dya priyatamāvirahapāṇḍubhiravayairghairyastambhitāśruparyākulena cakṣuṣoṣmaśvāsaśoṣitābhirivānatipeśalābhirvāgbhirviyogaṃ darśayantam, kathamapi rājakule kāryāṇi kārayantam, pūrvasaṃketitaiḥ puruṣairabhigrāhyābandhayat /

tasya kila sthāne sthāne doṣānuddhoṣya tathoddharaṇīye cakṣuṣī yathā tanmūlamevāsya maraṇaṃ bhavet' iti /
§14 カーマパーラの逮捕 ― スィンハゴーシャの暴挙

「『スラクシャナーはほぼそのまま、密かに王（スィンハゴーシャ）に伝えました。すると王はもはや恐れることなく、最愛の妻との別離に青ざめた手足で、堪えた涙に曇った目で、熱い溜息に枯れたような穏やかならぬ声で別離の苦しみを示しながら、どうにか宮中の職務を果たしていたカーマパーラを、予め手配していた兵たちに捕らえさせ、拘束しました。』」

「『そして所々で彼の罪状を布告し、両目を抉り出して、それがもとで死に至るようにせよ、と命じました。』」

注：cakṣuṣī uddharaṇīye（両目を抉り出すべし）は、悪臣たちの讒言によってスィンハゴーシャが下した残酷な刑罰。しかし「それがもとで死に至るように」（tanmūlam evāsya maraṇaṃ bhavet）という条件は、処刑ではなく目を奪った上での緩慢な死を意図している。
§15 Arthapālasya svaprakāśanam

ato 'traikānte yatheṣṭamaśru muktvā tasya sādhoḥ puraḥ prāṇānmoktukāmo badhnāmi parikaram' iti /

mayāpi tatpitṛvyasanamākarṇya paryaśruṇā so 'bhihitaḥ—"saumya, kiṃ tava gopāyitvā / yastasya suto yakṣakanyayā devasya rājavāhanasya pādaśuśrūṣārthaṃ devyā vasumatyā hastanyāsaḥ kṛtaḥ so 'hamasmi / śakṣyāmi sahasramapi subhaṭānāmudāyudhānāṃ hatvā pitaraṃ mocayitum /

api tu saṃkule yadi kaścitpātayettadaṅge śastrikāṃ sarva eva me yatno bhasmāni hutamiva bhavet' iti /
§15 アルタパーラの正体 ― 父を救う決意

「〔プールナバドラは涙ながらに語り終えました〕『それゆえ、ひとり人目のないところで思う存分涙を流した後、あの善き人（カーマパーラ）の前で命を捨てるつもりで帯を締めているのです。』」

「私（アルタパーラ）もまた父の災難を聞いて涙し、彼に言いました。『友よ、もう隠す必要はない。ヤクシャの娘（ターラーヴァリー）の子で、ラージャヴァーハナ殿下に仕えるためヴァスマティー妃に託された息子とは、この私だ。千人の武装した勇士を打ち倒してでも父を救い出す力がある。』」

「『ただし、混戦の中で誰かが父の体に刃を立てれば、私の全ての努力は灰に帰した供物のように無駄になる。』」

注：ここでアルタパーラがカーマパーラの息子であることを初めてプールナバドラに明かす。yakṣakanyayā はターラーヴァリーを指す。hastanyāsaḥ kṛtaḥ は「手に委ねられた」、すなわちヴァスマティー妃に託されたことを意味する。saṃkule（混戦の中で）武器を父の身に向けられることへの懸念が、毒蛇計略を案出する動機となる。
§16 Sarpayuktiḥ

anavasitavacana eva mayi mahānāśīviṣaḥ prākārarandhreṇodairayacchiraḥ / tamahaṃ mantrauṣadhabalenābhigṛhya pūrṇabhadramabravam—"bhadra, siddhaṃ naḥ samīhitam / anena tātamalakṣyamāṇaḥ saṃkule yadṛcchayā patitena nāma daṃśayitvā tathā viṣaṃ stambhavevaṃ yathā mṛta ityudāsyeta /

tvayā tu muktasādhvasena mātā me bodhayitavyā—" yā yakṣyā vane devyā vasumatyā hastārpito yuṣmatsūnuḥ so 'nuprāptaḥ pituravasthāṃ madupalabhya buddhibalāditthāmācariṣyati /

tvayā tu muktatrāsayā rājñe preṣaṇīyam—"eṣa khalu kṣātradharmo yadbandhurabandhurvā duṣṭaḥ sa nirapekṣaṃ nirgrāhya iti / strīdharmaścaiṣa yadaduṣṭasya duṣṭasya vā bharturgatirgantavyeti / tadahamamunaiva saha citāgnimārokṣyāmi / yuvatijanānukūlaḥ paścimavidhiranujñātavyaḥ' iti /

sa eva nivedito niyatamanujñāsyati / tataḥ svamevāgāramānīya kāṇḍapaṭīparikṣipte viviktodderśe darbhasastaraṇamadhiśāyya svayaṃ kṛtānumaraṇamaṇḍanayā tvayā ca tatra saṃnidheyam / ahaṃ ca bāhyakakṣāgatastvayā praveśayiṣye / tataḥ pitaramujjīvya tadabhirucitenābhyupāyena ceṣṭiṣyāmahe' iti /

sa "tathā' iti hṛṣṭatarastūrṇamagamat /
§16 毒蛇の計略 ― 偽死の策

「私がまだ話し終えぬうちに、大きな毒蛇が城壁の穴から鎌首をもたげました。私はマントラと薬の力でその蛇を捕獲し、プールナバドラに言いました。『友よ、我々の望みは成就した。この蛇で、群衆に紛れて偶然落ちたように見せかけて父を噛ませ、毒を止めて死んだように見せかけるのだ。』」

「『お前は恐れずに私の母に知らせよ。「ヤクシャの女によって森でヴァスマティー妃に託されたあなた方の息子が到着しました。父上の窮状を知り、知恵の力でこのように行動します」と。』」

「『そして母は恐れを捨てて王に使いを送り、こう申し入れよ。「クシャトリヤの法とは、親族であろうとなかろうと、罪ある者は容赦なく罰すべしということです。そして婦人の法とは、罪ある夫にせよ罪なき夫にせよ、その運命に従うべしということです。ゆえに私はこの夫と共に火葬の薪に上りましょう。婦人に相応しき最後の儀式をお許しください」と。』」

「『このように申し入れれば王は必ず許可するだろう。それから父を自宅に運び、帳で仕切った人目のない場所にダルバ草の褥を敷いて横たえ、母には殉死の装いをさせてそこに付き添わせよ。私は外の区画に来るから、お前が中に導き入れよ。そうして父を蘇生させ、状況に応じた策を講じよう。』」

「彼は『承知した』と喜び勇んで去って行きました。」

注：mantrauṣadhabala（マントラと薬草の力）は解毒術を指す。アルタパーラは蛇毒を自在に制御する能力を持つ。kṣātradharma（クシャトリヤの法）と strīdharma（婦人の法）を引き合いに出す母の台詞は、夫への忠誠を装いつつ遺体の引き取りを合法的に実現する策略である。anumaraṇa は夫の遺体と共に火に入るサティー（殉死）の意。
§17 Vadhyasthāna-yuktiprayogaḥ

ahaṃ tu ghoṣaṇasthāne ciñcāvṛkṣaṃ ghanataravipulaśākhamāruhya gūḍhatanuratiṣṭham / ārūḍhaśca loko yathāyathamuccaisthānāni / uccāvacapralāpāḥ prastutāḥ /

tāvanme pitaraṃ taskaramiva paścādbaddhabhujamuddhuradhvani mahājanānuyātamānīya madabhyāśa eva sthāpayitvā mātaṅgastriraghoṣayat—"eṣa mantrī kāmapālo rājyalobhadbhartāraṃ caṇḍasiṃham, yuvarājaṃ caṇḍaghoṣaṃ ca viṣānnenopāṃśu hatvā punardevo 'pi siṃhaghoṣaḥ pūrṇayauvana ityamuṣminpāpamācariṣyanviśvāsādrahasyabhūmau punaramātyaṃ śivanāgamāhūya sthūṇamaṅgāravarṣaṃ ca rājavadhāyopajapya taiḥ svāmibhaktyā vivṛtaguhyo rājyakāmukasyāsya brāhmaṇasyāndhatamasapraveśo nyāyya iti prāṅvivākavākyādakṣyuddharaṇāya nīyate / punaranyo 'pi yadi syādanyāyavṛttistamaṣyevameva yathārheṇa daṇḍena yojayiṣyati devaḥ' iti /
§17 処刑場での計略 ― 蛇を投げる

「私は布告の場所にあるタマリンドの木の、鬱蒼とした大枝に登って身を隠しました。群衆もそれぞれ高い場所に陣取り、さまざまな噂話を交わしていました。」

「やがて私の父が盗賊のように背後で両腕を縛られ、騒がしい道を大群衆に伴われて連行され、ちょうど私のすぐ近くに据えられました。不可触民（チャンダーラ）が三度布告しました。『この宰相カーマパーラは、王位への貪欲から、主君チャンダスィンハと皇太子チャンダゴーシャを毒入りの食事で密かに殺害し、さらにスィンハゴーシャ王が成人した暁にも同じ罪を犯そうとし、信頼に乗じて密議の場で大臣シヴァナーガとストゥーナ、アンガーラヴァルシャを呼び寄せ、王の暗殺を教唆した。しかし彼らが主君への忠義から秘密を暴露したため、王位を欲するこのバラモンには暗黒への没入こそ相応しいとの裁判官の判決により、目を抉り出されるために連行される。今後も不正を行う者があれば、同様に相応の刑罰を科すであろう。』」
§18 Sarpakṣepaḥ — mṛtakalpaḥ pitā

śrutvaitadbhaddhakalakale mahājane pituraṅge pradīptaśirasamāśīviṣaṃ vyakṣipam / ahaṃ ca bhīto nāmāvaplutya tatraiva janādanulīnaḥ kruddhvayāladaṣṭasya tātasya vihitajīvarakṣo viṣakṣaṇādastambhayam / apataccaiṣa bhūmau mṛtakalpaḥ /

prālapaṃ ca "satyamidaṃ rājāvamāninaṃ daivo daṇḍa eva spṛśatīti / yadayamakṣibhyāṃ vināvanipena cikīrṣitaḥ, prāṇaireva viyojito vidhinā' iti / maduktaṃ ca kecidanvamanyanta, apare punarnininduḥ /

darvīkarastu tamapi caṇḍālaṃ daṣṭvā rūḍhatrāsadrutalokadattamārgaḥ prādravat /
§18 蛇の投下 ― 偽りの死

「大群衆がざわめく中、それを聞いて、私は父の体に燃えるように鎌首をもたげた毒蛇を投げ落としました。そして恐れたふりをして飛び降り、群衆に紛れて身を隠しました。怒った蛇に噛まれた父の命を守るべく、即座に毒を止めました。父は地面に崩れ落ち、死んだも同然の姿になりました。」

「私は叫びました。『まことにこの通りだ。王を侮辱する者には天罰こそが下るのだ。王が目を奪おうとした者を、天命は命そのもので引き離した。』 ある者たちは私の言葉に同意し、またある者たちは非難しました。」

「コブラはあのチャンダーラをも噛み、恐怖で走り出した群衆が道を開けたので、蛇も走り去りました。」

注：darvīkara（コブラ）は darvi（柄杓）＋kara（作る者）で、鎌首の形状から。vihitajīvarakṣaḥ は「生命の護りを施した」、すなわちマントラで毒を中和したこと。viṣakṣaṇāt astambhayam は「毒を瞬時に止めた」の意。アルタパーラの蛇毒制御術が計略の鍵。

§22 地下道の発掘 ― マニカルニカー王女の発見

§23 リッディマティーの物語 ― マニカルニカーの秘密

「私は彼女たちに答えました。『美しき方々よ、恐れることはない。私はバラモンの雄牛カーマパーラとカーンティマティー妃から生まれたアルタパーラと申す者。まさしく自宅から王宮へ地下道を掘り進める途中で、偶然にもあなた方を見つけた。あなた方は何者か。どうしてここに暮らしているのか。』」

「『王はこう言って、自分の寝室の壁から二指幅、半腕尺（キシュク）の幅の石を引き抜き、その扉から私たちをこの場所に入れました。ここに住んで十二年が過ぎ、この娘も年頃になりました。しかし王はもはやこの子のことを覚えてもおりません。』」

§24 スィンハゴーシャの捕縛 ― 王国の奪取

「私は彼女たちに言いました。『今日中に王宮である任務を果たし、戻ったらあなた方に相応しく対処しよう。』そして灯りに照らされた地下道を辿り、深夜に半腕尺の石を引き抜いて寝室に侵入し、安心して眠っているスィンハゴーシャを生け捕りにしました。」

§25 結語 ― ラージャヴァーハナとの合流

「このような状況にあった折、アンガ国の王スィンハヴァルマーが、陛下（ラージャヴァーハナ）に忠誠を尽くし恩義ある者であるとのことで、敵に攻められた彼を救援すべく出陣しました。」

「こうして陛下の蓮華の御足の塵の恩寵を賜りました。あの不正なるスィンハゴーシャには、今こそ陛下の御足に礼拝するという贖罪を行わせ、一切の悪行を洗い清めさせてください。」こう述べてアルタパーラは合掌して平伏しました。

ラージャヴァーハナ王は言いました。「大いなる武勇であった。知恵も大いに役立てた。縛られた義父を解放し、我に拝謁させよ。」こう述べて、再びプラマティの方を見て、親愛の微笑を浮かべ、「では次に自らの物語を語れ」と命じました。

注：Aṅgarāja Siṃhavarmā（アンガ王スィンハヴァルマー）はラージャヴァーハナの同盟者。bhavaccaraṇapraṇāmaprāyaścittam（御足への礼拝という贖罪）は、スィンハゴーシャがラージャヴァーハナに臣従することで罪を清められるという意。pramatim eva paśyan は次の第五章の語り手プラマティへの言及。
iti śrīdaṇḍinaḥ kṛtau daśakumāracariter'thapālacaritaṃ nāma caturtha ucchvāsaḥ
以上、聖ダンディン作『ダシャクマーラチャリタ』（十王子物語）のうち「アルタパーラの物語」と名づく第四章
