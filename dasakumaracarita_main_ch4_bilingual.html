1ヴァーラーナスィー到着

deva, so 'ham apy ebhir eva suhṛdbhir eka-karmormimāli-nemi-bhūmi-valayaṃ paribhramann upāsaraṃ kadācit kāśīpurīṃ vārāṇasīm /
1.1「陛下、私（アルタパーラ）もまた、これらの友人たちと同じ目的を抱いて、海を縁とする大地の円環を巡りながら、あるとき聖都カーシー、すなわちヴァーラーナスィーに近づきました。」
upaspṛśya maṇi-bhaṅga-nirmalāmbhasi maṇikarṇikāyām avimukteśvaraṃ bhagavantam andhaka-mathanam abhipraṇamya pradakṣiṇaṃ paribhraman puruṣam ekam āyāmavantam āyasa-parigha-pīvarābhyāṃ bhujābhyām ābadhyamāna-parikaram avirata-ruditocchūna-tāmra-dṛṣṭim adrākṣam /
1.2「宝石の砕けたように澄み切った水をたたえるマニカルニカー・ガートで沐浴し、アヴィムクテーシュヴァラなるシヴァ神――アンダカの殺害者たる大神――に深く礼拝し、右繞して巡拝しておりますと、ある男を見かけました。背は高く、鉄の棒のように逞しい両腕で帯を締め直し、絶え間なく泣き続けて腫れ上がった赤い目をしておりました。」
atarkayaṃ ca “karkaśo 'yaṃ puruṣaḥ kārpaṇyam iva varṣati kṣīṇa-tāraṃ cakṣuḥ, ārambhaś ca sāhasānuvādī, nūnam asau prāṇa-niḥspṛhaḥ kim api kṛcchraṃ priya-jana-vyasana-mūlaṃ pratipatsyate / tat pṛccheyam enam / asti cen mamāpi ko 'pi sāhāyya-dānāvakāśas tam enam abhyupetyetyapṛccham “bhadra, saṃnāho 'yaṃ sāhasam avagamayati / na ced gopyam icchāmi śrotuṃ śoka-hetum” iti /
1.3「私は推察しました。『この男は荒々しい性格だ。瞳の光も衰えたその目は、哀れさを降らせているかのようだ。その身構えは無謀な行為を暗示している。きっとこの男は命を惜しまず、愛する者の災難に根ざした何か恐ろしいことを企てるのだろう。彼に尋ねてみよう。もし私にも何か助力の機会があるなら。』こう考えて近づき、尋ねました。『友よ、その武装は無謀を企てていることを示している。秘密でなければ、悲しみの原因を聞かせてほしい。』」
sa māṃ sabahu-mānaṃ nirvarṇya “ko doṣaḥ, śrūyatām” iti / kvacit karavīra-tale mayā saha niṣaṇṇaḥ kathām akārṣīt
1.4「彼は私を敬意をもって見つめ、『差し支えありません、お聞きください』と言い、あるカラヴィーラの木の下に私と共に座って物語を語り始めました。」
注マニカルニカー（maṇikarṇikā）はヴァーラーナスィー（ベナレス）の最も神聖な火葬ガートの一つ。アヴィムクテーシュヴァラ（avimukteśvara）は「決して去らぬ主」の意で、ヴァーラーナスィーのシヴァ神の名。andhakamathanam は魔神アンダカを殺した者の意で、シヴァの異名（Kale注）。

2プールナバドラの物語 ― 盗賊、象による処刑

“mahābhāga, so 'ham asmi pūrveṣu kāma-caraḥ pūrṇabhadro nāma gṛhapati-putraḥ / prayatna-saṃvardhito 'pi pitrā daiva-cchandānuvartī caurya-vṛttir āsam / athāsyāṃ kāśīpuryām arya-varyasya kasyacid gṛhe corayitvā rūpābhigrāhito baddhaḥ /
2.1「『大徳よ、私はかつて自由気ままに暮らしていたプールナバドラという名の商人の息子です。父に丹精込めて育てられましたが、運命に従い盗みを生業としておりました。この聖都カーシーで、ある高貴な方の家に忍び込み、現行犯で捕らえられ、縛り上げられました。』」
vadhye ca mayi matta-hastī mṛtyuvijayo nāma hiṃsā-vihārī rāja-gopuropari talādhirūḍhasya paśyataḥ kāmapāla-nāmna uttamāmātyasya śāsanāj jana-kaṇṭha-rava-dvi-guṇita-ghaṇṭā-ravo maṇḍalita-hasta-kāṇḍaṃ samabhyadhāvat /
2.2「『私が処刑されることになると、ムリティユヴィジャヤ（「死に勝つ者」）という名の、殺戮を好む狂象が、王宮の楼閣の上から見守るカーマパーラという名の宰相の命令により、群衆の喉を震わせるかのように鈴の音を倍加させ、鼻を振り回しながら突進してきました。』」
abhipatya ca mayā nirbhayena nirbhartsitaḥ pariṇaman dāru-khaṇḍa-suṣirānupraviṣṭobhaya-bhuja-daṇḍa-ghaṭita-pratimāno bhīta-van nyavartiṣṭa / bhūyaś ca netrā jāta-saṃrambheṇa nikāma-dāruṇair vāg-aṅkuśa-pāda-pātair abhimukhīkṛtaḥ / mayāpi dviguṇābaddha-manyunā nirbhartsyābhihato nivṛtyāpādravat /
2.3「『突進してきた象を、私は恐れずに一喝しました。象は向きを変えたところで、丸太の木枷にはめられた私の両腕で額を打たれ、怯えたように引き下がりました。御者が再び激昂し、残忍な鞭と言葉の鉤と足蹴りで象を向き直させましたが、私が倍加した怒りで一喝し打ち据えると、象は逃げ出しました。』」
atha mayopetya sarabhasam ākruṣṭo ruṣṭaś ca yantā “hanta, mṛto 'si kuñjarāpasada” iti niśitena vāraṇena vāraṇaṃ muhur muhur abhighnan-niryāṇa-bhāge katham api mad-abhimukham akarot /
2.4「『私が近づいて激しく罵ると、怒った象使いが「この象の恥さらしめ、死ぬがよい」と鋭い鞭で何度も打って、やっとのことで私に向き直らせました。』」
athāvocam — “apasaratu dvika-kīṭa eṣaḥ / anyaḥ kaścin mātaṅga-patir ānīyatām / yenāhaṃ muhūrtaṃ vihṛtya gacchāmi gantavyāṃ gatim” iti / dṛṣṭvaiva sa māṃ ruṣṭam udgarjantam utkrānta-yantṛ-niṣṭhurājñaḥ palāyiṣṭa /
2.5「『すると私は言いました。「このちっぽけな虫けらは下がらせろ。もっと立派な象を連れて来い。一時ほど戯れてから、行くべき道に行こうぞ。」すると象は、怒って雄叫びを上げる私を見、御者の残忍な命令をも超えて逃げ去りました。』」
注mṛtyuvijaya（ムリティユヴィジャヤ）は「死に勝つ者」の意。処刑用の狂象で、死刑囚を踏み殺す役割を担う。プールナバドラが象を恐れず、逆に威嚇して怯えさせた場面は、彼の超人的な勇猛さを示す（Kale注: "Mrityuvijaya is Death itself incarnate in the form of an elephant"）。
注dāru-khaṇḍa-suṣirānupraviṣṭobhaya-bhuja-daṇḍa は、丸太の穴に両腕を通した木枷（処刑される囚人の拘束具）のこと。プールナバドラはその木枷ごと両腕で象の額（pratimāna）を打ったのである。

3宰相カーマパーラの賞賛と登用

mantriṇā punar ahamāhūyābhyadhāyiṣi — “bhadra, mṛtyur evaiṣa mṛtyuvijayo nāma hiṃsā-vihārī / so 'yam api tāvat tvayaivaṃbhūtaḥ kṛtaḥ / tad viramya karmaṇo 'smān malīmasāt kim alam asi pratipadyāsmān ārya-vṛttyā vartitum” iti / “yathājñāpito 'smi” iti vijñāpito 'yaṃ mayā mitra-van mayyavartiṣṭa /
3.1「『すると宰相（カーマパーラ）が私を呼び寄せて言いました。「友よ、このムリティユヴィジャヤは死そのもの、殺戮を楽しむ象だ。それをお前はこのようにしてしまった。この汚れた行いをやめて、我々のもとに身を寄せ、正しい生き方で暮らしていくことができるか。」私は「仰せのままに」と申し上げ、彼は私に友のように接してくれました。』」
pṛṣṭaś ca mayaikadā rahasi jāta-viśrambheṇābhāṣata sva-caritam —
3.2「『そしてあるとき、密かに信頼関係が生まれた折、尋ねると彼は自らの身の上話を語り始めました。』」
注宰相カーマパーラがプールナバドラを登用する場面。karmaṇo 'smān malīmasāt は「我々を汚す（malīmasa）行為から」の意。宰相は盗賊の勇猛さを正しい方向に導こうとする（Kale注, p.128）。

4カーマパーラの身の上話（一）― クスマプラ出身、放蕩と恋

“āsīt kusumapure rājño ripuñjayasya mantrī dharmapālo nāma viśruta-dhīḥ śruta-ṛṣiḥ / amuṣya putraḥ sumitro nāma pitraiva samaḥ prajñā-guṇeṣu / tasyāsmi dvaimāturaḥ kanīyān bhrātāham /
4.1「『クスマプラ（パータリプトラ）にリプンジャヤ王の宰相ダルマパーラという名の、智慧高く聖仙のごとき者がおりました。その息子スミトラは、父と同じく知恵の徳に優れておりました。私はその異母弟にあたります。』」
veśeṣu vilasantaṃ mām asau vinaya-rucir avārayat / avārya-durnayaś cāham apasṛtya diṅmukheṣu bhraman yadṛcchayāsyāṃ vārāṇasyāṃ pramada-vane madanadamanārādhanāya nirgatya saha sakhībhiḥ kandukenānukrīḍamānāṃ kāśībhartuś caṇḍasiṃhasya kanyāṃ kāntimatīṃ nāma cakame / katham api samagacche ca /
4.2「『兄は遊郭に入り浸る私を礼儀正しく諌めましたが、私は止まらず、素行不良のまま家を飛び出して諸方を彷徨い、偶然このヴァーラーナスィーに来ました。そこで遊園（pramadavana）で愛神を滅ぼした神（シヴァ）を礼拝するために出てきた、カーシー王チャンダスィンハの王女カーンティマティーを、侍女たちとまり遊びに興じている姿に見染め、恋に落ちました。そしてどうにかして彼女と逢瀬を重ねるようになりました。』」
注Kusumapura（クスマプラ）はパータリプトラ（現パトナ）の別名。カーマパーラの父ダルマパーラはリプンジャヤ王の宰相で、兄スミトラも同様に賢明。dvaimāturaḥ は「異母の」の意（Kale注）。pramadavana は王宮付属の遊園。

5カーマパーラの身の上話（二）― 密通発覚、処刑未遂と逃亡

atha channaṃ ca viharatā kumārīpure sā mayāsīd āpannasattvā / kañcit sutaṃ ca prasūtavatī / mṛta-jāta iti so 'paviddho rahasya-nirbheda-bhayāt parijanena krīḍā-śaile /
5.1「『私は密かに王女の居室に通い、彼女は身ごもり、やがて男子を産みました。秘密が漏れることを恐れた侍従たちは、その子を死産と偽って遊戯の丘に捨てました。』」
śabaryā ca śmaśānābhyāśaṃ nītaḥ / tayaiva nivartamānayā niśīthe rājya-vīthyām ārakṣika-puruṣair abhigṛhya tarjitayā daṇḍa-pāruṣya-bhītayā nirbhinna-prāyaṃ rahasyam /
5.2「『シャバラ族の女がその子を火葬場の近くに連れていかれました。しかし夜中に帰る途中、巡回中の王の警吏に捕らえられ、脅された彼女は刑罰を恐れて秘密をほぼ打ち明けてしまいました。』」
rājājñayā niśīthe 'ham ākrīḍana-giri-darī-gṛhe viśrabdha-prasuptas tayopadarśito yathopapanna-rajju-baddhaḥ śmaśānam upanīya mātaṅgodyatena kṛpāṇena prājihīrṣye niyati-balāl lūna-bandhas tam asim ācchidyāntyajaṃ tam anyāṃś ca kāṃścit prahṛtyāpāsaram /
5.3「『王の命令で、夜中に遊戯の山の洞窟で安心して眠っていた私は、彼女の密告で見つかり、有り合わせの縄で縛られ、火葬場に連行されました。不可触民（マータンガ、チャンダーラ）が剣を振り上げたその時、運命の力で縄が切れ、その剣を奪い取り、不可触民やその他の者たちを打ち倒して逃れました。』」
注kumārīpura は王女の居所。krīḍāśaila（遊戯の丘）は王宮付属の人工の丘。mātaṅga は不可触民（チャンダーラ）を指し、処刑人の役割を担った。niyatibalāt（運命の力により）は、カーマパーラの脱出が天命であったことを示す（Kale注, p.128）。

6ターラーヴァリーとの出会い

aśaraṇaś ca bhramann aṭavyām ekadāśru-mukhyā kayāpi divyākārayā saparicārayā kanyayopāsthāyiṣi / sā mām añjali-kisalayottaṃsitena mukha-vilola-kuntalena mūrdhnā praṇamya mayā saha vana-vaṭa-drumasya kasyāpi mahataḥ pracchāya-śītale tale niṣaṇṇā, “kāsi vāsu, kuto 'syāgatā, kasya hetor asya me prasīdasi” iti sābhilāṣam ābhāṣitā mayā vāṅmayaṃ madhu-varṣam avarṣat
6.1「『身寄りもなく森を彷徨っておりますと、あるとき涙を浮かべた顔の、天上の姿をした侍女を伴う乙女が近づいてきました。彼女は蕾のように合わせた掌を頭上に掲げ、顔に垂れる巻き毛を揺らしながら頭を下げて私に礼拝し、私と共に森の大きなバニヤン樹の涼しい木陰に座りました。私が「お前は誰だ、どこから来た、何のために私を慕うのか」と情を込めて問うと、彼女は蜜の雨のような言葉を降らせました。』」

7ターラーヴァリーの物語 ― ヤクシャの娘

“ārya, nāthasya yakṣāṇāṃ maṇibhadrasyāsmi duhitā tārāvalī nāma / sāhaṃ kadācid agastya-patnīṃ lopāmudrāṃ namaskṛtyāpāvartamānā malaya-gireḥ paretāvāse vārāṇasyāḥ kam api dārakaṃ rudantam adrākṣam / ādāya cainaṃ tīvra-snehān mama pitroḥ saṃnidhim anaiṣam /
7.1「『「旦那様、私はヤクシャたちの主マニバドラの娘ターラーヴァリーと申します。かつてマラヤ山でアガスティヤ仙の妻ローパームドラーに礼拝した帰り、ヴァーラーナスィーの火葬場のあたりで泣いている赤子を見つけました。深い愛情から抱き上げ、両親の元に連れて行きました。」』」
anaiṣīc ca me pitā devasyālakeśvarasyāsthānīm / athāham āhūyājñaptā harasakhena, “bāle bāle 'smin kīdṛśas te bhāvaḥ” iti / “aurasa ivāsmin vatse vatsalatā” iti mayā vijñāpitaḥ “satyam āha varākī” iti tan-mūlām ati-mahatīṃ kathām akarot /
7.2「『「父は私をアラケーシュヴァラ（クベーラ神）の宮殿に連れて行きました。するとシヴァの友（クベーラ）が私を呼んで尋ねました。「おい娘よ、この子にどんな思い入れがあるのだ。」私が「実の子のようにこの子に慈しみを感じます」と申し上げると、「哀れな娘の言うことは真実だ」と仰り、その子にまつわる非常に長い物語を語り始めました。」』」
注Maṇibhadra（マニバドラ）はヤクシャの首長の一人でクベーラの部下。Lopāmudrā（ローパームドラー）はアガスティヤ仙の妻。Alakeśvara（アラケーシュヴァラ）はクベーラ神の別名で、アラカー城の主。harasakha（シヴァの友）もクベーラの別名。

8輪廻転生の物語 ― クベーラの啓示

tatraitāvan mayāvagatam “tvaṃ kila śaunakaḥ śūdrakaḥ kāmapālaś cābhinnaḥ / bandhumatī vinayavatī kāntimatī cābhinnā / vedimatyārya-dāsī somadevī vaikaiva / haṃsāvalī śūrasenā sulocanā cānanyā / nandinī raṅgapatākendrasenā cāpṛthag bhūtā /
8.1「『「その物語から私が理解したのは次のことです。あなたはシャウナカ、シュードラカ、そしてカーマパーラと同一人物です。バンドゥマティー、ヴィナヤヴァティー、カーンティマティーも同一人物です。ヴェーディマティー、アーリヤダースィー、ソーマデーヴィーも一人です。ハンサーヴァリー、シューラセーナー、スロチャナーも別人ではありません。ナンディニー、ランガパターカー、インドラセーナーも同じです。」』」
yā kila śaunakāvasthāyām agni-sākṣikam ātmasāt kṛtā gopa-kanyā saiva kilārya-dāsī punaś cādya tārāvalītyabhūvam /
8.2「『「シャウナカの世において火を証人として娶った牧女こそアーリヤダースィーであり、さらに今の私――ターラーヴァリーとなりました。」』」
bālaś ca kila śūdrakāvasthe tvayyārya-dāsyavasthāyāṃ mayyudabhūt / avardhyata ca vinayavatyā sneha-vāsanayā / sa tu tasyāṃ kāntimatyavasthāyām adyodabhūt /
8.3「『「シュードラカの世のあなたと、アーリヤダースィーの世の私との間に男の子が生まれ、ヴィナヤヴァティー（＝カーンティマティー）の愛情の宿縁で育てられました。その子が、カーンティマティーの世では今日お生まれになったのです。」』」
注ここにダンディン文学の核心的主題である輪廻転生の入れ子構造が現れる。シャウナカ→シュードラカ→カーマパーラ、バンドゥマティー→ヴィナヤヴァティー→カーンティマティー等、登場人物が複数の生にわたって同一であることをクベーラ神が明かす。gopakanyā（牧女）がターラーヴァリーの前世であるという設定は、ヤクシャ族の娘が人間と深い宿縁で結ばれていることを示す。

9ターラーヴァリーの使命 ― 赤子の托身

evam aneka-mṛtyu-mukha-paribhraṣṭaṃ daivān mayopalabdhaṃ tam ekapiṅgādeśād vane tapasyato rājahaṃsasya devyai vasumatyai tat-sutasya bhāvi-cakravartino rājavāhanasya paricaryārthaṃ samarpya gurubhir abhyanujñātā kṛtānta-yogāt kṛtānta-mukha-bhraṣṭasya te pāda-padma-śuśrūṣārtham āgatāsmi” iti /
9.1「『「こうして幾度も死の口から逃れたその子を、天命により私が見出し、エーカピンガ（クベーラ）の指示に従い、森で苦行するラージャハンサ王の妃ヴァスマティーに、その子にして未来の転輪聖王ラージャヴァーハナの侍者として献上しました。そして師たちの許しを得て、死の宿縁により死の口から逃れたあなた様の蓮華の御足に仕えるために参りました。」と（ターラーヴァリーは語りました）。』」
śrutvā tām aneka-janma-ramaṇīm asakṛd āśliṣya harṣāśru-mukho muhur muhuḥ sāntvayitvā tat-prabhāva-darśite mahati mandire 'harniśaṃ bhūmi-durlabhān bhogān anvabhūvam /
9.2「『幾世にもわたる愛しい女の言葉を聞き、私は何度も彼女を抱きしめ、歓喜の涙を浮かべながら繰り返し慰めました。そして彼女の神通力で現れた大きな宮殿で、昼夜を問わず地上では得がたい享楽を味わいました。』」
注ekapiṅga はクベーラ神の異名（片目が黄色い者）。bhāvicakravartin（未来の転輪聖王）としてのラージャヴァーハナの運命が予言されている。kṛtāntayogāt kṛtāntamukhabhraṣṭa は「死の宿縁により死の口から逃れた」という巧みな語呂合わせ（Kale注）。

10チャンダスィンハへの対決 ― 夜の王宮侵入

dvitrāṇi dināny atikramya mattakāśinīṃ tām avādiṣam “priye, pratyapakṛtya mat-prāṇa-drohiṇaś caṇḍasiṃhasya vaira-niryātana-sukham anububhūṣāmi” iti tayā sasmitam abhihitam “ehi kānta, kāntimatī-darśanāya nayāmi tvām” iti /
10.1「『二、三日が経ち、陶然としたターラーヴァリーに私は言いました。「愛しい者よ、命を狙ったチャンダスィンハに報復し、復讐の快楽を味わいたい。」彼女は微笑んで言いました。「さあ、愛しい方、カーンティマティーに会わせてあげましょう。」』」
sthite 'rdharātre rājño vāsagṛham anīye / tatas tacchiro-bhāga-vartinīm ādāyāsi-yaṣṭiṃ prabodhyainaṃ prasphurantam abravam — “aham asmi bhavaj-jāmātā / bhavad-anumatyā vinā tava kanyābhimarśī / tam aparādham anuvṛttyā pramārṣṭum āgataḥ” iti /
10.2「『深夜になって王の寝室に至ると、その枕元にあった剣を取り、王を起こし、震える彼に言いました。「私はあなたの婿です。あなたの許可なく王女を犯した者です。その非礼を、礼を尽くしてお詫びするために参った。」』」
so 'ti-bhīto mām abhipraṇamyāha “aham eva mūḍho 'parāddhaḥ yas tava duhitṛ-saṃsargānugrāhiṇo graha-grasta ivotkrānta-sīmā bhavad-adhīnam” ityavādīt /
10.3「『王は甚だ恐れ、私に平伏して言いました。「愚かなのは私の方でした。娘との縁を結んでくれた恩人であるあなたに対し、惑星に取り憑かれたように分を超えた振る舞いをしてしまいました。あなたに従います。」』」
注anuvṛttyā pramārṣṭum（恭順によって拭い去る）――anuvṛtti は「従うこと、礼を尽くすこと」。剣を手にしながら「お詫びに来た」と言う皮肉な場面である。ここでのカーマパーラの大胆な行動は、彼の策士としての性格を示す。

11正式な婚姻 ― 宰相から事実上の皇太子へ

athāparedyuḥ prakṛti-maṇḍalaṃ saṃnipātya vidhivad ātmajāyāḥ pāṇim agrāhayat / aśrāvayac ca tanaya-vārtāṃ tārāvalī kāntimatyai, somadevī-sulocanendrasenābhyaś ca pūrva-jāti-vṛttāntam /
11.1「『翌日、王は臣下の集会を召集し、正式な儀礼に則って自らの娘（カーンティマティー）の手を私に与えました。そしてターラーヴァリーはカーンティマティーに息子の消息を、またソーマデーヴィー、スロチャナー、インドラセーナーにも前世の経緯を語り聞かせました。』」
ittham ahaṃ mantri-padāpadeśaṃ yauvarājyam anubhavan viharāmi vilāsinībhiḥ” iti /
11.2「『こうして私は宰相の地位を名目として、実質的な副王（ユヴァラージャ）の権威を享受し、妃たちと共に暮らしておりました。』と（カーマパーラは語り終えました）。」
注mantripadāpadeśam yauvarājyam は「宰相の地位を口実として（実質は）副王の権力」の意。apadeśa は「名目、口実」（Kale注: "under the guise of the ministerial post"）。カーマパーラは義父チャンダスィンハを制圧した後、形式上は宰相だが実権を握っている。

12悪臣たちの讒言 ― スィンハゴーシャの毒心

sa evaṃ mādṛśe 'pi jantau paricaryānubandhī bandhur ekaḥ sarva-bhūtānām, alasakena svargate śvaśure, jyāyasi ca śyāle caṇḍaghoṣa-nāmni strīṣv ati-prasaṅgāt prāg eva kṣaya-kṣīṇāyuṣi, pañca-varṣa-deśīyaṃ siṃhaghoṣa-nāmānaṃ paiśunya-vādināṃ durmantriṇaḥ katicid āsann antaraṅga-bhūtāḥ /
12.1「〔プールナバドラの語り再開〕『このように彼（カーマパーラ）は私のような卑しい者にも恩寵を示す、万物に対して唯一無二の温かき人でした。しかし義父がアラサカ病で世を去り、義兄チャンダゴーシャも女色に溺れてすでに肺病で命を縮めて亡くなると、五歳ばかりのスィンハゴーシャという王子が即位しました。讒言を弄する悪臣が数人、王の側近となりました。』」
taiḥ kilāsāvittham agrāhyata “prasahyaiva svasā tavāmunā bhujaṅgena saṃgṛhītā / punaḥ prasupte rājani prahartum udyatāsir āsīt / tenāsmai tat-kṣaṇa-prabuddhena bhītyānunīya dattā kanyā / taṃ ca deva-jyeṣṭhaṃ caṇḍaghoṣaṃ viṣeṇa hatvā bālo 'yam asamartha iti tvam adyāpi prakṛti-viśrambhaṇāyopekṣitaḥ / kṣiṇoti ca purā sa kṛtaghno bhavantam / tam evāntaka-puram abhigamayituṃ yatasva” iti /
12.2「『彼らは幼王をこう唆しました。「あなたの姉をこの蛇のような男（カーマパーラ）が強引に我がものとした。さらに王（チャンダスィンハ）が眠っている間に殺そうとして剣を振り上げていた。恐怖で屈服させ、娘を与えさせたのだ。兄君チャンダゴーシャも毒殺した。この子（スィンハゴーシャ）は幼く無力だから今のところ臣下の信頼を繋ぎ止めるために放置しているだけだ。やがてこの恩知らずがあなたを滅ぼすだろう。だからこの男を死の都（ヤマの国）に送るべく手を打て。」と。』」
注paiśunyavādin（讒言者）は paiśunya（中傷）に由来。antakapuram は閻魔（Yama）の都、すなわち死の意。caṇḍaghoṣa は strīṣv atiprasaṅgāt（女色への過度の耽溺から）kṣayakṣīṇāyuṣi（肺病で寿命が尽きた）。Kale注では kṣaya は rājayakṣman（王の病＝肺結核）を指すとする。
注GRETILは本節冒頭の一句（jantau paricaryānubandhī … śvaśure, jyāyasi）を二度繰り返しているが、写しの重複と見て一つを削った。alasaka は腸の病の一種。

13カーンティマティーの苦悩 ― スラクシャナー王妃の問い

sa tathā dūṣito 'pi yakṣiṇī-bhayān nāmuṣmin pāpam ācaritum aśakat / eṣu kila divaseṣvayathāpūrvam ākṛtau kāntimatyāḥ samupalakṣya rāja-mahiṣī sulakṣaṇā nāma sapraṇayam apṛcchat “devi, nāham āyathātathyena vipralambhanīyā / kathaya tathyaṃ kenedam ayathāpūrvam ānanāravinde tavaiṣu vāsareṣu” iti /
13.1「『しかし王はヤクシャの女（ターラーヴァリー）を恐れ、カーマパーラに手を出すことができませんでした。そのころ、カーンティマティーの表情がいつもと違っているのを察した王（スィンハゴーシャ）の正妃スラクシャナーが、親しみを込めて尋ねました。「王妃殿、私は嘘で欺かれるべき者ではありません。何がこのところあなたの蓮華のような御顔をいつもと変えているのか、本当のことを話してください。」』」
sā tv avādīt “bhadre, smarasi kim adyāpyāyathātathyena kiñcin mayokta-pūrvam / sakhī me tārāvalī sapatnī ca kim api kaluṣitāśayā rahasi bhartrā mad-gotrāpadiṣṭā praṇayam apyupekṣya praṇamyamānāpy asmābhir upoḍha-matsarā prāvasat / avasīdati ca naḥ patiḥ / ato me daurmanasyam” iti /
13.2「『カーンティマティーは答えました。「親しき方よ、私がかつて嘘を申し上げたことがありましょうか。友にして共妻（sapatnī）であるターラーヴァリーが、何か心を乱されて、人目のない所で夫に私の名で呼び違えられ、親愛の情も顧みず、我々が礼を尽くしても嫉妬を募らせて去ってしまいました。そして夫も沈み込んでおります。それゆえの鬱でございます。」と。』」
注sulakṣaṇā はスィンハゴーシャの正妃。yakṣiṇībhayāt はターラーヴァリーのヤクシャとしての超自然的な力への恐怖を指す。mad-gotrāpadiṣṭā（私の名で呼ばれた）は、夫が閨でターラーヴァリーを誤ってカーンティマティーの名で呼んだこと（gotra-skhalana、名の言い違え）を指す。サンスクリット恋愛文学の常套の趣向で、ターラーヴァリーが心を乱して去ったのはそのためである。

14カーマパーラの逮捕 ― スィンハゴーシャの暴挙

tat-prāyeṇaikānte sulakṣaṇayā kāntāya kathitam / “athāsau nirbhayo 'dya priyatamā-viraha-pāṇḍubhir avayavair dhairya-stambhitāśru-paryākulena cakṣuṣoṣma-śvāsa-śoṣitābhir ivānati-peśalābhir vāgbhir viyogaṃ darśayantam, katham api rāja-kule kāryāṇi kārayantam, pūrva-saṃketitaiḥ puruṣair abhigrāhyābandhayat /
14.1「『スラクシャナーはほぼそのまま、密かに王（スィンハゴーシャ）に伝えました。すると王はもはや恐れることなく、最愛の妻との別離に青ざめた手足で、堪えた涙に曇った目で、熱い溜息に枯れたような穏やかならぬ声で別離の苦しみを示しながら、どうにか宮中の職務を果たしていたカーマパーラを、予め手配していた兵たちに捕らえさせ、拘束しました。』」
tasya kila sthāne sthāne doṣān udghoṣya tathoddharaṇīye cakṣuṣī yathā tan-mūlam evāsya maraṇaṃ bhavet” iti /
14.2「『そして所々で彼の罪状を布告し、両目を抉り出して、それがもとで死に至るようにせよ、と命じました。』」
注cakṣuṣī uddharaṇīye（両目を抉り出すべし）は、悪臣たちの讒言によってスィンハゴーシャが下した残酷な刑罰。しかし「それがもとで死に至るように」（tanmūlam evāsya maraṇaṃ bhavet）という条件は、処刑ではなく目を奪った上での緩慢な死を意図している。

15アルタパーラの正体 ― 父を救う決意

ato 'traikānte yatheṣṭam aśru muktvā tasya sādhoḥ puraḥ prāṇān moktu-kāmo badhnāmi parikaram” iti /
15.1「〔プールナバドラは涙ながらに語り終えました〕『それゆえ、ひとり人目のないところで思う存分涙を流した後、あの善き人（カーマパーラ）の前で命を捨てるつもりで帯を締めているのです。』」
mayāpi tat-pitṛ-vyasanam ākarṇya paryaśruṇā so 'bhihitaḥ “saumya, kiṃ tava gopāyitvā / yas tasya suto yakṣa-kanyayā devasya rājavāhanasya pāda-śuśrūṣārthaṃ devyā vasumatyā hasta-nyāsaḥ kṛtaḥ so 'ham asmi / śakṣyāmi sahasram api su-bhaṭānām udāyudhānāṃ hatvā pitaraṃ mocayitum /
15.2「私（アルタパーラ）もまた父の災難を聞いて涙し、彼に言いました。『友よ、もう隠す必要はない。ヤクシャの娘（ターラーヴァリー）の子で、ラージャヴァーハナ殿下に仕えるためヴァスマティー妃に託された息子とは、この私だ。千人の武装した勇士を打ち倒してでも父を救い出す力がある。』」
api tu saṃkule yadi kaścit pātayet tad-aṅge śastrikāṃ sarva eva me yatno bhasmāni hutam iva bhavet” iti /
15.3「『ただし、混戦の中で誰かが父の体に刃を立てれば、私の全ての努力は灰に帰した供物のように無駄になる。』」
注ここでアルタパーラがカーマパーラの息子であることを初めてプールナバドラに明かす。yakṣakanyayā はターラーヴァリーを指す。hastanyāsaḥ kṛtaḥ は「手に委ねられた」、すなわちヴァスマティー妃に託されたことを意味する。saṃkule（混戦の中で）武器を父の身に向けられることへの懸念が、毒蛇計略を案出する動機となる。

16毒蛇の計略 ― 偽死の策

anavasita-vacana eva mayi mahān āśīviṣaḥ prākāra-randhreṇodairayacchiraḥ / tam ahaṃ mantrauṣadha-balenābhigṛhya pūrṇabhadram abravam “bhadra, siddhaṃ naḥ samīhitam / anena tātam alakṣyamāṇaḥ saṃkule yadṛcchayā patitena nāma daṃśayitvā tathā viṣaṃ stambhayeyaṃ yathā mṛta ity udāsyeta /
16.1「私がまだ話し終えぬうちに、大きな毒蛇が城壁の穴から鎌首をもたげました。私はマントラと薬の力でその蛇を捕獲し、プールナバドラに言いました。『友よ、我々の望みは成就した。この蛇で、群衆に紛れて偶然落ちたように見せかけて父を噛ませ、毒を止めて死んだように見せかけるのだ。』」
tvayā tu mukta-sādhvasena mātā me bodhayitavyā “yā yakṣyā vane devyā vasumatyā hastārpito yuṣmat-sūnuḥ so 'nuprāptaḥ pitur avasthāṃ mad upalabhya buddhi-balād ittham ācariṣyati /
16.2「『お前は恐れずに私の母に知らせよ。「ヤクシャの女によって森でヴァスマティー妃に託されたあなた方の息子が到着しました。父上の窮状を知り、知恵の力でこのように行動します」と。』」
tvayā tu mukta-trāsayā rājñe preṣaṇīyam “eṣa khalu kṣātra-dharmo yad bandhur abandhur vā duṣṭaḥ sa nirapekṣaṃ nirgrāhya iti / strī-dharmaś caiṣa yad aduṣṭasya duṣṭasya vā bhartur gatir gantavyeti / tad aham amunaiva saha citāgnim ārokṣyāmi / yuvati-janānukūlaḥ paścimo vidhir anujñātavyaḥ” iti /
16.3「『そして母は恐れを捨てて王に使いを送り、こう申し入れよ。「クシャトリヤの法とは、親族であろうとなかろうと、罪ある者は容赦なく罰すべしということです。そして婦人の法とは、罪ある夫にせよ罪なき夫にせよ、その運命に従うべしということです。ゆえに私はこの夫と共に火葬の薪に上りましょう。婦人に相応しき最後の儀式をお許しください」と。』」
sa eva nivedito niyatam anujñāsyati / tataḥ svam evāgāram ānīya kāṇḍapaṭī-parikṣipte viviktoddeśe darbha-saṃstaraṇam adhiśāyya svayaṃ kṛtānumaraṇa-maṇḍanayā tvayā ca tatra saṃnidheyam / ahaṃ ca bāhya-kakṣāgatas tvayā praveśayiṣye / tataḥ pitaram ujjīvya tad-abhirucitenābhyupāyena ceṣṭiṣyāmahe” iti /
16.4「『このように申し入れれば王は必ず許可するだろう。それから父を自宅に運び、帳で仕切った人目のない場所にダルバ草の褥を敷いて横たえ、母には殉死の装いをさせてそこに付き添わせよ。私は外の区画に来るから、お前が中に導き入れよ。そうして父を蘇生させ、状況に応じた策を講じよう。』」
sa “tathā” iti hṛṣṭataras tūrṇam agamat /
16.5「彼は『承知した』と喜び勇んで去って行きました。」
注mantrauṣadhabala（マントラと薬草の力）は解毒術を指す。アルタパーラは蛇毒を自在に制御する能力を持つ。kṣātradharma（クシャトリヤの法）と strīdharma（婦人の法）を引き合いに出す母の台詞は、夫への忠誠を装いつつ遺体の引き取りを合法的に実現する策略である。anumaraṇa は夫の遺体と共に火に入るサティー（殉死）の意。

17処刑場での計略 ― 蛇を投げる

ahaṃ tu ghoṣaṇa-sthāne ciñcā-vṛkṣaṃ ghanatara-vipula-śākham āruhya gūḍha-tanur atiṣṭham / ārūḍhaś ca loko yathāyatham uccaiḥ sthānāni / uccāvaca-pralāpāḥ prastutāḥ /
17.1「私は布告の場所にあるタマリンドの木の、鬱蒼とした大枝に登って身を隠しました。群衆もそれぞれ高い場所に陣取り、さまざまな噂話を交わしていました。」
tāvan me pitaraṃ taskaram iva paścād baddha-bhujam uddhura-dhvani-mahājanānuyātam ānīya mad-abhyāśa eva sthāpayitvā mātaṅgas trir aghoṣayat “eṣa mantrī kāmapālo rājya-lobhād bhartāraṃ caṇḍasiṃham, yuvarājaṃ caṇḍaghoṣaṃ ca viṣānnenopāṃśu hatvā punar devo 'pi siṃhaghoṣaḥ pūrṇayauvana ityamuṣmin pāpam ācariṣyan viśvāsād rahasya-bhūmau punar amātyaṃ śiva-nāgam āhūya sthūṇam aṅgāra-varṣaṃ ca rāja-vadhāyopajapya taiḥ svāmi-bhaktyā vivṛta-guhyo rājya-kāmukasyāsya brāhmaṇasyāndhatamasa-praveśo nyāyya iti prāḍvivāka-vākyād akṣyuddharaṇāya nīyate / punar anyo 'pi yadi syād anyāya-vṛttis tam apyevam eva yathārheṇa daṇḍena yojayiṣyati devaḥ” iti /
17.2「やがて私の父が盗賊のように背後で両腕を縛られ、騒がしい道を大群衆に伴われて連行され、ちょうど私のすぐ近くに据えられました。不可触民（チャンダーラ）が三度布告しました。『この宰相カーマパーラは、王位への貪欲から、主君チャンダスィンハと皇太子チャンダゴーシャを毒入りの食事で密かに殺害し、さらにスィンハゴーシャ王が成人した暁にも同じ罪を犯そうとし、信頼に乗じて密議の場で大臣シヴァナーガとストゥーナ、アンガーラヴァルシャを呼び寄せ、王の暗殺を教唆した。しかし彼らが主君への忠義から秘密を暴露したため、王位を欲するこのバラモンには暗黒への没入こそ相応しいとの裁判官の判決により、目を抉り出されるために連行される。今後も不正を行う者があれば、同様に相応の刑罰を科すであろう。』」

18蛇の投下 ― 偽りの死

śrutvaitad baddha-kalakale mahājane pitur aṅge pradīpta-śirasam āśīviṣaṃ vyakṣipam / ahaṃ ca bhīto nāmāvaplutya tatraiva janād anulīnaḥ kruddha-vyāla-daṣṭasya tātasya vihita-jīva-rakṣo viṣa-kṣaṇād astambhayam / apatac caiṣa bhūmau mṛta-kalpaḥ /
18.1「大群衆がざわめく中、それを聞いて、私は父の体に燃えるように鎌首をもたげた毒蛇を投げ落としました。そして恐れたふりをして飛び降り、群衆に紛れて身を隠しました。怒った蛇に噛まれた父の命を守るべく、即座に毒を止めました。父は地面に崩れ落ち、死んだも同然の姿になりました。」
prālapaṃ ca “satyam idaṃ rājāvamāninaṃ daivo daṇḍa eva spṛśatīti / yad ayam akṣibhyāṃ vināvanipena cikīrṣitaḥ, prāṇair eva viyojito vidhinā” iti / mad-uktaṃ ca kecid anvamanyanta, apare punar nininduḥ /
18.2「私は叫びました。『まことにこの通りだ。王を侮辱する者には天罰こそが下るのだ。王が目を奪おうとした者を、天命は命そのもので引き離した。』 ある者たちは私の言葉に同意し、またある者たちは非難しました。」
darvīkaras tu tam api caṇḍālaṃ daṣṭvā rūḍha-trāsa-druta-loka-datta-mārgaḥ prādravat /
18.3「コブラはあのチャンダーラをも噛み、恐怖で走り出した群衆が道を開けたので、蛇も走り去りました。」
注darvīkara（コブラ）は darvi（柄杓）＋kara（作る者）で、鎌首の形状から。vihitajīvarakṣaḥ は「生命の護りを施した」、すなわちマントラで毒を中和したこと。viṣakṣaṇāt astambhayam は「毒を瞬時に止めた」の意。アルタパーラの蛇毒制御術が計略の鍵。

19母の殉死の装い ― カーマパーラの蘇生

atha mad-ambā pūrṇabhadra-bodhitārthā tādṛśe 'pi vyasane nāti-vihvalā kula-parijanānuyātā padbhyām eva dhīram āgatya mat-pitur uttamāṅgam utsaṅgena dhārayantyāsitvā rājñe samādiśat “eṣa me patis tavāpakartā na veti daivam eva jānāti / na me 'nayāsti cintayā phalam / asya tu pāṇigrāhakasya gatim ananuprapadyamānā bhavat-kulaṃ kalaṅkayeyam” ato 'numantum arhasi bhartrā saha citādhirohaṇāya mām” iti /
19.1「そこで私の母は、プールナバドラから事情を知らされていたので、このような災難の中でも取り乱すことなく、家の従者たちに伴われて堂々と歩いてやって来ました。父の頭を膝に抱いて座り、王に使いを出しました。『この人が陛下の加害者であったか否かは天のみが知ります。この罪について思い煩っても仕方がありません。しかし手を取って娶った夫の運命に従わなければ、御家門に汚名を着せることになります。どうか夫と共に火葬の薪に上ることをお許しください。』」
śrutvā caitat prīti-yuktaḥ samādikṣat kṣitīśvaraḥ “kriyatāṃ kulocitaḥ saṃskāraḥ / utsavottaraṃ ca paścimaṃ vidhi-saṃskāram anubhavatu me bhaginī-patiḥ” iti
19.2「王はそれを聞いて喜び、こう命じました。『家柄に相応しい葬儀を行え。我が姉の夫に対する最後の儀式と法事を盛大に行うがよい。』」
caṇḍāle tu mat-pratiṣiddha-sakala-mantra-vādi-prayāse saṃsthite “kāmapālo 'pi kāla-daṣṭa eva” iti sva-bhavanopanayanam amuṣya sva-māhātmya-prakāśanāya mahīpatir anvamaṃsta /
19.3「チャンダーラ（蛇に噛まれた処刑人）は、私が予め全てのまじない師の治療を妨害しておいたため死亡し、『カーマパーラも天命により蛇に噛まれて死んだのだ』として、王は自らの偉大さを誇示するためにカーマパーラの遺体を自宅に運ぶことを許可しました。」
ānītaś ca pitā me viviktāyāṃ bhūmau darbha-śayyām adhiśāyya sthito 'bhūt /
19.4「父は人目のない場所でダルバ草の褥に横たえられました。」

20母との再会 ― カーマパーラの蘇生と母の歓喜

atha mad-ambā maraṇa-maṇḍanam anuṣṭhāya sakaruṇaṃ sakhīr āmantrya, muhur abhipraṇamya bhavana-devatā yatna-nivārita-parijanākranditā pitur me śayana-sthānam ekākinī prāvikṣat /
20.1「母は殉死の装いを整え、悲痛に友人たちに別れを告げ、何度も家の神々を拝し、泣き叫ぶ従者たちを懸命に抑えながら、ただ独りで父の寝所に入りました。」
tatra ca pūrvam eva pūrṇabhadropasthāpitena ca mayā vainateyatāṃ gatena nirviṣīkṛtaṃ bhartāram aikṣata / hṛṣṭatamā patyuḥ pādayoḥ paryaśru-mukhī praṇipatya māṃ ca muhur muhuḥ prasnuta-stanī pariṣvajya saharṣa-bāṣpa-gadgadam agadat
20.2「そこには、先にプールナバドラの手配で、ガルダ鳥の力を得た私が解毒を施した夫が横たわっておりました。母は無毒化された夫を見て、この上なく喜び、夫の足元に涙を浮かべた顔で平伏し、私をも乳房が溢れるほどに何度も何度も抱きしめ、歓喜の涙に声を詰まらせながら言いました。」
“putra, yo 'si jāta-mātraḥ pāpayā mayā parityaktaḥ, sa kimartham evaṃ mām ati-nirghṛṇām anugṛhṇāsi / athavaiṣa niraparādha eva te janayitā / yuktam asya pratyānayanam antakānanāt /
20.3「『息子よ、生まれたばかりのお前を罪深い私は捨てた。それなのに何ゆえこのような無慈悲な母を慈しんでくれるのか。いや、お前の父こそ何の罪もない者。死神の口から連れ戻すのは正しいこと。』」
krūrā khalu tārāvalī yā tvām upalabhyāpi tattvataḥ kuberād asamarpya mahyamarpitavatī devyai vasumatyai saiva vā sadṛśa-kāriṇī / na hi tādṛśād bhāgya-rāśer vinā mādṛśo jano 'lpa-puṇyas tavārhati kala-pralāpāmṛtāni karṇābhyāṃ pātum / ehi, pariṣvajasva” iti bhūyobhūyaḥ śirasi jighranty aṅkam āropayantī, tārāvalīṃ garhayantyāliṅgayantyaśrubhir abhiṣiñcatī cotkampitāṅga-yaṣṭir anyādṛśīva kṣaṇam ajaniṣṭa /
20.4「『残酷なのはターラーヴァリーだ。お前を見つけておきながら、真実の母である私に返さず、クベーラからヴァスマティー妃に渡してしまうとは。いや、彼女こそ正しきことをしたのかもしれない。あのような福運の集積なしには、私のようなわずかな功徳の者は、お前の舌足らずの甘い喃語を耳で聞く資格がなかったのだ。さあ、抱きしめておくれ。』こう言いながら何度も頭の匂いを嗅ぎ、膝に乗せ、ターラーヴァリーを責め、抱きしめ、涙で私を灌ぎ、震える身体で別人のようにひとときを過ごしました。」
注vainateyatāṃ gatena は「ガルダ（ヴィナターの息子）の状態に至った者（＝蛇毒を制する力を得た者）」の意。ガルダは蛇の天敵であり、蛇毒の解毒の象徴。prasnutastanī（乳が溢れる）は、長年離れていた息子との再会で母乳が自然に溢れるという古典インド文学の常套表現。kalapralāpa（舌足らずの喃語）は幼児の片言を指す（Kale注）。

21反撃の策謀 ― 父子の協議

janayitāpi me narakād iva svargam, tādṛśād avyasanāt tathābhūtam abhyudayam ārūḍhaḥ pūrṇabhadreṇa vistareṇa yathāvṛttāntam āvedito bhagavato maghavato 'pi bhāgyavantam ātmānamajīgaṇat / manāg iva ca mat-saṃbandham ākhyāya harṣa-vismitātmanoḥ pitror akathayam “ājñāpayataṃ kādya naḥ pratipattiḥ” iti /
21.1「父もまた地獄から天国へ上るかのように、あのような災厄からこのような隆運に達し、プールナバドラから詳しく一切の事情を聞かされて、帝釈天よりも自分は幸運だと自認しました。私も手短に身の上を語り、歓喜と驚嘆に包まれた両親に言いました。『今後の方策をご指示ください。』」
pitā me prābravīt “vatsa, gṛham evedam asmadīyam ati-viśāla-prākāra-valayam akṣayyāyudha-sthānam / alaṅghyatamā ca guptiḥ / upakṛtāś ca mayāti-bahavaḥ santi sāmantāḥ / prakṛtayaś ca bhūyasyo na me vyasanam anurudhyante / su-bhaṭānāṃ cāneka-sahasram astyeva sasuhṛt-putra-dāram / ato 'traiva katipayānyahāni sthitvā bāhyābhyantarān kopān utpādayiṣyāmaḥ / kupitāṃś ca saṃgṛhya protsāhyāsya prakṛtyamitrān utthāpya sahajāṃś ca dviṣaḥ, durdāntam enam ucchetsyāmaḥ” iti /
21.2「父は言いました。『息子よ、この我が家は極めて広大な城壁に囲まれ、尽きることのない武器庫を備えている。防備も最も堅固だ。私が恩をかけた封臣は非常に多い。臣民の大半も私の不運を嘆いている。家族を連れた武士も数千おる。だからここに数日間留まり、外部と内部の者たちの不満を煽り、怒った者たちを糾合し鼓舞して、王の敵対勢力を蜂起させ、生来の敵も立ち上がらせ、この手に負えない者（スィンハゴーシャ）を打倒しよう。』」
“ko doṣaḥ, tathāstu” iti tātasya matam anvamaṃsi / tathāsmāsu pratividhāya tiṣṭhatsu rājāpi vijñāpitodanto jātānutāpaḥ pāragrāmikān prayogān prāyaḥ prāyuṅkta / te cāsmābhiḥ pratyaham ahanyanta /
21.3「『異存ありません、そのようにいたしましょう』と父の方針に同意しました。こうして我々が策を巡らせている間に、王の方も事態の報告を受けて後悔し、刺客などの敵対的な策略を頻りに仕掛けてきましたが、我々はそれを日々退けました。」

22地下道の発掘 ― マニカルニカー王女の発見

asminn evāvakāśe pūrṇabhadra-mukhāc ca rājñaḥ śayyā-sthānam avagamya tadaiva svodavasita-bhitti-koṇād ārabhyoragāsyena suraṅgām akārṣam / gatā ca sā bhūmi-svarga-kalpam analpa-kanyakā-janaṃ kam apyuddeśam / avyathiṣṭa ca dṛṣṭaiva sa māṃ nārī-janaḥ /
22.1「このような機に乗じて、プールナバドラの口から王の寝室の位置を知り、すぐさま自宅の壁の隅から蛇の口のような地下道を掘り始めました。するとその地下道は、地上の楽園のような、少なからぬ女たちが暮らすある場所に通じていました。女たちは私を見て驚きました。」
tatra kācid indu-kaleva sva-lāvaṇyena rasātalāndhakāraṃ nihnuvānā vigrahiṇīva devī viśvaṃbharā hara-gṛhiṇīvāsura-vijayāyāvatīrṇā, pātālam āgatā gṛhiṇīva bhagavataḥ kusumadhanvanaḥ gata-lakṣmīr ivāneka-durnṛpa-darśana-parihārāya mahī-vivaraṃ praviṣṭā, niṣṭapta-kanaka-putrikevāvadāta-kāntiḥ kanyakā, candana-lateva malaya-mārutena, mad-darśanenodakampata /
22.2「そこに一人の乙女がおりました。月の一片のように自らの美しさで地底の闇を打ち消すような、大地の女神の化身のような、魔族征伐のために降臨したシヴァの妃のような、あるいはカーマ神の妃が地底に来たかのような、多くの暴君の目を避けて大地の裂け目に入った幸運の女神のような、精錬された黄金の人形のように白く輝く乙女は、白檀の蔓がマラヤ山の風に揺れるように、私を見て震えました。」
tathā bhūte ca tasminn aṅganā-samāje, kusumiteva kāśa-yaṣṭiḥ, pāṇḍu-śirasijā sthavirā kācic caraṇayor me nipatya trāsa-dīnam abrūta “dīyatām abhaya-dānam asmā ananya-śaraṇāya strī-janāya / kim asi deva-kumāro danuja-yuddha-tṛṣṇayā rasātalaṃ vivikṣuḥ / ājñāpaya ko 'si / kasya hetor āgato 'si” iti /
22.3「そのような女たちの集いの中で、カーシャの茎が花を咲かせたように白髪の年長の女が私の足元にひれ伏し、恐れを帯びた声で言いました。『このよるべなき女たちに安全の保証をお与えください。あなたは神の御子でしょうか。阿修羅と戦う渇望から地底に入ろうとなさっているのでしょうか。お命じください。あなたはどなたですか。何の目的でおいでになったのですか。』」
注uragāsyena（蛇の口のように）は地下道の入口の形状を表す。bhūmisvargakalpa（地上の楽園のような）と表現される地下の部屋は、チャンダスィンハが孫娘マニカルニカーを秘密裏に育てさせた場所。kāśayaṣṭi（カーシャ草の茎）は白髪の老女の比喩。rasātala（地底界）は七つの地下世界の一つ。

23リッディマティーの物語 ― マニカルニカーの秘密

sā tu mayā pratyavādi — “sudatyaḥ, mā sma bhavatyo bhaiṣuḥ / aham asmi dvijāti-vṛṣāt kāmapālād devyāṃ kāntimatyām utpanno 'rthapālo nāma / satyarthe nija-gṛhān nṛpa-gṛhaṃ suraṅgayopasarann ihāntare vo dṛṣṭavān / kathayata kāḥ stha yūyam / katham iha nivasatha” iti /
23.1「私は彼女たちに答えました。『美しき方々よ、恐れることはない。私はバラモンの雄牛カーマパーラとカーンティマティー妃から生まれたアルタパーラと申す者。まさしく自宅から王宮へ地下道を掘り進める途中で、偶然にもあなた方を見つけた。あなた方は何者か。どうしてここに暮らしているのか。』」
sodañjalirudīritavatī “bhartṛ-dāraka, bhāgyavatyo vayam, yās tvām ebhir eva cakṣurbhir anagham adrākṣma / śrūyatām / yas tava mātāmahaś caṇḍasiṃhaḥ, tenāsyāṃ devyāṃ līlāvatyāṃ caṇḍaghoṣaḥ kāntimatītyapatya-dvayam udapādi / caṇḍaghoṣas tu yuvarājo 'tyāsaṅgād aṅganāsu rājayakṣmaṇā sura-kṣayam agād antarvatnyāṃ devyām ācāravatyām / amuyā ceyaṃ maṇikarṇikā nāma kanyā prasūtā / atha prasava-vedanayā mukta-jīvitācāravatī patyur antikam agamat /
23.2「その老女は合掌して語り始めました。『若君よ、罪なきあなた様をこの目で拝見できた私どもは幸運でございます。お聞きください。あなた様の母方の祖父チャンダスィンハ王には、リーラーヴァティー妃との間にチャンダゴーシャとカーンティマティーの二人の子がおりました。チャンダゴーシャは皇太子でしたが、女色への過度の耽溺から肺病にかかり、身籠っていた妃アーチャーラヴァティーを残して亡くなりました。この妃からマニカルニカーという名の王女が生まれましたが、母は産褥の苦しみで命を落としました。』」
atha devaś caṇḍasiṃho mām āhūyopahvare samājñāpayat “ṛddhimati, kanyakeyaṃ kalyāṇa-lakṣaṇā / tām imāṃ mālavendra-nandanāya darpasārāya vidhivad vardhayitvā ditsāmi / bibhemi ca kāntimatī-vṛttāntād ārabhya kanyakānāṃ prakāśāvasthāpanāt / ata iyam arāti-vyasanāya kārite mahati bhūmi-gṛhe kṛtrima-śaila-garbhotkīrṇa-nānā-maṇḍapa-prekṣā-gṛhe pracura-paribarhayā bhavatyā saṃvardhyatām / astyatra bhogya-vastu varṣa-śatenopabhogenāpyakṣayyam” iti /
23.3「『チャンダスィンハ王は密かに私（リッディマティー）を呼んでこう命じました。「リッディマティーよ、この王女は吉祥な相を持っている。マーラヴェーンドラの息子ダルパサーラに正式に嫁がせるつもりだ。しかしカーンティマティーの一件以来、王女を公に置くことが恐ろしい。そこで、いかなる災厄にも耐えうるよう、人工の岩山の中に彫り込んだ種々の宮殿や劇場を備えた大きな地下の部屋を作った。豊富な調度品と共にそなたがこの子を育てよ。百年分あっても使い切れぬ物資がある。」』」
sa tathoktvā nija-vāsagṛhasya dvyaṅgula-bhittāvardha-pādaṃ kiṣku-viṣkambham uddhṛtya tenaiva dvāreṇa sthānam idam asmān avīviśat / iha ca no vasantīnāṃ dvādaśa-samāḥ samatyayuḥ / iyaṃ ca vatsā taruṇībhūtā / na cādyāpi smarati rājā /
23.4「『王はこう言って、自分の寝室の壁から二指幅、半腕尺（キシュク）の幅の石を引き抜き、その扉から私たちをこの場所に入れました。ここに住んで十二年が過ぎ、この娘も年頃になりました。しかし王はもはやこの子のことを覚えてもおりません。』」
kāmam iyaṃ pitāmahena darpasārāya saṃkalpitā / tvad-ambayā kāntimatyā ceyaṃ garbha-sthaiva dyūta-jitā sva-mātrā tavaiva jāyātvena samakalpyata / “tad atra prāptarūpaṃ cintyatāṃ kumāreṇaiva” iti /
23.5「『この子は確かに祖父によってダルパサーラに嫁がせるつもりでした。しかしあなた様の母カーンティマティーは、この子がまだ胎内にいる時に、その母（アーチャーラヴァティー）から賭けの勝負で勝ち取り、あなた様の妻とすることを定めておりました。ですからここで相応しい処置をお考えくださいませ、若君。』」
注Ṛddhimati（リッディマティー）はマニカルニカーの乳母。rājayakṣman は「王の病」で肺結核を指す。dvyaṅgulabhittā は「二指幅の壁」で、入口が極めて狭い秘密の通路であることを示す。garbha-sthaiva dyūta-jitā（胎内にいるうちに賭けで勝ち取られた）――カーンティマティーが、身ごもっていたアーチャーラヴァティーとの賭けに勝ち、生まれてくる娘をアルタパーラの妻と定めていたことを指す。

24スィンハゴーシャの捕縛 ― 王国の奪取

tāṃ punar avocam “adyaiva rāja-gṛhe kim api kāryaṃ sādhayitvā pratinivṛtto yuṣmāsu yathārhaṃ pratipatsye” iti / tenaiva dīpa-darśita-bila-pathena gatvā sthite 'rdharātre tad-ardha-pādaṃ pratyuddhṛtya vāsagṛhaṃ praviṣṭo visrabdha-suptaṃ siṃhaghoṣaṃ jīva-grāham agrahīṣam /
24.1「私は彼女たちに言いました。『今日中に王宮である任務を果たし、戻ったらあなた方に相応しく対処しよう。』そして灯りに照らされた地下道を辿り、深夜に半腕尺の石を引き抜いて寝室に侵入し、安心して眠っているスィンハゴーシャを生け捕りにしました。」
ākṛṣya ca tam ahim ivāhi-śatruḥ sphurantam amunaiva bhitti-randhra-pathena straiṇa-saṃnidhim anaiṣam / ānīya ca sva-bhavanam āyasa-nigaḍa-saṃdita-caraṇa-yugalam avanamita-malina-vadanam aśru-bahula-rakta-cakṣuṣam ekānte janayitror adarśayam / akathayaṃ ca bila-kathām /
24.2「ガルダが蛇を引きずるように、もがく王をあの壁の穴の通路を通って女たちの場所に連れて行き、さらに自宅に運びました。鉄の足枷で両足を繋ぎ、頭を垂れ、汚れた顔で涙に充血した目をした王を、人目のないところで両親に見せました。そして地下道の一部始終を語りました。」
atha pitarau prahṛṣṭatarau taṃ nikṛṣṭāśayaṃ niśamya bandhane niyamya tasyā dārikāyā yathārheṇa karmaṇā māṃ pāṇim agrāhayetām / anāthakaṃ ca tad rājyam asmad-āyattam eva jātam / prakṛti-kopa-bhayāt tu man-mātrā mumukṣito 'pi na mukta eva siṃhaghoṣaḥ /
24.3「両親はこの上なく喜び、この卑しい心の者（スィンハゴーシャ）の話を聞くと、彼を拘束したまま、かの王女（マニカルニカー）と正式な婚礼の儀式で私の手を取らせました。主なき王国は我々の手中に収まりました。しかし臣民の怒りを恐れて、母が解放を望んだにもかかわらず、スィンハゴーシャは釈放されませんでした。」
注ahim iva ahiśatruḥ（蛇をガルダが〔引きずる〕ように）は、スィンハゴーシャの捕縛をガルダ神話に喩えた比喩。āyasanigaḍa は鉄の足枷。prakṛtikopabhayāt は「臣民の怒りを恐れて」の意で、カーマパーラがスィンハゴーシャを即座に殺さなかった政治的理由を示す。

25結語 ― ラージャヴァーハナとの合流

tathā sthitāś ca vayam aṅga-rājaḥ siṃhavarmā deva-pādānāṃ bhaktimān kṛta-karmā cetyamitrābhiyuktam enam abhyasarāma /
25.1「このような状況にあった折、アンガ国の王スィンハヴァルマンは陛下（ラージャヴァーハナ）に忠誠を尽くし、我々にも恩義のある方ですので、我々は敵に攻められた彼を救援すべく出陣しました。」
abhūvaṃ ca bhavat-pāda-paṅkaja-rajo 'nugrāhyāḥ sa cedānīṃ bhavac-caraṇa-praṇāma-prāyaścittam anutiṣṭhatu sarva-duścarita-kṣālanam anāryaḥ siṃhaghoṣaḥ” ityarthapālaḥ prāñjaliḥ praṇanāma /
25.2「こうして陛下の蓮華の御足の塵の恩寵を賜りました。あの不正なるスィンハゴーシャには、今こそ陛下の御足に礼拝するという贖罪を行わせ、一切の悪行を洗い清めさせてください。」こう述べてアルタパーラは合掌して平伏しました。
devo 'pi rājavāhanaḥ “bahu parākrāntam / bahūpayuktā ca buddhiḥ, mukta-bandhas te śvaśuraḥ paśyatu mām” ityabhidhāya bhūyaḥ pramatim eva paśyan prīti-smeraḥ “prastūyatāṃ tāvad ātmīyaṃ caritam” ityājñāpayat //
25.3ラージャヴァーハナ王は言いました。「大いなる武勇であった。知恵も大いに役立てた。縛られた義父を解放し、我に拝謁させよ。」こう述べて、再びプラマティの方を見て、親愛の微笑を浮かべ、「では次に自らの物語を語れ」と命じました。
注Aṅgarāja Siṃhavarmā（アンガ王スィンハヴァルマー）はラージャヴァーハナの同盟者。bhavaccaraṇapraṇāmaprāyaścittam（御足への礼拝という贖罪）は、スィンハゴーシャがラージャヴァーハナに臣従することで罪を清められるという意。pramatim eva paśyan は次の第五章の語り手プラマティへの言及。
