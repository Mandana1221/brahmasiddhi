karṇaparva — ṣaḍaśītitamo'dhyāyaḥ (86)
第86章　混戦、ビーマとドゥフシャーサナの対面と対話
sañjaya uvāca|
tataḥ karṇaḥ kuruṣu pradruteṣu varūthinā śvetahayena rājan|
pāñcālaputrānvyadhamatsūtaputro maheṣumirvāta ivābhrasaṅghān||
// 8-86-1 //
サンジャヤは語った。
sūtaṃ rathādañjalikairnipātya jaghāna cāśvāñjanamejayasya|
śatānīkaṃ sutasomaṃ ca bhallair avākiraddhanuṣī cāpyakṛntat||
// 8-86-2 //
ジャナメージャヤの御者を鋭い矢で戦車から落とし、その馬を殺した。シャターニーカとスタソーマの弓を鏃で切り落とした。
dhṛṣṭadyumnaṃ nirbibhedātha ṣaḍbhir jaghānāśvāndakṣiṇāṃstasya saṅkhye|
hatvā cāśvānsātyakeḥ sūtaputraḥ kaikeyaputraṃ nyavadhīdviśokam||
// 8-86-3 //
ドリシュタデュムナを六本で貫き、戦場でサーティヤキの右側の馬を殺した。そしてスータの子はカイケーヤ王の子ヴィショーカを殺した。
tamabhyadhāvannihate kumāre senāpatiḥ kaikayo mitravarmā|
śarairvidhunvanbhṛśamugravegaiḥ karṇātmajaṃ cāpyahanatsudevam||
// 8-86-4 //
王子が殺されると、カイケーヤの将軍ミトラヴァルマンが恐ろしい速さの矢でカルナに向かい、カルナの子スデーヴァをも殺した。
tasyārdhacandraistribhiruccakarta prahasya bāhū ca śiraś ca karṇaḥ|
sa syandanādgāmagamadgatāsuḥ paraśvathaiḥ sāla ivāvarugṇaḥ||
// 8-86-5 //
カルナは笑いながら三本の半月矢でミトラヴァルマンの両腕と首を切り落とした。彼は戦車から大地に落ちて息絶えた。斧で切り倒されたサーラ樹のように。
hatāśvamañjogamibhiḥ suṣeṇaḥ śinipravīraṃ niśitaiḥ pṛṣatkaiḥ|
pracchādya nṛtyanniva karṇaputraḥ śaineyabāṇābhihataḥ papāta||
// 8-86-6 //
馬を失ったスシェーナは、シニの一族の勇者を鋭い矢で覆い、踊るようにしたが、カルナの子はシャイネーヤ（サーティヤキ）の矢に打たれて倒れた。
putre hate krodhaparītayetāḥ karṇaḥ śinīnāṃ pravaraṃ jighāṃsuḥ|
hato'si he sātyaka ityudīrya vyavāsṛjadbāṇamamitrasāham||
// 8-86-7 //
息子が殺されると、怒りに駆られたカルナは、シニ族の最上者を殺そうとして叫んだ。「サーティヤキよ、お前は死んだ！」と言い、敵を圧倒する矢を放った。
tamasya ciccheda śaraṃ śikhaṇḍī tribhis tribhiś ca pratutoda karṇam|
śikhaṇḍinaḥ kārmukaṃ ca dhvajaṃ ca cchittvā kṣurābhyāṃ nyahanatsujātaḥ||
// 8-86-8 //
シカンディンがその矢を切り落とし、三本ずつでカルナを突き刺した。カルナは二本の剃刀矢でシカンディンの弓と旗を切り落とした。
śikhaṇḍinaṃ ṣaḍbhiravidhyadugro dhārṣṭadyumneḥ sa śiraścoccakarta|
tato'bhinatsutasomaṃ kṣureṇa susañjhitenādhirathirmahātmā||
// 8-86-9 //
カルナは六本でシカンディンを貫き、ドリシュタデュムナの子の首を切り落とした。そして偉大なアディラタの子は、鋭い剃刀矢でスタソーマの弓を切った。
athākrande tumule vartamāne dhārṣṭadyumne nihate tatra kṛṣṇaḥ|
apāñcālyaṃ kriyate yāhi pārtha karṇaṃ jahīlābravīdrājasiṃha||
// 8-86-10 //
ドリシュタデュムナの子が殺され、激しい悲鳴が上がる中、クリシュナは言った。「パーンチャーラ族が滅ぼされようとしている。アルジュナよ、行け！カルナを殺せ！」と。
tataḥ prahasyāśu narapravīro rathaṃ rathenādhiratherjagāma|
bhaye teṣāṃ trāṇamicchansubāhur abhyāhatānāṃ rathayūthapena||
// 8-86-11 //
そして人中の勇者アルジュナは笑い、戦車で素早くアディラタの子の戦車に向かった。矢に打たれた者たちの恐怖の中で保護を求める彼らのために。
tato'pare bhārata duṣprakampyāḥ pāñcālānāṃ rathasaṅghāḥ sametāḥ|
pratiśritā hyantarikṣe grahābhā dhanuḥpravīrāstu rathapravīrāḥ||
// 8-86-12 //
バーラタよ、パーンチャーラ族の揺るぎない戦車群が集結し、空中の惑星のように輝く弓の勇者、戦車の勇者たちがいた。
visphārya gāṇḍīvamathograghoṣaṃ jyayā samāhatya tale bhṛśaṃ ca|
bāṇāndhakāraṃ sahasaiva kṛtvā jaghāna nāgāśvarathadhvajāṃś ca||
// 8-86-13 //
恐ろしい轟音のガーンディーヴァを引き絞り、弦を何度も鳴らし、瞬く間に矢の闇を作り出し、象・馬・戦車・旗を殺した。
pratiśrutaḥ prācaradantarikṣe guhā girīṇāmapatanvayāṃsi|
yanmaṇḍalajyena vijṛmbhamāṇo raudre muhūrte'bhyapatatkirīṭī||
// 8-86-14 //
その反響は空中に広がり、山の洞窟から鳥たちが飛び立った。円輪の弦を振り回しながら、恐ろしい瞬間にアルジュナは突撃した。
taṃ bhīmaseno'nuyayau rathena pṛṣṭhe rakṣanpāṇḍavamekavīraḥ|
tau rājaputrau tvaritau rathābhyāṃ karṇāya yātāvaribhirviṣaktau||
// 8-86-15 //
ビーマセーナは戦車でアルジュナの後に従い、背後を守る唯一の勇者であった。二人の王子は急いで戦車でカルナに向かった。敵に阻まれながらも。
tatrāntare sumahānsūtaputraś cakre yuddhaṃ somakānsampramathya|
rathāśvamātaṅgaṇāñjaghāna pracchādayāmāsa śarairdiśaś ca||
// 8-86-16 //
その間にスータの子は大いなる戦いを行い、ソーマカ族を粉砕し、戦車・馬・象の群れを殺し、矢で四方を覆った。
tamuttamaujā janamejayaś ca kruddhau yudhāmanyuśikhaṇḍinau ca|
karṇaṃ bibheduḥ sahitāḥ pṛṣatkaiḥ sannardamānāḥ saha pārṣatena||
// 8-86-17 //
ウッタマウジャス、ジャナメージャヤ、怒れるユダーマンユとシカンディン——彼らはパールシャタ（ドリシュタデュムナ）と共に一致団結して矢でカルナを貫いた。
te pañca pāñcālarathāḥ sametā vaikartanaṃ karṇamabhidravantaḥ|
tasmādrathāccyāvayituṃ na śekur dhairyātkṛtātmānamivendriyārthāḥ||
// 8-86-18 //
五台のパーンチャーラの戦車が合流して、ヴァイカルタナ・カルナに突撃した。しかし彼の戦車から彼を追い落とすことはできなかった。感覚の対象が自己を制した者を動揺させられないように。
teṣāṃ dhanūṃṣi dhvajavājisūtāṃs tūrṇaṃ patākāś ca nikṛtya bāṇaiḥ|
tānpāñcālānabhyahanatpṛvatkaiḥ karṇastataḥ siṃha ivonnanāda||
// 8-86-19 //
カルナは彼らの弓・旗・馬・御者・幟を素早く矢で切り落とし、パーンチャーラ族を矢で殺し、獅子のように吼えた。
tasyāsyatastānabhinighnataś ca jyābāṇahastasya dhanuḥsvenana|
sādridrumā syātpṛthivī viśīrṇety atīva matvā janatā vyapīdat||
// 8-86-20 //
矢を放ち敵を殺し、弦と矢を手にした弓の音で——山も樹木も持つ大地が崩壊するかと人々は思い、大いに恐れた。
sa śakracāpapratimena dhanvanā bhṛśāyatenādhirathiḥ śarānsṛjan|
babhau raṇe dīptamarīcimaṇḍalo yathāṃśumālī pariveṣavāṃstathā||
// 8-86-21 //
インドラの弓（虹）に似た弓で、よく引き絞られた矢を放つアディラタの子は、輝く光の円輪を持つ太陽のように、暈をまとった太陽のように戦場で輝いた。
śikhaṇḍinaṃ dvādaśabhiḥ parābhinacchitaiḥ śaraiḥ ṣaḍbhirathottamaujasam|
tribhiryudhāmanyumavidhyadāśugais tribhistribhiḥ somakapārṣatātmajau||
// 8-86-22 //
シカンディンを十二本の鋭い矢で貫き、ウッタマウジャスを六本で、ユダーマンユを三本の速い矢で、ソーマカとパールシャタの子をそれぞれ三本ずつで射た。
parājitāḥ pañca mahārathāstu te mahāhave sūtasutena māriṣa|
nirudyamāstasthuramitranandanā yathendriyārthātmavatā parājitāḥ||
// 8-86-23 //
五人の大戦車戦士は、大いなる戦場でスータの子に敗れた。自己を制する者に感覚の対象が敗れるように、彼らは力を失って立ち尽くした。
nimajjatastānatha karṇasāgare vipannanāvo vaṇijo yathārṇave|
uddadhrire naubhirivārṇavādrathaiḥ sukalpitairdraupadijāḥ svamātulān||
// 8-86-24 //
カルナの海に沈みゆく彼らを——海で船が壊れた商人のように——ドラウパディーの息子たちが整えた戦車という船で、おじたちを引き上げた。
tataḥ śinīnāmṛṣabhaḥ śitaiḥ śarair nikṛtya karṇaprahitāniṣūnvahūn|
vidārya karṇaṃ niśitairayasmayais tavātmajaṃ jyeṣṭhamavidhyadaṣṭamiḥ||
// 8-86-25 //
シニ族の雄牛（サーティヤキ）は鋭い矢でカルナの放った多くの矢を切り落とし、鋭い鉄矢でカルナを引き裂き、八本で汝の長男（ドゥルヨーダナ）を射た。
kṛpo'tha bhojaś ca tavātmajastathā svayaṃ ca karṇo niśitairatāḍayat|
sa taiścaturbhiryuyudhe yadūttamo digīśvarairdaityapatiryathā tathā||
// 8-86-26 //
クリパ、ボージャ（クリタヴァルマン）、汝の息子、そしてカルナ自身が鋭い矢でサーティヤキを射た。ヤドゥ族の最上者はその四人と戦った。四方の守護神と戦うダイティヤの王のように。
samātateneṣvasanena kūjatā mahāsvanenāśanipātadīdhitiḥ|
babhūva durdharṣataraḥ sa sātyakiḥ śarannabhomadhyagato yathā raviḥ||
// 8-86-27 //
引き絞った弓が鳴り響き、雷の輝きを持つ大いなる音で、サーティヤキは攻め難い者となった。秋の空の中央にある太陽のように。
punaḥ samāsthāya rathānsudaṃśitāḥ śinipravīraṃ jugupuḥ parantapāḥ|
sametya pāñcālamahārathā raṇe marudraṇāḥ śakramivārinigrahe||
// 8-86-28 //
再び戦車に乗って武装したパーンチャーラの大戦車戦士たちが、シニの勇者を守った。マルト神群がインドラを雨の阻止において守るように。
tato'bhavadyuddhamatīva dāruṇaṃ tavāhitānāṃ tava sainikaiḥ saha|
rathāśvamātaṅgavināśanaṃ tathā yathā surāṇāmasuraiḥ purā'bhavat||
// 8-86-29 //
そして極めて恐ろしい戦いが起こった。汝の兵士と汝の敵の間で。戦車・馬・象を滅ぼす、かつての神々とアスラの戦いのような。
rathā dvipā vājipadātayastathā bhramanti nānāvidhaśastraveṣṭitāḥ|
paraspareṇābhihatāś ca caskhalar vinedurārtā vyasavo'pataṃstathā||
// 8-86-30 //
戦車・象・馬・歩兵が、様々な武器にまみれながら飛び回り、互いに打たれてよろめき、苦しんで叫び、息絶えて倒れた。
tathāgataṃ bhīmamabhīstavātmajaḥ sasāra rājāvarajaḥ kirañśaraiḥ|
tamabhyadhāvattvarito vṛkodaro mahāruruṃ siṃha ivābhipedivān||
// 8-86-31 //
そのような状況でビーマに向かい、汝の息子の弟（ドゥフシャーサナ）が矢を放ちながら追った。ヴリコーダラ（ビーマ）は、大きな鹿に向かう獅子のように、彼に素早く向かった。
tatastayoryuddhamatīva dāruṇaṃ pradīvyatoḥ prāṇadurodaraṃ dvayoḥ|
paraspareṇābhiniviṣṭaroṣayor udagrayoḥ śambaraśakrayoryathā||
// 8-86-32 //
二人の間に極めて恐ろしい戦いが起こった。命を賭けた、互いに怒りをたぎらせた二人の——シャンバラとインドラのような戦いが。
śaraiḥ śarīrārtikaraiḥ sutejanair nijaghnatustāvitaretaraṃ bhṛśam|
sakṛtprabhinnāviva vāsitāntare mahāgajau dorbhiradīnaghātinau||
// 8-86-33 //
体に苦痛を与える、鋭い鉄の矢で、二人は互いを激しく射合った。発情期に雌をめぐって争う二頭の大象のように。
ālokya tau caiva parasparaṃ tataḥ samaṃ ca śūrau ca sasārathī tadā|
bhīmo'bravīdyāhi duḥśāsanāya duḥśāsano yāhi vṛkodarāya||
// 8-86-34 //
そして互いを見つめ、武勇においても御者においても互いに等しい二人の勇者——ビーマは言った「来い、ドゥフシャーサナよ！」、ドゥフシャーサナは言った「来い、ヴリコーダラよ！」
tayo rathau sārathisampracoditau samaṃ rathau tau mahasā samīyatuḥ|
nānāyudhacchatrapatākikādhvajau divīva pūrvaṃ balaśakrayo raṇe||
// 8-86-35 //
御者に駆り立てられた二人の戦車は、等しい威光をもって合流した。様々な武器・傘・旗を備えた二台は——かつての天上でのバラとインドラの戦いのように。
bhīma uvāca|
diṣṭyā'si duḥśāsana adya dṛṣṭaḥ kṣaṇaṃ pratīcche sahavṛddhi mūlam|
ciroditaṃ yanmayā te sabhāyāṃ kṛṣṇābhimarśena gṛhāṇa mattaḥ||
// 8-86-36 //
ビーマは語った。
sa evamuktastu tato mahātmā duḥśāsano vākyamuvāca vīraḥ|
sarvaṃ smaranneva visaṃsmarāmi udīryamāṇaṃ śṛṇu bhīmasena||
// 8-86-37 //
このように言われると、偉大なドゥフシャーサナは、勇者として言葉を返した。「私は全てを覚えている、忘れてなどいない。言い続けよ、ビーマセーナ、聞いてやろう。」
smarāmi cātmaprabhavaṃ cirāya yajjātuṣe veśmani rātryahāni|
viśvāsahīnā mṛgayāṃ caranto vasanti sarvatra nirākṛtāstu||
// 8-86-38 //
「私は我々の生まれの時からずっと覚えている。漆の家で過ごした日々と夜を。信頼を失い、狩りをしながら放浪し、あらゆる場所で拒絶された。」
mahābhayaṃ rātryahāni smarantas tathopabhogācca sukhācca hīnāḥ|
vaneṣvaṭanto girigahvarāṇi pāñcālarājasya puraṃ praviṣṭāḥ||
// 8-86-39 //
「大いなる恐怖の中で日夜を思い出す。安楽と享受を奪われて。森をさまよい山の洞窟を彷徨い、パーンチャーラ王の都に入った。」
māyāṃ yūyaṃ kāmapi sampraviṣṭā yato vṛtaḥ kṛṣṇayā phalguno vaḥ|
saṃbhūya pāpaistadanāryavṛttaṃ kṛtaṃ tadā mātṛkṛtānurūpam||
// 8-86-40 //
「何らかの幻術に入り込み、そこでクリシュナー（ドラウパディー）がアルジュナを選んだ。罪ある者たちが一緒になって、あの不名誉な行いをした——母の行いにふさわしいものを。」
ekā vṛtā pañcabhiḥ sābhipannā|
hyalajjamāneś ca parasparasya|
smare sabhāyāṃ subalātmajena dāsīkṛtā yatsaha kṛṣṇayā ca||
// 8-86-41 //
「一人の女が五人に選ばれ——互いに恥じることもなく。集会の場でスバラの子（シャクニ）によって、クリシュナーと共に奴隷にされたことを私は覚えている。」
sañjaya uvāca|
ityevamuktastu tavātmajena pāṇḍoḥ sutaḥ kopavaśaṃ bhṛśaṃ dhanuḥ kṣurābhyāṃ dhvajameva cācchinat|
lalāṭamapyasya bibheda patriṇā // 8-86-42 //
サンジャヤは語った。
śiraś ca kāyātprajahāra sāratheḥ||
sa rājaputro'nyadavāpya kārmukaṃ vṛkodaraṃ dvādaśabhiḥ parābhinat|
svayaṃ niyacchaṃsturagānajihmagaiḥ śaraiś ca bhīmaṃ punarapyavīvṛṣat||
// 8-86-43-44 //
王の子（ドゥフシャーサナ）は別の弓を取り、十二本でヴリコーダラを貫いた。自ら馬を操りながら、真っ直ぐな矢でビーマに再び矢の雨を浴びせた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ṣaḍaśītitamo'dhyāyaḥ|| 86 ||
