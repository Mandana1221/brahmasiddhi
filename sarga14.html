kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

caturdaśaḥ sargaḥ ― 第十四章

アルジュナがキラータの要求を毅然と退け、挑戦的な返答をする（1–25）。使者がシヴァのもとに戻る（26）。シヴァの軍勢がアルジュナに向かって進軍し、矢の雨を浴びせるが、アルジュナはこれを見事に撃退する（27–65）。韻律：ヴァンシャスタ（Vaṃśastha）。第64偈はドゥルタヴィランビタ（Drutavilambita）、第65偈はマーリニー（Mālinī）。
1
Sanskrit
tataḥ kirātasya vacobhir uddhataiḥ parāhataḥ śaila ivārṇavāmbubhiḥ / jahau na dhairyaṃ kupito 'pi pāṇḍavaḥ sudurgrahāntaḥkaraṇā hi sādhavaḥ //
Vaṃśastha
和訳
さてキラータの高慢な言葉に打たれても、海の波に打たれる岩山のように、パーンダヴァは怒りながらも沈着さを失わなかった。善き者の内心は容易には動かぬものだから。
2
Sanskrit
saleśam ulliṅgitaśātraveṅgitaḥ kṛtī girāṃ vistaratattvasaṃgrahe / ayaṃ pramāṇīkṛtakālasādhanaḥ praśāntasaṃrambha ivādade vacaḥ //
Vaṃśastha
和訳
敵の意図を細部まで看破し、言葉の広がりと本質を凝縮することに長けた彼は、時と機を量り、怒りが静まったかのように言葉を発した。

アルジュナの返答（3–25）
Sanskrit
viviktavarṇābharaṇā sukhaśrutiḥ prasādayantī hṛdayāny api dviṣām / pravartate nākṛtapuṇyakarmaṇāṃ prasannagambhīrapadā sarasvatī //
Vaṃśastha
和訳
「明瞭な音韻で飾られ、耳に心地よく、敵の心をも和らげる、澄みて深き言葉の女神サラスヴァティーは、功徳を積まぬ者のもとには現れない。」
シュレーシャ（掛詞）：sarasvatīは「弁才の女神」と「弁論」の両義。viviktavarṇābharaṇāは「明瞭な音声で飾られた」（言語）と「輝かしい容姿と装飾を持つ」（女神）の二重の意味を持つ。

Sanskrit

Vaṃśastha
和訳
雄牛のような肩、太い項、巨岩のごとき堅固な胸を持ち、まるで大猪（ヴィシュヌの化身）が大海から重き大地を持ち上げんとするかのような者に。
ヴィシュヌの第三の化身ヴァラーハ（猪）が海底から大地を救い上げた神話への言及。
41
Sanskrit
harinmaṇiśyāmam udagravigrahaṃ prakāśamānaṃ paribhūya dehinaḥ / manuṣyabhāve puruṣaṃ purātanaṃ sthitaṃ jalādarśa ivāṃśumālinam //
Vaṃśastha
和訳
エメラルドのように黒く、聳え立つ体躯を持ち、他の一切の人間を圧倒して輝く者——人間の姿をとった太古の人（ナラ）が、水鏡に映る太陽のように現れたかのように。
アルジュナはナラの転生とされる（第6章19偈参照）。puruṣa purātanaは原人ナラを指す。
42
Sanskrit
gurukriyārambhaphalair alaṃkṛtaṃ gatiṃ pratāpasya jagatpramāthinaḥ / gaṇāḥ samāsedur anīlavājinaṃ tapātyaye toyaghanā ghanā iva //
Vaṃśastha
和訳
困難な企ての成果で飾られ、世界を揺るがす威厳の権化たる白馬の御者（アルジュナ）に、夏の終わりの雨雲のように、ガナ（部隊）たちは迫った。
43
Sanskrit
yathāsvam āśaṃsitavikramāḥ purā muniprabhāvakṣatatejasaḥ pare / yayuḥ kṣaṇād apratipattimūḍhatāṃ mahānubhāvaḥ pratihanti pauruṣam //
Vaṃśastha
和訳
各々に勝利を期していた敵たちは、聖仙の威力に気力を挫かれ、たちまち途方に暮れた。偉大なる威厳は武勇を打ち砕くのだ。
44
Sanskrit
tataḥ prajahre samam eva tatra tair apekṣitānyonyabalopapattibhiḥ / mahodayānām api saṃghavṛttitāṃ sahāyasādhyāḥ pradiśanti siddhayaḥ //
Vaṃśastha
和訳
そこで互いの力を頼りにし合いながら、一斉に攻撃した。たとえ偉大な者であっても、成功は仲間の助けを必要とし、集団の行動を教えるものだから。
45
Sanskrit
kirātasainyād urucāpanoditāḥ samaṃ samutpetur upāttaraṃhasaḥ / mahāvanād unmanasaḥ khagā iva pravṛttapattradhvanayaḥ śilīmukhāḥ //
Vaṃśastha
和訳
キラータ軍から大弓に弾かれた矢が、羽音を響かせながら一斉に飛び立った。まるで大森林から驚いて飛び出す鳥の群れのように。
46
Sanskrit
gabhīrarandhreṣu bhṛśaṃ mahībhṛtaḥ pratisvanair unnamitena sānuṣu / dhanurninādena javād upeyuṣā vibhidyamānā iva dadhvanur diśaḥ //
Vaṃśastha
和訳
山の深い洞穴での反響と、山稜で増幅された弓弦の轟音が、勢いよく迫り来るように、まるで四方が引き裂かれるかのように鳴り響いた。
47
Sanskrit
vidhūnayantī gahanāni bhūruhāṃ tirohitopāntanabhodigantarā / mahīyasī vṛṣṭir ivānileritā ravaṃ vitene gaṇamārgaṇāvaliḥ //
Vaṃśastha
和訳
樹木の密林を揺るがし、近辺の空と地平を覆い隠す、軍勢の矢の列は、風に駆り立てられた大雨のように轟音を響かせた。
48
Sanskrit
trayīm ṛtūnām anilāśinaḥ sataḥ prayāti poṣaṃ vapuṣi prahṛṣyataḥ / raṇāya jiṣṇor viduṣeva satvaraṃ ghanatvam īye śithilena varmaṇā //
Vaṃśastha
和訳
六カ月間風のみを食し三季を経たジシュヌ（アルジュナ）の体が、戦いの喜びで膨らむと、あたかもそれを知ったかのように、緩んでいた鎧がたちまち密着した。
苦行者は「風食者」（anilāśin）とされ、ほぼ何も食べない。三季（trayī ṛtūnām）は六カ月の苦行期間。鎧が自ら締まったかのように見える擬人化。
49
Sanskrit
patatsu śastreṣu vitatya rodasī samantatas tasya dhanur dudhūṣataḥ / saroṣam ulkeva papāta bhīṣaṇā baleṣu dṛṣṭir vinipātaśaṃsinī //
Vaṃśastha
和訳
武器が降り注ぐ中、天地に弓を振ろうとする彼の恐ろしい眼差しが、怒りに燃えた流星のように軍勢の上に落ちた——壊滅を予告するかのように。
50
Sanskrit
diśaḥ samūhann iva vikṣipann iva prabhāṃ raver ākulayann ivānilam / muniś cacāla kṣayakāladāruṇaḥ kṣitiṃ saśailāṃ calayann iveṣubhiḥ //
Vaṃśastha
和訳
方角を引き寄せるかのように、太陽の光を散らすかのように、風を撹乱するかのように、聖仙は滅亡の時のごとく恐ろしく進み出て、矢をもって山々もろとも大地を揺るがすかのようであった。
51
Sanskrit
vimuktam āśaṃsitaśatrunirjayair anekam ekāvasaraṃ vanecaraiḥ / sa nirjaghānāyudham antarā śaraiḥ kriyāphalaṃ kāla ivātipātitaḥ //
Vaṃśastha
和訳
敵の征服を期して森の民たちが同時に放った多くの武器を、彼は飛行の途中で矢をもって打ち砕いた。あたかも過ぎ去った時が行為の果報を空しくするように。
52
Sanskrit
gataiḥ pareṣām avibhāvanīyatāṃ nivārayadbhir vipadaṃ vidūragaiḥ / bhṛśaṃ babhūvopacito bṛhatphalaiḥ śarair upāyair iva pāṇḍunandanaḥ //
Vaṃśastha
和訳
敵には見えず、遠方まで届いて災いを防ぐ、大いなる成果をもたらす矢によって、パーンドゥの息子は大いに力を得た——あたかも策略（ウパーヤ）によるかのように。
53
Sanskrit
divaḥ pṛthivyāḥ kakubhāṃ nu maṇḍalāt patanti bimbād uta tigmatejasaḥ / sakṛd vikṛṣṭād atha kārmukān muneḥ śarāḥ śarīrād iti te 'bhimenire //
Vaṃśastha
和訳
「天からか、地からか、方角からか、太陽の輪からか、一度だけ引かれた弓からか、それとも聖仙の体そのものからか」——敵たちはその矢の出処を計りかねた。
54
Sanskrit
gaṇādhipānām avidhāya nirgataiḥ parāsutāṃ marmavidāraṇair api / javād atīye himavān adhomukhaiḥ kṛtāparādhair iva tasya pattribhiḥ //
Vaṃśastha
和訳
彼の矢は部隊長たちの急所を刺し貫いたが死には至らせず、使命を果たせなかった罪を恥じるかのように、頭を垂れてヒマーラヤの中に急ぎ消えていった。
部隊長たち（gaṇādhipa）はシヴァの配下の神格であり不死身。矢が彼らを殺せないのは「罪」ではなく道理であるが、矢の擬人化として描かれる。
55
Sanskrit
dviṣāṃ kṣatīr yāḥ prathame śilāmukhā vibhidya dehāvaraṇāni cakrire / na tāsu pete viśikhaiḥ punar muner aruṃtudatvaṃ mahatāṃ hy agocaraḥ //
Vaṃśastha
和訳
聖仙の最初の矢が敵の甲冑を貫いて傷を作ったその同じ場所に、後の矢は再び落ちなかった。すでに傷ついた箇所をさらに傷つけることは、偉大な者の為すことではないから。
56
Sanskrit
samujjhitā yāvadarāti niryatī sahaiva cāpān munibāṇasaṃhatiḥ / prabhā himāṃśor iva paṅkajāvaliṃ nināya saṃkocam umāpateś camūm //
Vaṃśastha
和訳
各々の敵に向けて放たれた聖仙の矢の群れは、弓から同時に飛び立ち、月の光が蓮の列を萎ませるように、ウマーの主（シヴァ）の軍勢を縮退させた。
57
Sanskrit
ajihmam ojiṣṭham amogham aklamaṃ kriyāsu bahvīṣu pṛthaṅ niyojitam / prasehire sādayituṃ na sāditāḥ śaraugham utsāham ivāsya vidviṣaḥ //
Vaṃśastha
和訳
真っ直ぐに、力強く、外れることなく、疲れを知らず、多くの任務に個別に投入された矢の洪水——あるいは彼の意志そのもの——を、打ち倒された敵は制することができなかった。
58
Sanskrit
śivadhvajinyaḥ pratiyodham agrataḥ sphurantam ugreṣumayūkhamālinam / tam ekadeśastham anekadeśagā nidadhyur arkaṃ yugapat prajā iva //
Vaṃśastha
和訳
シヴァの軍隊は、各戦士の前に恐ろしい矢の光輪を放って現れる彼を、一箇所にいるのに多くの場所に同時に現れるかのように見た。あたかも各地の人々が太陽を同時に見るように。
59
Sanskrit
muneḥ śaraugheṇa tadugraraṃhasā balaṃ prakopād iva viṣvag āyatā / vidhūnitaṃ bhrāntim iyāya saṅginīṃ mahānileneva nidāghajaṃ rajaḥ //
Vaṃśastha
和訳
聖仙の矢の洪水によって——あたかも怒りから四方八方に広がったかのような激しい勢いで——軍勢は揺さぶられ、大風に吹き散らされる夏の塵のように、収拾のつかない混乱に陥った。

Sanskrit

Vaṃśastha
和訳

62
Sanskrit
jayena kaccid viramed ayaṃ raṇād bhaved api svasti carācarāya vā / tatāpa kīrṇā nṛpasūnumārgaṇair iti pratarkākulitā patākinī //
