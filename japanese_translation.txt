第Ⅰ章　反形而上学的予備考察
1.

物理学の研究がここ数世紀の間に、自分自身の領域だけでなく、他の学問分野への貢献を通じても大きな成果をあげてきたことにより、物理学的な見方や方法がどこでも前面に押し出され、その応用に最も高い期待がかけられるようになった。

これに応じて、感覚の生理学もまた、ゲーテやショーペンハウアーらが、そして最も大きな成功を収めたのはヨハネス・ミュラーが切り開いた道を徐々に離れ、ほとんど専ら物理学的な性格を帯びるようになった。しかし、物理学がその著しい発展にもかかわらず、なおより大きな全体知の一部にすぎないこと、そしてその一面的な目的のために作られた一面的な知的手段ではこの素材を汲み尽くせないことを考えるならば、この転換は必ずしも適切なものとは思えない。

物理学の支援を放棄することなく、感覚の生理学は自分自身の独自の発展を続けることができるばかりか、物理学自体にも力強い助けを与えることができる。以下の簡単な考察が、この関係を明らかにする手助けとなるだろう。

2.

色、音、熱、圧力、空間、時間は、さまざまな仕方で互いに結びついており、そこにはまた、気分や感情や意志が結びついている。この網の目の中から、比較的固定した持続的なものが際立ってくる。それは記憶に刻み込まれ、言葉として表現される。比較的持続的なものとして最初に現れるのは、空間的・時間的に結びついた色・音・圧力などの複合体であり、これらは特別な名前を与えられて、物体と呼ばれる。しかし、こうした複合体が絶対的に持続的なわけではない。

私のテーブルは、あるときは明るく、あるときは暗く照らされており、暖かいことも冷たいこともある。インクの染みがつくこともある。脚が折れることもある。修理され、磨かれ、部分的に取り替えられることもある。しかしそれでも、私にとっては、毎日その前で書いている、あの同じテーブルである。

私の友人は別のコートを着ることがある。その顔は真剣になったり朗らかになったりする。顔色は照明や感情によって変わりうる。体つきは動きによって、あるいは恒久的に変わりうる。しかし、持続するものの総量は、緩やかな変化に比べれば常にとても大きく、変化は目立たない。毎日一緒に散歩する、あの同じ友人なのだ。

私のコートは染みがついたり穴が開いたりすることもある。この表現が示しているのは、重要なのは持続するものの総量であって、新しいものが付け加えられ、なくなったものがあとから差し引かれる、ということである。

持続するものの方が親しみやすく、変化するものに対して優勢であることが、部分的には本能的に、部分的には意図的・意識的に行われる表象と呼称の節約（＝経済化）へと押しやる。それが普通の思考や言葉づかいに表れている。一度表象されたもの、比較的に持続的なものには、特別な名前がつけられる。

さらに、ある特定の身体（Leib） に結びついた記憶・気分・感情の複合体もまた、比較的に持続的なものとして現れ、自我（Ich） と呼ばれる。私はこの仕事やあの仕事に携わることができ、穏やかで楽しいこともあれば、立腹して不機嫌になることもある。しかし（病的な場合を除けば）、自我をそのまま認めるのに十分な持続性が残っている。もっとも、自我もまたあくまで相対的な持続性しか持たないのだが。

注1） 自我の見かけ上の持続性は、主にその連続性、すなわち緩やかな変化のうちにある。昨日の多くの考えや計画が今日も続けられ、目覚めているあいだ周囲の環境がそれを絶えず思い出させる（だから夢の中では自我はとてもぼんやりし、二重化したり、まったく欠けたりすることがある）。無意識に無意志的に長期間保たれる小さな習慣が、自我の基盤をなしている。異なる人間の自我のあいだの違いよりも、一人の人間が何年もかけて経験する変化のほうが大きいことさえありうる。私が自分の幼少期を思い出すとき、いくつかのわずかな点を除けば、あの少年を別人と見なさなければならないだろう――記憶の連鎖がなければ。私自身が20年前に書いた著作さえ、とても見知らぬ印象を与える。身体の非常に緩やかな変化もまた自我の持続性に貢献しているが、思われているほどではない。人は自分の外見をほとんど分析も注意もしない。若い頃、街で横顔に映った実にいやな顔を見て、それが互いに傾いた二枚の鏡に映った自分自身の顔だと気づいたとき、少なからず驚いた。つい最近、疲れ切った夜行列車のあとで乗合馬車に乗り込んだところ、反対側からも一人の男が乗り込んできた。「なんとくたびれた学校教師が乗ってきたものだ」と思った。――それは自分自身だった。向かい側に大きな鏡がかかっていたのだ。つまり、類型としての見かけは、自分個人の見かけよりもずっと馴染みがあったのだ。

3.

実体概念「物体」「自我」（物質、魂）を形成することで最初の方向づけが果たされると、次に、この比較的持続的なものに起こる変化をより正確に注意する欲求が生まれる。変化するものこそが意志を動かすからである。そこではじめて、複合体の構成部分が、その複合体の属性として浮かび上がってくる。

ある果実は甘い。だが苦いこともありうる。他の果実もまた甘いことがある。探し求めていた赤い色は、多くの物体に見出される。ある物体の近くにいるのは心地よく、他の物体は不快である。こうして、さまざまな複合体が共通の構成部分から成り立っていることが徐々に明らかになる。物体から、見えるもの、聞こえるもの、触れるものが分離される。見えるものは、色と形に分かれる。色の多様性の中に、再びより少数の構成部分、すなわち基本色などが浮かび上がってくる。

複合体は要素へと分解されるのである。

4.

持続するものに名前をつけ、毎回の構成部分の分析なしに一つの思考にまとめるという合目的的な習慣は、構成部分を分離しようとする努力と、独特の対立に陥ることがある。持続するもののうち目立った変化がないとき、ある構成部分が欠けても何か「あるもの」が残るように見える。どの構成部分を一つ一つ取り除いても、その像は全体を代表し続け、再認されるので、全部を取り除いてもまだ何かが残るだろうと思い込んでしまう。

こうして、（その「現象」とは異なる、認識不可能な）物自体 という途方もない思想が生まれる。

物、物体、物質とは、色・音などの複合体の外にあるものではない。いわゆる標識の外にあるものではないのだ。「多くの標識を持つ一つの物」という、あの多彩な哲学的問題は、簡潔なまとめと、入念な分離とが——一方は暫定的に便利であり、他方は別の目的のために有益であるにもかかわらず——両方とも必要であるという事情を見誤ることから生じる。

物体は一つで不変である——個別の点に注意する必要がない限りは。地球やビリヤードの球も球体である——球形からのあらゆる逸脱を無視でき、より大きな精密さが不要である限りは。しかし、地理学や顕微鏡観察に追い込まれれば、どちらの物体も球ではなくなる。

人間には、自分の立場を意図的かつ意識的に決める能力がある。今はもっとも壮大なものから個別の点に目を向け、今は最も些細なことに注目し、今は定常的な流れを内容にかかわりなく見つめ、今はスペクトルの中のフラウンホーファー線の幅を測る。動物はこの能力をはるかに低い程度でしか持たない。帽子をかぶった父親を認識できない乳児や、主人の新しいコートに惑わされる犬は、立場の対立に屈しているのだ。だが、同じような場合に屈したことのない人がいるだろうか？　哲学的に思考する人間でさえ、上で述べたあの奇妙な問題が示すように、時に屈することがある。

5.

自我、すなわち物体と自我の関係もまた、同じ種類の擬似問題を生じさせる。

普通「物体」と呼ばれる色・音などの複合体を、ここではわかりやすくするために A B C … と表すことにする。我々の身体をなし、前者の一部をなす複合体を K L M … と呼ぶ。意志・記憶像などの複合体を α β γ … と表す。

通常、複合体 α β γ … K L M … が自我として、複合体 A B C … が物体世界としてまとめられる。時に、自我は物体世界に対立するものとして置かれ、時に A B C … が自我から独立して自存するものとされる。しかし、この独立性はあくまで相対的であり、注意を高めれば持ちこたえられない。α β γ … にさまざまなことが変化しても、A B C … に目立たないこともあり、その逆もある。しかし多くの場合、α β γ … の変化は K L M … の変化を通じて A B C … に伝わり、またその逆も起こる。

厳密に言えば、A B C … は常に K L M … によって共規定されていることがわかる。サイコロは近くにあれば大きく、遠くにあれば小さく見え、右目と左目では異なり、目を閉じれば二つに見え、両目を閉じればまったく見えなくなる。一つの同じ物体の諸属性が、このように異なって現れるのは、それらが身体によって変容されるからであり、身体によって条件づけられているからにほかならない。言えることはただ、異なる A B C … が異なる K L M … に結びついているということだけである。

6.

通常、複合体 α β γ … は K L M … とともに自我として、複合体 A B C … に対立させられる。A B C … のうち α β γ … をより強く変容させるもの——たとえば刺し傷や痛み——は、自我にまとめられがちである。しかし後に気づくのは、A B C … を自我に数え入れる権利がどこにもなくなるわけではないということだ。つまり、自我は最終的に全世界を包括しうるほどに拡張可能なのである。

自我は鋭く境界づけられたものではなく、かなり不確定で、恣意的に移動可能なものである。このことを見誤り、無意識のうちに境界を狭くしたり広くしたりすることで、立場の対立から形而上学的な困難が生じる。

いわゆる統一体としての「物体」も「自我」も、暫定的な方向づけと特定の実際的な目的のための便宜的な手段にすぎないと認識するや否や、さらに進んだ科学的研究においては、それらを不十分かつ不適切なものとして手放さなければならなくなる。自我と世界、感覚あるいは現象と物との対立は消え去り、問題は要素 A B C … K L M … α β γ … の連関だけになる。この対立は、部分的にしか当たらない不完全な表現にすぎなかったのだ。

7.

この困難は特に、次のような考察において痛感される。

我々が物体世界と呼んだ複合体 A B C … の中には、自分の身体 K L M … だけでなく、他の人間（や動物）の身体 K' L' M' …, K'' L'' M'' … も含まれており、それらには類推によって α β γ … に似た α' β' γ' …, α'' β'' γ'' … が結びついていると考えられる。K' L' M' … を扱っている限り、我々は全く親しみのある、感覚的にアクセス可能な領域にいる。しかし、他者の身体に属する感覚や感情を問い始めると、それらは感覚的領域にはもう見出されず、思考で付け加えなければならない。

そこに踏み込む領域はあまり馴染みがなく、その移行もまた比較的不確かである。まるで深淵に飛び込むべきかのような感覚を抱く。しかし、この道だけに限られているわけではない。

我々は、要素の相互関係を、K L M …（身体）に特別な注意を払うことなく観察できる。白い球がベルに当たれば音がする。ナトリウムランプの前では球は黄色に、リチウムランプの前では赤く見える。ここでは要素 A B C … は互いにのみ結びついており、身体 K L M … からは独立しているように見える。しかしサントニン（薬物）を飲めば球は黄色くなる。目を横に押せば球が二つ見える。両目を閉じれば球はまったく存在しなくなる。聴覚神経を切断すれば音も消える。

つまり、A B C … は互いの間だけでなく K L M … とも結びついている。A B C … が K L M … に依存している限りにおいて、我々はそれを感覚と呼び、自我に属するものと見なす。この道を行けば、物体と感覚、外と内、物質的世界と精神的世界の間に、先に述べたような溝は見出されない。すべての要素 A B C … K L M … はただ一つの連続した塊をなしており、どの要素をつかんでも全体が動き出す——ただし、K L M … での撹乱のほうが A B C … よりもはるかに深く広く及ぶのだが。

8.

こうして、物理学的研究と心理学的研究との大きな溝は、慣習的な紋切り型の見方に対してのみ存在する。色は、例えば照明する光源（他の色、熱、空間など）への依存に注目するときは、物理学的対象である。しかし網膜（要素 K L M …）への依存に注目すれば、それは心理学的対象であり、感覚である。素材ではなく、二つの領域における研究の方向が異なっているのだ。

9.

述べてきた考えは、抽象的な形で言い表すだけでなく、それが由来する事実を直接見つめることで、より確かさと直観性を得る。

例えば、私が長椅子に横たわり、右目を閉じると、左目には次のような図（図1）が見える。眉の弧、鼻、口ひげが作る枠の中に、自分の身体の見える部分と、その周囲の環境が現れる。

私の身体は、他の人間の身体とは次の点で区別される。生き生きとした運動表象がすぐにその身体の運動に変わること、他の物体との接触がより際立った変化を引き起こすこと、そしてそれが部分的にしか、特に頭なしに見えるということである。

10.

A B C … と α β γ … というふたつの要素群の違いについてはすでに触れた。実際、目の前に緑の木を見ているときと、その緑の木を思い出し想像しているときを、我々はよく区別できる。想像された木の姿はずっと不確定で、ずっと変わりやすく、その緑はずっとぼんやりしており、何よりも明らかに別の場（フィールド）の中に現れる。

要素 A あるいは α が異なる場に現れるということは、結局のところ、それらが異なる他の要素と結びついているということにすぎない。したがって、A B C … と α β γ … の基本構成部分は同じもの（色、音、空間、時間、運動感覚、神経支配……）であり、ただそれらの結合の仕方が異なるのである。

痛みや快は感覚とは異なるものと見なされがちである。しかし触覚だけでなく、他のすべての感覚もまた、痛みや快へと徐々に移行しうる。痛みや快もまた、正当に感覚と呼ぶことができる。それらは感覚ほどよく分析され親しまれてはいないが、いかにかすかに現れようとも、すべてのいわゆる感情の本質的な内容を成している。

こうして、知覚も表象も、感情も意志も、つまり内的世界と外的世界の全体が、少数の同質的な要素が、あるときは流動的に、あるときは強固に結びつくことで構成されている。これらの要素は通常感覚と呼ばれる。しかし、この名前にはすでに一面的な理論が含まれているため、我々は単に要素と呼ぶことにする。

すべての研究は、これらの要素の連関の解明に向かうのである。

11.

この要素の複合体——根本的にはただ一つの複合体である——から、物体と自我が、すべての場合に十分なやり方で明確に区切れるわけではないことは、すでに述べた。痛みや快にもっとも密接に関わる要素を思考経済的な統一体としての自我にまとめることは、痛みを避け快を求める意志に仕える知性にとって、最高の意義を持つ。自我の境界設定は本能的に成立し、慣れ親しまれ、おそらく遺伝によってさえ強化されてきた。

しかし、特殊な場合には——実際的な目的ではなく、認識そのものが目的となる場合には——この境界設定は不十分で、邪魔で、維持しがたいものとなりうる。

自我が一次的なのではない。要素（感覚）が一次的なのだ。 要素が自我を形作るのである。「私は緑を感じる」とは、緑という要素が、他の要素（感覚、記憶）のある複合体の中に出現する、ということを意味する。私が緑を感じなくなるとき、つまり私が死ぬとき、要素はもはやかつて慣れ親しんだあの仲間たちの中に現れなくなる。それだけのことである。ある理想的な思考経済的統一体が存在しなくなっただけで、実在的な統一体が消滅したわけではない。

12.

物体が感覚を生み出すのではない。むしろ感覚の複合体（要素の複合体）こそが物体を形作るのだ。物理学者にとって物体が持続的で実在するものに見え、感覚がその束の間の見かけに思えるとしても、彼はすべての物体が感覚の複合体（要素の複合体）のための思考記号にすぎないことを忘れている。

この洞察によって、心理学においても物理学においても多くのことがはるかに透明で経済的になり、多くのいわゆる問題が解消される。

したがって、我々にとって世界は謎めいた存在から成り立っているのではない。ある謎めいた存在が別の謎めいた存在（自我）と相互作用してのみアクセス可能な感覚を生み出す、というようなものではない。色、音、空間、時間……これらが我々にとっての最後の要素であり、その与えられた連関を我々は研究しなければならないのである。

13.

科学は常に、思考がある特定の経験領域に適応するプロセスを通じて生まれる。このプロセスの結果が、その領域全体を表現しうる思考要素である。経験領域が拡大されたり、それまで分離していた複数の領域が統合されると、受け継がれた慣れ親しんだ思考要素はもはや拡大された領域には足りなくなる。獲得された習慣と適応への努力との闘いの中で、問題が生まれる。それらは完全な適応とともに消滅し、別の問題に場所を譲る。

純粋な物理学者にとっては、物体という思考が方向づけを容易にしても、邪魔にはならない。純粋に実際的な目的を追う者にとっては、自我という思考が本質的な助けとなる。あらゆる思考形式は、ある特定の目的のために（無意志的にであれ意志的にであれ）形成されたものであり、まさにその目的に対して永続的な価値を持つ。

しかし、物理学と心理学が接触するや否や、一方の領域の思考が他方の領域では維持できないことが明らかになる。この相互適応の試みから、さまざまな原子論やモナド論が生まれるのだが、それらはその目的を果たすことができない。

もし我々が感覚を（上で述べた意味で）世界の要素と見なすならば、問題は本質的に解消され、最初にして最も重要な適応が果たされたことになる。この根本的な見方は（永遠の哲学と自称することなく）現在のところすべての経験領域に対して堅持でき、したがって最小の労力で暫定的な知識全体に対応できるもっとも経済的なものである。この根本的な見方は、そのもっぱら経済的な機能を自覚しつつ、最大の寛容さをもって現れる。まだ従来の見方で十分な領域には押しつけない。経験領域がさらに拡大されれば、より良い見方に喜んで道を譲る。

一般人の哲学的立場、つまりその素朴な実在論にこの名を認めるとすれば、それは最高の尊重に値する。それは人間の意図的な関与なしに、計り知れない長い時間の中で自然の産物として生まれ、自然によって保持されてきたものだから。哲学がそれに対してなしてきたことは——いかなる段階における、いかなる迷走にも生物学的な正当性は認められるとしても——ほんの些細ではかない人工物にすぎない。

実際、すべての思想家、すべての哲学者が、実際的な困難に迫られてその一面的な知的活動から引き出されると、ただちにこの一般的な（素朴実在論の）立場をとるのを見ることができる。

この「予備考察」は、この立場を貶めようとするものではない。ただ、なぜ、そしてどんな目的のために我々が人生の大半においてこの立場をとるのか、そしてなぜ、どんな目的のために、またどの方向に我々はこの立場を一時的に離れなければならないのかを示すことだけが、この考察の課題である。

どの立場も絶対的で永続的な妥当性を持つものではない。どの立場も、ある特定の目的にとってのみ重要なのである。

（第1章 終わり）

第Ⅱ章　先入見について
1.

物理学者はしばしば、ある領域の認識が、その領域自体の偏見のない探究の代わりに、別の領域で得られた見解をそこに無批判に持ち込むことによって、いかに妨げられうるかを目にする機会がある。しかし、物理学の分野から心理学の分野への先入見の移入によって生じる混乱は、はるかに重大である。いくつかの例で説明しよう。

ある物理学者が、摘出された眼球の網膜上の倒立像を観察し、「空間で下にある点が、なぜ網膜の上に結像するのか」と問う。この問いに彼は屈折光学の研究によって答える。ところが、この問い——物理学の領域では完全に正当なもの——を心理学に持ち込むと、混乱しか生まない。「倒立した網膜像があるのに、なぜ我々は正立して見えるのか」という問いは、心理学的問題としては意味をなさない。個々の網膜部位の光の感覚は、はじめから空間感覚と結びついており、網膜の下側に対応する場所を我々は「上」と呼ぶのである。感じる主体にとっては、そのような問いはそもそも生じえない。

「外界への投射」という有名な理論についても同様である。網膜上の像の点に対して、目の交差点を通る光線の延長上に発光する対象点を求めるのは、物理学者の仕事である。しかし感じる主体にとっては、そのような問題は存在しない。光の感覚は最初から特定の空間感覚に結びついているからだ。我々の視覚や触覚の感覚は、さまざまな空間感覚に結びついている。つまり、それらは互いに隣り合い、外に並んでおり、一つの空間的場の中にあり、我々の身体はその場の一部を占めているにすぎない。テーブルも木も家も、当然のこととして私の身体の外にある。投射の問題は、そもそも存在せず、意識的にも無意識的にも解かれることはない。

ある物理学者（マリオット）が、網膜の特定の箇所が盲目であることを発見する。物理学者は、空間上のすべての点に像の点を、すべての像の点に感覚を対応させる習慣がある。そこで問いが生まれる。「盲点に対応する空間の場所に、我々は何を見るのか？　その欠落はどのように埋められるのか？」。しかし、不当な物理学的な問いの形式を心理学的研究から取り除けば、ここにはそもそも問題が存在しないことがわかる。 我々は盲点の位置には何も見ない。像の欠落は埋められるのではなく、そもそも感じられないのだ。生まれつき盲目の箇所で光の感覚が欠けていることに気づけないのは、皮膚の感覚を持たない背中の皮膚が視野に隙間を生じさせないのとまったく同じである。

2.

私は意図的に、単純で身近な例を選んだ。一つの領域で妥当する見方や思考方法を、まったく別の領域に無用心に持ち込むことで、どれほど不必要な混乱が生じうるかを示すためである。

ある著名なドイツの民族学者の著書に、次の文章を読んだ。「この部族は人肉食によって深く堕落した」。その隣に、同じ主題を扱うイギリスの研究者の本が置いてあった。後者は単に「なぜある南洋の島民は人食いなのか」と問い、調査の過程で我々の祖先もまた人食いであったことを見出し、インド人のこの問題に関する考え方の理解にも到達する。

この態度は、私の5歳の息子の口からもかつて閃いたことがある。ある肉を食べている最中に突然立ち止まり、驚いた顔で言った。「僕たちは動物にとっての人食いだ！」——「人間を食べてはいけない」はまことに立派な原則である。しかし、民族学者の問いにおいては、この原則が**探究の崇高な穏やかな輝き——偏見のなさ——**を台なしにしてしまう。

もう一歩進めば、我々はこうも言うだろう。「人間は猿から生まれてはならない」「地球は回転すべきではない」「物質は空間を連続的に満たすべきではない」「エネルギーは一定でなければならない」等々。

我々の態度は、先に述べたようなやり方と程度においてのみ異なり、種類において異ならないと私は信じる——物理学の見解を、その使用可能性を事前に検証することなく、絶対的妥当性の主張をもって心理学の領域に持ち込むとき。そのような場合、我々はドグマに屈しているのだ。もっとも、スコラ学的な祖先のように外から押しつけられたドグマではなく、自分で作ったドグマに。そして、どんな研究成果であれ、長い習慣によってドグマになりうるではないか。たびたび現れる知的状況に対して獲得した手際のよさこそが、新しい状況において切実に必要とされる新鮮さと偏見のなさを奪うのである。

3.

以上の一般的な注意ののち、物理的なものと心理的なものの二元論に対する私の立場について、必要な説明を述べることができる。この二元論は、私の考えでは、人為的に、かつ不必要に作り出されたものである。

純粋に物理学的な過程を研究する際、我々はふつう非常に抽象的な概念を用いるので、その概念の基盤にある感覚（要素）のことをほんのちらりとしか、あるいはまったく考えない。例えば、「1アンペアの電流が1分間に0℃・760mmで10½ ccの爆鳴ガスを生成する」と確認するとき、こうして定義された対象に、自分の感覚とはまったく無関係な現実性を帰属させたくなる。しかし、この定義に到達するためには、感覚によってしか確認できない電流を、特定の半径の円形導線に流し、地磁気の強度が与えられたとき磁針が子午線から特定の角度だけ逸れるようにしなければならない。磁気の強度の決定も、爆鳴ガスの量の測定も、同様に手間がかかる。定義全体が、ほとんど見渡しがたいほどの感覚の連鎖に基づいているのだ——とりわけ測定に先立つ装置の較正まで考慮に入れれば。

ところが、自分の操作の心理学を研究していない物理学者には、よく知られた言い回しを逆にして言えば、「木ばかり見て森を見ない」ということが容易に起こる。つまり、自分の概念の基盤にある感覚を見落とすのである。

私が主張するのは、物理学的概念とは感覚的要素の特定の種類の連関を意味するものにほかならない、ということである。これらの要素——それ以上の分解にまだ成功していないという意味での要素——こそが、物理的世界（そして心理的世界）のもっとも単純な構成材料なのである。

4.

生理学的研究がまったく物理学的な性格を持ちうることは確かである。ある物理学的過程が感覚神経を通って中枢器官に至り、そこからさまざまな経路で筋肉に達し、その収縮が環境に新たな物理的変化をもたらす過程を追跡することができる。その際、観察されている人間や動物の感覚について考える必要はまったくない。私が研究しているのは、純粋に物理学的な対象である。もっとも、ここには個々の細部の理解にはまだ多くが欠けており、「すべては分子の運動に帰着する」という保証は、自分の無知について私を慰めも欺きもしない。

しかし、科学的な心理学が発達するはるか以前から、人間は気づいていた。動物の物理的条件下での行動は、自分のものに似た感覚や記憶を動物に帰属させれば、はるかによく予見できる、すなわち理解できるようになる、と。私が観察するもの、つまり自分の感覚を、自分の感覚の領域には見出されない動物の感覚によって、思考の中で補完しなければならないのである。

この対立は、無色の抽象的概念を用いて神経過程を追跡し、そこに例えば「緑」という感覚を思考で付け加えねばならない研究者にとって、非常に激しく見える。「緑」はまったく新しい、異質なものとして現れ、「この不思議なものが、どうして化学過程や電流などから生じうるのか」と問わずにいられなくなる。

しかし、心理学的分析は、この驚きが正当でないことを教えてくれる。 物理学者は常に感覚を用いて操作しているからだ。同じ分析はまた、感覚の複合体を、現在は観察されていない要素によって、あるいはそもそも観察できない要素によって、類推に基づいて思考の中で補完することが、物理学者の日常的な営みであることも示す。例えば、物理学者が月を手で触れうる重い慣性質量として表象するときがそうである。

先に述べた状況の完全な異質さは幻想にすぎない。この幻想は、別の考察によっても消える。それは自分自身の感覚的領域に限定された考察である。

目の前に植物の葉がある。葉の**緑（A）は、ある光学的空間感覚（B）、ある触覚（C）、そして太陽またはランプの可視性（D）と結びついている。ナトリウム炎の黄（E）が太陽に代わると、葉の緑は茶色（F）に変わる。アルコールでクロロフィルを除去すると——この操作もまた感覚的要素で記述可能だが——緑（A）は白（G）**に変わる。これらの観察はすべて物理学的なものである。

しかし、緑（A）は私の網膜の過程とも結びついている。この過程を、上述の場合とまったく同じ仕方で自分の目で研究することを、原理的に妨げるものは何もない。自分の目での研究に困難があれば、他人の目で行い、類推によって欠けた部分を埋めることができる——他の物理学的研究とまったく同じように。

ここで、A は B C D E … への依存においては物理学的要素であり、X Y Z …（網膜過程）への依存においては感覚であり、心理学的要素とも把握しうる。 しかし、緑（A）そのものの本性は、我々が注意を一方の依存関係に向けるか、他方の依存関係に向けるかによって、いささかも変わらない。

したがって、私は心理的なものと物理的なものの対立を見ない。これらの要素に関して、ただ単純な同一性を見るのである。私の感覚的意識の領域において、あらゆる対象は同時に物理的であり心理的である。

5.

この知的状況に暗さを見出す人がいるとすれば、それは私の考えでは、物理学的な先入見が心理学の領域に持ち込まれたことに起因するにすぎない。物理学者は言う。「私が至るところに見出すのは物体と物体の運動だけであり、感覚ではない。したがって感覚は、私が扱う物理的対象とは根本的に異なるものでなければならない。」心理学者は、この主張の後半を受け入れる。彼にとっては、確かに、まず感覚が与えられている。しかし感覚に対応するのは神秘的な物理的な何かであり、先入見によれば、それは感覚とはまったく異質でなければならないとされる。

では現実には、その神秘的なものとは何か？　物理（Physis）なのか、精神（Psyche）なのか、それとも両方なのか？　ほとんどそのように見える。というのは、あるときは一方が、あるときは他方が、不可解な闇に包まれて到達不能に思えるからだ。あるいは、我々はここで悪霊に円を描いて引き回されているのだろうか？

私は最後のものだと思う。私にとって要素 A B C … は直接的に、疑いなく与えられている。 そしてそれらが、結局のところ要素の存在に基づいている考察によって、あとから蒸発させられることはありえないのである。

感覚的な物理的＝心理的領域の専門的研究は、この一般的な方向づけによって不要になるわけではなく、A B C … の独自の連関を解明するという課題を持つ。これは記号的に表現すれば、専門的研究に対して F(A, B, C …) = 0 という形の方程式を見出すことを目標として設定する、ということである。

第Ⅲ章　アヴェナリウスおよび他の研究者との関係
1.

ここで展開されている見解と、さまざまな哲学者や哲学的に思考する自然科学者の見解との接点については、以前から指摘されてきた。すべてを挙げるならば、おそらくスピノザから始めなければならないだろう。私の出発点がヒュームのそれと本質的に異ならないことは明らかであろう。コントからは、私にとって心理学的事実が物理学的事実と少なくとも同等に重要な認識源泉であると思われる点で、離れなければならない。内在哲学の代表者たちにも私はかなり近い。とりわけシュッペについて——その著作を1902年に知った——そう言える。とくに彼の思想の凝縮された、特別な辞書なしに読める『認識論と論理学綱要』は、私に非常に好感を与えた。この本の中に、おそらく少しの修正を加えれば喜んで同意できないものを、私はほとんど見出さなかった。「自我」の把握は確かに相違点をなすが、合意に達しうるものだろう。

リヒャルト・アヴェナリウスとの関係において、類縁性は、発達過程も研究領域も異なる二人の個人の完全な相互独立のもとで期待しうる限りのものと同じくらい近い。この一致は、表現形式の大きな違いによっていくぶん覆い隠されている。アヴェナリウスは、非常に詳細であると同時に一般的に保たれた図式的叙述を行い、その理解は馴染みのない特異な術語によってさらに困難にされている。そのような叙述を行う動機も資格も、趣味も才能も、私にはなかった。私はあくまで自然科学者であって、哲学者ではない。 私はただ、感覚生理学においても心理学においても物理学においても通行可能な道が見え、形而上学的な霧がかからないような、確実で明晰な哲学的立場を獲得しようとしただけである。それができれば、すべてが得られたと考えた。

私の叙述は、それもまた若い時代に始まった長年の思索に基づいてはいるが、その簡潔さゆえに一種の着想（アペルシュ）の形をとっている。誰かがそう受け取ったとしても、私は少しも気分を害さない。人工的な術語への嫌悪において、私はアヴェナリウスとは正反対の極端に陥ったかもしれないことは認める。彼がしばしばまったく理解されなかったか、少なくとも遅れて理解されたのに対して、私の言葉はしばしば誤解された。

ある巧みな批評家は、私が到達すべきではなかった（!）結果に到達していると認め——つまり研究の手間は省ける、なぜなら到達すべき結果をすでに知っているのだから——さらに私はまったく普通の言葉しか使わないので捕まえにくく、私の属する「体系」が見えないと非難する。つまりまず体系を選ばなければならないのであり、その中でなら思考し発言してもよいということらしい。こうして人々は、私の言葉に通俗的な見解を気楽に読み込み、私を観念論者、バークリー主義者、さらには唯物論者などにしてしまったが、私には身に覚えがない。

二つの極端な叙述様式にはそれぞれ長所と短所がある。しかし、表現の違いはアヴェナリウスと私の相互理解にも不利な影響を及ぼした。私は見解の類縁性をかなり早くから認識し、1883年の『力学』と1886年の本書初版でその確信を表明した。ただし、その際にはアヴェナリウスの1876年の小さな著作にしか言及できなかった。傾向の同質性が私にとって十分に明らかになったのは、1888年、1891年、1894年のアヴェナリウスの出版物——『純粋経験批判』、『人間的世界概念』、そして『哲学季刊誌』の心理学的論文——によってであった。しかし最初の著作では、いくぶん肥大した術語が、同意の喜びを十分に味わうことを妨げた。多くの民族の言語に加えて一個人の言語をも学ぶことを、年配の人間に要求するのは過大というものである。したがって、アヴェナリウスの仕事を活用する作業は、若い世代に委ねられた。ここでH・コルネリウス、C・ハウプトマン、J・ペツォルトの著作を指摘できることを喜ぶ。彼らはアヴェナリウスの業績の核心を明らかにし、さらに発展させようとしている。

アヴェナリウスもまた類縁性を認め、1888年から1895年の著作でそれに言及している。もっとも、より深い一致の確信は彼においても徐々に発達したようであり、第三者への過去の発言からそう推測せざるをえない。私はアヴェナリウスと個人的に会ったことはない。その記憶を弱めようとする露骨な企てにもかかわらず、彼の仕事への認知は喜ばしい上昇を見せている。

2.

とりわけ私が重視する一致の点を述べたい。

思考の経済——事実の経済的な表現——を科学の本質的課題として最初に指摘したのは、1871年と1872年のことであり、1882年と1883年にさらに展開した。別の箇所で示したように、この見方はキルヒホッフの「完全かつもっとも単純な記述」（1874年）という考えを内包し先取りするものであるが、まったく新しいものではなく、アダム・スミスまで、そしてP・フォルクマンの見るところでは萌芽的にはニュートンまで遡りうる。同じ見方を我々は、叙述にいくぶんの隠蔽的な傾向はあるものの、アヴェナリウスにおいても非常に発達した形で見出す（1876年）。

この見方は、ダーウィン理論の示唆に従い、科学を含む心的生活全体を生物学的現象として把握し、生存競争・発達・淘汰というダーウィン的表象をそこに適用するならば、たちまち広い基盤を得、新しい側面から照らされる。この見方は、一切の心的なものが物理的に基盤づけられ、規定されているという想定と不可分である。『純粋経験批判』においてアヴェナリウスは、すべての理論的・実践的態度を中枢神経系の変化によって規定されたものとして具体的に叙述しようと試みる。その際、きわめて一般的な前提——中枢器官は全体としても部分においても自己を保存しようとする傾向を持ち、その平衡状態を維持しようとする傾向を持つ——だけを出発点にしている。これはヘーリングが生きた物質のふるまいについて展開した表象とよく一致する。

しかし、私がもっとも高く評価するのは、物理的なものと心理的なものの関係の把握における一致である。これが私にとっての核心である。この点でのアヴェナリウスとの符合を私が確信したのは、実は彼の心理学的論文によってであった。念のため、アヴェナリウスの立場に数年来の交流を通じて精通していたはずのルードルフ・ヴラッサーク博士に質問を向けた。ここに彼の回答を記す。

「『物理的なもの』と『心理的なもの』の関係の把握は、アヴェナリウスとマッハにおいて同じである。両者とも、物理的なものと心理的なものの区別は、一方が物理学の対象であり他方が心理学の対象であるような依存関係の相違にのみ存する、という結論に達している。」

「環境構成要素 A の、別の環境構成要素 B への依存を調べれば物理学を行い、A が生きた存在の感覚器官または中枢神経系の変化によってどのように変わるかを調べれば心理学を行う。アヴェナリウスはこれに基づき、『物理的』『心理的』という用語を排除し、物理学的依存性と心理学的依存性だけを語ることを提案した。」

「マッハにおいても同じ見方は現れているが、心理的なものの旧来の把握の不十分さ、したがって心理学の課題そのものが論証されていない点が（ヴラッサークの見るところでは）不足している。」

「この課題を解決するのが**摂入（Introjektion）**の発見——すなわちその根底にある形式論理的誤りの暴露——である。アヴェナリウスによれば、すべての哲学の出発点には素朴実在論、『自然的世界概念』がある。この中では、『自我』と『環境』（『物体世界』）のある程度の区分は可能だが、それは『身体』と『魂』の二元論には至らない。」

「この本来統一的な世界の真の分裂は、同胞の発言の解釈に際して生じる。木が私にとってだけでなく、同胞にも同じ仕方で存在すると言う限り、私と同胞の間の形式論理的に許容される類推を超えてはいない。しかし、木が同胞の中に『感覚』『表象』として、『模像』として存在すると言い、木を同胞の中に**取り込む（introjizieren）**とき——そのとき私は、自分自身の経験には決して見出されないものを同胞に想定している。環境構成要素は常に、私の身体との特定の空間的関係においてのみ与えられ、私の『意識』やそれに類するものの中に見出されることはないからだ。」

「摂入は経験の超越であるから、それを経験の事実と一致させようとするあらゆる試みは、擬似問題の尽きることのない源泉とならざるをえない。我々の『感覚』『表象』『意識内容』と、それらが模像や記号であるとされる『物質的事物』との関係を問う問題は、すべて擬似問題となる。投射の問題、空間感覚の外部への投射の問題等々も同様である。」

「他方、摂入の排除は、生理学的なもの以外の心理学は不当であることを意味する。『意識内容』——神経系の変化の傍らで進行する『心的過程』——が、私が同胞に、そしてついには自分自身にも取り込んだ環境構成要素にほかならないことが認識されれば、神経系の中には生理学的過程以外のものを求めることはできない。特別な心的因果性は消滅し、心的な力のエネルギー保存則との両立可能性に関するあらゆる問いも消滅する。」

3.

アヴェナリウスと私の叙述に残る違いは、容易に理解しうる理由に帰着する。

第一に、私は到達された立場に先立つ世界観の諸段階の完全な叙述を意図していない。第二に、アヴェナリウスの叙述は実在論的な段階から出発しているのに対し、私の叙述は観念論的な段階から出発している——実際、私は若い時代にこの段階を経験した。私は、いわば「排出（Extrajektion）の除去」について語ることもできたであろう。第三に、新しい立場に到達する前に、同胞の発言と摂入に、アヴェナリウスが与えるほどの重大な役割を演じさせる必要はなく、したがってこの摂入を改めて排除する必要もない。孤独な思索者もまた新しい立場に到達しうるのであり、その際にはもちろん、ヴラッサークが注記するように、二元論的な衝動を克服しなければならないだろう。しかし、この立場が一度到達され、要素の依存関係の相違が本質的なものとして認識されれば、実在論的な出発段階も観念論的な出発段階も、数学者や物理学者にとっての基本変数の交換ほどの意味しか持たない。

アヴェナリウスの見解も、したがって私の見解も、ほとんど自明なことを述べているにすぎないように思われる。少なくとも、タイラーの表現を借りれば「野蛮な哲学の遺物」の圧力から解放された者にとっては自明なことである。科学がその建造物を確実に基礎づけることができたのは、常にこのような自明なことの上にであった。

さまざまな哲学的思索者の道の接近において、とりわけ一般哲学的考察と実証的専門科学的考察の密接な合流において、私は諸科学の相互接近のための好ましい予兆を見ることができると信じる。

第Ⅳ章　感覚の研究のための主要な観点
1.

ここで、先に得られた立場から、我々の特別な目的に向けた方向づけの展望を試みよう。

探究する知性が、適応によって二つの事物 A と B を思考の中で結びつける習慣を身につけると、多少異なる状況のもとでも、この習慣をできるだけ維持しようとする。A が現れるところでは、どこでも B が付け加えて考えられる。ここに表れている原理——経済（節約）への努力に根を持ち、偉大な研究者のもとで特に明瞭に現れるこの原理を、連続性（持続性）の原理と呼ぶことができる。

しかし、A と B の結びつきにおいて実際に観察される変異は、気づかれるほど大きなものであれば、上の習慣に対する擾乱として作用する——習慣がその擾乱をもはや感じないほどに十分修正されるまでは。

例えば、空気とガラスの境界面に入射する光が屈折されるのを見ることに慣れたとしよう。しかし屈折の大きさは場合ごとに目に見えて変わり、少数の場合から得た習慣は、新たに現れる場合にそのまま妨げなく当てはめることはできない。個々の入射角に対応する個々の屈折角を割り当てることができるようになってはじめて——つまり、いわゆる屈折の法則を見つけ出し、それに含まれる円錐（関数関係）が馴染みのものになってはじめて——満足が得られる。

こうして、連続性の原理に対して、もう一つの原理が修正を加えるかたちで現れる。これを十分な確定性（十分な分化）の原理と呼ぼう。

両方の原理の共同作用は、先に触れた例をさらに展開することでよく説明できる。光の色が変化するときに生じる事実に対応するためには、屈折の法則という考えは維持しつつも、個々の色ごとに特別な屈折率を割り当てなければならない。やがて、温度ごとにも特別な屈折率を割り当てなければならないことに気づく、等々。

このプロセスは最終的に次のような到達点で一時的な安心と満足をもたらす。すなわち、二つの事物 A と B が、A のどの変化にも対応する B の変化が伴い、A のどの構成要素にも B の対応する構成要素が対応するように、結びつけて考えられるようになった時点である。A と B の両方がそれぞれ構成要素の複合体として現れることもある。例えば、A がある混合物の一つの試料であり、B がスペクトルであるとき、スペクトルの各構成部分には、分光器の前で気化された試料の各構成部分が、他とは独立に対応する。この関係が完全に馴染みのものになってはじめて、十分な確定性の原理に応えることができる。

2.

ここで、ある色覚 B を、発光する試料 A への依存においてではなく、網膜過程の要素 K への依存において観察すると考えてみよう。これによって変わるのは方向づけの種類ではなく、方向づけの方向だけであり、先に述べたことはすべてそのまま有効であり、従うべき原則も同じままである。このことは、当然ながらすべての感覚について成り立つ。

感覚は、それ自体として、直接的に、心理学的に分析することができる（ヨハネス・ミュラーが行ったように）。あるいは、感覚に対応する物理的（生理的）過程を物理学の方法で研究することもできる（近代の生理学派がおもに行っているように）。あるいは最後に——これが最も遠くまで導くだろう、なぜなら観察があらゆる点に手がかりを持ち、一方の研究が他方を支えるから——心理学的に観察されるものと、それに対応する物理的（生理的）過程との関連を追究することもできる。我々はこの最後の目標を、到達可能と思われるところではどこでも目指す。

この目標を念頭に置くならば、連続性の原理と十分な確定性の原理に応えるには、次のことが必要になる。すなわち、同じ B（ある感覚）にはいつでもどこでも同じ N（同じ神経過程）だけを帰属させ、B の観察される変化のどれに対しても、N の対応する変化を見つけ出すことである。B を心理学的に互いに独立な複数の構成部分に分解できるなら、N の中にも同じ数の対応する構成部分を見つけ出すことに安心を見出すことができる。一言でいえば、B の心理学的に観察可能なすべての個々の要素に対して、対応する N の物理学的な個々の要素を探し出さなければならない。

こうして、研究のための指導原理を立てることができる。これを心的なもの（心理学的なもの）と物理的なもの（物理学的なもの）の完全な平行性の原理と呼ぶことにしよう。我々の基本的な見方——二つの領域（心的なものと物理的なもの）のあいだにそもそも溝を認めないという見方——からすれば、この原理はほとんど自明である。しかし、この基本的な見方を借りなくても、発見的原理として独立に立てることもできる。私が数年前にそうしたように。

3.

やや抽象的に述べたこの原理を具体的に説明するために、いくつかの例を挙げよう。

空間を感じるところではどこでも——視覚によってであれ、触覚によってであれ、その他の方法によってであれ——あらゆる場合に同種の神経過程が存在すると想定しなければならない。すべての時間感覚に対しても、同じ神経過程を前提とする。

異なる色を持つ同一の形を見るとき、異なる色覚のほかに、特別な同一の空間感覚と、それに対応する同一の神経過程を探す。二つの形が類似しているなら（部分的に同じ空間感覚を与えるなら）、対応する神経過程にも部分的に同じ構成要素が含まれる。

二つの異なる旋律が同じリズムを持つなら、異なる音の感覚のほかに、両方の場合に同一の時間感覚と、同一の対応する過程が存在する。二つの旋律が異なる調で同一であるなら、音高は異なるにもかかわらず、音の感覚とその物理的条件には同一の構成要素がある。

色覚の一見無限に思える多様性が心理学的分析（自己観察）によって六つの要素（基本感覚）に還元できるなら、対応する神経過程の系にも同じ単純化を期待してよい。空間感覚の系が三重の多様性を示すなら、対応する神経過程の系もまた三重の多様性として現れるだろう。

4.

この原理は、多かれ少なかれ意識的に、多かれ少なかれ一貫して、これまでも常に実行されてきた。

例えば、ヘルムホルツが一つひとつの音の感覚に対して特定の神経線維（対応する過程とともに）を想定し、音色を音の感覚に分解し、音色の親近性を共通の音の感覚（と神経過程）の含有量に帰着させるとき、そこには述べた原理の実践がある。ただし、その適用は完全に一貫したものではない——後に示すように。

ブリュースターは、不十分ではあっても心理学的な色覚分析と不完全な物理学的実験に導かれて、三つの感覚——赤・黄・青——に対応して物理学的にも三種類の光しか存在しないと考え、したがって連続的に段階づけられた屈折率を持つ無限に多くの光の種類を認めるニュートンの仮定は誤りだという見解に至った。しかし、もしブリュースターが、色覚は物理的な光がなくてもまったく生じうるということに気づいていたなら、自分の結論を神経過程に限定し、ニュートンの物理学的主張——同様に十分な根拠を持つ——には手をつけなかったであろう。

トマス・ヤングはこの誤りを正した。彼は、連続的に段階づけられた屈折率（と波長）を持つ無限に多くの物理的な光の種類が、少数の色覚と神経過程と両立しうること、つまりプリズム中の偏差の連続体（空間感覚の連続体）に離散的な数の色覚が対応することを認識した。

しかしヤングもまた、この原理を完全な自覚をもって、また厳密な一貫性をもって適用したわけではなかった。心理学的分析にあたって物理学的先入見に惑わされることもあった。ヤングは最初、赤・黄・青を基本感覚として採用したが、後にウォラストンの物理学的な誤りに導かれて、赤・緑・紫に置き換えた。色覚の理論をどの方向に修正すべきかは、ヘーリングの研究によって高い完成度に達しており、私は以前に別の場所で示唆したことがある。

以上の例は、述べた研究原理の意味を説明し、またこの原理がまったく新しいものではないことを示すのに十分であろう。私がこの命題を数年前に自分自身に定式化したとき、それは本能的に長く感じていたことを、自分自身に完全に明確にするという意図以上のものではなかった。

5.

我々は物理的なものと心理的なものの間にそもそも溝を認めないのであるから、当然のこととして、感覚器官の研究においては、一般的な物理学的経験も特殊な生物学的経験も、ともに役立てることができる。

感覚器官を物理学的な装置と並べて考えると理解しがたいことも、発展（進化）の学説に照らし、特別な記憶を持ち、特別な習慣や癖を持つ生きた有機体——その長く波瀾に満ちた種の歴史にその起源を負う有機体——と関わっているのだと考えれば、透明になることが多い。

注21） 進化の学説を感覚の生理学や心理学一般に応用するという考えは、ダーウィン以前にすでにスペンサー（1855年）に見られる。この考えはダーウィンの著書『感情の表現について』によって力強い促進を受けた。後にシュルツェは「遺伝される表象」があるかどうかという問題をダーウィン的な意味で論じた。私もまた（ウィーン学士院紀要、1866年10月）、進化の学説を感覚器官の理論に適用することを支持した。心理学的・生理学的な進化論の応用としてもっとも美しく啓発的な論述のひとつは、ヘーリングの学術講演「組織された物質の一般的機能としての記憶について」（1870年）に含まれている。記憶と遺伝は、実際にほとんど一つの概念に融合する。なぜなら、親の体の一部であった有機体が移出し、新しい個体の基盤となるからである。この考えによって遺伝はほぼ、例えばアメリカ人が英語を話し、その国家制度が多くの点でイギリスのそれに似ていることと同程度に理解可能になる。もっとも、有機体が記憶を持つのに対して無機的な物質にはそれが欠けているように見えるという問題は、これによっては触れられず、依然として残る。

この機会にさらにいくつかの観察を述べたい。大きな喜びとともに思い出す観察である。1873年の秋の休暇に、幼い息子が巣から落ちた生後数日のスズメを連れてきて、育てたいと望んだ。しかし事は単純ではなかった。雛は飲み込もうとせず、無理に餌を与える際の避けがたい乱暴な扱いで、確実にまもなく死んでしまったであろう。そこで私は次のように考えた。「新生児は——ダーウィンの理論が正しかろうと正しくなかろうと——もし吸乳のための予め形成された器官と遺伝された本能——適切な刺激によってまったく自動的・機械的に活動する——がなければ、確実に死んでしまうだろう。鳥にも形を変えた同様のものがあるはずだ」。適切な刺激を見つけようとして、小さな虫を尖った棒に刺し、鳥の頭の周りで素早く動かした。すると直ちに雛はくちばしを開け、翼をばたつかせ、貪欲に差し出された餌を飲み込んだ。こうして私は、本能と自動的運動を誘発するための正しい刺激を見つけたのだった。雛はみるみる強く、貪欲になった。やがて餌に飛びつくようになり、あるとき棒からテーブルの上に偶然落ちた虫を自分でつかまえ、それ以降は難なく自力で食べるようになった。知性と記憶が発達するにつれて、必要な誘発刺激はどんどん少なくて済むようになった。

目的論的な考察もまた、研究の補助手段として避ける必要はない。もちろん事実そのものが、問題の多い未知の「世界目的」に遡及することで理解しやすくなるわけではない。しかし、ある機能が有機体の存続にとってどんな価値を持つか、それが有機体の存続に何を貢献するか、という問いかけは、その機能自体の理解を促進しうる。

ただし、ある機能が種の存続に必要であることを認識したからといって、それで機能を「機械的に説明した」と信じてはならない——一部のダーウィン主義者が言うように。ダーウィン自身はこの近視眼的な見方からは完全に自由である。有機体がどのような物理的手段によって発達したか、機能がどのように、またなぜ適応するのかは、依然として物理学的・心理学的な問題である。

種の保存は、実際上の価値ある手がかりにすぎず、決して究極のものでも最高のものでもない。種は実際に絶滅してきたし、新しい種も確かに生まれてきた。快を求め苦を避ける意志は、種の保存よりもさらに遠くまで及ぶものでなければならない。この意志は、種を保存する——それが割に合う限りで。種を変える——それが割に合う限りで。種を滅ぼす——その存続がもはや割に合わなくなったとき。

もしこの意志がもっぱら種の保存にだけ向けられていたなら、すべての個体と自分自身を欺きながら、目的もなく誤った円環の中をぐるぐる回っていたことだろう。これは、あの悪名高い物理学的「永久機関」の、生物学的な対応物であろう。

（第2章 終わり）

第Ⅴ章　物理学と生物学。因果性と目的論
1.

さまざまな知識領域は、互いに影響を及ぼさないまま長い間並行して発展することが多い。しかし、一方の教えによって他方が思いがけぬ解明を受けることに気づくと、両者はふたたび密接な接触に入りうる。そのとき、前者を後者に完全に吸収させようとする自然な傾向さえ現れる。しかし、希望にあふれた過大評価の時期のあとには、やがて失望と両領域の再分離が続き、各領域はふたたび独自の問いを立て、固有の方法を用いるようになる。ただし、そうした一時的接触は持続的な痕跡を残す。実証的な知識の収穫だけでなく、概念の変容が起こり、それによって概念はより透明になり、その成立した領域を超えて適用可能になる。

現在、我々はまさにそうした多面的な関係の時期にいる。物理学者の中には物理学的概念を心理学的・論理学的・数学的に浄化しようとする者がいる一方で、哲学者が放棄しつつある旧来の形而上学的概念を擁護する物理学者もいる。哲学者・心理学者・生物学者・化学者はエネルギー概念やその他の物理学的概念を、物理学者が自分の領域では到底試みないほど自由な仕方で、もっとも広い領域に適用している。ほとんど各分野の通常の役割が入れ替わっていると言えるほどである。

我々がここで扱うのは、とりわけ物理学と生物学の関係（もっとも広い意味において）である。

2.

すでにアリストテレスは作用因と**目的因（終局因）**を区別した。前者の領域の現象はもっぱら作用因によって、後者の領域の現象は目的によっても規定される、と前提されてきた。

例えば、ある物体の加速度は作用因によってのみ——すなわち現在の状況（重力・磁気・電気を帯びた他の物体の存在）によってのみ——規定される。しかし、ある動物や植物の成長発達をその固有の形態において、あるいは動物の本能的行動を、作用因だけからは導き出せない。けれども、それらの特殊な生活条件のもとでの自己保存の目的からは、少なくとも部分的に理解可能になる。

目的概念の適用に対してどれほどの理論的懸念を抱くにせよ、「因果的」考察がまだきわめて不完全な解明しか提供しない領域で、目的論的考察が提供する導きの糸を未利用のまま放置するのは、確かに間違いである。

夜蛾の幼虫がなぜ、外側に開くブラシ状の弁を持つ繭を紡がざるをえないのか、私はその原因を知らない。しかし、まさにそのような繭が自己保存の目的に適うことは理解できる。ハーヴェイは心臓弁と静脈弁の位置の問題的な目的を明らかにしようとすることで、血液循環の発見に到達した。ケプラーの目の研究においても、調節機能の存在は目の目的から疑いえなかったが、調節を引き起こす過程が実際に解明されたのは二世紀半も後のことだった。

3.

ある事実領域が目的論的に完全に見通されたとしても、「因果的」理解への欲求は依然として残る。しかし、一方の領域はまったく因果的にのみ、他方はまったく目的論的にのみ把握可能であるという信念は正当ではない。

物理学的な事実の複合体は単純であるか、少なくとも実験によって任意に単純にすることができる。そのため直接の連関が目に見えるようになる。この領域との十分な親しみによって、連関の種類に関する概念を獲得し、それがあらゆる事実に当てはまるであろうと期待するようになると——これが「因果的」理解である。しかしそこには自然の必然性はなく、我々の論理的期待があるだけだ。

生物学的な事実の複合体はきわめて複雑で、直接の連関が見渡せない。そこで我々は、直接にはつながっていないが顕著に関連する事実の部分を「結びついている」と指摘するにとどまる。比較的単純な因果関係に訓練された知性は、中間項の欠如に困難を覚え、それを探し出して補おうとするか、あるいはまったく新しい種類の連関という仮説に走る。後者は、我々の知識を不完全かつ暫定的なものと見なし、物理学の領域にもまったく類似の場合があることを考えれば、不必要である。

思考のひとつの転換によって、あらゆる目的論的問いを、目的概念をまったく含まない形に書き換えることは常に可能である。「目は異なる距離で鮮明に見る。ゆえにその屈折装置は可変でなければならない。この変化は何に存するか？」、「心臓弁と静脈弁はすべて同じ方向に開く。一方向の血液運動だけが可能である。それは存在するか？」——こうした形式は、近代の進化論が身につけた冷静な思考法にほかならない。

したがって、目的論的研究と因果的研究の間に、根本的な区別を設ける必然性はまだ見当たらない。前者は単に暫定的なものにすぎない。

4.

これをさらに根拠づけるために、因果性の概念そのものを再検討しよう。

旧来の因果性の表象はいささかぎこちない。「一服の原因」に「一服の結果」が続く、というものだ。これは一種の原始的・薬学的世界観の表れであり、「四元素」の教説にも通じる。しかし自然界の連関は、ある場合に一つの原因と一つの結果を指定できるほど単純であることはめったにない。

そこで私はかなり前から、原因概念を数学的な関数概念で置き換えることを試みてきた。すなわち、現象の相互依存、正確には現象の標識の相互依存。この概念は、調べるべき事実の要求に応じて、任意に拡張も限定もできる。

例えば重力を考えよう。質量 A に質量 B が対峙すると、A の B に向かう運動が続く。これが旧来の定式である。しかしより精密には、質量 A, B, C, D … は互いに加速度を規定し合い、これらの加速度は質量の設定と同時に与えられている。加速度は将来のある時点で到達される速度を示す。こうしてすべての時点における A, B, C, D … の位置が規定される。しかし物理学的な時間の測定はまた空間測定（地球の回転）に基づいている。結局のところ、位置の相互依存に帰着する。

正確かつ明瞭に認識されたすべての依存関係は、相互的な同時関係と見なしうる。これに対して通俗的な原因と結果の概念を見れば——太陽が物体 K を照射して暖めるが、K の温度変化は太陽の温度変化の「原因」とは見なされない——という非対称性が見出される。これは両者の間に介在する媒質の諸要素のためである。関数概念の原因概念に対する優位は、前者が精密さを求め、後者に付きまとう不完全さ・不確定性・一面性を持たない点にある。原因の概念は原始的な暫定的手段にすぎない。

5.

したがって、関数概念をもってすれば、物理学的領域でも生物学的領域でも通用し、すべての要求に応えうるように思われる。二つの領域がまったく異なる外見を示すとしても、我々を怯ませる必要はない。摩擦電気とガルヴァーニ電気のようなごく近い親縁の物理現象群でさえ、外見上は似ても似つかないのだから。

物理学と生物学の両領域はおそらく同じ基本的事実を含んでいる。ただし、ある側面は一方でのみ顕著に現れ、別の側面は他方でのみ顕著に現れる。したがって、物理学が生物学を助けるだけでなく、生物学が物理学を助けることもできる。物理学が生物学でなしえたことの疑いなき成果に対して、逆に生物学が新たな物理学的事実を明るみに出した事例（ガルヴァニズム、プフェッファーの浸透圧細胞など）もまた存在する。

6.

物理学的考察だけに慣れた者が生物学の領域に入り、動物にやがて後の生涯段階で初めて合目的的に使う器官が育つこと、学ぶことができなかったはずの本能的行動を行うこと、将来の敵を逃れるために環境に適応した色をまとうことを聞けば、まったく特別な力の想定に走りたくなるかもしれない。

しかし、生命の諸過程が世代を通じて周期的に反復することを思えば、ある生涯段階を「未来のもの」「遠隔作用するもの」と捉えるのは恣意的であり、それを祖先の過去として、すでに痕跡を残した所与として見ることもできる。そうすれば不可解さは大いに減じる。作用するのは不確かな未来ではなく、無数回繰り返されてきたことの確実な過去なのである。

7.

あらゆる有機体とその部分は物理法則に従う。したがって、有機体を徐々に物理学的に把握し、「因果的」考察だけで事足りるようにしようとする努力は正当である。しかしこれを試みると、有機的なものの独特な特徴——これまで解明されてきた物理現象（「無生物」の自然）には類似物がない特徴——につねに突き当たる。

有機体とは、その性状（化学組成、温度など）を外的影響に対して維持しうる系であり、かなりの安定性を持つ動的平衡を示す。有機体はエネルギーを費やして環境から他のエネルギーを引き寄せ、それによって消耗を補い、あるいは凌駕する。自分の石炭を自分で調達し、自分で火を焚く蒸気機関——これは有機体のなんと不出来な人工的模型であろうか。有機体はこれらの性質をきわめて小さい部分に持ち、そこから自己を再生する。すなわち成長し、繁殖する。

有機的なものの研究から物理学はまだ非常に多くの新しい洞察を汲まなければならないだろう。有機的なものを制御する以前に。

生命過程にとっての最良の物理学的比喩は、火（燃焼）である。 燃焼は環境を燃焼温度に引き上げ、隣接する物体を過程の中に引き込み、同化し、広がり、伝播する。動物の生命もまた、より複雑な状況のもとでの燃焼にほかならないのではないか。

8.

「作用因」と「目的」という概念は、もともとどちらもアニミスティックな表象に由来する。古代の研究者にはこのことがまだはっきりと見える。未開人は自分自身の自発的な（当然ながら自明に思える）運動についてはさほど考えないが、自然界に予期しない目立つ運動を見るや、それを本能的に自分の運動と類比させる。こうして自他の意志の観念が浮上する。

意識的な意志行為においては、原因と目的はなおも一致している。物理学的過程の大きな単純さと計算可能性が、それに関するアニミスティックな把握をしだいに退ける。原因の概念はぎこちない形を経て依存性の概念へ、関数概念へと移行する。しかし有機的生命の現象——アニミスティックな把握に抵抗しにくいもの——については、目的概念、目的意識的な行為の見方がなおも維持される。

アニミズム（人間中心主義）はそれ自体としては認識論的な誤りではない。 あらゆる類比がそうであるとすれば別だが。誤りは、その適用のための前提が欠けているか不十分な場合にのみある。

9.

我々の意志行為を、自分自身に観察される不意の反射運動や、動物の反射運動と比較してみよう。後二者では、全過程を有機体における瞬時の条件によって物理学的に規定されたものと見なしたくなる。意志と呼ばれるものは、運動の条件のうち部分的に意識的で、結果の予見を伴うものの総体にほかならない。

これらの条件を意識に上る限り分析すれば、以前の経験の記憶の痕跡とその結合（連合）以外の何も見出されない。このような痕跡の保存とそれらの結合は、基本的な有機体（微生物）の基本機能であるように思われる。

ヘーリングの広い意味での記憶と連合を基本有機体の基本的性質と見なしうるなら、適応は理解可能になるだろう。有利に働くものは、合成確率に比して頻繁に一緒に出会い、連合されたまま残る。餌の存在・満腹感・嚥下運動は結びついたままになる。個体発生が系統発生を短縮して反復するということは、思考がかつて辿った道を好んで再び辿り、類似の条件のもとで類似の仕方で再び生じるという周知の現象の並行物であろう。

記憶と連合に物理的に対応するものが何であるか、我々は知らない。すべての説明の試みはきわめて強引であり、有機的なものと無機的なものの間にはほとんど類推が存在しないように見える。しかし、感覚生理学においてこそ、心理学的観察と物理学的観察が相互に接触するところまで前進し、我々に新しい事実をもたらしうるかもしれない。 この研究からは二元論ではなく、有機的なものと無機的なものを包括し、両領域に共通する事実を叙述する一つの科学が生まれるであろう。

第Ⅵ章　目の空間感覚
1.

灰色の硬くざらざらした幹を持つ木、風に揺れる無数の枝、滑らかに光る柔らかい葉——これらはまず我々には分かちがたい一つの全体として現れる。同様に、黄色い丸い甘い果実、明るく暖かいさまざまに動く舌を持つ火を、一つのものと見なす。一つの名前が全体を指し示し、一つの言葉が、一本の糸のように、関連するすべての記憶を忘却の深みから一度に引き出す。

木の鏡像、果実の鏡像、火の鏡像は見えるが、手で触れることはできない。目をそむけたり閉じたりすれば、木を触ることはでき、果実を味わうことはでき、火を感じることはできるが、見ることはできない。こうして、一見して統一的に見えたものが部分に分かれる。それらの部分は互いにだけでなく、他の条件にも依存している。見えるものが、触れるもの、味わえるものなどから分離される。

2.

見えるものだけをとっても、最初は一つのものとして現れる。しかし、黄色くて丸い果実のそばに、黄色くて星形の花を見ることができる。第二の果実は最初のものと同じように丸いが、緑や赤かもしれない。二つのものが同じ色で異なる形であることもあれば、異なる色で同じ形であることもある。こうして、視覚は色覚と空間感覚に分かれる。

色覚——ここでは詳しく立ち入らない——は本質的に、生命にとって有利あるいは不利な化学的条件の感覚である。色覚はこれらの条件への適応の中で発達し、変化してきたのだろう。

光は有機的な生命を導く。緑色のクロロフィルと（補色の）赤いヘモグロビンは、植物体の化学過程と動物体の化学的対抗過程において際立った役割を演じている。両方の物質はさまざまに変化した形で、きわめて多彩な色彩をまとって我々の前に現れる。視紅（ロドプシン）の発見、写真や光化学の経験は、視覚過程もまた化学過程として捉えることを可能にする。

分析化学における色の役割、スペクトル分析における色の役割、結晶物理学における色の役割はよく知られている。これは次の考えに導く。すなわち、いわゆる光の振動は、純粋に力学的な振動ではなく、化学的な振動として——光化学的過程において一方向にのみ導かれるような振動的過程（結合と分離の交替）として——捉えるべきではないか、という考えである。この見方は、近年の異常分散に関する研究によって大いに支持されており、電磁的光理論にも合致する。

3.

色によって告げ知らされる化学的生命条件への適応は、味覚や嗅覚によって表される条件への適応よりも、はるかに大きな範囲での**移動運動（ロコモーション）**を必要とする。少なくとも人間に関しては——我々が直接的かつ確かな判断を持つ唯一の存在であり、ここで問題にしている存在だが——実際にそうである。こうして、（力学的な契機としての）空間感覚と（化学的な契機としての）色覚が密接に結びついていることが理解される。

次に、光学的な空間感覚の分析に踏み込もう。

4.

同じ形をした異なる色の形象——例えば同じ形の異なる色の文字——を見ると、色覚の違いにもかかわらず、同じ形を一目で認識する（図2：異なる色の同じ文字 N が二つ並んでいる）。したがって、視覚には同一の感覚構成要素が含まれていなければならない。それこそが（両方の場合に同一の）空間感覚である。

5.

ここで、形の再認を生理学的に条件づけている空間感覚がどのような種類のものかを調べよう。

まず明らかなのは、この再認は幾何学的な考察によってもたらされるのではないということだ。幾何学的考察は感覚の事柄ではなく、悟性の事柄である。むしろ、当該の空間感覚こそが、あらゆる幾何学の出発点と基礎を提供する。

二つの形は幾何学的には合同（congruent）でありながら、生理学的にはまったく異なりうる。 これは次の図（図3：同じ正方形だが異なる傾きで置かれた二つの図形）が示すとおりで、力学的・知的操作なしにはけっして同一と認識されえない。

関連する諸関係に慣れるために、いくつかの簡単な実験をしてみよう。何でもよい任意の染み（図4）を観察する。同じ染みを同じ向きで二つまたは複数並べると（図5）、独特の心地よい印象が生まれ、すべての形が同一であることをたやすく一目で認識する。

しかし、一方の染みを他方に対して十分に回転させると（図6）、知的な手段なしには形の同一性はもはや認識されない。

一方、観察者の正中面（体の左右対称面）に関して対称な染みを並べると（図7）、両者の間に著しい親近性が感じられる。ただし、対称面が正中面から大きくずれると（図8）、この親近性は回転や知的操作によってしか認められなくなる。

一方、ある染みにそれ自体を180度回転させたものを並べると（図9）、いわゆる**中心対称（centrische Symmetrie）**が生じる。

次に、すべての次元を同じ比率で縮小すると、幾何学的に**相似（ähnlich）**な染みが得られる。しかし、幾何学的に合同なものが必ずしも生理学的（光学的）に合同ではなく、幾何学的に対称なものが必ずしも光学的に対称でないのと同様に、幾何学的に相似なものが必ずしも光学的に相似なわけでもない。

幾何学的に相似な染みを同じ向きで並べれば（図10）、光学的にも相似に見える。しかし一方の染みを回転させれば（図11）、この類似性は消える。一方のかわりに正中面に関して対称なものを置けば（図12）、光学的価値を持つ対称的類似性が生じる。一方の図形を180度回転させた場合に生じる中心対称的類似性（図13）もまた、生理学的・光学的な価値を持つ。

6.

幾何学的類似性に対する光学的類似性の本質とは何か。

幾何学的に相似な形では、すべての対応する距離が比例している。しかし、それは悟性の事柄であって感覚の事柄ではない。辺 a, b, c の三角形に辺 2a, 2b, 2c の三角形を対置しても、この単純な関係は直接的にではなく、知的に計測することによってのみ認識される。

類似性が光学的にも際立つためには、さらに正しい向きが加わらなければならない。悟性にとっての単純な関係が必ずしも感覚にとっての類似性を条件づけないことは、辺 a, b, c と辺 a+m, b+m, c+m の二つの三角形を比較すれば明らかである。両者はけっして相似に見えない。同様に、すべての円錐曲線が相互に相似に見えるわけではない——幾何学的には単純な親近関係にあるにもかかわらず。三次曲線の間にはなおさら光学的な類似性は見られない。

7.

二つの形の幾何学的類似性は、すべての対応する距離が比例していること、あるいは、すべての対応する角が等しいことによって決まる。しかし光学的に相似になるのは、相似に位置している場合、つまりすべての対応する方向が平行（あるいは、我々がいいたいのだが、等しい）場合にはじめてである（図14）。

感覚にとっての方向の重要性は、図3を注意深く見るだけでもわかる。方向の等しさこそが、同一の空間感覚を条件づけ、形の生理学的・光学的類似性を特徴づけるものなのである。

観察される直線や曲線要素の方向の生理学的意味は、次の考察でさらに明らかになる。y = f(x) を平面曲線の方程式とする。一目見ただけで、曲線に沿った f(x) の値の推移を読み取ることができる。なぜなら、それは曲線の傾きによって決まるからであり、また dy/dx（一次導関数）の値についても目は定性的な情報を与える。なぜなら、それは曲線の曲率によって特徴づけられるからである。

では、なぜ d²y/dx²、d³y/dx³ 等々の値については同じように直接的に何も言えないのか？　答えは簡単である。人が見ているのはもちろん微分商（それは悟性の事柄だ）ではなく、曲線要素の方向と、ある要素の方向と別の要素の方向との**ずれ（変化）**である。

相似にして相似に位置する形の類似性を直接的に認識でき、さらにその特殊な場合である合同を他の場合から区別できるのだから、我々の空間感覚は、方向の等しさ・不等と寸法の等しさ・不等について情報を与えるのである。

8.

空間感覚が目の運動装置によって媒介されていることは、最初から高い確率を持つ。まだ細部に立ち入ることなく、まず次のことを指摘しておこう。目の装置全体、とりわけ運動装置は、頭の正中面に関して対称的に構成されている。

それに対応して、対称的な視線運動は同一の、あるいは少なくともほとんど同一の空間感覚を引き起こす。子どもは文字の b と d、p と q をしょっちゅう取り違える。大人であっても、特別な感覚的または知的手がかりがなければ、左右の反転に気づくことは容易ではない。

目の運動装置はきわめて完全な対称性を持つ。そのため、対称的な器官から生じる同一の興奮だけでは、左右の区別はほとんど不可能であろう。しかし、人体全体、とりわけ脳には、わずかな非対称性がある。これが例えば、運動機能において一方の手（普通は右手）を優先させることにつながる。このことがさらに右側の運動機能のより良い発達へとつながり、それに伴う感覚の変容をもたらす。書くときの目の空間感覚が右手の運動感覚と結びつけば、書字能力と書字習慣の及ぶ範囲の垂直対称的な形の混同は生じなくなる。この結びつきは非常に強くなりうるので、記憶が慣れた経路でしか作動せず、例えば鏡文字をきわめて困難にしか読めなくなることさえある。

しかし、左右の混同は、純粋に光学的な（例えば装飾的な）関心を引くだけで運動的な関心のない形については、依然として起こりうる。なお、動物もまた、多くの重要な場合に左右の方向感覚によってしか方位を定められないため、左右の違いをいくらか感じているはずである。

上下の眺めには根本的に異なる空間感覚が伴う。これは最も日常的な経験が教えるとおりである。目の運動装置が水平面に関して非対称であること、また重力の方向が身体全体の運動装置にとっても決定的に重要であることを考えれば、これは理解できる。風景とその水面の鏡像の対称性がまったく感じられないことは周知のとおりである。上下を逆にした知人の肖像は、知的手がかりなしには見知らぬ不可解なものに映る。

これまでの対称性と類似性に関する考察は、平面的な形だけでなく立体的な形にも当てはまる。したがって、奥行きの空間感覚についても一言つけ加えておく必要がある。遠くを見ることと近くを見ることは異なる感覚を引き起こす。それらは混同されてはならない。なぜなら、遠い・近いの区別は人間にとっても動物にとってもあまりにも重要だからである。また混同されえないのは、目の運動装置が、前後方向に垂直な面に関して非対称だからである。知人の胸像がその鋳型（ネガ型）で代用できないという経験は、上下の反転についての観察とまったく同様のものである。

9.

等しい寸法と等しい方向が等しい空間感覚を、正中面に関して対称的な方向が類似した空間感覚を引き起こすならば、上述の事実はきわめてよく理解される。

直線はすべての要素において同じ方向を持ち、どこでも同一の空間感覚を引き起こす。そこに直線の美的な優位がある。さらに、正中面内にある直線や正中面に垂直な直線は、視覚装置の両半分に対して対称的な位置にあるため、独特な仕方で際立つ。他のあらゆる直線の位置は「斜め」の位置として、すなわち対称位置からの逸脱として感じられる。

同じ空間的形を同じ向きで繰り返すと、空間感覚の繰り返しが生まれる。顕著な（対応する）点どうしを結ぶすべての線が同じ方向を持ち、同じ感覚を引き起こす。幾何学的に相似なだけの形を同じ向きで並べた場合にも、この関係は維持される。寸法の等しさだけが失われる。向きが乱されれば、この関係全体が、ひいては統一的な（美的な）印象が崩れる。

正中面に関して対称的な形の場合、同一の空間感覚の代わりに、対称的な方向に対応する類似した空間感覚が立つ。形の右半分が視覚装置の右半分に対して持つ関係は、形の左半分が視覚装置の左半分に対して持つ関係と同じである。寸法の等しさを放棄しても、対称的な類似性はなお感じられる。対称面の傾きが変わると、関係全体が崩れる。

中心対称の場合にもすべての対応する結合線は同じ方向を持ち、心地よく感じられる。規則性は対称性に対して独自の生理学的価値を持たないようである。規則性の価値はむしろ、一つの位置に限らず目立つ多重対称性にあると思われる。

10.

以上の考察の正しさは、オーウェン・ジョーンズの著作『装飾の文法』（ロンドン、1865年）をめくると非常に実感される。ほぼすべてのページに、さまざまな種類の対称性が、得られた見解の裏付けとして見出される。

装飾は、純粋な器楽音楽と同じく副次的な目的を追わず、もっぱら形（と色）の快に奉仕するので、本研究のための事実をもっともよく提供してくれる。文字は美の考慮以外の理由によって支配されている。それにもかかわらず、24個のラテン大文字のうち、10個が垂直対称（A, H, I, M, O, T, V, W, X, Y）、5個が水平対称（B, C, D, E, K）、3個が中心対称（N, S, Z）であり、非対称なのはわずか6個（F, G, L, P, Q, R）にすぎない。

11.

ここで改めて強調しておきたいのは、空間形の幾何学的属性と生理学的属性は明確に区別されなければならないということである。生理学的属性は幾何学的属性によって共規定されるが、それだけでは決定されない。逆に、生理学的属性が幾何学的研究への最初の動機を与えた可能性はきわめて高い。

直線が注目されたのは、おそらく二点間の最短距離であるという性質によってではなく、その生理学的な単純さによってである。平面もまた、幾何学的属性のほかに、特別な生理学的・光学的（美的）価値を持っており、それによって目を引く。

直角による平面と空間の分割は、等しい部分が生まれるという利点だけでなく、特別な対称価値をも持つ。合同で相似な幾何学的形がその親近性が生理学的に際立つような向きに配置できるという事情が、これらの種類の幾何学的親近関係が、アフィニティや射影（コリネアション）などのより目立ちにくい関係よりも先に研究されたことに、疑いなく影響を与えた。

感覚的直観と悟性の協働なしには、科学的な幾何学は考えられない。ハンケルはその『数学史』（ライプツィヒ、1874年）の中で、ギリシア幾何学では悟性の契機が、インド幾何学では感覚的契機が著しく優勢であることを見事に示した。インド人は対称性と類似性の原理を、ギリシア人にはまったく馴染みのない一般性で用いている。ハンケルの提案——ギリシア的方法の厳密さとインド的方法の直観性を新しい叙述様式に結合すること——は大いに傾聴に値する。ニュートンやヨハン・ベルヌーイの示唆に従えばよいのであり、彼らは類似性の原理を力学においてさらに一般的な仕方で用いていた。

（第3章 終わり）

第Ⅶ章　空間感覚のさらなる研究
1.

空間感覚が運動過程と結びついていることは、もう長い間異論のないところである。意見が分かれるのは、この結びつきをどのように理解すべきかという点だけである。

2.

二つの異なる色を持つ合同な像が次々と同じ網膜部位に投影されると、同一の形として難なく認識される。つまりまず、異なる空間感覚が異なる網膜部位に結びついていると考えることができる。しかし、空間感覚が不変的に特定の網膜部位に固定されているわけではないことは、自由に意図的に目を動かしてみればわかる。網膜上の像は移動するにもかかわらず、対象はその場所も形も変えない。

例えば、正面の対象 O を注視しているとき、明視の位置 o よりも下に像を結ぶ対象 A は、ある高さにあるように見える。ここで視線を上に向けて B を注視しても、A はもとの高さを保ったままである。もし網膜上の像の位置だけが空間感覚を決めるなら、A はもっと低く見えるはずだ。さらに視線を A まで、あるいはそれ以上に上げても、この関係は変わらない。

つまり、目の随意的な挙上を条件づけている生理的過程は、高さの感覚を全面的にあるいは部分的に代替することができる。この生理的過程は高さの感覚と同質であり、それと代数的に加算可能である。指で眼球を上向きに押すと、対象 A は、oa の弧の縮小に応じて実際に沈んで見える。何らかの無意識・不随意的な過程（例えば眼筋の痙攣）によって眼球が上向きに回転する場合も同様のことが起こる。

数十年来知られている眼科的経験によれば、外直筋の麻痺を持つ患者は、右側にある対象をつかもうとして右方に手を伸ばしすぎる。右方の対象を注視するために健常者より強い意志の衝動を必要とするからであり、「右を見よう」という意志が光学的空間感覚「右」を条件づけているのだと考えられる。

私は以前、この経験を誰でもすぐにできる実験の形に変換した。目をできるだけ左に向け、両眼球の右側にかなり硬いガラス職人用のパテの大きな塊を押し当てる。すると素早く右を見ようとしても、眼球の不完全な球形のため非常に不十分にしか成功せず、対象はその際に大幅に右方に移動して見える。つまり、右を見ようとする意志だけで、特定の網膜部位にある網膜像に、より大きな「右の値」が与えられるのだ。

最初は驚くべき効果だが、すぐに気づくのは、随意的な右方向転換では対象は移動しないこと、そして外力による強制的・不随意的な右方向転換では対象が左に移動すること——この二つの単純な経験を合わせると、まったく同じ結果になるということである。右に向けようとして向けることができない目は、随意的に右を向けてから外力で強制的に押し戻された目と見なすことができる。

3.

眼球運動を行おうとする意志、すなわち神経支配（Innervation）こそが、空間感覚そのものである。 これは、上の考察から自然に導かれる。

皮膚のある箇所にかゆみや刺し傷を感じ、注意が十分に引きつけられると、我々はたちに正しい運動の量をもって手を伸ばす。同様に、網膜上の像が十分に刺激的であれば、正しい運動の量をもって目をそちらに向ける。有機体の仕組みと長い練習のおかげで、特定の網膜部位に像を結ぶ対象の注視にちょうど十分な神経支配を即座に命中させるのである。

すでに目が右方を向いていて、さらに右方または左方にある新しい対象に注意を向けるなら、すでに存在している神経支配に、新しい同種の神経支配が代数的に加算される。擾乱が生じるのは、随意的に測られた神経支配に、異質な不随意的神経支配や外部からの運動力が加わるときだけである。

4.

私が以前、これに関連する問題に取り組んでいたとき、まだ記述されていない（と思われる）ある独特の現象に気づいた。

かなり暗い部屋で二つの光 A と B を観察し、A から下方の B へと素早く視線移動を行う（図16）。すると光 A は、急速に消える尾 AA' を上方に引くように見える。光 B も同様のことをするが、図の複雑化を避けるため描かれていない。

この尾は明らかに残像であり、視線移動の終了の直前または終了時に意識に上る。しかし興味深いのは、その残像が新しい目の位置と神経支配に対応する位置の値ではなく、以前の目の位置と神経支配に対応する位置の値を伴って現れることである。

同様の現象は、ホルツの起電機での実験中にしばしば見られる。下方への視線移動の途中で火花に不意を打たれると、火花は当然ながら電極の上方高くに見える。持続的な残像が得られれば、それもやはり電極のはるか上方に見えることが多い。

これらの現象は、天文学者のいわゆる「個人差（人差）」に対応するものである。ただし、視覚の領域に限定されている。

5.

これまで単純化のため、注視する目だけが動き、頭（や身体）は静止していると想定していた。ここで、光学的対象を特に注視することなく頭を自由に回転させると、対象は静止したままである。同時に、別の観察者は、目が摩擦のない慣性質量のように頭の回転に参加しないことに気づく。

この現象はさらに、垂直軸のまわりに上から見て時計回りに長時間連続回転すると、より顕著になる。ブロイアーが観察したように、開いたまたは閉じた目は、身体の一回転あたり約10回、時計と逆方向にゆっくり回転し、同じ回数だけ時計方向に急速に戻る（図17）。

これは明らかに、身体の回転によって反射的に引き起こされる自動的（無意識的）な眼球運動である。この運動がどのようにして生じるかは研究課題として残るが、我々にとって当面重要なのは、この自動的で無意識的な代償性眼球運動が実際に存在するという事実である。

ゆっくりとした無意識の代償運動（急速な戻りの方は光学的印象を残さない）こそが、頭を回転しても対象が定位置にとどまるように見える原因であり、これは方位の把握にきわめて重要である。

頭と同時に、対象を交互に注視しながら目も同方向に随意的に動かすと、無意識の自動的な代償運動を随意的な神経支配で過補償しなければならない。回転角全体を目だけで遂行した場合と同じ神経支配が必要になる。これによって、体を回転させたとき、光学的空間全体が断片的な視野の集合ではなく連続体として現れ、光学的対象が定位置にとどまる理由が解明される。自分の身体のうち見える部分は、明白な理由から、光学的に動いて見える。こうして、固定された空間の中で動く自分の身体という、実際上きわめて有用な表象に到達する。

通りや建物の中での複数の回転や方向転換の際にも、馬車に乗っているときや船室に閉じ込められているときにも（暗闇の中でさえ）方位を失わないことが理解できる。もっとも、出発点の座標は徐々に眠り込み、いつの間にか周囲の対象から数え直すようになる。真夜中に突然目覚めたときの独特の方向感覚の喪失——窓やテーブルを手探りで探す——には、おそらく覚醒直前の運動的な夢が関係しているのだろう。

6.

頭を回すと、その見える部分が回転して見えるだけでなく、回転しているのを感じる。これは、触覚の領域にも視覚と全く同様の関係が成り立つことに基づいている。

対象に手を伸ばせば、触覚が神経支配感覚と合成される。対象に目を向ければ、触覚の代わりに光の感覚が入る。皮膚の感覚は対象に触れなくても常に存在しており、注意を向けさえすれば、変化する神経支配と合成されて、我々の動く身体の表象を与える。これは光学的な経路で得られるものと完全に一致する。

能動的な運動では皮膚感覚が転位（dislocirt）される。受動的な運動では、反射的に引き起こされた無意識の代償的神経支配と運動が生じる。例えば私が能動的に右に回ると、皮膚感覚は右回転での対象接触と同じ神経支配と結びつき、右に回ったと感じる。受動的に右に回されると、反射的に回転を補償しようとする傾向が生じ、実際に静止するか、あるいは左方への回転を抑制する。しかし、この抑制には能動的な右回転と同じ随意的神経支配が必要であり、同じ運動感覚をもたらす。

7.

この単純な関係を、私は『運動感覚論』の執筆時にはまだ完全には見通していなかった。そのため、一部はブロイアーが、一部は私自身が観察したいくつかの現象が理解しがたいままだったが、今や困難なく説明される。

箱の中に閉じ込められた観察者が受動的に右に回されると、箱が回転して見える（相対回転を判断する手がかりがないにもかかわらず）。目が無意識に左方への代償運動を行えば、網膜像は右方運動に対応する移動をし、右への運動を感じる。箱を注視すると、無意識の運動を随意的に補償しなければならず、やはり右への運動を見る。これによって、ブロイアーの眼振性めまいの説明が正しいこと、そしてそれにもかかわらず随意的な注視によってこの見かけの運動を消すことはできないことが明らかになる。

我々が動くとき——例えば前進歩行や回転——、身体各部の逐一の位置感覚だけでなく、はるかに単純な前進運動そのものの感覚や回転そのものの感覚がある。実際、前進運動の表象を個々の足の振り出しの表象から組み立てるのではなく、それを行う必要もない。脚の運動とは無関係に前進運動の感覚が存在する場合さえある——例えば列車に乗っているとき、あるいは旅行を思い浮かべるとき、遠い場所を思い出すときなどである。これは、前進や回転への意志——そこから四肢が運動への刺激を汲み取り、特別な神経支配によってさらに修正される——が、比較的単純な性質のものだからにほかならない。

8.

以下の実験と考察は、これらの現象の正しい理解をさらに促すだろう。

橋の上に立ち、その下を流れる水を眺める。普通は自分が静止し、水が動いていると感じる。しかし、水を長時間見つめていると、ほぼ必ず、橋と観察者と周囲全体が突然水に逆らって動き始めたように見え、一方で水は静止しているように見える。

対象の相対的な運動は両方の場合に同じであるから、なぜあるときは一方が、あるときは他方が動いて感じられるのか、そこには正当な生理学的理由があるはずである。

これを手軽に調べるために、私は簡単な装置を作った（図18）。模様のついた人工皮革のベルトコンベアを、水平に、2メートルの長さで3メートル間隔の軸受に固定された二つのローラーの上を通し、ハンドルで一様に動かす。ベルトの約30センチ上には結び目 K のある糸が張ってあり、位置 A の観察者にとっての目の休憩点となる。

矢印の方向に動くベルトの模様を目で追うと、ベルトが動いて見え、自分と周囲は静止している。しかし結び目 K を注視すると——ベルトの模様がぼやけるのだが——たちまち観察者は自分が周囲の部屋ごと矢印と逆方向に動いているように感じ、ベルトは静止して見える。

このような切り替わりは、気分次第で数秒後に起こる。コツがわかれば、かなり速やかに意のままに二つの印象を切り替えることができる。ベルトを追うたびに観察者は止まり、K を注視したりベルトに注意を払わないとき（模様がぼやけるとき）には、観察者が動き出す。

この現象は、周知のプラトー＝オッペルの現象（局所的な網膜現象）とはまったく別物である。上の実験では、はっきりと見えている周囲全体が動くのであり、後者の現象では動くヴェールが静止した対象の上を通過するのだ。

鏡を使った変形実験では、ベルトの動きが上昇・下降の印象に変換される。自分が部屋ごと沈んでいく、あるいは気球のように上昇していく感覚が得られる。紙製ドラムを使った実験でも同様の原理が適用される。

これらの現象はすべて、純粋に光学的なものではなく、全身の紛れもない運動感覚を伴っている。

9.

これらの事実をもっとも単純に表現するために、我々の考えをどのように整えるべきか。

動く対象は目に対して特別な運動刺激を及ぼし、注意と視線を引きつける。実際に視線が追従すれば、これまで述べてきたことに基づき、対象は動いて見えるはずである。しかし、動く対象にもかかわらず目が持続的に静止するためには、対象から発せられる恒常的な運動刺激が、目の運動装置に流れ込む恒常的な神経支配の流れによって補償されなければならない。これは、注視している静止点が一様に逆方向に動いていて、目がそれを追おうとしているのとまったく同じ状態である。しかしそうなれば、注視されている静止物すべてが動いて見えるはずである。

私が一つの単純な意志の行為によって前に歩み出すとき、脚は振り子運動をするが、私はそれに特別に気を配らない。目は目標にしっかりと向けられ、歩行によって動く網膜像に惑わされない。この一つの意志行為によってすべてが開始され、この意志行為そのものが前進運動の感覚なのである。

列車の子どもの目が、外の風景を追ってひっきりなしにぴくぴく動くのを観察すればわかる。大人も、印象に身を任せれば同じ感覚を持つ。動く対象の追跡に抵抗してはじめて、前進運動の感覚が生まれる。

10.

以上の観察は、私の『運動感覚論』に記述された事実に矛盾することなく、その解釈を修正する可能性を示唆する。

頭の中に器官が存在する可能性はきわめて高い——これを**終末器官（EO）**と呼ぼう——これが加速度に反応し、その媒介によって我々は運動の認知に至る。しかし、この装置が特別な運動感覚を与えるとする代わりに、それが単に反射的に神経支配を引き起こすだけだと考えることもできる。

神経支配は随意的・意識的にも、不随意的・無意識的にもありうる。それぞれの源泉を WI（随意的神経支配の器官）と UI（不随意的神経支配の器官）と表す。両者とも眼球運動装置（OM）と移動運動装置（LM）に伝達されうる。

次の図式（図23）を考えよう。滑らかな矢印の方向に WI から能動的な運動を導入すると、それは OM と LM に伝わる。これに伴う神経支配を我々は直接に感じる。この場合、別個の運動感覚は不要である。

運動が（我々を不意に襲う）受動的なものであれば、EO から UI を経て、代償的な運動を引き起こす反射が出る（羽根付き矢印で示す）。代償が成功すれば、WI は関与せず、運動も運動感覚の必要もなくなる。しかし、代償運動が WI から（意図的に）抑制されると、能動的運動と同じ神経支配が必要となり、同じ運動感覚をもたらす。

つまり、EO は WI と UI に対して、同一の運動刺激に対して後二者に逆方向の神経支配が対応するように調律されている。EO から WI への影響は、UI への影響に比べてはるかに弱いと考えなければならない。

ここで述べたことを完全かつあらゆる面で正確な事実の描写だと主張するつもりはなく、自分の叙述の欠点も自覚している。しかし、展開された主要原理（第2章の28頁参照）に従って、視覚と触覚の領域に、移動運動に、移動運動の記憶にさえ、遠い場所を思い浮かべるときにさえ現れるすべての空間感覚と運動感覚を、一つの感覚の質に還元しようとする努力は、正当と認められるだろう。この感覚の質が、空間的位置と空間的運動に関する限りでの意志であり、すなわち神経支配感覚であるという想定は、さらなる研究を先取りするものではなく、現在知られている限りの事実を表現するものにすぎない。

11.

前章の対称性と類似性に関する議論から、我々は直ちに次の結論を引き出すことができる。見られる線の同じ方向には同質の神経支配感覚が、正中面に対して対称的な方向にはきわめて類似した神経支配感覚が、上と下、遠くと近くへの視線にはきわめて異なる神経支配感覚が対応する。これは目の運動装置の対称関係から、大部分は前もって予測できることである。

これだけで、これまでほとんど注目されてこなかった一連の独特な生理学的・光学的現象が解明される。

12.

幾何学者の空間は、手動的・知的操作の基盤の上に発達した三重の多様性を持つ表象構成物である。光学的空間（ヘーリングの「視空間」）は、幾何学者の空間とかなり複雑な幾何学的親近関係にある。光学的空間が幾何学的（ユークリッド的）空間を一種のレリーフ遠近法で写像していると言うのがもっとも適切であろう。これは目的論的にも説明できる。

いずれにせよ、光学的空間もまた三重の多様性を持つ。幾何学者の空間があらゆる点、あらゆる方向において同じ性質を示すのに対し、光学的空間にはそれが当てはまらない。生理学的空間の幾何学への影響は、なお多くの箇所に認められる。例えば凸の曲率と凹の曲率を区別するのはそうした場合である。幾何学者は本来、座標の平均値からの偏差のみを知るべきなのだが。

目の筋肉が個別に神経支配されると考える限り、この根本的事実を説明することはできない。私はこの困難を長年感じていたし、心理物理的平行論の原理に従って解決の方向を認識してもいた。しかし、この領域での経験不足のため、解決そのものは私には隠されたままだった。それだけに、ヘーリングが解決を見出した功績を高く評価することができる。

三つの光学的空間座標——高さの感覚・幅の感覚・奥行きの感覚——に対応して、同じヘーリングの研究によれば、やはり三重の神経支配だけが存在する。それはそれぞれ、右転または左転、挙上または下降、両目の輻輳を引き起こす。ここに、私にとってもっとも重要かつ本質的な解明がある。

神経支配そのものを空間感覚と見なすか、それとも神経支配の背後にさらに空間感覚を想定するかは、直ちに決定することが容易でも必要でもないかもしれない。いずれにせよ、ヘーリングの叙述は視覚過程の心理的な深みに豊かな光を投じている。対称性と類似性に関して私が挙げた現象もまた、この見方にみごとに合致する。

（第4章 終わり）

第Ⅷ章　意志
1.

これまでの叙述では「意志」という表現がしばしば用いられたが、それによって指示されるのは一般によく知られた心的現象にすぎない。私は意志のうちに、特別な心的あるいは形而上学的な力を理解せず、独自の心的因果性を認めない。 私はむしろ、大多数の生理学者および近代の心理学者とともに、意志現象は有機的＝物理的な力だけから——簡潔だが一般に理解しうるようにそう言おう——説明可能でなければならないと確信している。これが自明であることをあえて強調するのは、一部の批評家の論評によって、その必要性が証明されたからにほかならない。

下等な動物の運動も、新生児の最初の運動も、刺激によって直接に引き起こされ、まったく機械的に生じる反射運動である。高等動物の後の生涯段階にもこうした反射運動は欠けない。そして、例えば腱反射を自分自身ではじめて観察する機会があれば、我々の周囲の予期しない出来事に劣らず驚かされる。先に述べた若いスズメの行動も反射運動に基づいている。生まれたばかりのヒヨコは、見えるものすべてをまったく機械的につつく——ちょうど赤ん坊が目立つものすべてをつかむように。他方、あらゆる不快な接触に対して、知性の関与なしに四肢を引っ込める。有機体の保存を条件づける有機的な仕組みがすでに備わっているのだ。

ヘーリングの生きた物質に関する見解——物質の中の拮抗的過程が平衡を目指す——に従えば、そうした保存の傾向（あるいは事実上の安定性）を、有機体の要素にまですでに帰属させなければならない。

2.

感覚的刺激は、記憶像によって部分的にあるいは全面的に代替されうる。神経系に残るすべての記憶の痕跡が感覚とともに作用し、反射を誘発し、促進し、抑制し、修正する。こうして随意運動が生まれる。これは、記憶によって修正された反射運動として、少なくとも原理的には理解することができる——個々の詳細にはまだ多くが欠けていようとも。

一度きらきら光る炎で火傷をした子どもは、もうそれをつかまない。攻撃反射が、痛みの記憶が引き起こす拮抗的な逃避反射によって抑制されるからだ。ヒヨコは最初はすべてをつつくが、味覚の記憶の促進的・抑制的な影響のもとで、まもなく選り分けるようになる。反射運動から随意行動への漸進的な移行は、先に述べたスズメにおいて非常に美しく追跡できる。

反省する主体にとって、随意行動が反射運動と異なる特徴は、その行動を規定するものを自分自身の表象——この行動を先取りする表象——の中に認めることにある。

3.

随意行動・随意運動に伴う心的過程は、W・ジェイムズとH・ミュンスターベルクによって見事に分析された。現実の運動が、表象された運動に——あたかも一つの表象が別の表象に連合するように——連合する、というのが単純で自然な見方であるように思われる。

しかし、運動の遂行に伴う感覚——運動の種類・量・努力に関するもの——についてはっ二つの見解が対立している。

一方の見解（ベイン、ヴント、ヘルムホルツが代表する）は、筋肉に向かう神経支配そのものが感じられると考える。他方、ジェイムズとミュンスターベルクは、すべての運動感覚的な（キネステティックな）付随感覚は末梢的に——皮膚・筋肉・関節の感覚要素によって——引き起こされると主張する。

神経支配感覚の中枢的起源に反対する根拠としてとりわけ有力なのは、麻酔患者の観察である。彼らは感覚刺激が排除されると、四肢の受動的な運動について何も報告できない——視覚の導きのもとでは随意運動ができるにもかかわらず。ファラデー刺激された筋肉の努力感は、随意的に神経支配された筋肉の努力感とまったく同じに感じられる。特別な神経支配感覚の仮定は現象の説明に不要であり、したがって節約の原理に従って避けるべきである。さらに、そのような神経支配感覚は直接には観察されない。ただし、特定の光学的現象が特別な困難をなすが、これについてはのちに立ち返る。

連合の法則は、意識に上る過程（表象）を結びつけるだけでなく、もっとも多様な有機的過程をも結びつける。困惑すると顔が赤くなる人、手に汗をかきやすい人は、そうした過程がただ思い出されるだけで直ちに身体に現れるのを観察する。ニュートンは研究のために太陽を直視して残像を得たが、その残像は一度消えても、思い出すたびに何か月にもわたって感覚的な強さで再び現れた。意志的な心理的転換を長く続けてようやくこの煩わしい現象を脱することができた。これらの事実を合わせ考えれば、運動過程が表象に連合されることは不思議でない。

4.

私自身、1898年に脳卒中を経験し——意識の曇りはまったくなかった——ここで問題となる事実の一部と親しくなった。

列車の旅行中に突然、右腕と右脚の完全な麻痺に気づいたが、これは間欠的であり、一時的にはほとんど正常に運動できるかに見えた。数時間後には持続的な麻痺となり、右顔面神経の障害も加わり、かすかにしか、やや困難にしか話せなくなった。

完全な麻痺の期間における自分の状態を、私は次のようにしか表現できない。四肢を動かそうとする意図に努力を感じなかったが、運動への意志をどのようにしても喚起できなかった。不完全な麻痺の段階と回復期には、逆に、腕と脚が巨大な重荷に感じられ、最大の努力をもって持ち上げた。これはおそらく、麻痺した四肢の筋肉に加えて、他の筋肉群をも精力的に神経支配したことに起因するのだろう。

麻痺した四肢の感覚は、大腿の一か所を除いて完全に保たれていたため、受動的運動の位置と動きの知覚は維持された。麻痺した四肢の反射興奮性は著しく亢進しており、わずかな驚きでも激しい痙攣が生じた。

光学的・触覚的な運動像は記憶に残っていた。日に何度も右手で何かをしようとし、それが不可能であることを思い出さなければならなかった。ピアノ演奏や筆記の鮮やかな夢——「こんなにうまくいくなんて」という驚きを伴い、目覚めとともに苦い幻滅に終わる——も同じ源に帰せられる。運動の幻覚も生じた。麻痺した手の開閉を感じることがしばしばあったが、運動の範囲は広いが硬い手袋で制限されているようだった。しかし目で確かめると、運動の痕跡はまったくなかった。

手の感覚は保たれているのに随意運動がないのだから、新しい理論（ジェイムズ＝ミュンスターベルク説）でもこの運動の錯覚をうまく説明できない。意志の支配を離れた筋肉は、さまざまな刺激に反応し、手は伸びたり握ったりする。質的に異なる強い味覚刺激は、麻痺した手の異なる筋肉に不均等に作用するようである。例えば苦い水は、親指とその隣の二本の指の不随意的な屈曲緊張を引き起こした。

5.

ジェイムズとミュンスターベルクの見解は、これらの事実に無理なく合致し、本質的に正しいと認めてよいだろう。神経支配が感じられるのではなく、神経支配の結果が新たな末梢的感覚刺激を引き起こし、それが運動の遂行に結びついている。しかし、いくつかの困難のため、この見方で事態が完全に見通されたとは私には信じがたい。

単なる運動の表象を条件づける中枢過程と、実際の運動をも引き起こす中枢過程とは、何かにおいて異なるはずだと考えるべきだろう。過程の強度、拮抗的過程の欠如、神経支配中枢の準備状態が規定的でありうるが、さらなる解明の必要性は否定しがたい。

とりわけ、眼筋と他の随意筋の振る舞いの違いがより詳しく研究されなければならない。大部分の筋肉は可変の仕事を遂行し、その量を知ることは実際的に重要である。これに対して眼筋の仕事はわずかであり、常に眼球の位置の変化に正確に結びついている。光学的に意味を持つのは位置だけであり、仕事そのものは無関係である。それゆえ四肢の筋肉では運動感覚的な感覚がはるかに大きな役割を演じるのだろう。

6.

眼筋から発する感覚がいかに小さいかは、ヘーリングが示した。通常、我々は目の運動にほとんど注意を払わず、対象の空間的位置は目の運動によって影響を受けない。

神経支配感覚を認めず、眼筋の末梢的な運動感覚にも意義を認めないならば、（ヘーリングとともに）注意の場所が特定の心理物理的過程によって条件づけられていると見なすほかない。この過程は同時に、対応する眼筋の神経支配を引き起こす物理的契機でもある。この過程は「見ようとする意志」とほとんど異ならず、「注意」ともほとんど異ならない。

したがって、私が以前の叙述（第Ⅶ章）で用いた表現を本質的には維持することもできよう。ただし、中枢から出発し経過する一連の過程のうち、どれが感覚に入り込むのかという問いは、当面は未決のままにしておくべきかもしれない。

眼筋は空間的方向づけにのみ奉仕し、四肢の筋肉は主として力学的仕事に奉仕する。ここに二つの極端な事例があり、その間には中間的な事例も存在するだろう。生まれたばかりのヒヨコが完全な正確さでつつき、的中させるのを見れば、その頭部・頸部の筋肉が眼筋にある程度類似した空間的方向づけ装置として振る舞うと信じることができる。前進する鳥のぎくしゃくした頭の運動は、回転時の眼振性の頭の振りと同様、方向づけのために行われるのだろう。

四肢の筋肉も眼筋とまったく無類比ではありえない。そうでなければ、盲人の触覚的空間表象をどう理解すればよいのか。視覚空間の生得説と触覚空間の経験説を両立させるのは、やはり困難である。

第Ⅸ章　空間についての生物学的・目的論的考察
1.

我々の空間感覚の体系——生理学的空間と呼びうるもの——が、幾何学的空間（ユークリッド空間）とどれほど異なるかは、すでに繰り返し指摘してきた。これは視覚空間だけでなく、盲人の触覚空間にも当てはまる。

幾何学的空間は至るところ、あらゆる方向において同質であり、無限で無限定である（リーマン的意味で）。これに対して視覚空間は有限で境界がある。扁平な「天蓋」の眺めが教えるように、異なる方向に不均等な広がりを持つ。物体が遠ざかれば縮み、近づけば膨らむことによって、視覚空間はユークリッド空間よりもむしろ非ユークリッド幾何学者の構成物に似ている。「上」と「下」、「前」と「後」、厳密に言えば「右」と「左」の違いもまた、幾何学的空間にはない性質である。

触覚空間も視覚空間と同様の違いを幾何学的空間に対して持つ。生理学的空間は、人間やそれに類似した構造の動物にとって、幾何学的空間に対して、三斜晶系（トリクリン）のものが正方晶系（テッセラル）のものに対するのと同じ関係にある。これは人間や動物が運動と方向づけの自由を持たない限りでのことである。運動能力とともに生理学的空間はユークリッド空間に近づくが、その性質の単純さにおいて完全に到達することはない。

幾何学的空間と生理学的空間が共有するのは、三重の多様性と連続性である。幾何学的空間における点 A の連続的運動には、生理学的空間における点 A の連続的運動が対応する。対蹠地の学説が克服しなければならなかった困難を思い起こすだけで、幾何学的空間表象が生理学的なものによっていかに曇りうるかがわかる。我々のもっとも抽象的な幾何学でさえ、純粋に計量的な概念のみを用いているわけではなく、方向、向き、右、左といった生理学的な表象をなお使用している。

2.

空間感覚を孤立した現象としてではなく、その生物学的な連関の中で、その生物学的機能において眺めれば、少なくとも目的論的により理解しやすくなる。

ある器官またはある器官系が刺激されると、反射的に——概して合目的的な——運動が起こる。刺激の種類に応じて防御運動または攻撃運動でありうる。カエルの皮膚のさまざまな場所を酸の滴で刺激すると、カエルは各刺激に対して、刺激された場所に固有の特定の防御運動で応答する。同様に、網膜のさまざまな場所の刺激は、見たものをつかむ反射を引き起こす。つまり、異なる経路で有機体に入った変化が、異なる経路で再び環境へと伝播するのである。

こうした反応がより複雑な生活条件のもとでも、記憶によって自発的に生じ、記憶によって修正可能であるためには、刺激の種類と刺激された器官に対応する痕跡が記憶に残されなければならない。 自己観察が教えるように、我々は火傷の感覚の質的な同一性だけでなく、どの場所が刺激されたかをも同時に区別する。したがって、質的に同じ感覚に分化的な成分が付着していると想定してよい。それは刺激された基本器官の固有の性質に、刺激された場所に、あるいはヘーリングの表現を借りれば「注意の場所」に依存する。

こうして各感覚領域は、固有の空間的秩序を持つ独自の記憶を獲得する。相互に連結した基本器官の多数の親密な生物学的適応が、まさに空間知覚において特に明瞭に表現に到達するのである。

3.

我々はただ一種類の意識要素——感覚——のみを想定する。我々が空間的に知覚する限り、それは感覚に基づいている。これらの感覚がどのような種類であり、どの器官がそこで働くかは、当面は未決にしておかなければならない。

共通の胚発生的起源を持つ基本器官の系を、隣接する要素が最大の個体発生的親縁性を示し、距離とともにこの親縁性が減少するように配列されていると考える。器官の個体性にのみ依存する器官感覚——親縁度に比例して変化する——が空間感覚に対応し、これを、刺激の質に依存する感覚としての感覚質から区別する。器官感覚と感覚質はつねに一緒にしか現れえない。しかし、不変の器官感覚は変化する感覚質に対して固定されたレジスターを形成し、そこに後者が配列される。

4.

空間知覚は生物学的欲求から生じたものであり、この欲求からもっともよく理解される。

無限の空間感覚の系は有機体にとって無目的であるだけでなく、物理的・生理的に不可能でもある。 身体に対して方向づけられていない空間感覚も無価値である。視覚空間が、生物学的により重要な近い対象に対して感覚の指標をより密に段階づけ、遠い対象に対しては限られた指標の蓄えを節約することは理にかなっているし、物理学的に唯一可能な関係でもある。

視覚装置の運動的組織は次の考察で理解される。脊椎動物の眼の黄斑（中心窩）における、より精密な識別力は、経済的な仕組みである。これに伴い、注意の転換に追従する眼球運動が有利となる。一方、不随意的な眼球運動が静止した対象の空間感覚に影響を及ぼすことは不利と認識される。静止した網膜上の像の移動——すなわち静止した視線に対する対象の運動——を認知することは、しかし生物学的に不可欠である。

意識の関与しない要因（外力や筋肉の痙攣）によって目が動くという稀な場合に、静止対象の静止知覚を確保することは、有機体にとって不必要であった。

これらの要求は、随意的な眼球運動に際して、対応する像の網膜上の移動がその空間的価値において、まさにその随意運動によって補償されることによってのみ両立しうる。しかしそこから、眼球を固定したまま運動の意図だけで、静止した対象が視覚空間内で移動して見えることが帰結する。この実験（第Ⅶ章参照）によって、補償する二つの成分のうち第二のものが直接に証明されている。

5.

一般的な生物学的考慮は、光学的空間と触覚的空間の同質的な把握を迫る。生まれたばかりのヒヨコは小さな対象に気づき、すぐさまそれを見てつつく。刺激によって感覚器官と中枢器官の一定の領域が興奮し、それによってまったく自動的に、眼筋の視線運動も頭部・頸部筋肉のつつき運動も誘発される。物理的刺激の幾何学的位置によって決定される同じ神経領域の興奮が、同時に空間感覚の基盤と見なされなければならない。

子どもが光る物に向かって見つめ、手を伸ばすのも同様である。光学的刺激のほかに、音響・温度・嗅覚の刺激もまた、盲人の場合も含めて、つかむ運動や防御運動を引き起こしうる。同じ運動には同じ刺激場所と同じ空間感覚が対応するだろう。ただし盲人を刺激する刺激は概してより狭い範囲に限られ、場所の特定も精密でないため、その空間感覚の体系もいくぶん貧弱でぼんやりしたものになる。

したがって、さまざまな感覚領域の類縁的ではあるが同一ではない空間感覚が、誘発された保存のための運動という紐帯によって、連合的に融合し相互に支え合うことが期待される——実際にそのとおりである。

6.

均一に這い進むヤスデを観察すると、ある器官から均等な刺激の流れが出ており、連続する体節の運動器官がそれにリズミカルな自動運動で応答しているという考えを退けられない。後方の体節の前方に対する位相の遅れによって縦波が生じ、機械的な規則正しさでこの動物の無数の脚を引っ張っていくように見える。

より高度に組織された動物にも類似の過程は欠けていない。能動的・受動的回転時に引き起こされるよく知られた眼振的眼球運動を指摘するだけで十分だろう。ヤスデのように、単純な刺激によって特定の種類の移動運動の複雑な動作が開始される器官が存在するなら、この単純な刺激は——もしそれが意識的であれば——この移動運動への意志と見なしうる。あるいは、この移動運動への注意であり、注意が自ずとその運動を引き起こすのだ。

同時に、移動運動の効果を単純な仕方で感じることが有機体の欲求であることも認められる。実際に、視覚・触覚の対象は安定した空間値ではなく、変動する流動的な空間値をもって現れるようになる。視覚・触覚の刺激をできるだけ排除すると、加速度感覚が残り、それはかつてそれと結びついていた変動する空間値の像を連合的に呼び起こす。

7.

動物の有機体にとってまず最高の重要性を持つのは、自分の身体の諸部分の相互関係である。外部のものは、身体の部分と関係を持つことによってのみ価値を得る。もっとも低い発達段階の組織は、原始的な感覚——その中に空間感覚を含む——で生活条件への適応に足りる。しかし生活条件が複雑になると、知性の発達への圧力が生まれる。そのとき、我々が物体と呼ぶ要素（感覚）の関数的複合体の相互関係が間接的に重要になる。物体の空間的な相互比較から幾何学が生まれる。

空間の直接的な知覚（目測、記憶）は、制御困難な生理学的条件に影響されやすく、物体間の正確な空間関係の判断が求められるとき、それだけでは十分な基盤にならない。そこで、物体そのものにおけるより信頼しうる標識を探す必要が生じる。

日常経験は物体の恒常性を教える。この恒常性は通常、個々の属性——色・形・大きさ等——にも及ぶ。剛体は空間内で移動しても、身体に対して特定の関係に置かれるたびに、観察・触知によって常に同じ空間感覚を引き起こす。これらの物体は空間的な恒常性（空間的実体性）を示す。剛体 A を他の剛体 B やその部分と、直接的あるいは間接的に空間的に重ね合わせることができれば、この関係はいつでもどこでも成り立つ。B を A で測ったと言う。

この物体間の比較において問題となるのはもはや空間感覚の種類ではなく、同じ条件のもとでのその同一性の判断だけであり、これは非常に高い精度と確実性をもって行われる。測定の結果の変動は、直接的な空間判断の変動に比して消え去る。ここに測定の優位性と合理的根拠がある。各人が持ち歩く手や足の代わりに、不変性の条件をより高度に満たす一般にアクセス可能な尺度が選ばれ、これによってより大きな精度の時代が開かれる。

8.

すべての幾何学的課題は、求めるべき空間を、既知の等しい物体で数え上げることに帰着する。液体用の升目や、多数のほぼ等しい密接した物体がおそらくもっとも古い測度だろう。長さの測定——等しい紐や鎖の環で数え上げること——は、二つの点の間に独自の仕方で挿入しうる最小の体積を規定する。測定体の一つまたは二つの次元を度外視する（あるいは一定だが任意に小さいと仮定する）ことで、幾何学の理想化された概念に到達する。

9.

空間直観は、物体との実験を通じて、直観だけでは得られない計量的経験によって豊かにされる。こうして直線・平面・円などの長く親しんだ形の計量的性質を学ぶ。歴史の証言によれば、経験がまず特定の幾何学的命題の認識に導き、一つの対象のある寸法が別の寸法によって共規定されることを示した。

科学的幾何学は、寸法の相互依存を解明し、不必要な測定を省き、もっとも単純な幾何学的事実——他の事実がその論理的帰結として与えられるような——を見つけ出すという経済的課題を自らに課した。我々は思考の中で自然ではなく、自分自身の単純な論理的構成物だけを支配するから、この目的のために幾何学的な基本経験は概念的に理想化されなければならなかった。

直観、物理学的経験、概念的理想化——この三つの契機が科学的幾何学において協働する。そのいずれかの過大評価あるいは過小評価が、幾何学の本質に関するさまざまな研究者の大きく乖離した見解をもたらした。迅速な移動運動のために獲得された解剖学的・運動的・対称的組織のため、直観は例えば対称的形象の二つの半分を等価に見せる——しかしそれらは物理学的＝幾何学的には等価ではない。重ね合わせることができないからだ。物理学的にも、一方向の運動が逆方向の運動と等価でないのと同じである。カントのこの問題に関するパラドクスは、考慮すべき諸契機の不十分な分離に起因する。

第Ⅹ章　視覚感覚の相互関係と他の心的要素との関係
1.

視覚感覚は、正常な心理生活においては孤立して現れるのではなく、他の感覚と結びついて現れる。我々は光学的空間の中に光学的像を見ているのではない。我々は、さまざまな感覚的性質を備えた周囲の物体を知覚しているのである。意図的な分析によってはじめて、これらの複合体から視覚感覚が取り出される。

しかも知覚は全体として、ほとんど常に思考・願望・衝動と結びついた形で現れる。感覚を通じて、生活条件に応じた適応運動が動物において引き起こされる。生活条件が単純で変化が少なく遅い場合には、感覚による直接的な誘発で十分であり、高度な知的発達は不要である。

しかし、きわめて多様で変化の激しい生活条件のもとでは事情が異なる。下等な動物は近くに来て適切な刺激を与えるものなら何でも飲み込む。より高度に発達した動物は、危険を冒して食物を探し、見つけたものを巧みにつかみ、あるいは狡猾に捕らえ、慎重に吟味しなければならない。さまざまな記憶の連鎖が通り過ぎ、そのうちの一つが拮抗するものに対して十分に強くなったとき、はじめて対応する運動が引き起こされる。したがって、適応運動を共に決定する記憶（経験）の総体が感覚に対峙するのでなければならない。ここに知性の本質がある。

複雑な生活条件を持つ高等動物では、若い時期には感覚の複合体全体が適応運動を引き起こす。しかし知性の発達とともに、複合体のより小さな部分で引き起こすのに十分となり、感覚はますます知性によって補完され、代替されるようになる。

2.

したがって表象（想像）は、感覚が不完全である限りにおいてそれを補い、本来は感覚だけで条件づけられていた諸過程をさらに紡ぎ続ける役割を持つ。しかし、正常な生活において、感覚が存在する限り、表象が感覚を完全に駆逐してしまってはならない。そうなれば有機体にとって最大の危険が生じるだろう。

実際に、正常な心理生活においては、表象と感覚という二種類の心的要素の間にきわめて鋭い区別が存在する。目の前に黒い板を見ている。その板の上に、鋭い白線で描かれた六角形や色つきの図形をきわめて生き生きと想像することができる。しかし、病的な場合を除けば、何を見ていて何を想像しているかは常にわかる。表象に移行するとき、注意が目からそらされて別の方向に向けられるのを感じるのだ。

板の上に見えている点と、同じ場所に想像されている点は、この注意の向きの違いによって、いわば第四の座標で区別される。「想像されたものが見えたものの上に、曇りガラスの鏡像が透けて見える物体の上に重なるようだ」と言っただけでは、事実は完全にはカバーされない。これは当面は心理学的事実であるが、その生理学的説明もいずれ見つかるだろう。

人間の複雑な生活条件に要請されるより強い知性の発達に伴い、表象が一時的に注意全体を引きつけ、考えにふけっている人の周囲で起こる出来事が見えなくなったり、話しかけられても聞こえなくなったりすることがある。こうした没頭に慣れない人はこれを「散漫」と呼ぶが、むしろ「集中」と呼ぶ方がはるかに適切だろう。

3.

表象と感覚の間のこの鋭い境界に注意を払うことは、感覚現象の心理学的説明における不用意を防ぐのにきわめて有効である。有名な「無意識的推論」の理論は、この事情にもっと注意を払っていたならば、あれほど広範に発展することはなかっただろう。

表象の器官は、暫定的には次のように考えることができる。すなわち、（より低い度合いにおいて）感覚器官と運動器官のすべての特殊的エネルギーに参加しうるものであり、その注意の調律に応じて、ある器官のエネルギーがそこに波及する。このような器官は、さまざまなエネルギー間の生理学的な関係を媒介するのに格好である。

表象のための器官のほかにも、おそらくいくつかの類似の媒介器官が存在し、それらの過程は意識に上らない。これは大脳を除去された動物の実験が教えるところである。

自己観察から知られるような表象生活の豊かさは、確かに人間においてはじめて本格的に現れる。しかし、この生命表現の始まり——有機体のすべての部分の相互関係を表現するにすぎないもの——は、動物の発達系列において同様に深いところまで遡る。

もっとも有益な関連する観察は、ヨハネス・ミュラーがその美しい著作『幻視現象について』（コブレンツ、1826年）に集めたものだろう。ミュラーが覚醒状態で観察した視覚のファンタスマ（幻像）は、意志や思考の影響からまったく独立しており、表象の器官ではなく感覚器官に結びついた現象で、客観的に見えたもののような性格を持つ。それはまさに感覚の幻想とも記憶現象ともいうべきものである。

通常は網膜の刺激を受けて「視覚の実体」の中で展開される過程が、例外的に、網膜の刺激なしに自発的に起こりうる。これが幻像あるいは幻覚の源泉となる。幻像の性格が以前に見たものに強く接近するなら「感覚の記憶」と呼び、幻像がより自由に、より唐突に生じるなら「幻覚」と呼ぶ。しかし両者の間に鋭い境界を設けることは難しい。

私自身、あらゆる種類の視覚幻像を自分の経験から知っている。はっきりと見えないものの中に幻像が入り込む現象は、もっとも頻繁に起こるだろう。以前、脈波やスフィグモグラフに取り組んでいたとき、黒い地の上の細い白い曲線が、夕方にも昼間の薄暗がりにも、完全な生々しさと客観性をもって目の前に現れた。眠りに落ちる前の色鮮やかな変幻する壁紙模様を見ることは、若い頃はとても馴染みのものだった。子どもの一人も寝つく前の「花が見える」ことをよく話す。稀に、夕方に人間の姿が意のままでなく変化するのを見た。暗い部屋で目覚めたとき、最後の夢の像が鮮やかな色彩と豊富な光をともなってなお残っていることはしばしばあった。

ファンタスマの痕跡は、外的刺激の影響から網膜を遮り、注意を視野だけに向ければ、ほとんど常に見出される。外的刺激が弱くぼんやりしているとき——薄暗がりの中、あるいは汚れた染みのある面や雲や灰色の壁を見ているとき——にもすでに現れる。

レオナルド・ダ・ヴィンチはその『絵画論』の中で、このような幻像のはたらきを見事に述べている。「いろいろな染みに覆われた壁や、さまざまな混合物でできた石を見つめるがよい。何かの場面を考案しなければならないときに、そこにいろいろな風景に似たもの——山や川や岩や木々で飾られたもの——を見出すことができるだろう。……教会の鐘の音の中に、想像するどんな名前や言葉でも聞き取ることができるのと同様のことが、こうした壁や混合物でも起こるのだ。」

夢と半覚醒状態を除き、ファンタスマが網膜の刺激なしに強く自発的に出現するのは、生物学的な不合目的性のゆえに病的と見なされなければならない。同様に、ファンタスマが意志に異常に従属するのも病的と見なすべきである。そうした状態はおそらく、自分を非常に強力な存在や神などと見なす狂人のもとに見られるだろう。

4.

以上の予備的考察を経て、いくつかの生理光学的現象を見てみよう。完全な説明にはまだ遠いが、感覚器官の自立的な生命の表れとしては、比較的もっともよく理解できるものである。

通常、我々は両目で、しかも生活に奉仕する特定の目的をもって、色や形ではなく空間の中の物体を見ている。重要なのは複合体の個々の要素ではなく、生理学的・光学的な複合体全体である。この複合体が、特定の状況のもとで不完全に現れると、視覚はその生活条件のもとで獲得された（あるいは遺伝された）習慣に従って、複合体を補完しようとする。

これは片目で見ている場合や、両目でも非常に遠い対象を見ている場合（立体視の差異が目の間隔に比して消失する場合）に容易に起こる。

通常、光と影ではなく空間的な対象が知覚される。物体の自己影はほとんど気づかれない。明るさの差は奥行き感覚の差を引き起こし、立体視の差異では不十分なところで物体の造形を助ける。遠くの山を見るとき、これは非常に顕著になる。

写真暗箱のすりガラス上の像はこの点できわめて教育的である。すべてを一つの面の中に見なければならないために初めて気づく、光の明るさと影の深さに驚くことがしばしばある。

5.

折り曲げた名刺を使った以下の実験は、光の感覚と奥行き感覚の関係をきわめて明瞭に示す。名刺を書き机の上に立て、光が左から入るようにする。凸の稜 be が自分に向くようにすると、半分 ab は明るく、半分 bc はずっと暗いが、無心に見ているとほとんど気づかない。ここで片目を閉じる。空間感覚の一部が消失するが、それでも折り曲げた紙は立体的に見え、照明にも特に目立つところはない。

しかし、凸の稜 be の代わりに凹の稜を見ることに成功すると、光と影がまるで被覆塗料で塗られたように見える。このような「反転（Inversion）」が可能なのは、片目の像では奥行きが確定しないからである（図25参照）。

目は、見える面の明るさに応じて奥行き感覚の勾配をも変える習慣を身につけなければならない。光が左から来るとき、奥行きは右方の明るさ増加とともに減少し、光が右から来るとき、逆になる。眼球の殻は半透明であるから、網膜上の光の分布にとって、光が右から来るか左から来るかは無関係ではない。判断の助けを借りずとも、明るさと奥行きが特定の仕方で結びつく視覚の固い習慣が自ずと形成される条件が整っている。

ここで注意すべきは、互いに相関する感覚の質の間に、エネルギー保存の法則に似た原理が成り立っているように思われることである。明るさの差は部分的に奥行きの差に変換され、その際に明るさの差自身は弱まる。逆に、奥行きの差を犠牲にして明るさの差が増大されうる。

6.

空間的に大きなまとまった物体を観察する習慣——すなわち、光の感覚のより大きな連続体に注意を向ける習慣——は、独特の、一部は驚くべき現象をもたらす。

例えば、二色の絵や図は一般に、どちらの色を地と見なすかによってまったく違って見える。暗い木立の間に白い空を地と見れば幽霊が現れる、というような騙し絵はよく知られている。ただし例外的に、地と図が同じ形を呈することがあり、これは装飾で頻繁に用いられるモチーフである（図26、オーウェン・ジョーンズの『装飾の文法』参照）。

7.

片目で遠近法的な図を見たとき（あるいは、同じことだが、片目で対象を見たとき）の空間知覚の現象は、通常ほとんど自明のこととして軽く扱われている。しかし私の考えでは、そこにはまだ研究すべきことが多い。

同一の遠近法的図は無限に多くの異なる対象に属しうるのだから、空間感覚は部分的にしか決定されない。にもかかわらず、その図に対応して考えうる無数の物体のうち、ごくわずかだけが実際に見え、しかも完全な客観性をもって見える。これには正当な理由がなければならない。それは付加的な思考による規定（意識的な記憶）に基づくのではなく、視覚の特定の生活習慣に基づく。

視覚は、種と個体の生活条件のもとで獲得した習慣に従って、確率の原理に従って進む。すなわち、もっとも頻繁に一緒に引き起こされてきた機能は、一方だけが刺激されたときにも一緒に呼び起こされる。また、節約（倹約）の原理に従う。すなわち、視覚は刺激によって決定されている以上の負担をみずからに課さない。

8.

遠近法の図の中の直線は、常に空間の中の直線として見られる。一つの直線の像は無限に多くの平面曲線にも対応しうるにもかかわらず。空間の中の直線がいかなる場合にも両方の網膜に直線として映るのに対し、平面曲線がそうなる確率はきわめて低い。したがって、もっとも確率の高い対象は空間の中の直線であり、同時に直線は、奥行き感覚の偏差の最小値を示す——つまりもっとも楽に見られる。確率の原理と節約の原理は、その効果において一致する。

図の中で直線が一点に収束するように見えるところでは、収束する端あるいは接近する端は、確率の原理と節約の原理によって同じか近い奥行きに置かれる。こうして消失点の効果が説明される。

9.

片目の像によって引き起こされる奥行き感覚については、以下の実験が有益である。図28の四角形と二つの対角線は、片目で見れば確率・節約の法則に従ってもっとも容易に平面として見える。しかし同じ図は、対角線 bd が ac の前にある四面体として、あるいは bd が ac の後ろにある四面体としても見ることができる。

さらに、点 e を手前か奥に想像すれば、四角錐としても見うる。ただし be と ae が完全な直線であると、視覚が直線を強制なしに折れ線として見る習慣に反するため困難である。e にわずかな折れがあれば容易になる。

表象と意志が視覚過程に及ぼす影響はきわめて限定的であり、注意の導きと、視覚器官の習慣の範囲内にあるいくつかの選択肢のうちどれを採用するかの決定に限られる。選択された各場合は機械的な確実さと正確さで実現される。

10.

図の中で交わる線が相互に図の面から押し出し合うという独特の相互作用は、私が最初に、前述の名刺の反転実験の際に観察した。折り曲げた紙を凹に見ることに成功すると、その向きが変わるだけでなく形も変わる。

透明な対象の場合、この効果はとくに驚くべきものとなる。テーブルの上のガラスの立方体を片目で反転させると、手前の稜が奥に移り、奥の稜が手前に来て、立方体が一つの稜の上で斜めにテーブルに立っているように見える。色つきの液体が入ったコップでは、液面まで傾いて見える。

同じ現象は、十分な注意があればどの線画でも観察できる。鋭角の二辺は図の面の異なる側に押し出され、鈍角の二辺は同じ側に押し出される。すべての角が直角に近づこうとする、と言うこともできる。

これはツェルナーの疑似立体視（Pseudoscopie）に現れる現象と本質的に異なるものではない。しかし、これらの現象は多く研究されてきたにもかかわらず、現在のところ満足のいく説明は存在しない。「我々は直角を見慣れているから」といった安易な説明では、研究を途中で打ち切ることになるだけだ。

11.

これらの現象に表れる要素的な力は、もっと単純な視覚器官の習慣に根を持つと私は確信している。それは人間の文化生活の中ではじめて生じたものではない。

確率の原理はいくらかの展望を提供するように思われる。網膜上に見える角 A に対して、実際の角 a は 0° から 180° までのすべての値を取りうる。計算を行うと、見かけの鋭角にはより大きな実際の角が、見かけの鈍角にはより小さな実際の角が、もっとも確率の高い対象として対応することがわかる。しかし、幾何学的に等しく可能な場合が生理学的にも等しく可能と見なしてよいかどうかは判断できなかった。

12.

平面の線画は、片目で見ると平面に見えることが多い。しかし角を変化させ、運動を導入すると、すべてのそうした図はたちまち奥行きの中に伸び出す。回転中の剛体が見えるのが普通で、これは以前述べたリサジュー図形の場合と同様である。

剛体との付き合いの習慣によって説明しようとすることもできる。回転や方向転換をしている剛体は確かに我々を常に取り囲んでいる。しかし私はこの説明には満足できない。むしろ、ここにもまた要素的な習慣が根底にあり、それは意識的な個人的経験で生まれたのではなく、むしろ逆に、剛体の運動の把握を容易にしてきたのだと考える。

例えば、注意を向けている光学的な感覚の塊の横方向の縮小が、対応する奥行き方向の増大を引き起こす傾向がある（そしてその逆も）と想定すれば、この過程はまさにエネルギー保存に類比される上述の原理と同様のものになる。

剛体の回転の対照として、もう一つの観察を挙げておこう。つや消しの一様な表面を持つ卵や楕円体をテーブルの上で回転させると——ただし転がるのではなく回転体の軸のまわりに回すと——跳ねるような運動をしているように見え、両目で見ると流動的な物体、大きく振動する水滴のように見える。しかし、卵の表面に斑点をつけて動きを追えるようにすると、この印象は直ちに消え、回転する剛体が見える。

この章で与えた説明は完全にはほど遠い。しかし、以上の考察が、ここで論じた現象のより正確で詳細な研究を促し、その道を開くことができると信じている。

（第5章 終わり）

第Ⅺ章　感覚・記憶・連合
1.

これまでの議論から明らかなように、単なる感覚だけでは、我々のものに少しでも似た心的生活を基礎づけることはできない。感覚が消えるとともに直ちに忘れられるならば、心的状態のまとまりのないモザイクと連続が生じるだけであろう——もっとも低い動物や程度の低い白痴の場合にそうであると想定せざるをえないように。

激しい運動刺激として働く痛みの感覚のようなものを除けば、この段階の感覚はおそらく注意を引かないだろう。例えば、鮮やかに着色された球状の物体の眺め——それが果実の匂いや味、つまりその果実についての経験の記憶によって補完されないならば——は理解されないままで、関心を引かない。ちょうど「精神盲」の状態で観察されるとおりである。

記憶の保存、記憶どうしの連関、相互の再覚醒可能性——すなわち記憶と連合——が、発達した心的生活の根本条件である。

2.

では記憶とは何か？

心的な経験は心的な痕跡を残す。しかし同時に物理的な痕跡をも残す。火傷をした子どもや蜂に刺された子どもは、この経験のない子どもとは物理的にもまったく異なる振る舞いをする。なぜなら心的なものと物理的なものは、そもそも考察の仕方によってのみ異なるからだ。

しかしそれにもかかわらず、無機物の物理学の中に記憶に類縁する特徴を発見することは、きわめて難しい。

無機物の物理学においては、すべてが瞬間的な条件によって決まり、過去はまったく影響を持たないように見える。物体の加速度は瞬間の力によって与えられる。振り子は、最初の振動であれ千回目の振動であれ同じに振動する。水素は、以前に臭素やヨウ素と結合していたかにかかわらず、塩素と同じ仕方で結合する。

もちろん、物理学の領域にも過去がその影響を明瞭に示す場合はある。地球は我々にその地質学的前史を語る。月も同様である。地質学者E・ジュースのもとで、ある岩石片に非常に奇妙な合同な平行した引っかき傷の痕を見たことがあるが、ジュースはそれをきわめてもっともらしく先史時代の地震記録と解釈した。

針金は、被った捻りを長い間いわば「覚えている」。放電火花はどれも個体であり、先行する放電の影響を受けている。ライデン瓶の絶縁層は、先行する帯電の歴史を保存している。

この見かけの矛盾は、次のことを考慮すれば解消する。物理学において我々は、考察する場合を極端に理想化・図式化し、もっとも単純な条件を前提とする習慣がある。数学的な振り子を仮定すれば、確かに千回目の振動は一回目と同じである。過去の痕跡がないのは、それを度外視しているからにほかならない。しかし現実の振り子は刃先を摩耗させ、外部・内部の摩擦によって温まり、厳密に言えばどの振動も他とまったく同じではない。心理学においても同じように図式化できたなら、個々の体験の影響をまったく示さない、同一に振る舞う人間が得られるだろう。

現実には、あらゆる心的過程は、あらゆる物理的過程と同様に、消えることのない痕跡を残す。 両方の領域に不可逆的過程がある。エントロピーが増大するにせよ、いったん乱れてから修復された友情の結び目が感じられるにせよ。そしてあらゆる現実の過程は、少なくとも不可逆的な成分を含んでいる。

3.

しかし正当にこう言われるだろう。「過去の痕跡があるだけでは、まだ記憶ではない。」類似性がより大きくなるためには、かつてあった過程が、わずかなきっかけで再び展開しなければならない。よく弾かれた古いヴァイオリン、モーザーの曇り像、蓄音機は、多少ましな例である。しかし、ヴァイオリンも蓄音機も外部の力によって演奏されなければならないのに対し、人間は自分自身と自分の記憶を自分で演奏するのだ。

有機体は硬直した物質の系ではなく、本質的に「物質」と「エネルギー」の流れの動的平衡形態である。一度導入されたこれらの流れの平衡状態からの偏差形態こそが、常に同じ仕方で反復するのである。

動的平衡形態のこうした変異は、無機物の物理学ではまだほとんど研究されていない。偶然の事情で変化し、以後そのまま維持される河川の流路の変化は、ごく粗い例である。水道の蛇口を細く絞って静かな細い水流を出すと、偶然のきっかけだけで不安定な平衡が崩れ、持続的なリズミカルな滴下が始まる。長い鎖を、丸めて入れた容器から滑車を越えてサイフォンのように低い容器に流し込むことができる。落差が大きければ速度は著しく増し、鎖は空中で与えられた曲げを長く保持し、その形のまま流れ続ける性質を示す。

これらの例はすべて、有機体の過程反復に対する可塑性のきわめて貧弱な類比にすぎない。以上の考察が示そうとしたのは、記憶の物理学的理解は不可能ではないが、我々はまだそこからきわめて遠いということだ。物理学は有機的なものの研究を通じてなお著しく視野を広げなければならないだろう。記憶の豊かさが諸器官の相互作用と連関に基づいていることは確かである。しかし、記憶の萌芽は基本的有機体（微生物）にも帰属させなければならないだろう。そして、器官内のあらゆる化学的過程が痕跡を残し、同じ過程の再発を促進すると考えるほかないのである。

4.

心理学において連合の法則にきわめて大きな意義が認められていることは周知のとおりである。これらの法則は一つの法則に帰着する。すなわち、一度同時に出合った二つの意識内容 A と B のうち、一方が生じれば他方を呼び起こす、というものだ。この常に回帰する基本特徴を認識することで、心的生活は実際にはるかに理解しやすくなる。

単純な経験の回想、真剣な職業上の仕事、自由な空想や白昼夢における思考の流れの違いは、付随する状況によって容易に理解される。しかし、すべての心的過程を、個体の一生の間に獲得された連合だけに帰着させようとするのは誤りであろう。心は、どの段階においても「白紙（タブラ・ラーサ）」として我々の前に現れることはない。 獲得された連合のほかに、少なくとも生得的な連合も認めなければならない。

自省的な——自分自身に限定された——心理学にとって連合として現れるものを、生物学者は生得的な有機的結合、とりわけ神経結合に帰着させる。したがって、個別に獲得された連合も含めて、すべての連合が生得的な、あるいは使用によって強化された結合に基づいているかどうかを試みることが勧められる。

いずれにせよ、合理的な心理学は一時的な連合だけでは足りない。完成された結合経路がすでに存在していることも考慮しなければならない。そうすれば、連合によらない自発的な心的過程の可能性も認めなければならない——神経系の隣接部分を興奮させ、激しい場合には神経系全体に伝播するような過程の可能性を。幻覚は感覚的領域の、反射運動は運動的領域の例であり、他の領域にも類似のものが対応するだろう。

5.

中枢神経系の諸部分の相互作用に関する見解は、ローブが自身の研究とゴルツ、エヴァルトの研究に基づいて述べているように、注目すべき転換を迎えつつあるように見える。これによれば、動物の走性（トロピスム）は植物のそれと本質的に異ならず、神経は前者の場合に、より迅速な刺激伝導の利点を提供するにすぎない。神経系の生活は体節的な反射に、運動の協調は相互興奮と刺激伝導に、本能は連鎖反射に帰着させられる。カエルの捕食反射が嚥下反射を引き起こすように。複雑に組織された中枢は想定されず、脳そのものが体節の配列と見なされる。

これらの見解には、不必要に複雑で形而上学に浸された前提から解放されようとする幸運かつ重大な努力が含まれている。ただし、ローブがダーウィンの系統発生的な本能研究に誤った一面性を見出し、それを捨てて物理化学的研究に置き換えるべきだとする点には、私は賛同できない。物理化学的探究がダーウィンから遠かったのは確かである。しかしだからこそダーウィンは、いかなる物理学者もそれだけでは成し遂げえなかった、彼独自の偉大な発見のための自由な視野を得たのだ。

我々はもちろん、可能な限りどこでも物理学的（「因果的」）な洞察を、直接的連関の認識を目指す。しかし、それがすでにどこでも到達可能であるとは言いがたい。そのような場合に、暫定的と見なしうるとはいえ、他の実りある観点を放棄することは、別の、きわめて重大な一面性であろう。

6.

私が感じている間に、私自身あるいは他の誰かが、あらゆる物理学的・化学的手段をもって私の脳を観察できると想像しよう。そうすれば、有機体のどの過程に特定の種類の感覚が結びついているかを解明することが可能になるだろう。そうなれば、しばしば提起される問い——感覚は有機的世界のどこまで及ぶか、もっとも低い動物は、植物は感じるか——も、少なくとも類比によって、その解決に近づきうるだろう。しかし、この課題がただ一つの特殊な場合においてさえ解かれていない限り、これについて決定を下すことはできない。

ときに、（無機的な）「物質」は感じるかと問われることがある。通常の広く行きわたった物理学的表象から出発する場合——物質がもっとも確実に与えられた実在であり、そこから有機的なものも無機的なものもすべてが構成されると考える場合——この問いは自然である。感覚は、この構築のどこかで突然生じるか、あるいは最初から構成材料の中に存在していなければならない。

我々の立場では、この問いは倒錯したものである。 物質は我々にとって最初に与えられたものではない。最初に与えられたものはむしろ要素（特定の既知の関係において「感覚」と呼ばれるもの）である。人間の個人にとって意味を持ちうるあらゆる科学的課題は、要素の相互依存の解明に関わる。俗語で物質と呼んでいるものもまた、要素の特定の種類の連関にほかならない。したがって、「物質は感じるか」という問いは次のように読み替えられることになる。「要素（ある関係においてはつねに感覚でもある）の特定の種類の連関は、感じるか？」——この形では、誰もその問いを立てようとは思わないだろう。

我々にとって関心のあるものは、一般的課題の追究の中でおのずから明らかになるはずである。動物の感覚について我々が問うのは、その感覚的に観察される行動がそれによってより理解しやすくなる場合である。結晶の感覚について問うこと——その感覚的に完全に規定された行動についてさらなる解明を与えないような感覚——には、実際的な意味も科学的な意味もない。

第Ⅻ章　時間感覚
1.

空間感覚に比べて、時間感覚の研究ははるかに困難である。ある種の感覚は空間感覚を伴って現れるが、伴わないものもある。しかし時間感覚は他のあらゆる感覚に付き添い、どの感覚からも完全に切り離すことができない。したがって研究にあたっては、時間感覚の変動に注目するほかない。

この心理学的な困難に加えて、もう一つの困難がある。時間感覚が結びついている生理学的過程は、他の感覚に対応する過程よりもさらに知られておらず、より深く隠されたところにある。したがって分析は主として心理学的な側面に限定されざるをえない。他の感覚領域ではある程度可能であるような、物理的な側面からの対応づけは、ここでは期待しがたい。

2.

特殊な固有の時間感覚が存在するということは、私には疑いがない。

まったく異なる音の列からなる二つの小節の同じリズムが、直ちに認識される。これは悟性や考察の問題ではなく、感覚の問題である。異なる色をした同じ空間的形の物体が我々の前に現れうるのと同様に、ここでは音的に異なる色づけを持つ二つの音の形象が同じ時間的形を持っている。空間のほうでは同一の空間感覚構成要素を直接に感じ取るように、ここでは同一の時間感覚構成要素、すなわちリズムの同一性を直接に感じ取るのである。

3.

音響的にまったく同一の鐘の打撃を何回か聞くとき、一打目、二打目、三打目……を区別する。付随する思考や偶然の感覚——それらと鐘の音が結びついて——が区別の手がかりとなるのだろうか？　この見解を真剣に主張しようとする者はいないだろう。それでは我々の時間の尺度はどれほど不確実で信頼できないものになってしまうことか。偶然の思考や感覚の背景が記憶から消えてしまったらどうなるのか？

何かについて考えている間に時計が鳴り、私はそれに注意を払わない。鳴り終わったあとに、鐘の打数が気になることがある。実際、記憶の中に一つ、二つ、三つ、四つの鐘の音がはっきりと浮かび上がる。その記憶に注意を向けている間、時計が鳴っていたときに何を考えていたかはすっかり意識から消えている。鐘の音を固定できたはずの背景は、いまや存在しない。では、なぜ二打目を一打目から区別できるのか？　なぜすべての同じ打撃を一つと見なさないのか？

それぞれの打撃が特別な時間感覚と結びついて現れるからである。

記憶像を空想の産物から区別するのもまた、現在の瞬間のものではない固有の時間感覚による。

時間感覚は、我々が意識ある限り常に存在するのだから、意識に必然的に結びついた有機的消耗と関連しているらしい。我々は注意の労働を時間として感じているのだと思われる。注意を強く集中すれば時間は長く感じられ、楽な作業のときは短く感じられる。ぼんやりとして周囲をほとんど気にかけないとき、時間は速く過ぎる。注意が完全に尽きれば、眠りに入る。夢のない深い睡眠では時間の感覚もない。昨日は今日と結びついているが、深い眠りが間にあれば、それは知的な絆によってのみつながっている。

覚醒中、意識器官の疲労は連続的に進行し、注意の労働もまた着実に増大する。より大きな注意の労働と結びついた感覚が、我々にはより後のものとして現れる。

4.

正常な場合も異常な場合も、この見方にうまく合致するように思われる。

注意は同時に二つの異なる感覚器官にまたがることができないから、それぞれの感覚は、まったく同一の注意の労働と重なることができない。一方が他方より遅く現れる。天文学者のいわゆる「人差（個人差）」の類似現象は、同一の感覚領域の中でも、同様の理由から生じる。

物理的に後から生じた光学的印象が、ある状況のもとでは先に現れうることが知られている。例えば、外科医が瀉血の際にまず血が出るのを見てから、ランセットを打ち込んだのを見る、ということが起こる。ドヴォルザークは私の依頼で何年か前に行った一連の実験で、注意をもって注視されている対象が（実際には6分の1秒から3分の1秒遅れていても）間接的に見られている対象よりも先に現れることを示した。

注意がある場所から別の場所に移るのに要する時間は、次の実験に現れる。黒い地の上に2センチ角の赤い正方形を8センチ間隔で二つ置き、完全な暗闇の中で、目に隠された電気火花によって照明する。直接に見ている正方形は赤く見えるが、間接的に見ている方は緑に見える——しばしばかなり強烈に。遅れた注意が間接視の正方形に到達したとき、それはすでにプルキンエの正の残像の段階に入っているのである。

5.

次のような興味深い現象を、私は繰り返し観察した。仕事に没頭して自室に座っているとき、隣室で爆発の実験が行われていた。きまって、まず驚いてびくっと体が動き、そのあとで爆発音が聞こえるのだった。

夢の中では注意がとりわけ鈍いので、もっとも奇妙な時間錯誤が起こる。誰しもそうした夢を経験したことがあるだろう。例えば、男が我々に向かって突進し発砲する夢を見て、ぱっと目を覚まし、落下物がその夢全体を引き起こしたことに気づく。音響刺激が同時に複数の神経経路に入り込み、注意が任意の逆順でそれらに出会うと考えれば、不合理なことはない。上の観察で、全般的な身体の動揺をまず知覚し、そのあとで爆発音に気づいたのと同じである。もちろん多くの場合、ある感覚が、すでに存在していた夢の像の中に織り込まれると考える方が適切な場合もあるだろう。

6.

時間感覚が、増大する有機的消耗、あるいは同様に着実に増大する注意の労働に結びついているとすれば、次のことが理解される。生理学的な時間は不可逆であり、一方向にしか進まない。消耗は、覚醒中は増大することしかできず、減少することはできない。

二つの小節が視覚と悟性にとっては対称であっても、時間感覚に関しては対称なものは何もない。リズムと時間の領域には、対称性は存在しない。

もし消耗そのもの、あるいは何らかの疲労物質の蓄積が直接に感じられるとすれば、夢の中で時間が逆行することを期待しなければならないが、そうはならない。夢の奇妙さはすべて、ある感覚や表象がまったく意識に上らず、あるいは遅すぎて意識に上ることから説明される。知性はしばしば部分的にしか眠らない。夢の中で久しく亡くなった人と非常に理性的に話をするが、その人の死を思い出さない。夢の中で夢について考察し、その奇妙さからそれが夢であると気づくが、すぐにまた平気になっている。

7.

意識の器官を、あらゆる感覚器官の特殊的エネルギーに（低い度合いで）参加しうるものと考えるのは、おそらく自然で、不完全ではあるが近似的な表象であろう。それぞれの感覚器官はその一部のエネルギーしか示さないが、意識器官はすべてに参加できる。表象が感覚に比べて影のように淡くはかないのはそのためであり、感覚によって常に養われ、リフレッシュされなければならない。また意識器官があらゆる感覚や記憶の間の橋渡しとして機能しうるのもそのためである。

意識器官の各特殊エネルギーには、さらにもう一つの特別なエネルギー——時間感覚——が結びついていると考えなければならない。前者のどれも後者なしには活性化されない。

この最後の生理学的エネルギーが無用で、ただ場当たり的にでっち上げられたものに見えるとすれば、ただちにそれに重要な生理学的機能を割り当てることもできる。もしこのエネルギーが、働いている脳の各部分に栄養を送る血流を維持し、その目的地に導き、調節しているとしたらどうだろうか？　そうすれば、注意と時間感覚についての我々の表象はきわめて物質的な基盤を得ることになる。時間がただ一つの連続したものであることも理解できるだろう。なぜなら、ある感覚に向けられた部分的注意は、つねに全体的注意から流れ出し、それによって条件づけられているからである。

8.

同一の鐘の音を何回か聞くとき、少数であれば個々の打撃を記憶の中で互いに区別でき、あとから数えることができる。しかし数が多くなると、最後のいくつかは区別できても、最初のものはもはや区別できない。その場合に誤りを避けるには、鳴り始めと同時に数えなければならない——すなわち各打撃に意図的に順序記号を結びつけなければならない。

この現象は空間感覚の領域で観察されるものとまったく類似であり、同じ原理で説明される。前方に歩いて行くとき、出発点から遠ざかっている感覚はあるが、この距離の生理学的な尺度は幾何学的な尺度に比例しない。経過した生理学的時間も同じように遠近法的に縮む。個々の要素はどんどん区別しがたくなる。

9.

特殊な時間感覚が存在するなら、二つのリズムの同一性が直ちに認識されることは当然である。ただし見落としてはならないのは、同一の物理学的リズムが、生理学的にはきわめて異なって現れうるということである。これは、同一の物理学的な空間形が、その配置によって異なる生理学的空間形に対応しうるのと同様である。

例えば、記譜された一つのリズムも、どの垂直線を拍子線と見なすかによってまったく異なって聞こえる。これは、注意が（拍子の強調に導かれて）1、2、あるいは3のどの点から始まるかによって、連続する打撃に対応する時間感覚が、異なる開始感覚と比較されることによる。

二つの物理的な時間形象は、一方のすべての部分が互いに同じ比率をなし、他方の相同な部分も同じ比率をなすなら、相似と呼ぶことができる。しかし生理学的な類似性は、上の条件——すなわち、相同な時間点で注意が同期すること——が満たされてはじめて感じられる。

私の知る限り、二つのリズムの時間関係は、きわめて小さな整数で表しうる場合にのみ等しいと認識される。本来、我々が直接に認識できるのは二つの時間の等しさか不等だけであり、不等の場合に比率を認識するのは、一方が他方の中に単純に割り切れる場合に限られる。拍子を取るときに時間をことごとく等しい部分に分割するのは、このためである。

空間形の類似性は、リズムの類似性よりもはるかに直接的に感じられるだろう。——リズミカルな運動と時間の尺度との関連は、おそらく重要な目的論的意義を持つが、ここでは論じないでおく。

第ⅩⅢ章　音の感覚
1.

音の感覚についても、我々は主として心理学的分析に限定せざるをえない。ここでもまた研究の始まりしか提供できない。

我々にとってもっとも重要な音の感覚に属するのは、人間の声によって——苦痛や快楽の表現として、思考の言語的伝達として、意志の表現として——引き起こされるものである。声の器官と聴覚器官は疑いなく密接な関係にある。もっとも明確かつ単純な仕方で、音の感覚はその驚くべき性質を音楽において開示する。

音声の発出と音の感覚の間に強い生理学的関連があることは確かである。ショーペンハウアーが、音楽は意志を表現すると言い、音楽が感情の言語と呼ばれるとき、そこにはかなりの真実が含まれているだろう。しかし、それがすべてではない。

2.

H・ベルクはダーウィンに倣い、音楽を類人猿の発情期の叫びから導き出そうとした。ダーウィンとベルクの議論に啓発的で価値ある面があることを否定するならば、偏見というものだろう。今日でも音楽は性的な弦に触れることができるし、実際に求愛に使われている。

しかし、音楽の何が心地よいのかという問いに対して、ベルクは満足のいく答えを与えていない。彼はヘルムホルツの「うなり（Schwebungen）の回避」という立場に立ち、もっとも不快でなく吠えた雄が選好されたと想定しているが、それならもっとも賢い雄がいっそ黙っていなかったのが不思議だ、と言いたくもなる。

ある生物学的現象と種の保存との関係を明らかにし、系統発生的に導き出しても、それでその現象に関するすべての問題が解決されたわけではない。性的な快楽の心地よさを、種の保存との関連を示すことで説明しようとする者はいないだろう。むしろ、快楽が心地よいからこそ種が保存される、と言う方がよほど自然である。

音楽が遠い祖先の求愛を想起させるとしても、求愛に使われるためにはそもそも積極的に心地よいものを含んでいなければならない。消えかけの灯油ランプの匂いが子どもの頃に感嘆した幻灯の思い出を呼び起こすことがあるが、だからといってランプの匂い自体が嫌いでなくなるわけではない。薔薇の香りで楽しい体験を思い出す人も、それ以前から薔薇の香りが心地よかったことを疑わない。連想によって得をしただけである。

音楽の心地よさ一般すら十分に説明できないこの見方が、なぜある場合に四度が五度より好まれるのか、といった個別の問題に答えられるはずもない。

3.

音の感覚を、言語と音楽の領域だけで判断するのは一面的である。音の感覚は、伝達、苦痛と快楽の表現、男女・子どもの声の区別だけでなく、話者の努力や情熱の手がかりも提供する。我々は音によって、大きい物体と小さい物体、大きい動物と小さい動物の足音を区別する。

とりわけ高い音——人間の声では生み出せないほどの——は、音の来る方向を判断するのにおそらくきわめて重要である。これら後者の機能は、動物界ではおそらく社会生活の中で役割を果たすようになった機能よりも古いのである。

4.

聴覚感覚の分析に関してヘルムホルツの業績がもたらした本質的な進歩は、誰もが喜んで認めるだろう。我々はヘルムホルツとともに、雑音を音高・強度・数が時間とともに変化する複数の音の組み合わせとして認め、**音色（Klang）**の中には基音 n のほかに倍音（部分音）2n, 3n, 4n ……を聴き取り、そのそれぞれが単純な正弦波振動に対応することを認める。

二つの音色が旋律的あるいは和声的に結合されるとき、特定の振動数比においては部分音の部分的な一致が生じ、前者の場合は音色の親近性が認められ、後者の場合はうなりの減少がもたらされる。

これらすべてを否定することはできないが、それで尽くされたとも認められない。ヘルムホルツの聴覚器官の生理学的理論——振動数の系列に対応する神経末端器官の系列が存在し、異なる振動数には異なる末端器官が応答する——にも同様に賛意を表することができる。

5.

雑音を探るための特別な聴覚器官を求めることは、ヘルムホルツとともにすべての雑音が持続の長短はあれ音の感覚に分解できると考えるなら、当面は不要に思われる。

雑音（特に衝撃音・爆発音）と音の関係について私は以前から取り組み、両者の間にあらゆる移行が存在することを見出した。128回の完全な振動の音を回転円盤の小さな窓を通して聞くと、2〜3振動にまで持続が減ると音高が非常に不明瞭な短い乾いた打撃（弱い衝撃音）に縮まるが、4〜5振動ではまだ高さがはっきりとわかる。逆に、非周期的な空気運動から生じる衝撃音（火花の波、爆発する酸水素気泡）にも、十分な注意を払えばある程度の音高が知覚される。

大きな爆発する気泡は主に低い弦を、小さな気泡は高い弦を共振させることもピアノの実験で容易に確認できる。これによって、同一の器官が音と雑音の両方を媒介しうることが示されたと考える。

6.

ヘルムホルツの理論の不完全性を指摘する声も少なからずあった。かなり一般的に、協和の説明における積極的な要素が欠けていると感じられてきた。うなりがないというだけでは協和の十分な標識にはならないのである。

フォン・エッティンゲンもまた各音程に固有の積極的要素が欠落していると指摘し、音程の価値を偶然の音色（倍音の構成）に依存させることを拒む。彼は積極的な要素を、共通の基音（トニカ）への記憶——その部分音として音程の音が以前に出現した——あるいは共通の倍音（フォニカ）への記憶に見出そうとする。

批判の否定的な部分には私は完全に賛成する。しかし「記憶」は生理学的に適切ではないと思う。なぜなら、協和と不協和は表象の問題ではなく感覚の問題だからである。ただし、エッティンゲンの双対性の原理（トニカ的親近性とフォニカ的親近性）の提唱や、不協和を多義的な音として捉える見方には、貴重な積極的貢献がある。

8.

一連の調律された末端器官が存在し、振動数の増加に従って順に最大に応答すると想定し、各末端器官に固有の（特殊な）エネルギーを帰属させよう（図35）。

すると、末端器官の数だけ特殊エネルギーがあり、聴覚で区別可能な振動数もそれだけある。我々は音を区別するだけでなく、一つの系列に順序づける。三つの異なる高さの音のうち真ん中のものを直ちにそれと認識する。どの振動数が互いに近く、どれが遠いかを直接に感じる。

しかし、もっとも高い音ともっとも低い音の間にさえ、ある種の類似性が認められる。我々の研究原理に従えば、すべての音の感覚に共通の構成部分を想定しなければならない。したがって、区別可能な振動数の数だけ特殊エネルギーがあるのではありえない。

当面の事実を理解するためには、わずか二つのエネルギー——異なる振動数によって異なる比率で引き起こされる——を想定すれば十分である。具体的なイメージを持つために、もっとも低い振動数からもっとも高い振動数への移行において、音の感覚は色覚が純粋な赤から徐々に黄を混ぜて純粋な黄に至るのと同様に変化する、と考えてみよう。各区別可能な振動数に固有の末端器官がある、という考えはそのまま維持できるが、異なる器官が引き起こすのは完全に異なるエネルギーではなく、同じ二つのエネルギーが異なる比率で引き起こされるのである。

9.

では、なぜ同時に鳴る多くの音が一つの感覚に融合せず、二つの異なる高さの音が中間の高さの混合音にならないのか？

おそらく事情は、空間の異なる箇所に現れる赤と黄の一連の混合色が区別されて一つの印象に合流しないのと、まったく同じである。実際、音の系列は空間の類比物の中にある——一次元の、両端が閉じた空間であり、対称性のない空間――上から下への垂直線、あるいは正中面内を前から後ろへ走る直線に似た空間である。

色は空間の点に拘束されず移動しうるから、空間感覚と色覚を容易に分離できる。しかし音の感覚ではそうではない。特定の音の感覚は、その一次元空間の特定の場所にしか現れえず、当該の音を明瞭に知覚するためにはその場所を**固定（注視）**しなければならない。

10.

空間上の点を固定することと音を固定することとの間の類比を、私は繰り返し実験によって示してきた。

同じ二つの音の組み合わせも、一方を注意するか他方を注意するかで、異なって聞こえる。いくらかの練習を積めば、和声をその構成部分に分解し、個々の音を聞き分けることができる。

とくに驚くべきは、和声の中で注意していた音が消えたときの現象である。注意は次に近い音に滑り移り、その音がまるで今打鍵されたかのような明瞭さで浮かび上がる。この印象は、仕事に没頭しているとき、意識から完全に消えていた振り子時計の一様な音が突然聞こえてくるときの印象にきわめて似ている。

和声の進行も、どの声部を注視するかによってまったく異なって聞こえる。上声を注視すれば音色だけが変わるように聞こえるが、低音を注視すれば音の塊全体が下降するように感じられる。これらの観察は、装飾紋様のあるときこの点、あるときあの点を注視したときに変わる印象を、生き生きと想起させる。

さらに、ハルモニウムの一つの音を数分間持続的に鳴らし続けると、注意が自然にさまよい、すべての倍音が完全な明瞭さで浮かび上がってくる。これはある音に対する聴覚の疲労を示唆している。

11.

以上の見方では、次の重要な事実がなお理解されないままであり、より完全な理論はこれを必ず説明しなければならない。

二つの異なる音を出発点として、同じ振動数比で進行する二つの音列を聞くと、我々は両者の中に同じ旋律を、空間において幾何学的に相似かつ相似に配置された形象に同じ形を認めるのとまったく同じ直接さで認識する。 異なる調にある同じ旋律は、同じ音の形、あるいは相似な音の形象と呼ぶことができる。

すでに二つの音だけの列においても、振動数比の同一性が直ちに認識される。c–f、d–g、e–a 等々——すべて振動数比 3:4 を持つ——は、すべて等しい音程として、すべて四度として直ちに認識される。これが事実のもっとも単純な形である。

音程を覚え再認することは、音楽の初心者が最初に身につけなければならないことである。E・クルケの報告によれば、P・コルネリウスは各音程で始まる楽曲を覚えさせるという独創的な教授法を用いた。四度を聞くと、それがタンホイザー序曲の始まりでありうることに即座に気づき、それによって音程を同定する、というわけである。

旋律的にも和声的にも、単純な振動数比にある音は、(1) 心地よさと (2) その比に固有の感覚の二点で際立つ。心地よさについては、部分音の一致と（和声的結合における）うなりの減少で部分的に説明できることは否定できない。

しかし、そのほかに音と音の間に**一種のコントラスト（対比）**が存在するように思われる。一つの滑らかな持続音は、均一な色で周囲全体が包まれるのと同じく、つまらないものである。第二の音、第二の色が加わってはじめて活気が生まれる。音を連続的に滑らせるとコントラストは消える。しかし離れた音の間にはコントラストがあり、直接に隣接する音の間だけでなく、前後の音脈の間にも及ぶ。

12.

各音程に固有の特徴的な感覚は、これまでの理論で説明できるだろうか？

基音 n がその三度上の m と旋律的・和声的に結合されるとき、ヘルムホルツの理論によれば、すべての三度結合に共通するのは、第一の音の第5部分音（5n）と第二の音の第4部分音（4m）の一致である。しかし、C と E を結合したとき一致するのは e であり、F と A を結合したとき一致するのは a である。つまりまったく異なる音が一致しているのだ。

各区別可能な振動数に固有の特殊エネルギーを想定する限り、すべての三度結合に共通する感覚上の構成部分はどこにあるのか？ という問いに答えることはできない。

5n と 4m の一致は、物理学的に分析する悟性にとっての共通項にすぎず、感覚とは関係がない。この区別を些末事と見なしてはならない。空間的形象の生理学的類似性と幾何学的類似性を区別した問いが無用でなかったように、ここでの同時期の問いも同様に正当なのである。

13.

ここまでの議論は、一歩も後戻りする必要がないという確信をもって進めてきた。しかし以下に展開する仮説については同じ確信は伴わない。それでもこの仮説は、より完全な理論に私が要求すると信じるものを、積極的な側面からも照らし出し、説明するのに役立つだろう。

単純な組織を持つ動物にとって、それが住む媒質の微小な周期的振動の知覚が重要な生活条件であるとする。振動が速すぎ振幅が小さすぎて個々の位相が意識に上らなくても、蓄積された感覚効果を知覚することは可能だろう。こうして聴覚器官は触覚器官から発達する。

一つの共振末端器官（聴毛）は、物理学的特性によってすべての振動数には応答しないが、一つだけでなく、n のほかに 2n, 3n, 4n ……にも（はるかに弱く）応答する。振動数の全連続体が動物にとって重要になれば、少数の末端器官では足りず、段階的に調律された末端器官の系列が必要になる。コルティ器官はそうした系列と見なされている。

コルティ器官の各グリード R_n は n にもっとも強く応答するが、2n, 3n ……にもより弱く応答する。ここで各振動数に固有のエネルギーを想定するのは不可能であることはすでに示した。そこで二つのエネルギー——鈍（D：Dumpf）と明（H：Hell）——だけが、異なる振動数によって異なる比率で引き起こされると想定する。

振動数 n の感覚は記号的に [1 – f(n)]D + f(n)H と表される。

しかし、コルティ器官のグリードが倍音に応答するたびに、感覚はわずかな**付加的色づけ（Zusatzfärbung）**を得る可能性が高い。これを倍音に対して Z₁, Z₂, Z₃ ……、下方倍音に対して Z₋₁, Z₋₂ ……と表そう。

14.

三度結合を例にとろう。振動数は n = 4p, m = 5p で、もっとも低い共通倍音は 5n = 4m = 20p、もっとも高い共通下方音は p である。

このとき、三度に特徴的な付加感覚 Z₅ と Z₄（および Z₋₅, Z₋₄）が現れる。これは音色に倍音が含まれていなくても生じる。倍音が存在すれば（空気中またはは耳の中で）、Z₁, Z₄ はさらに強められる。

これらの付加的色づけは、単独の音や連続的に滑る音ではほとんど気づかれないが、特定の振動数比を持つ音の組み合わせにおいて際立って現れる——ちょうど、弱く着色されたほとんど白い光どうしのコントラストが、その組み合わせにおいて生き生きと顕在化するように。しかも、同じ振動数比にはどの音高においても常に同じコントラスト的色づけが対応する。

こうして、音が旋律的・和声的に他の音と結合されることで、単独の音にはない多彩な色づけを得る仕組みが理解される。

15.

以上の見方を概観すると、ヘルムホルツの業績によって確立されたことのほとんどすべてが保持されうることがわかる。雑音と音色は音に分解される。各区別可能な振動数に固有の末端器官が対応する。ただし、多数の特殊エネルギーの代わりにわずか二つを置き、それによってすべての音の感覚の親近性が理解可能になる。注意に割り当てた役割によって、同時に鳴る複数の音は依然として区別可能である。

コルティ器官の各グリードが複数の振動数に応答するという仮説と「付加的色づけ」によって、偶然の音色の役割は退き、音楽的な事実に基づいて音程の積極的な標識をさらに追究する道が開かれる。最後に、この見方によって、エッティンゲンの双対性原理にも一つの土台が与えられるだろう——ただし、双対性が完全な対称性たりえない理由も同時に示される。

16.

進化論の立場から見ると、現代の音楽がその高度な発達において、また突然自発的に現れる音楽的才能は、一見きわめて奇妙で謎めいた現象である。この聴覚の発達は種の保存と何の関係があるのか？　必要なもの、あるいは有用なものを遥かに超えてはいないか？

実はどの芸術についても同じ問いを立てることができる。音楽に関してもっとも問いは身近であるが、それはこの芸術が何の実際的な必要も満たさず、何も描写しないことが多いからである。

しかし、音楽にきわめて近い関係にあるのが装飾である。見るためには線の方向を区別できなければならない。精密に区別できる者には、いわばその能力の副産物として、線の組み合わせの美しさへの感覚が生まれうる。色彩の調和に対する感覚が色の区別力の発達後に生まれるのと同様に、音楽もまた同じ仕組みで生じたのだろう。

才能や天才と呼ばれるものも、その効果がどれほど大きく見えても、正常からのわずかなずれにすぎないことを忘れてはならない。ある領域でやや大きな心的力を持つことが才能であり、適応の自由——定型に囚われないこと——が幼年期を超えて保たれることで天才に高められる。ヴァイスマンが的確に指摘したように、才能と天才は世代を通じて徐々に現れるのではなく、自発的に突然現れる。したがって、先祖の積み重ねた練習の結果ではありえない。子孫は先祖とまったく同じではなく、同じ性質をやや弱めたりやや強めたりして変異的に示す——このことと合わせて考えれば、これもまた理解される。

（第7章 終わり）

第ⅩⅣ章　以上の研究が物理学の把握に及ぼす影響
1.

これまでの研究から物理学はどんな収穫を得るのか？

まず、ある広く行きわたった偏見と、それに伴う障壁が取り払われる。

心的なものと物理的なものの間に溝はない。内と外はない。感覚に対して、それとは異なる外的な「物」が対応しているのでもない。 存在するのはただ一種類の要素であり、それが見かけ上の「内」と「外」を構成している。その要素は、ただそのときどきの観点に応じて、内にも外にもなるのである。

2.

感覚的世界は、物理学的領域と心理学的領域に同時に属する。

気体の研究で温度変化を無視すればボイルの法則に、温度変化を明示的に考慮すればゲイ＝リュサックの法則に到達するが、研究対象自体は同じであるように、我々は身体（Leib）を完全に度外視して感覚世界の連関を研究する限り（もっとも広い意味での）物理学を行い、身体、特に神経系に主な注意を向ければ感覚の心理学を行っている。

我々の身体は他のあらゆるものと同様に感覚世界の一部であり、物理的なものと心理的なものの境界は単に実際上・慣習上のものにすぎない。より高い科学的目的のためにこの境界を存在しないものと見なし、すべての連関を等価と見なせば、新しい研究の道が開かれないはずはない。

3.

さらなる収穫として、物理学者はもはや従来の知的手段に気おされなくなる。日常的な「物質」がすでに感覚的要素の複合体に対する無自覚的・自然的な思考記号にすぎないとすれば、物理学と化学の人為的・仮説的な原子や分子にはなおさらそのことが当てはまる。

これらの手段にはその特定の限定された目的のための価値がある。それらは経験の世界の経済的な記号化にとどまる。代数の記号から、そこに入れた以上のものを期待しないように、これらの記号からも、経験そのものが与える以上の啓示を期待してはならない。

物理学の領域内でさえ記号の過大評価は避けられる。まして、心理的な過程の説明に原子を使おうなどという途方もない考えが、我々をとらえることはありえない。

4.

諸科学は素材によっても、素材の扱い方によっても区別される。しかしすべての科学は、事実を思考の中に再現すること——それが実際的な目的のためであれ、知的な不快感の除去のためであれ——を目指している。

「予備考察」（第1章）の記号を使えば、α β γ ……（思考・表象・意志）によって他の要素の連関が模写されるときに科学が成立する。例えば、A B C …… の相互関係の模写がもっとも広義の物理学を、A B C …… と K L M …… の関係の模写が感覚の生理学ないし心理学を、K L M …… 相互の関係の模写が生理学を、α β γ …… の α β γ …… による模写が狭義の心理学を生む。

物理学においては感覚的事実の提示よりも原子・力・法則が重要だという見解もありうる。しかし、素直に考えれば、我々の実際的・知的な欲求は、感覚的事実を思考で再現できた時点で完全に満たされる。この再現こそが物理学の目的であり、原子・力・法則はその再現を容易にする手段にすぎない。手段の価値はその助けの範囲に尽きる。

5.

我々はある自然の過程——例えば地震——について、思考が関連する感覚的事実の総体をあたかもその代替として提示できるほどになったとき、可能な限り完全に知っているのである。思考の中で地下の轟音を聴き、揺れを感じ、床の上下動の感覚を知り、壁のひび割れ、漆喰の剥落、家具や絵の動き、時計の停止、窓の割れを見、森を通り過ぎる波を、粉塵に包まれた街を、鐘の鳴る塔を心に描き、地下の過程もまた——現在はまだ未知であるが——感覚的に目の前に現れ、地震が遠くの馬車のように近づいてくるのを見、ついに足下の揺れを感じる。それ以上の洞察は求められない。

部分的事実を正しい規模で組み合わせるためにある種の（数学的な）補助表象が必要だとしても、それらは思考の力で一度にはできないことを段階的に可能にするためのものにすぎない。最終的に感覚的事実に到達できなければ、補助表象は無価値である。

すべての補助表象、法則、公式は、我々の感覚的表象の量的な規整にすぎず、感覚的表象が目標であり、それらは手段である。

6.

思考の事実への適応——これこそがすべての自然科学的営為の目標である。科学はただ、日常生活の中で自然に行われていることを、意図的かつ意識的に続けるにすぎない。

自己観察が可能になった時点で、我々の思考はすでに多くの点で事実に適応しているのを見出す。しかし限られた思考の蓄えは、絶えず増大する経験には足りない。ほとんどすべての新しい事実が、適応のさらなる継続をもたらす。それが判断の過程に表れる。

子どもがはじめて街から田舎の大きな草原に出て、四方を見回し、驚いて言う。「私たちは球の中にいる！」「世界は青い球だ！」——ここに二つの判断がある。「私たち」（付き添いの人々）という既成の感覚的表象が、同じくすでに持っていた「球」の表象によって一つの像に補完される。判断とは常に、ある感覚的表象を、感覚的事実の導きのもとに、別の感覚的表象によってより完全な事実描写へと補完することなのである。

自然科学と数学の成長は、大部分こうした直観的認識——ロックがそう呼ぶもの——の形成に基づいている。

7.

直観的認識は記憶に刻まれ、新たな感覚的事実に対して自発的に補完する記憶として現れる。異なる事実は互いに完全には一致しないが、共通する構成部分は強化される。ここに、できうる限りの一般化（連続性）の原理が記憶の中に入り込む。他方、事実の多様性に応えるには、記憶は十分な分化の原理にも従わねばならない。

動物でさえ、鮮やかに赤や黄に色づいた柔らかい果実は甘い味を想起させ、緑で硬い果実は酸っぱい味を想起させる。昆虫を追う猿はぶんぶん飛ぶものに何でも飛びかかるが、黄と黒の縞のある蜂は避ける。物理学者が「すべての透明な固体は空気から入る光を法線の方へ屈折させる」と一般化し、「正方晶系および非晶質のものは単屈折、それ以外は複屈折する」と分化的に付加するのも、まったく同じ営みである。

8.

思考の適応の大部分は、感覚的事実の導きのもとに無意識的・不随意的に行われる。この適応が、出現するほとんどの事実に対応できるほど広くなったところで、習慣化した思考の流れと激しく矛盾する事実に遭遇し、しかもただちに新たな分化へ導く決定的な契機が見出せないとき——問題が生まれる。

新しいもの、異常なもの、驚くべきものは、注意を引きつける刺激として働く。実際的理由や知的な不快感だけが、矛盾の解消への意志を、新たな思考適応への意志を生み出しうる。こうして意図的な思考適応、すなわち研究が生まれる。

9.

抽象するとは何をしているのか？　概念とは何か？　概念には感覚的な表象像が対応するのか？

「一般的な人間」を思い浮かべることはできない。「一般的な三角形」——直角三角形でもあり正三角形でもあるようなもの——は表象不可能である。しかし、概念の名前とともに浮かぶ像は概念ではない。多くの個別表象に対して窮余の策として同一の語が使われているからといって、それは概念をなさない。

概念を事実に適用するとき、事実は我々に対して、ある感覚的活動への単純な衝動として作用する。その活動が、それまで存在しなかった新しい感覚的要素をもたらし、それが我々のその後の思考の流れを事実に対応して規定する。我々は活動を通じて、貧弱すぎる事実を豊かにする。化学者が無色の塩溶液に特定の操作を加えて黄色や褐色の沈殿を引き出し、それが思考の流れを分化させるのとまったく同じである。

物理学者の概念は、ある特定の反応活動であり、それが事実を新しい感覚的要素で豊かにするのである。

10.

てこを見たとき、腕を測り、重さを量り、腕の長さと重さの積を求めるよう駆り立てられる。二つの積が同じ数字を示せば、均衡を期待する。以前は事実そのものに含まれていなかった新しい感覚的要素が獲得され、それが思考の流れを分化させる。

概念的思考が練習を要する反応活動であることを心に留めれば、数学や物理学やいかなる自然科学も、実際の練習なしに読書だけで身につけることはできないという周知の事実が理解される。理解することはまったく行為することにかかっている。

事実は概念的な処理によって拡張され豊かにされ、最終的にはまた単純化される。すべては、直観的認識の場合と同様に、決定的な感覚的要素の発見・強調・抽出に帰着する。研究はただ、直観的認識に直接与えられるものに、迂回によって到達するのである。

11.

感覚的事実は、物理学者のすべての思考適応の出発点であり、また目標でもある。事実にすぐに追随できないとき、もっとも力強く馴染み深い思考が押し寄せ、事実をより豊かで確定的なものにしようとする。すべての自然科学的仮説と思弁はこれに基づいており、その正当性は、仮説が促進し最終的にもたらす思考適応にある。

そうして我々は惑星を投射体と考え、帯電体を遠隔作用する流体に覆われたものと考え、熱を物体間を流れる物質と考える——やがて新しい事実が、補助として引き合いに出した古い事実と同じくらい馴染み深くなるまで。

直接的な直観性が問題にならない場合でも、物理学者の思考は連続性の原理と十分な分化の原理を最大限に守りつつ、少なくとも最短の迂回で直観性に到達しうる、経済的に秩序づけられた概念反応の体系に形成される。

12.

思考適応の成果を概観しよう。事実のうち恒常的なものにだけ思考は適応しうるのであり、恒常的なものの模写だけが経済的な利益をもたらす。ここに、思考の連続性への努力、すなわちできうる限りの恒常性の維持への努力の究極的な根拠がある。

13.

無条件に恒常的なものを我々は実体と呼ぶ。物体を見たいときに見え、触りたいときに触れることで、その要素の複合体が常に存在しているものと見なし、瞬間的に感覚に現れなくても、思考記号を常に準備しておくことで、予見の利益と、驚きの不利益の回避を得る。

太陽や月のように触れないもの、一度しか見られないかもしれない大陸、記述からしか知らない土地に対してさえ、同じように恒常性を帰属させる。さらに一歩進めて、過去全体——その痕跡はまだ存在する（何千年も前にあった場所で星が見える）——も未来全体——その萌芽はすでに存在する——も恒常的と見なすこともできる。時間経過全体が、我々の感覚の条件に拘束されているにすぎないのだから。

14.

しかし、真に無条件な恒常性は存在しない。 条件を見落とし、過小評価し、あるいは常に与えられたものと見なし、あるいは意図的に度外視することで恒常性に到達しているにすぎない。

あらゆる場合に通用する恒常性はただ一つ——結合（関係）の恒常性——だけである。自然科学の命題の大多数は、こうした結合の恒常性を表現している。「オタマジャクシはカエルになる。塩化ナトリウムは立方体の結晶形をとる。光線は直進する。物体は gt²/2 で落下する。」これらの恒常性の概念的表現を我々は法則と呼ぶ。

力（力学的な意味での）もまた結合の恒常性にすぎない。「物体 A が B に力を及ぼす」とは、B が A に対面すると直ちに一定の加速度を示す、という意味にほかならない。「力なき物質なし、物質なき力なし」という文句は、自ら招いた矛盾を徒に解消しようとするものであり、結合の恒常性だけを認めれば不要になる。

15.

環境の十分な恒常性に応じて、思考にも対応する恒常性が発達する。この恒常性のおかげで、思考は半ば観察された事実を自発的に補完しようとする。この補完衝動は、個々の事実から生じたものでも、意図的に作り出されたものでもない。我々は自分の関与なしにそれを自分の中に見出す。

この衝動は、経験によって発達してきたものではあるが、個々の経験以上のものを含んでいる。この衝動によって事実は豊かにされ、我々には未経験者が個々の事実だけで持つよりも、常により大きな自然の一片が視野に入っている。思考とその衝動を持つ人間もまた自然の一片であり、個々の事実にみずからを付加するのだから。

しかし、この衝動に無謬性の権利はなく、事実がそれに従わねばならない必然性もまったく存在しない。我々の信頼は、十分に適応してきた思考への信頼にとどまり、その信頼はいつでも裏切られる可能性に備えていなければならない。

我々はより恒常性の低い思考をより恒常性の高い思考で支え、強化し、置き換えようとする。ニュートンがケプラーの法則がすでに知られている惑星を投射体として考えるように、月から引かれるものとして潮汐を考え、大気圧をつけ加えてサイフォンの流れを理解しようとする。こうしたより弱い思考をより強い思考で支える欲求が因果性への欲求と呼ばれ、すべての自然科学的説明の主たる推進力である。

基盤としてもっとも強く、もっともよく検証された思考が選ばれるのは当然であり、それは我々のはるかに訓練された力学的な営みが提供するものである。ゆえに力学的説明の権威がある。さらに高い権威が数学的思考に帰属する。外的手段をほとんど必要とせず、実験材料を大部分自分自身の中に持ち運んでいるからである。

16.

ある要素の複合体の中でいくつかの要素が他に置き換えられると、一つの結合の恒常性が別の恒常性に移行する。この交替を貫く恒常性を見出すことが望ましい。J・R・マイヤーがこの欲求をはじめて感じ、彼の「力」（＝エネルギー）の概念を立てることでそれに応えた。

マイヤーはこのエネルギーを絶対的に恒常的なもの（蓄え、あるいは物質のようなもの）と表象し、もっとも強く直観的な思考にまで遡る。最初の二つの論文では表現との格闘と一般的哲学的常套句が見られ、まずは不随意的・本能的に強いこの概念への欲求が彼に迫ったことがわかる。しかし、既存の物理学的概念を事実と自らの欲求に適応させたことによって、偉大な業績が成し遂げられたのである。

17.

思考が十分に適応すれば、事実は自発的に思考によって模写され、部分的に所与の事実が補完される。物理学は量的な規整としてのみ機能し、自発的に進む思考を、実際的あるいは科学的な必要に応じて、より確定的にするのである。

18.

幾何学者の空間は、空間感覚（視覚と触覚の空間）の単なる体系ではない。それは空間感覚に結びつく多くの物理学的経験から成り立っている。幾何学者がその空間をあらゆる場所とあらゆる方向において同質と見なすとき、すでに触覚と視覚が与える空間——この単純な性質をまったく持たない——をはるかに超えている。物理学的経験なしにはそこに到達しえない。

幾何学（および数学全体）の説得力は、特殊な認識方法で得られるところにあるのではなく、その経験材料がとりわけ手軽に利用でき、とりわけ頻繁に検証され、いつでも再検証できるところにのみある。空間経験の領域は経験全体に比べてはるかに限定されており、その本質を尽くしたという確信がすぐに生まれ、必要な自信を生む。

同様の自信を、作曲家は音の感覚の領域で、装飾画家は色の感覚の領域で持っている。数学者、作曲家、装飾画家、そして思弁に身を委ねる自然研究者は、素材と目的が異なるにもかかわらず、まったく類似した仕方で行動している。

19.

物理学者の時間は、時間感覚の体系とは一致しない。物理学者が時間を測るとき、振り子の振動や地球の自転など、同一あるいは同一と前提された過程を尺度として当てる。時間感覚に結びつく事実に反応が加えられ、その結果得られる数が、時間感覚の代わりに思考の流れをより正確に規定する。温度感覚も体の温もりの感覚ではなく、温度計の反応（水銀柱の読み取り）に置き換えられる。

ある物理的量の変化を他の量の変化と結びつける方程式から時間を消去すれば、要素は単に相互依存的に現れる。しかしその方程式の意味を確定するには、例えば落下距離は増大するもの、温度差は減少するものとして順に代入しなければならない、と付記しなければならない。時間は不可逆である。 暖かい物体は冷たい環境では冷えるだけで暖まらない。炎は家を燃やし、建てるのではない。植物は地中に潜るのではなく、成長する。

時間の不可逆性という事実は、物理的量の値の変化がある定まった方向にだけ起こるということに帰着する。二つの分析的可能性のうち、一方だけが現実的なのである。ここに形而上学的問題を見る必要はない。

（第8章・最終章 終わり）

エルンスト・マッハ『感覚の分析への寄与』（Beiträge zur Analyse der Empfindungen, 1886年）全8章　和訳完了

第ⅩⅤ章　ここで述べた見解の受容
1.

本書の初版が出版されたのち、これに対する意見は大きく分かれた。認められたのは大多数の場合に個別的な論点であったが、そこに導いた根本的な見方はたいてい退けられた。公にされた批判は——私の知りうる限りでは——否定においても穏当で、その率直さは私にとってたいへん教えられるものだった。

R・アヴェナリウスの後年の出版物が、私の著作に対する判断にも好ましい影響を及ぼしたことは否めない。専門の哲学者が、詳細で体系的な叙述において、自然科学者のもとでは容易に理解しうる素人的な逸脱と見なされがちであった立場を基礎づけたことは、考えさせずにはおかなかったのだ。アヴェナリウスの弟子たちや、独自の道で私に接近した若い研究者たちが、今日では力添えをしてくれている。

それにもかかわらず、批評家たちは——少数の例外を除いて——また、私の基本思想を正しく紹介し、確かに理解しているはずの者たちさえ、重大な懸念を払拭できないでいる。これは無理からぬことである。読者の可塑性には非常に大きな要求が突きつけられるからだ。 ある思想を論理的に把握することと、それを心から受け入れることは別物である。論理の整序・単純化機能が発動するのは、心的生活がすでに発達の途上で遠くまで進み、本能的な獲得物の豊かな蓄えを持ってからのことであり、この前論理的・本能的な蓄えに対しては、論理の道ではほとんど太刀打ちできない。

問題はむしろ心理学的な変容の過程であり、それは私自身の経験に照らしても、若い時代にさえかなり困難なものである。したがって、すぐに同意を期待するのは僭越というものだろう。私はただ、偏見なしに耳を傾けてもらえるだけで満足する。

2.

我々が自分に力みをかけなければ、地球は静止し、太陽と恒星の天球が動いているように見える。この見方は、日常的な実用的目的には十分であるだけでなく、もっとも単純でもっとも有利でもある。しかし、特定の知的目的のためには反対の見方がより好都合であることが確認された。二つの見方はそれぞれの領域で等しく正しく適切であるが、後者は本能的な抵抗に逆らって、長い闘いの末にようやく自らを貫くことができた。

太陽の上に立って自分を観察者と考えよという要求は、しかし、自分の自我を無にして、それを変転する要素の一時的な結合として解消せよという要求に比べれば、ほんの些細なことである。 しかし、この後者の見方はさまざまな方面から長い間準備されてきた。我々は「自我」と呼ばれる統一体が受胎によって生まれ、死によって消滅するのを見ている。それが以前から潜在的に存在し、以後も存続するという虚構は、今日ではすでに突飛なものである。

心理学と精神病理学は、自我が成長し豊かになりうること、貧しくなり萎縮しうること、自分自身に疎遠になり分裂しうること——つまり生きている間にすでに著しく変化しうることを教えている。それにもかかわらず、自我は本能的な把握にとってもっとも重要でもっとも恒常的なものである。あらゆる経験の紐帯であり、あらゆる活動の源泉なのだから。

同様に、剛体も素朴で本能的な把握にとっては非常に恒常的なものである。しかしそれが分割され、溶解され、化学的に結合されると、恒常性の数は増減する。そのとき、慣れ親しんだ考えを無理に維持しようとすれば、潜在的な恒常性を仮定して原子論に逃れるのである。

実際の生活においては、自我の表象も物体の表象も、手放すわけにいかない。 生理学的には我々はエゴイストであり唯物論者であり続ける——太陽が常に昇るのを見るように。しかし理論的には、この見方を固持する必要はない。試みに変えてみよう！ そこから洞察が得られれば、やがて実際的な成果も生まれるだろう。

3.

かつてカントの影響のもとに立ち、観念論的な立場を取り、物自体の思想を最後の痕跡まで振り払えなかった者には、ある種の唯我論への傾きが残る。哲学的思索者は、原理的に解きえない自我の問題をすべての出発点とする。

思弁的哲学者が「唯我論こそ唯一の首尾一貫した立場である」と言うとき、閉じた完全な世界観体系への渇望から理解できる。同じく首尾一貫しているのは唯物論だ——物質こそ唯一の直接与えられた、解明不要の実在だと信じる者にとって。すべての体系はそうなのである。

しかし、自然科学者がそう言うなら、驚きを禁じえない。自然科学者は完成された世界観を求めない。 自分のすべての仕事が洞察を広げ深めうるだけだと知っている。彼にとっていかなる問題も、さらなる深化を要しないほど完全に解かれたものはなく、絶対に解けないと見なすべきものもない。

唯我論に傾く自然科学者は、温度計が世界の根本問題だと信じる物理学者に似ているだろう——膨張と熱の関係がまだ完全には見通されていないという理由で。あるいは、振り向くことをやめてしまった人間に似ている——見えるものはどうせ常に「自分の前」でしかないのだから、と。

「マッハの哲学」なるものは存在しない。 あるのはせいぜい、自然科学の方法論であり、諸科学の相互接続のためのプログラムにすぎない。

4.

私を、繰り返しの抗議にもかかわらずバークリーと同一視する者は、私の見解の正しい評価から非常に遠い。バークリーは「要素」をそれら自体の外にある未知のもの（神）によって条件づけられたものと見なす。カントはそれに代えて「物自体」を発明した。ここで述べている見解は、要素の相互依存によって、実際的にも理論的にもやりくりできると考える。

私に対して、思考の「自立した法則性」と「自発性」をまったく見落としていると非難する者もいる。しかし感覚に対してさえ我々は受動的にだけ振る舞うのではなく、感覚は生物学的反応を引き起こし、その自然な延長が思考の事実への適応にほかならない。この適応が直ちに完全に成功すれば、過程はそこで終わるだろう。しかし、不完全に適応した複数の思考が互いに矛盾するので、生物学的過程が続行される。これが、私が思考の相互適応と呼んだものである。科学的発展のどの過程が、論理を含めて、これに包含されないというのだろうか。

5.

多くの読者にとって、私の見方における世界は混沌に、もつれた要素の織物に見えるらしく、統一的な導きの視点が欠けていると感じるようだ。

これは本書の課題の誤解に基づいている。諸専門科学と哲学的世界考察のすべての価値ある視点は引き続き使用可能であり、私もそれらを用いている。一見すると破壊的に見える傾向は、もっぱら我々の概念への不要な、ゆえに誤解を招く付加物に向けられているのである。私は、心的なものと物理的なもの、主観と客観の対立を本質的なものに正しく還元し、同時に伝統的な迷信的見方から浄化したと信じている。

私はまた、悲壮にあるいは敬虔に嘆くような「イグノラビムス（我々は知らないだろう）」を、知るに値するもの・認識可能なものからの自己満足的な頑迷な背反で置き換えようというのでもない。無意味と認識された問いの回答を断念することには、いかなる諦めもない。 物理学者は永久機関を探さなくなっても、数学者は円の求積や五次方程式の代数的一般解を求めなくなっても、そこに諦めを見ないだろう。より一般的な哲学的問いにおいてもそれは同じである。問題は解かれるか、あるいは虚偽と認識されるかである。

6.

自然科学者も専門哲学者も、要素（感覚）からなる私の世界を空気のように軽いものと感じるらしい。私が物質を、感覚的要素の比較的安定した複合体に対する思考記号と見なすことは、軽視的な把握だと言われる。外界は感覚の総和としては十分に把握されておらず、少なくともミルの「感覚の可能性」を導入すべきだ、と。

これに対して述べなければならない。私にとっても世界は感覚の単なる総和ではない。 私は明確に要素の**関数的関係（Funktionalbeziehungen）**について語っている。それによってミルの「可能性」は不要になっただけでなく、はるかに堅固なもの——数学的な関数概念——に置き換えられたのである。

7.

もう一つの懸念は「マッハの哲学的見解のどこに誤りあるいは一面性があるのか？」と問うた、ある批評家の穏やかな問いに表れている。

私は、自分の叙述が複数の方向でなお非常に不十分であることを確信している。しかし、これほどの根本的な変容過程は、一つの頭の中で完全に遂行されることはありえない。私はその欠陥を感じはするが、指し示すことはできない。批評家たちの著作からも、それは私には明らかにならなかった。もう少し待とう！

8.

哲学者に私の基本思想をいつか納得させられるかどうかは、さておくほかない。あらゆる時代の偉大な哲学者たちの巨大な知的労働に対するすべての敬意をもってしても、これは当面はさほど重要ではない。

私が心から切に願うのは、自然科学者との相互理解であり、これは達成可能だと考えている。 自然科学者諸氏に考慮していただきたいのは次のことだけである。私の見方はすべての形而上学的問いを排除する——それらが現時点では解けないと見なされるにせよ、そもそも永久に無意味だと見なされるにせよ。

さらに考慮していただきたい。我々が世界について知りうることはすべて、必然的に感覚的要素において表現されるのであり、それらは正確に指定可能な仕方で観察者の個人的影響から解放されうる。我々が知ることを望みうるすべてのことは、数学的な形式の課題の解——すなわち感覚的要素の相互の関数的依存性の解明——によって提供される。 この認識によって「現実」の認識は尽くされる。

もっとも広い意味での物理学と自然科学的心理学の間の橋渡しをなすのは、まさにこれらの同じ要素であり、それらは研究される連関に応じて物理的対象でもあり心理的対象でもあるのだ。

9.

多くの、おそらく多くの生理学者が、ある個別問題における私の立場に異を唱えているかもしれない。これについてもう数言述べたい。

S・エクスナーのような研究を私は高く評価し、心的現象に関する多くの重要な問いが、中枢器官の神経結合の探究と興奮の量的段階づけへの注目だけで解決しうると信じている。しかし主要な問題は私にとって未解決のまま残る。 すなわち、感覚の質的多様性が、結合の変異と単なる量的差異だけからいかにして生じうるのか、ということは、私の立場からは理解できない。

私はかつて、フェヒナーの精神物理学に鼓舞されてこの問題に取り組んだが、ヘルムホルツの電信線理論（神経は電流を伝導するだけという理論）を説明したのち、こう述べた。「しかし、神経における電気的過程が、異なる感覚の質を説明するにはあまりに単純であるとしたらどうか？　脳全体を調べ尽くしてもいたるところに電流しか見出さなかったとしたら？　特定の強度の電流は、その断面を単位時間に通過する一定量の運動エネルギーがあるということしか教えてくれない。その運動エネルギーを担っているのがどのような過程であり分子運動であるかは、我々には分からない。同じ電流強度の根底には、もっとも多様な過程が存在しうるのだ。」

この考えを私は今日まで手放すことができず、本質的には今もなお同じように根拠づけなければならない。生理学的化学の進歩、電解質中の異なる電流についての知見、さまざまな器官の移植に関する経験は、今日ではいっそう決定的にこの考えを支持しているように思われる。

（改訂版 第ⅩⅤ章 終わり）

補遺（Zusätze）——各章への追加注記

改訂版では、初版の各章に版を重ねるごとに脚注と補注が追加された。以下は巻末にまとめて収録されている補遺（Zusätze）全21項目の和訳である。各補遺には、対応する本文ページと章が示されている。

補遺1（第Ⅰ章 p.30 に対して）

当面は実際的な目標だけを追求している人間——そういう人間は学者であることも、研究する物理学者であることも、当座は批判的であろうとしない哲学者であることさえもある——は、自分の活動を自動的に導いてくれる本能的に獲得された自然的世界観を、あえて放棄する必要はない。普通の人間と同様に、つかめるもの、秤に載せられるもの、調べたいものについて語り、それに従って行動すればよい。

しかし、自分の感覚の意味について、物理的なものと心理的なものの関係について考えようとするならば、次のことをよく考えなければならない。すなわち、感覚的要素の他の感覚的要素への依存関係の種類の違いだけが、自分の身体を他の環境構成要素から区別させているのだということを。物質について、世界について我々が知っていることは、ひとりの人間のまた複数の人間の感覚的要素の関数的結合を表しているにすぎない。特定の条件のもとでこの人あるいはあの人の感覚的要素や意識内容に影響を及ぼしえないものは、何ものも現実ではない。

我々が経験したことは、記憶・表象を残す。しかし、熱く・明るく・ちらちらと感じられたものは炎であり、湯も沸かせる。一方、熱く・明るく・ちらちらと表象されたものでは、当面は環境の中で何も成し遂げられない。前者では心的なものと物理的なものが一致するが、後者では関係がより緩い——しかし断たれてはいない。表象もまた物理的なものと同様に現実である。例えば、それが私をお茶を入れるために火を起こす気にさせるときのように。

補遺2（第Ⅱ章 p.32 に対して——盲点について）

p.32の考え（盲点には問題がそもそも存在しない）は単純で素朴に見えるが、徹底的に期待を裏切ることがある。A・ブリュックナー博士は美しい実験的研究によって、盲点が、そこに投影された像の消失だけでなく、コントラスト、残像、そして他の網膜部分から送り込まれる積極的な感覚内容による埋め合わせによっても可視化されうることを示した。もっとも見事な現象は、白と黒の直線的な境界が盲点を通過するときに現れる。

補遺3（第Ⅰ章 p.37 に対して——関数概念について）

A, B, C … がまだ質的な標識しか意味せず、互いに規定し合い制限し合い依存し合っているだけの段階では、方程式や関数はまだ象徴的な意味でしか語れない。この関係の明確化のためには、本書 p.21-22、p.281（第8段落）、p.300（第2段落）、および『認識と誤謬』p.278-323の叙述を参照されたい。

補遺4（第Ⅲ章 p.45 に対して——心的エネルギーについて）

C・シュトゥンプフ（ミュンヘン国際心理学会議の開会講演、第3版、1909年、p.18）や W・オストヴァルト（『自然哲学講義』1902年、p.74, 377以下）は、特別な心的エネルギーの仮定を行っている。これについては『認識と誤謬』（第2版、p.43）で意見を述べた。ここでさらに指摘したいのは、エネルギーは計量概念であり、質的な過程が問題となる心理学の領域では助けにならないということだ。

補遺5（第Ⅳ章 p.51 に対して——心身平行論について）

私はフェヒナーの当初の平行論から出発した。しかし、心的なものと物理的なものを一つの第三のものの二つの側面として見る考え方も、私はそれほど蔑むべきものとは思わない。精神主義と唯物論の思慮深い妥協がそこにあり、さらなる科学的帰結へ導きうるものだ。これを「同一の過程の二つの観察様式」と言い換えれば、いかなる自然科学者もこの定式にもはや異論は唱えないだろう。

私の特殊な応用はフェヒナーを超えている。 私は心的なものとそれに対応する物理的なものとの間に、形の類似性・形の親近性を探求するのである。

補遺6（第Ⅴ章 p.73 に対して）

パウル・イェンゼン著『有機的合目的性——生理学の立場からの発達と遺伝』（イェナ、1907年）を参照されたい。ここで述べたことをはるかに超える徹底的な研究である。

補遺7（第Ⅴ章 p.81 に対して——関数概念の一般的適用について）

とりわけ C・メンガー著『社会科学の方法に関する研究、特に政治経済学について』（ライプツィヒ、1883年）を参照されたい。

補遺8（第Ⅵ章 p.85 に対して——有機体の発達について）

有機的世界の発達は最も多様な道を歩んだようだが、人間においてはとりわけ脳の発達がもっとも有利なものとして実証された。これにより他の身体形態の強い変異は不要になった（補遺18、p.251も参照）。

補遺9（第Ⅶ章 p.108 に対して——空間値の補償について）

ヒレブラント教授が現在取り組んでいる研究によれば、相対的空間値が絶対的空間値によって補償されるという命題は無条件には成り立たない。暗室で点滅する正中の光点を注視し、暗い位相の間に右側の光点に視線を移すと、正中の光点は次に現れたとき見かけの正中線の左に見える。つまり見かけの正中線は二つの光点の間にずれている。

この実験から、暗室と光点という条件のもとでは、視線移動にはやはり絶対的空間値の変化が伴うが、その量は、網膜上の像移動による相対的空間値の変化を完全に補償するのに必要な量には届かないことがわかる。通常の明るい視覚環境ではほぼ完全な補償が達成される。

補遺10（第Ⅶ章 p.112 に対して——アリストテレスの触覚実験の反転について）

ここに記述したアリストテレスの触覚実験の反転（滑らかな棒を交差した指で触る）は、私が何年も前に実施したが、『感覚の分析』の後の版で初めて記述した。R・エヴァルトは同じ目的のために張った糸を使い、指の位置への注意による結果の変容を観察し、この反転がヴィクトル・アンリの著書（『触覚の空間知覚について』、ベルリン、1898年、p.67以下）で最初に記述されたと報告している。

補遺11（第Ⅶ章 p.122 に対して——耳の迷路について）

E・フォン・ツィオンの著書『空間と時間の数学的感覚の器官としての耳の迷路』（ベルリン、1908年）を指摘しておきたい。同書の攻撃や非難に応じる義務は感じないが、読者にはその読書を楽しんでいただきたい。

補遺12（第Ⅶ章 p.147 に対して）

補遺10で挙げたヴィクトル・アンリの価値ある著書を参照されたい。

補遺13（第Ⅸ章 p.159 に対して）

『認識と誤謬』の叙述を参照されたい。

補遺14（第Ⅹ章 p.162 に対して——昆虫の心理について）

H・フォン・ブッテル＝レーペン氏からの手紙：「『かなり高い心理的発達』という表現は言い過ぎだと思います。ヴァスマン、フォレル、私はいずれも、蟻や蜂が単なる反射機械よりは遥かに高い段階にあるが、高い心理的発達を示すわけではないという点で一致しています。それは多面的ではありますが、意識の閾値以下にとどまるか、本能の縁を辿る薄明意識に伴われる程度のものでしょう。可塑性や修正能力はきわめて限定的です。もっとも、場所の記憶や学習能力などは存在します。」

私はブッテル＝レーペン氏の言葉を引用し、今回は彼に公正を期したい。なお、まったく修正不能な反射が存在するかどうかは疑わしく、反射と随意行動の違いは程度の差にすぎないと私は考えている。

補遺15（第Ⅹ章 p.184 に対して——幾何学的＝光学的形態錯覚の理論の基礎）

L・ブルメスターによる詳細な理論的考察。 幾何学的＝光学的形態錯覚は、単眼で観察された立体的対象において、遠いものが近く、近いものが遠く、凹面が凸面に見えるという特徴を持つ。理論の基本原理は次のように定式化される。形態錯覚においては、対象空間と錯覚空間の対応する点を結ぶ直線は視点を通り、中立面で交わる対応する平面は中立面と等角をなす。 この原理によって、任意の対象形態に対する錯覚形態を作図的に決定できる。

補遺16（第Ⅹ章 p.188 に対して——視覚過程の新理論）

シュテーアは組織学的研究に基づき、視覚過程についての見解を修正した。シェフラーの理論（視細胞の移動）に賛同しつつ、この移動のメカニズムをも解明しようとしている。視覚の主過程は眼の中に置かれる。

補遺17（第Ⅶ章 p.147 に対して——前庭器官の理論）

1910年ウィーン国際生理学者会議の際、R・エヴァルト教授が私を訪問し、装置と実験結果を実演してくださった。それによって、この美しい理論の堅固さに対する最後の疑念が払拭された。

補遺18（第ⅩⅢ章 p.205-206 に対して——マッハの色彩現象について）

E・マッハが観察した色彩現象のより詳細な研究により、記述された実験条件のうち間接視（周辺視）だけが本質的であることが判明した。短時間の照明や第二の固定正方形は本質的ではない。周辺的に見られた有色光はすべて、速やかに無色の印象に退色し、その後持続的に補色として現れる。この事実は注意説の根拠を掘り崩す。明らかにこれは末梢的・生理学的原因（元の興奮過程の消耗など）によるものである。（R・パウリ記）

補遺19（第ⅩⅣ章 p.264 に対して——概念についてのシュテーアの研究）

シュテーアは概念に関する独創的な研究によって、私の見方にかなり接近した。彼の『心理学化的叙述による論理学の手引き』（ライプツィヒ・ウィーン、1905年）および『心理学化的叙述による論理学教科書』（ライプツィヒ・ウィーン、1910年）を参照されたい。

補遺20（第ⅩⅣ章 p.268 に対して——安定性の重視について）

本書第12段落（p.268）——すでに1886年の初版にあった——は、アヴェナリウスもまた1888年に同様にもっとも高い価値を安定性に置いたことの証拠として挙げてよいだろう。最後の文を除いて。

補遺21（第ⅩⅣ章 p.270 に対して——ドリーシュの「現実の段階」との関係）

p.268-270の第13段落に述べたことは、ドリーシュが「現実の第二段階と第三段階」と呼ぶものに関係している（『自然概念と自然判断』ライプツィヒ、1904年、p.4以下）。私はこれらを見落としたのではなく、ただ特別に命名しなかっただけである。こうした著作はとかく名前が多すぎることに悩まされがちなのだ。
