マハーバーラタ ― カルナ篇 第33章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 33 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ33」（シャリヤがカルナの先の自讃を強く非難し、子狐が獅子を真似るかのようだと様々な比喩を連ねてアルジュナとの実力差を説き諭す場面。カルナはこれに反論し、自らの武勇への確信を述べる）です。各段落は原典の詩節番号（8-33-N）と和訳の段落番号が対応しています。
karṇaparva — trayastriṃśo'dhyāyaḥ (33)
第33章
śalya uvāca|
mā sūtaputra manyeta(thāḥ) sauvarṇaṃ hastiṣaṅgavam|
prayacchasi mudhaiva tvaṃ drakṣyasi adya dhanañjayam|| // 8-33-1 //
シャルヤは語った。 （1）「御者の子よ、黄金の六象戦車を勘違いして気軽に与えぬがよい。お前は今日、必ずアルジュナを目にするだろう。
mā sūtaputra dānena sauvarṇaṃ hastiṣaṅgavam|
prayaccha puruṣāyādya drakṣyasi tvaṃ dhanañjayam|| // 8-33-2 //
（2）御者の子よ、黄金の六象戦車を施しとして人に与えるな。今日お前はアルジュナを目にするだろうから。
balena mattaḥ tyajasi vasu vaiśravaṇo yathā|
ayatnenaiva rādheya draṣṭāsi adya dhanañjayam|| // 8-33-3 //
（3）ヴァイシュラヴァナ（富の神クベーラ）のごとく、お前は力に酔って財産を捨てている。カルナよ、何の努力もせずとも、今日お前はアルジュナを目にするだろう。
purā sṛjasi yac ca api vittaṃ bahu ca mūḍhavat|
apātradānād ye doṣās tān mohān na avabudhyase|| // 8-33-4 //
（4）お前は愚か者のようにやたらと財を振りまいているが、不適切な者に施すことの罪を、愚かさゆえに理解していない。
yat pravedayase vittaṃ bahu tena khalu tvayā|
śakyaṃ bahuvidhair yajñair yaṣṭuṃ sūta yajasva taiḥ|| // 8-33-5 //
（5）お前は多くの財を撒き散らしているが、その財ではさまざまな祭祀を行うことができよう。御者の子よ、それらを祭祀に用いよ。
yac ca prārthayase hantuṃ kṛṣṇau mohād vṛthaiva tat|
na hi śuśruma sammarde kroṣṭrā siṃhau nipātitau|| // 8-33-6 //
（6）二人のクリシュナ（ヴァースデーヴァとアルジュナ）を討とうと望んでも、それは愚かさゆえのむなしい望みにすぎぬ。戦場で二頭の獅子がジャッカルに倒された、という話を我らは聞いたことがない。
aprārthitaṃ prārthayase suhṛdo na hi santi te|
ye tvāṃ nivārayanti āśu prapatantaṃ hutāśane|| // 8-33-7 //
（7）お前は望むべきでないことを望んでいる。火に飛び込もうとするお前を、すぐに引き止める友人たちが、お前にはいないのだ。
kāryākāryaṃ na jānīṣe kālapakko'sya saṃśayam|
bahvabaddhamakarṇīyaṃ ko hi brūyāj jijīviṣuḥ|| // 8-33-8 //
（8）なすべきこととなすべきでないことを知らぬお前は、明らかに死の時が熟している。でたらめで聞くに堪えぬ多くのことを、生きたい者ならだれが口にしようか。
samudrataraṇaṃ dorbhyāṃ kaṇṭhe baddhvā yathā śilām|
giryagrād vā nipatanaṃ tādṛk tva cikīrṣitam|| // 8-33-9 //
（9）腕に石を結びつけて海を渡ろうとするか、山頂から飛び降りようとするかのような――お前の望みはそのようなものだ。
sahitaḥ sarvayodhais tvaṃ vyūḍhānīkaiḥ surakṣitaḥ|
dhanañjayena yudhyasva śreyaś cet prāptum icchasi|| // 8-33-10 //
（10）幸いを得たいなら、すべての戦士と共に、陣形を整えた軍勢によく守られながら、アルジュナと戦え。
hitārthaṃ dhārtarāṣṭrasya bravīmi tvāṃ na hiṃsayā|
śraddhasva idaṃ mayā proktaṃ yadi te'sti jijīviṣā|| // 8-33-11 //
（11）私はドリタラーシュトラの子（ドゥルヨーダナ）のためを思ってお前に言っているのだ。危害を加えるためではない。生きたいという望みがあるなら、私の言葉を信じよ」。
karṇa uvāca|
svabāhuvīryamāśritya prārthayāmy arjunaṃ raṇe|
tvaṃ tu mitramukhaḥ śatrur māṃ bhīṣayitum icchasi|| // 8-33-12 //
カルナは語った。 （12）「自分の腕の力を頼って、私はアルジュナに挑もうとしている。それなのに、友のふりをした敵であるお前は、私を脅そうとしている。
na mām asmād abhiprāyāt kaścid adya nivartayet|
apīndro vajramudyamya kimu martyaḥ kathañcana|| // 8-33-13 //
（13）この決意から、今日だれも私を引き戻すことはできぬ。インドラが雷を振り上げても無理だ。まして人間にできようか」。
sañjaya uvāca|
iti karṇasya vākyānte śalyaḥ prāha uttaraṃ vacaḥ|
cukopayiṣur atyarthaṃ karṇaṃ madreśvaraḥ punaḥ|| // 8-33-14 //
サンジャヤは語った。 （14）カルナの言葉の後で、シャルヤは再び返事を返した。マドラ国の主は、ふたたびカルナを極度に怒らせようとして――。
yadā vai tvāṃ phalgunabāhuvegāj jyācoditā vegavanto'gnikalpāḥ|
anvetāraḥ kaṅkapatrāḥ śitāgrās tyakṣyaty eṣā svāṃ tadā karṇa buddhiḥ|| // 8-33-15 //
（15）「アルジュナの腕の勢いから、弦に押されて放たれる、火のような勢いで飛びくる、鋭い先端のカンカ鳥の羽矢に追われたとき、カルナよ、お前のその考えはすぐさま消え失せるだろう。
yadā divya dhanurādāya pārthaḥ pratāpayan pṛtanāṃ savyasācī|
tvāṃ mardayiṣyaty asukhaiḥ pṛṣatkais tadā āpṛcchāṃ tyakṣyase pāṇḍavasya|| // 8-33-16 //
（16）アルジュナが神の弓を取り、左右の手に巧みな彼（サヴィヤサーチン）が軍を焼き尽くし、痛みのある矢でお前を苦しめるとき、お前はパーンダヴァ（アルジュナ）に別れを告げ、命を失うだろう。
bālaś candraṃ māturaṅke śayāno yathā kaścit prārthayate'pahartum|
tadvan mohād dyotamānaṃ rathasthaṃ jetuṃ pārthaṃ kāṅkṣase sūtaputra|| // 8-33-17 //
（17）あたかも幼い子が、母の膝で寝ていて月を取りたがるように、愚かさゆえに、御者の子よ、お前は戦車に立つ輝くアルジュナに勝ちたがっている。
harād astraṃ tīkṣṇadhāraṃ yathā'dya sarvāṇi gātrāṇi nikarṣasi tvam|
sutīkṣṇaśastropamakarmaṇā iha yuyutsase phalgunenādya karṇa|| // 8-33-18 //
（18）鋭い刃のハラの武器（三叉戟=さんさげき）で全身をこすり削るように、鋭い武器のごとき業をもって、お前はアルジュナと戦おうとしているのだ、カルナよ。
hanyād asiṃ tīkṣṇadhāraṃ yathā'taḥ sutejanaṃ nihitaṃ vai pṛthivyām|
tathā khanasy adya śitān pṛṣatkān yathā arthayasy arjunena iha yuddham|| // 8-33-19 //
（19）鋭く磨かれた剣がどこかの地面に置いてあったら、それが身を切り裂くように、お前は今日、鋭い矢を掘り出しているかのように、アルジュナに戦いを望んでいる。
triśūlamāśliṣya sutīkṣṇadhāraṃ sarvāṇi gātrāṇi vigharṣasi tvam|
sutīkṣṇadhāropamakarmaṇā tvaṃ yuyutsase yo'rjunenādya karṇa|| // 8-33-20 //
（20）鋭い刃の三叉戟を抱きしめ、全身を傷つけるようなものだ。鋭い武器のごとき業でアルジュナに挑もうとするお前は、カルナよ。
kruddhaṃ siṃhaṃ kesariṇaṃ bṛhantaṃ bālo mūḍhaḥ kṣudramṛgas tarasvī|
samāhvayed vṛṣṭam upetya yoddhuṃ tathā tvam adya āhvayase hi pārtham|| // 8-33-21 //
（21）鬣をもつ怒った大きな獅子を、勇ましい小さな獣である愚かな子どもが近づいて戦おうと挑むように、お前は今日アルジュナに挑んでいるのだ。
mā sūtaputra āhvaya rājaputraṃ mahāvīryaṃ kesariṇaṃ yathaiva|
vane śṛgālaḥ piśitena tṛptaḥ pārthaṃ samāsādya vinaṅkṣyasi tvam|| // 8-33-22 //
（22）御者の子よ、王子を呼び出すな。偉大な力をもつ鬣つきの獅子のごとき者を。森で、肉に満足したジャッカルが、獅子に出会って滅ぶように、お前もアルジュナに出会えば滅びるだろう。
īṣādantaṃ mahānāgaṃ prabhinnakaraṭāmukham|
śaśako hayase yuddhe karṇa pārthaṃ dhanañjayam|| // 8-33-23 //
（23）象の牙のように大きな牙をもち、顔から発情の液を流す大きな象に、うさぎが戦いを挑むように、カルナよ、お前はアルジュナに挑んでいる。
vilasthaṃ kṛṣṇasarpaṃ tvaṃ jālyāt kāṣṭhena vidhyasi|
mahāviṣaṃ pūrṇakopaṃ yatpārthaṃ yoddhum icchasi|| // 8-33-24 //
（24）穴の中の黒蛇を、愚かにも棒で突くようなものだ。強い毒と満々たる怒りをもったアルジュナと、お前は戦おうとしているのだ。
siṃhaṃ kesariṇaṃ kruddham abhikramyābhinardase|
śṛgāla iva mūḍhas tvaṃ nṛsiṃhaṃ karṇa pāṇḍavam|| // 8-33-25 //
（25）鬣のある怒った獅子に向かっていって吠え立てる、愚かなジャッカルのように、お前は、人中の獅子、パーンダヴァ（アルジュナ）に吠えかかっているのだ、カルナよ。
suparṇaṃ patagaśreṣṭhaṃ vainateyaṃ tarasvinam|
svage iva āhvayase pārthaṃ tathā karṇaṃ dhanañjayam|| // 8-33-26 //
（26）鳥の中でも最上、素早きヴィナターの子ガルダを、カラスが呼び出すように、お前はアルジュナに挑んでいるのだ、カルナよ、アルジュナに。
sarvāmbhasāṃ nidhiṃ bhīmaṃ mūrtimantaṃ jhaṣākulam|
candrodaye vivardhantam apluvas tvaṃ titīrṣasi|| // 8-33-27 //
（27）あらゆる水を蓄える恐るべき姿をした、魚でいっぱいの海、月の出で満ちる海を、お前は泳ぐ術ももたずに渡ろうとしているのだ。
ṛṣabhaṃ dundubhigrīvaṃ tīkṣṇaśṛṅgaṃ prahāriṇam|
vatsa āhvayase yuddhe karṇa pārthaṃ dhanañjayam|| // 8-33-28 //
（28）首に鼓のような声を持ち、鋭い角をもって突きかかる雄牛に、仔牛が戦いを挑むように、お前はアルジュナに挑んでいるのだ、カルナよ。
mahāmeghaṃ mahāghoṣaṃ darduraḥ pratinardasi|
bāṇatoyapradaṃ kāle naraparjanyam arjunam|| // 8-33-29 //
（29）大きな音を立てる大雲に、蛙が鳴き返すようなものだ。時に応じて矢の雨を降らせる、人の雨雲アルジュナに、お前は挑んでいるのだ。
yathā ca śvā gṛhasthas tu vyāghraṃ vanagataṃ bhaṣet|
tathā tvaṃ bhaṣase karṇa naravyāghraṃ dhanañjayam|| // 8-33-30 //
（30）家にいる犬が、森の虎に吠え立てるように、お前は人虎アルジュナに吠えかかっているのだ、カルナよ。
śṛgālo hi vane karṇa śaśaiḥ parivṛto vasan|
manyate siṃhamātmānaṃ yāvat siṃhaṃ na paśyati|| // 8-33-31 //
（31）ジャッカルは、森でうさぎに囲まれて住むかぎり、自分を獅子だと思い込んでいる――獅子を見るまでは、カルナよ。
tathā tvam api rādheya siṃham ātmānam icchasi|
apaśyan śatrudamanaṃ narasiṃhaṃ raṇe'rjunam|| // 8-33-32 //
（32）同じように、カルナよ、お前も自分を獅子だと思っているが、戦場で敵を制する人中の獅子アルジュナを、まだ見ていないだけだ。
vyāghraṃ tvaṃ manyase''tmānaṃ yāvat kṛṣṇau na paśyasi|
samāsthitāv ekarathe sūryācandramasāv iva|| // 8-33-33 //
（33）お前は自分を虎だと思っているが、一つの戦車に、太陽と月のように共に立つ二人のクリシュナ（クリシュナとアルジュナ）をまだ見ていないだけだ。
yāvad gāṇḍīvaghoṣaṃ tvaṃ na śṛṇoṣi mahāhave|
tāvadeva tvayā karṇa śakyaṃ vaktuṃ yathā icchasi|| // 8-33-34 //
（34）大戦場でガーンディーヴァ弓の音を聞かぬうちは、カルナよ、お前は思うがままに語るがよい。
rathaśaṅkhadhanuḥśabdair nādayantaṃ diśo daśa|
nardantam iva śārdūlaṃ dṛṣṭvā kroṣṭā bhaviṣyasi|| // 8-33-35 //
（35）戦車・法螺貝・弓の音で十方を轟かせ、吠える虎のごとき彼を見れば、お前はジャッカルになるだろう。
nityam eva śṛgālas tvaṃ nityaṃ siṃho dhanañjayaḥ|
vīrapradveṣaṇān mūḍha tasmāt kroṣṭā iva lakṣyase|| // 8-33-36 //
（36）お前は常にジャッカルであり、アルジュナは常に獅子である。愚か者よ、勇者を憎む者として、お前はジャッカルに見えるのだ。
yathā ākhuḥ syād viḍālaś ca śvā vyāghraś ca balābale|
yathā śṛgālaḥ siṃhaś ca yathā ca śaśakuñjarau|| // 8-33-37 //
（37）ネズミと猫、犬と虎、強弱においてそうであるように、ジャッカルと獅子、うさぎと象の関係のように、――。
yathā'nṛtaṃ ca satyaṃ ca yathā ca api viṣa amṛte|
tathā tvam api pārthaś ca prakhyātāv ātmakarmabhiḥ|| || // 8-33-38 //
（38）偽りと真実、毒と不死の霊薬――そのように、お前とアルジュナは自らの行いによって名高いのだ」。
iti śrīmanmahābhārate karṇaparvaṇi trayastriṃśo'dhyāyaḥ|| 33 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十三章は終わる。
