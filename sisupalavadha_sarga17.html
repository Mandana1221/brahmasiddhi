सप्तदशः सर्गः

第十七章　集会の激昂と出陣の準備
Metre: Rucirā (ja-bha-sa-ja-ga) — V.1–68; Śārdūlavikrīḍita — V.69
V.1
Sanskrit (IAST) itīrite vacasi vacasvinā amunā yugakṣayakṣubhitamarudgarīyasi / pracakṣubhe sapadi tad amburāśinā samaṃ mahāpralayasamudyataṃ sadaḥ // 17.1 //
和訳

こうして弁舌巧みなこの使者が、世の終わりの暴風よりも重い言葉を語り終えると、たちまち集会は、大洪水の時の大海とともに荒れ狂うかのように、激しく動揺した。

注

【Vallabhadeva】

tat sadaḥ = その集会は。amunā vacasvinā = この弁舌家（使者）によって。iti vacasi īrite sati = このように言葉が語られた時。yugakṣayakṣubhitamarudgarīyasi = 劫末に荒れ狂う暴風よりも重い（言葉）。sapadi pracakṣubhe = たちまち激動した。amburāśinā samam = 大海とともに。mahāpralayasamudyatam = 大洪水に向けて荒れ立った。rucirā vṛttam（韻律: ルチラー）。

【Mallinātha】

vacasvinā vāgminā = 弁舌家たる（使者によって）。yugakṣaye kalpānte kṣubhitaḥ uddhataḥ marut tad-garīyasi = 劫の終わりに荒れ狂う暴風よりも重い。vacasi īrite sati = 言葉が語られた時に。tat sadaḥ = ハリの集会は。amburāśinā samaṃ tulyam = 大海と同様に。mahāpralaye sarvasaṃhāre samudyatam = 大洪水の一切破壊に向けて荒れ立った。sapadi pracakṣubhe = たちまち激動した。kalpoddhatamahamārutena mahārṇava iva tadvacasena tatsadaḥ kṣubhitam（劫末の暴風で大海が荒れるように、使者の言葉で集会が動揺した）。upamā。

V.2
Sanskrit (IAST) sarāgayā srutaghanagharmatoyayā karāhatidhvanitapṛthūrupīṭhayā / muhur muhur daśanavikhaṇḍitoṣṭhayā ruṣā nṛpāḥ priyatamayeva bhejire // 17.2 //
和訳

赤く紅潮し、滝のように汗を流し、手で大腿を叩いて大きな音を立て、繰り返し歯で唇を噛みしめる——王たちはそのような怒りを、愛しい女のように抱きしめた。

注

【Vallabhadeva】

nṛpāḥ ruṣā bhejire = 王たちは怒りに取り憑かれた。sarāgayā = 赤みを帯びた / 情愛ある。srutaghanagharmatoyayā = 激しい汗を流す。karāhatidhvanitapṛthūrupīṭhayā = 手で叩いて鳴り響く大きな腿座をもつ。muhur muhur daśanavikhaṇḍitoṣṭhayā = 繰り返し歯で噛み砕かれた唇をもつ。priyatamayā iva = 愛しい女のように。怒りの諸徴表（発汗・紅潮・唇噛み）が恋する女の特徴と重なる。

【Mallinātha】

sarāgayā = saha rāgeṇa pāṭalimṇā, anurāgeṇa ca（赤み / 情愛をもって）。srutaṃ ghanaṃ sāndraṃ gharmatoyaṃ svedodakam = 激しく流れる汗。karāhatyā dhvanitaṃ pṛthu uru pīṭham iva = 手の打撃で鳴り響く大きな腿座。muhur muhur daśanavikhaṇḍitoṣṭhayā = 歯で繰り返し噛まれた唇をもつ。ruṣā priyatamayā iva bhejire = 怒りを恋人のように抱いた。raudrasthāyī krodhaḥ prādurbhūtaḥ（忿怒の恒常情が現れた）。upamā。

V.3
Sanskrit (IAST) alakṣyata kṣaṇadalitāṅgade gade karodaraprahitanijāṃsadhāmani / samullasacchakalitapāṭalopalaiḥ sphuliṅgavān sphuṭam iva kopapāvakaḥ // 17.3 //
和訳

ガダが怒りのあまり手のひらで自らの肩を打つと、瞬時に腕輪が砕け、裂けた紅玉の破片が火花のように飛び散った——まるで怒りの炎がありありと燃え上がったかのように。

注

【Vallabhadeva】

gade = ガダ（クリシュナの弟）において。karodaraprahitanijāṃsadhāmani = 手のひらで打った自らの肩のある身体に。kṣaṇadalitāṅgade = 瞬時に砕けた腕輪をもつ。samullasacchakalitapāṭalopalaiḥ = 飛び散る砕けた紅玉の（火花で）。sphuliṅgavān iva = 火花を帯びたかのように。kopapāvakaḥ sphuṭam alakṣyata = 怒りの火がありありと見えた。utprekṣā（見立て）。

【Mallinātha】

gade gadākhye = ガダという名の者（クリシュナの弟）。karodaraprahitaṃ pāṇitāḍitaṃ nijāṃsadhāma svāṃsapradeśaḥ = 手のひらで打った自身の肩。kṣaṇād dalitāṅgade bhaṅgakeyūre = 瞬時に砕けた腕飾りをもつ。samullasad visphurad dagdhiḥ śakalitaiḥ śakalīkṛtaiḥ pāṭalopalaiḥ padmarāgaiḥ = 飛び散る砕けたパドマラーガ（紅玉）で。kopapāvakaḥ sphuliṅgavān iva sphuṭam alakṣyata = 怒りの火が火花を帯びたかのようにありありと見えた。utprekṣā。

V.4
Sanskrit (IAST) avajñayā yad ahasad uccakair balaḥ samullasaddaśanamayūkhamaṇḍalaḥ / ruṣāruṇīkṛtam api tena tatkṣaṇaṃ nijaṃ vapuḥ punar anayan nijāṃ rucim // 17.4 //
和訳

バラ（バラデーヴァ）が軽蔑をこめて高らかに笑うと、白く輝く歯の光環が広がり、怒りで赤く染まった体を、たちまちもとの白い輝きへと戻した。

注

【Vallabhadeva】

balaḥ = バラ（バラデーヴァ / ハラブリト）。avajñayā uccakaiḥ ahasat = 軽蔑して高らかに笑った。samullasaddaśanamayūkhamaṇḍalaḥ = 輝く歯の光環をもつ。ruṣāruṇīkṛtam api nijaṃ vapuḥ = 怒りで赤く染まった自身の体を。tena tatkṣaṇam punaḥ nijāṃ rucim anayat = その瞬間に再び本来の白い輝きに導いた。白い歯の輝きが怒りの赤みを消したという着想。

【Mallinātha】

balaḥ = バラバドラ。samullasaddaśanamayūkhamaṇḍalam = 輝き放つ歯の光芒の輪。avajñayā anādaraeṇa uccakaiḥ ahasat = 軽蔑して大声で笑った。tena hāsena ruṣāruṇīkṛtam api nijaṃ vapuḥ tatkṣaṇam punaḥ nijāṃ rucim dhāvalyam anayat = その笑いにより、怒りで赤く染まった体を再び本来の白さに戻した。tadguṇālaṅkāraḥ（自身の徳を捨てて他の優れた徳を取る修辞法）。

V.5
Sanskrit (IAST) yad utpatat pṛthutarahāramaṇḍalaṃ vyavartata drutam abhidūtam ulmukaḥ / bṛhacchilātalakaṭhināṃsaghaṭṭitaṃ tato 'bhavad bhramitam ivākhilaṃ sadaḥ // 17.5 //
和訳

ウルムカが使者に向かって素早く振り向くと、大きな真珠の首飾りが宙に舞い上がり、岩盤のように硬い肩がぶつかって、集会全体が回転したかのようであった。

注

【Vallabhadeva】

ulmukaḥ = ウルムカという名の王（ヤーダヴァ）。abhidūtam = 使者に向かって。drutam vyavartata = 急いで振り向いた。utpatat pṛthutarahāramaṇḍalam = 飛び上がる大きな真珠の首飾りをもって。bṛhacchilātalakaṭhinā̃saghaṭṭitam = 巨大な岩盤のように硬い肩がぶつかることにより。tataḥ akhilaṃ sadaḥ bhramitam iva abhavat = それにより集会全体が回転したかのようであった。utprekṣā。

【Mallinātha】

ulmukaḥ nāma rājā = ウルムカという名の王。utpatat ulluthat pṛthutaraṃ hāramaṇḍalaṃ muktākalāpaḥ = 飛び散る大きな真珠の首飾り。abhidūtaṃ dūtābhimukham = 使者に向かって。drutaṃ vyavartata = 急いで向き直った。bṛhatā śilātalakaṭhinā̃sena skandhena ghaṭṭitam = 巨大な岩盤のごとき硬い肩でぶつかって。akhilaṃ sadaḥ bhramitam iva abhavat = 全集会が回転したかのようであった。utprekṣā。

V.6
Sanskrit (IAST) prakupyataḥ śvasanasamīraṇāhatisphuṭoṣmabhis tanuvasanāntamārutaiḥ / yudhājitaḥ kṛtaparitūrṇavījanaṃ punas tarāṃ vadanasarojam asvidat // 17.6 //
和訳

激怒するユダージットの薄衣の裾の風が、素早く扇いでいるにもかかわらず、溜息の熱気に満ちた蓮のようなその顔は、ますます汗に濡れるばかりであった。

注

【Vallabhadeva】

prakupyataḥ yudhājitaḥ = 激怒するユダージットの。śvasanasamīraṇāhati = 溜息（の風の）打撃。sphuṭoṣmabhiḥ = 明らかな熱気をもつ。tanuvasanāntamārutaiḥ = 薄衣の端の風で。kṛtaparitūrṇavījanam = 急速な扇ぎがなされた。vadanasarojam = 蓮の面。punas tarām asvidat = さらにいっそう汗ばんだ。溜息の熱気が扇ぎの涼風を打ち消すという矛盾の趣向。

【Mallinātha】

prakupyataḥ atikupyataḥ yudhājitaḥ = 激しく怒るユダージットの。śvasanasamīraṇasya niḥśvāsamārutasya āhati-sphuṭoṣmabhiḥ = 溜息の風に打たれて噴出する熱気のある。tanuvasanāntamārutaiḥ = 薄い衣の裾の風で。kṛtaparitūrṇavījanam = 急いで扇がれた。punas tarām asvidat = さらにいっそう汗ばんだ。扇いでいるのに却って汗が出るという矛盾。kāvyaliṅgam（間接的因果の修辞）。

V.7
Sanskrit (IAST) prajāpatikratunidhanārtham utthitaṃ vyatarkayaj jvaram iva raudram uddhatam / samudyataṃ sapadi vadhāya vidviṣām atikrudhaṃ niṣadham anauṣadhaṃ janaḥ // 17.7 //
和訳

人々は、敵を殺さんと直ちに立ち上がった、治療の術もないほど激怒したニシャダ王を、プラジャーパティの祭祀を破壊せんと出現した恐ろしいルドラの熱病のように見なした。

注

【Vallabhadeva】

janaḥ niṣadham vyatarkayat = 人々はニシャダ（王）を推測した。samudyatam = 立ち上がった。sapadi vidviṣāṃ vadhāya = 直ちに敵の殺害のために。atikrudham = 激怒した。anauṣadham = 治療法のない。prajāpatikratunidhanārtham utthitam = プラジャーパティ（ダクシャ）の祭祀の破壊のために出現した。raudram jvaram iva = ルドラの恐ろしき熱病（ヴィーラバドラ）のように。śleṣa: prajāpati = 王 / ダクシャ。raudram = 恐ろしい / ルドラに属する。

【Mallinātha】

niṣadhaṃ nṛpam = ニシャダという名の王を。samudyataṃ tīkṣṇam = 激しく立ち上がった。atikruddham = 極度に激怒した。anauṣadham = apratikhāram, 対処法のない。prajāpatikratunidhanārtham = dakṣādhvaradhvaṃsanārtham（ダクシャの祭祀破壊のために）。utthitam raudram jvaram iva = 出現したルドラの熱病（ヴィーラバドラ）のように。vyatarkayat = （人々は）推察した。upamā。

V.8
Sanskrit (IAST) parasparaṃ parikupitasya piṃṣataḥ kṣatormikākanakaparāgapaṅkilam / karadvayaṃ sapadi sudhanvano nijair anāratasrutibhir adhāvyatāmbubhiḥ // 17.8 //
和訳

激怒して両手を互いに押し潰すように握りしめるスダンヴァンの両手は、砕けた指輪の金粉にまみれ、絶え間なく流れる彼自身の涙で洗い清められた。

注

【Vallabhadeva】

parikupitasya = 激怒した。parasparaṃ piṃṣataḥ = 両手を互いにすり潰す。sudhanvanaḥ karadvayam = スダンヴァンの両手は。kṣatormikākanakaparāgapaṅkilam = 砕けた指輪の金粉でまみれた。nijaiḥ anāratasrutibhiḥ ambubhiḥ adhāvyata = 自身の絶え間なく流れる涙で洗われた。

【Mallinātha】

parikupitasya atikruddhasya = 激怒した。parasparaṃ piṃṣataḥ = 互いに押し潰す。karadvayam = 両手。kṣatānāṃ piṣṭānām ūrmikāṇām aṅgulīyakānāṃ kanakaparāgeṇa suvarṇacūrṇena paṅkilam = 砕けた指輪の金粉でまみれた。nijaiḥ anārataśrutibhiḥ aviratasrāvaiḥ aśrubhiḥ svedodakaiḥ dhāvyata ākṣālyata = 自身の絶え間ない涙・汗で洗われた。atiśayokti（誇張法）。

V.9
Sanskrit (IAST) nirāyatām analaśikhojjvalāṃ jvalannakhaprabhākṛtapariveṣasaṃpadaṃ / avibhramad bhramadanalolmukākṛtiṃ pradeśinīṃ jagad iva dagdhum āhukiḥ // 17.9 //
和訳

アーフキは人差し指を振り上げた——真っ直ぐに伸び、炎のように輝き、燃える爪の光が光輪を作り、回転する松明のような姿で——あたかも世界を焼き尽くすかのように。

注

【Vallabhadeva】

āhukiḥ = アーフキという名の王。pradeśinīm = 人差し指（tarjanī）を。avibhramat = 振り回した。nirāyatām = 真っ直ぐに伸びた。analaśikhojjvalām = 炎の先端のように輝く。jvalannakhaprabhākṛtapariveṣasaṃpadam = 燃える爪の光で作られた光輪の美をもつ。bhramad analolmukākṛtim = 回転する松明のような姿の。jagad dagdhum iva = 世界を焼き尽くすかのように。utprekṣā。

【Mallinātha】

āhukir nāma rājā = アーフキという王。nirāyatāṃ prasāritām = 伸ばされた。analaśikhābhir jvālābhir ujjvalām = 炎のように輝く。jvalantībhir nakhaprabhābhiḥ kṛtā pariveṣasaṃpat paridhiśobhā = 輝く爪の光で作られた光輪。bhramataḥ analolmukasya ālātasyeva ākṛtiḥ = 回転する松明のような姿。pradeśinīṃ jagad dagdhum iva = 人差し指を世界を焼くかのように（振り回した）。utprekṣā。

V.10
Sanskrit (IAST) durīkṣatām abhajata manmathas tathā yathā purā paricitadāhadhārṣṭyayā / dhruvaṃ puraḥ saśaram amuṃ tṛtīyayā haro 'pi na vyasahata vīkṣituṃ dṛśā // 17.10 //
和訳

その指はかのカーマデーヴァがかつてそうであったように、恐ろしくて見つめられぬものとなった——焼き滅ぼすことに慣れた大胆な第三の眼をもつハラ（シヴァ）でさえ、弓を持ったこの者を正視することに堪えられなかったであろう。

注

【Vallabhadeva】

durīkṣatām abhajata = 見がたきものとなった。manmathaḥ tathā = カーマ（愛の神）がかつてそうであったように。yathā haro 'pi purā paricitadāhadhārṣṭyayā tṛtīyayā dṛśā = かつて焼き慣れた大胆さをもつ第三の眼ですら。saśaram amuṃ vīkṣituṃ na vyasahata = 弓矢を持ったこの者を見ることに堪えなかった。dhruvaṃ puraḥ = 確かに、前にして。ルドラですらその指を恐れるという着想。

【Mallinātha】

manmathaḥ = カーマデーヴァ。tathā durīkṣatām abhajata = そのように見がたきものとなった。yathā haro 'pi = ハラ（シヴァ）でさえ。purā pūrvajanmani = 前世において。paricitadāhadhārṣṭyayā = 焼くことに慣れた大胆さをもつ。tṛtīyayā dṛśā = 第三の眼で。saśaram amuṃ manmatham = 弓を持ったこのカーマを。dhruvaṃ punaḥ vīkṣituṃ na vyasahata = 確かに再び見つめることに堪えなかった。utprekṣāによりルドラの恐怖すら示唆される。

V.11
Sanskrit (IAST) vicintayann upanatam āhavaṃ rasād uraḥ sphurattanuruham agrapāṇinā / parāmṛśat kaṭhinakaṭhorakāminīkucasthalapramuṣitacandanaṃ pṛthuḥ // 17.11 //
和訳

近づく戦を愉悦とともに思い描きながら、プリトゥは指先で自らの胸を撫でた——その胸は体毛が逆立ち、堅く豊満な愛人の乳房で白檀が拭い取られていた。

注

【Vallabhadeva】

pṛthuḥ = プリトゥという王。upagatam āhavaṃ rasād vicintayan = 到来した戦を楽しみとして思案しながら。agrapāṇinā = 指先で。uraḥ parāmṛśat = 胸を撫でた。sphurattanuruham = 逆立つ体毛のある。kaṭhinakaṭhorakāminīkucasthalapramuṣitacandanam = 硬く逞しい愛人の胸で拭い取られた白檀の（胸を）。彼にとって恋の戦と実の戦は同等の味わい。

【Mallinātha】

pṛthur nāma rājā = プリトゥという名の王。upanatam āhavam = 近づいた戦を。rasād vīrarāgād vicintayan = 勇者の情趣から思い巡らし。kaṭhinaṃ karkaśena kaṭhoreṇa kāminyāḥ kucasthalena pramuṣitaṃ apahṛtaṃ candanam = 硬く豊かな恋人の胸で擦り取られた白檀の。sphurattanuruham = 鳥肌立つ体毛のある。uraḥ agrapāṇinā parāmṛśat = 胸を指先で撫でた。恋戦と実戦への同一の高揚を暗示。

V.12
Sanskrit (IAST) vilaṅghitasthitim abhivīkṣya rukṣayā ripoḥ girā gurum api gāndinīsutam / janais tadā yugaparivartavāyubhir vivartitā giripatayaḥ pratīyire // 17.12 //
和訳

敵の粗暴な言葉により、常は重厚なアクルーラ（ガーンディニーの子）までもが節度を超えて怒るのを見て、人々は、世の終わりの暴風で大山すら根こそぎにされたのだと信じた。

注

【Vallabhadeva】

gāndinīsutam akrūram = ガーンディニーの子アクルーラを。gurum api = 重厚な者であっても。rukṣayā ripoḥ girā = 粗暴な敵の言葉により。vilaṅghitasthitim = 規範を超えた姿を。abhivīkṣya = 見て。janaiḥ = 人々は。yugaparivartavāyubhiḥ vivartitāḥ giripatayaḥ pratīyire = 劫末の暴風で大山が根こそぎにされたと信じた。アクルーラが怒れば、世界の崩壊も信じられる。

【Mallinātha】

gurum svabhāvato dhīram = 本来は沈着な。rukṣayā paruṣayā ripoḥ girā = 粗暴な敵の言葉で。vilaṅghitasthitim = 品位を逸脱した。gāndinīsutam akrūram = アクルーラを。abhivīkṣya = 見て。yugaparivartavāyubhiḥ kalpāntavātaiḥ = 劫末の風で。vivartitāḥ sthānād uccālitāḥ giripatayaḥ adrayaḥ pratīyire = 山々が根こそぎにされたと信じた。akrūravikriyādarśanāt（アクルーラの変容を見て）世界の崩壊も信じられたという着想。

V.13
Sanskrit (IAST) vivartayan madakaluṣīkṛte dṛśau karāhatakṣitikṛtabhairavāravaḥ / krudhā dadhattanum atilohiṇīm abhūt prasenajid gaja iva gairikāruṇaḥ // 17.13 //
和訳

sadasilatāḥ = 優美な剣の蔓（sadasi-latāḥ = 美しい剣の蔓）。sumekhalāḥ = 美しい帯紐をもつ（剣帯／腰帯）。sitataradantacāravaḥ = 白い刃が美しい（白い歯が美しい）。samullasattanuparidhānasaṃpadaḥ = 薄い鞘の美しさが輝く（薄い衣の美しさ）。pulakabhṛtaḥ = 刀身の粒立ちがある（身の毛がよだった）。raṇaiṣiṇām adhikandharaṃ lalambire = 戦を望む者たちの首に垂れ下がった。priyā iva = 愛する女のように。śleṣa（掛詞）。

【Mallinātha】

sumekhalāḥ = 剣帯が美しい（腰帯が美しい）。sitataradantacāravaḥ = 極めて白い刃が美しい（極めて白い歯）。tanuparidhānasaṃpadaḥ = 鞘の美（衣装の美）。pulakabhṛtaḥ = 粒立ちある刀身（鳥肌の立った体）。sadasilatāḥ = 美しい剣蔓。adhikandharaṃ lalambire = 首に掛かった。priyā iva = 恋人のように。śleṣopamā（掛詞による比喩）。

V.26
Sanskrit (IAST) manoharaiḥ prakṛtimanoramākṛtirbhayapradaiḥ samitiṣu bhīmadarśanaḥ / sadaivataiḥ satatamathānapāyibhirnijāṅgavanmurajidasevyatāyudhaiḥ // 17.26 //
和訳

クリシュナは自らの肢体のような武器に仕えられた——心を奪う武器によって生来美しい姿をもち、恐怖を与える武器によって戦場では恐ろしい外見をなし、守護神を持つ武器のごとく常に神性を伴い、決して離れぬ武器のように永遠の存在であった。

注

【Vallabhadeva】

āyudhaiḥ nijāṅgavat asevyata = 武器に自らの肢体のように仕えられた。manoharaiḥ = 魅力的な武器により、彼は生来美しい姿。bhayapradaiḥ = 恐怖を与える武器により、戦場で恐ろしき外見。sadaivataiḥ = 守護神を持つ武器により、彼も常に神性を帯びる。satatam anapāyibhiḥ = 永遠に離れぬ武器により、彼も永遠の存在。

【Mallinātha】

murajid = クリシュナ。āyudhaiḥ = シャールンガ弓などの武器に。nijāṅgavat = 自らの体のように。asevyata = 仕えられた。manoharaiḥ = 魅力的な武器→生来美しい姿。samitiṣu bhayapradaiḥ = 戦場で恐怖を与える→恐ろしき外見。sadaivataiḥ = 神格を伴う（各武器に守護神がいる）。satatam anapāyibhiḥ = 常に離れぬ。utprekṣā（想像法）。

V.27
Sanskrit (IAST) avāritaṃ gatamubhayeṣu bhūriśaḥ kṣamābhṛtāmatha kaṭakāntareṣvapi / muhuryudhi kṣatasuraśatruśoṇitaplutapradhiṃ rathamadhirohati sma saḥ // 17.27 //
和訳

かの方は、二種の陣営の内にも——王たちの軍営にも山々の谷間にも——何にも阻まれず幾度も入り込み、幾多の戦いで倒した阿修羅の血に車輪の外縁が浸された、その戦車に乗り込んだ。

注

【Vallabhadeva】

saḥ = クリシュナ。ratham adhirohati sma = 戦車に乗り込んだ。ubhayeṣu = 二種の（王の陣営と山の谷間）。kṣamābhṛtām = 王たち（地を支える者）＝山々の。kaṭakāntareṣu = 軍営の内部＝山の斜面の間に。avāritam = 妨げられず。bhūriśaḥ gatam = 幾度も進んだ。kṣatasuraśatruśoṇitaplutapradhim = 倒された阿修羅の血に浸った車輪外縁をもつ。

【Mallinātha】

saḥ hariḥ = クリシュナ。ubhayeṣu = 二種の。kṣamābhṛtām = 王たち／山々の。kaṭakāntareṣu = 軍営内部／山腹の間。avāritam apratihataṃ bhūriśaḥ gatam = 何にも阻まれず幾度も入った。muhuḥ yudhi = 幾度もの戦で。kṣatāḥ suraśatravaḥ dānavāḥ = 倒された阿修羅たち。teṣāṃ śoṇitena plutāḥ pradhayaḥ = 血に浸った車輪縁。ratham adhirohati sma = 戦車に乗った。

V.28
Sanskrit (IAST) upetyaca svanagurupakṣamārutaṃ divastviṣā kapiśitadūradiṅmukhaḥ / prakampitasthiratarayaṣṭi tatkṣaṇaṃ patatpatiḥ padamadhiketanaṃ dadhau // 17.28 //
和訳

鳥の王ガルダが天から降り来たった——その音は重く翼の風は激しく、黄金の輝きで遠方の地平線を赤茶色に染めながら。堅固な旗竿をも震わせ、その瞬間、旗印の上に足を置いた。

注

【Vallabhadeva】

patatpatiḥ = 鳥の王ガルダ。divaḥ upetya = 天から降りてきて。svanagurupakṣamārutam = 音が重く翼の風が激しい。tviṣā kapiśitadūradiṅmukhaḥ = 輝きで遠方の地平線を黄褐色に染めた。akampitā sthiratarasudṛḍhā yaṣṭiḥ = 不動の堅固な旗竿（異読：Vallabhadeva「akampita 不動の」、Mallinātha/GRETIL「prakampita 震わせた」）。tatkṣaṇam = その瞬間に。adhiketanam padam dadhau = 旗印の上に足を置いた。

【Mallinātha】

patatpatiḥ = aṇḍajamaṇḍaleśvaraḥ（卵生類の王ガルダ）。divaḥ upetya = 天から降りてきて。svanena guruḥ mahān pakṣamārutaḥ = 音で重い翼の風。tviṣā kāntyā kapiśitāni dūrāṇi diṅmukhāni = 光輝で遠方の地平を褐色に染めた。prakampitā sthiratarā yaṣṭiḥ = 堅固な旗竿が震えた。adhiketanam = 旗印の上に。padam dadhau = 足を置いた。

V.29
Sanskrit (IAST) gabhīratāvijitamṛdaṅganādayā svanaśriyā hataripuhaṃsaharṣayā / pramodayannatha mukharānkalāpinaḥ pratiṣṭhate navaghanavadrathaḥ sma saḥ // 17.29 //
和訳

かくしてその戦車は新たな雨雲のごとく出発した——深みで太鼓の音を凌ぐ響きの美をもち、敵という白鳥の歓喜を奪い、孔雀のような味方を歓喜させながら。

注

【Vallabhadeva】

rathaḥ pratiṣṭhate sma = 戦車は出発した。navaghanavat = 新たな雨雲のように。svanaśriyā = 響きの美しさで。gabhīratāvijitamṛdaṅganādayā = 深さで太鼓を凌ぐ。hataripuhaṃsaharṣayā = 敵の白鳥の歓喜を奪う（雨雲は白鳥を悲しませる）。mukharān kalāpinaḥ pramodayan = 孔雀を鳴かせて喜ばせた（雨雲は孔雀を喜ばせる）。

【Mallinātha】

rathaḥ navaghanavat = 戦車は新たな雨雲のように。gambhīratayā vijitaḥ mṛdaṅganādaḥ yayā = 深みで太鼓を凌ぐ音の美で。hataḥ ripuhaṃsānāṃ harṣaḥ = 敵＝白鳥の歓喜が打ち砕かれた。mukharān kūjataḥ kalāpinaḥ pramodayan = 鳴く孔雀たちを喜ばせつつ（馬のいななきを雷鳴と思って孔雀が喜ぶ）。pratiṣṭhate sma = 出発した。pūrṇopamā（完全比喩）。

V.30
Sanskrit (IAST) nirantarasthagitadigantaraṃ tataḥ samuccaladbalamavalokayañjanaḥ / vikautukaḥ prakṛtamahāplave 'bhavadviśṛṅkhalaṃ pracalitasindhuvāriṇi // 17.30 //
和訳

全方位を隙なく覆い尽くしつつ出撃する軍勢を見て、人々は好奇心を失った——かつて世界の大洪水のとき、海の水が堰を切って溢れ出たのと同じ光景を見ていたからである。

注

【Vallabhadeva】

tataḥ = それから。nirantarasthagitadigantaram = 隙なく四方を覆い尽くした。samuccaladbalam = 出撃する軍勢を。avalokayan janaḥ = 見る人々は。vikautukaḥ abhavat = 好奇心を失った。prakṛtamahāplave = かつての大洪水の時に。viśṛṅkhalaṃ pracalitasindhuvāriṇi = 堰なく溢れ出た海の水において（同じ光景を見ていたので新鮮味がなかった）。darśanālaṃkāra（視覚的技法）。

【Mallinātha】

nirantaram = 隙なく。sthagitāni digantarāṇi = 四方が覆われた。samucchaladbalam = 進発する軍勢を。janaḥ avalokayan = 人々が見て。vikautukaḥ abhavat = 好奇心がなくなった。prakṛtaḥ = すでに起こった。mahāplavaḥ = 世界の大洪水（劫末の海溢れ）。viśṛṅkhalam pracalitam sindhuvāri = 制約なく動き出した海水。それを見たことがあるので驚かなかった。darśanālaṃkāra。
