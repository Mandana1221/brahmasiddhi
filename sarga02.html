kirātārjunīyam

キラータールジュニーヤ 対訳

Bhāravi 作 ― サンスクリット（IAST／デーヴァナーガリー）・和訳

dvitīyaḥ sargaḥ ― 第二章

ビーマがドラウパディーの主張に同調し、即座の行動を促す（1-24）。ユディシュティラは忍耐と時宜を説き、慎重な方策と待機の利を論じる（25-53）。ヴィヤーサが出現し、王の敬意をもって迎えられる（54-59）。
1
ビーマの言葉
Sanskrit
vihitāṃ priyayā manaḥpriyām atha niścitya giraṃ garīyasīm / upapattimad ūrjitāśrayaṃ nṛpam ūce vacanaṃ vṛkodaraḥ //
Viyoginī（Vaitālīya）
和訳
愛する妻が述べた心に快い重厚な言葉を熟慮したのち、ヴリコーダラ（ビーマ）は王に、理にかなった力強い言葉を語った。

vṛkodara（狼の腹）はビーマの異名。Mallinātha注はpriyāがドラウパディーを指し、彼女の助言が利益に向けられていることを示すと説明する。

2
Sanskrit
yad avocata vīkṣya māninī paritaḥ snehamayena cakṣuṣā / api vāgadhipasya durvacaṃ vacanaṃ tad vidadhīta vismayam //
Viyoginī（Vaitālīya）
和訳
「あの誇り高き女が、愛に満ちた眼で見渡しながら語った言葉は、弁舌の主たるブリハスパティにさえ驚嘆を生じさせるであろう。

vāgadhipaは神々の師ブリハスパティ。Mallinātha注は、女性であっても聖典に従い利益を語れば驚嘆に値すると解説する。

3
Sanskrit
viṣamo 'pi vigāhyate nayaḥ kṛtatīrthaḥ payasām ivāśayaḥ / sa tu tatra viśeṣadurlabhaḥ sad upanyasyati kṛtyavartma yaḥ //
Viyoginī（Vaitālīya）
和訳
困難な政策も、手引きがあれば理解し得る――渡し場のある湖のように。しかし、行動の正しき道を示す者こそ、とりわけ得がたい。

tīrthaは「浅瀬・渡し場」と「学問の手段・師」の二義をもつ。Mallinātha注はこのśleṣa（掛詞）を詳説する。

4
Sanskrit
pariṇāmasukhe garīyasi vyathake 'smin vacasi kṣataujasām / ativīryavatīva bheṣaje bahur alpīyasi dṛśyate guṇaḥ //
Viyoginī（Vaitālīya）
和訳
結末において快く、重みのあるこの言葉は、気力を挫かれた者には辛く響くが、ごく少量でも強い効力をもつ薬のように、多くの美点をそなえている。
5
Sanskrit
iyam iṣṭaguṇāya rocatāṃ rucirārthā bhavate 'pi bhāratī / nanu vaktṛviśeṣaniḥspṛhā guṇagṛhyā vacane vipaścitaḥ //
Viyoginī（Vaitālīya）
和訳
美しい内容をもつこの言葉が、善き資質を愛する汝にも心地よいものであれ。賢者は言葉において、語り手の性質を問わず、ただ美点のみを取る。
6
Sanskrit
catasṛṣv api te vivekinī nṛpa vidyāsu nirūḍhim āgatā / katham etya matir viparyayaṃ kariṇī paṅkam ivāvasīdati //
Viyoginī（Vaitālīya）
和訳
王よ、四学に精通した汝の明敏な知性が、なぜ誤った方向に陥り、泥沼にはまった象のように沈むのか。

四学（catasro vidyāḥ）はMallinātha注によればānvīkṣikī（論理学）、trayī（三ヴェーダ）、vārttā（経済学）、daṇḍanīti（刑政学）。

7
Sanskrit
vidhuraṃ kim ataḥ paraṃ parair avagītāṃ gamite daśām imām / avasīdati yat surair api tvayi sambhāvitavṛtti pauruṣam //
Viyoginī（Vaitālīya）
和訳
敵によってこのような恥辱の境遇に追いやられ、神々にさえ証明されたその武勇が、汝のもとで衰えるとは――これ以上の悲嘆があろうか。
8
Sanskrit
dviṣatām udayaḥ sumedhasā gurur asvantataraḥ sumarṣaṇaḥ / na mahān api bhūtim icchatā phalasampatpravaṇaḥ parikṣayaḥ //
Viyoginī（Vaitālīya）
和訳
聡明な者にとって、敵の隆盛は、たとえ大きくとも、悪しき結末に向かうものならば耐えうる。しかし繁栄を望む者は、敵の実りの成就へと向かう衰退を、たとえそれが大きくとも、見過ごしてはならない。

Cappellerの解釈では、「敵の衰退」が自分にとって好都合だからこそ軽視してはならないという逆説的な趣意を読み取る。

9
Sanskrit
acireṇa parasya bhūyasīṃ viparītāṃ vigaṇayya cātmanaḥ / kṣayayuktim upekṣate kṛtī kurute tatpratikāram anyathā //
Viyoginī（Vaitālīya）
和訳
賢者は、敵が速やかに大いに衰え、自分はそれと反対であると見定めれば静観する。しかしそうでなければ、直ちに対策を講じる。
10
Sanskrit
anupālayatām udeṣyatīṃ prabhuśaktiṃ dviṣatām anīhayā / apayānty acirān mahībhujāṃ jananirvādabhayād iva śriyaḥ //
Viyoginī（Vaitālīya）
和訳
無為のままに敵の増大する覇権を見守る王たちからは、人々の非難を恐れるかのように、繁栄はやがて去ってゆく。
11
Sanskrit
kṣayayuktam api svabhāvajaṃ dadhataṃ dhāma śivaṃ samṛddhaye / praṇamanty anapāyam utthitaṃ pratipaccandram iva prajā nṛpam //
Viyoginī（Vaitālīya）
和訳
たとえ衰えていても、生来の威光を保ち繁栄のために立ち上がった王を、人々は二日月のように敬い拝する。

pratipaccandra（二日月）は、欠けた月でも成長する兆しがあれば人々が敬うという比喩。Mallinātha注はKāmandakaの格言「弱き者も勇気あれば勝利を得る」を引用する。

12
Sanskrit
prabhavaḥ khalu kośadaṇḍayoḥ kṛtapañcāṅgavinirṇayo nayaḥ / sa vidheyapadeṣu dakṣatāṃ niyatiṃ loka ivānurudhyate //
Viyoginī（Vaitālīya）
和訳
確かに、五部門の判断を完了した政策は、国庫と軍事力の源である。その政策も、行動すべき事柄においては、世の人が運命に従うように、手腕を必要とする。

五部門（pañcāṅga）はMallinātha注によれば、同盟者、手段、場所と時の配分、災厄の防止、成功の五つ。

13
Sanskrit
abhimānavato manasvinaḥ priyam uccaiḥ padam ārurukṣataḥ / vinipātanivartanakṣamaṃ matam ālambanam ātmapauruṣam //
Viyoginī（Vaitālīya）
和訳
自尊心の高い賢者が、望ましき高き地位を得んと欲するとき、自らの武勇こそ破滅を回避しうる拠り所とみなされる。
14
Sanskrit
vipado 'bhibhavanty avikramaṃ rahayaty āpadupetam āyatiḥ / niyatā laghutā nirāyater agarīyān na padaṃ nṛpaśriyaḥ //
Viyoginī（Vaitālīya）
和訳
災いは勇気なき者を襲い、未来は不幸に陥った者を見捨てる。将来なき者には軽蔑が定まり、軽んじられた者は王の繁栄の器たりえない。

Mallinātha注はここにkāraṇamālā（原因の連鎖）という修辞法を認める――前の要素が次の要素の原因となる連鎖的構造。

15
Sanskrit
tad alaṃ pratipakṣam unnater avalambya vyavasāyavandhyatām / nivasanti parākramāśrayā na viṣādena samaṃ samṛddhayaḥ //
Viyoginī（Vaitālīya）
和訳
それゆえ、隆盛の障害たる努力の不毛にすがるのはもう十分だ。勇気に依拠する繁栄は、落胆とともに住まない。
16
Sanskrit
atha ced avadhiḥ pratīkṣyate katham āviṣkṛtajihmavṛttinā / dhṛtarāṣṭrasutena sutyajāś ciram āsvādya narendrasampadaḥ //
Viyoginī（Vaitālīya）
和訳
もし期限を待つというなら、公然と不正な振る舞いをするドリタラーシュトラの子が、長く王の富を味わったのちに、それを容易く手放すとでも言うのか。
17
Sanskrit
dviṣatā vihitaṃ tvayāthavā yadi labdhā punar ātmanaḥ padam / jananātha tavānujanmanāṃ kṛtam āviṣkṛtapauruṣair bhujaiḥ //
Viyoginī（Vaitālīya）
和訳
あるいは、敵から返還される形で王位を取り戻すというなら、人民の主よ、武勇を証明した汝の弟たちの腕は何のためにあるのか。

Mallinātha注は「クシャトリヤは征服によって得るべし」という聖典の原則を引き、武力による回復を正当化する。

18
Sanskrit
madasiktamukhair mṛgādhipaḥ karibhir vartayati svayaṃ hataiḥ / laghayan khalu tejasā jagan na mahān icchati bhūtim anyataḥ //
Viyoginī（Vaitālīya）
和訳
獅子は、発情液に濡れた顔をもつ象を自ら殺して糧とする。威光によって世を圧する偉大なる者は、他者から繁栄を受けようとはしない。
19
Sanskrit
abhimānadhanasya gatvarair asubhiḥ sthāsnu yaśaś cicīṣataḥ / acirāṃśuvilāsacañcalā nanu lakṣmīḥ phalam ānuṣaṅgikam //
Viyoginī（Vaitālīya）
和訳
自尊を宝とし、逝きゆく命をもって不朽の名声を築こうとする者にとって、稲妻の閃きのごとき不安定な富は、付随的な果実にすぎない。

Mallinātha注はparivṛtti（交換）の修辞法を指摘する――不安定な命を捨てて安定した名声を得るという交換。

20
Sanskrit
jvalitaṃ na hiraṇyaretasaṃ cayam āskandati bhasmanāṃ janaḥ / abhibhūtibhayād asūn ataḥ sukham ujjhanti na dhāma māninaḥ //
Viyoginī（Vaitālīya）
和訳
人は灰の山を踏みつけるが、燃え盛る火を踏みはしない。それゆえ誇り高き者たちは、屈辱を恐れて命は喜んで捨てるが、威光を捨てはしない。
21
Sanskrit
kim avekṣya phalaṃ payodharān dhvanataḥ prārthayate mṛgādhipaḥ / prakṛtiḥ khalu sā mahīyasaḥ sahate nānyasamunnatiṃ yayā //
Viyoginī（Vaitālīya）
和訳
獅子は何の利益を期して雷鳴を発する雲に挑むのか。他者の隆盛を許さぬこと――それこそ偉大なる者の本性なのだ。
22
Sanskrit
kuru tan matim eva vikrame nṛpa nirdhūya tamaḥ pramādajam / dhruvam etad avehi vidviṣāṃ tvadanutsāhahatā vipattayaḥ //
Viyoginī（Vaitālīya）
和訳
それゆえ王よ、怠りから生じた暗闇を払い、武勇にこそ心を定めよ。敵の不幸は汝の意気消沈によってのみ妨げられている――これを確信せよ。
23
Sanskrit
dviradān iva digvibhāvitāṃś caturas toyanidhīn ivāyataḥ / prasaheta raṇe tavānujān dviṣatāṃ kaḥ śatamanyutejasaḥ //
Viyoginī（Vaitālīya）
和訳
四方に名高き方位象のごとく、また広大なる四海のごとき、インドラの威力を備えた汝の弟たちに、戦場で敵のうち誰が耐え得ようか。

方位象（diggaja）は四方で大地を支えると信じられた象。Mallinātha注は四兄弟を四方位象と四海になぞらえた二重の比喩と説明する。

24
Sanskrit
jvalatas tava jātavedasaḥ satataṃ vairikṛtasya cetasi / vidadhātu śamaṃ śivetarā ripunārīnayanāmbusantatiḥ //
Viyoginī（Vaitālīya）
和訳
敵が点じ、汝の心に絶えず燃え盛る怒りの火を、敵の妻たちの眼から流れる涙の奔流が鎮めんことを。」

śivetarāは「不吉な」すなわち「寡婦の涙」を暗示する。Mallinātha注は、敵を殺さなければ怒りの火は消えないという含意を読み取る。

25
ユディシュティラの言葉
Sanskrit
iti darśitavikriyaṃ sutaṃ marutaḥ kopaparītamānasam / upasāntvayituṃ mahīpatir dviradaṃ duṣṭam ivopacakrame //
Viyoginī（Vaitālīya）
和訳
かくのごとく激しい感情を露わにし、怒りに心を満たした風神の子を、王は凶暴な象を宥めるように、なだめ始めた。

Mallinātha注は、ビーマを暴れ象に喩えたことで、ビーマに勇猛さはあっても知慧は不足しているとの含みがあると指摘する。

26
Sanskrit
apavarjitaviplave śucau hṛdayagrāhiṇi maṅgalāspade / vimalā tava vistare girāṃ matir ādarśa ivābhidṛśyate //
Viyoginī（Vaitālīya）
和訳
「過ちなく清澄で、心を捉え、吉祥の座たる汝の言葉の広がりの中に、汝の清らかなる知性が鏡のように映し出されている。

Mallinātha注は、鏡が朝早く見れば吉祥をもたらすというプラーナの教えを引用し、鏡の比喩に吉祥の意味を重ねる。

27
Sanskrit
sphuṭatā na padair apākṛtā na ca na svīkṛtam arthagauravam / racitā pṛthagarthatā girāṃ na ca sāmarthyam apohitaṃ kvacit //
Viyoginī（Vaitālīya）
和訳
言葉によって明晰さは損なわれず、内容の重みも取り落とされていない。表現の個々の意味は明確に構成され、全体の脈絡もどこにも失われていない。
28
Sanskrit
upapattir udāhṛtā balād anumānena na cāgamaḥ kṣataḥ / idam īdṛg anīdṛgāśayaḥ prasabhaṃ vaktum upakrameta kaḥ //
Viyoginī（Vaitālīya）
和訳
道理は力強く述べられ、推論によって聖典も傷つけられていない。このような精神を備えぬ者が、かくも強力に語り始めることができようか。
29
Sanskrit
avitṛptatayā tathāpi me hṛdayaṃ nirṇayam eva dhāvati / avasāyayituṃ kṣamāḥ sukhaṃ na vidheyeṣu viśeṣasampadaḥ //
Viyoginī（Vaitālīya）
和訳
それでもなお満ち足りぬゆえに、我が心は決断へと走る。なすべき事柄においては、言葉の卓越だけでは、たやすく決断を下させることはできないのだ。
30
Sanskrit
sahasā vidadhīta na kriyām avivekaḥ param āpadāṃ padam / vṛṇate hi vimṛśyakāriṇaṃ guṇalubdhāḥ svayam eva sampadaḥ //
Viyoginī（Vaitālīya）
和訳
性急に行動してはならない。無分別こそ災厄の最たる因である。美徳を求める繁栄は、熟慮して行動する者を自ら選ぶ。
31
Sanskrit
abhivarṣati yo 'nupālayan vidhibījāni vivekavāriṇā / sa sadā phalaśālinīṃ kriyāṃ śaradaṃ loka ivādhitiṣṭhati //
Viyoginī（Vaitālīya）
和訳
務めの種子を守り、分別の水で潤す者は、世の人が実り豊かな秋を迎えるように、常に果実ある行いに到達する。
32
Sanskrit
śuci bhūṣayati śrutaṃ vapuḥ praśamas tasya bhavaty alaṃkriyā / praśamābharaṇaṃ parākramaḥ sa nayāpāditasiddhibhūṣaṇaḥ //
Viyoginī（Vaitālīya）
和訳
清浄な学識が身を飾り、心の平静がその装飾となる。平静を飾るのは武勇であり、その武勇は策略によって成就された成功を飾りとする。

Mallinātha注はekāvalī（一連の装飾）の修辞法を指摘する――各要素が次の要素の修飾語となる連鎖的構造。

33
Sanskrit
matibhedatamastirohite gahane kṛtyavidhau vivekinām / sukṛtaḥ pariśuddha āgamaḥ kurute dīpa ivārthadarśanam //
Viyoginī（Vaitālīya）
和訳
意見の相違という暗闇に覆われ、見通しがたい行為の領域において、よく学ばれ清浄なる聖典の教えは、灯明のように事柄を照らし出す。
34
Sanskrit
spṛhaṇīyaguṇair mahātmabhiś carite vartmani yacchatāṃ manaḥ / vidhihetur ahetur āgasāṃ vinipāto 'pi samaḥ samunnateḥ //
Viyoginī（Vaitālīya）
和訳
称賛すべき資質をもつ偉人たちが歩んだ道に心を定める者にとって、運命に因る没落は罪なきものであり、隆盛にも等しい。

Mallinātha注はKāmandakaの格言を引く――「正しく着手された事業が逆転しても、運命に遮られた武勇ゆえに人は非難されるべきではない」。

35
Sanskrit
śivam aupayikaṃ garīyasīṃ phalaniṣpattim adūṣitāyatim / vigaṇayya nayanti pauruṣaṃ vijitakrodharayā jigīṣavaḥ //
Viyoginī（Vaitālīya）
和訳
勝利を望む者たちは、怒りの奔流に打ち克ち、大いなる果実の成就と損なわれぬ未来を見定めて、武勇を吉祥なる方策に導く。
36
Sanskrit
apaneyam udetum icchatā timiraṃ roṣamayaṃ dhiyā puraḥ / avibhidya niśākṛtaṃ tamaḥ prabhayā nāṃśumatāpy udīyate //
Viyoginī（Vaitālīya）
和訳
隆盛を望む者は、まず知慧によって怒りの暗闇を払わねばならない。太陽でさえ、夜が作った闇を裂かずには昇ることができない。
37
Sanskrit
balavān api kopajanmanas tamaso nābhibhavaṃ ruṇaddhi yaḥ / kṣayapakṣa ivaindavīḥ kalāḥ sakalā hanti sa śaktisampadaḥ //
Viyoginī（Vaitālīya）
和訳
たとえ力ある者でも、怒りから生じた暗愚の支配を防がぬ者は、欠けゆく月が月の光をすべて滅ぼすように、すべての力の財産を失う。
38
Sanskrit
samavṛttir upaiti mārdavaṃ samaye yaś ca tanoti tigmatām / adhitiṣṭhati lokam ojasā sa vivasvān iva medinīpatiḥ //
Viyoginī（Vaitālīya）
和訳
均衡ある振る舞いをなし、時に応じて柔和を示し鋭さを発揮する王は、太陽のように威力をもって世を治める。
39
Sanskrit
kva cirāya parigrahaḥ śriyāṃ kva ca duṣṭendriyavājivaśyatā / śaradabhracalāś calendriyair asurakṣā hi bahucchalāḥ śriyaḥ //
Viyoginī（Vaitālīya）
和訳
繁栄の長き保持と、制御しがたい感覚の馬に従属することと、どうして両立しようか。秋の雲のように移ろいやすく、多くの隙のある繁栄は、制御できぬ感覚をもつ者には守りがたい。
40
Sanskrit
kim asāmayikaṃ vitanvatā manasaḥ kṣobham upāttaraṃhasaḥ / kriyate patir uccakair apāṃ bhavatā dhīratayādharīkṛtaḥ //
Viyoginī（Vaitālīya）
和訳
時宜を得ぬ激情をかき立てて、なぜ汝は、かつて沈着さにおいて凌駕したはずの大海を、ふたたび汝より高みに置こうとするのか。
41
Sanskrit
śrutam apy adhigamya ye ripūn vinayante na śarīrajanmanaḥ / janayanty acirāya sampadām ayaśas te khalu cāpalāśrayam //
Viyoginī（Vaitālīya）
和訳
聖典を学んでもなお、身体に生まれた敵――欲望などの内なる敵を制御しない者たちは、軽率に基づく不名誉を繁栄にもたらす。

身体に生まれた敵（śarīrajanmanaḥ ripūn）はkāma（欲）、krodha（怒り）などの六敵を指す。

42
Sanskrit
atipātitakālasādhanā svaśarīrendriyavargatāpanī / janavan na bhavantam akṣamā nayasiddher apanetum arhati //
Viyoginī（Vaitālīya）
和訳
時と手段を逸し、自らの身体と感覚を苦しめる焦りは、凡人のごとく汝を政策の成果から引き離すべきではない。
43
Sanskrit
upakārakam āyater bhṛśaṃ prasavaḥ karmaphalasya bhūriṇaḥ / anapāyi nibarhaṇaṃ dviṣāṃ na titikṣāsamam asti sādhanam //
Viyoginī（Vaitālīya）
和訳
未来に大いに益し、豊かな行為の果実を生み出し、自ら滅びることなく敵を滅ぼすもの――忍耐に匹敵する手段はない。
44
Sanskrit
praṇatipravaṇān vihāya naḥ sahajasnehanibaddhacetasaḥ / praṇamanti sadā suyodhanaṃ prathame mānabhṛtāṃ na vṛṣṇayaḥ //
Viyoginī（Vaitālīya）
和訳
生まれながらの愛情に心を結ばれ、誇り高き者の第一人者であるヴリシュニ族が、恭順に傾く我らを捨ててスヨーダナに頭を下げることは決してない。

ヴリシュニ族（Vṛṣṇi）はヤーダヴァ族であり、クリシュナの一族。Mallinātha注は、彼らは本来パーンダヴァ側であり、時が来れば離反するだろうと注解する。

45
Sanskrit
suhṛdaḥ sahajās tathetare matam eṣāṃ na vilaṅghayanti ye / vinayād iva yāpayanti te dhṛtarāṣṭrātmajam ātmasiddhaye //
Viyoginī（Vaitālīya）
和訳
ヴリシュニ族の生まれながらの友も、また彼らの意向に背かぬ他の者たちも、自らの利益のためにのみ、礼節からであるかのようにドリタラーシュトラの子を支えている。
46
Sanskrit
abhiyoga imān mahībhujo bhavatā tasya tataḥ kṛtāvadheḥ / pravighāṭayitā samutpatan haridaśvaḥ kamalākarān iva //
Viyoginī（Vaitālīya）
和訳
定められた期限あるかの者に対する汝の攻撃は、昇りゆく太陽が蓮の群れを開かせるように、これらの王たちを引き離すであろう。
47
Sanskrit
upajāpasahān vilaṅghayan sa vidhātā nṛpatīn madoddhataḥ / sahate na jano 'py adhaḥkriyāṃ kim u lokādhikadhāma rājakam //
Viyoginī（Vaitālīya）
和訳
驕慢に酔い上がった彼は、王たちを侮り、離間に至らしめるだろう。普通の人でさえ屈辱を忍ばないのに、まして人の中の最高の輝きたる王族においてはなおさらのこと。
48
Sanskrit
asamāpitakṛtyasampadāṃ hatavegaṃ vinayena tāvatā / prabhavanty abhimānaśālināṃ madam uttambhayituṃ vibhūtayaḥ //
Viyoginī（Vaitālīya）
和訳
事業が未完成であるがゆえにわずかな謙遜で抑えられていた誇り高き者たちの驕りを、繁栄の力が再び増長させることができる。
49
Sanskrit
madamānasamuddhataṃ nṛpaṃ na viyuṅkte niyamena mūḍhatā / atimūḍha udasyate nayān nayahīnād aparajyate janaḥ //
Viyoginī（Vaitālīya）
和訳
驕りと矜持に高ぶった王から、愚昧は決して離れない。深く愚かな者は政策から遠ざけられ、政策なき者から人民は離反する。
50
Sanskrit
aparāgasamīraṇeritaḥ kramaśīrṇākulamūlasantatiḥ / sukaras taruvat sahiṣṇunā ripur unmūlayituṃ mahān api //
Viyoginī（Vaitālīya）
和訳
嫌悪の風に煽られ、根の連なりが次第に朽ちて乱れた敵は、たとえ強大であっても、忍耐強き者にとっては樹木のように容易く根こそぎにされうる。

Mallinātha注はkāraṇamālā（原因の連鎖）とupamā（直喩）の二重修辞法を指摘する。

51
Sanskrit
aṇur apy upahanti vigrahaḥ prabhum antaḥprakṛtiprakopajaḥ / akhilaṃ hi hinasti bhūdharaṃ taruśākhāntanigharṣajo 'nalaḥ //
Viyoginī（Vaitālīya）
和訳
内側の臣下たちの憤りから生じた争いは、たとえ小さくとも王を滅ぼす。樹の枝先の摩擦から生じた火が山全体を焼き尽くすように。
52
Sanskrit
matimān vinayapramāthinaḥ samupekṣeta samunnatiṃ dviṣaḥ / sujayaḥ khalu tādṛg antare vipadantā hy avinītasampadaḥ //
Viyoginī（Vaitālīya）
和訳
賢者は、礼儀を踏みにじる敵の隆盛を静観すべきである。そのような隙において容易に征服しうる。無法な者の繁栄は破滅に終わるからだ。
53
Sanskrit
laghuvṛttitayā bhidāṃ gataṃ bahir antaś ca nṛpasya maṇḍalam / abhibhūya haraty anantaraḥ śithilaṃ kūlam ivāpagārayaḥ //
Viyoginī（Vaitālīya）
和訳
王の軽率な振る舞いによって内外で分裂した勢力圏を、隣国の王は、河の流れが崩れかけた岸を押し流すように、制圧して奪い取る。」

anantaraは隣国を指す。インドの政治思想では隣国は自然の敵とされる（maṇḍala理論）。

54
Sanskrit
anuśāsatam ity anākulaṃ nayavartmākulam arjunāgrajam / svayam artha ivābhivāñchitas tam abhīyāya parāśarātmajaḥ //
Viyoginī（Vaitālīya）
和訳
かくのごとく、動揺するアルジュナの兄に政策の道を穏やかに説いている彼のもとに、まさに念願の対象が自ら現れたかのように、パラーシャラの子（ヴィヤーサ）がやって来た。

parāśarātmajaは聖仙ヴィヤーサ。arjunāgrajaはユディシュティラを指す。

55
Sanskrit
madhurair avaśāni lambhayann api tiryañci śamaṃ nirīkṣitaiḥ / paritaḥ paṭu bibhrad enasāṃ dahanaṃ dhāma vilokanakṣamam //
Viyoginī（Vaitālīya）
和訳
穏やかな眼差しによって奔放な獣をも静め、あたりに罪を焼き尽くす輝きを放ちながらも、なお見るに堪えうる光を帯びた聖仙――

55-56は長い複合文でヴィヤーサの姿を描写する。Cappellerはこれを一連の修飾句として訳している。

56
Sanskrit
sahasopagataḥ savismayaṃ tapasāṃ sūtir asūtir enasām / dadṛśe jagatībhujā muniḥ sa vapuṣmān iva puṇyasaṃcayaḥ //
Viyoginī（Vaitālīya）
和訳
苦行の源にして罪の消滅者たるその聖仙は、突如現れ、功徳の積み重ねが身体を得たかのように、王に驚きをもって見つめられた。
57
Sanskrit
athoccakair āsanataḥ parārdhyād udyan sa dhūtāruṇavalkalāgraḥ / rarāja kīrṇākapiśāṃśujālaḥ śṛṅgāt sumeror iva tigmaraśmiḥ //
Upajāti
和訳
そのとき、高く荘厳な座から立ち上がったユディシュティラは、赤い樹皮衣の裾をなびかせ、黄褐色の光の網を放って、須弥山の頂から昇る太陽のように輝いた。
58
Sanskrit
avahitahṛdayo vidhāya so 'rhām ṛṣivad ṛṣipravare gurūpadiṣṭām / tadanumatam alaṃcakāra paścāt praśama iva śrutam āsanaṃ narendraḥ //
Puṣpitāgrā
和訳
心を集中させた王は、師の教えどおりに聖仙の中の最上者に聖仙にふさわしい礼拝を捧げ、その許しを得て、心の平静が学識を飾るかのように、ふたたび座を荘厳した。
59
Sanskrit
vyaktoditasmitamayūkhavibhāsitoṣṭhas tiṣṭhan muner abhimukhaṃ sa vikīrṇadhāmnaḥ / tanvantam iddham abhito gurum aṃśujālaṃ lakṣmīm uvāha sakalasya śaśāṅkamūrteḥ //
Vasantatilakā
和訳
明るい微笑みの光に唇を輝かせ、光を放つ聖仙の前に立つ彼は、あまねく光の網を広げるグルの星（木星）の前の満月のごとき美しさを帯びていた。

guruは木星（ブリハスパティ）の別名。Mallinātha注はnidarśanā（例証）の修辞法を指摘する――直接の類似ではなく、映し出しの関係による比喩。

iti bhāravikṛtau mahākāvye kirātārjunīye dvitīyaḥ sargaḥ //
