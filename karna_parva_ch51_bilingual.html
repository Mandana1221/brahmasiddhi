マハーバーラタ ― カルナ篇 第51章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 51 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ51」、全124詩節（うち第111詩節は両資料（サンスクリット原典・和訳原典）に共通して欠落しており、誤記ではなく原典自体の脱落と確認）からなる、これまでで最大規模の章です。冒頭、ビーマセーナがチェーディ・パーンチャーラ・ケーカヤ連合軍を率い、カルナ自らがこれを矢で迎え撃ちます（第1〜5詩節）。続いてドゥルヨーダナの子がナクラ・サハデーヴァ（マードリーの双子）と一対一で激しく渡り合い（第7〜19詩節）、これにパーンダヴァ軍の総司令官ドリシュタディユムナが加わって乱戦となります（第20〜38詩節）。中盤では、カルナがサーティヤキを退け、ドローナを討った者（ドリシュタディユムナ）を追って戦場を疾駆し、パーンチャーラ・スリンジャヤ軍を獅子が鹿を蹴散らすように、火が蛾を焼くように圧倒する場面が壮大な比喩を連ねて描かれます（第39〜70詩節）。並行してビーマセーナはバーリーカ・ケーカヤ・マツヤ・ヴァーサートヤ・マドラ・サインダヴァの諸軍を相手に獅子奮迅の働きを見せます（第70〜82詩節）。後半は、アルジュナがクリシュナに対し「トリガルタ軍を追うべきか、カルナと直接対決すべきか」を問い、クリシュナの勧めに従ってカルナのいる方面へ向かう場面（第83〜97詩節）から、アルジュナがサンシャプタカ軍を阎魔の使者のごとく薙ぎ払い、スダクシナの弟を討つ場面（第98〜115詩節）、そして最後にドラウニ（アシュヴァッターマン）がアルジュナに挑む場面（第119〜122詩節）まで続き、アルジュナ対サンシャプタカ・ビーマ対クル・カルナ対パーンチャーラという三正面の激戦が同時進行する様で幕を閉じます（第123〜124詩節）。なお、本章でも前2章と同様、冒頭の「サンジャヤは語った」の一文に余分な二重の注記「8-51-0」「8-51-0x」が付されていたため、これを第1詩節の本文に統合しています。OCR誤記としては、「द」（da）と「ध」（dha）の混同（kruddo→kruddho）、「भ」（bha）と「ध」（dha）の混同（yadvaddhamarā→yadvat bhramarā、蜂の比喩）、レトロフレックス音の脱落（dromahantāram→droṇahantāram、ドローナを討った者）、字形類似による誤記（bhāṣmo→bhīṣmo、ビーシュマ）、「anatkaḥ」→「antakaḥ」（死神、本章自身の第102詩節の同一表現と内部照合して確認）、また頻出する「द्व」（dva）／「द्ध」（ddha）の混同が本章では実に5箇所（yudvaviśāradān、susaṅkrudvaḥ、krudvaḥ、krudve、yudvaṃ）に見られました。また、アヴァグラハ（ऽ）で示された母音脱落形（sarvato'bhyadravan、tato'bhavat等）は、本来の語境界規則に従い分離せず、アポストロフィ付きの融合形のまま保持しています。
karṇaparva — ekapañcāśo'dhyāyaḥ (51)
第51章
sañjaya uvāca|
bhīmasenaṃ sapāñcālaṃ cedikekayasaṃvṛtam|
senāpatiḥ svayaṃ kruddho vārayāmāsa sāyakaiḥ|| // 8-51-1 //
サンジャヤは語った。 （1） パーンチャーラ族、チェーディ族、ケーカヤ族に囲まれたビーマセーナを、総大将カルナ自ら怒りをもって矢で阻んだ。
tatas tu cedikārūśān sṛñjayāṃś ca mahārathān|
karṇo jaghāna samare bhīmasenasya paśyataḥ|| // 8-51-2 //
（2） そしてカルナは戦場にて、ビーマセーナが見ている前で、チェーディ族、カールーシャ族、スリンジャヤ族の大戦車戦士たちを次々と倒した。
bhīmasenas tataḥ karṇe vihāya rathasattamam|
prayayau kauravaṃ sainyaṃ kakṣam agnir iva jvalan|| // 8-51-3 //
（3） するとビーマセーナはカルナの最上の戦車を避け、燃え盛る火が乾いた草原を焼くように、カウラヴァの軍勢に向かって進んでいった。
sūtaputro'pi samare pāñcālān kekayāṃs tathā|
sṛñjayāṃś ca maheṣvāsān nijaghānaṃ sahasraśaḥ|| // 8-51-4 //
（4） スータの息子（カルナ）もまた戦場で、パーンチャーラ族、ケーカヤ族、スリンジャヤ族の大弓の勇士たちを千人単位で打ち倒した。
saṃśaptakeṣu pārthaś ca kauraveṣu vṛkodaraḥ|
pāñcāleṣu tathā karṇaḥ kṣayaṃ cakrur mahārathāḥ|| // 8-51-5 //
（5） サムシャプタカ族にはアルジュナが、カウラヴァ軍にはヴリコーダラ（ビーマ）が、パーンチャーラ族にはカルナが、それぞれ大戦車戦士として大殺戮を行った。
te kṣatriyā dahyāmānās tribhis taiḥ pāvakopamaiḥ|
jagmur vināśaṃ samare rājan durmantrite tava|| // 8-51-6 //
（6） 王よ、その火のごとき三人の勇者に焼かれたクシャトリヤたちは、汝の誤った策謀のゆえに戦場で滅びていった。
tato duryodhanaḥ kruddho nakulaṃ navabhiḥ śaraiḥ|
vivyādha bharataśreṣṭha caturaś ca asya vājinaḥ|| // 8-51-7 //
（7） バーラタ族の最良者よ、怒ったドゥルヨーダナはナクラを九本の矢で射貫き、その四頭の馬をも射た。
tataḥ param ameyātmā tava putro janādhipa|
kṣureṇa sahadevasya dhvajaṃ ciccheda kāñcanam|| // 8-51-8 //
（8） 王よ、計り知れぬ魂を持つ汝の息子は、鋭い剃刀の矢でサハデーヴァの黄金の旗を切り落とした。
nakulas tu tataḥ kruddhas tava putraṃ ca saptabhiḥ|
jaghāna samare rājan sahadevaś ca pañcabhiḥ|| // 8-51-9 //
（9） 王よ、それに怒ったナクラは汝の息子を七本の矢で、サハデーヴァは五本の矢で戦場にて打った。
tāvubhau bharataśreṣṭhau jyeṣṭhau sarvadhanuṣmatām|
vivyādha urasi saṅkruddhaḥ pañcabhiḥ pañcabhiḥ śaraiḥ|| // 8-51-10 //
（10） 怒り狂ったドゥルヨーダナは、全ての弓の使い手の中で最も優れたバーラタ族の二人の兄弟の胸を、それぞれ五本ずつの矢で射た。
tato'parābhyāṃ bhallābyāṃ dhanuṣī samakṛntata|
yamayoḥ prasabhaṃ vīro vivyādha āśu tribhis tribhiḥ|| // 8-51-11 //
（11） さらに別の二本のバッラ矢で双子の弓を断ち切り、この勇者は素早くそれぞれを三本ずつの矢で射た。
tāvanye dhanuṣī śreṣṭhe śakracāpanibhe śubhe|
pragṛhya rejatuḥ śūrau devaputrasamau yudhi|| // 8-51-12 //
（12） 二人の勇者は別の優れた弓を取り、インドラの弓のごとく輝く美しいそれを構えて、戦場で神の子のごとく輝いた。
tatastau rabhasau yuddhe bhrātarau bhrātaraṃ yudhi|
śarair vavarṣatur ghorair mahāmeghau yathā'calam|| // 8-51-13 //
（13） 戦いに熱烈な二人の兄弟は、兄に向かって大山を打つ大雨雲のごとく、恐ろしい矢の雨を降らせた。
tataḥ kruddho mahārāja tava putro mahārathaḥ|
pāṇḍuputrau maheṣvāsau vārayāmāsa patribhiḥ|| // 8-51-14 //
（14） 大王よ、怒った汝の息子、大戦車戦士は、パーンドゥの二人の息子を、優れた弓の使い手を、羽のある矢で阻んだ。
dhanurmaṇḍalamevāsya dadṛśe yudhi bhārata|
sāyakāś ca apyadṛśyanta niścarantaḥ samantataḥ|| // 8-51-15 //
（15） バーラタよ、戦場では彼の弓が円を描くのだけが見え、矢は四方八方に飛び交って見えなかった。
'tasya sāyakasañchannau mādreyau na virejatuḥ|
meghacchannau yathā vyomni candrasūryau gataprabhau|| // 8-51-16 //
（16） 矢で覆われたマードリーの二人の息子は輝きを失い、空で雲に覆われた月と太陽のようであった。
te tu bāṇā mahārāja svarṇapuṅkhāḥ śilāśitāḥ'|
ācchādayan diśaḥ sarvāḥ sūryasya iva marīcayaḥ|| // 8-51-17 //
（17） 大王よ、黄金の矢羽根を持ち石で研がれたそれらの矢は、太陽の光線のごとく全ての方角を覆い尽くした。
vāṇabhūte tatas tasmin sañchanne ca nabhastale|
rājñas tu dadṛśe rūpaṃ kālāntakayamopamam|| // 8-51-18 //
（18） 矢で空が覆い尽くされたその時、王の姿はまさに死の使者ヤマと終末の破壊者のように見えた。
parākramaṃ tu taṃ dṛṣṭvā tava sūnor mahārathāḥ|
mṛtyorupāntikaṃ prāptau mādrīputrau sma menire|| // 8-51-19 //
（19） 汝の息子のこの武勇を見て、大戦車戦士たちはマードリーの二人の息子が死の間際に至ったと思った。
tataḥ senāpatī rājan pāṇḍavānāṃ mahārathaḥ|
pārṣataḥ prayayau tatra yatra rājā suyodhanaḥ|| // 8-51-20 //
（20） 王よ、そこにパーンダヴァ軍の総大将たる大戦車戦士パールシャタ（ドゥリシュタデュムナ）が、スヨーダナ王の元に向かった。
mādrīputrau tataḥ śūrau vyatikramya mahārathau|
dhṣṭadyumnas tava sutaṃ pīḍayāmāsa sāyakaiḥ|| // 8-51-21 //
（21） 勇敢な大戦車戦士マードリーの二人の息子を追い越して、ドゥリシュタデュムナは汝の息子を矢で攻め立てた。
tamavidhyadameyātmā tava putro hi amarṣaṇaḥ|
pāñcālyaṃ pañcaviṃśatyā prahasya puruṣarṣabhaḥ|| // 8-51-22 //
（22） 計り知れぬ魂を持つ汝の息子は、怒りを抱えぬその人の最良者は、笑いながらパーンチャーリヤ（ドゥリシュタデュムナ）を二十五本の矢で射た。
tataḥ punar ameyātmā tava putro hi amarṣaṇaḥ|
viddhvā nanāda pāñcālyaṃ ṣaṣṭyā pañcabhir eva ca|| // 8-51-23 //
（23） さらに計り知れぬ魂を持つ汝の息子は怒りを抑えず、パーンチャーリヤを六十五本の矢で射て、雄叫びを上げた。
tathā asya saśaraṃ cāpaṃ muṣṭideśe viśāmpate|
kṣurapreṇa sutīkṣṇena rājā ciccheda saṃyuge|| // 8-51-24 //
（24） そして王よ、彼は戦場でその矢のかかった弓を、握りの部分で鋭い剃刀矢で断ち切った。
tat apāsya dhanuś chinnaṃ pāñcālyaḥ śatrukarśanaḥ|
anyad ādatta vegena dhanurbhārasahaṃ navam|| // 8-51-25 //
（25） 切られた弓を投げ捨て、敵を苦しめるパーンチャーリヤは素早く別の新しい、重厚な弓を取った。
krodhād rudhiraraktākṣaḥ saṃrambhāt prajvalan iva|
aśobhata maheṣvāso dhṛṣṭadyumnaḥ kṛtavraṇaḥ|| // 8-51-26 //
（26） 怒りで目を血のように赤くし、激昂で燃え上がるかのように、傷だらけの大弓手ドゥリシュタデュムナは美しく輝いた。
sa pañcadaśa nārācāñ śvasataḥ pannagān iva|
jighāṃsur bharataśreṣṭhaṃ dhṛṣṭadyumno vyapāsṛjat|| // 8-51-27 //
（27） バーラタ族の最良者を殺さんとして、ドゥリシュタデュムナは息づく蛇のような十五本の鉄矢を放った。
te varma hemavikṛtaṃ bhittvā rājñaḥ śilīmukhāḥ|
viviśur vasudhāṃ vegāt kaṅkabarhiṇavāsasaḥ|| // 8-51-28 //
（28） 鳥の羽根をつけた鋭い矢は、王の黄金で飾った鎧を突き破り、地面に突き刺さった。
so'tividdho mahārāja putras te ativyarājata|
vasantakāle sumahān praphulla iva kiṃśukaḥ|| // 8-51-29 //
（29） 大王よ、深く射られた汝の息子は、春に満開となったキンシュカの大木のように美しく輝いた。
sa cchinnavarmā nārācaprahārair jharjharīkṛtaḥ|
dhṛṣṭadyumnasya bhallena kruddhaś ciccheda kārmukam|| // 8-51-30 //
（30） 鎧を砕かれ、鉄矢の打撃で体中を穴だらけにされた彼は、怒りをもってドゥリシュタデュムナの弓をバッラ矢で断ち切った。
atha enaṃ chinnadhanvānaṃ tvaramāṇo mahīpatiḥ|
sāyakair daśabhī rājan bhruvor madhye samārpayat|| // 8-51-31 //
（31） 王よ、弓を失った彼を急いで王は十本の矢で両眉の間に命中させた。
tasya te aśobhayan vaktraṃ karmāraparimārjitāḥ|
praphullaṃ paṅkajaṃ yadvat bhramarā madhulipsavaḥ|| // 8-51-32 //
（32） 鍛冶が磨いたそれらの矢は、蜜を求める蜂が満開の蓮に集まるように、彼の顔を飾った。
tat apāsya dhanuś chinnaṃ dṛṣṭadyumno mahāmanāḥ|
anyad ādatta vegena dhanurbhallāṃś ca ṣoḍaśa|| // 8-51-33 //
（33） 偉大なる心のドゥリシュタデュムナは、断ち切られた弓を捨て、素早く別の弓と十六本のバッラ矢を取った。
tato duryodhanasya āśvān hatvā sūtaṃ ca pañcabhiḥ|
dhanuś ciccheda bhallena jātarūpapariṣkṛtam|| // 8-51-34 //
（34） そしてドゥルヨーダナの馬を倒し、御者を五本の矢で射て、黄金で飾られた弓をバッラ矢で切り落とした。
rathaṃ sopaskaraṃ chatraṃ śaktiṃ khaṅgaṃ gadāṃ dhvajam|
bhallaiś ciccheda daśabhiḥ putrasya tava pārṣataḥ|| // 8-51-35 //
（35） パールシャタは汝の息子の戦車と装具、日傘、槍、剣、棍棒、旗を十本のバッラ矢で打ち砕いた。
tapanīyāṅgadaṃ chatraṃ nāgaṃ maṇimayaṃ śubham|
dhvajaṃ kurupateś chinnaṃ dadṛśuḥ sarvapārthivāḥ|| // 8-51-36 //
（36） 黄金の腕輪、日傘、宝石で飾られた象の旗印が切り落とされたのを、全ての王たちが目撃した。
duryodhanaṃ tu virathaṃ chinnavarmāyudhadhvajam|
bhrātaraṃ samudaikṣanta sodarā bharatarṣabha|| // 8-51-37 //
（37） バーラタ族の雄牛よ、車を失い鎧も武器も旗も失ったドゥルヨーダナを、同母の兄弟たちは見つめた。
tamāropya rathe rājan kuṇḍadhāro mahāratham|
apāharad asambhrānto dhṛṣṭadyumnasya paśyataḥ|| // 8-51-38 //
（38） 王よ、大戦車戦士クンダダーラが、ドゥリシュタデュムナが見ている前で、慌てることなく彼を自分の戦車に乗せて退却させた。
karṇas tu sātyakiṃ hitvā rājagṛghnur amarṣaṇaḥ|
droṇahantāram ugreṣuṃ sasārābhimukho raṇe|| // 8-51-39 //
（39） カルナはサーティヤキを置き去りにし、王を奪い返さんとする怒りを抱き、ドローナ殺しの猛弓手（ドゥリシュタデュムナ）に向かって突進した。
taṃ pṛṣṭhato'nvayāttūrṇaṃ śaineyo'bhihataḥ śaraiḥ|
vāraṇaṃ jaghanopānte viṣāṇābhyām iva dvipaḥ|| // 8-51-40 //
（40） シャイネーヤ（サーティヤキ）は矢に打たれながらも背後から素早く追い、象の尾の傍で牙で突く象のごとくであった。
sa bhāratapurogānāṃ rājñāṃ ca sumahātmanām|
karṇapārṣatayor yuddhe saṅkruddhānāṃ mahāraṇe|| // 8-51-41 //
（41） バーラタ族を先頭とする王たちと偉大なる魂の者たちの、カルナとパールシャタの間に怒りに燃える大戦闘の中にあって、
na pāṇḍavānāṃ nāsmākaṃ kaścid āsīt parāṅmukhaḥ|
pratyadṛśyata yat karṇaḥ pāñcālāṃs tvarito yayau|| // 8-51-42 //
（42） パーンダヴァ軍にもわが方にも背を向ける者は一人もいなかった。カルナが急いでパーンチャーラ軍に向かったのが見えたのだ。
tasmin kṣaṇe naraśreṣṭha gajavājirathakṣayaḥ|
prādurāsīd ubhayato rājan madhyagate ahani|| // 8-51-43 //
（43） 人の最良者よ、まさにその瞬間、日の半ばにおいて、象・馬・戦車の壊滅が両陣に生じた。
pāñcālās tu mahārāja tvaritā vijigīṣavaḥ|
sarvato'bhyadravan karṇaṃ patattriṇa iva drumam|| // 8-51-44 //
（44） 大王よ、勝利を求めて急ぐパーンチャーラ族は、鳥が木に群がるように四方からカルナに殺到した。
teṣāmādhirathiḥ kruddhaḥ pradhānān vai tarasvinaḥ|
vicinvan iva bāṇaughaiḥ samāsādayad agrataḥ|| // 8-51-45 //
（45） アディラティの息子（カルナ）は怒り、彼らの主立った勇者たちを矢の群れで探し当てるかのように、前方で迎え撃った。
vyāghraketuḥ suśarmā ca śukraś citrāyudhaḥ kratuḥ|
durjayo rocamānaś ca siṃhasenas tathā aṣṭamaḥ|
mahatā rathavaṃśena parivavrur narottamam|| // 8-51-46 //
（46） ヴィヤーグラケートゥ、スシャルマン、シュクラ、チトラーユダ、クラトゥ、ドゥルジャヤ、ローチャマーナ、そしてシンハセーナの八人目、これら大戦車軍団でこの人の最良者を取り囲んだ。
sṛjantaḥ sāyakāṃstūrṇaṃ karṇamāhavaśobhinam|
yatamānāṃs tu tāñ śūrān manujendraḥ śitaiḥ śaraiḥ|
aṣṭābhir aṣṭau rādheyaḥ pāñcālān nyahanad raṇe|| // 8-51-47 //
（47） 戦場で輝くカルナに矢を放つこれらの勇者たちを、ラーデーヤ（カルナ）は鋭い矢で、八人をそれぞれ八本ずつの矢で、パーンチャーラ戦士を戦場で打ち倒した。
athāparānmahārāja sūtaputraḥ pratāpavān|
jaghāna bahusāhasrān yodhān yuddhaviśāradān|| // 8-51-48 //
（48） 大王よ、さらにスータの息子は勇猛なる者として、戦に熟練した戦士たちを数千人も打ち倒した。
viṣṇuṃ ca viṣṇuvarmāṇaṃ devāpiṃ bhadrameva ca|
daṇḍadhāraṃ ca samare citraṃ ciṃtrāyudhaṃ harim|| // 8-51-49 //
（49） ヴィシュヌ、ヴィシュヌヴァルマン、デーヴァーピ、バドラ、ダンダダーラ、チトラ、チトラーユダ、ハリ、
siṃhaketuṃ rocamānaṃ śalabhaṃ ca mahāratham|
nijaghāna susaṅkruddhaś cedīnāṃ ca mahārathān|| // 8-51-50 //
（50） シンハケートゥ、ローチャマーナ、シャラバの大戦車戦士を大いに怒って殺し、チェーディ族の大戦車戦士たちをも倒した。
teṣām ādadataḥ prāṇān āsīd ādhirather vapuḥ|
śoṇitābhyukṣitāṅgasya rudrasya eva atibhairavam|| // 8-51-51 //
（51） 命を奪い続けるアディラティの息子の姿は、血に染まった体のルドラ神のごとく極めて恐ろしかった。
tatra bhārata karṇena mātaṅgāstāḍitāḥ śaraiḥ|
sarvato'bhyadravan bhītāḥ kurvanto mahad ākulam|| // 8-51-52 //
（52） バーラタよ、カルナの矢に打たれた象たちは、恐怖に駆られて四方に逃げ惑い、大混乱を引き起こした。
nipetururvyāṃ samare karṇasāyakatāḍitāḥ|
kurvanto vividhān nādān vajranunnā iva acalāḥ|| // 8-51-53 //
（53） カルナの矢に打たれた象たちは戦場に倒れ、雷に打たれた山々のごとくさまざまな叫び声を上げた。
gajavājimanuṣyaiś ca nipatadbhiḥ samantataḥ|
rathair bhagnair dhvajaiś ca eva samāstīryata medinī|| // 8-51-54 //
（54） 象・馬・人間が四方から倒れ、壊れた戦車や旗と共に大地は覆い尽くされた。
na evaṃ bhīṣmo na ca droṇo na anye yudhi ca tāvakāḥ|
cakruḥ sma tādṛśaṃ karma yādṛśaṃ kṛtavān raṇe|| // 8-51-55 //
（55） ビーシュマもドローナも、他の味方の戦士たちも、この戦いでこれほどの武勲を立てたことはなかった。カルナが戦場で成し遂げたことに比べれば。
mṛgamadhye yathā siṃho dṛśyate nirbhayaścaran|
pāñcālānāṃ tathā madhye karṇaḥ acarad abhītavat|| // 8-51-56 //
（56） 鹿の群れの中で恐れなく歩くライオンのように、カルナはパーンチャーラ族の只中を恐れることなく進んだ。
sūtaputro'tha nāgeṣu hayeṣu ca ratheṣu ca|
nareṣu ca naravyāghraścakāra kadanaṃ mahat|| // 8-51-57 //
（57） スータの息子は、人中の虎として、象・馬・戦車・人間に対して大殺戮を行った。
yathā mṛgagaṇāṃs trastān siṃho drāvayate diśaḥ|
pāñcālānāṃ rathavrātān karṇo vyadrāvayat tathā|| // 8-51-58 //
（58） ライオンが恐れる鹿の群れを四方に追い散らすように、カルナはパーンチャーラの戦車軍団を追い散らした。
siṃhaṃ sma hi yathā prāpya na jīvanti mṛgāḥ kvacit|
tathā karṇamanuprāptā na jīvanti sma sṛñjayāḥ|| // 8-51-59 //
（59） ライオンに遭遇した鹿がどこにも生き残れぬように、カルナに遭遇したスリンジャヤ族は生き残れなかった。
vaiśvānaramukhaṃ prāpya dahyante śalabhā yathā|
karṇāgriṃ samare prāpya dagdhā bhārata sṛñjayaḥ|| // 8-51-60 //
（60） 蛾がアグニ（火）の炎に飛び込んで焼かれるように、バーラタよ、スリンジャヤ族は戦場でカルナの火に遭って焼かれた。
cediṣvekena karṇena pāñcāleṣu ca bhārata|
veśrāvya nāma nihatā bahavaḥ śūrasampatāḥ|| // 8-51-61 //
（61） バーラタよ、チェーディ族とパーンチャーラ族の中で、カルナ一人によって名を馳せた多くの勇者が倒された。
mama ca āsīn matī rājan dṛṣṭvā karṇasya vikramam|
na eko'pi ādhirather jīvan pāñcālyo mokṣyate yudhi|| // 8-51-62 //
（62） 王よ、カルナの武勇を見て、私にはこう思えた。アディラティの息子から戦場で生きて逃れられるパーンチャーリヤは一人もいまいと。
saṅkhye vimardya pāñcālān sūtaputraḥ punaḥ punaḥ|
abhyadhāvat susaṅkruddhaḥ kuntīputraṃ yudhiṣṭhiram|| // 8-51-63 //
（63） スータの息子は戦いでパーンチャーラ族を繰り返し蹂躙し、大いに怒ってクンティーの息子ユディシュティラに向かって突進した。
dhṣṭadyumnaś ca rājānaṃ draupadeyāś ca māriṣa|
parivavrur amitraghnaṃ śataśaś ca apare janāḥ|| // 8-51-64 //
（64） しかしドゥリシュタデュムナと、ドラウパディーの息子たち、そして親愛なる者よ、敵を殺す者（ユディシュティラ）を、数百の他の者たちが取り囲んだ。
śikhaṇḍī sahadevaś ca nakulo nākulistathā|
janamejayaḥ śiner naptā bahavaś ca prabhadrakāḥ|| // 8-51-65 //
（65） シカンディン、サハデーヴァ、ナクラ、ナークリ（ナクラの息子）、ジャナメージャヤ、シニの孫（サーティヤキ）、そして多くのプラバドラカ族が。
ete purogamā bhūtvā dhṣṭadyumnaś ca saṃyuge|
karṇam asyantam iṣvastrais tatakṣur amitaujasam|| // 8-51-66 //
（66） ドゥリシュタデュムナを先頭に、これらの者たちが戦場で、矢と武器を放ちながら、計り知れぬ力を持つカルナを攻撃した。
tāṃs tatra ādhirathiḥ saṅkhye cedipāñcālapāṇḍavān|
eko bahūn abhyapatad garutmān iva pannagān|| // 8-51-67 //
（67） 戦場でアディラティの息子は、チェーディ・パーンチャーラ・パーンダヴァ連合に対して、ガルダが蛇たちに向かうように、一人で多勢に立ち向かった。
taiḥ karṇasya abhavad yuddhaṃ ghorarūpaṃ viśāmpate|
tādṛg yādṛk purāvṛttaṃ devānāṃ dānavaiḥ saha|| // 8-51-68 //
（68） 王よ、カルナと彼らの間の戦いは、かつて神々と阿修羅の間に起こったのと同じほど恐ろしい姿であった。
tān sametān maheṣvāsāñ śaravarṣaudhavarṣiṇaḥ|
eko vyadhamad avyagras tamāṃsi iva divākaraḥ|| // 8-51-69 //
（69） 矢の雨を降らす大弓手たちが集まったのに、一人で動じることなく彼らを打ち負かした。闇を払う太陽のごとく。
bhīmasenas tu saṃsakte rādheye pāṇḍavaiḥ saha|
sarvato'bhyahanat kruddho yamadaṇḍanibhaiḥ śaraiḥ|| // 8-51-70 //
（70） ラーデーヤ（カルナ）がパーンダヴァ軍と交戦している間に、ビーマセーナは怒り、ヤマの杖のごとき矢で四方から打ちかかった。
bāhlīkān kekayān mātsyān vāsātyān madrasaindhavān|
ekaḥ saṅkhye maheṣvāso yodhayan bahu aśobhata|| // 8-51-71 //
（71） バーフリーカ族、ケーカヤ族、マツヤ族、ヴァサーティ族、マドラ族、サインダヴァ族を、大弓手として一人で戦い、大いに輝いた。
tatra marmasu bhīmena nārācaistāḍitā gajāḥ|
prapatanto hatārohāḥ kampayanti sma medinīm|| // 8-51-72 //
（72） そこでビーマによって急所に鉄矢を射られた象たちは、騎手を失い倒れ落ちて大地を震わせた。
vājinaś ca hatārohāḥ pattayaś ca gatāsavaḥ|
aśerata mahārāja vamanto rudhiraṃ bahu|| // 8-51-73 //
（73） 大王よ、騎手を失った馬たち、命を落とした歩兵たちは、大量の血を吐きながら横たわった。
tāḍitāḥ sahasā nāgā bhīmasenena māriṣa|
nipatanti mahāvegā vajrarugṇā iva acalāḥ|| // 8-51-74 //
（74） 親愛なる者よ、ビーマセーナに突然打たれた象たちは、雷に砕かれた山のごとく大きな速度で倒れた。
patitais tair mahārāja vegavadbhir mahārathaiḥ|
śuśubhe vasudhā rājan vikīrṇair iva parvataiḥ|| // 8-51-75 //
（75） 大王よ、倒れた大戦車や猛スピードの勇者たちで、大地は散乱した山々のように美しく見えた。
sahasraśaś ca rathinaḥ pattayaḥ patitāyudhāḥ|
akṣatāḥ samadṛśyanta bhīmād bhītā gatāsavaḥ|| // 8-51-76 //
（76） 千人単位の戦車兵や歩兵が武器を落とし、無傷であるのにビーマを恐れて命を落としたかのように見えた。
rathibhiḥ sādibhiḥ sūtaiḥ pādātair vājibhir gajaiḥ|
bhīmasenaśaraiś chinnair ācchannā sudhā abhavat||
tat stambhitam iva atiṣṭhad bhīmasenabhayārditam| // 8-51-77 //
（77） 戦車兵、騎兵、御者、歩兵、馬、象たちはビーマセーナの矢で切り裂かれ、大地は覆い尽くされた。
duryodhanabalaṃ sarvaṃ nirutsāhaṃ kṛtaṃ raṇe|
niśceṣṭaṃ tumulaṃ dīnaṃ babhau tasmin mahāraṇe|| // 8-51-78 //
（78） ビーマセーナの恐怖に打ちのめされたドゥルヨーダナの全軍は、戦場で意気消沈し、動けず、混乱し、力なく佇んでいた。
prasannasalile kāle yathā syāt sāgaro nṛpa|
tadvat tava balaṃ tad vai niścalaṃ samavasthitam|| // 8-51-79 //
（79） 王よ、穏やかな季節の静まった海のごとく、汝の軍は静止して動かなかった。
manyuvīryabalopetaṃ darpāt pratyavaropitam|
abhavat tava putrasya tat sainyaṃ niṣprabhaṃ tadā|| // 8-51-80 //
（80） 士気と勇気と力を失い、傲慢さを打ち砕かれた汝の息子の軍は、そのとき輝きを失っていた。
te bale bharataśreṣṭha vadhyamāne parasparam|
rudhiraughapariklinne rudhirārdre babhūvatuḥ|| // 8-51-81 //
（81） バーラタ族の最良者よ、互いに倒し合う両軍は、血の流れに浸って血に濡れていた。
sūtaputraḥ avadhīt kruddhaḥ pāṇḍavānām anīkinīm|
bhīmasenaḥ kurūṇāṃ ca trigartānāṃ dhanañjayaḥ|| // 8-51-82 //
（82） スータの息子は怒ってパーンダヴァ軍を殺し、ビーマセーナはクル軍を、ダナンジャヤはトリガルタ族を倒した。
vartamāne tathā rodre saṅgrāme adbhutadarśane|
nihatya pṛtanāmadhyaṃ saṃśaptakagaṇān bahūn|
arjuno jayatāṃ śreṣṭho vāsudevam atha abravīt|| // 8-51-83 //
（83） このように恐ろしく驚嘆すべき戦いが進む中、サムシャプタカの大群を軍の真ん中で打ち倒し、勝利者の最上たるアルジュナはヴァースデーヴァ（クリシュナ）に語った。
prabhagnaṃ balam etad hi yotsyamānaṃ mayā saha|
ete dhāvanti sagaṇāḥ saṃśaptakamahārathāḥ|| // 8-51-84 //
（84） 「私と戦おうとしているこの軍はすでに崩壊した。サムシャプタカの大戦車戦士たちは軍勢もろとも逃走している。
'durjayā hi eva samare devair api savāsavaiḥ'|
apārayanto mad bāṇān siṃhaśabdaṃ mṛgā iva|| // 8-51-85 //
（85） ヴァーサヴァ（インドラ）を含む神々でさえ倒し難い彼らも、私の矢に堪えられず、鹿がライオンの咆哮を聞くように逃げている。
dīryate ca mahat sainyaṃ sṛñjayānāṃ mahāraṇe|
'kuravaś ca abhidhāvanti bhīmasenabhayārditāḥ'|| // 8-51-86 //
（86） スリンジャヤ軍の大軍勢は大戦闘で崩壊しつつある。クル軍もビーマセーナを恐れて追い回されている。
hastikakṣyo hi asau kṛṣṇa ketuḥ karṇasya dhīmataḥ|
dṛśyate rājasainyasya madhye vicarato muhuḥ|| // 8-51-87 //
（87） クリシュナよ、あの象の綱の旗印は智慧あるカルナのもの。王の軍の真ん中で彼がしきりに動き回っているのが見える。
na ca karṇaṃ raṇe śaktā jetum ete mahārathāḥ|
jānīte hi bhavān karṇaṃ vīryavantaṃ parākrame|| // 8-51-88 //
（88） 戦場でカルナを倒せる大戦車戦士はこれらの中にはいない。貴公もカルナが武勇において偉大であることを知っている。
tatra yāhi yataḥ karṇo drāvayati eṣa no balam|
trigartān varjayan yāhi sūtaputraṃ mahāratham|
etan me rocate kṛṣṇa yathā vā tava rocate|| // 8-51-89 //
（89） カルナがわが軍を追い散らしているところに向かってくれ。トリガルタ族を避け、大戦車戦士スータの息子に向かおう。これが私の望みだ。クリシュナよ、貴公の意見はいかに。」
etac chrutvā vacas tasya govindaḥ prahasan iva|
abravīd arjunaṃ tūrṇaṃ kauravān yāhi pāṇḍava|| // 8-51-90 //
（90） この言葉を聞いたゴーヴィンダ（クリシュナ）は微笑みながら、アルジュナに素早く言った。「パーンダヴァよ、カウラヴァ軍に向かおう。」
tatas tava mahāsainyaṃ govindapreritā hayāḥ|
haṃsavarṇā viśaṃs tūrṇaṃ vahantaḥ arjunam āhave|| // 8-51-91 //
（91） そしてゴーヴィンダに駆り立てられた白鳥の色をした馬たちは、戦場でアルジュナを乗せて汝の大軍勢に突入した。
keśavapreritair aśvaiḥ śvetaiḥ kāñcanabhūṣaṇaiḥ|
praviśadbhis tava balaṃ caturdiśam adīryata|| // 8-51-92 //
（92） ケーシャヴァ（クリシュナ）に駆られた黄金で飾られた白馬が突入すると、汝の軍は四方に崩れ去った。
meghastanitanirhādaḥ sa ratho vānaradhvajaḥ|
calatpatākas tāṃ senāṃ vimānaṃ dyām iva āviśat|| // 8-51-93 //
（93） 雷雲の轟きのような音を立てる猿の旗のある戦車は、旗がはためきながら、天上の宮殿が空に入るかのようにその軍勢に突入した。
tau vidārya mahāsenāṃ praviṣṭau keśavārjunau|
kruddhau saṃrambharaktākṣau vibhrājetāṃ mahādyutī|| // 8-51-94 //
（94） 大軍勢を引き裂いて突入したケーシャヴァとアルジュナは、怒りで目を赤く染め、大いなる輝きで光り輝いた。
yuddhaśauṇḍau samāhūtau āgatau tau raṇādhvaram|
yajvabhir vidhinā hūtau makhaṃ devāv iva aśvinau|| // 8-51-95 //
（95） 戦いに熟達した二人は、戦いの祭壇に招かれた。祭司が正しき儀式でアシュヴィン双神を祭りに招くように。
'krodhatāmrekṣaṇau śūrau śuśubhāte mahābalau|
madotkaṭau yathā nāgau dṛṣṭisañcāracāriṇau'|| // 8-51-96 //
（96） 怒りで目を赤銅色にした二人の勇者は大きな力を持ち、発情した二頭の象が視線を巡らせるかのように輝いた。
kruddhau tau tu naravyāghro yogavantau babhūvatuḥ|
talaśabdena ruṣitau mahānāgāv iva utkaṭau|| // 8-51-97 //
（97） 怒った二人の人中の虎は力に満ち、手の音で怒らされた巨大な狂象のごとくであった。
vigāhya tu rathānīkam aśvasaṅghāṃś ca phalgunaḥ|
vyacarat pṛtanāmadhye pāśahasta iva antakaḥ|| // 8-51-98 //
（98） 戦車軍団と馬の群れに飛び込んだパルグナ（アルジュナ）は、縄を手にした死神のように軍の真ん中を駆け巡った。
taṃ dṛṣṭvā yudhi vikrāntaṃ senāyāṃ tava bhārata|
saṃśaptakagaṇān bhūyaḥ putras te samacūcudat|| // 8-51-99 //
（99） バーラタよ、汝の軍で猛威を振るう彼を見て、汝の息子はサムシャプタカの群れを再びアルジュナに差し向けた。
tato rathasahasreṇa dviradānāṃ tribhiḥ śataiḥ|
caturdaśasahasrais tu turagāṇāṃ mahāhave|
dvābhyāṃ śatasahasrābhyāṃ padātīnāṃ ca dhanvinām||
śūrāṇāṃ labdhalakṣāṇāṃ viditānāṃ samantataḥ|
abhyavartanta kaunteyaṃ chādayanto mahārathāḥ|| // 8-51-100 //
（100） 千台の戦車、三百頭の象、一万四千の馬、二十万の弓を持つ歩兵、
śaravarṣairmahārāja sarvataḥ pāṇḍunandanam|
sa cchādyamānaḥ samare śaraiḥ parabalārdanaḥ|| // 8-51-101 //
（101） 技を磨き名を馳せた勇者たる大戦車戦士たちが、矢の雨でクンティーの息子を覆い隠しながら迫ってきた。
darśayan raudram ātmānaṃ pāśahasta iva antakaḥ|
nighnan saṃśaptakān pārthaḥ prekṣaṇīyataraḥ abhavat|| // 8-51-102 //
（102） 大王よ、戦場で矢に覆われながらも、敵軍を滅ぼすその者は、縄を手にした死神のような恐ろしい姿を見せ、サムシャプタカ族を倒すパールタ（アルジュナ）はますます見事に見えた。
tato vidyutprabhair bāṇaiḥ kārtasvaravibhūṣitaiḥ|
nirantaram iva ākāśam āsīc channaṃ kirīṭinā|| // 8-51-103 //
（103） 稲妻のように輝く黄金で飾られた矢によって、キリーティン（アルジュナ）が放つとすき間なく空が覆われた。
kirīṭicāpanirmuktaiḥ sampatadbhir mahāśaraiḥ|
samācchannaṃ babhau sarvaṃ kādraveyair iva prabho|| // 8-51-104 //
（104） キリーティンの弓から放たれた大矢が飛び交い、王よ、全てがカードラヴェーヤ（蛇）の群れのように覆い尽くされた。
rukmapuṅkhāñ śarān ghorān prasannān nataparvaṇaḥ|
avāsṛjad ameyātmā dikṣu sarvāsu pāṇḍavaḥ|| // 8-51-105 //
（105） 計り知れぬ心のパーンダヴァは、黄金の矢羽根を持つ恐ろしい矢を、滑らかなしなりのものを、全方位に放った。
mahī viyaddiśaḥ sarvāḥ samudrā girayo'pi vā|
sphuṭantīti janā jajñuḥ pārthasya talaniḥsvanāt|| // 8-51-106 //
（106） パールタの弓弦の音に、人々は大地も空も方角も海も山もすべて砕けるのではないかと思った。
hatvā daśasahasrāṇi pārthivānāṃ mahārathaḥ|
saṃśaptakānāṃ kaunteyaḥ prapakṣaṃ tvarito'bhyayāt|| // 8-51-107 //
（107） 大戦車戦士クンティーの息子は、サムシャプタカの中の一万の王を倒し、急いで側翼に向かった。
prapakṣaṃ ca samāsādya pārthaḥ kāmbhojarakṣitam|
pramamātha balaṃ bhallair dānavān iva vāsavaḥ|| // 8-51-108 //
（108） カーンボージャ族が守る側翼に到達したパールタは、インドラがダーナヴァ族を滅ぼすように、バッラ矢で軍勢を粉砕した。
pracicchedāśu bhallena dviṣatām ātatāyinām|
śastrapāṇīṃs tathā bāhūṃs tathā api ca śirāṃsi uta|| // 8-51-109 //
（109） 武器を構えた敵の腕や首をバッラ矢で素早く切り落とした。
aṅgāṃṅgāvayavaiśchinnair vyāyudhās te apatan bhuvi|
viṣvagvātābhisambhagnā bahuśākhā iva drumāḥ|| // 8-51-110 //
（110） 肢体を切り裂かれ武器を失った彼らは、様々な方向から吹く風に折られた多くの枝を持つ木々のように地面に倒れた。
hastyaśvarathapattīnāṃ vrātān nighnantam arjunam|
sudakṣiṇādavarajaḥ śaravṛṣṭyābhyavīvṛṣat|| // 8-51-112 //
（112） 象・馬・戦車・歩兵の群れを倒し続けるアルジュナに、スダクシナの弟が矢の雨を浴びせた。
tasya āsyato ardhacandrābhyāṃ sa bāhū parighopamau|
pūrṇacandrābhavaktraṃ ca kṣureṇa apāharac chiraḥ|| // 8-51-113 //
（113） 矢を放つ彼の両腕を二本の半月矢で、そして満月のような顔を剃刀矢で切り落とした。
tat papāta tato vegāt svalohitapariṣkṛtam|
manaḥ śilāgireḥ śṛṅgaṃ vajreṇa iva avadāritam|| // 8-51-114 //
（114） その首は勢いよく落ち、自らの血で飾られ、まるで赤い鉱石の山の峰が雷によって割られたかのようであった。
sudakṣiṇādavarajaṃ kāmbhojā dadṛśur hatam|
prāṃśuṃ kamalapatrākṣamatyarthaṃ priyadarśanam|
kāñcanastambhasadṛśaṃ bhinnaṃ hemagiriṃ yathā|| // 8-51-115 //
（115） カーンボージャ族は殺されたスダクシナの弟を見た。背が高く蓮の花弁のような目を持ち、極めて美しく、黄金の柱のようで、砕かれた黄金の山のようであった。
tato'bhavat punar yuddhaṃ ghoram atyartham adbhutam|
nānāvasthāś ca yodhānāṃ babhūvus tatra yudhyatām|| // 8-51-116 //
（116） それから再び恐ろしく驚嘆すべき戦いが始まり、戦う者たちにさまざまな状況が生じた。
pārtheṣu nihatair aśvaiḥ kāmbhojairyavanaiḥ śakaiḥ|
śoṇitāktais tadā raktaṃ sarvā āsīd viśāṃ pate|| // 8-51-117 //
（117） 王よ、アルジュナの矢に倒されたカーンボージャ族、ヤヴァナ族、シャカ族は血に染まり、全てが赤くなった。
rathair hatāśvasūtaiś ca hatārohaiś ca vājibhiḥ|
dviradaiś ca hatārohair mahāmātrair hatadvipaiḥ|| // 8-51-118 //
（118） 馬と御者を失った戦車、騎手を失った馬、騎手を失った象、象を失った象使いたちが。
anyonyena mahārāja vināśaḥ pṛthivīkṣitām|
āsīt kruddhe arjune karṇe bhīmasene ca dāruṇam|| // 8-51-119 //
（119） 大王よ、アルジュナとカルナとビーマセーナが怒ったとき、王たちの相互の壊滅は恐ろしいものであった。
tasmin prapakṣe pakṣe ca vadhyamāne madotkaṭaḥ|
arjunaṃ jayatāṃ śreṣṭhaṃ tvarito drauṇir abhyayāt|| // 8-51-120 //
（120） 側翼も主力も壊滅させられていく中で、狂奔するドラウニ（アシュヴァッターマン）は勝利者の最良者アルジュナに急いで向かった。
vidhunvāno mahat cāpaṃ kārtasvaravibhūṣitam|
ādadānaḥ śarān ghorān svaraśmīn iva bhāskaraḥ|| // 8-51-121 //
（121） 黄金で飾られた大弓をしならせ、太陽が光線を手にするように恐ろしい矢を取って。
tayor āsīn mahad yuddhaṃ dharmabhrātror anaiṣṭhikam|
vismāpayiṣator lokaṃ yaśaś ca uttamam icchatoḥ|| // 8-51-122 //
（122） 法の兄弟である二人の間の大いなる戦いは決着がつかず、世界を驚嘆させ、最高の名声を求める二人であった。
saṃśaptakāṃs tu kaunteyaḥ kurūṃś ca api vṛkodaraḥ|
sūtaputras tu pāñcālāṃs trayo aghnaṃs tvaritāḥ śaraiḥ|| // 8-51-123 //
（123） クンティーの息子はサムシャプタカ族を、ヴリコーダラ（ビーマ）はクル軍を、スータの息子はパーンチャーラ族を、三人がそれぞれ急いで矢で倒した。
evam eṣa mahārāja vināśaḥ pṛthivīkṣitām|
yuddhaṃ ghoraṃ tathā tu āsīt tridhābhūte camūmukhe|| || // 8-51-124 //
（124） 大王よ、このように王たちの壊滅が起き、戦場が三つに分かれた中で恐ろしい戦闘が続いた。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekapañcāśo'dhyāyaḥ|| 51 ||
こうして、聖なる大マハーバーラタのカルナ篇の第五十一章は終わる。
