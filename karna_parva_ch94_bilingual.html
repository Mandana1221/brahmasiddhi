マハーバーラタ ― カルナ篇 第94章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 94 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ94」で、カルナとアルジュナの戦闘開始、アシュヴァッターマンによる和平勧告の場面を描きます。
karṇaparva — caturnavatitamo'dhyāyaḥ (94)
第94章 ― カルナとアルジュナの戦闘開始、アシュヴァッターマンの和平勧告
sañjaya uvāca|
taddetanāgāsurasiddhayakṣairgandharvarakṣopsarasāṃ ca saṅghaiḥ|
brahmarṣirājarṣisuparṇajuṣṭaṃ babhau viyadvismayanīyarūpam||
// 8-94-1 //
サンジャヤは語った。
天空は、神々、ナーガ、アスラ、シッダ、ヤクシャ、ガンダルヴァ、ラークシャサ、アプサラスの群れ、ブラフマリシ、ラージャリシ、スパルナ（ガルダ族）で満たされ、驚嘆すべき姿をしていた。
nānadyamānaṃ ninadairmanojñairvāditragītastutinṛtyahāsaiḥ|
sarve'ntarikṣaṃ dadṛśurmanuṣyāḥ khasthāśca tadvismayanīyarūpam||
// 8-94-2 //
心地よい旋律、楽器の音、歌、賛美、踊り、笑い声が響き渡り、すべての人間は天空を見上げ、天の者たちもまた驚嘆の光景を見つめた。
tataḥ prahṛṣṭāḥ kurupāṇḍuyodhā vāditraśaṅkhasvanasiṃhanādaiḥ|
vinādayanto vasudhāṃ diśaśca svanena sarvāndviṣato nijaghnuḥ||
// 8-94-3 //
そしてクル勢とパーンドゥ勢の兵士たちは奮い立ち、楽器と法螺貝の音、獅子の咆哮で大地と四方を震わせ、その響きですべての敵を撃った。
narāśvamātaṅgarathaiḥ samākulaṃ śarāsiśaktyṛṣṭinipātaduḥsaham|
abhīrujuṣṭaṃ hatadehasaṅkulaṃ raṇājiraṃ lohitamābabhau tadā||
// 8-94-4 //
人・馬・象・戦車で混み合い、矢・剣・槍の落下が耐えがたく、勇者たちが集い、討たれた体で散乱した戦場は血で赤く染まっていた。
babhūva yuddhaṃ kurupāṇḍavānāṃ yathā surāṇāmasuraiḥ sahābhavat|
tathā pravṛte tumule sudāruṇe dhanañjayaścādhirathiśca sāyakaiḥ|
diśaśca sainyaṃ ca śitairajihmagaiḥ parasparaṃ prāvṛṇutāṃ sudaṃśitau||
// 8-94-5 //
こうした恐るべき戦いの中、ダナンジャヤとアディラティ（カルナ）は鋭い矢で、四方と全軍を互いに覆い尽くした。
tatastvadīyāśca pare ca sāyakaiḥ kṛte'ndhakāre dadṛśurna kiñcana|
bhayāturā ekarathau samāśrayaṃstato'bhavattvadbhutameva sarvataḥ||
// 8-94-6 //
おまえの兵と敵の兵が矢で暗闇を作り上げ、何も見えなくなった。恐怖に駆られた者たちは二人の卓越した戦車戦士のもとに身を寄せ、あたり一面が驚異的な光景となった。
tato'stramastreṇa parasparaṃ tau vidhūya vātāviva pūrvapaścimau|
ghanāndhakāre vitate tamonudau yathoditau tadvadatīva rejatuḥ||
// 8-94-7 //
二人は互いの武器を武器で打ち払い、東風と西風のように。濃い暗闇が広がる中、闇を払う太陽と月のように、二人は輝いた。
na cābhisartavyamiti pracoditāḥ pare tvadīyāśca tathā'vatasthire|
mahārathau tau parivārya sarvataḥ surāsurāḥ śambaravāsavāviva||
// 8-94-8 //
「近づくべからず」と命じられた味方の兵も敵の兵もその場に留まり、二人の偉大な戦車戦士を取り囲んだ。まるで神々とアスラがシャンバラとヴァーサヴァ（インドラ）を取り囲むように。
mṛdaṅgabherīpaṇavānakasvanairninādite vāhanaśaṅkhanisvanaiḥ|
tau siṃhanādairbabhaturnarottamau pataṅgacandrāviva duḥsahāvubhau||
// 8-94-9 //
太鼓・銅鑼・小太鼓・軍鼓の音、乗り物と法螺貝の響きの中で、二人の人中の最良者は獅子の咆哮をあげ、太陽と月のように耐えがたい存在であった。
mahādhanurmaṇḍulamadhyagāvubhau suvarcasau bāṇasahasradīdhitī|
didhakṣamāṇau sacarācaraṃ jagadyugāntasūryāviva duḥsahau raṇe||
// 8-94-10 //
大弓の円の中にあって、矢の千本の光線を放ちながら、動くものも動かぬものもこの世界を焼き尽くそうとするかのように、世界の終末の二つの太陽のように戦場で耐えがたかった。
ubhāvajeyāvahitāntakāvubhāvubhau jighāṃsū kṛtinau parasparam|
mahāhave vītabhayau samīyaturmahendrajambhāviva karṇapāṇḍavau||
// 8-94-11 //
二人とも無敵で死神の如く、互いを殺そうとする達人であった。恐れなく大いなる戦いに挑んだカルナとパーンダヴァは、マヘーンドラ（インドラ）とジャンバのようであった。
tato mahāstrāṇi mahādhanurdharau vimuñcamānāviṣubhirbhayānakaiḥ|
narāśvanāgānamitānnijaghnatuḥ parasparaṃ cāpi mahārathau nṛpa||
// 8-94-12 //
偉大なる武器を持つ二人の大弓の持ち主が恐ろしい矢を放ち、人・馬・象を無数に討ち取り、互いをも打ち合った、王よ。
tato visasruḥ punararditā narā narottamābhyāṃ kurupāṇḍavāśrayāḥ|
sanāgapattyaśvarathā diśo drutāstathā yathā siṃhahatā vanaukasaḥ||
// 8-94-13 //
二人の人中の最良者に打たれて、クル勢とパーンダヴァ勢の兵たちは再び散り散りになった。象・歩兵・馬・戦車とともに四方に逃走した。まるで獅子に追われた森の動物のように。
tatastu duryodhanabhojasaubalāḥ kṛpo guroścāpi suto mahāhave|
mahārathāḥ pañca dhanañjayācyutau śaraiḥ śarīrārtikarairatāḍayan||
// 8-94-14 //
するとドゥルヨーダナ、ボージャ、ソウバラ（シャクニ）、クリパ、そして師（ドローナ）の息子（アシュヴァッターマン）の五人の大戦車戦士が、ダナンジャヤとアチュタ（クリシュナ）を、体に苦痛を与える矢で射った。
dhanūṃṣi teṣāmiṣudhīndhvajānhayānrathāṃśca sūtāṃśca dhanañjayaḥ śaraiḥ|
samaṃ pramadhyāśu parānsamantataḥ śarottamairdvādaśabhinna sūtajam||
// 8-94-15 //
ダナンジャヤは矢で彼らの弓、矢筒、旗、馬、戦車、御者をすべて打ち砕き、十二本の最上の矢でカルナ以外の四方の敵を撃退した。
athābhyadhāvaṃstvaritāḥ śataṃ rathāḥ śataṃ gajāścārjunamātatāyinaḥ|
śakāstuṣārā yavanāśca sādinaḥ sahaiva kāmbhojavarairjighāṃsavaḥ||
// 8-94-16 //
百台の戦車と百頭の象が弓を構えてアルジュナに突進してきた。シャカ族、トゥシャーラ族、ヤヴァナ族の騎兵も、カーンボージャの精鋭とともに殺意をもって迫った。
varāyudhānpāṇigataiḥ śaraiḥ saha kṣurairnyakṛntatprapatañśirāṃsi ca|
hayāṃśca nāgāṃśca rathāṃśca yudhyato dhanañjayaṛ śatrugaṇānkṣitau kṣiṇaut||
// 8-94-17 //
ダナンジャヤは手に握った矢とカミソリ矢で、優れた武器を持つ者たちの首を次々に斬り落とし、戦う馬・象・戦車を大地に倒した。
tato'ntarikṣe suratūryaniḥsvanāḥ sasādhuvādā hṛṣitaiḥ samīritāḥ|
nipeturapyuttamapuṣpavṛṣṭayaḥ surūpagandhāḥ pavaneritāḥ śubhāḥ||
// 8-94-18 //
すると天空で神々の楽器の音が響き、喜んだ者たちから「素晴らしい！」との称賛が発せられ、美しい姿と香りを持つ最高の花の雨が風に乗って降り注いだ。
tadadbhutaṃ devamanuṣyasākṣikaṃ samīkṣya bhūtāni visismiyustadā|
tavātmajaḥ sūtasutaśca na vyathāṃ na vismayaṃ jagmaturekaniścayau||
// 8-94-19 //
この驚異的な光景を、神々と人間が証人として見届けた。すべての生きものが驚嘆した。しかしおまえの息子（ドゥルヨーダナ）とスータの息子（カルナ）は動揺も驚きもせず、決意を固くしていた。
athābravīddroṇasutastavātmajaṃ karaṃ kareṇa pratipīḍya sāntvayan|
prasīda duryodhana śāmya pāṇḍavairalaṃ virodhena dhigastu vigraham||
// 8-94-20 //
そこでドローナの息子（アシュヴァッターマン）が、おまえの息子の手を握り、なだめながら言った。「ドゥルヨーダナよ、落ち着いてくれ。パーンダヴァたちと和解せよ。敵対はもう十分だ。争いなど忌まわしいものだ。」
hato gururbrahmasamo mahāstravittathaiva bhīṣmapramukhā mahārathāḥ|
ahaṃ tvavadhyo mama cāpi mātulaḥ praśādhi rājyaṃ saha pāṇḍavaiściram||
// 8-94-21 //
「ブラフマーに等しい偉大な武器の達人である師（ドローナ）は討たれた。ビーシュマを筆頭に大戦車戦士たちも討たれた。しかし私は不死身であり、私の叔父（クリパ）もそうだ。パーンダヴァたちとともに永く王国を治めてくれ。」
dhanañjayaḥ syāsyati vārito mayā janārdano naiva virodhamicchati|
yudhiṣṭhiro bhūtahite rataḥ sadā vṛkodarastadvaśagastathā yamau||
// 8-94-22 //
「ダナンジャヤは私が説得して止めよう。ジャナールダナ（クリシュナ）もまた争いを望んでいない。ユディシュティラは常に生きとし生けるものの幸福を願っている。ヴリコーダラ（ビーマ）も彼に従い、双子もそうだ。」
tvayā tu pārthaiśca kṛte ca saṃvide prajāḥ śivaṃ prāpnuyuricchayā tava|
vrajantu śeṣāḥ svapurāṇi pārthivā nivṛttavairāśca bhavantu sainikāḥ|
na cedvacaḥ śroṣyasi me narādhipa dhruvaṃ hi tapto'si hato'ribhiryudhi||
// 8-94-23 //
「おまえがパールタたちと和解すれば、おまえの意志によって人々は幸福を得るだろう。残りの王たちは自らの都に帰り、兵士たちは敵意を捨てるだろう。もし私の言葉を聞き入れなければ、おまえは必ず敵に討たれて苦しむことになる。」
vṛddhaṃ pitaramālokya gāndhārīṃ ca yaśasvinīm|
kṛpālurdharmarājo hi yācitaḥ śamameṣyati||
// 8-94-24 //
「年老いた父と名高いガーンダーリー（母）を見てくれ。慈悲深きダルマラージャ（ユディシュティラ）は、頼めば和解に応じるだろう。」
yathocitaṃ ca vai rājyamanujñāsyati te prabhuḥ|
vipaścitsumatirvīraḥ sarvaśāstrārthatattvavit||
// 8-94-25 //
「そして王としてふさわしい王国をおまえに与えてくれるだろう。彼は賢明で良い考えを持つ勇者であり、すべての教典の真髄を知る者だ。」
vairaṃ neṣyati dharmātmā svajane nāstyatikramaḥ|
na vigrahamatiḥ kṛṣṇā svajane pratinandati||
// 8-94-26 //
「ダルマの人（ユディシュティラ）は恨みを忘れてくれよう。身内に対して度を越したことはしない。クリシュナー（ドラウパディー）もまた、身内への争いを喜ばない。」
bhīmasenārjunau cobhau mādrīputrau ca pāṇḍavau|
vāsudevamate caiva pāṇḍavasya ca dhīmataḥ|
sthāsyanti puruṣavyāghrāstayorvacanagauravāt||
// 8-94-27 //
「ビーマセーナとアルジュナも、マードリーの二人の息子たちも、ヴァースデーヴァの意見と賢きパーンダヴァ（ユディシュティラ）の考えに、その言葉の重みゆえに従うだろう。」
rakṣa duryodhanātmānamātmā sarvasya bhājanam|
jīvane yatnamātiṣṭha jīvanbhadrāṇi paśyati||
// 8-94-28 //
「ドゥルヨーダナよ、自分自身を守れ。自己こそすべての器だ。生きることに努めよ。生きていればこそ幸福を見ることができる。」
rājyaṃ śrīścaiva bhadraṃ te jīvamāne ca kalpate|
mṛtasya tu khalu kauravya naiva rājyaṃ kutaḥ sukham||
// 8-94-29 //
「王国も繁栄も、おまえが生きていればこそ叶うもの。カウラヴィヤよ、死んでしまえば王国もなく、まして幸福など望めようか。」
lokavṛttamidaṃ vṛttaṃ pravṛttaṃ paśya bhārata|
śāmya tvaṃ pāṇḍavaiḥ sārdhaṃ śeṣaṃ rakṣa kulasya ca||
// 8-94-30 //
「バーラタよ、世の常の道理を見よ。パーンダヴァたちと和解し、一族の残りを守れ。」
mā bhūtsa kālaḥ kauravya yadā'hamahitaṃ vacaḥ|
brūyāṃ kāmaṃ mahābāho mā'vamaṃsthā vaco mama||
// 8-94-31 //
「カウラヴィヤよ、私が不快な言葉を言わねばならぬ時が来ないように。大いなる腕の主よ、どうか私の言葉を軽んじないでくれ。」
dharmiṣṭhamidamatyarthaṃ rājñaścaiva kulasya ca|
etaddhi paramaṃ śreyaḥ kuruvaṃśasya vṛddhaye|
prayāhi taṃ ca gāndhāre kulasya ca sukhāvaham||
// 8-94-32 //
「これは王のため、一族のために最もダルマにかなったことだ。これこそクル一族の繁栄のための最高の利益だ。ガーンダーラの主よ、一族に幸福をもたらすその道を歩め。」
pathyamāyatisaṃyuktaṃ karṇo'pyarjunamāhave|
na jeṣyati naravyāghra iti me niścitā matiḥ||
// 8-94-33 //
「カルナは戦場でアルジュナに勝つことはできない、人中の虎よ。これが私の確信した意見だ。」
rocatāṃ te naraśreṣṭha mamaitadvacanaṃ śubham|
ato'nyathā hi rājendra vināśaḥ sumahānbhavet||
// 8-94-34 //
「人の中の最良者よ、私のこの善き言葉を喜んで受け入れよ。そうでなければ、王の中の王よ、大いなる滅亡が訪れるだろう。」
idaṃ ca dṛṣṭaṃ jagatā saha tvayā kṛtaṃ yadekena kirīṭamālinā|
yathā na kuryādbalabhinna cāntako na ca pracetā bhagavānna yakṣarāṭ||
ato'pi bhūyānsvaguṇairdhanañjayo na cātivartiṣyati me vaco'khilam|
tavānuyātrāṃ ca sadā kariṣyati prasīda rājendra śamaṃ tvamāpnuhi||
// 8-94-35-36 //
「キリーティマーリン（アルジュナ）一人がなしたことを、おまえは世界とともに見た。インドラにも、終末の神にも、ヴァルナにもヤクシャの王にもできないことをなしたのだ。さらにダナンジャヤは自らの美徳で上回り、しかも私の言葉すべてに従うだろう。常におまえに従って歩むだろう。王の中の王よ、どうか和解を。」
mamābhimānaḥ paramaḥ sadā tvayi bravīmyatastvāṃ paramācca sauhṛdāt|
nivārayiṣyāmi ca karṇamāhave mahānhi me'sti praṇayo'tha sūtaje||
// 8-94-37 //
「私のおまえへの敬愛は最も深い。だからこそ最大の友情をもって言うのだ。戦場でカルナを止めてみせよう。スータの息子（カルナ）への私の親愛は深いのだから。」
vadanti maitrīṃ sahajāṃ vicakṣaṇāstathaiva sāmnā ca dhanena cārjitām|
pratāpataścopanatāṃ caturvidhāṃ tadasti sarvaṃ tava pāṇḍaveṣu||
nisargataste tava vīra bāndhavāḥ punaśca sāmnā hitamāpnuyuḥ prabho|
tvayi prasanne yadi mitratāṃ gate hitaṃ kṛtaṃ syājjagatastvayā'tulam||
// 8-94-38-39 //
「賢者たちは四種類の友情を説く。生まれながらの友情、なだめによる友情、財による友情、そして威力によって帰順した友情だ。パーンダヴァたちとおまえの間にはそのすべてがある。生まれながらの親族であり、なだめによっても利益を得るだろう。おまえが好意をもって友となれば、世界に比類なき善をなすことになる。」
itīdamuktaḥ suhṛdā vaco hitaṃ vicintya niḥśvasya ca durmanā'bravīt|
yathā bhavānāha sakhe tathaiva tanmamāpi vijñāpayato vacaḥ śṛṇu||
// 8-94-40 //
サンジャヤは語った。 友からこの有益な言葉を聞いて、おまえの息子は考え込み、ため息をつき、不機嫌にこう言った。「友よ、おまえの言うとおりだ。しかし私が申し述べることも聞いてくれ。」
nihatya duḥśāsanamuktavānbahu prahasya śārdūlavadeṣa durmatiḥ|
vṛkodarastadvṛdaye mama sthitaṃ na tatparokṣaṃ bhavataḥ kutaḥ śamaḥ||
// 8-94-41 //
「ドゥフシャーサナを殺した後、あの悪知恵のヴリコーダラ（ビーマ）が虎のように笑いながら多くのことを言った。あれが私の心に突き刺さっている。おまえもそれを知っているはずだ。どうして和解などできようか。」
na cāpi karṇaṃ prasahedraṇe'rjuno mahāgiriṃ merumivogramārutaḥ|
na cāśvasiṣyanti pṛthātmajā mayi prasahya vairaṃ bahuśo vicintya||
// 8-94-42 //
「アルジュナが戦場でカルナに勝つことなどない。猛烈な嵐がメール山という偉大な山を動かせないように。プリターの息子たちは私のもとで安らぎを得ることはないだろう。力ずくの敵意を何度も思い返して。」
na cāpi karṇaṃ guruputra saṃyugādupārametyarhasi vīra bhāṣitum|
śrameṇa yukto mahatādya phalgunastameṣa karṇaḥ prasabhaṃ haniṣyati||
'vasundharāyāḥ parivartanaṃ bhavedvrajecca śoṣaṃ makarālayo'rṇavaḥ|
plaveyurapyadrivarā mahāmbudhau na cārjuno jeṣyati karṇamāhave||
apāṃ pṛthivyā nabhaso nabhasvataḥ sutigmadīpteśca hiraṇyaretasaḥ|
abhāva eṣāmapi sarvato bhavenna cārjuno jeṣyati karṇamāhave'||
// 8-94-43-45 //
「師の息子よ、カルナが戦場から退くなどと言ってはならない。今日、疲労しきったアルジュナをカルナが力ずくで討ち取るのだ。大地が裏返り、海が干上がり、山が大海に浮かんでも、アルジュナが戦場でカルナに勝つことはない。水も大地も空も風も、灼熱の太陽も、これらすべてが消え失せても、アルジュナがカルナに勝つことはない。」
tamevamuktvā'pyanunīya cāsakṛttavātmajaḥ svānanuśāsti sainikān|
drutaṃ ghnatābhidravatāhitānimānahīnasatvāḥ kimu joṣamāsate||
// 8-94-46 //
こう言い、何度もなだめた後、おまえの息子は兵士たちにこう命じた。「急いで攻撃せよ、敵どもに突進せよ。勇気ある者たちよ、なぜ黙って座っているのか！」
