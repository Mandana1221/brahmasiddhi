karṇaparva — ekādaśo'dhyāyaḥ (11)
第11章　シュルタカルマンとチトラセーナの戦い、プラティヴィンディヤとチトラの戦い
sañjaya uvāca|
śrutakarmā tato rājaṃś citrasenaṃ mahīpatim|
ājaghne samare kruddhaḥ pañcāśadbhiḥ śilīmukhaiḥ|| // 8-11-1 //
サンジャヤは語った。 （1）王よ、シュルタカルマンは怒り、戦場でチトラセーナ王に五十本の矢を射ち込みました。
citrasenastu taṃ rājan navabhir nataparvabhiḥ|
śrutakarmāṇam āhatya sūtaṃ vivyādha pañcabhiḥ|| // 8-11-2 //
（2）王よ、チトラセーナはしなやかな九本の矢でシュルタカルマンを射ち、さらに五本の矢で御者を射ちました。
śrutakarmā tataḥ kruddhaś citrasenaṃ camūmukhe|
nārācena sutīkṣṇena marmadeśe samārpayat|| // 8-11-3 //
（3）するとシュルタカルマンは怒って、軍の正面でチトラセーナの急所に鋭い鉄の矢を突き刺しました。
so'tividdho mahārāja nārācena mahātmanā|
mūrcchām abhiyayau vīraḥ kaśmalaṃ cāviveśa ha|| // 8-11-4 //
（4）大王よ、偉大なる魂の鉄の矢に深く射抜かれたその勇者は、失神に陥り、意識を失いました。
etasmin antare cainaṃ śrutakīrtir mahāyaśāḥ|
navatyā jagatīpālaṃ chādayāmāsa patribhiḥ|| // 8-11-5 //
（5）この隙に、大いなる名声のシュルタキールティが、九十本の羽根つき矢でその王を覆い尽くしました。
pratilabhya tataḥ saṃjñāṃ citraseno mahārathaḥ|
dhanuś ciccheda bhallena taṃ ca vivyādha saptabhiḥ|| // 8-11-6 //
（6）やがてチトラセーナは意識を取り戻し、偉大な戦車戦士は矢尻の矢でシュルタキールティの弓を断ち切り、さらに七本の矢で彼を射ちました。
so'nyat kārmukam ādāya vegaghnaṃ rukmabhūṣitam|
citrarūpadharaṃ cakre citrasenaṃ śarormibhiḥ|| // 8-11-7 //
（7）シュルタキールティは別の金で飾られた強弓を取り、矢の波でチトラセーナを色とりどりの姿に変えました。
sa śarair citrito rājā citramālyadharo yuvā|
aśobhata mahāraṅge śvāvicchalalo yathā|| // 8-11-8 //
（8）矢で彩られたその若き王は、美しい花輪をつけた姿で、大きな闘技場で針山鼠のように輝きました。
śrutakarmāṇam atha vai nārācena stanāntare|
bibheda tarasā śūras tiṣṭha tiṣṭheti cābravīt|| // 8-11-9 //
（9）それからチトラセーナは勇猛に、鉄の矢をシュルタカルマンの胸に力強く突き刺し、「立て、立て！」と叫びました。
śrutakarmāṇi samare nārācena samarpitaḥ|
susrāva rudhiraṃ tatra gairikāmbu yathā'calaḥ|| // 8-11-10 //
（10）戦場で鉄の矢を打ち込まれたシュルタカルマンからは、山から赤土混じりの水が流れるように、血が流れ出しました。
tataḥ sa rudhirāktāṅgo rudhireṇa kṛtacchaviḥ|
rarāja samare vīraḥ sapuṣpa iva kiṃśukaḥ|| // 8-11-11 //
（11）血に染まり、血の色に輝くその勇者は、戦場で花咲くキンシュカ（火焔樹）のように美しく輝きました。
śrutakarmā tato rājañ śatruṇā samabhidrutaḥ|
śatrusaṃvāraṇaṃ kruddho dvidhā ciccheda kārmukam|| // 8-11-12 //
（12）王よ、シュルタカルマンは敵に追い立てられながらも、怒って敵を制する者（チトラセーナ）の弓を真っ二つに断ち切りました。
athainaṃ chinnadhanvānaṃ nārācānāṃ śatais tribhiḥ|
chādayan samare rājan vivyādha ca supatribhiḥ|| // 8-11-13 //
（13）弓を失ったチトラセーナに、三百本の鉄の矢を浴びせかけ、王よ、美しい羽根のついた矢で覆い尽くしました。
tato'pareṇa bhallena tīkṣṇena niśitena ca|
jahāra saśirastrāṇaṃ śiras tasya mahātmanaḥ|| // 8-11-14 //
（14）それから鋭く研ぎ澄まされた別の矢尻の矢で、かの偉大なる魂の者の頭を、兜ごと切り落としました。
tacchiro nyapatad bhūmau citrasenasya dīptimat|
yadṛcchayā yathā candraścyutaḥ svargān mahītalam|| // 8-11-15 //
（15）チトラセーナの輝く首は大地に落ちました。まるで月が偶然にも天から地上に落ちたかのように。
rājānaṃ nihataṃ dṛṣṭvā te'bhisāraṃ tu māriṣa|
abhyadravanta vegena citrasenasya sainikāḥ|| // 8-11-16 //
（16）王が討たれたのを見て、チトラセーナの兵士たちは勢いよく突撃して来ました。
tataḥ kruddho maheṣvāsas tatsainyaṃ prādravac charaiḥ|
antakāle yathā kruddhaḥ sarvabhūtāni pretarāṭ|| // 8-11-17 //
（17）すると偉大な弓の達人（シュルタカルマン）は怒り、矢を浴びせてその軍勢を敗走させました。まるで終末の時に怒れる閻魔王がすべての生き物を滅ぼすように。
te vadhyamānāḥ samare tava pautreṇa dhanvinā|
vyadravanta diśas tūrṇaṃ dāvadagdhā iva dvipāḥ|| // 8-11-18 //
（18）あなたの孫であるこの弓兵に戦場で打たれた者たちは、四方に素早く逃げ散りました。森の火に焼かれた象のように。
tāṃstu vidravato dṛṣṭvā nirutsāhān dviṣajjaye|
drāvayan niṣubhis tīkṣṇaiḥ śrutakarmā vyarocata|| // 8-11-19 //
（19）逃げ惑い、勝利への気力を失った者たちを見て、シュルタカルマンは鋭い矢で追い散らし、輝きを増しました。
prativindhyas tataś citraṃ bhittvā pañcabhir āśugaiḥ|
sārathiṃ ca tribhir vidvvā dhvajam ekeṣuṇāpi ca|| // 8-11-20 //
（20）プラティヴィンディヤは五本の素早い矢でチトラを射抜き、御者を三本で射ち、軍旗を一本の矢で射ちました。
taṃ citro navabhir bhallair bāhvor urasi cārpayat|
svarṇapuṅkhaiḥ prasannāgnaiḥ kaṅkabarhiṇavājitaiḥ|| // 8-11-21 //
（21）チトラは九本の矢尻の矢を——金の矢尻で、澄んだ先端の、鷺と孔雀の羽根をつけた矢を——プラティヴィンディヤの両腕と胸に打ち込みました。
prativindhyo dhanuś chittvā tasya bārata sāyakeḥ|
pañcabhir niśitair bāṇair athainaṃ sa hi jaghnivān|| // 8-11-22 //
（22）バーラタよ、プラティヴィンディヤはチトラの弓を断ち切り、さらに五本の鋭い矢で彼を射ちました。
tataḥ śaktiṃ mahārāja svarṇaghaṇṭāṃ durāsadām|
prāhiṇot prativindhyāya vicinvantīm asūn iva|| // 8-11-23 //
（23）すると大王よ、チトラは金の鈴のついた、恐るべき槍を——まるで命を求めるかのように——プラティヴィンディヤに投げつけました。
tāmāpatantī sahasā śaktim ulkām ivāmbare|
dvidhā ciccheda samare prativindhyo hasann iva|| // 8-11-24 //
（24）空に流星のように飛んでくるその槍を、プラティヴィンディヤは微笑みながら戦場で真っ二つに切り裂きました。
sā papāta dvidhā chinnā prativindhyaśaraiḥ śitaiḥ|
yugānte sarvabhūtāni trāsayantī yathā'śaniḥ|| // 8-11-25 //
（25）プラティヴィンディヤの鋭い矢で二つに割られたその槍は、世界の終末にすべての生き物を震え上がらせる雷のように大地に落ちました。
śaktiṃ tāṃ prahatāṃ dṛṣṭvā citro gṛhya mahāgadām|
prativindhyāya cikṣepa rukmajālavibhūṣitām|| // 8-11-26 //
（26）槍が打ち落とされたのを見て、チトラは大きな棍棒を取り上げ——金の網で飾られたものを——プラティヴィンディヤに投げつけました。
sā jaghāna hayāṃs tasya sārathiṃ ca mahāraṇe|
rathaṃ pramṛdya vegena dharām īm anvapadyata|| // 8-11-27 //
（27）その棍棒は彼の馬と御者を大戦闘で打ち倒し、戦車を粉砕した勢いで大地にめり込みました。
etasminneva kāle tu rathādāplutya bhārata|
śaktiṃ cikṣepa citrāya svarṇadaṇḍāmalaṅkṛtām|| // 8-11-28 //
（28）ちょうどその時、バーラタよ、プラティヴィンディヤは戦車から飛び降り、金の柄で飾られた槍をチトラに向けて投げました。
tāmāpatantīṃ jagrāha citro rājan mahāmanāḥ|
tatastāmeva cikṣepa prativindhyāya pārthivaḥ|| // 8-11-29 //
（29）王よ、大いなる心のチトラは飛んでくるその槍を空中で掴み取り、そのままプラティヴィンディヤに投げ返しました。
samāsādya raṇe śūraṃ prativindhyaṃ mahāprabhā|
nirbhidya dakṣiṇaṃ bāhuṃ nipapāta mahītale|
patitā'bhāsayaś caiva taṃ deśam aśanir yathā|| // 8-11-30 //
（30）大いなる輝きを放つその槍は、戦場の勇者プラティヴィンディヤの右腕を貫いて大地に落ち、落ちた所を雷のように照らしました。
prativindhyas tato rājaṃs tomaraṃ hemabhūṣitam|
preṣayāmāsa saṅkruddhaś citrasya vadhakāṅkṣayā|| // 8-11-31 //
（31）王よ、プラティヴィンディヤは激怒し、チトラを殺す望みを込めて、金で飾られた投げ槍を放ちました。
sa tasya gātrāvaraṇaṃ bhittvā hṛdayameva ca|
jagāma dharaṇīṃ tūrṇaṃ mahoraga ivāśayam|| // 8-11-32 //
（32）それはチトラの鎧を貫き、心臓をも貫いて、大蛇がねぐらに入るように速やかに大地に入りました。
sa papāta tadā rājā tomareṇa samāhataḥ|
prasārya vipulau bāhū pīnau pighasannibhau|| // 8-11-33 //
（33）投げ槍に打たれたその王は、太く丸い二本の腕を広げて倒れました。
citraṃ samprekṣya nihataṃ tāvakā raṇaśobhinaḥ|
abhyadravanta vegena prativindhyaṃ samantataḥ|| // 8-11-34 //
（34）チトラが討たれたのを見て、あなた方の戦場に輝く兵士たちは、勢いよく四方からプラティヴィンディヤに向かって突撃しました。
sṛjanto vividhān bāṇāñ śataghnīś ca sakiṅkiṇīḥ|
tam avacchādayāmāsuḥ sūryam abhragaṇā iva|| // 8-11-35 //
（35）さまざまな矢や、鈴のついた殺戮兵器を放ちながら、太陽を雲が覆うようにプラティヴィンディヤを覆い尽くしました。
tān vidhamya mahābāhuḥ śarajālena saṃyuge|
vyadrāvayat tava camūṃ vajrahasta ivāsurīm|| // 8-11-36 //
（36）しかし大いなる腕のプラティヴィンディヤは、矢の網で彼らを打ち払い、お前の軍を敗走させました。インドラが金剛杵で阿修羅の軍を散らすように。
te vadhyamānāḥ samare tāvakāḥ pāṇḍavair nṛpa|
viprakīryanta sahasā vātanunnā ghanā iva|| // 8-11-37 //
（37）王よ、あなた方の兵はパーンダヴァたちに戦場で打たれ、突然散り散りになりました。風に吹き散らされた雲のように。
vipradrute bale tasmin vadhyamāne samantataḥ|
drauṇir eko'bhyayāt tūrṇaṃ bhīmasenaṃ mahābalam|| // 8-11-38 //
（38）軍が敗走し、四方で打たれる中、ドローナの子（アシュヴァッターマン）だけが、すばやく大力のビーマセーナに向かいました。
taḥ samāgamo ghoro babhūva sahasā tayoḥ|
yathā daivāsure yuddhe vṛtravāsavayor iva|| || // 8-11-39 //
（39）そこで二人の間に、突然恐ろしい一騎打ちが始まりました。神と阿修羅の戦いにおけるヴリトラとインドラの戦いのように。
iti śrīmanmahābhārate karṇaparvaṇi ṣoḍaśadivasayuddhe ekādaśo'dhyāyaḥ|| 11 ||
こうして、聖なる大マハーバーラタのカルナ篇、第十六日の戦いの第十一章は終わる。
