マハーバーラタ ― カルナ篇 第101章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 101 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ101」で、カルナ討死後のアルジュナによるユダーマンユへの敬礼、クリシュナの語りの場面を描きます。本章が本翻訳の最終章です。
karṇaparva — ekaśatatamo'dhyāyaḥ (101)
第101章 ― カルナ討死後のアルジュナによるユディシュティラへの敬礼、クリシュナとユディシュティラの対話
sañjaya uvāca|
hate vaikartane karṇe kuravo bhayapīḍitāḥ|
vīkṣamāṇā diśaḥ sarvāḥ palāyanta sahasraśaḥ||
rāvaṇaṃ nihataṃ dṛṣṭvā rākṣasā rāghaveṇa vā|
diśo bhītā dravanneva tāvakā bhayapīḍitāḥ||
// 8-101-1-2 //
サンジャヤは語った。
ヴァイカルタナ・カルナが討たれると、恐怖に苦しむクル勢は四方を見渡しながら何千もの兵が逃げ出した。ラーヴァナがラーガヴァ（ラーマ）に倒された時、ラークシャサたちが恐怖に駆られて四方に逃げ散ったように、おまえの兵たちも恐怖に苦しんで逃げ散った。
tato mahāravaṃ cakruryodhā rājansamantataḥ|
vāryamāṇā bhṛśodvignāstava putreṇa bhārata||
teṣāṃ tu matamājñāya putraste bharatarṣabha|
avahāraṃ tataścakre śalyasyānumatena ca||
// 8-101-3-4 //
バーラタよ、兵士たちは四方から大きな叫びをあげたが、おまえの息子が必死に止めても深く動揺していた。おまえの息子は彼らの意向を理解し、バーラタの雄牛よ、シャリヤの同意を得て撤退を命じた。
kṛtavarmā raṇe tūrṇaṃ vṛto bhārata tāvakaiḥ|
nārāyaṇāvaśiṣṭaiśca śibirāyaiva dudruve||
// 8-101-5 //
バーラタよ、クリタヴァルマンは急いでおまえの兵たちに囲まれ、ナーラーヤナ軍の残存兵とともに陣営に引き返した。
aśvatthāmā tataḥ śūro viniśvasya muhurmuhuḥ|
pāṇḍavānāṃ jayaṃ dṛṣṭvā śibirāyaiva dudruve||
// 8-101-6 //
勇者アシュヴァッターマンも何度もため息をつきながら、パーンダヴァたちの勝利を見て陣営に引き返した。
kṛpaḥ śāradvato rājannāgānīkena bhārata|
mahatā meghakalpena śibirāyaiva dudruve||
// 8-101-7 //
バーラタよ、シャーラドヴァタのクリパは大いなる象軍とともに、雲のような大軍で陣営に引き返した。
gāndhārāṇāṃ sahasreṇa śakuniḥ parivāritaḥ|
suśarmā ca yayau rājanvīkṣamāṇo bhayārditaḥ||
// 8-101-8 //
シャクニは千人のガーンダーラ兵に囲まれて引き返した。スシャルマンも恐怖におびえて周りを見ながら去った。
duryodhano'pi sa yayau hvatasarvasva āturaḥ|
jñātiśokasamāpannaścintayitvā muhurmuhuḥ||
// 8-101-9 //
ドゥルヨーダナもまたすべてを失い苦しみながら去った。親族を失った悲しみに打ちのめされ、何度も何度も考え込みながら。
chinnadhvajena śalyastu rathena rathināṃ varaḥ|
prayayau śibirāyaiva vīkṣamāṇo diśo daśa||
// 8-101-10 //
旗を切られた戦車に乗る戦車戦士の中の最良者シャリヤは、十方を見渡しながら陣営に向かった。
tato'pare subahuśo bhāratānāṃ mahārathāḥ|
vyadravanta diśo bhītā bhayavihvalacetasaḥ||
aśrūpūrṇā bhayodvignā vepamānā bhayāturāḥ|
kuravaḥ prādravansarve dṛṣṭvā karṇaṃ nipātitam||
praśaṃsanto'rjunaṃ kecitkecitkarṇaṃ mahārathāḥ|
prādravanta raṇe bhītāḥ kuravaḥ kurusattama||
// 8-101-11-13 //
その他にも多くのバーラタの大戦車戦士たちが四方に恐怖に駆られて逃げ散った。心が恐怖で狂乱しながら。涙に溢れ、恐怖に動揺し、体を震わせ、恐怖に苦しむクル勢はすべて、カルナが倒されるのを見て逃げ出した。アルジュナを称える者もいれば、カルナを称える大戦車戦士もいたが、戦場で恐怖に駆られて逃げ出した、クル勢のクルの最良者たちよ。
teṣāṃ yodhasahasrāṇāṃ tāvakānāṃ mahāmṛdhe|
nāsīttatra pumānkaścidyastu yuddhe mano dadhe||
karṇe hate mahārāja nirāśāḥ kuravo'bhavan|
jīvaneṣu ca rājyeṣu dāreṣu ca dhaneṣu ca||
// 8-101-14-15 //
大王よ、この大いなる戦いで、おまえの何千もの兵士の中に、戦いに心を向ける者は一人もいなかった。カルナが倒されると、クル勢は命にも王国にも妻にも財産にも希望を失った。
tānsamānīya putraste yatnena mahatā vibho|
niveśāya mano dadhre duḥkhaśokasamanvitaḥ||
tasyājñāṃ śirasā dīnāḥ pratigṛhya viśāmpate|
viṣaṇṇamanaso bhītyā nyaviśanta mahārathāḥ||
cintayanto vadhaṃ ghoraṃ sūtaputrasya saṃyuge|
arjunasya jayaṃ yuddhe cintayānāḥ punaḥpunaḥ||
// 8-101-16-18 //
おまえの息子は大いなる努力でかれらを集め、悲しみと嘆きの中で陣営に落ち着かせた。悲嘆に暮れた大戦車戦士たちは、王の命令をうなだれて受け入れ、恐怖に心を沈ませながら陣営に入った。戦場でのスータの息子の恐ろしい死を思い返し、アルジュナの戦いの勝利を何度も何度も思い返しながら。
pāṇḍavāśca maheṣvāsā nyaviśanta parantapāḥ|
prahṛṣṭamanasaḥ sarve jitvā śatruṃ mahārathāḥ||
tato yudhiṣṭhiraṃ tatra niviṣṭaṃ vai mudānvitam|
sametya sarve pāñcālā vardhayanto yathāvidhi||
// 8-101-19-20 //
一方パーンダヴァたちは偉大な射手として、敵を焼き尽くす者として、敵の偉大な戦車戦士を討ち取り、歓喜した心で全員が陣営に入った。そこで喜びに満ちたユディシュティラを、すべてのパーンチャーラ勢がやって来て、しきたりどおりに「勝利おめでとう」と祝った。
arjunastu rathāttūrṇamavaruhya mahāyaśāḥ|
dharmarājasya caraṇau pīḍayāmāsa hṛṣṭavat||
tamutthāpya mahārāja dharmaputraḥ pratāpavān|
sasvaje bharataśreṣṭhamupajighrannupaspṛśan||
// 8-101-21-22 //
アルジュナは大いなる名声の持ち主として、すぐさま戦車から降り、ダルマラージャ（ユディシュティラ）の足に触れて敬礼した。大王よ、ダルマの息子（ユディシュティラ）は威厳ある者として、バーラタの最良者を立ち上がらせ、抱擁し、頭の匂いを嗅ぎ体に触れた。
nakulaḥ sahadevaśca pāṇḍavaśca vṛkodaraḥ|
abhivādya mahārājamasvajanta sma phalgunam||
// 8-101-23 //
ナクラとサハデーヴァ、そしてヴリコーダラ（ビーマ）は大王（ユディシュティラ）に敬礼してからアルジュナを抱擁した。
dhṛṣṭadyumnaḥ śikhaṇḍī ca pāṇḍavānāṃ ca ye rathāḥ|
vardhayante sma rājānaṃ nihate sūtanandane||
tataḥ kṛṣṇo mahārāja sātyakiścāpi sātvataḥ|
vardhayante sma rājānaṃ nihate sūtanandane||
// 8-101-24-25 //
ドリシュタデュムナ、シカンディン、パーンダヴァたちの戦車戦士たちが王（ユディシュティラ）を「勝利おめでとう」と祝った。スータの息子が倒されて。クリシュナもサーティヤキもまた王を祝った。
vāsudevaśca kaunteyaṃ praṇayādidamabravīt|
adya rājanhatāḥ sarve dhārtarāṣṭrāḥ sarājakāḥ|
hate vaikartane karṇe rathānāṃ pravare rathe||
// 8-101-26 //
ヴァースデーヴァ（クリシュナ）はカウンテーヤ（ユディシュティラ）に親しみを込めてこう言った。「今日、王よ、ドリタラーシュトラの息子たちはすべて王もろとも滅んだも同然です。戦車戦士の中の最高者、ヴァイカルタナ・カルナが討たれたのですから。」
yadi lokāstrayaḥ sarve yodhayeyuḥ savāsavāḥ|
tathāpi durjayaḥ sūtastava kopāttu sūditaḥ||
// 8-101-27 //
「三界すべてがインドラとともに戦っても、スータの息子は倒しがたかったでしょう。しかしあなたの怒りによって彼は討たれたのです。」
evamuktaḥ pratyuvāca dharmarājo janārdanam||
// 8-101-28 //
こう言われてダルマラージャはジャナールダナ（クリシュナ）にこう答えた。
tava prasādādgrovinda hataḥ karṇo mahāyaśāḥ|
pāṇḍavāśca jayaṃ prāpyā nāśitāścāpi śatravaḥ||
// 8-101-29 //
「ゴーヴィンダよ、あなたのお恵みによって大いなる名声のカルナは討たれました。パーンダヴァたちは勝利を得、敵は滅ぼされました。」
tvaṃ hi śakto bhayāttrātuṃ yasya kasyacidāhave|
tvamasya jagato goptā pāṇḍavānāṃ ca sarvadā||
// 8-101-30 //
「あなたは戦場で誰をも恐怖から救う力を持つお方です。あなたはこの世界の守護者であり、常にパーンダヴァたちの守護者です。」
tvāṃ samāsādya śakro'pi modate divi nityaśaḥ|
tvaṃ pātā pāṇḍuputrāṇāṃ yathaiva jagatastathā||
// 8-101-31 //
「あなたのもとに来ることで、インドラでさえ天で常に喜んでいます。あなたはパーンドゥの息子たちの守護者であり、世界の守護者でもあります。」
anāścaryo jayasteṣāṃ bhaktiryeṣāṃ tvayi prabho||
// 8-101-32 //
「あなたへの信愛を持つ者に勝利が訪れるのは、少しも不思議ではありません。」
tvayā nāthena govinda nāthavanto vayaṃ yudhi|
yathendreṇa purā devāstvayā cāpi janārdana||
// 8-101-33 //
「ゴーヴィンダよ、あなたを主とする我々は、戦いにおいて守る者を持つ者です。かつて神々がインドラによって守られたように、我々もジャナールダナよ、あなたによって守られています。」
svapsyāmyadya sukhaṃ kṛṣṇanidrāṃ lapsye tvahaṃ kṣapām|
vigataṃ hi bhayaṃ me'dya tvatprasādānna saṃśayaḥ||
// 8-101-34 //
「クリシュナよ、今夜は心地よく眠れるでしょう。眠りを得られるでしょう。今日、私の恐怖は消え去りました。あなたのお恵みで、疑いなく。」
evamuktastu pārthena keśavaḥ prāha pāṇḍavam|
nimittamātraṃ hi vayaṃ tavāpyasminmudāgame||
// 8-101-35 //
パールタ（ユディシュティラ）にこう言われて、ケーシャヴァ（クリシュナ）はパーンダヴァにこう言った。「この喜びにおいて、我々はただの道具にすぎません。」
yasya te bhrātaraḥ śūrā bhīmasenādayo nṛpa|
sambandhinaścendravīryāḥ pārṣatapramukhāstathā||
// 8-101-36 //
「あなたにはビーマセーナをはじめとする勇敢な兄弟たちがいます。インドラの武勇を持つ姻戚、パールシャタ（ドリシュタデュムナ）を先頭とする者たちも。」
arhate ca bhavānnityaṃ priyaṃ nityaṃ ca madvitam|
priyo hi me tvametena vacanena narottama||
// 8-101-37 //
「あなたは常に私の親しい友であり、常に私の心にかなう人です。この言葉によって、あなたは私にとって愛しい者です、人中の最良者よ。」
ityukto dharmarājastu svarathaṃ hemabhūpitam|
dantavarṇairhayairyuktaṃ kālavālairmahīpatiḥ||
āsthāya puruṣavyāghraḥ svabalenāpi saṃvṛtaḥ|
prayayau bahuvṛttāntaṃ draṣṭumāyodhanaṃ prati||
// 8-101-38-39 //
こう言われたダルマラージャは、黄金で飾られた自分の戦車に乗り、象牙色のカーラヴァーラ馬をつけた馬に引かれて、この人中の虎は自軍に囲まれ、多くの出来事のあった戦場を見に向かった。
sambhāṣamāṇau tau vīra ubhau mādhavapāṇḍavau||
sa dadarśa raṇe karṇaṃ śayānaṃ puruṣarṣabham|
gāṇḍīvamuktairviśikhaiḥ sarvataḥ sannipīḍitam||
saputraṃ nihataṃ dṛṣṭvā karṇaṃ rājā yudhiṣṭhiraḥ|
praśaśaṃsa naravyāghrāvubhau mādhavapāṇḍavau||
// 8-101-40-42 //
マーダヴァ（クリシュナ）とパーンダヴァ（アルジュナ）の二人の勇者が語り合いながら。そこでユディシュティラは、戦場に横たわるカルナを見た。人中の雄牛を。ガーンディーヴァから放たれた矢で四方から射抜かれた姿を。息子とともに倒されたカルナをパールタの矢に射抜かれた姿を見て、ダルマラージャ・ユディシュティラは、マーダヴァとパーンダヴァの二人の人中の虎を讃えた。
adya rājā'smi sarvasyāṃ pṛthivyāṃ madhusūdana|
diṣṭyā jayasi govinda diṣṭyāśatrurnipātitaḥ||
evaṃ subahuśo rājanpraśaśaṃsa janārdanam|
arjunaṃ ca kuruśreṣṭho dharmarājo yudhiṣṭhiraḥ||
// 8-101-43-44 //
「今日、私はマドゥスーダナよ、全大地の王となった。ゴーヴィンダよ、おめでとう、あなたが勝った。おめでとう、敵は倒された。」 こうしてクルの最良者、ダルマラージャ・ユディシュティラは、何度もジャナールダナとアルジュナを讃えた。
dṛṣṭvā ca nihataṃ karṇaṃ sa putraṃ pārthasāyakaiḥ|
punarjātamivātmānaṃ mene kurukulodvahaḥ||
sametya ca kuruśreṣṭhaṃ kuntīputraṃ yudhiṣṭhiram|
vardhayanti sma rājāno harṣayuktā mahārathāḥ||
// 8-101-45-46 //
パールタの矢に倒されたカルナを息子とともに見て、クル族を支える者（ユディシュティラ）は自分が生まれ変わったかのように感じた。クルの最良者、クンティーの息子ユディシュティラのもとに集まった王たちが、歓喜をもって偉大な戦車戦士たちとして王を祝った。
sañjaya uvāca|
evameṣa kṣayo vṛttaḥ sumahānromaharṣaṇaḥ|
tava durmantrite rājandiṣṭyā tvamanuśocasi||
// 8-101-47 //
サンジャヤは語った。 このように、背筋が凍るような大いなる殺戮が起こったのです。おまえの愚かな策謀のゆえに、王よ。運命によっておまえは嘆いているのだ。
vaiśampāyana uvāca|
śrutvaitadapriyaṃ rājā dhṛtarāṣṭro mahīpatiḥ|
papāta bhūmau niśceṣṭaḥ kauravyaḥ paramāsanāt|
tathā satyavratā devī gāndhārī divyadarśanā||
// 8-101-48 //
ヴァイシャンパーヤナは語った。 この不快な知らせを聞いて、王ドリタラーシュトラは最高の座から崩れ落ち、身動きできなくなった。カウラヴィヤの王は。同じく、真実の誓いを守る王妃ガーンダーリーも、神々しい容姿の彼女も。
tatastūrṇaṃ tu vidurastaṃ nṛpaṃ sañjayastathā|
paryāśvāsayatāṃ caitāvubhāveva tu bhūmipam||
tathaivāśvāsayāmāsurgāndhārīṃ kuruyoṣitaḥ||
// 8-101-49-50 //
するとすぐにヴィドゥラとサンジャヤが王を慰めた。二人とも王を支えた。同じくクルの婦人たちもガーンダーリーを慰めた。
sa daivaṃ paramaṃ mene bhavitavyaṃ ca bhārata|
tābhyāmāśvāsito rājā tūṣṇīmāste viśāmpate||
// 8-101-51 //
王は運命こそ最も強いものであり、起こるべきことは起こると考えた。バーラタよ、二人に慰められて王は黙って座った。
evamākhyāya rājñe ca sañjayo rājasattama|
jagāma śibiraṃ bhūyo hate karṇe mahātmani||
// 8-101-52 //
こうしてサンジャヤは王に報告した後、偉大な魂のカルナが討たれた後、再び陣営に向かった。
sa dṛṣṭvā nihataṃ śalyaṃ rājānaṃ ca suyodhanam|
śakuniṃ subahūnrājansainikāṃśca sahasraśaḥ||
tathaiva pāṇḍavīṃ senāṃ nihatāṃ prekṣya sañjayaḥ|
sauptike drauṇinā rājanhatavājinaradvipām||
sa hi dṛṣṭvā hatānsarvānsamantādyudhi sañjayaḥ|
prayāto hāstinapuraṃ śokārto bhayavihvalaḥ||
// 8-101-53-55 //
彼はそこでシャリヤが倒され、スヨーダナ（ドゥルヨーダナ）も倒され、シャクニも多くの兵士も何千と倒されたのを見た。同じくパーンダヴァの軍もまた、ドラウニ（アシュヴァッターマン）による夜襲で馬・人・象が倒されたのを見た。四方で全員が倒されたのを見て、サンジャヤは悲嘆に暮れ恐怖に怯えてハースティナプラに向かった。
hateṣu punareteṣu prabhūtagajavājiṣu|
yodhaiśca tairmahārāja nānādeśasamudbhavaiḥ||
kurukṣetraṃ tu tatsarvaṃ śūnyamāsīdviśāmpate|
nihataiḥ pāṇḍaveyaiśca dhārtarāṣṭraiśca saṃyuge||
// 8-101-56-57 //
これら多くの象と馬と、さまざまな国から集まった兵士たちが倒された後、クルクシェートラはすべて空になった、王よ。パーンダヴァ側の者もドリタラーシュトラ側の者も戦いで倒されて。
yathāhi viṣayaṃ vṛttaṃ dhārtarāṣṭrasya saṃñjayaḥ|
nivedayati tatsarvaṃ yathāvṛttaṃ yathāvidhi||
// 8-101-58 //
サンジャヤはドリタラーシュトラの領国で起きたすべてのことを、起きたとおりに、そのまま報告した。
evaṃ mahāyuddhamidaṃ mahātmano dhanañjayasyādhiratheśca yaḥ paṭhet|
sa samyagiṣṭasya makhasya yatphalaṃ tadāpnuyādyaḥ śṛṇuyācca nityaśaḥ||
// 8-101-59 //
この偉大なるダナンジャヤとアディラティ（カルナ）の大戦を読む者は、正しく行われた供犠の果報を得るであろう。常にこれを聞く者も同様である。
makho hi viṣṇurbhagavānsanātano vahanti yaṃ cāpyanilendubhānavaḥ|
ato'nasūyuḥ śṛṇuyātpaṭhecca yaḥ sa sarvalokāṃśca jayetsukhī bhavet||
// 8-101-60 //
供犠とはまさに永遠なるヴィシュヌ神であり、風と月と太陽がそれを運ぶ。だから嫉妬なくこれを聞き読む者は、すべての世界に勝ち、幸福になるであろう。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ekaśatatamo'dhyāyaḥ|| 101 ||
こうして、聖なる大マハーバーラタのカルナ篇の第101章は終わる。
