マハーバーラタ ― カルナ篇 第96章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 96 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ96」で、クリシュナによるアルジュナへの叱咤、およびアルジュナの反撃の場面を描きます。
karṇaparva — ṣaṇṇavatitamo'dhyāyaḥ (96)
第96章 ― クリシュナによるアルジュナの叱咤、アルジュナの反撃
sañjaya uvāca|
athābravīccakradharo'pi pārthaṃ dṛṣṭvā ratheṣūnpratihanyamānān|
amūmuṣatpaśyata eva te'dya hyastrāṇi karṇo'stragaṇaiḥ kirīṭin||
// 8-96-1 //
サンジャヤは語った。
チャクラ（円盤）を持つクリシュナもまた、パールタの矢が打ち返されるのを見て言った。「今日、おまえの目の前で、カルナがおまえの武器を武器で打ち破っているぞ、キリーティンよ。」
sa pārtha kiṃ muhyasi vetsi caiva tāndṛṣṭvā sametānnadataḥ kurūstvam|
karṇaṃ puraskṛtya vidurhi sarve tavāstramastrairvinihanyamānam||
// 8-96-2 //
「パールタよ、なぜぼんやりしているのだ。あのクル勢が叫びながら集結しているのが見えるだろう。カルナを先頭に据えて、全員がおまえの武器を武器で打ち破れることを知っているのだ。」
yayā dhṛtyā tāmasaṃ jaghnivāṃstvaṃ tatsaṃyuge tāmasāṃścātighorān|
dambhodbhavaṃ cāsuramāhave tvaṃ darpotsiktaṃ vīryavantaṃ kirīṭin|
tayā dhṛtyā tvaṃ jahi karṇamadya pārthāhave tyaktumastraṃ samarthaḥ||
// 8-96-3 //
「あのターマサ（暗黒の武器）を討った時の勇気を思い出せ。そしてあのダンボードバヴァ（魔族の戦士）を戦場で打った時の勇気を。キリーティンよ、あの勇気で今日カルナを討て。パールタよ、おまえは戦場で武器を捨てることもできる者ではないか。」
anena cāśu kṣuraneminādya mayā visṛṣṭena sudarśanena|
chindhyasya mūrdhānamareḥ prasahya vajreṇa śakro namucerivāreḥ||
// 8-96-4 //
「あるいはこの鋭い刃を持つ、私が放つスダルシャナ（円盤武器）で、敵の首を力ずくで斬り落とせ。インドラがナムチの首を雷で斬ったように。」
kirātarūpī bhagavānyayā ca tvayā mahātmā paritoṣito'bhūt|
sa tāṃ punarvīra dhṛtiṃ gṛhītvā sahānubandhaṃ jahi sūtaputram||
// 8-96-5 //
「キラータ（猟師）の姿をとった偉大な神（シヴァ）が、おまえによって満足された時のあの勇気を取り戻し、スータの息子をその一族もろとも討て。」
tato mahīṃ sāgaramekhalāṃ tvaṃ sapattagā grāmavatīṃ samṛddhām|
prayaccha rājñe nihatārisaṅghāṃ yaśaśca pārthātulamāpnuhi tvam||
// 8-96-6 //
「そうすれば、海を帯とするこの大地を、村々に満ちた豊かな大地を、敵の群れを討ち果たした上で、王（ユディシュティラ）に与えよ。パールタよ、比類なき名声を得よ。」
karṇaṃ puraskṛtya nadantiṃ sarve tavāstramagryaṃ pratihatya vīrāḥ|
kuru prayatnaṃ bharatapravīra dravantyamī sṛñjayāḥ somakāśca|
dṛṣṭvātha karṇaṃ samare prahṛṣṭaṃ tvāṃ cāpi dṛṣṭvā parihīyamānam||
// 8-96-7 //
「カルナを先頭に立てて、すべての勇者たちが叫びながらおまえの最高の武器を打ち返している。バーラタの最良者よ、努力せよ。スリンジャヤ勢もソーマカ勢も逃げ出しているぞ。戦場で奮い立つカルナを見て、そしておまえが劣勢になるのを見て。」
sañjaya uvāca|
sañcodito bhīmajanārdanābhyāṃ smṛtvā tadātmānamavetya sarvam|
ihātmanaścāgamane viditvā prayojanaṃ keśavamityuvāca||
// 8-96-8 //
サンジャヤは語った。 ビーマとジャナールダナの二人に叱咤され、自らを思い出し、すべてを悟り、この世に来た自分の使命を理解して、アルジュナはケーシャヴァ（クリシュナ）にこう言った。
prāduṣkarobhyeṣa mahāstramugraṃ śivāya lokasya vadhāya sauteḥ|
tanme'nujānātu bhavānsurāśca brahmā śivo brahmavidaśca sarve||
// 8-96-9 //
「世界の幸福のため、そしてスータの息子の討伐のため、恐るべき偉大な武器を発動させよう。ブラフマー、シヴァ、すべてのブラフマー知識者、そして神々がそれを許してくださるように。」
iti smoktvā pāṇḍavaḥ savyasācī namaskṛtvā brahmaṇe so'mitātmā|
anuttamaṃ brāhmamasahyamastraṃ prāduścakre manasā yadvidheyam||
// 8-96-10 //
こう言って、パーンダヴァの左手の射手サヴヤサーチンは、限りなき魂の持ち主として、ブラフマー神に敬礼し、抵抗しがたいブラフマーの武器（ブラフマーストラ）を、心の力で操る最高の武器を発動させた。
tato diśaśca pradiśaśca sarvāḥ samāvṛṇotsāyakairbhūritejāḥ|
gāṇḍīvamuktairbhujagairivograirdivākarāṃśupratimairjvaladbhiḥ||
sṛṣṭāstu bāṇā bharatarṣabheṇa śataṃ śataṃ bhīmamukhāḥ sutīkṣṇāḥ|
prācchādayankarṇarathaṃ kṣaṇena yugāntakālārkakaraprakāśāḥ||
// 8-96-11-12 //
すると偉大な輝きのアルジュナが、ガーンディーヴァから放たれた恐ろしい蛇のような矢で、太陽の光のように燃え輝く矢で、四方八方をすべて覆い尽くした。バーラタの雄牛（アルジュナ）が放った矢は、百本ずつの恐ろしい鋭い束となって、瞬く間にカルナの戦車を覆い隠した。世界の終末の太陽の光のように。
vaikartanenāśu tadājimadhye sahasraśo bāṇagaṇā visṛṣṭāḥ|
te cākṣayāḥ pāṇḍavamabhyupeyuḥ parjanyasṛṣṭā iva vāridhārāḥ||
// 8-96-13 //
ヴァイカルタナ（カルナ）もまた戦場の中央で千本単位の矢の群れを放った。それらは無尽蔵にパーンダヴァに向かった。パルジャニヤ（雨神）が降らす雨のように。
tataḥ sa kṛṣṇaṃ ca kirīṭinaṃ ca vṛkodaraṃ cāpratimaprabhāvaḥ|
tribhistribhirbhīmabalo nihatya nanāda ghoraṃ mahatā svanena||
// 8-96-14 //
するとカルナは、比類なき力で、クリシュナとキリーティンとヴリコーダラ（ビーマ）の三人を、それぞれ三本の矢で射て、恐ろしい大声で咆哮した。
tataḥ sa bāṇābhihataḥ kirīṭī bhīmaṃ tathā prekṣya janārdanaṃ ca|
amṛṣyamāṇaḥ punareva pārthaḥ śarāndaśāṣṭau samamudvavarṣa||
// 8-96-15 //
矢に打たれたキリーティン（アルジュナ）は、ビーマとジャナールダナを見て、怒りを抑えられず、十八本の矢を一斉に放った。
sa ketumekena śareṇa viddhvā śalyaṃ caturbhistribhireva karṇam|
tataḥ sumuktairdaśabhirjaghāna senāpatiṃ kāñcanavarmanadvam||
// 8-96-16 //
一本の矢でカルナの旗を射抜き、四本でシャリヤを、三本でカルナを射て、さらに見事に放たれた十本の矢で黄金の鎧をまとった軍の指揮官を討った。
sa rājaputro viśirā vibāhurvivājisūto vidhanurviketuḥ|
atho rathāgrādapatatprarugṇaḥ paraśvathaiḥ sāla ivāvakṛttaḥ||
// 8-96-17 //
その王子は頭も腕も馬も御者も弓も旗もすべて断ち切られ、戦斧で切り倒されたサーラ樹のように、戦車の前面から崩れ落ちた。
punaśca karṇaṃ tribhiraṣṭabhiśca dvābhyāṃ caturbhirdaśabhiśca viddhā|
catuśśataṃ dviradānāṃ nipātya rathāñjaghānāṣṭarathānkirīṭi|
sahasramaśvāṃśca punaśca sādīnaṣṭau sahasrāṇi ca pattivīrān||
// 8-96-18 //
キリーティンはさらにカルナを三本と八本と二本と四本と十本の矢で射て、四百頭の象を倒し、八台の戦車を打ち砕き、千頭の馬と多くの騎兵と八千人の歩兵を討った。
dṛṣṭvā tu mukhyāvatividhyamānau vareṣubhiḥ śūravarāvarighnau|
karṇaṃ ca pārthaṃ ca niyamya vāhā- nsarve variṣṭhāśca tato'vatasthuḥ||
// 8-96-19 //
二人の卓越した敵を砕く勇者が最高の矢で射合うのを見て、すべての者がカルナとパールタの周りで馬を止め、立ち止まった。
pracchādayāmāsa tataḥ pṛṣatkaiḥ saghoṣamācchidya ca gāṇḍivajyām|
asminkṣaṇe phalgunaṃ sūtaputraḥ samācinotkṣudrakāṇāṃ śatena||
// 8-96-20 //
カルナがその瞬間、音を立ててガーンディーヴァの弦を切り、百本の小さな矢でアルジュナを覆い尽くした。
nirmuktasarpapratimaiśca tīkṣṇaistailapraghautaiḥ khagapatravājaiḥ|
ṣaṣṭyā bibhedāśu ca vāsudevaṃ tadantare prātvaransomakāśca||
// 8-96-21 //
蛇のように鋭い、油で磨かれた、鳥の羽をつけた矢六十本でヴァースデーヴァ（クリシュナ）をも射た。その間にソーマカ勢が駆けつけた。
tato navajyāṃ sudṛḍhāṃ kirīṭi svabāhuvikṣepasahāṃ pragṛhya|
samādadhe gāṇḍive kṣiprakārī nimeṣamātreṇa mahādhanuṣmān||
jyāchedanaṃ jyāvidhānaṃ ca tasya naivāvabudhyatsūtaputro laghutvāt|
pārthasya saṅkhye dviṣatāṃ nihantustadadbhutaṃ tatra babhūva rājan||
// 8-96-22-23 //
そこでキリーティンは新しい弦を、自分の腕の動きに耐える丈夫なものを取り出し、ガーンディーヴァに素早く張った。大弓の使い手が瞬く間にそれをなした。弦を切られたことと弦を張り直したことを、スータの息子はその速さゆえにまったく気づかなかった。パールタの戦場での素早さは驚嘆すべきものであった。
pārtho'pi tāṃ jyāmavadhāya tūrṇaṃ śarāsanajyāmādhirathervihatya|
susaṃrabdhaḥ karṇaśaraiḥ kṣatāṅgo raṇe yodhāṃstāvakānpratyagṛhṇāt||
// 8-96-24 //
パールタはすぐに弦を張り直し、アディラティ（カルナ）の弓弦を射切り、カルナの矢で傷ついた体で怒りに満ち、おまえの兵士たちに立ち向かった。
naivāpatpakṣigaṇo'ntarikṣe pārthena cāstreṇa kṛte'ndhakāre||
// 8-96-25 //
パールタが武器で暗闇を作り出したため、天空を鳥の群れさえ飛べなくなった。
śalyaṃ tu pārtho daśabhirnimeṣādbhṛśaṃ tanutre prahasannavidhyat|
tataḥ karṇaṃ dvādaśabhiḥ pṛṣatkairviddhvā punaḥ saptabhirapyavidhyat||
// 8-96-26 //
パールタは笑いながらシャリヤの鎧を瞬く間に十本の矢で射抜いた。さらにカルナを十二本の矢で射て、もう七本追加した。
sa pārthabāṇāsanaveganunnairdṛḍhāhataḥ patribhirugravegaiḥ|
vibhinnagātraḥ kṣatajokṣitāṅgaḥ karṇo babhau rudra ivāntakāle||
// 8-96-27 //
パールタの弓から放たれた恐ろしい速度の矢に激しく打たれ、全身を裂かれ血に染まったカルナは、世界の終末のルドラのように輝いた。
tatastribhistaṃ tridaśādhipopamaṃ śarairbibhedādhirathirdhanañjayam|
śarāṃśca pañca jvalanānivoragānpraveśayāmāsa jighāṃsuracyute||
suvarṇacitraṃ puruṣottamasya varmātha bhittvābhyapatansupuṅkhāḥ|
vegena gāṃ te viviśuśca rājansnātvā karṇā'bhimukhāḥ pratīyuḥ||
tānpañcabhallairdaśabhiḥ sumuktaistridhātridhaikaikamathoccakarta|
dhanañjayaste nyapatanpṛthivyāṃ yathā'hayastārkṣyamukhena kṛttāḥ||
// 8-96-28-30 //
すると三十神の王（インドラ）に匹敵するダナンジャヤを、アディラティ（カルナ）が三本の矢で射た。さらに燃える蛇のような五本の矢をアチュタ（クリシュナ）に突き刺した。その見事な羽のついた矢はプルショーッタマ（クリシュナ）の黄金で飾られた鎧を貫き、勢いよく大地に突き刺さった。カルナに向かって行き、血を浴びて戻ってきた。ダナンジャヤは五本の矢と十本の矢で、一本ずつ三つに裂いた。ダナンジャヤの矢は地上に落ちた。ガルダの口で切られた蛇のように。
tataḥ prajajvāla kirīṭamālī krodhena kakṣaṃ pradahannivāgniḥ|
sa karṇamākarṇavikṛṣṭasṛṣṭaiḥ śaraiḥ śarīrāntakarairjvaladbhiḥ|
marmasvavidhyatsa cacāla duḥkhāddhairyāttuṃ tasthāvatimātradhairyaḥ||
// 8-96-31 //
するとキリーティン（アルジュナ）は怒りに燃え上がった。火が枯れ草を焼き尽くすように。耳まで引き絞って放った体を貫く燃える矢で、カルナの急所を射た。カルナは苦しみに揺れたが、超人的な忍耐力で踏みとどまった。
prāduścakārātha śarānmahātmā dehaṃ vicinvanniva sūtajasya|
śarāstu te kāñcanacitrapuṅkhāḥ sampetururvyāṃ śataśo mahāntaḥ||
tataḥ śaraughaiḥ pradiśo diśaśca raviprabhāḥ karṇarathaśca rājan|
adṛśya āsītkupite dhanañjaye tuṣāranīhāravṛto giriryathā||
// 8-96-32-33 //
偉大な魂の戦士は、スータの息子の体を探るかのように矢を放った。黄金で飾られた見事な羽の矢が数百本、大地に降り注いだ。矢の群れで四方八方を、そしてカルナの戦車を、王よ、太陽の輝きの中に見えなくした。ダナンジャヤが怒ると、まるで霜と霧に覆われた山のようであった。
sacakrarakṣā api pṛṣṭhagopāḥ karṇasya ye cāpi puraḥsarāśca|
bhītā dravanti sma nihanyamānā maheṣubhiḥ pārthakarapraṇunnaiḥ||
// 8-96-34 //
カルナの車輪の守りも、背後の守りも、前方の守りも、パールタの手から放たれた偉大な矢に討たれて恐怖に駆られ、逃げ出した。
tato'rjuno vai bharatapravīro mahānubhāvaḥ samare nihantā|
suyodhanenānumatānvinighnansamucchritānsarathānsārabhūtān||
gāṇḍīvadhanvā dviguṇaṃ sahasraṃ kurupravīrānṛṣabhaḥ kurūṇām|
kṣaṇena sarvānsarathānsasūtānnināya rājankṣayamekavīraḥ||
// 8-96-35-36 //
バーラタの最良者アルジュナは、偉大な心の持ち主として戦場で敵を殺す者、スヨーダナ（ドゥルヨーダナ）に従う者たち、立ち上がった精鋭たちを打ち倒した。ガーンディーヴァの弓の持ち主、クル族の雄牛は二千のクルの精鋭たちを、瞬く間にすべて、戦車も御者もろとも、一人の英雄として滅ぼした。
atho palāyanta vihāya karṇaṃ tavātmajā ye kuravaśca śiṣṭāḥ|
etānavākīrya śarakṣatāṃśca vilapyamānāṃstanayānvimṛdgan||
// 8-96-37 //
カルナを見捨てて、おまえの息子たちと残りのクル勢は逃げ出した。矢に傷つき嘆き悲しむ息子たちを踏みにじりながら。
sarve praṇeśuḥ kuravo vibhagnāḥ pārtheṣubhiḥ samparitapyamānāḥ|
suyodhanenātha punarvariṣṭhāḥ pracoditāḥ karṇarathānuyāne||
bhoḥ kṣatriyāḥ śūratamāstu sarve kṣatre ca dharme niratāḥ stha yūyam|
na yuktarūpaṃ bhavatāṃ samīpātpalāyanaṃ karṇamatiprahāya||
tavātmajenāpi tathocyamānā naivāvatiṣṭhanta bhayādvivarṇāḥ|
kṣaṇena naṣṭāḥ pradiśo diśaśca sarve tataḥ prekṣya diśo viśūnyāḥ||
// 8-96-38-40 //
すべてのクル勢は打ち砕かれて散り散りになった。パールタの矢に焼かれて。スヨーダナ（ドゥルヨーダナ）が彼らを叱咤して、カルナの戦車の後に続くよう命じた。「おい、すべてのクシャトリヤよ、最も勇敢な者たちよ、おまえたちはクシャトリヤのダルマに生きる者たちだ。カルナを見捨てて逃げるなど、おまえたちにふさわしくない！」 だが、おまえの息子にそう言われても、恐怖に青ざめた彼らは踏みとどまらなかった。瞬く間に消え失せ、四方八方は空になった。
bhayāvadīrṇaḥ kurubhirvihīnaḥ pārtheṣubhiḥ samparitapyamānaḥ|
na vivyadhe bhārata tatra karṇaḥ pratīpamevārjunamabhyadhāvat||
// 8-96-41 //
バーラタよ、恐怖に引き裂かれ、クル勢に見捨てられ、パールタの矢に焼かれながらも、カルナはそこでたじろがなかった。逆にアルジュナに向かって突進していったのだ。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe ṣaṇṇavatitamo'dhyāyaḥ|| 96 ||
こうして、聖なる大マハーバーラタのカルナ篇の第96章は終わる。
