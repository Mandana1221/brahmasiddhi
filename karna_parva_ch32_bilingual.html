マハーバーラタ ― カルナ篇 第32章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 32 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ32」（カルナが戦場で、白馬を御するアルジュナの姿を示した者には黄金・象・牛・美姫・村落など望むままの褒賞を与えると幾度も誓いを述べ、敵を討つ覚悟を語る場面。最後にカルナが法螺貝を吹き鳴らし、それに応えて両軍の太鼓・象の声が鳴り響き、ドゥルヨーダナ陣営が歓喜する）です。各段落は原典の詩節番号（8-32-N）と和訳の段落番号が対応しています。
karṇaparva — dvātriṃśo'dhyāyaḥ (32)
第32章
sañjaya uvāca|
prayatnena tadā karṇo harṣayan vāhinīṃ tava|
ekaikaṃ samare dṛṣṭvā pāṇḍavaṃ paryapṛcchata|| // 8-32-1 //
サンジャヤは語った。 （1）そのとき、カルナは努めてあなたの軍を励まし、戦場で一人ひとりにパーンダヴァ（アルジュナ）について尋ねた。
yo mamādya mahātmānaṃ darśayec chvetavāhanam|
tasmai dadyām abhipretaṃ dhanaṃ yan manasā icchati|| // 8-32-2 //
（2）「今日、私に高潔な、白馬に乗る者（アルジュナ）を見せる者には、彼の望む財宝を何でも与えよう。
na cet tad abhimanyeta tasmai dadyām ahaṃ punaḥ|
śakaṭaṃ ratnasampūrṇaṃ yo me brūyād dhanañjayam|| // 8-32-3 //
（3）もし、それでも足りぬと思うなら、宝石で一杯の荷車を、アルジュナを知らせた者に与えよう。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
śataṃ dadyāṃ gavāṃ tasmai naityakaṃ kāṃsyadohanam|| // 8-32-4 //
（4）もし、アルジュナを見せた者がそれでも満足せぬなら、毎日青銅の器で乳を搾り取れる牛を百頭、彼に与えよう。
śataṃ grāmavarāṃś ca eva dadyām arjunadarśine|
tathā tasmai punar dadyāṃ śvetam aśvatarīratham|
yuktam añjanakeśībhir yo me brūyād dhanañjayam|| // 8-32-5 //
（5）アルジュナを見せた者には、百のすぐれた村を与えよう。さらに白いラバを引かせた戦車も与えよう。その美しい髪の黒いラバで飾られたものを、アルジュナを知らせた者に。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
anyaṃ vā'smai punar dadyāṃ sauvarṇaṃ hastiṣaṅgavam|| // 8-32-6 //
（6）もし、それでも満足せぬなら、黄金でできた六頭の象のような戦車を、もうひとつ与えよう。
tathāpy asmai punar dadyāṃ strīṇāṃ śatam alaṅkṛtam|
śyāmānāṃ niṣkakaṇṭhīnāṃ gītavādyavipaścitām|| // 8-32-7 //
（7）さらに美しく装った百人の、黒い肌の、胸飾りをつけ、歌と楽器に巧みな若い女性を与えよう。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
tasmai dadyāṃ śataṃ nāgāñ śataṃ grāmāñ śataṃ rathān|| // 8-32-8 //
（8）アルジュナを見せた者がそれでも満足せぬなら、百頭の象、百の村、百の戦車を与えよう。
suvarṇasya ca mukhyasya hayāgryāṇāṃ śataṃ śatān|
ṛdvyā guṇaiḥ sudāntāṃś ca dhuryavāhān suśikṣitān|| // 8-32-9 //
（9）最上の黄金と、最高の馬を百の百倍（一万頭）、よく調教された、戦車を引くに足る、優れた駿馬を――。
tathā suvarṇaśṛṅgīṇāṃ godhenūnāṃ catuḥśatam|
dadyāṃ tasmai savatsānāṃ yo me brūyād dhanañjayam|| // 8-32-10 //
（10）金の角をもつ乳牛と、仔牛のついた雌牛を四百頭、アルジュナを知らせた者に与えよう。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
anyad asmai varaṃ dadyāṃ śvetān pañcaśatān hayān|| // 8-32-11 //
（11）もし、それでもなお満足せぬなら、他の褒美として白馬を五百頭与えよう。
hemabhāṇḍaparicchannān sumṛṣṭamaṇibhūṣaṇān|
sudāntān api ca eva ahaṃ dadyām aṣṭādaśāparān|| // 8-32-12 //
（12）金の馬具で覆われ、磨かれた宝石で飾られた、よく訓練された馬を十八頭、さらに与えよう。
rathaṃ ca śubhraṃ sauvarṇaṃ dadyāṃ tasmai svalaṅkṛtam|
yuktaṃ paramakāmbhojair yo me brūyād dhanañjayam|| // 8-32-13 //
（13）白く、黄金で美しく飾られた戦車を、最上のカーンボージャ馬につないだものを、アルジュナを知らせた者に与えよう。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
anyad asmai varaṃ dadyāṃ kuñjarāṇāṃ śatāni ṣaṭ|| // 8-32-14 //
（14）それでもなお満足せぬなら、他の褒美として六百頭の象を与えよう。
kāñcanair vividhair bhāṇḍair ācchannān hemamālinaḥ|
utpannān aparānteṣu vinītān hastiśikṣakaiḥ|| // 8-32-15 //
（15）さまざまな黄金の馬具で覆われ、金の花飾りをつけ、西方の辺境で生まれ、象使いたちによって調教された象を。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
anyad asmai varaṃ dadyāṃ vaiśyagrāmāṃś caturdaśa|| // 8-32-16 //
（16）それでもなお満足せぬなら、他の褒美として十四の豊かなヴァイシャの村を与えよう。
susphītān dhanasaṃyuktān pratyāsannavanodakān|
akutobhayān susampannān rājabhojyāṃś caturdaśa|| // 8-32-17 //
（17）財に満ち、森と水に近く、恐れなく、王の暮らしにふさわしい、豊かな十四の村を。
dāsīnāṃ niṣkakaṇṭhīnāṃ māgadhīnāṃ śataṃ tathā|
pratyagravayasāṃ dadyāṃ yo me brūyāddhanañjayam|| // 8-32-18 //
（18）胸飾りをつけたマガダ国の奴隷女百人、若い娘たちを、アルジュナを知らせた者に与えよう。
na cet tad abhimanyeta puruṣo'rjunadarśivān|
anyaṃ tasmai varaṃ dadyāṃ yam asau kāmayet svayam|| // 8-32-19 //
（19）それでもなお満足せぬなら、彼自身が望むどんな褒美でも与えよう。
putradārān vihāya eva yad anyad vittam asti me|
tac ca tasmai punar dadyāṃ yadyac ca manasā icchati|| // 8-32-20 //
（20）妻子を除いて、私の財産はすべて、望みのままに与えよう。
hatvā ca sahitau kṛṣṇau tayor vittāni sarvaśaḥ|
tasmai dadyām ahaṃ yo me prabrūyāt keśavārjunau|| // 8-32-21 //
（21）そして二人のクリシュナ（ヴァースデーヴァ=クリシュナとアルジュナ）を倒したあと、二人の財宝のすべてを、ケーシャヴァとアルジュナを知らせた者に与えよう」。
sañjaya uvāca|
etā vācaḥ subahuśaḥ karṇa uccārayan yudhi|
dadhmau sāgarasambhūtaṃ susvaraṃ śaṅkham uttamam|| // 8-32-22 //
サンジャヤは語った。 （22）このようにカルナは戦いの中で何度もこのような言葉を発し、海から生まれた、音のよい最上の法螺貝を吹き鳴らした。
tā vācaḥ sūtaputrasya tathā yuktā niśamya tu|
duryodhano mahārāja saṃhṛṣṭaḥ sānujo'bhavat|| // 8-32-23 //
（23）御者の子のこれらの言葉を聞いて、大王よ、ドゥルヨーダナは弟たちと共に大いに喜んだ。
tato dundubhinirghoṣo mṛdaṅgānāṃ ca sarvaśā|
siṃhanādaḥ savāditraḥ kuñcarāṇāṃ ca niḥsvanaḥ|| // 8-32-24 //
（24）そして太鼓の音、ムリダンガ鼓の響き、獅子吼の声、楽器の音、象たちの咆哮――。
prādurāsīt tadā rājaṃs tvatsainye puruṣarṣabha|
yodhānāṃ samprahṛṣṭānāṃ tathā samabhavat svanaḥ|| // 8-32-25 //
（25）そのすべてが、国王よ、あなたの軍の中に響き渡った、人中の雄牛よ。喜び勇む戦士たちの声が、そのように起こった。
tathā prahṛṣṭe sainye taṃ pluvamānaṃ mahāratham|
vikatthamānaṃ ca tadā rādheyam arikarśanam|
madrarājaḥ prahasya idaṃ vacanaṃ pratyabhāṣata|| || // 8-32-26 //
（26）このように軍が喜ぶなか、進軍する偉大な戦車戦士、自讃する敵を討つカルナ（ラーデーヤ）に対して、マドラ王は笑いながら、次の言葉を語った。
iti śrīmanmahābhārate karṇaparvaṇi dvātriṃśo'dhyāyaḥ|| 32 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十二章は終わる。
