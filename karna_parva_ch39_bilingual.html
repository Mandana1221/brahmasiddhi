マハーバーラタ ― カルナ篇 第39章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 39 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ39」（カルナとシャルヤの両軍が激突する直前の場面）です。出陣するカルナの軍勢を見て、シャルヤは不吉な予兆（猛禽や肉食獣の徘徊、旗の震え、地鳴りなど）を列挙してカルナを挑発しつつ、パーンダヴァ軍の将たち（アルジュナ、ビーマ、ユディシュティラ、ナクラ・サハデーヴァ、ドラウパディーの子らなど）の武勇を次々と讃え、対するカルナの勝利は望めないと説きます。シャルヤの発言中、第4詩節・第5詩節はトリシュトゥブ調（4行詩節）で書かれており、章の他の部分の標準シュローカ調（2行詩節）とは異なります。
karṇaparva — ekonacatvāriṃśo'dhyāyaḥ (39)
第39章
sañjaya uvāca|
tataḥ parānīkabhidaṃ vyūham apratimaṃ kṛtam|
samīkṣya karṇaḥ pārthānāṃ dhṛṣṭadhumnābhirakṣitam|| // 8-39-1 //
サンジャヤは語った。 （1）そしてカルナは、ドリシュタデュムナに守られたパーンダヴァ方の、敵を突き破るほどの比類なき陣形を見て――。
prayayau rathaghoṣeṇa siṃhanādaraveṇa ca|
vāditrāṇāṃ ca ninadaiḥ kampayanniva medinīm|| // 8-39-2 //
（2）戦車の轟音、獅子吼、楽器の音でまるで大地を震わせるようにして進んだ。
sañjaya uvāca|
tataḥ prayāntaṃ rādheyaṃ madrarājaḥ smayanniva|
avadhūya idaṃ vākyamabravīt kurusannidhau|| // 8-39-3 //
サンジャヤは語った。 （3）進軍するカルナに、マドラ王は微笑むようにして、クル族の面前で、次の言葉を皮肉に語った。
camūṃ tavemāṃ vipulāṃ samṛdvām asaṅkheyām aśvanarākulāṃ ca|
tathā praveṣṭā samare dhanañjayaḥ kakṣaṃ dahan dīpta ivāśrayāśī|| // 8-39-4 //
（4）「お前のこの豊かな広大な軍勢、馬や兵士に満ち、数え切れぬほどの軍を、アルジュナは戦場で突き進むであろう。燃え立つ炎が乾いた枝を焼くように。
rathe stitau vīravarau vareṇyau siṃhaskandhau lohitapadmanetrau|
draṣṭā bhavān adya vinā prayatnāt tathāhi me śakunā vedayanti|| // 8-39-5 //
（5）戦車には、二人の勇者の中でも最高の者、獅子の肩をもち、赤い蓮のような目をした者たち（アルジュナとクリシュナ）が立っている。お前は今日、努力もなく彼らを見るだろう。鳥の前兆がそう告げている。
adya draṣṭā'si taṃ vīraṃ śvetāśvaṃ kṛṣṇasārathim|
nighnantaṃ śātravān saṅkhye yaṃ karṇa paripṛcchasi|| // 8-39-6 //
（6）今日、お前は、白馬をつけ、クリシュナを御者とする、戦場で敵を討つあの勇者（アルジュナ）を見るだろう。お前が尋ねていた、その人を。
adya tau puruṣavyāghrau lohitākṣau parantapau|
vāsudevārjunau karṇa draṣṭā'sy amitavikramau|| // 8-39-7 //
（7）今日、お前は、この人中の虎、赤い目の敵を焼く二人、ヴァースデーヴァとアルジュナを見るだろう、カルナよ、計り知れぬ武勇の二人を。
sārathiryasya govindo gāṇḍīvaṃ yasya kārmukam|
taṃ ced vantā'si rādheya tvaṃ no rājā bhaviṣyasi|| // 8-39-8 //
（8）御者はゴーヴィンダ（クリシュナ）、弓はガーンディーヴァの彼を、もしお前が討てるなら、お前は我らの王となるだろう、カルナよ。
pravāty eṣa mahāvāyurabhitas tava vāhinīm|
kravyādā vyāharanty ete mṛgāḥ kurvanti bhairavam|| // 8-39-9 //
（9）この大風は、お前の軍の周りに吹いている。肉食獣が鳴き、獣たちが恐ろしい声を発している。
paśya karṇa mahāghoraṃ bhayaṃ vai romaharṣaṇam|
arkaṃ jīmūtasaṅkāśaḥ kabandho vārya tiṣṭhati|| // 8-39-10 //
（10）見よカルナ、大いなる恐怖、身の毛もよだつ恐れを。雲のような黒い首なし胴体が、太陽の方を向いて立っている。
paśya yūthaṃ mṛgaśataṃ mṛgāṇāṃ sarvatodiśam|
rarāsa dīptalāṅgūlamādityām abhi saṃsthitam|| // 8-39-11 //
（11）見よ、百頭の獣の群れがあらゆる方向に。燃え立つ尻尾を振り、太陽に向かって吠えている。
paśya kākāṃś ca gṛdhrāṃś ca samavetān sahasraśaḥ|
ādityam abhivīkṣante hy aśivāḥ karṇa sasvarāḥ|| // 8-39-12 //
（12）見よ、カラスとハゲワシが何千と集っている。太陽を睨みながら、不吉な声で鳴き立てている、カルナよ。
śvetavājisamāyukte tava karṇa mahārathe|
patākāḥ prajvalanty etā dhvajaś ca atīva kampate|| // 8-39-13 //
（13）お前の白馬の大戦車の上で、旗は燃え、幡はひどく震えている。
udīryato hayān paśya mahākāyān mahājavān|
plavamānān mahāvīryān ākāśe garuḍān iva|| // 8-39-14 //
（14）見よ、大きな体、大きな速さ、偉大な武勇の馬たちが、空を漂うガルダ鳥のように立ち上がっている。
dhruvameṣu nimitteṣu bhūmim āvṛtya pārthivāḥ|
svapsyanti nihatāḥ karṇa śataśo'tha sahasraśaḥ|| // 8-39-15 //
（15）これらの兆しによって、確かに、王たちは大地を覆って眠るだろう、討たれて、カルナよ、百、千と。
śaṅkhānāṃ tumulaḥ śabdaḥ śrūyate romaharṣaṇaḥ|
ānakānāṃ ca rādheya mṛdaṅgānāṃ ca hanyatām|| // 8-39-16 //
（16）法螺貝の大きな音が聞こえる、身の毛のよだつ音が。カルナよ、太鼓、鼓、打ち鳴らされる楽器の音が。
śṛṇu śabdān bahuvidhān narāśvarathavājinām|
jyātalatreṣuśabdāṃś ca śṛṇu karṇa mahātmanām|| // 8-39-17 //
（17）さまざまな音が聞こえる――人・馬・戦車・象の、弓弦、籠手、矢の音が、カルナよ、高潔な者たちの。
hemarūpyapramṛṣṭānāṃ vāsasāṃ śilpinirmitāḥ|
sahemacandratārābhāḥ patākāḥ kiṅgiṇīyutāḥ|| // 8-39-18 //
（18）金や銀で飾られ、工匠が作った衣服、金の月と星のような、鈴のついた旗――。
nānāvarṇā raṇe bhānti śvasanena prakampitāḥ|
paśya karṇārjunasya etāḥ saudāminya iva ambude|| // 8-39-19 //
（19）さまざまな色の、戦場で風に揺れて輝く旗を見よ、カルナよ、アルジュナの旗を。雲の中の稲妻のごとく。
dhvajāḥ kaṇakaṇāyante vātenātisamīritāḥ|
sapatākarathāś ca api pāñcālānāṃ mahātmanām|| // 8-39-20 //
（20）旗は風に煽られてカチャカチャと音を立て、パーンチャーラの偉大な戦車戦士たちの戦車と旗もそうだ。
eṣa reṇuḥ samudbhūto divam āvṛtya tiṣṭhati|
gajavājipraṇunnā ca kampate karṇa medinī|| // 8-39-21 //
（21）この砂塵が立ち上って、天を覆っている。象と馬によって起こされて、大地は震えている、カルナよ。
śrūyate meghasaṅkāśo rathanemisvanas tathā|
paśya kuntīsutaṃ vīraṃ bībhatsum aparājitam|
prahariṣyantam āyāntaṃ kapipravaraketanam|| // 8-39-22 //
（22）雷のような戦車の車輪の音が聞こえる。見よ、クンティーの子、勇者アルジュナ、不敗の者を。戦いに来る猿の旗の者を。
gajāśvarathapattyoghāṃs tāvakān yudhi nighnataḥ|
dhvajāgraṃ dṛśyate tasya jyāśabdaś caiva śrūyate|| // 8-39-23 //
（23）象・馬・戦車・歩兵の群れをお前の戦士を討ちながら、旗の先が見える。弓弦の音が聞こえる。
eṣa saṃśaptakān bhūyas tān eva abhimukho gataḥ|
karoti kadanaṃ caiṣa saṅgāme dviṣatāṃ balī|| // 8-39-24 //
（24）さらに、サンシャプタカたちに向かって戦いに行く、敵を滅ぼす強者――この戦場で、大虐殺を行っている」。
sañjaya uvāca|
iti bruvāṇaṃ madreśaṃ karṇaḥ provāca manyumān|| // 8-39-25 //
サンジャヤは語った。 （25）そう語るマドラ王に、カルナは腹を立てて答えた。
paśya saṃśaptakaiḥ kruddhaiḥ samantāt samabhidrutaḥ|
eṣa sūrya iva ambhodaiś channaḥ pārtho na dṛśyate|
eṣa dānto'rjunaḥ śalya nimagnaḥ śokasāgare|| // 8-39-26 //
（26）「見よ、怒ったサンシャプタカたちにあらゆる方向から襲われて、雲に覆われた太陽のように、アルジュナは見えない。抑えられて、シャルヤよ、悲嘆の海に沈んでいる」。
śalya uvāca|
varuṇaṃ ko'mbhasā hanyād indhanena ca ko'nalam|
ko vā'nilaṃ nigṛhṇīyāt pibed vā ko mahārṇavam|| // 8-39-27 //
シャルヤは語った。 （27）「だれがヴァルナ神を水で討てようか、だれが火神アグニを薪で討てようか、だれが風（ヴァーユ）を捕えられようか、だれが大海を飲み干せようか。
īdṛgrūpam ahaṃ manye pārthasya yudhi nirjayam|
na hi śakyo'rjuno jetuṃ yudhi devāsurair api|| // 8-39-28 //
（28）それに等しいものと、私は考える、アルジュナを戦場で打ち負かすことを。アルジュナは、神々にもアスラにも、戦場で打ち負かすことはできぬ。
athaighaṃ paritoṣas te vāgbhis tvaṃ sumānā bhava|
na hi śakyo yudhā jetum anyaṃ kuru manoratham|| // 8-39-29 //
（29）あるいは、それで満足して、言葉で喜ぶがよい。戦で勝てぬなら、別の望みをもて。
bāhubhyām uddhared bhūmiṃ dahet kruddha imāḥ prajāḥ|
pātayet tridivād devān na arjunaṃ samare jayet|| // 8-39-30 //
（30）アルジュナは、両腕で大地を引き上げ、怒れば民すべてを焼き尽くし、天から神々を落とせる。戦場で彼を倒せはしない。
paśya kuntīsutaṃ bhīmaṃ vīramakliṣṭakāriṇam|
praharantaṃ mahābāhuṃ sthitaṃ merum iva acalam|| // 8-39-31 //
（31）見よ、クンティーの子ビーマ、苦労知らずの勇者を。打ち下ろしながら立つ、メール山のように動かぬ長き腕の者を。
amarṣī puruṣavyāghraḥ sadā vairamanusmaran|
eṣa bhīmo jayaprepsur yudhi tiṣṭhati vīryavān|| // 8-39-32 //
（32）忍び難い者、人中の虎、常に憎しみを思い起こし、戦場で勝利を望む武勇のビーマが立っている。
eṣa dharmabhṛtāṃ śreṣṭho dharmarājo yudhiṣṭhiraḥ|
tiṣṭhaty asukaraḥ saṅkhye paraiḥ parapurañjayaḥ|| // 8-39-33 //
（33）正義を持つ者の中で最上、ダルマ王ユディシュティラが、打ち勝ちがたく、敵を退ける者として戦場に立っている。
etau ca puruṣavyāghrāv āśvineyau mahārathau|
nakulaḥ sahadevaś ca tiṣṭhato yudhi durjayau|| // 8-39-34 //
（34）これら人中の虎、アシュヴィン神の子である偉大な戦車戦士たち、ナクラとサハデーヴァが、打ち勝ちがたく戦に立つ。
ete tiṣṭhanti kārṣṇeyāḥ pañca pañcācalā iva|
yotsyamānā mahāvīryā bhīmārjunasamā yudhi|| // 8-39-35 //
（35）カルシュナヤ家の五人の勇者（五皇子）が、五つの山のように立つ。戦おうとしている偉大な武勇の者たち、ビーマとアルジュナに等しい者たち。
ete drupadaputrāś ca dhṛṣṭadyumnapurogamāḥ|
hīnāḥ satyajitā vīrās tiṣṭhanti paramaujasaḥ|| // 8-39-36 //
（36）これらドゥルパダの息子たち、ドリシュタデュムナを先頭とした、劣らず、真実を征服する者たち、最高の輝きを持つ者たちが立っている。
yatra kṛṣṇārjunau vīrau yatra rājā yudhiṣṭhiraḥ|
tatra dharmaś ca satyaṃ ca yato dharmas tato jayaḥ|| // 8-39-37 //
（37）勇者クリシュナとアルジュナ、ユディシュティラ王がいる場所――そこには正義と真実がある。正義あるところに勝利はある」。
iti saṃvadatoreva tayoḥ puruṣasiṃhayoḥ|
te sene samasajjetāṃ gaṅgāyamunavadbhṛśam|| // 8-39-38 //
（38）そのように人中の獅子二人（カルナとシャルヤ）が語り合っているうちに、両軍は激しく激突した。ちょうどガンジスとヤムナーが合流するように。
iti śrīmanmahābhārate karṇaparvaṇi ekonacatvāriṃśo'dhyāyaḥ|| 39 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十九章は終わる。
