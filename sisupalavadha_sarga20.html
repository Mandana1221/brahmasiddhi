विंशः सर्गः

第二十章　シシュパーラとクリシュナの一騎討ち
Metre: Aupacchandasika (Vaitālīya variant) — V.1–79
V.1
Sanskrit (IAST) mukham ullasita-tri-rekham uccair bhidura-bhrū-yuga-bhīṣaṇaṃ dadhānaḥ / samitāv iti vikramān amṛṣyann agata-bhīr āhvata cedi-rāṇ murārim // 20.1 //
和訳

三条の皺が浮かび上がった顔を高く掲げ、曲がった眉の対で恐ろしき相を呈して、戦場においてムラーリの武勇に堪えかね、恐れなきチェーディ王は挑戦した。

注

【Vallabhadeva】

cedi-rāṭ（チェーディ王＝シシュパーラ）は samitau（戦場で）vikramān（ムラーリの武勇を）amṛṣyan（堪えかねて）、agata-bhīḥ（恐れなく）murārim āhvata（ムラーリに挑戦した）。ullasita-tri-rekham（怒りで三条の額の皺が浮かんだ）mukham（顔を）dadhānaḥ（呈して）。bhidura-bhrū-yuga-bhīṣaṇam（曲がった眉の対で恐ろしき）。第二十章の韻律は Aupacchandasika。

【Mallinātha】

iti（かくして＝前章の激戦の後）samitau ājiに（戦場で）。vikramān murāreḥ（ムラーリの武勇を）amṛṣyan（堪えかね）。ullasitā tri-rekhāḥ（怒りで浮かんだ三条の額皺）。bhidureṇa granthilena bhrūyugena bhīṣaṇam（曲がった眉弓で恐ろしき）mukham uccaiḥ unnataṃ（高く掲げた顔を）dadhānaḥ（呈する）。gata-bhīḥ（恐れなき）cedi-rāṭ（チェーディ王）が murārim（ムラーリを）āhvata（挑んだ）。amṛṣya（怒り）が挑戦の hetu となる kāvyaliṅga。本章は Aupacchandasika（Vaitālīya の重音過多型）韻律。

V.2
Sanskrit (IAST) śita-cakra-nipāta-saṃpratīkṣyaṃ vahataḥ skandha-gataṃ ca tasya mṛtyum / abhi śauri ratho 'tha noditāśvaḥ prayayau sārathi-rūpayā niyatyā // 20.2 //
和訳

鋭利な円盤の一撃を待ち受け、肩に死を載せて運ぶその者に向かい、馬を駆られた彼の戦車は、御者の姿をした運命に導かれてシャウリの方へ進み出た。

注

【Vallabhadeva】

tasya caidyasya（チャイディヤの）rathaḥ（戦車は）abhi śaurim（シャウリに向かい）prayayau（進んだ）。śita-cakra-nipāta-saṃpratīkṣyam（鋭い円盤＝スダルシャナの一撃を待ち受ける）。skandha-gatam mṛtyum vahataḥ（肩に死を載せて運ぶ者）。sārathi-rūpayā niyatyā（御者の姿をした運命＝niyati に）noditāśvaḥ（馬を駆られた）。運命が御者となって死へ導くという rūpaka。

【Mallinātha】

atha āhvānānantaram（挑戦の後に）。śita-cakra-nipātam（鋭いスダルシャナの一撃を）saṃpratīkṣate iti saṃpratīkṣyam（待ち受ける）。skandha-gatam mṛtyum vahataḥ tasya（肩に死を載せ運ぶ彼の）。sārathi-rūpayā niyatyā（御者の姿をした運命に）noditāśvaḥ（馬を駆られ）。abhi śaurim（シャウリに向かい）prayayau（進んだ）。niyati＝vidhi（運命）の rūpaka。

V.3
Sanskrit (IAST) abhi caidyam agād ratho 'pi śaurer avaniṃ jāguḍa-kuṅkumābhitāmraiḥ / guru-nemi-nipīḍanāvadīrṇa-vyasu-deha-sruta-śoṇitair vilimpan // 20.3 //
和訳

シャウリの戦車もまたチャイディヤに向かって進んだ。重い車輪の圧迫に砕かれた死者の体から流れ出た血で――ジャーグダのサフランのように赤い血で――大地を塗りながら。

注

【Vallabhadeva】

śaureḥ rathaḥ api（シャウリの戦車もまた）abhi caidyam agāt（チャイディヤに向かって進んだ）。guru-nemi-nipīḍanā（重い車輪の圧迫で）avadīrṇa（砕かれた）vyasu-deha（死体から）sruta-śoṇitaiḥ（流れ出た血で）avanim vilimpan（大地を塗りながら）。jāguḍa（ジャーグダ地方の）kuṅkumābhitāmraiḥ（サフランのように赤い血で）。jāguḍa はサフランの産地。

【Mallinātha】

śaureḥ kṛṣṇasya rathaḥ api（クリシュナの戦車もまた）abhi caidyam agāt（チャイディヤに向かった）。jāguḍaḥ は deśa-viśeṣaḥ（特定の地域＝サフラン産地）。tad-vad abhitāmraiḥ（それのように赤い）。guru-nemi-nipīḍanāt（重い車輪の圧で）avadīrṇa（裂かれた）vyasūnāṃ vigataPrāṇānāṃ dehebhyaḥ（死体から）srutaiḥ śoṇitaiḥ（流出した血で）avanim vilimpan（大地を塗りながら）。upamā。

V.4
Sanskrit (IAST) sa nirāyata-ketanāṃśukāntaḥ kala-nikvāṇa-karāla-kiṅkiṇīkaḥ / virarāja ripu-kṣaya-pratijñā-mukharo mukta-śikhaḥ svayaṃ nu mṛtyuḥ // 20.4 //
和訳

長く伸びた旗布の裾を持ち、美しい音を立てる恐ろしき小鈴をつけ、敵の滅亡の誓いで喧しく、髪を解き放った、その戦車は輝いた――まるで死神そのもののように。

注

【Vallabhadeva】

saḥ bhagavad-rathaḥ（クリシュナの戦車は）virarāja（輝いた）。nirāyata-ketanāṃśukāntaḥ（長く伸びた旗布の端を持つ）。kala-nikvāṇa-karāla-kiṅkiṇīkaḥ（美しい響きの恐ろしき小鈴を持つ）。ripu-kṣaya-pratijñā-mukharaḥ（敵の滅亡の誓いで喧しい）。mukta-śikhaḥ（髪を解いた＝敵を殺すまで髪を結ばぬ誓い）。svayam nu mṛtyuḥ（死神そのものではないか）という utprekṣā。

【Mallinātha】

saḥ kṛṣṇasya rathaḥ（クリシュナの戦車は）。nirāyataḥ atidīrghaḥ ketanāṃśukāntaḥ（非常に長い旗布の裾を持つ）。kala-nikvāṇaiḥ madhura-svaraiḥ karālāḥ kuśalāḥ pragalbhāḥ kiṅkiṇyaḥ（美しい声で巧みに鳴る小鈴）。ripu-kṣaya-pratijñayā mukharaḥ（敵殺害の誓で声高い）。mukta-śikhaḥ mukta-keśaḥ（髪を解放した＝殺すまで結わぬ誓い）。svayam nu mṛtyuḥ（まさに死神か）という utprekṣā。

V.5
Sanskrit (IAST) sajalāmbudharāravānukārī dhvanir āpūrita-diṅmukho rathasya / praguṇīkṛta-keka-mūrdhva-kaṇṭhaiḥ śiti-kaṇṭhair upakarṇayāṃbabhūve // 20.5 //
和訳

雨雲の轟きを模した、四方に満ちる戦車の響きは、鳴き声を超える首を上げた孔雀たちによって聞き取られた。

注

【Vallabhadeva】

rathasya dhvaniḥ（戦車の響きは）sajala-ambudhara-ārava-anukārī（水を含んだ雲の轟きを模す）āpūrita-diṅmukhaḥ（方角を満たす）。śiti-kaṇṭhaiḥ（孔雀たちに）ūrdhva-kaṇṭhaiḥ（首を上げた）praguṇīkṛta-kekaiḥ（鳴き声を優れたものにした）upakarṇayāṃ babhūve（聞かれた）。雲の轟きと間違えて孔雀が首を上げて鳴いたという bhrāntimad-alaṅkāra。

【Mallinātha】

sajala ambudharaḥ tasya āravamの anukāra＝雷鳴を模した深い響き。āpūrita-dik-mukhaḥ（四方に満ちる）rathasya dhvaniḥ（戦車の音は）。ūrdhvāḥ kaṇṭhāḥ yeṣām（首を上げた）śiti-kaṇṭhaiḥ nīla-kaṇṭhaiḥ（孔雀たちに）praguṇīkṛtāḥ atitārīkṛtāḥ kekāḥ（鳴声が超えられた）。upakarṇyā babhūve（傾聴された）。雷の音と思い込んだ孔雀が鳴く bhrāntimat。vastunaの alaṅkāra-dhvani。

V.6
Sanskrit (IAST) abhivīkṣya vidarbha-rāja-putrī-kuca-kāśmīraja-cihnam acyutoraḥ / cira-sevitayāpi cedi-rājaḥ sahasāvāpa ruṣā tadaiva yogam // 20.6 //
和訳

ヴィダルバ王女の乳房のサフランの跡がついたアチュタの胸を見て、チェーディ王は長年にわたり蓄えてきた怒りとたちまち一体になった。

注

【Vallabhadeva】

cedi-rājaḥ（チェーディ王は）acyuta-uraḥ（アチュタの胸に）vidarbha-rāja-putrī-kuca-kāśmīraja-cihnam（ヴィダルバ王女＝ルクミニーの乳房のサフラン痕を）abhivīkṣya（見て）、cira-sañcitayā api（長く蓄えた）ruṣā（怒りと）sahasā tadaiva yogam āvāpa（直ちに一体となった）。ルクミニーは元々シシュパーラに与えられるはずだったがクリシュナに奪われた。その怨恨の証が胸のサフラン痕。samāsokti。

【Mallinātha】

cedi-rājaḥ śiśupālaḥ（チェーディ王シシュパーラは）vidarbha-rāja-putryāḥ rukmiṇyāḥ（ヴィダルバ王女ルクミニーの）kucayoḥ yat kāśmīrajam kuṅkumam（乳房のサフランの）tac cihnam（その印が）yasya tat acyutoraḥ（アチュタの胸を）abhivīkṣya（見て）、cira-sevitayā api（長年馴染みの＝ルクミニー略奪以来蓄えた）ruṣā（怒りと）sahasā tadaiva yogam āvāpa（突然一体になった）。恋人が他者の情交の印を見て嫉妬する如き samāsokti。utprekṣā（tadaiva＝tadānīm iva）も。

V.7
Sanskrit (IAST) janitāśani-śabda-śaṅkam uccair dhanur āsphālitam adhvanan nṛpeṇa / capala-anila-codyamāna-kalpa-kṣaya-kālāgni-śikhānibha-sphuraj-jyam // 20.7 //
和訳

雷鳴の疑いを起こさせるほどに、王によって打ち鳴らされた弓は高く轟いた――激しい風に煽られた劫末の火焔に似た弦を閃かせながら。

注

【Vallabhadeva】

nṛpeṇa（王＝チェーディ王に）āsphālitam（打ち鳴らされた）dhanuḥ（弓は）uccaiḥ adhvanat（高く鳴り響いた）。janita-aśani-śabda-śaṅkam（雷鳴と疑わせる）。capala-anilena codyamānasya（激しい風に煽られた）kalpa-kṣaya-kālāgneḥ（劫末の火の）śikhā-nibhā（焔に似た）sphuraj-jyam（閃く弦を持つ）。upamā と bhrāntimat と kāvyaliṅga の saṅkara。

【Mallinātha】

nṛpeṇa cedi-pena（チェーディ王に）āsphālitam（叩かれた）dhanuḥ uccaiḥ adhvanat（弓は高く轟いた）。janita-aśani-śabda-śaṅkam（雷鳴の疑いを生じた）。calapa-anilena tīvra-anilena codyamānasya（激しい風に煽られた）kalpa-kṣaya-kālāgneḥ（劫末の火の）yā śikhā（その焔に）nibhā samānā（似た）sphurantī（閃く）jyā（弦）yasya（を持つ）。agni-śikhā-nibha の upamā、aśani-śabda-śaṅkā の bhrāntimat、āsphālitam-adhvanat の kāvyaliṅga の saṅkara。

V.8
Sanskrit (IAST) samakālam ivābhilakṣaṇīya-graha-saṃdhāna-vikarṣaṇāpavargaiḥ / atha sābhisaraṃ śarais tarasvī sa tiraskartum upendram abhyavarṣat // 20.8 //
和訳

つかみ・番え・引き・放ちがほとんど同時に行われた矢をもって、力強いかのチェーディ王は随兵とともにウペーンドラを圧倒せんと矢の雨を降らせた。

注

【Vallabhadeva】

atha（さて）tarasvī saḥ（力強い彼は）sābhisaram（随兵とともに）upendram（ウペーンドラ＝ハリを）tiraskartum（圧倒するため）abhyavarṣat（矢の雨を降らせた）。samakālam iva（ほとんど同時に）abhilakṣaṇīya-graha-saṃdhāna-vikarṣaṇa-apavargaiḥ（見事に見えるつかみ・番え・引き・放ちを持つ）śaraiḥ（矢で）。弓術四動作の同時性の utprekṣā。

【Mallinātha】

atha dhanur-āsphālanānantaram（弓の打鳴らしの後）tarasvī balavān saḥ caidyaḥ（力強いチャイディヤは）samakālam iva（ほぼ同時に）。abhilakṣaṇīyāḥ dṛśyāḥ（見事な）grahaḥ（つかみ）saṃdhānam（番え）vikarṣaṇam（引き）apavargaḥ（放ち）yeṣām taiḥ śaraiḥ（の矢で）。sābhisaram sānucaram（従者とともに）upendram harim tiraskartum（ウペーンドラを覆わんと）abhyavarṣat（矢の雨を降らせた）。utprekṣā。

V.9
Sanskrit (IAST) ṛjutā-phala-yoga-śuddhi-bhājāṃ guru-pakṣāśrayiṇāṃ śilīmukhānām / guṇinā natim āgatena sandhiḥ saha cāpena samañjaso babhūva // 20.9 //
和訳

正直さと果実と結びつきと清浄を持ち、大なる翼に依る矢たちと、弦を持ち身を屈めた弓との結合は、まことにふさわしいものであった。

注

【Vallabhadeva】

śilīmukhānām（矢の）cāpena saha（弓との）sandhiḥ（結合は）samañjasaḥ babhūva（ふさわしかった）。śleṣa：ṛjutā＝真っ直ぐさ／正直、phala＝矢尻／果実、yoga＝結合／修行、śuddhi＝金属純度／清浄。guru-pakṣa-āśrayiṇām＝大きな羽根（翼）に依る／偉大な側に依る。guṇinā＝弦を持つ／徳ある。natim āgatena＝引き曲げられた／恭順の姿勢を取った。弱者が強者と結ぶ sandhiの道理という samāsokti。

【Mallinātha】

ṛjutvam avakratvam（真っ直ぐさ＝誠実さ）。phalam śalyam（矢尻＝報い）。yogaḥ śuddhiḥ（結合・清浄＝内外の清浄）。guru-pakṣasya（大きな翼＝有力者の）āśrayaḥ（庇護）。guṇinā jyāvatā（弦ある＝徳ある）natim āgatena（曲がった＝恭順の）cāpena saha（弓との）sandhiḥ samaぁjasaḥ（結合はふさわしい）。弱者が有力な庇護者と同盟する政治的 samāsokti。

V.10
Sanskrit (IAST) aviṣahyatame kṛtādhikāraṃ vaśinā karmaṇi cedi-pārthivena / arasad dhanur uccakair dṛḍhārti-prasabhākarṣaṇa-vepamāna-jīvam // 20.10 //
和訳

最も耐え難き務めに任じられた弓は、チェーディ王という主人に力ずくで弦を引かれ、堅き苦悩に震える弦をもって、高らかに叫んだ。

注

【Vallabhadeva】

dhanuḥ（弓は）uccakaiḥ arasat（高らかに叫んだ）。vaśinā cedi-pārthivena（支配者たるチェーディ王に）aviṣahyatame karmaṇi（最も耐え難い任務＝敵殺害の業務に）kṛtādhikāram（任命された）。dṛḍhayoḥ atyoḥ（堅い弓端の）prasabhā-ākarṣaṇena（力ずくの引きによって）vepamānā jīvā（震える弦）yasya tat（を持つ）。弓の擬人化：王に過酷な任務を命じられた従者が強制的に引かれて叫ぶ samāsokti。

【Mallinātha】

vaśinā svatantreṇa cedi-pārthivena（自在なるチェーディ王に）aviṣahyatame duṣkare karmaṇi（最も困難な任務＝敵討滅に）kṛtādhikāram（任命された）dhanuḥ（弓は）。dṛḍhayoḥ atyoḥ dhanuṣ-koṭyoḥ（堅い弓端の）prasabhā-ākarṣaṇena（力ずくの引きで）vepamānā jīvā jyā（震える弦）yasya tat（を持つ）。uccakaiḥ arasat ādhvanat（高く叫んだ）。王に任命された従者が強制的に引っ張られて叫ぶ samāsokti。jīvā は「弦」と「命」の両義。

V.11
Sanskrit (IAST) anusantatipātinaḥ paṭutvaṃ dadhataḥ śuddhibhṛto gṛhītapakṣāḥ / vadanād iva vādino 'tha śabdāḥ kṣitibhartur dhanuṣaḥ śarāḥ prasasruḥ // 20.11 //
和訳

途切れなく飛び、鋭さを備え、清浄を帯び、一方に与する――チェーディ王の弓という論者の口から、矢という言葉が次々と発せられた。

注

【Vallabhadeva】

弓を論者に喩える samāsokti。śarāḥ（矢）＝śabdāḥ（言葉）。anusantatipātinaḥ（途切れなく続けざまに落ちる）＝途切れなく論ずる。paṭutvam（鋭さ）＝弁舌の切れ味。śuddhibhṛtaḥ（清浄を有する）＝浄化された／正しい。gṛhītapakṣāḥ（羽を有する）＝一方の立場を取る。vadanāt（口から）＝弓口から。

【Mallinātha】

kṣitibhartuḥ dhanuṣaḥ（王の弓から）śarāḥ prasasruḥ（矢が放たれた）。vādinaḥ vadanād iva（論者の口から言葉が出るように）。矢の属性が論者の言葉の属性と重なる samāsokti：anusantatipātinaḥ（連続して飛ぶ／連続して述べる）、paṭutvam（鋭い／巧みな）、śuddhibhṛtaḥ（浄化された／正しい）、gṛhītapakṣāḥ（羽を持つ／立場を取る）。

V.12
Sanskrit (IAST) gavalāsitakānti tasya madhyasthitaghorāyatabāhudaṇḍanāsam / dadṛśe kupitāntakonnatabhru-yugabhīmākṛti kārmukaṃ janena // 20.12 //
和訳

水牛の角のように黒く輝き、中央に恐ろしく長い腕という棒を構え、怒れる死神が眉を吊り上げたかのような恐ろしい姿をしたシシュパーラの弓は、人々の目に映った。

注

【Vallabhadeva】

弓を怒れる死神に喩える。gavalāsitakānti（水牛角のように黒い輝き）。madhyasthita-ghora-āyata-bāhu-daṇḍa-nāsam（中央に恐ろしく長い腕＝棒のような鼻＝矢台を持つ）。kupitāntaka-unnata-bhrū-yuga-bhīma-ākṛti（怒った死神が眉を吊り上げた恐ろしい姿）＝弓の両端が反り上がった形状。

【Mallinātha】

tasya kārmukam janena dadṛśe（彼の弓が人々に見られた）。gavalāsitakānti（水牛角の黒い輝き）は弓の色を示す。madhyasthita...nāsam：弓の中央に構えた腕が棒のように長い。kupitāntaka...ākṛti：怒れる死神が眉を上げた恐ろしい相貌のような形。弓全体を擬人化する rūpaka。

V.13
Sanskrit (IAST) taḍidujjvalajātarūpapuṅkhaiḥ khamayaḥśyāmamukhair abhidhvanadbhiḥ / jaladair iva raṃhasā patadbhiḥ pidadhe saṃhatiśālibhiḥ śaraughaiḥ // 20.13 //
和訳

savituḥ marīcīn paribhāvukaiḥ（太陽光線を圧する）acirābhyaktasya mataṅgajāṅgasya bhābhiḥ（塗油直後の象の体の光沢のような）jaladaiḥ（雲で）abhitaḥ sphuradbhiḥ uccaiḥ（四方に高く広がり）dhūmaketoḥ ketanatā iva vidadhe（彗星の旗のようになった）。utprekṣā修辞。

V.70

注

【Vallabhadeva】

vārivāhāḥ（雲が）jvalataḥ citrabhānoḥ śamanāya（燃え盛る火を鎮めるために）pralayāplāvam iva abhidarśayantaḥ（劫末の大洪水を示すかのように）vṛṣanādinaḥ（牡牛のように吼え）nadīnām prataṭāropitavāri（河の岸辺を溢れさせる水を）vavṛṣuḥ（降らせた）。upamā。

【Mallinātha】

vārivāhāḥ meghāḥ（雲が）jvalataḥ citrabhānoḥ agneḥ（燃える火の）śamanāya（鎮静のため）pralaye āplāvam iva abhidarśayantaḥ（劫末の大洪水を示すかの如く）。vṛṣavat nādayanti iti vṛṣanādinaḥ（牡牛のように吼える）。nadīnām prataṭeṣu āropitāni vārīṇi（河の岸に溢れる水を）vavṛṣuḥ（降らせた）。upamā。

V.71
Sanskrit (IAST) madhurair api bhūyasā sa medhyaiḥ prathamaṃ pratyuta vāribhir didīpe / pavamānasakhas tataḥ krameṇa praṇayakrodha ivāśamad vivādaiḥ // 20.71 //

風の友である火は、甘い雲の水に浴びてかえっていっそう燃え盛った。しかしやがて次第に鎮まった――恋人の痴話喧嘩が甘い言葉にかえって燃え上がり、やがて静まるように。

注

【Vallabhadeva】

pavamānasakhaḥ agniḥ（風の友＝火が）medhyaiḥ（雲の）madhuraiḥ vāribhiḥ（甘い水で）prathamam pratyuta bhūyasā didīpe（最初はかえっていっそう燃えた）。tataḥ krameṇa aśamat（やがて次第に鎮まった）。praṇayakrodhaḥ iva vivādaiḥ（恋の怒りが言い争いで燃え、やがて静まるように）。upamā。

【Mallinātha】

pavamānasya sakhaḥ agniḥ（風の友＝火が）medhyaiḥ（雲由来の）madhuraiḥ vāribhiḥ（甘い水で）prathamam pratyuta bhūyasā didīpe（最初はかえっていっそう輝いた）。tataḥ krameṇa aśamat（やがて次第に鎮火した）。praṇayakrodhaḥ iva vivādaiḥ（恋の怒りが甘い言い争いで燃え、やがて鎮まるように）。水で火が燃える逆説、次いで鎮火。upamā修辞。

V.72
Sanskrit (IAST) paritaḥ prasabhena nīyamānaḥ śaravarṣair avasāyam āśrayāśaḥ / prabaleṣu kṛtī cakāra vidyudvyapadeśena ghaneṣv anupraveśam // 20.72 //
和訳

水の矢に四方から力ずくで滅びへ追いやられた火は、巧みに稲妻の姿を装って力ある雲の中に潜り込んだ。

注

【Vallabhadeva】

āśrayāśaḥ agniḥ（火が）śaravarṣaiḥ（水の矢＝雨に）paritaḥ prasabhena avasāyam nīyamānaḥ（四方から力ずくで滅びへ導かれ）kṛtī（巧みに）prabaleṣu ghaneṣu（強力な雲の中に）vidyudvyapadeśena（稲妻を口実として）anupraveśam cakāra（潜入した）。強者に圧された者が異国に逃げ、再入するという処世の知恵。samāsokti修辞。

【Mallinātha】

āśrayāśaḥ agniḥ（火が）śaravarṣaiḥ toyasekaiḥ（水の矢＝雨に）prasabhena（力ずくで）paritaḥ avasāyam nīyamānaḥ（四方から滅びへ導かれ）kṛtī kuśalaḥ（巧みな者として）prabaleṣu ghaneṣu megheṣu（強大な雲の中に）vidyudvyapadeśena tadicchale na（稲妻の口実で）anupraveśam cakāra（潜入した）。火が稲妻として雲に入った。samāsokti修辞。

V.73
Sanskrit (IAST) prayataḥ praśamaṃ hutāśanasya kvacid ālakṣyata muktamūlam arciḥ / balabhitprahitāyudhābhighātāt truṭitaṃ patripater ivaikapatram // 20.73 //
和訳

消えゆく火の根元を離れた炎がところどころに見えた。それはインドラの投じた雷の一撃でガルダからちぎれ落ちた一枚の翼羽のようであった。

注

【Vallabhadeva】

praśamam prayataḥ hutāśanasya（鎮火に向かう火の）muktamūlam arciḥ（根元を離れた炎が）kvacit ālakṣyata（ところどころ見えた）。balabhit-prahita-āyudha-abhighātāt（インドラの放った雷の打撃から）truṭitam（折れた）patripateḥ garuḍasya ekam patram iva（ガルダの一枚の羽のように）。かつてガルダがインドラの雷の重さゆえに一枚の羽を捨てたという伝承に基づく。upamā。

【Mallinātha】

praśamam prayataḥ（鎮火に向かう）hutāśanasya（火の）muktamūlam（根元を離れた）arciḥ jvālā（炎が）kvacit ālakṣyata（どこかに見えた）。balabhidā śakreṇa prahitasya（インドラに放たれた）āyudhasya vajrasya（武器＝雷の）abhighātāt truṭitam（打撃で折れた）patripateḥ garuḍmataḥ ekam patram iva（ガルダの一枚の羽のように）。upamā。

V.74
Sanskrit (IAST) vyagaman sahasā diśāṃ mukhebhyaḥ śamayitvā śikhinaṃ ghanāghanaughāḥ / upakṛtya nisargataḥ pareṣām uparodhaṃ na hi kurvate mahāntaḥ // 20.74 //
和訳

雨雲の群れは火を鎮めると、たちまち四方の空へ去っていった。偉大な者は本性から他者を助け、助けた後に居座ることはしないものである。

注

【Vallabhadeva】

ghanāghanaughāḥ（雨雲の群れが）śikhinam（火を）śamayitvā（鎮めて）diśām mukhebhyaḥ sahasā vyagaman（方角の入口から忽ち去った）。mahāntaḥ（偉大な者は）nisargataḥ（本性から）pareṣām upakṛtya（他者を助けて）uparodham na hi kurvate（妨害はしないものだ）。もし雲が去らねば日光を遮り続け害となる。arthāntaranyāsa修辞。

【Mallinātha】

ghanāghanaughāḥ（雨雲の群れが）śikhinam agnim（火を）śamayitvā（鎮めて）sahasā diśām mukhebhyaḥ vyagaman（忽ち方角から立ち去った）。mahāntaḥ（偉大な者は）nisargataḥ svabhāvāt（天性により）pareṣām upakṛtya（他者を助けて）uparodham na hi kurvate（居座って邪魔はしない）。arthāntaranyāsa修辞。

V.75
Sanskrit (IAST) kṛtadāham udarciṣaḥ śikhābhiḥ pariṣiktaṃ muhur ambhasā navena / vigatāmbudharavraṇaṃ prapede gaganaṃ tāpitapāyitāsilakṣmīm // 20.75 //
和訳

火の炎で焼かれ、次に新たな水で繰り返し注がれ、雲という傷跡も消えた空は、焼入れして水に浸した剣の美しさを得た。

注

【Vallabhadeva】

gaganam（空が）udarciṣaḥ śikhābhiḥ（火の炎で）kṛtadāham（焼かれ）navena ambhasā muhuḥ pariṣiktam（新たな水で繰り返し注がれ）vigatāmbudharavraṇam（雲という傷跡が消え）tāpitapāyitāsilakṣmīm prapede（焼入れし水に浸した剣の美を得た）。刀も焼入れして水で冷やすと傷跡が消え光沢を得る。nidarśanā に rūpaka が混合。

【Mallinātha】

gaganam（空が）udarciṣaḥ agneḥ śikhābhiḥ（火の炎で）kṛtadāham（焼かれ）navena ambhasā muhuḥ pariṣiktam（新水で何度も注がれ）vigatāḥ ambudharāḥ eva vraṇāḥ（去った雲が傷跡のよう）tāpitasya pāyitasya aseḥ lakṣmīm（焼入れし水に浸した刀の美を）prapede（得た）。nidarśanā に rūpaka が混合。

V.76
Sanskrit (IAST) iti narapatir astraṃ yadyad āviścakāra prakupita iva rogaḥ kṣiprakārī vikāram / bhiṣag iva gurudoṣacchedinopakrameṇa kramavid atha murāriḥ pratyahaṃ tattad āśu // 20.76 //

注

【Vallabhadeva】

narapatiḥ śiśupālaḥ（王シシュパーラが）kṣiprakārī（素早い者として）yad yad astram āviścakāra（次々と武器を繰り出すのを）prakupitaḥ rogaḥ vikāram iva（激昂した病が変調をもたらすように）。kramavit murāriḥ（手順を知るムラーリが）bhiṣak iva（医師のように）gurudoṣacchedinā upakrameṇa（重い病を断つ治療法で）tattad āśu pratyahan（その一つ一つを速やかに退けた）。upamā。韻律：Mālinī。

【Mallinātha】

iti（このように）kṣiprakārī narapatiḥ caidyaḥ（素早く行動する王チェーディが）prakupitaḥ rogaḥ vikāram iva（激昂した病が変調の如く）yad yad astram āviścakāra（次々と武器を顕わすのを）kramavit murāriḥ（手順を知るムラーリが）bhiṣak iva（医師のように）gurudoṣacchedinā upakrameṇa（重い病を断つ処方で）tattad āśu pratyahan（その一つ一つを速やかに打ち返した）。upamā。韻律：Mālinī。

V.77

【Vallabhadeva】

V.78

V.79

caidyasya vapuṣṭaḥ（チェーディ王の体から）dhāma tejaḥ（光輝が）nirīya（出て）aupendram vapuḥ（ウペーンドラ＝クリシュナの御体に）viśat（入った）。śriyā juṣṭam（吉祥に伴われ）divyaiḥ puṣpavarṣaiḥ sapaṭaharavaiḥ anvitam（天の花雨と太鼓に伴われ）ṛṣigaṇaiḥ stūyamānam（聖仙に讃えられ）ākāśe prakāśena dinakarakarān vikṣipat（空で輝きをもって太陽光を圧し）vismitākṣaiḥ narendraiḥ vīkṣām babhūve（驚く目の王たちに見守られた）。聖典「チェーディ王の体から輝き飛び立ち、クリシュナに入った」に基づく。bhāvika修辞。韻律：Meghavisphūrjitā。
