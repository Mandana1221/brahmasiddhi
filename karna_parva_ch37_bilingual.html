マハーバーラタ ― カルナ篇 第37章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 37 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ37」（カルナがシャルヤを嘲笑しつつ痛烈に罵る場面）です。カルナは、シャルヤの出自であるマドラ・バーリーカの人々を「正法を持たぬ者たち」として、バラモンたちの伝聞や故事を引きながら、その風俗・食習慣・婦女の振る舞いを次々と非難していきます。さらに、かつてシンドゥ河畔の地を旅したある婆羅門が語った見聞として、バーリーカの地で行われる乱れた酒宴や歌舞、節度を欠いた男女の交わりなどが具体的に列挙されます。なお本章は標準的なシュローカ調（2行詩節）で書かれており、第36章のトリシュトゥブ調から再び通常の韻律に戻っています。
karṇaparva — saptatriṃśo'dhyāyaḥ (37)
第37章
sañjaya uvāca|
tataḥ punar mahārāja madrarājam arindamaḥ|
abhyabhāṣata rādheyaḥ sannivāryottaraṃ vacaḥ|| // 8-37-1 //
サンジャヤは語った。 （1）そして、大王よ、ふたたび敵を討つカルナ（ラーデーヤ）は、返事を抑えつつマドラ王に語った。
nirbhartsanārthaṃ śalya tvaṃ yattu jalpitavānasi|
nāhaṃ śakyas tvayā vācā vibhīṣayitumāhave|| // 8-37-2 //
（2）「シャルヤよ、お前が私を脅すために語ったこと――お前の言葉で、私を戦場で怯ませることはできぬ。
yadi māṃ devatāḥ sarvā yodhayeyuḥ savāsavāḥ|
tathāpi me bhayaṃ na syāt kimu pārthāt sakeśavāt|| // 8-37-3 //
（3）たとえ、インドラと共にすべての神々が私と戦に挑もうとも、私には恐れがない。まして、ケーシャヴァを含むアルジュナに対して何を恐れよう。
nāhaṃ bhīṣayituṃ śakyaḥ śuddhakarṇā mahāhave|
abhijānīhi śaktas tvam anyaṃ bhīṣayituṃ raṇe|| // 8-37-4 //
（4）戦場では、純きった耳を持つ私を脅すことはできぬ。戦場で他の者を脅せるかもしれぬが、私はそうではない。
nīcasya balam etāvat pāruṣyaṃ yat tat tvam āttha mām|
aśakto hi guṇān vaktuṃ valgase bahu durmate|| // 8-37-5 //
（5）下等な者の力はここまでである。お前は荒い言葉を私に語るが、美徳を語ることはできぬ。ゆえに吠えるのだ、愚か者よ、多くを。
na hi karṇaḥ samudbhūto bhayārtham iha madraka|
vikramārtham ahaṃ jāto yaśorthaṃ ca tathā ātmanaḥ|| // 8-37-6 //
（6）ここでカルナは、恐れるためにこの世に生まれたのではない、マドラカ族よ。武勇のため、名誉のために、私は生まれたのだ。
sakhibhāvena sauhārdānmitatrabhāvena caiva hi|
kāraṇais tribhir etais tvaṃ śalya jīvasi sāmpratam|| // 8-37-7 //
（7）友情のゆえ、好意のゆえ、穏和さのゆえ――この三つの理由で、シャルヤよ、お前は今、生かされている。
rājñaś ca dhārtarāṣṭrasya kāryaṃ sumahadudyatam|
mayi tac ca āhitaṃ śalya tena jīvasi me kṣaṇam|| // 8-37-8 //
（8）ドリタラーシュトラの子（ドゥルヨーダナ）王の大仕事が始まる。その重要な任が私に託された、シャルヤよ。ゆえにお前を今生かしている。
kṛtaś ca samayaḥ pūrvaṃ kṣantavyaṃ vipriyaṃ tava|
'samayaḥ paripālyo me tena jīvasi sāmpratam'|| // 8-37-9 //
（9）そして、以前に約束したとおり、お前の不快な言葉を許そう。『約束を守らねばならぬ。ゆえに、お前は今生きているのだ』。
ṛte śalyasahasreṇa vijayeyamahaṃ parān|
mitradrohas tu pāpīyāniti jīvasi sāmpratam|| // 8-37-10 //
（10）シャルヤのような者が千人いても、敵に勝てるが、友への裏切りは罪深い。ゆえに、お前は今生きている。
śalya uvāca|
ārtapralāpāṃs tvaṃ karṇa yān bravīṣi parān prati|
na te karṇasahasreṇa śakyā jetuṃ pare yudhi|| // 8-37-11 //
シャルヤは語った。 （11）「お前が敵についてたわごとを語っているだけだ、カルナよ。カルナが千人いようと、戦場で敵に勝てぬ」。
sañjaya uvāca|
tathā bruvantaṃ paruṣaṃ karṇo madrādhipaṃ tadā|
paruṣaṃ dviguṇaṃ bhūyaḥ provācāpriyadarśanam|| // 8-37-12 //
サンジャヤは語った。 （12）このように厳しく語るマドラ王に、カルナはさらに倍の厳しさで、不愉快な言葉を語った。
idaṃ tvamekāgramanāḥ śṛṇu madrajanādhipa|
sannidhau dhṛtarāṣṭrasya procyamānaṃ mayā śrutam|| // 8-37-13 //
（13）「専心して聞け、マドラ国の主よ。ドリタラーシュトラのそばで、語られたのを私は聞いた。
deśāṃś ca vividhāṃś citrān pūrvavṛttāṃś ca pārthivān|
brāhmaṇāḥ kathayanti sma dhṛtarāṣṭraniveśane|| // 8-37-14 //
（14）さまざまな地域や王たちの昔の出来事について、バラモンたちがドリタラーシュトラの居室で語っていた。
tatra vṛddhaḥ purāvṛttāḥ kathāḥ kaścid dvijottamaḥ|
bāhlīkadeśaṃ madrāṃś ca kutsayan vākyam abravīt|| // 8-37-15 //
（15）そこで、長老の最も優れたあるバラモンが、古の物語を語りながら、バーフリーカ国とマドラ族をけなしてこう言った。
bahiṣkṛtā himavatā tāḥ gaṅgayā ca tiraskṛtāḥ|
sarasvatyā yamunayā kurukṣetreṇa cāpi ye|| // 8-37-16 //
（16）『ヒマラヤに阻まれ、ガンジス川に遮られ、サラスヴァティー川、ヤムナー川、クルクシェートラ――。
pañcānāṃ sindhuṣaṣṭhānāṃ nadīnāṃ ye'ntarāśritāḥ|
tāndharmabāhyānaśucīnbāhlīkānapi varjayet|| // 8-37-17 //
（17）五つの川、インダス川を六つ目として、これらの間に住む者たち、ダルマを外れた不浄な者たち、バーフリーカ族を避けよ。
govardhano nāma vaṭaḥ subhāṇḍaṃ nāma pattanam|
etad rājan kalidvāram ākumārāt smarāmy aham|| // 8-37-18 //
（18）ゴーヴァルダナという名のバンヤン樹、スバーンダという名の町――これが、大王よ、幼年のころから覚えている争乱の門である。
kāryeṇātyarthagūḍhena bāhlīkeṣūṣitaṃ mayā|
tata eṣāṃ samācāraḥ saṃvāsād vidito mayā|| // 8-37-19 //
（19）秘密の任務で、バーフリーカ国に私は住んだことがある。そこで彼らの行動を、共に住むことによって知った。
śākalaṃ nāma nagaram āpagānām animnagā|
caṇḍālā nāma bāhlīkās teṣāṃ vṛttaṃ suninditam|| // 8-37-20 //
（20）シャーカラという都があり、アーパガーという川は水量が乏しく、バーフリーカ族はチャンダーラ（賎民）と呼ばれ、その行いはひどく非難された。
pānaṃ guḍāsavaṃ pītvā gomāṃsaṃ laśunaiḥ saha|
apūpasaktumadyānām āśitāḥ śīlavarjitāḥ|| // 8-37-21 //
（21）グダ酒を飲み、ニンニクと一緒に牛肉を食べる。菓子と麦と酒を食らい、徳を失い――。
gāyantyatha ca nṛtyanti striyo mattā vivāsasaḥ|
nagarāpaṇaveśeṣu bahirmālyānulepanāḥ|| // 8-37-22 //
（22）女たちは酔って、裸で歌い踊る。都市の店や住居のそばで、花輪と香油を身に着けて――。
mattāḥ pragītavirutaiḥ kharoṣṭraninadopamaiḥ|
anāvṛtā maithune tāḥ kāmacārāś ca sarvaśaḥ|| // 8-37-23 //
（23）酔って、ロバやラクダのような声で歌い、性交でも恥を捨て、欲望のままに振る舞う。
āhuranyonyasūktāni prabruvāṇā madotkaxxxḥ|
hehatehehatetyevaṃ svāmibhartṛhate iti ca|| // 8-37-24 //
（24）酔って互いに語り合い、『ヘーヘタ、ヘーヘタ』と、『夫に打たれた、主に打たれた』――。
ākrośantyaḥ pranṛtyanti vrātyāḥ parvasvasaṃyatāḥ|
tāsāṃ kilāvaliptānāṃ nivasan kurujāṅgale|| // 8-37-25 //
（25）と叫びながら踊る。祭りの時、自分を抑えず、誓いを破って。そのような傲慢な彼女たちのもとに住んだあるバーフリーカの邪悪な者が、クル・ジャーンガラ国に住みながら――。
kaścidbāhlīkaduṣṭānāṃ nātihṛṣṭamanā jagau|
sā nūnaṃ bṛhatī gaurī sūkṣmakambalavāsinī|| // 8-37-26 //
（26）あまり満足せぬ気持ちで歌った――「彼女は、大柄で色白、細い毛織りの衣を着た、――。
mām anusmaratī śete bāhlīkaṃ kuruvāsinam|
śatadruṃ nu kadā tīrtvā tāṃ ca ramyām irāvatīm|
gatvā svadeśaṃ drakṣyāmi sthūlajaṅghāḥ śubhāḥ striyaḥ|| // 8-37-27 //
（27）私を思いながら寝ているだろう、クル国に住むバーフリーカの者を。いつシャタドルー川、美しきイラーヴァティー川を渡り、自分の国で、太い腿の美しい女たちを見られるだろうか。
manaḥśilojjvalāpāṅgyo gauryas tāḥ kākukūjitāḥ|
kambalājinasaṃvītā rudantyaḥ priyadarśanāḥ|| // 8-37-28 //
（28）赤い鉱物のような目尻の白い彼女ら、鳩鳴きのような声をもち、毛織物や鹿皮をまとい、愛しげに泣くさまで見せる――。
mṛdaṅgānakaśaṅkhānāṃ mardalānāṃ ca niḥsvanaiḥ|
kharoṣṭrāśvatarais caiva mattā yāsyāmahe sukham|| // 8-37-29 //
（29）太鼓、法螺貝、大鼓、マルダラ鼓の音と共に、ロバ・ラクダ・ラバに酔いしれて楽しく行くだろう。
śamīpīlukarīrāṇāṃ vaneṣu sukhavartmasu|
apūpān saktupiṇḍāṃś ca prāśnanto mathitānvitān|| // 8-37-30 //
（30）シャミー、ピールー、カリーラの森の快き道で、菓子と麦団子、練り粉を食べ――。
pathiṣu prabalo bhūtvā tathā sampatato'dhvagān|
celāpahāraṃ kurvāṇās tāḍayiṣyāma bhūyasaḥ|| // 8-37-31 //
（31）道で強者となり、旅人が来れば、服を奪って、さらに殴るだろう。
evaṃśīleṣu vrātyeṣu bāhlīkeṣu durātmasu|
kaścetayāno nivasen muhūrtam api mānavaḥ|| // 8-37-32 //
（32）このような振舞いの、誓いなき、邪悪なバーフリーカ族の中に、分別ある人間がどうして一瞬でも住めようか」』。
karṇa uvāca|
īdṛśā brāhmaṇenoktā bāhlīkā moghacāriṇaḥ|
yeṣāṃ ṣaḍbhāgahartā tvamubhayoḥ puṇyapāpayoḥ|| // 8-37-33 //
カルナは語った。 （33）「このようにバラモンが語ったのだ、バーフリーカ族を、無駄に歩き回る者たちと。その六分の一（税金）を、善行と悪行の両方にあずかる者として、お前は取っている（すなわち、お前はその国の王だ）。
ityuktvā brāhmaṇaḥ sādhuruttaraṃ punaruktavān|
bāhlīkeṣvavinīteṣu procyamānaṃ nibodha tat|| // 8-37-34 //
（34）そう語ったバラモンは、さらに答えを重ねた。規律のないバーフリーカ族について語ったことを聞け。
tatatra sma rākṣasī gāti kṛṣṇacaturdaśīm|
nagare śākale sphīte āhatya niśi dundubhim|| // 8-37-35 //
（35）そこに夜、鬼女が歌っているのを聞いた――黒い十四日目の夜に、栄える都市シャーカラで、太鼓を叩きながら――。
kathaṃ vas tādṛśo gāthāḥ punar gāsyāmi śākale|
gavyasya tṛptā māṃsasya pītvā gauḍaṃ surāsavam|| // 8-37-36 //
（36）「いつ再びこのような歌を、シャーカラで歌えるだろう――牛肉に満足し、グダ酒を飲み――。
gaurībhiḥ saha nārībhir bṛhatībhiḥ svalaṅkṛtā|
palāṇḍugaṇḍūṣayutāḥ khādantaśceśikānbahūn|| // 8-37-37 //
（37）大柄で色白の、よく飾られた女たちと、ネギ（タマネギ）を口いっぱいに入れ、多くの肉を食らいながら。
vārāhaṃ kaukkuṭaṃ māṃsaṃ gavyaṃ gārdabhamauṣṭrakam|
dhānāś ca ye na khādanti teṣāṃ janma nirarthakam|| // 8-37-38 //
（38）豚肉、鶏肉、牛肉、ロバ肉、ラクダ肉、穀物を食べない者の人生は無意味だ」。
evaṃ gāyanti ye mattāḥ śīdhunā pīlukāvane|
sabālavṛddhāḥ krandanti teṣāṃ dharmaḥ kathaṃ bhavet|| // 8-37-39 //
（39）こう、ピールーの森で、シードゥ酒に酔って歌う者たち、子どもや老人も叫ぶ――そのような者にどうして道（ダルマ）があるか。
yatra lokeśvaraḥ kṛṣṇo devadevo janārdanaḥ|
vismṛtaḥ puruṣair ugrais teṣāṃ dharmaḥ kathaṃ bhavet|| // 8-37-40 //
（40）世界の主クリシュナ、神々の神ジャナールダナが、凶暴な男たちに忘れ去られている場所に、どうして道があろうか。
iti śalya vijānīhi hanta bhūyo bravīmi te|
yad anyopy uktavān asmān brāhmaṇaḥ kurusaṃsadi|| // 8-37-41 //
（41）このように、シャルヤよ、知れ。さらに言うぞ、クル族の会議の場で、別のバラモンが我らに語ったことを――。
pañcanadyo vahantyetā yatra pīluvanāny uta|
śatadruś ca vipāśā ca tṛtīyairāvatī tathā|| // 8-37-42 //
（42）五つの川がピールーの森のあたりを流れる。シャタドゥル、ヴィパーシャー、第三のイラーヴァティー――。
candrabhāgā vitastā ca sindhuṣaṣṭhā mahānadī|
āraṭṭā nāma bahlīkā eteṣvāryo hi no vaset|| // 8-37-43 //
（43）チャンドラバーガー、ヴィタスター、そして六つ目の大川シンドゥ。アーラッタと呼ばれるバーフリーカ族の中には、アーリア（高貴な人）は住まぬだろう。
vrātyānāṃ dāsamīyānāṃ videhānām ayajvanām|
na devāḥ pratigṛhṇanti pitaro brāhmaṇās tathā|| // 8-37-44 //
（44）規律なき、奴隷のごとき、ヴェーダ学習を欠き、祭祀を行わぬ者たち――彼らから神々も祖先もバラモンも供物を受け取らぬ。
teṣāṃ pranaṣṭadharmāṇāṃ bāhlīkānām iti śrutiḥ|
brāhmaṇena yathā proktaṃ viduṣā sādhusaṃsadi|| // 8-37-45 //
（45）正しい道を失ったバーフリーカ族について、そう伝わっている。クル族の立派な会議の場で、賢いバラモンが語ったように。
kāṣṭhakuṇḍeṣu bāhlīkā mṛṇmayeṣu ca bhuñjate|
saktumadyāvalipteṣu śvāvalīḍheṣu nirghṛṇāḥ|| // 8-37-46 //
（46）木の桶や土の桶で、バーフリーカ族は食べる。麦酒や酒で汚れた、犬に舐められた桶で、恥じずに。
āvikaṃ cauṣṭrikaṃ caiva kṣīraṃ gārdabhameva ca|
tadvikārāṃś ca bāhlīkāḥ khādanti ca pibanti ca|| // 8-37-47 //
（47）羊・ラクダ・ロバの乳、それらの加工品を、バーフリーカ族は食し飲む。
pātrasaṅkariṇo jālmāḥ sarvānnakṣīrabhojanāḥ|
āraṭṭā nāma bāhlīkā varjanīyā vipaścitā|| // 8-37-48 //
（48）器を混ぜ合わせ、賎しく、すべての食と乳を食す、アーラッタ族と呼ばれるバーフリーカ族は、識ある者には避けられるべきだ。
iti śalya vijānīhi hanta bhūyo bravīmi te|
yad anyo'py uktavān mahyaṃ brāhmaṇaḥ kurusaṃsadi|| // 8-37-49 //
（49）このように、シャルヤよ、知れ。さらに別のバラモンがクル族の会議の場で語ったこと――。
yugandhare payaḥ pītvā proṣya ca api acyutasthale|
tadvad bhūtilaye snātvā kathaṃ svargaṃ gamiṣyati|| // 8-37-50 //
（50）ユガンダラで乳を飲み、アチュタスターラ（アチュタの土地）に滞在し、ブーティラヤで沐浴して、どうして天界へ行けようか。
pañcanadyo vahantyetā yatra niḥsṛtya parvatāt|
āraṭṭā nāma bāhlīkā na teṣvāryo dvyahaṃ vaset|| // 8-37-51 //
（51）山から流れ出る五つの川が流れる場所、アーラッタ族と呼ばれるバーフリーカ族の地には、アーリアは二日も住まない。
bāhlīkā nāma hīkaś ca vipāśāyāṃ piśācakau|
tayorapatyaṃ bāhlīkā naiṣā sṛṣṭiḥ prajāpateḥ|| // 8-37-52 //
（52）バーフリーカとヒーカは、ヴィパーシャーにおける二匹のピシャーチャ鬼であった。彼らの子孫がバーフリーカ族である。創造神プラジャーパティの創造物ではない。
te kathaṃ vividhān dharmāñ jñāsyante hīnayonayaḥ|| // 8-37-53 //
（53）血筋の低い彼らに、どうしてさまざまな道が理解できようか。
kāraskarān māhiṣakān karambhān kaṭakālikān|
karkarān vīrakān vīrā unmattāṃś ca vivarjayet|| // 8-37-54 //
（54）カーラスカラ族、マーヒシャカ族、カランバ族、カタカーリカ族、カルカラ族、ヴィーラカ族、勇者たちは、ウンマッタ（狂人のような者）を避ける。
iti tīrthānusañcārī rākṣasī kācid abravīt|
ekarātram uṣitvā iha maholūkhalamekhalā|| // 8-37-55 //
（55）このように、聖地巡りの鬼女が語った。ここに一夜泊まって、マホールーカラメーカラ（大杵の帯)――。
āraṭṭā nāma te deśā bāhlīkaṃ nāma tadvanam|
vasātisindhusauvīrā iti prāyo'tikutsitāḥ|| || // 8-37-56 //
（56）『アーラッタという地、バーフリーカという森、ヴァサーティ・シンドゥ・サウヴィーラ族はほとんど、きわめて非難すべきである』」。
iti śrīmanmahābhārate karṇaparvaṇi saptatriṃśo'dhyāyaḥ|| 37 ||
こうして、聖なる大マハーバーラタのカルナ篇の第三十七章は終わる。
