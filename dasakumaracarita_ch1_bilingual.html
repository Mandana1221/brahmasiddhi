王子たちの誕生
◆ Maṅgala-śloka 帰敬偈
◆ 帰敬偈
brahmāṇḍa-cchatradaṇḍaḥ śatadhṛti-bhavana-ambhoruho nāladaṇḍaḥ
kṣoṇī-nau-kūpadaṇḍaḥ kṣarad-amara-sarit-paṭṭikā-ketudaṇḍaḥ /
jyotiś-cakra-akṣadaṇḍas tribhuvana-vijaya-stambhadaṇḍo 'ṅghridaṇḍaḥ
śreyas traivikramas te vitaratu vibudha-dveṣiṇāṃ kāladaṇḍaḥ //
asti samasta-nagarī-nikaṣāyamāṇā śaśvad agaṇya-paṇya-vistārita-maṇigaṇādi-vastu-jāta-vyākhyāta-ratnākara-māhātmyā magadha-deśa-śekharī-bhūtā puṣpapurī nāma nagarī //
梵卵（ブラフマーンダ）の天蓋の柄であり、百祭者（ブラフマー）の住まいたる蓮の茎であり、大地という船の帆柱であり、流れゆく天河の幡（はた）の竿であり、星辰の輪の車軸であり、三界征服の勝利柱たる足の杖――かのトリヴィクラマ（ヴィシュヌ）の足が、汝らに永遠の至福を授けんことを。神々の敵（阿修羅）にとっては、それは死の杖なり。
あらゆる都市の試金石となり、つねに数え切れぬ商品として陳列された宝石その他の品々によって大洋の偉大さを証し、マガダ国の冠たるプシュパプリー（花の都）という名の都があった。
【注】 Kale注：冒頭偈の各複合語に繰り返される daṇḍa（杖）は、原作者ダンディン（Daṇḍin）の名に対する意識的な言葉遊び（conscious use of the word daṇḍa）である。著者はヴァイシュナヴァ派として帰敬偈でヴィシュヌ神に帰依を捧げつつ、ダンディンの名にも敬意を表している。トリヴィクラマ（trivikrama「三歩を踏みし者」）はヴィシュヌのヴァーマナ化身の名であり、三歩で三界を覆った神話に基づく（Ragh. VII. 35参照）。
nikaṣāyamāṇā（試金石として機能する）は nikaṣa（試金石）からの名動詞（denominative）の現在分詞女性形。Kaleによれば「あらゆる都市の完全な模範」の意。puṣpapurī は現代のパトナー（Pāṭaliputra）に同定される。
◆ Dkc 1,1.2 — 王ラージャハンサの描写
◆ 王ラージャハンサの描写
tatra vīra-bhaṭa-paṭala-uttaraṅga-turaṅga-kuñjara-makara-bhīṣaṇa-sakala-ripu-gaṇa-kaṭaka-jalanidhi-mathana-mandarāyamāṇa-samuddaṇḍa-bhuja-daṇḍaḥ, purandara-pura-aṅgaṇa-vana-viharaṇa-parāyaṇa-taruṇa-gaṇikā-gaṇa-jegīyamāna-yāti-mānayā śarad-indu-kunda-ghana-sāra-nīhāra-hāra-mṛṇāla-marāla-sura-gaja-nīra-kṣīra-giri-śāṭṭahāsa-kailāsa-kāśa-nīkāśa-mūrtyā racita-dig-antarāla-pūrtyā kīrtyā abhitaḥ surabhitaḥ svar-loka-śikhara-uru-rucira-ratna-ratnākara-velā-mekhalāyita-dharaṇī-ramaṇī-saubhāgya-bhoga-bhāgyavān, anavarata-yāga-dakṣiṇā-rakṣita-śiṣṭa-viśiṣṭa-vidyā-sambhāra-bhāsura-bhūsura-nikaraḥ, viracita-arāti-saṃtāpena pratāpena satata-tulita-viyan-madhya-haṃsaḥ, rājahaṃso nāma ghana-darpa-kandarpa-saundarya-sodarya-hṛdya-niravadya-rūpo bhūpo babhūva //
その都に、勇壮な戦士たちが波のように押し寄せ、馬や象がマカラのように恐ろしい敵軍の全軍という大洋を攪拌するマンダラ山のごとき、高く振り上げた力強い腕を有する王がいた。インドラの都の庭園で遊ぶ若き天女（ガニカー）たちに繰り返し讃えられる名声は、秋の月・クンダ花・樟脳・雪・真珠の首飾り・蓮茎・白鳥・アイラーヴァタ（帝釈天の象）・水・牛乳・ギリ山・シヴァ神の哄笑・カイラーサ山・カーシャ草のように白く輝き、全方位を満たしていた。メール山頂の美しき宝石に匹敵する宝を蔵する大洋を帯として戴く大地という妃の美と富を享受する幸運に恵まれ、絶え間なき祭祀の布施によって護られたヴェーダに通暁する優れた婆羅門の群を擁し、敵に苦悩を与える武威によってつねに中天の太陽に比肩する、ラージャハンサ（rājahaṃsa）という名の王がいた。その姿は、驕り高きカンダルパ（愛神カーマ）に匹敵する美しさを持ち、心惹きつけ、欠点なきものであった。
【注】 Kale注：敵軍を大洋に、王の腕をマンダラ山に喩える比喩は、神々と阿修羅による乳海攪拌の神話に基づく（Ragh. I. 19参照）。mandarāyamāṇa は mandara からの名動詞現在分詞で、先の nikaṣāyamāṇā と同形式。jegīyamāna は gai（歌う）の反復動詞（Frequentative）の現在分詞。haṃsa は通常「白鳥」の意であるが、ここでは「太陽」の意味で用いられており、直後の rājahaṃsa（王の名）との韻律的遊び（anuprāsa）のためである。同様に ghana-darpa（雲の誇り）も直後の kandarpa（カーマ神）との頭韻のために添えられたもので、特段の意味的必然性はない。
◆ Dkc 1,1.3 — 王妃ヴァスマティー
◆ 王妃ヴァスマティー
tasya vasumatī nāma sumatī līlāvatī-kula-śekhara-maṇī ramaṇī babhūva //
その王には、ヴァスマティーという名の、聡明にして優美な女性の一族の至宝たる、美しき妃がいた。
【注】 Kale注：sumatī（聡明な）は本来 sumatiḥ とすべきであるが、頭韻のために sumatī の形が用いられている。vasumatī は「大地」の意味も持ち、後続の段落で大地との二重の意味が展開される。
◆ Dkc 1,1.4 — ヴァスマティーの美の描写
◆ ヴァスマティーの美の描写
roṣa-rūkṣeṇa niṭilākṣeṇa bhasmīkṛta-cetane makara-ketane tadā bhayena anavadyā vanitā iti matvā tasya rolambāvalī keśajālam, premākaraḥ rajanīkaraḥ vijita-aravinda-vadanam, jaya-dhvajāyamānaḥ mīnaḥ jāyā-yutaḥ akṣi-yugalam, sakala-sainika-aṅga-vīraḥ malaya-samīraḥ niḥśvāsaḥ, pathika-hṛd-dalana-karavālaḥ pravālaś ca adhara-bimbam, jaya-śaṅkhaḥ bandhurā lāvaṇya-dharā kandharā, pūrṇa-kumbhau cakravāka-anukārau payodharau; jyāyamāne mārdava-asamāne bilasate ca bāhū, iṣad utphulla-līlā-avataṃsaka-hlāra-korakau gaṅgā-āvarta-sanābhir nābhiḥ, dūrīkṛta-yogi-manorathaḥ jaitra-rathaḥ ati-ghanaṃ jaghanam, jaya-stambha-bhūte saundarya-bhūte vighnita-yati-jana-ārambhe rambhe ca uru-yugam, ātapatra-sahasra-patraṃ pāda-dvayam astra-bhūtāni prasūnāni tāni itarāṇi aṅgāni ca samabhūvann iva //
怒りに険しいシヴァ神の額の眼によってカーマ神（マカラの旗を持つ者）の意識が灰にされた時、その眷属たちは「この非の打ちどころなき美女こそ我らの安全な拠り所である」と恐れより考え、彼女のさまざまな肢体となったかのようであった。すなわち――カーマの弓弦たる黒蜂の列は彼女の黒髪となり、愛の源泉たる月は蓮をも凌ぐ彼女の顔となり、勝利の旗として機能するミーナ（魚）はその伴侶とともに彼女の両目となり、全軍の主力たるマラヤ山の微風は彼女の吐息となり、旅人の心を切り裂く刀たるプラヴァーラ（新芽）は彼女のビンバのように赤い下唇となり、勝利の法螺貝は彼女の優美にして色香あふれる首となり、カーマの満壺は一対のチャクラヴァーカ鳥に似た彼女の両乳房となり、弓弦たる比類なき柔らかさの蓮茎は彼女の両腕となり、戯れの耳飾りたるわずかに開いた蓮の蕾はガンガーの渦巻きに似た彼女の臍となり、苦行者の願望をも挫く凱旋車は彼女の豊満な臀部となり、美の極致にして苦行者の修行を妨げる勝利柱たるバナナの木は彼女の両腿となり、千弁の蓮の日傘は彼女の両足となり、武器たる花々は彼女のその他の肢体となったかのようであった。
【注】 Kale注：カーマ神がシヴァに焼かれた後、その眷属（弓弦＝黒蜂の列、旗＝魚、法螺貝、花の矢など）が身の安全を求めて「非の打ちどころなき美女」の肢体に宿ったという趣向。anavadyā は「称賛すべき、非の打ちどころなき」の意であると同時に「攻撃し得ない」（aghrṣyā）をも含意し、それゆえカーマの眷属が彼女を安全な避難所と見なした（Kum. III. 72参照）。jyāyamāne は jyā（弓弦）からの名動詞現在分詞で「弓弦のように機能する」の意。後段 pp. 43-45 のアヴァンティスンダリーの描写にほぼ同一の趣向と表現が再現される。
◆ Dkc 1,1.5
◆ 王とヴァスマティー
vijita-amara-pure puṣpapure nivasatā sa-ananta-bhoga-lālitā vasumatī vasumatīva magadha-rājena yathā-sukham anvabhāvi //
天界の都をも凌ぐプシュパプラ（花の都）に住まう王は、アナンタ（蛇王シェーシャ）の多くの蛇頭で支えられた大地（vasumatī）のように、ヴァスマティーを限りなき享楽で愛で、思いのままに楽しんだ。
【注】 Kale注：vasumatī vasumatīva（ヴァスマティーは大地のように）は śleṣa（二重語義）。ananta-bhoga は(1)「無限の享楽」（王妃に対して）、(2)「アナンタ＝シェーシャ蛇の蛇身」（大地に対して）の両義。anvabhāvi は bhū＋anu の受動態アオリスト三人称単数で、著者はこの種の受動態を好んで用いる（abhāṇi, samabodhi, agāmi, avāci など）。
◆ Dkc 1,1.6–7 — 三大臣とその子たち
◆ 三大臣とその子たち
tasya rājñaḥ parama-vidheyāḥ dharmapāla-padmodbhava-sitavarma-nāmadheyāḥ dhīra-dhiṣaṇā-vadhīrita-vibudha-ācārya-vicārya-kārya-sāhityāḥ kulāmātyās trayo 'bhūvan //
teṣāṃ sitavarmaṇaḥ sumatī-satyavarmāṇau, dharmapālasya sumantra-sumitra-kāmapālāḥ padmodbhavasya suśruta-ratnodbhavāv iti tanayāḥ samabhūvan //
その王にはこの上なく従順で、堅固なる知力をもってブリハスパティ（神々の師）でさえ熟慮を要する政務をも容易に処理する、ダルマパーラ・パドモードバヴァ・シタヴァルマンという名の世襲の三大臣がいた。
そのうちシタヴァルマンにはスマティーとサティヤヴァルマンの二子、ダルマパーラにはスマントラ・スミトラ・カーマパーラの三子、パドモードバヴァにはスシュルタとラトノードバヴァの二子があった。
【注】 Kale注：三大臣の七人の息子がそれぞれ一人ずつ子を持ち、これが物語の題名「十王子」のうちの七人を構成する。vidheyāḥ（従順な）は「王の富と繁栄に資する形でつねにその意に沿って行動する」の意（Kir. I. 5参照）。
◆ Dkc 1,1.8–11 — 大臣の息子たちのそれぞれの道
◆ 大臣の息子たちのそれぞれの道
teṣu dharmaśīlaḥ satyavarmā saṃsārāsāratāṃ buddhvā tīrthayātrābhilāṣī deśāntaram agamat //
viṭa-naṭa-vāranārī-parāyaṇo durvinītaḥ kāmapālo janaka-agrajanmanoḥ śāsanam atikramya bhuvaṃ babhrāma //
ratnodbhavo 'pi vāṇijya-nipuṇatayā pārāvāra-taraṇam akarot //
itare mantrisūnavaḥ purandara-pura-atithiṣu pitṛṣu yathāpūrvam anvatiṣṭhan //
そのうち、敬虔なるサティヤヴァルマンは世俗の空しさを悟り、聖地巡礼を志して異国へ旅立った。
放蕩者・俳優・遊女に耽溺するカーマパーラは、行儀の悪い者であり、父と兄の諫めを顧みず大地をさすらった。
ラトノードバヴァもまた、商業に巧みであったので海を渡った。
残りの大臣の息子たちは、父たちがインドラの都の客となった（＝死去した）のち、従前のとおり職務を継いだ。
【注】 Kale注：viṭa は語源的には「遊女と風流人の間の使いを伝える者」（veśyānāgarikayoḥ parasparaṃ sandeśaṃ viṭati kathayati iti viṭaḥ）であり、サンスクリット劇では王子や放蕩者の伴侶として登場する。pārāvāra（海）は pāram āvṛṇoti itir（彼方を覆うもの）に由来する。purandarapurātithiṣu（インドラの都の客となった）は「死去した」の婉曲表現。古代インドの商人が海上交易を広く行っていたことも示唆される（Śāk. VI参照）。
◆ Dkc 1,1.12 — マーラヴァ王への出征
◆ マーラヴァ王マーナサーラへの出征
tataḥ kadācin nānā-vidha-mahad-āyudha-naipuṇya-racita-agaṇya-janya-rājanya-mauli-pālinihi taniśita-sāyako magadha-nāthakaḥ mālava-īśvaraṃ prati agra-saṅgrāma-ghasmaraṃ samutkaṭa-mānasāraṃ mānasāraṃ prati sahela-nyakkṛta-jaladhi-nirghoṣa-ahaṅkāreṇa bherī-jhaṅkāreṇa haṭhikā-karṇana-ākrānta-bhaya-caṇḍimānaṃ dig-dantāvala-valayaṃ vighūrṇan nija-bhara-naman-medinī-bhareṇa ākrānta-bhujaga-rāja-mastaka-balena caturaṅga-balena saṃyutaḥ saṅgrāma-abhilāṣeṇa roṣeṇa mahatā āviṣṭo niryayau //
さてある時、多種の偉大なる武器に精通し、数え切れぬ戦場で諸王子の冠列にその鋭き矢を放ってきたマガダの王は、戦闘のたびに猛威を振るい、驕りと力が頂点に達していたマーラヴァの王マーナサーラに対して、大洋の轟きの誇りをたやすく打ち砕く太鼓の響きにより、猛烈な音の衝撃に怯えた方位の守護象たちをよろめかせ、自らの重みで大地をたわませることでシェーシャ蛇王の頭を圧する四軍（象・馬・戦車・歩兵）を伴い、戦いへの渇望と大いなる怒りに駆り立てられて出征した。
【注】 Kale注：mahad-āyudha（偉大な武器）は文法的には mahā-āyudha とすべき不正な複合語（faulty compound）である。Bühler は mahad-āni āyudhāni（「偉大さを与える武器」の意）として擁護するが、著者は mahad-āśā (p. 30)、mahad-āśvaryānvita (p. 53) など同種の形をしばしば用いており、文法規則への無関心がうかがえる。ghasmara は ghas（食う）＋mara で「大食い」から転じて「戦で常習的に猛威を振るう者」。caturaṅga-bala（四軍）は象・馬・戦車・歩兵の四要素からなる（Amara参照）。
◆ Dkc 1,1.13
◆ マーラヴァ王の進軍
mālava-nātho 'py aneka-aneka-yūthapa-sanāthaḥ vigrahaḥ savigraha iva sāgrahaḥ abhimukhībhūya bhūyo nirjagāma //
マーラヴァの王もまた、数多くの象群の長に護衛され、戦の化身のごとく、固き決意をもって迎え撃たんと出撃した。
【注】 Kale注：savigrahaḥ は「肉体を持つ者」すなわち「戦争の具現」の意。sāgrahaḥ は「確固たる決意を持つ」。bhūyaḥ（再び）は頭韻のためだけに添えられ、実質的な意味はない。
◆ Dkc 1,1.14 — 大戦
◆ 大戦
tayor atha ratha-turaga-khura-kṣuṇṇa-kṣoṇī-samudbhūte kari-ghaṭā-kaṭa-sravat-mada-dhārā-dhauta-mūle navya-vallabha-varaṇa-āgata-divya-kanyā-jana-javanikā-paṭa-maṇḍapa iva viyat-tala-vyākule dhūlī-paṭale diviṣat-dhvani-dhikkṛta-anya-dhvani-paṭaha-dhvāna-badhirita-aśeṣa-dig-antarālaṃ śastra-aśastri hasta-ahasti paraspara-abhihata-sainyaṃ janyam ajani //
かくして両者の間に大戦が起こった。戦車と馬の蹄に蹴り上げられた大地から立ち上る砂塵は空一面に広がり、象の群れのこめかみから流れる発情液がその根元を洗い流し、新たな恋人を選ばんと集まった天女たちのための幔幕の天蓋のようであった。天鼓の響きが他のあらゆる音を圧して全方位を聾せしめ、武器を持つ者と武器なき者、象に乗る者と象なき者が互いに打ち合い、軍勢は両軍ともに斃された。
【注】 Kale注：砂塵が天女（アプサラス）の幔幕のようだという比喩は、戦場で斃れた勇士を天女が夫として選ぶという信仰に基づく（svayaṃvara の趣向）。mada-dhārā-dhauta-mūle（発情液が根元を洗う）という表現は Mudr. V. 23, Ragh. VII. 43 にも類例がある。
◆ Dkc 1,1.15 — 寛大なる勝利
◆ 寛大なる勝利
tatra magadha-rājaḥ prakṣīṇa-sakala-sainya-maṇḍalaṃ mālava-rājaṃ jīvagrāham abhigṛhya kṛpālutayā punar api svarājye pratiṣṭhāpayām āsa //
その戦でマガダ王は、全軍を失ったマーラヴァ王を生け捕りにしたが、慈悲のゆえにふたたび彼を自領に復位させた。
