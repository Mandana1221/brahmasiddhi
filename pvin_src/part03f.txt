# III.2.1.3 | 「存在」は論証因になるが所証にはならない | sattā, k.58–62
G 仏教徒は「存在するから無常である」と、「存在（sattva, sattā）」を論証因（理由）に使う。ではなぜ、サーンキヤの根本原質（pradhāna）などについて「存在する」ことを所証として証明することはできないのか。ダルマキールティは、所証としての「存在」と理由としての「存在」とでは事情が違うことを示し、さらに「存在」を証明しようとする理由はどれも、不成・不定・矛盾のいずれかの過失に陥ると論じる。この節全体が『プラマーナ・ヴァールッティカ』自己注（PVSV）第1章 93–96頁（PV I 187–191）とほぼ並行する。
L 263
J 以上で次のことが確定した――自性の非知覚（svabhāvānupalabdhi）は自性因（svabhāvahetu）に含まれるので、それ（自性因）の実例によってすでに例示されている、と。そしてそれ（自性因）は、限定要素（upādhi）の違いを考慮したものであれ、単独のものであれ、「作られたものであること（kṛtakatva）」や「存在すること（sattva）」のように、消滅（を証明する場合）に示される、とすでに述べた。
N 前節（その5）の非知覚因の議論をまとめ、自性因の話に戻る。「作られたものであること」は「原因に依存する」という限定を含んだ存在であり、「存在すること」は限定のない単独の存在である。どちらも「無常（消滅すること）」を証明する自性因の代表例である。第2章（PVin 2, 52cd）および PV I 186 を受ける。

## III.2.1.3.i | 反論――理由にできるなら所証にもできるはずだ | k.58
L 264
J そこで（反論がある）。
V 265-266
J （反論）もし理由が「存在」を本質とするものであるなら、どうして「存在」が（所証として）証明されないのか。なぜなら、特殊なもの（bheda）には随伴（anvaya）がないということは、理由と所証との両方にとって（等しく）致命的だからである。（第58偈）
N 反論者は、仏教徒が根本原質などの存在証明を「随伴がない」として退けるのを逆手に取る。もし特殊な「存在」に随伴がないことが所証にとって致命的なら、理由としての「存在」にも同じことが言えるはずだ、というのである。随伴とは「理由があるところには所証がある」という肯定的な関係のこと。PV I 187 と並行。
L 267:1-4
J （反論）もし「存在」が、無常性や他のもの（を証明すること）について理由であるとしたら、（それを）所証としてもどうして認めないのか。（あなた方によれば）それはこのように証明されるとき、特殊化されたものになるのだそうだ。そして特殊なものは、随伴がないので証明することができない。（ディグナーガが）「認識手段の対象が知られないから」と言っているとおりである。
N 仏教徒の言い分を反論者が要約している。根本原質について「存在する」と証明しようとすると、その「存在」は「根本原質の存在」という特殊なものになり、そういう特殊な存在が見られる喩例はどこにもない（随伴がない）ので、証明は成り立たない。引用はディグナーガ『プラマーナ・サムッチャヤ』（PS）III 44c。
L 267:5-6
J （反論）この特殊（という過失）は、所証においてだけ妨げとなるのではない。そうではなく、理由においても（妨げとなる）。過失が等しいからである。なぜなら、随伴のない理由は証明の手段とならないからである。それ（随伴のない理由）からは疑いが生じるからである。
N 理由として使われる「存在」も、主題（例えば音声）に属する特殊な存在であるなら、やはり喩例に随伴しないはずだ、というのが反論の要点である。

## III.2.1.3.ii.a | 所証としての「存在」は特殊でなければならず、特殊なら随伴がない | k.59–60
L 268
J （答え）これは過失ではない。なぜなら――
V 269-270
J しかし、一般的な主題（dharmin）について、ただ存在を取り上げることだけが所証であるなら、いかなる事物も証明されたことにはならないであろう。また、そのようなもの（一般的な存在）は（誰によっても）否定されていない。（第59偈）
N 「何かが存在する」とだけ証明しても、何の主張にもならない。仏教徒もそれを否定してはいないからである。論争の的になるのは、「永遠で唯一の根本原質が存在する」といった特定の内容をもつ存在である。PV I 188 と並行。
L 271:1-2
J 存在を証明しても、特殊なものは決して証明されない。「ただ存在によってだけ限定された何らかの事物、すなわち主題がある」と証明する者に対しては、自性の特殊が示されていない何ものかのただの存在については矛盾がないので、ここで存在の証明が否定されるのではない。そうではなく、「そのように何かがある」と、そのものの何の区別にも触れずに語る者は、どんな自分の目的を満たすのであろうか。
L 271:3
J それゆえ、この者（存在を証明しようとする者）にとっては、区別を取り上げたもの（特殊化されたもの）こそが所証である。
N 仏教徒が反対しているのは「存在の証明」一般ではない。「何かがある」とだけ言うなら誰も否定しないが、それではサーンキヤ学派の目的は果たせない。だから彼らが証明したいのは、必ず特殊化された存在なのである。
V 272-273
J （ところが）区別を取り上げたものが所証であるならば、このとき理由は随伴をもたないことになろう。それゆえ、存在が所証であるときには、（実際に証明されるのは）特殊なもの（ということになる）であろう。（第60偈）
N 第59偈と第60偈とで両刀論法になっている。一般的な存在を証明するなら無意味であり、特殊な存在を証明するなら随伴がない。PV I 189 と並行。
L 274:1-3
J なぜなら、その主題が、根本原質（pradhāna）という特徴をもつもの、唯一のもの、常住なもの、楽などを本質とするもの、あるいはそれ以外のものとして、どのようにであれ特殊化されているなら、そういう本質をもつもの（の存在）が証明されることになる。そしてそれは、そのようには随伴しない。また、ただの存在は随伴するけれども、それが証明されても何にもならない。
N サーンキヤ学派の根本原質は、唯一・常住で、楽・苦・迷妄（サットヴァ・ラジャス・タマスの三要素）を本質とするとされる。こうした性質を帯びた存在は他のどこにも見られないので、喩例に随伴しない。PVSV 94,11–22 と並行。

## III.2.1.3.ii.b | 「火」を所証とする場合とは違う | ayogavyavaccheda
L 275:1-3
J （反論）しかし、そうだとすると、火などについても同じ過失になる。なぜなら、そこでも火の存在については何の争いもない。しかし、特定の場所を限定要素とする、意図された（火）は、随伴がないので成立しない（ことになる）。
N 「あの山に火がある、煙があるから」という典型的な推論でも、証明したいのは「あの山の火」という特殊な火であり、それは台所などの喩例には見られない。だから同じ論法で、煙からの火の推論も成り立たなくなるのではないか、という反論である。
L 275:4-5
J （答え）決してその場所がそれ（火）を特殊化するのではない。（場所は）非結合の排除（ayogavyavaccheda）によって限定するからである、とすでに述べた。それゆえそこ（火の推論）では、一般（としての火）だけが、それ（場所）との非結合を排除するという仕方で証明されるのである。
N 「山に火がある」という命題で、山は火の種類を変えるのではない。「山に火が無いのではない」、つまり山と火との非結合を排除するだけである。限定辞の三用法（非結合の排除・他との結合の排除・絶対的非結合の排除）については第2章（PVin 2, 50,7）で論じられた。したがって証明されるのは火一般であり、随伴の問題は生じない。
L 276:1-2
J ここ（根本原質の存在証明）では、そのように、どこかにおいて存在を証明するということはない。根本原質などの語によって表示されるような事物は何も存在しないので、それ（存在）は限定要素をもたないものにほかならないからである。
N 火の場合は、山という実在する場所に火一般を結びつければよい。ところが根本原質の場合は、存在を結びつけるべき実在の場所（主題）そのものがない。だから「どこかに存在を結びつける」という形をとることができない。
L 276:3-5
J （反論）どうして（根本原質などが）無いのか。それもまた、知られうるもの（jñeya）・言い表されうるもの（abhidheya）・認識されうるもの（prameya）であることによって、成立しているではないか。

（答え）それでは今度は、「知られうるものがある」という証明があればよい（ことになる）。それでも、何が証明されたことになろうか。
N 「根本原質」という語で考えられ、語られているのだから、知られうるものとして成立している、という反論。答えは、それなら「何か知られうるものがある」と証明しても同じことで、根本原質に固有な何ものも証明されない、というもの。
L 276:6-8
J （反論）言葉の対象（śabdārtha）とは、知に属する分別の現れ（vikalpapratibhāsa）ではないか。そして、それが個別相（svalakṣaṇa、実在する個物）を基体（upādāna）としていることが証明されるのである。

（答え）証明されればよい。しかし、それもまた、根本原質などという特徴をもつ区別の拠り所とはならず、ただの言葉の対象というあり方にとどまる。そしてそうであれば、前と同じように、「何か言い表されうるものがある」ということが所証となるであろう。
N 反論者は仏教の言語論を逆用する。仏教では語の対象は概念的な表象（分別の現れ）であり、それ自体は実在ではない。そこで「根本原質という表象には実在の基盤がある」ことを証明するのだ、と言う。しかし、その表象そのものは根本原質の特徴を何も担っていないので、結局「何か言い表されるものがある」という空疎な証明に戻ってしまう。
L 276:9-12
J なぜなら、言葉の対象は、それ自体としては何の特殊な性質も帯びないからである。基体であるという性質は、それらに比喩的に付与されるのである。それは、基体が成立していないもの（言葉の対象）については、ありえない。それゆえ、これら（根本原質などの言葉の対象）は限定要素をもたない。
L 276:13-14
J それらについて事物を基体とすることを証明するのは、事物のただの存在を証明することにほかならず、特殊な事物を証明することではない。だから無意味である。しかし他の場合（火の推論）には、まさにその火一般が、そこ（その場所）では成立していないので、証明されるのである。
N 火の推論では、「火一般があの場所に結びついている」ことがまだ知られていないので、証明に意味がある。根本原質の場合には、意味のある証明対象が残らない。PVSV 94,22–95,10 と並行。

### III.2.1.3.ii.b.3 | 煙は火一般と随伴する | agnisāmānya, PS II 11
L 277:1-2
J （反論）しかしここ（火の推論）でも、それ（特定の場所）との結合を欠いた一般とは、随伴は成立していないではないか。

（答え）決して誰も、そのようなあり方で随伴を立てるのではない。
L 277:3-4
J なぜなら、他人に説明する者は、煙が火と不可離であること（agninā antarīyaka）を示さなければならない――「煙のあるところには火がある」と。それ（煙）は、そのようにただの火によって遍充されていることが成立している――それ自身が見られるまさにそのところで、火の知を生じさせるのである。
L 277:5-7
J そこでは所証を（主張として）述べても何にもならない。そこでは、（煙が）見られることと（火との）関係とを告げるだけで、望むものが成立するからである。あるいは、それ（所証）が述べられなかったとしたら、どうしてそれによって限定されたものとの随伴がありえようか。だから、この（煙）は火なしにはありえないものとして成立しているのである。
N 喩例で示されるのは「煙のあるところには火がある」という一般的な関係（遍充）であって、「山の火」との関係ではない。主張（所証の言明）を立てなくても、煙が見られ、それと火との関係が示されれば、山の火は自然に知られる。
L 277:8-9
J それ（煙）は、おのずから（arthād）、その場所と火との非結合を排除するので、それ（火）はそのような仕方で所証であると言われるのである。しかし、そのように（場所に限定された所証の）提示を前提とした随伴があるのではない。ここでは所証の言明は（論証の）支分ではないからである。
L 277:10-11
J あるいは、それ（所証の言明）を前提とする（随伴がある）としたら、誰が主張（pratijñā）を論証（の支分）から除くであろうか。そこで（ディグナーガは）次のように言った――
N ダルマキールティは、ニヤーヤ学派の五支作法とは違い、主張（pratijñā）を論証式の支分に数えない。随伴が主張の提示を前提とするなら主張は論証に不可欠になってしまうが、実際にはそうではない、という論法。
V 278-279
J しかし、徴表（liṅga）が属性（所証）から逸脱しないことは、他の場所（喩例）において見られる。（その徴表は）そこ（主題）において、それ（属性）と結びついた、よく知られた主題を知らせるであろう。
N ディグナーガ PS II 11 の引用。逸脱しない関係（遍充）は喩例で確かめられ、主題に適用されるのは、その関係をもつ徴表がそこにあるという事実だけである、という趣旨。
L 280
J と。それゆえ、火などの証明の場合とは違って、存在の証明は過失のないものではないのである。

## III.2.1.3.ii.c | 論証因としての「存在」には随伴の問題がない | k.61
V 281-282
J しかし、その区別に触れないただの実在（vastu）が論証因であるときには、そのただ（の実在）を遍充する所証の随伴は損なわれない。（第61偈）
N ここから反論への本来の答えになる。理由としての「存在」は、主題の特殊な存在としてではなく、ただの実在として扱えばよく、そのただの実在が無常性によって遍充されていればよい。PV I 190 と並行。
L 283:1-3
J 他方、存在が論証因であるときには、自性の特殊を取り上げずに、所証の属性がただの実在を遍充しているので、随伴は損なわれない。なぜならそこ（論証因の場合）では、必ずしも特殊を取り上げる必要はない。ただの存在を拠り所としていても、論証因には（所証を知らせる）能力があるからである。所証である場合にはそうではない。（ただの存在を証明しても）無益だからである。
N 理由と所証とは非対称である。理由は「ただの存在」で十分に役目を果たすが、所証は「ただの存在」では証明する意味がない（第59偈）。だから反論者の言う「過失が等しい」は成り立たない。PVSV 95,13–16 と並行。

## III.2.1.3.ii.d | 存在を証明する正しい理由はない | k.62
L 284
J さらにまた――
V 285-286
J （存在が）成立していないものには、実在の属性（bhāvadharma）はない。両方（実在と非実在）を拠り所とする（属性）は逸脱するものである。非実在の属性は矛盾するものである。（そうであれば）その存在がどうして証明されようか。（第62偈）
N 根本原質などの存在を証明しようとするときに使える理由は、(1) 実在の属性、(2) 実在と非実在の両方の属性、(3) 非実在の属性、の三通りしかない。それぞれが不成・不定・矛盾という似因（hetvābhāsa）になる、と順に論じる。PV I 191 と並行。
L 287
J なぜなら、存在が所証であるとき、そのための理由はどれも、三種の過失――すなわち不成（asiddhi）、逸脱（vyabhicāra、不定）、矛盾（virodha）――を超えることがないからである。

### III.2.1.3.ii.d.1 | 実在の属性は不成 | asiddha
L 288:1-2
J そのうち、もし実在の属性が理由として述べられるなら、それは、存在が成立していないもの（主題）にどうしてありえようか。なぜなら、実在の属性を理由として望む者が、どうして実在を望まないことがあろうか。
L 288:3-4
J なぜなら、自性そのものが、何らかの観点から「属性」として、あたかも属性の持ち主（dharmin）から区別されたもののように示されるのだからである。なぜなら、属性を表す語と属性の持ち主を表す語とで、表示されるものに何の違いもない――このことは『プラマーナ・ヴァールッティカ』で詳しく論じ尽くした。
N 実在の属性を理由に挙げることは、主題がすでに実在であると認めることと同じである。属性とその持ち主は実は同じ一つの実在を別の観点から呼んだものにすぎないからである。したがって、存在が問題になっている主題に実在の属性を理由として立てると、理由が主題に成立しない（不成）か、所証を先取りすることになる。

### III.2.1.3.ii.d.2 | 実在と非実在の両方の属性は不定 | ubhayadharma
L 289:1
J また、もし（反論者が）両方（実在と非実在）の属性を（理由として）述べるとしよう。（その場合の理由は）実在に依存しない、定立的でない否定（paryudāsa でない否定）によるただの排除なので、非存在においても矛盾がないからである。例えば、「有形のもの（mūrta）の中にはない」という（意味での）無形性（amūrtatva）は、何とも言い表せないもの（nirupākhya、非存在）にもありうるであろう。
N 否定には、別のものを肯定的に立てる否定（paryudāsa、「非バラモン」＝バラモン以外の人）と、単に打ち消すだけの否定（prasajyapratiṣedha）とがある。「無形である」を単なる打ち消しと取れば、実在でないもの（例えば兎の角）にも当てはまる。だからこの種の理由は、実在と非実在の両方に属する。
L 289:2-3
J （反論）何とも言い表せないものは非存在なので、否定の対象ではない、と言うなら――

（答え）それなら今度は、肯定の対象であるとせよ。それもそうではない、と言うなら、どうして今度は否定の対象でないことがあろうか。否定は肯定の止滅を本質とするからである。
L 289:4
J （反論）否定がはたらくのは数え上げられたもの（実在）についてだけだと認められる。だから、言い表せないものには無形性などはない、と言うなら――

（答え）ああ、この哀れな人は、取り決め（saṅketa）によるもの、すなわちただ（人々の）意欲に従うだけの意味を規制しようとして、苦しんで生きている。彼が胸を打って泣き叫んでも、世間（の言葉づかい）はやまないからである。
N 「非存在には否定語を適用できない」という反論者の規則は、恣意的な言語規範の押しつけにすぎない。言葉の意味は取り決めに従うものであり、世間の人は「兎の角は無形だ」と平気で言う。ダルマキールティらしい皮肉である。
L 289:5-8
J なぜなら、理解は取り決めのとおりに生じるからであり、言葉の使用はただそれ（理解させること）だけを目的とするからである。（実在と非実在とで）意図されるものに違いがないので、（一方に否定語が使えないとすれば）両方の場合に理解がないことになってしまうからである。それ（非存在についての言葉）からも理解が生じるからである。それは他の場合（実在についての言葉）にも等しいからである。
N 簡潔な理由句が並び、解釈には幅がある。要するに、非存在についての否定表現からも人々は現に理解を得ており、その点は実在についての表現と変わらないので、否定語を実在に限る理由はない、ということであろう。
L 289:9
J それゆえ、両者（実在と非実在）のいずれにもありうるこのただの排除が、どうして、ありうる異類（vipakṣa）への出現の疑いを排除することによって得られる「知らせる力（gamakatva）」を、自分のものにできようか。
N 正しい理由は、異類（所証のないところ）には決して現れないという保証によって、所証を知らせる力をもつ。存在を証明する場合、異類は非存在である。非存在にも現れうる理由は、まさにこの保証を欠くので、不定となる。PVSV 96,10–13 と並行。
L 290
J 排除を本質としない、知られうるものであること（jñeyatva）などの属性もまた、非実在さえも何らかの仕方で知によって設定されるので、（実在と非実在とに）共通のものである。それらもまた、これによって説明された。
N 「知られうるもの」「言い表されうるもの」といった肯定的な属性も、兎の角のような非実在がとにかく思い浮かべられる以上、実在と非実在の両方に属する。したがってやはり不定の理由である。

#### III.2.1.3.ii.d.2.3 | 両方の属性は逸脱する――主題を逸脱の判定から外すことはできない | pakṣasapakṣānyataratva
L 291:1
J そして、その者は、自分の言葉で（理由が）両方の属性であると語りながら、それが存在するもの以外にも生じると言い、しかも存在から逸脱しないと言う。どうして狂人でないことがあろうか。
L 291:2-4
J （反論）逸脱とは異類に生じることによるものである。したがって、「主題か同類かのいずれかであること（pakṣasapakṣānyataratva）」などは、異類に生じないので、両方の属性であっても過失はない。なぜなら、主題そのものは逸脱の領域ではないからである。
N 当時の論理学者（ニヤーヤ系か）が用いた「主題か同類のいずれかであるから」という人工的な理由を持ち出す反論である。この理由は定義上、主題と同類にしか現れないので、異類には現れない。主題の中に所証のないものが含まれていても、主題は逸脱の判定から外す、というのが反論者の言い分。
L 291:5-7
J （答え）では、あなたはここで何を異類と理解するのか。

（反論）所証の無いもの（sādhyābhāva）である。

（答え）それなら、どうして理由が、異類に生じないものであり、かつ両方の属性でありえようか。
N 存在を証明する場合、所証の無いもの、すなわち非存在が異類である。両方の属性は非存在にも生じるのだから、異類に生じないとは言えない。
L 291:8-9
J なぜなら、理由の不逸脱は、主題と異類との区分によるものではない。実在に基づくものだからである。なぜなら、理由の不可離関係（avinābhāva）は、「主題でないものはすべて、作られたものであれば無常である」というように取り決めによって示されるのではない。そうではなく、実在の力によってもたらされた遍充（vyāpti）が、認識手段によって「作られたものはすべて無常である」と示されるのである。
N 遍充は「主題を除いたすべて」について成り立てばよいのではなく、主題を含めたすべてについて実在に即して成り立たなければならない。主題を除外して遍充を立てれば、どんな理由でも正しいことになってしまう。
L 291:10-13
J なぜなら、そのように成立してはじめて、その属性はそれ（所証）を知らせるものとなるのであり、そうでなければ（知らせるものとは）ならないからである。人の行為は実在に従属しないからである。なぜなら、人が証明しようと望むもの、それが主題である。その者は、このように逸脱の領域だと見るものを、まさに主題にしてしまうであろう。
N 主題は論者が自由に選べるものである。もし主題を逸脱の判定から外してよいなら、論者は反例となる事例をすべて主題に繰り込んで、逸脱を免れることができてしまう。
L 291:14-15
J また、推論の対象について、知覚などによる否定（bādhā）はない。認識手段が別の認識手段によって否定されるならば、それは認識手段でないことになってしまうからである。特徴（三相）を備えた（理由）について否定がありうるならば、その特徴そのものが損なわれたことになる、とすでに述べた。
N 「主題を除外しても、主題に反例があれば知覚などで否定されるから大丈夫だ」という考えへの反駁である。正しい理由の三相を備えた推論が他の認識手段で否定されることはありえず、もし否定されるなら三相の定義そのものが欠陥をもつことになる。
L 291:16-17
J 否定されないことも特徴であるとすれば、それ（特徴）は確定されないものを特徴とすることになる。そうなれば、（理由は）知らせるものではなくなる。そうなれば、何が何の証明となろうか――そのためにこそ不逸脱が考究されるのに。
N 「否定されないこと（abādhita）」を理由の条件に加えるのはニヤーヤ学派の立場である。しかし、否定されないかどうかは前もって確定できないので、それを条件にすると、どんな推論も確定できなくなる。
L 291:18-20
J それゆえ、実在に即して、あるものがあるものによって遍充されているか遍充されていないかに応じて、それはそれを知らせるものであったり知らせないものであったりするのであり、実在の属性が人の意欲によって定まるのではない。この者が（それを）主題にするときには逸脱がなく、ほかのときにはそれによって逸脱がある――とは、なんとも清らかな妥当性であることよ。
N 最後は皮肉。主題に入れるかどうかという人の都合で理由の正しさが変わるなら、それは実在に基づく認識手段とは言えない。PVSV 96,13 以下と並行。

### III.2.1.3.ii.d.3 | 非実在の属性は矛盾 | viruddha
L 292
J 他方、非実在の属性、すなわちただの実在を遍充する事物（実在性）の排除を、存在（を証明すること）について理由として述べる者にとっては、理由は矛盾するものとなろう。それ（非実在の属性）は実在には決して生じえず、非存在においては、どこでも実在の排除があるからである。
N 「実在でないこと」を理由にして存在を証明しようとすれば、その理由は異類（非存在）にだけ現れ、同類（存在）には決して現れない。これは所証の反対を証明してしまう矛盾因である。
L 293
J それゆえ、この三種のいずれの属性も、存在の証明においては理由の特徴をもたず、また他の道もない。それゆえ、存在は（所証として）証明されないのである。

## III.2.1.3.ii.e | 論証因としての「存在」は三つの過失を免れる | sādhanatva
L 294
J 一方、それ（存在）が論証因である場合には、一般的に、ただそれ（実在）を遍充する実在の属性（である存在）は、存在が成立している主題にあるのだから、不成ではない。そして、もしその所証の属性による遍充が何らかの仕方で確定されるなら、そのときには矛盾も逸脱もない。だから、この（反論者の言う）帰結はあたらない。
N 音声のように存在が成立している主題について、「存在」を理由として無常を証明する場合、理由は主題に成立しており（不成でない）、遍充が確定されれば（例えば刹那滅論証によって）矛盾も不定もない。こうして第58偈の反論に最終的に答える。

# III.2.1.4–III.2.2 | 矛盾因と不確定因――理由の要は「異類からの排除」 | viruddha, anaikāntika
G ディグナーガの「九句因（hetucakra）」に即して、正しい理由が逆に使われると矛盾因になること、そして不確定因（不定因）がなぜ不確定なのかを説明する。結論は、理由が所証を知らせる力の決め手は、同類への随伴の多少ではなく、異類から完全に排除されていること（vyatireka）だ、という点にある。

## III.2.1.4 | 矛盾因 | viruddha
L 295
J この理由は二種、すなわち自性を特徴とするものと結果を特徴とするものとである。（ディグナーガは）それ（正しい理由）こそが、自らの遍充者（vyāpaka）の反対が所証であるときには矛盾因（viruddha）となることを示しつつ、四つの主題所属性（pakṣadharma）を説いた。
N 九句因は、理由が同類（sapakṣa）・異類（vipakṣa）の全部にあるか、一部にあるか、まったくないかを組み合わせた九通りの分類である。正しい理由は「同類の全部または一部にあり、異類にはまったくない」二句、矛盾因はその逆に「同類にまったくなく、異類の全部または一部にある」二句で、合わせて四句となる。正しい理由を、それが遍充する所証の反対を証明するのに使えば、そのまま矛盾因になる、という関係である。PSṬ（ジネーンドラブッディ注）に並行箇所がある。

## III.2.2.1 | 共通不定と不共不定 | sādhāraṇa, asādhāraṇa
L 296
J また、不確定（anaikāntika）である特殊（不共、asādhāraṇa）と一般（共、sādhāraṇa）とについて、それが確定的であると主張する者に反駁して、二つ（の主題所属性）を（説いた）。そしてそれは、似因（hetvābhāsa）（の章）で取り上げるべき機会が来たときに述べることにしよう。
N 「共通不定」は同類にも異類にも全部にある理由（例：「音声は常住である、知られうるものだから」）、「不共不定」は主題以外の同類にも異類にもまったくない理由（例：「音声は常住である、聞かれるものだから」）。編者の分析では九句因の第I句と第V句にあたる。詳しい議論は本章の第4節（校訂本 117頁以下）に回される。

## III.2.2.2 | 同類への随伴だけでは不十分で、異類からの排除が必要 | vyāvṛttiprādhānya
L 297:1-2
J （ディグナーガは）排除（vyāvṛtti）が主要であることを証明するために、理由の三つの主題所属性を説いた。すなわち、理由は随伴（anvaya）の面から（所証を）知らせるのではない。無常であることから、努力の直後に生じたものでないこと（aprayatnānantarīyakatva）は理解されないからである。
N 「音声は努力の直後に生じたものではない、無常だから」という論証。無常という理由は、同類（稲妻など、努力によらないもの）の一部にあり、異類（壺など、努力によって作られるもの）の全部にもある。同類に随伴する例があっても、所証は知られない。
L 297:3
J （反論）これ（この例）から理解が生じないのは、随伴が単独で、否定的随伴（vyatireka）を伴わないからだ、と言うなら――（答え）それでは、ここでは（理解が）あるとせよ――「常住である、触れられないものだから」と。
N 「音声は常住である、触れられないもの（無触）だから」という論証。理由は同類（虚空など）の一部にあり（原子は触れられるので一部）、異類の一部（行為など）にもある。否定的随伴もある程度あるのに、やはり所証は知られない。
L 297:4-5
J （反論）いや、ここでも随伴が主要でないからだ、と言うなら――（答え）しかしここでは随伴が強く、否定的随伴は弱い。理由が同類を遍充しており、異類の一部には無いからである。例えば、「努力の直後に生じたものである、無常だから」という場合である。
N 「音声は努力の直後に生じたものである、無常だから」。理由は同類（壺など）の全部にあり、異類の一部（稲妻）にもあるが一部（虚空）にはない。随伴が「主要」であるはずのこの場合も、所証は知られない。
L 297:6-8
J （反論）異類全体から排除されていないので、（知らせるものとは）ならない、と言うなら――（答え）それならば、「作られたものは無常にほかならない」というように、常住なものを排除することによって知らせることが認められることになろう。そうでなければ、異類全体からの排除を示すことはできないからである。それゆえ、これ（理由）には、ただ（随伴が）あることによっても、（随伴と否定的随伴とが）同等であることによっても、（随伴が）主要であることによっても、理解（を生じさせる力）はない。
N 反論者が最後に「異類全体から排除されていないからだ」と認めれば、それこそダルマキールティの主張どおり、決め手は異類からの排除だということになる。随伴が「ある」か、否定的随伴と「同等」か、「主要」か、のいずれも決め手ではない。PSṬ に並行箇所がある。
L 298:1-2
J 随伴が主要でなくても、否定的随伴が遍充的であれば、（理解は）ある。例えば、「無常である、努力の直後に生じたものだから」という場合である。
N 「音声は無常である、努力の直後に生じたものだから」。理由は同類（無常なもの）の一部（壺）にしかないが（稲妻にはない）、異類（常住なもの）には決してない。随伴は部分的でも、異類から完全に排除されているので正しい理由となる。
L 298:3-4
J それゆえ、理由はまさにこのようにして知らせるものとなる――「努力の直後に生じたものは無常にほかならない」というように、常住なものを排除することによって。なぜなら、この言明の能力は、音声や（煙のある）場所などにおいて、常住なものや火でないものを排除することによって否定的随伴を理解させることで完結するからである。
N 「〜にほかならない（eva）」という限定が、異類（常住なもの、火のないもの）の排除を表している。論証の言明は、それだけを伝えれば役目を果たす。本文の sāmarthyaparisamāptaḥ は sāmarthyaparisamāpteḥ（校訂本の読み）と読んで訳した。
L 299:1-2
J また、これら（の理由）から理解されるのは、ただの区別（bhedamātra）ではない。そうではなく、反対のものをもたない、まさにその一般（所証）である――「ここにはこれだけがあり、他のものはない」と。
L 299:3-4
J もしこれらが他のものと結びつかないものとして必ず理解されるべきだとすれば、それらのその非結合こそが理解されるものであればよい。それだけで目的は果たされるからである。役に立たない一般（の実在）が何の役に立とうか――このことを（ディグナーガは）「排除による証明」（という表現）によって示している。
N 推論が知らせるのは、他から区別された一般（例えば「無常」）であるが、それは実在する普遍ではなく、「反対のもの（常住）ではない」という排除そのものである。ニヤーヤ学派などの言う実在の普遍は、推論の役に立たない「余計なもの（antargaḍu）」にすぎない。仏教のアポーハ（排除）論が背景にある。
