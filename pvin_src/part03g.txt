# IV | 似因（誤った理由）：総説と分類 | hetvābhāsa, k.67–68
G ここから、正しい理由の条件である三相（主題所属性・肯定的随伴・否定的随伴）のどれかが欠けている「似因（hetvābhāsa、理由のように見えて理由でないもの）」を論じる。まず総説として、三相のどれかが成立していないか疑わしければ似因である、と定義し、その分類を示したうえで、主題所属性が欠けた「不成立因（asiddha）」を詳しく扱う。

## IV.1 | 似因の一般的定義 | trairūpyāsiddhisandeha, k.67
V 324-325
J 知らせるための支分（である三相）が成立していないものには、知らせることについて能力がないので、三相（trairūpya）が成立していないか疑わしいときには、（それは）理解する者たちにとって論証因（sādhana）ではない。（第67偈）
N 「知らせるための支分」とは、理由が所証を知らせるための条件、つまり三相のこと。三相のどれかが欠けている（不成立）か、あるかないか確定できない（疑わしい）ならば、その理由は聞き手に何も知らせることができない。これが似因の一般的な定義である。
L 326:1-2
J なぜなら、知らせるものである理由は、ある本質によって（所証を）知らせるのであるが、その（本質）が成立していないか疑わしいならば、知らせるものではないからである。言葉のように。
N 言葉も、その意味の取り決め（語と意味の結びつき）が知られていなかったり、あいまいだったりすれば、何も伝えない。理由も同じで、所証を知らせる根拠となる本質（三相）がはっきりしなければ、知らせる働きをもたない。
L 326:3
J そして理由は三相によって対象（所証）を理解させる。（所証と）結びついていないものからは理解が生じないからである。台所などで見られた煙などから、大海における火（が理解されない）ように。また、（本質的な）結びつき（pratibandha）がなくても（理解させる）とすれば、あらゆるものからあらゆるものの理解が生じてしまうからである。
N 理由が所証を知らせるのは、両者のあいだに本質的な結びつきがあるからであり、それが三相によって保証される。台所で煙を見ても、遠く離れた大海に火があるとはわからない。結びつきのないところで推論が成り立つなら、何からでも何でも推論できることになってしまう。
L 326:4
J したがって、論証される者（聞き手）と論証する者（立論者）（の双方）にとって、主題との関係（dharmisambandha）・肯定的随伴（anvaya）・否定的随伴（vyatireka）が成立していないか疑わしい性質が、似因（hetvābhāsa）である。
N 三相を「主題との関係（主題所属性 pakṣadharmatva）」「肯定的随伴（同類にあること）」「否定的随伴（異類にないこと）」と言いかえて、そのどれかが不成立または疑わしいものを似因と定義する。『ニヤーヤ・ビンドゥ』（NB）3.56 に並行する定義がある。

## IV.2 | 似因の分類 | k.68
L 327
J そのうち、
V 328-329
J （三相のうちの）一つが成立していないか疑わしいときには、不成立（因 aprasiddha）か、逸脱をもつもの（不定因 vyabhicārabhāk）である。二つが成立していないときには矛盾（因 viruddha）であり、（二つが）疑わしいときには逸脱をもつもの（不定因）である。（第68偈）
N 似因は、どの相がどう欠けているかによって分類される。一つの相の欠陥は、それが主題所属性なら「不成立因」、否定的随伴なら「不定因（anaikāntika）」となる。二つの相（肯定的随伴と否定的随伴）がともに不成立（逆に成立している）なら「矛盾因」、ともに疑わしいなら不定因である。この偈は、ヴァーダニヤーヤ注（VNṬ 135,27–28）にも引かれている（Frauwallner 1954 参照）。

### IV.2.1 | 一つの相の欠陥：不成立因と不定因 | asiddha, anaikāntika
L 330
J 一つ一つの相が成立していないか疑わしいときには、不成立（asiddha）と不定（anaikāntika）という似因となる。
N 「一つの相」とは、具体的には主題所属性か否定的随伴のどちらかを指す（ダルマキールティにとって肯定的随伴と否定的随伴は表裏一体なので、肯定的随伴だけの欠陥は別に立てられない）。以下、まず主題所属性の欠陥（不成立因）、次に否定的随伴の欠陥（不定因）が論じられる。NB 3.57, 3.66 と並行。

# IV.2.1.1 | 主題所属性の欠陥：不成立因 | pakṣadharma, asiddha
G 三相のうち主題所属性（理由が主題に属すること）が欠けている、または疑わしい理由が「不成立因」である。立論者・対論者の両方にとって不成立なもの、一方にとってだけ不成立なもの、理由が主張の一部であるもの、主題や理由の所在が疑わしいもの、主題そのものが成立していないもの、が順に論じられる。とくに、同じ言葉が使われていても指している事物が違えば理由は成立しない、という点が強調される。

## IV.2.1.1.i | 両者にとって不成立な理由 | asiddha
L 331
J 主題との関係が成立していないときには、不成立（因）である。例えば、「音声は無常である。眼で見られるものであるから」。
N 理由「眼で見られるもの」は、主題である音声にそもそも属していない（音声は耳で聞かれるもの）。これが、立論者にも対論者にも成立していない「両者にとっての不成立（ubhayāsiddha）」の典型例である。NB 3.58–59 と並行。

## IV.2.1.1.ii | 論争者の一方にとって不成立な理由 | anyatarāsiddha
### IV.2.1.1.ii.a | ジャイナ教徒の「樹木は死ぬ」 | maraṇa
L 332:1-2
J 「樹木には精神がある。すべての樹皮をはぎ取ると死ぬから」というのは、対論者（仏教徒）には認められていない。死とは、識・感官・寿命の消滅を特徴とするものだからである。そして、どうして（仏教徒が樹木の）死を認めながら、精神性を認めないことがあろうか。
N ジャイナ教徒は、植物にも霊魂（精神）があると主張し、その論証として「樹皮を全部はぐと枯れて死ぬ」ことを挙げる。しかし仏教徒にとって「死」とは識（心）・感官・寿命が尽きることなので、樹木が「死ぬ」とは認めない。死を認めれば精神も認めたことになるからである。これは「論争者の一方にとっての不成立（anyatarāsiddha）」の例である。PV II 17cd 参照。
L 332:3-4
J （反論）（樹木についても）「死」という語が用いられるから、（理由は）まさに成立している。
（答え）語は（話し手の）意欲によって用いられる。それによって事物のあり方が（決まるの）ではない。過大適用になるからである。
N 「木が死ぬ」と言うことはできても、言葉の使い方は話し手の自由なので、言葉が使われることから事物の本当のあり方を決めることはできない。もし決められるなら、比喩的な言い方からも何でも証明できてしまう。
L 332:5-7
J したがって、（ジャイナ教徒は）樹木における、乾燥からなる死を言っていることになる。そして生き物の死はそのようなもの（乾燥）ではないので、これ（生き物の死）は樹木において成立しない。なぜなら、事物を顧慮しない、意欲のままに働く単なる語は（論証の根拠として）有効ではなく、したがって、事物によって知られる事物が成立するのだからである。
N 樹木について言われる「死」は実際には「枯れて乾くこと」にすぎず、生き物の死（心の消滅）とは別物である。同じ「死」という言葉が使われていても、指している事物が違えば、論証の理由にはならない。推論は語ではなく事物にもとづく、というのがダルマキールティの一貫した立場である。
### IV.2.1.1.ii.b | 語は共通でも事物が共通でない理由 | anityatva, saṃsthānaviśeṣa
L 333
J これによって、知性（buddhi）などに対する「無常であること」、世界（bhuvana）などに対する「特定の形状（saṃsthānaviśeṣa）」など、すなわち「非精神性」や「特定の知性に先行されること」などを論証する（理由）も説明された。そこでも、ただ語だけが成立しているのであって、意味（事物）は（成立して）いないからである。
N 同じ型の誤りの例が二つ挙げられる。（1）サーンキヤ派は「知性（ブッディ）は精神をもたない。無常だから」と論じる。（2）ニヤーヤ・ヴァイシェーシカ派は「世界などは知的な作者（神）をもつ。特定の形状をもつから」と論じる。どちらも、理由の語は双方に通じているが、その語が指す事物は仏教徒と相手とで違うので、理由は実際には成立していない。以下、（1）と（2）を順に検討する。

#### IV.2.1.1.ii.b.1 | サーンキヤ派の「無常」は仏教徒と共通しない | anityatva, tirodhāna
L 334:1
J なぜなら、他者たち（仏教徒）は、本体が失われない（apracyutātman）ものの消失（upalayana）を無常性とは認めないからである。
N サーンキヤ派によれば、結果はすでに原因（根本原質）の中に潜在的に存在しており（因中有果論 satkāryavāda）、ものが「なくなる」とは、本体はそのままで原因の中に「没し隠れる」ことにすぎない。仏教徒にとって無常とは本当に滅することなので、サーンキヤ派のいう「無常」は仏教徒には成立していない。
L 334:2-4
J （反論）特殊を問題にしない一般（としての無常性）は（双方に）成立しているではないか。それが成立している以上、特殊を分別して不成立だと非難するのは、誤った返答（mithyottara）にほかならない。
（答え）もし、「作られたものであること」などのように、両者に認められた何らかの事物としての一般があって、この「無常」という語がそれに基づくのであれば、誤った返答となろう。
N 「誤った返答」とは、正しい論証に対して見当違いの非難をすること（ニヤーヤ学派のいう誤難 jāti に当たる）。反論者は「細かい違いを抜きにした『無常』一般は双方に共通だ」と言う。答えは、そのような共通の事物がもし本当にあるなら非難は不当だが、実際にはない、というものである。ディグナーガの『集量論』第3章へのジネーンドラブッディ注（PSṬ）に、この反論の並行がある。
L 334:5-6
J （反論）隠没（tirodhāna）は（仏教徒にとっても）まさにある。
（答え）他者（仏教徒）はそれを無常性とは言わない。そうではなく、消滅（vināśa）を（無常性と言うのである）。
L 334:7-9
J （反論）滅したものと隠没したものとの両者において、非顕現（avyakti）は等しいので、一般は確かにある。
（答え）では、この非顕現とは何か。
（反論）見えない本性であること（adṛśyātmatā）である。
L 334:10-11
J （答え）それならば、この定義によって、根本原質（pradhāna）や精神（puruṣa）なども無常であることになってしまう。
（反論）以前には別の性質をもっていたものが非顕現であること、それが無常性である。
（答え）「別の性質をもつ」ということと、「以前（の状態）から本体が失われていない」ということとは、まことに見事な言い方である。
N サーンキヤ派は、「消滅」と「隠没」に共通する「見えなくなること（非顕現）」を無常の共通の意味にしようとする。しかし、根本原質や精神ももともと目に見えないので、それらまで無常になってしまう。そこで「以前は別の性質をもっていたものが見えなくなること」と限定するが、「別の性質になった」のに「本体は失われていない」というのは自己矛盾だ、と皮肉っている。PVA 46,8–10 参照。
L 335:1-3
J これによって、その状態の停止（avasthānivṛtti、を無常性とする説）も説明された。状態の停止を、隠没と似たものとして（「無常」という）語の対象だと言う者がいるが、その者にとっても、それ（状態）はどうして停止していて、しかも（本体が）失われていないのか。
（反論）状態が停止するのであって、状態をもつもの（avasthātṛ）は（停止し）ない。
（答え）この状態とは何か。
N サーンキヤ派の別の言い方では、変化とは、変わらない基体（状態をもつもの）の上で「状態」が入れ替わることである。ダルマキールティは、その「状態」とは何なのかを問いつめる。
L 335:4
J 水を運ぶことなどの効果的作用（arthakriyā）に用いられ、人が「これは壺だ」と直接に判断するもの、それ（が状態だとすれば、それ）が停止したときには、（それとは）別のこの（状態をもつもの）は、停止していなくても、まったく存在しない（のと同じである）からである。
N 実際に水を運ぶ役に立ち、「壺だ」と見られているのは「状態」の方である。それが壊れてしまえば、後に残るとされる「状態をもつもの」は何の役にも立たず、壺として認められるものは何もない。
L 335:5-7
J それならば、まさにその状態が壺であるとせよ。これ（状態）が先に述べた特徴をもつからである。そしてそれは停止したのだから、停止せずに状態をもつものとして存続しているもの（が何であるか）が問いただされるべきである。あるいは、（それが）存在するとしても、実在する壺ではない。その特徴（効果的作用など）をもたないからである。
L 335:8-9
J （反論）事物は一つであって、別の状態に入ることによって差異が見られるのである。
（答え）まさにその状態の差異が事物の差異の特徴であると、どうして認めないのか。なぜなら、そうしてこそ、楽など（の三つの構成要素）に疑いのない差異が成り立つからである。
N サーンキヤ派は、楽・苦・迷妄（サットヴァ・ラジャス・タマスの三グナ）を互いに別のものとする。その差異も、結局は現れ方（状態）の違いによって認められているのだから、状態の差異を事物の差異と認めるべきだ、という論法である。
L 335:10
J （反論）ある形相が（どの状態にも）引き継がれているので、状態が異なっていても非別異である。
（答え）そのことは、楽などと精神たちとについても同じではないか。
N 「共通のものが引き継がれているから同一」と言うなら、互いに似た点をもつ三グナどうし、あるいは多数の精神（プルシャ）どうしも同一になってしまい、サーンキヤ派自身の多元的な体系が崩れる。
L 335:11-12
J （反論）異なっているならば、順次的に顕現することと矛盾するので、一体である。
（答え）それでは今度は、壺や凝乳などは、順次的でなく顕現するから多数だというのか。あるいは、非別異が（順次的顕現を）遍充することが成立していないのに、順次的顕現とのどんな矛盾があるのか。
N 反論は、粘土→壺→破片のように「順々に現れる」のは、同じ一つのものが姿を変えているからだ、と言う。答えは、その論法なら同時に現れるもの（壺と凝乳など）は別々だということになるが、サーンキヤ派はすべてを一つの根本原質の変容と見るので困るだろう、と応じ、さらに、同一であることと順次的顕現との結びつきそのものが証明されていない、と指摘する。
L 335:13-14
J 順序（があるの）は、それ（後のもの）がそれ（前のもの）の結果なので、それ（前のもの）が完成しなければ（後のものも）完成しないからである。むしろ非別異であれば、一つの本体であるのと同じように、まったく順序のないこと（同時性）になってしまう。
N 順序は因果関係から生じる。もし前後のものが本当に同一なら、同じ一つのものが同時に全部あることになり、かえって順序が説明できなくなる。
L 335:15-16
J （反論）結果であるからこそ非別異である。
（答え）もし（同一性による）結びつき（pratibandha）が成立するならば、それは妥当であろう。しかしそれは、（原因の本体が結果に）引き継がれていないものについては成立しない、ということを（後で）述べるであろう。
N 「結果は原因と同一だ」という因中有果論の主張に対して、原因と結果のあいだに引き継がれる同一の本体などない、と答える。校訂者は後の箇所（校訂本 115,7）を参照させている。

#### IV.2.1.1.ii.b.1.3 | 「無常」と「死」に共通の事物はない | samāno dharmaḥ
L 336
J いずれにせよ、滅したものと他のもの（隠没したもの）とに非別異を想定するとしても、この「無常」という語が適用されるような共通の性質はない。ちょうど、「作られたもの（kṛtaka）」という語が、関係するもの（それぞれの原因）の区別を除いたうえで、原因からの生起に（適用される）ような（共通の性質は、ここにはない）。
N 「作られたもの」という語なら、壺の原因と音声の原因の違いを抜きにしても、「原因から生じること」という共通の事物を指す。ところが「無常」という語には、仏教徒の「消滅」とサーンキヤ派の「隠没」に共通する事物がない。
L 337:1-2
J 同様に、樹木と人間とに（共通の）死一般も（ない）。それを見ることによって、他の生き物について「死んだ」と理解されるようなもの、そのようなものがもし樹木に認められるならば、これ（理由）は成立するであろう。
L 337:3
J もし乾燥など（だけ）を「死」という語で言うのなら、それについても、精神性（caitanya）との結びつきが検討されなければならない。それ（結びつき）によって（精神性が）成立するような（結びつきが）。
N 先のジャイナ教徒の論証に戻る。「乾燥」を「死」と呼ぶのは自由だが、その場合には、乾燥と精神性のあいだに本質的な結びつきがあることを別に示さなければ、樹木に精神があるとは言えない。

#### IV.2.1.1.ii.b.2 | ニヤーヤ・ヴァイシェーシカ派の「特定の形状」も不成立 | saṃsthānaviśeṣa, k.69–76
L 338
J 同様に形状についても、宮殿などの種々のものにおいて（共通に）継続して、知性に先行されたもの（作者をもつもの）として見られているようなもの――それを見れば、作る行為を見ていない者にも「作られたものだ」という知が生じるようなもの――もしそのようなもの（が世界などにある）ならば、すべての理由は（正しい理由）となるであろう。
N 神の存在論証（世界は形状をもつから知的な作者をもつ）への批判。宮殿や壺のように、見ただけで「人が作った」とわかる形状なら作者を推論できるが、山や大地の形状はそういうものではない。「形状」という同じ語が使われていても、指す事物が違う。
L 339
J さらにまた、
V 340-341
J 支配者（adhiṣṭhātṛ、作者）の有無に（自らの有無が）随うものとして成立しているような配置（sanniveśa）など、それから推論されるものは妥当である。（第69偈）
N 作者がいるときにあり、いないときにはない、ということが確かめられている種類の形状（家や壺の形）からなら、作者を正しく推論できる。PV II 11–16（『プラマーナ・ヴァールッティカ』「認識手段の確立」章の神の存在論証批判）に並行する偈が続く。
V 342-343
J 異なる事物において成立しているものを、言葉が同じであるために区別のないもの（とみなして推論する）なら、推論は妥当ではない。白っぽい物質から火（を推論する）ように。（第70偈）
N 立ちのぼる白っぽいもの（湯気や塵など）を煙と見まちがえて火を推論するのが誤りであるのと同様に、「形状」という言葉が同じだからといって、性質の異なる事物から作者を推論することはできない。
V 344-345
J さもなければ、陶工が、土の変化したもの――壺など――の何かを作ることから、蟻塚もそれ（陶工）の作ったものとして成立してしまうであろう。（第71偈）
N 蟻塚も「土でできた形のあるもの」だが、陶工が作ったものではない。言葉の共通性だけで推論すれば、こうした不合理が生じる。
V 346-347
J 結果（作られたもの）において所証と（理由との）随伴があるので、（理由を）一般として論証因としても、関係するものの差異によって（理由の）差異を言う過失は、「結果相似（kāryasama）」とされる。（第72偈）
N 「音声は無常である。作られたものだから」のように、理由と所証の結びつきが一般的に成り立っている場合に、「壺の『作られたもの』と音声の『作られたもの』は違う」と言って非難するのは、ニヤーヤ学派の誤難の一つ「結果相似」という誤りである。しかし神の存在論証の場合は、そもそも一般的な結びつきが成り立っていないので、差異の指摘は正当な批判である、という含みがある。
V 348-349
J 別の種類において成立しているものを、言葉の共通性を見ることによって（論証因とするのは）妥当な論証因ではない。「go であること」によって、言葉など（go と呼ばれるもの）が角をもつ（と論証する）ように。（第73偈）
N サンスクリットの go という語は「牛」も「言葉」も意味する。牛は角をもつからといって、同じ go と呼ばれる「言葉」も角をもつと推論するのはばかげている。語が同じでも事物が違えば推論は成り立たない、という例。
V 350-351
J 語は（話し手の）言おうとする意図に依存しているので、どこにないことがあろうか。それ（語）があることから対象が成立するのであれば、あらゆるものからあらゆるものが成立してしまう。（第74偈）
N 語は話し手がどこにでも当てはめられるので、語の存在から事物の存在を推論すれば、何からでも何でも証明できてしまう。
V 352-353
J この道理は、事物の本性が成立していない場合のものである。（事物が）成立しているならば、限定語（viśeṣaṇa）は、（それ自体は）不成立であっても過失を生じない。「虚空を所依とする」音声の（場合の）ように。（第75偈）
N 逆に、事物そのものが双方に成立していれば、理由の言い方に相手の認めない語が含まれていても問題はない。ヴァイシェーシカ派は音声を「虚空（ākāśa）を所依とする」性質と見るが、仏教徒はそのような虚空を認めない。それでも「虚空を所依とする音声」と言われているもの（音声そのもの）は双方に成立しているので、論証は損なわれない。PV II 18 と並行。
V 354-355
J 語（の意味）が不成立であっても、事物が成立していれば（論証は）成立する。仏教徒が、ウルーカの徒（ヴァイシェーシカ派）に対して述べた「有形性（mūrti）」などの論証因のように。（第76偈）
N 仏教徒がヴァイシェーシカ派に対して「有形性」などを理由として立てる場合、その語の定義は両派で異なっていても、指されている事物が双方に成立していれば論証は有効である。PV II 19 と並行。
L 356
J 以上が中間偈（antaraśloka）である。

### IV.2.1.1.ii.c | 学説に基づく一方の不成立はここでは扱わない | śāstrāśraya
L 357:1
J また、学説（śāstra）に基づいて（論争者の）一方にとっての不成立が提起される場合――例えば、顕現説論者（abhivyaktivādin）にとって「作られたものであること」は不成立である、というような――それはすべての推論において（あてはまるの）ではない。認識手段によって見られたもの（理由）について、（学説上の）主張によって不成立を非難することは不適当だからであり、また、学説は推論に関して権限をもたないからである。
N ミーマーンサー学派は、音声（ヴェーダの言葉）は常住で、発声によって「顕現する」だけで「作られる」のではない（顕現説）と主張する。だから彼らの学説からすれば「音声は作られたものだから無常」という理由は不成立となる。しかしダルマキールティは、理由が認識手段（知覚など）によって確かめられているなら、学説上の主張を持ち出して不成立と言うことはできない、とする。推論はあくまで事物の力によるもので、学説の権威には左右されない。
L 357:2-3
J 認識手段によってこそ（理由が）否定される場合、あるいはそれ（理由）が存在することの認識手段が認められない場合には、顕現説が何の役に立とうか。したがって、学説に基づく推論においてのみ、学説による一方の不成立がある。
L 357:4-5
J それ以外の場合には（一方の不成立は）無知によるのである。だから（学説による不成立は）論争（vāda）の例ではない。ただし、師（ディグナーガ）は例の方向を示したのである。
N 学説による不成立は、聖典の権威に基づいて論じる場合にだけ問題になる。それ以外の場で一方が理由を認めないのは、単にその人が事物を知らないからにすぎない。ディグナーガ（「師」）が顕現説論者の例を挙げたのは、一方の不成立がどのようなものかを示す手がかりとしてにすぎない、という解釈である。

## IV.2.1.1.iii | 主張の一部である理由 | pratijñārthaikadeśa, k.77–81
### IV.2.1.1.iii.a | 主題そのものは理由になりえない | dharmī na hetuḥ
L 358:1
J また、主張の意味の一部（pratijñārthaikadeśa）である不成立（因）と言われるもの――例えば「音声は無常である。音声であるから」――それも、所証と論証因とは別のものであるから、所証である主題（音声）は自分自身を論証することについて論証因であることが成立しないので、理由としては不成立と言われるのである。
N 主張「音声は無常である」の一部である「音声」を、そのまま理由に立てる誤り。ディグナーガはこれを不成立因の一種として挙げた（PSV ad PS III 11 参照）。ダルマキールティは、論証するものと論証されるものは別でなければならないので、主題が自分自身を論証することはできない、と説明する。PV IV 180 と並行。
L 358:2-3
J なぜなら、それ自体がそれの論証因となることはないからである。それ（音声）の存在だけに付随するもの（無常性）について、再びそれ（音声）を述べることは無意味だからである。なぜなら、そこ（理由）では（主題とは）別の特殊は何も述べられていない。
L 358:4-5
J それ（音声）が音声としてそのよう（無常）であるのなら、主題を提示するだけでそのように成立する。（理由として）再び（述べても）、それ自身によってそのようであるのだから。したがって、それ自身はそれ自身にとっての理由として不成立である。
N 音声が音声であるというだけで無常なのなら、主張で「音声は」と言った時点で話は終わっており、理由で「音声だから」と繰り返しても何も新しい情報は加わらない。
L 359:1-3
J （反論）いったいどうして音声が不成立なのか。音声は成立している。
（答え）それ（音声）は、自らについて理由のかたちとしては成立していないので、不成立と言われるのである。
L 359:4-5
J そしてその音声は主題とされたのであり、理由となるような別の音声はない。そしてそれ自体が理由であるならば、（それは）重ねて述べるべきでない、と（すでに）述べた。
N 音声そのものは存在していても、「理由として」は成立していない、という意味で「不成立」と呼ばれる。「すでに述べた」は直前の 98,5（L 358:2）を指す。
L 360:1-2
J また、（主題が理由になるのなら）常に争いはないことになろう。それ（主題）が存在することは成立しているからである。
（反論）肯定的随伴が見られないから不成立なのである。
（答え）それでは今度は、主題が別の主題に随伴するようになるというのか。
N 反論者は、「音声だから」が誤りなのは、音声以外の同類（喩例）に随伴しないからだ、と説明する。しかしダルマキールティによれば、問題はそこではない。主題が別の主題に随伴することなどそもそもありえないので、それを欠陥の理由に挙げるのは的外れであり、根本の欠陥は「理由として成立していない」ことにある。
L 360:3
J 灯火などは、本性上の適合性によって自らについての知を生じさせ、そのように照らし出しているので、「自らを照らすもの」と言われる。
L 360:4-6
J しかし、徴表と徴表をもつもの（所証）とについてはそうではない。それ（徴表と徴表をもつものであること）は差異を基盤とするからである。なぜなら、徴表が自ら知の対象となることは、徴表をもつものを知らせることではない。しかし主題が自らを論証する場合には、この過失がある。
N 灯火は他を照らすと同時に自分も照らすので、「自分で自分を知らせる」例のように見える。しかし推論における徴表（理由）と所証の関係は、別々のもののあいだの関係であり、徴表が知られることと、それによって所証が知られることとは別のことである。

### IV.2.1.1.iii.a.4 | 所証と論証因の区別は概念上のもの | vyāvṛttisamāśraya, k.77–78
L 361:1
J （反論）あらゆる存在において、主題と性質との区別は成立していないので、この過失はどこでも同じである。
（答え）これについてはすでに述べた――存在には、排除（vyāvṛtti）に基づく言語慣習の違いによって、所証と論証因との違いがある、と。
N 反論：仏教徒の考えでは、事物そのものは分割できない一つの個物であり、主題と性質の区別は実在しない。それなら「音声は作られたものだから無常」でも、理由と主題は結局同じものではないか。答え：区別は「他からの排除（アポーハ）」に基づく概念上の区別であり、言語慣習のうえでは成り立つ（第2章、PVin 2 56,12–57,3、および PVSV 2,21–3,3 参照）。PV IV 181 と並行。
L 361:2-3
J 究極的な（paramārtha）考察においては、そのような（実在的な区別）は成立しないので、世俗的な（sāṃvṛta）事物について、同一であるか別であるかは否定される。しかし推論と推論されるものという言語慣習は、知において成立している区別に依拠して想定されるのである。
N 勝義（究極の真実）のレベルでは、事物とその性質が同じか別かを問うこと自体が意味をなさない。推論はあくまで、知（概念）のうえで成り立つ区別を用いて行う世俗の営みである。PV IV 182–183 と並行。本文の praklpyate は prakalpyate の誤記と見て訳した。
V 362-363
J それぞれに応じて区別に立脚する知において、識別する者には主題と諸性質とが（別々に）現れる。言語慣習はそれに依拠している。（第77偈）
V 364-365
J ここ（「音声だから」という論証）では、言語慣習に持ち込まれた、区別の結びつけられていない知（の対象）であるそれ自体が、所証でありながら論証因とされている。それゆえ（それは）不成立であると明らかにされたのである。（第78偈）
N 「音声である、無常である、作られたものである」のように、知のうえで区別された性質どうしなら所証と論証因になれる。ところが「音声だから」の場合は、主題として知られている「音声」と何も区別されていないものが論証因に回されているので、不成立とされる。PV IV 184–185 と並行。
L 366
J 以上が要約偈（saṅgrahaśloka）二つである。
L 367
J したがって、主題は理由ではない。両者にとって不成立だからである。

### IV.2.1.1.iii.b | 所証である性質も理由になりえない | sādhyadharma
L 368:1-2
J これによって、（所証である）性質（を理由とする場合）も説明された。そこでも、もしそれ自体から（所証が）成立するのなら、それはすでに先に（主張で）述べられているので、前と同様の帰謬が言われるべきである。
L 368:3
J 肯定的随伴が不成立であると言う場合にも、それ自体がそれ自体に随伴するということはないので、（その説明は）的外れである。
N 「音声は無常である。無常だから」のように、所証の性質そのものを理由にするのも、主題の場合と同じ理由で誤りである。

### IV.2.1.1.iii.c | 「異類でないから」という理由も不成立 | vipakṣavyatireka
L 369:1-2
J （反論）それでは、「異類からの排除（vipakṣavyatireka）」が理由として述べられる場合はどうなのか。
（答え）その場合も、所証の非存在が異類なのだから、それ（異類）の排除とは所証である性質にほかならない。だから不成立である。
N 例えば「音声は無常である。常住なもの（異類）ではないから」という論証。「常住でない」とは「無常である」ことにほかならないので、これも所証を理由に立てたのと同じである。
L 370:1-4
J （反論）主題・同類・異類は互いに区別されるので、異類でないこと（avipakṣatva）は主題にまさにある。
（答え）何が主題で、何が異類なのか。
（反論）ある性質を論証しようと意図されるところ、それが主題である。それ（所証）の排除が異類である。
N 反論者は、主題（音声）・同類（壺など）・異類（虚空など）を三つの別々のグループと考え、主題は定義上異類ではないのだから、「異類でないこと」は主題について成立している、と言う。
L 370:5-7
J （答え）それならば、それ（主題）は意図によって特徴が定められたものであるのに、どうして異類が事物の力によって定まっていることを退けることができようか。またこのようであれば、いかなる理由も不定とはならないであろう。異類も意図によって作られるものとなるから――とは、ほぼ（すでに）述べた。
N 主題は「論証したいもの」として話し手の意図で決まるが、何が異類かは事物そのもの（所証の性質をもたないこと）で決まる。意図で決まる主題が、事物で決まる異類から自分を除外することはできない。もし意図で異類が決まるなら、都合よく異類を決めて、どんな理由も不定（異類にもあること）にならないようにできてしまう。校訂本 77,6 以下を参照させている。
L 370:8
J また、異類が所証の排除であるとき、それ（異類）の排除がもし主題において成立しているのなら、何が不成立で、そのために理由が述べられるのか。
L 371:1
J （反論）所証が成立していないというだけで、すべてが異類となるのではない。そうではなく、それ（所証）の排除によって両者に確定されているもの（が異類）である。だから、（主題においては所証の排除が）確定されていないので、主題において「異類でないこと」が成立している。
L 371:2
J （答え）所証の性質が疑わしいものも、このように異類でないことになるので、それ（主題）の「異類でないこと」は、「所証の排除が確定されていないこと」による除外を本質とするのに、どうして論証因となろうか。その特徴が確定していないからである。
L 371:3-5
J （反論）まさにそれ（論証因）によって確定がなされるのだ。
（答え）どうして確定されていないことから確定が（生じよう）か。なぜなら「異類でない」という語によって言われているのは、排除が確定されていないことなのである。まさにそれから、どうして非存在の確定があろうか。
L 371:6
J 「これがここで疑わしいから、これはここにない」というのは、まことに見事な言い方である。
N 反論者は「異類」を「所証がないと確定しているもの」と定義し直し、主題はまだ確定していないから異類ではない、と言う。しかしその意味での「異類でないこと」は「疑わしい」というだけのことなので、そこから「所証の非存在はない（＝所証がある）」と確定することはできない。最後の一文は、疑わしさから非存在を結論する論法への皮肉である。
L 372:1-2
J したがって、主題の設定を顧慮しない、諸性質の存在と排除とは、互いに相手を排除することによって特徴が定まっているので、第三の部類を区別しない。それら二つのうち、一方の停止は他方の存在であるから、どうして「無常の非存在（常住）の排除」が、無常であることを所証とする主題において（無常性と別に）成立しようか。
N 事物の性質は「ある」か「ない」かの二つに一つで、主題という第三のグループがあるわけではない。「常住でない」ことは「無常である」ことと同じなので、無常性を論証しようとしている主題について、それだけ先に成立していることはありえない。
L 372:3-5
J （反論）それでは今度は、主題も異類なのか。
（答え）場合によってはそうでもあろう。しかし（主題と異類の）特徴の違いはすでに述べた。
N 主題は、結論が出てみれば同類か異類かのどちらかに入る。主題と異類の違いは、事物上の区別ではなく、「論証したいもの」という定義上の違いにすぎない。
L 372:6-7
J なぜなら、（主題が）異類でないかどうかが疑われるときに、所証の非存在を除外するために理由が述べられるのではないからである。また、理由の（所証との）関係を示す時点では、主題などの区別はない。それによってこの過失（主題も異類になってしまうこと）が生じるような（区別は）。
L 372:8-9
J なぜならそれ（理由）は、単独で、あるもの（所証）の有無に応じて存在と排除をもつものとして示され、自ら存在しつつ、その能力によってそれ（所証）をそのようなものとしてもたらすのである。だから、それ（理由）の能力が後から（及ぶ）対象が主題と言われる。それゆえ、それ（主題）の特徴を通じて得られる性質（「異類でないこと」など）は、理解させる時点にあるものではないので、（論証の）支分ではない。
N 遍充（理由と所証の必然的な結びつき）を示す段階では、主題・同類・異類の区別は問題にならず、「理由があるところには所証がある」という一般的関係だけが示される。主題とは、そのあとで理由の力が適用される対象にすぎない。だから「主題であること」から得られる「異類でないこと」を論証の要素にすることはできない。
