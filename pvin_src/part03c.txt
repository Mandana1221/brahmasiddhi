# II.2.4 | 「のみ（eva）」という語の意味 | eva
G ディグナーガの主張の定義「自らの形のみによって（svarūpeṇaiva）述べられるべきもの」にある「のみ（eva）」が、なぜ『集量論』の定義には必要で『正理門論』の定義には不要なのかを説明する。「のみ」は、まだ成立していない論証因のように、論証を要するが所証として立てられていないものを主張から除く。
L 102:1
J ここ（ディグナーガの主張の定義）では、限定（avadhāraṇa）の意味は「自ら（svayam）」と「意図された（iṣṭa）」という語によってすでに伝えられているけれども、（「意図された」が）クリティヤ接辞で終わる語（「述べられるべき nirdeśya」）と結びつくので、これから述べられようとするもの（すべて）にまで（主張であるという）過大適用（prasaṅga）が及ばないように、それを排除するために（ディグナーガは「のみ」と）言ったのである。
N ディグナーガ『集量論』（PS）III 2 の主張（pakṣa）の定義は「自らの形のみによって（svarūpeṇaiva）述べられるべき（nirdeśyaḥ）、自ら（svayam）意図された（iṣṭaḥ）、……によって否定されていないもの」である。前節までで「自ら」と「意図された」の意味が論じられたので、ここでは残る「のみ（eva）」を扱う。「述べられるべき」という語は義務・可能を表すクリティヤ接辞（-ya）をもつので、論証の場で「述べられるもの」なら何でも主張になるかのような誤解が生じうる。「のみ」はそれを防ぐ、という説明である。parallel は PV IV 87。
L 102:2
J それゆえ、ここ（『集量論』の定義）では語根 iṣ（意図する）の過去分詞語尾（niṣṭhā）は（限定の）要因とはならないが、（『正理門論』の定義にある）「得ようと望まれた（īpsita）」という語では、（それが）まさに要因となる。
N ディグナーガは初期の『正理門論』（Nyāyamukha）では主張を「自ら所証として得ようと望まれた（īpsita）もの」と定義した。ダルマキールティによれば、そこでは「望まれた」という語自体が「所証としてのみ」という限定を含むので「のみ」は不要だが、『集量論』の「意図された（iṣṭa）」は「述べられるべき」と結びつくため、その働きをもたない。それで「のみ」が別に必要になる、というのである。文法的な論点で解釈の難しい箇所である（parallel は PV IV 88）。
L 102:3
J それ（「のみ」）によって、成立していない論証因（asiddhahetu）などが（主張であることを）否定される。
N たとえば「音声は無常である、目で見られるものだから」と言うとき、「音声が目で見られるものであること」は成立しておらず、本来なら論証を要する。しかしそれは論証の手段として出されたもので、所証として立てられたものではない。「自らの形のみによって」、すなわち「所証としてのみ」という限定は、こうしたものを主張から除く。ディグナーガ自身も PSV でこの点を説明している。

# II.2.5 | 「自ら意図された」の趣旨のまとめ | svayam iṣṭa
G 「自ら意図されたもの」という限定から、二つの帰結が出てくる。①意図されていないものと混ざった所証はありえないので、意図されていない部分が否定されても誤りではない。②論争の文脈（prakaraṇa）に入っていないもの、とくに一般的なものが問われているときの特殊な性質は、所証にならない。

## II.2.5.1 | 意図されないものが混じった所証はない | aniṣṭasaṃsṛṣṭa
L 103:1
J このこと（すなわち、論者自身によって意図されたものが推論されるべきもの（anumeya）であると述べたこと）によって、意図されていないものと混ざっている（場合の）意図されたものも所証（sādhya）ではないこと、そしてそれ（意図されていない部分）が否定されても、主張（pakṣa）と論証因（hetu）を述べたことに誤りはないことが知られるべきである。所証をあるがままに（否定しては）いないからである。
L 103:2
J たとえば、（「作られたものだから」という因が、ヴァイシェーシカの意図する）「虚空の属性であることと同一の基体に内属する無常性」が無いことをも論証してしまう（としても誤りではない）ように、である。
N ヴァイシェーシカ派は、音声を虚空（ākāśa）の属性と考える。そのため、彼らが「音声は無常である」と言うときの無常性は、「虚空の属性であること」と同じ基体（音声）に内属する無常性という特殊なものになる。仏教徒の因「作られたものだから」はそうした特殊な無常性を論証しないばかりか、むしろその否定を導く。しかし論争で意図されているのは単なる無常性なので、それは誤りにはならない。parallel は PV IV 90。

## II.2.5.2 | 文脈外のものは所証でない | aprakaraṇāpanna
L 104:1-2
J そしてまさにこのこと（すなわち、推論の際には論書（śāstra）に依拠しない、と（ディグナーガが）述べたこと）によって、文脈に入っていないものを主張にすることも退けられた。たとえば、「音声は無常か、常住か」という文脈で、「音声は、別の感官によって把握される普遍と同一の基体に内属する無常性をもつ」（と主張する場合）である。
N ディグナーガは PSV で、「自ら」という語は推論の場で論者が自派の論書に頼らないことを示す、と説明した。この原則から、論争の論点になっていない学説上の細かな規定を主張に持ち込むことも許されない。例はヴァイシェーシカ説で、音声性という普遍は耳で把握されるが、無常性そのものは別の仕方で知られる、といった学派内の規定を指す。
L 104:3-4
J なぜなら、論書に依拠しているならば、その（論書の）内容を主張にすることは適切であろうし、あるいは対論者がそれを知りたいと望んでいる場合も（そうであろう）。そうでなければ、これはまったく無関係なおしゃべりにすぎず、注意を払うに値しないであろう。論書に依拠していない二人が何かを吟味するときに、論点になっていないものを主張にする、どんな機会があるだろうか。

## II.2.5.3 | 一般が問われるとき特殊は文脈外である | sāmānya, viśeṣa
L 105:1-2
J （反論）特殊は一般を含意するので、それ（特殊）が成立すれば、意図されたもの（一般）もすでに成立したことになる。（答え）そうではない。（所証は）理解する者（対論者）の望みという文脈によって（決まる）からである。
N 反論者は「特殊な無常性を論証すれば、一般的な無常性も当然論証される。だから特殊を主張に立ててもよい」と言う。ダルマキールティは、何が所証かは相手が何を知りたいかという文脈で決まる、と答える。
L 105:3-4
J まさにそれゆえ、「所証である性質が意図されていることは文脈によって知られる」と言われるのである。なぜなら、一般を求める者が必ずしも特殊への限定を求めているわけではないし、また別の特殊については論争がありえないからである。
N 引用はダルマキールティ自身の偈（本書の前の箇所、PV IV 46ab にあたる）である。「別の特殊については論争がありえない」とは、相手が一般的な性質しか問題にしていないとき、特定の学派の特殊な規定は論争の対象になっていない、という意味であろう。
L 105:5
J また、論書を介して論争するのでもない。そのときにはそれ（論書）が欠かせないもの（つまり文脈そのもの）になるからである。
L 105:6
J また、このような（学説上の）性質は、どの教義にも立たない人に対しては、（喩例において）随伴する（anvayin）ものとして（成立して）いるわけではなく、また（それを論証する）誤りのない論証因もない。
N 学派独自の特殊な性質は、その学説を認めない人にとっては、同類例（sapakṣa）に見いだされることもなく、それを確実に導く因もない。だから論証の対象にはなりえない。
L 105:7-8
J また、「第二のものを伴う」論証（sadvitīyaprayoga）もすでに退けられた。論書に依拠する場合でも、文脈を越えるならば過大適用になる、と述べられた。
N 「第二のものを伴う論証」は、前の箇所（校訂本 14,5 以下、II.2.2.2）で批判されたチャールヴァーカの論証。後半はダルマキールティ自身の偈（PV IV 52 にあたる）を指す。
L 105:9-10
J それゆえ、文脈に入ったものだけ、すなわち限定詞をもたない性質そのものだけが、所証である、あるいは（所証として）聞かれるべきである。そうでなければ、別の論点に移ること（arthāntaragamana）によって敗北（avasāda）することになろう。
N 「別の論点に移ること」は、ダルマキールティの『論争の理論』（Vādanyāya）で敗北の立場（nigrahasthāna）の一つとして論じられる（VN 21,2–3 参照）。論争で問われていない学説を持ち出すことは、論点をずらすことにほかならない。

# II.2.6 | 「否定されていない（anirākṛta）」の意味 | anirākṛta, k.26–32
G 主張は、知覚の対象・推論・権威（聖典や自分の言葉）・世間の承認のいずれによっても否定されていてはならない。この節ではまずその四つの基準の全体を説明し、次に一つずつ詳しく論じる。

## II.2.6.1 | 四基準の概説 | k.26–27
### II.2.6.1.i | 四つの基準 | k.26ab
L 106
J そして、この所証の承認（sādhyābhyupagama）は、
V 107
J 知覚の対象・推論・権威（āpta）・世間に広く認められたこと（prasiddha）によって否定されていない（もの）、（第26偈前半）
L 108:1-2
J 「述べられるべきもの」である。「述べられるべきもの」であるとすれば、知覚の対象と推論と権威と世間の承認とによって否定されていない承認が、（それを論証する）論証因を必要とする（ということである）。
N 第26偈前半は、ディグナーガの主張の定義（PS III 2）のうち「知覚の対象・推論・権威・世間の承認によって否定されていない」という部分をそのまま取り込んでいる。つまり、主張とは論証因によって証明されるべきものであり、すでにほかの正しい認識手段で否定されているものは、それに当たらない。
L 108:3
J 知覚について「対象（artha）」と言うのは、感官による認識の中にはまちがった対象をもつものもあるので、それを除いて、正しい認識手段（pramāṇa）の対象だけを取るためである。
N たとえば眼病の人には月が二つ見える。そうした錯覚の認識に反するからといって主張が否定されるわけではない。主張を否定しうるのは正しい知覚の対象だけだ、ということを「対象」という語が示す。

### II.2.6.1.ii | 否定されたものは疑わしくないので主張でない | k.26cd
L 109
J （問い）では、否定されたものは、なぜ主張でないのか。
V 110
J 疑わしいものについて論証因が述べられるからである。覆されたものは、論証因の依りどころ（āśraya）ではない。（第26偈後半）
L 111:1-2
J 「覆された」とは、（知覚と推論という）二つの正しい認識手段によって否定された（という意味である）。（そのような主張は、）反対のことについて正しい認識手段がはたらいているので、対抗する正しい認識手段の依りどころにはならない。相反する二つのものについて、一つの基体に正しい認識があることはありえないからである。
N たとえば「火は冷たい」という主張は、知覚によって「火は熱い」ことがすでに確定しているので、それを論証する因（対抗する認識手段）がはたらく余地はない。parallel は PV IV 91cd。
L 111:3-5
J また主張は、（論証因の）対象を示すために述べられる。それ（主張）が否定されているときには、（その対象を）対象とするもの（すなわち論証因）がありえないので、（それは）主張ではない。それゆえ、疑わしいものが、論証因のはたらきの対象である。
N 論証とは、まだ決まっていないこと（疑わしいこと）を決着させる営みである。すでに反対のことが確定しているものは論証の対象にならないので、主張とは呼べない。

### II.2.6.1.iii | 四基準と三種の推論 | k.27
V 112
J 推論の区別によって、その否定は四種と説かれた。（第27偈前半）
L 113
J この主張の否定は、推論を三つに分けて、四種として示された。
N ディグナーガは否定の基準を四つ挙げたが、ダルマキールティによれば、それは知覚に加えて、推論を三つ（ふつうの推論・権威・世間の承認）に分けたものである。parallel は PV IV 92ab。
V 114
J そのうち、承認（abhyupāya）は結果（を因とする推論）の一部であり、世間の取り決め（jagatsthiti）は本質（を因とする推論）の一部である。（第27偈後半）
L 115
J 権威の言葉は結果を特徴とする徴表（liṅga）であり、世間の承認は本質を特徴とする（徴表）である。
N ダルマキールティは正しい論証因を、結果因（kāryahetu）・本質因（svabhāvahetu）・非認識因（anupalabdhi）の三種とする。信頼できる人の言葉は、その人が正しく見たことの「結果」として生じるので、結果因の一種とみなされる。一方、世間の承認とは「語は話し手の意図どおりに何でも指しうる」という語の本質にもとづくので、本質因の一種とされる。parallel は PV IV 92cd。

## II.2.6.2 | 四基準の個別的な説明 | āpta, prasiddha, pratyakṣa, anumāna
### II.2.6.2.i | 権威（āpta）によって否定されていないこと | āpta
#### II.2.6.2.i.a | 論書と自分の言葉はともに「権威」に含まれる | śāstra, svavacana
L 116:1-3
J 自分であれ他人であれ、事物をあるがままに見ることにもとづいて言葉を発すると認められている者が、権威（āpta）である。その（人の）言葉は、事物がそのとおりであることなしには生じない。それゆえ（言葉は）その（事物のあり方の）結果である。その（事物のあり方）は、自らの結果（である言葉）によって示されて、自らと反対のことを認めることを妨げる。
N ここから四つの基準を一つずつ説明する。まずディグナーガの言う「権威（āpta）」。信頼できる人の言葉は、その人が事物を正しく見たことの結果として生じるので、言葉から逆に事物のあり方が推論できる。これが、権威の言葉が「結果を因とする推論」の一種とされる理由である。parallel は PV IV 93。
L 116:4-5
J このように、自分の言葉と論書とを一つにまとめて、似ていることから一つのものとして（ディグナーガは「権威」と）述べた。自分（の言葉）が正しい認識手段でなければ言葉がはたらかないのと同様に、論書に依拠しないならばその（論書に）説かれていることについての考察は（はたらか）ない。このように、（論書が）論議の文脈の基盤であるときには論書は（主張を）否定するものとなる、という趣旨を述べるために、似ていることを示そうとして、それ（論書）を自分の言葉と一緒に述べたのである。
N 自分の発言と矛盾する主張（自語相違）と、自分が依拠する論書に矛盾する主張（聖典相違）とは、ディグナーガの「権威による否定」に一括される。どちらも、自分で認めた言葉が自分の主張を否定するという点で共通するからである。parallel は PV IV 93–95。
L 116:6-8
J まさにそれゆえ、（ディグナーガは）ここで例も似たものを挙げる。「認識対象をもつ正しい認識手段は存在しない」と。正しい認識手段が存在しなければ、論書も自分の言葉もありえないからである。（この例は）自分の言葉との矛盾については明白な例であるが、聖典（āgama）については方向を示しただけのものである。こちら（聖典との矛盾）の例は、「ダルマ（善）は死後に不幸を与える」である。
N 「正しい認識手段は存在しない」と言えば、その発言自体が正しい認識手段であることも否定されるので、自分の言葉と矛盾する。ディグナーガが PSV（PS III 2cd への注）で挙げた例である。一方、聖典と矛盾する例としては、聖典が「善は死後に幸福をもたらす」と説くのに反する主張が挙げられる。parallel は PV IV 96–97。

#### II.2.6.2.i.b | 論書が正しい認識手段となる条件 | śāstra pramāṇa
L 117:1
J （善などの）主題（dharmin）の確定はそれ（論書）に依存しているので、それが否定されると、（主題という）基体が消えてしまうから、（その）特殊についての考察がはじまらない。それゆえ、このような領域では、必ず論書を正しい認識手段とするべきである。
N 善（dharma）や悪のように目に見えない事柄は、論書によってはじめて論議の主題として立てられる。その論書を否定すれば主題そのものがなくなり、「善は死後に何をもたらすか」といった議論はできなくなる。そのような領域では、論書を（いわば）認識手段として扱わなければならない。
L 117:2-3
J （反論）では、どうして「聖地での沐浴などは悪（adharma）を浄めない」と（仏教徒が言うこと）が、承認されたこと（論書）との矛盾にならないのか。（答え）見えないことを教えるすべての論書がこのように（沐浴が悪を浄めると）説いているわけではないので、（それを）否定しても誤りはない。
N ヒンドゥー教の聖典には、ガンジス川などの聖地で沐浴すれば罪が浄められると説くものがある。仏教徒がこれを否定するのは聖典との矛盾ではないか、という反論である。parallel は PV IV 107d。
L 117:4-5
J なぜなら、自分が認めたことの基盤である論書と矛盾する者が打ち負かされるのであって、他の者は（打ち負かされ）ない。（その論書を）認めていないからである。また、沐浴によって清浄になると説くその者にとっても、この主張内容は（彼自身の）論書の自分の言葉によって否定されるからである。
L 117:6-7
J 「悪は貪りなどを根とする」というのは、すべての論書における定説である。貪り・怒り・迷いのない者に罪（pāpa）があるとは認められないからである。その定説は、沐浴などが罪を浄めるという説を否定する。原因が鎮まらなければ、（原因から生じた）結果は断たれないからである。ちょうど、粘液性の病気が、甘いもの・冷たいもの・油っぽいものによっては（治らない）ように。
N インド医学（アーユルヴェーダ）では、甘く冷たく油っぽいものは粘液（kapha）を増やすとされるので、粘液性の病気を治すどころか悪化させる。同様に、罪の原因である貪りなどの煩悩を取り除かずに、体を水で洗っても罪はなくならない。しかも「悪の根は貪り・怒り・迷いである」ことは、沐浴を説く論者の論書も認めているので、彼の説はその論書自身と矛盾する。parallel は PV IV 107c。
L 117:8-9
J まさにそれゆえ、論書に説かれた事柄についての考察は、主として矛盾を指摘することから成る。（すなわち、）知覚できるものと知覚できないものという（二種の）対象について、事物の力によってはたらく正しい認識手段によっても、自分の言葉によっても否定されない論書、それが受け入れられるべきである。
N 論書の内容を吟味するには、①見えるものについては知覚・推論と矛盾しないか、②見えないものについてはその論書の中で自己矛盾がないか、を調べる。この二重の検査に合格した論書だけが受け入れられる（PV IV 107ab–108 に対応）。ダルマキールティが聖典の権威を認める範囲は、このように非常に限定されている。

#### II.2.6.2.i.c | 否定（bādhā）と妨げ（pratibandha）の区別 | bādhaka, pratibandhaka
L 118:1-2
J 論書をもつ者であっても、その（論書の）対象でない事物について矛盾したことを述べた場合には、否定（bādhā）ではなく妨げ（pratibandha）があるだけであろう。両者が同等の立場にあるからである。ちょうど自分の言葉（との矛盾）の場合と同じである。そしてそのときには、その（主張）は自分の言葉と矛盾するのであって、論書と（矛盾するの）ではない。
N 「否定（bādhā）」とは、正しい認識手段によって主張が覆されること。「妨げ（pratibandha）」とは、同じ重みしかない二つの言明が互いにぶつかり合い、どちらも確定できない状態をいう。知覚や推論で確かめられる事柄について論書と違うことを言っても、論書はその事柄の認識手段ではないので、主張を「否定」することはできず、単に自分の前言と食い違うだけである。parallel は PV IV 98。
L 118:3-4
J その二つのうち、正しい認識手段を伴っている方が、他方を否定するものとなる。そうでなければ、どうして論拠を欠いた主張が、同等の立場にある主張を、あるいは事実に即した推論を、否定できようか。
N parallel は PV IV 99–100。
L 118:5-6
J また、聖典（āgama）が（それ自体として）正しい認識手段であることは否定された。それゆえ、この（論書との矛盾という）誤りは、（論書を）認めたうえでの考察の場合にあるのである。
N ダルマキールティは、聖典が独立の認識手段であることを認めない。論書との矛盾が主張の誤りになるのは、論者が自らその論書を受け入れて議論している場合に限られる。parallel は PV IV 101。
L 119:1-2
J まさにそれゆえ、承認（abhyupāya、すなわち論書）は、推論の外にあるものではないけれども、対象領域の違いを示すために（推論とは）別に立てられた。（それが主張を）否定することを認めるからである。そうでなければ過大適用となるか、あるいは別に立てたことが無意味になるだろう。
N 論書の権威は、前に見たように結果因にもとづく推論の一種なので、本来は「推論による否定」に含まれる。それでもディグナーガが別に数えたのは、「目に見えない事柄」という特別な領域を扱うことを示すためだ、とダルマキールティは説明する。parallel は PV IV 102。
L 119:3
J 自分の言葉も別に立てた理由は、言葉だけの発言において妨げ（が生じること）にある。
N parallel は PV IV 103。
L 120:1
J （反論）正しい認識手段でないことは論書についても同じである。だから、そこでも（否定ではなく）妨げがあるだけにせよ。
L 120:2
J （答え）なぜなら、妨げというものは基体があるときに生じるからである。たとえば、発言（の存在）が成立していれば、（その発言が）正しい認識手段であることとそうでないこととが互いに（妨げ合う）。あるいは、ある女性（の存在）が成立していれば、子を産む性質とそうでない性質とが（妨げ合う）。その（妨げ）は性質に関わるものである。
N 「私の母は石女である」という発言を考えるとよい。母という女性が存在することは成立しているので、「子を産んだ」と「子を産まない」という二つの性質がその女性の上でぶつかり合う。妨げは、こうして共通の基体の上で性質どうしが衝突するときにだけ起こる。
L 120:3-5
J しかし、主題そのものが成立していないところでは、どこで、何によって、何が妨げられようか。論議の文脈そのものがないからである。それゆえ、（論者は）主題を確立することによって、論書を（正しい認識手段として）確立する。だからそれ（論書）は（主張を）否定するものなのである。
N 善のように目に見えない主題は、論書によってしか立てられない。論書を受け入れなければ主題自体がないので、妨げ合う基体もない。逆に主題を立てて論じる以上、その論書を認識手段として受け入れていることになり、論書は主張を否定する力をもつ、という論理である。
L 121:1-2
J （問い）では、正しい認識手段をもたないその論書が、どうして主題を確立するのか。（答え）正しい認識手段として認められているからである。
L 121:3-5
J それならば、まさに自分の承認が（論書に）正しい認識手段であることを与えて、主題を確立するのである。そして、他の性質を再び拒むのもその同じ（承認）である。だから、論書との矛盾は自分の言葉との矛盾と異ならない。それゆえ、（論書との矛盾は）妨げにすぎず、否定ではない。
N 論書が主題を立てられるのは、結局のところ論者自身がそれを認めているからにすぎない。とすれば、論書と矛盾する主張とは、自分の認めたことと自分の主張とが食い違う状態であり、本質的には自語相違と同じである。parallel は PV IV 105ab。

#### II.2.6.2.i.d | 論書と自分の言葉は実は異ならない | abhyupagamavirodha
L 122:1-4
J （問い）では今や、この二つ（論書との矛盾と自分の言葉との矛盾）の違いは何か。（答え）何もない。（問い）では、なぜ別々に述べるのか。（答え）文が異なることによって、そう（区別）されうるのであろう。
L 122:5-6
J 前の（文）によって確立されたことを、後の（文）が否定する、というのが承認との矛盾（abhyupagamavirodha）である。まさにそれゆえ、（ディグナーガは『正理門論』で）「以前の承認によって」と言っている。
N ディグナーガは『正理門論』（NMu）で、主張の否定の一つとして「以前に認めたこととの矛盾」を挙げている。ダルマキールティによれば、これは以前の文（論書）と後の文（主張）との矛盾であり、文が別々である点だけが自語相違と違う。
L 122:7
J 同じ一つの文が自らの意味と矛盾しているものが、自分の言葉と矛盾するもの（svavāgviruddha）である。たとえば、「推論は正しい認識手段ではない」（という主張）である。
N 「推論は認識手段でない」と言う人は、その主張を言葉で相手に理解させようとしている時点で、言葉から意味を推し量るという推論の働きに頼っている。だからこの一文は自分自身の意味と矛盾する。同じ例は『正理一滴』（NB）III 52 にもある。

#### II.2.6.2.i.e | 論書は否定するか妨げるか | pratibandha
L 123:1-3
J （問い）正しい認識手段でないものが、どうして妨げにさえなるのか。（答え）まさにそれゆえ、すなわち同等の立場にあるからである。なぜなら、そこでどちらか一方が正しい認識手段であるならば、（それは）成立にほかならず、妨げではない。正しい認識手段によって、正しい認識手段でないものが否定されるからである。
L 123:4-5
J （反論）それゆえ、承認によって正しい認識手段である論書は、あらゆる事物について否定するものにほかならない。（答え）では、承認という点で違いがないのに、どうして一方は正しい認識手段であり否定するものであって、他方はそうでないのか。だからこれはとるに足らない（説）である。また、その（論書の）完全な認識手段性は、人の意志によって作られたもの（にすぎない）。
N 「論書は承認されているので、どんな事柄についても主張を否定できる」という説を退ける。承認された点では自分の言葉も同じなのだから、論書だけを特別扱いする理由はない。論書の権威は、人がそう認めたというだけのものである。

#### II.2.6.2.i.f | 権威による否定がなぜ主張の誤りか | pakṣadoṣa
L 124:1-2
J （反論）自分の言葉との矛盾と承認との矛盾とにおいて、妨げが誤りであるとしても、それでもそこからは事柄についての疑いが生じるだけである。それは誤りのない主張を述べた場合でも同じである。だからどうして（それが）主張の誤りになるのか。
N 論証の前の主張は、誤りがなくても相手にはまだ疑わしい。だから「疑いが生じる」ことは主張の誤りの理由にならない、という反論である。
L 124:3-4
J （答え）実に、その発言から不確定が生じるから誤った発言をした者となるのではない。そうではなく、どれだけの言葉によって裏づけられるべきであるにせよ、それを裏づけないからである。（論者は）ありうべき自分の意図を、主張の言葉によって示すべきである。
L 124:5-6
J そしてそれ（意図）は、正しい認識手段による否定があるときにありえないのと同様に、一つのもの（主題）に相反する二つのことを結びつける場合にもありえない。なぜなら、他人のための推論では、言葉の長所と短所が問題とされるのであって、事柄の（長所・短所）ではないからである。事実に即さない言い方をしたことで、話し手が非難されるからである。
N 自語相違の主張は、一つの主題に相反する二つのことを言うので、論者が何を意図しているのかを相手に示すことができない。他人のための推論とは言葉による論証なので、言葉として成り立たないことが、そのまま主張の誤りになる。

#### II.2.6.2.i.g | 以前の承認との矛盾も自語相違である | pūrvopagamavirodha
L 125:1-2
J （問い）自分の言葉との矛盾と承認との矛盾とに何の違いもないならば、以前の承認との矛盾には、どんな対象領域の違いがあるのか。（答え）何らかの教義に依拠しなければ考察がはじまらないところでは、それ（教義）に必ず依拠しなければならない。欠かせないものだからである。それだけがその（以前の承認との矛盾の）妨げの対象領域である。自分の言葉と矛盾することを述べるのは、あらゆるところに（ありうる）。
L 125:3-4
J ここでも、この「必ず他（の論書）に依拠すること」とは何であろうか。その同じ人が、その事柄を他人の口を借りて確立しておきながら、再びそれを覆すのである。
N 結局、論書との矛盾とは、自分が論書という「他人の口」を通じて確立したことを自分で覆すことであり、自語相違の一種にほかならない。ただ、目に見えない事柄のように論書なしには議論できない領域でだけ問題になる、という点で領域の違いがある。

### II.2.6.2.ii | 世間の承認（prasiddha）によって否定されていないこと | prasiddha
#### II.2.6.2.ii.a | 語は話し手の意図どおりに何でも指しうる | śabdayogyatā
L 126:1-2
J また、世間の承認（prasiddhi）も、それと矛盾する主張内容を否定する。人の意志に従う「意図された語によって指示されうること」は、事物について否定することができないからである。言語慣習（vyavahāra）から生じるその性質が、「世間の承認」という語で言われている。
N ディグナーガが挙げた例は「月（śaśin、兎をもつもの）は月（candra）ではない」という主張である。語と意味の結びつきは人々の取り決め（約束）によるので、ある語がある物を指すことは否定できない。だから「śaśin は candra と呼ばれない」と主張すれば、世間の承認によって否定される。parallel は PV IV 109–110。
L 126:3-4
J なぜなら、あらゆるものは本来、（すでに）作られた語であれ、まだ作られていない語であれ、（それによって指示されるのに）適合している。（語は）ただ意志だけによってはたらくからである。それ（世間の承認）を妨げる者は、ただ事物に従うだけの、未来のあるいは過去の、語の適合性（yogyatā）によって否定される。
N 語はもともと特定の物と自然に結びついているわけではなく、人がそう呼ぼうと決めれば何でも何とでも呼べる。この「何にでも適用されうること」が語の適合性である。parallel は PV IV 111–112。
L 127
J まさにその適合性の力によって、あらゆる語は実際にこれ（すべての事物）に結びつけられている。だから、たとえ（ある語が実際に）それ（ある物）に（適用されること）が知られていなくても、（ディグナーガは）それが成立していると言う。「推論が非共通的（asādhāraṇa）であるために推論が成り立たない場合でも、語による世間の承認という矛盾する意味によって退けられるものは主張ではない」と。
N 引用はディグナーガの PSV（PS III 2cd への注）。ここから、この文中の「非共通的であるために」という語をどう解釈するかが論じられる。parallel は PV IV 113。

#### II.2.6.2.ii.b | 否定のための論証因は非共通的になる（第一の解釈） | asādhāraṇa
L 128:1-2
J まさにそれゆえ、（「月は candra ではない」と論証しようとする）否定の因は非共通的（asādhāraṇa）である。どこにも「candra でないもの」は成立しないからである。（ディグナーガは）このこと（世間の承認）が否定できないことを示して、このように言ったのである。あるいは、対抗する正しい認識手段がないことによって（世間の承認が）確定していることを（示して）。
N 非共通的な因（asādhāraṇa）とは、主題にだけあって、同類例（sapakṣa）にも異類例（vipakṣa）にもない因で、不確定因の一種である。どんなものも candra と呼ばれうるので、「candra と呼ばれないもの」という同類例はどこにも見つからない。だから、それを論証しようとする因はすべて非共通的になる。parallel は PV IV 114ab。
L 128:3-4
J なぜなら、その（適合性の）否定は推論によってなされるはずである。知覚によっては適合性は確定されないからである。そしてそこ（その推論）では、すべての論証因が非共通的になる。「存在すること」でさえ随伴（anvaya）をもたない、という（ディグナーガの）例は、このことを示すためのものである。
N ディグナーガの挙げた論証は「月は candra ではない、存在するから」というもので、ふつうならどこにでもある「存在性」でさえ、ここでは同類例をもたない。どんな因を使っても同じだ、ということを示す例だとダルマキールティは解釈する。parallel は PV IV 114cd–115。

#### II.2.6.2.ii.c | 「語による世間の承認」は相違決定を除く | śābdaprasiddha
L 129:1-2
J 語は取り決め（saṅketa）に依存し、それ（取り決め）はただ意志だけに依存する。だから語によって成立するものに不成立はない、ということを示して、（ディグナーガは）「語による世間の承認によって」と言ったのである。
N parallel は PV IV 116。
L 129:3
J （論理的な）結びつきが疑われるもの（因）は、疑いがあるので（所証を）成立させない。また、長いあいだ見られなかったものについても、再び思いつきが生じることが見られるので、（その可能性が）ありうるときには、その非存在はふつうの人には確定できない。それゆえ、（ディグナーガは）正しい認識手段から確定すると述べることによって、推論の領域では相違決定（viruddhāvyabhicārin）がありえないことを、言外の含意（arthāpatti）によって示している。
N 相違決定（viruddhāvyabhicārin）とは、相反する二つの主張をそれぞれ別の、一見正しい因が論証してしまう状態で、ディグナーガは不確定な似因の一つに数えた。ダルマキールティは、正しい推論は事物の本質に根ざしているので、本当の推論の領域ではこれは起こりえないと考える。ディグナーガが「確定する」と言ったことは、それを暗に示しているというのである。parallel は PV IV 117。
L 130:1-3
J これによって、知覚と推論（による否定）も説明された。両者とも正しい認識手段である点に違いはないからである。もし一方（の因）がその（正しい因の）定義を満たしていても、対抗する（因）が見られるというなら、知覚についても同じことになろう。そして、知覚には、正しい認識手段の定義以外に、（知覚だけを）絶対的な論証手段として確立するような別の特徴はない。（もしあるなら）その特徴を欠くために推論は正しい認識手段でないことになろうが、（そうではない）。
N 正しい推論は知覚と同じく正しい認識手段である。三相を満たした因に対抗する因がありうるなら、知覚に対抗する知覚もありうることになり、どちらも信頼できなくなってしまう。
L 130:4-5
J （反論）（ディグナーガは相違決定を似因の）一つとして数えようと意図したのであり、対抗する（因）が示されていない（因）は正しい認識手段であるから、誤りはない。（答え）そのような（因）について、「これには対抗するものが存在しない」と確定することがありえようか。（定義上）違いのないものについて、一方で見られたものが他方には無いと確定することはできないからである、とすでに述べた。
N 「対抗因が示されていないかぎり因は正しい」とすると、いつ対抗因が現れるかわからないので、ある因が本当に正しいかを決して確定できなくなる。最後の「すでに述べた」は第2章の議論を指すとされる。
L 130:6-8
J また、正しい認識手段の定義は、人の思いつきによって述べられるのではなく、事物のあり方によって（述べられる）。そしてそれ（事物のあり方）がこのように確定できないものであるなら、そのように疑わしい定義は実際の運用に適さない。ちょうど、主題所属性（pakṣadharmatva）などについて疑いがある場合のように。また、（推論の）定義には「知（jñāna）」という語が含まれているからでもある。
N 推論とは確定した知である以上、「後で対抗因が現れるかもしれない」ような不確かな状態は、そもそも推論の定義に合わない。
L 130:9-11
J 述べられた定義をそなえた推論においては、その定義をもつ対抗者はありえないので、推論においては相違決定はありえない。そして、その「一つとして数えようとする意図」も、この領域では認められない。その（相違決定の）領域については、（のちに）述べるであろう。
N ダルマキールティは、相違決定が起こるのは、事物の力によらず論書（聖典）に依拠した議論の場合だけだと考える。その説明は本章の後の部分で行われる。
L 130:12-14
J このように、（ディグナーガは）正しい認識手段が否定するものであると言うことによって、それ（正しい認識手段）から確定（が生じる）と述べている。それによって、対抗主張（がありうる）という想定を退けている。それによって、推論の領域では相違決定が存在しないことを示唆しているのである。

#### II.2.6.2.ii.d | 肯定のための論証因も非共通的になる（第二の解釈） | asādhāraṇa
L 131:1-3
J あるいは、（ディグナーガは、月を candra と）言う世間の人にとって推論がないことを述べたのである。それによって、（世間の）認識（pratīti）は推論とは対象が異なる、と言われたことになる。それによって、事物の存在・非存在に従う推論とは対象の異なる認識は、事物の力によってはたらくのではない、と示唆されたことになる。
L 131:4-5
J なぜなら、月が candra であることを望まない人は、ほかのどんな認識を望むだろうか。それゆえ、その人に対しては、（「月は candra と呼ばれうる」という）推論は喩例を欠く。だから（ディグナーガは）「非共通的」と言ったのである。
N 第二の解釈では、逆に「月は candra と呼ばれうる」ことを推論で示そうとしても、相手が月にさえそれを認めないなら、ほかに喩例として出せるものがない。だから肯定の推論も非共通的になる。世間の承認は推論ではなく、人々の取り決めにもとづく別種の認識だ、というのがここでの論点である。parallel は PV IV 118–120。

#### II.2.6.2.ii.e | 非共通性は対象が一つしかないからではない | ekārtha
L 132:1-2
J なぜなら、これはこの一つの例だけを念頭において言われたのではなく、世間の認識とのあらゆる矛盾に共通する特徴として（言われた）からである。同様に、「シンシャパー樹は木ではない」と言う場合にも、（世間の承認による）否定があるからである。
N 「月という物は一つしかないから、喩例がなくて非共通的になるのだ」という解釈を退ける。「シンシャパー（樹の一種）は木と呼ばれない」という主張も同じく世間の承認に反する。parallel は PV IV 121。
L 132:3-4
J ここ（月の例）でも、世間では樟脳（karpūra）や銀などにも（candra という語が用いられるのが）見られるので、非共通性はないことになろう。また、取り決めによってはたらくものには、いかなる非共通性もない。
N サンスクリットの candra は「月」のほか「樟脳」や「金・銀」なども意味する。したがって、対象が一つしかないから喩例がない、という説明は成り立たない。parallel は PV IV 122。
L 132:5-7
J なぜなら、もしそれ（candra であること）がどこかで成立するなら、それは事物の力によって成立したことになる。（一方、それが）認識によって成立していると認めるなら、月においても（それを）妨げることはできない。もしそれが事物において成立しているなら、月においても妨げられないのは当然である。もしその事物が無いなら、月において（それを）妨げても何の誤りもない。
L 132:8
J それゆえ、事物に限定されない取り決めの語から生じる性質には、あらゆるものが適合する。意志には妨げがないからである。
N 「candra と呼ばれること」は事物そのものの性質ではなく、人々の取り決めによる性質である。だから、それはどんなものにも当てはまりうる。parallel は PV IV 123–125。

#### II.2.6.2.ii.f | まとめ | k.28–29
L 133
J これによって、取り決めに従う語には何ら意味の限定はなく、そしてここ（世間の承認）においてそれら（の語の適用）を否定すれば矛盾がある、と言われたことになる。
N parallel は PV IV 127。
V 134-135
J 原因にもとづいて語が適用される（naimittikī）語の（語源的な）意味、あるいは語の究極的な意味を妨げる者は、彼（ディグナーガ）によって（世間の承認によって）否定されるとは述べられていない。（第28偈）
N たとえば candra は語源的には「喜ばせるもの」の意だが、「月は人を喜ばせない」と言っても世間の承認に反するわけではない。世間の承認が守るのは「その語でその物を呼べる」ということだけである。parallel は PV IV 128。
V 136-137
J それゆえ、対象領域の違いを示すために、（世間の）認識も、推論の外にあるものではないけれども、前（の承認）と同様に、別に立てられたのである。（第29偈）
N 前の第27偈では、世間の承認は本質因にもとづく推論の一種とされた。それでも別に数えられるのは、権威（論書）の場合と同様、扱う領域が違うからである。parallel は PV IV 129。
L 138
J 以上が二つの中間偈（antaraśloka）である。

### II.2.6.2.iii | 知覚の対象によって否定されていないこと | pratyakṣārtha, k.30–32
L 139:1-2
J 知覚との矛盾についても、さまざまな側面をもつ（音声の）うち、聴覚においてそれだけが単一のものとして現れる側面、それを否定する場合にだけ矛盾がある。（ほかに）関係するものがないので、混ざり合った姿で現れる認識は見られないからである。たとえば、「音声は聞かれるものではない」（という主張）である。そして、「対象（artha）」という語はそのためのものである。
N ディグナーガが知覚との矛盾の例として挙げたのは「音声は聞かれない（aśrāvaṇa）」である（PSV）。音声には無常性・作られたものであることなど多くの性質があるが、耳による知覚にじかに現れるのは「聞かれるもの」という音声そのものの姿だけである。だから知覚に反するのは、その姿を否定する場合に限られる。PS の「知覚の対象（pratyakṣārtha）」の「対象」という語は、このことを示す。parallel は PV IV 131–132。
V 140-141
J まさにその姿（rūpa）が、そこ（知覚）での対象である。それ以外のものは、排除（vyāvṛtti）を特徴とする、実在でないものとしての普遍（sāmānya）である。それゆえ、それ（普遍）は感官の領域ではない。（第30偈）
N ダルマキールティ認識論の基本で、知覚がとらえるのは個々の実在（自相、svalakṣaṇa）だけである。「無常性」のような一般的性質は、他のものからの排除によって概念的に構成された普遍（共相）であって、知覚の対象ではない。parallel は PV IV 133。
V 142-143
J それゆえ、一般的な性質は知覚の対象でないことが成立するので、（それを）否定しても（知覚による）否定はない、ということが、「聞かれる」という語によって明らかにされた。（第31偈）
V 144-145
J （個別の実在は）どのようにしても言葉では表せない姿をもつので、また（「聞かれること」は）その（実在の）成立に依拠しているので、また（否定は）その力によって起こるので、感官の領域が「聞かれる」という語によって述べられたのである。（第32偈）
N 知覚の対象そのもの（自相）は言葉では言い表せない。そこでディグナーガは、その自相にもとづいて成り立つ「聞かれるもの」という表現で、感官の領域を指し示した、という説明である。parallel は PV IV 134–135。
L 146
J 以上が中間偈である。

### II.2.6.2.iv | 推論によって否定されていないこと | anumāna
#### II.2.6.2.iv.a | 「壺は常住である」は推論によって否定される | nityo ghaṭaḥ
L 147:1-3
J 推論との矛盾についても、たとえば「壺は常住である」（という主張）である。これは、（壺が）打撃に耐えるのを見る人には、錯誤によって（そう思われる）ことがあろう。しかしそれ（常住性）は、壊れたのが見られる壺のように、生起などがあるのでありえない。
N ディグナーガの挙げた推論との矛盾の例である。壺は作られたもの（生起するもの）であり、実際に壊れるのが見られる。だから推論によって無常であることが知られ、「壺は常住」という主張はそれと矛盾する。
L 148:1-2
J （反論）いかなる壺も無常ではない。そこ（壊れた壺）でも、顕現が隠れるだけだからである。（答え）われわれは、同じ状態にとどまらないことを無常性と言い、同じ状態にとどまることを実在（tattva）と言うのである。それ（同じ状態にとどまらないこと）は、壊れた（壺）にある。それが滅によるのか隠没によるのか、ということにここでこだわりはしない。
N 反論者はサーンキヤ派。サーンキヤ派は因中有果論（satkāryavāda）に立ち、結果は原因の中にすでに存在し、生起はその顕現、消滅は隠没（tirobhāva）にすぎないと説く。ダルマキールティは、名前はどうあれ、壺が以前と同じ状態を保てない以上それが無常性だ、と答える。
L 148:3-4
J そして、知覚されるべき（現在の）中間の姿が、前と後の両端にも存在すると言う者は、事物の区別の確立を否定することになる。そうすると、サットヴァ・ラジャス・タマス（の三要素）や精神（caitanya）についても、互いの姿を区別して確立することができなくなるからである。
N 結果（たとえば凝乳）が、生起する前（牛乳の段階）にも消滅した後にも存在するなら、ものを区別する根拠がなくなる。サーンキヤ派自身が立てる三要素（グナ）や精神（プルシャ）の区別もできなくなってしまう。
L 148:5-6
J なぜなら、そこ（三要素などの区別）においても、非認識（anupalambha）以外に、確立の根拠は何もないからである。それゆえ、知覚されうるという特徴をもつこの凝乳などが牛乳などの中に知覚されないので、あるいは牛乳が（凝乳の中に知覚されないので）、そこには存在しない、というこの（推理）は正当である。
N 知覚されうるはずのものが知覚されないことから、その非存在を知る、というのが非認識因（anupalabdhi）である。サーンキヤ派が三要素を区別できるのも、一方に他方の姿が見られないからにほかならない。同じ論理で、牛乳の中に凝乳が見られない以上、牛乳の中に凝乳は存在しない。

#### II.2.6.2.iv.b | 原因の中に結果が存在するという説の論駁 | satkāryavāda
L 149:1-2
J （反論）凝乳などは牛乳などの中に（存在すると）認めることがまさにある。（それは）推論である。（凝乳を生む）能力のないものからは（凝乳は）生じないからである。（答え）そのような（知覚されうる）ものの存在は、推論の対象ではない。
N サーンキヤ派は『サーンキヤ・カーリカー』第9偈で、結果が原因の中に存在する理由の一つに「能力あるものが可能なものを作るから」を挙げる。ここはそれにもとづく反論である。parallel はダルマキールティ『プラマーナ・ヴァールッティカ自注』（PVSV）16,23–24。
L 149:3-5
J なぜなら、それ（そのようなものの存在）は、まさに見られうるものとしてある。もしそれ（凝乳）が（牛乳の中に）あるなら、中間の状態（凝乳になったとき）のように知覚されるはずである。なぜなら、その特徴を捨てることこそがそのものの消滅であり、別のあり方になることが別異性である。異なることとは、相反する本質を特徴とするからである。このことはほぼすでに述べた。
N 「見られうるものとして存在する」ものが見られないなら、それは存在しない。また、知覚されうるという特徴を失った状態で存在するなら、それはもう別のものであり、凝乳そのものとは言えない。最後の文は第2章の議論（PVin 2, 89,14–90,1 = PVSV 20,21–22）を指す。
L 149:6
J それゆえ、生起（という事実）からは、その原因がそれを生み出す本質をもつことが成立するのであって、その（結果が原因の中に）存在することが（成立するの）ではない。
L 150:1
J （反論）もし存在しないものから生起があるなら、どうして牛乳から兎の角が（生じ）ないのか。非存在である点では同じなのに、どんな違いがあるのか。（答え）そうではない。原因の本質が異なるからである。
N 因中無果論（結果は原因の中にはなく新たに生じる）に対する、サーンキヤ派の定番の反論である。
L 150:2-3
J 牛乳は、それ（凝乳）を本質とするものではないが、凝乳を生み出し、兎の角を生み出さない、という本質をもっている。（問い）それ（その本質）はどこから来たのか。（答え）自らの原因から生じたのである。このように、原因の本性の連鎖は始まりがない。
L 150:4
J それゆえ、兎の角は、それを生み出す本質をもつ原因が存在しないから生じない。もう一方（凝乳）は、その（原因）が存在するから（生じる）のである。
N 牛乳の中に凝乳が前もって存在する必要はない。牛乳が「凝乳を生み出す本質」をもっていれば十分であり、その本質も無始以来の原因の連鎖から来ている、というのが仏教側の答えである。
L 151:1-4
J では、この能力（śakti）とは何か。それはその存在そのもの（凝乳）なのか、それともまったく別の何かなのか。もしそれ（凝乳）そのものであるなら、（牛乳の中でも凝乳と）まったく同じように知覚されるはずである。違いがないからである。違い（がある場合）については、すでに述べた。
N サーンキヤ派は「凝乳は牛乳の中に能力（潜勢力）として存在する」と言う。もしその能力が凝乳そのものなら、凝乳と同じように見えるはずである。見え方が違うなら別のものだ、というのはすでに述べたとおりである。parallel は PVSV 16,24–26。
L 151:5-6
J もし別のものであるなら、別のものが存在するときに、どうしてそれ（凝乳）が存在することになろうか。（そう言うのは）比喩的な表現にすぎないことになろう。これによって、「別のあり方」（という説）も退けられた。
N 能力が凝乳とは別のものなら、牛乳の中にあるのは凝乳ではなく別のものであり、「凝乳がある」と言うのは比喩にすぎない。こうして、結果は原因の中に別のあり方で存在するというサーンキヤ説も否定される。ここで「主張の定義」をめぐる長い議論（第II部）が終わり、次から論証因の分類に移る。
