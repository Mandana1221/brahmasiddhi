# IV.2.2 | 二つの相がともに欠ける場合 | dvayor asiddhau sandehe ca
G 論証因の三相のうち、「同類（sapakṣa）にあること＝随伴（anvaya）」と「異類（vipakṣa）にないこと＝排除（vyatireka）」の二つがともに成り立たない場合を論じる。二つが逆の形で成り立つと「相違因」（逆の結論を証明してしまう）になり、一方が不成立で他方が疑わしいか、両方とも疑わしいと「不定因」になる。後者の代表例として、ニヤーヤ派などの「生きた身体には自己（アートマン）がある、呼吸などがあるから」という論証が詳しく検討される。

## IV.2.2.1 | 二相が逆に成立する場合：相違因 | viruddha
### IV.2.2.1.i | 相違因の二つの例 | kṛtakatva, prayatnānantarīyakatva
L 400:1
J 二つ（の相）が成立しないとき、（その論証因は）相違（因）（viruddha）である。たとえば、（音声が）常住であることを論証する際の「作られたものであること（kṛtakatva）」と「努力の直後に生じること（prayatnānantarīyakatva）」とである。
N ここから、これまでの「一つの相が欠ける場合」に続き、「二つの相が欠ける場合」に入る。太字の見出し句（dvayor viruddho 'siddhau ca）はダルマキールティ自身の『ニヤーヤ・ビンドゥ』（NB）3.81 以下とほぼ同じ文言で、NB 3.83–89 の相違因の説明とよく対応する（校訂本の脚注）。「音声は常住である、作られたものだから」という論証では、論証因が実際には「無常」のほうと結びついているので、主張と逆の結論を証明してしまう。
L 400:2-3
J この二つ（の論証因）は、同類にはなく、異類にはある。それゆえ、二つの相（随伴と排除）が成立しない、すなわち逆のかたちで成立する、ということである。したがって、この二つの論証因は、（所証と）逆のことを証明するので相違（因）である。
N 常住を証明したいとき、同類は「常住なもの」（たとえば虚空）、異類は「無常なもの」（たとえば壺）である。「作られたもの」は虚空にはなく壺にはあるから、第二相・第三相がちょうど裏返しに成り立っている。だからこれは単に「決まらない」のではなく、「逆を証明する」相違因になる。

### IV.2.2.1.ii | 「意図に反するもの」を別立てしない理由 | iṣṭavighātakṛt
L 401:1-3
J （反論）第三の相違（因）として、「意図されたものを損なうもの（iṣṭavighātakṛt）」があるではないか。たとえば、「眼などは他のためのものである。集合体であるから。寝台・座具など（の部分）のように」（という論証）である。これは、意図された「集合していない（精神）のためにあること」の逆を証明するので、相違（因）である。それがどうして（ここで）述べられていないのか。
N サーンキヤ派は、身体や感官のような「寄り集まったもの（saṃghāta）」は、寄り集まっていない純粋精神（プルシャ）のために存在すると論じる。ところが実際に言葉で掲げた主張は「他のためにある」だけである。寝台や椅子は「他のため」にあるが、その「他」は人間の身体、つまりこれも集合体である。だから論証因は、本当に言いたいこと（集合していないもののため）の逆、つまり「集合体のため」を証明してしまう。ディグナーガ以来、これは「意図に反する相違因」と呼ばれてきた。対応は NB 3.90 以下。
L 401:4-6
J （答え）所証であることに違いがないからである。なぜならこれ（第三のもの）は、所証の逆を証明するという点で、この二つ（の相違因）と違わないからである。というのも、意図されたもの（iṣṭa）と述べられたもの（ukta）とでは、所証であることになんの違いもない、とすでに述べた。
N 主張命題を論じた箇所（校訂本 p.12 以下）で、「所証（sādhya）」とは言葉にしたものだけでなく、論者が証明したいと意図しているものでもある、と述べられていた。そうであれば、意図されたものの逆を証明するのも、所証の逆を証明することにほかならず、別の種類を立てる必要はない。
L 401:7-9
J もし違いがあるなら、相違（因）と同じように、（正しい）論証因についても、意図されたものを証明するものを別に述べなければならなくなるだろう。しかし（両者のうち）一方だけを述べることによって、所証であることに違いがないことが示されている。まさにそれゆえ、その（所証の）逆を証明する相違（因）もまた一つだけである。
L 401:10-11
J ただし、（論証式の）用い方の違いによってその区別がある。ある場合には、言葉（で述べたこと）と（その言外の）含意とによって（所証が示され）、ある場合には、（論者の）意図によって、性質と有法とを限定語として取り入れることによって（所証が示される）。

（反論）それなら、相違（因）と同様に、（正しい）論証因もこのように区別されないのはなぜか。

（答え）区別したい人を誰が止めようか。
N 区別があるとしても、それは論証因の定義の違いではなく、所証の示され方（言葉そのものか、言外の意図か）の違いにすぎない。区別したければ正しい論証因の側でも区別してよいが、本質的な違いではない、という余裕のある答え。
L 401:12-13
J 相手は、述べられてはいないが含意によって引き出される意図されたものを言わんとしている。そこで、その（相手の）意図にもとづいて「意図されたものを損なうもの」と言われるのであって、定義が異なるからではない。それゆえにこそ、「別には説かれない」と（すでに）述べたのである。
N NB 3.91–92 にもほぼ同じ趣旨の説明がある（脚注）。

### IV.2.2.1.iii | 「集合体であるから」はやはり相違因である | saṃghātatva
L 402:1-2
J （反論）集合したものが、集合していない他者を助けるという決まりはないので、（この論証因は）不定（因）にほかならず、相違（因）ではない。そもそも「集合したものは他者を助ける」というこの決まりとは、いったい何なのか。
N 反論者は、この論証因は逆を証明する（相違因）のではなく、そもそも何も決めない（不定因）だと言う。集合体が他を助けるという必然的関係すら確かでないからである。
L 402:3
J たとえある結果について、（互いに）結びつきあった諸事物の総体が集合体であるとしても、原因が必ず結果をもつわけではない。妨げなどがありうるからである。したがって（この論証因は）逸脱しているにほかならない。
N 原因の総体があっても、何かに妨げられれば結果は生じない。だから「集合体である」から「他を助ける」は必然的に出てこない、という主張。
L 402:4
J もし、眼などは妨げられることのない助けをするものであって他者を助ける、と言うなら、この場合にも、（それらは）集合したもの（だけ）を助ける、という結びつきの決まりがどこにあるのか。
L 403:1-2
J （答え）助けるたびごとに、それら（眼など）から、助けられるもの（の側）に別の本質が生じるのであるから、このように役立つものたちについて、これ（集合体であること）は、さまざまな本質への助けを証明するものである。同時に一つ（の不変のもの）に多くの助けをすることを証明するものではない。
N ダルマキールティの答え。眼などが何かを「助ける」とは、相手に新しい性質・状態を生じさせることである。そうであれば助けられる側は変化するもの、つまり無常で集合的なものでなければならない。常住で変化しない純粋精神は、助けを受け入れる余地がない。
L 403:3-4
J 助けが（助けられるものとは）別のものであるなら、「それ（助けられるもの）への助けではない」などの（過失）もすでに述べた。（助けられるものにも助けにも）どちらにも作用しないものたちは無意味であるから、それ（精神）のためにあることを証明するのは矛盾している。
N 「助け」を精神とは別のものとすると、精神そのものは何も変わらないので、本当に精神を助けたことにならない、という論法は、第1章・第2章や『プラマーナ・ヴァールッティカ』（PV）でも繰り返し使われる。
L 403:5-6
J それゆえ、助けをなす眼などは、何かを付け加えうるもの（ādheyātiśaya）にだけ助けをなす。それ（助けられるもの）は、それゆえ単一不変の本質をもつものではない。だから（この論証因は）相違（因）である。
N 結局、「集合体であるから他のためにある」という論証は、「変化しうるもの（＝集合体）のためにある」を証明してしまい、サーンキヤ派が意図する「不変の精神のためにある」と正反対になる。だから不定因ではなく相違因だ、という結論。

## IV.2.2.2 | 一方が不成立で他方が疑わしい場合 | vacanāt
L 404:1
J （「二つが成立しないとき、相違因である」という句の）「また（ca）」という語は、二つ（の相）のうち一方が成立せず、他方が疑わしいときには、（その論証因は）逸脱にあずかる（＝不定因である）、ということを示すためのものである。たとえば、「（ある人は）貪りを離れている、あるいは一切を知る者である。話すから」（という論証）である。
N 「一切知者（sarvajña）」や「離貪者（vītarāga）」を「話すこと」から証明しようとする論証は、仏陀の一切知を論証しようとする者、あるいはそれを否定しようとする者（ミーマーンサー派など）の間で問題になってきた。ここでは肯定の側の論証が取り上げられている。対応は NB 3.93–95。
L 404:2-3
J ここでは、排除が成立せず、随伴が疑わしい。一切知者や離貪者は（私たちの知覚から）遠く隔たっているので、そこに話すことなどがあるのかないのかは疑わしいからである。
N 「話すこと」は、一切知者でない普通の人（異類）にも見られるので、「異類にない」（排除）は成り立たない。他方、一切知者（同類）が話すかどうかは、一切知者そのものが見えないので確かめようがなく、随伴は疑わしい。だから論証は何も決めない不定因である。前の部分で論じられた「話すから貪りがある」という逆の論証と対になっている。

## IV.2.2.3 | 二相がともに疑わしい場合：「呼吸があるから自己がある」 | prāṇādimattva
L 405:1-3
J 「疑わしいときにも、逸脱にあずかる」。（ここには前の句から）「二つの」（という語）が続いている。随伴と排除がともに疑わしい場合である。たとえば、「生きている身体は自己（ātman）をもつ。呼吸など（prāṇādi）をもつから」（という論証）である。
N 「生きた身体には自己がある、呼吸・まばたき・生命などがあるから」は、ニヤーヤ派（ウッディヨータカラなど）が自己の存在を証明するために用いた有名な論証である。彼らはこれを、同類（ほかに自己をもつと知られたもの）がなく、異類（壺など）からの排除だけで成り立つ「排除のみの論証因（kevalavyatirekin）」の代表例とした。ダルマキールティはこれを、随伴も排除も疑わしい不定因だと批判する。対応は NB 3.96–97。

### IV.2.2.3.i | 「呼吸」は疑いの原因である | saṃśayahetu
L 406:1-2
J なぜなら、自己をもつものと自己をもたないものとのほかに、呼吸などがそこに生じうるような別の群は存在しないからである。自己が生じていること（ātmavṛtti）とその否定とによって、すべてが包括されるからである。また、この二つのうちどちらか一方に（呼吸などが）あるという確定もない。そのような本性をもつと（すでに）よく知られたもの（のなか）に（呼吸などがあることが）成立していないからである。
N 世界のすべては「自己があるもの」か「自己がないもの」かのどちらかであり、第三の群はない。だから呼吸は必ずどちらかにあるはずだが、どちらにあるのかを確かめるには、自己があると確かに知られた別の実例が必要になる。そんなものは見つからないし、自己がないと確かに知られたものに呼吸がないことも、実は確かめられない（後述）。NB 3.98–100 に対応。
L 406:3-5
J それゆえ、生きた身体に結びついた呼吸などは、（自己をもつ・もたない）両方の本性の外にあることはないので、その両者から排除されることはない。また、（そのうちの一方に）随伴するのでもない。一方の本性（をもつもの）においてさえ成立していないからである。まさにそれゆえ、随伴と排除とが疑わしいので、不定（因）である。そこから所証とその反対とが確定されないからである。
N 「両方から排除されない」とは、呼吸が「自己あり」と「自己なし」のどちらか一方には必ず含まれる、という意味。「随伴しない」とは、どちらに含まれるかがわからない、という意味。結果として、「自己がある」とも「自己がない」とも決まらない。NB 3.101–104、3.107–108 に対応。

L 407:1-3
J また、（これは何の理解も生まない）無理解（apratipatti）（の因）でもない。何らか（の主題）と結びついているからである。結びつきがない場合には、疑い（vimarśa）は生じない。たとえば、音声について「眼で見られること（cākṣuṣatva）」から（は何の疑いも生じない）ように。（他方）結びつきがあれば、「これはいったい何と結びついているのか」と、どうして疑わずにいられようか。
N 「眼で見られること」は音声にはそもそも無い（第一相の不成立）ので、何の疑いも起こさない。これに対して呼吸は、主題である生きた身体には確かにある。だから「何も知らせない」のではなく、「疑いを起こす」原因、すなわち不定因になる、という区別。
L 407:4-5
J 結びつきが十分に知られていないために、ある特定の人との結びつきについて、（まったく）結びつきがないということはありえないので、（それが誰なのか）迷った人が疑うように、ここでも、（呼吸などが）すべて（＝自己あり・自己なしの両群）に含まれないことはありえないので、疑いが生じる。（何も）理解されないこと――それは「どちらでもない」という理解や（第三のものではないかという）疑いのかたちをとる――は、（論証因が）両者の外にある場合に起こるだろう。（両者の）内に含まれているのに、どうして（何も）理解されないことがあろうか。
N たとえば、ある品物が誰か特定の人の持ち物であることは確かだが、それが誰なのかがわからないとき、人は「あの人のか、この人のか」と迷う。結びつきがあることは確かなので、疑いが生じる。呼吸の場合も同じで、自己あり・自己なしのどちらかには必ず属するから、どちらなのかという疑いが起こる。
L 407:6-8
J （反論）それなら、「眼で見られること」からも（疑いが生じると）してよいではないか。

（答え）そうではない。「結びつきがないから（疑いは生じない）」と言ったのである。それゆえ、（呼吸などのような）共通しない（asādhāraṇa）（論証因）は、疑いの原因である。
N 「共通しない不定因（asādhāraṇānaikāntika）」とは、主題（ここでは生きた身体）にしかなく、同類にも異類にも実例が見つからない論証因のこと。ディグナーガはこれを不定因の一種に数えた。

L 408:1-3
J とりわけ呼吸などは（疑いの原因である）。自己は（知覚から）遠く隔たっているので、（何かに）それがあることもないことも成立せず、それゆえ、そこに呼吸などがある（かない）かも（成立しない）からである。また、（自己は呼吸とは）別の事物であって、（呼吸がその）結果であることが（確かめられて）いない以上、（そこから自己は）成立しないからでもある。
L 408:4-5
J なぜなら、呼吸などと自己との因果関係は成立しないからである。それ（因果関係の確定）は、知覚と非知覚とに依拠するからである。それゆえ、結びついていないものがある（からといって、別のもの）がある、ということにはならない、という疑いがある。
N ダルマキールティの体系では、正しい論証因は「本質（svabhāva）」か「結果（kārya）」か「非知覚（anupalabdhi）」の三つだけである。自己と呼吸は別の事物だから、呼吸が自己を証明できるとすれば、呼吸が自己の結果である場合に限られる。しかし因果関係は「Aがあるときに Bが見え、Aがないときに Bが見えない」という知覚と非知覚によってしか確かめられない。自己は決して知覚されないので、因果関係は確かめようがない。

### IV.2.2.3.ii | 「呼吸」は「排除のみの論証因」としても正しくない | kevalavyatirekin
#### IV.2.2.3.ii.a | 反論：排除が一方的だから知らせる | aikāntikavyatireka
L 409:1-2
J ある者は言う。「呼吸などは、まさに自己を知らせるものである。その排除が一方的（aikāntika）だからである。なぜなら、呼吸などは異類（＝自己のないもの）からだけ退いていて、同類からは（退いてい）ない。存在しないもの（である同類）から退くことはありえないからである。
L 409:3-4
J それゆえ、一方的な随伴をもつ（論証因）と同じように、一方的な排除をもつ（論証因）も、知らせるものにほかならない。しかし『聞かれるものであること（śrāvaṇatva）』はそうではない。両方から退いているからである」と。
N ニヤーヤ派の「排除のみの論証因（kevalavyatirekin）」の擁護。自己をもつ同類（主題以外で自己があると知られたもの）はそもそも存在しないから、呼吸は同類から「退く」こともない。退くのは異類（壺など）からだけである。これに対し、ディグナーガが不共不定因の例とした「音声は常住である、聞かれるものだから」の「聞かれること」は、常住なもの（同類）からも無常なもの（異類）からも退いているので、両者は違う、という主張。PV IV 205–206 以下に並行する議論がある。

#### IV.2.2.3.ii.b | 答え：「呼吸」には排除が成立しない | vyatirekāsiddhi
L 410:1-4
J それゆえ、このような種類の排除を説く者は、（実は）不可離の関係（avinābhāva）を述べていることになる。なぜなら、そのように「自己がないところには決してない」と言えば、意味の上から、他と交わることのない（呼吸などの）自己における存在が示されるからである。それこそが不可離の関係である。まさにそこから随伴も成立するので、（それは）排除のみの（論証因）ではない。
N 「自己がないところには呼吸は決してない」という一方的な排除をまじめに主張すれば、それは「呼吸があるなら必ず自己がある」と言うのと同じであり、それはすでに随伴でもある。だから「随伴なしで排除だけ」という論証因はありえない、という指摘。
L 410:5-8
J そして不可離の関係とは、結びつき（pratibandha）である。そして、自己との結びつきは、同一性（tādātmya）と（そこからの）生起（tadutpatti）とのほかにはない、とすでに述べた。そしてこの二つは、知覚なしには成立しない。それゆえ、呼吸などは自己と不可離のものではない。
N 第2章で確立された原則。必然的な結びつき（pratibandha）には、①同一の本質であること（本質因の場合）、②そこから生じること（結果因の場合）の二種しかない。どちらも、最終的には知覚によって確かめられなければならない。
L 410:9-11
J まさにそれゆえ、自己がなくなるときにこれ（呼吸など）がなくなる、ということもない。それがあればこそ、（この論証因は）「排除をもつもの」と言われるのに。なぜなら、結びついていないものは、何かがなくなっても、必ずなくなるわけではないからである。それゆえ、（主題にしかない）特殊な（論証因）には、排除もなく、随伴もない。
L 410:12-15
J 先生（ディグナーガ）は、単に見られないことに依拠して、「聞かれるものであること」に排除がある、と述べた。（しかし）それだけでは非存在の理解はない、とすでに述べた。そうでなければ、（それは）疑いの原因ですらないことになろう。なぜなら、あるものがある所にありえないのに、それを知覚することによってそこで疑いが生じる、というのは不合理だからである。
N ディグナーガは「聞かれること」について、同類にも異類にも「見られない」という意味で排除があると語った。しかしそれは「見られない」だけで、「ない」と確定したわけではない。もし本当に「ない」と確定しているなら、主題に「聞かれること」を見ても疑いは起こらないはずである。不共不定因が「疑いの原因」とされること自体、排除が確定していない証拠だ、という論法。PV IV 207、PVin 第2章 65–66 偈などを参照（脚注）。

L 411:1
J （反論）無我（nairātmya、自己がないこと）は呼吸などの非存在によって遍充されているので、自己がなくなれば呼吸などもなくなる。

（答え）そうではない。結びついていない（呼吸などの）非存在によって、（それに対して）何の役にも立たない（自己の）非存在が遍充されることは、成立しないからである。
N 反論者は、「自己がないところには呼吸がない」という逆の遍充（vyatirekavyāpti）を主張する。ダルマキールティは、呼吸と自己の間に結びつきが証明されていない以上、その遍充も成り立たないと答える。PV IV 208 以下に対応。
L 411:2-5
J もし呼吸などが、それ（自己）を本質とすることによって、あるいはそこから生じることによって、自己と結びついているのであれば、それらは、それ（自己）がなくなることによってなくなるだろう。そのときには、呼吸などの非存在が無我を遍充するだろう。それ（自己）がないときに（呼吸などが）ないことが成立することによって遍充（が成立する）のであるが、それは成立しない。逆の場合（＝自己がない場合）に結びつきが成立しないからである。というのも、知覚と非知覚とによって、その二つの結びつきを知ることができるのだが、その二つは、まったく知覚を超えたもの（である自己）については成立しないからである。
L 411:6-9
J また、自己をもたないもののうち、どれが呼吸などの非存在によって遍充されているのか。もし壺などだと言うなら、ほかの所で見られたことのないそれ（自己）が壺などにない、ということがどうして（わかる）のか。それゆえ、排除の知られていないものについては、排除の遍充は成立しない。なぜなら、呼吸などは、どこかで見られることによってのみ、あるともないとも理解されるのであって、自己はそうではないので、それがあるともないとも理解されないからである。
N 「自己のない壺には呼吸がない」と言うためには、まず壺に自己がないことを知っていなければならない。しかし自己はどこでも見られないのだから、壺に自己がないことも確かめられない。異類の実例（喩例）そのものが成り立たない、という鋭い指摘。PV IV 211–212 に対応。

L 412:1-3
J また、（反論者が）「もし生きた身体が自己をもたないなら、呼吸などがないことになってしまう。自己がないから。壺などのように」と言う（帰謬の論法）も、因果関係がない場合には成立しない。なぜなら、前に「非知覚において、（あるものの）原因でも結果でもないものを否定しても、（何も）知らせない」と述べたからである。そして、自己が（呼吸の）原因であることは、（自己が）見られないので成立しない、とすでに述べた。
N 帰謬（prasaṅga）の形にしても同じことである。「自己がなければ呼吸もないはずだ」と言うには、自己が呼吸の原因だとわかっていなければならない。引用は第2章の非知覚論（PVin 2, p.60）を指す。PV IV 213、PVSV 13 も参照。

L 413:1-3
J （自己が）見られたとしても、排除が成立しないので、（自己の存在は）成立しない。

（反論）壺などが排除の領域（＝異類の実例）である。

（答え）そうではない。このような排除からは、原因の能力は成立しない。他の能力ある原因がそろっているのに結果が生じないことが、別の原因があることを知らせる、とすでに述べた。
N 仮に自己が見えるものだったとしても、壺を異類の実例にしても役に立たない。壺には自己がないだけでなく、呼吸を生む他の条件（知・身体の器官など）もそろっていないからである。ある原因の能力を確かめるには、「他の条件がすべてそろっているのに、それだけが欠けたとき結果が生じない」ことを見なければならない（前の部分 p.111 参照）。
L 413:4-6
J なぜなら、呼吸などの原因である知（buddhi）なども、壺などにはないからである。それゆえ、自己の排除は、（自己に呼吸を生む）能力があるかどうか疑わしい。

（反論）それら知なども、自己がないところにはないだろう。

（答え）そうではない。そこ（知など）については、ほかのものにだけ能力が見られるからである。
L 413:7-9
J まず、眼などによる認識（眼識など）にとっては、それぞれの感官と対象とが原因である。また、先行する損なわれていない認識も（原因である）。それ（先行する認識）が別の対象に気を取られたり妨げられたりすると、後の認識が生じなかったり混乱したりすることなどが見られるからである。意識（manovijñāna）にとっては、先行する損なわれていない認識が（原因である）。
L 413:10-11
J 感官なども、同類の系列（sabhāga）のそれぞれ先行する状態の違いが質料因（upādānahetu）であり、知が補助因（pratyaya）である。このように、これだけのもの（＝感官・対象・先行する認識など）からなるこの自己存在（ātmabhāva、生きた身体）が、随伴と排除をもつので、これこそが（呼吸などの）原因である。（これ以外の）別のもの（＝自己）を想定すれば、無限遡及（anavasthā）になるだろう。
N 仏教の立場からの説明。認識は、感官・対象・直前の認識という条件で生じ、身体の器官も、それ自身の前の瞬間を質料因とし、心を補助因として続いていく。呼吸や生命活動の原因は、このように実際に「あれば生じ、なければ生じない」と確かめられる心身の要素だけで十分であり、その背後に恒常的な「自己」を想定する必要はない。PV IV 216–217 に対応。

V 414-415
J それがあるときに必ず（結果が）生じるもの、それとは別のものを、それ（結果）の原因であると想定するなら、どこにおいても原因の限定がなくなってしまう。（第82偈）
N 結果を生じさせるのに十分な原因が見つかっているのに、さらにそのほかの見えない原因を想定してよいなら、何でも原因として想定できることになり、因果関係の確定がまったく不可能になる。この偈は PV II 24 と同文（脚注）。
L 416
J と、要約の偈（saṅgrahaśloka）にある。

#### IV.2.2.3.ii.c | 排除があるとしても「排除のみ」ではない | na kevalavyatirekin
L 417:1-4
J また、呼吸などは、逸脱（vyabhicāra）という点で「聞かれるものであること」と同じである。

（反論）そうではない。それ（聞かれるものであること）の排除には逸脱があるからである。

（問い）どうして逸脱があるのか。

（反論者）それ（聞かれるものであること）は、異類からだけ排除されているのではない（同類からも排除されている）からである。
L 417:5-6
J （答え）だが、そのように言えば、これ（聞かれるものであること）が同類に随伴しないことが語られているのである。それは他方（呼吸など）にも同じである。それなのに、どうして呼吸などが（聞かれるものであることと）同じでないことがあろうか。
N 「聞かれること」は同類（常住なもの）にない。呼吸も、反論者自身が認めるとおり、主題以外の同類には見られない。どちらも「同類にない」点では同じであり、片方だけを正しい論証因とする理由はない。PV IV 218–219 に対応。ジネーンドラブッディの『プラマーナ・サムッチャヤ注』（PSṬ）がこの箇所を引用している。

L 418:1-3
J また、「異類にだけはない」（という言い方）によって、これ（呼吸など）が同類にはあることが言われている。二重の否定によって、本来の（肯定の）意味に戻るからである。そうでなければ、限定（avadhāraṇa「だけ」）には、それによって除かれるものがないので、何の成果があるだろうか。そしてもし（「だけ」という）限定がないなら、その文（が述べる）排除は、逸脱がないことが成立しないからである。
N 「異類にだけない」と「だけ」をつけるのは、「同類にはない」可能性を除くためである。つまりそれは「同類にはある」と言っているのと同じで、随伴を認めたことになる。逆に「だけ」を外せば、「異類にない」ことの必然性（逸脱しないこと）が言えなくなる。
L 418:4-6
J まさにそれゆえ、（ディグナーガは）「同類にだけある」「異類にだけない」という二つの喩例のうちどちらか一方によって、含意（arthāpatti）によって両方が示される、と説いたのである。それゆえ、このような排除の不逸脱は、随伴のない（論証因）には成立しない。そして成立するとすれば、それは否応なく随伴をもたらす。否定の否定は肯定の形をとるからである。
N ディグナーガの『ニヤーヤ・ムカ』（NMu 3a3、PVSV 18,17 に引用）の趣旨。同類の喩例（随伴の実例）か異類の喩例（排除の実例）のどちらか一方を示せば、残りの一方は意味の上から理解される。随伴と排除は表裏一体であって、片方だけの正しい論証因はない。PV IV 220–221 に対応。

L 419:1
J （反論）存在しない同類からは退くことはないので、（私たちは）「異類にだけない」と言うのだ。

（答え）そうではない。（あなたが同類について言う）「（退くことは）ない」という、その退くことの否定そのものを、存在しないものについて、どうして認めるのか。
N 反論者は「存在しないものについては否定（＝退くこと）を語れない」と言いながら、まさに存在しない同類について「退くことはない」と否定を語っている。自己矛盾である。PV IV 222 に対応。
L 419:2-4
J なぜなら、「非存在の否定、すなわち存在は、存在しないものについてもあるが、存在の否定はありえない」と考える、この神々に愛された人（devānāṃ priya、＝愚か者）は、まことにつまずくことのない智慧をもっている（と皮肉られる）。彼は、それ（存在しないもの）を対象とする否定を認めないのに、「非存在（asadbhāva）」などという言い方はしているのである。この問題は、「存在しないものにおける非存在」（を論じた箇所）ですでに詳しく論じ尽くされている。それゆえここでは詳説しない。
N 「神々に愛された人」は古典インドの論書で相手を愚か者として皮肉る決まり文句。「存在しないものにおける非存在（asati nāstitā）」の議論は第2章（PVin 2, p.53）、PV IV 223 などを指す（脚注）。存在しないものについても否定的な言明は可能だ、というのが仏教論理学の一貫した立場である。

L 420:1-2
J また、自己が存在しないのでもない。（反論者自身が）その存在を証明するもの（＝論証）を行っているからである。（せいぜい）疑わしいものであろう。
L 420:3-5
J また、相手（ニヤーヤ派）によってそのように認められているから、量（pramāṇa）ではない承認によってそのとおりになる、ということはない。（そうなら何でも成り立つという）過大適用になるからである。また、承認の力によって同類・異類を設定して量を働かせる、というのも適切でない。なぜなら、そうであれば自己は聖典によって成立するものとなり、推論によって成立するものではなくなってしまうからである。
N 反論者は「自己をもつ同類は存在しない」と言うが、まさに自己の存在を証明しようとしているのだから、「自己をもつもの」が存在しないとは言えない。存在するかしないかは、まだ疑わしいだけである。また、自分の学派がそう認めているからといって、それで同類・異類を決めることはできない。それでは推論ではなく聖典による証明になってしまう。PV IV 237、PVSV 13,6–9 に対応。

L 421:1-3
J それゆえ、（異類からの）排除があるとしても、呼吸などの、存在しない（とされる）同類からの排除は、疑わしいであろう。自己が疑わしいからである。まさにそれゆえ、異類から（の排除）も（疑わしい）。なぜなら、一方において（必ずあるという）限定が成立したときに、他方から退くことが成立するからである。
L 421:4-5
J なぜなら、そうでなければ、見られたある（異類の）ものにおいては（呼吸などの）非存在が成立しても、見られていないものについては疑いがあることになる。というのも、ある類のすべての個体の違いにはゆきわたっていないが、その類のものにあると見られる性質がある。たとえば地性のもの（pārthiva）における「鉄で傷つけられないこと」のように。
N 異類の実例をいくつ調べても、まだ調べていない異類に呼吸がないとは言えない。ある性質がある類の一部にだけ見られることはよくある。たとえば、地の元素からなるものの大半は鉄で傷つくが、金剛石（ダイヤモンド）のように鉄で傷つかない地性のものもある。（pārthivālohalekhyavat は「pārthiva-alohalekhya」と分けて訳した。「pārthiva-lohalekhya（鉄で傷つくこと）」と読んでも論旨は同じ。）PV IV 238–240 に対応。
L 421:6-9
J また、矛盾が見られない以上、疑いがあるだけである。呼吸などと無我とのあいだに、すでに述べた特徴をもつ矛盾が成立しないので、無我からの排除は疑わしい。なぜなら、（呼吸などが）自己に限定されているなら、その結果を本質とすることによって、呼吸などは無我と矛盾するであろう。しかしそれは成立しない、とすでに述べた。
N 「異類には決してない」と確定できるのは、論証因と異類とが矛盾する（両立しない）とわかっている場合だけである。呼吸が自己の結果であると確定していれば、自己のないところには呼吸はありえないと言えるが、その因果関係が証明できないのだから、矛盾も成り立たない。PV IV 241–242 に対応。

#### IV.2.2.3.ii.d | 排除を認めても自己は証明されない | nānairātmyād ātmā
L 422
J 呼吸などが自己をもたないものから排除されており、それ（呼吸など）があるときには無我が退けられる、ということを仮に認めるとしよう。それでも、「無我でないこと」から、生きた身体に自己が（あるものとして）成立するわけではない。というのも、この（論者）は、（無我の）排除の非存在を、（そのまま自己の）存在として認めはしないからである――ちょうど、（同類からの）排除がないにもかかわらず、呼吸などが同類にあることを認めないように。
N 反論者は「呼吸は同類から排除されていない」と言いつつ、「同類にある」とは認めない。つまり彼は「〜でない、ということはない」と「〜である」とを区別している。それなら同じ論理で、「無我ではない」から「自己がある」を引き出すこともできないはずである。PV IV 242–243 に対応。
V 423-424
J もし論証因が同類から排除されないのであれば、それゆえ論証因は随伴をもつものである。もし随伴をもたず、（しかも同類から）排除されないのであれば、（証明されるのは）「無我ではない」ということであって、「自己をもつ」ということではない。（第83偈）
N 二者択一。同類から排除されないことが「同類にある」ことを意味するなら、論証因は随伴をもつことになり、「排除のみ」ではない。そうでないなら、「無我でない」が言えるだけで、積極的に「自己がある」とは言えない。PV IV 244 に対応。
L 425
J と、要約の偈にある。

L 426:1

L 426:2-3

### IV.2.2.3.iii | 「所量性」も「随伴のみの論証因」として正しくない | kevalānvayin
#### IV.2.2.3.iii.a | 反論：異類が存在しないから随伴のみ | prameyatva
L 428
J また、無為（asaṃskṛta）の存在を否定する論者は、（同類にも異類にも）共通する（不定因である）「量の対象であること（prameyatva、所量性）」をも、存在しないもの（＝異類）には随伴がありえないので随伴が逸脱しない（論証因）であり、「同類にだけある」として、随伴のみをもつ論証因である、と言う。
N 「すべては無常である、量の対象（認識されうるもの）だから」という論証。ディグナーガの分類では、「所量性」は常住なもの（虚空など）にも無常なものにもあるので「共通する不定因」の典型である。ところが、虚空や涅槃のような無為法（常住なもの）の存在を否定する論者（経量部系の仏教徒と考えられる）にとっては、常住なもの（異類）は存在しないので、「所量性」は無常なもの（同類）にだけあり、「随伴のみの論証因（kevalānvayin）」として正しい、と主張される。ジネーンドラブッディの PSṬ がこの説を伝えている（脚注）。

#### IV.2.2.3.iii.b | 随伴のみということはありえない | anvayamātra
L 429:1-4
J （答え）この場合にも、どうして異類から排除されないことがあろうか。あるいは、どうして「同類にだけある」と言えるのか。もし異類にあることが除かれないのなら、この限定（「だけ」）にどんな成果があろうか。あるいは除かれるのなら、どうして排除がないことがあろうか。なぜなら、存在の否定のほかに排除はないからである。
L 429:5-6
J そして、「（異類に）随伴はない」と「（異類からの）排除はない」とは互いに矛盾する。なぜなら、「ない」という随伴の否定、それこそが排除だからである。
N 前の「排除のみ」の批判と対称的な議論。「同類にだけある」と言うことは「異類にはない」と言うことであり、それがすなわち排除である。だから「随伴だけで排除がない」論証因はありえない。

L 430:1-3
J （反論）それでも、話は「存在しないもの（である異類）について排除はありえない」という点に戻ってくる。

（答え）これについても、同じことをもう一度言わなければならない。「存在しないものについて、どうして随伴の否定ができるのか」と。（もし）事物の本性を引き寄せる（ような）否定（だけを考えるの）なら、存在しないものについての否定はありえないであろう。
L 430:4-5
J しかし、否定辞（nañ）の対象は、相対的否定（paryudāsa）だけではなく、絶対的否定（prasajyapratiṣedha）でもある。そしてそれ（絶対的否定）には、存在しないもの（を対象とすること）との矛盾はない。
N インド文法学・哲学で区別される二種の否定。「相対的否定（paryudāsa）」は「非バラモン」のように、否定しつつ別の何か（バラモン以外の人）を肯定的に示す。「絶対的否定（prasajya）」は「〜でない」と純粋に否定するだけで、何も肯定しない。後者なら、存在しないものについても問題なく語ることができる。対応は PSṬ（脚注）。
L 430:6-7
J （反論）それ（絶対的否定）もありえない。否定の領域を示す（はずの）処格（adhikaraṇa）などの意味をもつ格語尾が、（存在しないものには）当てはまらないからである。

（答え）これにはすでに答えた。それゆえ、随伴のみをもつ論証因などというものは、一つもない。
N 「異類には（処格）〜がない」と言うときの「〜には」が、存在しないものには使えない、という反論。これについては第2章（PVin 2.15 以下）ですでに答えた、とする。

#### IV.2.2.3.iii.c | 「所量性」は異類にも随伴しうる | abhāvo 'pi prameyaḥ
L 431:1-3
J また、所量性が異類に随伴することがありえない、ということもない。なぜなら、性質（dharma）には、存在に依拠するもの、非存在に依拠するもの、その両方に依拠するものの三種がある、とすでに述べたからである。

（反論）非存在には、いかなる性質もない。

（答え）その、性質がないということこそが、それ（非存在）の性質ではないか。
N 「性質は三種」というのは、この章の第53偈（＝PV I 205）を指す。たとえば「作られたもの」は存在にだけ、「非存在であること」は非存在にだけ、「無常」などの否定的な性質は両方に依拠しうる。「性質がない」ことも一つの性質として語ることができる、という切り返し。
L 431:4-5
J なぜなら、事物の本性だけが性質なのではないからである。存在しないものも、何らかの仕方で、この言語活動（vyavahāra）の道へと引き入れられる。そうでなければ、それについては言語活動がまったくないことになろう。
L 431:6-8
J また、存在するものについてさえ、究極的には、いかなる性質と有法（性質をもつもの）との関係もない。ただ知（buddhi）がこのような関係を作り上げているだけである、と『（プラマーナ・）ヴァールッティカ』で述べた。そして、知によって作られる結びつけを、存在しないものについて、誰が妨げられようか。
N 仏教論理学では、「性質」と「その持ち主」の区別は、そもそも概念的思考（分別）が作り出したもので、実在の側にあるものではない（PVSV 3,1、PV I 61 など）。そうであれば、存在しないものについても、思考が「性質」を立てることは同じように可能である。

L 432:1-2
J また、「有」「無」「両者」「両者でない」という（四句の）決定も、あれこれの教義を奉じる者たちにとっては、その論証が確定されていないので、一方的に（確定的に）把握するものではないことになろう。それゆえ、どのような仕方であれ、存在しないものを確定する者は、それらを量の対象と言わなければならない。
L 432:3-5
J なぜなら、量は存在するものだけを対象とするのではないからである。量の特徴は、欺かないこと（avisaṃvāda）だからである。それ（ある知）が、有と無とをそのとおりに確立して、もし自分の対象について他（の量）によって否定されないなら、それには量の特徴がある。それゆえ、非存在は量の対象（prameya）である。
N 第1章で「量（pramāṇa）とは欺かない知である」と定義された。その定義に従えば、「ここに壺はない」と正しく知ることも、他の知によって覆されない限り量である。したがって非存在も「量の対象」であり、「所量性」は異類（存在しない常住なもの）にもあることになる。だから所量性は随伴のみの論証因にはならない。

L 433:1
J （反論）非存在というものは何もない。すべてのものは何らかの仕方で存在するからである。

（答え）それらが存在しない、その在り方が非存在である。
L 433:2-4
J また、この者は、兎と角とが存在することを理由に、「兎の角はない」と説く者をあざ笑うが、（実は）自分自身をあざ笑っているのである。「兎の部分としての角はない」と述べる者に対して、「兎もあるし角もある」という答えが何の関係があろうか。
N 「すべては何らかの仕方で存在する」と主張する者は、「兎の角はない」と言う者に「兎も角もある」と反論する。しかし「兎の角がない」とは、兎に属する角がないということであって、兎や角がこの世にないということではない。的外れな反論である。
L 433:5-7
J なぜなら、この者（兎の角はないと説く者）は、角そのものを否定しているのではない。もしそうなら、その（答え）によって反駁されもしよう。そうではなく、兎に属する（角を否定しているの）である。

（反論）もしそうなら、「関係がない」と言うべきであって、「角が（ない）」と言うべきではない。

（答え）いったい、角をもつ動物たちの角においても、単に関係だけが区別されていて、実体の本性は（区別されてい）ないのか。
L 433:8-10
J 本性も（区別されている）。結果ごとに原因の本性が異なるからである。それなら、「関係の非存在を言うべきだ」というこの非難はいったい何なのか。

（反論）角をもつ動物たちには、角の本性の違いがある。（しかし）兎には、そのように異なる本性をもつ何らかの角があるわけではない。

（答え）私たちもまさにそのことを言っているのである。
N 牛の角と鹿の角は、単に別の動物に「属している」だけでなく、それぞれ別の原因から生じた別の本性をもつ角である。だから「兎の角」とは「兎に属する（兎から生じた特有の）角」であり、それがないと言うのは、まさにそういう角が存在しないと言うことにほかならない。
L 433:11-12
J あるいは、「関係がない」と言われるもの、それこそが非存在である。そして、「関係するものはあるが、関係はない」というのは、まことに巧みな言葉の運びである。
L 433:13-14
J （反論）（兎との）関係を受け入れた実体（としての角）もまた、ない（と言うのだ）。

（答え）結構なことだ。もし最初からこう言っていれば、神々に愛された人（＝愚か者）も、こんなに苦労しなくて済んだだろうに。
N 結局、反論者も「兎に属する角という実体はない」と認めざるをえなくなり、それは最初から仏教側が主張していた「非存在」そのものである。皮肉をこめた結び。こうして、非存在も認識の対象になりうること、したがって所量性も異類（非存在）に随伴しうることが示された。

# IV.2.3 | 相違決定 | viruddhāvyabhicārin
G ディグナーガは、同じ主題について正反対の結論を導く二つの論証因が、それぞれ三相をそなえているように見える場合を「相違決定（viruddhāvyabhicārin）」と呼び、疑いの原因に数えた。ダルマキールティは、実在にもとづく正しい推論（本質因・結果因・非知覚因）ではこれは起こりえず、論書の権威にもとづく推論でだけ起こる、と論じる。例として、ヴァイシェーシカ派内部の普遍（sāmānya）の遍在をめぐる二つの論証が挙げられる。

## IV.2.3.1 | 相違決定は実在にもとづく推論には起こらない | anumānaviṣaye 'sambhavāt
L 434:1-3
J （ディグナーガによって）相違決定もまた疑いの原因として説かれた。それはここでは説かれない。推論の領域ではありえないからである。なぜなら、すでに述べた特徴をもつ結果（因）と本質（因）、あるいは非知覚（因）が相違決定であることはありえないからである。そして、これら以外に逸脱しない（論証因）はない。
N 相違決定とは、たとえば A が「X である、P だから」と論じ、B が「X でない、Q だから」と論じて、P も Q もそれぞれ三相をそなえているように見え、どちらとも決められなくなる事態をいう。ディグナーガ『プラマーナ・サムッチャヤ』第3章はこれを六種の不定因の一つとした。ダルマキールティは NB 3.110–116 でも同じ立場をとる（脚注）。
L 434:4-5
J それゆえ、実在を見ることの力によって働くのではない、聖典に依拠する推論にもとづいて、その（聖典の）意味を考察する場面で、相違決定が論証の過失として説かれたのである。論書の著者たちは、事物について誤って、反対の本性を（ものに）帰することがありうるからである。なぜなら、事物のありのままのあり方に即した本質・結果・非知覚（の論証因）においては、（それは）ありえないからである。
N 実在にもとづく推論では、同じものに矛盾する二つの性質が同時にあることはないので、両方の論証が正しいということはありえない。ところが論書（śāstra）の説を前提にした推論では、論書の著者が誤って矛盾する性質を同じものに帰していることがあるので、それぞれの論証が論書の上では成り立ってしまう。PSṬ がこの箇所を伝えている（脚注）。

## IV.2.3.2 | 聖典にもとづく相違決定の例 | sarvagataṃ sāmānyam
### IV.2.3.2.i | 本質因による論証：普遍は遍在する | svabhāvahetu
L 435
J その例は（次のとおりである）。「普遍（sāmānya）は遍在する。あらゆる場所にある自らの関係者（＝個体）と同時に結びついているから。虚空のように」。
N ヴァイシェーシカ派では、「牛性」のような普遍は常住・単一で、多くの個体（牛たち）に内属するとされる。ではそれは個体のある場所にだけあるのか、世界中に遍在するのか。この論証は遍在説の側のもの。チベットの伝承や PSṬ によれば、これはヴァイシェーシカ派のパイルカ（Pailuka）の論証とされる（Analysis）。NB 3.117–119 にも同じ例がある。

L 436:1-2
J その（関係者の）場所に現前している本性をもつことは、それ（関係者）と結びついているという本性だけに付随する。なぜなら、ある場所にないものは、その場所を自らによって覆うことはないからである。
N 論証因（関係者と同時に結びついていること）が、所証（その場所にあること）と本質的に結びついている（本質因である）ことの説明。何かと結びつくには、その場所にいなければならない。
L 436:3-4
J （反論）しかし、色などは虚空の場所にはなく、それ（壺など）の場所にあって壺などに遍く行き渡っているではないか。

（答え）結合（saṃyoga）と内属（samavāya）とによる、この場所と場所をもつものとの関係は、ひとまず置いておこう。私たちは世間的な場所――（他から）切り離された、あるいは切り離されていない（ものとして）現れる知を生じさせうること、を特徴とする場所――にもとづいて言うのである。
N 反論者は、ヴァイシェーシカ流に「ある場所にある」とは結合や内属によって決まるのであって、壺の色は壺に内属しているだけで虚空にあるわけではない、と言う。ダルマキールティは、そうした学説上の位置関係ではなく、ふつうの意味での空間的な場所、つまり「ここにある」と知覚に現れる場所で考えればよい、と答える。
L 436:5-6
J 「別々に成立しているものどうしの関係が結合であり、別々に成立していないものどうしの関係が内属である」というのが論書における規定でもある。それゆえ、自らの存在だけに付随するところの、その（関係者の）場所に現前していることを所証とするとき、それ（関係者）と結びついていることが論証因である。
N 引用されている結合と内属の定義の出典は特定されていない（脚注）。いずれにせよ、ここでは論証因と所証の関係が本質因の関係であることが確認される。

L 437:1
J （反論）自らの基体（＝個体）だけに遍く行き渡る（とする）論者も、その（個体の）場所に現前していることは、まさに認めている。それなら、（この論証が証明することの）何が（相手にとって）望ましくないのか。
N 普遍は個体にだけあるとする説の論者（パイタラ Paiṭhara。Analysis による）も、普遍が個体のある場所に現前することは認める。だからこの論証は、相手もすでに認めていることを証明しているにすぎないのではないか、という反論。
L 437:2-4
J （答え）作用をもたず、一つの個体と結びついている（普遍）は、別の場所に新しい個体が生じたとき、以前にはそこに存在しなかったので、それ（新しい個体）と結びつくことはありえない。それゆえ、異なる場所にあるもの（個体たち）と同時に結びつくことは、すべてに遍く行き渡るものにおいてのみ成立する。それゆえ、一つ（の個体）と結びついている単一のもの（普遍）が、別の場所に移動することなく、その場所にある新しいもの（個体）と結びつくことは、それら（個体）の中間に遍く行き渡っていることと不可離である。日光などが壺などと（結びつく）ように、と。
N 普遍は動かない（作用をもたない）。だから、新しく生まれた牛と「牛性」が即座に結びつくためには、牛性はもともとそこに（つまり個体と個体の間の空間にも）ゆきわたっていなければならない。日光があたり一面にあるからこそ、どこに置いた壺も照らされるのと同じである。こうして遍在説の論証は、本質因として三相をそなえているように見える。

### IV.2.3.2.ii | 非知覚因による論証：普遍は遍在しない | anupalabdhihetu
L 438
J 第二の論証式もある。「普遍は遍在しない。知覚されうる条件を満たしている（upalabdhilakṣaṇaprāpta）のに、それら（個体）の中間には知覚されないから」。
N 反対側の論証。ダルマキールティ自身の非知覚因の形式で立てられている。PSṬ と NB 3.120 にも見える（脚注）。
L 439:1-3
J 知覚されうる条件を満たしているとは、顕現していることである。（普遍は）区別のない（単一の）ものであるから、一つの個体を通して（顕現すれば）すべての個体において（顕現するので）、顕現していないあり方をもたない。（また、知覚の条件である）遮るものがないこと、遠くにないこと、見られうる本性をもつこと、感官が自らの基体（＝個体）を介して結びついていること（もそなわっている）。（これも普遍が）区別のないものであるからにほかならない。そして、基体に内属していないあり方をもたないこと（もそなわっている）。
N ヴァイシェーシカ派の普遍は、個体を介して感官で知覚されるものとされる。しかも普遍は単一で部分がないので、ある所で見えているなら、どこでも同じように見えるはずである。だから個体と個体の間の空間に普遍が知覚されないのは、知覚の条件がそろっているのに見えない、ということであり、そこには普遍が「ない」と言える（非知覚因）。
L 439:4-5
J （反論者が知覚には）同じ場所にある基体と感官との結合が必要だとするなら、基体と同じ場所にあるあり方と同じ場所にないあり方とをもつ（普遍）が区別のない（単一の）ものであることと矛盾する。見られうる本性と見られえない本性（をあわせもつこと）などの矛盾も述べるべきである。
N 「中間の普遍は、基体（個体）がないから見えないのだ」と弁明すると、普遍は「基体と同じ場所にある部分（見える部分）」と「そうでない部分（見えない部分）」をもつことになり、単一で部分がないという前提に反する。
L 440
J それゆえ、この非知覚（因）と本質（因）とは、互いに矛盾する事柄を証明するので、同じ一つのもの（主題）について疑いを生じさせる。
N こうして、ヴァイシェーシカ派の論書の前提の上では、「普遍は遍在する」と「普遍は遍在しない」の両方が三相をそなえた論証で証明されてしまう。これが相違決定である。

## IV.2.3.3 | 相違決定は承認にもとづいてのみ起こる | abhyupagamabalapravṛtta
L 441:1-2
J 論書の著者は、二つ（の論証因）がそれぞれ矛盾する性質と不可離であることを見ずに、その二つを矛盾しないものとして示して説いた。それで相違決定が起こりうるのである。しかし、事物に即した推論においては、矛盾する二つ（の性質）が同じ一つのものにありえないのと同様に、それらに遍充される二つ（の論証因）も（同じものに）ありえない。だからその二つが同じ一つのものにあることはない。
L 441:3-4
J それゆえ、ここ（実在にもとづく推論）には相違決定はない。だからこれ（相違決定）は、承認（abhyupagama）の力によって生じるものである。
N 相違決定の原因は、論書の作者がもともと両立しない性質（たとえば「単一であること」と「場所ごとに見え方が違うこと」）を同じ普遍に認めてしまったことにある。現実の事物では矛盾する性質は同居しないので、本当に三相をそなえた二つの論証因が対立することはありえない。

## IV.2.3.4 | ディグナーガの挙げた例について | kṛtakatva, śrāvaṇatva
L 442:1-2
J ところで先生（ディグナーガ）は、方向を示すだけのために、「音声は無常である。作られたものだから」「（音声は）常住である。聞かれるものだから」という例を挙げた。なぜなら、ここでは、量（の裏づけ）のない三つのことを認めなければならないからである。（すなわち、個々の音声とは）別のものである音声性という普遍（があること）、（それが）感官によって知られること、そして常住であることである。
N ディグナーガは『プラマーナ・サムッチャヤ自注』（PSV ad PS III 23b）で、相違決定の例としてこの一対を挙げた（脚注）。第二の論証は、ヴァイシェーシカ派の「音声性という普遍が耳で聞かれ、常住である」という学説を認めて初めて成り立つ。だから、ここでも相違決定は承認に依存している。
L 442:3-6
J それゆえ、これ（第二の論証）という量が働くのである。それゆえ、これ（承認にもとづく論証）は、事物の力によってもたらされた「作られたものであること」を妨げることはない。また、「作られたものであること」の文脈は聖典に依拠するものではないので、（そこに）聖典（にもとづく論証）を持ち出すことはできない。さらに、「聞かれるものは常住である」という結びつきは証明されるべきもの（で、まだ証明されていないもの）なので、（第二の論証因の）不逸脱も成立しない、と。
N 結論として、ディグナーガの例は相違決定という類型を示すための便宜的なものにすぎない。「作られたものは無常である」は実在の力にもとづく正しい推論であり、学説上の承認にすぎない「聞かれるものは常住である」によって覆されることはない。これで論証因の過失（似因）の考察が終わる。
