# III.2.1.2 | 非知覚因（その一）：非知覚とは何か、どう成立するか | anupalabdhi
G ディグナーガ以来の三種の正しい理由のうち、第三の「非知覚（anupalabdhi）」を扱う。ダルマキールティはまず、非知覚因が実は自性因に含まれることを示し、次に、非知覚そのものが「別のものの知覚」として自己認識によって成立することを論じる。

## III.2.1.2.i | 知覚されうるものの非知覚は自性因に含まれる | dṛśyānupalabdhi, k.40
L 194:1-3
J （反論）前に述べた特徴をもつ非知覚（anupalabdhi）もまた、第三の理由（hetu）である。それはなぜ（ここで）例示されなかったのか。

（答え）それもまた自性因（svabhāvahetu）に含まれるので、すでに例示されているのである。すなわち――
N ダルマキールティは正しい理由（論証因）を、自性因（本質的属性による理由）・結果因（kāryahetu）・非知覚因の三種に分ける。前節までで前二者の実例を検討したので、反論者は「三番目の非知覚因の例がない」と問う。「前に述べた特徴をもつ」とは、ダルモッタラの注（PVinṬ）によれば「知覚されうるものの非知覚（dṛśyānupalabdhi）」、つまり、もしそこにあれば当然見えるはずのものが見えないこと、を指す。PV IV 260 を参照。
V 195-196
J なぜなら、知覚されないものについて、非存在性は、非知覚と別のものではない。（それゆえ）それ（非存在）の知と言葉――それ（非知覚）に基づくもの――が、それ（非知覚）があることによって論証されるのである。（第40偈）
N 「ここに壺はない、（見えるはずの壺が）知覚されないから」という推論で、「壺の非存在」は「壺の非知覚」と別の事柄ではない。だから非知覚因によって証明されるのは非存在そのものではなく、「無い」という知や言葉（言語慣習）である、と言うのである。理由と所証が同一の事態に帰するので、これは自性因の一種となる。PV IV 265 と並行。
L 197
J このことはすでに（第2章で）述べた――「知覚されうる自性の非存在は、非知覚とまったく別のものではない。その成立している（非存在）によって、それを原因とする『無い』という知と言葉が論証される」と。
N 第2章（校訂本 PVin 2, 59,7–8 および 73,9）の文言を受けている。非知覚が成立した時点で非存在もすでに成立しているので、推論の役割は、「無い」と判断し、そう言ってよいという点を確定させることにある。

## III.2.1.2.ii | 非知覚は「無い」という言語慣習の適合性を証明する | asadvyavahārayogyatā, k.41–44
L 198
J （反論）原因であっても、結果があることは必然ではないのに、どうしてこのような理解（非知覚から「無い」という知と言葉を知ること）がありえようか。
N 前偈では、「無い」という知と言葉は非知覚に「基づく」、つまり非知覚を原因とするものだとされた。ところが、原因があっても結果が必ず生じるとは限らない（障害があれば結果は生じない）。そうであれば、原因（非知覚）から結果（「無い」という知・言葉）を推論することはできないのではないか、という反論である。
V 199-200
J なぜなら、この言語慣習（vyavahāra）――「知覚されうるものが見られないとき、（それは）無い」という――はすでに成立しているからである。それ（非見）が成立しているならば、知と言葉は、それの結果であっても、疑いのないものである。（第41偈）
N 答えの要点は、ここで問題になっているのは、これから生じさせるべき結果ではなく、すでに世間に成立している言語慣習だということである。見えるはずのものが見えなければ「無い」と言う、という取り決めはすでにあるので、非知覚が成り立てば「無い」と言ってよいことに疑いの余地はない。PV IV 266 と並行。
L 201:1-2
J なぜなら、この言語慣習は（これから）起こさせるべきものではない。（もしそうなら）それによって（結果として必然でない、つまり）不確定となるであろうが。そうではなく、知覚されうる自性が見られないときには「無い」という（慣習）は、すでに成立しているのである。
L 201:3-4
J ただしその人は、その言語慣習を（すでに）理解していても、よく知られた「無いもの（nirupākhya、何とも言い表せないもの）」については、対象（である非知覚）があるにもかかわらず、何らかの理由で（その対象を表す）主体（である言葉）を思い出さないので、思い出させられるのである。なぜなら、無の言語慣習には、どこにおいても（非知覚以外の）別の根拠は何もないからである。
N 非知覚因による推論は、新しい知識を与えるというより、すでに知っている取り決めを「思い出させる」ものだ、という説明。うっかり、あるいは迷いのために、目の前の事態に「無い」という言葉を当てはめられない人に、「見えるはずのものが見えないのだから、無いと言うべきだ」と気づかせるのである。
L 201:5-6
J そしてそれ（無の言語慣習）は、この人によって以前に何度も行われてきたものである。だから、この二つ（非知覚と無の言語慣習）の関係を（改めて）論証する必要はない。したがって、知覚されうるものの非見が成立すれば、「無い」という知と言葉がそれ（非見）を原因とするものであっても、（非見が）それ（知と言葉）にふさわしいこと（yogyatā）は、まったく疑いがない。喉袋（sāsnā）などが成立すれば、「牛」という言語慣習が（疑いない）のと同じである。
N 喉袋（牛の首の下に垂れた皮）などの特徴が確認されれば、それを「牛」と呼んでよいことに疑いはない。同じように、非知覚が確認されれば、それを「無い」と呼ぶ適合性は確実である。ここで論証されるのは、結果の発生ではなく、言語慣習への「適合性（yogyatā）」なので、反論の「原因があっても結果は必然でない」という問題は生じない。
V 202-203
J 対象（である非知覚）が存在していても、迷いのためにここで（「無い」と）言い表さない他者が、ただ既に成立した（事例との）同類性によって、取り決め（samaya）を思い出させられるのである。（第42偈）
N 前の散文の要約。「既に成立した事例」とは、喩例（たとえば以前に「無い」と言った場所）のこと。論証は、その事例と同じ状況であることを示して、言葉の取り決めを思い出させる。PV IV 267–269 と並行。
V 204-205
J ちょうど、因果関係（kāryakāraṇatā）が知覚と非知覚とによって論証されるのと同様である。なぜなら、「結果」などの語は、その二者（知覚と非知覚によって知られる事態）の言語慣習のために仮設されたものだからである。（第43偈）
N 仏教論理学では、AとBの因果関係は「Aがあるとき Bが知覚され、Aがないとき Bが知覚されない」という知覚と非知覚の組み合わせによって確定される。「原因」「結果」という言葉は、この事態に名前をつけるための約束にすぎない。だから因果関係の証明も、じつは言語慣習の確定であり、非知覚の場合と同じ構造をもつ、という類比である。
V 206-207
J 原因から結果を成立させること（原因から結果を推論すること）は、自性（因）に含まれるので、理由の区分を説く際に、この例は別に示されなかったのである。（第44偈）
N 完全な原因がそろっていることから「結果を生む能力がある」と推論するのは、第2章で自性因の一種とされた。非知覚因が自性因に含まれるのと同様に、これも独立の理由の類として立てる必要はない、という趣旨。
L 208
J 以上が中間偈（antaraśloka）である。
N 中間偈とは、散文の議論の途中に置かれ、要点をまとめる偈のこと。
L 209:1-2
J あるいは、無の言語慣習にふさわしいこと（asadvyavahārayogyatā）という、非知覚の遍充者（vyāpaka）である自性が論証される（とも言える）。そして遍充（vyāpti）は、他の場所（喩例）において、言語慣習がそれ（非知覚）だけによって成立することによって（確立される）。（ここと喩例とで）違いがないからである。
N 「遍充者」とは、理由があるところには必ずあるもの。非知覚があるところには必ず「無いと言ってよいこと」があるので、後者は前者の遍充者であり、遍充者を論証する理由は自性因である。この遍充関係は、喩例において、非知覚だけで「無い」と言われていることから確かめられる。
L 209:3
J 「成立している、非知覚を本質とする非存在によって、無の言語慣習が論証される」とすでに述べた。
N 第2章（PVin 2, 58,7 以下）を参照せよ、という指示。
