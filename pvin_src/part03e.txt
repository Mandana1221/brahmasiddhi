# III.2.1.2 | 非知覚因（その一）：非知覚とは何か、どう成立するか | anupalabdhi
G ディグナーガ以来の三種の正しい理由のうち、第三の「非知覚（anupalabdhi）」を扱う。ダルマキールティはまず、非知覚因が実は自性因に含まれることを示し、次に、非知覚そのものが「別のものの知覚」として自己認識によって成立することを論じる。

## III.2.1.2.i | 知覚されうるものの非知覚は自性因に含まれる | dṛśyānupalabdhi, k.40
L 194:1-3
J （反論）前に述べた特徴をもつ非知覚（anupalabdhi）もまた、第三の理由（hetu）である。それはなぜ（ここで）例示されなかったのか。

（答え）それもまた自性因（svabhāvahetu）に含まれるので、すでに例示されているのである。すなわち――
N ダルマキールティは正しい理由（論証因）を、自性因（本質的属性による理由）・結果因（kāryahetu）・非知覚因の三種に分ける。前節までで前二者の実例を検討したので、反論者は「三番目の非知覚因の例がない」と問う。「前に述べた特徴をもつ」とは、ダルモッタラの注（PVinṬ）によれば「知覚されうるものの非知覚（dṛśyānupalabdhi）」、つまり、もしそこにあれば当然見えるはずのものが見えないこと、を指す。PV IV 260 を参照。
V 195-196
J なぜなら、知覚されないものについて、非存在性は、非知覚と別のものではない。（それゆえ）それ（非存在）の知と言葉――それ（非知覚）に基づくもの――が、それ（非知覚）があることによって論証されるのである。（第40偈）
N 「ここに壺はない、（見えるはずの壺が）知覚されないから」という推論で、「壺の非存在」は「壺の非知覚」と別の事柄ではない。だから非知覚因によって証明されるのは非存在そのものではなく、「無い」という知や言葉（言語慣習）である、と言うのである。理由と所証が同一の事態に帰するので、これは自性因の一種となる。PV IV 265 と並行。
L 197
J このことはすでに（第2章で）述べた――「知覚されうる自性の非存在は、非知覚とまったく別のものではない。その成立している（非存在）によって、それを原因とする『無い』という知と言葉が論証される」と。
N 第2章（校訂本 PVin 2, 59,7–8 および 73,9）の文言を受けている。非知覚が成立した時点で非存在もすでに成立しているので、推論の役割は、「無い」と判断し、そう言ってよいという点を確定させることにある。

## III.2.1.2.ii | 非知覚は「無い」という言語慣習の適合性を証明する | asadvyavahārayogyatā, k.41–44
L 198
J （反論）原因であっても、結果があることは必然ではないのに、どうしてこのような理解（非知覚から「無い」という知と言葉を知ること）がありえようか。
N 前偈では、「無い」という知と言葉は非知覚に「基づく」、つまり非知覚を原因とするものだとされた。ところが、原因があっても結果が必ず生じるとは限らない（障害があれば結果は生じない）。そうであれば、原因（非知覚）から結果（「無い」という知・言葉）を推論することはできないのではないか、という反論である。
V 199-200
J なぜなら、この言語慣習（vyavahāra）――「知覚されうるものが見られないとき、（それは）無い」という――はすでに成立しているからである。それ（非見）が成立しているならば、知と言葉は、それの結果であっても、疑いのないものである。（第41偈）
N 答えの要点は、ここで問題になっているのは、これから生じさせるべき結果ではなく、すでに世間に成立している言語慣習だということである。見えるはずのものが見えなければ「無い」と言う、という取り決めはすでにあるので、非知覚が成り立てば「無い」と言ってよいことに疑いの余地はない。PV IV 266 と並行。
L 201:1
J なぜなら、この言語慣習は（これから）起こさせるべきものではない。（もしそうなら）それによって（結果として必然でない、つまり）不確定となるであろうが。そうではなく、知覚されうる自性が見られないときには「無い」という（慣習）は、すでに成立しているのである。
L 201:2-3
J ただしその人は、その言語慣習を（すでに）理解していても、よく知られた「無いもの（nirupākhya、何とも言い表せないもの）」については、対象（である非知覚）があるにもかかわらず、何らかの理由で（その対象を表す）主体（である言葉）を思い出さないので、思い出させられるのである。なぜなら、無の言語慣習には、どこにおいても（非知覚以外の）別の根拠は何もないからである。
N 非知覚因による推論は、新しい知識を与えるというより、すでに知っている取り決めを「思い出させる」ものだ、という説明。うっかり、あるいは迷いのために、目の前の事態に「無い」という言葉を当てはめられない人に、「見えるはずのものが見えないのだから、無いと言うべきだ」と気づかせるのである。
L 201:4-5
J そしてそれ（無の言語慣習）は、この人によって以前に何度も行われてきたものである。だから、この二つ（非知覚と無の言語慣習）の関係を（改めて）論証する必要はない。したがって、知覚されうるものの非見が成立すれば、「無い」という知と言葉がそれ（非見）を原因とするものであっても、（非見が）それ（知と言葉）にふさわしいこと（yogyatā）は、まったく疑いがない。喉袋（sāsnā）などが成立すれば、「牛」という言語慣習が（疑いない）のと同じである。
N 喉袋（牛の首の下に垂れた皮）などの特徴が確認されれば、それを「牛」と呼んでよいことに疑いはない。同じように、非知覚が確認されれば、それを「無い」と呼ぶ適合性は確実である。ここで論証されるのは、結果の発生ではなく、言語慣習への「適合性（yogyatā）」なので、反論の「原因があっても結果は必然でない」という問題は生じない。
V 202-203
J 対象（である非知覚）が存在していても、迷いのためにここで（「無い」と）言い表さない他者が、ただ既に成立した（事例との）同類性によって、取り決め（samaya）を思い出させられるのである。（第42偈）
N 前の散文の要約。「既に成立した事例」とは、喩例（たとえば以前に「無い」と言った場所）のこと。論証は、その事例と同じ状況であることを示して、言葉の取り決めを思い出させる。PV IV 267–269 と並行。
V 204-205
J ちょうど、因果関係（kāryakāraṇatā）が知覚と非知覚とによって論証されるのと同様である。なぜなら、「結果」などの語は、その二者（知覚と非知覚によって知られる事態）の言語慣習のために仮設されたものだからである。（第43偈）
N 仏教論理学では、AとBの因果関係は「Aがあるとき Bが知覚され、Aがないとき Bが知覚されない」という知覚と非知覚の組み合わせによって確定される。「原因」「結果」という言葉は、この事態に名前をつけるための約束にすぎない。だから因果関係の証明も、じつは言語慣習の確定であり、非知覚の場合と同じ構造をもつ、という類比である。
V 206-207
J 原因から結果を成立させること（原因から結果を推論すること）は、自性（因）に含まれるので、理由の区分を説く際に、この例は別に示されなかったのである。（第44偈）
N 完全な原因がそろっていることから「結果を生む能力がある」と推論するのは、第2章で自性因の一種とされた。非知覚因が自性因に含まれるのと同様に、これも独立の理由の類として立てる必要はない、という趣旨。
L 208
J 以上が中間偈（antaraśloka）である。
N 中間偈とは、散文の議論の途中に置かれ、要点をまとめる偈のこと。
L 209:1-2
J あるいは、無の言語慣習にふさわしいこと（asadvyavahārayogyatā）という、非知覚の遍充者（vyāpaka）である自性が論証される（とも言える）。そして遍充（vyāpti）は、他の場所（喩例）において、言語慣習がそれ（非知覚）だけによって成立することによって（確立される）。（ここと喩例とで）違いがないからである。
N 「遍充者」とは、理由があるところには必ずあるもの。非知覚があるところには必ず「無いと言ってよいこと」があるので、後者は前者の遍充者であり、遍充者を論証する理由は自性因である。この遍充関係は、喩例において、非知覚だけで「無い」と言われていることから確かめられる。
L 209:3
J 「成立している、非知覚を本質とする非存在によって、無の言語慣習が論証される」とすでに述べた。
N 第2章（PVin 2, 58,7 以下）を参照せよ、という指示。

# III.2.1.2.iii | 非知覚はどのように成立するか | anupalambhasiddhi, k.45–48
G 「見えない」ということは、それ自体どうやって知られるのか。ダルマキールティは、非知覚とは知が単に欠けていることではなく、「別のものだけを知覚している」という積極的な経験であり、それが自己認識（svasaṃvedana）という直接知覚によって確かめられる、と答える。あわせて、非知覚を単なる知の欠如と見る説や、「無の知覚」を独立の認識手段とする説を退ける。

## III.2.1.2.iii.a | 別のものの知覚が非知覚である | ekopalambha
### III.2.1.2.iii.a.1 | 一つの知覚から二つの分別が生じる | k.45
L 210:1-2
J （問い）その非知覚そのものは、どのようにして成立するのか。また、どうしてその無（である非知覚）が何かの原因でありえようか。

（答え）その誤りはない。なぜなら――
N 二つの疑問が出される。①「知覚がない」ということを、さらに何によって知るのか。②非知覚は一種の「無」であるのに、それがどうして「無い」という知や言葉の原因になれるのか。仏教では、原因となる能力をもつのは実在するもの（bhāva）だけだからである。
V 211-212
J 一つのものの知覚を経験することから、「これを私は知覚しない」あるいは「（これを）私は知覚する」という、分別する知が生じるからである。（第45偈）
N たとえば、何もない床だけを見ている経験から、「床が見える」という肯定の判断と、「壺は見えない」という否定の判断の両方が生まれる。非知覚とは、この「一つのもの（床）だけの知覚」のことである。PV IV 270 と並行。
L 213:1
J なぜなら、諸事物について、それ自身を対象とする知が無いことによって「これを私は知覚しない」という（判断）がこのように生じ、そこから無の言語慣習がある、というのではない。そうではなく、（別のものによって）特定された知があることによってである。（もし知覚がまったくなく）すべてが理解されないならば、どこにおいても無は理解されないからである。
N 壺の非存在は「壺の知がない」という欠如から知られるのではない。何も知覚していなければ（たとえば気を失っているとき）、「壺がない」とも分からない。「床だけを見ている」という積極的な知があってはじめて、「壺はない」と分かるのである。
L 213:2
J したがって、何かが直接知覚されているとき、その認識手段の力によって、二つの分別が生じる――「これを私は知覚する」と、「他のものを私は知覚しない」とである。
N 一つの直接知覚（pratyakṣa）が、その後に肯定と否定の二つの分別知（vikalpa）を引き起こす。否定の判断は、新しい認識手段によるのではなく、同じ直接知覚の力によって生じる。

### III.2.1.2.iii.a.2 | 対象の区別は知に、知の区別は自己認識による | saṃvedanaviśeṣa
L 214:1-3
J なぜなら、対象の特殊性（他との区別）の理解は、知の特殊性による。他方、知の区別の理解は、そのような（特定の形をもつ）自己を知ること（自己認識）だけによる。その（知）は、自ら、自分によって特殊性が成立しているので、対象を、事実上（arthāt）区別するのである。
N 「この対象は壺であって布ではない」と分かるのは、その対象を捉える知が「壺の形をした知」であるからである。では知の区別は何によって分かるのか。仏教認識論では、知はみずからを照らし知る（自己認識、svasaṃvedana）ので、知の形は知自身によって直接に知られる。こうして、知の区別が確定すれば、対象の区別もおのずと確定する。PV IV 271 と並行。
L 214:4
J さもなければ、知についても、別の知の特殊性によって特殊性が成立することになり、その（別の知）もまた（さらに）他のものから（成立する）、というように無限遡及となるので、何ものの特殊性も成立しないことになろう。
N 知を知るのに別の知が必要だとすると、その知を知るのにさらに別の知が必要になり、きりがない（無限遡及、anavasthā）。これが自己認識を立てる典型的な論拠である。
L 214:5-6
J しかし対象については、自分の存在と特殊性とによってその（対象の）成立があるのではない。そうではなく、自分についての知の存在と特殊性とによる。だから（対象の）成立は独立のものではない。知の場合は、このように別の知の存在と特殊性とによってその成立があるのではない。（そうであれば）すべてが理解されないことになってしまうからである。
N 対象は、それを捉える知を通してしか成立しない（知に依存する）。一方、知は他の知に依存せず、自分で成立する。この非対称が、非知覚の成立を説明する鍵となる。PV IV 272 と並行。

### III.2.1.2.iii.a.3 | 非知覚とは別のものの知覚にほかならない | k.46–47
L 215
J それゆえ――
V 216
J 特定の形相の経験とは別に、他のものの否定はない。（第46偈）
N 「壺がない」という否定は、「床だけの形」をもつ経験そのものであり、それと別に否定の働きがあるのではない。PV IV 273ab と並行（PV では nāto 'nyā 'nyanirākriyā）。
V 217-218
J それゆえ、それ（あるもの）によって特定された知覚が、それ（他のもの）の非知覚でもある。したがって、この非知覚は直接知覚によってのみ成立する。（第47偈）
N 床によって特定された知覚が、そのまま壺の非知覚である。そしてその知覚は自己認識によって直接に知られるので、非知覚もまた直接知覚によって成立する。これで「非知覚は何によって成立するのか」という問い①に答えたことになる。PV IV 273cd–274 と並行。
L 219:1-2
J なぜなら、一つの形相に限定され、（他のものと）混じり合わない経験とは別に、他のものの否定があるのではない。なぜなら、まさにその（経験）が、その限定によって「それだけがある」と確定させつつ、その能力によって（＝おのずと）、「他のものはない、あるいは他のものの経験はない」と確定させるからである。
N 「床だけがある」と確定することは、裏を返せば「床以外のもの（壺）はない」と確定することでもある。別の推論を立てなくても、一つの経験の内容がそのまま否定を含んでいる。
L 220:1-2
J したがって、一つのものに限定された知覚が、他のものの非知覚であり、またそれ（他のもの）の無の言語慣習を成立させる原因である。そしてそれは、自己認識という直接知覚（svasaṃvedanapratyakṣa）によって成立している。
N 問い②への答えでもある。非知覚の正体は「床の知覚」という実在する知なので、「無い」という知や言葉の原因となることができる。

## III.2.1.2.iii.b | 反論の検討 | parihāra
### III.2.1.2.iii.b.1 | 暗闇で手を動かす場合 | santamasa
L 221:1-2
J （反論）自分を特定する知がなくても、無の知は生じる。たとえば真っ暗闇で手を動かすことによって（そこに何もないと知る）ように。

（答え）そうではない。そこでも、そのように動いている手の、内的な特殊な触覚を知覚することによって、他のものの非存在が知られるからである。
N 暗闇では何も見えないのに、手を振り回して「ここには何もない」と分かる。これは「別のものの知覚」がなくても無が知られる例ではないか、という反論。答えは、そこでも「手が空を切っている」という独特の触覚が知覚されており、それが「別のものの知覚」にあたる、というもの。
L 221:3
J なぜなら、特殊な触覚の知覚から、努力があってもなくても「私の手は動いている」という（知）が生じる、まさにそれ（同じ知覚）から、他のものの非存在が知られるのである。それ（その知覚）がなければ、無は理解されないからである。

### III.2.1.2.iii.b.2 | 「他の知覚の原因がそろっているのに知覚されない」という説 | upalambhakāraṇa
L 222:1-2
J （反論）知覚の他の諸原因がそろっているときに、知覚されうるものが知覚されないことから、無が成立する（のである）。だから、睡眠などの状態では、何かが無いという理解はないことになる。そこでは、感官の健全さなど、知覚の条件そのものがないからである。
N 反論者は、非知覚を「知覚の条件（感官・光など）はそろっているのに、対象の知覚だけがない」という欠如として定義する。眠っているときに「無い」と分からないのは、条件がそろっていないからだ、と説明する。仏教の伝統的な非知覚の定義（「知覚の他の条件がそろっていながら」）を、知の欠如として読む立場である。
L 222:3
J したがって、そこで何かの無が理解されないのは、特定のもの（別のもの）の知覚がないからではなく、そのような（条件のそろった）非知覚そのものがないからである。
L 223:1-3
J （答え）ここでも、「知覚の諸原因がそろっているとき」というのは、それら感官などが、働きの健全さによって、知覚を働かせていることを示している。なぜなら、それら（諸原因）が欠陥のないものであるのは、それらの結果が働いているときだからである。そしてそれ（結果の働き）は知覚にほかならない。
N 「感官などの条件がそろっている」と言えるのは、実際にそれらが何かを知覚させているときだけである。つまり反論者の定義は、ひそかに「別のものの知覚」を前提している、という切り返しである。
L 223:4-5
J 知覚されうるものが知覚されないことによっても、まさにその特定の知覚が一つの形相に限定されていること（が示されている）。それゆえ、特定のものの知覚こそが、他のものの非知覚なのである。
V 224-225
J さもなければ、対象の非存在は非知覚によって知られ、（その）知覚の非存在は別の（非知覚）によって（知られる）ことになり、こうして無限遡及となる。（第48偈）
N 非知覚を「知が無いこと」とすると、その「知が無いこと」をまた別の非知覚で知らねばならず、きりがない。PV IV 275 と並行。
L 226:1
J 「さもなければ」とは（こういうことである）。もし、自分を対象とする知の非存在によって無が成立するのだとすれば、その（知の）非存在もまた、別の非知覚によって論証されねばならない。こうして無限遡及となるので、無はまったく理解されないことになる。
L 226:2-3
J なぜなら、知の非存在は自ら成立するのではない。（もしそうなら）それと違いがないので、対象（の非存在）についても（自ら成立することに）なってしまうからである。なぜなら知は、自分の特殊性のゆえに、他のものによる証明を必要としないが、無はそうではない。
N 知は自己認識によって自分で成立するが、「知が無いこと」には自分を照らす働きがない。もし「知の非存在」が自分で成立するなら、「対象の非存在」も同じく自分で成立してよいことになり、非知覚という理由そのものが不要になってしまう。

### III.2.1.2.iii.b.3 | 「無の知覚」は独立の認識手段ではない | abhāvopalambha
L 227:1-2
J （反論）自分を対象とする知の非存在から無が成立するのではない。（そうだとすれば）この誤りがあるからである。また、自分を特定する（別のものの）知があることからでもない。そうではなく、「壺はない」というこの知覚、まさにそれから無が知覚されるのであり、それは独立した認識手段（pramāṇa）である、と。
N 第三の説。無は「壺がない」という独自の知覚によって直接とらえられ、それは知覚や推論とは別の独立した認識手段だ、とする。ミーマーンサー学派などが立てる「無（abhāva）」という認識手段に近い考え方である。
#### III.2.1.2.iii.b.3.1 | 無は知を生じさせない | asāmarthya
L 228:1-4
J （答え）それならば、その無の知はどこから生じるのか。なぜなら、無は何ものの原因でもない。能力がないからであり、また存在（bhāva）は能力を特徴とするからである。（もし無が原因なら）それ（無）が消滅することはないので、それだけによって生じるものが、常に存在することになってしまうからである。
N 仏教では「存在する」とは「結果を生む能力がある（arthakriyāsāmarthya）」ということである。無には能力がないので原因になれない。また、もし無が原因なら、無は変化も消滅もしないので、その結果（無の知）は永遠に生じ続けることになってしまう。
L 228:5
J （また無は）何にも依存しないからである。依存とは特殊性の獲得を特徴とし、そしてそれ（特殊性の獲得）を特徴とするのは存在であるから、（もし無が依存するなら）無は（無で）なくなってしまうであろう。
N 「補助因がそろえば結果を生む」と言っても、補助因によって何らかの変化を受けるのは実在するものだけである。変化を受ける無は、もはや無ではない。
L 228:6-8
J 「無」というのも、存在の否定である。（だから無の知が無から生じると言えば）「それがあることによって生じる」という存在の（否定）、つまり「存在からは生じない」という、原因の否定を、この（知）について行ったことになろう。それゆえ（その知は）原因をもたないことになる。
N 「無から生じる」とは、言いかえれば「何ものからも生じない」ということで、結局その知は原因なしに生じることになる。原因のないものは、常にあるか常にないかのどちらかになり、ときどき生じることはありえない。
L 228:9-10
J そうでなければ、「無」というのは、何らかの存在が別名で呼ばれているにすぎないことになろう。それゆえ、この知（独立の無の知覚）が生じることはありえない。
N もし「無」が原因として働くなら、それは実は何らかの実在に「無」という名を付けているだけであり、仏教側の「別のものの知覚」説と変わらなくなる。

#### III.2.1.2.iii.b.3.2 | 無の知は独立の認識手段ではない | na pramāṇam
L 229:1-3
J また、独立した（認識手段である無の知覚）が、（壺のない床の）知覚の直後に（生じる）ということはないことになろう。（もし）その（知覚の）力によって生じるのなら、それ（知覚）にこそそこでの能力があるので、それ（知覚）こそが認識手段となるであろう。その（知覚の）形相の限定の力によって、他のものが否定されるからであり、（知覚が）別の形相と混じっているときには、それ（他のものの否定）はないからである。
N 「壺がない」という判断はいつも床を見た直後に生じる。それは床の知覚に依存しているからであり、そうであれば認識手段としての働きは床の知覚の側にある。独立した認識手段なら、知覚と無関係に生じてよいはずである。
L 229:4-6
J それゆえ、この、別の認識手段（直接知覚）の力によって生じた、感官にも徴表にも依拠しない非知覚の分別知は、認識手段ではない。なぜなら、そのように生じたそれは、じつは知覚にほかならない。それ（知覚）によって、その直後に肯定と否定の二つの分別が生じるのである。たとえば、青を見ている人に「これは青だ、黄ではない」と（分別が生じる）ように。それゆえ、その二つ（の分別）は認識手段ではない。
N 「壺がない」という分別は、感官に基づく知覚でも、徴表（liṅga）に基づく推論でもない。それは知覚の後に生じる分別知にすぎず、新しい対象を知らせないので、独立の認識手段とは認められない。仏教が認める認識手段は直接知覚と推論の二つだけである。

# III.2.1.2.iv–vi | 非知覚因（その二）：論式と応用 | anupalabdhiprayoga, k.49–57
G 知覚されえないものの非知覚は確定をもたらさないので理由にならないこと、非知覚因の論式の二つの型（非知覚そのものを述べる型と、対立するものの知覚を述べる型）、その基礎となる三種の「矛盾」を説明する。最後に、サーンキヤ学派の根本原質のように実在しないものを「非知覚」で否定するとき、主題は何なのかを論じる。

## III.2.1.2.iv | 知覚されえないものの非知覚は確定をもたらさない | adṛśyānupalabdhi, k.49–50
V 230-231
J 知覚されえないもの（adṛśya）については確定がありえないので、それ以外の場合には（非知覚による「無い」の）確立は退けられる。ちょうど、徴表のない場合、他の衆生（の心）において分別知など（の非存在）が成立しないように。（第49偈）
N 正しい非知覚因は「もしあれば見えるはずのもの」の非知覚に限られる。幽霊や他人の心のように、もともと見えないものは、見えないからといって「無い」とは言えない。他人の心の中に今どんな考えがあるかは、言葉や表情などの徴表がなければ、あるともないとも決められない。PV IV 276 と並行。
V 232-233
J なぜなら、この（知覚されえないものの非知覚）は、確定がないことを結果とするものであり、（異類からの）排除（vyāvṛtti）を論証するのに十分ではない。最初の（知覚されうるものの非知覚）が理由として扱われる。確定されたもの（理由）によってのみ論証がなされるからである。（第50偈）
N 知覚されえないものの非知覚から得られるのは「疑い」だけである。正しい理由は確定されていなければならないので、理由として認められるのは「知覚されうるものの非知覚」だけである。PV IV 277 と並行。
L 234
J 以上の二つが中間偈である。

## III.2.1.2.v | 非知覚因の論式 | prayoga, k.51
V 235-236
J それ（非知覚）が、自ら（理由として）論式に用いられるときには、その自体が用いられるか、あるいは、（否定されるべき）対象を排除するものの姿が用いられる。（一方が）存在するときには（他方は）存在しないからである。（第51偈）
N 非知覚因の言い表し方には二つの型がある。①「見えないから無い」と非知覚そのものを述べる型、②「それと両立しないものがあるから無い」と、対立するものの存在を述べる型。②が成り立つのは、一方があれば他方は存在できないという「矛盾（virodha）」の関係があるからである。PV IV 278 と並行。
### III.2.1.2.v.a | 非知覚そのものを述べる型 | svarūpa
L 237
J この、無の確定を結果とし、（他の論証では）異類からの排除（vyatireka）を論証するものである非知覚が、自ら無を論証するために用いられるとき、そのときには、その自体によって用いられる。たとえば、「ここに煙はない、非知覚のゆえに」「ここにシンシャパー樹はない、樹がないから」「ここに煙はない、火がないから」というように。
N 非知覚は、ふだんは他の論証のなかで「異類（所証のないところ）に理由がない」ことを確かめる役目を果たすが、ここでは単独で無を証明する理由として使われる。挙げられた三例は、順に、自性の非知覚、遍充者（「樹」は「シンシャパー樹」を包む上位概念）の非知覚、原因（火）の非知覚にあたる。第2章で論じた非知覚の諸類型を参照。
### III.2.1.2.v.b | 対立するものの知覚を述べる型と矛盾の三種 | viruddhopalabdhi
L 238
J あるいは、否定されるべき対象を排除するものの姿を提示することによって用いられる。たとえば、「ここに冷たい触覚はない、火（がある）から」というように。（その他の）例は以前と同様である。
N 冷たさと火は両立しない。だから「火がある」ことを示せば「冷たさはない」と証明できる。これを「矛盾するものの知覚（viruddhopalabdhi）」という。「以前と同様」とは、第2章で挙げた諸例を指す。
#### III.2.1.2.v.b.1 | 共存しないという矛盾 | sahānavasthāna
L 239:1-2
J （問い）では、この矛盾（virodha）はどのように知られるのか。

（答え）あるもの（A）が、原因が欠けることなく存在しているのに、他のもの（B）があるときには（Aが）存在しなくなることから、矛盾が知られる。たとえば、冷たい触覚と熱い触覚とのように。
N 第一の矛盾は「共存しない（sahānavasthāna）」という矛盾。冷たさの原因が十分にそろっていても、強い熱が加われば冷たさは続かない。このことが知覚によって確かめられて、両者の矛盾が知られる。PVSV 5,13–15 と並行、『ニヤーヤ・ビンドゥ』（NB）III 73–74 を参照。なお本文の読みについては末尾の報告を参照（kvacid avikalakāraṇasya と読む）。
#### III.2.1.2.v.b.2 | 相互に排除しあうという矛盾 | parasparaparihāra, k.52ab
V 240
J あるいは、相互の区別が成立することによって（矛盾が知られる）。常住であることと滅とのように。（第52偈前半）
N PV IV 279ab と並行。
L 241
J あるいは、相互に排除しあうことによって成立している特徴をもつことによって、矛盾がある。常住性と無常性とのように。
N 第二の矛盾は「相互排除（parasparaparihāra）」。一方を肯定すれば必ず他方を否定することになる関係で、「常住」と「無常」、「AとAでないもの」のように、第三の可能性がない。NB III 75 を参照。
#### III.2.1.2.v.b.3 | 認識手段による否定にもとづく矛盾 | pramāṇabādhana, k.52cd
V 242
J あるいは、認識手段による否定によっても（矛盾がある）。（他に）依存するものと常住であることとのように。（第52偈後半）
N PV IV 279cd と並行。
L 243
J あるいは、もし認識手段が、（依存するものが常住である）そのことを否定するのであれば、その徴表によっても矛盾がある。たとえば、依存するものと常住であることとのように。
N 第三の型は、両者が直接に排除しあうのではなく、認識手段（推論）によって「依存するものは常住ではありえない」と示されることで成り立つ、間接的な矛盾である。その場合、「依存する」という徴表を述べれば「常住ではない」ことが論証される。
L 244:1-2
J その認識手段とは次のとおりである。「滅の原因を説く者は、生起するものを、滅に決定されている（必ず滅する）ものとして認めるべきではない。それ（滅）が生じることについて、他のものに依存するものとして認められているからである。あるものが生じることについて他のものに依存すると認められているものは、それが生じることに決定されているとは認められない。衣が染色（について他のものに依存する）ように」。
N 相手はニヤーヤ学派やヴァイシェーシカ学派など、「ものの滅には滅の原因（棒で壺を打つなど）が必要だ」とする説（vināśahetuvāda）である。仏教は、生じたものは本性として刹那ごとに滅すると考える。滅が外的な原因に依存するなら、その原因が来なければ滅しないことになり、「生じたものは必ず滅する」とは言えなくなる、と追及する。衣は染料がなければ染まらないのと同じである。
L 244:3-4
J （反論）その（滅の）原因もまた、そこに（必ず到来することが）決定されているので、誤りはない、というなら。

（答え）そうではない。それら（滅の原因）が完全にそろい、妨げられないことが決定されているということはありえないからである。なぜなら、それ（生起したもの）が存在するとき、自分の原因の総体に依存する他のもの（滅の原因）もまた、それ（滅）に向かって存在しなければならない、ということはない。（それらはそのものに）依存していないからである。
N 滅の原因（たとえば棒）は、それ自身の原因によって生じるもので、壺が存在するからといって必ずやって来るわけではない。だから「滅の原因も必ず来る」という言い逃れは通らない。
L 244:5-6
J あるいは、（滅することが）その（もの）の本性であるならば、そのことから、それが刹那的であること（kṣaṇikatā）を認めることになろう。（滅が）本性であるならば、（前後で）違いがないので、以前には存在しなかったもの（生じたもの）は、後にも存在しないことになってしまうからである。
N 逆に、滅が外からの原因ではなく、ものの本性に属するなら、その本性は生じた瞬間から備わっているので、そのものは生じた直後に滅することになる。これがまさに仏教の刹那滅論である。本文の読みについては末尾の報告を参照（viśeṣābhāvād apūrvabhāvinaḥ paścād apy と読む）。
L 244:7-9
J また、その（もの）の原因こそが、無常性の原因を決定づける本性をもつもの、あるいはそれ（滅する）本性をもつもの、あるいはその本性（をもつもの）を生み出す本性をもつものである、とどうして認めないのか。間接的な（滅の原因を介する）ことに何の意味があろう。最後には、その本性をもつもの（それ自身）にこそ、それ（滅）が生じることについての能力があるのだから。これによって、時々（しか）存在しない本性であることと、（他に）依存しないこととの矛盾も説明された。
N 結局、滅を決めているのは、そのものを生み出した原因が与えた「滅する本性」であり、別の滅の原因を持ち出すのは回り道にすぎない。また同じ論法で、「時々しか存在しない」ものは必ず原因に依存するので、「時々存在する」と「依存しない」は矛盾する、ということも示された。
L 245:1-2
J （反論）しかしそうであっても、矛盾しあう二者の矛盾は、相互に排除しあうことによって成立する特徴をもつことによるものにほかならない。決定されていないこと（依存性）によって、決定されていること（常住性）が否定されるからである。認識手段は反対のものを論証するのであって、否定はまさにそれ（相互排除）からある。だから、認識手段による否定にもとづく矛盾というもの（第三の型）があるのではない。
N 反論者は、第三の型は結局第二の型（相互排除）に帰着すると言う。「依存する」は「決定されていない（いつ滅するか定まらない）」ことを含み、それは「決定されている」と相互に排除しあうからである。
L 245:3-4
J （答え）その通りである。（しかし）矛盾するものに遍充される自性によっても、事実上、矛盾があるからである。それ（そのような自性）を提示することによって非知覚の論式がありうる、ということを示すために、このことが述べられたのである。ちょうど直前に例示されたこの論式のように。
N ダルマキールティは反論を認めつつ、第三の型を立てた意図を説明する。「依存する」は「無常」に遍充されており、「無常」は「常住」と矛盾する。だから「依存する」と述べるだけで、間接的に「常住ではない」ことが示せる。このような論式があることを示すのが目的だった、というのである。

## III.2.1.2.vi | 根本原質の否定と言葉の対象 | na santi pradhānādayaḥ, k.53–57
L 246
J （問い）では、「根本原質（pradhāna）などは存在しない、非知覚のゆえに」というこの（論証）においては、どうして無の言語慣習の肯定、あるいは有の言語慣習の否定が（ありうるの）か。

（反問）では、どうして（ありえ）ないのか。

（問い）その対象（根本原質）を否定する場合、基体（dharmin）を表す名称が用いられえないからである。それ（基体）が否定されているからであり、対象のない否定はありえないからである。

（答え）この誤りはない。なぜなら――
N 「根本原質」はサーンキヤ学派が説く、世界の物質的な根源。ディグナーガは『ニヤーヤ・ムカ』で「根本原質などは存在しない、非知覚のゆえに」という論証を挙げている。しかし、存在しないものを主題（基体）に立てると、主題そのものが成り立たず、「存在しない」と述べる対象がなくなる、という難問が生じる。PVSV 105,15–19 と並行。
### III.2.1.2.vi.a | 主題は自相ではなく分別の産物である | śabdārtha, k.53–56
V 247-248
J 始まりのない習気（vāsanā）から生じた分別知においてのみ確立している、言葉の対象（śabdārtha）という属性は、三種である。（すなわち）存在に依拠するもの、非存在に依拠するもの、その両方に依拠するものである。（第53偈）
N 言葉が指す対象は、外界の実在（自相）ではなく、過去の経験が心に残した潜在的な印象（習気）から生じる概念的な像である。その像には、実在するものに対応するもの（「壺」）、実在しないものに対応するもの（「兎の角」）、両方にまたがるものがある。PV I 205 と並行。
V 249-250
J その（言葉の対象）が存在を質料因（upādāna）としない（実在に基づかない）ことを論証すべきとき、それ（言葉の対象）についての非知覚が、そのように理由となる。それ（言葉の対象）そのものが無であるのではない。言葉が用いられていることから（それはあると知られる）。（第54偈）
N 「根本原質は存在しない」という論証の主題は、「根本原質」という言葉が心に呼び起こす概念的な像である。この像そのものは確かに心に現れているので否定できない。論証されるのは「その像に対応する実在がない」ということである。PV I 206 と並行。
L 251:1-2
J これらの言葉は、自相（svalakṣaṇa、個々の実在）を対象とするのではない。始まりのない時以来の習気から生じた分別知に現れる対象を、対象として我がものとする。話し手と聞き手とはその分別知をもつ者であり、（言葉は）現れるとおりの事物を伝えようとする意図によって用いられ、またその形相をもつ分別知を生み出すからである。
N 話し手は自分の心に浮かんだ像を伝えようとして言葉を使い、聞き手の心にも同じような像が生じる。言葉のやりとりは、つねに分別知の像の次元で行われている。PVSV 105,24 以下と並行。
L 251:3-4
J また、（分別知の）質料因であれ結果であれ、その知に現れない姿を、その（言葉の）対象として判断することはできない。そしてその分別知は、存在・非存在・その両方の知によって植え付けられた習気から生じるものであり、またそれに現れる形相を（外界のものと）判断することによって、「存在・非存在・両方の属性」と言われるのである。
N 分別知に現れていない実在そのものを、言葉の対象とみなすことはできない。言葉の対象が「存在するもの」「存在しないもの」と区別されるのは、分別知に現れる像を外界のものと思い込む（判断する、adhyavasāya）ことによるのである。
L 251:5-6
J それゆえ、人々はこの（言葉の対象である）基体に立って、有と無とを考察する――「根本原質」という語に現れるこの対象は、存在を質料因とするものなのか、そうでないのか、と。それ（その対象）が存在を質料因としないことを論証すべきとき、その対象は、各自の内で知られるものであるから否定されえないものであって、基体である。
N だから主題はなくならない。「根本原質」という言葉を聞けば誰の心にもある像が浮かぶ。それは各自が内的に経験するので否定できず、論証の主題として立てることができる。
L 251:7-8
J また、その対象こそが自相であると言うことはできない。まだ到来していない対象やすでに滅んだ対象についても、それ（言葉の対象）はなくならないからであり、また事物と反対の形相を設定する他学派の人々の知においても、（それが）あるからである。
N 言葉の対象が実在そのものでない証拠として二点が挙げられる。①未来や過去のもの（今は存在しないもの）についても言葉は意味をもつ。②他学派が実在に反する教説（根本原質など）を語るときにも、言葉の対象はある。
V 252-253
J もし言葉が勝義（実在）だけに専ら関わるのならば、さまざまな学説によって異なる対象について、根拠のない（言葉の）働きはないことになろう。（第55偈）
N 実際には、学派ごとに異なる、実在に基づかない対象（根本原質、主宰神など）について言葉が使われている。これは言葉が実在だけを指すのではないことを示す。PV I 207 と並行。
V 254-255
J また、過去や未来のものについても（言葉の働きはないことに）なろう。また、ある言葉が偽りの対象をもつということもないことになろう。それゆえ、この（言葉の対象）は、知の上にある対象を対象とするものと考えられる。（第56偈）
N 言葉が実在だけを指すなら、偽りの言葉（嘘）はありえないことになるが、実際には嘘がある。だから言葉の対象は、知の中に現れる像（bauddhārtha）なのである。PV I 208 と並行。
L 256
J 以上の二つが要約偈である。
### III.2.1.2.vi.b | 理由は主題の属性として成立している | sādhanadharmasiddhi
L 257
J そして、それ（言葉の対象）が、（相手が）意図しているとおりの姿（実在）を質料因としないことを論証すべきとき、そのように（その対象についての）非知覚という属性がある。だから、論証因である属性が（主題に）成立していないということはない。
N 理由は主題の属性でなければならない（第一相）。ここでの主題は「根本原質」という言葉の像であり、その像に対応する実在が知覚されないということは、主題の属性として確かに成り立つ。PVSV 106,15–19 と並行。
### III.2.1.2.vi.c | 概念は否定されず、考察されるのは事物である | vastv eva cintyate, k.57
L 258
J しかし、ここでは、言葉の分別知に現れるこの対象そのものが否認されるのではない。それを知に現し出すために言葉が用いられるのであり、それ（その対象）がなければ、それ（言葉の使用）はありえないからである。さらに、
N 「根本原質は存在しない」と言っても、「根本原質」という言葉が呼び起こす像まで否定しているのではない。その像がなければ、そもそも言葉を使うことができない。PVSV 106,26 と並行。
V 259-260
J 有と無という主張の違いに応じて（論じる人々）は、言葉の対象を否定することなく、ここでは事物（vastu）だけを考察する。結果の生起は（事物に）結びついているからである。（第57偈）
N 「ある」「ない」を論じるとき、本当に問題にしているのは言葉の像ではなく、実在する事物である。人の役に立つ結果は事物から生じるからである。PV I 210 と並行。
L 261:1
J なぜなら、言葉の対象は、存在するにせよ存在しないにせよ、何ら人間の目的を妨げることも満たすこともない。（人の）思い込みのとおりには実在せず、実在のとおりには意図されていないからである。
N 言葉の像は、人が思い込むような実在ではなく、また実在そのものは言葉で意図されているわけでもない。だから言葉の像の有無は、実際の役には立たない。PVSV 107,1–10 と並行。
L 261:2-3
J それゆえ、この（人）は、（行動に）向かうとき、つねに、有無の考察において、分別知に現れるものを顧みず、事物だけを拠り所とする。そこにこの人間の目的がかかっているのである。たとえば、火に寒さを除くことなど（がかかっている）ように。なぜなら、ここで言葉の対象は（その目的を果たす）能力がない。その（言葉の対象の）経験を得ても、それ（寒さの除去）はないからである。
N 寒い人が求めるのは本物の火であって、「火」という言葉の像ではない。「火」という言葉をいくら思い浮かべても暖かくはならない。
L 261:4-5
J それゆえ、この、効果的作用（arthakriyā）を求める人が、それ（効果的作用）の能力のないものについて吟味を加えるのは適切でない。なぜなら、男を求める女は、去勢された男の容姿の美醜を吟味することに心を向けない。
N 役に立たないものの性質をあれこれ調べても無意味だ、という比喩。ダルマキールティにとって、認識や議論の目的は、つねに実際の効果をもたらす事物（効果的作用をもつもの）を得ることにある。
### III.2.1.2.vi.d | 「仮構されたものの非知覚は属性である」の意味 | kalpitasyānupalabdhir dharmaḥ
L 262:1-3
J また、（ディグナーガが）「仮構されたもの（kalpita）の非知覚は属性である」と述べたことの意味は何か。分別（kalpanā）の対象であるから、言葉の対象こそが仮構されたものである。その（言葉の対象）の、事物に依拠する非知覚が属性である、というのがここでの意図である。
N ディグナーガは『ニヤーヤ・ムカ』で、根本原質否定の論証について「仮構されたものの非知覚が（主題の）属性である」と述べた。ダルマキールティはこれを、「仮構されたもの」＝言葉の対象（概念の像）、その属性＝「それに対応する事物が知覚されないこと」と解釈し、自説と一致させている。PVSV 107,13–14 と並行。
