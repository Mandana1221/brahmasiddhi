マハーバーラタ ― カルナ篇 第62章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 62 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ62」、全75詩節からなり、クリシュナがアルジュナに戦況を語り続ける場面（第1〜36詩節）と、サンジャヤの語りに切り替わってアルジュナがサンシャプタカ軍団を殲滅しビーマの奮戦を描く場面（第37〜75詩節）で構成されます。本章はカルナ篇最長クラスの章のひとつであり、前章（第61章）に引き続きクリシュナによる長大な語り（第1〜36詩節）が続き、ユディシュティラの苦境（第1〜4詩節）、カルナの圧倒的な武勇（第5〜17詩節）、ドゥルヨーダナの後退（第23〜25詩節）、アルジュナへの出陣促進（第26〜34詩節）、そして戦況の好転（第35〜36詩節）が語られます。第71詩節以降はサンジャヤが語り手となり（第71詩節の0x注記「サンジャヤは語った」）、アルジュナによるサンシャプタカ軍団殲滅（第71〜72詩節）、ナーラーヤナ軍（牛飼い）の撃破（第73詩節）、ビーマによる象軍への猛攻（第56〜70詩節・再叙述）が描かれます。なお、本章では冒頭の注記「8-62-0」「8-62-0x」（「聖なる主（クリシュナ）は語った」）が第1詩節の本文に統合されています。第31・32・33・35・36・73詩節には「xxxxx」で示されるテキスト損傷箇所が含まれますが、サンスクリット原典のまま記載しています。OCR誤記としては、第50詩節「tenaivaitān」（tena+iva+etān）の連声を分かち書きしています。また第38詩節末「bhaptata」は原典の明らかな誤植（「bhārata」のOCR誤読）ですが、日本語訳との照合により対応箇所を確認できるため、本訳注にのみ記載しています。
karṇaparva — dvāṣaṣṭitamo'dhyāyaḥ (62)
第62章
śrībhagavānuvāca|
āturo me mato rājā avipahyaś ca bhārata|
yathaīnam anuvartante pañcālāḥ saha pāṇḍavaiḥ||
// 8-62-1 //
「バーラタよ、王は苦境にあり、救い難い状態にあると私は見ている。パーンチャーラ族がパーンダヴァたちと共に王に従っている様子を見ればわかる。」
tvaramāṇāstvarākāle sarvaśastrabhṛtāṃ varāḥ|
majjantamiva pātāle balino hy ujjihīrṣavaḥ||
// 8-62-2 //
武器を持つ者たちの中の最高の者たちが、急ぐべき時に急ぎ、奈落に沈みゆく者を引き上げようとしている。
na keturdṛśyate rājñaḥ karṇasya pihitaḥ śaraiḥ|
paśyator yamayoḥ pārtha sātyakeś ca śikhaṇḍinaḥ||
// 8-62-3 //
パールタよ、王の旗印はカルナの矢に覆われて見えない。双子（ナクラとサハデーヴァ）、サーティヤキ、シカンディンが見ている前でだ。
dhṛṣṭadyumnasya bhīmasya śatānīkasya vā vibho|
pāñcālānāṃ ca sarveṣāṃ cedīnāṃ caiva bhārata||
// 8-62-4 //
主よ、ドリシュタデュムナ、ビーマ、シャタニーカ、パーンチャーラ族の全て、チェーディ族の全てが見ている前でだ、バーラタよ。
eṣa karṇo raṇe pārtha pāṇḍavānāmanīkinīm|
śarairvidhvaṃsayāmāsa nalinīm iva kuñjaraḥ||
// 8-62-5 //
パールタよ、このカルナは戦場で、パーンダヴァ軍を矢で粉砕したのだ。象が蓮の池を踏み荒らすように。
ete dravanti rathinas tvadīyāḥ pāṇḍunandana|
paśya paśya yathā pārtha gacchanty ete mahārathāḥ||
// 8-62-6 //
パーンドゥの子よ、おまえの側の戦車戦士たちが逃げ出しているぞ。見よ、見よ、パールタよ、大戦車戦士たちがどのように去っていくかを。
ete bhārata mātaṅgāḥ karṇena abhihatāḥ śaraiḥ|
ārtanādānvikurvāṇā vidravanti diśo daśa||
// 8-62-7 //
バーラタよ、これらの象たちはカルナの矢に打たれ、悲鳴を上げながら十方に逃げ散っている。
rathānāṃ dravate vṛndam etac caiva samantataḥ|
drāvyamāṇaṃ raṇe pārtha karṇena amitatejasā||
// 8-62-8 //
パールタよ、戦車の群れもまた四方に逃走している。測り知れぬ威光のカルナに追い散らされて。
hastikakṣyāṃ raṇe paśya carantīṃ tatra tatra ha|
rathasthaṃ sūtaputrasya ketuṃ ketumatāṃ vara||
// 8-62-9 //
旗印を持つ者の中の最高よ、戦場であちこちを動き回る御者の子（カルナ）の戦車の旗印を見よ。象の陣の中を駆け巡っているのを。
asau dhāvati rādheyo bhīmasenarathaṃ prati|
kiran śaraśatāny eva vinighnaṃs tava vāhinīm||
// 8-62-10 //
ラーデーヤ（カルナ）はビーマセーナの戦車に向かって突進し、数百の矢を浴びせながらおまえの軍を打ち倒しているのだ。
ete naśyanti pāñcālā drāvyamāṇā mahātmanā|
śakreṇeva yathā daityā drāvyamāṇā mahātmanā||
// 8-62-11 //
パーンチャーラ族はこの偉大な者に追い散らされ、滅びようとしている。ちょうどダイティヤ（悪魔）たちが偉大なインドラに追い散らされるように。
eṣa karṇo raṇe jitvā pāñcālān pāṇḍusṛñjayān|
diśo viprekṣate sarvās tvadartham iti me matiḥ||
// 8-62-12 //
パールタよ、このカルナは戦場でパーンチャーラ族とパーンドゥ・スリンジャヤ族を破り、四方を見渡しているが、それはおまえを探してのことだと私は思う。
eṣa karṇo dhanuḥśreṣṭhaṃ vidhūnvan bahuśobhate|
śatruṃ jitvā yathā śakro devasaṅkhaiḥ samāvṛtaḥ||
// 8-62-13 //
このカルナは最高の弓を振りかざし、大いに輝いている。敵を打ち破ったインドラが天の群衆に囲まれているように。
ete nardanti kauravyā dṛṣṭvā karṇasya vikramam|
trāsayanto raṇe pāṇḍūnsṛṃjayāṃś ca samantataḥ||
// 8-62-14 //
カウラヴァたちはカルナの武勇を見て吼え立て、戦場で四方からパーンドゥの子たちとスリンジャヤ族を恐怖させている。
eṣa sarvātmanā pāṇḍūṃstrāsayitvā mahāraṇe|
abhibhāṣati rādheyaḥ sarvasainyāni mānada||
// 8-62-15 //
栄誉を与える者よ、このラーデーヤは大いなる戦いでパーンドゥの子たちを全力で恐怖させ、全軍に告げているのだ。
abhidravata bhadraṃ vo drutaṃ dravata kauravāḥ|
yathā na jīvavān kaścinmucyeta yudhi sṛñjayaḥ||
// 8-62-16 //
『突撃せよ、汝らに幸あれ。速やかに突撃せよ、カウラヴァ族よ。スリンジャヤの者で生きて逃れる者がいないようにせよ。』
tathā kuruta saṃyattā vayaṃ yāsyāma pṛṣṭhataḥ|
evamuktvā gato hy eṣa pṛṣṭhato vikirañcharān||
// 8-62-17 //
『そのように全力を尽くせ。我らは背後から追う。』こう言って、背後から矢を振り撒きながら進んだのだ。
paśya karṇaṃ raṇe pārtha śvetacchatravirājitam|
udayaṃ parvataṃ yadvacchaśāṅkena abhiśobhitam||
// 8-62-18 //
パールタよ、戦場で白い天蓋に輝くカルナを見よ。月で飾られた日の出の山のようだ。
pūrṇacandranikāśena mūrdhni cchatreṇa bhārata|
dhriyamāṇena samare śrīmac chataśalākinā||
// 8-62-19 //
バーラタよ、満月のごとく輝く百本の骨組みを持つ美しい天蓋を頭上に掲げて、戦場にいるのだ。
eṣa tvāṃ prekṣate karṇaḥ sakaṭākṣaṃ dhanañjaya|
uttamaṃ yatnamāsthāya dhruvam eṣyati saṃyuge||
// 8-62-20 //
ダナンジャヤよ、このカルナは横目でおまえを見ている。最大の努力をもって、必ず戦いに臨んでくるだろう。
paśya hy enaṃ mahābāho vidhunvānaṃ mahaddhanuḥ|
śarāṃś cāśīviṣākārānvisṛjantaṃ mahāraṇe||
// 8-62-21 //
大腕よ、大いなる弓を振りかざし、毒蛇のような矢を大いなる戦場で放っている彼を見よ。
asau nivṛtto rādheyo dṛṣṭvā te vānaradhvajam|
prārthayan samaraṃ pārtha tvayā saha parantapa|
vadhāya hy ātmano 'bhyeti pāvakaṃ śalabho yathā||
// 8-62-22 //
パールタよ、あのラーデーヤはおまえの猿の旗印を見て引き返してきた。敵を焼く者よ、おまえとの戦いを望んでいるのだ。蛾が自らの死のために火に飛び込むように。
karṇamekākinaṃ dṛṣṭvā dhārtarāṣṭro raṇājire|
tvāṃ ca pārtha abhisaṃrabdhaṃ karṇaṃ prati mahāratham||
// 8-62-23 //
カルナが戦場にただ一人いるのを見、またおまえパールタがカルナに向かって激しく怒っている大戦車戦士であるのを見て、
kṛtāgasaṃ ca rādheyaṃ dharmātmani yudhiṣṭhire|
atmānaṃ ca kṛtārthaṃ ca samīkṣya bharatarṣabha||
// 8-62-24 //
バーラタの雄牛よ、ダルマの心を持つユディシュティラに罪を犯したラーデーヤのこと、そして自分自身の目的が果たされたことを考えて、
asau duryodhanaḥ kruddho rathānīkena bhārata|
rirakṣiṣuḥ susaṃvṛtto dhārtarāṣṭro nivartate||
// 8-62-25 //
ドゥルヨーダナは怒りつつも、戦車軍団で自らを守りながら、バーラタよ、ドリタラーシュトラの子は引き返そうとしている。
sarvaiḥ saha ebhir duṣṭātmā badhyatāṃ ca prayatnataḥ|
tvayā yaśaś ca rājyaṃ ca sukhaṃ cottamamicchatā||
// 8-62-26 //
名誉と王国と至高の幸福を求めるおまえによって、全ての象と共に、あの邪悪な者を努めて殺すのだ。
adīnayorviśrutayoryuvayoryotsyamānayoḥ|
devāsure pārtha mṛdhe devadānavayoḥ iva|
paśyantu kauravāḥ sarve tava pārtha parākramam||
// 8-62-27 //
パールタよ、ひるむことなく名高い二人、すなわちおまえたちが戦うとき、デーヴァとアスラの戦いにおけるデーヴァとダーナヴァのように、カウラヴァの全てがおまえの武勇を見届けるがよい。
tvāṃ ca dṛṣṭvā atisaṃrabdhaṃ karṇaṃ ca bharatarṣam|
asau duryodhanaḥ kruddho nottaraṃ pratipadyate||
// 8-62-28 //
激しく怒るおまえとバーラタの最高者カルナを見て、あのドゥルヨーダナは怒りつつも返す言葉を持たない。
ātmānaṃ ca kṛtātmānaṃ samīkṣya bharatarṣabha|
kṛtāgasaṃ ca rādheyaṃ dharmātmani yudhiṣṭhire||
// 8-62-29 //
バーラタの雄牛よ、自分自身が武を修めた者であることを見定め、ダルマの心を持つユディシュティラに罪を犯したラーデーヤのことを見定めよ。
pratipadyasva kaunteya prāptakālam anantaram|
āryāṃ yuddhe matiṃ kṛtvā pratyehi rathayūthapam||
// 8-62-30 //
カウンテーヤよ、今こそ時が来た。高貴なる戦いの決意をもって、戦車軍の長たるカルナに立ち向かえ。
pañca hy etāni mukhyāni rathānāṃ rathasattama|
śatānyaxxxxxxjalināṃ tinmatejasām||
// 8-62-31 //
戦車の最高者よ、ここには光輝ある主要な戦車が五百台あり（テキスト損傷あり）、
pañca nāghaxxxxx dviguṇā vājinastathā|
abhisaṃhatya kaunteya padātāḥ prayutāni ca||
// 8-62-32 //
五（百）の象、倍の騎馬、カウンテーヤよ、歩兵は何百万もいる。
xxxxxxxx vīra balaṃ tāmabhivartate|
dromaputraṃ puraskṛtya tacchīghraṃ sanniṣūdaya||
// 8-62-33 //
勇者よ、その軍勢がドローナの子を先頭に立てて迫りくる。それを速やかに打ち倒せ。
nikṛttya etad rathānīkaṃ balinaṃ lokaviśrutam|
sūtaputre maheṣvāse darśayātmānam ātmanā||
// 8-62-34 //
この強大で世に名高い戦車軍を切り裂き、大弓のスータの子（カルナ）に対しておまえ自身の力を見せつけよ。
xxxxxxxxxxxxxxxbharatarṣabha|
xxxxxxxxxxxxx pāñcālānabhighāvati|
// 8-62-35 //
（テキスト損傷）バーラタの雄牛よ（テキスト損傷）パーンチャーラ族に突進する。
xxxxxx hi paśyāmi dhṛṣṭadyumnarartha prati|
xxxxxx pāñcālāniti manye parantapa||
// 8-62-36 //
（テキスト損傷）ドリシュタデュムナに向かっているのが見える（テキスト損傷）パーンチャーラ族を（テキスト損傷）と私は思う、敵を滅ぼす者よ。
ācacakṣe priyaṃ pārtha tavedaṃ bharatarṣabha|
rājāsau kuśalī śrīmāndharmaputro yudhiṣṭhiraḥ||
// 8-62-37 //
パールタよ、バーラタの雄牛よ、おまえに嬉しい知らせがある。あの王、ダルマの子ユディシュティラは無事で輝いている。
asau bhīmo mahābāhuḥ sannivṛttaścamūyukhe|
vṛtaḥ sṛñjaya sainyena śaineyena ca bhaptata||
// 8-62-38 //
あの大腕のビーマは軍の先頭に帰還し、スリンジャヤの軍とシャイネーヤ（サーティヤキ）に囲まれている。
vadhyanta ete samare kauravā niśitaiḥ śaraiḥ|
bhīmasenena kaunteya pāñcālaiś ca mahātmabhiḥ||
// 8-62-39 //
カウンテーヤよ、カウラヴァたちは戦場でビーマセーナと偉大なパーンチャーラ族の鋭い矢で殺されている。
senā hi dhārtarāṣṭrasya vimukhā vyadravadraṇāt|
vegena bhīmasenasya vihatā vividhaiḥ śaraiḥ||
// 8-62-40 //
ドリタラーシュトラの子の軍は顔を背け、戦場から逃走した。ビーマセーナの勢いに様々な矢で打たれて。
vipannasasya eva mahī rudhireṇa samukṣitā|
bhāratī bharataśreṣṭha senā kṛpaṇadarśanā||
// 8-62-41 //
バーラタの最高者よ、実りを失った大地のように、血に濡れたバーラタの軍は哀れな姿である。
nivṛttaṃ paśya kaunteya bhīmasenaṃ yudhāmpatim|
āśīviṣam iva kruddhaṃ tasmād dravati bhārati||
// 8-62-42 //
カウンテーヤよ、帰還した戦いの主ビーマセーナを見よ。怒れる毒蛇のように、バーラタ（カウラヴァ）軍はそこから逃げ出している。
pītaraktāsitasitāstārācandrārkamaṇḍitāḥ|
patākā viprakīryante chatrāṇy etāni cārjuna||
// 8-62-43 //
アルジュナよ、黄・赤・黒・白の星・月・太陽で飾られた旗が散乱し、天蓋が散っている。
sauvarṇā rājatāś caiva taijasāś ca pṛthagvidhāḥ|
ketavo 'bhinipātyante hastyaśvaṃ ca prakīryate||
// 8-62-44 //
金や銀や様々な輝く旗印が打ち倒され、象と馬は散り散りになっている。
rathebhyaḥ prapatanty ete rathino vigatāsavaḥ|
nānāvarṇair hatā bāṇaiḥ pāñcālairapalāyibhiḥ||
// 8-62-45 //
戦車から戦車戦士たちが命を失って落ちている。退かぬパーンチャーラ族の様々な色の矢に打たれて。
nirmanuṣyān gajān aśvānrathāṃś caiva dhanañjaya|
samādravanti pāñcālā dhārtarāṣṭrāṃstarasvinaḥ||
// 8-62-46 //
ダナンジャヤよ、人のいない象・馬・戦車に向かって、速き者パーンチャーラ族はドリタラーシュトラの子らに突進している。
vimṛdranti naravyāghrā bhīmasenabalāśrayāt|
balaṃ pareṣāṃ durdharṣaṃ tyaktvā prāṇānarindam||
// 8-62-47 //
敵を滅ぼす者よ、人中の虎たちはビーマセーナの力を頼りに、命を捨てて敵の難攻不落の軍に踏み込んでいる。
ete nardanti pāñcālā dhmāpayanti ca vārijān|
abhidravanti ca raṇe mṛdrantaḥ sāyakaiḥ parān||
// 8-62-48 //
パーンチャーラ族は吼え、法螺貝を吹き鳴らし、戦場で矢をもって敵を打ちながら突撃している。
paśya svargasya māhātmyaṃ pāñcālā hi parākramāt|
dhārtarāṣṭrān vinighnanto viśanty ete rathottamān||
// 8-62-49 //
天国の偉大さを見よ。パーンチャーラ族は武勇によってドリタラーシュトラの子らを殺しながら、最高の戦車に乗り込んでいるのだ。
śastram ācchidya śatrūṇāṃ sāyudhānāṃ nirāyudhāḥ|
tena iva etān amoghastrā nighnanti ca nadanti ca||
// 8-62-50 //
武器を持つ敵から武器を奪い取り、丸腰でありながらその奪った武器で敵を打ち倒し、吼えているのだ。
śirāṃsyetāni pātyante śatrūṇāṃ bāhavo'pi ca|
rathanāgahayā vīrā yaśasyāḥ sarva eva ca||
// 8-62-51 //
敵の首が落とされ、腕も切り落とされ、戦車・象・馬の戦士たちは、皆名誉ある者たちである。
sarvataś cābhipannaiṣā dhārtarāṣṭrī mahācamūḥ|
tyaktvā prāṇān maheṣvāsaiḥ pāñcālaiḥ paripātyate||
// 8-62-52 //
ドリタラーシュトラの大軍は四方から攻められ、命を捨てた大弓のパーンチャーラ族に打ち倒されている。
suhṛdaś ca parākrāntāḥ kṛpakarṇādayo vibho|
nivāraṇe maheṣvāsāḥ pāñcālānāṃ parantapa||
// 8-62-53 //
主よ、クリパ・カルナらの味方の大弓の戦士たちは、パーンチャーラ族を阻止しようと奮戦しているが、敵を滅ぼす者よ。
anivṛttāṃś ca bhītāṃs tāndhārtarāṣṭrān parantapa|
dhṛṣṭadyumnamukhā vīrā ghnanti śatrūnsahasraśaḥ||
// 8-62-54 //
敵を滅ぼす者よ、退却して恐怖に陥ったドリタラーシュトラの子らを、ドリシュタデュムナを先頭とする勇者たちが数千単位で殺している。
rathāś ca vividhāḥ sarve nivṛtte bharatarṣabhe|
vivarṇamukhabhūyiṣṭhā dhārtarāṣṭrī mahācamūḥ||
// 8-62-55 //
バーラタの雄牛が帰還すると、様々な戦車の全てが（パーンダヴァ側に）戻り、ドリタラーシュトラの大軍は大半が蒼白な顔である。
paśya bhīmena nārācairbhinnā nāgāḥ patantyamī|
vajrivajrahatānīva śikharāṇi dharābhṛtām||
// 8-62-56 //
見よ、ビーマの鉄矢で打たれた象たちが倒れている。インドラの雷に打たれた山の頂のように。
bhīmasenasya nirviddhā bāṇaiḥ sannataparvabhiḥ|
svāny anīkāni mṛdganto dravanti ete mahāgajāḥ||
// 8-62-57 //
ビーマセーナの曲がった節の矢に射抜かれた大象たちは、自軍の陣形を踏み潰しながら逃走している。
'ete dravanti kuravo bhīmasenabhayārditāḥ|
tyaktvā rathāngajāṃścaiva hayāṃś caiva sahasraśaḥ||
// 8-62-58 //
カウラヴァたちはビーマセーナへの恐怖に苦しみ逃走している。戦車も象も馬も数千単位で捨てて。
hastyaśvarathapattīnāṃ dravatāṃ niḥsvanaṃ śṛṇu|
bhīmasenasya ninadaṃ drāvayānasya kauravān||
// 8-62-59 //
逃げる象兵・馬兵・戦車兵・歩兵の轟音と、カウラヴァを追い散らすビーマセーナの咆哮を聞くがよい。
abhijānāmi bhīmasya siṃhanādaṃ punaḥ punaḥ'|
nadataḥ pāṇḍaveyasya saṅgrāme jitakāśinaḥ||
// 8-62-60 //
戦場で勝ち誇って繰り返し吼えるパーンダヴァの子ビーマの獅子吼を、私は聞き分けることができる。
eṣa naiṣādir abhyeti dvipamukhyena pāṇḍavam|
visṛjaṃs tomarān kruddho daṇḍapāṇir iva āntakaḥ||
// 8-62-61 //
ニシャーダの子が最高の象に乗って、怒りに燃えてパーンダヴァ（ビーマ）に向かってくる。棍棒を持つヤマ（死神）のように投げ槍を放ちながら。
tasya caiva bhujau chinnau bhīmasenena garjataḥ|
nāgaś ca krakaraprakhyair nārācair daśabhir hataḥ||
// 8-62-62 //
吼えるニシャーダの子の両腕はビーマセーナに切り落とされ、象もまた鷺のような十本の鉄矢で殺された。
hanta ete punar āyānti nāgā hy anye prahāriṇaḥ|
nīlāñjanacayaprakhyā mahāmātrairadhiṣṭhitāḥ||
// 8-62-63 //
おお、他の攻撃的な象たちが再びやってくる。黒い目薬の山のような姿で、大将たちに乗られて。
śaktitomarasaṅghatairvinighnanto vṛkodaram|
saptasapta ca nāgasthā vaijayantyaś ca sadhvajāḥ|
navatyā niśitair bāṇaiśchinnāḥ pārthāgrajena te||
// 8-62-64 //
槍や投げ槍の集団でヴリコーダラ（ビーマ）を打ちながら、七人ずつの象乗りと勝利の旗が、パールタの長兄（ビーマ）によって九十本の鋭い矢で切り落とされた。
daśabhir daśabhiś caiko nārācair nihato gajaḥ||
// 8-62-65 //
一頭の象は十本ずつの鉄矢で殺された。
na cāsau dhārtarāṣṭrāṇāṃ śrūyate ninadas tathā|
purandarasame kruddhe nivṛtte bharatarṣabhe||
// 8-62-66 //
バーラタの雄牛、インドラに等しいビーマが怒って帰還したとき、ドリタラーシュトラの子らの雄叫びはもはや聞こえなくなった。
akṣauhiṇyastathā tisro dhārtarāṣṭrasya saṅgatāḥ|
kruddhena bhīmasenena narasiṃhena vāritāḥ||
// 8-62-67 //
ドリタラーシュトラの三個のアクシャウヒニーの軍は集結したが、怒れる人中の獅子ビーマセーナに阻まれた。
na śaknuvanti vai pārthaṃ pārthivāḥ samudīkṣitum|
madhyandinagataṃ sūryaṃ yathā durbalacakṣuṣaḥ||
// 8-62-68 //
王たちはパールタ（ビーマ）を見上げることすらできない。弱い目の者たちが真昼の太陽を見られないように。
ete bhīmasya santrastāḥ siṃhasya iva itare mṛgāḥ|
śaraiḥ santrāsitāḥ sahkhye na labhante sukhaṃ kvacit||
// 8-62-69 //
ビーマの矢に怯えた彼らは、獅子に怯える他の獣のように、戦場のどこにも安らぎを得られない。
rādheyo bahubhiḥ sārdhamasau gacchati vegitaḥ|
vardhayitvā tu bhīruṃ taṃ pārśvato hy ānayaldhanuḥ|
taṃ pālayanmahārājaṃ dhārtarāṣṭraṃ balānvitaḥ||
// 8-62-70 //
ラーデーヤ（カルナ）は多くの者と共に急いで向かい、臆病な者（ドゥルヨーダナ）を励まし、脇から弓を取らせた。あの大王ドリタラーシュトラの子を、力ある者として守りながら。
sañjaya uvāca|
etac chrutvā mahābāhurvāsudevād dhanañjayaḥ|
bhīmasenena tatkarma kṛtaṃ dṛṣṭvā suduṣkaram|
arjuno vyadhamacchiṣṭān saṃśaptakagaṇān bahūn||
// 8-62-71 //
ヴァースデーヴァ（クリシュナ）からこの話を聞き、ビーマセーナの成し遂げた至難の業を見て、大腕のダナンジャヤ・アルジュナは、残りのサンシャプタカ軍団を多数打ち倒した。
te vadhyamānāḥ pārthena saṃśaptakagaṇāḥ prabho|
śakrasya ātithitāṃ gatvā viśokā hy abhavaṃs tadā||
// 8-62-72 //
主よ、パールタ（アルジュナ）に殺されたサンシャプタカ軍団の者たちは、インドラの客人の身分を得て、悲しみから解放された。
nārāyaṇāṃs tu gopālān vyadhamatpāṇḍunandanaḥ|
uttamaṃ vexxxxxptāsthāya caṇḍavāyurdhanāniva||
// 8-62-73 //
パーンドゥの子は牛飼いのナーラーヤナ軍をも打ち破った。最高の努力をもって、激しい風が雲を吹き散らすように。
anvakīryanta bhītās te tatra tatraiva bhārata|
lulitāṃś ca tataḥ śūrānahanatpuruṣottamaḥ||
// 8-62-74 //
バーラタよ、恐れた彼らはあちこちに散り散りになった。そして打ちのめされた勇者たちを、人中の最高者（アルジュナ）は殺した。
punaś ca puruṣavyāghraḥ śaraiḥ sannataparvabhiḥ|
jaghāna dhārtarāṣṭrasya caturvidhabalāṃ camūm||
// 8-62-75 //
さらに人中の虎は、曲がった節の矢で、ドリタラーシュトラの子の四種の軍（象・馬・戦車・歩兵）を殺した。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe dvāṣaṣṭitamo'dhyāyaḥ|| 62 ||
