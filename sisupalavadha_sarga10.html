दशमः सर्गः / 第十章　情事の描写（suratavarṇana）

飲酒の宴と愛の営みを描く
svāgatā throughout — r-n-bh-g-g (—◡— ◡◡◡ ——◡ ——), 11 syllables per pāda
V.1
Sanskrit (IAST) sajjitāni surabhīṇy atha yūnām ullasannayanavāriruhāṇi / āyayuḥ sughaṭitāni surāyāḥ pātratāṃ priyatamāvadanāni //
和訳

さて、若者たちの恋人の顔は――美しく飾られ、芳しく香り、蓮華のように咲き開く瞳を湛え、端正に造られた――酒の器となった。

注

【Vallabhadeva】

priyatamāvadanāni（恋人たちの顔）が surāyāḥ pātratāṃ āyayuḥ（酒の器の地位に達した）。śleṣa：pātra は「器」と「ふさわしき者」の二義。顔は sajjita（化粧で飾られた）、surabhī（芳香ある）、ullasannayanavāriruhāṇi（蓮のように輝く瞳を持つ）、sughaṭita（端正に造られた）。酒杯もまた同じ形容が当てはまる。svāgatā 韻律。

【Mallinātha】

vadanāni が pātratāṃ āyayuḥ は pariṇāma の修辞。sajjita は「yāvaka 等で磨き清められた」。杯も同じ修容を持ち、顔で酒を飲んだ（＝口づけで味わった）という含意。śleṣasaṃkīrṇā upamā。

V.2
Sanskrit (IAST) sopacāram upaśāntavicāraṃ sānutarṣam anutarṣapadena / te muhūrtam atha mūrtam apīpyan prema mānam avadhūya vadhūḥ svāḥ //
和訳

さて、若者たちは怒りを払い去り、丁重に、分別を忘れさせるかのように、渇望を伴いつつ、酒（anutarṣa）の名のもとに、自らの妻たちに具現化した愛をひととき飲ませた。

注

【Vallabhadeva】

anutarṣapadena は「酒（anutarṣa）を口実として」。mūrtaṃ prema apīpyan は「形あるものとなった愛を飲ませた」（utprekṣā）。sopacāram は「敬意を込めて」。upaśāntavicāram は「善悪の判断が失われたさまで」。mānam avadhūya は「怒りを捨てて」。

【Mallinātha】

apīpyan は pā（飲む）の ṇijanta imperfect。anutarṣa は madya（酒）の異名。mūrtaṃ prema は utprekṣā：愛そのものを飲ませたかのよう。酒を飲ませるという行為の裏に愛情の表出を読む sāpahnavotprekṣā。

V.3
Sanskrit (IAST) krāntakāntavadanapratibimbe bhaṅgabālasahakārasugandhau / svāduni praṇaditālini śīte nirvivāra madhunīndriyavargaḥ //
和訳

恋人の顔の映像が映り込み、砕いた若いマンゴーの芳香が漂い、甘美で、蜂の群れが唸り、冷たい――そんな酒の中で、五感すべてが満たされた。

注

【Vallabhadeva】

五感の満足を一つの酒杯に集約する。映り込んだ顔は眼を、sahakāra（マンゴー）の香は鼻を、甘味は舌を、蜂の羽音は耳を、冷たさは肌を満たす。madhuni（酒に）indriyavargaḥ nirvivāra（感覚群が満足した）。

【Mallinātha】

krānta = saṃkrānta（映り込んだ）。bhaṅga = 砕いた若いマンゴーの花片（酒の香り付けに用いる）。pranaditālini は「蜂が鳴り響く」。五つの形容がそれぞれ五感の満足に対応する。padārthakāvyaliṅga（事物の理由に基づく修辞）。

V.4
Sanskrit (IAST) kāpiśāyanasugandhi vighūrṇann unmado 'dhiśayituṃ samaśeta / phulladṛṣṭi vadanaṃ pramadānām abjacāru caṣakaṃ ca ṣaḍaṅghriḥ //
和訳

酔って旋回する蜂は、酒の芳香に惹かれ、花のように見開かれた目の女たちの顔と、蓮のように美しい酒杯と、どちらにとまるべきか迷った。

注

【Vallabhadeva】

ṣaḍaṅghriḥ（六脚＝蜂）は kāpiśāyana（酒の一種）の香りに酔い、女の顔と酒杯の双方に adhiśayitum（止まろうと）した。両者が同じ芳香と蓮花の美しさを持つため区別がつかない。

【Mallinātha】

unmada（酔った）vighūrṇan（旋回する）蜂が、phulladṛṣṭi vadanam（開花したような瞳の顔）と abjacāru caṣakam（蓮のように美しい酒杯）の両方に samaśeta（迷った）。蜂の両者への欲求が等しいという tulyayogitā の修辞。

V.5
Sanskrit (IAST) bimbitaṃ bhṛtaparisruti jānan bhājane jalajam ity abalāyāḥ / ghrātum akṣi patati bhramaraḥ sma bhrāntibhāji bhavati kva vivekaḥ //
和訳

酒に満たされた杯に映った女の瞳を蓮と見なして、蜂は香りを嗅ごうと飛びかかった。惑いに囚われた者に、どうして分別があろうか。

注

【Vallabhadeva】

bhṛtaparisruti（parisrut＝蒸留酒を湛えた）杯に映った女の目を jalaja（蓮華）と見なして、蜂は ghrātum（嗅ぐために）落ちた。bhrāntibhāji（迷乱に与る者）にどこに viveka（判断力）があろうか。

【Mallinātha】

bhrānti は śleṣa：「飛び回ること」と「誤った認識」。蜂が瞳を蓮と錯覚する bhrāntimadalaṅkāra。その理由づけに śleṣa に基づく atiśayokti から引き出された arthāntaranyāsa。saṅkara（複合修辞）。

V.6
Sanskrit (IAST) dattam iṣṭatamayā madhu patyur bāḍham āpa pibato rasavattām / yat suvarṇamukuṭāṃśubhir āsīc cetanāvirahitair api pītam //
和訳

最愛の女が差し出した酒は、夫が飲むとき実にいっそう味わい深くなった。なぜなら、意識なき金の冠の光によってさえ、すでに「飲まれて」いたのだから。

注

【Vallabhadeva】

śleṣa：pīta は「飲まれた」と「黄金色にされた」の二義。無生物たる金冠の光線さえ酒を「飲んだ」（＝黄色く染めた）のだから、恋人の手から直接受けた有情の者ならばなおさら美味であるという含意。

【Mallinātha】

pīta の śleṣa に基づく atiśayokti。acetanāṃśukartṛkapānakriyānimittā utprekṣā（無生物を飲む主体に見立てる想像修辞）。無生物のものさえ飲めるならば、有情者にとってはいうまでもないという arthāpattivyañjana。

V.7
Sanskrit (IAST) svādanena sutanor avicārad oṣṭhataḥ samacariṣṭa raso 'tra / anyam anyad iva yan madhu yūnaḥ svādam iṣṭam ataniṣṭa tad eva //
和訳

美しい女の唇を味わったことで、疑いなくその味わいが酒に移り入った。なぜなら、まさにその同じ酒が、まるで別の飲み物であるかのように、若者にとって新たな好ましい味を生み出したのだから。

注

【Vallabhadeva】

sutanoḥ oṣṭhataḥ は「美しい女の唇から」。samacariṣṭa は saṃ+car のアオリスト（味が移り入った）。同じ酒なのにまるで別の酒のように新しい味がした。唇の味が酒に移ったからこそ別物に感じられるという utprekṣā。

【Mallinātha】

svādanena は āsvādana（味わうこと）。avicārāt は「疑いなく」。唇に触れた後にこそ味が変わったということから、味の移行を推定する utprekṣā。vyañjakāprayogāt（暗示表現の使用により）vācyā（直接表現の修辞）。

V.8
Sanskrit (IAST) bibhratau madhuratām atimātraṃ rāgibhir yugapad eva papāte / ānanair madhuraso vikasadbhir nāsikābhir asitotpalagandhaḥ //
和訳

この上ない甘美さを帯びた二つのもの――酒の味と青蓮華の香り――が、情熱ある者たちの花開く顔と鼻とによって、同時に味わわれた。

注

【Vallabhadeva】

bibhratau（二つのものが甘美さを担う）は双数。madhurasa（酒の味）は ānanaiḥ（顔＝口で）、asitotpalagandha（青蓮華の香）は nāsikābhiḥ（鼻で）、yugapad eva（同時に）ともに papāte（飲まれた＝味わわれた）。二つの感覚対象が同時に享受された。

【Mallinātha】

madhurasa（酒の味）と asitotpalagandha（青蓮華の芳香）という、本来別の感覚器官で捉えるべき二つが yugapad（同時に）享受されたという tulyayogitā の修辞。vikasadbhiḥ（咲き開く＝渇望に膨らむ）は顔と鼻の両方にかかる。

V.9
Sanskrit (IAST) pītavaty abhimate madhutulyasvādam oṣṭharucakaṃ vidadaṅkṣau / labhyate sma pariraktatayātmā yāvakena viyatāpi yuvatyāḥ //
和訳

愛しい男が酒を飲み干すと、酒と同じ甘さの唇という宝飾を噛みたがったが――去りゆく若い女の唇から、紅の染料の赤さによって、その本来の姿がふたたび現れた。

注

【Vallabhadeva】

oṣṭharucakam は「唇という装飾品」。pītavati は「（男が）飲んだ時」（locative absolute）。yāvaka（ラック染料）の tikta（苦味）によって唇の ātman（本性＝甘さとの区別）が明らかになる。酒と唇は同じ甘さゆえ区別できないが、ラック染料の味で初めて唇と分かる。

【Mallinātha】

vidadaṅkṣau は daṃś（噛む）の desiderative：「噛もうとした」。madhutulyasvādam は「酒と等しい味の」。viyatā（去りゆく）女の唇から pariraktatayā（赤く染まっていることによって）ātmā（自己＝本性）が回復された。

V.10
Sanskrit (IAST) kasyacit samadanaṃ madanīyapreyasīvadanapānaparasya / svāditaḥ sakṛd ivāsava eva pratyuta kṣaṇavidaṃśapade 'bhūt //
和訳

ある若者は、酔わせる恋人の顔を飲むことに夢中になっていた。酒はただ一度味わわれたに過ぎず、かえって一口のつまみ程度のものとなってしまった。

注

【Vallabhadeva】

samadanam は「欲情を伴って」。madanīyapreyasīvadanapānaparasya は「酔わせる恋人の顔を飲むこと（＝口づけ）に専念する者の」。通常は酒が主で肴が従だが、この男にとっては恋人の顔への口づけが主で、āsava（酒）は pratyuta（かえって）avadaṃśapade（つまみの地位に）落ちた。

【Mallinātha】

vadanapāna は「顔を飲むこと」＝口づけ。sakṛd iva（一度だけのように）味わわれた酒が、avadaṃśa（酒の肴）の地位に転落した。主客が逆転する洒落た情景。

V.11
Sanskrit (IAST) pītaśīdhumadhurair mithunānām ānanaiḥ parihṛtaṃ caṣakāntaḥ / vrīḍayā rudadivālibirāvair nīlanīrajam agacchad adhastāt //
和訳

杯の中に香りのために沈められた青蓮は、酒を飲んで甘い息の恋人たちの顔に見捨てられ、恥じらいに泣くかのように蜂の羽音とともに沈んでいった。

注

【Vallabhadeva】

nīlanīrajam（青蓮）は杯の中に香りづけとして入れられた花。恋人たちが互いの顔に見とれて杯を放置したため、花は底に沈む。その際の蜂の声を「泣き声」に見立てる。caṣakāntaḥ＝pātramadye（杯の中で）。

【Mallinātha】

酒の消費とともに杯底に沈む青蓮の情景。parihṛtam＝tyaktam。蜂の羽音を泣き声に喩えるのは、集団の中で見捨てられた者は必ず泣くという俗諺に基づく。rūpaka と utprekṣā の saṅkara。

V.12
Sanskrit (IAST) prātibhaṃ trisarakeṇa gatānāṃ vakravākyaracanāramaṇīyaḥ / gūḍhasūcitarahasyasahāsaḥ subhruvāṃ pravavṛte parihāsaḥ //
和訳

三杯の酒で機知を得た美眉の女たちの間に、巧みな言い回しで趣深く、密やかに秘事を仄めかしつつ笑いを含んだ戯れが始まった。

注

【Vallabhadeva】

trisarakeṇa＝三度の飲酒（triḥpātena）で prātibham＝dhṛṣṭatvam（大胆さ）を得た。gūḍham＝aprakaṭam（隠された）、sūcitam＝īṣaduktam（わずかに示された）、rahasya＝秘めごと。parihāsa＝narma（冗談・戯れ）。

【Mallinātha】

saraka は酒杯・飲酒・酒そのものの三義を持つ。prātibham は pratibhā（機知）の派生語。vakravākya は遠回しの言葉、rahasya は以前は恥じらいに隠されていた私的な事柄を指す。ここから mada（酔い）が sañcārī（副次的情感）として機能する。

V.13
Sanskrit (IAST) hāvahāri hasitaṃ vacanānāṃ kauśalaṃ dṛśi vikāraviśeṣāḥ / cakrire bhṛśam ṛjor api vadhvāḥ kāmineva taruṇena madena //
和訳

媚態に満ちた笑い、言葉の巧みさ、目もとの様々な色めき——素朴な花嫁にさえ、まるで若い恋人のように、初々しい酔いがこれらを大いにもたらした。

注

【Vallabhadeva】

ṛjoḥ＝atimuṣṭhāyāḥ（きわめて素朴な女）にさえ。taruṇena madena＝pratyagreṇa jīvatayā（新鮮な活気ある酔いによって）。kāminā iva＝若い恋人がそうするように。hāva は vilāsa（なまめかしい仕草）の一種。

【Mallinātha】

cakrire は karmaṇi（受動態）。素朴な花嫁にさえそうであるなら、況んや熟練の女にはなおさら——という arthāpatti（推論的含意）が示される。hasita・kauśala・vikāra の三者が同時に生じることで samuccaya（併列修辞）、さらに upamā との saṅkara。

V.14
Sanskrit (IAST) aprasannam aparāddhari patyau kopadīptam urarīkṛtadhairyam / kṣālitaṃ nu śamitaṃ nu vadhūnāṃ drāvitaṃ nu hṛdayaṃ madhuvāraiḥ //
和訳

過ちを犯した夫に対して不機嫌で、怒りに燃え、決然と心を固めていた妻たちの胸を、酒の杯は洗い流したのか、鎮めたのか、それとも溶かしたのか。

注

【Vallabhadeva】

aprasannam＝kaluṣam（濁った）は kṣālitam（洗浄された）に、kopadīptam＝kopena jvalitam（怒りに燃えた）は śamitam（鎮火された）に、urarīkṛtadhairyam＝aṅgīkṛtakāṭhinya（固さを受け入れた）は drāvitam（溶かされた）に、それぞれ yathāsaṅkhya で対応する。

【Mallinātha】

汚れたものは洗い、燃えたものは消し、硬いものは溶かす——酒は液体であるからこそこの三つすべてが可能。nu は saṃśaya（疑い）を示す。三つの形容が互いに矛盾しないため、真の saṃśayālaṅkāra ではなく yathāsaṅkhyālaṅkāra。

V.15
Sanskrit (IAST) santam eva ciram aprakṛtatvād aprakāśitam adidyutad aṅge / vibhramaṃ madhumadaḥ pramadānāṃ dhātulīnam upasarga ivārtham //
和訳

女たちの体に久しく存在しながらも、折がなく表に出なかった媚態を、酒の酔いが輝かせた——動詞の語根に潜む意味を接頭辞が顕わにするように。

注

【Vallabhadeva】

dhātu（語根）に līna（潜む）artham（意味）を upasarga（接頭辞）が顕示するように、女たちの体に常にあった vibhrama（媚態）を madhumada（酒の酔い）が明るみに出した。aprakṛtatvāt＝aprastāvāt（場にそぐわないため）。adidyutat は dyut の不定過去。

【Mallinātha】

文法学の比喩。upasarga は dhātu の意味を「遮断する」のではなく「明示する」もの。同様に vibhrama は常に女の本性に内在するが、年長者の前や家事の場では aprakṛta（不適切）ゆえ現れない。酒の酔いがそれを解放する。upamālaṅkāra。

V.16
Sanskrit (IAST) sāvaśeṣapadam uktam upekṣā srastamālyavasanābharaṇeṣu / gantum utthitam akāraṇataḥ sma dyotayanti madavibhramam āsām //
和訳

言いさしの言葉、花飾りや衣や装身具が落ちても気にかけぬこと、理由もなく立ち上がって行こうとすること——これらが彼女たちの酔いの乱れを示していた。

注

【Vallabhadeva】

sāvaśeṣapadam uktam＝言い終わらぬ言葉。srasta＝落ちた。mālyavasanābharaṇeṣu upekṣā＝花輪・衣服・装飾品への無関心。akāraṇataḥ＝理由なく。これらは madavibhrama（酔いによる昂奮）の anubhāva（外的徴候）。

【Mallinātha】

言いかけの言葉、装飾品への無頓着、理由のない立ち上がり——三つの行動が共同して酔いの兆候を示す khaṇḍopakti 式の第二 samuccaya。各徴候が一つでは不十分だが、複合して酔態を物語る。

V.17
Sanskrit (IAST) madyamandavigalattrapam īṣac cakṣur unmiṣitapakṣma dadhatyā / vīkṣyate sma śanakair navavadhvā kāmino mukham adhomukhayaiva //
和訳

酒にゆるやかに恥じらいの薄れた、睫毛をわずかに持ち上げた目をして、新妻はうつむいたまま、そっと恋人の顔を盗み見ていた。

注

【Vallabhadeva】

adhomukhayā eva＝俯いたまま。madyena mandaṃ vigalantī trapā＝酒により徐々に消えゆく恥じらい。unmiṣitapakṣma＝睫毛をわずかに開いた。横目の一瞥を描く。

【Mallinātha】

navavadhvā＝navoḍhayā（新たに嫁いだ女）。酔いと羞恥の拮抗——酔いにもかかわらず恥じらいが勝る初々しさの極致。maugdhya（素朴さ）の atiśayokti。

V.18
Sanskrit (IAST) yā kathañcana sakhīvacanena prāg abhipriyatamaṃ prajagalbhe / vrīḍajāḍyam abhajan madhupā sā svāṃ madāt prakṛtim eti hi sarvaḥ //
和訳

以前は友の勧めでやっとのことで恋人の前で大胆にふるまえた女が、酒を飲むとかえって恥じらいに固まってしまった——酔えば誰もが本性に戻るものだから。

注

【Vallabhadeva】

madāt svāṃ prakṛtim eti＝酔いにより自らの本性に帰る。本来恥じらい深い女であるから、酔いが彼女を大胆にするのではなく、かえって恥じらいという本性を露わにする。madhupā＝madhu（酒）を pibatī（飲む者）。

【Mallinātha】

abhipriyatamam＝priyatamasamakṣam（最愛の者の前で）。prajagalbhe は galbh の完了形。vrīḍajāḍyam＝maugdhyam（恥じらいの硬直）。一般命題「酔えば本性に戻る」で個別事例を裏づける arthāntaranyāsa。

V.19
Sanskrit (IAST) chāditaḥ katham api trapayāntaryaḥ priyaṃ prati cirāya ramaṇyāḥ / vāruṇīmadaviśaṅkam athāviś cakṣuṣo 'bhavad asāv iva rāgaḥ //
和訳

V.20

和訳

【Vallabhadeva】

abhisisārayiṣūṇām は abhi-sṛ の使役活用の希求形。savipratisāre＝paścāttāpayukte（後悔に満ちた）心に。酒が困難な行為を容易にするという samādhyalaṅkāra。自分から呼び寄せれば軽薄と見なされるが、酔いを口実にすれば非難を免れる。

V.21

V.22

注

V.23
Sanskrit (IAST) dattam āttamadanaṃ dayitena vyāptam atiśāyikena rasena / sasvade mukhasuraṃ pramadābhyo nāma rūḍham api ca vyudapādi //

mukhasura は女性名詞 surā の中性形（「vibhāṣā senāsurā-」の規則による）。rūḍham＝prāgabhrākaṇādivadavyutpannam（語源に遡らぬ慣用的な名）。vyudapādi は pad の使役形 luṅ。前半の文意が後半の根拠となる kāvyaliṅga。

V.24

madirā の香りと aṅganāsya-caṣaka（女の顔という杯）の香りが itaretarayogāt（相互の結合により）増す。前者が後者を高め、後者もまた前者を高める。anyatā（別のもの）になったか atiśaya（より強い同じもの）になったかで saṃśaya（疑い）が生じる。

yakṣakardama（香膏の混合）と ghṛtākta-kuṅkuma（バター入りクンクマ）のように、混合物が新しい性質を帯びるか元の性質の強化かは判然としない。moditāli＝ānandita-bhṛṅga（喜ぶ蜂）。saṃśayālaṅkāra。

V.25

rāgam は śleṣa（掛詞）で「赤み」と「愛着」の両義。mada（酒の酔い）が praṇayin（恋人）のように四つの作用を同時に果たす。śleṣa に基づく atiśayokti に upamā が混じる saṃkīrṇa。

V.26

nirvṛtir hi manaso madahetuḥ＝心の悦びこそが酔いの原因。一般命題で個別事例を支持する arthāntaranyāsa。この女は新妻で臆病であり、そもそも疑いを持つ者は飲むことすら控えるだろうという含み。

V.29

mukulitākṣi＝閉じた目。aṅgasāda＝体の衰弱。avasāditavāc＝言葉の衰え。これらは hrī（恥じらい）にも mada（酔い）にも共通の anubhāva（外的兆候）。酒が嫉妬から恥じらいの徴候を自ら帯びるという utprekṣā。hrī と mada の tulyābhāvakatva（同じ徴候を生む性質）に基づく。

sāmānyālaṅkāra（同一視の修辞）——飲酒前は月と頬の色が同じゆえ区別がつかない。飲酒後は頬が赤くなり、白い月影が lodhracūrṇa（白檀粉）のtilaka（装飾点）のように見える nidarśanā（例証）と結合。vyāñji は vy-añj の受動不定過去。

V.33

V.34

V.36

V.37

和訳

歯を食いしばる息づかい、甘い呻き声、哀れな訴え、やさしい愛語、「もうやめて」という禁止の言葉、笑い声、装身具の音色――これらすべてがカーマ・スートラの条文のようになった。

注

【Vallabhadeva】

【Mallinātha】

Vātsyāyana 等の kāma-tantra が教える情事の要素。実際の行為そのものが経典の条文となった、という utprekṣā。hāsa＝微笑、bhūṣaṇa-rava＝腕輪・足環の音。

V.76

和訳

V.77

和訳

「これほど大きなあなたが、情事のたびにこう軽々と落ちるとは、何ということ」――地に落ちて長々と伸びた腰紐は、あたかもそう問いかけるかのように、腰の偉大さを見せつけた。

【Vallabhadeva】

【Mallinātha】

rateṣu＝情事のたび。mahattva は jaghana の広大さ。落ちた紐が地に長く伸びることで、腰回りの大きさが証明される。utprekṣā のアランカーラ。

V.78
