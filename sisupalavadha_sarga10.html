दशमः सर्गः / 第十章　情事の描写（suratavarṇana）

飲酒の宴と愛の営みを描く
svāgatā throughout — r-n-bh-g-g (—◡— ◡◡◡ ——◡ ——), 11 syllables per pāda
V.1
Sanskrit (IAST) sajjitāni surabhīṇy atha yūnām ullasannayanavāriruhāṇi / āyayuḥ sughaṭitāni surāyāḥ pātratāṃ priyatamāvadanāni //
和訳

さて、若者たちの恋人の顔は――美しく飾られ、芳しく香り、蓮華のように咲き開く瞳を湛え、端正に造られた――酒の器となった。

注

【Vallabhadeva】

priyatamāvadanāni（恋人たちの顔）が surāyāḥ pātratāṃ āyayuḥ（酒の器の地位に達した）。śleṣa：pātra は「器」と「ふさわしき者」の二義。顔は sajjita（化粧で飾られた）、surabhī（芳香ある）、ullasannayanavāriruhāṇi（蓮のように輝く瞳を持つ）、sughaṭita（端正に造られた）。酒杯もまた同じ形容が当てはまる。svāgatā 韻律。

【Mallinātha】

vadanāni が pātratāṃ āyayuḥ は pariṇāma の修辞。sajjita は「yāvaka 等で磨き清められた」。杯も同じ修容を持ち、顔で酒を飲んだ（＝口づけで味わった）という含意。śleṣasaṃkīrṇā upamā。

V.2
Sanskrit (IAST) sopacāram upaśāntavicāraṃ sānutarṣam anutarṣapadena / te muhūrtam atha mūrtam apīpyan prema mānam avadhūya vadhūḥ svāḥ //
和訳

さて、若者たちは怒りを払い去り、丁重に、分別を忘れさせるかのように、渇望を伴いつつ、酒（anutarṣa）の名のもとに、自らの妻たちに具現化した愛をひととき飲ませた。

注

【Vallabhadeva】

anutarṣapadena は「酒（anutarṣa）を口実として」。mūrtaṃ prema apīpyan は「形あるものとなった愛を飲ませた」（utprekṣā）。sopacāram は「敬意を込めて」。upaśāntavicāram は「善悪の判断が失われたさまで」。mānam avadhūya は「怒りを捨てて」。

【Mallinātha】

apīpyan は pā（飲む）の ṇijanta imperfect。anutarṣa は madya（酒）の異名。mūrtaṃ prema は utprekṣā：愛そのものを飲ませたかのよう。酒を飲ませるという行為の裏に愛情の表出を読む sāpahnavotprekṣā。

V.3
Sanskrit (IAST) krāntakāntavadanapratibimbe bhaṅgabālasahakārasugandhau / svāduni praṇaditālini śīte nirvivāra madhunīndriyavargaḥ //
和訳

恋人の顔の映像が映り込み、砕いた若いマンゴーの芳香が漂い、甘美で、蜂の群れが唸り、冷たい――そんな酒の中で、五感すべてが満たされた。

注

【Vallabhadeva】

五感の満足を一つの酒杯に集約する。映り込んだ顔は眼を、sahakāra（マンゴー）の香は鼻を、甘味は舌を、蜂の羽音は耳を、冷たさは肌を満たす。madhuni（酒に）indriyavargaḥ nirvivāra（感覚群が満足した）。

【Mallinātha】

krānta = saṃkrānta（映り込んだ）。bhaṅga = 砕いた若いマンゴーの花片（酒の香り付けに用いる）。pranaditālini は「蜂が鳴り響く」。五つの形容がそれぞれ五感の満足に対応する。padārthakāvyaliṅga（事物の理由に基づく修辞）。

V.4
Sanskrit (IAST) kāpiśāyanasugandhi vighūrṇann unmado 'dhiśayituṃ samaśeta / phulladṛṣṭi vadanaṃ pramadānām abjacāru caṣakaṃ ca ṣaḍaṅghriḥ //
和訳

酔って旋回する蜂は、酒の芳香に惹かれ、花のように見開かれた目の女たちの顔と、蓮のように美しい酒杯と、どちらにとまるべきか迷った。

注

【Vallabhadeva】

ṣaḍaṅghriḥ（六脚＝蜂）は kāpiśāyana（酒の一種）の香りに酔い、女の顔と酒杯の双方に adhiśayitum（止まろうと）した。両者が同じ芳香と蓮花の美しさを持つため区別がつかない。

【Mallinātha】

unmada（酔った）vighūrṇan（旋回する）蜂が、phulladṛṣṭi vadanam（開花したような瞳の顔）と abjacāru caṣakam（蓮のように美しい酒杯）の両方に samaśeta（迷った）。蜂の両者への欲求が等しいという tulyayogitā の修辞。

V.5
Sanskrit (IAST) bimbitaṃ bhṛtaparisruti jānan bhājane jalajam ity abalāyāḥ / ghrātum akṣi patati bhramaraḥ sma bhrāntibhāji bhavati kva vivekaḥ //
和訳

酒に満たされた杯に映った女の瞳を蓮と見なして、蜂は香りを嗅ごうと飛びかかった。惑いに囚われた者に、どうして分別があろうか。

注

【Vallabhadeva】

bhṛtaparisruti（parisrut＝蒸留酒を湛えた）杯に映った女の目を jalaja（蓮華）と見なして、蜂は ghrātum（嗅ぐために）落ちた。bhrāntibhāji（迷乱に与る者）にどこに viveka（判断力）があろうか。

【Mallinātha】

bhrānti は śleṣa：「飛び回ること」と「誤った認識」。蜂が瞳を蓮と錯覚する bhrāntimadalaṅkāra。その理由づけに śleṣa に基づく atiśayokti から引き出された arthāntaranyāsa。saṅkara（複合修辞）。

V.6
Sanskrit (IAST) dattam iṣṭatamayā madhu patyur bāḍham āpa pibato rasavattām / yat suvarṇamukuṭāṃśubhir āsīc cetanāvirahitair api pītam //
和訳

最愛の女が差し出した酒は、夫が飲むとき実にいっそう味わい深くなった。なぜなら、意識なき金の冠の光によってさえ、すでに「飲まれて」いたのだから。

注

【Vallabhadeva】

śleṣa：pīta は「飲まれた」と「黄金色にされた」の二義。無生物たる金冠の光線さえ酒を「飲んだ」（＝黄色く染めた）のだから、恋人の手から直接受けた有情の者ならばなおさら美味であるという含意。

【Mallinātha】

pīta の śleṣa に基づく atiśayokti。acetanāṃśukartṛkapānakriyānimittā utprekṣā（無生物を飲む主体に見立てる想像修辞）。無生物のものさえ飲めるならば、有情者にとってはいうまでもないという arthāpattivyañjana。

V.7
Sanskrit (IAST) svādanena sutanor avicārad oṣṭhataḥ samacariṣṭa raso 'tra / anyam anyad iva yan madhu yūnaḥ svādam iṣṭam ataniṣṭa tad eva //
和訳

美しい女の唇を味わったことで、疑いなくその味わいが酒に移り入った。なぜなら、まさにその同じ酒が、まるで別の飲み物であるかのように、若者にとって新たな好ましい味を生み出したのだから。

注

【Vallabhadeva】

sutanoḥ oṣṭhataḥ は「美しい女の唇から」。samacariṣṭa は saṃ+car のアオリスト（味が移り入った）。同じ酒なのにまるで別の酒のように新しい味がした。唇の味が酒に移ったからこそ別物に感じられるという utprekṣā。

【Mallinātha】

svādanena は āsvādana（味わうこと）。avicārāt は「疑いなく」。唇に触れた後にこそ味が変わったということから、味の移行を推定する utprekṣā。vyañjakāprayogāt（暗示表現の使用により）vācyā（直接表現の修辞）。

V.8
Sanskrit (IAST) bibhratau madhuratām atimātraṃ rāgibhir yugapad eva papāte / ānanair madhuraso vikasadbhir nāsikābhir asitotpalagandhaḥ //
和訳

この上ない甘美さを帯びた二つのもの――酒の味と青蓮華の香り――が、情熱ある者たちの花開く顔と鼻とによって、同時に味わわれた。

注

【Vallabhadeva】

bibhratau（二つのものが甘美さを担う）は双数。madhurasa（酒の味）は ānanaiḥ（顔＝口で）、asitotpalagandha（青蓮華の香）は nāsikābhiḥ（鼻で）、yugapad eva（同時に）ともに papāte（飲まれた＝味わわれた）。二つの感覚対象が同時に享受された。

【Mallinātha】

madhurasa（酒の味）と asitotpalagandha（青蓮華の芳香）という、本来別の感覚器官で捉えるべき二つが yugapad（同時に）享受されたという tulyayogitā の修辞。vikasadbhiḥ（咲き開く＝渇望に膨らむ）は顔と鼻の両方にかかる。

V.9
Sanskrit (IAST) pītavaty abhimate madhutulyasvādam oṣṭharucakaṃ vidadaṅkṣau / labhyate sma pariraktatayātmā yāvakena viyatāpi yuvatyāḥ //
和訳

愛しい男が酒を飲み干すと、酒と同じ甘さの唇という宝飾を噛みたがったが――去りゆく若い女の唇から、紅の染料の赤さによって、その本来の姿がふたたび現れた。

注

【Vallabhadeva】

oṣṭharucakam は「唇という装飾品」。pītavati は「（男が）飲んだ時」（locative absolute）。yāvaka（ラック染料）の tikta（苦味）によって唇の ātman（本性＝甘さとの区別）が明らかになる。酒と唇は同じ甘さゆえ区別できないが、ラック染料の味で初めて唇と分かる。

【Mallinātha】

vidadaṅkṣau は daṃś（噛む）の desiderative：「噛もうとした」。madhutulyasvādam は「酒と等しい味の」。viyatā（去りゆく）女の唇から pariraktatayā（赤く染まっていることによって）ātmā（自己＝本性）が回復された。

V.10
Sanskrit (IAST) kasyacit samadanaṃ madanīyapreyasīvadanapānaparasya / svāditaḥ sakṛd ivāsava eva pratyuta kṣaṇavidaṃśapade 'bhūt //
和訳

ある若者は、酔わせる恋人の顔を飲むことに夢中になっていた。酒はただ一度味わわれたに過ぎず、かえって一口のつまみ程度のものとなってしまった。

注

【Vallabhadeva】

samadanam は「欲情を伴って」。madanīyapreyasīvadanapānaparasya は「酔わせる恋人の顔を飲むこと（＝口づけ）に専念する者の」。通常は酒が主で肴が従だが、この男にとっては恋人の顔への口づけが主で、āsava（酒）は pratyuta（かえって）avadaṃśapade（つまみの地位に）落ちた。

【Mallinātha】

vadanapāna は「顔を飲むこと」＝口づけ。sakṛd iva（一度だけのように）味わわれた酒が、avadaṃśa（酒の肴）の地位に転落した。主客が逆転する洒落た情景。

V.11
Sanskrit (IAST) pītaśīdhumadhurair mithunānām ānanaiḥ parihṛtaṃ caṣakāntaḥ / vrīḍayā rudadivālibirāvair nīlanīrajam agacchad adhastāt //
和訳

杯の中に香りのために沈められた青蓮は、酒を飲んで甘い息の恋人たちの顔に見捨てられ、恥じらいに泣くかのように蜂の羽音とともに沈んでいった。

注

【Vallabhadeva】

nīlanīrajam（青蓮）は杯の中に香りづけとして入れられた花。恋人たちが互いの顔に見とれて杯を放置したため、花は底に沈む。その際の蜂の声を「泣き声」に見立てる。caṣakāntaḥ＝pātramadye（杯の中で）。

【Mallinātha】

酒の消費とともに杯底に沈む青蓮の情景。parihṛtam＝tyaktam。蜂の羽音を泣き声に喩えるのは、集団の中で見捨てられた者は必ず泣くという俗諺に基づく。rūpaka と utprekṣā の saṅkara。

V.12
Sanskrit (IAST) prātibhaṃ trisarakeṇa gatānāṃ vakravākyaracanāramaṇīyaḥ / gūḍhasūcitarahasyasahāsaḥ subhruvāṃ pravavṛte parihāsaḥ //
和訳

三杯の酒で機知を得た美眉の女たちの間に、巧みな言い回しで趣深く、密やかに秘事を仄めかしつつ笑いを含んだ戯れが始まった。

注

【Vallabhadeva】

trisarakeṇa＝三度の飲酒（triḥpātena）で prātibham＝dhṛṣṭatvam（大胆さ）を得た。gūḍham＝aprakaṭam（隠された）、sūcitam＝īṣaduktam（わずかに示された）、rahasya＝秘めごと。parihāsa＝narma（冗談・戯れ）。

【Mallinātha】

saraka は酒杯・飲酒・酒そのものの三義を持つ。prātibham は pratibhā（機知）の派生語。vakravākya は遠回しの言葉、rahasya は以前は恥じらいに隠されていた私的な事柄を指す。ここから mada（酔い）が sañcārī（副次的情感）として機能する。

V.13
Sanskrit (IAST) hāvahāri hasitaṃ vacanānāṃ kauśalaṃ dṛśi vikāraviśeṣāḥ / cakrire bhṛśam ṛjor api vadhvāḥ kāmineva taruṇena madena //
和訳

媚態に満ちた笑い、言葉の巧みさ、目もとの様々な色めき——素朴な花嫁にさえ、まるで若い恋人のように、初々しい酔いがこれらを大いにもたらした。

注

【Vallabhadeva】

ṛjoḥ＝atimuṣṭhāyāḥ（きわめて素朴な女）にさえ。taruṇena madena＝pratyagreṇa jīvatayā（新鮮な活気ある酔いによって）。kāminā iva＝若い恋人がそうするように。hāva は vilāsa（なまめかしい仕草）の一種。

【Mallinātha】

cakrire は karmaṇi（受動態）。素朴な花嫁にさえそうであるなら、況んや熟練の女にはなおさら——という arthāpatti（推論的含意）が示される。hasita・kauśala・vikāra の三者が同時に生じることで samuccaya（併列修辞）、さらに upamā との saṅkara。

V.14
Sanskrit (IAST) aprasannam aparāddhari patyau kopadīptam urarīkṛtadhairyam / kṣālitaṃ nu śamitaṃ nu vadhūnāṃ drāvitaṃ nu hṛdayaṃ madhuvāraiḥ //
和訳

過ちを犯した夫に対して不機嫌で、怒りに燃え、決然と心を固めていた妻たちの胸を、酒の杯は洗い流したのか、鎮めたのか、それとも溶かしたのか。

注

【Vallabhadeva】

aprasannam＝kaluṣam（濁った）は kṣālitam（洗浄された）に、kopadīptam＝kopena jvalitam（怒りに燃えた）は śamitam（鎮火された）に、urarīkṛtadhairyam＝aṅgīkṛtakāṭhinya（固さを受け入れた）は drāvitam（溶かされた）に、それぞれ yathāsaṅkhya で対応する。

【Mallinātha】

汚れたものは洗い、燃えたものは消し、硬いものは溶かす——酒は液体であるからこそこの三つすべてが可能。nu は saṃśaya（疑い）を示す。三つの形容が互いに矛盾しないため、真の saṃśayālaṅkāra ではなく yathāsaṅkhyālaṅkāra。

V.15
Sanskrit (IAST) santam eva ciram aprakṛtatvād aprakāśitam adidyutad aṅge / vibhramaṃ madhumadaḥ pramadānāṃ dhātulīnam upasarga ivārtham //
和訳

女たちの体に久しく存在しながらも、折がなく表に出なかった媚態を、酒の酔いが輝かせた——動詞の語根に潜む意味を接頭辞が顕わにするように。

注

【Vallabhadeva】

dhātu（語根）に līna（潜む）artham（意味）を upasarga（接頭辞）が顕示するように、女たちの体に常にあった vibhrama（媚態）を madhumada（酒の酔い）が明るみに出した。aprakṛtatvāt＝aprastāvāt（場にそぐわないため）。adidyutat は dyut の不定過去。

【Mallinātha】

文法学の比喩。upasarga は dhātu の意味を「遮断する」のではなく「明示する」もの。同様に vibhrama は常に女の本性に内在するが、年長者の前や家事の場では aprakṛta（不適切）ゆえ現れない。酒の酔いがそれを解放する。upamālaṅkāra。

V.16
Sanskrit (IAST) sāvaśeṣapadam uktam upekṣā srastamālyavasanābharaṇeṣu / gantum utthitam akāraṇataḥ sma dyotayanti madavibhramam āsām //
和訳

言いさしの言葉、花飾りや衣や装身具が落ちても気にかけぬこと、理由もなく立ち上がって行こうとすること——これらが彼女たちの酔いの乱れを示していた。

注

【Vallabhadeva】

sāvaśeṣapadam uktam＝言い終わらぬ言葉。srasta＝落ちた。mālyavasanābharaṇeṣu upekṣā＝花輪・衣服・装飾品への無関心。akāraṇataḥ＝理由なく。これらは madavibhrama（酔いによる昂奮）の anubhāva（外的徴候）。

【Mallinātha】

言いかけの言葉、装飾品への無頓着、理由のない立ち上がり——三つの行動が共同して酔いの兆候を示す khaṇḍopakti 式の第二 samuccaya。各徴候が一つでは不十分だが、複合して酔態を物語る。

V.17
Sanskrit (IAST) madyamandavigalattrapam īṣac cakṣur unmiṣitapakṣma dadhatyā / vīkṣyate sma śanakair navavadhvā kāmino mukham adhomukhayaiva //
和訳

酒にゆるやかに恥じらいの薄れた、睫毛をわずかに持ち上げた目をして、新妻はうつむいたまま、そっと恋人の顔を盗み見ていた。

注

【Vallabhadeva】

adhomukhayā eva＝俯いたまま。madyena mandaṃ vigalantī trapā＝酒により徐々に消えゆく恥じらい。unmiṣitapakṣma＝睫毛をわずかに開いた。横目の一瞥を描く。

【Mallinātha】

navavadhvā＝navoḍhayā（新たに嫁いだ女）。酔いと羞恥の拮抗——酔いにもかかわらず恥じらいが勝る初々しさの極致。maugdhya（素朴さ）の atiśayokti。

V.18
Sanskrit (IAST) yā kathañcana sakhīvacanena prāg abhipriyatamaṃ prajagalbhe / vrīḍajāḍyam abhajan madhupā sā svāṃ madāt prakṛtim eti hi sarvaḥ //
和訳

以前は友の勧めでやっとのことで恋人の前で大胆にふるまえた女が、酒を飲むとかえって恥じらいに固まってしまった——酔えば誰もが本性に戻るものだから。

注

【Vallabhadeva】

madāt svāṃ prakṛtim eti＝酔いにより自らの本性に帰る。本来恥じらい深い女であるから、酔いが彼女を大胆にするのではなく、かえって恥じらいという本性を露わにする。madhupā＝madhu（酒）を pibatī（飲む者）。

【Mallinātha】

abhipriyatamam＝priyatamasamakṣam（最愛の者の前で）。prajagalbhe は galbh の完了形。vrīḍajāḍyam＝maugdhyam（恥じらいの硬直）。一般命題「酔えば本性に戻る」で個別事例を裏づける arthāntaranyāsa。

V.19
Sanskrit (IAST) chāditaḥ katham api trapayāntaryaḥ priyaṃ prati cirāya ramaṇyāḥ / vāruṇīmadaviśaṅkam athāviś cakṣuṣo 'bhavad asāv iva rāgaḥ //
和訳

美しい女の、恋人への長い想いが恥じらいに辛うじて内に隠されていたが、酒の酔いに臆することなく、それが目からあらわになった——あの情念そのもののように。

注

【Vallabhadeva】

chāditaḥ＝pihitaḥ（隠された）。rāga は śleṣa（掛詞）で「愛情」と「赤み」の両義。内なる恋情が酒の力で目の赤みとして外にあらわれた。vāruṇīmadaviśaṅkam＝酒の酔いにより恐れなく。

【Mallinātha】

rāga の二義——rati-rāga（愛欲）と mada-rāga（酒の赤み）——の śleṣa に基づく abheda-adhyavasāya（同一視）による atiśayokti。内に閉じ込められた情念が、酒に解き放たれて目の充血として外に溢れ出す。āviḥ bhū の構文。

V.20
Sanskrit (IAST) āgatān agaṇitapratiyātān vallabhān abhisisārayiṣūṇām / prāpi cetasi savipratisāre subhruvām avasaraḥ sarakeṇa //
和訳

かつて訪ねて来た恋人を顧みず帰してしまい、今は呼び戻したいと悔やむ美眉の女たちにとって、酒は心に口実を与えた。

注

【Vallabhadeva】

āgatān＝自ら来た恋人たちを、agaṇitān＝顧みず、pratiyātān＝去らせた。後悔する女たちが abhisārayiṣati（呼び寄せたい）と望むが、体面を気にして踏み出せない。sarakeṇa＝酒の力で「酔いのせいだ」と言い訳でき、avasara（機会）を得た。

【Mallinātha】

abhisisārayiṣūṇām は abhi-sṛ の使役活用の希求形。savipratisāre＝paścāttāpayukte（後悔に満ちた）心に。酒が困難な行為を容易にするという samādhyalaṅkāra。自分から呼び寄せれば軽薄と見なされるが、酔いを口実にすれば非難を免れる。

V.21
Sanskrit (IAST) mā punas tam abhisīsaram āgaskāriṇaṃ madavimohitacittā / yoṣid ity abhilalāpa na hālāṃ dustyajaḥ khalu sukhād api mānaḥ //
和訳

ある女は、酔いに心を惑わされながらも「あの罪深い男のもとへ二度と行くまい」と言って酒を断った——誇りは快楽よりもなお捨てがたいものだから。

注

【Vallabhadeva】

māniṇī（矜持の女）であるがゆえに hālā（酒）すら拒む。飲めば酔いのせいでまたあの男のもとへ行ってしまいかねない。sukhādapi māno dustyajaḥ＝快楽よりも誇りの方が捨てがたい、という一般命題で裏づける。

【Mallinātha】

abhisīsaram は sṛ の使役活用の luṅ（不定過去）一人称単数。「dīrgho laghoḥ」の規則により重複音節が長母音化。āgaskāriṇam＝aparādhakṛtam（過ちを犯した者）。一般命題による特殊事例の支持で arthāntaranyāsa。

V.22
Sanskrit (IAST) hrīvimoham aharat dayitānām antikaṃ ratisukhāya nināya / saprasādam iva sevitam āsīt sadya eva phaladam madhu tāsām //
和訳

酒は彼女たちの恥じらいの迷いを取り去り、愛の喜びのために恋人のそばへ導いた。まるで信心をもって仕えられたかのように、酒は彼女たちにたちまち実を結んだ。

注

【Vallabhadeva】

saprasādam＝心からの敬意をもって。madhu（酒）は sevita（奉仕された）ものとして sadya eva phaladam（即座に果実をもたらすもの）であった。hrīvimoha（恥じらいの惑い）を除き、dayitānām antikam（恋人の近くへ）導いた。

【Mallinātha】

saprasādam＝manaḥprasādapūrvakam（心の清浄を伴って）。「師・医・聖者には信心をもって仕えよ」との格言になぞらえる。hrī の除去と恋人への誘導という二つの効果で果報を説明する kāvyaliṅga。

V.23
Sanskrit (IAST) dattam āttamadanaṃ dayitena vyāptam atiśāyikena rasena / sasvade mukhasuraṃ pramadābhyo nāma rūḍham api ca vyudapādi //
和訳

恋人から与えられ、情を掻き立て、この上ない風味に満ちた口移しの酒は女たちに美味であった。そして「歓喜の女」という彼女たちの名も、慣用を超えて真に相応しいものとなった。

注

【Vallabhadeva】

mukhasura（口の酒）は口移しの酒、すなわち口から口へ渡された gaṇḍūṣamadya。pramadā の語源は pra+mada（激しい酔い）であり、この場面で酒に深く酔った女たちにおいて、慣用的な名が語源通りの意味を持つに至った。

【Mallinātha】

mukhasura は女性名詞 surā の中性形（「vibhāṣā senāsurā-」の規則による）。rūḍham＝prāgabhrākaṇādivadavyutpannam（語源に遡らぬ慣用的な名）。vyudapādi は pad の使役形 luṅ。前半の文意が後半の根拠となる kāvyaliṅga。

V.24
Sanskrit (IAST) labdhasaurabhaguṇo madirāṇām aṅganāsyacaṣakasya ca gandhaḥ / moditāliritaretarayogād anyatām abhajatātiśayaṃ nu //
和訳

酒の香りと、女たちの顔という杯の香りとが、互いに混じり合って芳しさを増し蜂を喜ばせた——それは全く別の香りとなったのか、それとも一層強まっただけなのか。

注

【Vallabhadeva】

madirā の香りと aṅganāsya-caṣaka（女の顔という杯）の香りが itaretarayogāt（相互の結合により）増す。前者が後者を高め、後者もまた前者を高める。anyatā（別のもの）になったか atiśaya（より強い同じもの）になったかで saṃśaya（疑い）が生じる。

【Mallinātha】

yakṣakardama（香膏の混合）と ghṛtākta-kuṅkuma（バター入りクンクマ）のように、混合物が新しい性質を帯びるか元の性質の強化かは判然としない。moditāli＝ānandita-bhṛṅga（喜ぶ蜂）。saṃśayālaṅkāra。

V.25
Sanskrit (IAST) mānabhaṅgapaṭunā suratecchāṃ tanvatā prathayatā dṛśi rāgam / lebhire sapadi bhāvayatāntar yoṣitaḥ praṇayineva madena //
和訳

矜持を砕き、情交への欲を広げ、目に情の色を浮かべさせ、心の奥を揺り動かす酒によって、女たちはたちまち、恋人に口説かれるかのように心を奪われた。

注

【Vallabhadeva】

mānabhaṅgapaṭunā＝矜持を砕くに巧みな。suratecchāṃ tanvatā＝情交への望みを広げつつ。dṛśi rāgam prathayatā＝目に情の色を顕しつつ。antaḥ bhāvayatā＝心の内を揺り動かしつつ。praṇayinā iva＝恋人のように。

【Mallinātha】

rāgam は śleṣa（掛詞）で「赤み」と「愛着」の両義。mada（酒の酔い）が praṇayin（恋人）のように四つの作用を同時に果たす。śleṣa に基づく atiśayokti に upamā が混じる saṃkīrṇa。

V.26
Sanskrit (IAST) pānadhautanavayāvakarāgaṃ subhruvo nibhṛtacumbanadakṣāḥ / preyasām adhararāgarasena svaṃ kilādharamupāli rarañjuḥ //
和訳

酒を飲んで唇の新しい紅が洗い落とされた美眉の女たちは、ひそやかな口づけに巧みで、女友だちのそばにいながら恋人の唇の色を自らの唇に移し染めた。

注

【Vallabhadeva】

upāli＝ālī（女友だち）の近くで。nibhṛtacumbanadakṣāḥ＝密かな口づけに巧みな。yāvakarāga は lac（紅）の色。pāna（飲酒）で洗い落とされた唇に preyasām adhararāgarasena（恋人の唇の色の汁で）新たな色を塗った。

【Mallinātha】

rāga の口実で密かに恋人の唇を吸ったという nīlaṅkārabheda（隠蔽の修辞法）。rañj は「染める」だが、実際は口づけの隠喩。kilā＝aparamārthe（本気でなく見せかけて）。友人の前でありながらの巧みな振る舞い。

V.27
Sanskrit (IAST) arpitaṃ rasitavatyapi nāmagrāham anyayuvater dayitena / ujjhati sma madam apyapibantī vīkṣya madyam itarā tu mamāda //
和訳

恋人が別の女の名を呼びつつ差し出した酒を味わいながらも、ある女は酔いを失った。しかし名を呼ばれた方の女は、飲みもしないのに見ただけで酔いしれた。

注

【Vallabhadeva】

nāmagrāham＝名前を呼んで。arpitam＝差し出された酒。rasitavatyapi＝味わったにもかかわらず。嫉妬により酔いが醒めた一方、名を呼ばれた栄誉で飲まずとも酔った。mada は酔いと誇りの二義。

【Mallinātha】

前半は viśeṣokti（結果の不在を示す修辞）——原因（飲酒）があるのに結果（酔い）がない。後半は vibhāvanā（原因なき結果）——飲んでいないのに酔う。両者の saṅkara（混合修辞）。

V.28
Sanskrit (IAST) anyayānyavanitāgatacittaṃ cittanātham abhiśaṅkitavatyā / pītabhūrisurayāpi na mede nirvṛtir hi manaso madahetuḥ //
和訳

夫の心が他の女に移ったと疑うある女は、たっぷり酒を飲んでも酔えなかった——心の喜びこそが酔いの真の原因なのだから。

注

【Vallabhadeva】

cittanātham＝bhartāram（夫）。anyavanitāgatacittam＝sapatnīsaṅkrāntacetasam（他の女に心が移った者）。pītabhūrisurayā api＝多量の酒を飲んだにもかかわらず。na mede＝酔わなかった。mādy の bhāve liṅ。

【Mallinātha】

nirvṛtir hi manaso madahetuḥ＝心の悦びこそが酔いの原因。一般命題で個別事例を支持する arthāntaranyāsa。この女は新妻で臆病であり、そもそも疑いを持つ者は飲むことすら控えるだろうという含み。

V.29
Sanskrit (IAST) kopavatyanunayān agṛhītvā prāg atho madhumadāhitamohā / kopitaṃ virahakheditacittā kāntam eva kalayantyanuninyē //
和訳

以前は怒りに満ちて恋人の懇願を退けたこの女が、今は酒の酔いに惑わされ、離別に心を痛め、自ら怒らせた恋人のもとへ行きなだめた。

注

【Vallabhadeva】

prāk＝以前。kopavatī＝怒りに満ちて。anunayān＝恋人の懇願を。agṛhītvā＝受け入れずに。athaḥ＝その後、酒の酔いで惑い、自らが怒らせた男をかえって宥めに行った。kalahāntaritā（痴話喧嘩で隔てられた女）の類型。

【Mallinātha】

madhumadāhitamohā＝酒の酔いが迷いを与えた状態。virahakheditacittā＝離別の苦に心を痛めて。anuninye は anu-nī の完了形。自ら相手を怒らせておきながら自分から折れるという逆説的行動を酒の作用に帰す。

V.30
Sanskrit (IAST) kurvatā mukulitākṣiyugānām aṅgasādam avasāditavācām / īrṣyayeva haratā hriyam āsāṃ tadguṇaḥ svayam akāri madena //
和訳

目を閉じさせ、体を萎えさせ、声を弱めることで、酒はまるで嫉妬するかのように、自ら奪った恥じらいと同じ効果を自ら生み出した。

注

【Vallabhadeva】

hrī（恥じらい）と mada（酔い）は共に同じ外的徴候を持つ——目の閉じ、体の弛緩、声の衰え。酒が恥じらいを奪いながら、そのまま恥じらいの効果を自ら再現するという矛盾。īrṣyā（嫉妬）による utprekṣā——恥じらいの領分を横取りするかのように。

【Mallinātha】

mukulitākṣi＝閉じた目。aṅgasāda＝体の衰弱。avasāditavāc＝言葉の衰え。これらは hrī（恥じらい）にも mada（酔い）にも共通の anubhāva（外的兆候）。酒が嫉妬から恥じらいの徴候を自ら帯びるという utprekṣā。hrī と mada の tulyābhāvakatva（同じ徴候を生む性質）に基づく。

V.31
Sanskrit (IAST) gaṇḍabhittiṣu purā sadṛśīṣu vyāñji nāñjitadṛśāṃ pratimenduḥ / pānapāṭalitakāntiṣu paścāl lodhracūrṇatilakākṛtir āsīt //
和訳

化粧した美しい目の女たちの頬に、飲酒の前は色が似ているため映った月は見分けがつかなかった。飲酒で頬が薔薇色に染まった後は、月影が白檀粉の額飾りのようにくっきりと浮かんだ。

注

【Vallabhadeva】

purā＝飲酒前。sadṛśīṣu＝頬と月が同じ蒼白色であったため。pratimenduḥ＝pratibiṃbacandra（映った月）が vyāñji na＝顕われなかった。pānapāṭalita＝酒で赤らんだ後は色の違いから月影が白い tilaka のように見えた。

【Mallinātha】

sāmānyālaṅkāra（同一視の修辞）——飲酒前は月と頬の色が同じゆえ区別がつかない。飲酒後は頬が赤くなり、白い月影が lodhracūrṇa（白檀粉）のtilaka（装飾点）のように見える nidarśanā（例証）と結合。vyāñji は vy-añj の受動不定過去。

V.32
Sanskrit (IAST) uddhatair iva parasparasaṅgād īritāny ubhayataḥ kucakumbhaiḥ / yoṣitām atimadena jughūrṇur vibhramātiśayapuṃsi vapūṃṣi //
和訳

溢れる媚態を湛えた女たちの体は、深酔いに揺れ動いた——まるで傲然たる力士のようにぶつかり合う壺のような双乳に、両側から押しやられるかのように。

注

【Vallabhadeva】

kucakumbhaiḥ＝壺のような胸。parasparasaṅgāt＝互いにぶつかり合うことで。ubhayataḥ＝両側から。uddhataiḥ iva＝傲慢な力士のように。jughūrṇuḥ＝ghūrṇ（揺れる）の完了形。vibhramātiśayapuṃsi＝媚態の極みを育む体。

【Mallinātha】

力士同士の格闘で互いの衝突から体が揺れるように、重い胸が揺れ合うことで体全体が揺れるという比喩。atimadena＝過度の酔いにより。vapūṃṣi は napuṃsaka の複数形。

V.33
Sanskrit (IAST) cārutā vapur abhūṣayad āsāṃ tām anūnanavayauvanayogaḥ / taṃ punar makaraketanalakṣmīs tāṃ mado dayitasaṃgamabhūṣaḥ //
和訳

彼女たちの体を美しさが飾り、その美しさを満ちた若さが飾り、その若さを愛神の輝きが飾り、その輝きを——恋人との逢瀬を飾りとする——酔いが飾った。

注

【Vallabhadeva】

cārutā→vapus→yauvanayoga→makaraketanalakṣmī→mada→dayitasaṅgama と、後のものが前のものを順次飾る連鎖。恋人の不在ではすべての要素が意味をなさない。dīpakālaṅkāra。

【Mallinātha】

後続の各項が前項を飾る ekāvalī（首飾り型修辞）。Bhāravi の「śuci bhūṣayatī-」に倣う手法。mada（酔い）の最終の装飾が dayitasaṅgama（恋人との逢瀬）であることで、酒の効果が恋の成就に直結することを示す。

V.34
Sanskrit (IAST) kṣībatām upagatāsv anuvelaṃ tāsu roṣaparitoṣavatīṣu / agrahīn nu saśaraṃ dhanur ujjhāmāsa nūjjhitaniṣaṅgam anaṅgaḥ //
和訳

酔いに達し刻一刻と怒りと歓びを交互にみせる女たちに対して、愛神は矢を携えて弓を取ったのか、それとも矢筒ごと投げ捨てたのか。

注

【Vallabhadeva】

女たちが怒るとき愛神は弓を取り（「この者たちを征服しよう」と）、喜ぶとき弓を捨てる（すでに征服されたため）。anuvelam＝絶え間なく。ujjhitaniṣaṅgam＝矢筒まで捨てた。

【Mallinātha】

kṣībatā＝mattatā（酔態）。agrahīt nu... ujjhāmāsa nu＝取ったのか…捨てたのか。roṣa（怒り）→弓を取る、paritoṣa（満足）→弓を捨てる、の yathāsaṅkhya に utprekṣā が重なる saṅkara。ujjhāmāsa は ujjh の完了形。

V.35
Sanskrit (IAST) śaṅkayānyayuvatau vanitābhiḥ pratyabhedi dayitaḥ sphuṭam eva / na kṣamaṃ bhavati tattvavicāre matsareṇa hatasaṃvṛti cetaḥ //
和訳

他の女への疑いだけで、妻たちは恋人をあからさまに責め立てた。嫉妬に分別を失った心は、真実を見極める力を持たないのだ。

注

【Vallabhadeva】

śaṅkayā＝単なる疑念で。sphuṭam eva＝確定したかのように明白に。pratyabhedi＝非難された（受動不定過去）。saṃvṛti＝sneha（思慮深さ）gāmbhīrya（沈着）。嫉妬がこれを破壊すると真実の吟味ができない。

【Mallinātha】

anyayuvatau＝sapatnyām（共妻＝ライバルの女）に関して。pratyabhedi は karmaṇi（受動態）。不当な非難であっても嫉妬に目が眩んだ心は検証できない、という一般命題で支持する arthāntaranyāsa。

V.36
Sanskrit (IAST) ānanair vicakase hṛṣitābhir vallabhān abhi tanūbhir abhāvi / ārdratāṃ hṛdayam āpa ca roṣo lolati sma vacaneṣu vadhūnām //
和訳

妻たちの顔は輝き開き、総毛立つ体は恋人の方へと向かい、心は柔らかくなった——ただ言葉の中にのみ、怒りがまだ揺れ残っていた。

注

【Vallabhadeva】

ānanaiḥ vicakase＝顔で花開いた。tanūbhiḥ hṛṣitābhiḥ＝鳥肌の立った体で（恋人の方へ）。hṛdayam ārdratām āpa＝心は柔らかさを得た。roṣaḥ vacaneṣu lolati sma＝怒りは言葉の中だけで揺れていた。

【Mallinātha】

vicakase は vi-kas（花開く）の bhāve liṭ（完了形）。abhāvi は bhāve luṅ。顔の開花・体の歓喜・心の軟化・言葉の怒り残留の四つが同時に起こる samuccaya。怒りは言葉だけに残り、もはや曲がった調子すら失われている。

V.37
Sanskrit (IAST) rūpam apratividhānam anojñaṃ prema kāryam anapekṣya vikāsi / cāṭu cākṛtakasaṃbhramam āsāṃ kāmaṇatvam agaman ramaṇeṣu //
和訳

造作なく魅力的な容姿、打算を離れて広がる愛情、飾らぬ甘い言葉——これらが恋人たちへの呪術のような力となった。

注

【Vallabhadeva】

rūpa＝apratiyatnam anoharam（努力なく魅惑する容姿）。prema＝kāryam anapekṣya vikāsi（目的を気にせず広がる愛情）。cāṭu＝akṛtakasaṃbhramam（作為のない甘言）。kāmaṇatvam＝vaśīkaraṇakatvam（呪術的な魔力）。

【Mallinātha】

rūpa・prema・cāṭu の三つに kāmaṇatva（魔術的な支配力）が付与される pariṇāmālaṅkāra（転変の修辞）。kāmaṇa は『アマラコーシャ』に vaśīkṛyā（支配術）と定義される。agaman は gam の luṅ。

V.38
Sanskrit (IAST) līlayaiva sutanos tulayitvā gauravāḍhyam api lāvaṇikena / mānavañcanavidā vadanena krītam eva hṛdayaṃ dayitasya //
和訳

ほっそりした女の顔は、秤の不正に長けた塩商人のように、重々しい恋人の心をいとも軽々と量り、その美しさで買い取ってしまった。

注

【Vallabhadeva】

lāvaṇikena は二義を持つ：（1）lāvaṇya（美しさ）を備えた、（2）lavaṇa（塩）を商う者。mānavañcanavidā＝（1）矜持を奪うに巧みな、（2）秤を誤魔化す術を知る。vadanena＝顔によって（商人の意では「言葉で」）。gauravāḍhyam＝（1）重厚な、（2）重い。samāsokti（暗示的比喩）。

【Mallinātha】

lāvaṇika は「atiṇiṭhanau」により lāvaṇya から派生。samāsokti として、vadana（顔）が lāvaṇika（塩商人）に、hṛdaya（心）が paṇya（商品）に重ねられ、美しさによる心の獲得が商取引に擬えられる。krītam＝買い取られた＝征服された。

V.39
Sanskrit (IAST) sparśabhāji viśadacchavicārau kalpite mṛgadṛśāṃ suratāya / sannatiṃ dadhati petur ajasraṃ dṛṣṭayaḥ priyatame śayane ca //
和訳

鹿のような瞳の女たちの視線は、恋人と寝台の双方にひっきりなしに注がれた——どちらも触れて快く、明るく美しく、情事のために整えられ、しなやかに身を委ねるものだった。

注

【Vallabhadeva】

priyatama と śayana の双方に四つの形容が同時に適用される。sparśabhāji＝触れて快い（恋人の肌も寝台も）。viśadacchavicāru＝明るく美しい。suratāya kalpite＝情事のために用意された。sannatiṃ dadhati＝しなやかに従う。

【Mallinātha】

priyatama と śayana という二つの prakṛta（本来の主題）が同じ dharma（属性）を共有することで aupaṃya（比喩性）が生まれる tulyayogitā（等値修辞）。dṛṣṭayaḥ petuḥ＝視線が落ちた＝目がそちらに向いた。ajasram＝休みなく。

V.40
Sanskrit (IAST) yūni rāgataralair api tiryak pātibhiḥ śrutiguṇena yutasya / dīrghadarśibhir akāri vadhūnāṃ laṅghanaṃ na nayanaiḥ śravaṇasya //
和訳

花嫁たちの目は、情に揺れ、斜めに流れ、遠くまで届くものであったが、聴覚という徳を備えた耳を越えることはなかった——流し目は恋人の耳元で止まったのだ。

注

【Vallabhadeva】

nayanaiḥ＝目で。śravaṇasya laṅghanaṃ na akāri＝耳を越えなかった。すなわち流し目は恋人の耳元まで伸びて止まった。rāgataralaiḥ＝情欲に震える。tiryakpātibhiḥ＝斜めに落ちる。dīrghadarśibhiḥ＝遠くまで見る。śrutiguṇena yutasya＝聴覚の機能を備えた耳。

【Mallinātha】

samāsokti（暗示的比喩）による二重の意味。（1）字義通り：流し目は耳元で止まった。（2）比喩：情に揺れ斜めに動く者でも、聖典（śruti）の徳に裏打ちされていれば聖典の教えを踏み越えない。dīrghadarśin＝先見の明ある者。rāga・tiryakpātin・dīrghadarśin に śleṣa。

V.41
Sanskrit (IAST) saṃkathecchurabhidhātumanīśā saṃmukhī na ca babhūva didṛkṣuḥ / sparśanena dayitasya natabhrūraṅgasaṅgacapalāpi cakampe //
和訳

語らいたいのに話すことができず、見つめたいのに恋人の方を向けない。体の触れ合いに焦がれていても、愛する人の手が触れると、眉を伏せたその女は身を震わせた。

注

【Vallabhadeva】

語りたいのに語れず、見たいのに向き合えず、触れたいのに触れられると震える——これが mugdhā（初心な女）の振る舞いである。

【Mallinātha】

kampa（震え）等は lajjā-sādhvasa（羞恥と怯え）の anubhāva（身体的表現）。この女は lajjā に征服された mugdhā（羞恥に支配される初心な女）である。GRETIL 校訂：aṅgacapalāpi → aṅgasaṅgacapalāpi（saṅga 脱落、韻律 9→11音節）。

V.42
Sanskrit (IAST) uttarīyavinayāttrapamāṇā rundhatī kila tadīkṣaṇamārgam / āvariṣṭa vikaṭena vivoḍhurvakṣasaiva kucamaṇḍalamanyā //
和訳

上衣を取られて恥じらう別の女は、夫の視線を遮るかのように、夫の広い胸そのもので乳房を覆い隠した。乳房を隠す口実で抱きしめたのである。

注

【Vallabhadeva】

衣を奪われ恥じらい、広い夫の胸で乳房を覆った。kila は「口実として」の意——目線を遮るふりをして実は抱擁を求めた。胸で隠しても乳房は見えるし触れるのだから、lajjā は口実にすぎない。

【Mallinātha】

乳房を覆うことで抱擁の欲望を隠す unmīlana-bheda（隠れた開示）。この女は lajjā と manmatha の中間にある madhyamā（中間型の女）。GRETIL 校訂：ācariṣṭa → āvariṣṭa（ā-vṛ「覆う」の luṅ、両注釈確認）。kucamaṇaḍalam → kucamaṇḍalam（余分な母音、韻律 13→11音節）。

V.43
Sanskrit (IAST) aṃśukaṃ hṛtavatā tanubāhusvastikāpihitamugdhakucāgrā / bhinnaśaṅkhavalayaṃ pariṇetrā paryarambhi rabhasādaciroḍhā //
和訳

衣を奪った夫に、細い腕を交差させて胸の先を隠す新妻が、激しく抱きしめられた。その勢いに螺鈿の腕輪が砕け散った。

注

【Vallabhadeva】

ある新妻（aciroḍhā＝navavadhū）が夫に衣を奪われ、細い両腕を svastika（交差）させて美しい胸の先を隠していたが、夫は力ずくで抱きしめた（paryarambhi）。その勢いで螺鈿の腕輪が砕けた。

【Mallinātha】

paryarambhi は ram の受動態 luṅ（「抱きしめられた」）。numāgama（nUM 挿入）あり。この女は tirohita-mugdhā（初心さを隠す女）に分類される。bhinnaśaṅkhavalayam＝激しい抱擁で螺鈿の腕輪が割れた。

V.44
Sanskrit (IAST) saṃjahāra sahasā parirabdhapreyasīṣu virahayya virodham / saṃhitaṃ ratipatiḥ smitabhinnakrodhamāśu taruṇeṣu maheṣum //
和訳

若者たちが恋人を抱きしめ、怒りが微笑みに砕かれて痴話喧嘩も消え去ると、目的が果たされた愛神は、構えていた大きな矢をたちまち収めた。

注

【Vallabhadeva】

女たちが自ら進んで恋人を抱きしめたので、Kāma が矢を射る必要がなくなった。smitabhinnakrodham＝微笑で怒りが砕かれた状態。virahayya は rah（＋svārthika ya）の lyap 形で「捨てて」。taruṇīṣu の異読あり。

【Mallinātha】

siddhe'rthe sādhanānavakāśāt＝目的が達成されれば手段は不要になる。parirabdhapreyasīṣu＝恋人たちを抱擁した（女たちの）もとで。抱擁で恋の戦いは終結する。

V.45
Sanskrit (IAST) sraṃsamānamupayantari vadhvāḥ śliṣṭavatyupasapatni rasena / ātmanaiva rurudhe kṛtineva svedasaṅgi vasanaṃ jaghanena //
和訳

共妻のそばで夫に情熱のまま抱きしめられた花嫁の、ずり落ちかけた衣を、汗で肌に貼りついたその腰が、まるで心得た者のように自ら留めた。

注

【Vallabhadeva】

ある花嫁の衣が自然と腰に留められた。汗で貼りつく（svedasaṅgi）衣。共妻のそばで衣が落ちれば恥（lāghava）になると知っているかのような腰＝kṛtin（賢者）に喩える utprekṣā。

【Mallinātha】

svedasaṅgi＝sāttvika（不随意的身体反応）としての汗で貼りつく。腰が衣の軽率な落下を防いだという utprekṣā。GRETIL 校訂：upasapakṣi → upasapatni（avyayībhāva「共妻のそばで」、注釈確認）。svasaṅgi → svedasaṅgi（意味不通＋韻律 10→11音節）。

V.46
Sanskrit (IAST) pīḍite pura uraḥpratipeṣaṃ bhartari stanayugena yuvatyā / spaṣṭameva dalataḥ pratināryāstanmayatvamabhavaddhṛdayasya //
和訳

ある女が胸を夫の胸に押しつけて圧迫すると、目の前にいた共妻の心臓がはっきりと裂けた。夫と一体でなければ、彼が押されて自分の心が裂けるはずがない。

注

【Vallabhadeva】

uraḥpratipeṣam は ṇamul 形（「胸を押しつけながら」）。dalataḥ は「裂ける」だが、文字通りではなく比喩として解すべし、さもなくば bībhatsa（嫌悪感）を生じてしまう。

【Mallinātha】

tanmayatva＝夫と心が一体であること。夫が押されて共妻の心が裂ける＝ asaṃgati（因果の不一致）に基づく tanmayatva-utprekṣā の saṃkara（修辞の複合）。GRETIL 校訂：pratiṣedhaṃ → pratipeṣaṃ（「禁止」ではなく「圧搾」の ṇamul 形）。yuvatyāḥ → yuvatyā（属格→具格、両注釈確認）。pratināryaḥ → pratināryāḥ（属格長母音）。

V.47
Sanskrit (IAST) dīpitasmaramurasyupapīḍaṃ vallabhe ghanamabhiṣvajamāne / vakratāṃ na yayatuḥ kucakumbhau subhruvaḥ kaṭhinatātiśayena //
和訳

欲情をかき立てられた恋人が胸を押しつけ激しく抱きしめても、美眉の女の乳房は、その硬さの極みゆえにいささかも撓むことがなかった。

注

【Vallabhadeva】

kucakumbhau＝水瓶に喩えた乳房。vakratā＝歪み・撓み。kaṭhinatātiśayena＝硬さの極みによって。別解として：押されても「丸くならない」のは dṛḍhapratijñatva（堅い誓い）による＝性格の比喩。

【Mallinātha】

激しい抱擁でも乳房の壺が歪まないという atiśayokti（誇張法）。urasyupapīḍam は ṇamul 形。GRETIL 校訂：apapīḍaṃ → upapīḍaṃ（apa-「離れて」ではなく upa-「に向かって」押す、両注釈確認）。

V.48
Sanskrit (IAST) saṃpraveṣṭumiva yoṣita īṣuḥ śliṣyatāṃ hṛdayamiṣṭatamānām / ātmanaḥ satatameva tadantarvartino na khalu nūnamajānan //
和訳

抱きしめられる女たちの心に入り込もうとするかのような愛神の矢——だが矢は知らなかったのだ、自分がとうに彼女たちの心の内に宿っていることを。

注

【Vallabhadeva】

女たちは常に心に恋人を宿しており、矢はすでにその中にいるのに入ろうとするのは、piṣṭapeṣaṇa（既成事の反復）に等しい。ajānan は √jñā の laṭ。

【Mallinātha】

入ろうとする動作＝kriyāsvarūpa-utprekṣā（動作の想像比喩）。すでに内にいるのに気づかない＝aśānā-utprekṣā（不可能の想像比喩）。同種の saṃkara（修辞の複合）。

V.49
Sanskrit (IAST) snehanirbharamadhatta vadhūnāmārdratāṃ vapurasaṃśayamantaḥ / yūni gāḍhaparirambhaṇi vastrakṣopamambu vavṛṣe yadanena //
和訳

花嫁たちの体は愛情に満ち、疑いなく内側が潤っていた。若者が固く抱きしめると、衣を絞るように汗がしたたり落ちたからである。sneha に「愛情」と「油」の掛詞。

注

【Vallabhadeva】

sneha＝愛情と油脂の二義。snehanirbhara（愛に満ちた／油に満ちた）体は内部が湿る。証拠：夫に強く抱きしめられると、衣を絞る（vastrakṣopam）ように水が出た。内部が湿っていなければ、搾って水は出ない。

【Mallinātha】

antarārdratā（内部の湿り）の utprekṣā。汗は sāttvika（不随意的身体反応）。GRETIL 校訂：snahanirbharam → snehanirbharam（snaha は不在語）。adatta → adhatta（√dhā の過去形、「保持した」）。parirambhiṇi → parirambhaṇi（両注釈確認）。vastraknopamambu → vastrakṣopamambu（kn→kṣ、「衣の絞り」の ṇamul 形）。

V.50
Sanskrit (IAST) na sma māti vapuṣaḥ pramadānāmantariṣṭatamasaṅgamajanmā / yadbahurbahiravāpya vikāsaṃ vyānaśe tanuruhāṇyapi harṣaḥ //
和訳

最愛の人との逢瀬から生まれた歓びは、女たちの体の内に収まりきらず、あふれ出て外に広がり、体毛にまで行き渡った。

注

【Vallabhadeva】

歓び（harṣa）が内に収まらない＝水が壺に入りきらなければ外に溢れるという比喩。外に広がって体毛（tanuruhāṇi＝romāṇi）にまで及んだ＝鳥肌（romāñca）を意味する。vyānaśe は √aś の liṭ（nUḌ 挿入あり）。

【Mallinātha】

内に収まらないから外にあふれた＝antarmāna の utprekṣā。鳥肌と歓喜の śleṣamūla-abheda-adhyavasāya-atiśayokti（掛詞に基づく同一視の誇張法）。GRETIL 校訂：tadbahur → yadbahur（指示代名詞→関係代名詞、両注釈確認）。
