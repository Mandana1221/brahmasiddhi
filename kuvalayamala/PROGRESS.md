# クヴァラヤマーラー対訳 作業メモ

## 手順
1. 原文の取り出し: `python3 kuvalayamala/tools/sections.py <km.txt> 13 20 [--foot]`
   - km.txt は jainelibrary No. 002777 の docx から抽出した OCR テキスト（リポジトリ外）。
     docx は `word/document.xml` の `<w:t>` を段落ごとに連結して作る。
   - OCR では § が「६」と誤認される。自動分割が失敗した節（§7, 45, 80, 81, 84, 86, 99, 101, 103,
     131, 134, 135, 138, 146, 165, 176, 188, 195, 224, 255, 292, 328, 374, 408）は前後の節に含まれる。
2. data/NN_x.txt（NN = 巻番号）に書く。形式は build.py の冒頭を参照。
3. `python3 kuvalayamala/build.py` → kuvalayamala_N.html
4. 巻ごとにコミット・プッシュ。

## 方針
- 各ブロック：原文（OCRを韻律・文脈・脚注の異読で修正）／チャーヤー（試案）／和訳／解説 2〜4項目
- 解説のラベル：情景・背景・人物・教義・修辞・語注・本文（OCR修正と推定箇所）など
- 1巻 ≒ 20節前後。物語の区切りで分ける。
