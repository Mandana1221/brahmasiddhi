マハーバーラタ ― カルナ篇 第82章 対訳

Mahābhārata — Karṇaparvan, Adhyāya 82 (Southern Recension) — Bilingual Edition
本章は南伝（Southern Recension）テキストの「アディヤーヤ82」、全64詩節からなります。カルナの武勇の描写（第1〜64詩節）で本章は終わります。本章は詩節ごとの詳細な対訳が収録されています。
karṇaparva — dvyaśītitamo'dhyāyaḥ (82)
第82章　カルナの武勇の描写
dhṛtarāṣṭra uvāca|
tato bhagneṣu sainyeṣu bhīmasenena saṃyuge|
duryodhano'bravītkiṃ nu saubalo vā'pi sañjaya||
// 8-82-1 //
ドリタラーシュトラは語った。
karṇo vā jayatāṃ śreṣṭho yodhā vā māmakā yudhi|
kṛpo vā kṛtavarmā vā drauṇirduḥśāsano'pi vā||
// 8-82-2 //
弓持ちの中の最上者カルナは？あるいは我が方の戦士たちは？クリパは？クリタヴァルマンは？ドローナの子は？ドゥフシャーサナは？
atyadbhutamahaṃ manye pāṇḍaveyasya vikramam|
yadekaḥ samare sarvānyodhayāmāsa māmakān||
// 8-82-3 //
パーンダヴァの武勇はまことに驚嘆すべきものだと私は思う。一人で戦場において我が方の全員と戦ったのだから。
yathāpratijñaṃ yodhānāṃ rādheyaḥ kṛtavānapi|
kurūṇāmatha sarveṣāṃ karṇaḥ śatruniṣūdanaḥ|
śarma varma pratiṣṭhā ca jīvitāśā ca sañjaya||
// 8-82-4 //
ラーデーヤ（カルナ）は戦士たちへの誓いの通りに行動したのか？クルたちの全員にとって、敵を滅ぼすカルナこそが慰め、鎧、拠り所、そして生きる希望であるのだ、サンジャヤよ。
tadbhagraṃ svabalaṃ dṛṣṭvā kaunteyenāmitaujasā|
dhanurdarāṇāṃ pravaraḥ karṇaḥ kimakarodyudhi||
// 8-82-5 //
計り知れぬ力を持つカウンテーヤ（アルジュナ）に自軍が打ち破られるのを見て、弓の名手の中の最上者カルナは戦場で何をしたのか？
putrā vā mama durdharṣā rājāno vā mahārathāḥ|
etanme sarvamācakṣva kuśalo hyasi sañjaya||
// 8-82-6 //
あるいは、我が子ら、不屈の者たち、あるいは大戦車戦士たる王たちは？サンジャヤよ、汝はこれらを全て語る技量があるのだから、全てを語れ。
sañjaya uvāca|
aparāhṇe mahārāja sūtaputraḥ pratāpavān|
jaghāna somakānsarvānbhīmasenasya paśyataḥ||
// 8-82-7 //
サンジャヤは語った。
bhīmo'pyatibalaṃ sainyaṃ dhārtarāṣṭraṃ vyapothayat||
// 8-82-8 //
ビーマもまた、強大なドリタラーシュトラの軍を粉砕した。
drāvyamāṇaṃ balaṃ dṛṣṭvā bhīmasenena dhīmatā|
yantāramabravītkarṇaḥ pāñcālāneva māṃ vaha||
// 8-82-9 //
知恵あるビーマセーナに軍が追い散らされるのを見て、カルナは御者に言った。「パーンチャーラ軍の方へ私を連れて行け。」
madrarājastataḥ śalyaḥ śvetānaśvānmahājavān|
prāhiṇoccedipāñcālānkarūśāṃś ca mahābalaḥ||
// 8-82-10 //
マドラ国王シャルヤは、白く俊足の馬を、チェーディ族・パーンチャーラ族・カルーシャ族へ向けて走らせた。
praviśya ca mahatsainyaṃ śalyaḥ parabalārdanaḥ|
nyayacchatturagānhṛṣṭo yatrayatra ca te rathāḥ||
// 8-82-11 //
敵の軍を苦しめるシャルヤは、大軍に突入し、喜んで馬を操り、戦車のあるところへ次々と向かった。
taṃ rathaṃ meghasaṅkāśaṃ vaiyāghraparivāraṇam|
saṃdṛśya pāṇḍupañcālāstrastā hyāsanviśāmpate||
// 8-82-12 //
雲のごとき、虎の皮で覆われたその戦車を見て、パーンドゥ軍とパーンチャーラ軍の者たちは、王よ、恐怖に陥った。
tato rathasya ninadaḥ prādurāsīnmahāraṇe|
parjanyasamanirghoṣaḥ parvatasyeva dīryataḥ||
// 8-82-13 //
大いなる戦場で、その戦車の轟音が響き渡った。それは、崩れ落ちる山のように、雷雲と同じ響きであった。
tataḥ śaraśataistīkṣaṇaiḥ karṇa ākarṇaniḥsṛtaiḥ|
jaghāna pāṇḍavabalaṃ śataśo'tha sahasraśaḥ||
// 8-82-14 //
カルナは、弓いっぱいに引き絞って放つ鋭い何百もの矢で、パーンダヴァの軍を百単位・千単位で殺した。
taṃ tathā samare karma kurvāṇamaparājitam|
parivavrurmaheṣvāsāḥ pāṇḍavānāṃ mahārathāḥ||
// 8-82-15 //
そのように戦場で無敵の業を行うカルナを、パーンダヴァ方の大弓持ちの大戦車戦士たちが取り囲んだ。
taṃ śikhaṇḍī ca bhīmaś ca dhṛṣṭadyumnaś ca pārṣataḥ|
nakulaḥ sahadevaś ca draupadeyāś ca sātyakiḥ||
parivavrurjighāṃsanto rādheyaṃ śaravṛṣṭibhiḥ|
sātyakistu tadā karṇaṃ viṃśatyā niśitaiḥ śaraiḥ||
// 8-82-16-17 //
シカンディン、ビーマ、パールシャタ・ドリシュタデュムナ、ナクラ、サハデーヴァ、ドラウパディーの息子たち、サーティヤキが、矢の雨でラーデーヤ（カルナ）を殺そうと取り囲んだ。勇敢な人中の最上者サーティヤキは二十本の鋭い矢でカルナの胸を射た。
atāḍayadraṇe śūro jatrudeśe narottamaḥ|
śikhaṇḍī pañcaviṃśatyā dhṛṣṭadyumnaś ca saptabhiḥ||
// 8-82-18 //
シカンディンは二十五本で、ドリシュタデュムナは七本で射た。
draupadeyāś catuḥṣaṣṭyā sahadevaś ca saptabhiḥ|
nakulaś ca śatenājau karṇaṃ vivyādha sāyakaiḥ||
// 8-82-19 //
ドラウパディーの息子たちは六十四本で、サハデーヴァは七本で、ナクラは百本の矢でカルナを戦場で射た。
bhīmasenastu rādheyaṃ navatyā nataparvaṇām|
vivyādha samare kruddho jatrudeśe mahābalaḥ||
// 8-82-20 //
大力のビーマセーナは、怒り狂って九十本のまっすぐな節の矢でラーデーヤの胸を戦場で射た。
atha prahasyādhirathirvyākṣipaddhanuruttamam|
mumoca niśitānbāṇānpīḍayansumahābalaḥ||
// 8-82-21 //
そしてアディラタの子（カルナ）は笑って最上の弓を引き絞り、鋭い矢を放ち、大いなる力で敵を苦しめた。
tānpratyavidhyadrādheyaḥ pañcabhiḥ pañcabhiḥ śaraiḥ|
sātyakestu dhanuśchittvā dhvajaṃ ca bharatarṣabha||
// 8-82-22 //
ラーデーヤは五本ずつの矢で彼ら各人を射返した。バーラタの雄牛よ、サーティヤキの弓と旗を切り落とし——
taṃ tathā navabhir bāṇairājaghāna stanāntare|
bhīmasenaṃ tataḥ kruddho vivyādha triṃśatā śaraiḥ||
// 8-82-23 //
九本の矢でサーティヤキの胸を射た。そして怒り狂い、三十本の矢でビーマセーナを射た。
sahadevasya bhallena dhvajaṃ ciccheda māriṣa|
sārathiṃ ca tribhir bāṇairājaghāna parantapaḥ||
// 8-82-24 //
サハデーヴァの旗を鏃で切り落とし、三本の矢で御者を射た、敵を滅ぼす者よ。
virathāndraupadeyāṃś ca cakāra bharatarṣabha|
akṣṇornimeṣamātreṇa tadadbhutamivābhavat||
// 8-82-25 //
バーラタの雄牛よ、ドラウパディーの息子たちを、瞬きする間に戦車を失わせた。それはまるで奇跡のようであった。
vimukhīkṛtya tānsarvāñśaraiḥ sannataparvabhiḥ|
pāñcālānahanañchūrāṃścedīnāṃ ca mahārathān||
// 8-82-26 //
まっすぐな節の矢で彼ら全員を退け、勇敢にもパーンチャーラの戦士たちとチェーディ族の大戦車戦士たちを殺した。
te vadhyamānāḥ samare cedimatsyā viśāmpate|
karṇamekamabhidrutya śarasaṅkhaiḥ samārpayan||
// 8-82-27 //
王よ、戦場でチェーディ族とマツヤ族が殺されながらも、カルナ一人に向かって突撃し、矢の群れを浴びせた。
tāñjaghāna śitairbāṇaiḥ sūtaputro mahārathaḥ|
te vadhyamānāḥ samare cedimātsyā viśāmpate|
prādravanta raṇe bhītāḥ siṃhatrastā mṛgā iva||
// 8-82-28 //
スータの子の大戦車戦士は鋭い矢で彼らを殺した。王よ、戦場で殺されるチェーディ族とマツヤ族は、獅子に怯える鹿のように恐怖に駆られて逃げ散った。
etadatyudbhataṃ karma dṛṣṭvānasmi bhārata|
yadekaḥ samare śūrānsūtaputraḥ pratāpavān||
yatamānānparaṃ śaktyā yodhayānāṃś ca dhanvinaḥ|
pāṇḍaveyānmahārāja śarairvāritavānraṇe||
// 8-82-29-30 //
バーラタよ、この極めて驚異的な業を見た。スータの子の威光ある勇者が、戦場で一人で、全力で戦い、弓の名手たるパーンダヴァの勇者たちを、大王よ、矢で阻止したのを。
tatra bhārata karṇasya lāghavena mahātmanaḥ|
tutuṣurdevatāḥ sarvāḥ siddhāś ca saha cāraṇaiḥ||
// 8-82-31 //
バーラタよ、偉大なカルナの身軽さに、全ての神々とシッダたちとチャーラナたちが満足した。
apūjayanmaheṣvāsā dhārtarāṣṭrā narottamam|
karṇaṃ rathavaraśreṣṭhaṃ śreṣṭhaṃ sarvadhanuṣmatām||
// 8-82-32 //
大弓持ちのドリタラーシュトラの息子たちは、全ての弓持ちの中の最上、戦車戦士の最上たるカルナを称賛した。
tataḥ karṇo mahārāja dadāha ripuvāhinīm|
kakṣamiddho yathā vahnirnidādhe jvalito mahān||
// 8-82-33 //
大王よ、カルナは敵の軍を焼き尽くした。夏の乾季に燃え盛る火が枯れ草を焼くように。
te vadhyamānāḥ karṇena pāṇḍaveyāstatastataḥ|
prādravanta raṇe bhītāḥ karṇaṃ dṛṣṭvā mahāratham||
// 8-82-34 //
カルナに討たれて、パーンダヴァ軍はあちこちに恐怖に駆られて逃げ散った。大戦車戦士カルナを見て。
tatrākrando mahānāsītpāñcālānāṃ mahāraṇe|
vadhyatāṃ sāyakaistīkṣṇaiḥ karṇacāpavaracyutaiḥ||
// 8-82-35 //
大いなる戦場で、カルナの弓から放たれる鋭い矢に討たれるパーンチャーラ族の叫び声は大きかった。
tena śabdena vitrastā pāṇḍavānāṃ mahācamūḥ|
karṇamekaṃ raṇe yodhaṃ menire tatra śātravāḥ||
// 8-82-36 //
その音に恐れおののいたパーンダヴァの大軍は、戦場においてカルナ一人をそこに残る唯一の戦士とみなした。
tatrādbhutaṃ punaścakre rādheyaḥ śatrukarśanaḥ|
yadenaṃ pāṇḍavāḥ sarve na śekurabhivīkṣitum||
// 8-82-37 //
そこでラーデーヤ（カルナ）は、敵を苦しめる者として、さらに驚異的なことをした。パーンダヴァたちの誰一人として彼を見ることさえできなかったのだ。
jalaughaḥ parvataśreṣṭhaṃ yathāsādya prabhidyate|
tathā tatpāṇḍavaṃ sainyaṃ karṇamāsādya dīryate||
// 8-82-38 //
水流が山の頂に当たって砕けるように、パーンダヴァの軍はカルナに当たって崩れた。
karṇo'pi samare rājanvidhūmo'gniriva jvalat|
dahaṃstasthau mahābāhuḥ pāṇḍavānāṃ mahācamūm||
// 8-82-39 //
王よ、カルナもまた戦場で、煙のない燃え盛る火のように、大いなる腕を持ってパーンダヴァの大軍を焼き尽くしながら立っていた。
śirāṃsi ca mahārāja karṇāṃ ścaiva sakuṇḍalān|
bāhūṃś ca vīro vīrāṇāṃ ciccheda laghu ceṣubhiḥ||
// 8-82-40 //
大王よ、勇者は耳飾りのついた頭、勇者たちの腕を、素早く矢で切り落とした。
hastidantatsarūnkhaṅgāndhvajāñśaktīrhayāngajān|
rathāṃś ca vividhānrājanpatākā vyajanāni ca||
akṣaṃ ca yugayoktrāṇi cakrāṇi vividhāni ca|
ciccheda bahudhā karṇo yodhavratamanuṣṭhitaḥ||
// 8-82-41-42 //
象の牙で作られた剣鞘・剣・旗・槍・馬・象・様々な戦車、旗と払子を、車軸・軛・繋ぎ紐・様々な車輪を、カルナは戦士の務めを守りつつ、幾重にも切り裂いた。
tatra bhārata karṇena nihatairgajavājibhiḥ|
agamyarūpā pṛthivī māṃsaśoṇitakardamā||
// 8-82-43 //
バーラタよ、カルナに殺された象と馬で、大地は肉と血のぬかるみとなり、通行不能となった。
viṣamaṃ ca samaṃ caiva hatairaśvapadātibhiḥ|
rathaiś ca kuñjaraiś caiva na prājñāyata kiñcana||
// 8-82-44 //
殺された馬・歩兵・戦車・象で、高低の区別もつかず、何も見分けることができなかった。
nāpi sve na pare yodhāḥ prājñāyanta parasparam|
ghore śarāndhakāre tu karṇāstre ca vijṛmbhite||
// 8-82-45 //
カルナの武器から生じた恐ろしい矢の闇の中で、味方も敵も互いを見分けることができなかった。
rādheyacāpanirmuktaiḥ śaraiḥ kāñcanabhūṣaṇaiḥ|
sañchāditā mahārāja pāṇḍavānāṃ mahārathāḥ||
// 8-82-46 //
ラーデーヤの弓から放たれた黄金で飾られた矢で、大王よ、パーンダヴァの大戦車戦士たちは覆い尽くされた。
te pāṇḍaveyāḥ samare rādheyena punaḥ punaḥ|
abhajyanta mahārāja yatamānā mahārathāḥ||
// 8-82-47 //
大王よ、パーンダヴァ軍の大戦車戦士たちは、力を尽くすも、戦場でラーデーヤに何度も打ち破られた。
mṛgasaṅghānyathā kruddhaḥ siṃho drāvayate vane|
pañcālānāṃ rathaśreṣṭhāndrāvayañśātravāṃstathā||
// 8-82-48 //
怒れる獅子が森で鹿の群れを追い散らすように、カルナはパーンチャーラの最上の戦車戦士たちと敵を追い散らした。
karṇastu samare yodhāṃstrāsayunsumahāyaśāḥ|
kālayāmāsa tatsainyaṃ yathā paśugaṇānvṛkaḥ||
// 8-82-49 //
大いなる名声のカルナは戦場で戦士たちを震え上がらせ、狼が家畜の群れを殺すように、その軍を殺し尽くした。
dṛṣṭvā tu pāṇḍavīṃ menāṃ dhārtarāṣṭrāḥ parāṅyukhīm|
tatrājagmurmaheṣvāsā rudanto bhairavātravān ||
// 8-82-50 //
パーンダヴァの軍が背を向けて逃げるのを見て、ドリタラーシュトラの息子たちの大弓持ちたちは恐ろしい叫び声を上げながらやって来た。
duryodhano hi rājendra mudā paramayā yutaḥ|
vādayāmāsa saṃhṛṣṭo nānāvādyāni sarvaśaḥ||
// 8-82-51 //
王の中の王よ、ドゥルヨーダナは最高の喜びに満ち、様々な楽器を喜んで打ち鳴らした。
pāñcālāś ca maheṣvāsā bhagnāstatra narottamāḥ|
nyavartanta tadā śūrā mṛtyuṃ kṛtvā nivartanam||
// 8-82-52 //
大弓持ちのパーンチャーラ族は打ち破られ、人中の最上の勇者たちは、死を覚悟で引き返した。
tānnivṛttānraṇe śūrānrādheyaḥ śatrutāpanaḥ|
anekaśo mahārāja babhañja puruṣarṣabhaḥ||
// 8-82-53 //
戦場で引き返した勇者たちを、敵を苦しめるラーデーヤ、人中の雄牛は、大王よ、幾度となく打ち破った。
tatra bhārata karṇena pāñcālā viṃśatī rathāḥ|
nihatāḥ sāyakaiḥ krodhāccedayaś ca paraṃśatāḥ||
// 8-82-54 //
バーラタよ、カルナはパーンチャーラの二十台の戦車を鋭い矢で殺し、チェーディ族の何百人もを怒りで殺した。
kṛtvā śūnyānrathopasthānvājipṛṣṭhāṃś ca bhārata|
nirmanuṣyāngajaskandhānpādātāṃścaiva vidrutān||
// 8-82-55 //
バーラタよ、戦車の台座を空にし、馬の背から騎手を落とし、象の背を無人にし、歩兵を逃走させた。
āditya iva madhyāhne durnirīkṣyaḥ parantapaḥ|
kālāntakavapuḥ śūraḥ sūtaputro'bhyarājata||
// 8-82-56 //
正午の太陽のように見つめ難く、敵を滅ぼすスータの子は、死神の時のような姿をした勇者として輝いた。
evametanmahārāja naravājirathadvipān|
hatvā tasthau maheṣvāsaḥ karṇo'rigaṇasūdanaḥ||
// 8-82-57 //
大王よ、このようにして大弓持ちのカルナ、敵の群れを滅ぼす者は、人・馬・戦車・象を殺して立っていた。
yathā bhūtagaṇānhatvā kālastiṣṭhenmahābalaḥ|
tathā sa somakānhatvā tasthāveko mahārathaḥ||
// 8-82-58 //
強大な死神が生き物の群れを殺して立つように、その大戦車戦士は一人でソーマカ族を殺して立っていた。
tatrādbhutamapaśyāma pāñcālānāṃ parākramam|
vadhyamānā'pi yatkarṇaṃ nājahū raṇamūrdhani||
// 8-82-59 //
パーンチャーラ族の武勇にも驚嘆すべきものがあった。殺されながらもカルナを戦場の先頭で見捨てなかったことだ。
rājā duḥśāsanaścaiva kṛpaḥ śāradvatastathā|
aśvatthāmā kṛtavarmā śakuniś ca mahābalaḥ|
vyahananpāṇḍavīṃ senāṃ śataśo'tha sahasraśaḥ||
// 8-82-60 //
王（ドゥルヨーダナ）とドゥフシャーサナ、シャラドヴァットの子クリパ、アシュヴァッターマン、クリタヴァルマン、大力のシャクニが、パーンダヴァの軍を百単位・千単位で殺した。
karmaputrau tu rājendra bhrātarau satyavikramau|
nijaghnāte balaṃ kruddhau pāṇḍavānāmitastataḥ||
// 8-82-61 //
王の中の王よ、カルナの二人の息子、真の武勇を持つ兄弟も、怒り狂ってパーンダヴァの軍をあちこちで殺した。
tatra yuddhaṃ mahaccāsītkrūraṃ viśasanaṃ mahat||
// 8-82-62 //
そこでは大いなる激しい戦闘と恐ろしい殺戮があった。
tathaiva pāṇḍavāḥ śūrā dhṛṣṭadyumnaśikhaṇḍinau|
draupadeyāś ca saṅkruddhā abhyaghnaṃstāvakaṃ balam||
// 8-82-63 //
同様に、勇敢なパーンダヴァ方のドリシュタデュムナとシカンディン、怒れるドラウパディーの息子たちも、汝の軍を攻撃した。
evameṣa kṣayo vṛttaḥ pāṇḍavānāṃ tatastataḥ|
tāvakānāmapi raṇe bhīmaṃ prāpya mahābalam||
// 8-82-64 //
このように、パーンダヴァ軍のあちこちでの壊滅と、大力のビーマに出会った汝の軍の壊滅が起こった。
iti śrīmanmahābhārate karṇaparvaṇi saptadaśadivasayuddhe dvyaśītitamo'dhyāyaḥ|| 82 ||
